Topic 19874

Test System Speed

DSM currently does not support X modes. Therefore, DSM is limited to the base frequency of the test system.

Within a test suite, both X modes and DSM can be used, just not together. Different test suites can use either X modes or DSM independently; for example, one test suite could use X modes and another test suite could use DSM.

Functional changes

  1. Introduced before SmarTest 6.3.2
