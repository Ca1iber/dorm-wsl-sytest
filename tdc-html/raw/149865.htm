CCTgetPAResultId()

Retrieves the remembered PA result id list (remembered using the CCTaddPAResultId() API).

Syntax

vector<string>& CCTgetPAResultId();

Example

virtual void init()
{
    vector<string> resultID = CCTgetPAResultId();
          PROTOCOL_TEST_RESULT_VECTOR result;
result = 2ndWapper::getInstance(tsName).getPAImpResults(resultID);
   
}

Related information

CCTaddPAResultId()

Functional changes

  1. Introduced in SmarTest 7.3.3
