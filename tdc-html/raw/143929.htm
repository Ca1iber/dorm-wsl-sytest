getVecVar()

Retrieves the vector variable name created for the digital capture pin.

Syntax

string getVecVar(const string& pin);
List of parameters

Parameter

Description

pin

The pin to query.

Example

rdi.id("dc_hidden_4pins").getVecVar("DATA2");

Functional changes

  1. Introduced in SmartRDI 2.1.0
