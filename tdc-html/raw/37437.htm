Topic 37437

Introduction to the ASCII Interface

Subtopics

  1. Basic Translation Concept
  2. High Level Tools and Low Level Tools
  3. How to Read the Graphics

This chapter introduces to the basic translation concept of the ASCII interface and gives an overview of its module structure. It is intended for readers who have a good knowledge of SmarTest, but know nothing about the ASCII interface. Its purpose is to supply this target audience with the information that is needed to understand the following chapters.

The chapter consists of three sections:

  • The first section, Basic Translation Concept, describes the essentials of the translation process. It explains the fundamental concept of an ASCII device cycle, describes the two main input files for the tool (ASCII timing file and ASCII vector file), and shows how timing translation and vector translation, the two main parts of the ASCII interface, interlock.
  • The second section, High Level Tools and Low Level Tools, explains that for both timing and vector translation there is a high level user interface and a low level module that is called repeatedly by the user interface. It also indicates how the timing translation can create nearly all the information that is needed by the vector translation, except the ASCII vector files.
  • The third section, How to Read the Graphics, explains the components of the graphical examples, of which there are a great number in this document.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.2.0: ASCII interface 5.4.15 requires V93000 SmartInstall 1.3.6-0 or higher
