Example program for calling CPI functions

This example program uses the CPI function SetSystemFlag(). It can be called from your production test shell to pause, resume or abort SmarTest.

The following is the source code of set_flag:

/* List the standard header files. */
#include <stdio.h>

/* List the custom header files. */
#include "tpi_c.h"
#include "ci_types.h"
#include "libcicpi.h"
int main(int argc, char *argv[])
{
    /* Declare the local variables. */
    long lReturnValue;
    int iExitStatus;

    HpInit();

    /* Check for a valid argument count. */
    if (argc == 2)
    {
        /* Set or clear the appropriate system flag. */
        if (strcmp(argv[1], "CI_PAUSE") == 0)
        {
            /* Set the CI_PAUSE system flag. */
            lReturnValue = SetSystemFlag(CI_PAUSE, 1);
        }
        else if (strcmp(argv[1], "CI_RESUME") == 0)
        {
            /* Clear the CI_PAUSE system flag. */
            lReturnValue = SetSystemFlag(CI_PAUSE, 0);
        }
        else if (strcmp(argv[1], "CI_ABORT") == 0)
        {
            /* Set the CI_ABORT system flag. */
            lReturnValue = SetSystemFlag(CI_ABORT, 1);
        }
        else
        {
            /* Error - invalid system flag. */
            lReturnValue = 1;
        }

        /* Set the exit status based on the return value. */
        if (lReturnValue == 0)
        {
            iExitStatus = CI_CALL_PASS;
        }
        else
        {
            iExitStatus = CI_CALL_ERROR;
        }
    }
    else
    {
        /* Error - invalid argument count. */
        iExitStatus = CI_CALL_ERROR;
    }
      HpTerm();
      exit(iExitStatus);
}

You can compile this program by creating a makefile using the install_cs program:

$ /opt/hp93000/soc/prod_env/lbin/install_cs -t PROGRAM

Remove the default pg_templ.c:

$ rm pg_templ.c

Update the makefile with the new C file set_flag.c:

$ make depend

You can try it out without any custom production shell by running it from the command line as follows:

$ ./set_flag (CI_PAUSE|CI_RESUME|CI_ABORT)

Here CI_RESUME is a custom value, which will set the CI_PAUSE flag to 0. The following example will pause SmarTest:

$ ./set_flag CI_PAUSE
