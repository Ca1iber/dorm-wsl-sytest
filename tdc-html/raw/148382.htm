VEC_TRANSFER_PIN_TASK

The VEC_TRANSFER_PIN_TASK class is a data container holding the object that reflects the pin data. The target label and download vector address are specified via the class VEC_TRANSFER_TASK. The VEC_TRANSFER_PIN_TASK class is called as a subsidiary data container of the VEC_TRANSFER_TASK class.

Syntax

VEC_TRANSFER_PIN_TASK & data(const ARRAY_I & data);

Specifies the vector data that is used to modify the label specified in VEC_TRANSFER_TASK. The size of data has to be equal to the block size specified in VEC_TRANSFER_TASK. The array contains physical waveform DC/DC power units.
