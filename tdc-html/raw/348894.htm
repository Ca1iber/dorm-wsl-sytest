rdi.id().getMultiPassFail()

Retrieves per-label pass/fail results from all patterns in the burst.

Before this function is implemented, only burst pass/fail results can be retrieved from the rdi.func().burst().execute(); action in the static mode. With this function, per-label pass/fail results from burst can be retrieved.

Syntax

ARRAY_I& rdi.id().getMultiPassFail();
ARRAY_I& rdi.id().getMultiPassFail(string sPort=="@");
List of parameters
Parameter Description
sPort The port name.

Examples

Also see the example in rdi.func().burstRunTime().

rdi.func("id1").burst("burstPattern").perLabelPassFail(true).execute(); 
ARRAY_I ary = rdi.id("id1").getMultiPassFail(); 

rdi.func("id2").burst("MP_burst").perLabelPassFail(true).execute(); 
ARRAY_I ary2 = rdi.id("id2").getMultiPassFail("port1"); 
ARRAY_I ary3 = rdi.id("id2").getMultiPassFail("port2");
