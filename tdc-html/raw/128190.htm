Defining a protocol

Subtopics

  1. Setting up the protocol definition
  2. Assigning pin roles and protocols
  3. Modifying an existing protocol definition
  4. Validating a protocol definition
  5. Example: Defining a MDIO protocol

This chapter describes how to set up a new or modify an existing protocol definition.

Defining a new protocol always has two key elements:

  • Transferring the device independent protocol's definition to SmarTest, which is covered in Setting up the protocol definition.
  • Linking device independent and dependent protocol related details together, which is covered in Assigning pin roles and protocols

Functional changes

  1. Introduced in SmarTest 7.1.2
