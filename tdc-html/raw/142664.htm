HSM Service & Support Guide

The HSM Series test system service and support guide is available now in version 1.6.

This guide describes all details necessary

  • to plan and prepare the installation site for the V93000 High-Speed MemorySeries test system. It provides floor plans and gives hints on unpacking and placing the test system. It also includes information on system requirements.

    An HSM Series test system comes in two different configurations:

    The large test head based system consisting of:

    • large test head (LTH)
    • manipulator
    • standard support rack
    • cooling unit (E2760FC) (one for each test system)
    • calibration robot (E8006A) (for the first and every third to fifth test system)
    • focus calibration unit (E8606A) (for several test systems)
    • system controller (PC)

      The compact test head (CTRL) based system consisting of:

    • compact test head (CTH)
    • manipulator (optional)
    • engineering cart
    • cooling unit (E2760FC) (one for four test systems)
    • calibration robot (E8006A) (for the first and every third to fifth test system)
    • focus calibration unit (for several test systems)
    • system controller (WS XW8200) (PC)

      A Site Preparation Checklist helps you verify that all system requirements have been met.

  • to install the test system. You find information on how to unpack and connect the system components and how to install and configure the software. In case you have to return a part of the system for repair you will find here some hints on packing the major components for safe shipment.
  • to regularly maintain the test system. It gives you information on tasks to be performed after three, six, nine and twelve months of operation. The various maintenance procedures are described in detail. The steps within these chapters must be followed closely to avoid the risk of injury to personnel or damage to equipment.
  • to service the test system. Even the most careful handling of your test system or its components may not be sufficient to prevent damage. This chapter gives you instructions on how to
    • diagnose the test system
    • repair and replace units of the test system
  • to operate the test system safely
