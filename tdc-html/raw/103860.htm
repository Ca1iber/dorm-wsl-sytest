LoopLevel()

This API issues the AppModelLevelLoopEventType EDL event if the implicit event generation is turned on. It is called at the beginning of each loop of a level.

SUCCESS will be returned if no error occurred. Otherwise, an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • There is no active level currently.

RECOVERABLE

Parameters

I/O

Parameter

Description

I

SESSION_ID

The local session ID.

Prototype

Status syncCommand("LoopLevel", ParamList(), sessionID);

Example

string sid = LOCAL_SESSION_ID; //the local session ID

Status retVal = syncCommand("LoopLevel", ParamList(), sid);
if ( retVal.isError() ) 
{
cout<<"error code= " << retVal.code() << " description=" << retVal.text() << endl;
}

Functional changes

  1. Introduced in SmarTest 6.5.0
