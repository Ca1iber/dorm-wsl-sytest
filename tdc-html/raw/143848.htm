Topic 143848

pin()

Specifies the pin(s) for the following DC actions. It indicates the ending of the setups for the previous pin(s) and the start of the setups for the specified pin(s).

Do not specify different types of pins in the same function pin(). To set up different types of pins in the same line of code, put different types of pins in separate functions of pin() with the same execute().

Syntax

pin(const string& sPin, TA::PinType instrument = TA::PPMU);
List of parameters

Parameter

Description

sPin

The pin on which the following setups will be done. Its value can be a pin, a pin group, a port name as a pin group, the pins or pin groups separated with comma, or all pins.

instrument

The instrument used to do the measurement. It is TA::SPMU for SPMU test.

Example

rdi.dc("vMeas").pin("pinA",TA::SPMU).vMeas().execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 2.4.0: Support a port name as a pin group.
