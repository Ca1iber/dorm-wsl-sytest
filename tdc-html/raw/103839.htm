EvalWaferDescriptionFile()

This API loads the wafer description file and parse the wafer map so that the FTEST process and the PH drivers can read the content of it. It should be put before the execution of a testflow and the PH driver call ph_die_start.

SUCCESS will be returned if no error occurred. Otherwise, an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

PARAMETER_EXCEPTION
  • The value of the parameter "WAFER_DESCRIPTION_FILE" is empty.
  • The value of the parameter "WAFER_DESCRIPTION_FILE" should only be a name relative to the currently loaded device.

RECOVERABLE

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • The local session does not exist.
  • The test type is not wafer sort, not necessary to evaluate the wafer description file.
  • Currently there is no device downloaded.
  • Can not access the wafer description file <XXX> in the device directory.
  • Failed to load the wafer description file to the tester.
  • The format of the wafer description file is not valid.
  • Failed to open the loaded wafer description file for read.

RECOVERABLE

Parameters

I/O

Parameter

Description

I

SESSION_ID

The ID of the SmarTest session to work with.

I

WAFER_DESCRIPTION_FILE

The wafer description file.

Prototype

ParamList inputParams;
Status syncCommand("EvalWaferDescriptionFile", inputParams, sessionID);

Syntax

string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams; 
inputParams["WAFER_DESCRIPTION_FILE"] = "wafer_file";

Status retVal = syncCommand("EvalWaferDescriptionFile", inputParams, sid);
if ( retVal.isError() ) 
{
cout<<"error code= " << retVal.code() << " description="
    << retVal.text() << endl;
}

Functional changes

  1. Introduced in SmarTest 6.5.0
