The configuration for handlers

The table below lists the plug-ins, configuration files and cables for directly supported handlers.

Please note the following:

  • Seiko-Epson handlers can be set up either with serial or parallel binning (with exception of the NS 5000 F(0)/F3/ F4 handler).
  • Multitest handlers can be set up either with explicit or encoded binning.

    See Multitest Handlers for more information.

    Note If your handler model is not listed, please see Creating a New Driver Configuration and Configuring a Custom GPIO Cable (for handlers with GPIO interface).
    Note For some handlers with GPIO interface, there is no preconfigured handler cable available. Refer to the sections listed in the footnotes of the table below for information on configuring the respective cable.
