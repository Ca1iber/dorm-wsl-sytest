Topic 343551

Routing Tools configuration

The digital control pins for sequencer‑controlled utility lines, the configuration of the PMUX cards and the digital control pins for the PMUX cards and the XML file, which holds the complete setup and state data of the Routing Tools editors, must be defined.

Sequencer‑controlled utility lines

The serial interface of Sequencer-controlled utility lines is to be connected to four digital pins. One set of four digital pins controls the serial interface of one single utility pogo block or up to eight utility pogo blocks if "ganging" of utility blocks is used.

Unlike shown in SmartRDI: Utility lines control, the control pins for the sequencer controlled utility lines must be defined in the Routing Tools - Utility Lines Control editor if the Routing Tools are to be used.

Routing Tools setup file

The Routing Tools setup file holds all configuration data for software controlled utility lines, sequencer‑controlled utility lines and the MUX cards. The predefined switch states are also stored in this file. The file is created and stored by the Routing Tools editors.

The setup file to be loaded must be defined in the RDI_Configure file. For more information, refer to keyword ROUTING_SETUP_FILE in topic RDI_Configure file.

Function rdi.route().downloadPmuxMemSet() must be called at least once in the test program flow. The function does not only download the PMUX switch states but also reads and processes the setup file.
Note The function rdi.route().downloadPmuxMemSet() must be called at least once in the test program flow even if only utility lines are controlled by the Routing Tools.
