Topic 131085

execute()

Executes the resampling operation.

Syntax

bool execute(const ARRAY_COMPLEX& inputData, ARRAY_COMPLEX& resultData);
bool execute(ARRAY_COMPLEX& data);
bool execute(const ARRAY_D& inputData, ARRAY_D& resultData);
bool execute(ARRAY_D& data);
bool execute(const DOUBLE_VECTOR& inputData, DOUBLE_VECTOR& resultData);
bool execute(DOUBLE_VECTOR& data);
Parameters

I/O

Parameter

Notes

Type

I

inputData

Array of input data

ARRAY_COMPLEX/ARRAY_D/DOUBLE_VECTOR

O

resultData

Array of output data

ARRAY_COMPLEX/ARRAY_D/DOUBLE_VECTOR

IO

data

Array of input/output data

ARRAY_COMPLEX/ARRAY_D/DOUBLE_VECTOR

Returns

Returns true if the resampling operation was successful.

Example

ARRAY_COMPLEX cwave = MEAS_DEF().getComplexWaveform(1);
DOUBLE Fs;
MEAS_DEF().get("SampleRate", 1, Fs);
RESAMPLER myResampl;
myResampl.init(Fs, 2*Fs, WINDOW_RESAMPLER);
if (myResampl.execute(cwave)) {
    // do something on cwave
}
