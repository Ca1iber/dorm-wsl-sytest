Reference between channel and port

Channel

When you add a channel SmarTest automatically adds the corresponding port value.

If there is no associated firmware port value the port entry will not be changed.

If the channel is not supported by the firmware, SmarTest displays a warning on the annotation bar.

Port

When you add a port SmarTest automatically adds the corresponding channel value.

If there is no associated firmware channel value the channel entry will not be changed.

If the port is not supported by the firmware, SmarTest displays a warning on the annotation bar.
