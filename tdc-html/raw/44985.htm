Command Set Dependencies

Note the following:

  • All Function Command Sets are dependent on libcicpi.so (CPI functionality).
  • All Program Command Sets are dependent on libcicpi.so (CPI functionality).
  • All Ci processes are deposited in prod_env/lib, and are accessed through the use of links from Command Set directories. If any Ci is updated, the update is automatically seen by every user Command Set, without intervention.
