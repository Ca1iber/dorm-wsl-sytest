Create

The Create subcommand is used to create a list object.

Syntax

DDEF {"ListName"},{Create},{"ListType"}, {"Comment"}

Parameters

ListName

User-defined unique name to identify what type of data list is being defined. It is a string without a ".".

Create

Create is used to create a new object.

ListType

This is a case-sensitive, predefined keyword. The available types are FreqList, PowerList, and Hex32List.

FreqList: Used to create a Frequency List.

PowerList: Used to create a Power List.

Hex32List: Used to create a list of 32-bit unsigned integers.

Comment

This is an optional string of user-defined information.

Example

DDEF "myFreqList", CREATE,"FreqList","any comments"
DDEF "myPowerList", CREATE,"PowerList","any comments"
DDEF "myHex32List", CREATE,"Hex32List","BER List"

Functional changes

  1. Introduced before SmarTest 6.3.2
