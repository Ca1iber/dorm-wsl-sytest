Spec Searches from Spec Tool

The Spec Tool provides the possibility to search the transition values of spec variables. The transition value is the spec value where the result of the functional test switches from PASS to FAIL or vice versa.

Multi-Port Spec Searches

Spec searches can be used in a multiport setting as in non-multi-port settings. In a multiport setup where spec variables can be local or global the following rules apply:

  • If you execute a spec search for a spec variable on a port where the spec variable is global the spec variable will be shifted globally. That is, it will not only be varied on the pins of the port that is assigned to, but on the pins of all ports where the spec variable is defined as global.
  • If you execute a spec search for a spec variable on a port where the spec variable is local the spec variable will only be varied on the pins of that port.
