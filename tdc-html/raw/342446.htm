Getting the SmartRDI revision information

Subtopics

  1. getBuildDate()
  2. Macros to get the SmartRDI version number
  3. rdi.getActiveRdiRev()
  4. rdi.getCompileRdiRev()

SmartRDI provides functions and macros that help user to retrieve SmartRDI revision information including:

  • major, minor, quality and patch version numbers. See Macros to get the SmartRDI version number.
  • build date of the current beta revision. See getBuildDate().
  • currently selected revision. See rdi.getActiveRdiRev().
  • revision in use for compilation. See rdi.getCompileRdiRev().

Functional changes

  1. Introduced in SmartRDI 2.4.5
