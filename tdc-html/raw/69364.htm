Topic 69364

Quad-site-encoded configuration

Subtopics

  1. Valid combinations of plug-ins and configuration files
  2. Binning map
  3. GPIO box jumpering
  4. Timing diagram (Multitest quad-site-encoded)

The Multitest "Quad-site-encoded" configuration is valid for Multitest Quad-site handlers.

Supported handler models

  • mt9320
  • mt9510
  • mt9308/4

Features

  • up to 4 sites
  • 4 DUT signals
  • no global test start signal
  • serial binning
  • encoded binning
  • 32 bin categories
  • no "empty" bin

Required handler cable

There is no preconfigured handler cable available for this configuration. Please see Multitest handler cable with 50-pin SUB-D connector(new pin assignment) for the information on configuring the cable.
