Running Tests

Subtopics

  1. Changing the site in focus

Running tests in an engineering environment is very much the same as with single-site testing. You must, however, use the Site Control to select the Sites you wish to run your test for:

  1. Load the appropriate setup files.
  2. Open the testflow.
  3. Open the Site Control (see, Site Control Window) and select the Sites to be tested. Check the active boxes (this automatically also checks the enable boxes).
  4. Run the test suite.
  5. Open one of the result tools, like the Error Map for example, for further analysis.

The result tools always display the results of the Site in focus. To show the results of another Site, see the section Changing the site in focus.
