Topic 97890

Copying and pasting a group

About this task

By the function of copying and pasting, you can define a new group with other group as a starting point.

Before you begin

You have defined at least one pin group.

Procedure

  1. In the Test Program Explorer view, right-click the pin group name you want to copy (for example, io_out) and select Copy.
  2. Right-clicke of the groups and select Paste...
  3. Naming a Group window is displayed. Type the group name in the Group Name text box (for example, all_out). Click OK.

Results

TheGroup Editor of all_out opens. The setting of all_out is the same as for io_out.

What to do next

Edit the group all_out.
