Opening the Pattern Explorer

The Pattern Explorer displays all patterns of the loaded setup.

About this task

To create or change patterns you must open the Pattern Explorer.

Before you begin

Make sure the setup perspective is opened.

The setup perspective includes Test Program Explorer. From here, you open the Pattern Explorer.

Procedure

  1. If not yet done, load the following setup components:
    • Pin Configuration,
    • Levels,
    • Timing,
    • Pattern,

      as described in Loading a single setup component.

  2. In the Test Program Explorer double-click the pattern item.
    Note When debugging a test flow, you can also click the failing test suite, to display its properties. In the Properties view, either right-click the pattern item and select Open Pattern or press F3. This opens the Pattern Explorer and loads the pattern in the editor.

Results

The Pattern Explorer opens and displays the patterns of the currently loaded setup.
