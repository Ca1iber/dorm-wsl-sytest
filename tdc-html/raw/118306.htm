AC test function conversion

  2. Input Voltage Sensitivity conversion
  3. Output Voltage Sensitivity Conversion

  5. Hold Time test function conversion
  6. Propagation Delay conversion

There are several AC test functions which have no equivalent predefined test method libraries. But you can convert these test functions to the test method libraries by modifying the device setup files and adjusting the parameters of test method libraries.

  • To convert the Frequency test function to the predefined test method library, you can use the ac_tml.AcTest.frequency_ByDigitalCapture test method. But you need to create new setups to use digital capture.
  • To convert the test functions Global Search, Hold Time, Setup Time, Input Voltage Sensitivity, Output Voltage Sensitivity, Propagation Delay and Output Data Hold Time to test method library, you can use the ac_tml.AcTest.parametricFunctionalTest test method. You need to modify the device setup files and adjust the parameters of ac_tml.AcTest.parametricFunctionalTest to implement different tests.
  • To convert the Jitter test function to test method library, you can use the ac_tml.AcTest.jitterHistogram test method. But a different test methodology is used in the measurement.

In this section, the conversions of Global Search, Hold Time, Setup Time, Input Voltage Sensitivity, Output Voltage Sensitivity, Propagation Delay and Output Data Hold Time are described in detail.
