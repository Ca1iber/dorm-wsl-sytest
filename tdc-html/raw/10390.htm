The commands described in this manual are firmware instructions which you can use for low level control of the test system.

You can do this in the following ways:

  • issue firmware commands using the /opt/hp93000/soc/pws/bin/hpt or /opt/hp93000/soc/fw/bin/hpt utility.
  • include firmware commands within test methods (with the FW_TASK API).
  • issue firmware commands directly in the SmarTest Work Center's Firmware view.

This manual describes the firmware commands required to:

  • Configuration Setup Commands
  • Level Setup Commands
  • Routing Setup Commands
  • Timing Setup Commands
  • Vector Setup Commands
  • Relays Control Commands
  • AC Test Function Commands
  • DC Measurement Commands
  • Test Result Commands
  • Utility Line Commands)
  • Calibration and Attributes Commands)

Before you perform any of these functions, you must first read the following sections in this chapter which provide a firmware overview, describe how to use the /opt/hp93000/soc/pws/bin/hpt utility, and describe the use of the command DSCP, DSCP? - (Define System Control Parameter) for setting up a new device.

Full syntax descriptions for the commands are given in Commands in alphabetical order.
