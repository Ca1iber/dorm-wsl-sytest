TSTL, TSTL? - (TeST Label)

The TSTL (TeST Label) command activates the label specified by label for editing. Many commands that modify the sequencer or the vector areas of a label require that the label has been activated with TSTL.

TSTL

TSTL {"label"}, [(port)]

TSTL?

TSTL?

returns: 

TSTL {"label"}, {(port)}

Parameters

label

Defines the label you wish to edit. Enter an alphanumeric string, 1 to 128 characters long, enclosed in double quotes. You can deactivate the currently selected label by specifying an empty string ("").

port

This parameter is ignored in the command. In the query reply, it specifies the port to which the active label belongs.

Application

Edit and download command in Pattern Tool.

Errors

An error is generated if:

  • the specified label does not exist.
  • the selected label is too long.
  • the test table or the sequencer is corrupt.
  • The waveform first free address and the sequencer program are not consistent with each other.

Example

TSTL "new",

This example selects the label "new" for editing.

Functional changes

  1. Introduced before SmarTest 6.3.2
