License requirements for transaction based protocol tests

Transaction based protocol testing on V93000 is licensed as a 'floating per tester' license.

This means that only one license per test system is required and the license can be shared between different systems.

The feature can be explicitly enabled in the GLOBAL section of either the model or device license file using the keyword protocol_aware.

For disabling the feature the corresponding entry either needs to be commented out, removed or explicitly turned off.

If there is no license available, but the feature is requested by the string protocol_aware = ON, an error will be displayed.

Note No license is required for offline mode!

If the feature is disabled, the system refuses to execute transaction based protocol tests. Creating, respectively loading and editing protocol setups is still possible.

Example

The following excerpt of a model file shows the syntax to be used in either the model or the device license file to request the feature.

...
GLOBAL
    testhead = TH_8CC
    dut_interface = SOC
    device_maintenance = ON
    timing_bundle = w256-d8-r8
    protocol_aware = ON
...
