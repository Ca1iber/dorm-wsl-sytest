loadCap()

Sets the load capacitance in Farad (F).

The load capacitance of the DUT or on the DUT board has an effect on the dynamic behavior of a DPS channel. The function is used to adapt the dynamic behavior of the channel to the load capacitance.

Some rules must be respected when changing the load capacitance. The rules are different for the supported DC Scale cards:
  • DPS128 / DPS64:

    • DPS128 allows for cap-less operation that is defined as working with some bypass capacitor network ≤ 10 nF.

    • The cap-less mode is enabled if the load capacitance is set to 0.0 μF by this API.
    • The cap-less mode is disabled and up to 470 μF per channel are supported if the load capacitance is set to any value > 0.0 μF1).
    • The reset value for the load capacitance is 1.0 μF: The cap-less mode is disabled and a load capacitance of up to 470 μF per channel is supported.
    • Default value if this API is omitted: The last programmed value is kept until it is (in disconnected state) explicitly programmed or the system is reset. This applies also if another setup is applied or the channel is disconnected and reconnected again.
    • The pin must be disconnected to set the load capacitance.
    • The function can be used only in the code‑based mode.
    • Function loadCap() can be used in combination with other functions that connect the channel.
    • The set load capacitance must be maintained in all following code‑based commands until the pin is disconnected. With cap-less mode already enabled by setting the load capacitance once to 0.0 μF, you can omit this API for the following setups.
    • Pattern‑based commands do not change the connection state. Therefore, connection state changes are supported with the load capacitance set in the code‑based mode.

      For further details, refer to Load capacitance connected to the DC Scale DPS128/DPS64.

  • XPS256:
    • The programmed analog load capacitance value is used to adapt the dynamic behavior of a pin to the load capacitance.
    • The default value for the load capacitance is 0.0 μF.
    • The load capacitance can be set with connected or disconnected pin.
    • The function can be used in code‑based mode and in pattern‑based mode.
    • Function loadCap() can be used in combination with all other functions.

Syntax

dcBase& loadCap(double cap)
Parameter

Parameter

Description

cap

The value of the load capacitor(s) in F (Farad).

Card-specific default value and range:
  • DPS128 / 64:
    • Range:
      • 0.0 μF: Enables the cap-less mode
      • > 0.0 μF: Enables the standard mode that supports a load capacitance of up to 470 μF per channel1).
    • Default value after reset: 1.0 μF - standard mode with load capacitance.
    • Default value if not programmed: The last programmed value or the reset value of 1 μF
  • XPS256: Refer to section Dynamic behavior in XPS256 programming - Force and clamp voltages.

Return Value

A reference to the dcBase object.

Example

rdi.dc().pin("DPS128_SIG").vForce(1).clamp(1 mA).loadCap(10e-6).execute();

Functional changes

  1. Introduced in SmartRDI 2.3.1
  2. SmartRDI 2.4.2: DC Scale AVI64 card added.
  3. SmartRDI 2.4.5: Minimum load capacity allowed changes from 1 uF to 1 nF, for better support of pattern‑based mode for AVI64.
  4. SmarTest 7.5.0: DC Scale FVI16 card added. Pattern‑based programming added for AVI64 and FVI16.
  5. SmarTest 7.10.1: DC Scale XPS256 card added.
1) Since the cap-less mode of DPS128/64 can be enabled or disabled only, we recommend, programming a value ≥ 1.0 μF to avoid any issue with the accuracy of internal calculations.
