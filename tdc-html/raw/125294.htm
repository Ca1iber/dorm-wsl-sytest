toSCS()

Calculates a state character sequence from a given integer or binary value.

The first parameter must be specified either as

  • integer or
  • string, representing a hexadecimal or binary value.

It represents the value that should be translated to a state character sequence.

Note An integer value is limited to 63 bits, as only positive numbers are supported (based on 64bit integer type).
Note The hexadecimal or binary values represented in a string are unlimited.

The second parameter represents the length of the resulting state character sequence.

The third parameter must be a sequence of two characters. The first character is used for logic '0' and the second as logic '1'.

Errors will be issued if,

  • the number does not fit into the specified length or
  • an invalid (negative) number is used with the first parameter or
  • an invalid type is used with the first parameter or
  • the length parameter is not of type integer or negative.

Syntax

sequence := toSCS(integer_constant , length, sequence)
sequence := toSCS(string, length , sequence)
Parameter

I/O

Parameter

Description

I

integer_constant

Integer value to be transformed to a state character sequence.

 

string

String representing a hex or bin value to be transformed to a SCS.

 

length

Overall length of the resulting state character sequence.

I

sequence

Two character sequence that determine the result.

First character is used for logic 0, second for logic 1, in analogy L and H.

Allowed sequences are either "01" or "LH".

Example

toSCS(1+2, 2*3, "01") is equal to toSCS(2,6,"01") and results in "000011".

toSCS(7, 3, "LH") results in "HHH".

toSCS(0, 2, "LH") results in "LL".

toSCS(0, 0, "LH") results in "".

toSCS("0x2", 2, "LH") results in "HL".

toSCS("0b111", 3, "01") results in "111".

toSCS(12, 3, "LH") results in "HLL".

toSCS("0x9", 3, "LH") results in "ERROR: number does not fit into specified length."

toSCS("0b11001", 2, "LH") results in "ERROR: number does not fit into specified length."

toSCS(-1, 3, "01") results in "ERROR: invalid number specified", because the integer has to be positive.

toSCS(0x123, 10, "LH") results in "ERROR: invalid first parameter"

toSCS(1, -1, "01") results in "ERROR: invalid number specified", because the resulting SCS length cannot be negative.

toSCS(5, 0x3, "LH") results in "ERROR: invalid second parameter."

toSCS("\"101\"", 3, "01") results in "ERROR: not allowed to specify a SCS as first parameter."

Functional changes
