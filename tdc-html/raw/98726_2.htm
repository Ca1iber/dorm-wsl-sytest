SAOF, SAOF? - (Set Alternating Operation Features)

The SAOF (Set Alternating Operation Features) command serves to change the operation mode of the test system software for certain tasks. After performing these tasks, you should switch back to the standard editing mode (ZERO) as soon as possible; many firmware commands do not work properly in the alternative modes.

SAOF

SAOF {mode|"label"}

SAOF?

SAOF?

returns:

SAOF {mode|"label"}

Parameters

mode

The operation mode which can take the following values:

ZERO

Editing mode. This is the default.

APP

This mode serves to append data to the sequencer and vector areas. In order to do that, you must first allocate memory for the respective area with the DMAS command. Now,in editing mode, the DMAS command defines the size of the area (it starts from address 0). If, however, the system is in APP mode, the existing area will be expanded by the size specified in the DMAS command.

Note that you cannot iterate this step. If you allocate memory in APP mode for a second time, the first expansion will be redefined. In order to further expand the area, you must first issue SAOFAPP again.

LOAD

Load vectors. This mode improves performance of a vector download.

TMLD

Load timing and/or pin attributes. This mode improves performance of a timing download.

EGRP

Edit group definitions.

label

If you call SAOF with a label name, you can generate a vector file for this label only.

Application

Test Program Explorer, Pattern Manager, Pin Configuration

Example

The following example illustrates the effects of the APP mode:

> SAOF?
< SAOF ZERO
> DMAS SQPG,SM,4,(@)
> DMAS SQPG,SM,3,(@)
> DMAS? SQPG,SM,(@)
< DMAS SQPG,SM,3,(@)
> SAOF APP
> DMAS SQPG,SM,4,(@)
> SAOF ZERO
> DMAS? SQPG,SM,(@)
< DMAS SQPG,SM,7,(@)

Functional changes
