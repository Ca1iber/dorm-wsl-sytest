Topic 43078

Selecting a new application model file

Selecting a new application model file, and loading/saving an application data file is done from within the Test Program Explorer.

When you select a new application model file, the software requests you specify one of the models from within the /opt/hp93000/soc/applic_models/ directory.

  1. In the Test Program Explorer highlight the Application Data item.
  2. Right-click and select new.

    The Application Model dialog lists all the empty types application file within the /opt/hp93000/soc/applic_models/ directory.

  3. Highlight the desired file and click OK.
  4. Enter a file name and click OK.

    A new file is created. Double-click the Application Data item in the Test Program Explorer to enter your data.
