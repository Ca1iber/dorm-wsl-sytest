Topic 81104

Loading the GDDR device

Procedure

  1. In SmarTest, import and select the GDDR3 device.
  2. Make the device current.
  3. Choose a test flow (if one exists already) and click Load.
  4. If the device file does not contain a test flow, create a test flow.
    Note Make sure no error message is displayed in the report window of SmarTest.

Results

The test flow is opened in the test flow editor.
