DRLShmooAxisData

You can use a variable of this type to record the configurations of a shmoo plot axis.

  • start: The start value on the axis.
  • stop: The stop value on the axis.
  • totalSteps: The number of steps on the axis.
  • linearSteps: The number of linear steps on the axis.
  • primaryValue: The primary value of the shmooed resource.
  • scale: The scale method adopted for the shmooing on the axis, which is either "Linear" or "Logarithmic".
  • otherDescription: The description for the axis.
  • parameterType: The data type of the parameter that be shmooed on the axis. The available data types are:
    • DRLShmooSpecVariableType: (Default) a spec variable.
    • DRLShmooHXInstrumentType: A HighspeedExtensionInstrument.
    • DRLShmooHXResourceType: A HighspeedExtensionResource.
    • DRLShmooUserDefinedParamType: Your defined parameter with the addParameterType function.
  • parameter: The parameter that is shmooed on the axis.

Syntax

typedef struct _DRLShmooAxisData 
{
  double start;
  double stop;
  unsigned int totalSteps;
  unsigned int linearSteps;
  const char* primaryValue;
  const char* scale;
  const char* otherDescription;
  DRLShmooParametersType parameterType;
  union
   {
     DRLShmooSpecVariableType spec;
     DRLShmooHXInstrumentType HXInstrument;
     DRLShmooHXResourceType HXResource;
     DRLShmooUserDefinedParamType userDefinedParam;
   } parameter;
} *DRLShmooAxisData;
