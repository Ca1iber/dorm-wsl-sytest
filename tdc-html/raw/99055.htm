DGCM? - (DiGital Capture Mode)

The DGCM query returns whether digital data are captured sequentially (capture mode SEQ) or selectively (capture mode SEL) for a vector label.

With the sequential capture mode, any filtering of the data is done with the DIDT? query after uploading the data. With the selective mode, data is already filtered at capturing time. This is achieved by using the special edge actions C and D in the waveforms.

Syntax

DGCM? {"vector_label"}

returns:

DGCM {"vector_label"},{capt_mode}

Parameters

vector_label

Vector main label. Must be enclosed in double quotes

capt_mode

 

Specifies the capture mode. Possible values are:

SEQ

Data is captured sequentially. Filtering is done after upload.

SEL

Filtering is already done at capturing time.

Application

Digital capture applications.

Errors

An error occurs if:

  • The referenced vector label is not a main label.
  • The referenced vector label is not in the sequencer memory (SM).

Example

> DGCM? "my_vec_lab"
< DGCM "my_vec_lab", SEQ

Functional changes

  1. Introduced before SmarTest 6.3.2
