CFCF, CFCF? - (Clock Forwarding ConFiguration)

This command serves to define and query clock forwarding domains for a specified clock forwarding set. This set must have been defined with CFDF. A clock forwarding domain defines a set of pins, the sink pins, that are to borrow their tracking behavior from another pin, the source pin; for more information see Forwarding the clock.

With this command you configure setups of those sites that have the setup focus: For more information, see also: PSFC, PSFC?.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Within one clock forwarding set, no pin must occur more than once. If you define a domain with a pin that is already used in another domain, SmarTest tries to preserve this requirement according to the following rules:

  • If the specified source pin already occurs as a source pin, the new domain definition replaces the old one (it does not add any new pins to the old definition).
  • If the specified source pin already occurs as a sink pin, it is removed from the existing domain. If it was the only sink pin of that domain, the domain is also removed.
  • If one of the specified sink pins already occurs as a source pin, the respective domain is removed.
  • If one of the specified sink pins already occurs as a sink pin, it is removed from the existing domain. If it was the only sink pin of that domain, the domain is also removed.

CFCF

CFCF {"cf_name"}, {(source_pin)}, {(sink_pins)} [, speed]

CFCF?

CFCF? {"cf_name"}, {(pinlist)}

returns:

CFCF {"cf_name"}, {(source_pin)}, {(sink_pins)} [, speed]

Parameters

cf_name

Specifies the name of a clock forwarding set that must have been defined with CFDF.

source_pin

Specifies the pin whose tracking behavior is to be transferred.

sink_pins

Specifies the pins that are to make use of the tracking behavior of the source pin.

speed

Defines the maximum expected shift per ns. This can be used to determine the maximum supported shift. See Implementation details of clock forwarding.

pinlist

This query parameter specifies the pins whose role in the specified clock forwarding set is to be retrieved.

Application

Protocol engine test.

Errors

An error is generated if no clock forwarding set with this name exists.

Example

> CFCF? "cf_set1",(@)
< CFCF "cf_set1",(Pin1),(Pin3, Pin2)
< CFCF "cf_set1",(Pin4),(Pin5)
> CFCF "cf_set1",(Pin1),(Pin6, Pin3)
> CFCF "cf_set1",(Pin7),(Pin4)
> CFCF? "cf_set1",(@)
> CFCF "cf_set1",(Pin1),(Pin6, Pin3)
> CFCF "cf_set1",(Pin7),(Pin4)

Functional changes

  1. Introduced in SmarTest 7.0.1
