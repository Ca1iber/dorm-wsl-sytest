Topic 31484

Arrange Graphs

This menu item allows you to tile, cascade, iconify, and delete graphs in the Waveform Graphs Tool (WGT).

The following menu items are included:

Tile (Horizontal) - allows you to align multiple graphs in the WGT horizontally.

Tile (Vertical) - allows you to align multiple graphs in the WGT vertically.

Cascade - allows you to overlap (or cascade) multiple graphs in the WGT.

Iconify All - allows you to minimize (or iconify) all graphs in the WGT.

Delete All - allows you to delete all graphs in the WGT.

Auto Tile (Horizontal) - enables graphs in the WGT to always be aligned horizontally.

Auto Tile (Vertical) - enables graphs in the WGT to always be aligned vertically.
