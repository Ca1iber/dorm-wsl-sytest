Smart correlation - release checker examines test program setups and execution results based on customized rules for improving release quality.

It provides the following standard check items:

  • General risks: Helps you to check the general test program setup risks, such as unused files, HiZ risk, hot-switching risk, and risky voltage/current programmed to pin.
  • Check general risks for SmartRDI: Helps you to check the general risks for SmartRDI, such as risky voltage/current programmed to pin, hot-switching on instrument relay risk, hot-switching on utility or PMUX risk, and illegal connection combination risk.
  • Check model file setups: Helps you check if Xpress data mode is enabled in the model file.
  • Check pin setups: Helps you to check the pin setup risks. Check no trigger line definition for MCA, MCB, and MCC.
  • Check level setups: Helps you to check the level setup risks, such as the missing/undefined/redefined pins in level file, DPS setup risks.
  • Check timing setups: Helps you to check timing setup risks, such as the window compare risk and edge placement risk.
  • Check vector setups: Helps you to check vector setup risks, such as the missing/undefined pins in a pattern file, and name conflicts of label and multiport burst.
  • Check test table setups: Helps you to check the test table setups risks, such as the undefined suite entries, the test naming and numbering, consistency of test mode, the duplicate test and test number.
  • Check testflow setups: Helps you to check the testflow setups risks, such as the system and flow flags, suite flags, and the bin consistency between flow and test table.
  • Check test method: Helps you to check the test method risks, such as the UTM library build mode, memory leakage risks, and thread safe related risks.
  • Check warning/error of flow execution: Helps you to highlight the warnings, errors and other messages from flow execution, the "test number conflict" or " invalid test number" on executed tests from data log (EDL). This includes configurable flow execution and highlight warning/error from flow execution, configuration flow execution and check your numbers issues.

Based on the check result report, you should modify the test program to fix these risks, and then use Smart Correlation - Release Checker again to do the double check.
