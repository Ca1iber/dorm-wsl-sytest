Changing and obtaining conditions for digital capture test

To change the conditions used for capturing digital data, use the VECTOR API.

VECTOR(vectorVarLabel).<memberFunction_1>.<memberFunction_2>. ... .<memberFunction_N>;

where, <memberFunction_1> to <memberFunction_N> mean the member functions of the VECTOR API. For changing conditions, you can describe multiple member functions. For obtaining a parameter value, you can describe only one member function per statement.

The following member functions are available for changing the particular condition:

The task to be executed <memberFunction_#> for ...
... changing a condition … obtaining a condition
Encode format format() getFormat()
Set the input mode of the code to be applied to the device inputMode() getInputMode()
Set the byte order of device byteOrder() getByteOrder()
Set the data bit width bits() getBits()
Set the data offset offset() getOffset()
