Topic 130756

TestsuiteProxy.setTestsuiteFlag()

This function sets a value to a test suite flag. If it is successfully executed,true will be returned. Otherwise, false will be returned.

Syntax

bool setTestsuiteFlag(const TestsuiteFlag name, const int value);
Parameters

name

The test suite flag name. It can be one of the options of TestsuiteFlag enumeration defined below :

enum TestsuiteFlag

{

TESTSUITEFLAG_BYPASS = 0,

TESTSUITEFLAG_SET_PASS,

TESTSUITEFLAG_SET_FAIL,

TESTSUITEFLAG_HOLD,

TESTSUITEFLAG_HOLD_ON_FAIL,

TESTSUITEFLAG_OUTPUT_ON_PASS,

TESTSUITEFLAG_OUTPUT_ON_FAIL,

TESTSUITEFLAG_VALUE_ON_PASS,

TESTSUITEFLAG_VALUE_ON_FAIL,

TESTSUITEFLAG_PER_PIN_ON_PASS,

TESTSUITEFLAG_PER_PIN_ON_FAIL,

TESTSUITEFLAG_SET_BREAK_POINT,

TESTSUITEFLAG_FORCE_SERIAL,

TESTSUITEFLAG_LOG_MX_WAVEFORMS,

TESTSUITEFLAG_FAIL_PER_LABEL,

TESTSUITEFLAG_FFC_ENABLE,

TESTSUITEFLAG_FFC_SCAN_INFO_ENABLE,

TESTSUITEFLAG_LOG_FIRST,

TESTSUITEFLAG_FFV_ENABLE,

TESTSUITEFLAG_FRG_ENABLE,

TESTSUITEFLAG_FRG_SINGLE_SHOT,

TESTSUITEFLAG_HW_DSP_DISABLE,

TESTSUITEFLAG_TEST_LEVEL,

TESTSUITEFLAG_UNDEFINED

};

value

The value to set. It must be 0 or 1 except for TESTSUITEFLAG_LOG_FIRST and TESTSUITEFLAG_TEST_LEVEL.

Functional changes

  1. Introduced in SmarTest 6.5.2
