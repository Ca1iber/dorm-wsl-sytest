Setting up the Digital Capturing

Some mixed-signal tests such as ADC tests need to capture the digital data. If your test needs it, you must set up the digital capture conditions within the Vector Setup Tool.

A full description of the Digital Capture process, its setup and memory usage together with detailed explanations are given in Using Digital Capture.

These are the key points during setting up the digital capturing:

  • Specifying the Sequencer Memory for storing the drive digital data, and the Vector Memory for storing the captured digital data.
  • Defining the pins of the data to be captured (in the Digital Capture setup wizard).
  • Defining various parameters for the vector variable corresponding to the defined digital capture (in the Digital Capture setup wizard).
