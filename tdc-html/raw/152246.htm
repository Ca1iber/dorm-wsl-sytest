Topic 152246

rdi.tmu().label().copyLabel()

This function follows a label() command and gives an option to edit the existing patterns. One purpose is to save vector memory. It must be used inside a RDI_BEGIN()/RDI_END() block.

Syntax

label("Label").copyLabel(boolVar);
List of parameters
Parameter Description
boolVar Specifies whether to edit an existing pattern, or create a copy from an existing pattern and edit the copied pattern.
List of available options of parameter: bool
Option Description
true Make a copy of an existing pattern and edit the copied pattern.

This is the default value.
false Edit an existing pattern.

Return value

There is no return value.

Example

RDI_BEGIN();
...
rdi.tmu("id_2").label("func_2").copyLabel(false).pin("PS1600_1")
    .insertVec(280)
    .vth(3.0 V)
    .samples(4)
    .measMode(TA::RISE)
    .dataRate(25 MHz)
    .execute();
...
RDI_END();
