Dual-site GPIO configuration

Subtopics

  1. Valid combinations of plug-ins and configuration files
  2. Binning map
  3. Timing diagram (HITACHI MH-22)

The HITACHI "Dual-site" configuration is valid for HITACHI dual-site handlers.

Supported handler models

  • MH-22

Features

  • 2 sites
  • Global test start signal
  • parallel binning
  • explicit binning
  • global test completed pulse
  • The following signal from the handler is not supported by the driver: Double Contact

Required handler cable

There is no preconfigured handler cable available for this configuration. Please see Hitachi handler cable for the information on configuring the cable.
