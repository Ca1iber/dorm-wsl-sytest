Topic 20901

Logging Array Data

To log array data, specify the array data to be logged in the PUT_DATALOG API as follows:

ARRAY_D wave_array;
   :
PUT_DATALOG("Aout", "THD", wave_array);

The PUT_DATALOG API puts out the array data wave_array for the pin name Aout and test name THD to the event data logging stream.
