Topic 144107

PPMU_BADC_MEASURE

Subtopics

  1. PPMU_BADC_PIN_MEASURE

The PPMU_BADC_MEASURE class is used to define DC-dynamic high accuracy board ADC (BADC) measurements. PPMU_BADC_MEASURE objects can be added to a PATTERN_CONTROLLER object.

A typical PPMU-BADC measurement sequence is:

  1. Program all PPMU's in parallel (PPMU_SETTING).
  2. Close relays (PPMU_RELAY)
  3. Measure values via BADC by connecting the BADC serially to the PPMUs (PPMU_BADC_MEASURE)

This type of measurement is supported by PS1600 digital cards (see also PS1600 DC value measurements). The BADCs of the PS1600 digital card are connected via an AMUX to a PPMU output. 16 channels share one BADC. All BADCs measure in parallel.

CAUTION For the serialization of the DC-dynamic high BADC measurements (measuring values dynamically by connecting the BADC serially to the PPMUs) using the PPMU_BADC_Measure class, turn OFF the Site Match Mode flag (site_match_mode=OFF). Turning ON the Site Match Mode flag (site_match_mode=ON) may impact the proper serialization of measurements that use shared resource such as the BADC and could cause an execution crash.
Note

The typical time required for a BADC or PPMU measurement can be calculated as follows:

twait = (25 μs + N * 4 μs)
where: 25 μs is a one-time overhead
"N" is the number of samples

After the measurement is performed, SmarTest needs an additional time (typical) of 20 μs * N, where N is the number of samples, to fetch the results. For this additional duration of time, the BADC cannot be used to perform a new measurement.

In additional, an extra wait time of, at least, 60 μs must be added for the first BADC measurement after switching the measurement mode on one channel for EXA Scale digital cards or Smart Scale digital cards in Exa Scale compatibility mode.

Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PpmuBadcMeasure.h.

Constructor
PPMU_BADC_MEASURE();

This constructor defines an object that holds the measurement setup. 

PPMU_BADC_MEASURE();
Parameters
There are no parameters associated with the constructor.
Member functions
  • pin()

Using the API

For creating an object:

PPMU_BADC_MEASURE <object>;
Note Do not create static objects of the class in the test method and do not create test method member variables from this class.

For setting up the measurement:

<object>.pin("pinlist").<member_function>;
<object> Object name to be defined
pinlist Target pin name or pin group name of this class. You can specify multiple pins and pin groups by separating with a comma.
<member_function> Member functions of the PPMU_BADC_PIN_MEASURE class

Example

//Pin DC Current Measurement
PATTERN_CONTROLLER measPattern;

ON_FIRST_INVOCATION_BEGIN();

    PPMU_BADC_MEASURE ppmuBadcMeas;
    PPMU_SETTING      ppmuSetting;
    PPMU_RELAY        ppmuOn, acOn;

    ppmuSetting.pin(measPins).vForce(2000 mV).iRange(-56000 uA).min(0 uA).max(100 uA);

    ppmuOn.pin(measPins).status("PPMU_ON");
    ppmuOn.wait(1.3 ms);

    ppmuBadcMeas.pin(measPins).numberOfSamples(4);
    ppmuBadcMeas.wait(150 us);

    acOn.pin(measPins).status("AC_ON");

    measPattern.label("subroutine","@")
               .add(ppmuSetting)
               .add(ppmuOn)
               .add(ppmuBadcMeas)
               .add(acOn);

    ...

ON_FIRST_INVOCATION_END();

...

For further examples, including result upload, see PS1600 DC value measurements, BADC_SETTING, and BADC_PIN_MEASURE.
