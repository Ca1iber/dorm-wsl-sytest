Saving and resetting a perspective

You can save a perspective as your own perspective or reset it to the default state.

Procedures

Save a perspective

  1. Right-click the perspective header and select Save As....
  2. Select Window > Save Perspective As....

    The Save Perspective As window opens.

  3. Type in a name for your perspective and click OK.

Reset a perspective

  1. Right-click the perspective header and select Reset.
  2. Select Window > Reset Perspective from the main bar.
