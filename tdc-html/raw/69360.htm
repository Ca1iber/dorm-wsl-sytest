Topic 69360

Dual-site-encoded GPIO configuration

Subtopics

  1. Valid combinations of plug-ins and configuration files
  2. Binning map
  3. GPIO box jumpering
  4. Timing diagram (Multitest dual-site-encoded)

The Multitest "Dual-site-encoded" configuration is valid for Multitest dual-site handlers.

Supported handler models

  • mt8588
  • mt8589
  • mt9308/2

Features

  • up to 2 sites
  • 2 DUT signals
  • global test start signal
  • parallel binning
  • encoded binning
  • 32 bin categories
  • no "empty" bin

Required handler cable

There is no preconfigured handler cable available for this configuration. Please see Multitest handler cable with 50-pin SUB-D connector(old pin assignment) for the information on configuring the cable.
