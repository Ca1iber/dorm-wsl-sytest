About SmarTest Program Manager

SmarTest Program Manager (STPM) is a time and cost efficient test management program for updating and maintaining existing test programs and developing new ones.

A common challenge for test engineers is that of updating existing test programs. Test engineers regularly add, remove, extend, and replace tests, and in doing so can either simply concatenate the tests and all related primaries, thereby creating large databases of many waveform tables, equation sets, spec sets, and other primaries; or they can manually check if a new test can use any of the existing timing or levels in the SmarTest device directory.

With the SmarTest Program Manager tool, this process is fully automated, including reusing and merging primaries, using STPM's ability to read and analyze the device directory. When possible, STPM reuses device directory elements (such as timing, levels, and so on) following a set of merge rules that optimizes test time by avoiding unnecessary reloads.

SmarTest Program Manager:

  • Integrates new source test programs (STPs) into existing test programs
  • Updates test suites in test programs
  • Removes test suites from test programs

A set of merge rules gives you complete control over the process.

Test program templates

STPM also lets you prepare test program templates with a predefined structure that can be reused for different devices, allowing you to better leverage test program development effort.

It is not uncommon that a new device that needs to be tested could be tested with a test program that has been developed for another, similar device, with a few modifications. You could duplicate the test program and manually make the necessary changes, but this process is both cumbersome and error-prone - it is easy to forget to change a setting or reference.

Using STPM, you can convert an existing testflow into a test program template and modify it for the new device in a convenient spreadsheet format. When you are done, STPM creates a new device directory from the template, and you add the test suites appropriate for the new device, either with STPM or in SmarTest. This way, you can incrementally build or update test programs with STPM while creating and editing the test program in a convenient spreadsheet format.

This approach is also well-suited for letting both test engineers and managers review test program content.

Use cases

Common cases where STPM proves beneficial are:

  • Creation of a new test program from varied sources, such as existing test programs for similar devices or device variants and new tests created by the DFT group.
  • Maintaining existing, working test programs by replacing individual tests with newer versions and by removing redundant tests.
  • Optimize existing test programs by removing unused or duplicate primaries and other objects.

Companion tool

SmarTest Program Manager MCM (STPM MCM) is a tool to be used with STPM workflows that combines individual test programs for components of multichip modules or multicore modules into a single test program for the entire module.
