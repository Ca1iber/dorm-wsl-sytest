Defining a utility purpose

A utility purpose is a group of utility lines which is associated with a name and a standard output (desired) state for each of its members. It is created with the DFUP command. This construct allows you to control many utility lines with one statement.

Note In order to activate the standard states specified with the DFUP command, it does not suffice to issue the FLSH command. Rather, you must first select them as the values to be activated with the UPST command, and then activate them with FLSH. For more information see Accessing Utility Lines.

The DFUP? query returns the definition of the specified utility.

The UDUP command removes a utility purpose.

Related firmware commands

You can use the UPTI command to set a settling time that is used as the wait time. This settling time is used when the defined utility purpose is activated.

The UPAS command controls the standard states of utility purposes for sites > 1. It allows you to define different standard states for different sites.
