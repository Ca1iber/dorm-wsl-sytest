Topic 125285

sub()

Subtracts a state character sequence from another.

Both sequences must be convertible to consistently coded integer values.

The result is a state character sequence representing the arithmetic difference of both parameters. The length of the result is the same length as the first parameter.

Errors will be issued if,

  • a parameter is not convertible to integer or
  • a parameter coding is inconsistent or
  • an underflow occurred.

Syntax

integer := sub(integer1, integer2)
Parameter

I/O

Parameter

Description

I

integer1

State character sequence from which integer2 will be subtracted.

I

integer2

State character sequence to subtract from integer1.

Example

sub("001", "001") results in "000".

sub("HLLH", "LLHL") results in "LHHH".

sub("HLLH", "HL") results in "LHHH".

sub("0011", "1") results in "0010".

sub("0011", "000000001") results in "0010".

sub("1", "100") results in "ERROR: underflow."

sub("000001", "100") results in "ERROR: underflow."

sub("LLLH", "HHL") results in "ERROR: underflow."

sub("LLH", "HHZ") results in "ERROR: "HHZ" is not convertible to integer."

sub("001", "LLH") results in "ERROR: inconsistent coding."

Functional changes

  1. Introduced in SmarTest 7.1.0
