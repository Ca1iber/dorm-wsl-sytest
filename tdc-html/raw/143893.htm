iMeas()

Creates a current measurement.

The function can be used in the code‑based mode and in the pattern‑based mode.

Syntax

dcBase& iMeas();

Example

Example 1: Simple current measurement

RDI_BEGIN();
{
    rdi.dc("iMeas").pin("pinA").vForce(3 V).iMeas().execute();
}
RDI_END();

Related information

SmartRDI timing settings of DC events

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 7.5.0: New syntax for "LAST" measurements of FVI16.
