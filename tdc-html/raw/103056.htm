How to do Multi-Site Testing

Subtopics

  1. Introduction to Multisite Testing
  2. Developing a Multisite Test
  3. User Procedures
  4. Multisite Test Method Programming
  5. Application Specific Multisite

By running a multi-site test on the SOC Series you can test multiple1) identical devices on one DUT board. All devices are tested simultaneously, thus reducing the overall testing time to a fraction.

You can also make optimum use of your test system's resources when testing devices with fewer pins than the number of channels your test system provides (mixed test floor). The more devices you have to test, the more beneficial multi-site testing becomes.
