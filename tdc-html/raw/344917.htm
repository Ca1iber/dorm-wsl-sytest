vMeasReturnDrop()

Specifies a voltage drop measurement on the return line and initiates the transfer of an available measurement value from the front-end to the test processor.

The voltage drop is measured from the low sense pogo pin to the low force pogo pin or common ground. The measured voltage drop depends on the actual current and the impedance of the connection to the DUT. For ganged channels, the voltage drop is measured on the master channel.

This member function is supported for HC channels of DC Scale DPS128/DPS64 cards and the DC Scale XPS256 card both in PMU and DPS operating mode and for the DC Scale UHC4T card in DPS operating mode.

For more information on DPS128 voltage drop measurements, refer to Voltage drop measurement in DPS128 / DPS64 functionality and features.

For more information on XPS256 voltage drop measurements, refer to XPS256 voltage drop measurement.

The function can be used in the code‑based mode and in the pattern‑based mode.

Syntax

dcBase& vMeasReturnDrop();
Return Value
A reference to the dcBase object.

Examples

DPS128 return drop measurement

rdi.dc().pin("DPS128_SIG_1").iForce(1 mA).clamp(2.5).vMeasReturnDrop().execute();

RDI_BEGIN();

    rdi.dc().pin("DPS128_SIG_1").vMeasReturnDrop().execute();

RDI_END();

UHC4T return drop measurement

RDI_BEGIN();

    rdi.dc(2).pin("UHC4T_2").vMeasReturnDrop().execute();

RDI_END();

double dVal2 = rdi.id(2).getValue();
