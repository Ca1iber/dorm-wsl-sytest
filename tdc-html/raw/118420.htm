Topic 118420

Using the operator console

Subtopics

  1. Buttons and menus of the operator console

This section describes the usage the operator console.

Before you begin

Before you can use the console, make sure that:

  • The operator console is installed and has booted as described in Installing the operator console.
    CAUTION Always use the operator console with batteries loaded. If you use the console without batteries and disconnect it while running SmarTest, whether by chance or by purpose, SmarTest may freeze.
  • The org file at /etc/opt/hp98000/soc/ is adapted as described in Adapting the org file.
  • Set up or select the Application model for your needs.
  • At least one work order is defined, that shall be used with the console. For detailed information, see Creating New Workorders.
    Note When naming work orders for usage with the operator console: Make sure that the work order name consists of numbers only. Do not use other characters like alphabetical or symbol.
    Note Make sure that the operator console has booted properly before starting SmarTest.
  • Use the following command to start SmarTest:

    HPSmarTest -C

    Note SmarTest recognizes the console in this "operator console mode" only.

Procedures

General usage

Note After a defined period the console starts a screen saver. To stop the screen saver and to re-activate the console just touch the display.
  • Working with workorders using the operator console is similar to the procedures using SmarTest on the system controller, see Working with workorders.
  • To call a menu, press the respective function key, see Buttons and menu of the operator console

Executing a workorder

Note The following procedure reflects the usage of the standard workorder. It may vary according to your workorders.
  1. On the operator console, type the workorder name and press OK.
  2. Type the lot ID and press OK.
  3. Type your operator ID and press OK.
  4. Type the package ID and press OK.
  5. Press Start.

    To cancel the procedure, press Abort.

    The output depends on your Application Model and your workorder.

    For further information, see Executing a Workorders.
