Inter-layer via design

Subtopics

  1. Inter-layer via examples

Like pogo via design, the design of vias for changing routing layers depends on several aspects. But unlike pogo via design, the design of inter-layer vias allows more freedom.

When designing inter-layer vias you have the following variables:

  • Number of ground vias
  • Pitch between signal and ground vias
  • Drill size of the signal via
  • Drill size of the ground via
  • Pad size if the via goes to the top or bottom layer
  • Removal of non-functional pads (NFPs) (Yes / No)
  • Back drilling (Yes / No)
  • Reference plane clearance or swell
