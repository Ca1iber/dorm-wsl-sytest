DSP_REG1

This API computes the regression coefficient and constant for the specified elements in a specified array.

This API computes a straight regression line in accordance with the least-squares fit method, which calculates the expected mean of the src elements relative to the subscript "i". The calculations result in a regression line that can be expressed as follows:

y = A × i + B

where "y" is the expected src element and "i" is its subscript. "A" is the regression coefficient, which equals the slope of the regression line. "B" is the regression constant, which equals the offset of the regression line.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_REG1(ARRAY_I& src, DOUBLE *coefficient, 
         DOUBLE *constant, INT start, INT size);
DSP_REG1(INT *src, DOUBLE *coefficient, 
         DOUBLE *constant, INT start, INT size);
DSP_REG1(ARRAY_D& src, DOUBLE *coefficient, 
         DOUBLE *constant, INT start, INT size);
DSP_REG1(DOUBLE *src, DOUBLE *coefficient, 
         DOUBLE *constant, INT start, INT size);
Parameters

I/O

Parameter

Description / Range

I

src

Source array

O

coefficient

Regression coefficient value within source array

O

constant

Regression constant value within source array

I

start

Start point of regression in source array

0 ≤ start

I

size

Number of elements to be processed

2 ≤ size

start + size - 1 ≤ (size of source array)

start + size - 1 ≤ 2097152

Example

double array1[50];
double coefficient, constant;
  .
  .
DSP_REG1(array1, &coefficient, &constant, 5, 10);

DSP_REG1 computes the regression coefficient and constant for array1[5] through array1[14] , and returns the results to coefficient and constant .
