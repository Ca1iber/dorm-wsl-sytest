DIGITAL_OFFSET_SEARCH_PINS.getExecutionContext()

Retrieves the context name that has been referenced with setExecutionContext().

Syntax

const STRING& getExecutionContext();

List of parameters

There are no parameters.

Return value

Returns a context name, or an empty string if no context execution had been referenced.
