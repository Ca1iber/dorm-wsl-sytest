Topic 118980

Editing a TMLimits master file

TMLimits master files can be edited independently of the CSV file that they reference.

About this task

Edit TMLimits master files, for example, to add or remove referenced CSV files.

Before you begin

Make sure that there is a TMLimits master file that you can edit.

Procedure

  1. In the Test Program Explorer, right-click the <Test Table> entry and choose Load from the shortcut menu.

    An Open dialog is displayed.

  2. Choose the TMLimits master file that you want to edit and click OK.
  3. Right-click the test table in the Test Program Explorer and choose Show in Project Explorer from the shortcut menu.

    The Project Explorer view is displayed, with the loaded master file highlighted.

  4. Double-click the file to display it in its editing window.
  5. Make the desired changes.

    You can edit the file as any other text file. As a shortcut, you can double-click a file in the Project Explorer view to add it to the master file.

  6. Save and close the master file.
    Note The TMLimits master files have the .mfh filename extension but are plain text files. You can, therefore, edit them with any text editor. However, to avoid the risk of syntax errors, we recommend that you edit them from within the Project Explorer, as described above.

Results

The master file is now updated.
