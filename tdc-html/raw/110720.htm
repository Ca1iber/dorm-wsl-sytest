DSP_SORT

The DSP_SORT API sorts array elements in ascending order. For the complex array, the elements are sorted by ascending magnitudes.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_SORT(ARRAY_D& src, ARRAY_D& result);
DSP_SORT(ARRAY_I& src, ARRAY_I& result);
DSP_SORT(ARRAY_COMPLEX& src, ARRAY_COMPLEX& result);
DSP_SORT(DOUBLE * src, DOUBLE * result, INT size);
DSP_SORT(INT * src, INT * result, INT size);
DSP_SORT(COMPLEX * src, COMPLEX * result, INT size);
Parameters

I/O

Parameter

Description/Range

I

src

Source array

1 ≤ size ≤ 2097152

 

O

result

Computed result array.

src_size ≤ result_size < 2097152

If the result array is larger than the src array, only the elements from result[0] to result[src_size -1] are meaningful.

The result array and src array can be the same array.

 

I

size

Number of elements of the src array

1 ≤ size ≤ 2097152

Example

ARRAY_D data(100);
ARRAY_D sorted_data(100);
...
DSP_SORT(data, sorted_data);

The example sorts the data array and outputs the result to the data_sorted array.

Functional changes

  1. Introduced in SmarTest 6.5.2
