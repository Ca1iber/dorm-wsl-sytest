rdi.id().getCombinedFailCount()

Retrieves the total fail counts of many pins in just one label. It works together with combinedFailCount().

Syntax

ARRAY_LL getCombinedFailCount();

Example

RDI_BEGIN();      
  rdi.emap("a").label("pat").pin("@").combinedFailCount().execute();
RDI_END();
int dVal =rdi.id("a").getCombinedFailCount();
Note pin("@") can only be used for the combinedFailCount() command and cannot be used with all the other error map commands.

Related information

combinedFailCount()

Functional changes

  1. Introduced in SmartRDI 7.5.1
