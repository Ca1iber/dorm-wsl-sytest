enPassFail()

This function retrieves the pass/fail result of a pattern specified in .label().

Syntax

enPassFail(bool val = true)

Example

RDI_BEGIN();
  rdi.smartVec("a").label("label1").pin("A")....enPassFail(true).execute();
  rdi.smartVec("b").label("label2").pin("B")....enPassFail().execute();
RDI_END();

rdi.id("a").getPassFail();
rdi.id("b").getPassFail();

Related information

Pass/Fail per label

Functional changes

  1. Introduced in SmartRDI 2.4.0
