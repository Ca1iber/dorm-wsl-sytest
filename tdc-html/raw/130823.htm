TIMING_OFFSET_SEARCH_PINS.minPassCount()

This function sets the minimum fine consecutive pass count to stop the binary search. If less than minimum number of consecutive PASS result are detected the search continues. The parameter does not impact the decision for left boundary and right boundary.

Syntax

TIMING_OFFSET_SEARCH_PINS& minPassCount(INT minpasscount);
Parameter

minpasscount

The minimum fine consecutive pass count to stop the binary search.

Functional changes

  1. Introduced in SmarTest 7.0.1
