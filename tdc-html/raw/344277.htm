Retrieving bin statistics

These functions retrieve the bin statistical information.

Use

CI_CPI_BIN_CURSOR GetBinFirst();
CI_CPI_BIN_CURSOR GetBinNext(CI_CPI_BIN_CURSOR cursor);
int GetBinStatistics(CI_CPI_BIN_CURSOR c, CI_CPI_BIN_DESCRIPTOR* bin);

These functions can also retrieve the information about how many devices have been binned to each bin.

Example

CI_CPI_BIN_CURSOR cursor;
  for(cursor = GetBinFirst(); cursor != CI_CPI_INVALID_BIN_CURSOR; cursor = GetBinNext(cursor)) 
  {
    CI_CPI_BIN_DESCRIPTOR binDescriptor;
    int deviceCount = GetBinStatistics(cursor, &binDescriptor);
    fprintf(stderr, "%d devices were binned to Bin %s\n", deviceCount, binDescriptor.bin_name);
    int site;
    for(site = 0; site < CI_CPI_MAX_SITES; site++)
    {
      fprintf(stderr, "Site %d: %d devices\n", site + 1, binDescriptor.dies_per_site[site]);
    }
  }

Functional changes

  1. Introduced in SmarTest 7.5.0
