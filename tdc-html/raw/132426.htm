TMU_TASK.getListofSets()

Retrieves the list of defined TMU sets and stores it in the specified parameter.

Syntax

static void getListofSets(STRING_VECTOR& setNames);
Parameter

I/O

Parameter

Description

O

setNames

The list of defined TMU sets. The name of the TMU set in the list is composed of the test suite name plus '_' and the defined TMU set.

Return value

There is no return value.

Functional changes

  1. Introduced in SmarTest 7.1.0
