Changing the Check Options

The check options let you set edge order checks - drive, tristate and window - for the drive and receive periods. The number of periods over which the check should be made (1 or 2) is also definable.

  1. Choose Change > Change Check Status.

    A screen similar to that of the figure below appears.

  2. Highlight the Specification Set whose check status you want to change.
  3. Select which Edge Order checks you want to perform.
  4. Select how many Drive periods over which you want to check.
  5. Select how many Receive periods over which you want to check.
  6. Click assign.
  7. Repeat these last steps as often as required (for other specification sets), and click done when finished.

Functional changes

  1. Introduced before SmarTest 6.3.2
