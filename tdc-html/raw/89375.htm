Topic 89375

Setting up the timing equation

About this task

Adapt the timing equation file to be used with the test method as described below.

Before you begin

Required is one tsweep spec value for each SourceSync data out and SourceSync read clock pin.

Procedure

  1. Start SmarTest.
  2. Load your program.
  3. Open the timing equation file from your test flow.
  4. In the editor scroll to the section starting with the text: 
    EQNSet 2 "DataTraining"
  5. Add the specification variables to the SPECS section.

    For example you can add:

    tAC0_offset [ns] for Tsweep_d0 for DQ_o.0
tAC1_offset [ns] for Tsweep_d1 for DQ_o.1
...
tDQSCK1_offset [ns] for Tsweep_r1 for RDQS_o.1
tDQSCK2_offset [ns] for Tsweep_r2 for RDQS_o.2
...

    and so on.

    Then, add these specification variables as an additional component to the timing of all read clock and data output pins.

Results

The timing is prepared for the DataTraining test method.
