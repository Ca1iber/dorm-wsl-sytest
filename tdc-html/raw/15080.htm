Current cycle and pattern

In the left upper corner, above the navigation area, the Error Map Tool displays the following fields.

Field

Description

Cycle
  • Shows the corresponding cycle number of the current selected cell in the error results area.
  • Type a cycle number to select the corresponding cell in the error results area.

Pattern

For the Error Map views Cycles and Edges:

Shows the current pattern of a burst.

Cycle of Pattern

For the error map tabs Cycles and Edges:

Shows the cycle number of the corresponding pattern shown in the field Pattern, see above.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.1.1: Displaying the current pattern and its cycle number
