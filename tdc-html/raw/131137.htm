Receivers

Smart Scale generation cards and Pin Scale cards have both single-ended and differential receivers (comparators).

Single-ended mode

For single-ended setups on Smart Scale and Pin Scale cards you use the output threshold keywords as follows:

  • On Smart Scale PS1600 cards and on Pin Scale cards, you program the output compare thresholds with the vol and voh keywords.

Differential mode

On Pin Scale systems the threshold for differential modes is fixed at 0 V. On Smart Scale generation cards you can define the vth threshold for differential signals.
