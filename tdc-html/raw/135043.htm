MTP_MEMORY_TEST.getMemoryPatternNamesList()

The getMemoryPatternNamesList() member function of MTP_MEMORY_TEST retrieves the names of the memory patterns (per pin subroutines generated by the MTL compiler) used for a memory test.

The function returns the number of the retrieved pattern names.

Syntax

LONG getMemoryPatternNamesList(STRING_VECTOR& name)

Parameter

Description

name

The name of an array which is used to store the retrieved memory pattern names which are the per pin subroutine labels for MTL.

Example

STRING_VECTOR pattern_names; 
LONG maxPatternsNr = 0;
MTP_MEMORY_TEST memoryTest;

maxPatternsNr = memoryTest.getMemoryPatternNamesList(pattern_names);
  
for(int i = 0; i < maxPatternsNr; i++)
{
  cout << "Memory Pattern Name: " << pattern_names[i] << endl;
  string bfd_file_name = pattern_names[i]; 
  memoryTest.getMemoryPattern(pattern_names[i]).setBitMapFileName(bfd_file_name); 
}

ON_FIRST_INVOCATION_BEGIN();
{
  CONNECT();
  memoryTest.execute();
}
ON_FIRST_INVOCATION_END();
