Aligning Timing Diagram and Error Map tool

When analyzing the test results and looking for errors (device or setup errors), it is very useful to keep all result displays synchronized with the vector setup. This allows you to correlate the data displayed by each tool, with each other, and the vector setup data. You then have the basis for a failure 'cause and effect' analysis.

All the result windows (together with the Pattern Debug Tool) share the common feature of being able to align their displays with one another - that is, if you view an area of results in one tool - say the Timing Diagram, if you change to another tool, the area that you were viewing previously will be automatically selected.

The following table outlines the menu path to align the displays:

Tool

Menu path

Error Map Tool

View > Align Display

Timing Diagram

Display > align displays
