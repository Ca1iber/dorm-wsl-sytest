Topic 17609

Defining additional test sites

About this task

SmarTest allows you to configure your test setup for multisite testing. You do this by defining additional sites, and then editing the pin configuration for the new sites. In theory you can edit all the information in the pin configuration table for each site. In practice, however, all sites are identical apart from the channel allocations - which must be edited separately for each site.

Before you begin

Ensure that you have completed the pin configuration for one site (site 1).

Procedure

  1. In the Test Program Explorer view, right-click Pin Settings and select Define Site....

    The Define Site Number dialog opens.
  2. Type the total number of sites (for example, 2) in the Select number of sites (1-1024) field.
  3. Click OK.

    In every Pin Setting editors, the tester channel column for all the sites appears. The following figure shows the example of Digital Pin editor.

  4. Allocate the test system channels for the additional sites.
  5. Apply the data and save the pin configuration file.
