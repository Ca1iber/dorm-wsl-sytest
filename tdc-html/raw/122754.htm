Topic 122754

PPMU Considerations

Subtopics

  1. Sampling with the PPMU

Generally, where possible consider using the PPMU to deliver a result rather than a value as this way there will be less data to upload.

Use the PPMU for continuity tests instead of the programmable-load because SmarTest can optimize only one DC test using programmable-load.

Consider using the PPMU instead of the SPMU where possible as there are a number of fast PPMU FlexDC API calls available.

In a multiport setup, try to do the PPMU measurements with a fast period if possible and try to stay within one port because otherwise the slowest port will determine the period.
