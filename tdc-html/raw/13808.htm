Topic 13808

Follow Current Mode

The Follow Current Mode option uses the acquisition mode settings which were defined in a test suite.

The error map will always be updated with the latest error data resulting from an execution, regardless of whether the execution was executed in cycle oriented or in failure oriented mode.

When executing a functional test from the error map, the test will be executed in the mode that was last used or set.

Functional changes

  1. Introduced before SmarTest 6.3.2
