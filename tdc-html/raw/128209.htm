SMC_SET_VECTOR_UPLOAD_PACKAGE_SIZE()

Sets the package size for the vector upload to the specified number of bytes. This size is valid until the value is changed again.

In general package sizes are determined automatically by the SmartCalc framework. However, this function allows to set user specific package sizes in case the automatically determined are not sufficient.

The specified package size is only used, if the estimated sequencer run time has elapsed, but the sequencer is still running, and the hidden upload shall proceed even after the estimated time. For further details refer to SMC_SET_TEST_EXECUTION_TIME().

Note Modification of the package size can have bad impact on the test time if not chosen correctly. A larger package size can improve the upload speed, however as the package size also determines the time slots to check if the sequencer is still running, this can cause that the sequencer execution times increases.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Syntax

void SMC_SET_VECTOR_UPLOAD_PACKAGE_SIZE(INT size);
Parameter

Parameter

Description

size

Package size in bytes.

Return value

There is no return value.

Example

The following example shows how the upload size can be set to 512 kB.

SMC_SET_VECTOR_UPLOAD_PACKAGE_SIZE(512 * 1024);
