Downloading waveform patterns from the Signal Analyzer

  1. Open a new or existing vector label.
  2. In the Signal Analyzer, create or load an existing waveform.
  3. Download the waveform to vector memory.
  4. Set the Code, Range, Averaging, and Operation parameters.
  5. For the Destination parameters, complete the following fields:
    • Group Name-name of the pin group for the downloaded waveform pattern
    • Test Label-name of the vector label to contain the downloaded waveform pattern
    • Port (optional)-name of the port to which the vector label belongs (this field is required to download a waveform pattern to a port-specific vector label)
    • Starting Vector-starting vector for the downloaded waveform pattern
    • Device Cycle-name of the device cycle for the downloaded waveform pattern
  6. Click OK to download the waveform pattern.
