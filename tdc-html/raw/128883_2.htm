Creating and assigning a port burst

A port burst is a burst (sequence of main patterns) for a specified group of pins (the port). A port burst is always part of a multiport burst and must belong to a sync group.

About this task

To create a port burst you use the New Port Burst dialog. You can access the dialog both from the Pattern Explorer and from the Overview page or a sync group page of the Multiport Burst Editor. The result is identical.

Before you begin

There must be already one or more multiport bursts, to which the port burst will be assigned.

The 'Hide/Show all PortBurst tabs' and 'Hide/Show all SyncGroup tabs' icons on the main toolbar toggle the display of the respective pages in the current multiport editor. Make sure port burst pages and sync group pages are displayed.

Procedure

  1. To create a port burst:
    • In the Pattern Explorer, right-click the target multiport burst or one of its port bursts and select New > Port Burst
    • On a sync group page or the Overview page of the Multiport Burst Editor, right-click and select New Port Burst

      The New Port Burst dialog opens. The Multiport Burst field is predefined depending on your prior right-click selection.

  2. If required, use content assist to select the multiport burst, to which you want to assign the port burst.
  3. In the Port Bursts field select one or more ports to add to the multiport burst. Ports that belong already to the selected multiport burst are displayed as selected but grayed out.

    Note that device pins must belong to only one of the selected ports.

  4. For each selected port, specify a Sync Group to which the port belongs. The content assist (Ctrl + spacebar) helps to find the already existing sync groups. To create a new sync group, type its name in the Sync Group cell. Otherwise the DEFAULT sync group is used. You can change the sync group later in the Pattern Explorer. The synchronization group (sync group) forces all its ports to start at the same point in time.
  5. When done, click Finish.

Results

You created a port burst.

In the Pattern Explorer:

  • The new port burst is listed in the Pattern Explorer underneath the specified multiport burst. The naming syntax is <MuliportBurstName>@<Port>.

In the Multiport Burst Editor:

  • The new port burst is added to the Overview page of the multiport burst.
  • If the display of port bursts is on ( toggles the display), a new port burst page is added to the multiport burst editor.
  • The port burst is added to the specified sync group, and shown if the display of sync groups is on ( toggles the display).

What to do next

If required you can modify multiport burst setups in the multiport burst editor and in the Pattern Explorer.
