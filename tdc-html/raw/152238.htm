Topic 152238

insertSub()

This function inserts one or more subroutines with DC, PPMU or BADC actions into an existing pattern.

You can also use this function to add multiple measurements onto one pin in a pattern. To retrieve the result, use getMultiValue().

Syntax

insertSub(int lineNum);
insertSub(int VecNo,int level);
List of parameters

Parameter

Description

lineNum

The number of a vector line where one or more subroutines to be inserted in a specified label.

VecNo The vector number.
level 2 means the sublabel is inserted to a user-defined pattern.

1 is the default value.

Examples

Example 1

RDI_BEGIN();
  rdi.dc().label("dc_label").insertSub(10).pin("pinA").vForce(1)
                            .insertSub(20).pin("pinB").vForce(2).iMeas().execute();
RDI_END();
rdi.dc().pin("pinA").vForce(2 V).iMeas().iMeasRange(1 mA).execute();

Example 2

Since SmartRDI 2.4.4., DC supports multiple insertSub() calls in one vector line. In the following code example, two subroutines are both inserted into the vector line 10. 

RDI_BEGIN();
  rdi.dc().label("dc_label").insertSub(10).pin(A).vForce(1)
                            .insertSub(10).pin(B).vForce(2).iMeas()
                            .execute();
RDI_END();

Example 3

Starting from 7.5.1, this function supports waveform sourcing and sampling. 

RDI_BEGIN;
  rdi.dc().label("label1").insertSub(10)
          .pin("dig").vForce().waveform(sine)
          .FS(100 KHz).execute(); //force waveform
  rdi.dc().label("label2").insertSub(20)
          .pin("dig2").vMeas().samples(1024)
          .FS(10 KHz).execute(); //sampling
RDI_END:

Example 4

Starting from 7.5.2, this function supports both an existing sublabel to be inserted to a user-defined pattern and DC actions to be inserted to the sublabel.
RDI_BEGIN();
rdi.dc().label("mainlabel")
   .insertSub(10).pin(A).vForce(1)
   .insertSub(15).label("sublabel")
   .insertSub(10,2).pin(B).vForce(2)
   .insertSub(20).pin(C).iForce(1mA).vMeas().execute();
RDI_END();

Related information

getMultiValue()

Functional changes

  1. Introduced in SmartRDI 2.4.1
  2. SmartRDI 2.4.4: Support multiple insertSub() calls in one vector line.
  3. SmartRDI 7.5.1: Support waveform sourcing and sampling.
  4. SmartRDI 7.5.2: Support both an existing sublabel to be inserted to a user-defined pattern and DC actions to be inserted to the sublabel.
