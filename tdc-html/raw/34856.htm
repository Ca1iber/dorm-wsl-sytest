DRLXYDataResultAttr

An attribute of this type contains detailed data that is used for a graphical display of the results within the jitter screen.

typedef const struct _DRLXYDataResultAttr {
      const char *description;
      const char *x_parameter;
      const char *x_unit;
      const char *y_parameter;
      const char *y_unit;
      short number_points;
      DRLXYPair *measurements;
      short num_pin_measurements;
      DRLPinDataResult *pin_data;
} *DRLXYDataResultAttr;
Note You can specify any derived unit (such as ns or mA) for EDL data logging. However, when data logs are converted to STDF, all units are converted to their SI equivalents (ns to s, mA to A) and the corresponding values are converted accordingly. (For example, 435 mA is converted to 0.435 A.)

Functional changes

  1. Introduced before SmarTest 6.3.2
