Topic 110700

Converting user procedures to universal test methods

Subtopics

  1. How to convert a user procedure to a UTM project

A conversion tool is provided to convert user procedures to universal test method projects. The conversion tool convertUP is located in the directory /opt/hp93000/soc/prod_pws/migration/UTM_conversion/bin.

The conversion tool is only available in the 32-bit SmarTest.

During conversion the conversion tool does not touch the original user procedure files. It just copies these files and the related files to a sub-directory of the converted universal test method project. The universal test method project will call the user procedures in the run() function. The universal test method will take over the responsibility of

  • defining the parameters and limits interfacing with testflow and test suite.
  • parsing parameters and evaluating values for user procedures
  • invoking user procedure
  • logging comments and test results.

Two sub-directories, tm and up, are created in the converted universal test method project directory. tm contains the universal test method files and up contains all relevant elements of the user procedure.

There is only one *.cpp file in the tm directory. The header of the file looks like:

#include "ImportUserProcedure.hpp"
IMPORT_USER_PROCEDURE("Up.myProcedure1",myProcedure1); 
IMPORT_USER_PROCEDURE("Up.myProcedure2",myProcedure2);

The file ImportUserProcedure.hpp is in the directory /opt/hp93000/soc/testmethod/include. The specified name of the converted test method project is also the name of the converted source file. The test method class name is the original user procedure function name plus the prefix UP_.

Multi-site execution

The original user procedure is executed per site. After conversion, the universal test method is still executed per site.
