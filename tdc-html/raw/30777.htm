Topic 30777

ooc_stop_rule

Subtopics

  1. Associated Syntax Entities

The ooc_stop_rule keyword is used as an argument for GET_TEST_INFO to return the elements of the current out-of-control stop rule, as defined in the Global OOC Rule page of the testflow editor.

Functional changes

  1. Introduced before SmarTest 6.3.2
