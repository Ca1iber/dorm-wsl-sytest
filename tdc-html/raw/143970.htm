SOURCESYNC_TEST.stopCycle()

Specifies the number of the tester cycle where to stop a source-sync test.

Syntax

SOURCESYNC_TEST& stopCycle (const string& stopCycle);
Parameter

Parameter

Description

stopCycle

The number of the tester cycle where to stop a source-sync test. The minimum stop tester cycle number is 1, which is the second tester cycle.

You can specify multiple stop cycles separated with ";" in order to stop multiple source-sync tests. For example, "1;127; 256".

Related information

SOURCESYNC_TEST.startCycle()

Functional changes

  1. Introduced in MTP 3.2.2
