Wafer Configuration Record (WCR)

The Wafer Configuration Record contains the configuration information for the wafers tested. It provides dimensions and orientation information for all wafers and dice in the lot. This record is used only when testing at wafer probe time.

Location in the file:

The Wafer Configuration Record can be located anywhere in the data stream after the initial sequence, and before the MRR.

WCR field name

Field description

Value

93000 data source

WAFR_SIZ
  • Diameter of wafer in WF_UNITS
  • 4-byte floating point number
  • 0 = missing or invalid data
  • Application model variable1):

    WAFR_SIZ

  • Data source can also be a constant value in the configuration file or a system environment variable.

DIE_HT
  • Height of die in WF_UNITS
  • 4-byte floating point number
  • 0 = missing or invalid data
  • Application model variable1):

    DIE_HT

  • Data source can also be a constant value in the configuration file or a system environment variable.

DIE_WID
  • Width of die in WF_UNITS
  • 4-byte floating point number
  • 0 = missing or invalid data
  • Application model variable1):

    DIE_WID

  • Data source can also be a constant value in the configuration file or a system environment variable.

WF_UNITS
  • Units for wafer and die dimensions
  • 0 = Unknown units
  • 1 = Inches
  • 2 = Centimeters
  • 3 = Millimeters
  • 4 = Mils
  • Application model variable1):

    WF_UNITS

  • Data source can also be a constant value in the configuration file or a system environment variable.

WF_FLAT
  • Orientation of wafer flat
  • One-byte character string
  • U = Up
  • D = Down
  • L = Left
  • R = Right
  • <space> = Unknown
  • Application model variable1):

    WF_FLAT

  • Data source can also be a constant value in the configuration file or a system environment variable.

CENTER_X
  • X coordinate of center die on wafer
  • Two-byte signed integer
  • -32768 = invalid data
  • Application model variable1):

    CENTER_X

  • Data source can also be a constant value in the configuration file or a system environment variable.

CENTER_Y
  • Y coordinate of center die on wafer
  • Two-byte signed integer
  • -32768 = invalid data
  • Application model variable1):

    CENTER_Y

  • Data source can also be a constant value in the configuration file or a system environment variable.

POS_X
  • Positive X direction of wafer
  • One-byte character string
  • L = Left
  • R = Right
  • <space> = Unknown
  • Application model variable1):

    POS_X

  • Data source can also be a constant value in the configuration file or a system environment variable.

POS_Y
  • Positive Y direction of wafer
  • One-byte character string
  • U = Up
  • D = Down
  • <space> = Unknown
  • Application model variable1):

    POS_Y

  • Data source can also be a constant value in the configuration file or a system environment variable.
