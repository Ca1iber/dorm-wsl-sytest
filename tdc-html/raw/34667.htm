UserProcedureEventType

An event of this type is logged when a user procedure is called for a site.

Attributes

  • UserProcedureNameAttrType

    Holds the name of the called user procedure.

  • SiteIdAttrType

    Holds the ID of the site for which the user procedure was called.

  • PassFailResultAttrType

    Holds a pass or fail result for the user procedure. If the return_status (exit code) is CI_CALL_PASS or CI_TEST_PASS, the result is "pass"; for the other exit codes the result is "fail".

  • PlainDataAttrType

    Holds the output data for data logging of the user procedure. For a function, this is the contents of comment_out, for a program, it is the string that is written to stdout; for a script it is the echo string to standard out (echo "....").

  • TimeStampAttrType

    Holds the time when the execution of the user procedure was started.

Functional changes

  1. Introduced before SmarTest 6.3.2
