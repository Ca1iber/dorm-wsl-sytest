Pattern Editor quick reference

Content assist shortcut keys

The content assist helps you to fill out forms and editor cells. The content assist is available in the Pattern Editor and many other SmarTest views and editors.

Shortcut key

Function

Ctrl+Spacebar

Activates the content assist and opens pull-down menu

Ctrl+Backspace

Activates the content assist and deletes the current entry

Shift+Left Mouse Button

Selects a range in a table. To select a range in a table click the left upper cell, press Shift and click the right lower cell.

ESC

Leaves the content assist without changing the value.

Changing the Layout

  • To cut a signal from the layout highlight the signal column and press Delete.
  • To move a signal in the layout:
    1. Highlight the signal column you want to move, right-click and select Cut Signal from Layout.
    2. Highlight the signal column following the insertion point, right-click and select Insert Signal in Layout.

For more information see Configuring the layout of the Pattern Editor.

Finding/Replacing

  • To open the Find/Replace window, right-click in the Pattern Editor and select Find/Replace... .
  • To find a cell within a signal column, highlight the signal column and select Find/Replace... . The signal field in the Find/Replace window is filled out.

For more information see Finding and replacing pattern cells.

Incremental Find

Incremental Find allows you to go up and down in the editor with focus either on any signal column or on the first column. This is either the Cycle# or the Vector# column, depending on your layout configuration.

Ctrl + J

Activates "incremental find".

SHift + Ctrl + J

Activates "reverse incremental find".

For example, the current focus is on Vector/Cycle# 7. The whole row is highlighted. To go to # 15, press Ctrl + J and type 15. Focus and highlighting goes automatically to row 15.
