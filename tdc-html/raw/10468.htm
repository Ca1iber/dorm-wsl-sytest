Topic 10468

DC Measurements Using the PMU

You can use the following low level PMU commands that define and execute a sequencer program for pin PMU measurements so that you can apply individual settings per pin to pin PMUs.

  • MSET, MSET? - (definition of Measurement SET) defines a sequencer program for pin PMU measurements.
  • MEAS - (execute a MEASurement set) executes a sequencer program defined with the MSET command.
  • MEAR (retrieve MEAsurement Results) retrieves and stores the results of the last measurement executed with the MEAS command.
  • PMUR? (read PPMU result) retrieves the result of the measurement that is set up and performed with the MSET command.

For DC measurements, it is recommended to use the APIs described in DC Test Programming.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.3: Maximum number of parameter sets increased to 256
