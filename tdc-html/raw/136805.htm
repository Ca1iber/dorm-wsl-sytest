DRAM_ADDRESS_MAPPER

The DRAM_ADDRESS_MAPPER class supplies objects that allow you to change the default address mapping of a memory emulation by assigning DRAM row addresses either to ERAM row addresses or to predefined data.

The number of columns is the same in DRAM and ERAM (namely 1024), but typically, the DRAM contains much more rows. Therefore such an address mapping is usually necessary, but because of the identical number of columns, it can be defined on the row level. You have two options to overcome the different size of DRAM and ERAM. You can either map more than one DRAM row to the same ERAM row, or, as already indicated, map DRAM rows to predefined data, namely sequential memory or one fixed value, both of which can only be read, but not changed.

There is no constructor for this class. Use the getDramAddressMapper() member function of a MEMORY_EMULATION object to create an DRAM address mapper.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/DramAddressMapper.h.

Member functions

defineAddressMapping()

void defineAddressMapping(const INT startControllerRow, const INT rowCount, const EMULATION_TARGET targetMemory, const INT startEramRow = -1);

This member function maps a row block of a DRAM bank to the corresponding ERAM bank, to sequential memory or to fixed data. Since the mapping is the same for all banks, the DRAM bank need not be specified.

If you specify a block of 10 rows starting from 0 as the mapping source, the mapping target is ERAM, and the target location is 15, then the first 10 rows of every DRAM bank will be mapped to rows 15 through 24 of the corresponding ERAM bank. The mappings to sequential memory or fixed data are global, that is, no target address is specified.

Parameters

I/O

Parameter

Description

I

startControllerRow

A DRAM row address within a DRAM bank. The specified mapping holds for all banks. You cannot define different mappings for different banks.

The possible range is between 0 and the DRAM bank size.

I

rowCount

The number of rows to be mapped.

I

targetMemory

The mapping target. Possible values are:

EMULATION_TARGET::ERAM

EMULATION_TARGET::SEQUENTIAL_A

EMULATION_TARGET::SEQUENTIAL_B

EMULATION_TARGET::FIX_DATA

If SEQUENTIAL_A, SEQUENTIAL_B, or FIX_DATA is selected, the mapping is global.

I

startEramRow

If the mapping target is set to ERAM, the start row within an ERAM bank must be specified. If S is the size of an ERAM bank, this number must not be larger than S - rowCount.

If the mapping target is set to SEQUENTIAL or FIX_DATA, this parameter must be set to -1.

getEmulationTarget()

EMULATION_TARGET getEmulationTarget(const INT controllerRow, INT& eramRow);

This member function retrieves the mapping target of a DRAM row. If the DRAM row is mapped to ERAM, the row number within the ERAM bank will be returned. Otherwise, the function will return -1.

Parameters

I/O

Parameter

Description

I

controllerRow

The DRAM row within a bank whose mapping target is to be retrieved.

O

eramRow

If the DRAM row is mapped to ERAM, then the row number of the target ERAM row will be returned. If the DRAM row is mapped to sequential memory or fixed data, -1 will be returned

getControllerAddresses()

ARRAY_I getControllerAddresses(const INT eramAddress);

This member function retrieves the DRAM cells that are mapped to a certain ERAM cell. In this function the ERAM address is not bank related, but the absolute word number within ERAM. The function returns an array of integers that specifies all DRAM cells that are mapped to this ERAM cell. There can be more than one cell because more than one DRAM row can be mapped to the same ERAM row.

The information is returned as an integer which must be converted into binary format for interpretation: Bits 9 to 0 specify the column number (maximum value: 1023), bits 22 to 10 the row number (maximum value: 8191), and bits 25 to 23 represent the bank number.

Parameter

I/O

Parameter

Description

I

eramAddress

The absolute address of an ERAM cell.

setRowOfContentImage()

void setRowOfContentImage(MEMORY_IMAGE& targetImage, const INT controllerAddress, const ARRAY_I& data);

This function writes data to a memory image. It can be used to edit memory images that are used to initialize the ERAM (eramContent parameter of the setStartConfiguration() member function of the MEMORY_EMULATION class).

The function assumes that the memory image is organized as a matrix with 1024 columns and that the specified data fit into the row that is identified by the start address, which specifies a DRAM bank, row, and column. Accordingly, the size of the data array must not exceed the difference of the specified column number from 1024. If the specified controller address is mapped to sequential memory or the fixed value, an error message will be issued.

Parameters

I/O

Parameter

Description/Range

I

targetImage

The memory image to which the data is to be downloaded.

I

controllerAddress

Specifies the DRAM address as an integer. In the binary representation of this integer bits 9 through 0 must specify the column (maximum value: 1023), bits 22 to 10 the row number (maximum value: 8191), and bits 25 to 23 the bank number. The controller address bank #1, row 6, column 2, for example, would have to be coded as 8394754 (1 0000000000110 0000000010 in binary format).

Note that not all row addresses ≤ 8191 may be valid. This depends on the setting of the connectionMode parameter within the memoryConfiguration string, as set by the MEMORY_EMULATION constructor.

I

data

The data to be downloaded. The maximum size of the array is 1024 - the specified column number.
