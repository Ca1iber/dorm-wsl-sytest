Topic 10525

The label definition

A label is defined with the SQLB command. This command specifies the following items:

  • The name of the label.

    This name is associated with a port (see below), but it must be unique across ports.

  • The type of the label.

    The label type determines the role of the label within a complex of labels, for example, whether it can be executed independently (this is only possible for types MAIN and MPBU), or must be started from within another label (for example, type SVEC). The type also defines whether a label can contain genuine processing instructions (types MAIN, SVEC), or only serves to call other labels in a certain mode (types BRST, MPBU). For more information on the individual label types see Main programs and subroutines, and Burst and multi-port burst labels.

  • The location of the associated sequencer program.

    The location is specified by the command numbers of the first and the last instruction of the program within the sequencer area of the label port (see Label definition, sequencer program, and sequencer area).

  • The base wavetable (base waveform set in fixed timing).

    The definitions of this wavetable (waveform set for fixed timing) are used by the Pattern Tool. When a pattern is loaded they serve to translate the physical waveform DC/DC power units that are stored in the vector areas (see Sequencer program and vector areas) into device cycle names (or state characters) which are then displayed by the Pattern Tool. When the vector data is changed they are used to convert the new device cycle name (state character) into a waveform index, which is then written into the port specific vector area of the respective pin.

    Note that the base wavetable is not used for interpretation of the waveform DC/DC power units during test execution. Rather, the primary wavetable (which is determined by the timing specification defined with the SPRM command, see Executing a label) is used for that purpose. But the primary and the base wavetable must usually be identical.

  • The port with which the label is associated.

    Every label is associated with a port. If no port is specified in the definition, the label will be associated with the default port @, which comprises all pins. If the label is associated with a user defined port, it cannot be executed independently, but must be called from a multi-port burst (type MPBU).

    When a label is executed, its sequencer program will be applied to all pins of this port. Thus, if the label belongs to the default port, the same sequencer program will be applied to all pins.

Example

The following instances of the SQLB command define the labels which provide the standard example for the explanation of the vector setup:

SQLB "test_1",MAIN,4,8,"table1"
SQLB "test_2",MAIN,9,12,"table1"

Both labels are associated with the default port, that is, they can be executed independently (with FTST?); both are of type MAIN, and both have table1 as their base wavetable.
