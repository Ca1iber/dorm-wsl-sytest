Creating the Prober Stepping Pattern

Subtopics

  1. Method 1: Using the Mouse to Create Your Stepping Pattern
  2. Method 2: Using a Sort Method to Define Your Stepping Pattern
  3. Sorting Patterns Provided

After the grid appears, you can describe how the actual die on your wafer relate to this grid - for example, a certain number of die on each of the corners may not be valid. You might also want to describe the stepping pattern. With SmarTest, by describing the stepping pattern, you also describe which die are valid.

Note Specifying the prober pattern is optional. For it to be meaningful, you must ensure that the prober actually uses the pattern you create.
