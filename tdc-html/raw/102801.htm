Topic 102801

Preprocessor statements

MTL supports a range of standard preprocessor statements that allow modularizing and parameterizing the compilation process.

The supported statements are #define, #include, #ifdef, #ifndef, #if, #endif, #else, #elif, and #error. They can be used in the following types of files:

  • APG pattern file
  • APG program file
  • Device access file
  • Device architecture file
  • Pin mapping file
  • DC event file

These statements must appear as the first non-whitespace characters in their lines; otherwise, they are treated as comments.

The :defines: statement is supported only in the APG pattern file.

Keywords

The following table provides parameter and description information for each keyword in alphabetical order:

Keyword

Parameters and descriptions

:defines:

Creates a string macro that assigns a name to an arbitrary string.

The named string is used in subsequent code by enclosing it in curly braces and prefixing it with a dollar sign ($): ${<string_macro>}.

The :defines: statement is only supported in the APG pattern file.

The expansion ${<string_macro>} can be used in the following files:

  • APG pattern file
  • any non-SmarTest syntax file referenced from the APG pattern file
Note The expansion ${<string_macro>} cannot be used in files using SmarTest syntax (pin configuration, timing, and waveform mapping files).

The string macro can only be used after it has been defined.

:defines: sections can reside in the pattern file itself or in an external file referenced with #include. However, each section must completely reside within the same file - it may not be interrupted by #include statements.

:defines: can be used multiple times in the same file (directly or via #include). The only restriction is that names must be defined only once. (Trying to do so results in a compiler error.)

For example: 

:defines:
{
  :format:
  { :name:  :value: }
  { device   DDR3  }
}
...
:maintenanceOperation: ${device}_static

The program will in this case use the maintenance operation named "DDR3_static".

Note that the values assigned in the :value: column can be overwritten using the -D command line option. See apgc command syntax for details.

#define

Creates a macro that associates an identifier with a token string. For a defined macro, each occurrence of the identifier in the source file is substituted with the value of the token string.

For example:

#define ODT_ON1      1
#define ODT_OFF      0

#elif

A short version of "else if" that can be used in an #if statement to set off another alternative.

For example:

#if ${myVar} == 0
  // alternative 1
#elif ${myVar} == 1
  // alternative 2
#elif ${myVar} == 2
  // alternative 3
#else
  // alternative 4
#endif

#else

Indicates what is to happen when none of the preceding #if or #elif conditions is met.

#if ${myVar} == 0
  // alternative 1
#else
  // alternative 2
#endif

#endif

Closes an #if statement.

#if

Indicates code that is to be compiled only in certain conditions.

For example:

#if ${myVar} == 0
  :scramble: "address scrambling"
#endif

In this example, the "address scrambling" scrambling routine is only used if the myVar string macro has the value 0.

#ifdef

Same as #if, but tests whether a symbol has been defined.

For example:

#ifdef myVar
  :scramble: "address scrambling"
#endif

In this example, the "address scrambling" scrambling routine is only used if the myVar string macro has been defined. Its value does not matter.

#ifndef:

Same as #if, but tests whether a symbol has been not yet been defined.

For example:

#ifndef myVar
  :scramble: "address scrambling"
#endif

In this example, the "address scrambling" scrambling routine is only used if the myVar string macro has not been defined.

#include

Includes a named file as if that file's text was part of the current file.

For example:

#include ../variableDefinitions.txt

Before the file containing the #include statement is compiled, the preprocessor replaces the statement with the content of the file variableDefinitions.txt. The file is located in the folder containing the parent folder of the current file.

#error

Reports your specified error message at compile time and then terminates the compilation.

For example:

#error  "ddr3.dvac: unknown DataBusWidth '${DataBusWidth}'"

Functional changes

  1. Introduced in MTP 2.4.0
  2. MTP 3.0.1: String macro values can be overwritten from the command line
  3. MTP 3.3.2: Adds, #define and #error
