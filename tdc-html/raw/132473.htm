TMU_TASK.uploadRawResults()

Uploads the raw result data for a specified shot into the result cache. You need a TMU_RESULTS object for each shot.

Syntax

TMU_RESULTS& uploadRawResults(shotnum = 0);
TMU_RESULTS& uploadRawResults(const char *ResultHandle,shotnum = 0);
TMU_RESULTS& uploadRawResults(STRING &ResultHandle,shotnum = 0);
Parameters

I/O

Parameter

Description

I

resultHandle

The result handle to access.

I

shotnum

The shot number which result to be uploaded.

The default value is 0, which means the results of all shots will be uploaded.

Return value

A reference to the TMU_RESULTS object is returned.
