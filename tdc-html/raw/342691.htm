Topic 342691

Setting up DC tests

Dynamic DC tests are set up by defining NameMaps objects and adding specially formatted pattern labels.

Specifying DC events

The DC events that you want to use are specified in a NameMaps object.

The NameMaps object must be named "93kDynamicDC_Events" and contain one AllNames object. That object contains a list of event specifications, separated by semicolons.

Each definition has this form:

event-name "signal=codeph>signal-name, force=category, value=value[, measure=category][, samples=number-samples][, limitLow=lower-limit][, limitHigh=upper-limit]"

The parameters indicate:
event-name
The name of the DC event that you are defining.
signal

The name of the supply pin.

This parameter is mandatory.

force

voltage or current. Whether voltage or current is forced by the event.

This parameter is mandatory.

value

The value to which the voltage or current is set.

This can be either a fixed value (for example, "1.95V") or it can be a DC spec variable. A variable must be prefixed with "LEV"; for example, to specify the DC variable VDDA, use value=LEV:VDDA.

This parameter is mandatory.

measure

voltage or current. The type of measurement to perform.

This parameter is optional. If it is not specified, no measurement is performed.

samples

The number of samples to take.

This parameter is optional. If it is not specified, one sample is taken.

limitLow

The lower limit to use with the measurement.

This parameter is optional. However, you should not omit both limitLow and limitHigh.

limitHigh

The upper limit to use with the measurement.

This parameter is optional. However, you should not omit both limitLow and limitHigh.

For example:
CM1 "signal=VDD, force=voltage, measure=current, value=2, samples=16, limitmode=on, limitLow=0.1, limitHigh=1";

Calling DC events

When you have defined the events as described above, you call them in your pattern by inserting specially formed labels into the pattern.

The label you insert has the form:

"<DC_EVENT_n>event-name":IddqTestPoint

The placeholders indicate:
n
An integer that is needed to differentiate the labels from each other.
event-name

The name of the event as defined in the NameMaps element.

For example: "<DC_EVENT_15>CM1":IddqTestPoint

Example

Sample dynamic DC test

This STIL file sets up five DC events (CM1, CM2, CM3, vb1, and vb2) and calls one of them (vb2) towards the end of the pattern.

STIL 1.0 {
  Design D22;
  DCLevels 2002;
}

Signals {
  clk In;
  d1 In;
  VDD Supply;
}

SignalGroups {}

Spec all_specs {
  Category all_cats {
    per1 = '100ns';
    vdd_low = '1.5V';
    vdds_low = '2.7V';
    vdd_hi = '1.8V';
    vdds_hi = '3.3V';
    iddmax = '100mA';
    vih_hi = '3V';
    vil_hi = '0V';
  }
}

Environment {
  NameMaps "93kExtraLevels" {
    Signals {
     clk         "term=off,rec_swing=-5.5V";
     VDD         "offcurr=act, t_ms = -20";       
    }
  }
  NameMaps "93kPorts" {
    SignalGroups {
       clk       "port=p1,wavetbl_name=t1";
       d1        "port=p2";
       VDD       "port=pVdd,wavetbl_name=t1";
    }
  }

  NameMaps "93kDynamicDC_Events" {
    AllNames {
        CM1    "signal=VDD, force=voltage, measure=current, value=2, samples=16, limitmode=on,limitLow=0.1, limitHigh=1";
        CM2    "signal=VDD, force=voltage, measure=current, value =LEV:vdd_hi, samples=32, limitmode=off, limitLow=0.1, limitHigh=1";
        CM3    "signal=VDD, measure=current, samples=16, limitmode=on, limitLow=0.2, limitHigh=LEV:iddmax";
        vb1    "signal=VDD, force=voltage, value =LEV:vdd_low";
        vb2    "signal=VDD, force=voltage, value =LEV:vdd_hi";
    }
  }
}


Timing slow {
  WaveformTable ts1 {
    Period 'per1';
    Waveforms {
      clk      { P  { '0ns' D; '1.3ns' U; } }
      d1       { 01 { '2ns' D/U; } }
      VDD      {}
    }
  }
}

DCLevels hi_vdd {
  VDD {
    VForce 'vdds_hi';
    IClamp 'iddmax';
  }
  'd1+clk' {
    VIH 'vih_hi';
    VIL 'vil_hi';
  }

}

DCSets all_sets {
  DCLevels hi_vdd;
}


Selector all_typ {
  per1 Typ;
  vdds_low Typ;
  vdd_hi Typ;
  vdds_hi Typ;
  iddmax Typ;
  vih_hi Typ;
  vil_hi Typ;
}

PatternBurst one_pat {
  PatList {
    nolevels;
  }
}


PatternExec all_func {
  Category all_cats;
  Selector all_typ;
  Timing slow;
  DCLevels hi_vdd;
  DCSets all_sets;
  PatternBurst one_pat;
}

Pattern nolevels {
  W ts1;
  V { d1 =1; clk=P;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  "<DC_EVENT_1>vb2":IddqTestPoint;
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
  V { d1 =1;}
}
