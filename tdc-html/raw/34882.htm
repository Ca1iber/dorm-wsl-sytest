Appendix C: File Locations

This is an overview of where the files related to event data logging are located:

  • The header file of the Data Retrieval Library (DRL) is located in /opt/hp93000/soc/com/include/drl.h

    In the same directory, you also find the header files dcl.h and dcl_drl.h, which also are related to the data retrieval library.

    These files are important for writing a custom data retrieval tool.

  • The executable of the DRLDump tool is /opt/hp93000/soc/.service/bin/DRLDump.

    See Appendix B: The DRLDump Tool for more information.

  • The source file of the DRLDump tool, main.c, and a make file for compilation are provided in the directory /opt/hp93000/soc/.service/DRLDump/.

    If you want to write your own data retrieval tool, we recommended that you use the DRLDump tool as a template.

  • The executable of the STDF reader is /opt/hp93000/soc/formatter/bin/STDFreader.
