Data-logging protocol-aware tests

Fine result granularity (FRG) is not compatible with protocol-aware testing.

While, in general, all data-logging features are available for protocol-aware tests, fine result granularity is not. This means the following settings must not be active for protocol-aware tests:

  • The FRG enable test suite flag
  • The datalog_detail settings 4 and 5.

Using any of these settings for protocol-aware test will usually result in an error message:

Requested fine result granularity cannot be achieved with current settings.

Mixed testflows

If you want to use these settings for testflows that also contain protocol-aware test suites, you can define override rules for these test suites.

For example:

*pa.*.*.datalog_detail = 3
*.*.*.datalog_detail = 5

These settings specify data logging detail level 3 for all test suites whose names end with "pa" and level 5 for all other test suites. Of course, this requires you to give all protocol-aware test suites names ending in "pa". If you have different naming conventions, you must adapt the rules accordingly.
