EVENT_WAVEFORM_ICIM.iClampLow()

Sets the low clamp current waveform.

You can specify both the low and the high clamp current waveform or just one.

Note iClampLow is used to force a sink current, while iClampHigh is used to force a source current. Both parameters must be > 0. You can specify both clamp currents independently, but only one of the clamps can be active at a time, depending on the load conditions. Therefore, if you want to modify the flowing current, it's sufficient to modify the value of the clamp that's currently active. The value of the other clamp does not matter, because it's inactive.

Syntax

EVENT_WAVEFORM_ICIM &iClampLow ( ANALOG_WAVEFORM & waveform);
Parameter
Parameter Description
waveform

Waveform definition object

Return value

There is no return value.

Example

For an example see EVENT_WAVEFORM_ICIM.
