Popup Message

This function generates a message popup with maximum 8 buttons. The popup appears with two default buttons and the message in *msg. When any parameters *b2s to *b7s are non-empty strings, additional buttons between Quit and Continue buttons also appear (see below).

long MsgDisplayMsgGetResponse(char *msg, char *b2s, char *b3s,

char *b4s, char *b5s, char *b6s, char *b7s,

long *response)

The popup disappears when any button is pressed and the parameter *response is set to the button number selected as follows:

*response = 1; Quit

*response = 2; user button 2 (b2s)

*response = 3; user button 3 (b3s)

*response = 4; user button 4 (b4s)

*response = 5; user button 5 (b5s)

*response = 6; user button 6 (b6s)

*response = 7; user button 7 (b7s)

*response = 8; Continue

Button strings are restricted to a length of CI_MAX_BUTTON_STR_LEN = 9. The Message string is limited to a length of CI_MAX_MESSGE_STR_LEN = 512.
