Waveform classes provide functionality to define events that generate waveforms.

EVENT_WAVEFORM_IC is a specialized event class that defines an array of current clamps (IC) as waveform.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

EVENT_WAVEFORM_IC ( const STRING & id);
EVENT_WAVEFORM_IC ( INT & id);

This constructs an object of the EVENT_WAVEFORM_IC class. The class derives from the EVENT_BASE class.

Parameter
Parameter Description
id

Event identifier

Return value

There is no return value.

Example

The example shows the definition of the low clamp current value(.iClampLow()), and of the distance between sample vectors (100).

PATTERN_CONTROLLER cleanUpPattern;
PATTERN_CONTROLLER pc;

EVENT_WAVEFORM_IC iClampWaveform("iClampWaveform");

ANALOG_WAVEFORM rampUpLow("rampUpLow");
  rampUpLow.definition(TM::RAMP).min(100. mA).max(400. mA)
           .direction(TM::POS).samples(10);

ON_FIRST_INVOCATION_BEGIN;

    cleanUpPattern.label("patEvents", "@")
                  .vecEvents("dps1")
                  .clearAll()
                  .setup();
  
    iClampWaveform.iClampLow(rampUpLow).sampleVectorDistance(100);

    // insert events into pattern
    PATTERN & pattern(pc.label("patEvents", "@"));
    pattern.vecEvents("dps1").insert(300, iClampWaveform);

    pc.setup();
ON_FIRST_INVOCATION_END();
