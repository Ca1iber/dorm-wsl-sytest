The AI_V2B_OPTIONS Section

This section of the Vector Configuration File specifies v2b parameters that are to be applied to the vector translation of all patterns in the PATTERNS section. If the specifications of this section contradict those of the v2b_options column (see The PATTERNS Section) for a specific pattern, the v2b_options column has priority.

There is one option that can only be specified in the AI_V2B_OPTIONS section, not in the PATTERNS section:

-cmb <x-mode_control_file>

For more information on this option see Adapting the X-Mode Control file to the ASCII Vector Files.

Functional changes

  1. Introduced before SmarTest 6.3.2
