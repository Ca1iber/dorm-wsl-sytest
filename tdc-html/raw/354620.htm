XPS256 programming - Surge tracker

The XPS256 card features a surge tracker per channel that monitors the voltage between the high sense (PS#) and ground sense (GS#) pins or the output current of the PMU.

API overview

The complete functionality of the surge tracker is covered by the APIs DPS_AUX_TASK and DPS_AUX_PIN_TASK.

Functionality

Member function

Select and enable the surge tracker

DPS_AUX_PIN_TASK.setMode()

Set the voltage or current thresholds

  • XPS256 supports setting both the voltage thresholds and the current thresholds in a single setup.

DPS_AUX_PIN_TASK.selectVSensorSetThresholds()

DPS_AUX_PIN_TASK.selectISensorSetThresholds()

Write the accumulated status to the test method cache and clear the accumulated status

DPS_AUX_PIN_TASK.checkSurgeTracker()

Read the accumulated status from the test method cache

DPS_AUX_TASK.getSurgeTrackerStatus()

Kelvin test / sense connection test in Hardware view

The Kelvin test / sense connection test is supported by the Hardware view for the XPS256 pins in DPS operating mode or in PMU operating mode.

Application note

Surge tracker is silently disabled in temporarily unganged mode

Note that on DPS128/64 and XPS256 you cannot execute a current compare on a ganged group of channels in unganged mode. Already activated comparators are silently disabled in unganged mode. A user notification (Error or warning) is omitted in this case, to avoid any interrupt in the testflow. The previous state of the comparators is automatically restored after the ganged group has been restored.

Example

Simultaneously tracking the voltage and the current

DPS_AUX_TASK auxTask;

ON_FIRST_INVOCATION_BEGIN();
{
    auxTask.pin("XPS256_PMU_1")
            .setMode                    (TM::SURGE_TRACKER)
            .selectVSensorSetThresholds (-0.5 V, 3.5 V)
            .selectISensorSetThresholds (-0.1 A, 0.4 A);

    auxTask.execute();

    ...
    ...

    auxTask.pin("XPS256_PMU_1").checkSurgeTracker(TM::AGAINST_BOTH);
}
ON_FIRST_INVOCATION_END();

TM::SURGE_TRACKER_STATUS statusVoltage, statusCurrent;

auxTask.getSurgeTrackerStatus("XPS256_PMU_1", statusVoltage, statusCurrent);

cout << "Site " << CURRENT_SITE_NUMBER() << ", Voltage surge tracker: " << statusVoltage << endl;
cout << "Site " << CURRENT_SITE_NUMBER() << ", Current surge tracker: " << statusCurrent << endl;
