Fail bit count

The fail bit count (FBC) sums up the number of failing cells per data bit, bank, and DUT. It is based on physical addresses.

When the fail_count_enabling parameter of the ExecutionEngine test method is set to YES, the fail bit count is used instead of the results of the functional test to determine the pass/fail result for a device.

If the FBC is to be used to determine pass/fail results, the limits must be specified in these ExecutionEngine parameters:

  • limit_per_device
  • limit_per_DQ
  • limit_per_bank

The test fails if the FBC exceeds one of these limits and passes otherwise. A failed FBC interrupts the redundancy analysis (if fail_count_enabling is YES).

FBC can be enabled independently of the redundancy analysis. It supports multisite testing.

FBC reporting

Fail bit count results are reported in these places:

  • The SmarTest report window displays the individual FBC results as well as the pass/fail results of these counts.
  • The result server's log file includes the individual FBC results as well as the pass/fail results of these counts.
  • The BFD file includes the individual FBC results.
  • The event data log includes events for the individual FBC results as well as the pass/fail results of these counts.

See the examples in Parameters for the ExecutionEngine test method and Output of the Successive algorithm for samples of how FBCs are reported.
