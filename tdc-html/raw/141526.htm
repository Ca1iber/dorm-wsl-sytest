MTP_MEMORY_TEST.setRAUseCountingResults()

Determines whether the redundancy analysis algorithm will use the counting results calculated from setRACounting().

The redundancy analysis algorithm is specified in a Redundancy analysis configuration file.

Therefore, to use this function, you must select an RA configuration file with setRAConfigFile() and enable the RA algorithm with setRAAlgorithm().

Syntax

MTP_MEMORY_TEST& setRAUseCountingResults (const bool & status);
Parameter

Parameter

Description

status

The status can be:

  • true: The RA algorithm will use the counting results calculated from setRACounting().

    Do not set setRAAlgorithm(concurrent mode) with setRACounting(delay mode), because the concurrent RA algorithm cannot use the delayed counting results.

  • false: The RA algorithm will not use the counting results calculated from setRACounting().

List of parameters

There are no parameters.

Return value

There is no return value.
