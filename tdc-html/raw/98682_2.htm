PCLK, PCLK? - (Pin CLocK)

The PCLK (Pin CLocK) command defines the test system period for the specified waveform set/equation set and timing set. All pins will have the same period if you use the all specifier (@) for the pin list. Otherwise a pin specific periods will be programmed.

If you change the period of timing set 1 with PCLK for all pins (@), and if no period resolution has been explicitly defined (for example, with CLKR), then the period resolution will be recalculated in order that the new period be an integer multiple of the period resolution. This can also lead to new auto-corrections for the periods of timing sets > 1. In contrast, if you change the period of a timing set > 1 with PCLK, then the specified value will be corrected if it is not an integer multiple of the actual period resolution. For more information see Determining the period resolution.

In fixed timing, new timing sets are created, if the timing set number specified is greater than the maximum number of allowed timing sets as defined with TSUS. New waveform sets are also created if the given waveform set is greater than the maximum number of allowed waveform sets as defined with WSUS.

The PCLK? query can return the values specified by the user, and for timing sets > 1, also the corrected values that are actually used.

PCLK

Fixed timing:

PCLK{waveform_set}, {timing_set}, {period}, {(pinlist)}

Equation-based timing:

PCLK {specset_id|"multi-port_spec"}, {timing_set}, {period}, {(pinlist)}

PCLK?

Fixed timing:

PCLK?{waveform_set},{timing_set},{(pinlist)} [,query_mode]

returns: 

PCLK {waveform_set}, {timing_set}, {period}, {(pinlist)}

Equation-based timing:

PCLK? {specset_id|"multi-port_spec"}, {timing_set}, {(pinlist|portlist)} [,query_mode]

returns: 

PCLK {specset_id|"multi-port_spec"}, {timing_set}, {period}, {(pinlist)}

Parameters

waveform_set

Waveform Set Number. Enter PRM for the Primary Waveform Set, or an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by WSUS. For the query command you can also enter ALL for all waveform sets.

specset_id

Used for equation based timing. It is derived as follows:

100 * equation_set_no + specset_no

Note that if you change the period for an equation based timing setup, PCLK will only change the runtime value, not the setup value specified in the timing set.

multi-port_spec

In the command, you cannot enter a multi-port specification unless the specification is associated with the default port, and no other ports are configured. This restriction does not apply to the query.

timing_set

Timing Set Number. Enter PRM for the Primary Timing Set, ALL for all timing sets, or an integer in the range 1 to the maximum number of allowed timing sets. The maximum number is determined by TSUS.

period

Enter the test system period in ns. The period range depends on the model. For the Pin Scale 800, the range is 2.5 ns to 31250 ns. All values entered (or queried regardless of query_mode) are in ns and will be rounded to nine digits after the decimal point (atto-seconds) according to the accuracy of the firmware. The power-on default value for all configured pins also depends on the model.

pinlist

The name of the pin or pins whose period you want to define or read back. This parameter can also include groups previously created by DFGP. If more than one pin is to be included, the names must be separated with a comma. The symbol @ can be used to set or read the periods for all configured pins. If you do not use @, the firmware assumes asynchronous operation.

portlist

In the query, you must specify a list of ports, if you have specified a multi-port specification for the first parameter.

query_mode

In the query, you can specify whether the period specified by the user or the corrected period calculated by the system is to be returned. The allowed values are:

WANT: The period defined by the user is returned. This is also the default.

EXACT: The period calculated by the system is returned.

Application

Timing Setup, see Timing Setup Commands.

Errors

An error is generated if:

  • waveform_set is greater than the range allowed by the WSUS command.
  • timing_set is greater than the range allowed by the TSUS command.
  • The period lies outside the given range.

Examples

Example 1

PCLK 101,1,20,(@)

This example sets the test system period for specification 101 to 20 ns.

Example 2

PCLK 101,1,40,(S1)

This example sets the test system period of pin S1 for specification 101 to 40 ns.

The VCLK? query checks whether a PCLK command with the specified parameter values was accepted with or without auto-correction.

Functional changes

  1. Introduced before SmarTest 6.3.2
