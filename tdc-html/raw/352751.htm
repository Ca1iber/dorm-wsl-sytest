Topic 352751

Switching between SmarTest versions

Before you begin

Before attempting to switch versions, make sure that:

  • Two or more versions of SmarTest are installed.
  • SmarTest or other tools, such as TML, MTP, and RDI, are not running.
Note Use the command line form when executing the switch_version tool in a script. For details see Switch version command line tool.
Note For SmarTest 7.10.0 a warning is always given after a selection has been made for the Calibration Data (std). This warning, that the selected cal data version does not match the selected SmarTest version, must be ignored. Press 'y' to continue.

Procedure

  1. On the task bar, click Start > Applications > Advantest V93000 > Switch Version

    Alternatively, type on the command line:

    /opt/hp93000/soc_common/bin/switch_version

    The switch version window opens and lists the installed SmarTest versions.

  2. Enter the number corresponding to the SmarTest version that you want to use.

    In the following example, to select SmarTest version 7.4.5.4, entry 15 is specified:

  3. If, for example, TML is installed, the Select TML version section is displayed with the matching TML version preselected, if available.

    In the example, the TML version TML 7.4.5.4 matching the selected SmarTest version 7.4.5.4 is selected by default:

    Press Enter to select the matching TML version or specify an alternative item number and press Enter.

    For further tools such as RDI, similarly select the version required.

    Switch Version activates the chosen versions of SmarTest, TML, and RDI if specified, and on completion displays the message:

    All databases successfully installed.
  4. Press Return to exit Switch Version.

Results

The specified version of SmarTest is activated.

The specified version of SmarTest and additional tools such as RDI or MTP, if selected, are activated.

Starting SmarTest from the Red Hat menu or /opt/hp93000/soc/prod_env/bin/HPSmarTestlaunches the active version.

What to do next

Start SmarTest or other tools such as MTP.
