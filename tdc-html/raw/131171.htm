TMU_RESULTS.getRawData()

Retrieves the raw result data. If it is successfully execute, TRUE is returned. Otherwise, FALSE is returned.

Syntax

Boolean getRawData(STRING&  pin, Wave<DOUBLE> * wave,UINT32 meas = 1, UINT32 site = 0);
Boolean getRawData(const char* pin, Wave<DOUBLE> * wave, UINT32 meas = 1, UINT32 site = 0);
Parameters

I/O

Parameter

Description

I

pin

The pin to query.

O

wave

The Wave object to store the raw result data.

I

meas

The measurement ID.

I

site

The site to query. Default is 0, which means the current site.

Return value

The execution status of the function is returned. It can be true or false.

Functional changes

  1. Introduced in SmarTest 7.1.0
