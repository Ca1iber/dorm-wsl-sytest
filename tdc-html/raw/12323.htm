Topic 12323

Test Result Commands

Subtopics

  1. Concepts of test result processing
  2. List of test result commands

This chapter explains the commands that are used by the result tools. These commands can be grouped as follows:

  • global result commands,
  • commands for managing the Error Maps,
  • subsidiary commands that do not require a previous test execution.

Each of these groups will be described in a separate section of this chapter.
