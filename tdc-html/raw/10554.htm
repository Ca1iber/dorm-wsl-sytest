Vector generating instructions

The two main instructions for applying parallel vectors to the DUT are GENV and RPTV. Both have a length parameter that specifies the number of vectors to be generated. RPTV also has a repetition parameter that defines how often the specified number of vectors is to be applied. For details see SQPG, SQPG? - (SeQuencer ProGramming).

Maximum number of vectors that can be generated with GENV and RPTV sequence instructions

  • For the GENV sequencer instruction: for param_1 (the number of parallel vectors to be generated): the maximum is (221- 1) * 8.

  • For the RPTV sequencer instruction:

    • For param_1 (the number of parallel vectors to be generated): the maximum is (221- 1) * 8.
    • For param_2 (the number of repetitions): the maximum value depends on whether param_1 exceeds the word length of 8. If it does not, the maximum is 224 - 8. If it does, the maximum number is 218.

Example

Two examples of vector generating instructions are:

SQPG 7,GENV,9,,,(@)

This GENV instruction generates 9 vectors.

SQPG 6,RPTV,6,5,,(@)

This RPTV instruction generates 6 vectors 5 times in a row.
