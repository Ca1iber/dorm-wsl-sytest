DIGITAL_OFFSET_SEARCH_PINS.enableFastStop()

Enables or disables the FASTSTOP mode.

FASTSTOP stops the linear search when:

  • The first valid eye is returned for the EYE search type. The search types are defined with DIGITAL_OFFSET_SEARCH_PINS.searchType()

    A valid eye means both edges of an eye (a fail/pass and a pass/fail transitions within the search window) are returned. An open eye is not taken account of. The number of the PASS tests does not matter.

  • The first two subsequent measurements of pass/fail or fail/pass are returned for the search type LB or RB.
  • If the above conditions are not met, FASTSTOP returns the same result as the standard mode, which returns the largest pass area.

Syntax

void DIGITAL_OFFSET_SEARCH_PINS& enableFastStop(status);
Parameter

Parameter

Description

status

TRUE or FALSE to enable or disable the FASTSTOP mode.

When FALSE, the standard search mode that returns the largest pass area is used.

Return value

A reference to the DIGITAL_OFFSET_SEARCH_PINS object.
