INSI - (INsert Instructions)

The INSI (INsert Instructions) command inserts count place holder (NOP) instructions into the sequencer area before the command with the number cmd_No. You can then overwrite the NOP instructions with other instructions by using the command SQPG, SQPG? - (SeQuencer ProGramming).

The INSI command can only be issued after a label has been selected for editing with the TSTL command.

Syntax

INSI {cmd_No}, {count}

Parameters

cmd_No

The command number before which instructions are to be inserted.

count

This parameter defines the number of NOP instructions to be inserted.

Application

Edit command in Pattern Tool.

Errors

An error is generated if:

  • There is insufficient channel memory.
  • There is insufficient disk space (offline operation only).
  • No label has been activated for editing.
  • The specified command number is out of range.

Example

TSTL "test_1",(@)
INSI 358, 12

This example inserts 12 NOP sequencer instructions before command number 358.

Functional changes

  1. Introduced before SmarTest 6.3.2
