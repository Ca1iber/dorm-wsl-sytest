External tools needed for working with virtual machines

To work with a TE-Cloud virtual machine, some third-party tools are needed.

The tools listed here are only recommendations. If desired, you can substitute other tools with similar capabilities. For information on working with substitute tools, refer to their documentation.
  • Web browser: Google Chrome, Firefox, or other modern web browsers. Do not use Internet Explorer or Windows Edge in a very old version.

    The web browser launches the TE-Cloud dashboard for creating a virtual machine.

  • SSH client: PuTTY. This client is used to set up the mapping of ports on the virtual machine and remote connection.
  • Key generation tool: PuTTYgen. It is installed as a package with PuTTY, and is used to generate the SSH keys for the virtual machine.
  • VNC client: VNC Viewer. With the VNC client, you can visit the virtual machine for project development and virtual machine management.
  • SFTP file transmission client: FileZilla. This is used to transmit files to and from the virtual machine.

Functional changes
