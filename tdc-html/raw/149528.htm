Topic 149528

search()

This function specifies a search type.

Syntax

search(TA::SEARCH_MODE sMode)
List of parameters

Parameter

Description

sMode

The type of search to perform.

TA::BINARY: A binary search.

TA::LINEAR: A linear search.

TA::HYST_LINEAR: A hysteresis linear search.

Examples

Binary search

RDI_BEGIN();
  rdi.cogo().search(TA::BINARY).pathPin("pinA")
            .start(0).stop(4.0).init(1.0).step(3).blockBegin();
       rdi....(rdi.searchInput()).execute();
       rdi....execute() // With pass/fail judgment.
  rdi.cogo().search().blockEnd();
RDI_END();

Linear search

RDI_BEGIN();
  rdi.cogo().search(TA::LINEAR).pathPin("pinA")
            .start(0).stop(4.0).step(10).blockBegin();
       rdi....(rdi.searchInput()).execute();
       rdi....execute() // With pass/fail judgment.
  rdi.cogo().search().blockEnd();
RDI_END();

Hysteresis linear search

RDI_BEGIN();
   rdi.cogo("result").search(TA::HYST_LINEAR).pathPin("pinA")...blockBegin();
       ...
  rdi.cogo().search().blockEnd();
RDI_END();

rdi.id("result").getSearchRiseResult();
rdi.id("result").getSearchFallResult();

Functional changes

  1. Introduced in SmartRDI 2.4.0
  2. SmartRDI 2.4.3: Supported hysteresis linear search with a new HYST_LINEAR type.
