SQEC, SQEC? - (SeQuencer Execution Context)

The SQEC command serves to define an execution context. The SQEC? query returns the definition of a selected execution context, or of all execution contexts. For information on execution contexts, see Using execution contexts.

SQEC

SQEC {"context_name"}, {(port_list)}

SQEC?

SQEC? {"context_name"|ALL}

returns:

SQEC {"context_name"}, {(port_list)}

Parameters

context_name

The name of the context. If a context with this name already exists, the previous definition will be overwritten.

ALL

In the query, you can specify ALL in order to retrieve the definitions of all executuion contexts

port_list

The list of the ports that are to run in this execution context.

Errors

An error occurs if:

  • One of the specified ports does not exist.
  • Any two of the specified ports contain the same pin.

Example

> SQEC "c1",(P1,P2)
> SQEC? ALL
< SQEC "c1",(P1,P2)

Functional changes

  1. Introduced in SmarTest 7.2.0
