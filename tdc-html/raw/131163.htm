TMU_RESULTS.getPeriodStddev()

Returns the standard deviation value of the period of the specified pin, measurement ID and site. The member function uploadPeriodResults() of TMU_PINS needs to be used before using this function.

Syntax

DOUBLE getPeriodStddev(STRING& pin, UINT32 meas = 1,UINT32 site = 0);
DOUBLE getPeriodStddev(const char* pin,UINT32 meas = 1,UINT32 site = 0);
Parameters

I/O

Parameter

Description

I

pin

The pin to query.

I

meas

The measurement ID.

I

site

The site to query. Default is 0, which means the current site.

Return value

The standard deviation of the period is returned in the unit second.

Functional changes

  1. Introduced in SmarTest 7.1.0
