Using a DC resource as an AWG with SmartRDI

Subtopics

  1. addWaveform()
  2. FS()
  3. perSiteVal()
  4. repeat()
  5. sampleCycle()
  6. samplePeriod()
  7. waveform()

Setting up DC resources as AWG is like setting up a real AWG. Define a waveform and then set up a type and sampling frequency for the waveform.

About this task

The DC resources used as AWG can be DC Scale pins and PPMU.

Before you begin

Make sure the SmarTest version is 7.2.1 or above.

Procedure

  1. Define the waveform with the class anaWaveform.
  2. Set up a pin or pins to work as AWG.
    1. Specify the port to set up. It is a must setup for PPMU and optional for DC Scale pins.
    2. Create a test with the class dc().
    3. Specify the pin(s) to work as AWG with pin(). For PPMU, the specified pin must be the same as defined in the specified port.
    4. Specify the type of waveform with vForce() for voltage waveform or iForce() for current waveform. It is voltage waveform by default.
    5. Specify the waveform to force with the function waveform().
    6. Specify the sampling frequency with FS(), samplePeriod() or sampleCycle().
    7. Execute the setup with execute().

Results

The DC resource can be used as an AWG to generate the defined waveform.

Note To send a waveform with PPMU, port() must be used. The port must only have the pin which will send the waveform. For example, 
RDI_BEGIN();
   rdi.port("portA").dc().pin("pinA").vForce().waveform("wav").FS(100 K).execute();
RDI_END();
// The portA only has pinA.
Note When PPMU is used as AWG, its default relay action is the same as a normal PPMU measurement:
Parameter Description
rly_before The relay actions before a PPMU measurement. The default value is TA::ppmuRly_onPPMU_offACDC.
rly_after The relay actions after a PPMU measurement. The default value is TA::ppmuRly_NO. If not specified, the relay will not be changed after the measurement.
You can use relay() to change the relay actions. See relay().

Example

anaWaveform vwav ("UP_V");
vwav.definition(TM::SINE).periods(3).amplitude(3 V).offset(0.5 V).samples(2048);
...
rdi.dc().pin("VI32_1").waveform(vwav).FS(10 KHz).execute();
rdi.dc().pin("VI32_1").vForce().waveform(vwav).FS(10 KHz).execute();
rdi.dc().pin("DPS32_SIG_1").vForce().waveform(vwav).FS(10 KHz).execute();
rdi.port("ptPin1").dc().pin("DATA1").waveform(vwav).samplePeriod(100 us).execute();
rdi.port("ptPin1").dc().pin("DATA1").iForce().waveform(vwav).sampleCycle(1000).execute();
