rdi.setInfoLevel()

Sets an RDI information level value to replace the RDI_INFO_LEVEL in block(s) or test suite(s).

For debugging, you can use this function in RDI blocks or test suites to set a high level so you will be able to know more detailed information about the certain RDI blocks or test suites. Except for the blocks or test suites with this function, the level for other segments remain unchanged as the variable RDI_INFO_LEVEL has set.

rdi.getInfoLevel() is used to retrieve the debug level value.

Syntax

void setInfoLevel(int val);

Example

Setting the RDI_INFO_LEVEL to 2 for a block:

...
cout<<"RDI_INFO_LEVEL ="rdi.getInfoLevel()<<endl;
rdi.setInfoLevel(2);

RDI_BEGIN();
  rdi.dc().pin("DATA1").vForce(3 V).execute();
  rdi.dc().pin("DATA2").iForce(0 mA).vMeas().measWait(100 us).execute();
RDI_END();

cout<<"RDI_INFO_LEVEL ="rdi.getInfoLevel()<<endl;

rdi.setInfoLevel(0);
