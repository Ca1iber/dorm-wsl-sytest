Using hidden upload with SmartRDI

SmartRDI supports the hidden upload for the measurement with digitizer, RF measurement, DC measurement, and digital capture test, error maps and TMU.

About this task

SmartRDI provides the rdi.hiddenUpload() function to enable the hidden upload functionality. The functions to retrieve the test result with the hidden upload are the same functions to retrieve the test result without hidden upload.

Procedure

  1. In the run() function of the test method class,
    1. Enable the hidden upload with the function rdi.hiddenUpload().
    2. Execute the test as usual in an RDI block.
    3. Start the hidden upload with SMC_ARM().
  2. Retrieve the result with SmartRDI get...() functions in the public method SMC_backgroundProcessing() of the test method class. No unique result ID is required for the result retrieval functions.

Results

The test result will be uploaded through hidden upload.

Notes on the usage:

Note In the first run after build/TM termination, SmartRDI will do normal uploads instead of hidden uploads for all user-specified hidden-upload results. The purpose is to prevent the conflict between hidden uploads and setup generation.
Note SMC_backgroundProcessing() supports all rdi.id().get...() functions and tool functions, except for the following get...() functions:
  • rdi.getBuildDate()
  • rdi.getActiveRdiRev()
  • rdi.getCompileRdiRev()
  • rdi.getLabelCycleNum()
  • rdi.getCommentCycleNum()
  • rdi.getCommentVectorNum()
  • rdi.getPriAnaSet()

Except for get...() and tool commands, SMC_backgroundProcessing() does not support other SmartRDI commands.

Refer also to Automatic check for thread-safe APIs in Thread safety: SmarTest will throw an error message if an API used in SMC_backgroundProcessing() is not thread-safe1)

Example

RF and DC
virtual void run()
{
    RDI_INIT();

    ON_FIRST_INVOCATION_BEGIN();
    {
        rdi.hiddenUpload(TA::ALL);

        RDI_BEGIN();
        {
            rdi.rfm("id1").pin("A").signal(TA::MOD_OUT).freq(1e9).bw(2e6).execute();
            rdi.dc("id2").pin("A").iForce(1 mA).vMeas().execute();
            rdi.dc("id3").pin("B").vForce(1 V).iMeas().average(5).execute();
        }
        RDI_END();
    }
    ON_FIRST_INVOCATION_END();

    SMC_ARM();

    return;
}

public:

void SMC_backgroundProcessing()
{
    double pwr = rdi.id("id1").getPower();
    double r1 = rdi.id("id2").getValue();
    double r2 = rdi.id("id3").getValue();
}
Digitizer and digital capture
virtual void run()
{
    RDI_INIT();

    ON_FIRST_INVOCATION_BEGIN();
    {
        rdi.hiddenUpload(TA::ALL);

        RDI_BEGIN();
        {
            rdi.dgt("id1").pin("A").samples(1024).filter(1e6).FS(20e6).execute();
            rdi.digCap("id2").pin("A").samples(1024).execute();
        }
        RDI_END();
    }
    ON_FIRST_INVOCATION_END();

    SMC_ARM();

    return;
}

public:

void SMC_backgroundProcessing() 
{
    ARRAY_D wave1 = rdi.id("id1").getWaveform(); 
    ARRAY_I bits  = rdi.id("id2").getVectorBit(); 
}
Error map
virtual void run()
{
    RDI_INIT();

    ON_FIRST_INVOCATION_BEGIN();
    {
        rdi.hiddenUpload(TA::ALL); // Include the EMAP mode

        RDI_BEGIN();
        {
            rdi.smartVec("rb").pin("A").readBit(100).execute();
            rdi.emap("fc").label("bbb").pin("A").failCyc().execute();
        }
        RDI_END();
    }
    ON_FIRST_INVOCATION_END();

    SMC_ARM();

    return;
}

public:

void SMC_backgroundProcessing()
{
    rdi.id("rb").getReadBit();
    rdi.id("fc").getFailCyc();
}
