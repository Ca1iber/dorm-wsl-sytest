IS_TEST_RUNNING()

Returns TRUE if any analog or digital sequencer is running, else FALSE is returned.

For multi-site testing, only the sequencers of the active sites are evaluated.

The IS_TEST_RUNNING() function can be used to check if any AWG sequencers are still running after the test has been executed. The context can be used as parameter if related to a specific sequencer context.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Execute.h.

Syntax

Boolean IS_TEST_RUNNING();
Boolean IS_TEST_RUNNING(const STRING& context);

List of parameters

There are no parameters.

Example

This example shows how to write the Boolean return value of IS_TEST_RUNNING() into the variable RunState.

Boolean RunState;

RunState = IS_TEST_RUNNING();

Functional changes

  1. Introduced before SmarTest 6.3.2
