Topic 16264

Shutting down SmarTest

This topic explains how to shut down SmarTest in engineering mode.

Procedure

  1. To shut down the SmarTest Work Center, from the menu click File > Exit.

    A confirmation window opens.

  2. To confirm the exit click OK.
    • If all data are saved, SmarTest shuts down.
    • If you changed any setup data, the system displays the Exit dialog. The Exit dialog lists any processes which may still be running, and any setup and resource files, which you did not save yet.
  3. If you want to save any of the changed setup data, click Cancel.
  4. To continue the exit, click OK. In this case any changes to the listed files will be lost.

    If SmarTest hangs up, on the main menu (Red Hat button on the task bar), click Red Hat button and select Advantest > kill SmarTest.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.0: Enhanced exit sequence.
