Model file reference (model/legacy)

This section describes the model file structure and associated syntax for the legacy type model file. This model file is used only with the V93000 Smart Scale systems.

Legacy model file structure:

GLOBAL
Specifies what kind of system is used and what features are available system-wide.
POGOCABLING
Specifies the mapping between the physical position of the channel cards and the pogo blocks of the DUT interface.
IOCHANNEL
Specifies the master configuration for the test system.
ETC
Defines several general parameters.
DPS
Specifies each available DPS card, including DC Scale cards.
DMM (Digital Multimeter)
Specifies optionally installed external digital multimeters.

Example

The following is an example of a model file:

   testhead = TH_8CC
   dut_interface = SOC
   device_maintenance = OFF
   multiport = ON
   noise_figure = OFF
   memory_stacker = OFF
   multisite = ON

   timing_bundle = w256-d8-r8
   psrf_pa_library = OFF
   xpressdata = OFF
   S&S_value_package = ON
   protocol_aware = ON

   utility_lines = 256, type = sequencer_controlled, pogo_size = 32
