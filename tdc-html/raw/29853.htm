WAIT_TIME

This API waits for execution of the next statement during the time specified by the parameter.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Execute.h.

Syntax

WAIT_TIME(DOUBLE time = 0);
Parameter

I/O

Parameter

Description / Range

I

time

Wait time

Unit: s

Resolution: 1 µs

The accuracy of this parameter is influenced by the overhead time of the operating system.

Example

WAIT_TIME(100 ms);

This API waits the next statement execution for 100 ms.
