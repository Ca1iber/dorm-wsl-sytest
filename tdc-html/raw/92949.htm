DSP_RF_PHASE_NOISE()

This function is used to measure phase noise. It supports two techniques of reducing the noise: either be conventional averaging (one sourceData array) or using cross correlation (two sourceData arrays, see References for background information).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_RF_PHASE_NOISE(const ARRAY_COMPLEX  & sourceData,
                        const ARRAY_D        & measParams,
                        ARRAY_D        & offsetResults_dBc_Hz);
DSP_RF_PHASE_NOISE(const ARRAY_COMPLEX & sourceData,
                        const ARRAY_D       & measParams,
                        ARRAY_D       & offsetResults_dBc_Hz,
                        ARRAY_D       & spectrumData);   
DSP_RF_PHASE_NOISE(const ARRAY_COMPLEX  & sourceData,
                        const ARRAY_COMPLEX  & sourceData2,
                        const ARRAY_D        & measParams,
                        const ARRAY_D        & measParams2,
                        ARRAY_D              & offsetResults_dBc_Hz);
DSP_RF_PHASE_NOISE(const ARRAY_COMPLEX & sourceData,
                        const ARRAY_COMPLEX & sourceData2,
                        const ARRAY_D       & measParams,
                        const ARRAY_D       & measParams2,
                        ARRAY_D             & offsetResults_dBc_Hz,
                        ARRAY_D             & spectrumData);
Parameters

I/O

Parameter

Notes

I

sourceData

A complex array representing captured data.

I

sourceData2

A complex array representing captured data from the second card.

 

I

measParams

An array of doubles which contains information about the properties of the measurement definition, together with frequency-dependent calibration data.

I

measParams2

An array of doubles which contains information about the properties of the measurement definition, together with frequency-dependent calibration data.

O

offsetResults_dBc_Hz

An ARRAY_D of n results (in dBc/Hz), where n is the number of offsets.

O

spectrumData

An ARRAY_D (array of doubles) representing the source data (in dBc/Hz) in the frequency domain.

Examples

Example 1

ARRAY_COMPLEX cData = MEAS_DEF("myPhaseNoiseMeas").getComplexWaveform(); 
ARRAY_D measParams = MEAS_DEF().getParameters(1);
INT numOffsets = (INT)measParams[TM::PN_NUM_OFFSETS];
ARRAY_D offsetPower(numOffsets);
DSP_RF_PHASE_NOISE(cData, measParams, offsetPower);
//The results (for Sequence Block 1, as indicated by the MEAS_DEF().getParameters(1) function call) could be printed to the report window as follows: 
for(int i = 0; i < numOffsets; i++)
   cout << "Offset " << i+1 << " measured " << offsetPower[i] << 
   " dBm/Hz" << endl;

Example 2 (with Cross Correlation)

ARRAY_COMPLEX cData1 = MEAS_DEF("myPhaseNoiseMeas1").getComplexWaveform();
ARRAY_COMPLEX cData2 = MEAS_DEF("myPhaseNoiseMeas2").getComplexWaveform();
ARRAY_D measParams1 = MEAS_DEF("myPhaseNoiseMeas1").getParameters();
ARRAY_D measParams2 = MEAS_DEF("myPhaseNoiseMeas2").getParameters();
INT numOffsets = (INT)measParams[TM::PN_NUM_OFFSETS];
ARRAY_D offsetPower(numOffsets);
DSP_RF_PHASE_NOISE(cData1, cData2, measParams1, measParams2, offsetPower);

//The results (for Sequence Block 1, as indicated by the MEAS_DEF().getParameters(1) function call) could be printed to the report window as follows:

for(int i = 0; i < numOffsets; i++)
   cout << "Offset " << i+1 << " measured " << offsetPower[i] <<
   " dBm/Hz" << endl;
