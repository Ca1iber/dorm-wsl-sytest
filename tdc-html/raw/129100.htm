Automatic Map Converter operating principles

The Automatic Map Converter compiles the map converter library based on the MTL device architecture file and a device property file that you provide.

To use the converter, you call it from the command line with the location of the device property file (which itself contains the location of the MTL pattern file).

The Automatic Map Converter then calculates from the geometry information contained in these files the conversions necessary to translate between physical, logical, and geometric addresses. If a redundancyAnalysis element is specified in the device property file, conversions for translating between physical and layout addresses are also created.

Note The created phys_to_layout function covers the basic structure of the specified device. You may need to adapt the function to any irregular features of the layout of your device. This adaptation is performed in the generated C source code (see below).

It then creates a C source file and compiles a library from it. The compilation of the library can be suppressed; if one is compiled, it can be a release or a debug library.

Prerequisites

The Automatic Map Converter can be used only if the device meets certain prerequisites:

  • The column and row addresses (for example, within a bank) must be contiguous.

    Column and row addresses must continuously increase or decrease within a bank or DQ area - there must be no gaps or gradient changes.

    If this is not the case, a transformation has to be applied to the addresses first to make them linear. This transformation has to be specified through the scrambling expression in the Device architecture file.

  • Banks and DQs cannot be split into subentities.

    The address spaces of each bank or DQ must be contiguous as well.

  • The banks and DQs must form some kind of addressable matrix.
  • If device access are executed in bursts with an offset that is not zero, the data reordering that may occur as a consequence must be compensated for to ensure that the Automatic Map Converter calculates the correct addresses.

    We recommend using MTL arrays to compensate for burst reordering in your pattern.
