The <smartVec> element

This element stores test results retrieved with functions of the SmartRDI's smartVec() class.

The <smartVec> element stores test results in its readData, readBit, matchCount and matchPassFail attributes. The readData attribute saves test results returned by a getReadData() function; the readBit attribute saves test results returned by a getReadBit() function; the matchCount attribute saves test results returned by a getMatchCount() function; the matchPassFail attribute saves test results returned by a getMatchPassFail() function. Results retrieved with a Smart Vector's getFailCount(), getFFC() or getFailCyc() is treated the same as the results returned by using the emap() class and as a result saved in the <emap> element.

Examples

Below is an example of the <smartVec> element and its corresponding SmartRDI code block.
<offlineResultEmulation>
  <id name = "smv1">
    <pin name = "DATA1">
      <smartVec readData = "34,37"/>   </pin>
    <pin name = "DATA2">
      <smartVec readBit = "./bits.txt"/>   </pin>
  </id>
  <id name = "smv2">
    <pin name = "DATA3">
      <smartVec matchCount = "5"/>
      <smartVec matchPassFail = "1"/>
    </pin>
  </id> 
</offlineResultEmulation>
RDI_BEGIN();
  rdi.smartVec("smv1").pin("DATA1")
     .readData(8,2).readData(8,12)
     .pin("DATA2").readBit(8,2)
     .readBit(8,12).execute();
  rdi.smartVec("smv2").pin("DATA3")
    .matchData(0x20,8,8,5).matchCycle(5)
    .readMatchCount("DATA3")
    .readMatchPassFail("DATA3").execute();
  ...
RDI_END();
...
rdi.id("smv1").getReadData("DATA1");// {34,37}
rdi.id("smv1").getReadBit("DATA2"); // {1,0,0,1,0,1}
rdi.id("smv2").getMatchCount();     // 5
rdi.id("smv2").getMatchPassFail();  // 1

Below is another example of the <smartVec> element and its corresponding SmartRDI code block.

An ORE file containing <smartVec> elements:

<id name = "smv1">
  <pin name = "DATA1">
<smartVec matchCount= "5" />
<smartVec matchPassFail= "1" />
  </pin>
</id> 
<id name = "smv2">  
  <pin name = "DATA2">
    <emap failCyc = "1" />
    <emap failCyc = "3,5" />
    <emap failCyc = "8" to= "12" />
  </pin>
</id>
The corresponding SmartRDI code block from which the ORE gets the result:
RDI_BEGIN();
  rdi.smartVec("smv1").pin("DATA1")
     .matchData(0x20,8,8,5).matchCycle(5)
     .readMatchCount("DATA2")
     .readMatchPassFail("DATA2").execute();
  rdi.smartVec("smv2").pin("DATA2").FFC(2)
     .failCount(2,9).failCyc(2,9).execute();
RDI_END();

rdi.id("smv1").getMatchCount();    // 5
rdi.id("smv1").getMatchPassFail(); // 1
rdi.id("smv2").getFFC();           // 3
rdi.id("smv2").getFailCyc();       // {3,5,8,9,10}
rdi.id("smv2").getFailCount();     // 5

More attributes and syntax can be used in SmartRDI 7.5.2

An ORE result example: 
<id name = "smv2">
  <pin name = "DATA2">
     <emap FFC = "3"/>
     <emap failCount = "4"/>
     <emap failCyc = "3,5,6,8"/>
     <emap multiFFC = "3,5,6"/>
  </pin>
</id>
The corresponding SmartRDI code block from which the ORE gets the result:
RDI_BEGIN();
  rdi.smartVec("smv2").label("label1").pin("DATA2")
                      .FFC(2).failCyc(2,9).multiFFC(2,3)
                      .failCount(2,9).execute();
RDI_END();

rdi.id("smv2").getFFC();       // 3
rdi.id("smv2").getFailCyc();   // {3,5,6,8}
rdi.id("smv2").getFailCount(); // 4
rdi.id("smv2").getMultiFFC();  // {3,5,6}
