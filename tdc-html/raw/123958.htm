Configuring Migration Profile

About this task

During device migration, the migration profile will determine how the migration cheatsheet will be used to migrate specific devices.

Before you begin

Ensure that SmarTest is running and a cheat sheet is open.

Procedure

  1. Click Click to perform to open a migration profile configuration wizard.
  2. Select Original Software Version, default is 6.5.X.
  3. Select current Hardware Environment, default is P1600.
  4. Select Current Software Version, default is 7.1.0.
  5. Select Current Hardware Environment, default is PS1600.
  6. Select ScanType: Testflow or Test Program.
  7. Select Scan File, the specific migration file.
  8. Select Conversion Mode, you can choose to backup the original resource while using conversion tool.
  9. Click Finish

Results

Your Profile is ready.

What to do next

Screen you testflow or Test Program.
