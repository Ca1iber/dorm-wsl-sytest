Topic 16902

Physical drive edge action (physical_drive_edge_action)

One of N, F0N, FN0, FNZ, F00, F0Z, F10, F1Z, . (period), !Z, Z, 0 or 1.

N

No action.

F0N

Drive 0, no tri-state action.

FN0

No drive action, tri-state off.

FNZ

No drive action, tri-state on.

F00

Drive 0, tri-state off.

F0Z

Drive 0, tri-state on.

F10

Drive 1, tri-state off.

F1Z

Drive 1, tri-state on.

.

Can be used instead of N.

!Z

Can be used instead of FN0.

Z

Can be used instead of FNZ.

0

Can be used instead of F00.

1

Can be used instead of F10.

Functional changes

  1. Introduced before SmarTest 6.3.2
