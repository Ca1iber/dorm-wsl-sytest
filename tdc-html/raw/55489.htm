Topic 55489

Creating a pin group

You can create a pin group of fixed type or expression-based type.

Before you begin

You have defined pins.

Procedure

  1. In the Test Program Explorer view, right-click Groups and select New.

    The New Group window opens.

  2. Select the group type:
    • Fixed Group (default)
    • Expression Based Group

    See Defining pin groups for a description of the group types.

  3. In the New Group, type the group name.
  4. Click OK.

Results

The Group Editor for the new group opens. The Group Members area is blank.

What to do next

Edit the group.
