GET_TESTSUITE_FLAG

Retrieves the current value of the specified test suite flag.

Note Do not use this in a SMC_backgroundProcessing() method.

Available test suite flag names are listed below. For details of the test suite flags, see Test suite flags.

  • bypass
  • set_pass
  • set_fail
  • site_match
  • hold
  • hold_on_fail
  • output_on_pass
  • output_on_fail
  • value_on_pass
  • value_on_fail
  • per_pin_on_pass
  • per_pin_on_fail
  • mx_waves_enable
  • fail_per_label
  • ffc_enable
  • ffc_on_fail
  • ffv_enable
  • frg_enable
  • frg_single_shot

The following are read-only flags which cannot be set by using the SET_TESTSUITE_FLAG API.

  • force_serial
  • executed
  • passed

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

void GET_TESTSUITE_FLAG(const STRING& tsname, const STRING& flag, INT *value);
Parameters

I/O

Parameter

Description / Range

I

tsname

A testsuite name

I

flag

A testsuite flag name.

O

value

The current value of the specified flag is returned to this variable.

Example

INT hof_state;
...
...
GET_TESTSUITE_FLAG("SampleTest", "hold_on_fail", &hof_state);

The GET_TESTSUITE_FLAG API retrieves the state of the hold_on_fail flag of the SampleTest testsuite.
