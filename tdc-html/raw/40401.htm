Topic 40401

Loading a Tone Definition

Clicking the Load Tone Setup button at the bottom of the dialog window opens a browser as shown below that lets you load a tone definition saved before.

After you load a tone definition, if you use the phase offset values saved in the loaded file, select the User defined phase values check button in the Phase Algorithm Setup dialog window.

Note The Multitone Setup tool uses temporary files in the "waveform" subdirectory of the device to store tone definitions before the calculation of the waveform (file .MULTITONE_SETUP) and after the calculation (file .MULTITONE_RESULT_TEXT). The latter one also contains the calculated PRR (Peak-to-RMS-Ratio) and phase shifts. If desired, these files may also be loaded.
