Fast Sync setup with SmartRDI

Subtopics

  1. fastSyncOff()
  2. fastSyncOn()
  3. fastSyncPortNum()

Fast Sync enables the local synchronization of the test processor. For more information, see Fast Sync.

SmartRDI provides the following functions to set up the Fast Sync feature in the code‑based mode:

fastSyncOn(), fastSyncOff(), and fastSyncPortNum().
