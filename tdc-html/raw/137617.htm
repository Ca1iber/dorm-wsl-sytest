Recipe for 2 Volt, 20 Amp step application

Example 2

Default capacitors for a single UHC4 / UHC4T supply with 2 Volt and 20 Amp transients (Max Current Transient = 100 %) with 5% Voltage ripple.

Steps 1 to 3 provide

  • max ESR = 2.5 mΩ (Milli-Ohm),
  • Min Bulk C = 1453 µF, and
  • Max Ceramics = 147 µF
Note The design is scalable. For higher current applications, multiply the quantities of each capacitor type by the scaling factor. Similarly, for ganged higher current supply channels, multiply the quantities of each capacitor type by the number of ganged UHC4 supplies.
Note To be able to place additional capacitors during fine tuning, add several differently sized un-populated capacitor pad banks in the area around the DUT.
