Topic 112046

How to get notified with a SmarTest event

This topic introduces how to handle the event from SmarTest in a HVM API client.

About this task

Handling the event in the client includes creating and registering an event handler for a particular event and starting an HVMAPI internal event loop. The event loop will execute the particular event handler when the corresponding event occurs.

Before you begin

Make sure you are using SmarTest 6.2 or later.

Procedure

  1. Define the event handler function to handle a particular event. In this function, define the actions that need to be taken when the particular event occurs. You can use the code template below as a reference. 
    using namespace std;
using namespace ::xoc::hvmapi;
void handlerforEvent1(const string &evName, const ParamList &evParams, 
                       unsigned long sec, long usec, const string &sessionId)
{
  if ( evName == "event_category" ) //event_category can be EXECUTION or SESSION.
  {
    const string &execState = params["param1"];
    if ( execState == "state_1" ) 
    {
      const string & testflowName = params["param2"];
      
      //other normal operation here
      ...
    } 
    else 

    {
      cout<< "Internal Error, the execution state should be state_1" <<endl;
    }
  } 
  else 
  {
    cout<< "Internal Error, the event name should be event_category" <<endl;
  }
}
  2. Register the event handler in the main() function with the signature addEventhandler. You can use the following code template as a reference. 
    ParamList evProperty;  //the variable holding the event parameters.
string sid;
evProperty["param1"] = "value_for_param1";
sid = sSessionId; //sSessionId is the variable containing the exact session ID to work with
addEventListener(handlerforEvent1, "EXECUTION", evProperty, sid);
  3. In the main() function, start the event loop to execute the event handler as below: 
    xoc::hvmapi::eventLoop();
  4. Exit the event loop when necessary. You can refer to the code template below. 
    void myGlobalHandler (const string &evName, 
                      const ParamList &evParams, 
                      unsigned long sec, long usec, 
                      const string &sessionId)
{
  if ( evName == "SESSION" ) 
  {
    const string &ssnState = evParams["SESSION_STATE"];
    if ( ssnState == "SMARTEST_SESSION_TERMINATED" ) 
    {
      eventLoopExit(); 
      //this will terminate the HVMAPI internal execution thread
    }
  }
}

Results

The event handler is registered and will be executed when the specified event occurs.

Example

The following example defines the event handler for the event TESTFLOW_EXEC_COMPLETED.

using namespace std;
using namespace ::xoc::hvmapi;
void handlerTestflowExecCompleted(const string &evName, 
                                  const ParamList &evParams, 
                                  unsigned long sec, 
                                  long usec, 
                                  const string &sessionId)
{
  if ( evName == "EXECUTION" )
  {
    const string &execState = evParams["EXECUTION_STATE"];
    if ( execState == "TESTFLOW_EXEC_COMPLETED" )
    {
      
      //other normal operations here
      ...
    }
    else

    {
      cout <<"Internal Error, the execution state should be TESTFLOW_EXEC_COMPLETED" <<endl;
    }
  }
  else
  {
    cout <<"Internal Error, the event name should be EXECUTION" <<endl;
  }
}

In the main() function, you need to register the event handler as below:

ParamList evProperty;
string sid = "sessionId"; // the exact session ID to work with, such as ":13"
evProperty["EXECUTION_STATE"] = "TESTFLOW_EXEC_COMPLETED";
addEventListener(handlerTestflowExecCompleted,
                 "EXECUTION", evProperty, sid);
