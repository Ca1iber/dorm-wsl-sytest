Defining a memory test setup

  2. Create pin configuration
  3. Defining pin groups
  4. Create levels
  5. Create timing

This section describes how to use the various software tools to define a memory test.

You begin the whole memory test process by functionally describing your device. This is done using the normal setup tools, where you tell the software what pins do what, the levels to expect on each, and the relative timing on the pins. You then describe how your memory test relates to this "general" setup - for example, the pins of your port, the way the read/write cycles work, etc. This is done in the dedicated memory setup tools.

Although this chapter deals mainly with the dedicated memory test tools, bear in mind that the normal setup tools - especially the Timing Setup - do affect your memory test.
