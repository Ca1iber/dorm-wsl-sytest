Automatic Map Converter

Subtopics

  1. Automatic Map Converter operating principles
  2. Creating a map converter library with the Automatic Map Converter
  3. Device property file

The Automatic Map Converter creates the address converter library required for mapping between physical and geometrical memory addresses based on the MTL device setup file and device-specific property file.

It produces both C source code and a ready-to-use compiled library.

The Automatic Map Converter can create a basic phys_to_layout function for use in redundancy analysis. The function may require adaption to peculiarities of the DUT.

Functional changes

  1. Introduced in MTP 3.1.3
  2. MTP 3.1.4: Redundancy analysis is now supported.
