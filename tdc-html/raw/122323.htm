CCTsetWaitTimeBeforeStart

This function sets the time to wait before sequencer start.

In serial mode, the waiting time before sequencer start is the specified value.

In concurrent mode, the waiting time before sequencer start is the maximum waiting time among all the test suites in the CCF block.

This function is usually used in the init() function but not used in the other functions of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

void CCTsetWaitTimeBeforeStart(const double timeInSec);
Parameter

timeInSec

The time to wait in [s]. Default is 0.

Example

virtual void init() 
{
//...
CCTsetExecMode(EXM_EXECUTE_TEST);
CCTsetWaitTimeBeforeStart(10 ms);
 }

In this example, the waiting time before sequencer start is set to 10 ms.

Functional changes

  1. Introduced in SmarTest 6.5.4
