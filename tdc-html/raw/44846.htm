The parameters are passed to the script in the conventional Unix manner. The parameter count is available through the variable $#. Parameters are passed to the script exactly as written in the Command Set call and are available in the order specified (left to right).

The following line shows an example:

EXEC_INP_CALL(init one two three);

The script executed is init, and the parameters passed are one, two, and three as follows:

$* = "one two three" where

$1 = "one"

$2 = "two"

$3 = "three"

Note that $# is 3.

To start a script in background mode, add an & to the last parameter of the Command Set call, as shown in the following example.

EXEC_INP_CALL(init one two three &);
