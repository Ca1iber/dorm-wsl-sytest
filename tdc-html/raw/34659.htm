TestSuiteEndEventType

An event of this type is logged when a test suite execution has terminated. The attributes listed below will be logged, once for each site that was involved in the test suite execution.

Attributes

  • SiteIdAttrType

    Holds the ID of one site for which the test suite has terminated.

  • PassFailResultAttrType

    Holds the pass or fail result of that site, or indicates if the test suite was bypassed.

  • TimeStampAttrType

    Holds the time when the execution of the test suite was started.

Functional changes

  1. Introduced before SmarTest 6.3.2
