Demodulation in the Signal Analyzer

Subtopics

  1. Accessing the demodulation tool
  2. Specifying waveform and standard
  3. Editing input parameters
  4. Executing demodulation
  5. Verifying results
  6. Configuring parameter list

The demodulation tool in the Signal Analyzer offers a graphical interface for demodulating RF waveforms. With this tool you can adjust input parameters, execute demodulation and visualize the results.

Note The Demodulation tool relies on the demodulation library. Demodulation library revision can be found in Help menu About in Signal Analyzer.
