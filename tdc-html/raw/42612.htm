TPI procedures for multisite testing

Subtopics

  1. Multi-site access functions
  2. Get Connect State

The Test Programming Interface (TPI) library provides calls to control the state of testing sites. Two types of functions are available for site-specific data:

  • Multisite access functions
  • GetConnectState function

Functional changes

  1. Introduced before SmarTest 6.3.2
