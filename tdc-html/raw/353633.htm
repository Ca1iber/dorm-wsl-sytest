perSiteVal()

Specifies a value or waveform per site. The value or waveform is only downloaded in the first run and will not be updated for each execution.

This API supports the following commands:
  • PPMU: iForce(), vForce(), and waveform()
  • DC Scale: iForce(), vForce(), iClamp(), and waveform()

Syntax

perSiteVal(string,ARRAY_D);
perSiteVal(string,vector<anaWaveform>);

Examples

Example 1

ARRAY_D rtv_arr(4);
rtv_arr.init(0.0);
rtv_arr[0]=1.0; rtv_arr[1]=1.1; rtv_arr[2]=1.2; rtv_arr[3]=1.3;
rdi.perSiteVal("psVal",rtv_arr);

RDI_BEGIN();
  rdi.dc().pin("A").vForce("psVal").execute();
RDI_END();

Example 2

ARRAY_I sites;
int siteNum = GET_CONFIGURED_SITES(sites);
vector<anaWaveform> siteWav(siteNum); // Per site waveform array for multi-site testing.
rdi.perSiteVal("psWave",siteWav); // Per site waveform matches ID.
 
RDI_BEGIN();
  // The waveform is only downloaded in the 1st run
  rdi.port("ptPin").dc().pin("pinA").vForce().waveform("psWave").FS(10 KHz).execute();
RDI_END();
