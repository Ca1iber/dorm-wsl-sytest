getWaveform()

Retrieves the raw waveform.

Syntax

ARRAY_D& getWaveform(const string& pin);
Parameter

Parameter

Description

pin

The pin to query.

Return Value

An ARRAY_D object containing the raw waveform is returned.

Example

const ARRAY_D &Result = rdi.id("cap").getWaveform("DATA_1");

Related information

ARRAY_D

Functional changes

  1. Introduced in SmartRDI 2.1.0
