Built-in functions

The Testflow Editor provides a number of built-in functions you can use to access internal data during testflow execution like, for example, test suite results. You can use these functions in the flow control nodes for more sophisticated testflow control.

The following built-in functions allow you to retrieve information on the execution of individual test suites.

tf_result(<test_suite_name>, <result_index>)

Access the result array of the given test suite and return the value of that array with the index result_index.

For example, tf_result(hold_time,0) returns the minimum measured hold time.

pass(<test_suite_name>)

Return 1, if the test suite has passed, otherwise return 0.

fail(<test_suite_name>)

Return 1, if the test suite has failed, otherwise return 0.

has_run(<test_suite_name>)

Return 1, if the test suite has already been executed during the current testflow execution, otherwise return 0.

has_not_run(<test_suite_name>)

Return 1, if the test suite has not been executed during the current testflow execution, otherwise return 0.

The following built-in functions allow you to retrieve further information on the current testflow:

lsus()

Return the number of level sets used.

dsus()

Return the number of DPS equation sets used.

tsus(waveset_no)

Return the number of timing sets used.

waveset_no may also be an expression.

wsus()

Return the number of waveform sets used.

burstfirst(burstlabel)

Return a string that is the first label of burstlabel.

See Identifying fail labels in a burst.

burstnext(burstlabel)

Return a string that is the next label of burstlabel in the current burst sequence, or an empty string if burstlabel is the last label in the sequence.

See Identifying fail labels in a burst.

spst_timing(eqst_no, spst_no)

Return 1 if the equation set number eqst_no and the spec set number spst_no define a valid combination in the timing equation system, otherwise return 0.

eqst_no and spst_no may also be expressions.

spst_level(eqst_no, spst_no)

Return 1 if the equation set number eqst_no and the spec set number spst_no define a valid combination in the level equation system, otherwise return 0.

eqst_no and spst_no may also be expressions.

svlr_timing(eqst_no, spst_no, "variable_name")

Return the value of the timing equation variable specified by the equation set number eqst_no, the spec set number spst_no and variable_name.

svlr_timing("specification", "variable_name@port")

Return the value of the timing equation variable specified by the multiport specification specification for the port port.

svlr_level(eqst_no, spst_no, "variable_name")

Return the value of the level equation variable specified by the equation set number eqst_no, the spec set number spst_no and variable_name.

Built-in functions are used in much the same way as variables in Flow control nodes.

Note Built-in functions must be specified using lower case characters.

Functional changes
