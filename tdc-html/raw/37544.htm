Topic 37544

Calling ait

Subtopics

  1. ait command line parameters

The ait tool is located in /opt/93000/aif/ait/bin. It is called from the command line by entering ait with the appropriate parameters. These parameters are described in the following section.

ait prints its messages to stdout, while d2w, which is called by ait, prints them to stderr. If you want to redirect all messages into one file, call ait, for example, as follows:

ait <parameters> >time.log 2>&1

This will collect all messages in the file time.log.
