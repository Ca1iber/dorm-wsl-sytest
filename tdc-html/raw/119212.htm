Using the Flow Sequence Editor

The flow sequence editor displays a graphic view of the testflow. For a long testflow, you can easily browse the flow within the Outline view.

  • Inserting a node
  • Deleting nodes

    To delete the Run and Branch node and Flow control nodes, wide select them.

  • Cutting, copying and pasting nodes
  • Moving nodes

    To move the Run and Branch node and Flow control nodes, wide select them.

  • Cloning nodes
  • Grouping nodes

    To group the Run and Branch node and Flow control nodes, wide select them.

Click a node to edit the node's properties in the Properties view.
