Topic 146814

average()

Specifies the number of samples used to do the averaging when the measurement instrument is board ADC. The result of the measurement is averaged.

For accuracy considerations, refer to member function number of samples() of API PPMU_PIN_MEASURE.

Syntax

average(int iSample);
List of parameters

Parameter

Description

iSample

The number of samples.

The default value is 1.

Starting from SmartRDI 7.5.3:

  • The default average value for vMeas is changed to 16.
  • The default average value for iMeas is changeable, depending on the value specified by iRange.
    Note These changes may impact compatibility in some cases.

    The setting time after measurement is based on the average value, so the setting time will be changed too.

Examples

rdi.dc("multi1").pin("PinA").vMeas().average(20).valueMode(TA::BADC).execute();

The default average value is 16 for vMeas() and changeable for iMeas() in SmartRDI 7.5.3.

RDI_BEGIN();
  rdi.dc().pin("dig1").vForce(1).iMeas().iRange(2 mA).execute(); // average = 4 
  rdi.dc().pin("dig2").iForce(1 uA).vMeas().execute(); // average = 16 
RDI_END();

Related information

PPMU_PIN_MEASURE

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 7.5.3: The default average values for PPMU and BADC are changed.
