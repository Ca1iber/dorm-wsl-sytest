Loading bit fail maps automatically

The BFM Viewer can load bit fail maps automatically. If this mode is active, it is notified by the Result Server when new bit fail maps are stored on disk and loads those bit fail maps without requiring user intervention.

Before you begin

You cannot manually load bit fail maps if this mode is active.

You may want to configure the BFM Viewer; however, this is optional except for setting the paths, which should have happened when you started the BFM Viewer.

Procedure

To make the BFM Viewer load bit fails maps automatically upon notification from the Result Server, use either of these methods:
  • Enable the Autoload Mode option in the Extras menu.
  • Start the BFM Viewer from the command line using the --autoload option.

Results

  • Any existing bit fail maps in layers A and B are cleared. (Bit fail maps in layers C through G remain unaffected.)
  • The bit fail map viewer assigns any new bit fail map that it is informed about by the Result Server to layers A and B according to these principles:
    • "Fail on 0" bit fail maps are assigned to layer A.
    • "Fail on 1" bit fail maps are assigned to layer B.
    • Combined bit fail maps are assigned to layer A.
  • As long as the Autoload mode is active, you can neither manually assign bit fail maps to layers nor save or restore sessions.
