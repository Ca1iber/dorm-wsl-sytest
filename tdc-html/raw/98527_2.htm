DCRT, DCRT? - (Digital Compare Result Target)

The DCRT command defines where the detailed error map data is to be stored, within the test processor or in the external memory (RDRAM). The performance is better in the former case, but the external memory provides much more space. The external memory is especially useful when you set the result granularity to 8 with DCRM. The DCRT? query returns the current settings.

DCRT sets the location of the detailed error map on the port level. If the timing ports and vector ports of a multi-port setup are not identical, it is the vector ports that determine the error map location.

If you select the external memory as the location of the error map, it will occupy all the memory space that is not reserved for other kinds of data. You can query with DCRS? how many cycles can currently be stored in the error map.

DCRT

DCRT {target},{(port_list)}

DCRT?

DCRT? [answer_type,] {(port_list)}

returns:

DCRT {target},{(port)}

Parameters

target

 

Specifies the target area for the error map. Possible values are:

TP

The error map data is stored within the test processor. This is the default.

RAM

The error map data is stored in the external memory as the vector memory.

Note that if you select the external memory as the location of the detailed error map on a P/Ce system, the parallel vector areas must be located in the Sequencer Memory.

port_list
Specifies the ports for which the target is to be defined:
  • If you specify @@ (all ports, multi-port label), the DCRT command will set the specified target area for all configured ports.
  • If you specify @ (all pins, non-multiport label), the DCRT command will set the specified target area for the default port (all pins).
  • If you specify the name of a specific port (multi-port label), the DCRT command will set the specified target area for that port only.

answer_type

This query parameter specifies whether the current configuration or the configuration of the last executed test is to be returned. Possible values are:

 

CONF

The current configuration is returned. This is the default.

 

EXEC

The configuration of the last executed test is returned.

Application

Error Map.

Examples

Querying the location of the error map for all ports and setting it for specific ones (multi-port label)

This example queries the location of the error map for all ports. Then, it sets the location of the error map in the test processor for port P2, and in RDRAM for P1:

DCRT? (@@) // Note: this is equivalent to specifying DCRT? CONF,(@@)
DCRT RAM,(P1) // Set location of error map for port P1 in RDRAM
DCRT TP,(P2) // Set location of error map for port P2 in Test Processor

Querying and setting the location of the result map for the default port (non multi-port label)

To query or set the location of the error map for the default port, you need to specify @ as the port_list of the DCRT? and DCRT commands, respectively:

DCRT? (@) // Query location of error map for the default port
DCRT TP,(@) // Set location of error map for the default port to Test Processor
