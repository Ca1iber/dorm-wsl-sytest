DDEF, DDEF? - Data DEFinition

Subtopics

  1. Create
  2. Set
  3. Remove
  4. Query
  5. Equation Definition Type
  6. Values Definition Type
  7. Error

The DDEF (Data DEFinition) command is used to create a data object (usually a List), make settings to that object, or to remove that object.

The DDEF? query returns information about the specific subcommand performed by DDEF.

The List module consists of two sub-modules, the Frequency and Power List module and the Hex32 List module.

For the Frequency and Power List module, regular expressions are used to represent the elements, for example,

0.2, -0.3, 1.50e9, and so on.

For the Hex32 List module, the elements are written in the form of 0xHHHHHHHH, where H is a Hexadecimal number (1....F). Each hexadecimal is 4 bits.

Basically, there are four types of sub-commands: creating, setting, deleting, and querying. The syntax and purpose of these commands are similar for all lists. However, the keywords used are different depending on the type of list with which you are working.

There are variations of the syntax, based on the subcommands for DDEF, DDEF?. These will be described in the following sections:

  • Create
  • Set
  • Remove
  • Query
