Topic 129118

Moving or copying pattern files

Moving or copying pattern files helps to organize and manage pattern files within a folder structure. The function is available only in pattern master file setups.

About this task

The Move function allows to copy or move pattern files within a folder structure. You can use either the shortcut menu (move or copy) or modify the Location cell (copy only) in the Pattern Explorer. The pattern master file will be automatically updated when saving it.

Before you begin

You should have already a folder structure to organize your pattern files within. Otherwise you are limited to the Move Pattern File dialog, which allows to create new folders.

You are also limited to the Move Pattern File dialog and its "copy" option (see below), if another pattern master file refers to the pattern file you are "moving".

Procedures

To move or copy a pattern file using the shortcut menu:

  1. In the Pattern Explorer right-click a pattern or port burst and select Move. The Move Pattern File dialog pops up.
  2. Specify the target folder. Content assist (Ctrl + spacebar) lists the valid folder options. To create a new folder click Browse > Create Folder.
  3. Decide to copy or move the pattern file.
    • To copy files select the "Keep a copy of the file(s) at its original location" option. This is the default option. Other pattern master files that may reference the file will remain valid.
    • To move files select the "Delete the file(s) at its original location" option. In this case make sure that no other pattern master files are affected.
  4. Click OK. The pattern file is copied or moved and the current pattern master file will be updated accordingly when saved.

To copy a pattern file by modifying the Location cell:

  1. In the Pattern Explorer highlight the Location cell of the pattern or port burst to be copied. You may need to scroll to the right to see the Location cells.
  2. Type the new location (path and file name), or press Ctrl+Spacebar to activate a content assist and a selection button.
    • If you specify a new pattern file, you create a copy of the file at the new location.
    • If you choose an existing pattern file, the pattern will be merged to that file.

Results

The specified pattern file is moved (or copied) to its target location. The pattern master file receives an asterisk (*) to indicate that the pattern setup was changed. The path in the pattern master file will be updated automatically when the file is saved.
