Exporting the bookmarks to a file

You can export the bookmarks to a file for later use.

Before you begin

You have set bookmarks to the testsuites.

Procedure

  1. In the SmarTest Work Center, choose File > export.
  2. The Export Wizard opens. On Select page, choose 93000 Bookmarks from the list and then click Next.
  3. The Export Bookmarks page appears. Select the bookmarks you want to export and enter the path and name of the XML file. Then click Finish.

Results

The current bookmarks are exported to a XML file.
