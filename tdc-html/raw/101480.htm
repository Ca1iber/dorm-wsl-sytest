Topic 101480

Multiport operation

Subtopics

  1. Multiport timing conventions

Multiport operation allows you to test different parts of a DUT with independent timing sets or spec variables using a single memory test pattern.

Procedure

  1. Make sure that all required ports are defined in the Pin configuration file.

    Set up each port so that it groups pins with identical timing. Usually, this is done in SmarTest.

  2. Declare the ports in the Pin mapping file by means of the using port statement.
  3. Specify the required pin ratios in the pin mapping file, either for the port's individual pins or for the port as a whole.
  4. Set up levels, timing, and vectors for each port as usual.

    There are certain conventions to be observed when specifying the timing for multiport operation, as described in Multiport timing conventions.

Results

The pattern is set up so that you can test different parts of the DUT simultaneously with different timing.

If the :testLabel: keyword is used in the APG pattern file, the compiler creates a multiport burst label. If not all ports were declared in the Pin mapping file, the multiport burst label only covers the declared ports and break vectors are applied to all other ports.
