CCTgetUploadId

This function returns the correct upload id of the registered digitizer pin or RF Tx pin.

This function is usually used in the preStart(), postStart(), process() and cleanup() function but not used in the init() function of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

int CCTgetUploadId(const string& pinName)
Parameter

pinName

The registered digitizer pin or RF Tx pin name.

Example

dgtz_waveform = DGT(dac_out).getWaveform(CCTgetUploadId(dac_out));

This example retrieves the waveform of the digitizer pin dac_out.
