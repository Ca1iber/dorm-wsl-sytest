Topic 142781

Changing the default pin status with SmartRDI

Subtopics

  1. clearPinStatus()
  2. setPinStatus()

Introduces the ways to change the default status of pin(s) in the generated pattern.

Note In all patterns generated by RDI, the default waveform index is f, which means keeping the current status of the pin. So you need to define the waveform index f in the wavetable as follows.
PINS pinA
0 "XXXX" X
1 "XXXX" X
...
f  " " .

If the index f is occupied by other meaningful actions or the pin needs a changing waveform as the default index, you can change the default index in the generated pattern with the RDI_configure file or the setPinStatus() and clearPinStatus() functions.

Set the pin status in all generated patterns

Specify the pin and the waveform index in the RDI_configure file with the DEFAULT_STATUS_PIN and DEFAULT_STATUS_INDEX keywords as below:

DEFAULT_STATUS_PIN="pinA,pinB"
DEFAULT_STATUS_INDEX="3,5"

The waveform index of the pinA and pinB in all the generated patterns will be 3 and 5.

Set the pin status in one generated pattern

Specify the pin and the waveform index with the function setPinStatus() like below. You can have more flexible default index in the burst pattern. You can also reset the default waveform index with the function clearPinStatus().

rdi.setPinStatus("pinA",3);

All the indexes in the generated pattern for this pin will be the specified status. The pin name and pin status will be added to the name of the generated pattern.

Note If you specify the status for the pin(s) with both the setPinStatus() and the RDI_configure file, the status specified in setPinStatus() will overwrite the status specified by the keywords in the RDI_configure file.
Note The pin status setting is valid only for the current test suite. This means that even without calling clearPinStatus(), the following test suite will use the default pin status.

Examples

Example 1

RDI_BEGIN();
  rdi.setPinStatus("pinA",3);
  rdi.digCap("mcsame1_DATA1_0").pin("DATA2").samples(30).execute();
  rdi.clearPinStatus("pinA");
RDI_END();

Example 2

Do not use setPinStatus() and clearPinStatus() in the burstLabel block of smartVec.

Wrong position: 

RDI_BEGIN();
  rdi.smartVec().burstLabel("labelName").begin();
    ...
    rdi.setPinStatus("A",1); // This is not allowed.
    ...
  rdi.smartVec().burstLabel().end();
RDI_END();
Correct position:
RDI_BEGIN();
  rdi.setPinStatus("A",1); // This is correct.
  rdi.smartVec().burstLabel("labelName").begin();
    ...
    ...
  rdi.smartVec().burstLabel().end();
RDI_END();
