Topic 125490

Encoding

The encode functions describe the state character sequence generated to by applied to the DUT.

State character sequences are strings of characters that will be mapped to vector data.

Any state character specified in the state map section of the wavetable may as well occur in state character sequences except for the reserved character "R" which marks protocol fields to be read back from the device under test.

The use of state character pairs 0/1 and L/H makes a state character sequence special with regard to enabling specific arithmetic operations on them.

Example

The following example will repeat 64 time the state character 1, thus it is encoding the repeat function into a 64 bit long vector of 1's:

repeat("1",64)

The following example will encode the register address to be 5 bit width and of MSB to LSB order:

regaddr[4..0]
