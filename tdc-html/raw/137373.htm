SEQUENCER_CONTEXT_ITEM

This class creates a single execution context, but only on the test method level. In order to be downloaded to the firmware, the object must be included in a SEQUENCER_CONTEXT object, and be activated by the apply() member function of this SEQUENCER_CONTEXT object.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SequencerContextItem.h.

Syntax

Constructor

SEQUENCER_CONTEXT_ITEM(const STRING &name);

Member functions

SEQUENCER_CONTEXT_ITEM& setPorts(const STRING& portList);
SEQUENCER_CONTEXT_ITEM& getPorts(STRING &portList);

Constructor

SEQUENCER_CONTEXT_ITEM(const STRING &name);

The constructor creates new SEQUENCER_CONTEXT_ITEM objects. The name specified for the name parameter will be used on the firmware level.

Member function

setPorts()

SEQUENCER_CONTEXT_ITEM& setPorts(const STRING& portList);

This member function defines the port list of the execution context. If such a port list already exists, it will be overwritten.

Parameter

I/O

Parameter

Description

I

portList

The list of ports for this execution context.

getPorts()

SEQUENCER_CONTEXT_ITEM& getPorts(const STRING& portList);

This member function retrieves the port list of the execution context.

Parameter

I/O

Parameter

Description

O

portList

The list of ports for this execution context.

Example

For an example, see SEQUENCER_CONTEXT.
