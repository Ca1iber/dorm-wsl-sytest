rdi.id().getImmediateVector()

Gets the result vector chunk when test is running. This is only needed when users want to put their own calculation behind the current execution.

Syntax

array& getImmdiateVector(int offset, const string & pin = TOOL::NOT_DEF_STRING);
List of parameters
Parameter Description
offset The size of data.
pin The specified pin name.

See Using Immediate Upload in SmartRDI for more information about how to use this function together with rdi.digCapImmediateUpload().

Example

resultChunk = rdi.id("resultId").getImmediateVector(uploadDataOffset[site]);

For more examples, see examples in Using Immediate Upload in SmartRDI.
