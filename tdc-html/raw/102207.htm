  • the user-specific modifications of the driver,
  • the reference information like configuration files, configuration parameters, driver functions,
  • and the use of driver functions in the application model.
    Note To use a driver generated on 32-bit system for a 64-bit system or vice versa, you need recompile the source code to generate the driver for the new system.
