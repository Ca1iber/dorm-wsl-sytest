Smart-install-3 command examples

A quick reference for the most commonly used smart-install-3 commands.

Example smart-install-3 commands

The following table includes examples of some commonly used installation-related commands. And is divided into the following groups:

  • Install from the Advantest Software Center
  • Install from a YUM repository
  • Install downloaded products from a local directory
  • Uninstall a product
  • Download a product from the Advantest Software Center
  • Show all installed products
  • Search the Advantest Software Center
  • Search for products in a local directory
  • Miscelleneous commands
Feature Example command
Install from the Advantest Software Center
Install a released version of SmarTest /opt/ate/smart_install_3/smart-install-3 install smartest 8.3.2.1
Install a released version of the SmarTest Suite /opt/ate/smart_install_3/smart-install-3 install smartestsuite 8.3.2.1
Install a PDB version /opt/ate/smart_install_3/smart-install-3 install pdb-workstation 419.0-6
Install from the Advantest Software Center and switch to the newly installed version (SmarTest, SmarTest Suite and TP360) /opt/ate/smart_install_3/smart-install-3 install smartest 8.3.2.1 --switch-version
Install from the Advantest Software Center and force a downgrade of the product if a newer version is already installed (testcellaccess, smartci_client, smartci_server) /opt/ate/smart_install_3/smart-install-3 install testcellaccess 8.3.2.1 --force-downgrade
Install a SmarTest release from a custom YUM repository /opt/ate/smart_install_3/smart-install-3 --yum-repository https://artifact.advantest.com/ install smartest 8.3.2.1

or

/opt/ate/smart_install_3/smart-install-3 --yum-repository file:/repo install smartest 8.3.2.1
Installation of downloaded products from a local directory
Install a product from an RPM package /opt/ate/smart_install_3/smart-install-3 local-install v93000_TestCellAccess-8.3.3.0-T.el7.x86_64.rpm
Install a product from a tar.gz archive /opt/ate/smart_install_3/smart-install-3 local-install smartest-8.3.3.1_RHEL7.tar.gz
Install downloaded products from a directory containing product files (for example, rpm and tar.gz files). /opt/ate/smart_install_3/smart-install-3 local-install /mnt/usbdrive/
Force a downgrade of a product if newer version is installed /opt/ate/smart_install_3/smart-install-3 local-install v93000_TestCellAccess-8.3.3.0-T.el7.x86_64.rpm --force-downgrade

or

/opt/ate/smart_install_3/smart-install-3 local-install /mnt/usbdrive/ --force-downgrade
Uninstall SmarTest /opt/ate/smart_install_3/smart-install-3 uninstall smartest 8.3.2.1
Download a product from the Advantest Software Center /opt/ate/smart_install_3/smart-install-3 download smartest 8.3.3.0 /home/user/products

or

/opt/ate/smart_install_3/smart-install-3 download pdb-workstation 419.0-6 /home/user/products
Show all installed products /opt/ate/smart_install_3/smart-install-3 show
Search the Advantest Software Center for products including a specified search pattern /opt/ate/smart_install_3/smart-install-3 search smartest 8.4.0

or

/opt/ate/smart_install_3/smart-install-3 search smartest 8.4.1
Search for products in a local directory containing tar.gz and rpm files /opt/ate/smart_install_3/smart-install-3 local-search v93000_TestCellAccess-8.3.3.0-T.el7.x86_64.rpm

or

/opt/ate/smart_install_3/smart-install-3 local-search smartest-8.3.3.1_RHEL7.tar.gz

or

/opt/ate/smart_install_3/smart-install-3 local-search /mnt/usbdrive/
Miscellaneous
Display the installed version of smart-install-3 /opt/ate/smart_install_3/smart-install-3 version
Login to the Advantest Software Center to enable external access. /opt/ate/smart_install_3/smart-install-3 login
Logout from the Advantest Software Center /opt/ate/smart_install_3/smart-install-3 logout

Functional changes

  1. Introduced in SmarTest 8.4.3
