DRLAttributeRec

A variable of this type holds the data of one attribute record. Such variables are initialized using the DRLEventGetAttribute function.

The DRLAttributeRec data type is a structure consisting of two members:

  • type (see DRLAttributeType), holds the type of the attribute (see Attribute types). The type determines which element of the second member, the unit data, is valid.
  • data holds the data of the body section of an attribute record for all possible attribute types. If, for example, type is PinResultAttrType, the pin_result_attr element holds the corresponding data.

For further information on how attribute data is organized, see Data Organization.
