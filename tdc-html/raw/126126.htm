Topic 126126

Editing protocol specific levels

About this task

This task describes how to create or modify protocol specific level segments.

Note This task is optional and only needed if you do not specify the protocol relevant levels in the device level equations already.
Note The levels you define here will be saved with the protocol definition. Thus they will be available if the protocol is imported to a new device.

Procedure

  1. Open the Level Segment view by clicking on the Level tab of the protocol editor.
  2. Click New to create a new level segment.
  3. Enter the name of the new level segment and click OK.
  4. Select the level segment and click into the content space to enter new or modify protocol level specifications.
    Note The syntax is equivalent to the one used with equation based levels.
    Note Use pin roles only to define protocol specific levels here.
  5. Save your modifications by pressing the CTRL + S key combination simultaneously.

Results

You have defined protocol specific level settings for your pin roles.

What to do next

In order to use these level settings you have to add the line USE_PROTOCOL "<protocolName>:<levelSegmentName>" [<portList>] to your device level file.
