SmartInstall is a tool for SmarTest-related installation tasks.

Installing software can be done using one of the following routes:

  • The Advantest Software Center
  • The smart-install-3 command line tool

The SmartInstall add-on is a prerequisite to installing SmarTest software from the Advantest Software Center. For detailed information about installing the SmartInstall add-on, refer to Downloading and installing the SmartInstall add-on.

For further information refer to:

  • Searching the Software Center

  • Downloading SmarTest software

  • Installing software products

Functional changes

  1. Introduced in SmarTest 8.4.3
