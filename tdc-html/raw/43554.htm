Resetting a Production Run

Resetting a production test halts the execution of the test, returns the software to its initial state, and resets the downloaded settings in the tester.

To reset a production test, click the RESET toggle button in the Operation Control window shown in Controlling a Production Run. A check box appears asking if you really want to reset the test; if so, click OK.
