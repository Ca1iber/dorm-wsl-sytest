Application Scenario

The scenario begins with the operator selecting a workorder. The software then downloads the corresponding data sets and vectors to the tester. In the meantime, the operator prepares the prober and loads all cassettes on the prober. All specific setups for the test devices, like z-heights for chuck and clean disc, auto alignment pattern, and first die settings, must be available on the wafer prober. If not, then the operator has to set up the product on the wafer prober manually.

After downloading the testprogram, the software prompts the operator to check that the equipment is well prepared. If so, the operator presses the START button on the screen to start the test.

First, the wafer prober is initialized. All necessary setup commands for the prober and the step pattern are downloaded to the prober. The hotchuck is set to the temperature specified by the test engineer and a window appears that prompts the operator for the wafer identifiers in each cassette.

The software then instructs the prober to load the wafer on the chuck, align and profile it. The dies are tested according to the step pattern - defined in the wafer description file - and the actual die location is logged. After testing the die, the software sends pass/fail information to the prober.

If the engineer selected immediate inking, the prober inks all bad dies. An on-line wafermap shows graphically the bin information.

If the die being tested falls into a reprobe bin category, the part is reprobed - that is, the chuck is lowered and raised, and the die is tested again. Once a wafer is completed, testing begins again with the next wafer.

Upon pausing the test, the operator should be able to do the following:

  • print a summary of all the accumulated binning
  • check a die without logging the test result
  • test a reference wafer

    Testing the reference wafer would be along the lines of,

    1. a window informs the operator to remove the current wafer
    2. the operator removes the current wafer and puts the reference wafer on the chuck
    3. the software tests the complete reference wafer and shows the results on the on-line wafermap
    4. after testing the reference wafer, the operator is asked to remove the reference wafer and reinstall the previous one.
