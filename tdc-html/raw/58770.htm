Termination of the sequencers

The termination mode of the sequencers is defined with the SQGB command. The default is that the complete test is executed once. This will be called standard termination.

But you can also cause the sequencers to

  • stop already at a specified cycle (STSQ mode),
  • stop already at the first error (SE mode),
  • repeat the test in an endless loop until it is stopped manually (EL mode),
  • repeat the test in an endless loop and stop at the first error (SEEL mode).
