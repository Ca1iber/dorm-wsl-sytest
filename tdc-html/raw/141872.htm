SHMOO_RESULT.getResult()

Retrieves the test result displayed on a shmoo cell.

Before using this function, use SHMOO_RESULT.coordinate() to specify the position of the cell. Otherwise, you will get the test result of the last cell.

Syntax 1

For your specified shmoo cell, this syntax will retrieve one of its displayed test results from specified sites and pins.

DOUBLE getResult(INT site, const STRING& pin, const STRING& test);

After you get the result, this result related site, pins, test name and shmoo cell coordinate are released from your system.

Syntax 2

Before using Syntax 2, you must specify a shmoo test name with testName(). Then, this syntax will retrieve this type of test result displayed on your specified shmoo cell from all pins at current site.

DOUBLE getResult() const;.

To retrieve the result of particular pin or site, specify the pin and site with SHMOO_RESULT.site() and SHOO_RESULT.pin(). (See the code fragment in the Example section).

After you get the result, this result related site, pins, test name and shmoo cell coordinate are released from your system.

Parameters

Parameter

Description

site

A site number, for which you want to retrieve a shmoo test result.

pin

The name of a pin or a pin group, for which you want to retrieve a shmoo test result.

test

The name of a shmoo test, from which you want to retrieve a shmoo test result.

Return value

Returns:

  • A value if the referenced shmoo test performs measurement tests.
  • ShmooCellData::PASS or ShmooCellData::FAIL if the referenced shmoo test performs pass/fail tests.

Example

std::vector<unsigned int> spacePoint; // coordinate (1,3)
spacePoint.push_back(1);
spacePoint.push_back(3);

//get the result of the last cell from the shmoo test "t1", at the current site, on all pins.
double result1 = SHMOO_RESULT.testName("t1").getResult();

//get the result of the shmoo cell (1, 3) from the shmoo test "t1", at the current site, on all pins.
double result2 = SHMOO_RESULT.coordinate(spacePoint).testName("t1").getResult();

//get the result of the shmoo cell (1, 3) from the shmoo test "t1", at site 1, on all pins.
double result3 = SHMOO_RESULT.coordinate(spacePoint).testName("t1").site(1).getResult();

//get the result of the shmoo cell (1, 3) from the shmoo test "t1", at site 1, on the "Q0" pin.
double result4 = SHMOO_RESULT.coordinate(spacePoint).testName("t1").site(1).pin("Q0").getResult();

if (result4 == ShmooCellData::PASS)
{
  cout << "result for Q0 is pass" << endl;
}
else if (result4 == ShmooCellData::FAIL)
{
  cout << "result for Q0 is fail" << endl;
}
else
{
  cout << "result value for Q0 is " << result4 << endl;
}
