12" Port Scale RF wafer prober interface

Subtopics

  1. 12" WPI components
  2. 12" WPI installation procedure

The wafer prober interface is a high bandwidth extension of the DUT interface that reaches into the wafer prober to deliver test signals to the probe card.

Supported V93000 systems : Smart Scale (SmarTest 7), Pin Scale

Main features of the 12" Wafer Prober Interface

When developing a wafer prober interface, the main guide lines were to:

  • keep the DUT board generic and make the probe card device specific.
  • provide more space for the dies and related components on the probe card.
  • provide a microscope hole for applications such as CMOS imaging.

The 12" wafer prober interface satisfies those guide lines:

  • it provides sufficient center space for parallel probing and components.
  • it provides large pin count for the majority of present and upcoming applications.
  • it supports probe card exchangers even in RF applications.
  • it covers all applications in wafer sort.
  • it ensures high signal integrity.
  • it supports test cost reduction effort.
  • it ensure parallel probing ensured with center hole and space on probe card widened from 4" to almost 7".
  • Up to 1280 I/O pins supported plus 528 power and utility lines plus ground pins (by the pogo tower itself, 1024 pins on the generic DUT boards).
  • Probe card with 12" stiffener for all manual and auto probe card changers.
  • Pogo tower has 7GHz bandwidth, 2GHz including generic DUT board, large generic DUT board supports 128 matched lines.
  • Pogo segments are isolated from each other, 2 analog ground planes on large generic DUT board (1 for the small version).
  • Steel stiffener for best probe card planarity.

Functional changes

  1. Introduced in SmarTest 6.3.2
