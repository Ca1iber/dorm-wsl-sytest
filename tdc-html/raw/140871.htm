Topic 140871

RESULT_AREA_CONFIG_SET.setAsPrimary()

This function sets the current result area configuration set as the primary set. The result area configuration set will be activated with the next digital test.

Syntax

void setAsPrimary();

List of parameters

There are no parameters.

Return value

There is no return value.
