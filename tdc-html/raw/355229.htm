Migrating test programs to SmarTest 7.10

SmarTest 7.10 is, for the most part, compatible with earlier versions of SmarTest. This section summarises what to consider, when migrating to SmarTest 7.10.

CAUTION THIS TOPIC IS WORK IN PROGRESS!

Hardware

SmarTest 7.10 supports the new EXA Scale test systems, as well as the Smart Scale test system. EXA Scale is the next generation of Advantest test systems, consisting of the CX, SX, and, LX test heads, see topic Test heads for an overview.

With EXA Scale comes support of the new EXA Scale generation cards:
  • The DC Scale XPS256 card, and
  • the Pin Scale 5000 card.

These cards, as well as the new Utility Card, are not supported with the Smart Scale test system.

The Pin Scale generation cards are no longer supported. See section Smart Scale vs. Pin Scale for considerations when upgrading to Smart Scale or EXA Scale generation cards.

The DPS-Slot power supplies and the DC Scale UHC4 and PVI8 cards are no longer supported.

For an overview of supported cards, see section Test Head Cards.

Software

Consider the following list when migrating your test program to SmarTest 7.10:
  • The EXA Scale test system only supports the tester.model style model files. See Converting legacy model files for how to convert your old model file.
  • The High Precision PMU (system PMU) is no longer supported. The Pin PMU must be used instead, see Per Pin PMU.
  • The master clock period is fixed at 8/3 = 2.67 ns (frequency of 375 MHz). The Smart Scale and EXA Scale digital cards still provides an independent clock domain per pin.
  • High voltage pins are no longer supported.
  • The Memory Stacker is no longer supported. Use instead Memory pooling and memory sharing.

Other considerations

Maintenance is executed by means of an auxiliary embedded maintenance core, see Executing SmarTest 7.10 maintenance activities.
