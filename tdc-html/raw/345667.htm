Twinning DUT board EEPROM requirements

For a standard EEPROM in the DUT board, as used on the standard V93000 DUT boards, the utility 1 EEPROM control pins (as described in Utility lines and DUT board EEPROMs) should have been properly routed through the family board and available at some pins in the Twinning segments. These pins should then be routed to the EEPROM circuitry. It is not a good idea to have the EEPROM only on the Twinning family board because different DUT boards might be used with the same family board. Both the Twinning family board and the DUT board should have EEPROMS connected to the utility 1 with different addresses as shown below.
Board EEPROM Address A1 EEPROM Address A2
Twinning Family Board 1 1
Twinning DUT Board 0 0
