Topic 142698

MTL Program File Simplification

The keywords

  • :version:
  • :apgAccess:
  • :format:
  • :name:
  • :interface:
  • :deviceParam:
  • :programParam:
  • :code:

are not needed anymore in the program file (*.prog).

For more informationrefer to APG program file in Memory Test Language (MTL) Programming Reference.
