Topic 69429

Dual-site GPIO configuration

Subtopics

  1. Valid combinations of plug-ins and configuration files
  2. Binning maps
  3. Timing diagram (Advantest M-4182)

The Advantest "Dual-site" configuration is valid for Advantest dual-site handlers.

Supported handler models

  • M-4182

Features

  • 2 sites
  • test system ready signal
  • serial binning
  • encoded binning
  • global parity line
  • The following signals from the handler is not supported by the driver: STRQ M, FR, SELx, MODEx, TEMPx

Required handler cable

There is no preconfigured handler cable available for this configuration. Please see Advantest handler cable for the information on configuring the cable.
