EVENT_FILTER.getFilterValue()

Queries the value of the filter that has been defined by EVENT_FILTER.setFilterValue().

Syntax

void getFilterValue(EVENT_VALUE_DOUBLE &filterValue) const;
Parameter
List of parameters
Parameter Description
filterValue

The filter value that has been programmed by EVENT_FILTER.setFilterValue().
Return value
There is no return value.

Example

For an example, see EVENT_FILTER.

Related information

EVENT_FILTER.setFilterValue()
EVENT_VALUE_DOUBLE

Functional changes

  1. Introduced in SmarTest 7.4.2
