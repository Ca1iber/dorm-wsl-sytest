APRM - (Activate PRiMary sets)

The APRM command activates primary sets in the hardware which were made known to the firmware by the SPRM (Set PRiMary sets).

Mode of operation

The following commands do not require a prior execution of APRM, since they themselves perform this function:

  • FTST? - (Functional TeST)
  • RCLS? - (ReCeive Level Sensitivity)
  • SQST RUN - (SeQuencer STate)
  • PSST - (Power Supply STatus)

Syntax

APRM {mode}

Parameters

mode Selects the activation mode:
FRC Forced activation. Primary sets are always activated.
CNL Conditional activation, depends on previous activation performed by APRM or by any of the commands in the second list above.

Application

AC tests and DC Measurement Commands.

Example

APRM CNL

Functional changes

  1. Introduced before SmarTest 6.3.2
