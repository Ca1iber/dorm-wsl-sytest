MTP_MEMORY_TEST.setFBCLimit()

The setFBCLimit() member function of MTP_MEMORY_TEST lets you specify which fail bit counts (FBC) is to be used to determine the overall pass/fail result.

This is an optional method. The setting is relevant only if using the FBC to determine the pass/fail result has been enabled using the enableFailBitCount() function.

The setFBCLimit() function causes the a fail result if any one of the specified fail limits is exceeded.

Syntax

MTP_MEMORY_TEST& set FBCLimit(MTP::FBC_DIMENSION dimension, const LONG64 limit, STRING entity = "@")
MTP_MEMORY_TEST& set FBCLimit(MTP::FBC_DIMENSION dimension, const LONG64 limit, const int index)

Parameter

Description

dimension

The device dimension for which the failed bits limit applies:

  • MTP::FBC_DEVICE: The test fails if the failed bit count for the entire device exceeds limit.
  • MTP::FBC_DBIT: The test fails if the failed bit count for any data bit exceeds limit.
  • MTP::FBC_BANK: The test fails if the failed bit count for any bank exceeds limit.

limit

The maximum permissible number of failed bits. If the failed bit count for the specified dimension is larger than this number, the test fails.

entity

A list of data bits (if dimension is MTP::FBC_DBIT) or banks (if dimension is MTP::FBC_BANK) that are considered for the pass/fail result.

If any of the specified data bits or banks exceeds limit, the overall test result is fail. Data bits or banks that are not included in entity do not cause a fail when they exceed limit failed bits.

This parameter is optional. If it is not specified, all data bits or all banks are compared to limit, unless an index has been specified. (That is, the default value is "@".)

This parameter is ignored if dimension is MTP::FBC_DEVICE.

index

An index of a data bit (if dimension is MTP::FBC_DBIT) or bank (if dimension is MTP::FBC_BANK) that is considered for the pass/fail result.

This is a simplified version of using the entity parameter when you want to check only a single data bit or bank to determine the overall pass/fail result. Specifying an index for an element (data bit or bank) is the same as specifying a list containing only the name of that element as the entity.

For example, if there are two data bits DQ01 and DQ02, these two calls are equivalent:

  • setFBCLimit(MTP::FBC_DBIT,4,"DQ02")
  • setFBCLimit(MTP::FBC_DBIT,4,2)

This parameter is optional. If it is not specified, failed bits from all devices, data bits, or banks are compared to limit, unless an entity has been specified. (That is, the default value is -1.)

Examples

Example 1

The following example switches on the fail bit count and specifies that the test will fail if there are more than:

  • 1024 fail bits for the entire device
  • 256 fail bits for at least one of the banks 1, 2, 3, and 4
  • 128 fail bits for any single data bit
    MTP_MEMORY_TEST memoryTest();
memoryTest.enableFailBitCount(true);
memoryTest.setFBCLimit(MTP::FBC_DEVICE,1024).setFBCLimit(MTP::FBC_BANK,256,"1,2,3,4").setFBCLimit(MTP::FBC_DBIT,128);

Example 2

You can apply this function multiple times to set multiple simultaneous limits for the same dimension. The following example sets the test to fail is any one data bit exceeds 32 failed bits or if data bit DQ01 or data bit DQ02 exceed 20 failed bits:

MTP_MEMORY_TEST memoryTest();
memoryTest.enableFailBitCount(true);
memoryTest.setFBCLimit(MTP::FBC_DBIT,32).setFBCLimit(MTP::FBC_DBIT,20,"DQ01,DQ02");
