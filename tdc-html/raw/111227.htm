Topic 111227

setSiteInFocus()

This API sets the focused site.

If the site is not activated yet, this API will activate it and then focus on it. If the specified site is not available, an error message will be sent out without changing the site.

Syntax

void setSiteInFocus(const int site);
Parameters

site

The site to set in focus.
