Parameter: gpio_box_clear_latch_lines

Using the Agilent Technologies GPIO Interface box E2828A-560 test start signals are usually latched. After binning the current devices, it must be ensured that the previous test start latches are cleared. The GPIO box provides latch clear functionality for different GPIO output lines depending on the current jumpering inside the box. If not already pulsed during device binning, the GPIO lines defined by this parameter are pulsed to reset the GPIO box latches.

Valid values are "CTL0" and "CTL1"

Driver default: depends on plug-in

Changeable at run-time: yes

Applicable for: handlers and probers

Example: gpio_box_clear_latch_lines: ["CTL0"]
