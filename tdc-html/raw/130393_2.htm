Topic 130393

TSVD? - (TimStamper ValiD)

This query serves to check the consistency of a specified timing specification with a specified TMU set. In order that such a pair be consistent, the distance between two events as selected by the prescaler must not be smaller than the positive pulse by which such events are represented to the event discarding block. For more information see Dealing with very high data rates.

Postdependencies

Increase the prescaler value or reduce the data rate of the TMU set.

Syntax

TSVD? {waveform_set|specset_id|"multi-port_spec"|PRM}, {"TMU_set"|PRM}

returns:

TSVD? {waveform_set|specset_id|"multi-port_spec"|PRM}, {"TMU_set"|PRM}, {VALID|ERROR}

Parameters

waveform_set

Specifies a waveform set number for a fixed timing setup.

specset_id

Specifies a spec set ID for an equation based setup. The spec set ID is derived from an equation set number and a spec set number as follows:

100 * equation_set_no + specset_no

multi-port_spec

Specifies the name of a multiport specification for a multi-port setup.

TMU_set

The TMU set that is to be checked.

PRM

Refers to the current primary timing specification or the current primary TMU set.

VALID

Timing specification and TMU set are consistent.

ERROR

Timing specification and TMU set are not consistent.

Application

TMU per pin.

Example

> TSVD? PRM, "TMU_set1"
< TSVD PRM, "TMU_set1",VALID

This example queries if the current primary timing is consistent to the TMU set TMU_set1.

Functional changes

  1. Introduced in SmarTest 7.1.3
