Get Connect State

This routine lets you determine the connect state of the device as shown in the report window.

  • GetConnectState(INT32 *connect_state)
    Note Note that the connect state might not reflect the actual hardware settings if relevant firmware commands have been sent to the test system, bypassing the connect/disconnect testmethod.

    This function sets connect_state to FALSE (0) if the device disconnected and to TRUE (1) if it is connected.

    This function is especially helpful for user procedures that require certain connect/disconnect states but for optimization do not want to reconnect if this state is already set.

Functional changes

  1. Introduced before SmarTest 6.3.2
