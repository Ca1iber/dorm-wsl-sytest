Topic 44912

Package ID

get

Retrieves the string currently set as the Package ID and copies it to the string pointer *id.

This function writes a maximum CI_CPI_MAX_PACKAGE_LEN + 1 bytes to the pointer *id.

If multiple sites are used, the second function (GetPackageIdOfSite) allows you to retrieve the information from a specific site. If you use the first function (GetPackageId), the information for the site currently in focus is returned.

long GetPackageId(char *id)

long GetPackageIdOfSite(long site, char *id)

set

Sets the string recorded as device test Package ID to the value pointed to by string pointer *id.

The second function (SetPackageIdOfSite) allows you to set the information for a specific site. If you use the first function (SetPackageId), the information for the site currently in focus is set.

long SetPackageId(char *id)

long SetPackageIdOfSite(long site, char *id)
