Combining transition tracking with a PRBS or pattern‑based SmartLoop test

It is possible to combine a PRBS test or pattern‑based SmartLoop™ test (see Commands for PRBS and SmartLoop tests) with transition tracking at the output pins. Since only the tracking block is needed in this case, the transition test set must be configured as the following example set PRBS_LOOPBACK_TT:

  • TTCF "PRBS_loopback_TT",TRACKING_MODE,ACTIVE,(out1)

    This enables adjustment of the observation window.

  • TTCF "PRBS_loopback_TT",FIRST_INITIAL_SYNC,OFF,(out1)

    TTCF "PRBS_loopback_TT",SUBSEQUENT_INITIAL_SYNC,OFF,(out1)

    Initial synchronization makes no sense for a PRBS or pattern‑based SmartLoop™ test, because no expected data are available (the seed for the expected PRBS is taken from the received data).

  • TTCF "PRBS_loopback_TT",ERR_COMPARE,OFF,(out1)

    In a PRBS test, the PRBS checker decides about the test result. In a pattern‑based SmartLoop™ test, the result data only serves as input for the loopback.

For all other properties, you can use the default.

Functional changes

  1. Introduced in SmarTest 7.0.1
