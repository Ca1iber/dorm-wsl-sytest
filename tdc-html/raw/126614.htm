Logging memory tests

Subtopics

  1. Logging formats and data types
  2. Configuring data logging for memory tests
  3. Memory test data log event structure

Memory test can be logged in a similar way to other tests using the event data log.

No special setup is required (beyond setting up logging in general), and the general settings regarding the level of logging detail also apply to the logged memory test events.

Functional changes

  1. SmarTest 7.0.4: Logging memory test evens is available only in MTP on HSM.
  2. MTP 3.1.4: Logging memory tests events is available both in MTP on HSM and MTP on SOC.
