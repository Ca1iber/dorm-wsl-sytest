DELV - (DELete Vectors)

The DELV (DELete Vectors) command deletes a number of active vectors from the end of a sequencer construct. The instruction of the construct must be GENV (GENerate Vectors), RPTV (RePeaT Vectors), or MRPT (Match RePeaT).

Predependencies

DELV can only be issued after the label to which the sequencer construct belongs has been activated for editing with the TSTL command.

Mode of operation

The deletion is achieved by reducing the length of the sequencer construct accordingly. This can have the effect that one or more complete memory units become inactive. In this case, the inactive units are deleted, and the STVA instructions of the labels that use later segments of the respective vector area are updated accordingly.

If the number of vectors to be deleted equals the active vectors of the sequencer construct, the instruction at cmd_No is overwritten by a NOP instruction. See also Deleting a sequencer instruction.

This command also moves the comments so that they are aligned to the correct vectors.

Syntax

DELV {cmd_No}, {vect_length}

Parameters

cmd_No

The command number which references the sequencer construct where vectors are to be deleted. The instruction of the construct must be GENV (GENerate Vectors) or RPTV (RePeaT Vectors)

vect_length

The number of active vectors to be deleted at the end of the referenced sequencer construct.

Application

Edit command in Pattern Tool.

Errors

An error is generated if:

  • You specify a negative vector length.
  • The sequencer construct is not of type GENV or RPTV.
  • You try to delete more vectors than the sequencer construct contains.
  • No label has been activated for editing.
  • The specified command number is out of range.

Example

> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,34,,,(@)
< SQPG 3,STOP,,,,(@)
< SQPG 4,STVA,544,,,(@)
< SQPG 5,STSA,,,,(@)
< SQPG 6,STOP,,,,(@)
> TSTL "test_1",(@)
> DELV 2,25
> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,9,,,(@)
< SQPG 3,STOP,,,,(@)
< SQPG 4,STVA,520,,,(@)
< SQPG 5,STSA,,,,(@)
< SQPG 6,STOP,,,,(@)

This example deletes 25 vectors from the end of the sequencer construct referenced by command number 2. Three memory words become inactive in the process and are deleted. The start address of the following label (command line 4) is adjusted.
