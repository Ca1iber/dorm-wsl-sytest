LoadExecInputLib()

This API loads the existing execution input shared library into the memory. If a shared library is already loaded, this API will first unload the shared library and then load the requested one.

SUCCESS will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

PARAMETER_EXCEPTION

The value of the parameter "EXEC_INPUT_LIB" is empty.

RECOVERABLE

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • The local session does not exist.
  • The specified library "XXX" cannot be loaded into the memory.
  • An execute-input library is already loaded but failed to unload.

RECOVERABLE

 

FIL_NOT_FOUND
  • The specified library "XXX" does not exist.
  • The Ci link "XXX" does not exist.

RECOVERABLE

FILE_ACCESS_DENIED

The specified library "XXX" is not accessible.

RECOVERABLE

Parameters

I/O

Parameter

Description

I

SESSION_ID

The local session ID.

I

EXECUTE_INPUT_LIB

The full path of the execution input shared library.

Prototype

ParamList inputParams;
Status syncCommand("LoadExecInputLib", inputParams, sessionID);

Example

string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams; 
inputParams["EXEC_INPUT_LIB"] = "/opt/hp93000/soc/exec_input/OFFLINE_SIM/libcifset.so";

Status retVal = syncCommand("LoadExecInputLib", inputParams, sid);
if ( retVal.isError() ) 
{
cout<<"error code= " << retVal.code() << " description="
   << retVal.text() << endl;
}

Functional changes
