update_template

The update_template command for the SmarTest Program Manager MCM (STPM MCM) control file recalculates the tables in the MTPT (STPM MCM mapping table). Depending on the mode you choose, STPM MCM recalculates all tables - except those you specify - based on changes in the STPs and in the specified read-only tables, or it reviews the errors listed in the Notes columns of some or all tables and remove fixed ones.

Using this command makes it easier to keep an MTPT consistent when you have made changes and keep an overview of which errors still need attention.

Note that, in either mode, STPM will overwrite the contents of the Notes columns in the MTPT (except in the tables marked as read-only), so that you will lose any text you may have entered in these columns.

Before update_template can be executed, an MTPT (STPM MCM mapping table) must have been created, which is typically done with the generate_template command.

Syntax

update_template(
  mode      = '<mode>',
[ read_only = ['<table>', ...]  ]
)

Parameters

mode

What STPM MCM is to update in the MTP.

<mode> can be any of these:

  • 'adjust_tables': All tables in the MTP - except any read-only tables, see below - are updated from the STPs and the tables marked as read-only.

    If this mode is specified and no table is listed as read-only, the effect is the same as rerunning generate_template with the original parameters.

  • 'clear_errors': STPM MCM reviews the errors and warnings in the note columns of all tables in the MTP - except any read-only tables, see below - and removes all that no longer apply.

read_only

A list of all tables STPM MCM is to leave unchanged. These tables are used as the sources to recalculate the other tables.

<table> can be any of these terms:

  • 'STPs'
  • 'Pins Map'
  • 'Groups Map'
  • 'Tests Map'
  • 'Test Suites'
  • 'Bins Map'
  • 'Test Numbers Map'
  • 'Flow Variables Map'
  • 'Special Tests'
  • 'Shared Pins'
  • 'Test Flags'
  • 'Off DC Levels'
  • 'STP Test Info'

You can specify multiple tables that must remain unchanged by separating them with commas. The list of tables - whether one or more - must be enclosed in square brackets.

This is an optional parameter. If it is not specified, STPM MCM will update all tables.

(The information which MTPT to update comes from the mtp_template_dir setting in the control file.)

Example

This example checks the errors noted in the MTP in /prj/MTPT and removes those that have been fixed since the last update of the MTP. It does not remove any errors from the STP and test mapping tables.

mtp_template_dir = "/prj/MTPT"
update_template(
  mode = "clear_errors",
  read_only = ['STP Table', 'Tests Map']
)
