Topic 10608

Selecting and ordering edges

Subtopics

  1. Restrictions for drive edges
  2. Restrictions for receive edges

Every action in a waveform shape definition must be associated with an edge, which is a point in time within a tester cycle. SmarTest knows two types of edges, drive edges, which can only be associated with a drive action, and receive edges, which can only be associated with a compare action.

On the Pin Scale 800/3600 boards, drive edges are denoted by dn, where 1 ≤ n ≤ 8. Receive edges are denoted by rn, where 1 ≤ n ≤ 8 for Pin Scale boards. Thus, there are 8 drive and 8 receive edges for a Pin Scale board.

On the Smart Scale boards, there are two kinds of drive edges, which are denoted by fn and sn, respectively. There are 8 edges for each of the two types. For details see Defining waveforms for Smart Scale pins.

Note that edge delays are defined on the pin level, not for individual waveforms. Thus, if you want to use the first two drive waveforms shown in Waveform Shapes and Edge Delays with the same timing set, you would have to define two shapes and use different edges, for instance d4 and d5, for the last two actions of the second definition. The resulting definitions could look as follows:

(PDW1) "d1:0 d2:1 d3:0"

(PDW2) "d1:0 d4:1 d5:0"

The required delays for d4 and d5 would have to be added to the timing set in question. This timing set could then look as follows:

(DE) d1=0

d2=20

d3=40

d4=15

d5=25

In addition, there are specific restrictions for drive edges and for receive edges, see Restrictions for drive edges and Restrictions for receive edges.
