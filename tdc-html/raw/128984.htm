MTP_MEMORY_TEST.restrictToChannelCaptureMemorySize()

The restrictToChannelCaptureMemorySize() member function of MTP_MEMORY_TEST lets you specify specify that only as much result data is captured as the channel memory can hold.

This is an optional method.

Syntax

MTP_MEMORY_TEST& restrictToChannelCaptureMemorySize(const bool status)

Parameter

Description

status

Whether to restrict the amount of captured data to the capacity of the channel memory:

  • true: When there is no more room in the channel memory for storing additional captured data, the test is stopped.
  • false: When there is no more room in the channel memory for storing additional captured data, the data is uploaded and the test is repeated. Data capture in the repeated test starts from the point where the previous test was ended.

The default is false, that is, all test data is captured.

Example

To capture only as much data as the channel memory can hold:

MTP_MEMORY_TEST memoryTest();
memoryTest.restrictToChannelCaptureMemorySize(true);
