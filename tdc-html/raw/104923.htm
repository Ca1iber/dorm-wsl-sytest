LabelListAttrType

Is used with "configuration changed" events and carries the information of which vector labels are loaded into the tester. The data type is DRLLabelListAttr.

Field Name

Data Type

Description

Comments

length

int

Attribute length

These fields form the attribute header.

type

short

Attribute type

mode

unsigned int

Bitwise or'ed,

DRL_LABEL_LIST_MODE_APPEND = append the contents of this label list rather than deleting the existing one

 

label_count

int

Number of labels in this label list, that is, the number of times the pair of label_id and label_name is repeated.

 

label_id

int

Numeric identifier by which the label is referenced later

 

label_name

string

Label or pattern name
