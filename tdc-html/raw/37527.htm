The KEEP_PLL_ALIVE Section of the ASCII Timing File

In its basic form, the KEEP_PLL_ALIVE section defines the timing for one pair of clock port and data port that are to be used together. The timing for the clock pins is specified globally for the whole section (not for a fixed ASCII device cycle). The timing for the data pins is defined by one or more ASCII device cycles which are part of the KEEP_PLL_ALIVE section.

From this information, the ASCII interface creates separate equation sets for the clock port and the data port, and generates a multi-port specification for these ports. In this specification, clock port and data port are assigned to different sequencing groups, and phase synchronization is activated.

The wavetable section for any clock pin contains only one waveform (and an identical break waveform). In the timing map files, the clock pins are integrated into the ASCII device cycles for the data pins; all of these ASCII device cycles will also contain an entry for every clock pin. These entries map any state characters of the respective clock pin to the index of its single waveform.

One ASCII timing file can contain more than one KEEP_PLL_ALIVE section.
