CFPR, CFPR? - (Clock Forwarding PRimary set)

CFPR defines the primary clock forwarding set. Note that if a primary clock forwarding set is defined, then it will also be used in the test. CFPR? returns the current primary set.

CFPR

CFPR {"cf_set_name"}

CFPR?

CFPR?

returns: 

CFPR {"cf_set_name"}

Parameters

cf_set_name

Specifies the name of an existing clock forwarding set. Specify an empty string to inactivate the current primary set and thus to disable clock forwarding.

Application

Protocol engine test.

Errors

An error is generated if no clock forwarding set with this name exists.

Example

> CFPR   "cf_set1"

Functional changes

  1. Introduced in SmarTest 7.0.1
