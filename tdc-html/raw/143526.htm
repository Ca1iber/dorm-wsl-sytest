clamp()

Specifies the clamp voltage or clamp current.

When forcing voltage, it is current clamp.

When forcing current, it is voltage clamp. And the clamp voltage can determine the direction of the flowing current.

This function can be used to set a current measurement range for SPMU.

Syntax

clamp(double dClamp);
List of parameters

Parameter

Description

dClamp

The clamp voltage or current

Example

rdi.dc().pin("pinA",TA::SPMU).vMeas().clamp(2 V).execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
