Topic 81101

Setting up the timing file

Subtopics

  1. Setting up the timing equation
  2. Setting up the wavetables
  3. Setting up vector labels

To set up the timing files for the Multi-Strobe test methods, you modify setup files by:

  • Creating a timing equation set
  • Creating two additional wavetables
  • Creating a vector label for the additional wavetables or use the existing patterns if applicable

Functional changes

  1. Introduced before SmarTest 6.3.2
