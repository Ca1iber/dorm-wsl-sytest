Clock boards

Subtopics

  1. Clock board clock generation and distribution
  2. Clock board hardware overview
  3. Clock board specific setup tasks

Each card cage of the V93000 Smart Scale test system is equipped with one clock board.

Clock generation and distribution

The main task of the clock board is to generate the master clock (MCLK) for the test system. The master clock is used as a reference for all timing signals within the test system. For more information, refer to Clock board clock generation and distribution and to Clock board hardware overview.

Connection to external instrumentation

External instrumentation, such as external calibration equipment that is connected to the BNC connectors "FORCE", "SENSE" and "GND SENSE" of the test head's side panel can be connected to the internal DC rail and to the dedicated utility pogo pins of the DUT interface.

Other functional blocks

In addition, the clock board contains the following functional blocks:

  • Utility line interface to control external devices such as relays, solenoids or indicators on the DUT board.
  • AC Calibration circuitry to allow calibration of channel boards with the calibration robot.
  • Auxiliary voltage generators to produce voltages for use by the interface modules on channel boards, the DPS and the DUT board.
