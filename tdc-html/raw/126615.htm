Logging formats and data types

Memory tests are logged to EDL with the TEST_TYPE_MEMORY event type and can be formatted as STDF.

EDL data types

In particular, the following EDL data types are used to log memory tests:

  • DRLPatternLabelAttr
  • DRLBitFailMapDescAttr
  • DRLFailingAddressCountAttr
  • DRLResultPinName
  • DRLBankSpecificCounts
  • DRLPinSpecificCounts
  • DRLFailingAddressesAttr
  • DRLPinSpecificAddresses
  • DRLRARepairResultsAttr

STDF record types

STDF formats memory tests as FTR records.

Event formatter

The Event Formatter logs events with the TEST_TYPE_MEMORY type, and supports the DRLPinSpecificAddresses and DRLRARepairResultsAttr data types.

Functional changes

  1. SmarTest 7.0.4: Logging memory tests events is available only in MTP on HSM.
  2. MTP 3.1.4: Logging memory tests events is available both in MTP on HSM and MTP on SOC.
  3. MTP 3.2.2: Adds a new EDL data type, DRLRARepairResults.
  4. MTP 3.2.2: The event formatter logs events with the TEST_TYPE_MEMORY type, and supports the DRLPinSpecificAddresses and DRLRARepairResultsAttr data types.
