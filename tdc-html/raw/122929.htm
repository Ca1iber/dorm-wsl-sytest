PS1600 compatibility

Subtopics

  1. Identifying Pin Scale vs. Smart Scale test systems

The following describes some specific differences.

Memory usage of PS1600 rev. A and PS1600 rev. B

Depending on the PS1600 revision, A or B, the maximum memory differs. While the PS1600 rev. A features 112 MB max., the PS1600 rev. B features 224 MB max.

If you develop or modify a test program on the PS1600B and want it to be compatible on the PS1600A, you need to set the smem parameter in the IOCHANNEL section of the model file or the device license file to 112M max. For example:

10101: HW = PS1600, speed = 1600Mbps, smem = 112M

Note that an entry in the device license file overrides a license specific entry in the model file.

Test head infrastructure

A Pin Scale 1600 card requires a Smart Scale test system. It is not supported by Pin Scale test systems.

Refer to Identifying Pin Scale vs. Smart Scale test systems if you need to identify whether your test system already has been upgraded to Smart Scale, or not.

Pogo block compatibility

The Pin Scale 1600 cards support three pogo pin layouts with regard to compatibility:

  • Standard (compatible) layout (including the long pogo cable assembly), consisting of eight pogo blocks per card having 16 pins per block. This layout is compatible with existing DUT boards and gives you a total of 2048 pins.
  • High-density (HD) layout, consisting of four pogo blocks per card having 32 pins per block. This layout is compatible with the layout for the inner 16 pins, which provides a total of 2048 standard (compatible) pins.

    For additional pins up to 4096 pins, two outer rows (each containing 8 pogo pins) are provided.

  • Very-high-density layout, consisting of two pogo blocks per card having 64 pins per block. This layout is compatible with the layout for the inner 16 pins of the SD pogo block and with rows A, B, C, and D of the HD pogo block. Three additional rows increase the total number of pins to 8192 pins using the non-standard filling scheme.

The outer rows of the SD pogo block and the additional rows of the VHD block must be considered in your DUT board layout if you need to use them. See also PS1600 pogo pin assignment and Pogo block compatibility.
