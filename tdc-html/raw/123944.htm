d2s wait

The d2s wait method modifies the vector repeat count in the wait-template label.

This is done by calculating the repeat count based on the primary timing period.

The d2s-framework will calculate and modify the repeat count automatically.

Syntax

void wait(double timeInS);
Parameter

I/O

Parameter

Description/Range

I

timeInS

Wait time.

Unit: s

Depending on the timing period of the particular port, wait time is achieved by generating wait-cycles within the (multiport) burst

Example

The following excerpt illustrates how the wait method can be used.

In learning mode it will generate a wait label, add it to the burst label MyBurstLabelName and execute the pattern at d2s_LABEL_END().

In production mode only the MyBurstLabelName pattern will be executed at d2s_LABEL_END().

virtual void run()
{
   d2sFramework fr;
   d2sJTAG& jtag = d2sJTAG::Instance();

   // Register your protocol with the framework
   fr.registerTransactionPort(jtag);

   ON_FIRST_INVOCATION_BEGIN();
      fr.d2s_LABEL_BEGIN("MyBurstLabelName", d2sFrameWorkModeType::LearningMode);
         jtag.write(0xdead, 0xbeaf);
         jtag.wait(200 us);
         jtag.read(0xdead, "one");
      fr.d2s_LABEL_END();

      // do your measurement here

   ON_FIRST_INVOCATION_END();

   cout << "Result: " << jtag.getReadValue("one") << endl;
}

The static write patterns created by the code above for a single port setup would be saved into the device vector directory as:

d2s_jtag_AT_W_0xdead_0xbeaf, d2s_jtag_AT_R_0xdead and d2s_jtag_AT_Wait_200us
