Select operator

The select operator allows you to select specific bits of a binary number in the Device access file when used with macros (crc, data, xaddr, yaddr, or zaddr).

You can specify:

  • A single bit: value[<bit_number>]
  • Multiple bits: value[bit_number_1,bit_number_2]
  • A range of bits: value[<from_bit_number>..<to_bit_number>]

These syntaxes can be combined, as shown in the examples below.

Note Do not use loop dependent Variables in select operations with scrambles (xaddr(), yaddr(), zaddr()) and data macros (data()) in device accesses. For example, data(dw, x, y, z)[DQNo] is not allowed while dw[DQNo] is supported, where DQNo is one of loop dependent variables.

This selector is also useful in selecting pins from a pin group using the same construction but giving the name of the pin group instead of the binary number.

The selector is very similar to but slightly different from the index operator. The differences are detailed in Index operator.

Example

  • value[3]: The third bit of value.
  • value[1,2,5]: The first, second, and fifth bits of value.
  • value[6..8]: The sixth, seventh, and eighth bits of value.
  • value[1..3,6,8]: Bits one, two, three, six, and eight of value.

Functional changes

  1. Introduced before SmarTest 6.3.2
