TCCT Preferences

The TCCT Preferences page can be used to configure the device lock notification and the color of the status. It is opened by clicking Window > Preferences in TCCT.

  • Device Lock Notify

    Specifies whether to show the confirmation dialog asking to break the device in lock. The dialog will not be shown by default.

  • Status Color

    Allows adding, modifying or removing the status and their corresponding colors.

Functional changes

  1. Introduced in SmarTest 7.2.0
  2. SmarTest 7.2.3: New preference page for Device Lock Notify in TCCT 1.5
