rdi.route().pin().setOff()

Switches off a utility line or a Power MUX (PMUX) switch or a list of utility lines or PMUX switches without using the stored states and keeps the status of the remaining switches.

This function provides direct access to the utility lines and does not use the stored switch states. The function works similar to function rdi.util().setOff, but expects a switch name or a list of switch names that have been defined in the Utility Lines Config editor of the Routing Tools editors.

The "off" state is defined as follows:

  • Utility line open collector output is off
  • PMUX switch is open

Usage of the function:

  • Depending on the target pin, the function can be called in the code‑based mode or in the pattern‑based mode:
    Software‑controlled (static) utility lines: Code‑based mode only
    Sequencer‑controlled (dynamic) utility lines: Pattern‑based mode only
    PMUX switches: Pattern‑based mode only

    For more information, refer to Execution mode in topic SmartRDI.

  • For information regarding the execution sequence for the combination of software controlled and sequencer‑controlled utility lines or PMUX switches, refer to the Execution sequence in rdi.route().pin().
  • The utility lines and PMUX switches are to be defined by function rdi.route().pin().

Syntax

ROUTE& setOff();
List of parameters
There are no parameters.
Return value
A reference to the ROUTE object.
