MTP_MEMORY_TEST.execute()

The execute() member function of MTP_MEMORY_TEST lets you execute the functional test as the conditions set in the setup functions and generate the test results.

Note that this member function dose not connect tester resources to DUTs automatically. You must ensure the tester and DUTs are already connected, for example, using the CONNECT() API prior to using execute().

Syntax

void execute()

Example

Enabling address-based results and executing the test:

MTP_MEMORY_TEST memoryTest();
memoryTest.enableAddressBasedResults(true);
CONNECT();
memoryTest.execute();
