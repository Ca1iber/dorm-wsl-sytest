Timeout setup

When network latency occurs, you can use startTimeout, CI_START_TIMEOUT or HP83000_TIMEOUT to reduce the impact of transmission delay.

startTimeout
This variable is used in the SystemConfiguration.xml to control the process property. It defines the start process timeout. It is located in /opt/hp93000/soc/system/etc/SystemConfiguration.xml.

Set the variable as follows: 

<Property name="startTimeout" value="1000">
The default value of startTimeout is 100 seconds.
CI_START_TIMEOUT
This is an environment variable and it defines the timeout value for CI process startup. Its default value is 20.

Use it in the SmarTest startup command as follows: 

CI_START_TIMEOUT=300 HP83000_TIMEOUT=1200 /opt/hp93000/soc/prod_env/bin/HPSmartTest
HP83000_TIMEOUT
This is an environment variable and it defines the timeout value for SmarTest work center startup. Its default value is 120.

Use it in the SmarTest startup command as follows: 

CI_START_TIMEOUT=300 HP83000_TIMEOUT=1200 /opt/hp93000/soc/prod_env/bin/HPSmartTest

Functional changes

  1. Introduced in SmarTest 7.5.4
