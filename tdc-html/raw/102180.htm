DSP_RF_CW_FILTER()

This function exports the raw functionality of a cw power measurement

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_RF_CW_FILTER( const ARRAY_COMPLEX& source_data,
const INT averageNum,
const INT swDecimation,
COMPLEX* result)
Parameters

I/O

Parameter

Notes

I

sourceData

A complex array representing the captured waveform data.

I

averageNum

Averaging factor if average is used.

I

swDecimation

This parameter must be higher than 2.

O

*result

result array in raw complex form
