Selecting a Waveform for Editing

In order to edit a waveform, you have to select it first. This means selecting the test system cycle containing the waveform.

Click the appropriate test system cycle number in the cycle> row, refer to the figure below.

The system highlights in dark green:

  • the selected test system cycle for all device cycles if no device cycle is selected (all device cycles are in the setup mode),
  • the selected test system cycle in the selected device cycle (dev. cyc. in edit mode).

To clear the waveform (the highlighting switches off), click the same cycle number in the cycle> row again.

Refer back to Using Device Cycle Setup and Edit Modes.
