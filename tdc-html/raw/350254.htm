SmartRDI 7.5.3

This section summarizes software changes including new features and enhancements in SmartRDI 7.5.3.

Changes and new features

Category

 Description
General
  • rdi.pureGenerationMode() helps control the pure generation mode in a test suite only.
Alarm handling
  • New parameter GlobalDisableAlarmIth defines a global current threshold value in the Alarm setup file for globally disabling alarm handling actions.
  • New parameter DisableAlarmIth defines a current threshold value per pin in the Alarm setup file for disabling alarm handling on a specific pin.
  • New commands globalDisableAlarmIth() or disableAlarmIth() defines a current threshold value for disabling alarm handling globally or per pin.
Analog
  • getAnaResultHandle() retrieves the name of the analog result handler.
COGO
  • SmartRDI provides a new solution to retrieve cogo search result without the pathPin() command.
DC
  • New option TA::PF_ONLY to allow valueMode() work together with limit(min, max) for the cases when the burst pass/fail result of dynamic DC measurements on digital pins is required only.
  • New FVI16 connection state TA::FORCE_SENSE_LINK_KEEPcan keep the internal force to sense (FS) link closed after pattern execution.
  • BADC digitizing performance with trigger mode is optimized through a new internal transfer mode without any impact on existing test methods.
  • The default average values for both vMeas and iMeas of PPMU and BADC modules is changed. For vMeas, the average value is 16 now; for iMeas, the average value is not fixed but based on the iRange value.
EMAP
  • New API FFV() specifies a start cycle number for retrieving the first fail vector.
  • New API rdi.id().getFFV() retrieves the number of the first fail vector in pattern for a specified pin.
ROUTE
  • New parameter ROUTING_ACK_CHECK of the RDI_Configure file to enable or disable a check if the route state is applied successfully.
Runtime values
  • New parameter FAST_PPMU_LEVEL_TRANSFER of the RDI_Configure file to enable or disable DC fast download. This reduces the time required for high-site-count applications.

    For more information, refer to PPMU fast transfer mode of SmartRDI.
TMU
  • New API rdi.id().getTmuFinished() helps check whether TMU measurements have been finished or not.

Supported SmarTest versions

SmartRDI 7.5.3 supports SmarTest 7.5.3.
