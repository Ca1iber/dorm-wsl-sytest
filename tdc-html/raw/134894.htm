Topic 134894

Generating the (partial) lot summary file with the Datalog Control tool

About this task

Introduces how to generate the partial or complete lot summary with the Datalog Control tool. This is done in the File tab of Datalog Control tool.

Before you begin

The Datalog Control tool is started. A lot has been started and multiple executions of a testflow have been finished.

Procedure

  1. Open the File tab.
  2. To generate the partial summary file, click Get Partial Summary.

    The summary of the tested devices until now in this lot will be included in the summary file if it is not cleared. Otherwise the summary of the tested devices since last summary clearance will be included in the file.

  3. To generate the complete summary file for the lot, click End Lot.

    The summary of the whole lot will be included in the file if the summary has not been cleared. Otherwise the summary of the tested devices since last summary clearance will be included in the lot summary file.

  4. To clear the summary, click Reset Summary Counter.

    The summary for the previous executions in this lot will be cleared.

Results

The (partial) lot summary file is generated as you specified.

Functional changes

  1. Introduced in SmarTest 7.2.0
