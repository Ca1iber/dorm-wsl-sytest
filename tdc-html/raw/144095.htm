SPMU_PIN_TASK.connectState()

Specifies a connection state. The connection state defines the mode of connecting a pin to the DUT or defines the bandwidth and reaction time of the pin.

This member function is currently used only for the DC Scale DPS128/DPS64 cards and the DC Scale XPS256 card.

The functionality of the member function is different for the supported cards:
  • DPS128-HC: The function is used to select a voltage drop measurement on the force or return line.
  • XPS256: The function is used to select a voltage drop measurement on the force or return line.

Syntax

SPMU_PIN_TASK& connectState (const STRING& DPS128_connectionState);
SPMU_PIN_TASK& connectState (const STRING& XPS256_connectionState);
Parameters
Parameter Description
DPS128_connectionState The parameter defines some special measurement modes or (for compatibility) connection states.

This parameter is supported only for the HC variant of DPS128.

For the available options, refer to table DPS128_connectionState.
XPS256_connectionState

The parameter defines some special measurement modes or (for compatibility) connection states.

This parameter is supported only for XPS256 pins.

For the available options, refer to table XPS256_connectionState.
Available options of parameter: DPS128_connectionState
Option Description
"MEAS_KELVIN_HIGH" This connection state selects a voltage drop measurement.

The voltage drop is measured from the high force pogo pins (P#) of the channel to the high sense pogo pin (PS#).

For ganged channels, the voltage drop is measured on the master channel.

These connection states require that a voltage measurement mode like "IFVM" or "VFVM" has been selected by function SPMU_PIN_TASK.mode().

These connection states are available only for the HC variant of DPS128 / DPS64. For more information, refer to Voltage drop measurement in DPS128 / DPS64 functionality and features.
"MEAS_KELVIN_LOW" This connection state selects a voltage drop measurement.

The voltage drop is measured from the ground sense pogo pin (GS#) to the common ground (GND) pins of the channel.

For ganged channels, the voltage drop is measured on the master channel.
Available options of parameter: XPS256_connectionState
Option Description
"MEAS_KELVIN_HIGH" This connection state selects a voltage drop measurement.

The voltage drop is measured from the high force pogo pins (P#) of the channel to the high sense pogo pin (PS#).

For ganged channels, the voltage drop is measured on the master channel.

These connection states require that a voltage measurement mode like "CFVM" or "VFVM" has been selected by function SPMU_PIN_TASK.mode().

For more information, refer to XPS256 voltage drop measurement and XPS256 programming - Voltage drop measurement.
"MEAS_KELVIN_LOW" This connection state selects a voltage drop measurement.

The voltage drop is measured from the ground sense pogo pin (GS#) to the common ground (GND) pins of the channel.

For ganged channels, the voltage drop is measured on the master channel.
Return value
A reference to the SPMU_PIN_TASK object.

Example

The following example shows how to set the connection state.

SPMU_TASK spmuTask;

spmuTask.pin("...")
    ...
    ...
    .connectState("...")
    ;

Note: The example concentrates on the function described in this topic. More settings are required for an executable SPMU_TASK object.
