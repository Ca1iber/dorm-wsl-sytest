Topic 149064

comment()

Inserts a comment at a position of the vector.

Syntax

comment(const string &comment, int vecNum);
List of parameters

Parameter

Description

comment

The content to be added.

vecNum

The position of the vector.

See SMV_IGNORE_COMMENT, which can be used in the RDI_Configure file to globally disable comment output in pattern generation.

Examples

RDI_BEGIN();
  rdi.smartVec().pin("DATA1").writeData(0x54,8).comment("MSB",0).comment("LSB",8).execute();
RDI_END();
Note Adding comments significantly increases the time for pattern generation (first-run). To reduce the first-run time, you can remove the comment commands from your code after the pattern generation and debugging have been finished.

Related information

SmartRDI: Vector and protocol programming

Functional changes

  1. Introduced in SmartRDI 2.3.0
  2. SmartRDI 7.6.0: SMV_IGNORE_COMMENT in the RDI_Configure file can be used to globally allow comments output in pattern.
