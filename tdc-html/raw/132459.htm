TMU_PINS.setBThreshold()

Sets the voltage threshold for the second shot. If the number of shots is two and the voltage threshold for the first shot is set, the voltage threshold for the second shot must be set.

Syntax

TMU_PINS& setBThreshold(DOUBLE Bthr);
Parameter

I/O

Parameter

Description

I

Bthr

The voltage threshold of the second shot. The unit is Volt.

Return value

A reference to the TMU_PINS object is returned.

Related information

TMU_PINS.getBThreshold()

Functional changes

  1. Introduced in SmarTest 7.1.0
  2. SmarTest 7.1.1: Renamed to setBThreshold().
