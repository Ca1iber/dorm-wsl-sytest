DSP_A_DECODE

This API decodes the contents of a specified array using the A-law conversion method.

Encoding/Decoding Table for A-Law/µ-Law lists the decoding format of the A-law conversion used by this API. Also, refer to Code Format Tables for the two's complement and A-law code format.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_A_DECODE(ARRAY_I& src, ARRAY_D& result, 
             INT input_format);
DSP_A_DECODE(INT *src, DOUBLE *result, INT size, 
             INT input_format);
Parameters

I/O

Parameter

Description / Range

I

src

Source array

O

result

Decoded results

(size of result) = (size of src)

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src)

I

input_format

Input data format

CMPLM2: Twos complement

ALAW: A-law code format

ADI_ALAW: Alternative Digit Inverse (ADI) of A-law code format

Example

int array1[500];
double array2[500];
  .
  .
DSP_A_DECODE(array1, array2, 500, CMPLM2);

DSP_A_DECODE decodes INT array array1 , which contains 8-bit A-law data (two's complement code format), and returns the results to DOUBLE array array2. In this example, 500 elements in array1 are decoded.
