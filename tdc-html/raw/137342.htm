Topic 137342

Displaying test results in analysis views

Test results are displayed as analysis views by selecting summary rows in data navigation views and choosing the desired view type from the shortcut menu.

About this task

Display numeric data log summaries as graphs or tables to more easily detect interesting or problematic data points or get a global overview of the results.

Before you begin

Open a data log.

Procedures

Opening a result graphs for selected test results

  1. In the data navigation view of the data log, select the rows that you want to display in an analysis view.

    Depending on the type of view, different selections are required or possible:

    • Trend chart: One or more rows in a Test summary tab.

      If all rows share the same test suite, test method, and test, the limits are displayed in the graph.

    • Histogram: One or more rows in a Test summary tab. All rows must share the same test suite, test method, and test.

      If all rows share the same test suite, test method, and test, the limits are displayed in the graph.

    • Probability chart: One or more rows in a Test summary tab. All rows must share the same test suite, test method, and test.

      If all rows share the same test suite, test method, and test, the limits are displayed in the graph.

    • Box chart: One or more rows in a Test summary tab. All rows must share the same test suite, test method, and test.

      If all rows share the same test suite, test method, and test, the limits are displayed in the graph.

    • Scatter chart: Two rows in a Test summary tab. Both rows must share the same device. Additional conditions apply, as described in Scatter chart view.
    • Range chart (special scatter chart mode): Three or more rows in a Test summary tab. (Or two rows, followed by clicking the Switch button in the scatter chart.)
    • FFC Pareto chart: One row in a Test summary tab.
    • Protocol Monitor view: One or more rows that contain test results with the type Protocol in a Test summary tab.
    • Shmoo plot: One row that summarizes shmoo test results in a Test summary tab.

      See the description of the various modes in Shmoo graph modes for details of the available shmoo variants.

      Note that the data logs to be displayed as shmoo plots must have been created by SmarTest 7.2.0 or higher. The Integrated Result Tool cannot create shmoo plots from logs created with SmarTest 7.1.4 or earlier.

    • Parametric wafer map: One row in a Test summary tab.
    • Scan view: One row that contains test results with the type Scan in a Test summary tab.
    • Bin wafer map: One or more rows in a Wafer summary tab.

      If an analysis view of the desired type is already open, the selection is automatically displayed in that view, unless the view is pinned as described below. If no unpinned view is open, you must open the chart view as described in the next step.

      Note that there is a maximum number of rows that can be displayed in a chart at the same time. This number is set in the Result Tool preferences.

  2. Right-click the selected row and choose the desired view type from the Show In submenu of the shortcut menu.

    The selected data is displayed as a view of the chosen type.

  3. For parametric wafer maps and shmoo plots: Right-click the chart and choose from the Accumulation submenu of the shortcut menu whether you want to display the minimum, mean, or maximum test result values in the chart.
  4. For shmoo plots: Right-click the chart and choose the pin whose results you want to display from the Pin submenu of the shortcut menu and the result type from the Result Types submenu.
  5. If you want to freeze the data displayed in the analysis view, click the Pin button in the graph's toolbar.

    By default, an analysis view always displays the current selection in the frontmost data navigation view. If the selection changes, the display in the view changes as well.

    If you click the Pin button , this dynamic update is interrupted, and the analysis view continues to display the same data even if the selection in the summary tabs changes. Clicking the Link button unfreezes the update, and the display changes once again with the selection.

  6. If you are displaying the system data log stream in an analysis view, the view is by default not updated when new log entries arrive. if you want to enable dynamic updates, you can do so by choosing the appropriate shortcut menu commands:
    • In the Test summary tab, choose Auto Update Chart.
    • In the Wafer summary tab, choose Auto Update Wafer Chart.

      These commands do not apply to EDL or STDF data log files.

Opening an additional graph for the same data

If you already display data in a graph and you would like an additional graph of the same type (in which later to display different data), click the New button in the graph view.

Results

The selected information form the summary tabs is displayed as a graph of the chosen type.
