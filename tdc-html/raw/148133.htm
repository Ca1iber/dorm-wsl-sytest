Load capacitance connected to the DC Scale DPS128/DPS64

For the DPS128/DPS64, SmarTest automatically sets the performance range considering the value of the load capacitor(s) connected to the DUT power pin on the DUT board.

Entering a capacitance value in the C[uF] column of the DPS Pins editor has an effect for a DPS128/DPS164 channel in DPS mode.

For DPS128/DPS64 channels in PMU mode (SIG), you optionally can set the load capacitance in the DPS128/DPS64 hardware view in the LoadCap field and with the SPMU_PIN_TASK.loadCap() test method API function.

For the supported load capacitance ranges see Load capacitance range in DPS128-HC specifications.
