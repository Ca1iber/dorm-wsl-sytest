Pull-down resistor

For detailed information refer to Pull-down function.

Differential comparator single voltage threshold (vth)

The PS1600 comparator in differential mode supports the single threshold voltage vth.
Note The differential comparator also supports a dual voltage threshold, namely: vol and voh. For details, see the section "Differential comparator dual voltage thresholds (vol and voh)" below.
You can enable the comparator to operate in differential mode by specifying the keyword term center_tap in the level set. Specifying the threshold voltage (vth) is optional. If vth is not specified, the PS1600 defaults to 0V:
LEVELSET 1 "io_diff_ctrtap"
PINS P1@diff
#---------------------------
#Enable termination voltage
#---------------------------
term center_tap

You specify the single differential threshold (vth) for your differential measurement in the level set as shown below:

LEVELSET 1 "io_diff_ctrtap"
PINS P1@diff
#---------------------------
#Enable termination voltage
#---------------------------
term center_tap

vih = 1.8
vil = 0
#---------------------------
# Differential comparator single voltage threshold 
#---------------------------
vth = 0.9

Differential comparator dual voltage thresholds (vol and voh)

The comparator in differential mode supports dual differential thresholds, namely: vol and voh. For details on how to generally setup differential connections, see How to set up differential connections.
Note The differential comparator also supports a single voltage threshold, namely: vth. For details, see the section "Differential comparator single voltage threshold (vth)" above.

You can enable the comparator to operate in differential mode using the keyword term center_tap in your level set:

LEVELSET 1 "io_diff_ctrtap"
PINS P1@diff
#---------------------------
#Enable termination voltage
#---------------------------
term center_tap

Single-ended comparator dual voltage thresholds (vol and voh)

You specify the dual voltage thresholds (vol and voh) for your differential measurement in the level set as shown below:

LEVELSET 1 "io_diff_ctrtap"
PINS P1@diff
#---------------------------
#Enable termination voltage
#---------------------------
term center_tap

vih = 1.8
vil = 0
#---------------------------
# Differential comparator dual voltage thresholds 
#---------------------------
vt = 1.8
vol = -1
voh=1
