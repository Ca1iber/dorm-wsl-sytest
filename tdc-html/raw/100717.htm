Topic 100717

Creating a testflow

About this task

There are two methods to create the sequence of the testflow:

  • Use the Flow Sequence Editor to create the sequence of the testflow. Then use the Flow Data Editor to set up the attributes of all test suites.
  • Add the test suites and bins in the Flow Data Editor as floating test suites and floating bins. Then connect the floating test suites to the testflow. The floating bins can be used for the multi-bin.

You can use either method or combine both methods to create the testflow. This topic describes the first method.

Before you begin

Make sure that

  • All the test setups have been loaded.
  • All the required test methods have been built.

Procedure

  1. In the Test Program Explorer view, right-click the testflow item and select New.

    The New Testflow window opens.

  2. In this window,
    1. Enter the testflow name. The directory of the testflow file is automatically set to device_directory/testflow and uneditable.
    2. The Ignore unsaved setup check box appears in the New Testflow window when some loaded setup files are changed and unsaved. Select this check box.
    3. Click Finish.
  3. Open the Flow Data Editor for the new created testflow.
  4. On the Setups page of the Flow Data Editor, select and load the setup files. (See Selecting setup files.)
  5. In the Flow Sequence Editor, create the sequence of the testflow:
    1. Insert the first test suite into the testflow. (See Inserting a test suite in the testflow.)
    2. Copy the first test suite and paste it where you want it to be. The name of the second test suite is the name of the first test suite plus a number. Edit this name as desired. (See Cutting, copying & pasting nodes.)
    3. Insert the other test suites in the same way.
    4. Insert the bins in the same way: insert the first bin, copy and paste it to create the other bins, then change the bin names. (See Inserting a bin in the testflow.)

      Now the attributes of all the test suites are the same. And so are the bins. You need to modify their attributes according to the test plan.

  6. In the Flow Data Editor:
    1. Edit the attributes of the test suites and bins. (See Editing a test suite in the Flow Data Editor.)
    2. Set the test suite flags, testflow flags, and system flags.
  7. Save the testflow. (See Changing setup data and saving the changes.)

Results

The testflow has been created.

Debug the testflow.
