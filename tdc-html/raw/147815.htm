Migrating DPS32 cards

To be able to migrate a device test from a DPS32-based test system, power requirement calculations for the new DPS64 and DPS128 must be made. The configuration files for model, limits, and pin configurations from the DPS32-based test system are used as the inputs for the DPS128 Power Calculator, which calculates the required:

  • DC-Scale cards
  • Pogo cable assembly types
  • power per domain

The recommended card position and detailed information about pin usage is also displayed by the DPS128 Power Calculator.

To calculate the power requirements for the DPS64 and DPS128 cards to replace existing DPS32-based cards, complete the following steps:

  1. Load the configuration files for model, limits, and pin configuration from the DPS32-based test system using the load file browser (File > Load menu items).
  2. To display which files are currently selected, click Loaded files.
  3. Click the Calculate button to determine the required DPS128 cards and cables assemblies.

    Domain power results displayed against a green background are within the available power for the selected card. If the available power is exceeded, the power requirement values are displayed on a red background.

    Selections that are within the overall power availability, but cannot provide sufficient power for individual pins, result in the affected pin data being displayed against a red background. For each affected pin, a tooltip provides information about the underlying problem.

    Note Alternative arrangements of cables may also be possible. Change the cable type for a DC-Scale card selection to check for valid alternatives. Selecting a different pogo cable assembly might result in an alternative DC-Scale card selection.
  4. Optional: Select a global safety margin value from the Margin dropdown.

    The total power available per domain is recalculated and displayed in the top line of the DPS128 Power Calculator main window. If you select a margin value before clicking Calculate, the calculating is executed simultaneously.

  5. Optional: Export the calculated results in CSV format to a file using the export file browser (File > Export menu).
