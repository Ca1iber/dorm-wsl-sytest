Interfacing the test system to Accretech UF3000 EX wafer prober

Subtopics

  1. Hiding the wafer prober chuck
  2. Deinstalling Direct-Probe bridge beam from Accretech UF3000 EX wafer prober
  3. Bridge beam installation on Accretech UF3000 EX prober - Overview

This section takes you through the steps needed to interface the V93000 test system with the Accretech UF3000 EX wafer prober.

You need to:

  1. prepare the wafer prober for the installation of a special piece of hardware called the Direct Probe™ Bridge Beam
  2. install the Direct Probe™ Bridge Beam hardware in the wafer prober
  3. load a DUT board into the wafer prober.
