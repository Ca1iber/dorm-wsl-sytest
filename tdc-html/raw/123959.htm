Topic 123959

Scan Setups

During device migration,you will scan your testflow or test program to detect potential migration items in advance. You can then fix them according to the resolution description. This step will help to minimize the migration gap during load or execution.

About this task

The following migration items will be detected by scanner:

  • Test method project uses obsolete Redhead Linux 3
  • Test method project uses obsolete Classical Test Method
  • Test method project uses obsolete User Procedure
  • Testflow uses obsolete Test Function and Classical Test Method
  • Timing uses obsolete EEdge
  • Timing uses obsolete MultiPeriod device cycle
  • Timing uses obsolete logical waveform
  • Vector uses obsolete CMM pattern
  • Vector uses obsolete F330 scan style
  • Vector uses Logical waveform
  • The hp83_to_stdf formatter is obsolete
  • The relevant firmware is obsolete

Before you begin

Ensure that SmarTest is running and a cheat sheet is open.

Procedure

  1. Open the "Screener"
  2. Click Click to perform button to start the scan process. The scan result will be listed in the "Migration Items" view.
  3. Switch to the "Migration Items" view and analyze the results.
  4. Select related item and browse for detail information and resolution.
  5. Fix migration item according to resolution description, conversion tool and TDC document support.
