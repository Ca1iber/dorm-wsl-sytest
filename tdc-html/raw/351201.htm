PS1600 card configuration in the model file

The pogo pins are mapped in the POGOCABLING section of the model file as follows:

Standard-density pogo blocks

Type SD is used for PS1600 pogo cable assembly E8030PSD: 8 SD pogo blocks and for PS1600 pogo cable assembly E8030PSDL: 8 SD pogo blocks.

The default pogo block sequence and the sequence for type SD is defined as follows:

"A,  B,  C,  D,  E,  F,  G,  H"

The following example shows the allocation of eight standard-density pogo blocks:

POGOCABLING

    101: pogoblocks = "101 - 108"

or 

POGOCABLING

    101: pogoblocks = "101, 102, 103, 104, 105, 106, 107, 108"

The eight pogo blocks A ... H are mapped to pogo block positions "101" … "108". The code type = SD is optional for the standard-density pogo block.

High-density (HD) pogo blocks

Type HD4x32 is used for the PS1600 pogo cable assembly E8030PHD: 4 HD pogo blocks.

For channels A1 … A16, the same mapping is used as for the standard-density pogo block. The additional channels B1 … B16 are mapped to virtual pogo blocks. The number of a virtual pogo block is defined by the position of the physical pogo block plus an offset of 400.

The pogo block sequence for type HD4x32 is defined as follows:

"A,  B,  C,  D,  A+400,  B+400,  C+400,  D+400"

The following example shows the allocation of four high-density pogo blocks:

POGOCABLING

    101: pogoblocks = "101, 102, 103, 104, 501, 502, 503, 504", type=HD4x32
Channels A1 … A16 on block A … D are assigned to pogo blocks "101" … "104" while additional channels B1 … B16 of the same physical blocks are assigned to virtual pogo blocks "501" … "504".

Note that although you use only four physical high-density pogo blocks for the 128 pins, you need to define four more virtual pogo blocks to cover the additional pins B1 … B16.

For type HD4x32, you must enter the same physical and virtual pogo blocks also in the IOCHANNEL section of the model file as shown in the following example:
IOCHANNEL

    10101-10416:HW = PS1600, speed = ...
    50101-50416:HW = PS1600, speed = ...
Very-high-density (VHD) pogo blocks
Type VHD1x128 is used for the PS1600 pogo cable assembly E8030PVHD: 2 VHD pogo blocks.

Each physical pogo block covers four logical boards and needs three additional virtual pogo blocks defined with an offset of 400, 32 and 432.

The pogo block sequence for VHD1x128 is defined as:

"A,  A+400,  A+32,  A+432,  B,  B+400,  B+32,  B+432"

Example:

POGOCABLING

    101: pogoblocks = "101, 501, 133, 533, 102, 502, 134, 534", type=VHD1x128
For type VHD1x128, you must enter the same physical and virtual pogo blocks also in the IOCHANNEL section of the model file as shown in the following example:
IOCHANNEL

    10101-10216:HW = PS1600, speed = ...
    50101-50216:HW = PS1600, speed = ...
    13301-13416:HW = PS1600, speed = ...
    53301-53416:HW = PS1600, speed = ...

Functional changes

  1. Introduced in SmarTest 7.1.0
  2. SmarTest 7.3.2: Support of PS1600B
  3. SmarTest 7.5.4: Pogo pin assignment for the "Very-high-density (VHD) pogo cable assembly" added.
