rdi.oreFile()

Specifies a path to save ORE files when ORE is applied.

It overrides the ORE setting with ORE_FILE in the RDI_Configure file for the related test suite. If a relative path is used, the path must be under the current device folder.

You can set up different ORE files in rdi.oreFile() in each run of a loop. See the example below.

Syntax

rdi.oreFile(string oreFilePath);
Parameters

Parameter

Description

oreFilePath

Specifies a path to store ORE files.

Examples

rdi.enableOre(true);
rdi.oreFile("./myORE.xml"); // under the device folder.
            
RDI_BEGIN();
  ...
RDI_END();
            
rdi.id().getXXX();
Setting multiple ORE files in rdi.oreFile() in each run of a loop:
virtual void run()
{
  RDI_INIT();

  CONNECT();

  static int i = 0;
  string oreFile[4];

  oreFile[0] = "./demo1.xml";
  oreFile[1] = "./demo2.xml";
  oreFile[2] = "./demo3.xml";
  oreFile[3] = "./demo4.xml";

  rdi.enableOre(true);

  rdi.oreFile(oreFile[i]);

  ON_FIRST_INVOCATION_BEGIN();

    RDI_BEGIN();
      rdi.emap("emap").label("funcPass").pin("DATA2").failCount(2).execute();
    RDI_END();

    i++;

  ON_FIRST_INVOCATION_END();

  cout<<"in run "<<i<<" , ore getFailCout result"<< rdi.id("emap").getFailCount()<<endl;

  return;
}
