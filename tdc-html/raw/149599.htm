matchBit()

This function specifies the bit stream you want to write to the vector, the starting vector, and the maximum number of loops to be executed.

Syntax

matchBit(ARRAY_I bitStream,int startBit,int maxLoopNum)
List of parameters

Parameter

Description

bitStream

The bit stream to be written to the vector.

startBit

The starting position of the vector to be included in the match loop.

maxLoopNum

The maximum number of loops to be executed.

Functional changes

  1. Introduced in SmartRDI 2.4.0
