Topic 103806

Level control API

Subtopics

  1. StartLevel()
  2. LoopLevel()
  3. CompleteLevel()

If you want to maintain the application model file level structure in the BLC, you can use the level control APIs.

If no level structure is maintained but the level related events need to be issued, the level information should be provided as input parameters to the event generation API. (See IssueEDLEvent() and IssueHVMExecutionEvent())

Functional changes

  1. Introduced in SmarTest 6.5.0
