Topic 10681

Set

The Set subcommand is used to define a list. It is used to specify how many elements are in the list, and what they are.

There are two definitions used to determine a list, Equation and Values.

Syntax

DDEF {"ListName"},{Set},{"DefinitionType"},{"Equation"}

Parameters

ListName

User-defined unique name to identify what type of data list is being defined. It is a string without a ".".

Set

Set is used to create a new object.

DefinitionType

This is a predefined keyword. The available types are Equation and Values.

Equation: List Equation used to define a list. See Equation Definition Type.

Values: List of Values used to define a list. See Values Definition Type.

Equation

This can be a list of elements separated by a space or spaces, or a predefined function. All functions must be placed in quotes.

Functional changes

  1. Introduced before SmarTest 6.3.2
