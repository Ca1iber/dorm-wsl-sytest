Topic 95292

Non-transparent x-modes

Subtopics

  1. Introducing x-modes
  2. X2 mode example (for SRAM)
  3. X4 and x8 mode example (for GDDR)

Earlier releases of MTL supported x-modes in a different way than the current release, requiring users to create specific device accesses for each x-mode they wanted to use. This made x-mode programs both harder to use and maintain as well as more difficult to read.

While the MTL compiler still supports these non-transparent x-modes, we strongly suggest that you do not create new programs that use them. Use the much more convenient transparent x-mode instead.

Note that non-transparent x-modes are not compatible with Counted match loops.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. MTP 2.6.6: Non-transparent x-modes are incompatible with match loops
