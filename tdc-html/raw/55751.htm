Topic 55751

PPMU_CLAMP

Subtopics

  1. PPMU_PIN_CLAMP

The PPMU_CLAMP class is a data container holding the contents of the task for setting up the voltage clamp circuit of pin PMUs. This class can be used to call the PPMU_PIN_CLAMP class that is a subsidiary data container to specify the setup of the voltage circuit per pin.

Note This class can only be used for Pin Scale systems. It is needed for DC tests that force the current and measure the voltage if they are defined with the DC task API's PPMU_SETTING, PPMU_RELAY, PPMU_MEASURE, and TASK_LIST.

Tasks defined with this class will be performed with the execute() member function of the TASK_LIST class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PpmuClamp.h.

Class definition

Constructor:

PPMU_CLAMP();

Member Functions:

PPMU_PIN_CLAMP & pin(const STRING& pinlist);
wait(const DOUBLE time);
void syncWait(DOUBLE time);

Constructor

PPMU_CLAMP

PPMU_CLAMP();

This constructor defines a task that is a set of clamp operations.

Note Do not create static objects of the class in the test method and do not create test method member variables from this class.

Syntax

For creating an object:

PPMU_CLAMP <object>;

For setting up clamp operations:

<object>.pin("pinlist").<member_func>;

For setting a wait time from when the execution of the task defined with the PPMU_CLAMP is started:

<object>.wait(time);

<object>

Object name to be defined

pinlist

Target pin name or pin group name. You can specify multiple pins and pin groups by separating with a comma or using "@" which means the all PPMU pins. "@" includes the digital pins that are wired to an analog module on the DUT board for a trigger source.

<member_func>

Member functions of the PPMU_PIN_CLAMP class to control the clamp operations.

time

Specifies the wait time for the start of the following task.

The execution of the following task will be started after the wait time.

Member functions

pin()

PPMU_PIN_CLAMP & pin(const STRING& pinlist);

This function returns the reference to the PPMU_PIN_CLAMP class object that represents the clamp operations for the specified pin. To add an action to the task, use the member functions of the PPMU_PIN_CLAMP class.

Parameter

pinlist

Target pin name or pin group name. You can specify multiple pins and pin groups by separating with a comma or using "@" which means all PPMU pins. "@" includes the digital pins that are wired to an analog module on the DUT board for a trigger source.

wait()

void wait(const DOUBLE time);

For setting a wait time from when the execution of the next task is started.

Parameter

time

Wait time after the PPMU_CLAMP task. The default unit is [s].

syncWait()

void syncWait(DOUBLE time);

This function sets the waiting time for the sequencers before the execution of the measurement.

Parameter

time

The time to wait. Default unit is [s]. The time usually needs to be set as the value euqaling to period*250.

Example

IFVM and VFIM test

PPMU_SETTING   ppmuSetting;
PPMU_RELAY     ppmuRelay_on, ppmuRelay_off;
PPMU_MEASURE   ppmuMeasure;
PPMU_CLAMP     ppmuClamp_on, ppmuClamp_off;
TASK_LIST      taskList_1;

ON_FIRST_INVOCATION_BEGIN();

    //
    // Setups for PPMU
    //
    ppmuSetting.pin("S0").iRange(1 mA).min(0 V).max(4.3 V).iForce(10 uA);
    ppmuSetting.pin("S1").iRange(10 mA).min(-10 uA).max(30 uA).vForce(3.3 V);

    //
    // Relay setups
    //
    ppmuRelay_on.pin("S0,S1").status("PPMU_ON");
    ppmuRelay_on.wait(1.3 ms);
    ppmuRelay_off.pin("S0,S1").status("AC_ON");

    //
    // Measurement setups
    //
    ppmuMeasure.pin("S0,S1").execMode(TM::PVAL);

    //
    // Hardware specific programming to avoid hot switching on the current force setup
    //
    ppmuClamp_on.pin("S0").status("CLAMP_ON").low(2.6 V).high(2.9 V);
    ppmuClamp_off.pin("S0").status("CLAMP_OFF");

    //
    // Build and execute the task list
    //
    taskList_1.add(ppmuSetting)
              .add(ppmuClamp_on)
              .add(ppmuRelay_on)
              .add(ppmuClamp_off)
              .add(ppmuMeasure)
              .add(ppmuRelay_off);

    taskList_1.execute();

ON_FIRST_INVOCATION_END();

//
// Result upload and Datalog
//
double VMeas, IMeas;

VMeas = ppmuMeasure.getValue("S0");
IMeas = ppmuMeasure.getValue("S1");

TEST("DC_Test",ppmuMeasure, true);

In this example, a PPMU IFVM test on the pin S0 and a PPMU VFIM test on the pin S1 are performed in parallel. For Pin Scale test system, clamp is used to avoid hot switching in the IFVM test.
