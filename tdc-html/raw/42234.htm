Topic 42234

Parameter: tel_o_command_style

Some models of TEL or KLA probers (basically certain 10xx or 20S models installed in the USA) may use a different style for the answer to the GPIB command 'O'.

Most of the models return a binary coded format, using one character for any group for 4 probes ("encoded" style answer). The length of the result string then depends on the number of probes. The prober models named above may use an ASCII string made of '0' and '1' instead ("ascii" style answer). In this case, each position of the string refers to one probe.

This parameter specifies the format of the answer string.

Driver default: "encoded"

Changeable at run-time: no

Applicable for: TEL probers

Applicable for: probers

Used by plug-in: TEL

Example: tel_o_command_style: "ascii"
