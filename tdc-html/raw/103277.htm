Topic 103277

Install WPI DUT board on wafer prober interface

About this task

This task is about mounting the WPI DUT board onto the wafer prober interface.

Before you begin

Ensure you have mounted the probe card stiffener into the mounting ring.

Procedure

  1. Place the DUT board on the wafer prober interface.
  2. Lock it in place with the two locking levers.
  3. Adjust the height of the adapter plate kit to compensate for the thickness of the DUT board PCB.
    1. Raise the height of the adapter plate slightly by evenly turning out all four adjustment screws.
    2. Push out all four black levers so they click in.
    3. Using a flat head screwdriver, turn each adjustment screw on the adapter plate until the black levers touch the WPI DUT Board stiffener. This gives the correct height.
    4. Lock each adjustment screw by bringing up the serrated lock ring.
