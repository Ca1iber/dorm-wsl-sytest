WRST - (Waveform ReSeT)

The WRST (Waveform ReSeT) command resets all timing sets and waveform definitions in the system data base for the specified waveform set and for all pins, and updates the hardware.

Syntax

WRST {waveform_set}

Parameters

waveform_set

Waveform set number. Enter an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by WSUS, WSUS? - (Waveform Sets USed).

Application

Timing setup, see Timing Setup Commands.

Errors

There are no error messages.

Example

WRST 3

This example resets all waveform and timing entries for all pins for waveform set 3.

Functional changes

  1. Introduced before SmarTest 6.3.2
