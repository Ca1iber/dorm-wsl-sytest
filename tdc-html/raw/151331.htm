iFilter()

Sets the filter frequency of the force or clamp current filter.

This function is only for the DC Scale XPS256 card. The function can be used in the code‑based mode. In addition to that, it can be used in the pattern‑based mode for XPS256 pins in PMU operating mode.

The set value defines a bandwidth filter that has an effect on the dynamic behavior of an XPS256 pin that is forcing or clamping the current.

Syntax

dcBase& iFilter(double iFilter);
Parameter

Parameter

Description

iFilter

Defines the filter frequency in Hertz (Hz).

Programmable double values are

  • Value between the card-specific minimum and maximum value: The filter is switched on and set to the defined filter frequency.
  • 0.0: The filter is set to the card-specific default value.
Card-specific range and default value:
  • XPS256: Refer to section Dynamic behavior in XPS256 programming - Force and clamp currents.

Return Value

A reference to the dcBase object.

Example

rdi.dc().pin("Pin_1")
        .iForce(30.0 mA)
        .vClamp(-1.0 V, 15.0 V)
        .iSlewRate(2.0 mA)
        .iFilter(5.0 kHz)
        .execute();
