Using the DPS128 Power Calculator

Subtopics

  1. Configuring a new DPS128 test system to test a new device
  2. Setting up an existing DPS128 test system to test a new device
  3. Calculating the power consumption of installed DPS128 cards
  4. DPS128 Power Calculator - Menus and buttons
  5. Migrating DPS32 cards

The DPS128 Power Calculator is a tool to help you to:

  • Configure a new DPS128 test system to test a new device
  • Check and enhance an existing DPS128 test system to test a new device
  • Migrate from DPS32 cards to the DPS64 and DPS128 cards

Download of the DPS128 Power Calculator

For downloading the DPS128 Power Calculator, follow these instructions:
  1. Open the Advantest Software Center in a browser: https://softwarecenter.advantest.com/

    Login with your credentials.

  2. Download the Power Calculator from the Advantest Software Center: https://softwarecenter.advantest.com/.

    The Power Calculator located under SmarTest Addons > PowerCalculator.

  3. Scroll to and select the version you want to install ( for example, 2.1.1) and expand to display the details.

  4. Select the required operating system.
  5. Expand the release version.

  6. Download the Power Calculator package by clicking the icon.

    The download dialog for the package is displayed.

  7. Download and save the package by clicking OK and if requested, specify a destination folder.

    The selected Power Calculator package is downloaded to your browser's download folder.

Starting the DPS128 Power Calculator

Start the DPS128 Power Calculator:
  • Windows: Double-click the PowerCalc.jar file.1)

  • Linux: Open a shell window, browse to the location of extracted PowerCalc.jar file and start the program from the command line. The default command is

    • java -jar PowerCalc.jar

    To find the location of your Java installation, enter the command: whereis java

Data entry in SmarTest 7

Input data includes pin configuration files and DC scale limits files that you typically export from your existing test system using the export functionality of SmarTest as follows:

  1. From the Test Program Explorer open Pins > Pin Settings, right-click an item, for example, DPS Pins, and choose Export. The Export 93000 Setup window opens.
  2. In this window, click Browse. The Enter or Select File to Export window opens.
  3. Enter a file name, choose the location to which the CSV file should be saved and click OK. You return to the Export 93000 Setup window.
  4. In the Setups section, choose the items you want to export, for example DPS Pins, and then click Finish.
  5. Repeat the above steps for the DC Scale Limits.
  6. Now you can open the CSV file using a spreadsheet program or a text editor to check its content.

If required, you can edit the resulting CSV-format files using common office tools such as Microsoft Excel or Apache OpenOffice.

Manual creation and editing of pin data can also be done directly in the Pin Data table of the DPS128 Power Calculator. You can directly import and load these exported or modified files into SmarTest.

Note Model files are exported using a SmarTest format and can be imported and used as the model file for the new test system.
1) The Java Runtime Environment (JRE) must already be installed.
