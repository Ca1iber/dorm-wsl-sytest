Installing the line model encrypted database

The line model encrypted database (smartest_aslmedb*) is required to add a DSL-tag to the device license file.

About this task

Perform this procedure to install the database for the first time or update to a new version.

You can find the line model encrypted database (ASLMEDB) installer package on the same server as the SmarTest installation packages. For details please check with your Advantest representative.

Before you begin

You must have root access rights on your computer.

Procedure

  1. Log in as root.
  2. Copy the line model encrypted database installer package to your computer.
  3. Open a terminal window and change to the directory containing the installer package.
  4. Type and execute the command:

    rpm -ivh <package_name>

Results

The line model database is installed and ready to use. The name of the database is smartest_aslmedb*, followed by version information.

What to do next

Next you can generate a device license file.
