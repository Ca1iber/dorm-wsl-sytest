GET_CURRENT_SEMI_PARALLEL_GROUP_NUMBER()

Gets the ID of the semi-parallel group being tested.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SemiParallelConfig.h.

Syntax

int GET_CURRENT_SEMI_PARALLEL_GROUP_NUMBER();

List of parameters

There are no parameters.

Return value

The ID of the semi-parallel group being tested is returned.

Example

The following example utilizes optional pairs of curly brackets "{" and "}" for the "first-invocation block" and for the "semi parallel test block". These optional curly brackets enclose the complete code within the blocks and are used for simplifying the correct indentation with assistance of the related Eclipse tool.

//
// Define the semi-parallel test configuration
//
SEMI_PARALLEL_CONFIG semiParallelConfig1, semiParallelConfig2;

semiParallelConfig1.group(1).add(1).add(3).add(5).add(7);
semiParallelConfig1.group(2).add(2).add(4).add(6).add(8);

semiParallelConfig2.group(1).add(1).add(2).add(3).add(4);
semiParallelConfig2.group(2).add(5).add(6).add(7).add(8);

ON_FIRST_INVOCATION_BEGIN();
{
    ARRAY_D testResult[GET_CONFIGURED_SITES(configuredSites)];

    //
    // The first semi-parallel execution block begin.
    //
    // The 8 sites are split into two groups:
    //
    //     Site 1, 3, 5, 7 will be tested in the 1st iteration of the semi-parallel loop.
    //     Site 2, 4, 6, 8 will be tested in the 2nd iteration of the loop.
    //
    FOR_SEMI_PARALLEL_TEST_BEGIN (semiParallelConfig1);
    {
        //
        // Statements work for each semi-parallel test group.
        //
        Routing.pin("Aout").connect(TM::SINGLE);
        Analog.DGT("Aout").enable();

        EXECUTE_TEST(0.1 sec);

        //
        // Statements which only work for active site in semi-parallel test group 1
        //
        if (GET_CURRENT_SEMI_PARALLEL_GROUP_NUMBER() == 1)
        {
            ...
            ...
        }

        //
        // Loops over each active sites in current semi-parallel test group to
        // retrieve the test result.
        //
        FOR_EACH_SITE_BEGIN();
        {
            testResult[CURRENT_SITE_NUMBER() -1] = Analog.DGT("Aout").getWaveform();
        }
        FOR_EACH_SITE_END();
    }
    FOR_SEMI_PARALLEL_TEST_END();

    //
    // Second semi-parallel execution block
    //
    FOR_SEMI_PARALLEL_TEST_BEGIN (semiParallelConfig2);
    {
        //
        // Statements to be executed for the second configuration
        //
        ...
        ...
    }
    FOR_SEMI_PARALLEL_TEST_END();
}
ON_FIRST_INVOCATION_END ();
