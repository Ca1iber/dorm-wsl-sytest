Appendix B: Man Pages for Driver Functions

If you have unpacked the driver sources, as described in Unpacking the Driver and Hook Sources, man pages are available for all driver functions defined in the header files which are located in the directory

... /GenericHandler/include

or

... /GenericProber/include

For example, these are the driver functions to be called from the application model, the hook functions, and the functions of the driver interface to CPI calls.

The man pages are provided in the directory

... /GenericHandler/man

or

... /GenericProber/man

Man pages contain information about what the function does, its parameters, and its (possible) return values.

Man pages may be read with the man command or with the nroff command, for example

nroff -man .../GenericHandler/man/phStateGetSiteInfo.3
