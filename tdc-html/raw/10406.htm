Executing Firmware Commands from a Command File

In fw-hpt, you can put a sequence of commands into a file and pass this file to hpt. The following is an example for such a command file:

APTS "test_1",MAIN,"spec_search_wtb"
TSTL "test_1",
INSI 2,1
SQLA ,"test_1","PARA_MEM=SM"
SQPG 2,GENV,8,,SM,(@)
VECD PARA,SM,0,8,(S0_1),00001001 00001000 00000111 00000110 00000101 00000100 00000011 00000010

This command sequence creates a test label that generates 8 waveforms and has its vector areas in the Sequencer Memory. The command number 2, which is specified in both the INSI and the SQPG command, presupposes that this is the first label in the actual vector setup file.

In order to execute a command file, enter its name at the fw-hpt prompt with one of the two prefixes ! (exclamation mark) or < (less than). There are two prefixes because fw-hpt has two modes for commands that read and write binary data.

If you use the < prefix, fw-hpt assumes that the binary commands are in normal mode. If you use !, is is assumed that the binary commands specify their input in the so-called binary mode (which is the case with the VECD command in the above example). For more information on these two modes see Storing and Retrieving Binary Data.
