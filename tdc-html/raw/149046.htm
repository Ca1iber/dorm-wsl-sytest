expectBit()

Specifies the expected bit stream from the captured pin. If an ID and expectBit() are used together, the result of pass/fail per label will be retrieved.

Syntax

expectBit(ARRAY_I bitStream,int startBit=0);
expectBit(string rtv, int startBit=0); // For runtime setup

Relationship of bit to DVC:

  • X1 mode: bit 0 to DVC "L", 1 to "H", and 2 to "X".
  • Xn mode: 0101 to "LHLH" and 0112 to "LHHX".
SmartRDI always deals with 0, 1, and 2 for DVC "L", "H", and "X".
List of parameters

Parameter

Description

bitStream

The expected bit stream you need to get from the captured pin.

startBit

The starting position of the bits to be compared. If the startBit parameter is not specified, the default value is 0.

rtv

The value to be used at runtime.

Example

ARRAY_I bitStream(4);
bitStream[0]=1;
bitStream[1]=0;
bitStream[2]=1;
bitStream[3]=1;

ON_FIRST_INVOCATION_BEGIN();

RDI_BEGIN();
  rdi.smartVec(1).pin("DATA7").expectBit(bitStream,2).execute();
RDI_END();

ON_FIRST_INVOCATION_END();

int pf_result=rdi.id(1).getPassFail();
