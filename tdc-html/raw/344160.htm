EVENT_RDM.getAverages()

Queries the number of internal samples to average.

The value is read from the corresponding EVENT_RDM object and returned as an EVENT_VALUE_INT object.

Syntax

void getAverages(EVENT_VALUE_INT & samples) const;
Parameter
Parameter Description
samples Number of internal samples from which the average is created.
Return value
There is no return value.

Example

For an example see EVENT_RDM.

Related information

EVENT_RDM.averages()

Functional changes

  1. Introduced in SmarTest 7.5.0
