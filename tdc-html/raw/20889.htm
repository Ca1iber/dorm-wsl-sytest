Retrieving Functional Test Results

To retrieve a result of functional test, use the GET_FUNCTIONAL_RESULT API. It returns the latest functional pass/fail result. For example, use this API as follows:

FUNCTIONAL_TEST();
INT rslt = GET_FUNCTIONAL_RESULT(pin);

where, pin is a pin name to retrieve the test result. If pin is omitted, the GET_FUNCTIONAL_RESULT API returns the global pass/fail result of the functional test. For details, see GET_FUNCTIONAL_RESULT. Generally, the global pass/fail result of the functional test is directly judged using the TEST API. In this case, you do not have to use the GET_FUNCTIONAL_RESULT API.
