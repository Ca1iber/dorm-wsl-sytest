Topic 136541

Displaying the shmoo plot of a shmoo test suite

The Shmoo Tool can display the shmoo plot of a shmoo test suite only after you have transferred the setups of the shmoo test suite into the Shmoo Tool.

About this task

However, the Shmoo Tool cannot display the shmoo plots for a running shmoo test suite or a testflow. To view these shmoo plots, use the Integrated Result Tool. For details, see Interaction with the Integrated Result Tool.

Before you begin

  • Make sure a shmoo test suite has been set up in the testflow you want to load.
  • Load such testflow with its full setups and open it with Flow Sequence Editor.
  • Open the Shmoo Tool.

Procedure

  1. In the testflow, right-click the shmoo test suite, select Shmoo > Show In Shmoo Tool.
    • A new shmoo page opens in the shmoo editor with the name "<the shmoo test suite name>_shmoo".
    • All setups of the shmoo test suite are transferred to the Properties view related to this shmoo page.
  2. In the Shmoo Tool, execute the shmoo test.

Results

  • The shmoo plot shows up in the shmoo page.
  • When you click the shmoo page in the Shmoo Tool, the shmoo test suite in the testflow is highlighted automatically.
  • When you select the shmoo test suite in the testflow, the corresponding shmoo page in the Shmoo Tool opens automatically.

What to do next

You can:

  • Zoom this plot.
  • View the shmoo plots of different result pins.
  • View the shmoo plots of different test results.
  • Views the shmoo plots of different sites.
  • Take a picture of this shmoo plot with its setups.
  • Debug this shmoo test through modifying the settings in the Properties view.

Functional changes

  1. Introduced in SmarTest 7.2.0
  2. SmarTest 7.2.1: The Shmoo Tool dose not display shmoo plots for a running test suites nor displays the shmoo plots during the execution of a testflow.
  3. SmarTest 7.2.1: After you transferred a shmoo test suite to the Shmoo Tool, the shmoo test suite and the corresponding shmoo page are linked. If you clicke, the other one is selected automatically.
