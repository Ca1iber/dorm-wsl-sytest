Topic 130389

Validating a protocol definition

Once a protocol has been defined from scratch or an existing one has been modified its definition should be checked for formal errors.

About this task

This task describes how to validate a protocol definition using the protocol's Build feature within the Protocol Editor or the Test Program Explorer.

Before you begin

Ensure you have followed either of the descriptions Setting up the protocol definition or Modifying an existing protocol definition.

Procedure

  1. Follow either of the two options:
    1. In the Protocol editor, right-click the protocol icon and select Build.
    2. In the Test Program Explorer, right-click the Protocols node and select Build all to validate all protocols loaded.
      Note If you select a single protocol here, you can perform a build on that protocol only.
  2. If the icons in the details area of the Protocol editor indicate an error, either
    1. click through the elements of the protocol's definition showing an error or
    2. check the Problems View for Protocol Marker type of errors alternatively.
  3. Resolve the issues described in the Description column of the Problems view.
    Note The problem description will also be displayed when moving the mouse over the problem highlighted int the Protocol editor.

Results

You have performed a pre-execution build to identify generic protocol definition problems and resolved them.
