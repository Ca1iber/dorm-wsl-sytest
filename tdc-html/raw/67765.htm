Memory test pattern definition elements

Subtopics

  1. Defining memory test patterns with multiple data words
  2. Define the address stepping sequence
  3. Define the memory device operations performed on each step
  4. Define the data word used by each operation
  5. Define the data sequencing
  6. Defining memory test patterns for devices with data latency
  7. Defining memory test patterns for devices with a burst data mode

The following basic elements need to be defined for a memory test pattern.

  • Define the address stepping sequence.
  • Define the memory device operations performed on each step.
  • Define the dataword used by each operation.
  • Define the data sequencing (for example solid or checkerboard).
  • Defining memory test patterns using x-modes.
  • Defining memory test patterns for devices with data latency.
  • Defining memory test patterns for devices with a burst data mode

The memory test language syntax supports the definition of each of the elements listed above.
