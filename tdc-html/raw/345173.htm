Alarm handling commands

SmartRDI provides alarm checking commands to specify alarm sets, enable or disable alarm checking on pins, and set limit values.

These commands are described in other individual topics. For detailed information, click the command name in the Function column to go to its specific topic.
Overview of alarm handling functions - Table I
Function Description Mode
rdi.alarm().applySet() Specify an alarm set. P, C
rdi.alarm().check().execute() Add an alarm checking event in any position inside an RDI_BEGIN-RDI_END block.

This command is the only alarm handling command that requires the usage of port in case of multiport setups.

The rule is: all commands that are completed by .execute() require .port() for multiport setups.

 P
rdi.alarm().enable() Enable or disable alarm checking on all pins P, C
rdi.alarm().pin().enable() Enable or disable alarm checking on specified pins. P, C
rdi.id().getAlarmPassFail() Retrieves the alarm pass or fail result on a pin or the general alarm pass or fail result on all pins.
rdi.id().getAlarmBurstValue() Gets alarm DC results on specified pins in burst.
rdi.id().getAlarmPassFailPerId() Gets pass/fail results on a specified label.
rdi.id().getAlarmValue() Gets alarm DC results on specified pins per id.
rdi.alarm().getEnabledPins() Gets back the list of enabled alarm handling pins.

In the Mode column: C = Code-based, P = Pattern-based.

The commands in the following table are used to set limit values. These commands work as the same as the values specified in the alarm setup file. All of them can be put either inside or outside an RDI_BEGIN-RDI_END block.
Overview of alarm handling functions - Table II
Function Description Mode
rdi.alarm().globalLimitRelForcePercent(double); Specify a global relative limit percentage for vforce actions, for example, rdi.alarm().globalLimitRelForcePercent(10%);. P, C
rdi.alarm().globalLimitRelForceValue(double); Specify a global relative limit value for vForce actions, for example, rdi.alarm().globalLimitRelForceValue(0.1 V);. P, C
rdi.alarm().globalLimitMinDisForce(double); Specify a global minimum limit value for vForce actions, for example, rdi.alarm().globalLimitMinDisForce(10 mV);. P, C
rdi.alarm().globalLimitRelClampPercent(double); Specify a global relative limit percentage for Clamp actions, for example, rdi.alarm().globalLimitRelClampPercent(20%);. P, C
rdi.alarm().globalLimitRelClampValue(double); Specify a global relative limit value for Clamp actions, for example, rdi.alarm().globalLimitRelClampValue(0.1 V);. P, C
rdi.alarm().globalDisableAlarmIth(double); Specify a global current threshold value for disabling alarm handling, for example, rdi.alarm().globalDisableAlarmIth(10 uA);. P, C
rdi.alarm().pin(pinA).limitRelForcePercent(double); Specify a relative limit percentage for vForce actions per pin, for example, rdi.alarm().pin(pinA).limitRelForcePercent(10%);. P, C
rdi.alarm().pin(pinA).limitRelForceValue(double); Specify a relative limit value for vForce actions per pin, for example, rdi.alarm().pin(pinA).limitRelForceValue(0.1 V);. P, C
rdi.alarm().pin(pinA).limitMinDisForce(double); Specify a minimum limit distance, for example, rdi.alarm().pin(pinA).limitMinDisForce(10 mV);. P, C
rdi.alarm().pin(pinA).limitRelClampPercent(double); Specify a relative limit percentage for clamp actions per pin, for example, rdi.alarm().pin(pinA).limitRelClampPercent(20%);. P, C
rdi.alarm().pin(pinA).limitRelClampValue(double); Specify a relative limit value for clamp actions per pin, for example, rdi.alarm().pin(pinA).limitRelClampValue(0.1 V);. P, C
rdi.alarm().pin(pinA).limit(low,high); Specify fixed low and high values per pin, for example, rdi.alarm().pin(pinA).limit(2 V,3 V);. P, C
rdi.alarm().pin(pinA).disableAlarmIth(double); Specify a current threshold value per pin for disabling alarm handling, rdi.alarm().pin(pinA).disableAlarmIth(10 uA);. P, C

In the Mode column: C = Code-based, P = Pattern-based.

Result retrieval

SmartRDI provides rdi.id().getAlarmPassFail() for retrieving the alarm pass or fail result. For how to retrieve the alarm pass or fail result, see rdi.id().getAlarmPassFail().
Note An alarm fail can impact the burst pass/fail result. If an alarm check fails, the burst result fails too.

Examples

rdi.alarm().applySet("abc"); // Use an alarm handing set "abc"

RDI_BEGIN();
  rdi.class(id)... // Each measurement with "id" triggers an alarm compare event after it
  ...
  rdi.alarm().check().execute(); // Add an alarm check point
RDI_END();

rdi.id("id").getAlarmPassFail("pinA"); // Alarm result of pinA, and any result "id" in burst
rdi.id("id").getAlarmPassFail();       // Alarm result for all alarm pins.
Each of these commands takes effect in its test suite and subsequently keeps valid no matter where it is located, inside or outside an RDI_BEGIN-RDI_END block in the test suite.
RDI_BEGIN();
  rdi.alarm().globalLimitRelForcePercent(0.1);
...
RDI_END();

RDI_BEGIN();
... // the globalLimitRelForcePercent also takes effect.
RDI_END();
