Using the UNGANG connect state with DC Scale DPS cards

The UNGANG mode allows to set a lower current clamp value for a gang of DPS channels than allowed in the normal connect state. It is supported by all DC Scale DPS cards.

For example, ganged DPS128 channels must be in the 1.0 A current clamp range. That is, the maximum clamp current is 1.0 A and the minimum clamp current is 200 mA per channel. The minimum clamp current for N ganged channels is therefore 

N * 200 mA

If you want to set a lower clamp current in a test suite, then you can use the UNGANG connect state. In this state, the test system detaches as many channels as possible from the gang - and leaves only as many active channels in the gang as are necessary to achieve the required clamp current.

You can set the UNGANG mode with the connect_state parameter of an equation based level setup or with the PSLR firmware command:

  • Equation:
    DPSPINS <pinlist>
    connect_state  = UNGANG
    vout_frc_rng   = <vout_frc_rng>
    iout_clamp_rng = <iout_clamp_rng>
  • Firmware Command:
    PSLR {dps_No|dps_set_id},[vout_frc_rng],[iout_clamp_rng],[const_curr_check],UNGANG,(pinlist)

The connect state UNGANG can be combined with an unganged current measurement (the MEASURE_CURRENT_UNGANGED parameter in the measurementMode() member function of the DPS_PIN_TASK API, or the template parameter "3" of the DPSE firmware command).

During an unganged current measurement, you temporarily can ungang even more channels to measure very low currents with the best possible accuracy.

Note that on DPS128/64 and XPS256 you cannot execute a current compare on a ganged group of channels in unganged mode. Already activated comparators are silently disabled in unganged mode. A user notification (Error or warning) is omitted in this case, to avoid any interrupt in the testflow. The previous state of the comparators is automatically restored after the ganged group has been restored.

Note that for the DC Scale UHC4T card the setup connect_state = UNGANG features a double role. This connect state will not only remove channels from a ganged group but also switch a single channel from the High-power mode to the Precision mode. For more information refer to UHC4T power modes.

Note DC profiling of the current is not supported if a pin is in UNGANG mode.

vout_frc_rng and iout_clamp_rng

The vout_frc_rng and iout_clamp_rng parameters are used to determine the minimum number of required channels. You need to specify the maximum voltage and current values that are required for a DPS set with these parameters.

In connect state NORM (default), the vout_frc_rng value is rounded up to the next available voltage force range and the iout_clamp_rng value is divided by the number of ganged channels. This value is also rounded up to the next available current clamp range of one channel.

In connect state UNGANG, the unrounded vout_frc_rng value is used to determine the maximum allowed current of one DPS channel at this voltage. The unrounded iout_clamp_rng value is then divided by this value. The result is the number of required channels.

The actual maximum clamp current per channel is iout_clamp_rng divided by the number of required channels. The vout_frc_rng and the maximum clamp current per channel are then rounded up to get the actual voltage force and current clamp ranges for each active channel. The number of channels, which are not required, are detached from the gang.

The actual force voltage and clamp current values must not exceed the vout_frc_rng and iout_clamp_rng values, otherwise a range overflow may occur.

Examples

Description

Here are three examples applying different voltage and ampere values for 32 ganged DPS128 channels and connect_state = UNGANG

Example 1: 2.5 V, 5 A

vout_frc_rng = 2.5V, iout_clamp_rng = 5A
At 2.5 V, each channel can source or sink 1.0 A.
Number of channels = ceil(5A / 1.0A) = 5
Current per channel = 5A / 5 = 1.0A

Five channels will be set to the 1.0 A clamp range, 27 channels will be detached.

Example 2: 7 V, 5 A

vout_frc_rng = 7V, iout_clamp_rng = 5A

At 7 V, each channel can source or sink 0.5 A.

Number of channels = ceil(5A / 0.5A) = 10
Current per channel = 5A / 10 = 0.5A

Ten channels will be set to the 1.5A clamp range, 22 channels will be detached.

Example 3: 7 V, 100 µA

vout_frc_rng = 7V, iout_clamp_rng = 100µA

At 7 V, each channel can source or sink 0.5 A.

Number of channels = ceil(100µA / 0.5A) = 1
Current per channel = 100µA / 1 = 100µA

One channel will be set to the 100 µA clamp range, 31 channels will be detached.

The 100 µA current clamp range is allowed, because only one channel remains active so this is effectively a single channel and no longer a gang.
