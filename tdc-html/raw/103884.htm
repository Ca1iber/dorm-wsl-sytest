Setting up the generation of reconstruction information

Reconstruction information is needed to link results with memory addresses. The MTL compiler can generate it automatically.

About this task

You will want to set up the generation of reconstruction information when you are debugging the DUTs.

Procedure

  1. Make sure that all device accesses for which you need reconstruction data use the data macro in the :data: column.
  2. When compiling the program, check the Generate Reconstruction File option in the MTL Compiler Control dialog (when using the GUI) or specify the -r1, -r2 or -r3 compiler switch (when using the command line).

Results

In addition to the other files it creates, the compiler generates a file with reconstruction information.
