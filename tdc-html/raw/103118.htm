Setting up flags

You have to set the testflow flags, system flags, and test suite flags according to your test purpose.

  • The testflow flags primarily help you to debug the testflow.
  • The system flags are tools that allow you to control test program execution. This flag defines global information relating to the entire test program.
  • The test suite flags control the output of the test suite. With this flag, you can set which result will be acquired during execution of the test, and will then be included in the report window output and in the specified files. As such, the flags directly influence how a test suite is executed.

This section discusses some flags relating to digital tests briefly.

For event data logging:

  • output on pass/output on fail test suite flags:

    These test suite flags determine whether the test suite returns an overall pass and/or fail message. These flags must be set if the output needs to be sent to the event data log subsystem.

  • log events enable system flag
  • If you are turning this system flag on together with the output on pass or output on fail test suite flag, the general data log capability activates in the test method programs.
