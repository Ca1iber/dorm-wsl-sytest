HW_STATE.checkKelvinStatus()

This member function initiates a sense connection test on the defined pins to verify that the force lines and sense lines are connected together on the DUT board or at the DUT pins.

The test is performed for the site in focus. The member function returns individual results for all tested pins in two integer arrays for the positive and for the negative line.

The test is started for the connection between the high force lines and the high sense lines (positive power lines) and for the connection between the low force lines and low sense lines or ground sense lines and ground (negative power lines).

For more information regarding the sense connection test refer to DPS128 sense connection test, UHC4T sense connection test, and XPS256 Kelvin test unit.

The tested pins must be disconnected for the sense connection test.

The member function must be called outside of the ON_FIRST_INVOCATION block or within a FOR_EACH_SITE block. The FOR_EACH_SITE_BEGIN_WITH_QUERY API must be used to set the query focus within the FOR_EACH_SITE block.

Syntax

bool checkKelvinStatus(const STRING pinList, ARRAY_I & statusPos, ARRAY_I & statusNeg);
bool checkKelvinStatus(const STRING pinlist, const INT samples, ARRAY_I &statusPos, ARRAY_I &statusNeg);
The following syntax is supported only for the DC Scale XPS256 card:
bool checkKelvinStatus(const STRING pinlist, const INT samples,
        const DOUBLE maxResistance, ARRAY_I &statusPos, ARRAY_I &statusNeg);

bool checkKelvinStatus(const STRING pinlist, const INT samples,
        const DOUBLE maxResistancePos, const DOUBLE maxResistanceNeg, ARRAY_I &statusPos, ARRAY_I &statusNeg);
Parameters
Parameter Description/Range
pinList The pins connected to the DUT board that will be queried. The pins are separated with commas. If the pinList is empty or an invalid pin is specified, an error message will be thrown out and the test will not be executed.
samples The optional parameter defines the number of averaged measurements to be performed.

The valid range of the integer parameter is 1 … 128.

The default value is 1.

maxResistance

maxResistancePos

maxResistanceNeg

The threshold for the pass/fail decision in ohms (Ω).

The programmable range is 0 ... 5000 Ω.

The three parameters are supported only for the DC Scale XPS256 card.

According to the selected syntax, the threshold value can be set together for the positive power lines and negative power lines or can be set separately for positive and negative power lines.

For the default value if another syntax is selected and no threshold is defined, refer to XPS256 programming - Kelvin test / sense connection test.
statusPos Integer array that is filled with the results of the Kelvin test on the positive power lines.

The size of the array is defined by the number of defined pins. The first element of the array corresponds to the first pin in pinList.

The returned integer values are to be interpreted as follows:

0:
The Kelvin test has failed on the corresponding pin.
1:
The Kelvin test has passed on the corresponding pin.
statusNeg Integer array that is filled with the results of the Kelvin test on the negative power lines.

The size of the array is defined by the number of defined pins. The first element of the array corresponds to the first pin in pinList.

The returned integer values are to be interpreted as follows:
0:
The Kelvin test has failed on the corresponding pin.
1:
The Kelvin test has passed on the corresponding pin.

Return value

The returned bool value indicates the state of the conversion from the read data to the data in the arrays:

  • true: No error found
  • false: Invalid data read

Example

The following example performs a sense connection test on three pins "pin1", "pin2", "pin3" in parallel on all active sites. Failing sites are re-tested in the FOR_EACH_SITE block to identify the failing pins and lines. Note that the FOR_EACH_SITE_BEGIN_WITH_QUERY() API must be used to set the query focus within the block.

SPMU_TASK       spmuTask;
HW_STATE        hwState;
ARRAY_I         goNogoResult;
ARRAY_I         statusPosArray;
ARRAY_I         statusNegArray;
STRING          pinlist          = "pin1, pin2, pin3";

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Disconnect the tested pins
    //
    spmuTask.pin(pinlist).vForce(0.0 V).min(-1.0 A).max(1.0 A).relay("NT");

    spmuTask.execMode(TM::FORCE_OFF).execute();

    //
    // Perform the Kelvin test in parallel on all active sites
    //
    hwState.checkKelvinStatusParallel(pinlist, goNogoResult);

    //
    // Evaluate the go/no-go results, re-test failing sites
    //
    cout << "Parallel Kelvin tests GoNogo results per site:" << endl << endl;

    FOR_EACH_SITE_BEGIN_WITH_QUERY();
    {
        cout << "\tSite " << CURRENT_SITE_NUMBER() << ": ";

        if (goNogoResult[CURRENT_SITE_NUMBER() -1] == 1)
        {
            cout << "PASS" << endl;
        }
        else
        {
            cout << "FAIL, serial test on site " << CURRENT_SITE_NUMBER() << endl << endl;

            //
            // Serial test identifies failing pins
            //
            hwState.checkKelvinStatus(pinlist, statusPosArray, statusNegArray);

            for (int arrayIndex = 0; arrayIndex < statusPosArray.size(); arrayIndex++)
            {
                cout << "\t\tPin " << arrayIndex + 1
                     << ": positive = " << statusPosArray[arrayIndex]
                     << ", negative = " << statusNegArray[arrayIndex] << endl;
            }

            cout << endl;
        }
    }
    FOR_EACH_SITE_END();

    cout << endl;
}
ON_FIRST_INVOCATION_END();
