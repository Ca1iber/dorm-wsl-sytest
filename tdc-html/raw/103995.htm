Topic 103995

Fixed timing

Subtopics

  1. Data organization of fixed timing
  2. Defining waveform shapes
  3. Defining the period
  4. Defining the Edge Delays

The standard timing of SmarTest is equation based. Such a timing consists of three data collections, equation sets, wavetables and specifications. Every collection can contain several items of the respective type and is downloaded to the tester as one string argument of the EQSP or EQFS commands. There exists another type of timing, called fixed timing, where each single setup element, such as a waveform or the edge positions for one pin and timing set, is defined separately by calling a firmware command. In fixed timing, periods and edge delays must be specified as constants. Also, the organization of the data differs from that of equation based timing (for which see Data organization of equation based timing).

Functional changes
