TMU_RESULTS.getLastMeasurementId()

Returns the highest arming ID for which samples have been uploaded.

Syntax

UINT32 getLastMeasurementId (STRING&     pin, TMU::ApplicationType appType, UINT32 site = 0);
UINT32 getLastMeasurementId (const char* pin, TMU::ApplicationType appType, UINT32 site = 0);
Parameters

I/O

Parameter

Description

I

pin

The pin to query.

I

appType

The application type. It currently can only be APP_PERIOD or APP_RAW.

I

site

The site to query. Default is 0, which means the current site.

Return value

The highest arming ID, for which samples have been uploaded, is returned.

Functional changes

  1. Introduced in SmarTest 7.3.1
