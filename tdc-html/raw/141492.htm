MTP_MEMORY_PORT.isRepairable()

Queries whether the current port is repairable.

The port is specified with getMemoryPort().

Syntax

bool isRepairable () const;

List of parameters

There are no parameters.

Return value

true: The port is repairable.

false: The port is not repairable.

Related information

MTP_MEMORY_TEST.getMemoryPort()

Functional changes

  1. Introduced in MTP 3.2.1
