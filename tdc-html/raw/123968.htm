Topic 123968

How to develop a test program with concurrent test framework

Subtopics

  1. How to create a test method with concurrent test framework
  2. How to create a CCF block in the testflow

Before you begin

Make sure you are using SmarTest 6.5.4 or later versions.

Procedure

  1. Create the setup files following the Guidelines of using concurrent test framework.
  2. Create the test method and testflow with concurrent test framework. For details, see
    • How to create a test method class with concurrent test framework
    • How to implement a concurrent test method
    • How to create a CCF block in the testflow
  3. Execute and debug the testflow in development and serial mode. Enable the output of debugging information.
    1. Start with single site and no smartCalc execution. Make the testflow single execution pass.
    2. Enable multi-sites, testflow loop execution and smartCalc (if needed) and make the testflow pass.
  4. Execute and debug the testflow in development and concurrent mode. Enable the output of debugging information.
    1. Start with single site and no smartCalc execution. Make the testflow single execution pass.
    2. Enable multi-site, testflow loop and smartCalc (if needed) and make the testflow pass.
  5. Save the merged multi-port burst label and multi-port timing file generated in development mode explicitly with the name specified in the parameter CCT_LabelName and CCF_TimingSpecSetName.
  6. Save the loaded level setup file.
  7. Set the CCF variables as concurrent mode, production mode and no debugging information output.
  8. Execute the test program.

Results

A test program using concurrent test framework is ready.

Functional changes

  1. Introduced in SmarTest 6.5.4
