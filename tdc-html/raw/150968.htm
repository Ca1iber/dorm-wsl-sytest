Topic 150968

Sync group support with SmartRDI

Subtopics

  1. addPort()
  2. syncGroup()

In multiport bursts, a synchronization group (sync group) forces related ports to start always at the same point in time. For more information about sync groups, see Working with sync groups.

In SmartRDI, you can use syncGroup() and addPort() to assign one or more ports to a sync group.

Example

rdi.syncGroup("sg1").addPort("ptA");
rdi.syncGroup("sg2").addPort("ptB").addPort("ptC");

RDI_BEGIN();
  rdi.port("ptA")...
  rdi.port("ptB")...
  rdi.port("ptC")...
RDI_END();
