ERCT? - (ERror CounT)

The ERCT? query returns the number of results that contain recorded errors. If DCRM has been set to 8,PF, the query returns the total number of failed compare actions in all recorded cycles.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

ERCT? {type}, [MUX,] {(pinlist)}

returns: 

ERCT {type}, {valid_code}, {no_of_errors}, [map_mode], [MUX,] {(pinlist)}

Parameters

type

The type parameter can be:

ERCP

Error count per pin, as delivered by the hardware error counter. The map_mode is always F160. For differential pins, the maximum of the specified pin and its counterpart is returned.

ERCG

Error count global, which requests a sum of all error counts reported by ERCP. No map_mode information is returned.

EOLY

The Errors OnLY option delivers the numbers of failed cycles per pin from the detailed Error Map. The map_mode is F160. For differential pins, the numbers of those cycles will be returned where at least one of the pins produced an error.

valid_code

This parameter tells you if the error count the system returns is valid. The system may return:

VALD

The error count is valid. (This reply is always returned in offline mode.)

OVFL

Signifies error counter overflow. The hardware error counter has a range of 231.

no_of_errors

This parameter returns the total number of results containing errors for one of the specified pins. For the ERCG type, it returns the sum of all the error counts for the individual pins.

map_mode

The system returns the Error Map mode. The only possible value is:

F160

The pin is operating in standard mode

MUX

If this flag is set, and one of the specified (Pin Scale) pins is multiplexed to an HXA pin, then the errors from all Pin Scale pins multiplexed to this HXA pin will be used to calculate the total number of errors.

pinlist

The command returns the error count only for pins specified in pinlist. If more than one pin is to be included, the names must be separated by a comma. All pins in pinlist must be O or IO types.

Application

Test results, see Test Result Commands.

Errors

An error is generated if:

  • You send the query while the sequencer is running. There is then no result data available.
  • You make a change in the setup and then send the query. There is then no result data available. To get the data, start a new test.

Example

> ERCT? ERCP, (Q0)
< ERCT ERCP, VALD, 1, F160, (Q0)

This example requests the error count for pin Q0. The system returns one error, the error count is valid, the map mode is F160.

Functional changes

  1. Introduced before SmarTest 6.3.2
