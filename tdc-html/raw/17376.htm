Adding a New Spec/Variable

  1. From within the Timing or Level Setup, choose edit equations from the Select menu.
  2. Add the new specs/variables - in the SPEC section - in all desired equation sets (EQNSET).
  3. When you have made your changes, download them to firmware by clicking Download.
  4. In the Spec Tool main window, choose Upload from the File menu.

    The new specs now appear in the Spec Tool table, with initial values set to zero.

  5. Change the values of these specs as necessary, as described in Changing Spec Values.
  6. If necessary perform a sort, and download these settings to firmware.

Functional changes

  1. Introduced before SmarTest 6.3.2
