Topic 119339

Selecting a Layout

Procedure

  1. If you have configured and saved several layouts for a pattern in the Pattern Editor, you can select one of these layouts either
    • in the Pattern Editor (with a right-click), or
    • in the Pattern Explorer in the Layout on Pattern Editor column (you may need to scroll to see the column).
  2. The Select Layout dialog from the Pattern Editor offers additional sorting features. For example, the list of available layouts can be reduced by typing text into entry field.
