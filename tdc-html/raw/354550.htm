Topic 354550

Generating and saving key files

Generate the public and private key pair for accessing TE-Cloud with PuTTYgen and save them as key files.

About this task

The public and private key files are used to connect to the TE-Cloud virtual machine and file transmission.

Before you begin

Download and install PuTTYgen. See External tools needed for working with virtual machines for details.

Procedure

  1. Open PuTTYgen.
  2. Click the Generate button.
  3. Move the cursor randomly over the blank area during the key generation process.

    A RSA public and private key pair is generated.



  4. If you want to customize the key, enter a label for the key in the Key comment field.

    This step is recommended. By default, the label is rsa-key-key_generation_date. A specified label for a public key helps distinguish multiple public keys when more than one user is authorized to access a TE-Cloud virtual machine.

    The public key content is updated with the entered label at the end.

  5. Click the Save private key button, and save the private key as a PuTTY Private Key (PPK) file.

    The directory you select to save the private key file must not contain Chinese characters.

    Do not enter the file extension .ppk after the file name. It is added automatically.

  6. Save the private key as a PEM file.
    1. Choose Conversions > Export OpenSSH key in the PuTTY Key Generator window.

      A warning message is displayed.

    2. Click Yes.
    3. Enter the file name with the extension .pem in the Save dialog.
  7. Save the public key.
    1. Create a text file, and open it.
    2. Copy the full content of the Public Key field in the PuTTY Key Generator window into the text file, and save the file.

Results

Three key files have been generated:
  • Text file with the public key information: Used for authorizing a user to the cloud virtual machine.
  • PPK file with the private key information: Used for connecting to a cloud virtual machine from Windows.
  • PEM file with the private key information: Used for connecting to a cloud virtual machine from Linux.
CAUTION Ensure no new private or public key is regenerated during the file saving process.
