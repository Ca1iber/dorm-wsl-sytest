Setting up the Timing

Subtopics

  1. Setting up the Timing for Sequential Capturing
  2. Setting up the timing for selective capturing

As the test system uses normal digital pins for data capturing, the timing for a capture pin can be defined in the same way and with the same tools as for any other digital pin.

Setting up the timing for Digital Capture is different for the two Capture Modes Sequential and Selective.

This is because in Sequential Mode capturing will be performed on edges with normal compare actions, while in Selective Mode the capturing will be performed on edges with a designated ‘capture' action (C for capture and D for do not capture).

Note In both modes, capturing can only be performed on single edge actions, that is, capturing using window compare is not possible.
