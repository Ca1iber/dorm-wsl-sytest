Parameter: driver_error_log

In addition to printing warnings and errors to the report window, the driver can also write these to a file. Also ‘trace' information (see Parameter: trace_driver_calls) will be written to this file.

If the following value is not an empty string, it is treated as an additional log file for errors and warnings. Environment variable substitution in the path definition works.

Driver default: "" (empty string)

Changeable at run-time: yes

Applicable for: handlers and probers

Example: driver_error_log: "/var/opt/hp93000/soc/PH_libs/errors&warnings"
