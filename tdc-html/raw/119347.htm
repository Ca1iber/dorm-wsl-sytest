Topic 119347

Configuring the layout of the pattern editor

Procedure

  1. Add w/Selector >

    Signals in the state character (SC) format can be added with a selector. That is, you can assign SC signals to groups. The signal(s) appear(s) indented underneath the selector name.

  2. Add Members >

    A Pin Group can be added as such, or you can add the individual members of the Pin Group.

    You save and select a layout in the editor, either the pattern editor or on a sync group page of the multiport burst editor.

    Note In order to list DC Scale signal pins in the Configure Layout dialog, you must set the amount of test points in the .technology file to greater than 0. For instructions see Editing technology data, and Technology file for a device for details.
