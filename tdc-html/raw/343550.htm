Routing Tools hardware

The Routing Tools support sequencer‑controlled utility lines. These resources are controlled via serial interfaces that must be wired on the DUT board.

The Sequencer-controlled utility lines can be controlled by digital pins that are connected to the inputs of the serial interfaces.

Sequencer‑controlled utility lines

The utility lines feature a four-wire serial interface as shown below.

To make use of sequencer‑controlled utility lines you need to route four digital pins on the DUT board to the appropriate serial interface pins. For more information, refer to Sequencer-controlled utility lines.

For the pogo pin assignment of the utility pogo blocks refer to Pogo pin assignment - Utility pogo blocks. The following signals are required for sequencer controlled utility lines:
  • FRAMn: Frame, active low
  • SINP: Serial input to the FPGA on active wiring board
  • SCLK: Serial clock
  • SOUT: Optional serial output from the FPGA on active wiring board
The serial interface for sequencer‑controlled utility lines can handle the data stream for more than one utility block. This cascading of serial interfaces of utility blocks is called "ganging" in the context of the sequencer‑controlled utility lines. For more information, refer to Ganging utility blocks.
