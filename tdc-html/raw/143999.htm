SOURCESYNC_SUB_TEST.sweepSpecVar()

Specifies sweeping spec variables sweeping from sweepStart() to sweepStop() for every edge.

Syntax

SOURCESYNC_SUB_TEST& sweepSpecVar (const string& sweepSpecVar);
Parameter

Parameter

Description

sweepSpecVar

The name of the sweeping spec variable. You can specify multiple variables separated with ";".

It supports multiport. For example, "sweep_a@port_a".
