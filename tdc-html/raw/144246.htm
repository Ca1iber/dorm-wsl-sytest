Pin configuration report

On the home page of the Test Program Browser report, click the hyperlink in the Pin configuration row, the report for pin configurations is displayed.

As illustrated in the following screenshot, the hyperlinks above the table let you view the configurations for:

  • Digital pins.
  • Analog pins.
  • DPS pins.
  • Utility lines.
  • Pin groups.
  • The related source codes.

This following screenshot displays the configurations for digital pins. The table includes the digital pin numbers, names, modes, types, DUT board, site numbers and channels. TP360 highlights the shared pins.
