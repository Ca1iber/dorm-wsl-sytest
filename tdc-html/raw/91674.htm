How to set the driver levels for differential pins

To set the drive levels for the differential pair which consists of i pins or io pins, you need only set the positive pin. The negative pin is assigned same value automatically.

Before you begin

Make sure that the Level Setup window is open.

Procedure

  1. In the Level Setup window, choose Select > Edit Equations.
  2. The Level Equation editor opens. In the level equations, add the Additional pin qualifier @diff (in the manual Command Reference) to the positive pin. And then set the drive levels as the following example.
  3. To download the values in the level equations to the test system hardware, in the Level Equation editor, press F8.
  4. To verify the result of drive level settings, in the Level Setup window, choose Select > Show I/O Eqn. & Specs Results.

Results

In the Level Setup window, the level [V] low and high columns show the resulting drive levels.
