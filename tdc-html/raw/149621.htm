Postfix in burst pattern names

Subtopics

  1. burstPostfix()
  2. RDI_BURST_POSTFIX

SmartRDI can generate a postfix to append after burst pattern names.

SmartRDI automatically appends a string to burst pattern names to make them unique. There are two ways to do so:

  • With the RDI_BURST_POSTFIX testflow variable:

    The content of this string variable is appended to the names of all burst patterns generated by SmartRDI.

  • The rdi.burstPostfix(string) function:

    Add a specified postfix to the names of all burst patterns in the current test suite.

These two features can append different strings for all test suites in different testflows.
