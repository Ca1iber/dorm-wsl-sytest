Parameter: bin_waveform

This parameter defines, whether the bin information is a "pulse" to the handler or remains "static". If bin information is pulsed, the output levels of the bin lines go back into the inactive state according to the bin_data_polarity definition after the bin data has been sent. Otherwise, they remain with set bin information until the next device is binned.

Driver default: depends on plug-in

Changeable at run-time: yes

Applicable for: handlers and probers

Example: bin_waveform: "pulse"
