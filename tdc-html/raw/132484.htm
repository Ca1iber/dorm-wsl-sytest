SMC_UPLOAD_STATUS.finished()

Returns if the upload of an SMC task has finished or if the upload is in progress or has not yet started. This state is stored in a vector that is populated by SMC_GET_UPLOAD_STATUS().

Syntax

const Boolean finished() const;

List of parameters

There are no parameters.

Return value

Returns true if the upload of an SMC task has finished.

Returns false if the upload is in progress or has not yet started.

Example

This example shows how to create a vector of type SMC_UPLOAD_STATUS and how to retrieve the information if the upload has finished or not from the vector.

Note As SMC_UPLOAD_STATUS represents a collection, one has to iterate over the collection to obtain the item.
typedef vector<SMC_UPLOAD_STATUS> SmcUploadStatusVector;
boolean Done;

// Obtain the collection
SmcUploadStatusVector statusVector = SMC_GET_UPLOAD_STATUS();

// iterate through collection
for(SmcUploadStatusVector::iterator it = statusVector.begin();
     it != statusVector.end(); ++it) {
        Done= it->finished();
        if (Done) {
           cout << "Upload has finished." << endl;
        }
        else {
           cout << "Upload has not finished." << endl;
        }
     }
