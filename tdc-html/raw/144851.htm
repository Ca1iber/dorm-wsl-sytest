How to call the functions in one test method library from another test method library

To call the functions in one test method library from another test method library, reference to the project to be called from another project, call the functions of the referenced project in the test method of another project and build the test method.

About this task

The default linker option -rpath=’$$ORIGIN’ is added for each created test method project. It helps to call the functions in one test method library from another test method library.

Before you begin

Make sure the test method libraries are valid and located in the sub-directory testmethod/sh_lib-EL7-64bit of the device directory.

Procedure

  1. Right-click the test method project to call the functions of other test method projects and select Properties.
  2. In the Properties dialog, click C/C++ General > Paths and Symbols.
  3. Click the Reference page, check the test method project containing the functions to be called and click OK.
  4. Call the functions of the referenced test method project in the test method of the current project.
  5. Build the test method project.

Results

The functions of the referenced test method project are successfully called in another project.

Functional changes

  1. Introduced in SmarTest 7.3.1
