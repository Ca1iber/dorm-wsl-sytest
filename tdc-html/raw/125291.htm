length()

Determines the length of a state character sequence and returns it as an integer value.

Syntax

number := length( sequence )
Parameter

I/O

Parameter

Description

I

sequence

State character sequence which length will be determined.

Example

length("") results in 0.

length("XXL") results in 3.

The following example determines the length of the field "myfield" and fills five "0" to the left of "001" resulting in "00000001" of a total length of 8 characters (assuming @myfield has a length of 8 characters).

fillLeft("001", length(@myfield), "0")

Related information

fillLeft(), fillRight()

Functional changes

  1. Introduced in SmarTest 7.1.0
