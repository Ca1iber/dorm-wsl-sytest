Creating a pattern

To create a new pattern you can use the Pattern Explorer.

Before you begin

The Pattern Explorer must be open, see Opening the Pattern Explorer.

Procedure

  1. In the main area of the Pattern Explorer right-click and select New > Pattern. The New Pattern dialog pops up. The default values in the dialog derive from the currently selected pattern. The newly created pattern is automatically selected and will become the new default.
  2. In the text boxes type or select the following:
    • Pattern Name: A unique name for the new pattern. The name can be 128 characters long and must not contain blanks.
    • Pattern Type:

       

       

      Function

       

      Main

      Regular pattern, most commonly used

       

      SJMP

      Sub-pattern, jump from a main pattern(old)

       

      SubRoutine

      Sub-pattern, jump from a main pattern

       

      Burst

      A group of main patterns that are executed in series without any break. Bursts use always the default port (@).

      For how to create a port burst (Type = PortBurst) and multiport burst (Type = MPBurst) see Creating a port burst and Creating a multiport burst respectively.

       

      DSRC

      Pattern for Digital SouRCe Memory
    • Port: The port the new pattern is related to. The default is @ (all pins).
    • Memory Type: SM (Sequencer Memory) or SHMEM (Shared Memory, the pattern is distributed over more tester channels, the pattern can be edited, but not the sequencer instructions, for more information see Selecting the memory type)
    • Wavetable: The wavetable that is used for the Pattern Editor in collapsed mode.
      Note The wavetable selected here is not necessarily the same wavetable used for test execution. This wavetable is called base wavetable and is only used to display the device cycle names or state characters in the Pattern Editor. See also Function of the base wavetable. The wavetable that is used for test execution is defined in the test suite dialog and is called primary wavetable.
    • Folder: The folder containing the new pattern file. The default is ../vectors.

      This option is available only in a pattern master file setup. When saving the new pattern, it is automatically added to the pattern master file.

      A content assist is available for all fields, except for the Pattern Name field. To activate the content assist for a specific field, set the cursor in this field and press Ctrl+Spacebar. Delete the content of the field to see all possible values.

  3. When you have typed all values, click Finish.

Results

A new pattern has been created. The pattern contains only one vector line with the STOP instruction.
