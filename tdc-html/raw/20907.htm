Topic 20907

Applying Desired Vector before DC Test

The PMU_VFIM and PMU_IFVM APIs (DC APIs) can perform a functional test as a pre-action of the DC test with the FTST option of the preAction member function. This feature is effective when you perform a DC test with applying the break vector to the device.

You can also use the SEQUENCER_STATUS API to apply the vector of the desired vector address or device cycle number. For details, see SEQUENCER_STATUS - (Sequencer).
