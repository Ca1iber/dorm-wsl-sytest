How to create a BLC executable file

This section describes how to create a BLC executable file.

About this task

A BLC executable file is a compiled BLC object file.

Before you begin

Make sure you are using SmarTest 6.5.0 or above versions.

Procedure

  1. Create a C/C++ BLC file with the BLC APIs.
    • Include the header file hvmapi.hpp.
    • Usually you will implement the following functions in the file: BLC execution initialization, input file parsing, setup loading, level controlling, execution status processing and pause/abort state checking. (Refer to Example codes of the most often used tasks.)
    • The source file templates for package test and wafer sort are provided in the directory /opt/hp93000/soc/applic_models/blc_templates. You can create your file according to them.
  2. Compile and link the file.

    You can build your client program like any ordinary C++ program. Use a makefile or other tools to build the program. For example, you use a makefile, change to your program directory and type in make in the Linux command line to build your program.

    You can find some BLC makefile templates in the directory /opt/hp93000/soc/applic_models/blc_templates.

Results

You will get the BLC executable file *.so in the directory you specified.
