Digital pin editor reference

The digital pin editor contains the following columns:

  • Name: The name of the pin.

    The name can be up to 16 characters long and must not contain the characters: # ; ( ' ' ) ? @ ,

  • No: The number of the pin on the DUT package (optional).
  • Type: The function of the pin:
    • off: No type set
    • i: DUT input
    • o: DUT output
    • io: DUT input and output
    • dc: HPPMU DC measurement; no test system IO
  • Mode: The operating mode of the test system channel:
    • std: Standard mode for digital pins
    • fast: Fast mode for digital pins
    • SIG: PMU mode for DC Scale pins
    • MUX2: MUX2 mode for HX card pins
    • MUX4: MUX4 mode for HX card pins
    • Loopback: Loopback mode for HX card pins
  • HW: The hardware information of the channel. Not editable.
  • Connection Set: ID string for the definition of sequentially reused DC Scale pins. Leave this field empty for other pin types.
  • Comment: Any text. Optional.
  • Tester Channel: The tester channel to be used.

    The channel is specified with by a five-digit number:

    • First three digits: The pogo block number (101-132, ..., 401-432)
    • Fourth and fifth digits: The channel number within the block (01-16)

      Example: 10301
