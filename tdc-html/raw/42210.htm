Topic 42210

Parameter: temp_setpoint

The input of this parameter is the list of temperature setpoints. By these setpoints you define the temperatures which you want to obtain in a certain chambers. The order of the setpoints within the list has to be the same as the order of the affiliated chambers as they were listed within the parameter temp_chambers.

The parameter temp_setpoint is only active, if the parameter temperature_control is set to "active" mode. The number of entries in the list must either match the number of entries of the parameter temp_chambers or one single value only may be set. In case you insert one single value only, the setpoints of all chambers will be set to this temperature value. The unit of the values is defined with the parameter temp_conf_unit.

Driver default: empty list

Changeable at run-time: yes

Applicable for: handlers and probers, plug-in dependent

Example 1: temp_setpoint: [20.5 42.3]

Example 2: temp_setpoint: 20.3
