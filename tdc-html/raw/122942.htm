Topic 122942

Timing Equation

Equation based setups must no longer contain any syntax elements, which deal with bidirectional edges. This affects timing equations and wavetables.

In the timing equations, bidirectional edge specifiers e1 to e6 are replaced by unidirectional edge specifiers d1 to d6 / r1 to r6. As described in the timing firmware commands, also in the timing equations, we cannot tell, whether an edge is used as drive or receive. Therefore, a bidirectional edge is replaced by both drive and receive edges.

TIMINGSET {setIdx} "{setName}"
PINS {pinlist}
e1 = {expression_1}
...
e6 = {expression_6}

Replacement:

TIMINGSET {setIdx} "{setName}"
PINS {pinlist}
d1 = {expression_1}
r1 = {expression_1}
d6 = {expression_6}
r6 = {expression_6}

Functional changes

  1. Introduced in SmarTest 6.5.4
