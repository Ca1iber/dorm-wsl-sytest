Defining variables

You must create a variable on the Variables page before using it in the testflow.

Before you begin

Make sure that the Flow Data Editor is open.

Procedure

  1. On the Variables page of the Flow Data Editor, right-click anywhere on the page and select Add Variable. The Add Variable window appears.
  2. Choose the variable type and enter the name for the new variable and its desired value. (String values have to be entered in quotes, like "String".)

    Userflag

    An integer value (0 or 1). Can be viewed and edited during Test Program execution from within the User Flags window.

    String

    Text (for the maximum string number see SmarTest character and number limits). String values must be enclosed in double quotes, for example, "abc".

    Double

    A double number or an expression that represents a double value (available range [-123.456 .. 789.654]).

    Typically, such variables take result values of Test suites.

  3. Click OK.

Results

The new variable appears on the Variables page. You can modify its value on this page.

What to do next

Use the variable in the testflow.

You can retrieve the value of the defined variable by following Obtaining Values of Testflow Variables.

To, for example, get the current value of the double type variable set above, use GET_USER_DOUBLE:
    ...
    DOUBLE print_example ;
    GET_USER_DOUBLE("X", &print_example);
    report_stream << "User-defined variable: " << print_example << endl;
    ...
