Topic 145619

MTP-EWC new features

  • The MTP editor starts to support:
    • Subroutine parser, including supporting syntax highlight, hyperlink opening, text help, content assistant, and error annotations for it.
    • Device parameter parser, including supporting syntax highlight, hyperlink opening, text help, content assistant, and error annotations for it.
    • Variables used in a file path.
    • Warnings for the pin mapping file.
    • Notifying you that an MTL setup file has been modified when it is used by multiple APG sets and edited in one set.

      For details, reference Features in the editor view of MTP-EWC.

  • New menu command MTP Wizard is created to open the MTP wizard.

    For details, reference Creating MTL files with the MTP wizard.
