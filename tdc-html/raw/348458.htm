Electrical design: Product-specific rules

Subtopics

  1. Electrical design rules - DC Scale cards
  2. Electrical design rules - DPS-slot power supplies
  3. Electrical design rules - Digital cards
  4. Electrical design rules - MUX cards
  5. Electrical design rules - Other cards, DUT interfaces, systems

For some products, specific design rules must be followed when designing a new DUT board. This section holds all product-specific rules.

The generations, variants and used SmarTest versions of the V93000 system support different sets of test head cards:
  • V93000 EXA Scale systems (SmarTest 8)
  • V93000 EXA Scale systems (SmarTest 7.10 and higher)
  • V93000 Smart Scale system (SmarTest 8)
  • V93000 Smart Scale system (SmarTest 7)
  • V93000 Pin Scale system
  • V93000 HSM system

V93000 EXA Scale systems (SmarTest 8)

The following product-specific design rules apply to the V93000 EXA Scale system running SmarTest 8:

  • DC Scale cards
    • DC Scale AVI64 card
    • DC Scale DPS128 / DPS64 card
    • DC Scale UHC4 / UHC4T card
    • DC Scale XPS256 card
  • Digital cards
    • Pin Scale 5000 card
  • MUX cards
  • Twinning DUT interface

V93000 EXA Scale systems (SmarTest 7.10 and higher)

The following product-specific design rules apply to the V93000 EXA Scale system running SmarTest 7.10 and higher:

  • DC Scale cards
    • DC Scale DPS128 / DPS64 card
    • DC Scale UHC4 / UHC4T card
    • DC Scale XPS256 card
  • Twinning DUT interface

V93000 Smart Scale system (SmarTest 8)

The following product-specific design rules apply to the V93000 Smart Scale system running SmarTest 8:

  • DC Scale cards
    • DC Scale AVI64 card
    • DC Scale DPS128 / DPS64 card
  • Digital cards
    • Link Scale USB3 card
  • MUX cards
  • Twinning DUT interface

V93000 Smart Scale system (SmarTest 7)

The following product-specific design rules apply to the V93000 Smart Scale system running SmarTest 7:

  • DC Scale cards
    • DC Scale AVI64 card
    • DC Scale DPS128 / DPS64 card
    • DC Scale DPS32 and VI32 card
    • DC Scale FVI16 card
    • DC Scale PVI8 card
    • DC Scale UHC4 / UHC4T card
  • DPS-slot device power supplies
    • General Purpose DPS (GP-DPS)
    • High Current DPS (HC-DPS)
    • High Voltage DPS (HV-DPS)
    • Multisite DPS (MS-DPS)
  • MUX cards
  • Twinning DUT interface

V93000 Pin Scale system

  • DC Scale cards
    • DC Scale DPS32 and VI32 card
    • DC Scale UHC4 / UHC4T card
  • Digital cards
    • Pin Scale HX cards
  • DPS-slot device power supplies
    • General Purpose DPS (GP-DPS)
    • High Current DPS (HC-DPS)
    • High Voltage DPS (HV-DPS)
    • Multisite DPS (MS-DPS)

V93000 HSM system

The following product-specific design rules apply to the V93000 HSM systems:

  • Pin Scale HX cards
  • HSM DUT board design
  • Multisite DPS (MS-DPS)
  • Precision Parallel Source
