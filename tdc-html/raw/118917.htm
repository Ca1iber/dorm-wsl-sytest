Topic 118917

Hidden digital upload and calculation

Subtopics

  1. Result areas for hidden digital upload

The main difference compared to hidden calculation is that the digital upload is also integrated into your SMC_backgroundProcessing() method.

Digital capture uses a dual port memory allowing the upload of data while capturing new data. However, before digital capture test is executed, the result areas need to be defined.

In summary, SMC_ARM() kicks off the threads. SMC_GET_VECTORS() waits until the upload gets triggered by a SMC wrapper API like SMC_WAIT_TIME() or SMC_FUNCTIONAL_TEST(). SMC controls the serial data upload. The DSP threads continue with the parallel calculation immediately afterwards and the test results get buffered until a SMC_SYNCHRONIZE() is performed.

Note If no limits are assigned to the test suite and TMLimit is not used, the limits assigned to SMC_SYNCHRONIZE() will be used.

This reflects the ideal case in terms of test time reduction, because the entire upload and calculation is hidden behind 'other test(s)'. The user has to take care about the memory allocation for the digital data.

Note For using hidden upload, Xpress Data Mode has to be enabled, which requires a license.

Example

class runSNRtestMethod: public testmethod::TestMethod
{
     protected:
      virtual void initialize()
      {
         addLimit("test_limit");
      }
     virtual void run()
     {
          ON_FIRST_INVOCATION_BEGIN()
               // digital capture setup for hidden upload
               RESULT_AREA_CONFIG resConf("pin1"); //capture pin
               resConf.appendArea("1kBitArea", 3072).activate();

               // setup and execute your test as usual, but use the SMC_xxx API
               ...
               SMC_DIGITAL_CAPTURE_TEST("1kBitArea");
               LIMIT lim = GET_LIMIT_OBJECT("test_limit");

               FOR_EACH_SITE_BEGIN()
                    // kick off calculation thread
                    SMC_ARM("1kBitArea", lim);
               FOR_EACH_SITE_END();
          ON_FIRST_INVOCATION_END();
     }

     public:
     void SMC_backgroundProcessing(STRING area, LIMIT lim)
     {
          // trigger upload when SMC wrappers indicate non-blocking action
          // a reference to the captured data is copied here, as we
          // do not access the data outside this function
          // (or after SMC_SYNCHRONIZE())
          const ARRAY_I& data = SMC_GET_VECTORS("VectorVariable", area);

          // do your calculation
          DSP_SNR(data,&snr,&sPow,&nPow, 1024, 1, 3, 0.0, 0);

          // do judgment
          SMC_TEST("pinDGT","SNR", lim, snr,,"55");
          SMC_TEST("pinDGT","signalPow", lim, sPow,,"57");
          SMC_TEST("pinDGT","noisePow", lim, nPow,,"59");
     }
     (...)
}
