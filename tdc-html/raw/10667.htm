Pin Configuration Example

The following is an example of a configuration file.

Note In the following file, some lines contain comments beginning with "--". These comments have been included to improve your understanding of the firmware commands. Please note that it is not possible to include comments in your firmware command files!
hp93000,config,0.1
DFPN 10101,"13",(CP)    -- DeFine Pin Name for each pin
DFPN 10102,"7 ",(D3)
DFPN 10104,"21",(D0_NCET)
DFPN 10105,"16",(MR)
DFPN 10106,"20",(NCEP)
DFPN 10202,"9 ",(P3)
DFPN 10115,"10",(P2)
DFPN 10114,"11",(P1)
DFPN 10113,"12",(P0)
DFPN 10109,"19",(S2)
DFPN 10110,"18",(S1)
DFPN 10111,"17",(S0)
DFPN 10204,"5 ",(NQ3)
DFPN 10207,"4 ",(NQ2)
DFPN 10212,"26",(NQ1)
DFPN 10206,"25",(NQ0)
DFPN 10108,"23",(NTC)
DFPN 10103,"6 ",(Q3)
DFPN 10116,"3 ",(Q2)
DFPN 10112,"27",(Q1)
DFPN 10107,"24",(Q0)
DFGP I,(P3,P2,P1,P0,S2,S1,S0),(preset)    -- DeFine GrouPs
DFGP I,(S2,S1,S0),(select)
DFGP O,(NQ3,NQ2,NQ1,NQ0),(NQ_out)
DFGP O,(Q3,Q2,Q1,Q0),(Q_out)
CONF I,F160,(CP,D3,D0_NCET,MR,NCEP,P3,P2,P1,P0,S2,S1,S0)    -- CONFigure pins
CONF O,F160,(NQ3,NQ2,NQ1,NQ0,NTC,Q3,Q2,Q1,Q0)
RDIV 50,(NQ3,NQ2,NQ1,NQ0,NTC,Q3,Q2,Q1,Q0)    -- set Resistive Divider Vals
DFPS 13,POS,(Vee)    -- DeFine Power Supply pin
PSLC 4.7,(Vee)
