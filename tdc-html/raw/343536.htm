The <tmu> element

This element stores results of a TMU test performed using the SmartRDI's tmu() class.

The <tmu> element stores TMU test results in its stamp attribute. This attribute saves TMU test results returned by a getStamp() function.

Note The getArm(), getMultiArm(), getPreScaler() and getInterSkip() can return right results in offline mode and thus do not need ORE.
Get Result Function in SmartRDI

ORE File Syntax Example

ARRAY_D getStamp(pin);

<tmu stamp = "-1.22,1.51,1,82" />

or

<tmu stamp = "./ORE/waveform.txt" />

Example

Below is an example of the <tmu> element and its corresponding SmartRDI code block.

An ORE file containing <tmu> elements:

<id name = "tmu1">
  <pin name = "DATA1">
    <tmu stamp = "1.22,1.51,1,82"/>
  </pin>
</id>
The corresponding SmartRDI code block that can generate this ORE file:
RDI_BEGIN();
  rdi.tmu("tmu1").pin("DATA1").vth(1.5)
                 .samples(4).measMode(TA::RISE)
                 .execute();
  rdi.wait(10 ms);
RDI_END();
...
rdi.id("tmu1").getStamp("DATA1"); // {1.22,1.51,1,82}
