Topic 125038

Processor-based device

Today's complex SOC devices typically consist of several independent internal building blocks. Usually there a CPU is responsible of the sequence of interactions executed between these building blocks. This unit typically can be accessed over the device's external control interface to establish communication from a surrounding system which could be either the native application or a test system.
