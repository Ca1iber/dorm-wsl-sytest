Topic 10621

Specifying the period

Subtopics

  1. Defining the global period
  2. Determining the period resolution

You can define a global period for all pins, and also different periods for individual pins, which will override the global value. The global period must exist; if you do not specify it, it will be set to a default value.

Note You cannot define pin specific periods in a multi-port setup (see Restrictions for multiport setups).
Note Pin specific periods are not supported by the result tools.
Note For Smart Scale systems more sophisticated conditions apply, refer to Period resolution for a multi-port setup (Smart Scale).

Functional changes
