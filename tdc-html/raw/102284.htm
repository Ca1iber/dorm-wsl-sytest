Prober/Handler

Subtopics

  1. Selecting a Prober/Handler command set

The driver consists of two main components

  • the general equipment driver, and
  • equipment specific plug-ins.

The term "equipment" stands for either handler or wafer prober.

This means there is one general handler driver and one general wafer prober driver. Likewise, there are handler specific plug-ins and wafer prober specific plug-ins, each plug-in to be used with the corresponding general equipment driver.

The Prober/Handler icon in the Test Program Explorer view is used to select the general equipment driver.

Note To use a library generated on 32-bit system for a 64-bit system or vice versa, you need recompile the source code to generate the library for the new system.
