Debugging the testflow during tests with the Test Cell Control Tool

If some error occurrs during the test with TCCT, you can debug the testflow in the EWC.

Before you begin

Make sure TCCT is started and a SmarTest session is started in engineering mode. The testflow was loaded and executed.

Procedure

  1. In the EWC, if the user interface is in suspended mode, click 93000 in the main toolbar and uncheck the UI updates suspended option.
  2. Debug the test suite(s) with error(s) to solve the problem in the EWC.

Results

The problems found in the execution of the testflow are solved.
