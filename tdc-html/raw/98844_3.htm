Topic 98844

VCLK? - (Verify CLocK)

The VCLK? (Verify CLocK) query checks if the desired test system period will cause auto-correction. The system responds with a 0 or a 1 to indicate auto-correction.

You allocate a test system period per timing set to the specified pin or pins using PCLK, PCLK? - (Pin CLocK).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

VCLK? {waveform_set}, {timing_set}, {period}, {(pinlist)}

returns:

VCLK {autocorrect}

Equation-based testing

VCLK? {specset_id|"multi-port_spec"}, {timing_set}, {period},{(pinlist)}

returns: 

VCLK {autocorrect}

Parameters

waveform_set

Waveform set number. Enter PRM for the primary waveform set, or an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by WSUS, WSUS? - (Waveform Sets USed).

specset_id

Derived as follows:

100 * equation_set_no + specset_no

multi-port_spec

To enter a multi-port specification is only possible if the specification is associated with the default port and if no other ports are configured.

timing_set

Timing set number. Enter PRM for the primary timing set, ALL for all timing sets, or an integer in the range 1 to the maximum number of allowed timing sets. The maximum number is determined by TSUS, TSUS? - (Timing Sets USed).

period

Enter the test system period in ns for which you wish to check whether auto-correction will take place or not. period must be within the maximum and minimum test system periods of the model.

pinlist

The name of the pin or pins whose period you want to check. This parameter can also include groups previously created by DFGP, DFGP? - (DeFine GrouP). If more than one pin is to be included, the names must be separated with a comma. The @ symbol can be used to check all configured pins.

autocorrect

The auto-correction flag returned by the system. It can be:

0

No auto-correction will occur.

1

Auto-correction will occur.

Application

Timing setup, see Timing Setup Commands.

Errors

An error is generated if:

  • The period is outside the given range.
  • waveform_set is outside the valid range.
  • timing_set is outside the valid range.

Example

VCLK? 1,1,20,(@)

This example checks if a period of 20 ns will cause auto-correction to the edge placements in Timing Set 1 of Waveform Set 1 on any pin. If no auto-correction will occur the following string is returned: 

VCLK 0

Functional changes

  1. Introduced before SmarTest 6.3.2
