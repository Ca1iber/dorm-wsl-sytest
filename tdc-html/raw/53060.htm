DUT interfaces

  2. DUT Scale interface
  3. Twinning DUT interface
  4. Remote control unit (V93000 EXA Scale system)
  5. Remote control unit (V93000 Pin Scale / Smart Scale system)

The DUT interface on the test head consists of high-performance coaxial cabling and spring-loaded contact pins (pogo pins) that provide electrical contact between the test head electronics and the DUT board. The DUT interface can also contain a mechanism for docking to handlers and wafer probers.

Advantest offers a common DUT interface for all V93000 test heads to provide DUT board compatibility across all classes of test heads.

CAUTION The DUT interface can carry a maximum weight of 25 kg.
