The ASCII vector files, which have the standard extension *.avc, are the main input files for the vector translation. In contrast to the timing translation, where you specify a single ASCII timing file for one run of the high level tool ait, the ASCII vector files are pattern specific; a separate ASCII vector file is passed to the high level tool aiv in the vector configuration file for every call of v2b.

You can insert comments into the file. These are identified by the hash character (#); if this character occurs in a line, the rest of the line after the hash character will be considered as a comment.
