Executing shmoo tests with the Shmoo Tool

There are three manners for you to execute a shmoo test with the Shmoo Tool.

Before you begin

  • Set up a shmoo test in the Shmoo Tool.

    Or,

  • Transfer a shmoo test from a shmoo test suite into the Shmoo Tool.

Procedures

Manner A

From the toolbar of SmarTest, click (the Run Shmoo shortcut).

For the other shortcuts in the toolbar, see Commands in the menu bar and their shortcuts in the toolbar.

Manner B

From the menu bar of SmarTest, select Shmoo > Run Shmoo.

For the other commands in the Shmoo menu, see Commands in the menu bar and their shortcuts in the toolbar.

Manner C

On the shmoo page related to the shmoo test, right-click anywhere on the shmoo page and select Run.

For the other commands, see Commands in the shmoo editor of the Shmoo Tool.

Results

A shmoo plot is displayed on the related shmoo page in the shmoo editor.

Different cells on the shmoo plot may have different colors. For details, see Colors on shmoo plots.

What to do next

View the shmoo plot with zooming, changing result pins, Test modes and sites, or viewing a selected area of the plot. For details, see Viewing shmoo plots with the Shmoo Tool.
