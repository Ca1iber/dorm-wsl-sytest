Topic 141131

DIGITAL_OFFSET_SEARCH_PINS.DigitalOffsetResultReset()

Resets the offsets of specific timing or level sets to the default value.

Alternatively, use the TORR firmware command to reset.

Syntax

void DigitalOffsetResultReset (DIGITAL_OFFSET_SEARCH::SetSelector & selector);
Parameter

Parameter

Description

selector

It can be:

  • A TimingSetSelector object defined with TimingSetSelector, selects timing sets. Or,
  • A LevelSetSelector object defined with LevelSetSelector, selects level sets.

Return value

There is no return value.

Related information

TORR (Timing/level Offset Reset Result)

Functional changes

  1. Introduced in SmarTest 7.2.1
