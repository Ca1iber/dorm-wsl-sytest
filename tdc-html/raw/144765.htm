Topic 144765

setAnaSet()

Specifies the analog set name for the next RDI_BEGIN()/RDI_END() block.

Syntax

setAnaSet(const string &setName);
List of parameters

Parameter

Description

setName

The analog set name

Example

rdi.setAnaSet("set1");

Functional changes

  1. Introduced in SmartRDI 2.1.0
