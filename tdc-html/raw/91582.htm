Topic 91582

Pin Scale HX card requirements for loopback mode

In loopback mode Pin Scale HX card does not require any Pin Scale 3600 channels to be routed.

As there exists no multiplexing or de-multiplexing, it might be necessary to route some auxiliary signals (for example, external jitter injection, level selection enable, and so on), depending on the application.

Functional changes

  1. Introduced before SmarTest 6.3.2
