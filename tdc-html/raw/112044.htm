How to issue a query

The signature query is used to execute the data query command of HVM API.

About this task

These APIs include:

GetOnlineSmartestSessionID, GetSmartestSessionProfile, ListInstalledSmartestVersions, ListSmartestSessionIDs, PingSmartestSessions, GetApplicationProfile, GetLastEvent, GetLevelProfile, GetSmarTestExecStatus, GetControllerInfo, GetLoadboardInfo, GetInstrumentInfoById, GetProbeCardInfo, GetTesterInfo, GetTestHeadInfoByID, GetTestBoardInfoByID, GetTestModuleInfobyID, GetCalStatus.

The prototype of query is defined as

xoc::hvmapi::Status query(
const std::string &qrName,
xoc::hvmapi::ParamList &qrResults,
const xoc::hvmapi::ParamList &qrParams=xoc::hvmapi::ParamList(),
const std::string &sessionId=std::string("") );

The session ID of SmarTest is required to execute some API. If you Do not know it, you can get the session ID with the API GetOnlineSmartestSessionID or ListSmartestSessionIDs.

Before you begin

Make sure you are using SmarTest 6.2 or later versions.

Procedure

  1. Prepare the parameters and session ID to be used by the API.

    Each API has different parameters. You refer to the code template below.

    ParamList qrResults, qrParams;  //define the variables
string sessionId = ":0"
qrParams["param1"] = "value_for_param1";  //set values for parameters
qrParams["param2"] = "value for param2";
  2. Execute the query and output the result. 
    Status obj = query("API_to_execute", qrResults, qrParams, sessionId);
if( obj.success() )
{
  std::vector<std::string> varList = qrResults.valueArray("result1");
  std::vector<std::string> valueList = qrResults.valueArray("result2");

  for(int i=0; i<varList.size(); i++) 
  {
    std::cout << varList.at(i) << " : " << valueList.at(i) << std::endl;
  }
}

Results

The API is executed and outputs the results. An error object will be returned to indicate the execution status of the API.

Example

The following example shows how to get a SmarTest session profile using the query signature.

ParamList qrResults;
string sessionId = "sessionId"; // the exact session ID such as ":13"
Status retVal = query("GetSmartestSessionProfile", qrResults, ParamList(), sessionId);
if(retVal.isSuccess())
{
  cout <<"SmarTest session " << sessionId <<" profile: "<<endl;
  cout <<"Revision: " << qrResults["VERSION"] << "."<< qrResults["PATCH_LEVEL"] <<endl;
  cout <<"Online_mode: " <<qrResults["ONLINE_MODE"] <<endl;
  cout <<"User_mode: " <<qrResults["USER_MODE"] <<endl;
  // ...
}
