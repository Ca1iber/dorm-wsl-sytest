TMU_PIN measurement status

Subtopics

  1. TMU_PINS.errorState()
  2. TMU_PINS.getStatus()
  3. TMU_PINS.getPinsFinishedButMayFailed()
  4. TMU_PINS.getPinsFinishedNotFailed()

  6. TMU_PINS.getPinsNotFinished()

The methods in this section return the status of completed TMU measurements.

These values are available after waitTmuFinished(). They can be used before upload and enables you to decide whether upload should be executed.

Status errors are transferred form TMU_PINS into TMU_RESULTS only after upload.

Functional changes

  1. Introduced in SmarTest 7.4.3
