SOURCESYNC_TEST.repeatWholeSweep()

Specifies how many times a sweep test will be repeated.

If an edge fails in one of the repeat tests, this edge is regared as fail after the repeat test.

Syntax

SOURCESYNC_TEST& repeatWholeSweep (const int repeatWholeSweep);
Parameter

Parameter

Description

repeatWholeSweep

The repeat times for a sweep test. The default value is 1.

Related information

SOURCESYNC_TEST.repeatSameTiming()

Functional changes

  1. Introduced in MTP 3.2.2
