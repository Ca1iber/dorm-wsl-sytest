Topic 140968

DIGITAL_OFFSET_SEARCH_TASK.pin()

Specifies the pins on which you want to search for the timing or level offsets.

Syntax

DIGITAL_OFFSET_SEARCH_PINS& pin(const STRING& pinlist);
Parameter

Parameter

Description

pinlist

The pins on which you want to search for timing or level offsets.

Return value

Returns the reference to a DIGITAL_OFFSET_SEARCH_PINS object so that you can use its member functions to set up search conditions for the specified pins.

Example

STRING strpins1("pcie_tx1n");
DIGITAL_OFFSET_SEARCH_TASK dos;

dos.pin(strpins1).resourceType(VIH);

Related information
