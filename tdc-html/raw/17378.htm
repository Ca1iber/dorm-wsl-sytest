Topic 17378

Changing Spec Values

About this task

Occasionally you may need to change values for specs/variables in a particular specification file. Although this process is essentially the same as editing the values directly in the Spec Tool table, if you have a lot of variables in your different spec sets, editing them in the table can become tedious.

Note You define the units in the equation based spec setup only. You cannot define units using the spec tool.

Procedure

  1. Click Change Spec Values in the Edit menu.

    A screen similar to that of the figure below appears.

  2. Highlight the variables you want to change.
  3. Highlight the specification sets whose variables you want to change.
  4. Click a toggle button (value, min, max and unit) to get access an edit field.
  5. Double-click in the edit field, and key in a new value for the entity.
  6. Repeat these last two steps for any other entities you want to change.
  7. When you have finished editing entity values, click assign.
  8. Repeat this process as often as required (for other variables/specification sets), and click done when finished.

Functional changes

  1. Introduced before SmarTest 6.3.2
