TMU_PINS.setLongTimeCorrection()

This method activates or deactivates support for long-time measurements.

Depending on the clock setup, TMU hardware can only generate time stamps for about 15 to 17 seconds of measurements before wrapping. If you perform longer measurements, activate this option. The software will then auto-correct the samples by adding a suitable offset.

Syntax

TMU_PINS& setLongTimeCorrection(Boolean active = FALSE);
Parameter

Parameter

Description

active

Whether the long-time correction is on or off:

  • False: No correction will be performed. (Default).
  • True: The software will correct the wrapped-around time stamps.

Return value

There is no return value.

Functional changes

  1. Introduced in SmarTest 7.2.0
