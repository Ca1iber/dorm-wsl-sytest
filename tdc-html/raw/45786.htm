TestMask

Class TestMask is responsible for test mask operations. This class is a member object of class Graph. A Graph object has only one test mask.

Member functions

setTestMaskStyle()

TestMask & setTestMaskStyle(bool isAnd, Display::Color color);

This function sets the test mask style.

Parameters

isAnd

The junction among the multiple inequalities in the test mask. be:

  • true: The junction is AND.
  • false: The junction is OR

color

The color of the masked points or area. It can be:

BLACK, BLUE, CYAN, DARK_GRAY, GRAY, LIGHT_GRAY, GREEN, MAGENTA, ORANGE, PINK, RED, YELLOW, WHITE or AUTO.

Example

GraphManager * graphManager = GraphManager::getInstance();
ARRAY_D waveform = Analog.DGT("digitizer").getWaveform();
vector<double> wfm;
for (int i = 0; i<waveform.size(); i++)
{
  wfm.push_back(waveform[i]);
}
Graph graph;
TestMask testMask;
TestMaskInequality inequality;
// If y-value is over 0, the point will be highlighted with red
inequality.setTestMaskInequality(0,1,0);
testMask.setTestMaskStyle(1,Display::RED);
testMask.setInequality(inequality, 1);
graph.setTestMask(testMask);
graphManager->setGraph(graph, 1);

This example retrieves the waveform data from digitizer and sets the test mask to highlight the points if the y-value is larger than 0. And then the waveform data is plotted in graph 1 of the signal analyzer.
