WSMM Family Board E8027FAA pogo block mapping

The family board of the Wave Scale Millimeter (WSMM) solution maps custom configured DUT Scale interface resources to the pogo blocks of the WSMM Card Cage DUT interface. The mapping of the pogo blocks is shown in the following tables.

The tables cover the mapping of the pogo blocks for the WSMM Family Board E8027FAA (E8027-66402, Rev. 1).

For the mapping of the individual pogo pins, refer to WSMM Family Board E8027FAA pogo pin mapping.

The following sections are available in this topic:
  • Pogo blocks of the DUT scale interface
  • Pogo blocks of the WSMM Card Cage DUT interface
  • Color scheme
  • Important restrictions

Pogo blocks of the DUT scale interface

Some notes on the pogo block mapping:
  • One DPS128 card is routed to DPS-slots of the DUT Scale interface using the MS‑DPS style pogo blocks. For more information, refer to DPS128 / DPS64 pogo cable assemblies and pogo pin assignments.
  • Some pogo blocks of the DUT Scale interface occupy only a half of a WSMM Card Cage pogo block:
    • MS‑DPS style pogo blocks of DPS128 (DPS-slot)
    • Standard-density PS1600 and PS9G pogo blocks
    • WSWB pogo blocks
  • Pogo blocks 305/5403 can be configured for the WSMX card or for the PS9G card. Maximum one WSMX card is supported by the family board if all four PS9G pogo blocks are to be routed to the WSMX DUT interface. For the second (optional) WSMX card, only one of the two WSMX-HD pogo blocks can be routed to the WSMX DUT interface.
  • Pogo block usage "General" of block 423 means a 1:1 direct through connection via an E8027CXP coaxial pogo block for digital/mixed signal.

Important restrictions

The following restrictions must be respected when designing a DUT board for the WSMM solution:
  • Digital channels
    • 11615 (WSMM block.pin = 6418.A16)
    • 11616 (WSMM block.pin = 6418.B17)
    are normally routed to the DUT interface but can be configured to control the WSMM Card Cage switches in the old way. For this purpose, switches are inserted into the signal path on the family board and the impedance is therefore slightly different from that of the other channels.
  • Digital channels
    • 11613 (WSMM block.pin = 6418.A14)
    • 11614 (WSMM block.pin = 6418.D15)
    have longer routes on the family board in order to match pins 11615 and 11616 as differential pairs.
  • UP5V supply current capability on utility blocks
    • UTIL 4 (WSMM block.pin = 7225.A05 and 7225.B04)
    • UTIL 5 (WSMM block.pin = 4129.A05 and 4129.B04)
    • UTIL 8 (WSMM block.pin = 7221.A05 and 7221.B04)
    is restricted depending on the installed RMMs.
