How to create a test method with concurrent test framework

Subtopics

  1. How to implement a concurrent test method
  2. How to import the CCF files in an existing project
  3. Doing retest with the concurrent test framework
  4. How to handle the fail branch with concurrent test framework

About this task

To create a test method with concurrent test framework, you can follow the same procedure as creating a normal test method.

Procedure

  1. Create a test method project with New Test Method Project wizard, see How to create a universal test method project.
  2. Create a concurrent test method with Create a new test method class wizard and select the Concurrent test method class as the template, see How to create a universal test method class.

    Test method library ccf_tml will be imported from /opt/hp93000/soc/testmethod/library into the path you specified. The library file libccf_core.so will be copied to the directory device/testmethod/sh_libxxx/preload.

    The path ccf_tml/ccf_include will be added to the include directory in your UTM project property. (property-> paths and Symbols -> Includes)

    To get the concurrent test framework version information, you can use the predefined string type variables MAJOR_RELEASE, ENHANCE_RELEASE and FIX_BUG_RELEASE. These variables are included in the file ccf_tml/ccf_include/internal/CCVariables.hpp.

  3. Implement your concurrent test method following the provided template, see How to implement a concurrent test method.
  4. Build the test method project. If any errors occurred, correct the errors and rebuild it until no error exists.

Functional changes

  1. Introduced in SmarTest 6.5.4
  2. SmarTest 7.1.3: Supports creating concurrent test method with Create a new test method class wizard.
