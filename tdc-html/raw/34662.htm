TestEventType

An event of this type is logged for every execution of an individual test that is part of a complete test method execution. For example, a DC test method can perform the two individual tests Leakage high and Leakage low.

Many of the attribute types that can come with an event of this type are specific for only one test or a small number of tests.

Examples:

  • Attributes of the type ShmooLegendAttrType occur only when sweep tests are performed.
  • Attributes of the type LinearWaveformAttrType occur only when mixed signal tests are performed.

The attributes appear in unspecific order.

Attributes

  • TestNameAttrType

    Holds the name of the executed test.

  • TestIdAttrType

    Holds the ID of the executed test.

  • PassFailResultAttrType

    Holds the overall pass or fail result of the executed test.

  • PassRangeAttrType

    Holds the upper and lower limits that define the pass range for the measured value, whether these values are inner or outer values of that range, and the unit of the limits. Depending on the test (for example, for Hold Time), this attribute may also hold just one value defining the pass/fail limit.

  • MeasuredRangeAttrType

    Holds the highest and the lowest value that were measured during execution of the test, and the unit of the measured values.

  • PinPFResultAttrType

    If the executed test performed a pass/fail test only, this attribute holds the pass/fail results of all tested pins.

  • PinValueResultAttrType

    If the executed test performed a value measurement, this holds the result values with units of all tested pins, and the pass/fail results of all these pins.

  • PinRangeResultAttrType

    If the executed test performed a value range measurement, this holds the result value ranges (minimum and maximum measured value) with units of all tested pins, and the pass/fail results of all these pins.

  • ValueResultAttrType

    This attribute is used if the value is not associated with a pin. For example, the IDDQ test function logs the sum of all measured currents as a value result attribute.

  • FailingCycleAttrType

    Holds a list of all pins which failed in a certain cycle during the test execution. This attribute type is repeated once for each cycle in which one or more pins failed.

  • VectorResultAttrType

    Holds a set of data that specifies a cycle, and holds a list of drive data, expected data, received data, and edge information for each tested pin.

    Whenever a vector fails during the execution of a test function, and the first failing vector flag (ffv enable) is set for the test suite, attributes of this type will be logged with the event. The number of attributes that appear with the event depends on the settings for the two Testflow flags log_cycles_before and log_cycles _after. With these two flags you can specify for how many previous and following cycles of a failing cycle additional data will be logged. For each such cycle, one attribute will then be stored with the event.

  • VectorFineResultAttrType

    If the test was executed in per-edge mode (multishot detailed or single-shot pass/fail), this holds cycle number, vector label, label type, vector number, sequencer command, result and comment for one cycle, and the results of each pin.

  • LinearWaveformAttrType

    Holds the values and complete presentation data for a waveform that has been measured or calculated from the measured values of a mixed signal test for a list of pins (usually one pin).

  • ShmooLegendAttrType

    Holds the complete data that defines the executed sweep test. The title, the type of sweep test (Shmoo2D, ShmooTrack, ShmooSpec), the mode (Normal, ERCT, FFCI), the definition of the x- and y-axis, and all tracking parameters.

  • ShmooCellAttrType

    Holds the complete result data of the executed sweep test. This result data is organized in cells, where each cell represents one point of the shmoo-plot that is the graphical presentation of the sweep test result.

  • CycleAttrType

    Holds the number of the cycle up to which the functional pretest for the executed test was run.

  • VectorAttrType

    Holds the number of the vector up to which the functional pretest for the executed test was run.

  • XYDataResultAttrType

    Holds data and results of a jitter test for graphical displaying.

  • ParametricOrFunctionalTestAttrType

    Contains an enumerated value of the type of test being performed.

  • TestDescriptionAttrType

    Allows a string of information to be passed with a test event.

  • TimeStampAttrType

    Holds the time when the test was finished.

  • TestSuiteNameAttrType

    Holds the name of the a test suite.

  • SiteIdAttrType

    Holds the site number (ID).

  • RARepairResultsAttrType

    Holds the results of an redundancy analysis.

  • AlarmAttrType

    Holds the ID of an alarm.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.1.3: Added TestSuiteNameAttrType and SiteIdAttrType required by hidden data logging.
  3. SmarTest 7.2.2: Added RARepairResultsAttrType attribute.
