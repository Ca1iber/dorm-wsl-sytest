Creating and editing an STPM MCM control file

The control file for SmarTest Program Manager MCM (STPM MCM) can be created and modified with a standard text editor. It follows the syntax conventions of the Python programming language.

About this task

Perform this task to create a new control file for STPM MCM or modify an existing one.

Before you begin

Install STPM MCM as described in Installing SmarTest Program Manager MCM.

Procedures

Creating a new control file

You can create a control file from scratch, using the syntax described in STPM MCM control file. However, it is usually much more convenient to start with a template create by STPM:

  1. In a terminal, enter:
    stpm_mcm -template

    This creates the stpm_mcm_setup_template.setup template file for the control file in ./templates/.

  2. Open the template and edit it as desired.

    The control file syntax is described in STPM MCM control file.

  3. Save the file.
  4. If desired, rename it and/or put it into a different location.

    An STPM control file can have any name and be stored in any location. It also does not require a specific filename extension, although .setup and .py are common.

Editing an existing control file

  1. Open the control file that you want to edit with any text editor.
  2. Make the desired changes.

    The control file syntax is described in STPM MCM control file.

  3. Save the file.

    If desired, you can put it into another location and/or rename it.

Results

You have a control file that you can use to control STPM MCM's operation.
