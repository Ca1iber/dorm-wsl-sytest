Topic 15024

View control area

Subtopics

  1. Current cycle and pattern
  2. Navigation area
  3. Error map tabs

The view control area of the Error Map Tool displays the error results of the executed test setup.

The view control area consists of the following four sections (see the figure below):

  • Current cycle and pattern
  • Navigation area
  • Error map tabs
  • Per Pin tab

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.1.1: Displaying the current pattern and its cycle number
