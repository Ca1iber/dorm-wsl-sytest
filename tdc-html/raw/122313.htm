CCTgetResultHandle

This function returns the result handle name for hidden upload of analog waveform.

This function is usually used in the preStart(), postStart(), process() and cleanup() function but not used in the init() function of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

string CCTgetResultHandle();

Example

dgtz_waveform = SMC_GET_WAVEFORM(dac_out, CCTgetResultHandle(), CCTgetUploadId(dac_out));

In this example, the waveform is retrieved for the result handle from CCTgetResultHandle() and the upload ID from CCTgetUploadId().

Functional changes

  1. Introduced in SmarTest 6.5.4
