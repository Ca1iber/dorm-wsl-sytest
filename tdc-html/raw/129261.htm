SHARED_LEAKAGE_PARALLEL_TEST.settlingTime()

The settlingTime() member function of SHARED_LEAKAGE_PARALLEL_TEST lets you specify the additional settling time for a test.

Syntax

SHARED_LEAKAGE_PARALLEL_TEST& settlingTime(double time)

Parameter

Description

time

The additional settling time.

  • The unit is second (S).
  • The default time value is 0 S.

Example

SHARED_LEAKAGE_PARALLEL_TEST mTest;
mTest.settlingTime(0);
mTest.settlingTime(1);

Related information
