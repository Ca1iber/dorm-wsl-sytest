EVENT_CMP.low()

This member function defines the low match compare setting. It is used for match loops and matches if the value is lower than the low threshold.

Syntax

void low ();

List of parameters

There are no parameters.

Return value

There is no return value.

Example

For an example see EVENT_CMP.
