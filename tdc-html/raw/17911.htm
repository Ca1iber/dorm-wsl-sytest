Topic 17911

Selecting Other Saved Formats

The test system allows you to store up to 999 different table formats. The last three formats that you have used are always listed in the Format pulldown menu as options select format<format_name>.

To select one of these formats, simply pick the option. To get at the other saved formats, pick the get other formats option and select the format you require from the format list browser in the dialog box. Then click select.
