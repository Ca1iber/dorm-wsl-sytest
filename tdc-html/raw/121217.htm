Importing layouts of the Pattern Editor

The import of pattern layouts saves you the effort to recreate these layouts and also gives you the option to share them across a device.

About this task

You can import pattern layouts from any other version of the pattern debug tool: from the legacy blue-window version, from the Java-based version, or from the current Eclipse-based version. All use different type suffixes:

  • Classic, Multi, Single: Legacy layouts of the blue-window pattern debug tool
  • STWC-PDT: Legacy layouts of the Java-based Pattern Debug Tool
  • PDT: Current layouts of the Eclipse-based Pattern Debug Tool

When importing a current Eclipse-based layout and setting the Shared option (see below), you must also set the "Share Pattern Layouts across device" option on the Layout preference page.

Before you begin

Check the pattern editor layouts of your current device and verify, if they can be overwritten by the import layouts or not. Note that layouts may be bound to a certain pattern.

Procedure

  1. To import one or more layouts, click File > Import > 93000 > Pattern Debug Tool Layout Import. The Layout Import Wizard opens.
  2. In the wizard change to the device directory from where you want to import the layout(s). The wizard lists all pattern editor layouts of the selected device.
  3. Select the layouts you want to import. By default all layouts of the device are preselected.

    Besides that you have several options:

    • Overwrite existing layouts: Default is on (yes). If switched off, the import will create a copy of the existing layout. A second import with the same setting will overwrite that copy.

      Target Location

    • Shared: Saves the layout(s) independently of the current pattern (master) file.
    • Current Vector Context: Binds the layout(s) to the current pattern (master) file.

      Signal Modifier

    • Device Cycle (DVC) (default), State Character (SC), Physical Waveform (PW): Defines the initial display format in the pattern editor.
  4. Click Finish.

Results

The layout(s) are imported and shared across the device (if you selected the Shared option). The resulting data representation may vary from the original layout.

What to do next

You can select the imported layout(s) from the Pattern Editor. See Pattern Editor tasks.
