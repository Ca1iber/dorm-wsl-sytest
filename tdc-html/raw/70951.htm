Topic 70951

Single-shot per-edge pass/fail results

Pin Scale test systems default to the single-shot per-edge P/F result mode.

In single-shot-per-edge P/F result mode, the event data log uses the same output format as in multishot per-edge detailed result mode, but only pass/fail information per edge is shown.

Failing edges are indicated by a "#" sign, passed edges by a ".".

The multishot per-edge detailed result mode is not available when the H/L/I/U (multiple execution) flag in the FFV tab of Test Suite dialog is set.

Functional changes

  1. Introduced before SmarTest 6.3.2
