Pin Scale 5000 feature scope

The following features of the Pin Scale 5000 digital card are not supported by SmarTest 7.10.3 but subject to a later release:

  • time measurement unit
  • FAST mode capable of speeds up to 5.0 Gbps
    Note A pre-release version of FAST mode has been enabled on SmarTest 7.10.3 only for evaluation purposes.
  • Using PPMU as arbitrary waveform generator (AWG)

Functional changes

  1. Introduced in SmarTest 7.10.2
