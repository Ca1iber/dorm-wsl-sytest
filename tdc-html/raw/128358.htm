Utility pogo block - STH DUT Scale interface

The small test head system fitted with the DUT Scale interface uses an active wiring board to generate utility lines.

Supported V93000 systems : Smart Scale, Pin Scale, HSM

Each utility pogo block on the STH DUT Scale interface is connected via the utility cable to the corresponding connector on the wiring board. Depending on the type of pogo block selected, 2-row or 4-row, 16 or 32 utility lines are available on each block. This arrangement provides 128 or 256 utility lines in 8 pin groups. The utility cable is always the same and has the capacity for 32 utility lines. The pogo blocks are exchangeable and are plugged on to the end of the cable, see Utility line assignments.

Mapping of pin groups and utility pogo blocks

The layout of utility and DPS blocks on the DUT Scale interface is shown in below.

CAUTION The 4‑row utility block uses the row sequence c-a-b-d for compatibility with the 2‑row utility block. This sequence is different to the row sequence a-b-c-d of other 4‑row pogo blocks. Do not use the wrong row sequence a-b-c-d for the 4‑row utility block. Use only the correct row sequence c-a-b-d for the 4‑row utility block. Violating this rule results in unusable DUT boards.

A layout overview of utility and DPS blocks for all types of DUT interfaces and test heads is shown in Utility line assignments.

The power pogo pins of the same name and output voltage on all utility blocks used should be connected to common power planes of the DUT board. Note: The maximum allowed current per pogo pin is 1 A. This limit is not exceeded with evenly distributed currents. However, in case of a shortcut on a single pogo block, the current might be higher. To protect the power pogo pins from damage, polyfuses are mounted directly on the 4-row utility pogo blocks. In addition, polyfuses are available on the wiring board to protect the sense lines. When triggered, a polyfuse needs a short time to reset.

If an output is not used, you can leave the pins unconnected.

Wiring rules and notes

Some rules and notes are to be considered for the wiring of the utility line pogo blocks:

  • Not all signals may be present on all utility blocks. This may vary depending on the type of interface used.
  • On SmarTest Work Center DUT boards ensure that all power planes supplied by a particular external utility power line are connected together.
  • Pins PDCS, PDCF, PGDS, PGRD are connected to the High Precision PMU (HPPMU) of the Clock board. Note: The HPPMU functionality is not supported in SmarTest 8.
  • Pins SINP, SOUT, SCLK and FRAMn are used as serial utility line interface pins. For more information, refer to Sequencer‑controlled utility lines.
  • Pins URW14 and URW15 of utility block 1 (UTIL 1) are internally connected to the DUT Interface EEPROM of the system and can be used to control up to three more EEPROMS on the DUT board or probe card. For more information, refer to Utility Lines and DUT Board EEPROMs.
    Note Utility pins URW14 and URW15 on utility block 1 are not to be used for a purpose other than EEPROM access otherwise the readout from the DUT Interface EEPROM may become corrupted. This would be the case when the DUT Board is docked while an EDC dump is in progress. For more information, refer to EDC Dump in the "Service Guide Part 1".

  • The designation for utility pogo pins is URW00 ... URW15 (2‑row block) or URW00 ... URW31 (4‑row block). The corresponding scheme used by SmarTest is as follows:

    SmarTest 8:

    #01 … #16 or #01 … #32 with # to be replaced by the utility pogo block number 1 ... 8.

    The three‑digit pogo pin number is to be defined in the DUT board description file. For more information refer to SmarTest 8 topics DUT board description file reference or Controlling utility lines.
    SmarTest 7:

    UTI#01 ... UTI#16 or UTI#01 ... UTI#32 with # to be replaced by the utility pogo block number 1 ... 8.

    For more information refer to SmarTest 7 topics Utility Line view or Defining a utility line.
    V93000 EXA Scale systems (SmarTest 7 and 8)
    ###01 ... ###32 with ### to be replaced by the three‑digit utility pogo block number as defined in Utility pogo block mapping of Utility pogo block - Utility Card (V93000 EXA Scale systems).
    Note An offset of 1 is to be considered for transferring the utility pogo pin definitions of this section to SmarTest.
