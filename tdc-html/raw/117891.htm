CTestMethodConfig

This class provides an interface to the training parameters in the configuration file.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/training/include/TestMethodConfig.h.

parse()

void parse(const string &path, const string &fileName, bool force)

Parses the specifie configuration file and loads the found parameters into this instance of the CTestMethodConfig class.

Parameters

path

The path of the directory in which the configuration file is located.

fileName

The name of the configuration file to be parsed.

force

Whether an existing configuration is to be overwritten:

  • true: The specified file is parsed and its contents written to the class instance even if it already contains a configuration.
  • false: If the class instance already contains a configuration, the parse() function does nothing.

The default is false.

setSupportedParas()

void setSupportedParas(const string *pParas, const string *pValues, int size)

Sets the specified parameters to the supplied values.

Parameters

pParas

An array of parameter names.

pValues

An array of values that are to be stored in the parameters named in pParas.

The values must have the same order as the parameter names in pParas.

size

The number of parameter values in the pParas array (which must also be the number of values in the pValues array).
