DIGITAL_WAVEFORM.getWaveform()

This function returns the waveform data retrieved in the previous execution of the method execute() as ARRAY_I for the specified pin. The returned waveform data are integer offset values.

Syntax

const ARRAY_I& getwaveform(const STRING& pin) const
Parameter

pin

The pin to retrieve the waveform.

Related information
