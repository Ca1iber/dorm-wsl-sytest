CCTsetContextPins

Sets the pins or ports to be executed on the synchronous or independent sequencer.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

void CCTsetContextPins(const string &s_contextPins);
Parameter

Parameter

Description

s_contextPins

The pins to be executed on the specific sequencer.

Return value

There is no return value.

Example

STRING contextPins;
CCTsetContextPins(contextPins);

Functional changes

  1. Introduced in SmarTest 7.2.0
  2. SmarTest 7.2.1: Rename the API from CCT_setContextPins to CCTsetContextPins.
