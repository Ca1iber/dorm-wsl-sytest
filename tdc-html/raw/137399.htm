DRLShmooTestCellAttr

A variable of this taype holds the results of the cells on a shmoo plot:

  • numberOfPin: The number of the pins that display test results on a shmoo plot.
  • numberOfTestMode: The number of the available Test modes on a shmoo plot.
  • pinNames: Lists the names of the pins displaying test results on a shmoo plot. Different names are separated by ";".
  • testModes: Lists the available Test modes separated by ";".
  • numberOfCell: The number of cells on a shmoo plot.
  • cellData: The results data of each cell stored as the DRLShmooTestCellData type.

Syntax

typedef struct _DRLShmooTestCellAttr 
{
  unsigned int numberOfPin;
  unsigned int numberOfTestMode;
  const char* pinNames;
  const char* testModes;

  unsigned int numberOfCell;
  DRLShmooTestCellData* cellData;
}*DRLShmooTestCellAttr;
