Topic 30714

date_time

Subtopics

  1. Associated Syntax Entities

This keyword is used in conjunction with GET_TEST_INFO to assign the current date and time to a variable.

The format for the time mark is YYYYMMDD_HHMMSS (year, month, day, hours, minutes, and seconds).

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.4: Changed the output format of the date and time
