NB Digital Capture Overview

The non-blocking (NB) function is designed to execute tests which utilize analog sequencer settings that also require digital capture (for example, ADC). This functionality allows the user to continue to execute firmware commands on analog instrumentation while the digital sequencer is running (concurrent test).

The benefit of using concurrent tests is that independent IPs can be tested in parallel.

Because the execution time of a single digital test may be much longer than the longest individual analog test, it is helpful to join several analog tests together in a single test sequence to better balance the concurrent activity.

Simple techniques allow a single test sequence to perform several analog tests. However, if the analog instruments need to be used on multiple DUT pins, routing changes are required.

To create multiple analog tests in a single concurrent testsuite using routing changes, non-blocking execution is required.

The following sections describe some considerations for executing several analog tests in a single testsuite to achieve the most efficient parallel execution.
