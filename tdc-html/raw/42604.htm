Topic 42604

Assignment of Timing and Level Values by Equations

You can use equations in a multisite test exactly as you would for a single-site test.

Internally, the system creates its own equation system for each site. While the equations are equivalent for all sites, variables can take different values - depending on a SpecSearch for example. So you can run multisite tests for devices with output-dependent timings.

Functional changes

  1. Introduced before SmarTest 6.3.2
