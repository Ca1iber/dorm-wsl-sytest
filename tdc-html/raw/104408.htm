Topic 104408

Function: ph_get_status

This function retrieves various kinds of production information from probers or handlers. Different parameters are supported for different probers or handlers.

Parameters supported for probers

Parameter

Description

Applicable probers

wafer_size

The wafer size.

TEL P8, P12

TSK UF200, UF300, UF3000

The height of the die.

TEL P8, P12

TSK UF200, UF300, UF3000

The width of the die.

TEL P8, P12

TSK UF200, UF300, UF3000

The units used to describe the die size.

TEL P8, P12

TSK UF200, UF300, UF3000

wafer_flat

The orientation of wafer flat.

TEL P8, P12

TSK UF200, UF300, UF3000

center_x

The x-coordinate of the center die.

TEL P8, P12

TSK UF200, UF300, UF3000

The y-coordinate of the center die.

TEL P8, P12

TSK UF200, UF300, UF3000
