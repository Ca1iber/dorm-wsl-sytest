SHARED_IDD_TEST.samples()

The samples() member function of SHARED_IDD_TEST lets you specify the number of measurements to be averaged.

Syntax

SHARED_IDD_TEST& samples(int samples)

Parameter

Description

samples

The number of measurements to be measured.

  • The default value is 8.

Example

SHARED_IDD_TEST mTest;
mTest.samples(10);

Related information

SHARED_IDD_TEST

Functional changes

  1. Introduced in MTP 3.1.3
