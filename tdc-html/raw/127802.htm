TESTSET().testtext()

Appends additional comments or overwrites the content of the TEST_TXT field.

How the text you specify is handled depends on the setting of the disableTestTxtOverride configuration option:

  • If set false (default), the text you specify will overwrite the entire content of the TEST_TXT field.
  • If set true, the specified text is appended to TEST_TXT.

Syntax

TESTSET & testtext(const STRING &text);

Parameter

Description

text

String of text stored in the EDL as a TestDescriptionAttrType.

Example

The following example appends the comment 'trail_test' to TEST_TXT if the disableTestTxtOverride is set to true.

{
    ...
    TestSet.testtext("trial_test").testnumber(50).judgeAndLog_ParametricTest("pin1", "limit1", TM::Pass, 0);
    ...
}
