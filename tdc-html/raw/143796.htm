Topic 143796

label()

Specifies an existing label to insert digital capture actions.

The specified label must be the main label, not a burst label or subroutine.

Syntax

label(const string& sLabelName);
Parameter List

Parameter

Description

sLabelName

The label name

Example

RDI_BEGIN();
  rdi.digCap("norm").label("lpDcap_new").pin("DATA2").addVecRange(3,15).samples(10).execute();
RDI_END();

Functional changes

  1. Introduced in SmartRDI 2.1.0
