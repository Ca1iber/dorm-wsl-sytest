Topic 10641

Set fixed receiver levels

The command RCLV, RCLV? - (ReCeive LeVel) sets the logic 0 and logic 1 threshold levels of the receive comparators for any named pins or groups of pins. The levels will become part of the level set you specify.

The threshold levels are the voltages at which the dual level comparator distinguishes between:

  • a logic 0 and an intermediate level output from the DUT,
  • an intermediate level and logic 1 output from the DUT.

These levels are subject to range and swing limitations.

The RCLV? query lists the receive threshold levels for any specified pin and level set.

All card types have both single-ended and differential comparators. Smart Scale cards have the additional capability to define the threshold for differential signals. If you define a threshold voltage other than zero volt, the differential voltage will be against the threshold voltage (Vpos - Vneg > vth or Vpos-Vneg < vth).

In contrast, the threshold for differential modes is fixed at 0 V on Pin Scale systems.
