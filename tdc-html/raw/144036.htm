SOURCESYNC_HANDLER.OPERATION_PRE_ITERATE_EACH_CYCLE()

Operations defined in this function will be executed before printing out sweep results for every cycle on an error map.

Note You must inherit this function when defining your own SOURCESYNC_HANDLER class. If you do not have operations for this function, program it as an empty function. See the example in SOURCESYNC_TEST.handle().

Syntax

virtual void OPERATION_PRE_ITERATE_EACH_CYCLE (const EMAPVars& emap)=0;
Parameter

Parameter

Description

emap

References to an EMAPVars data structure, which contains:

  • long int startCycle: The start cycle number on a source-sync error map.
  • long int cycleNum: The number of cycles on an error map.
  • unsigned int shotNum: (Mandatory) The number of shots (steps) for each edge on an error map.

Return value

There is no return value.

Example

See the example in SOURCESYNC_TEST.handle().
