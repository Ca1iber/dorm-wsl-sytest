Setting up Utility Lines

Each utility line can control a user relay on the DUT board or logic device. You can change the utility line setting with the util member function of the ROUTING_STATUS API.

Routing.util(util_name).func;

where, util_name is the name of a utility line and func is a member function of the UTIL_I class that is used as a subsidiary data container of the ROUTING_STATUS API.

To execute a particular task, specify any of the following member functions.

The task to be executed...

Use this member function...

Turns the utility line on

on()

Turns the utility line off

off()

For details, see UTIL_I.

To download the utility line settings, put the FLUSH API after the ROUTING_STATUS API as shown below:

Routing.util("Util_a").on();
FLUSH();

In addition, you can set multiple utility lines in one go by using a utility purpose that contains a group of utility lines together with the setting data. For information on how to control multiple utility lines using a utility purpose, see UTI_PURPOSE_I.
