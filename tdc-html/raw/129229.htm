Setting up for using driver sharing APIs

To use driver sharing APIs, you must include the API header file and the API library to the test method property.

About this task

Note From MTP 3.3.2, using Driver Sharing APIs does not require these pre-settings as described in this topic. After installing MTP 3.3.2 and restarting the computer, the pre-settings will be automatically set up.

You should do the following settings when you use the Driver Sharing APIs.

Before you begin

Make Sure:

  • A universal test method project is created.
  • SmarTest is open with MTP tape installed.

Procedure

  1. In Project Explorer, right-click the test method project you have created and choose Properties from the shortcut menu.

    The properties dialog is displayed.

  2. In the left-hand sidebar, click C/C++ Build > Settings.
  3. In the Tool Settings tab, click GCC C++ Compiler > Directories.
  4. Add the path of the API header file to the Include paths field: /opt/93000mts/mts/solution_tools/common/include.
  5. In the Tool Settings tab, click GCC C++ Linker > Libraries.
  6. Add SolutionToosAPI to the Libraries field.
  7. Add the path of this API library to the Library search path field:

    /opt/93000mts/mts/solution_tools/common/sh_lib.

  8. In the Tool Settings tab, click GCC C++ Linker > Miscellaneous.
  9. In the Other options field, enter:

    -rpath

  10. Still in the Other options field, enter another option:

    /opt/93000mts/mts/solution_tools/common/sh_lib/

  11. Manually add this line at the beginning of your test method code file: 
    #include "solution_tools.h"

Results

You can now use the driver sharing APIs in your test method code.

What to do next

Program the test method as usual.
