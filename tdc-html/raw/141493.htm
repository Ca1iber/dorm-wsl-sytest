MTP_MEMORY_PORT.generateBitMapFile()

Generates fail bit map files (.bfd files) for the patterns in the current port.

The port is specified with the getMemoryPort() function of the MTP_MEMORY_TEST class.

Syntax

void generateBitmapFile () const;

Return value

There is no return value.

Related information

MTP_MEMORY_PORT.getMemoryPattern()

Functional changes

  1. Introduced in MTP 3.2.1
