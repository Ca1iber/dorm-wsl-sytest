Generic Input/Output (GIO) API

In order to control external instruments from a V93000 system controller, a Generic Input/Output library Application Programming Interface (GIO library API) is provided for test application programs.

The GIO library API replaces the former Standard Instrument Control Library (SICL) that is not supported in SmarTest 7.10 anymore.

Note The GIO library API is the only replacement for SICL functionality. Other APIs, such as the communication between handling equipment and system controller, cannot serve as a replacement for SICL.

Functional changes

  1. Introduced in SmarTest 7.10.0
