Topic 10552

Executing a label

In order to execute a label, SmarTest must know the name of the label and the primary sets that are to be used.

Procedure

  1. Specify the label to be executed with the SQSL command.

    This command informs the sequencer which label it is to execute. This label is called the start label. It must be a MAIN label that is associated with the default port, or a burst or multi-port burst label.

  2. Specify the primary sets to be used with the SPRM command.

    This command determines which timing and level setup is to be used for label execution.

  3. Execute the label with the FTST? query.

    This query executes the label specified with the SQSL command using the information determined with the SPRM command. If you have not issued SPRM, FTST? will use waveform set 1 with timing set 1, level set1, and dps set 1. FTST? returns a PASS or FAIL result.

    Note that the cycles generated from the vectors are passed to the DUT in multiples of 8. If the number of user cycles is not divisible by 8 then it will be filled up with break cycles to the next multiple of 8 at the end of the label. For the current start label, you can check this with the VCYC? query. See also Data transfer from the vector area to the data queue.

Results

FTST? returns a global PASS/FAIL result.

Example

In order to execute the label test_2 of the standard example with the timing defined in the Timing Setup Commands chapter, proceed as follows:

  1. SQSL "test_2"
  2. SPRM 101,1,101002,101003
  3. FTST?

Functional changes

  1. Introduced before SmarTest 6.3.2
