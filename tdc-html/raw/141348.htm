EVENT_ICVM.limitLow()

Sets the lower voltage limit to compare against threshold.

Syntax

EVENT_ICVM & limitLow(const EVENT_VALUE_DOUBLE & value );
Parameter
Parameter Description
value

Lower value of range

Return value

A reference to the corresponding EVENT_ICVM object.

Example

For an example see EVENT_ICVM.
