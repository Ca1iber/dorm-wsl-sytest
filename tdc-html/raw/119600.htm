Topic 119600

Editing test limits

Procedure

  1. Load the test table in the Test Program Explorer.
  2. Open the test table.

    The table is displayed in the test table editor.

  3. Edit the limits in the table as needed.
  4. Save the changes using the shortcut menu in the Test Program Explorer
