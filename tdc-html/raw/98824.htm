UDPT - (UnDefine PorT)

The UDPT (UnDefine PorT) command removes a previously defined port from the current configuration.

Syntax

UDPT {(portlist)}

Parameters

portlist

List of port names or the symbol @@, which undefines all ports. If more than one port is to be removed, the names must be separated with a comma.

Application

Pin configuration, see Configuration Setup Commands.

Example

UDPT (port_1)

This command undefines port port_1.

Functional changes

  1. Introduced before SmarTest 6.3.2
