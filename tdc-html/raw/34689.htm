PinPFResultAttrType

Contains the pass/fail result data for a list of pins. The data type is DRLPinPFResultAttr.

Field Name

Data Type

Description

Comments

length

int

Attribute length

These fields form the attribute header.

type

short

Attribute type

description

string

Description

 

pin_index

short

Pin index

These fields form a block, which occurs for every pin. The number is implicitly specified by the length field.

failure_code

char

Failure code, see table below
Failure code values

Value

Description

-2= DRLFailureCode_Fatal

test method execution incomplete or test method crashed

-1= DRLFailureCode_NA

no pass/fail result determined

0 = DRLFailureCode_Pass

passed

1 = DRLFailureCode_Fail

failed

2 = DRLFailureCode_Error

error

3 = DRLFailureCode_Bypass

bypassed (this applies only to test suites)
