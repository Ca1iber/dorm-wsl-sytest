Topic 136536

Saving shmoo plots to png or ASCII files

When executing a shmoo test suite or testflow, to log its shmoo setups and plots into the report window, and to save the generated shmoo plots as .png files or as ASCII files, use the Event Formatter.

Before you begin

In SmarTest, open a testflow and load its full setups.

Procedure

  1. Activiate the Event Formatter.
  2. To save shmoo plots as .png files, copy the Event Formatter configuration file (.formatterrc.def) to your home directory with the new file name .formatterrc. Then, change the value of shmoo_picture_generation to 1.

    After executing the shmoo test suite or testflow, you will see the file path in both the Console view and the Event Formatter output window.

  3. To save shmoo plots and results as ASCII files, copy the Event Formatter configuration file (.formatterrc.def) to your home directory with the new file name .formatterrc. Then, change the value of shmoo_txt_generation to 1.

    After executing the shmoo test suite or testflow, you will see the file path in both the Console view and the Event Formatter output window.

  4. In the test flow, set up a shmoo test suite with the Shmoo test method or with the Fail Bit Count Shmoo test method, which is available only for MTP.

    Alternatively, you can set up a shmoo test in the Shmoo Tool and then transfer it to the testflow as a shmoo test suite.

  5. In the testflow, enable the following test suite flags for this shmoo test suite:
    • Output on pass
    • Output on fail
    • Pass value
    • Fail value
    • Per pin on pass
    • Per pin on fail
  6. Execute the shmoo test suite or testflow.

Results

  • The shmoo test setups and plots are displayed on both the report window and the Console view.

    See Shmoo output of the Event Formatter.

  • If you have enabled shmoo picture generations as described in step 2, shmoo plots named with time stamps are saved as .png files to the <the current device>/shmoo/shmooPNG/ directory.

    You will find this directory in both the Console view and the Event Formatter output window which is in the report window.

  • If you have enabled shmoo ASCII file generations as described in step 3, shmoo plots and results are saved as ASCII files.

    You will find the file directory in both the Console view and the Event Formatter output window which is in the report window.

What to do next

In the report window, you can view, save and print these data logs. For details, see Report window menus.
