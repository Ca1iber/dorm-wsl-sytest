Assignments

Values are assigned to variables using the = operator.

Assignments later in the program overwrite earlier ones. For example:

myVar = 1;
myVar = 2;

The variable myVar now has the value 2.

Syntax

There are three types of assignment: direct, incremental, and formular.

Direct assignments

Direct assignments are the form used in C and similar programming languages:

aVar = 12;
myVar(0) = 12;
myVar(1) = aVar + 5;

In principle, tupels can also be assigned to variables, although it is rarely useful to do so:

aVar = (2,5,1);

Incremental assignments

Incremental assignments allow you to base the value of indexed variables on lower indexes. For example: 

myVar(0) = 1;
myVar(1) = +2;

These statements assign the variable myVar(0) the value 1 and myVar(1) the value 3. This works with tuples as well:

myVar(0) = (1,1);
myVar(1) = (+2,+1);

To decrement a value, use a negative number. To leave a value unchanged, use +0. For example:

myVar(0) = (1,1);
myVar(1) = (+0,-1);

This results in myVar(1) having the value (1,0).

Formular assignments

Certain system variables be assigned values using a loop-like structure, called formular assignment.

To specify a formular assignment, replace the variable's index with a loop statement and the expression to the right of the assignment operator with a calculation based on the loop variable. The calculation must be enclosed in curly braces.

The loop statement specifies the loop variable, followed by a = sign, followed by three parameters:

  1. The beginning value of the loop
  2. The end value of the loop
  3. The increment

The parameters are enclosed in square brackets and are separated by commas.

For example:

dg(n=[0,3,1]) = {0,n};

This formular assignment has the same effect as:

dg(0) = (0,0);
dg(1) = (0,1);
dg(2) = (0,2);
dg(3) = (0,3);

Formular assignments can also be used to assign values to a range of indexed variables and initialization functions. For example:

dg(n=[0,nDatabit-1,1]) = {(0,2*n+3)};

This statement initializes variables from dg(0) to dg(nDatabit-1). Each variable is initialized with a tuple with zero as the first element and twice the index plus three as the second element. For example: dg(0) is (0,3) and dg(1) is (0,5).

For indexed variables and some initialization functions, loop-like statements can also appear on the right-hand side of assignments. The syntax and limitations for the various initialization functions are included in the descriptions of the functions in Initialization functions. If you use right-hand loops with variables, these rules apply:

  • Formular assignments can be used only for system functions supporting such assignments.
  • Right-hand loops are only supported when there is also a left-hand loop.

    For example, this statement results in a syntax error:

    dg = {n=[0,7,1]};   // Error!
  • Right-hand loop iterates in sync with the left-hand loop.

    For example, this loop statement initializes four instances of myVar:

    dg(n=[1,4,1]) = {(i=[12,15,1], j=[0,3,1])};

    It is equivalent to these individual statements:

    dg(1) = (12,0);
dg(2) = (13,1);
dg(3) = (14,2);
dg(4) = (15,3);
  • If there are several loops on the right-hand side, the loop variables from loops further to the left can be used in loops further to the right, but not vice versa.

    For example, only the first of the following two statements is legal:

    dg(n=[1,4,1]) = {(m=[1,4,1], k=[2,5,m])};
dg(n=[1,4,1]) = {(m=[1,4,k], k=[2,5,1])};  // Error!
  • Loop variables can be used in calculations, as long as the calculations are to the right of the loop declaration.

    For example:

    dg(n=[1,3,1]) = {(m=[3,5,1], n*m)};

    This is equivalent to these statements:

    dg(1) = (3,3);
dg(2) = (4,8);
dg(3) = (5,15);
