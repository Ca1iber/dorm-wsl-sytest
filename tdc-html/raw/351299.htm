Topic 351299

Internal utility resources specific setup tasks

This section describes some of the typical setup tasks for the internal utility resources of a V93000 EXA Scale system in the basic configuration.

The following specific setup tasks are available in this topic:
  • Global compatibility settings
  • Internal utility resources configuration in the model file

Global compatibility settings

Some characteristics of utility power supplies have been optimized for V93000 EXA Scale systems. For compatibility, the behavior can be adapted to the Pin Scale and Smart Scale systems using global settings. These settings are to be defined in a configuration file that is parsed when the SmarTest Work Center is started.

The compatibility setting are defined in file /opt/hp93000/soc/system/etc/systemPreferences.txt.

Data in the file are defined as key=value pairs.

The following key is available for the internal utility resources:

  • utility_power_featureset

    For internal utility resources, the key controls the global power on/off behavior of the UP5V utility power supply.

    Key: /system/hw_config/utility_power_featureset
    Value: Integer value 2 or 3
    Default: 2
    Example: /system/hw_config/utility_power_featureset=2
    Supported values and functionality:
    2 This value activates the power on/off behavior that is compatible with the Pin Scale and Smart Scale systems:
    • The UP5V utility power supply is enabled as soon as the test head is switched on.
    • The state of the "DSC" utility pin is ignored when switching on the UP5V utility power supply.
    • The UP5V utility power supply automatically recovers after an overload condition.

    This is the default value and the default behavior if utility_power_featureset is not defined in the systemPreferences.txt file.

    The change in behavior applies to the Utility power supply - UP5V pins of only the first card cage.
    3

    This value enables the new behavior of the V93000 EXA Scale systems running SmarTest 8.

    This value is not supported on V93000 EXA Scale systems running SmarTest 7.

    • The UP5V utility power supply remains disabled until it is enabled by a Device Test API.
    • The state of the "DSC" utility pin is checked when switching on the UP5V utility power supply. The DSC pin of every utility block has to be connected to UGND on the DUT board to enable the UP5V utility power supply.
    • The UP5V utility power supply remains switched off after an overload condition.
    In SmarTest 8 only, a warning is issued if the key /system/hw_config/utility_power_featureset is not defined:
    WARNING: The '/system/hw_config/utility_power_featureset' preference has not been set.
    Backwards compatible settings will be used.
    The preference can be changed in file '/opt/.../etc/systemPreferences.txt'.
    In SmarTest 7 only, a warning is issued if the key /system/hw_config/utility_power_featureset is set to the unsupported value "3":
    WARNING: This SmarTest version only supports the backwards compatible setting (2) for
the '/system/hw_config/utility_power_featureset' preference.
         The current value (3) is not supported and will be ignored.
         The preference can be changed in file '/opt/.../etc/systemPreferences.txt'.
    SmarTest issues a warning if an invalid parameter value is set:
    UNRECOVERABLE ERROR (CORRECTNESS EXCEPTION): Problems found during hardware detection. ...
The '/system/hw_config/utility_power_featureset' preference must be in the range 2 to 3. ...

Internal utility resources configuration in the model file

The internal utility resources are to be defined in the GLOBAL section of the tester.model file:
  • Internal utility lines:
    The utility lines are to be defined in the GLOBAL section as follows:
    utility_lines = number_of_lines, type = static, pogo_size = 32
    number_of_lines is to be replaced with
    • 32 for the default configuration or
    • 64 for the SX test head (18 slots) and for the LX test head (27 slots) if an optional utility line module and pogo cable assembly are installed in the second card cage.
    Keyword utility_lines, followed by all parameters is mandatory for a V93000 EXA Scale system.
    Example:
    utility_lines = 32, type = static, pogo_size = 32
  • Internal Utility Power Option:
    This internal utility power supply is to be defined in this section as follows if the required pogo cable assembly is installed:
    legacy_udps = 2681)
    Pogo block 268 is the new designation for the legacy DPS 8 pogo block. For more information, refer to DUT interface layout.
    Note This entry in the tester.model file prevents a second Utility Card from being installed: The second Utility Card occupies all pogo blocks from 266 (DPS 1) to 268 (DPS 8).
