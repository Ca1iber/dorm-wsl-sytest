Master Information Record (MIR)

The Master Information Record contains all of the global information that is to be stored for a tested lot of parts.

Location in the file:

The Master Information Record is located immediately after the VUR. If the VUR is not used, the MIR is located immediately after the ATR. If the ATR is not used either, the MIR is located immediately after the FAR.

MIR field name

Field description

Value

93000 data source

SETUP_T
  • Date and time when Test Program starts
  • Whether the time is local or UTC depends on the setting of the useUTCTime option in formatter.stdf.main.conf.
  • Four-byte unsigned integer
  • EDL Event: TestProgramStartEvent
  • EDL Attribute: Seconds

START_T
  • Date and time of first part tested
  • Whether the time is local or UTC depends on the setting of the useUTCTime option in formatter.stdf.main.conf.
  • Four-byte unsigned integer
  • EDL Event: TestFlowStartEvent
  • EDL Attribute: Seconds

STAT_NUM
  • Tester station number
  • One-byte unsigned integer
  • 1 = Default
  • Application model variable1):

    STAT_NUM

  • Data source can also be a constant value in the configuration file or a system environment variable.

MODE_COD
  • Test mode code
  • One-byte character string
  • Hard-coded value of 'D'
  • Application model variable1):

    MODE_COD

  • Data source can also be a constant value in the configuration file or a system environment variable.

RTST_COD
  • Lot retest code
  • Indicates whether the lot of parts has been previously tested under the same conditions.
  • One byte character string
  • <space> = missing or invalid data
  • Acceptable values are:

    Y = Lot was previously tested

    N = Lot was not previously tested

    0 - 9 = Number of times tested
  • Application model variable1):

    RTST_COD

  • Data source can also be a constant value in the configuration file or a system environment variable.

  • <space> = missing or invalid data
  • Application model variable1):
