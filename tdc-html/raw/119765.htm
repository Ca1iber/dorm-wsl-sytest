Creating a new context

  1. In the Test Program Explorer, right-click the Pin Setting entry of the pin configuration section and choose Add Context.
  2. In the Add Context dialog, select the context on which you want to base the new context.

    The pins in the new context will have the same IO types and operation modes as in the existing context that you selected.

  3. Enter the name of the new context.
  4. Click OK.
