PPMU_IClamp()

This API is used to set up a label to hold PPMU IClamp.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTMultiportSync.hpp.

Syntax

void PPMU_IClamp(const String&  _pinName, const String&  _status, DOUBLE _IClampLow, DOUBLE _IClampHigh, DOUBLE _waitTime = 10.0 us);
Parameters

pinName(string)

Specifies the pin name.

_status(string)

Specifies the force voltage.

_IClampLow(double)

Specifies the low current of the clamp in A.

_IClampHigh(double)

Specfies the high current of the clamp in A.

_waitTime(double)

Specfies the wait time.

Further information about pin clamp data is available under PPMU_PIN_CLAMP.

Example

DCDynamicPort::getInstance().PPMU_Relay("DC_Pin1", "PPMU_ON", 20 ns);
DCDynamicPort::getInstance().PPMU_Setting_VForce("DC_Pin1", vin V, 10 mA,-12 uA ,12 mA,10 ns);
DCDynamicPort::getInstance().PPMU_IClamp("DC_Pin1","CLAMP_ON", 0, 100 uA, 0.1 us);
DCDynamicPort::getInstance().PPMU_Relay(MeasPin,"PPMU_ON", 20 us);
DCDynamicPort::getInstance().PPMU_Setting_IForce(MeasPin, 0 uA,100 uA, -1 uA, 1 uA, 0.002 ms);
DCDynamicPort::getInstance().PPMU_VClamp(MeasPin,"CLAMP_ON", 0, 4 V, 0.1 us);
DCDynamicPort::getInstance().PPMU_Meas(MeasPin,"VMUM", "PVAL",2, 10 ns);
Sync.sync();
Sync.flush();
