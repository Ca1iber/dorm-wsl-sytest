Software Bin Record (SBR)

The Software Bin Record stores a count of the parts associated with a particular logical bin after testing. This bin count can be for a single test site (when parallel testing) or a total for all test sites. The STDF specification also supports an HBR for physical binning categories. A part can be "logically" associated with a software bin during or after testing.

Location in the file:

The Software Bin Record can be located anywhere in the data stream after the initial sequence and before the MRR. When data is being recorded in real time, this record will usually appear the end of the data stream.

SBR field name

Field description

Value

93000 data source

HEAD_NUM
  • Test head number
  • One-byte unsigned integer
  • Value = 255

    If the ATR and GDR indicate that there are more than 255 sites in the test, HEAD_NUM is the number of the site divided by 256. For example, in a record for site 384, HEAD_NUM would be 2.
  • For tests with up to 255 sites: hard-coded value

    For tests with more than 255 sites: derived from SiteID

SITE_NUM
  • Test site number
  • One-byte unsigned integer

    If the ATR and GDR indicate that there are more than 255 sites in the test, SITE_NUM is the number of the site modulo 256. For example, in a record for site 600, SITE_NUM would be 88.
  • EDL Event:

    BinReachedEventType

  • EDL Attribute:

    SiteIdAttrType

SBIN_NUM
  • Software bin number
  • Two-byte unsigned integer
  • The translator will attempt to convert the string obtained from SmarTest using base 10 first, then base 16.
  • If the string cannot be converted the number for the corresponding hardware bin will be used.
  • Valid values are 0 - 32767
  • EDL Event:

    BinReachedEventType

  • EDL Attribute:

    BinNumber

SBIN_CNT
  • Number of parts in this bin
  • Four-byte unsigned integer
  • EDL Event:

    BinReachedEventType

SBIN_PF
  • Pass or Fail indication
  • One-byte unsigned integer
  • P = Passing bin
  • F = Failing Bin
  • <space> = unknown type of bin
  • EDL Event:

    BinReachedEvent

  • EDL Attribute:

    IsGoodBin

SBIN_NAM
  • Software bin name
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • Software bin number and software bin description from Testflow Editor Bin Dialog.
  • EDL Event:

    BinReachedEvent

  • EDL Attribute:

    BinName

    BinDescription

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.2.2: Added HEAD_NUM and SITE_NUM conventions for tests on more than 255 sites.
