Preference Page on Test Time Breakdown Analyzer

Enables you to configure parameters to generate specific report.

This preference page contains three tabs:

Common Parameters

  • Ignore first n testflow execution(s) when calculating test time: When the SmarTest executes testflow, the analyzer ignores the first n times and use the last time's data to calculate the test time.
  • Execute testflow in SmarTest supervisor mode (SmarTest Eclipse shutdown): SmarTest switches to supervisor mode when executing a testflow. During execution, the SmarTest GUI is hidden, and is redisplayed after execution is completed.
  • Password of switching SmarTest from supervisor mode to engineering mode: Lets you enter the password if you change the default password of switching SmarTest from the supervisor mode to the engineering mode.

Parameters for UTM per-line analysis

  • Highlight source code lines if test time is longer than (ms): The report highlights the code lines if test time is longer than the value you specified.
  • Analyze test time breakdown information if test time of suite is longer than [ms]: The suite is listed in the report if the test time is longer than the value you specified.
  • Do not evaluate test time for basic code statements: Checking this option to not to analyze the basic code statements in the report.
  • Consider loop as one statement if loop count is bigger than: The analyzer considers the loop as one statement if the loop count is bigger than the value you specified, and ignores the detailed test time of the codes in the loop.
    Note The bigger the value you specify for the loop count, the more time the analyzer will require.

Parameters for testtime profiling (with SmartRDI)

  • Testflow loop number: Specify the number of execution.
  • Remove the loop containing Setup Generation from analysis: Checking this option to do not analyze the loop with set up generation.
  • Generate Single site vs Multi sites report: Checking this option to generate single site and multi-site reports.
