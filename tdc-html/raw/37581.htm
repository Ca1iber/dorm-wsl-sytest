Specifying the Port in the ASCII Vector File

You can also specify the port for which a ASCII vector file is to be translated in this very file with the PORT statement. This statement must be placed at the start of the ASCII vector file and has the following format:

PORT <port_name>;

The port name can also be specified in the vector configuration file, or, if you call v2b directly, with the-J parameter. These specifications override an eventual PORT statement in the ASCII vector file.
