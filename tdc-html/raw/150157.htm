EVENT_CFVM.limitHigh()

Sets the upper voltage limit to compare against threshold.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

EVENT_CFVM & limitHigh(const EVENT_VALUE_DOUBLE & highLimit);
Parameter
Parameter Description
highLimit

The upper limit to be set in V (Volt).

Return value

A reference to the corresponding EVENT_CFVM object.

Example

For an example see EVENT_CFVM.
