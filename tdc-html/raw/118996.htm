DISCONNECT_EX

This API is used to disconnect the DPS pins from DUT.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/DisconnectEx.h.

Class definition

Constructor

DISCONNECT_EX();

Member function

void disconnect();
void force(const STRING &pinList="@");
void exclude(const STRING &pinList);

Syntax

DISCONNECT_EX obj;
obj.mem_func;

or

DISCONNECT_EX().mem_func;

obj is an object of DISCONNECT_EX. mem_func is a member function of DISCONNECT_EX.

Constructor

DISCONNECT_EX();

It creates an object of DISCONNECT_EX.

Member functions

disconnect()

void disconnect();

This function disconnects the test system from DUT. It has the same functionality with the DISCONNECT API.

force()

void force(const STRING &pinList="@");

This function disconnects the specified pins from DUT no matter their previous connection status is on or off.

Parameter

pinList

The pin list to be disconnected.

exclude()

void exclude(const STRING &pinList);

This function disconnects the DPS pins from DUT except the specified pin list, no matter their previous connection status is on or off.

Parameter

pinList

The pin list to be disconnected.

Examples

Disconnect all the DPS pins

DISCONNECT_EX().force();

This example disconnects all the DPS pins no matter thei previous connect status is on or off.

Disconnect the specified pins

DISCONNECT_EX().force("pinA, pinB");

This example disconnects pinA and pinB no matter their previous connection status is on or off.

Disconnect DPS pins except the specified pins

DISCONNECT_EX().exclude("pinA, pinB");

This example disconnects DPS pins except pinA and pinB, no matter their previous connection status is on or off.
