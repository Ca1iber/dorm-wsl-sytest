Topic 131195

SPMU_TASK.execute()

Executes the DC measurement with the settings defined by the member functions of SPMU_TASK. If the settings have not been downloaded to the firmware already it first performs a SPMU_TASK.setup().

Note If the pins defined for this measurement are within the same card cage, the measurement will be executed sequentially per pin!

Syntax

void execute();
virtual void execute(const string& measurementName)
Parameter

Parameter

Description

measurementName

The measurementName is used with the Offline Result Emulation (ORE) feature of SmarTest. It refers to the corresponding offline measurement result specified in the ORE setup file.

Return value

There is no return value.

Note To retrieve results use the SPMU_TASK.getPassFail() or SPMU_TASK.getValue() functions.
