Pin role

Subtopics

  1. Using pin role groups for parallel protocols

A pin role is an abstract name of an interface (hardware) pin which is used in the protocol definition.

A physical device pin is assigned to a pin role in the protocol assignment.

Note Only pin roles are used within transactions, no physical pin names.

During protocol test execution a state character sequence is generated based on the field definitions of a transaction. This sequence is generated for a pin role and due to the assignment passed through the resource pin to the DUT.

Optional pin roles

Pin roles can be qualified as optional in a protocol definition. Optional pin roles can be left out in a pin role assignment. Thus the same protocol can be used for similar setups even if they do not have exactly the same number of pins.

If optional pin roles exist in a protocol, this is as a rule pointed out in case of an error. An analysis of the error will usually be easier if all pin roles are mapped to a device pin in the protocol assignment.
