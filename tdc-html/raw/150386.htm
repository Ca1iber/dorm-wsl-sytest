EVENT_WAVEFORM_VCIM.vClampHigh()

Sets the upper clamp voltage waveform as ANALOG_WAVEFORM.

Only one of the two clamp waveforms can be set per DC event. The upper clamp voltage waveform, defined by this member function, and the lower clamp voltage, defined by EVENT_WAVEFORM_VCIM.vClampLow(), must be set in separate DC events.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

EVENT_WAVEFORM_VCIM & vClampHigh(ANALOG_WAVEFORM & waveform);
Parameter
Parameter Description
waveform

Defines the waveform to be set in V (Volt).

Return value

A reference to the corresponding EVENT_WAVEFORM_VCIM object.

Example

For an example see EVENT_WAVEFORM_VCIM.
