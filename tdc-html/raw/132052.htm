Topic 132052

TESTSET().combineMultiPortTests()

This member function of TESTSET lets you specify one summary FTR record in multiport testing instead of individual FTR records for each port.

This function is not supported within the SMC_backgroundProcessing() test method when flag hidden_datalog_mode is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

Syntax

TESTSET & combineMultiPortTests(bool combine);

Parameter

Description

combine

Whether to combine the result FTR records into one for multiport tests:

  • true: One combined FTR record is created.
  • false: A separate FTR record is created for each port.

The default setting is false.

Related information
