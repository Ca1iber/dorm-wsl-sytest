Version Update Record (VUR)

The Version Update Record indicates the version of STDF to which the STDF file conforms.

If this record is not present, the file conforms to STDF V4.

If this record is used, it must be located immediately after the ATR. If no ATR is present, the VUR must be located immediately after the FAR.

The structure of the record is different in STDF V4/2007 and STDF V4/2007.1, as described below.

Syntax

VUR in STDF V4/2007

VUR field name

Field description

Value

93000 data source

UPD_NAM

The version after STDF V4 to which this data log conforms.

Variable-length character string.

Maximum 255 characters.

The content is taken from the stdfVersion parameter.
VUR in STDF V4/2007.1

VUR field name

Field description

Value

93000 data source

UPD_CNT

The number of UPD_NAM fields in this record.

 One-byte unsigned integer.

UPD_NAM

 An array of versions after STDF V4 to which this data log conforms.

Array of variable-length character strings.

Each array element contains a maximum of 255 characters.

The content is based on the stdfVersion parameter.

Functional changes

  1. Introduced in SmarTest 6.5.0
  2. SmarTest 7.5.3: Expanded record structure for STDF V4/2007.1
