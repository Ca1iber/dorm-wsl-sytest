Topic 98841

VALD? - (VALid Data)

The VALD? query returns the number of the first cycle (or label call) and the total number of cycles (or label calls) recorded in the Error Map for the specified digital pins. All these digital pins must belong to the same port. For DC Scale pins, use VALC?.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

VALD? {map_id}, {(pinlist)}

returns:

VALD {map_state}, {map_id}, {start}, {number}, {(pinlist)}

Parameters

map_id
Determines the type of Error Map for which data is to be read out:

ERRM

The error map option reads the error map.

OVEM

The overview error map option reads the overview error map in FCM mode (defined by DCRM). If the Overview Error Map was in LMAP mode for the last executed test, an error message will be issued.

LMAP

The label map option reads the overview error map in LMAP mode (defined by DCRM). If the overview error map was in FCM mode for the last executed test, an error message will be issued if LMAP is selected.

Note If you use the LMAP error map mode, FLBL ignores the RETC clearing flag for failures.

RECD

The receive data option reads the error map (compatibility with the ERMP query). Equivalent to ERRM.

DERR

The per pin detailed error map option reads the detailed error map. Equivalent to ERRM.

EOLY

The errors only map option reads the per pin errors only in the error map. Equivalent to ERRM.

pinlist

Error map information will only be returned for the pins specified in pinlist. If more than one pin is to be included, the names must be separated with a comma. All pins in pinlist must be O or IO pin types.

map_state

Returns the current state of the error map. The state can be:

INVL

Invalid is returned if no error map details are available (the setup has been changed, but no functional test has been performed).

INCS

This is returned if the contents of the error map are inconsistent with the current setup.

CONS

This is returned after a functional test has been performed and indicates that the contents of the error map are consistent with the current setup.

start

This is an integer that indicates the first cycle that was recorded, or, for the LMAP option of map_id, the first label call that was recorded. start will be a value between 0 and 248.

number

This is an integer that indicates the number of cycles recorded, or for the LMAP option of map_id, the number of label calls recorded. If ERRM, RECD or DERR have been selected, the range for this parameter depends on whether the internal or the external error map is used. For the internal error map, it is 0 to 8191; for the external error map the upper limit can be higher. When EOLY has been selected, the upper limit is 248.

For the Pin Scale 5000 card, the upper limit is 4096.

In the reply, this parameter indicates the number of cycles (or label calls) which have been read. If a 0 is returned, no data is available for the given range.

Application

Test results, Test Result Commands.

Errors

An error is generated if:

  • You send the query while the sequencer is running. There is then no result data available.
  • The errors-only map has overflowed, because you have pressed BREAK while the sequencer was executing a match loop, and the map_id was set to EOLY.

Example

VALD? ERRM, (Q0,Q1,Q2,Q3)

returns: 

VALD CONS, ERRM, 0, 1024, (Q0,Q1,Q2,Q3)

This example queries the error map and returns data between the cycles of 0 and 1024. The error map data is consistent with the current setup.

Functional changes

  1. Introduced before SmarTest 6.3.2
