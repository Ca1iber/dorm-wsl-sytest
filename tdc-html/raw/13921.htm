Topic 13921

Focusing the Timing Diagram

Positioning the Timing Diagram on a section of your test:

  1. Scroll the Timing Diagram to the area of the test that you want to view.
  2. If there is no data for the Timing Diagram in this part of the test, perform the following actions:
    1. Start the Error Map Tool if not yet done:

      On the menu, click 93000 > Results > Error Map.

    2. On the Timing Diagram menu click Display > align displays
    3. On the Error Map tool menu click Result > Execute

The Timing Diagram now has data for the section that you have selected.
