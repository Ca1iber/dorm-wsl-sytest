Glossary of terms - level setup

DPS set ID

This replaces DPS set number in an equation-based environment. It is derived from equation set number and specset number using the following calculation:

100000 * equation_set_no + 1000 * specset_no + 1

The purpose of this calculation is to calculate a unique number over 256 - 256 being the highest DPS set number in a non-equation-based environment. This enables equation-based and non-equation-based environments to be mixed.

Equation

A derived variable.

Level equation set

Defines sets of logical test system level resource settings. Logical because they are specified in terms of specs and/or equations which are only evaluated when the equation set is referenced by a level specset - which is where the spec values are assigned. Each level equation set must declare a list of the specs referenced. These must correspond to the specs listed in the level specset.

Level equations

A level setup component where level equation sets are defined. Found after an EQSP LEV,EQN command in a level setup file. Created and modified using a text editor opened from the Timing Setup window.

Level set ID

An equation-based environment. It is derived from equation set number and specset number using the following calculation:

100000 * equation_set_no + 1000 * specset_no + level_set_no

The reason for this calculation is to get a unique number over 256 - 256 being the highest level set number in a non-equation-based environment. This enables equation-based and non-equation-based environments to be mixed.

Level specifications

A level setup component where level specsets are defined. Found after an EQSP LEV,SPS command in a level setup file. Created and modified using a text editor or the spec tool opened from the Timing Setup window.

Level Specset

Allocates level sets and one DPS set in hardware by applying spec values to the logical assignments set up in the level equation sets.

Spec

A variable.

Specset ID

Specsets are accessed using a specset ID. This is derived from equation set number and specset number using the following calculation:

100 * equation_set_no + specset_no

The purpose for this calculation is to allow blocks of IDs to each equation set. Thus each equation set may be referenced by 100 specsets.

Functional changes

  1. Introduced before SmarTest 6.3.2
