Topic 94711

Standard DPS functionality of DC Scale cards in DPS operating mode

Subtopics

  1. Connecting and disconnecting in DPS operating mode
  2. Pin configuration and level setup in DPS operating mode

In DPS operating mode you can use DC Scale cards like a DPS-slot DPS, to supply devices with power during the execution of a test flow.

Connecting and disconnecting in DPS operating mode

When connecting and disconnecting in DPS operating mode, DC Scale cards behave like a DPS-slot device power supply.

When connected, it forces the programmed power supply voltage (vout). The current is limited to the connect current limit (ilimit).

The DC Scale card must be disconnected before changing any of the following:

  • a voltage force range (vout_frc_rng)
  • a clamp current range (iout_clamp_rng)

If the DC Scale card is still connected, you cannot activate a dps set that contains one of above changes. To avoid damages to your device or DUT board, the system will display an error message in the report window instead.
