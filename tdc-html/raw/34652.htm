TestProgramStartEventType

An event of this type is logged when the test program is started.

Attributes

  • WorkorderNameAttrType

    Holds the path and file name of the work order that the executed test program belongs to.

  • HostNameAttrType

    Holds the host name of the system controller on which SmarTest is running.

  • UIDAttrType

    Holds the login name of the user who started the test program or work order, respectively.

  • TestProgramNameAttrType

    Holds the file name of the started test program which is local to the current device directory.

  • DeviceDirectoryAttrType

    Holds the path of the device directory for the device tested by the test program

  • BinListAttrType

    Holds a list of all bins and their descriptions.

  • SWVersionAttrType

    Contains a string representing the build version and build date of the software.

  • TesterProductAttrType

    Contains a string representing the tester type description. It has a constant value of "93000".

  • TestHeadNumberAttrType

    Contains a string representing the test head number. It has a constant value of "1".

  • LotTypeAttrType

    Contains one of two strings: "PACKAGE Test" or "WAFER Test"..

  • TimeStampAttrType

    Holds the time when the test program was started. For example, you can use this time (together with the time which is logged with the event of the TestProgramEndEventType type) to calculate the execution time of the test program.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.3.5.3: Moved TimeStampAttrType to end of attribute list
