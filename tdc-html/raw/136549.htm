Commands in the shmoo tool icon

After you right-click the shmoo tool icon (), which is in the Test Results folder in the Test Program Explorer view, you will see these commands:

  • New: To create a new shmoo file to be opened with the Shmoo Tool. The new file will be saved in the <device directory>/shmoo directory.
  • Open: To open the Shmoo Tool. Refer to Opening the Shmoo Tool.
  • Load: To load an existing shmoo file.
  • Reload: To load a loaded file again.
  • Save: To save all shmoo pages related shmoo setups, results and plots to the current file. See Saving shmoo tests in the Shmoo Tool.
  • Save As: To save all shmoo pages related shmoo setups, results and plots to a new file. See Saving shmoo tests in the Shmoo Tool.
  • Save Setup: To only save all shmoo pages related shmoo setups to the current file. See Saving shmoo tests in the Shmoo Tool.
  • Save Setup As: To only save all shmoo pages related shmoo setups to a new file. See Saving shmoo tests in the Shmoo Tool.
