id()

Specifies a measurement ID for retrieving test result through a result retrieval function.

SmartRDI is designed to support up to 1000000 measurement result IDs at the same time.

Each SmartRDI class has its own result retrieval functions. For how to use id() together with a result retrieval function, see the particular topic of the result retrieval function.

Syntax

XXX(data type) result = rdi.id().getXxxx();

Example

const ARRAY_D &Result = rdi.id("cap").getWaveform("DATA_1");
ARRAY_D results = rdi.id("meas").getMultiValue("pinA");
rdi.id("id").getAlarmPassFail("A");
