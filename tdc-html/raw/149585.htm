Topic 149585

rdi.func().startVec()

This function specifies a start vector line in a user pattern.

You can use both startVec() and stopVec() to execute just part of a pattern, from a startVec line to a stopVec line.

In the emap() class, startVec() and stopVec() can be used together to split the pattern and create a new pattern. The created pattern begins from the startVec() line and ends at the stopVec() line. From the new partial pattern, the results of EMAP actions can be retrieved.

Restriction

There is a restriction on those specified vector lines which are near a sequencer instruction in the test pattern. That is, the vector line specified in startVec() should never contain a sequencer instruction, and it should never immediately succeed a vector line which contains a sequencer instruction. See the figure below.

This restriction is printed out in the Report window when the test is executed.

Syntax

rdi.func().startVec(int vec);
List of parameters

Parameter

Description

vec

The number of a vector in the pattern.

Examples

Example 1

For an IDDQ test, the code could be:

RDI_BEGIN();
  rdi.func().label("abc").stopVec(39).execute();
  rdi.dc().pin("VDD").iMeas().execute();
  rdi.func().label("abc").startVec(40).stopVec(49).execute();
  rdi.dc().pin("VDD").iMeas().execute();
  rdi.func().label("abc").startVec(50).stopVec(80).execute();
  rdi.dc().pin("VDD").iMeas().execute();
RDI_END();

Vector lines start from 0.

Example 2

startVec() and stopVec() are supported in the emap() class.
RDI_BEGIN();

rdi.emap("id").label("abc").pin("A")
              .startVec(10).stopVec(30)
              .failCout(5,10).FFC(5).execute();

RDI_END();
...
rdi.id("id").getFailCout(); 
rdi.id("id").getFFC();

In this example, a new pattern abc_START_10_STOP_30 will be generated, which begins at startVec(10) and ends at stopVec(30). The FFC(5) means that the start cycle 5 is in the new generated pattern.

Related information

Functional changes
