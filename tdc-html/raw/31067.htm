Save Trace As...

This menu item saves the trace data in the following formats.

ASCII - Single waveform data can be saved in ASCII format (decimal floating point numbers). In this format, only the data points are saved. The other context information such as title, axis, and color is not saved.

Binary - Single waveform data can be saved in Binary format (float32). In this format, only the data points are saved. The other context information such as title, axis, and color is not saved.

Enhanced ASCII - Single waveform data can be saved in ASCII format. In this format, some context information such as title is saved.
