SPMU_PIN_TASK.vForceFilter()

Sets the force voltage or clamp voltage filter as frequency.

This member function is supported only for the DC Scale XPS256 card.

Both this member function and SPMU_PIN_TASK.vFilter() control the same functionality of the hardware.

The force voltage filter or clamp voltage filter is set as frequency. The set value defines a bandwidth filter that has an effect on the dynamic behavior of a channel that is forcing or clamping the voltage.

Syntax

SPMU_PIN_TASK& vForceFilter (DOUBLE filterFrequency);
SPMU_PIN_TASK& vForceFilter (const STRING & filterFrequency);
Parameter
Parameter Description
filterFrequency Sets the filter to the given frequency in Hertz (Hz) or switches the filter off. The parameter can be defined as double value or as string.

Programmable double values are

  • Value between the card-specific minimum and maximum value: The filter is switched on and set to the defined value.
  • 0.0: The filter is set to the card-specific default value.

Programmable strings are

  • "OFF": The filter is set to the card-specific default value.
Card-specific range and default value:
  • XPS256: Refer to section Dynamic behavior in XPS256 programming - Force and clamp voltages.

Return value

A reference to the SPMU_PIN_TASK object.

Example

The following example shows how to set the force voltage filter and the clamp current filter.

SPMU_TASK spmuTask;

spmuTask.pin("###")
   ...
   ...
   .vForceFilter(0) // Switch the force voltage filter off
   .iClampFilter(1000) // Set the clamp current filter to 1 kHz
   ;

Note: The example concentrates on the function described in this topic. More settings are required for an executable SPMU_TASK object.
