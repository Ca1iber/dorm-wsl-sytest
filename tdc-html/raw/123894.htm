Test method snippets for baseband to RF test

The following snippets for baseband to RF test are provided with SmarTest. These test method snippets are included in the file /opt/hp93000/soc/segements/tml/testmethodSnipptets.xml.

IQ setup is required for the execution of these snippets. To save test time, the data of ARRAY_X type is not passed as parameters but as private member variables of test method class to the post processing functions.

The snippets are listed in the alphabetical order.

  • V93000_BBtoRF_CarrierSuppressionImageRejection_Measure

    This snippet sets up and executes a baseband to RF carrier suppression and image rejection test. It then uploads the waveform and kicks off the data calculation with the smartCalc background post processing function.

  • V93000_BBtoRF_CarrierSuppressionImageRejection_SMCPostProcess

    This snippet does the post processing for the baseband to RF carrier suppression and image rejection test with smartCalc. It calculates the carrier suppression and image rejection of the retrieved waveform. The results are judged with the limits in the test table and logged. The snippet can be used together with the snippet V93000_BBtoRF_CarrierSuppressionImageRejection_Measure in the test method.

  • V93000_BBtoRF_EVM_Measure

    This snippet sets up and executes a baseband to RF EVM test. It then uploads the result waveform and kicks off the hidden calculation with the smartCalc background post processing function.

  • V93000_BBtoRF_EVM_SMCPostProcess

    This snippet does the post processing for the baseband to RF EVM test. It calculates the EVM rms value and DB value. The results are judged with the limits in the test table and logged. The snippet can be used together with the snippet V93000_BBtoRF_EVM_Measure in the test method.

  • V93000_BBtoRF_GainFlatnessModulate_Measure

    This snippet sets up and executes a baseband to RF modulated gain flatness test. It then uploads the result waveform and kicks off the hidden calculation with the smartCalc background post processing.

  • V93000_BBtoRF_GainFlatnessModulate_SMCPostProcess

    This snippet does the post processing for the baseband to RF modulated gain flatness test. It calculates the gain flatness and judges and logs the results with the limits in the test table. The snippet can be used together with the snippet V93000_BBtoRF_GainFlatnessModulate_Measure in the test method.

  • V93000_BBtoRF_RefSpurs_Measure

    This snippet sets up and executes a baseband to RF TX reference spurs test. It then uploads the result waveform and kicks off the hidden calculation with the smartCalc background post processing function.

  • V93000_BBtoRF_RefSpurs_SMCPostProcess

    This snippet does the post processing for the baseband to RF TX reference spurs. It calculates the spurs and judges and logs the results with the limits in the test table. The snippet can be used together with the snippet V93000_BBtoRF_RefSpurs_Measure in the test method.

  • V93000_BBtoRF_SpectrumMask_Measure

    This snippet sets up and performs a baseband to RF spectrum mask test. It then uploads the result waveform and kicks off the hidden calculation with the smartCalc background post processing function.

  • V93000_BBtoRF_SpetrumMask_SMCPostProcess

    This snippet does the post processing function for the baseband to RF spectrum mask test. It calculates the spectrum mask, judges and logs with the limits defined in the test table. The snippet can to be used together with the snippet V93000_BBtoRF_SpectrumMask_Measure in the test method.

Functional changes

  1. Introduced in SmarTest 6.5.4
