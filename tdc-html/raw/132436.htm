TMU_PINS.errorState()

Returns the bitwise errors occurred for the specified pin(s).

Syntax

UINT32 errorState(const STRING& pin);
Parameter

I/O

Parameter

Description

I

pin

The pins for which the state of the TMU measurement is to be returned.

Return value

The error state is returned. The returned value can be:

  • 0x00000000: represents NO_OVERRUN and means that there are no error.
  • 0x00000001: represents VDL_OVERRUN and means the sample rate of the TMU is exceeded.
  • 0x00000002: represents ARM_OVERRUN and means that the TMU is re-armed before all the requested samples have been taken in the preceding measurement execution.
  • 0x00000004: represents DEGLITCH_OVERRUN and means that the prescaler is programmed incorrectly.
  • 0x00000008: represents OUT_OF_MEMORY and means that the embedded processor has run out of memory.
  • 0x00000010: represents NOT_FINISHED and means the measurement is still running.
  • 0x00000020: represents RESULT_FIFO_OVERFLOW.
  • 0x00000400: represents LAST_EVENT_NOT_MEAS_END.
  • 0x00000800: represents MEAS_ID_TABLE_INVALID and means that the pattern setup is invalid, no EVENT_TMU_MEAS object with mode END_MEAS is present.
  • 0x00001000: represents ARMING_EVENT_MISSING and means that the pattern setup is invalid, the EVENT_TMU_START is not present.
  • 0x00002000: represents UNEXPECTED_TERMINATION and means that the pattern setup is invalid, the EVENT_TMU_MEAS is not present.
  • 0x00004000: represents SAMPLE_AQUISITION_ERROR and means that no sampling data is available due to lost samples.
  • 0x00008000: represents LESS_SAMPLES_THAN_REQUESTED and means that the TMU sample count is smaller than total sample count in the pattern.

Functional changes

  1. Introduced in SmarTest 7.1.0
  2. SmarTest 7.1.2: New option NOT_FINISHED added to TMU::ERROR_TYPE.
  3. SmarTest 7.5.1: New hexadecimal values.
