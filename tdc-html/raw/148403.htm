PPMU_VClamp()

This API is used to set up a pattern to hold PPMU VClamp.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTMultiportSync.hpp.

Syntax

void PPMU_VClamp(const String&  _pinName, const String&  _status, DOUBLE _VClampLow, DOUBLE _VClampHigh, DOUBLE _waitTime = 10.0 us);
Parameters

pinName(string)

Specifies the pin name.

_status(string)

Specifies the force voltage.

_VClampLow(double)

Specifies the low voltage of the clamp in V.

_VClampHigh(double)

Specfies the high voltage of the clamp in V.

_waitTime(double)

Specfies the wait time.

Further information about pin clamp data is available under PPMU_PIN_CLAMP.

Example

DCDynamicPort::getInstance().PPMU_Relay("DC_Pin1", "PPMU_ON", 10 ns);
DCDynamicPort::getInstance().PPMU_Setting_VForce("DC_Pin1", vin V, 10 mA, -10 uA, 10 mA, 0.002 ms);

DCDynamicPort::getInstance().PPMU_Relay(MeasPin,"PPMU_ON", 10 us);
DCDynamicPort::getInstance().PPMU_Setting_IForce(MeasPin, 0 uA,10 uA, -1 uA, 1 uA, 0.002 ms);
DCDynamicPort::getInstance().PPMU_VClamp(MeasPin, "CLAMP_ON", 0, 3 V, 0.1 us);
DCDynamicPort::getInstance().PPMU_Meas(MeasPin,"VMUM","PVAL",1, 250 us);
