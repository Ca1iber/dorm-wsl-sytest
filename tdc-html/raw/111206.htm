Topic 111206

getTestsuite()

This API gets a test suite from the test flow and creates a TestsuiteProxy object for the test suite.

If the target test suite is a valid universal-test-method-based test suite, an object of TestsuiteProxy will be returned. Otherwise, a runtime_error exception message will be sent out.

Syntax

TestsuiteProxy getTestsuite(const std::string& name);
Parameters

name

The test suite name.
