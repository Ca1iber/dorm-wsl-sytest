Topic 56439

Providing emergency licenses

You can obtain emergency application software licenses or hardware feature licenses, to solve a manufacturing problem caused by a failed or otherwise inoperable license server.

About this task

The Emergency License Facility (ELF) will provide you with licenses immediately upon application via the Advantest Service & Support website at https://www.advantest.com/service-support/ic-test-systems/products-list/v93000-licensing. To view the content of this Service & Support website you need to login with your Advantest customer login.

These emergency licenses enable you to meet test needs for 10 days or until your license is rehosted.

Note Emergency licenses are available for emergency circumstances only.

Emergency licenses are required and will be provided in the following cases:

  • The mother board of your license server fails, or your license server suffers a catastrophic crash that will require replacement of the server (see Case 1 below).

    In the case of a server that has been catastrophically damaged, you will also have to rehost your original licenses. See Replacing licenses after a server problem. Rehosting can take several days during which time emergency licenses will meet your testing needs.

  • Your network fails (see Case 2 below).

There are several considerations you should be aware of, when applying for emergency licenses:

  • You must notify your Advantest sales representative as soon as possible by voice or email before (!) you apply for a license.
  • You must take all reasonable steps to restore operation to your original license server, or replace it, within 10 days.
  • You should understand that the temporary licenses you receive will be good for 10 days, by which time you must have rehosted your licenses.

To receive an emergency license from https://www.advantest.com/service-support/ic-test-systems/products-list/v93000-licensing, you need to provide the following data:

  • A valid, usable entitlement ID

    With this entitlement ID you identify yourself as Advantest customer. After using the entitlement ID to receive an emergency license, the entitlement ID will be blocked (unusable) for one year.

  • The host ID of the system controller hosting the replacement license server
  • The number of test systems that were served by the failing license server

Procedures

Case 1: Failure and replacement of the license server

Once you have received the emergency license(s), proceed as follows.

On the replacement license server:

  1. Install the FLEXlm executables (lmgrd, lmutil, ...).

    To download the executables go to https://www.advantest.com/service-support/ic-test-systems/products-list/v93000-licensing and go to FLEXlm License Server Software Downloads and Documents

  2. Create the /opt/flexlm/ELF directory.
  3. Put the emergency license(s) in that directory.
  4. Start lmgrd pointing to the /opt/flexlm/ELF directory:
    /opt/flexlm/lmgrd -c /opt/flexlm/ELF -l /opt/flexlm/log/<logfilename>

On each test system controller (tester workstation):

  1. Create the /opt/flexlm/ELF directory.
  2. Put the ELF license in that directory.
  3. Set the SOCBU_LICENSE_FILE environment variable to the /opt/flexlm/ELF directory.

Case 2: Replacement license server not available or cannot be reached because of network failure

In case your network failed, you must install a local replacement license server and emergency license on every test system controller (workstation). In this case you must provide the host ID of every controller and obtain one (1) emergency license for each. That is, you have to type 1 in the Number of Testers Served by License Server field.

If, for example, you have a network problem and 5 workstations are affected, you have to get 5 emergency licenses to establish 5 local license servers (one on each workstation).

Once you have received the emergency licenses, proceed as follows on each test system controller (tester workstation):

  1. Check if there is another local license server running. If there is a local license server running, stop this license server.
  2. If not already available, install the FLEXlm executables (lmgrd, lmutil, ...).
  3. Create the /opt/flexlm/ELF directory.
  4. Put the emergency license in that directory.
  5. Start lmgrd pointing to the /opt/flexlm/ELF directory: 
    /opt/flexlm/lmgrd -c /opt/flexlm/ELF -l /opt/flexlm/log/<logfilename>
  6. To ensure that SmarTest accesses the emergency license, set the SOCBU_LICENSE_FILE environment variable to the /opt/flexlm/ELF directory.

What to do next

After fixing the license server/network issue,

  • the emergency licenses and any backups must be deleted;
  • the SOCBU_LICENSE_FILE environment variable has to be reset on each test system controller (workstation);
  • the lmgrd license server process pointing to the /opt/flexlm/ELF directory must be stopped.
