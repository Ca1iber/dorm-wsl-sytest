TestSuiteStartEventType

An event of this type is logged when a test suite starts executing.

Attributes

  • TestSuiteNameAttrType

    Holds the name of the started test suite.

  • SiteSetAttrType

    Holds a list of all sites which are involved in the test suite execution.

  • TestSuiteListAttrType

    Holds a list of all test suites, types, and numbers.

  • BypassStateAttrType

    Contains a string representing the bypass/execution state for the particular test suite.

  • PerPinOutputOnFailAttrType

    Contains a string representing the enabled or disabled state of the output of per-pin data with a fail result for the particular test suite.

  • PerPinOutputOnPassAttrType

    Contains a string representing the enabled or disabled state of the output of per-pin data with a pass result for the particular test suite.

  • TimeStampAttrType

    Holds the time when the execution of the test suite was started.

Functional changes

  1. Introduced before SmarTest 6.3.2
