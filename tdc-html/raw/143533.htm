relay()

Specifies relay actions before and after the measurement for DC Scale pins in the code‑based mode.

Syntax

dcBase& relay(TA::SIGNAL_RELAY_ACTION rly);
List of parameters
Parameter Description
rly The relay action.
List of available options of parameter: rly
Option Description
TA::sigRly_on_MEAS_off Before the measurement, connect the Force/Sense.

After the measurement, disconnect the Force/Sense.
TA::sigRly_NO No relay action.

This is the default value.

Return Value

A reference to the dcBase object.

Example

rdi.dc("vm5").pin("DPS32SIG").relay(TA::sigRly_on_MEAS_off).vMeas().execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
