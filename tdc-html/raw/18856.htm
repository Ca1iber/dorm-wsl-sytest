Topic 18856

Using the Pin Attribute Setup Expert Tool

The Pin Attribute Setup Expert Tool enables you to set and or edit pin attributes. The pin attributes are the edge delays per pin to fine-tune the calibration of the device setup.

Before you begin

Make sure that the pin configuration file has been loaded.

Procedure

  1. In the SmarTest Work Center, choose 93000 > Setup > Pin Attributes.

    The Pin Attribute Setup Expert Tool is open.

  2. In the Pin Attribute Table, enter the values which range from -8 ns to 8 ns.

    In case a row of the table represents a pin group made of non Pin Scale 9G pins, the pin attributes are shown only if all pins within the group have identical delays for that particular pin attribute, otherwise a question mark ('?') is shown.

Results

When you change a pin attribute, the entered value is immediately downloaded to the tester.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.1: The attributes of slow edge and fast edge for each Pin Scale 9G pin can be set respectively or simultaneously.
