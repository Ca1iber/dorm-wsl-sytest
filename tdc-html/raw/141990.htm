UTILITY_POWER_STATUS.state()

Switches a utility power supply on or off.

The selected state and the settling time are applied by executing the UTILITY_POWER_STATUS member function execute().

Syntax

void state (TM::UTILITY_POWER onOff);
void state (TM::UTILITY_POWER onOff, TM::UTILITY_BOARD_POWER_SUPPLY supplyId, int resourceId);

The first syntax controls the Utility power supply - XP pins (V93000 EXA Scale systems) of the first optional Utility Card. The second syntax controls the other utility power supplies of the first Utility Card, all utility power supplies of the second Utility Card, or the Internal utility power supplies.

Parameters
Parameter Description
onOff

Defines the new state of the supply.

Available options of the parameter:
  • TM::POWER_ON: Switch the external utility power supply on.
  • TM::POWER_OFF: Switch the external utility power supply off.
supplyId

The parameter of type TM::UTILITY_BOARD_POWER_SUPPLY defines the utility power supply to be set.

Available options of the parameter:

  • TM::UP5V: The +5 V supply on UP5V pins of the optional Utility Card or the internal utility resources.
  • TM::XPP5V: The +5 V supply on XPP5V pins of the optional Utility Card.
  • TM::XPM5V: The -5 V supply on XPM5V pins of the optional Utility Card.
  • TM::XPP3V3: The +3.3 V supply on XPP3V3 pins of the optional Utility Card.
  • TM::P15V: The +15 V supply on UPP15V pins of the optional Utility Card.
  • TM::M15V: The -15 V supply on UPM15V pins of the optional Utility Card.
  • TM::F24VA: The floating 24 V supply on F24VA pins of the optional Utility Card.
  • TM::F24VB: The floating 24 V supply on F24VB pins of the optional Utility Card.
  • TM::UDPS: The Internal Utility Power Option of the internal utility resources that replaces the legacy SE-UDPS.
resourceId

The integer parameter defines the utility power resource to be set.

Available options of the parameter:

  • 1: First optional Utility Card or the Internal utility power supplies of the first card cage.
  • 2: Second optional Utility Card or the Internal utility power supplies of the second card cage.
Some hints and restrictions for setting the supplyId and resourceID parameters:
  • For compatibility with the Internal utility power supply (V93000 systems), the TM::UP5V supply of the first Utility Card or the internal TM::UP5V supply of the first card cage is always switched on. The supply can be programmed by this function but it has no effect on the hardware.
  • For compatibility with PinScale and SmartScale systems, the Utility power supply - XP pins (V93000 EXA Scale systems) of the first optional Utility Card can be programmed only using the first syntax void state (TM::UTILITY_POWER onOff); without the additional parameters defined. The supplyId parameter set to TM::XPP5V, TM::XPM5V, or TM::XPP3V3 in combination with the resourceID parameter set to 1 is not supported.
  • Independently switching the TM::XPP5V, TM::XPM5V, or TM::XPP3V3 supply is supported only for the second Utility Card with resourceID parameter set to 2.
  • The supplyId parameter set to UDPS is supported only in combination with the resourceID parameter set to 1: Since, the second optional Utility Card occupies all (legacy) DPS pogo blocks, the Internal Utility Power Option cannot be used if a second Utility Card is installed.
Return value
There is no return value.
The DUT board must be docked before the utility power supply is switched on by this API.
