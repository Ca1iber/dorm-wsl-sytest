Test Table preference page

By default, the very first row of the test table is considered the header row. However, in case that this first row contains comments or other extraneous information, a different row can be set to be the header.

The Advantest V93000 > Test Table preference page allows you to set a row other than the first row as the header row by specifying the row number.
