Parameters for the DataTraining test method

These tables describe all parameters for the DataTraining testmethod.

DataTraining test method parameters

Name

Comment

TrainingAlgorithm

SpecTraining or EmbeddedTraining

SpecTraining performs the search for the on the test controller workstation as a parallel spec search.

EmbeddedTraining performs the search in the test processor on the test head card.

SourceSyncPinGroups

Pin group. List of source synchronous pin groups (clock domains), separated by a semicolon. Each group must contain one clock output pin and at least one data output pin.

Example:

4 groups: RDQS0o, DQ0o, DQ1o; RDQS1o, DQ15o; RDQS2o, DQ_Bus2;ssgroup3

The sequence of the pins must match the sequence of the variables.

SweepSpecVars

Spec name. The timing specification variables that are to be used for sweeping the specified source synchronous pin groups, separated by semicolons. Variable names can be identical for different source synchronous pin groups. The number of source synchronous pin groups and the number of timing specification variables need to be the same. The sequence of the specification variables must match the sequence of the pins in the field SourceSyncPinGroups.

Syntax:

For single-port testing:

{spec_name_0}; {spec_name_1}; ...; {spec_name_n-1}

spec_name_0, spec_name_1, ... , spec_name_n-1 are names of specification variables.

For multi-port testing:

{spec_name_0@port_0}; {spec_name_1@port_1}; ...; {spec_name_n-1@port_n-1}

SweepStart

Number. The starting value for the sweep. The range between SweepStart and SweepStop is swept first using a linear search and then a binary search. The unit is nanoseconds.

SweepStop

Number. The ending value for the sweep. The unit is nanoseconds.

MinOpenEye

Number. The step size of the linear search, specified in nanoseconds. For the sweep to deliver useful results, this must be considerably smaller than the expected minimum eye open time. The unit is nanoseconds.

AlignAccuracy

Number. The resolution (end criterion) of the binary search, specified in nanoseconds.

PrintEye

Yes or No. If Yes output is printed to the report window.

EdgeCentering

Yes or No. If Yes, the edge center timing data in the sweep spec var is used for further measurements in the later test suite.
Result parameters

Name

Comment

OpenEyeLimit

Number. Specify the upper and lower limit for the eye width. If the eye width is within this range, the test passes. Otherwise the test fails.
