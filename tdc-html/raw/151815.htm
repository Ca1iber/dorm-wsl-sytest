getSearchFallResult()

Retrieves the search result from a falling hysteresis linear search.

Syntax

double getSearchFallResult();

Example

RDI_BEGIN();
  rdi.cogo("result").search(TA::HYST_LINEAR).pathPin("pinA")...blockBegin();
    ...
  rdi.cogo().search().blockEnd();
RDI_END();

rdi.id("result").getSearchFallResult();

Related information

Sequencer-controlled searching with cogo

Functional changes

  1. Introduced in SmartRDI 2.4.3
