Properties of the FUNCTIONAL_TEST API function

  • Accessed through the Digital Test API menu
  • Used with the TEST function formats for overall or port-specific judgment and data logging
  • Used with the GET_FUNCTIONAL_RESULT() function formats for retrieving (no judgment or data logging) overall or port-specific results
  • Can be used to execute any test that includes only digital vector patterns
  • Executes all functional vectors defined for the primary Multi-port Burst label

Functional changes

  1. Introduced before SmarTest 6.3.2
