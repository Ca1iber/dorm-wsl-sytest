The topic you have requested is not available. The topic is available in the latest DUT board design reference. Get the latest DUT board design reference online from V93000 Technical Documentation and install the documentation for your system as described below.

Linux

  1. Copy the files to a temporary directory.
  2. Change to the temporary directory.
  3. Make sure you are logged on as root.
  4. To install the documentation open a terminal window and execute rpm -ihv <file_name>.noarch.rpm. Quit the viewer before each installation.

Windows

To install the documentation execute the <file_name>.msi installer and follow the on-screen installation instructions. Quit the viewer application before each installation.
