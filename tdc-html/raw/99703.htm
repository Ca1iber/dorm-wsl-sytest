Topic 99703

Editing patterns

About this task

Editing patterns includes:

  • Inserting vector lines
  • Deleting vector lines
  • Copying and pasting vector lines
  • Copying and pasting multiple vector cells
  • Copying and pasting particular cells from Pattern Explorer to editor
  • Editing a cell of a vector
  • Resizing a signal column
  • Inserting commands and vectors
  • Copying and pasting test points and events
  • Reusing events

When editing patterns, the following rules apply:

  • You can undo and redo editing actions by selecting Edit > Undo or Edit > Redo.
  • When you copy cells, the cells to be copied will be highlighted with a dark gray color.
  • When you paste cells, the content of the cells will be overwritten. No new cells will be inserted.
    Note Depending on your current selection and buffer content, the context-sensitive right-click menu offers varying copy and paste commands. You must differentiate between, for example, Copy, Paste, Paste Vector, and Paste as New Event. For details see below.

Before you begin

Make sure the Pattern Editor is open with the pattern you want to change, see Opening the Pattern Editor.

Procedures

To insert one vector line:

Highlight the line below the insertion point, right-click and select Insert Vector. A new line will be inserted containing the values of the highlighted line.

To insert one or more vector lines:

  1. Highlight one or more lines below the insertion point, right-click and select Insert Special. The Insert Special dialog pops up.
  2. The Insert Special dialog gives you the following options:
    • To insert one vector line, choose Insert Data from first Selected Vector. This duplicates the first highlighted line.
    • To insert one or more lines, select Insert Data from Paste Buffer (n lines). In this case you must have copied the vector lines in a previous step.
    • If you want to insert the copied data without any instructions, clear the Include Instructions check box.
  3. In the Repeat Count field, type how often you want the vectors or data to be inserted, and click OK.

To delete one or more vector lines:

Highlight the lines you want to delete, right-click and select Delete.

To copy and paste one vector line:

  1. Highlight the line you want to copy, right-click and select Copy.
  2. Position the cursor in the target line, right-click and select Paste Vector. This does not insert a new line, it overwrites the cells of the line.

To copy and paste more than one vector line:

  1. Highlight the lines you want to copy: Click the first line, press Shift and click the last line, right-click and select Copy.
  2. Highlight the line you want to overwrite, right-click and select Paste Vector. This does not insert new lines, it overwrites the lines.

    If the target vector lines are an exact multiple of the copied lines, the copied lines will be pasted multiple times. Otherwise the copied lines will be inserted only once.

To copy and paste a test point:

  1. Right-click the event cell and select Copy.
  2. Right-click the target cell and select Paste.

This copies the test point only, but not the event. The new test point refers to the same event as the source test point. Therefore the reference count of the event increases by 1.

To copy and paste an event for further editing:

  1. Right-click the event cell and select Copy.
  2. Right-click the target cell and select Paste As New Event. The Paste As New Event window is displayed.
  3. Type a new event name and click Finish. This creates the new event, and inserts its test point at the target cell.

You can now continue and modify the event in the properties view of the new event, for example, changing the event type.

To reuse an existing event:

  1. Alternatively to copying and pasting a test point, you can apply the content assist to reuse existing events.
  2. Position the cursor in the target cell.
  3. Press Ctrl-Spacebar-Spacebar. This activates the content assist and opens a pull-down menu. The menu lists the already defined events.
  4. Select an event and press Enter.

This copies the test point only. The new test point refers to the same event as the source test point. Therefore the reference count of the event increases by 1.

To cut and paste a test point:

  1. Right-click the event cell, and select Cut.
  2. Right-click the target cell, and select Paste.

    This moves the test point only. In its new location, the test point refers to the same event as before. The reference count of the event does not change.

To delete a test point:

Right-click the event cell, and select Delete.

This deletes the test point only. It does not delete the event. If the event had only one test point, this leaves the event unreferenced.

Note To delete events without test point references, in the Test Program Explorer right-click the level item and select Delete Unreferenced Events. Select the events to be deleted, and click Finish.

To copy and paste multiple vector cells:

  1. Highlight the source region you want to copy: Click the left upper cell, press Shift and click the right lower cell.
  2. Right-click and select Copy.
  3. Highlight the target region where you want to paste the data: Click the left upper cell, press Shift and click the right lower cell.

    The target region can be any of:

    • A single cell
    • Multiple cells equivalent to the source region
    • The exact multiple of all cells of the source region

      If the target region consists of one cell, the source region will be pasted once. The highlighted target cell will be considered as the left upper cell of your region to be copied.

      If the target region consists of an exact multiple of all cells equivalent to the source region, the source region will be pasted multiple times, both vertically and horizontally.

      If the target region does not consist of an exact multiple of all cells equivalent to the source region, the source region will be pasted only once.

      Use the status line of the Pattern Editor to easily determine the format of the copy and paste regions. The status line is described in Pattern Editor status line.

  4. Right-click and select Paste.

To copy and paste particular cells from Pattern Explorer to editor:

  1. In the Pattern Explorer right-click the cell you want to copy and select Copy.
  2. Got to the target cell in the editor, right-click and select either Paste or Insert.

The cell content is copied if the required conditions, for example naming conventions, are met. Otherwise the paste or insert is rejected.

To edit a vector cell:

  1. Highlight the cell you want to edit and press Ctrl+Spacebar. You may also double-click or press Backspace in a filled cell. A content assist will be activated, which displays a list box containing the valid values. Select the value.
  2. Highlight the cell you want to edit and type the value.
    Note To cancel an entry in a cell press Esc.

To resize a signal column:

To quickly resize the width of a signal column, double-click the column divider to the right of the column in the header area, for example to the right of the signal name. The first double-click increases the width, the second double-click restores the original width.

To change a large number of cells:

  1. Highlight the first cell you want to change.
  2. Enter the value, for example 0 or 1.
  3. Use the arrow keys to select the next cell you want to change.
  4. Enter the value.
  5. Repeat this for all cells you want to change.

To fill a large number of cells with repeating content:

  1. Example: Fill all vector cells of a clock signal with 0,1,0,1 ...
  2. Highlight the first cell and type 0
  3. Highlight the second cell and type 1.
  4. To highlight the first and second cell click the first cell, press Shift and click the second cell.
  5. Right-click and select Copy.
  6. Highlight the remaining cells of the signal, right-click and select Paste. The number of cells must be a multiple of the copied cells, otherwise only the first block will be inserted.
