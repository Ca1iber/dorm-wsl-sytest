Test number conversion rules

As inputs the test number conversion tool requires a testflow file and its corresponding test number file. As output, its generates a modified testflow file and a test table CSV file if specified. To use the test number manager some rules apply.

  1. The conversion will start if the following testflow flags are set to 1 in the specified testflow. After the conversion, the test number manager flag value will be set to 0 in the converted testflow file.
  2. For all tests that appear in the Tests tab of the testflow editor, the test number will be set based on the test number file. For tests that do not appear in the Tests tab, there will be a warning message that indicates you to modify the test numbers manually in test methods.
  3. If a test involves different pins, the first test number of those tests will be set to Tests tab, a Test Numbering Preference should then be modified accordingly based on the guidelines of the conversion result.
  4. If a test table CSV file is specified, a Pins column will be added to the test table CSV file, assuming there's pin information in the subtest section of the test number file. In such a case, the lookup key contains three columns: test suite name, test name and pin name. If no pins column is specified in the test table CSV file, the lookup key contains only two columns: test suite name and the pin name.
  5. If a csv TMLimits file is specified, the priority of test number in this file is higher than that in testflow file. This applies to following three situations:
    • If the test is specified in the TMLimits CSV file and the corresponding test number is the same with that in test number file, no conversion needed no matter if such test number is defined in testflow file or not and no matter if such test number is the same or not.
    • If the test number defined in the TMLimits CSV file is different from that in test number file, the test number in the TMLimits CSV file will be converted no matter if test number defined in testflow is same or not.
    • If the test is not specified in the TMLimits CSV file, then this conversion tool will check the definition in testflow file.
  6. Manual work is required it test numbers are hard-coded in test methods.
