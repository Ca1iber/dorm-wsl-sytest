SMC_SET_HLM_FORMAT()

Formats the higher limit of the previous SMC_TEST() in the data formatter output.

Calling this function stores the supplied format string in the C_HLMFMT fields of the parametric test record (PTR) and the multiple-result parametric record (MPR).

Note This API cannot be used with Hidden data logging.

Use the TESTSET.hlmfmt() function instead, if you need this functionality with hidden data logging.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Syntax

void SMC_SET_HLM_FORMAT(const STRING& format);
Parameter

Parameter

Description

format

A string describing the desired format. The string is a standard ANSI C format string, for example, "%7.3f".

Return value

There is no return value.
