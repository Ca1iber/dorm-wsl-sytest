Topic 96398

DEVICE_CHANGE_STARTED

This asynchronous event indicates that device change is starting. Both the HVM API ChangeDevice and the change device operation in SmarTest Work Center will result in this event.

Dependency

The changing device operation is in execution.

Parameters

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session this event belongs to.

O

TIME_STAMP

The time point when the event occurs. It contains two long-type part: SECONDS and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always EXECUTION.

O

EVENT_BODY

The event parameters. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always CHANGE_DEVICE_STARTED.

DEVICE_PATH

The device path to set.

DEVICE_NAME

The device name that to set.

This parameter is represented by ParamList whose key and value are both string type.
