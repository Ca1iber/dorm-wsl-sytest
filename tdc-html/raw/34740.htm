DRLGetEventMask

const DRLEventMask *DRLGetEventMask (DRLDataStream *stream)

DRLGetEventMask returns a pointer to the currently active event mask of the data log stream or file referenced by stream. With this pointer you can access the active event mask, for example, in order to find out which events are respectively masked or unmasked at the moment (see DRLEventMask).

Note that we do not recommend making changes directly to the active event mask; this should be done using the DRLSetEventMask function.

Return Value

The function returns a pointer to the active event mask of the data log stream or file event, or NULL in case of an error.

Functional changes

  1. Introduced before SmarTest 6.3.2
