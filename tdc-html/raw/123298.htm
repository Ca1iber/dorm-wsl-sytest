GET_LIMIT_OBJECT()

Returns the reference of the LIMIT object for the specified test name.

Syntax

const LIMIT& GET_LIMIT_OBJECT(const string& testname);

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Parameters
testname

A test name used in the current test suite.

If the test name specified is invalid, an exception will be issued.
Return value
A reference to the requested LIMIT object.

Example

This example retrieves the reference to the LIMIT object of the test name "ppJitter" and copies the object into variable limitPP of type LIMIT.

LIMIT limitPP;

limitPP = GET_LIMIT_OBJECT("ppJitter");

Related information
