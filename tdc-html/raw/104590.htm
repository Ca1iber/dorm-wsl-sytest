DSP_RESAMPLING

This function resamples arrays containing sampled waveforms with a new sampling frequency. The resampled waveform is stored in a new data array. This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_RESAMPLING(ARRAY_D& src, ARRAY_D& result, DOUBLE fs_src, DOUBLE fs_rslt);
DSP_RESAMPLING(DOUBLE *src, DOUBLE *result, INT size_src, INT size_rslt,
               INT *size_rslt_wfm, DOUBLE fs_src, DOUBLE fs_rslt);
Parameters

I/O

Parameter

Description

I

src

Source array

O

result

Data array containing the resampled waveform. This array has to be defined large enough to store all the resampled data.

I

size_src

Size of the data array containing the original waveform (src array).

I

size_rslt

Size of the data array containing the result waveform (result array).

ceil(size_src * fs_rslt/ fs_src) ≤ size_rslt

O

size_rslt_wfm

Size of the resampled waveform.

size_rslt_wfm = ceil(size_src * fs_rslt / fs_src)

I

fs_src

Sampling frequency of the sampled waveform contained in src array

I

fs_rslt

Sampling frequency of the resampled waveform contained in result array

Example

  1. This example resamples the 80 MHz signal baseband_sig with 100 MHz and saves the resampled waveform in the baseband_signal_100MHz array. 
    ARRAY_D baseband_sig, baseband_signal_100MHz;
  .
  .
DSP_RESAMPLING(baseband_sig, baseband_signal_100MHz, 80E6, 100E6);
  2. In this example, the signal wave_src, which has been sampled at 2 Msps, is resampled at a rate of 2.048 Msps. The result is stored in the array wave_rslt.
    int size_in = 1100;
int size_out = 1026;
int size_rslt_wfm;
double fs_in = 2.0E6;
double fs_out = 2.048E6;
 
double wave_src[1000];
double wave_rslt[1026];
 
DSP_RESAMPLING(wave_src, wave_rslt, size_in, size_out, &size_rslt_wfm, fs_in, fs_out);

Functional changes

  1. Introduced in SmarTest 6.5.2
