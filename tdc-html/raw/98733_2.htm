SHVL, SHVL? - (SHmoo spec VaLues)

The SHVL (SHmoo spec VaLues) command sets values to the shmoo specifications defined by the SHSP command. It works only with primary sets.

  • When a shmoo spec is defined using SHSP, but its value is omitted in the SHVL command, the value is left unchanged. This speeds up shmoo when one row or column is completely measured.
  • To restore values after shmoo, submit an SHVLRSTO,RSTO command.

The SHVL? query returns the values of the shmoo specifications defined by the SHSP command. It always works with primary sets.

With this command you configure setups of those sites that have the setup focus: For more information, see also: PSFC, PSFC?.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

SHVL

SHVL [value_1], [value_2]

SHVL?

SHVL?

returns:

SHVL [value_1], [value_2]

Parameters

value_1

A double float defining the new value, with up to 5 digits after the decimal point. Valid range is -21474.83648 to +21474.83647.

Or use RSTO to restore the original value.

value_2

A double float defining the new value, with up to 5 digits after the decimal point. Valid range is -21474.83648 to +21474.83647.

Or use RSTO to restore the original value.

Application

  • Shmoo

Errors

An error is generated if no shmoo specifications have been defined using the SHSP command.

Example

> SHSP TIM, "shmsp@Port1",, TIM, "shmsp@Port2",
> SHVL 2,3
> SHVL?
< SHVL 2,3
