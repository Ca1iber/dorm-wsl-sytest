Topic 20920

Controlling GPIB Instruments

You can connect peripheral devices such as external instruments, printers, and plotters to the tester controller of the V93000. The tester controller can control these devices through the General Purpose Interface Bus (GPIB).

Each device, tester controller, or peripheral connected to the GPIB can function in one or more of the following roles:

Tester Controller

Master controller of the GPIB. The tester controller usually controls the GPIB, and all peripheral devices on the GPIB are slaves to the tester controller. The tester controller is always address 21.

However, any other device can become the GPIB (active) controller if it is equipped to act as a controller, and control is passed to it by the tester controller. The tester controller is always the GPIB (active) controller at power-up.

Active Controller

Present controller of the GPIB. At power-up or whenever InterFace Clear (IFC) is set to true by the tester controller, the tester controller is the active controller.

Under certain conditions, the tester controller may pass control to another device that is capable of managing the GPIB, and the active controller can then pass control to another controller or back to the tester controller. If the tester controller sets IFC to true, the tester controller immediately becomes the active controller.

Talker

A device that has been authorized by the present active controller to place data onto the GPIB. Only one talker can be authorized at a time.

Listener

Any device that has been programmed by the active controller to accept data from the GPIB. Any number of devices on the GPIB can be programmed by the active controller to listen simultaneously.

The GPIB is composed of 16 lines (plus ground) that are divided into three groups:

  • Eight data lines form a bidirectional data path to carry data, commands, and device addresses.
  • Three handshake lines control the transfer of data bytes.
  • Five lines for GPIB management control.

V93000 testers provide the following test method APIs for controlling GPIB instruments. For details, see API Reference.

  • GPIB_SET

    Sets a timeout time and a data terminator for data input.

  • GPIB_SEND

    Sends data or GPIB commands.

  • GPIB_ENTER

    Gets data from the specified device and saves the ASCII data to the specified variable.

  • GPIB_ENTER_B

    Gets data from the specified device and saves the binary data to the specified variable.

  • GPIB_OUTPUT

    Sends device-dependent data to the specified device.

  • GPIB_SPOLL

    Gets the serial poll response from the specified device.
