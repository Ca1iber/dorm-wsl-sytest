Topic 71561

DRLParaOrFuncTestTypeAttr

A variable of this type holds an enumerated one-byte value indicating the type of test, whether parametric or functional.

Expected values: (1-byte integer values of type ParaFuncTestType)

typedef enum {
  TEST_TYPE_UNDEFINED,             /*0*/
  TEST_TYPE_FUNCTIONAL,            /*1*/
  TEST_TYPE_PARAMETRIC,            /*2*/
  TEST_TYPE_MULTIPLE_PARAMETRIC,   /*3*/
  TEST_TYPE_PARAMETRIC_FUNCTIONAL, /*4*/
  TEST_TYPE_ANALOG,                /*5*/
  TEST_TYPE_FLEX_DC,               /*6*/
  TEST_TYPE_SCAN,                  /*7*/
  TEST_TYPE_MEMORY,                /*8*/
} ParaFuncTestType;

Functional changes

  1. Introduced before SmarTest 6.3.2
