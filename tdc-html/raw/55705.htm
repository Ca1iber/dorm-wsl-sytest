Parameter: single_step_mode

Sometimes it is necessary to slow down all driver operations, for example when testing a new application model, or when analyzing a malfunction.

This parameter sets the driver to the single step mode. In single step mode the operator is prompted for confirmation at each call from the application model to the equipment driver.

Single step mode can also be activated/deactivated by calling special driver functions from the application model. These are described in Functions for Changing the Driver Mode.

Note If the single step mode was enabled by the function ph_stepmode_start, and not by setting this parameter to "on," it cannot be disabled by setting this parameter to "off'. The function ph_stepmode_stop must be used for this. Likewise, if the single step mode was disabled by the function ph_stepmode_stop, and not by setting this parameter to "off," it cannot be enabled by setting this parameter to "on." The function ph_stepmode_start must be used.

Driver default: "off"

Changeable at run-time: yes

Applicable for: handlers and probers

Example: single_step_mode: "off"
