Topic 97815

Creating a port

Before you begin

Make sure your pins are defined.

Procedure

  1. In the Test Program Explorer view, right-click Ports and choose New.

    The New Port window opens.

  2. Type the port name (for example, Port_IO) in the New Port field.
  3. Click OK.

Results

The Port Setup Editor for the new port opens. The Port Members area is blank.

What to do next

Edit the port.

Functional changes

  1. Introduced before SmarTest 6.3.2
