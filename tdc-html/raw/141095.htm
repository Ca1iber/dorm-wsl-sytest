DIGITAL_OFFSET_SEARCH_PINS.resolution()

Sets the resolution for the binary search. If the resolution is not specified, the step width will be used to stop the binary search.

Syntax

DIGITAL_OFFSET_SEARCH_PINS& resolution(DOUBLE res);
Parameter

Parameter

Description

res

The resolution of the binary search.

For timing searches, the unit is seconds [s].

For voltage searches, the unit is Volts [V].

Return value

A reference to the DIGITAL_OFFSET_SEARCH_PINS object.

Related information

DIGITAL_OFFSET_SEARCH_PINS.stepWidth()

Functional changes

  1. Introduced in SmarTest 7.2.1
