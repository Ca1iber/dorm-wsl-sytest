Execute a test program

The ExecTestProgram and ExecTestProgramSync functions execute the test program currently loaded in the Test Program Explorer that is the same function as the execute option in the Test Program Explorer. After a test program is started, ExecTestProgram does not wait for the end of the test program execution, and ExecTestProgramSync waits for the end of the test program execution.

long ExecTestProgram()

long ExecTestProgramSync()

For executing testmethod-based testsuites, you can also use the Hardware Response Emulator for importing a hardware response data file that is generated by storing the actual measurement data or software simulation data. For more details of the Hardware Response Emulator, see the Test Method Programming Reference manual.

The ExecTestProgramImport and ExecTestProgramSyncImport functions execute the test program currently loaded in the Test Program Explorer and start the Hardware Response Emulator for importing a hardware response data file for testmethod-based testsuites. After a test program is started, ExecTestProgramImport does not wait for the end of the test program execution, and ExecTestProgramSyncImport waits for the end of the test program execution.

long ExecTestProgramImport()

long ExecTestProgramSyncImport()

The ExecTestProgramStore and ExecTestProgramSyncStore functions execute the test program currently loaded in the Test Program Explorer and start the Hardware Response Emulator for storing the actual measurement data or software simulation data to a file for testmethod-based testsuites. After a test program is started, ExecTestProgramStore does not wait for the end of the test program execution, and ExecTestProgramSyncStore waits for the end of the test program execution.
