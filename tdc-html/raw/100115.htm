Topic 100115

GET_BIN

This API retrieves the bin information. This API can be used to get the bin information that a device has reached. Once a site has reached a bin in the testflow, the software and hardware bin number of this bin are available through this API. If the bin is configured as overon, the first bin that the site has reached is available through this API.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

GET_BIN(STRING& softbin, INT hardbin);

Parameters

I/O

Parameters

Description

O

softbin

The software bin number of the bin.

O

hardbin

The hardware bin number of the bin.

Example

string softbin;
int hardbin;
GET_BIN(softbin, &hardbin);

Functional changes

  1. Introduced before SmarTest 6.3.2
