General information about the Yokogawa GPIB handler driver

This section provides general information about the Yokogawa GPIB handler driver.

Configurations provided

The following configurations are provided with the driver:

  • HS2000-GPIB-1.cfg
  • HS2000-GPIB-2.cfg
  • HS2000-GPIB-4.cfg

The configurations differ only in the number of sites they provide.
