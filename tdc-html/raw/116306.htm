Topic 116306

Creating a Digital Capture setup

Digital Capture is a technique that allows you to capture large amounts of unpredictable digital output of a device at high data rates. It is typically applied to test analog-to-digital converters, or to read out registers or memories with arbitrary content.

About this task

Captured data can be formatted, as it is uploaded from memory, using so-called "vector variables". A vector variable is always related to one specific pattern and cannot be used with another one. After executing the pattern, the captured data can be accessed with a test method, which usually also performs some post-processing.

A setup wizard guides you through the Digital Capture setup. The wizard provides screens to maintain the set of capture pins of the device and to create new vector variables with all the necessary parameters.

Once a test has completed, usually you want to format the data from a subset of the capture pins and to omit certain vectors or even entire portions of the captured data. The vector variable allows you to define an arbitrary sub-set of the captured data to be uploaded (a special sub-set could also be the complete data).

The typical workflow in the wizard is:

  1. You define or adjust existing device capture pins.
  2. You select the capture pins that will contribute data to the new vector variable.
  3. You set vector variable parameters to format the uploaded data.

All x-modes are supported. Digital Capture can also be set up using the ASCII-interface.

The terms "label" and "vector label" are often used as synonyms for pattern.

Before you begin

You can set up a pattern for Digital Capture with the pattern debug tool just like any other pattern, but the pattern type must be Main.

Procedure

  1. In the pattern explorer open the Main pattern for which you want to define capture settings.
  2. In the pattern editor, right-click and select New Setup. The Setup Wizard opens.
    Note If you right-click in a pin cell, or preselect pins in the pattern editor, any capture pin will be automatically added to the set of device capture pins.
  3. Select Digital Capture and click Next.

    Depending on the wavetable used by the capture pattern, the wizard is automatically set to Selective mode or Sequential mode. If the pattern uses a wavetable containing selective capture actions ('C' for Capture, or 'D' for Do not Capture), the Selective mode is set, otherwise, the Sequentialmode. In case that none of the device pins is defined as capture pin, the capture mode is set to Undefined.

    The following options differ slightly depending on the mode.

  4. Specify the Device Capture Pins:
    • To keep the pin configuration and simply change the current pattern (label) to a capture pattern (label), click Finish.
    • To modify the current capture pattern (label) configuration, click Configure.

      This opens the Pin Selection View, which allows to add or remove pins, or to modify the sequence of pins in the capture pattern.

      On the left, the Pin Selection View shows all possible capture pins of the device, on the right the currently defined capture pins.

      When done in the Pin Selection View, click OK. The modified Device Capture Pins configuration is listed in the Setup Wizard.

  5. For the Resolution, the wizard provides several options:
    • Standard: One capture sample will be taken per test system period.
    • Double: Two capture samples will be taken per test system period (for Sequential capture mode only).
    • Statemap: The number of samples to be taken per test system period are read directly from the X-mode definitions in the STATEMAP section of the pattern's wavetable.

      Choose a Resolution. When done click Next.

  6. To specify the vector variable name, type it in the Vector Variable text box.
  7. To specify the Vector Variable Pins configuration, click Configure. This opens the Pin Selection view, which allows you to add or remove pins, or to modify the sequence of pins in the vector variable.

    On the left, the Pin Selection View shows all possible device capture pins; on the right it lists the vector variable pins, that is, the pins which will source data to this new vector variable.

    When done click OK. The modified Vector Variable Pins configuration is listed in the setup wizard.

    The pin sequence in the Vector Variable Pin list is important: the first pin defines the MSB (Most Significant Bit) and the last pin defines the LSB (Least Significant Bit).

    When satisfied with the Vector Variable Pins configuration list, click Next.

  8. Select the Transfer Mode.Note that the capture parameters change depending on your selection - Parallel or Serial.
  9. Modify the capture parameters.

    Parallel Transfer Mode - Transfers the captured data of more than one pin at once.

    • Initial Skip Samples: The number of initial samples to be skipped.
    • Frame Length in Samples: The number of read samples for each pin specified in the vector variable pins field to form one frame.
    • Frame Count: The number of frames to be read.
    • Skip Samples: The number of samples to be skipped after reading one sample. For example, a value of 1 reads every second sample from the memory (Sample 1, 3, 5, ...).
    • Inter-Frame Skip Samples: The number of samples to be skipped between frames.
    • The number of Samples per Word is always 1

      Serial Transfer Mode - Transfers the captured data of only one pin.

    • Bits per Word: The number of formatted bits (after skipping) to be uploaded in each single 32-bit word. The choice of bits per word can have consequences on the upload performance.The higher the value (max. 32) of Bits per Word, the faster the resulting upload performance.
      Note The bits in the captured samples are assembled in the order MSB to LSB.
    • Initial Skip Bits: The number of initial bits to be skipped.
    • Sample Length in Bits: The number of bits per sample.
    • Sample Count: The number of samples.
    • Skip Bits: The number of bits to be skipped after reading one bit. For example, a value of 1 reads every second bit from the memory (Bit 1, 3, 5, ...).
    • Inter-Sample Skip Bits: The number of bits to be skipped between samples.
      Note Unlike the other settings of the vector variable to blend out certain parts of the captured data, the initial discard will already be applied when the captured data is uploaded from the vector to the system controller. That is, the samples defined by the initial discard will not be uploaded from the memory. All other data filtering will be carried out on the uploaded data in the system controller.

      For a detailed explanation of these parameters see Vector variable examples.

  10. When done click Finish.

Results

You completed the Digital Capture setup. To view the new vector variable in the pattern editor, it must belong to the layout configuration.

The Outline view displays all vector variables attached to a pattern. To remove a vector variable, right-click in the Outline view and select Delete.

The Properties view of a vector variable displays all the parameters you have set. You can also modify them in the Pattern editor properties view.

What to do next

To execute a digital capture pattern use the function DIGITAL_CAPTURE_TEST API. After the execution, the captured values can be displayed in the pattern editor. To retrieve the captured data use the VECTOR API.
