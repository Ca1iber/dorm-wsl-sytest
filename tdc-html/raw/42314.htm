The hook function files ph_hhook.c and ph_phook.c contain the templates of the five hook functions

  • phHookActionStart
  • phHookActionDone
  • phHookActionProblem
  • phHookActionWaiting
  • phHookPopup

Each template contains a simple example implementation of functionality. To implement user-specific functionality, this example code must be replaced.

The header file ph_hhook.h for ph_hhook.c is located in the directory

... /GenericHandler/include/

The header file ph_phook.h for ph_phook.c is located in the directory

... /GenericProber/include/

The following sections describe the hook function templates and explain when each hook function is called by the driver.

In addition, man pages are available for all functions in ph_hhook.c and ph_phook.c which contain further information about these functions. See Appendix B: Man Pages for Driver Functions for details.

Note The hook function print-outs in this manual show the functions of the general handler driver Revision 2.0. Please look at the hook function source and header files ph_hhook.c, ph_phook.h and ph_phook.c, ph_phook.h for the most up-to-date hook function implementation of the general handler and prober drivers.
