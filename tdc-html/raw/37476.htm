The DELETE Section

As already mentioned, you can use the output version of the global configuration file as the input version of a second ait call in order to expand or modify an existing timing. Modifications are executed with the help of the DELETE section. The format of this section is:

DELETE

(PAT|GRP) <pattern_or_group> (SUB|REF|REP)

The meaning of the elements is as follows:

  • PAT:

    Signifies that a pattern is to be deleted or modified.

  • GRP:

    Signifies that a pattern group is to be deleted or modified.

  • <pattern_or_group>:

    Specifies the name of a pattern or a group. The name must be defined in the PATTERNS section and/or the GROUPS section.

  • SUB:

    This operator indicates that the pattern or group <pattern_or_group> is to be deleted. If it is a group, not only the group, but also all of its elements are removed, unless they are also contained in another group. If it is a pattern, the pattern is also removed from all the groups in which it is contained; the groups themselves are not deleted.

  • REF:

    This operator is only applicable to groups (type GRP). It indicates that only the group is to be removed, but not its elements.

  • REP:

    This operator indicates that the properties of the respective pattern or group are to be modified. A PATTERNS or GROUPS section redefining the parameters of <pattern_or_group> must be added after the DELETE section.

For an example, see Making Use of the Output Version.
