Topic 42321

Parameters:

  • phFrameAction_t call

    the identifier of the driver function called by the PROB_HND_CALL from the application model, for example, PHFRAME_ACT_DEV_START for the function ph_device_start.

    In the switch(call) section, the function contains the code to be executed for the different driver functions called by the PROB_HND_CALL.

    There are identifiers for all driver functions which can be called from the application model. The identifiers are defined in the header file phFrame.h in the directory ... /GenericHandler/include/ and in

    ... /GenericProber/include

  • char *parm_list_input

    the driver function parameters passed over from the PROB_HND_CALL of the application model.

  • int parmcount

    the number of parameters passed over.

  • char *comment_out

    the comment to be send back to the application model, as already set by the driver (or, for example, by the phHookActionStart function) during the PROB_HND_CALL executed right before this phHookActionStart function was called.

  • int *comlen

    the length of the comment, as already set by the driver

  • phTcomUserReturn_t *stReturn

    The SmarTest return value, as already set by the driver. See Common Components of All Hook Functions.
