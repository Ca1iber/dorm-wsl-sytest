vForce()

Specifies the voltage to force.

Syntax

vForce(double dV);
vForce(const string& sData);
List of parameters

Parameter

Description

dV

The voltage to force

sData

The string containing the value to be used at run-time.

Example

rdi.dc().pin("pinA",TA::SPMU).vForce(2.5 V).execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
