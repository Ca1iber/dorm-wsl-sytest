Topic 126283

Generating protocol wrappers

Subtopics

  1. Generating protocol wrappers using the 2nd level protocol wrapper tool

About this task

This task describes how to generate a customized wrapper of you protocol's transaction which can be used within your test methods.

Within this task you can also decide to generate protocol independent result classes you may use in your test methods to access results of your protocol's transactions.

Before you begin

Ensure you have completed the protocol definition including transactions, pin roles and fields.

Note If you have modified your protocol and if you use your wrapper in your test methods, you have to re-generate your wrapper again!

Procedure

  1. In the protocol editor right-click the protocol icon and select Generate Protocol Wrapper...
  2. Enter the Class Name of your choice and select a Location to save the generated files.
    Note Disable the Uses Result Access Classes option if you do not intend to have result classes included to your wrapper class.
  3. If you like to generate protocol independent result classes, enable the corresponding Generate options and select a Location.
  4. Click Next to proceed to select the Transaction Methods to be included to your wrapper class.
    Note All transaction methods are enabled by default.
  5. Deselect transaction methods you do not like to be included to your wrapper class by clicking on the check box in front of that method.
  6. Click Finish to generate the files in the locations you've selected in the previous steps.

Results

The protocol related wrapper class files have been saved to the location you entered.

If you have chosen to generate result classes, too, they are also saved to the location you entered.
