Logging text data in the TEST_TXT field

The TESTSET API contains methods and members to allow logging of text data to the TEST_TXT field.

The TESTSET API accesses a data container holding information that defines numbering procedures for results in a given test suite. The TESTSET API provides a range of functions for judging and logging the test results. (For backward compatibiltiy, the TEST API can also be used form this purpose.) The test name and test number functions are used with TESTSET to assign user-defined names and numbers to specific tests. The test number member functions are used with the TESTSET API to define test numbering procedures.

You can use the system-prepared class object "TestSet" when using member functions. You can also create a new class object. If a function sets up a parameter, the parameter setting is kept until you reset it or return it to a default setting.

Note Only some methods and member functions of the TESTSET API are shown here. For complete information, see TESTSET.

If you do not want to use the TEST_TXT field, you can suppress the logging of data in this field by setting the setTestTxtEmpty parameter in the formatter.stdf.main.conf file to true.

Syntax

For a temporary object:

TESTSET().member_func().TEST(parameters);

For a system-prepared object:

TestSet.member_func().TEST(parameters);

User object (TESTSET obj;)

obj. member_func().TEST(parameters);

member_func() is one of or a combination of the following member functions:

  • port()
  • cont()
  • reliability()
  • testnumber_default()
  • testnumber_none()
  • testnumber()
  • testname_default()
  • testname()
  • testtext_none()
  • testtext()
  • testtype_default()
  • testtype()
    Note member_func entries are optional.

TEST(parameters): One of the TEST member functions. See the TEST API in the Test Method Programming Reference.

Class definition

Constructor

TESTSET();

Member functions

TESTSET & testtext_none();
TESTSET & testtext(const STRING &text);
TESTSET & testtype_default();
TESTSET & testtype(TM::TEST_TYPE type);

System-prepared class object:

TestSet

Constructor

TESTSET();

This constructor creates the class object that contains the settings of the member functions that define numbering procedures for results in a given test suite, and is used for specifying all options that relate to the TEST API and test methods.

Member functions

  • testtext_none( )
    TESTSET & testtext_none();

    No text for the current test will be stored into the EDL.

    Parameters: none

  • testtext( )
    TESTSET & testtext(const STRING &text);

    This member function lets you enter descriptive text in the TEST_TXT field. How the text you specify is handled depends on the setting of the disableTestTxtOverride configuration option:

    • If it is false (the default), the text you specify is the entire content of the TEST_TXT field.
    • If it is true, the specified text is appended at the end of the field as a comment.

      Parameters:

    • text: String of text stored in the EDL as a TestDescriptionAttrType.
  • testtype_default( )
    TESTSET & testtype_default()

    Parameters: none

  • testtype( )
    TESTSET & testtype ()

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.1: testtext() text can replace the content of TEST_TXT or be appended to it
  3. SmarTest 7.2.1: Logging in TEST_TXT can be completely suppressed
