SHARED_CONTINUITY_TEST.sharingConfigFile()

The sharingConfigFile() member function of SHARED_CONTINUITY_TEST lets you specify the name of the driver sharing configuration file used which should be located in <device directory>/configuration/.

Syntax

SHARED_CONTINUTIY_TEST& sharingConfigFile(const string& filename)

Parameter

Description

filename

Name of the driver sharing configuration file used.

This file should be in <device directory>/configuration/.

Example

SHARED_CONTINUITY_TEST mTest;
mTest.sharingConfigFile("default.cfg");

Related information

SHARED_CONTINUITY_TEST
