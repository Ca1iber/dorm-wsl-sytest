Transferring test suites to the Shmoo Tool

You can transfer the setups of a test suite to the Shmoo Tool.

Before you begin

Make sure:

  • A testflow is loaded with full setups and is opened with Flow Sequence Editor.
  • The Shmoo Tool is opened. See Opening the Shmoo Tool.

Procedure

In the Flow Sequence Editor, right-click a test suite and select Shmoo > Show In Shmoo Tool.
Note You must select this test suite with narrow selection. Otherwise, the Show In Shmoo Tool command is not available.

Results

  • A new shmoo page opens in the shmoo editor with the name "<the test suite name>_shmoo". Then,
    • When you click this shmoo page in the Shmoo Tool, the shmoo test suite in the testflow is highlighted automatically.
    • When you select the shmoo test suite in the testflow, the corresponding shmoo page in the Shmoo Tool opens automatically.
  • If the test suite is a shmoo test suite, all setups of the shmoo test suite are transferred to the Properties view related to the shmoo page.
  • If the test suit is a non-shmoo test suite, this test suite is transferred to the Shmoo Tool as shmoo over a test suite, which means, in the Properties view related to the shmoo page:
    • No primary setups because the shmoo test will use the primaries of the transferred test suite.
    • In the Testmethod field, the ac_tml.AcTest.Shmoo test method is selected.
    • In the shmooTestSuite field, you see the name of the transferred test suite.
    • No the resultPins and perPinResult parameters.
    • You need to set up the other parameters.

What to do next

  • If you transferred a shmoo test suite to the Shmoo Tool, in the Shmoo Tool, execute and view the shmoo plot.
  • If you transferred a non-shmoo test suite to the Shmoo Tool, in the Shmoo Tool, set up the shmoo over this test suite.

    For the setups, see Setting up shmoo tests in the Shmoo Tool.
