Topic 112629

Activating and deactivating filter rules

Filter rules can be activated and deactivated individually. Only activated rules are used in filtering the bit fail map displays.

About this task

You can deactivate individual rules to temporarily remove them from the applied filter without completely discarding them.

Before you begin

The filter rules must have been set up, as described in Creating and editing filter rules.

Procedures

Deactivating a filter rule

  1. In the Filters tab, uncheck the rule in the Active column.
  2. Click the Apply button to put the change into effect.

Activating a filter rule

  1. In the Filters tab, check the rule in the Active column.
  2. Click the Apply button to put the change into effect.

Results

If you have deactivated a rule, the bit fail maps are now filtered as if the rule did not exist.

If you have activated a rule, it is included in filtering the bit fail maps.

Functional changes

  1. Introduced before SmarTest 6.3.2
