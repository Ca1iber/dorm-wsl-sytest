Topic 141501

SmartRDI: DC test setup

Subtopics

  1. DC test with digital channels
  2. Setting up DC Scale pins with SmartRDI

SmartRDI supports DC tests with PPMU, BADC, and DC Scale on V93000.

To do static DC tests, use the code‑based mode. To do dynamic DC tests, use the pattern‑based mode.

  • Pattern-based commands only trigger actions that you have specified. Although it is rare, there are some pattern‑based commands that do not follow this rule, for example, commands for TMU connections.
  • Code-based commands can contain default settings if the related parameters have not been specified. The default settings are applied in each separate command (.execute()). For examples, 
    // For DPS128 pin
rdi.dc().pin("P1_DPS128").vForce(1 V).iForceRange(150 mA).execute(); // range=200mA, iClamp=150mA, min/max=150mA
rdi.dc().pin("P1_DPS128").disconnect();
rdi.dc().pin("P1_DPS128").vForce(1 V).execute(); // range=1000mA, iClamp=500mA, min/max=500mA
  • Recommendations:
    • If you are not to use default values for parameters used for connecting pins, specify all the relevant parameters in code‑based commands.
    • Use code‑based commands only for connection or disconnection of pins and put all other commands inside an RDI_BEGIN/RDI_END block.
    • If you need to execute setups or measurements in code‑based commands, specify all relevant parameters in each .execute().
    • Set RDI_INFO_LEVEL = 1 or 3 and then verify the execution events of code‑based commands in the UI_Report log; or check the HW-Monitor.
Note In a command as rdi.dc().pin(A)...pin(B)...execute():
  • If pin A and pin B are the same type, for example, both are DC Scale pin or digital channel, pin A and pin B will act in parallel.
  • If pin A and pin B are not the same type, for example, pin A is a DC Scale pin and pin B is a digital channel pin, pin A and pin B will act in serial order.

Functional changes

  1. Introduced in SmartRDI 2.1.0
