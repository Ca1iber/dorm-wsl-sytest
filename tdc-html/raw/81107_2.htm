Topic 81107

Setting up vector labels

About this task

Create a vector label each for the additional wavetables for tDQSQmax and tDQSQmin created in the previous section. You need to do that only if you do not want to use one of the standard test patterns, for example the march6n pattern.

Before you begin

Make sure your source code generates toggle patterns for clock and data that match your wavetables.

Procedure

  1. Using the data manager of SmarTest, save the timing equation file.
  2. Open the vector setup tool.
  3. Select the vector label by clicking, for example, mtl_gapless.
  4. Right-click the vector label mtl_gapless and choose Copy from the menu.
  5. Right-click the same area and choose Paste from the menu. The Paste Pattern window opens.
  6. Rename the pattern in the Name field to, for example, DQSQmaxtime_mtl_gapless.
  7. Click OK to apply your changes and to close the window.
  8. Select the vector label by clicking, for example, mtl_gapless.
  9. Right-click the vector label mtl_gapless and choose Copy from the menu.
  10. Right-click the same area and choose Paste from the menu. The Paste Pattern window opens.
  11. Rename the pattern in the Name field to, for example DQSQmintime_mtl_gapless.
  12. Click OK.

Results

Now the vector label is ready for use with this test methods.

Functional changes

  1. Introduced before SmarTest 6.3.2
