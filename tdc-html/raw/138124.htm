An STPM MCM control file contains a script that tells SmarTest Program Manager MCM how to perform an conversion process. The detailed rules for combining the files are set out in the MTPT (STPM MCM mapping tables).

There are commands for generating mapping tables or test program directories, for creating the MTP or updating specific objects in the MTP, as well as for executing Python scripts. The control file also contains a number of global settings.

Functional changes

  1. Introduced in SmarTest 7.1.4
