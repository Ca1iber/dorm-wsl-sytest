RESULT_POINT_LIST

The RESULT_POINT_LIST is a container class representing an array of result points similar to the ARRAY_I or ARRAY_D classes.

One RESULT_POINT_LIST object represents a number of results, not necessarily in a continuous range. To specify a continuous range you need two RESULT_POINT objects.

It allows handling a set of RESULT_POINTs at once. In the result retrieval API the RESULT_POINT_LIST class is used mainly as an input parameter for some accessor functions, where it refers to specific results for which some information should be accessed.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ResultPoint.h.

operator[]

const RESULT_POINT& operator[](const INT index) const;

Returns a const reference to the RESULT_POINT object at the position specified by "index". The "index" has to be in the range 0 .. size() -1. Otherwise an exception is thrown. This operator can only be used for read access to the elements of the RESULT_POINT_LIST. Write access is not supported. For writing in the RESULT_POINT_LIST the add() member functions should be used.
