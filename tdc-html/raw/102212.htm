Perspectives

A perspective defines the initial set and layout of views in the work center window. Each perspective provides a set of functionality aimed at accomplishing a specific type of task. For example, the Design perspective combines views that you use while editing SmarTest setup data, while the Debug perspective contains the views that you use while debugging test programs. As you work in the work center, you will probably switch perspectives frequently.

Perspectives control what appears in certain views. You can change the views to customize a perspective. You can save a perspective that you build, making your own custom perspective that you can open again later.

The SmarTest work center contains several predefined perspectives (see Opening a perspective). Each perspective provides a set of functionality aimed at accomplishing a specific type of task. Additional perspectives can be defined by the user.
