Topic 118949

Creating TMLimits test tables

TMLimit test tables for storing test numbers, limits, and other test-related information can be created in various ways.

About this task

Perform this task whenever you want to create a new TMLimits test table.

(For information on modifying TMLimits tables, see Editing TMLimits test tables. For creating other kinds of test tables, see Editing test tables.)

Procedure

  1. Load the testflow for which you want to create a test table.
  2. In the Test Program Explorer, right-click the <Test Table> entry and choose New from the shortcut menu.

    A Save dialog is displayed.

  3. Enter a name for the new test table, choose a location, and click OK.

    The name of the test table appears in the Test Program Explorer.

    The created file already contains two Header rows: The first header row contains the names of the columns. The second row contains the test mode assigned to each column.

  4. Right-click the test table in the Test Program Explorer and choose Open from the shortcut menu.

    The test table is displayed in the Test table editor. It contains the values that have been set for the testflow.

  5. Edit the values in the table as needed.

    To edit the value in a cell, double-click it.

    If desired, you can add new rows or columns. For a description of the standard columns, see Structure of a TMLimits CSV file. To add a test mode row (if one is not present), add an empty row at the top and enter "Test mode" (without the quotes, case matters) in the first cell.

    For a description of generating test numbers, see Generating test numbers from the SmarTest GUI.

  6. Right-click the test table in the Test Program Explorer and choose Save from the shortcut menu.

    The standard location for TMLimits test tables is in the testtable subdirectory of the device directory.

    Note You can create TMLimits test tables from a test method or using an external editor by creating general test tables, as described in Creating test tables, and making sure that these tables conform to the specifications for TMLimits tables, as described in Structure of a TMLimits CSV file.

Results

The new TMLimits test table is saved as a file on disk.
