Switching between TML versions

The switch version tool allows you to switch between different versions of test method libraries (TML) installed on your system controller.

TML is named as tml_x.y.z_r.s.t, where x.y.z is the SmarTest version number, r.s.t is the TML version number. This means this TML version r.s.t is for SmarTest x.y.z. For example, tml_6.5.4_2.1.0 means TML 2.1.0 for SmarTest 6.5.4. You can only use it for SmarTest 6.5.4. For MTP, see Switching to a different MTP version.

To select a SmarTest version or a version of SmarTest together with a TML version, you can either run switch_version with the dedicated versions as options, or run it without any options to show a list of the installed versions, see Switching between TML versions.

Prerequisites

Note This topic is applicable to SmarTest 7 only.
  • Make sure your SmarTest installation is version 6.5.4 or later, but excluding SmarTest 8.x.
  • Several versions of SmarTest or MTP are installed
  • The software is not running

Syntax

/opt/hp93000/soc_common/bin/switch_version <valid software version> [-tml <valid tml_version>]

Parameters

valid software version
  • SmarTest release:

    soc64_<release number>

  • MTP release:

    mts-<release number> or

    mts-plus-<release number>

tml_version

TML version:

tml64_<SmarTest release number>_<TML release number>

Errors

If switch_version detects any shared memory, semaphores, or message queues left over by other users and they contain 0x93000 or 0x0a930 it shows a pop-up window with the following message:

WARNING: IPC resources of user 'userName' found. Do you want to delete it?
0) No
1) Yes
Enter 0 or 1

1

Cleans up and shows the message

WARNING: IPC resources of user 'userName' have been deleted.

0

Does not clean up and shows the message

WARNING: IPC resources of user 'userName' not deleted.

Example

To switch to SmarTest release 7.2.0 and a compatible test method library, type:

switch_version soc64_7.2.0 -tml tml64_7.2.0_2.1.0
