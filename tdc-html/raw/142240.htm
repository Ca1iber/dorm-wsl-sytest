CCTsetConcurrent

This API allows the user to control the execution mode of the test suite or the CCT group, a global test flow parameter is used in the test method.

The CCT test method executes the test suite in serial as default, for concurrent execution you can use the CCTsetConcurrent(). The API should be called inside the init() function.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

void CCTsetConcurrent(const int concurrent);
Parameter

Parameter

Description

concurrent

For serial execution, 0 is used. This is the Default.

For concurrent execution, 1 is used.

List of parameters

There are no parameters.

Return value

There is no return value.

Example

init()

{

CCTsetConcurrent(1); //Set to concurrent mode

}

Functional changes

  1. Introduced in SmarTest 7.2.1
