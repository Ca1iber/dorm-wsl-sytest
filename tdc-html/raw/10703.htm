Available functions for FreqList and PowerList

Equation

x1 x2 x3.......xn (separated by spaces)

x1, x2, x3,......xn (are double values)

For example:

DDEF "A",SET,"Equation","0.1 0.2 0.3"

Therefore, list A is 0.1 0.2 0.3

Loop(Start, End, Count)

Start is the first element. It is a double value. End is the last element. It is a double value. Count is the number of elements. It is an integer.

The interval between elements is constant. For example:

DDEF "A",SET,"Equation","Loop(1e9,5e9,5)"

List A is 1e9 2e9 3e9 4e9 5e9.

Step(From,To,Increment)

From is the first element. It is a double value. Increment is the interval between elements. It is a double value. To is the limit of the last element. It is a double value.

If To is greater than From, the last element is less than, or equal to, To.

If To is less than From, the last element is greater than, or equal to, To.

If To is equal to From, or the interval equals 0, the list contains only the first element. For example:

DDEF "A",SET,"Equation""Step(1e9,2e9,0.5e9)"

List A is 1e9 1.5e9 and 2e9

DDEF "B",SET,"Equation","Step(3e9,0.5e9,1e9)"

List B is 3e9 2e9 1e9

Sublist(List,From,To)

List is the name of an existing list, as a string. From and To are double values. A list defined by this function will consist of elements, from the existing list, which are greater than, or equal to, From and less than, or equal to, To. For example:

DDEF "A",SET,"Equation"0.5,0.55,0.7,0.85
DDEF "B",SET,"Equation","Sublist("A",0.54,0.75)

List B is 0.55 and 0.7

Intersect(List1,List2)

List 1 and List 2 are names of two existing lists. A list defined by this function will consist of elements that exist in both List 1 and List 2.

If list A is 0.3, 0.4, and 0.5, list B is 0.4, 0.5, and 0.6 and list C is defined as:

DDEF "C",SET,"Equation","Intersect("A","B")"

then list C will be 0.4 and 0.5.

Union(List1,List2)

List 1 and List 2 are names of two existing lists. A list defined by this function will consist of all elements of List 1 and List 2.

If list A is 0.3, 0.4, and 0.5, list B is 0.4, 0.5, and 0.6, and list C is defined as:

DDEF "C",SET,"Equation","Union("A","B")"

then list C will be 0.3, 0.4, 0.5, and 0.6.

AscendingSort(List)

List is the name of an existing list. A list defined by this function will consist of all elements from the existing list, sorted in the ascending order.

If list A is 0.4, 0.3, 0.2, 0.5, 0.45, and 0.7, and list B is defined as:

DDEF "B",SET,"Equation",AscendingSort("A")

then list B will be 0.2, 0.3, 0.4, 0.45, 0.5, and 0.7.

Note For ease in programming, you can use the abbreviation Asort(List) or Sort(List) for AscendingSort(List).

DescendingSort(List)

Similar to the AscendingSort, but in the descending order.

If list A is 0.4, 0.3, 0.2, 0.5, 0.45, and 0.7, and list B is defined as:

DDEF "B",SET,"Equation",DescendingSort("A")

then list B will be 0.7, 0.5, 0.45, 0.4, 0.3, and 0.2.

Note For ease in programming, you can use the abbreviation Dsort(List) for DescendingSort(List).
