rdi.tmu().measMode()

Sets the measurement mode for the time measurement unit.

This function is only for Smart Scale digital pins. The function can be used only in the pattern‑based mode.

Syntax

Syntax for digital pins

tmuBase& measMode(TA::TMU_EDGE_MODE digital_measMode);

Syntax for DC Scale pins in the PMU operating mode:

tmuBase& measMode(TA::TMU_MEAS_MODE dcScale_measMode);
Parameters
Parameter Description
digital_measMode Defines the TMU measurement mode for:
  • Smart Scale digital pins
  • DC Scale pins in the Digital I/O operating mode
For the available options, refer to table Available options of parameter: digital_measMode below.
dcScale_measMode Defines the TMU measurement mode for: DC Scale pins in the PMU operating mode
Available options of parameter: digital_measMode
Option Description
TA::RISE One edge type to trigger the event, the rising Edge.
TA::FALL One edge type to trigger the event, the falling Edge.
TA::RISE_FALL One edge type to trigger the event, the alternate rising and falling edges. This option is used for pulse and jitter measurements.

In this case, the prescaler must be set to a value > 1 and < 17. Moreover, if an event discard is specified, it must be even (including 0). For conceptual information about the operation mode of the TMU with this option, see example "Pulse width measurement" in TMU per Pin overview.

Note The RISE_FALL mode of the digital TMU requires clean and sharp edges of the signal. Otherwise more than one sample might be recorded from one edge.

Return Value

A reference to the tmuBase object.

Example

RDI_BEGIN();

    rdi.tmu().pin("PS1600_1")
            .vth(1.0 V).samples(5).measMode(TA::RISE).execute();

    rdi.tmu().pin("PVI8_PMU_1")
            .measMode(TA::RISE_TIME)
            .connectMode(TA::HIGH_BW)
            .vth(1.0 V,2.0 V).samples(50).execute();

    rdi.wait(100 us);

RDI_END();
