Re-hosting FlexNet Embedded licenses

It is possible to move licenses between FlexNet Embedded license servers.

Procedure

  1. Go to the Advantest License Portal: https://license.advantest.com/ and login.
  2. Go to the License Management tab.
  3. In the "Re-host Licenses" section, select Re-host Licenses.
  4. Select one of the following options (re-host based upon the license server or based upon an entitlement):
    • By license server - a list of license servers IDs are displayed
    • By entitlement - a list of entitlement IDs are displayed
  5. Select a license server or entitlement as appropriate and click Continue.
  6. Enter the count (number of licenses that you want to re-host) and click Continue.

    Re-host everything - selects all available licenses.

    Reset - reverts the selections to the original values on the initial license server.

  7. Review the re-hosting summary.
  8. When you are sure that the information has been entered correctly, click Apply License Count Changes.

    The Download license files page is displayed.

    If your license servers are connected to the internet, onlineThe selected licenses are re-hosted on the specified target license server.

  9. If your license servers are connected to the internet, perform the command sync-fne-server.

    If the license servers are not connected to the internet, download or email the license and manually install the licenses onto the replacement license server.

  10. If the license servers are connected to the internet, in the Removal Confirmation dialog box, click Continue re-hosting.

    If the license servers are not connected to the internet, click Upload.

  11. Go to the License Managementtab and in the "Re-host Licenses" section, select Upload Removal Confirmation File.

    Select Upload and specify the Removal Confirmation File location.

Functional changes

  1. Introduced in SmarTest 8.1.4
