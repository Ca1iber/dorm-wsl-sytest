DSP_POL_RECT

This API converts polar coordinate data to rectangular coordinate data.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_POL_RECT(ARRAY_D& rad, ARRAY_D& arg, 
             ARRAY_COMPLEX& result);
DSP_POL_RECT(DOUBLE *rad, DOUBLE *arg, 
             COMPLEX *result, INT size);
Parameters

I/O

Parameter

Description / Range

I

rad

Source array, which contains the radius data

I

arg

Source array, which contains the angle data

Unit: radian

O

result

Result array in which to store the rectangular coordinate data

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of rad)

size ≤ (size of arg)

size ≤ (size of result)

Example

DOUBLE    phase[256], amplitude[256];
COMPLEX   result[256];
      .
      .
DSP_POL_RECT(amplitude, phase, result, 256);

DSP_POL_RECT converts amplitude and phase from polar coordinate data to rectangular coordinate data, then returns the results to result .
