CHECK Statement Options

The "CHECK all" line has the effect that all available consistency checks are performed. If you do not want all checks performed, you can switch on the individual checks for the edge delays by specifying one of the following keywords after CHECK:

1period, 2period, 10period,

1period_drv, 2period_drv, 10period_drv,

1period_rcv, 2period_rcv, 10period_rcv.

The individual checks for the edge order are switched on by specifying one of the following keywords:

edgeorder, edgeorder_drv, edgeorder_tri, edgeorder_win

The edgeorder keyword is equivalent to the combination of the other three keywords. What is checked is if the edges of the respective type are ordered in in all waveform definitions of the specified wavetable by increasing delay for all timing sets of the specified equation set. This requirement would be violated, for example, if the wavetable for one drive pin contained the definition "d1:1 d2:0", and one of the timing sets specified a greater delay for d1 than for d2.

Note that drive actions and tri-state actions are treated as different types. Thus, the waveform definition string "d1:F10 d3:F1N" is compatible with a delay of 4 for d1 and a delay of 2 for d3.

If you want to suppress all checks, specify CHECK NONE. Note, however, that this is not allowed for the Pin Scale Digital Cards
