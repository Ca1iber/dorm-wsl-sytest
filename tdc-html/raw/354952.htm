Connecting to a virtual machine via VNC

Connect to the virtual machine through PuTTY and access its desktop in a VNC client.

About this task

VNC Viewer is used as the VNC client in this procedure. You can use other VNC clients as you prefer. For details on using other VNC clients, see their documentation.

Before you begin

Set up the VNC port of the virtual machine.

Procedure

  1. Open PuTTY.
  2. In the Category field, select Session.
  3. In the Saved Sessions field, double-click the name of the session which was created in Setting up a VNC connection.

    A terminal window opens.

  4. Enter the user name and press Enter.
  5. Open VNC Viewer.
    Note Ensure PuTTY is connected.
  6. Enter the port address 127.0.0.1:port_number.

    The port number is 5901 for port 1, 5902 for port 2, and 5903 for port 3.

    The Authentication window opens.

  7. Enter the password you set when you set up the VNC port.
  8. Click OK.

Results

The desktop of the virtual machine is displayed in VNC Viewer.
