Topic 119603

Editing test numbers

Procedure

  1. Load the test table in the Test Program Explorer.
  2. Open the test table.

    The table is displayed in the test table editor.

  3. Right-click a cell in the Test Number column and open the Test Numbering preferences.
  4. Adjust the settings when needed and click OK.
  5. Select all cells in the Test Number column that you want to re-number.
  6. Right-click a selected cell and choose Generate Test Numbers.

    New test numbers are generated in all selected cells.

  7. Manually adjust the numbers if desired.
  8. Save the changes using the shortcut menu in the Test Program Explorer.
  9. Run the testflow to check for collisions.

    Any collisions are marked with a dotted red border in the test table:

  10. If there are collisions, adjust the loop increments to eliminate them.
