Topic 351492

Register write

Register write is to write data to a register or dynamically write data to registers.

Bit field write is applicable only when register definitions (SVD) are available and converted. When bit field write is used, RA_MODE (RA::LEARNING | RA::PRODUCTION) must be configured and Check mode is optional.

Examples

Example 1

Register write

RA_SET_MODE(RA::LEARNING);

ON_FIRST_INVOCATION_BEGIN();
RDI_BEGIN();
  // Entire Register Write
  reg.PERIPHERAL0().REGISTER0().setValue(0x55).write();
  // Bit Field Write, RMW
  reg.PERIPHERAL0().REGISTER1().setField_HiClm(1).write();
  
  // Use this command when register structure is unknown.
  // RA_WRITE(0x1234, 0x55);

RDI_END();
ON_FIRST_INVOCATION_END();

Example 2

Write runtime data (write dynamic)
MultiSite<ULONG64> dynData;

FOR_EACH_SITE_BEGIN();
  int siteIndex = CURRENT_SITE_NUMBER() - 1;
  dynData[siteIndex] = rand() % 256;
FOR_EACH_SITE_END();

// Set dynamic data
RA_SET_DYNAMIC_DATA("DYN_ID",dynData,[RA::VECD|RA::VTT]); // Patch mode; VECD by default

RDI_BEGIN();
  // Use the same ID to address to dynamic data
  reg.PERIPHERAL0().REGISTER0().writeDynamic("DYN_ID");
  
  // or 
  // RA_WRITE_DYNAMIC("DYN_ID", 0x1234);

RDI_END();

Functional changes

  1. Introduced in SmartRDI 7.6.0
