Topic 79167

License number error

A license number error indicates that not enough licenses are available for the requested configuration and capability. The error message displays the number of required, available, and missing licenses.

About this task

License availability may be affected by several factors:

  • Licenses have been checked out for use elsewhere.
  • Not enough licenses were purchased for your addressed tests.
  • The license server is not running.
  • A problem with the network connection to the license server.

When a license number error occurs the license check-out process for that type is canceled. All licenses of that type, for example, all speed licenses, are returned to the server, and the system starts with reduced capabilities.

Procedure

  1. To correct a license number error do one of the following:
  2. Edit the model license to scale a more limited version of the test, if appropriate. The error message says exactly how many licenses are available for use.
  3. Wait until sufficient licenses are freed up and available from the license server.
  4. Purchase additional licenses to meet the requirements of the current test.
  5. In case of a server or network problem, focus on fixing the hardware or connection problem.

Example

Sample license number error for an SOC device:

   License type                | Required |  Acquired  | Missing    
-------------------------------+----------+------------+------------
 Digital_E7945_0_50Mbps        |    32    |   14(  7)  |   18       
 Digital_E7945_50_100Mbps      |    32    |   14(  7)  |   18       
 Digital_Shared_mem_32_64MB    |    32    |   14(  0)  |   18

The figure inside the brackets, in the Acquired column, indicate the licenses acquired through device specific licensing. If Device specific licensing (DSL) is not enabled, only the first figure without brackets is shown. The figure in the Missing column indicates the number of missing standard InstaPin licenses.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.1: Report window lists the number of licenses acquired through device specific licensing (DSL)
