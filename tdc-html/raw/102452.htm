Topic 102452

DMM section

In the DMM section of the model file you specify digital multimeters, as they are required for focus calibration.

Note The DMM section is supported only in the model file and not in the device license file.

Syntax

DMM
<unit>: <cardcage>,<type>,<address>

Parameters

<unit>

The unit number (1: ... 8:) is the unique identifier of the digital multimeter (DMM) definition.

cardcage

Specifies the card cage to which the digital multimeter is connected. Only one instrument can be connected per card cage.

type

Describes the digital multimeter type. For example, type=HP3458A specifies the Agilent 3458A Digital Multimeter.

address

Configures the multimeters GPIB address, which is used for the communication with the multimeter. The GPIB interface must be defined in the GLOBAL section.

Example

DMM
  1: cardcage=1,type=HP3458A,address=18
  2: cardcage=2,type=HP3458A,address=19
  3: cardcage=3,type=HP3458A,address=24

Functional changes

  1. Introduced before SmarTest 6.3.2
