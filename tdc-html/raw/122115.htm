Topic 122115

Situation analysis

There are several scenarios where you may want to optimize the test time of your testflow. In all such cases you need to start with an analysis of the situation.

About this task

This task will tell you what are the key facts you need to know prior to beginning to work on the test program or on the testflow.

Before you begin

There are hard and soft facts which influence the project. You will concentrate on the hard facts. Soft facts are team, relationship etc.

Make sure you fill in the following tables with relevant information. In some cases, you will acknowledge that you have the information available instead of entering it in the table.

Procedure

  1. Ensure that you know the following data or file names about the available V93000 test system:
    • Tester configuration
    • Model file
    • License
    • Operating system
  2. System controller model
    • SmarTest version
  3. Make sure you know the following facts about the application:
    • Application focus
    • Multisite or single-site
    • Purpose: wafer, final, qualification, ...
    • Engineering or production
  4. Make sure you have the following tools at hand and you know how to use them:
    • V93000 Extract TestTime:

      This GUI Windows based tool can read two test time data logs, generated with debug mode 3, and compare them with each other.

      It is a very useful tool to investigate and compare any test time difference between software or test program versions. The output can also be saved to a comma separated file.

    • Flow Data Editor:

      Standard SmarTest tool, now with test time data.

    • testflow_debug3_analyzer.pl

      Parse one or two V93000 debug 3 log files. Report on execution time for each test suite and give totals. If two files are given, show test time differences

    • TTT:

      This tool automates the process of test time creation by executing the flow in operator mode and collecting a summary of test time.

  5. Analyze the above collected information and make a realistic statement about the target test time.
