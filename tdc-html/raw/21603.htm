Topic 21603

Flag priority

There are two rules:

  • Should a pass level and fail level in the testflow flags be in conflict, the pass level has priority.
  • The individual test suite flags, Set pass, Set fail and Bypass have priority over the global testflow flags.

Example

  1. If you set the pass level to 4 and the fail level to 2, then all test suites with test levels 2 and 3 will be set to fail, and all test suites with test levels 4 and above will be set to pass.
  2. If you set the test level of an individual test suite to 1 and then the Set pass level testflow flag to 1, this test suite will be set to pass each time it is executed. If, however, you activate the individual test suite flag Set fail, the test suite will always be set to fail, irrespective of its own test level or the testflow flags.
