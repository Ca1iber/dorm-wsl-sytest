DIGITAL_WAVEFORM.sampleStart()

This function specifies the sampling point offset to start data retrieval in 1 UI (Unit Interval = 1 Bit time). The default value is 0, which means the compare edge position defined in the timing setup file.

Syntax

DIGITAL_WAVEFORM& sampleStart(INT sample_offset);
Parameter

sample_offset

The sampling point offset to start the data retrieval in 1 UI. It is an integer. The actual sampling time is calculated as:

actual timing = compare_edge + sample_offset*timing_resolution
