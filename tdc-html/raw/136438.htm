Topic 136438

Detail data views

Subtopics

  1. Raw data views
  2. Stream data view

The detail data section of the Result perspective contains views that display the records from the loaded data logs or the system data log stream that are summarized in the selected row of a summary view. There are different vies for records from data logs and from the system data log stream:

  • Raw data views
  • Stream data view
