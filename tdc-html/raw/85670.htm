Defining the device license file to be used

Licensing per device provides several options to define or change the device license file to be used. The following hierarchy applies:

  1. Environment variable
  2. Workorder Manager
  3. Change Device

Change device

To define the device license file in the Change Device dialog:

  1. In the Change Device dialog click Next. The Edit Device dialog opens.
  2. Open the Licensing file drop-down list and select the device license file.
  3. To save the modification click Finish. This saves the device license file name to the specifying "licensing_file" keywords in the ".technology" file. See also Editing technology data.

The possibility to change the device license file allows several test scenarios for the same device by using different license files.

Workorder Manager and environment variable

Alternatively, in production environment, you can specify the licensing file within the Workorder Manager dialog.

CAUTION Be aware of hierarchy!

When applying the V93000_LICENSING variable you should be aware of the hierarchy between the setting of the licensing environment variable and modifications that may be done in the "Edit Device" user interface dialog.

If the V93000_LICENSING variable is set, the entry in the Edit Device dialog is still displayed and can be modified. But the content of the V93000_LICENSING environment variable has higher priority than the modifications in a user interface dialog and the configuration stored in the ".technology" file.

In this case a message appears in the Edit Device dialog saying that the selection will be ignored and that the licensing file specified in V93000_LICENSING will be used.

To verify which is the current device license file, check the report window.

Every time a device license file or model file is evaluated and applied, the following message appears in the report window: 

Dev_license_file: <file name>.

If the licensing-per-device file is specified via the V93000_LICENSING environment variable, the message is extended accordingly and reads 

Dev_license_file: <file name> specified in V93000_LICENSING.
