This section describes the process of setting up:

  • A memory device for testing
  • The Memtest test methods to execute the memory test

Preliminary steps

Before you set up a Memtest test method for use with a new memory device, you need to set up:

  • Vectors
  • Reconstruction information
  • Address scrambling

After the above preliminary steps, follow the procedure below:

  1. Add a test suite to the test flow containing a test method.
  2. Set the test suite flags depending on your use case.
  3. Set the test method parameter depending on your use case.
  4. Execute the test suite or test flow.
    Note This step applies only to debugging on immediate execution and for failure analysis with delayed execution.
  5. Analyze the data using the BFM Viewer.
    Note This step applies only to debugging on immediate execution and for failure analysis with delayed execution.

Functional changes
