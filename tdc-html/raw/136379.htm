Creating a customized shmoo test method

You can create your own shmoo test method based on a customized shmoo test method template.

About this task

You can create your own shmoo test method when the ac_tml.AcTest.Shmoo test method cannot meet your needs. For example, if you want device training before a shmoo, which is normally done with two test suites, you can do it with one test suite by creating a customized shmoo test method.

Before you begin

Make sure:

  • The ac_tml test method library is imported. Refer to Using the predefined universal Test Method Libraries for how to import the ac_tml test method library.

Procedure

  1. In the Project Explorer view of the C++ perspective, right-click the ac_tml test method project and select New > Test Method Class.

    The Create a new TestMethod Class wizard opens.

  2. In the Templates field, select Customized shmoo test method class.
  3. In the Class Name field, enter a name for your shmoo test method.
  4. Complete the other setups as described in How to create a universal test method class and click Finish.
    • A new test method file opens.
    • The new file is added to the ac_tml project.
    • If you have already added parameters in step 4, you will see these parameters in the addParameters() function of the new file.
  5. In the new test method file, program the functions which are provided with the customized shmoo test method template.
  6. Build the project.

Results

A new shmoo test method is created with the customized parameters and functions and the parameters of the ac_tml.AcTest.Shmoo.

What to do next

Use this test method to create a shmoo test with the Shmoo Tool, or to create a shmoo test suite in a testflow.
