TIMING_OFFSET_SEARCH_PINS.TimingOffsetResultCopy()

This function copies the timing offsets from one timing set to another timing set.

Syntax

void TimingOffsetResultCopy(TIMING_OFFSET_SEARCH::TimingSetSelector& source,
                            TIMING_OFFSET_SEARCH::TimingSetSelector& dest);
Parameters

source

The timing set to copy from.

dest

The timing set to copy to.

Functional changes

  1. Introduced in SmarTest 7.0.1
