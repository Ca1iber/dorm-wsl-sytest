Topic 95812

ChangeDevice

This remote control command sets the designated device for a SmarTest session. The operation of changing device usually contains a set of procedures (like re-read model file, check the license etc.), so it will take some time.

When starting to change the device, the event DEVICE_CHANGE_STARTED is notified. When the device is successfully changed, the event DEVICE_CHANGE_COMPLETED is notified. To execute this command, make sure that SmarTest session is running and no other change device is in operation.

SUCCESS will be returned if the command is successfully issued. Otherwise, an error object indicating the error code, description and severity will be returned.

Code

Typical Description

Severity

PARAMETER_EXCEPTION
  • The value of the parameter "DEVICE_PATH" is empty.
  • The value of the parameter "DEVICE_NAME" is empty.

RECOVERABLE

FILE_NOT_FOUND
  • The device path "XXX" does not exist.
  • There is no device name "XXX".

RECOVERABLE

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.

RECOVERABLE

Constraints

The SmarTest session should be running. There is no other changing device operation in execution.

Parameters

I/O

Parameter

Description

I

SESSION_ID

The ID of the SmarTest session to work with.

I

DEVICE_PATH

The device path to set.

I

DEVICE_NAME

The device name to set.

I

DEVICE_LICENSE (optional)

A device license file being used for changing the device. It supports either the absolute path starting with slash("/"), or the relative path that is relative to <device-directory>/license/.

The specified device license file has a higher priority than the device .technology file but a lower priority than the V93000_LICENSING environmental variable.

Prototype

ParamList cmdParams;
string sessionId;
Status command("ChangeDevice", cmdParams, sessionId);

Example

ParamList cmdParams;
string sessionId;
cmdParams["DEVICE_PATH"] = "/home/demo/devices/";
cmdParams["DEVICE_NAME"] = "74ACT299";
cmdParams["DEVICE_LICENSE"] = "74ACT299.license";

Status retVal = command("ChangeDevice", cmdParams, sessionId);
if(!retVal.isError())
{
printf("Device is changed to s%\n", cmdParams["DEVICE_NAME"]);
}
else
{
printf("error(code = d%, description = s%)",
        retVal.code(),
        retVal.text();
}
