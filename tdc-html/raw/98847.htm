VDCN - (Vector Device Cycle Name)

The VDCN (Vector Device Cycle Name) command downloads the physical waveform DC/DC power units resulting from the default data parameters of the specified device cycle into the vector areas of the specified pins. The default data parameters are F00 for the drive data parameters, and FX for the expected data parameters. VDCN uses the base waveform set / wavetable to translate device cycle names and data parameters into physical waveform DC/DC power units.

If you specify FDC for the device cycle name, the first device cycle name in the device cycle table is chosen for every specified pin.

If for some pins in pinlist, the default parameters cannot be set, an error is reported in the report window, and the affected pins are left unchanged.

If for some pins in the pinlist, the length of the referenced device cycle is not equal to the length parameter length, an error is reported in the report window and the affected pins are left unchanged.

The VDCN command can only be issued on a label that has been selected with TSTL, TSTL? - (TeST Label).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

VDCN {vec_No}, {"dev_cyc_name"}, {dev_cyc_len}, {repeat_count}, {(pinlist)}

Parameters

vec_No

A logical vector number of the selected label. Logical vector numbers count the active vectors of one label. The first active vector of a label has the logical vector number 0 (zero).

dev_cyc_name

The device cycle name. Enter a string of up to 16 alphanumeric characters (upper or lower case) enclosed in double quotes.

Alternatively, enter FDC for the first device cycle name in the device cycle table.

dev_cyc_len

Length of the device cycle that is being downloaded.

This is always 1. (For SmarTest 7.10, only 1 waveform per device cycle is possible.)

repeat_count

Determines how many times the device cycle is to be downloaded.

pinlist

The pin name or names for which vectors are to be downloaded. If more than one pin is required, the names must be separated with a comma. The @ character can be used to download to all configured pins.

Application

Download command in Pattern Tool.

Errors

An error is generated if:

  • For some pins in pinlist, the default parameters (F00 for drive and FX for expected data) cannot be set.
  • For some pins in pinlist, the length of the referenced device cycle is not equal to the length parameter length.
  • For some pins in pinlist, no device cycles are specified.
  • The repeat count is out of range.
  • You enter an invalid vector number.
  • The currently specified base waveform set is outside the range of used waveform sets.
  • No label has been activated for editing.
  • The specified device cycle length lies outside the allowed length of 1 to 16 test system cycles.
  • There is insufficient disk space for offline operation.

Example

VDCN 93, "EXAMPL", 1, 15, (@)

This example downloads vector data resulting from the default values for the EXAMPL device cycle to all pins, starting at active vector 93. The download is repeated 15 times.

Functional changes

  1. Introduced before SmarTest 6.3.2
