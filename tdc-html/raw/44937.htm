Determine First Use of a User Procedure

This function can be used during testing of multiple sites. In order to write user procedures that operate in parallel on all sites, a user procedure must be able to find out if the current call to the user procedure was the first one in the context of a testsuite execution. It could then perform all operations on the first call and only return values when called again.

This function returns a 1 the first time that the user procedure makes a call to any site within the testsuite. Any subsequent calls of the user procedure within the testsuite return a 0.

long IsFirstInvokation(long *is_first)
