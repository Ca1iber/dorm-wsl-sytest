Logging Array Data with Captions

To log array data with captions, the data must be provided as a class object of the WAVE_LOG API. Add the data and captions to be logged into a class object of the WAVE_LOG API as follows:

ARRAY_D wave_array;
   :
WAVE_LOG raw_wave(wave_array);
raw_wave.xAxis(0.0, 1023.0);
raw_wave.xTitle("Sample Point");
raw_wave.yTitle("Output Voltage");
raw_wave.yUnit("V");
PUT_DATALOG("Aout", "THD", raw_wave);

In this example, the WAVE_LOG API creates an object raw_wave for the double type of array wave_array. Then, the member functions set up the captions as follows:

X-axis data: Linearly scaled valued from 0 to 1023

X-axis Title: Sample Point

Y-axis data: wave_array (double array)

Y-axis Title: Output Voltage

Y-axis Unit: V
