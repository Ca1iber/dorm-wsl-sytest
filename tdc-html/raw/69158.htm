Communication between Equipment and System controller

Subtopics

  1. Communication with a GPIO interface
  2. Communication with a GPIB interface
  3. How the prober/handler driver functions

Advantest supports various interfaces between the equipment and system controller. GPIO and GPIB and LAN (TCP/IP) interfaces are currently supported.

Functional changes

  1. Introduced in SmarTest 7.0.4
  2. SmarTest 7.2.3: LAN supported
