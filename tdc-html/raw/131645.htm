SHARING_CONFIGURATION.isFXDLIgnorePin()

The isFXDLIgnorePin() member function of SHARING_CONFIGURATION returns "true" if the specified pin is in the ignore list of the fixture delay settings and "false" if it is not.

Syntax

bool isFXDLIgnorePin(const string & pinname) const

Parameter

Description

pinName

The name of a pin for which you want to know whether it is ignored by the fixture delay settings.

Related information

SHARING_CONFIGURATION

Functional changes

  1. Introduced in MTP 3.1.5
