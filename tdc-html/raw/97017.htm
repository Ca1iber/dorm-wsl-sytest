Topic 97017

SESSION_MANAGER_TERMINATED

This asynchronous event indicates that the session manager managing all the Advantest software sessions has been terminated. Typically this event is issued when installing a new SmarTest version or switching the SmarTest version.

Parameters

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session this event belongs to.

O

TIME_STAMP

The time point when this event occurs. It contains two long-type parts: SECONDS and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always SESSION.

O

EVENT_BODY

The event parameters. It contains the following members:

SESSION_STATE

The HVM event type. Here it is always SESSION_MANAGER_TERMINATED.

This parameter is represented by ParamList whose key and value are both sting type.
Note All HVM API clients are expected to be shut down with this event and need to be restarted after version switch.
