Saving shmoo tests in the Shmoo Tool

To save the shmoo tests that have been setup with the Shmoo Tool, use the Save, Save As, Save Result, and Save Result As commands. You will see these commands after you right-click the shmoo tool icon ().

  • Save and Save As: Save only the setups to the current file or to a different file.

    The setups in all shmoo pages will be saved.

  • Save Result and Save Result As: Save both the results and setups to the current file or to a different file.

    The setups and results in all shmoo pages will be saved.
