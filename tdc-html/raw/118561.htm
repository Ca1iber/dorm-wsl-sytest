SharedIDD syntax

The SharedIDD test method is required to test IDD with driver sharing.

To edit the parameters of the SharedIDD test method, click it in the tabular test editor. The parameters are displayed in the Test Suite window and you can edit them there.

Name

Type

Default

Comment

DriverSharing Config File

String

 

Name of sharing configuration file used.

The file must be located in the configuration subdirectory of the current device directory.

See Creating a sharing configuration file for details.

VDD

PinString

 

Name of the power supply pin

This parameter is ignored for DPS-shared load boards for which there is a utility_control section in the Sharing configuration file.

VDDQ

PinString

 

Name of the DQ power supply pin

This parameter is ignored for DPS-shared load boards for which there is a utility_control section in the Sharing configuration file.

RESETn

PinString

 

Name of the reset pin.

This is an optional parameter.

Wait Time

Double

 

The time to wait before taking a measurement, in milliseconds (ms).

This value must be greater than zero.

Utility control

The keywords for specifying the utility line settings for SharedIDD in the utility control section of the sharing configuration file are idd and iddq.

For information on the syntax, see Sharing configuration file.
