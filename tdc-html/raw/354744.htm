Test program resource profiler

Subtopics

  1. Executing the test program resource profiler
  2. Test program resource profiler report
  3. Report for the required resources
  4. Report for the resource used when generating reports
  5. Vector memory usage report

The test program resource profiler generates a report for the hardware resources required by your test program, the hardware resources currently used with your program when generating the report, and the vector memory usage report.

Three analyzing functions are included in the test program resource profiler:
  • Analyze required test resources: Summarizes the minimally required tester resources of the current test program and lists the required licenses. See Report for the required resources for details.
  • Analyze resources used to generate the report: Summarizes the current workstation and tester resources when generating this report. See Report for the resource used when generating reports for details.
  • Analyze vector memory usage per signal and per pool: Summarizes the vector memory usage from the signal and memory pool perspective with bar graphs and tables. See Vector memory usage report for details.

To execute the analysis, perform the steps described in Executing the test program resource profiler.

Functional changes
