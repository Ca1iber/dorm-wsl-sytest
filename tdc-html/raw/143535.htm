Topic 143535

iForceRange()

Specifies the range of forcing current for DC Scale pins.

  • XPS256 pins:

    The function can be used in the code‑based mode and in the pattern‑based mode. The pin must not be disconnected for changing the current force range.

  • Other DC Scale pins:

    The function can be used only in the code‑based mode together with the iForce() function. Disconnect the pin before changing the range of the forcing current.

Range programming sequence (XPS256)

DC Scale XPS256 pins can change the force or clamp range in connected mode. The programmed force or clamp value must always match to the selected range. Violating this rule may lead to a range overflow warning.

The behavior of SmartRDI differs for the code‑based mode and the pattern‑based mode:

  • Code-based mode:

    The programmed sequence is always defined and applied as complete setup. The test processor of XPS256 pins will automatically select the correct sequence to avoid range overflow warnings. No special sequence must be considered in code‑based mode.

  • Pattern-based mode:

    The programmed value and the range that are defined within the same RDI command (rdi()...execute()) are set by separate patterns of the automatically created pattern burst. Regardless of the programmed sequence within the RDI command, SmartRDI always executes first the pattern that sets the range, followed by the pattern that sets the value.

    For the pattern‑based mode, we therefore recommend carefully checking the sequence for changing the force value, the clamp value, or the related range of an XPS256 pin. For the correct sequence, the settings must be programmed in separate RDI commands.

    The correct sequence depends on the currently set range and the new force or clamp value to be set:

    • The force or clamp value of an XPS256 pin is to be increased:
      1. The new range that matches to the new force or clamp value must be programmed first and must be applied using function execute().
      2. The new force or clamp value can be set now using a new RDI command.
    • The range of an XPS256 pin is to be decreased:
      1. The new force or clamp value that matches to the new range must be programmed first and must be applied using function execute().
      2. The new range can be set now using a new RDI command.

    Both steps of the sequence are to be programmed in separate RDI commands (rdi()...execute()). Using separate RDI commands ensures that the patterns are started in the programmed order.

Syntax

dcBase& iForceRange(double dIForceRange);
dcBase& iForceRange(string SpecName,TA::LEVEL_SPEC);
Parameter
Parameter Description
dIForceRange

The range of the forcing current.
SpecName The spec variable name in Level setup.
Return Value
A reference to the dcBase object.

Application note

Programming both the force and the measurement range of XPS256

XPS256 does not have different force and measurement ranges.

Thus using iForceRange() and iMeasRange() within one SmartRDI command that is terminated by execute() will not result in different ranges, but the current measurement range will finally be active. The applied sequence is

  1. Set current force range (active for a short time)
  2. Set current measurement range (overrides the current force range)

Examples

Example 1: Set force range in code‑based mode

rdi.dc().pin("pin1").iForceRange(10 mA).iForce(1 mA).execute();

Example 2: Change range of AVI64 without disconnecting

For an example that shows the correct sequence of programming the force or clamp value and the force or clamp range in pattern‑based mode, refer to AVI64 Use Case - Change range without disconnecting in the SmarTest 7.6.x documentation.
