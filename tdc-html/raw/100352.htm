Topic 100352

Managing the universal test method libraries

Subtopics

  1. How to install a universal test method library for system wide usage
  2. How to use universal test method libraries under multiple directories
  3. How to call the functions in one test method library from another test method library

If your test method libraries are bug free and ready to use, you can share it with other users of the same SmarTest system. See How to install a universal test method library for system wide usage.

If you have some test method libraries located under different directories, you can use them for one device testing by setting the system environment variable 93000_TM_LIBRARY_PATH. See How to use universal test method libraries under multiple directories.
