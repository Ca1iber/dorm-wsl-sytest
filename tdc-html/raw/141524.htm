MTP_MEMORY_TEST.setRACounting()

Controls whether and when the built-in counting algorithm will accumulate the number of failed cells that are generated during test.

Syntax

MTP_MEMORY_TEST& setRACounting (const MTP::RA_EXECUTE_MODE & mode);
Parameter

Parameter

Description

mode

The default mode is MTP::RA_EXECUTE_ENABLE_ON_CONCURRENT_MODE.

See the available modes in the following table.
Available options of parameter: <mode>

Option

Description

MTP::RA_EXECUTE_DISABLE

Does not accumulate the failed cells.

MTP::RA_EXECUTE_ENABLE_ON_CONCURRENT_MODE (default)

Accumulates the number of failed cells after the execution of every test suite when the fail map is generated.

Return value

There is no return value.

Related information

MTP_MEMORY_TEST.setRAUseCountingResults()

Functional changes

  1. Introduced in MTP 3.2.1
  2. MTP 3.3.2: Obsoletes the MTP::RA_EXECUTE_ENABLE_ON_DELAYED_MODE option for the mode parameter.
