SmartRDI 7.5.0

This section summarizes software changes including new features and enhancements in SmartRDI 7.5.0.

Changes and new features

Category

 Description
General A new testflow variable RDI_CONFIGURE_FILE can specify a customized RDI_Configure file for each testflow. See RDI_Configure file.
Alarm handling for DCVI SmartRDI provides a solution for alarm handling for DCVI to ensure that force voltage or force current on device pins are as correct as expected.

SmartRDI provides alarm checking commands to specify alarm sets, enable or disable alarm checking on pins, and set limit values.

Two keywords are introduced to activate the alarm handling in the RDI_Configure file:
  • ALARM_HANDLING_DCVI_ENABLE: Enable the alarm handling for DCVI.
  • ALARM_HANDLING_DCVI_SETUP_FILE: Specify a path that directs to an alarm setup file which contains the limit setups for handling alarms for DCVI pins.

See SmartRDI: Alarm handling for DCVI for more detailed information.
DC Scale FVI16 card The FVI16 card is a high-current and high-voltage floating VI source that is optimized for a wide range of analog power tests. The card belongs to the DC Scale family and can reside in any channel card slot.
ROUTE Two new functions are introduced in the route() class:
  • rdi.route().enableOnlyActiveSites() enables the utility line and PMUX switch settings on active sites or disables them on inactive sites.
UTIL
  • The keyword UTIL_PADDING_RPTV_FLAT can be added in the RDI_Configure file for defining how many vectors are to be repeated in padding. The default value is 16.
  • Utility control patterns take dvc "0" as 0, dvc "1" as 1, and dvc "Z" as Z in the util() class as in the route() class from this version.
    Note This change may cause a compatibility issue in existing test programs when running in SmartRDI 7.5.0. If util() commands do not work after you have switched to SmartRDI 7.5.0, check the index style.

Supported SmarTest versions

SmartRDI 7.5.0 supports SmarTest 7.5.0.
