d2s_LABEL_END

The d2s_LABEL_END() defines the end of the d2s_LABEL-block.

At d2s_LABEL_END() the bust pattern gets created or executed, depending on the mode the d2s-framework is set to.

Further more the error map is evaluated and read values (per site) are cached in production mode.

Syntax

void d2s_LABEL_END();
