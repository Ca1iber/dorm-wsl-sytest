GIO_ERROR gio_printf ( IDID  id,
char *  pBuffer,
size_t  bufferSize,
const char *  pFormat,
  ... 
)

Send a formatted string to a device or interface.

Attention
Unlike SICL, this function doesn't buffer I/O. The caller must pass a buffer which is large enough to hold the formatted string. The format string will be interpreted according to the rules for printf(3), not according to SICL's formatting rules.
Returns
GIO_ERROR
Return values
GIO_ERR_NO_ERROROperation successfully completed.
otherAn error occurred.
Parameters
idInterface or device ID.
pBufferFormatting buffer.
bufferSizeSize of buffer.
pFormatprintf(3) style format.
