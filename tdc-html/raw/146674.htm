GetTestflowInformation()

Retrieves the testflow information of the specified SmarTest session. The information can only be successfully queried after a testflow is downloaded.

Success will be returned if the command is successfully issued. Otherwise an error object indicating the error code, description and severity will be returned.

code

Typical description

Severity

PARAMETER_EXCEPTION

Testflow is empty.

RECOVERABLE

ILLEGAL_OPERATION

The designated session ID "XXX" does not exist.

RECOVERABLE

Parameters

I/O

Parameter

Description

I

SESSION_ID

The ID of the SmarTest session to query.

O

DEVICE_NAME

The Device Name from the Information page of the Flow Data Editor.

O

DEVICE_VERSION

The Device Version from the Information page of the Flow Data Editor.

O

TEST_DESCRIPTION

The Description from the Information page of the Flow Data Editor.

O

TEST_REVISION

The Test Revision from the Information page of the Flow Data Editor.

Prototype

ParamList qrResults;
string sessionId;
Status query("GetTestflowInformation", qrResults, ParamList(), sessionId);

Example

ParamList qrResults;
Status obj = query("GetTestflowInformation", qrResults, ParamList(), sessionId);
if (obj.success())
{
  cout << "SmarTest session "<<sessionId <<" profile:" <<endl;
  cout <<"DEVICE_VERSION: " << qrResults ["DEVICE_VERSION"] <<endl;
  cout <<"DEVICE_NAME: "<<qrResults["DEVICE_NAME"] <<endl;
  cout <<"TEST_DESCRIPTION: "<<qrResults ["TEST_DESCRIPTION"] <<endl;
  cout <<"TEST_REVISION: "<< qrResults ["TEST_REVISION"] <<endl;
}
else
{
  cout<<"error code= " << obj.code() << endl;
  cout<<"description="<< obj.text() << endl;
}

Functional changes

  1. Introduced in SmarTest 7.2.3
