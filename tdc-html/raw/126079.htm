DSP_RF_NF_GAIN_METHOD()

The function DSP_RF_NF_GAIN_METHOD() extracts the noise based on the gain method.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_RF_NF_GAIN_METHOD(const ARRAY_COMPLEX & cData, const ARRAY_D & noiseParams, const DOUBLE deviceGain_Watts, DOUBLE * noiseFigure_dBm);
DSP_RF_NF_GAIN_METHOD(const ARRAY_COMPLEX & cData, const ARRAY_D & noiseParams, const DOUBLE deviceGain_Watts, const INT site, DOUBLE * noiseFigure_dBm);

Example

//Get MeasParams from a NoiseFigure type of measurement
ARRAY_D noiseParams = MEAS_DEF(measName).getParameters(captureNumber,freqListIndex);
//Get Capture Data from the NoiseFigure measurement.
ARRAY_COMPLEX cData = MEAS_DEF(measName).getComplexWaveform(captureNumber);
// Run the DSP
DOUBLE deviceGain_Watts = 1; // This is in watts, to compute from dB use -> Watts = pow(10.0, (gain_dB)/10.0)
DOUBLE measNF_Gain = 0;
DSP_RF_NF_GAIN_METHOD(cData, noiseParams, deviceGain_Watts, &measNF_Gain);

Functional changes

  1. Introduced in SmarTest 6.5.3
