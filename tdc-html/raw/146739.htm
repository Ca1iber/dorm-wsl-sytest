SmartRDI: DC resource AWG/DGT usage

Subtopics

  1. Using a DC resource as an AWG with SmartRDI
  2. Runtime DC waveform
  3. DC waveforms per site
  4. Using a DC resource as a digitizer with SmartRDI
  5. Using a DC Scale resource as a digitizer while sourcing a waveform on the same pin
  6. Serial/Semi-parallel execution of BADC as digitizer over sites
  7. DC waveform and sampling in parallel
  8. Parallel pulse actions with measurement and sampling

When using a DC resource as an AWG/DGT, SmartRDI supports

  • Using the DC resource as an AWG
  • Using the DC resource as a digitizer
  • Using the DC Scale resource as a digitizer while sourcing a waveform on the same pin

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 2.2.0: Supports using the DC Scale resource as a digitizer while sourcing a waveform on the same pin.
