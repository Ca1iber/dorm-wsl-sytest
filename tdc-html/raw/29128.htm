DSP_POWER_VEC

This API raises the elements of the specified array to the specified power and returns the results to the corresponding elements of result as follows:

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_POWER_VEC(ARRAY_D& src, DOUBLE scaler, 
              ARRAY_D& result);
DSP_POWER_VEC(DOUBLE *src, DOUBLE scaler, 
              DOUBLE *result, INT size);
Parameters

I/O

Parameter

Description / Range

I

src

Source array

I

scaler

Exponent

O

result

Raised results

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src)

size ≤ (size of result)

Example

double array1[50],array2[25];
  .
  .
DSP_POWER_VEC(array1, 2.0, array2, 25);

DSP_POWER_VEC raises the first 25 elements of the array array1 to the power of 2, and returns the results to the corresponding elements of the array array2. Therefore, the elements in the array array2 will be the square of the corresponding elements in the array array1.
