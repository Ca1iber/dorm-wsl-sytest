Notes regarding the Summit configuration files

The driver was tested on a Summit running SW revision 1.7.3. The GPIB interface definition of the Summit is still under development and subject of change. Only a restricted set of commands is used by the driver. This leads to the following limitations:

  • The handler cannot be started or stopped remotely by this handler driver.
  • The handler does not support bin verification mode.
  • Reprobing on a per site basis only works for single site setups. Multi-site setups will always try to reprobe site "a", reprobing all devices in parallel.
    Note These three limitations are handled by the summit_workarounds parameter.
  • If temperature parameters are to be sent to the handler by the driver, the handler must be manually stopped. Temperature is set up by automatically creating a recipe file and activating it. The handler must be set up to run in the following modes to accept the temperature setup:

    Op Mode: normal

    System Mode: normal

    Tester Mode: normal

    Control Mode: Tester

    Processing Mode:Device
