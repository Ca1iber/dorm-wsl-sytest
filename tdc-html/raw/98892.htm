Troubleshooting: Collecting log and dump files

Subtopics

  1. Collecting log files if SmarTest crashed
  2. Creating Java dump file if SmarTest shows a hang-up
  3. SmarTest Status Snapshot

When SmarTest crashes or does not run due to a hang-up, collect all available log files, check them for improvements of your device and project data, and, in case of open questions, send them to your Advantest service representative. The log files allow a detailed analysis of the cause.
