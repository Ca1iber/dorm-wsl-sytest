DRLTimeStampAttr

A variable of this type holds the time elapsed since 1 January 1970 (epoch) in seconds and microseconds.

typedef struct _DRLTimeStampAttr {
  unsigned long seconds;
  long microseconds;
} DRLTimeStampAttr;

Functional changes

  1. Introduced before SmarTest 6.3.2
