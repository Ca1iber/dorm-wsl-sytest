Topic 42309

Preparing a Driver for Hook Function Use

Subtopics

  1. Unpacking the Driver and Hook Sources
  2. Compiling the Driver

This section describes the necessary preparations for using hook functions. You must generate a new driver directory which contains a new compilation of the complete driver, and the hook function C templates.

To finally run your own hook functions, you must run this driver compilation, containing the hook functions. This is described in Running Hook Functions.

Note It is possible to run the original driver with a recompiled plug-in which contains user-specific hook functions, if the header files have not been altered. However, it is strongly recommended to use a new driver compilation, as described here, in order to keep a clean separation between originally provided software and user-modified software.
Note In this section, Generic* stands for either GenericHandler or GenericProber. Use GenericHandler if you want to unpack the general handler driver sources, use GenericProber if you want to unpack the general prober driver sources.
