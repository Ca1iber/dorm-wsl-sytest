Opening the transaction view

About this task

This task describes how to open the protocol transaction view.

Before you begin

Open a protocol with the protocol editor, refer to Opening a protocol in the protocol editor.

Procedure

  1. In the overview area of the protocol editor, right-click the protocol icon.
  2. Select Show in Transactions.
    Note The following procedure is also valid if performed on the respective icon of transaction, pin role or field.

Results

The transaction view opens, displaying the selected content of the protocol, transaction, pin role or field respectively.
