Topic 142422

GP-DPS capacitor requirements

Subtopics

  1. GP-DPS load capacitors
  2. GP-DPS filter capacitors
  3. GP-DPS performance ranges
  4. GP-DPS capacitor precautions

There are two basic types of capacitors that can be used for the GP-DPS channels of the V93000 test system: Load Capacitors which stabilize the DPS operation and prevent voltage drops, and Filter Capacitors which filter noise-related signals from the DPS pins.

Functional changes

  1. Introduced before SmarTest 6.3.2
