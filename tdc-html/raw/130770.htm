Configuring an external GPIB DPS

The externalGPIB_dps.xml configuration file, located in the /opt/hp93000/soc/pws/data/ directory, specifies a specific external GPIB DPS, to allow control by the V93000 system software.

We provide a default xml config file. You may use it to write your own xml configuration file.

When modifying the xml config file, change only the "value" fields. Do not modify any other field. Use correct data provided by your external GPIB DPS manual.

To specify the line feed character "\n" in the xml config file, use "&#10;". In the ASCII character set, "&#10;" means the control character with the decimal value of 10.

Each string after 'value=' must be enclosed in quotes, for example, value="1".

To specify your own xml config file follow the instructions:

  • Line 1 and 2 of the xml config file provide system information. Do not modify them.
  • Line 3 and 691 form the enclosing tag pair of the root node. All external DPS information must be specified within this pair of tags.
  • Line 4 and Line 56 form the pair of tags which includes all data specifying the instrument.
  • In line 4 you specify your own DPS model. If you have a "HP6626A" model, line 4 should read <MODEL value="HP6626A">.
    Note The model value (such as HP6624A or HP6626A) must match the ID returned by the GPIB ID query command "ID?;\n".
  • Line 5 states the 'power on' GPIB command of the DPS in the value field.
    Note The '\n'(CR,LF) control character must be entered as '&#10;' to be recognized as control character. '&#10;' means character 10 in the ASCII character set.
  • Line 6 states the 'reset' GPIB command of the DPS in the value field. As in line 5 you must use '&#10;' to replace '\n'.
  • Line 7 states if the channel index should be appended in the GPIB command. Use "TRUE" or "FALSE".
    • Use "TRUE" if the channel index must be appended in the GPIB command.
    • Use "FALSE" if the channel index value does not need to be appended.
    • You must append the channel index in the GPIB command, if your DPS has 2 or more channels.
  • Line 8 specifies the total number of channels in the DPS model. If your DPS has 2 channels, enter "2" in the value field.
  • Line 9 and line 17 form the enclosing pair of tags for the status register of the DPS.
    • Line 10 to line 16:

      Find the required register type data in the DPS manual, and enter the decimal value of the status bit in the value field.

  • Line 18 and line 23 form the enclosing pair of tags pair for the serial poll register of the DPS.
    • Line 19 to line 22:

      Find the required register type data in the DPS manual, and enter the decimal value in the value field.

    • Line 22:

      The "fault_mask" register type requires the decimal sum of all possible fault bits for each output. Add the decimal values of all fault bits in the serial poll register, and enter the sum in the value field.

  • Line 24 and line 55 form the enclosing pair of tags for the Channels info of the DPS. The Channel block requires a total of 8 parameter values.
    • The <CHANNEL> tag pair encloses two sub nodes: <DEFAULT_PARAMETERS> and <INDEX>.
    • Either one of the sub nodes is optional.
    • If the DPS has the same parameter values for all channels, you can enter them in the <DEFAULT_PARAMETERS> tag block. All <INDEX> tags blocks can be deleted or kept blank.
    • If each channel of the DPS has different parameter values, the <DEFAULT_PARAMETERS> tag block can be deleted or kept blank. Enter all values in <INDEX> tag blocks.
    • If you have some default parameters, and some per-channel parameters, you can enter parameter values in all tag blocks.
    • If a parameter value is defined in the <DEFAULT_PARAMETERS> tag block, it can be overwritten in the <INDEX> tag block.
      Note Each of the 8 parameters must be defined, either in the <DEFAULT_PARAMETERS> tag block or in the <INDEX> block.
  • Line 25 and line 34 form the enclosing tag pair for the default parameter values of the channels. This tag block is optional.
    • In the default file, the lines 26 to 33 show all 8 parameters. You are not required to specify all 8 parameters here. Optionally you can specify 3 parameter values in this tag block and define the other 5 parameter values in the <INDEX> channel tag block. In the <INDEX> tag block you can also overwrite the 3 parameter values defined earlier.
  • The index tags in line 35 and line 44 form the enclosing tag pair for the individual channel parameter values. The tag block is optional. The value field in <INDEX value="3"> is required to specify an individual channel.
    • The default xml config file assumes 4 channels in total and uses a <DEFAULT_PARAMETERS> tag block. Channel 1 and channel 2 have the same parameter values as specified in the <DEFAULT_PARAMETERS> tag block. Therefore <INDEX value="1"> and <INDEX value="2"> are not specified. Channel 3 and channel 4 have different parameter values and must be specified under <INDEX value="3"> and <INDEX value="4">.
  • Parameter tags, like in line 36 to 43, describe one parameter value each.
    • Parameter values must be an integer.
    • Voltage related values must be in mV.
    • Current related values must be in uA.
    • Time related values must be in ms.
