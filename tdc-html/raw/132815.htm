CCTgetLabelName

Returns the label name.

In concurrent mode (CCF_Concurrent = 1), it returns the merged multiport burst label name specified for CCF_LabelName in the execution test suite of the CCF block.

In serial mode (CCF_Concurrent = 0), it returns the label name specified in the current test suite.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

string CCTgetLabelName();

List of parameters

There are no parameters.

Return value

The label name is returned.

Functional changes

  1. Introduced in SmarTest 7.2.0
