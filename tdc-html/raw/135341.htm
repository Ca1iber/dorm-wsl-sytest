MTP_MULTI_FILTER.addAddressFilter()

This member function adds a filter defined by MTP_ADDRESS_FILTER to the filter created by MTP_MULTI_FILTER.

Syntax

MTP_MULTI_FILTER& addAddressFilter(const MTP_ADDRESS_FILTER filter);
Parameter

Parameter

Description

filter

The name of the filter which you want to add.

Return value

There is no return value.

Example

MTP_ADDRESS_FILTER filter1, filter2;
MTP_MULTI_FILTER multi_filter;

//Define filter1 and filter2.
filter1.setRange(MTP::X_ADDRESS,0,1024).setRange(MTP::Y_ADDRESS,0,1024);
filter2.setRange(MTP::X_ADDRESS,1024,2048).setRange(MTP::Y_ADDRESS,0,1024).setMode(MTP::EXCLUDE);

//Add filter1 and filter2 to multi_filter.
multi_filter.addAddressFilter(filter1).addAddressFilter(filter2);
