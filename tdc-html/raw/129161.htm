SHARED_CONTINUITY_TEST.pinNonShared()

The pinNonShared() member function of SHARED_CONTINUITY_TEST lets you specify the non-shared pins, pin groups that are to be measured.

Syntax

SHARED_CONTINUITY_TEST& pinNonShared(const string& pinlist)

Parameter

Description

pinlist

The list of the non-shared pins, pin groups that are to be measured.

Separate entries with commas.

 

Example

SHARED_CONTINUITY_TEST mTEST;
mTEST.pinNonShared("DQ_Bus");
mTEST.pinNonShared("DQ_Bus,DM");

Related information

SHARED_CONTINUITY_TEST

Functional changes
