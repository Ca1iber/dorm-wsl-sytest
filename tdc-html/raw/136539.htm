Topic 136539

Interaction with testflow

Subtopics

  1. Displaying the shmoo plot of a shmoo test suite
  2. Transferring the shmoo tests from the Shmoo Tool to testflows
  3. Transferring test suites to the Shmoo Tool

The Shmoo Tool and the testflow can interact with each other:

  • The shmoo tests set in the Shmoo Tool can be transferred to a testflow as a shmoo test suite.

    See Transferring shmoo tests from the Shmoo Tool to testflows.

  • A test suite can be transferred to the Shmoo Tool.

    See Transferring test suites to the Shmoo Tool.

  • The Shmoo Tool can display the shmoo plot of a shmoo test suite only after you have transfterred the shmoo test suite setup into the Shmoo Tool. For details, see Displaying the shmoo plot a shmoo test suite.
    Note The Shmoo Tool cannot display the shmoo plots of a running shmoo test suite or a running testflow. To view these shmoo plots, use the Integrated Result Tool. For details, see Interaction with the Integrated Result Tool.
