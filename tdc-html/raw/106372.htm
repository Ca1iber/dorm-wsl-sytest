Topic 106372

How to Set Up a Multi-Port Test with a DC Sub-pattern

Subtopics

  1. Configuring Ports, Pins, Timing, Vectors and Test Methods

About this task

This describes the steps needed for setting up a test to carry out PPMU (DC) and digital tests in parallel in a multi-port setup.

Procedure

  1. Define the Ports and assign pins to them.
  2. Define the timing.
  3. Define the main patterns for the multi-port burst.
  4. Define a subpattern (not a main pattern) for the port on which the PPMU test is to be run and call this sub-pattern from the main pattern of this port.
  5. Integrate the main patterns into a multi-port burst.
  6. Create a test method that:
    • uses the PPMU_XXX API's to create a PPMU test for one or more pins of the desired port.
    • uses the PATTERN_CONTROLLER and PATTERN API's to specify a sub-pattern from which this test will be run.
  7. Define a test suite that:
    • Specifies the newly created test method in the "Testmethod" field
    • Specifies the multi-port burst in the "Vector Label" field

Functional changes

  1. Introduced before SmarTest 6.3.2
