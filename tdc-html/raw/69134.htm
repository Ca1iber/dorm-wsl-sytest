Pin Map Record (PMR)

The Pin Map Record provides indexing of tester channel names and maps them to physical and logical pin names. Each PMR defines the information for a single channel/pin combination.

The Pin Map Record is located after the Initial sequence and before the first FTR or MPR that uses this record's PMR_INDX value.

PMR field name

Field description

Value

93000 data source

PMR_INDX
  • Unique pin index
  • Two-byte unsigned integer
  • Index between 1 and 32767
  • Not a configurable option
  • Populates automatically

CHAN_TYP
  • Channel type
  • Two-byte unsigned integer
  • 0 = missing or invalid data
  • ConfigurationChangedEvent
  • Not a configurable option
  • Populates automatically

CHAN_NAM
  • Channel name
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • Length byte = 0 if missing or invalid data
  • ConfigurationChangedEvent
  • Not a configurable option
  • Populates automatically

PHY_NAM
  • Physical pin name
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • Length byte = 0 if missing or invalid data
  • ConfigurationChangedEvent
  • Not a configurable option
  • Populates automatically

LOG_NAM
  • Logical name of pin
  • Variable length character string
  • Length byte = 0 if missing or invalid data.
  • This is the pin number, but it is a string container, so alphanumeric pin numbers are handled correctly
  • ConfigurationChangedEvent

 

HEAD_NUM
  • Test head number associated with channel
  • One-byte unsigned integer
  • Value = 1

    If the ATR and GDR indicate that there are more than 255 sites in the test, HEAD_NUM is the number of the site divided by 256. For example, in a record for site 384, HEAD_NUM would be 2.
  • For tests with up to 255 sites: hard-coded value

    For tests with more than 255 sites: derived from SiteID

SITE_NUM
  • Test site number associated with channel
  • One-byte unsigned integer
  • 1 = missing or invalid data

    If the ATR and GDR indicate that there are more than 255 sites in the test, SITE_NUM is the number of the site modulo 256. For example, in a record for site 600, SITE_NUM would be 88.
  • Configuration Changed Event

The PMR_INDX values are unique in multisite testing, with one PMR_INDX value per PMR record. For example, if a dual-site test generates PMR records for each site/pin combination, then a 4-pin device, dual-site test, will generate eight unique PMR_INDX values, reported in eight PMR records. So the PMR_INDX = 1, 2, 3, 4, 5, 6, 7, 8.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.2.2: Added HEAD_NUM and SITE_NUM conventions for tests on more than 255 sites.
