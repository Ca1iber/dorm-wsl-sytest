Topic 20289

Assigning a level or timing spec value

Before you begin

Make sure that a level or timing spec variable has been defined.

Procedure

  1. In the Flow Sequence Editor, select an insertion point where you want to insert a node. On the Palette, click assign level value or assign timing value. The corresponding wizard opens.
  2. Enter the numbers of the equation set and spec set.
  3. From the Variable Name List, choose the variable to which you want to assign a value.
  4. In the Variable Value text box, enter the desired value, either as a literal value or as an expression.
  5. Click Finish.

Results

The Assign Level Spec Value node or Assign Timing Spec Value node appears in the testflow displaying the spec variable name. Whenever the testflow passes this node, the specified value is assigned to the indicated level or timing variable.
