Topic 98562

DIAG - (DIAGnostics)

The DIAG command allows you to control the following functions:

  • Trace function, which records all the firmware commands issued by the user interface of SmarTest, and also the replies to these commands
  • Message suppress function which controls whether the error and warning messages are displayed in the report window
    Note The DIAG command can be used as temporary solutions, but the consistency of behavior over multiple releases is not ensured and these options should be used only when no other options exist to complete the task. You should also consider the UI_SUSPEND test method API.

Syntax

DIAG {option}

Parameters

option Specifies the desired option:
2 Starts the logging of the issued firmware commands/queries to a file /var/opt/hp93000/soc/MCDLog.

The default state for this function is OFF (-2).
-2 Stops the logging of the issued firmware commands/queries to a file /var/opt/hp93000/soc/MCDLog.
44 Suppresses the error and warning messages to the report window.

The default state for this function is OFF (-44).
-44 Starts to display the error and warning messages to the report window.

Application

See Using the Trace Function.

Errors

An error is generated if the option value is invalid.

Example

DIAG 44

This example stops to display the error and warning messages to the report window.
