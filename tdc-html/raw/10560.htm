Topic 10560

Changing the level set (CLEV)

The CLEV instruction allows you to change the level set during a test by specifying a new set number. It is implemented similarly to the CTIM instruction (see Changing the timing set). The overall length of a CLEV instruction equals the length of a CTIM instruction with p1 = p2.

Functional changes

  1. Introduced before SmarTest 6.3.2
