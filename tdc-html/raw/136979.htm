SHMOO.drawPlot()

This function is used to draw a two-dimensional plot with a data array.

After running the corresponding test suite or testflow, to view the plot, use the shmoo view of the Integrated Result Tool.

To call this member function, use the SHMOO.drawPlot() syntax, where SHMOO is the predefined instance for the shmoo utility class and is used to directly access the member functions of this class.

Note SHMOO.drawPlot() replaces the old APIs, openShmoo, closeShmoo and writeShmoo, which have been obsoleted since 7.2.0.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ShmooUtility.h.

Syntax

void drawPlot(const DOUBLE**data, INT yLen, INT xLen);
Parameters

Parameter

Description

data

The name of an data array to be used to fill in the corresponding cells of a drawn plot.

yLen

The number of cells in one column of a drawn plot.

xLen

The number of cells in one row of a drawn plot.

Example

Draw a plot whose y-axis has 10 steps and x-axis has 5 steps with a data array data[10][5].

#include "mapi.hpp"

void TestForGraphicDisplayByShmoo ()
{
  double data[10][5];
  for (int iY=0; iY<10; iY++)
  {
    for (int iX=0; iX<5; iX++)
    {
      data[iY][iX] = 5*iY+iX;
    }
  }
  SHMOO.drawPlot((const double**)data, 10, 5);  
  //10 is the total steps of Y; 5 is the total steps of X.
}
