Topic 10490

Connecting the DUT to the test system resources

CAUTION Ensure that the break vector and the format setting do not conflict with the DUT requirements. Particular attention must be given to IO pins to avoid driving into an active output.

In order to avoid hot switching of the relays, the connect sequence starts from the sequencer OFF state. Then the AC relay (connection to the pin electronics) is closed and subsequently the DPS is powered up. The sequencer is then set to the break state. By default, the following sequence of commands is used:

RLYC AC, OFF, (all I pins)

RLYC, RLYC? - (ReLaY Control)

RLYC AC, OFF, (all remaining ac pins)

PSST ON

PSST ON

PSST, PSST? - (Power Supply STatus)

SQST BRK

SQST, SQST? - (SeQuencer STate)

The figure in Control of the Pin Electronics Relays and the Relay Switching Method shows the relays which are controlled by the RLYC command.

The pin electronics steady state is controlled through the break vector and the sequencer state. If the sequencer is in the OFF state all pins go into the High-Z state.

After you set the sequencer to break, the pin electronics go active and apply the designated break vector. The actual signal applied to the DUT input pins is a function of the break vector and the signal format defined by the timing setup.
