Topic 151470

rdi.enableWarning()

Resumes SmartRDI warnings to be shown in the UI report window after you have used disable() for a specific code segment.

You must put this function outside the RDI_BEGIN and RDI_END block which holds the specific segment.

This function cannot impact any warnings from MAPI or firmware commands.

Syntax

rdi.enableWarning();

Return value

There is no return value.

Example

rdi.enableWarning();
   RDI_BEGIN();
      ...
   RDI_END();

Related information

rdi.disableWarning()

Functional changes

  1. Introduced in SmartRDI 2.4.3
