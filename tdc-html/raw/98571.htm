DPSA, DPSA? - (Define per Pin Subroutine Address)

The DPSA (Define per Pin Subroutine Address) command is generated by the MTL compiler. Do not attempt to execute it from the hpt utility! The following information is provided to improve your understanding of any hpt output listings you may make. You may execute the query. The command is used to define the sequencer start address of a Per-Pin Sequencer Subroutine for each pin.

DPSA

DPSA {name}, {address}, {(pinlist)}

DPSA?

DPSA? {name}, {(pinlist)}

returns:

DPSA {name}, {address}, {(pinlist)}

Parameters

name

Per-pin Subroutine name. This parameter can be used to call the subroutine from a parallel sequencer program.

For the query, you can also enter ALL to return all per-pin subroutine label names.

address

Per-pin Sequencer subroutine entry address.

pinlist

Pins for which a per-pin subroutine is valid.

Application

Per-pin sequencer subroutines.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.3: DPSA instructions are no longer generated by SINAS, which has been removed from SmarTest
