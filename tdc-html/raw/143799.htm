bitPerWord()

Specifies the number of bits per word for the serial transfer mode.

Syntax

bitPerWord(int iBit);
Parameter List

Parameter

Description

iBit

The number of bits. The default value is 32.

Example

rdi.digCap("norm").label("lpDcap_new").pin("DATA2").addVecRange(3,15).samples(10).bitPerWord(4).execute();
