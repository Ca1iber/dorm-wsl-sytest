Test Method Introduction

Test method is a standard or customized C++ test program created with test method APIs.

Test method API is a variety of customized functions that are extensions of the standard C++ programming language for programming operations such as the following:

  • Measure the output signal from a test device
  • Retrieve the measured data
  • Analyze the measured data
  • Judge the calculated result as pass/fail.

Universal test method

Universal test method is the programming style and environment available since SmarTest 6.3. It is a standard C++ project and is independent of any device project and Eclipse project.

The following topics guide you through creating an AC test with universal test method.
