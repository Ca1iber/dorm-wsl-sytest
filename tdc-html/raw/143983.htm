SOURCESYNC_SUB_TEST.domain()

Retrieves an SOURCESYNC_TEST_DOMAIN object in order to get the margin values of the source-sync test in the specified domain.

Syntax

SOURCESYNC_TEST_DOMAIN& domain (const string& domainName);
Parameter

Parameter

Description

domainName

The name of a created domain.

If the domain does not exist, warning message will be issued.

Return value

Returns an object of the SOURCESYNC_TEST_DOMAIN class.

Related information

SOURCESYNC_TEST.domain()

Functional changes

  1. Introduced in MTP 3.2.2
