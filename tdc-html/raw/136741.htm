Shmoo test method customization

Subtopics

  1. Creating a customized shmoo test method
  2. Customized shmoo test template
  3. Viewing customized results of a customized shmoo test in the Shmoo Tool
  4. Performing customized source-sync shmoo tests with the shmoo tool

The shmoo test method customization is to create your own shmoo test method instead of using the provided ac_tml.AcTest.Shmoo test method.

During the customization, you add additional test method parameters and functions to the ac_tml.AcTest.Shmoo test method. Therefore, the new test method will:

  • Keep all the parameters and functions of the ac_tml.AcTest.Shmoo test method.
  • Have new test method parameters.
  • Display desired results on a shmoo plot.
  • Perform specific actions before, during, or after a shmoo.
