Topic 42232

Parameter: summit_workarounds

In the Summit Software Revisions 1.7.3 and 1.7.4 some features are not yet fully supported.

Since it is not yet known, with which Summit Software revision these features will be supported, the Delta plug-in provides workarounds that can be selected with this parameter. The currently existing workarounds are:

"no-multi-site-reprobe": Instead of sending bit coded reprobe information in multisite scenarios (like reprobe X), the driver will always send reprobe 1, if reprobing of any site is necessary.

"no-stop-start": The driver will never try to send stop or start commands, since they are not yet implemented in the Summit Software.

"no-verify": The driver will never try to ask for bin verification mode, neither will it try to activate, deactivate or to use the bin verification mode.

Driver default: empty list

Changeable at run-time: yes

Applicable for: Delta Summit handlers

Example: summit_workarounds: ["no-multi-site-reprobe"

"no-stop-start" "no-verify"]
