Topic 96465

PauseTestprogram

This remote control command tries to pause the execution of a test program. When the test program execution is paused, the event TESTPROGRAM_EXEC_PAUSED is notified.

Success will be returned if the command is successfully issued. Otherwise an error object indicating the error code, description and severity will be returned.

Code

Description

Severity

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • Cannot pause the test program execution because there is no test program currently running.
  • The test program is already paused.

RECOVERABLE

Dependency

The test program is in execution.

Parameters

I/O

Parameter

Description

I

SESSION_ID

The ID of the SmarTest session to work with.

Prototype

string sessionId;
Status command("PauseTestprogram", ParamList(), sessionId);
