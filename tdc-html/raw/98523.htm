DCRE? - (DC set REsult)

The DCRE? query returns the results of the specified DC set and pins.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Predependencies

The DC set must have been defined using DCCH or DCVH and must have been executed by DCEX.

Mode of operation

Results can be retrieved for the pins specified in the DC set (pass/fail or values). The global result is FAIL as soon as one queried pin is FAIL. If the DC set has not been executed, the result value is set to 0 and the Pass/Fail result is calculated from that value, according to the compare mode and thresholds of the DC set (I/L/H).

Syntax

DCRE? setNr,[resultMode]
Parameters

setNr

The DC set identification number, starting with 1.
resultMode The optional parameter defines the result mode:
GPF

A single result, which includes the pass/fail result of the pins, specified in the DC set. A pass is only returned if all pins passed the test.
PPF Returns the pass/fail result for each specified pin of the DC Set.
VAL Returns for each pin of the DC set the pass/fail result and the measured value.

If the resultMode is not specified for DCRE?, the result mode given to DCEX is returned.

DCRE? reply syntax

DCRE setNr, pfResult, value, pinList
Parameters
setNr The DC set identification number, starting with 1.
pfResult The pass/fail result:
P Pass
F Fail
value The measured value is returned in µA (Microampere) or mV (Millivolt) if the resultMode has been set to VAL.
pinList In case of a global pass/fail result query the pin list is empty.

In case of a per-pin pass/fail result query the pin list contains multiple pins. All fail pins are summarized in one answer string and all pass pins are summarized in one answer string.

In case of a value result query the pin list contains only one pin, as each pin will return different values.

Errors

An error is returned if the specified DC set ID has not been defined yet.

Warnings

A warning is generated if the DC set has not been executed. The value is set to 0.

Examples

Example 1

Preconditions:

DCVH 1,,20000,200,-100,100,I,25,NTBBM,PAR,(pin1, pin2, pin3)
DCEX 1, MEAS_VAL

Result:

DCRE? 1, VAL
DCRE 1,P, 10.3, (pin1)
DCRE 1,F, 200.1, (pin2)
DCRE 1,P, 20.4, (pin3)

Result:

DCRE? 1, GPF
DCRE 1,F,, ()

Result:

DCRE? 1, PPF
DCRE 1,P,, (pin1,pin3)
DCRE 1,F,, (pin2)

Example 2

Preconditions:

DCVH 1,,20000,200,-100,100,I,25,NTBBM,PAR,(pin1, pin2, pin3)
DCEX 1, MEAS_VAL

Result:

DCRE? 1, 
DCRE 1,P, 10.3, (pin1)
DCRE 1,F, 200.1, (pin2)
DCRE 1,P, 20.4, (pin3)

Result:

DCRE? 1, GPF
DCRE 1,F,, ()

Result:

DCRE? 1, PPF
DCRE 1,P,, (pin1,pin3)
DCRE 1,F,, (pin2)
