DFLV, DFLV? - (DeFaultLeVel)

The DFLV command allows you setting user defined default levels. These levels overwrite the levels that are defined by the selected device technology cmos or ecl and are applied when a device is loaded and no other level settings are defined in the level setup.

The command must be issued after the reset of the system by *RST - (ReSeT) and before pins are configured. This command does not apply the default values to the hardware but stores the values in a table. The stored default values are applied to the hardware when pins are configured without any further level setup information.

Changing the default values via DFLV command after a pin has already been defined, will not effect the default values or initialization of existing level sets for these pins.

With the *RST - (ReSeT) command performed, all default values defined by the DFLV are reset to the system-defined default values of the selected cmos or ecl device technology.

DFLV 

DFLV [resourceSpecifier,] [mode,] {value}

DFLV?

DFLV? [resourceSpecifier] [, mode]

returns

DFLV VIL,STD,value
DFLV VIH,STD,value
DFLV VIHH,STD,value
DFLV VOL,STD,value
DFLV VOH,STD,value
DFLV VOL_DIFF,STD,value
DFLV VOH_DIFF,STD,value
DFLV VT,STD,value
DFLV VCOM,STD,value
DFLV REC_OFFSET,STD,value
DFLV REC_SWING,STD,value

if neither parameter resourceSpecifier nor parameter mode have been specified.

Parameters

resourceSpecifier

The extra parameter specifies the resource to be set or queried.

The following resources are supported:

Resource specifier Description
VIL and VIH Input (drive) voltage definition for I and I/O pins.
VIHH High voltage level definition for I and I/O pins.
VOL and VOH Output threshold voltage definition for O and I/O pins.
VOL_DIFF and VOH_DIFF Output threshold voltage definition for O and I/O pins in differential mode.
VT Termination voltage definition.
VCOM Commutation voltage of the active load.
REC_SWING The receiver swing for a differential comparator.
REC_OFFSET The receiver offset for a differential comparator.
ALL Keyword ALL selects all resources.
mode

The extra parameter specifies for which operation mode parameter value should be applied or queried.

Supported operation modes:

  • STD
  • ALL

Keyword ALL selects all operating modes.

Extra parameter resourceSpecifier must also be defined if mode is specified.

If the parameter is not defined, mode STD is taken as default value. In this case the specified value is applied to STD values only and default values used in STDDIFF mode will not be affected.

Note: There is an exception when setting parameter value to RESET. In this case, an omitted mode parameter will be counted as ALL.
value

The mandatory parameter defines the default value for the selected resource and operating mode.

This parameter is to be defined as
  • voltage (in mV) or
  • as keyword RESET.

With the parameter set to RESET, the affected values will be set to the system-defined default values of the selected cmos or ecl device technology.

Examples

Example 1: Resource and mode specified

DFLV VIL,STD,100

This example sets the default value for the VIL resource in STD mode to 100 mV. Other default values are not modified.

Example 2: Resource specified, mode omitted

DFLV VIL,100
DFLV VIH,200

This example sets the default value for the VIL resource to 100 mV, and VIH to 200 mV. As no operating mode is specified, the values are applied only for the STD mode.

Example 3: Reset single resource

DFLV VIL, RESET

Sets the default value for the VIL resources to the technology defined default value for all operating modes. This overwrites potential user-defined values by the initial system value.

Example 4: Reset all default values to the technology defined values and query all values

DFLV RESET
DFLV? ALL, ALL

returns

DFLV VIL,STD,2250
DFLV VIH,STD,2500
DFLV VIHH,STD,0
DFLV VOL,STD,2250
DFLV VOH,STD,2500
DFLV VOL_DIFF,STD,0
DFLV VOH_DIFF,STD,0
DFLV VT,STD,2500
DFLV VCOM,STD,2500
DFLV REC_OFFSET,STD,1200
DFLV REC_SWING,STD,3200

for the cmos technology.
