DRLEventRec

A variable of this type holds data of one event record. Such variables are initialized by the DRLGetNextUnmaskedEvent function.

The event_header member contains the event type.

The attributes member holds the number of attribute records which come with the event.

The attribute_list member points to the first attribute record. This pointer is used in DRLEventGetAttribute to access the individual attribute records in the event record body.

The cleanup_list and data members are used for internal memory management. When extracting data from the data log stream, the DRL allocates memory to store temporary data. The cleanup_list member is used to free the allocated memory for this data, after the event record data has been fully extracted.

For further information on how event data is organized, see Data Organization.

Note The members of a DRLEventRec variable must only be accessed by the designated DRL functions. Do not directly access these members. 
typedef struct {
          struct DCLEventHdrRec event_header;
          unsigned attributes;
          DRLAttributeRec *attribute_list;
          struct DRLCleanupList *cleanup_list;
          void *data
          }DRLEventRec;
