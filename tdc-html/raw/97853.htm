Pin group

You can group pins together and handle these groups in the same way as you handle individual pins. This is useful for handling an address bus, for example, where you are interested in the value of an address rather than the states of its individual pins.

Defining groups improves the readability of the setup displays and allows you to keep an overview of the DUT data. A group of four pins for example, occupies only one parameter column in the Pattern Tool, when displayed in hexadecimal format. Also, with high pin-counts, if you group pins together in the Level Setup and Timing Setup windows, each entry sets up several pins at once. This compresses the size of the data files so that the data can be loaded into the hardware more quickly.

The way that you group pins together has a huge effect on the ease with which you can analyze the test results later. So it is important to keep this in mind when you define the pin groups. Careful planning at this stage can save time later because of the improved visibility of the test results.
