Topic 256008

Using the GIO library API from a SmarTest application

Subtopics

  1. Adding a project to the Java build path

If a SmarTest test application shall make use of GIO library functions, it will have to be linked to the GIO library.

About this task

The header file of the GIO library API is compatible to C. The GIO library API functions are written in C++.

The GIO shared library is located at

/opt/hp93000rt/el7/x86_64/gio/lib/libhw_cor_gio.so

and the related header file is located at

/opt/hp93000rt/el7/x86_64/gio/include/xoc/hw/cor/gio/gio.h.

This topic considers applications of SmarTest 7.5 and higher releases running on RHEL7.4. For the invocation of the GIO library API from a C++ test application, see Using the GIO library API from a C/C++ test application.

A mechanism must be used to expose the GIO library API to the application based on SmarTest 7.5 and onwards.

Before you begin

If you install the platform delta bundle (PDB) the GIO API library will be installed as well.

If your test application is already existing and based on SICL, you will have to port it the GIO library API. Consider Porting SICL-based applications to GIO for details.

Results

The user application implements connectivity to external instruments using the GIO library API.

Functional changes
