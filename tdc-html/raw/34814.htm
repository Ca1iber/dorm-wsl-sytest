DRLMeasuredRangeAttr

A variable of this type holds a pointer to a structure named _DRLMeasuredRangeAttr. In this structure the range of measured values is stored.

The member min_value holds the lowest measured value, max_value holds the highest measured value.

The member unit holds the unit of the measured values as a NULL terminated string.

Note You can specify any derived unit (such as ns or mA) for EDL data logging. However, when data logs are converted to STDF, all units are converted to their SI equivalents (ns to s, mA to A) and the corresponding values are converted accordingly. (For example, 435 mA is converted to 0.435 A.)
typedef const struct _DRLMeasuredRangeAttr{
    double min_value;
    double max_value;
    char *unit;
   } *DRLMeasuredRangeAttr;
