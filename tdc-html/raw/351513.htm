Topic 351513

SmartRDI 7.6.0

This section summarizes software changes including new features and enhancements in SmartRDI 7.6.0.

Changes and new features
Category Description
Register Access library The Register Access library can be used in test methods to perform register operations.
Alarm handling Alarm check per result ID. See rdi.alarm().check().execute().
AWG addWaveform() adds multiple waveforms to an analog set.
Cogo Before 7.6.0, each search step in a linear search is a subroutine.

SmartRDI 7.6.0 supports the entire linear search with only one subroutine in pattern.
DC vMeasForceDrop() and vMeasReturnDrop() support HC channels of DC Scale DPS128 cards.
EMAP rdi.func().startVec() and rdi.func().stopVec() are enhanced to be used by the emap() class for splitting a pattern to create a new partial pattern and get the EMPA result.
Relays The "NO" value can be used for opening a type of relay on one site and closing the same type of relay on another in runtime. See runTimeVal().
smartVec New flag SMV_IGNORE_COMMENT in the RDI_Configure file to skip comments generated in pattern.
TMU rdi.id().getTmuErrorState() for retrieving the error state of specified pins and sites.
Utility line control Wait time can be added to pins in Pin Configuration for sequencer‑controlled utility lines.

Supported SmarTest versions

SmartRDI 7.6.0 supports SmarTest 7.6.0.
