MTP_DPS_MEASURE.execMode()

The execMode() member function of MTP_DPS_MEASURE lets you select the measurement mode.

Syntax

MTP_DPS_MEASURE & execMode(const TM::DCTEST_MODE mode)

Parameter

Description

mode

Measurement mode. It can be: TM::GPF (default), TM::PPF, TM::PVAL, or TM::DCTEST_AUTO.

  • TM::GPF: This mode executes a global pass/fail measurement. The test will pass if all of the measurements pass. The test result can be retrieved with the getPassFail() member function.
  • TM:PPF: This mode executes a per-pin pass/fail measurement. The pass/fail result for each measured pin can be retrieved with the getPassFail(const STRING & pinlist) member function. In this mode, you can also retrieve the global pass/fail result with the getPassFail() member function.
  • TM::PVAL: This mode executes a per-pin value measurement. The result value for each measured pin can be retrieved with the getValue(const STRING & pin) member function. In this mode, you can also retrieve the global pass/fail result and the per-pin pass/fail result by using the getPassFail() and getPassFail(const STRING & pinlist) member function, respectively.
  • TM::DCTEST_AUTO: This mode executes the DC test according to the test suite flags.

    If the flag "Pass value" or "Fail value" is on, the DC test will execute in the same way as in the TM::PVAL mode.

    If the flags "Pass value" and "Fail value" are off and the flag "Per pin on pass" or "Per pin on fail" is on, the DC test will execute in the same way as in the TM::PPF mode.

    If the flags "Pass value" and "Fail value" are off and the flag "Per pin on pass" and "Per pin on fail" are off, the DC test will execute in the same way as in the TM::GPF mode.

The default value is TM::GPF.

Return Value

Returns a Boolean true for pass or false for fail result of the measurement.
