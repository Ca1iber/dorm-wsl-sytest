pulldown()

Enables or disables the pull‑down circuit after disconnect.

This function can be used only in the code‑based mode.

This function supports only DC Scale XPS256 card in the PMU operating mode.

The setting of the pull‑down circuit applies only to the current RDI command.

Syntax

dcBase& pulldown(TA::PULLDOWN_MODE mode);
Parameter
Parameter Description
mode

The pull‑down mode of type TA::PULLDOWN_MODE to be set.

Supported values:
  • TA::PULLDOWN_ON
  • TA::PULLDOWN_OFF

Default value for the DC Scale XPS256 card is TA::PULLDOWN_ON.
Return Value
A reference to the dcBase object.

Example

rdi.dc().pin("XPS256_PMU_1").iForceRange(50 mA).iForce(5.0 mA).vClamp(-5.0, 5.0 V).pulldown(TA::PULLDOWN_ON).execute();

Functional changes

  1. Introduced in SmartRDI 7.10.1
