FFV()

Specifies a cycle number, starting from which the cycles in range are to be checked for finding and retrieving the number of the first fail vector in pattern.

This setup command must work together with rdi.id().getFFV() to get the first fail vector.

Syntax

FFV(int startCycle);
List of parameters
Parameter Description
startCycle The number of the first cycle in the cycle range.

Example

RDI_BEGIN();
  rdi.emap("a").label("label2").pin("pB")
               .FFV(10).execute();
RDI_END();

int iffv=rdi.id("a").getFFV();
