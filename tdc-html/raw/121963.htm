Topic 121963

Leakage

This test method measures the leakage current at a device input, output, IO, DC or mixed pin.

To perform the leakage measurement you can use the Pin PMU or DC Scale pins in PMU operating mode. You need to explicitly specify the instruments to use in the parameter.

This test method consists of both low level test and high level test. You can execute them individually or together.

If specified, a functional test is executed up to a specific vector or cycle to bring the DUT into the desired state first. After the execution, the sequencer is set to break state with the AC relays closed and DPS set to the voltage programmed in the level setup.

Then, either a parallel or a serial current measurement is executed on the specified pins.

When measuring with PPMU, the precharge option can be used to program the PPMU to a voltage prior to closing the PPMU relay. The SW will then wait this voltage to be settled and then connect the DUT to the PPMU by closing the relay. Typically this precharge voltage is the same as the voltage used to measure the leakage current.

The PMU current range is determined by the maximum of the absolute lower limit value and absolute upper limit value.

This test method supports different parameter settings and different limit settings for different pins or pin groups. Multi-port setup is supported.

This test method supports test table. But you need to enter the test names manually in the parameter. You can use both test table and testflow limits in a testflow. The test table has higher priority than testflow limits. If a test name used in the test flow is defined in both test table and testflow limits, the value defined in the test table will be used.

Parameters of measuring with PPMU

UsePPMU

string

Use PPMU to do the measurement or not. Its value can be YES or NO. The following parameters in this table are only available when its value is YES.

UsePPMU.pinlist

PinString

The list of pins or pin groups to be measured with PPMU. These pins and pin groups are separated by comma.

UsePPMU.measure

string

The measurement direction. Its value can be:

BOTH: measure leakage of both low level and high level

LOW: measure leakage of low level only

HIGH: measure leakage of high level only

To specify different settings for different pins, separate them with comma.

UsePPMU.forceVoltage_mV

string

The force voltage in [mV]. If both levels are measured, its value is in the format of "(forceVoltage_low, forceVoltage_high)".

To specify different settings for different pins, separate them with comma.

UsePPMU.preCharge

string

Whether to precharge PPMU before forcing voltage. Its value can be ON or OFF.

To specify different settings for different pins, separate them with comma.

UsePPMU.prechargeVoltage_mV

string

The precharge voltage for PPMU in [mV]. If both levels are measured, its value is in the format of "(prechargeVoltage_low,prechargeVoltage_high)".

To specify different settings for different pins, separate them with comma.

UsePPMU.settlingTime_ms

string

The additional settling time to system. If both levels are measured, its value is in the format of "(settlingTime_low, settlingTime_high)".

To specify different settings for different pins, separate them with comma.

UsePPMU.measureMode

string

The measurement mode. Its value can be:

PAR: parallel measurement

SER: serial measurement

To specify different settings for different pins, separate them with comma.

UsePPMU.relaySwitchMode

string

The relay switching mode. Its value can be:

DEFAULT(BBM): open AC relay and PMU relay, then open ac relay and close PMU relay in parallel.

MBB: close PMU relay and then open AC relay

PARALLEL: open AC relay and close PMU relay in parallel

To specify different settings for different pins, separate them with comma.

UsePPMU.testName

string

The test names to be used as limit. You can:

  • Use the test names defined in the test table or testflow limits. Type in the test names manually. Make sure these test names are in the Test name column of the test table (Refer to Structure of a TMLimits CSV file) or in Test Name column of Tests page of Flow Data Editor.
  • Define new test names. After that you need to add the defined test names (limits) to the test suite. (Refer to Adding a limit in the Properties view and Adding a limit on the Tests page.)

To specify different settings for different pins or pin groups, separate them with commas.

Common parameters for all measurements

preFunction

string

Whether to execute a functional test before measurement. Its value can be:

NO: Do not execute the functional test

ALL: execute the whole pattern

ToStopVEC: execute the pattern and stop at the specified vector

ToStopCYC: execute the pattern and stop at the specified cycle

stopVecLow

PinString

Vector number to stop the pattern for low level test when preFunction is ToStopVEC.

It does not support multi-port pattern.

stopVecHigh

string

Vector number to stop the pattern for high level test when preFunction is ToStopVEC.

It does not support multi-port pattern.

stopCycLow

string

Cycle number to stop the pattern for low level test when preFunction is ToStopCYC.

For single port pattern, its value is a cycle number.

For multi-port pattern, its value is in the format of cycle_number@port_name.

stopCycHigh

string

Cycle number to stop the pattern for high level test when preFunction is ToStopCYC.

For single port pattern, its value is a cycle number.

For multi-port pattern, its value is in the format of cycle_number@port_name.

output

string

Controls how to output the per pin test result. It can be:

  • None: Do not output the per pin result.
  • ReportUI: Output all the per pin result to the report window.

ShowFailOnly: Only outputs the failed pin result to the report window.

Limits

If you define new test names in the parameter testName, you need to add limits to the test suite with the same test name. (Refer to Adding a limit in the Properties view and Adding a limit on the Tests page.)

Implementation pseudo code

IF low level test THEN
  IF pre-function specified THEN
    execute functional test to specified vector/cycle
    retrieve test result
  ENDIF
  IF PPMU low level measurement THEN
    set up PPMU measurement with specified parameters
  ENDIF
  IF SPMU low level measurement THEN
    set up SPMU measurement with specified parameters
  ENDIF
  IF DCScale SIG mode low level measurement THEN
    set up DCScale pin in SIG mode with specified parameters
  ENDIF
  execute PPMU measurement/SPMU measurement/DCScale SIG mode measurement in parallel
  IF MCx-PMU low level measurement THEN
    set up MCx-PMU measurement with specified parameters
    execute MCx-PMU low level measurement
    retrieve MCx-PMU measurement result
  ENDIF
  retrieve PPMU measurement result
  retrieve SPMU measurement result
  retrieve DCScale SIG mode measurement result
ENDIF
IF high level test THEN
  IF pre-function specified THEN
    execute functional test to specified vector/cycle
    retrieve test result
  ENDIF
  IF PPMU high level measurement THEN
    set up PPMU measurement with specified parameters
  ENDIF
  IF SPMU high level measurement THEN
    set up SPMU measurement with specified parameters
  ENDIF
  IF DCScale SIG mode high level measurement THEN
    set up DCScale pin in SIG mode with specified parameters
  ENDIF
  execute PPMU measurement/SPMU measurement/DCScale SIG mode measurement in parallel
  retrieve PPMU measurement result
  retrieve SPMU measurement result
  retrieve DCScale SIG mode measurement result
ENDIF
