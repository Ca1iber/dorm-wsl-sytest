Modifying the password of a virtual machine user account

To change the password for a user account, modify the public key and modify the VNC login password.

About this task

To change the password of the virtual machine, you can disable the old one and replace it with a new password.

VNC Viewer is used as the VNC client in this procedure. You can use other VNC clients as you prefer. For details on using other VNC clients, see their documentation.

Procedure

  1. Generate a public and private key pair in PuTTYGen and save the key files.

    See Generating and saving key files for details.

  2. Open VNC Viewer.
  3. Login to the virtual machine.

    See Connecting to a virtual machine via VNC for details.

  4. Right-click the desktop and click Konsole in the menu.

    The Konsole window opens.

  5. If you have not enabled the copy and paste function cross systems, do so as described in authorizing another user for a virtual machine.
  6. Open the key configuration file authorized_keys.
    1. In the Konsole window, enter cd ~/.ssh/ to switch to the .ssh directory of the virtual machine.
    2. Enter gedit authorized_keys to open the key configuration file.
  7. Delete the public key you generated before creating the virtual machine from the configuration file.

    Do not delete other public keys which are used to authorize other users for the virtual machine.

  8. Copy the public key content generated in step 1 into the configuration file.
  9. Save the configuration file.

    Do not close VNC Viewer before you have verified the new key as described in steps 10 to 14.

  10. Configure the connection to the virtual machine with PuTTY.
  11. Connect to the virtual machine via SSH.
  12. Enter vncpasswd in the Konsole window.
  13. Enter the new password and press Enter.
  14. Enter the new password again to verify it.

Results

The password has been changed to the new one.

If you cannot login with the new password, contact the TE-Cloud support team (PDL-ATC-TECloud@advantest.com).
