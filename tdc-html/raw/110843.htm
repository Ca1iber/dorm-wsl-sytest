ShmooSpec

This API is used to change the value of spec variables on X axis and Y axis of a shmoo. The changed value can be applied to specified pins.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ShmooSpec.h.

Constructor

shmooSpec();

It creates an object of the shmooSpec class.

Member functions

setX()

ShmooSpec& setX(const std::string& xSpecName, 
TM::SPEC_TYPE xSpecType, 
const std::string& xPinlist = "@");

This function sets the spec variable for X axis of a shmoo. The spec variable is only shifted for the specified pins.

Parameters

specName

The spec variable used for X axis.

specType

The type of the spec variable. It can be TM::TIM or TM::LEV.

xPinList

The pins for which the spec is shifted. The default value is "@".

setY()

ShmooSpec& setY(const std::string& ySpecName, 
TM::SPEC_TYPE ySpecType, 
const std::string& yPinlist = "@");

This function sets the spec variable for Y axis of a shmoo. The spec variable is only shifted for the specified pins.

Parameters

specName

The spec variable used for Y axis.

specType

The type of the spec variable. It can be TM::TIM or TM::LEV.

yPinList

The pins for which the spec is shifted. The default value is "@".

setup()

ShmooSpec& setup();

This function prepares for later spec value change. It must be called before the function setValue() or restore() is called.

setValue()

ShmooSpec& setValue(double xValue, double yValue);

This function sets the spec variable's value on X axis and Y axis to xValue and yValue respectively. If X or Y Axis is not specified in the shmooSpec object, xValue or yValue will be ignored. The function setup() must be called before it.

restore()

ShmooSpec& restore();

This function restores the spec variables' values to the values when setup() is called. It is not mandatory to use it. The function setup() should be called before restore() is called.

Note The member function setup(), setValue() and restore() of two shmooSpec objects cannot be called alternately.

Examples

Change the spec variables' value of two objects

The following example changes the value of the spec variable of shmooSpec1 and shmooSpec2.

ShmooSpec shmooSpec1;
shmooSpec1.setX("specA", TM::LEV, "pin1");
shmooSpec1.setY("specB", TM::TIM, "@");
shmooSpec1.setup();
shmooSpec1.setValue(1.0, 2.0);
shmooSpec1.restore();
ShmooSpec shmooSpec2;
shmooSpec2.setX("specC", TM::LEV, "pin1");
shmooSpec2.setY("specD", TM::TIM, "@");
shmooSpec2.setup();
shmooSpec2.setValue(1.0, 2.0);
shmooSpec2.restore();

Change one spec variable's value.

The example below changes the value of the spec variable on X axis. The value specified for Y axis is ignored.

ShmooSpec shmooSpec;
shmooSpec.setX("specA", TM::LEV, "pin1");
shmooSpec.setup();
shmooSpec.setValue(3.0, 4.0);
shmooSpec.restore();
