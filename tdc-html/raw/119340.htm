Topic 119340

Saving a Layout

Procedure

  1. To save a layout as a new layout, type a new unique name for the layout.
  2. To save a layout under an existing name, press Ctrl+Spacebar and select one of the listed layouts.
  3. On the Layout preference page you can also assign a default layout, or individual layouts per pattern.
  4. If you have configured and saved several layouts for a pattern in the Pattern Editor, you can select these layouts also in the Pattern Explorer, in the Layout on Pattern Editor column (you may need to scroll to see the column).
  5. Every time you start the Pattern Editor, this layout is used to display the pattern.
