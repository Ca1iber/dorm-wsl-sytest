iRange()

Specifies the range to measure the current. The default range is the maximum range.

Syntax

iRange(double dIR);
List of parameters
Parameter Description
dIR The maximum possible current to measure.

Example

rdi.dc().pin("pinA").vForce(2 V).iMeas().iRange(1 mA).execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
