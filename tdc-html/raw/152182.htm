MTP_MEMORY_PATTERN.getDQDC/DC power unitsByPinName()

Retrieves the data bit index based on a pin name.

If the pin is related to multiple data bits, all the data bit DC/DC power units will be returned.

Syntax

vector<INT> getDQDC/DC power unitsByPinName(const STRING &pinName);
Parameter

Parameter

Description

pinName

The name of a pin.

Return value

Returns a data bit index list.

Example

See Example 4 in MTP_MEMORY_TEST.

Functional changes

  1. Introduced in MTP 3.4.2
