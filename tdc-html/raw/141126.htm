DIGITAL_OFFSET_SEARCH_PINS.start()

Sets the start position for a timing or level offset search. The start position is relative to the start of the searched resources.

The combination of the start value, the number of search steps, and the step width defines the range for the initial linear search.

Syntax

DIGITAL_OFFSET_SEARCH_PINS& start(DOUBLE startval);
Parameter

Parameter

Description

startval

A value represents the interval between the search start and the value of the searched resource. It can be a negative value. Therefore, the start position is calculated from:

the value of the searched resource + startval

The units for timing and voltage searches are seconds [s] and Volts [V] respectively.

Return value

A reference to the DIGITAL_OFFSET_SEARCH_PINS object.
