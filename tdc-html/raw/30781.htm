Topic 30781

POST_PROCESSING

Subtopics

  1. Associated Syntax Entities

This specifies a special type of action which tells the software that at a specific point in time a certain action is to be performed.

A typical use for this feature is in data-logging, in conjunction with the NEW_RESULT_FILE statement. If you use POST_PROCESSING in conjunction with the NEW_RESULT_FILE, the section specified in POST_PROCESSING will only occur after the NEW_RESULT_FILE has been created.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.1.0: GDF logging in application model is obsolete.
