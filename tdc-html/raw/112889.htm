Topic 112889

Customizing toolbars and menus

This topic describes how to configure the toolbar buttons and menu items of a perspective.

Before you begin

Open the perspective which you want to configure.

Procedure

  1. On the menu, click Window > Customize Perspective.

    The Customize Perspective window opens.

    The window contains the following tabs:

    • Tool Bar Visibility: Showing and hiding toolbar buttons
    • Menu Visibility: Showing and hiding menu items
    • Command Groups Availability: Adding and removing command groups to and from the current perspective.
    • Shortcuts: Showing and hiding the shortcuts buttons which will be added as cascade items to the chosen submenus.
      Note On the Shortcuts tab, you cannot configure keyboard shortcuts. For keyboard shortcuts, see Useful keyboard shortcuts.
  2. Click the tab you want to configure.
  3. Select the items you want to see and clear the items you want to hide in the current perspective.
  4. Exit the window:
    • To save the configuration, click OK.
    • To discard the configuration, click Cancel.

      For detailed information, on the Customize Perspective - Setup window click the question mark in the bottom left corner to open the related help topics of the SmarTest Work Center.
