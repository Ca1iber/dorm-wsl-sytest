DRLVectorResultAttr

A variable of this type is a pointer to a structure named _DRLVectorResultAttr. In this structure the pin data related to one tester cycle is stored. The structure consists of a set of members which hold cycle and vector information, and of the pin array. Each element of this array is itself a structure, named DRLVectorResultAttr. This structure holds a range of information for a pin: drive, expected and received data, edge data, and the name of the device cycle.

  • cycle_number holds the number of the tester cycle in the current test.
  • label holds the vector label.
  • label_type holds the type of the label, for example, main or sscn.
  • vector_number holds the number of the vector in the current label.
  • sequencer_command holds the sequencer command for the vector.
  • vector_comment holds the comment related to the vector.
  • failure_code holds the pass/fail information for the tester cycle (see DRLPinPFResult).

The members label_type, label, sequencer_command, and vector_comment contain data as NULL terminated strings.

The member size holds the number of array elements in pin. This is the number of input, output, I/O, and muxo pins in the current test pattern.

Members of the structure pin:

  • pin holds the name and the index of the pin(see DRLPinName).
  • device_cycle_name holds the name of the device cycle as a NULL terminated string.
  • dd1 and dd2 hold one of the values 0 through 3, which indicate the drive values in the device cycle (0=0, 1=0z , 2=1, 3=1z).

    ee1 and ee2 hold one of the values -1, 0, 1, 2, 4, or 5, which indicate the expected values in the device cycle (0=X, 1=1, 2=I, 4=0, 5=U).

  • received holds one of the values 0, 1, 2, 4, or 5, which indicates the received value:

    For input pins: received is always 0

    For output, I/O, and muxo pins:

    • 0 - correct value received
    • 1 - 1 received (incorrect)
    • 2 - I received (incorrect)
    • 4 - 0 received (incorrect)
    • 5 - U received (incorrect)
  • edge holds the number of the edge (1 through 6) for which an error occurred. If no error occurred for this pin, the value is undefined. If errors occurred at multiple edges, the value is -1.
  • parameter holds the compare parameter for the edge at which the error occurred (0= fix, 1=E1, 2=E2).
    typedef const struct _DRLVectorResultAttr {
  DRLCycleNumber cycle_number;
  const char *label;
  const char *label_type;
  int vector_number;
  const char *sequencer_command;
  const char *vector_comment;
  int failure_code; 

  int size;
  struct DRLVectorResultOfPin {
    DRLPinName pin;
    const char *device_cycle_name;
    char dd1, dd2; 
    char ee1, ee2; 
    char received; 
    char edge;
    char parameter;
  } pin[1]; /* the real number of array elements is
               size */

} *DRLVectorResultAttr;
