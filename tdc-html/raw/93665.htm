Debugging a Program

In principle, you can also debug a program from the test program. However, it will be often more convenient to debug the program independently of SmarTest.

To debug the program from a test program, perform the following steps:

  1. Type install_debug <program_name> at the command line in the directory containing the Program Command Set. This creates a debug version <program_name>.d of the respective program.
  2. Specify <program_name>.d instead of <program_name> in the testsuite window (if the program is used as a user procedure) or in the application model.
  3. Execute the test program from the Test Program Explorer. The test program will be executed until the call of the Command Set program.
  4. A ddd window will appear with a breakpoint set at the start of the program. Set additional breakpoints as required.
  5. Start execution of the Command Set program by entering c in the debugger console or by clicking Cont in the ddd command tool.
  6. Debug the program. For details on the ddd debugger see the ddd manual.
  7. After you have finished debugging the program clear all breakpoints and complete the Command Set program by entering c in the debugger console.
  8. Leave ddd. Execution of the test program will be resumed.
  9. After completion of the test program, correct your source code.
  10. Repeat steps 1 through 9.
  11. When all errors have been removed, recompile the Program Command Set with make clean all to create a normal version of it.

If the program is called as a user procedure, you can also debug it from the testflow or testsuite level, as follows:

  1. Type install_debug <program_name> at the command line in the directory containing the Program Command Set. This creates a debug version <program_name>.d of the respective program.
  2. Specify <program_name>.d instead of <program_name> in the testsuite window.
  3. Execute the testflow or testsuite from the testflow editor. The testflow/testsuite will be executed until the call of the Command Set program.
  4. A ddd window will appear with a breakpoint set at the start of the program. Set additional breakpoints as required.
  5. Start execution of the Command Set program by entering c in the debugger console or clicking Cont in the ddd command tool.
  6. Debug the program. For details on the ddd debugger see the ddd manual.
  7. After you have finished debugging the program clear all breakpoints and complete the Command Set program by entering c in the debugger console.
  8. Leave ddd. Execution of the testflow/testsuite will be resumed.
  9. After completion of the testflow/testsuite, correct your source code.
  10. Repeat steps 1 through 9.
  11. When all errors have been removed, recompile the Program Command Set with make clean all to create a normal version of it.
