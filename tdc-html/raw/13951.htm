Topic 13951

Copying cursor and marker positions

This topic describes how to copy the cursor and marker positions of One Channel to All Output Channels: when using the softscope function.

Procedure

  1. Highlight the pin name of the output channel you want to copy from.
  2. On the menu click Edit > copy positions.
  3. When the selection is done click copy in the resulting dialog box.
