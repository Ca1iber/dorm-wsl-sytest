SPMU_PIN_TASK.highAccuracy()

Selects for DC Scale XPS256 pins for the current task the high‑accuracy mode for voltage.

Only the DC Scale XPS256 card in the PMU operating mode is supported:
  • Forcing, clamping, and measuring voltage is performed in the 1.5 V voltage range: See the XPS256 voltage specifications.
  • A license is required to use the 1.5 V range: See High‑accuracy voltage mode in XPS256 specific setup tasks.

The selection of the high‑accuracy voltage mode applies only to the current SPMU_TASK.

Syntax

SPMU_PIN_TASK & highAccuracy();
List of parameters
There are no parameters.
Return value
A reference to the SPMU_PIN_TASK object.
Errors
An error message is displayed in the UI report window if the high‑accuracy license is missing or is not enabled in the DC Scale Extensions editor:
Connection state HC_HAC not supported or no license for pin ...

Functional changes

  1. Introduced in SmarTest 7.10.1
