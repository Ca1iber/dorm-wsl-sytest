Using the Result of Functional Test

You can give the global pass/fail result of functional test to the TEST API as shown below. You do not have to use the GET_FUNCTIONAL_RESULT because it is automatically called by the TEST API.

FUNCTIONAL_TEST();
TEST();

The TEST API handles the global pass/fail result as the judgment result of the TEST API.

To continue the program execution when the functional test fails, specify TRUE for the continue parameter in the TEST API.

See also: GET_FUNCTIONAL_RESULT().
