Topic 152901

rdi.disableSmcExec()

Disables the SmartCalc (SMC) execution for the following RDI blocks.

When the SmartCalc (SMC) execution is disabled, SmartRDI replaces calls of the SmartCalc wrapper APIs with calls of the related standard test method APIs. For more information, refer to Wrapper APIs to control hidden upload in threads in SmartCalc API overview.

The SMC execution is enabled by default.

Syntax

void disableSmcExec();
List of parameters
There are no parameters.
Return value
There is no return value.
Using the function
The function can be accessed only via the main SmartRDI class rdi.

Example

rdi.disableSmcExec();

Related information

rdi.enableSmcExec()

Functional changes

  1. Introduced in SmartRDI 2.4.5
