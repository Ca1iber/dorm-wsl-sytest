RSSR? - (Retrieve Spec Search Results)

The RSSR? query returns the result of a parallel search previously executed by EXSR for selected pins. The search is identified by the search set number.

The RSSR? query returns the result for the site that has the query focus. The query focus is set by the PQFC command.

With this command you configure setups of those sites that have the setup focus: For more information, see also: PSFC, PSFC?.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

RSSR? {set_nr},[(setup_pinlist)]

returns:

RSSR {set_nr},(search_result),[pass_value],[fail_value],(setup_pinlist)
Parameters

set_nr

Specifies the number of the search set for which results are to be returned.

setup_pinlist

The specified setup pins identify the search conditions for which the results are to be returned. For conditions with several setup pins, only one of them needs to be specified.

If this parameter is omitted, results are returned for all search conditions for which a valid result exists.

search_result

 

Specifies whether a transition was found.

Possible values are:

P

Transition found

 

F

No transition found

 

E

No result found for the specified pins. Search was not executed or had errors.

pass_value

The last (in a PASS/FAIL transition) or the first (in a FAIL/PASS transition) spec value or edge position where the test passed.

If only a pass value is returned, the test always passed.

fail_value

The first (in a PASS/FAIL transition) or the last (in a FAIL/PASS transition) spec value or edge position where the test failed.

If only a fail value is returned, the test always failed.

Application

Parallel search tests.

Errors

An error is generated if:

  • One of the specified pins is not configured.
  • No search condition was defined for one of the selected pins.
  • The search set number is missing or greater than 128.

Example

> PQFC 2
> RSSR? 3,(@)
< RSSR 3,P,90.1,90.2,(OUT1)
< RSSR 3,P,33.1,33,(IN1)

In this example, RSSR? returns the results of all setup pins in search set 3 for site 2. For OUT1, a pass/fail transition was found, for IN1 a fail/pass transition.

Functional changes

  1. Introduced before SmarTest 6.3.2
