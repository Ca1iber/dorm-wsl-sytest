This section describes semi-parallel tests with SmartRDI.

SmartRDI supports semi-parallel tests in three ways:

  • Test suite level
  • Test block level
  • Pattern-based mode
For Test block level and Pattern-based mode, if you use FOR_SEMI_PARALLEL_TEST_BEGIN()/FOR_SEMI_PARALLEL_TEST_END() or RDI_SEMI_PARALLEL_TEST_BEGIN()/RDI_SEMI_PARALLEL_TEST_END(), you must set the following two items under the Site Control of the test suite property in advance:
  • Select the Allow Parallel check-box.
  • Set Site Control to PARALLEL.

Functional changes

  1. Introduced in SmartRDI 2.4.3
