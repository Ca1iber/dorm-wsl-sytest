Topic 353597

SmartRDI 7.10.0

This section summarizes software changes including new features and enhancements in SmartRDI 7.10.0.

Changes and new features
Category Description
General Two functions are added for changing the value specified by the testflow flag variable RDI_INFO_LEVEL:
  • rdi.setInfoLevel(): Set a new debug information level for a block or test suite.
  • rdi.getInfoLevel(): Retrieve the level result value.
Cogo
  • The results of binary, linear, and hysteresis linear searches can be retrieved without pathPin().
DC
  • perSiteVal() specifies a value per site.
  • Both vMeasReturnDrop() and vMeasForceDrop() support UHC4T card.
  • Parallel DC actions on multiple pins.
  • Parallel pulse actions with measurement and sampling.
  • DC waveforms per site.
Func
  • rdi.func().burst() supports multiport burst labels in the pattern‑based mode.
  • rdi.port(TA::MULTI_PORT).func() supports inserting multiport bursts into a new label.
ORE
  • ORE_TEMPLATE_DATA_FILE_SIZE_THRESHOLD can be used to set a threshold for the result size of your ORE template.
  • An ORE template file can be generated with real test results of all sites. See Test results of all sites to the template file.
  • An ORE template file can be generated for each execution. See Generating an ORE template file for each execution.
  • Alarm handling ORE results can be retrieved and an alarm handling ORE result template file can be generated.
  • rdi.startNextOreTemp() can be used to set a separate point between executions so a template file for each execution can be generated.
smartVec
  • The default value of SMV_DIGCAP_AUTO_BURSTUPLOAD is changed from FALSE to TRUE.

Supported SmarTest versions

SmartRDI 7.10.0 supports SmarTest 7.10.0.
