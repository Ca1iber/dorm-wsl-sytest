Topic 106452

Writing a custom redundancy analysis algorithm

You can write your own analysis algorithm to replace the Successive algorithm supplied by Advantest. Advantest provides template files that provide a framework for this purpose.

About this task

If you want to use a redundancy analysis algorithm of your own, customize and compile the templates as described here.

You may want to write multiple variations of the algorithm, one geared for usability to use, for example, in engineering and offline analysis, and one optimized for performance to use in production. Creating multiple versions of the algorithm is optional; you can use the same version for all applications, if desired.

Before you begin

Make sure that you are familiar with writing and compiling C++ programs and with the details of the algorithm you want to implement. Discussing either topic is beyond the scope of this manual.

Procedure

  1. Create a directory for the required program files.
  2. From the /opt/93000mts/rr/include/ directory, copy these file to the directory created in step 1:
    • RaAlgorithmUserDefined.hpp
    • RaAlgorithmUserDefined.cpp
    • Makefile
  3. Open the .cpp and .hpp files and change the class name "CRaAlgorithmUserDefined" to the name of your algorithm.
  4. Implement the functions found as shells in the .cpp file.

    Add functions and data structures of your own in the .cpp or .hpp file as needed. The predefined functions and the changes you need and can make to them are described in the source code file.

  5. Save all source code files.
  6. Compile the algorithm by making the directory created in step 1 the active directory and executing make.
  7. When needed, you can remove all generated file with the make clean command.

Results

The complied algorithm is available as a shared library in the source code directory.

What to do next

Copy the shared library to a suitable subdirectory of the device directory and adjust the Redundancy analysis configuration file as needed. If needed, create a control file and a DUT representation file for your algorithm.
