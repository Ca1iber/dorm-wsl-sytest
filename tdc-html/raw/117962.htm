SCAN_TEST_PIN_RESULT

This class is holds the per-pin result data of a scan test. You cannot directly create an object of it. Its member functions are to be used after the pin() function of SCAN_TEST_RESULT.

Note The SCAN_TEST_RESULT and SCAN_TEST_PIN_RESULT API only support PinScale test system.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ScanTestResult.h.

Class definition

Member functions

SCAN_TEST_PIN_RESULT& failingCycles(const ARRAY_LL& cycles);
SCAN_TEST_PIN_RESULT& expectedData(const ARRAY_CHAR& expected);
SCAN_TEST_PIN_RESULT& receivedData(const ARRAY_CHAR& recevied);

Syntax

SCAN_TEST_RESULT obj(mode);
obj.pin(scanPin).func(param);

where pin(scanPin) is the member function of SCAN_TEST_RESULT and func(param) is one of the member functions SCAN_TEST_PIN_RESULT.
