Topic 102045

MTL compiler directories and file name extensions

This overview describes the installation directories used by the MTL compiler and the file extensions for the various file types it uses.

Installation directories

Directory

Description

/opt/93000mts/mts/mtl/bin

Contains the binary files.

/opt/93000mts/mts/mtl/sh_lib

Contains the shared libraries.

/opt/93000mts/mts/mtl/msg

Contains the error message files.

/opt/93000mts/mts/mtl/93k_import

Contains external shared libraries.

File name extensions

Input files

File type

Extension

Comments

APG pattern file

.apg

 

APG program file

.prog

 

DC event file

.dcev

Optional; needed only for using the DC_Scale testmethod.

Device access file

.dvac

 

Device architecture file

.dvar

 

Pin configuration file

.pin

Optional; required for Automatic waveform generation and Multiport operation. This file is created in SmarTest.

Pin mapping file

.pmap

 

Timing file

.pin

This file is created in SmarTest.

Waveform mapping file

.wmap

Optional; required for Indirect waveform mapping.
Output files

File type

Extension

Comments

Binary APG vector file

.apg.vec

 

APG reconstruction output file

.apg.rec.so

Optional; created when the compiler is run with the -r1 or -r2 options.

Output file

.txt

Optional; created when the compiler is run with the -o option
Other files

File type

Extension

Comments

Pattern file list

Optional. Pattern file list can be saved from the MTL Compiler Control dialog.

Functional changes
