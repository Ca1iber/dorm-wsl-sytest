How to convert legacy memory test pattern

This legacy memory test pattern converter tool mtst2ppss.pl is one Perl script that converts vectors from pre Smartest 7.1 to 7.1+ UMM mode, and eliminates all MTST label definitions and converts the MTST labels calls to corresponding PPSS label calls. The vector file to be converted can have MTST label definitions and calls or purely functional test patterns.

About this task

This task is about converting legacy memory test pattern to Smartest 7.x compatible pattern.

Before you begin

Ensure you have access to the Test Program migration tools.

Procedure

  1. Execute
    /opt/hp93000/soc/prod_pws/migration/MTST2PPSS_conversion/mtst2ppss.pl
  2. Parameters
    • -in {name} specifies the vector file name to convert or the directory name where conversion will execute recursively.
  3. Optional parameters
    • -help prints the usage message and ends.
    • -debug {level} 1 overall info, 2: detailed info for each file, 3: internal execution info.
    • -backup backups the original vector directory or vector file as a new copy with suffix .bak.

Examples

Example 1

mtst2ppss.pl  -debug 3  -in /home/username/sample_device/vectors -backup  | tee  debug_out.txt

Example 2

mtst2ppss.pl   -in /home/username/sample_device/vectors/convert_me.vec  | tee  debug_out.txt

What to do next

Load you converted pattern in the Test Program Explorer.
