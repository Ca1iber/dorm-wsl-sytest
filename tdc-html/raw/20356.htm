Pogo pin assignment

The pogo pin assignment and pad layout on your DUT board is determined by the specific hardware installed in your system. The modular design of the test head allows for many different configurations.

The generations, variants and used SmarTest versions of the V93000 system support different sets of test head cards:
  • V93000 EXA Scale systems (SmarTest 8)
  • V93000 EXA Scale systems (SmarTest 7.10 and higher)
  • V93000 Smart Scale system (SmarTest 8)
  • V93000 Smart Scale system (SmarTest 7)
  • V93000 Pin Scale system
  • V93000 HSM system

V93000 EXA Scale systems (SmarTest 8)

The following pogo pin layouts apply to the V93000 EXA Scale system running SmarTest 8:

  • Analog cards
    • Wave Scale MX pogo pin assignment and model file configuration
  • DC Scale cards
    • AVI64 pogo pin assignment
    • DPS128 / DPS64 pogo cable assemblies and pogo pin assignments
    • UHC4 / UHC4T pogo pin assignment
    • XPS256 pogo pin assignment
  • Digital cards
    • PS1600 pogo pin assignment
    • PS5000 pogo pin assignment
    • PS9G pogo cable assembly, pogo pin layout and model file configuration
    • PSSL pogo cable assembly, pogo pin layout and model file configuration
    • Link Scale USB3 pogo pin assignment
  • Pogo pin assignment - MUX cards
  • RF cards
    • RF Pure Clock pogo pin assignment
    • Wave Scale Millimeter pogo pin assignment
    • Wave Scale PS-PD pogo pin assignment
    • Wave Scale RF pogo pin assignment (10 MHz clock)
    • Wave Scale RF with RFIM-6/RFIM-8 pogo pin assignment
    • Wave Scale RF with RFIM-18 pogo pin assignment
    • Wave Scale Wideband pogo pin assignment
  • Pogo pin assignment - Utility pogo blocks
  • Utility power supplies
    • Internal Utility Power Option pogo pin assignments (V93000 EXA Scale systems)
