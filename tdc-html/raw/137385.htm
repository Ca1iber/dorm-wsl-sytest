SHMOO_RESULT is a predefined instance for the ShmooResultAdapter class. You use this instance to access the member functions of ShmooResultAdapter.

ShmooResultAdapter is used to:

  • Define the results to be displayed on shmoo plots.

    To view the shmoo plots, use the Shmoo Tool or the Integrated Result Tool.

  • Retrieve a test result displayed on a shmoo cell.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ShmooUtility.h.

Syntax

SHMOO_RESULT.mem_func

mem_func is the member functions listed in this chapter.

Parameters

There are no parameters.

Examples

Example 1

View the measured value of a test suite on pin1 and pin2 on a shmoo plot.

void run()
{
  // do a test on pin1 and get the test result as a value
  double resultValue = test result value;
  SHMOO_RESULT.pin("pin1").setResult(resultValue);

  // do another test on pin2 and get the test result as a value
  double resultValue = test result value;
  SHMOO_RESULT.pin("pin2").setResult(resultValue);
}

Example 2

In your customized shmoo test method, define the results to be displayed on a shmoo plot in the UserDefinedMeasure() function.

virtual void userDefinedMeasure()
{
/**
 *Do a shmoo test on site 1, a measured value of all pins will be displayed on each cell of
 *the shmoo plot.
 */
  double resultValue = test result value;
  SHMOO_RESULT.site(1).setResult(resultValue);
  //the test will be named as "result1" by default

/**
 *Do a shmoo test site on the focused site, a functional test result of all pins will be 
 *displayed on the shmoo plot.
 */
  bool funcResult = GET_FUNCTIONAL_RESULT();
  SHMOO_RESULT.testName("funcResult").setResult(funcResult);
}
