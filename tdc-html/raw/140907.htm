Topic 140907

Creating a test table from a test program template

You can create a SmarTest test table from a TPT (test program template) by specifying in the TPT test table which settings you want to include.

About this task

Note This topic describes creating a SmarTest test table (as described in Working with test tables), not an STPM test table (as described in Test table).

Set up the creation of a SmarTest test table when you want to specify test limits and other parameters in SmarTest through test tables.

Before you begin

Create a test program template and fill in the TPT tables.

Procedure

  1. In the TPT test table, set the Source column to "Test table" for all tests that you want to control through a test table.
  2. Save the TPT test table.

Results

When STPM generates a test program (using the tpt_generate_tp command), it will automatically create a SmarTest test table for all tests where "Test table" is the specified source. Likewise, the tpt_add_test and tpt_replace_test commands will update the SmarTest Test table where specified.

What to do next

Generate or update the test program.

Functional changes

  1. Introduced in SmarTest 7.2.1
