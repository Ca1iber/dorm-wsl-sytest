Messages related to Memory Test conversion

During conversion, some messages (warning, error or information) may be reported. Most messages are self-explained. Below are explanations for some messages, which may be not so straightforward.

WARNING: replaced MTST call (xxx/yyy) by JPPS call (xxx_1_llpattern_yyy_0) with assumptions in 'file_zzz'. Please check if it works for you.

This warning message often occurs when converting a separate vector file (.binl), which contains MAIN label definition and MTST label calls, but doesn’t contain corresponding PPSS label definitions. Due to lack of PPSS label definition information, the replacement is done based on some assumption, for example, memory test port number, etc. This works for many cases, but not all cases. So please double check whether it works for your case or not.

WARNING: ppss label ppss_label_xxx in file 'file_yyy' is not compiled for Base-II system, but used in this pattern. Please re-generate this pattern!

Legacy memory test supports both Base-I and Base II systems. Some vectors generated for Base-I system cannot be used directly on Base-II system. In Smartest 7.x, Base-I system is not supported any more, while Base-II system is still supported. This message means the vector file is generated for Base-I system, but potentially it will be used on Base-II system, because the conversion is done on one Smartest version where Base-I system is not supported.

ERROR: ppss label ppss_label_xxx in file 'file_yyy' is not defined. This may cause a pontential problem.

This error message occurs when one PPSS label call is detected in main label, but the label definition is not found in this file. If the PPSS label definition is defined in another vector file and also downloaded, there will be no problem. If not, error will happen.

********Conversion was successful!

This means some valid vector files are converted and no warning or error messages are issued during conversion.

********Conversion was partial successful!

This means some valid vector files are converted and some warning or error messages are issued during conversion.

********Conversion was failed!

This means no valid vector files is converted and some warning or error messages are issued during conversion.

********No conversion needed!

This means no valid vector files is converted and no warning or error messages are issued during conversion.
