GraphException

Class GraphException controls error handling. If an error occurs when using the Data Display API, this class will be sent. Then, you can capture this class and analyze the root cause of the error.

Class definition

Constructor

GraphException(void);
GraphException(const GraphException & ex);
const GraphException & operator=(const GraphException & ex);

Member functions

const STRING_VECTOR & errorTrace(void) const;
void printError(void) const;

Syntax

GraphException obj;
obj.func;

where obj is the object of GraphException and func is a member function of GraphException.

Constructor

GraphException(void);

This constructor creates an object of GraphException.

GraphException(const GraphException & ex);
const GraphException & operator=(const GraphException & ex);

These two constructors create an object of GraphException by copying from another object.

Parameter

ex

The GraphException object to copy from.

Member functions

errorTrace()

const STRING_VECTOR & errorTrace(void) const;

This function traces the origin of the error.

printError()

void printError(void) const;

This function prints an error information into stderr.

Example

try 
{
  GraphManager * graphManager = GraphManager::getInstance();
  vector<int> identifiers = graphManager->getGraphIds();
  int size = identifiers.size();
  // Close all existing waveform display areas
  for (int i = 0; i < size; i++)
  {
    graphManager->deleteGraph(identifiers[i]);
  }

} 
catch (GraphException & e) 
{
  e.printError();
}
