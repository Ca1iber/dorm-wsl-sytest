Topic 142962

Importing test time files to view

About this task

Using the Test Time Utilities, you can import and view test time files of the following types:

  • TP360 test time files

    For information about generating this file, see Measuring test time.

  • Data log files, which can be of the following types:
    • Debug mode 3 file.
    • Event data log file.
    • Test time csv file from event data log.
  • Online system event data log stream when executing a testflow.

Procedure

  1. Open TP360 and launch Test Time Utilities from the App Center tab.
  2. Click the Manage Test Time tab and select the Import test time button.

    The Import file(s) window opens:

  3. In this window, select the format of the time file to be imported and click Next.

    The available formats are:

    • TP360 report.
    • Debug mode 3 file.
    • Event data log file.
    • Test time csv file from event data log.
    • System event data log stream.

      If you select the format of 'Debug mode 3 file', 'Event data log file' or 'Test time csv file from event data log', the 'Calculate MSE by importing reference single/multi site test time' option is active. Selecting it, calculates the MSE value, which is output to the Report view.

  4. On the opened window, click the button and select the file to be imported.

    In this window, if you select the "Bind test time with current test program" option, the report to be displayed in the Report view is saved to:

    <device_pah>/TP360_Reports/TTM_Reports

    If you do not select this option, the report is saved to:

    /temp/.vda/<host_name>/TTM/tmp/TP360_Reports/TTM_Reports

    Note Note the following:
    • If you have checked the Calculate MSE by importing reference single/multi site test time option in step 3, you must select both a single site file and a multisite file from this window.
    • If you have selected the 'Test time csv file from event datalog' format and checked the Calculate MSE by importing reference single/multi site test time option in step 3, in this window, you must select a single site file, a multisite file, and specify the multisite count.
    • If you have selected the "TP360 report" format in step 3, after you click the button in this window, the existing TP360 test time reports of the current loaded device are listed in a table for you to select. You can also select another TP360 test time report in a different directory.
    • If you have selected the "System event datalog stream" format in step 3, TP360 collects the online test data when you execute a testflow, and displays the event data log in the Report view.

      Note that before running the testflow, you must enable the log_events_enable flag and clear data logs displayed in the ui_report window as illustrated in the following screenshot:

  5. Click the Finish button.

    The importing starts.

Results

The imported test time file is displayed in the Report window.
