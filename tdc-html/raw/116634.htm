Topic 116634

Replacing failed state characters for golden device

To debug a test program you can apply a pattern to a so-called "golden device" (reference device).

About this task

To apply a pattern to a golden device, you debug a pattern in expanded mode, and use the Replace Failed State Characters dialog wizard on a selected range of pins or vectors.

Note that this function is supported by the pattern editors and the port burst pages of the multiport burst editor, but not by the sync group pages of multiport burst editors.

Before you begin

SmarTest must be running online.

You must have executed a test on a so-called "golden device", which showed up failures.

To display the results and the failed state characters, the pattern editor must be in expanded mode. See Displaying failure data.

Note The replacement works per pattern and on state characters only.

Procedure

  1. Configure the pattern layout to show state characters (SC) only. See Configuring the layout of the Pattern Editor.
  2. In the pattern editor select one or more pin columns, cycle rows, or an area of state characters.
  3. In the main menu click Pattern > Replace Failed State Characters. The dialog wizard opens.

    On the Scope tab the dialog displays the previously selected cycle range, and the failed pins within your selection.

  4. You may add pins to the list of Selected Failed Pins, or remove pins.
    • To remove a pin, select it and click Remove.
    • To add a pin, click Add.

      This opens the Pin Selection dialog, which allows to add or remove pins, or to modify the sequence of selected failed pins. On the left, the Pin Selection dialog shows all failed pins, on the right the currently selected failed pins. When done in the Pin Selection dialog, click OK. The Scope Definition shows the modified list of selected failed pins.

  5. You may change the mapping.

    A mapping is a failing state character, its replacement character, and the selector. In most cases you will accept the proposal.

    • To change the mapping, open the Mapping tab. You may either modify the proposal, choose a different mapping, or define a new mapping.
    • To modify the proposal, click any of the values (except in the Selector column) and type the new value. Pressing Ctrl+Spacebar activates the content assist (See Pattern Editor quick reference).
    • To choose a different mapping, open the pull down menu next to the Mapping Name box, and select another mapping.
    • To create a new mapping definition click New and specify the new mapping and a mapping name in the Define New Mapping dialog. (see below).
    • To accept the new mapping click OK.
  6. In the Replace Failed State Characters dialog, in the "Mapping Per Pin" pane, you can select any newly defined mapping for each selected failed pin.
  7. To accept the replacement, in the Replace Failed State Characters dialog, click OK.

    This starts the replacement of failed state characters according to the current mapping. A progress bar appears if the operation takes longer.

Results

All expected state characters are changed according to the given mappings.

To see the previous state, for example for comparison, you must reload the old pattern file.

What to do next

Repeat the debugging test, especially in case of a limited error map.
