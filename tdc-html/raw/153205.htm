Routing Tools (SmartRDI)

The Routing Tools feature native multisite handling, user friendly table based configuration editors and a unified programming interface for controlling utility lines and MUX card switches. The Routing Tools are a part of the SmartRDI (Rapid Development Interface).

The Routing Tools are a combination of the Routing Tools editors and the rdi.route() class of SmartRDI. The Routing Tools editors, are the central place for configuring the handling of utility lines and MUX card switches and for defining complete states that are applied by SmartRDI class rdi.route().
