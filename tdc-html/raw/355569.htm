Topic 355569

rdi.alarm().getEnabledPins()

Gets back the list of enabled alarm handling pins.

getEnabledPins() must be used inside an RDI_BEGIN()/RDI_END() block.

Syntax

string.getEnabledPins();

Example

rdi.alarm().applySet(alarmSet)         // Assume pinA to pinF are enabled for alarm checking.
rdi.alarm().pin("pinF").enable(false); // pinF is disabled

RDI_BEGIN();
  rdi.alarm().pin("pinA").enable(false);              // pinA is disabled
  rdi.dc().pin("pinB").iClamp(-1 uA, 1 uA).execute(); // pinB is disabled by Ith
  string pinList = rdi.alarm().getEnabledPins();      // pinList "pinC, pinD, pinE"
  rdi.alarm().enable(false);                          // pinC to pin E are disabled
  ...
  rdi.alarm().pin(pinList).enable (true);             // pinList "pinC, pinD, pinE" enabled

RDI_END();

Related information

rdi.alarm().pin().enable()

Functional changes
