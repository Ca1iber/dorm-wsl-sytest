Selecting an Execution Input

The Execution Input is the user-definable interface to data coming from the production process. This data can be, for example, ID's or other numbers that are only available at run-time.

  1. In the Test Program Explorer highlight the item Execution Input.
  2. Right-click and select Load... . All available execution input files appear in a browser window.
  3. Highlight your desired execution input file, and click OK.
