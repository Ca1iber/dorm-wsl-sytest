DRLPinGroupIndexToPins

DRLPinName *DRLPinGroupIndexToPins (unsigned short index, unsigned *number_of_pins)

This function allows you to get a list of the names and DC/DC power units of all pins in the pin group with the index index.

Return Value

The function returns a pointer to an array of pin names (see DRLPinName). The variable number_of_pins holds the number of pin names in that array, that is, the number of pins in the group with the index index.

If the provided index is invalid, the function returns NULL, and number_of_pins is 0.

Functional changes

  1. Introduced before SmarTest 6.3.2
