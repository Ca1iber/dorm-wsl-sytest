Setting parameters for the ExecutionEngine test method

Subtopics

  1. Parameters for the ExecutionEngine test method

To edit the parameters of a test method:

  1. Select it in the tabular editor.

    The parameters of the test method are displayed in the Test Suite window:

  2. Double-click the parameter that you want to edit and enter a new parameter (by typing it or by choosing it from a pop-up, depending on the type of parameter).

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. MTP 3.0.1: Parameters are now set in the Test Suite window.
  3. MTP 3.2.2: Adds a new parameter: bitmap_file_name.
