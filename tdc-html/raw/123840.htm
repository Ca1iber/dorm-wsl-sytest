Configuring wait parameters

About this task

This task describes the modifications of the wait parameters you need to carry out in your protocol file, for example d2sJTAG.h .

Before you begin

Rename the d2sSerialProtocolTemplate.h template to reflect your protocol, for example d2sJTAG.h .

Configure the general parameters as described in Configuring general parameters.

Configure the write parameters as described in Configuring write parameters.

Configure the read parameters as described in Configuring read parameters.

Procedure

  1. Keep the timing port template ('@') if you use a single port setup with our wait template pattern, else replace it with the port name that matches your setup.
    Note The number in brackets() refers to the corresponding number in the figure below.
  2. Replace the wait template pattern name to match your wait template (1).

Example

The above modifications are highlighted in bold in this d2sJTAG.h file example.

#ifndef D2SSERIALPROTOCOLTEMPLATE_H_
#define D2SSERIALPROTOCOLTEMPLATE_H_
#include "d2s_Serial.h"

class d2sSerialProtocolTemplate : public d2s_Serial{
private:
    d2sJTAG(std::string pName):d2s_Serial(pName){};
    d2sJTAG(const d2sJTAG&);
    d2sJTAG& operator= (const d2sJTAG&);

public:    
    //singleton
    static d2sJTAG& Instance(){
        static d2sJTAG instance("my_d2sPort");
        d2sJTAG& ref = instance;
        return ref;
    }
    
    /*general parameters*/
    int getAddressBits(){ return 6;}
    int getDataBits(){ return 16;}
    int getHighWaveformIndex(){ return 1;}
    int getLowWaveformIndex(){ return 0;}
    int getHighStrobeWaveformIndex(){ return 3;}
    int getLowStrobeWaveformIndex(){ return 2;}
    int getMaskStrobeWaveformIndex(){ return 4;}
    std::string getInterfaceName(){ return "my_PA";}
    std::string getPatternStoragePath() { return "d2s/my_sbiA"; }


    /*write parameters*/
    std::string getWriteTemplatePatternName(){ return "d2s_simple_write_templ";}
    std::string getWritePinName() { return "di_A";}
    int getWriteAddressVectorNumberLSB(){ return 8;}
    int getWriteAddressVectorNumberMSB(){ return 3;}
    int getWriteDataVectorNumberLSB(){ return 24;}
    int getWriteDataVectorNumberMSB(){ return 9;}

    /*read parameters*/
    std::string getReadTemplatePatternName(){ return "d2s_simple_read_templ";}
    std::string getReadAddressPinName() { return "di_A";}
    std::string getReadPinName() { return "do_A";}
    int getReadAddressVectorNumberLSB(){ return 8;}
    int getReadAddressVectorNumberMSB(){ return 3;}
    int getReadDataCycleNumberLSB(){ return 24;}
    int getReadDataCycleNumberMSB(){ return 9;}
    int getReadDataVectorNumberLSB(){ return 24;}
    int getReadDataVectorNumberMSB(){ return 9;} 
    
    /*wait parameters*/
    // step 1
    std::string getTimingPort(){ return "@";}

    // step 2
    std::string getWaitTemplatePatternName(){ return "d2s_simple_wait_templ";}
};

#endif
