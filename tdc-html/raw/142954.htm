Installing TP360

The TP360 installation package is a standard RPM file. Ask an ADVANTEST application engineer for an installation package.

About this task

Note Log in as root so that you can access the RPM database on your workstation.

The installation is the same as you install any other rpm files with the rpm commands.

Before you begin

Make sure you are using:

  • SmarTest 7.10.x respecting the rules described in SmarTest Prerequisites.
  • The "S&S_tools_package" license.

You can use the FLEXlm licensing to manage the usage of licenses.

After installation, by default, TP360 exists in the /opt/hp93000/TP360 directory.

To install TP360 into a different directory, use the "--prefix" option for the rpm command.

To learn more options of the rpm command, refer to the RPM documentation (for example, the "man-pages").

Procedures

Installing a TP360 package

  • To install a TP360 package:

    rpm -ivh TP360 package name

    For example, rpm -ivh v93000-TP360-3.3.0.noarch.rpm

  • To force to install a TP360 package when the old versions exist:

    rpm -ivh --force TP360 package name

    For example, rpm -ivh --force v93000-TP360-3.3.0.noarch.rpm

Removing a package

To remove a package:

rpm -e TP360

Displaying package contents

To see the contents of a package:

rpm -q -i TP360
