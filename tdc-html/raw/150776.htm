Map converter library

Subtopics

  1. get_ra_layout()
  2. phys_to_layout()

When you set up the map converter library, make sure the library contains the required functions. If the functions do not exist, add them and recompile the library. For more information about recompiling the library, see Setting up address scrambling.

The required functions are:

  • get_ra_layout and phys_to_layout for the RA_LAYOUT_BASED type.
  • get_map_size and phys_to_map for the TOPO_ADDR_BASED type.
