TIMING_OFFSET_SEARCH_PINS.edgeType()

This function sets the edge type for the timing offset search.

Syntax

TIMING_OFFSET_SEARCH_PINS& edgeType(TIMING_OFFSET_SEARCH::EDGE_TYPE etype);
Parameter

etype

The edge type. It can be:

  • TIMING_OFFSET_SEARCH::RECEIVE: receive edges
  • TIMING_OFFSET_SEARCH::FAST_DRIVE: fast drive edges
  • TIMING_OFFSET_SEARCH::SLOW_DRIVE: slow drive edges
  • TIMING_OFFSET_SEARCH::DRIVE: drive edges
  • TIMING_OFFSET_SEARCH::ALL_EDGES: all edges

Functional changes

  1. Introduced in SmarTest 7.0.1
