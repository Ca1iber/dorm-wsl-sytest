Instructions for changing the setup

Subtopics

  1. Changing the timing set (CTIM)
  2. Changing the level set (CLEV)

With the CTIM and the CLEV instructions, you can change the timing, respectively level setup during a test. These changes are global with respect to the current test; if you change the setup in a subroutine, the change remains valid after return to the calling routine.

Functional changes

  1. Introduced before SmarTest 6.3.2
