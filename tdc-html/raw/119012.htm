How to insert a snippet in the test method

You can insert the snippets in the test method through Content Assist.

Before you begin

The snippet to be used exists in your Templates page of the Preference window and is checked on.

Procedure

  1. In the test method editor, type in the first several letters of the snippet and press the key Ctrl + Space. A list of snippets started with the letters you typed in will be displayed.
  2. Highlight a snippet in the list. You will see the content of the snippet as in the figure below.
  3. Double click the snippet you want to use in the list. The code of the snippet will be inserted in the test method.
