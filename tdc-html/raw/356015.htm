Topic 356015

Definition of terminations in the level file

The table below shows the correlation between the keywords used to define various termination types in the level file and in the level setup editor.

Note FAST mode is a pre-release version on SmarTest 7.10.3 and has been enabled only for evaluation purposes.

For the "i' pins (driving to the DUT), no term definition is necessary as the driver terminates the DUT automatically.

For "io" pins which are only applicable to std mode, use the level setup editor keyword term which corresponds to "term on" in the level file.

Note that the keywords are different depending on whether you use the level setup editor or enter the definitions directly into the level file.

The examples below illustrate the effect of defining different resources in the level file.

Example

  1. The keyword off will be displayed in the Level Setup Editor.

    <eqn file excerpt for std mode with no termination resource definition>...

    LEVELSET 1 "no_term"
PINS p1 p2
vol = VOL
voh = VOH
...
  2. The keyword term will be displayed in the Level Setup Editor.
    <eqn file excerpt for std mode with vt resource definition>…
    LEVELSET 2 "implicit_term"
PINS p1 p2
vt = VT # this will implicitly set term to "term" in the GUI
vol = VOL
voh = VOH
...
  3. The keyword load will be displayed in the Level Setup Editor. Note that the active load circuit cannot be used in the FAST mode.

    <eqn file excerpt for std mode with iol (active load) resource definition>...

    LEVELSET 3 "implicit_term"
PINS p1 p2
ioh = 1.3
iol = 0.5 # this will implicitly set term to "load" in the GUI
vol = VOL
voh = VOH
...

The settings in the Level Setup Editor temporarily override what is specified in the level setup file. There is no option to save these temporary changes to the setup file for equation-based setups. For example, if there are no term-related resources specified in the level setup file (i.e., no term mode is set implicitly), the Level Setup Editor will display off in the term mode column.

If you then set the term mode to term in the Level Setup Editor, the level setup file will not be changed, but the Level Setup Editor will temporarily override what was specified in the level file, and the hardware will be set for a term type of termination.

If you want to make a permanent change you must do so in the level setup file itself.

For an example of a level file containing the term definition, see the level setup shown in the figure in Context "Differential" in Definition of contexts in level file, where a center tap termination has been defined with the keyword term center_tap. Note that Selecting ctrtap in the Level Setup Editor window would give the same termination.

Functional changes

  1. Introduced in SmarTest 7.10.3
1) The word "off" is displayed if, in std mode, no term keyword has been defined in the level file. If, however, in std mode you do not define a term keyword in the level file, but specify a value for one of the std mode termination resources, then the Level setup editor will display a corresponding keyword. For example, if you define a vt value (to get a 50 ohm termination on std "o" pins), then the word term will be displayed here.
