Wafer prober interfaces

Subtopics

  1. Direct-Probe interface
  2. 9.5" and 12" wafer prober interfaces (WPI)

The wafer prober interface is the mechanical and electrical connection between the test head and the wafer prober.

Direct-Probe™ wafer prober interface

Supported V93000 systems : Pin Scale, Smart Scale, EXA Scale
Key elements of the Direct-Probe™ wafer prober interface are
  • the Direct-Probe™ probe card that connects to the pogo pin blocks of the test system on one side and holds the wafer probes on the other side and the
  • bridge beam that locks the probe card to the prober head plate.

The Direct-Probe™ wafer prober interface is designed for "Technology driven" applications like Wireless, WLCSP, MPU and GPU devices. It is the solution for advanced packaging applications (10/7nm), high pin count devices and high number of parallel sites.

The solution provides a highly accurate and rigid mechanical design for a contact force up to 300 kg with superior planarity, improved XY repeatability and high-performance signal integrity for functional test at wafer stage.

9.5" and 12" wafer prober interfaces (WPI)

Supported V93000 systems : Pin Scale, Smart Scale
Not supported in EXA Scale systems.
The key elements of the 9.5" and 12" wafer prober are
  • the DUT board with its stiffener,
  • the pogo tower and
  • the probe card with its stiffener.

The solution is suitable for high-power applications and large components on the DUT board or probe card, This type of wafer prober interface provides better access for external instruments and has an initially significant cost advantage.

Functional changes
