CYCLE_CHUNK

A special data structure that is defined to contain an uploaded chunk of the start tester cycle and a sequence of error map edge results.

Syntax

typedef struct 
{
long long cycle;
std::vector<char> edges;
} CYCLE_CHUNK;
Variables

Variable

Description

cycle

Start tester cycle.

edges

A sequence of edge results.

Related information

SMC_PIN_ERROR_MAP.getNextCycleChunk()

Functional changes

  1. Introduced in SmarTest 7.2.1
