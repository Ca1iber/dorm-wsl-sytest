CMVC - (Clear and MoVe Comments)

The CMVC (Clear and MoVe Comments) command serves to

  • move comments when new device cycles are inserted into a label in the Vector Table
  • to delete comments from a certain range of vectors.

Predependencies

CMVC can only be issued after the label which is to be edited has been activated with the TSTL command.

Mode of operation

The comments located in the range src_vec_No to src_vec_No + vect_length - 1 are moved to dst_vec_No to dst_vec_No + vect_length - 1. Any comments located between the source and destination ranges are deleted.

Syntax

CMVC {src_vec_No}, {dst_vec_No}, {vect_length}

Parameters

src_vec_No

The logical vector number that determines the start of the source range.

dst_vec_No

The logical vector number that determines the start of the destination range.

vect_length

The vector range from which comments are to be moved. Specify 0 in order to simply delete the vectors between the source and the destination number.

Application

Edit command in Pattern Tool.

Errors

An error is generated if the logical vector addresses are out of range.

Example

> CMNT? 0,6
< CMNT 0,"0"
< CMNT 1,"1"
< CMNT 2,"2"
< CMNT 3,"3"
< CMNT 4,"4"
< CMNT 5,"5"
> TSTL "test_1",(@)
> CMVC 0,4,2
> CMNT? 0,6
< CMNT 4,"0"
< CMNT 5,"1"

This example moves comments in the vector range 0 to 1 to the range 4 to 5. The previous comments for vectors 4 and 5 are overwritten, the comments for vector 2 and 3 are cleared.
