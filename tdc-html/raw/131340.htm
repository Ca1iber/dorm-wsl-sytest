The MTP_LEAKAGE_PIN_TASK class is a data container holding the leakage measurement setup data performed with the MTP_LEAKAGE_TASK API. It is used by the pin() member function.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/MTP_LEAKAGE_PIN_TASK.h.
