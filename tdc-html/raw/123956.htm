Migration GUI Framework

The graphical user interface of the Test Program migration supports you during migration of Test programs from SmarTest 6.5.X to 7.1.0. It supports hardware transition from PS400/PS800/PS3600 to PS1600. The basic workflow will guide you through the migration process.

First you will screen a specific testflow or test program, including its relevant setup files like pin configuration, timing, level and vector setup files. The migration tool will list potential migration items in the "Migration Items View", show the detail information and provide possible resolution.

In a second phase, you will load and execute your testflow or test program. The relevant migration gap will be captured by the framework listener and display in the "Migration Items View" as well. It is consistent with the screener method to provide the resolution description, conversion tool and TDC document support as well.

Functional changes

  1. Introduced in SmarTest 7.1.0
