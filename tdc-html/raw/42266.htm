Function: ph_lot_start

This function assures that a new lot is available, before the next command in the application model is executed. The implementation of the function depends on the plug-in. For example, the function wait for the prober to report that a new lot is ready to be tested.

Applicable for: prober driver, handler driver

Example: PROB_HND_CALL (ph_lot_start)
