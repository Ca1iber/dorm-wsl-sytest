Utility Purpose Editor reference

  • Site: The site for which the configuration is being displayed.
  • Utility Lines: The list of all available utility lines. Lines with a check mark in front of them are part of the utility purpose.
  • Utility Members: A list of the lines in the utility purpose together with their desired states (0, 1, or X for "Do not care")
  • X, 0, 1: Clicking these buttons sets the state for selected lines.
  • Settling Time: The waiting time after a write action. The same settling time applies to all sites.
