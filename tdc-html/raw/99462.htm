Assigning values to variables

About this task

There are two possible ways to assign values to variables:

  • Enter the desired values on the Variables page.
  • Use Assign Value nodes in the testflow (described below). This changes the current value of a variable.

Before you begin

Make sure that the variable to which you want to assign a value has been defined.

Procedure

  1. In the Flow Sequence Editor, insert an Assign Value node into the testflow. The Assign Value Dialog window opens.
  2. From the Variable list, choose the variable to which you want to assign a value.
  3. Enter the desired value in the Value text box. (String values have to be entered in quotes, like "String".)
  4. Click OK.

Results

The Assign Value node appears in the testflow displaying the variable name. Whenever the testflow passes this node, the specified value is assigned to the indicated variable.
