Topic 102285

Data Bridge

Subtopics

  1. Selecting a Data Bridge

The Data Bridge item in the Test Program Explorer is used to select a Data Bridge directory (or Command Set).

This directory (or Command Set) contains a data-formatting routine that accesses generic data format files and converts them in to other formats (for linking to data bases or statistical analysis packages, for example). The data in these files is determined by the application file, and flags set in the testflow.

Note To use a library generated on 32-bit system for a 64-bit system or vice versa, you need recompile the source code to generate the library for the new system.
