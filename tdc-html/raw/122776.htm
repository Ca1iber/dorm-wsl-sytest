Pattern per site (Label per site)

Subtopics

  1. How to execute separate patterns per site (Label per site)

The label per site feature allows you to associate different sites with different start labels (patterns). In this way you can execute different tests on different sites in parallel. This can be useful, for example, for trimming tests, where every site may have to be given a different signature.

You can make use of this feature on the firmware level (see SQSL, SQSL? - (SeQuencer Start Label) in the command reference manual) and on the test method level.

The following section How to execute separate patterns per site (Label per site) describes this feature.

Functional changes

  1. Introduced in SmarTest 6.5.3
