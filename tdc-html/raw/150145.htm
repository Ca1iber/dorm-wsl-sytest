EVENT_CFVM.cForce()

Sets the force current.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

EVENT_CFVM & cForce(const EVENT_VALUE_DOUBLE & value);
Parameter
Parameter Description
value

Defines the force current in A (Ampere) to be set.

Return value

A reference to the corresponding EVENT_CFVM object.

Example

For an example see EVENT_CFVM.
