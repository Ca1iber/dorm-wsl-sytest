GDDR5 Training test method

The GDDR5 Training test method combines the previous five test methods, allowing you to apply them in one step instead of individually. You can configure the GDDR5 Training test method using a set of parameters that are explained below.

Additional parameters as well as defaults are configured in the GDDR5 training configuration file.

Parameters for the GDDR5 Training test method

Name

Options and values

AddressTraining

Enable or Disable. Switches address training on or off.

Default value: Enable

AddressTraining.TrainingAlgorithm

This is the TrainingAlgorithm parameter of the Address Training test method.

AddressTraining.SweepStart

This is the SweepStart parameter of the Address Training test method.

AddressTraining.SweepStop

This is the SweepStop parameter of the Address Training test method.

AddressTraining.PinOffsets

This is the PinOffsets parameter of the Address Training test method.

AddressTraining.EdgeCentering

This is the EdgeCentering parameter of the Address Training test method.

AddressTraining.VectorLabel

<label>. The name of the vector label to be executed for the address training. If it is left empty, the vector label is taken from the primaries.
