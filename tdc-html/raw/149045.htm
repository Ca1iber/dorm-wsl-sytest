fillBit()

Writes bit data to a pattern.

Syntax

fillBit(int bit,int bitLength,int startBit);
fillBit(const string bit,int bitLength,int startBit);
List of parameters

Parameter

Description

bit

The bit or string that you want to write to the pattern.

bitlength

The length of the bits to be filled.

startBit

The starting position of the bit to be written. If you do not specify a starting position, the default value is 0.

Example

RDI_BEGIN();
  rdi.smartVec().pin("DATA1").fillBit(1,4,2).execute(); // index
RDI_END();

Supporting a string

RDI_BEGIN()
  rdi.smartVec().pin("A").defaultBit(0).fillBit("p",4,1)
                         .xMode(2).bitLength(6)
                         .execute();
RDI_BEGIN();

You must define device cycles in the corresponding wavetable.
