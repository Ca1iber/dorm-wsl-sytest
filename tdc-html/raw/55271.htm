Topic 55271

How to set up a multiport timing specification

Subtopics

  1. Global and local spec values (scope of the spec variable)
  2. Spec Searches from Spec Tool
  3. Timing Sequencing Groups
  4. How to Synchronize Port Phases

The specification combines the port-specific timing setups (port-specific equation sets and port-specific wavetables) to a complete timing setup of the device, and defines spec values for the spec variables declared in the equation sets.

About this task

To create a multiport specification, you can utilize common specification settings.

Procedure

  1. From the Timing Setup window, open the SpecTool window.
  2. On the menu, click Change > Create Multiport Specification.

    The Create a multiport timing specification window opens.

    Note Defined Ports lists the ports in a specific order. This order is of importance when SmarTest will be used for automatic assignment of port periods through the selection of a period_res.
  3. On Defined Ports, select the ports you want to assign to the specification.
  4. In Specification Name, type a name.
  5. Click Create.

    SmarTest creates the new multiport specification.

    The Spec Tool shows the specification page for a multiport setup.

    Wavetable shows the first wavetable defined in the wavetable setup (default).

    Equation shows equation set 1 (default).

    Note If SmarTest does not show this page: On the menu, select Display > Show Equation Info.
  6. Adapt the ports:
    1. In the Port List, click a port.
    2. Select an equation and a wavetable set.

      The Name column shows all spec variables declared in the selected equation set.

    3. In the Actual column, assign a value to a spec variable and click run.
    4. Repeat the above for every port.
    5. Specify the scope of the Spec variable (Global and Local Spec Values). For every spec variable you specify the scope per port.
    • To specify the scope of a variable as global. in the column Scope type g.
    • To specify the scope of a variable as local. in the column Scope type l.

      Once the data is entered in the newly generated multiport specification, the data needs to be downloaded for temporary use and saved through the timing file for permanent use.
