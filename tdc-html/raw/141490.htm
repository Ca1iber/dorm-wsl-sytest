MTP_MEMORY_PORT.getMemoryPatternNamesList()

Retrieves the names of the memory patterns (per pin subroutines generated by the MTL compiler) in the current port.

The port is specified with the getMemoryPort() function of the MTP_MEMORY_TEST class.

Syntax

LONG getMemoryPatternNamesList(STRING_VECTOR& pattern_names_list);
Parameter

Parameter

Description

pattern_names_list

A vector used to store the names of the memory patterns in the specified port.

Return value

Returns the number of the retrieved pattern names.

Related information

MTP_MEMORY_TEST
MTP_MEMORY_TEST.getMemoryPort()
