Signal return paths

In general, the signal return paths for DC/low speed signals are different from high-speed signal return paths.

High-speed signals follow the path of least inductance, and the DC/low speed signals follow the path of least resistance.

  • For DC/low speed signals, ground planes offer a path of least resistance by allowing the return currents to flow in wide, arc-like patterns on their way back to the source.
  • For high-speed signals, the path of least inductance tends to be directly under the signal conductor.

When designing a DUT board for very low currents, you want to minimize any ground noise sources. So the paths for the signal and ground lines should be designed like the ones for high-speed digital.
