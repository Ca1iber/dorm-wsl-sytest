Topic 34862

Installing and starting a user-written data retrieval process

Subtopics

  1. Data retrieval programs
  2. Data retrieval functions

Data retrieval works as an independent process which automatically attaches to the system's shared memory and to the data log stream or data log file, respectively. You can implement data retrieval as a program or a function and accordingly run it in several ways:

  • A data retrieval program, like the example of a yield monitor provided in Example (yield monitor), can be started directly from the command line.
  • If the data retrieval was implemented as a program command set or a function command set it, can be called from the application model.

    For further information on how to implement function command sets and program command sets, see the manual Command Reference and the V93000 User Training. These also explain how to direct retrieved data log data to the report window.

For information on the essentials of the different data retrieval implementation methods, see:

  • Data retrieval programs
  • Data retrieval functions
    Note Be sure to always include the header file drl.h for the data retrieval library (#include "drl.h").
