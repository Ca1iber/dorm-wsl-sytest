Topic 30755

FILE_INPUT

Subtopics

  1. Associated Syntax Entities

Reads the content of a file into a parameter. This parameter must be a valid file name. It is used, for example, in the wafer_auto application model file to get the list of wafers from the /tmp/ directory;

cassette_list = FILE_INPUT (/tmp/{Lot_id}.waf_list);

The wafer list file is in the format below. The line starting with # will be skipped. The line starting with -- is a comment line. Each of the other lines represents a wafer to be tested. If the application model file uses the data defined in the wafer list file via ELEMENT_OF_PARAM_LIST keyword, the corresponding application model variable must have the same data type (specified by REGEXP keyword) as the data in the wafer list file.
