Extended Variable Support

Several limitations on using variables have been removed and variables in loops can now behave in line with standard C practice:

  • You can now use variables in statements assigning values to themselves. For example, a statement like myVar = myVar + 1 is now legal.
  • Optionally, variables in loops now keep their values from one iteration to the next, as in standard C. Previously, each variable used in a loop (except for the loop variable itself) would be reset at the beginning of each iteration to the value it had during the first iteration.

    If you want to activate the new behavior for a particular application, compile it with the -evs compiler option.

    Note that there has been a late change to this behavior that could not be incorporated into the main documentation any more. The documentation therefore states erroneously that the new variable behavior is the default and a compiler switch (-lvs) is required to return to the old behavior. We regret any confusion that may arise from this.

  • Variables can now be used multiple times in one expression. For example: var1 = var2 + var2.

Benefit

You can use variables now much more like they are used in standard C. Also, advanced techniques like diagonal patterns with scrambling become possible.
