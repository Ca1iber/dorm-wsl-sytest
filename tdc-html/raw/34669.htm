Topic 34669

ConfigurationChangedEventType

An event of this type is logged whenever a new pin configuration file is downloaded to the tester.

Attributes

  • TimeStampAttrType

    Holds the time when the pin configuration was downloaded.

No public attribute types are used. The data of an event of this type is a list of all pins specified in the downloaded pin configuration file. This data is only used internally and is essential for correctly mapping pin indexes to pin names (see DRLPinIndexToName). You cannot directly access this data, as you can data stored in other attribute record bodies.

Note How the DRL handles an event of this type: Even if the event is masked by the current event mask, the pin list is stored locally by the DRL. This is necessary to correctly map pin indexes to pin names (see DRLPinIndexToName).

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.3.5.3: New attribute TimeStampAttrType
