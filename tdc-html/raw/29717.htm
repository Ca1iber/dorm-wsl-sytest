Topic 29717

SET_SYSTEM_FLAG

This API sets the specified system flag to a particular value.

Note Change of any flag state will be valid when the next testsuite is executed. Use this API with this point in mind.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

SET_SYSTEM_FLAG(const STRING& flag, INT value);
Parameters

I/O

Parameter

Description / Range

I

flag

A system flag name. For more details, see Important Points in GET_SYSTEM_FLAG.

I

value

An integer value for the specified flag.
Note There are several read-only flags which cannot set these flags by using the SET_SYSTEM_FLAG API. See GET_SYSTEM_FLAG.

Example

SET_SYSTEM_FLAG("datalog_formatter",1)

The SET_SYSTEM_FLAG API sets the datalog_formatter flag to 1 ("on").

Functional changes

  1. Introduced before SmarTest 6.3.2
