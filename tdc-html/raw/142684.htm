Memory Pattern Validation tool enhancements and updates

  • One click synchronization of program browser and report window.

    For more information refer to Synchronize program browser with report window.

  • Support of padding instructions.

    For more information refer to Inspect padding events.

  • The actions menu items are renamed and enhanced. Now Unroll inner and outer for-loops are supported.
  • Unroll inner and outer functions
  • Display non-selected code in both the report and browser window.

    For more information refer to Non-selected code.

  • New field to enter compiled cycle number and a show button.
    Note MPVT becomes obsolete in MTP 7.5.0, MTP 7.4.5, and future versions.
