Topic 44924

Command Set Message File

MsgGetMsg is a function that allows you to define and use a local catalog file as part of a Command Set. When you use it within a program, messages may be changed or modified without further code changes.

char *MsgGetMsg(long label)

Example

  1. Create the messages/string lines in any text file using the format as described by the gencat Linux command:

    file myfile.msg

    2001 this is message 2001

    2002 this is message 2002

  2. Generate the message file using the command:

    /opt/hp93000/soc/prod_env/lbin/install_cs -m myfile.msg

  3. Messages in the catalog file may now be accessed with the MsgGetMsg routine, for example:

    fprintf(stderr, "%s", MsgGetMsg(2001));

    generates the string this is message 2001 on the report window.

    You might also find it useful to refer to the Linux man pages for catopen, catclose and catget.
