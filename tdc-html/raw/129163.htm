SHARED_CONTINUITY_TEST.pinCross()

The pinCross() member function of SHARED_CONTINUITY_TEST lets you specify the cross-terminated pins, pin groups that are to be measured.

Syntax

SHARED_CONTINUITY_TEST& pinCross(const string& pinlist)

Parameter

Description

pinlist

The list of the cross-terminated pins, pin groups to be measured.

Separate entries with commas.

 

Example

SHARED_CONTINUITY_TEST mTEST;
mTEST.pinCross("Clock_Bus");
mTEST.pinCross("Clock_Bus1,Clock_Bus2");

Related information
