To test under driver sharing, MTP offers both the ready-made test methods and APIs. When you Do not want to use the ready-made test methods, you can use the APIs to create your own custom test methods.

The MTP software package includes an RPM package (solution_tools) that contains the shared library libMTP_SolutionTools.so with the ready-made test methods that you can use in your test flow to test devices in a driver shared environment. The library also provides access to the DriverSharing classes, which contains the driver sharing APIs.

Advantest also provides fd_merge, a tool that helps you to handle fixture delay files. This is also contained in the solution_tools directory.
