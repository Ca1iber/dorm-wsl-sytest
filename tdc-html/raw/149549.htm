Topic 149549

Global variables

Subtopics

  1. setGlobalVar()
  2. getGlobalVar()

SmartRDI provides global variables to share values across test suites.

SmartRDI includes two functions to handle these variables:

  • setGlobalVar()
  • getGlobalVar()
To call a global variable command in the SMC_backgroundProcessing() function, you must set an SMC_SYNCHRONIZE after the command's test suite. For example, 
// Suite 1:
SMC_backGroundProcessing()
{
rdi.setGlobalVar("str",value);
}

// Suite 2:
SMC_SYNCHRONIZE();

// Suite 3:
SMC_backGroundProcessing()
{
rdi.getGlobalVar("str");
}
