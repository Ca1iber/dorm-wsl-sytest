Production Flags

Production flags typically have a boolean 0/1 value representing the states on and off. However, some of the flags contain an integer values.

The Production Flags each have a PREDEFINED name, and are grouped into the following categories:

  • Test suite flags
  • Testflow flags
  • System Flags (Testflow flags for dataloggging)

All production flags are declared as type integer (int).
