TRANSACTION_ITERATOR

Returns transaction iterator objects of protocol tests for

  • looping over all transactions
  • all failed transactions
  • all error transactions

after the protocol test was executed.

Note Iterator objects can become invalid if the protocol test they were created from is executed again.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TransactionIterator.h.

Syntax

Boolean hasNext();
TRANSACTION& next();

Member functions

hasNext()

Boolean hasNext();

Indicates whether all transactions have been looped already.

If the return value is

  • TRUE, the next call to function next() will return another valid transaction.
  • FALSE, the iterator either points to the last transaction or became invalidated by another execution of the associated protocol test.

next()

TRANSACTION& next();

Returns the next transaction, which can be the

  • next in sequence
  • next failing
  • next erroneous transaction
    Note This function must only be called if function hasNext() returned TRUE and the iterator was not invalidated by another test execution in the meantime.
