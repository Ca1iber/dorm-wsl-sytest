RDI_INFO_LEVEL

Subtopics

  1. rdi.getInfoLevel()
  2. rdi.setInfoLevel()

This testflow variable controls the level of SmartRDI related information that is shown in the SmarTest UI report window. SmartRDI supports logging levels 0, 1, 2, and 3.

The optional flag can be defined as Userflag on the Variables page of the Flow Data Editor.

Level 0

When the information level is 0, nothing is reported in the SmarTest UI report window.

Level 1

When the information level is 1, SmarTest command behind SmartRDI appears in the SmarTest UI report window.

For example, consider this piece of SmartRDI code:

RDI_BEGIN();
rdi.dgt("cap").pin("E+").samples(1024).FS(1e5).execute();
rdi.wait(TA::WAIT_DGT);         
RDI_END();

Executing it will generate a log similar to this (numbers in square brackets indicate sites): 

rdi:[1] Analog.primary("_RDI_PLAY_BK1");
rdi:[1] Routing.pin("DGT1_E+").connect(TM::SINGLE);
rdi:[1] DGT("DGT1_E+").enable();
rdi:[1] FLUSH();
rdi:[1] Primary.label("_rdi_burst_RDI_BK1_v1");
rdi:[1] SMC_FUNCTIONAL_TEST();
rdi:[1] ---------------------------------------------  
rdi:[1] DGT("DGT1_E+") .getWaveform(1,results,1)
rdi:[2] DGT("DGT1_E+") .getWaveform(1,results,1)
rdi:[3] DGT("DGT1_E+") .getWaveform(1,results,1)
rdi:[4] DGT("DGT1_E+") .getWaveform(1,results,1)  
rdi:[1] ---------------------------------------------
rdi:[1] Routing.pin("DGT1_E+").disconnect();

Level 2

When the information level is set to 2, separate test times are displayed for each test in the SmarTest UI report window.

This is a sample for the information level 2:

Total:                             26.071 msec
  Setup Generation:                       15.631 msec
    Action pattern & Dc generation:              14.090 msec
    Burst pattern gen:                     0.080 msec
    Other init & check:                    0.069 msec
    Pattern Cycle Calculation:                   1.376 msec
    User Code:                             0.016 msec
  Setup Command:                           6.044 msec
    DC Setup:                              5.839 msec
    Other Command:                         0.205 msec
  Pattern Execution:                       3.278 msec
  Result Upload:                           1.043 msec
    DC Result Upload:                      1.023 msec
  Others:                                  0.075 msec
The information level 2 example above is generated from the following code: 
RDI_BEGIN();
  rdi.dc().pin("DATA1").vForce(3 V).execute();
  rdi.dc().pin("DATA2").iForce(0 mA).vMeas().measWait(100 us).execute();
RDI_END();
Note All "other" time refers to SmartRDI execution/generation overhead that does not consume a significant portion of time in general.

Level 3

When the information level is set to 3, executed RDI actions are dumped to the SmarTest UI report window in the first run.

This feature shows RDI commands and their default values. It helps to debug deeply layered code structures.

For example, consider this piece of SmartRDI code:

RDI_BEGIN();
write (data1);
write (data2);
write (data3);         
RDI_END();

void write (int data)
{data2=process(data)
rdi.smartVec().pin("DATA1").defaultBit(0).writeData(data2,8,2).execute();
}

Executing it will generate a log similar to this: 

**************************
SmartRDI version : 2.4.5.0
**************************
----------RDI commands in testsuite RDI_Dump_info-----------
RDI_BEGIN(TA::BURST);
rdi.smartVec().pin("DATA1").defaultBit(0).writeData(71,8,2).execute();
rdi.smartVec().pin("DATA1").defaultBit(0).writeData(73,8,2).execute();
rdi.smartVec().pin("DATA1").defaultBit(0).writeData(75,8,2).execute();
RDI_END();

Functional changes

  1. SmartRDI 2.4.0: Support RDI_INFO_LEVEL 2.
  2. SmartRDI 2.4.5: Support RDI_INFO_LEVEL 3.
