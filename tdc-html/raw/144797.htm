DPS_AUX_PIN_TASK.checkIcHacError()

High accuracy clamp events are used in dynamic DC tests to improve the current clamp accuracy.

In case it fails, a latched error flag is set.

The DPS_AUX_PIN_TASK.checkIcHacError() member function retrieves the error flag and resets it. The flag status is cached inside of the test method.

The API must be called within the ON_FIRST_INVOCATION block.

Note

Pass/fail results that are retrieved by command PRLT are invalidated by commands CSAS and PSAS.

We recommend therefore using the command PRLT directly after the related functional test and before command CSAS or PSAS are performed.

This behavior applies not only to the commands but also to the related APIs: Function GET_FUNCTIONAL_RESULT() must be performed before any of the DPS_AUX_PIN_TASK.check...() functions is called or the results of GET_FUNCTIONAL_RESULT() are invalid.

Syntax

DPS_AUX_PIN_TASK & checkIcHacError();

List of parameters

There are no parameters.

Return value

A reference to the corresponding DPS_AUX_PIN_TASK object.

For retrieving the read result see DPS_AUX_TASK.getIcHacError().

Example

DPS_AUX_TASK auxTask;

ON_FIRST_INVOCATION_BEGIN();

    auxTask.pin("dps2").checkIcHacError();

ON_FIRST_INVOCATION_END();

if ( auxTask.getIcHacError("dps2") == TM::AUX_TASK_STATUS_PASS )
{
    cout << "auxTask.getIcHacError(\"dps2\") returned TM::AUX_TASK_STATUS_PASS" << endl;
}
else
{
    cout << "auxTask.getIcHacError(\"dps2\") returned TM::AUX_TASK_STATUS_FAIL" << endl;
}
