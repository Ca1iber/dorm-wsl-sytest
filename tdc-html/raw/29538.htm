PMU_AUTORANGE

This API controls the autorange function of the Pin PMU, and returns the current autorange mode.

Per default, PMU autoranging is switched off for all testmethod APIs to minimize measurement times. This applies for pass/fail as well as for value measurements. The PMU current range is determined as follows:

  • For I-force V-measure test

    The force current specified determines the PMU current range.

  • For V-force I-measure test

    The maximum of the absolute values of minimum and maximum current limit determines the PMU current range.

PMU autoranging works as follows: The initial current range is determined as described above (PMU autoranging switched off). If the value measured is outside this range the PMU will repeat the measurement using the next higher range. This is repeated until the value measured is inside the current range.

Range can be shifted only to the larger direction. For High-Precision PMU, the range shift can be stopped by the clamp.

Note This PMU_AUTORANGE aPI only works for PMU_IFVM and PMU_VFIM. It does not work for the FlexDC APIs.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Execute.h.

Syntax

Boolean PMU_AUTORANGE();
Boolean PMU_AUTORANGE(Boolean stat);
Parameter

I/O

Parameter

Description / Range

I

stat

 

Autorange mode. Set ENABLE to set the autorange mode of all PMUs to on, DISABLE to set the autorange mode of all PMUs to off. If this parameter is not set, this function only returns the current autorange mode.

Example

Boolean stat;
if(!PMU_AUTORANGE()) stat = PMU_AUTORANGE(ENABLE);

The PMU_AUTORANGE API sets the autorange mode of all PMUs to on when the autorange mode is set off.
