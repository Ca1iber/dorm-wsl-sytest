Generating protocol wrappers using the 2nd level protocol wrapper tool

The 2nd level protocol wrapper tool allows you to generate protocol-aware (for short, PA) wrappers. It makes use of the CCTMultiportSync APIs in order to handle the port synchronization automatically. This tool is very useful in PA concurrent testing.

About this task

Note The 2nd level protocol wrapper tool is not provided with SmarTest. To get this tool, please contact your local Advantest application engineer.

This task describes how to generate PA wrappers (C++ classes) from the protocol transaction using the 2nd level protocol wrapper tool. The generated PA wrapper can be used within your test methods.

Before you begin

Make sure that you have completed the protocol definition including transactions, pin roles and fields.

Note If you have modified your protocol and if you use the wrapper in your test methods, you have to re-generate your wrapper again.

Procedure

  1. Under the 2nd_level_Protocol_Wrapper directory, execute the command ./advantest.sh. The following window appears:
  2. Specify the source .hpp file path in the Please select source *.hpp file field.
  3. Specify the target class name in the Target Class Name field.
  4. Click Parser *.hpp file and get met..., the transaction of the first level (without concurrent test framework (CTF) support) wrapper will appear in the table.
  5. Select the required transaction from the Method column in the table.
  6. Now to generate your code (that supports the concurrent test frame work (CTF)), click Code Generator. The Code generated successfully window appears.

Results

The protocol related wrapper class file (.cpp) have been saved to the new directory with the name you specified in step 3 above. The generated code supports the concurrent test framework (CTF).

What to do next

Copy the .hpp and .cpp files into your test method directory.
