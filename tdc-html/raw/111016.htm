DRLShmooTestAttr

A variable of this type holds the result data of a shmoo plot. It contains the following members.

  • title: The title of the shmoo plot.
  • testMode: The test mode of the shmoo.
  • resultPins: The pins which contribute to the pass/fail result.
  • otherDescription: The overall description of the shmoo plot.
  • resultResolution: The resolution to differentiate the results.
  • xStart: The start value of X axis.
  • xStop: The stop value of X axis.
  • xTotalSteps: The total step number of X axis.
  • xLinearSteps: The linear step number of X axis.
  • xScale: The scale on X axis. It can be Linear or Logarithmic.
  • xUnit: The unit of X axis.
  • xAxisDescription: The description of X axis.
  • yStart: The start value of Y axis.
  • yStop: The stop value of Y axis.
  • yTotalSteps: The total step number of Y axis.
  • yLinearSteps: The linear step number of Y axis.
  • yScale: The scale on Y axis. It can be Linear or Logarithmic.
  • yUnit: The unit of Y axis.
  • yAxisDescription: The description of Y axis.
  • measuredCellNumber: The measured cell number.
  • cellResults: The result of each cell in the shmoo plot.
    Note You can specify any derived unit (such as ns or mA) for EDL data logging. However, when data logs are converted to STDF, all units are converted to their SI equivalents (ns to s, mA to A) and the corresponding values are converted accordingly. (For example, 435 mA is converted to 0.435 A.)
