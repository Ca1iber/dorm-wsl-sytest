CCTgetAllDCUploadStartIdx

Retrieves multiple start index of the DC values for the native test suite in the DC test results generated by the merged burst pattern.

This function is usually used in the preStart(), postStart(), process() and cleanup() function but not used in the init() function of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

vector<RESULT_POINT::IndexType> CCTgetAllDCUploadStartIdx(const string& pins);
Parameter

Parameter

Description

pins

The list of pins or pin groups separated by comma. They can be Smart Scale pins or DC Scale pins.

Return value

The vector containing the first index of multiple pins for the native test suite is returned.

Example

DC_RESULT_ACCESSOR dcResultAccessor;
TM::RESULT_RANGE dcRange_Pin1 dcRange_Pin2;
vector<RESULT_POINT::DistanceType> allDCUploadLength;
vector<RESULT_POINT::IndexType> allDCUploadStartIdx;
allDCUploadStartIdx = CCTgetAllDCUploadStartIdx("Pin1,Pin2");
allDCUploadLength = CCTgetAllDCUploadLength("Pin1,Pin2");
//Get the result of Pin1;
dcRange_Pin1.first = allDCUploadStartIdx[0];
dcRange_Pin1.length = allDCUploadLength[0];
dcResultAccessor.uploadResult("Pin1", dcRange_Pin1);
ARRAY_D dc_Pin1(dcRange_pin1.length);
dc_Pin1 = dcResultAccessor.getValue("Pin1");
//Get the value of Pin2
dcRange_Pin2.first = allDCUploadStartIdx[1];
dcRange_Pin2.length = allDCUploadLength[1];
dcResultAccessor.uploadResult("Pin2", dcRange_Pin2);
ARRAY_D dc_Pin2(dcRange_Pin2.length);
dc_Pin2 = dcResultAccessor.getValue("Pin2");
