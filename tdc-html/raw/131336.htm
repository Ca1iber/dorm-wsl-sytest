MTP_IDD_TASK.samples()

The samples() member function of MTP_IDD_TASK lets you specify the number of measurements to average.

Syntax

void samples(int samples)

Parameter

Description

samples

The number of measurements to average.

The default value is 8.

Related information

MTP_IDD_TASK

Functional changes

  1. Introduced in MTP 3.1.5
