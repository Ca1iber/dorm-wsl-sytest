Global and local spec values (scope of the spec variable)

Different ports can have the same spec variables. In particular, if you use the same equation set for more than one port the spec variables of these ports are the same. Although the name of a spec variable can be the same you can set up the scope of the spec variable by allocating the spec value

  • locally to a port, or
  • globally to a port.
    Note For how to set up the scope of a spec variable, see How to set up a multiport timing specification.

Local Spec Values

If a spec value is local for a port the assigned value for the spec variable is only valid for that port. If you change a local spec value the change only applies to the one port where you change the value.

Global Spec Values

If a spec values is global for a port the assigned value for the spec variable applies to all ports where this spec value is set to global. If you change a global spec value for one port the change also applies to all other ports where the value of this spec variable is set to global.

Note The values of the same spec variable can be local for some ports and global for other ports.

For example, consider the spec "f" of the table above. It is local for PORT 1, PORT 2 and PORT 3 and global for Port 4 and Port 5.

  • If, for example, you change the value of "f" at PORT 2 ("f" is local at this port) the value of "f" at all other ports will not change.
  • If, for example, you change the value of "f" at PORT 4 ("f" is global at PORT 4) the change automatically applies to PORT 4 and PORT 5 because "f" is global at PORT 4 and PORT 5.
    Note In the shmoo tool, the distinction between local and global scope must be expressed in the same way as for the SVLR command. If you want to change a spec variable locally, you must add the name of the port for which the change is to be made in the following format: <spec_variable>@<port_name>
