EVENT_VF

The EVENT_VF class is a voltage force event.

Force event classes provide functionality to define events changing force settings.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Class definition

Constructor

class EVENT_VF : public EVENT_BASE
    EVENT_VF(const STRING & id);
    EVENT_VF(      INT      id);

Member Functions

EVENT_VF & vForce(const EVENT_VALUE_DOUBLE & value);
void getVForce(EVENT_VALUE_DOUBLE & value) const;

Constructor

class EVENT_VF : public EVENT_BASE
    EVENT_VF(const STRING & id);
    EVENT_VF(      INT      id);

This constructs an object of the EVENT_VF class. The class derives from the EVENT_BASE class.

Parameter
Parameter Description
id Event identifier

Member functions

vForce(), getVForce()

EVENT_VF & vForce(const EVENT_VALUE_DOUBLE & value);
void getVForce(EVENT_VALUE_DOUBLE & value) const;

These member functions define or query a force voltage.

Parameter
Parameter Description
value Fixed voltage or derived from spec

Example

Defines a fixed force voltage event:

EVENT_VF fixedFrcEvent("frc1.5V");
fixedFrcEvent.vForce(1.5 V);

Defines an equation based force voltage event:

EVENT_VF specFrcEvent("frcV_Spec");
specFrcEvent.vForce("LEV:myFrcSpec");
