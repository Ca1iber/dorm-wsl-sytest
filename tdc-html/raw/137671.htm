Topic 137671

Setting up the data log information

The Datalog Setup dialog provides a central place to configure the data log related settings. It allows to select the data log profile, specify the output data log files and control the generation of the lot summary file.

About this task

To generate the text data log file, set the system flag log_events_enable to on. The flag is set to on by default when you create a new testflow.

To generate the STDF data log file, set the system flag log_events_enable to on. The flag is set to on by default when you create a new testflow.

If you use Data Logging Profiles, the settings in the data logging profile will have higher priority than the settings in the testflow.

If the correct setting of log_events_enable does not generate the STDF file correctly, check the setting of formatter.stdf.generateStdf in the configuration file global.conf and the setting of generateDetailedFile and generateSummaryFile in the configuration file main.formatter.conf.

In the naming of the data logging files and the lot summary files, you can use the following variables in a pair of braces to specify the name and path of the output data log file or lot summary file. In the real name of the files, they will be replaced by the value of the variables at that moment.

  • The variables related to lot information, including PART_TYP, TST_TEMP, TEST_COD, LOT_ID and OPER_NAM
  • The system variables, including HOSTNAME, USER and LOGNAME
  • Others: DEVICE_PATH, DEVICE_NAME, TESTFLOW_NAME and TIMESTAMP
  • All the variables defined in the /etc/opt/h93000/tcct/newlotuiconfiguration.xml file
    Note DEVICE_PATH can only be used to specify the path of the files and cannot be used to specify the name of the files.

Before you begin

Start TCCT and the Datalog Setup dialog.

Procedure

  1. In the Datalog Setup dialog, choose whether to use the data logging profile.
    • If you choose Not Used, the data log settings in the flag setting of the testflow will be used.
    • If you need to use the data logging profile, choose Active and select the profile from the list. (Refer to Data Logging Profiles for the details about the data log profile.)
  2. (optional) For the PROBER test, to generate the data log file and the lot summary file per wafer,check the box before the Per Wafer. The wafer ID will be automatically added in the naming of the per-wafer data log files and per-wafer lot summary files.
  3. In the DataLog section:
    • Specify the full path of the EDL file to be logged.
    • Specify the full path of the text file to be logged. To output the text file content to the Text Datalog console in TCCT, check the option console.

      You can also specify the width of the test name and choose whether to show the column of pin name in the text data log.

    • Specify the full path of the STDF file to be logged.

      Multiple STDF and text data log files can be generated for one lot. To do this, specify a new file name when you want to log the following test results in another file.

    • If you want to generate the data log file with your own formatter, specify the full path of the data log file and choose the library of your data log formatter.
      Note If you specify the data log files here, the log_events_enable flag must be set to on. Otherwise you will get an error message asking you to turn on the flags when you click Start Test. The test of the lot will be aborted after the testflow is executed. The log_events_enable flag will be automatically turned on.
    • Specify the full path of the text lot summary file and the per-wafer lot summary file. To output the lot summary content in a pop-up window, check the option Window.

      The per-wafer lot summary file can only be specified when Per Wafer is checked for PROBER test. The wafer ID will be automatically added to the name of the generated files.

    • Choose which tests are included in the lot summary file. It can be All Tests, Fail Tests or No Tests.
    • Choose whether to generate summary by site. If the by site option is checked, the test results will be summarized by site in the lot summary. Otherwise, the test results of all sites will be summarized together.
  4. Click Apply to make the settings effective.
  5. (optional) If you are using the environment variables in the data log and summary file name, click Show Current Open Dialog File to show the real file name that will be used.
  6. (optional) You can generate the partial summary for the tested devices by clicking Get Partial Summary.
  7. (optional) To clear the summary for the tested devices, click Reset Summary Counter.

Functional changes

  1. Introduced in SmarTest 7.2.0
  2. SmarTest 7.2.0: in patch 2, supports per wafer lot summary file in TCCT 1.1
  3. SmarTest 7.2.1: New option Test Name Width and Show Pin Column to control the text data log files in TCCT 1.3
  4. SmarTest 7.2.1: All the variables defined in the newlotuiconfiguration.xml file can be used in the data log file name in TCCT 1.3
  5. SmarTest 7.2.2: Supports logging the EDL data log file in TCCT 1.4
  6. SmarTest 7.2.2: Supports logging the content with customized data log formatter in TCCT 1.4
  7. SmarTest 7.4.5: Removed stdf_generation flag
