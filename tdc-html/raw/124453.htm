UTDE - (Unload Test Data Entity)

The UTDE command lets you unload a test data entity (TDE) that has been loaded using the LTDE command.

Syntax

UTDE "<file_name>" | ALL

Parameters

file_name

The file name of the protocol test data entity (TDE) to unload.

The specified TDE must belong to the directory specified with the PTDE command.

ALL

Unloads all test data entities.

Only test data entities belonging to the directory specified with the PTDE command will be unloaded.

Example

UTDE "test.prot_asg"

Related information

LTDE, LTDE? - (Load Test Data Entity)
PTDE, PTDE? - (Path for Test Data Entities)
STDE - (Save Test Data Entity)

Functional changes

  1. Introduced in SmarTest 6.5.0
  2. SmarTest 7.1.0: Added new parameter ALL.
