Application Data

Subtopics

  1. Selecting a new application model file
  2. Creating an Application Data File
  3. Loading/Saving an Application Data File
  4. Editing the Application Data File

The application data file consists of the data within the application model file which is used as parameters for the test program, test site, temperature, and so on. The values you entered in the application data editor can be accessed with APPLIC_DATA_EDITOR_INPUT. The retrieved data can be used as a regular application model variable. For example, it can be used to construct a file name.

The application data file can be displayed and edited within the Application Data Editor Window. The application model file together with the data in the application data file, is called the Application.
