UTST, UTST? - (UTility line STate)

The UTST command sets or reads the output (desired) state of the specified utility lines.

Queried utility lines need to be defined by the DFUTcommand.

The FLSH command is required to activate the state settings of the UTST command.

Utility lines allow you to control external devices such as relays, solenoids or indicators, depending on the application. The utility lines are implemented as open drain output with a maximum current of 100 mA and a maximum voltage of about 5.0 V.

With this command you configure setups of those sites that have the setup focus: For more information, see also: PSFC, PSFC?.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

UTST

UTST {value}, {(util_name)}

UTST?

UTST? type, {(util_name)}

returns:

UTST {value}, {(util_name)}

Parameters

value

Specifies the output (desired) status of the utility line with the specifier 0 or 1.

  • 0: High output
  • 1: Low output
type

This parameter is used to specify whether the output (desired) state or the input (actual) state is to be returned. Possible values are:

  • w: Returns the output (desired) state.
  • r: Returns the input (actual) state

For pure output utility lines, this parameter is ignored.
util_name

Specifies the utility line name or names to be set or read.

In the query, specifying @ returns all utility lines.

If more than one name is required, the names must be separated by commas.
Note All utility lines that are set with UTST or UPST will be switched in parallel when the FLSH command is performed. If the WSDN command is used immediately after FLSH, the time span during which execution will pause equals the longest settling time that is defined for any of the switched utility lines (with UTTI) or purposes (with UPTI).

Application

For details about utility lines, see Routing Setup Commands.

Warnings

A warning is generated if the referenced utility line has not been defined before.

Example

UTST 1,(Filt1,Filt2)
UTST 0,(Filt3,Filt4)
FLSH
WSDN
UTST? w,(Filt1,Filt2,Filt3,Filt4)

will return:

UTST 1,(Filt1,Filt2)
UTST 0,(Filt3,Filt4)

This example sets the utility lines "Filt1" and "Filt2" to high output, and "Filt3" and "Filt4" to low output.

Functional changes

  1. Introduced before SmarTest 6.3.2
