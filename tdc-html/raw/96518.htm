Topic 96518

WAFER_STARTED

This asynchronous event indicates the test for a wafer is started in the test program execution. It is only available for wafer sort.

Dependency and constraints

  • The test program is in execution.
  • If the application model does not contain the custom Wafer level or does not use the standard prober/handler driver function call (ph_wafer_start) or the equivalent, this event may not be generated.

    The standard naming for the application model variable should be used (not case-sensitive):

    For Lot ID: "ph_LOT_ID" | "LOT_ID"

    For Cassette ID: "ph_CASSETTE_ID" | "CASSETTE_ID" | "ph_CASS_ID" | "CASS_ID"

    For Wafer ID: "ph_WAFER_ID" | "WAFER_ID" | "ph_WAF_ID" | "WAF_ID"

    For Wafer Slot number: "ph_WAFER_SLOT" | "WAFER_SLOT"

    For Wafer Size: "ph_WAFER_SIZE" | "WAFER_SIZE"

    For Die Height: "ph_DIE_HEIGHT" | "DIE_HEIGHT" | "DIE_HT"

    For Die Width: "ph_DIE_WIDTH" | "DIE_WIDTH" | "DIE_WID"

    For Wafer Unit: "ph_WAFER_UNITS" | "WAFER_UNITS"

    For Wafer Flat: "ph_WAFER_FLAT" | "WAFER_FLAT"

    For Center X: "ph_CENTER_X" | "CENTER_X"

    For Center Y: "ph_CENTER_Y" | "CENTER_Y"

    For Positive X: "ph_POS_X" | "POS_X"

    For Positive Y: "ph_POS_Y" | "POS_Y"

    Otherwise it will fail to response the variable values.

Parameters

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session this event belongs to.

O

TIME_STAMP

The time point when this event occurs. It contains two long-type parts: SECONDS and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always EXECUTION.

O

EVENT_BODY

The event parameters. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always WAFER_STARTED.

LOT_ID

The current lot ID. It can be empty

CASSETTE_ID

The current cassette ID. It can be empty.

WAFER_ID

The current wafer ID. It can be empty.

WAFER_SLOT

The wafer slot number. It can be empty.

WCR

The wafer configuration record data. Each data field is coded according to STDF specification V4 and separated by space. (For details of WCR, see Wafer Configuration Record.)

This parameter is represented by ParamList whose key and value are both string type.
