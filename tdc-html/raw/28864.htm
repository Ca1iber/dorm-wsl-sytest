Topic 28864

DSP_A_ENCODE

This API encodes the contents of a specified array into 8-bit code using the A-law conversion method.

Encoding/Decoding Table for A-Law/µ-Law lists the encoding format of the A-law conversion used by this API. Also, refer to Code Format Tables for the two's complement and A-law code format.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_A_ENCODE(ARRAY_D& src, ARRAY_I& result, 
             INT output_format);
DSP_A_ENCODE(DOUBLE *src, INT *result, INT size, 
             INT output_format);
Parameters

I/O

Parameter

Description / Range

I

src

Source array

O

result

Encoded results

(size of result) = (size of src)

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src)

I

output_format

Output data format

CMPLM2: Two's complement

ALAW: A-law code format

ADI_ALAW: Alternative Digit Inverse (ADI) of A-law code format

Example

int array2[100];
double array1[100];

DSP_A_ENCODE(array1, array2, 100, CMPLM2);

DSP_A_ENCODE encodes 100 elements of DOUBLE array array1 using the A-law method. The 8-bit A-law code data (two's complement code format) is stored in INT array array2.
