*IDN? - (IDeNtify)

The *IDN? (IDeNtify) query displays the current model and firmware revision number.

Syntax

*IDN?

returns: 

*IDN {id_string}

Parameters

id_string

The string contains the model, the firmware revision number, and the revision date.

Example

*IDN?

returns:

*IDN Firmware  s/w rev. 3.1.0+95x, 06-Aug-01

Functional changes

  1. Introduced before SmarTest 6.3.2
