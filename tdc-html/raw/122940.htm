Why converting edges?

With SmarTest 7.0, all firmware commands and syntax elements, which deal with "bidirectional edges" are obsolete. Bidirectional edges are e1 to e6, which are replaced by the unidirectional edges d1 to d6 (drive direction) and r1 to r6 (receive direction), respectively. The direction, which must be used to replace a bidirectional edge, depends on the action, which is assigned to the edge. E-edge conversion tool (eedge tool) automatically converts "bidirectional edges" to "unidirectional edges".

The edge Converion is a 2 steps process:

  1. Run the conversion tool for each file
  2. Reload the setup file to verify the result immediately or later

As a result, a V93000 timing file with unidirectional edges is generated.

Functional changes

  1. Introduced in SmarTest 6.5.4
