Topic 55958

IOCHANNEL section

Subtopics

  1. Minimum sequencer period (base rate) for digital cards
  2. Channel range conversion
Note This section is for Smart Scale system model files only.

The IOCHANNEL section of the model file is the master configuration for the test system. If enough licenses are available and no hardware conflict exists (for example, hardware is not installed or not compatible), the test system is configured as described in the IOCHANNEL section.

After reading the IOCHANNEL section the software checks out the necessary licenses to achieve the required configuration.

Note Any installed channel card which is not specified in the IOCHANNEL section, is activated with its minimum capabilities only.

In the IOCHANNEL section, for each channel card you must define the available features: type of digital channel card, maximum base rate, sequencer memory depth, capture memory depth, vector memory depth, number of waveforms with number of edges, and differential receiver function.

Note The number of waveforms and edges can optionally be specified in the GLOBAL section.

The following definitions are available:

  • diff
  • HW
  • speed
  • tim
  • tmu
  • loopback
  • smem

Use the following syntax:

<ioch_description> :: = <ioch_range> : <ioch_feature_list>

To address the IO channels:

<ioch_range> :: = <io_channel> | <io_channel> - <io_channel>

For each range the channel numbers must start with the same digit. For example:

10101 - 13216

20101 - 23216

Not allowed: 10101 - 23216

For details, see Channel range conversion.

<io_channel> :: = <board><channel>
<board> :: = [101..132, 201..232, 301..332, 401..432]
<channel> :: = [01..16]

To specify the features for the IO channels:

<ioch_feature_list> = <ioch_feature> { , <ioch_feature> }
<ioch_feature> = <HW> | <speed> | <smem> | <tim> | <diff> |
 <tmu> | <loopback> |

Parameters

diff

Enables the differential receiver feature for the specified channels.

diff

Note that the diff parameter is not in the expression style. If not specified, the differential receiver feature is disabled by default.

The differential receiver feature is only supported per pin pair.

HW

Specifies the installed hardware type (channel card) for the specified channels. Parameter HW must be specified. Any channel card not specified is ignored.

HW = PS1600
  • PS1600: Pin Scale 1600 channel card

loopback

Enables the "PHY test bundle" for PS1600 digital cards.

The "PHY test bundle" combines the SmartLoop™ external loopback mode, PRBS (HW), and the 32k "compliance pattern". If not specified, the feature is disabled by default.

smem

Specifies the maximum sequencer memory depth (unified memory mode) in vectors for the specified channels.

smem = 8M | 16M | 32M | 56M | 64M | 112M | 224M

Maximum Sequencer Memory Depth:
  • PS1600 rev.A: 16M - 112M
  • PS1600 rev.B: 16M - 224M

The unit for this parameter is megavectors.

smem must be specified. If not specified, an error occurs during start up or when changing the device.

speed

Specifies the maximum base rate or bit rate for the specified channels.

speed = 100Mbps | 200Mbps |

533Mbps | 1600Mbps | max-rate

Available Maximum Base Rate (= 1/Test System Period) or Bit Rate:

  • PS1600: 100, 200, 533, and 1600 Mbps

- For the PS1600: max-rate enables a data rate of 1600 Mbit/s.

tim

Specifies the timing bundle (number of wave forms and edges) for the specified channels.

Note: With release 5.2 and later we recommend using the timing_bundle parameter in the GLOBAL section.

tim = w32-d8-r6 | w256-d8-r8

  • If tim (or timing_bundle) is not specified, w0-d0-r0 is used. An error message is displayed during start up of SmarTest or changing the device.
  • tim is valid per specified channel. Hence, all specified channels must have the same setting. If you mix different settings, an error message is displayed.

tmu

Enables the Time Measurement Unit (TMU) per pin for PS1600 cards.

tmu

Note that the parameter is not in the expression style. If not specified, the TMU feature is disabled by default.

Example

11101-11816:HW = PS1600, smem = 112M, speed=max-rate,
 tmu, diff, loopback = 1600Mbps
