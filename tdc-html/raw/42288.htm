Functions for Changing the Driver Mode

Subtopics

  2. Function: ph_get_configuration
  3. Function: ph_handtest_stop
  4. Function: ph_stepmode_start
  5. Function: ph_stepmode_stop

These functions allow you to set the driver to special modes of operation which differ from the normal mode.

The functions are closely related to the corresponding configuration parameters hand_test_mode and single_step_mode described in Configuration Parameters for Driver Mode.
