External utility power supply - Configuration and DUT board design

To use the external utility power supply, you must enable the 4-row pogo blocks and connect some pins of the utility pogo blocks on the DUT board.

Supported V93000 systems : Smart Scale, Pin Scale, HSM

Configuration for 4-row utility blocks

SmarTest 7
The following settings are required in the model file of the system and in the .technology file of your test program:
  • Enter the correct utility pogo block size in the GLOBAL section of the model file.
  • Enter the correct utility pogo block size in the .technology file.

    For dependencies between the model file and the .technology file, refer to Configuration of 4-row or 2-row utility pogo blocks.

SmarTest 8
The following settings are required in the tester.model file of the system:
  • Enter the correct utility pogo block size in the GLOBAL section of the tester.model file.

DUT board design

Pogo pins to be connected to "UGND"
On the DUT board, the following pogo pins must be connected to a common "UGND" plane.
Name Type Description Notes and recommendations
DSC I digital1) DUT board detection pin:
  • Low level: DUT board connected
  • High level / open: DUT board not connected
 The DSC pin of every utility block has to be connected to UGND on the DUT board.
POG4R

I

digital1)

 Indicates a 4-row utility block:

  • Low level: 4-row pogo block

  • High level / open: 2-row pogo block

Every POG4R pin has to be connected to UGND on a DUT board that utilizes 4-row utility pogo blocks.

Provide unconnected landing pads for these pins on a 2-row DUT board.

The system will recognize a 4-row pogo block only if the pin is connected to UGND on a DUT board that is designed for 4-row pogo blocks.
Outputs of the external utility power supply

Connect the following pins according to the needs of your application to the DUT board circuitry.

Name Type Description Notes and recommendations
XPM5V O power -5 V output of the external utility power supply

Return of XPM5V, XPP3V3 and XPP5V is UGND.

The power pogo pins of the same name and output voltage on all utility blocks used should be connected to common power planes of the DUT board. Note: The maximum allowed current per pogo pin is 1 A. This limit is not exceeded with evenly distributed currents. However, in case of a shortcut on a single pogo block, the current might be higher. To protect the power pogo pins from damage, polyfuses are mounted directly on the 4-row utility pogo blocks. In addition, polyfuses are available on the wiring board to protect the sense lines. When triggered, a polyfuse needs a short time to reset.

If an output is not used, you can leave the pins unconnected.

For the capabilities of the supply and the information how to use it, refer to External utility power supply.
XPP3V3 O power +3.3 V output of the external utility power supply
XPP5V O power +5 V output of the external utility power supply
XPM5Vs I power sense -5 V sense input of the external utility power supply

Return sense pin is UGNDs.

Connect only one sense pin of each voltage (-5 V, +3.3 V and +5 V) on only one utility block for power sensing. Leave the sense pins on the other utility blocks unconnected.

Leave all sense pins of XPM5V, XPP3V3 or XPP5V unconnected if the related output is not used.
XPP3V3s I power sense +3.3 V sense input of the external utility power supply
XPP5Vs I power sense +5 V sense input of the external utility power supply
UGND power

Utility ground

Provides the return path for UP5V, XPP5V, XPP3V3, XPM5V and all utility lines.

Connect every UGND pin on all utility blocks to a common ground plane on the DUT board.

For information on ground connections see Grounding and Connecting the different grounds on the DUT board.
UGNDs I power sense Ground sense pin of the external utility power supply: XPM5V, XPP3V3, XPP5V Connect only one UGNDs sense pin on only one utility pogo block for ground sensing. Leave the UGNDs pins on the other utility blocks unconnected.
Note The maximum current is limited to 1 A per pogo pin. For the maximum current capabilities of the supply, you must therefore connect the XP... power output pins of the same name and output voltage on all utility blocks to common power planes on the DUT board.
Decoupling capacitors
We recommend adding a ceramic decoupling capacitor to each power line on your DUT board and position it as close to the load as possible. The value should be in the range of approximately 1 μF … 22μF depending on the current drawn. For applications such as high current DC/DC converters tantalum capacitors are recommended.

Use high quality ceramic capacitors with dielectric X5R, X7R or COG.

  • For analog, DC/DC and lower speed digital applications we recommend capacitors with the X5R dielectric.
  • For high speed digital applications use a combination of X5R (or X7R) in parallel with a COG dielectric ceramic capacitor.
  • For RF applications a more careful filter design using COG capacitors is recommended.

Example range of values for digital applications:

  • 1 μF, size 0402, BDV=10V, GRM155R61A105xxxx
  • Up to 22 μF, size 1210, BDV=10V, GRM32ER61A226xxxx

The use of high capacity (Tantalum) capacitors is a requirement for high current dynamic load applications where F < 100 kHz. Effective is for instance the T510 series from KEMET.
