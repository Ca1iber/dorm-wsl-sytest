Shmoo Tool

The Shmoo Tool helps you to create shmoo tests and view shmoo plots.

You use the Shmoo Tool to:

  • Perform shmoo over a functional test, shmoo over an existing test suite or multiple test suites, fail bit count shmoo for MTP, and customized shmoo tests.

    When shmooing a test suite, you can view value results on the shmoo plot.

    For details, see set up, execute and view shmoo tests.

  • Peform multisite shmoo tests.
  • Overlay shmoo plots.
  • Interact with the Testflow Tool to:
    • Display the shmoo plot of a shmoo test suite.
    • Transfer a shmoo setup between the Shmoo Tool and a test suite.
    • Log shmoo data into the report window and save shmoo plots as PNG or ASCII files: To do this, you must transfer the shmoo tests from the Shmoo Tool to a testflow first.
  • Interact with the Integrated Result Tool to display shmoo plots in the Integrated Result Tool: To do this, you must transfer the shmoo tests from the Shmoo Tool to a testflow first.

Functional changes

  1. SmarTest 7.2.2: Introduces shmoo over multiple test suites.
  2. SmarTest 7.2.2: Saves shmoo plots and results as ASCII files..
