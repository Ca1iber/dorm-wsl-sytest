Topic 43568

Customizing the Workorder Screens

Subtopics

  1. Displaying the Test Program Components
  2. Displaying the Workorder Select Screen

This chapter explains how to change the appearance and functionality of the following screens of the operating environment, namely

  • the Workorder Manager screen and
  • the Workorder Select screen

by setting certain Linux environment variables.

You will also find descriptions of how the SmarTest mode passwords can be changed or reset to their defaults.
