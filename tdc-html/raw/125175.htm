Displaying data in the signal analyzer tool

You can plot De-embedding cit files on the signal analyzer tool.

Procedure

  1. Select one or more rows of interest.
  2. Right-click the row.
  3. On the shortcut menu, select Signal Analyzer.

    Signal Analyzer tool opens displaying the corresponding graph or graphs (see Elements of the Signal Analyzer Tool).
