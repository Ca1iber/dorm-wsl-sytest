CCTsetRetest()

Sets the test suite to be retested.

It needs to be used outside of the first invocation block or in the for-each-site block.

This function is usually used in the preStart(), postStart(), process() and cleanup() function but not used in the init() function of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

void CCTsetRetest(int siteNum, bool enableSMC);
Parameters

Parameter

Description

siteNum

The site to retest

enableSMC

Specifies whether to enable SMC in the test method. It can be:

  • true: enable SMC
  • false (default): do not enable SMC

Return value

There is no return value.

Example

CCTsetRetest(1);

Related information

Doing retest with the concurrent test framework

Functional changes

  1. Introduced in SmarTest 7.3.1
  2. SmarTest 7.2.3: New parameter enableSMC.
