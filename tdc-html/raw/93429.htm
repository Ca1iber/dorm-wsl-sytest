Topic 93429

Setting parameters for the binning handler

The binning handler saves the software bin and hardware bin information for a failing device. If a safety-relevant test has failed, the handler is able to disconnect all DUTs.

To edit the parameters of the BinningHandler test method, click it in the tabular test editor. The parameters are displayed in the Test Suite window and you can edit them there.

Parameters

Name

Type

Value

Softbin

Integer

Default: 1

Hardbin

Integer

Default: 1

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. MTP 3.0.1: Parameters are now edited in the Test Suite window
