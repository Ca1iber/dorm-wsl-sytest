DPS pin editor reference

The DPS pin editor contains the following columns:

  • Name: The name of the pin.

    The name can be up to 16 characters long and must not contain the characters: # ; ( ' ' ) ? @ ,

  • Polarity: The operating mode for the DPS pin: POS.
  • Load Capacity [uF] / V-Ramp [us]: The value of the load capacitor connected to the DPS pin.
  • Instrument: The hardware information of the channel. Not editable.
  • Comment: Any text. Optional.
  • Tester Channel: The number of the tester channel to be used.
