STPM MCM parameter settings

Several parameter settings in the SmarTest Program Manager MCM (STPM MCM) control file let you specify the directory and testflow on which to operate as well as several general settings for the merging process.

The available settings are:

  • Settings specifying the MTP (master test program):
    • mtp_template_dir
    • mtp_device_testflow
  • Settings regarding the merging process:
    • cct_lev_offset
    • apply_prefix_on_specs_and_equations
  • Settings regarding the environment:
    • ate_target
    • ate_model
    • ate_version
    • ate_config_msdps

Syntax

mtp_template_dir = '<dir_path>'             
[mtp_device_testflow = '<testflow_path>']
[cct_lev_offset = <offset>]
[apply_prefix_on_specs_and_equations = <apply_prefix_flag>]
[ate_target = '<platform>']
[ate_model = '<model>']
[ate_version = '<version>']
[ate_config_msdps = {'<module>':'<mode>', ...} ]

Parameters

The parameters of the commands in the order in which they are listed above:

mtp_template_dir

<dir_path> (string) is the path of the MTPT (mapping tables) directory that is be used for the merging process.

It can be an absolute or a relative path. If it is a relative path, the base directory is the current working directory at the time STPM MCM was called.

mtp_device_testflow

<testflow_path> (string) is the name and path of the MTP testflow file.

This parameter is required if the generate_device_dir, create_mtp, or update_mtp commands are used in the control file; otherwise it is optional. There is no default value.

cct_lev_offset

<offset> (integer) is the number used for the first level equation set created for concurrent tests (CCT mode). If this number is already assigned to a set, the next larger available number is used. Numbers for additional sets are created by incrementing this number.

If this parameter is set to -1, no CCT integration is possible.

This parameter is required if the CCT mode is used; otherwise it is optional. The default is -1.

apply_prefix_on_specs_and_equations

Default = 1.

<apply_prefix_flag> (integer) specifies whether STPM MCM applies the prefix defined for an STP (see STP table for details) to the specs and equation variables it imports from that STP to the MTP:

  • 0: The names of specs and equation variables copied from the STP are not changed; the prefixes are ignored.
  • 1: When a spec or equation variable is imported from the STP to the MTP, the prefix defined for the STP is added to its name.

Note that the application of prefixes to pin configuration objects is controlled individually for each STP through the Apply Prefix On Pin Config column in the STP table.

This parameter is optional. The default is 1.

ate_target

<platform> (string) indicates the type of V93000 architecture on which the test program will run:

'93000SS': Smart Scale system

ate_model

<model> (string) indicates the specific test system on which the test program will run.

The available settings depend on the specified ate_target.

For '93000SS', you can specify:

  • 'PS1600'

This is an optional parameter. If it is omitted, the default used depends on the setting for ate_target:

ate_version

<version> (string) is the release number of the SmarTest version under which the test program will be running.

This is an optional parameter. If it is omitted, "7.1.4" is used.

ate_config_msdps

A list with the channel numbers of the DSP modules.

<module> (integer or range) is one module or a range of modules:

  • One module: Specify the number of the module, for example, 3.
  • Range of modules: Specify the first and last module in the range, separated by a dash. For example, 2-4.

You can specify multiple modules or module ranges; separate them with commas. The list of modules (whether you specify one or more) must be enclosed in curly brackets.

This is an optional parameter. If it is omitted, STPM MCM determines the channel mode automatically by assigning mode 8 to every module that has a channel number greater than four and mode 4 to all other modules.

Example

mtp_template_dir = '/prj/MTPT'
mtp_device_testflow = '/prj/MTP/testflow/rel.tf'
cct_lev_offset = 2
apply_prefix_on_specs_and_equations = 1
ate_target  = '93000SS'
ate_model   = 'PS1600'
ate_version = '7.2'
ate_config_msdps = { '1' : '4', '4-7' : '8' }

Functional changes

  1. Introduced in SmarTest 7.1.4
  2. SmarTest 7.2.0: Added 93000SS option for the ate_target parameter and PS1600 for ate_model.
  3. SmarTest 7.2.1: Added ate_config_msdps parameter.
  4. SmarTest 7.2.1: Removed PS3200 and PS6800 options for the ate_model parameter.
