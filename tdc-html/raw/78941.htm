Testflow flags for data logging

The data logging flags (sometimes referred to as system flags) constitute an additional set of tools that allow you to control the test program. They define global information, relevant to the whole test. The flags are available per testflow.

These flags are most relevant to data logging:

  • calib_age_monitor
  • current_monitor
  • datalog_formatter
  • datalog_sample_size
  • diag_monitor
  • graphic_result_display
  • hidden_datalog_mode
  • ink_wafer
  • log_events_enable
  • max_reprobes
  • print_wafermap
  • state_display
  • temp_monitor
  • tm_crash_as_fatal

For a detailed list of the flags for data logging, refer to Alphabetical list of flags. Select Data logging in the filter settings of column Area to show only the flags for data logging.

The data logging flags are stored in the flags section of the Testflow file.

The flag names denoted above represent the string to be used in test methods.
