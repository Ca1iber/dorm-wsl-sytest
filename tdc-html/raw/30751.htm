ELEMENT_OF_PARAM_LIST

Subtopics

  1. Associated Syntax Entities

Gets the next element of a list (contained in one parameter). If there are no more elements in this list, the level is ended.

This feature is used in the wafer_auto application model file to get the wafer_id from the cassette_list.

For example,

cassette_list=FILE_INPUT(/tmp/{Lot_id}.waf_list);

wafer_id=ELEMENT_OF_PARAM_LIST({cassette_list})/REGEXP(int);

This shows that the whole file "/tmp/{Lot_id}.waf_list" is assigned to the variable cassette_list. Individual elements of this file can then be accessed via the ELEMENT_OF_PARAM_LIST expression.
