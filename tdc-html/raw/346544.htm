PinPropertyMonitor

Subtopics

  1. PinPropertyMonitor.printStatus()
  2. PinPropertyMonitor.printStatus2File()

The pin property monitor is a class which provides functions to read and print tester status (the current settings of all instruments) to system console or to text files.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PinPropertyMonitor.h. You do not need to manually include it in your test method because it is included in MAPI.

Class definition

Constructor

PinPropertyMonitor();
PinPropertyMonitor(const ARRAY_I& sites, const string& pins);
PinPropertyMonitor(const ARRAY_I& sites, const string& pins, const string& instruments);
PinPropertyMonitor(const ARRAY_I& sites, const string& pins, const string& instruments, const string& property);

Parameters

Parameter Description
Instruments Possible options are: RELAY, PE_Driver, PE_Receiver, PE_Termination, PPMU, DPS, RELS, DPS128HC, CSAS, PSAS.

Member functions

  • printStatus()
  • printStatus2File()

Example

ARRAY_I sites;
GET_ACTIVE_SITES(sites);
//string pinList = "SWITCH_R/4,SWITCH_R/2,SWITCH_R,SWITCH_2R";
pinList = "@";
PinPropertyMonitor ppm1(); //get tester status for all sites and pins
PinPropertyMonitor ppm1(sites, pinList); //get tester status for given sites and pins
PinPropertyMonitor ppm1(sites, pinList, "PPMU"); //filter by instrument "PPMU"
PinPropertyMonitor ppm1(sites, pinList, "PPMU", "slewI"); //filter by instrument "PPMU" and property "slewI"
