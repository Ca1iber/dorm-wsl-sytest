Topic 129011

MTP_MEMORY_TEST.getPassFailResult()

The getPassFailResult() member function of MTP_MEMORY_TEST lets you retrieve the overall test result for the site in focus.

Syntax

bool getPassFailResult(void)

Example

Enabling address-based results, executing the test, and storing the test result in an external variable:

MTP_MEMORY_TEST memoryTest();
memoryTest.enableAddressBasedResults(true);
CONNECT();
memoryTest.execute();
bool test_result;
test_result = memoryTest.getPassFailResult();

Related information

MTP_MEMORY_TEST

Functional changes
