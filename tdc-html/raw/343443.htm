Topic 343443

rdi.route().pin()

Subtopics

  1. rdi.route().pin().setOff()
  2. rdi.route().pin().setOn()
  3. rdi.route().pin().execute()

Specifies a utility line or a Power MUX (PMUX) switch or a list of utility lines or PMUX switches that should be set to on or off directly without using the stored states.

This class is a data container to define pins for direct access to the utility lines and PMUX switches. The created ROUTE object can only be accessed via rdi.route().

Usage of the function:
  • Depending on the target pin, the function can be called in the code‑based mode or in the pattern‑based mode:
    Software‑controlled (static) utility lines: Code‑based mode only
    Sequencer‑controlled (dynamic) utility lines: Pattern‑based mode only
    PMUX switches: Pattern‑based mode only
    For more information, refer to Execution mode in topic SmartRDI.
  • The selected switches must already be defined in the "Name" column of the Utility Lines Config editor.
Execution sequence:
  • Code-based mode:
    • Combination of static utility lines and sequencer‑controlled utility lines or PMUX switches:

      The new state of the static utility lines is applied first, followed by a pattern that switches on or off the sequencer‑controlled utility lines and the selected PMUX switches.

    • Only sequencer‑controlled utility lines or PMUX switches:

      A pattern that switches on or off the sequencer‑controlled utility lines and the selected PMUX switches is started.

  • Pattern-based mode:

    A pattern that switches on or off the sequencer controlled utility lines and the selected PMUX switches is started within an RDI burst.

    Note The switch settings for any pin definition that contains static utility lines cannot be applied in pattern‑based mode. This restriction ensures that the sequence of applying the switch settings corresponds to the source code.
Note The functionality of this API is not affected by rdi.route().enableOnlyActiveSites().

Syntax

ROUTE& pin(const string &sPin);
List of parameters
Parameter Description
sPin The string defines one or more utility lines or Power MUX (PMUX) switches that are already defined in the Utility Lines Config editor.

Multiple definitions can be combined in one string. The delimiter is the comma ",". A comma at the end of the string is accepted to simplify merging of several strings.
Return value
A reference to the ROUTE object.
