TMU_PINS.getEdgeSelect()

Returns the selected edge type that triggers the event.

Syntax

TMU::EdgeType getEdgeSelect() const;

List of parameters

There are no parameters.

Return value

The selected edge type is returned. It can be RISE, FALL or RISE_FALL.

Related information

TMU_PINS.setEdgeSelect()

Functional changes

  1. Introduced in SmarTest 7.1.0
