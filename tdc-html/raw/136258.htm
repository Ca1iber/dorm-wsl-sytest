Using the Integrated Result Tool

Subtopics

  1. Opening the Integrated Result Tool
  2. Managing data logs
  3. Working with result data tables
  4. Analyzing test results

You analyze data logs using the Integrated Result Tool by loading them into the tool, opening them in tabular views, and examining their underlying data or displaying the logs as a variety of graphs.

For details, see:

  • Opening the Integrated Result Tool
  • Managing data logs
  • Working with result data tables
  • Analyzing test results

The result data stream is not saved to disc automatically. See Saving the system data log stream.

Functional changes

  1. Introduced in SmarTest 7.2.0
