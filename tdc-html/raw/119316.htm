Topic 119316

FLEXLM_LICENSE_REQUEST_COMPLETED

This asynchronous event indicates that the FlexLM license request is completed. This event is received after the FLEXLM_LICENSE_REQUEST_STARTED event.

The HVM client can get the requested, acquired and missing license information with this event passively. It can get these information with the GetFlexLMLincseState() API actively.

Dependency

Changing device is performed.

Parameter

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session that this event belongs to.

O

TIME_STAMP

The time point when this event occurs. It has two long-type parts, SECONDS and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always EXECUTION.

O

EVENT_BODY

The event parameter represented by a ParamList. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always FLEXLM_LICENSE_REQUEST_COMPLETED.

LICENSE_TYPES_REQUESTED

The list of requested license types. The license type can be "SMARTEST_SOC", "SMARTEST_OFFLINE_SOC" or "SOC_93K_FULL_SYSTEM_CAPABILITY".

LICENSES_REQUESTED

The list of requested licenses. It is in one-to-one correspondence with LICENSE_TYPES_REQUESTED.

LICENSES_ACQUIRED

The listed of acquired licenses. It is in one-to-one correspondence with LICENSE_TYPES_REQUESTED.

LICENSES_MISSING

The list of missing licenses. It is in one-to-one correspondence with LICENSE_TYPES_REQUESTED.
