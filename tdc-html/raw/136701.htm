CCTgetFuncBlkId

Helps to access the correct function block in the merged RF definition. Use CCTgetFuncBlkID()+id to access a function blockin both concurrent and serial mode. id is the original function block ID before merging.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

int CCTgetFuncBlkId();

List of parameters

There are no parameters.

Return value

Returns the offset of the original sequence block in the merged RF definition(sequence blocks).

Example

SEQ_SETTINGS::RF_MEAS_CW_OUT param1;
//to get the sequence block parameter for function block 2
RF_MEAS_BASE (name).getSequenceParam(CCTgetFuncBlkID()+1,name,param1);

Functional changes

  1. Introduced in SmarTest 7.2.0
