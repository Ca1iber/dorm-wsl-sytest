Topic 112634

Saving and loading filter rules

The BFM Viewer can save complete filter rule sets as files and reload these sets in later sessions. This allows you to preserve filter rules across sessions.

About this task

A active filter rules are discarded when you close a session or change devices. To save these rules, you must save them as a file and load them when you want to use them again.

Before you begin

The filter rules must be set up as desired before you save them. See Creating and editing filter rules for details.

Procedures

Saving filter rules

This procedure saves all currently defined filter rules, both active and inactive ones:

  1. In the Filters tab, click the Save button.

    A standard Save dialog is displayed.

  2. Choose a location for the file and enter its name.

    Make sure to give the file the .fr filename extension.

  3. Click Save.

Loading filter rules

This procedure overwrites all filter rules that are currently defined in BFM Viewer. Make sure to save them first if you do not want to lose them.

  1. In the Filters tab, click the Load button.

    A standard Open dialog is displayed.

  2. Choose the desired filter rules (.fr) file and click Open.

    The current BFM Viewer rules are discarded and the rules from the chosen file are loaded.

  3. Click Apply to activate the loaded rules.

Results

When you have saved the rules, they are stored in a file and are available for later re-use.

When you have loaded the rules, they are now the active filter rules.
