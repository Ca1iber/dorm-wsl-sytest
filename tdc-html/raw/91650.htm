Editing a Setup File Directly

Normally you edit your setup data with tools as the pin configuration tool. These tools are started from the Test Program Explorer or the 93000 menu. With these tools you change the setup data in the test system hardware.

Another way to edit your setup data is by opening the file with an editor and changing the firmware commands in the setup file which is stored on the hard disk of the system controller. After you have changed the setup file you must load the file again to the test system using the Test Program Explorer.

Note Although it is possible to edit your setup files directly, keep in mind that all checks for consistency are bypassed and in some cases the editor cannot interpret binary data correctly. This is valid especially for timing or vector setup files. Only very experienced users should edit the setup files directly.

To open a device setup file with an editor:

  1. In the Project Explorer view, open the device directory.
  2. Double-click the file you want to edit. The file is opened with an editor.
  3. Edit the file. When you close the editor, you are asked whether or not you want to save your changes.

Functional changes
