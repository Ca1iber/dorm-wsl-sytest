PS1600 pogo pin assignment

The PS1600 is the Smart Scale generation digital base card. With 128 channels per card it supports higher pin count and higher multisite testing, which enables smaller infrastructure usage and cost.

Pogo pin assignment SD pogo block

The standard-density (SD) pogo block (sometimes referred to as a single-density pogo block) connects 16 channels of a PS1600 card to the DUT board. The SD block is used for the following PS1600 pogo cable assemblies:
  • PS1600 pogo cable assembly E8030PSD: 8 SD pogo blocks
  • PS1600 pogo cable assembly E8030PSDL: 8 SD pogo blocks

The SD pogo block can also connect to DUT boards that are designed for the HD pogo block or for the VHD pogo block but can access only the channels A1 … A16 on rows b and c. For more information, refer to Pogo block compatibility.

Pogo pin assignment HD pogo block

The high-density (HD) pogo block connects 32 channels of a PS1600 card to the DUT board. The HD block is used for the following PS1600 pogo cable assembly:
  • PS1600 pogo cable assembly E8030PHD: 4 HD pogo blocks

The HD pogo block can also connect to DUT boards that are designed for the SD pogo block as long as landing pads are provided for the extra pogo pins of the HD block. In addition, the HD pogo block can connect to DUT boards that are designed for the VHD block but can access only channels A1 … A16 and B1 … B16 on rows a, b, c, and d. For more information, refer to Pogo block compatibility.

Pogo pin assignment VHD pogo block

The very-high-density (VHD) pogo block connects 64 channels of a PS1600 card to the DUT board. The VHD block is used for the following PS1600 pogo cable assembly:
  • PS1600 pogo cable assembly E8030PVHD: 2 VHD pogo blocks

The VHD pogo block can also connect to DUT boards that are designed for the SD pogo block or for the HD pogo block as long as landing pads are provided for the extra pogo pins of the VHD block. For more information, refer to Pogo block compatibility.

This pogo cable assembly is to be used for special configurations only.

CAUTION The 7-row VHD block uses the row sequence a-e-b-f-c-g-d for compatibility with the 4-row STD block and HD block. This sequence is different to the row sequence a-b-c-d of the 4-row pogo blocks. Do not use the wrong row sequence a-b-c-d-... for the 7-row VHD block. Specific design rules

Specific design rules must be followed when designing a new DUT board and assigning PS1600 channels:
  • Pogo block compatibility: The three types of pogo blocks use the same grid. We recommend adding always landing pads for the VHD pogo block so that the higher density pogo blocks can connect to DUT boards that are designed for lower density pogo blocks.
  • Differential pin pairs: For the configuration PS1600 pins as differential pin pairs, these pin pairs must be considered when designing the DUT board.
  • The SmartLoop loopback scheme: Loopback pins must belong to the same test processor.
  • Pin assignment for Fast Sync / Fast Match: For fast local synchronization, the synchronized DUT pins must be assigned to the same group of channels respectively to the same test processor.
Pogo block compatibility

For the digital channels A1 … A16, the high-density pogo block has the same pogo pin assignment as the standard-density pogo block. These channels are marked yellow in the tables above.

Digital channels B1 … B16 are the additional channels of the high-density pogo block. For compatibility with the standard-density pogo block, only "NC" positions of the standard-density block are used for B1 … B16. These channels are marked light-red in the HD pin assignment table above and are located in rows a and d of the pogo block with exception of digital channel B16 that is located in row b.

The very-high-density pogo block has the same pogo pin assignment as the STD and HD block for channels A1 … A16 and B1 … B16. Channels C1 … C16 and D1 … D16 occupy positions in the extra rows e, f, and g. These extra rows are placed between the other four rows a, b, c, and d and are marked light blue and green in the VHD pin assignment table above.

For the compatibility of the three type of pogo blocks, refer also to Pogo block compatibility.
