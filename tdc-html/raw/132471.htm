TMU_PINS.waitTMUfinished()

Sets the time to wait before ending the TMU data acquisition. It also saves the errors and the finish information for every pin and site.

Syntax

TMU_PINS& waitTMUfinished(DOUBLE sec,Boolean& finished);
Parameters

I/O

Parameter

Description

I

sec

The time to wait in seconds.

O

finished

Whether the data acquisition is finished or not.

Return value

There is no return value.

Example

STRING          pinList         = "...,...";
int             initDiscard     = ...;
TMU_TASK        tmuTask;
...
...

ON_FIRST_INVOCATION_BEGIN();
{
    tmuTask.pin(pinList)
            .setEdgeSelect      (...)
            ...
            ...
            .setInitialDiscard  (initDiscard);

    tmuTask.setAsPrimary();
    tmuTask.setup();

    FUNCTIONAL_TEST();

    bool taskFinished = false;

    tmuTask.waitTMUfinished(tmuTimeout, taskFinished);

    ...
    ...
}
ON_FIRST_INVOCATION_END();

//
// Upload the results into the result cache
//
tmuTask.uploadRawResults();

//
// Get the reference to the resultCache
//
TMU_RESULTS&  tmuResults = tmuTask.getResultCache().pins(pinList).shot(1);

if ( !tmuResults.checkSiteAppTypeStored(TMU::APP_RAW))
{
    cout << "ERROR!! No results uploaded for TMU RAW measurement" << endl;

    return;
}

//
// Continue processing of results for the TMU RAW measurement
//
...
...
