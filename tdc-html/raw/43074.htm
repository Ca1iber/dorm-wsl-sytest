Resizing the Wafer Map Geometry

You can resize the wafer map editor in the following two ways.

Procedure

  • To double the size of the wafer map geometory, click Display > Double Size in the Wafer Description Editor.
  • To manually define the size of the wafer map geometory,
    1. click the X in the upper left of the wafer map editor and select Advanced > Special Window Settings. The Edit Window-Specific Settings-Kwin dialog pops up.
    2. In the Geometory tab, check the box before size, select Force from the list and then enter the size you want to have. The scaled values you enter should have roughly the same aspect ratio with the default value.
