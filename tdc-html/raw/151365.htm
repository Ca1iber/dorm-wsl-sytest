Topic 151365

getVoltageWaveform()

Retrieves the voltage measurement values from a previously performed combined voltage and current measurement.

The function requires that viMeas() has been previously executed in an RDI block. The function can be used only in the code‑based mode. The read values are from the site in focus.

Syntax

ARRAY_D& getVoltageWaveform(const string& pin);
Parameter

Parameter

Description

pin

The pin to query.

Return Value

An ARRAY_D object containing only the voltage measurement values of the combined voltage and current measurement.

Example

ON_FIRST_INVOCATION_BEGIN();
{
    rdi.dc().pin("Pin_1")
            .vForce(0.0 V).vForceRange(10.0 V)
            .iClamp(-20.0 mA, 20.0 mA).iForceRange(50 mA)
            .execute();

    RDI_BEGIN();
    {
        rdi.dc("viDGT").pin("Pin_1")
                .viMeas()
                .average(50)
                .samples(20)
                .FS(10 kHz)
                .execute();
    }
    RDI_END();
}
ON_FIRST_INVOCATION_END();

ARRAY_D measuredVoltageValues;
ARRAY_D measuredCurrentValues;

double measuredVoltage_1, measuredVoltage_2;
double measuredCurrent_1, measuredCurrent_2;

measuredVoltageValues = rdi.id("viDGT").getVoltageWaveform("Pin_1");
measuredCurrentValues = rdi.id("viDGT").getCurrentWaveform("Pin_1");

measuredVoltage_1 = measuredVoltageValues[0];
measuredVoltage_2 = measuredVoltageValues[1];

measuredCurrent_1 = measuredCurrentValues[0];
measuredCurrent_2 = measuredCurrentValues[1];
