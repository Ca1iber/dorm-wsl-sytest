Viewing different types of results on a shmoo plot

If you have selected multiple Test modes in the testMode field when setting, you can view the results related to each test mode on the shmoo plot.

Before you begin

  • Make sure you have selected multiple Test modes in the testMode field when Setting up a shmoo test in the Shmoo Tool.
  • Executing the shmoo test to display its shmoo plot on a shmoo page.

Procedure

  1. Right-click the shmoo plot and select Test Modes.

    A shortcut menu opens. All the selected Test modes during setting are listed.

  2. Select your desired test mode.

Results

  • The new results for the selected test mode are dispalyed on the shmoo plot.
  • The name of the selected test mode is displayed in the plot title.
