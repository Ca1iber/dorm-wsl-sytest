Topic 149619

enPassFail()

This function retrieves the pass/fail result of the specified pattern in .label().

Syntax

enPassFail()

Example

RDI_BEGIN();
  rdi.tmu("a").label("label1").pin("A")....enPassFail().execute()
  rdi.dc("b").label("label2").pin("B")....enPassFail().execute();
  rdi.digCap("c").label("label3").pin("C")....enPassFail().execute();
RDI_END();

rdi.id("a").getPassFail();
rdi.id("b").getPassFail();
rdi.dc("c").getPassFail();

Related information

Pass/Fail per label

Functional changes

  1. Introduced in SmartRDI 2.4.0
