Topic 349552

Setting the period

Subtopics

  1. Minimum period / maximum frequency of the sequencer

Click period on the Select pulldown menu of the Timing Setup window.

Enter the desired period (in ns) into the period entry field. The allowed range depends on the type of system you have. For the minimum period or the maximum frequency, refer to Minimum period / maximum frequency of the sequencer.

Note If you have already set up some timing settings and subsequently changed the period to a smaller value, SmarTest may automatically correct the existing settings. In this case SmarTest displays a message in the report window.

Functional changes

  1. Introduced before SmarTest 6.3.2
