Pin Configuration Tool preferences page

You can change the following preferences on the Advantest V93000 > Pin Configuration Tool preference page.

  • Select Enable alternate coloring for rows to show the rows of the pin configuration tool in alternate colors.
  • Click Pin Config Tool Colors to open the preferences page General > Appearance > Colors and Fonts, where you can define the colors.
  1. On the list, open Advantest > Pin Configuration Tool.
  2. Select the background color for content depending on its function within the pin configuration.
  3. Click the color button in the upper right corner (left beside the Reset button) to open the color chooser window.
  4. Select a color.
  5. On the Preferences window click Apply.

    If have the pin configuration tool opened in the background you can see immediately your changes.

Functional changes

  1. Introduced in SmarTest 6.5.4
