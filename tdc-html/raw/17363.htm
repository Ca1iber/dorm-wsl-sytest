Editable sections

The Timing Set and Wavetable entities in the uppermost area of the window provide information, and are also user-editable. To edit any particular entity, click the appropriate edit field (it appears highlighted), enter a new value, and press return.

You can enter figures with up to 9 decimal places. Depending on the text you have typed, the closest matching entity will be displayed. For an alternative way of changing any of these parameters, see the topics listed in the "In this section" paragraph.

The timing and edge check information in the middle area of the window is changed by activating the appropriate radio button.

The variable information in the table at the bottom part of the window is also editable - apart from each variable name and its unit of measurement, as these will be retrieved automatically from the equation file. To edit any particular value (actual, min, max, etc.), double-click the appropriate edit field, double-click any existing value, enter a new value, and press return. See also Changing Spec Values.

Note You define the units in the equation based spec setup only. You cannot define units using the spec tool.

Update between software and hardware

Unlike the Level setup tool, the Spec Tool does not automatically update the frontend of the hardware. The Spec Tool UI download changes levels or DPS sets inside the backend hardware, but not the frontend state. To apply the modifications to the frontend, the primaries need to be activated:

  • Press the download button of the Spec Tool for downloading the changes to the backend of the hardware.
  • Activate the primaries for applying the changes to the frontend:
    • Perform a global disconnect / connect sequence using the Connect and disconnect buttons in the short cut bar of the SmarTest Eclipse window
    • or perform a disconnect / connect sequence of the individual channel using the Hardware view
    • or invoke the FW command APRM in the Firmware view tab.

Unit conflict between EQNSET and SPECSET

If one or more of the loaded SPECSET contain units different to the units that are defined in the referenced EQNSET, SmarTest displays the following warning window. This may happen, for example, after importing setups converted by STIL reader with version 2.1 or earlier.

WARNING: Unit for spec variable "<variable>" in EQNSET <no>, SPECSET <no> is not consistent (EQNSET unit: [<unit>], SPECSET unit: [<unit>]).
Only EQNSET units will be used. To overwrite SPECSET units with EQNSET units, press "Download" and then save the setup.
To keep SPECSET units, edit EQNSETs and set the same units as in SPECSETs.

Follow the procedure given in the warning window (for details on the spec tool interface, refer to The Spec Tool window):

  • Use units defined in the equation based setup:
    1. On the Spec Tool click the Downloadbutton.
    2. On the menu click File > Save.
  • Use units defined in the SPECSET setup:
    1. Edit the equation based setup file.
    2. Refer to Equation based timing setup and Equation based level setup.
