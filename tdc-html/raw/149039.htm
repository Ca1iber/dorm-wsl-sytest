Topic 149039

writePat()

Adds device cycles data or wavetable index to a pattern.

Syntax

writePat(const string &dvc,int startVec);
List of parameters

Parameter

Description

dvc

The device cycle you want to write into the pattern.

startVec

The starting position of the vector to be written. If the startVec parameter missing, the default value is 0.

Example

RDI_BEGIN();
rdi.smartVec().pin("DATA1").writePat("0,1,Z,Z,H",1).execute();
RDI_END();

Related information
