Topic 140705

Building MTP files with MTP-EWC

Subtopics

  1. Accessing the MTP build configuration pages
  2. The MTP build configuration pages
  3. MTP build commands in the shortcut menu

The MTP build functions offered in MTP-EWC (SmarTest Work Center) are the MTP build configuration pages and MTP build commands. To build MTP .apg files, you first set up build configurations on The MTP build configuration pages, and then build those files with MTP build commands.

About this task

The advantages of using MTP_EWC to build are:

  • You can create multiple build configurations.
  • You can create multiple compilers in one build configuration. Each compiler will compile a group of .apg files.
  • Incremental build

    During a SmarTest session, the MTP .apg files which have been built will not be built again by the same build configuration unless you modify the .apg files, the related MTL setup files, or the compiler options.

    Note To learn the other features on MTP-EWC, see MTP-EWC.

Procedure

  1. Open the MTP build configuration pages.

    You will see the configuration pages, which include the MTP Build main page and two subpages: Compiler Options and Environment. For details, see The MTP build configuration pages.

  2. On the MTP Build page, create as many build configurations as you want and activate the one you want to use.

    For details, see the "MTP Build page" section in The MTP build configuration pages.

  3. On the Compiler Options page, select a created build configuration and set up compiler options for it.

    You can set up different compilers for this build configuration. Each compiler, set up as a Compiler Group on this page, has its own compiler options and .apg files. When build, each compiler will compile its contained .apg files according to its compiler options.

    For details, see The Compiler Options page.

  4. On the Environment page, select a created build configuration and set up environment variables for it.

    For details, see The Environment page.

  5. If you have created multiple build configurations in step 2, repeat step 3 and 4 for each build configuration.
  6. Click on OK to finish setup.

    All configuration pages close.

  7. In the Project Explorer view, right-click the .apg files or the MTP project containing the .apg files you want to build to display the MTP build commands.
  8. Select Build By Active (its keyboard shortcut is Alt + B) or Build MTP Pattern(s) Using to build the MTP .apg files.
