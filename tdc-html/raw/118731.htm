Topic 118731

TDL-related STIL Reader setup options

The TDL-related options in a STIL Reader setup file let you configure translation options that are specific to TDL files.

Syntax

The TDL-related options in alphabetical order:
tdl_2_edge_clocks=boolean
Whether to generate the CLOCK signal using two or three edges:
  • 0: CLOCK is generated using three edges (SBH/SBL).
  • 1: CLOCK is generated using two edges (RH/RL)

This parameter is optional. The default value is 0.

tdl_drive_off_position=time

Where the drive-off edge is placed.

By default, this edge is placed at the beginning of the cycle (at 0 ns). This parameter can be used to override that behavior for all pins. Possible options include:

  • A specific interval, specified as a number and a unit. Supported units include s, ms, us, ns, ps as well as other combinations of s with SI prefixes from E to a (for example, Gs or fs).

    There must be no space between the number and the unit, and the time must be between 0 and the period length. (Positions cannot be outside of the cycle.) The specified position must not lie after the compare edge.

    For example: "2.5ns", "333ps".

  • as_drive_on: Specifying this keyword puts the drive-off edge at the same position as the drive edge.

This parameter is optional. The default value is 0 ns.

See also tdl_signal_drive_off_position, below.

tdl_import_scan_structures=boolean
Whether to import scan structures:
  • 0: Scan structures are not imported.
  • 1: Scan structures are imported.

This parameter is optional. The default value is 1.

tdl_purge_unused_timing=boolean
Whether to remove unused timing templates and waveforms from the translated files:
  • 0: Leave all timing templates and waveforms in the translated files, even if they are unused.
  • 1: Remove timing templates and waveforms that are not used.
tdl_signal_drive_off_position={ pin:time, ...}

A list of positions for the drive-off edge for individual pins.

By default, this edge is placed at the position specified in tdl_drive_off_position or, if that parameter is omitted, at the beginning of the cycle (at 0 ns). This parameter can be used to override that behavior for individual pins.

  • pin is the name of the pin for which the position is specified.

  • time is the desired offset.

    Possible options for time include:

    • A specific interval, specified as an integer and a unit. Supported units include s, ms, us, ns, ps as well as other combinations of s with SI prefixes from E to a (for example, Gs or fs).

      There must be no space between the number and the unit, and the time must be between 0 and the period length. (Positions cannot be outside of the cycle.) The specified position must not lie after the compare edge.

      For example: "2.5ns", "333ps".

    • as_drive_on: Specifying this keyword puts the drive-off edge at the same position as the drive edge.

You can specify one or more combinations of a pin and a time, separated by commas. For example: {"data":"500ps"} or {"P1":"3ns", "P2":"4ns", "P3":3.2ns"}.

This parameter is optional. If it is not specified, the position set by tdl_drive_off_position (above) is used for all pins. This parameter is optional. The default value is 0.
