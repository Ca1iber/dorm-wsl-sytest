TMU_PINS.setInitialDiscard()

Sets the number of events to ignore before the first sample is taken.

Note This functionality is not supported for DC Scale pins. The function must therefore be omitted or the programmed value must be set to 0.

Syntax

TMU_PINS& setInitialDiscard(UINT64 val);

This function

Parameter

I/O

Parameter

Description

I

val

The number of initial discards.

Return value

A reference to the TMU_PINS object is returned.

Related information

TMU_PINS.getInitialDiscard()

  1. Introduced in SmarTest 7.1.0
