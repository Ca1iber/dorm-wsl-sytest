Topic 100173

Get the bin information

Use

long GetBin(char* softbin, int* hardbin)

long GetBinOfSite(long site, char* softbin, int* hardbin)

This function retrieves the software bin and hardware bin information of the bin that a site is binned to.

The softbin holds the bin name. The first function works for the site which is currently in focus while the second function works for the specified site.
