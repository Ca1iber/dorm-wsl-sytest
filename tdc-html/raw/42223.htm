Parameter: subdie_step_pattern

This parameter defines the sub-die stepping pattern of the prober. The pattern must be defined, when stepping_controlled_by is set to "smartest" or "learnlist, and the perform_subdie_probing is set to "yes."

[0 0] is the reference position of the first sub-die. The configured parameter is a list of lists of X,Y pairs that define the sub-die stepping. The values given for X and Y are step counts. Typically, the stepping starts with [0 0].

If a prober performs sub-die stepping, the die position is kept as long as the sub-die stepping pattern is not completed. In the graphical wafer test result display, sub-die testing appears as if the individual die positions were tested repeatedly, until the prober steps to the next die. If a sub-die fails, the complete die is displayed as failed in the wafer test result display of SmarTest.

Example: Row pattern to be performed on a grid of 2x2 sub-dies.

subdie_step_pattern: [ [0 0] [1 0] [0 1] [1 1] ]

Driver default: [0 0]

Changeable at run-time: no

Applicable for: probers

Example: subdie_step_pattern:[ [0 0] [1 0] [1 1] ]
