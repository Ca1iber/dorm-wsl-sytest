MTP_PPMU_MEASURE

The MTP_PPMU_MEASURE class provides an API for measuring specific pins with per-pin PMUs. You can define the measurement modes for the per-pin PMUs, execute the measurements in parallel, and retrieve the pins' test results.

MTP_PPMU_MEASURE provides the similar functionality to the PPMU_MEASURE API. But PPMU_MEASURE cannot be used for driver sharing test since the multiple executions will overwrite the previous results.

Note MTP_PPMU_MEASURE is available only for MTP.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/MTP_PPMU_MEASURE.h.
