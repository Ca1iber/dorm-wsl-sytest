Topic 346549

Printing tester status

Subtopics

  1. Printing tester status from system control
  2. Printing tester status from testflow
  3. Printing tester status from test method

There are several ways to print tester status for debug purpose. You can choose to print tester status to system console or text files, at default or customized settings.

Before you begin

Check that your SmarTest has a version no less than 7.5.2.

Procedure

Choose one from the following ways to read and print tester status (the current settings of all instruments).
  • Use the Print Tester Status button in the System Console toolbar. See Printing tester status from system control.
  • Automatically print tester status to files when test suite execution completes. See Printing tester status from testflow.
  • Customize tester status outputs through test method. See Printing tester status from test method.

Functional changes

  1. Introduced in SmarTest
  2. SmarTest 7.5.3: A new user flag "enableAccumulatedStateLogging" and a new button "Diff Tester Status" in the system console toolbar.
  3. SmarTest 7.6.0: New instrument "UTILITY" is supported.
