Topic 141807

execute()

Executes the previous specified setups in this line of code. It means starting the analog action in analog tests.

In the code‑based mode, the setups will be executed immediately.

In the pattern‑based mode, it will create the label for the specified setups. The burst pattern and the analog set will be generated and the burst pattern will be executed when RDI_END() is executed.

This function is available for all SmartRDI classes.

Syntax

execute();

List of parameters

There are no parameters.

Return value

There is no return value.

Example

rdi.util().pin("upin_A").setOn().pin("upin_B").setOff().execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
