Topic 10639

Create a fixed level set

Subtopics

  1. Set fixed driver levels
  2. Set fixed receiver levels
  3. Set fixed clamping levels

The system lets you create multiple level sets up to the maximum number previously defined by the command DSCP, DSCP? - (Define System Control Parameter). Each level set contains all level resources. The sequencer controls the use of level sets during test. At power-on, one level set exists, containing the default drive and receive levels. This set is identified as level set 1.

Note The support for fixed level setups is discontinued with SmarTest version 7.4.1T. We recommend using the Equation based level setup for all releases of SmarTest 7.2 or higher versions.

The commands associated with creating a level set are as follows:

  • LSUS, LSUS? - (Level Sets USed)
  • DRLV, DRLV? - (DRive LeVel)
  • RCLV, RCLV? - (ReCeive LeVel)
  • TERM, TERM? - (TERMination mode)
  • CLMP, CLMP? - (CLaMP level)
  • EQFC, EQFC? - (EQualization and Filter Configuration)

Before creating a level set, use the LSUS? query to determine the number of sets currently in use. You can then identify the new set using the next available number. The firmware will then be updated to include the new number of sets.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.1: : Added firmware command EQFC[?]
