Topic 136921

The functions of the customized shmoo test method template

Subtopics

  1. addParameterType

The functions in the customized shmoo template aim to create new test method parameters, define results shown on shmoo plots, and perform actions before, during or after a shmoo test.

The functions are:

  • addParameterTypes(): Lets you add parameters to be varied for the x-axis and y-axis. The parameters are int or double data type.

    To add, you must use addParameterType().

    The added parameters will become the options of parameterType which is a test method parameter as described in ac_tml.AcTest.Shmoo.

    Do not use any other APIs here.

  • addParameters(): Lets you add new the test method parameters.

    To add, you use the addParameter() API.

    Do not use any other APIs here.

  • customizedPreShmooRun(): Lets you perform actions before a shmoo starts.

    For example, you can set a device to a certain state before a shmoo executes the first cell.

  • customizedPostShmooRun(): Lets you perform actions after a shmoo ends.

    For example, you can restore device states after a shmoo finishes the last cell.

  • runAtEachRow(): Lets you perform actions before the shmoo executs the next row or column.
  • userDefinedMeasure(): Lets you define any measurement.

    Here, you can define the results showing on shmoo plots with the SHMOO_RESULT() API. To view the results with the Shmoo Tool, see Viewing customized test results for a customized shmoo test in the Shmoo Tool.

Example

Create a customized shmoo to measure the voltages at the IO1 and IO2 pins, and the pass/fail result of the current site.

#include "Shmoo.hpp"

using namespace std;

//This class is used to customize shmoo.

class MyShmoo : public Shmoo {

protected:
// Add class data member
      double iForce_uA;
      bool pfResult;
      double meaValue1,meaValue2;

protected:

  virtual void addParameterTypes()
  {
      // Add iForce_uA to the option of the ParameterType test method parameter in both x-axis and y-axis
      addParameterType("iForce_uA", "double", &iForce_uA);
  }

  virtual void addParameters()
  {
      //Add iForce_uA and myTestmethodP as two test method parameters
      addParameter("iForce_uA", "double", &iForce_uA);
      addParameter("myTestmethodP", "string");
  }

  virtual void customizedPreShmooRun()
  {
    registerCustomizedShmoo(); //@see Customized Shmoo Skeleton, Do not remove
    Primary.label("gross_func");
    FUNCTIONAL_TEST();
  }

  virtual void customizedPostShmooRun()
  {
    //Add your code
  }

  virtual void runAtEachRowBody()
  {
    //Add your code
  }

  virtual bool userDefinedMeasure()
  {
      PPMU_SETTING ifvmSet;
      PPMU_RELAY ppmuOn, acOn;
      PPMU_MEASURE  ifvmMea;
      TASK_LIST meaTask;

      ifvmSet.pin("I/O1,I/O2").iForce(iForce_uA uA).iRange(1 mA).min(1 V).max(2 V).mode("IFVM");
      ppmuOn.pin("I/O1,I/O2").status("PPMU_ON");
      ppmuOn.wait(1.3 ms);
      ifvmMea.pin("I/O1,I/O2").execMode("PVAL");
      meaTask.add(ppmuOn).add(ifvmSet).add(ifvmMea);
      meaTask.execute();

      FOR_EACH_SITE_BEGIN();  // to get value per site
      meaValue1 = ifvmMea.getValue("I/O1");
      meaValue2 = ifvmMea.getValue("I/O2");
      pfResult = ifvmMea.getPassFail();

      //set result to shmoo to display the value result in shmoo tool
      SHMOO_RESULT.site(CURRENT_SITE_NUMBER()).pin("I/O1").testName("meaVoltage1").setResult(meaValue1);
      SHMOO_RESULT.site(CURRENT_SITE_NUMBER()).pin("I/O2").testName("meaVoltage2").setResult(meaValue2);
      SHMOO_RESULT.testName("pfResult").setResult(pfResult);
      FOR_EACH_SITE_END();

      return pfResult;
  }
};

REGISTER_TESTMETHOD("AcTest.MyShmoo", MyShmoo);
