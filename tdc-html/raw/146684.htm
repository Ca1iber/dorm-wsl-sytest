SET_ENABLED_SITES()

Enables and disables sites in multisite testing and updates the test method internal cache.

Enabled sites will be connected with the initialization of the next test routine (disabling is done immediately).

Syntax

void SET_ENABLED_SITES( TM::MS_SITE_SET sites );
Parameter

Parameter

Description

sites

A character array. Each character except sites[0] will be used to enable or disable a site; sites[0] will be ignored:

  • If sites[i] is not 0, site i will be enabled.
  • If sites[i] is 0, site i will be enabled.

i starts from 1 to represent site 1, 2, 3, ...; 0 is not a valid site number.

Do not enable more than the current configured sites.

Example

//
// Get number of configured sites
//
INT     numberOfConfiguredSites;
ARRAY_I configuredSites;

numberOfConfiguredSites = GET_CONFIGURED_SITES(configuredSites);

//
// Set enabled sites
//
TM::MS_SITE_SET enabledSitesSet;

for (INT siteIndex = 1; siteIndex <= numberOfConfiguredSites; siteIndex++)
{
    if ((siteIndex == 1) || (siteIndex == 3))
    {
        enabledSitesSet[siteIndex] = 0;
    }
    else
    {
        enabledSitesSet[siteIndex] = 1;
    }
}

SET_ENABLED_SITES(enabledSitesSet);

//
// Get enabled sites, 1st syntax, string
//
STRING  enabledSitesString;
INT     numberOfEnabledSites;

numberOfEnabledSites = GET_ENABLED_SITES(enabledSitesString);

cout << "1st syntax, string,  "
     << numberOfEnabledSites << " sites enabled: "
     << enabledSitesString << endl;

//
// Get enabled sites, 1st syntax, ARRAY_I
//
ARRAY_I enabledSitesIntArray;

numberOfEnabledSites = GET_ENABLED_SITES(enabledSitesIntArray);

cout << "1st syntax, ARRAY_I, "
     << numberOfEnabledSites << " sites enabled: "
     << enabledSitesIntArray << endl;

//
// Get enabled sites, 2nd syntax, TM::MS_SITE_SET
//
TM::MS_SITE_SET enabledSitesCharArray;

GET_ENABLED_SITES(enabledSitesCharArray);

cout << "2nd syntax,            "
     << "enabled sites: ";

for (INT siteIndex = 1; siteIndex <= numberOfConfiguredSites; siteIndex++)
{
    cout << (INT) enabledSitesCharArray[siteIndex];
}

cout << endl;

It is assumed that the eight sites (site number: 1 to 8) are configured. Sites 1 and 2 are disabled by API SET_ENABLED_SITES(). The modified settings are read back by all three syntax variants of API GET_ENABLED_SITES(). The code above results in the following output:

1st syntax, string,  6 sites enabled: 01011111
1st syntax, ARRAY_I, 6 sites enabled: {	2,	4,	5,	6,	7,	8,	}
2nd syntax,            enabled sites: 01011111
