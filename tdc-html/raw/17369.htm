Changing the Description of Specification Sets

  1. Click Change Name in the Change pulldown menu.

    A screen similar to that of the figure below appears.

  2. Highlight the specification set whose description you want to change.
  3. Key in a new description in the Description edit field. note that it must not contain a semicolon.
  4. Repeat this last step as often as required (for other specification sets), and click done when finished.

Functional changes

  1. Introduced before SmarTest 6.3.2
