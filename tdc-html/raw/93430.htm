Topic 93430

Setting parameters for the binning executor

To edit the parameters of the BinningExecutor test method, click it in the tabular test editor. The parameters are displayed in the Test Suite window and you can edit them there.

Note The binning executor must be immediately followed by a multibin, which performs the final binning.
Parameters

Name

Type

Value

Softbin

Integer

Default: 1

Hardbin

Integer

Default: 1
