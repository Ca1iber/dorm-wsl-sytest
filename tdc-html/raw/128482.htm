Offline result emulation for Class TASK_LIST

Measurements can be made by using DPS_TASK, SPMU_TASK, and PPMU_MEASURE objects directly (by calling their execute() member functions) or be put in a TASK_LIST object which queues up tasks to be executed (by calling the execute() method on the TASK_LIST object rather than on the TASK objects themselves). This requires an enhancement also on the TASK_LIST add() method which takes a measurement name as additional parameter.

TASK_LIST& add(const TASK& task)

This is the existing function which adds the specified task to the task list.

TASK_LIST& add(const TASK& task, const string& measurementName)

This function adds the specified task to the task list.

Parameter

measurementName

Associate the measurement that will be executed by calling task_list.execute() with offline data.
