Introduction

STIL Reader is a tool that translates test description files in the STIL, WGL, or TDL91 formats to V93000 format, either to be run immediately or to be modified with the standard SmarTest tools.

The STIL 1450-1999, 1450.1, and 1450.2 formats are supported.

Operating principles

STIL Reader converts specified STIL files in a batch operation to V93000 format. The conversion can either be started from the command line or from the STIL Reader window. The conversion details can be controlled by:

When operating as a command line tool, STIL Reader can be controlled in a number of ways:

  • By command-line parameters (only when launched from the command line)
  • By an optional configuration file
  • By optional preflight scripts that are automatically launched before the tool converts the files

STIL Reader reads the specified source files and converts all valid STIL blocks to V93000 data files according to the active settings. STIL Reader operates in batch mode, that is, without human intervention during the conversion process. It outputs progress information to STDOUT or, when the graphical interface is used, to the STIL Reader window.
