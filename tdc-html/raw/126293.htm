PROTOCOL_TEST_RESULT_VECTOR

The PROTOCOL_TEST_RESULT_VECTOR class is independent from the specific protocol definition. It provides access to all result proxies of transactions that capture results.

Constructor

PROTOCOL_TEST_RESULT_VECTOR();

Creates an empty result vector object that is not associated to a protocol test when instantiated. Only when assigned from an object generated through a protocol test, the object can be used to access result data.

PROTOCOL_TEST_RESULT_VECTOR(const PROTOCOL_TEST_RESULT_VECTOR&);

Constructs a copy of a result vector. The new object has the same association with a protocol test as the original and provides the same access to result proxies.

Operator

PROTOCOL_TEST_RESULT_VECTOR& operator=(const PROTOCOL_TEST_RESULT_VECTOR&);

Assigns a result vector. The assigned object has the same association with a protocol test as the original and provides the same access to result proxies. Any previous association is released and the results can no more be accessed through this object.

int size() const;

Returns the number of result proxies accessible in this result vector. When used with the default generated wrapper, this will be the number of transactions with capture parameters used in the protocol test instance.

const TRANSACTION_RESULT_PROXY& operator[](int index) const;
Parameter

I/O

Parameter

Description/Range

I

index

Index of parameters captured.

Valid DC/DC power units will be 0 through size()-1.

Provides access to the results of a specific transaction within the associated protocol test.

The index counts through transactions with capture parameters in the same order specified in the protocol definition.

Member function

getResultArray()

Boolean getResultArray(ARRAY_I& resultArray);

This function store the data of the result vector in an integer array. This can be used to construct a WAVE object for further processing.

Parameter

I/O
