Topic 149063

pMode()

If one device cycle extends over multiple tester cycles, this is called a 1/x mode or padding mode, also known as pMode. The parameter in pMode() is specified as the number of tester cycles per device cycle. For example, pMode(4), which means that four tester cycles describe one device cycle. The default value is set to 1.

pMode() can be set to different values per pin within an .execute() command.

pMode() cannot vary for the same pin within an .execute() command.
Supported functions
Bit stream functions Data block functions Burst functions
writeBit() writeData() writeDataBurst()
defaultBit() expectData() writeParDataBurst()
fillBit() readData()
expectBit()
readBit()

pMode() does not support writeVec(), fillVec(), defaultVec(), and writePat().

Syntax

pMode(int Pmode);
List of parameters

Parameter

Description

Pmode

The number of tester cycles per device cycle.

Example

RDI_BEGIN();
  rdi.smartVec().pin("DATA1").fillBit(1,4,2).pMode(2).execute();
  rdi.smartVec().pin("DATA3").readBit(4,2).pMode(2).execute();
  rdi.smartVec().pin("DATA5").writeData(0x54,8,4).pMode(4).execute();
  rdi.smartVec().pin("DATA7").readData(8,4).pMode(4).execute();
RDI_END();
