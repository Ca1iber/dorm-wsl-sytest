Help menu

The Bit Fail Map Viewer's Help menu lets you get help on the BFM Viewer and view version information.

The menu contains these commands:

  • BFM Viewer - Help

    Choosing this command displays the BFM Viewer's online help.

  • BFM Viewer - Context Help

    Choosing this command turns the mouse pointer into a question mark. Clicking an object in the BFM Viewer displays the help page for that object.

  • About

    Choosing this command displays version information on BFM Viewer.

Functional changes

  1. Introduced before SmarTest 6.3.2
