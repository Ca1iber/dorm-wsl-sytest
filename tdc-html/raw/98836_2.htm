UTIN? - (UTility line INputs)

The UTIN? (UTility line INputs) query reads the current state of the seven utility input lines URW06 ... URW00. The command is still available for F330 compatibility reasons.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

UTIN?

returns: 

UTIN {data}

Parameters

data

This parameter returns a decimal number that you must translate to binary.

Ignore the most significant bit. The other bits give the state of the seven lines.

Application

Reading the input utility lines, see Utility Line Commands.

Example

UTIN?

returns:

UTIN 6

This example returns a decimal value of 6, which is 0000 0110b.

Functional changes

  1. Introduced before SmarTest 6.3.2
