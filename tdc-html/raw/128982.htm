MTP_MEMORY_TEST.setStopCaptureCycle()

The setStopCaptureCycle() member function of MTP_MEMORY_TEST lets you specify with which cycle the data capturing is to end.

This is an optional method.

Syntax

MTP_MEMORY_TEST& setStopCaptureCycle(const LONG64 cycle)

Parameter

Description

cycle

The number of the last cycle that is to be captured.

Specifying -1 sets the data capture to end after the last cycle (that is, to capture the cycles until the end).

The default is to end the data capture after the last cycle.

Example

To end capturing data after cycle 1024:

MTP_MEMORY_TEST memoryTest();
memoryTest.setStopCaptureCycle(1024);
