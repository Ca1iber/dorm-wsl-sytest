TESTSET().testnumber()

The function has three forms, which allow you to get a test number based on different information provided:

  • Name of a test result: testnumber(&name, logname)
  • Integer: testnumber(number)
  • TESTNUMBER object: testnumber(&testnumber)

Instead of using this member function you can assign a number in the test table.

Syntax

TESTSET & testnumber(const STRING &name, bool logname = false);

This form of the function assigns a test number to a test result from the test number values entered in the Properties view for the specified test name, and the number of calls for the TEST member function with that test name. You can use this member function to assign a test number to a test result that does not have a test name, such as the result of a functional test. In this case, you must enter a test name in the Properties view, even if you have selected a functional test.

If you wish to log the specified test name, set the logname parameter to TRUE. The name is stored into the EDL as a TestNameAttr. The values of the test number offset and test number increment named "name" are searched from the test number table whose values are input through the Properties view. If "name" and the corresponding values are found, when one of the TEST() methods is called, these values are used to generate a subtest test number. The subtest test number return value is stored into the EDL as a TestId attribute.

TESTSET & testnumber(int number);

If the test_number_enable testflow flag is enabled, this form of the function stores the number integer value in the EDL as a TestId attribute.

TESTSET & testnumber(int number, const bool forceSTDFTestName);

If the test_number_enable testflow flag is enabled, this form of the function stores the number integer value in the EDL as a TestId attribute.

If forceSTDFTestName is true, the data formatter writes the name value of the test directly into the TEST_NAM field of the TSR record, instead of calculating it from the test suite name, test name, and pin name. If this parameter is false, it results in the same behavior as using TESTSET & testnumber(int number).

TESTSET & testnumber(TESTNUMBER &testnumber);

This form of the function assigns a test number for a test result from the offset and increment values defined by the TESTNUMBER API. When the test_number_enable testflow flag is enabled and one of the TEST() methods is called, the integer value returned by testnumber.applyTestNumber() is stored in the EDL as a TestId attribute.

TESTSET & testnumber(TESTNUMBER &testnumber, const bool forceSTDFTestName);

This form of the function has the same effect as TESTSET & testnumber(TESTNUMBER &testnumber), above. In addition, it lets you specify that the name of the test is put into the TEST_NAM field of the TSR record (as described for TESTSET & testnumber(int number, const bool forceSTDFTestName), above).

Note The TEST() methods have to be called within the scope of the testnumber variable after this method is called. If one of the TEST() methods is called outside of the testnumber variable scope, an error occurs and the test method stops running. After you set the testnumber variable, one of the other testnumber() methods must be called before exiting the scope of the variable.

Parameter

Description

name

The name you assign to a result that has not been previously assigned a name. The name assigned through the Properties view will reference corresponding test number in the Properties view.

logname

A Boolean value that indicates whether the name is stored in the EDL.

number

An integer value that you assign to directly generate a subtest test number in the EDL.

testnumber

The TESTNUMBER object you assign to a test

forceSTDFTestName

If this parameter is true, the data formatter writes the name value name directly into the TEST_NAM field of the TSR record.

If the parameter is false, the data formatter calculates the content of the TEST_NAM field from the test suite name, test name, and pin name.

Examples

Example 1

This example assigns the test number defined in limit1 to the current test. The specified test name is logged to EDL stream.

TestSet.testnumber("limit1",true);

Example 2

This example assigns 100 as the test number to the current test.

TestSet.testnumber(100);

Example 3

This example assigns the test number in tm1 to the current test.

TESTNUMBER tm1;
...
TestSet.testnumber(tm1);
