Select the level/timing spec for test method parameter

In this window, you see the level and timing specs defined for your device.

Assuming you have defined a universal test method with parameters of a "specVar" type, you can add the appropriate level or timing specs to your test method by selecting them from the list.

The specs selected show up in the "specVar" box under "Parameters" in the test method property view.

You can use the filter text box to reduce the display to show only items whose names include the string you typed in.
