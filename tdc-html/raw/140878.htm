RESULT_AREA_CONFIG_PINS.setToDefault()

This function overwrites any previously configured settings with the default setting. All property values will be set with the default values (i.e. no error map or DC result area will be defined for any pin for the RESULT_AREA_CONFIG_SET that this instance is based on).

Syntax

void setToDefault() const;

List of parameters

There are no parameters.

Return value

There is no return value.

Related information
