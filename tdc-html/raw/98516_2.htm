CYRP? - (CYcle Resolution Parameter)

The CYRP command serves to set certain parameters for the fine granularity (EDGE) mode of the Error Map (see the CYRM command). The CYRP? query returns the current setting of these parameters.

Syntax

CYRP [recovery],[shots]
CYRP?

returns:

CYRP {recovery},{shots}

Parameters

recovery

Specifies whether the test is repeated with all receive edges enabled after the last fine granularity shot. This serves to reset the hardware registers into the state in which they were before the first fine granularity shot. Possible values are:

RCRY

The test is repeated at the end with all receive edges enabled. This is the default.

NRCR

The test is not repeated.

shots

Specifies whether additional shots are allowed. Possible values are:

ONE

No additional shots are allowed. This option allows execution of a test only if CYRM is set to CYCLE, or the mode parameter of DCRM is set to 8.

ONE can be used to prevent execution of a test in fine granularity mode (EDGE option of CYRM) with several shots if this would lead to erroneous results.

MULT

Additional shots are allowed. This is the default.

Application

Error Map

Example

CYRP NRCR,ONE
