Forcing waveform on a pin and sampling on the same pin

SmartRDI supports the combination of parallel AWG and DGT actions on the same DC Scale pin. That means that SmartRDI can force a waveform on a pin and take samples on the same pin at the same time.

When forcing a waveform and taking samples on the same DC Scale pin:

  • Each force event in the waveform is combined with a sampling event.
  • This option is supported for ONLY DC Scale pins.
  • The result retrieval is done with rdi.id("idx").getWaveform(pin) .
The combination actions of AWG and DGT on the same DC Scale pin:
  • vForce, iMeas
  • vForce, vMeas
  • iForce, iMeas
  • iForce, vMeas

Example

RDI_BEGIN();
  rdi.dc("id1").pin().vForce().iMeas().waveform(wav).FS(10 KHz).execute();
  rdi.dc("id2").pin().vForce().vMeas().waveform(wav).FS(10 KHz).execute();
  rdi.dc("id3").pin().iForce().iMeas().waveform(wav).FS(10 KHz).execute();
  rdi.dc("id4").pin().iForce().vMeas().waveform(wav).FS(10 KHz).execute();
RDI_END();
