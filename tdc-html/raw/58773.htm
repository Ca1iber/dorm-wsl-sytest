Recording position

In order to record the results for your region of interest within the restricted space of the internal Error Maps, you can specify a recording position. This position can be applied both to the detailed and the overview Error Map.

For the detailed Error Map, you can select if the recording position is to be interpreted as a start or a stop position, or if it is to be ignored. For the overview Error Map, it can only be treated as a stop position or be ignored.
