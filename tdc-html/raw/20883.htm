Topic 20883

Retrieving AC Test Results

Subtopics

  1. Retrieving Results of Multiple Measurements from Digitizer/Sampler
  2. Retrieving Result from Vector Memory
  3. Retrieving Functional Test Results

When the measured analog waveform data is retrieved, the analog waveform data requires the used measurement condition, that is, the used analog set. This is because the measurement data will be compensated with the used analog set data before the measurement data is returned.

This section describes how to retrieve measurement data of analog module in the following topics.

  • Retrieving Results of Multiple Measurements from Digitizer/Sampler
  • Retrieving Result from Vector Memory

This section also describes how to retrieve a functional test result in the following topic.

  • Retrieving Functional Test Results

For the following analog modules, you can check the status whether the analog modules have received one or more triggers (0) in a test or not (1). For details of this function, see Error Handling on Missing Trigger Input.

  • MCA Audio Digitizer (ADGT) / Video Digitizer (VDGT)
  • MCB LF Digitizer / VHF Digitizer
  • MCC Sampler
  • MCE LF Digitizer / VHF Digitizer

For debugging and analyzing the measurement result, you can pass the analog waveform (or array data) to Signal Analyzer by using the PUT_DEBUG API in order to display it on the Signal Analyzer. For details, see Passing Analog Waveform to Signal Analyzer or PUT_DEBUG.

You can also process the retrieved data using the Computation APIs. See Computing Measurement Values.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.1.2: Support of MBAV8+.
