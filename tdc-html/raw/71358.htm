SEARCH_FUNC_PIN_TASK

The SEARCH_FUNC_PIN_TASK class is a subsidiary data container that holds search conditions for individual pins or spec variables.

Class definition

Constructor
The class cannot be instantiated directly, but can only be accessed by the pin() or spec() member functions of the SEARCH_FUNC_TASK class.

Member functions

limits()
SEARCH_FUNC_PIN_TASK & limits(const STRING testname);
SEARCH_FUNC_PIN_TASK & limits(const LIMIT & limitobj);

This member function specifies start and stop values using a test name or an instance of the LIMIT class. It overrides the start and stop values specified with the start() and stop() member functions.

Parameters
testname Name of a test defined in the Properties view
limitobj Name of a LIMIT class instance
maskEdges()
SEARCH_FUNC_PIN_TASK & maskEdges(const STRING & edgeList);

This function masks some receive edges of the searched pins before executing the spec search. The mask will be cleared when the spec search is finished or the test method stops due to some error occurs before the search ends.

Parameter
edgeList The receive edges to be masked. If more than one edge is included, separate the edges by comma. It is in the format of "r1,r2,r3".
method()
SEARCH_FUNC_PIN_TASK & method(TM::SPEC_METHOD method);
SEARCH_FUNC_PIN_TASK & method(const STRING & methodstring;

This member function specifies the search method. A search method must be specified for every search condition

Parameters
method Type of the method. Possible values are:
TM::Linear Specifies a linear search from the start to the stop value with a certain step width.
TM::Binary Specifies a binary search between the start and stop value.
TM::LinBin Specifies a linear search from the start to the stop value, followed by a binary search between the resulting PASS and FAIL values.
methodstring Type of the method, specified as a string. Possible values are:
"L" Linear search
"B" Binary search
"LB" Combined linear and binary search.
numberOfSteps()
SEARCH_FUNC_PIN_TASK & numberOfSteps(INT val);

This member function specifies the number of steps for a linear or combined linear and binary search. You can either define a number of steps or the step width (with the stepWidth() member function) for a search condition, but not both.

Parameter
val Number of steps for a linear search.
resolution()
SEARCH_FUNC_PIN_TASK & resolution(DOUBLE val);

This member function specifies the resolution of the search. For a binary search, this is the minimum length of the interval between the returned PASS value and the returned FAIL value. For a linear (not: binary) search, the start, stop, and step width values are rounded to multiples of the specified resolution. If the parameter is omitted, the smallest values allowed by the software (for spec variables) or the hardware (for edges) will be used.

Parameter
val Resolution of the search.
resource()
SEARCH_FUNC_PIN_TASK & resource(const STRING & name)

This member function specifies a hardware resource that is to be varied in the search. Currently, only timing edges can be specified.

You must either specify a resource using this member function or you must specify a spec variable using the member function spec() but you cannot specify both.
Parameter
name Name of a hardware resource. Currently the only allowed values are "d1" through "d8" for drive edges, and "r1" through "r8" for receive edges.
resultPins()
SEARCH_FUNC_PIN_TASK & resultPins(const STRING & pinlist);

This member function specifies the output pins whose results are used to determine the total PASS or FAIL result of the test. In case of error count based search, the error count of the specified pin list is used to determine the pass/fail result. For multiple pins, sum of the error count is considered as the result to be compared with the error count threshold. This parameter is optional. If it is not specified, all output and I/O pins are used as result pins.

Parameter
pinlist The output pins whose results determine the test result.
setErrorCountNumber()
SEARCH_FUNC_PIN_TASK & setErrorCountNumber(const INT num);

This member function specifies the error count number as the pass threshold. It will overwrite the number specified by the constructor SEARCH_FUNC_TASK(const INT errorCountNumber, const TM::ERROR_COUNT_MODE). When the error count is less than errorCountNumber, it is regarded as PASS. When the error count is larger than errorCountNumber, it is regarded as FAIL.

This is designed to continue the execution with an almost passing pattern.

Parameter
num The error count number as pass threshold. It must be positive.
spec()
SEARCH_FUNC_PIN_TASK & spec(const STRING & name, TM::SPEC_TYPE type);
SEARCH_FUNC_PIN_TASK & spec(const STRING & name, const STRING & typestring);

This member function specifies a spec variable that is to be varied in the search.

You must either specify a spec variable using this member function or you must specify a resource using the member function resource() but you cannot specify both.

Parameters
name Name of a spec variable.

Note that you cannot specify the spec variable with SEARCH_FUNC_PIN_TASK if

  • the search is executed with a multi-port burst,
  • and you want to use the maskCycles() member function of SEARCH_FUNC_TASK.

In this case the spec variable must be specfied by SEARCH_FUNC_TASK.
type Type of the spec variable. Possible values are:
TM::TIM Timing spec variable
TM::LEV Level spec variable
typestring Type of the spec variable, specified as a string. Possible values are:
"TIM" Timing spec variable
"LEV" Level spec variable
start()
SEARCH_FUNC_PIN_TASK & start(DOUBLE val);

This member function specifies the start value of the search.

Parameter
val Start value of the search. For a spec variable, the unit is the unit of spec variable. For a timing hardware resource, the unit is seconds; if you want to use another unit, for example, 10 nanoseconds, code start(10 ns).
stepWidth()
SEARCH_FUNC_PIN_TASK & stepWidth(DOUBLE val);

This member function specifies the step width of a linear or combined linear and binary search. You must either define a step width or the number of steps (with the numberOfSteps() member function) for a linear search condition, but cannot define both.

Parameter
val Step width of a linear search. For a spec variable, the unit is the unit of spec variable. For a timing hardware resource, the unit is seconds; if you want to use another unit, for example, 10 nanoseconds, code stepWidth(10 ns).
stop()
SEARCH_FUNC_PIN_TASK & stop(DOUBLE val);

This member function specifies the stop value of the search.

Parameter
val Stop value of the search. For a spec variable, the unit is the unit of spec variable. For a timing hardware resource, the unit is seconds; if you want to use another unit, for example, 10 nanoseconds, code stop(10 ns).
wait()
SEARCH_FUNC_PIN_TASK & wait(DOUBLE val);

This member function specifies a wait time between the functional test runs.

Parameter
val Delay time between the functional test runs in seconds.

Valid range: 0 … (231 - 2) ms

Default value if not specified: 0 s
