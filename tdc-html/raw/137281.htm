Topic 137281

Parametric wafer map properties

Titles tab

Chart title: The title of the chart, displayed at the top.

Chart subtitle: The subtitle of the chart, displayed below the title.

X-Axis: The label for the x-axis.

Y-Axis: The label for the y-axis.

Classes tab

Lower Limit and Upper Limit: The limits with which the displayed test has been executed.

Minimum: The beginning of the range that is to be divided into value classes.

Maximum: The end of the range.

Class Count: The number of classes into which the range is divided.

Class Width: The resulting width of each class.

Mean: The value for a die is the mean of its test values.

Min: The value for a die is the minimum of its test values.

Max: The value for a die is the maximum of its test values..

Marks

Enable Mark: Marks each dies from a particular site with a small black triangle in the upper left corner: .

Mark Site: The number of the site to mark.
