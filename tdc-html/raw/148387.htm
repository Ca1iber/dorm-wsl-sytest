CCTMultiportSync()

Subtopics

  1. CCTMultiportSync.flush()
  2. CCTMultiportSync.start()
  3. CCTMultiportSync.sync()

This is the constructor for the class of CCTMultiPortSync, It is used to generate a new instance for this object in a CTF group or block.

CCTMultiportSync is a data container to trace the activities (insertion of a label) at each port and control synchronization across ports. The CCTMultiportSync also supports multiple digital captures for different digital capture ports (DigitalCapturePort).

Example

CCTMultiportSync    Sync;
CCTtsName = CCTgetTestsuiteName();
GET_TESTSUITE_NAME(tsName);

Sync.registerCCTestMethod(tsName, this);

PatternPort::getInstance().setPort("SH1_Port");
PatternPort::getInstance().setWaitTemplatePatternName("SH1_Port_wait_template");
Sync.registerSyncPort(PatternPort::getInstance());

DCDynamicPort::getInstance().setPort("pDPS128");
Sync.registerSyncPort(DCDynamicPort::getInstance());

Sync.start();
...
Sync.sync();
...
Sync.flush();

Primary.label(Sync.getMultiPortBurstName());
Sync.dumpMPBGraph();
