rdi.route().execute()

The function will create the label for the setups defined by the rdi.route() functions. The related burst pattern will be generated and the burst pattern will be executed when RDI_END() is executed.

Usage of the function:
  • The function can be called in the code‑based mode or in the pattern‑based mode. For more information, refer to Execution mode in topic SmartRDI.

Syntax

void execute();
List of parameters
There are no parameters.
Return value
There is no return value.

Example

Example 1

RDI_INIT();
...
...
ON_FIRST_INVOCATION_BEGIN();
{
    ...
    ...
    RDI_BEGIN();
    {
        ...
        ...
        rdi.route().applyState("Connect_load").execute();
        ...
        ...
    }
    RDI_END();
    ...
    ...
}
ON_FIRST_INVOCATION_END();
...
...
