getCalibrationHistory()

This function returns the calibration execution history information.

With SmarTest 7.10, the calibration is done with SmarTest 8, so the history should be found in the SmarTest 8 calibration database.

Syntax

const char* getCalibrationHistory();
List of parameters
There are no parameters.
Return value

A reference to a string holding the calibration execution history information.

The history information is build by one line containing the following fields:

  • <calibration class> for example "std"

  • <calibration type> for example "full"

  • <date & time of cal.> for SmarTest 7.10, this always returns "1900-01-01 00:00".

  • <SW revision of cal.> for example "6.3.0"

  • <SW rev. date & time> for example "2008-01-31 12:00"

  • <calibration pass or fail result> not applicable in SmarTest 7.10, so always returns "fail"

Example

Example: Read and show history information in a SmarTest test method class

#include "testmethod.hpp"

#include "mapi.hpp"

#include "/opt/hp93000/soc/pws/include/calibration.h"

...
...

virtual void run()
{
    ON_FIRST_INVOCATION_BEGIN();
    {
        cout << "Calibration history:" << endl << endl;
        cout << getCalibrationHistory() << endl;
    }
    ON_FIRST_INVOCATION_END();

    return;
}

...
...
The available calibration execution history information is shown in the ui_report window if the code above is executed in a SmarTest test suite.

Functional changes

  1. Introduced in SmarTest 6.5.0
