Topic 136810

Box chart view

Subtopics

  1. Box chart properties

The box chart visualizes the statistical distribution of results for a test, indicating the mean, the extremes, and various levels in between in a way that enables easy comparison between multiple data sets.

A box chart is opened by choosing Show In > Box Chart from the shortcut menu of a Test summary tab. It can also be opened using the New button (see below) from the toolbar of another box chart or using the Window > Show View > Box Chart menu command.

These are the elements in the main area of the chart (for the toolbar and shortcut menu, see below):

  • Title: By default, the name of the test being displayed and its number in parentheses. You can edit this label in the chart properties.
  • Subtitle: By default, the grouping in effect, if any. You can edit this label in the chart properties.
  • Toolbar: The action buttons of the chart. See the Toolbar section, below, for details.
  • Y-axis label: By default, this label shows the unit for the numbers displayed on the y-axis (value axis). You can edit this label in the chart properties.
  • Y-axis: The y-axis (value axis) displays the magnitude of the measured values. You can specify the range of this axis in the chart properties.
  • X-axis: The x-axis (data axis) displays the selected data sets.
  • X-axis label: By default, this label is "Data". You can edit it in the chart properties.
  • Boxes: Each box displays the statistical distribution of values within one data set. It has the standard elements of box plots:
    • Outlier points: Data points that are larger than the upper whisker or smaller than the lower whisker are plotted individually.
    • Upper whisker: By default, this marks the 98th percentile. You can configure this using the shortcut menu (see below) or in the chart properties.
    • 75th percentile line: 75% of all measured values lie below this line.
    • Median line: The median of all measured values. 50th percentile line. 50% of all measured values lie below this line.
    • 25th percentile line: 25% of all measured values lie below this line.
    • Lower whisker: By default, this marks the 2nd percentile. You can configure this using the shortcut menu (see below) or in the chart properties.
  • Legend: A description of the individual test series that are displayed. You can configure the display of the legend in the preferences.

You can zoom in on a portion of the chart by clicking at one end of the value range on which you want to focus and drag the mouse to the bottom of the range. You can reset the display to its default by double-clicking anywhere in the chart.

Toolbar

The toolbar of a box chart view includes these buttons:

  • Link: Links the display in the view to the selected row in the data navigation view.

    In this mode, if the selection in the data navigation view changes, the display updates automatically.

  • Pin: Freezes the display in the view.

    In this mode, the view keeps displaying the rows it currently displays, even when the selection in the data navigation view changes. Dynamic updating can be resumed by clicking the Link button.

  • New: Creates a new box chart view.
  • Zoom In: Enlarges a section of the chart to show more detail.
  • Zoom Out: Reduces the scale of the chart to show more data.
  • Properties: Opens the Box Chart Properties dialog.
  • Statistics: Displays the data that underly the graph. The information categories are the same as the columns in test summary tabs. Clicking the button again hides the values and displays the chart.
  • Image: Clicking this buttons lets you save the current chart display as a PNG or JPEG image.
  • Switch Legend: Switches the position of the legend between the bottom and the right side of the chart.

Shortcut menu

The shortcut menu of a box chart view contains these commands:

  • Zoom In: Enlarges a section of the chart to show more detail.
  • Zoom Out: Reduces the scale of the chart to show more data.
  • Y Axis: The commands in this submenu let you set the range of the value axis:
    • Min/Max: The axis begins with the smallest measured value and ends with the largest measured value.
    • Limits: The axis begins with a value slightly below the lower limit and ends with a value slightly above the upper limit. (This is the default setting.)
    • Double: The range of the axis around its midpoint is doubled.
    • Half: The range of the axis around its midpoint is halved.
  • Upper Whisker: The commands in this submenu let you set which percentile the upper whisker of a box indicates.

    Note that choosing 75th Percentile will place the upper whisker over the upper border of the box.

    The percentile that a whisker indicates can also be set in the chart properties, where you can specify any desired percentile.

  • Lower Whisker: The commands in this submenu let you set which percentile the lower whisker of a box indicates.

    Note that choosing 25th Percentile will place the lower whisker over the lower border of the box.

    The percentile that a whisker indicates can also be set in the chart properties, where you can specify any desired percentile.

  • Show in Raw Data: Right-clicking on a data point and choosing this command highlights the row in the raw data view that contains the data point's underlying data.

    This command is only available when you click a data point, not in other regions of the chart.

  • Restore Defaults: Resets the zoom level, axis settings, and whisker settings to their defaults.
  • Properties: Opens the Box Chart Properties dialog.
