Topic 99227

How to use universal test method libraries under multiple directories

This topic shows you how to use universal test method libraries located in different directories to test one device.

About this task

To use the test method libraries under multiple directories you must set the system environment variable V93000_TM_LIBRARY_PATH accordingly.

Before you begin

Make sure you are using SmarTest 6.3 or later. The test method libraries to be used must be error free and ready to use.

Procedure

Set the system environment variable V93000_TM_LIBRARY_PATH to the directories where the libraries are located. Use ':' to separate the directories.

V93000_TM_LIBRARY_PATH=directory1:directory2

Results

When you start SmarTest and the test method executor is started, it will automatically search for the test method libraries under the directories defined by V93000_TM_LIBRARY_PATH. You can select which test method to use in the tabular testflow editor.

Example

If you want to use the test method libraries both under the directory /home/demo/testmethod and under the directory /usr/project/, enter the following command on the command line before starting SmarTest from the command line in the same terminal.

$ export V93000_TM_LIBRARY_PATH=/home/demo/testmethod:/usr/project

If you want the setting for every start, you can add the command to a start script.
