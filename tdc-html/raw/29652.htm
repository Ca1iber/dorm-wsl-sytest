Topic 29652

PUT_DATALOG

This API logs array data such as an analog waveform data with captions that is held in the class object created by the WAVE_LOG and SCATTER_LOG APIs at the certain condition. This API also logs a specified string in the data log stream.

You can control the execution of PUT_DATALOG through data logging profiles, as described in Data logging profile rule syntax.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Parameters

I/O

Parameter

Description / Range

I

pin

The pin name to identify the logged array data.

I

testname

The label to identify the logged array data. You can use the same label to several different pins.

I

waveform

The array data to be logged or the WAVE_LOG API's class object that contains the array data with captions to be logged .

I

def

It gets the pin name of an analog measurement to identify the logged array data.

I

xydata

The SCATTER_LOG API's class object to be logged.

I

xseries

The data array for x-axis to be logged.

I

yseries

The data array for y-axis to be logged.

I

genObj

The GENERIC_DATA_EVENT - (gde) class object to be logged. It allows logging GDR records from within test methods.

I

comment

A string to be logged. Up to 65535 characters can be set. This allows logging DTR records from within test methods.

Important points

  • To log data by using the PUT_DATALOG API and display the test report by using the logged data, you must set the report formatter to the "EventFormatter" and enable the following flags:
    • The log_events_enable system flag
    • The output_on_pass or output_on_fail test suite flag or both
    • The log_mx_waveforms flag if you want to log mixed-signal data
  • If you will be converting the test data from the event data log to Standard Test Data Format (STDF) for test data analysis, the entry for the pin parameter must be an existing, defined pin name. To ensure that the string entered for the pin parameter is an existing pin name, set the Check Testmethod API flag to "on". With the Check Testmethod API flag set to "on", a fatal error will occur at runtime if the pin parameter is not an existing, defined pin name.
    Note The analog waveform array data cannot be logged to the STDF file.
  • If you develop original report formatter for event data logging, you should understand that the PUT_DATALOG API produces a data log event of the type "TestEventType" with an attribute of the type "LinearWaveformAttrType". For these types, see the Event Data Logging manual.
  • All the escape sequences in the comment argument are effective in event data logging. You can cancel this behavior according to the rule of the C language. For example, "\n" is an escape sequence of CR+LF, but "\\n" does not work as an escape sequence.
  • The PUT_DATALOG API produces the following data log events. This behavior is different from the Print to Datalog test suite as shown below:

Examples

Log data in an WAVEFORM_LOG object

ARRAY_D wave_array;
WAVE_LOG log_obj(wave_array);
PUT_DATALOG("Aout", "AnaWave", log_obj);

In the WAVE_LOG API, the log_obj object is created. The PUT_DATALOG API logs the wave_array data in the log_obj object.

Log data in the WAVE_LOG

ARRAY_D wave_array;
PUT_DATALOG("Aout","AnaWave",WAVE_LOG(wave_array));

The PUT_DATALOG API logs the wave_array data using WAVE_LOG.

Log data with captions in the WAVE_LOG object

ARRAY_D wave_array;
double sampling_period;
WAVE_LOG log_obj(wave_array);
log_obj.xAxis(0.0, 1023.0*sampling_period);
log_obj.xTitle("Time");
log_obj.xUnit("sec");
log_obj.yTitle("Output Voltage");
log_obj.yUnit("V");
PUT_DATALOG("Aout", "AnaWave", log_obj);

The WAVE_LOG API creates the log_obj object that contains the wave_array data and captions such as the x-axis data, the title of the x-axis, the unit of the x-axis, the title of the y-axis, and the unit of the y-axis. The PUT_DATALOG API logs the object.

Log scattered data in an SCATTER_LOG object

ARRAY_D timeArray,voltageArray;
SCATTER_LOG log_obj;
log_obj.xAxis(timeArray);
log_obj.xTitle("Time");
log_obj.xUnit("sec");
log_obj.yAxis(voltageArray)
log_obj.yTitle("Output Voltage");
log_obj.yUnit("V");
PUT_DATALOG("Aout", "Waveform", log_obj);

The SCATTER_LOG API creates the log_obj object. The object contains the scattered data and captions. The variable timeArray holds the scattered data for x-axis and the variable voltageArray holds the scattered data for y-axis. The PUT_DATALOG API logs the object.

Functional changes
