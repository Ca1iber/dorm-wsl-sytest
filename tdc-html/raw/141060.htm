Topic 141060

DIGITAL_OFFSET_SEARCH_PINS.uploadResult()

Uploads the results for the latest transition search from the tester to the workstation.

Those results include:

  • The offsets for the boundaries of the pass area relative to the searched edges or levels. (Boundaries are the first and last passing values of the pass area representing the fail-to-pass and pass-to-fail transitions respectively.)
  • The offsets for the middle of the pass area relative to the searched edges or levels.

Later on, to read out the offsets for the middle of the pass area, use DIGITAL_OFFSET_SEARCH_PINS.getOffset().

To read out the offsets for the boundaries, use DIGITAL_OFFSET_SEARCH_PINS.getLatestLBTransitionOffset(), and/or DIGITAL_OFFSET_SEARCH_PINS.getLatestRBTransitionOffset().

If you retrieve the offset on multiple pins and those pins have different settings, the exception TESTMETHOD_API::AmbiguityException will be issued.

Syntax

void uploadResult(SetSelector& selector, RESOURCE_TYPE resource) throws TMException;
Parameters

Parameter

Description

selector

It can be:

  • A TimingSetSelector object defined with TimingSetSelector, to select timing sets. Or,
  • A LevelSetSelector object, defined with LevelSetSelector, to select level sets.

resource

It can be a timing resource or a level resource whose offset and/or boundaries of the pass area you want to upload.

Use a timing or level resource for the timing or level selector accordingly. Otherwise, an exception will be thrown.

For the resource types, see the following table.
Available options of parameter: <resource>

Option

Description

DIGITAL_OFFSET_SEARCH::RECEIVE

Receive edges

DIGITAL_OFFSET_SEARCH::DRIVE

Drive edges which contain both FAST_DRIVE and SLOW_DRIVE

DIGITAL_OFFSET_SEARCH::FAST_DRIVE

Fast drive edges

DIGITAL_OFFSET_SEARCH::SLOW_DRIVE

Slow drive edges

DIGITAL_OFFSET_SEARCH::ALL_EDGES

All edges containing FAST_DRIVE, SLOW_DRIVE, and RECEIVE

DIGITAL_OFFSET_SEARCH::VIH

High driver levels

DIGITAL_OFFSET_SEARCH::VIL

Low driver levels

DIGITAL_OFFSET_SEARCH::VIOFFSET

The search of the offsets for VIH and VIL at the same time

DIGITAL_OFFSET_SEARCH::VTH

Receiver thresholds

DIGITAL_OFFSET_SEARCH::VOH

High receiver levels

DIGITAL_OFFSET_SEARCH::VOL

Low receiver levels

DIGITAL_OFFSET_SEARCH::VOOFFSET

The search of the offsets for VOH and VOL at the same time

DIGITAL_OFFSET_SEARCH::VISWING

Driver swings

DIGITAL_OFFSET_SEARCH::VOSWING

Receiver swings

Return value

There is no return value.

Example

STRING strpins("pcie_rx1n");

DIGITAL_OFFSET_SEARCH_TASK dos;

dos.pin(strpins)
        .resourceType(DIGITAL_OFFSET_SEARCH::VIH)
        .searchType(DIGITAL_OFFSET_SEARCH::EYE)
        .start(15 mV)
        .numSteps(120)
        .stepWidth(15 mV)
        .restoreFlag(DIGITAL_OFFSET_SEARCH::NO);

dos.execute();

DIGITAL_OFFSET_SEARCH::LevelSetSelector dest(DIGITAL_OFFSET_SEARCH::ALL);

dos.pin(strpins).uploadResult(dest, DIGITAL_OFFSET_SEARCH::VIH);

Functional changes

  1. Introduced in SmarTest 7.2.1
