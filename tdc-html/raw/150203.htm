EVENT_WAVEFORM_CFIM.outOfRangeCheck()

Enables or disables the out-of-range check. Per default this check is enabled. If the check is enabled and the measurement range is exceeded, the event contributes with a FAIL to the global test result.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

EVENT_WAVEFORM_CFIM & outOfRangeCheck(bool failOnOutOfRange = true);
Parameter
Parameter Description
failOnOutOfRange

Enables or disables the out-of-range check.

  • true: The out-of-range check is enabled
  • false: The out-of-range check is disabled

Default value: true

Return value

A reference to the corresponding EVENT_WAVEFORM_CFIM object.

Example

For an example see EVENT_WAVEFORM_CFIM.

Related information

EVENT_WAVEFORM_CFIM.getOutOfRangeCheck()
