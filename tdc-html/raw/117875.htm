LoadConfig test method

With the LoadConfig test method, you can explicitly load a configuration file.

LoadConfig loads the specified configuration file when no configuration file has been loaded so far. If a configuration file with a different name has been loaded, it outputs a warning message.

If you do not use this test method, the default configuration file testflow/.GDDR5Training.cfg is loaded.

Name

Comment

ConfigFile

<filepath>: The name of the configuration file to load. The file must be located in the testflow directory inside your device directory.
