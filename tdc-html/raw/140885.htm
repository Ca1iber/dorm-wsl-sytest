RESULT_AREA_CONFIG_SET.deselectGlobally()

This function disables recording into any user defined result area configuration set, i.e. it returns the recording focus for the next functional test to the default digital and DC result areas.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/RESULT_AREA_CONFIG_SET.h.

Syntax

static void deselectGlobally();

List of parameters

There are no parameters.

Return value

There is no return value.

Related information

RESULT_AREA_CONFIG_SET()
RESULT_AREA_CONFIG_PINS()

Functional changes

  1. Introduced in SmarTest 7.2.0
