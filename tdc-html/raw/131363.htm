SPMU_PIN_TASK.connect()

This function connects the DUT pins to the DC instrument to be used (DC Scale pins in PMU mode or BADC).

Note It is recommend to use the FLEX_RELAY class for the path control of dynamic Board ADC measurements.

Syntax

void connect();

List of parameters

There are no parameters.

Return value

There is no return value.

Example

Note Every other function called before the connect() or disconnect() function inside the same task is not taken into account.
Note When using two or more pins in one SPMU_TASK object, where some pins need to be connected (connect()) and other pins need to be disconnected (disconnect()), you must specify two separate tasks and execute the tasks individually. 
SPMU_TASK tsk1, tsk2;
ON_FIRST_INVOCATION_BEGIN();
    tsk1 .pin("VI32_1") .relay("NT").connect();
    tsk2 .pin("VI32_2") .relay("NT").disconnect();
    tsk1 .execute();
    tsk2 .execute();
ON_FIRST_INVOCATION_END();
