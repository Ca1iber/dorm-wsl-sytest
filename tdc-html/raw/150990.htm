SmartRDI 2.4.1

This section summarizes the changes and new features in SmartRDI 2.4.1.

Changes and new features

Category

Description

General
  • Sync group support for multiport bursts.
    • syncGroup()
    • addPort()
  • Pin context support.

func()
  • An ERMP option for pass-fail-per-label results in the RDI_Configure file.

dc()
  • PPMU or BADC setups run only in the first iteration of loops. See firstRunInLoop().
  • Insertion of sublabels with DC events.See insertSub().
  • Runtime current clamp for DC tests. See Changing the parameter value at runtime with SmartRDI.
  • One-side limit for DC Scale pins. See limit().

smartVec()
  • Match CONTINUE support for sequencer instructions. See instruction() and matchData().
  • An SHMEM option in the RDI_Configure file for support of SHMEM memory in pattern generation.

digCap()
  • Data format support enhancement. See format().

cogo()
  • Cogo pass/fail judgment enhancement for DC Scale pins. See SmartRDI: Pattern-based conditional jump - cogo.
