Topic 86929

ETC section

The ETC section of the model file defines several parameters. The following two are explained here:

  • CALIBRATION: defines which calibration is performed.
  • REFERENCECLOCK: defines which 10 MHz reference clock signal is used.

CALIBRATION

The CALIBRATION parameter defines which calibration is performed.

Syntax

CALIBRATION : <pps_cal_mode>

Parameters

<pps_cal_mode> specifies the calibration type.

pps_cal_mode = PPS_OLD_CAL | PPS_EXD_CAL | PPS_AUT_CAL

where:

 

PPS_OLD_CAL:

Measures voltage, gain, and offset. needs DVM 3458A and writes the results on std__.

 

PPS_EXD_CAL:

Measures voltage, gain, and offset. needs DVM 3458A and writes the results on EEPROM.

 

PPS_AUT_CAL:

Measures only offset with system PMU.

Example

CALIBRATION : pps_cal_mode = PPS_AUT_CAL

REFERENCECLOCK

The REFERENCECLOCK parameter defines which 10 MHz reference clock signal is used.

Syntax

REFERENCECLOCK : <input> <output_at_rf_connector>

Parameters

<input> specifies which clock signal is used as reference clock signal.

input = INTERNAL | EXTERNAL

where:

 

INTERNAL:

Internal source is used for 10 MHz reference clock signal, default value.

 

EXTERNAL:

External (RF) source is used for 10 MHz reference clock signal, external clock generator must be connected.

If the reference clock entry is missing, the internal reference clock is used.

<output_at_rf_connector> specifies whether the reference clock signal is output at the 10MHz output socket on the Interconnection Panel.

output_at_rf_connector = ON | OFF

where:

 

OFF:

Reference clock signal is not output at the 10MHz output socket on the Interconnection Panel.

 

ON:

Reference clock signal is output at the 10MHz output socket on the Interconnection Panel.

Example

REFERENCECLOCK : input = INTERNAL, output_at_rf_connector = OFF

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.3.3: Added parameter info for "output_at_rf_connector".
