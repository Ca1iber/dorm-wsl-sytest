Master file format for level setup

The first line of a level master file must be

hp93000,level_master_file,0.1

The second line has the format

testerfile: <tester_file_name>

It specifies the tester setup file which is to be split or into which the subfiles are to be merged.

The subsequent lines in the level master file associate level equation sets with a subfile.

You can also separate common blocks (each enclosed by #begin<block_description> and #end) that are placed at the top of the equation set section. Note that common blocks can be placed everywhere within the level setup file. But only those at the top of the section are recognized by the Setup Management tool.

The set of common blocks and the level sets are associated with a subfile by a line which specifies the type of the part, its number, and the associated subfile. Different level sets can be associated with the same subfile.

The paths for the subfiles can be relative or absolute. The reference directory for relative paths is the directory of the master file.

You can insert comments everywhere in the file. They are identified by the hash (#) character at the start of a line.

Master file entries

EQNSET <equationset_number> [PIN_ALIAS_SET <pin_alias_set_name>]: <file_name>
TESTDATA <testdata_name>: <file_name> 
DEFINES: <file_name>
GENERAL: <general_info_file>
  • EQNSET:

    Each level equation set starts with the EQNSET keyword followed by an equation set number and a descriptive name. For more information, see Equation set number and description.

    The PIN_ALIAS_SET keyword identifies the alias set used in the equation set of the assembled level setup file.

    When the assembled level setup file is split with the Setup Management Tool, the alias set is removed from the generated sub-file and package pin names are used.

  • TESTDATA:

    Automatically created by SmarTest in case of DCScale dynamic measurements. For more information, see DFTD.

  • DEFINES:

    Manually added by the user inside the master file. The keyword DEFINES adds the capability of defying port specific sets to multi-port equation sets. For more information, see Multi-port equation setup.

  • GENERAL:

    Automatically added when the level switching order was changed and saved. The level switching order is saved in the auto-generated file GENERAL.lev.

Format of automatically generated file names

When the Setup Management Tool splits the level setup file and finds a part for which no entry exists in the master file, it creates a new subfile for this part with the following name pattern.

eqnset_<equation_set_number>.lev
defines.lev

You can add a user defined prefix to the names with the environment variable VERIGY93000_MFH_PREFIX. Specify

export VERIGY93000_MFH_PREFIX=<prefix>

in the shell where you start SmarTest.

Example

Level master file

hp93000,level_master_file,0.1

# this is a comment
testerfile: demo.lev

EQNSET 1 [PIN_ALIAS_SET usb_set]: files/eqnset01.lev
EQNSET 2 : files/eqnset02.lev
EQNSET 3 : files/eqnset_34.lev
EQNSET 4 : files/eqnset_34.lev
TESTDATA : files/testdata.lev
DEFINES : files/defines.lev
GENERAL: GENERAL.lev

In the assembled level setup file demo.lev, the alias set usb_set is used in the equation set 1. When demo.lev is splitted, the alias set usb_set is removed from the generated sub-file eqnset01.lev and package pin names are used.
