UTILITY_SEQ_POGO_MODE

The class provides the function to specify the mode for the utility pogo block.

Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/UtilitySequencerMode.h.

Constructor
This class has no public constructor. The UTILITY_SEQ_POGO_MODE object can only be accessed via the function UTILITY_SEQ_MODE.pogoBlock() of the UTILITY_SEQ_MODE class.
Member function
  • mode()

Member function

mode()
void mode (TM::UTILITY_SEQ_POGO_MODE_STATE state);
Parameter
Parameter Description
state The mode of the utility pogo block.
Available options of parameter: state
Option Description
TM::SEQ_POGO_MODE_OFF Static mode
TM::SEQ_POGO_MODE_RD Sequencer‑controlled reading mode.
TM::SEQ_POGO_MASK_MODE_RD

Sequencer‑controlled masked reading mode.

Note: This mode enhances the serial protocol with an extra mask bit per utility line and requires therefore a pattern that sends two bits per utility line. For more information refer to Mask mode of sequencer-controlled utility lines.
TM::SEQ_POGO_MODE_RW Sequencer‑controlled reading and writing mode.
TM::SEQ_POGO_MASK_MODE_RW

Sequencer‑controlled masked reading and writing mode.

Note: This mode enhances the serial protocol with an extra mask bit per utility line and requires therefore a pattern that sends two bits per utility line. For more information refer to Mask mode of sequencer-controlled utility lines.
Return value
There is no return value.

Related information
