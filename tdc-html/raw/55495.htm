Topic 55495

Editing an expression-based group

About this task

Whichever action you selected:

  • to define a new expression-based group from scratch
  • to make changes to an existing expression-based group

the way you edit the group is always the same.

Expression-based groups are defined by group expressions and the process consists of three basic steps:

  1. Defining the group expression
  2. Selecting the component type
  3. Evaluating the group expression

Before you begin

Make sure that an expression-based group has been created.

Procedure

  1. Open the setup editor of the expression-based group you want to edit. If the group is new created, there are no pins in the Group Members area.
  2. The Available Group/Pin List shows all the defined digital pins, pin groups, and pin aliases in the form of pin_alias_set::pin_alias_name. To define the group expression, click an item in the Available Group/Pin List and clicke group operator (+ Union, - Difference or * Intersection).
    Note To quickly find the pins or groups you are interested in, you can use Filter line.
  3. Repeat step 2 until you finish the group expression.

    The group expression can also be typed directly in the Group Expression text box (see the figure below).

  4. To determine the type of active pins in the group, select the component type (I, O, IO and DC) in the Component Type list.
  5. To evaluate the group expression, click Evaluate.
  6. Apply the data and save the pin configuration file.

Results

After the expression is evaluated, the pins in the group are indicated in the Group Members area. Considering the chosen component type, inactive pins in the list are marked with "*".

In the Available Group/Pin List, the pins in the group are indicated with "√".

Example

A group contains all the input pins (all_in), without the pin I/O7. So the expression is all_in - I/O7.

After selecting I type, the steps for building such expression are:

  1. Click group all_in in the Available Group/Pin List and then click operator + Union. This results in the following group expression.
  2. Click pin I/O7 in the Available Group/Pin List and then click operator - Difference. This results in the final group expression.
  3. To evaluate the group expression, click Evaluate. The pins are printed to the Group Members area.
