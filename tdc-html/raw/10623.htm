Topic 10623

Restrictions for multiport setups

The period definitions for the individual ports of a multi-port setup are largely independent of each other.

On a Smart Scale system, every port has its own period resolution (see Period resolution for a multi-port setup (Smart Scale)). However, the following restrictions apply:

  • You cannot define pin specific periods in a multi-port setup. That is, you cannot connect an equation set containing a period specification for a single pin to a port in a multi-port specification.
  • You cannot use the PCLK command to change the period within a multi-port specification. The PCLK? query can be used.

Functional changes

  1. Introduced before SmarTest 6.3.2
