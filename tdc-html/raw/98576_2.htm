DRLS? - (DRive Level Sensitivity)

The DRLS? (DRive Level Sensitivity) query allows you to determine the high and low input voltage thresholds for the pins specified.

Syntax

DRLS? {test}, {pass_value}, [limit], {(pinlist)}

returns: 

DRLS {value_specifier}, {result_value}

Parameters

test

This parameter is one of the following:

H

This parameter must be entered to determine the high input voltage threshold (VIH,min). VIH,min is the minimum input level which is recognized as logic 1 by the DUT.

L

This parameter must be entered to determine the low input voltage threshold (VIL,max). VIL,max is the maximum input level which is recognized as logic 0 by the DUT.

pass_value

For a simple pass or fail test (limit parameter omitted), the pass value defines the expected pass level (in mV) for the test. For value measurements, this parameter defines the start value of the measurement window; set it to a value that ensures a pass result for the functional test. pass_value must be in the range of the drive level in the channel board (see DRLV, DRLV? - (DRive LeVel)).

limit

The limit parameter is an integer which defines the upper (for a low level search) and lower (for a high level search) limits for the measurement window of a value measurement. The limit must be specified in mV. This parameter must be omitted if only a pass/fail result for the test is required. The range limitations for this parameter are as follows:

  • when checking the high threshold, the limit parameter must be between the minimum drive level of the channel board (see DRLV, DRLV? - (DRive LeVel) and the specified pass value;
  • when checking the low level threshold, the limit parameter must be between the specified pass value and the maximum drive level of the channel board.

pinlist

The name of the pin or pins that you want to test. This parameter may also include groups previously created using the DFGP command. If more than one pin is to be included, the names must be separated with a comma. pinlist must only contain pins configured as inputs.

value_specifier

This reply parameter is one of the following:

LT

(less than) is returned if a VIL,max measurement was performed and already the first test (with the pass_value parameter) failed.

LE

(less than or equal to) is returned if a VIH,min measurement was performed and all the functional tests performed within the measurement window passed.

EQ

(equal to) is returned if a value measurement was performed and the first failed functional test occurred within the measurement window.

GE

(greater than or equal to) is returned if a VIL,max measurement was performed and all tests performed within the measurement window passed.

GT

(greater than) is returned if a VIH,min measurement has been performed and the first functional test performed within the measurement window failed.

P

This indicates that the functional test performed passed. This is only returned if the limit parameter is omitted.

F

This indicates that the functional test performed failed. This is only returned if the limit parameter is omitted.

result_value

The result value is the level (in mV) of the last passed test.

Application

AC Tests.

Errors

An error is generated if:

  • The pass value is less than the minimum allowed level;
  • The pass value is greater than the maximum allowed level;
  • The parameters are mismatched.

Examples

Example 1

DRLS? H,5000,,(Q0_1)

returns:

DRLS P,5000

Example 2

DRLS? H,5000,-1000,(Q0_1)

returns:

DRLS EQ,-490

Functional changes

  1. Introduced before SmarTest 6.3.2
