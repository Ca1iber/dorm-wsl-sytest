FORMAT_GRAPH class

This class allows specifying the way a graph is shown. An object of this class is instantiated and filled with desired parameters and then passed as the last parameter to PUT_DEBUG API.

Member functions

setUserComment

FORMAT_GRAPH & setUserComment (const std::string comment)

Sets a comment that is shown at the top right area of the graph.

Parameter

comment

A comment that will be shown in top right area of the graph.

setGraphStyle

FORMAT_GRAPH & setGraphStyle(Display::GraphStyle style)

Sets the graph style. Different styles exist as shown in the table below.

Parameter

style

Possible values are: PLOT_LINE, PLOT_BAR, PLOT_POLAR

setLegendVisible

FORMAT_GRAPH & setLegendVisible (bool visible)

Sets the legend as visible.

visible

true = visible; false = not visible.
