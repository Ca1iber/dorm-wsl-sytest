WGL-related STIL Reader setup options

The WGL-related options in a STIL Reader setup file let you configure translation options that are specific to WGL files.

Syntax

The WGL-related options in alphabetical order:
wgl_add_drive_off=boolean
Whether to add drive-off events (to turn the driver off in compare waveforms) where they are missing:
  • 0: No drive-off events are added.
  • 1: Drive-off events are added where they are missing.

This parameter is optional. The default value is 1.

wgl_export_scanchains=boolean
Whether to export WGL scan chains to STIL scan structures:
  • 0: Scan chains are not exported.
  • 1: Scan chains are exported.

This parameter is optional. The default value is 0.

wgl_purge_unused_timeplates=boolean
Whether to remove unused timing templates from the translated files:
  • 0: All timing templates are left in the translated files, even if they are unused.
  • 1: Unused timing templates are removed.

This parameter is optional. The default value is 0.

wgl_purge_unused_timing=boolean
Whether to remove unused timing templates and waveforms from the translated files:
  • 0: All timing templates and waveforms are left in the translated files, even if they are unused.
  • 1: Unused timing templates and waveforms are removed.

This parameter is optional. The default value is 0.

wgl_purge_unused_waveforms=boolean
Whether to remove unused waveforms from the translated files:
  • 0: All waveforms are left in the translated files, even if they are unused.
  • 1: Unused waveforms are removed.

This parameter is optional. The default value is 0.

wgl_scan_in_padding='padding-char'

The padding value to be applied for scan input. Valid values for padding-char are 0, 1, X, and Z.

This parameter is optional. The default value is 0.

wgl_scan_out_padding='padding-char'

The padding value to be applied for scan output. Valid values for padding-char are 0, 1, X, and Z.

This parameter is optional. The default value is X.

wgl_skip_inverters=boolean
Whether scan chain inverters are to be ignored during the processing of scan data:
  • 0: Scan chain inverters are taken into account for processing scan data.
  • 1: Scan chain inverters are ignored.

This parameter is optional. The default value is 0.
