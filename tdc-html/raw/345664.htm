Topic 345664

Twinning utility requirements

The Twinning family board needs to route the required utility resources to the Twinning DUT board. This requires an up-front understanding of the utility resources needed for the application. One optimization step can be to implement any noise filtering for the utility line power in the family board to save space in the DUT board. Another important point is to also route the utility lines needed for the EEPROM on the DUT board as described in Utility lines and DUT board EEPROMs. It is also advisable to include a separate EEPROM on the family board since different DUT boards might be used with the same family board. It can be daisy chained with the DUT board EEPROM but using a different address since address 11 is available, see Twinning DUT board EEPROM requirements.

Another important point for the family board design is that unlike for the DUT board, the utility pins DSC (disconnect lines) and POG4R (in a 4-row utility configuration case) should not be connected to GND as required in the standard V93000 DUT board guidelines. This connection should be done on the Twinning DUT board, and not on the family board.
