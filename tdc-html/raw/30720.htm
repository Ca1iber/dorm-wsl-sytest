Topic 30720

DEVICE

Subtopics

  1. Associated Syntax Entities

A keyword representing a level (like WAFER), that has special features associated with it, namely,

  • the screens that appear in this level have special buttons associated with them, such as check_dev or restest_dev.
  • its own set of identifiers, such as <header> and <level_name>. You might use this to give each device an ID number.
