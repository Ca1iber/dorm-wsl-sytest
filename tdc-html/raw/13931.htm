Displaying not reconstructible state ("N")

The not reconstructible state occurs if not enough information is available in the Error Map to allow the Timing Diagram to reconstruct the waveform. This state may occur if, for example, you have multiple compares within a cycle.

Not reconstructible cycles are identified by an N as shown below.

If all pins within a group contain not reconstructible cycles, then an N is displayed. However, if only some pins in the group are not reconstructible, then a question mark is displayed instead of the hexadecimal value.
