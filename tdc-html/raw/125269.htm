State character sequence constants

Constant sequence of state characters is written in double quotes "", like strings in the C programming language.

Note No whitespace is allowed in the string and the used characters must be defined in the associated state map.
Note 'R' cannot be used in a SCS because it is a reserved character which marks protocol fields to be read back from the DUT.

Syntax

sequence := "<characters>"
