DSP_MU_ENCODE

This API encodes the contents of a specified array using the µ=255 law.

If other output formats are required, use the DSP_MU_ENCODE API with output_format = CMPLM2. Then, use the VECTOR API to convert result to the desired format.

Encoding/Decoding Table for A-Law/µ-Law lists the encoding format of the µ=255 law conversion used by this API. Also, refer to Code Format Tables for the two's complement and complementary symmetry code format.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_MU_ENCODE(ARRAY_D& src, ARRAY_I& result, INT output_format);
DSP_MU_ENCODE(DOUBLE *src, INT *result, INT size, INT output_format);
Parameters

I/O

Parameter

Description / Range

I

src

Source array

O

result

Encoded results

(size of result) = (size of src)

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src)

I

output_format

Output data format

CMPLM2: Two's complement

CMPLM_SYMM: Complementary symmetry

Example

double array1[100];
int array2[100];
  .
  .
DSP_MU_ENCODE(array1, array2, 100, CMPLM2);

DSP_MU_ENCODE encodes 100 elements of DOUBLE array array1 using the µ= 255 law. The 8-bit µ= 255 code data (two's complement code format) are stored in INT array array2.
