Topic 141130

DIGITAL_OFFSET_SEARCH_PINS.DigitalOffsetResultCopy()

Copies the edge offsets from one timing set to another timing set; or copies the level offsets from one level set to another level set.

Note Alternatively, use the TORC firmware command to perform the copy action.

Syntax

void DigitalOffsetResultCopy(DIGITAL_OFFSET_SEARCH::SetSelector &source, DIGITAL_OFFSET_SEARCH::SetSelector &dest);
Parameters

Parameter

Description

source

The source timing set specified with an object of the TimingSetSelector class.

Or,

The source level set specified with an object of the LevelSetSelector class.

dest

The destination timing set specified with an object of the TimingSetSelector class.

Or,

The destination level set specified with an object of the LevelSetSelector class.

Return value

There is no return value.

Example

DIGITAL_OFFSET_SEARCH::LevelSetSelector sour();
DIGITAL_OFFSET_SEARCH::LevelSetSelector dest(102003);
STRING strpins("pcie_rx1n");
DIGITAL_OFFSET_SEARCH_TASK dos;

dos.pin(strpins)
        .resourceType(DIGITAL_OFFSET_SEARCH::VIH)
        .searchType(DIGITAL_OFFSET_SEARCH::EYE)
        .start(15 mV).numSteps(120).stepWidth(15 mV)
        .restoreFlag(DIGITAL_OFFSET_SEARCH::NO);

dos.execute();

dos.pin(strpins).DigitalOffsetResultCopy(sour, dest);
