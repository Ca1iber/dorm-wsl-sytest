Wave Scale PS-PD pogo pin assignment

The Wave Scale Precision Source card using N2601PD direct pogo cable (WSPS-PD) provides high precision clock signals directly to the DUT interface. One WSPS-PD card provides three independent high precision clock sources and fan-out up to four outputs per clock source, resulting in 12 outputs at the DUT interface level.

Supported V93000 systems : EXA Scale (SmarTest 8), Smart Scale (SmarTest 8)
