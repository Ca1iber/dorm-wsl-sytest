iClampFilter()

Sets the clamp current filter as frequency.

The method is currently used only for the DC Scale XPS256 card and in code‑based mode.

The clamp current filter is used to modify the rise time and fall time when the clamp current value is changed. The programmed value will be applied for the sourcing and sinking clamp currents.

Syntax

iClampFilter(double filterFrequency);
Parameter

Parameter

Description

filterFrequency

Defines the filter frequency in Hertz (Hz).

Programmable double values are

  • Value between the card-specific minimum and maximum value: The filter is switched on and set to the defined filter frequency.
  • 0.0: The filter is set to the card-specific default value.

Card-specific range and default value:

  • XPS256: Refer to section Dynamic behavior in XPS256 programming - Force and clamp voltages.

Example

rdi.dc().pin("...")
    .vForce(5)
    .clamp(50 mA)
    .iForceRange(100 mA)
    .iClampFilter(10 KHz);

Functional changes

  1. Introduced in SmartRDI 2.2.0
