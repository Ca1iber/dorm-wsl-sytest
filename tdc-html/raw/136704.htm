CCTcontinueCurrentTest

Sets the flag of continuing current test to true.

It is used in the postStart() function to tell the concurrent test framework to continue the test in the test method according to the changed settings. It is for the spec-search like test.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

void CCTcontinueCurrentTest();

List of parameters

There are no parameters.

Return value

There is no return value.

Example

if(tsResult=1)
{
   CCTcontinueCurrentTest();
}

Functional changes

  1. Introduced in SmarTest 7.2.0
  2. SmarTest 7.2.1: Renamed the API from CCT_ContinueCurrentTest to CCTcontinueCurrentTest.
