Load capacitance connected to the DC Scale XPS256

For the DC Scale XPS256, SmarTest automatically sets the performance range considering the value of the load capacitor(s) connected to the DUT power pin on the DUT board.

For the supported load capacitance ranges, refer to section Dynamic behavior in force voltage or clamp voltage mode in XPS256 programming - Force and clamp voltages.

Load capacitance in the DPS operating mode

Entering a capacitance value in the C[uF] column of the DPS Pins editor has an effect for an XPS256 channel in DPS mode.

Note The supported maximum load capacitance depends on the selected current for range of the XPS256 channel. SmarTest automatically limits the load capacitance value which has been set in the DPS Pins editor, to the maximum value that is defined in section Dynamic behavior in force voltage or clamp voltage mode of XPS256 programming - Force and clamp voltages.

Load capacitance in the PMU operating mode

For XPS256 channels in PMU operating mode, you optionally can set the load capacitance using the SPMU_PIN_TASK.loadCap() test method API function.
