SmartRDI provides the class digCap() and the following functions to set up digital capture tests.

pin(), initDiscard(), samples(), capMode(), label(), copyLabel, addVecRange(), interSkip(), bitPerWord(), execute(), getVecVar(), getVector(), getVectorBit(), enPassFail(), burstUpload(), vecVarOnly(), and format().

Currently only the selective mode capturing is supported by SmartRDI.

SmartRDI can create the digital capture label and the vector variable according to the x-mode and the capture waveform index in the wavetable.

SmartRDI supports both serial transfer mode and parallel transfer mode.

For the serial transfer mode, a vector variable is created for each capture pin with 32 bits per word by default. You can only get the vectors of one pin at a time. In the parallel mode, a vector variable is created for all pins in the capture with one sample per word. You need to get the vectors of all the pins at a time.

The bits in the captured samples are assembled in the order of MSB (Most Significant Bit) to LSB (Least Significant Bit) from the first pin to the last.

For the usage of hidden upload, refer to using hidden upload with SmartRDI.

See X-mode handling in digCap with SmartRDI for an example of digCap x-mode handling and some attention points.
