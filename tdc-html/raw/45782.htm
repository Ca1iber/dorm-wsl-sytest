GraphDialogBox

This class holds the components of a dialog box in the GraphManager. The components include text field, combo box and radio button. The GraphDialogBox object can be used in the member function openDialogBox() of GraphManager. The components will be displayed in the dialog box. Then, you can put a value to each argument of the dialog box.

Example

GraphManager * graphManager = GraphManager::getInstance();
GraphDialogBox dialog("title");
dialog.addTextField("text", "none",""); 
vector<string> lists;
lists.push_back("list a");
lists.push_back("list b");
lists.push_back("list c");
dialog.addComboBox("combobox", lists,"");
vector<string> buttons;
buttons.push_back("button 1");
buttons.push_back("button 2");
buttons.push_back("button 3");
dialog.addRadioButton("radiobutton", buttons);
// Open a dialog box and gets user inputs
vector<string> inputs = graphManager->openDialogBox(dialog);
cout << "Text Field is " << inputs[0] << endl;
cout << "Combo Box is " << inputs[1] << endl;
cout << "Radio Button is " << inputs[2] << endl;

This example creates a GraphDialogBox object, adds components to the object and then open a dialog box and get user inputs.
