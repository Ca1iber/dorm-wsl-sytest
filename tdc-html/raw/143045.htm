Topic 143045

PSSL pogo cable assembly, pogo pin layout and model file configuration

The E8080P pogo cable assembly connects the 32 channels of the PSSL card to the DUT board. The PSSL card supports the standard pogo locations.

Supported V93000 systems : EXA Scale (SmarTest 8), Smart Scale (SmarTest 7+8)

Pogo cable assembly

The pogo cable assembly features
  • 2 pogo blocks per PSSL card
  • 16 signal pogo pins per pogo block
  • 32 ground pogo pins per pogo block

Typically, a PSSL card uses two adjacent pogo block locations close to the DUT, for example, 301, 302 (or 305, 306). For further layout details see Card Cage to Pogo Slot Standard Assignments and DUT interface layout.

Pogo pin assignment

CAUTION The following signal assignment applies without restriction only to the STD operation mode. With the STDDIFF and FASTDIFF modes, differential drive pins can only be assigned to an odd‑numbered channel pair, and receive pins can only be assigned to an even‑numbered channel pair. Moreover, bidirectional pins are not supported in these modes.

PSSL card configuration in the model file

For the syntax of standard density (SD) pogo block entries in a model file, refer to the SD section in PS1600 card configuration in the model file.

CARD_CONFIGURATION
# PSSL card has standard-density pogos per filling rules in S2 locations  
  slot = 105, HW = PSSL,     pogoblocks = 317 321
  slot = 106, HW = PSSL15G,  pogoblocks = 301 305
