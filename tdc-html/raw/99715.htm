Supported test suites and test method APIs

The emulator can emulate the result of the test suite and the following test method APIs:

  • ANALOG or ANALOG_STATUS class:
    • DGT class (getWaveform, getComplexWaveform and getDebugWaveform member functions)
    • TIA class (getResult, getMean, getMin, getMax and getJitter member functions)
  • Vector class (getVectors member function)
  • SpecSearch (getResultSpec, getPassVal and getFailVal member functions)
  • DC APIs (PMU_IFVM, PMU_VFIM, DPS_VFIM, PPMU_MEASURE, DPS_TASK and SPMU_TASK)
  • FW_TASK(command, answer)
  • GET_FUNCTIONAL_RESULT
  • TEST (for functional test)
  • SEARCH_FUNC_TASK
  • PATTERN_CONTROLLER

The emulator does not support other member functions of the above APIs.

Functional changes

  1. Introduced before SmarTest 6.3.2
