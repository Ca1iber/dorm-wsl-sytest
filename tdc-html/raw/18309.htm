Topic 18309

The Significance of the Base Waveform Set

Interpretation of Vector Memory data depends on the waveform set used. The Base Waveform Set serves as the waveform set which the Vector Setup uses to interpret the current contents of the Vector Memory.

Whenever you generate (or edit) data in the Vector Table, you modify the contents of the Vector Memory. If you do this with one waveform set and then switch to another one, the interpretation of the Vector Memory will be incorrect. If the interpretation fails, the Vector Setup displays question marks (?) instead of vector data that you have programmed.

Note Do not confuse the base waveform set with the primary waveform set - see Relationship between waveform sets and timing sets.
