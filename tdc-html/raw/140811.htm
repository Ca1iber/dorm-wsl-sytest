Topic 140811

SMC_PIN_ERROR_MAP.getNextCycleChunk()

Uploads error map edge results. These results are stored as CYCLE_CHUNK data structures.

Syntax

bool getNextCycleChunk(CYCLE_CHUNK& cycleChunk);
Parameter

Parameter

Description

cycleChunk

A structure containing cycle information (edge results).

Return value

True: when cycle chunk is successfully uploaded. False: when there is no additional data to upload.

Related information

SMC_PIN_ERROR_MAP
CYCLE_CHUNK

Functional changes

  1. Introduced in SmarTest 7.2.1
