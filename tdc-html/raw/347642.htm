Utility pogo block - Utility Card (V93000 EXA Scale systems)

V93000 EXA Scale systems can be equipped with the optional Utility Card (EK051A) that provides 256 dynamically controlled utility lines and several utility power supplies per card. The 256 utility lines and the utility power supplies are routed to eight 4-row utility pogo blocks.

Supported V93000 systems : EXA Scale (SmarTest 7+8)

For the utility pogo pin assignment of a V93000 EXA Scale system that is not equipped with the optional Utility Card, refer to Utility pogo block - Basic configuration (V93000 EXA Scale systems).

The following specific setup tasks are available in this topic:
  • Mapping of pin groups and utility pogo blocks
  • Mapping of pins on a 4-row utility pogo block
  • Pin description
  • Utility pogo block mapping
  • Utility power supply mapping of the Utility Card

Mapping of pin groups and utility pogo blocks

Note

The assignment of the eight utility pogo blocks to the pogo blocks on the DUT interface is different for the first and second Utility Card. The mapping affects also the availability of the utility supplies on UPP15V / UPM15V / F24V pins.

For more information, refer to section Utility pogo block mapping below.

In V93000 EXA Scale systems, the legacy pogo blocks DPS 1 … DPS 8 are used either for the optional 2nd Utility Card or for the Internal Utility Power Option. See also section Structure of the DUT interface layout in topic DUT interface layout.

CAUTION The 4‑row utility block uses the row sequence c-a-b-d for compatibility with the 2‑row utility block. This sequence is different to the row sequence a-b-c-d of other 4‑row pogo blocks. Do not use the wrong row sequence a-b-c-d for the 4‑row utility block. Use only the correct row sequence c-a-b-d for the 4‑row utility block. Violating this rule results in unusable DUT boards.

Utility DC pins

The utility DC pins support connection of utility card pins via the DC rail to external instruments connected to the test-head. The following channel specifications are used in the Digital pins editor:
Utility DC pin in Digital Pins Editor Utility card
UTIDC165 1st utility card
UTIDC265 2nd utility card
Note The Utility DC pins are supported only in SmarTest 7.10.

Wiring rules and notes

  • Connect all pogo pins of all blocks of a utility supply output to a separate power plane on the DUT board.
  • Connect all sense pins of all blocks of a utility supply output to the related power plane.
  • Utility power supply pogo pins of different Utility Cards must not be connected together.
  • Maximum offset of utility ground to system ground: ±0.5 V
  • Pins URW14 and URW15 of utility block 1 (UTIL 1) are internally connected to the DUT Interface EEPROM of the system and can be used to control up to three more EEPROMS on the DUT board or probe card. For more information, refer to Utility Lines and DUT Board EEPROMs.
    Note Utility pins URW14 and URW15 on utility block 1 are not to be used for a purpose other than EEPROM access otherwise the readout from the DUT Interface EEPROM may become corrupted. This would be the case when the DUT Board is docked while an EDC dump is in progress. For more information, refer to EDC Dump in the "Service Guide Part 1".

  • The designation for utility pogo pins is URW00 ... URW15 (2‑row block) or URW00 ... URW31 (4‑row block). The corresponding scheme used by SmarTest is as follows:

    SmarTest 8:

    #01 … #16 or #01 … #32 with # to be replaced by the utility pogo block number 1 ... 8.

    The three‑digit pogo pin number is to be defined in the DUT board description file. For more information refer to SmarTest 8 topics DUT board description file reference or Controlling utility lines.
    SmarTest 7:

    UTI#01 ... UTI#16 or UTI#01 ... UTI#32 with # to be replaced by the utility pogo block number 1 ... 8.

    For more information refer to SmarTest 7 topics Utility Line view or Defining a utility line.
    V93000 EXA Scale systems (SmarTest 7 and 8)
    ###01 ... ###32 with ### to be replaced by the three‑digit utility pogo block number as defined in Utility pogo block mapping of Utility pogo block - Utility Card (V93000 EXA Scale systems).
    Note An offset of 1 is to be considered for transferring the utility pogo pin definitions of this section to SmarTest.
