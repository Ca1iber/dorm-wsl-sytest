setPatBurst()

Specifies the burst pattern's name for the next RDI_BEGIN()/RDI_END() block.

Syntax

setPatBurst(const string &burstName);
setPatBurst(const string &burstName,TA::MD5_OPTION);
List of parameters

Parameter

Description

burstName

The specified name of the burst pattern.

TA::MD5_OPTION

The option which defines to use an MD5 postfix string or not.
List of available options of parameter: <TA::MD5_OPTION>

Option

Description

TA::MD5_ON

With an MD5 postfix string.

TA::MD5_OFF

Without an MD5 postfix string.

This is the default value.

Example

rdi.setPatBurst("pattBurst1");             // No MD5 postfix by default.
rdi.setPatBurst("pattBurst1",TA::MD5_ON);  // With an MD5 postfix.
rdi.setPatBurst("pattBurst1",TA::MD5_OFF); // Without an MD5 postfix.

Functional changes

  1. Introduced in SmartRDI 2.1.0
