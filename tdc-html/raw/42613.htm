Topic 42613

Multi-site access functions

The following list shows a selection of the Test Programming Interface (TPI) library Multisite access functions:

  • GetNumberOfSites(INT32 *number_of_sites)

    Retrieves the number of sites that are currently configured.

  • GetSiteInFocus(INT32 *site_in_focus)

    Retrieves the site number of the site in focus.

  • SetSiteInFocus(INT32 site_in_focus, INT32 *state)

    Sets the focus to the specified site number. If an invalid site number is specified, the focus remains unchanged. An error is reported in the return value of state (0 when there is no error, a non-zero value otherwise). If the return value is 1, setting the site focus was unsuccessful.

  • GetEnabledSites(MS_SITE_SET enabled_set)

    Retrieves the set of enabled sites. If site i is enabled, enabled_set[i] is not 0. MS_SITE_SET has been declared an array of the configured sites (char Array 1 ... MS_MAX_SITES).

    Note: MS_SITE_SET and MS_MAX_SITES are defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/MapiBasic.h.

  • GetAvailableSites(MS_SITE_SET available_set)

    Retrieves the set of available sites. If site i is available, available_set[i] is not 0. Available sites are all configured sites except those that cannot be used due to hardware defects. Only available sites can be enabled, activated, or receive the setup or result focus.

  • SetEnabledSites(MS_SITE_SET enabled_set, INT32 *state)

    Enables and disables sites according to enabled_set. If enabled_set[i] is not 0, site i is enabled. Otherwise site i is disabled. An error is reported in the return value of state (0 when there is no error, a non-zero value otherwise). If return value is 1, not all sites in the site set could be activated.

  • GetActiveSites(MS_SITE_SET active_set)

    Retrieves the set of active sites. If active_set[i] is not 0, site i is active. Otherwise site i is not active.

  • SetActiveSites(MS_SITE_SET active_set, INT32 *state)

    Activates and deactivates sites according to active_set. If active_set[i] is not 0, site i is activated. Otherwise site i is deactivated. An error is reported in the return value of state (0 when there is no error, a non-zero value otherwise). If return value is 1, not all sites in the site set can be activated.

  • GetSiteState (MS_SITE_STATE *site_state)

    Retrieves the site setup state consisting of the focus, the enabled sites, and the active sites. The state information is stored in a user-provided variable of type MS_SITE_STATE. The site state can later be restored using the RestoreSiteState() function.

  • RestoreSiteState(MS_SITE_SATE *site_state,INT32 *return_state)

    Restores a previously saved site setup state. If the number of sites before and after the restoring is not the same, an error is indicated by returning a non-zero value in return_state.

    Note You should always use GetSiteState() and RestoreSiteState() before and after making any changes. This makes sure that your user procedure does not interfere with the regular test flow.
