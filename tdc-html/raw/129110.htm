Topic 129110

Creating a port burst

A port burst is always part of a multiport burst and must belong to a sync group.

Multiport Burst: The field is predefined depending on your prior selection.

Port Bursts:

  • Port: Select one or more ports to add to the multiport burst. Ports that belong already to the selected multiport burst are preselected but grayed out. Note that device pins must belong to only one of the selected ports.
  • Sync Group (optionally): Specify a sync group per port or use the DEFAULT sync group. The sync group forces all its ports to start at the same point in time.
