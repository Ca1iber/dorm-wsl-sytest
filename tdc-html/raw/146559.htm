DIGITAL_OFFSET_SEARCH_TASK.enableAutoOffsetUpload()

Uploads the offset for the middle of the pass area found in the latest offset search from the tester to the system controller.

It functions the same as DIGITAL_OFFSET_SEARCH_TASK.uploadOffset() but used in different scenarios:

  • When using TASK_LIST to execute one or more DIGITAL_OFFSET_SEARCH_TASK objects, if you want to retrieve the found offsets, before adding those objects to a TASK_LIST, you must have set up this member function instead of uploadOffset() for every object to upload the offsets to the system controller. Otherwise, you cannot get the correct offset values.
  • In the other cases, use uploadOffset().

Syntax

void enableAutoOffsetUpload(SetSelector& selector, RESOURCE_TYPE resource) throws TMException;
Parameters

Parameter

Description

selector

It can be:

  • A timing set selector defined with TimingSetSelector, used to select the timing sets for use.
  • A level set selector defined with LevelSetSelector, used to select the level sets for use.

resource

A timing or level resource whose offset you will upload. In the following table, you will see the available resources.
Available options of parameter: <resource>

Option

Description

DIGITAL_OFFSET_SEARCH::RECEIVE

Receive edges

DIGITAL_OFFSET_SEARCH::DRIVE

Drive edges which contain both FAST_DRIVE and SLOW_DRIVE

DIGITAL_OFFSET_SEARCH::FAST_DRIVE

Fast drive edges

DIGITAL_OFFSET_SEARCH::SLOW_DRIVE

Slow drive edges

DIGITAL_OFFSET_SEARCH::ALL_EDGES

All edges containing FAST_DRIVE, SLOW_DRIVE, and RECEIVE

DIGITAL_OFFSET_SEARCH::VIH

High driver levels

DIGITAL_OFFSET_SEARCH::VIL

Low driver levels

DIGITAL_OFFSET_SEARCH::VIOFFSET

The search of the offsets for VIH and VIL at the same time

DIGITAL_OFFSET_SEARCH::VTH

Receiver thresholds

DIGITAL_OFFSET_SEARCH::VOH

High receiver levels

DIGITAL_OFFSET_SEARCH::VOL

Low receiver levels

DIGITAL_OFFSET_SEARCH::VOOFFSET

The search of the offsets for VOH and VOL at the same time

DIGITAL_OFFSET_SEARCH::VISWING

Driver swings

DIGITAL_OFFSET_SEARCH::VOSWING

Receiver swings

Return value

There is no return value.

Example

Refer to the example in DIGITAL_OFFSET_SEARCH_TASK.enableAutoTransitionUpload().
