Topic 20240

Inserting a node

Before you begin

The Flow Sequence Editor must be open.

Procedure

  1. In the Flow Sequence Editor, click an insertion point to highlight it. It appears red.
  2. On the Palette, click the node you want to insert. The corresponding wizard window appears.
  3. Fill in the wizard window, entering all desired variables and parameters, and setting any appropriate flags.
  4. Click Finish.

Results

The node appears in the testflow.

What to do next

If necessary, edit the attributes of the nodes in the Properties view.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.2: You can insert a testflow node in the Flow Sequence Editor.
