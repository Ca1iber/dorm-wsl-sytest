PinPropertyMonitor.printStatus()

Saves tester status to a string stream for later output.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PinPropertyMonitor.h.

Syntax

PinPropertyMonitor & printStatus();
PinPropertyMonitor & printStatus(std::ostream& ss);
Parameter
Parameter Description
ss

A string stream which holds the retrieved tester status for further output.

Examples

Example 1

The following example saves tester status in memory and then prints it to system control. 

ARRAY_I sites;
GET_ACTIVE_SITES(sites);
PinPropertyMonitor ppm1(sites, "@");
ppm1.printStatus();

Example 2

The following example saves tester status in memory as a string stream and then prints it to system control. 

ARRAY_I sites;
GET_ACTIVE_SITES(sites);
PinPropertyMonitor ppm1(sites, "@");
stringstream ss;
ppm1.printStatus(ss);
cout<<ss.str()<<endl;

Functional changes

  1. Introduced in SmarTest 7.5.2
