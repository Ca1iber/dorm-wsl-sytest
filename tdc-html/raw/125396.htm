TOCR, TOCR? - (Timing/level Offset Configure Result pins)

A pin is defined as a setup pin for an embedded timing/level search with TOCF. The setup pins are the pins the edge positions of which are modified during the search. By default, the result pin for an O or IO setup pin, that is, the pin on which the outcome of a search step for this setup pin is to depend, is identical with the setup pin.

The TOCR command serves to change this default, and also to define the mandatory result pins for setup pins that are pure drive pins. You can define more than one result pin for one setup pin. In this case a search step counts as passed only if all result pins pass.

Note that the result pins must belong to the same 8-channel group (PS1600) as the setup pin.

The TOCR? query displays the current settings.

In a multi-site setup, TOCR respects the setup focus, and TOCR? the query focus.

With this command you configure setups of those sites that have the setup focus: For more information, see also: PSFC, PSFC?.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

TOCR

TOCR [(result_pinlist)], {(setup_pin)}

TOCR?

TOCR? {(result_pinlist)},

or

TOCR? , {(setup_pinlist)}

Both formats return:

TOCR {(result_pinlist)}, {(setup_pin)}

Parameters

result_pinlist

In the command, this parameter specifies the result pins for the setup pin specified with setup_pin. It can be omitted for O or IO setup pins. In this case the result pin will be identical with the setup pin.

In the query, it lists the result pins for which the associated setup pins are to be retrieved.

setup_pin

The setup pin for which the result pins are to be defined.

setup_pinlist

This query parameter lists the setup pins, for which the associated result pins are to be retrieved.

Application

Embedded timing and level search.

Example

TOCR (Pin2,Pin3),(Pin1)

This example defines Pin2 and Pin3 as the result pins for Pin1.

> TOCR? ,(Pin1,Pin5)
< TOCR (Pin2,Pin3),(Pin1)

This example queries the result pins for Pin1 and Pin5. No reply is given for setup pin Pin5, because its result pin is also Pin5.

Functional changes

  1. Introduced in SmarTest 7.1.0
