Class ::xoc::hvmapi::ParamList

The ::xoc::hvmapi::ParamList class provides the parameter representation for all signatures, including the input value (like command parameter, query parameter, notify parameter) and output value (like query result, event body of event notification).

::xoc::hvmapi::ParamList implements the container of <key, value> pair similar to std::map. In comparison with the std::map, it also supports the value with std::vector<std::string> type and the key with type of std::string.

Constructor

ParamList ();

This constructs a ParamList object which provides the parameter representation for all signatures.

ParamList (const ParamList& obj);

This constructs a ParamList object by copying from another defined object.

Parameter

obj

The ParamList object to copy from.

Member functions

value()

std::string value (const std::string& param) const;

This function returns the first parameter value, if there is a parameter value array assigned to the given parameter name.

Parameter

param

The parameter to query.

Operator[]

std::string operator[] (const std::string& param) const;

This operator returns the first parameter value, if there is a parameter value array assigned to the given parameter name.

Parameter

param

The parameter to query.

setValue()

ParamList& setValue (const std::string& param, const std::string& value);

This function sets the first parameter value for the given parameter name. If the parameter name does not exist, it will be added in the parameter list.

Parameters

param

The name of the parameter to set.

value

The value to be set.

operator[]

std::string& operator[] (const std::string& param);

This operator returns a modifiable reference to the first parameter value. You can use it to set a new value. If the parameter name does not exist, it will be added in the parameter list with an empty value assigned to it.

Parameter

param

The name of the parameter to set.

valueArray()

std::vector< std::string > valueArray (const std::string& param) const;

This function returns all the values of the specified parameter.

Parameter

param

The name of the parameter to query.

setValueArray()

ParamList& setV alueArray (const std::string& param,
                          const std::vector <std::string>& valueArray);

This function sets new values for the specified parameter. If the parameter name does not exist, it will be added to the parameter list. If the valueArray is empty, the parameter will be erased.

Parameters

param

The parameter to set.

valueArray

The new values for the specified parameter.

hasValueArray()

const bool hasValueArray (const std::string& param) const;

This function checks whether multiple values have been assigned to the parameter. It will return true if multiple values have been assigned to this parameter. Otherwise false is returned.

Parameter

param

The parameter to query.

hasParam()

const bool hasParam (const std::string& param) const;

This function checks whether at least one value exists for the parameter. It returns true if any value exists. Otherwise false is returned.

Parameter

param

The parameter to query.

erase()

void erase (const std::string& param);

This function removes the specified parameter from parameter list.

Parameter

param

The parameter to query.

clear()

void clear ();

This function removes all parameters from the parameter list.

getKeys()

const std::vector<std::string> getKeys() const;

This function returns all the parameter keys contained in a ParamList object. You can access all the parameter values using the parameter keys. An empty vector will be returned if there is no parameter key assigned to the given ParamList object.

Example

The following example shows how to set and get values with the member functions of ParamList.

::xoc::hvmapi::ParamList param param1;
param.setValue["SESSION_ID"] = "sid1";
std::string value1 = param.value("SESSION_ID");

param["SESSION_ID"] = "sid2";
std::string value2 = param["SESSION_ID"];

std::vector<std::string> values;
values.push_back("6.2.0");
values.push_back("6.2.1");

param1.setValueArray("INSTALLED_VERSION_LIST", values);

vector<string> keys = param1.getKeys();
// to display the values of the keys
for ( vector<string>::iterator it=keys.begin(); it != keys.end(); it++)
{
  cout <<"the keys: "<< *it << endl;
  // if the keys has value array
  if (param1.hasValueArray(*it))
  {
    vector<string> values=param1.valueArray(*it);
    for(vector<string>::iterator itr=values.begin(); itr != keys.end(); itr++)
    {
      cout << values.value(*itr) << endl;;
    }
  }
 // if the keys has a single value
 else
 {
    cout << param1.value(*it) << endl;
 }
}
