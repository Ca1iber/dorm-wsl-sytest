Topic 142956

Measuring test time

Subtopics

  1. Global parameters

Test Time Utilities measures the test time of your test program.

Before you begin

Launch SmarTest and load your testflow and setups. Make sure the testflow is executed successfully.

Procedure

  1. Open TP360 and launch Test Time Utilities from the APP Center tab.
  2. In the Configuration and Execution view, click the Measure Test Time tab.

    A table with two default measurement sets opens:

    • Measure with current flow setting.
    • Measure with customized setting.

      If your test program is multisite:

    • Measure with current flow setting contains two measurements:

      "Single site" and "Multi-sites".

    • Measure with customized setting contains four measurements:

      "Single site - not optimized", "Multi-sites - not optimized" "Single site - optimized", and "Multi-sites optimized".

      If your test program is single site:

    • Measure with current flow setting contains one measurement:

      "Single site".

    • Measure with customized setting contains two measurements:
    1. "Single site - not optimized".
    2. "Single site - optimized".

      In this table, different columns except the first one represent different conditions:

    • Measures list: Lets you specify a name for a measurement or for a measurement set.
    • Enabled site(s): Lets you select sites for measuring.
    • Loop count: Lets you enter the number of testflow loops during measuring. The range is from 1 to 9999.
    • Optimize testflow: Lets you choose whether optimizing a testflow or not when measuring.
    • Testflow flag setting: Lets you use either the TP360 recommended flags or the flags used in the current test program.

      To view the recommended flags, click the icon and select the Recommended flags setting page.

  3. Modify the above default measurement sets according to your needs. You can:
    • Double-click a cell to modify its setting.
    • Enable or disable any measurement by checking or unchecking it.
    • Create a new measurement by highlighting any measurement and selecting the icon. A new measurement with the same setups is added into the same measurement set. To modify the setups, double-click the relative cells.
    • Create a new measurement set by highlighting a measurement set and selecting the icon. A new measurement set with the same setups is added to the table.
    • Enable or disable a measurement set by checking or unchecking it. When you select a set, all the other sets are unchecked automatically.
    • Delete a measurement or a measurement set by highlighting it and selecting the icon.
      Note Note the following:
    • You cannot delete the default sets, "Measure with current flow setting" and "Measure with customized setting".
    • Within the "Measure with current flow setting" measurement set, you cannot delete nor colon any measurement, and you cannot modify the name of each measurement nor the settings in the Optimized testflow and Testflow flag setting columns.
    • Within "Measure with customized setting", you cannot delete any measurement.
  4. (Optional) To customize the measuring behavior, such as ignoring the first testflow execution for the test time calculation, click the icon and configure the global parameters.

    See Global parameters.

  5. Select Measure Test Time to execute your setups.
    • A progress window opens and shows the progress details.
    • The Console view shows any warning and error messages.
    • The Report view displays the test time results.

Results

In the Report view, you see the test time measurement report (a TP360 test time report). By default, this report is generated in the directory: /<device_path>/TP360_Reports/TTM_Reports.

  • To save the report to a desired directory, click the icon.
  • To delete the report or to compare it with another test time report, see Managing test time reports and Comparing test time.
