Topic 143675

MSDF, MSDF? - (Modulation Set DeFinition)

MSDF creates a modulation set by defining a unique name for it. Up to 128 modulation sets can be stored in the hardware. If you exceed this number by selecting a modulation set that is not yet stored in the hardware, the new set will replace the set that was downloaded first.

MSDF? returns the name of the specified or the names of all defined modulation sets.

MDSF

MSDF {"ms_set_name"} ,{modulation_type}

MDSF?

MSDF? ["ms_set_name"|ALL]

returns:

MSDF {"ms_set_name"} ,{modulation_type}

Parameters

ms_set_name

In the command, this is the name of a new modulation set. In the query, it is a name of an existing modulation set. If you omit this parameter in the query, MSDF? will return the names of all user defined modulation sets.

modulation_type

Currently, the only allowed modulation type is TIM (for "timing").

ALL

With this parameter, the query returns all existing modulation sets.

Application

Jitter test.

Errors

An error is generated if a modulation set with the specified name already exists.

Example

> MSDF   "ms_set1",TIM
> MSDF   "ms_set2",TIM
> MSDF   "ms_set3",TIM

> MSDF?
< MSDF   "ms_set1",TIM
< MSDF   "ms_set2",TIM
< MSDF   "ms_set3",TIM

Functional changes

  1. Introduced in SmarTest 7.3.0
