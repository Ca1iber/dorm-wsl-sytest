Example 2

This example illustrates the different ways to code the state characters for pin groups.

Note the following points in the figure :

  • io_pins is a pin group that contains the 8 pins I/O0 through I/O7. Only the download commands for these 8 pins are displayed in the vector file excerpt at the bottom of the figure.
  • The first two vectors code the same state character sequence for io_pins in different ways.
  • In the last vector, the state characters for io_pins cannot be specified in abbreviated hexadecimal form because of the X for pin I/O2.
