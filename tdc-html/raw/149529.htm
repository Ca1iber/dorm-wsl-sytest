Topic 149529

pathPin()

This function specifies a digital pin to be a channel for retrieving the search path of a search.

If you have an ID in cogo() and a pathPin() in the code, you can retrieve the result.

If you do not need a search result, you do not have to add an ID and pathPin() in the searching code.

Starting from SmartRDI 7.5.3, you do not have to use pathPin() for retrieving results in binary and linear searches, but you still need to use pathPin() for HYST_LINEAR tests.

Starting from SmartRDI 7.10.0, you do not have to use pathPin() for retrieving results in binary, linear, and hysteresis searches.

Syntax

pathPin(const string& sPin);
Parameter

Parameter

Description

sPin

The name of a pin to be used for tracking the path.

Waveform definition for pathPin

You need to define a waveform in your wavetable for the specified pathPin.

For a binary search, define a waveform as follows: 

PINS pinA
...
m "d1:1 r1:L" 1L

m indicates a physical index in the wavetable, for example 4. Change m to a proper physical index number in your wavetable.

For a linear search, define a waveform as follows: 

PINS pinA
HRPF # Enable both digital capture and functional pass/fail.
...
m  "d1:1 r1:C" 1C
n  "d1:0 r1:C" 0C
...

m and n indicate physical indexes in the wavetable, for example, 4 and 5. Change m and n to proper physical index numbers in your wavetable.

For more information about a wavetable, see Wavetables

To enable functional results in a digital capture test, set HRPF to all pins in the wavetable.

Note For the digital pin which is specified by pathPin(), you must close the AC relay to make the internal loopback work. If there is any external interference, the interference will impact the loopback signal of the pin.
Note A DUT board calibration might be required to ensure correct functionality of the path pin at higher pattern speeds, for example, a cycle time greater than 50 MHz.

Examples

rdi.cogo("res").search(TA::LINEAR).pathPin("pinA").start(0).stop(4.0).step(10).blockBegin();
Cogo search without pathPin()
RDI_BEGIN();
  rdi.cogo("B1").search(TA::LINEAR).start(0).stop(4.0).step(10).blockBegin();  // No pathPin()
  ...
  rdi.cogo().search().blockEnd();
RDI_END();

rdi.id("B1").getSearchResult();
rdi.id("B1").getSearchPath();
