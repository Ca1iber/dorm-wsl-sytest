PH_QUERY_PROFILE()

You can use this API to get a list of profiles defined for each site.

Syntax

map<int, int> PH_QUERY_PROFILE(string &err_msg)
Parameter

Parameter

Type

Description

err_msg

string &

The return value of the function whether it has succeeded or failed.

Return value

Parameter

Description

map<int, int>

Returned profile IDs for each site. The site number is the key of the map and the profile id is the value.

Related information

PH_DOWNLOAD_PROFILE()

Functional changes
