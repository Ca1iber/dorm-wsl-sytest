forceDropWarn()

Sets a force drop voltage as a warning threshold for the force line.

This function can be only used in the code‑based mode.

This function only supports DC Scale XPS256 card in the PMU operating mode.

Syntax

dcBase& forceDropWarn(double value);

Example

rdi.dc().pin("XPS256_PMU_1").iForceRange(50 mA).iForce(5.0 mA).vClamp(-5.0, 5.0 V).forceDropWarn(3.0 V).execute();

Functional changes

  1. Introduced in SmartRDI 7.10.1
