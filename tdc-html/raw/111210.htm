Topic 111210

getSpecialTestsuite()

This API gets a special test suite of the test flow and creates TestsuiteProxy object for the test suite.

If the target test suite is a valid universal-test-method-based test suite, an object of TestsuiteProxy will be returned. Otherwise, an runtime_error exception will be thrown out.

Syntax

TestsuiteProxy getSpecialTestsuite (const std::string& name);
Parameters

name

The name of the special test suite. It can be "init", "abort", "download", "pause", "reset", "exit", or "bin_disconnect".
