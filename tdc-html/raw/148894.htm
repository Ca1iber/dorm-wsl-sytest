Topic 148894

Parameter: interface_type

Description:

Handlers or wafer probers may be connected through a GPIO, GPIB, or LAN interface to the test system. (Some equipment even supports more than one interface type).

This parameter specifies the interface type used.

GPIO interfaces are of two types: gpio and ngpio

  • ngpio

    Refers to the new configuration where a GPIO E2790C card is used without the GPIO Interface Box E2828A-560.

  • gpio

    Refers to the old configuration where either a GPIO E2790C or a GPIO E2790B card is used with the GPIO Interface Box E2828A-560.

  • gpib

    Refers to a GPIB interface.

  • lan

    Refers to a LAN (TCP/IP) interface

Driver default: None; value must be defined in the driver configuration

Changeable at run-time: No

Applicable for: Handlers and probers

Example:

interface_type: "ngpio"
interface_type: "gpib"
interface_type: "lan"

Functional changes

  1. Introduced in SmarTest 7.0.4
  2. SmarTest 7.2.3: No support for RS-232
  3. SmarTest 7.2.3: LAN supported
