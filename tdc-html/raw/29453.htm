GPIB_ENTER

This API gets data from the specified device and stores the ASCII data into specified variable, and returns 0 on success, non-zero when timeout occurred.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/GpibMapi.h.

For getting data as STRING type:

INT GPIB_ENTER(INT address, STRING *result_s,
 INT num_of_data, 
 TERM_COND term_condition);

INT GPIB_ENTER(INT address, INT address2,
 STRING *result_s,INT num_of_data,
 TERM_COND term_condition);

For getting data as DOUBLE type:

INT GPIB_ENTER(INT address, DOUBLE *result_d,
 INT num_of_data, INT length,
 TERM_COND term_condition); 

INT GPIB_ENTER(INT address, INT address2,
 DOUBLE *result_d, INT num_of_data,
 INT length, TERM_COND term_condition);

INT GPIB_ENTER(INT address, DOUBLE *result_d,
 INT num_of_data, char separator,
 TERM_COND term_condition);

INT GPIB_ENTER(INT address, INT address2,
 DOUBLE *result_d, INT num_of_data,
 char separator TERM_COND term_condition);

INT GPIB_ENTER(INT address, DOUBLE *result_d,
 INT num_of_data,
 TERM_COND term_condition); 

INT GPIB_ENTER(INT address, INT address2,
 DOUBLE *result_d, INT num_of_data,
 TERM_COND term_condition);
Parameters

I/O

Parameter

Description / Range

I

address

GPIB address (or primary GPIB address) of target devices.

Range: 0 to 30 [except 21]

I

address2

(Optional)

GPIB secondary address of target device.

Range: 0 to 30

Default: -1 (Secondary address is not specified)

I

term_condition

(Optional)

Termination condition, CHAR_EOI (Default), TERM_EOI, CHECK_LAST or CLAST_TCHR. See "Important Points".

I

num_of_data

 

Number of data to get from target device(0 to 2147483647). This parameter is required to receive multiple data blocks.

I

length

(Optional)

Number of bytes for a data block (1-256). This is used to split a data block into multiple data blocks.

I

separator

(Optional)

Data separator to split a data block into multiple data blocks.

Range: 0 to 127 (ASCII character code).

Default: ',' (comma).

O

 
result_s
result_d

Pointer for the variable that stores the returned values.

These are used for the data of STRING type and DOUBLE type respectively

Important points

  • TERM_COND is a system-defined data type for setting a termination condition. The following specifiers can be set for this function.
TERM_COND data type

Specifier

Description

CHAR_EOI

Terminates data input when the controller receives a data terminator (for example, lf) or an EOI signal.

TERM_EOI

Terminates data input when the controller receives an EOI signal.

CHECK_LAST

Terminates data input when the number of received data gets to the setting of the "num_of_data" parameter. An EOI signal received before the last data is regarded as a data separator, not a terminator.

CLAST_TCHR

Terminates data input when the number of received data gets to the setting of the "num_of_data" parameter. An EOI signal or a data terminator received before the last data is regarded as a data separator, not a terminator.
  • To receive data and store it as DOUBLE type, the "result_d" parameter is required. To receive multiple numeric data blocks, the "num_of_data" parameter is also required. The "result_d" parameter can receive only numeric data. That is, characters, data terminators, and data separators are discarded.
  • You cannot specify the both "separator" and the "length" parameter at a time.
  • To receive data and store it as STRING type, the "result_s" parameter is required. In this case, the "separator" and "length" parameter cannot be used. To receive multiple data blocks, only an EOI signal or terminator is effective as end of a data block.

Examples

Example 1

INT address = 17;
INT num_of_data = 48;
STRING result[48];
GPIB_ENTER( address, result, num_of_data );

The input data is assumed to be as follows.

DATA1+345.6E-2[cr][lf]DATA2+334.7E-2[cr][lf]....

DATA3+334.9E-2[cr][lf]

(EOI occurs when the lf character is sent)

Data is stored into "result" as follows.

result[0] = "DATA1+345.6E-2"

result[1] = "DATA2+334.7E-2"

.

.

result[47] = "DATA3+334.9E-2"

The GPIB_ENTER API receives 48 data blocks of data sent from the device at address 17, and stores it into the STRING type array.

Example 2

INT address = 17;
INT num_of_data = 48;
DOUBLE result[3];
GPIB_ENTER( address, result, num_of_data );

The input data is assumed to be as follows.

DATA1+345.6E-2,DATA2+334.7E-2,DATA3+

334.9E-2[cr][lf]

(EOI occurs when the lf character is sent)

The values stored into "result" as follows.

result[0] = "DATA1+345.6E-2"

result[1] = "DATA2+334.7E-2"

result[2] = "DATA3+334.9E-2"

The GPIB_ENTER API receives 3 data blocks of data sent from the device at address 17, and stores it into DOUBLE type array.
