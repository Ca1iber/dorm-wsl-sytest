DSP_DIV_C

This API returns the quotient of 2 complex numbers.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_DIV_C(COMPLEX src1, COMPLEX src2, 
                    COMPLEX result);
Parameters

I/O

Parameter

Description / Range

I

src1

Dividend

I

src2

Divisor (Divisor must not be zero (0).)

O

result

result = dividend / divisor

Example

COMPLEX impedance, imp1, imp2;
      : 
DSP_DIV_C(imp1, imp2, impedance);

DSP_DIV_C divides the COMPLEX variable imp1 by imp2 , and returns the results to the COMPLEX variable impedance as shown in the following:

COMPLEX impedance, imp1, imp2; 
DOUBLE   z_product;
      : 
z_product = imp2.real() * imp2.real()+ imp2.imag() * imp2.imag();
impedance.real()=imp1.real()*imp2.real()+imp1.imag()*imp2.imag();//z_product;
impedance.imag()=imp1.imag()*imp2.real()-imp1.real()*imp2.imag();//z_product;

Functional changes

  1. Introduced before SmarTest 6.3.2
