RestoreSiteState

This routine is used for multisite testing. It restores a site setup state previously saved using the GetSiteState routine. If the number of sites before and after restoring does not match, an error is returned.

Syntax

VOID RestoreSiteState(
MS_SITE_STATE     *site_state,
INT32     *return_state);

Parameters

Parameters for RestoreSiteState

Parameter

Description

site_state

Points to a structure of type MS_SITE_STATE containing information on the number of sites and on the sites currently enabled, active, and in focus. This structure usually is filled by a call to GetSiteState.

return_state

Status is set to 0 if execution was ok. Otherwise the site state could not be restored because the number of sites before and after restoring did not match.

Note To change site states use SetActiveSites, SetEnabledSites and SetSiteInFocus.

Example

MS_SITE_STATE site_state;
INT32 re_state;
GetSiteState(&site_state);
...
RestoreSiteState(&site_state, &re_state);

Functional changes

  1. Introduced before SmarTest 6.3.2
