Creating multiple shmoo tests in the Shmoo Tool

In the Shmoo Tool, you can create different independent shmoo tests. Each shmoo test requires you to create a new shmoo page in the shmoo editor (The Shmoo editor is displayed in the editor view after you open the Shmoo Tool).

Before you begin

Open the Shmoo Tool.

Procedure

  1. In the shmoo editor, right-click the bottom area under the scroll bar (see the following picture) and select New.
  2. Enter a name for a new shmoo page and click OK.

    The new shmoo page is created and its name shows on the bottom bar.

  3. Click the new page name and set up a shmoo test in the related Properties view. For details, see set up a shmoo test in the Shmoo Tool.

What to do next

Execute the shmoo test and view the shmoo plot on this new shmoo page.
