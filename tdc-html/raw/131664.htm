Topic 131664

SHARING_CONFIGURATION.getTerminatedPinList()

The getTerminatedPinList() member function of SHARING_CONFIGURATION returns a list of pins that are terminated by the specified termination pin in the topology block.

Syntax

string getTerminatedPinList(const string & vterm) const

Parameter

Description

vterm

The termination pin terminates the pins you want to retrieve.
