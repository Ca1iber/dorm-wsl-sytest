How to import the CCF files in an existing project

About this task

This is not needed when creating a new concurrent test method. When you already have the concurrent test method from previous implementation and need to import the concurrent test framework files, follow the procedure below.

The source files are stored in the file /opt/hp93000/soc/testmethod/library/ccf_tml.zip.

Procedure

  1. Unzip the file ccf_tml.zip.
  2. Import the CCF related files to your test method project
    1. Right-click the test method project and select Import.
    2. In the Import wizard, select General > File System and click Next.
    3. Select the directory where the files are located with Browse button.
    4. Select the subfolders and click Finish.
  3. Include the CCF header files to your project.
    1. Right-click the test method project and select Properties.
    2. In the Properties dialog, select C/C++ General > Paths and symbols > Includes.
    3. Click Add.
    4. In the Add directory path dialog, click Workspace.
    5. Select the <current_project>/ccf_include folder from the pop-up window and click OK.
    6. Check all the three boxes in the Add directory path dialog and click OK.
  4. Copy the file ccf_tml/ccf_lib/libccf_core.so into the directory $device/testmethod/sh_lib-EL7-64bit/preload. If the preload directory does not exist, create it manually.
  5. Build the test method project. If any errors occurred, correct the errors and rebuild it until no error occurs.

Functional changes

  1. Introduced in SmarTest 6.5.4
