How to handle COMPLEX Data Type

This subsection describes the basics of handling the COMPLEX data type. Carefully read the following topics to gain a clear idea about these procedures before actual programming.

Defining and initializing variable

To define the complex variable, do as follows:

COMPLEX variable(DOUBLE init_real, DOUBLE init_imag);

where,

variable COMPLEX data type variable name

init_real Initial value for real part.

Default is 0.0.

init_imag Initial value for imaginary part.

Default is 0.0.

The following are examples for COMPLEX:

COMPLEX cd1();            // cd1=0.0+0.0i
COMPLEX cd2(3.1);         // cd2=3.1+0.0i
COMPLEX cd3(10.3, 23.4);  // cd3=10.3+23.4i

Defining complex variable by copying another variable

To define the complex variable by copying another complex variable, do as follows:

COMPLEX variable2(variable1);

The following expression is also available. 

COMPLEX variable2=variable1;

where,

variable1 original variable

variable2 new variable defined by copying variable1

The following is an example for COMPLEX.

COMPLEX cd2(cf1);           //cd2=3.2+4.3i
COMPLEX cd3=cf1;            //cd3=3.2+4.3i

Accessing Real and Imaginary Part

For accessing the real and imaginary part, use the following methods:

variable.real()
variable.imag()

where, variable is a COMPLEX data type variable.

The following is an example for COMPLEX. 

COMPLEX cd(3.2, 4.3);        // cd=3.2+4.3i
DOUBLE d = cd.real();        // d=3.2
cd.imag() = 12.3;            // cd=3.2+12.3i
const COMPLEX ccd(2.1, 3.4); // ccd=2.1+3.4i
ccd.real() = 3.5;            // error! ccd is const variable

Using an assignment operator

You can use the assignment operator (=) in the same manner as the C++ standard data types. The real and imaginary parts of the variable on the left of the assignment operator are changed to the real and imaginary values of the variable on the right of the assignment operator.

Using relational operators

You can use two relational operators in the same manner as the C++ standard data types: equals (==) and not equals (!=). They compare the real and imaginary parts of the variables on the left and right of the relational operator.

Using mathematical operators

You can use the following four mathematical operators for COMPLEX type data in the same manner as the C++ standard data types; addition (+), subtraction (-), multiplication (*), and division (/).

The following explains what is done for each mathematical operator inside the software.

Suppose three variables cd1, cd2, and cd3 as COMPLEX data type.

  • Addition (+)

    cd3=cd1+cd2

    performs

    cd3.real()=cd1.real()+cd2.real()
cd3.imag()=cd1.imag()+cd2.imag()
  • Subtraction (-)

    cd3=cd1-cd2

    performs

    cd3.real()=cd1.real()-cd2.real()
cd3.imag()=cd1.imag()-cd2.imag()
  • Multiplication (*)

    cd3=cd1*cd2

    performs

    cd3.real()=cd1.real()*cd2.real()-cd1.imag()*cd2.imag()
cd3.imag()=cd1.imag()*cd2.real()+cd1.real()*cd2.imag()
  • Division (/)

    cd3=cd1/cd2

    performs

    cd3.real()={cd1.real()*cd2.real()+cd1.imag()*cd2.imag()}/
                  {cd2.real()*cd2.real()+cd2.imag()*cd2.imag()}
cd3.imag()={cd1.imag()*cd2.real()-cd1.real()*cd2.imag()}/
                  {cd2.real()*cd2.real()+cd2.imag()*cd2.imag()}

The following are examples.

COMPLEX cd0, cd1, cd2, cd3, cd4, cd5, cd6;
cd0=cd1+cd2;
DOUBLE d=(cd3/cd4).real();
if(cd5!=cd6){ ... };

Printing

To print COMPLEX type data, use the << operator. The data is printed in the following form:

( real, imag )

where,

real real part

imag imaginary part

The following is an example.

COMPLEX cd(1.5, 2.3);
cout << cd;             //Output is (1.5, 2.3)
