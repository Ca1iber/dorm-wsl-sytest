FLEX_UTILITY_RELAY

This class is a data container holding the settings of utility lines.

In one task of FLEX_RELAY, if you make different settings for a utility line by using multiple FLEX_UTILITY_RELAY member functions or using a member function multiple times, only the latest setting is downloaded to the hardware when the task is executed.

When you control utility lines, note that the settling time specified in the Pin Configuration window (for the defined utility line names and utility purposes) are not used in the FLEX_RELAY API when the task is executed. Specify a necessary wait time by using the wait() member function of FLEX_RELAY.

Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/FlexUtilRelay.h.

Constructor
This class is always called as the subsidiary data container of the FLEX_RELAY, API. Therefore, the FLEX_UTILITY_RELAY class does not have a public constructor.
Member functions
In this class, the following public member functions are defined:
  • set()
  • on()
  • off()

Member functions

set()
FLEX_UTILITY_RELAY& set (const STRING& conditions);

This member function defines the setting for each of the specified utility lines.

Parameter
Parameter Description
conditions

This parameter is a list of "0", "1", and "x" separated with a comma, or a list of "0","1","x" and " " (space), which represents the settings of the utility lines in the same order as specified in the parameter of the FLEX_RELAY util() member function. "0" sets the user relay to off, "1" sets it to on, and "x" remains it unchanged. For example, "0,0,0,0,1,1,x,1" or "0000 11x1". You may enter a space between values, or may omit it.

For example, the following statements set UTL1 to on, UTL2 to off, UTL3 to be unchanged. 

     FLEX_RELAY relay;
     relay.util("UTL1, UTL2, UTL3").set("1,0,x");
         [ or relay.util("UTL1,UTL2,UTL3").set("10x"); ]

The number of listed settings must be equal to the number of the specified utility lines.
Return value
A reference to the FLEX_UTILITY_RELAY class object.
on()
FLEX_UTILITY_RELAY& on();
This member function sets the user relays connected to the specified utility lines to on.
List of parameters
There are no parameters.
Return value
A reference to the FLEX_UTILITY_RELAY class object.
off()
FLEX_UTILITY_RELAY& off();
This member function sets the user relays connected to the specified utility lines to off.
List of parameters
There are no parameters.
Return value
A reference to the FLEX_UTILITY_RELAY class object.
