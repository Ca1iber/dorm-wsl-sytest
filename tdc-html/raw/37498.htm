The Mapping Operator "->"

You can use the mapping operator (->) to associate a state character sequence (the source sequence, which stands to the left of the mapping operator) with a waveform that was created from another state character sequence (the target sequence, which stands to the right of the mapping operator). For example, the block

DDC dvc dvc dvc

PINS input

111->011

will cause the timing translator to create a waveform from the target sequence 011, and to map 011 to the index of this waveform in the timing map file. But no waveform will be created from the source sequence 111, and in the timing map file, 111 will be mapped to the same index as 011.

You can use lists in the source sequences. Then all the concrete sequences represented by the generic source sequence will be mapped to the index of the waveform created from the target sequence. For example

DDC dvc dvc dvc

PINS input

***->111

will have the effect that all state possible state character sequences will be mapped to the index of the waveform created from 111.

It is also possible to refer within the target sequence to a position of the source sequence. This is coded by a dollar sign ($), followed by the position. As with the \ operator, the reference means that the state character at the position referred to is to be used at the position containing the reference. The following example shows how such a reference can be combined with a list:

DDC dvc dvc dvc

PINS input

[01]**->$111

This has the effect that waveforms will be created from 011 and 111. All other sequences starting with 0 will be mapped to the waveform created from 011, and all other sequences starting with 1 will be mapped to the waveform created from 111.
