TESTSET().testnumber_default()

This member function of TESTSET creates a default test ID that is passed to any called method of TEST() when the test_number_enable testflow flag is enabled for storing in the TestId EDL attribute.

If the limit defined in the test table is used, the default test number is the sum of the test number value defined in the test table and the test number value specified in the Flags area of the Properties view.

If the test table is not used, the default test number is the sum of the test number value specified in the Limits area and the test number value specified in the Flags area of the Properties view.

Syntax

TESTSET & testnumber_default();

Example

TestSet.testnumber_default();
