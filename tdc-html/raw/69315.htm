Seiko-Epson Handlers

Subtopics

  1. HM2000-serial GPIO configuration
  2. HM3500-parallel GPIO configuration
  3. NS5000/6000-parallel GPIO configuration
  4. GPIB driver configurations

The Seiko Epson handlers are currently supported with GPIO and GPIB interface. The following configurations are supported:

  • HM2000-serial GPIO configuration
  • HM3500-parallel GPIO configuration
  • NS5000/6000-parallel GPIO configuration
  • GPIB driver configurations
