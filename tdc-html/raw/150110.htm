Topic 150110

EVENT_CFIM.getCForce()

Reads the force current that has been defined by EVENT_CFIM.cForce().

The value is read from the corresponding EVENT_CFIM object and returned as an EVENT_VALUE_DOUBLE object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

void getCForce(EVENT_VALUE_DOUBLE & value) const;
Parameter
Parameter Description
value

The programmed force current in A (Ampere).

Return value

There is no return value.

Example

For an example see EVENT_CFIM.

Related information
