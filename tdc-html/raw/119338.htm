Working with the Pattern Explorer

Procedure

You can use the Pattern Explorer together with the Pattern Editor to create, clone, edit,and debug patterns and bursts, and save partial patterns.
  1. To highlight executed patterns with results, click .
  2. To link the active editor to the Pattern Explorer selection, click .
  3. If you have configured and saved several layouts for a pattern in the Pattern Editor, you can select these layouts also in the Layout on Pattern Editor column (you may need to scroll to see the column).

    Every time you start the Pattern Editor, this layout is used to display the pattern.
