TMU_TASK.disableTMU()

Syntax

Every TMU_TASK object is representing one TMU Setup (TMU set). There can exist up to 128 TMU sets in parallel. They will be dynamically handled, that is, removed/created, if fewer/more are needed. A set will be activated for the next sequencer run with .setAsPrimary(). The .disableTMU() will deactivate all TMU sets so that no TMU is active during next sequencer run.

static void disableTMU();

List of parameters

There are no parameters.

Return value

There is no return value.

Related information
