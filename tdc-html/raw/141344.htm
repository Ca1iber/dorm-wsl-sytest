EVENT_ICVM.outOfRangeCheck()

Enables or disables the out-of-range check. Per default this check is enabled. If the check is enabled and the measurement range is exceeded, the event contributes with a FAIL to the global test result.

Syntax

EVENT_ICVM & outOfRangeCheck(bool failOnOutOfRange = true);
Parameter
Parameter Description
failOnOutOfRange

Possible values are: true | false

Default is true

Return value

A reference to the corresponding EVENT_ICVM object.

Example

For an example see EVENT_ICVM.

Related information

EVENT_ICVM.getOutOfRangeCheck()

Functional changes

  1. Introduced in SmarTest 7.2.1
