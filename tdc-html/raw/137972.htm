Pin mapping table

The pin mapping table of the MTPT (STPM MCM mapping tables) describes how the pins and utility lines from the STPs (source test programs) are named in the MTP (master test program) and mapped to channels.

The table is stored in a file named pinmap.csv in the MTPT directory. It is created by the generate_template command. The names of the STP pins and utility lines are automatically entered in the STP columns (see <STP name>, below) and the MTP Pin column is prefilled with defaults, but you may need to edit these columns according to the type of mapping:

  • STP pin is mapped to a standard MTP pin (connected to only one device): Enter the name of the MTP pin in the MTP Pin[@shared port] column.
  • Multiple STP pins are mapped to the same MTP pin (the MTP pin is connected to multiple devices): Enter the names of the STP pins in the same row (each in the <STP name> column of their respective STP) and the name of the MTP pin in the MTP Pin[@shared port] column.
  • STP pin is not mapped (does not exist in the MTP): Enter __NC__ in the MTP Pin[@shared port] column.
  • New MTP pin (used in MTP but no STP pin is mapped to it): Enter the name of the MTP pin in the MTP Pin[@shared port] column. (Do not enter anything in the <STP name> columns in this row.)

The naming conventions for pins in the table differ depending on the type of pin:

  • DC pins are listed with just their names.
  • Digital pins that do not belong to a port are listed with just their names.
  • Digital pins that belong to a port are listed with @<portname> after their names, for example "A_CLK@MTP_SHARED".

The file is best edited by importing it into the OpenOffice spreadsheet located in the MTPT folder. Editing is also possible in text editors, but this requires you to make sure yourself that all formatting is correct.

Syntax

Each row in the pin mapping table describes the mapping of a specific STP pin or utility line. The table contains these columns:

  • STP:<STP name>: Beginning at the left of the table, there is one column for each STP, with the STP name as the column title. The columns list the pin names from the STPs.
  • MTP Pin[@shared port]: The name of the pin in the MTP. If the pin belongs to a shared port in the MTP, the port name is appended with a @ character, for example, "A_CLK@MTP_SHARED".

    The default name STPM MCM enters in this column is the STP pin name with the prefix defined in the STP table. (If the "apply prefix on pin config" setting is 0, STPM MCM enters just the STP pin name without the prefix.)

    If an STP pin is not connected to any MTP pin, this is indicated by __NC__.

  • MTP Pin Attribute: Digital pins can be defined as triggers in this column; analogs pins can be assigned triggers.

    A digital pin is defined as a trigger by entering a statement in the form TRIG_DEF:<trigger_id>, <input_pin> in this column:

    • <trigger_id> must be C1, C2, C3, or C4. Each of these IDs can be used only once per MCM.
    • <input_pin> specifies which pin is used as the trigger. It can be either COM1 (to specify the CT2 pin) or COM2 (to specify the CT1 pin).

      An analog pin is triggered by a digital pin by including a statement of the form TRIG:<pin name> in this column. <pin name> is the name of a pin (as it appears in the MTP Pin[@shared port] column) that you have declared as a trigger pin as described above.

  • Site <n>: There is one column for each site that has been defined in the generate_template command. These columns list the channel number that the pin has for the site in question in the MTP. This information is not automatically generated by STPM MCM and must be filled in by you.
  • Notes: This column allows both you and STPM MCM to add remarks about the pin. These notes are just for human consumption and are never processed automatically by STPM MCM. They may be overwritten when the tables are updated, so they are not a suitable place for storing important information.
