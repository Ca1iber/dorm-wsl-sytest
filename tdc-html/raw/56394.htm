Topic 56394

Configuration information in the report window

When you start the SmarTest, change the device, or create a new device on the SmarTest, SmarTest shows the configuration information in the report window.

At startup the SmarTest report window displays the following tables:
License type table
Quantity of licenses checked out from the license server.
MAXIMUM POSSIBLE CONFIGURATION table
Maximum capability of the installed hardware.
REQUESTED CONFIGURATION table
Configuration defined by the model file.

If there are no configuration or licensing errors during startup of SmarTest, this requested configuration is the system configuration used by the SmarTest software.

For details of the model file see The model file.

Viewing the report window can help you to confirm:

  • Installed hardware and its capabilities
  • Correct model file is referenced
  • Correct data is entered in the model and/or device license file
  • Source of a feature dependency error that might occur (see Feature dependency error)
  • Installed hardware is the correct hardware and has the capability that is required in the model and/or device license file
  • Necessary licenses are checked out from the license server

If an incompatibility is detected, an error message is displayed. See Model file error messages.

In offline mode, the report window displays only one table. The table is the same as the second table for online mode, and shows the final system configuration on the software.

License type table

The License type table shows the number of licenses checked out from the license server. For example:

   License type                      | Required | Acquired  | Missing    
-------------------------------------+----------+-----------+----------- 
 SmarTest_SOC                        |      1   |       1   |     0   
 S&S_Tools_Package                   |      1   |       1   |     0

The table columns provide the following information:

Required
Total number of required licenses as defined in the device license file.
Acquired
  • The first figure (outside of the bracket) indicates the sum of the licensed capability acquired through Device specific licensing (DSL) and through the standard InstaPin license pool. The number of standard InstaPin licenses in this example is 134 (224-90).
  • The second figure (inside of the bracket) indicates the licensed capability acquired through Device specific licensing (DSL) only.

If Device specific licensing (DSL) is not enabled, only the first figure without brackets is shown, indicating the licensed capability acquired through the standard InstaPin license pool.

Missing
Number of missing standard InstaPin licenses.

For details of all available licenses, see V93000 License Master Look-up Table.

MAXIMUM POSSIBLE CONFIGURATION table

Note In offline mode, the MAXIMUM POSSIBLE CONFIGURATION table and the REQUESTED CONFIGURATION table will show different configurations if model file and device license file do not match.

In online mode, the MAXIMUM POSSIBLE CONFIGURATION table (see below) describes the maximum possible configuration based on the installed hardware. In offline mode it shows the requested configuration defined by the model file.

Use this table to ensure that parameters you enter in the model file are compatible with the installed hardware. Make sure you select hardware parameter settings that do not exceed the maximum hardware capability.

REQUESTED CONFIGURATION table

The REQUESTED CONFIGURATION table (see below) shows the hardware configuration as defined by the current model file or device license file (both online and offline). If a device license file is found, the licensing content in the model file is ignored and the device license file is used instead.

Use this table to ensure that you accurately enter the values you intend in the model file or device license file. In addition, this table can be used to analyze parser syntax and feature dependence errors.

The table columns provide the following information:

Channel
Range of digital test system channels to which the following parameters apply. Usually, more than one channel is in use for tests.
HW
Channel cards and power supply cards (hardware) used for current tests.
Speed
Available data rates available (bit rate).
Vectors
Amount of memory available for storing vector data and sequencer programs.
Speed Loopback
Maximum loopback speed in bit rate (only available with the SmartLoop external loopback mode of Smart Scale cards).
misc
diff - Enable the differential receiver feature: enter diff in the model file. Disabled by default.

tmu - Time Measurement Unit (TMU) per Pin functionality support available.
