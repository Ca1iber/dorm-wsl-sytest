DDR solution tools enhancements

The test method class: DriverSharing has been enhanced allow efficient testing of devices in a shared driver environment.

  • An online compensation test method has been introduced that compensates dynamically for the loading effect during testflow execution.

    For more information, refer to OnlineCompensation test method.

  • A leakage test method has been introduced that allows testing the leakage current in a shared driver setup.

    For more information refer to Leakage test concept.

  • The fd_merge tool has been enhanced to allow delay offset and loading effect compensation.

    For more information refer to Fd_merge tool.
