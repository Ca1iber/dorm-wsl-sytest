MTP_MEMORY_PATTERN.getPinNameListByDQIndex()

Retrieves pin names based on a data bit index.

If the data bit is related to multiple pins, all the pin names will be returned.

Syntax

STRING_VECTOR getPinNameListByDQIndex(const int &dqIndex);
Parameter

Parameter

Description

dqindex

The data bit index.

Return value

Returns a pin name list.

Example

See Example 4 in MTP_MEMORY_TEST.

Functional changes

  1. Introduced in MTP 3.4.2
