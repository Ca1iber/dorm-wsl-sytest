repeat()

Repeats a given state character sequence a specified amount of times, concatenating copies of the sequence.

If the integer_constant parameter is not of type integer, an error is issued.

Syntax

sequence := repeat( sequence, integer_constant )
Parameter

I/O

Parameter

Description

I

sequence

State character sequence to be repeated.

I

integer_constant

Specifies the number how often the sequence will be repeated.

Example

repeat("01", 3) results in "010101".

repeat("0LLLH", 2) results in"0LLLH0LLLH".

Functional changes

  1. Introduced in SmarTest 7.1.0
