Topic 99060

DVCU, DVCU? - (Define Vector variable Configuration Usage)

The DVCU command connects a source label to a vector variable configuration (VVC). When the source label is a DSRC label, it also allocates the required number of frames for this label. When the source label is a main label (flat setup), DVCU expects that the required amount of memory has already been allocated. This command also downloads the static data, if requested.

The DVCU? query returns the definition of a VVC usage. A usage is identified by three parameters:

  • Label name
  • VVC name
  • Vector offset

DVCU

DVCU {label_name}, {VVC_name}, {vector_offset},
{init_discard_frames}, {number_of_frames}, {var_name_def}, {init_static_data}

DVCU?

DVCU? {label_name}, {VVC_name}, {vector_offset}
Parameters

label_name

Name of the label for which usage is to be created.

In the query, label_name can also be ALL.

VVC_name

Name of the Vector Variable Configuration. For more information, refer to DVVC, DVVC? - (Define Vector Variable Configuration).

In the query, VVC_name can also be ALL.

vector_offset

vector_offset is the offset in the source label where the first frame of the usage is to be created. vector_offset is the logical vector number in the label. The first usage for a source label should start at 0.

The query also accepts ALL.

init_discard_frames

Not in use at this time. This is a reserved parameter.

number_of_frames

Number of frames this usage is to create in the source label.

var_name_def

This parameter specifies the vector variable names for the variable names defined in VVC. This parameter is a string.

Syntax:

"VVC_NAME_1=VEC_VAR_NAME_1[,VVC_NAME_2=VEC_VAR_NAME_2[,.....]]"

The vector variable name can be identical with the VVC variable name. But notice that the vector variable names must be unique in the vector setup.

init_static_data

This parameter is either TRUE or FALSE.

TRUE: Static data, as defined in the VVC, will be downloaded on definition of usage.

FALSE: Static data will not be downloaded.

Application

Digital Source Memory.

Errors

An error is generated for the following conditions:

  • Not enough memory.
  • Specified label or VVC does not exist.
  • Invalid offset (for example if offset > total number of available vectors in a flat DSM label).
  • Overlapping with other usages but with a frame pattern different from the existing one.
  • Given vector variable already exists.
  • Usage already exists with same VVC, label and offset
  • Frame definition not available in VVC for any pins in port of label

Example

The following example creates a usage for the label "src_ramp", using VVC "AC97", at offset 0.

VVC "AC97" looks like:

ATTR DIGDATA
VARIABLES LEFT,RIGHT
PINS ser_in
 SOURCE_DATA_TEMPLATE LEFT[0-19] ; RIGHT[0-19]
 MAPPING
 0 low
 1 high

This usage creates two vector variables, LEFT_DATA and RIGHT_DATA. It creates 1024 frames.

> DVCU "src_ramp","AC97",0,0,1024,"LEFT=LEFT_DATA,RIGHT=RIGHT_DATA",TRUE
> DVCU? ALL,ALL,ALL
< DVCU "src_ramp","AC97",0,0,1024,"LEFT=LEFT_DATA, RIGHT=RIGHT_DATA",TRUE
