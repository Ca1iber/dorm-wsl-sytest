Example

ARRAY_COMPLEX matrix1, matrix2, matrix3;
  .
  .
DSP_MUL_MAT(matrix1, matrix2, matrix3, 15, 10, 20);

DSP_MUL_MAT computes the matrix product of matrix1 (15 by 10) and matrix2 (10 by 20), and returns the results to matrix3 (15 by 20) as follows:

  COMPLEX matrix1[15][10], matrix2[10][20], 
          matrix3[15][20];
  int i, j, k;
  double sumr, sumi;

  for(i=0; <15; i++) {
    for(j=0; j<20; j++) {
       sumr=0.0;
       sumi=0.0;
       for(k=0; k<10; k++) {
       sumr=sumr + matrix1[i][k].real * matrix2[k][j].real 
                 - matrix1[i][k].imag * matrix2[k][j].imag;
       sumi=sumi + matrix1[i][k].real * matrix2[k][j].imag 
                 + matrix1[i][k].imag * matrix2[k][j].real;
       matrix3[i][j].real=sumr;
       matrix3[i][j].imag=sumi;
       }
    }
  }
