EVENT_VCVM.getLimitHigh()

Reads the upper limit that has been defined by EVENT_VCVM.limits() or EVENT_VCVM.limitHigh().

The value is read from the corresponding EVENT_VCVM object and returned as an EVENT_VALUE_DOUBLE object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

bool getLimitHigh(EVENT_VALUE_DOUBLE & high) const;
Parameter
Parameter Description
highLimit

The programmed upper limit in V (Volt).

Return value

bool value indicating the state of the limit definition:

  • true: Limit has been defined by EVENT_VCVM.limits() or EVENT_VCVM.limitHigh().
  • false: No limit is defined or the limit has been cleared by EVENT_VCVM.clearLimits().

Example

For an example see EVENT_VCVM.
