Setup Management Tool

  5. Collision handling

The Setup Management tool enables multiple users to work on different parts of the same setup component in parallel without interfering with each others work. It can be used for distributed setup development and debugging even if the individual users need access to the complete setup component, provided that they do not change the same part of it. The Setup Management tool can handle the following setup components:

  • Level setup
  • Timing setup
  • Testflow setup
  • TMLimits test table setup

The tool is integrated into the Test Program Explorer by means of the scripts that are called when a setup component is loaded or saved, but it can also be called from the command line or by user programs.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.3: TMLimits setup is now supported
