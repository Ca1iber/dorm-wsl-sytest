Format Dialog Box

  2. X Axis Properties
  3. Y-axis Properties
  4. Cursor Properties

The Format dialog box of the Waveform Graphs Tool (WGT) allows you to customize almost all the context information of the graph, such as title, axis, grid, cursor, marker, and trace. This dialog box can be opened from the Format > Edit menu in the Menu Bar and also from the Tool Bar.

The following screen shows the Format dialog box. This dialog box has several tabs: Graph, X Axis, Y Axis, Cursor, Marker, and Trace. Clicking a tab opens the corresponding area in the dialog box.
