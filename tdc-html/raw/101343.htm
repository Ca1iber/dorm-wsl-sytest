Topic 101343

Going to a signal or vector

About this task

The Go to function of the editor allows you to jump easily to a specific

  • Signal Name,
  • Tester Vector Number (tester cycle),
  • X-vector (X-cycle), or
  • Index/Call Number (multiport bursts editor only).

The options of the Go To dialog adapt automatically to the status of the Pattern Editor, because in expanded mode the vector number may not be precise enough. In collapsed mode you can specify, for example, a tester vector number or an X-vector number. In expanded mode you specify a tester cycle number or an X-cycle number instead.

Alternatively to stepping through the menus, you may also double-click the location field in the status line to open the Go To dialog.

Before you begin

Make sure the editor is active and open with the pattern or multiport burst you want to change.

Procedure

  1. For example, in the pattern editor, in the SmarTest main menu select Navigate > Go To and then one out of three: Signal, Tester Vector/Cycle or X-Vector/Cycle.
  2. The Go To dialog box opens. Depending on the Pattern Editor status - collapsed or expanded - the dialog box refers either to vectors or to cycles. Depending on your selection, the focus in the Go to dialog box will be set to one of the three input fields.

    You can type a signal name, tester vector (cycle) number, or X-vector (cycle) number.

    For the Signal Name field a content assist is available. You activate the content assist by pressing Ctrl+Spacebar. If you type only a signal name, the tool jumps to that signal column. If you type in addition to the signal name a tester vector number or an x-vector number, the tool jumps to this vector in the signal column.

    If you do not type a signal name but a tester vector (cycle) number or an x-vector (cycle) number, the tool jumps to this vector (cycle) row.

    You can highlight a signal column and select Navigate > Go To > Tester Vector/Cycle or X-Vector/Cycle.The tool then fills out the Signal Name field. Then you can type a tester vector (cycle) number or an x-vector (cycle) number. The tool jumps to this vector (cycle) in the highlighted signal column.
