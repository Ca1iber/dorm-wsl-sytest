SmartCalc API overview

Note This is only a brief overview of the SmartCalc APIs. Detailed API description can be found in SmartCalc API reference.

APIs provided with the SmartCalc framework

Member function Description
SMC_ARM() Arms your SMC_backgroundProcessing() method with up to 8 arguments of any type. The calculation thread is automatically started. In case a SMC upload is performed, the thread will wait for a SMC upload trigger from, for example, SMC_WAIT_TIME(), ...
SMC_TEST() Buffers results and delays data log until SMC_SYNCHRONIZE() is called. Syntax and parameters are similar to TEST.
SMC_SITE_NUMBER() Gets the site number for which this calculation routine was started.
SMC_SERIAL_EXECUTION_BEGIN() Forces from this point on the execution in serial instead of parallel. SMC_SERIAL_EXECUTION_BEGIN() always needs to be used together with SMC_SERIAL_EXECUTION_END().
SMC_SERIAL_EXECUTION_END() Ends a block of serial execution to allow for parallel execution again. SMC_SERIAL_EXECUTION_BEGIN() always has to be called before.
SMC_PUT_DEBUG() Replacement for the PUT_DEBUG API for SmartCalc multithreaded purpose. For details refer to the PUT_DEBUG description.
SMC_BACKGROUND_ENABLE() Sends SmartCalc the trigger signal to enable background uploads. While this state is enabled, it is not allowed to execute any commands which requires communication with the tester or FW. Need to call SMC_BACKGROUND_DISABLE() at the end.
SMC_BACKGROUND_DISABLE() Disables the background upload. Call only when SMC_BACKGROUND_ENABLE() has been called before.
SMC_GET_VECTORS() Performs hidden upload in SMC thread. Return the captured data of the vector memory located by the vector variable to an array. The returned reference is valid until SMC_SYNCHRONIZE() is called for this thread/site.
SMC_SET_VECTOR_UPLOAD_PACKAGE_SIZE() Sets the package size for the vector upload to the specified number of bytes. This size is valid until the value is changed again. The default implementation assumes a package size of 32 kBytes for all HW including mixed HW.
SMC_GET_VECTOR_UPLOAD_PACKAGE_SIZE() Returns the current package size for the vector upload in bytes.
SMC_GET_WAVEFORM()

Performs hidden upload in SMC thread.

Returns the captured waveform data to an array.

The returned reference is valid until SMC_SYNCHRONIZE() is called for this thread/site.
SMC_GET_COMPLEX_WAVEFORM()

Performs hidden upload in SMC thread.

Returns the captured waveform data to an array of complex.

The returned reference is valid until SMC_SYNCHRONIZE() is called for this thread site.
SMC_SET_WAVEFORM_UPLOAD_PACKAGE_SIZE()

Sets the package size for the waveform upload to the specified number of bytes.

This size is valid until the value is changed again.

The default implementation assumes a package size of 4 kBytes.
SMC_GET_WAVEFORM_UPLOAD_PACKAGE_SIZE() Returns the current package size for the waveform upload in bytes.
SMC_DISABLE() Disables the SMC features like multithreading and hidden upload. This feature is meant for debug purposes. It will disable all the SMC features and execution will continue as without SMC, except the fact that SMC_TEST() statements still will be evaluated during SMC_SYNCHRONIZE().
SMC_SYNCHRONIZE()

Synchronizes the multithreaded execution.

Waits for all calculation threads to be finished or terminate them after the specified timeout. Executes their test statements. Performs internal cleanup.

Has to be called per site and thus outside of an ON_FIRST_INVOCATION_BEGIN/END() block.

The timeout must be greater than or equal to 0. If equal to 0 an infinite wait will be performed (no forced termination of thread).

Returns FALSE when calculation routines had to be aborted or an invocation error occurred. The return value is independent from results of the test statements.
SMC_CLEANUP()

Aborts the multithreaded execution.

Waits for all calculation threads to be finished or terminate them after 10 ms timeout. Performs internal cleanup.

Operates on the active site only, so it has to be called outside the ON_FIRST_INVOCATION_BEGIN/END() block.
SMC_PUT_DATALOG() Buffers the data log values and executes them as soon as the synchronization point (SMC_SYNCHRONIZE()) is reached. The data log values will be executed in the order as the different background threads are started.
SMC_NB_DIGITAL_CAPTURE_END()

Declares the end of a test which contains digital capture started by NB_DIGITAL_CAPTURE_START.

It waits for the digital sequencer completion and performs hidden data upload in between. The specified result area ID must match the area specified in NB_DIGITAL_CAPTURE_START.
SMC_EXECUTE_DEBUG_ACTION() Executes a SmartCalc debug action that can be used for test flow performance optimization by providing hidden upload utilization statistics.

Wrapper APIs to control hidden upload in threads

The following APIs are capable to control the upload of the SMC threads and have the same functionality as their non SmartCalc counterparts.

SmartCalc wrapper non SmartCalc counterpart
SMC_EXECUTE_TEST() EXECUTE_TEST
SMC_FUNCTIONAL_TEST() FUNCTIONAL_TEST
SMC_WAIT_TIME() WAIT_TIME
SMC_WAIT_TEST_DONE() WAIT_TEST_DONE
SMC_DIGITAL_CAPTURE_TEST() DIGITAL_CAPTURE_TEST
SMC_NB_DIGITAL_CAPTURE_END() NB_DIGITAL_CAPTURE_END
