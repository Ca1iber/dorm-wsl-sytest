Adding user defined testflows to the Run menu

You may add your own testflows (user defined) to the Run menu.

Procedure

  1. Open the Run testflow configuration window:
    1. On the menu choose Run > Open Run Dialog
  2. For every user defined testflow you want to add to the menu:
    1. Select the testflow
    2. On the configuration pane select the Common tab
    3. On the Display in the favorite menu area select Run
    4. Click Apply
    5. Close the Run window
