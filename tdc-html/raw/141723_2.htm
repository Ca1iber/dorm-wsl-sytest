rdi.id().getPassFail()

Retrieves the pass/fail result of the functional test.

Syntax

int rdi.id().getPassFail();
List of parameters
There are no parameters.
Return Value
The pass/fail result is returned:
  • 1 is returned for pass and
  • 0 is returned for fail.

Example

int result = rdi.id("f1").getPassFail();

Functional changes

  1. Introduced in SmartRDI 2.1.0
