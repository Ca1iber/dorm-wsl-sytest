Topic 44833

Dependencies

When you code a Command Set function, consider the following dependencies:

  • A maximum CI_MAX_COMMENT_LEN bytes are written to *comment_out.

    Failure to observe this dependency corrupts the command interface. This may result in a segmentation violation or a bus error.

  • A maximum CI_MAX_COMMENT_LEN is assigned to *comlen.

    Failure to observe this dependency results in a comment truncation warning if the value is set greater than CI_MAX_COMMENT_LEN, or results in 0 bytes being transferred to the application model file variable if the value is negative. If the comment length is greater than the comment itself, but is still within the limits of CI_MAX_COMMENT_LEN, random garbage is assigned to the application model file variable.

  • The *return_status is assigned one of the following constants:

    CI_CALL_PASS = 0

    CI_TEST_PASS = 0

    CI_TEST_FAIL = 1

    CI_CALL_ERROR = 2

    CI_CALL_BREAKD = 3

    Failure to observe this dependency results in an undefined return status being returned to the production software. This results in zero bytes of comment being transferred to the application model file variable. The undefined state is treated as an error and an error message is generated. Manual intervention is required and a RETRY and an ABORT button are made available.

  • Any SmarTest Work Center requirements must be satisfied by the user (SIGALRM available), as SmarTest simply waits for the function to finish.

    Failure to observe this dependency may result in a production software hang-up.

  • The Makefile provided by the software must be used for source file compilation.

    Failure to observe this dependency may result in a run time crash. This is caused by unresolved dynamically created external references from the shared library referencing unlinked Command Set Programming Interface (CPI) functions. The Makefile also contains special commands to switch between debug/non-debug modes of operation.

  • Error Messages are your responsibility, and must be written to stderr. This is the medium for passing messages to the report window.
  • The actions for all SIGNALS remain undisturbed for the duration of the function execution. The exceptions are SIGALRM, SIGINT, SIGUSR1 and SIGUSR2).

    Failure to observe this dependency causes system hang-up and/or crash.
