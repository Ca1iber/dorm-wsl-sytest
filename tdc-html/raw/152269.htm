Topic 152269

getFailCount()

Returns fail count.

Syntax

int getFailCount(string pin);
List of parameters

Parameter

Description

pin

Specifies a pin for which to get the fail count.

Return value

The return value is an integer indicating the number of errors.

Example

ON_FIRST_INVOCATION_BEGIN();

  RDI_BEGIN();
    rdi.smartVec("a").pin("pA").writePat("0,1,1,H,H,H,L").failCount().execute();
  RDI_END();

ON_FIRST_INVOCATION_END();

int fcount=rdi.id("a").getFailCount("pA");

Related information

failCount()

Functional changes

  1. Introduced in SmartRDI 2.4.4
