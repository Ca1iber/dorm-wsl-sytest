Topic 96595

ACTION_ASSIGNMENT_EVENT

This asynchronous event indicates that an assignment event occurs in the test program execution.

Dependency

The test program is in execution.

Parameters

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session that this event belongs to.

O

TIME_STAMP

The time point when this event occurs. It contains two long-type parts: SECONDS and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always EXECUTION.

O

EVENT_BODY

The event parameters. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always ACTION_ASSIGNMENT_EVENT.

LEVEL_TYPE

The level type can be WAFER_LEVEL, DEVICE_LEVEL, PAUSE_LEVEL or CUSTOM_LEVEL.

LEVEL_NAME

The level name within a certain level type.

PRE_POST

The position where the dialog takes against the low level. It can be PRE or POST.

VARIABLE_NAME

The application model variable name.

VARIABLE_VALUE

The value assigned to the application model variable.

This parameter is represented by ParamList whose key and value are both string type.
