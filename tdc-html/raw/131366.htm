SPMU_PIN_TASK.relay()

Sets the relay switching mode that automatically also executes a specific relay control pattern. Measurements performed with the shared resources like the BADC are automatically serialized.

Note The same relay mode may result in a different relay control pattern determined by the underlying HW.
Note Although Board ADC measurements can be done with this function, it is recommend using the FLEX_RELAY class instead.

Syntax

SPMU_PIN_TASK& relay(const STRING& relay);
Parameters
Parameter Description
relay

Default mode is "NO".

Refer to the list of available options of the relay parameter below.
Note DC Scale cards do not support TERM, NTBMM and NTMBB modes!

Supported only in PMU operating mode of DC Scale pins.

Relay actions depend on the settings of SPMU_PIN_TASK.mode() with SPMU_TASK.execMode() set to "FORCE_ON":

  • mode() set to "IFVM", "VFIM":
    1. Connect DC Scale card by closing AC_Force, H_IMP and AC_Sense relays.
    2. Measure
    3. Open AC_Force, H_IMP and AC_Sense relays.
  • mode() set to "VM_HIZ":
    1. Connect DC Scale card by closing H_IMP and AC_Sense relays.
    2. Measure
    3. Open H_IMP and AC_Sense relays.
  • mode() set to "VFIM_UNGANGED":
    1. Connect DC Scale card by closing AC_Force, H_IMP and AC_Sense relays.
    2. Measure (not needed pins will be disconnected)
    3. Open AC_Force, H_IMP and AC_Sense relays.

Return value

A reference to the SPMU_PIN_TASK object.
