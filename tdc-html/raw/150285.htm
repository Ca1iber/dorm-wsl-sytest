EVENT_VCIM.limitHigh()

Sets the upper current limit to compare against threshold.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

EVENT_VCIM & limitHigh(const EVENT_VALUE_DOUBLE & high);
Parameter
Parameter Description
highLimit

The upper limit to be set in A (Ampere).

Return value

A reference to the corresponding EVENT_VCIM object.

For an example see EVENT_VCIM.
