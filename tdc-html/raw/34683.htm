LevelsAttrType

Contains the numbers of the sets defining the levels. For set based levels, these are the level set numbers and the DPS set numbers. For equation based levels, these are the level set numbers, the equation set numbers, and the spec set numbers.

The data type is DRLLevelsAttr.
