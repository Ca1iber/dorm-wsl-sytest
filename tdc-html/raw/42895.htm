A Suggested Test Program Methodology

The following method is just one way of creating your test program. It is split into defining all device-related information, followed by all testfloor-related information. Some of the steps, however, may not be relevant (for example, if you use a package handler the wafer description screen does not apply). You must decide which steps are relevant for you and set them up appropriately.

The method for creating a test program for multi-site testing is slightly different, although the principle steps are the same.

  1. Create your Testflow. (See Inserting a test suite in the testflow)
    1. Place tests with a high fault coverage early in your testflow
    2. Place time-consuming tests later in your testflow
  2. Define your Wafer (see Wafer Description Tool)
    1. Wafer orientation
    2. Wafer coordination
    3. Number of die on your wafer
    4. Stepping pattern
    5. Prober setup-command file
  3. Select your Application and define the application data in the Application Data Editor Input window.
  4. Select the Handler/Prober File from the appropriate library (see Selecting a Handler/Prober Command Set)
  5. Select an Execution Input file as required (see Selecting an Execution Input)

    These might be, for example:

    1. Optical character recognition
    2. Barcode reader
  6. Select the Data Bridge (see Selecting a Data Bridge)
