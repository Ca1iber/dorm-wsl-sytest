rdi.route().enableOnlyActiveSites()

Enables the utility line settings on active sites and disables them on inactive sites.

Usage of the function:

  • To ensure the site masks are correctly set, this API must be called at the beginning of a testflow when the testflow is executed for each time.
  • The function can be called only in the code‑based mode. For more information, refer to Execution mode in topic SmartRDI.
  • The function can work together with FOR_SEMI_PARALLEL_TEST_BEGIN/FOR_SEMI_PARALLEL_TEST_END to set different utility relay states on different sites. See the example below.
Note This function only affects states that have been defined by the Routing Tools editors. The function has no effect on the manipulation of utility lines by rdi.route().pin().

Syntax

routeGroup& enableOnlyActiveSites();
Note Although this command must not be called inside of an RDI block, it generates and executes a pattern and thus can be called with port().
List of parameters
There are no parameters.
Return value
A reference to the routeGroup object.

Examples

rdi.route().enableOnlyActiveSites().execute();
rdi.port("RouteCtrlPort").route().enableOnlyActiveSites().execute(); // The port "RouteCtrlPort" includes UTIL digital control pins.
Setting different utility relay states on different sites in FOR_SEMI_PARALLEL_TEST_BEGIN/FOR_SEMI_PARALLEL_TEST_END:
...
FOR_SEMI_PARALLEL_TEST_BEGIN();
  If(GET_CURRENT_SEMI_PARALLEL_GROUP_NUMBER()==1)  // For example, site 1, 3 active
  {
    rdi.route().enableOnlyActiveSite().execute();  // Mask site 2, 4 
    rdi.route().applyState("s1").execute();        // "s1" will apply on site 1, 3
    rdi.route().pin("pin1").setOn().execute();     // pin1 will setOn on site 1, 3
  }
  else  // For example, site 2, 4 active
  {
    rdi.route().enableOnlyActiveSite().execute();  // Mask site 1, 3
    rdi.route().applyState("s2").execute();        // "s2" will apply on site 2, 4
    rdi.route().pin("pin2").setOn().execute();     // pin2 will setOn on site 2, 4
  }
FOR_SEMI_PARALLEL_TEST_END();

rdi.route().enableOnlyActiveSite().execute();      // Unmask all active sites

Functional changes

  1. Introduced in SmartRDI 7.5.0
