EVENT_WAVEFORM_CFIM.getCForce()

Queries the force current waveform that has been defined by EVENT_WAVEFORM_CFIM.cForce().

The waveform is read from the corresponding EVENT_WAVEFORM_CFIM object and returned as an ARRAY_D object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

const ARRAY_D & getCForce() const;

List of parameters

There are no parameters.

Return value

An ARRAY_D object containing the waveform samples that are defined in A (Ampere).

Example

For an example see EVENT_WAVEFORM_CFIM.

Related information
