CCTenableSMC

This function defines how SmartCalc is supported by the concurrent test framework.

This function is usually used in the init() function but not used in the other functions of the CCF test method template.

The framework can handle the SmartCalc in the following three modes:

  • SMC_AUTO

In this mode, the framework will automatically request the hidden upload resources and start the process() method in a separate thread. User should put hidden upload and calculation code in process method and ensure its thread safety.

  • SMC_CONFIG_HIDDEN_UPLOAD

In this mode the framework will request the hidden upload resources. But you need to write your own upload and calculation code to your SMC_backgroundProcessing() method and start it manually in a separate thread.

  • SMC_NONE

In this mode, the framework will do nothing specific for SmartCalc. You can write your own calculation code to your SMC_backgroundProcessing() method and start it manually in a separate thread. Or you can handle result process without SmartCalc. Hidden upload is not supported in this mode.

This function is defined in the header file /opt/hp93000/soc/segments/tml/include/CCTestMethod.hpp.

Syntax

void CCTenableSMC(bool option)
Parameter

yn

Enable SmartCalc or not. It can be SMC_AUTO,

SMC_CONFIG_HIDDEN_UPLOAD or SMC_NONE.

Examples

Using SMC_AUTO mode

void init()
{
    CCTsetExecMode(EXM_DIGITAL_CAPTURE_TEST);
    CCTsetResultArea(digcapPin, 8096);
    CCTenableSMC(SMC_AUTO);
    ...
}

void process()
{
    ARRAY_I data = SMC_GET_VECTORS(capture_name, CCTgetResultArea());
    DSP_ADC_HISTOGRAM(data, &result, ..);
    SMC_TEST(...);
}

Using SMC_CONFIG_HIDDEN_UPLOAD mode

void init()
{
  CCTsetExecMode(EXM_DIGITAL_CAPTURE_TEST);
  CCTsetResultArea(digcapPin, 8096);
  CCTenableSMC(SMC_CONFIG_HIDDEN_UPLOAD);
  ...
}

void process()
{
  // do some other non threading -safe code
  // or non hidden supported upload and calc
  ...
  SMC_ARM();
  ..
}

void SMC_backgroundProcessing()
{
  ARRAY_I data = SMC_GET_VECTORS(capture_var, CCTgetResultArea());
  DSP_ADC_HISTOGRAM(data, &result, ..);
  SMC_TEST(...);
}

Using SMC_NONE mode

void init()
{
    CCTsetExecMode(EXM_DIGITAL_CAPTURE_TEST);
    CCTenableSMC(SMC_NONE);
    ...
}

void process()
{
    // do some other non threading -safe code
    // or non hidden supported upload and calc

    ARRAY_I data = VECTOR(capture_var).getVectors();
    SMC_ARM(data);
    ..
}

void SMC_backgroundProcessing(ARRAY_I &data)
{
    DSP_ADC_HISTOGRAM(data, &result, ..);
    SMC_TEST(...);
}
