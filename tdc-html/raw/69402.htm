Single-site GPIO configuration

Subtopics

  1. Valid combinations of plug-ins and configuration files
  2. Binning map
  3. Timing diagram (TESEC single-site)

The TESEC "Single-site" configuration is valid for TESEC single-site handlers.

Supported handler models

  • 9588 or others with similar interface

Features

  • 1 site
  • global test start signal
  • explicit binning
  • 5 bin categories
  • no "empty" bin

Required handler cable

There is no preconfigured handler cable available for this configuration. Please see Tesec handler cable for the information on configuring the cable.
