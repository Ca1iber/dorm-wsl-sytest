Working with pattern master files

Subtopics

  1. Creating a pattern master file
  2. Loading or initializing a pattern master file
  3. Loading and saving selected items of a pattern master file
  4. Saving a pattern master file
  5. Saving patterns in separate files (Save Partial As)

SmarTest's general pattern management and the use of pattern master files gives you flexibility to organize your test patterns.

  • A pattern master file defines and references the set of pattern files to be used for a testflow.
  • You can store pattern files everywhere in the file system. The pattern files do not have to reside in the vectors subdirectory of the device directory. Storing patterns in different files allows much faster debugging.

The Pattern Explorer allows you to select individual patterns, edit them, and then use them for your test by building a master list of the patterns that will be downloaded and used for the test.

Pattern master file versus single pattern file

Both approaches have certain advantages and disadvantages. Pattern master files allow the following:

  • You can store individual patterns in separate pattern files.
  • You can place pattern files anywhere on the file system.
  • You can load only the patterns required for a specific test.
  • You can save only the changed pattern files.
  • You can use the testflow editor without loading the pattern files.

When working with single pattern files, the following applies:

  • All patterns are contained in one large file.
  • The pattern file must reside in the device directory.
  • Whenever debugging the pattern file (even when changing just one vector) the complete file must be loaded.
  • The Save function always saves the entire pattern file.
  • The testflow editor only works when the pattern file is loaded.

Performance

There is a trade-off when using a pattern master file between flexibility and performance.

  • Maximum flexibility is achieved when you use a separate file for each pattern.
  • Maximum performance is achieved when one pattern file (allvec.bin) contains all the patterns. On download, the pattern master file takes around 5% to 20% (worst case) more time than a single pattern file.

As a consequence of these performance differences, we recommend:

  • Use a pattern master file for debugging tests, especially when you are working with very large pattern files.
  • Use a single pattern file (allvec.bin) for production tests, especially when download timing is critical.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.3: Pattern Explorer supports pattern master files.
  3. SmarTest 7.1.3: The New Pattern Setup wizard supports the creation of pattern master files.
