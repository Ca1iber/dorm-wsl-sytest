Topic 151333

measFilter()

Sets the measure filter for voltage and current measurements.

XPS256 pins feature programmable anti-aliasing, low-pass measurement filters for voltage and current measurements. This member function sets the filter for the selected measurement mode.

This function is only for the DC Scale XPS256 card in PMU operating mode. The function can be used in the code‑based mode and in the pattern‑based mode.

Syntax

dcBase& measFilter(double filterFrequency);
Parameter
Parameter Description
filterFrequency Sets the filter to the given frequency in Hertz (Hz) or switches the filter off.

Programmable double values are

  • Value between the card-specific minimum and maximum value: The filter is set to the defined value.
  • 0.0: The filter is set to the card-specific default value.
Card-specific range and default value:
  • XPS256: Refer to section
    • Measurement filters in XPS256 programming - Measure voltages or to section
    • Measurement filters in XPS256 programming - Measure currents.

Return Value

A reference to the dcBase object.

Application notes

Replacing average() with measFilter() on XPS256 pins
The average() function for XPS256 pins utilizes hardware based averaging for calculating the average of multiple consecutive samples on board. Using the average() function limits the effective maximum sample frequency to
  • 1.5 MHz / Number of averaged samples.
The average() function may be replaced by the measFilter() function to avoid this limitation. The digital low-pass measure filter behaves like a simple RC filter. Therefore, not only the signal settling time but also the measure filter settling time must be considered when programming the delay time of the measurement by function measWait().

For more information, refer to application note Measure filter settling time.

Measure filter settling time
The programmable digital low-pass measure filters for all ADCs behave like simple RC filters. A short settling time is to be applied or some samples are to be ignored to settle to an acceptable difference to the input signal.
The required settling time of the filter or the number of samples to be ignored depends on the accepted maximum relative error and the filter settings. The supported DC Scale cards show a slightly different behavior:
  • XPS256: Refer to the related application notes in topics Measure voltages or in Measure currents of the XPS256 programming overview.

Example

rdi.dc().pin("Pin_1")
 .vMeasRange(3.0 V)
 .connectState(TA::HIZ)
 .measFilter(5.0 kHz)
 .execute();
