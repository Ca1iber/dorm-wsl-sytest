DPSPINS resources

Parameters of the DPSPINS resources define the behavior of DPS pins in the equation based level setup. Specific keywords and values are to be used to define the resource parameters.

Resource parameter table

Resource parameter Expression Description
capacitance Capacitance in microfarads (μF)

Specifies the load capacitance on the DUT board.

This optional parameter is supported only by the DC Scale XPS256 card.

For the programmable range, refer to section Dynamic behavior in force voltage or clamp voltage mode in XPS256 force and clamp voltages.

Default value if not defined: 0 μF
connect_state Keyword:
  • himp
  • hdig
  • norm_hdig
  • ungang

Defines which current to apply if the DC Scale pins in DPS mode are connected.

This parameter is only for DC Scale cards.

norm1) The default state for all DC Scale cards.
himp

Activates the high-impedance measurement mode.

This mode allows you using the DC Scale card as a voltmeter.

This parameter is for all DC Scale cards.
hdig

Activates the digitizer mode.

This parameter is only for the DC Scale UHC4T card.
norm_hdig

Activates the normal DPS mode with digitizer mode.

This parameter is only for the DC Scale UHC4T card.
ungang

Specifies to connect only necessary channels.

This parameter is for all DC Scale cards. See also Using UNGANG connect state with DC Scale DPS cards.

Note that on DPS128/64 and XPS256 you cannot execute a current compare on a ganged group of channels in unganged mode. Already activated comparators are silently disabled in unganged mode. A user notification (Error or warning) is omitted in this case, to avoid any interrupt in the testflow. The previous state of the comparators is automatically restored after the ganged group has been restored.
current_filter_frequency Frequency in hertz (Hz)

Sets the force current or clamp current filter to the given frequency or sets the filter to the default value.

The expression must be 0 to set the card-specific default value.

This optional parameter is supported only by the DC Scale XPS256 card.

Card-specific range and default value:

  • XPS256: For the programmable range and the default value, refer to "Current bandwidth" in section Dynamic behavior in force current or clamp current mode in XPS256 programming - Force and clamp currents.
disable_const_curr_check none

Switches off the constant current check. Also prevents that constant current warning messages are printed in the UI report window.
load_step_mode Keyword:
  • STD
  • FAST

Sets the load step mode to compute optimal regulation loop behavior.

This optional parameter is supported only by the DC Scale XPS256 card.
STD The standard mode provides a dynamic behavior similar to DC Scale DPS128/DPS64 cards.
FAST This mode provides a shorter reaction time to load steps.

Default value if not defined: STD

For more information, refer to XPS256 programming - Force and clamp voltages and XPS256 programming - Load step response.
ilimit Current in milliamperes (mA)

Starts the current limit definition and sets both the source and the sink current limit.

The value must be within the current force (clamp) ranges listed in the specifications for DC Scale Device Power Supplies.

This parameter is for both DPS-slot DPS and DC Scale pins.
ilimit_sink Current in milliamperes (mA)

Sets only the sink current limit.

The value must be within the current force (clamp) ranges listed in the specifications for DC Scale Device Power Supplies.

This parameter is for DC Scale pins only.
ilimit_source Current in milliamperes (mA)

Sets only the source current limit.

The value must be within the current force (clamp) ranges listed in the specifications for DC Scale Device Power Supplies.

This parameter is for DC Scale pins only.
iout_clamp_rng Current in milliamperes (mA)

Sets the clamp current range for DC Scale pins in DPS mode.

This parameter is only for DC Scale pins.
max_voltage_drop_force Voltage in volts (V)

Defines a threshold for the voltage drop on the force line above which a channel is disconnected. Regardless of the voltage drop polarity, the threshold is to defined as absolute value.

This optional parameter is supported only by the DC Scale UHC4T card and the DC Scale XPS256 card.

The DC Scale UHC4T card and the DC Scale XPS256 card can measure the voltage drop of the force line on the DUT board.

Card specific behavior:

  • UHC4T: A comparator defines if the voltage drop is small enough or not. This means to measure the drop of the pogo cable (see specifications) plus the drop of the DUT board. Value/flag available for all channels ganged. The range is 0.0 ... 0.5 V with a resolution of 1 mV. Default is 0.25 V.

    Two rules apply for the two parameters max_voltage_drop_force and max_voltage_drop_return and the programmed force voltage:

    • Both max_voltage_drop_force and max_voltage_drop_return must be between 0.0 and 0.5 V.
    • The sum of max_voltage_drop_force and max_voltage_drop_return is limited by the programmed force voltage according to the diagram below. Only values within the red area are allowed.

  • XPS256: An ADC measures the voltage drop on the force line. A comparator evaluates the absolute value of the measured voltage and triggers the disconnection of the channel if the maximum value is reached.

    For the specification, refer to Voltage drop protection / measurement in XPS256 other performance characteristics.

    The programmable range is 0.0 … 1.0 V for the force line and for the return line but, the total for the two lines must not exceed 1.0 V.

    For a maximum voltage drop > 0.5 V, the openLoopProtection parameter must be set to none and in the DC Scale Safety editor the Vdrop Disco parameter must be set to ON.

The measurement range covers positive and negative voltages for source and sink currents but only the absolute value is to be programmed.
max_voltage_drop_return Voltage in volts (V)

Defines a threshold for the voltage drop on the force line above which a channel is disconnected. Regardless of the voltage drop polarity, the threshold is to defined as absolute value.

This optional parameter is supported only by the DC Scale UHC4T card and the DC Scale XPS256 card.

The DC Scale UHC4T card and the DC Scale XPS256 card can measure the voltage drop of the force line on the DUT board.

Card specific behavior:

  • UHC4T: A comparator defines if the voltage drop is small enough or not. This means to measure the drop of the pogo cable (see specifications) plus the drop of the DUT board. Value/flag available for all channels ganged. The range is 0.0 ... 0.5 V with a resolution of 1 mV. Default is 0.25 V.

    Two rules apply for the two parameters max_voltage_drop_force and max_voltage_drop_return and the programmed force voltage:

    • Both max_voltage_drop_force and max_voltage_drop_return must be between 0.0 and 0.5 V.
    • The sum of max_voltage_drop_force and max_voltage_drop_return is limited by the programmed force voltage according to the diagram below. Only values within the red area are allowed.

  • XPS256: An ADC measures the voltage drop on the common return line referenced to the channel specific ground sense pin (GS#). A comparator evaluates the absolute value of the measured voltage and triggers the disconnection of the channel if the maximum value is reached.

    For the specification, refer to Voltage drop protection / measurement in XPS256 other performance characteristics.

    The programmable range is 0.0 … 1.0 V for the force line and for the return line but, the total for the two lines must not exceed 1.0 V.

    For a maximum voltage drop > 0.5 V, the openLoopProtection parameter must be set to none and in the DC Scale Safety editor the Vdrop Disco parameter must be set to ON.

The measurement range covers positive and negative voltages for source and sink currents but only the absolute value is to be programmed.
ms_const_curr_disconnect Time in milliseconds (ms)

Specifies the delay time before a channel that is in constant current mode without interruption is disconnected. If the "Constant current" flag set without interruption for the defined time, the channel is disconnected.

This optional parameter is supported only by the DC Scale UHC4T card and the DC Scale XPS256 card.

The valid range for UHC4T is 0 to 65 ms with a resolution of 0.001 ms.

The valid range for XPS256 is 0 ms … 1270 ms.

If you Do not define ms_const_curr_disconnect, the power supply will not disconnect in case of constant current.
ms_const_curr_time_to_alarm Time in milliseconds (ms)

Specifies the time until the "Constant current" flag is set for a channel that is in constant current mode without interruption.

This optional parameter is supported only by the DC Scale XPS256 card.

Valid range: 0 ms … 1270 ms

Default value if not defined: 0 ms

For more information, refer to Constant current in XPS256 status flags.
ms_fast_preload Time in milliseconds (ms)

Applies full power (40 A) for a programmable time. Afterwards the UHC4T returns to its previous state.

This optional parameter is supported only by the DC Scale UHC4T card.

To be used after the DPS has been connected to charge large capacities. The valid range is 0 ... 10 ms with a resolution of 0.001 ms. Default is 0 ms.
offcurr Keyword:
  • min
  • act
  • open
  • act_min
  • act_open

The parameter defines which current to apply if the pins in the DPS pin list are disconnected.

This parameter is for both DPS-slot DPS and DC Scale pins.

One of the following specifiers can be set:
min

Use min (minimum current) for high impedance (HIZ in the PSLV command).
act

Use act (actual current) for low impedance (LOZ in the PSLV command).

Note This is the recommended default setting for the off-state of DPS pins. Only act discharges capacitors on the DUT board. Use min or open carefully and only for selected tests.
open Use open for high impedance with opening output relay (HIZ_R in the PSLV command).
act_min

Combines act and min. First, the DPS is switched to 0 V with an unchanged current limit. After the output voltage has reached 0 V (±50 mV) or after a timeout of 1 second, the DPS pin is switched to high impedance.

Note The HC-DPS cannot go down to 0 V output voltage. Here the DPS pin is switched to high impedance at 200 mV (+/-50mV) or after a timeout of 1 second.

Using act_min is safer when changing the DUT or DUT board after a disconnect (LOZ_HIZ in the PSLV command).
act_open

Combines act and open. First, the DPS is switched to 0 V with an unchanged current limit. After the output voltage has reached 0 V (±50 mV) or after a timeout of 1 second, the DPS pin is switched to open.

Using act_open is safer when changing the DUT or DUT board after a disconnect (LOZ_HIZ_R in the PSLV command).
open_loop_protection Keyword:
  • diode
  • none

The parameter selects the status of the internal force to sense connections.

The internal force to sense connections are available between the P# pin and the PS# pin and between the GS# pin and the common GND pin.

One of the following specifiers can be set:
diode

The internal connections are made via anti-parallel diodes.

This is the default state if the parameter is not defined.

This is the recommended setting if both parameters max_voltage_drop_force and max_voltage_drop_return are set to a value < 0.5 V.
none

The internal connections are open. The output stage no longer has any voltage feedback if the force to sense connection on the DUT or the DUT board is (unintentionally) open.

The following rules apply to this option:
  • The Vdrop Disco parameter must be disabled in the DC Scale Safety editor.
  • This is the required setting if one of the parameters max_voltage_drop_force or max_voltage_drop_return is set to a value ≥ 0.5 V.
This optional parameter is supported only by the DC Scale XPS256 card.
protect none

The current limiter protection mode protects against the switch-off of the system.

This optional parameter is supported only by the DC Scale UHC4T card.
pulldown Keyword:
  • on
  • off

The parameter defines the state of the pull‑down circuit for disconnected channels.

One of the following specifiers can be set:
on

Pull‑down circuit is active in disconnected state.

This is the default state in "HIZ" disconnect state.
off Pull‑down circuit is inactive in disconnected state.

This is the default state in "LOZ" disconnect state.

This optional parameter is supported only by the DC Scale XPS256 card.
t_ms Time in milliseconds (ms)

Sets the connect setup time from the connect of a pin to a common connect reference time point for rising and falling edges.

The allowed range is ±2 147 483 646 ms.

This parameter is for both DPS-slot DPS and DC Scale pins.
voltage_filter_frequency Frequency in hertz (Hz)

Sets the force voltage or clamp voltage filter to the given frequency or sets the filter to the default value.

The expression must be 0 to set the card-specific default value.

This optional parameter is supported only by the DC Scale XPS256 card.

Card-specific range and default value:

  • XPS256: For the programmable range and the default value, refer to "Voltage bandwidth" in section Dynamic behavior in force voltage or clamp voltage mode in XPS256 programming - Force and clamp voltages.
voltage_slew_rate Slew rate in millivolts per microsecond (mV/μs)

Specifies the voltage slew rate. The hardware‑defined voltage ramp is generated by the digital control loop of the front‑end and is therefore more precisely defined than ramps that are defined by the vout_fall_... and vout_rise_... parameters.

This optional parameter is supported only by the DC Scale XPS256 card.

For the specification and the programmable range, refer to section Dynamic behavior in force voltage or clamp voltage mode in XPS256 force and clamp voltages.

Default value if not defined: 0 μF

For more information, refer to XPS256 programming - Load step response and XPS256 programming - Load step response.
vout Voltage in volts (V)

Starts the voltage level definition.

This parameter is for both DPS-slot DPS and DC Scale pins.
vout_fall_settling_t_ms Time in milliseconds (ms)

Sets the settling time for the falling edge.

The allowed range is -10 000 ... 10 000 ms.

The parameter is always used for connect and disconnect cases. See the example 2 below.

This parameter is for both DPS-slot DPS and DC Scale pins.
vout_fall_settling_t_ms_c2c Time in milliseconds (ms)

Sets the settling time for the falling edge.

The allowed range is -10 000 ... 10 000 ms.

The parameter is optional. If specified, it is used for "connect-to-connect" cases, that is for level changes caused by a reprogramming of the output voltage within one DPS set, or by a switch to another DPS set while the DPS is connected. If omitted, the parameter vout_fall_settling_t_ms is used instead.

This parameter is for both DPS-slot DPS and DC Scale pins.
vout_fall_t_ms_per_volt Inverse slew rate in milliseconds per volt (ms/V)

Sets the inverse slew rate for the falling edge.

The allowed range is 0 ... 10 000 ms/V.

The parameter is always used for connect and disconnect cases. See the example 2 below.

This parameter is for both DPS-slot DPS and DC Scale pins.
vout_fall_t_ms_per_volt_c2c Inverse slew rate in milliseconds per volt (ms/V)

Sets the inverse slew rate for the falling edge.

The allowed range is 0 ... 10 000 ms/V.

The parameter is optional. If specified, it is used for "connect-to-connect-" cases, that is for level changes caused by a reprogramming of the output voltage within one DPS set, or by a switch to another DPS set while the DPS is connected. If omitted, the parameter vout_fall_t_ms_per_volt is used instead.

This parameter is for both DPS-slot DPS and DC Scale pins.
vout_frc_rng Voltage in volts (V)

Sets the force voltage range for DC Scale pins in DPS mode.

This parameter is only for DC Scale pins.
vout_rise_settling_t_ms Time in milliseconds (ms)

Sets the settling time for the rising edge.

The allowed range is -10 000 ... 10 000 ms.

The parameter is always used for connect and disconnect cases. See the example 2 below.

This parameter is for both DPS-slot DPS and DC Scale pins.
vout_rise_settling_t_ms_c2c Time in milliseconds (ms)

Sets the settling time for the rising edge.

The allowed range is -10 000 ... 10 000 ms.

The parameter is optional. If specified, it is used for "connect-to-connect-" cases, that is for level changes caused by a reprogramming of the output voltage within one DPS set, or by a switch to another DPS set while the DPS is connected. If omitted, the parameter vout_rise_settling_t_ms is used instead.

This parameter is for both DPS-slot DPS and DC Scale pins.
vout_rise_t_ms_per_volt Inverse slew rate in milliseconds per volt (ms/V)

Sets the inverse slew rate for the rising edge.

The allowed range is 0 ... 10 000 ms/V.

The parameter is always used for connect and disconnect cases. See the example 2 below.

This parameter is for both DPS-slot DPS and DC Scale pins.
vout_rise_t_ms_per_volt_c2c Inverse slew rate in milliseconds per volt (ms/V)

Sets the inverse slew rate for the rising edge.

The allowed range is 0 ... 10 000 ms/V.

The parameter is optional. If specified, it is used for "connect-to-connect-" cases, that is for level changes caused by a reprogramming of the output voltage within one DPS set, or by a switch to another DPS set while the DPS is connected. If omitted, the parameter vout_rise_t_ms_per_volt parameter is used instead.

This parameter is for both DPS-slot DPS and DC Scale pins.
warn_voltage_drop_force Voltage in volts (V)

Specifies a voltage threshold for setting the "Voltage drop force warning" status flag. The threshold should be a reasonable value below the maximum voltage drop specified by max_voltage_drop_force.

This optional parameter is supported only by the DC Scale XPS256 card.

For the specification and the programmable range, refer to Voltage drop protection / measurement in XPS256 other performance characteristics.

Default value if not defined: 150 mV

For more information, refer to Voltage drop force warning in XPS256 status flags.
warn_voltage_drop_return Voltage in volts (V)

Specifies a voltage threshold for setting the "Voltage drop return warning" status flag. The threshold should be a reasonable value below the maximum voltage drop specified by max_voltage_drop_return.

This optional parameter is supported only by the DC Scale XPS256 card.

For the specification and the programmable range, refer to Voltage drop protection / measurement in XPS256 other performance characteristics.

Default value if not defined: 50 mV

For more information, refer to Voltage drop return warning in XPS256 status flags.
Note Resource values may be specified in any order, but must not be specified more than once for any DPS pin. If they are, an error is reported.

Some parameters are valid for selected DUT power supplies:

  • For the above parameters, vout, ilimit, t_ms, vout_rise_t_ms_per_volt, vout_fall_t_ms_per_volt, vout_rise_settling_t_ms, vout_fall_settling_t_ms, offcurr, and disable_const_curr_check can be defined for both DPS-slot DPS (non-DC Scale) pins and DC Scale pins.
  • Parameters vout_frc_rng, iout_clamp_rng,and connect_state are only for DC Scale pins.
  • Parameters ms_const_curr_disconnect, and ms_fast_preload are only for DC Scale UHC4T.
  • Parameters max_voltage_drop_force and max_voltage_drop_return are only for DC Scale UHC4T and DC Scale XPS256.
  • Parameters current_filter_frequency and voltage_filter_frequency are only for DC Scale XPS256.

If any DPS pins are not listed within an equation set, a warning is issued and the default setting is used.

No check is made that the units of all specs used in expression are compatible with each other or that they have been scaled correctly. It is up to the user to ensure that the expression is defined correctly.
