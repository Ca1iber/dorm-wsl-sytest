DSP_SOLVE_EQUATION

The DSP_SOLVE_EQUATION API can be used to solve an equation system of the form A*x=b.

Syntax

DSP_SOLVE_EQUATION (DOUBLE *a, const INT m, const INT n, DOUBLE *b, DOUBLE *result, const INT nrhs=1)

Where, a, b, and result are pointers to double arrays that are used to solve the equation system A*x=b (note that A is a in the syntax above). In which:

  • A (a in the syntax above) is an m*n matrix with m rows and n columns
  • x is a column vector with n entries
  • b is a column vector with m entries
Note The pointer starts with the data from the first row, followed by the 2nd row and so on.

Example

Fitting a sine waveform using DSP_SOLVE_EQUATION

To fit a sine waveform, the following equation system needs to be solved:

b = x0*1 + x1*sin(2*PI*f*t) + x2*cos(2*PI*f*t)

Using the DSP_SOLVE_EQUATION function to solve this equation system corresponds to:

  • b containing the m waveform samples
  • n equals three for the three unknowns (x0, x1, and x2)
  • result is the pointer to the result. This is a return value which contains the three unknowns. Namely: the dc offset x0, the sine wave amplitude x1, and the cosine wave amplitude x2.
  • a containing the coefficients at all capture times. If the waveform contains N samples, a contains N times the value 1.0, followed by sin( 2.0 * M_PI * double * frequency); for all i from 0 to i<N and then cos( 2.0 * M_PI * double * frequency); for all i from 0 to i<N.

Finally, the phase of the sine waveform can then be determined by invoking atan2(result[2],result[1]).
