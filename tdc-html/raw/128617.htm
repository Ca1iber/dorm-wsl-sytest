Miscellaneous test method snippets

These test method snippets are included in the file /opt/hp93000/soc/segements/tml/testmethodSnipptets.xml.

  • V93000_Miscellaneous_AddNewUTMClass

This snippet allows you to include more than UTM classes in one .cpp file. You just need to insert this template after the existing test method class and enter your code in the corresponding functions.

  • V93000_Miscellaneous_AddParameter

This snippet helps you to add a new parameter to the test method.

Functional changes

  1. Introduced in SmarTest 7.1.3
