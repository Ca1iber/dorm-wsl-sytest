UDVP - (UnDefine Virtual Pin)

The UDVP command removes a defined virtual pin or list of virtual pins from the current configuration.

UDVP

UDVP (pinlist)

Parameters

pinlist

The names of the pins to undefine. The @ symbol can be used to undefine all pins that were previously defined by the VPIN command.

Application

Managing virtual pins, see Virtual pins.

Errors

An error occurs if:

  • The specified pin is not a virtual pin.
  • The specified pin has not been defined.

Example

  1. To undefine a virtual pin:
    > UDVP (VPIN1)
  2. To undefine multiple virtual pins:
    > UDVP (VPIN2,VPIN3)
  3. To undefine all virtual pins:
    > UDVP (@)

Related information

Functional changes
