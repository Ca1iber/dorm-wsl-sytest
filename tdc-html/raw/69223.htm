The configuration for probers

The following conventions are used for naming the configuration files:

<model>-<ifc>-<ctrl>-<probes>-<die>[-<misc>].cfg

<model>

Model name or configuration group.

 

TEL probers:

 

20S

1007, 1011, and 20S probers

 

78S

1200, 1201, 1220, 78S, 80S, and 80W probers

 

P8

All P-8 models

 

Electroglas probers:

 

2001

Prober Vision 2001, 2010, 3001, and 4085 probers

 

4080

Commander Series 4060, 4080, and 4090 probers

 

TSK probers:

 

Generic

All TSK probers

<ifc>

Interface type.

 

GPIB

GPIB interface is supported.

<ctrl>

Defines how the stepping is controlled.

 

smartest

SmarTest controls the stepping.

 

prober

Prober controls the stepping.

 

learnlist

LearnList controls the stepping, (Only available for Electroglas probers).

<probes>

Number of probes/sites.

<die>

Indicates if sub-die probing is supported.

 

die

Subdie testing is not supported.

 

subdie

Subdie testing is supported.

<misc>

Additional information, such as if the configuration file is for debugging.

Example

If you have a TEL 1007 prober (configuration group 20S), you will use SmarTest to control the stepping, and you have two sites, you need the following configuration file:

20S-GPIB-SmarTest-2.cfg

You will need a standard GPIB cable for the connection. Make sure you follow the general rules for GPIB connections, as described in Communication with a GPIB interface.
