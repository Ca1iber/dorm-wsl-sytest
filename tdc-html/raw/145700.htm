setCCExecuteStatus()

Let the concurrent test framework know the result of the test suite.

Call setCCExecuteStatus() in the CCTestMethodEx::process() function when you want to execute the fail branch of the test suite in the concurrent test framework.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethodEx.hpp.

Syntax

void setCCExecuteStatus(CCExecuteStatus status);
Parameter

Parameter

Description

status

The test result of the native test suite in the concurrent execution. It can be: CCT_EXECUTE_STATUS_FAIL representing the failing of the test suite

CCT_EXECUTE_STATUS_PASS representing the pass of the test suite

Return value

There is no return value.

Example

setCCExecuteStatus(CCT_EXECUTE_STATUS_PASS);

Related information

How to handle the fail branch with concurrent test framework
