Deleting a Spec/Variable

  1. From within the Timing or Level Setup, click edit equations in the Select pulldown menu.
  2. Locate the spec you wish to delete and if it is used as part of an evaluation elsewhere in the equation set, replace it with a fixed value.
  3. Download these settings to firmware.

    These last two manoeuvres represent an initial debugging check; provided they do not reveal errors (in the report window) you can continue in deleting the variables.

  4. If errors are revealed at this stage, repeat steps 2 and 3 with another value that does not yield errors.
  5. Delete the spec and download the new settings to hardware.
  6. In the Spec Tool main window, click Upload in the File pulldown menu.

    The error report window (see Error Checking Facilities) appears, indicating that the spec is unknown.

  7. Delete each of the references to the spec, and click done when finished.
  8. Download these new settings to firmware.

Functional changes

  1. Introduced before SmarTest 6.3.2
