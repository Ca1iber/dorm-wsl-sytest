EVENT_ICIM.iClampLow()

Sets the low clamp current value.

You can specify both the low and high clamp current values or just one.

Syntax

EVENT_ICIM & iClampLow  (const EVENT_VALUE_DOUBLE & value );
Parameter
Parameter Description
value

Low clamp current

Return value

There is no return value.

Example

For an example see EVENT_ICIM.

Related information
