getPassFail()

Retrieves the pass/fail result of a protocol test.

When you use this function to retrieve the pass/fail result, you must have already used the function readExpect() in the test.

If the result is pass, 1 is returned. If the result is fail, 0 is returned.

Syntax

int getPassFail();

Example

int result = rdi.id("protocol_1").getPassFail();

Functional changes

  1. Introduced in SmartRDI 2.1.0
