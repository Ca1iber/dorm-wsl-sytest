SmartShell

SmartShell is an external scripting interface for SmarTest that allows external tools (for example, EDA tools or shell scripts) to control the test execution and receive the test results back.

SmartShell consists of a network-capable server component that can control a running instance of SmarTest and modify settings and parameters.

The server is accessed either through simple APIs that can be used from external applications such as EDA software, or from user scripts (for example, written in Python). It can also be used interactively through a text-based terminal interface.
