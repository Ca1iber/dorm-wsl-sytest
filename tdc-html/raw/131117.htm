Error map for Smart Scale cards

There is an error map size difference between previous Pin Scale cards and newer Pin Scale cards of the Smart Scale generation (PS1600, PS9G).

On previous Pin Scale cards, the size of the internal error map (DCRT TP) is 16384 bits. For Smart Scale generation channel cards, the size is 65536 bits. The number of cycles that fit into the error map (in Acquire All mode, DCGM ALL) depends on the selected X mode and the number of bits stored per result:

  • numberOfCycles = errorMapSizeInBits / (xMode * bitsPerResult)

For example, in X1 PFC mode (2 bits/result), Pin Scale cards can store 8192 cycles, Smart Scale generation cards can store 32768 cycles. In X8 mode (1 bit/result), Pin Scale cards can store 2048 cycles, Smart Scale generation cards 8192 cycles. The size of the external error map (DCRT RAM) is not fixed and always depends on the amount of available RAM, for both Pin Scale and Smart Scale generation cards.

Storage limitations

To get result information on all fails on the edge level, you usually put the detailed Error Map into the external memory, which provides more space than the internal error map. But the amount of edge data can become too large for the bandwidth of the memory if

  • all channels of an 8-channel group or 4-channel group (Channel groups of Smart Scale cards) are associated with O or IO pins of such a port, and
  • the tester cycle is very short.

In this case recording will be aborted. For measures against such a recording abort see Dealing with storage issues on Smart Scale systems.

Error code resolution and result granularity

There are mutual dependencies between the error code resolution and result granularity. Furthermore, these dependencies vary for the different channel cards. In particular, there are combinations of recording mode and result granularity for which only one error code resolution is available on certain systems. For details see Recording parameters and Possible combinations of CYRM, CYRP, and DCRM.
