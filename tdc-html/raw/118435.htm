Topic 118435

Adapting the org file

This topic describes how to adapt the org file to the user's environment before using the operator console.

About this task

Before you can use the operator console, you must adapt the org file at /etc/opt/hp93000/soc/ according to your environment.

Procedure

  1. 1st line: Add the character # at the beginning.
  2. 2nd line: Delete the character # and change the path from /tmp to /home/<user name>.
  3. 3rd line: Delete the character # and add /home/<user name>: before the entry /users/demo:/tmp.

    Line

    Old

    Modified

    1

    DUT_PATH /tmp

    # DUT_PATH /tmp

    2

    # INSTALLED_DUT_PATH /tmp

    INSTALLED_DUT_PATH /home/<user name>

    3

    # WORKORDER_PATH /users/demo:/tmp

    WORKORDER_PATH /home/<user name>:/users/demo:/tmp
