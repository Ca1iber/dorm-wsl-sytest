DRLScanInstanceDescriptorAttr

A variable of this type holds the description of a scan instance. The variable is used in DRLScanInstanceListAttr.

Syntax

typedef struct _DRLScanInstanceDescriptor {
  int id;
  const char *name;
  int label_id;
  const char* label;
  long long start_cycle;
  long long end_cycle;
} *DRLScanInstanceDescriptor;
