Index Operator

A new index operator lets you access individual bits of an expression directly in the progam file and the device access file. For example, myVar[2] accesses the second bit of the value in the myVar variable.

Benefit

The index operator makes it unnecessary to use bit-shifting for accessing individual bits. This makes programming easier and results in more readable code.

More Info

For further details, see Index operator.
