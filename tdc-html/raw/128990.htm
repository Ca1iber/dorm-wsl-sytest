MTP_MEMORY_TEST.setFailListStyle()

The setFailListStyle() member function of MTP_MEMORY_TEST lets you specify whether a single bit fail map is created for all failures, or whether two separate bit fail maps are generated for results where 0 was expected and results where 1 was expected, respectively.

This is an optional method. It has an effect only if the generation of bit fail maps is enabled through setImmediateBitmapToFile().

Syntax

MTP_MEMORY_TEST& setFailListStyle(const MTP::FAILLIST_TYPE mode)

Parameter

Description

mode

Whether one or two bit fail maps are generated:

  • MTP::PASS_FAIL_ONLY: One bit fail map is generated for all results, irrespective of whether a 0 or 1 was expected.
  • MTP::FAIL_FOR_0_1: Two bit fail maps are generated - one containing all results where a 0 was expected and another containing all results where a 1 was expected. The file are named "Failed_for0" and "Failed_for1", respectively.

The default is MTP::PASS_FAIL_ONLY.

Example

Setting the test method to generate two bit fail map files:

MTP_MEMORY_TEST memoryTest();
memoryTest.setFailListStyle(MTP::FAIL_FOR_0_1);
