Topic 145033

UNSOLICITED_EVENT_ITERATOR

Returns the unsolicited events of a serial link test after completion of the test. It is intended to simplify looping over all existing unsolicited events. In fact, it provides the only way to access the unsolicited events. This iterator is generated by the getUnsolicitedEvents() function of the SERIAL_LINK_TEST class.

Note Iterator objects can become invalid if the protocol test they were created from is executed again.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/UnsolicitedEventIterator.h.

Syntax

Boolean hasNext();
UNSOLICITED_EVENT& next();

Member functions

hasNext()

Boolean hasNext();

This function indicates whether all unsolicited events of the specified type(s) have already been looped over.

If the return value is

  • TRUE, the next call to function next() will return another valid unsolicited event.
  • FALSE, the iterator either points to the last unsolicited event or has become invalid by another execution of the associated serial link test.

next()

UNSOLICITED_EVENT& next();

Returns the next unsolicited event of the specified type(s).

Note This function must only be called if function hasNext() returned TRUE and the iterator was not invalidated by another test execution in the meantime.

Example

The following code snippet shows how unsolicited events must be processed:

if (test.hasUnsolicitedEvents())
    {
      UNSOLICITED_EVENT_ITERATOR eventIter = test.getUnsolicitedEvents();
      while (eventIter.hasNext())
      {
        UNSOLICITED_EVENT event = eventIter.next();

        try
        {
          event.dump();
        }
        catch (Error& error)
        {
          error.print();
        }
      }
    }
