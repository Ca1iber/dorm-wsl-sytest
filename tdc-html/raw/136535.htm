Overlaying shmoo tests in the Shmoo Tool

In the Shmoo Tool, to overlay shmoo plots, use the Overlay command in the bottom bar of the shmoo editor.

Before you begin

  1. Create shmoo tests in the Shmoo Tool. Or, transfer shmoo test suites to the Shmoo Tool.
  2. Execute these shmoo tests in the Shmoo Tool.

Procedure

  1. In the shmoo editor, right-click the bottom bar and select Overlay.

    The Overlay window opens:

  2. In the Overlay Name field, enter a name for a new shmoo page to display an overlay shmoo plot.
  3. In the Overlay Title field, give a title for the overlay shmoo plot.
  4. In this window, select the shmoo tests you want to overlay.

    You can overlay shmoo plots (represented by shmoo page names) of different sites different pins.

    • To overlay shmoo plots of different pins, you must enable perPinResultwhen setting.
    • To overlay shmoo plot of different sites, you must enable multiple sites before executing the shmoo tests.
    • Error message will show up if the selected the shmoo tests have different steps, or have no common Test modes.
  5. In the Test Mode field, select the test mode for overlay.

    This box:

    • Becomes available only after you have selected the shmoo tests in step 4.
    • Lists only the common test modes among the selected shmoo tests.
  6. In the Calculate Type field, select the type for the result to be displayed on the overlay shmoo plot. This box becomes available only after you have selected the shmoo tests in step 4

    The available types are:

    • percentage: Displays the percentage of pass tests on each cell on the overlay plot if you have selected pass/fail in step 5.
    • max: Displays the maximum number or the maximum measured value on each cell on the overlay plot.
    • mean: Displays the average number or the average measured value on each cell on the overlay plot.
    • min: Displays the minimum number or the minimum measured value on each cell on the overlay plot.
    • sum: Displays the total numbers on each cell on the overlay plot.
  7. Click OK.

Results

  • An overlay shmoo plot is generated on a new shmoo page in the shmoo editor.

    Different cells may have different colors. See Colors on shmoo plots.

  • The Properties view for the overlay shmoo page displays the configurations for this overlay, such as the name of each shmoo test, the test modes for overlay, and the calculation types.

What to do next

You can:

  • Overlay another shmoo plot on the current overlay plot.

    To do this, use the AddToOverlay command in the bottom bar of the shmoo editor.

  • Zoom, or take a picture of the overlay shmoo plot.
