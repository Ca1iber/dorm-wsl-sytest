DRLPinGroupIndexToName

const char *DRLPinGroupIndexToName (unsigned short index)

This function allows mapping of a pin group index (0 ... DRLNumberOfPinGroups()-1) to a pin group name to regain the name of the pin group. With this function, for example, you can obtain a list of all configured pin groups by simply passing all pin group DC/DC power units with a loop.

Return Value

The function returns the name of the pin group with the index index.

In the case of an invalid index, the function returns NULL.

Functional changes

  1. Introduced before SmarTest 6.3.2
