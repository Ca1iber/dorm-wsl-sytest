Topic 141299

vMeas()

Measures voltage on pins.

Before SmartRDI 2.3.0, the vMeas() function and its force current must be set in the same line. Otherwise, vMeas() will use iForce(0) for measurement.

In SmartRDI 2.3.0, if the force current has already been set up, setting up vMeas() in a different line will still use this force current. In SmartRDI 2.3.0, to keep the behavior in SmartRDI 2.2.0, in the configuration file set PPMU_PURE_VMEAS_2P2_COMPATIBLE_MODE to TRUE.

Note When you use this function on multiports, if the following measurement conditions exist:
  • valueMode() is set to BADC (the default value since SmartRDI 2.5.0 ).
  • Pins from different ports share the same BADC.

You must use rdi.portSync() to ensure the sequence of pins' access to the BADC is correct.

For accuracy considerations, refer to the number of samples for voltage measurement in BADC_PIN_MEASURE.

Syntax

vMeas();

Examples

Example 1

The setup before SmartRDI 2.3.0

RDI_BEGIN();
  rdi.dc("vMeas").pin("pinA").iForce(1 mA).execute();
  rdi.dc("vMeas").pin("pinA").vMeas().execute(); // Use iForce(0) here but not iForce(1 mA).
RDI_END();

Example 2

The setup in SmartRDI 2.3.0

RDI_BEGIN();
  rdi.dc("vMeas").pin("pinA").iForce(1 mA).execute();
  rdi.dc("vMeas").pin("pinA").vMeas().execute(); // Use iForce(1 mA) here.
RDI_END();

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 2.3.0: Supports setting up the force current iForce() and vMeas() in different lines.
  3. SmartRDI 2.3.0: Adds new keyword PPMU_PURE_VMEAS_2P2_COMPATIBLE_MODE to the RDI configuration file.
