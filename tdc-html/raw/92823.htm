DUT Scale interface

Advantest offers several different test head sizes with a common DUT interface to provide DUT board compatibility across all test heads. The DUT Scale interface allows you to fully use the large DUT board on all V93000 test head types.

However, the number of groups in this case is 4:

Note The LTH DUT interface supports the use of large and small DUT boards.

The POGOCABLING section in the model file of SmarTest 7 and the CARD_CONFIGURATION section in the tester.model file of SmarTest 8 maps the physical position of a card with the pogo block numbering of the DUT interface. The mapping of pogo blocks to card slots is explained in Pogo mapping for SmarTest 7 and in the corresponding topic for SmarTest 8.
