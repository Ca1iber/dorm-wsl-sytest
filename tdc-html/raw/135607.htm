Topic 135607

Generating a pattern with PPSG

Subtopics

  1. PPSG parameters

A pattern is generated with the Per-Pin Signal Generator (PPSG) by entering the desired parameters in the tool's window and clicking OK.

About this task

Generate a pattern with the PPSG when you want to simulate an analog signal over a digital pin.

Note that the meanings of the various parameters are explained only briefly below. You can find more extensive descriptions in PPSG parameters.

Wherever a value has a unit, you can change the unit by clicking it. Each unit display is a button, clicking which cycles through the available units.

Before you begin

Start the PPSG.

Procedure

  1. Specify the desired channel settings in the Digital Channel Settings section of the window:
    • Digital Channel Selection: The type of card you want to use.
    • Signal Mode: Whether you want to create a single-ended or a differential signal.
    • Pin Name: The pin over which you want to send the signal (optional). In case of differential signals, the positive pin.
    • Negative Pin Name: The negative pin for a differential signal (optional).
    • Port Name: The name of the port to use (optional).
    • Waveform Name: The name of the generated waveform (optional).
  2. Specify the characteristics for the DUT board's low-pass filter in the Filter section of the window:
    • Cut-Off Frequency: The cut-off frequency (500 Hz to 100 MHz) for the filter.
    • Order: The order of the low-pass filter (1 to 10).
    • Series Resistance: The series resistance of the filter (1 Ω to 100 MΩ).
  3. Specify the desired signal characteristics in the Signal section of the window:
    • Waveform Shape: The desired waveform shape.
    • Signal Frequency: The frequency of the generated signal (1 Hz to 50 MHz).
    • Initial Phase: The phase in which the signal starts (-180° to 180°).
    • Signal Periods: The number of signal periods to generate. (The minimum is 1; the maximum is (number of signals - 1) / 6 for triangles or(number of signals - 1) / 3 for ramps).
    • Min. Voltage: The minimum voltage for the generated analog signal.
    • Max. Voltage: The maximum voltage for the generated analog signal.
    • Pre-Waveform Duration: The amount of time in the pattern before the generated signal begins (0 ms to 100 ms).
    • Post-Waveform Duration: The amount of time in the pattern after the generated signal ends (0 ms to 100 ms).
  4. Specify the settings for the device under test in the DUT section of the window:
    • Number of Connected Inputs: The number of devices connected to the pin (1 to 32).
    • Input Impedance: The input impedance of the DUT input (50 Ω to 100 MΩ).
    • Number of Samples: The number of samples the A/D should take (2 to 1,048,576).
    • Sample Rate: The sample rate of the A/D converter on the DUT board.
    • Noise-Reduced Bandwidth: The upper limit of the frequency band in which the noise is reduced by shifting it to higher frequencies. (The lower limit of the band is 10 Hz.)
  5. Click OK.

    If there are invalid entries in any of the fields, an alert will inform you of the problem and no output is generated. In that case, correct the problem and click OK again.

    Note The progress of generating the waveforms is reflected in a progress bar. This bar may not filled smoothly during lengthy calculations, so that you may have the impression that the tool is not progressing for a few minutes. You can find additional progress information in the message view of the Signal Analyzer.

Results

Files

Several files are generated in the <device-name>_PPSG_STIL directory at the same level as the current device directory:

  • A STIL file specifying the pattern according to your settings (<waveform>.stil)
  • A setup file for STIL Reader (<waveform>.setup)
  • A log file (<waveform>.log)

If STIL Reader is installed on your computer and a valid license is available, the pattern is translated automatically by STIL Reader (using the setup file) into a test program containing one test suite. The files are generated in the Dev_<waveform> subdirectory of the directory containing the STIL file.

Note Patterns that are generated with the PPSG can be very large, and it may not be possible to open them with the Pattern Editor. The Pattern Editor will display an error message if you try to open a pattern that is too large.

Signal Analyzer display

The data that the PPSG creates are displayed as vectors and graphically in the Signal Analyzer.

Example

This is a set of sample values for the PPSG; fields not listed are either disabled or no entry is made in them (resulting in the default settings being used):

  • Digital Channel Selection: PS1600
  • Signal Mode: Single ended
  • Cut-Off Frequency: 1.3 kHz
  • Order: 3
  • Series Resistance: 50 Ω
  • Waveform Shape: RampUp
  • Signal Periods: 1
  • Min. Voltage: -1.2999 V
  • Max. Voltage: 6.2999 V
  • Pre-Waveform Duration: 0 ms
  • Post-Waveform Duration: 0 ms
  • Number of Connected Inputs: 1
  • Input Impedance: 50 MΩ
  • Number of Samples: 32k
  • Sample Rate: 200 ksps
  • Noise-Reduced Bandwidth: 100 kHz
