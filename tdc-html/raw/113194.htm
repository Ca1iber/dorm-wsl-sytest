Setting up the testflow for a dynamic DC test

This step of the dynamic DC test setup defines the test suites in the testflow editor and sets the previously defined test methods and primaries.

About this task

Setting up a testflow includes selecting the test methods and the primaries.

Before you begin

Before you can define the test suites in the testflow, the primaries setup and test methods for the dynamic DC test should be complete, and you must have built the test method project.

Procedure

  1. To add test suites to the testflow, in the Test Program Explorer right-click the testflow item, select New.
  2. Type a name for the new testflow, for example, dcdyn_test and click OK.
  3. In the testflow editor open the Palette and click run and branch.
  4. In the New-Run-and-Branch-Node wizard:
    • Type the test suite name: connect
    • Position the cursor in the Test Method field, and press Ctrl+Spacebar to open the test method browser.
    • To select the test method, navigate to your test_method_project_name > DcDynDemoTests , select connect, and click OK.
    • Proceed similarly to select Timing, Level, and Pattern.
  5. To complete the wizard dialog, click Finish. This adds the 'connect' test suite to the testflow.
  6. Proceed similarly to add the 'ramp' and 'disconnect' test suites.
  7. Add the bad bins.
  8. Add the good bin.

Results

The graphic shows the resulting testflow and the properties of the "ramp" test suite.

What to do next
