Topic 103812

Setting up cyclic redundancy checks

Setting up cyclic redundancy checks (CRC) requires defining the settings, activating the desired settings, and accessing the CRC result in the device access file.

About this task

Set up CRCs to quickly check data buses for errors.

Before you begin

Make sure that the pin configuration and pin mapping files are properly set up.

Procedure

  1. Define the CRC settings in the Device architecture file.
    1. Add a :crc: block and name it.
    2. Add a :bitSequence: block for each set of pins from which the CRC is to be calculated.
    3. Add a :bitexpression: block for each way you want to calculate a CRC from a data stream.
    4. Add a :configuration: block for each combination of a bit sequence and a bit expression that you want to use as a argument for the crc macro.

      Repeat steps a through d for each additional group of CRC settings that you want to create.

  2. Specify the desired CRC setting in the APG pattern file by adding the :crc: keyword and the name of the desired CRC setting (from step 1a) to the file.
  3. Apply the crc macro in the :operation: column of every device access where you want to use it. More information on this is available in Macros and functions in device accesses.

Results

When the compiled program is run, cyclic redundancy checks are calculated for the specified buses.

Note Using the crc macro in the :operation: column disables the data column in that :apgAccess: element.

Related information

Functional changes

  2. MTP 3.0.3: (MTP on SOC 103.0.0) Cyclic redundancy checks are now available in both MTP on HSM and MTP on SOC
