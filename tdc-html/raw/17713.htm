Topic 17713

Working with level sets and DPS sets

Subtopics

  1. Setting switching order modes of level sets and DPS sets

You use the following procedures for creating, deleting and editing both DPS sets and Level sets.

Creating a new level set

  1. Click the box
    • Lset #
    • DPSset #
  2. Type the set number in which you want to store your data.

    If the new set number has not been previously defined, the new set will contain the same values as set 1.

  3. To define a new set: Edit the values in set 1 of the Level Setup window.

    The data from set 1 is now also stored under the new set number that you have entered.

Copying a level set

If you want to copy the data from one level set to another level set:

On the menu, click Edit > copy set.

Deleting level sets

If the level setup file that you want to load to hardware contains more level sets than you require for the test, you can delete the unwanted sets.

  1. On the menu, click Edit > delete set
  2. Delete all sets above a given number:

    Type the number of the last set you want to keep.

    delete sets above #

  3. Click delete

Selecting a level specification

On the menu, click Select > Select Specification.

Showing equations and specifications

On the menu , click

  • Select > Show I/O Eqn. & Specs Results
  • Select > Show Fast Eqn. & Specs Results
  • Select > Show DPS Eqn. & Specs Results
