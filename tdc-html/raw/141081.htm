Topic 141081

DIGITAL_OFFSET_SEARCH_PINS.getConfiguration()

Gets the offset search configurations for pins specified with DIGITAL_OFFSET_SEARCH_TASK.pin().

Syntax

void getConfiguration(DIGITAL_OFFSET_SEARCH::DigitalOffsetSearchConfigDataType & configdata);
Parameter

Parameter

Description

configdata

A data used for storing the retrieved configurations, such as search type, resource type, start value, and stop value. See more data type in DigitalOffsetSearchConfigDataType.

Return value

There is no return value.

Related information

DigitalOffsetSearchConfigDataType
DIGITAL_OFFSET_SEARCH_TASK.pin()

Functional changes

  1. Introduced in SmarTest 7.2.1
