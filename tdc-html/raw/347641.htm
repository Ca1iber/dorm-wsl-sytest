Internal Utility Power Option (V93000 EXA Scale systems)

The Internal Utility Power Option can be routed to a 3-row DPS-slot pogo block if maximum one optional Utility card (EK051 or EK051A) is installed. The supply provides compatibility with the legacy SE-UDPS and requires the EK051UP pogo cable assembly.

Configuration
TH: CX / SX / LX
Slots: 9 / 18 / 27
Optional Utility Cards (EK051 and EK051A): = 11)
Total number of supplies 1
Supply routed to pogo block DPS 8 (268)2)
Characteristics
Voltage Accuracy Maximum current Pogo pins
The "Internal Utility Power Option" is routed to a 3-row DPS pogo block. Refer to Internal Utility Power Option pogo pin assignments (V93000 EXA Scale systems) for more information.
+5.0 V, sensed ±2 % 3 A P1, PS1, G1 (two pins)
+12.0 V, sensed ±2 % 1 A P2, PS2, G2 (two pins)
+15.0 V, sensed ±2 % 1 A P3, PS3, G3 (two pins)
-15.0 V, sensed ±2 % 1 A P4, PS4, G4 (two pins)

Functional changes

  1. Introduced in SmarTest 8.3.4
  2. SmarTest 8.4.1: Default pogo block changed from 266 (DPS 1) to 268 (DPS 8).
  3. SmarTest 8.4.3: Support of LX test head of V93000 EXA Scale systems.
1) Maximum one Utility card (EK051 or EK051A) can be installed for accessing the Internal Utility Power Option. The second Utility card occupies the pogo block position that is required for the Internal Utility Power Option.
2) Pogo block DPS 8 (268) is the recommended position as defined in the V93000 Standard Configuration Guidelines.
