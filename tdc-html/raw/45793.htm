TestMaskInequality

Class TestMaskInequality is used to define the test mask area. This class is a member object of class TestMask. A TestMask object can have multiple inequalities.

setTestMaskInequality()

TestMaskInequality & setTestMaskInequality(double a, double b, double c);

This function sets a test mask inequality. Test mask is expressed as ax+by+c > 0.

If the sum of the left side of the inequality is greater than 0 in a point of a trace, the test mask will highlight the point. If you intend to define a more complicated test mask, you can overlay multiple test masks.

Parameters

a

b

c

Parameter of the test mask inequality.

Example

GraphManager * graphManager = GraphManager::getInstance();
Graph graph;
TestMask testMask;
testMask.setTestMaskStyle(false, Display::BLUE);
TestMaskInequality inequality1;
inequality1.setTestMaskInequality(1, 0, 8);
TestMaskInequality inequality2;
inequality2.setTestMaskInequality(-1, 0, 5);
testMask.setInequality(inequality1, 1);
testMask.setInequality(inequality2, 2);
graph.setTestMask(testMask);
graphManager->setGraph(graph, 1);

This example sets the junction among the inequalities to OR and set the test mask color to blue. Then it defines two ineuqlities, x+8>0 and 5-x>0 for the test mask of the graph. If one of the two conditions is met, the points will be highlighted in blue.
