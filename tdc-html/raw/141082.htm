DIGITAL_OFFSET_SEARCH_PINS.getLatestLBTransitionOffset()

Retrieves the offset at the left boundary of the pass area, found in the latest transition search. This offset records the fail-to-pass transition. Before using this function, you must upload the boundary offsets into the workstation with DIGITAL_OFFSET_SEARCH_PINS.uploadLatestTransition().

If you retrieve the offset on multiple pins and the pins have different settings, the exception TESTMETHOD_API::AmbiguityException will be issued.

Syntax

DOUBLE getLatestLBTransitionOffset();

Return value

Returns the offset at the left boundary of the pass area found in the latest transition search:

  • For timing offset searches, the units of the returned values are [s].
  • For level offset searches, the units of the returned values are [V].

If the offset search had been applied on multiple pins, this function only returns the largest offset among these pins' in order to form the smallest eye (a pass area).
