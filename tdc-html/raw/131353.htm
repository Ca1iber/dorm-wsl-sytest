SPMU_PIN_TASK.vForce()

Sets the value of the voltage to be forced and the measurement mode to "VFIM".

Syntax

SPMU_PIN_TASK& vForce(DOUBLE voltage);
Parameter

Parameter

Description

voltage

Forced voltage in Volt.

Return value

A reference to the SPMU_PIN_TASK object.
