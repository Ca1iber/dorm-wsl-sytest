A dynamic analog test example

The example program shown below performs the following steps:

  1. Enables the trigger signal of the digitizer or sampler specified by the input parameter dgtz_pin (pin name), which is entered in the Parameter Dialog.
  2. Performs the measurement by the digitizer or sampler, using the setup data of the primaries.
  3. Computes the total harmonic distortion (THD) and signal-to-noise ratio (SNR) from the measurement data.
  4. Logs the captured analog waveform data with captions.
  5. Performs the judgment on the computation result. 
    ARRAY_D AnaWave;
THDtype thd_result;
DOUBLE sampling_period;
//Enable trigger sigbal for analog module
Routing.pin(dgtz_pin).connect(TM::SINGLE);
Analog.DGT(dgtz_pin).enable();

//Execute a test
EXECUTE_TEST(0.1 sec);

//Disable trigger signal for analog module
Analog.DGT(dgtz_pin).disable();
Routing.pin(dgtz_pin).disconnect();
FLUSH();
.
.
.
//Retrieve measured analog waveform
AnaWave = Analog.DGT(dgtz_pin).getWaveform();

//Get the current sampling frequency
sampling_period = Analog.DGT(dgtz_pin).getConvClock();
//Calculate THD and SNR
DSP_THD(AnaWave,&thd_result,1,3,DB,NULL);

//Setup for logging raw waveform data
WAVE_LOG logwave(AnaWave);
logwave.xAxis(0.0,1023.0*sampling_period);
logwave.xTitle("Time");
logwave.xUnit("sec");
logwave.yTitle("Output Voltage");
logwave.yUnit("V");
PUT_DATALOG(dgtz_pin, "AnaWave", logwave);

//Judge THD result
TEST(dgtz_pin,"THD", thd_result.thd,TRUE);

//Judge SNR result
TEST(dgtz_pin, "SNR",thd_result.snr);
