Topic 119586

Editing test method from a testflow

A shortcut menu Open Test Method is provided to open and edit the test method from a testflow.

About this task

The shortcut menu Open Test Method

Before you begin

Make sure you are using SmarTest 6.5.3 or later versions.

Procedure

  1. In the flow data editor, right-click the test method you want to modify and select Open Test Method.
  2. Modify the test method and then build the project.
    • If no error occurs, the test method source file is opened. You can modify the test method and build the project.
    • If some error occurs, an error message or a warning message will be popped up. You need to fix the error or warning first and open the test method again to modify the build the test method. The following messages may be popped up due to different conditions.
