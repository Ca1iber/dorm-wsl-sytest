EVENT_WAVEFORM_VFVM.sampleVectorDistance()

Sets the distance between sample vectors.

Syntax

EVENT_WAVEFORM_VFIM & sampleVectorDistance(INT vectors);
Parameter
Parameter Description
vectors

Number of vectors defining the distance. Minimum is 32 vectors.

Return value

A reference to the corresponding EVENT_WAVEFORM_VFVM object.

Example

For an example see EVENT_WAVEFORM_VFVM.

Related information

EVENT_WAVEFORM_VFVM

Functional changes

  1. Introduced in SmarTest 6.5.2
