MTP_ADDRESS_FILTER.setRange()

This member function sets the address range for an address filter.

Syntax

MTP_ADDRESS_FILTER& setRange(const MTP::ADDRESS_DIMENSION dimension, const long start, const long stop);
Parameters

Parameter

Description

dimension

The X, Y or Z dimension. See the options in the table below.

start

The start address in the specified dimension.

stop

The stop address in the specified dimension.
Available options of parameter: dimension

Option

Description

MTP::X_ADDRESS

The X dimension.

MTP::Y_ADDRESS

The Y dimension.

MTP::Z_ADDRESS

The Z dimension.
Note If you do not specify an address range for a specific dimension, by default, all addresses in this dimension are used by the filter. The filter will set or exclude these addresses to generate memory test results through setting MTP_ADDRESS_FILTER.setMode().

Return value

There is no return value.

Example

MTP_ADDRESS_FILTER filter;
filter.setRange(MTP::X_ADDRESS,0,1024);
filter.setRange(MTP::Y_ADDRESS,1024,2048);

Related information

MTP_ADDRESS_FILTER.setMode()

Functional changes

  1. Introduced in MTP 3.1.6
