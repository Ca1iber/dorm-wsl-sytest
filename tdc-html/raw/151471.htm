rdi.smartVec().vecEditMode()

Specifies a mode for editing the vector at runtime.

SmartRDI supports two modes for vector editing at runtime: VECD firmware command and VEC_TRANSFER_TASK (VTT) API. Generally, you can select either VECD or VTT for the VEC_EDIT_MODE keyword in the RDI_Configure file for editing all the vectors.

This function allows you to select one mode for one pattern while another mode for another pattern in the code level. See the Example 1.

When copyLabel() is used and different vectors in the same label are to be edited, only the VTT mode can be used to edit vectors. See the Example 3.

Syntax

rdi.smartVec().vecEditMode(TA::Mode);
List of parameters

Parameter

Description

TA::Mode

The mode to be used for one piece of pattern.
List of available options of parameter: <TA::Mode>

Option

Description

TA::VECD

The VECD firmware command mode, which calls the VECD FW command for vector editing.

TA::VTT

The VEC_TRANSFER_TASK API mode.

Examples

Example 1

To change the edit mode across RDI_BEGIN()/RDI_END() blocks:

rdi.smartVec().vecEditMode(TA::VECD);
RDI_BEGIN();
   ...
   rdi.smartVec() ... execute(); // Runtime editing
   ...
RDI_END();

rdi.smartVec().vecEditMode(TA::VTT);
RDI_BEGIN();
   ...
   rdi.smartVec() ... execute(); // Runtime editing
   ...
RDI_END();

Example 2

To change edit mode inside the RDI_BEGIN()/RDI_END() block: 

RDI_BEGIN();
    rdi.smartVec().vecEditMode(TA::VECD);
    rdi.smartVec()...;// run-time edit
    rdi.smartVec().vecEditMode(TA::VTT);
    rdi.smartVec()...;// run-time edit
RDI_END();

Example 3

Use only the VTT mode for editing vectors when copyLabel() is used for the label.
rdi.smartVec().vecEditMode(TA::VTT);

RDI_BEGIN();
  rdi.smartVec().label("sLabel").copyLabel(false).pin(A)
                                .writeData("rt",8,0).execute();
  rdi.smartVec().label("sLabel").copyLabel(false).pin(A)
                                .writeData("rt",8,8).execute(); // a different position
RDI_END();
