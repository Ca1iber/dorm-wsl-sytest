Topic 143933

disconnect()

Opens the Force/Sense relay of a DC Scale pin. It works for the pins in the DPS operating mode or in the PMU (SIG) operating mode.

This function is used only in the code‑based mode.

Syntax

dcBase& disconnect();
dcBase& disconnect(min, max);
List of parameters

Parameter

Description

min
The minimum value of the biggest iRange for ganged pins.1)

max

The maximum value of the biggest iRange for ganged pins.1)

Return Value

A reference to the dcBase object.

Examples

Example 1

rdi.dc().pin("pinA").disconnect().execute();

Example 2

rdi.dc().pin("DPS128_SIG_GANG").disconnect(-400 mA, 400 mA).execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 2.4.4: Adds disconnect(min, max) for ganged pins to avoid warning message.
1) The static RDI command .disconnect() for DCS SIG pins sets the smallest iRange and sets the min/max values according to that range. However for ganged pins, .disconnect() always has to use the biggest iRange and set the min/max values accordingly. SmarTest will issues the warning message
Clamp current limit is smaller than minimum value and will be auto-corrected.
In SmartRDI 2.4.4, disconnect(min, max) allows to set the minimum and maximum values for the clamp on the ganged pins to avoid the warning. See Example 2 above for code example.
