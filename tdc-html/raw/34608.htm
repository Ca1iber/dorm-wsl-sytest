Topic 34608

Appendix A: Event Formatter Files

Subtopics

  1. Files explanations

This appendix contains a short description of the contents and the functions of all files in the /opt/hp93000/soc/formatter/EventFormatter directory.

These files are used to build the Event Formatter, which is provided with SmarTest as the standard event-based report formatter. The Event Formatter fully uses the capabilities of event data logging and writes the retrieved data to the report window. For further information on this formatter see Using the Event Formatter.

For further information on the contents of the files, see also the comments contained in each file.

Functional changes

  1. Introduced before SmarTest 6.3.2
