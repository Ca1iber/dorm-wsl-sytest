TIMING_OFFSET_SEARCH_PINS.transitionDetection()

This function sets the transition detection type of the search.

Syntax

TIMING_OFFSET_SEARCH_PINS& transitionDetection (TIMING_OFFSET_SEARCH::TR_DETECTION_TYPE detectiontype);
Parameter

detectiontype

The transition detection type. It can be:

  • TIMING_OFFSET_SEARCH::PF: pass/fail transition.
  • TIMING_OFFSET_SEARCH::ECL: using the specified error count limit to judge whether a test is pass or fail. If the error count larger than the limit, it is considered as fail. Otherwise, it is considered as pass.

Functional changes

  1. Introduced in SmarTest 7.0.1
  2. SmarTest 7.1.0: New transition detection type TIMING_OFFSET_SEARCH::ECL.
