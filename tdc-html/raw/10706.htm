Values Definition Type

FreqList and PowerList Values

Used to define the values of a list. Where:

x1 x2 x3.......xn (separated by spaces)

x1, x2, x3,......xn (are double values).

DDEF "A",SET,"Values","1.0e9 2.0e9 3"

List A is 1.0e9 2.0e9 3.0e9

Hex32List Values

DDEF "A",SET,"Values","0x55555555 0x12345abc" where A is a Hex32List, List A will be 55555555 12345abc

Functional changes
