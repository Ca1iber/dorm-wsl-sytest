Topic 118159

Converting MTP testflows to UTM

Testflows written with classic test methods must be converted before they can be used in MTP 3.0, as described in convertTestflow.

Procedure

  1. Convert all user-written test methods used in the testflow to UTM as described in How to convert a classic test method project to universal test method project.
  2. Convert the testflow itself using the procedure described in How to convert a classic testflow to universal-test-method-based testflow. However, instead of the convertTestflow tool at /opt/hp93000/soc/testmethod/bin, use the convertTestflow tool at /opt/93000mts/mts/utilities/bin.

Functional changes

  1. Introduced in MTP 3.0.1
