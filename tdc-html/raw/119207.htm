RF Trace Verification

Trace Verification (TV) Calibration measures and calculates data at the same frequencies and on the same paths as those used for trace verification. Trace verification cannot be run until TV calibration has been run.

TV calibration is not an "individual" calibration type - it consists of:

  • Stim/Receiver Calibration
  • IQ calibration
  • Noise Figure Calibration
  • IF Flatness Calibration
