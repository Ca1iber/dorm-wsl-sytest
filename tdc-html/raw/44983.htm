Topic 44983

Software Updates

Subtopics

  1. Command Set Dependencies
  2. Ci Dependencies

This chapter contains information needed if you make an update to the software.

After any software updates on the Command Interface, call mk_all_ci_u command. Use make clean all on every user Command Set where a makefile exists.

Note that after a software update, all Command Sets belong to root. After the update, use the chown or chgrp commands to change the owner or group as necessary.
