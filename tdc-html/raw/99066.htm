RVCU - (Remove Vector variable Configuration Usage)

The RVCU (Remove Vector variable Configuration Usage) command is used to remove an existing vector variable configuration usage. The combination of label name, VVC name, and vector offset is used to identify the unique usage to be removed. When removed, vectors will be removed in the DSRC label if they are not referenced by any other usage.

Syntax

RVCU {label name}, {VVC name}, vector offset

Parameters

label name

Name of the label for which usage is to be modified.

VVC name

Name of the vector variable configuration. Refer to DVVC, DVVC? - (Define Vector Variable Configuration) for more information.

Vector offset

This is the offset in the label where usage needs to be modified. Vector offset is the logical vector number in the label. A usage with this combination of parameters {label name, VVC name, Vector offset} should already exist in the system as defined by DVCU. Refer to DVCU, DVCU? - (Define Vector variable Configuration Usage).

Application

Digital source memory

Errors

An error message is generated if the usage does not exist with the combination of label, VVC and offset.

Example

The following example removes the usage defined for label "src" using VVC "AC97" at offset 0.

> RVCU "src","AC97",0

Functional changes

  1. Introduced before SmarTest 6.3.2
