Test table editor reference

In this view, you can edit test tables, especially TMLimits tables.

Double-click a cell to edit is content or use the shortcut menu:

  • Add Row: Add a new row (test)
  • Delete Rows: Delete the selected rows
  • Add Column: Add a column (field)
  • Delete Columns: Delete the selected columns
  • Test Numbering Preferences: Specify numbering settings
  • Generate Test Numbers: Generate new test numbers in selected cells
  • Clear Test Numbers: Remove test numbers from selected cells

The other commands are standard Eclipse commands.
