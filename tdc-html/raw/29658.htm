Topic 29658

PUT_DEBUG

Subtopics

  1. FORMAT_GRAPH class

Passes the specified array data or WAVE_LOG/SCATTER_LOG/Wave API's class object (array data with captions) to the signal analyzer if the debug_analog testflow flag is on.

Two array parameters ( xseries and yseries) can be passed to the signal analyzer to put different data to the x and y axis.

Two traces of ARRAY_COMPLEX and Wave<COMPLEX> data are displayed in one graph in the signal analyzer.

You can specify the way a graph is shown with the use of an object of the FORMAT_GRAPH class. First, you have to create the object and assign the desired parameters to it. The object is then appended as the last parameter to PUT_DEBUG API. See example 6 below.

Note This API works only for the single site in focus which has been set in the site control window.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Parameters

I/O

Parameter

Description / Range

I

pin

The pin name to identify the array data.

The pin name is used with label to specify the data in the Signal Analyzer.

I

label

The label to identify the array data.

The label is used with pin to specify the data in the Signal Analyzer.

You can use the same label to several different pins.

I

waveform

The array data or WAVE_LOG API's class object to be passed to the Signal Analyzer. This data is always handled as the x-axis data.

I

def

It returns the pin name of the analog measurement. The pin name is used with label to specify the data in the Signal Analyzer.

I

xydata

The SCATTER_LOG API's class object to be passed to the Signal Analyzer.

I

xseries

The array data to be passed as the x-axis data to the Signal Analyzer.

I

yseries

The array data to be passed as the y-axis data to the Signal Analyzer.

I

colors

The array data defines the color of each point of the graph displayed in the signal analyzer. It can only be used in the scattered graph display. The value can be:

TM::BLACK, TM::BLUE, TM::CYAN, TM::DARK_GRAY, TM::GRAY, TM::LIGHT_GRAY, TM::GREEN, TM::MAGENTA, TM::ORANGE, TM::PINK, TM::RED, TM::YELLOW or TM::WHITE.

I

demod

The DEMODULATION API's class object to be passed to the Signal Analyzer.

I

graphSelect

The style of the graph.

Using a DEMODULATION object, the valid values of the graphSelect parameter are:

  • TM::CONSTELLATION: plots the constellation points of a demodulation
  • TM::COMPOSITE: plots the composite error of a demodulation
  • TM::EVM_VS_SYMBOL: plots the EVM (Y-Axis) versus the Symbol Number (X-Axis)
  • TM::ALL_GRAPHS: plots all graphs available for the object
  • TM::ERROR_VECTOR_SPECTRUM: plots the EVM (Y-Axis) versus Frequency Offset (X-Axis)
  • TM::ERROR_VECTOR_TIME: plots the EVM (Y-Axis) versus Time (X-Axis)

I

sampleUnit

The unit of the sampling frequency.

I

sampleValue

The sampling frequency.

I

wave

The waveform to display

I

formatGraph

An object of the FORMAT_GRAPH class to which the different parameters to specify how a graph is shown are appended.

Example

  1. ARRAY_D wave_array;
PUT_DEBUG("Aout", "AnaWave", wave_array);

    The PUT_DEBUG API passes the wave_array data to the Signal Analyzer. The pin name and label are used to specify the data in the Signal Analyzer.

  2. ARRAY_D wave_array;
double sampling_period;
WAVE_LOG log_obj(wave_array);
log_obj.xAxis(0.0, 1023.0*sampling_period);
log_obj.xTitle("Time");
log_obj.xUnit("sec");
log_obj.yTitle("Output Voltage");
log_obj.yUnit("V");

PUT_DEBUG("Aout", "AnaWave", log_obj);

    The WAVE_LOG API creates the object log_obj that contains the wave_array data and captions such as the x-axis data, the title of the x-axis, the unit of the x-axis, the title of the y-axis, and the unit of the y-axis. Then the PUT_DEBUG API passes this log_obj data to the Signal Analyzer.

  3. ARRAY_D x_array,y_array;
PUT_DEBUG("Aout", "freq_domain", x_array, y_array);

    The PUT_DEBUG API passes the x and y axis arrays x_array and y_array to the Signal Analyzer. The pin name and label are used to specify the data in the Signal Analyzer.

  4. ARRAY_D timeArray, voltageArray;
SCATTER_LOG log_obj;
log_obj.xAxis(timeArray);
log_obj.xTitle("Time");
log_obj.xUnit("sec");
log_obj.yAxis(voltageArray);
log_obj.yTitle("Output Voltage");
log_obj.yUnit("V");

PUT_DEBUG("Aout", "ScatterWave", log_obj);

    The SCATTER_LOG API creates the object log_obj that contains the scattered data and captions. The variable timeArray holds the data array for x-axis and the variable voltageArray holds the data array for y-axis. Then the PUT_DEBUG API passes this log_obj data to the Signal Analyzer.

  5. Wave<DOUBLE> wave(1024, 1.0);
STRING pin = "Aout";
STRING label = "label";
DGT(pin).getWaveform(wave); 
PUT_DEBUG(pin, label, wave);

    This example creates the object wave that stores the waveform and pass the waveform to Signal Analyzer.

  6. Char *pin;
Char *label;
Array_I waveform;
FORMAT_GRAPH formatGraph;
formatGraph.setBackgroundColor (Display::GRAY);
PUT_DEBUG(pin, label, waveform, &formatGraph);

    This example creates the object formatGraph of FORMAT_GRAPH class. The background color is changed into GRAY using setBackgroundColor function. The object is then passed as the last parameter in the PUT_DEBUG API. For more information see FORMAT_GRAPH class.
