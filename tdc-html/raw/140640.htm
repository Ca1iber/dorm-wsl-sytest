DPS128 / DPS64 specific setup tasks

DPS128 in the model file

For more information, refer to DPS128 and DPS64 pogo cabling and model file configuration.

Pin configuration

The pin configuration of channel-slot DC Scale cards is slightly different to that of a DPS-slot device power supply.

To configure a DC Scale pin for DPS operating mode you must specify the pin type as DPS+. For details see DC Scale pin (DPS mode) setup.

Multisite setup

In case of a multisite setup you must strictly differentiate between high-current (HC) and high-voltage (HV) channels. The same device pin on the various sites must be allocated to a channel of the same type (HC or HV). A device pin cannot be an HV pin on one site and an HC pin on another site.

Multiport setup

The total channel memory of DPS128/DPS64 cards is 28 MB. If you run out of available channel memory, it is recommended to use a separate port for the DPS128/DPS64. For details see Typical issues when converting to DPS128 .

The minimum period for DPS128/DPS64 is 20 ns. In case of period incompatibilities in a test program, it is recommended to use a separate timing port for the DPS128/DPS64. For details see Typical issues when converting to DPS128 .

For further details see also Minimum period / maximum frequency of the sequencer.

DC Scale Limits

DC Scale Limits is a safety feature for the DC Scale power supply cards. The limits cannot be exceeded. If the voltage or current is too high or too low, an error message is triggered. See also Setting DC Scale voltage and current limits.

Level Setup tool

The Level Setup tool displays the currently active DPSPINS resource settings of the DC Scale card as follows:

  • Force voltage (vout)
  • Clamp current (ilimit)
    • Source current limit (ilimit_source) (see also below)
    • Sink current limit (ilimit_sink) (see also below)
  • Setup time (t_ms)
  • Off current state (offcurr)
  • Force voltage range (vout_frc_rng)
  • Clamp current range (iout_clamp_rng)
  • Constant current check (disable_const_curr_check)
  • Connect state (connect_state)

For a more detailed description see How to read the DPS Setup window.

Different limits for source and sink current

For DC Scale DPS128/DPS64 cards, the maximum source current per card or channel is different to the maximum sink current per card or channel. For the exact values see DPS128 / DPS64 specifications.

To use all features of the power supply card in DPS mode, especially when operating close to the power limits, you must use equations. The following DPSPINS resources were either changed or introduced with the DPS128/DPS64:

ilimit

Sets both the source and the sink current limit

ilimit_source

Sets only the source current limit

ilimit_sink

Sets only the sink current limit

Any specified current limits must be within the current force (clamp) ranges listed in the DPS128 / DPS64 specifications. For DPS128/DPS64 cards, the iout_clamp_rng is rounded up to the next current force (clamp) range. If ilimit falls into this range there is no error or warning if ilimit is larger than the iout_clamp_rng.

For further details see Setting DC Scale voltage and current limits, Level Equations, and DPSPINS resources (also DPSPINS).

Parallel dynamic and static DC actions

The DPS128/DPS64, when starting the sequencer with the SQST RUN firmware command or with the SEQUENCER_STATUS run() member function, cannot execute dynamic and static DC actions in parallel. For measurements during a sequencer run use profiling. Profiling allows to measure in parallel to a dynamic pattern.

Compare event for counted match loops in Pattern editor

The DPS128/DPS64 supports compare events for the last compare vector of counted match loops. In the Properties view of the event you can set the Compare Type to either High or Low. For details see Inserting counted match loops.

Automatic down-ranging

DPS128/DPS64 channels feature automatic down-ranging for current measurements.

Automatic down-ranging means that the current range is automatically changed to the best fit range for the measurement and restored to the original range after the measurement.

Two parameters define whether the automatic down-ranging is performed or not:
  • The force current or clamp current range:
    • Can be set explicitly or (if not defined)
    • is automatically derived from the forced or clamped value.
  • The current measurement range:
    • Can be set explicitly or (if not defined)
    • is automatically derived from the pass/fail thresholds.
Automatic down-ranging is performed only if the current measurement range is lower than the force / clamp current range regardless whether the ranges have been set explicitly or have been selected automatically.

Automatic down-ranging is supported for both code‑based programming using the SPMU_TASK and DPS_TASK test method APIs and the pattern‑based programming using the DC events and is also supported by SmartRDI.

For more information, refer to the DC Scale DPS128/64 HC/HV Cookbook, section 4.2.1 Auto-Ranging Use Model.
