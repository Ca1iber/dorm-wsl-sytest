Creating a Digital Source Setup for DSM FLAT setup

Creating a Digital Source setup for DSM FLAT setup is same as the DSM normal setup, except for the following points:

  1. Before you create the Digital Source setup, make sure that the number of vectors in the MAIN label is at least: 
    offset + frame_size * number_of_frames
  2. Select Main[main_label_name] button on the Data Pattern panel as the sourced data is in the MAIN label.
  3. Set all the defined pins as source pins.
  4. The Offset means where the source data starts in the MAIN label.

The settings for the other parameters are same to the normal test.

After you created the Digital Source setup, you can see it in the Outline view if you enable the editor of the MAIN label where you start the Setup Wizard.
