The EVENT_WAVEFORM_CF (Current Force) waveform class provides the functionality to define events that generate waveforms in the force current mode.

This class is supported only for the DC Scale XPS256 card in PMU operating mode.

Class definition

The class derives from the EVENT_BASE class.

The object that is created by this class has to be assigned to the PATTERN_CONTROLLER which is responsible for further handling.

This class is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Constructor
EVENT_WAVEFORM_CF (const STRING & id);
EVENT_WAVEFORM_CF (INT id);

The constructor creates an object of the type EVENT_WAVEFORM_CF and assigns the given identifier to the object.

Parameters
Parameter Description
id

Identifier of the event.

The identifier may be defined as integer value or as string.
Return value
The constructor has no return value.

Example

The following example creates a new DC event, fills the DC event with the data of an ANALOG_WAVEFORM and inserts the DC event into an already existing pattern. The programmed data are then read back from the event object and shown in the console window.

PATTERN_CONTROLLER patController;

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Create a wave
    //
    ANALOG_WAVEFORM sineWave ("sine_1");

    sineWave
        .definition (TM::SINE)
        .amplitude  (20.0 mA)
        .offset     (5.0 mA)
        .samples    (20)
        .periods    (2);

    //
    // Create a new event object
    //
    EVENT_WAVEFORM_CF event_WAVEFORM_CF ("WAVEFORM_CF");

    //
    // Set the event data
    //
    event_WAVEFORM_CF
        .cForce (sineWave)
        .sampleVectorDistance(50);

    //
    // Insert the event into a pattern
    //
    PATTERN & pattern = patController.label("...", "@");

    pattern.vecEvents("pin1").clearAll();

    pattern.vecEvents("pin1")
        .insert(100, event_WAVEFORM_CF)
        .setup ();

    //
    // Read data from the event object
    //
    ARRAY_D readWave;
    INT     samples, distance, repeats;

    readWave = event_WAVEFORM_CF.getCForce();

    cout << "wave size  = " << readWave.size() << endl;
    cout << endl;

    for (INT arrayIndex = 0; arrayIndex < readWave.size(); arrayIndex++)
    {
        cout << "readWave[" << arrayIndex << "] = " << readWave[arrayIndex] << endl;
    }

    event_WAVEFORM_CF.getSamples                (samples);
    event_WAVEFORM_CF.getSampleVectorDistance   (distance);
    event_WAVEFORM_CF.getRepeatCount            (repeats);

    cout << endl;
    cout << "samples  = " << samples  << endl;
    cout << "distance = " << distance << endl;
    cout << "repeats  = " << repeats  << endl;
}
ON_FIRST_INVOCATION_END();
