Counting failing addresses for a pin group

A new syntax is added to the MTP_MEMORY_PATTERN.getFailingAddressList() function to count the failing addresses that are different from (x, y, z) addresses for a group of data pins.

This syntax is: 

LONG getFailingAddressList(const ARRAY_I& dBitGroup, const LONG_LONG number_of_addresses, MTP::ARRAY_ADDRESSES& addresses)
