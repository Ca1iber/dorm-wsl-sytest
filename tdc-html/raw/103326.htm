Topic 103326

Setting up automatic waveform generation

Automatic waveform generation is specified when a pattern is compiled.

Before you begin

Make sure that all MTL Configuration Files are correctly set up.

Procedure

When you run the MTL compiler, make sure to check the Automatic Waveform Generation option in the compiler control dialog.

If you run the compiler from the command line, specify the -w or -vw option.

Results

All waveforms required by the compiled pattern are present in the timing file (when direct waveform mapping is used) or the waveform mapping file (when indirect waveform mapping is used).

The original timing or waveform mapping file has been saved as backup, with .BAK$$ appended to the file name. (Any previous backup files with the same name are overwritten.)

Waveform usage report

If the verbose mode was specified for the compiler (with the appropriate checkbox or the -vw option), a waveform usage report is generated. It looks like a wavetable with an added column in which the status of each waveform is listed:

  • #unused: The waveform was specified (manually) but not used.
  • #used: The waveform was specified and used.
  • #added: The waveform was used but not specified in the original wavetable. The compiler therefore added it.

What to do next

If you need to edit the automatically created wavetable, do so now.
