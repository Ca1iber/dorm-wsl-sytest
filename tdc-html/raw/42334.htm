Topic 42334

Running Hook Functions

To finally use the user-specific hook functions you must carry out the following two steps:

  1. Set up your global configuration file to select the plug-in directory which contains the user-specific hook functions. (See Setting Up the Global Configuration).
  2. In the Data Manger's test program page, select as Prober/Handler driver the general equipment driver which you have installed and compiled as described in Preparing a Driver for Hook Function Use, and which contains the plug-in with the user-specific hook functions.

    For example, select in n the Data Manger's test program page the driver /home/user/mydriver/GenericHandler

    (for details see Selecting the General Equipment Driver).
