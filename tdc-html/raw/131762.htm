SMC_GET_UPLOAD_STATUS()

Queries the status of the SmartCalc upload queue to be stored in a vector of type SMC_UPLOAD_STATUS.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h

Syntax

vector<SMC_UPLOAD_STATUS> SMC_GET_UPLOAD_STATUS();

List of parameters

There are no parameters.

Return value

Returns a vector of type SMC_UPLOAD_STATUS.

Example

This example shows how the SMC upload status can be retrieved and and elements of it be displayed.

// type definition
typedef vector<SMC_UPLOAD_STATUS> SmcUploadStatusVector;

// Obtain the collection
SmcUploadStatusVector statusVector = SMC_GET_UPLOAD_STATUS();

// dump the size of the collection using the .size() function of a vector
cout << "SMC_UPLOAD_STATUS, size= " << statusVector.size() << endl;

// iterate over collection using functions of a vector
for (SmcUploadStatusVector::iterator iter = statusVector.begin();
     iter != statusVector.end();
     ++iter)
{
   // selectively display attributes unsing functions of SMC_UPLOAD_STATUS
   cout  << iter->uploadType()
   <<  ", " << iter->testSuiteName()
   <<  ", " << iter->site()
   <<  ", " << iter->finished()
   << ", "  << iter->handle()
   << ", "  << iter->name()
   << ", "  << iter->area()
   << endl;

   // display all attributes using the toString() method of SMC_UPLOAD_STATUS
   cout << iter->toString() << endl;
}
