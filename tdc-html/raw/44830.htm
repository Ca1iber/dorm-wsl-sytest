Installing a Function Command Set

To install a function Command Set:

  1. Type the following at the command line:

    /opt/hp93000/soc/prod_env/lbin/install_cs -t FUNCTION

    The install_cs script copies the following into your directory:

    • a special Makefile
    • the function template fn_templ.c
    • and a command interface link.
  2. Use the template file fn_templ.c for each source file in which you want to implement the functions of the Command Set.

    You can write all of your functions into one source file, or split them up into several source files. In both cases, use the template provided. You can ignore the template and generate your own source files. However, this is not recommended, because the template file uses the exact syntax of the mandatory function declaration.

  3. Code your functions (as described in Writing a Function).
  4. Type

    make depend all

    at the command line. This action generates the shared library libcifset.sl. This is the file that is actually loaded by the command interface to make your functions available to the production software.

You can call the install_cs script with the -u option. This means that a user procedure function template is copied into the directory instead of the normal fn_templ.c.

The install_cs -t FUNCTION can be called as often as required and does not destroy any source files you have created. It does, however, always overwrite the Makefile and the template file fn_templ.c, so do not implement any of your functions in a file with these names.

The make depend command updates the Makefile to make the newly created source files visible to the Makefile. You only need to call make depend when a new source file has been created.

Use the make all command as often as necessary until you get a clean compile.

The implementation is complete when the shared library libcifset.sl exists within the directory.

Function coding must adhere to the rules as defined in the section Dependencies.
