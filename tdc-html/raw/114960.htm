Topic 114960

PRBS_SET

Subtopics

  1. PRBS_PINS
  2. PRBS_LABEL

The PRBS_SET class is a container representing a PRBS (Pseudo-Random Binary Sequence) set. The associated pins for PRBS features will be specified via this class. It is used to create and remove a set and change the primary set.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PRBS_SET.h.

Constructor

PRBS_SET(const std::string& setName,TESTMETHOD_API::TMAPICTXT_TYPE ctxt = TESTMETHOD_API::TMAPI_CURR);
PRBS_SET(const STRING & setName,const STRING& modeContext);

This constructs an object of the PRBS_SET class with the specified set name and the specified context. If the specified PRBS set does not exist, it is automatically created. If the set is existing but the context is different, the specified set will be created again.

Note The number of sets which can be created is limited by the hardware. This is checked when one of the following member functions is called. If it is not valid, an exception will be issued.
Parameter

setName

The PRBS set name.

ctxt

The context name for which the set is created. If not specified, the context DEFAULT is used.

modeContext

The context for which the set is created. It can be:

  • TESTMETHOD_API::TMAPI_DEFAULT: The default context
  • TESTMETHOD_API::TMAPI_CURR: The context of the current primary sets (default)
  • TESTMETHOD_API::TMAPI_PRM: Synonymous with TMAPI_CURR

Member functions

The member functions are operated on an object of PRBS_SET.

pin()

PRBS_PINS& pin(const std::string& pinList);

This function returns a reference to a PRBS_PINS object associated with the specified pins. You can use the following functions to set the PRBS set.

Parameter

pinList

The pins associated with the PRBS set.

setAsPrimary()

void setAsPrimary();

This function defines the current PRBS set as primary. This PRBS set is activated before next sequencer start.

remove()

void remove(const std::string& setName);

This function removes the set from firmware. It makes the PRBS set invalid and calling other functions after it will cause an exception.

Class functions

The following class functions Do not relate to specific PRBS set. You can use them without an object of PRBS_SET.

getPrimarySet()

static const STRING & getPrimarySet();

This function returns the current primary PRBS set. If the default setting is currently activated as primary, it will return an empty string.

getListofSets()

static void getListofSets(STRING_VECTOR& setNames);

This function executes a PRDF? query and returns the list of the PRBS set you defined.

Parameter

setNames

The list of the defined PRBS set names.

deselectGlobally()

static void deselectGlobally();

This function deselects PRBS sets globally. It will activate the default PRBS settings.

The length of the default setting is 32^2-1.

The default polynomial is:

f(x)=1+x+x^2+x^4+x^6+x^7+x^9+x^10+x^15+x^16+x^17+x^18+x^22+x^23+x^24 +x^27+x^31+x^32

The default seed for PRBS generator pins is:

00110010011011110001001101100111

label()

static PRBS_LABEL& label(const STRING& labelname,const STRING& port);

This function returns an object of the PRBS_LABEL class associated with the specified label and port. If this label does not exist, it is automatically created. It is provided to simplify the modifications of the label used for PRBS in test methods.

Functional changes

  1. Introduced in SmarTest 7.0.1
  2. SmarTest 7.2.1: New syntax to support creating a PRBS set for the specified context.
