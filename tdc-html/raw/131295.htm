MTP_DPS_MEASURE.wait()

The wait() member function of MTP_DPS_MEASURE lets you specify the wait time before the measurements.

Syntax

MTP_DPS_MEASURE & wait(DOUBLE waitTime_s)

Parameter

Description

waitTime_s

The wait time before the measurements.

The unit is second ([s]).

Related information

MTP_DPS_MEASURE
DPS_TASK

Functional changes
