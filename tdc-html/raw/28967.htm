DSP_EXP10_VEC

This API raises 10 to the powers specified by the elements in the specified array.

For the specified elements in src, this API raises 10 to the powers specified by the elements, and returns the results to result as follows:

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_EXP10_VEC(ARRAY_D& src, ARRAY_D& result);
DSP_EXP10_VEC(DOUBLE *src, DOUBLE *result, 
                            INT size);
Parameters

I/O

Parameter

Description / Range

I

src

Source array

O

result

Raised results

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src)

size ≤ (size of result)

Example

double array1[50], array2[25];
.
.
DSP_EXP10_VEC(array1, array2, 25);

DSP_EXP10_VEC raises 10 to the powers specified by the first 25 elements in the arrayarray1, and returns the results to the corresponding elements of the arrayarray2. For example, if the element ofarray1is 2, 10 is raised to the power of 2 (102 = 100), and returned to the first element ofarray2. This function does the following:

int i; 
for (i=0; i<25; i++)
 array2[i] = exp(array1[i] * log(10));
