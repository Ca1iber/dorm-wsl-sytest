Topic 16167

Device Technology Directory

This topic lists the path and subdirectories of a device directory for cmos and ecl.

Path of the default device technology directories cmos and ecl:

  • /opt/hp93000/soc/dev_tech
Subdirectories and files in the device technology directory

Subdirectory

Contains

.project

Configuration of the device project

.settings/vectors

Layout data for the Pattern Debug Tool and Pattern Explorer

.technology

See Technology file for a device for details.

analog_control

Analog setup file

applicat

Application data for production mode

calibration

Calibration data. For the ACTCatr file, see ACTCatr.

ch_attributes

See Channel attributes files for details.

configuration

Pin file

data_set

(Reserved)

di_report

(Reserved)

error_map

Exported error maps in ASCII format

format

Pin display information for GUI tools

levels

Level file

license

License file

lock_file

Lock file for the device

pin_attributes

Edge delays for each pin, used for calibration

profiles

Date logging configuration

report

Log file

routing

Analog and relay routing information

scan_res

(Reserved)

shmoo

Shmoo setup and result files

testflow

Testflow file

testfunc

Customer-defined connect and disconnect sequences

testmethod

Test method file

testprog

Test program file

testtable

Test table file

timing

Timing file

timing_dgrm

(Reserved

vectors

Vector file

vectors/.cache

Cached pattern file dependencies

wafertyp

Wafer description file

waste

Default temporary directory

waveform

Waveform file

waveform/.result

Result waveform file

Some of these directories are generated only when particular tools or options are used, not by default. Additional directories may be present that were created by third-party tools such as version control software.

Within each of the sub-directories are files (containing firmware commands) which specify the default values.

Every time you create a new setup file, the defaults are used and, of course, can be changed.
