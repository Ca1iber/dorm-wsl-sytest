TMU_RESULTS.getNumberOfMeasuredSamples()

Returns the number of measured samples of the specified pin, application type, measurement ID and site.

Syntax

UINT64 getNumberOfMeasuredSamples(STRING&  pin, TMU::ApplicationType appType, UINT32 meas = 1, UINT32 site = 0);
UINT64 getNumberOfMeasuredSamples(const char* pin, TMU::ApplicationType appType, UINT32 meas = 1, UINT32 site = 0);
Parameters

I/O

Parameter

Description

I

pin

The pin to query.

I

appType

The application type. It currently can only be APP_PERIOD or APP_RAW.

I

meas

The measurement ID.

I

site

The site to query. Default is 0, which means the current site.

Return value

The number of measured samples is returned.

Functional changes

  1. Introduced in SmarTest 7.1.0
