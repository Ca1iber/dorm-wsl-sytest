Topic 131361

SPMU_PIN_TASK.limits()

Sets the low and high thresholds for evaluating the pass/fail result using either the limit settings of a test suite or a LIMIT object.

Note Both thresholds (min and max) must be specified regardless of the measurement mode.

Syntax

SPMU_PIN_TASK& limits(const STRING& limits);
SPMU_PIN_TASK& limits(const LIMIT& limits);
Parameter

Parameter

Description

limits

The Name of the LIMIT object or the limit's name from the test suite as STRING.

Return value

A reference to the SPMU_PIN_TASK object.

Related information
