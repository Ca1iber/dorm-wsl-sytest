Topic 42203

Parameter: auto_reprobe_on_check_device

If the equipment provides a reprobe feature (disconnect and re-connect the device), and this feature can be addressed through the communication interface, it is possible to automatically reprobe devices.

This parameter determines whether reprobing will be performed, if check_dev was selected from the application model's pause menu.

Driver default: "no"

Changeable at run-time: yes

Applicable for: handlers and probers

Example: auto_reprobe_on_check_device: "yes"
