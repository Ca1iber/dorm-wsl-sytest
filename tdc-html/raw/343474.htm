Creates a "routeGroup" object for controlling setups of the Routing Tools.

This class handles all states that have been defined by the Routing Tools editors. The class translates the state setup table of the State Setup editor into executable pattern and provides functions for downloading the MUX cards states to the setup memory of the cards. The class additionally provides functions for applying or activating the states, clearing all connections and modifying PMUX switches.

The created routeGroup object can only be accessed via the rdi() class.

Note In SmartRDI, utility lines may be controlled by the rdi.util() class or by the rdi.route() class of the Routing Tools. In addition, the utility lines may be controlled by test method APIs, firmware commands or the "Routing Setup Tool".

This may lead to conflicts if the same utility line is controlled by more than one API or tool.

For SmartRDI we therefore strongly recommend, controlling utility lines either by the rdi.route() class or by the rdi.util() class. The mixed use of the two APIs or other test method APIs and tools is not recommended. This recommendation applies to code‑based programming and to pattern‑based programming.

Code‑based programming for the rdi.route() means that the utility lines are set to "static" in the "Control table" of the Utility Lines Control editor. Pattern‑based programming for the rdi.route() means that the utility lines are set to "dynamic" in the "Utility Lines Control editor".

Syntax

Usage of the function:
  • The function can be called in the code‑based mode or in the pattern‑based mode. For more information, refer to Pattern-based mode and Code-based mode in topic SmartRDI.
routeGroup& route(const int id);
routeGroup& route(const string& id="");
List of parameters
Parameter Description
id Optional ID for the following setups.

The parameter can be defined as int or as string.

Default value: Empty string ""

Return value

A reference to the routeGroup object.
