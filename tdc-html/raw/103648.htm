Topic 103648

GetCalStatus

This data query command gets the status of the loaded calibration data.

Note Advantest strongly recommends the use of the GetCalStatus API in test programs.

SUCCESS will be returned if no error occurs. Otherwise an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • The designated calibration type "XXX" is not supported.

RECOVERABLE

Dependency

The specified session is running.

Parameters

I/O

Parameters

Description

I

SESSION_ID

The ID of the SmarTest session to query.

I

CAL_TYPE

The calibration type. It can be CALIBRATION.

O

qrResults

The query results are represented by a ParamList object. It contains the following members:

  • CAL_DATE: This is no longer supported with SmarTest 7.10. For compatibility reasons, it can still be queried, but will always return "01.01.1900".
  • CAL_EXEC_STATUS: This is no longer supported with SmarTest 7.10. For compatibility reasons, it can still be queried, but will always return FAIL.
  • CAL_DATA_VALIDITY: The calibration data is valid or not. It can be CURRENT or EXPIRED.
    Note In SmarTest 7.10, the values are kept for compatibility reasons. A failing calibration will lead to the CAL_DATA_VALIDITY = EXPIRED.

Prototype

ParamList qrResults, qrParams;
Status query ("GetCalStatus", qrResults, qrParams, sessionId);

Example

ParamList qrResults, qrParams;
string sid;
qrParams ["CAL_TYPE"] = "DC_UPDATE"; 
query("GetCalStatus", qrResults, qrParams, sid);
printf("the information for the calibration <DC_UPDATE> is:\n");
printf("< CAL_DATE >: %s\n", qrResults ["CAL_DATE"]);
printf("< CAL_EXEC_STATUS >: %s\n", qrResults ["CAL_EXEC_STATUS"]);
printf("< CAL_DATA_VALIDITY >: %s\n", qrResults ["CAL_DATA_VALIDITY"]);
