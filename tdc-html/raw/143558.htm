RARepairResultsAttrType

Contains results of a redundancy analysis. The data type is DRLRARepairResultsAttr.

Field Name

Data Type

Description

Comments

length

int

Attribute length

These fields form the attribute header

type

short

Attribute type

repairable

DRLFailureCode

Whether the test device is repairable:

  • DRLFailureCode_Fail: The device is not repairable. The following fields contain the cells that have been repaired.
  • DRLFailureCode_Pass: The device is repairable. The following fields contain the repair solution.
