SQRC - (SeQuencer Remove execution Context)

The SQRC command serves to remove a selected or all existing execution contexts. For information on execution contexts, see Using execution contexts.

SQRC

SQRC {"context_name"|ALL}

Parameters

context_name

The name of the context to be removed.

ALL

With this option, all existing contexts will be removed.

Errors

An error occurs if:

  • The specified context does not exist.

Example

> SQRC "c1"

Functional changes

  1. Introduced in SmarTest 7.2.0
