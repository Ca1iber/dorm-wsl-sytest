Topic 43002

Printing a graphical representation of the testflow

The graphical representation of a testflow can be saved as a file.

Before you begin

Make sure that the testflow has been created.

Procedure

  1. Activate the Flow Sequence Editor. In the SmarTest Work Center, choose File > Save as picture.
  2. The Save Testflow as Image window opens. Enter the name (for example, testflow.jpg) and location of the image file.
  3. Click OK.

Results

The image of the testflow has been saved with the specified name testflow.jpg. You can use an image processing tool to open it.

Related information

Flow Sequence Editor

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.2: You can output the testflow image rather than an ASCII testflow description to a file.
