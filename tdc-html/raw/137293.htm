Integrated Result Tool

Subtopics

  1. Principles of operation of the Integrated Result Tool
  2. Using the Integrated Result Tool
  3. Integrated Result Tool reference

The Integrated Result Tool supports the statistical and graphical evaluation of saved data log files and the system data log stream.

Using the tool, you can load and open data logs. The logs are automatically summarized, and you can create a variety of result graphs to easily spot data of interest.

Functional changes

  1. Introduced in SmarTest 7.2.0
