GPIB driver configuration

The Rasco SO3000 and SO1000 handlers are supported.

The following configurations are provided with the driver:

SO3000-GPIB-1.cfg

SO3000-GPIB-2.cfg

SO3000-GPIB-3.cfg

SO3000-GPIB-4.cfg

The configurations differ only in the number of sites.

Default GPIB configuration

This section describes the variables used in the configuration files. When the configuration files were created, certain aspects necessarily had to be defined. The table below lists these aspects and how they were defined.

Important aspects of the Rasco configuration files

Aspect

Used setting

Debug level

0, will log only basic messages. It can be changed to a value between -1 and 4.

GPIB port used

6, must be changed to correct value based on the handler's setup.

Bin mapping

default

Number of bins

32 (SmarTest hardbins 0 through 31), bin 0 represents the SmarTest reset bin.

Reprobe mode

Automatic reprobe on a per site mode, if devices fall into SmarTest reprobe bins.

Reprobe bin number

31, represents number sent to handler upon receiving a SmarTest reprobe bin. It must be changed to correct value according to set up of handler. The reprobe mechanism refers to the disconnection and reconnection of the device before a retest is performed.

To disable this setting remove the handler_reprobe_bin parameter and set the automatic_reprobe_mode to "off"

Temperature parameters

Temperature control may be activated by changing the parameter temp_control to active and setting the temp_setpoint.

Test start detection

Done by interrupt (SRQ). It can be changed to pure polling mode with given polling interval for troubleshooting.

Polling interval

The default value is 100 ms, only used if waiting for parts is done by polling.

Functional changes

  1. Introduced before SmarTest 6.3.2
