Topic 116966

TTMD? - (Transition Test MoDe query)

The TTMD? query returns the protocol engine mode for the specified pins in the specified timing specification.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

TTMD? {specset_id|"multi-port_spec"}, {timing_set}, {(pinlist)}

returns: 

TTMD {specset_id|"multi-port_spec"}, {timing_set}, {tt_mode}, [clk_fwd], {(pinlist)}

Parameters

specset_id

Number of a single-port timing specification. Derived as follows:

100 *equation_set_no + specset_no

multiport_spec

For a multiport setup, specify the name of a multiport specification.

Note that the multiport specification uniquely determines an equation set for every pin of pinlist, because no pin can belong to more than one port within a multiport specification.

timing_set

Timing set number. Enter PRM for the primary timing set, ALL for all timing sets, or an integer in the range 1 to the maximum number of allowed timing sets. The maximum number is determined by TSUS.

tt_mode

 

Specifies the protocol engine test mode. Possible values are:

OFF

Protocol engine is inactivated

X4

X4-mode is activated.

X6

X6-mode is activated.

clk_fwd

Not used.

pinlist

The name of the pin or pins for which the protocol engine mode is to be retrieved. This parameter can also include groups previously created by the DFGP (DeFine GrouP) command. The symbol @ can be used to specify all configured pins. If more than one pin is to be included, the names must be separated by a comma.

In a multiport setup, every pin must belong to a port of the specified specification.

Application

Protocol engine test.

Errors

An error is generated if:

  • timing_set is greater than the range allowed by the TSUS command.
  • The selected timing set is not defined for the respective equation set.

Example

> TTMD 101,1,(PIN1)
< TTMD 101,1,X4,,(PIN1)

Functional changes

  1. Introduced in SmarTest 7.0.1
