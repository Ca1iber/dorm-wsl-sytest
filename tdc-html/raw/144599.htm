Topic 144599

ungang()

Specifies whether to temporarily ungang the DC Scale pins before the current measurement.

This function is only applied to ganged pins. It can be used in the code‑based mode only.

Syntax

ungang(bool mbGangmode);
List of parameters

Parameter

Description

mbGangmode

The flag indicating whether to ungang the DC Scale pins. It can be:

  • true: ungang the DC Scale pins.
  • (default) false: Do not ungang the DC Scale pins.

Example

rdi.dc(2).pin("DPS32_SIG_GANG").vForce(1 V).iMeas().iMeasRange(2 mA).ungang(0).execute();
rdi.dc(3).pin("VI32_GANG").iMeas().iMeasRange(2 mA).ungang(1).execute();
