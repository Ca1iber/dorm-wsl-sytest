Topic 116559

FOR_EACH_SITE_BEGIN_WITH_QUERY

This API allows you to sequentially setup and query setup and result information for all active sites. It sets the current site as the query focus site in each iteration. It must be used together with FOR_EACH_SITE_END as a pair, called "each site with query loop block". The query focus will be reset by FOR_EACH_SITE_END(). If you want to execute only setup information for all sites, use FOR_EACH_SITE_BEGIN.

Application note

  • This API is used to change query focus site and enable querying the setup and result information from firmware for each site.
  • This API is meaningful for multi-site testing. For single-site testing, this API is ignored.
  • The "each site with query loop block" must be placed
    • in the first-invocation block declared by ON_FIRST_INVOCATION_BEGIN and ON_FIRST_INVOCATION_END or
    • in the last-invocation block declared by ON_LAST_INVOCATION_BEGIN and ON_LAST_INVOCATION_END.
  • All statements in the "each site with query loop block" are executed serially for all active sites when the program is run for the first tested site.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/MapiUtil.h.

Syntax

FOR_EACH_SITE_BEGIN_WITH_QUERY();

List of parameters

There are no parameters.

Return value

There is no return value.

Examples

Example 1: Minimum code

The following example shows the minimum code for a "each site with query loop block". The ellipses ("...") are to be replaced with your code.

ON_FIRST_INVOCATION_BEGIN();
    ...
    ...
    FOR_EACH_SITE_BEGIN_WITH_QUERY();
        ...
        ...
    FOR_EACH_SITE_END();
    ...
    ...
ON_FIRST_INVOCATION_END();

Example 2: Optional curly brackets

The example utilizes optional pairs of curly brackets "{" and "}". These optional curly brackets are used for simplifying the correct indentation with assistance of the related Eclipse tool.

ON_FIRST_INVOCATION_BEGIN();
{
    ...
    ...
    FOR_EACH_SITE_BEGIN_WITH_QUERY();
    {
        ...
        ...
    }
    FOR_EACH_SITE_END();
    ...
    ...
}
ON_FIRST_INVOCATION_END();

Example 3

ON_FIRST_INVOCATION_BEGIN ();

    //
    // Do site-specific query for each site serially in the
    // for each site with query loop.
    //
    // The FW query focus is set to the current site in
    // iteration by for each site with query loop.
    //
    // At this point the query focus is site 1.
    //

    FOR_EACH_SITE_BEGIN_WITH_QUERY ();

        //
        // The query focus is set to current site in iteration.
        //
        // The following FW query will return the result of the
        // current site in iteration.
        //
        string sAnswer;

        FW_TASK ("SVLR? TIM, PRM; \"SpecName\"", sAnswer); 

    FOR_EACH_SITE_END ();

    //
    // At this point the query focus is reset to site 1.
    //

ON_FIRST_INVOCATION_END ();
...
...
