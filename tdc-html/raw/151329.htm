vSlewRate()

Sets the force voltage slew rate in Volts per microsecond (V / µsec).

This function is only for the DC Scale XPS256 card. The function can be used in the code‑based mode. In addition to that, it can be used in the pattern‑based mode for XPS256 pins in PMU operating mode.
Note For XPS256 pins, the slew rate settings are applied only in connected mode. The maximum slew rate, limited by the programmed bandwidth, is applied when a disconnected channel is connected. We recommend therefore connecting an XPS256 pin with the forced value set to 0 V or 0 A respectively and changing the forced value to the target value after the channel has been connected. The bandwidth can be set by test method APIs SPMU_PIN_TASK.vFilter() and SPMU_PIN_TASK.iFilter() or by SmartRDI functions rdi.dc().vFilter() or rdi.dc().iFilter.

Syntax

dcBase& vSlewRate(double vSlewRate);
Parameter
Parameter Description
vSlewRate

Defines the voltage slew rate in Volts per microsecond (V / µsec).

Programmable double values are

  • Value between the card-specific minimum and maximum value: The slew rate is set to the defined value.
  • 0.0: The slew rate is set to the card-specific default value.
Card-specific range and default value:
  • XPS256: Refer to section Dynamic behavior in XPS256 programming - Force and clamp voltages.

Return Value

A reference to the dcBase object.

Example

rdi.dc().pin("Pin_1")
        .vForce(20.0 V)
        .iClamp(-10.0 mA, 80.0 mA)
        .vSlewRate(500 mV)           // 500 mV / us
        .vFilter(20.0 kHz)
        .execute();
