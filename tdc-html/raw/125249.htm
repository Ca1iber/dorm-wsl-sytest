GPIB communication flow for SRM handlers

This section describes the GPIB communication between the driver and the handler. The actions and messages are listed in sequential order in the table below.

See Conventions for GPIB communication for syntax description. Please note the GPIB messages sent from the SRM driver plug-in to the handler end with '\r' instead of '\r\n'.

0x41 SOT for site A

Bin devices:

bSORTxn

Bin the part from site "x", where "x" is A, B, C or D according to Bin number "n", where "n" is 1 To 8. Separate message is sent for each site.
