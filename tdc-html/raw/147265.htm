DVM_TASK.execute()

The execute() member function executes the DVM measurement with the settings defined by the member functions of DVM_PIN_TASK.

Syntax

void execute()

List of parameters

There are no parameters.

Return value

There is no return value.

To retrieve results use the DVM_TASK.getValues() function.

Example

See the example in DVM_TASK.
