Twinning DUT interface

  5. Twinning DUT board design

This chapter describes the special considerations necessary for designing Twinning DUT and family boards.

Twinning is an extension of the Advantest V93000 Interface that provides not only a larger DUT board area for routing and components, but also an internal area that can be used for large component integration or even built-off self test (BOST) circuits. On the Twinning family board it is possible to include multiple circuits and even large components that usually do not fit on a DUT board. The signals from the family board are then routed through a base frame that contains multiple pogo segments to the DUT board on top. The DUT board also has a different PCB geometry and pogo locations compared with the standard V93000 DUT board.

The following V93000 Instruments are supported by Twinning
  • All V93000 digital pin electronics (standard and HD pogo pins)
  • DPS32/128
  • Wave Scale RF
