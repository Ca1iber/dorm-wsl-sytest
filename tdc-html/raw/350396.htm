getAnaResultHandle()

Retrieves the name of an analog result handler that SmarTest uses to save the result.

You can use this function to see which analog result handler is occupied. In some cases, you may need to release the analog result handler.

This function returns the name of the analog result handler used by the previous upload action. If the latest upload does not have an analog set or if no upload action exists at all, this function returns empty.

Syntax

string getAnaResultHandle();

Example

rdi.hiddenUpload(TA::ALL);

RDI_BEGIN();
  rdi.rfm("sp1").pin("LB_src,RX_Src").signal(TA::S_PARA)
                .freq(1e9).execute();
  rdi.wait(TA::WAIT_RFDGT);
RDI_END();

string resultHandle = rdi.getAnaResultHandle();

Functional changes

  1. Introduced in SmartRDI 7.5.3
