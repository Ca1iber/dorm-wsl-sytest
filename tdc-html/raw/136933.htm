Shmoo output of the Event Formatter

The shmoo output by using the Event Formatter is demonstrated in this topic. (To use the Event Formatter to output shmoo data log, refer to Logging shmoo tests in the report window.)

The shmoo output contains:

  • The shmoo test suite name, appearing at the beginning and end.
  • The shmoo setups:
    • This shmoo test suite used primary settings.
    • Result setups, such as the title of a shmoo plot, the result pins, and the test modes that determine the result data to be shown on shmoo cells.

      For details, see ShmooTestInforAttrType.

    • The axis setups on shmoo plots. For details, see ShmooTestInforAttrType.
  • Shmoo plots, including:
    • Plot descriptions: Such as the number of result pins and their names and the number of test modes and their names. For details, see ShmooTestCellAttrType.
    • Shmoo plots of different result pins and test modes.

      By default, the y axis of the shmoo plot points down. To change its direction to be up, change the value of shmoo_y_axis_direction to 1 in the Event Formatter configuration file (.formatterrc).

If it is a multisite shmoo test, you will see shmoo setups and plots for each site and site numbers.

  • (Optional) The directory in which the shmoo plots are saved as .png files. The directory will be <the current device>/shmoo/shmooPNG/. You will see it only if you have set shmoo_picture_generation to 1 in the configuration file .formatterrc.

Functional changes

  1. Introduced in SmarTest 7.2.0
  2. SmarTest 7.2.0: (7.2.0 patch 1) The output format of shmoo tests is changed.
  3. SmarTest 7.2.1: The Event Formatter starts to support the output of fail-bit-count shmoo test which is available for MTP.
  4. SmarTest 7.2.1: The Event Formatter can save shmoo plots to the <the current device>/shmoo/shmooPNG/ directory as .png files.
  5. SmarTest 7.2.2: Patch 5, the output will show the primary values of those resources that the X and Y axes represent
