DSP_RF_GET_SYSTEM_COLD_NOISE()

The function DSP_RF_GET_SYSTEM_COLD_NOISE() extracts the System Cold Noise Power.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

INT DSP_RF_GET_SYSTEM_COLD_NOISE(const ARRAY_D & measParams, DOUBLE * calFactor)
INT DSP_RF_GET_SYSTEM_COLD_NOISE(const ARRAY_D & measParams, const INT site, DOUBLE * calFactor)
Parameters

I/O

Parameter

Notes

I

measParams

cal data for all sites

I

Site

Site Id

I

calFactor

calibration correction factor

Example

//Get MeasParams from a NoiseFigure type of measurement
ARRAY_D noiseParams = MEAS_DEF(measName).getParameters(captureNumber,freqListIndex);
//Extract the System Noise Factor
DOUBLE systemNoise;
DSP_RF_GET_SYSTEM_NOISE_FACTOR(noiseParams, &systemNoise);
//Extract the System Cold Noise Power
DOUBLE systemCOldNoise;
DSP_RF_GET_SYSTEM_COLD_NOISE(noiseParams, &systemColdNoise);

Functional changes

  1. Introduced in SmarTest 6.5.3
