TMU_TASK.getResultCache()

Returns the reference to a TMU_RESULTS object identified by test suite name and the TMU set name.

Syntax

TMU_RESULTS& getResultCache();

List of parameters

There are no parameters.

Return value

A reference to the TMU_RESULTS object is returned.

Related information

TMU_RESULTS

Functional changes

  1. Introduced in SmarTest 7.1.3
