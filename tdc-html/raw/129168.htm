SHARED_CONTINUITY_TEST.terminationDPS()

The terminationDPS() member function of SHARED_CONTINUITY_TEST lets you specify the termination voltage DPS pins used.

Syntax

SHARED_CONTINUITY_TEST& terminationDPS(const string& dps)

Parameter

Description

dps

The pin list of the termination voltage DPS pins used.

Separate multiple DPS pins with commas.

This parameter is ignored for DPS-shared load boards for which there is a utility_control section in the Sharing configuration file.

Example

SHARED_CONTINUITY_TEST mTest;
mTest.terminationDPS("VTERM");
mTest.terminationDPS("VTERM1, VTERM2");
