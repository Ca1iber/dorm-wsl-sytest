Global result queries

FTST? executes a functional test and returns a global pass or fail result. If you want a combined result for a subset of the configured pins, then you must use PASS?. More detailed information can be obtained by CHER?, which returns a separate result for every specified pin.

The CHFA? query is intended for tests that fail because of a failing match loop (see Match loops). It returns the result of the last match loop cycle for selected pins. This information cannot be retrieved from the Error Map (for which see Using the Error Maps), because match loop cycles are not recorded in the Error Map. Another match loop related query is MCNT?, which returns the number of the match loop pass where a match was obtained.
