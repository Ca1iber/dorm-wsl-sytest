SMC_UPLOAD_STATUS.testSuiteName()

Returns the test suite name of an SMC task that is stored in a vector which is populated by SMC_GET_UPLOAD_STATUS().

Syntax

const STRING& testSuiteName() const;

List of parameters

There are no parameters.

Return value

The name of the test suite of a SMC task in the upload queue.

Example

This example shows how to create a vector of type SMC_UPLOAD_STATUS and how to retrieve the test suite name from the vector.

Note As SMC_UPLOAD_STATUS represents a collection, one has to iterate over the collection to obtain the item.
typedef vector<SMC_UPLOAD_STATUS> SmcUploadStatusVector;
string TSName;

// Obtain the collection
SmcUploadStatusVector statusVector = SMC_GET_UPLOAD_STATUS();

// iterate through collection
for(SmcUploadStatusVector::iterator it = statusVector.begin();
     it != statusVector.end(); ++it) {
        TSName= it->testSuiteName();
        cout << "SMC upload type:" << TSName << endl;
     }
