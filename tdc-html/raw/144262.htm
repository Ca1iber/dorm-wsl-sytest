Preference page on Test Program Cleaner

Click the preference icon to open the preference page, using which you can customize the cleaning of a test program.

This preference page contains four tabs:

Remove optional files or directories

You can select to clean the following items:

  • Remove directory of TP360 reports: Select it to remove all the directory
  • Remove directory of HW_RESPONSE_DATA
  • Remove files/directories in waste directory
  • Remove .setting files
  • Remove .svn files
  • Remove files/directories in waveform/.result
  • Remove unused labels according to primary setting in testflow file and following configuration file
  • Configuration file of additional label primary settings
  • Specified files/directories to be removed: this is a text field where you can specify the types of files you want to clean, such as ~*, *.o, .svn, *.d, .cache, lock file, core dumper file, *.bak, *.bck, format.TS_DEFAULT_DC , hs_err_pid*.log.
  • Specified files/directories to be skipped

Remove test program setups

As redundant pin setups lead to the warning "redefined pins" in SmarTest, TP360 removes the redundant pins from level/timing/vector files.

Note TP360 tries to keep the original format, however, some modifications replaces group name with pin list.
  • Level - remove redundant pins from level file
  • Timing - remove redundant pins from timing file
  • Level/timing/vector - remove setups of undefined digital pins
  • Test table - remove unused test suite entries from test table file: TP360 removes the lines in the test table file where the used suites are not defined in the test flow file.
  • Testflow - remove unused test method(tm_xx) from testflow file: TP360 removes the definition of the tm-link which are not linked by suites.
  • Testflow - remove unused test suite(floating suites) from testflow file
  • Testflow - remove bypassed test suite/group from testflow file
  • Testflow - remove unwanted 'if(0)' branches from testflow file: only remove the unwanted 'if(0)' branches.
  • Testflow - remove unwanted 'if' branches from testflow file by editing the rulef ile below: You can remove any other unwanted 'if' branches by specifying a rule file, and the format of the rule file as below.

Collect additional components

You can clean the external files or setups of the device.

  • Source files of UTM projects: Select it to clean the UTM projects associated with the device.
  • Specified external files/directories: This is a text field where you can specify the external files to be cleaned.

Output directory

You can configure the output path of the cleaned test program.

  • Skip vector directory copy and cleanup (faster): Select it to copy the vector to the output device, because too large vector will slow down the clean process.
  • Cleaned device directory: Specify an output directory where the cleaned devices will be placed.
