Topic 92321

Post-Save Operations for Setup Data: hp83_postsave

The script hp83_postsave is automatically executed every time you save setup data, immediately after the actual save operation.

The default of the script (as you find it in opt/hp93000/soc/com/lbin/hp83_postsave.def) performs the following tasks:

  • It compresses the saved file if its extension is *.gz or *.Z.
  • It calls the Setup Management tool if the extension of the saved file is *.mfh.
