Topic 99159

Opening the Pattern Editor

About this task

To change patterns you must open the Pattern Editor.

Before you begin

Make sure either the Pattern Explorer or the testflow tool is open.

Procedure

To display a pattern you have several options:
  • In the Pattern Explorer, double-click either the name or the icon on the left of the pattern.
  • When debugging a testflow, you can also click the failing test suite, to display its properties. In the Properties view, either right-click the pattern item and select Open Pattern or press F3.

Results

The Pattern Editor opens and displays the selected pattern.

Note The Pattern Editor does not open patterns with more than 500,000 instructions.
