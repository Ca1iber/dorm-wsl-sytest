GETX? - (GET eXtended vector information)

The GETX? query connects a cycle and a vector in the test that is referenced by the current start label.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Mode of operation

You can either get vector information for a cycle, or cycle information for a vector. In the first case, simply enter a cycle number. The system will return the logical number and label name of the vector that generated the cycle. Note that the label can be be different from the start label; for example, it can be a SVEC label within a MAIN label which is called from a burst. In the second case, you must enter a logical vector number and a label which is called directly or indirectly from the current start label. The system will return the first cycle that is generated by this vector.

Syntax

GETX? [type], [label], [vector], [cycle], [index], {(pinlist)}

returns: 

GETX {type}, {label}, {vector}, {cycle}, [index], {(pinlist)}

Parameters

type

The label type. You can supply one of the following options:

MAIN

The MAIN program.

SJMP

A JuMP Subroutine.

SVEC

A VECtor Subroutine.

BRST

BuRST mode.

MPBU

Multi-Port BUrst mode

ALL

reads the configurations for all label types (query only).

label

The label name. It references the label for which you require vector information. Enter a string enclosed in double quotes. The string can have a length of between 1 and 128 alpha-numeric characters.

vector

The logical number of a vector within the label specified by label. The logical vector number counts the active vectors within one label, starting from 0.

cycle

A cycle number. If this parameter is specified, the label and vector parameters are ignored.

index

This parameter is reserved for future use. In this implementation it must be left blank!

pinlist

Information is only returned for the pins specified in pinlist. If more than one pin is to be included, the names must be separated with a comma. You can type the character @ to obtain data for all pins.

Application

Vector addressing for download.

Errors

An error is generated if:

  • The entered label does not exist.
  • The label has not been executed.
  • The logical vector does not exist.
  • The entered cycle does not exist.

Example

> GETX? ,,,4,,(CP)
< GETX MAIN,"multi",4,4,,(CP)

This example asks for vector data at cycle 4 on pin CP. The system replies that cycle 4 was generated by vector 4 in a main label called multi.

Note that this type of query where only a cycle number is supplied is similar to the GETV? query requesting information on just a single cycle - see GETV? - (GET Vectors). 

> GETX? MAIN,"multi",10,,,(CP)
< GETX MAIN,"multi",10,10,,(CP)

This example requests the number of the cycle that was generated by vector 10 in the main label called multi. The system replies with cycle 10.

Functional changes

  1. Introduced before SmarTest 6.3.2
