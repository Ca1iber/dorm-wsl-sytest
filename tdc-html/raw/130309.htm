Random address patterns

In some patterns, addresses are accessed in an arbitrary order.

Without MTL arrays, if you you cannot find formulas to use in a loop for calculating the next addresses, you only can program such patterns in a flat style, which creates lengthy and hard to maintain code.

With MTL arrays, you can program such patterns in a loop function with a simple algorithm:

  1. Create a mapping table which contains all the addresses in the same arbitrary order.
  2. Use loop to iterate over the elements of this table sequentially.
