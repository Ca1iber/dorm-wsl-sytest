Example:

Increasing the time until the driver notifies a 'waiting for parts' timeout from the current value 30 seconds to 60 seconds:

Current setting of the corresponding parameter in the configuration file is:

waiting_for_parts_timeout: 30

First, check the definition of valid parameter settings in the attributes definition file:

waiting_for_parts_timeout: (1:3600 i)

(The definition allows for integer values between 1 and 3600. Thus, 60 is a valid setting.)

Then, change the setting in the configuration file to:

waiting_for_parts_timeout: 60
