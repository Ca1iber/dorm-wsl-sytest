Topic 17605

Creating a utility purpose

Before you begin

Make sure that a new pin configuration file has been created or an existing pin configuration file has been loaded.

Procedure

  1. In the Test Program Explorer view, right-click Utility Purpose and choose New.
  2. The New Utility Purpose window opens. Type a utility purpose name in the New Utility Purpose text box. Click OK.

Results

The Utility Purpose Editor for the new utility purpose opens. The Utility Members area is blank.

What to do next

Edit the utility purpose.
