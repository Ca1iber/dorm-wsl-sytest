JITTER_INJECTION_PINS

The JITTER_INJECTION_PINS class holds the jitter injection properties of a list of pins. It provides methods to modify the jitter properties and query the settings. It is a sub-class of the JITTER_INJECTION_SET class. You cannot directly create an object with it.

Jitter injection can be set up in two ways:

  • manual jitter waveform setup

    This is done by setting the waveform with setWaveform(). The member functions setWaveform() and setPeriodFactor() can be only used for manual jitter waveform setup.

  • predefined jitter waveform setup

    This is done by setting the waveform with setWaveformSinus(), setWaveformRectangle() or setWaveformTriangle(). The member functions setPeriod() and setPhase() can be only used for predefined jitter waveform setup.

The member functions setMode() and setNoise() can be used for both manual jitter waveform setup and predefined jitter waveform setup.

Note that if you link a timing modulation set to the pins of a JITTER_INJECTION_PINS instance with linkModulationSet(), you cannot use any other waveform related member function in the jitter set from which this instance was created.

Member functions

setMode()

JITTER_INJECTION_PINS& setMode(JITTER_INJECTION::MODE mode);

This function sets the jitter injection mode.

Parameter

mode

The jitter injection mode. It can be:

  • JITTER_INJECTION::OFF: no jitter injection.
  • JITTER_INJECTION::RESTART: The jitter injection is stopped after each FTST? and restarted before next FTST?.
  • JITTER_INJECTION::CONT: The jitter injection is started with the first FTST? and then continuously running

setPeriodFactor()

JITTER_INJECTION_PINS& setPeriodFactor(INT factor);

This function sets the period factor for the jitter waveform defined with setWaveForm(). The waveform period equals the ECLK period multiplies the period factor.

Parameter

factor

The factor of the period. It can be an integer from 1 to 1024.

For SOC and HSM use 1, 3, or 5 only.

linkModulationSet()

JITTER_INJECTION_PINS& linkModulationSet(const::string& set);

This member function connects one or two modulation sets to the pins of the respective JITTER_INJECTION_PINS object. Note that if you call this member function, then you cannot call any other waveform related member functions.

Parameter

set[i]

The modulation set to be linked. You can either use the object identifier of the MODULATION_SET_TIMING object (without quotes), or the name that was specified for its setName parameter (with quotes) .

Examples

Use predefined waveform

JITTER_INJECTION_SET jset("Sinusoidal");
JITTER_INJECTION_PINS & jitter_pins = jset.pin("pin1");
jitter_pins.setWaveFormSinus(0.000000000100,0.0000004);
jitter_pins.setMode(JITTER_INJECTION::CONT);

This example defines a sine waveform for the jitter set of pin1. The jitter injection is started with the first FTST and then continuously running.

Define the waveform manually

JITTER_INJECTION_SET jset2("manual");
JITTER_INJECTION_PINS & jpins = jset2.pin("pin2");
jpins.setMode(JITTER_INJECTION::CONT);
DOUBLE_VECTOR waveform;
waveform.push_back(0.000000000100);
waveform.push_back(0.000000000050);
waveform.push_back(0.000000000000);
waveform.push_back(-0.000000000050);
waveform.push_back(-0.000000000100);
waveform.push_back(-0.000000000050);
waveform.push_back(0.000000000000);
waveform.push_back(0.000000000050);
jpins.setWaveForm(waveform);
jpins.setPeriodFactor(4);

This example defines the waveform data manually for the jitter set of pin2. The jitter injection is started with the first FTST and then continuously running.

Additional noise for algorithmic waveforms

When the property "NOISE" is set to a value different from 0 ps for algorithmic waveforms, the quantization error is subtracted from the user defined additional noise, before the noise is applied.

Set NOISE = 15 ps and the quantization error = 5 ps results in 10 ps of additional noise.

Get the jitter waveform based on the specific clock resolution

JITTER_INJECTION_SET jitterinject("Random");
jitterinject.pin(PinList)
     .setMode(JITTER_INJECTION::CONT)
     .setWaveFormTriangle(SineJitter_Amp_ps ps,1/SineJitter_Freq_MHz us, 50)
     .setPhase(0)
     .setAllowedNoise(20 ps)
     .setNoise(100 ps );

jitterinject.setAsPrimary();
FUNCTIONAL_TEST();

DOUBLE_VECTOR get_jwf;
jitterinject.pin(PinList).getWaveForm(get_jwf, 1.25e-9);
cout << "Jitter waveform size = " << get_jwf.size() << endl << "Contents: " << endl;
for(unsigned int i=0;i<get_jwf.size();i++)
   cout << "i[" << i << "]: " << get_jwf[i] << endl;
