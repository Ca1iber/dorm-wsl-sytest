Test suites and other test flow related operations such as data reporting/logging, sorting, flow control, and values assignment are represented by test flow nodes. You find the following node types when creating your test flow in SmarTest:

  • Test suite nodes
    • Run
    • Run and branch

      For more information see "Run" and "Run and Branch" test suites.

  • Sorting nodes:
    • Good bin
    • Bad bin
    • Multibin

      For more information see Bins.

  • Print nodes:
    • Print
    • Print to Datalog

      For more information see Print nodes.

  • Flow control nodes:
    • If/Then
    • Repeat Loop
    • While Loop
    • For Loop

      For more information see Flow control nodes.

  • Value assignment nodes:
    • Assign Value
    • Assign Level Value
    • Assign Timing Value

      For more information see Assign Value node.

The operations of the nodes (including Test suites and testflow nodes) in this section are completed in the Flow Sequence Editor.

Note The following operations cannot be performed in the Flow Data Editor: inserting, cutting, moving, cloning, and deleting nodes or node groups, and grouping the nodes.
