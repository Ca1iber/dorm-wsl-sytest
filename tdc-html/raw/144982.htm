Data types relevant to operators

The expression and operands data types for each operator are summarized in the following table.

Expressions

Data types

operand1 + operand2

Data types for the two operands can only be strings or numbers (normally signed 64 bit integers).

If both operands are strings, the result of the expression will be string.

If both operands are integers, the result of the expression will be integer.

If one operand is string and the other one is integer, the result of the expression will be string.

operand1 - operand2

This expression also applies to *, /, &, |, ^, <<, and >>.

Data types for the two operands can only be integers (normally signed 64 bits).

The result of the expression will be integer.

[bit index]

Data types of the bit index can only be integer.

operand1 > operand2

This expression also applies to >=, <, <=, and ==.

Both operands must have the same data type. They can be integers, strings, or Boolean.

The result of the expression will be the Boolean type.

operand1 && operand2

This expression also applies to ||.

Both operands can only be the Boolean type.

The result of the expression will be the Boolean type.

!operand

The operand can only be the Boolean type.

The result of the expression will be the Boolean type.

~operand

The operand can only be integer.

The result of the expression will be integer.

condition? operand1 : operand2

Both operands must be the same data type. They can be integers, string, or Boolean.

If the condition is true, the value and data type of operand1 become the result of this expression.

If the condition is false, the value and data type of operand2 become the result of this expression.

variable = operand

The value of an operand can be assigned to a variable only if they have the same data type. The possible data type can be integers, string, and Boolean.

In MTL, a variable gets its data type at its initial time, same to the initial value's data type. After that, the data type of the variable cannot be changed.

To learn more details about variable, see Variables.

array assignments

You can assign a value to an array element only if the data types of the value and of the array are the same. The possible data type can be integers, string, and Boolean.

In MTL, an array gets its data type at the initial time, same to array element initial values' data type. After that, the data type of the array cannot be changed.

To learn more details about array assignments, see Defining MTL arrays.

Example

The following examples demonstrates you data types for variables in the APG program file.

a="hello";    //The data type for a is string.
a=5;        //Error, because a has been a string variable and cannot be assigned with an integer value.

b="hello";    //The data type for b is string
b=b+1;        //The value for b becomes to "hello1" 

c=(1==1);    //The data type for c is Boolean.
d=c?1:0;    //The value for d is 1, and the data type for d is integer.

arr[3]={1,2,"hello"};    //Error, because the array is assigned with values of different data types (integers and string).
