EVENT_FDM.averages()

Sets the number of internal DC measurement samples for hardware based averaging.

Syntax

EVENT_FDM & averages(const EVENT_VALUE_INT & samples);
Parameter
Parameter Description
samples Number of internal samples from which the average is created.
Return value
A reference to the corresponding EVENT_FDM object.

Example

For an example see EVENT_FDM.

Related information
