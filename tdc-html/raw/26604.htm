Topic 26604

ExecMonitor

This routine allows you to program the Monitor from a test flow program. The settings you make control the Monitor behavior or execute specific Monitor functions. The ExecMonitor routine provides a subset of Monitor capabilities available in the interactive environment.

Syntax

VOID ExecMonitor(
 UINT16  FuncType, 
 CHAR *Parameter, 
 INT32 *ExecReturn);

Parameters

Parameters for ExecMonitor

Parameter

Value

Description

FuncType

TM_CONTROL_MONITOR

Lets you program the Monitor.

 

TM_RESET_MONITOR_

STATUS

Lets you reset the test system Operation state displayed in the report window. After reset the state is updated with the actual Monitor state.

 

TM_UNLOCK_TESTER

Lets you unlock the test system. Executes Connect and Disconnect after you have locked the test system.

Parameter

 

A string containing the information necessary to execute the required Monitor function.

 

Monitor type

Specifies Monitor function (see the table below).

 

Monitor settings

Settings you can make when programming the Monitor (see the table below).

ExecReturn

 

Monitor function execution state.

 

TM_SUCCEED

Monitor function successfully executed.

 

TM_BAD_FUNC_TYPE

Incorrect function type entered.

 

TM_BAD_PARAM_S_

SYNTAX

Incorrect parameter string syntax used.

 

TM_PARAM_S_TOO_

LONG

Parameter string is too long.

 

TM_POLL_TIME_OUT_OF_RANGE

Entered Poll Time is out of the allowed range.

 

TM_SOFT_ALARM_OUT_OF_RANGE

Entered Soft Alarm is out of the allowed range.

"minute(s)"

"month(s)"

"year(s)"

<high soft alarm value>

 

set limit for "CalAge"

time since last cal; range is 0.0 ... 7884000.0 seconds (1/4 year)

set limit for "BoardTempr"

positive temp. delta in range 0.0 ... (2.5 - max cal. temp. delta/2) [C]

set limit for "DpsCurrent"

% value of programmed current limits of all DPSs in range 0.0 ... 1.0

<low soft alarm value>

set limit for "BoardTempr"

negative temp. delta in range

(-2.5 + max cal. temp. delta/2) ... 0.0 [C]

<soft alarm unit>

"second(s)"

"minute(s)"

"hour(s)"

"day(s)"

"week(s)"

"month(s)"

"year(s)"

set unit of soft alarm limit for "BoardTempr"

 

"C" (celsius)

"K" (kelvin)

"F" (fahrnheit)

set unit of soft alarm limit for "DpsCurrent"

"A" (Ampere)

<lock tester enable>

set "lock_enable" / "lock_disable" (used for DPS Current only)

"lock_enable" or " lock_disable"

Example

INT32 ExecReturn;

ExecMonitor(TM_RESET_STATUS,"",&ExecReturn);
ExecMonitor(TM_CONTROL_MONITOR,"CalAge;enable;\
           1;day(s);4.0;month(s)", &ExecReturn);
ExecMonitor(TM_CONTROL_MONITOR,"BoardTempr;enable;\
 2.0;-2.0;C",&ExecReturn);
ExecMonitor(TM_CONTROL_MONITOR,"DpsCurrent; \
            enable;10.0;second(s);0.8;A;\
            lock_enable",&ExecReturn);
