Topic 343353

Controlling burst site upload

Subtopics

  1. digCapBurstSiteUpload()

SmartRDI supports "burst site upload" capacity for DC and digital capture results.

The data upload time for high site counts but low data sizes is mainly influenced by the FW query per site. The "burst site upload" capacity uploads all results over all sites by one FW query to achieve a better throughput.

SmarTest 7.4.2.1 provides a new capability to perform "burst site upload" for digital capture results. SmartRDI 2.4.5.1 supports this capability with options to enable and disable it:

  • The keyword DIGCAP_BURST_SITE_UPLOAD in RDI_Configure file provides a global control of enabling and disabling "burst site upload" for digital capture results.
  • The test method digCapBurstSiteUpload() provides a local control which overwrites the global control setting.

SmarTest 7.4.3 supports the upload of DC results over sites in one burst. SmartRDI 2.5.0 supports this capability with an option to enable and disable it:

  • The keyword DC_BURST_SITE_UPLOAD in RDI_Configure file provides a global control of enabling and disabling "burst site upload" for DC results.

Functional changes

  1. Introduced in SmartRDI 2.5.0
