Topic 56462

Installing licenses

If I accidentally enter the wrong hostid number in the redemption process, what will happen?

  • You should be very careful when entering the hostid in the activation form, as a mistaken entry will result in your license being inoperable. When you attempt to start SmarTest, an error will be returned that indicates no licenses are available. If this occurs, you will need to contact your Advantest sales representative to reinstall the hostid. This can be a time-consuming process.

Do I have to reboot after I installed a license?

  • You should restart SmarTest. You do not need to reboot the computer or test system.

How do I determine the version of the license daemon or lmgrd I am using?

  • Use the lmver command that comes with the lmutil license management system. See lmutil lmver.

Where do I download the latest versions of lmgrd and lmutil?

  • Download the latest versions from the Advantest site: V93000 SOC/HSM Licensing.

How do I activate my licenses?

  • Follow the process explained in the FLEXlm License Overview and License Server Guide chapter of the LTH/STH Site Planning and Preparation Guide.

How should I select a license server?

  • Read the FLEXlm License Overview and Server Selection Guide chapter of the LTH/STH Site Planning and Preparation Guide, or chapter 4 of the FLEXlm End User Guide.

What is the "model file"? How does it work?

  • The model file is an ASCII file that you must edit in order to define scalable hardware parameters, such as speed and memory, that will be used for the current DUT. When you start SmarTest, the software checks the model file and the hardware to ensure hardware compatibility and that enough licenses are available for the designated test program.

What is "multiple server redundancy"?

  • Multiple server redundancy means using more than one computer as license server, to protect against production interruptions that might occur if you rely on a single server. Multiple servers are more complex to manage than single server operation. See the FLEXlm License Overview and License Server Guide chapter of the LTH/STH Site Planning and Preparation Guide, or chapter 4 of the FLEXlm End User Guide for more detail.
