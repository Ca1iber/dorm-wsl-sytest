rdi.func().readMatchPassFail()

This function returns true if a match is found on the specified pin.

Syntax

rdi.func().readMatchPassFail(string pin)

Example

rdi.func("mch").label("abc").readMatchPassFail("pinA").readMatchCount("pinA").execute();

Related information

rdi.id().getMatchPassFail()

Functional changes

  1. Introduced in SmartRDI 2.4.0
