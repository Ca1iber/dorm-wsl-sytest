Explicit setting of termination mode for standard/single-ended

The differential termination modes must be set explicitly in the equation based level setup file with the keyword "term". In addition, the single-ended termination modes can also be set explicitly with the keyword "term" as opposed to implicitly as described in Implicit setting of termination mode for standard/single-ended.

The line containing the keyword "term" must immediately follow the line with the key word "PINS".

The syntax for the keyword "term" line is

term <termination_mode_str>
