Topic 30724

diagnostic_check

Subtopics

  1. Associated Syntax Entities

This expression is used in conjunction with MONITOR_CALL, and enables you to check if the diagnostics have been done or not. You would typically have this expression at the beginning of your application model file.

The line,

diag_done = MONITOR_CALL (diagnostic_check);

checks to see if diagnostics have been done. The result will be a simple yes or no that can be seen, for example, in Report window or in the log file CompleteSystem.slg (usually under /opt/hp93000/soc/system/log/).
