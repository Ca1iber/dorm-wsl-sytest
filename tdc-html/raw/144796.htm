DPS_AUX_PIN_TASK.checkSetRangeError()

Automatic down‑ranging in DC measurements can fail if the target current measurement range cannot be set. In this case a latched status flag "Measurement range change failed" is set, which can be read by this member function.

Used in DC test with DPS128 or XPS256 cards.

This member function retrieves the status flag from all active sites, resets the flag and stores the read status in the test method cache. The API should be called within the ON_FIRST_INVOCATION block.

Note

Pass/fail results that are retrieved by command PRLT are invalidated by commands CSAS and PSAS.

We recommend therefore using the command PRLT directly after the related functional test and before command CSAS or PSAS are performed.

This behavior applies not only to the commands but also to the related APIs: Function GET_FUNCTIONAL_RESULT() must be performed before any of the DPS_AUX_PIN_TASK.check...() functions is called or the results of GET_FUNCTIONAL_RESULT() are invalid.

Syntax

DPS_AUX_PIN_TASK & checkSetRangeError();
List of parameters
There are no parameters.
Return value

A reference to the corresponding DPS_AUX_PIN_TASK object.

For retrieving the read result see DPS_AUX_TASK.getRangeError().

Example

DPS_AUX_TASK auxTask;

ON_FIRST_INVOCATION_BEGIN();

    auxTask.pin("dps2").checkSetRangeError();

ON_FIRST_INVOCATION_END();

if ( auxTask.getRangeError("dps2") == TM::AUX_TASK_STATUS_PASS )
{
    cout << "auxTask.getRangeError(\"dps2\") returned TM::AUX_TASK_STATUS_PASS" << endl;
}
else
{
    cout << "auxTask.getRangeError(\"dps2\") returned TM::AUX_TASK_STATUS_FAIL" << endl;
}
