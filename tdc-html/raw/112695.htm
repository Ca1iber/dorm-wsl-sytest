Topic 112695

Exporting information

The BFM Viewer can export a variety of information in graphical and textual formats.

About this task

In particular, these export options are available:

  • Exporting chip overviews and detail views as PNG graphic files
  • Exporting the currently loaded bit fail maps as a combined ASCII file
  • Exporting the list of failed cells as a tab-delimited text file

Exporting information is useful to visualize data (for example, to share it with others) or to further process some of the data with other tools.

Before you begin

Set up the data you want to export as desired. Details are included in the individual procedures as their first steps.

Procedures

Exporting the chip overview or a detail view as a graphic

  1. To set up the view that you want to export:
    • Set the filters as desired.
    • Set the colors and other display options as desired.
    • Mark and unmark cells and choose whether to display these markers and their labels.
  2. In the view you want to export, right-click and choose Export from the shortcut menu.

    A standard Save dialog is displayed.

  3. Enter a name for the file, choose a location for it, and click Save.

The view is saved to disk as a PNG file.

Exporting the bitmaps as an ASCII file

  1. To set up the bitmaps that you want to export, load them into the BFM Viewer.

    The order of the bitmaps in the layers is unimportant for purposes of exporting them.

  2. Choose Extras > Save ASCII Bitmap.

    A standard Save dialog is displayed.

  3. Enter a name for the file, choose a location for it, and click Save.

The loaded bit fail maps are exported as a combined ASCII file. The file contains a dot (.) for areas where there are no faults on any of the layers and a hash mark (#) for areas containing at least one fault on at least one layer.

Exporting a list of failed cells

  1. To set up the list of failed cells:
    1. Load the bit fail maps into the BFM Viewer.
    2. Set the Analyze All option and the maximum number of listed failed cells.
    3. Activate the failed cells list, if needed.
    4. Choose the desired display options for the list (type of address displayed, hexadecimal or decimal format).
  2. Right-click anywhere in the Failed Cells List and choose Export.

    A standard Save dialog is displayed.

  3. Enter a name for the file, choose a location for it, and click Save.

The displayed failed cells are saved as a tab-delimited text file.

Results

The respective information has been saved as a file to disk, as described above.
