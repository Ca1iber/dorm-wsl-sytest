Fail bit count shmoo test method

This test method (MTP_FailBitCountShmoo.Execute) shmoos a memory test to display the number of fail bits at every specified (x, y) on a shmoo plot.

It can display the number of fail bits of:

  • An entire memory DUT
  • Any bank of a memory DUT
  • Any dq pin (a bidirectional data pin) of a memory DUT

The parameters of this test method include the parameters of the Shmoo test method and the ExecutionEngine test method:

  • The parameters of the Shmoo test method will construct a shmoo plot which contains the plot title, the axes and the results to be displayed.

    To set up these parameters for fai bit count shmoo tests, refer to the description in Shmoo except for these parameters:

    • shmooTestSuite: Do not enter a test suite name.
    • x.setupPins and y.setupPins: Select @ (all pins) only.
    • testMode: You can choose:

      fail bit count on device: Displays the number of fail bits of an entire memory DUT at every specified (x, y) on a shmoo plot.

      fail bit count per bank: Displays the number of fail bits of a bank at every specified (x, y) on a shmoo plot .

      fail bit count per dq: Displays the number of fail bits of a dq pin (a bidirectional data pin) at every specified (x, y) on a shmoo plot.

    • resultPins: The selected pins must include the dq pins. Otherwise, you will not see the number of fail bits on the shmoo plot.
    • perPinResult: You will not see this parameter.
  • The parameters of the ExecutionEngine test method will execute a memory test and count the fail bits.

    To set up these parameters for the fail bit count shmoo tests, refer to the ExecutionEngine test method. And you must:

    • Enable the parameters Create_Bitmap and Fail_count_enabling.

Viewing the results of fail bit count shmoo tests

You can:

  • Create a test suite with this test method in a testflow, and view the outputs in the report window.

    To create the test suite, see Inserting a test suite into a testlfow.

    To view the result in the report window, see Logging shmoo tests in the report window and Shmoo output of the Event Formatter.

  • Use the Shmoo Tool to set up a fail bit count shmoo test with this test method and view the plot.

    For details, see Setting up a shmoo test in the Shmoo Tool and Viewing fail bit count shmoo plot.
