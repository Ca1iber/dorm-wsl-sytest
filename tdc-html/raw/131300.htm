The MTP_FUNC_TASK class provides an API for executing a functional test.

MTP_FUNC_TASK provides the same function as the FUNCTIONAL_TEST API. But FUNCTIONAL_TEST cannot be used for driver sharing test since the multiple executions will overwrite the previous results.

Note MTP_FUNC_TASK is available only for MTP.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/MTP_FUNC_TASK.h.
