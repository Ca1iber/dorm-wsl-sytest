Topic 19975

For Sequential Capturing

  • Capturing starts with the first vector and ends with the last vector of the main pattern. For each vector, the result data of each capture pin will be captured once per capture edge. That is, at edge 1 in Standard Resolution Mode, and at edge 1 and edge 4 in Double Resolution Mode.

    In other words, for each capture edge one sample is taken.

    If n capture pins are defined, the n samples of these pins taken at edge 1, together form one n-bit sample of one vector. In Double Mode, the n samples taken at edge 4, form a second n-bit sample of that vector.

    Thus, in Standard Resolution Mode the number of n-bit samples that will be taken is equal to the number of executed vectors.

    In Double Resolution Mode the number of n-bit samples is twice the number of executed vectors.

  • If you have vectors at the beginning of the label to set the device to a certain state, samples will also be taken for these vectors. You can disregard these samples later on, when analyzing the captured data, by defining the initial discard of the vector variable which is used to retrieve the captured data for further processing. (See Setting up a Vector Variable for information about how to set up the initial discard).
