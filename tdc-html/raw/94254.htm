Topic 94254

Defining a context

Before you begin

Make sure that the setup perspective is opened.

Procedure

  1. In the Test Program Explorer View, right-click Pin Setting and select Add Context.

    The Add Context window opens.

  2. Select the context on which you want to base the new context.

    The pins in the new context will have the same IO types and operation modes as in the selected existing context.

  3. Type a context name in the New Context text box.

    In this example, we enter the name differential.

  4. Click OK.
  5. Apply the data and save the pin configuration file.

Results

In the Digital Pins editor, you can see in the Context list, there are two options: DEFAULT and differential.
