Adding a special test suite

Special test suites do not appear as nodes in the Flow Sequence Editor, but in the Flow Data Editor, they are displayed at the end of the Test Suites page when sorting by default.

The seven types of special test suites are described in Special test suites.

  1. In this window, select one of the three option buttons according to the executed test type: Test Method, Test Function, or User Procedure.
  2. Type the test suite name in the Test Suite Name text box.
  3. Select the test to be executed in the test suite. Selecting a test differs depending on the type of test suite. For details on this, see Inserting a test suite into the testflow.
  4. Select the timing setup components, level setup components, and the analog set by clicking on the left of the text box. The descriptions for the setup component are displayed in separate windows.
  5. Select the pattern.
  6. Enter the context (see Context)
  7. Click Finish.
