Set fixed clamping levels

To set the low and high voltage levels for the clamps of the specified pins you can use either the CLMP or the TERM command. The levels will become part of the level set you specify.

For details see CLMP, CLMP? - (CLaMP level) and TERM, TERM? - (TERMination mode).

Use the CLMP command if you want to set the clamps independently from the termination mode.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.1: Added information on clamps for Pin Scale 9G cards
