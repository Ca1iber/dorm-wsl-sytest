LAN communication flow for OSAI handlers

This section describes the LAN communication between the driver and the handler. The actions and messages are listed in sequential order.

See Conventions for GPIB/LAN communication for the syntax description.

LAN communication flow for OSAI handlers
Message from driver Message from handler Description
Lot start:
n|SOL The handler sends the lot start command.
n|SOL=Lot_ID=1... The driver sends the lot information to the handler.
n|ASK_START=LotID:1... The handler asks for the confirmation.
n|ASK_START=OK The driver replies with OK. Otherwise, the driver replies with ERROR and aborts the execution.
Wait for device:
n|TESTSITES=X_001+X_... The handler sends the information of test sites.
n|TESTSITES=OK|ERROR The driver replies the result after parsing the site information. The driver will reply ERROR if the site information is not correct and abort the test execution; or end the lot when it has received the lot end command while waiting for devices.
n|START The handler sends the test start signal.
n|START=OK The driver replies with OK. If it has received an unexpected message, it will abort the test.
Test result:
n|TESTRESULTS=... The driver sends the result to the handler.
n|TESTRESULTS=... The handler echos the driver command.
n|TESTRESULTS=OK|ERROR The handler sends the final result to the driver. If it is OK, the driver will continue the testing. If it is not OK, the driver will abort the testing.
Lot end:
n|EOL The handler sends the command to end the lot.
n|EOL=OK The driver replies with OK to confirm the end of lot.
Pause and resume:
n|COMMAND=PAUSE

n|COMMAND=RESUEME

 The driver sends the pause or resume command to stop or restart the handler.
n|COMMAND=PAUSE

n|COMMAND=RESUEME

 The handler echos the pause or resume command.
n|COMMAND=OK|ERROR The handler returns the OK or ERROR result to the driver.
n|COMMAND=OK|ERROR The driver echos with OK or ERROR. The driver sends warning if the command result is not OK.
Status query:
n|STATUSH The driver sends the status query command to the handler.
n|STATUSH The handler echos the driver command.
n|STATUSH=... The handler returns the query result to the driver.
n|STATUSH=... The driver echos the result.
Set thermos temperature:
n|SET_THERMOSTEP=... The driver sends the temperature-control sequence command to the handler.
n|SET_THERMOSTEP=... The handler echos the command.
n|SET_THERMOSTEP=OK|KO|ERROR... The handler returns the setting result.
n|SET_THERMOSTEP=OK|KO|ERROR... The driver echos the result.

The driver will abort the execution if one other result except for OK is returned.
n|THERMOSTEP_RES= The handler returns the final result to the driver.
n|THERMOSTEP_RES= The driver echos the final result.
Query thermos temperature:
n|QUERY_THERMOSTEP=... The driver sends the query command to the handler.
n|QUERY_THERMOSTEP=... The handler echos the command.
n|QUERY_THERMOSTEP=... The handler returns the query result to the driver.
n|QUERY_THERMOSTEP=... The driver echos the result.
