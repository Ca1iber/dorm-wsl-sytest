iClamp()

Specifies the high and low clamp current for DC Scale pins.

The function can be used in the code‑based mode and in the pattern‑based mode.

Each DC supply requires a minimum clamp current to work properly. If necessary, SmarTest automatically adjusts the clamp current settings to the minimum value that is normally defined in the specifications and displays the following warning in the UI report window:

Clamp current limit is smaller than minimum value and will be auto-corrected.
For the minimum clamp current distance, refer to
  • DPS128 / DPS64 specifications and Clamping and forcing current in DPS128 / DPS64 functionality and features
  • Minimum clamp current distance in XPS256 programming - Force and clamp currents

Change range in pattern‑based mode (XPS256)

The force or clamp range of DC Scale XPS256 pins can be changed without disconnecting the channel. In pattern‑based mode, the correct sequence of changing the range and the value must be applied to avoid range overflow warnings.

For more information refer to iForceRange() or vForceRange().

Syntax

dcBase& iClamp(double iClamp);

Syntax for applying different values for the lower and upper clamp current:

dcBase& iClamp(double iClampLow, double iClampHigh);

Syntax for a clamp current waveform:

dcBase& iClamp();

Syntax for changing the clamp current at runtime:

dcBase& iClamp(const string& runTimeId_iClamp);
dcBase& iClamp(const string& runTimeId_iClampLow, const string& runTimeId_iClampHigh);
Syntax for XPS256 HAC IF mode in DC SIG mode:
dcBase& iClamp(double iClampLow, double iClampHigh, TA::DCS_IF_MODE mode);
dcBase& iClamp(double iClamp, TA::DCS_IF_MODE mode);
dcBase& iClamp(const string& runTimeId_iClampLow, const string& runTimeId_iClampHigh, TA::DCS_IF_MODE mode); // For runtime
dcBase& iClamp(const string& runTimeId_iClamp, TA::DCS_IF_MODE mode); // For runtime
List of parameters

Parameter

Description

iClamp

Defines the clamp current in Ampere.

The lower (or sinking) clamp current and the upper (or sourcing) clamp current are set to the same (absolute) value for cards that support different values: XPS256.

For DPS128 and DPS64, this parameter sets one side clamp. If the iClamp value is positive, it sets the sourcing clamp; otherwise it sets the sinking clamp.

iClampLow

iClampHigh

The parameters define the lower (or sinking) clamp current and the upper (or sourcing) clamp current in Ampere.

The parameters are supported only for the DC Scale cards DPS128/64 and XPS256.

runTimeId_iClamp

runTimeId_iClampLow

runTimeId_iClampHigh

The string parameters refer to single double values or arrays of type ARRAY_D that have been assigned by function runTimeVal() and are filled with the clamp current values.

For more information refer to Changing the parameter value at run-time with SmartRDI.

These parameters are only for DC Scale pins.
mode Specifies whether to clamp the current in the high accuracy current force mode TA::HAC. It is only for XPS256 cards.

Examples

RDI_BEGIN()

    rdi.dc().pin("dcScalePin_1")
            .vForceRange(10 V).vForce(5.0 V)
            .iForceRange(20 mA).iClamp(10.0 mA)
            .execute();

    rdi.dc().pin("dcScalePin_2")
            .vForceRange(10 V).vForce(5.0 V)
            .iForceRange(20 mA).iClamp(-2.0 mA, 15.0 mA)
            .execute();

RDI_END();
The TA::HAC parameter defines a HV channel in the DC SIG mode.
rdi.dc().pin("A").iClamp(1,2,TA::HAC).execute();
rdi.dc().pin("B").iClamp(1,TA::HAC).execute();
