Values

To query the list's values, the syntax is:

DDEF? "ListName","Values"

Example

1. If list A is defined as

DDEF "A",SET,"Equation","Loop(3,4,5)"

then DDEF? "A","Values" will return:

DDEF "A",DATA,"Values",##9000000042 3.000000e+00      4.000000e+00 5.000000e+00

2. If list A is defined as

DDEF "A",SET,"Equation","RepeatValue(0x55555555,2)"

then DDEF? "A","Values" will return

DDEF "A",DATA,"Values",#9000000042 55555555 55555555

Functional changes

  1. Introduced before SmarTest 6.3.2
