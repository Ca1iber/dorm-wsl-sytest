Topic 16938

Pin timing resource (pin_timing_resources)

For 6-edge setups

e1 to e6

Edge identifiers. These must not be duplicated within a pin list. If they are, an error is reported.

expression

See Syntax of expression.
Note Each of these resources can only be defined once for each pin.

For 16-edge setups

d1 to d8 and r1 to r8

Edge identifiers. These must not be duplicated within a pin list. If they are, an error is reported.
