Topic 144008

Utility Purpose view

The Utility Purpose view allows you to apply utility purpose, which you defined previously in the pin configuration.

An Utility purpose is defining some values for a subset of utility lines. After applying the utility purpose you can check the specified values in the Utility Line view. Depending on your configured preferences, you need to refresh it.

Note The Utility Purpose view sets a defined utility purpose, but it does not recognized what or if an utility purpose is set.
