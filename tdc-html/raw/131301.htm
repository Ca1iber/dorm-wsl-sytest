Topic 131301

MTP_FUNC_TASK.pin()

The pin() member function of MTP_FUNC_TASK lets you specify the pins whose functional test results you want to retrieve.

Syntax

void pin(const string & pinname)

Parameter

Description

pinname

The names of the result pins. Multiple pins are separated by commas.

Related information

MTP_FUNC_TASK

Functional changes
