Defining pin groups

When the individual pins have been fully defined, you may want to assemble groups of pins. This lets you perform any actions on all pins within the group with one statement. There are two types of pin groups, fixed groups and expression based groups.

Fixed groups are defined by specifying a list of pins. Expression based groups are built up from existing pins or pin groups, or from a mixture of pins and pin groups, by basic set operations. Fixed groups are called "fixed" because they do not depend on other groups, whereas the expression based groups are automatically changed if one of the fixed groups from which they are ultimately built up is changed.

Individual pins can be included in more than one group. For example, an io pin can be included in both an input and in an output pin group. Pin groups are not supported for DPS pins and analog pins.

Fixed groups

Fixed groups are defined with the DFGP command. Every fixed pin group has a type. The following types are supported for fixed groups:

  • I: input group
  • O: output group
  • DC: DC measurement pins
  • X: pins of any type

An I group is expected to contain only i or io pins, an O group should contain only io or o pins. However, DFGP performs no plausibility check with respect to the group type. You can add, for example, an output pin (type o) to an input pin group (type I) without any objection from the firmware. Internally, however, SmarTest proceeds as usual, and considers only the pins that fit the group type in any action on the group.

Expression based groups

Expression based groups are defined with the DFGE command. As with fixed pin groups, every expression based group has a type. The following types are supported for expression based groups:

  • I: input group
  • O: output group
  • IO: bidirectional pins
  • DC: DC measurement pins

The above remarks about plausibility checks for and processing of heterogeneous pin groups also hold for pin groups defined with DFGE.

The format of the expression can be inductively defined as follows:

  1. A pin name or pin group name is a legitimate expression.
  2. If ex1 and ex2 are legitimate expressions, then ex1 + ex2 (set union), ex1 * ex2 (set intersection), and ex1 - ex2 (set difference) are also legitimate expressions.

Note that if you want to inspect the member pins of an expression based pin group, you must use DFGP?, not DFGE?. DFGE? will return the defining expression for the group.

Deleting group definitions

The UDGP command serves to delete both fixed and expression based group definitions.

Example

The following example contains both fixed and expression based pin group definitions:

> DFGP X,(SI1,SI2,SO1,SO2),(SCAN)
> DFGP O,(O1,SO1,SO2),(OUT)
> DFGE O,"SCAN * OUT",(SCAN_OUT)
> DFGE? (SCAN_OUT)
< DFGE O,"SCAN * OUT",(SCAN_OUT)
> DFGP? (SCAN_OUT)
< DFGP O,(SO1,SO2),(SCAN_OUT)

The DFGE command defines SCAN_OUT as the intersection of SCAN and OUT.
