Topic 343352

digCapBurstSiteUpload()

Provides a local control over the "burst site upload" capacity for digital capture results.

Syntax

digCapBurstSiteUpload(bool digCapBurstSiteUpload);
List of parameters

Parameter

Description

digCapBurstSiteUpload

Whether to use burst site upload for the following digital capture test. It can be true or false. The default value is false.

If it is set to true, the maximum sample number is 8192.
List of available options of parameter: hwDecimation

Option

Description

true

Use burst site upload.

false

Do not use burst site upload.

Example

rdi.digCapBurstSiteUpload(true);
RDI_BEGIN();
  rdi.digCap(1).pin("DATA1").samples(1024).execute();
RDI_END();

Functional changes

  1. Introduced in SmartRDI 2.5.0
