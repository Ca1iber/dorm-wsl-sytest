Topic 136496

Viewing the shmoo plots of different sites

In the Shmoo Tool, to view the shmoo plot of another site, use the Site Control Window to change the site.

About this task

The shmoo test for a multisite testflow is a multisite shmoo test as well. After execution, you can view the shmoo plots of different sites.

Before you begin

  • Make sure the loaded testflow is multisite.
  • Set up a shmoo test in the Shmoo Tool, or set up a shmoo test suite in the testflow.

Procedure

  1. To view the shmoo plot of each site, in the menu bar of SmarTest, select 93000 > System > Site Control.

    The Site Control Window opens.

  2. In the Site Control window, enable and active all sites, and focus on your desired site (you only can focus on one site). For Details, see Site Control Window.
  3. If you have created a shmoo test suite in the testflow, transfer the shmoo test suite to the Shmoo Tool.
  4. Execute the shmoo test with the Shmoo Tool.

    The shmoo plot of the current site is displayed in the Shmoo Tool. The corresponding site number is displayed in the plot title.

  5. To view the shmoo plot of another site, change the focused site in the Site Control Window.

    The shmoo plot of the new site replaces the previous shmoo plot in the Shmoo Tool. The new site number replaces the previous site number in the plot title.

What to do next

You can:

  • Overlay shmoo plots of the multiple sites.
  • Zoom the shmoo plot.
  • Select and magnify an area of the shmoo plot to view.
  • View different types of test results on the shmoo plot.
  • View the shmoo plots of different result pins.
  • Take a picture of the shmoo plot and its setups.

Functional changes

  1. Introduced in SmarTest 7.2.0
