Topic 107052

Console view

Subtopics

  1. Console view: System console
  2. Console view: Data log console
  3. Console view: C-Build console
  4. Test method debugger default console

The console view shows the system output message, data log message, test method building message, test method debugging message and other SmarTest output messages in different consoles.

On the console view toolbar, click the drop down menu icon to select the output of the console:

  • Default outputs:
    • Datalog
    • System
  • When working with test methods:
    • C-Build
    • Test method debugger default
Note Click the icon to toggle between the two most recently used outputs.

Functional changes

  1. Introduced before SmarTest 6.3.2
