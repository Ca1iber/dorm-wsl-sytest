Binary to ASCII Conversion

Many of the setup files used by the SmarTest software are originally created using the ASCII interface. The ASCII interface converts ASCII timing and vector files into binary files. Since it is often more convenient to work with files in the ASCII format, the binary to ASCII conversion tool (b2a) has been developed to provide the capability to convert binary timing and vector files into ASCII files. This is especially useful if the binary files created using the ASCII interface are subsequently modified, or if the original ASCII files are no longer available. After the ASCII files produced by the b2a tool have been modified as needed, they can then be converted back into binary files using the ASCII interface.
