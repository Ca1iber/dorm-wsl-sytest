Setting pin configuration

Setup the general pin configuration using the SmarTest software as described in the procedure below.

  1. Define the pins in "FAST" context using the pin names in the example table below.

    Digital signal groups with same functionality

    The DQ data pins are mapped to different pogo pins for input and output definitions due to the dual transmission line used.

  2. Define the additional pins:
    • Digital pins: RESET and VREF
    • DPS pins: VDDA,VDDQ, and VDD.
  3. Set up the digital signal pin groups with same functionality using the pin group names in the example table above.
  4. Set up the digital source synchronous data signal pin groups using the pin names in the table below.
