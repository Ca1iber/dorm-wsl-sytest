EVENT_WAVEFORM_ICIM.getRepeatCount()

Queries the number of repeats of the waveform.

Syntax

void getRepeatCount(INT & repeats) const;
Parameter
Parameter Description
repeats

The number of times the waveform is repeated.

Note: The getRepeatCount() member function of DC events returns always 1 as repeat count.

Return value

Number of repeats of the waveform.

Example

For an example see EVENT_WAVEFORM_ICIM.
