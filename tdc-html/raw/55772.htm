There are two kinds of DSM setups:

  1. The source data is downloaded to the DSRC label, and the MAIN label sources data from the DSRC label. This is normal setup.
  2. The source data is downloaded to the MAIN label. This setup is called FLAT setup.

This section introduce the DSM normal setup.

You can define the pin and port configuration, vector variable configuration and usage, and MAIN label for a Digital Source Memory test with the standard setup tools of SmarTest.

The setup for DSM, using the DSRC label, requires some additional settings, such as the definition of the port from which you want the data to be sourced, and the setup of a vector variable configuration which defines how the data of interest is stored in source memory.

The normal sequence for the setup of Digital Source Memory is:

  1. Define the pins and port for sourcing (Tool: Pin Configuration Tool). See Pins and port for Digital Source Memory
  2. Define the Timing and Levels (Tool: Timing and Level Setup Tool). See Timing and Levels
  3. Create a MAIN label and a DSRC label, which is for Digital Source Memory in the sequencer or vector memory. (Tool: Pattern Tool). See Defining the MAIN Label and Defining the Source Label.
  4. Define the vector variable configuration and its usage for the DSRC label (Tool: Pattern Tool). See Creating a Digital Source setup.
  5. Download the waveform data to the vector variables (Tool: Signal Analyzer, Test Methods). See Downloading the waveform data to the vector variables.
  6. Enter the vector and the proper sequencer instructions in the MAIN label (Tool: Pattern Tool). The Wizard automatically adds the STARTSOURCE (SSRC) instruction at the top of the label. SOURCE (SRCV) instructions need to be added manually. See Entering the vectors in the MAIN label.
  7. Run the MAIN label for the test.
