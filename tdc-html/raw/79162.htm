Topic 79162

Model file error messages

Subtopics

  1. Parser syntax error
  2. Feature dependency error
  3. Hardware error
  4. License number error

Model file error messages, also called IOCHANNEL error messages, belong to one of four types:

  • parser syntax error
  • feature dependency error
  • hardware compatibility error
  • license number error

These error types are explained in the topics of this section, along with the steps to correct the problem.

Functional changes

  1. Introduced before SmarTest 6.3.2
