TESTSET().testsuite()

This member function of TESTSET lets you specify a test suite for determining the limits and the test numbers as well as for logging purposes.

The limits and test numbers for the executed test are taken from the specified test suite (instead of the default test suite). The specified test suite is is also logged in the TestSuiteNameAttrType attribute of a TestEventType value instead of the default test suite.

Syntax

TESTSET & testsuite(const STRING &name);

Parameter

Description

name

The name of the test suite that you wish to use as the source for test limits and test numbers and include in the data log.

Note that the test suite name must be listed in the test table.

Example

TestSet.testsuite("Functional_test");

Related information

TESTSET
TESTSET().testsuite_default()

Functional changes

  1. Introduced in SmarTest 6.5.3
  2. SmarTest 7.2.1: The specified test suite now also provides the limits and test numbers
