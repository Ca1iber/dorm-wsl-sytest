Release information

Informs you about the software support for new products, newly added features and functionalities as well as on provided defect fixes. Advantest provides support and maintenance over stated time periods for all SmarTest release streams.

  • To download SmarTest software and Release Notes, go to Software Information and Download.
  • For information on how to transition test programs to new enterprise releases, see Test Program Conversion tools.
  • For maintenance release notes like calibration and diagnostic changes see Maintenance Release Information.
  • For release notes see the table below.

You can access the Release Notes also from SmarTest Help > About SmarTest Eclipse Workcenter > Release Notes.

Pin Scale 5000 card The Pin Scale 5000 is a high-density universal digital card suitable for all SOC test applications.

The card builds on the latest test processor technology, improving the memory and data-rate capabilities as well as the density. It can reside in any card slot of a V93000 EXA Scale based test system.

RDI enhancements
  • When masking sites, selected sites can be held in a certain state.
  • Digitizer upload times can be reduced by skipping a number of initial samples.
  • Propagation delay measurements are supported.
  • DC waveform support has been improved
  • The performance of initial waveform downloads has been improved.
  • Alarms on pins using runTimeVal() are supported and multiple result retrieval commands are implemented.
  • Analog waveform content can be logged.
