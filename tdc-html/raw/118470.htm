Topic 118470

Pattern Debug Tool preference page

You can change the following preferences on the V93000 > Pattern Debug Tool preference page.

Area

Option

Description

Editor

Use advanced Find/Replace Dialog

Specify whether the advanced Find/Replace dialog is opened when you right-click the Pattern Editor and select Find/Replace.

 

Do not warn if edit and active wave form table are different

Specify whether to warn or not when using different wavetables for editing and test execution. See also Function of the base wavetable.

 

Enable Point Marker Annotations display and navigation

Specify whether to display and navigate the point marker annotations.

 

Maximum number of annotations

Specify the maximum number of the annotations.

 

Maximum number of warning markers

Specify the maximum number of the warning markers.

Multi Page Editor

Hide Port Burst Pages per default

Specify whether to display port burst pages at startup.

 

Hide Sync Group Pages per default

Specify whether to display synchronization group pages at startup.

 

Link selection between pages per default

Specify whether selected items will be automatically highlighted also on other pages of the editor.

Error Annotation Display & Error Marker Usage
  • Do not Use Markers and Annotations
  • Use Markers and Annotations
  • Use Annotations only

Specify whether either one or both annotations and markers are to be used.

 

Maximum number of error markers / error annotations

Specify the maximum number of error markers and annotations.

Functional changes

  1. Introduced in SmarTest 6.5.2
  2. SmarTest 7.1.3: Multi Page Editor options added. Alternate coloring options removed.
