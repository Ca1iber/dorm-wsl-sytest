Multistrobe test methods

  1. Setting up the timing file
  2. Setting up the timing equation
  3. Setting up the wavetables

  5. Parameters for multistrobe test methods

The multistrobe test methods are intended to be used by development engineering for device characterization.

Note The measured data is shown in the report window. To also direct the measured values into the data log you need to set various flags.

To get measured data from the test runs to enable you to analyze the results, you can log the output as explained in Logging TM output.

Functional changes

  1. Introduced before SmarTest 6.3.2
