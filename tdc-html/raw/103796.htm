Topic 103796

Variable access API

Subtopics

  1. GetApplicationVar()
  2. SetApplicationVar()

The application model process saves the value of each variable in the application model file to the shared memory and the external program like test method can access these variables via CPI calls. To maintain the interface compatibility, the level model shared memory is kept in the BLC.

Two APIs are provided to get and set the value of the level model variables. The variables from function call (like PH/EI call) or const value hard-coded are supported.

Functional changes

  1. Introduced in SmarTest 6.5.0
