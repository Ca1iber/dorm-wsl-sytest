Topic 130769

External device power supply (external GPIB DPS)

Subtopics

  1. Configuring an external GPIB DPS

In rare cases an internal DPS may not fulfill your requirements. This might be if your test configuration requires higher voltages, higher currents, or more channels than supported by the internal DPS. Or you may want to apply a DPS from an existing F330 tester setup.

In cases like the above you can configure an external DPS. The configuration of an external DPS follows the programming model of the HP/Agilent DPS types prior to 2005.

Every external DPS must be configured in the DPS section of the model file. For details see also Configuration for DPSs and Analog Modules.

Note When specifying an external DPS you should use a DPS slot number between 9 and 16. Otherwise, if using a DPS slot number between 1 and 8, you would block that slot for any internal DPS that might reside in that slot. The highest possible slot number for an external DPS is 16.
External GPIB DPS configuration in the model file
Below an example entry for the model file. Here the external DPS model HP6624A is assigned to DPS channel 9 and GPIB address 9.
DPS
    9 : type = HP6624A, address = 9

The address in above example is the GPIB address.

Note All supported DPS types are included in the default XML configuration file. You can use those DPS types without modification.

To add new DPS types you must edit the externalGPIB_dps.xml file located in the /opt/hp93000/soc/pws/data/ directory. For a new external DPS follow the syntax of the DPS types already supported.

An external DPS requires a GPIB interface.

For details see Communication with a GPIB interface.

CAUTION Configuring an external DPS requires knowledge and experience. Unintended high voltages may damage your test system or device. Before applying an external DPS, you must thoroughly test your configuration.

There are certain limitations with an external DPS.

  • The programming speed of an external DPS is lower than of an internal DPS.
  • Advantest does not provide hardware support for an external DPS.
  • The V93000 test system supports only HP/Agilent device power supplies existing prior to 2005.

Example

For an example and further details see Configuring an external GPIB DPS and the externalGPIB_dps.readme file at /opt/hp93000/soc/pws/data.
