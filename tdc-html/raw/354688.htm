SmartRDI 7.10.1

This section summarizes software changes including new features and enhancements in SmartRDI 7.10.1.

Changes and new features
Category Description
DC New static commands for setting DC Scale pins:
  • forceDropWarn()
  • hiAccuracy()
  • iClampTimeToAlarm()
  • iClampTimeToDisconnect()
  • loadStepMode()
  • pulldown()
  • returnDropWarn()

In SmartRDI 7.10.1, these member functions only support DC Scale XPS256 card in the PMU operating mode.

iClamp() for DC Scale pin setups supports the HAC IF mode for XPS256 cards.

Supported SmarTest versions

SmartRDI 7.10.1 supports SmarTest 7.10.1.
