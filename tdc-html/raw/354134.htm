SmartProd (0.1.0-14 with PDB 424)

The following table summarizes software changes including new features and enhancements in SmartProd.

Changes and new features
Module Description
TestCell class Two functions:
  • getCurrentTesterVersion(): Retrieve the current SmarTest version.
  • getTesterVersion(): Retrieve all installed SmarTest versions in a list.
SmartMonitor class

In SmartProd 0.1.0-12, consume() supports VERSION SWITCH events. In SmartProd 0.1.0-14, consume() starts to support TESTERSTATUS events.

Therefore, SmartProd can monitor tester hardware configurations for all releases of both SmarTest 7 and SmarTest 8 on the same host workstation.

In online mode, when the SmarTest system is ready, SmartProd will output the information about tester, board, utility line number, and ignored cards and channels that the current SmarTest version does not support.
