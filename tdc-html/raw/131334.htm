MTP_IDD_TASK.pin()

The pin() member function of MTP_IDD_TASK lets you specify the shared or non-shared VDD or VDDQ pins you want to check for IDD test. pin() returns the MTP_IDD_PIN_TASK class object which you use to set up the measurement conditions for these pins.

Syntax

MTP_IDD_PIN_TASK pin(const string & pinlist)

Parameter

Description

pinlist

The list of the VDD or VDDQ pins to be measured in the IDD test. Multiple pins or pin groups are separated with commas.
