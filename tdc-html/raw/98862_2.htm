VTIM? - (Verify TIMing)

The VTIM? (Verify TIMing) query checks if the period and edge timing is the same for all the specified pins in one or all timing sets of a waveform set or equation set. When all timing sets are checked, a positive answer indicates that there is no timing set which has different edge timings or periods for any two of the specified pins; it does not imply that the values are identical for the same pin in different timing sets. The system responds with a 1 if the timing is the same and a 0 if it is not.

In a multi-port setup, the specified pins can belong to more than one port. VTIM? checks for every involved port if one or all timing sets associated with the respective port agree for those pins that belong to the port. Only pins within one port are compared with each other; it is not required for a positive answer that pins belonging to different ports have the same values in timing sets with the same number. If the check is positive for all involved ports, VTIM? returns 1; otherwise, it returns 0.

Syntax

VTIM? {waveform_set},{timing_set},{(pinlist)}

returns: 

VTIM {status}

Equation-based testing

VTIM? {specset_id|"multi-port_spec"},{timing_set}, {(pinlist)}

returns:

VTIM {status}

Parameters

waveform_set

Waveform Set Number. Enter PRM for the Primary Waveform Set, or an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by WSUS, WSUS? - (Waveform Sets USed).

specset_id

Derived as follows:

100 * equation_set_no + specset_no

multi-port_spec

To query a multi-port specification, enter the name of the specification.

timing_set

Specifies the timing sets to be checked. Enter PRM for the Primary Timing Set, ALL for all timing sets, or an integer in the range 1 to the maximum number of allowed timing sets. The maximum number is determined by TSUS, TSUS? - (Timing Sets USed).

In a multi-port setup, the check is performed for those pins from pinlist that belong to the same port. If you specify a number, a timing set with this number must be present in every equation set that is associated with a port of the multi-port specification.

pinlist

The name of the pin or pins to be checked. This parameter can also include groups previously created by DFGP, DFGP? - (DeFine GrouP). If more than one pin is to be included, the names must be separated with a comma. The symbol @ can be used to check all configured pins.

In a multi-port setup, the pins can belong to more than one port. Only those pins are considered that belong to one of the ports of the specification.

status

 

The system returns:

0

The timing is not the same.

1

The timing is the same.

Application

Timing setup, see Timing Setup Commands.

Errors

An error is generated if:

  • The specified waveform set number is outside the range allowed by the WSUS command.
  • The specified timing set number is outside the range allowed by the TSUS command.

Example

The following example illustrates the working of VTIM? in a multi-port setup. The pins S1_1 and DS0_1 belong to the same port, and S1_2 belongs to another one.

> ETDS? "spec_port_1_port_2",ALL,,(S1_1,DS0_1,S1_2)
< ETDS "spec_port_1_port_2",1,,"d1:0 d2:30",(S1_1,DS0_1)
< ETDS "spec_port_1_port_2",2,,"d1:0 d2:12",(S1_1)
< ETDS "spec_port_1_port_2",2,,"d1:1 d2:12",(DS0_1)
< ETDS "spec_port_1_port_2",1,,"d1:-0.67 d2:1.33 d3:9.3",(S1_2)

This call of ETDS? shows that the edge timings of S1_1 and DS0_1 are the same in timing set 1, but not in timing set 2 of the port to which these pins belong.

> PCLK? "spec_port_1_port_2",ALL,(S1_1,DS0_1,S1_2)
< PCLK "spec_port_1_port_2",1,50,(S1_1)
< PCLK "spec_port_1_port_2",2,20,(S1_1)
< PCLK "spec_port_1_port_2",1,50,(DS0_1)
< PCLK "spec_port_1_port_2",2,20,(DS0_1)
< PCLK "spec_port_1_port_2",1,16.667,(S1_2)

This call of PCLK? shows that the periods of S1_1 and DS0_1 are the same in the two timing sets of the port.

> VTIM? "spec_port_1_port_2",ALL,(S1_1,DS0_1,S1_2)
< VTIM 0

VTIM? returns 0 because of the different timings for S1_1 and DS0_1 in timing set 2.

> ETDS "spec_port_1_port_2",2,,"d1:0 d2:12",(DS0_1)
> VTIM? "spec_port_1_port_2",ALL,(S1_1,DS0_1,S1_2)
< VTIM 1

After changing the edge timing of DS0_1 in timing set 2 to the values of S1_1 with a call of ETDS, VTIM? returns 1 although DS0_1 has a different timing in timing set 1 and in timing set 2, and S1_2, which belongs to another port, has different values altogether.
