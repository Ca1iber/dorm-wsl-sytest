TestsuiteProxy.setTestmethodLimits()

This function sets values for the limits and test numbers defined in test method, test method API and test suite view.

Syntax

void setTestmethodLimits(const LimitNameValueMap& userDefinedLimits,
const LimitNameValueMap& defaultLimits = LimitNameValueMap ());
Parameters

userDefinedLimits

The name-value pair for limits defined in test method source code. If the name does not exist, the pair will be ignored and a warning message will be sent out.

defaultLimits

The name-value pair for limits defined in test method API, for example "DEFAULT FUNCTIONAL TEST", "DEFAULT GENERAL TEST", "DEFAULT PMUTEST", "DEFAULT DPS TEST", "DEFAULT SPEC SEARCH" and "DEFAULT TIA TEST".

If the limit is not used in the test suite, it will be added. If the limit does not exist, it will be ignored and a warning message will be sent out.

Functional changes

  1. Introduced in SmarTest 6.5.2
