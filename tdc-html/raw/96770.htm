Topic 96770

NotifyDieStartedToSmartest

This notification command notifies the test start event for a die to SmarTest.

It is mainly used when the FA (Factory Automation) client maintains the level handling and SmarTest does not know the level change information. FA can tell its state to HVM API and SmarTest with using this API.

When executing this API, the event DIE_STARTED will be notified. Success will be returned if the command is successfully issued. Otherwise an error object will be returned indicating the error code, description and severity.

Code

Description

Severity

PARAMETER_EXCEPTION
  • Unknown event name (category) "XXX".
  • Unknown execution state "XXX".
  • The value of the parameter "LOT_ID" is empty.
  • The value of the parameter "WAFER_ID" is empty.
  • The value of the parameter "SITE_ID_FOR_SITES" is empty.
  • The value of the parameter "SITE_ID_FOR_SITES" "XXX" is not valid.
  • The value of the parameter "SITE_SETUP_FOR_SITES" is empty.
  • The value of the parameter "SITE_SETUP_FOR_SITES" "XXX" is not valid; only "I" or "X" is allowed.
  • The value of the parameter "DIE_X_FOR_SITES" is empty.
  • The value of the parameter "DIE_X _FOR_SITES" is not valid.
  • The value of the parameter "DIE_Y_FOR_SITES" is empty.
  • The value of the parameter "DIE_Y _FOR_SITES" is not valid.
  • The site setup for the site 4 is not specified.
  • The die's X coordinate for the site 4 is not specified.
  • The die's Y coordinate for the site 4 is not specified.

RECOVERABLE

ILLEGAL_OPERATION

The designated session ID "XXX" does not exist.

RECOVERABLE

Dependency

The FA maintains level handling.

Parameters

I/O

Parameters

Description

I

SESSION_ID

The ID of the SmarTest session to notify.

I

EVENT_NAME

The event category. Here it is always EXECUTION.

I

EVENT_BODY

The event parameters. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always DIE_STARTED.

LOT_ID

The current lot ID.

CASSETTE_ID

(Optional) The current cassette ID.

WAFER_ID

The current wafer ID.

SITE_ID_FOR_SITES

The list of site IDs.

SITE_SETUP_FOR_SITES

The list of site setups.

DIE_X_FOR_SITES

The list of dies' X coordinates, which is separated by space.

DIE_Y_FOR_SITES

The list of dies' Y coordinates, which is separated by space.

This parameter is represented by ParamList whose key and value are both string type.

Prototype

ParamList eventParams;
string sessionId;
Status notify("EXECUTION", eventParams, sessionId);

Example

ParamList eventParams;
string sessionID;
eventParams["EXECUTION_STATE"] = "WAFER_COMPLETED";
eventParams["LOT_ID"] = "lot_123";
eventParams["CASSETTE_ID"] = "cass1";
eventParams["WAFER_ID"] = "wafer-12345";
eventParams.setValueArray("SITE_ID_FOR_SITES", split("1 2 3 4", " "));
eventParams.setValueArray("SITE_SETUP_FOR_SITES", split("I I I X", " "));
eventParams.setValueArray("PACKAGE_ID_FOR_SITES", split("100 101 102 -1", " "));
eventParams.setValueArray("DIE_X_FOR_SITES", split("10 11 12 13", " "));
eventParams.setValueArray("DIE_Y_FOR_SITES", split("0 1 2 3", " "));
notify("EXECUTION", eventParams, sessionID);
Note split() is a user defined function to split the string into separate characters. This function is not provided in the HVM API library. You can define your own function to implement this capability.
