Defining a utility line

A utility line channel is associated with a pin name and an operation mode by the DFUT command. The pin name is the name by which the software identifies the utility line channel. Utility line channels are identified by a three-digit number. The first digit (1-8) specifies the utility line block. The second and third digits (01-16) specify the channel number of the utility line.

Note In the header row of the Utility Line view, SmarTest shows the channel numbers of the utility lines, using the range [01 … 32] from right to left. The utility line itself are numbered with an offset of -1 in the range [00 … 31] that corresponds to the scheme "URW##" of the "Utility pogo pin layouts" in the "DUT Board Design Guidelines". For detailed description about utility pogo blocks, see Utility line assignments.

The DFUT? query lists the channel number and operation mode of the specified names.

The UDUT command removes a utility line.

You can identify a named utility line by its name to the UTST command which serves to set the output state of the line. Instead of setting the state of one utility line with UTST, you can also define a utility purpose with DFUP, which allows you to set the state of a group of utility lines with one statement. For more information see Defining a utility purpose and Accessing Utility Lines.

Related firmware commands

You can use the UTTI command to set a settling time that is used as the wait time for the WSDN command. All utility lines that are set with UTST or UPST will be switched in parallel when the FLSH command is performed. If the WSDN command is used immediately after FLSH, the time span during which execution will pause equals the longest settling time that is defined for any of the switched utility lines (with UTTI) or purposes (with UPTI).
