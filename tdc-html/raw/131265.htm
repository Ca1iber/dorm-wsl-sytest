MTP_CONTINUITY_TASK.execute()

The execute() member function of MTP_CONTINUITY_TASK executes the continuity test based on the measurement conditions set with the pin() member function.

Note that when using this member function, you must:

  • Use the DISCONNECT API before using execute() since the continuity test requests powering down the DUTs and disconnecting the digital pins before measuring.

    The measurement procedure is described in SharedContinuity test method.

  • Call the postExecute() member function at the end of the continuity test after all pins have been measured.

Syntax

void execute()
