SmarTest environment variables

This section provides a list of SmarTest environment variables. Some like LANG are not just specific to SmarTest but affect its proper operation.

The list contains variables for different independent use cases, for example, engineering, production or individual software configuration.

Note Do not set or change environment variables unless you know what you are doing. The documentation describes the variables in the related sections. If you are not sure, contact your system administrator or your Advantest representative.
SmarTest environment variables

Environment Variable

Description

AGILENT93000_PPUDEV

Defines the RS-232 interface for pay per use:

  • /dev/ttyS0: COM1
  • /dev/ttyUSB0: Port 0 of USB to RS-232 adapter
  • /dev/ttyUSB1: Port 1 of USB to RS-232 adapter
Note

To identify the USB ports refer to the appropriate product guide:

Z4 G4: Z4_Maintenance_Service_Guide.pdf

AGILENT93000_TMP_DIR

Specifies the location of the SmarTest temporary directory. The default is under /var/opt/hp93000/soc/tmp

DATAFORMATTER_SYSTEM_CONFIG_DIRECTORY

Specifies the location of the main configuration files of the data formatter. The default path is /etc/opt/hp93000/soc_common/datalog

DI_RS-232

Used to specify the built-in RS-232 interface to use for diagnostics. By default, ttyUSB0 is used.

  • ttyS0 COM1
  • ttyUSB0 Port 0 of USB to RS-232 adapter
  • ttyUSB1 Port 1 of USB to RS-232 adapter.
Note

To identify the USB ports refer to the appropriate product guide:

Z4 G4: Z4_Maintenance_Service_Guide.pdf

DISPLAY_HP83000

This can be any name. You need to set this variable when running more than one SmarTest session on the same workstation.

GLOBAL_HANDLER_CONFIGURATION

The default is normally /etc/opt/hp93000/soc/PH_libs/GenericHandler/Global-handler-config.cfg

This variable specifies the location of the 93000 handler configuration file, which specifies the handler model and configuration file.

GLOBAL_PROBER_CONFIGURATION

The default is normally /etc/opt/hp93000/soc/PH_libs/GenericProber/Global-prober-config.cfg

This variable specifies the location of the 93000 prober configuration file, which specifies the prober model and configuration file.

HP83000_ANNOTATE_MCDLog

Allows that the names of every testsuite are logged in the /var/opt/hp93000/soc/MCDLog.

This is very useful for debugging.Set this variable like this:export HP83000_ANNOTATE_MCDLog=1

You get easily turn on the MCDLog by running DIAG 2 from the hpt utility. DIAG -2 turns logging off (see Using the Trace Function).

HP83000_EDITOR

The default editor under Linux is NEdit. If you prefer another editor like vi, you can specify HP83000_EDITOR=/bin/vi

HP83000_PRC_TIMEOUT

Default of 30 seconds.This is the timeout value SmarTest uses when waiting for sub-processes to start. You may increase this value on systems with a very high load.

HP83000_ROOT

Default is /opt/hp93000/soc

LANG

Set it to C for a proper operation of the Pin Margin tool.

SA_NO_SPLASH

Default is 0.

Set it to 1 to disable the appearance of the splash screen during SmarTest startup, see How to disable the interactive windows.

SHOW_PROG_COMPONENTS

Default is OFF.If you set this variable to ON, the Work Order Select screen will display another panel with additional details about the work order (test program, test flow etc.)

SOC_GPIB_SYSTEM_ONLINE

If you want to use the Test Methods API for controlling GPIB instruments when SmarTest is off-line, set this variable to 1.

V93000_LICENSING

Specifies the location of the device license file. The must location for the device license file is <device-directory>/license

V93000_MODEL

Specifies the location of the model file. The default location for the model file is /etc/opt/hp93000/soc/model

WORKORDER_PATH

Normally, work orders are located under $HOME/workorders.

This variable allows you to specify a different path for workorders.
