Protocol Aware preference page

Open the Advantest V93000 > Protocol Aware preference page.

The preferences you can modify here are:

Preference options

Option

Description

Enable alternate row coloring

Displays every second row of tables with a colored background.

The default setting is: disabled

Automatically expand protocols node on related change

Automatically expands the Protocols node in the Test Program Explorer when a protocol is loaded or unloaded.

The default setting is: disabled

Functional changes

  1. Introduced in SmarTest 7.1.0
  2. SmarTest 7.1.1: Added new option to control Test Program Exlplorer's behavior upon un-/loading protocol definition.
