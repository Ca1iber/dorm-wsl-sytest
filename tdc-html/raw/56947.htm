Specs module

A specs module declares the spec variables and its units used in the equations module, the level sets, or in the DPS module. It does not specify the values of the spec variables. This is done in the SPECSET (or Spec Tool).

The module header starts with the SPECS keyword.

Note You define the units in the equation based spec setup only. You cannot define units using the spec tool.

Example

SPECS
  vcc_level   [V]  # Base vcc voltage
  vcc_offset   [V]  # Offset to add to vcc_level

Functional changes

  1. Introduced before SmarTest 6.3.2
