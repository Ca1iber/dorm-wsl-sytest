Introduction

Configuring pins is the first step you must take when preparing a test. It is impossible to define level, timing, or vector parameters without the pin configuration. The commands for defining a pin configuration can be grouped as follows.

Commands for digital pins: DFPN, CONF, UDEF

Commands for mode contexts: CTXT, CONF

Commands for DPS pins: DFPS, UDPS

Commands for DC Scale pins: DFPN, UDEF, DFPS, UDPS, PSSL

Commands for utility lines: DFUT, UDUT, DFUP, UPAS, UDUP

Commands for utility DC pins: CONF, DFPN, PALS

Commands for pin groups and ports: DFGP, UDGP, DFPT, UDPT

Commands for pin alias: DFPR, UDPR

Commands for multi-site setups: PACT, PALS, PQFC, PSFC, PSTE, STME

Note The firmware does not accept any configuration changes while a test is running.

An example of a pin configuration file is given in Pin Configuration Example.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.2: New command: DFPR
