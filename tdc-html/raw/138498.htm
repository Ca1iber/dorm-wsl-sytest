generate_device_dir

The generate_device_dir command for the SmarTest Program Manager MCM (STPM MCM) control file creates a device directory that can be used for an MTP (master test program).

The generated device directory includes a config file and a testflow file. The config file is intended to be used as is. It is not modified by running create_mtp, and although you can edit in SmarTest, you do not normally need to do so. The testflow files initially contains only placeholders for the various groups and is populated with the actual tests when create_mtp is run. You can edit this file to put the groups in the desired order.

The command is intended to be executed before the content of the device directory is created with the create_mtp command. This should happen once during the initial setup of an STPM MCM conversion process.

Before generate_device_dir can be executed, an MTPT (STPM MCM mapping table) must have been created, which is typically done with the generate_template command. The Pin mapping table in this MTPT must be correctly filled in.

Syntax

generate_device_dir()

The command has no parameters. (The information about the MTPT to use comes from the mtp_template_dir setting in the control file; the information on where to create the device directory comes from the mtp_device_testflow setting in the same file.)

Example

mtp_template_dir    = "/prj/MTPT"
mtp_device_testflow = "/prj/MTP/testflow/rel.tf"
generate_device_dir()
