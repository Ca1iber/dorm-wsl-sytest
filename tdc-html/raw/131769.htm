The object of this type holds he upload state items of the upload queue. It is used to determine how many uploads are still pending.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Example

The following example shows how to create a vector of type SMC_UPLOAD_STATUS and how to obtain the parameters of the upload queue.

typedef vector<SMC_UPLOAD_STATUS> SmcUploadStatusVector;

// Obtain the collection
SmcUploadStatusVector statusVector  = SMC_GET_UPLOAD_STATUS();
