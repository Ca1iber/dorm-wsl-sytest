Retrieves the fail bit results and the functional test results of the pattern that is specified with getMemoryPattern() and is tested with the MTP_MEMORY_TEST class.

Note This API is available only for MTP.

This API is defined in the header file /opt/93000mts/mts/execution_engine/include/MtpMemoryPattern.h.

Syntax

This class has no constructor. Instances of this class are created by using the getMemoryPattern() function of the MTP_MEMORY_PORT class.

Example

See the examples in MTP_MEMORY_TEST.
