Bring up and Close Flag Windows

The functions bring up and close the Flag Window specified by mode.

long PopupFlagWindow(long mode)

long PopupFlagWindow(long mode)

The long mode can be one of the following:

CI_TF_FLAG_WINDOW for the Testflow Flags Window

CI_TS_FLAG_WINDOW for the Testsuite Flags Window

CI_SYS_FLAG_WINDOW for the System Flags Window

CI_USR_FLAG_WINDOW for the User Flags Window
