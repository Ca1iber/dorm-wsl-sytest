2. Create a Test Method Class

Procedure

  1. To create a new Test Method Class, right-click the project Utmmethod and select New > Test Method Class from the shortcut menu.
  2. In the Create a new Test Method class wizard, type in the class name PspecSearch in the Class Name area.
  3. Add the parameters listed in the table below to the class by clicking the Add button in the Parameters area.

    Parameter Type

    Parameter Name

    PinString

    sPinList

    string

    sResultPins

    SpecVariable

    sSpecVariableName

    string

    sSearchType

    double

    dxStart

    double

    dxStop

    double

    dxRes

    double

    dxStep
