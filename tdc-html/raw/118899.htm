This section provides details to the test program structure required by SmartCalc and an overview of the SmartCalc APIs.

It also describes some example implementations of the different use models of SmartCalc.

Note The SmartCalc APIs are implemented as shared library. Loading the shared library and resolving dynamic references may cause a small delay. Typically this delay is < 1 ms. Depending on the file system and the utilization of the operating system it can be significantly higher.
