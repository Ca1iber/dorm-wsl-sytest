Topic 350395

rdi.id().getTmuFinished()

Checks if TMU measurements have been finished or SmarTest Work Center.

When you use getTmuFinished() to check measurement results, it checks all sites to see whether measurements on all sites are done or measurements on any site is SmarTest Work Center. If the measurements on all sites have been done, this API returns TRUE. If the measurements on any site is SmarTest Work Center, this API returns FALSE.

getTmuFinished() is designed for a burst, not for a measurement. This means when it is used with a result ID, the ID is a burst ID, not the measurement ID.

Syntax

bool getTmuFinished();
Return value
  • TRUE: Measurements on all sites have been done.
  • FALSE: Measurements on a site is SmarTest Work Center.

Example

RDI_BEGIN();
  rdi.tmu("id1").pin("dig1").vth(2).samples(5).measMode(TA::RISE).execute();
...
RDI_END();

bool flag = rdi.id("id1").getTmuFinished();

Functional changes

  1. Introduced in SmartRDI 7.5.3
