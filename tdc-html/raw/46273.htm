Using Shots: the shots Column

Subtopics

  1. Purpose
  2. Implementation
  3. Example 1
  4. Example 2

A shot is an instance of a pattern which executes all drive actions associated with the state character, for every state character of the ASCII device cycle specified for the pattern, but only a subset of its compare actions. Compare actions are distributed between the different shots in such a way that every compare action is executed in exactly one shot.
