Commands in the shmoo editor of the Shmoo Tool

In the Shmoo Tool, after you right-click a shmoo plot, which is displayed on a shmoo page of the shmoo editor (see The interface of the Shmoo Tool), you will see these commands:

  • Run, Run Fast, Abort Run: The same as the Run Shmoo, Run Fast Shmoo, and Abort Run commands and their shortcuts , , .
  • Apply to HW and Restore: Available only when you select one cell on a shmoo plot.
    • Apply to HW: The primary settings of the selected cell will replace the current hardware settings in the Primaries group in the related Properties view.
    • Restore: To return to the original settings in the Primaries group.
  • Zoom In, Zoom Out: The same as the ZoomIn and ZoomOut commands and their shortcuts , .
  • Full Size: To display the whole shmoo plot from (x-start, y-start) to (x-end, y-end) on the shmoo page.

    The full size plot is the default plot after an execution.

  • Magnify: To increase the resolution of the selected area of a shmoo plot and replace the shmoo plot with this area. For details, refer to the descriptions about "Magnify" in Viewing and magnifying a selected area of a shmoo plot.
  • Test Modes: If you have selected multiple Test modes during settings, this command lets you view different types of results on the shmoo plot.

    For details, see Viewing different results on a shmoo plot.

  • Result Pin: Lets you view the shmoo plots of different result pins.

Functional changes

  1. Introduced in SmarTest 7.2.0
  2. SmarTest 7.2.1: Adds a new command: Magnify.
