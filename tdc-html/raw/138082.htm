An MTPT contains a number of CSV tables that specify various aspects of how STPs (source test programs) are combined into an MTP (master test program).

The STP table describes the STPs used in creating the MTP:

  • STP table

Several mapping table describe which objects from the STPs correspond to which objects from the MTP:

  • Pin mapping table
  • Group mapping table
  • Test mapping table
  • Bin mapping table
  • Test number mapping table
  • Testflow variable mapping table

Several tables describe settings and parameters for the objects in the MTP:

  • Test suite table
  • Special tests table
  • Shared pins table
  • Test flag table
  • Off DC levels table

Two additional tables, the MTPT configuration file and the STP test information table, are intended for internal bookkeeping and future expansion, respectively, and should not be edited.

While the tables listed above tables can be edited with text editors, we recommend using the OpenOffice spreadsheet that is also part of the MTPT for editing the CSV files.
