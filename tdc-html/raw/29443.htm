GET_USER_FLAG

This API retrieves the current value of the specified user flag (INT type of testflow variable), which can have been stored at a defined site. The flag and the site must have been previously declared as type INT.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

GET_USER_FLAG(const STRING& flag, INT *value);
GET_USER_FLAG(const STRING& flag, INT site, INT *value);
Parameters

I/O

Parameter

Description / Range

I

flag

The user-defined user flag name.

I

site

Site number, must be in the range [1 ... MAX_SITES], where MAX_SITES is the maximum number of sites allowed by SmarTest.

Note This is not the number of enabled or active sites.

O

value

The current value of the specified flag is returned to this variable.

Examples

For the current site only

The GET_USER_FLAG API retrieves the current value of the user flag specified by the parameter flag_A of the current site.

INT flag_A_state;
    :
GET_USER_FLAG("flag_A", &flag_A_state);

For a particularly set site

You can get the flag in a later called test method even if you executed the initialization test method for different sites:

...
INT flag_B;
SET_USER_FLAG("flag_B", 1, flag_B); // site-independent value is stored at site 1
...

Get the variable:

...
INT flag_B;
GET_USER_FLAG("flag_B", 1, &flag_B);
report_stream << "My flag: " << flag_B << endl;
...

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.3.2: New parameter site
