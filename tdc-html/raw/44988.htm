Function Command Set Error Messages

The following are the error messages if an error occurs when the Command Set is used:

CI: ci_load_lib: illegal .sl:

CI: file not a lib!

This error occurs when the file libcifset.sl is not a shared library. Solve the problem by using the Make command to create a shared library.

CI: ci_load_lib: illegal .sl:

CI: undefined sym(s):

This error occurs when the file libcifset.sl contains undefined symbols, that are not permitted. A list of the undefined symbols is generated in the report window. Solve the problem by ensuring that all function names are spelled correctly, and by ensuring that all functions are located in the correct library.

CI: ci_load_lib: illegal .sl:

CI: handle/index error

This error occurs when an inconsistency exists between the Command Interface process and the shared library. Remake the library and start again.

CI: ci_load_lib: illegal .sl:

CI: address space ??

This error occurs if not enough address space exists to load the shared library. This error can only be resolved by the System Administrator.

CI: ci_load_lib: illegal .sl:

CI: does not exist

The error occurs if no shared library exists. Make and generate the shared library.

CI: ci_load_lib: illegal .sl:

CI: permission ??

Change the access permission to the shared library.

The following warning can occur under general execution of a function command set:

CI: execute_command: comment truncation warning

This message occurs when too many bytes have been included in the comment, causing it to be truncated. Solve the problem by looking at the command that you have implemented and reducing the number of bytes written as comment.

The following are general internal program errors that can only be resolved by Advantest personnel:

CI: get address: symbol table overflow

This warning occurs when an overflow occurs during the storing of function symbols. This is a non-fatal situation. The Command Set may become slower in operation due to having to fetch function addresses at every call.

CI: ci_load_lib: internal error!

CI: ci_load_lib: illegal message queue id

CI: ci_load_lib: illegal action identifier

CI: execute_command: illegal message queue id

CI: cons_check: illegal message queue id
