Topic 42262

Function: ph_driver_start

This function starts the driver, and initializes it with the parameter settings of the driver configuration file (see Setting Up the Driver Configuration).

ph_driver_start also establishes the connection to the equipment by opening the interface session, checking the equipment identity, and downloading pre-configured data to the equipment.

ph_driver_start should be called from the application model before any other call of a driver function.

Applicable for: handler and prober driver

Example: PROB_HND_CALL (ph_driver_start)
