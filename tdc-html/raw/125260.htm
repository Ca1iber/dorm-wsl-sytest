The encode/decode function's syntax is expression based and operates on state character sequence values.

Each specific function may have restrictions on parameters and operators or functions. The operator's precedence is similar to the C programming language expanded by additional operators fit (highest precedence first):

Some operators can be applied to state character sequences only if they consist of the characters 0/1 or L/H. In this case the semantics of the operator is the same as with the corresponding integer operator of the C programming language.
