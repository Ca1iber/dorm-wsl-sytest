MULTI_LIMITS

The MULTI_LIMITS class is the container holding multiple objects of the LIMIT class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/MultiLimits.h.

Class definition

MULTI_LIMITS();

Constructor

MULTI_LIMITS()

This constructs an object of the MULTI_LIMITS class that allows the user to contain multiple objects of the LIMIT class by using a test name or an object of the LIMIT class.

Member functions

add()

MULTI_LIMITS & add(const STRING & testname, size_t n = 1);

This function appends n elements, each of which is a copy of a specified limit, to the container by using a test name.

Parameters

testname

Test name that can be referred to from the Properties view.

n

The number of limit elements to be appended to the container. (default: 1)

This must be a positive integer.

add()

MULTI_LIMITS & add(const LIMIT & limitobj, size_t n = 1);

This function appends n elements, each of which is a copy of specified limit, to the container by using a class object of the LIMIT API.

Parameters

limitobj

Object name of the LIMIT class.

n

The number of limit elements to be appended to the container. (default: 1)

This must be a positive integer.

add()

MULTI_LIMITS & add(TM::COMPARE opl, const ARRAY_D & min,
 TM::COMPARE oph, const ARRAY_D & max);

This function appends multiple limits by using specified limit arrays and comparison operators.

Parameters

opl

The comparison operator to be set. Applicable operators are: LT (less than a limit value), LE (less than or equal to a limit value), and NA (no compare).

oph

The comparison operator to be set. Applicable operators are: GT (greater than a limit value), GE (greater than or equal to a limit value), and NA (no compare).

min

Lower limit values to be set. The nth elements of min and max make up a LIMIT pair.

Note: There must be an equal number of min and max elements.

max

Upper limit values to be set. The nth elements of min and max make up a LIMIT pair.

Note: There must be an equal number of min and max elements.

size()

size_t size();

This function returns the total number of elements in the container.

get()

const LIMIT get(size_t index) const;

This function returns a const reference to the nth element of the container, where the initial element has position 0.

Parameter

index

Index for which the element is to be returned.

testname

Example

Example: Typical External Trigger DPS measurement

Note MULTI_LIMITS class is used by DPS_TASK only in external trigger mode.

  1. :

    DPS_TASK task;
 :

    Construct DPS_TASK class objects (task).

  2. :
MULTI_LIMITS m_limits1, m_limits2;
m_limits1.add("limits1").add("limits2").add("limits3");
m_limits2.add("limits4",2).add("limit5");
task.pin("pin1").limits(m_limits1);
task.pin("pin2").limits(m_limits2);
 :

    Construct MULTI_LIMITS class object (m_limits1, m_limits2).

    Append multiple limits to the m_limits1 and m_limits2.

    Define measurement condition (multiple limits) for pin1 and pin2.

  3. :
Primary.timing(3);
FLUSH();
task.trigMode(TM::EXTERNAL).execMode(TM::GPF).execute();
 :

    Specify and activate the primaries.

    Download measurement conditions for pin1 and pin2 into the firmware layer.

    (This downloading is omitted and the previously cached measurement conditions are re-used. If the measurement conditions have already been downloaded into the firmware layer during the first testflow execution, this re-use of conditions occurs after the second execution of the testflow .)

    Execute External Trigger DPS measurement for pin1 and pin2 simultaneously.
