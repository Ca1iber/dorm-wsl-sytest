The V93000 test system memory test software supports the definition of algorithmic patterns using the Memory Test Language (MTL).

The topic Memory test pattern definition elements shows with examples how each the definition elements are supported by the common MTL syntax.

Creating an MTL pattern is the central information point to finally get to your test program using MTL compiler.

During pattern creation you have to define the compiler input files:

  • Create device access
  • Create device architecture
  • Create pattern file
  • Create program file
  • Pin Mapping (one pin mapping file per device)

When the set of MTL files for the compiler are created you run the compiler using the options available. See Using the MTL compiler from the GUI and Using the MTL compiler from the command line for details.
