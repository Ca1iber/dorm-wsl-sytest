FLEX_PIN_RELAY

This class is a data container holding the setting for digital pins or digital inputs of DC Scale cards.

In one task of FLEX_RELAY, if you make multiple settings for a pin by sending the FLEX_PIN_RELAY.set() statement multiple times, an error occurs.

Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/FlexPinRelay.h.

Constructor
This class is always called as the subsidiary data container of the FLEX_RELAY, API. Therefore, the FLEX_PIN_RELAY class does not have a public constructor.
Member functions
In this class, the following public member functions are defined:
  • set()
  • setTMU()

Member functions

set()
FLEX_PIN_RELAY& set (const STRING& pin_mode, const STRING& dc_target="X");
FLEX_PIN_RELAY& set (const STRING& pin_mode, const STRING& dc_target, const STRING& mux_select);

This member function defines the relay settings, which are applied to the hardware when the task is executed.

Parameters
Parameter Description
pin_mode

This parameter controls per-pin relays (AC, DC and pin PMU relays) of the digital channels.

The following options are available:
"X" The settings of all the relays remain unchanged.
"IDLE" Disconnects all the relays (AC, DC, and pin PMU relays). Use this option to set the digital pin to Hi-Z by disconnecting the relays.
"AC" Connects a DUT pin to its associated digital channel. Use this option for example when you return the disconnected digital pin to the state same as the connect state where the AC relay is closed for the i/o/io pin.
"DC" Closes the DC relay.
"PPMU" Closes the pin PMU relay to connect the pin to the Pin-PMU
"ACDC" Closes both the AC and DC relays.
"BOTH" Identical to ACDC.
"ACPM" Closes both the AC and the pin PMU relays.
"DCPM" Closes both the DC and pin PMU relays.
"ALL" Closes all the relays (AC, DC, and pin PMU relays).
"CNCT" Special connect mode: for all I, O, IO pins AC relay closed, for all DC pins AC relay open.

For utility DC pins, only the pin modes "IDLE", "CNCT", and "X" are supported.
dc_target

This optional parameter specifies the resource to be connected when the DC relay is closed. The ISOL and other relays are controlled. The default setting ("X") does not change any of these relays. Thus, you can omit this parameter for example when you set the digital pins to Hi-Z, and returns them to the state same as the connect state where the AC relays are closed for the i/o/io pins.

This parameter is identical to the dc_target parameter of the RLYC firmware command. You can specify any "enum" value of the RLYC dc_target parameter. The "enums" specify fixed combinations of relay settings, necessary to perform certain functions.

As an alternative you can control the relays individually using the string entry (not supported for utility DC pins). This has the format: "CCCCC", where each character "C" represents a relay on a channel board or a Clock board. Each "C" can take the value 0, 1, or X, where a 0/1 opens/closes the relay(s) respectively and an X leaves it unchanged. For example, flexObj.set("DC","11100").

Going from left to right:

  • Character 1 - ISOL relay on channel board
  • Character. 2 - GND relay on channel board
  • Character. 3 - PMU relay on channel board (BADC)
  • Character. 4 - EXT relay on Clock board
  • Character. 5 - DUT relay on Clock board

For details, see the description of the dc_target parameter of the RLYC, RLYC? - (ReLaY Control) command in the Command Reference.
mux_select This optional parameter connects the board ADC for the High Impedance measurement mode, or for the measurement path through the pin PMU. In this case you can connect only one pin PMU per board with the ADC, as there is only one ADC per board.

This preparation is needed for pattern-controlled measurements.

Note that for high-voltage pins only high-impedance measurements (VM_HIZ) can be executed in the pattern run.

These are the options:
"MUX_VM_HIZ" Connects the ADC for the High Impedance measurement mode.
Note
  • The pin_mode parameter should be set to "DC" to connect the pin to the DC line.
  • The dc_target parameter should be set to "PMU" to connect the BADC relay with the board ADC.
"MUX_PPMU" Connects the ADC to the Pin PMU.
Note
  • The pin_mode parameter should be set to "PPMU" to connect the pin to the pin PMU.
  • The dc_target parameter can be ignored and set to ""X"".
Return value
A reference to the FLEX_PIN_RELAY class object.
setTMU()
FLEX_PIN_RELAY& setTMU (const STRING& connect);

This member function defines the TMU connection mode and TMU input relay settings, which are applied to the hardware when the task is executed. This member function is currently available for TMU inputs of DC Scale cards only.

The TMU input relay settings are independent from the output relay settings of channel. The TMU relay settings are not changed by the member function FLEX_PIN_RELAY::set() that is described above.

Parameter
Parameter Description
connect This parameter defines the connection mode and the input relay state of the TMU.
"HIGH_BW" Closes the TMU input relays in the high-bandwidth connection mode.
"HIGH_IMP" Closes the TMU input relays in the high-impedance connection mode.
"HIGH_SPEED" Closes the input relay of the TMU_H# pogo pin when the high-speed comparator has been selected.

Not currently supported by any cards.
"IDLE" Opens the TMU the output relays.

This is the default state.
Return value
A reference to the FLEX_PIN_RELAY class object.
