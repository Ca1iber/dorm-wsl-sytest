Topic 126514

Defining a compliance pattern for pattern‑based SmartLoop testing

The SmartLoop™ license also enables you to define short compliance patterns for pattern‑based SmartLoop™ tests. These patterns are allowed to run with the speed that is associated with the SmartLoop™ license even if this speed exceeds the speed license for the digital channels.

A compliance pattern is identified by the memory type HSER. The timing that is used for a compliance pattern must be marked by the keyword compliance in the equation set. The vector area of a compliance pattern is restricted to 32 K. However, it can be expanded by memory pooling up to 128 K on a PS9G system (512 K on PS1600) on the following conditions, where P is the port of the compliance pattern:

  • All channels of any PS9G 4-channel group (PS1600 8-channel group) that provides the channel for a pin of P are licensed for SmartLoop™.
  • All the other compliance patterns are defined for ports that share no pins with P.

For more information on memory pooling see Memory pooling within channel groups.

Examples

Model file entry

IOCHANNEL
10101-10108: HW=PS9G, speed= 3600Mbps, smem = 112M, loopback = 6800Mbps
...

Pin configuration

>  DFPN? (PortD)
<  DFPN 10101,"4",(Pin4)
<  DFPN 10105,"5",(Pin5)

Equation set

EQNSET 1 "equation set 1"

DEFINES  PortD

SPECS  
p      [ns]

compliance

TIMINGSET 1 "eq 1 ts 1"
period=1.5

PINS  Pin4
d1=0 #DU

PINS  Pin5
r1=16 #RU

Pattern

>  SQLB? ALL,MAIN,(PortD)
<  SQLB "compl",MAIN,0,3,"wavetable 1",(PortD)
>  SQLA? ALL,ALL,ALL,(PortD)
<  SQLA LBL,"compl","PARA_MEM=HSER,PARA_MCTX=DEFAULT",(PortD)
<  SQLA LBL,"burst","PARA_MEM=NONE",(PortD)
>  SQPG? ALL,(PortD)
<  SQPG 0,STVA,,0,,(PortD)
<  SQPG 1,STSA,,,,(PortD)
<  SQPG 2,GENV,100501,,,(PortD)
<  SQPG 3,STOP,,,,(PortD)
<  SQPG 4,CALL,,"compl",,(PortD)
<  SQPG 5,BEND,,,,(PortD)

Note that the compliance pattern compl comprises 100501 vectors. This is possible because channels 10101 through 10104 and 10105 through 10108 are all licensed for SmartLoop™, but only 10101 and 10105 are associated with a pin.
