Enumeration Type Documentation

enum GIO_GPIB_STATUS_REQUEST

Parameters for GPIB Bus Status command.

A value of this type is passed to gio_gpib_bus_status() to select one of a number of status inquiries that can be made about a GPIB interface.

Enumerator
GIO_GPIB_STATUS_REMOTE 

Checks if the GPIB interface is in remote state.

GIO_GPIB_STATUS_SRQ 

Checks if the SRQ line is asserted, indicating a service request is pending.

GIO_GPIB_STATUS_NDAC 

Checks if the NDAC line is asserted.

GIO_GPIB_STATUS_SYSTEM_CONTROLLER 

Checks if the interface is the system controller.

GIO_GPIB_STATUS_CONTROLLER_IN_CHARGE 

Checks if the interface is the active controller.

GIO_GPIB_STATUS_TALKER 

Checks if the interface is addressed to talk.

GIO_GPIB_STATUS_LISTENER 

Checks if the interface is addressed to listen.

GIO_GPIB_STATUS_BUS_ADDRESS 

Returns the GPIB address of the interface.

Send a GPIB command.

This function asserts the ATN line and writes a block of data to a GPIB interface. The data bytes are interpreted as GPIB commands.
