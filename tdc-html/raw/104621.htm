ERROR_MAP_TEST

Subtopics

  1. PIN_ERROR_MAP_TEST

In conjunction with the PIN_ERROR_MAP_TEST API, this API provides detailed access to functional test results like error counter and fail cycles stored in test processor resources like hardware error counter and error map.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ErrorMap.h.

Class definition

Constructor

ERROR_MAP_TEST(mode:TM::CYCLE_MODE);
ERROR_MAP_TEST(const TM::CYCLE_MODE mode, bool skipErrorMapConfig);
Parameter

CYCLE_MODE

Determines whether cycle related parameters for other test methods are interpreted as x-mode cycles or tester cycles (as returned by the emap command)

  • XMODE_CYCLES (only for equation-based timing).

    See DUT oriented view - xN and x1/N mode for details of XMODE_CYCLES.

  • TESTER_CYCLES
skipErrorMapConfig This option is used to reduce test time, by skipping redundant error map settings. Set to true in order to skip setting the error map mode when using FUNCTIONAL_TEST().

Syntax

ERROR_MAP_TEST emap1(cycle_mode);
...
emap1.func1();
emap1.pin("pin1").func2();

Here func1 is one of the member functions of ERROR_MAP_TEST. While func2 is one of the member functions PIN_ERROR_MAP_TEST.

Member functions

pin()

PIN_ERROR_MAP_TEST& pin(pins:STRING);

Returns an instance of the PIN_ERROR_MAP_TEST class (see PIN_ERROR_MAP_TEST) for the specified pins.

The returned object can be used to configure parameters for the pin given and to retrieve the results. The member functions of PIN_ERROR_MAP_TEST are used after it.

Parameter

pins

The pins to work with.

You can specify multiple pins; however, some of the functions of PIN_ERROR_MAP_TEST objects are available only for objects that have been created for single pins.

getErrorCount()

LONG getErrorCount();

Returns the global error count.

getLastCycleExecuted()

LONG_LONG getLastCycleExecuted();

Returns the last cycle of the pattern that has been executed.

prepareForTest()

void prepareForTest();

Activates the error map settings.

getNumberOfExecutedTesterCycles()

void getNumberOfExecutedTesterCycles(const STRING& pin, const STRING& sites, ARRAY_LL& executedCycles)

Retrieves the number of valid cycles in the pattern that has been executed.

Note Specify a single pin for the function only.

The following example demonstrates how to use getNumberOfExecutedTesterCycles(). 

virtual void run()
  {
      ON_FIRST_INVOCATION_BEGIN();
          ERROR_MAP_TEST emap(TM::TESTER_CYCLES);

          FUNCTIONAL_TEST();
          string pinName = "pin1";
          string sites = "11";
          GET_ACTIVE_SITES(sites);
          ARRAY_LL arrCycles;
          emap.getNumberOfExecutedTesterCycles(pinName, sites, arrCycles);

          FOR_EACH_SITE_BEGIN();
              int currentSiteNumber = CURRENT_SITE_NUMBER();
              cout << "Number of executed cycles for site " << currentSiteNumber 
                   << " is: " << arrCycles[currentSiteNumber-1] << endl;
          FOR_EACH_SITE_END();

          // Results for all sites have been processed - stop the site loop
          setStopSiteLoop(true);
      ON_FIRST_INVOCATION_END();
    return;
  }

GET_FIRST_FAILING_XMODE_CYCLE()

INT GET_FIRST_FAILING_XMODE_CYCLE(const STRING& pin, INT startCycle, INT amount, ARRAY_LL& cycles, Boolean& fewerFailsReturnedDueToEmapFull);

The return value of the function is the number of cycles recorded in the cycles array.

Parameters
Parameter Description
pin The name of the queried pin.
startCycle The cycle from which to list the failing cycles.

Parameter startCycle must be within the recorded error map range or an error is thrown.
amount The number of failing cycles to list.
cycles The array in which the found failing cycles are to be stored
fewerFailsReturnedDueToEmapFull Boolean value:
  • TRUE: Error map is full and less than the requested number of failing cycles to list (parameter number) is available.
  • FALSE: The requested number of failing cycles to list (parameter number) is available.

Example

ERROR_MAP_TEST emap(TM::XMODE_CYCLES);
ON_FIRST_INVOCATION_BEGIN();
  FUNCTIONAL_TEST();
ON_FIRST_INVOCATION_END();
ARRAY_LL CP_FFC;
ARRAY_CHAR CP_expected;
emap.pin("CP").getFirstFailingCycles(0,10,CP_FFC);
emap.pin("CP").getExpectedDataInRange(3,10,CP_expected);

In this example, an error map test is executed in x-mode cycles. Then the first 10 failing cycles of pin CP is retrieved and stored in CP_FFC. The expected data in range 3 to 12 cycle of pin CP is retrieved and stored in CP_expected. getFirstFailingCycles() and getExpectedDataInRange() are member functions of PIN_ERROR_MAP_TEST.
