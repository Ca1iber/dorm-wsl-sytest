Topic 103801

EDL logging API

Subtopics

  1. IssueEDLEvent()
  2. MoveEDLStream()

Two BLC APIs are defined for EDL logging.

The EDL events here include:

  • AppModelLevelStartEventType: created at the beginning of each level. There's only one event for each level.
  • AppModelLevelEndEventType: created at the end of each level. There's only one event for each level.
  • AppModelLevelLoopEventType: created at the beginning of each iteration of a level (a level can be entered for multiple times).
  • AssignmentEventType: created when a value is assigned to a local or system variable.
  • TestProgramStartEvent: created at the beginning of each test program execution
  • TestProgramEndEvent: created at the end of each test program execution.

BLC provides both implicit and explicit approach to issue the EDL events. The implicit event generation functionality is controlled by the ENABLE_IMPLICT_EVENT parameter of the SetBLCProfile() aPI. The ApplModelLevelStartEventType, AppModelLevelLoopEventType, TestProgramStartEvent, TestProgramEndEvent and ApplModelLevelEndEventType EDL events can be issued either implicitly or explicitly. The AssignmentEventType can only be issued explicitly.

For the application model level related EDL events, when there's no level structure maintained in BLC (by calling StartLevel() and CompleteLevel()) you need to define the boundary of each level and create the EDL event.

The EDL event generation is dependent on the LOG_EVENTS_ENABLE system flag. The API will firstly checks the status of this flag and then decide whether an event can be created.
