Bit Fail Map Viewer window

Subtopics

  1. Bit Fail Maps
  2. Chip Overview
  3. Fail Combinations
  4. Filters
  5. Colors
  6. Messages

The Bit Fail Map Viewer window is the tool's main window. In its tabs, most of the work with the tool takes place.

The window contains the menu bar that is described in Bit Fail Map Viewer menus. It also contains these tabs:

  • Bit Fail Maps: In this tab, the available bit fail maps are displayed and can be assigned to layers of the BFM Viewer. See Bit Fail Maps for details.
  • Chip Overview: This tab displays the loaded bit fail maps, failed and marked cells, and filters. See Chip Overview for details.
  • Fail Combinations: This tab displays a report on how many cells contain defects on one or more overlays. It also lets you hide certain error combinations in the Chip Overview tab. See Fail Combinations for details.
  • Filters: This tab displays all filter rules that have been defined and lets you edit, create, and delete them. See Filters for details.
  • Colors: This tab lets you set up the colors for the various elements in the Chip Overview tab. See Colors for details.
  • Messages: This tab is the BFM Viewer console which displays all warnings and error notifications from the tool. See Messages for details.

Functional changes

  1. Introduced before SmarTest 6.3.2
