DRLFailingCycleAttr

A variable of this type is a pointer to a structure named _DRLFailingCycleAttr. In this structure a list of pins which failed in a specific cycle is stored.

The member cycle_number holds the number of the cycle.

The member pins holds the list of the failed pins. size is the real number of elements in the array pins, i.e. the number of pins in the pin list.

For further information on the data types used see DRLCycleNumber and DRLPinName.

typedef const struct _DRLFailingCycleAttr {
  DRLCycleNumber cycle_number;
  unsigned short size;
  DRLPinName pins[1];
} *DRLFailingCycleAttr;
