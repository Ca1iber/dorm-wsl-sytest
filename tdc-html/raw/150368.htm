EVENT_WAVEFORM_VCVM.getOutOfRangeCheck()

Reads the state of the out-of-range check that has been defined by EVENT_WAVEFORM_VCVM.outOfRangeCheck().

The state is read from the corresponding EVENT_WAVEFORM_VCVM object and returned as a bool value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

void getOutOfRangeCheck(bool & failOnOutOfRange) const;
Parameter
Parameter Description
value

The programmed value true or false of the out-of-range check.

  • true: The out-of-range check is enabled
  • false: The out-of-range check is disabled

Return value

There is no return value.

Example

For an example see EVENT_WAVEFORM_VCVM.

Related information
