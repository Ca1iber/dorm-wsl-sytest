DPS_AUX_TASK.setup()

The DPS_AUX_TASK.setup() member function allows to program and configure the surge tracker comparator pair or the TMU (Time Measure Unit) comparator pair of DC Scale cards.

Supported DC Scale cards:
  • Surge tracker: DPS128/DPS64 and XPS256

  • TMU (Time Measure Unit): Currently not supported by any card.

This member function downloads the measurement conditions defined in DPS_AUX_TASK and DPS_AUX_PIN_TASK into the firmware layer. But they will not be applied to the test card hardware until the DPS_AUX_TASK.execute() member function is called. If this task is added to TASK_LIST, the setup() member function of the TASK_LIST class calls this member function.

Syntax

void setup();

List of parameters

There are no parameters.

Return value

There is no return value.

Example

For an example see DPS_AUX_TASK.
