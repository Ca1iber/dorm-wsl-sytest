Topic 137080

Examining the underlying data of a summary

The underlying data of a summary row in a data navigation view can be displayed and examined in a detail data view.

About this task

Data from a data log file is examined in a raw data view; data from the system data log stream is examined in a Stream data view or a raw data view.

Examine the underlying data when you want to see the individual test results that are being aggregated in a summery row.

You do not need to perform any operation to display the system data log records in the stream data view; this happens automatically if the system data log stream is open and the view is open.

Before you begin

Open the data log.

Make sure that the correct detail data view is displayed:

  • If you want to examine the selected row: Raw data view
  • If you want to examine the entire system data log stream: Stream data view

Procedure

To display the underlying records of a summary:
  • In the data navigation view for the data log, click the row you want to examine

Results

The individual results that the row summarizes are displayed in the detail data view.
