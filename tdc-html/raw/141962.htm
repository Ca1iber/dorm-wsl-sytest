Enhancements of the Bit Fail Map Viewer

The Bit Fail Map Viewer has been enhanced with the following functionalities.

These enhancements are:

  • When starting BFM Viewer, you can specify any directory as the device directory. You can select bit maps and map converter libraries from the desired directories.
  • The maximum number of failed cells listed in the Failed Cells tab is increased to 5,000,000. See the Limits section in Global.
  • On the Global Settings page, you can configure the size and the pass/fail symbols of the exported ASCII bit map. See the ASCII Bitmapsection in Global.
  • Supports hexadecimal number when specifying an Analysis Area.
