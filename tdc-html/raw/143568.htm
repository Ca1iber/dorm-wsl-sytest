initDiscard()

Specifies the number of initial samples to be skipped/discarded.

Syntax

initDiscard(long iInitSkipSamples);
List of parameters

Parameter

Description

iInitSkipSamples

The number of initial samples to be skipped.

For different types of cores, default values are different:
  • LF core: Default value is 64.
  • VHF or IQ core: With oversampling, the default value 64; without oversampling, the default value is 0.
  • Other cores: Default value is 0.

Example

rdi.digCap("cap").pin("DATA1").samples(100).initDiscard(10).interSkip(1,2).execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
