Topic 10548

Creating a label with edit commands

About this task

This task explains how to create the label test_2 with edit commands.

Procedure

  1. Issue the APTS command as follows:

    APTS "test_2",MAIN,"table1"

    APTS expands the sequencer area by 3 (not 4) lines, defines the label, and creates the STVA, STSA, and STOP instructions. APTS also lets the STVA instruction point to the current end of the vector areas (432).

    Note that you can use APTS only for labels of types MAIN and SVEC. For the other label types, you must proceed as described in steps 1 and 2 of Creating a label with low level commands.

  2. For the further steps, you must activate the new label for editing with the TSTL command if you want to apply any edit command:

    TSTL "test_2",(@)

  3. Now you can insert the GENV instruction and expand the vector areas with the INGV command in one step (if necessary, determine the command numbers of the new label first with SQLB?):

    INGV 11,12

    INGV inserts the GENV instruction for 12 vectors before the STOP instruction in line 11, and since this is the first vector generating instruction of the new label, it also expands the vector areas of all pins by 2 memory words.

  4. Finally, you must download the waveform DC/DC power units into the vector areas of all pins, which is done with VECD as before.
