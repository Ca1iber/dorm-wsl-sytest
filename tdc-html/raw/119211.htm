Topic 119211

Configuring the Testflow Tool

  • Resolve name conflicts by adding suffix automatically
    • If you check this option, the name of the pasted node is the original name with "_1" suffix.
    • If you clear this option, pasting a node opens the Name Conflict window prompting you to enter a new name for the pasted node.
  • Synchronize selection between Flow Data Editor and Flow Sequence Editor

    Check this to synchronize the display of the test component between the two editors.

    For example, if you click a test suite in the Flow Sequence Editor, the test suite will also be in focus in the Flow Data Editor.

  • Create only UTM based testflow

    Check this to allow you only create a testflow based on universal test methods, or to insert test suites based on universal test methods.

  • Use which UTM executor for single test suite execution

    Here you specify which UTM executor is used for single testsuite execution.

  • Startup options

    Here you specify whether the last opened editor (the Flow Data Editor or the Flow Sequence Editor), or both editors will be opened, when you open the Testflow Tool again.
