SOURCESYNC_TEST.sharingConfigFile()

Specifies the name of a sharing configuration file for use. If not specifying a file with this function, by default, the source-sync test will not use sharing configuration files.

Syntax

SOURCESYNC_TEST& sharingConfigFile (const string& configFileName);
Parameter

Parameter

Description

configFileName

The name of a sharing configuration file to be used.

Make sure this file is located at {device directory}/configuration/. Otherwise, it cannot be used.

Related information

Sharing configuration file

Functional changes

  1. Introduced in MTP 3.2.2
