Topic 10640

Set fixed driver levels

The command DRLV, DRLV? - (DRive LeVel) sets the low and high voltage levels of the driver amplifiers for the named pins or groups of pins. These voltages become part of the level set which you specify.

The drive levels you define determine the logic 0 and logic 1 voltages which are applied to the DUT pin. These levels are subject to swing and range limitations.

The logic 0 and logic 1 parameters are optional. If you omit these parameters, the firmware inserts appropriate values.

The DRLV? query lists the drive levels for any specified pin and level set.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.1: Added new terms for driver modes
  3. SmarTest 7.0.1: Added Pin Scale 9G driver levels
