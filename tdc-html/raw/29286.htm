DSP_XOR_SCL

This API performs a bit-wise logical XOR (exclusive OR) between a scalar value and each element in a specified array.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_XOR_SCL(INT scaler, ARRAY_I& src, 
            ARRAY_I& result);
DSP_XOR_SCL(INT scaler, INT *src, INT *result, 
            INT size);
Parameters

I/O

Parameter

Description / Range

I

scaler

Scalar value. It must be a decimal integer that corresponds to the desired bit pattern.

I

src

Source array

O

result

XORed results

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src)

size ≤ (size of result)

Example

int array1[10];
int result[3];
  .
  .
DSP_XOR_SCL(4, array1, result, 3);

If array1 elements and variable are as follows:

array1[0] = 7 = 0 ... 0111

array1[1] = 5 = 0 ... 0101

array1[2] = 3 = 0 ... 0011

and so on

scaler = 4 = 0 ... 0100

then, the XORed results returned to result are as follows:

result[0] = 3 = 0 ... 0011

result[1] = 1 = 0 ... 0001

result[2] = 7 = 0 ... 0111

Only the first three elements of array1 are processed and returned to result . The remaining elements in result are not changed.
