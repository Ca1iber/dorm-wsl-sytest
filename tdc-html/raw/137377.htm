GET_MULTIBIN

Gets the software bin number and hardware bin number of the multibin.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

void GET_MULTIBIN(STRING& softbin, INT& hardbin);
Parameters

I/O

Parameter

Description

O

softbin

The software bin number of the multibin.

O

hardbin

The hardware bin number of the multibin.

Return value

There is no return value.

Example

STRING softbin;
INT hardbin;
GET_MULTIBIN(softbin, &hardbin);
cout << "Soft bin : "  << softbin  << endl;
cout << "Hard bin : "  << hardbin << endl;
