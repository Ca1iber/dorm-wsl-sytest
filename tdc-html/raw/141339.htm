EVENT_ICVM.iClampHigh()

Sets the high clamp current value.

You can specify both the low and high clamp current values or just one.

Syntax

EVENT_ICVM & iClampHigh ( const EVENT_VALUE_DOUBLE & value );
Parameter
Parameter Description
value

High clamp current

Return value

A reference to the corresponding EVENT_ICVM object.

Example

For an example see EVENT_ICVM.

Related information

EVENT_ICVM.getIClampHigh()
EVENT_ICVM.getIClampLow()
