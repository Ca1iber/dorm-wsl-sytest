HSM3600 Memory Test Card

The Pin Scale System is the latest infrastructure of the V93000 HSM Series which supports the following hardware:

  • The high density channel board E8610A called HSM3600 Memory Test Card.
  • A high-performance clock board.

This gives you the capabilities for testing single ended or differential applications up to a data rate of 3.6 Gbit/s (at 1.65 V swing) and supporting up to 8 independent clock domains and 32 read/write utility lines.

In conjunction with this hardware the following hardware and software features are available:

  • Hardware
    • Support of 8 drive and 8 receive edges with full tri-state support for all 8 drive edges.
    • Increased waveform memory to accommodate 256 waveforms.
    • Availability of a dynamic drive high level shift option
  • Software
    • Convenient expression based wavetable syntax.
    • Support of device cycle names up to 16 characters.
    • Introduction of a Pattern Debug Tool in the SmarTest work center to replace the vector editor and states list tools.
    • Support of a special differential view in the wavetable for differential pins.
    • "Format" definition in the vector setup, to allow you to make one differential vector set from two single ended sets.
    • A new programming syntax for the timing.
    • Support of X2, X3, X4, X6 and X8 modes for each pin.
    • Use of "contexts" for pins, levels and timing.

Benefit

Because the HSM3600 memory test card offers data rates of up to 3.6 Gbit/s, you can use them to test devices such as:

  • Rambus XDR DRAM
  • Graphics DDR3/4
  • DDR2 and DDR3

and other high-speed memories
