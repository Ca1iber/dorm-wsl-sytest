How to set up a dynamic DC test

Subtopics

  1. A dynamic DC test example
  2. DC event application examples

These use case examples illustrate the setup of a dynamic (sequencer‑controlled) DC test and will help you to understand the related user interface concepts, firmware commands, and test methods. Dynamic (sequencer‑controlled) DC tests are opposed to static (set-based) DC tests.

  • The dynamic DC test example uses one DC signal pin (PMU) and one power pin (DPS). The test will
    • drive a rising voltage signal on the power pin (DPS), using test points on the sequencer.
    • measure the output voltage on the DC signal (PMU) pin.
  • Refer to Event classes and data types for a list of all DC event related APIs.
