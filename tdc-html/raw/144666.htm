CCTsetSubExecutionFlag()

Sets the sub-execution flag for the test suite.

It needs to be put in the init() function of the concurrent test framework.

Syntax

void CCTsetSubExecutionFlag(const bool flag = true);
Parameter

Parameter

Description

flag

The flag indicating the end of a sub-execution group.
List of available options of parameter: flag

Option

Description

true (default)

The current test suite and the previous untested test suites in the CCF block are set to one sub-execution group.

false

The sub-execution group does not end in the current test suite.

Return value

There is no return value.

Example

CCTsetSubExecutionFlag(0);

Functional changes

  1. Introduced in SmarTest 7.2.1
  2. SmarTest 7.2.1: Supported with patch 2.
