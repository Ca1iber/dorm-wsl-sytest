This section describes the procedure of developing a universal test method library in SmarTest.

About this task

The procedure is to create a universal test method library from scratch. If you have already some classic test method libraries, you can convert them to universal test method libraries. (See How to convert a classic test method project to universal test method project)

Before you begin

Make sure you are using SmarTest 6.3 or later, and the device primary setups are ready to use.

Procedure

  1. Create a universal test method project.
  2. Create a universal test method class for the universal test method project.
  3. Create a universal-test-method-based testflow.
  4. Debug a universal test method.

Results

The universal test method libraries are error free and ready to use.
