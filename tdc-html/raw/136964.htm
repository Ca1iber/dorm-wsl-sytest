DC_WAVEFORM.iRange()

This function defines the input current range, for which the DC waveform gets created.

Note To execute the waveform, the PPMU needs to be connected in the range.

Syntax

DC_WAVEFORM & iRange (DOUBLE iRange);
Parameter

Parameter

Description

iRange

The value of input current range for a DC waveform.

Return value

A DOUBLE data representing the input current range is returned.

Related information

DC_WAVEFORM.getIRange()

Functional changes

  1. Introduced in SmarTest 7.2.0
