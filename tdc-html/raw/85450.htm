The hardware definition file (HDF)

The hardware definition file (HDF) describes the hardware of the current test system, because hardware of production test systems may differ from the development test system.

The HDF describes the hardware of your test system:

  • Tester type
  • Available cards or boards
  • Memory mode
The tester type is SOC Series, and the memory mode is either compatible (COM) or unified (UMM).

Functional changes

  1. Introduced before SmarTest 6.3.2
