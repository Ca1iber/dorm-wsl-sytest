GPIB communication flow for TechWing handlers

This section describes the GPIB communication between the driver and TechWing handlers. The actions and messages are listed in the sequential order in the table below.

See Conventions for GPIB communication for descriptions of the syntax.

GPIB communication flow for TechWing handlers

Message from driver

Message from prober

Comment

wait for devices: <SRQ> <query testkind> <poll>

 

The driver only supports the interrupt method.

SRQ

SRQ(0X41)

Handler sends test start SRQ.

query testkind:

TESTKIND?

TESTKIND n

The following results can be returned for the query:

"TESTKIND 02": prime lot start

"TESTKIND 04": first auto-retest

"TESTKIND 05": second (last) auto-retest

"TESTKIND 08": retest done

"TESTKIND 10": lot end

For normal test, the TechWing handler always sends the "TESTKIND 02" which thus means the normal device start; after this, the driver will poll the device number.

Poll: FULLSITES?

 

FULLSITES n

Handler returns bit coded site number.

bin devices:

BINON n

ECHO n

Bin the devices. n represents the bin code string for all the sites, like "xxxxxxxx,xxxxxxxx". The first character is the Site 16's bin code, and the last character is the Site 1's bin code.
