Parameter: tel_send_wafer_abort

For certain TEL probers the "VF" command (unload all wafers and force a lot end) is not a valid command. In such cases communication will fail when the driver sends out a "VF" command. This can be seen, for example, if the user decides to quit a currently running session in which a wafer is still being probed. If such an error is detected then this parameter should be set to "no" to prevent the "VF" command being sent.

Driver default: "yes"

Changeable at run-time: yes

Applicable for: TEL probers

Example: tel_send_wafer_abort: "no"
