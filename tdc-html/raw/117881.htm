The Training API consists of a number of classes that provide the underlying functions of the GDDR5 training test methods to other test methods.

See the description of the individual classes for details:

  • CDataEyeAlign provides functions for data eye alignment training.
  • CSearchTask is the base class for the trainings implemented in CDataEyeAlign and CTransistionAlign.
  • CTestMethodConfig provides functions for handling GDDR5 training configuration files.
  • CTransistionAlign provides functions for finding transitions.

Using the Training API classes

To use the classes in this library, you must link it in your program. The relevant files are found here:

  • solution_tools/common/training/include/ contains the header files for the API.
  • solution_tools/common/sh_lib/libtrainingapi.so is the shared library.

Example

See the source code for the GDDR5 training test methods at /opt/93000mts/mts/solution_tools/sh_lib/GDDR5Test.tar.gz for an example of how to use the classes and functions of the Training API.
