X-mode and digital capture throughput

The X-mode can both create opportunities and potential difficulties with digital capture throughput.

Avoid X1, X2 modes for selective digital

In X1 or X2 mode for selective digital capture, twice the needed data is uploaded to the system controller.

Internally, the compare mode Acquire All is activated and this mode only supports 2 bit result code formats. In addition, the 2nd bit of every pair needs to be stripped out in firmware prior to making it into a result container. This costs test time.

In X1 mode, for example, 1000 samples require 2000 results bits in the memory, whereas 1000 samples in X4 mode require 1000 result bits in the memory.

Prefer X4, X8 modes

For digital capture the X4 or X8 modes are optimal! The X4 and X8 modes show about the same throughput, and therefore should be used for optimal throughput.
