Accessing the MTP build configuration pages

There are three ways to access the MTP build configuration pages, via the toolbar, menu bar, or Project Explorer of SmarTest.

About this task

Open the MTP build configuration pages when you want to set up or edit configurations for building MTP .apg files.

Before you begin

Make sure:

  • MTP is installed.
  • A memory device is loaded in SmarTest.

Procedures

Method A: from the toolbar of SmarTest

Select MTP Build Configuration as displayed in the following picture:

Method B: from the menu bar of SmarTest

Select 93000 > Memory Test > MTP Build Configuration.

Method C: from the Project Explorer of SmarTest

  1. In the Project Explorer view, select an MTP device.
  2. In the menu bar of SmarTest, select Project > Properties.

    The property window opens.

  3. In this window, expand Advantest V93000.
  4. Expand MTP Build.

Results

You see the MTP build configuration pages which contains three pages: MTP Build, Compiler Options and Environment. For details, see The MTP build configuration pages.

What to do next

Set up or edit build configurations on these pages, see The MTP build configuration pages.
