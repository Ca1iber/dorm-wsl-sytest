Detailed Description

Typedef Documentation

typedef void(* gio_error_handler_t) ( IDID id, GIO_ERROR error)

Type of error handler functions.

An error handler is called when a GIO function encounters an error. The first argument to the handler is the IDID of the session which was passed to the failing operation (if any); the second argument is the error code.

There is only a single, global error handler.

If an error handler returns to its caller, the client application will be notified of the error via a returned error code (which is identical to error).

Attention
The id may be zero in some situations (e.g., when gio_open() or gio_resume_events() encounter errors).

Enumeration Type Documentation

enum GIO_ERROR

Error codes.

Almost all functions in GIO return an error code of this type. All of them, when they encounter an error, set an internal error state which can be queried using the gio_get_errno() function.

Attention
Client applications should normally not check for specific error codes, because not all access methods will return the same set of errors. Exceptions to this rule are codes like GIO_ERR_NO_ERROR (i.e., success) and GIO_ERR_IO_TIMEOUT.
