Topic 103803

Test result display update API

Subtopics

  1. UpdateResultDisplay()

The purpose of this API is to clear and update the test result display window.

For wafer sort, the wafer map needs to be cleared and the header/sub-header needs to be updated before a new wafer is started.

For package test, the header/sub-header needs to be updated before new devices are ready.

Functional changes

  1. Introduced in SmarTest 6.5.0
