HW_STATE.checkGangConnectionParallel()

This member function initiates a gang connection test on the defined ganged pins to verify that all force lines of the individual channels are connected together on the DUT board or at the DUT pins.

The function is supported only with the DC Scale XPS256 card.

The test is performed in parallel for all active sites. The member function returns a go/no-go result for each configured site in a single integer array.

For more information regarding the gang connection test, refer to the Checking the gang connections section in XPS256 programming - Ganging.

The tested pins must be disconnected for the gang connection test.

The member function should be called within the ON_FIRST_INVOCATION block.

Syntax

bool checkGangConnectionParallel (const STRING& pinList, ARRAY_I &result);
bool checkGangConnectionParallel (const STRING& pinlist, const INT samples, ARRAY_I &result);
bool checkGangConnectionParallel (const STRING  pinlist, const INT samples, const DOUBLE maxResistance, ARRAY_I &result);
List of parameters
Parameter Description
pinList The pins connected to the DUT board that will be queried. The pins are separated with commas. If the pinList is empty or an invalid pin is specified, an error message will be thrown out and the test will not be executed.
samples

The optional parameter defines the number of averaged measurements to be performed.

The valid range of the integer parameter is 1 … 128.

The default value is 1.

maxResistance

The optional threshold for the pass/fail decision in ohms (Ω).

The programmable range is 0 ... 100 Ω.

The default value if another syntax is selected and no threshold is defined is 20 Ω.
result Integer array that is filled with the go/no-go results of the gang connection test of all tested sites.

The size of the array is defined by the number of configured sites. The first element of the array corresponds to site 1.

The returned integer values are to be interpreted as follows:

-1:
No test performed: The corresponding site is not active.
0:
The Kelvin test has failed on the corresponding site.
1:
The Kelvin test has passed on the corresponding site.

Return value

The returned bool value indicates the state of the conversion from the read data to the data in the array:

true
No error found
false
Invalid data read

Example

The following example performs a gang connection test on three pins "pin1", "pin2", "pin3". The test is implemented into the ON_FIRST_INVOCATION block but a FOR_EACH_SITE block is used for the serial sense connection test. Note that the FOR_EACH_SITE_BEGIN_WITH_QUERY() API must be used to set the query focus within the block.

SPMU_TASK       spmuTask;
HW_STATE        hwState;
STRING          pinlist         = "pin1, pin2, pin3";
int             samples         = 10;
double          maxResistance   = 30.0 Ohm;
ARRAY_I         goNogoResult;
ARRAY_I         perPinResult;

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Disconnect the tested pins
    //
    spmuTask.pin(pinlist).vForce(0.0 V).min(-1.0 A).max(1.0 A).relay("NT");

    spmuTask.execMode(TM::FORCE_OFF).execute();

    //
    // Perform the gang connection test in parallel on all active sites
    //
    ARRAY_I goNogoResult;

    hwState.checkGangConnectionParallel(pinlist, samples, maxResistance, goNogoResult);

    //
    // Evaluate the go/no-go results, re-test failing sites
    //
    cout << "Parallel gang connection test GoNogo results per site:" << endl << endl;

    FOR_EACH_SITE_BEGIN_WITH_QUERY();
    {
        cout << "\tSite " << CURRENT_SITE_NUMBER() << ": ";

        if (goNogoResult[CURRENT_SITE_NUMBER() -1] == 1)
        {
            cout << "PASS" << endl;
        }
        else
        {
            cout << "FAIL, serial test on site " << CURRENT_SITE_NUMBER() << endl << endl;

            //
            // Serial test identifies failing pins
            //
            hwState.checkGangConnection(pinlist, samples, maxResistance, perPinResult);

            for (int arrayIndex = 0; arrayIndex < perPinResult.size(); arrayIndex++)
            {
                cout << "\t\tPin " << arrayIndex + 1 << " = " << perPinResult[arrayIndex] << endl;
            }

            cout << endl;
        }
    }
    FOR_EACH_SITE_END();

    cout << endl;
}
ON_FIRST_INVOCATION_END();
