Cpk & Limit Calculator

The Cpk & Limit Calculator lets you determine which limits are required to achieve a desired Cpk value for a given test or which Cpk values would result from particular limits.

The dialog is opened from a test summary view with the Cpk Limit Calculator shortcut menu command.

The calculator consists of these sections:

  • Data Set: The test suite, test method, and test name of the selected row.

    This is the test for which the Cpk value or limits will be calculated.

  • Statistics: Some important statistical values from the selected test. This section also contains input fields:
    • Cpl: The left field (not editable) displays the Cpl value of the selected test summary. The right field lets you enter a desired Cpl value. (This value is used for calculating limits; see the description of the Calculate Limit button, below.)
    • Cpu: The left field (not editable) displays the Cpu value of the selected test summary. The right field lets you enter a desired Cpu value. (This value is used for calculating limits; see the description of the Calculate Limit button, below.)
  • Limits: The current and, optionally, desired limits of the selected test:
    • Upper Limit: The left field (not editable) displays the upper limit with which tests in the selected test summary have been performed. The right field lets you enter a limit value. (This value is used for calculating Cpk values; see the description of the Calculate Cpk button, below.)
    • Lower Limit: The left field (not editable) displays the lower limit with which tests in the selected test summary have been performed. The right field lets you enter a limit value. (This value is used for calculating Cpk values; see the description of the Calculate Cpk button, below.)

The calculator contains these buttons:

  • Calculate Cpk: Clicking this button calculates the Cpk, Cpl, and Cpu values that the selected test would have produced with the limits as entered in the right-hand fields of the Limits section. The contents of the right-hand Cpl and Cpu fields is overwritten.
  • Calculate Limits: Clicking this button calculates which limits would have been needed to achieve the Cpl and Cpu values in the right-hand Cpl and Cpu fields. The contents of the right-hand Upper Limit and Lower Limit fields is overwritten.
  • Reset: Resets the values in the four right-hand fields to the actual values from the selected test (that is, the values that are displayed in the left-hand fields).
  • Close: Closes the calculator window.
