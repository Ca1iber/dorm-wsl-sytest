Returning Test Running Status

To return test running status, use the IS_TEST_RUNNING API. For details, see IS_TEST_RUNNING.

To return the digital sequencer status, use the isRunning member function of the SEQUENCER_STATUS API.

The APIs that execute a test (except the START_TEST API) is usually programmed so that it waits at least until the digital sequencer stops.
