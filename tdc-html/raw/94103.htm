Topic 94103

Filling rules for DC Scale cards (Pin Scale & Smart Scale)

DC Scale cards can reside in any channel card slot of a card cage but the following filling rules must be respected for V93000 Smart Scale and Pin Scale systems:

  • A pair of adjacent odd and even slots must be filled with the same card type. For details see Card compatibility.
  • On the large DUT interface, no UHC4T pogo block is allowed in the four outer half-groups. For details see UHC4T standard configuration.

These filling rules apply only to V93000 Smart Scale and Pin Scale systems.
