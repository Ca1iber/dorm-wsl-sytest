Topic 70624

Configuring the STDF file locations

If you wish to change the path locations for STDF files or the generation of STDF from the Testflow Editor you may edit the configuration file called global.conf located in the /etc/opt/hp93000/soc_common/datalog directory. If you delete the file or delete an option, the formatter will use default values.

Note If you need another copy of the global.conf file you can copy the file global.conf.template also located in the /etc/opt/hp93000/soc_common/datalog directory.

The options available in the global.conf file are described below.

Contents of global.conf located at /etc/opt/hp93000/soc_common/datalog

Configuration Option

Data Type

Value

Description

formatter.stdf.generateStdf

Boolean

True

If generateStdf is set to true, then STDF will be generated according to the settings in the formatter.stdf.main.conf file. For example, if generateDetailedFile = true or generateSummaryFile=true, then STDF will be generated.

 

 

False (default)

No STDF file will be generated.

formatter.stdf.detailedFileLocation

String

$HOME/stdf

Location of detailed STDF file.

formatter.stdf.summaryFileLocation

String

$HOME/stdf/summary

Location of summary STDF file.

formatter.stdf.testFlowEditorFileLocation

String

$HOME/stdf/manual

Location of STDF files generated from Testflow Editor.

formatter.stdf.getOutputFileNameFromAppModel

Boolean

True

If set to True, the application model variable STDF_FILE, if it exists, is used to determine the STDF file name. If it starts with a / it is treated as an absolute path.

If it does not start with a /, it is treated as a path relative to the configured output directories as mentioned above.

 

 

False (default)

If you are testing lots of packages or wafers and generate one detailed STDF file per lot, the file will be named:

main_Lot_<lot id>

_<timestamp>_STDF

If you are testing wafers and generating one detailed STDF file per wafer, the file will be named:

main_Lot_<lot id>

_Wafer_<wafer id>

_<timestamp>_STDF

If you are generating a summary file instead of a detailed file the word "Summary" will appear before the word "Lot", for example, if generating one STDF file per lot the file would be named:

main_Summary_Lot_<lot id>

_<timestamp>_STDF

The timestamp is the time that the lot started; the following information is included

<month>_<day>_<hour>

h<minute>m<second>s

Single-digit days are padded with an underscore; single-digit hours, minutes, and seconds are padded with a zero. For example, an hour and five minutes past midnight on New Year's Day is Jan__1_01h05m00s.

formatter.stdf.generateStdfFromTestflowEditor

Boolean

True

Enables generation of STDF files when a testflow is run from the Testflow Editor

 

 

False (default)

Disables generation of STDF files when a testflow is run from the Testflow Editor

formatter.stdf.alternateLotLevelName

String

lot (default)

The formatter will assume the lot level is named "lot".

 

 

non-zero string

The formatter will assume that the name of the lot level in the application model is the string specified.

formatter.stdf.main.priority

 

 

This option is reserved for internal use. Do not edit it.
Note The file locations listed above refer to your home path variable.
