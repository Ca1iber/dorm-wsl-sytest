syncCommand

The syncCommand signature is to synchronously execute a control command which has no output value. It has no outputs and will impact the SmarTest system status after execution.

Prototype

xoc::hvmapi::Status syncCommand(
const string &cmdName, 
const ParamList &cmdParams=ParamList( ), 
const string &sessionID= string(""));
Parameters

cmdName

The synchronous command to execute.

cmdParams

The parameter list of the synchronous command.

sessionID

The ID of the session to work with.

Example

string sid = "sessionID"; // the exact session ID used  
ParamList inParams;
inParams ["EXECUTION_STATE"] = "ACTION_ASSIGNMENT_EVENT";
inParams ["VARIABLE_NAME"]  = "lot_id";
inParams ["VARIABLE_VALUE"] = "123";
syncCommand ("IssueHVMExecutionEvent", inParams, sid);
