This section describes the data types provided by the DRL and gives the full type definition of each.

Variables of the DRL data types are designed to hold all kinds of event data and allow easy processing of this data. You assign logged event data to these variables by calling corresponding DRL functions.

Most of the DRL data types are structures, with the structures' members containing the actual data.

DRL data types with names ending in "Attr" (like, for example, DRLTestSuiteNameAttr or DRLPinResultAttr) hold the complete data in the body section of an attribute record.

Functional changes

  1. Introduced before SmarTest 6.3.2
