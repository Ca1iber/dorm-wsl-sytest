Controlling printing accumulated status from testflow

By setting up a user flag in testflow, you can control whether to include the accumulated status in the automatically saved tester status outputs (ASCII files) when testflow execution completes.

About this task

When the user flag enableTestsuitesPreAndPostHWStateLogging is enabled in testflow, tester status are automatically saved to text files when testflow execution completes. See Printing tester status from testflow for details. A user flag enableAccumulatedStateLogging provides further control of whether accumulated status are included in the outputted tester status. This flag controls two types of accumulated status: the Power Supply Accumulated Status, as which is retrieved by the PSAS? firmware command and the Channel Slot Accumulated Status, as which is retrieved by the CSAS? firmware command.

Before you begin

Check that your SmarTest has a version no less than 7.5.3.

Make sure that your device works properly.

Make sure the enableTestsuitesPreAndPostHWStateLogging user flag is enabled, as described in Printing tester status from testflow.

Procedure

  1. In the Test Program Explorer panel, right-click Test Program and load your test program.
  2. Right-click Testflow and select Load All Setups.
  3. Right-click Testflow and select Open With > Flow Data Editor.
  4. Select the Variables tab.
  5. Add the user flag enableAccumulatedStateLogging.
    1. In the Variables tab, right-click and select Add Variable....
    2. On the Add Variable window displayed, select USERFLAG for Type.
    3. Enter enableAccumulatedStateLogging for Name.
    4. Enter a value for Value.

      Enter 1 to include the accumulated status in the tester status outputs, or enter 0 to exclude them from the tester status outputs.

  6. Right-click Testflow and select Open With > Flow Sequence Editor.
  7. Right-click the testflow displayed in the flow sequence editor and select Run Testflow.

Results

After testflow execution, tester status are printed to text files in the TestsuitesPreAndPostHWStateLog folder under <your device root>/waste.

For each site, a pair of pre-run and post-run hardware status logs are saved.

Example

If you open the saved files with a text editor, the outputs look the same as what you print to System console using the Print Tester Status button. See Printing tester status from system control for an example of outputs.

What to do next

See also Printing tester status from test method if you need to customize your outputs.

Functional changes

  1. Introduced in SmarTest 7.5.3
