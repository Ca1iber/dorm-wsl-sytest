DRLEventMask

A variable of this type holds an event mask. The active event mask, which is set by DRLSetEventMask, determines whether an event is masked or unmasked. Every event record will be treated accordingly by the function DRLGetNextUnmaskedEvent.

The event of type <EventType> is masked if the member event_mask[<EventType>] is not zero; it is unmasked if event_mask[<EventType>] is zero.

For compatibility of user-written data retrieval programs with future software versions of SmarTest, you should always assign the value NumberOfEventTypes to the member size.

typedef struct {unsigned short size;
                unsigned char event_mask[NumberOfEventTypes];
               } DRLEventMask;

Example

void example (void)
{
  DRLEventMask event_mask = {NumberOfEventTypes,0};
  /* initialization */

  event_mask.event_mask[TestSuiteStartEventType] = 1;
  event_mask.event_mask[TestSuiteEndEventType] = 1;
  event_mask.event_mask[BinReachedEventType] = 1;
  event_mask.event_mask[AssignmentEventType] = 1;
  /* masking of events which are specified by the
     event type*/

  DRLSetEventMask(&event_mask);
 /* sets the active event mask as specified in event_mask */
}

Functional changes

  1. Introduced before SmarTest 6.3.2
