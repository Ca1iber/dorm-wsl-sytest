DTCP, DTCP? - (Define Technology Control Parameters)

This command serves to control certain system control parameters. It supplements the DSCP command. The values that are defined with DTCP must be activated with the *RST command.

The DTCP? query returns the currently selected value of a specified parameter. Note that this is not the active value, if a new value has been defined, but not yet been activated with *RST.

DTCP

DTCP {"key"}, {"value"}

DTCP?

DTCP? {"key"}

returns:

DTCP {"key"}, {"value"}

Parameters

key The string specifies the system control parameter.

Currently, the only supported control parameters are testpoints and extended_dram_factor.

For more information, refer to testpoints and extended_dram_factor in Technology file for a device.
value The value to be set as string.

Examples

> DTCP? "testpoints"
< DTCP "testpoints", "0"
> DTCP "testpoints", "100"
> DTCP? "testpoints"
< DTCP "testpoints", "100"
> *RST
> DTCP? "testpoints"
< DTCP "testpoints", "100"
> DTCP "extended_dram_factor","90"
> *RST
> DTCP? "extended_dram_factor"
< DTCP "extended_dram_factor","90"
