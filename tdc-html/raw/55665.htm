DPS_PIN_TASK

The DPS_PIN_TASK class is a subsidiary data container of the DPS_TASK class, holding the current limits for pass/fail judgments for device power supplies (DPS).

Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/DpsPinTask.h.

Constructor
You cannot directly construct any objects of this class. The DPS_PIN_TASK class is a subsidiary data container of the DPS_TASK class. You can access this class object via the pin() member function of the DPS_TASK class by specifying the target DPS names.

min()
DPS_PIN_TASK & min(DOUBLE val);

This function sets the lower current or voltage limit for pass/fail judgment. Both the minimum and maximum limit must be specified by the min and max functions. If not, an error occurs when the measurement program is started. Both the minimum and maximum limit values are used to set the DPS measurement range. See also the note below.

This function creates multiple sets of the lower and upper limit values for pass/fail judgments by using a MULTI_LIMITS class object. Note The current range defined by the DPS_PIN_TASK minimum and maximum values remains after the DPS_TASK execute() member function is called. The regulation performance of the DPS is negatively affected by the current sense resistor and therefore the current measurement range should be restored to the highest possible range after a low current measurement. switchableCap()
DPS_PIN_TASK& switchableCap( const STRING & utilityPinName, TM::SWITCHABLE_CAP_STATE state );

This function is used to switch the state for the specified utility pin in order to set the load capacitance to the value specified by member function targetCap().

The target state of the utility pin is defined by parameter state. The selected state is applied for measurement only. The original state is automatically restored after the measurement.

The function is only supported with the XPS256 specifications in DPS operating mode.

Parameter
utilityPinName

The name of the utility pin that switches the capacitor on or off and is defined in the Utility Pins editor.

Multiple utility pins can be defined as comma separated list.
state

The state of type TM::SWITCHABLE_CAP_STATE to be set for the measurement.

Programmable values:

  • TM::CAP_STATE_OFF

  • TM::CAP_STATE_ON

The original state of the utility pin is automatically restored after the measurement.
targetCap()
DPS_PIN_TASK & targetCap (const DOUBLE & capFarad);

This function sets the target load capacitance for member function switchableCap().

The defined load capacitance is set only for the measurement. The original capacitance value, which has been defined in the DPS Pins editor or by the capacitance parameter of the DPSPINS resources, is automatically restored after the measurement. This is needed to, for example, measure the quiescent power supply current for high current XPS256 applications.

The target state of the utility pin is defined by parameter state. The selected state is applied for measurement only. The original state is automatically restored after the measurement.

The function is only supported with the DC Scale XPS256 card.
Parameter
capFarad

The load capacitance in µF (Microfarad).

Number of channels in unganged mode

When using TM:MEASURE_CURRENT_UNGANGED, the values assigned for the .max() and .min() pass/fail limits determine the measurement range. The values also define the number of channels to be temporary unganged respectively remaining in case of an unganged current measurement.

The following rule is applied:

  • No. of remaining ganged channels = CEIL [ P/F limit / ilimitPerChannel ]

The ilimitPerChannel is to be calculated as follows:

  • ilimitPerChannel = (programmedIlimit / totalNumberOfGangedChannels) - clampError
with
  • programmedIlimit = Current limit specified in mA in equation based level setup
  • totalNumberOfGangedChannels = Original number of ganged channels as defined in the pins editor
  • clampError = Maximum error, defined in the current clamp specification of the used DPS

The current limit per channel is defined by the programmed current limit and the total number of ganged channels. For calculating the number of remaining ganged channels, the current limit per channel is lowered by the maximum specified error for the selected range. This will ensure that the requested current can flow in temporary unganged mode.

Note We recommend always, verifying current measurements in temporarily unganged mode carefully. Automatic unganging of channels may result in current measurements directly at the range boundaries or close to the programmed clamp current.

Example

DPS_TASK dpsTask;

ON_FIRST_INVOCATION_BEGIN();

    CONNECT();

    dpsTask.pin("dps1")
        .measurementMode(TM::MEASURE_CURRENT)
        .min(0 mA)
        .max(200 mA);

    dpsTask.pin("dps2")
        .measurementMode(TM::MEASURE_VOLTAGE)
        .min(2 V)
        .max(4 V);

    dpsTask.pin("dps_gang_of_10-A")
        .measurementMode(TM::MEASURE_CURRENT_UNGANGED)
        .min(0 mA)
        .max(10 mA);

    dpsTask.pin("dps_gang_of_10-B")
        .measurementMode(TM::MEASURE_CURRENT_UNGANGED)
        .min(0 mA)
        .max(750 mA);

    dpsTask.samples(5).execMode(TM::PVAL).execute();

ON_FIRST_INVOCATION_END();

cout << "dps1:"  << dpsTask.getValue("dps1") << " A" << endl;
cout << "dps2:"  << dpsTask.getValue("dps2") << " V" << endl;

cout << "dps_gang_of_10-A:" << dpsTask.getValue("dps_gang_of_10-A") << " A" << endl;
cout << "dps_gang_of_10-B:" << dpsTask.getValue("dps_gang_of_10-B") << " A" << endl;

The example executes first a current measurement, then a voltage measurement.

In a third step it executes two single unganged current measurements on the two 10-channel-gangs, for "dps_gang_of_10A" with one remaining channel (see Case A above) and for "dps_gang_of_10B" with two ganged remaining channels (see Case B above). Finally the measured current and voltage values are retrieved.
