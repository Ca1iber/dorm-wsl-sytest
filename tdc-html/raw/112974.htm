Digital Source Memory FLAT setup

Subtopics

  1. Creating a Digital Source Setup for DSM FLAT setup
  2. Download the waveform data to the vector variables for DSM FLAT setup
  3. Viewing and editing content in the MAIN label

The source data is downloaded to the MAIN label. It is called FLAT setup. This section introduces the FLAT setup flow, which is same to the DSM normal setup, except for the following points:

  1. You need not define the DSRC label.
  2. The setting of the Digital Source Setup is different.
  3. You need not insert the SSRC and SRCV instructions in the MAIN label.

The normal sequence for sourcing data form the MAIN label is:

  1. Define the pins (Tool: Pin Configuration Tool). For FLAT setup, you need not define a specific port for source pins.
  2. Define the Timing and Levels (Tool: Timing and Level Setup Tool). See Timing and Levels.
  3. Create a MAIN label, which is for Digital Source Memory in the sequencer or vector memory. (Tool: Pattern Tool). See Defining the MAIN Label.
  4. Define the Digital Source setup including the vector variable configuration and its usage (Tool: Pattern Tool). See Creating a Digital Source Setup for FLAT DSM setup.
  5. Download the waveform data to the vector variables (Tool: Signal Analyzer, Test Methods). See Download the waveform data to the vector variables for SDM FLAT setup.
  6. Run the MAIN label for the test.
