Topic 141298

vForce()

Specifies the voltage to force.

Syntax

vForce(double dV);
vForce(const string& sData);
List of parameters

Parameter

Description

dV

The voltage to force

sData

The string containing the value to be used at run-time. (Refer to Changing the parameter value at run-time with SmartRDI.)

Example

rdi.dc().pin("pinA").vForce(2.5 V).execute();

Related information

SmartRDI timing settings of DC events

Functional changes

  1. Introduced in SmartRDI 2.1.0
