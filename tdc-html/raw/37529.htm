Topic 37529

Considerations for the Global Configuration File

A pattern that is associated in the PATTERNS section of the global configuration file with ASCII devices cycles belonging to a KEEP_PLL_ALIVE section must fulfill the following conditions:

  • If any of its ASCII device cycles belongs to a KEEP_PLL_ALIVE section all its ASCII device cycles must belong to this KEEP_PLL_ALIVE section. This is checked by the timing translation.
  • The KEEP_PLL_ALIVE feature requires that the sequencer program of the vector port contains no CTIM instructions (see the introduction of Setting Up a Continuous Clock with the KEEP_PLL_ALIVE Feature). For this reason, the ctim column of the PATTERNS section, if present, must be set to NCT for the respective patterns. If it is set to CT, the vector translation may insert CTIM instructions automatically into the sequencer program. Note that the value of the ctim column is not checked by the timing translation.
