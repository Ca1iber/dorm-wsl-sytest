Topic 67573

Waveform mapping

Subtopics

  1. Setting up direct waveform mapping
  2. Setting up indirect waveform mapping
  3. Automatic waveform generation

Waveform mapping refers to the process by which patterns of logical zeros and ones created by the APG program are converted to physical waveforms that are sent to the tester pins.

There are two different ways of mapping waveforms in MTL. Both convert logical patterns created by the compiler to indexes into the timing file:

  • Direct waveform mapping uses the standard SmarTest Timing file to convert the patterns to indexes.

    It is set up by specifying the timing file and the desired wavetable as the arguments of the :waveformMap: keyword in the APG pattern file.

  • Indirect waveform mapping uses the MTP Waveform mapping file for the conversion.

    It is set up by specifying the waveform mapping file as the argument of the :waveformMap: keyword in the APG pattern file.

A form of waveform mapping must always be used. We recommend that you always use direct waveform mapping unless there is a specific reason to use indirect waveform mapping. Reasons include:

  • You are using the :devCyc: keyword in the Device access file (which we recommend you no longer do).
  • You are testing devices that require a third level at high data rates. (More generally speaking: You need to map multiple logical waveforms to one physical waveform, which is not possible using direct waveform mapping.)
