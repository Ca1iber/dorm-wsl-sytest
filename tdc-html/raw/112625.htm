Topic 112625

Creating and editing filter rules

The filter that the BFM Viewer applies consists of a number of rules. Adjusting the filter involves adding, deleting, or editing rules and the conditions of which these rules consist.

About this task

Any changes to filter rules and conditions are automatically saved but become active only after you click the Apply button.

When creating and editing rules, remember that the order of rules is important: Rules are evaluated from top to bottom in the order in which they appear in the list, and the last rule to match a given cell determines whether it is covered by the filter or not.

Procedures

Creating a new filter rule

  1. In the Filters tab's Filter Rules list, right-click an existing rule and choose either of these commands from the shortcut menu:
    • Insert Rule to create a new rule above the rule on which you clicked.
    • Append Rule to create a rule below the rule on which you clicked.

      If you right-click in the empty area below the existing rules, only the Append Rule command is available; choosing it creates a new rule at the end of the list.

      The newly created rule is selected; its conditions are displayed in the Selected Filter Rule Conditions list. The new rule contains one default condition.

  2. Specify whether the rule is to hide the matching cells or show them. To do so, double-click the rule in the Action column and choose the desired action from the shortcut menu:
    • Exclude: Matching cells are hidden when the filter is applied.
    • Include: Matching cells are displayed when the filter is applied.
  3. Edit the default condition and add new conditions, as described in Creating and editing filter rule conditions.
  4. If desired, add a comment describing the rule in the Remarks column. To do so, double-click the column and enter the text.
  5. Click the Apply button to make the new rule active.

Editing an existing filter rule

  1. In the Filters tab's Filter Rules list, click the rule that you want to edit.
  2. Make changes to the rule as desired:
    • To change its action type, double-click the rule in the Action column and choose Exclude or Include from the shortcut menu.
    • To edit its comments, double-click the rule in the Remarks column and enter the new text.
    • To change the conditions of the rule, work on them as described in Creating and editing filter rule conditions.
  3. Click the Apply button to make the changes active.

Deleting an existing filter rule

  1. In the Filters tab's Filter Rules list, right-click the rule that you want to delete and choose Remove Rule from the shortcut menu.
  2. Click the Apply button to make the removal active.

Activating and deactivating filter rules

This is described in Activating and deactivating filter rules.

Saving and loading filter rules

This is described in Saving and loading filter rules.

Results

The filter rules are set up as desired and are active.
