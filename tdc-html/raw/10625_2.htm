Topic 10625

Determining the period resolution

Subtopics

  1. Automatic calculation of period resolution for single-port setups
  2. Specifying the Period Resolution
  3. Period resolution, clock resolution, and master clock period
  4. Period resolution for a multi-port setup (Smart Scale)

All periods for all pins in all timing sets belonging to the same single-port timing specification or waveform set must be integer multiples of a value that is called period resolution.

In the case of a multi-port specification every Smart Scale port can have a different period resolution (see Period resolution for a multiport setup (Smart Scale)).

Functional changes

  1. Introduced before SmarTest 6.3.2
