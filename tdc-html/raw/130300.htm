Topic 130300

Restrictions when using MTL arrays

MTL array carry some restrictions regarding their use in loops and changing their values.

These restrictions must be observed when using MTL arrays:

  • Values cannot be assigned to arrays inside a loop, except when there are no other statements inside the loop. See example 1, below, for correct use of a loop with an array and examples 2 and 3 for incorrect uses.
  • Inside loops, values of arrays cannot be assigned expressions that depend on variables outside the loop. The only exceptions is that loop variables from outer loops can be assigned in initialization loops (that is, loops that contain no other statements than assignments to array elements).
  • Once arrays have been assigned to other variables or used as function arguments for the first time, their values cannot be changed any more.

Examples

Example 1

Correct use.

DataWords[2][2] = { {0,0},
                    {0,0} };
DataWordsTwo[2][2] = { {1,1},
                       {1,1} };

  for(j = 0; j < 2; j+= 1)
  {
    for(i = 0; i < 2; i+=1)
    {
      DataWords[j][i] = OtherDataWords[i];
      DataWordsTwo[j][i] = OtherDataWords[i];
    }
  }

Example 2

Incorrect use.

DataWords[2][2] = { {0,0},
                    {0,0} };
var = 0;

for(j = 0; j < 2; j+= 1)
  {
  var+= 1;   // This statement changes a value other than the array.
    for(i = 0; i < 2; i+=1)
    {
      DataWords[j][i] = OtherDataWords[i]; 
    }
  }

Example 3

Incorrect use.

DataWords[2][2] = { {0,0},
                    {0,0} };

  for(j = 0; j < 2; j+= 1)
  {
    for(i = 0; i < 2; i+=1)
    {
      DataWords[j][i] = OtherDataWords[i];
      read(0,0,0,0); // A device access is used in the same loop 
                     // as the array assignment.
    }
  }

Example 4

In this example, the last statement incorrectly tries to assign values to an element of an array that has already been read (in the next-to-last statement).

array[4];

for(j = 0; j < 4; j++)
{
  array[j] = 0; // null initialize
}

array[1] = 0xFF;      // Array values are set.
deviceAccess(array);  // Array values are read.
array[2] = 0xAA;      // Array values are set again: This
                      // is not allowed.
