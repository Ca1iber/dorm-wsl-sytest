HM3500-parallel GPIO configuration

Subtopics

  1. Valid combinations of plug-ins and configuration files
  2. Binning map
  3. GPIO box jumpering
  4. Timing diagram (Seiko-Epson HM3500-parallel)

The "HM3500-parallel" configuration is valid for Seiko-Epson handlers.

Supported handler models

  • HM 2000
  • HM 3000
  • HM 3500

Features

  • up to 3 sites
  • 3 DUT signals
  • no global test start signal
  • parallel binning
  • explicit binning
  • 5 bin categories
  • no "empty" bin

Required handler cable

  • E2790-61601-1
