RESET_EXCEPTION_HANDLER

This API resets all the error handler settings that had been set by the SET_EXCEPTION_HANDLER API.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ExceptionHandler.h.

Syntax

RESET_EXCEPTION_HANDLER( );

Related information

SET_EXCEPTION_HANDLER

Functional changes

  1. Introduced before SmarTest 6.3.2
