Topic 99152

DC event file

Subtopics

  1. DC event file syntax

The DC event file is an optional configuration file that is needed for actively driving the voltage, current, or measurements on DC Scale cards. The file is needed only if such active control is required during the test. (If no DC event file is used, the DC Scale pins act as a standard passive power supply.)

The DC event file has the .dcev file name extension. It is referenced from the APG pattern file with the :dcTest: keyword.

A DC event file consists of named sets of events, which are drive or compare actions assigned to DC Scale pins.

Note Properly driving DC Scale pins requires them to be linked to suitable Reference pins in the Pin mapping file.

Example

:dcTest:
{
  :dcSet:
  {
    :name: vBump
    :table:
    {
      :format:
      { :dcEvent:     :pinList:   :dcSetup:   :type: }
      { forceLow       VDD,VDDQ    vBump,1   dcscale }
      { forceHigh      VDD,VDDQ    vBump,2   dcscale }
      { forceDefault   VDD,VDDQ    vBump,3   dcscale }
    }
  }

  :dcSet:
  {
    :name: IDD
    :table:
    {
      :format:
      { :dcEvent:     :pinList:   :dcSetup:  :type: }
      { setRange       VDD        IDD,0     dcscale }
      { measure        VDD        IDD,1     dcscale }
    }
  }

  :dcSet:
  {
    :name: forceMeasure
    :table:
    {
      :format:
      { :dcEvent:     :pinList:   :dcSetup:          :type: }
      { setRange       VDD,VDDQ   forceMeasure,0    dcscale }
      { forceLow       VDD,VDDQ   forceMeasure,1    dcscale }
      { forceDefault   VDD,VDDQ   forceMeasure,2    dcscale }
      { measureLow     VDD,VDDQ   forceMeasure,3    dcscale }
      { measureDefault VDD,VDDQ   forceMeasure,4    dcscale }
    }
  }

  :dcSet:
  {
    :name: randomPowerUp
    :table:
    {
      :format:
      { :dcEvent:     :pinList:   :dcSetup:   :type: }
      { force0      VDD,VDDQ      powerUp,0   dcscale }
      { force1      VDD,VDDQ      powerUp,1   dcscale }
      { force2      VDD,VDDQ      powerUp,2   dcscale }
      { force3      VDD,VDDQ      powerUp,3   dcscale }
      { force4      VDD,VDDQ      powerUp,4   dcscale }
    }
  }

  :dcSet:
  {
    :name: modulation
    :table:
    {
      :format:
      { :dcEvent:     :pinList:   :dcSetup:        :type: }
      { force1400      VDD,VDDQ    modulation,1   dcscale }
      { force1450      VDD,VDDQ    modulation,2   dcscale }
      { force1475      VDD,VDDQ    modulation,3   dcscale }
      { force1500      VDD,VDDQ    modulation,4   dcscale }
      { force1550      VDD,VDDQ    modulation,5   dcscale }
      { force1600      VDD,VDDQ    modulation,6   dcscale }
    }
  }
}
