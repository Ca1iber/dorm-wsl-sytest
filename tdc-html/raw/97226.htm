EventListenerType

This signature defines the prototype of call back function (event handler).

Prototype

typedef void (*EventListenerType) (
const std::string &evName,
const xoc::hvmapi::ParamList &evParams,
unsigned long sec,
long usec,
const std::string &sessionId );
Parameters

evName

The HVMAPI event category the listener works with. It can be SESSION or EXECUTION.

evParams

The input parameter represented by ParamList.

sec

SECONDS part of TIME_STAMP of the event.

usec

MICROSECONDS part of TIME_STAMP of the event.

sessionId

The ID of the SmarTest session that the event belongs to.

Example

The following example defines an event handler concerning the TESTFLOW_EXEC_COMPLETED event.

using namespace std;
using namespace ::xoc::hvmapi;
void handlerTestflowExecCompleted(const string &evName, 
              const ParamList &evParams, 
              unsigned long sec, 
              long usec, 
              const string &sessionId)
{
  if ( evName == "EXECUTION" ) 
  {
    const string &execState = evParams["EXECUTION_STATE"];
    if ( execState == "TESTFLOW_EXEC_COMPLETED" ) 
    {
      const string & testflowName = evParams["TESTFLOW_NAME"];
      
      //other normal operation here
      ...
    } 
    else 

    {
      printf("Internal Error, the execution state should be TESTFLOW_EXEC_COMPLETED");
    }
  } 
  else 
  {
    printf("Internal Error, the event name should be "EXECUTION");
  }
}
