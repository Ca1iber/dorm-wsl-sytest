Topic 10543

Managing sequencer constructs

There is a group of edit commands that serve to generate and modify sequencer constructs. Their common characteristic is that the necessary changes are performed in both area types, the sequencer area and the vector areas. These commands are:

Command

Description

INGV

Inserts a GENV instruction into the sequencer area and makes room for the new instruction in the parallel vector areas. For some details see Inserting a sequencer instruction.

APDV

Expands a sequencer construct

DELV

Reduces the length of a sequencer construct. For some details see Deleting a sequencer instruction.

SPGV

Splits a GENV sequencer construct into two such constructs

CNGV

Combines two consecutive GENV sequencer constructs into one.

CPYV

Serves to copy waveform DC/DC power units within one sequencer construct

Functional changes

  1. Introduced before SmarTest 6.3.2
