MTP_MEMORY_TEST.setBitmapMode()

The setBitmapMode() member function of MTP_MEMORY_TEST lets you specify whether bit fail maps are created in ASCII mode or binary mode.

This is an optional method. It has an effect only if the generation of bit fail maps is enabled through setImmediateBitmapToFile().

Syntax

MTP_MEMORY_TEST& setBitmapMode(const MTP::BITMAP_MODE mode)

Parameter

Description

mode

The way in which the results are stored in the bit fail map file:

  • MTP::ASCII_ENCONDING: This format is human-readable but takes up a lot more space than the binary format. It is useful when the bit fail map file is expected to be read by humans.
  • MTP::BINARY_ENCONDING: This format cannot be read by humans but takes up much less space and is optimized for large amounts of data.

The default is MTP::BINARY_ENCONDING.

Example

Switching the bit fail map files to ASCII:

MTP_MEMORY_TEST memoryTest();
memoryTest.setBitmapMode.(MTP::ASCII_ENCODING);
