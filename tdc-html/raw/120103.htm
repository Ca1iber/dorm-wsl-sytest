Topic 120103

SMC_CLEANUP()

Terminates all threads of the currently active site and deletes all corresponding queued data. It ensures that all data in the background queue of this site will be deleted and will not further be uploaded nor evaluated whenever that site is running into a fail bin.

The disconnect parameter allows to execute a standard disconnect of the currently active site.

The timeout parameter allows to kill all threads when the given time has elapsed.

CAUTION Killing threads may result in a memory leak or a hang up (freeze) of SmarTest, because resources are not freed up properly.
Note The use of the timeout parameter is intended for experts only!

SMC_CLEANUP() should be called only in case the data of the calculation threads is not needed anymore, for example, if a site has been evaluated to a fail bin already. However, SMC_CLEANUP() does not terminates the background process. That means, that an eventually running calculation process is kept alive and is not terminated. This also means, that data logging is still possible.

Note You need to make sure that you handle incomplete uploads in your code properly.

Use SMC_CLEANUP() inside your bin_disconnect routine in case the corresponding site cannot be synchronized with SMC_SYNCHRONIZE(),, for example, after a failing test. This will ensure that the site related threads get terminated.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Syntax

void SMC_CLEANUP(Boolean disconnect);
void SMC_CLEANUP(Boolean disconnect, DOUBLE timeout);
Parameters

Parameter

Description/Range

disconnect

If true, it stops the threads and executes DISCONNECT for the currently active site.

If false, it only stops the threads.

timeout

The time out in seconds to kill remaining threads.

To be used by experts only!

Return value

There is no return value.
