SHARING_CONFIGURATION.setRefPin()

The setRefPin() member function of SHARING_CONFIGURATION lets you load the sharing configuration information from a given pin's physical connections. Then you can read the configuration data using the data-accessing member functions of SHARING_CONFIGURATION.

The setRefPin() dose not load the specified configuraiton if a configuration has already been loaded.

Note If you are not sure about the pin's physical connections, use the load() member function to load the configuration from the sharing configuration file.

Syntax

void setRefPin(const string & pinName)

Parameter

Description

pinName

The name of a pin whose sharing configuration information you want to load.
