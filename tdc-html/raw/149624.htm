RDI_BURST_POSTFIX

This testflow string variable specifies a name to be appended to the names of all SmartRDI-generated burst patterns in the testflow.

Set up this string variable in the Flow Data Editor. As an option in the Editor, this testflow variable differentiates the burst pattern generations from different testflows in which the test suite names can be the same..

When BURST_NAME_MD5 = TRUE is set in the RDI_Configure file, an MD5 postfix is used to differentiate patterns; and then this RDI_BURST_POSTFIX variable option is no longer required.

Variable

Type

Description

RDI_BURST_POSTFIX

String

Specify a postfix name to be appended to the names of all burst patterns in the testflow.
