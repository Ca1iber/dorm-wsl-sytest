EAEX? - (Edge Action EXpected data)

The EAEX? query returns drive and expected edge action data in the requested cycle range. It is used for cycle reconstruction by the Timing Diagram.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

EAEX? {start_cycle}, {no_of_cycles}, {(pinlist)}

returns: 

EAEX {start_cycle}, {no_of_cycles}, {timing_set}, [err_type], {(pinlist)}, {#spec(data)}

Parameters

start_cycle

This is an integer that defines the first cycle for which information is to be returned. The scanning method and the range of values this parameter can take depend on the analysis mode:

  • In the Start Analysis mode, enter a positive value between 0 and 248. The system responds by counting cycles forwards from the first cycle of the test and returns a positive number. The Start Analysis mode is the default setting.
  • In the Stop Analysis mode, enter a negative number between -248 and -1. The system responds by counting cycles backwards relative to the end of the test at -1 cycle and returns a negative number. This mode is used by the system for Stop-on-Error tests.

no_of_cycles

This is an integer that defines the number of cycles for which information is to be returned.

If a 0 is returned, no data is available for the given range.

timing_set

This parameter is an integer that represents the timing set used in the given cycle range. If the timing set was changed within the requested cycle range, more than one answer is returned.

pinlist

Information is only returned for the pins specified in pinlist. If more than one pin is to be included, the names must be separated by a comma. You can use the @ character to read the edge actions for all pins.

err_type

This parameter is optional and specifies what type of error information is available. It is always NOER since this query only reports expected data.

NOER

Error information is not available. The reported range lies outside the range covered by the Error Map.

#spec(data)

Edge action data in binary format. This parameter reports the length of data (in bytes) being transferred, followed by the reconstructed data. The data is returned for each pin separately. Edges without action are not reported.

 

The data is to be decoded as follows:

Each cycle of the reported cycle range is preceded by a two byte header information:

  • First byte, bits 7, 6, 5, 4: Always zero, reserved for future use.
  • First byte, bits 3, 2, 1, 0: Always 1: number of waveforms contained in the device cycle.
  • Second byte: Number of edge actions following (0 - 140)

 

Each of the following edge actions is described by two bytes:

  • First byte, bit 7: Channel selector for differential pins. The first channel has the value 0, the second the value 1.
  • First byte, bits 6, 5, 4, 3: Waveform index (0 - 9)
  • First byte, bits 2, 1, 0: Edge index (0 - 7)
  • Second byte, bit 7: Error flag

    0: No error on receive edge, or a drive edge

    1: Cannot occur since only expected data are reported

  • Second byte, bits 6, 5: Data parameter

    00: Fixed value

    10: Data parameter 1

    11: Data parameter 2

    01: Reserved for future use

  • Second byte, bit 4: Edge direction

    0: Drive/tri-state edge

    1: Receive edge

  • Second byte, bits 3, 2, 1, 0

    If bit 4 is a 0, then drive/tri-state data:

    Bits 3, 2: Tri-state data

    00: Not used

    10: Tri-state off

    11: Tri-state on

    01: Reserved for future use

    Bits 1, 0: Drive data

    00: Not used

    10: Drive 0

    11: Drive 1

    01: Reserved for future use

  • Second byte, bits 3, 2, 1, 0

    If bit 4 is a 1, then receive data compare method:

    0001: Edge compare to intermediate

    0010: Edge compare to 0

    0011: Edge compare to 1

    0100: Edge compare to mask

    0101: Edge compare to unstable

    1001: Window compare to intermediate

    1010: Window compare to 0

    1011: Window compare to 1

    1100: Window compare to mask

    1101: Window compare to unstable

    1111: Window close

    0000: Reserved for future use

    0111: Reserved for future use

    1000: Reserved for future use

Application

Reconstruction command used by the Timing Diagram in Test Result Commands.

Errors

An error occurs if:

  • You send the query while the sequencer is running. There is then no result data available.
  • You enter an invalid cycle range.

Example

EAEX? 0, 1, (pin1)

returns:

EAEX 0,1,3,,(pin1),#9000000010\x01\x04\x00\x0B\x01\x0A\x02\x19\x03\x1F\x0A

This example returns edge action drive and expected data (in hex notation) for one cycle. To decode the data, convert it into binary notation and use the lists above.

The data in binary format is:

0000 0001 0000 0100 0000 0000 0000 1011 0000 0001
0000 1010 0000 0010 0001 1001 0000 0011 0001 1111

The device cycle contains 1 waveform with 4 edge actions. The edge actions are RZ on the drive edges 1 and 2 and a window compare to intermediate on the receive edges 3 and 4.

Functional changes
