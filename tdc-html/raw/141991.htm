UTILITY_POWER_STATUS.checkState()

Retrieves the current state of a utility power supply.

Syntax

TM::UTILITY_POWER_STATE checkState() const;
TM::UTILITY_POWER_STATE checkState(TM::UTILITY_BOARD_POWER_SUPPLY supplyId, int resourceId) const;

The first syntax queries the state of the Utility power supply - XP pins (V93000 EXA Scale systems) of the first optional Utility Card. The second syntax queries the state of the other utility power supplies of the first Utility Card, all utility power supplies of the second Utility Card, or the Internal utility power supplies.

Parameters
Parameter Description
supplyId

The parameter of type TM::UTILITY_BOARD_POWER_SUPPLY defines the utility power supply to be queried.

Available options of the parameter:

  • TM::UP5V: The +5 V supply on UP5V pins of the optional Utility Card or the internal utility resources.
  • TM::XPP5V: The +5 V supply on XPP5V pins of the optional Utility Card.
  • TM::XPM5V: The -5 V supply on XPM5V pins of the optional Utility Card.
  • TM::XPP3V3: The +3.3 V supply on XPP3V3 pins of the optional Utility Card.
  • TM::P15V: The +15 V supply on UPP15V pins of the optional Utility Card.
  • TM::M15V: The -15 V supply on UPM15V pins of the optional Utility Card.
  • TM::F24VA: The floating 24 V supply on F24VA pins of the optional Utility Card.
  • TM::F24VB: The floating 24 V supply on F24VB pins of the optional Utility Card.
  • TM::UDPS: The Internal Utility Power Option of the internal utility resources that replaces the legacy SE-UDPS.
resourceId

The integer parameter defines the utility power resource to be queried.

Available options of the parameter:

  • 1: First optional Utility Card or the Internal utility power supplies of the first card cage.
  • 2: Second optional Utility Card or the Internal utility power supplies of the second card cage.
Some hints and restrictions for setting the supplyId and resourceID parameters:
  • For compatibility with the Internal utility power supply (V93000 systems), the TM::UP5V supply of the first Utility Card or the internal TM::UP5V supply of the first card cage is always switched on.
  • For compatibility with PinScale and SmartScale systems, the Utility power supply - XP pins (V93000 EXA Scale systems) of the first optional Utility Card can be queried only using the first syntax TM::UTILITY_POWER_STATE checkState() const; without the additional parameters defined. The supplyId parameter set to TM::XPP5V, TM::XPM5V, or TM::XPP3V3 in combination with the resourceID parameter set to 1 is not supported.
  • Independently querying the TM::XPP5V, TM::XPM5V, or TM::XPP3V3 supply is supported only for the second Utility Card with resourceID parameter set to 2.
  • The supplyId parameter set to UDPS is supported only in combination with the resourceID parameter set to 1: Since, the second optional Utility Card occupies all (legacy) DPS pogo blocks, the Internal Utility Power Option cannot be used if a second Utility Card is installed.
Return value
The state of the utility power supply is returned as enum of type TM::UTILITY_POWER_STATE. It can be:
  • TM::UTIL_POWER_STATE_OFF: The utility power supply is switched off.
  • TM::UTIL_POWER_STATE_ON: The utility power supply is switched on.
  • TM::UTIL_POWER_STATE_OFF_TRIP: The utility power supply was shut down automatically because the load-board was undocked or an overcurrent happened.
For more information, refer to Utility power supplies. For a description of the "power good signal", refer to the description of the "XDCGD" pin in Pogo pin assignment - Utility pogo blocks.

Example

Example: Retrieving the state of the External utility power supply

UTILITY_POWER_STATUS    utilityPowerEnum;
vector<STRING>          utilityPowerString;

utilityPowerString.push_back("UTIL_POWER_STATE_OFF");
utilityPowerString.push_back("UTIL_POWER_STATE_ON");
utilityPowerString.push_back("UTIL_POWER_STATE_OFF_TRIP");
utilityPowerString.push_back("UTIL_POWER_STATE_ON_TRIP");

ON_FIRST_INVOCATION_BEGIN();
{
    cout << endl;

    utilityPowerEnum.state(TM::POWER_ON);
    utilityPowerEnum.wait(10 ms);
    utilityPowerEnum.execute();

    cout << "Utility power switched on, state = " << utilityPowerString.at(utilityPowerEnum.checkState()) << endl;

    WAIT_TIME (1.0);

    utilityPowerEnum.state(TM::POWER_OFF);
    utilityPowerEnum.wait(10 ms);
    utilityPowerEnum.execute();

    cout << "Utility power switched off,state = " << utilityPowerString.at(utilityPowerEnum.checkState()) << endl;
    cout << endl;
}
ON_FIRST_INVOCATION_END();
The code above results in the following output in the ui_report window if the DUT board is docked and the "power good signal" indicates that all voltages are settled:
Utility power switched on,  state = UTIL_POWER_STATE_ON
Utility power switched off, state = UTIL_POWER_STATE_OFF

Functional changes

  1. Introduced in SmarTest 7.2.1
  2. SmarTest 7.10.1: Support of utility power supplies of V93000 EXA Scale systems.
