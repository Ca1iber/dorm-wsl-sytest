Variables View

You can view information about the specified variables in the Variables view. When execution stops, the changed values are by default highlighted in red. Like the other debug-related views, the Variables view does not refresh as you run your executable. A refresh occurs when execution stops.

The complex structures of the data type maps, lists and vectors can also be displayed clearly in the Variables view, including the elements, the data types and the element values.

Toolbar

Icon

Command

Description

Show Type Names

This option can be toggled to show or hide type names.

Show Logical Structure

This option can be toggled to show or hide logical structure for the variables.

Collapse All

Collapses the logical structure for the variables.

Add Global Variables

Adds global variables that are available in the project to this view.

Remove Global Variables

Removes selected global variable from this view.

Remove All Global Variables

Removes all global variables from this view.

Menu

Click the triangle icon to open a menu of items specific to this view. You can select a menu item from a shortcut menu.

  • Vertical View Orientation

    This option can be toggled to separate the areas for showing the variables and values vertically.

  • Horizontal View Orientation

    This option can be toggled to separate the areas for showing the variables and values horizontally.

  • Variables View Only

    This option can be toggled to make one area for showing the variables.

  • Wrap Text in Details Pane

    This option can be toggled to show the wrapped text in the area for showing the values.

Minimize

Minimizes this view.

Maximize

Maximizes this view.

Shortcut menu

Menu Item

Description

Select All

Selects all variables in this view.

Copy Variable

Copies a text representation of all selected variables onto the clipboard.

Enable

Enables the selected variables.

Disable

Disables the selected variables.

Display As Array

Displays the selected variable as array data.

Cast To Type

Casts the selected variable value to the desired data type.

Restore Original Type

Restores the selected variable value to the original data type.

Change Value

Changes the value of the selected variable.

Add Global Variables

Adds global variables that are available in the project to this view.

Remove Global Variables

Removes selected global variable from this view.

Remove All Global Variables

Removes all global variables from this view.

Format

Changes the format of the selected variable value to one of the following:

  • Natural
  • Decimal
  • Hexadecimal

Watch

Adds the selected variable to the Expressions View.

Assign Value

Changes the value of the selected variable in the details area (lower area) directly. Select this after typing the new value.

Cut

Copy

Paste

Select All

Performs the standard edit operations. Which options are available depends on where the focus is in this view.

Find/Replace

Opens a Find/Replace dialog that operates only on the text in this view.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.2.0: Enhanced the display of the data types with complex structures like map, list and vector.
