Topic 140848

HSM memory test card pogo pin assignment

Supported V93000 systems : HSM

High-density pogo layout

The high-density pogo cable (HD1x256) required by HSM3G/HSM6800/HSM8G cards routes the signals of four cards to one pogo assembly block. The pogo assembly block holds 256 signal pogo pins plus 272 ground pogo pins and occupies eight neighboring S1/S2 pogo blocks.

This high number of pins requires additional logical pogo addresses, compared to other HSM memory test cards. Previously existing pogo locations have the same name for standard double-density and high-density pogo layouts.

Pogo block numbering: high-density versus double-density

The standard "double-density" style uses both the S1 and S2 pogo blocks for digital pins.

The S1 blocks have numbers like 101-132 and 201-232, while the adjacent S2 blocks have numbers like 301-332 and 401-432. The S2 pogo block number is decided by the number of the adjacent S1 pogo block plus 200. For example, the number of the pogo block adjacent to the pogo block 224 is 424 (=224+200).

The "high-density" style for the HSM3G/HSM6800/HSM8G cards adds 16 pogo pins to every S1/S2 pogo block. Thus resulting in a quadruple density.

To derive the number of the quadruple high-density blocks (magenta ±Bx pins) from the standard "double-density" pogo blocks (yellow ±Ax pins), add 400 to both the compatible S1 and the S2 pogo block numbers.

For example:

101-132 -> + 400 -> 501-532

201-232 -> + 400 -> 601-632

301-332 -> + 400 -> 701-732

401-432 -> + 400 -> 801-832

The additional high-density channel IDs on the large test head are 5BBCC, 6BBCC, 7BBCC, 8BBCC. That is 50101-50116, 50201-50216, ..., to 83201-83216. The compatible channel IDs on the large test head are 10101-10116, 10201-10216 ... to 43201-43216.

Double-density pogo layout

Besides the high-density layout, HSM3G/HSM6800/HSM8G cards also support the established DUT board layout, and therefore 4 pogo blocks per physical board (standard pogo layout).
