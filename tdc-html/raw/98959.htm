How to convert a classic test method project to universal test method project

You may have used some mature classic test method libraries in your testing. If you want to use these test methods in the universal test method environment, you need to convert them to universal test methods.

About this task

A conversion tool is provided with SmarTest to convert a classic test method project to a uniersal test method project. The path of the conversion tool is /opt/hp93000/soc/prod_pws/migration/UTM_conversion/bin/convertTMProject.

The conversion tool is only available for 32-bit SmarTest.

There are some constraints in the test method project conversion.

  • If you modified the classic test method system generated files, except for test method class implementation files (*.cpp), these modifications cannot be converted to universal test method. You need to move these modifications manually to the universal test method project after conversion.
  • After conversion, the comments in the new source file may not be able to explain the code. In this case you need to modify the comments in the new class implementation file to match the source code.

Before you begin

This conversion tool is available with SmarTest 6.3 or later. To successfully convert a classic test method project, make sure that

  • All the project components, including project, classes, methods, parameters and limits, can be accepted and handled correctly by the classic test method editor.
  • The project is error free and can be compiled successfully.
  • The target directory of the converted project is outside of all device directories and Eclipse project directories.
  • A SmarTest license is required.

Procedure

To execute the conversion tool type

/opt/hp93000/soc/prod_pws/migration/UTM_conversion/bin/convertTMProject [-m conversion_mode] [-p name_of_new_project] <path_of_classic_testmethod_project> <output_directory_of_new_testmethod_project>

[-m conversion_mode]: This optional parameter specifies the conversion mode. It can be:

CPPONLY: (default)Only universal testmethod class files (*.cpp) are generated.

CPPHPP: Both universal testmethod class files (*.cpp) and header files (*.hpp) are generated.

[-p name_of_new_project]: This optional parameter specifies the name of new test method project. The name is composed of the following characters: 'a-z', 'A-Z', '0-9', '-' and '_'. If it is not specified, the classic project name is used as the new project name by default.

<path_of_classic_testmethod_project >: This parameter specifies the complete path of the classic test method project which will be converted.

<output_directory_of_new_project >: This parameter specifies the target directory of the new test method project.

Note If some errors are reported in the conversion, you can follow the error messages, make some modifications to the project and fix the conversion issue.

Results

If the conversion was successfully completed, you will find the corresponding universal test method under the target directory.

  • The new test method project name can only contain characters '0-9', 'a-z', 'A-Z', '-' and '_'. Any characters in the classic test method name that violate the naming rule will be automatically converted to '_'.
  • The new test method class name is the combination of classic test method class name and test method name, joined by '_'.

If the classic test method project is invalid or the specified target directory is invalid, the error messages will be displayed in the report window.

Example

In the following example, the classic test method project /home/demo/devices/74HC299/TestMethod/MyTMLib is converted to universal test method project.

Files and directories under the classic test method project directory:

MyTMLib.cpp, MyTMLib.dsw, MyTMLib.h, MyTMLibTlb.cpp, MyTMLib_i.cpp, ClassDcTest.cpp, ClassDcTest.h, myFunc.h, GNUMakefileDBG, GNUMakefileREL, Debug.L, Release.L

Enter the following command in the command line.

$ cd /home/demo/devices/74HC299/TestMethod

$ /opt/hp93000/soc/prod_pws/migration/UTM_conversion/bin/convertTMProject MyTMLib /home/demo/UTMProjects

This creates the following files in the converted project directory /home/demo/UTMProjects/MyTMLib:

ClassDcTest.cpp, myFunc.h, .cproject, .project.

If you use "-m CPPHPP" in the conversion, the header file ClassDcTest.hpp will also be in the target directory.
