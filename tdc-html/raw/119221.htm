Searching for a bin node

Select a bin in this window and then click Go To, the bin will be highlighted in the Flow Sequence Editor.

Software Bin Number

This is a specific value that uniquely identifies the bin. It can be up to five alpha-numerical characters. To be compatible with STDF, the number must be an integer between 0 and 32767. There can be up to 2003 software bins.

Software bins occurring more than once in a testflow are called common bins. They are considered instances of the same bin. All their attributes are identical, including the hardware bin number.

To create common bins, you can clone an existing bin.
