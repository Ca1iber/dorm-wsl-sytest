Topic 80062

Using the bitmap converter

To display the topological addresses, you need to specify the mapping between physical addresses and topological addresses (which are computed by the Result Server).

The conversion is carried out by a shared library called libmapconv-EL7.so. This library is located in the directory:

<device_directory>/mts/bitmap/converters/bin/

To generate a converter:

  1. Execute the script: 
    /opt/93000mts/mts/bfm/bin/cp_conv_template

    This script copies the sample converter source files in a directory such as:

    <device_directory>/mts/bitmap/converters/

    For example, use this command on the command line:

    cp_conv_template <device_directory>/mts/bitmap/converters/

    (The <device_directory>/mts/bitmap/converters directory must exist).

  2. Open the mapconv.cpp file in the <device_directory>/mts/bitmap/converters/src directory with an editor (NEdit, for example).
  3. The mapconv.cpp file contains comments that instruct the user how to program the necessary functions to define a converter. Program the converter functions, as described in these comments.
  4. In the src directory, run:
    /opt/93000mts/mts/bfm/bin/convbuild <source file name>

    This automatically compiles your changes in debug mode and runs an automatic test. The source file is the mapconv.cpp file referred to above (although the user could have named it differently).

  5. When you run convbuild, it brings up a dialog box which provides options to perform a check of the correctness of the source file (the automatic test referred to above) and/or compile the .cpp file. If the test fails, the checker will display the errors and the line numbers they occur on; you can then resolve the errors and run convbuild again to check. Repeat this process as needed to resolve all the errors.
  6. Once the errors are resolved, run convbuild again, and choose the option to build ("release") the library. The compiled library libmapconv.so is placed in the <device_directory>/mts/bitmap/converters/bin directory. When the Bit Fail Map Viewer (see Memory Test Plus Tools Reference for details) is started, it will usually automatically reference the compiled library in the /bin directory.

There are cases where you need to select at least the device directory. There might be more than one converter for the same device.
