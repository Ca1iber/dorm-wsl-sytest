Using multiple windows

If you run SmarTest on a dual screen setup, you can create multiple Eclipse windows. Each window can show a different perspective. The layout of multiple windows is kept when you exit SmarTest.

Procedure

  1. To create a new Eclipse window, select Window > New Window. A new window is created showing the current perspective you are using.
  2. In the new window, open the perspective that you want to use.
  3. If you are using dual screen setup, you can move a window to another screen and see the two Eclipse windows at the same time.

Functional changes

  1. Introduced before SmarTest 6.3.2
