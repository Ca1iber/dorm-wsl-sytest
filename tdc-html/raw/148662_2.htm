limit()

Adds limits for judging the pass/fail result of a dynamic DC measurement on digital pins or DC Scale pins. You must use this function within the RDI_BEGIN and RDI_END block. This function supports one-side limits only on DC Scale pins.

PASS will be issued only if the measured current or voltage lies between the lower and upper limits. Otherwise, FAIL will be issued. To retrieve the pass/fail result, use rdi.getBurstPassFail().

For digital dc, limit() must work together with iForce()/vForce(); otherwise limits will not be applied for burst pass/fail.

Syntax

limit(double dMin, doube dMax);
limit(double dMin, TA::NO_LIMIT)
limit(TA::NO_LIMIT, double dMax)
List of parameters
Parameter Description
dMin The lower limit. The default unit is [V] or [A].
dMax The upper limit. The default unit is [V] or [A].
TA::NO_LIMIT

No limit on one side. It works only with DC Scale pins.

Example

RDI_BEGIN();

    rdi.dc("meas").pin("pinA").vMeas().limit(0.1, 1.2).execute();

RDI_END();

int result = rdi.getBurstPassFail("pinA");

Related information

rdi.getBurstPassFail()

Functional changes

  1. Introduced in SmartRDI 2.3.0
  2. SmartRDI 2.4.1: One new option TA::NO_LIMIT only for DC Scale pins.
