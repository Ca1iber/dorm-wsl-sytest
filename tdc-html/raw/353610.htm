Topic 353610

Downloading and installing the SmartInstall add-on

To be able to install SmarTest software, first download and install the SmartInstall add-on.

About this task

Installing the smart-install-3 software used to install SmarTest software is a three step process:

  • Download the SmartInstall package
  • Install SmartInstall
  • Verify the installed device (system controller workstation)

Before you begin

Make sure the following prerequisites are met:

  • The workstation operating system is Red Hat Enterprise Linux ≥ 7.2.x or the required operating system version for the software to be to be installed, whichever is the higher.

  • You have a my.advantest.com account with access to 'Software Center' and access to the software areas of interest, such as 'smart install 3' to install SmarTest Work Center software. You can request an account at: https://login.myadvantest.com/ and ask for access to "Software Center" and "smart install 3".

The installation commands for SmartInstall must be run as system administrator (root). The two main command line options are:

  • Use su and enter the root password when prompted.
  • Prefix the command with sudo and enter your password when prompted.

Procedure

  1. Open the Advantest Software Center in a browser: https://softwarecenter.advantest.com/

    Login with your credentials.

  2. To get the list of all available SmartInstall releases, from the left menu select:

    SmarTest Addons, scroll down to SmartInstall, and click Show.

  3. Select the latest SmartInstall release and download the package by clicking the icon.

    The SmartInstall (tar.gz) package is downloaded to your browser's download folder.

    Example package: smartinstall_3.7.2-0.0.81bdce8_rhel7.tar.gz

  4. Create an empty installation directory. For example: /tmp/smart-install-3

    mkdir /tmp/smart-install-3

  5. Extract the SmartInstall RPM packages to the installation directory:

    tar xzf /path to smartinstall_<version>_rhel7.tar.gz -C /path to smart-install-3 installation directory

    For example:

    tar xzf /downloads/smartinstall_3.7.2-0.0.81bdce8_rhel7.tar.gz -C /tmp/smart-install-3

  6. Install the RPM packages from the smart-install-3 directory on your workstation:

    yum --assumeyes localinstall --disablerepo=* *.rpm

  7. To check that the installation was successful, enter the following command:

    /opt/ate/smart_install_3/smart-install-3 --version

    The version number of the installed SmarTest version is displayed. For example:

    3.7.2-0.0.81bdce8 (20210401)
  8. For unverified devices only: Before you can install software using smart-install-3, you must login using your Software Center credentials. Enter the command:

    /opt/ate/smart_install_3/smart-install-3 login

    A device verification code is displayed. For example:

    Smart Install 3 - Version 3.0.2-0.0.51c0323 (20200530)
  Copyright (c) 2020 - advantest. All rights reserved!

  Device verification requested.

  Visit following URL: https://login.advantest.com/activate?user_code=ABCD-WXYZ
  Device code: ABCD-WXYZ

  Please verify the device code and login.
  9. Copy the URL created for your device from the message displayed by your workstation and open it in a browser.

    Your device is verified and confirmed with the message:

    Device verification was successful!
  10. Remove the installation directory. For example:

    rm -rf /tmp/smart-install-3

Results

SmartInstall is installed and can be used to install Advantest SmarTest products.
