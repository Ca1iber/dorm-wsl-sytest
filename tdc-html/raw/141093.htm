DIGITAL_OFFSET_SEARCH_PINS.numSteps()

Sets up the number of search steps excluding the start value.

The combination of the start value, the number of search steps, and the step width defines the range for the initial linear search.

Syntax

DIGITAL_OFFSET_SEARCH_PINS& numSteps(INT numstep);
Parameter

Parameter

Description

numstep

The number of search steps excluding the start value.

Return value

A reference to the DIGITAL_OFFSET_SEARCH_PINS object.
