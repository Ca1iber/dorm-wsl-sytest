DPS_MeasVoltage()

This API is used to set up a label to hold the measured voltage.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTMultiportSync.hpp.

Note When using this API with Multi-Site in CTF3.0, the API Sync.flush() must be include into the block ON_FIRST_INVOCATION_BEGIN / END. For details, see the following example.

Syntax

void DPS_MeasVoltage(const String& _pinName, INT _average = 2);
Parameters

pinName(string)

Specifies the pin name.

_average(double)

Specifies the number of readings over which the average is calculated.

Example

CCTMultiportSync Sync;
......

Sync.start();

DCDynamicPort::getInstance().DPS_MeasVoltageRange(mDpsPins, 3.0);
DCDynamicPort::getInstance().DPS_Force("DPS128_2",vin, 50 mA);
DCDynamicPort::getInstance().DPS_MeasVoltage(mDpsPins,2);
Sync.sync();

ON_FIRST_INVOCATION_BEGIN();
Sync.flush();
ON_FIRST_INVOCATION_END();

......
