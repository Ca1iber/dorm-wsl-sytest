EVENT_IM

Measurement event classes provide functionality to define events doing measurements. There are functions to set and query limits or to configure clamp and out-of-range checks.

EVENT_IM allows current measurements without limits, with spec-based limit checks, or with upper and lower limit checks.

Class definition

Specialized measurement event classes are EVENT_IM (Current measurement event) and EVENT_VM (Voltage measurement event).

Both classes derive from the EVENT_BASE class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

These member functions set and query the current clamp checks or the voltage clamp checks.

The selected clamp checks for current or voltage are defined by the active force mode of the target pin:

  • The current clamp checks are set and queried if the pin is forcing voltage.
  • The voltage clamp checks are set and queried if the pin is forcing current.

Per default these checks are off. If they are enabled and a checked clamp is hit, the event contributes with a FAIL to the global test result.

Both the clampChecks() member function and the iClampChecks() member function control the same functionality of the hardware. The same behavior applies for the two get...() member functions.

Automatic down-ranging

DPS128 and XPS256 support automatic down-ranging current measurements.

Automatic down-ranging means that the current range is automatically changed to the best fit range for the measurement and restored to the original range after the measurement.

Two parameters define whether the automatic down-ranging is performed or not:
  • The force current or clamp current range:
    • Can be set explicitly or (if not defined)
    • is automatically derived from the forced or clamped value.
  • The current measurement range:
    • Can be set explicitly or (if not defined)
    • is automatically derived from the pass/fail thresholds.
Automatic down-ranging is performed only if the current measurement range is lower than the force / clamp current range regardless whether the ranges have been set explicitly or have been selected automatically.
For more information, refer to
  • DPS128 / DPS64 specific setup tasks and DC Scale DPS128/64 HC/HV Cookbook - Section 4.2.1
  • XPS256 measure currents and XPS256 programming - Measure currents
  • DPS_AUX_PIN_TASK.checkSetRangeError() and DPS_AUX_TASK.getRangeError()

Example

Defines a current measure event with a limit check based on specs:

EVENT_IM measEventA("measA_limSpec");
measEventA.averages(4);
measEventA.limitLow("LEV:iMin");
measEventA.limitHigh("LEV:iMax");

Defines a current measure event with only an upper limit check:

EVENT_IM measEventA_H("measA_limH");
measEventA_H.averages(2);
measEventA_H.limitHigh(100 mA);
