General information about the Advantest GPIB handler driver

The Advantest handler driver supports many models of handlers, including M4542, M4871, DLT and YUSHAN.

Supported handler models

The Advantest handler driver supports the following handlers:

  • M45 handler family
  • M48 handler family
  • DLT handler family
  • YUSHAN handler family

Configurations

You can use the following handler configurations which are available with the driver.

  • For DLT handlers:

    DLT-GPIB-1-site-32-bin.cfg

    DLT-GPIB-1-site-32-bin-default-mapping.cfg

    DLT-GPIB-4-site-32-bin.cfg

    DLT-GPIB-4-site-32-bin-default-mapping.cfg

  • For GS1 (M4871) handler:

    GS1-GPIB-1-site-16-bin.cfg

    GS1-GPIB-1-site-16-bin-default-mapping.cfg

    GS1-GPIB-1-site-32-bin.cfg

    GS1-GPIB-1-site-32-bin-default-mapping.cfg

    GS1-GPIB-4-site-16-bin.cfg

    GS1-GPIB-4-site-16-bin-default-mapping.cfg

    GS1-GPIB-4-site-32-bin.cfg

    GS1-GPIB-4-site-32-bin-default-mapping.cfg

  • For M45 handlers:

    M45-GPIB-1-site-16-bin.cfg

    M45-GPIB-4-site-16-bin.cfg

  • For M48 handlers:

    M48-GPIB-1-site-16-bin.cfg

    M48-GPIB-1-site-16-bin-default-mapping.cfg

    M48-GPIB-1-site-32-bin.cfg

    M48-GPIB-1-site-32-bin-default-mapping.cfg

    M48-GPIB-4-site-16-bin.cfg

    M48-GPIB-4-site-16-bin-default-mapping.cfg

    M48-GPIB-4-site-32-bin.cfg

    M48-GPIB-4-site-32-bin-default-mapping.cfg

  • For YUSHAN handlers:

    YUSHAN-GPIB-1-site-16-bin-default-mapping.cfg

    YUSHAN-GPIB-1-site-16-bin.cfg

Functional changes

  1. Introduced in SmarTest 7.2.3
  2. SmarTest 7.3.2: New parameters for M4871 driver to define the format of the binning command.
  3. SmarTest 7.3.2: Driver enhancement to support DLT handlers.
  4. SmarTest 7.3.3: Driver enhancement to support YUSHAN handlers.
