Level tab

Within the level tab you can specify one or more level segments that can be linked into your device level file.

The level segment tab carries a symbolic name that will be referred from the device level setup. There can be various definitions for multiple level segments per protocol level definition. This allows for merging level segments flexibly to various level set definitions and locations within the level equation stream.

Within the protocol level setup, the protocol levels are specified for pin roles explicitly. The protocol level definition allows to use variables. These variables are resolved either in the equations or specifications of the device setup or directly in related level segment.

In opposite to a regular device level setup file, the segment does not need to carry level setup information about any other pins that are out of scope of the protocol definition.

Note The specification is based on pin roles defined with the protocol specification and not on (hardware) pin names.
