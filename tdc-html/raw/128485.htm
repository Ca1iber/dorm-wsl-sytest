Topic 128485

Offline result emulation for Class RESULT_AREA_CONFIG

Offline result emulation capabilities will be provided for analog waveforms obtained by digital capture. Digital capture waveforms are unambiguously identified by the result area and the site number. The creation of a result area with the member function appendArea() of the class RESULT_AREA_CONFIG is mandatory for offline result emulation as it is used to associate the result array with the offline data.
