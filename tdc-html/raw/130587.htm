DIGITAL_WAVEFORM.bitStart()

This function specifies the bit number in the label where data retrieval starts. The default value is 0. "bit" means the sub-cycle in a tester cycle (1 cycle/x-mode), for example in x-8 mode, there are 8 bits in a tester cycle.

Note x-mode only applies to pins of FAST mode. To use the x-mode, you need to switch on the FRG enable test suite flag to enable the fine result granularity. (Refer to Usage of test suite flags.)

Syntax

DIGITAL_WAVEFORM& bitStart(INT bit)
Parameter

bit

The bit number where data retrieval starts

Related information
