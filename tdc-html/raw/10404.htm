Starting and Stopping hpt

Typing the following on the Linux command line will start the pws-hpt utility:

$ /opt/hp93000/soc/pws/bin/hpt

To start fw-hpt, enter the following on the command line:

$ /opt/hp93000/soc/fw/bin/hpt

The system responds in both cases with the prompt:

task:

You close hpt with Ctrl+C.
