Diagnostic output

To support debugging of GDDR5 training test methods, the detail of the diagnostic output can be varied by setting the GDDR5_TRAINDEBUG environment variable or the testflow variable of the same name.

The variables can be set to these values:

  • ALL
  • INFO
  • RELEASE
  • WARN
  • ERR
  • NONE

The higher the level, the more output is provided. That is, ALL results in more output than INFO, which results in more output than RELEASE, etc. A higher level always includes all messages from the lower levels.
