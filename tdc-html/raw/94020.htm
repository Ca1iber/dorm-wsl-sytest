Topic 94020

Supported x-modes

Subtopics

  1. X8 mode, mid-level x4 mode, and mid-level x6 mode

There are two supported modes of operation: mid-level x4 and mid-level x6 mode.

In mid-level x4 mode each data drive edge has one associated mid-level drive edge.

For higher data rates mid-level x6 mode has been developed where each tester cycle has one associated mid-level drive edge. A second mid-level drive edge is provided to accomplish pre- and post-amble testing.
