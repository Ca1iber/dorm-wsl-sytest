Topic 122773

Disable cout

Writing to the standard output stream from your test method code increases system overhead, slowing down testing, and should be avoided to maximize throughput.

If you write to cout in your test method code for debugging or development purposes, you should make all such writes conditional and disable them when using the test program for production purposes:

  • Define a variable that is set to 0 for production and 1 for debugging uses.

    You can set this variable in the code of your test method or define it as a property that can be set from a data logging profile.

  • Encapsulate all statements that write to cout in if constructs (or other conditional constructs) that test whether the variable is 1.

Example

...
const static INT DebugFlag = 0;
...
if (DebugFlag) cout << "Starting test" << endl;
...
