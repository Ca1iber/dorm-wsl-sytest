Topic 99281

Importing a testflow from a CSV file

The CSV (Comma-Separated Values) file format is a file type for storing tabular data. The testflow tool lets you import a testflow from a CSV file. You can use this capability to build testflows based on other testflows or to exchange testflows among different test system platforms.

Before you begin

There must be a CSV file containing a testflow.

Procedure

  1. In the Test Program Explorer, right-click the testflow item and select Import.
  2. The Import 93000 Setup window opens. In this window, click Browse.

    The Enter or select file to import window opens.

  3. Select the file you want to import (or enter a new file name to create a file) and click OK.

    The Enter or select file to import window closes and the Import 93000 Setup window is active again.

  4. Click Finish.
    Note Do not uncheck any of the items in the Setups list. Doing so results in an error message and prevents importing the CSV file.

Results

A testflow is imported from a CSV file.

What to do next

Edit the testflow.
