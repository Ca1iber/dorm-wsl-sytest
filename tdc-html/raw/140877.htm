RESULT_AREA_CONFIG_PINS.setResultRetentionEnabled()

Per default, once a user defined result area has been configured and selected for recording, the results are automatically made persistent after the test execution, allowing for a later upload of these results using hidden upload for example. In other words, result retention is per default enabled for all user defined result areas. In some cases though, result retention is not really needed, as the result area may have only been defined to allow for recording of more than 4096 DC value measurement results on a digital pin. In such a scenario result retention can be disabled to save around 100us of overhead using this member function and specifying ‘false’ as the parameter value.

Syntax

RESULT_AREA_CONFIG_PINS& setResultRetentionEnabled(bool isEnabled);
Parameter

Parameter

Description

isEnabled

Boolean flag if result retention is enabled. The default value for this property is true.

Return value

A reference to the RESULT_AREA_CONFIG_PINS() object.
