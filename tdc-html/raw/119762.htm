What is a context?

A context is a way to indicate which settings can be used together. It applies to:

  • Level equation sets
  • Timing equation sets
  • Wavetables
  • Vector labels (via the wavetable definition)

These settings can only be used together if all have the same context.

By default, all settings you create have the DEFAULT context. To use additional contexts, you must create them first and assign them to the settings using the MODECONTEXT keyword.
