Topic 120106

SMC_DISABLE()

Disables the whole SmartCalc feature so that neither hidden upload nor background calculation take place. This is used for debugging purposes to execute parts of a test program without the SMC framework without the need of changing the existing functions calls.

This status will be active until SMC_DISABLE()will be set to false.

SmarTest still evaluates SMC_TEST() statements during SMC_SYNCHRONIZE() with synchImmediately set to false. Thus, SMC_SYNCHRONIZE() must be called even if SmartCalc is disabled.

With synchImmediately set to true, SMC_SYNCHRONIZE() can be omitted. However you need to make sure that SMC_ARM() calls are outside the ON_FIRST_INVOCATION block, because no data log statements can be executed inside that block.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Syntax

void SMC_DISABLE(Boolean value);
void SMC_DISABLE(Boolean value, Boolean synchImmediately);
Parameters

Parameter

Description/Range

value

true: SmartCalc is disabled.

false: SmartCalc is enabled.

synchImmediately

true: SmartCalc immediately executes the SMC_TEST() statements at the end of your SMC_backgroundProcessing() method without waiting for the next SMC_SYNCHRONIZE() call.

Note TESTSET().judgeAndLog_ParametricTest() uses SMC_TEST() internally if Hidden data logging is disabled.

Return value

There is no return value.

Related information

ON_FIRST_INVOCATION_BEGIN

Functional changes

  1. Introduced in SmarTest 6.5.3
  2. SmarTest 6.5.3: Patch 1 - New parameter synchImmediately.
