Opening a data log for examination

A data log that has been loaded into the Data Log Explorer can be opened via double-clicking or a shortcut menu command into a data navigation view where you can explore it. Opening a log automatically creates the statistical evaluations of the data it contains.

About this task

Load a data log to examine the statistical summaries of its content.

Before you begin

Load the data log file. (This is not necessary if you want to examine the system data log stream, which is always automatically loaded.)

Procedure

  1. In the Data Log Explorer, select the data log that you want to open.

    You can select more than one log by shift-clicking or control-clicking additional loaded logs.

  2. Use any of these actions to open the selected log or logs:
    • Right-click and choose Open.
    • Press F3.
    • Double-click the log.

      Double-clicking does not work for opening multiple logs at the same time.

Results

Each selected log opens into one data navigation view which displays the contents of the log in several tables containing statistical summaries.

Note that opened data log files are static (their content does not change), but the system data log stream is dynamic: If new data log entries are generated by a running test, they are immediately added to the open log. The summaries and result displays are updated accordingly.

What to do next

Depending on your requirements, you can:

  • Adjust how the result data tables appear and what data is displayed
  • Examine the underlying data for a summary
  • Open an analysis view
  • Analyze the data in other ways
