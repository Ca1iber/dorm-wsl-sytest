Topic 145681

Saving the system data log stream

The system data log stream can be saved to disk as an EDL file by choosing the Save and Clear shortcut menu command in a data navigation view.

About this task

Save the data log stream when you want to preserve it for future examination.

Procedure

  1. Open the system data log for examination.
  2. In any tab of the data navigation view, right-click and choose Save and Clear from the shortcut menu.

    A standard Save dialog is displayed.

  3. Specify the name and location for the EDL file and click OK.

Results

The current system data log stream is saved as an EDL file in the specified location. The system data log stream is cleared.

What to do next

If you want to analyze the saved file, load it as described in Loading and unloading data log files and open it as described in Opening a data log for examination.
