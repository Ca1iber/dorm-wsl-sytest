Preference page on Test Program Comparator

It lets you configure the compared objects and the generation of comparison reports.

On this preference page, there are four groups of configurations:

  • Setup components of testflow to be compared: Lets you select the settings to be compared between testflows. The setups includes testflows, pins, levels, timings, vectors, test tables, analog setups, test methods and device licenses.

    By default, all are selected.

    These options take effect only on testflow comparisons, which requires you to select the testflow type when setting up comparisons.

  • Global options: Configurations for comparing vectors and test tables.
    • Compare vector data of pins (unchecked by default): Compares vector data.

      This option takes effect only on vector comparison, which requires you to select the vector, vector_bin_file, or vector_directory type when setting up comparisons, or select the testflow type when setting up comparisons and enable the testflow option on this page inside the Setup components of testflow to be compared group.

    • Compare test number of test in test table (checked by default): Compares test numbers.

      This option takes effect only on test table comparisons, which requires you to select the test table type when setting up comparisons, or select the testflow type when setting up comparisons and enable the test table option on this page inside the Setup components of testflow to be compared group.

    • Sow pin group rather than single pins
    • Do not show bypassed test suites or groups
  • Any_Diretory type comparson options

    Select the items you want to compare in the directory.

  • Options of report generation: Configures the output of comparison report.

    You can select:

    • Only show differences (unchecked by default): You will not see the same setups in the report.
    • Generate HTML report (checked by default): You will see an HTML report in the report area of TP360.
    • Generate Excel report (unchecked by default): You will get an Excel report in a specific directory on your computer. This directory is shown in the TP360 report area.

      Note that, if you are comparing testflows and the number of the testflows exceeds 10, only the Excel report is generated.
