Topic 99770

Using classic test method in the universal test method environment

Subtopics

  1. How to convert a classic test method project to universal test method project
  2. How to import a universal test method project
  3. How to convert an incomplete classic test method to a universal test method

To use classic test methods and testflows in universal test method environment, you must convert the classic test methods to universal test methods and convert the classic testflow to universal-test-method-based testflow. The conversion tools are provided with SmarTest.

Before you begin

Make sure you are using SmarTest 6.3 or later, and your classic test method libraries and testflows are ready to use.

Procedure

  1. Convert a classic test method project to a universal test method project
  2. Import the universal test method project in your workspace
  3. Convert the classic testflow to the universal-test-method-based testflow.

Results

The classic test methods are converted to universal test methods and the classic testflows are converted to universal-test-method-based testflows. You can re-use the test method libraries created before in the universal test method environment.
