DCGM, DCGM? - (Digital Compare Global Mode)

The DCGM command sets the recording mode for the detailed Error Map and specifies how the position value defined with DCRP is to be interpreted. The DCGM? query returns the current settings.

DCGM

DCGM {acqu_mode},{emap_pos_int},{ovem_pos_int}

DCGM?

DCGM? [answer_type] [,"exec_context"]

returns:

DCGM {acqu_mode},{emap_pos_int},{ovem_pos_int}

Parameters

acqu_mode

Specifies the recording mode for the detailed Error Map. Possible values are:

ALL

All cycles are recorded (cycle oriented mode). In this mode, recording will wrap around to the start when the error map is full before the specified stop position or the end of the test.

In this mode, the response time of the result queries EMAP? and ERMP? will be better than in the FAIL mode.

FAIL

Only failed cycles are recorded (failure acquire mode). In this mode, recording for the detailed Error Map will always stop when the map is full. Note that this may happen before the area of interest is reached.

In this mode, more data can be stored in the detailed Error Map.

STRD

SmarTest is to decide whether ALL or FAIL is selected.

emap_pos_int

Specifies how the Error Map position, as set with DCRP or SQGB, is interpreted for the detailed Error Map. Possible values are:

STRT

The Error Map position is interpreted as a start value. If the start position is greater than the total number of test cycles, no data will be recorded.

HALT

The Error Map position is interpreted as a stop value. Recording will stop at this position at the latest. If the stop position is greater than the total number of test cycles, recording will stop at the end of the test.

NONE

The Error Map position is ignored. Recording will stop at the end of the test or (if the recording mode is FAIL) when the Error Map is full.

Note that the options STRT and HALT cannot be used with the sequencer modes EL, SE, SEEL, STSQ, and STSV (as set with SQGB). If one of these sequencer modes is active, DCGM will issue a warning, and FTST? will refuse to run.

ovem_pos_int

Specifies how the Error Map position is interpreted for the overview Error Map. Possible values are:

HALT

The Error Map position is interpreted as a stop value. Recording will stop at this position. When the error map is full before this position is reached, recording will wrap around. If the stop position is greater than the total number of test cycles, recording will stop at the end of the test.

This value is only allowed if the emap_pos parameter is also set to HALT.

NONE

The Error Map position is ignored. Recording will stop at the end of the test.When the error map is full before the test ends, recording will wrap around.

answer_type

This query parameter specifies whether the current configuration or the configuration of the last executed test is to be returned. Possible values are:

 

CONF

The current configuration is returned. This is the default.

 

EXEC

The configuration of the last executed test is returned.

exec_context

An execution context. For more information on execution contexts see Using execution contexts . This parameter is only accepted when answer_type is set to EXEC.

Application

Error map.

Example

DCGM FAIL,STRT,NONE

This example sets the error map into acquire failure mode and specifies that the error map position is to be interpreted as a start value for the detailed error map, and to be ignored for the overview error map.

Functional changes
