Create User Defined Function

The following script creates the template of the User Defined Function (UDF) and its Makefile into the current working directory. This template contains the declarations of required header files.

/opt/hp93000/soc/prod_env/lbin/install_udf (function name)

Therefore, the development flow for creating the UDF is:

  1. Run the script "install_udf" with the specified function name.
  2. Create an analysis function with the Test Method API (ARRAY_X, SDP_XXX) and the Data Display API.
  3. Run the "make all" command in order to build the function. If successful, the executable file "function name" will be created.
  4. Assign the function to the toolbar or a shortcut menu of a graph in the Waveform Graphs Tool.
