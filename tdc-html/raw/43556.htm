Topic 43556

Pausing a Production Run

Subtopics

  1. Using the Form Dialog Screen

To pause a production test run, simply click the PAUSE toggle button in the Operation Control screen shown in Controlling a Production Run. This sets the PAUSE flag. The application model evaluates this flag immediately after the execution of a device test. The further course of action is specified in the ON_PAUSE section of your particular application model. For the wafer_auto application model, the test is paused and the Form Dialog screen appears.
