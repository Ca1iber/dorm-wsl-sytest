Topic 95809

ListInstalledSmartestVersions

This data query command lists the current SmarTest version in use and all the SmarTest versions installed on the controller workstation.

SUCCESS is always returned.

Parameters

I/O

Parameter

Description

O

qrResults

The query result is represented by a ParamList object. It contains the following members:

INSTALLED_VERSION_LIST: A string list containing the available SmarTest versions. vector<string> is used to represent the data. The value is empty if no SmarTest installed in the system controller.

CURRENT_VERSION: The current SmarTest version in use, such as "5.4.3".

CURRENT_PATCH_LEVEL: The patch level of the current installed SmarTest version.

Prototype

ParamList qrResults;
Status errobj=query("ListInstalledSmartestVersions", qrResults);

Example

ParamList qrResults;
Status errObj = query("ListInstalledSmartestVersions", qrResults);
vector<string> versions = qrResults.valueArray("INSTALLED_VERSION_LIST");
cout << "current SmarTest version: " << qrResults["CURRENT_VERSION"];
cout << ", current PATCH_LEVEL: " << qrResults["CURRENT_PATCH_LEVEL"] << endl;
cout << "Installed version list: ";
for (int i = 0; i < versions.size(); i++) {
  cout << versions[i] << ", ";
  }
cout << endl;

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.3.2: New output parameter CURRENT_PATCH_LEVEL
