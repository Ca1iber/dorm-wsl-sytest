Pre-Load Operations for Setup Data: hp83_import

The script hp83_import is automatically executed every time you load setup data, immediately before the actual load operation.

The default of the script (as you find it in opt/hp93000/soc/com/lbin/hp83_import.def) performs the following tasks:

  • It decompresses the file if its extension is *.gz or *.Z.
  • It calls the Setup Management tool to merge the subfiles pointed at by the master file if the extension is *.mfh.
  • It passes the resulting file to stdout.

If you store your setup files in encrypted form in order to secure them against unauthorized modification, you must decrypt them before they can be loaded. You can achieve this with a customized version of hp83_import.
