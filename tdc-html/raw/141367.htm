EVENT_WAVEFORM_IC.iClampLow()

Sets the low clamp current waveform.

You can specify both the low and the high clamp current waveform or just one.

Syntax

EVENT_WAVEFORM_IC &iClampLow ( ANALOG_WAVEFORM & waveform);
Parameter
Parameter Description

waveform

Waveform definition object

Return value

There is no return value.

Example

For an example see EVENT_WAVEFORM_IC.

Related information
