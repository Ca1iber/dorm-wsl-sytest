The ASCII Timing File (*.dvc)

Subtopics

  2. ASCII Break Device Cycles
  3. EQUATIONS Blocks, SPECS Blocks, and Equation Variables
  4. Merging State Character Definitions: The OPTIONS Statement
  5. Mapping State Characters to Waveform DC/DC power units: The FIXMAP Section

The main purpose of the ASCII timing file, which has the standard extension *.dvc, is to define the ASCII device cycles which, in their turn, define the state characters that are used in the ASCII vector files. In addition, the ASCII timing file can contain EQUATIONS and SPECS blocks; these blocks serve to create the equation sets and specsets of the timing setup file.

Several ASCII device cycles can be combined into a FIXMAP section or a KEEP_PLL_ALIVE section. The ASCII device cycles contained in these sections will be processed by the timing translation in a special way. For the KEEP_PLL_ALIVE section, see The KEEP_PLL_ALIVE Section of the ASCII Timing File; the function of the FIXMAP section will be explained in Mapping State Characters to Waveform DC/DC power units: The FIXMAP Section .

You can insert comments into the file. These are identified by the hash character (#); if this character occurs in a line, the rest of the line after the hash character will be considered as a comment.
