MTP_LEAKAGE_PIN_TASK.limits()

The limits() member function of MTP_LEAKAGE_PIN_TASK lets you set the low and high limit values.

Syntax

MTP_LEAKAGE_PIN_TASK& limits(const LIMIT & limit)

Parameter

Description

limit

A LIMIT class object that contains the limits you want to use.

Related information

MTP_LEAKAGE_PIN_TASK
