Uploading measured data is crucial for high performance.

There are built-in, license free features, which simply require the latest revision of SmarTest to be used, as well as improved hardware, like the latest system controller.

For unleashing the full performance capabilities of the V93000 test system, a combination of latest HW and SW features together with specific licenses is required.

This section provides an overview of features of which you may choose to optimize the performance of your test program.
