Resolution of the error code

This parameter defines whether only a 1 bit or a 2 bit result is recorded. In the former case, you get only a pass or fail result, but can record twice as many results. In the latter case, three different error codes can be returned, which facilitates error analysis for dual threshold and window compares.

There are mutual dependencies between the error code resolution and result granularity. Furthermore, these dependencies vary for the different hardware types. In particular, there are combinations of recording mode and result granularity for which only one error code resolution is available on certain systems. For details see Possible combinations of CYRM, CYRP, and DCRM.
