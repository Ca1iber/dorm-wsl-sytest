matchData()

This function specifies the number of vectors to be included in a match loop, the beginning vector in the loop, and the maximum loop number to be executed.

Syntax

matchData(long long data,int bitLength,int startBit,int maxLoopNum)
matchData(long long data,int bitLength,int startBit,int maxLoopNum,TA::MATCH_CONT)
List of parameters

Parameter

Description

bitLength

The number of vectors to be included in the match loop.

startBit

The starting position of the bit to be written in the match loop.

maxLoopNum

The maximum number of the loops to be executed.

TA::MATCH_CONT

An option parameter which presents CONTINUE for the MACT instruction.

Examples

defaultBit

rdi.smartVec().pin("DATA1").defaultBit(0).matchData(0x36,8,10,6).matchCycle(8).execute();

matchData

rdi.smartVec().pin("DATA1").matchData(0x36,8,10,6,TA::MATCH_CONT).matchCycle(8).execute();
