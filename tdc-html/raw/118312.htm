Topic 118312

Propagation Delay conversion

The Propagation Delay test can be pass/fail test or value test.

About this task

For pass/fail test, you can convert it to an ac_tml.AcTest.functionalTest test method by setting the measured edge to reference time plus pass propagation delay.

For value test, you can convert it to an ac_tml.AcTest.parametricFunctionalTest. Firstly, you need to define a timing spec to control the measured receive edge. Then in ac_tml.AcTest.parametricFunctionalTest, you can use it as the parameter to shift.

The Propagation Delay tries to find the maximum time delay between a change in the device input and the corresponding change at the device output to its new final state. It varies the position of the receive edge to find the pass/fail or fail/pass transition of the functional test. Procedure

  1. Define a timing spec as propagation delay to control the measured edge.
  2. Calculate the range of the spec according to the range of the measured edge. The propagation delay equals the receive edge minus the reference time.

    The left boundary of the receive edge is

    • for edge compare, the nominal setting in the timing setup minus one period.
    • for window compare, another edge that opens/closes a window that exits between the nominal setting and the beginning of the test cycle or the nominal setting in the timing setup minus one period

      The right boundary of the receive edge is

    • for edge compare, the first receive edge in the test cycle plus one period
    • for window compare, the close edge of the window compare
  3. Enter the parameter values for ac_tml.AcTest.parametricFunctionalTest. Only spec search of the test method is needed, you can ignore the parameters of customized functional test.

    resultPinList

    pin list in the test function

    resultPinListMode

    parallel

    spec

    The spec defined to control the receive edge

    setupPinList

    pin list in the test function

    setupPinListMode

    parallel

    method

    For edge compare: lin/bin

    For window compare:binary

    start

    The start value calculated in last step

    stop

    The stop value calculated in last step.

    step

    omit

    The step width is defined by ESGB firmware command. Default is 0.5 ns.

    resolution

    omit

    The resolution is limited by the hardware resolution.

    passMin

     

    passMax

    pass prop delay value in the test function

Example

The following example shows how to convert a propagation delay test to the ac_tml.AcTest.parametricFunctionalTest. The timing set used in the example is listed on the left side.

In the example, the propagation delay is measured for edge r1 of pin group ser_out. The reference time is edge d1 of pin CP. If the measured propagation delay is less than 5 ns, the measurement is pass.

To convert the propagation delay to ac_tml.AcTest.parametricFunctionalTest, you need to:

  1. Define a timing spec prop_delay to control the receive edge:
    PINS ser_out
r1 = prop_delay + 20
  2. Edge compare is used in this example. The left boundary of receive edge is nominal setting for r1 minus one period. The right boundary is nominal setting for r1 plus one period.

    Start position is 45 ns. period is 50 ns. The left boundary of r1 is start - period = -5 ns. The right boundary of r1 is start + period = 95 ns.

    prop_delay = r1 -20. So the search range of prop_delay is from -25 ns to 75 ns.

  3. Enter the parameter values for ac_tml.AcTest.parametricFunctionalTest.

    spec

    prop_delay

    resultPinList

    ser_out

    resultPinListMode

    parallel

    setupPinList

    ser_out

    setupPinListMode

    parallel

    method

    lin/bin

    start

    -25

    stop

    75

    step

     

    resolution

     

    passMin

     

    passMax

    5
