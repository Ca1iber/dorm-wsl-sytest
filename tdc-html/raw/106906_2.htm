Topic 106906

DDIC, DDIC? - (Define DUT Interface Connection)

The DDIC (Define DUT Interface Connection) command describes the DUT board traces that are needed to support ganging across DC Scale cards (UHC4T). The command therefore specifies pogo pins, not pin names.

This command is not applicable for DC Scale XPS256 card. Ganging across XPS256 cards is controlled via internal data paths and need not to be defined separately.

DDIC

DDIC ["connectionSet",] {"circuitry_type"}, {(cp1,cp2)}

DDIC?

DDIC? {"circuitry_type"}

Parameters

connectionSet

This parameter is currently not used.

This extra string parameter adds the ability to define several pins containing the same DC Scale channel in PMU mode. A multiple defined DC Scale channel can be sequentially reused as single pin or in ganging groups. Note: The documentation for supported DC Scale cards knows this feature also as "Ganging on the fly".

Default connection set: The default connection set is defined if this extra parameter is not used or if an empty string is programmed. A DC Scale pin can be defined in only one default connection set.

It's possible to specify several DDIC commands which differ in the name parameter, but have identical (cp1, cp2) combination.

circuitry_type

The following circuitry types are supported:

CONN

A simple direct connection between the given pogo pins.

Two pogo pins on one or two DC Scale cards (UHC4T) must be given: One GANG_IN (pppGI) pogo and one GANG_OUT pogo (pppGO).

CLR

Clears all previously defined circuitry.

ALL

Only for queries:

Returns all previously defined circuitry.

cp1,cp2

The parameters define the ganging or stacking connections:

  • Format pppxx defines a pogo block and a ganging connection.

    Only pogo pin in/out pairs are allowed as connection points.

ppp

The three digits specify the pogo block number.

xx

Alpha numeric code for specifying the ganging connections:

GO

Ganging Output

GI

Ganging Input
cc The two digits define the channel number from 01 to 16.
- Low force (LF#) / Return of the upper channel
+ High force (HF#) / Force of the lower channel
CAUTION "Upper channel" in this context means towards the DUT while the "lower channel" means towards a stable reference like ground or the supply voltage of the DUT. This applies to both positive and negative voltages.

Application

Ganging of DC Scale cards (UHC4T) via the DUT board to increase output currents.

Example

Example 1: Ganging

DDIC CONN, (207GO,209GI)
DDIC? ALL

returns

DDIC CONN, (207GO,209GI)
