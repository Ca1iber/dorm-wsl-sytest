CHFA? - (CHannel FAil flag)

If a test contains a counted match loop, and it fails because no match was obtained, the CHFA? query serves to identify the pins that did not match.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Mode of operation

The CHFA? query returns the result of the last match loop cycle for selected pins. This information cannot be retrieved from the error map (for which see Using the Error Maps), because match loop cycles are not recorded in the error map.

Syntax

CHFA? [MUX,] {(pinlist)}

returns:

CHFA {res_flag}, [MUX,] {(pinlist)}

Parameters

MUX

If this flag is set, and one of the specified (Pin Scale) pins is multiplexed to an HXA pin, then the combined result from all Pin Scale pins multiplexed to the HXA pin will be used to determine the answer.

res_flag

The result flag can be:

F

The pin failed in the last match loop cycle.

P

The pin passed in the last match loop cycle.

pinlist

List of pins. If more than one pin is included, the names must be separated by a comma. All pins in pinlist must be of O or IO type.

Application

Test results.

Example

CHFA? (D1)

returns: 

CHFA F, (D1)
