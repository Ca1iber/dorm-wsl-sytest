MTP_LEAKAGE_TASK.execute()

The execute() member function of MTP_LEAKAGE_TASK executes the shared parallel leakage test based on the measurement conditions set with the pin() member function.

Note that when using this member function, you must:

  • Use the CONNECT API before using execute() since the leakage test is measured in a connected state.
  • Call the postExecute() member function at the end of the leakage test after all pins have been measured.

Syntax

void execute()
