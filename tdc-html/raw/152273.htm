Topic 152273

getFailCyc()

Returns positions of all failing cycles.

Syntax

ARRAY_LL getFailCyc(string pin);
List of parameters

Parameter

Description

pin

Specifies a pin for which to get all failing cycles' positions.

Return value

The return value is an ARRAY_LL indicating all failing cycles' positions.

Related information
