SMC_EXECUTE_TMU_TEST()

This API executes a non-blocking test on both TMU and non-TMU pins.

While the main SmartCalc test excution API SMC_EXECUTE_TEST() waits on all pins until the TMU pins are finished, the SMC_EXECUTE_TMU_TEST() does not wait. This is achieved by specifying the TMU pins in pinlist.

For example, you can run longer TMU measurements on a certain pin in parallel to multiple non-TMU tests on another pin. This improves the testing turnover per test suite. The function executes the tests in parallel and it must be called inside the ON_FIRST_INVOCATION_BEGIN() block.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Syntax

void SMC_EXECUTE_TMU_TEST(DOUBLE timeout, const STRING& pinlist);
void SMC_EXECUTE_TMU_TEST(DOUBLE timeout, const STRING& context, const STRING& pinlist);
Parameters

Parameter

Description

timeout

The timeout of the measurement (test) in seconds.

This API cannot detect a timeout for the AWGs.

context

Name of an execution context. The ports of the context must be included in the current start label (which must be a multiport burst). For more information on execution contexts, see Using execution contexts.

The context must have been defined on the firmware level (with the SQEC command), or as a SEQUENCER_CONTEXT_ITEM object. In the latter case, this object must have been included in a SEQUENCER_CONTEXT object, and must also have been activated on the firmware level with the apply() function of this SEQUENCER_CONTEXT object. If the context has been defined as a SEQUENCER_CONTEXT_ITEM object, you must use the name specified for its name parameter.

pinlist

The TMU pins. The function will wait for the tests on these pins to finish.

Return value

There is no return value.
