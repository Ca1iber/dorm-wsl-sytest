Making timing measurements using the cursor

The cursor and marker in the Timing Diagram allow you to make measurements on the waveforms being displayed in high resolution mode.

Note Remember that if you do not use High Resolution, the output waveforms that you are measuring only show you where the Timing Setup window has positioned the comparator edge - it does not show you when the output signal occurred!

To make a measurement:

  1. Display the waveforms that you wish to measure using high resolution mode (as described above).
  2. Click the radio button Marker.
  3. Use the mouse to drag the Marker (diamond shape) to the beginning of the interval you wish to measure. (for example, if you are measuring the propagation delay of a synchronous device, place the Marker on the trigger edge of the clock pin).
  4. Click the radio button Cursor.
  5. Use the mouse to drag the Cursor (square shape) to the end of the interval you wish to measure. (for example, for the example in step 3, place the Cursor on the point where the output pin changes its logic-level).
  6. Read the timing difference between the Cursor and Marker from the left-hand column of the Timing Diagram, under: Timing Delta [ns].

In steps 3 and 5, you can also move the Cursor or Marker (after you have selected its radio button) by just typing the offset, relative to the beginning of the test system period, in the edit box Offset [ns].

Note If you drag the cursor or marker close to the transition point of a signal, it automatically aligns itself to the transition.
