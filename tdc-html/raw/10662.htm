Setting the setup focus

You can to a certain extent control which sites will be affected by subsequent setup commands. This is done with the PSFC command, which defines the sites that have the setup focus.

However, only a subset of the setup commands takes this setup focus into account. For example, the level and timing commands in fact change only the data of the sites that have the setup focus. The vector setup commands, on the other hand, disregard the setup focus; they always affect all available sites (unless the command itself can restrict the scope of the affected sites, as does the SQSL command).

By default, all sites have the setup focus.

One typical application of the PSFC command is to disconnect a single site. To do so, restrict the setup focus to the site in question with the PSFC command, and then use the firmware commands associated with the disconnect sequence (see Disconnect the DUT from the Tester Resources) to disconnect the site. No other site will be affected by this command sequence.
