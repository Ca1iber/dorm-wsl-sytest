MTP_LEAKAGE_TASK.postExecute()

The postExecute() member function of MTP_LEAKAGE_TASK must be called at the end of leakage test after all pins have been measured. postExecute() will restore the settings as specified in the Sharing configuration file.

Syntax

void postExecute()
