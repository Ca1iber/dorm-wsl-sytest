DRLKeepEvent

void DRLKeepEvent (DRLDataStream *stream, DRLEventRec *event))

This function lets you save the data of the event record event so that it will not automatically be overwritten by the next call of DRLGetNextUnmaskedEvent. You can then access the data of event later, unless you have called DRLGetNextUnmaskedEvent with event as parameter before. (In that case, event would be filled with new event data.)

See the function description of DRLGetNextUnmaskedEvent for further information.

To free the memory allocated by DRLKeepEvent, you have to call DRLFreeEvent when you no longer need the kept data.

DRLKeepEvent only needs to be used if you need to keep event record data for later processing. Typically, events are processed immediately after they have been read from the data log stream by DRLGetNextUnmaskedEvent, using always the same DRLEventRec variable event. In this case, DRLKeepEvent and DRLFreeEvent are not required.

Return Value

None.

Example

/* keeps the data of 100 event records that are read 
   from the data log stream */

DRLEventRec event_rec[100];
int last = 0;
while (last < 100)
 { DRLGetnextUnmaskedEvent (&my_stream, &event_rec[last]);
   DRLKeepEvent(&my_stream, &event_rec[last]);
   last++;
  };

/* after the event records have been processed, the
   allocated memory must be freed again */

while (last > 0)
 { /* process the event record event_rec[last] */
   DRLFreeEvent(&event_rec[--last]);
  };

Functional changes

  1. Introduced before SmarTest 6.3.2
