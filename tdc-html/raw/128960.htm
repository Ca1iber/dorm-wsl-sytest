Topic 128960

Activating offline result emulation in the testflow

This topic describes how to activate offline result emulation using the Flow Sequence Editor.

Before you begin

The setup meets the requirements according to Test program requirements for ORE.

Note Offline result emulation (ORE) is available with the S&S_TOOLS_PACKAGE SW license. If this license is not available, ORE is disabled.

For an overview of all licensed V93000 products by product ID, as they are referenced on the Entitlement Certificates, see Licensed V93000 products.

Procedure

  1. Create a single ORE setup file that contains all pattern cycle failures or parametric data that you want to inject.
  2. Create a corresponding activation test method that references this setup file.

    Examples are provided in Examples on how to use offline result emulation.

  3. Open the testflow in the Flow Sequence Editor.
  4. Insert a test suite at the beginning of the testflow.

    Note that inserting the ORE-enabling test suite anywhere except at the beginning of the testflow may cause unwanted effects.

  5. Configure the test suite:
    1. Type a name.
    2. Optionally, type a comment.
    3. Select the test method that you created in step 2.
    4. Click Finish.

Results

The testflow is prepared for the offline result emulation.
