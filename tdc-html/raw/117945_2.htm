Topic 117945

JSPR, JSPR? - (Jitter Set PRimary set)

JSPR defines the primary jitter set. Note that

  • if a primary jitter set is defined, then it will automatically be used in the test, and
  • the primary jitter set (as defined with JSPR) must be associated with the same context as the other primary sets.

JSPR? returns the current primary jitter set.

JSPR

JSPR {"js_set_name"|""}

JSPR?

JSPR?

returns: 

JSPR {"js_set_name"|""}

Parameters

js_set_name

Specifies the name of an existing jitter set. Specify an empty string to inactivate the current primary set and thus to disable jitter injection.

Application

Jitter test.

Errors

An error is generated if no jitter set with the specified name exists.

Example

> JSPR   "js_set1"

Functional changes

  1. Introduced in SmarTest 7.0.1
