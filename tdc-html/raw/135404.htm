MTP_MEMORY_TEST.setMultiPatternResultMode()

If a main label contains multiple memory patterns, use this member function to set the mode of generating and logging address-based results for all patterns. The address-based results include fail bit data file, fail bit count, and failing address list.

Alternatively set the Multi_Pattern_Result_Mode parameter in the ExecutionEngine test method, see Parameters for the ExecutionEngine test method.

Syntax

MTP_MEMORY_TEST& setMultiPatternResultMode(const MTP::MULTI_PATTERN_RESULT_MODE mode);
Parameter

Parameter

Description

mode

The mode of generating address-based results for multiple patterns in one main label. The default mode is MTP::FIRST_FAILING_PATTERN.

The following table lists all available modes.
Available options of parameter: <mode>

Option

Description

MTP::FIRST_FAILING_PATTERN

(Default mode) Only the first failing pattern's address-based results are generated and logged.

MTP::PER_PATTERN

Every individual pattern's address-based result is logged and generated. And an additional fail bit count for all failing addresses combined from all patterns is generated and logged.

MTP::ALL_PATTERNS_COMBINED

Combines all failing addresses of all patterns, and generates and logs a fail bit count, a failing address list, and a BFD file naming as the main label for these combined failing addresses.

Note that this option dose not generate the individual BFD file, fail bit count and failing address list for each individual pattern.

Return value

There is no return value.

Example

MTP_MEMORY_TEST memoryTest;

memoryTest.enableAddressBasedResults(true);
memoryTest.enableFailBitCount(true);
memoryTest.setImmediateBitmapToFile(true);

memoryTest.setMultiPatternResultMode(MTP::PER_PATTERN);
