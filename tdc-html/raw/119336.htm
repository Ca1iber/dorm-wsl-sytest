Topic 119336

Export Pattern

You can export any pattern of the MAIN type in the ASCII Interface format or in the STIL (Standard Test Interface Language) format. The pattern is translated using the STATEMAP section of the pattern's associated base wavetable in the timing file.

Exporting a pattern to the ASCII Interface format creates the following files:

  • <pattern_name>.avc (ASCII vector file)
  • <pattern_name>.tmf (timing map file)
  • <pattern_name>.wtb (contains the WAVETABLE name)
  • <pattern_name>.b2alog (log file)

Exporting a pattern to the STIL format creates the file:

  • <pattern_name>.pat.stil

The pattern export uses either the ASCII Interface tool b2a (binary to ascii conversion), or the STIL tool bin2stil (binary to STIL) respectively.
