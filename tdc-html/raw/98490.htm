BLUP - (BLock UP to date)

The BLUP command serves to modify information about changes of sequencer labels (patterns). It should be used with care.

BLUP

BLUP {"name"}, {type}, {state},

Parameters

name

The name of a label.

type

The only allowed option is:

 

LBL

This comprises labels of types MAIN, BRST, SVEC, and MPBU.

state

This parameter defines the status and can be one of the following:

 

UPTD

Label is up to date.

 

CHNG

Label was changed.

Application

Pattern management.

Example

BLUP "test",LBL,UPDT,

This example sets the state of label test to up to date.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.3: Removed MTST option of type parameter . The query BLUP? was also removed.
