Pin Scale 5000 compatibility

Pogo cable compatibility

The Pin Scale 5000 card supports two pogo pin layouts with regard to compatibility:

  • Standard (compatible) layout, consisting of 16 pogo blocks per card having 16 pins per block. This layout is compatible with existing DUT boards.
  • High-density layout, consisting of eight pogo blocks per card having 32 pins per block. This layout is compatible with the current layout for the inner 16 pins.

    For additional pins, two outer rows (each containing 8 pogo pins) are provided. See Pin Scale 5000 pogo pin assignment.

    The outer rows must be considered in your DUT board layout if you need to use them.

Functional changes
