Enhancements of the maintenance operation

The maintenance operation supports multiple static refreshes operations.

To support this feature:

  • New refresh control instructions are developed.
  • Multiple rows are needed in the :maintenanceOperation: table of the Device architecture file syntax.
  • Additional configurations for setting up a multiple refreshes operation.
