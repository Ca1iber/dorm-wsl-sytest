Topic 10475

DC Measurements Using the DPS

The following commands and queries are used to perform a measurement using the DPS:

  • The query PSAS? - (Power Supply Accumulated Status)
  • The query PDMM? - (PDps Miscellaneous Measurement)
  • The command PSST, PSST? - (Power Supply STatus)

The PSST command allows you to switch the DPS on or off. When switched on, the DPS supplies the voltage specified by the command PSLV, PSLV? - (Power Supply LeVel), see also Set Fixed Power Supply Levels (legacy).

The DPSM command allows you to define sets for DPS measurements. Each set comprises the minimum and the maximum pass values for a test.

You can use the PSME? query to determine the actual voltage and current being supplied or to obtain a pass/fail result against the values defined in the DPSM command. The answer string contains the measured values and also the output state of the power supply (which is constant current or constant voltage), or a pass/fail result.

You can read the internal status of the DPS using the PSAS? command. This command returns a decimal value that you can translate into binary form to determine the state of the DPS since the previous execution of the command, or since the last connect or disconnect sequence was executed:

  • Constant current
  • Constant voltage
  • Overcurrent
  • Overtemperature
  • Unregulated
