MTP_MEMORY_PATTERN.setBitMapFileName()

Lets you name the bit fail map files generated from the current pattern specified by getMemoryPattern(). The .bfd suffix will be automatically added.

If you do not specify a name with this function, each BFD file will get a default name, {time}-{label}-{pattern}@{port}-site{site}.bfd.

Note If the pattern belongs to the default port '@', you will not see the port information in the name.

Syntax

MTP_MEMORY_PATTERN& setBitMapFileName(const STRING& name)

Parameter

Description

name

A string to name the generated bit fail map files.

The name string can contain application model variables, testflow variables, and the reserved variables listed below to display more information in the file name, such as wafer, site, and port information. The syntax for using a variable in the name is ${variable name}.

  • ${time}: The file name will show the time at which the BFD file is generated.
  • ${pattern}: The file name will show the name of the memory pattern (per pin subroutines generated by the MTL compiler) that the BFD file is generated from.
  • ${label}: The file name will show the name of the start label where in the pattern to start generating the BFD file.
  • ${port}: The file name will show the name of the port that the pattern belongs to.
  • ${site}: The file name will show the site number.
  • ${test}: The file name will show the name of the test suite.

If the name string contains a variable which is an application model variable and that is also a testflow variable, the file name will display the value of the application model variable.

If the name string does not contain a variable, all generated BFD files will have the same name and the later one will overwrite the earlier one.

If the string does not contain the ${time} variable, the BFD file generated with the execution of a test and the BFD file generated with RA if you have enabled RA and configured setRAEndAction(MTP::RA_END_SAVE_BFD) will have the same name. The later one will overwrite the earlier one.

By default, all generated BFD files are saved to: device/mts/bitmap/bitmap_data. You can change the path of BFD files generated with an execution of a test by using MTP_MEMORY_TEST.setBitMapFilePath() or MTP_MEMORY_PATTERN.setBitMapFilePath(). But you cannot change the path of the BFD file generated with RA.

Examples:

  • "${time}-${label}-${pattern}-Port${port}-Site${site}"
  • "Time${time}-Port${port}-$Lot{LOT_ID}-Cassette${CASSETTE_ID}-Wafer${WAFER_ID}-X${DIE_X}-Y${DIE_Y}"

Example

Specify a name for the generated bit fail map file to show the file generating time, pattern, label, port and site information:

MTP_MEMORY_TEST memoryTest;
MTP_MEMORY_PATTERN &march6N = memoryTest.getMemroyPort("A").getMemoryPattern("march6N");
march6N.setBitMapFileName("${time}-Label${label}-Pattern${pattern}-Port${port}-Site${site}").generateBitmapFile();
