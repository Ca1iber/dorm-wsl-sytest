SmartRDI provides some general functions for setting up multiple types of tests.

The working scope of general SmartRDI commands is test suite. This means that a general command resumes its original setup after the test suite has been executed. For example rdi.setPinStatus("A",1), this command specifies the default status of pin A in the current test suite to 1. The value 1 will not be valid after the test suite has been executed. If you need the status of pin A to be 1 again, you must set the command again in the next test suite.
