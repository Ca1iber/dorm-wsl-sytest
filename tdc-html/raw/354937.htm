XPS256 programming - Safety line and DUT board disconnect

XPS256 pins provide a safety line shutdown per site that is controlled by utility pins. This hardware‑controlled shutdown can be configured for selected XPS256 pins or as a global disconnect shutdown for all XPS256 pins. It can be used for both the PMU operating mode and the DPS operating mode.

Utility pins are configured for the safety line shutdown or for the global DUT board disconnect shutdown in the Utility Pins editor:

In the Mode column, the following options configure a utility pin for the safety line shutdown or for the global DUT board disconnect shutdown:
triggerIfHigh

Configure the utility pin for the safety line shutdown:

  • Only one utility pin can be configured.
  • A shared utility line or utility lines per site can be assigned.
triggerIfLow
triggerSiteIfHigh

Configure the utility pin for the global DUT board disconnect shutdown:

  • Only one utility pin can be configured.
  • A shared utility line or utility lines per site can be assigned.
triggerSiteIfLow

Both shutdown modes can be configured so that a trigger signal is sent if the input signal is changed from low level to high level or from high level to low level. For more information, see XPS256 safety line and DUT board disconnect.

In the Tester Channel columns, only utility lines of the optional Utility Card can be assigned to the utility pin.

Safety line shutdown

A utility pin configured as
  • triggerIfHigh or
  • triggerIfLow
as shown above can be assigned to the XPS256 pins in the DC Scale Safety editor:

In the Safetyln Pin column, you can assign the XPS256 pins shown in the first column to the utility pin configured for the safety line shutdown.

Only XPS256 pins that are assigned to the appropriately configured utility pin are shut down when an underlying utility line sends a trigger signal.

Note that the safety line shutdown is available per site, but shared utility lines can also be assigned. If utility lines per site are assigned to the utility pin, only XPS256 pins of the related sites will be shut down.

When a pin has received a safety line shutdown signal, the Safety line status flag is set. The next time the hardware is accessed, an error message is displayed and the status of the flag can be read. Although the pin is already disconnected by the channel controller, the flag must also be cleared by disconnecting the pin by SmarTest.

DUT board disconnect shutdown

There are no more settings to be done for activation of the DUT board disconnect shutdown.

A utility pin configured as
  • triggerSiteIfHigh or
  • triggerSiteIfLow
as shown above is automatically assigned to all XPS256 pins.

A shared utility line or utility lines per site can be assigned to the utility pin in the Utility Pins editor. This means that the shutdown can be triggered per site or for all sites, but the shutdown is always performed for all XPS256 pins of a site.

Note that only one utility pin can be configured for the DUT board disconnect shutdown.

When a pin has received a DUT board disconnect shutdown signal, the DUT board disconnect status flag is set. The next time the hardware is accessed, an error message is displayed and the status of the flag can be read. Although the pin is already disconnected by the channel controller, the flag must also be cleared by disconnecting the pin by SmarTest.
