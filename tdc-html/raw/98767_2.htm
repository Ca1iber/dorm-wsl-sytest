TCMT, TCMT? - (Test CoMment Transfer)

The TCMT (Test CoMment Transfer) command is used for inserting comments in the Vector Table. This command works on the label that is currently activated for editing with TSTL, TSTL? - (TeST Label). If no label is active, the command does nothing. If the comment text text is empty, the comment is deleted.

Do not confuse this command with the download command CMNT, CMNT? - (CoMmeNT). CMNT works on the port level, TCMT on the label level.

TCMT

TCMT {vect_addr}, {"text"}

TCMT?

TCMT? {vect_addr}, [vect_length]

returns a comment text for each TCMT in the range vect_addr to vect_addr +vect_length - 1.

Parameters

vect_addr

The logical number of the vector at which the comment is to be inserted or read. The specified number range must not exceed the maximum vector address allowed by the system.

text

A string of up to 250 characters. The string must be enclosed with double quotes.

Comments can contain any characters with ASCII codes from 32 to 126, that is, all printable ASCII characters. To put a double quote character (", ASCII 34) into a comment, enter two double quote characters.

vect_length

The vector range forwards from vect_addr.

Application

Edit command in Pattern Tool.

Errors

An error is generated if you specify an address outside the valid range.

Example

TCMT 2063,"Start of test 2".

This example inserts the comment "Start of test 2" at the logical vector address 2063.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.3: Maximum comment length increased from 40 to 250.
