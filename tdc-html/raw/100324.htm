Site control flags

Site control flags allow to modify the focus on one specific site or change from parallel to serial execution. The site control flags are available per test suite.

These site control flags are available:
  • Allow Parallel (force_serial) - Additional information
  • Site Control (site_control)
    • Size, Cycles (site_control)
    • #1 ... #n (site_control)
  • Site Match (site_match)

For a detailed list of the site control flags, refer to Alphabetical list of flags. Select Site control in the filter settings of column Area to show only the test suite flags.

The site control flags are stored in the test_suites section of the Testflow file.

Additional information: Allow Parallel (force_serial)

If you are using multiple test sites, then set the Allow parallel flag to ensure that the test suite is executed in parallel for each site. However, if any of the following conditions apply to your test suite, you must ensure that the flag is not set, so that the sites will be tested serially:

  • You are executing a user-procedure.
  • The test suite depends on a synchronized state from a previous test suite.
  • The test suite depends on error information generated by a previous test suite.

The site_match flag is used for multi-site testing using the analog modules that are shared with multiple sites.

Further, the expanded Site Control Window is used to set up the test order of sites only when you develop multi-site testing.
