I2C predefined transactions

The Register Access library provides many predefined transactions for I2C, which can be used directly in a newly-created protocol.

Overview of predefined transactions for I2C
Transaction Description
ackCompareLow()

Compare to a low acknowledge.

After sending a byte, DUT typically drives a low to SDA and the master can compare against this signal.
ackNo()

No acknowledge issued by DUT.

SCL issues a clock and SDA sets to HiZ.
ackSendLow()

Send an acknowledge to DUT.

The tester issues a low on SDA while SCL issues a clock.

changeSpeed(double freq)

Change the I2C clock speed. The I2C speed can be changed between transactions calls when a register read/write sequence is defined.

The speed is adapted to the resolution of the tester period.

freq: The frequency of clock to be changed to.
comment(const string& comments)

Add comments to the generated pattern where the subsequent transaction is located. For debugging the generated pattern, comments can be optionally issued together with subsequent transactions.

For example, i2c.comment("AAA").sendByte(0xFF);
compareByte(RA::ULONG64 expectValue, RA::ULONG64 maskValue = 0 )

Receive a byte data and compare against expected byte data.

  • expectValue: The expected data in byte.
  • maskValue: The mask setting of the expected data. bit 1 stands for mask, 0 stands for no mask.

The default value is 0, which stands for no mask is applied.
compareByteAckLow(RA::ULONG64 expectValue, RA::ULONG64 maskValue = 0)
Receive a byte followed by sending a low ack and compare against the expected data. It is equivalent to compareByte() plus ackSendLow().
  • expectValue: The expected data in byte.
  • maskValue: The mask setting of the expected data. bit 1 stands for mask, 0 stands for no mask.

The default value is 0, which stands for no mask is applied.
compareByteNoAck(RA::ULONG64 expectValue, RA::ULONG64 maskValue = 0 )
Receive a byte followed by no ack and compare against expected data. It is equivalent to compareByte() plus ackNo().
  • expectValue: The expected data in byte.
  • maskValue: The mask setting of the expected data. bit 1 stands for mask, 0 stands for no mask.

The default value is 0, which stands for no mask is applied.
loopBegin(int numberOfLoops)

Issue the instruction command of loop to begin. It results in a sequencer instruction command loopBegin issued in the generated pattern.

This transaction must be used in pair with loopEnd().

For example, 
i2c.loopBegin(10);
i2c.sendByte(0xFF);
i2c.loopEnd();
matchLoopBegin(int numberOfLoops, bool continueOnFail = false)
Start a counted match loop. This transaction must be used in pair with matchLoopEnd().
  • numberOfLoops: The number of loops.
  • continueOnFail: Specify whether the digital sequence continues when the maximum loop number is exceeded and no match is reached.

matchLoopEnd(const string& repeatStateCharacterList = "")

Set the end of a block of match loop.

This transaction must be used in pair with matchLoopBegin(). repeatStateCharacterList: The state character string of pins when matching is evaluated.

Format is pinList1@Pattern1:PinList2@Pattern2:......PinListN@PatternN.
  • Pin Lists are separated by comma.
  • Pattern is DVC name (1 character length) string streams. For example, 1000L1H.
  • Groups of Pinlists and patterns are separated by colon.

By default, the value is the last state of pattern.
receiveByte(const string& outDataFieldName)

Receive a byte data from DUT.

outDataFieldName: A tagged string to represent the received data. The name is used in composeRegisterReadData().
receiveByteAckLow(const string& outDataFieldName)

Receive a byte and then an active low driven signal on SDA sent to DUT. It is equal to receiveByte() plus ackSendLow().

It indicates the byte is NOT the last byte received from DUT, more bytes are expected to be received from DUT.

outDataFieldName: A tagged string to represent the received data. The name is used in composeRegisterReadData().
receiveByteNoAck(const string& outDataFieldName)

Receive a byte and then NO acknowledge. It is equal to receiveByte() plus ackNo(). It indicates the byte is the last byte received from DUT.

outDataFieldName: A tagged string to represent received data..
restoreSpeed() Restore the speed to its specification.
sendByte(RA::ULONG64 data, const string& name = "")

Send out a byte of data on SDA.

  • data: A data in byte, MSB (most significant bit) first.
  • name: A tagged name in reference to the byte data to be sent. The name can be used in composeRegisterWriteData() and can also be ignored if it is not referenced in composeRegisterWriteData().
sendByteWithAck(RA::ULONG64 data, const string& name = "")

Send a byte and then compare acknowledge to low. It is equal to sendByte() plus ackCompareLow().

  • data: The data byte to be sent. MSB first.
  • name: A tagged name in string in reference to the byte data to be sent. The name can be used in composeRegisterWriteData() and can also be ignored if it is not referenced in composeRegisterWriteData().
setState(const string& sclState, const string& sdaState)
Set the state list of SCL and SDA.
  • sclState: The state character list on SCL.
  • sdaState: The state character list on SDA.

The lengths of state characters on SCL and SDA must be the same. For example, setState("0110", "XXLX");

startCondition() Start the condition of I2C. SDA sees a failing edge when SCL is high.
stopCondition() Stop the condition of I2C. SDA sees a rising edge when SCL is high.
wait(double waitTime)

Hold and wait for the specified time

waitTime: The holding time in seconds.

Example

Transaction definitions for write operations:

virtual void defineWriteRegister(I2C& i2c, ULONG64 address, ULONG64 data) {
  
  i2c.startCondition();

  i2c.sendByteWithAck(0xE8);
  i2c.sendByteWithAck(address / 256);
  i2c.sendByteWithAck(address % 256);
  i2c.sendByteWithAck(data, "inData");
  
  i2c.stopCondition();
}
