Defining the Main pattern

You can set up a Main pattern (label), which uses the Digital Source Memory (DSM) feature, like any other pattern with the pattern tool set (Pattern Explorer and Editor).

To define the Main pattern (label):

  1. In the Pattern Explorer, right-click and select New. The New Pattern window opens.
  2. Specify the following:

    Pattern Name:

    dsm_main

    Pattern Type:

    Main

    Port:

    @

    Memory Type

    SM (Sequencer Memory)

    Wavetable:

    dsm_wavetable
  3. Click Finish. The source pattern is created and listed in the Pattern Explorer.

In the Pattern Editor, you may use the SSRC, SRCV, and LOOPSequencer instructions and program the Main pattern (label) to source the digital source memory as desired. For details see Entering the vectors in the Main pattern.
