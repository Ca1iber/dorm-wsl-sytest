Topic 127025

Adaptive Range Setting Search Method

Zhou,Qiang, Verigy

Paper-ID: 127025 May 2011

Abstract

Search methods are widely used to find the right timing setting before a functional test. A large number of search routines can consume a significant amount of test time when using linear search algorithms with wide search ranges and small resolutions. To save test time and keep high accuracy (small resolution), this adaptive range setting search method is proposed. The result shows, compared with linear search, that this method can save about 50% or more test time for all search routines.

Key Words: COT, Statistical, Adaptive Search

Introduction

Some timing specifications, such as setup time and propagation delay, will vary under different operation conditions like clock frequency and power supply voltage. Usually, to fully verify the device's quality, many functional patterns need to be executed under different testing condition (clock period and power supply voltage combinations). The result of the functional test is heavily dependent on the timing setup. As a result, a search routine must be used to find the right drive/receive edge settings before the functional tests. With the wider search range and smaller search resolution, a search routine will consume more time. As an example: in a testflow, there are more than 20 search routines with 1 ns resolution and 0~500 ns search range, if these search routines were executed linearly, the test time consumption is huge (for example, more than 6s in one real application ], which results in the high COT. This paper will introduce an adaptive method to reduce test time for search routing in production program. The simulation result shows more than 50% test time can be saved compared with linear search.

Traditional Search Algorithm

Linear Search

Linear search, or sequential search, is a method to find a transaction point in predefined search range. Each step it will increase a certain width (resolution). Following figure (figure 1) illustrates the linear search method. If search step is very fine, it will cost a lot of time, because many iterations is needed.

Figure 1. Linear search

Binary Search

The binary search for the transition point begins by testing at the predefined search region and then if a pass/fail transition is found it continues. By halving the distance between limits it produces a new range where it performs a test. Following figure (figure 2) illustrates the binary search method. In many cause, binary search is faster than linear search since it often has less iterations.

Figure 2. Binary search

Lin/Bin Search

Although binary search is usually faster than linear search; binary search is not feasible in certain situation, such as when signal has pulse shape and pattern execution fails at both start point and stop point of search range. In this case, lin/bin search can be used. Lin/bin search use linear search with coarse step size to find transaction firstly, then use binary search with fine step size to get better granularity. Following figure (figure 3) illustrates the lin/bin search method.

Figure 3. Binary search

Adaptive Range Setting Search Algorithm

Basic Concept

The obvious way to reduce test time for search routine is to reduce the total number of iterations before finding the transaction point by either narrowing down the search range or enlarging the search step. However, timing specifications maybe influenced by the manufacture process. For example, some companies may intentionally request foundry to produce certain special devices like "Fast fast DUT", "Fast DUT", "Normal DUT", "Slow DUT", "Slow slow DUT" to simulate the variation in the manufacture process and verify them. So, using a predefined narrow search range will cause the search routine to fail, which will lead to overkill (In case of the transaction point is out of the predefined narrow search range but in the original wider range) in production. In some case, due to device's attribute or a customer's requirement, a larger search step cannot be used. This proposed adaptive range setting search algorithm will save test time without sacrificing granularity. Also it won't hurt yields.

This adaptive range setting search uses statistical method to narrow down the search range, while keeping the original fine resolution. Suppose in production environment the mean value and variance of search results are calculated .After N devices are tested, the mean value is E, the variance is σ2. Per N is large enough, search result follows normal distribution. If 2 * Mσ is smaller than original search range interval (M is a user-defined variable, its usage is explained in following sentences), then search routing will go in reduced range mode and the new search range will be set to (E-Mσ, E+Mσ). When M=3, 99.74% of the search results for following devices are in the range (E-3σ, E+3σ); When M=6, 99.9996% of the search results for following devices are in the range (E-6σ, E+6σ). With this new narrow search range, test time for the search routine can be saved.

Failure Protection

It is possible that for certain devices, their transaction point will be out of the reduced range. So, when a search routine with a narrow range fails, a search with the original range will be executed to make sure device is not a false fail. If a search routine with a narrow range fails successively more than T times, the search routine will quit reduced range mode and the mean value and variance of search results will be cleared and re-calculated starting from next device.

Above three tables show that all the results of three search tests are in the range (E-Mσ, E+Mσ), either M=3 or M=6. For SA and SB test, when M=3, only 3 iteration steps are needed to find transaction points for binary search. Compared with original range which needs 6 iteration steps, half of iterations number is saved. When original search range is wider, such as SC test, more iteration steps are saved.

Conclusion

In this paper, a new search algorithm suitable for production program was introduced. This algorithm uses a statistical method to narrow down the search range adaptively without hurting the search resolution. Simulation with field data shows about 50% test time savings with this new adaptive search test . The greater the amount of search tests and the wider the original search range, the more efficient this algorithm becomes.
