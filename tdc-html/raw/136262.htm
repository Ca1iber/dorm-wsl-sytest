Shmoo tests in the Shmoo Tool

The Shmoo Tool can set up:

  • Shmoo a functional test

    After execution, the shmoo plot displays pattern execution results related to pass/fail. The results can be pass/fail, the first failing cycle, the first failing vector, total error count, and edge error count.

  • Shmoo an existing test suite

    After execution, the shmoo plot displays the pass/fail results or the measured values of this test suite. See Viewing customized test results in the shmoo plot.

  • Shmoo over multiple test suites

    It shmoos over each of these test suites one by one. The shmoo plot will display Pass or Fail on shmoo cells. Pass indicates all test suites have passed at this cell. Fail indicates at least one test suite has failed at this cell.

  • A customized shmoo test. Use it only when the manner of shmoo over test suite cannot meet your requirements.

    To do this, you must create a customized shmoo test method first. Then, use this test method when setting up a shmoo test.

  • A fail bit count shmoo test for MTP

    This is available only for MTP to display the number of fail bits on the shmoo plot.

The setups for the above shmoo tests are the same except for a few parameters. For details, see Setting up a shmoo test in the Shmoo Tool.
