Measuring current or voltage in DPS operating mode

Current measurement

In DPS operating mode, each channel of a DC Scale card can measure the supplied current.

Unganged current measurement in DPS mode

To achieve a higher output current, you can gang multiple DC Scale channels. But the higher current of ganged channels has a negative impact on current-measurement accuracy.

To achieve a higher accuracy, for example for IDDQ-measurements, you can temporarily ungang channels during measurement.

To temporarily ungang channels in DPS mode, use the TM::MEASURE_CURRENT_UNGANGED parameter in the DPS_TASK test method API.

For further details see the DPS_PIN_TASK test method API.

Voltage measurement

In DPS operating mode, each channel of a DC Scale card can measure the supplied voltages.

For further details see the DPS_TASK test method API in the Test Method Programming Reference.
