Topic 43058

How to set the driver levels for single ended pins

You can set the driver of an i pin or the input part of an io pin.

Before you begin

Make sure that the Level Setup window is open.

Procedure

  1. In the Level Setup window, choose Select > Edit Equations.
  2. The Level Equation editor opens. In the level equations, set the driver level values: 
    vil = drive low level
vih = drive high level
  3. To download the values in the level equations to the test system hardware, in the Level Equation editor, press F8.
  4. To verify the result of drive level settings, in the Level Setup window, choose Select > Show I/O Eqn. & Specs Results.

    To set the drive levels, you can also directly type the values in the level [V] low and high columns of the Level Setup window. However, this will result in the inconsistence between the setting in the Level Setup window and the content of the level equation file. See How to restore the equation settings after you change them in the Timing/Level Setup window.

Results

In the Level Setup window, the level [V] low and high columns display the drive levels.

Note that the SmarTest software allows a minimum swing of 0 V, but the specified accuracy is only valid down to 200 mV.
