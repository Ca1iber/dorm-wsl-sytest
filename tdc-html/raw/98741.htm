SPOP, SPOP (Set Performance Optimization Parameter)

The SPOP command serves to modify certain parameters which have an effect on the system performance. In general, the default values provided by SmarTest are sufficient for most applications. It is only in certain corner cases that these values must be modified. You must also be aware that such a change can have negative consequences for other system parameters.

The SPOP? query returns the current value of a defined performance parameter.

SPOP

SPOP {keyword}, {value}

SPOP?

SPOP? {keyword}

returns:

SPOP{keyword}, {value}

Parameters

keyword

Specifies the parameter for which performance optimization is to be changed or queried. Currently, the only possible value is:

  • SVLR_CACHE_DEPTH: Defines the number of timing sets which will be cached for searches and SVLR TIM commands.

    For Pin Scale systems, the default is 10, the minmum is 1, and the maximum is 30. For P/C systems, the only possible value is 1.

value

Specifies the value for the optimization parameter.

Example

> SPOP SVLR_CACHE_DEPTH, 20

> SPOP? SVLR_CACHE_DEPTH

< SPOP SVLR_CACHE_DEPTH, 20

Functional changes

  1. Introduced before SmarTest 6.3.2
