Import Pattern

You can import any pattern that was previously exported in the ASCII Interface format or in the STIL (Standard Test Interface Language) format.

The following files are required for the ASCII Interface format:

  • <pattern_name>.avc (ASCII vector file)
  • <pattern_name>.tmf (timing map file)
  • <pattern_name>.wtb (contains the WAVETABLE name)

For the STIL format:

  • <pattern_name>.pat.stil

The imported pattern is merged to the existing set of loaded patterns using the specified Target Pattern name. For STIL imports, the target pattern name is predefined in the STIL file. If the target pattern already exists, the existing pattern is renamed.

The pattern import uses either the ASCII Interface tool v2b (vector to binary conversion), or the STIL tool stil2bin (STIL to binary) respectively.
