The Pin Scale 1600 is the Smart Scale generation digital base card. It provides DUT board and test program compatibility to other Pin Scale digital cards.

It exists in two revisions: Pin Scale 1600 rev. A and Pin Scale 1600 rev B. The PS1600B supersedes the PS1600A and features twice the memory than the PS1600A (224 MB max. versus 112 MB max.).
Note The maximum number of vectors that will completely fill up the vector memory can be determined as the physical memory size (for instance, 224MB maximum for PS1600 Rev. B or 112MB maximum for PS1600 Rev. A) times the used X-mode. For example, in case of X-8 mode on the PS1600 Rev. B card, the maximum number of vectors is 224MVectors * 8 = 1.792GVectors. However, be aware that this memory is also shared with other components of your test program, for example: sequencer instructions, vector padding, as well as digital and DC sets. Thus, the actual memory for your vectors is generally less than what is calculated above.

With 128 channels per card, the PS1600 supports higher pin count and higher multisite testing, which enables smaller infrastructure usage and cost.

The Pin Scale 1600 addresses test requirements such as:

  • IPs with increasing number of cores
  • Higher speed serial and parallel interfaces
  • More parametric DC, smaller geometries
  • Higher scan data volume
  • System like stress test
