Topic 136485

Viewing the shmoo plots of different pins

You can view the shmoo plots of different result pins or pin groups by right-clicking the shmoo plot and selecting the desired pin or pin group.

About this task

  • When you set up a shmoo over a functional test, if you have selected multiple result pins in the resultPins field and enabled the perPinResult parameter, after execution, you can view the shmoo plot of each result pin.
  • When you set up a shmoo over test suite test, if you have defined results with the judgeAndLog API or the SHMOO_RESULT API in the test method code of the to be shmooed test suite, after execution, you can view the shmoo plots of the defined result pins or pin groups.

Procedures

For shmoo over functional tests

  1. When setting up shmoo tests, in the resultPins field, select pins or pin groups.

    Do not select @ (all pins). Otherwise, you cannot view the shmoo plot of different pins.

  2. In the perPinResult field, select ON.
  3. Finish the other setups for shmoo over functional tests as described in Setting up shmoo tests in the Shmoo Tool.
  4. Execute the shmoo test.

    A shmoo plot of one result pin is displayed in the Shmoo Tool. The name of this result pin is displayed in the plot title.

  5. To view the shmoo plot of another pin, right-click the shmoo plot, select Result Pin, and select the desired pin.

For shmoo over an existing test suite

Refer to Viewing the test results of a test suite on a shmoo plot for the detailed procedure.
