VDCG? - (Verify Device Cycle for Group)

The VDCG? (Verify Device Cycle for Group) query is a consistency check on device cycles for a group of pins. You can also use it within the context of the current label, given by TSTL, TSTL? - (TeST Label).

The query checks that the device cycle referenced by dev_cyc_name is defined for every pin in the pinlist in the specified waveform set, and that the length of the device cycle for all pins in the pinlist is the same.

Note If one specific device cycle or FDC is queried, a response is only given if the logical waveform sequence is defined.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Equation-based testing

In equation-based testing, you must identify a wavetable instead of a waveform set. This is achieved either by supplying wavetable_name directly, or by supplying a specset_id, calculated from equation set number and spec set number as follows:

100 * equation_set_no + specset_no

The appropriate wavetable is determined by looking at which wavetable is referenced by equation_set_no and specset_no in the timing specification file.

Syntax

VDCG? {waveform_set}, {dev_cyc_name}, {(pinlist)}

returns:

VDCG {waveform_set}, {dev_cyc_name}, {dev_cyc_len}

Or:

VDCG? {specset_id}, {dev_cyc_name}, {(pinlist)}

returns:

VDCG {specset_id}, {dev_cyc_name}, {dev_cyc_len}

Or:

VDCG? {wavetable_name}, {dev_cyc_name}, {(pinlist)}

returns:

VDCG {wavetable_name}, {dev_cyc_name}, {dev_cyc_len}

Parameters

waveform_set

Waveform set number. Enter PRM for the primary waveform set, or an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by WSUS, WSUS? - (Waveform Sets USed).

specset_id

Derived as follows:

100 * equation_set_no + specset_no

wavetable_name

The wavetable name. Enter a string of up to 40 alphanumeric characters (upper or lower case) enclosed in double quotes.

dev_cyc_name

The device cycle name. Enter a string of up to 16 alphanumeric characters (upper or lower case) enclosed in double quotes.

Alternatively, you can enter:

 

ALL

With this specifier the command checks that:

  • The pins in pinlist have exactly the same device cycle names.
  • For each device cycle, each pin defines the device cycle with the same length.

 

FDC

With this specifier the command checks that the first device cycle in the device cycle definition table for each pin in the pinlist has the same length.

pinlist

The pin name or names whose device cycles are to be checked. If more than one pin is required, the names must be separated with a comma. The @ character can be used to read all configured pins.

dev_cyc_len Always 1 for SmarTest 7.10.

Application

Edit command in Pattern Tool.

Errors

An error is generated if:

  • The waveform set is outside the valid range as set by WSUS.
  • specset_id is invalid because equation_set_no, specset_no, or both are invalid.
  • specset_id does not reference a defined wavetable.
  • wavetable_name does not reference a defined wavetable.

Example

VDCG? 1,ALL,(inputs)

returns: 

VDCG 1,ALL,SLEN

This example checks the consistency of all device cycles for pins in the pin group "inputs" in waveform set 1. The test system replies that all device cycles for the specified group are consistently defined.

Functional changes
