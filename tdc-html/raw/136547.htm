Interaction with the Integrated Result Tool

After you transfer a shmoo test from the Shmoo Tool to a testflow, you can use the Integrated Result Tool to view the shmoo plots generated by this shmoo test.

About this task

Displays shmoo plots of shmoo test suites or testflows.

Before you begin

  • A testflow is loaded with full setups and is opened with both the Flow Sequence Editor and Flow Data Editor.
  • Set up a shmoo test in the Shmoo Tool.

Procedure

  1. Transfer the shmoo test from the Shmoo Tool to the testflow as a new test suite.
  2. In the Flow Sequence Editor, enable the following test suite flags:
    • Output on pass
    • Output on fail
    • Pass value
    • Fail value
    • Per pin on pass
    • Per pin on fail
  3. In the Flow Data Editor, on the Flags tab, enable the log_events_enable system flag.
  4. Open the Integrated Result Tool.
  5. Run this shmoo test suite or the whole testflow.
  6. In the test summary window of the Integrated Result Tool, right-click the shmoo test suite name and select Show In > Shmoo View.

Results

The shmoo plot is displayed in the shmoo view of the Integrated Result Tool.
