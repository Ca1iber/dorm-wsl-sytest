DC_WAVEFORM.getSampleVectorDistance()

This function returns the specified value of vectors between DC waveform points.

Syntax

void getSampleVectorDistance(INT & distance) const;
Parameter

Parameter

Description

distance

The parameter returns the number of vectors specified by the DC_WAVEFORM.sampleVectorDistance() member function.

Return value

There is no return value.

Related information

DC_WAVEFORM.sampleVectorDistance()

Functional changes

  1. Introduced in SmarTest 7.2.0
