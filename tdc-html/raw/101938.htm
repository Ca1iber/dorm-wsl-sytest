Creating Test Patterns

  5. Using the MTL compiler from the command line

Compiling a test pattern for HSM testing is, in principle, a simple process:

  1. Set up the test environment in SmarTest.
  2. Set up the required MTL configuration files.
  3. Run the MTL compiler, either from the command line or from the GUI.
  4. Include the compiled pattern in a SmarTest test flow and run it there.

    The execution of the pattern can be specified as a compiler option, in which case it happens automatically after the compilation. This requires a suitable test flow to have been set up in SmarTest.

The MTL-related topics are discussed in this chapter. For information on using SmarTest, please see the separate SmarTest documentation.
