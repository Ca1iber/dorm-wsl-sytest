EVENT_WAVEFORM_CF.cForce()

Sets the force current waveform as ANALOG_WAVEFORM.

Syntax

EVENT_WAVEFORM_CF & cForce (ANALOG_WAVEFORM & waveform);
Parameters
Parameter Description
waveform

Defines the waveform to be set in A (Ampere).
Return value
A reference to the corresponding EVENT_WAVEFORM_CF object.

Example

For an example see EVENT_WAVEFORM_CF.

Related information
