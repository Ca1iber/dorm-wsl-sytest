GetSiteState

This routine is used for multisite testing. It retrieves the actual site setup state consisting of focus, enabled sites, and active sites. The state information is stored in a user provided variable of type MS_SITE_STATE. The site state can later be restored by means of the routine RestoreSiteState.

Syntax

VOID GetSiteState (
    MS_SITE_STATE *site_state);

Parameters

site_state points to a structure of type MS_SITE_STATE containing information on the number of sites and on the sites currently enabled, active, and in focus.

Example

MS_SITE_STATE site_state;
GetSiteState(&site_state);

Functional changes

  1. Introduced before SmarTest 6.3.2
