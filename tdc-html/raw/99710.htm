Topic 99710

Configuring the layout of the editor

A layout defines which signals (equivalent to pins, pin aliases, and pin groups) are displayed and in which format they are displayed.

About this task

You can configure and save several layouts for an editor. You can, for example for the Pattern Editor, define a layout that shows only those signals which you are currently working on.

If you have configured and saved several layouts, you can select one of these layouts in the Pattern Explorer. Every time you start the editor, this layout is used to display the pattern.

In order to facilitate the selection in large tables, you can sort and filter the tables.

  • Sorting: To sort a table, click the table header field you want to sort by, for example Signal. On the first click the order is ascending. If you click the same field again, the order will be changed to descending, non, etc.
  • Filtering: To filter the a table, double-click the green colored field of the column you want to filter and type the filtering condition. Regular expressions are supported. To activate the content assist press Ctrl and Space.
    Note In order to list DC Scale signal pins in the Configure Layout dialog, you must set the amount of test points in the .technology file to greater than 0. For instructions see Editing technology data, and Technology file for a device for details.

For the multiport burst editor you can configure only the expanded port burst and sync group pages. For all other pages the layout cannot be configured.

Before you begin

Make sure the editor is open, for example with the pattern whose layout you want to change. (See Opening the Pattern Editor)

Procedure

  1. In the editor right-click and select Configure Layout. The Configure Layout dialog pops up. Note the Port option, which is active only for the sync group pages of the multiport editor.

    The Configure Layout dialog contains two tables:

    • The left table shows all available signals.
    • The right table shows the signals currently contained in the layout.

      The left table shows every signal three times, because every signal can be displayed in three different formats. For details see Signal and pin group representations.

      The right table has a X# column with check boxes. If you select a box, an additional state number column showing the user vector number will be displayed for that particular signal.

  2. To configure the layout:
    • To add signals to the right table, first select them in the left table in the format to be displayed, then click Add >. To add all signals listed in the left table to the right table, click Add All >.
    • Signals in the state character (SC) format can be added with a selector. That is, you can assign SC signals to groups while adding them. Select the signal(s), and click Add w/Selector >. The Define Selector window is displayed. Type a string. The signal(s) appear(s) indented underneath the selector string.
    • To remove signals from the right table, first select them in the right table, then click < Remove. To remove all signals grouped underneath a selector, select that selector string. To remove all signals from the right table, click < Remove All.
    • Shortcuts: A double-click in the left table adds the signal to right table and a double-click in the right table will remove the signal from this table.
    • To change the sequence in which the signals are displayed, use the Up and Down buttons.
  3. To complete the configuration, click OK.
  4. To save the layout configuration:
    1. In the editor right-click and select Save Layout As....
    2. Type a unique name for the layout and click OK.

Results

You have configured and saved the layout of the editor according to your needs.

What to do next

In order to make sure your layout is used every time you start the editor, select your layout in the Pattern Explorer as described in Editing pattern properties.
