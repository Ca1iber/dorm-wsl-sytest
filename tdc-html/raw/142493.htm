Using the SmartCalc framework for protocol tests

The SmartCalc framework can be used for result processing of protocol tests (not for the upload from the hardware). In principle, all you have to do is to set the protocol test into background processing mode with the smcArm() member function of the PROTOCOL_TEST class. However, the following prerequisites must be fulfilled:

  • In a multi-site setup, smcArm() must be called within the FOR_EACH_SITE block.
  • smcArm() must be called before calling SMC_ARM().
  • The protocol test must be defined dynamically within the run() function, otherwise it may no longer exist when the background process needs it to process the results.
  • Bulk upload must be enabled (see the enableBulkUploadMode() function).
  • If the test object is reused, smcArm() must be called every time it is executed.

For a code example, see PROTOCOL_TEST.

Functional changes

  1. Introduced in SmarTest 7.2.1
