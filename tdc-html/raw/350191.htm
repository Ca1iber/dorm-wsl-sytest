Topic 350191

Basic rules for SmartRDI

Some basic rules must be observed when setting up tests SmartRDI tests.

The following topics are covered:

  • Structure of a SmartRDI command
  • SmartRDI setup inside the ON_FIRST_INVOCATION block only
  • Pattern-based mode and code-base mode
  • MAPI commands inside the ON_FIRST_INVOCATION block
  • Semi-parallel test or serial execution
  • Multiple actions in one RDI command
  • Do not divide RDI blocks by conditionals or loops
  • Retrieve results outside of the ON_FIRST_INVOCATION block
  • Split an RDI command into multiple lines using cont()
  • Split an RDI command for multiple pins and related data of an array

Basic rules

Structure of a SmartRDI command

The code setting up an RDI command is structured as follows:

rdi.class().pin("pinA").para1(...).para2(...). ... execute();

The sections of the code are defined as follows:

  • rdi is the main SmartRDI class.

  • class() defines one of the child classes listed in section SmartRDI classes of topic SmartRDI.

  • pin() is used to specify the pin(s) or pin groups to set up. It can be a single pin, multiple pins separated with comma, a pin group or all pins (@). It can also be a port name or a alias name, for example:

    rdi.dc().pin("portDPS128").vForce(1).execute();
rdi.dc().pin("alias::PIN1").vForce(2).execute();
    Note

    Do not repeat a pin name in pin(), like pin("p1,p1").

    Do also not repeat a pin name within an RDI command as follows:
    rdi.class().pin("p1").para1()
           .pin("p1").para2()
           .execute();
  • para1(...) and para2(...) represent the functions to set up the test parameters.
    Note

    If on one pin, the same parameter is set for multiple times in an RDI command as rdi.class().pin().para1(v1).para1(v2)...execute(), the later parameter will overwrite the previous one.

    For example, rdi.dc().pin(A).vForce(1).vForce(2).execute(), the vForce(2) will take effect.

SmartRDI setup inside the ON_FIRST_INVOCATION block only
Include the setup code in the ON_FIRST_INVOCATION block.
Note SmartRDI setup commands must be put inside the ON_FIRST_INVOCATION block. SmartRDI commands must not be put inside the ON_LAST_INVOCATION block.
Pattern-based mode and code-base mode
In the ON_FIRST_INVOCATION block, put the code to be executed in the pattern‑based mode inside the RDI block, and the code to be executed in the code‑based mode outside the RDI block.
MAPI commands inside the ON_FIRST_INVOCATION block

When using SmartRDI, you must put the following MAPI commands' object declarations inside the ON_FIRST_INVOCATION block:

  • DPS_TASK
  • DPS_AUX_TASK
  • HV_DC_TASK
  • PPMU_MEASURE
Semi-parallel test or serial execution
Semi-parallel or serial execution of multiple sites is supported if it is set with the Site control flags.
Multiple actions in one RDI command
To execute multiple actions at the same time, you can put multiple pins and setups in one execute() like below: 
rdi.class().pin("p1").para1()
           .pin("p2").para2()
           .pin("p3").para3()
           .execute();

For the dc() class, if you use the same pin type, such as sig, dps or io, and the same command in a parallel execution, write the statement as follows:

rdi.dc().pin("p1").para1()
        .pin("p2").para1()
        .pin("p3").para1()
        .execute();
Do not divide RDI blocks by conditionals or loops

Do not put RDI_BEGIN() or RDI_END() into any conditionals or loops like this:

RDI_BEGIN();
....
    if(....)
    {
        RDI_END();
        ...
        RDI_BEGIN();
}
....
RDI_END();
Retrieve results outside of the ON_FIRST_INVOCATION block
Put the result retrieval code outside the ON_FIRST_INVOCATION block. The code is programmed as follows:
XXX(data type) result=rdi.id("idA").getXXX();

Member function id() is used to specify the measurement ID to retrieve. getXXX() represents the function to retrieve the test result.

SmartRDI is designed to support up to 500 000 measurement result IDs at the same time.

Split an RDI command into multiple lines using cont()
Use function cont() to separate an RDI command for each pin():
rdi.dc().pin("A").iForce(10 mA).cont();
rdi.dc().pin("B").iForce(100 mA).cont();
rdi.dc().execute();
Split an RDI command for multiple pins and related data of an array
If you have arrays to hold pins and parameters, write the code similar to this example:
for (i=0;i<n;i++)
{
    rdi.dc().pin(vpin[i]).iForce(iForce[i]).cont();
}

rdi.dc().execute();
Note All actions for a pin must be in one RDI command.
