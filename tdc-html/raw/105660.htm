Topic 105660

GPIB_SELECT_CARD

The GPIB_SELECT_CARD test method API serves to select a card type for GPIB communication.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/GpibMapi.h.

Syntax

const GPIB_CARD_TYPE GPIB_SELECT_CARD(const GPIB_CARD_TYPE type);
Parameter

I/O

Parameter

Description

I

type

The GPIB card type. The value can be GPIB_USER or GPIB_SYSTEM.

  • GPIB_SYSTEM: If this value is specified and the INTERFACE_SECTION section of the model file contains a SOCGPIB or SOCHPIB entry, then this entry is used. Otherwise, the SICL interface hpib2 is used.
  • GPIB_USER: If this value is specified and the INTERFACE_SECTION section of the model file contains a USERGPIB or USERHPIB entry, then this entry is used. Otherwise, the SICL interface hpib is used.

Example

The INTERFACE_SECTION section of the model file looks as follows:

SOCGPIB : iftype=GPIB, addr="vxi11/192.168.0.101/gpib0"

SOCGPIB2 : iftype=GPIB, addr="vxi11/192.168.0.102/gpib0"

USERGPIB : iftype=GPIB, addr="vxi11/192.168.0.104/gpib0"

Then the call GPIB_SELECT_CARD(GPIB_SYSTEM) will have the effect that GPIB communication takes place at IP address 192.168.0.101. On the other hand, the call GPIB_SELECT_CARD(GPIB_USER) will have the effect that GPIB communication takes place at IP address 192.168.0.104.

Functional changes

  1. Introduced before SmarTest 6.3.2
