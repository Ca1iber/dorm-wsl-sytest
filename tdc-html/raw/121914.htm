How to print static variable value in debugging

In the test method, a static variable may be defined for the whole file, for the class or for a specific function. To print the static variable in debugging, you can use the command print in console.

Procedure

  • For the static variables defined for the whole file, in console, use the command like below: 
    print 'MyTestMethod.cpp'::variableInFile

    where MyTestMethod.cpp is the file name and variableInFile is a variable defined for the whole file

  • For the static variables defined for the class, in console, enter the command like below: 
    print 'MyTestMethod::variableInClass'

    where MyTestMethod is the class name and variableInClas is a variable defined for the class

  • For the static variables defined for a function, enter the command like below 
    print 'MyTestMethod::myFunc()::variableInMemberFunction'

    where MyTestMethod is the class name, myFunc() is the function name and variableInMemberFunction is the variable name defined for the function myFunc()
