EVENT_RANGE_VM

Measurement range classes provide functionality to define events to select measurement ranges.

Specialized measurement range classes are EVENT_RANGE_VM (Voltage Measurement Range Event) and EVENT_RANGE_IM (Current Measurement Range Event). Both classes derive from the EVENT_BASE class.

EVENT_RANGE_VM defines the voltage range.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

These member functions set and query the voltage range.

Parameters

minvalue

Minimum voltage. The unit is V.

maxvalue

Maximum voltage. The unit is V.

accuracy

Possible values are:

TM::RANGE_ACCURACY_STD

TM::RANGE_ACCURACY_HIGH

Example

Defines an event to select the voltage measurement for measurements in the range from 0 V to 7 V:

EVENT_RANGE_VM measRngEventV("setRange7V");
measRngEventV.vRange(0 V, 7 V);
