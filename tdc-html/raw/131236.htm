MTP_CONTINUITY_PIN_TASK.vForce()

The vForce() member function of MTP_CONTINUITY_PIN_TASK lets you specify the voltage to be forced.

The vForce() member function is used for testing shared pins (see the details in SharedContinuity test method). It cannot be used for non-shared and cross-terminated pins.

Syntax

MTP_CONTINUITY_PIN_TASK& vForce(double value)

Parameter

Description

value

The voltage to be forced.

The default unit is [V].
