Topic 42313

Special Functions in the Hook Source File

In addition to the hook function templates described below, the hook function source files ph_hhook.c and ph_phook.c contain two more functions.

  • phHookAvailable

    This function is called once at the start-up of the driver. It tells the driver which of the five hook functions are activated (are available). These hook functions will then be called by the driver at the respective points during the driver execution. Deactivated hook functions will not be called.

    This function does not need to be changed when implementing user-specific hook functions.

  • phHookInit

    This function is called once at the start-up of the driver, after phHookAvailable was called. It provides data which is required by hook functions when they communicate with other components of the driver.

    Any initialization a user-specific hook function may require should be implemented in this function.
