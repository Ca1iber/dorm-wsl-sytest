SEMI_PARALLEL_CONFIG.group()

Creates a semi-parallel test group with the specified group ID.

When a group is created, you can add sites to it and query the group information with the member functions of SEMI_PARALLEL_GROUP.

Syntax

SEMI_PARALLEL_GROUP & group(int groupId);
Parameter

Parameter

Description

groupId

The ID of the group to create.

Return value

A reference to the created SEMI_PARALLEL_GROUP object is returned.

Functional changes

  1. Introduced in SmarTest 7.2.0
