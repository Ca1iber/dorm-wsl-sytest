MTP_MEMORY_PATTERN.generateBitmapFile()

The generateBitmapFile() member function of MTP_MEMORY_PATTERN lets you save the contents of the memory pattern object as a bit fail map file to disk.

Syntax

void generateBitmapFile();

Example

To save the fail map of the memory pattern "march6N" as a fail bit map file (.bfd). This pattern is from port A.

memoryTest.getMemroyPort("A").getMemoryPattern("march6N").setBitMapFileName("march6N").generateBitmapFile();
