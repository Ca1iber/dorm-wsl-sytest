SmarTest in Eclipse 4

SmarTest Work Center is based on Eclipse 4 and the main advantages and differences for SmarTest users are introduced in this topic.

New functionality for SmarTest users

The following list highlights some of the main features available with Eclipse 4:

Eclipse plugins support

Eclipe 4 supports almost all existing Eclipse plugins available at: https://marketplace.eclipse.org/.

Integrated EGit plugin
From release 7.6, SmarTest includes the latest EGit plugin. Devices managed with Git version control benefit from the many new features added to the EGit tooling.
Modeled user interface
Editors and views can be placed in the same stack and it is possible to move editors outside of the main window.
Console improvements
Word wrap feature () is added to I/O consoles and text editors, enabling word wrapping for long output lines. I/O consoles include the Automatic Scroll Lock feature, which is automatically enabled when scrolling using the keys, mouse wheel, or scroll bar. For more information about the Console view, see Console view.
Show in System Explorer

To open the system default explorer and highlight the selected file or folder, right-click a file or folder in Eclipse and select Show In > System Explorer.

In case the system default explorer does not open, the command line to launch it can be configured under Window > Preferences > General > Workspace and select the command for launching the System Explorer.

Close menu options for tabs
The shortcut menu of editor tabs and view tabs include the options:
  • Close Others
  • Close Tabs to the Left
  • Close Tabs to the Right
Most Recently Used or automatic editor placement
When more tabs are opened than there is space to display them, the following overflow strategies are available:
  • Displayed in the order of opening with excess tabs being placed in the Show List (Default).
  • Most recently used tabs are displayed with the least recently used tabs being placed in the Show List.

The setting can be configured under: Window Preferences General Appearance.

In the section Visible tabs on overflow, select or deselect Show most recently used tabs.

Workspace selection dialog

The workspace selection dialog includes links to start a previously selected workspace. The link title is a shortened representation of the path to the workspace. The full path is displayed in a tooltip.

You can remove link entries using the shortcut menu.

Changes and compatibility

The following list details changes and compatibility between SmarTest versions 7.6.0 and later in comparison with SmarTest 7.5.x and earlier:

Debug Shell
The Display view has been renamed to Debug Shell view.
Workspace compatibility

Workspaces created with SmarTest versions up to and including 7.5.x are not fully compatible with SmarTest 7.6 and later.

Using a workspace created in an older SmarTest version is not recommended. Opening a workspace created in an older SmarTest version in SmarTest 7.6 and later displays a warning. It is recommended that you create a new workspace in SmarTest 7.6.

Device and test program compatibility

Devices and test programs are independent of the Eclipse version.

You can use existing SmarTest 7 devices and test programs in a new Eclipse workspace.
