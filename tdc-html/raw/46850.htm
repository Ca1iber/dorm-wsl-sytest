Parameter: tester_ready_line

Some handlers need an addition "ready signal" from the test system before populating sites. This parameter defines such a static signal. The signal is set after initialisation of the driver plug-in, reset while the test system is testing and then set again after the test is completed.

Valid values for the output lines are "DO0" to "DO15", "CTL0", and "CTL1"

Driver default: depends on driver plug-in

Changeable at run-time: yes

Applicable for: handlers

Example: test_system_ready_line: "CTL0"
