AppModelLevelStartEventType

An event of this type is logged when an application model level is entered.

Attributes

  • AppModelLevelAttrType

    Holds the name of the application model level that was entered and the type of that level.

  • TimeStampAttrType

    Holds the time when the application model level was entered.

Functional changes

  1. Introduced before SmarTest 6.3.2
