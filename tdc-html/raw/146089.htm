EVENT_WAVEFORM_IM.outOfRangeCheck()

Enables or disables the out-of-range check. Per default this check is enabled. If the check is enabled and the measurement range is exceeded, the event contributes with a FAIL to the global test result.

Syntax

EVENT_WAVEFORM_IM & outOfRangeCheck(bool failOnOutOfRange = true);
Parameter
Parameter Description
failOnOutOfRange

Possible values are: true | false

Return value

There is no return value.

Example

For an example, see EVENT_WAVEFORM_IM.

Related information

EVENT_WAVEFORM_IM

Functional changes
