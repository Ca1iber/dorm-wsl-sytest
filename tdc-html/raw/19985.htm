Topic 19985

Running Digital Capture and Retrieving Capture Results

Subtopics

  1. Retrieving Captured Data with Firmware Commands
  2. Executing Digital Capture with Firmware Commands

When using Digital Capture with user-specific applications which require the acquisition of large amounts of digital device output, for example, when capturing the output generated by a BIST, a user procedure should be used to perform the Digital Capture.

Although the meaning of the captured data, and the way it will be analyzed and processed will vary widely between test applications, two tasks are common for all these applications:

  1. Device input vectors must be run and the digital output must be captured to memory (this is called a Digital Capture Test).
  2. The captured data must be uploaded from the memory to the workstation before performing the data analysis.

SmarTest allows you to program test methods that perform specific tests required for your application.

Digital capturing can be run by test methods (recommended) using designated API calls for digital capture.

Additionally these tasks can be performed with firmware commands: DGCT? (DiGital Capture Test) and DIDT? (Download/upload DIgital daTa)
