How to set up and execute a TMU measurement

The following describes how to set up and execute a TMU measurement on the firmware level for a PS1600 pin in STDDIFF mode.

About this task

TMU measurements serve to measure the period length, pulse width, and rise time or fall time of output signals. See TMU per Pin overview for more information.

Procedure

  1. Define a TMU set:
    1. Create a TMU set with TSDF.
    2. Define the measurement parameters for the appropriate pins with TSCF.

      An example for measuring the period length is given in the description of TSCF.

    3. Make the TMU set the primary such set with TSPR.
  2. Define the arming waveforms:
    • Define waveforms that specify the ARM keyword for the r7 edge.
    • Define an appropriate delay for r7 in the active timing set.
  3. Make use of the arming waveforms in the pattern as required.
  4. Activate the appropriate result area with TSRH?, if necessary (see Storing the results of more than one measurement).
  5. Start the sequencers, for example with FTST?.

Results

The measurement results can be retrieved with TSRS? (period length) or TSRW? (raw time stamps).

Functional changes

  1. Introduced in SmarTest 7.1.0
