Topic 349492

Test Time Profiling (with SmartRDI)

Subtopics

  1. Test Time Profiling Overview

Test Time Profiling analyze how the test time is spent between "RDI_BEGIN" and "RDI_END".

About this task

You can find the test time analysis of setup command, pattern execution and result upload time consuming.

Procedure

  1. Launch SmarTest and import project into the workspace.
  2. Open TP360 and click Test Time Breakdown Analyzer from App Center.

    The Setup tab of Test Time Breakdown Analyzer opens.

  3. Select Test Time Profiling (with SmartRDI).
  4. To select the sites to be analyzed, double-click Enable sites for execution.

    Site selection window opens.

  5. Select the site number you want to analyze and click OK.

    Site selection window is closed.

  6. To select the test suites to be analyzed, double-click Select test suites for FMEA participation.

    Test suite selection window opens.

  7. Select the test suites you want to analyze and click OK.

    Test suite selection window is closed.

  8. If you want to customize the analysis, click and configure the reference. See Preference Page on Test Time Breakdown Analyzer for details.
  9. Click Analyze Test Time to begin analyzing.
    • A progress window opens and shows the progress details.
    • The Console view shows any warning and error messages.
    • The Report view displays the analyzing results.

Results

TP360 compiles an analyze report and displays it in the report view. This report is saved as a file, by default in device_path/TP360_Reports/TTM_Reports/. To save the report to another desired location, click the Save icon. You can browse this report with Firefox.
