This section introduces ADC Tests on the V93000. It describes the various static and dynamic characteristics and provides the formula that are used to calculate these characteristics.

Note SmarTest 7.10 does not yet support ADC tests.

Before the various calculations are performed the transition voltages need to be determined first. Transition voltages form the base for the calculation of all static and dynamic characteristics.

The following basics steps are performed in an ADC test:

  1. The ADC is stimulated by the AWG. The stimulus is either a sine wave or a ramp.
  2. The ADC response is captured by digital channels using the Digital Capture functionality.
  3. Histogram data is generated and stored.
  4. The transition voltages are calculated.
  5. Now static characteristics can be calculated, to calculate dynamic characteristics a FFT is performed to obtain the spectral components of the DUT response.
