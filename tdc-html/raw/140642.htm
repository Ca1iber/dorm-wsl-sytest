DPS128 / DPS64 in DPS operating mode

For the DPS mode specify the pin type as DPS+. In DPS mode you can use the DC Scale DPS128/DPS64 card like a DPS-slot DPS, to supply devices with power during the execution of a test flow.

Each of the 128/64 channels can source and sink current at a programmed voltage, and each channel can measure the voltages and currents supplied. Each high current channel provides up to 1 Amp. Each high voltage channel can provide -6 to +15 Volt. For the maximum source/sink current per card see the DPS128 / DPS64 specifications.

Equations

Note To use all features of the DC Scale DPS128/DPS64 card in DPS mode you should use equations. For details see Level Equations.

Connecting and disconnecting in DPS operating mode

When connecting and disconnecting in DPS operating mode, the DPS128/DPS64 card behaves like a DPS-slot device power supply.

When connected, it forces the programmed power supply voltage (vout). The current is limited to the connect current limit (ilimit).

The DPS128/DPS64 must be disconnected before changing any of the following:

  • a voltage force range (vout_frc_rng)
  • a clamp current range (iout_clamp_rng)

If the card is still connected, you cannot activate a dps set that contains one of above changes. To avoid damages to your device or DUT board, the system will display an error message in the report window instead.

Current and voltage measurement

In DPS operating mode, each channel of a DC Scale card can measure the supplied current or voltage. See also Hardware view for DPS and VI pins.

Unganged current measurement in DPS mode

To achieve a higher output current, you can gang multiple DC Scale channels (see DFPS, DFPS? - (DeFine Power Supply). But the higher current of ganged channels has a negative impact on current-measurement accuracy.

To achieve a higher accuracy, for example for IDDQ-measurements, you can temporarily ungang channels during measurement.

To temporarily ungang channels in DPS mode, use the MEASURE_CURRENT_UNGANGED parameter in the DPS_TASK test method API.

Note that on DPS128/64 and XPS256 you cannot execute a current compare on a ganged group of channels in unganged mode. Already activated comparators are silently disabled in unganged mode. A user notification (Error or warning) is omitted in this case, to avoid any interrupt in the testflow. The previous state of the comparators is automatically restored after the ganged group has been restored.

For further details see the DPS_TASK test method API.
