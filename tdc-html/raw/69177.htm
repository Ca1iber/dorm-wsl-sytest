Components

To work, however, the driver needs two additional components that are defined in the global configuration file:

  • an equipment-specific plug-in

    Each plug-in has its own directory containing the plug-in-related files: /opt/hp93000/soc/PH_libs/[GenericHandler|GenericProber]/<plug-in>.

    Currently, the equipment-specific plug-ins listed in the table below are available.

These plug-ins provide equipment-related driver functionality, such as a specific communication protocol, and parameters for bin and site management.

Note The GPIO plug-in "Universal-GPIO" is a generalized GPIO plug-in and can be used for handlers with GPIO interface. This plug-in provides the complete set of configuration parameters and, therefore, allows the overall configuration of the driver (see also Customizing Driver Configurations).
  • a plug-in-specific configuration file

    The configuration files are located under /etc/opt/hp93000/soc/PH_libs/

    [GenericHandler|GenericProber]/<plug-in name>/

    A configuration file allows you to configure the driver for a specific application. For example, it provides the driver with the interface type and binning and site parameters.
