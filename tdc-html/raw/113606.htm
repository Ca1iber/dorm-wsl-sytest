Locating events and their test points

The pattern editor handles events and their test points slightly different than other signals. To ease locating test points, they are marked with blue annotations in the annotation rulers.

About this task

You can display the test point lists per vector or per pin.

This describes the default setting. You can modify the appearance of the pattern editor in the Preferences window.

Before you begin

A pattern containing one or more events must be loaded.

Procedure

  • To display the list of test points for a specific pin or vector, hover the pointer over the blue annotation markers in the top or left annotation ruler.

    The displayed list indicates the test point name and the number of the vector line.

  • To go to the first test point in a row or vector line, click the top or left annotation marker.
  • To step from one test point to the next, select Navigate > Go To > Previous Element or Next Element. Alternatively press Shift+Ctrl and either the Up or Down arrow key.

What to do next

Once you located a test point, you can for example, edit it or just view its parameters in the properties view.
