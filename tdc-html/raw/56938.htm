Data Organization of Equation Based Levels

Subtopics

  1. Elements of Equation Based Level Setup
  2. Structure of an equation based level setup
  3. Testing with equation based level sets
  4. Example of an equation based level setup

The goal of a level setup is to assign values to the level resources like drive levels, compare levels, load currents, power supply voltage.

Because a fixed level setup does not satisfy the requirements of many applications, SmarTest also provides the more powerful equation-based approach to level setup.

With equation based level setup, the levels are determined by expressions that are built up from variables (and constants) by arithmetic and logical operators.

This allows you to define dependencies between different parameters in a general form and provides more flexibility.

In equation based level setup, the setup elements are part of larger data blocks which are downloaded to the test system as a whole.
