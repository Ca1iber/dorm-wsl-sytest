Topic 97816

Editing a port

About this task

Whatever action you selected:

  • to define a new port from scratch,
  • to make changes to an existing port,

the way to edit the port is always the same.

Before you begin

Make sure that a port has been created.

Procedure

  1. Open the setup editor of the port you want to edit. If the port is a new one, there are no pins in the Port Members area.
  2. To add pins to the port, select one or more pins (press Ctrl and then click) in the Available Pin List and click Add>.

    To add all the pins to the port, click Add All >>.

  3. To delete pins from the port, select one or more pins in the Port Members area and click < Remove.

    To delete all the pins from the port, click << Remove All.

    Note To quickly find the pins you are interested in, you can use Filter line.
  4. Repeat the steps 2 to 3 until your group is set up completely.
  5. Apply the data and save the pin configuration file.

Results

In the Available Pin List, the pins in the port are indicated with "√".
