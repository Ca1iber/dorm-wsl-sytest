Switch version tool

Subtopics

  1. Switching between SmarTest versions
  2. Switch version command line tool
  3. Troubleshooting the switch version tool

The switch version tool is installed as part of SmarTest Platform Delta Bundle (PDB), and is used to switch between installed versions of SmarTest and also other SmarTest tools such as TML, MTP, RDI, and correction data.

Use the version of the switch version tool that is part of the associated Platform Delta Bundle.

You can switch versions between SmarTest 7 and SmarTest 8 and within major versions as follows:

  • SmarTest
  • Test Method Library (TML)
  • Memory Test Plus (MTP)
  • Rapid Development Interface (RDI)

You can run the tool in its interactive form or from the command line.

Interactive form

The interactive form checks for the presence of versions of software, libraries, calibration files and so on, installed on the system controller and lets you choose the versions and combinations of versions interactively. The interactive form also identifies which software version, library version or calibration data files match the chosen version of SmarTest. Non-conforming combinations result in a warning but can be force installed if necessary.

Note The interactive Switch Version tool also calls the switch_version with no options. Both interactive and command line activation operate in the same way and are supported using the same error handling.

Command line form

Use the switch_version command line tool when executing a switch version from a script. switch_version employs switches to select the action you require and it is possible to make a non-conforming selection. When used in scripts, it is recommended to check the return code as warnings or errors may be reported.

For calibration files, the tool uses an algorithm to decide whether a certain calibration file gets loaded. It is possible to override this algorithm, so it is important to understand how the tool works.

Note It is possible to install a version of SmarTest while another SmarTest instance is up and running. However, after installing a new SmarTest package, execute switch_version.

The following links are not changed during installation of SmarTest:

  • /opt/hp93000/soc
  • /etc/opt/hp93000/soc
  • /var/opt/hp93000/soc

Functional changes

  1. Introduced in SmarTest 7.4.1
  2. SmarTest 7.5.3: Term "calibration data" replaced
