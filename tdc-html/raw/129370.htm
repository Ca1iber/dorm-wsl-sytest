Topic 129370

Deleting pattern files

About this task

When deleting a pattern file, which is part of a pattern master file setup, you can choose whether to delete only the reference in the pattern master file, or to delete the reference and the pattern file from the file system.

But even when you select the "Delete reference and pattern file from file system" option, the file is not completely deleted. A backup file named file_name.bak remains at the original location.

Before you begin

You should check for references. You must first delete any references, for example references from a pattern master file, before you can delete the pattern file.

Procedure

  1. In the main area of the Pattern Explorer, right-click a pattern file and select Delete. The system prompts you either with a "Cannot delete ..." error message or with a confirmation dialog. See examples below.
    • In case of the "Cannot delete ..." error message", click Show References. This lists any references in the Search window.
    • In case of the confirmation dialog proceed with step 5 below.
  2. In the Search view right-click an entry and select Next Match or Previous Match. Any references of the item, for example a port burst, are highlighted in the editor.
  3. Right-click the highlighted reference (CALL pattern) and select Delete. The reference of the pattern file is removed from the multiport burst file.
  4. Go back to step 1.
  5. In the confirmation dialog choose, whether to delete only the reference in the pattern master file, or to delete the reference and the pattern file from the file system.

Results

Either only the reference, or the reference and the pattern file is removed.

But even when you select the "Delete reference and pattern file from file system" option, the file is not completely deleted. A backup file named file_name.bak remains at the original location.
