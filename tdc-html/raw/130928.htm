TIMING_OFFSET_SEARCH_PINS.restoreFlag()

This function sets whether to enable the restore flag. If the flag is enabled, the actual edge offsets will have the same values as they had before the timing search was executed. If the restore flag is disabled, the actual edge offsets will be modified in the following way after the search is finished and the eye was found:

  • Eye search mode:

    The search offset is set to the middle of eye (MV) with MV= (RB-LB)/2

  • RB, LB-Transition search modes:

    The search offset is set to the PASS value next to the FAIL value.

If an eye is not found, the offset and LB,RB transition values remain unchanged.

Syntax

TIMING_OFFSET_SEARCH_PINS& restoreFlag(TIMING_OFFSET_SEARCH::YES_NO restoreflag);
Parameter

restoreflag

The value of the restore flag. It can be:

  • TIMING_OFFSET_SEARCH::YES: enable the restore flag.
  • TIMING_OFFSET_SEARCH::NO: disable the restore flag.

Default is TIMING_OFFSET_SEARCH::NO.

Functional changes

  1. Introduced in SmarTest 7.0.1
