Topic 118271

Selecting pins in the Properties view

Sometimes in a test method, a parameter of the PinString type, which defines the names of pins, is used. The parameter's value can be @ for all applicable pins, or any number of applicable single pins. In the Properties view, you can modify its value easily.

Before you begin

The test method selected in the test suite has at least one parameter of the PinString type.

Procedure

  1. In the Flow Sequence Editor, highlight the desired test suite. To illustrate the procedure, the continuity test suite is selected.

    The information of the test suite is displayed in the Properties view, including the test suite name, test type, and test method parameters, etc.

    The continuity test suite uses the predefined test method dc_tml.DcTest.Continuity. In this test method, the parameter pinlist of the PinString type defines the names of the pins to be tested.

  2. To modify the parameter pinlist, click the value of pinlist to make it editable. Then click the button shown in the following graphic.

    The window for selecting pins opens.

  3. In the window for selecting the pins:
    • To choose all pins, select the option All Pins (@) and click OK.
    • To choose any number of single pins, select the option Pins selected below, choose the pins from the pin list, and then click OK.

Results

The value of the parameter pinlist has been changed.

Functional changes

  1. Introduced in SmarTest 6.5.0
