PSLC, PSLC? - (Power Supply Load Capacitance)

The PSLC (Power Supply Load Capacitance) command describes the value of the load capacitor on the DUT board. This value is used by the firmware to set the DPS to the optimal performance range.

The PSLC? query returns the last programmed value.

Note For DC Scale pins, the capacitance must be specified as second parameter (DCS_value). The first value parameter is accepted and returned, but it is not applied (supports obsolete cards).

PSLC

PSLC [value], [DCS_value,] {(pinlist)}

PSLC?

PSLC? {(pinlist)}

returns: 

PSLC {value}, [DCS_value,] {(pinlist)}

Parameters

value

The value of the load capacitor (capacitance) in μF in the range of 0.0 ... 214748364.6.

DCS_value

Capacitance for DPS128 HC. This value must be set to 0, if there is no capacitance on the DUT board. Otherwise it must be set to the capacitance value of the DUT board.

The range is: 2147 μF * number_of_ganged_channels

pinlist

pinlist contains the DPS pins whose capacitive load range you want to set or read. Note that pinlist must contain the names of pins previously defined by the DFPS command. If more than one pin is specified, the names must be separated by a comma.

Example

DC Scale DPS128/DPS64

PSLC ,4.7, (VDD)

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.2.3: Support of DCS_capacitance parameter starts with 7.2.3 patch version
