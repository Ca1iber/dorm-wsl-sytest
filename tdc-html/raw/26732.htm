Topic 26732

SetSiteInFocus

Note Another focus exists besides the query focus: the setup focus.

This routine is used for multisite testing. It lets you set the query focus to a specified site. If an invalid site number is specified, the focus remains unchanged.

For the site in focus results are displayed in the Testflow window and in the Error Map. Only one site can be in focus.

Syntax

VOID SetSiteInFocus(
    INT32      site_in_focus,
    INT32     *return_state);

Parameters

Parameters for SetSiteInFocus

Parameter

Description

site_in_focus

Specifies the number of the site to be focused.

return_state

Status is set to 0 if execution was ok. Otherwise an error occurred.

Example

INT32 re_state;
SetSiteInFocus(2, &re_state);

Functional changes

  1. Introduced before SmarTest 6.3.2
