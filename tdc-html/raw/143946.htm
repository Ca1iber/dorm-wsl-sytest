PS1600 Digitizer

Each Pin Scale 1600 channel can be used as a Digitizer for both voltage and current, supporting 2 use models:

  • Vector Based

    A command in a pattern triggers a single measurement. Waveforms are captured by adding measurement commands at the appropriate time intervals into a pattern.

  • Trigger Based

    A single command in a pattern triggers capturing of a complete waveform.

Each use model can be applied to these measurement types:

  • High impedance voltage measurement

    All specifications for static Board ADC measurements apply.

  • Force current, measure voltage

    All specifications for PMU per pin apply.

  • Force voltage, measure current

    All specifications for PMU per pin apply.

Only 1 out of 16 consecutive channels can be used as digitizer at a time.

Note To be able to capture more than 4k samples, a result area must be defined for PPMU or BADC. Refer to RESULT_AREA_CONFIG_SET() for more information. The result area is to be defined as shown in the following example:
RESULT_AREA_CONFIG_SET resultAreaConfigSet("voltageRamp");

resultAreaConfigSet.pin("pin_1").setDcResultAreaSize(8192);

The example above reserves the space for 8192 samples in the memory that is shared by the error map and the digitizer samples.
