Note All the events can be generated explicitly by calling the API IssueHVMExecutionEvent() and IssueEDLEvent().

The implicit event generation functionality can be switched on/off by setting the ENABLE_IMPLICIT_EVENT parameter of SetBLCProfile() to TRUE/FALSE.

The level related information in the HVM event is empty if the events are generated implicitly in the BLC program that does not maintain the level structure.
