Topic 21379

Using Setup APIs for AC test

To set up AC measurement conditions, use the Setup APIs and their member functions. Most of the Setup APIs are "class type" APIs and used with the following two types of syntax:

Syntax1 - for accessing the object of a class used as a subsidiary data container of the Setup API:

object.func.subfunc1.subfunc2...subfuncN;

where, parameters mean as follows:

object

Class object name of a Setup API.

(for example Primary)

func

Member function of the Setup API. This member function returns the object of a class that is used as a subsidiary data container of the Setup API.

subfunc1 to

subfuncN

Member functions of a class used as a subsidiary data container of the Setup API. These member functions access data in the object returned by func.

Syntax2 - for accessing the class object of the Setup API:

object.func;

where, parameters mean as follows:

object

Class object name of a Setup API.

(for example Primary)

func

Member function of the Setup API. This member function accesses data in object.
