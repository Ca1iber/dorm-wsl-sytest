Task 6: Executing a Test Flow and Obtaining the Results

  1. Make a testflow which consists of complete tests and then execute all tests.
    1. Insert bin, flow control, assign value elements and so on.
    2. Finalize the system, testflow, and test suite flag settings.
    3. Execute all tests.
  2. Obtain the execution flow and debug the testflow.
    1. Verify the execution flow of the testflow.
    2. If there are some bugs in the testflow, fix them and then execute it again.
