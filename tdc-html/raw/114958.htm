CLOCKFORWARDING_SET

The CLOCKFORWARDING_SET class is a container representing a clock forwarding set. A clock forwarding set is composed of the clock forwarding domains that are used together. The associated clock forwarding domains will be specified via this class. For more information on clock forwarding see Forwarding the clock.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ClockForwardingSet.h.

Constructor

CLOCKFORWARDING_SET(const STRING & setName,TESTMETHOD_API::TMAPICTXT_TYPE ctxt = TESTMETHOD_API::TMAPI_CURR);
CLOCKFORWARDING_SET(const STRING & setName,const STRING& modeContext);

This function creates an object of CLOCKFORWARDING_SET with the specified name and the specified context. If the specified clock set does not exist, it is automatically created.

Parameter

setName

The clock forwarding set name.

ctxt

The context for which the set is created. It can be:

  • TESTMETHOD_API::TMAPI_DEFAULT: The default context
  • TESTMETHOD_API::TMAPI_CURR: The context of the current primary sets (default)
  • TESTMETHOD_API::TMAPI_PRM: Synonymous with TMAPI_CURR

modeContext

The context name for which the set is created. If not specified, the context DEFAULT is used.

Member functions

The member function are described in alphabetical order.

The member functions are operated on an object of CLOCKFORWARDING_SET.

remove()

void remove();

This function removes the clock forwarding set from the firmware. It makes the clock forwarding set invalid and calling other functions after it will cause an exception.

removeDomain()

void removeDomain(const STRING& singlePin);

This function removes the clock forwarding domain with the specified source pin from the firmware.

setAsPrimary()

void  setAsPrimary();

This functions defines the current clock forwarding set as primary. The set will be activated with the next FTST? query(which means before start sequencer). It uses the CFPR firmware command.

source()

CLOCKFORWARDING_DOMAIN&  source(const string& singlePin);

This function returns a reference to a CLOCKFORWARDING_DOMAIN object.

It defines the pin for which the respective clock forwarding settings will be done with other member functions of CLOCKFORWARDING_DOMAIN.

Parameters

singlePin

The pin to be used as clock forwarding source.

Class functions

The following functions Do not relate to a specific clock forwarding set. You can use it without an object of CLOCKFORWARDING_SET.

deselectGlobally()

static void deselectGlobally();

This function deselects the clock forwarding sets globally. It disables the clock forwarding feature completely.

getListofSets()

static void getListofSets(std::vector<string>& setNames)

This function executes a CFDF? query and returns a list of clock forwarding set names you have defined.

getPrimarySet()

static const string& getPrimarySet();

This function returns the primary set name. If the default setting is currently activated as primary, it will return an empty string.

Example

CLOCKFORWARDING_SET mySet("ClockForwardingSet");
mySet.source("pin1").sink("pin2,pin3,pin4");
mySet.source("pin10").sink("pin11,pin12");
// display clockforwarding setting
cout << mySet;
mySet.setAsPrimary(); // set this set as primary
// execute first functional test
START_TEST();
WAIT_TEST_DONE();
TEST();
// remove this set from SW
mySet.remove();
