XPS256 measure currents

Each channel of an XPS256 card features six combined force, clamp, and measure current ranges.

Current ranges

Each PMU features six combined force, clamp, and measure current ranges:

Variant Range Minimum and maximum current
XPS256 1 A -1.0 A ... 1.0 A
100 mA -100.0 mA ... 100.0 mA
10 mA -10.0 mA ... 10.0 mA
1 mA -1.0 mA ... 1.0 mA
100 μA -100.0 μA ... 100.0 μA
10 μA -10.0 μA ... 10.0 μA

The current ranges are common for forcing, clamping, and measuring currents. The force or clamp range is always the same as the measurement range. For specification data, refer to XPS256 voltage specifications.

Measurement filters

XPS256 channels feature programmable anti-aliasing, low-pass measurement filters for all ADCs:

  • Voltage measurement ADC of the PMU
  • Current measurement ADC of the PMU
  • Voltage drop measurements on the force line
  • Voltage drop measurements on the return line
Measurement filter characteristics
Minimum cutoff frequency: 10 Hz
Maximum cutoff frequency: 500 kHz
Default cutoff frequency: 30 kHz

The dynamic behavior of the force output is independent of the measurement filters.

Averaging

All channels of the card feature hardware based averaging of measurements. The average of multiple consecutive ADC samples is calculated and stored on board. Hardware based averaging can be utilized for code‑based and pattern‑based measurements.

Hardware-based averaging
Programmable range of samples: 1 ... 262144 (any value supported)
ADC sample frequency: 2 MHz1)

Some hints to consider:

  • The sample time for averaged measurements must be taken into account.
  • Pattern‑based measurements require a minimum number of vectors after the trigger has been initiated. For more information, refer to Timing of DC events and the related sub-topics.
  • The effective maximum sample frequency is the ADC sample frequency of 2 MHz1) divided by the number of averaged samples.
  • The "measurement filter" may be used instead of averaging if a high effective sample frequency is required. This filter behaves like a simple RC filter. The settling time is to be considered but the filter setting has no effect on the effective maximum sample frequency.
  • The dynamic behavior of the force output is independent of the settings for averaging.

Dynamic range switching

The XPS256 features dynamic force and measurement range switching. The combined force and measurement ranges can be changed without disconnecting and connecting a channel.

This feature is supported for the API based (static) programming and for programming by DC events in pattern.

The dynamic current range switching minimizes the glitches when changing the current force and measurement range of an already connected channel. The dynamic current range switching can therefore easily be used to implement IDDQ tests or similar tests that perform current measurements in low current ranges but require powering up or setting up the DUT in a higher current range.

Automatic down‑ranging

XPS256 channels feature automatic down‑ranging for current measurements:
  • In DPS operating mode, automatic down‑ranging is supported for both code‑based and pattern‑based programming using the DPS_TASK API, the DC events or SmartRDI.
  • In PMU operating mode, automatic down‑ranging is supported only for pattern‑based programming using the DC events or SmartRDI. Automatic down‑ranging is not supported for code‑based programming, which means that settings done by APIs SPMU_PIN_TASK.iMeasureRange() and rdi.dc().iMeasRange() are silently ignored. For code‑based programming, we recommend therefore, always using the APIs SPMU_PIN_TASK.iForceRange() and rdi.dc().iForceRange().

Automatic down-ranging means that the current range is automatically changed to the best fit range for the measurement and restored to the original range after the measurement.

Two parameters define whether the automatic down-ranging is performed or not:
  • The force current or clamp current range:
    • Can be set explicitly or (if not defined)
    • is automatically derived from the forced or clamped value.
  • The current measurement range:
    • Can be set explicitly or (if not defined)
    • is automatically derived from the pass/fail thresholds.
Automatic down-ranging is performed only if the current measurement range is lower than the force / clamp current range regardless whether the ranges have been set explicitly or have been selected automatically.
Restoring the XPS256 current range after down-ranging always restores the last applied force current range:
  • For code-based programming in DPS operating mode, the current range is automatically restored.
  • For pattern-based programming in DPS- or PMU operating mode, the current measure range is not automatically restored. We recommend adding an EVENT_RANGE_RESTORE at the end of the pattern or using SmartRDI function restoreRange() at least at the end of the RDI block.

Application note

Parallel connected resources and the pull down circuit
Each of the pins (P#), (PS#) and (GS#) features a pull-down resistor of typically 200 kΩ that pulls the pin down to ground. The resistor keeps the voltage at disconnected pins at a defined level of about 0 V referenced to the GND pin.

The pull down circuit is normally active in the disconnected state of the channel and is normally inactive in the connected state of a channel but some exceptions must be considered as shown in XPS256 pogo pins.

The active pull down circuits of a disconnected XPS256 channel may falsify a current measurement that is performed with another parallel connected resource The disconnected channel must be connected in high impedance (HIZ) mode to deactivate the pull down circuit for the current measurement with the other resource.
