Topic 16168

Creating a new device technology

Device technology defaults are used as default values when you create a new setup file, see the topic Device Technology Defaults.

To create a new device technology:

  1. Copy either the cmos or ecl directory structure from /opt/hp93000/soc/dev_tech to a new location.
  2. Edit all relevant default files in the necessary directories.

    For example, to change the default ECL levels:

    1. Change to the levels directory in the newly created device technology directory.
    2. Open the file new for editing.
    3. Change the drive and receive levels (DRLV and RCLV) to the levels you require (values are in mV).
    4. Save the changes.
  3. Next time you create a device, enter the new device technology name in the appropriate box.

See the Command Reference manual for details on the firmware commands.
