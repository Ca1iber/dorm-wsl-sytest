SOURCESYNC_SUB_TEST.edgeList()

Specifies the edges to be swept in every cycle.

Syntax

SOURCESYNC_SUB_TEST& edgeList (const string& edges);
Parameter

Parameter

Description

edges

Edges to be swept in every cycle. Different edges are separated with ",".

For example,"1,2,3,4".

Functional changes

  1. Introduced in MTP 3.2.2
