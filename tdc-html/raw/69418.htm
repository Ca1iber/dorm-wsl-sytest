Topic 69418

GPIB Protocols

The Tesec 9588 provides two different GPIB protocol modes: The LTX mode (GP-IB1) mode and the Theradyne mode (GP-IB2) on the handler's menu. The LTX mode is out of date. To run with the Tesec GPIB handler driver, the handler must be set to the Theradyne mode. The two modes are not compatible.
