SQTO, SQTO? - (SeQuencer TimeOut)

The SQTO command allows you to set the timeout for the sequencer. The main application is for timed (old style) match loops.

SQTO

SQTO {timeout}             // in seconds

SQTO?

SQTO?

returns: 

SQTO {timeout}

Parameters

timeout

Defines the time (in seconds) that the sequencer runs. The default value is 900 and the range is 0.001 to 2147483.

Application

Runtime command in Pattern Tool.

Errors

An error is generated if you enter a timeout value outside the allowed range.

Example

SQTO 3000

This example programs the sequencer to exit after 50 minutes.

Functional changes

  1. Introduced before SmarTest 6.3.2
