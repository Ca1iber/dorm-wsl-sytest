GPIB driver configuration

The GPIB driver configuration currently supports the handler model MR5800, M660 and M330.

The following configurations are provided for the driver:

M5800-GPIB-32.cfg

M660-GPIB-16.cfg

M330-GPIB-32.cfg

Default GPIB configuration

When the configuration files were created, certain aspects necessarily had to be defined. The table below lists these aspects and how they were defined.

Important aspects of the Mirae configuration files

Aspect

Used setting

Debug level

0. It will log only basic messages, can be changed to a value between -1 and 4.

GPIB port used

(for MR5800, M330)22,

(for MR660) 0

This must be changed to correct value based on the handler's setup.

GPIB end of message action

(for MR660) "serial-poll"

Bin mapping

default

Number of bins

(for MR5800, MR330) 32

(for MR660) 16

Temperature parameters

Temperature control may be activated

by changing the parameter temp_control to active and setting the temp_setpoint.

Test in parallel in test tray

(for MR5800, M660)(default) 32. It can be changed to 64 or 128.

Test tray step

(for MR5800, M660)(default) 4. It can be changed to 1 or 2.

Test tray row

(for MR5800, M660)(default) [1 1 1 1]

Test start detection

Done by interrupt (SRQ). It can be changed to pure polling mode with given polling interval for troubleshooting.
