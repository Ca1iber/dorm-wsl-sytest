Result menu

Menu item

Action

First Failure

Set the cursor to the position where the first failure is located

Previous Failure

Set the cursor to the position where the previous is located

Next Failure

Set the cursor to the next failure from the current cursor location.

Last Failure

Set the cursor to the previous failure from the current cursor location

Result Configuration

Open the result configuration window. For details, see Result Configuration.

Execute

Start the test

Break

Stop the execution of the test

Acquisition Mode

Set how the error data will be acquired in the Error Map and displayed in the error map tool. See Setting the acquisition mode.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.1.2: Configuration window Bandwidth Related Settings introduced
