Controlling a Production Run

Subtopics

  1. Aborting a Production Run
  2. Resetting a Production Run
  3. Aborting a Testflow
  4. Pausing a Production Run

In test execution mode, the Operation Control window shows four extra toggle buttons providing the following control functions:

  • ABORT
  • RESET
  • ABORT TESTFLOW
  • PAUSE
Note What happens, when using these functions, is determined by your individual application model. The descriptions given in the following sections only make examples of using the control functions.
