Topic 142450

TESTSET().suppressTestNameLoopCount()

This member function of TESTSET causes identical test names not to be distinguished by added numbers.

When two tests would have the same name, SmarTest normally adds a number to the second one to make sure that every test name is unique. If this function is called, this behavior is suppressed for this instance of TESTSET().

Note that many tools assume that test names are unique and regard a second test with a similar name as a retest. When you use this function, make sure that all downstream tools still behave as expected.

This function is not supported within the SMC_backgroundProcessing() test method when flag hidden_datalog_mode is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

Syntax

TESTSET & suppressTestNameLoopCount(bool suppress);

Parameter

Description

suppress

A If this parameter is true, no numbers are added to test names to make them unique.

If the parameter is false (the default), numbers are added to a test name that is the same as that of another test to make sure that both tests have different names.

Examples

Test names are made unique

TestSet.suppressTestNameLoopCount(false);

If the test "myTest" is executed three times in a loop with this setting active, the logged test names would be: "myTest[1]", "myTest[2]", and "myTest[3]".

Test names are not made unique

TestSet.suppressTestNameLoopCount(true);

If the test "myTest" is executed three times in a loop with this setting active, the logged test names would be: "myTest", "myTest", and "myTest".
