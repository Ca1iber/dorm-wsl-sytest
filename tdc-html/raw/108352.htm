Topic 108352

Opening a perspective

This topic describes how change the perspective. For details on perspectives, see Perspectives.

About this task

The following are predefined perspectives:

  • Setup
  • C/C++
  • Hardware
  • Debug

In addition to the predefined perspectives, you can define your own perspectives, see Saving and resetting a perspective.

When you start SmarTest for the first time, the 93000 Setup perspective will be opened by default.

Procedure

  • Click the Open Perspective button or click Window > Open Perspective.
    1. On the shown menu, select the perspective you want to open.
  • Click the shortcut button of a perspective.

What to do next

  • Adapt the perspective to your needs, see Arranging views, Customizing toolbars and menus, and Saving and resetting a perspective.
  • Start working on your project. For example, see Key Setup and Debug Workflows or Use cases and application papers.
