SmartRDI provides the class dc() and related functions to measure the voltage of a digital pin directly with board ADC.

The code‑based mode is supported on all Smart Scale cards.

The pattern‑based mode is supported on Smart Scale cards.

If measurements are done on more than one pin sharing the same board ADC, the measurements will be done serially in the pattern.

Note When serial measurements are being done on multiple pins that share the same board ADC, SmartRDI adds a default setting time between consecutive measurements that is long enough waiting for a single measurement done. For more information, see MSET timing of digital pins.
CAUTION In the high impedance mode, the board ADC may generate a spike when the DC relay of a digital bin is being closed. To avoid the spike occurrence, discharge the board ADC or force a voltage before the next measurement.
Note If the BADC is shared over sites, make sure to set Site Match = OFF in the related test suite.

Overview of dc() class functions for BADC setups

API Description Mode
amux() Control the multiplexer to switch or to hold the signal to the board ADC. P
average() Specify a sample number to do averaging. P, C
copyLabel() Specify to edit an existing pattern or copy and edit the pattern. P
enPassFail() Work together with getPassFail() to retrieve the pass/fail results of the pattern specified by label(). P
firstRunInLoop() Control the running of PPMU pattern setups and relays to be done only within the first iteration of loops. C
limit() Add a pair of limits for judging the pass/fail result of a dynamic DC measurement on digital pins or DC Scale pins. P
measWait() Specify a period of time to wait between the previous event and measuring the value. P, C
pin() Specify pin(s) for the subsequent DC actions. P, C
postWait() Specify a time period to wait after a action. P, C
relay() Specify relay actions before and after a measurement. P, C
vMeas() Specify a voltage measurement P, C
getValue() Retrieve the measure value from a pin. C

In the Mode column: C = Code-based, P = Pattern-based.

Example

ON_FIRST_INVOCATION_BEGIN();
  RDI_BEGIN();
    rdi.dc("rly1").pin("DATA1",TA::BADC).vMeas().execute();
  RDI_END();
ON_FIRST_INVOCATION_END();
double val;
val=rdi.id("rly1").getValue("DATA1");

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 2.2.0: Supports switching AMUX on PS1600 in the pattern‑based mode.
