Topic 42615

Firmware Commands for Multi-Site Testing

Subtopics

  1. PSTE, PSTE? - (Parallel SiTe Enable)
  2. PSFC, PSFC? - (Parallel Setup FoCus)
  3. PQFC, PQFC? - (Parallel Query FoCus)
  4. PALS, PALS? - (Pin ALlocation for multiple Sites)
  5. PACT, PACT? - (Parallel ACTivities control)
  6. PRLT? - (request Parallel ResuLTs)

Note By using firmware commands there is a danger of changing parameters and setups required by the TPI calls (the Setup Focus, described in the next paragraph, for example).

If you use TPI alone, the system handles these parameters automatically.

The Site Control window uses TPI functions in order to address specific sites. Therefore, your User Procedures should also use TPI functions to ensure maximum consistency.

The syntax of the various commands that follow conforms to that given in the manual, Command Reference.

CAUTION It is not recommended to use the site control firmware commands directly, as this may result in the site control window not showing the correct information about which sites are active and which are not. This may lead to sites, thought to be inactive, being updated by site control FW commands with undesirable results or even damage. For this reason, the site control should normally be performed via the site control window (see Using the site control) or test method APIs.

Functional changes
