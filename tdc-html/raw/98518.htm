DCCH - (DC Current measurement High precision pmu)

The DCCH (DC Current measurement High precision PMU) command allows you to define a current measurement using a DC signal pin. You use the DC set ID to assign the measurement to a DC set.

The content of a DC set defined with DCCH can be retrieved with the DCST? query.

To execute the measurement use the DC set execution command (DCEX). To retrieve results use the DC Result query (DCRE?).

The thresholds are evaluated internally for the pass/fail results.

The measurement is valid for the specified channels until minimum one of these conditions occurs:

  • A measurement for the same DC Set is re-defined for that channel.
  • A reset is executed (DCCH, DCVH, *RST, RSET DC, UDEF).

With this command you configure setups of those sites that have the setup focus: For more information, see also: PSFC, PSFC?.

Syntax

DCCH {setNr}, [prechargeVoltage], [forceMode,] [forceValue], [clampValue], [voltageDrop,]
            [lowThreshold], [highThreshold], [forceRange,] [compareMode], [settlingTime],
            [clampRange,] [relayAction], [measureCurrentRange,] [executionMode],
            [connectState,] [samples,] {(pinlist)} [, (refPinList)]
Parameters
setNr

The DC set identification number, starting with 1.
prechargeVoltage

Defines a precharge voltage (in mV).

This is an optional parameter.
forceMode This extra parameter specifies the force mode:
I Specifies the force current mode.

Parameter forceValue is to be defined in µA (Microampere).
V Specifies the force voltage mode.

Parameter forceValue is to be defined in mV (Millivolt).

This is the default force mode.

The force current mode is currently supported only by the DC Scale XPS256 card.
forceValue The force value parameter specifies the force current in µA (Microampere) or the force voltage mV (Millivolt).

The type and unit of the value depends on the value of the forceMode parameter:

I The force value is to be specified as current in µA (Microampere).
V The force value is to be specified as voltage in mV (Millivolt).
The valid range for the force value depends on the hardware.
clampValue The optional clamp value parameter specifies the output clamp voltage in mV (Millivolt) or the output clamp current in µA (Microampere).

The type and unit of the value depends on the value of the forceMode parameter:

I The clamp value is to be specified as output clamp voltage in mV (Millivolt).

This is the default mode.
V The clamp value is to be specified as output clamp current in µA (Microampere).
The parameter may be defined as floating-point number or as string.

The string format supports different values for the upper (or positive) clamp value and the lower (or negative) clamp value.

The string must be defined with pairs of properties and values in the format "property1:value1 property2:value2 ...":

Property Value type Description
lowLimit float The lower (or negative) clamp value. The value must be less than 0.0.
highLimit float The upper (or positive) clamp value. The value must be higher than 0.0.
In the query answer the lower clamp value is returned only if it is not symmetrical to the upper clamp value.

Example:

...,"lowLimit:-2000 highLimit:15000",...

The valid range for the clamp value depends on the hardware.
voltageDrop The extra parameter specifies the following values:
  • Maximum allowed force voltage in mV (Millivolt)
  • Maximum allowed return voltage drop in mV (Millivolt)
  • Warning threshold for force/return voltage drop in mV (Millivolt)
  • Delay time before a current clamp alarm is raised in ms (Millisecond)
  • Delay time before a disconnect is performed, after the clamp current is reached in ms (Millisecond)

The extra parameter is to be defined as string and is supported only by the DC Scale XPS256 card.

The string format supports different values for the force drop and for the return drop.

The string must be defined with pairs of properties and values in the format "property1:value1 property2:value2":

Property Value type Description
forceDrop integer

The maximum voltage drop on the force line or return line in mV (Millivolt).

For the specification, refer to Voltage drop protection / measurement in XPS256 other performance characteristics.

The programmable range is 0.0 … 1.0 V for the force line and for the return line but, the total for the two lines must not exceed 1.0 V.

The related power supply bits are set if the limits are hit: Bit 6 (Voltage drop force) or bit 7 (Voltage drop return). For more information, refer to PSAS? - (Power Supply Accumulated Status).

For a maximum voltage drop > 0.5 V, the OPEN_LOOP_PROT property of the connectState parameter must be set to OFF and in the DC Scale Safety editor the Vdrop Disco parameter must be set to ON.
returnDrop integer
warnForceDrop integer

The warning levels for the voltage drop on the force line or return line in mV (Millivolt).

The related power supply bits are set if the limits are hit: bit 15 (Voltage drop force warning) or bit 16 (Voltage drop return warning). For more information, refer to PSAS? - (Power Supply Accumulated Status)
warnReturnDrop
currClampTimeToAlarm integer Specifies the delay time before an alarm is raised or a disconnect is performed, after the clamp current is reached.

Unit is milliseconds.
currClampTimeToDisconnect integer

Example:

...,"forceDrop:5000 returnDrop:4000",...
lowThreshold The low threshold is used for evaluating the Pass/Fail result. It's specified in µA.
highThreshold The high threshold is used for evaluating the Pass/Fail result. It's specified in µA.
forceRange This extra parameter specifies the force range.

The type and unit of the value depends on the value of the forceMode parameter:

I The force current range is to be specified in µA (Microampere).
V The force voltage range is to be specified in mV (Millivolt).
compareMode This optional string parameter defines how the measured value is compared against the lowThreshold and the highThreshold.

The parameter may be defined as follows:

Value Mode Description
L Low The Pass/Fail result is set to PASS if the measured value is lower than the lowThreshold.
H High The Pass/Fail result is set to PASS if the measured value is higher than the highThreshold.
I Intermediate The Pass/Fail result is set to PASS if the measured value is between lowThreshold and highThreshold.
settlingTime The settling time specifies the additional time between the setup and the measurement being performed.

The valid range is 0 ms to 2000 ms. The specified settling time is added to the internal settling time of the test system.
clampRange This extra parameter specifies the clamp range.

The type and unit of the value depends on the value of the forceMode parameter:

I The clamp voltage range is to be specified in mV (Millivolt).
V The clamp current range is to be specified in µA (Microampere).
relayAction This parameter defines the termination mode of the measurement. The mode can be:

NTBBM

No-Termination-Break-Before-Measure.

Relay action:
  • For digital DC pins:

    Non-terminated measurement: Causes all pins in the pin list to be disconnected from the pin electronics (AC relay open).
NTMBB

No-Termination-Measure-Before-Break.

Relay action:
  • For digital DC pins:

    Non-terminated measurement: Causes all pins in the pin list to be disconnected from the pin electronics (AC relay open). Relay switching order is changed to MBB.
TERM Relay action:
  • For digital DC pins:

    Terminated Measurement: Causes all pins in the pin list, which are already connected to the pin electronics (AC relay closed) to remain connected during measurement. The state of the AC relay is not changed.
NO

NO relay action: No relays are switched during the measurement.

NT

Not terminated.

  • For DC Scale pins:

    Supported only in PMU operating mode. For more information, see SPMU_PIN_TASK.relay().

See also SPMU_PIN_TASK.relay().
measureCurrentRange This extra parameter defines the current measurement range.
executionMode Measurements belonging to the same DC Set must have the same execution mode. The measurement defined first defines the execution mode of the DC set:
SER Serial measurement (all pins of a site are measured sequentially)
PAR Parallel measurement (clock board parallel measurement)
SER_UNG Serial measurement (all pins of a site are measured sequentially). Ganged pins are unganged during the measurement as far as possible.

Only supported for DC Scale channels in PMU mode. Ignored for unganged pins.

PAR_UNG Parallel measurement (clock board parallel measurement). Ganged pins are unganged during the measurement as far as possible.

Only supported for DC Scale channels in PMU mode. Ignored for unganged pins.

HV_PPMU_BADC_VAL The measurement is set up using the pin PMU and performed using the board ADC.

This mode is not supported
HV_PPMU_GPF A global pass/fail measurement is performed using the pin PMU (not the system PMU).

This mode is not supported
HV_PPMU_PPF A pass/fail measurement for each pin is performed using the pin PMU (not the system PMU).

This mode is not supported
connectState The combination of the parameters executionMode and connectState defines the behavior of the selected channel.

This parameter is currently supported only by the DC Scale XPS256 card.

This parameter must be defined as string, containing pairs of properties and values in the format "property1:value1 property2:value2 ...".

Property Value Description
SAFE_CON

ON

OFF

Enables or disables the Smart Connect feature: The voltage at the DUT is sensed and the PMU is automatically set to the measured voltage before a channel is connected.

Default property is OFF.

Note: Parameter prechargeVoltage will be ignored if the Smart Connect is enabled.
OPEN_LOOP_PROT ON

OFF

The property selects the internal connection from the force output line (P# pin) and the high sense output line (PS# pin).

One of the following specifiers can be set:

  • ON

    The internal connection is made via two anti-parallel diodes.

    This is the default state if the property is not defined.

    This is the recommended setting if both the forceDrop propery and the returnDrop property of the voltageDrop parameter are set to a value < 0.5 V.

  • OFF

    The internal connection is open. The output stage no longer has any feedback if the force to sense connection on the DUT or the DUT board is (unintentionally) open.

    The following rules apply to this option:
    • The Vdrop Disco parameter must be set to ON in the DC Scale Safety editor.
    • This is the required setting if the forceDrop propery or the returnDrop property of the voltageDrop parameter is set to a value ≥ 0.5 V.
See also XPS256 programming - Voltage drop measurement.
PULLDOWN ON

OFF

Enables/disables the pulldown resistor at disconnect.

Default property is ON.
HIGH_ACCURACY ON

Enables usage of High Accuracy mode if possible. If this connection state is defined, the setup can use the 1.5V high accuracy range, see XPS256 measure voltages. If HIGH_ACCURACY is specified in a setup but the license is missing, an error message will be generated.
samples

The number of samples must be a power of 2 (2n).

This limitation does not apply for XPS256.
pinList The previously defined parameters are applied to all pins specified with the pinList parameter. If more than one pin is specified, pin names must be separated by commas. The pinList can contain pins configured as O, I, IO, or DC pin types.
refPinList

The reference pin is currently not supported.

The connection state HC_AWG requires a reference pin. This extra parameter defines a single pin or a list of pins that are used as reference pin for the pins defined by pinList.

The reference pin defines always the low force or low sense pin(s). These pins are the LF pin of the floating high-current unit or the LS pin of the differential voltmeter.

Each pin in the refPinList corresponds to a pin in the pinList. Both lists must have the same number of pins defined. The first pin in refPinList belongs to the first pin in pinList.

The refPinList cannot be defined if pinList defines all pins or more than the half of the available pins that support a reference pin based connection state.

A "single-ended" connection mode will be selected if refPinList is omitted and no reference pin is defined: The low force pin and the low sense pin of the floating resource are connected to the common ground and the channel specific ground sense input.

Reset

To reset the DC Set for all pins omit all parameters and specify all pins (@) in the pinList. This also resets existing voltage measurements belonging to the same DC Set.

Example: DCCH 1,,,,,,,,,(@)

A reset resets all measurements for the specified DC Set ID and pins. It does not care about current or voltage measurement definitions. This means a voltage measurement with DC Set ID 1 for pin p1 that has been defined by the DCVH command can be reset by the DCCH command.

Automatic down-ranging

DC Scale cards DPS128 support automatic down-ranging current measurements.

Automatic down-ranging means that the current range is automatically changed to the best fit range for the measurement and restored to the original range after the measurement.

Two parameters define whether the automatic down-ranging is performed or not:
  • The force current or clamp current range:
    • Can be set explicitly or (if not defined)
    • is automatically derived from the forced or clamped value.
  • The current measurement range:
    • Can be set explicitly or (if not defined)
    • is automatically derived from the pass/fail thresholds.
Automatic down-ranging is performed only if the current measurement range is lower than the force / clamp current range regardless whether the ranges have been set explicitly or have been selected automatically.
For more information, refer to
  • DPS128 / DPS64 specific setup tasks and DC Scale DPS128/64 HC/HV Cookbook - Section 4.2.1
  • DPS_AUX_PIN_TASK.checkSetRangeError() and DPS_AUX_TASK.getRangeError()

Notes

  • Different settling times for parallel measurements with the same ID will internally wait for the specified maximum settling time.
  • If none of the voltage or current ranges is given, the maximum of the calculated ranges (either force / measure or clamp / measure) is set.

Errors

An error is returned:

  • If any parameter is out of the allowed range (hardware dependent).
  • If any parameter is missing.
  • If the setNr is already in use by a pin which uses the same channel than the pin in pinlist. This means every DC set exists only once per channel and only for one pin containing this channel.
  • If the pinList or refPinList contains multiple pin definitions for the same channel. This may happen if connection sets are used.
  • If the force and measure range of the same type (current or voltage) do not match. For example, an explicit measure range setup of 50 mA with an implicit force range of 200 mA by 100 mA force value. Implicit clamp ranges are not considered.
  • If a reference pin is specified but the connectState is not HC_AWG.

Warnings

A warning is generated if multiple measurements are defined with the same DC set ID but with different execution modes, the execution mode of the newly defined measurement is modified and set to the execution mode of the DC set. Any DC sets following later (with the same ID) must have the same execution mode specified as the first DC set with that ID.

Examples

Example 1

Precondition:

DCCH 1,,1000,6000,-4170,-3830,I,0,NO,SER,(pin1,pin2,pin3)

Execution:

DCEX 1, MEAS_VAL

Result: 

DCRE? 1, VAL
DCRE P, -4103.3, (pin1)
DCRE F, 200.1, (pin2)
DCRE P, -3908.4, (pin3)

Example 2

Precondition:

DCCH 1,,I,100000,"lowLimit:-1000 highLimit:10000",0,100000,I,0,NT,PAR,"HC_AWG:ON",(pin1, pin2),(refPin1,refPin2)

Execution:

DCEX 1, FORCE_ON

Example 3

Precondition:

DCCH 1,,V,10000,"lowLimit:-100000 highLimit:200000",0,100000,I,0,NT,PAR,(pin1, pin2)

Execution:

DCEX 1, FORCE_ON
