System flags

  1. Open the Flags page of Flow Data editor:
    1. In the Test Program Explorer, right-click the testflow and choose Open with > Flow Data Editor.
    2. At the bottom of the Flow Data editor click the Flags tab.
  2. The System Flags tab opens.

    You can set the flags as desired. For optimized throughput, we recommend these settings:

    • datalog_formatter: off
    • datalog_sample_size: 1
    • graphic_result_display: off
    • state_display: off
    • print_wafermap: off
    • ink_wafer: off
    • max_reprobes: 1
    • temp_monitor: off
    • calib_age_monitor: off
    • diag_monitor: off
    • current_monitor: off
    • log_events_enable: on

      If this flag is off, no event data logging is performed.

    • tm_crash_as_fatal: off

      Depending on your requirements, other settings may be appropriate.

      Note You can specify system flag settings as part of Data Logging Profiles. This lets you quickly change flags for different use cases simply by assigning a different data logging profile without having to modify the setup.
