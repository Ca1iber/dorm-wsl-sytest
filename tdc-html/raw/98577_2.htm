DRLV, DRLV? - (DRive LeVel)

The DRLV command defines the low and the high voltage levels for the driver amplifiers. You can set levels for one or more pins within the same command. This command can also be used to set the drive levels for a group of pins previously defined by DFGP, DFGP? - (DeFine GrouP). These levels are included in the level set you specify. The DRLV? query returns the present voltage levels for the set and pins specified.

In connection with equation based timing, note that DRLV only changes the runtime values, not the setup values specified in the level set.
Note Each call of the DRLV FW command requires an activation of the level set. This could lead to increase in the test time in particular when high number of sites are tested in parallel. In such cases, use the SVLR FW command.

With this command you configure setups of those sites that have the setup focus: For more information, see also: PSFC, PSFC?.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

DRLV

DRLV {level_set_no | level_set_id}, [logic_0_level], [logic_1_level], [v3h_level | range,] {(pinlist)}

DRLV?

DRLV? {level_set_no | level_set_id}, {(pinlist)}

returns:

DRLV {level_set | level_set_id}, [logic_0_level], [logic_1_level], [v3h_level | range,] {(pinlist)}

Parameters

level_set_no

The identification number of the level set (fixed levels) in which you want the levels to be included. The number must not exceed the maximum number of level sets allowed (as defined by the DSCP command). Typing ALL in this field sets the levels for all existing level sets. Typing PRM sets the drive voltage levels for the primary level set.

level_set_id

Used in equation based level setup. It is derived as follows:

100000 * equation_set_no + 1000 * specset_no + level_set_no

Note that if you use the command for an equation based level setup, you modify only the runtime values, not the value in the level set.

logic_0_level

An integer (in mV) which sets the low level voltage for the drive amplifier.

logic_1_level

An integer (in mV) which sets the high level voltage for the drive amplifier.

v3h_level

Input (drive) 3rd level definition (high level voltage shift). The expression of this extra parameter must define a value in millivolts (mV).

This parameter is no longer used.

range

This extra parameter selects the drive range in mV:

 

  • -8000.0 ... 8000.0 selects the 8 V range
  • -30000.0 ... 30000.0 selects the 30 V range
  • all other values select the -40 V ... +80 V range

 

If not specified the best fit range will be selected based on logic_0_level and logic_1_level.

This parameter is currently not available.

The query returns the parameter only if it is defined for the queried level set.

pinlist

The name of the pin or pins whose levels you want to set. This parameter can also include groups previously created by the DFGP (DeFine GrouP) command. If more than one pin is to be included, the names must be separated with a comma. The symbol @ sets or reads the drive levels of all input pins in the level set. You can include I and IO pin types in pinlist.

For card specifications, like level ranges, see Digital Cards, for example:

  • Pin Scale 1600
  • Pins Scale 5000

Application

Level Setup, see Level Setup Commands.

Errors

An error is generated if:

  • The high or low level is out of range;
  • The swing limitations are exceeded;
  • The set number is out of range;
  • The set number is out of the range defined by the DSCP command;
  • The set number is out of the used range of sets (DRLV? only).
  • The parameter "range" exceeds the hardware defined maximum range.

Warnings

A warning is generated if:

  • Auto-correction of logic level 1 or 0 occurs.
  • The logic 1 or 0 level for a pin lies outside the specification.

Examples

Example 1

DRLV 1,-1750,-850,(Q0,Q1,Q2,Q3)

This example sets the driver levels for level set 1 for pins Q0, Q1, Q2 and Q3. The logic 0 level is set to -1750 mV and the logic 1 level to -850 mV.

Example 2

DRLV 1,-1750,-850,8000,(avi64Pin1)

This example shows how the 8 V drive range of an AVI64 pin is selected.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.1: No single-density support
  3. SmarTest 7.4.0: Usage of the fourth parameter extended: v3h_level changed to v3h_level | range.
