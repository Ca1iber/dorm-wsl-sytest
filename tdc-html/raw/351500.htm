Register read

Read register is to read a complete register or multiple registers.

Read a register

If a register is read-only, you can use a read operation ID in both the read() and RA_GET_READ_RESULT() commands to retrieve the register data. If register definitions are not used, you can use a read operation ID and register address in RA_READ to retrieve the register data.

RA_GET_READ_RESULT() can be called in the SMC background processing.

See Example 1.

Read multiple registers

Protocols can support burst write and read. That means the protocol allows to read multiple data from a start address. The address is automatically incremented.

It is optional to define Multiple Read in RA.

See Example 2 for how to set the protocol and how to use Multiple Read in Test Method.

Examples

Example 1

Read a register

ON_FIRST_INVOCATION_BEGIN();
RDI_BEGIN();

  reg.PERIPHERAL0().REGISTER0().read("READ_ID"); // Read operation ID.
  
  // or 
  // RA_READ("READ_ID", 0x1234 ); // 0x1234 is the address.

RDI_END();
ON_FIRST_INVOCATION_END();

ULONG64 readResult1 = RA_GET_READ_RESULT("READ_ID"); // Collect the result for the ID.

Example 2

Multiple read: Settings in protocol
virtual void defineReadRegister(I2C& i2c, ULONG64 address, int numberOfData) {
 
 i2c.startCondition();
  i2c.sendByteWithAck(SLAVE_ADDRESS);
  i2c.sendByteWithAck(address / 256);
  i2c.sendByteWithAck(address % 256);
  i2c.startCondition();
  i2c.sendByteWithAck(SLAVE_ADDRESS + 1); // Read slave address

  if(numberOfData <= 1) {
    // One data
    i2c.receiveByteNoAck("outData");
  } else {
    // Burst read
    i2c.loopBegin(numberOfData -- 1);    // Sequence instruction loop
      i2c.receiveByteAckLow("outData");  // Active ack low
    i2c.loopEnd();
    i2c.receiveByteNoAck("outData");     // No ack
  }
 i2c.stopCondition();
}
Application in Test Method
RDI_BEGIN();
  // Burst read 10 data
  RA_READ("readArray_ID", START_ADDR, 10 );
RDI_END();

// Result retrieve
vector<ULONG64> res;

RA_GET_READ_RESULT_ARRAY("readArray_ID", res);

for(unsigned int i=0;i<res.size();++i) {
  cerr << "site[" << CURRENT_SITE_NUMBER() 
       << "], " << i        << " : " << res.at(i) << endl;
}
