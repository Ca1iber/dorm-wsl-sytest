EVENT_WAVEFORM_CFVM.getSampleVectorDistance()

Reads the distance between sample vectors that has been defined by EVENT_WAVEFORM_CFVM.sampleVectorDistance().

The sample vector distance is read from the corresponding EVENT_WAVEFORM_CFVM object and returned as an integer value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

void getSampleVectorDistance(INT & vectors) const;
Parameter
Parameter Description
vectors

The sample vector distance.

Return value

There is no return value.

Example

For an example see EVENT_WAVEFORM_CFVM.

Related information

EVENT_WAVEFORM_CFVM.sampleVectorDistance()

Functional changes

  1. Introduced in SmarTest 7.4.0
