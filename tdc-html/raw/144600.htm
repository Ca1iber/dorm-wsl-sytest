connectSense()

Connects only the sense line of a DC Scale pin.

This connection mode is used for high impedance voltage measurements with the DC Scale pin in PMU operating mode.

The function can be used only in the code‑based mode.

Syntax

dcBase& connectSense();

Return Value

A reference to the dcBase object.

Example

rdi.dc().pin("DPS128_SIG_1").connectSense().execute();

RDI_BEGIN();

    rdi.dc().pin("DPS128_SIG_1").vMeas().execute(); // High-impedance measurement

RDI_END();

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 2.4.2: AVI64 added.
