Topic 136516

SMC_EXECUTE_DEBUG_ACTION()

Executes a SmartCalc debug action that can be used for test flow performance optimization by providing hidden upload utilization statistics.

Note This API should only be used for debugging and profiling performance optimization as it incurs a performance penalty.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Syntax

void SMC_EXECUTE_DEBUG_ACTION(SMC_DEBUG_ACTION action);
Parameter

Parameter

Description

action

Debug action to be performed.
List of available options of parameter: action

Option

Description

ENABLE_HIDDEN_UPLOAD_SMC_DEBUG_ACTION

Enables the gathering of hidden upload run time data to display statistics showing the percentage hidden upload utilization.

Perform this action at the beginning of a test flow.

DISABLE_HIDDEN_UPLOAD_SMC_DEBUG_ACTION

Disables the gathering of hidden upload run time data to display statistics showing the percentage hidden upload utilization. The current cached statistics are cleared.

Perform this action a the end of a test flow.

PRINT_HIDDEN_UPLOAD_SMC_DEBUG_ACTION

Prints the statistics showing the hidden upload utilization.

Perform this action after SMC_SYNCHRONIZE().

PRINT_UPLOAD_PACKAGE_SIZE_SMC_DEBUG_ACTION

Prints the detected workstation, used test head card type, express mode state, waveform and vector upload sizes.

Perform this action at the beginning of a test flow.

ENABLE_FIXED_PACKET_SIZE_SMC_DEBUG_ACTION

Enables the hidden upload fixed packet size (packet which can be uploaded in 1 ms), and disables the automatic packet size calculation.

Perform this action at the beginning of a test flow when a performance comparison between auto and fixed upload package size is required.

DISABLE_FIXED_PACKET_SIZE_SMC_DEBUG_ACTION

Disables the hidden upload fixed packet size (packet which can be uploaded in 1ms), and enables the automatic packet size calculation.

Perform this action a the end of a test flow.

PRINT_ACTIVE_THREADS_SMC_DEBUG_ACTION

Prints the thread ID, test suite name, and site number of all active upload threads. Typically called right before SMC_SYNCHRONIZE() in order to identify upload tasks that are not completed yet.
Note For FPGA compatibility refer to service note E8001-140611A when using hidden upload with MBAV8+.

Return values

Only these actions return data to the console:

  • PRINT_UPLOAD_PACKAGE_SIZE_SMC_DEBUG_ACTION
  • PRINT_HIDDEN_UPLOAD_SMC_DEBUG_ACTION
  • PRINT_ACTIVE_THREADS_SMC_DEBUG_ACTION

Refer to the examples section for more details.

Examples

Statistics on hidden upload package sizes

The statistics on hidden upload package sizes will be printed at the console with this API call:

SMC_EXECUTE_DEBUG_ACTION(PRINT_UPLOAD_PACKAGE_SIZE_SMC_DEBUG_ACTION);

The console output will show one line with information to workstation, test head card, express mode, waveform and vector upload sizes:

UploadPackageSize::info Workstation:XW8400, TesterBoard:PSIO, ExpressMode:1,WaveformUploadSize:72704Bytes/ms, VectorUploadSize:2457Bytes/ms

Statistics on hidden upload utilization

The statistics on hidden upload utilization will be printed to the console with this API call:

SMC_EXECUTE_DEBUG_ACTION(PRINT_HIDDEN_UPLOAD_SMC_DEBUG_ACTION);

The console output will show two tables; AutoUpload and RunTimeInfo:

AutoUploadMeasurement::info, AutoUpload entries = 4
AutoUpload[idx]:  ExecuteTime   ExecuteKey
AutoUpload[0]:    99.60ms     SPRM 101,1,101001,101001 SQSL"functional_long"EXECUTE
...
AutoUpload[3]:    22.08ms     SPRM 102,2,101001,101001 SQSL"capture_1Mbit"EXECUTE
AutoUIpload lists all test suites with their unique key (ExecuteKey), an index (idx) and the time the sequencer needed for executing the corresponding test suite (ExecuteTime).
AutoUploadMeasurement::info, RunTimeInfo entries = 80
RunTimeInfo[idx]: AutoUpload[idx] ExecuteTime UploadTime Utilization SuiteName
RunTimeInfo[ 0]:  AutoUpload[ 2]  2.20ms      0.00ms     0.00%     capture_16Kbit
RunTimeInfo[ 1]:  AutoUpload[ 1]  3.36ms      2.94ms     87.55%    capture_128KBit
...
RunTimeInfo[78]:  AutoUpload[ 3]  22.08ms     0.00ms     0.00%     capture_1Mbit
RunTimeInfo[79]:  AutoUpload[ 0]  99.60ms     2.46ms     2.47%     digital_start

RunTimeInfo refers to the AutoUplaod table and extends it by displaying hidden upload times (UploadTime) and resulting utilization (Utilization). The utilization is the percentage of how much time was used for uploading data in the background while a test suite was running on the sequencer. In above console snippet this means for line RunTimeInfo[79], that AutoUpload[0] took 99.6ms of the sequencer's execution time and SMC framework was able to utilize only 2.46ms for uploading data. This results in 2.47% utilization for that particular combination.

Display uncompleted upload tasks

This example will display the thread ID, test suite name and site number of upload tasks that are not completed when SMC_EXECUTE_DEBUG_ACTION() is called.

SMC_EXECUTE_DEBUG_ACTION (PRINT_ACTIVE_THREADS_SMC_DEBUG_ACTION);

The console output will look like this:

active thread: ID=1186064704; test suite=DoCapture; site=1
active thread: ID=1196554560; test suite=DoCapture; site=2
active thread: ID=1238513984; test suite=DoCapture; site=3

Sequence for default auto package size calculation

This example shows the logical sequence of debug actions for default auto package size calculation.

// Print upload package statistics at start of test flow
SMC_EXECUTE_DEBUG_ACTION(PRINT_UPLOAD_PACKAGE_SIZE_SMC_DEBUG_ACTION);

// Enable hidden upload statistics at start of test flow
SMC_EXECUTE_DEBUG_ACTION(ENABLE_HIDDEN_UPLOAD_SMC_DEBUG_ACTION);

// print hidden upload statistics after synchronize
SMC_SYNCHRONIZE();
SMC_EXECUTE_DEBUG_ACTION(PRINT_HIDDEN_UPLOAD_SMC_DEBUG_ACTION);

// Disable hidden upload statistics at end of test flow
SMC_EXECUTE_DEBUG_ACTION(DISABLE_HIDDEN_UPLOAD_SMC_DEBUG_ACTION);

Sequence for fixed package size calculation

This example shows the logical sequence of debug actions for fixed package size calculation.

// Enable the fixed packet size (disable the default auto size calculation)
SMC_EXECUTE_DEBUG_ACTION(ENABLE_FIXED_PACKET_SIZE_SMC_DEBUG_ACTION);

// Print upload package statistics at start of test flow
SMC_EXECUTE_DEBUG_ACTION(PRINT_UPLOAD_PACKAGE_SIZE_SMC_DEBUG_ACTION);

// Enable hidden upload statistics at start of test flow
SMC_EXECUTE_DEBUG_ACTION(ENABLE_HIDDEN_UPLOAD_SMC_DEBUG_ACTION);

// print hidden upload statistics after synchronize
SMC_SYNCHRONIZE();
SMC_EXECUTE_DEBUG_ACTION(PRINT_HIDDEN_UPLOAD_SMC_DEBUG_ACTION);

// Disable hidden upload statistics at end of test flow
SMC_EXECUTE_DEBUG_ACTION(DISABLE_HIDDEN_UPLOAD_SMC_DEBUG_ACTION);

// Disable the fixed packet size (enable the default auto size calculation)
SMC_EXECUTE_DEBUG_ACTION(DISABLE_FIXED_PACKET_SIZE_SMC_DEBUG_ACTION);
