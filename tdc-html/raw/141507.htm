To do the static DC measurement with SPMU, the class dc() and the following functions are provided.

Overview of dc() class functions for SPMU setups

API Description Mode
average() Specify a sample number to do the averaging. P, C
clamp() Specify a clamp voltage or current. P
connect() Connect a DPS pin. C
disconnect() Open the Force/Sense relay of a DC Scale pin. C
iForce() Specify a current to force. P, C
iMeas() Create a current measurement. P, C
iMeasRange() Specify a range of current for a measurement with SPMU. p
iRange() Specify a range of current to measure. P, C
measWait() Specify a period of time to wait between the previous event and measuring the value. P, C
pin() Specify pin(s) for the subsequent DC actions. P, C
relay() Specify relay actions. P, C
vForce() Specify a voltage to force. P, C
vMeas() Create a voltage measurement. P, C
getValue() Retrieve the measured value for a pin. C

Example

ON_FIRST_INVOCATION_BEGIN();
  rdi.dc(0).pin("DATA1",TA::SPMU).iForce(2 mA).vMeas().execute();
ON_FIRST_INVOCATION_END();
double val;
val=rdi.id(0).getValue("DATA1");

Functional changes
