Bit Fail Map Viewer windows

Subtopics

  1. Bit Fail Map Viewer window

The BFM Viewer has one main window, the Bit Fail Map Viewer window, with several tabs to display the fail map data and configure the display. Optionally, additional detail windows can be opened.
