Topic 349942

Comparing tester status from system console

About this task

The Diff Tester Status button lets you compare hardware changes between the last two saved tester status.

Before you begin

Check that your SmarTest has a version no less than 7.5.3.

Make sure that your device works properly.

Procedure

  1. In the Test Program Explorer panel, right-click Test Program and load your test program.
  2. Right-click Testflow and select Load All Setups.
  3. In System console, click the Print Tester Status button from the toolbar.

    The tester status before change are saved.

  4. In the Firmware view, make some changes to hardware properties by sending firmware commands.
  5. In System console, click the Print Tester Status button from the toolbar.

    The tester status after change are saved.

  6. In System console, click the Diff Tester Status button from the toolbar.

Results

A delta report of the tester status change is printed with details to the system console.

Example
