MTP_ADDRESS_FILTER.setMode()

This member function sets the filter mode to either use or exclude the addresses selected by MTP_ADDRESS_FILTER.setRange().

Syntax

MTP_ADDRESS_FILTER& setMode(const MTP::FILTER_MODE mode);
Parameter

Parameter

Description

mode

The mode you choose for a filter.

Default mode is MTP::INCLUDE. See the options in the table below.
Available options of parameter: mode

Option

Description

MTP::INCLUDE

Only the addresses in the defined range (defined by MTP_ADDRESS_FILTER.setRange()) can be used for generating memory test results.

MTP::EXCLUDE

Except the addresses in the defined range (defined by MTP_ADDRESS_FILTER.setRange()), all the other addresses can be used for generating memory test results.

Return value

There is no return value.

Example

Ignore the addresses from the X-address 0 to 1024 when generating a memory test results.

MTP_ADDRESS_FILTER filter;
filter.setRange(MTP::X_ADDRESS,0,1024);
filter.setMode(MTP::EXCLUDE);
