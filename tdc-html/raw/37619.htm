Structure of the Pattern Configuration File

The pattern configuration file consists of a MAPPING section, which has the form of a table, and several one line statements. The MAPPING section associates ASCII device cycles of the ASCII vector file with timing sets, and optionally also with ASCII device cycles used in the ASCII timing file. The one line statements serve to specify the base wavetable of the pattern and to control the insertion of CTIM instructions into the sequencer program.
