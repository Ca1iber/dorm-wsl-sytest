BADC_PIN_MEASURE

The BADC_PIN_MEASURE class is the data container holding the object reflecting the BADC measurement modes. The BADC_PIN_MEASURE object can only be accessed via the BADC_MEASURE class.

The API allows to measure voltage and current waveforms with board ADC of PS1600 in two ways: Sequencer based measurement and trigger based measurement.

CAUTION You must turn off site matching (see Controlling the site match function) when sharing BADC(s) over sites, to ensure proper pattern-controlled DC value measurements with the BADC.

Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/BadcPinMeasure.h.

Constructor
This class has no constructor.

Member functions

execMode()
BADC_PIN_MEASURE & execMode( const TM::DCTEST_MODE& mode);

This function selects the measurement mode.

Parameters
Parameter Description
mode

The measurement mode of type TM::DCTEST_MODE.

The following values are supported:
TM::PVAL

This mode selects a per-pin value measurement. In this mode, also the Global Pass/Fail result and the Per-pin Pass/Fail result are set.

This is the default mode.
TM::OVAL

This measurement mode delivers only a measurement value, but no pass/fail information.

This measurement mode is faster than the measurement in the TM::PVAL mode. Use it when throughput is important.
Return value
A reference to the BADC_PIN_MEASURE object.
numberOfSamples()
BADC_PIN_MEASURE & numberOfSamples(const INT numberOfSamples);

This function defines how many samples are taken for a value measurement. In static measurements, a minimum number of samples is automatically applied.

For dynamic BADC measurements on the PS1600 the default number of samples is one. It can be increased to fulfill the PS1600 Board ADC specification. To achieve the specified accuracy you need to specify the number of samples according to the table below.

Note The function cannot be used together with the member functions waveformSize() and waveformSamplePeriod().
Parameters
Parameter Description

numberOfSamples

The number of samples to be taken for a value measurement: The default is 1; the maximum is 4096.

The required number to fulfill the specification depends on the measurement type and on the current range.

Range:

Required number of samples:

For voltage measurements:

n.a.

16

For current measurements:

2 μA

64

10 μA

32

100 μA

8

2 mA

4

40 mA

4

You may specify fewer samples for a higher speed but less accuracy, or more samples for a higher accuracy but lower speed.
Note Each sample measured by the PS1600 Board ADC takes 4 μs plus a one-time overhead of 25 μs per measurement. For example, a BADC measurement with 32 samples takes 153 μs (that is, 25 μs + 32 x 4 μs). You can specify the required measurement time in the BADC_PIN_MEASURE:: wait() routine, then BREAK vectors are executed for the time the measurement takes. Alternatively you can set the waiting time to 0 seconds and manually stimulate the device for the required time with user vectors.
Return value
A reference to the BADC_PIN_MEASURE object.
waveformSize()
BADC_PIN_MEASURE & waveformSize(const INT nrOfValues);

Sets the number of values to measure in the waveform.

Note It cannot be used together with the member function numberOfSamples().
Parameters
Parameter Description
nrOfValues The number of values to measure. It is an integer in the range from 1 to 4096.
Return value
A reference to the BADC_PIN_MEASURE object.
waveformSamplePeriod()
BADC_PIN_MEASURE & waveformSamplePeriod(const double seconds);

Sets the sampling period for the value measurement.

Note It cannot be used together with the member function numberOfSamples().
Parameters
Parameter Description
seconds

The sampling period. It is a value in the range from 4 us to 409.6 us. The first sample has an additional trigger delay of 25 μs.

The sampling period resolution is 25 ns.
Return value
A reference to the BADC_PIN_MEASURE object.

Examples

Example 1: Defining a BADC value measurement

This example defines a task to set the "p1" pin to per pin value measurement mode and to take 25 samples for this measurement.

...
BADC_MEASURE meas1;
meas1.pin("p1").numberOfSamples(25);
...

Example 2: Pattern controlled high impedance voltage measurement with FLEX_RELAY path control

This example forces a voltage with pin PMU on pin "pin_force". This pin is cross-connected with pin "pin_meas". The "pin_meas" pin uses the high impedance (HIZ) measurement path to measure the voltage of "pin_force". The measurement path is configured with the FLEX_RELAY API.

virtual void run()
{
    DC_RESULT_ACCESSOR result;
    static STRING_VECTOR pinList;
    static string measPins = "pin_meas";

    if(firstRun)
    {
        PATTERN_CONTROLLER pc;
        FLEX_RELAY badcConnect;
        PPMU_SETTING ppmuForce;
        PPMU_RELAY ppmuOn,ppmuOff;
        BADC_SETTING badcSetting;
        BADC_MEASURE badcMeasure;

        ON_FIRST_INVOCATION_BEGIN();

            badcConnect.pin(measPins).set("DC","PMU","MUX_VM_HIZ");
            badcConnect.execute();

            ppmuForce.pin("pin_force")
                    .vForce(forceVoltage.getValueAsTargetUnit("V"))
                    .iRange(1 uA).min(0 uA).max(2 uA);
            ppmuForce.wait(1 ms);

            ppmuOn.pin("pin_force").status("PPMU_ON");
            ppmuOn.wait(1 ms);

            ppmuOff.pin("pin_force").status("AC_ON");
            ppmuOff.wait(1 ms);

            badcSetting.pin(measPins).min(0 V).max(5 V);
            badcSetting.wait(1 ms);

            badcMeasure.pin(measPins).numberOfSamples(16);
            badcMeasure.wait(100 us);

            pc.label("MeasBADC","@").add(ppmuForce)
                    .add(ppmuOn)
                    .add(badcSetting)
                    .add(badcMeasure)
                    .add(ppmuOff);

            pc.setup();

        ON_FIRST_INVOCATION_END();

        firstRun=false;
    }

    ON_FIRST_INVOCATION_BEGIN();

        FUNCTIONAL_TEST();

        result.uploadResult(measPins ,TM::RESULT_INDEX);

        pinList = PinUtility.getDigitalPinNamesFromPinList(measPins,TM::ALL_DIGITAL);

    ON_FIRST_INVOCATION_END();

    //
    // Results
    //
    int numberPins = pinList.size();

    for(int i=0; i<numberPins; i++)
    {
        ARRAY_D values      = result.getValues(pinList[i]);
        int numberOfResults = values.size();

        for (int j = 0; j< numberOfResults; j++)
        {
            double value = values[j];

            cout << "PF: " << result.getPassFail() << endl;
            cout << "NumVal: " << result.getNumberOfAvailableResults(pinList[i]) << endl;
            cout << "FailInfo: " << result.getFailInfo() << endl;
            cout << "PPMU VMHIZ BADC Measurement result: " << value << endl;
        }
    }

    return;
}

Example 3: Pattern controlled Pin PMU voltage measurement using Board ADC and FLEX_RELAY path control

This example does two value measurements with the Board ADC, connected to the Pin PMU.

The measurements validate the voltage forced with Pin PMU on pin "pin_force". This pin is cross connected with pin "pin_meas". The measurement path is configured with the FLEX_RELAY API.

virtual void run()
{
    DC_RESULT_ACCESSOR result;
    static STRING_VECTOR pinList;
    static string measPins = "pin_meas";
  
    if(firstRun)
    {
        PATTERN_CONTROLLER pc;
        FLEX_RELAY badcConnect;
        PPMU_SETTING ppmuSetMeasVolt, ppmuSetMeasVolt2;
        PPMU_RELAY ppmuOn,ppmuOff;
        BADC_MEASURE badcMeasure;

        ON_FIRST_INVOCATION_BEGIN();

            badcConnect.pin(measPins).set("PPMU","X","MUX_PPMU");
            badcConnect.execute();

            ppmuOn.pin("pin_force").status("PPMU_ON");
            ppmuOn.wait(1 ms);

            ppmuOff.pin("pin_force").status("AC_ON");
            ppmuOff.wait(1 ms);

            ppmuSetMeasVolt.pin("pin_force").vForce(3 V).iRange(10 uA).min(1 uA).max(2 uA);
            ppmuSetMeasVolt.pin(measPins).iForce(1 uA).iRange(10 uA).min(2 V).max(4 V);
            ppmuSetMeasVolt.wait(1 ms); // ppmu settling

            badcMeasure.pin(measPins).numberOfSamples(16);
            badcMeasure.wait(100 us); 

            ppmuSetMeasVolt2.pin("pin_force").vForce(300 mV).iRange(1 mA).min(1 uA).max(2 uA);
            ppmuSetMeasVolt2.pin(measPins).iForce(1 uA).iRange(1 mA).min(250 mV).max(350 mV);

            ppmuSetMeasVolt2.wait(1 ms); //ppmu settling

            pc.label("MeasPPMU_ADC","@").add(ppmuOn)
                                .add(ppmuSetMeasVolt)
                                .add(badcMeasure)
                                .add(ppmuSetMeasVolt2)
                                .add(badcMeasure)
                                .add(ppmuOff);

           pc.setup();

        ON_FIRST_INVOCATION_END();

        firstRun=false;
    }

    ON_FIRST_INVOCATION_BEGIN();

        FUNCTIONAL_TEST();

        result.uploadResult(measPins ,TM::RESULT_INDEX);

        pinList = PinUtility.getDigitalPinNamesFromPinList(measPins,TM::ALL_DIGITAL);

    ON_FIRST_INVOCATION_END();

    //
    // Results
    //
    int numberPins = pinList.size();

    for(int i=0; i<numberPins; i++)
    {
        ARRAY_D values      = result.getValues(pinList[i]);
        int numberOfResults = values.size();

        for (int j = 0; j< numberOfResults; j++)
        {
            double value = values[j];

            cout << "PF: " << result.getPassFail() << endl;
            cout << "NumVal: " << result.getNumberOfAvailableResults(pinList[i]) << endl;
            cout << "FailInfo: " << result.getFailInfo() << endl;
            cout << "PPMU PPMU BADC Measurement result: " << value << endl;
        }
    }

    return;
}

Example 4: Using BADC of PS1600 for mixed-signal testing

This example uses BADC of PS1600 as digitizer to measure the voltage of a waveform.

virtual void initialize()
{
    firstRun = true;

} // virtual void initialize(

virtual void connectInstruments()
{
    BADC_SETTING badcSetting;
    FLEX_RELAY connectPpmu;
    TASK_LIST taskList;

    badcSetting.pin("p8").min(-2 V).max(6 V);
    connectPpmu.pin("p1").set("ACDC");
    connectPpmu.pin("p8").set("DC","OFF","MUX_VM_HIZ");
    connectPpmu.wait(1 ms);
    taskList.add(badcSetting).add(connectPpmu).execute();

} // virtual void connectInstruments()

virtual void disconnectInstruments()
{
    FLEX_RELAY disconnectPpmu;

    disconnectPpmu.pin("p1,p8").set("IDLE","OFF");
    disconnectPpmu.execute();

} // virtual void disconnectInstruments()

virtual void run()
{
    DC_RESULT_ACCESSOR result;

    if (firstRun)
    {
        PATTERN_CONTROLLER patternControllerBadcMeasure;

        ON_FIRST_INVOCATION_BEGIN();

            BADC_MEASURE badcMeasure;

            badcMeasure.pin("portBadc").waveformSize(waveformSize).waveformSamplePeriod(samplePeriod us);
            patternControllerBadcMeasure.label("miniDigitizerSub","portBadc").add(badcMeasure);
            patternControllerBadcMeasure.setup();

        ON_FIRST_INVOCATION_END();

        createMiniDigitizerSetup();

        firstRun = false;
    }

    ON_FIRST_INVOCATION_BEGIN();

        connectInstruments();

        FUNCTIONAL_TEST();

        disconnectInstruments();

        result.uploadResult("p8",TM::RESULT_INDEX);

    ON_FIRST_INVOCATION_END();

    ARRAY_D waveform = result.getValues("p8");

    PUT_DEBUG("p8","miniDigitzer",waveform);

    return;

} // virtual void run()
