Properties of the NB_DIGITAL_CAPTURE_START and NB_DIGITAL_CAPTURE_END API function

The non-blocking (NB) function is designed to execute functional tests that include digital capture (for example, ADC).

This functionality allows the user to continue to execute firmware commands on analog instrumentation for different cores while the digital capture test is running.

  • Accessed through the Digital Test API menu
  • Allows communication with analog instruments while a digital capture test is running
  • Used where test time is the most important consideration
  • May introduce digital noise that could interfere with sensitive digital tests
  • Executes all functional vectors defined for the primary Multi-port Burst label

Functional changes

  1. Introduced before SmarTest 6.3.2
