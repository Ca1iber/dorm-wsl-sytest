Topic 112601

Loading bit fail maps into the BFM Viewer

Subtopics

  1. Loading bit fail maps automatically

Loading the bit fail maps is the first step in analyzing them.

About this task

Bit fail maps can be loaded manually or automatically or manually. This task loading them manually; see Loading bit fail maps automatically for information on automatic loading.

The bit fail maps with which you want to work must be located in the mts/bitmap/bitmap_data/ directory within the device directory that you have specified during the initial setup (see step 1 of Starting the BFM Viewer) or during later configuration (see Setting paths in Configuring the BFM Viewer).

Before you begin

You may want to configure the BFM Viewer; however, this is optional except for setting the paths, which should have happened when you started the BFM Viewer.

Procedure

  1. In the Extras menu, make sure that Autoload Mode is deactivated.

    If the Autoload mode is activated, bit fail maps are loaded automatically and cannot be manually loaded. See Loading bit fail maps automatically for details.

  2. In the main BFM Viewer window, click the Bit Fail Maps tab.

    The tabs lists all found bit fail map files in the Available BFMs list. Each file contains one or more bit fail maps.

  3. Click the bit fail map file that contains the desired bit fail map to expand it in the list.
  4. Assign the bit fail map to one of the layers (A through G) in either of these ways:
    • Drag it to the desired layer in the BFM Layer Assignment list.
    • Right-click it and choose the desired layer from the Assign to Layer submenu of the shortcut menu.

      The bit fail map appears under the chosen layer in the BFM Layer Assignment list.

      If you want to assign all bit fail maps from a file containing multiple bit fail maps to a layer, you can drag or click the file (instead of individual bit fail maps).

      If you want to view just one individual bit fail map, you can choose Fast View from the shortcut menu. Note that this removes all other bit fail maps from the BFM Layer Assignment list. Skip steps 4 and 5 in this case; the bit fail map is loaded automatically.

      You can assign multiple bit fail maps to one layer. For analysis purposes, the BFM Viewer combines them with logical or; that is, the layer indicates a failure for a cell if at least one of the bit fail maps it contains has a failure for that cell.

  5. Repeat steps 2 and 3 for any additional bit fail maps you want to include in the analysis.

    If desired, you can also drag bit fail maps from one layer to another in the BFM Layer Assignment list.

    To unassign a bit fail map, right-click it in the BFM Layer Assignment list and choose Remove from the shortcut menu.

  6. When you have arranged the bit fail maps as desired in the BFM Layer Assignment list, click the Apply button.

    This loads the chosen bit fail maps into the working memory of the BFM Viewer.

    While the loading process is under way, the current state of each layer is displayed in the BFM States list. You can click the Cancel button to stop the loading process.

    If the bit fail maps have been completely loaded, the active layers and the bit fail maps they contain are shown in the BFM States list.

Results

The loaded bit fail maps can now be analyzed with the BFM Viewer.
