Topic 10652

Configuring pin type and operating mode for a context

Subtopics

  1. Mode contexts

After a digital pin has been defined with DFPN, its type (input or output or both) and operating mode must be configured. This is done with the CONF command. The following table lists which operation modes are supported on the various systems:

Operation modes

PS1600

 PS5000

F160 (= STD)

x

 x

FAST (no IO type)

 

 x

STDDIFF (no IO type)

 

FASTDIFF (no IO type)

 

Type and operating mode are always specified for a certain mode context (see Mode contexts). The same pin may have a different direction and operating mode in different contexts. If no context is specified, the settings apply to the DEFAULT context.

The CONF? command lists the pin type and operating mode of the specified pins in the specified or implied context.

Note Executing the CONF command affects the following relay settings of the specified channel: AC relays connecting the pin electronics to the DUT pin are opened, and DC relays connecting the DC rail to the DUT pin are opened. You can close the relays (and reconnect the DUT) by using the RLYC command, as described in Connect the DUT to the Tester Resources.
