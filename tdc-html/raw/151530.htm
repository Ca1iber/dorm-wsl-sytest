RDI_SEMI_PARALLEL_TEST_END()

Declares the end of the semi-parallel testing block.

It needs to be used in pair with RDI_SEMI_PARALLEL_TEST_BEGIN(). The semi-parallel testing block needs to be within an RDI_BEGIN and RDI_END block.

Syntax

RDI_SEMI_PARALLEL_TEST_END();

See the example in the RDI_SEMI_PARALLEL_TEST_BEGIN() topic for its usage.

Functional changes

  1. Introduced in SmartRDI 2.4.3
