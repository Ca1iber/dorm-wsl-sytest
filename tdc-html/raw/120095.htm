SMC_PUT_DEBUG()

Passes the specified array to the signal analyzer if the debug_analog testflow flag is on.

Two array parameters ( xseries and yseries) can be passed to the signal analyzer to put different data to the x and y axis.

Use this API inside your SMC_backgroundProcessing() method, because PUT_DEBUG is not thread safe.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Parameters

Parameter

Description/Range

pin

The pin name to identify the array data.

The pin name is used with label to specify the data in the signal analyzer.

label

The label to identify the array data.

The label is used with pin to specify the data in the signal analyzer.

You can use the same label for several different pins.

waveform

The array data or WAVE_LOG object to be passed to the signal analyzer. This data is always handled as the x-axis data.

def

A reference to the pin name of the analog measurement. The pin name is used with label to specify the data in the signal analyzer.

xydata

The SCATTER_LOG object to be passed to the signal analyzer.

xseries

The array data to be passed as the x-axis data to the signal analyzer.

yseries

The array data to be passed as the y-axis data to the signal analyzer.

colors

The array data defines the color of each point of the graph displayed in the signal analyzer. It can only be used in the scattered graph display. Refer to PUT_DEBUG for a list of available colors.

demod

The DEMODULATION object to be passed to the signal analyzer.

graphSelect

The style of the graph.

Refer to the tables below listing the available options to this parameter.

sampleUnit

The unit of the sampling frequency.

sampleValue

The sampling frequency.
List of available options of parameter: graphSelect using a DEMODULATION object.

Option

Description

TM::CONSTELLATION

Plots the constellation points of a demodulation.

TM::COMPOSITE

TM::EVM_VS_SYMBOL

TM::ALL_GRAPHS

List of available options of parameter: graphSelect using a MEAS_DEF_I object

Option

Description

TM::SPECTRUM

Plots the frequency spectrum.

TM::POWER_VS_TIME

Plots the Signal Power (Y-Axis) versus Time (X-Axis).

TM::TIME_DOMAIN

Plots the I and Q data traces in Volts (Y-Axis) versus Time (X-Axis).

TM::ALL_GRAPHS

Return value

There is no return value.

Example

Here SMC_PUT_DEBUG() passes the wave_array data to the signal analyzer. The Aout and AnaWave are used to specify the data in the signal analyzer.

ARRAY_D wave_array;
SMC_PUT_DEBUG("Aout", "AnaWave", wave_array);

In this example SMC_PUT_DEBUG() passes the x and y axis arrays x_array and y_array to the signal analyzer. The Aout name and frequ_domain are used to specify the data in the signal analyzer.

ARRAY_D x_array, y_array
SMC_PUT_DEBUG("Aout", "frequ_domain", x_array, y_array);
