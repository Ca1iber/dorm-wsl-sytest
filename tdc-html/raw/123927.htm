Scan Test Record (STR)

The Scan Test Record contains the results of a single scan test execution. In particular, it contains all individual pin and cycle failures. If there are more failures than fit into a single record, there may be STR continuation records. Scan test records are also created if no failures were detected during the scan test.

The Scan Test Record is located after the Part Information Record.

Syntax

PSR field name

Field description

Value

93000 data source

CONT_FLAG

Flag for the existence of STR continuation records

Variable-length bit-encoded field

If the value is 1, there is a STR continuation record after the current record.

If the value is 0, this STR is the last record.

 

TEST_NUM

Test number

Four-byte unsigned integer

 

HEAD_NUM

Test head number

One-byte unsigned integer

If the system does not support identifying test heads by unique numbers, set to 1.

 

SITE_NUM

Test site number

One-byte unsigned integer

If the system does not support identifying test sites by unique numbers, set to 1.

 

PSR_REF

The index of the PSR record in which the patterns are described that were executed for this test.

When the patterns are described in multiple PSRs, this field contains the index of the first one.

Two-byte unsigned integer

 

TEST_FLG

Flags that indicate status information regarding the test.

Variable-length bit-encoded field.

If the scan test passed, all bits are zero. If it failed, the bits are set according to the entries below.

 

 

 

Bit 0:

0 = No alarm has been logged.

1 = An alarm has been logged.

 

 

Bit 1: not used at present

n/a

 

 

Bit 2:

  • If 0, the test result is not reliable.
  • If 1, the test result is reliable.

 

 

 

Bit 3:

  • If 0, no timeout occurred.
  • If 1, a timeout occurred.

 

 

 

Bit 4:

  • If 0, the test was not executed.
  • If 1, the test was executed.

 

 

 

Bit 5:

  • If 0, the test was not aborted.
  • If 1, the test was aborted.

 

 

 

Bit 6:

  • If 0, there is a pass/fail flag
  • If 1, the test was completed.

 

 

 

Bit 7:

  • If 0, the test passed.
  • If 1, the failed.

 

LOG_TYP

User-defined description of the data log type to indicate what type of information the log contains

Variable length character string

First byte is unsigned count of bytes to follow

Maximum 255 bytes

Length byte = 0 if missing or invalid data

 

 

TEST_TXT

The test name, as specified by the user

Variable length character string

First byte is unsigned count of bytes to follow

Maximum 255 bytes

Length byte = 0 if missing or invalid data

 

ALARM_ID

An optional tester-dependent name or ID of the alarm (if bit 0 of TEST_FLG is 1)

Variable length character string

First byte is unsigned count of bytes to follow

Maximum 255 bytes

Length byte = 0 if missing or invalid data

 

PROG_TXT

Information on the test program, as specified by the user

Variable length character string

First byte is unsigned count of bytes to follow

Maximum 255 bytes

Length byte = 0 if missing or invalid data

 

RSLT_TXT

Information on the test results, as specified by the user

Variable length character string

First byte is unsigned count of bytes to follow

Maximum 255 bytes

Length byte = 0 if missing or invalid data

 

Z_VAL

An indicator how the Z values (dual side comparison values) were handled on the tester

One-byte unsigned integer

  • 0: The tester does not perform dual side comparison
  • 1: Z is mapped to L
  • 2: Z is mapped to H
  • 3: Z is mapped to Z )If Z is expected, it is mapped to the mid-level between L and H.)
  • 4: Z is mapped to X

 

FMU_FLG

The statuses of the failure map and the mask map

Variable-length bit-encoded field

 

 

 

Bits 0 and 1:

  • 00: No mask map is present, no pin is globally masked.
  • 01: No mask map (MASK_MAP) present, use previous mask map definition.
  • 10: Use the mask map from this record and make it persistent.
  • 11: Not used.

 

 

 

Bits 2 and 3:

  • 00: No information on the buffer status is present or all tests have passed.
  • 01: All fails were logged, there is no fail map (FAL_MAP).
  • 10: There is a fail map.
  • 11: Not used.

 

MASK_MAP

Optional arrays of bits corresponding to the PMR index numbers of comparators that were disabled during the test.

The first bit corresponds to PMR index 1, and so on.

If this field is missing, the pin enabling as defined in the pattern source file was used.

Variable-length bit-encoded field

The first two bytes are an unsigned integer that contain the number of bits that follow.

If a bit is 1, the corresponding comparator was disabled.

 

FAL_MAP

Optional array of bits corresponding to pins that had failures after failure logging was stopped during the test.

The first bit corresponds to PMR index 1, and so on.

If this field is missing, the pin enabling as defined in the pattern source file was used.

Variable-length bit-encoded field

The first two bytes are an unsigned integer that contain the number of bits that follow.

If a bit is 1, the corresponding pin had a failure.

 

CYC_CNT

Total number of cycles executed in the test

Eight-byte unsigned integer

0: the number of cycles could not be determined

 

TOTF_CNT

 

Total number of failures detected during the test (both logged and unlogged).

Each failure of one pin in one cycle is counted as one failure. For example, if two pins failed in the same cycle or if one pin failed in two different cycles, two failures would be counted.

Four-byte unsigned integer

0: the number of failures could not be determined or there were no failures

 

TOTL_CNT

The total number of failures logged during the test.

If there a STR continuation records, the total includes the failures from all records.

Four-byte unsigned integer

 

CYC_BASE

The offset for the cycle numbers in the failure log.

This number must be added to the logged cycle number to arrive at the ATPG cycle number.

Eight-byte unsigned integer

 

BIT_BASE

The offset for the bit positions in the failure log in the pattern/chain/bit format.

Four-byte unsigned integer

 

COND_CNT

The number of test conditions listed in the COND_LST array of this record

Two-byte unsigned integer

0: COND_LST is not present

 

LIM_CNT

The number of pins for which limit specifications are provided in the LIM_INDX and LIM_SPEC fields

Two-byte unsigned integer

0: LIM_INDX and LIM_SPEC are not present

 

CYC_SIZE

The size in bytes of the CYC_OFST array members

One-byte unsigned integer

Supported values: 1, 2, 4, 8

 

PMR_SIZE

The size in bytes of the PMR_INDX array members

One-byte unsigned integer

Supported values: 1, 2

 

CHN_SIZE

The size in bytes of the CHN_NUM array members

One-byte unsigned integer

Supported values: 1, 2, 4

 

PAT_SIZE

The size in bytes of the PAT_NUM array members

One-byte unsigned integer

Supported values: 1, 2, 4

 

BIT_SIZE

The size in bytes of the BIT_POS array members

One-byte unsigned integer

Supported values: 1, 2, 4

 

U1_SIZE

The size in bytes of the USR1 array members

One-byte unsigned integer

Supported values: 1, 2, 4, 8

 

U2_SIZE

The size in bytes of the USR2 array members

One-byte unsigned integer

Supported values: 1, 2, 4, 8

 

U3_SIZE

The size in bytes of the USR3 array members

One-byte unsigned integer

Supported values: 1, 2, 4, 8

 

UTX_SIZE

The size in characters of the USER_TXT array members

One-byte unsigned integer

A value from 1 to 255

 

CAP_BGN

Offset added to the BIT_POS value for failures logged in the PAT_NUM and BIT_POS fields.

Two-byte unsigned integer

This number can be an arbitrary number, which must be bigger than the maximum scan chain pattern length.

If a failure occurs on the first capture cycle, CAP_BGN + 0 is recorded in the BIT_POS array; if it occurs on the second cycle, CAP_BGN + 1 is recorded, and so on.

 

LIM_INDX

An array of PMR indexes for pins for which fail logging limits are listed in LIM_SPEC

Array with the dimension LIM_CNT

Each value is a two-byte unsigned integer

The first array element (element 0) is reserved for indicating all pins or default pins.

 

LIM_SPEC

An array of fail logging limits for the pins listed in LIM_INDX

Array with the dimension LIM_CNT

Each value is a four-byte unsigned integer

The first array element (element 0) contains the default value that is applied to all pins for which no explicit limit is given.

 

COND_LST

An array of test conditions specified for the test.

 

Array with the dimension COND_CNT

Each entry is a variable length character string:

  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • Length byte = 0 if missing or invalid data

Each entry has the form <condition>=<value>.

Two keywords are reserved:

  • SHIFT_FREQ specifies the shift frequency for the scan test.
  • CAPTURE_FREQ specifies the capture frequency.

 

CYC_CNT

The number of elements in the CYC_OFST array

Two-byte unsigned integer

Index between 1 and 32767

0: CYC_OFST is not present

 

CYC_OFST

An array of cycle numbers that correspond to ATE cycles at which failures occurred.

The cycle numbers are relative to CYC_BASE.

Whether the first cycle is 0 or 1 is specified in bit 3 of the OPT_FLG field in the PSR record specified in the PSR_REF field.

Array with the dimension CYC_CNT

Each value is a fixed-length unsigned integer with the length CYC_SIZE

 

PMR_CNT

The number of elements in the PMR_INDX array

Two-byte unsigned integer

Index between 1 and 32767

0: PMR_INDX is not present

 

PMR_INDX

An array of PMR indexes that correspond either to the PAT_NUM array (in "pattern mode") or to the cycle number array created by adding CYC_BASE to the elements of CYC_OFST (in "cycle mode")

Array with the dimension PMR_CNT

Each value is a one- or two-byte unsigned integer with the length PMR_SIZE

 

CHN_CNT

The number of elements in the CHN_NUM array

Two-byte unsigned integer

Index between 1 and 32767

0: CHN_NUM is not present

 

CHN_NUM

An array of scan chain numbers in which failures occurred.

The values can be combined with BIT_POS values to identify CNR records.

Whether the first bit position is 0 or 1 is specified in bit 5 of the OPT_FLG field in the PSR record specified in the PSR_REF field.

Array with the dimension CHN_CNT

Each value is a one- or two-byte unsigned integer with the length CHN_SIZE

 

EXP_CNT

The number of elements in the EXP_DATA array

Two-byte unsigned integer

Index between 1 and 32767

0: EXP_DATA is not present

 

EXP_DATA

An array of expected data values that correspond either to the elements of CYC_OFST or PAT_NUM

The elements can also be used to store the 'old' data states corresponding to the 'new' data states in NEW_DATA when the STR records is used to define test pattern modifications.

Array with the dimension CAP_CNT

Each value is a one-byte character

 

CAP_CNT

The number of elements in the CAP_DATA array

Two-byte unsigned integer

Index between 1 and 32767

0: CAP_DATA is not present

 

CAP_DATA

An array of captured data values that correspond either to the elements of CYC_OFST or PAT_NUM

Array with the dimension CAP_CNT

Each value is a one-byte character

 

NEW_CNT

The number of elements in the NEW_DATA array

Two-byte unsigned integer

Index between 1 and 32767

0: NEW_DATA is not present

 

NEW_DATA

An array of required test pattern data modifications that correspond either to the elements of CYC_OFST or PAT_NUM

Array with the dimension NEW_CNT

Each value is a one-byte unsigned integer

 

PAT_CNT

The number of elements in the PAT_NUM array

Two-byte unsigned integer

Index between 1 and 32767

0: PAT_NUM is not present

 

PAT_NUM

When used in the pattern format, an array of failing pattern numbers

Whether the first pattern position is 0 or 1 is specified in bit 4 of the OPT_FLG field in the PSR record specified in the PSR_REF field.

Array with the dimension PAT_CNT

Each value is a fixed-length unsigned integer with the length PAT_SIZE

 

BPOS_CNT

The number of elements in the BIT_POS array

Two-byte unsigned integer

Index between 1 and 32767

0: BIT_POS is not present

 

BIT_POS

When used in the pattern format, an array of failing bit positions in the scan chain

The array can also be used together with the CHN_NUM array to specify an index of an SSR record for looking up the name of a flip flop.

Whether the first bit position is 0 or 1 is specified in bit 6 of the OPT_FLG field in the PSR record specified in the PSR_REF field.

Array with the dimension BPOS_CNT

Each value is a fixed-length unsigned integer with the length BIT_SIZE

 

USR1_CNT

The number of elements in the USR1 array

Two-byte unsigned integer

Index between 1 and 32767

0: USR1 is not present

 

USR1

An optional array of user-defined values

Array with the dimension USR1_CNT

Each value is a fixed-length unsigned integer with the length U1_SIZE

 

USR2_CNT

The number of elements in the USR2 array

Two-byte unsigned integer

Index between 1 and 32767

0: USR2 is not present

 

USR2

An optional array of user-defined values

Array with the dimension USR2_CNT

Each value is a fixed-length unsigned integer with the length U2_SIZE

 

USR3_CNT

The number of elements in the USR3 array

Two-byte unsigned integer

Index between 1 and 32767

0: USR3 is not present

 

USR3

An optional array of user-defined values

Array with the dimension USR3_CNT

Each value is a fixed-length unsigned integer with the length U3_SIZE

 

TXT_CNT

The number of elements in the USER_TXT array

Two-byte unsigned integer

Index between 1 and 32767

0: USER_TXT is not present

 

USER_TXT

An optional array of user-defined values

Array with the dimension TXT_CNT

Each value is a fixed-length string with the length UTX_SIZE

 

Functional changes

  1. Introduced in SmarTest 6.5.0
  2. SmarTest 7.2.3: STRs are now also created when there are no failures.
