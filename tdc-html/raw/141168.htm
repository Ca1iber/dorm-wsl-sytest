DigitalOffsetSearchConfigDataType

This class contains all configuration data of a timing or level offset search.

It is used with DIGITAL_OFFSET_SEARCH_PINS.getConfiguration() and DIGITAL_OFFSET_SEARCH_PINS.setConfiguration(). You can create an object of this class to employ the different configuration data.

The attributes of this class, corresponding to different configuration data, are listed in the following table.

Attributes

Definitions

searchType

The available search types are:

  • DIGITAL_OFFSET_SEARCH::EYE (default)
  • DIGITAL_OFFSET_SEARCH::LB
  • DIGITAL_OFFSET_SEARCH::RB

See the descriptions of each type in DIGITAL_OFFSET_SEARCH_PINS.searchType().

resourceType

The resource types for level searches are: VIH, VIL, VOH, VOL, VTH, VISWING, and VOSWING.

The resource types for timing searches are: DRIVE, RECEIVE, FAST_DRIVE, SLOW_DRIVE, and ALL_EDGES.

See the descriptions of each type in DIGITAL_OFFSET_SEARCH_PINS.resourceType().

start

A value represents the interval between the search start and the value of the searched resources. Negative values are allowed.

Therefore, the start position is calculated from:

(The value of the searched resource) + (The value set for this parameter).

The units for timing and voltage searches are [s] and [V].

numSteps

The number of search steps excluding the start value for a timing or level offset search

stepWidth

The step width for a timing or level offset search.

resolution (optional)

The resolution for a binary search.

minPassCount (optional)

A minimum consecutive pass count, which will stop the binary search if the consecutive pass count is equal to or greater than the minimum count.

transitionDetection (optional)

The transition detection types are:

  • DIGITAL_OFFSET_SEARCH::PF (default)
  • DIGITAL_OFFSET_SEARCH::ECL

See the descriptions of each type in DIGITAL_OFFSET_SEARCH_PINS.transitionDetection().

errorCountLimit (optional)

An error count limit is used to consider a test pass or fail. If the error count of a test is greater than this limit, the test is considered fail.

minStableErrorCount (optional)

A minimum error count is used to measure a stable search.

If some adjacent tests have the same number of errors, and the number of these adjacent tests is equal to or greater than this minimum count, the search is regarded as stable.

resolutionHistogramSearch (optional)

The step width for the histogram based search.

restoreFlag (optional)

It can be:

  • DIGITAL_OFFSET_SEARCH::YES: Enables the restore flag. The actual offsets will keep the original offsets before the searches.
  • DIGITAL_OFFSET_SEARCH::NO: Disables the restore flag. The actual offsets will change to the searched offsets.

enableFastStop

TRUE or FALSE to enable or disable the FASTSTOP mode.

To learn FASTMODE, refer to DIGITAL_OFFSET_SEARCH_PINS.enableFastStop().
