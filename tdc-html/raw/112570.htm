Topic 112570

How to issue a syncCommand

syncCommand is used to synchronously execute a control command which has no output value.

About this task

The BLC APIs which use the syncCommand signature include:

SetBLCProfile(), ResetBLCProfile(), StartLevel(), LoopLevel(), CompleteLevel(), SetApplicationVar(), LoadPHDriverLib(), LoadExecInputLib(), LoadDataBridgeLib(), DownloadTestflowSyn(), ExecTestflowSync(), SetReprobeAction(), SetSpecialBLCTestEnv(), IssueEDLEvent(), MoveEDLStream(), EvalWaferDescriptionFile(), UpdateResultDisplay(), IssueHVMExecutionEvent(), SetPackageID().

The prototype of syncCommand is:

xoc::hvmapi::Status syncCommand(const string &cmdName, 
const ParamList &cmdParams=ParamList( ), 
const string &sessionID= string(""));

Before you begin

Make sure you are using SmarTest 6.5.0 or later.

Procedure

  1. Prepare the parameters and session ID for the BLC API.

    Each API has different parameters. You can refer to the code template below.

    ParamList Params;
Params ["param1"] = "value_param1";
Params ["param2"] = "value_param2";
Params ["param3"] = "value_param3";
  2. Execute the API with syncCommand as below. 
    Status retVal;
retVal = syncCommand ("API_to_execute", Params, LOCAL_SESSION_ID);

Results

The API is executed and an error object will be returned to indicate the execution status of the API.

Example

The following example shows how to execute the IssueEDLEvent() API with syncCommand.

ParamList Params;
Status retVal;
Params ["EVENT_TYPE"] = "ApplModelLevelStartEventType";
Params ["LEVEL_TYPE"] = "CUSTOM_LEVEL";
Params ["LEVEL_NAME"] = "lot";
syncCommand ("IssueEDLEvent", Params, LOCAL_SESSION_ID);
