CSV Export command line tool

The CSV Export tool lets you export EDL or STDF files as CSV files from the command line with a similar range of options as the Export shortcut menu command in the Data Log Explorer view.

Note that exporting data logs with the CSV Export tool requires that SmarTest is running (although the file you want to export does not need to be loaded).

The CSV Export tool is installed with SmarTest and is installed at /opt/hp93000/soc/system/bin/CsvExport.

Syntax

CsvExport -I <input_file>[-O <output_file>] -T <report>[-F <format>][-G <grouping>][-C columns][-h]

All commands options have an abbreviated and a descriptive form. (For example, -h or --help.) This table shows both forms:

Parameter

Description

-I<input_file>

--input<input_file>

The input file, including the full path.

EDL and STDF files are supported. They do not have to be loaded into the Data Log Explorer.

-O<output_file>

--output<output_file>

The output CSV file, including the full path.

This parameter is optional. If it is not specified, the output file is saved in the same location as the input file and has the same name, just with the suffix .csv.

-T<report>

--reporttype<report>

The desired summary report you want to export. Available types include:

  • testsummary
  • devicesummary
  • binsummary
  • wafersummary

-F<format>

--reportformat<format>

Whether you want to export the summary with horizontal or vertical formatting:

  • h: Horizontal orientation; groups are exported in adjacent columns.
  • v: Vertical orientation; groups are exported in adjacent rows (the default).
  • This setting has an effect only if the exported summary is grouped. (See the -G parameter, below.)

This is an optional parameter. If it is not specified, v is used.

-G<group>

--group<group>

Whether and how the exported summaries should be grouped. These grouping options are available:

  • wafer: Group by wafer. This is available for test summaries.
  • site: Group by wafer. This is available for test summaries.
  • pin: Group by wafer. This is available for test summaries.
  • binsite: Group by site. This is available for bin summaries.

You can specify multiple grouping levels by separating the keywords with colons. For example, site:pin groups by site and pin.

This is an optional parameter. If it is not specified, exported summaries are not grouped.

-C<columns>

The columns you want the exported file to contain.

<columns> is a string that contains the desired columns separated by colons. Each individual column is specified by these elements, separated by vertical bars |:

  • Field name: The title the column has in the summary tab in SmarTest.
  • Format: If this value is set to 0, columns with group-related statistical data are shown besides each other.

    This setting applies only to columns whose names begin with "statisticData.". It is ignored for other columns. It is also ignored when the -F flag is set to v.

  • Title: The title the column has in the CSV file.

For example, -C Sbin|0|softbin:Dev#|0|devices exports two columns to the CSV file, one containing the id of the software bin (Sbin) with the title "softbin" and another containing the number of tested devices (Dev#) with the title "devices".

This is an optional parameter. If it is not specified, a default set of columns (depending on the type of summary that is exported) is included in the CSV file. The titles are the same as in the summary tabs in SmarTest.

-h

--help

Displays help information for the tool.

If -h or --help are specified, any other command line parameters are ignored and no export is performed.

Example

CsvExport -I ~/datalogs/myLog.std -O ~/Analysis/CSV/testSum.csv -T testsummary -F h -G site: Exports the test summaries for the data log file myLog.std (located in the datalogs folder of your home directory) as the file testSum.csv (which is saved in the Analysis folder of your home directory). The summaries are grouped by site, and the data for each site are put into adjacent columns.
