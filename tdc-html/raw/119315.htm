FLEXLM_LICENSE_REQUEST_STARTED

This asynchronous event indicates the start of the FlexLM licenses request. It is received after the DEVICE_CHANGE_COMPLETED event.

Dependency

Changing device is performed.

Parameter

I/O

Parameter

Description

O

SESSION_ID

the ID of the SmarTest session this event belongs to

O

TIME_STAMP

The time point when this event occurs. It consists two long-type parts SECONDs and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always EXECUTION.

O

EVENT_BODY

The event parameters represented by a ParamList. It contains the following member:

EXECUTION_STATE

The HVM event type. Here it is always FLEXLM_LICENSE_REQUEST_STARTED.
