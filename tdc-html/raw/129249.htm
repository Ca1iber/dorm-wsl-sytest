SHARED_IDD_TEST.sharingConfigFile()

The sharingConfigFile() member function of SHARED_IDD_TEST lets you specify the name of the driver sharing configuration file used which should be located in <device directory>/configuration/.

Syntax

SHARED_IDD_TEST& sharingConfigFile(const string& filename)

Parameter

Description

filename

Name of the driver sharing configuration file used.

This file should be in <device directory>/configuration/.

Example

SHARED_IDD_TEST mTest;
mTest.sharingConfigFile("default.cfg");

Related information

SHARED_IDD_TEST
