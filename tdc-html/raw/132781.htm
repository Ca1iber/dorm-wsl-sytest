Test flag table of a TPT

The test flag table CSV file in an STPM Test program template (TPT) contains information about sets of test suite flags to be applied to test suites in the test program.

The file is best edited by importing it into the OpenOffice spreadsheet provided with TPT Admin. Editing is also possible in text editors, but this requires you to make sure yourself that all formatting is correct.

Syntax

Each row in the test flag table describes one set of settings of test suite flags. The table contains these columns:

  • Flag Set ID: The name for the set of test flags. It is used to refer to this set from the test suite table.
  • (individual flags): Each column corresponds to one flag. It can contain 1 to indicate that the flag is on, or 0 to indicate that it is off.
  • Notes: Any notes you want to make about the test flag set. Comments are strictly for human use and are not processed in any way by STPM.
