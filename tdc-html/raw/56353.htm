Topic 56353

View menu

Subtopics

  1. Configured channels
  2. Installed channels

The functions in the View menu allow you to determine which channels are displayed in the Fixture Delay Tool window and how the information in the window is displayed.

Item

Function

Configured Channels

See Configured channels

Installed Channels

See Installed channels

Boards

The displayed data are the value of each channel in all boards.

Sites

The displayed data are the value of each pin in all sites.

Show Channel Numbers

Add the channel numbers to the displayed data.

Show Pin Names

Add the pin name to the displayed data

Show Site Numbers

Add the site number to the displayed data

Show Pin Numbers

Add the pin number to the displayed data

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.1: For Pin Scale 9G pins, clicking View > Show Receive Values can display the fixture delay for receive.
