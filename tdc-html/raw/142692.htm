MTL compiler

The compiler now supports defining compiler options in the APG pattern file (using the :defines: keyword) as well as override these options during compilation (using the -D compiler switch).

There is also now support for makefiles, which can be created using the -M compiler switch.

The -r0 option for creating non-binary reconstruction files has been removed.

The -O0, -O1, and -O2 option lets you configure different levels of vector compression.

Padding can be partially disabled with the -dp0 and -dp1 options.

The compiler control dialog contains appropriate controls for these new options.

Benefit

The support for predefined compiler options give you more flexibility in setting up workflows. The support for makefiles can speed up recompilation processes greatly because only changed files and files dependent on them need to be recompiled.

The selectable vector compression allows you to trade off compilation time against pattern size.
