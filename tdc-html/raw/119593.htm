Topic 119593

Adding limits in a TMLimits test table

You can add test limits to a TMLimits objects using the test table editor.

About this task

Perform this task whenever you want to modify an existing TMLimits test table to add, remove, or change existing limits.

(For creating new TMLimits test tables, see Creating TMLimits test tables. For editing general test tables, see Editing test tables.)

Before you begin

Make sure that the test table that you want to edit exists as a TMLimits CSV file.

Procedure

  1. In the Test Program Explorer, right-click the <Test Table> entry and choose Load from the shortcut menu.

    An Open dialog is displayed.

  2. Choose the TMLimits test table that you want to edit and click OK.

    You can also choose a master file (with a .mfh filename extension). The name of the chosen file appears in the Test Program Explorer.

  3. Right-click the test table in the Test Program Explorer and choose Open from the shortcut menu.

    The test table is displayed in the Test table editor. It contains the values that have been set for the testflow.

    When you have opened a master file, each file it references is displayed in an individual tab and can be edited independently.

  4. Edit the values in the table as needed.

    To edit the value in a cell, double-click it.

  5. If desired, you can add new rows or columns. For a description of the standard columns, see Structure of a TMLimits CSV file. To add a test mode row (if one is not present), add an empty row at the top and enter "Test mode" (without the quotes, case matters) in the first cell. Right-click the test table in the Test Program Explorer and choose Save from the shortcut menu.
    Note You can edit TMLimits test tables from a test method or using an external editor by editing them as general test tables, as described in Creating test tables. If you do so, make sure that these tables conform to the specifications for TMLimits tables, as described in Structure of a TMLimits CSV file.

Results

The modified TMLimits test table is saved as a file on disk.
