TestFunctionEndEventType

An event of this type is logged every time a test function execution has terminated for one of the sites involved in the test.

Attributes

  • TestSuiteNameAttrType

    Holds the name of the test suite that was executed.

  • SiteIdAttrType

    Holds the ID of the site for which the test function is executed.

  • PassFailResultAttrType

    Holds the overall pass or fail result of the test function. The overall result is a pass if all individual tests executed by the test function pass.

  • TimeStampAttrType

    Holds the time when the execution of the test function was complete.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.1.4: Added TestSuiteNameAttrType and SiteIdAttrType attributes
