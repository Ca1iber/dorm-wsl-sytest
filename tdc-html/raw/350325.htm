Topic 350325

Solution of setting up 256 sites

BLC provides two solutions to support up to 256 sites.

Site control setups in BLC code

The first solution is to set up configuration parameters in BLC code to control the quantity of sites.

For the support of 256 sites in BLC, you cannot set up the site management parameters in one block as follows: 
inputParam["FUNCTION_NAME"] = "ph_set_configuration";
inputParam["PARAMETER"] = "handler_site_ids:[ \"A\" \"B\" \"C\" \"D\" ] \ 
                           handler_site_mask:[ 1 1 1 1 ] \ 
                           smartest_site_to_handler_site_map:[ 1 2 3 4 ]";

retVal = syncOperation("CallPHDriverFunc", outputParam, inputParam, LOCAL_SESSION_ID);

Set up the site management parameters in separate statements to avoid the limitation of command length defined by #define CI_MAX_CMD_LEN (4096) in the header file.

See the first example.

Site control setups in the application model file

Another solution is to use PROB_HND_CALL in the application model file to call the site management parameters, such as prober_site_ids and prober_site_mask, which can define the site quantity.

See the second example.
