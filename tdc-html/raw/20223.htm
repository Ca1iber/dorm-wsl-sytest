Introduction of the Testflow

Subtopics

  1. Testflow methodologies
  2. Testflow components
  3. Hierarchy within a testflow
  4. Multiple Sites Execution
  5. Configuring the messages printed in the Report Window

A testflow is an interconnected collection of individual tests, each one testing a particular parameter. These tests can be interconnected in a multitude of different ways - sequentially, dependent on the previous/another result, while something is valid, etc. Together, all these tests form the complete test of your device.

Functional changes
