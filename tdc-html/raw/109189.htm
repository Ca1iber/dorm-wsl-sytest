1. Create a Test Method Project

To create a Test Method project, you need to open the C/C++ perspective first.

Procedure

  1. To open the C++ perspective, click Open Perspective and select C/C++.
  2. In the C++ perspective, right-click in the Project Explorer and select New > Test Method Project from the shortcut menu.
  3. Click Finish to use the default project name and default location of the project. The default project name is act299_tml.
