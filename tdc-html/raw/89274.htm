Internal Utility Power Supply (SE-UDPS)

Subtopics

  1. Internal Utility Power Supply (SE-UDPS) specifications
  2. Internal Utility Power Supply (SE-UDPS) pogo pin assignments

The optional Internal Utility Power Supply (SE-UDPS) provides 4 channels, delivering +5 V, +12 V, +15 V, and -15 V for active components on the DUT board. The SE-UDPS can reside in the DPS-slot (that is the ninth slot beside the DC/DC cards) of any card cage of a V93000 Pin Scale or Smart Scale system.

Typical examples for components are relays, switches, operational amplifiers, and buffers. The SE-UDPS supports also applications with DC amplifiers (low voltage measurements) and I/V converters (low current measurements), which require a low noise power supply.

The SE-UDPS is a product from Salland Engineering (Europe) BV.

Capabilities

Voltage and current capabilities

The SE-UDPS provides 4 channels, delivering as follows:

+5.0 V ±2 % 3 A
+12.0 V ±2 % 1 A
+15.0 V ±2 % 1 A
-15.0 V ±2 % 850 mA
General capabilities
  • Overcurrent protection
  • Individual ON / OFF per power supply
  • ON / OFF detection when DUT board is removed
  • Kelvin connection per DPS channel (power line)

The Kelvin connection per channel is used as ON/OFF control for voltages. When the Kelvin connection is open, the SE-UDPS voltage is set to zero. Therefore, the output voltages will only be present if a DUT board is docked.

The power-up sequencing starts 10ms after a DUT board is detected, and the power-down sequencing starts immediately after the DUT board is undocked. The default power-up sequence is +5V -> +12V -> +15V -> -15V.

Location / Filling

The SE-UDPS can reside in any DPS slot of the V93000 Pin Scale or Smart Scale system. Thus the maximum number of SE-UDPS cards is

  • 2 in a compact test head,
  • 4 in a small test head, and
  • 8 in a large test head.

You can mix the SE-UDPS with any other device power supply.

Note: The SE-UDPS is not supported in V93000 EXA Scale systems. In these systems, the SE-UDPS has been replaced by the Internal Utility Power Option.

Software and User Manual

The SE-UDPS is software revision independent. For a complete documentation of the SE-UDPS see the SE-UDPS user manual (PDF) provided by Salland Engineering (Europe) BV.

Pogo pin assignment

For the pogo pin assignments see Internal Utility Power Supply (SE-UDPS) pogo pin assignments.

Overcurrent protection

The SE-UDPS features overcurrent protection that behaves as follows:

  • The SE-UDPS monitors the output voltage by an on-board ADC.
  • In case of overcurrent the voltage drops and the related channel gets disabled whenever the voltage threshold is reached.
  • The SE-UDPS control circuitry automatically retries to enable the disabled channel, so when the overload remains the channel will not be enabled again since it does not reach its nominal voltage.
  • The sampling period of the overcurrent protection is 350 ms.

SE-UDPS internal utility power supply configuration in the model file

Although the SE-UDPS is software revision independent and cannot be controlled by SmarTest, it needs to be defined in the model file or tester.model file:

  • model file of SmarTest 7 and the legacy model file of SmarTest 8:

    The SE-UDPS is to be defined in the DPS section of the model file and in the POGOCABLING section of the file.

    Syntax:
    POGOCABLING
    <physical_card_location>: pogoblocks = "<pogoblock_list>"

DPS
    <dps_range> : <type>
    with
    <physical_card_location> = The DPS-slot of the card cage: #09 or #18 with "#" replaced by 1, 2, 3, or 4. See also table Card cage allocation based on test head type in topic POGOCABLING section.

    <pogoblock_list>

    <dps_range>

    		 = The DPS-slot pogo block 1 ... 8 as defined in DUT interface layout.
    <type> = SE-UDPS
    Example:
    POGOCABLING
    109: pogoblocks = "1"
    218: pogoblocks = "4"

DPS
    1: type = SE-UDPS
    4: type = SE-UDPS
  • tester.model of SmarTest 8 and SmarTest 7.10:

    The SE-UDPS must be defined in the CARD_CONFIGURATION section of the tester.model file.

    Syntax:
    CARD_CONFIGURATION
    slot = physical_card_location, HW = card_name, pogoblocks = pogo_cabling
    with
    physical_card_location = The DPS-slot of the card cage: #09 or #18 with "#" replaced by 1, 2, 3, or 4.
    card_name = SE-UDPS
    pogo_cabling = The DPS-slot pogo block 1 ... 8 as defined in DUT interface layout.
    Example:
    CARD_CONFIGURATION
    slot = 109, HW = SE-UDPS, pogoblocks = 1
    slot = 218, HW = SE-UDPS, pogoblocks = 4
