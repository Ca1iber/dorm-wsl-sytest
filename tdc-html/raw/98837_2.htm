UTIX? - (UTility line Inputs eXtended)

The UTIX? (UTility line Inputs eXtended) query allows the user to read the current state of the utility lines. All utility lines have read and write capabilities.

Utility lines are organized in pogo blocks that provide 32 lines per block on the DUT interface. The blocks can be accessed independently of each other. Several test head configurations are available offering either 32, 64, 256 or 512 utility lines accessible on 1, 2, 8 or 16 utility blocks. For information on this and on the mapping of utility blocks see Utility line assignments.

Note All utility lines can also be used as output lines (see UTOT, UTOT? - (UTility line OuTputs)). To use a utility line as an input line the output driver must be in high impedance state. To achieve that, you can either set the line to 0 using the UTOT command or you do not send an UTOT command for this block at all after power on.

Syntax

UTIX? [utility_group]

returns

UTIX {utility_group}, {value}

Parameters

utility_group

This parameter specifies the utility pogo block.

The pogo block is defined by a three‑digit number. For valid pogo blocks, refer to DUT interface layout and to Utility pogo block mapping in Utility pogo block - Utility Card (V93000 EXA Scale systems).

The legacy single‑digit format 1 ... 8 is also supported, but the query always returns the three‑digit format.

For the query, ALL can be entered to specify all utility blocks.

For more information, see Utility line assignments and DUT interface layout.

value

The returned integer word.

This integer word must be translated to binary code to get the state of each utility line in the utility line block specified in the query.

The range is 0 ... 4 294 967 295 for a 4‑row utility block.

Application

Reading utility lines.

Errors

An error is generated if the block number specified is out of range.

Examples

Example 1

Assuming that the first 16 utility lines of block 165 are high, then

UTIX? 165

returns

UTIX 165,65535

In this example the first 16 utility lines of block 165 were set to 0 by the UTOT command and no external device has pulled down any of the utility lines.

Example 2

UTIX? 165

returns

UTIX 165,65534

In this example the first 16 utility lines of block 165 were either set to FFFEh by UTOT or they were set to FFFFh and an external device has pulled down line 00, or both occurrences have taken place.
