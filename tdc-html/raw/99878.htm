Opening the Testflow Tool

Before you begin

Make sure that the 93000 Setup perspective is opened.

The 93000 Setup perspective includes the Test Program Explorer view where you can open the Testflow Tool.

Procedure

  • To open the Testflow Tool, in the Test Program Explorer view, double-click the testflow item.

    If you select the Open recent editor option when you configure the Testflow Tool, the most recently closed editor (the Flow Data Editor or the Flow Sequence Editor) and the Properties view are opened.

    If you select the Open integrated testflow tool option, the Flow Data Editor, the Flow Sequence Editor and the Properties view are opened.

  • If you only want to open the Flow Data Editor or the Flow Sequence Editor, you can right click the testflow item in the Test Program Explorer view and select Open With > Flow Sequence Editor or Open With > Flow Data Editor.

Results

The Testflow Tool has been opened.

When you open a testflow and the option Check UTM test method library version when opening testflow editor is enabled, the testflow tool will check whether the test method library used in the testflow is built on the version of SmarTest you are currently using. If not, a warning message will be displayed.
