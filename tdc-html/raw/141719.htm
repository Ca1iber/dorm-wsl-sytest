Topic 141719

regNum()

Specifies the number of registers to read.

Syntax

regNum(int iRegNr);
List of parameters

Parameter

Description

iRegNr

The register number to read

Example

rdi.protocol("id1").pname("prt").regNum(3).read(0x01).execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
