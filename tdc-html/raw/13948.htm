Topic 13948

Creating a "One-Shot" softscope

This topic describes how to display all output waveforms of a dedicated number of cycles in one screen.

Procedure

  1. Choose Display > Scope Size.

    This automatically sets the timing diagram to double-size with the additional softscope controls (see later) at the bottom left of the screen.

    Note The current display mode is saved automatically when you close the Timing Diagram window. That means, if the Timing Diagram window is closed in scope size, the window will be set to scope size when it is re-opened.
  2. Scroll to the cycles you want to examine. If necessary, reduce the number of cycles being displayed using the Cycles edit box so that just the cycles you need to examine are in the display.
  3. Click Scope at the bottom left of the screen.

    The softscope function will build up all output waveforms in the display.
