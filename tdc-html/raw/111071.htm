Topic 111071

TestheadTemperature

This test method reads the temperature card types from the test head.

The temperature is read in degrees Kelvin and then converted to the selected unit.

Note It is only available for universal test method.
Parameters
Parameter Type Description
boardType STRING

The type of the card. It can be:

  • DIGIO: Digital IO card (include DC Scale cards)
  • CLK: Clock board
  • ALL: Just return the highest temperature of all of these types of cards.
boardID INT

The parameter defines

  • the card number (or pogo block number) of the logical channel board (three digits)
  • or the clock board number (11, 12, 21, 22, ..., 41, 42),
  • or an identification number of the DPS card (101 to 108).
unit STRING

The temperature unit. It can be:

  • K for degree Kelvin
  • C for degree Celsius
  • F for degree Fahrenheit
