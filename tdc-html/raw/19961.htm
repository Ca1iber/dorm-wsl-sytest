Setting up the Levels

Levels for digital capture pins can be defined in the same way as for standard digital output pins. This is done in the Level Setup.

When capturing digital data, for example, to obtain the generated output codes of an ADC, typically not the quality of the output signal levels is of interest (these would be tested with other tests), but only whether a 1 or a 0 is received. Thus, a comparison with a single threshold level is sufficient to determine the capture result (1 or 0).

Therefore, for digital capturing, the high level threshold and the low level threshold should always be set to the same value in the middle between the high output level and the low output level of the capture pins.
