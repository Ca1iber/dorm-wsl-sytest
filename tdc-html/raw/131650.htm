SHARING_CONFIGURATION.utilityActionExecute()

The utilityActionExecute() member function of SHARING_CONFIGURATION executes the settings of the specified utility control line indicated by its location in the utility_control block.

Syntax

int utilityActionExecute(int index) const

Parameter

Description

index

The location of a utility control line within the utility_control block in the Sharing configuration file.

0 represents the first line.

Related information

SHARING_CONFIGURATION

Functional changes
