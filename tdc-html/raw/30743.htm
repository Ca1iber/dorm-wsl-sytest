Topic 30743

DOWNLOAD_INTERFACE_DATA

Subtopics

  1. Associated Syntax Entities

This expression downloads the calibration data for a specific interface (for example, a DUT board, or a DUT board with its cable assembly) to the tester. The parameter used with DOWNLOAD_INTERFACE_DATA points to a file in the directory, <device_path>/chan_attributes/. This file contains the interface data. For example, the line,

DOWNLOAD_INTERFACE_DATA (my_DUT_board);

downloads the values in the file <device_directory>/chan_attributes/my_DUT_board to the tester.
