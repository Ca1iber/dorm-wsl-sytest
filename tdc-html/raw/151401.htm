Topic 151401

Tool for Baseband IQ calibration when you have shared AWG/DGT resources to different sites

Yun Dai, Advantest Asia COE

Paper ID: 151401 June 2016

Abstract

In massive sites' application, we may nedd to share a AWG or DGT for different sites to test devices in semi-parallel. Standard Baseband IQ calibration is not able handle this semi-parallel sharing resource case. This application note will introduce a script which is designed for the above mentioned shared resource case.

Key Words

Baseband IQ calibration, Shared Resource, Script

Introduction

In some applications you need to do a baseband IQ calibration and use the calibration data file in your program. Because of the limited hardware resource users may share the AWG or DGT resource to different sites. For example users can share the AWG/DGT from site 1 and site 3 to site 2 and site4. In the above case, the standard baseband IQ calibration will only do the calibration once for site 1 and site 3, and does not care you shared the same resource to sites 2 and 4. In this situation, SMT will report an error when you run site 2 and site 4. The error message is similar to the below.

ERROR: ACMD "SRCA" - No specified Baseband IQ CAL data is measured or downloaded.
BBIQ Calibration file load failed. Exiting test program...

The script mentioned in this application note is defined to handle this kind of case. It will create a new calibration data file and will not overwrite the original. First step is moving the original calibration file to ".original" before calling the script. The new calibration file name should be the same as the condition file name. Meanwhile the condition file time stamp should be earlier than the calibration file.

The difference between the original and new calibration data file is that data is duplicated for all shared sites.

User Procedure

The tool name is "expand_bbiq_data" and is attached here.

Usage is as below:

expand_bbiq_data.pl <pinconfig> <calfile.original> <outfile>

pinconfig: current pin configuration file

calfile_original: original calibration file which is got from normal baseband IQ calibration.

outfile: output file, the file name should be same with your condition file.

  1. Follow TDC topic 93100 to get calibration file, no need to care pin sharing at this step.
  2. If there is sharing AWG/DGT pin used, use the attached script to convert the calibration file. Please copy the script into your device dir.
  3. Write code in Test Method to call the script. Pseudocode is for your reference. 
     if(!CollectBBIQFile)
 {
     if(perlFirstRun)
     {
          //file_name path is /var/opt/hp93000/soc/calibration/mc/<device>/<pinconfig>_<analog>/<file name> 
          //above file is got in standard BBIQ calibration procedure 
              
          STRING perlCpCalFile = "cp /var/opt/hp93000/soc/calibration/mc/<device>/<pinconfig>_<analog>/<file name> 
          /var/opt/hp93000/soc/calibration/mc/<device>/<pinconfig>_<analog>/<file name.original>"; 
          int cpStatus = system (perlCpCalFile);
              
          //creat "script" folder in your device dir, then put the expand_bbiq_data.pl into this folder 
          //please add full path of pingconfig and file_name 
     
          STRING perlCommand =  "../script/perl expand_bbiq_data.pl <pinconfig>  <file_name.original>  <file_name>";
          int perlStatus = system (perlCommond.c_str());     
          if(perlStatus == 0)
          {
              cout<<" BB IQ Calibration files for sharing resource generated."<<endl;
              perlFirstRun = 0;
          }
          else
          {
              cout<<"Script Running ERROR!!!"<<endl;
          }
     }
     BCAL.loadCalData(file_name);
}

The perl script will only be called one time during testflow first run, where pinconfig, calfile.original and outfile should be given with full path.
