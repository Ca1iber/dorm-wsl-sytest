Topic 354169

XPS256 operating modes

Subtopics

  1. XPS256 in DPS operating mode
  2. XPS256 in PMU operating mode

The XPS256 channels feature the PMU operating mode and the DPS operating mode.

The XPS256 operating mode is defined by the pin type that has been selected in the Pin setting editors. The operating mode can be set individually for each channel of the card. The combination of the operating mode and the selected connection state defines the characteristics, the dynamic behavior, and the basic programming mode of the channels.

PMU operating mode

An XPS256 channel is configured for the PMU operating mode if the channel is defined as DC Scale pin using the Digital Pins editor. In PMU operating mode, the channel is used like a standard PMU to temporarily supply power during the execution of a single test suite or a group of test suites. An XPS256 channel in PMU operating mode is programmed using test methods and APIs. The connection state is set by additional parameters in the level setup or by APIs.

DPS operating mode

An XPS256 channel is configured to operate in DPS mode if it is defined as a device power supply using the DPS Pins editor. In DPS mode, the channel is normally used to supply devices with power during the execution of a testflow. An XPS256 channel in DPS operating mode takes part in the standard connect and disconnect sequences and is programmed using DPS primary sets.
