Function: ph_stepmode_start

Sometimes it is necessary to slow down all driver operations, for example, when testing a new application model, or when analyzing a malfunction of the equipment.

This parameter sets the driver to the single step mode. In single step mode the operator is prompted for confirmation at each call from the application model to the handler driver.

Applicable for: handler and prober driver

Example: PROB_HND_CALL (ph_stepmode_start)
