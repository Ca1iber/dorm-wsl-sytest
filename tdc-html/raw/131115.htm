Clock domain per pin

The Smart Scale generation digital cards (PS1600 and PS9G) provide independent clock domains per pin. This enables each pin to run independently on its own period, at any data rate, in any clock domain, or in any phase.

The advantages are

  • Unconstrained routing on the DUT board
  • Concurrent testing of all interfaces at their native data-rates
  • Optimized tester resource utilization with per pin granularity

To set up independent clock domains per pin, you put the respective pins into ports (a port can contain only one pin if desired) and use a multiport setup. For details see Period resolution for multiport setups and CLKR, CLKR? - (CLocK Resolution).
