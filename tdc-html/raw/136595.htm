Topic 136595

Histogram view

Subtopics

  1. Histogram properties

The histogram visualizes how the different tested devices are distributed among categories of test measurements. You can also compare different histograms.

A histogram view is opened by choosing Show In > Histogram Chart from the shortcut menu of a Test summary tab. It can also be opened using the New button (see below) from the toolbar of another histogram view or using the Window > Show View > Histogram Chart menu command.

Note When the histogram is configured in the preferences to show bars (instead of columns, as displayed above), the frequency axes, the columns, the mean and sigma lines, and the limits are horizontal. The value axis is vertical.

These are the elements in the main area of the chart (for the toolbar and shortcut menu, see below):

  • Title: By default, the name of the test being displayed and its number in parentheses. You can edit this label in the chart properties.
  • Subtitle: By default, the grouping in effect, if any. You can edit this label in the chart properties.
  • Toolbar: The action buttons of the chart. See the Toolbar section, below, for details.
  • Frequency axes: The axis for the fraction of tested devices in each range of measured values. The axis on the left displays the percentage, the axis on the right the number of tested devices.
  • Frequency axis labels: By default, these labels are "Percentage" and "Count". You can edit them in the chart properties.
  • Value axis: The categories of measured values. You can specify the axis range and number of categories in the chart properties.
  • Value axis label: By default, this is the unit of the measured values. You can edit this label in the chart properties.
  • Columns: Each bar is a visual indicator for the number of devices for which a value in a particular category has been measured. (The category is defined by the two numbers to the left and the right of the bar on the value axis.)

    Columns that lie completely in the limits are indicated by diagonal lines: .

    In the preferences, you can choose to display the count and/or percentage on each column.

  • Mean line: This line indicates the mean measured value. You can configure the display of the line in the preferences.
  • 2-sigma line: These lines indicate the values which deviate by two standard deviations from the mean. You can configure the display of the line in the preferences.
  • 3-sigma line: These lines indicate the values which deviate by three standard deviations from the mean. You can configure the display of the line in the preferences.
  • Limits: These zones indicate areas outside the specified test limits.
  • Legend: A description of the individual test series that are displayed. You can configure the display of the legend in the preferences.

You can zoom in on the chart by drawing a rectangle around the area you want to enlarge (in addition to using the Zoom In button described below). You can reset the zoom level to its default by double-clicking anywhere in the chart area.

Toolbar

The toolbar of a histogram view includes these buttons:

  • Link: Links the display in the view to the selected row in the data navigation view.

    In this mode, if the selection in the data navigation view changes, the display updates automatically.

  • Pin: Freezes the display in the view.

    In this mode, the view keeps displaying the rows it currently displays, even when the selection in the data navigation view changes. Dynamic updating can be resumed by clicking the Link button.

  • New: Creates a new histogram view.
  • Zoom In: Enlarges a section of the chart to show more detail.
  • Zoom Out: Reduces the scale of the chart to show more data.
  • Double Bin: Makes each data category represented by a column half as wide. (That is, it doubles the number of data categories.)

    This button is unavailable if the number of categories would get too large.

  • Half Bin: Makes each data category represented by a column twice as wide. (That is, it halves the number of data categories.)
  • This button is unavailable if only one data category is displayed.
  • Properties: Opens the Histogram Properties dialog.
  • Statistics: Displays the data that underly the graph. The information categories are the same as the columns in test summary tabs. Clicking the button again hides the values and displays the chart.
  • Image: Clicking this buttons lets you save the current chart display as a PNG or JPEG image.
  • Switch Legend: Switches the position of the legend between the bottom and the right side of the chart.

Shortcut menu

The shortcut menu of a histogram view contains these commands:

  • Zoom In: Enlarges a section of the chart to show more detail.
  • Zoom Out: Reduces the scale of the chart to show more data.
  • Value Axis: The commands in this submenu let you set the range of the value axis:
    • Min/Max: The axis begins with the smallest measured value and ends with the largest measured value.
    • Limits: The axis begins with a value slightly below the lower limit and ends with a value slightly above the upper limit. (This is the default setting.)
    • 3 Sigma: The value axis begins with a value slightly below the lower 3-sigma line and ends with a value slightly above the upper 3-sigma line.
    • 2 Sigma: The value axis begins with a value slightly below the lower 2-sigma line and ends with a value slightly above the upper 2-sigma line.
    • Double: The range of the axis around its midpoint is doubled.
    • Half: The range of the axis around its midpoint is halved.
  • Frequency Axis: The commands in this submenu let you set the range of the frequency axis:
    • Auto: Scales the axis so that all data points are displayed. (This is the default setting.)
    • Double: The range of the axis around its midpoint is doubled.
    • Half: The range of the axis around its midpoint is halved.
  • Bin Count: The commands in this submenu let you specify how many data categories ("bins") there are on the value axis:
    • 30: The axis is divided into 30 categories.
    • 20: The axis is divided into 20 categories. (This is the default.)
    • 10: The axis is divided into 10 categories.
    • Double: The number of categories is doubled. (This is the same as the Double Bin toolbar button.)
    • Half: The number of categories is halved. (This is the same as the Half Bin toolbar button.)

      You can also set the bin count in the chart properties.

  • Restore Defaults: Resets the zoom level, axis settings, and data category ("bin") specifications to their defaults.
  • Properties: Opens the Histogram Properties dialog.
