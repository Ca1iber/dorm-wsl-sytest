Functional Test Record (FTR)

Function

The Functional Test Record contains the results of the single execution of a functional test in the test program. The first occurrence of this record also establishes the default values for all semi-static information about the test. The FTR is related to the TSR by test number, head number, and site number.

There is one FTR record for each failing vector in a test. CYCL_CNT specifies the first failing cycle and REL_VADR the first failing vector.

In multiport testing, a separate FTR is created for each port by default. To create a summary FTR for all ports instead, use the combineMultiPortTests member function of the TESTSET class.

Location in the file

The Functional Test Record can appear anywhere in the data stream after the corresponding PIR, and before the corresponding PRR.

HEAD_NUM
  • Test head number
  • One-byte unsigned integer
  • Value = 1

    If the ATR and GDR indicate that there are more than 255 sites in the test, HEAD_NUM is the number of the site divided by 256. For example, in a record for site 384, HEAD_NUM would be 2.

    For tests with more than 255 sites: derived from SiteID

SITE_NUM
  • Test site number
  • One-byte unsigned integer

    If the ATR and GDR indicate that there are more than 255 sites in the test, SITE_NUM is the number of the site modulo 256. For example, in a record for site 600, SITE_NUM would be 88.

    TestFlowStartEventType

  • EDL Attribute:

RTN_ICNT
  • Count of return data PMR indexes
  • Two-byte unsigned integer
  • The size of the RTN_INDX array is determined by the value of RTN_ICNT.
  • The indexes referred to in RTN_INDX are those defined in the PMR.
  • This field may be omitted if all data following them is missing or invalid.
  • EDL Event:

    PinPFResult

PGM_ICNT
  • Count of programmed state indexes
  • Two-byte unsigned integer
  • Determines size of PGM_INDX and PGM_STAT arrays.
  • Calculated value

RTN_INDX
  • Array of returned data PMR indexes
  • Two-byte unsigned integer
  • RTN_ICNT = 0 if test passes

  • EDL Event:

    PinPFResult

  • EDL Attribute:

    Pin + ":" + CurrentSite

RTN_STAT
  • Array of returned states
  • Unsigned integer data stored in a nibble (4 bits of a byte)
  • Size of array determined by RTN_ICNT
  • Calculated value

PGM_INDX
  • Array of programmed state indexes
  • Two-byte unsigned integer
  • Size of array determined by PGM_ICNT
  • Calculated value

PGM_STAT
  • Array of programmed states
  • Unsigned integer data stored in a nibble (4 bits of a byte)
  • Size of array determined by PGM_ICNT
  • Calculated value

FAIL_PIN
  • Failing pin bit field
  • Variable length bit-encoded field (maximum 65,535 bits)
  • First two bytes are unsigned count of bits to follow
  • Each bit represents the pass/fail state of a pin from the PMR record: 0 = pass, 1 = fail.
  • The bit for pin 0 from the PMR is the least-significant bit in the third byte (the byte after the length bytes); the bit for pin 7 is the most-significant bit in the third byte; the bit for pin 8 is the least-significant bit in the fourth byte; and so on:
  • Unused bits at the high order end of the last byte must be 0.
  • Length bytes = 0 if missing or invalid data
  • EDL Event:

    PinPFResult

  • EDL Attribute:

    failed pins

  • Variable length character string
  • First byte = unsigned count of bytes to follow
  • Maximum 255 bytes

    TestFunctionStartEventType

  • EDL Attribute:

    VectorLabelAttrType
