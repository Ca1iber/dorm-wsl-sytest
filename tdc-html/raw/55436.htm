APIs for executing concurrent tests

Subtopics

  1. Properties of the DIGITAL_CAPTURE_TEST API function
  2. Properties of the NB_DIGITAL_CAPTURE_START and NB_DIGITAL_CAPTURE_END API function
  3. Properties of the START_TEST API function
  4. Properties of the FUNCTIONAL_TEST API function

Only certain API functions can be used to execute concurrent test. The choice of execution APIs depends on the types of tests necessary for the device ports. The following API functions can be used to execute concurrent tests:

  • DIGITAL_CAPTURE_TEST
  • NB_DIGITAL_CAPTURE_START and NB_DIGITAL_CAPTURE_END
  • START_TEST
  • FUNCTIONAL_TEST

Functional changes

  1. Introduced before SmarTest 6.3.2
