Topic 97563

DPS_POWER_STATUS

Subtopics

  1. DPS_POWER_PIN_STATUS

This class enables you to connect or disconnect one or more power supply pins and query the connection status of a power supply pin.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/DpsPowerStatus.h.

Constructor

DPS_POWER_STATUS();

This constructs an object of DPS_POWER_STATUS class. It allows you to connect or disconnect specified power pins, connect or disconnect all power pins, and retrieve the connect status of a single pin.

Member functions

pin()

DPS_POWER_PIN_STATUS& pin(const STRING &pinlist);

This function specify the pin list to connect/disconnect or the single pin of the focus site to retrieve the connection status.

Note A call to this function must be followed by calls to member functions of DPS_POWER_PIN_STATUS class. You cannot call other DPS_POWER_STATUS member functions after calling pin().
Parameter

pinlist

The pin list to work with.

on()

void on();

This function connects all the power supply pins for all enable sites.

off()

Void off();

This function disconnects all the power supply pins for all enable sites.

Example

DPS_POWER_STATUS().pin("@").off();
DPS_POWER_STATUS().pin("dps1").on();
bool dpsStatus = DPS_POWER_STATUS().pin("dps1").isOn();
DPS_POWER_STATUS().on();

In this example

  • The first line disconnects all power supply pins for all enable sites.
  • The second line connects pin dps1 for all enable sites.
  • The third line checks whether pin dsp1 is connected and puts the value in the variable dpsStatus.
  • The fourth line connects all the power supply pins for all enable sites.
