Topic 126128

Editing protocol specific timing

About this task

This task describes how to create or modify protocol specific timing segments.

Note This task is optional and only needed if you do not specify the protocol relevant timing in the device timing equations already.
Note The timings you define here will be saved with the protocol definition. Thus they will be available if the protocol is imported to a new device.

Before you begin

Utilizing port-based setups is not required. However, it is recommended that it is utilized to simplify the leverage and reuse of protocol setups.

Procedure

  1. Open the Timing Segments view by clicking on the Timing tab of the protocol editor.
  2. Click New to create a new timing segment.
  3. Enter the name of the new timing segment and click OK.
  4. Select the timing segment and click into the content space to enter new or modify protocol timing specifications.
    Note The syntax is equivalent to the one used with equation based timing.
    Note Use pin roles only to define protocol specific timing here.
  5. Save your modifications by pressing the CTRL + S key combination simultaneously.

Results

You have defined protocol specific timing settings for your pin roles.

What to do next

In order to use these timing settings you have to add the line USE_PROTOCOL "<protocolName:<timingSegmentName>" [<portList>] to your device level file.
