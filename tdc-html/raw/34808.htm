DRLExpressionAttr

A variable of this type holds the data to be printed to the data log, as specified in a 'Print To Datalog' testflow element.

The member type specifies whether the expression given in the "Print to Datalog" testflow element is a string, or an (arithmetic) expression which represents a value. Accordingly, type can be one of the values DRLStringExpression or DRLValueExpression.

The member expression holds the actual expression.

The member value holds the result of the evaluation of the expression, in case type is DRLValueExpression.

typedef struct _DRLExpressionAttr {
  enum {DRLStringExpression, DRLValueExpression} type;
  char *expression;
  double value;
} DRLExpressionAttr;

Functional changes
