Topic 103807

Cyclic redundancy checks

Subtopics

  1. Setting up cyclic redundancy checks

Cyclic redundancy checks (CRCs) are used to verify the data integrity of data streams.

MTL supports both inline CRCs and CRCs on pins external to the data stream.

CRC settings are defined in the Device architecture file. There is a switch in the APG pattern file to choose a setting or disable CRC.

To use cyclic redundancy check results in device accesses, use the crc macro in the :operation: column and provide the desired CRC configuration from the active CRC settings as an argument.
