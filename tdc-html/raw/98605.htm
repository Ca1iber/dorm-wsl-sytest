FLBL? - (Failing LaBeLs)

If the last test was executed with the overview Error Map in LMAP mode, which implies that the start label was a (single-port or multi-port) burst, then the FLBL? query returns information about the failing labels of the burst within a certain cycle range for a specified port. This information can include the number of the first failing cycle. If this is requested, separate cycle information is returned for every failing pin of the port.

If the last test was not executed in LMAP mode, FLBL? issues an error message.

Note If you use the LMAP error map mode, FLBL ignores the RETC clearing flag for failures.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

FLBL? {cycle_info},[start_cycle]},[no_of_cycles],{(port)}

returns: 

FLBL {index_of_call},{label_name},{cycle_info}, [ffc_abs],[ffc_rel],[ffv], {(pinlist)}

Parameters

cycle_info

This parameter specifies which information is to be retrieved about the first failing cycle of the labels. Possible values are:.

 

AFFC

Returns the first failing cycle relative to the start of the burst.

 

RFFC

Returns the first failing cycle relative to the start of the label.

 

FFCS

Both numbers, relative to the start of the burst and relative to the start of the label, are returned.

 

FFV

Returns the first failing vector and the first failing cycle relative to the start of the label.

 

ALL

Returns the first failing cycle relative to the start of the burst and relative to the start of the label, and the first failing vector relative to the start of the label

 

NONE

No information about first failing cycles is provided.

index_of_call

This reply parameter specifies the index of the call for which the label name is returned.

label_name

This reply parameter specifies the name of the label that was called at the position index_of_call.

start_cycle

This reply parameter specifies the start cycle of the label within the burst. It is omitted if reconstruction of the label is not possible.

no_of_cycles

This reply parameter specifies the number of cycles of the label. It is omitted in the reply if reconstruction of the label is not possible.

If it is omitted in the query, the reply depends on the value for start_cycle:

  • If both start_cycle and no_of_cycles are omitted, FLBL? returns information about the complete test.
  • If no_of_cycles is omitted, but start_cycle is not, FLBL? returns information about the start cycle.

If you want to get information about an end segment of the test, simply specify a number which is certainly greater than the size of the end segment.

port

Specifies the port for which label information is requested. The port is also returned in the reply if cycle_info is set to NONE.

ffc_abs

The first failing cycle relative to the start of the burst.

There are two special return values:

 

-1

The label contains errors, but recording started too late.

 

-2

The label contains errors, but the detailed error map is already full.

ffc_rel

The first failing cycle relative to the start of the label.

ffv

The first failing vector relative to the start of the label.

pinlist

This reply parameter specifies the pins of the port which fail for the first time in the same cycle within the specified label. A pinlist is returned if cycle_info is not NONE.

Example

> FLBL? ALL,0,105,(@)
< FLBL 1,"MainFailures",ALL,26,10,10,(Read)
< FLBL 1,"MainFailures",ALL,25,9,9,(Write,RowAS)
< FLBL 1,"MainFailures",ALL,20,4,4,(Addr3)
< FLBL 1,"MainFailures",ALL,23,7,7,(Data0,Data1,Data2,Data3)
< FLBL 3,"MainRowAsFail",ALL,82,18,6,(RowAS)
< FLBL 4,"MainWriteFail",ALL,92,4,4,(Write)
< FLBL 5,"MainFailures",ALL,114,10,10,(Read)
< FLBL 5,"MainFailures",ALL,113,9,9,(Write,RowAS)
< FLBL 5,"MainFailures\",ALL,108,4,4,(Addr3)

This example returns all available information for a single-port burst from cycle 0 through 104. The first two replies for the first call of label MainFailures are to be read as follows: Pin Read fails at cycle 26, counted from the start of the burst, which is 10 counted from the start of the label. The pins Write and RoWAS already fail at cycle 25, respectively 9.

Note that the fifth call is included in the reply although none of its failing cycles is inside the requested cycle range. Every failing label which has at least one cycle in the specified range is reported.

Functional changes

  1. Introduced before SmarTest 6.3.2
