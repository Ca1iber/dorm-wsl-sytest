Working with TMLimits

Subtopics

  1. Creating TMLimits test tables
  2. Editing TMLimits test tables
  3. Creating a TMLimits master file
  4. Editing a TMLimits master file
  5. Using TMLimits test tables
  6. TMLimits backwards compatibility

TMLimits is a high-level implementation of test tables that can be accessed both through the SmarTest Work Center and programmatically through test methods.

Working with TMLimits is described in:

  • Creating TMLimits test tables
  • Creating a TMLimits master file
  • Editing TMLimits test tables
  • Editing a TMLimits master file
  • Using TMLimits test tables
  • TMLimits backwards compatibility
    Note For information on working with test tables other than TMLimits, see Working with test tables. We recommend that you use TMLimits unless you have specific requirements that TMLimits does not meet.
