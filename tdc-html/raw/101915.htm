The MTL compiler transfers a source file into an executable vector pattern. The details of this compilation process and the interplay of the pattern and the device are determined by a number of configuration files that the compiler accesses. These files are listed in the APG pattern file.

This chapter describes all mandatory and optional input files for the MTL compiler:
