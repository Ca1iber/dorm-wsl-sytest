EVENT_FILTER.getLoadStepValue()

Queries the load step value set by EVENT_FILTER.setLoadStepValue().

Syntax

void getLoadStepValue(TM::LOADSTEP_VALUE &value) const;
Parameter
List of parameters
Parameter Description
value

The load step mode value that has been set by EVENT_FILTER.setLoadStepValue().
Return value
There is no return value.

Related information

EVENT_FILTER.setLoadStepValue()

Functional changes

  1. Introduced in SmarTest 7.10.3
