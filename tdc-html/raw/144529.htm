EVENT_IC_HAC.iClampHigh()

Sets the high clamp current value.

You can specify either the high or the low clamp current value.

EVENT_IC_HAC functions are supported in PMU operating mode (pin type SIG) on DC Scale DPS28/64 cards only. They are not supported in DPS mode (pin type DPS+).

Syntax

EVENT_IC_HAC & iClampHigh ( const EVENT_VALUE_DOUBLE & value );
Parameter
Parameter Description
value

High clamp current

Return value

There is no return value.

Example

For an example see EVENT_IC_HAC.
