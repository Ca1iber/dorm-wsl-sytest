DIGITAL_OFFSET_SEARCH_RESULT_PINS.setResultPin()

Defines the result pins for the setup pins specified with DIGITAL_OFFSET_SEARCH_TASK.resultPin().

The results pins and the setup pins must be in the same physical test processor. Otherwise, an exception will be thrown.

The result pins are the pins to return pass/fail test results.

After you set up result pins with this function, you must inform the tester with DIGITAL_OFFSET_SEARCH_TASK.setup().

Syntax

void setResultPin(const STRING& resultPin);
Parameter

Parameter

Description

resultPin

The pins to return pass/fail test result.

To reset the result pins to the default pins, use the following syntax:

void setResultPin();

Return value

There is no return value.

Example

Refer to the examples in DIGITAL_OFFSET_SEARCH_TASK.resultPin().
