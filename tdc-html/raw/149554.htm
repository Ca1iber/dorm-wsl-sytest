Topic 149554

instruction()

This function inserts MACT and MRPT instructions in a pattern which is generated by the smartVec() class.

Syntax

instruction(string instruct, int vecPos);
List of parameters

Parameter

Description

instruct

An MACT X, MACT X CONTINUE, or MRPT X instruction to be inserted.

"X" presents an integer number for the loop repetitions.

vecPos

The starting vector position from which MACT or MRPT to be inserted.

Example

rdi.smartVec().pin("DATA1")
    .writePat("X,X,H,L,H,L",8)
    .defaultVec("X")
    .vecLength(20)
    .instruction("MACT 6",8) 
    .instruction("MRPT 6",14)
    .execute();

With a CONTINUE option for the MACT instruction, the sequencer program continues even if the match loop has failed: 

rdi.smartVec().pin("DATA1")
    .writePat("X,X,H,L,H,L",8)
    .instruction("MACT 6 CONTINUE",8)
    .instruction("MRPT 6",14)
    .execute();
