failCount()

This function returns the number of failed cycles within a specified cycle range.

Syntax

The Vector class there is no return value.

failCount(int startCyc,int cycRange)
failCount(int startCyc)  // From the start cycle to the end.
failCount()              // From the beginning to the end.
List of parameters

Parameter

Description

startCyc

The number of the first cycle in the cycle range in which the fails are counted. An integer. Cycle numbers are zero-based.

This is an optional parameter. If it is omitted, the cycle range starts with the first cycle.

cycRange

The number of the cycles in the cycle range in which the fails are counted. An integer. Cycle numbers are zero-based.

This is an optional parameter. If it is omitted, the cycle range ends with the last cycle.
Note
  • The fail count and fail position are about "compare edge" (not tester cycle). So they supports xMode directly.
  • The xMode parameter for a pin must be correct, otherwise the result for the pin will not be correct.
  • The parameter specified in the function, such as startCyc and cycRange, is about user cycles (edge), not tester cycles. This setting is critical when xMode is set to be greater than 1.
  • For one pin, xMode must remain the same in different labels in burst; otherwise the results might be wrong.

Example

rdi.emap("a").label("label1").pin("pA").failCount().pfMap().pin("pC").failCyc(5).execute();
