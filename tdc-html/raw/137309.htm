Topic 137309

Histogram preferences

Value as count: Whether the test count is displayed on each bar or column

Value as percentage: Whether the test percentage is displayed on each bar or column

Mean: Whether a line (- - - - -) indicates the mean of the values in the histogram

2 Sigma: Whether lines (— - — - —) indicate two standard deviations from the mean

3 Sigma: Whether lines (— - - — - - —) indicate three standard deviations from the mean

Axes: Whether test counts are displayed as horizontal bars or vertical columns

Show legend: If this option is checked, a legend is displayed beside the chart.
