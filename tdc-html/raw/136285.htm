Topic 136285

Loading and unloading data log files

STDF and EDL data log files are loaded and unloaded using toolbar buttons or context menu commands in the Data Log Explorer.

About this task

Load data log files to be able to open them for statistical analysis or combine them by merging or correlating them with other logs.

Unload data logs to free up the memory that they use.

Note This procedure does not apply to the system data log stream, which is always automatically loaded and cannot be unloaded.

Before you begin

Open the Integrated Result Tool.

Procedures

Loading a data log file

  1. In the Data Log Explorer, click the Load button .

    You can also right-click anywhere in the view and choose Load.

    A standard Eclipse file selection dialog opens.

  2. Select one or more STDF or EDL files and click OK.

Each selected file is opened in a data navigation view.

Unloading one or more data log files

  1. In the Data Log Explorer, select all files you want to unload.

    Shift-click or control-click to select multiple files.

  2. Right-click any of the selected files and choose Unload.

The selected files are unloaded. If any Data navigation views are open for these files, they are closed.

Unloading all loaded data log files

In the Data Log Explorer, perform either of these actions:

  • Click the Unload All button .
  • Right-click anywhere and choose Unload All.

All data log files (but not the system data log stream) are unloaded. If any Data navigation views are open for these logs, they are closed.

Results

The Data Log Explorer contains all files you have loaded and no files you have unloaded. (It also contains the system data log stream.)

What to do next

Open a loaded log to examine it or merge or correlate logs to open and examine the resulting combined log.
