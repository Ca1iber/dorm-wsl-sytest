GET_CURRENT_BIN_INFORMATION

This API retrieves the bin information of a device. It can only be used in the test method for special test suite bin_disconnect.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

void GET_CURRENT_BIN_INFORMATION (INT* hwBinNumber, STRING &hwBinDescription, 
                                  STRING &swBinNumber, STRING &swBinDescription,
                                  INT* goodBin, INT* reprobe, INT* overon, INT* otherwiseBin);
Parameters

I/O

Parameter

Description

O

hwBinNumber

Hardware bin number.

O

hwBinDescription

Hardware bin description.

O

swBinNumber

Software bin number.

O

swBinDescription

Software bin description.

O

goodBin

Good bin or not. 0 means bad bin and 1 means good bin.

O

reprobe

Reprobe or not. 0 means Do not reprobe and 1 means reprobe.

O

overon

Overon or not. 0 means overon disabled and 1 means overon enabled.

O

otherwiseBin

whether this is an otherwise bin. 0 means this is not an otherwise bin and 1 means this is an otherwise bin.

Example

int hwBinNumber, goodBin, reprobe, overon, otherwiseBin;
string hwBinDescription,swBinNumber,swBinDescription;
GET_CURRENT_BIN_INFORMATION (&hwBinNumber, hwBinDescription,swBinNumber, swBinDescription,
                      &goodBin, &reprobe, &overon, &otherwiseBin);
