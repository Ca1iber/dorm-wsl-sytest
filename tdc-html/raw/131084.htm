Topic 131084

init()

Initializes the resampler.

Syntax

void init(DOUBLE inputSampleRate, DOUBLE outputSampleRate, ResamplerType type = CIRCULAR_RESAMPLER);
Parameters

I/O

Parameter

Notes

Type

I

inputSampleRate

Input sample rate in Hz

DOUBLE

I

outputSampleRate

Output sample rate in Hz

DOUBLE

I

type

Type of resampler. Possible values:

  • CIRCULAR_RESAMPLER (default)
  • WINDOW_RESAMPLER

ResamplerType

Example

RESAMPLER myResampl;

myResampl.init(1e6, 2e6, WINDOW_RESAMPLER);

Related information

RESAMPLER

Functional changes

  1. Introduced in SmarTest 7.1.4
