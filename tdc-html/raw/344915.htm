returnDropMax()

Sets the maximum voltage drop on the return line. The pin gets automatically disconnected in case the voltage drop exceeds the programmed voltage.

The voltage drop is measured from the to theground sense pogo pin (GS#). The measured voltage drop depends on the actual current and the impedance of the connection to the DUT. The continuously measured voltage drop is compared against the programmed maximum voltage drop and a pin that exceeds the programmed limit is disconnected.

This member function is supported only for the DC Scale XPS256 card in PMU operating mode.

The function can be used in the code‑based mode.

Syntax

dcBase& returnDropMax(double returnDrop);
Parameter
Parameter Description
returnDrop

The maximum voltage drop in Volts (V) to be set.

A positive voltage has to be set regardless of the polarity of the actual or programmed current.

Valid range and default value:
  • XPS256: Refer to Voltage drop protection / measurement in XPS256 other performance characteristics

    Default value: 50 mV
Return Value
A reference to the dcBase object.

Example

Maximum voltage drop of XPS256

rdi.dc().pin("...")
        .vForceRange    (7.0 V)
        .vForce         (5.0 V)
        .iForceRange    (1.0 A)
        .iClamp         (0.5 A)
        .forceDropMax   (300 mV)
        .returnDropMax  (100 mV)
        .execute();
