GetTesterInfo

This data query command gets the tester information including the IDs related to external instruments and test head.

SUCCESS is returned if the command is successfully issued. Otherwise an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

ILLEGAL_OPERATION
  • The designated session ID "XXX" is not online session ID.
  • The designated instrument ID "XXX" does not exist.

RECOVERABLE

Dependency

An online SmarTest session is running.

Parameters

I/O

Parameters

Description

I

SESSION_ID

The online session ID.

O

qrResults

The query results are represented by a ParamList object. It contains the following members:

TESTHEAD_ID: The V93000 test head ID. Currently it is always 1.

INSTRUMENT_ID_LIST: The ID list for all the installed external instruments.

Prototype

ParamList qrResults;
string sessionId;
Status query("GetTesterInfo", qrResults,  ParamList(), sessionId);

Example

string sid;
ParamList qrResults; 
Status retval = query("GetTesterInfo", qrResults, ParamList(), sid);
if ( retval == SUCCESS ) 
{
  vector<string> iidList = qrResults.valueArray("INSTRUMENT_ID_LIST");
  printf("the TESTHEAD_ID is %s\n", qrResults["TESTHEAD_ID"]);//always 1
  for (int i = 0; i < iidList.size(); i++)
  {
    printf("Instrument ID is %s\n", iidList[i]);
  }
}
