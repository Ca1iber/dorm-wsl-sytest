SmartRDI provides the class dc() and related functions to set up tests with PPMU.

Overview of dc() class functions for PPMU setups

API Description Mode
average() Specify a number of samples to do averaging. P, C
clamp() Specify a clamp current or voltage. P
clampOff() Set the clamp to OFF in the current test item. P
copyLabel() Specify to edit an existing pattern or copy and edit the pattern. P
enPassFail() Work together with getPassFail() to retrieve the pass/fail results of the pattern specified by label(). P
firstRunInLoop() Control the running of PPMU pattern setups and relays to be done only within the first iteration of loops. C
iClamp() Specify a clamp current value, low and high clamp values. P, C
iForce() Specify a current value to force. P, C
iMeas() Create a current measurement. P, C
insertSub() Insert subroutines with DC, PPMU or BADC actions to an existing pattern. P
iRange() Specify a range value to measure the current. The value is usually the possible maximum current. P, C
limit() Add a pair of limits for judging the pass/fail result of a dynamic DC measurement on digital pins or DC Scale pins. P
loadCap() Specify a load capacitance. P, C
measWait() Specify a period of time to wait between the previous event and measuring the value. P, C
pin() Specify pin(s) for the subsequent DC actions. P, C
postWait() Specify a period of time to wait after a action. P, C
relay() Specify relay actions before and after a PPMU measurement P, C
valueMode() Specify a method for measuring voltage or current on pins with PS1600 or PS9G cards. P; C for PS9G card
vForce() Specify a voltage to force. P, C
vMeas() Measure voltage on pin(s). P, C
getBurstValue() Retrieve all measurement results for a pin specified in the same RDI_BEGIN/RDI_END block. C
rdi.id().getMultiValue() Retrieve all the values measured on the specified pins. C
getValue() Retrieve the measure value from a pin. C

In the Mode column: C = Code-based, P = Pattern-based.

Example

ON_FIRST_INVOCATION_BEGIN();
  RDI_BEGIN();
    rdi.dc("id1").pin("PinA").vForce(0 V).valueMode(TA::BADC).iMeas().execute();
    rdi.dc("id2").pin("pinB").iForce(1 mA).vMeas().execute();
  RDI_END();
ON_FIRST_INVOCATION_END();

double res1=rdi.id("id1").getValue();
double res2=rdi.id("id2").getValue();
