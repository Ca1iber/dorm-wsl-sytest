Working with the multiport burst editor

The multiport burst editor is a multipage editor. It provides and Overview page, one page per port burst, and one page per sync group.

It has two display modes: expanded and collapsed. The expanded mode shows the timeline synchronization of port bursts per sync group and displays failure data. The collapsed mode does not show the synchronization of port bursts.

To collapse or expand the display, click . To activate the icon you must run the testflow.

Failing tests are marked on the sync group pages in the annotation ruler on the right. A failing port burst is highlighted in red. To go directly to a failed port burst, click the annotation marker on the sync group page.

In expanded mode, to generate the annotations for a marked line, click . Markers and annotations must be enabled (Window > Preferences > Advantest V93000 > Pattern Debug Tool).

The icon aligns the Overview page and the port burst pages with the display of other result analysis tools.

Right-click sync group pages to configure, select, or save an editor layout.
