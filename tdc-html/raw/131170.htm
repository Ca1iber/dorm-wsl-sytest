TMU_RESULTS.getPinsNotFinished()

Retrieves the pins which did not finish sampling.

Syntax

UINT32 getPinsNotFinished(STRING_VECTOR& pinvec, STRING& str, INT site)
Parameters

I/O

Parameter

Description

O

pinvec

A vector of string containing the pins that did not finish sampling.

O

str

A string containing the pins that did not finish sampling. The pins are separated by comma.

I

site

(optional) The site to retrieve. The default value is 0, representing all sites.

Return value

The number of pins that did not finish sampling is returned.

Functional changes

  1. Introduced in SmarTest 7.1.0
