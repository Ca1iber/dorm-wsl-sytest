Test Program 360 (TP360) is a GUI tool independent of SmarTest, designed to check the quality and performance of your test program. It provides various function modules for you to easily examine test programs in different scenarios and for different purposes.

These function modules and their aims are:

  • Test Time Utilities: Measures and compares test time of your test programs.
  • Executing the test program resource profiler: Collects the tester, system controller, and SmarTest information when releasing a test program.
  • Test Program Stability Checker: Checks programming risks (such as Hi-Z, hot-switching) in your test programs.
  • Test Program Browser: Generates summary reports for your test program setups and test methods.
  • Test Program Cleaner: Cleans the redundant files and setups in your test program.
  • Smart Correlation – Release Data Collector: Identifies and resolves correlation issues.
  • Smart Correlation – Release Checker: Performs setups and flow execution related checks for better release quality.
  • Smart Correlation - Datalog Utilities: Reports and compares data log files.
  • Test Program Comparator: Compares test programs for you.
  • Test Time Breakdown Analyzer: Calculates the breakdown time in your test suites.
  • TDR connectivity checker: Checks the connection status by measuring propagation delay on electrical trace lines.
