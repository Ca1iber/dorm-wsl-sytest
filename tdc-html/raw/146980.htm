Filtering license data

Filtering enables you to display only the license data that you want to see.

About this task

You can filter the data based on any combination of the following parameters:

  • customers
  • license server host IDs
  • order IDs
  • product descriptions
  • license expiration dates

Before you begin

All required files must be loaded and the Comparison Tool must have completed the comparison process.

Procedure

  1. Click Filter > Filter Using Product Descriptions.

    The filter dialog appears, displaying the included items on the left and the excluded items on the right.

  2. To exclude a parameter, select it and click >. To include a parameter, select it and click <.
  3. To exclude all parameters, click >>. To include all parameters, click <<.
  4. To complete the filtering and close the dialog, click OK.

Results

The selected filter parameters are applied and the Comparison Tool shows only the license data that you want to see.

The filtering parameters remain applied until you exit the tool or click Filter > No Filtering.
