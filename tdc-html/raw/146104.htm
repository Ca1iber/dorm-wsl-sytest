EVENT_WAVEFORM_VM.getOutOfRangeCheck()

Queries about the out-of-range check. Per default this check is on. If this check is enabled and the measurement range is exceeded, the event contributes with a FAIL to the global test result.

Syntax

void getOutOfRangeCheck(bool & failOnOutOfRange) const;
Parameter
Parameter Description
failOnOutOfRange

Possible values are: true | false

Return value

The setting of the failOnOutOfRange parameter.

Example

For an example, see EVENT_WAVEFORM_VM.

Related information

EVENT_WAVEFORM_VM

Functional changes

  1. Introduced in SmarTest 6.5.2
