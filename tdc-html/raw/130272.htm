Passing MTL arrays to functions and device accesses

MTL arrays can be passed to functions or device accesses through the function parameters, or the interface parameters of device accesses.

About this task

The purpose of passing MTL arrays either to subfunctions or to device accesses is to employ such functions or device accesses for programming patterns.

Before you begin

Define the MTL arrays.

Procedure

  1. For a called function or device access, add array parameters to the parameter list of the function, or the interface definition of the device access.

    The array parameters are made by names followed by the needed dimension sizes, such as dataArray[8][8]. The dimension sizes must be specified.

  2. When you call this function, or device access in another function, replace the array parameters by declared arrays.

    You can pass a full array by only providing the array name. You also can pass a partial array by specifying the original array name and the needed dimension sizes, such as fullArray[1][4].

    Note that the passed arrays sizes, no matter full arrays or partial arrays, must match the sizes of the called functions or device accesses' array parameters.

Example

:deviceAccess:
{
  # DBUS_WR8 - write access BL = 8
  :apgAccess:
  {
    :name:   DBUS_WR8
    :interface: { bData[BL] bSeq[BL] row col bank }
    :table:
    {
      :format:
      { :pin:   :states: :data: }
      { DQ.Data { 0 1 }  data(bData[bSeq[0]], row, col + bSeq[0], bank) }
      {   ""    { 0 1 }  data(bData[bSeq[1]], row, col + bSeq[1], bank) }
      {   ""    { 0 1 }  data(bData[bSeq[2]], row, col + bSeq[2], bank) }
      {   ""    { 0 1 }  data(bData[bSeq[3]], row, col + bSeq[3], bank) }
      {   ""    { 0 1 }  data(bData[bSeq[4]], row, col + bSeq[4], bank) }
      {   ""    { 0 1 }  data(bData[bSeq[5]], row, col + bSeq[5], bank) }
      {   ""    { 0 1 }  data(bData[bSeq[6]], row, col + bSeq[6], bank) }
      {   ""    { 0 1 }  data(bData[bSeq[7]], row, col + bSeq[7], bank) }
    }
  }
}
