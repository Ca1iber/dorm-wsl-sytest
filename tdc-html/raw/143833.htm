average()

Specifies the number of samples to do the averaging. The result of the measurement has been averaged.

Syntax

average(int iSample);
List of parameters

Parameter

Description

iSample

The number of samples

 

		
Example
rdi.dc("multi1").pin("DATA2",TA::SPMU).vMeas().average(20).execute();

	


Functional changes
  1. Introduced in SmartRDI 2.1.0
