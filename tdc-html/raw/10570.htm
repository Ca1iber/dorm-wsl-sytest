Topic 10570

Main labels

MAIN labels are all purpose labels. There are only three restrictions applying to them:

  • they can only be called from a BRST or MPBU label,
  • they cannot themselves call a BRST or MPBU label,
  • they can serve as the start label (SQSL command) only if they are defined for the default port.

Every MAIN label must start with an STVA and an STSA instruction. The STVA instruction points to the address in the vector areas, the STSA instruction must be present only for historical reasons. The end of a MAIN label is marked by the STOP instruction.

Functional changes

  1. Introduced before SmarTest 6.3.2
