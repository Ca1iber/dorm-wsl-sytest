PRBS_LABEL

The PRBS_LABEL class is provided to simplify the setup and modification of PRBS-enabled main labels in test methods. Labels containing a PRBS instruction can also be modified via the pattern debug tool.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PRBS_LABEL.h.

Member function

Constructor

PRBS_LABEL(const std::string & labelname);

Member functions

PRBS_LABEL& length(INT length);
PRBS_LABEL& delay(INT delay);
INT getDelay();
INT getLength();

Constructor

PRBS_LABEL(const std::string & labelname);

This function creates an object of the PRBS_LABEL with the specified label. If this label does not exist, it will be automatically created.

Member functions

length()

PRBS_LABEL& length(int length);

This function sets the length of the PRBS sequence generated. Its unit is tester cycle. It will modify the parameters for the PRBS instruction in the label.

Parameter

length

The length of the label that PRBS sequence generated.

delay()

PRBS_LABEL& delay(int delay);

This function sets the number of cycles that the PRBS generator or checker needs to wait before starting the actual PRBS sequence. It will modify the length of the BRKV instruction in the label.

Parameter

delay

The number of cycles to wait.

getDelay()

INT getDelay();

This function returns the number of cycles to wait before the PRBS sequence starts.

getLength()

INT getLength();

This function returns the length of the PRBS sequence generated.

Examples

Configure a PRBS test

The following example shows how to configure a PRBS test. In the example, there are two pin groups Tx and Rx defined, containing two pins Tx1, Tx2 and Rx1, Rx2 respectively.

//
// Create a PRBS set
//
PRBS_SET prbsSet1("PRBS_7_BER3");

//
// Configure parameters common for all pins
//
prbsSet1.pin("Tx,Rx").polynomial("0000011");

//
// Configure parameters for individual Rx pins, different seeds for each pin
//
prbsSet1.pin("Rx1").seed("1111000");
prbsSet1.pin("Rx2").seed("0000111");

//
// Create another set
//
PRBS_SET prbsSet2("PRBS_31_BER3");

//
// Configure
//
prbsSet2.pin("Tx,Rx").polynomial("0000000000000000000000000001001");
prbsSet2.pin("Rx1").seed("1111100000111110000011111000001");
prbsSet2.pin("Rx2").seed("0010010110111100010100000000011");

//
// Create and configure the PRBS label
//
prbsSet1.label("prbs_label_rx","@").length(125);
prbsSet2.label("prbs_label_tx","@").length(10000000).delay(125);

Access the PRBS sets

The following example shows how to access the PRBS sets defined in the example above. PRBS sets are kept in firmware and their lifetime does not correspond to the lifetime of the PRBS_SET object.

//
// Access the set defined in test method A
//
PRBS_SET mySet("PRBS_7_BER3");

//
// Modify only the polynomial for pin Rx1
//
mySet.pin("Rx1").polynomial("1001001");
