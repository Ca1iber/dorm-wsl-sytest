MTP_DPS_MEASURE.pin()

The pin() member function of MTP_DPS_MEASURE lets you specify the DPS pins you want to measure. pin() returns the DPS_PIN_TASK class object which you use to set up the measurement conditions for these pins.

Syntax

DPS_PIN_TASK & pin(const STRING & pinname)

Parameter

Description

pinname

The names of the DPS pins to be measured.

The different DPS pins are separated by commas.

Related information
