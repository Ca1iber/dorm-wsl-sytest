The Global Information Area

This is the first area in the window, directly below the pulldown menu bar. The parameters that are displayed, or that you can enter or modify are:

  • the current waveform set (entry field WFset #),
  • the current timing set (entry field Tset #),
  • the default device cycle (entry field Def. DevCyc:),
  • the number of displayed test system cycles (entry field cycles:).
