Deleting a Table Format

To delete an existing table format proceed as follows:

  1. In the Format pulldown menu pick the option delete format. The delete format dialog box appears, see the figure below.
  2. Select the format name to delete from the format list:.
  3. Click delete.

    You can delete one or more formats in one go.

  4. When you've finished deleting formats click done.
