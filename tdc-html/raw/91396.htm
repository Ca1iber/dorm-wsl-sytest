Create program file

The APG program (.prog) file referenced with :apgProgram: contains the APG program code that generates the test pattern applied to the memory device (:code:). The APG program needs an interface to define the resources used during the code execution. For example, access mode variables, device parameters, external calls, and so on (:deviceInterface:). The APG program code of the APG program file is closely based on the C language conventions.
