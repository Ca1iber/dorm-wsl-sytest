Topic 30218

DC Test Programming with PPMU

Subtopics

  1. PPMU voltage clamp on Pin Scale systems

The following APIs can be used in the DC test programming with PPMU: PPMU_SETTING, PPMU_PIN_SETTING, PPMU_RELAY, PPMU_PIN_RELAY, PPMU_CLAMP, PPMU_PIN_CLAMP, PPMU_MEASURE, PPMU_PIN_MEASURE, TASK_LIST.

About this task

To program a DC test with PPMU, at least DC tasks for setting up measurement parameters, relay connections and measurement mode must be defined. To execute these DC tasks, create a set of tasks that is called "task list" and add the defined tasks to the task list using the member functions of the TASK_LIST API. After that you can execute the DC tasks in the task list with the execute() member function of the TASK_LIST. Then the DC tasks are performed sequentially. After the measurement is completed, you can retrieve the measurement results with the member functions of the PPMU_MEASURE API.

Procedure

  1. Setting up measurement conditions for each PPMU
    • setting up measurement parameters

      To set up measurement parameters, first, define a class object of the PPMU_SETTING API as shown below:

          PPMU_SETTING obj;

      To set up measurement conditions for each pin, use the member functions of the PPMU_PIN_SETTING class as shown below:

          obj.pin("pinName").func1.func2...funcN;

      where, pin("pinName") is a member function of the PPMU_SETTING API to specify the target pin or pins to be set up. func1-N are the member functions of the PPMU_PIN_SETTING class to set the mesurement parameters.

    • Setting up relay connections

      To set up relay connections, first, define a class object of the PPMU_RELAY API as shown below:

          PPMU_RELAY obj;

      After you defined an object, set up the relay connections using the status() member function of the PPMU_PIN_RELAY class as shown below:

          obj.pin("pinName").status(relay_stat);

      where, pin("pinName") is a member function of the PPMU_RELAY API to specify the target pin or pins to be set up. relay_stat specifies the relay connections of the specified pin or pins. For a typical DC test, set PPMU_ON to connect PPMU relays and ALL_OFF to disconnect all the relays of the PMUs for relay_stat. Other specifiers are shown in PPMU_RELAY.

      After you set up the relay connections, set the wait time for the relay control using the wait() member function of the PPMU_RELAY API. Note that it takes 0.32/0.58/0.40 ms respectively for the PS1600 (DC-relays only)/PS9G/pin scale1) cards to open or close relays. Further, 4.0/2.8/1.0 respectively ms is needed for the PS1600/PS9G/pin scale cards as settling time of PMUs after closing relays. Therefore, for PS1600 for example, you must set at least 4.32 ms (for connecting relays) or 0.32 ms (for disconnecting relays) for the action for opening and closing relays.

      If you program a DC test using the PPMU_XXX APIs , relays will not be disconnected and the output from PPMU will not be stopped automatically. You need to prepare a task to disconnect the relays like below:

          relay2.pin("@").status("ALL_OFF");
    • Setting up the measurement mode

      To set up measurement mode, first, define a class object of the PPMU_MEASURE API as shown below:

          PPMU_MEASURE obj;

      After you defined an object, set up the measurement mode using the execMode() member functions of the PPMU_PIN_MEASURE class as shown below:

          obj.pin("pinName").execMode(mode);

      where, pin("pinName") is a member function of the PPMU_MEASURE API to specify the target pin or pins to be set up, mode specifies one of the measurement mode.

    • Setting up the clamp voltage

      to set up the clamp voltage, define two class objects of the PPMU_CLAMP API to enable and disable the clamp as shown below:

          PPMU_CLAMP clamp_on;
                                PPMU_CLAMP clamp_off;

      For the object clamp_on, set up the clamp voltage, status and current range with the member functions of the PPMU_PIN_CLAMP class. For the object clamp_off, disable the clamp voltage with the status() member function of PPMU_PIN_CLAMP.

          clamp_on.pin("pinName").func1.func2...funcN;
                                        clamp_off.pin("pinName").status("OFF");

      where, pin("pinName") is a member function of the PPMU_CLAMP API to specify the target pin or pins to be set up. func1-N are the member functions of the PPMU_PIN_CLAMP class.

  2. Execute a DC test

    To perform a measurement, create a task list that defines a sequence of the DC tasks, and execute the task list. For this purpose, first, define a class object of the TASK_LIST API as shown below:

    TASK_LIST obj;

    After you defined an object, add and execute the DC tasks using the add() and execute() member functions of the TASK_LIST API as shown below:

    obj.add(obj1).add(obj2)...add(objN).execute();

    where, obj1 to objN mean objects defined with the PPMU_SETTING, PPMU_CLAMP, PPMU_RELAY and PPMU_MEASURE APIs, and execute() performs the DC tasks in the task list sequentially.

    The following example defines a task list and performs the already defined DC tasks.

    TASK_LIST task1;
task1.add(setting1).add(relay1).add(meas1).execute();

    The above program can also be described as shown below so that it can be read easily:

    TASK_LIST task1;
task1.add(setting1).add(relay1).add(meas1);
task1.execute();
    Note Do not define the objects of the flexDC APIs in other places instead of the run() function of the test method.
  3. Retrieve the measurement results

    To retrieve measurement results of the DC test that achieved with the execute() member function of the TASK_LIST API, use the member functions of the PPMU_MEASURE API as shown below:

    result = obj.func;

    where, result means a variable to store the returned value, obj means the PPMU_MEASURE class object that holds the measurement results, and it was defined when the measurement mode is defined. func means the member function getPassFail() or getValue() ofPPMU_MEASURE .

    Note that you can retrieve only the data specified with the mode parameter of the execute member function of the TASK_LIST API. For example, to retrieve data with getValue, the measurement must be done with TM::PVAL mode. The following example retrieves the global pass/fail result of the meas1 object.

    Boolean pass_fail = meas1.getPassFail();
  4. Judging the result and data logging

    To judge the PPMU test result, you can use the judgeAndLog_PpmuMeasure() member function of TESTSET API.

    TESTSET().judgeAbdLog_PpmuMeasure(meas1);

    where meas1 is the defined PPMU_MEASURE object.

    The member function performs data logging if the system flag "log_events_enable" and either test suite flag "output_on_pass" or test suite flag "output_on_fail" is "on".

Example

  1. The following example shows a multi-site measurement with different settings on different pins.
    PPMU_MEASURE ppmuMeasure;
ON_FIRST_INVOCATION_BEGIN();
  PPMU_SETTING ppmuSetting;
  PPMU_RELAY   ppmuRelayOn, acRelayOn;
  TASK_LIST    simpleFlexDc;
  
  ppmuSetting.pin("I/O1").vForce(0 V).iRange(1 uA).max(1 uA).min(-1 uA);
  ppmuSetting.pin("I/O2").iForce(1 uA).iRange(1 uA).max(0.5 V).min(1 V);
  ppmuRelayOn.pin("I/O1,I/O2").status("PPMU_ON");
  ppmuRelayOn.wait(1.3 ms);
  ppmuMeasure.pin("I/O1").execMode(TM::PPF);
  ppmuMeasure.pin("I/O2").execMode(TM::PVAL);
  acRelayOn.pin("I/O1,I/O2").status("AC_ON");
  simpleFlexDc.add(ppmuSetting).add(ppmuRelayOn).add(ppmuMeasure).add(acRelayOn);
  simpleFlexDc.execute();   
ON_FIRST_INVOCATION_END();
TESTSET().judgeAndLog_PpmuMeasure(ppmuMeasure);
  2. The following example shows how to measure a current on a device pin and then use it as a force value for a following measurement for multi-sites. The result value of the first measurement differs from site to site.
    PPMU_MEASURE ppmuMeasure2;
ON_FIRST_INVOCATION_BEGIN();
  PPMU_MEASURE ppmuMeasure1;
  PPMU_SETTING ppmuSetting1,ppmuSetting2;
  PPMU_RELAY   ppmuRelayOn, acRelayOn;
  TASK_LIST multiDeltaFlexDc1, multiDeltaFlexDc2;
  // 1st measurement
  ppmuSetting1.pin("I/O1").vForce(0 V).iRange(1 uA).max(1 uA).min(-1 uA);
  ppmuRelayOn.pin("I/O1").status("PPMU_ON");
  ppmuRelayOn.wait(1.3 ms);
  ppmuMeasure1.pin("I/O1").execMode(TM::PVAL);
  acRelayOn.pin("I/O1").status("AC_ON");
  multiDeltaFlexDc1.add(ppmuSetting1).add(ppmuRelayOn).add(ppmuMeasure1);
  multiDeltaFlexDc1.execute();   

  // dummy setting for avoiding DC set run out
  ppmuSetting2.pin("I/O1").iForce(0 uA).iRange(1 mA).max(0.5 V).min(-0.5 V);
  ppmuSetting2.wait(1 ms);
  ppmuMeasure2.pin("I/O1").execMode(TM::PVAL);
  multiDeltaFlexDc2.add(ppmuSetting2).add(ppmuMeasure2).add(acRelayOn);
  multiDeltaFlexDc2.setup();

  // 2nd measurement
  FOR_EACH_SITE_BEGIN();
    ppmuSetting2.pin("I/O1")
                .iForce(ppmuMeasure1.getValue("I/O1"))
                .iRange(ppmuMeasure1.getValue("I/O1"))
                .max(0.5 V)
                .min(-0.5 V);
  FOR_EACH_SITE_END();
  multiDeltaFlexDc2.execute();
ON_FIRST_INVOCATION_END();

TEST("I/O1",
     "multi_delta",
     ppmuMeasure2.getPassFail("I/O1")?TM::Pass:TM::Fail,
     ppmuMeasure2.getValue("I/O1"),
     true );
  3. The following example shows a PPMU IFVM test on the pin S0 and a PPMU VFIM test on the pin S1. Clamp is used to avoid hot switching in the IFVM test.
    PPMU_SETTING   ppmuSetting;
PPMU_RELAY     ppmuRelay_on, ppmuRelay_off;
PPMU_MEASURE   ppmuMeasure;
PPMU_CLAMP     ppmuClamp_on, ppmuClamp_off;
TASK_LIST      taskList_1;

ON_FIRST_INVOCATION_BEGIN();

    //
    // Setups for PPMU
    //
    ppmuSetting.pin("S0").iRange(1 mA).min(0 V).max(4.3 V).iForce(10 uA);
    ppmuSetting.pin("S1").iRange(10 mA).min(-10 uA).max(30 uA).vForce(3.3 V);

    //
    // Relay setups
    //
    ppmuRelay_on.pin("S0,S1").status("PPMU_ON");
    ppmuRelay_on.wait(1.3 ms);
    ppmuRelay_off.pin("S0,S1").status("AC_ON");

    //
    // Measurement setups
    //
    ppmuMeasure.pin("S0,S1").execMode(TM::PVAL);

    //
    // Hardware specific programming to avoid hot switching on the current force setup
    //
    ppmuClamp_on.pin("S0").status("CLAMP_ON").low(2.6 V).high(2.9 V);
    ppmuClamp_off.pin("S0").status("CLAMP_OFF");

    //
    // Build and execute the task list
    //
    taskList_1.add(ppmuSetting)
              .add(ppmuClamp_on)
              .add(ppmuRelay_on)
              .add(ppmuClamp_off)
              .add(ppmuMeasure)
              .add(ppmuRelay_off);

    taskList_1.execute();

ON_FIRST_INVOCATION_END();

//
// Result upload and Datalog
//
double VMeas, IMeas;

VMeas = ppmuMeasure.getValue("S0");
IMeas = ppmuMeasure.getValue("S1");

TEST("DC_Test",ppmuMeasure, true);
