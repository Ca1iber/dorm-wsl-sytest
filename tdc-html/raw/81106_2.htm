Topic 81106

Setting up the wavetables

About this task

You need to create additional wavetables for tDQSQmax and tDQSQmin timing measurements each. To facilitate the creation of the two additional tables, copy an existing wavetable. (This table will be referred to as the "original" wavetable in the following examples.) This wavetable is present in the setup timing file of the sample GDDR3 device delivered with MTP.

Procedure

  1. In the Setup Dialog, edit the Waveform. The Timing Setup window opens.
  2. In the Timing Setup window, click File > Edit Wavetables. The editor window opens, displaying the original wavetable Mem_Patterns.
  3. Create two new wavetables for tDQSQmax time and one for tDQSQmin time.
  4. Copy the entire Mem_Patterns wavetable and paste it twice after the original wavetable.
  5. Rename the wavetable that you pasted at first to, for example, to WAVETBL "HSM_tDQSQmin":
  6. Rename the second of the pasted wavetables to, for example, WAVETBL "HSM_tDQSQmax".
  7. Invert the expected data patterns for the DQo data pins in the wavetable tDQSQmin. Do not change the expected data patterns for the RDQSo pins.
  8. To invert the pattern, mark the wavetable for DQ_Bus and change H into T, then change L into H, then change T into L. Use the Search menu of the editor.
  9. In the tDQSQmax wavetable, invert the expected data for the RDQSo data clock pins. Do not change the expected data for the DQo pins.
  10. To save the modified wavetable file, choose Shell > Download and close the file.
    Note The above described method of inverting the patterns assumes that you use the same test pattern (vector label) for both tests. The method also allows you to use a standard test pattern, for example the march6n pattern for the multi-strobe test. If you do, you must assure that you select as a sweep start those cycles where the pattern provides toggling on the data as well as on the strobe clock lines.

Results

You now have prepared the wavetables required for the multi-strobe test methods.
