Topic 20295

Navigating a testflow

Subtopics

  1. Searching for test suites, bins and variables

The Testflow Tool provides several tools that help you to navigate a testflow, making large testflows significantly easier to handle simplifying debugging and creating testflows.

You can:

  • Quickly jump to test suites by using bookmarks in the Bookmarks view.
  • Use the filter line in the Flow Data Editor to find the desired test suites, bins, parameters, limits, and flags, etc.
  • Search for test suites, bins, and variables in the Flow Sequence Editor.
  • Jump from one test suite to the next or previous passed, failed, executed, cloned, or bookmarked test suite, or the test suite with invalid parameter by using the Next Annotation or Previous Annotation buttons on the main toolbar.
