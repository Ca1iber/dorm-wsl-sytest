Before You Start the SmarTest Software...

Subtopics

  1. SmarTest Software Base Directory
  2. Specifying the Device Path
  3. Setting up Workorder Directories
  4. SmarTest environment variables

Before any workorder management can take place, each tester you intend to use must have the appropriate devices and test programs installed on it. See Specifying the Device Path for details.

In addition, SmarTest expects workorders to be located in certain directories. This must be considered, before you start executing workorders (see Setting up Workorder Directories).

Note Before you start SmarTest, make sure you have selected the desired version. To switch the version to be started, use the Switch version tool.
