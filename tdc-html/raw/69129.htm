Topic 69129

Multiple-Result Parametric Record (MPR)

Subtopics

  1. Logging user text to the MPR TEST_TXT field

Function

The Multiple-Result Parametric Record contains the results of a single execution of a parametric test with multiple results. The first occurrence of this record also establishes the default values for all semi-static information about the test, such as limits, units, and scaling. The MPR is related to the TSR by test number, head number, and site number.

Location in the file

The Multiple-Result Parametric Record can appear anywhere in the data stream after the corresponding PIR, and before the corresponding PRR.

RTN_ICNT

 Count of PMR indexes
  • Two-byte unsigned integer
  • The number of elements in the RTN_INDX and RTN_STAT arrays is determined by the value of RTN_ICNT.
  • The indexes referred to in RTN_INDX field are the PMR indexes defined in the Pin Map Record (PMR).
  • RTN_ICNT may be omitted if it is zero and it is the last field in the record.
  • EDL Event:

    PinPFResult

RSLT_CNT

 Count of returned results
  • Two-byte unsigned integer
  • The number of test results returned by the test and put into RTN_RSLT
  • RSLT_CNT may be omitted if it is the zero and it is the last field in the record
  • Calculated value

RTN_STAT

 Array of returned states
  • Unsigned integer data stored in a nibble (4 bits of a byte)
  • RTN_ICNT = 0x0 if missing or invalid data.
  • RTN_ICNT = 0x0 for every pin if there are multiple pins.
  • Hard-coded value

RTN_RSLT

 Array of returned results
  • Four-byte floating point number
  • Array of results from a parametric test that returns more than one result
  • If the per-pin test suite flags are turned on, the results for each pin will also be included, in the order specified by the RTN_INDX field.
  • EDL Event:

    PinValue

  • EDL Attribute:

    Value

TEST_TXT

 Descriptive text or label
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum of 255 bytes
  • Length byte = 0 if missing or invalid data
  • The test text contains: "Test suite name: test name#test comment" for MPR's and FTR's. Where '#' is the separator and can be configured in the config file. The comment is logged from the test method api and is optional.
  • It contains "Test suite name: test name#pin name#test comment". Where '#' is the separator and can be configured in the config file. The comment is logged from the test method API and is optional.

START_IN

 Starting input value (condition)
  • Four-byte floating point number

INCR_IN

 Increment of input condition
  • Four-byte floating point number
  • OPT_FLAG bit 1 = 1
  • Hard-coded value

RTN_INDX

 Array of PMR indexes
  • Two-byte unsigned integer
  • RTN_ICNT = 0 if missing or invalid data
  • Numbers are automatically generated by the formatter. They start with 1 and go up to the number of pins on all sites. For example, if there are 7 pins and 4 sites, then there will be a total of 28 pin indexes from 1-28.

UNITS

 Units of returned results
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum of 255 bytes
  • Length byte = 0 if missing or invalid data
  • V, A, and so on
  • EDL Event:

    TestEventType

  • EDL Attribute:

    PinValueResultAttrType -> Units

    PassRangeAttrType -> Units

UNITS_IN

 Input condition units
  • Always 0
  • Hard-coded value

C_RESFMT

 ANSI C result format string
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum of 255 bytes
  • Length byte = 0 if missing or invalid data
  • Hard-coded string "%7.9f"
  • Set by the TESTSET().resFmt function.

C_LLMFMT

 ANSI C low limit format string
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum of 255 bytes
  • Length byte = 0 if missing or invalid data
  • Hard-coded string "%7.9f"
  • Set by the TESTSET().llmFmt function.

C_HLMFMT

 ANSI C high limit format string
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum of 255 bytes
  • Length byte = 0 if missing or invalid data
  • Hard-coded string "%7.9f"
  • Set by the TESTSET().hlmFmt function.

LO_SPEC

 Low specification limit value
  • Four-byte floating point number
  • Always OPT_FLAG bit 2 = 1
  • Hard-coded value

HI_SPEC

 High specification limit value
  • Four-byte floating point number
  • Always OPT_FLAG bit 3 = 1
  • Hard-coded value
    Note The fields RTN_ICNT, RTN_INDX, RTN_RSLT are filled in only if the per-pin test suite flags are turned on (if the flags are turned off, it will still contain the global results).

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.1.1: The values of the C-RESFMT, C_LLMFMT, and C_HLMFMT fields are no longer hardcoded.
  3. SmarTest 7.5.0: TEST_FLG bit 0 is no longer hard-coded
