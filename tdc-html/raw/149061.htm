Topic 149061

rdi.smartVec().readMode()

Specifies a read mode for subsequent RDI_BEGIN()/RDI_END() blocks.

readMode() must be located outside of RDI_BEGIN()/RDI_END() blocks. See the example.

If you do not use this command to specify a read mode in your test methods, the default read mode is determined by the DEFAULT_SMV_READ_MODE keyword in the RDI_Configure file. If this keyword is not set in the file, the default read mode is digital capture DIGCAP.

Syntax

readMode(TA::MEAS_TYPE mode);
List of parameters

Parameter

Description

mode

The read mode.
List of available options of parameter: <mode>

Option

Description

TA::EMAP

The error map as the read mode.

In this mode, for each pin, the ERROR_MAP_TEST API is used to get all failed positions. A post processing is done afterward.

TA::DIGCAP

The digital capture as the read mode.

In this mode, a dummy pattern with a digital capture variable is created. It cannot be mixed with the digCap() class inside a burstUpload-begin()/end() block.
Note The option TA::EMAP cannot be used together with a match loop in label.

Example

rdi.smartVec().readMode(TA::EMAP);

RDI_BEGIN();
  ...
  rdi.smartVec().pin("A").read...().execute();
  ...
RDI_END();
