Topic 34711

VectorResultAttrType/VectorResultLongNameAttrType

Contains the received data and edge information for each pin of a cycle. The data type is DRLValueResultAttr.

Device cycle name. The number of characters depends on the attribute type:

  • VectorResultLongNameAttrType: 17 characters
