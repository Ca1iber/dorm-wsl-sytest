Dual-site GPIO configuration

Subtopics

  1. Valid combinations of plug-ins and configuration files
  2. Binning map
  3. GPIO box jumpering
  4. Timing diagram (Synax dual-site)

The "Dual-site" configuration is valid for Synax handlers.

Supported handler models

  • 141H10A
  • 1211H04A
  • 1701-01A
  • 1701-02A/B
  • 1701-03A

Features

  • up to 2 sites
  • 2 DUT signals
  • no global test start signal
  • parallel binning
  • explicit binning
  • 8 bin categories
  • no "empty" bin

Required handler cable

  • E2790-61601-2
