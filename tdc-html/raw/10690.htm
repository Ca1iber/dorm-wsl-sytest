Topic 10690

Defined

The syntax to return the Defined results to the query is:

DDEF? "ListName",Defined

or

DDEF? ALL,Defined

Example

If list A is created and defined as:

DDEF "A",CREATE,"FreqList","Comments"
DDEF "A",SET,"Equation","Loop(1,10,10)"

then DDEF? "A",Defined will return:

DDEF "A",CREATE,"FreqList","Comments"
DDEF "A",SET,"Equation","Loop(1,10,10)"

If list A is created and defined as:

DDEF "A",CREATE,"FreqList","Comments"
DDEF "A",SET,"Equation","RepeatValue(0x55555555,10)"

then DDEF? "A",Defined will return:

DDEF "A",CREATE,"FreqList","Comments"
DDEF "A",SET,"Equation","RepeatValue(0x55555555,10)"

Functional changes

  1. Introduced before SmarTest 6.3.2
