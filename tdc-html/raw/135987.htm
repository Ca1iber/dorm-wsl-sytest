Testing with the recipe file in the Test Cell Control Tool

The Recipe file can contain all the settings needed for the test in the Test Cell Control Tool(TCCT). Using the recipe file can help avoid the step-by-step setup in the test with TCCT as described in Setting up tests manually with the Test Cell Control Tool.

Before you begin

Make sure the needed SmarTest version and TCCT are installed.

The recipe file is correct and ready to use. (Refer to Recipe file for the detailed explanation.)

Procedure

  1. Start SmarTest and TCCT. The following actions are done in TCCT.

    In the engineering mode, only TCCT is started. You need start SmarTest and load the recipe file separately.

    In the production mode, SmarTest and TCCT are started and the recipe file is loaded.

    Make sure TCCT is successfully attached to the SmarTest session. The status is shown in the lowest part of TCCT. "SmarTest XXX Attached" will be shown if it is successfully attached. Otherwise, you will see the message "SmarTest Session Detached".

  2. If TCCT was started in the engineering mode, to load the recipe file, click the Load Recipebutton and select the recipe file to load.

    The full path of the loaded testflow, the equipment settings in the recipe file and the full path of the recipe file will be displayed in the Lot Summary area of TCCT.

  3. To start the lot, click the New Lot button in the lower part of TCCT. In the pop-up Lot Information dialog, enter the values for the listed variables if needed.

    You can edit the configuration file of the dialog to change the variables listed in the dialog.

  4. To start the testing of the lot, click Start Test.

    The text data log file is created as specified in the recipe file. The binning information of the execution will be displayed in the Binning area and counted in the Binning Statistics area.

  5. (optional) If some error occurs in the testing, you can debug the testflow in EWC or disable some sites before further testing.

    For HANDLER and PROBER test, you need to click Pause Test before the debugging.

  6. (optional)To generate the partial summary for the tested devices, click Pause Test and then click Partial Summary for the PROBER and the HANDLER test. For the HAND test, just click Partial Summary.

    The partial summary is generated in the lot summary file you specified in the recipe file.

  7. To continue the tests for other devices in the lot, click Resume for HANDLER and PROBER test and click Start Test for HAND test.
  8. When all the devices in this lot are finished, click End Lot.

    The data log files and the lot summary file are generated as specified in the recipe file.

Results

The data log file(s) and lot summary file(s) can be generated as specified. The binning statistics and the yield of the tests are shown in the main GUI of TCCT.

Functional changes

  1. Introduced in SmarTest 7.2.0
