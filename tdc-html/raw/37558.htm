General Overview of Pattern Structure and Parallel Vector Translation

The basic components of a vector pattern are an array of physical waveform DC/DC power units and a sequencer program. The rows of the index array represent the parallel vectors that are sent to the DUT by the sequencer program. The array columns contain the waveform DC/DC power units for one pin in temporal order. A pattern can also contain scan vectors, but these will be discussed elsewhere (see Creating a Scan Test Setup).

The sequencer program serves to send the vectors to the DUT. It consists of a sequence of instructions. Some of these generate vectors, that is, they create a certain number of signals from as many rows of the index array and send them to the DUT either exactly once (the GENV instruction) or for a specified number of times (the RPTV instruction); other instructions serve to change the timing or level setup, others to call a subpattern. Every sequencer program is associated with a port; by default this is the port @, which always exists and to which all pins belong.

The sequencer program and the array of waveform DC/DC power units are stored in different locations; the sequencer program is stored in the sequencer area, the index array for the parallel vectors in the parallel (vector) area. Therefore, every sequencer program must contain an instruction that specifies the start address of its associated index array. If the sequencer program contains several vector generating instructions, each of them is associated with a different section of the array. The start rows of these sections are calculated from the address of the whole array and the lengths of the array sections for the previous vector generating instructions.

The vector translation converts the ASCII vectors into download commands for the index array. Every download command contains the waveform DC/DC power units for one pin, that is, one column of the index array, in binary format.

The vector translation also creates the download commands for a complete sequencer program for the pattern. In the simplest case, when the ASCII vector file only contains a sequence of ASCII vectors (and no sequencer instructions), the body of the program will consist of one GENV instruction which will create vectors from the whole index array and send them to the DUT exactly once. If you want to send a sequence of vectors repeatedly, or to change the level setup within the pattern (instructions for a change of the timing set will usually be inserted automatically, see Controlling the Automatic Insertion of CTIM Instructions), you must insert the respective instructions into the ASCII vector files at the appropriate places; see Inserting Sequencer Instructions.
