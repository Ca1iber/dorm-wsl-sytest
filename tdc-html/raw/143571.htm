Topic 143571

samples()

Specifies the number of samples to capture.

Syntax

samples(long iSamples);
List of parameters

Parameter

Description

iSamples

The number of samples.

 

		
Example
rdi.digCap("cap").pin("DATA1").samples(100).execute();

	


Functional changes
  1. Introduced in SmartRDI 2.1.0
