Topic 20235

Multiple Sites Execution

When you perform tests on multiple sites, it is important to be aware of what happens when the test reaches a test suite:

  • If all sites reach a test suite in parallel, then they all leave that test suite in parallel, unless they are binned. This means that if the test performed in that test suite has passed for one site, this site will wait until the test (and all tests in the fail branch) has finished for all other sites, before it goes to the next test suite.
  • If the node contains a branch (like the run & branch node and all flow control nodes), then the false (failing) path is always executed first.

Functional changes

  1. Introduced before SmarTest 6.3.2
