PSAS? - (Power Supply Accumulated Status)

The PSAS? (Power Supply Accumulated Status) query reads and clears the internal status flags of the Device Power Supplies (DPS) in DPS operating mode, in PMU operating mode, or in Digital I/O operating mode. All DPS status flags are cleared at connect and disconnect if the trigger condition is no longer true.

The query returns either a hex value or a pass/fail result. The hex value must be translated into binary form to interpret the status. The result will show any bits that have been set on tests performed since the previous execution of the command, or since the last connect or disconnect sequence was executed.

Note All DPS status flags are reset to 0 at connect (PSST ON) and disconnect (PSST OFF)1), but the effect of a PSAS? query differs depending on the DPS card. For details see the DPS flag reset table below. A reset to 0 is only effective if the condition for the flag is no longer true. If the condition is true at the time of the connect/disconnect or PSAS? query, then the flag is not reset.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Note

Pass/fail results that are retrieved by command PRLT are invalidated by commands CSAS and PSAS.

We recommend therefore using the command PRLT directly after the related functional test and before command CSAS or PSAS are performed.

This behavior applies not only to the commands but also to the related APIs: Function GET_FUNCTIONAL_RESULT() must be performed before any of the DPS_AUX_PIN_TASK.check...() functions is called or the results of GET_FUNCTIONAL_RESULT() are invalid.

Syntax

PSAS? [msMode ,] {mask}, {(pinlist)}

returns

PSAS {status}, {(pinlist)}
Parameters
msMode The extra parameter controls how the return value is created.

The value of the parameter can be PQFC:

  • PQFC specified: The current query focus is respected and allows status query per site without affecting status bits of other sites.
  • PQFC not specified: The command reads (and clears) status bits of all enabled and active sites at a glance, ignoring the actual query focus.
The parameter applies only to use of parameter mask as integer value.
mask Integer bit mask or ALL.

  • Integer bit mask: Integer value is used to mask out individual status bits. Each bit of mask is logically AND-ed with the corresponding bit of the DPS status. If one of the resulting bits is set, then F (Fail) is returned, otherwise P (Pass).

    It is used to check for an error condition. All bit positions of the status flags that should be checked, must be set to 1 in mask. If one of the selected status bits is set, then PSAS? returns F.

  • ALL: Hex value (hexadecimal representation of all status bits) is returned.
For setting the integer bit mask or interpreting a returned hex value, refer to the status parameter below.
pinlist Comma separated list of DPS128/64 or XPS256 pins. The @ character can be used to read the status for all DPS pins.
status If parameter mask is ALL, you need to translate the hex value (hexadecimal representation of the status bits) to its binary form as follows:
Bit 0 (LSB): Constant voltage
Bit 1: Constant current
Bit 2: Unregulated
Bit 3: Overvoltage
Bit 4: Overpower / Overcurrent / Power budget exceeded
Bit 5: Overtemperature
Bit 6: Voltage drop force
Bit 7: Voltage drop return
Bit 8: DUT board disconnect For the special mapping of bit 9 and 8 on UHC4 and UHC4T, refer to table DPS flag description below.
Bit 9: Safety line
Bit 10: Current limit disconnect
Bit 11: Low headroom
Bit 12: Current limiter protection detected
Bit 13: Range overflow
Bit 14 (MSB): Clamp distance too low
Bit 15: Voltage drop force warning
Bit 16: Voltage drop return warning
If parameter mask is specified as an integer bit-mask:
  • Pass: P
  • Fail: F

Refer to table DPS flag implementation below for information regarding the card specific implementation of the bits or flags.

DPS flag description

The functionality of the flags is largely the same for the various DPS cards.

For a card-specific detailed description of the flags refer to
  • XPS256 status flags
Flag Description
Constant voltage The flag indicates the constant voltage operating mode.

The DPS channel is forcing or clamping the voltage.

Note: In offline mode of SmarTest, this flag will be set to 1.
Constant current The flag indicates the constant current operating mode.

The DPS channel is forcing or clamping the current.
Unregulated The channel is in an unregulated state.
Overvoltage An overvoltage condition has been detected.
Overpower / Overcurrent / Power budget exceeded An overpower or overcurrent condition has been detected or a power budget has been exceeded.
Overtemperature The temperature of the channel hardware is too high.
Voltage drop force

The user defined voltage drop on the high force line of the DUT board is too high.

For UHC4T channels in DPS operating mode, see max_voltage_drop_force in DPSPINS resources.
Voltage drop return

The user defined voltage drop on the low force / return line of the DUT board is too high.

For UHC4T channels in DPS operating mode, see max_voltage_drop_return in DPSPINS resources.
DUT board disconnect The DUT board has been disconnected. Due to the hardware structure of UHC4 and UHC4T, bit 9 (Safety line) is actually mapped to bit 8 (DUT board disconnect) and bit 9 will never be set. This special mapping of the bit applies only to UHC4 and UHC4T.
Safety line The interlock of the safety line is open.
Current limit disconnect The user defined time for constant current mode was reached.

See ms_const_curr_disconnect in DPSPINS resources.
Low headroom The energy supply provides not enough headroom for the proper function of the output buffer.
Current limiter protection detected The current limiter protection mode has been triggered.
Range overflow An overflow of the force range or the clamp range has been detected. The flag is also set for comparator range overflows if the related measurement range is determined by the force or clamp range.
Clamp distance too low The programmed distance between the upper and lower clamp voltage or between the sourcing and sinking clamp current is too low.
Voltage drop force warning The measured voltage drop on the force line (P#) exceeds the programmed warning threshold.
Voltage drop return warning The measured voltage drop on the common return line (GND) referenced to the ground sense line (GS#) exceeds the programmed warning threshold.

DPS flag reset

All DPS status flags are reset to 0 at connect (PSST ON) and disconnect (PSST OFF), but the effect of a PSAS? is different for the "Constant Voltage" flag. It is 1 when all other flags are 0.

Note that a reset to 0 is only effective if the condition for the flag is no longer true. The flag is not reset, if the condition is still true at the time of the connect / disconnect or PSAS? query.

Application

DC Tests, see DC Measurement Commands.

Errors

An error is generated if a communication error with the DPS occurs.

The status bits 4 to 11 result in a disconnect of the pin. To reconnect you must execute a disconnect-connect sequence.

Examples

Description

For the following examples (1 to 4), the assumed binary value of the status of the UHC4 pin Vcc is 10000110 (Voltage drop return, Unregulated, Constant Current).

Example 1

To get all flags:

PSAS? ALL,(Vcc)

returns

PSAS #86,(Vcc)

Example 2

To check if Unregulated (bit 2) is set:

PSAS? 4,(Vcc)

returns

PSAS F,(Vcc)

Example 3

To check if Constant Current (bit 1) or Overpower (bit 4) is set:

PSAS? 18,(Vcc)

returns

PSAS F,(Vcc)

Example 4

To check if Voltage Drop Force (bit 6) or DUT Board Disconnect (bit 8) is set:

PSAS? 320,(Vcc)

returns

PSAS P,(Vcc)

Example 5

PSAS? ALL,(Vee)

returns 

PSAS 2,(Vee)

This example for device pin Vee shows the DPS is working in constant current mode.

Example 6

PSAS? ALL,(Vee)

returns 

PSAS 64,(Vee)

This example for device pin Vee shows the DPS has hit the voltage drop force threshold.
