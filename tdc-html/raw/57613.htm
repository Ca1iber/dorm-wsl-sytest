Topic 57613

Configuration for DPSs

For DPSs, SmarTest decides the test system configuration in online mode as follows:

  1. It reads the model file.
  2. It checks if there is a syntax error or feature dependency error in the model file.
  3. It checks for hardware conflicts (for example, hardware is not installed, or hardware is not compatible) by comparing the model file settings with the actually installed test system resources. At this time, SmarTest detects all modules installed in the test system.
  4. For system resources and features that are controlled by licenses, it generates the license requests from the model file to the license server.
  5. It checks out the requested licenses from the license server.
  6. It configures the test system based on detected hardware information and given licenses.

Thus in online mode, the license requirements for the license-controlled resources are based on the model file. On the other hand, for the resources not controlled by licenses, the system configuration is based on the detected hardware, not on the model file.

For the DPSs that require licenses and in offline mode, the process for the system configuration is the same as of the digital resources. For these cards, the model file or the device license file enables the required resources and features.

CAUTION If a device license file exists, its parameters will be evaluated and any licensing parameters in the model file will be ignored.

For details see The model file and Configuration for digital cards.

The device license file can only include license relevant entries, like speed, memory, etc. Non-license relevant entries like test head, etc. belong into the model file. If no device license file is provided, the relevant licensing parameters in the model file will be evaluated. See also The device license file.

In offline mode, the process for system configuration is the same as for the digital resources. That is, the model file is the basis for the system configuration.

If SmarTest detects an error, such as a syntax error in the model file, a hardware conflict, or no available license, an error message will be displayed in the report window or in a pop-up error window.

The configuration information for DPSs is displayed in the report window below the configuration information for digital resources.
