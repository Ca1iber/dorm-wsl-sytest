Topic 111627

Creating a floating test suite

Subtopics

  1. Connecting a floating test suite to the testflow

You can add a test suite on the Test suites page of the Flow Data editor as a Floating test suite.

About this task

For SmarTest any test suite, which you add on the Test Suite page of the Flow Data editor, is a floating test suite

Before you begin

Make sure that the primary setup files have been loaded.

Open the testflow in the Flow Data Editor.

Procedures

Creating a floating test suite from scratch

  1. On the Test suites page, right-click and select Add Test Suite.

    The New Test Suite Wizard window opens.

  2. Enter the information for the floating test suite in the same way as described in Inserting a test suite into the testflow.
  3. Click Finish.

SmarTest displays the floating test suite with a dark gray background.

Creating a floating test suite based on an existing test suite

  1. On the Test suites page, right-click the line number of the test suite you want to copy and select Copy.
  2. Right-click the Test suites page and select Paste as New Test suite.

    The floating test suite is added.

  3. Edit the test suite settings if necessary.

SmarTest displays the floating test suite with a dark gray background.

What to do next

You can run it for debugging.

You can connect it to the testflow in the Flow Sequence Editor (then the floating test suite becomes a normal test suite).
