Topic 70980

Differential Context

In the pin configuration window, it is necessary to define a "context". The use of contexts makes it possible for the configuration of the channel to change from one test suite to another in the test flow. (For example, the channel might be configured as an input in one test, and as an output in the next.) Each test has a context assigned to it, and the channel configuration that is appropriate to that context is automatically selected during test execution.

For testing in the differential signaling mode, you need to create a differential context (that is, a context which says that the tester channel is to be used for differential signaling). The context is defined in the pin configuration window, but it is referenced or selected in the level setup, timing setup, test setup, and vector setup.
