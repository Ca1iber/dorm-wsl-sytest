Topic 37519

Creating a Multi-Port Timing with ait

Subtopics

  1. The MULTI_PORT_BURST Statement
  2. The MULTI_PORT_TIMING Statement
  3. Generating the Specification and the Vector Configuration File

To generate a multi-port timing with the ASCII interface, you must define the ports in the pin configuration file and specify the input information for the multi-port timing specification in the global configuration file (*.aic). The ports must be defined with the firmware command DFPT. The input information for the specification must be specified in the GROUPS section of the global configuration file (for general information on the GROUPS section see The GROUPS Section).

If your timing port set and vector port set are identical (as illustrated by Figure General Overview of Multi-Port Testing), you should use a group of type MULTI_PORT_BURST to define the multi-port timing specification. This ensures that ait, in addition to creating the specification, generates a MULTI_PORT_BURST statement in the vector configuration file (*.aiv), which will then be converted into a multi-port burst definition by the vector translation (see Bursts and Multi-Port Bursts).

If timing port set and vector port set are different, you can use the MULTI_PORT_TIMING statement to define the timing specification.
