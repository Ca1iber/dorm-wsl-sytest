Topic 10489

Relays and Control Commands

Subtopics

  1. Concepts of relay control

This chapter describes the use of firmware commands to set relay positions and the tester state, and to control the connection and disconnection of DPSs. These allow you to perform the following functions:

  • Connect the DUT to the Tester Resources
  • Disconnect the DUT from the Tester Resources
  • Control of the Pin Electronics Relays and the Relay Switching Method
  • DPS Control (User Defined Connect / Disconnect)
