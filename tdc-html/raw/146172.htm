Production configuration file

This file can be used to specify the settings to start SmarTest, set values for the SmarTest environment variables and specify the configuration files for TCCT.

It will be used when you start TCCT in production mode. SmarTest will be started with the settings in this file. When it is used by starting TCCT in production mode, the file /etc/opt/hp93000/tcct/production_environment_config.xml will be used. If this file does not exist, the file /opt/hp93000/tcct/etc/production_environment_config.xml will be used.

The production configuration file has the following elements:

  • smartest: specifies the settings to start SmarTest and the values for the SmarTest environment variables.
    • startup_mode: specifies the online or offline mode.
    • user_mode: specifies the supervisor, operator or engineer mode.
    • model_file: specifies the model file to use.
    • break_device_lock: specifies whether to remove the break device lock dialog. It can be true for removing the dialog and false for popping up the dialog. By default, the dialog is removed. (If you have no authority to delete the device lock file, the dialog will be popped up even if you specify true.)
    • env: specifies the values for the environment variables.
  • tcct: specifies the configuration files for TCCT.
    • ui_config_file: specifies the UI configuation file for TCCT.
    • recipe_file_location: specifies the path that contains recipe files to use.

Example

<?xml version="1.0" encoding="UTF-8"?>
<production>
  <smartest>
    <startup_mode>offline</startup_mode>
    <user_mode>supervisor</user_mode>
    <model_file>/etc/opt/hp93000/soc_common/model</model_file>
    
    <env>
    <!-- specify the environment variables for SmarTest -->
      <V93000_TM_LIBRARY_PATH>/home/path/to/external/93k_TM_lib</V93000_TM_LIBRARY_PATH>
      <LD_LIBRARY_PATH>/path/or/paths/to/3rd_party_libs</LD_LIBRARY_PATH> 
    </env>
  </smartest>
  <tcct>
    <ui_config_file>/etc/opt/hp93000/tcct/tcct_gui_configuration.xml</ui_config_file>
    <recipe_file_location>/tmp</recipe_file_location>
  </tcct>
</production>
