Parameter: log_files_to_keep

The messages and warnings/errors log files generated by the driver may be kept or overwritten with each start-up of the driver (each test program execution), or with each change of one of the parameters driver_message_log or driver_error_log to a log file which already exists.

This parameter sets the number of old log files to be kept by renaming the files according to the following scheme: file -> file_old_1 -> file_old_2 -> ... -> file_old_<log_files_to_keep>

Driver default: 0

Changeable at run-time: yes

Applicable for: handlers and probers

Example: log_files_to_keep: 3
