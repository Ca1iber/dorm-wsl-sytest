JRST - (Jitter modulator ReseT)

The JRST command serves to reset the jitter modulator to its default state OFF. If jitter injection is running continuously (CONT option for the MODE property of the jitter set) and JRST is issued between repeated executions of the same pattern, this will ensure that every execution starts from the same initial conditions.

For general information on jitter injection see Principles of jitter injection.

Syntax

JRST {(pin_list)}

Parameters

pin_list

The pins for which the jitter modulator is to be reset. Typically, this must be done for all configured pins, so that you will usually specify @ for the pin list.

Application

Jitter injection.

Example

JRST (@)

This example resets the jitter modulator of all configured pins to its default state OFF.

Functional changes

  1. Introduced in SmarTest 7.0.1
