addParameterType

addParameterType() is used only in the addParameterTypes() function, one of the provided functions in the Customized shmoo test template.

addParameterType() adds parameters to be varied for x-axis and y-axis in a shmoo test. The added parameters will become the options of parameterType which is a test method parameter of ac_tml.AcTest.Shmoo.

Syntax

addParameterType("parameterIdentifier","parameterType", &pValueObject)
List of parameters

Parameter

Description

parameterIdentifier

The name of a parameter to be varied for x-axis and y-axis on a shmoo plot.

parameterType

The parameter's data type. The available types are int and double.

pValueObject

(optional) A pointer to an another defined variable whose data type is the same as the data type specified in parameterType.

Example

Define a variable which points to the "mVlotage" variable and will be varied for x-axis and y-axis on a shmoo plot.

double mVoltage;
addParameterType("param1","double",&mVoltage)
