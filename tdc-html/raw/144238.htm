Topic 144238

Test Program Browser

Subtopics

  1. Test Program Browser report

Test Program Browser scans your test program and summarizes the setups and the test methods of your test program.

About this task

Use Test Program Browser when you want to check the following setups of your test program:

  • Testflow.
  • Pin configurations.
  • Level setups.
  • Timing setups.
  • Patterns.
  • Test table.
  • Test methods (either UTM or CTM).

Before you begin

Make sure:

  • You have the license "S&S_tools_package".
  • Your test program is built successfully.
  • If your test program is UTM based, make sure the source code can be found by SmarTest.

Procedure

  1. Open TP360 and launch Test Program Browser from the App Center tab.
  2. In the setup area, select Specify testflow file to be browser to choose the device and testflow.
  3. On the opened window, select the device directory and the testflow you want to check (only one testflow) and click OK to close this window.
  4. (Optional) To view or choose the objects to be checked, open the Preference page by clicking the "Configure global parameters" button () in the setup area.

    The Preference page opens, which lists the available objects to be checked:

    • Testflow.
    • Pin configuration.
    • Level setup.
    • Timing setup.
    • Vector setup.
    • Test table.
    • Test methods.

      Select the interested ones and click OK to close the Preference page. (By default, all are selected.)

  5. In the setup area, select Browse Setups to start checking.

Results

An HTML report for your selected objects are displayed in the report area of TP360.

This report is locate in the directory:

/tmp/.vda/{user_name}/tpb/tmp/TPB_Report/TP360_TPB_Report

What to do next

In the report area of TP360, you can view, navigate and save the report by using the search, home, back, forward and save as buttons on the window.

To learn about the report, see The Test Program Browser report.
