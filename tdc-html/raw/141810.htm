Topic 141810

setOn()

Closes the relays of digital pins or DC Scale pins in Digital I/O operating mode.

This function can be used only in the code‑based mode for the DC scale pin digital I/O mode.

Syntax

setOn(const string& sRelays);
Parameter

Parameter

Description

sRelays

The string defines the relays to close. It can be any combination of the strings

  • "DC",
  • "AC" or
  • "PPMU"

separated by a comma (",").

You can also use "ALL" to connect all three relays.

It also can be:

  • "AMUX_PPMU": Closes the pin's PPMU relay. The signal will pass though PPMU and reach the multiplexer. Then, the multiplexer will transfer this signal to the board ADC.
  • "AMUX_BADC":

    This option controls the multiplexer before a board ADC to select the voltage signal coming from the measured pin that has been connected to a DC Line and inputs it to the board ADC for value measurement. To close the DC relay, use setOn("DC") one more time. See the example below.

    See the MUX_VM_HIZ_ON description in the PPMU_PIN_RELAY topic for more information.

These two options work only with setOn(). Do NOT use them with setOff(), for example, setOff("AMUX_PPMU").
CAUTION In the high impedance mode, the board ADC may generate a spike when the DC relay of a digital bin is being closed. To avoid the spike occurrence, discharge the board ADC or force a voltage before the next measurement.

Example

rdi.hwRelay().pin("pinA").setOn("DC,AC").setOff("PPMU").execute();
rdi.hwRelay().pin("pinB").setOn("AMUX_PPMU").execute();
rdi.hwRelay().pin("pinC").setOn("AMUX_BADC").execute();

Using setOn("AMUX_BADC") to configure AMUX and setOn("DC") to close the DC relay:

rdi.hwRelay().pin("pinA").setOn("AMUX_BADC").setOff("AC_PPMU").execute(); // AMUX on
rdi.hwRelay().pin("pinA").setOn("DC").execute(); // DC on
rdi.hwRelay().pin("pinA").setOff("All").execute(); // All off

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 2.3.0: New options: AMUX_PPMU and AMUX_BADC.
  3. SmartRDI 2.4.2: AVI64 added.
