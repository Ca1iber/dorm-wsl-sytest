Consistent setup between MTL and standard setup files

Set up the same groups as in the pin configuration to enable group based pattern programming (*.dvac).

:groups:
{
  :format:
  { :name:    :size:  }
  { "CLK"       "2"   }
  { "DQi"      "32"   }
  { "DQo"      "32"   }
  { "RDQSo"     "4"   }
  { "WDQSo"     "4"   }
  { "DM"        "4"   }
  { "CMD"       "5"   }
  { "BANK"      "3"   }
  { "ADDRESS"  "12"   }
}

Be aware of the LSB to MSB mapping: MTL considers the lowest (right-most) bit to be most significant; SmarTest the highest (left-most).

In the pin group example below, the SmarTest pins BA0 through BA2 are mapped to the pins of BANK, an MTL pin group:

BANK.000=BA0
BANK.001=BA1
BANK.002=BA2
BANK=Banjk

To allow you to write the LSB and MSB in the "natural" Way (LSB as the right-most bit), you should define a subgroup with the same name as the base MTL group and invert the bit order:

:subgroups:
{
  :format:
  { :baseGroup:  :context: :name:   :bits:  }
  { "BANK"       "ALL"     "BANK"  "[2..0]"   }
}

For example, if the SmarTest pin group Bank (BA0, BA1, and BA2) is 0x6:

       Value
(MSB)    1    BA2 - BANK.000 - BANK.ALL.BANK.2
         1    BA1 - BANK.001 - BANK.ALL.BANK.1
(LSB)    0    BA0 - BANK.002 - BANK.ALL.BANK.0

Note that, to access the subgroup and so use the "natural" bit order, you must append the context and subgroup name to the base group name, as in this Device access file example:

:apgAccess:
{
  :name: "GroupAccessExample"
  :interface:
  { "zAddr" "xAddr" }
  :table:
  {
    :format:
    { :pin:             :states:     :data:  }
    { "BANK.ALL.BANK"   { "0" "1" }  "zAddr" }
    { ""                { "0" "1" }  "0x7"   }
    { ""                { "0" "1" }  "0x7"   }
    { ""                { "0" "1" }  "0x7"   }
    { ""                { "0" "1" }  "0x7"   }
    { ""                { "0" "1" }  "0x7"   }
    { ""                { "0" "1" }  "0x7"   }
    { ""                { "0" "1" }  "0x7"   }
    { "ADDRESS"         { "0" "1" }  "xAddr" }
    { ""                { "0" "1" }  "0xFFF" }
    { ""                { "0" "1" }  "0xFFF" }
    { ""                { "0" "1" }  "0xFFF" }
    { ""                { "0" "1" }  "0xFFF" }
    { ""                { "0" "1" }  "0xFFF" }
    { ""                { "0" "1" }  "0xFFF" }
    { ""                { "0" "1" }  "0xFFF" }
  }
}
