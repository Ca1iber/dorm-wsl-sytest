Topic 143892

iForce()

Specifies a current to force.

Considerations when setting up a DC scale pin

For the pin in the signal mode, the function in code‑based mode also closes the relay to output the current.

You can specify a range of the forcing current with iForceRange(). If the range is not specified, RDI will choose the minimum range that fits the specified current. To avoid the unnecessary changing of the current rage, you can specify the range explicitly with iForceRange().

Change range in pattern‑based mode (XPS256)

The force or clamp range of DC Scale XPS256 pins can be changed without disconnecting the channel. In pattern‑based mode, the correct sequence of changing the range and the value must be applied to avoid range overflow warnings.

For more information refer to iForceRange() or vForceRange().

Syntax

iForce(double dI);
iForce(const string& sData);
iForce(double dI,TA::DCS_IF_MODE mode);
iForce(string SpecName,TA::LEVEL_SPEC);
List of parameters

Parameter

Description

dI

The current to force.

sData

The string containing the value to be used at runtime. (Refer to Changing the parameter value at runtime with SmartRDI.)

mode

Specifies whether to force the current in the high accuracy current force mode. It is only for DPS128 cards.
SpecName The spec variable name in Level setup.

Examples

rdi.dc().pin("pinA").iForce(1 mA).execute();
rdi.dc().pin("A").iForce(0.3 mA,TA::HAC).execute(); // Setting up a pin

The parameter TA::HAC defines the HV channel to be used.

Setting up SPMU

rdi.dc().pin("pinA",TA::SPMU).iForce(1 mA).execute();

Related information

DC Scale DPS128 Device Power Supply (E8023CS/E8023CSH) - high current specifications

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 7.5.0: Spec variables can be added to DC events.
