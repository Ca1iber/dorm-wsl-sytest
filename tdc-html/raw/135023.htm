Topic 135023

Logging test results with Datalog Control tool in EWC

Subtopics

  1. Setting the data log general information in the Datalog Control tool
  2. Setting the data log output information in the Datalog Control tool
  3. Generating the (partial) lot summary file with the Datalog Control tool

About this task

Datalog control tool is only used to log the testflow execution results. Do not use it to log the results of test programs. Otherwise, the results may be messed up.

Before you begin

SmarTest is started and the testflow is ready for execution.

Procedure

  1. In the SmarTest Work Center, load the testflow and its setup files.
  2. To open the Datalog Control tool, click 93000 > Datalog > Datalog Control in the EWC.
  3. In the Setup tab of Datalog Control tool, set the data log profile and the lot information.
  4. In the File tab of Datalog Control tool, set the data log and lot summary output information.
  5. To start the data log for the following executions, click Start Lot in the Datalog Control tool .
  6. In the EWC, execute the testflow. The text data log file is created as you specified.
  7. To test another device, change the DUT and execute the testflow again.
  8. (optional) If needed, you can generate the partial lot summary for the tested devices.
  9. After the whole lot is tested, generate the lot summary for the tested devices. The specified STDF data log file and the lot summary file in the Datalog Control tool are generated.

Results

The data log files and the lot summary file you specified are generated.

What to do next

Check and analyze the test results

Functional changes

  1. Introduced in SmarTest 7.2.0
  2. SmarTest 7.2.2: The Datalog tab and the Summary tab are merged to the File tab.
