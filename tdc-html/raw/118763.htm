STIL Reader performance

The performance of STIL Reader is affected by several factors. By configuring the system properly, you can ensure that conversions are performed as quickly as possible.

System factors

Usually, the processor speed is the limiting factor. The faster the processor, the quicker the conversion will happen.

However, poor disk performance may limit the conversion speed even with fast processors. Optimal disk performance is offered by high-performance drives, while network file systems with low bandwidth can negatively impact performance. Putting the source and the target files of a conversion on different physical drives can also enhance performance.

Settings

The main performance-affecting settings are gzip_patterns and use_vecc (both of which are documented in Test-processing STIL Reader setup options). Switching on both types of compression they control results in faster disk read and write times and smaller files.

File content

Signal assignment in pattern statements is a computationally intensive task. Patterns with many vector statements (for narrow signal interfaces) require more processing time than patterns of the same size with fewer vector statements (for wider signal interfaces).
