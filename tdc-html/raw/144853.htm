restoreRange()

Restores the very first current measurement range specified in the RDI_BEGIN() ... RDI_END() block.

The function is to be used to restore the current range after an auto-ranging current measurement.

Supported only by DC Scale DPS128/DPS64 cards and the DC Scale XPS256 card. The function can be used only in the pattern‑based mode.

Syntax

dcBase& restoreRange();

Return Value

A reference to the dcBase object.

Example

RDI_BEGIN();

    rdi.dc().pin("DSP128_1").iMeas().execute();
    rdi.dc().pin("DSP128_1").restoreRange().execute();

RDI_END();

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 2.4.2: DC Scale AVI64 card added.
  3. SmartRDI 7.5.0: DC Scale FVI16 card added.
  4. SmartRDI 7.10.1: DC Scale XPS256 card added.
