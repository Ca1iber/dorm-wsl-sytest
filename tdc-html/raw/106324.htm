Topic 106324

Values

The DUT Representation Language (DRL) supports integers as values. Strings and other types of data are not supported, although in some places, tuples of integers are used as values. Exception: Strings are supported as the values for the deviceName and deviceDirectory system variables.

Fractional values are truncated, for example:

  • 36/10 becomes 3
  • -36/10 becomes -3

Integers

Integers are specified in the usual way, for example: 3, -2, 0, 12345.

Tuples

Tuples are ordered sets of values, enclosed in parentheses and separated by commas that are used in some functions and system variables. For example: (0,-1,0,1).

Tuples can contain tuples. For example: (0,1,(2,3,2),0).

Tuples in assignment statements can contain variables and expressions instead of literal values.
