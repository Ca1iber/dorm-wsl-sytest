PIN_ERROR_MAP_TEST

This API gives in conjunction with the API ERROR_MAP_TEST detailed access to functional test results like error counter and fail cycles stored in the respective test processor resources like hardware error counter and error map.

Note The ERROR_MAP_TEST and PIN_ERROR_MAP_TEST API only support PinScale test system.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PinErrorMap.h.

Class definition

Constructor

No public constructor available. You can get an instance of this class through the ERROR_MAP_TEST API and use the member functions after the instance.

Member functions

setStartCycle()

PIN_ERROR_MAP_TEST& setStartCycle(const LONG startCycle);

Sets the first cycle to be recorded. Access to failures before this cycle is not possible. If this method is never called, start cycle 0 is assumed.

Parameter

startCycle

First cycle to be recorded in the error map.

setLocation()

PIN_ERROR_MAP_TEST& setLocation(const TM::ERROR_MAP_LOCATION location);

Specifies where the recording of the cycles is to be stored, in the test processor or in the vector memory. This is similar to the DCRT firmware command.

If the setLocation function is not called, the results are stored in the test processor.

Parameter

location

The location of the error map:

  • TP: test processor
  • RAM: vector memory

setRecordingMode()

PIN_ERROR_MAP_TEST& setRecordingMode(const TM::ERROR_MAP_RECORDING_MODE recMode);

Specifies the recording mode, pass/fail or pass/fail code:

  • In pass/fail mode, one bit is recorded per cycle. A 1 indicates a fail, a 0 indicates a pass.
  • In pass/fail code mode, two bits are recorded for each cycle, indicating the relationship between expected and received result, as per the following table.

This function is not available when the cycle mode was set to x-mode cycles in ERROR_MAP_TEST.

This function calls the DCRM firmware command.

Parameter

recMode

The type of result recorded for each cycle (as described above):

  • PF: pass/fail (one bit)
  • PFC: pass/fail code (two bits)

getErrorCount()

LONG getErrorCount();

Returns the number of recorded failures for the pin. It uses the ERCT command to do so.

This function works only for PIN_ERROR_MAP_TEST objects that havebeen created for only one pin.

getFirstFailingCycles()

LONG getFirstFailingCycles(const LONG_LONG startCycle,
                           const LONG_LONG number, ARRAY_LL& cycles);

LONG getFirstFailingCycles(const LONG_LONG startCycle,
                           const LONG_LONG number, ARRAY_LL& cycles,
                           Boolean& fewerFailsReturnedDueToEmapFull);
Note

The second syntax should be used to check that the requested number of failing cycles can be recorded in the error map: Parameter fewerFailsReturnedDueToEmapFull will be set to TRUE in case the error map is full and less than the requested number of failing cycles to list (parameter number) is available.

This check will not be done for the first syntax.

The number failing cycles that follow startCycle are listed in the cycles array.

The return value of the function is the number of cycles recorded in the cycles array.

For example, consider these test results:

Given these recorded results, calling getFirstFailingCycles(4,3,myResultArray) produces these values in myResultArray: {4,7,9}.

This function works only for PIN_ERROR_MAP_TEST objects that have been created for only one pin.

Parameters

startCycle

The cycle from which to list the failing cycles.

Parameter startCycle must be within the recorded error map range or an error is thrown.

number

The number of failing cycles to list

cycles

The array in which the found failing cycles are to be stored
fewerFailsReturnedDueToEmapFull Boolean value:
  • TRUE: Error map is full and less than the requested number of failing cycles to list (parameter number) is available.
  • FALSE: The requested number of failing cycles to list (parameter number) is available.

getFailingCyclesInRange()

LONG getFailingCyclesInRange(const LONG_LONG startCycle,
                             const LONG_LONG length, ARRAY_LL& cycles);

The failing cycles among the length cycles that follow startCycle are listed in the cycles array. In other words, all failing cycles from startCycle to (startCycle + length - 1) are listed in the cycles array.

The return value of the function is the number of cycles recorded in the cycles array.

For example, given the failing cycles listed in getFirstFailingCycles(), above, calling getFailingCyclesInRange(4,3,myResultArray) produces these values in myResultArray: {4}.

This function works only for PIN_ERROR_MAP_TEST objects that have been created for only one pin.

Parameters

startCycle

First failing cycle

Parameter startCycle must be within the recorded error map range or an error is thrown.

length

Length of range

Note: The function will throw an error if the requested range is longer than recorded by the error map and the error map is full.

cycles

Result object

getPassFailResultsInRange()

LONG getPassFailResultsInRange(const LONG_LONG startCycle,
                               const LONG_LONG length, ARRAY_BOOL& pfResults);

After this call the array passed as parameter result contains a list of pass/fail results for the given pin between cycles startCycle and startCycle+length. The return value is the number of cycles (that is the size of the array pfresult).

This function works only for PIN_ERROR_MAP_TEST objects that have been created for only one pin.

Parameters

startCycle

First failing cycle

Parameter startCycle must be within the recorded error map range or an error is thrown.

length

Length of range

Note: The function will throw an error if the requested range is longer than recorded by the error map and the error map is full.

pfResults

Result object

getExpectedDataForCycles()

LONG getExpectedDataForCycles(const ARRAY_LL& cycles, ARRAY_CHAR& expData);

The expected data for the cycles specified in cycles are listed in the expData parameter. One character is returned for each cycle. The characters correspond to the state characters visible in the pattern debug tool.

The return value of the function is the number of cycles for which data was returned (that is, the size of expData).

Restrictions

This method can only be used if both of these are true:

  • The PIN_ERROR_MAP_TEST object has been created for only one pin.
  • Each cycle (user or tester cycle, depending on the mode chosen) contains only one edge.
Parameters

cycles

The cycles for which the expected values are to be listed

expData

The array in which the expected data is to be stored

getExpectedDataInRange()

LONG getExpectedDataInRange(const LONG_LONG startCycle, 
                            const LONG_LONG length, ARRAY_CHAR& expData);

The expected data for length cycles, beginning with startCycle, are listed in the expData parameter. One character is returned for each cycle. The characters correspond to the state characters visible in the pattern debug tool.

The return value of the function is the number of cycles for which data was returned (that is, the size of expData).

Restrictions

This method can only be used if both of these conditions are true:

  • The PIN_ERROR_MAP_TEST object has been created for only one pin.
  • Each cycle (user or tester cycle, depending on the mode chosen) contains only one edge.
Parameters

startCycle

The first cycle for which the expected values are to be listed

length

The number of cycles for which the expected values are to be listed

expdata

The array in which the expected data is to be stored

getLastCycleExecuted()

LONG_LONG getLastCycleExecuted();

This function returns the last cycle executed.

Example

ERROR_MAP_TEST emap(TM::XMODE_CYCLES);
ON_FIRST_INVOCATION_BEGIN();
  FUNCTIONAL_TEST();
ON_FIRST_INVOCATION_END();
ARRAY_LL CP_FFC;
ARRAY_CHAR CP_expected;
emap.pin("CP").getFirstFailingCycles(0,10, CP_FFC);
emap.pin("CP").getExpectedDataInRange(3, 10, CP_expected);

In this example, an error map test is executed in x-mode cycles. Then the first 10 failing cycles of pin CP is retrieved and stored in CP_FFC. The expected data in range 3 to 12 cycle of pin CP is retrieved and stored in CP_expected. getFirstFailingCycles() and getExpectedDataInRange() are member functions of PIN_ERROR_MAP_TEST.
