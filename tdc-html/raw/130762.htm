TestsuiteProxy.setTestmethodParameterValues()

This function sets values to the test method parameters. Only the specified parameters will be changed. The order of the parameter to set must be the same as the parameter definition order in test method.

Syntax

void setTestmethodParameterValues(const std::map<std::string, std::string>& params);
Parameters

params

The name-value pair of the test method parameters.

Functional changes

  1. Introduced in SmarTest 6.5.2
