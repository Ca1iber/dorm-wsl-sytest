rdi.cogo().wait()

Specifies a system wait time that occurs after pass or fail judgment. Within this time, SmartRDI waits for the pass/fail judgment to be propagated.

If you do not specify a value for this function, SmartRDI uses the EPRC? firmware command to automatically calculate an appropriate time period for waiting.

If you specify a value for this function, SmartRDI checks whether this specified wait period is long enough. If the period is not long enough, the report window displays an event message, for example, cogo().wait(0.001) is not enough at port A to make cogo judgment. It needs 0.2 us at least for this cogo node.

See system reserved time for the definition of system reserved time.

Syntax

rdi.cogo().wait(double);
rdi.cogo().wait();

Example

rdi.cogo().node("this").passNode("id1").failNode("id2").begin();
    ...
    rdi.cogo().wait(100 us); // SmartRDI checks whether this time period is long enough.
rdi.cogo().node().end(); //

For more examples, see Structures of multiple cogo() nodes.

Related information

EPRC? - (Error Propagation Repetition Count)

Functional changes

  1. Introduced in SmartRDI 2.4.0
