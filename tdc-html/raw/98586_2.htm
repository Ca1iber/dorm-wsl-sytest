EDGE? - (EDGE errors)

The EDGE? query returns, for each pin in pinlist, the edges which failed during a functional test.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

EDGE? {(pinlist)}

returns: 

EDGE {fail_string},{(pinlist)}

for each group of consecutive pins having the same result.

Parameters

pinlist

The name of the pin or pins for which edge direction definitions are to be read back. This parameter can also include groups previously created by the DFGP (DeFine GrouP) command. The symbol @ can be used to specify all configured pins. If more than one pin is to be included, the names must be separated with a comma.

fail_string

One character per edge. F means failed and . means not failed.

Application

Error map.

Example

> EDGE? (pin1, pin2, pin3, pin4)
< EDGE ...F.... (pin1,pin2)
< EDGE .F..F... (pin3)
< EDGE ..F..... (pin4)

Functional changes

  1. Introduced before SmarTest 6.3.2
