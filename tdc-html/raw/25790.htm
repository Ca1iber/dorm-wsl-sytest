Current Force Mode

In the current force mode the PPMU is programmed to force a specified current that flows through the pin while comparing the resulting voltage against specified limits. Again a set of vectors may be executed to condition the DUT before the actual DC measurement takes place. In case currents cannot flow (for example, due to bad connections) the resulting voltages can grow to rather high levels that are outside the power supply voltages of the DUT. This must be considered when setting up PPMU tests in this mode. In contrast to the voltage force mode the PPMU cannot be brought to a settled condition before the PPMU relay connects the PPMU to the DUT since the current cannot flow before the relay is actually closed.

Consequently, the PPMU is in a voltage force mode until the PPMU relay is closed. This precharges all PPMU nodes to a voltage that can be specified in the test setup. This precharging minimizes the capacitive loading when connecting the PPMU to the DUT and minimizes voltage glitches that occur if currents would be forced into an open relay. After closing the PPMU relay the PPMU is immediately switched to the current force mode and the specified current is forced at the DUT pin.
