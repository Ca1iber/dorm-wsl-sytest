Topic 118322

Installing the operator console

This topic describes how to configure the system controller and how to connect the operator console.

Before you begin

CAUTION Always use the operator console with batteries loaded. If you use the console without batteries and disconnect it while running SmarTest, whether by chance or by purpose, SmarTest may freeze.
Note Check the state of the batteries before using the console. See the information of the battery vendor for handling instructions.
  • At least one work order has to be set up. More prerequisites on the system controller for working with work orders may be necessary.
  • For details on work orders, see Working with workorders.
  • The system controller is running but SmarTest is not started yet.

Procedure

  1. Log in as root and open a terminal window.
  2. Change to the directory /etc/sysconfig/network-scripts/.
  3. In this directory, create the file ifcfg-usb0 with the following content: 
    DEVICE=usb0
BOOTPROTO=static
IPADDR=192.168.129.200

BROADCAST=192.168.129.255
NETMASK=255.255.255.0
NETWORK=192.168.0.0
ONBOOT=yes
  4. Save and close the file.
  5. Connect the mini USB connector to the operator console.
    Note

    To identify the USB ports refer to the appropriate product guide:

    Z4 G4: Z4_Maintenance_Service_Guide.pdf

  6. Connect the USB cable to the USB extension cable.
  7. Connect the USB extension cable to the system controller.
    Note If you use the operator console without batteries, the console boots immediately when you connect it to the system controller. In this case skip the next step.
  8. On the operator console, press the power button.

    The console starts to boot. This may take several minutes.

  9. Wait for the operator console to boot until the boot screen ("Angstrom") disappears.
  10. Check the communication between the system controller and the console:
  11. On the system controller, type:

    DISPLAY="192.168.129.201:0.0" xterm

    On the screen of the console a terminal opens.

  12. Close the terminal window: On the system controller keyboard, press Ctrl+C.

Results

The operator console is set up ready for data communication with the system controller.

Make sure that the operator console has booted properly before starting SmarTest.

What to do next

Adapt the org file as described in Adapting the org file.
