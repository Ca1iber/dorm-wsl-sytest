Version 7.6.2 / 7.10.1 / 8.4.3

Versions 7.6.2 / 7.10.1 / 8.4.3 cover the following newly introduced features and new or updated drawings and topics.

New hardware
  • Link Scale USB3 card: The Link Scale USB3 card supports software-based functional tests and high‑speed I/O (HSIO) scan tests using the USB protocol. A matrix in the front‑end of the card supports also routing signals of other DUT board resources to the DUT.
New drawings
  • Design kit for the PMUX Wing Stiffener in MUX cards design data

    DUT boards using the PMUX Wing Stiffener provide additional application space on the left and right side.

    Note: The content of former topic "MUX cards PCB layout and stiffener info for Direct-Probe" (150942) has been integrated into topic MUX cards design data.

New topics
  • Wave Scale Wideband pogo pin assignment

    The Wave Scale Wideband (WSWB) card provides modulated wideband (up to 2 GHz) signal stimulus and measure capabilities.

Version 7.6.1 / 8.4.2

Versions 7.6.1 / 8.4.2 cover the following newly introduced features and new or updated drawings and topics.

New hardware
  • E8023PB pogo cable assembly: 2 VHD pogo blocks:

    The E8023PB pogo cable assembly connects the DPS64 via two VHD pogo blocks to the DUT board.

    Pogo cable assembly E8023PB is supported by SmarTest 7.5.4.4, 8.3.4.2, and higher.

    The E8023PK pogo cable assembly connects the DPS128 via four VHD pogo blocks to the DUT board.

Additional information
The "DUT Board Design Guidelines" of SmarTest 7 (Topic 105096) have been merged with the SmarTest 8 version of the guidelines. The combined "DUT board design reference" covers all currently supported V93000 systems and is available for SmarTest 7, SmarTest 8 and as stand-alone package.

The "HSM DUT Board Design Guide" (Topic 94277) has been fully integrated into the "DUT board design reference". The HSM-specific topics are available as sub-topics of HSM DUT board design that holds also a sitemap with all common sections.
