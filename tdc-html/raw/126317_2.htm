Topic 126317

Editing field details

About this task

This task describes how to create or edit protocol field details, like symbols and encoding/decoding functions.

Procedure

  1. Select a field within the structure of the protocol.
  2. Enter the overall length of the field in state characters into the Length field.
    Note If you rename the field here, the protocol structure will be updated accordingly. You may disable this propagation feature in the preference settings of the protocol editor.
  3. If required, click New in the symbol section to add a new symbol.
  4. Double-click into the Value field behind the symbol's name to enter the corresponding value.
    Note You have to select a direction if you enter a symbol.
    Note The selected direction will determine the direction of the whole field and thus of all associated symbols!
  5. Enter the field's encode function in the Function section.
  6. Save your modifications by pressing the CTRL + S key combination simultaneously.

Results

You have defined the selected field along with the corresponding symbols.

What to do next

If not already done, you now should assign resource pins to your protocol as described in Assigning pin roles and protocols.
