Topic 136294

Setting up a shmoo test with the Shmoo Tool

Subtopics

  1. The parameters for the x/y-axis setups for a shmoo test
  2. Test modes

Use the Properties view of a shmoo page to set up a shmoo test.

About this task

Use the Shmoo Tool to create:

  • Shmoo over functional tests
  • Shmoo over one or multiple test suites
  • Customized shmoo tests when you have created a customized shmoo test method
  • Fail bit count shmoo tests for MTP

For descriptions of these different shmoo tests, see Shmoo tests in the Shmoo Tool.

In the editor view, select a shmoo page. In the relative Properties view, set up a shmoo test by configuring the parameters as the steps below.

Before you begin

  • In SmarTest, open a testflow and load its full setups.
  • Open the Shmoo Tool and make sure a shmoo page is displayed in the shmoo editor.

    To create a shmoo page, use the New command after you right-click the bottom bar of the shmoo editor.

  • If you want to create a fail bit count shmoo test for MTP, make sure the MTP software is installed.

Procedure

  1. To create shmoo over one or multiple test suites:
    Note Skip step 1 to create shmoo over functional tests or fail bit count shmoo tests for MTP.
    1. In the Testmethod field, choose the ac_tml.AcTest.Shmoo test method.
    2. Expand the Testmethod group.
    3. In the shmooTestSuite field, select one or more test suites that have the same primaries (multiple test suite names should be separated with ";"). After that, the Primaries group in the current Properties view will disappear. When shmooing, the shmoo test will automatically use the primaries of the shmooed test suites.

      Entering one test suite name will shmoo over this test suite.

      Entering multiple test suite names will shmoo over each of these test suites one by one and generate a pass/fail shmoo plot. Each shmoo cell is filled up with either Pass or Fail. Pass indicates all test suites are pass at this cell. Fail indicates at least one test suite is failed at this cell. Note that to shmoo over multiple test suites, you must select pass/fail in the testMode field.

    4. Go to Step 4.
  2. Expand the Primaries group and set up the Timing, Level, Analog, Context, and Pattern primaries.

    For Timing, Level, and Context, you must select a timing set, a level set, and a context.

    For Analog, only set it up when you create a customized shmoo test which has analog settings.

    For Pattern:

    • Do select a pattern for shmoo over functional tests and fail bit count shmoo tests for MTP.
    • It is optional for customized shmoo tests, depending on whether the shmoo test uses a pattern or not.
  3. In the Testmethod field, select one of the following shmoo test methods:
    • ac_tml.AcTest.Shmoo (default): A system provided test method, which can perform shmoo functional test and shmoo over test suite.
    • A customized shmoo test method, which is available only if you have created it: Select it for setting up a customized shmoo test.
    • MTP_FailBitCountShmoo.Execute (available only for MTP): Select it for setting up a fail bit count shmoo test in memory testing.
  4. Expand the Testmethod group and set up the test method parameters:
    • title: The title of a shmoo plot. The default title is "shmoo". The title will be displayed on the shmoo plot after execution.
    • shmooTestSuite: Names of the test suites to be shmooed. Skip this parameter for a shmoo functional test and for a fail bit count shmoo test.

      For shmoo over test suites, select one or multiple test suites that have the same primaries. See more details in step 1.

      For customized shmoo tests, it is optional depending on the setups of the customized shmoo test method.

    • x: X-axis setups. Expand the x group and set up the parameters, described in The parameters of x/y-axis setups.
    • y: Y-axis setups. Expand the y group and set up the parameters, described in The parameters of x/y-axis setups.
    • isYAxisFirst: The default is OFF. ON or OFF to create or not create a Y-first shmoo (the y parameter is varied first, then the x parameter). OFF will create an X-first shmoo (the x parameter is varied first, then the y parameter).
    • testName: The test name for the shmoo test. The default name is Shmoo.

      You can enter a test name which has been defined in the test table or testflow limits.

    • Testmode: The default mode is pass/fail. The modes selected here determine what kinds of test results will be displayed on the shmoo plot, such as pass/fail, error numbers, or measured values. See the available test modes in Test modes.

      For fail bit count shmoo tests for MTP, the default mode is fail bit count on device.

      For shmoo over multiple test suites, do select the pass/fail mode.

      You can select multiple modes here. After execution, to view the shmoo plots of different modes, right-click the shmoo plot, select Test Modes and select one test mode.

    • resultPins: Used only for shmoo over functional test and for fail bit count shmoo for MTP.

      Pins that contribute to the shmoo result. The default is all pins (@).

      If you select @, you cannot select ON in the perPinResult field (see next parameter).

      For fail bit count shmoo tests for MTP, the result pins must include dq pins. Otherwise, no numbers will be disaplayed on the shmoo plot.

      Note that, to create result pins for shmoo over test suite, or for customized shmoo tests, see Viewing the test results of a test suite on a shmoo plot.

    • perPinResult: Used only for shmoo over functional test. The default value is OFF.

      ON or OFF enables or disables you to view the shmoo plot of each result pin that is selected in the resultPins field (see the above parameter).

      If you select ON, to view the shmoo plot of different result pins, right-click the shmoo plot, select Result Pin, and select a desired pin.

    • For additional test method parameters used only with the fail bit count shmoo test method (MTP_FailBitCountShmoo.Execute), see Fail bit count shmoo test method.

Results

A shmoo test is set up with the Shmoo Tool.

What to do next

  • Execute and view the shmoo plot in the current shmoo page.
  • Save the shmoo test with the Shmoo Tool
  • Create new shmoo pages to set up other shmoo tests in the Shmoo Tool

Functional changes

  1. Introduced in SmarTest 7.2.0
  2. SmarTest 7.2.1: The setup panel of the Shmoo Tool is removed from the shmoo page. Instead, use the Properties view to set up a shmoo test.
  3. SmarTest 7.2.1: For the shmoo over test suite setup, the Primaries group in the Properties view disappears.
  4. SmarTest 7.2.1: For the shmoo over test suite setup, the resultPins and perPinResult parameters are invisible.
  5. SmarTest 7.2.2: The shmooTestSuite parameter accepts multiple test suite names to support shmoo over multiple test suites.
