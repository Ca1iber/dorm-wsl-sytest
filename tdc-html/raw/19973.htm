Entering the Vectors

Subtopics

  1. In General
  2. For Sequential Capturing
  3. For Selective Capturing
  4. Incorporating Vectors from Other Sources

After a main pattern for Digital Capture has been defined, you can enter in the pattern debug tool the actual vectors which contain the input data of the device and the expected output data.

Entering the vectors is done in the normal way.

However, there are some special aspects which should always be considered when setting up vectors for Digital Capture. These special aspects are described in this section.
