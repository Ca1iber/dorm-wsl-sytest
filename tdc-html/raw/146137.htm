EVENT_WAVEFORM_VFIM.getSampleVectorDistance()

Queries the distance between sample vectors.

Syntax

void getSampleVectorDistance(INT & vectors) const;
Parameter
Parameter Description
vectors

Number of vectors defining the distance. Minimum is 32 vectors.

Return value

The sample vector distance as an INT.

Example

For an example see EVENT_WAVEFORM_VFIM.
