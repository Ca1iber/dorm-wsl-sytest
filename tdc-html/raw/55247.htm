Topic 55247

Saving a modified pin configuration

Before you begin

CAUTION Setup data becomes invalid when there is a change in the pin configuration. Never save the setup (except the pin configuration) immediately after modifying the pin configuration! You would overwrite valid setup files with invalid data or no data.

You have modified the pin configuration file.

Procedure

  1. In the Project Explorer view, right-click the modified item and select Apply.
  2. Save the pin configuration.
  3. Reload all other setups from the setup files.
