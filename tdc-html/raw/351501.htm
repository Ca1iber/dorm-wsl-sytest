Topic 351501

Register compare

Register operation is to read a complete register and compare to an expected value with or without a mask.

If you do not use an ID in your register compare operation, you can only retrieve the global pass/fail result.

If you use the same ID in both the compare command and the result retrieval command, you can retrieve the compare result for the specific register compare operation.

You can still put a read operation in the same RDI_BEGIN/RDI_END block.

Examples

Example 1

Register compare without ID.

RDI_BEGIN();
  reg.PERIPHERAL0().REGISTER0().setValue(0x55).compare();
  // or
  // RA_COMPARE(0x1234, 0x55);
  // RA_COMPARE(0x1234, 0x55, 0xFE);       // 0xFE is mask.
  ...
RDI_END();

bool pf = GET_FUNCTIONAL_RESULT();  // Only global pass/fail.

Example 2

Register compare with the same ID in the compare command and the result retrieval command.
RDI_BEGIN();
  reg.PERIPHERAL0().REGISTER0().setValue(0x55).compare("COMP_ID");
  // or
  RA_COMPARE("COMP_ID", 0x1234, 0x55);
  // or
  RA_COMPARE("COMP_ID", 0x1234, 0x55, 0xFE); // 0xFE is mask.
  
  RA_READ("READ_ID", 0x1234 ); // READ can be used in the same block.
  ...
RDI_END();
const CompareResult& cr = RA_GET_COMPARE_RESULT("COMP_ID"); // the same ID with the compare command.
// cr.getPassFail();  cr.getExpectedValue();  cr.getReceivedValue()

Functional changes

  1. Introduced in SmartRDI 7.6.0
