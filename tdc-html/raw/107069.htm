Topic 107069

Breakpoints View

This view shows all breakpoints that you set, and know which breakpoints have optional code snippets (conditional breakpoints). You can also remove breakpoints and temporarily disable a breakpoint without losing the information it contains.

Toolbar

Icon

Command

Description

Remove Selected Breakpoints

Removes the selected breakpoint(s).

Remove All Breakpoints

Removes all breakpoints in this view.

Show Breakpoints Supported by Selected Target

This option can be toggled to show the breakpoints applicable to the selected debug target.

Go to File for Breakpoint

If the resource containing the selected breakpoint is not open and/or active, this command causes the file to be opened and made active, focusing on the line with which the breakpoint is associated.

Link with Debug View

Toggles whether the breakpoints in this view are linked to the Debug view. When this option is turned on, the Debug view automatically shows the breakpoint position on a process.

Skip All Breakpoints

Disables all breakpoints by force. To enable them, toggles this again.

Menu

Click the triangle icon to open a menu of items specific to this view. You can select a menu item from a shortcut menu.

  • Show Test Method Locations

    This option can be toggled to show or hide a path for the class source file.

  • Show Full Paths

    This option can be toggled to show or hide a path for the current source file.

Minimize

Minimizes this view.

Maximize

Maximizes this view.

Shortcut menu

Menu Item

Description

Go to File

If the resource containing the selected breakpoint is not open and/or active, this command causes the file to be opened and made active, focusing on the line with which the breakpoint is associated.

Select All

Selects all breakpoints in this view.

Copy Variable

Copies a text representation of all selected expressions and variables onto the clipboard.

Enable

Enables the selected breakpoints.

Disable

Disables the selected breakpoints.

Remove

Removes the selected breakpoints from this view.

Remove All

Removes all breakpoints from this view.

Properties

Opens a breakpoint properties dialog for the currently selected breakpoint.

Functional changes

  1. Introduced before SmarTest 6.3.2
