BADC_MEASURE

Subtopics

  1. BADC_PIN_MEASURE

The BADC_MEASURE class is a data container holding the contents of the task for setting up measurement operations of BADCs. This class can be used to call the BADC_PIN_MEASURE class that is a subsidiary data container to set up per pin measurement mode for BADCs. This class also contains the member functions to retrieve test results.

Measurements defined with this class, will be performed with the PATTERN_CONTROLLER class. Results of this measurement are available with the DC_RESULT_ACCESSOR.

Note

The typical time required for a BADC or PPMU measurement can be calculated as follows:

twait = (25 μs + N * 4 μs)
where: 25 μs is a one-time overhead
"N" is the number of samples

After the measurement is performed, SmarTest needs an additional time (typical) of 20 μs * N, where N is the number of samples, to fetch the results. For this additional duration of time, the BADC cannot be used to perform a new measurement.

In additional, an extra wait time of, at least, 60 μs must be added for the first BADC measurement after switching the measurement mode on one channel for EXA Scale digital cards or Smart Scale digital cards in Exa Scale compatibility mode.

CAUTION You must turn off site matching (see Controlling the site match function) when sharing BADC(s) over sites, to ensure proper pattern-controlled DC value measurements with the BADC.

Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/BadcMeasure.h.

Constructor
BADC_MEASURE();

This constructor defines a Board ADC measurement task holding the number of samples for the measurement.

Parameters
There are no parameters associated with the constructor.
Member functions
  • pin()
  • wait()
Using the API

For creating an object:

BADC_MEASURE <object>;

For setting up measurement mode of BADCs:

<object>.pin("pinlist").<member_func>;
<object> Object name to be defined
pinlist Target pin name or pin group name of this class. You can specify multiple pins and pin groups by separating with a comma or using "@" which means all pins. "@" includes the digital pins that are wired to an analog module on the DUT board for a trigger source.
<member_func> Member functions of the BADC_PIN_MEASURE class

Member functions

pin()
BADC_PIN_MEASURE & pin(const STRING &pinlist);

This function returns the reference to the BADC_PIN_MEASURE class object that represents the number of samples for the specified pin. To add an action to the task, use the member functions of the BADC_PIN_MEASURE class.

Parameter
Parameter Description
pinlist Target pin name or pin group name of this class. You can specify multiple pins and pin groups by separating with a comma or using "@" which means all pins. "@" includes the digital pins that are wired to an analog module on the DUT board for a trigger source.
Return value
A reference to the BADC_PIN_MEASURE object.
wait()
void wait(const DOUBLE time);

This function sets a time to wait when the task defined with BADC_MEASURE is executed.

Parameter Description
time The time to wait. Default unit is [s]

Example

Set to per pin value measurement

...
BADC_MEASURE meas1;
meas1.pin("p1");
...

This example defines a task to set the "p1" pin to execute a board ADC value measurement.
