Topic 111089

GET_TESTHEAD_TEMPERATURE

This API gets the temperature of the specified card or gets the highest temperature of the selected type of cards. The unit of the returned temperature is Kelvin.

Syntax

DOUBLE GET_TESTHEAD_TEMPERATURE(const STRING& boardType = "ALL", INT board_id = -1);
This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestheadTemperature.h.
Parameters
Parameter Description

boardType

The optional type of card to retrieve the temperature. It can be

  • DIGIO for digital IO boards and DC scale boards;
  • PDPS for DPS boards;
  • CLK for clock boards;
  • ALL (default) for all the above three types of boards.

board_id

The optional card ID can be

  • the card number (or pogo block number) of the logical channel board (three digits)
  • or the Clock Board number (11, 12, 21, 22, ..., 41, 42),
  • or an identification number of the DPS card (101 to 108).
Return value

The temperature of the specified card or the highest temperature of the selected type of cards as double value. The unit of the returned value is Kelvin:

  • The highest temperature of the selected type of cards will be returned if parameter board_id is not specified.

  • The highest temperature of the selected type of cards will be returned if a specified particular board_id is not available. The following message message will be shown:
    Warning: the board id: ### is invalid.
The highest temperature of this kind of board is returned.

  • -999 will be returned if a particular boardType has been specified but no card of this type is available.

  • Default value in offline mode is 292.3 K.

Example

double temperature = GET_TESTHEAD_TEMPERATURE (DIGIO, 101);
double temperature = GET_TESTHEAD_TEMPERATURE (PDPS, 116);
double temperature = GET_TESTHEAD_TEMPERATURE (CLK, 11);

In offline mode, all the above calls will return the value 292.3 with the unit Kelvin.
