SATR, SATR? - (System ATtRibutes)

The SATR (System ATtRibutes) command sets the common receiver delay. The value you enter is an offset to the previously calibrated value. Using the SATR? command returns the existing value.

SATR

SATR {comm_rec_delay}

SATR?

SATR?

returns:

SATR {comm_rec_delay}

Parameters

comm_rec_delay

The common receiver delay represents the adjustment to the round-trip delay between the drivers and receivers. The delay is in [ns] and must be in the range -50 to +50. Three digits are allowed after the decimal point. The default value is 0.

Application

Calibrating the digital channels.

Errors

An error is generated if the parameter is out of range.

Example

SATR 20

This example sets the common receiver delay to 20 ns.

Functional changes

  1. Introduced before SmarTest 6.3.2
