Introduction

The event data logging provided with SmarTest is a powerful tool for retrieving data from the entire production test. Event data logging is fully event based. This makes production test data accessible immediately after it was generated during the test run.

The included Event Formatter, a report formatting tool, provides access to the full capabilities of event data logging.

The main features and benefits of event data logging are:

  • Production test data is immediately accessible after it is generated during the test run.
  • The Event Formatter, a flexible tool with a graphical user interface, provides access to SmarTest's event data logging capabilities.
  • The stream of logged production test data is easily manageable. It will not overload the system memory or the file system.
  • Logged data is available in C data types. This allows for immediate further processing; no additional parsing of output data is necessary.
  • The programming interface lets you write data retrieval and analysis procedures tailored to your individual requirements.
  • Event data logging can be completely turned off if not needed.
  • Future enhancements of the data logging software will not conflict with user-written procedures based on earlier versions.
  • Event data logging co-exists with earlier provided data logging mechanisms which produce GDF output. Thus, user-written tools will not be rendered obsolete by the new concept.

Functional changes
