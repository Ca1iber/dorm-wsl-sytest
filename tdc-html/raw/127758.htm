DRLTestCondition

Variables of the DRLTestCondition type store a key-value pair describing a particular condition of a test.

They are used in DRLTestConditionAttr structs.

Syntax

typedef struct _DRLTestCondition {
char* key;
char* value;
} *DRLTestCondition;

Functional changes

  1. Introduced in SmarTest 7.1.2
