Topic 137777

Setting up additional DC levels and options

Using the reserved "93kExtraLevels" name map, you can set up extra DC levels available on V93000 systems in your STIL files. You can also specify slew rates for DC voltages.

To set up the extra levels or slew rates, create a NameMaps object named "93kExtraLevels" in your STIL file. (The name is fixed; you cannot use a different name.) In this object, create a Signals object.

In the Signals object, list all the signals to which you want to make available the extra levels or options. For each of these signals, specify the settings for the extra levels in a configuration string.

A configuration string consists of a number of parameter value pairs that are separated by commas - "<parameter>=<value>, <parameter>=<value>, ...". These parameters are supported; all of them are optional:

  • offcurr: The off current state of the signal.

    Specify one of these keywords:

    • min: Minimum current for high impedance
    • act: Actual current for low impedance
    • open: High impedance and open output relay

      See DPSPINS resources for more information on these states.

  • t_ms: The connect setup time for rising and falling edges. Specify the number of milliseconds. (Do not include the unit.)
  • term: The termination mode for the signal.

    Specify one of these keywords:

    • cross
    • center_tap
    • single_ended_cross
    • act_load
    • on
    • scope+
    • scope-
    • single_ended+
    • single_ended-
    • off

      See Explicit setting of termination mode for standard/single-ended for more information on these modes.

  • rec_offset: The receiver offset voltage for the differential comparator. Specify the value including the unit (for example, V).
  • vout_fall_t_ms_per_volt_c2c: The inverse slew rate of the falling edge in ms/V for "connect-to-connect" cases. This is the same as the vout_fall_t_ms_per_volt_c2c parameter described in DPSPINS resources.
  • vout_fall_t_settling_t_ms_c2c: The settling time of the falling edge in ms/V for "connect-to-connect" cases. This is the same as the vout_fall_t_settling_t_ms_c2c parameter described in DPSPINS resources.
  • vout_rise_t_ms_per_volt_c2c: The inverse slew rate of the rising edge in ms/V for "connect-to-connect" cases. This is the same as the vout_rise_t_ms_per_volt_c2c parameter described in DPSPINS resources.
  • vout_rise_t_settling_t_ms_c2c: The settling time of the rising edge in ms/V for "connect-to-connect" cases. This is the same as the vout_rise_t_settling_t_ms_c2c parameter described in DPSPINS resources.

Example

STIL 1.0 { Design D22; DCLevels 2002; }

Header {
  Title "Example";
  Date "Sep 30, 2009";
  Source "Sample";
  History { Ann {* Thu Jun 01 08:00:00 2006 -- Initial Revision *} }
}

Signals {
  // Regular signals
  clk In;
  data Out;
  VDD Supply;
}

/* Expected translation is two ports which happen to match Pattern block active signals */
Environment {
  NameMaps "93kExtraLevels" {
    Signals {
      VDD  "offcurr=act, t_ms=10, term=cross, rec_offset=2.3V";
      data "term=cross, rec_offset=2.3V";
    }
  }
}

DCLevels normal {
  VDD {
    VForce '3V';
    IClamp '500mA';
  }
  'clk' {
    VIH '2.2V';
    VIL '0.4V';
    VIHSlew '2.0V';
    VILSlew '0.6V';
  }
  data {
    VOH '1.8V';
    VOL '0.9V';
  }
}

Timing {
  WaveformTable t1 {
    Period '100ns';
    Waveforms {
      clk  { P  { '0ns' D; '25ns' U; '75ns' D; } }
      data  { LH { '50ns' L/H; } }
    }
  }
}

PatternBurst B1 {
  PatList  { 
    P1;
  }
}

// Patterns - no change
PatternExec PE1 {
  DCLevels normal;
  PatternBurst B1;
}

Pattern P1 { 
  W t1;
  V { clk = P; data = L; }
  Loop 30 {
    V { data = H; }
    V { data = L; }
  }
}
