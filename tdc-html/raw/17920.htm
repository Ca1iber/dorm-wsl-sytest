Topic 17920

Keeping Waveform Sets Compatible

The set of vectors required to test a device is always matched to the timing setup. You cannot start setting up vectors if the timing is not finished.

Whenever you test a device you must finish setting up the timing before going on to the vectors. Once the vectors are in place you cannot go back and make major changes to the timing. If you do, the interpretation of the vectors in the vector table will not work correctly and you will send the wrong physical waveforms to the DUT.

Major changes to the timing setup amount to:

  • defining a new device cycle
  • renaming an existing device cycle
  • deleting an existing device cycle
  • copying an existing device cycle
  • defining a SCAN device cycle
  • changing the parameter values for receive pins

If you need to make changes to the timing after you've set up the vectors, you must ensure you do not violate these major change rules given above. System timing is always stored in a waveform set.
