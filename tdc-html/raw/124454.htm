STDE - (Save Test Data Entity)

The STDE command lets you save modified or newly created test data entities (TDEs).

The STDE command always saves all modified or newly created TDEs into the directory specified by the PTDE command.

Syntax

STDE

Example

STDE

Related information

LTDE, LTDE? - (Load Test Data Entity)
PTDE, PTDE? - (Path for Test Data Entities)
UTDE - (Unload Test Data Entity)

Functional changes

  1. Introduced in SmarTest 7.1.0
