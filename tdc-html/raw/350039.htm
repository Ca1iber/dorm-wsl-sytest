Topic 350039

Default levels file for a device

SmarTest provides the two predefined device technologies cmos and ecl in the New Device wizard and in the Change Device wizard. The default levels of the selected device technology can be customized per device using the optional .default_levels file.

SmarTest verifies that levels for all digital pins are defined when the level sets are downloaded to the hardware. For pins that have no definition in the level sets, the following warning is displayed:
line ...: M014: level set ... "..." contains no user definition for "..." default is taken
The applied default values are defined by the selected device technology cmos or ecl. In case, these default values do not match to the needs of your device, they must be customized using the .default_levels file.

The .default_levels file

The optional .default_levels file holds the customized default levels for the currently loaded device. Like the .technology file, the .default_levels file must be stored in the root directory of the device.

SmarTest loads and parses the file when the device is loaded. The following line is displayed in the ui_report window if the file is available:
Setting default levels from /.../.default_levels
Loading of the file is aborted if syntax errors are found, and an error message similar to the following example is displayed in the ui_report window:
ERROR: ../.default_levels:##: DFLV VIL,STD,225: expected resource=voltage. for example, vt=50mV)
If reported syntax errors have been resolved, you must reload the device to apply the changes.

Format of the .default_levels file

The .default_levels file holds one or more level definitions similar to the Equation based level setup but only fixed values can be set for selected resources. The general syntax for all entries is
resource = valueUnit
where resource The resource to be set. Supported resource keywords are defined in the following table.
valueUnit

A numeric value defining a voltage level, directly followed by the unit "V" or "mV".

The unit is mandatory and must follow directly without any whitespace character in between.
The following resources are supported:
Resource specifier Description
vil and vih Input (drive) voltage definition for I and I/O pins.
vihh High voltage level definition for I and I/O pins.
vol and voh Output threshold voltage definition for O and I/O pins.
vol_diff and voh_diff Output threshold voltage definition for O and I/O pins in differential mode.
vt Termination voltage definition.
vcom Commutation voltage of the active load.
rec_swing The receiver swing for a differential comparator.
rec_offset The receiver offset for a differential comparator.

You can define levels for all or only for a part of the supported resources. Multiple definitions of the same resource are supported but only the last definition is taken into account.

Some additional rules for formatting:
  • Whitespace characters at the begin of the line, at the end of the line and within the line are ignored.
  • Whitespace characters between the numeric value and the unit are not allowed.
  • Empty lines are ignored.
  • A hash character (#) at the beginning of a line defines a comment and the entire line is ignored.
  • Only parameters for the STD mode can be set.
For the default values that are defined by the used device technology, see Example 4: Reset all default values to the technology defined values and query all values in DFLV, DFLV? - (DeFaultLeVel).

Filling the .default_levels file

The file can be edited by an external text editor or by the text editor of the SmarTest work center.

Note

The dot file .default_levels is normally hidden. If you are using the text editor of the SmarTest work center, you must disable the filter for the hidden files:

On the toolbar of the Project Explorer view, click the Menu button to open the drop-down menu of display options. Select Customize View..., open tab Filters and deactivate the check-box for .* resources.

Example

.default_levels file

All resources except vol_diff and voh_diff are set to customized default values.

vil         =  2250mV
vih         =  2500mV

vihh        =  7.0V

vol         =  2250mV
voh         =  2500mV

vt          =  2500mV
vcom        =  2500mV

rec_swing   =  0.800V
rec_offset  =  0.500V
