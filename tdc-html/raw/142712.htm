New syntax added for getFailingAddressList()

The getFailingAddressList() member function of MTP_MEMORY_PATTERN is enhanced to retrieve list of failing addresses for a group of data pins with the related failing cycle numbers, and data information.

The retrieved addresses are ordered by failed cycles.

To support this functionality, a new syntax with new data types are added to this member function.

  • New syntax:

    LONG getFailingAddressList(const LONG_LONG first_N_failing_cycle_number, CycleToAddrWordMap& cycleAndAddrWord);

  • New data type: CycleToAddrWordMap

    This data structure contains failing cycle numbers, the corresponding failing addresses and data.

Note

Before this release, getFailingAddressList() only can retrieve failing addresses for a specific pin.

The syntax is:

LONG getFailingAddressList(const int bit_index, const LONG_LONG number_of_addresses, MTP::ARRAY_ADDRESSES& addresses);
