Topic 343510

rdi.route().pin().execute()

The function will create the label for the setups defined by the rdi.route().pin() functions. The related burst pattern will be generated and the burst pattern will be executed when RDI_END() is executed.

Usage of the function:

  • Depending on the target pin, the function can be called in the code‑based mode or in the pattern‑based mode:
    Software‑controlled (static) utility lines: Code‑based mode only
    Sequencer‑controlled (dynamic) utility lines: Pattern‑based mode only
    PMUX switches: Pattern‑based mode only

    For more information, refer to Execution mode in topic SmartRDI.

Syntax

void execute();
List of parameters
There are no parameters.
Return value
A reference to the ROUTE object.

Example
