Creating a multiport burst

A multiport burst is the combination of one or more port bursts that are executed in parallel in a multiport test.

About this task

To create a multiport burst you use the New Multiport Burst dialog. You access the dialog from the Pattern Explorer.

Before you begin

You should have defined already several ports to assign or combine them to a multiport burst.

Note that you cannot assign two or more ports that share the same pins.

Procedure

  1. In the Pattern Explorer, right-click and select New > Multiport Burst. The New Multiport Burst dialog opens.
  2. In the Name field, type a name for the multiport burst.
  3. In the Port Bursts list, select the ports you want to add to the multiport burst.
  4. Optionally you may change the sync group for each selected port.

    Sync groups force ports to always start at the same point in time. Use content assist (Ctrl + spacebar) to select a sync group, or type a name to create a new sync group. Otherwise the DEFAULT sync group is used. You can also change the sync group later in the Pattern Explorer.

  5. In the Folder field, specify the location of the port burst files.
  6. When done click Finish.

Results

The resulting multiport burst (Type = MPBurst) appears in the Pattern Explorer.

Note The port burst files are not written to the specified folder, until you explicitly save the created multiport burst.

What to do next

You can assign further port bursts to the multiport burst.
