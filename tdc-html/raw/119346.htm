Topic 119346

Find and Replace

Procedure

  1. Use Find/Replace to search and replace in single vector cells and in series of vector cells. You can also search for comments.
  2. Do not use the Find/Replace dialog if you are searching for sequencer instructions. Click (Hide all vectors in current editor) instead.
  3. If the "Space is Delimiter" option is selected, you search will be limited to one cell only. If the option is not selected you search will go over multiple cells.

Example

"Space is Delimiter" selected: The string 111 is interpreted as one string.

"Space is Delimiter" not selected: The string 111 is interpreted as a sequence of three consecutive strings of 1.

To search for comments, select the "Space is Delimiter" option. The tooltip displays how the search pattern is interpreted.

You may also use the advanced Find/Replace dialog. To enable it, go to Window > Preferences > Advantest V93000 > Pattern Debug Tool.
