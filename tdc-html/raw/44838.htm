Installing a Program Command Set

To install a program Command Set:

  1. Type the following at the command line:

    /opt/hp93000/soc/prod_env/lbin/install_cs -t PROGRAM

    The install_cs script copies the following into your directory:

    a special Makefile

    the program template pg_templ.c and the script template sc_templ.c

    and a command interface link.

  2. Copy the template file pg_templ.c to the set of source files in which you want to implement the programs for the Command Set. Use the script template sc_templ to generate scripts. Each program has a unique source file. You can ignore the template and generate your own source files. However, this is not recommended, because the template file uses the exact syntax of the mandatory program declaration.
  3. Code your programs (as described in Writing a Program), or code your scripts (as described in Writing a Script).
  4. Type

    /opt/hp93000/soc/system/bin/run -Qx /usr/bin/make depend all

    at the command line. This action compiles each of the source files into a separate executable unit. These units are available to Command Interface when you run the production software. Ensure that all the scripts are executable by using the chmod +x scriptname command.

The install_cs -t PROGRAM can be called as often as required and does not destroy any source files you have created. It does, however, always overwrite the Makefile, the template file pg_templ.c, and the template file sc_templ.c, so do not implement any of your functions in a file with these names.

The make depend command updates the Makefile to make the newly created source files visible to the Makefile. You only need to call make depend when a new sourcefile has been created.

Use the make all command as often as necessary until you get a clean compile.

The implementation is complete when make succeeds without compilation errors.

Coding of programs or scripts must adhere to the rules as defined in the section Program Dependencies, or Script Dependencies.
