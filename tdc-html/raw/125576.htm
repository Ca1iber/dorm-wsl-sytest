Enabling software licenses

All *.lic license files (both system license files and software license files) reside by default in the /opt/flexlm/license directory on both the license client and the license server.

If you have support contracts for several test heads, you will receive several software *.lic files, because every software license is locked to one test system.

Advantest recommends to merge all software *.lic files in one file and distribute this file on the license clients and the license server. This ensures that the software license is available, independent of the client you use to run a test system.

Note Unlike system licenses, software licenses are already activated when you receive them and they are not part of the annual renewal process.

FLEXnet license server

The software licenses require the FLEXnet license server version 11.9 (or higher) from Flexera Software.

The FLEXnet license server version 11.9 is supported on the operating systems Red Hat 5 and Solaris 10.

System serial number must be initialized

The software license is locked to the system serial number of the test head (as with the support contract). The report window shows the system serial number and the master release date. For example: 

System serial number: DExxxxxxx
Master release date: 2011.1

For test systems shipped before May 2010 the system serial number must be initialized. If the system serial number of your test system is not yet initialized, the report window line will be

System serial number: None

In this case, please contact your Advantest service representative.

Limited license usage

The online license component of the software license must be available to start SmarTest in online mode.

In case one ore more licenses are not available, you have several options to start SmarTest from the command line with limited license usage:

HPSmarTest -j

Loads only software licenses

HPSmarTest -n

Loads no licenses at all

For further start options see Starting SmarTest.

Example

A software license file looks like this:

INCREMENT SmarTest_SOC socbu 2011.01 permanent uncounted \
        HOSTID=VSN=DE123456789 ISSUER=FID-23452352345 VENDOR_STRING=123456 
        NOTICE=perpatual_SW_update SIGN="1A42 6036 7B94 1727 5CAE 4868 \
        3DDC 0E04 F389 86E2 CCB5 C3D5 AFEF B3DD DC3F 12F1 6B6A A664 \
        CE31 1F15 93E4 3795 BA72 9BCD 3F38 D527 283B C6AA 634E 7749"

The 2011.01 string in the first line refers to the master release date. With this license you will be able to use all SmarTest release streams with a master release date of 2011.01 or earlier.

Note the difference to system license files as shown in Editing system .lic license files.
