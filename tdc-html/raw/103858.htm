StartLevel()

This API creates a new level and then set the level to active. The EDL event AppModelLevelStartEventType and the HVM event LEVEL_STARTED will be issued if the implicit event generation is turned on.

SUCCESS will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

PARAMETER_EXCEPTION
  • The value of the parameter "LEVEL_TYPE" can only be CUSTOM_LEVEL, WAFER_LEVEL and DEVICE_LEVEL.
  • The value of the parameter "LEVEL_TYPE" is empty.
  • The value of the parameter "LEVEL_NAME" is empty.
  • The value of the parameter "LEVEL_NAME" exceeds the maximum length(79).

RECOVERABLE

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist
  • The local session does not exist
  • The level "XXX" has already been in existence
  • Maximum level number (13) reached.
  • Failed to issue the HVM event
  • Can't start a WAFER level in package test.

RECOVERABLE

Parameters

I/O

Parameter

Description

I

SESSION_ID

The local session ID.

I

LEVEL_TYPE

The level type. It can be CUSTOM_LEVEL, WAFER_LEVEL or DEVICE_LEVEL.

I

LEVEL_NAME

The level name.

Prototype

ParamList inputParams;
Status syncCommand("StartLevel", inputParams, sessionID);

Example

string sid = LOCAL_SESSION_ID; //the local session ID 
ParamList inputParams; 
inputParams["LEVEL_TYPE"] = "WAFER_LEVEL";
inputParams["LEVEL_NAME"] = "wafer";

Status retVal = syncCommand("StartLevel", inputParams, sid);
if ( retVal.isError() ) 
{
cout<<"error code= " << retVal.code() << " description="
   << retVal.text() << endl;
}
