SHMOO_RESULT.index()

Adds an index to the current test name set with SHMOO_RESULT.testName(). After you use this function, the original shmoo test name, for example "VOLPin", changes to "VOLPin[<the index number you have specified with this function>]".

Syntax

ShmooResultAdapter& index(INT index);
Parameter

Parameter

Description

index

The index number you want to add to the current shmoo test name.

Return value

Returns an instance of the ShmooResultAdapter class.

Example

Adds an index number "1" to the shmoo test name "VOLPin".

double meaValue1;
SHMOO_RESULT.pin("P1").testName("VOLPin").index(1).setResult(meaValue1);

Related information

SHMOO_RESULT.testName()

Functional changes

  1. Introduced in SmarTest 7.2.1
