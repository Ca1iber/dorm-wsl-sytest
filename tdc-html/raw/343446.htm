rdi.route().reset()

Resets all switches to the default state.

The function resets all switches, bypassing the possibly set masks.

The default state is defined as follows:

  • Utility line open collector output is off
  • PMUX switch is open
The stored states of the PMUX cards are not cleared.
Note The reset() function also clears the global mask defined with the enableOnlyActiveSites() function.

Usage of the function:

  • The function can be called only in the code‑based mode. For more information, refer to Execution mode in topic SmartRDI.

Syntax

routeGroup& reset();
List of parameters
There are no parameters.
Return value
A reference to the routeGroup object.
