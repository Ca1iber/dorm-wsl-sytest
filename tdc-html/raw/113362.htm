DSP_CONCAT

The DSP_CONCAT API concatenates two arrays.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_CONCAT(ARRAY_D& src1, ARRAY_D& src2, ARRAY_D& result);
DSP_CONCAT(ARRAY_I& src1, ARRAY_I& src2, ARRAY_I& result);
DSP_CONCAT(ARRAY_COMPLEX& src1, ARRAY_COMPLEX& src2, ARRAY_COMPLEX& result);

DSP_CONCAT(DOUBLE *src1, DOUBLE *src2, DOUBLE *result, INT size1, INT size2);
DSP_CONCAT(INT *src1, INT *src2, INT *result, INT size1, INT size2);
DSP_CONCAT(COMPLEX *src1, COMPLEX *src2, COMPLEX *result, INT size1, INT size2);
Parameters

I/O

Parameter

Description/Range

I

src1

Source array 1

 

I

src2

Source array 2

 

O

result

Computed result array

(src1_size + src2_size) ≤ result_size < 2097152

If the size of result arrray is larger than the sum of src1 size and src2 size, only the elements from result[0] to result[src1_size + src2_size -1] are meaningful.

 

I

size1

Number of elements of source array 1

1 ≤ size1 ≤ 2097152

 

I

size2

Number of elements of source array 2

1 ≤ size2 ≤ 2097152

Example

ARRAY_D wave1(100);
ARRAY_D wave2(130);
ARRAY_D wave3;
...
DSP_CONCAT(wave1, wave2, wave3);

The arrays wave1 and wave2 are concatenated and the result is stored in the array wave3. The array wave3 has 230 elements. The 1st to 100th elements are from wave1, and the 101st to 230th elements are from wave2.

Functional changes

  1. Introduced in SmarTest 6.5.2
