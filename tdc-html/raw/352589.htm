Wave Scale RF pogo pin assignment (10 MHz clock)

The 10 MHz clock signal of the WSRF card can be connected to the DUT interface via the pogo block N2605-62101.

Supported V93000 systems : EXA Scale (SmarTest 8), Smart Scale (SmarTest 8)
