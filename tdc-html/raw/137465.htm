Topic 137465

Viewing customized results of a customized shmoo test in the Shmoo Tool

When you have created a customized shmoo test method and have defined the results to be shown on a shmoo plot with the SHMOO_RESULT API, you can use the Shmoo Tool to view the results.

Before you begin

Open SmarTest.

Procedure

  1. Create a customized shmoo test method.
  2. In the test method file, in the userDefinedMeasure() function, define the results to be displayed on a shmoo plot with the SHMOO_RESULT API.
  3. Use the Shmoo Tool to create a customized shmoo test based on this test method.

    Alternatively, create a shmoo test suite with this customized test method.

    When configuring the testMode test method parameter, select "user defined measurement".

  4. If the shmoo test is created with the Shmoo Tool, execute the shmoo test in the Shmoo Tool.

    A shmoo plot displays in the corresponding shmoo editor in the editor view.

    Go to step 6.

  5. If you created a new shmoo test suite, transfer the setups of the test suite to the Shmoo Tool and then execute the shmoo test in the Shmoo Tool.

    The shmoo plot displays in the corresponding shmoo editor in the editor view

  6. On the shmoo plot:
    • To view different results which you have defined with SHMOO_RESULT.setResult() in the userDefinedMeasure() function, right-click the shmoo plot and select Test Modes, and select your desired result.
    • To view different shmoo plot of different pins or pin groups which you have defined with SHMOO_RESULT.pin() in the userDefinedMeasure() function, right-click the shmoo plot and select Result Pin, and select your desired pin or pin group.
    • To view different shmoo plots of different sites which you have defined with SHMOO_RESULT.site() in the userDefinedMeasure() function, see Viewing different site's shmoo plot.

What to do next

In the Shmoo Tool:

  • Zoom the shmoo plot, take a picture of the shmoo plot, or save the shmoo test.
  • Debug this shmoo test through adjusting its setups in the corresponding Properties view.
