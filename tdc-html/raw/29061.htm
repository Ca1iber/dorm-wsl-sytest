DSP_MOVAVG

This API takes a moving average of the specified array's elements.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_MOVAVG(ARRAY_I& src, ARRAY_D& result, 
           INT length);
DSP_MOVAVG(INT *src, DOUBLE *result, INT size, 
           INT length);
DSP_MOVAVG(ARRAY_D& src, ARRAY_D& result, 
           INT length);
DSP_MOVAVG(DOUBLE *src, DOUBLE *result, 
           INT size, INT length);
Parameters

I/O

Parameter

Description / Range

I

src

Source array

O

result

Moving average results

size - length + 1 ≤ (size of result array)

I

size

Number of elements to be processed

2 ≤ size ≤ 2097152

size ≤ (size of src)

I

length

The moving average window

2 ≤ length ≤ size

size - length + 1 ≤ (size of result array)

Example

double array1[100],array2[100];
  .
  .
DSP_MOVAVG(array1, array2, 100, 50);

DSP_MOVAVG calculates the moving average with length = 50 for the first 100 elements of the arrayarray1, and returns the results to the arrayarray2as follows:

array2[0]: Average of array1[0] to array1[49]

array2[1]: Average of array1[1] to array1[50]

:

array2[i]: Average of array1[i] to array1[i+50-1]

:

array2[50]: Average of array1[50] to array1[99]
