MTP_FUNC_TASK.getPassFail()

The getPassFail() member function of MTP_FUNC_TASK lets you retrieve a pass/fail judgment either for all measured pins or for a specific pin.

Syntax

  • To retrieve a pass/fail judgment for all measured pins:
    bool getPassFail(void) const
  • To retrieve a pass/fail judgment for a specific pin:
    bool getPassFail(const string & pin) const

    Parameter

    Description

    pin

    The name of a pin whose pass/fail result you want to retrieve.

Return Value

Returns a Boolean true for pass or false for fail result of the measurement.

Related information
