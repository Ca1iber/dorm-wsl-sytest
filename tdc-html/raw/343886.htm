SmartRDI 2.5.1

This section summarizes software changes including new features and enhancements in SmartRDI 2.5.1.

Changes and new features

Category

 Description
SmartVec Support pattern generation with per-site data no matter whether the site is enabled or not. See writeBit(), writeData(), writeParData(), and writeVec()
DC Support inserting a wait pattern as a sublabel to control the waiting time between actions. See the example in insertSub().
UTIL The default value for UTIL_DYN_MASK_UNSPECIFIED_PIN is changed to TRUE. Therefore, the default behavior of sequencer‑controlled utility is changed. See RDI_Configure file.
