Topic 137403

Configuring value categories in result graphs

In several types of result graphs, you can specify how the individual results are grouped into categories.

About this task

Configure the value categories to display the underlying data more finely or more coarsely differentiated.

Before you begin

Open a result graph of the desired type.

Procedures

Configuring the number of categories charted on an axis

This procedure applies to histograms and FFC Pareto charts.

  1. Click the Properties button on the chart's toolbar or choose Properties from the context menu.

    The chart's properties dialog opens.

  2. Click the Scales tab.
  3. In the Bin Count field, enter the desired number of categories.
  4. Click OK.

In the histogram, the test results are sorted into the specified number of categories. In the FFC Pareto chart, the specified number of first failing cycles are displayed. (The chart displays the cycles that had the greatest numbers of first fails.)

You can also set the number of categories from submenus of the context menus in these charts: the Bin Count submenu in a histogram and the Failing Cycle Axis submenu in a FFC Pareto chart.

Configuring the value categories in a parametric wafer map

  1. Click the Properties button on the chart's toolbar or choose Properties from the context menu.

    The chart's properties dialog opens.

  2. Click the Classes tab.
  3. In the Minimum and Maximum fields, enter the lower and upper limits of the value range that you want to divide into classes.
  4. In the Class Count field, enter the desired number of classes.

    All classes have the same size; you can see in the Class Width field how big the range of each class is.

  5. Click OK.

The cells in the parametric wafer map are assigned to the classes and colored according to the new specifications.

Results

The chart display is updated according to your settings.
