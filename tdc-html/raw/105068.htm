Test heads

The test head type of a V93000 test system defines the maximum number of test head cards that can be installed. A V93000 EXA Scale system can be equipped with an LX, SX, or CX test head, while a V93000 Pin Scale or Smart Scale system can be equipped with an L‑Class, S‑Class, C‑Class, or A‑Class test head.

Pin Scale and Smart Scale Systems: EXA Scale Systems
  • Large Test Head (V93000 L-Class)
    8 card cages, 64 slots + 8 DPS slots
  • LX Test Head (V93000 EXA Scale LX)
    3 card cages, 27 slots
  • Small Test Head (V93000 S-Class)
    4 card cages, 32 slots + 4 DPS slots
  • SX Test Head (V93000 EXA Scale SX)
    2 card cages, 18 slots
  • Compact Test Head (V93000 C-Class)
    2 card cages, 16 slots + 2 DPS slots
  • CX Test Head (V93000 EXA Scale CX)
    1 card cages, 9 slots
  • A-Test Head (V93000 A-Class)

    1 card cage, 8 slots + 1 DPS slot
