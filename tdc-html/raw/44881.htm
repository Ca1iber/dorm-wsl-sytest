Flag Access

This section describes the flags available through CPI routines, and the various methods in which they are specified.

Direct String

Use the quoted string method to specify the flag that you wish to query/set:

long val;
GetSystemFlag("bin_number", &val);

Predefined Strings

A set of constants to specify flag names are available. For example:

long val;
GetSystemFlag(CI_BIN_NUMBER, &val);

For a listing of the various flags available, together with their values, see the relevant function in the next section.

Functional changes
