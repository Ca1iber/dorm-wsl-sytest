Setting the clock sync group

You can set the clock sync group in imported STIL files by specifying the group in the 93kPorts NameMaps element.

To set the desired clock sync group, specify it as the sync_group parameter in a SignalGroups element in the NameMaps element.

For example:

Environment "default" {
  NameMaps "93kPorts" {
    SignalGroups {
      "CLK1" "port=p1, sync_group=SG1 ,phase_sync=off, sync_clock=clk1";
    }
    ...
  }
  ...
}

Translating this STIL code will result in:

...
PORT p1
SYNC {SEQUENCE "SG1" CLOCK "clk1"}
...

Functional changes

  1. Introduced in SmarTest 7.4.1
