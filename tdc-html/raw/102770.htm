Topic 102770

Conditional execution

MTL supports the if statement and the conditional operator (: ?) for conditional execution of code.

The if statement used in MTL is similar to the standard C, supporting the else and else if options, but it also has some limitations:

  • The condition part in an if statement cannot be changed during executing MTL programs. That is:
    • When the if statement is used outside any loop, there is no limitation.
    • When the if statement is used in a loop, the condition part cannot contain any loop variable or any variable that will be changed in the loop (including its outer and inner loops).
  • Only the MTL supported operators can be used with the if statement.

    For those operators, see Operators.

To learn the conditional operator (: ?), see Operators. The significant difference between this operator and the if statement is that this operator supports the usage of loop variables in it. See the example in the following section.

Examples

Example 1

This example demonstrates permitted and non-permitted uses of the if statement. See the program comments for details.

v1 = 1;
v2 = 2;
v3 = 3;
for (x=0; x<100; x += 1)
{
  if (x < 3) {NOP();}      # Incorrect: x is the loop variable
  v1 += 2;
  if (v1 > 100) {NOP();}   # Incorrect: v1 changes within the loop
  if (v3 < 5) {NOP();}     # Incorrect: v3 changes within the inner loop (below)
  if (v2 == 1) {NOP();}    # OK
  for (y = 0; y < 32; y += 2)
  {
    v3 += 3;
    if (x < 4) {NOP();}    # Incorrect: x is the loop variable of the outer loop
    if (v1 > 100) {NOP();} # Incorrect: v1 changes in the outer loop
    if (v2 == 1) {NOP();}  # OK
  }
}
if (v1 < 50) {NOP();}      # OK: v1 is used outside of any loop

Example 2

When 'if' statements in subroutines, the if statement still have the same the limitations. For example:

sub(var)
{
  if (var > 0) {NOP();}
}

main()
{
  v1 = 1;
  for (x=0; x<100; x +=1)
  {
    sub(x);  # Incorrect: x is the loop variable and is
             # used in an if statement in the subroutine
    sub(v1); # Correct: v1 does not change in the loop
  }
}

Example 3

This example shows using the conditional operator (: ?) with loop variables to develop a diagonal-like pattern.

for(y=yStart;y<yStop;y++)
{
  for(x=xStart; x < xStop; x++)
    {
      data = (x==y) ? 0:1;
      write(data);
    }
}
