Assigning a Specification Set to Another Equation Set

  1. Click Change Equation in the Change menu.

    A window similar to that of the figure below opens.

  2. Highlight the specification set you want to assign to another equation set.
  3. Highlight the new equation set from the Equation list.
  4. Click assign.
  5. Repeat these last steps as often as required (for other specification sets), and click done when finished.

Functional changes

  1. Introduced before SmarTest 6.3.2
