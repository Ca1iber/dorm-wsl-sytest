Topic 123821

Prepare the test method infrastructure

About this task

The following steps have to be carried out to prepare your test method code in order to enable and configure the d2s-framework.

Before you begin

Import the d2s_tml.zip library to your UTM project. It is located in /opt/hp93000/soc/testmethod/library.

Files that will be imported to your UTM project

File name

Description

./include/d2sFramework.h

./generic_d2s/d2sFramework.cpp

./include/d2sModes.h

General framework code.

./include/TransactionPort.h

./generic_d2s/TransactionPort.cpp

General port-specific implementation.

./include/eviceRegisterTransactionPort.h

./generic_d2s/DeviceRegisterTransactionPort.cpp

General port-specific implementation for device register access

./include/d2s_Serial.h

./generic_d2s/d2s_Serial.cpp

General implementation for serial interfaces.

./include/Event.h

./generic_d2s/Event.cpp

General implementation for event based transactions.

./include/PatternManager.h

./generic_d2s/PatternManager.cpp

Code that handles the generation of labels.

./include/FW.h

./generic_d2s/FW.cpp

Code to handle FW-commands.

./include/PortChecker.h

./generic_d2s/PortChecker.cpp

Code to make sure ports are not overlapping.

./d2sSerialProtocolTemplate.h

User's protocol file template.

Procedure

  1. Rename the d2sSerialProtocolTemplate.h template file to create your protocol file, for example d2sJTAG.h.
    Note Modify the user template (d2sSerialProtocolTemplate.h) only, do not modify any other d2s files.
  2. Include the d2sFramework.h and your protocol template file, for example d2sJTAG.h, to your test method. You may already add non protocol related code to your test method, such as initialization parameters.

Example

This example highlights the necessary modifications to a test method template in bold. The d2s-framework and the protocol template file have been included. All d2s specific files have been copied to the ./d2s_files directory of the current UTM project.

#include "testmethod.hpp"

//for test method API interfaces
#include "mapi.hpp"

//for d2s specific interfaces
#include "d2s_files/d2sJTAG.h"        // This is the users protocol template file.
#include "d2s_files/d2sFramework.h"

using namespace std;

/**
 * Test method class.
 *
 * For each testsuite using this test method, one object of this
 * class is created.
 */
class d2sExample: public testmethod::TestMethod {

protected:
  /**
   *Initialize the parameter interface to the testflow.
   *This method is called just once after a testsuite is created.
   */
  virtual void initialize()
  {
    //Add your initialization code here
    //Note: Test Method API should not be used in this method!
  }

  /**
   *This test is invoked per site.
   */
  virtual void run()
  {
    //Add your test code here.
    ...
    //Add the initial d2s framework specific code to your test method.
    //Each protocol needs to be registered with the d2s-framework.
    d2sFramework fr;
    d2sJTAG& jtag = ds2JTAG::Instance();
    fr.registerTransactionPort(jtag);

   ...   // more d2s specific code will be added here.

    return;
  }

  /**
   *This function will be invoked once the specified parameter's value is changed.
   *@param parameterIdentifier
   */
  virtual void postParameterChange(const string& parameterIdentifier)
  {
    //Add your code
    //Note: Test Method API should not be used in this method!
    return;
  }

  /**
   *This function will be invoked once the Select Test Method Dialog is opened.
   */
  virtual const string getComment() const 
  {
    string comment = " please add your comment for this method.";
    return comment;
  }
};
REGISTER_TESTMETHOD("d2sExample", d2sExample);

What to do next

Configure the parameters within your protocol file as described in detail in Configure the protocol.
