Topic 112301

Bit Fail Map Viewer menus

Subtopics

  1. Session menu
  2. Settings menu
  3. Extras menu
  4. Help menu

The menus of the BFM Viewer let you set up the program, manage sessions, export data, and get help.

The BFM Viewer has these menus:

  • Session for setting the device and managing sessions
  • Settings for configuring the program
  • Extras for additional configuration and for exporting bit fail maps as text
  • Help
