DataTraining parameters

The parameters for the DataTraining test method are available in the Test Suite window. You can define the pin groups participating and the spec variables that are swept. Sweep start and stop must be set such that the expected transition is well inside the sweep range. With the MinOpenEye parameter, you control the coarse sweep steps. This parameter should be considerable smaller than the expected minimum eye width. The AlignAccuracy parameter controls the resolution in which the edge timing is determined.
