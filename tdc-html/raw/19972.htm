Creating a Pattern (Label)

Note The terms label and vector label are often used as a synonym for pattern.

You can set up a pattern for Digital Capture with the pattern debug tool just like any other pattern.

Note that the pattern type must be Main. Also, a group of digital capture patterns (a group of main patterns) can be integrated into a burst.
