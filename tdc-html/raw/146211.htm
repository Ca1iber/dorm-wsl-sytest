Disabling SmartCalc

SmarTest provides two convenient options to disable the SMC and/or multithreading capabilities.

Disable SmartCalc

Set SMC_DISABLE(bool value) to TRUE to disable all the SMC features like multithreading and hidden upload.

Execution will continue as without SMC, except that the SMC_TEST statements still will be evaluated during a SMC_SYNCHRONIZE(). It is recommended to put this statement in the test program and control it by a test flow flag, for example, GET_TESTFLOW_FLAG("SMC_OFF", &value).

Force serial execution

If certain calculation routines are not thread safe, it is possible to force serial execution. This can be achieved by disabling the parallel background execution with SMC_SERIAL_EXECUTION_BEGIN(). The enclosed code will be performed serially in the foreground. In order to enable background execution again use SMC_SERIAL_EXECUTION_END().

Functional changes

  1. Introduced in SmarTest 6.5.3
