Linear search modes

This topic describes the linear search modes and the difference between the standard and the FASTSTOP mode.

Search types

  • Single transition:
    • Pass/fail transition = right boundary
    • Fail/pass transition = left boundary
  • Eye:
    • Closed eye: One or more pass results enclosed by fail results within the measurement range, for example

      F-F-P-P-P-P-P-F

    • Open eye: One or more pass results enclosed by an open end and a fail result, for example

      P-P-P-P-P-F-F-F or

      F-F-F-P-P-P-P-P

P = pass, F = fail, as seen when executing all linear steps

Standard mode

The linear search scans always the whole search range for the largest eye. It first looks for closed eyes, but if there is none, it also considers open eyes.

FASTSTOP mode

The FASTSTOP mode stops the linear search as soon as the first valid eye or single transition is returned:

  • Requesting an eye, the linear search stops as soon as both edges of the first eye are returned.
    • It requires both, a fail/pass and a pass/fail transitions within the search window.
    • It does not acknowledge an open eye as eye.
    • The number of the returned PASS values does not matter.
  • Requesting a single transition, the first two subsequent measurements (pass/fail or fail/pass), which show the requested transition, stop the linear search.
  • If the requested condition is not fulfilled, it returns the same result as the standard mode.

Examples

Scenario 1

P-P-P-P-F-F-P-F-F
  • Requesting an eye
    • The standard mode scans the whole search range and returns the only closed eye as the result (although the open eye is larger).
    • The FASTSTOP mode stops the search at the second single transition and also returns the only closed eye.
  • Requesting a single transition and searching only for the right transition (P-F with search type RB)
    • The standard mode scans the whole search range, finds exactly one closed eye and returns the P-F transition of this eye.
    • The FASTSTOP mode stops the search at the second P-F transition from the left and returns this transition as result.

Scenario 2

F-P-P-P-F-P-P-F

Both search modes return the first pass-region (F-P-P-P-F) as the eye. The only difference is that the FASTSTOP mode stops the search after the second single transition, whereas the standard mode scans the whole search range.

Scenario 3

F-P-F-P-P-P-P-F
  • Requesting an eye
    • The standard mode scans the whole search range, acknowledges the second eye (F-P-P-P-P-F) as the largest eye.
    • The FASTSTOP mode stops the search at the second single transition and returns the first, very small, eye (F-P-F), that is, it stops before it finds the largest eye.
  • Requesting a single transition and searching only for the right transition (P-F with search type RB)
    • The standard mode scans the whole search range, acknowledges the second eye (F-P-P-P-P-F) as the largest eye and returns the second P-F transition from the left.
    • The FASTSTOP mode stops the search at the first P-F transition from the left and returns this transition as result.

      The search stops before it finds the largest eye.

Scenario 4

P-P-P-P-F-F-F-F-F
  • Requesting an eye
    • Both modes scan the whole search range, find no closed eye, and therefore return the open eye as the result.
  • Requesting a single transition and searching only for the right transition (P-F with search type RB)
    • Both modes scan the whole search range, acknowledge the open eye as the only eye and return the P-F transition.
