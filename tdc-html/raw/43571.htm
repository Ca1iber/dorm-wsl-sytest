Changing the SmarTest Mode Passwords

When SmarTest is started, it is done so with either operating, supervising or engineering status. The button at the top of the Operation Control screen shows the current status. If the software has been started in either operating or supervising mode, and you wish to change to Engineer status you need to know the Engineer password for that SmarTest (as each workstation has its own SmarTest installed on it, the supervising and engineering mode passwords for each SmarTest on each machine may well be different).

A script is delivered with SmarTest that enables you to either install the default passwords, or to modify the existing ones.

Note You have to be logged in as a root user. Otherwise you will not be able to change passwords.

To install the default passwords:

  1. Call the script /opt/hp93000/soc/prod_env/bin/pw_maint.
  2. Key in i followed by return
  3. Answer y to overwrite the existing password file and install the default passwords. The default passwords are:

    Engineer Status-engineer

    Supervisor Status-supervisor

  4. Key in e to exit the program.

To modify the existing passwords:

  1. Call the script /opt/hp93000/soc/prod_env/bin/pw_maint.
  2. Key in m followed by return, to modify the passwords.
  3. Either,
    • select 1 if you want to modify the engineer password, or
    • select 2 if you want to modify the supervisor password.
  4. Key in the new password, when prompted.
  5. Key in the new password again, when prompted.
  6. Key in e to exit the program.
