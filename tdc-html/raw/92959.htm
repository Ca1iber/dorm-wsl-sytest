DSP_RF_NORMALIZE()

In most applications, users will not need to call the DSP_RF_NORMALIZE() function, because normalization (if it is needed) is performed automatically by the DSP_RF_ACLR() function. The DSP_RF_NORMALIZE() function is provided for the benefit of users who wish to create their own custom ACLR functions within a TestMethod, and therefore need direct access to a normalization function.

Normalization is the process of correcting for differences in measured power which occur when two measurements have different bandwidths. If power measurements at a carrier frequency and an offset channel frequency do not have the same bandwidth, you can use the DSP_RF_NORMALIZE function to calculate a normalization factor (which can then be used to compensate for the bandwidth difference, so that the two measurements can be compared).

The DSP_RF_NORMALIZE() function uses this formula:

10.0*log10(toBW/fromBW)

where fromBW is typically the bandwidth of the carrier measurement and toBW is typically the bandwidth of an offset channel measurement.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_RF_NORMALIZE(const DOUBLE    fromBW,
                 const DOUBLE    toBW,
                 DOUBLE        * normFactor);
Parameters

I/O

Parameter

Notes

I

fromBW

Bandwidth of the measurement that is being normalized (typically, the bandwidth of the carrier measurement).

I

toBW

Bandwidth of the measurement to which the fromBW measurement is being normalized (typically, the bandwidth of the offset measurement).

O

normFactor

The normalization factor (in dB) which must be subtracted from the difference between the two power measurements to compensate for the difference in bandwidth.

How the function is used

Given a carrier bandwidth of 1.23 MHz and a channel bandwidth of 30 kHz, the normalization factor will be calculated as:

10.0*log10(0.03e6/1.23e6) = -16.1

This normalization factor can be used in calculating channel power relative to carrier power:

  • Channel_dBc = Channel_dBm - Carrier_dBm - normFactor
  • Channel_dBm = -80
  • Carrier_dBm = -10
  • normFactor = -16.1
  • Channel_dBc: (-80) - (-10) - (-16.1) = -53.9 dBc

Example

ARRAY_D measParams = MEAS_DEF().getParameters(TM::RF_MEAS_ACLR,0);
DOUBLE fromBW = measParams[TM::ACLR_CARRIER_BW];
DOUBLE toBW = measParams[TM::ACLR_CHANNEL_BW];
DOUBLE normFactor = 0;
DSP_RF_NORMALIZE(fromBW, toBW, normFactor);
