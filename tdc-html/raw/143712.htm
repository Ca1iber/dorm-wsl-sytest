LOOPBACK_OPERATION_PINS

The LOOPBACK_OPERATION_PINS class serves to hold the operation mode of one or more loopback pins. You cannot directly create an instance of it. Rather, these instances are created by the pin() member function of the LOOPBACK_OPERATION_TASK class.Note that direct and direct retimed SmartLoop based loopback is currently not supported.

Member functions

setOperationMode()

void setOperationMode(LOOPBACK_OPERATION::LOOPBACK_OPERATION_MODE mode);
void setOperationMode(LOOPBACK_OPERATION::LOOPBACK_OPERATION_MODE mode, LOOPBACK_OPERATION::LOOPBACK_OPERATION_IDLE_MODE idle_mode);

This function determines the loopback operation mode for the pins of the LOOPBACK_OPERATION_PINS instance.

Parameter

mode

The operation mode for the pins of the LOOPBACK_OPERATION_PINS instance. The possible values are:

 

PARAMETRIC_LOOP

A loopback test in direct mode will be executed.

Currently not supported.

 

PARAMETRIC_LOOP_RETIMED

A loopback test in direct retimed mode will be executed.

Currently not supported.

 

OFF

No loopback test will executed.

idle_mode

This parameter determines if in the case of an OOB state in the output signal an OOB state will also be generated by the resulting input signal (value ENABLED), or if L or H will be passed to the input pins even then (value DISABLED).

setup()

void setup();

This function executes the configuration firmware command for all pins of the LOOPBACK_OPERATION_PINS instance.

execute()

void execute();

This function executes the loopback test for all pins specified in the pin() function.

getOperationMode()

LOOPBACK_OPERATION::LOOPBACK_OPERATION_MODE getOperationMode();

This function retrieves the current operation mode for the pins of the LOOPBACK_OPERATION_PINS instance. It has no parameters.

getIdleMode()

LOOPBACK_OPERATION::LOOPBACK_OPERATION_IDLE_MODE:: getIdleMode();

This function returns ENABLED if an OOB state in the output signal is passed to the input signal, otherwise DISABLED.
