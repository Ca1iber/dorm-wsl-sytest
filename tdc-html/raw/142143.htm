Topic 142143

EVENT_CMP

Subtopics

  1. EVENT_CMP.low()
  2. EVENT_CMP.high()

The EVENT_CMP class is used for match loops and allows to compare against low or high thresholds, which are defined with DPS_AUX_PIN_TASK.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

EVENT_CMP ( const STRING &id );
EVENT_CMP ( INT &id );

This constructs an object of the EVENT_CMP class. The class derives from the EVENT_BASE class.

Parameter
Parameter Description
id

Event identifier

Return value

There is no return value.

Example

The example compares against the high threshold.

PATTERN_CONTROLLER cleanUpPattern;
PATTERN_CONTROLLER pc;

EVENT_CMP matchCompare("matchCmpHigh");

ON_FIRST_INVOCATION_BEGIN();

    cleanUpPattern.label("patEvents", "@")
                  .vecEvents("dps1")
                  .clearAll()
                  .setup();

    matchCompare.high();

    PATTERN & pattern(pc.label("patEvents", "@"));
    pattern.vecEvents("dps1").insert(32, matchCompare);

    pc.setup();

ON_FIRST_INVOCATION_END();
