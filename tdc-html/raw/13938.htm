Reading Test Label Information

For debugging purposes it is useful to match a particular cycle in the Timing Diagram to a particular label in your test:

  1. Move the cursor to the appropriate cycle in the Timing Diagram.
  2. On the menu click Info > label.

    The Label Information dialog box opens.

    Note The label information displayed always refers to the last test run.
  3. After having read the label, click the continue button to return to the Timing Diagram.
