Defining and Activating Primary Set

The SRPR command sets a routing set as the primary set, which should be activated with the next ACRS command for each test.

The ACRS command activates the specified routing set. Generally, you should specify the primary routing set. You can also specify another defined routing set. The routing statements in the routing set are executed in the order specified in the DFRT command and make the desired routes.

CAUTION To prevent lowering the reliability of the relays in the multiplexer of the digitizers, you should first change the output voltage from the analog pin of the test device to 0 V or the presently-used DC offset voltage (if you use the DC offset function) if possible, then switch the routing for the analog pin.

The ACRS command executes the routing statements such as described in Setting up Routing. The following example explains the execution order of the routing statements.

Example:

#Definition of routing set

DFRS 1,4

DFRT 1,1,ANA_CNCT,"OFF",,(Vout1,Vout2)

DFRT 1,2,FLSH,"1",,

DFRT 1,3,ANA_CNCT,"DIFF,EXT,fwd",,(Vout1)

DFRT 1,4,ANA_CNCT,"DIFF,CORE",,(Vout2)

#Definition and activation of primary routing set for a test

SRPR 1

ACRS PRM

In the above example, the ACRS command executes the routing statements defined by the previous multiple DFRT commands in the following order.

  1. Execute the routing statement #1 by using the "FLSH" task of the routing statement #2.
  2. Wait 1 ms for the hardware to stabilize after the "FLSH" task is executed.
  3. Execute the routing statements #3 and #4 in parallel by using the auto-attached "FLSH" task. This "FLSH" task is automatically executed after the last statement.
