Naming of blocks and elements

Blocks and elements in the files that STIL Reader generates are named according to the conventions listed below.

The following variables are used in creating the names:

  • <port>: Port name.
  • <stil_category>: STIL Category name, as specified in the PatternExec block.
  • <stil_level_name>: STIL DCLevels name, as specified in the PatternExec block.
  • <stil_pattern>: STIL pattern name.

    By default, the STIL pattern name is pattern block name. If the stil_file_name_as_pattern_name parameter in the STIL Reader setup file is set to 1, the STIL file name (without the extension) is used instead.

  • <stil_pattern_burst>: STIL PatternBurst block name.
  • <stil_selector>: STIL spec Selector name, as specified in the PatternExec block.
  • <stil_wft>: STIL WaveformTable name.

Syntax

Element

V93000 name

Timing wavetable (no multiport)

<stil_wft_1>_<stil_wft_1>_..._<stil_wft_n>

The maximum length of the name is 40 characters; see Long element names, below, for additional information.

Timing wavetable (with multiport)

<stil_wft_1>_<stil_wft_1>_..._<stil_wft_n>_<port>

The maximum length of the name is 40 characters; see Long element names, below, for additional information.

Timing equation set

As timing wavetables, above.

Timing spec set

<stil_category> or optionally

<stil_category>_<stil_selector>

If no specifications are defined, the name is "Default".

The maximum length of the name is 40 characters; see Long element names, below, for additional information.

Timing timing set

As timing wavetables, above, except that the name may be up to 60 characters long.

Levels level set

<stil_level_name>

The maximum length of the name is 40 characters; see Long element names, below, for additional information.

Levels equation set

<stil_level_name>

The maximum length of the name is 40 characters; see Long element names, below, for additional information.

Levels spec set

<stil_category> or optionally

<stil_category>_<stil_selector>

The maximum length of the name is 40 characters; see Long element names, below, for additional information.

Test suite name

<stil_pattern>

The maximum length of the name is 40 characters; see Long element names, below, for additional information.

Pattern burst sequence label

Pattern burst definitions

The maximum length of the name is 40 characters; see Long element names, below, for additional information.

Vector sequence label

<stil_pattern>

The maximum length of the name is 128 characters for SmarTest 6.1.1 and above and 40 characters for older versions; see Long element names, below, for additional information.

The maximum length of vector comments is 250 characters for SmarTest 6.5.3 and above and 40 characters for older versions.

Long element names

Element names that would exceed the length restrictions are automatically trimmed, and a suffix is added to generate a unique name.

In addition to the limits given in the table, there are these restrictions:

  • Device cycle names: 6 characters
  • Port names: 16 characters
