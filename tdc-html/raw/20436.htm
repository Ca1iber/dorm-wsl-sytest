DUT board docking

Subtopics

  1. Docking to handlers
  2. DUT board and interface alignment
  3. Final docking
  4. Purge kit

The DUT interface is the assembly on the test head that is used to establish the mechanical and electrical connection between the DUT board assembly and the test head electronics. The process of connecting the DUT board assembly to the DUT interface is called DUT board docking.

CAUTION The DUT interface can carry a maximum weight of 25 kg.

In most cases, you will attach the DUT board assembly to the handler using a DUT board stiffener inlay (see DUT board stiffeners and inlay plates) and a DUT docking plate designed for use with your specific handler. After you attach the DUT board assembly to the handler, you can use the test system hard-docking interface function to bring the test head into correct alignment with the DUT board assembly. You can then mechanically lock and electrically engage the DUT board assembly and the test system using the DUT docking function. The hard docking interface hardware ensures a durable and sturdy mechanical connection between the test head and the handler without exerting excessive force on the DUT board or on test head connectors. The DUT docking function ensures the precise, fine alignment.
