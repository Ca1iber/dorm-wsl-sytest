GET_LIMIT

This API retrieves the limit values of the specified test for recording limit data in the data log file or for using the retrieved limit value in the program. If new limit values are changed in the test method program by using the LIMIT class, for instance, the GET_LIMIT API returns the new values.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

GET_LIMIT(const char * testname, 
 TM::COMPARE & opl, DOUBLE & low,
 TM::COMPARE & oph, DOUBLE & high);
GET_LIMIT(const STRING & testname, 
 TM::COMPARE & opl, DOUBLE & low,
 TM::COMPARE & oph, DOUBLE & high);
Parameters

I/O

Parameter

Description / Range

I

testname

Test name that can be referred from the Properties view.

O

opl

Returns one of the following integer values corresponding to the comparison operator for lower limit:

2: Greater than a lower limit value

3: Greater than or equal to a lower limit

value

4: A lower limit value is not used

O

low

A lower limit value. If 4 is returned to opl, 0 is returned to this parameter.

O

oph

Returns one of the following integer values corresponding to the comparison operator for upper limit:

0: Less than an upper limit value

1: Less than or equal to an upper limit

value

4: A upper limit value is not used

O

high

A upper limit value. If 4 is returned to oph, 0 is returned to this parameter.

Example

TM::COMPARE opl, oph;
DOUBLE low, high;

cout << "executing ";
cout << "GET_LIMIT(\"test1\",opl,low,oph,high)" <<endl;
GET_LIMIT("test1",opl,low,oph,high);
cout << "opl = "  << opl  << endl;
cout << "low = "  << low  << endl;
cout << "oph = "  << oph  << endl;
cout << "high = " << high << endl;

This example retrieves the limit values of the "test1" and outputs the retrieved values.

Functional changes

  1. Introduced before SmarTest 6.3.2
