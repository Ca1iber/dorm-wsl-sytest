CallDataBridgeFunc()

This API executes a data bridge function after the shared library is loaded. The ACTION_DATA_BRIDGE_CALL_STARTED/ACTION_DATA_BRIDGE_CALL_COMPLETED HVM events will be generated if the implicit event generation is turned on.

SUCCESS will be returned if no error occurs. Otherwise, an error object is returned indicating the error code, description and severity.

Code

Typical Description

Severity

PARAMETER_EXCEPTION

The value of the parameter "FUNCTION_NAME" is empty.

RECOVERABLE

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • The local session does not exist.
  • There is no shared library loaded.
  • The function "XXX" cannot be found in the loaded shared library-Detailed info:XXXXX.
  • The execution of function "XXX" failed.
  • Failed to issue the HVM event.

RECOVERABLE

Parameters

I/O

Parameter

Description

I

SESSION_ID

The local session ID.

I

DATA_BRIDGE_LIB_FILE

The full path of the data bridge shared library.

Prototype

ParamList inputParams, outputResults;
Status syncOperation("CallDataBridgeFunc", outputRestuls,
                     inputParams, sessionID);

Example

string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams, outputResults; 
inputParams["FUNCTION_NAME"] = "dbinit";

Status retVal = syncOperation("CallDataBridgeFunc", outputResults,
                              inputParams, sid);
if ( retVal.isError() ) 
{
cout<<"error code= " << retVal.code() << " description="
    << retVal.text() << endl;
}
