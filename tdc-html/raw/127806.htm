TESTSET().testtype()

This member function of TESTSET sets the test type.

This function is not supported within the SMC_backgroundProcessing() test method when flag hidden_datalog_mode is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

Syntax

TESTSET & testtype(TM::TEST_TYPE type);

Parameter

Description

type

The test type can be TM::FUNCTIONAL, TM::PARAMETRIC, or TM::SCAN.

Example

TestSet.testtype(TM::PARAMETRIC);

Related information

TESTSET
TESTSET().testtype_default()

Functional changes

  1. Introduced before SmarTest 6.3.2
