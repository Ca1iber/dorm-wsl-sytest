Topic 98834

UPTD, UPTD? - (UP To Date)

The UPTD (UP To Date) command allows you to declare a given setup, result or command set as up to date or out of date.

The UPTD? query allows you to read if the data in hardware has been changed since the current device file was last saved or loaded. A 1 or a 0 is returned. At power-on or after use of the *RST or DSCP commands, all the flags are set to 0.

UPTD

UPTD {status}, {flag}

UPTD?

UPTD? {status}

returns: 

UPTD {status}, {flag}

Parameters

status

This parameter sets or returns the current status of the hardware.

Options for the status parameter

Option

Description

ALL

The status of all options is returned. Use of the PATR (PADSfor 14 edge setups), DFPN (DeFine Pin Name), or CONF (CONFiguration) commands sets the flag to 0 until the setup is saved or loaded.

ANA

The status of the analog control data is returned. When analog control data has changed the flag is set to 0 until the changed data is saved or loaded.

APPL

The status of the production test application data file is returned. When application data is changed, the flag is set to 0 until the changed data is saved or loaded.

ATR

The status of the edge attributes setup is returned. Use of the commands PCLK (Pin CLocK), DFPN (DeFine Pin Name), or CONF (CONFiguration) sets the flag to 0 until the setup is saved or loaded.

CAL

The status of the calibration data is returned. When the calibration data is changed, the flag is set to 0 until the changed data is saved or loaded.

CNFG

The status of the production test configuration is returned. When the data is changed, the flag is set to 0 until the changed data is saved or loaded.

CONF

The status of the pin configuration setup is returned. Use of any of the Pin configuration setup commands sets the flag to 0 until the setup is saved or loaded.

DFRM

The status of the Data Bridge Command Set is returned. When the Command Set name is changed, the flag is set to 0. When the Command Set process is successfully loaded and running, the flag is set to 1.

DPS

The status of the power supply setup is returned. Use of equation based level setup, the PSLV (Power Supply LeVel) command, or any of the Pin configuration setup commands sets both the DPS and LEV flags to 0 until the setup is saved or loaded (see Note below).

DSET

The status of the data set is returned. When the data set is changed, the flag is set to 0 until the changed data is saved or loaded.

EDA

The status of the CAE link files is returned. When the CAE link data is changed, the flag is set to 0 until the changed data is saved or loaded.

ERMP

The status of the Error Map files is returned. When the Error Map data is changed, the flag is set to 0 until the changed data is saved or loaded.

FLOW

The status of the production testflow file is returned. When testflow data is changed, the flag is set to 0 until the changed data is saved or loaded.

LEV

The status of the level setup is returned. Use of equation based level setup, any of the Pin configuration setup commands, or any of the Level Setup Commands sets both the DPS and LEV flags to 0 until the setup is saved or loaded (see Note below).

PDL

The status of the path delay data is returned. Use of the commands SATR (System ATtRibutes), or FXDL (FiXture DeLay), as well as DFPN (DeFine Pin Name) or CONF (CONFiguration) sets the flag to 0 until the changed data is saved or loaded.

PRBH

The status of the Prober/Handler Command Set is returned. When the Command Set name is changed, the flag is set to 0. When the Command Set process is successfully loaded and running, the flag is set to 1.

PRCS

The status of the Execution Input Command Set is returned. When the Command Set name is changed, the flag is set to 0. When the Command Set process is successfully loaded and running, the flag is set to 1.

PROG

The status of the production test program file is returned. When production test data is changed, the flag is set to 0 until the changed data is saved or loaded.

REP

The status of the report window data is returned. When the data in the report window changes, the flag is set to 0 until the changed data is saved or loaded.

ROUT

The status of the routing setup is returned. When routing definition data has changed the flag is set to 0 until the changed data is saved or loaded.

SLST

The status of the state list files is returned. When the state list data is changed, the flag is set to 0 until the changed data is saved or loaded.

TIM

The status of the timing setup is returned. Use of the commands CONF (CONFiguration), DFPN (DeFine Pin Name), or any of the Timing Setup Commands set the flag to 0 until the setup is saved or loaded.

TMDG

The status of the timing diagram files is returned. When the timing diagram is changed, the flag is set to 0 until the changed data is saved or loaded.

USRP

The status of the User Procedure Command Set is returned. When the Command Set name is changed, the flag is set to 0. When the Command Set process is successfully loaded and running, the flag is set to 1.

VEC

The status of the vector and sequencer setup is returned. Use of the commands DFPN (DeFine Pin Name), CONF (CONFiguration), or any of the Vector Setup Commands set the flag to 0 until the setup is saved or loaded.

WAFR

The status of the wafer description file is returned. When description data is changed, the flag is set to 0 until the changed data is saved or loaded.

WAVE

The status of the waveform definition data is returned. When waveform definition data has changed the flag is set to 0 until the changed data is saved or loaded.
Note The status of the DPS and LEV parameters is kept synchronized when modified via the pin configuration tool or by equation based level setup. Only the commands PSLV (Power Supply LeVel), DRLV (DRive LeVel), or RCLV, RCLV? - (ReCeive LeVel) allow to unsychronize their status.

flag

Sets or returns the up-to-date status:

  • 1: The specified device file is identical to the data currently used in hardware.
  • 0: The specified device file differs from the data currently used in hardware.

Application

Test Program Explorer.

Errors

An error is generated if you specify a flag other than 0 or 1.

Example

UPTD? CONF

This example requests if the pin configuration data has been changed since the file was last loaded or saved. If the data has not changed, the response is:

UPTD CONF,1

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.3: BIT and FAM are no longer supported
  3. SmarTest 7.0.3: TSTF are no longer supported due to the obsoletion of standard test functions.
  4. SmarTest 7.2.0: Removed the SHMO parameter
