The Physical Waveform Table

For every test system channel the hardware contains a physical waveform table. The signals that the test system sends to, or receives from the DUT are referenced in the Vector Memory by an index to the physical waveform table. This index has a range of 0 to 255, and is called the physical waveform index. Along with the index the table contains a waveform without data. This waveform determines the state of the signal that will be used to test the device. The waveform and the index are called a physical waveform.

The index is read by the sequencer during test. This enables only the selected waveform states to take part in the device test. The physical waveform index is discussed in How the Vector Memory Stores Vectors.

As you create new waveforms you use up system resources. The Timing Setup window informs you of the number of physical waveforms that you still can create. This number is displayed in the free column in the device cycle edit area under Wf, see Relationship between waveform sets and timing sets. The free column is available only in the double size display mode. Thus if the free column displays Wf 5, then you have defined eleven of the available 16 physical waveforms for a particular pin. The free column is discussed later in the chapter in Device Cycles and Setting up the Table Format.

You can save system resources by actively reusing physical waveforms.
