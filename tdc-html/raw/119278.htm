Topic 119278

Searching for a variable

Procedure

Select a variable in this window and then click Go To.
  • If the variable is used in the test suite, the related test suite will be highlighted in the Flow Sequence Editor.
  • If it is used in the control node (Flow control nodes, Assign Value node, Print nodes), the related node is highlighted.
