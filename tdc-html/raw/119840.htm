Using the Test Suites page

On this page, you can edit the test suite settings.

Three types of test suites are shown on the Test Suites page

  • "Run" and "Run and Branch" test suites
  • Special test suites displayed with a cyan background
  • Floating test suite displayed with a gray background

Common tasks on this page

  • Set the Test suite flags
  • Set Up a Special Testsuite
  • Create a floating test suite
  • Delete a floating test suite and special test suite

    The Run and Branch node and Run node can only be deleted in the Flow Sequencer Editor.

  • Edit a testsuite in the Flow Data Editor
  • Run a testflow
  • Configure this page in the Test Suites preference page
  • Configure how the annotation is displayed in the Table Annotations preference page
