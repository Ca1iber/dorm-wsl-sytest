Adding a test suite in the testflow

There are two ways to insert a test suite:

  • In this window, enter all the information of the test suite:
    1. Test suite name
    2. Test method name
    3. The primary sets
    4. Context
  • Enter only the test suite name and the test method name, and leave the other fields blank.

    The inserted test suite will use the primary set of the preceding test suite in the current testflow
