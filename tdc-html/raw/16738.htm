Topic 16738

Debugging a testflow

Subtopics

  1. Single step testflow debugging

SmarTest automatically displays the Debug view when the Testflow tool is open.

Before starting a debug session, set the Debug Mode flag to choose the level of debug information in the Report window.

To step through the testflow, test suite for test suite, see Single step testflow debugging. For debugging individual test methods, see How to debug a universal test method.

When you debug a, potentially multi-site, testflow, the Site Control Window lets you identify passing and failing sites and view the results of individual sites with the result tools.

When you perform multisite testing using analog modules shared among multiple sites, you can also view and change the test order of sites for every site in the testflow in the expanded window.

Note Running a wide selection behaves different than running a narrow selection (see Narrow selection and wide selection). Running a wide selection will behave like a full testflow execution without disconnecting on Binning.
