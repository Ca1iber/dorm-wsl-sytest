Topic 149617

enPassFail()

This function retrieves the pass/fail result of the specified pattern in .label() for the digCap() class.

When enPassFail() is used together with selective digital capture, follow the "multiple of 8 cycles" rule. Refer to the Note in the For Selective Capturing topic for more information.

If required, set the High-Resolution-Pass/Fail (HRPF) mode in the timing for all pins. See High-Resolution-Pass/Fail (HRPF) for how to set HRPF. If HRPF is set, burst pass/fail results can be retrieved.

The pins used for digital capture are not recorded by the error map; as a result, they do not contribute to the per-label pass/fail result. See also Combining selective digital capture with a functional test for more information.

Syntax

enPassFail();

Example

RDI_BEGIN();
  rdi.tmu("a").label("label1").pin("A")....enPassFail().execute()
  rdi.dc("b").label("label2").pin("B")....enPassFail().execute();
  rdi.digCap("c").label("label3").pin("C")....enPassFail().execute();
RDI_END();

rdi.id("a").getPassFail();
rdi.id("b").getPassFail();
rdi.dc("c").getPassFail();
