Central profile

Central profile is directory which stores the configuration of the supported TP360 modules. Users can access this directory to load the profile and initialize TP360.

About this task

There are three modules in TP360 that you can save their configurations in a profile:

  • Test Program Stability Checker
  • Test Program Cleaner
  • Executing the Smart Correlation release checker

Before you begin

Make sure you have the permission to access the central profile directory.

Procedure

  1. Open TP360 in command mode with a parameter: -p <central_profile_dir>, in default it would be /opt/hp93000/tp360/run –p <central_profile_dir>
  2. Launch one of the modules which support profile, TP360 will initial the configuration of this module by load the profile from <central_profile_dir>
  3. After finish the configuration, you can use "export" to export the configuration back to the central profile directory.
  4. (Optional) you can use "import" to reload the configuration from central profile directory if you want give up current setting.
    Note Use the "export to central profile" to initial the central profile when you using the central profile at the very first time.

Example

  1. Taking the Test Program Cleaner as an example. Open TP360 in command mode: /opt/hp93000/tp360/run –p /tmp/Jason_tp360_profile.
  2. Launch Test Program Cleaner, TP360 is warning to initial the central profile directory.
  3. Configure the Test Program Cleaner.
  4. Click "export" icon to open Export page, and choose "export to central profile"
  5. Click "Finish" to export.
  6. (Optional) you can verify this export by close TP360, and repeat step 1, step 2, TP360 will auto load the configuration you have exported to the central profile. Or do some changes, and then manually click "Import" to import from central directory.

What to do next

If you have changed the content of the central profile, please notice other engineers so that they can import the latest profile.
