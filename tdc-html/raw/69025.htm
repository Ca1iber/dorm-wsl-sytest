Session menu

The Bit Fail Map Viewer's Session menu lets you change the active device; create, open, and save sessions; and close the program.

The menu contains these commands:

  • Change Device

    Choosing this command lets you switch to a different device, as described in Configuring the BFM Viewer.

    This resets the color scheme, filters, and display options to their defaults.

  • New

    Choosing this command creates a new Bit Fail Map Viewer session.

    This resets the color scheme, filters, and display options to their defaults.

  • Open

    Choosing this command lets you open an existing Bit Fail Map Viewer session that has been saved to disk.

  • Save

    Choosing this command saves the currently active Bit Fail Map Viewer session to disk.

  • Save As

    Choosing this command lets you save the currently active Bit Fail Map Viewer session to disk as a new file.

  • Exit

    Choosing this command closes the Bit Fail Map Viewer. Note you are not prompted to save changes, that is, all unsaved changes are always lost if you choose Exit.
