ACS TE-Cloud

Subtopics

  1. The TE-Cloud dashboard
  2. Help Center
  3. Working with virtual machines
  4. Accessing online testers
  5. External tools needed for working with virtual machines

The Advantest cloud solution (ACS) TE-Cloud platform provides a one-stand test engineering environment for test engineers. With the cloud virtual machine, you can get remote access to tester resources at Advantest labs and partner labs.

A cloud virtual machine provides secure computing capabilities based on the cloud services. With a cloud virtual machine, you can get access to and set up the computing resources per your needs.

To TE-Cloud platform consists of TE-Cloud dashboard and Help Center.

To set up and connect to a TE-Cloud virtual machine, follow these steps:
  1. Generating and saving key files
  2. Opening the TE-Cloud dashboard
  3. Creating a TE-Cloud virtual machine
  4. Configuring a remote connection to a virtual machine
  5. Connecting to a virtual machine via SSH
  6. Setting up a VNC connection
  7. Connecting to a virtual machine via VNC

When a virtual machine has been set up, you can perform these procedures to work with the virtual machine:

  • Transmitting files
    • Setting up a site to transmit files to and from the virtual machine based on SFTP
    • Transmitting files between Linux machines with command line
  • Setting up user accounts
    • Authorizing another user for a virtual machine
    • Revoking access to a virtual machine
    • Modifying the password of a virtual machine user account
    • Adding a user account to a virtual machine
  • Other procedures
    • Accessing a virtual machine from another virtual machine
    • Installing software to the virtual machine
To access the online tester resources, follow these steps:
  1. Getting contact information for an engineering test center
  2. Adding a public SSH key
  3. Booking a tester for a specific time slot
  4. Connecting to a tester over the internet
  5. Transmitting files to the tester

To get in touch with the TE-Cloud Support Team, send an e-mail to PDL-ATC-TECloud@advantest.com.

You can also chat with the support team in the TE-Cloud website. For users in China, see https://te-cloud.advantest.com.cn/. For users in Europe, see https://eu.te-cloud.advantest.com/.
