Using the Workorder Manager

To bring up the Workorder Manager and execute a workorder, you must first start SmarTest in operator mode from the command line as follows:

/opt/hp93000/soc/prod_env/bin/HPSmarTest -O &

The -O option forces SmarTest into operator mode.

Once SmarTest is up and running, the Workorder Manager GUI is presented to the operator. At this time, the operator makes the Workorder selection, assigns data to the test parameters (such as LotID or OperatorID), and then presses the Load button to begin execution. After the lot has been tested, the Workorder Manager reappears. To test another lot, the operator must follow the same procedure as just described.

SmarTest derives the complete path of the device and the test program by extracting the DUT_PATH and WORKORDER_PATH from the org file in /opt/hp93000/soc/prod_env.

The following is an example of an org file:

DUT_PATH = /devices

WORKORDER_PATH = /workorders

A workorder file could look as follows:

hp93000,workorder,0.1

device: 74ACT299

test_prog_rev:

test_prog: package_74ACT299

In the above examples, the workorder file will be found under the directory /workorders (can be local or NFS mounted) and the 74ACT299 device will be found under /devices/74ACT299 (local or NFS mounted). Note that the full path of the device can also be specified in the workorder file (for example, device: /devices/74ACT299).

If you know the workorder you wish to execute in advance, the Workorder Manager GUI step can be skipped by adding the workorder name to the command line, as follows:

/opt/hp93000/soc/prod_env/bin/HPSmarTest -O <workorder_name> &

If the org file does not specify the workorder path, SmarTest will try to find it under $HOME/workorder.

You can also specify the full path of the workorder:

/opt/hp93000/soc/prod_env/bin/HPSmarTest -O <path>/<workorder_name> &

Note that when you call SmarTest in operator mode and also specify a workorder, SmarTest will terminate after the lot has completed.

Note If the test_prog_rev is set and INSTALLED_DUT_PATH in the org file is set, the path of the device will be /INSTALLED_DUT_PATH/device/test_prog_rev.
