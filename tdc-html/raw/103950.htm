Topic 103950

Creating a pin mapping file

The pin mapping file maps pin definitions from the Device access file to pin or pin group specifications from the SmarTest Pin configuration file. The MTL compiler creates test patterns only for SmarTest pins for which APG pin names have been specified in the pin mapping file.

About this task

The easiest way for you to create a pin mapping file is to use the pin mapping file contained in the fundamental device. You can also build it from scratch using an editor, for example NEdit.

Before you begin

You need to have a pin configuration file for SmarTest defined with all pins and pin groups that are needed for MTL.

Procedure

  1. Open a file in NEdit.
  2. Type the pin names as used by the MTL program and equate it to the pin names as used in SmarTest.
  3. Add the global declarations (using statements) for:

    pinconfig, port, defaultxmode, and modecontext.

    If you use multiple ports add a using port statement for each port.

  4. Add the attributes for the individual pins in brackets. The default pin type is digital, which you need not to specify. The other attributes are cycle ratio, expansion size, and pin-specific x-mode
  5. Save the file as a .pmap. Choose the filename as you want to name it in the APG pattern file.

Results

The pin mapping file is now ready to use.

What to do next

If all MTL files are complete, you can start a compile run.
