UTILITY_POWER_STATUS

Subtopics

  1. UTILITY_POWER_STATUS.state()
  2. UTILITY_POWER_STATUS.checkState()

  4. UTILITY_POWER_STATUS.execute()

Switches a utility power supply on or off or queries the state of a utility power supply.

The utility power supplies that can be controlled or queried are the utility power supplies of the optional Utility Card or the Internal utility power supplies.

The UTILITY_POWER_STATUS object can be added to a TASK_LIST.

Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/UtilityPowerStatus.h.

constructor
UTILITY_POWER_STATUS();
List of parameters
The constructor has no parameters.
Return value
The constructor has no return value.
Member functions
  • UTILITY_POWER_STATUS.state()
  • UTILITY_POWER_STATUS.checkState()
  • UTILITY_POWER_STATUS.wait()
  • UTILITY_POWER_STATUS.execute()

Example

UTILITY_POWER_STATUS utilityPowerOn;

ON_FIRST_INVOCATION_BEGIN();

    if ( firstRun == true )
    {
        //
        // Switch the Utility power supply - XP pins (V93000 EXA Scale systems) of the first Utility Card on
        //
        utilityPowerOn.state(TM::POWER_ON);
        utilityPowerOn.wait(10 ms);
        utilityPowerOn.execute(); 

        firstRun = false;
    }

ON_FIRST_INVOCATION_END();
