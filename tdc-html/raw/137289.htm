Exporting data logs

  1. At the top of the dialog, check all data logs that you want to export.
  2. In the Options part, check all summaries that you want to export for each log.

    When you export correlated data stores, you can choose to export tests grouped by wafer, site, or pin as a collection of columns (Vertical) or rows (Horizontal).

  3. Specify the target folder and tell SmarTest whether it is OK to overwrite existing files with the same names.
  4. Click Finish.

The files are exported to the folder you specified. They are named <log-name>.<table-type>.csv, where <log-name> is the filename of the exported log and <table-type> indicates the exported table (tsum, wsum, dsum, hbin, or sbin).
