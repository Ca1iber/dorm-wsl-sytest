GET_TESTER_CLASS

This API returns the class (Pin Scale or P/C/Ce) of the tester in use.

After getting the tester class, you can perform different operations on different platforms. This avoids the risks that occur because of performing the same operation on different platforms.

Enumeration Types

The enumeration TESTER_CLASS is defined to specify the class of the tester.

namespace TM {
    enum TESTER_CLASS {
                       P_C_CE,
                       PINSCALE,
                       UNKNOWN_CLASS
              };
        }

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

Const TESTER_CLASS& GET_TESTER_CLASS();

Return Value

The tester class is returned. For Smart Scale test system, TM::PINSCALE is returned.

Example

This example is a part of a voltage measurement program. pinList, preCharge, dCurrentRange and forceCurrent are parameters defined in the test method. PmuUtil::ppmuPreCharge() is a function defined in PmuUtil.hpp of dc_tml.

PPMU_SETTING settingPpmuFirst;
PPMU_SETTING settingPpmuPrecharge;
TASK_LIST   tasklist;
PPMU_CLAMP ppmuClampOn;
PPMU_CLAMP ppmuClampOff;
DOUBLE low, high;
LIMIT limit;

limit.getLow(&low);
limit.getHigh(&high);
settingPpmuFirst.pin(pinList)
                .iRange(dCurrentRange uA)
                .min(low)
                .max(high)
                .iForce(forceCurrent uA);
/* pinList, dCurrentRange and forceCurrent are the input parameters defined in the program. */

TM::TESTER_CLASS testerClass;
testerClass = GET_TESTER_CLASS();

/*  1. determine whether to precharge (P/CE) or set the clamp (PinScale)*/
if( testerClass == TM::PINSCALE )
{
  tasklist.add(settingPpmuFirst);
  /* clamp low/high are fixed to -0.1V/0.1V */
  ppmuClampOn.pin(pinList)
             .status("CLAMP_ON")
             .low(-0.1 V)
             .high(0.1 V);
  ppmuClampOn.wait(1 ms);
  tasklist.add(ppmuClampOn);
}
else
{
  if ( preCharge == 1)
  {
    /* precharge voltage is fixed to 0.0V */
    PmuUtil::ppmuPreCharge(settingPpmuPrecharge,pinList,0.0,tasklist);
  }
  else
  {
    tasklist.add(settingPpmuFirst);
  }
}

The first several lines define the variables that will be used in the measurement. Next, the variable settingPpmuFirst is filled with some data. Then the tester class is retrieved with the GET_TESTER_CLASS API. If it is Pin Scale system, the PPMU clamp voltages are set to +/-0.1V. If it is P/C/Ce system, the precharge voltage is set to 0V or the precharge is disabled according to the parameter preCharge.
