SHMOO_RESULT.pin()

This member function defines the specific pin or pin group for the results to be displayed on a shmoo plot.

The displayed results are defined with the setResult() member function.

If you do not use the member function, the result pin will be all pins (@).

If you have defined multiple pins and pin groups, use the Shmoo Tool to view the shmoo plots of different pins or pin groups. For details, see Viewing the shmoo plots of different pins with the Shmoo Tool.

Syntax

ShmooResultAdapter& pin(const STRING& pin);
Parameter

Parameter

Description

pin

The name of a pin or a pin group.

Return value

Returns an instance of the ShmooResultAdapter class.

Example

double meaValue1;
SHMOO_RESULT.pin("IO1").setResult(meaValue1);
