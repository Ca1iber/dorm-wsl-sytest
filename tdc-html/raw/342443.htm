Functions like RDI_BEGIN(), RDI_END() and RDI_INIT() are mandatory for using SmartRDI to program a test method.

RDI_UNIT_INIT() and RDI_WAIT_TEST_DONE() are often used together with them.

See Code structure with SmartRDI for details on general SmartRDI code struture.
