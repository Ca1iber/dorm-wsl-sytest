Variables

The DUT Representation Language (DRL) supports untyped variables. Variables can contain integers as values.

In principle, variables can also contain tuples, although it is rarely useful to use them in this way.

You can use these variables in statements as in standard C, assigning values to them and using them in statements. Two special constructs not found in standard C, indexed variables and system variables, are described below.

There is no separate initialization of variables in DRL; to define a variable, simply assign it a value. Later assignments overwrite earlier ones.

Indexed variables

While you can use variables in the standard way in DRL (for example, myVar = 3 * testVar), you can also use them as indexed variables, which are similar to one-dimensional arrays. For example: myOtherVar(0) = 23.

Each indexed variable can be read and written independently from the others. Indexes are appended to the variable name in parentheses and can be any positive number or zero.

System variables

System variables are much like normal variables. However, in contrast to normal variables they are predefined, although they do not initially contain values. That is, the variables exist at the beginning of each DRL program but must be assigned values before they can be used.
