Topic 146474

DIGITAL_OFFSET_SEARCH_TASK.setExecutionContext()

Refers to an execution context that has been defined with the SEQUENCER_CONTEXT API or the SQEC firmware command, so that you can apply the offset search on the ports that the execution context refers to.

Syntax

void setExecutionContext(const STRING& context);
Parameter

Parameter

Description

context

An execution context you have already defined with the SEQUENCER_CONTEXT API or the SQEC firmware command.

Return value

There is no return value.
