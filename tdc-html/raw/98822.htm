UDGP - (UnDefine GrouP)

The UDGP (UnDefine GrouP) command dismantles a group that has been previously defined by DFGP or DFGE.

Syntax

UDGP {(group)}

Parameters

group

Defines the name of the group of pins to be removed. The symbol @ can be used to dismantle all groups. If more than one group is to be removed, the names must be separated by a comma.

Application

Pin configuration, see Configuration Setup Commands.

Example

UDGP (Qout)

This command dismantles the group entitled Qout.

Functional changes

  1. Introduced before SmarTest 6.3.2
