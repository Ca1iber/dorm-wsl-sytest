EVENT_WAVEFORM_VCVM.getRepeatCount()

Reads the number of repeats of the waveform that has been defined by EVENT_WAVEFORM_VCVM.vClampLow() or EVENT_WAVEFORM_VCVM.vClampHigh().

The number of repeats is read from the corresponding EVENT_WAVEFORM_VCVM object and returned as an integer value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

void getRepeatCount(INT & repeats) const;
Parameter
Parameter Description
repeats

The read repeat count.

Note: The member function getRepeatCount() of DC events returns always 1 as repeat count.

Return value

There is no return value.

Example

For an example see EVENT_WAVEFORM_VCVM.
