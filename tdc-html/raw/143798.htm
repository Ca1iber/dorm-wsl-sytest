interSkip()

Specifies the number of consecutive samples to capture and the number of consecutive samples to discard.

This function skips iInterSkipSamples samples for each iBlockLength captured samples.

Syntax

interSkip(int iBlockLength ,int iInterSkipSamples);
Parameter List

Parameter

Description

iBlockLength

The number of samples to capture

iInterSkipSamples

The number of samples to discard

Example

rdi.digCap("norm").label("lpDcap_new").pin("DATA2").samples(100).interSkip(2,3).execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
