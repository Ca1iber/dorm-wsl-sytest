TestFunctionStartEventType

An event of this type is logged every time a test function or test method is executed for one of the sites involved in the test.

Attributes

  • TestSuiteNameAttrType

    Holds the name of the test suite that was executed.

  • SiteIdAttrType

    Holds the ID of the site for which the test function is executed.

  • TestFunctionTypeAttrType

    Holds the name of the executed test function.

  • TestFunctionParametersAttrType

    Holds the test function parameters used to call the test function, but without the first parameter, which is the test function name.

  • LevelsAttrType

    Holds the set numbers that define the levels used in the test function.

  • TimingsAttrType

    Holds the set numbers that define the timing used in the test function.

  • LabelAttrType

    Holds the label of the vectors used for the test function.

  • TimeStampAttrType

    Holds the time when execution of the test function was started.

Functional changes

  1. Introduced before SmarTest 6.3.2
