C/C++ editor

The Editor view gives you specific features for editing and debugging your test method code. This editor is opened when you double-click a test method file in the Project Explorer view.

The Editor view includes the following features:

  • Syntax highlighting
  • Content assist
  • Integrated debugging features
  • Test method panel

Using the content assist in the C/C++ editor:

You can customize some operations of the Editor view in the preference dialog (on the Preferences window, see section C/C++).

This editor does not contain a toolbar itself, but relies on the use of the main toolbar, edit menu, search menu and key binding actions (see Keyboard shortcuts - context related).

C++ options

To support testmethod development, SmarTest builds on top of the C/C++ Development Tooling (CDT).

The CDT is active when developing or debugging C++ code. It comes with multiple preferences to customize look and feel (like syntax highlighting, folding, and automatic formatting), the automatic indexer (turning it off can give higher UI performance for network file system (NFS) based project folders), and the behavior of the build console.

Functionality settings for testmethod development (makefile settings, build properties etc.) are set automatically for SmarTest testmethod projects. Do not change these settings!
