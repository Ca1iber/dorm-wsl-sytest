DRLNamedValueAttr

A variable of this type is a pointer to a structure named _DRLNamedValueAttr. In this structure a name and its value are stored, where the value can be of various types.

The member name holds the name as a NULL terminated string. The member type specifies the type of the value and determines which of the elements of the unit val is valid. type can be any of the values listed below. 

typedef const struct _DRLNamedValueAttr {
  char *name;
  unsigned char type; /* DRLStringValue,
                         DRLIntegerValue,
                         DRLDoubleValue */
  union {
    char *s;
    int i;
    double d;
  } val;
} *DRLNamedValueAttr;
