Topic 125410

Multisite handling

The V93000 multisite mechanism is used to run protocol tests on multiple-sites.

However, the following topics need to be considered for proper use:

  • Protocol test objects are to be set up and executed inside an ON_FIRST_INVOCATION block.
  • The objects have to be declared outside the ON_FIRST_INVOCATION blocks because they must be accessible for result retrieval.
  • The result retrieval and the result analysis is done per site (either outside of the ON_FIRST_INVOCATION block or in a FOR_EACH_SITE block)
  • The structure (i.e. set, order and type) of executed transactions is always the same for all sites. Values can differ per site.
  • Sequencing per site is not supported.
  • Values are set per site. If no value is set for specific sites, the default value ('0') will be used. In this case no error will be issued!
