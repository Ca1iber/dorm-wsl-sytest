Selecting a Prober/Handler command set

The application file uses handler or prober commands at different times during the test program. These commands address scripts, procedures or programs in the prober/handler command set.

  1. In the Test Program Explorer highlight the item Prober/Handler.
  2. Right-click and select Load... All available handler/prober command sets appear in a browser window.
  3. Select the desired prober/handler command set and click OK.
