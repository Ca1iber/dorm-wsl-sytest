TestNumGen

The TestNumGen class provides a way to automatically and consistently number tests.

Test numbering with TestNumGen does not vary across multiple runs of a testflow or when the same testflow is run on multiple testers. This makes aggregating and comparing the event data logs from multiple test easy.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/TestNumGen.hpp.

applyGlobalLoopSettings()

bool applyGlobalLoopSettings(TestTable* testTable)

Writes the testflow loop and test method loop settings made with setTestFlowLoopIncrement() and setTestFlowLoopIncrement() to the testflow file. These loop settings can only be applied to testflow content, not to CSV files.

Parameter

testTable

A pointer to the TestTable object to which the loop settings are to be applied

clear()

void clear(TestTable* testTable, int testNumFieldPos, int startOffset, int endOffset)

Deletes the test numbers in the specified table and replaces them with the empty string. Optionally, you can also specify a range within the table, in which case only the test numbers in that range are cleared.

Parameters

testTable

A pointer to the TestTable object from which the test numbers are to be deleted

testNumFieldPos

The position of the test number field within the table.

For example, if the test number field is the third column, specify 2 for this parameter. (Column numbering starts with 0.)

startOffset

The index of the first test from which the test number is to be cleared.

For example, if clearing is to start with the second row, specify 1. (Test numbering starts with 0.)

If no start offset is specified, clearing begins with the first test.

endOffset

The index of the last test from which the test number is to be cleared.

If no end offset is specified, clearing ends with the last test.

generate()

bool generate(TestTable* testTable, int testNumFieldPos, int startOffset, int endOffset)

Generate test numbers for each test in the specified table or for each test in a range that you specify within the table, according to the settings specified via the set<function specification>() functions.

Parameters

testTable

A pointer to the TestTable object from which the test numbers are to be deleted

testNumFieldPos

The position of the test number field within the table.

For example, if the test number field is the third column, specify 2 for this parameter. (Column numbering starts with 0.)

startOffset

The index of the first test for which the test number is to be generated.

For example, if number generation is to start with the second row, specify 1. (Test numbering starts with 0.)

If no start offset is specified, test number generation begins with the first test.

endOffset

The index of the last test for which the test number is to be generated.

If no end offset is specified, test number generation ends with the last test.

getUseTestFlowLoopIncrement()

bool getUseTestFlowLoopIncrement()

Returns information on whether the testflow loop increment is to be written to the testflow file before the test numbers are generated:

  • true: The testflow loop increment setting from the TestNumGen object is written to the testflow file.
  • false: The testflow loop increment data are not written to the testflow file.

getUseMethodFlowLoopIncrement()

getUseMethodFlowLoopIncrement()

Returns information on whether the test method loop increment is to be written to the testflow file before the test numbers are generated:

  • true: The test method loop increment setting from the TestNumGen object is written to the testflow file.
  • false: No test method loop increment data are written to the testflow file.

isDuplicateNum()

bool isDuplicateNum(TestTable* testTable, int num)
bool isDuplicateNum(TestTable* testTable, int testNumFieldPos, int num)

Returns true if the specified number is a duplicate, that is, if it has already been assigned to a test in the TestTable object, and false if it is not.

You can use this function to test for test number collisions after running a testflow.

Parameters

testTable

A pointer to the TestTable object against which the number is to be checked

num

The number to be checked

testNumFieldPos

The position of the test number field within the table.

For example, if the test number field is the third column, specify 2 for this parameter. (Column numbering starts with 0.)

isTestNumEnableFlagSet()

bool isTestNumEnableFlagSet()

Returns true if the test_num_enabled flag is set for the active testflow and false if the flag has not been set.

The Test Number Generator works properly only if the flag is set.

isTestNumMgrFlagSet()

bool isTestNumMgrFlagSet()

Returns true if the test_num_mgr_enabled flag is set for the active testflow and false if the flag has not been set.

For working with the Test Number Generator, this flag must be disabled.

setNumIncrement()

setOverwriteMode()

void setOverwriteMode(bool overwrite)

Specifies whether generating new test numbers overwrites existing numbers.

Parameter

overwrite
  • true: When test numbers are generated, those test in the specified range that already have numbers get new numbers.
  • false: When test numbers are generated, they are generated only for tests that do not yet have a number.

setUseTestFlowLoopIncrement()

void setUseTestFlowLoopIncrement(bool use)

Switches the use of testflow loop increments in generating test numbers on or off.

Parameter

use
  • true: Calling applyGlobalLoopSettings() increments all loops in the testflow by the value specified in the TestNumGen object (using the setTestFlowLoopIncrement() function).
  • false: The test numbering increments in the testflow file are not changed when applyGlobalLoopSettings() is called.

Switches the use of test method loop increments in generating test numbers on or off.

Parameter

use

  • false: The test numbering increments in the testflow file are not changed when applyGlobalLoopSettings() is called.
