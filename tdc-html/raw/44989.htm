Program Command Set Error Messages

The following error messages can occur when you execute a program Command Set:

CI: execute_command: comment truncation warning

This message occurs when too many bytes have been included in the comment, causing it to be truncated. Solve the problem by looking at the command that you have implemented and reducing the number of bytes written as comment.

When a program crashes, the following message is displayed:

CI: child died:<reason>

where reason is one of the following:

"",

"Hangup",

"Interrupt",

"Quit",

"Illegal Instruction",

"Trace Trap",

"IOT instruction",

"EMT instruction",

"Floating Point Exception",

"Kill",

"Bus Error",

"Segmentation Violation",

"Bad arg to system call",

"Write on Pipe",

"Alarm Clock",

"Terminate Signal",

"User Signal 1",

"User Signal 2",

"Death of Child",

"Power Fail",

};

or when the software cannot identify the signal:

CI: child died: signal <num>

where num is the signal number received.

Solve this error by debugging the program and then fixing the error.

The following are general internal program errors that can only be resolved by Advantest personnel:

CI: ci_main: illegal message queue id

CI: ci_main: illegal action identifier

CI: execute_command: illegal message queue id

CI: cons_check: illegal message queue id
