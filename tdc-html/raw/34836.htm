DRLShmooLegendAttr

A variable of this type is a pointer to a structure named _DRLShmooLegendAttr. This structure holds the complete data defining a sweep test.

title holds the title of the sweep test as a NULL terminated string.

shmoo_kind holds the information about the type of the sweep test. It is one of the values defined in the enumeration DRLShmooKind:

DRLShmoo2D

DRLShmooTrack

DRLShmooSpec

shmoo_mode holds the information whether the sweep test was executed in normal or fast mode. shmoo_mode can be either DRLShmooNormal or DRLShmooFast, as defined in the enumeration DRLShmooMode.

test_mode holds the information about the test mode of the sweep test. It can be one of the values defined in the enumeration DRLShmooTestMode:

DRLShmooTestNormal

DRLShmooTestERCT

DRLShmooTestFFCI

axis_xy contains the full definition of the two master axes x (axis_xy[0]) and y (axis_xy[1]), and of the tracking parameters. See DRLShmooAxisXYInformation for a full description. DRL_SHMOO_MAX_XY_AXIS is 2.

typedef struct _DRLShmooLegendAttr
{
  const char *title;
  DRLShmooKind shmoo_kind;
  DRLShmooMode shmoo_mode;
  DRLShmooTestMode test_mode;
  DRLShmooAxisXYInformation axis_xy[DRL_SHMOO_MAX_XY_AXIS];
} *DRLShmooLegendAttr;

Functional changes

  1. Introduced before SmarTest 6.3.2
