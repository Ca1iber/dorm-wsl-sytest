DRLSave

int DRLSave (DRLDataStream *stream, const char *filename, int truncate)

This function saves the data log stream/file associated with stream to a file.

The system data log stream is implemented as a file in the temporary directory. The function DRLSave copies this file to the path and filename you specify in filename. The copied file can be accessed later by the DRL for offline analysis of data log data (see DRLStart).

Note that an existing file with the same name as that given in path will be overwritten.

As new event records are always appended to the data log stream, the stream constantly grows in size and may contain older event records that are no longer of interest. Therefore, DRLSave also lets you clear the data log stream after saving it. If the parameter truncate is true (=1), the data log stream will be cleared directly after it has been copied to the file. All pointers to the data log stream and the event counter will be reset (see also DRLStart and DRLTruncate.

The parameter truncate will be ignored if stream references a data log file and not the data log stream. In any event, the data log file will be copied to the location specified in path.

Return Value

The return value is zero if the function was successful or one of the following error codes (see Error Codes) is returned in case of an error:

  • ERR_ACCESS: the path specified in path could not be accessed
  • ERR_TRUNC: the data log stream could not be truncated

Functional changes

  1. Introduced before SmarTest 6.3.2
