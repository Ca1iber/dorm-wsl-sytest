DUT board design overview

Subtopics

  1. Release information
  2. Safety information
  3. DUT board planning

This reference provides the information needed to design DUT boards, wafer prober interface boards, and wafer probe cards for the V93000. It is not intended to provide comprehensive information about the V93000 hardware, software, and testing capabilities. If you need additional information on these topics, refer to the appropriate section in the V93000 documentation.

This guide also is not intended to provide information on generic printed circuit board (PCB) design and manufacturing. For generic design recommendations please refer to the references provided in the various topics.

Modular design

The V93000 test system head is designed to allow the installation of many different combinations of digital, analog, and RF cards. Because of this variability, it is important for the DUT board designer to have accurate information about the configuration of the specific test system head on which the DUT board will be used.

Compatibility between individual test systems

If carefully designed, a DUT board can be made to operate on test systems with different test head configurations, including test heads of different sizes. Advantest often recommends specific configurations to customers to increase the potential for universal applicability of DUT boards. Considerations include careful selection of DPS, utility, digital, and analog resource assignments as well as consideration of mechanical features of the DUT board. Where appropriate, this manual will highlight those features which require extra consideration when designing a DUT board such that it will function properly on many different test systems.

Handler support

Properly integrating a test system to a packaged parts handler for production testing requires specific hardware that varies with the equipment involved. In some cases, this hardware requires modification for use with a particular device or test application. The mechanical information for DUT boards and DUT board stiffeners in this design guide applies only to the handler setups that are listed on the respective stiffener drawings.

Non-standard configurations

Advantest sometimes provides customized interface equipment (wafer prober interfaces, stiffeners, and test heads) to customers for specific test applications. Customized versions are identified by an additional product option, such as "E2812A #I02", printed or engraved on parts of the test head or on the interface.

Customers or third parties also sometimes use nonstandard hardware or modify existing hardware. Before designing your DUT board, determine first whether any nonstandard interface hardware is being used.
