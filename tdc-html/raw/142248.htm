STPM menu

The STPM UI plug-in provides access to its functions through the STPM menu and a submenu in the Testflow Editor shortcut menu.

Both menus contain global commands (that affect the entire test program), while commands affecting only selected test groups are contained only in the submenu of the Testflow Editor shortcut menu.

The STPM menu contains these commands:

  • Clear Unused: Lets you remove unused primaries from the testflow, similar to the clear_unused control file command.

    The command opens the Clear Unused dialog, where you can set the desired parameters.

    This command is not present in the Testflow Editor shortcut menu.

  • Clear Duplicated: Lets you remove duplicated primaries from the testflow, similar to the clear_duplicated control file command.

    The command opens the Clear Duplicated dialog, where you can set the desired parameters.

    This command is not present in the Testflow Editor shortcut menu.

  • Extract Selected: Lets you extract test groups from a master test program (MTP) into a source test program (STP), similar to the extract_subflow control file command.

    The command opens the Extract Subflow dialog, where you can set the desired parameters. If no test group is selected, the command displays an error instead. If one or more test groups are selected plus additional testflow elements (for example, bins), the additional elements are ignored.

  • Merge Selected: Lets you integrate test groups from an STP into an MTP, similar to the merge_subflow control file command.

    The command opens the Merge Subflow dialog, where you can set the desired parameters. If no test group is selected, the command displays an error instead. If one or more test groups are selected plus additional testflow elements (fr example, bins), the additional elements are ignored.

  • Extract Selected [Quick]: Lets you save the selected test groups as a new test program, similar to the extract_subflow control file command.

    The selected test groups are saved with the default settings of the extract_subflow command.

  • Merge Selected [Quick]: Lets you replace selected test groups with test groups with the same names from an external test program, similar to the merge_subflow control file command.

    The merge process is performed with the default settings of the merge_subflow command.
