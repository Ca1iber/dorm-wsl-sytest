Topic 55363

Pass/fail judgment of test method based test suite in a testflow

In a test suite, if all TEST APIs in the test method program judge the test results as pass, the test suite is handled as pass in the testflow even in the multiport test. If any test result is judged as fail in a TEST API, the test suite is handled as fail in the testflow.

Functional changes

  1. Introduced before SmarTest 6.3.2
