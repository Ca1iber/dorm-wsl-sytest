DIGITAL_OFFSET_SEARCH_TASK.execute()

Executes the timing or level offset search for the pins specified with DIGITAL_OFFSET_SEARCH_TASK.pin().

Syntax

void execute();

List of parameters

There are no parameters.

Return value

There is no return value.
