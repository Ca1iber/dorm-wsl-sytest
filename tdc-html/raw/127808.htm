TESTSET().hlmFmt()

This member function of TESTSET assigns the format for displaying the higher limit in the data formatter output.

Calling this function stores the supplied format string in the C_HLMFMT fields of the parametric test record (PTR) and the multiple-result parametric record (MPR).

This function is not supported within the SMC_backgroundProcessing() test method when flag hidden_datalog_mode is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

Syntax

TESTSET & hlmFmt(const STRING &format);

Parameter

Description

format

A string describing the desired format. The string is a standard ANSI C format string, for example, "%7.3f".

Example

TestSet.hlmFmt("%7.3f");
