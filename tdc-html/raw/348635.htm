The Wave Scale Millimeter (WSMM) solution is an extension of the V93000 DUT interface providing an integrated test solution for 5G and WiGig applications. The solution is based on the Wave Scale RF card and extend its capabilities for IF (5.85 to 18 GHz) using RFIM-18 modules, and for mm-Wave frequencies using Remote Mixing Modules (RMMs).

Supported V93000 systems : EXA Scale (SmarTest 8), Smart Scale (SmarTest 8)

Main components of the Wave Scale Millimeter (WSMM) solution

The solution consists of three main components as shown below and one or more Wave Scale RF with RFIM-18 in the test head.

The functionality of the main components is as follows:
  • WSMM DUT Board

    The DUT board connects the DUT to the DUT interface of the WSMM card cage. The board features four groups of WSMM RF ports, resources of the DUT Scale interface in four groups of pogo blocks and direct access to RFIM-6 and RFIM-18 ports of the Wave Scale RF card. Compared to the DUT scale interface, the pogo block groups and RF ports are shifted outwards providing more application space in the center of the board.

    For information on how to design the DUT board and the stiffener, refer to
    • Wave Scale MM PCB layout and stiffener info for Direct-Probe and
    • Wave Scale MM PCB layout and stiffener info for final test.
  • WSMM Card Cage

    The card cage holds the active components of the solution, features the WSMM Card Cage DUT Interface and the docking mechanism for the "WSMM DUT board", and connects to the pogo blocks and RF ports of the DUT Scale interface.

  • WSMM Card Cage Family board

    The family board is integrated into the "WSMM Card Cage". The family board routes the resources of the DUT Scale interface to the DUT interface of the WSMM card cage.

    For the WSMM Family Board E8027FAA, the mapping of pogo blocks and pogo pins is available in
    • WSMM Family Board E8027FAA pogo block mapping and
    • WSMM Family Board E8027FAA pogo pin mapping.
