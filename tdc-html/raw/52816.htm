Topic 52816

Defining connect/disconnect sequences

SmarTest provides you with the flexibility to modify the behavior of the standard connect/disconnect sequence.

CAUTION If you plan to make use of this feature, you must have expert knowledge of the test system. Otherwise it is possible that you may write command files that cause damage to your test device or the test system, or both.
Note On startup SmarTest always performs a standard disconnect.

Standard connect/disconnect sequence

The standard connect/disconnect sequence, which can be used as model for your own sequences, is as follows:

Connect:

 
RLYC CNCT,OFF,(@)
PSST ON
CNCT ON,(@)
SQST BRK

Disconnect:

 
DLSO (@)
CHRS OFF
FLSH MUX
WSDN
SQST OFF
CNCT OFF,(@)
BCMD "",ACTION,"Update",
PSST OFF
RLYC IDLE,OFF,(@)

User-defined disconnect sequence

To write your own command files that define a connect/disconnect sequence for DPSs, use the enhanced PSST command to define a series of specific pinlists (see PSST, PSST? - (Power Supply STatus)), for example:

Connect:

 
RLYC CNCT,OFF,(@)
PSST ON,(pinlist for DPS1)
PSST ON,(pinlist for DPS2)
CNCT ON,(@)
SQST BRK

Disconnect:

 
SQST OFF
CNCT OFF,(@)
CHRS OFF
FLSH MUX
WSDN
PSST OFF,(pinlist for DPS2)
PSST OFF,(pinlist for DPS1)
RLYC IDLE,OFF,(@)

Using this feature has the following restrictions:

  • To keep the throughput, the files are read only during a software start or a device change. Editing a file while the software is running may not have any effect.
  • Shared multisite is not supported with this feature.
