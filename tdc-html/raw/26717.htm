SetErrorMapMode

This routine lets you determine the mode in which the results are recorded for the result displays (for example, the Error Map) when executing a test.

Syntax

VOID SetErrorMapMode(
    INT32     mode);

Parameters

The mode variable supports two values:

  • ERROR_MAP_FAILURE_ORIENTED to set the error map to failure oriented mode (only failed cycles are logged in the error map).
  • ERROR_MAP_CYCLE_ORIENTED to set the error map to cycle oriented mode (all cycles are logged in the error map).

Defaults

Initially (while loading) the error map mode is set to ERROR_MAP_CYCLE_ORIENTED.

Example

SetErrorMapMode(ERROR_MAP_FAILURE_ORIENTED);

Functional changes

  1. Introduced before SmarTest 6.3.2
