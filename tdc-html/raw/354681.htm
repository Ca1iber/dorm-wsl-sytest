iClampTimeToAlarm()

Sets a period of current clamp time in seconds. When the current clamp action spends a time longer than the time period, the "" status flag is set.

This function can be only used in the code‑based mode.

This function only supports DC Scale XPS256 card in the PMU operating mode.

See also Current limit disconnect in XPS256 status flags.

Syntax

dcBase& iClampTimeToAlarm(double timeToAlarm);

Example

rdi.dc().pin("XPS256_PMU_1").iForceRange(50 mA).iForce(5.0 mA).vClamp(-5.0, 5.0 V).iClampTimeToAlarm(1 s).execute();

Functional changes

  1. Introduced in SmartRDI 7.10.1
