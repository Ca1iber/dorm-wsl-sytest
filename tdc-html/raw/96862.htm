ERROR_COUNT_ACQUIRE_PIN

This class is a data container to hold different acquisition condition for pins. You can access this class object by the member function pin(const STRING& pinlist) of ERROR_COUNT_ACQUIRE. You cannot directly create any objects of this ERROR_COUNT_ACQUIRE_PIN class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ErrorCountAcquirePin.h.

Class definition

In this class, the following eight member functions are defined.

ERROR_COUNT_ACQUIRE_PIN & port(const STRING& port);
ERROR_COUNT_ACQUIRE_PIN & spec(const STRING& specVar, TM::SPEC_TYPE specType);
ERROR_COUNT_ACQUIRE_PIN & start(const DOUBLE start);
ERROR_COUNT_ACQUIRE_PIN & stop (const DOUBLE stop);
ERROR_COUNT_ACQUIRE_PIN & stepWidth(const DOUBLE stepWidth);
ERROR_COUNT_ACQUIRE_PIN & numberOfSteps(const INT steps); 
ERROR_COUNT_ACQUIRE_PIN & enableFastStop(DOUBLE lastStepWidth,
                          const INT stableSteps);
ERROR_COUNT_ACQUIRE_PIN & errorCountMode (const TM::ERROR_COUNT_MODE  mode);

Member functions

port()

ERROR_COUNT_ACQUIRE_PIN & port(const STRING& port);

This member function specifies the port name.

Parameter

port

The port to be used for acquiring error count. Default value is "@" for all ports.

spec()

ERROR_COUNT_ACQUIRE_PIN & spec(const STRING& specVar, TM::SPEC_TYPE specType);

This member function specifies the spec variable to be shifted.

Parameters

specVar

The spec variable to be shifted in the error count acuqisition.

specType

The type of the spec variable.It can be TM::TIM or TM::LEV.

start()

ERROR_COUNT_ACQUIRE_PIN & start(const DOUBLE start);

This member function specifies the start value of the spec variable in the error count acquisition. The acquisition is always from start to stop value.

Parameter

start

The start value of the spec variable in error count acquisition. Its unit is the same as the unit of spec variable.

stop()

ERROR_COUNT_ACQUIRE_PIN & stop(const DOUBLE stop);

This member function specifies the stop value of the spec variable in the error count acquisition.

Parameter

stop

The stop value of the spec variable in error count acquisition. Its unit is the same as the unit of spec variable.

stepWidth()

ERROR_COUNT_ACQUIRE_PIN & stepWidth(const DOUBLE stepWidth);

This member function specifies the acquisition step width for the error count retrieving. It must be positive. If the number of steps is specified later, step width is overridden.

Parameter

stepWidth

The step width of error count acquisition. Its unit is the same as the unit of the spec variable.

numberOfSteps()

ERROR_COUNT_ACQUIRE_PIN & numberOfSteps(const INT steps);

This member function specifies the number of steps for the error count retrieving. It must be a positive number. If step width is specified later, the number of steps is overridden.

Parameter

steps

The number of steps for error count acquisition. It must be positive number.

enableFastStop()

ERROR_COUNT_ACQUIRE_PIN & enableFastStop(DOUBLE lastStepWidth,
                          const INT stableSteps);

This member function activates the fast stop of acquisition after arriving at the stable error count area. In this mode, when the error count keeps stable for stableSteps steps, the step width will be changed to lastStepWidth. If the next position is beyond stop position or the error count of next position is the same as the error count before, the acquisition is stoped. If the error count of next position is not the same as the error count before, the step width is changed to normal step width and the error count acquisition is started again.

Parameters

lastStepWidth

The last step width needed in algorithm to identify whether the stable area is reached.

stableSteps

The number of consecutive steps with the same error count, which triggers the identification of stable error count area. Default value is 9. It must be positive number.

errorCountMode()

ERROR_COUNT_ACQUIRE_PIN & errorCountMode(const TM::ERROR_COUNT_MODE mode);

This member function specifies the error count acquisition mode, per cycle or per edge.

Parameter

mode

The error count acquisition mode. It can be TM::ERROR_PER_CYCLE: Acquire the error count once per cycle.

or

TM::ERROR_PER_EDGE: Acquire the error count once per edge.
