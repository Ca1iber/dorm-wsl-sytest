List of parameters

Parameter

Description

name

The name of the parameter which value can be changed at runtime.

value

The value to be used at runtime. The array type of value can contain different values for different sites.

For digital channel relay control

Sometimes relay actions are based on a previous result, or needs to be site dependent. For this purpose, SmartRDI provides the following commands to support runtime values for digital relays:
  • setOnRunTime()
  • setOffRunTime()
  • runTimeVal()
runTimeVal(string runTimeValueString, vector <string> runTimeAction);
List of parameters

Parameter

Description

runTimeValueString

The string defines the runtime value.

runTimeAction

The string defines the runtime actions. It can be any combination of the strings:

  • "DC"
  • "AC"
  • "PPMU"

separated by a comma (",").

Only the values introduced here are acceptable.

Starting from SmartRDI 7.6.0, The "NO" action value is supported by hwRelay. "NO" means No Change. If you intend to open a type of relay on one site while close the same type of relay on another, you can use "NO" in runtime.

"NO" only works for setOnRunTime() and setOffRunTime(). When "NO" is used, setOnRunTime() and setOffRunTime() must be used together.

For the relay of each site, the combination actions of setOn() and setOff() cannot have NO change.

See the Example

Examples

Using different values for different sites

ARRAY_D rtv_arr(4);
rtv_arr[0]=1.0; 
rtv_arr[1]=1.1; 
rtv_arr[2]=1.2; 
rtv_arr[3]=1.3;

rdi.runTimeVal("rtv",rtv_arr);

Using the same value for all sites

double vol; vol=1.5;
rdi.runTimeVal("vvv",vol);

Controlling relays

vector <string> rtRelay(2); // 2 sites
  rtRelay[0] = "AC";        // AC relay on site 1 is selected
  rtRelay[1] = "PPMU";      // PPMU relay on site 2 is selected
                
rdi.runTimeVal("rtd", rtRelay);
                
RDI_BEGIN();
  rdi.hwRelay().pin().setOnRunTime("rtd").execute();
RDI_END();
"NO" action on one site and some action on another in runtime
vector<string> vecOn(2), vecOff(2); //2 sites
  vecOn[0]="NO";  vecOn[1]="AC"; 
  vecOff[0]="AC"; vecOff[1]="NO"; 

rdi.runTimeVal("rt1",vecOn);
rdi.runTimeVal("rt2",vecOff); 

//----------- site1 opens AC; site2 closes AC----------------------------
RDI_BEGIN();
  rdi.hwRelay().pin("A").setOnRunTime("rt1").setOffRunTime("rt2").execute();
RDI_END();
Alarm checking on pins using runTimeVal()
...
rdi.runTimeVal("rtvForce", rtvForce);
rdi.dc().pin("rtvPin").vForce(0 V).iClamp(50 uA).execute();

RDI_BEGIN();
  ...
  rdi.dc("id").pin("rtvPin").vForce("rtvForce").iClamp(50 uA)
                            .vMeas().measwait(100 us).execute();
  ...
RDI_END();

Runtime vector editing
ARRAY_I trimData = ... // based on previous measurement.
rdi.runTimeVal("trimValue", trimData);

RDI_BEGIN();
  ...
  rdi.smartVec().pin(pinA).writeData("trimValue",8).execute();
  ...
RDI_END();
