DRLShmooCellResult

A variable of this type holds the position information and result data for one cell of a shmoo plot.

Such variables are used in DRLShmooTestAttr. It contains the following members.

  • xCoordinate: The X coordinate of the cell. It is relative to the start point of X axis.
  • yCoordinate: The Y coordinate of the cell. It is relative to the start point of Y axis.
  • passFailResult: The pass/fail result of the cell. It can be DRLFailureCode_NA, DRLFailureCode_Pass or DRLFailureCode_Fail.
  • result: The test result value of the cell.
