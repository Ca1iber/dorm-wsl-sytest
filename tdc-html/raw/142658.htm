GDDR Memory Device Testing

The V93000 HSM Series offers a complete solution package for GDDR memory device testing including:

  • Source synchronous for characterization and production.
  • Analyzing memory test results.
  • Memory device maintenance operation.

Benefit

The high-speed memory device's architecture introduces a fundamental break with the I/O technologies used so far in the computation arena for the sake of future scalability headroom and application coverage poses quite some test challenges on V93000 HSM Series. Besides all of these challenges, it has been shown using real world examples that today's V93000 HSM Series is capable to cover the test needs of high-speed memory devices in all steps of a memory device's life cycle.

The availability of the V93000 HSM Series based test solutions is key to allow the volume ramp of high-speed memory devices based products.

More Info
