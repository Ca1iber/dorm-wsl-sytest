Topic 111063

GetUtilityLines

This test method reads the states of up to 512 utility lines and displays the state in report window.

Note It is only available for universal test method.

You can view the status of the utility lines in the Utility Line view of 93000 Hardware perspective.

Note When using this test method, the primary sets specified in this test suite are not used. The primary sets of the previously executed test suite are used.

Parameters

Parameter

Type

Description
blockId INT

The utility pogo block to query.

The valid value is from 0 to 8.

If the three‑digit format for pogo blocks is used, the valid range is 165 ... 172.

For the second optional Utility Card of EXA Scale systems, the utility pogo blocks can be defined using only the three‑digit format. The valid range for the second card is 265 ... 272.

See also Utility pogo block mapping in Utility pogo block - Utility Card (V93000 EXA Scale systems).

0 means all utility line blocks and other valid number means the specified utility block.
