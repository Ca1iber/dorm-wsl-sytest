Topic 134891

Setting the data log general information in the Datalog Control tool

About this task

The general information includes the data log profile and the lot information to be logged. This is done in the Setup tab of the Datalog Control tool.

Before you begin

Make sure the Datalog Control tool is started.

Procedure

  1. Open the Setup tab.
  2. Choose whether to use the data log profile.
    • If you choose Not Used, the data log settings in the testflow flags will be used.
    • If you choose to use the data log profile, click Active and select the data log profile from the list. (Refer to Data Logging Profiles for the details about the data log profile.)
  3. Enter the lot information like lot ID, operator name, part ID. The information will be logged in the data log files.

    The part IDs will be automatically increased after a testflow execution. You can also manually change them. The displayed part IDs are for the devices to be tested next.

    You can also enter more lot information by clicking More Setting. Select the variable name from the provided list or define your own variable. The entered information will also be logged.

  4. Click Apply button to make the settings effective in the next execution.

Results

The data log general settings are changed.

Functional changes

  1. Introduced in SmarTest 7.2.0
