How to set the termination for DUT outputs

Subtopics

  1. Using the clamp for termination
  2. Using the active load for termination
  3. Using the cross termination
  4. Using the bidir_receiver termination for full swing in fast mode

Transmission line conducts the output signals of a device's o (output) or io (bidirectional) pins to the comparator in the test system. Reflections on the transmission line can distort the signal at the receiver side of the test system. To avoid reflections, the transmission line must be terminated.

In the level setup, you can apply several termination types: driver, clamp, active load, and differential termination. The specific applicable termination type and termination mode depend on the channel card.

This section introduces how to use the Level Setup window to set the termination. Termination mode explains all the items in the termination mode column.

You can also use the TERM, TERM? - (TERMination mode) firmware command.

Note Take the following into account: after having set a termination for o or io pins, the compare thresholds set for the unterminated transmission line may not longer work in the terminated environment. SmarTest cannot adjust the compare thresholds automatically.
