READ_WAVEFORM_DATA ()

The purpose of the READ_WAVEFORM_DATA function is to read a waveform file from the workstation and load it into the testmethod. Depending on the file type you will either have to select one single file or two files for I and Q waveforms.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/WaveformFile.h.

Syntax

READ_WAVEFORM_DATA(const STRING& fileName, ARRAY_COMPLEX& iqData, DOUBLE & sampleRate, const TM::WAVEFORM_FILE_TYPE fileType = TM::AGILENT_VSA_89600);
READ_WAVEFORM_DATA(const STRING& fileName, ARRAY_D& iData, ARRAY_D& qData, DOUBLE& sampleRate, const TM::WAVEFORM_FILE_TYPE fileType = TM::AGILENT_VSA_89600);
READ_WAVEFORM_DATA(const STRING& iFileName, const STRING& qFileName, ARRAY_COMPLEX& iqData, DOUBLE & sampleRate, const TM::WAVEFORM_FILE_TYPE fileType = TM::CUSTOM_WAVEFORM_FORMAT);
READ_WAVEFORM_DATA(const STRING& iFileName, const STRING& qFileName, ARRAY_D& iData, ARRAY_D& qData, DOUBLE & sampleRate, const TM::WAVEFORM_FILE_TYPE fileType = TM::CUSTOM_WAVEFORM_FORMAT);
READ_WAVEFORM_DATA(const STRING& fileName, ARRAY_D& data);
READ_WAVEFORM_DATA(const STRING& fileName, ARRAY_D& data, DOUBLE& sampleRate, const TM::WAVEFORM_FILE_TYPE fileType = TM::ASCII_TEXT);
Parameters

Parameter

Description

fileName

The name of the file in which the data is to be read, it may be an absolute path or a path relative to the device directory.

iFileName

The name of the file in which the I data is to be read, it may be an absolute path or a path relative to the device directory.

qFileName

The name of the file in which the Q data is to be read, it may be an absolute path or a path relative to the device directory.

fileType

The type of the waveform file. Optional. This can be one of the following:

TM::AGILENT_VSA_89600

TM::CUSTOM_WAVEFORM_FORMAT

TM::ASCII_TEXT

iqData

The array into which the I waveform data will be saved.

iData

The array into which the waveform data will be saved.

qData

The array into which the Q waveform data will be saved.

sampleRate

The sample rate of the waveform data.

You can also use READ_WAVEFORM_DATA () to transfer analog waveform data along digital interfaces such as DigRF. Basically the analog waveform data read out from given waveform file(s) is quantized and saved to two integer arrays, for I and Q respectively. The integer arrays can be applied to digital interfaces. If you use READ_WAVEFORM_DATA () to transfer analog waveform data along digital interfaces, the Syntax will be:

READ_WAVEFORM_DATA(const STRING& fileName, INT bitResolution, ARRAY_I& iData, ARRAY_I& qData, DOUBLE& sampleRate, DOUBLE& quantizationStepSize, const TM::WAVEFORM_FILE_TYPE fileType = TM::AGILENT_VSA_89600, DOUBLE attenuation = 1.0, DOUBLE offset = 0.0);
READ_WAVEFORM_DATA(const STRING& iFileName, const STRING& qFileName, INT bitResolution, ARRAY_I& iData, ARRAY_I& qData, DOUBLE& sampleRate, DOUBLE& quantizationStepSize, const TM::WAVEFORM_FILE_TYPE fileType = TM::CUSTOM_WAVEFORM_FORMAT, DOUBLE attenuation = 1.0, DOUBLE offset = 0.0);
Parameters

Parameter

Description

fileName

The name of the file from which the complex waveform data is read out. It may be an absolute path or a path relative to the device directory.

iFileName

The name of the file from which the I waveform data is read out. It may be an absolute path or a path relative to the device directory.

qFileName

The name of the file from which the Q waveform data is read out. It may be an absolute path or a path relative to the device directory.

fileType

The type of the waveform file. Optional. This can be one of the following:

TM::AGILENT_VSA_89600

TM::CUSTOM_WAVEFORM_FORMAT

TM::ASCII_TEXT

bitResolution

Bit resolution of the quantization.

attenuation

Attenuation factor (<=1.0) of the input waveform data comparing to the full scale. Optional. Using this option, will further reduce the waveform resolution.

An example where this option is useful, is you want to have a vector waveform smaller than the DUT's DAC full scale.

offset

DC offset of the input waveform. Optional.

iqData

The array into which the I waveform data will be saved.

iData

The array into which the waveform data will be saved.

qData

The array into which the Q waveform data will be saved.

sampleRate

The sample rate of the waveform data.

quantizationStepSize

Step size used in quantization, which is calculated based on the range of the waveform, bit resolution and attenuation factor.

Return value

no returned value.

Example

Example 1: Read out ASCII data

ARRAY_COMPLEX iqData;
DOUBLE sampleRate;
READ_WAVEFORM_DATA("waveform/myWave.txt", iqData, sampleRate);
