SmartRDI 2.4.2

This section summarizes the changes and new features in SmartRDI 2.4.2.

Changes and new features

Category

Description

General
  • Full support to AVI64.
  • Result retrieval enhancements:
    • Non-hidden upload result retrieval commands can be put in an SMC_BackgroundProcessing() block.
    • No unique result ID is required for a hidden upload process.
    • No location limitation for a result retrieval command in RDI_UNIT_INIT.
  • Error map hidden upload. See rdi.hiddenUpload().
  • Support to Fast Sync. See Fast Sync setup with SmartRDI.
    • fastSyncOn()
    • fastSyncOff()
    • fastSyncPortNum()
