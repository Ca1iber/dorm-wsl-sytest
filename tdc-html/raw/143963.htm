SOURCESYNC_TEST.rapidSourceSync()

Specifies whether to execute a rapid source-sync test or not. If not specifying with this function, the rapid source-sync test will not be executed by default.

Syntax

SOURCESYNC_TEST &  rapidSourceSync (SOURCE_SYNC::JUDGE_TYPE option);
Parameter

Parameter

Description

option

You can select SOURCE_SYNC::YES or SOURCE_SYNC::NO.
Available options of parameter: <option>

Option

Description

SOURCE_SYNC::NO

(Default) does not execute a rapid source-sync test.

SOURCE_SYNC::YES

Executes a rapid source-sync test.

Functional changes

  1. Introduced in MTP 3.2.2
