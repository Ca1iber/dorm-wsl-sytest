DSP_AND_VEC

This API performs a bit-wise logical AND operation between the corresponding elements of two arrays.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_AND_VEC(ARRAY_I& src1, ARRAY_I& src2, 
            ARRAY_I& result);
DSP_AND_VEC(INT *src1, INT *src2, INT *result, 
            INT size);
Parameters

I/O

Parameter

Description / Range

I

src1

Source array

I

src2

Source array

O

result

ANDed results

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src1)

size ≤ (size of src2)

size ≤ (size of result)

Example

int array1[3], array2[3], array3[3];
  .
  .
DSP_AND_VEC(array1, array2, array3, 3);

If array1 and array2 have the following elements:

array1[0] = 7 = 0...0111
array1[1] = 5 = 0...0101
array1[2] = 3 = 0...0011

and so on

array2[0] = 2 = 0...0010
array2[1] = 4 = 0...0100
array2[2] = 6 = 0...0110

and so on

then, the ANDed results returned to array3 are as follows:

array3[0] = 2 = 0...0010 
array3[1] = 4 = 0...0100 
array3[2] = 2 = 0...0010

Only the first three elements of each array are processed and returned to array3. The remaining elements in array3 are not changed.
