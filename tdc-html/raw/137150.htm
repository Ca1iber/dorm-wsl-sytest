Device summary tab

Each row contains the information for one device.

The details for each row can be displayed in a raw data view by selecting it or by choosing Show In > Raw Data from the shortcut menu.

The rows can be sorted by clicking the column titles and filtered by entering match conditions in the table filter (top row with blue background).
