Topic 89949

Mapping HXA Pins To Pin Scale Pins

Subtopics

  1. Creating a Timing Setup for HXA

The pin multiplexing file can also be used to map HXA pins to Pin Scale pins. In this case the statements must have the following form:

MUX HX <pos> <neg> -> <phase> <data_1> <data_2> [<data_3> <data_4>]

The individual components of this statements have the following function:

  • MUX (mandatory): This keyword introduces a mapping from a pair of HXA pins to two or 4 Pin Scale pins.
  • HX (mandatory): This keyword indicates that a HXA mapping follows.
  • <pos> (mandatory): Specifies the positive pin for a differential pair of HXA pins.
  • <neg> (mandatory): Specifies the negative pin for a differential pair of HXA pins.
  • <phase> (mandatory): Specifies the phase reference pin.

    The timing for this pin is created automatically from the virtual data records 0 0:0 and 1 1:0. It does not need to be defined in the ASCII timing file.

  • <data_1><data_2> (mandatory): Specifies the Pin Scale pins to which the HXA pins are to be mapped. For a 2-multiplexing, only these two pins must be specified. The timing for these pins will be created from the entries for <pos> in the ASCII timing file.
  • <data_3><data_4> (optional): Specifies the Pin Scale pins to which the HXA pins are to be mapped. These additional pins must be specified for a 4-multiplexing. The timing for these pins will also be created from the entries for <pos> in the ASCII timing file.
