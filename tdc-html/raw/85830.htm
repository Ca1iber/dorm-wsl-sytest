Per-pin pass/fail details

Clicking Detail in the Testsuite/Site tab opens the Detail window (see following figure). It displays the current execution, test suite, site triplet (as displayed in the windows title bar) information on a per-pin basis. The Result column contains the accumulated (logical AND) results for the patterns executed and listed in the columns further to the right.

Click Close to close this window.
