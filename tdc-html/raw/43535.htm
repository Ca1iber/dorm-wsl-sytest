Printing Workorders

The Print button within the Workorder Manager menu allows you to print workorders:

  1. If necessary, set up the software for your printer (see "Setting Up a Printer" below).
  2. Open the Workorder Manager.
  3. Click Print.

    The Tester/Operator/Workorder screen appears.

  4. Select the appropriate tester, operator and workorder, and click Print.

    The contents of the particular workorder will be printed.

Setting Up a Printer

To set up a printer for SmarTest, change the referring line of /etc/opt/hp93000/soc/lbin/hp83000_lp

so that line_lp=<the name of your printer>.
