Topic 354621

Authorizing another user for a virtual machine

Generate the key pair, add it to the key configuration file of the virtual machine, and verify the connection.

About this task

By default, only you as the creator of a virtual machine can access it. If you authorize additional users, they can also access it. You can revoke their access when they should no longer be able to work with that virtual machine.

VNC Viewer is used as the VNC client in this procedure. You can use other VNC clients as you prefer. For details on using other VNC clients, see their documentation.

Before you begin

Ensure you have created a TE-Cloud virtual machine and configured the connection to it successfully.

Procedure

  1. Generate a public and private key pair in PuTTYGen and save the key files.

    See Generating and saving key files for details.

  2. Open VNC Viewer.
  3. Connect to the virtual machine.

    See Connecting to a virtual machine via VNC for details.

  4. Right-click the desktop of the virtual machine and click Konsole in the menu.

    The Konsole window opens.

  5. Enable the copy and paste function cross systems.
    1. In the Konsole window, enter vncconfig and press Enter.

      The VNC config window opens.



    2. Select all the four options.
    3. Close the window.
  6. Open the key configuration file authorized_keys.
    1. In the Konsole window, enter cd ~/.ssh/ to switch to the .sshdirectory of the virtual machine.
    2. Enter gedit authorized_keys to open the key configuration file.
  7. Copy the public key content generated in step 1 and paste it into the key configuration file below the original content of the file.

    Do not edit or delete the existing content of the key configuration file.

  8. Save the key configuration file.

    This new public key is available on the virtual machine.

  9. To verify the authorization, follow these steps from the computer of the authorized user:

    The verification procedure might be performed by the authorized user. You should provide the authorized user with the private key file (.ppk) you saved in step 1, the user name and public IP address of the virtual machine.

    1. Open PuTTY.
    2. In the Host Name field, enter the public IP address of the virtual machine to be connected.
    3. In the Category field, choose SSH > Auth, and choose the private key file (.ppk) you saved in step 1.
    4. In the Category field, select Session, enter a name in the Saved Sessions field, and click Save.

      This step defines a new session name in PuTTY for the new user.

    5. Connect to the virtual machine via SSH using the user name.

Results

If logging in successfully, you have authorized the user to access the virtual machine.
