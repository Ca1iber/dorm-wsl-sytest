Datalog Text Record (DTR)

The Datalog Text Record contains the ASCII text string logged by the PUT_DATALOG(const STRING& comment) API in your test method program. This record occurs only when this API is executed. The information is included in the data log printout. DTRs may be written under the control of a test plan: for example, to highlight unexpected test results. They may also be generated by the tester executive software: for example, to indicate that the data log sampling rate has changed.

The Data Log Text Record can appear anywhere in the data stream after the initial sequence.

DTR field name

Field description

Value

93000 data source

TEXT_DAT
  • ASCII text string
  • Variable length character string
  • First byte = unsigned count of bytes to follow
  • Maximum 255 bytes
  • Length byte = 0 if missing or invalid data
  • EDL Event:

    PrintToDatalogEventType

     

    Note If the TEXT_DAT field contains more than 255 bytes, additional DTRs are written to contain the characters beyond the maximum 255 bytes.
