Topic 150697

STRIP_COMPLETED

This asynchronous event indicates that the execution of a strip level is completed in the test program execution.

Dependency and constraints

  • The test program is in execution.
  • If the Application Model does not contain a custom strip level or does not use the standard prober/handler driver function call (ph_strip_done) or the equivalent, this event may not be generated. To get the value of a strip ID, the variable for the strip ID should be ph_STRIP_ID or STRIP_ID.
Parameters

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session that this event belongs to.

O

TIME_STAMP

The time point when this event occurs. It contains two long-type parts: SECONDS and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always EXECUTION.

O

EVENT_BODY

The event parameters. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always STRIP_COMPLETED.

DEVICE_PATH

The current device path.

DEVICE_NAME

The device in use.

TESTPROGRAM_NAME

The test program name in execution.

OPERATOR_NAME

The operator name who starts this event.

STRIP_ID

The current strip ID in the test.

This parameter is represented by ParamList whose key and value are both string types.
