FOR_EACH_TEST_END

FOR_EACH_TEST_END() works together with FOR_EACH_TEST_BEGIN() or FOR_EACH_TEST_BEGIN_WITH_RESET() as a pair to declare a block to test the shared sites.

For details, see FOR_EACH_TEST_BEGIN() and FOR_EACH_TEST_BEGIN_WITH_RESET().

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/SHARED_UTIL.h.

Syntax

FOR_EACH_TEST_END()
