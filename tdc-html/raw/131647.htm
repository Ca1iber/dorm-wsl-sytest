SHARING_CONFIGURATION.utilitySearchNext

The utilitySearchNext() and utilitySearchFirst() member functions of SHARING_CONFIGURATION find the locations of the specified utility control line within the utility_control block in the Sharing configuration file. If it is the first line, 0 will be returned.

utilitySearchFirst() returns the first matched location; utilitySearchNext() returns the next matched location.

Syntax

int utilitySearchNext(const string & name) const

Parameter

Description

name

The name of a utility control line which you want to search in the utility control block.
