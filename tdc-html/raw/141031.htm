DIGITAL_OFFSET_SEARCH_RESULT_PINS

Subtopics

  1. DIGITAL_OFFSET_SEARCH_RESULT_PINS.setResultPin()
  2. DIGITAL_OFFSET_SEARCH_RESULT_PINS.getResultPin()

Defines the result pins for the setup pins specified in resultPin().

The result pins will return pass/fail test results.

Syntax

This class has no constructor. You cannot directly create an object with this class. It is a sub-class of DIGITAL_OFFSET_SEARCH_TASK.

An instance of this class is created with DIGITAL_OFFSET_SEARCH_TASK.resultPin().

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/DigitalOffsetSearchResultPins.h.

List of parameters

There are no parameters.

Return value

There is no return value.
