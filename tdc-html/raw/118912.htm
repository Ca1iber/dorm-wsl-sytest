Parallel site calculation

Parallel site calculation uses the advantages of the multicore and multiprocessor architecture of the CPU. Individual test can be put into a separate SMC_backgroundProcessing() method that is specific to SmartCalc. That method causes SmartCalc to perform anything in it in the background in a different thread.

Your SMC_backgroundProcessing() method needs to be defined as a public method. The number of parameters passed to this method are limited to eight parameters. Since each test method is a separate class, parameter handling can be avoided by defining variables as private member variables of the class. This way they are valid in all class methods. This is a fast and therefore the recommended way for large arrays.

The coding follows the UTM programming scheme.SMC_ARM() needs to be executed for each site (see example below) to start the SMC_backgroundProcessing() thread. Each test class typically contains one method with the predefined name SMC_backgroundProcessing().

In case different SMC_backgroundProcessing() methods become necessary in your test method class, they need a different number of parameters to be distinguishable (different types is insufficient).

SMC_SYNCHRONIZE() checks and - if necessary - waits until all threads of the active site are finished. The time out in seconds can be specified by a double variable. The time out setting is disabled by default.

Example

class runSNRtestMethod: public testmethod::TestMethod
{
     private:

    //
    // Definition of member variables,
    // can be accessed from all methods
    // inside the class
    //
    DOUBLE snr[MAX_SITES], sPow[MAX_SITES], nPow[MAX_SITES];
    ARRAY_D I_Capt[MAX_SITES];

    protected:

    virtual void run()
    {
        ON_FIRST_INVOCATION_BEGIN()

            //
            // Setup and execute your test as usual
            //
            DGT("pinDGT").enable();

            SMC_EXECUTE_TEST( 1.0 );

            //
            // Upload data per site and start calculation
            //
            FOR_EACH_SITE_BEGIN()

                //
                // Upload waveform
                //
                INT site = CURRENT_SITE_NUMBER();
                I_Capt[site] = DGT("pinDGT").getWaveform();

                //
               // Kick off calculation thread
               SMC_ARM();

            FOR_EACH_SITE_END()

        ON_FIRST_INVOCATION_END()

        //
        // Wait until all calculations are done
        //
        SMC_SYNCHRONIZE();

        INT site = CURRENT_SITE_NUMBER();

        //
        // Log all results
        //
        TEST("pinDGT","SNR", snr[site]);
        TEST("pinDGT","signalPow", sPow[site]);
        TEST("pinDGT","noisePow", nPow[site]);

    } // virtual void run()

    public:

    void SMC_backgroundProcessing(void)
    {
        //
        // Retrieve the thread specific site number from SmartCalc
        //
        INT site = SMC_SITE_NUMBER();

        //
        // Do your calculation
        //
        DSP_SNR(I_Capt[site],&snr[site],&sPow[site],&nPow[site], 1024, 1, 3, 0.0, 0);

    } // void SMC_backgroundProcessing(void)

} // class runSNRtestMethod: public testmethod::TestMethod
