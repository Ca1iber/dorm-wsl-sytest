EVENT_FILTER.getFilterType()

Queries the type of the filter that has been defined by EVENT_FILTER.setFilterType().

Syntax

void getFilterType(TM::FILTER_TYPE &filterType) const;
Parameter
Parameter Description
filterType

The filter type that has been programmed by EVENT_FILTER.setFilterType().
Return value
There is no return value.

Example

For an example see EVENT_FILTER.

Related information

EVENT_FILTER.setFilterType()

Functional changes

  1. Introduced in SmarTest 7.4.2
