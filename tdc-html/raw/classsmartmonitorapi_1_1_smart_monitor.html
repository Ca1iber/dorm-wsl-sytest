virtual SmartMonitor& smartmonitorapi::SmartMonitor::start ( )
virtual

Starts to monitor test cell events.

When an event is received, the function SmartMonitor::consume() will be called back. This function will be blocked until SmartMonitor::stop is called.

Returns
The reference to the invoked SmartMonitor instance.

Example

In this example, monitor is an invoked SmartMonitor instance.

MyMonitor monitor;
monitor.start();
