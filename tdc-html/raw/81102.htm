Topic 81102

Configuring a test suite

To select a source synchronous test method for a test suite follow the procedure below.

Procedure

  1. Insert a run or run and branch test suite into the testflow.

    The Test Suite Dialog window opens.

  2. Click the Test Method button at the top of the window.
  3. To define the test suite's name, type the name for your test suite into the Test suite name entry field, for example Multistrobe_GDDR3.
  4. Select the basic timing and level equations and the vector label, for example march6n.
  5. Edit the timing file and the wavetables as described in topic Setting up the timing file.
  6. Click the Test method entry field at the bottom of the test suite window.
  7. Click Select in the right pane.

    The Select Class/Method window opens.

  8. In the Class list box, select DEV ss_lib.
  9. Choose a method from the Method list, for example FastMode.
  10. To close the window, click Select at the bottom of the Select Class/Method window.

What to do next

Configure the parameters for the test method.
