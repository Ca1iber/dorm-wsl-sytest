rdi.enableOre()

Enables or disables Offline Result Emulation (ORE) for a selected test suite or code block.

It overrides the ORE setting with ENABLE_ORE in the RDI_Configure file in the related test suite.

Syntax

rdi.enableOre(bool oreOn);
Parameters

Parameter

Description

oreOn

Specifies whether to enable ORE for the selected test suite or code block.
List of available options of parameter: oreOn

Option

Description

true:

Enables ORE for the selected test suite or code block.

false (Default):

Disables ORE for the selected test suite or code block.

Example

rdi.enableOre(true);
rdi.oreFile("./myORE.xml");

RDI_BEGIN();
  ...
RDI_END();

rdi.id().getXXX();
