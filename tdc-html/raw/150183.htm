EVENT_WAVEFORM_CF.getRepeatCount()

Reads the number of repeats of the waveform that has been defined by EVENT_WAVEFORM_CF.cForce().

The number of repeats is read from the corresponding EVENT_WAVEFORM_CF object and returned as an integer value.

Syntax

void getRepeatCount(INT & repeats) const;
Parameter
Parameter Description
repeats

The read repeat count.

Note: The getRepeatCount() member function of DC events returns always 1 as repeat count.
Return value
There is no return value.

Example

For an example see EVENT_WAVEFORM_CF.

Related information

EVENT_WAVEFORM_CF.cForce()

Functional changes

  1. Introduced in SmarTest 7.4.0
