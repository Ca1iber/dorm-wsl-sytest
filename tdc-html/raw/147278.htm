DVM_TASK.pin()

The pin() member function creates a DVM_PIN_TASK object to hold the measurement specifications for the specified pins.

Syntax

DVM_PIN_TASK & DVM_TASK::pin (const STRING & pinlist);
Parameter

Parameter

Description

pinlist

Utility pins for which to define the voltage measurement.

To specify multiple pins, separate them with a comma.

The pins must be specified as Utility DC pins.

Return value

Returns a reference to the DVM_PIN_TASK object.

Example

See the example in DVM_TASK.
