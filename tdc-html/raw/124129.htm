Scan Structure Record (SSR)

A Scan Structure Record contains the scan structure record normally found in STIL files. It contains an array of indexes to Chain Description Records (CDRs).

A Scan Structure Record can appear after the Scan Cell Name Record (CNR).

SSR field name

Field description

Value

93000 data source

SSR_NUM

The name of the STIL scan structure.

Variable length character string

 

CHN_CNT

The number of chains listed in CHN_LST

Two-byte unsigned integer

0: CHN_LST is not present

 

CHN_LST

An array of indexes of CDR records

Array with the dimension LIM_CNT

Each value is a two-byte unsigned integer
