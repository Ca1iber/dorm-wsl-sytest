TESTSET().judgeAndLog_Spmu()

This member function of TESTSET performs a pass/fail judgment of an SPMU test specified by an SPMU_TASK object and logs the results.

Optional values for this function can be set by prior methods, for example, port(), cont(), reliability(), or testname().

Syntax

bool judgeAndLog_Spmu(const SPMU_TASK &spmuTask, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE);

Parameter

Description

spmuTask

Specifies an SPMU_TASK object to be judged.

logTestNumber

An optional test number.

If this test number is provided, it overrides the actual test number. If it is not provided, the actual test number is logged.
Note Only the first six digits of values are ensured to be correctly logged into the STDF file.

Return Value

The pass/fail result of the judgment is returned. It can be true for pass or false for fail.

Example

SPMU_TASK spmuTask;
ON_FIRST_INVOCATION_BEGIN();
  CONNECT();
  spmuTask.pin("I/O0").iForce(10 uA).clamp(3.5 V).min(1.5 V).max(3 V).relay("NTMBB");
  spmuTask.pin("I/O1").vForce(3 V).clamp(1.5 mA).min(0.5 mA).max(1 mA).relay("NTMBB");   
  spmuTask.execMode(TM::PPF).execute();
ON_FIRST_INVOCATION_END();
TESTSET().judgeAndLog_Spmu(spmuTask);

This example performs voltage measurement on pin "I/O0" and "I/O1". The test result is judged and logged with the TESTSET API.

Related information

TESTSET

  2. SmarTest 7.5.3: Optional logTestNumber parameter added.
