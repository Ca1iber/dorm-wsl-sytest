Topic 126315

Editing transaction details

About this task

This task describes how to create or edit protocol transaction details, like parameters and encoding/decoding functions.

Procedure

  1. Select a transaction within the structure of the protocol.
  2. Enter the overall length of the transaction in state characters into the Length field.
    Note If you rename the transaction here, the transaction's name in the protocol structure will be updated accordingly. You may disable this propagation feature in the preference settings of the protocol editor.
  3. In the Parameters section click New to enter parameters for the transaction that can be used in your test method.
  4. Define the Direction, Length and Decode function of each parameter by clicking into the corresponding field behind the parameter name.
  5. If necessary you can change the order of parameters by selecting the parameter and than clicking on Move Up or Move Down.
    Note The order and the direction of parameters is important for using parameters within your test method.
  6. If required, select a parameter and click New in the symbol section to add a new symbol.
  7. Double-click into the Value field behind the symbol's name to enter the corresponding value.
  8. If required at this level, enter any encode / decode function in the Function section.
  9. Save your modifications by pressing the CTRL + S key combination simultaneously.

Results

You have defined the selected transaction along with the corresponding parameters.

What to do next

If required, enter the pin role specific encode / decode functions by Editing pin role details.

If your protocol does not need pin role specific encoding/decoding you may enter the required protocol field details by Editing field details.
