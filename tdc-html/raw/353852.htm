Topic 353852

Finding non-matching settings across sites

You can make changes to settings for a selected signal and compare and display the differences in the Measurement window.

Before you begin

You have opened a signal in the Hardware view

Procedure

  1. In the Hardware view, select Focus Site Only and make the required setting changes for the selected site.
  2. Select All Active Sites.

    Any values that are not consistent across sites are displayed with a yellow background.

Results

You have made changes to settings for a selected signal and compared and highlighted the settings that are not consistent across sites in the Measurement window.

Functional changes

  1. Introduced in SmarTest 7.6.1
