Topic 150590

get_ra_layout()

This function is used to get the RA layout information that is data bit group, segment, row and column for the map converter.

Make sure that you have implemented the function in the map converter shared library before you specify the map converter type to RA_LAYOUT_BASED in the Redundancy analysis configuration file. This function works together with phys_to_layout for the map converter in an RA execution.

Syntax

void get_ra_layout (long *dbitg_num, long *segm_num, long *row_num, long *col_num);
List of parameters

Parameter

Description

dbitg_num

The number of total data bit groups. It must be 1.

segm_num

The number of total segments on the device.

row_num

The number of total rows on the device.

col_num

The number of total columns on the device.

Example

#define pROW  16
#define pCOL  8
#define pBANK 4
#define pDATA 4

// RA functions

void get_ra_layout(long *dbitg_num, long *segm_num, long *row_num, long *col_num)
{
    // This parameter must be 1 for all the time. 
    *dbitg_num = 1;

    // The number of all segments.
    *segm_num = pBANK * pDATA;

    // The size of one segment.
    *row_num = pROW;
    *col_num = pCOL;
}

For more information about the DUT representation, see DUT representation file.
