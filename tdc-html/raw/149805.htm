SPMU_PIN_TASK.vSlewRate()

Sets the force voltage slew rate.

This member function is supported only for the DC Scale XPS256 card.

The force voltage slew rate is used to modify the rise time and the fall time when the force voltage is changed. The slew rate has no effect if the clamp voltage is changed.

Note XPS256 pins, the slew rate settings are applied only in connected mode. The maximum slew rate, limited by the programmed bandwidth, is applied when a disconnected channel is connected. We recommend therefore connecting an AVI64 or FVI16 channel with the forced value set to 0 V or 0 A respectively and changing the forced value to the target value after the channel has been connected. The bandwidth can be set by test method APIs SPMU_PIN_TASK.vFilter() and SPMU_PIN_TASK.iFilter() or by SmartRDI functions rdi.dc().vFilter() or rdi.dc().iFilter.

Syntax

SPMU_PIN_TASK& vSlewRate (const DOUBLE vSlewRate);
Parameter
Parameter Description
vSlewRate Defines the voltage slew rate in Volts per microsecond (V / µsec).

Programmable double values are

  • Value between the card-specific minimum and maximum value: The slew rate is set to the defined value.
  • 0.0: The slew rate is set to the card-specific default value.
Card-specific range and default value:
  • XPS256: Refer to section Dynamic behavior in XPS256 programming - Force and clamp voltages.

Return value

A reference to the SPMU_PIN_TASK object.

Example

The following example shows how to set the force voltage slew rate.

SPMU_TASK spmuTask_1;

spmuTask_1.pin("...")
    .mode("VFIM")
    ...
    ...
    .vSlewRate(20 mV) // [V/us]
    ;

Note: The example concentrates on the function described in this topic. More settings are required for an executable SPMU_TASK object.
