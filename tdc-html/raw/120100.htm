SMC_GET_VECTORS()

Retrieves the captured data of the vector memory identified by the vector name and a result area id.

This API can be used only inside your SMC_backgroundProcessing() method to make use of hidden upload.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Syntax

const ARRAY_I& SMC_GET_VECTORS(const STRING& name,
                               const STRING& area,
                               INT samples = -1,
                               INT bits = -1,
                               INT offset = 0,
                               const STRING& format = "BIN",
                               VECTOR::INPUT_MODE mode = VECTOR::NORM,
                               VECTOR::SOC_VECTOR_BYTE_ORDER order = VECTOR::SOC_VECTOR_BIG_ENDIAN);

const ARRAY_I& SMC_GET_VECTORS(const INT site,
                               const STRING& name,
                               const STRING& area,
                               INT samples = -1,
                               INT bits = -1,
                               INT offset = 0,
                               const STRING& format = "BIN",
                               VECTOR::INPUT_MODE mode = VECTOR::NORM,
                               VECTOR::SOC_VECTOR_BYTE_ORDER order = VECTOR::SOC_VECTOR_BIG_ENDIAN);

const ARRAY_I& SMC_GET_VECTORS(const STRING& name,
                               const INT instanceIndex,
                               const STRING& area,
                               INT samples = -1,

                               INT offset = 0,

                               VECTOR::SOC_VECTOR_BYTE_ORDER order = VECTOR::SOC_VECTOR_BIG_ENDIAN);
Parameters

Parameter

Description

site

Site to retrieve data from.

name

Label of the vector variable to upload.

instanceIndex

Instance index of a (burst) vector variable.

Specifies the instance of the vector variable to upload in case of a (burst) capture where the same capture pattern may be called more than once.

area

Result area which was used to capture the data. For details see RESULT_AREA_CONFIG API.

samples

Number of data items to retrieve and upload.

The default value "-1" retrieves all samples.

bits

Bit width of the code to retrieve. The default value is "1".

offset

Sets the start location offset for retrieving data. The default value is "0".

format

Sets the format of the DUT output codes. Default is BIN.

Code formats determine how this function manipulates vector data when converting them from vector data to integer data.

mode

Sets the input mode of the DUT code. Code formats specified by mode modify how this method will manipulate vector data when converting vector data to integer data.

Possible modes are
  • NORM (normal) and
  • COMP (complementary).

The default value is NORM.

For details, see Code Format Tables.

order
Sets the order of the bytes of the code to be retrieved. Possible options are
  • SOC_VECTOR_BIG_ENDIAN (high-order byte most significant) and
  • SOC_VECTOR_LITTLE_ENDIAN (low-order byte most significant).

The default value is SOC_VECTOR_BIG_ENDIAN.
List of available options of parameter: format

Option

Description

BIN

Binary

COMP1

One complement

COMP2

Two complement

MOD_COMP1

Modified one complement

SYMM

Symmetry

MOD_SYMM

Modified symmetry

GRAY

Gray code

BCD

More details to the options listed above can be found in the Code Format Tables.

Return value

Returns an array of the captured data of the vector memory identified by the vector name and a result area id.

The returned array is valid till SMC_SYNCHRONIZE() is called.

Example

This example starts a background process and downloads the vector results.

protected:

    virtual void initialize()
    {
    }

    virtual void run()
    {
        STRING testName;

        GET_TESTSUITE_NAME(testName);

        ON_FIRST_INVOCATION_BEGIN();
        {
            RESULT_AREA_CONFIG resultAreaConfig("dig1,dig2,dig3,dig4");

            resultAreaConfig.appendArea("16KBITArea",3072).activate();

            SMC_DIGITAL_CAPTURE_TEST("16KBITArea");

            ARRAY_I activeSites;

            GET_ACTIVE_SITES(activeSites);

            SMC_ARM(activeSites);
        }
        ON_FIRST_INVOCATION_END();

        return;

    } // virtual void run()

public:

    virtual void SMC_backgroundProcessing(ARRAY_I& activeSites)
    {
        for (int siteIndex = 0; siteIndex < activeSites.size(); ++siteIndex)
        {
            INT currentSite = activeSites[siteIndex];

            ARRAY_I vectorArray = SMC_GET_VECTORS(currentSite, "cap1", "16KBITArea");

            cout << "Vector data: " << vectorArray << endl;
        }

    } // virtual void SMC_backgroundProcessing(ARRAY_I& activeSites)
