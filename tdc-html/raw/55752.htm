PPMU_PIN_CLAMP

The PPMU_PIN_CLAMP class is a data container holding the object reflecting the pin PMU's clamp circuit setup data. The target pin PMU must be specified via the PPMU_CLAMP class because the PPMU_PIN_CLAMP class can only be called as a subsidiary data container of the PPMU_CLAMP class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PpmuPinClamp.h.

Member functions

status()

PPMU_PIN_CLAMP & status(const STRING& on_off);

This function enables or disables the clamp function.

Parameters

on_off

Specifies the status of the clamp circuit. Possible values are:.

 

"CLAMP_ON"

The clamp function is enabled.

 

"CLAMP_OFF"

The clamp function is disabled.
Note To avoid the impact on measurement accuracy, disable the clamp before voltage measurement when forcing small currents (<100uA). See the example in PPMU_CLAMP.

The PPMU voltage clamp is disabled when using the PMU in VForce mode.

low()

PPMU_PIN_CLAMP & low(DOUBLE low_v);

This function sets the low voltage of the clamp function.

Parameter

low_v

Sets the low voltage of the clamp in V.

Pin Scale 1600 range:

For the current range 1: -2.0 V to 5.75 V

For the current range 2..5: -2.0 V to 6.50 V

To identify the current range, see PS1600 Current force and measure.

Pin Scale 5000 range:

For the current range I ≤ 25 mA: -1.50 V to 6.45 V

For the current range I > 25 mA: -0.60 V to 5.60 V

The low value must be smaller than the high value.

high()

PPMU_PIN_CLAMP & high(DOUBLE high_v);

This function sets the high voltage of the clamp function.

Parameter

high_v

Sets the high voltage of the clamp in V.

Pin Scale 1600 range:

For the current range 1: -2.0 V to 5.75 V

For the current range 2..5: -2.0 V to 6.50 V

To identify the current range, see PS1600 Current force and measure.

Pin Scale 5000 range:

For the current range I ≤ 25 mA: -1.50 V to 6.45 V

For the current range I > 25 mA: -0.60 V to 5.60 V

The high value must be greater than the low value.

iRange()

PPMU_PIN_CLAMP& iRange(DOUBLE range);
PPMU_PIN_CLAMP& iRange(const STRING& range);

This function sets the measurement range required to program the current clamp values.

Parameter

range

The measurement range.

Example

PPMU_SETTING setting;
PPMU_RELAY relayOn;
PPMU_RELAY relayOff;

PPMU_MEASURE measure; // define measurement
PPMU_CLAMP clampOn;
PPMU_CLAMP clampOff;

PATTERN_CONTROLLER p_c;
setting.pin("pin1").iForce(-50 uA);
setting.pin("pin1").min(-100 mV).max(1000 mV).iRange(100 uA);

relayOn.pin("pin1").status("PPMU_ON");
relayOn.wait(400 us);

relayOff.pin("pin1").status("PPMU_OFF");
relayOff.wait(400 us);

clampOn.pin("pin1").low(-1500 mV).high(1500 mV).status("CLAMP_ON").iRange(100 uA);
clampOn.wait(1000 us);

clampOff.pin("pin1").status("CLAMP_OFF");
clampOff.wait(1000 us);

measure.pin("pin1").measurementType(TM::VMUM);
// measurement, return a value
p_c.label("subPattern_Dc_s","port1")
 .add(setting)
 .add(clampOn)
 .add(relayOn)
 .add(clampOff)
 .add(measure)
 .add(relayOff);
p_c.execute();
p_c.getPassFail(); // get the pass/fail result
