SEMI_PARALLEL_CONFIG.getGroupByIndex()

Accesses the group by the index in the semi-parallel configuration.

Syntax

const SEMI_PARALLEL_GROUP* getGroupByIndex(int index);
Parameter

Parameter

Description

index

The index of the group in the current configuration.

Return value

A pointer to the semi-parallel group is returned.

Functional changes

  1. Introduced in SmarTest 7.2.0
