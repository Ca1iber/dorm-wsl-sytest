TestNameAttrType

Contains the test name. The data type is DRLTestNameAttr.

Data Type

type

Attribute type

name

string

Test name

The displayed test name has the format <testname>@<pinname>[<counter>], where:

  • <testname>: The name of the test
  • <pinname>: The name of the pin on which this test was performed.

    The pin name is included for multiport labels (which generate separate test events per pin).

    It is also included if any of the JudgeAndLog_xxx member functions of the TESTSET class are used (or any of the variants of TEST() that they replace) and a pin name is specified as a parameter of that function.

    In other cases, the pin name is not included in the test name.

  • <counter>: A counter to distinguish multiple executions of the same test (for multiport labels: the same test on the same pin).
