Using STPM MCM

Subtopics

SmarTest Program Manager (STPM) is controlled from the command line interface (for more information, see STPM MCM command line options). The details of its operation are determined by the contents of its control file.

Running STPM MCM

You run STPM MCM from the command line. The details of the operation it is to perform are found in the control file that is specified as a command line argument. The main options include:

  • Generating or updating mapping templates from test programs
  • Generating or updating test programs from mapping templates
  • In addition, you can run custom Python scripts that you have created yourself. This feature lets you perform an almost unlimited variety of actions during STPM MCM conversions. Access to key template parameters is provided to the Python script through dictionaries.

Depending on the commands you have added to the control file, in general either the template files or the test programs created from it are updated.

The exact results depend on the commands in the control file, and a wide range of differing or additional results is possible.
