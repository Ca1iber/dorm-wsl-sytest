TESTSET().llmFmt()

This member function of TESTSET assigns the format for displaying the lower limit in the data formatter output.

Calling this function stores the supplied format string in the C_LLMFMT fields of the parametric test record (PTR) and the multiple-result parametric record (MPR).

This function is not supported within the SMC_backgroundProcessing() test method when flag hidden_datalog_mode is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

Syntax

TESTSET & llmFmt(const STRING &format);

Parameter

Description

format

A string describing the desired format. The string is a standard ANSI C format string, for example, "%7.3f".

To indicate a hex result, use TESTSET().resFmt("%x").

Example

Code example for result in hex format:

LIMIT lim1;
lim1.low(TM::GE, 0x0001);
lim1.high(TM::LE, 0xFFFE);
lim1.unit(" ");
TESTSET hex_test;
hex_test.resFmt("%x").hlmFmt("%x").llmFmt("%x");
hex_test.testtext("TEST TEXT HERE");
hex_test.cont(1).testnumber(1000).judgeAndLog_ParametricTest("tdo", "dummy", lim1, 100);
