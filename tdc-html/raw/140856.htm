The MTP Build configuration pages provided with MTP-EWC

The MTP Build configuration pages in MTP-EWC are used to set up configurations for building MTP .apg files.

With it, you can:

  • Set up different configurations.
  • Set up multiple different compilers within one build configuration. Each compiler will compile a group of .apg files.
