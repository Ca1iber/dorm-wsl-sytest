iForce()

Specifies the current to force.

Syntax

iForce(double dI);
iForce(const string& sData);
List of parameters

Parameter

Description

dI

The current to force

sData

The string containing the value to be used at run-time. (Refer to Changing the parameter value at run-time with SmartRDI)

Example

rdi.dc().pin("pinA",TA::SPMU).iForce(1 mA).execute();
