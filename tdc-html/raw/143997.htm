SOURCESYNC_SUB_TEST.sweepStart()

Specifies the start value for the sweeping spec variable specified with SOURCESYNC_SUB_TEST.sweepSpecVar().

Once you set up this function, the sweeping of every edge will start at the point by assigning the sweeping spec variable to this value. The original value of the sweeping spec variable will be overwritten.

Syntax

SOURCESYNC_SUB_TEST& sweepStart (const string& sweepStart);
Parameter

Parameter

Description

sweepStart

A number to represent the start value of the sweeping spec variable.

  • If you have specified multiple sweeping spec variables with SOURCESYNC_SUB_TEST.sweepSpecVar(), specify multiple start values here accordingly separated with ";". For example, "1; 2; 3".
  • If UsePredefinedTimingFile is NO, the unit in ns.
  • If UsePredefinedTimingFile is YES, the number here is an integer.
