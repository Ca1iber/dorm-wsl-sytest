Overview

This section provides details about the STDF files, fields, and records populated by the SmarTest Data Formatter. The topics include:

  • A description of all STDF record types populated by the tool.
  • The location of each record type in the STDF file.
  • How STDF records and fields are mapped to V93000 event attributes.
  • Information about test methods and user procedures used to log STDF data.

Record types

This is a list of record types, sorted by their abbreviations:

  • ATR: Audit Trail Record
  • CDR: Chain Description Record
  • CNR: Scan Cell Name Record
  • DTR: Datalog Text Record
  • FAR: File Attributes Record
  • FTR: Functional Test Record
  • GDR: Generic Data Record
  • HBR: Hardware Bin Record
  • MIR: Master Information Record
  • MPR: Multiple-Result Parametric Record
  • MRR: Master Result Record
  • NMR: Name Mapping Record
  • PCR: Part Count Record
  • PIR: Part Information Record
  • PMR: Pin Map Record
  • PRR: Part Result Record
  • PSR: Pattern Sequence Record
  • PTR: Parametric Test Record
  • RDR: Retest Data Record
  • SDR: Site Description Record
  • SBR: Software Bin Record
  • SSR: Scan Structure Record
  • STR: Scan Test Record
  • TSR: Test Synopsis Record
  • VUR: Version Update Record
  • WCR: Wafer Configuration Record
  • WIR: Wafer Information Record
  • WRR: Wafer Result Record

Functional changes
