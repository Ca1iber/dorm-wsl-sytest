FFC Pareto chart properties

Specify the labels and axis settings for an FFC pareto chart.

Titles tab

Chart title: The title of the chart, displayed at the top.

Chart subtitle: The subtitle of the chart, displayed below the title.

Cycle: The label for the cycle axis.

Test Count: The label for the test count axis.

Scales tab

Minimum: The lowest value displayed on the y-axis.

Maximum: The highest value displayed on the y-axis.

Bin Count: The number of columns that are displayed in the chart.
