EVENT_WAVEFORM_VC.getSampleVectorDistance()

Reads the distance between sample vectors that has been defined by EVENT_WAVEFORM_VC.sampleVectorDistance().

The sample vector distance is read from the corresponding EVENT_WAVEFORM_VC object and returned as an integer value.

Syntax

void getSampleVectorDistance(INT & vectors) const;
Parameter
Parameter Description
vectors

The sample vector distance.
Return value
There is no return value.

Example

For an example see EVENT_WAVEFORM_VC.

Related information

EVENT_WAVEFORM_VC.sampleVectorDistance()

Functional changes

  1. Introduced in SmarTest 7.4.0
