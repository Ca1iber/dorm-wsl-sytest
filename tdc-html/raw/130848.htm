Using the debugger

Subtopics

  1. Debugging test methods: Finding and moving to information
  2. Debugging patterns efficiently

This topic describes in three step how to use the debugger efficiently.

Procedure

  1. Launch the debugger
    1. Click Window > Open Perspective > Debug.

      The Debug perspective opens.

    2. In the Debug perspective, click the button Start Test Method Debug . The test method debugger will be opened.
  2. Run the testflow:
    • Press Ctrl+F11.

  3. Analyze your results:

    Step through C++ code by standard debugger navigation.
