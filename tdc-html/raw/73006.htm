Topic 73006

Memory core

The MTL language provides you with the APG software for creating customized memory tests to test the memory core.

The Memory Test Language (MTL) is a per-pin APG (Algorithmic Pattern Generator) programming language. Using MTL you can generate memory test patterns which are included as vectors in SmarTest to be used to test memory devices on the V93000. MTL enables at-speed memory testing up to 3.6 Gbps on the V93000.

MTL offers:

  • Flexible language
  • Modular setups
  • Unlimited X-mode support

MTL breaks the description of the pattern into two parts:

  • A description of the device's memory core interfaces
  • A memory pattern program.

The description of the memory core's interface is called "device access definition". This modularized programming structure allows the user to enter the device description once and reuse it in combination with a pool of MTL-based patterns. The pattern can be written for reuse within a device family as well, where more than one pattern program can be used in different combinations of port definitions.
