Site Match Enabled with Shared Resources

If you enable the site match (match flag ON), you can evaluate the result for each site individually, but exact triggering with shared pins is not possible because the match loops are started successively for each site (starting with the site having the highest number) so that the trigger will not be exact depending on the site.
