SlimBusController.loadFromSequence

This function loads the SLIMbus program from a sequence file. This is a prerequisite for calling the translate() function.

Syntax

Boolean loadFromSequenceFile(const STRING & sequenceFile, bool validate = true);
Parameters

Parameter

Description

sequence file

The sequence file that is to be loaded.

validate

This parameter controls whether (TRUE) or not (FALSE) the input file is checked for syntactical correctness. TRUE is the default.

Return value

TRUE if the loading was successful, FALSE if an error occurred.

Functional changes

  1. Introduced in SmarTest 7.2.1
