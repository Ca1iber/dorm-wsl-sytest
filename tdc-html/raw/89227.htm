MBAV8 (MCB) pogo pin assignment

This section gives you an overview of the pin assignments of the MBAV8 - Multi Band Audio/Video 8 analog card (MCB).

Supported V93000 systems : Smart Scale (SmarTest 7), Pin Scale

Notes on GND pins:

  • AGND - Analog ground - The AGND pins in one MBAV8 (MCB) module are connected to each other inside the analog module.
  • FGND - Floating ground - For the MBAV8 (MCB), the FGND is the ground for the common trigger input and is separated from analog ground. On the DUT board, wire the FGND of the MCB to the ground of the digital channel that is used as a trigger source. The wiring is the same as for other analog modules whose trigger input ground is DGND. In the MBAV8 (MCB) module, the FGND pin for CT1 and the FGND pin for CT2 are separate from each other.

The MBAV8 (MCB) module contains eight units. For the E9722A/B MBAV8 (MCB) Source and Measure model, units 1 to 4 are source units and units 5 to 8 are measure units. For the E9723A/B MBAV8 (MCB) Measure model, all units are measure units.

Each source unit contains an LF AWG (1.024 Msps 24-bit), HF AWG (200 Msps 16-bit), and VHF AWG (500 Msps 16-bit). Each measure unit contains one VHF digitizer (110 Msps 16-bit) and two LF digitizers (200 ksps 24-bit). The MBAV8 (MCB) module has the common trigger (CT1/2) pins. The common trigger pins can be shared with any units in an MBAV8 (MCB).

In the pin assignment table, the following names are used.

FGND: floating ground

AGND: analog ground on analog module

CT1, CT2: Common trigger input

A+, A-, to H+, H-: AWG output (A+, A-, to D+, D- of source units), digitizer input (measure units), MCB- PMU pin, or V source output

(A+, A-, to D+, D-: for source units, connection to AGND is also possible)

AA+, AA- to HH+, HH-: Digitizer input (measure units), MCB-PMU pin, or V source output

(AA+, AA-, to DD+, DD-: for source units, connection to AGND is also possible)

The MBAV8 (MCB) uses both the S1 and S2 pogo blocks.
