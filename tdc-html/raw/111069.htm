Topic 111069

TestState

This test method returns the current sequencer state, which may be Off, Break, HALT or Run.

The test method does not change the state of the sequencer. It also returns a single pass/fail result for the last test performed on all O/IO pins.

Note It is only available for universal test method.

This test method is intended for debugging purpose to produce endless vector sequences. Therefore, it will mostly be used interactively, not as part of a test flow.

Functional changes

  1. Introduced in SmarTest 6.5.2
