SOURCESYNC_TEST.repeatSameTiming()

Specifies how many times each single step (shot) in a sweep test will be repeated.

Syntax

SOURCESYNC_TEST& repeatSameTiming (const int repeatSameTiming);
Parameter

Parameter

Description

repeatSameTiming

The repeat times for every step (shot) in a sweep test. The default value is 1.
