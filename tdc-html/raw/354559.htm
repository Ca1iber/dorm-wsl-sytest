Transmitting files between Linux machines with command line

Modify the access permission of the PEM file and transmit files with command line.

Before you begin

Requirements for the computers or virtual machines to transmit files using command line:
  • Linux.
  • Internet connection.
  • The SFTP protocol is supported.
  • Port 22 is open.

Procedure

  1. Open PuTTY.
  2. Connect to the virtual machine via SSH or via VNC.
  3. Modify the access permission of the PEM file: 
    chmod 600 PEM_file_name

    PEM_file_name is the name of the PEM file which is saved in Generating and saving key files for the target virtual machine.

  4. Transfer the file: 
    scp -i PEM_file_name transmit_file_name login_name@public_IP：target_directory
    PEM_file_name
    Name of the PEM file which is saved in Generating and saving key files.
    transmit_file_name
    The file to be transmitted to the target machine.
    login_name
    User name of the target machine.
    public_ip
    The public IP address of the target machine.
    target_directory
    The directory in the target machine to save the transmitted file.

Results

The file is transmitted to the target Linux machine at the designated location.

Example

chmod 600 vicky_VM.pem
scp -i vicky_VM.pem transmission_test.tar.gz vicky_demo@66.79.4.76:~

Functional changes
