Topic 42255

Changing the Driver Configuration at Run-Time

Subtopics

  1. Direct Change of Configuration Parameters
  2. Changing Configuration Parameters with the Editor

You can change the driver configuration at run-time with two special configuration functions which can be called from the application model (see Using driver functions in the application model for information about how to call driver functions from the application model).

The configuration function ph_set_configuration lets you directly change the settings of configuration parameters by providing the parameter names and the new settings as function parameters. See Direct Change of Configuration Parameters for details.

The configuration function ph_interactive_configuration allows you to change parameter settings with the designated editor for driver configurations. See Changing Configuration Parameters with the Editor for details.

Both functions change the internal parameter settings of the driver only. The driver configuration file, which was loaded at driver start-up and defined the initial setting of the driver parameters, will not be changed.

Note Some configuration parameters cannot be changed at run-time per definition. Configuration Parameters states for each parameter whether changes at run-time are possible, or not possible.
