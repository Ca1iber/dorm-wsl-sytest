Starting the formatter

Enabling the data formatter for automatic startup

You must enable the SmarTest Data Formatter for it to start automatically when SmarTest starts. To enable the SmarTest Data Formatter:

  1. Open the file /etc/opt/hp93000/soc_common/datalog/global.conf.

    Editing this file requires root permissions.

  2. Change the STDF generation configuration option to formatter.stdf.generateStdf=true

    STDF is the Standard Test Data Format, an industry-standard data log format. It is not the abbreviation for "SmarTest Data Formatter".

  3. Save and close the file.
  4. Restart SmarTest.

After this configuration change, the SmarTest Data Formatter automatically starts when SmarTest starts. The formatter runs in the background, and attaches to the current data stream. This behavior applies both for on-line and off-line (hardware not connected) testing.

In order for the EDL to generate the necessary events and attributes in the data stream, the correct data log flags need to be set and the formatter needs to be enabled.

After SmarTest has initialized and the data formatter is ready to begin capturing data, the behavior is controlled by configuration files. These format configuration files enable you to create a custom STDF format.

The configuration options also allow you to turn off the STDF formatter if you choose not to output any STDF records.

See STDF Configuration for more information.

Changes to the STDF configuration

If you make changes to the STDF configuration, in most cases these changes will take effect at the next TestProgramStart event. However, any changes that you make to the STDF configuration settings that are in the global.conf file will not take effect until you shut down and restart SmarTest.

Command line formatting of a saved EDL stream

The data formatter can either read a current data log stream generated by the test system during the production test or a saved data log stream. This allows you to generate real-time and post-processed STDF files.

Note The saved EDL stream can be found in the data collection file located at /var/opt/hp93000/soc/tmp/93k.xxxxx/, where 93k.xxxxx is the session name.

To process a saved EDL stream, the formatter can be called from a command line as follows:

%dataformatter -d <EDL filename>

(The data formatter program is located in the directory /opt/hp93000/soc/formatter/bin.)

The -d option is required and allows you to specify the name of the EDL file to be processed into STDF.

You are not required to specify an STDF format configuration at the command line, but you may do so by using the -c option and giving the name of the directory containing the STDF format configuration files as follows:

%dataformatter -d <EDL filename> -c <STDF configuration file directory>

See STDF Configuration for more information.
