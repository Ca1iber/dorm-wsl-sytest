DCST? - (DC SeT)

The DCST? query returns the parameters of the specified DC set.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Predependencies

The DC set must have been defined by DCCH and DCVH.

Syntax

DCST? {setNr}
DCST? ALL

Parameters

setNr

The DC set identification number, starting with 1.
ALL Selects all available DC sets.

The query returns the DC set definition with the syntax as described for DCCH and DCVH.

Errors

An error is returned if the DC set has not been defined yet.

Examples

Example 1: Read a specific setup

Precondition
DCVH 1,,20000,200,-100,100,I,25,NTBBM,PAR,(pin1, pin3)
DCCH 1,,4000,200,-100,100,I,25,NTBBM,PAR,(pin2)
DCVH 3,,20000,200,-100,100,I,25,NTBBM,PAR,(pin4)
DCCH 2,,7000,3000,100,2000,I,25,NTBBM,PAR,(pin5)
Execution
Task>  DCST? 1
DCVH 1,,20000,200,-100,100,I,25,NTBBM,PAR,(pin1,pin3)
DCCH 1,,4000,200,-100,100,I,25,NTBBM,PAR,(pin2)
The example works in offline mode for five PS1600 pins.

Example 2: Read all setups

Precondition
DCVH 1,,20000,200,-100,100,I,25,NTBBM,PAR,(pin1, pin3)
DCCH 1,,4000,200,-100,100,I,25,NTBBM,PAR,(pin2)
DCVH 3,,20000,200,-100,100,I,25,NTBBM,PAR,(pin4)
DCCH 2,,7000,3000,100,2000,I,25,NTBBM,PAR,(pin5)
Execution
Task>  DCST? ALL
DCVH 1,,20000,200,-100,100,I,25,NTBBM,PAR,(pin1,pin3)
DCCH 1,,4000,200,-100,100,I,25,NTBBM,PAR,(pin2)
DCCH 2,,7000,3000,100,2000,I,25,NTBBM,PAR,(pin5)
DCVH 3,,20000,200,-100,100,I,25,NTBBM,PAR,(pin4)
All defined DC sets are returned. The sort order is defined by the DC set identification number.
The example works in offline mode for five PS1600 pins.

Functional changes

  1. Introduced before SmarTest 6.3.2
