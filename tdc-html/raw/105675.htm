Collision handling for the testflow master file

The collision that may happen in testflow master file is the test group name collision.

The setup management tool can handle the collision automatically by renaming the group according to the renaming strategy.

You can also specify the new group name with the REMAP keyword.

The Bind may exist between the testflow file and other setup files. You need to specify the Bind manually in the testflow master file.

The Bind format is like below:

Group 3 [open]: files/group3.tf
[Bind: ../../level/master.lmf: files/eqnset02.lev;../../timing/master.tmf: files/eqnset01.lev;...]

During the assembling of group 3, the setup management tool will scan the binding master setup file pairs, like level, timing, analog control,etc. If the binding setup used in the test suites of group 3 have been re-mapped to a new number or name because of collision handling, it will change the setup of the test suites to the new number or name.

For example, test suite1 in group 3 uses level equation set eqn1 defined in the file eqnset02.lev. In the level master file master.lmf, equation set eqn1 of eqnset02.lev is re-mapped to eqn2 because of level equation set number collision handling. So during the assembling of group 3, the level equation set eqn1 used in test suite1 will be changed to eqn2 according to the re-mapping in the level master file .

Split strategy

When you split the loaded setup file according to the testflow master file, the Group name in the sub-setup files will follow the left column number of the master file.The binded setup information of the sub-setup files will be changed to the settings before collision handling of the binded master setup file.

For example,

Group 3 [open]: files/group3.tf
[Bind: ../../level/master.lmf: files/eqnset02.lev;../../timing/master.tmf: files/eqnset01.lev;...]

The level and timing setup information in Group 3 of files/group3.tf will be changed to the settings before the collision handling of level master file and timing master file.

Functional changes

  1. Introduced in SmarTest 6.5.0
