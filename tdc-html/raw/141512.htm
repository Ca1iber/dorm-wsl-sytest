MTP_MEMORY_TEST.getMemoryPortNamesList()

Retrieves the names of the ports.

Syntax

LONG getMemoryPortNamesList (STRING_VECTOR &port_names_list) const;
Parameter

Parameter

Description

port_names_list

A vector which is used to store the retrieved port names.

Return value

Returns the number of the retrieved port names.

Functional changes

  1. Introduced in MTP 3.2.1
