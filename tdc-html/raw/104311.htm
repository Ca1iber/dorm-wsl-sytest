Topic 104311

Controlling power supply and measurements

Subtopics

  1. Setting up a DC event
  2. Setting up DC event sequences

Power supply and voltage and current measurements on both DC Scale cards and per-pin PMUs can be controlled from with compiled patterns. This is done through so-called DC events. The type of these events - DCScale or pmu - determines which kind of power supply is controlled as well as the syntax of the event detail descriptions.

There are two functions for controlling power and measurements:

  • DC_EVENT lets you set the power or initiate a measurement by calling a so-called DC event defined in the DC event file. Configuring this is described in Setting up a DC event.
  • DC_EVENT_RANGE lets you execute predefined periodic sequences of DC events alongside the standard program code, for example to test the DUT's behavior in case of voltage fluctuations. Configuring this is described in Setting up DC event sequences.

Both functions can be employed in the APG program file. They are discussed in Macros and functions in program files.

There are some differences between DCScale type events which are executed on DC Scale cards and pmu type events which are executed on the PMUs of standard test head cards. These differences are described in Differences between DCScale type and PMU type events.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. MTP 2.4.0: Sequences of DC events introduced
  3. MTP 3.0.1: DC events now support also PMUs
