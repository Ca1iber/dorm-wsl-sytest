Hardware overview

Subtopics

  1. The V93000 HSM Series hardware

Devices that contain memory cores have evolved due to the following trends:

  • Greater data bandwidth or performance requirements
  • Higher degrees of functionality designed into each generation of devices

To support these trends, the following device feature enhancements challenge the capabilities of traditional automatic test equipment.

  • Greater device clock speeds
  • Increased device pin counts
  • Greater device complexity

    Additional layers and wrappers of logic have been added to memory devices and to SOC devices that contain embedded memories.

The per-pin processor architecture of the V93000 test system, combined with the memory test software provides the flexibility and capabilities required to test the continuing evolution of memory devices and SOC devices that contain embedded memories. The per-pin concept is discussed in more detail in V93000 test system architecture.
