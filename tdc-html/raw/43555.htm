Topic 43555

Aborting a Testflow

Aborting a testflow halts the execution of a device test between the testsuites of the device test. When you click the ABORT TESTFLOW button in the Operation Control window (see Controlling a Production Run), you are asked if you really want to abort the testflow. If so, click OK. The test program is then held in PAUSE mode (see Pausing a Production Run). If continue is clicked in PAUSE mode, the test continues on the next device. Note that the test will also stay in PAUSE mode until the PAUSE button in the Operation Control window is released.
