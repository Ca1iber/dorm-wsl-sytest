node()

This function specifies a node ID and a node type.

Syntax

node(string nodeId, enum nodeType);
List of parameters

Parameter

Description

nodeId

The ID of the node that is being created.

The ID can be any string.

nodeType

The type of the node that is being created.

Available types include:

  • TA:ROOT: This node is called from the main label or other nodes.
  • TA:NON_ROOT: This node can only be called from other nodes, not from the main label.

    This is the default value.

Example

rdi.cogo().node("a",TA::ROOT).passNode("b").failNode("c").begin()

Functional changes

  1. Introduced in SmartRDI 2.4.0
