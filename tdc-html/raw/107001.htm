Topic 107001

Overview

This chapter describes how to access flags settings.

Note The flags settings consist of: System Flags, Testflow Flags, Testsuite Flags and User Flags.

Flags settings are typically assigned and saved with each testflow, when the engineer develops it. They are a means to

  • control the execution of the test program and its components down to the test suite, for example by_value vs. pass/fail,
  • control whether and what data is reported/logged, and where such data goes,
  • control exception handling (OOC rules),
  • facilitate debugging with specific debug information (First Failing Vector, for example), and
  • monitor test system status (calibration age, for example).

You will learn how to select report formatters. A report formatter is a means to

Note The report formatter controls the output to the report window produced during test execution.
  • control the "look and feel" (layout and formatting) of data reported to the report window,
  • derive summary information from individual test data for statistical process control (SPC), lot reports etc., and
  • customize the appearance of the report window with additional menu entries and their associated actions to be performed when selected.

Flags settings and the selected report formatter can also be stored in production settings files. Production settings allow you to apply a particular focus for test execution and for the evaluation and logging of result information.

The final section of this chapter describes how to create and use production settings.
