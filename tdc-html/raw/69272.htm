Topic 69272

Parameters for interface identification

The following parameters must be set correctly for the GPIB communication between the equipment and the driver to function:

  • gpib_port

    The configured GPIB port in the configuration file must be the same as the GPIB port configured on the equipment. Check the user documentation of the equipment to find out how to determine and change the GPIB port.

  • interface_type

    Make sure that gpib is entered in the configuration file.

  • gpib_end_of_message_action

    This parameter can be added to ensure that the EOI control line is released after sending a message. Must be set, for example, if an Electroglas 4080 prober is being used in conjunction with an Electroglas station controller.
