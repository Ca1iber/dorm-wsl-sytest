Topic 116761

TTPR, TTPR? - (Transition Test PRimary set)

TTPR defines the primary transition test set. This is the set that will actually be used for testing. If no user defined set has been specified, the predefined set DEFAULT is the primary transition test set. You can also switch from a user defined set back to DEFAULT. TTPR? returns the current primary set.

TTPR

TTPR {"tt_set_name"|DEFAULT}

TTPR?

TTPR?

returns: 

TTPR {"tt_set_name"}

Parameters

tt_set_name

Specifies the name of an existing transition test set.

DEFAULT

This is a predefined transition test set.

Application

Protocol engine tests.

Errors

An error is generated if no transition test set with the specified name exists.

Example

> TTPR   "myTTTrckSet1"

Functional changes

  1. Introduced in SmarTest 7.0.1
