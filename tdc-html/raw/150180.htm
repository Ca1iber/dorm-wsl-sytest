EVENT_WAVEFORM_CF.sampleVectorDistance()

Sets the distance between sample vectors.

Syntax

EVENT_WAVEFORM_CF & sampleVectorDistance(INT vectors);
Parameter
Parameter Description
vectors

Number of vectors defining the distance. Minimum is 32 vectors.
Return value
A reference to the corresponding EVENT_WAVEFORM_CF object.

Example

For an example see EVENT_WAVEFORM_CF.

Related information

EVENT_WAVEFORM_CF.getSampleVectorDistance()

Functional changes
