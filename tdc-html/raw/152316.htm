SmartRDI 2.4.4

This section summarizes the changes and new features in SmartRDI 2.4.4.

Changes and new features

Category

Description

General

General features:

  • A new copyLabel() command supports overwriting existing patterns instead of editing copied patterns for all commands with label(). See the following new commands:
    • copyLabel()
    • rdi.tmu().label().copyLabel() for tmu()
  • Supporting Shmoo serial execution. See the new ALLOW_SAME_RESULT_ID_ACROSS_RDI_BLOCK keyword in the RDI_Configure file.

General Improvements:

  • 1st-run speed improvement.
  • Run-time vector download speed improvement.
    • Supports the combination of run-time accesses for the VTT mode within a burstLabel().begin()/burstLabel().end() block. See burstLabel().

SmartVec
  • Supporting pattern generation based on user pattern. See the new label() and copyLabel() commands.
  • Switching run-time pattern edit mode in TM code. See "Example 2" in rdi.smartVec().vecEditMode().
  • Supporting JSUB / JMPE / RPTJ instruction invocation.
    • See the new command insertSub() for JSUB instruction invocation.
    • See the new command repeatSub() for RPTJ instruction invocation, which should be used together with insertSub().
    • See the new commands insertJmpe(), passNode() and failNode() for JMPE instruction invocation.
  • Supporting fail count, fail cycle, first failing cycle.
    • See the new commands failCount() and getFailCount() for falil count.
    • See the new commands failCyc() and getFailCyc() for fail cycle.
    • See the new commands FFC() and getFFC() for first failing cycle.
  • More flexible repeat() command.
  • Default read mode option in the RDI_Configure file. See the DEFAULT_SMV_READ_MODE keyword in the RDI_Configure file.

Emap

Error map for AVI64 digital pin.

DC
  • Shared BADC-HIZ measurement support in pattern. See "Example 2" and "Example 3" in pin(). Also see "Board ADC example 2" in measWait().
  • Serial/semi-parallel execution of PPMU/BADC digitizing for shared BADC over sites. See Serial/Semi-parallel execution of BADC as digitizer over sites.
  • DCS SIG disconnect(min, max) enhancement for ganged pins. See the enhanced disconnect() command.
  • AWG- & DGT-functionality for different pins within the same execute(). See Forcing waveform on a pin and sampling on another pin.
  • New connect modes for AVI64 SIG pin (SmarTest 7.4.1).
  • Support of multiple insertSub() in one vector line. See the enhanced insertSub() command.

TMU
  • TMU runtime value support for threshold setting. See the enhanced command.
  • Support TMU hidden upload for PVI8/AVI64 (SmarTest 7.4.1). See "Example 2" in rdi.hiddenUpload().
  • Common thread TMU hidden upload (SmarTest 7.4.1). See "Example 3" in rdi.hiddenUpload()

PMUX

Support PMUX sensors.Not supported with SmarTest 7.10

UTIL

Maximum speed option for sequencer‑controlled utility lines. See the new UTIL_CTRL_MAX_SPEED keyword in the RDI_Configure file.

Auxiliary

Get user label's cycle number. See the new command getLabelCycleNum().
