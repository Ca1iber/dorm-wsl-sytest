Topic 44885

Test suite Flag

get

long GetTestsuiteFlag(char *tsname, char *flag, long *value)

long GetTestsuiteFlagOfSite(char *tsname, char *flag, long site, long *value)

This function retrieves the current value of the flag named *flag in test suite *tsname and deposits it in the long pointed to by *value. Flags are actually declared as int's, but are typecast to long's within this function. You can also use a "string" to specify the test suite name (*tsname) required.

GetTestsuiteFlagOfSite() lets you specify which site should be used (1,2,..), while GetTestsuiteFlag() assumes the site currently in focus (for example during sequential User Procedure execution). In a single site test, the first site is always in focus.

Note Use the function, GetTestsuiteName to find out in which test suite context this user procedure is executed.

The following example shows how this function is used,

void CiExample1(char  *parm_list_input,
                int    parmcount,
                char  *comment_out,
                int   *comlen,
                int   *state_out)
{
  char testsuite_name[CI_CPI_MAX_TESTSUITE_LEN];
  long  value;
  *comment_out='\0';
  *comlen=0;

  if (GetTestsuiteName(testsuite_name))
     {
     ErrorHandling("Cannot retrieve testsuite name.");
     *state_out=CI_TEST_FAIL;
     return;
     }

  if (GetTestsuiteFlagOfSite(testsuite_name
                             CI_FORCE_SERIAL,
                             1,
                              &value))
     {
     ErrorHandling("Cannot read testsuite flag FORCE_SERIAL.");
     *state_out=CI_TEST_FAIL; 
     return;
     }

  fprintf(stderr,
     "FORCE_SERIAL flag of testsuite %s at site 1 is: %ld\n",
      testsuite_name,
      value);

  *state_out = CI_CALL_PASS;
}

set
long  SetTestsuiteFlag(char *tsname, char *flag, long value)
long  SetTestsuiteFlagOfSite(char *tsname, char *flag, long site, long value)

This function sets the value of the flag named *flag in test suite *tsname with the value value. Flags are actually declared as int's, but are typecast to long's within this function.

SetTestsuiteFlagOfSite() lets you specify which site should be used (1,2,..), while SetTestsuiteFlag() assumes the site currently in focus (for example during sequential User Procedure execution). In a single site test, the first site is always in focus.

The returned values are,

0

OK

1

erroneous name

-1

internal error
