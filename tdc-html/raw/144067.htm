SOURCESYNC_SUB_TEST.repeatEdgeLength()

Specifies the total number of edges to be displayed on an error map. Use it together with SOURCESYNC_SUB_TEST.repeatEdgeInterval() and SOURCESYNC_SUB_TEST.repeatEdgeOffset() to specify which edges will be printed out on an error map.

Note When the repeatEdgeInterval is set to 0, this function does not take effect.

Syntax

SOURCESYNCE_SUB_TEST& repeatEdgeLength (const int length);
Parameter

Parameter

Description

length

The total number of edges to be shown on an error map.

The default length is 1.

Related information

SOURCESYNC_SUB_TEST.repeatEdgeInterval()
SOURCESYNC_SUB_TEST.repeatEdgeOffset()

Functional changes
