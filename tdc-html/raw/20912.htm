Topic 20912

Obtaining Values of Testflow Variables

To obtain the current values of the testflow variables such as user flags, string variables, and double variables, you can use the following APIs.

The task to be executed....

Use this API....

Provide access to the user flag

GET_USER_FLAG(params)

Provide access to the user double variable

GET_USER_DOUBLE(params)

Provide access to the user string variable

GET_USER_STRING(params)
Note params means the parameters to be specified.

For more details, see GET_USER_FLAG, GET_USER_DOUBLE, and GET_USER_STRING.
