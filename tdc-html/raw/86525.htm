File menu

Menu item

Action

New Error Map

Open an new Error Map Tool. You can open an unlimited number of Error Maps tools. Every Error Map Tool can use different settings concerning the port of format selection.

Snapshot

Generate a snapshot of the Error Map Tool

Print

Print out the Error Map to a printer or file

Close

Close the Error Map Tool. The user´s current settings will be saved automatically

Functional changes

  1. Introduced before SmarTest 6.3.2
