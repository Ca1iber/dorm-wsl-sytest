Compressed digital and analog upload

Since SmarTest 6.5.3 both analog and digital uploads have been improved to handle uploads with less overhead without being licensed.

Compressed uploads split up the 'pure' data from data processing portion. This way the processing part can be accelerated utilizing multithreading capabilities, where the data upload remains serial per site, resulting in reduced upload times.

However, this is only one part of optimized upload of data.

In oder to improve upload times even further, consider to use SmartCalc, which allows uploads to be distributed and hidden.

Note In case you want to use SmartCalc hidden upload you have to have a Xpress Data Mode license.
Note Only SMC upload APIs are capable to take advantage of pure upload. As soon as pure data upload is finished, the SMC uploader process will allow uploading the next capture (and/or continue the execution of the foreground process).
