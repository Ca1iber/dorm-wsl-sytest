Topic 343480

setOffRunTime()

Disables runtime actions for the relays of digital pins or DC Scale pins in Digital I/O operating mode.

Sometimes relay actions are based on a previous result or site dependent. For this purpose, SmartRDI provides the following commands to support runtime values for digital relays:
  • setOnRunTime()
  • setOffRunTime()
  • runTimeVal()

Syntax

setOffRunTime(string runTimeValueString);
Parameter

Parameter

Description

runTimeValueString

The string defines the runtime value.

Examples

In the dynamic mode

vector <string> rtRelay(2); // 2 sites
  rtRelay[0] = "AC";        // AC relay on site 1 is selected
  rtRelay[1] = "PPMU";      // PPMU relay on site 2 is selected
                
rdi.runTimeVal("rtd", rtRelay);
                
RDI_BEGIN();
  rdi.hwRelay().pin().setOffRunTime("rtd").execute();
RDI_END();

In the static mode

vector <string> rtRelay(2); // 2 sites
  rtRelay[0] = "AC";        // AC relay on site 1 is selected
  rtRelay[1] = "PPMU";      // PPMU relay on site 2 is selected
                        
rdi.runTimeVal("rtd", rtRelay);
rdi.hwRelay().pin(A).setOffRunTime("rtd").execute();  //static

Related information

runTimeVal()
setOnRunTime()

Functional changes

  1. Introduced in SmartRDI 2.5.0
  2. SmartRDI 7.5.2: This function can be used in the static mode.
