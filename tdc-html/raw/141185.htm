SlimBusController.dump()

This function dumps the SLIMbus protocol pattern to a human readable format. This can be used for data logging or debugging purposes.

Syntax

STRING dump() const;

List of parameters

There are no parameters.

Return value

A string that interprets the protocol pattern in terms of the underlying protocol.

Functional changes

  1. Introduced in SmarTest 7.2.1
