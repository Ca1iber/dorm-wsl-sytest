TESTSET().port()

This member function of TESTSET applies only to multiport testing. The port name specified by the name parameter is judged and logged into the event data log stream.

This function is not supported within the SMC_backgroundProcessing() test method when flag hidden_datalog_mode is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

Syntax

TESTSET & port(const STRING &name);

Parameter

Descriptions

name

The port name defined in the pin configuration whose functional test result is judged and logged.

Example

TestSet.port("port1");

Related information

TESTSET

Functional changes

  1. Introduced before SmarTest 6.3.2
