SourceSync standard mode

Some parameters of the standard mode source sync test method differ from the parameters in fast mode.

The table which follows explains the parameters.

Note Besides using this provided test method, you can use the SOURCESYNC_TEST API to create your own source-sync test.
Note To shmoo over a source-sync test, besides using the shmoo parameters described in this table, you can use the shmoo tool. For detailed procedures and comparisons between these two methods, see Shmooing over a source-sync test with Shmoo Tool.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. MTP 3.0.1: The test method is now a universal test method.
  3. MTP 3.0.1: The test method is now configured in a window instead of a dialog.
  4. MTP 3.0.3: (MTP on SOC 103.0.0) Added Sharing Config File parameter.
  5. MTP 3.1.3: Added the Shmoo parameter section.
  6. MTP 3.1.3: Added the DQ Offset Min and DQ Offset Max limits
  7. MTP 3.2.2: Shmoo Tool can be used to shmoo over a source-sync test.
  8. MTP 3.2.2: Adds new API SOURCESYNC_TEST.
