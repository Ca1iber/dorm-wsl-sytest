The parameters for the x/y-axis setups for a shmoo test

The parameters for the x-axis setups and the y-axis setups are the same.

These parameters are:

  • ON or OFF for the x-axis: When OFF, no x-axis will be on the shmoo plot, which becomes a one-dimensional shmoo plot. The default is ON.
  • ON or OFF for the y-axis: When OFF, no y-axis will be on the shmoo plot, which becomes a one-dimensional shmoo plot. The default is ON.
  • start: The start value.
  • stop: The stop value.
  • step: The number of intervals (one interval is a step width) between the start and stop values. The default is #10.

    The syntaxes you can enter in this field are:

    • #number: The total intervals, such as #10.
    • #<number1>/<number2>: number1 is the total intervals between the start and stop values, but the results displays every number2 intervals. For example, #<96>/<2>.

      number2 can only be a power of 2, such as 1, 2, 4, 8, 16, ...

    • f#number: A fast shmoo mode, which is equivalent to #<number>/<4>, such as f#96 is the same as #<96>/<4>.

      Note that this mode is different from the Fast Run Shmoo command, which is equivalent to #<number>/<2>.

    • number: the step width, such as 0.1.
  • scale: The scaling method: Linear or Logarithmic. The default value is Linear.
  • parameterType: The type of the parameter that will be varying on x-axis or y-axis. The available types are:
    • SpecVariable (Default): Represents spec variables.
    • Hardware Resources: Represents the HX instruments, the HX resources, the timing resources, and the level resources.
    • Test Method Parameter: (Visible only when test suite names have been selected in the shmooTestSuite field.) It represents the test method parameters with the int and double data types of the to be shmooed test suites.
  • setupPins: (not visible for the Test Method Parameter type) The default is @ (all pins). Lets you specify the pins whose spec variables or hardware resources will be varied during shmoo.

    When setting up a fail bit count shmoo test for MTP, you must only select @ (all pins). Otherwise, errors will occur.

  • spec: Visible only when you select SpecVariable in the parameterType field.

    Lets you select a spec variable in the used timing set or level set. This spec variable will be varying only on the pins selected in setupPins during shmoo.

  • resourceName and unit: Visible only when you select Hardware Resource in the parameterType field.

    Lets you select the following resources, which will be varying only on the pins selected in setupPins during shmoo.

    The available resources are:

    • Any drive/receive edge.
    • Any level resource, such as drive high and low voltages, receive high and low voltages, and etc..
    • Any HX instrument (a HighspeedExtension instrument).
    • Any HX resource( a HighspeedExtension resource).
  • tmParameter and unit: Visible only when you select Test Method Parameter in the parameterType field.

    Lets you choose any test method parameter with the int and double data type of the to be shmooed test suite.
