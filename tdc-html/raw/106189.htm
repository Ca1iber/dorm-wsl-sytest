Topic 106189

DUT representation file

Subtopics

  1. Compiling the DUT representation file
  2. DUT Representation Language

The DUT representation file is used by the redundancy analysis algorithm to learn the structure of the DUT.

The file has the .drs suffix.

The completed representation file is compiled to a shared library, as described in Compiling the DUT representation file.

Note Shared libraries that have been compiled with version 2.x of MTP cannot be used with version 3.x (MTP for SOC 103.x) or later and need to be recompiled.

Syntax

The DUT representation file consists of declaration of system variables and, optionally, user variables and calls to the Initialization functions. The system variables must always be declared before the initialization functions are called.

The DUT is described using the DUT Representation Language.

Example

This is sample DUT representation file to show how such files might look. (This file does not describe a real device.)

// DUT representation
deviceDirectory =  "/home/devices/eDram_xx"; //only for identification
deviceName =       "eDram_xx";               //only for identification

/*******************************************************************************
 * DUT Architecture Section
 ******************************************************************************/
// For whole DUT
nSegment =   512; 
nDatabit =   16;
nDatabitGroup = 1;
nRow =  4096;
nCol =  2048;
nSpareRow = 64;
nSpareCol = 64;
nRowsInWLSet = 4;
nColsInBLPair = 2;

// Per segment
nRowPerSegment = 8;
nColPerSegment = 4;
nSpareRowPerSegment = 1;
nSpareColPerSegment = 1;

// Among segments
nSpareRowSharing = 1;
nSpareRowLinkage = 8;
nSpareColSharing = 4;
nSpareColLinkage = 2;


/*******************************************************************************
 * DUT Initialization Section
 ******************************************************************************/
/**
 * ++++ databit_groups ++++
 * databit_groups_index: (firstDatabit, lastDatabit)
 *   Initialize one databit group (index starts from 0) with its first databit 
 * (number starts from 1) and its last data bit.
 **/

/*-------- direct format --------
@Syntax
DG_STMT_SINGLE: TOK_DG '(' TOK_NUMBER ')' 
                '=' '('  OFFSET_EXPR1 ',' OFFSET_EXPR2 ')' TOK_EOI
  TOK_NUMBER: databit group index               
  OFFSET_EXPR1: first data bit index in this data bit group
  OFFSET_EXPR1: last data bit index in this data bit group                  

OFFSET_EXPR:   '+' EXPR 
             | '-' EXPR  
             | EXPR

#all index starts from 0  
--------------------------------*/
dg(0) = (1,nDatabit/2);
dg(1) = (nDatabit/2+1,nDatabit);

/*-------- incremental format --------
#All incremental format syntax is also covered by the syntax of direct format
--------------------------------*/
dg(0) = (1,nDatabit/2);
dg(1) = (+nDatabit/2,+nDatabit/2);

/*-------- formular format --------
DG_STMT_MULTIPLE: TOK_DG '(' RANGE ')' 
                  '=' '{'  '('   EXPR ','  EXPR  ')' '}' TOK_EOI
RANGE:    TOK_NAME '=' '[' EXPR ',' EXPR ',' EXPR ']'                   
--------------------------------*/
dg(i=[0,1,1]) = {(i*nDatabit/2+1,(i+1)*nDatabit/2)};


/**
 * segments
 * segment_index: databitgroup_idx, 
                  origin_x, origin_y, 
                  num_of_spare_rows, num_of_spare_cols 
   Initialize properties of one segment, for example, databit group it belongs to,
   position of its origin, as well as the number of the spare rows and columns
 */

/*-------- direct format --------
@Syntax
SG_STMT_SINGLE: TOK_SG  '(' TOK_NUMBER ')' 
                '='  '(' EXPR ','  
                         OFFSET_EXPR ',' OFFSET_EXPR ','  
                         OFFSET_EXPR ',' OFFSET_EXPR ')' TOK_EOI 
****************************************/
sg(0) = (0, 0, 0, nSpareRowPerSegment, nSpareColPerSegment);
sg(1) = (0, 1, 0, nSpareRowPerSegment, nSpareColPerSegment);
//...
sg(7) = (0, 7, 0, nSpareRowPerSegment, nSpareColPerSegment);
sg(8) = (0, 0, 1, nSpareRowPerSegment, nSpareColPerSegment);
sg(9) = (0, 1, 1, nSpareRowPerSegment, nSpareColPerSegment);
//...
sg(15) = (0, 7, 1, nSpareRowPerSegment, nSpareColPerSegment);

/*-------- incremental format --------
--------------------------------*/
sg(0) = (0, 0,  0, nSpareRowPerSegment, nSpareColPerSegment);
sg(1) = (0, +1, +0, nSpareRowPerSegment, nSpareColPerSegment);
//...
sg(7) = (0, +1, +0, nSpareRowPerSegment, nSpareColPerSegment);
sg(8) = (0, 0,  +1, nSpareRowPerSegment, nSpareColPerSegment);
sg(9) = (0, +1, +0, nSpareRowPerSegment, nSpareColPerSegment);
//...
sg(15) = (0, +1,+0, nSpareRowPerSegment, nSpareColPerSegment);


/*-------- formular format --------
@Syntax
SG_STMT_MULTIPLE: TOK_SG '(' RANGE ')' 
                  '=' '{'  '(' EXPR ','  
                               EXPR ',' EXPR ',' 
                               EXPR ',' EXPR  ')' '}' TOK_EOI
--------------------------------*/
sg(i=[0,nSegment-1, 1]) = {(0, 
                            i%8, i/8, 
                            nSpareRowPerSegment, nSpareColPerSegment)};

/**
 * spare resource assignment
 * segment_index: databitg_idx, idx_of_spare_row_in_this_segment, spare_row_id
   segment_index: databitg_idx, idx_of_spare_col_in_this_segment, spare_col_id
   Specify spare resource assignment of one segment, for example, which spare resource 
   (spare_row_id) is allocated for this segment and its index in this segment.
 **/
/*-------- direct format --------
@Syntax
SRA_ROW_STMT_SINGLE: TOK_SRA_ROW '(' TOK_NUMBER ')' 
                     '='  '(' EXPR1 ','  
                              EXPR2 ',' OFFSET_EXPR ')' TOK_EOI
SRA_COL_STMT_SINGLE: TOK_SRA_COL '(' TOK_NUMBER ')' 
                     '='  '(' EXPR ','  
                              EXPR ',' OFFSET_EXPR ')' TOK_EOI 
--------------------------------*/
sra_row(0) = (0, 0, 0);
//...
sra_row(7) = (0, 0, 0);
//spare row 0 is used by segments 0,1,2,..7
// and it's the first (0) spare row in the segments.
sra_row(8) = (0, 0, 1);

sra_col(0) = (0, 0, 0);
//...
sra_col(3) = (0, 0, 0);
sra_col(4) = (0, 0, 1);
//...
sra_col(7) = (0, 0, 1);
sra_col(8) = (0, 0, 0);
//...
sra_col(15) = (0, 0, 1);
sra_col(16) = (0, 0, 2);

/*-------- incremental format --------
--------------------------------*/
sra_row(0) = (0, 0, 0);
//...
sra_row(7) = (0, 0, 0);
sra_row(8) = (0, 0, +1);

sra_col(0) = (0, 0, 0);
//...
sra_col(3) = (0, 0, 0);
sra_col(4) = (0, 0, +1);
//...
sra_col(7) = (0, 0, 1);
sra_col(8) = (0, 0, 0);
//...
sra_col(15) = (0, 0, 1);
sra_col(16) = (0, 0, +1);


/*-------- formular format --------
@Syntax
SRA_ROW_STMT_MULTIPLE: TOK_SRA_ROW '(' RANGE ')' 
                       '=' '{'  '(' EXPR ','  
                                    RANGE ',' EXPR  ')' '}' TOK_EOI
SRA_COL_STMT_MULTIPLE: TOK_SRA_COL '(' RANGE ')' 
                       '=' '{'  '(' EXPR ','  
                                    RANGE ',' EXPR  ')' '}' TOK_EOI
--------------------------------*/
sra_row(i=[0,nSegment-1, 1]) = {(0, j=[0, nSpareRowPerSegment-1, 1], i/8)};
sra_col(i=[0,nSegment-1, 1]) = {(0, j=[0, nSpareColPerSegment-1, 1], 
                                 (i%8)/4+(i/16)*2)};


/**
 * spare resource usage
 * Resource: databitg_idx, sharing_length, linkage_length, repairing_segment_ids
 *
   Specify the usage of spare resource (row/col), for example, its shareing length, its
   linkage length, as well as which segments it can repair.
 **/
/*-------- direct format --------
@Syntax
SRU_ROW_STMT_SINGLE: TOK_SRU_ROW '(' TOK_NUMBER ')' 
                     '='  '(' EXPR ',' 
                              EXPR ',' EXPR ','  
                              '(' OFFSET_EXPR_LIST ')' ')' TOK_EOI 
SRU_COL_STMT_SINGLE: TOK_SRU_COL '(' TOK_NUMBER ')' 
                     '='  '(' EXPR ',' 
                              EXPR ',' EXPR ','  
                              '(' OFFSET_EXPR_LIST ')' ')' TOK_EOI
--------------------------------*/
sru_row(0)=(0, 1, 8, (0,1,2,3,4,5,6,7));
sru_row(1)=(0, 1, 8, (8,9,10,11,12,13,14,15));
//...
sru_col(0)=(0, 2, 4, (0,1,2,3,8,9,10,11));
sru_col(1)=(0, 2, 4, (4,5,6,7,12,13,14,15));
//...

/*-------- incremental format --------
--------------------------------*/
sru_row(0)=(0, 1, 8, (0,1,2,3,4,5,6,7));
sru_row(1)=(0, 1, 8, (+8,+8,+8,+8,+8,+8,+8,+8));
//...
sru_col(0)=(0, 2, 4, (0,1,2,3,8,9,10,11));
sru_col(1)=(0, 2, 4, (+4,+4,+4,+4,+4,+4,+4,+4));
//...

/*-------- formular format --------
@Syntax
SRU_ROW_STMT_MULTIPLE: TOK_SRU_ROW '(' RANGE ')' 
                       '=' '{'  '(' EXPR ','  
                                    RANGE ',' RANGE ',' 
                                    EXPR  ')' '}' TOK_EOI
--------------------------------*/
sru_row(i=[0, nSpareRow-1,1])={(0, j=[0,0,1], k=[0,7,1], i*8+k)};
sru_col(i=[0, nSpareCol-1,1])={(0, j=[0,1,1], k=[0,3,1], i*4+k+j*8)};
