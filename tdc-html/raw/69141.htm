Wafer Information Record (WIR)

The Wafer Information Record acts mainly as a marker to indicate where testing of a particular wafer begins for each wafer tested. The WIR and the WRR bracket all the stored information pertaining to one tested wafer. This record is used only when testing at wafer probe. A WIR/WRR pair will have the same HEAD_NUM and SITE_GRP values.

Location in the file:

The Wafer Information Record can be located anywhere in the data stream after the initial sequence and before the MRR. This record is sent before testing each wafer.

WIR field name

Field description

Value

93000 data source

HEAD_NUM
  • Test head number
  • One-byte unsigned integer
  • Value = 1
  • Hard-coded value

SITE_GRP
  • Site group number
  • One-byte unsigned integer
  • 255 = missing or invalid data
  • Hard-coded value

START_T
  • Date and time first part tested
  • Whether the time is local or UTC depends on the setting of the useUTCTime option in formatter.stdf.main.conf.
  • Four-byte unsigned integer
  • Hard-coded value

WAFER_ID
  • Wafer ID
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • Length byte = 0 if missing or invalid data
  • Application model variable1):

    WAFER_ID

  • Data source can also be a constant value in the configuration file or a system environment variable.

Functional changes

  1. Introduced before SmarTest 6.3.2
