NotifyWaferCompletedToSmartest

This notification command notifies the Wafer complete event to SmarTest.

It it mainly used when the FA (Factory Automation) client maintains the level handling and SmarTest does not know the level change information. FA can tell its state to HVM API and SmarTest with using this API.

When executing this API, the event WAFER_COMPLETED will be notified. Success will be returned if the command is successfully issued. Otherwise an error object will be returned indicating the error code, description and severity.

Code

Description

Severity

PARAMETER_EXCEPTION
  • Unknown event name (category) "XXX".
  • Unknown execution state "XXX".
  • The value of the parameter "LOT_ID" is empty.
  • The value of the parameter "WAFER_ID" is empty.

RECOVERABLE

ILLEGAL_OPERATION

The designated session ID "XXX" does not exist.

RECOVERABLE

Dependency

The FA maintains level handling.

Parameters

I/O

Parameters

Description

I

SESSION_ID

The ID of the SmarTest session to notify.

I

EVENT_NAME

The event category. Here it is always EXECUTION.

I

EVENT_BODY

The event parameters. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always WAFER_STARTED.

LOT_ID

The current lot ID.

CASSETTE_ID

(Optional)The current cassette ID.

WAFER_ID

The current wafer ID.

WAFER_SLOT

(Optional) The wafer slot number.

WCR

(Optional) The wafer configuration record data.

This parameter is represented by ParamList whose key and value are both string type.

Prototype

ParamList eventParams;
string sessionId;
Status notify("EXECUTION", eventParams, sessionId);
