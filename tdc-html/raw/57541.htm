SWVersionAttrType

Contains a string representing the build version and build date of the SmarTest software release. It is intended for insertion into the STDF MIR::EXEC_VER field.

The data type is DRLSWVersionAttr.

<revision>,<date>, where <date> is in the <dd-mmm-yy> format
