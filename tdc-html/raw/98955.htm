How to create a universal test method project

This topic shows how to create a universal test method project step by step in SmarTest.

About this task

You will use the New Project wizard to create a universal test method project.

Before you begin

Make sure you are using SmarTest 6.3 or later, and the device primary setups are ready to use.

Procedure

  1. Open a C++ perspective.
    1. In the SmarTest Work Center click Window > Open Perspective > Other. The Open Perspective window opens.
    2. Double-click C/C++. The C/C++ perspective opens.
  2. Open the New Test Method Project wizard.

    Right-click in Project Explorer of the C/C++ perspective and choose New > Test Method Project. The New Test Method Project wizard is opened. The default project name is device name plus "_tml". If the device name contains dot (.), it will be changed to underline (_) when used in the UTM project name. The project name must not contain dot (.). The default location of the project is in the same directory with the device directory.

    Note You are recommended to create only one universal test method project for a device. If you create several projects for a device, you need to select the project location manually.
  3. Enter your own project name if necessary.
    Note The project name is automatically also the name of the test method project directory and the base for the generated shared library. If the project name is "MyTMLib", the library created would be libMyTMLib.so. The library name must not contain dot (.) except the postfix.so.
  4. A default project location is provided with the same folder name as the project. You can also select your own project location.
  5. By default, the new project is referenced by the current device. If you Do not want it to be referenced, deselect the option Referenced by current device.
  6. Click Finish. The project is created.

Results

You can see the universal test method project folder in the C/C++ perspective of SmarTest Work Center. A directory named according to the project name is created in the location you specified. This directory contains two project files .project and .cproject.

To make a UTM project work for both the 32-bit operating system and the 64-bit operating system,

  • use the data types long and pointer carefully. You can use the macro __LP64__ to judge whether the system is 64-bit and then specifically handle the data types.
  • use XOC_ECLIPSE_C_32BITS_OPTION to replace the option -m32 in the compiler and linker.
  • when linking to external libraries, use XOC_OS_SUFFIX to replace the postfix -EL7-64bit.
