Test Program Comparator

Subtopics

  1. Preference page on Test Program Comparator
  2. Comparison reports of Test Program Comparator
  3. Comparison reports

The Test Program Comparator compares test programs and generates a comparison report in HTML or Excel format. The comparison report highlights the differences between the selected test programs.

About this task

The Test Program Comparator can compare:

  • Various setups, such as pins, levels, timings, vectors (including binary data), analog setups (including RF setting), waveforms, testflows (including graphic logic and checksum), test methods, device licenses, and technology files.
  • Setups of any number of testflows or test programs.
    Note When the count of compared testflows is more than 10, it only generates an Excel report.

Before you begin

Make sure:

  • You use the "S&S_TP360_Plus_SOC" license.
  • Your test program setups are correct.

Procedure

  1. Open TP360 and click Test Program Comparator from the App Center tab.
  2. In the Specify test program setups for comparison row of the Setup tab, click the button.

    The Device selection window opens in which you can select the objects to compare:

  3. In the Specify comparison type field, select the type of the files you want to compare.

    The available types are:

    • Testflow: Compares testflows of devices.All setups of testflows are compared, including testflow logic, testflow text content, pins, levels, timings, vectors, analog setups, test tables, test methods used with testflows, the test method libraries being used, and the technologies and licenses being used.
    • Pin: Compares pin configurations of devices.
    • Level: Compares level setups of devices.
    • Timing: Compares timing setups of devices.
    • Vector: Compares patterns of devices.
    • Test table: Compares test tables used with devices.
    • Analog setups: Compares analog setups of devices.
    • Waveform: Compares waveforms of devices.
    • License: Compares licenses used with devices.
    • Test method: Compares UTM codes.
    • Vector_bin_file: Compares binary vector files.
    • Vector_directory: Compares all binary vector files and the sub-directories of different directories.
      Note This does not compare the file content.
    • Any_directory: Compares all files and the sub-directories of different directories.
      Note This does not compare the file content.
  4. Click Open Device to select the objects you want to compare.

    Depending on the type selected in the previous step:

    • The name of the Open Device button can be changed to Open File, Open Directory, and Open Project.
    • The compared objects can be testflows, files, test methods and directories.
  5. Click Finish to close this window.

    The objects selected in step 4 are listed on the Setup tab below the Specify test program setups for comparison row.

    By default, the first listed object is the base object that all the other listed objects are being compared to.

  6. If you want to change the base object, in the Specify one setup as reference row of the Setup tab, click the button. A new window opens listing all the selected objects.Select an alternative base object and click OK to accept the selection and close this window.
  7. If you want to customize the options for comparison, on the Setup tab, click the icon to open the Preference page of Test Program Comparator.
  8. On the Setup tab, select Compare Setups to start the comparison.

Results

An HTML comparison report is displayed in the report area of TP360. You can save the report to a desired directory by clicking the icon in the report view.

If you are comparing more than 10 testflows, an Excel report is generated. The file path of the Excel report is displayed in the report area.

To learn more about the comparison report, see Comparison reports of Test Program Comparator.
