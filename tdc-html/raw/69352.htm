Multitest Handlers

Subtopics

  1. Single-site GPIO configuration
  2. Single-site-encoded GPIO configuration
  3. Dual-site GPIO configuration
  4. Dual-site-encoded GPIO configuration
  5. Quad-site GPIO configuration
  6. Quad-site-encoded configuration
  7. GPIB driver configurations

The Multitest handlers are currently supported with GPIO and GPIB interface. The following configurations are supported:

  • Single-site GPIO configuration
  • Single-site-encoded GPIO configuration
  • Dual-site GPIO configuration
  • Dual-site-encoded GPIO configuration
  • Quad-site GPIO configuration
  • Quad-site-encoded configuration
  • GPIB driver configurations
