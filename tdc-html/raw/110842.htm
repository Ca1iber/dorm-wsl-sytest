ShmooData

ShmooData class is used to do event data logging for shmoo test. It is a data container which holds the shmoo setup information and measurement results of the shmoo cells.

Note Since SmarTest 7.2.0, this class functions as an empty function. Any setup with this class does not take effect but can pass the compilation. To perform the 'ShmooData' functionalities with SmarTest 7.2.0 or the later versions, use the Event Formatter. For details, see Logging shmoo tests into the report window and saving shmoo plots as png files.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ShmooData.h.

setResult()

ShmooData& setResult(unsigned int x, unsigned int y,
                     const ShmooCellResult& cellResult);

This function sets the result of cell (x,y) to the specified value.

Parameters

x

the relative coordinate of x axis.

y

the relative coordinate of x axis.

cellResult

The result to set in the type of ShmooCellResult. The ShmooCellResult is defined as:

struct ShmooCellResult

{

enum ShmooCellPassFail

{

SHMOO_CELL_VALUE = -1,

SHMOO_CELL_PASS = 0,

SHMOO_CELL_FAIL = 1

};

ShmooCellPassFail resultType;

double value;

};

Example

ShmooData shmooData;
ShmooCellResult shmooCellRes;
shmooData.setTitle("shmoo  TestMethod");
shmooData.setTestMode("Normal");
shmooData.setTitle("shmoo TestMethod");
shmooData.setXStart(1);
shmooData.setXStop(17);
shmooData.setXTotalSteps(16);
shmooData.setXLinearSteps(4);
shmooData.setXAxisDescription("Level Low Voltage");
shmooData.setYStart(6);
shmooData.setYStop(10);
shmooData.setYTotalSteps(4);
shmooData.setYLinearSteps(2);
shmooData.setYAxisDescription("Timing the first receiving edge delay");
shmooCellRes.resultType=ShmooCellResult::SHMOO_CELL_VALUE;
shmooCellRes.value=0.0;
shmooData.setResult(1,2,shmooCellRes);
//the result at cell(1, 2) is neither PASS nor Fail, it is 0.0.
TESTSET().doLog_ShmooTest("shmoo TestMethod", shmooData);

In this above example, the shmoo setup and result data are set and logged.
