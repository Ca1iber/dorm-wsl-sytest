Topic 17878

Displaying the Timing

Subtopics

  1. Displaying Device Cycles for Pins in Table Format
  2. Displaying Device Cycles Generated for One Pin

There are two modes of displaying the timing. You can:

  • show device cycles that are valid for pins listed in the current display format. All these device cycles have the same name.
  • show all device cycles that have been generated for a particular pin. Each of these device cycles has a different name.
