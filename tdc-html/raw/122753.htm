Reduce number of Samples

A reduction in test time can be achieved by keeping the number of samples to a minimum.This can be achieved by.

  • Good DUT board design to eliminate noise
  • Reducing wait time (WAIT_TIME())
  • Reducing sample size
  • Reducing oversampling rate
  • Optimizing pattern length
  • Check for unnecessary code that can be removed

If you need to capture a large number of samples, an efficient way is to use vector loops or the RPTV vector sequencer instructions.
