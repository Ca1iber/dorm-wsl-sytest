SPMU_PIN_TASK.settling()

Sets the settling time that specifies the additional time interval between the DC instrument being connected and the static measurement being performed. The settling time is added to the internal settling time of the tester hardware.

The settling time will be applied to each pin used with serial measurements.

Note For dynamic measurements the settling time has to be dealt with in the pattern.

Syntax

SPMU_PIN_TASK& settling(DOUBLE time);
Parameter

Parameter

Description

time

Settling time in seconds (s).

Default is 0 seconds.

Valid range is 0 s to 2 s.

Return value

A reference to the SPMU_PIN_TASK object.
