Activating a Hook Function

To tell the driver that a hook function should be called during the driver execution, the hook function must be activated. Deactivated hook function, although existent in the ph_hhook.c source file, will not be called (see also Special Functions in the Hook Source File).

To activate a hook function you must remove the comment delimiters

/* .. */ around the respective define command in the ph_hhook.c file.

/*#define ACTION_START_IMPLEMENTED */

/*#define ACTION_DONE_IMPLEMENTED */

/* #define PROBLEM_IMPLEMENTED */

/*#define WAITING_IMPLEMENTED */

/*#define POPUP_IMPLEMENTED */

To deactivate a hook function, add the comment delimiters again.

In the provided default ph_hhook.c file, all hook functions are deactivated.
