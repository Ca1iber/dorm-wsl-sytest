Topic 141304

valueMode()

Specifies a method for measuring voltage or current on the pins of PS1600 or PS5000 cards.

If measurements are done on more than one pin sharing the same board ADC, the measurements will be done serially in the pattern.

In this case, the pins setups are different between SmartRDI 2.2 and 2.3:

  • In SmartRDI 2.2, pins that share the same board ADC must be separated in different pin() functions.

    For example, 

    RDI_BEGIN();
  rdi.dc().pin("pinA").vForce(4).iMeas().valueMode(TA::BADC).execute();
  rdi.dc().pin("pinB").vForce(4).iMeas().valueMode(TA::BADC).execute();
RDI_END();
  • In SmartRDI 2.3: pins that share the same board ADC can be set in the same pin() function. SmartRDI automatically switches the relay for each pin and adds a default wait time between two measurements if no measWait() is specified.

    For example,

    RDI_BEGIN();
  rdi.dc().pin("pinA, pinB").vForce(4).iMeas().measWait(100 us).valueMode(TA::BADC).execute();
RDI_END();
  • From SmartRDI 2.3.1, you can add an option in the RDI_Configure file to set a default value mode for PPMU: PPMU_DEFAULT_VALUE_MODE = SA # BADC.

    If you do not set this option in the RDI_Configure file, the default value is TA::BADC.

Syntax

valueMode(TA::PinType src);
List of parameters

Parameter

Description

src

The method used to measure a value. It can be:

  • TA::BADC (default): To measure values by using the board ADC.
  • TA::SA: A successive approximation value calculated by using the level comparator of the PPMU.
    Note valueMode(TA::SA) is specified only for voltage measurement, not for current measurement. See PS1600 Voltage force and measure and PS1600 Current force and measure.
  • TA::PF_ONLY: When you only need the burst pass/fail result of dynamic DC measurements on digital pins, you can use this value. With valueMode(TA::PF_ONLY), SmartRDI only adds 10 us after measurement. As a result, if you do not care too much about measurement values, this setting can save some test time.

    It must work together with limit(min,max).

Examples

rdi.dc("id3").pin("PinA").vMeas().valueMode(TA::BADC).execute();

valueMode(TA::PF_ONLY) working together with limit(min,max) when the burst pass/fail result of dynamic DC measurements on digital pins is only required.

RDI_BEGIN();
  rdi.burstId("burst","pinA");
  rdi.dc().pin("pinA").iForce(0).vMeas()
                      .valueMode(TA::PF_ONLY)
                      .limit(0.1,1.2).execute();
RDI_END();

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 2.2.0: Supports switching AMUX in the pattern‑based mode when measuring with board ADC on PS1600.
  3. SmartRDI 2.3.0: Supports high voltage pins.
  4. SmartRDI 2.3.0: When pins that share the same board ADC are measured with the BADC, these pins can be set in the same pin() function.
  5. SmartRDI 2.3.1: You can add an option PPMU_DEFAULT_VALUE_MODE in the RDI_Configure file to set the default value mode for PPMU.
  6. SmartRDI 2.5.0: The default value is changed from TA::SA to TA::BADC.
  7. SmartRDI 7.5.3: New value TA::PF_ONLY.
