Topic 122740

Restrictions for selective digital capture

The action codes C and D, with which selective digital capture is triggered (C) or suppressed (D) must be used according to the following requirements:

  • If a waveform contains digital capture actions, its receive actions must be used exclusively for digital capture, that is, the waveform must not contain any compare action.
  • A waveform can contain more than one digital capture action, but C and D cannot be combined within one waveform.
  • If any waveform contains more than one digital capture action, all capture waveform must contain the same number of actions and use the same edges. The first edge must be r1, and there must not be any numbering gaps.

Differing rules for HRPF mode

In HRPF mode, capture waveforms with more than one capture edge must observe certain pairing rules as follows:

r1 must be combined with r5

r2 must be combined with r6

r3 must be combined with r7

r4 must be combined with r8

On the other hand, you may use different pairs in different capture waveforms (which is not allowed with standard selective capture) as long as the total number of edges is the same. Note that the pairing rule apply only on the receive edges of the capture waveforms defined in your wavetable. The timing equations for these edges in your timing set specify the edges in ascending order, that is, r1, r2, r3, and so on. See the following example:

Example

This example shows the setup of digital capture in X8 mode. The digital capture waveform is defined in the wavetable. The receive edges are specifies according to the pairing rule mentioned above. However, the timing equations for these edges are specified in the timing set in ascending order, that is, r1, r2, r3, r4, till r8:

# WAVETABLE
WAVETBL "X8Capt"
...
PIN SEROUT
HRPF 0 "d1:0" 0
1 "d1:1" 1
2 "d1:Z r1:L"       L
3 "d1:Z r1:H"       H
4 "d1:Z r1:X"       X
// receive edges in the capture waveform are defined according to the pairing rule
5 "d1:Z r1:C r5:C r2:C r6:C r3:C r7:C r4:C r8:C"  CCCCCCCC 
...
# Timing
EQNSET "X8CaptTim"
...
PIN SEROUT
d1=0d2=0.5*Tcyc
// receive edges for the digital capture are specified in ascending order
r1=0.100*Tcyc
r2=0.225*Tcyc
r3=0.350*Tcyc
r4=0.475*Tcyc
r5=0.600*Tcyc
r6=0.725*Tcyc
r7=0.850*Tcyc
r8=0.975*Tcyc

The following examples illustrate the restrictions for standard selective capture:

0 "r1:L r2:C"   LC

This will be rejected because digital capture actions and standard compare actions are combined in one waveform.

0 "r1:D r2:C"   DC

This will be rejected because C and D are combined in one waveform.

0 "r1:C r3:C"   CC
1 "r1:D r3:D"   DD

This will be rejected because of the edge numbering gap.

0 "r2:C r3:C"   CC
1 "r2:D r3:D"   DD

This will be rejected because the first edge is not r1.

0 "r1:C"        C
1 "r1:D r2:D"   DD

This will be rejected because the two waveforms contain a different number of edges.

If, however, the capture waveforms contain only one action, the edges are allowed to be different:

0 "r1:C"   C
1 "r2:D"   D

This will be accepted.
