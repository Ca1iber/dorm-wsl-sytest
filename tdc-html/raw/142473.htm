Topic 142473

Creating both detailed and summary output files

To create both a detailed and a summary STDF output file, create an additional STDF configuration file and modify global.conf.

About this task

Perform this setup when you want to regularly create both detailed and summary STDF files from the same data log.

Before you begin

Quit SmarTest.

Procedure

  1. In the application model, create these two variables:
    • STDF_FILE=CONST_INPUT(*.stdf)
    • STDF_SUMMARY_FILE=CONST_INPUT(*.stdf.summary)

      These two variables contain the file names for the standard and summary STDF logs, respectively. If you desire different names, change the definition of these variables.

  2. Set these options in formatter.stdf.main.conf: 
    generateDetailedFile=true
generateSummaryFile=true
STDF_FILE_SRC=AppVar:STDF_FILE
STDF_SUMMARY_FILE_SRC=AppVar:STDF_SUMMARY_FILE

    If you want to suppress the output of the standard or the default log, set generateDetailedFile or generateSummaryFile, respectively, to false. Note that you need to close SmarTest before each change to formatter.stdf.main.conf and restart it afterwards.

  3. Start SmarTest.

Results

Each time an STDF file is created, both a detailed and a summary file are created from now on. Both files have the same name, except that .summary is added to the name of the summary file.
