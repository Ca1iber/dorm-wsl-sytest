Topic 10466

DUT Input Stability

All DC measurements using a PMU require the DUT to be stable when the measurement is made. As most of the measurements are taken with the tester in the break state, you must ensure that the break waveform in the active waveform set does not cause toggling.

The break waveform is set with the command BWDF, BWDF? - (Break Waveform DeFinition).
