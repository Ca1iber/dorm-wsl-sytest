Level setup master file

Subtopics

  1. Master file format for level setup
  2. Editing the level and timing subfiles

The level setup can be organized as one single file, or its individual level equation sets and testdata blocks (DFTD command) can be be stored in separate files. In the latter case the parts that belong together are connected by a master file which contains references to the respective files. This construction has the advantage that several users can work on the same level setup in parallel.
