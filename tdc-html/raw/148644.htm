Topic 148644

rdi.id().getBurstPassFail()

Retrieves a burst pattern test result (pass/fail). The pass/fail result has been stored in buffer by rdi.func().burstId().

Note If SmartRDI alarm handling is used, the burst pass/fail result is impacted by an alarm fail. This means if an alarm check fails, the burst result will fail too.

Syntax

rdi.id(string burstId);
rdi.id(int burstId);
List of parameters

Parameter

Description

burstId

The same ID that you have given in a rdi.func().burstId(). It supports both string and int types.

Example

For its usages, see the Example section in rdi.func().burstId().

Related information

rdi.getBurstPassFail()
rdi.func().burstId()

Functional changes

  1. Introduced in SmartRDI 2.3.0
