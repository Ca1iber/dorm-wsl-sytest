Additional pin qualifier @diff

In the equation editor you can add an additional pin qualifier for differential pins: @diff. This differential qualifier ensures, that a differential pair will be fully defined, although just one connection of the pair is specified.

Note The @diff qualifier is not available in the level and timing setup GUIs. You can only use it in the equation editor.

Here an example of a level equation file entry using this syntax:

PINS clkout_p@diff cadout_n@diff
term center_tap
Vt=spec1

Note that there is no space between the pin designation and the @diff qualifier.
