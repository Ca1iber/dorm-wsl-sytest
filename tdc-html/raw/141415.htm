MTP_MEMORY_PORT.getPassFailResult()

Retrieves the overall pass/fail test result of a specific port.

The port is specified with getMemoryPort().

Syntax

bool getPassFailResult ();

List of parameters

There are no parameters.

Return value

Returns true or false.

Related information

MTP_MEMORY_TEST.getMemoryPort()

Functional changes

  1. Introduced in MTP 3.2.1
