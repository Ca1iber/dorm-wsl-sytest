TESTSET().testname_default()

This member function of TESTSET cancels the test name which has been set by a prior call of the testname(const STRING &name) member function and returns to the default mode.

In default mode the test name that is given to the TEST() method, or that is automatically generated in the TEST() API, based on the test name given to the TEST() method, is stored into the EDL as a TestName attribute. This member function is used only after the testname function has been executed.

This function is not supported within the SMC_backgroundProcessing() test method when flag hidden_datalog_mode is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

Syntax

TESTSET & testname_default();

Example

TestSet.testname_default();
