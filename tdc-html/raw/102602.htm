Topic 102602

Pattern list file syntax

A pattern list file contains references to a number of pattern files that are to be compiled together.

Pattern list files are loaded in the MTL Compiler Control dialog. They must be saved in the /device/mts/pattern_defs/pattern_list directory and have the file name extension .plf.

Syntax

A pattern list file looks like this:

hp93000,pattern_list_file,0.1
path:
<folderPath>
files:
<fileName>
...
...

Italic text indicates meta-syntax, as described in Syntax conventions.

Parameter

Description

<fileName>

The name of the APG pattern file.

The name does not include any path information; all files are located in the folder specified by the previous path: statement.

For example: myPattern.apg

<folderPath>

The path of the folder in which the following files are located.

The path is specified relative to the directory in which the pattern list file is located (/device/mts/pattern_defs/pattern_list). For example: ../myDir/

All files listed after one path: statement until the next path: belong to the same folder. A pattern list file can contain any number of path: statements.

Limitations

Please observe these limitations:

  • Pattern list files must be located in the /device/mts/pattern_defs/pattern_list directory.
  • All pattern files referenced in a pattern list file must be located in the same device directory as the pattern list file.
  • All referenced pattern files must have different names, even if they are located in different directories.

Example

hp93000,pattern_list_file,0.1

path:
../initialization/

files:
init.apg

path:
../refresh/

files:
no_refresh.apg

path:
../scan/

files:
scan.apg
scan_clk.apg
scan_short.apg
scan_short_clk.apg
