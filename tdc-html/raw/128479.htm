Offline result emulation for the FlexDC API

Subtopics

  1. Offline result emulation for Class DPS_TASK
  2. Offline result emulation for Class PPMU_MEASURE
  3. Offline result emulation for Class SPMU_TASK
  4. Offline result emulation for Class TASK_LIST

Parametric offline result emulation capabilities are provided only for the following parts of the FlexDC API.

The detailed specification can be found in the test method API Reference documentation.

  • PPMU_MEASURE
    • PPMU_PIN_MEASURE
  • DPS_TASK
    • DPS_PIN_TASK
  • SPMU_TASK
    • SPMU_PIN_TASK
  • TASK_LIST

SmarTest provides offline result emulation capabilities only for parametric measurements on device power supplies (DPS), the system parametric measurement unit (SPMU), and the per-pin parametric measurement unit (PPMU). This required enhancements to the following classes:

  • Class DPS_TASK
  • Class SPMU_TASK
  • Class PPMU_MEASURE
  • Class TASK_LIST
