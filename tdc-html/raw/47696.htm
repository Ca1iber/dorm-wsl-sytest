Topic 47696

Mutiport Timing Setup

The following syntax must be used to set up multiport timing:

PRIMARY TIMING MULTIPORT <specification-name> SET <set-list>

or

PRIMARY TIMING MULTIPORT <specification-name> SET <set-number>
  1. The specification-name is a string. It represents a multiport specification.
  2. N is the number of ports associated with the multiport specification.
  3. The set-list represents the timing set used for each port in which the port list is in alphabetical order. A set-list is a string that has the following format:
    set-list = set-number1,set-number2,set-number3,...,set-numberN
  4. The set-number is a positive integer that represents a timing set.
  5. If all ports use the same timing set, the second syntax is used. If more than one timing set is used, the first syntax is used.

For example, a multiport specification called MyFourPortSpec has four timing ports: portA, portB, portC, and portD. (Note that the ports are already in alphabetical order.) Each port has two timing sets: 1 and 2. If timing set 1 is used for portA and portC, and timing set 2 is used for portB and portD, the syntax is as follows:

PRIMARY TIMING MULTIPORT "MyFourPortSpec" SET "1,2,1,2"

If all ports use timing set 1, then the syntax is as follows:

PRIMARY TIMING MULTIPORT "MyFourPortSpec" SET 1

If all ports use timing set 2, then the syntax is as follows:

PRIMARY TIMING MULTIPORT "MyFourPortSpec" SET 2

If a multiport specification is used, no period margin test is allowed. If you want to margin a period, you must perform a spec-search.
