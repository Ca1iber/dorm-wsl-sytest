Topic 58785

Subsidiary queries

Subtopics

  1. Match loop traces in the test results

The subsidiary queries do not require that a test has been executed. However, the label (pattern) you are interested in must have been defined as the start label with SQSL, and the timing setup with which it is to be run must have been declared the primary timing with SPRM.

The subsidiary commands can be divided into two groups. The queries of the first group return setup data for a cycle range:

  • CDCP? translates physical waveform DC/DC power units into device cycle names and data parameters using the primary (not the base) wavetable.
  • EAEX? returns drive and expected edge action data in the requested cycle range.
  • GETV? returns the vector setup from which a certain cycle range was created.
  • GETS? returns the timing and level sets that were used for a given cycle range.

The queries of the second group return cycle information.

  • GETC? returns the cycle number for a given vector.
  • VCYC? returns the physical waveform DC/DC power units for the requested cycle range.
  • VRCS? returns the number of cycles that result from the current start label.

GETX? belongs to both groups. It can be used for retrieve the cycle number for a certain vector, and also to get setup information for a certain cycle.
