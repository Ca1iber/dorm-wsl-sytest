Topic 37599

Using X-Modes for Scan Setups

Subtopics

  1. Creation of the Waveform DC/DC power units for the Parallel Part
  2. ASCII Vector Padding for Scan Vectors

X-modes for scan vectors do not differ essentially from x-modes for parallel vectors. There is, however, one restriction. Fractional x-modes are only supported for download and execution; the scan tool of SmarTest cannot manage such vectors adequately.

Furthermore, two implementation details require some explanation. These concern

  • the waveform DC/DC power units for the state characters of the parallel parts and
  • the ASCII vector padding for the scan pins.
