Test number conversion use cases

This section shows some typical use cases of the test number conversion tool.

Conversion check

Purpose: Check if conversion is needed and how many test number should be converted for the specified testflow file.

Precondition:

  • SmarTest is running (offline/online)
  • The specified testflow file is loadable by SmarTest 7.1
  • The specified testflow file is in a device directory
  • There is a corresponding test number file for the specified testflow file under the test_numbers directory in the device directory

Main success scenarios ?????:

  • Run the conversion tool with check option
  • The tool indicates that if conversion is needed and provide a list of test number that needs to be converted

Test numbering conversion for a specified testflow file

Purpose: Convert the test number for those tests that appear in Tests tab of the testflow editor from test number manager to test number generator.

Precondition:

  • SmarTest started (offline/online).
  • The specified testflow file is loadable by SmarTest 7.1
  • The specified testflow file is in a device directory
  • The value for test_number_manager flag in testflow file is 1
  • The value for test_number_enabled flag in testflow file is 1
  • There are tests that appear in Tests tab in testflow editor
  • There are tests that do not appear in Tests tab in testflow editor
  • There is a corresponding test number file for the specified testflow file under the test_numbers directory in the device directory

Main success scenarios:

  • Run the conversion tool without check option
  • The specified testflow file is modified
  • The value of test_number_manager is set to 0
  • Test numbers for those tests that appear in Tests tab in testflow editor
  • There are messages that notify you to manually convert test numbers for the tests that do not appear in Tests tab in testflow editor.

Test numbering conversion with TMLimits CSV file

Goal:

Convert the test number and save them in a specified TMLimits CSV file.

Precondition:

  • SmarTest started (offline/online)
  • The specified testflow file is loadable by SmarTest 7.1
  • The specified testflow file is in a device directory
  • The value for test_number_manager flag in testflow file is 1
  • The value for test_number_enabled flag in testflow file is 1
  • There are tests that appear in "Tests" tab in testflow editor
  • There is a corresponding test number file for the specified testflow file under the test_numbers directory in the device directory

Main success scenarios:

  • Run the conversion tool without check option but with a TMLimits csv option
  • The specified TMLimits CSV file will be created and test limits including converted test numbers will be store in it.
  • There are messages that notify you to to manually modify your test methods to adapt TMLimits csv file if needed.
