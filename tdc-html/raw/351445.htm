Topic 351445

Setting up the Register Access library

Subtopics

  1. Register structure
  2. Importing a C++ register structure

The Register Access library needs to be set up before it can be used to execute register operations in a test method project.

About this task

Two required steps are introduced for setting up the Register Access library.

Procedure

  1. Set up a protocol for register access. See Protocol management for detailed information.
  2. (Optional) Import the register structure of a device. See Register structure and Importing a C++ register structure.

Results

The Register Access library is ready to be used in test methods.

What to do next

Use the library's member functions in your test method.

Functional changes

  1. Introduced in SmartRDI 7.6.0
