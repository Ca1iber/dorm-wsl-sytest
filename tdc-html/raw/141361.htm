EVENT_ICIM.limitLow()

Sets the lower current limit to compare against threshold.

Syntax

EVENT_ICIM & limitLow(const EVENT_VALUE_DOUBLE & value );
Parameter
Parameter Description
value

Lower value of current range

Return value

There is no return value.

Example

For an example see EVENT_ICIM.
