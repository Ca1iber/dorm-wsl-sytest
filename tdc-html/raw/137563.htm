MTP 3.2.1

MTP 3.2.1 is released together with SmarTest 7.2.1. From MTP 3.2.1, MTP-on-SOC and MTP-on-HSM become one software package, called "MTP <version number>". Depending on the used licenses, the functionalities will be different.

This section summarizes the changes and new features in MTP 3.2.1.

  • Error map of the SourceSync test method
  • The SourceSync.FastMode test method enhancements
  • ASCII data log for the fail bit count shmoo test
  • Counting failing addresses for a pin group
  • The MTP Build configuration pages provided with MTP-EWC
  • The MTP build commands provided with MTP-EWC
  • Enhancements on the MTP testflow launch configuration page
  • APIs for redundancy analysis
  • APIs to support multiport with MTP_MEMORY_TEST
  • The MTP_MEMORY_PATTERN API enhancements
  • apgc -t command
  • Bit Fail Map Viewer enhancements
  • The legacy memory test pattern converter
