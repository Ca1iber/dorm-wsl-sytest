Set up the CCT Test Flow

After conversion to a concurrent test, one important aspect of the test flow settings is based on the decision whether to re-run or terminate the test execution upon a port failure.

The reason for this is the following:

In a concurrent test, you test several or all of the device cores simultaneously. However, the normal operating conditions of the device may not require all of these cores to be operating at the same time.

Hence, during the concurrent test, if a core fails it may be as a result of crosstalk, noise, power limitations or other factors coming from the activity of the other cores.

In this case, the failed cores will require re-testing separately as a stand-alone test before you can decide whether it is defective or not.

For example, consider a setup where you combine the testA (core A), testB (core B), and testC (core C) into one simultaneous CCT test suite.

If, under normal operating conditions of the device, cores A and B are not active when core C is, then a failure of the concurrent test, due to a failure of core C means that you will have to test core C on its own before deciding whether to discard the device or not.

If, however, under normal operating conditions for the device, the cores A, B and C are all active together, then any failure of the CCT test flow means that the device is defective and it can be discarded without any further testing.

Test Method Code

An example of a piece of CCT test method code for this purpose is shown below:

The case where core C fails in CCT together with core A and core B

    if (coreA_result&&coreB_result&&coreC_result)
    {    
        SET_SYSTEM_FLAG("hard_bin",1);
        SET_SYSTEM_FLAG("soft_bin", 1);
        if (debug) cout<< " PASS: All cores"<< endl;
    }    
    else
    {
        if (coreA_result&&coreB_result)
        {
          if (!(coreC_result)
          {
           SET_SYSTEM_FLAG("hard_bin",3);
           SET_SYSTEM_FLAG("soft_bin", 130);
           if (debug) cout<< "FAIL: parallel test on core C"<< endl;
          }
         }
         else
         {  if(coreC_result)
            {
            SET_SYSTEM_FLAG("hard_bin",3);
            SET_SYSTEM_FLAG("soft_bin",200);
            if (debug) cout<< "FAIL: coreA and coreB "<< endl;
            }
            else
            {
            SET_SYSTEM_FLAG("hard_bin",3);
            SET_SYSTEM_FLAG("soft_bin",300);
            if (debug) cout<< "FAIL: coreA, coreB, and coreC "<< endl;
         }
       }
