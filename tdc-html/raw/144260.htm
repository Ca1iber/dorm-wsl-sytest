Test Program Cleaner

Subtopics

  1. Using the Test Program Cleaner
  2. Programs after cleaning
  3. Preference page on Test Program Cleaner

Test Program Cleaner will find out and clean the redundant files and setups of your test program (device).

You can use it when you are releasing test programs. It can:

  • Clean setups and files for one or multiple testflows of your device.
  • Clean redundant files.
  • Clean redundant setups including:
    • Unused level, timing and pin definitions.
    • Unused setups for executing testflows.
    • Undefined digital pins, levels, timings and vectors.
  • Collect UTM projects and external files/directories.
