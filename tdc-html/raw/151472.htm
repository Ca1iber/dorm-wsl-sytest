Topic 151472

rdi.tmu().measNum()

Specifies the number of existing arming events defined in the used pattern.

Based on the number, you can know how many time stamp results are to be retrieved after the pattern execution. For example, if you set this function's value to 5 and the sample()'s value to 4, getStamp() will return an array which contains 20 results with time stamps.

The number must be consistent with the amount of existing arm events in the pattern. If it is greater than the amount, the result from the current execution will be affected; if it is smaller, the results from following executions will be affected.

Note This function is only used for a digital pin.

Syntax

measNum(int sNumber);
List of parameters
Parameter Description
sNumber The number of existing arming actions in the label.

Example

RDI_BEGIN();

...rdi.tmu("tmu_test").label("abc").pin("DATA1").vth(1.0 v)

      .sample(4).measMode(TA::RISE).measNum(5).execute(); // Do not have to use insertVec().

   rdi.wait(1 ms);

RDI_END();

ARRAY_D result = rdi.id("id").getStamp(); // The size of the returned ARRAY_D is 20 which is from measNum(5) and sample(4).

Related information
