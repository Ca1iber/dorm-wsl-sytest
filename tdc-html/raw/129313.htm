Driver Sharing APIs

Using those ready-made driver sharing test methods provided with MTP is normally the quickest and easies way to test shared DUTs. However, if you have special requirements that those test methods cannot meet, you can also develop you own test methods using these APIs:

  • To test pins (either shared, non-shared or cross-terminated pins) with same measurement conditions, use APIs:
    • SHARED_CONTINUITY_TEST lets you check the continuity and find short circuits for the DUTs with driver sharing.
    • SHARED_IDD_TEST lets you check the IDD and IDDQ for the DUTs with driver sharing.
    • SHARED_LEAKAGE_PARALLEL_TEST lets you do the parallel leakage test for the DUTs with driver sharing.
    • SHARED_VBUMP_TEST lets you change the power supply voltages during a functional test for the DUTs with driver sharing.

      All these APIs support logging their test results.

  • To test any number of pins (either shared, non-shared or cross-terminated pins) with any types of measurement conditions within one test method, these classes, defines, and functions are supported:

    Classes:

    • MTP_CONTINUITY_PIN_TASK
    • MTP_CONTINUITY_TASK
    • MTP_DPS_MEASURE
    • MTP_FUNC_TASK
    • MTP_IDD_PIN_TASK
    • MTP_IDD_TASK
    • MTP_LEAKAGE_PIN_TASK
    • MTP_LEAKAGE_TASK
    • MTP_PPMU_MEASURE
    • SHARING_CONFIGURATION

      Defines:

    • FOR_EACH_TEST_BEGIN()
    • FOR_EACH_TEST_BEGIN_WITH_RESET()
    • FOR_EACH_TEST_END()
    • FOR_EACH_SHARED_SITE_BEGIN()
    • FOR_EACH_SHARED_SITE_END()
    • GET_CURRENT_UTILITY_CONTROL()

      Functions:

    • GET_SITES_UNDER_TEST()
