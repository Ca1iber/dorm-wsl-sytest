Fine result granularity

Subtopics

  1. Setting the FRG (fine result granularity) flag
  2. Short data representation with fine result granularity
  3. Verbose data representation with fine result granularity
  4. Single-shot per-edge pass/fail results

"Fine result granularity" (FRG) is a mode that provides pass/fail results for each edge of a tester cycle. If the mode is not active, there is a single pass/fail result for the entire cycle.

FRG provides more precise location of failures, but also generates more result data, which results in slower execution.

Both modes use the same result format. Failing edges are indicated by a "#" sign, passed edges by a period (.).

Note that fine result granularity is not compatible with protocol-aware tests. Do not set this flag for test suites that perform protocol-aware tests.

Functional changes

  1. Introduced before SmarTest 6.3.2
