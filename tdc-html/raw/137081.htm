Specific analysis

The various views of the Integrated Result Tool let you analyze data logs in a great variety of ways.

This list briefly describes how to perform some common analytical tasks. For details, see the pages linked in the individual descriptions.

  • Determining the test time

    In the Test summary tab, check the displayed times in the T$ and TS$ columns.

    (For greater detail, you can also check the same information in a raw data or stream data view. See Examining the underlying data of a summary for more information on displaying detail data for a summary.)

    You can also check the T$ column in wafer summary tabs or device summary tabs.

  • Comparing test results for different sites

    In the test summary tab, group the tests summaries by site. Select the sites you are interested in and display them a suitable result graph, for example, trend chart or histogram chart.

  • Comparing test results from two data logs

    Open both logs.

    To compare the results numerically, arrange the two views so that you can compare the values you are interested in.

    To compare the results graphically, open the same kind of graphs for the corresponding rows from the two logs and pin them to prevent unwanted automatic changes in the graphs when the selection changes. (See Displaying test results as result graphs for more information on pinning.)

  • Comparing two different transaction protocols

    To compare two PCI Express transaction protocols, open the first protocol in the Protocol Monitor view and click that view's Create baseline toolbar button. Then open the second protocol. All cells that are different from the baseline are marked by annotations in the left-hand margin and the cells themselves are highlighted.

    You can configure the columns that are to be considered for the comparison by clicking the button beside the search field in the Protocol Monitor view. You can switch the comparison mode on and off by clicking the Toggle Compare Mode toolbar button.

  • Viewing basic statistical information

    In tables, you can display this information numerically by displaying - depending on the desired information - the Min, Max, Mean, Sdev, Cp, Cpk, P%, F%, or Dev% columns.

    To see the mean, two-sigma, or three-sigma points of a test graphically, display the test in a histogram and enable the corresponding lines in the chart properties or the chart's shortcut menu.

    To see the statistical distribution of values within a test, display it as a box chart.

  • Finding outlier test results

    To find outlier results graphically, display the test in a box chart and set the whiskers in the chart properties so that the outliers are outside the whisker range.

    For example, when you consider values in the top 10% and bottom 15% to be outliers, set the whiskers to 90% and 15%.

    The outliers are displayed as red dots in the chart.

  • Displaying the correlation of two independent test results

    To see how values measured in different test correlate with each other, display the two tests in a scatter chart.
