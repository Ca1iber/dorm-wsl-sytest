EVENT_CFIM.limitLow()

Sets the lower current limit to compare against threshold.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

EVENT_CFIM & limitLow (const EVENT_VALUE_DOUBLE & lowLimit);
Parameter
Parameter Description
lowLimit

The lower limit to be set in A (Ampere).

Return value

A reference to the corresponding EVENT_CFIM object.

Example

For an example see EVENT_CFIM.
