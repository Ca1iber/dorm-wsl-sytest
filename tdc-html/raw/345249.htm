rdi.alarm().pin().enable()

Enables or disables alarm checking on specified pins based on which alarm compare events are to be generated.

Syntax

rdi.alarm().pin(string alarmPins).enable(bool);
List of parameters
Parameter Description
alarmPins Specify a pin or pins for which alarm compare events are to be generated.
bool Specify whether to enable or disable alarm compare actions on the specified pins.
List of available options of parameter: bool
Option Description
true Enable alarm checking on the pins specified by alarmPins.
false Disable alarm checking on the pins specified by alarmPins.

This command can be put either inside or outside of an RDI_BEGIN()-RDI_END() block. When you put rdi.alarm().pin("pinA").enable(true) inside an RDI_BEGIN()-RDI_END() block, "pinA" must be one of the pins that have been initially applied for this RDI_BEGIN()-RDI_END() block.

The enabled pin will follow the global parameters in the current alarm set. You can also set local parameters for this pin.

The application scope of this command is the current test suite. The next test suite will use the default alarm limit settings again.

Functional changes

  1. Introduced in SmartRDI 7.5.0
