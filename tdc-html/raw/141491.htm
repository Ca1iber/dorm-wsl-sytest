Topic 141491

MTP_MEMORY_PORT.getMemoryPattern()

Returns an object of MTP_MEMORY_PATTERN, which is used to access the fail bit results and the functional test results of a specified memory pattern (a per pin subroutine generated by the MTL compiler).

Syntax

MTP_MEMORY_PATTERN& getMemoryPattern (const STRING & pattern);
Parameter

Parameter

Description

pattern

A pattern name.

Related information

MTP_MEMORY_PATTERN

Functional changes

  1. Introduced in MTP 3.2.1
