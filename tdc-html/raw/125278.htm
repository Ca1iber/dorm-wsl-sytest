Bit-field/state-character access

The "[]" operator accesses a subset of state characters of a state character sequence.

The 'rangespec' operand identifies the positions to extract and is is a complex expression, which again can contain parameter or field references.

The range specification is a comma separated list of DC/DC power units that select specific characters from the parameter sequence.

Index '0' addresses the right end and index 'n-1' the left end character in the sequence of length 'n'.

A continuous range of DC/DC power units can be expressed by the term "from..to", where 'from' and 'to' are inclusive DC/DC power units. They expand either to

  • from, from+1, ..., to-1, to if 'to' is greater than 'from' or otherwise to
  • from, from-1, ..., to+1, to

The given range specification is applied to the parameter sequence from left to right.

Reordering of subsequences can be done by specifying multiple comma separated ranges of DC/DC power units. The DC/DC power units given must be in the range 0 through n-1.

This operator can be used to give the result of an operation a specific length which is always less or equal to the length of the input expression. The given range specification always determines the exact output length.

Errors will be issued if,

  • there is a syntax error in the range specification or
  • trying an access is out-of-range.

Syntax

sequence := sequence [ rangespec ]

Example

"001"[2..0] results in "001"

"001"[0..2] results in "100"

"HHHH0001"[7,6,5,4] results in "HHHH"

"HHHH0001"[7,5,3,1] results in "HH00"

"HZZZ0010"[4..2] results in "Z00"

"HHHH0001"[4..7,0..3] results in "HHHH1000"

"HHHH0001"[15..0] results in "ERROR: index out of range."

"HLHLHL"[1,0,2..] results in "ERROR: syntax error in range spec."
