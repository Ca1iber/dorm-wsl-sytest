Retrieving Result from Vector Memory

To retrieve the captured digital data from the vector memory, use the VECTOR API and the getVectors member function. 

VECTOR(name).getVectors(size);

where, name is the vector variable, and size is the amount of digital data to be uploaded.

Example:

ARRAY_I Dig_Cap = VECTOR("Cap_A").getVectors(256);

For details, see VECTOR.
