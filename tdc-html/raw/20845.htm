How to handle STRING Data Type

This subsection describes the basics of handling the STRING data type.

The STRING data type behaves in the same manner as the string data type supported by the standard library of C++.

If you want to handle data of the STRING type as the normal char type, use the c_str() function to extract the value of that data type.

For details, see the example below.

STRING sPath;
GET_USER_STRING("Path", sPath);
printf("Path: %s\n", sPath.c_str());

The GET_USER_STRING API retrieves the current value of the user-defined variable "Path" and returns it to the parameter sPath. The c_str() function extracts the value of the STRING type data of sPath in the form of the char type. The printf function displays it.
