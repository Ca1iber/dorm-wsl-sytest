PPSG parameters

The parameters in the Per-Pin Signal Generator window let you specify a quasi-analog signal generated by the PPSG tool, as described in Generating a pattern with PPSG.

Digital Channel Settings parameters

  • Digital Channel Selection: The channels on the PS1600 have the following capabilities:

    Parameter

    PS1600

    Maximum frequency

    0.8 GHz

    Maximum bit rate

    1.6 GHz

    Minimum digital period

    5 ns

    X-mode

    8

    Vil

    -1.5 V

    Vih

    6.5 V

    Jitter

    6.5 ps
  • Signal Mode: Whether the created signal will be single-ended or differential.
  • Pin Name: The name of the pin for which the pattern will be generated. In the case of differential signals, this is the name of the positive pin.

    If you do not specify a name, the PPSG uses "PPSG_Pin".

  • Negative Pin Name: The name of the negative pin for a differential signal.

    For single-ended signals, this field is disabled.

    If you do not specify a name, the PPSG uses "PPSG_PinNeg".

  • Port Name: The name of the port to use. The port must include the specified pins.

    If you do not specify a port name, PPSG uses the port name "p<pin_name>" (where <pin_name> is the name of the pin used).

  • Waveform Name: The name of the generated waveform (optional).

    If you do not specify a waveform name, PPSG uses these names:

    • Ramp and triangle shapes: <wavetype>_<number_of_samples>_<sampling_frequency>_<filter_cutoff_frequency>

      <wavetype> can be either "Ramp" or "Triangles

    • Sine shapes: Sine_<signal_frequency>_<number_of_samples>_<sampling_frequency>_<filter_cutoff_frequency>

Filter parameters

  • Cut-Off Frequency: The cut-off frequency of the low-pass filter on the DUT board. Frequencies from 500 Hz to 100 MHz are supported.

    To change the unit (Hz, kHz, MHz), click the unit button until the desired unit is shown.

  • Order: The order of the low-pass filter. Filter orders from 1 to 10 are supported.
  • Series Resistance: The series resistance of the filter. Resistances from 1 Ω to 100 MΩ are supported.

    To change the unit (Ω, kΩ, MΩ), click the unit button until the desired unit is shown.

Signal parameters

  • Waveform Shape: The desired waveform shape for the generated signal: sine, ramp up, ramp down, or triangle.
  • Signal Frequency: The frequency of the generated sine signal. Frequencies from 1 Hz to 50 MHz are supported.

    To change the unit (Hz, kHz, MHz), click the unit button until the desired unit is shown.

    For ramp and triangle waveforms, this field is disabled. Instead, the frequency (with a range of 1 to 100 MHz) is calculated from other inputs:

    signal frequency = signal periods * sample rate / number of samples
  • Initial Phase: The initial phase of the generated sine signal. Phases from -180° to 180° are supported.

    For ramp and triangle waveforms, this field is disabled.

  • Signal Periods: The number of signal periods to generate. The minimum supported value is 1, the maximum depends on the shape:
    • Ramp: 1 <= signal periods <= (number of samples - 1) / 3
    • Triangle: 1 <= signal periods <= (number of samples - 1) / 6

      For sine waveforms, this field is disabled.

  • Min. Voltage: The minimum voltage for the generated analog signal. (See Max. Voltage, below, for supported values.)

    To change the unit (mV, V), click the unit button until the desired unit is shown.

  • Max. Voltage: The maximum voltage for the generated analog signal.

    To change the unit (mV, V), click the unit button until the desired unit is shown.

    The specified minimum and maximum voltages (Vmin and Vmax) must satisfy these equations:

    • Vilmin < (Vmax + Vmin - ((Vmax - Vmin) * factor / 0.95)) / 2
    • Vihmax > (Vmax + Vmin + ((Vmax - Vmin) * factor / 0.95)) / 2

      Where:

    • Vilmin is the minimum Vil supported by the card. (See the Digital Channel Selection parameter, above.)
    • Vihmax is the maximum Vih supported by the card. (See the Digital Channel Selection parameter, above.)
    • Factor is 1 + ((filter series resistance + 50) / input impedance * number of connected inputs)
  • Pre-Waveform Duration: The amount of time in the pattern before the generated signal begins. Durations from 0 ms to 100 ms are supported.
  • Post-Waveform Duration: The amount of time in the pattern after the generated signal ends. Durations from 0 ms to 100 ms are supported.

DUT parameters

  • Number of Connected Inputs: The number of devices connected to the specified pin. In particular in multisite testing, multiple devices may be connected to the same pin, increasing the load on that pin. Values from 1 to 32 are supported.
  • Input Impedance: The input impedance of the DUT input. Impedances from 50 Ω to 100 MΩ are supported.

    To change the unit (Ω, kΩ, MΩ), click the unit button until the desired unit is shown.

  • Number of Samples: The number of samples the A/D converter on the DUT board should take. Numbers from 2 to 1,048,576 samples are supported.
  • Sample Rate: The sample rate of the A/D converter on the DUT board. Frequencies from 100 sps (sps - samples per seconds) to 100 Msps are supported.

    To change the unit (sps, ksps, Msps), click the unit button until the desired unit is shown.

  • Noise-Reduced Bandwidth: The width of the frequency band in which the noise is reduced (by shifting it out of the band); usually the input bandwidth of the A/D converter of the DUT. The width must be at least 10 Hz.

    The default value for this field is automatically generated and updates as you change entries in the relevant source fields. However, after you manually enter a value in this field, it is no longer automatically updated. (To resume automatic updates, delete the content of this field.)
