FFPM? (First Failing cycle information Pin Mapping)

The FFPM? query retrieves information on the order of the pins of a FFCI? query.

Syntax

FFPM? [port]

returns:

FFPM {no_pins}, {Pinlist}

Parameters

port Specifies the port for the pins for which information is to be returned. If you omit this parameter information will be returned for the default port @ to which all configured pins belong.
no_pins The number of pins, which belong to the specified port.
PinList

List of pin names, corresponding to the order in the FFCI pin result block (from MSB of first byte to LSB in the last byte).

For more information, refer to the FFCI parameter description for #spec(data).

Application

Error Map

Example

The pogo numbers of the following example setup are assigned in descending order to emphasize that the order of the pogo numbers and not the order of the definition by DFPN matters.

DFPN 11105,"",(pinA)
DFPN 11104,"",(pinB)
DFPN 11103,"",(pinC)
DFPN 11102,"",(pinD)
DFPN 11101,"",(pinE)
CONF IO,F160,(pinA)
CONF I,F160,(pinB,pinC)
CONF O,F160,(pinD,pinE)

The FFCI? command will sort I / IO pins based on their pogo number defined for the first site resulting in the pin list pinE, pinD, pinA. The two pins pinB and pinC have no output capability and, therefore, will not be included in the FFCI? answer.

Assuming a test has been executed where pinA passes, but pinD and pinE fail for every cycle, the FFCI? answer for the first two failing cycles now would look like this:

FFCI? 2
FFCI 2,3,#218
  00000000 00000000 00000000 00000000 00000000 00000000 00000000 00000000
  11000000 00000000 00000000 00000000 00000000 00000000 00000000 00000000
  00000001 11000000
The binary data of the answer is to be interpreted as follows:
  • Byte 1 … 8: Address of the first cycle (00000000 … 00000000 = 0)
  • Byte 9: Pin data 11000000
  • Byte 10 … 17: Address of the second cycle (00000000 … 00000001 = 1)
  • Byte 18: Pin data 11000000

Byte 9 and 18 show that the first two pins on the left side (MSB) are failing. According to the sorting scheme that is defined in the FFCI parameter description for #spec(data), the failed pins are pinE (Channel 11101 and pinD (Channel 11102).

For the configuration defined above, the FFPM? command will return the following data:
FFPM 3,(pinE,pinD,pinA)
