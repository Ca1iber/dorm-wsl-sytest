Topic 118401

Generating and checking pseudo random bit sequences

Every PS9G or PS1600 channel contains a Fibonacci LFSR (see also Instructions for PRBS and SmartLoop tests). This LFSR can be used on the input side to create a drive PRBS per pin. On the output side, it can create an expected PRBS which is then compared to the received data stream. In both cases, the user must specify the connection polynomial. In order to generate an input PRBS, he must also define the seed. The seed for the expected PRBS, on the other hand, is always sampled from the received data. This is possible for the following reason:

If the received data actually corresponds to an expected PRBS whose connection polynomial has degree m, then any segment of the output data with length m can be used, in reversed order, as the seed to create this PRBS. This follows from the relation between internal states and output sequence in a Fibonacci LFSR, as indicated in Overview of pseudo random bit sequences. Therefore, if the nth output bit is the first sampled bit, the output data starting from bit n will match the PRBS that is created from the sample.

The LFSR on the PSG9 channels can be used in three scenarios:

  • Both input PRBS and expected output PRBS are generated by SmarTest.
  • The input PRBS is generated by the DUT, and the expected output PRBS by SmarTest.
  • The input PRBS is generated by SmarTest, and the expected output PRBS by the DUT.

In the last two cases, the DUT must be initialized appropriately for both LFSR types.

The connection polynomial and the seed (for the input PRBS) are defined in a PRBS set (with PRDF and PRCF). In order that a PRBS set be used, it must be made the primary PRBS set with PRPR.

You can combine a PRBS check with transition tracking. For details see Combining transition tracking with a PRBS or pattern‑based SmartLoop test.

The PRBS test is started with the sequencer instruction PRBS. If no primary PRBS set has been defined, a default polynomial and a default seed are used (for details see the PRCF command).

The PRBS per pin is activated by the SmartLoop™ license (loopback keyword in the IOCHANNEL section of the model file).

Observe the following restrictions:

  • You cannot combine PRBS pins and normal digital pins in one port. If you want to execute a normal digital test in parallel with a PRBS test, you must put the PRBS pins and the digital pins into different ports.
  • Match loops cannot be executed in a port that belongs to the same sequencing group as a PRBS port.
  • No detailed error information is available for a PRBS test. If the test fails, you can only retrieve the number of errors (with the ERCT? query).
  • The sequencer termination modes SE and SEEL cannot be used for a PRBS test.
