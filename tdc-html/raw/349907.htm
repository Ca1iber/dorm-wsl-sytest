Topic 349907

Local license server installation for bare-metal RHEL7 SmarTest system controllers

SmarTest licenses are managed by a license server, which can be installed locally on the SmarTest system controller workstation.

About this task

There are two possible arrangements for the local license server installation:

  • The SmarTest client only accesses the local license server.
  • The SmarTest client accesses both the local license server and other license servers to get all licenses.

An important part of this process involves your identification of a computer that can function effectively as a license server. For an overview of considerations that may affect your choice of a license server that fits your specific test setup, refer to FLEXlm Floating License Server Selection Guide in the LTH/STH Site Planning and Preparation Guide.

Before you begin

A license server can be installed and configured directly (bare-metal) on the following types of system controller workstations:

  • Z4G4 workstations running a supported RHEL 7.x operating system.

The supported SmarTest versions and system controllers are detailed in the topic: SmarTest Prerequisites.

Procedure

  1. Install the license server software on the workstationas described in Create a SmarTest license server.
  2. Configure the license servers to be used: either the local license server only or both the local license and central license servers.

    • Using local license server only:

      1. Place the license file in the /opt/flexlm/license directory. (If the license directory does not exist, create it).
      2. From the directory /opt/flexlm/license, open the license file for editing.
      3. Without changing any other content in the license file, in the first line: SERVER this_host, replace this_host with the hostname of the workstation.

    • Using local and central license servers:

      1. Create the directory /opt/flexlm/local_license.
      2. Place the local license file (with the INCREMENT lines) in the /opt/flexlm/local_license directory.
      3. Place the pointer files to the central license servers in the directory: /opt/flexlm/license.
      4. Also in the /opt/flexlm/license directory, create a pointer file to the local license server with the following content: 
        SERVER this_host <host ID>
VENDOR socbu
USE_SERVER
        Note Do NOT include INCREMENT LINES, but include the USE_SERVER line.

        The /opt/flexlm/license directory is used by SmarTest to check which license servers to contact. Therefore, only pointer files are needed.

        The /opt/flexlm/local_license directory is used by the local license server to read the actual license file with INCREMENT lines to know which licenses to serve.

  3. Start the license server: log in as root user and enter the command appropriate for your operating system:

    RHEL7: systemctl start v93-license

  4. Check if the local license server is running:

    /opt/flexlm/bin/lmutil lmstat -a -c /opt/flexlm/license

    A message stating that the license server is UP confirms that the license server is running. If the license server is not running start it. For details see SmarTest License server basic operations.

  5. Start SmarTest and check if the license checkout is working.

Results

You have installed and configured a license server locally on your SmarTest system controller.
