DUT Representation Language

Subtopics

  2. Variables
  3. Operators
  4. Assignments
  5. Initialization functions
  6. Comments

The DUT Representation Language (DRL) is a simple description for describing DUTs.

DRL consists mainly of reserved system variables and system functions. Writing a DUT representation mostly consists of making the correct assignments for both.

When you write a DUT representation, we recommend that you take an existing description and use it as a template on which to base your new representation.

Language elements

The language has a range of elements:

  • Values
  • Variables
  • Operators
  • Assignments, including loop-like formular assignments
  • Initialization functions
  • Comments

Other programming language features - such as data types, subroutines, or conditional execution (if) - are not supported.

All statements in DRL files must be separated by semicolons (;).
