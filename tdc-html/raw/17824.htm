Topic 17824

Dropping Unused Edges

Any edge you do not wish to use can be moved back into the unused edge box (position at 0 ns). To drop an edge in this box, click and drag it back into the box with the mouse.

You can only drop an edge back in the unused edge box if it is not used in any device cycle generated for a particular pin.

Note If an edge refuses to return back into the box, it is being used in some device cycle that may currently not be displayed. Change to one pin mode to see all device cycles for a pin. Refer to Displaying Device Cycles Generated for One Pin.
