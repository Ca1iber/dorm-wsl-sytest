Defining a Workorder for the Test Program

The test program must be started in supervisor mode. If you start it in engineering mode, for example, from the testflow editor, execution will be slowed down by background processes, for example, of the pattern debug tool.

Therefore, you must create a workorder for the test program, as follows:

  1. Edit the /opt/hp93000/soc/prod_env/org file so that it points to your device directory.
  2. Switch to supervisor mode by clicking Supervise in the Operation Control window.
  3. Select Workorder Manager in the Supervising window.
  4. Click New in the Workorder Manager window.
  5. Select the appropriate device, and then the test program defined for the measurement.
  6. Click Continue.
  7. Click Save as.
  8. Specify a name for the new workorder.
    Note When naming work orders for usage with the operator console: Make sure that the work order name consists of numbers only. Do not use other characters like alphabetical or symbol.
  9. Click OK.

Functional changes

  1. Introduced before SmarTest 6.3.2
