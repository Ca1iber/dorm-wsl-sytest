Flags and data logging profiles

Data logging profiles contain definitions of how system flags, testflow flags and user flags are set.

When a data logging profile is loaded, some flags are set immediately and some are not set until test execution.

Flags with rules related to any of the following context selectors are not set until test execution begins:

  • Group
  • Test method
  • Test name, number or bin

When a data logging profile has been loaded, the flag definitions it contains have the highest priority. You can change flags by hand using the flag user interfaces, but when the test is executed all flags will be overwritten with the values from the data logging profile. To prevent this overwriting of your manually set flags, unload the profile as described in Unloading a data logging profile.

When you load a data logging profile and subsequently change some of the flags using the flag user interfaces, the testflow will be marked as changed in the test program explorer. (An asterisk * is displayed besides the file name.) If you then save the testflow, both the flags defined in the data logging profile and the manually set flags are saved with the testflow.
