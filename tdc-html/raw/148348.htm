Topic 148348

Viewing the data log report

This task introduces how to view the generated data log report.

About this task

After executing the report generation process, you can view and save the HTML report in the TP360 report view. You can also use firefox to open the report from the directory you saved report to. The default directory is:

/tmp/.vda/username/datalog_utilities/tmp/TP360_Datalog_Report/

Procedure

  1. View the home page of the data log report.
  2. In the home page above, click details to view the Test Result Summary.

    The test suite name, test name, test number, execution times, fail times, limits, min, max, mean, yield, std dev, cp, cpk are shown in the summary.

  3. In the Test Result Summary page, click Global info to view the global information of the data log file.
  4. In the Test Result Summary page, click Test Detailed Report to view the test result of each device, each site.
  5. In the Test Result Summary page, click Wafer Map to view the hard bin wafer map and the corresponding fail bin distribution.

    You can click the link Soft Bin Wafer Map to view the software bin part:

  6. In the Test Result Summary page, click Bin Histogram to view the hardware bin histogram of the whole data log file.

    You can click the Soft Bin Histogram link to view the software bin part:

  7. In the Test Result Summary page, click Bin Summary or Failure Summary to view the detailed bin distribution information.
  8. If there is shmoo data in the selected data log file, a link named Shmoo info is available in the Test Result Summary page. You can click Shmoo info to view the shmoo analysis report.
    Note Shmoo data is only available in EDL with latest SmarTest shmoo test method library. To support shmoo hole information, you need to install the rpm zenith_opencv_2.4.5, which is usually installed before installing Smartest version 7.2.0.0 or above.
