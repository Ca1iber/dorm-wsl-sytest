Topic 93911

Parameters for the DataTrainingFlex test method

When you have selected the test method you can enter the parameters (see figure below).

Note The test method performs spec searches on input and output pins. Result pins are output pins.

The tables explain the parameters.

Test method parameters

Name

Comment

TrainingAlgorithm

SpecTraining or EmbeddedTraining

SpecTraining performs the search for the on the test controller workstation as a parallel spec search.

EmbeddedTraining performs the search in the test processor on the test head card.

OutputPinGroups

Pin group. List of output pin groups, separated by a semicolon.

Example:

4 groups: RDQS0o, DQ0o, DQ1o; RDQS1o, DQ15o; RDQS2o, DQ_Bus2;ssgroup3

The sequence of the pins must match the sequence of the sweep variables.

OutputSweepSpecVars

The timing specification variables that are to be used for sweeping the specified pins or pin groups, separated by semicolons. Variable names can be identical for different pin groups. The number of pin groups and the number of timing specification variables need to be the same. The sequence of the specification variables must match the sequence of the pins in the SourceSyncPinGroups field.

Syntax:

For single-port testing:

{spec_name_0}; {spec_name_1}; ...; {spec_name_n-1}

spec_name_0, spec_name_1, ... , spec_name_n-1 are names of specification variables.

For multi-port testing:

{spec_name_0@port_0}; {spec_name_1@port_1}; ...; {spec_name_n-1@port_n-1}

InputPinGroups

Pin group. List of input pin groups, separated by a semicolon.

InputSweepSpecVars

Define timing specification variables for each pin group, separated by semicolon. Name can be identical for different pin groups. The number of pin groups and the number of timing specification variables need to be the same, or, if names for all pin groups are identical, only one name, otherwise the Test Method aborts with an error.

Syntax:

For single-port:

{ispec_name_0}; {ispec_name_1}; ...; {ispec_name_n-1}

For multi-port:

{ispec_name_0@port_0}; {ispec_name_1@port_1}; ...; {ispec_name_n-1@port_n-1}

FirstSweepStart

Number. Sweep start value used for first training.

FirstSweepStop

Number. Sweep stop value used for first training.

SecondSweepStart

Number. Sweep start value used for second training.

SecondSweepStop

Number. Sweep stop value used for second training.

MinOpenEye

Number. Time in nanoseconds. Step size of the linear search. Must be considerably smaller than minimum eye open time.

AlignAccuracy

Number. Time in nanoseconds. Resolution of binary search (ending criteria of search).

FirstDataTraining

Output_Output or Input_Output. The former selects first training as device output training.

Input_Output selects the first training as an device input training.

SecondDataTraining

Off or On. If On, there is a second training. First and second training are always complements: If first training is output, then second training is input training. And vice versa.

PrintEye

Yes or No. Yes directs output to the report window.

EdgeCentering

Yes or No. If Yes, the edge center timing data in the sweep spec variable is used for further measurements in the later test suite.

To translate the measured parameter into a pass/fail result, use the result parameter field.

Result parameters

Name

Comment

OpenEyeLimit

Number. Specify the upper and lower limit for the eye width. If the eye width is within this range, the test passes. Otherwise the test fails.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. MTP 3.0.1: New parameter TrainingAlgorithm
  3. MTP 3.0.1: The test method is now configured in a window instead of a dialog.
