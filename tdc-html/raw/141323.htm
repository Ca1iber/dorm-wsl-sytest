EVENT_ICVM (Current Clamp / Voltage Measurement Event) is a combined clamp/measure event class. These classes provide the combined functionality of clamp setting and measurement events in a single event.

You can define combined clamp current setting / voltage measure events with all specific functions of EVENT_IC and EVENT_VM, except for the EVENT_VM functions iClampChecks() and getIClampChecks().

Class definition

The class derives from the EVENT_BASE class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

EVENT_ICVM ( const STRING &id );

Example

The example sets high clamp current value to 300 mA and the number of samples to average to 2.

PATTERN_CONTROLLER cleanUpPattern;
PATTERN_CONTROLLER pc;

EVENT_ICVM iClampVoltMeas("iClampVMeas");

ON_FIRST_INVOCATION_BEGIN();

    cleanUpPattern.label("patEvents", "@")
                  .vecEvents("dps1")
                  .clearAll()
                  .setup();
  
    iClampVoltMeas.averages(2).iClampHigh(300 mA);

    // insert events into pattern
    PATTERN & pattern(pc.label("patEvents", "@"));
    pattern.vecEvents("dps1").insert(128, iClampVoltMeas)

    pc.setup();

ON_FIRST_INVOCATION_END();
