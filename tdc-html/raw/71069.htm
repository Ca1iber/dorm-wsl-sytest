Topic 71069

Logging user text to PTR records with test methods

To log data using test methods to the TEST_TXT field in the Parametric Test Record (PTR) the appropriate calls to the test methods must be made.

The user text can be viewed with the Detail data views of the Result perspective.

For details, see the TESTSET API.

Functional changes

  1. Introduced before SmarTest 6.3.2
