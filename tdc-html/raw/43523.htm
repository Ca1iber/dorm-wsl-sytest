Starting SmarTest with engineer mode

With engineer status you have all the possibilities of creating, allocating and executing workorders. In addition, you can access testflow and production settings (see Modifying Testflow Execution and Data Logging for further details).

To start SmarTest in engineer status enter:

HPSmarTest -E or,

HPSmarTest -Eo if you are running the software offline (that is, the tester is not connected).

The screen shown below appears.

In order to change the user mode of SmarTest, click the button engineering in the Operation control window (figure above), and chose the new desired mode.

In order to exit SmarTest, click Quit in the Operation control window.
