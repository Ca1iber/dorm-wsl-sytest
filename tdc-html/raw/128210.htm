DCEL, DCEL? - (Digital Compare Exception List)

The DCEL command serves to circumvent recording problems that can arise if the detailed error map of a port is located in the external memory, and most or all pins of the port belong to the same 4-channel or 8-channel group. If you are only interested in the result data of some of the port pins, you can override the DCRT setting for the remaining pins and direct the results of these into the internal error map with DCEL. For more information on recording problems with respect to the extenal error map see Dealing with storage problems on Smart Scale systems.

DCEL? returns the pins that have their result data stored in the internal error map regardless of the settings defined with DCRT.

With this command you configure setups of those sites that have the setup focus: For more information, see also: PSFC, PSFC?.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Operation mode

The location of the detailed error map is defined with DCRT on the port level. In contrast, DCEL operates on the pin level. It creates and manages a list of pins whose detailed error map is to be located within the test processor regardless of the location defined with DCRT. The exception list defined with DCEL overrides the DCRT definitions on all ports containing the pins in question: If a pin belongs to two different ports, and its error map is located in the external memory on both ports, DCEL will always override the DCRT settings on both ports. It is not possible to change the location selectively for only one of these ports.

DCEL

DCEL {DCRT}, {TP}, {action}, {(pinlist)}

DCEL? 

DCEL? {DCRT}, {parameter}, {(pinlist)}

returns:

DCEL? {DCRT}, {parameter}, {action}, {(pinlist)}

Parameters

DCRT The command for which an exception list is to be created. Currently, DCRT is the only allowed command.
TP The option of the command specified in the first parameter. Currently TP is the only allowed value.
parameter This query parameter can be TP or ALL.
action This can be one of the following:
SET Add the specified pins to the exception list related to the command in the first parameter.
DEL Delete the specified pins from the exception list related to the command in the first parameter.
pinlist In the command, these are the pins that are to be added to or deleted from the exception list. In the query, DCEL? returns the subset of the specified pins that is included in the exception list. Instead of a pin list, you can also specify one or more pin groups.

Application

Test results.

Example

> DCRT RAM,(portA)
> DFPT? (portA)
< DFPT (p1,p2,p3),(portA)
> DCEL DCRT,TP,(p2)
> DCEL? DCRT,TP,(portA)
< DCEL DCRT,TP,SET,(p2)
> DCEL DCRT,TP,(p1,p3)
> DCEL? DCRT,TP,(portA)
< DCEL DCRT,TP,SET,(p1,p2,p3)
> DCRT? (portA)
< DCRT RAM,(portA)

Note that you can add further pins to the exception list, and that the settings of DCRT are not changed even if all three pins of portA are in the exception list.

Functional changes

  1. Introduced in SmarTest 7.1.2
