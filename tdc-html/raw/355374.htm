EVENT_FILTER.setLoadStepValue()

Sets the load step mode for the DC Scale XPS256 card.

Syntax

EVENT_FILTER & setLoadStepValue(TM::LOADSTEP_VALUE value);
Parameter
List of parameters
Parameter Description
value

The load step mode value. Valid enums are TM::STANDARD (normal load step response) and TM::FAST (fast load step response).
Return value
A reference to the corresponding EVENT_FILTER object.

Related information

EVENT_FILTER.getLoadStepValue()
XPS256 load step response

Functional changes

  1. Introduced in SmarTest 7.10.3
