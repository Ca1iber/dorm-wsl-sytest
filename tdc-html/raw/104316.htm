Topic 104316

Setting up DC event sequences

DC event sequences allow you to execute a sequence of DC events with a single call.

About this task

DC event sequences are only available for DC Scale events, not for PMU events.

Before you begin

Set up the DC event file and the events you want to include in the sequence as described in Setting up a DC event.

Procedure

  1. Open the DC event file to which you want to add the sequence.
  2. Add the sequence to the desired :dcSet:. The syntax of DC sequences is described in DC event file syntax.

    Note that only sequences within the DC set that is currently specified via the :dcTest: keyword in the APG pattern file can be accessed from the program file.

    Note, too, that none of the DC events in the sequence must have the pmu type.

  3. Specify the desired event sequence in the DC set.

    Give the sequence a name, specify its parameters and its length. Then list the DC events that you want to include and provide the time when each is to occur as its offset.

    Note that you can use only events from the sequence's DC set.

    See DC event file syntax for more information.

  4. Save the DC event file.
  5. Reference the DC event file and DC set from the APG pattern file using the :dcTest: keyword.
  6. In the appropriate locations in the program code, insert the DC_EVENT_RANGE function, providing the name of the sequence and the required sequence parameters as its parameter.
  7. If you want to execute the sequence only a limited number of times, irrespective of how long the associated instructions take to execute, specify the maximum number of times that the sequence is to be executed in the maxRepeats() function property.
  8. If the DC sequence is to start executing later than the associated program instructions, specify the offset in the initialDelay() function property.
  9. Enclose the sequence of program statements that are to be executed in parallel to the DC sequence in the curly braces of the DC_EVENT_RANGE function. (Similar to an if or a for statement.)
  10. After the closing brace of DC_EVENT_RANGE, insert a DC_EVENT statement that sets the desired voltage for the following code.
    Note This last step may not always be strictly necessary. However, we strongly recommend it because the DC sequence may not always execute completely in its last iteration. This means that, after the sequence finishes, the voltage can remain at any level specified by one of the events in the sequence - essentially, the level is undefined. This can be remedied by explicitly setting the level using DC_EVENT immediately after the sequence.
    Note If the border between one execution of a DC event range falls within a for loop, this may result in (possibly greatly) increased compilation times and increased sizes of the compiled patterns.

Results

The DC sequence is executed alongside the specified code when the compiled program is executed.
