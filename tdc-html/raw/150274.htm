The EVENT_VCIM (Voltage Clamp / Current Measurement) is a combined clamp voltage / current measure event class. This class provides the combined functionality of setting and measurement events in a single event.

This class is supported only for the DC Scale XPS256 card in PMU operating mode.

Class definition

The class derives from the EVENT_BASE class.

The object that is created by this class has to be assigned to the PATTERN_CONTROLLER which is responsible for further handling.

This class is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Constructor
EVENT_VCIM (const STRING & id);
EVENT_VCIM (INT id);

The constructor creates an object of the type EVENT_VCIM and assigns the given identifier to the object.

Parameter Description
id

Identifier of the event.

The identifier may be defined as integer value or as string.
Return value
The constructor has no return value.

Automatic down-ranging

DPS128 and XPS256 support automatic down-ranging current measurements.

Automatic down-ranging means that the current range is automatically changed to the best fit range for the measurement and restored to the original range after the measurement.

Two parameters define whether the automatic down-ranging is performed or not:
  • The force current or clamp current range:
    • Can be set explicitly or (if not defined)
    • is automatically derived from the forced or clamped value.
  • The current measurement range:
    • Can be set explicitly or (if not defined)
    • is automatically derived from the pass/fail thresholds.
Automatic down-ranging is performed only if the current measurement range is lower than the force / clamp current range regardless whether the ranges have been set explicitly or have been selected automatically.
For more information, refer to
  • DPS128 / DPS64 specific setup tasks and DC Scale DPS128/64 HC/HV Cookbook - Section 4.2.1
  • XPS256 measure currents and XPS256 programming - Measure currents
  • DPS_AUX_PIN_TASK.checkSetRangeError() and DPS_AUX_TASK.getRangeError()

Example

The following example creates three new DC events, sets the data of the DC events and inserts the DC events into an already existing pattern. The programmed data are then read back from the event objects and shown in the console window:

  • event_VCIM_1 uses member functions limitLow() and limitHigh() to define the limits. The lower clamp value is set by this DC event.

  • event_VCIM_2 uses the class LIMIT and the member function limits() to define the limits. The upper clamp value is set by this DC event.

  • event_VCIM_3 uses member functions limitLow() and limitHigh() to define the limits but the limits are cleared by member function clearLimits() to demonstrate how this function works. The lower clamp value is set by this DC event.

PATTERN_CONTROLLER patController;

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Create new event objects
    //
    EVENT_VCIM event_VCIM_1 ("VCIM_1");
    EVENT_VCIM event_VCIM_2 ("VCIM_2");
    EVENT_VCIM event_VCIM_3 ("VCIM_3");

    //
    // Set the event data
    //
    event_VCIM_1
        .vClampLow          (-5.0 V)    // vClampLow() OR vClampHigh()
        .averages           (50)
        .outOfRangeCheck    (true)
        .limitLow           (15.0 mA)
        .limitHigh          (20.0 mA);

    LIMIT event_VCIM_2_limits;

    event_VCIM_2_limits.low     (TM::GE, 17.0 mA);
    event_VCIM_2_limits.high    (TM::LE, 22.0 mA);
    event_VCIM_2_limits.unit    ("mA;-3;mA;-3");

    event_VCIM_2
        .vClampHigh         (22.0 V)    // vClampLow() OR vClampHigh()
        .averages           (50)
        .outOfRangeCheck    (true)
        .limits             (event_VCIM_2_limits);

    event_VCIM_3
        .vClampLow          (-2.0 V)    // vClampLow() OR vClampHigh()
        .limitLow           (15.0 mA)   // Cleared with clearLimits()
        .limitHigh          (20.0 mA)   // Cleared with clearLimits()
        .clearLimits        ();

    //
    // Insert the events into a pattern
    //
    PATTERN & pattern = patController.label("...", "@");

    pattern.vecEvents("pin1").clearAll();

    pattern.vecEvents("pin1")
        .insert(100, event_VCIM_1)
        .insert(150, event_VCIM_2)
        .insert(200, event_VCIM_3)
        .setup ();

    //
    // Read data from the event object event_VCIM_1
    //
    EVENT_VALUE_DOUBLE  lowerClamp_1, upperClamp_1, lowLimit_1, highLimit_1;
    EVENT_VALUE_INT     averages_1;
    bool                lowLimitDefined_1, highLimitDefined_1, outOfRangeCheck_1;

    event_VCIM_1.getVClampLow       (lowerClamp_1);
    event_VCIM_1.getVClampHigh      (upperClamp_1);
    event_VCIM_1.getAverages        (averages_1);
    event_VCIM_1.getOutOfRangeCheck (outOfRangeCheck_1);

    lowLimitDefined_1  = event_VCIM_1.getLimitLow   (lowLimit_1);
    highLimitDefined_1 = event_VCIM_1.getLimitHigh  (highLimit_1);

    cout << "lowerClamp_1          = " << lowerClamp_1                                      << endl;
    cout << "upperClamp_1          = " << upperClamp_1                                      << endl;
    cout << "averages_1            = " << averages_1                                        << endl;
    cout << "outOfRangeCheck_1     = " << outOfRangeCheck_1                                 << endl;
    cout << "lowLimit_1  (defined) = " << lowLimit_1  << " (" << lowLimitDefined_1  << ")"  << endl;
    cout << "highLimit_1 (defined) = " << highLimit_1 << " (" << highLimitDefined_1 << ")"  << endl;
    cout << endl;

    //
    // Read data from the event object event_VCIM_2
    //
    EVENT_VALUE_DOUBLE  lowerClamp_2, upperClamp_2, lowLimit_2, highLimit_2;
    bool                lowLimitDefined_2, highLimitDefined_2;

    event_VCIM_2.getVClampLow   (lowerClamp_2);
    event_VCIM_2.getVClampHigh  (upperClamp_2);

    lowLimitDefined_2  = event_VCIM_2.getLimitLow   (lowLimit_2);
    highLimitDefined_2 = event_VCIM_2.getLimitHigh  (highLimit_2);

    cout << "lowerClamp_2          = " << lowerClamp_2                                      << endl;
    cout << "upperClamp_2          = " << upperClamp_2                                      << endl;
    cout << "lowLimit_2  (defined) = " << lowLimit_2  << " (" << lowLimitDefined_2  << ")"  << endl;
    cout << "highLimit_2 (defined) = " << highLimit_2 << " (" << highLimitDefined_2 << ")"  << endl;
    cout << endl;

    //
    // Read data from the event object event_VCIM_3
    //
    EVENT_VALUE_DOUBLE  lowerClamp_3, upperClamp_3, lowLimit_3, highLimit_3;
    bool                lowLimitDefined_3, highLimitDefined_3;

    event_VCIM_3.getVClampLow   (lowerClamp_3);
    event_VCIM_3.getVClampHigh  (upperClamp_3);

    lowLimitDefined_3  = event_VCIM_3.getLimitLow   (lowLimit_3);
    highLimitDefined_3 = event_VCIM_3.getLimitHigh  (highLimit_3);

    cout << "lowerClamp_3          = " << lowerClamp_3                                      << endl;
    cout << "upperClamp_3          = " << upperClamp_3                                      << endl;
    cout << "lowLimit_3  (defined) = " << lowLimit_3  << " (" << lowLimitDefined_3  << ")"  << endl;
    cout << "highLimit_3 (defined) = " << highLimit_3 << " (" << highLimitDefined_3 << ")"  << endl;
}
ON_FIRST_INVOCATION_END();
