Topic 152329

iMeasRange()

Specifies a current measurement range for DC SPMU.

This function can be used in the code‑based mode only.
Note To set a measurement range for SPMU, use clamp() instead.

Syntax

iMeasRange(double dIMeasRange);
List of parameters

Parameter

Description

dIMeasRange

The range of current to be measured.

Return value

There is no return value.

Example

rdi.dc("id").pin("pin2",TA::SPMU).vForce(0).iMeas().iMeasRange(1 mA).execute();

Related information

clamp()

Functional changes

  1. Introduced in SmartRDI 2.4.3
