Topic 96520

PACKAGE_STARTED

This asynchronous event indicates the test for a packaged device is started in the test program execution. It is only available for final test.

Dependency and constraints

  • The test program is in execution.
  • If the application model does not use the standard prober/handler driver function call (ph_device_start) or the equivalent, this event may not be generated. The variable naming for lot ID should be ph_LOT_ID or LOT_ID.
Parameters

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session this event belongs to.

O

TIME_STAMP

The time point when this event occurs. It contains two long-type parts: SECONDS and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always EXECUTION.

O

EVENT_BODY

The event parameters. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always PACKAGE_STARTED.

LOT_ID

The current lot ID.

SITE_ID_FOR_SITES

The list of site IDs.

SITE_SETUP_FOR_SITES

The list of site setups.

PACKAGE_ID_FOR_SITES

The list of package IDs. Package ID is only a counting for device test. "-1" is used for empty sites.

This parameter is represented by ParamList whose key and value are both string type.
