Nested match loops

Match loops can be nested.

To program a nested match loop:

  • Use the MACT instruction to start each match loop, specifying the maximum number of unsuccessful repetitions.
  • End each match loop with LOOPEND instruction.
  • For each match loop, enter the MRPT instruction, specifying the number of vectors (number of dummy vectors to be repeated in the wait loop).
  • End each MRPT instruction with the REPEATEND instruction after the number of specified vectors.

Example of instructions and vectors for a nested match loop:

MACT 10     # Outer match loop start
            # Vector value 
            # Vector value
            # Vector value ...
MACT 20     # Inner match loop start
            # Vector value 
            # Vector value 
            # Vector value ...
MPRT 8      # Inner match repeat start block
            # Dummy vector value 
            # Dummy vector value
            # Dummy vector value 
            # Dummy vector value
            # Dummy vector value 
            # Dummy vector value
            # Dummy vector value 
            # Dummy vector value
REPEATEND    
MRPT 8      # Outer match repeat start block
            # Dummy vector value 
            # Dummy vector value
            # Dummy vector value 
            # Dummy vector value
            # Dummy vector value 
            # Dummy vector value
            # Dummy vector value 
            # Dummy vector value
REPEATEND

For information about specifying match loops, see Inserting counted match loops.

Nesting is limited to seven nested levels.

Functional changes

  1. Introduced in SmarTest 7.5.1
