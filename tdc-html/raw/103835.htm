Topic 103835

IssueEDLEvent()

This API generates the EDL (event data log) events for the specified SmarTest session. The execution of this API will result in an EDL event created and appended to the system EDL data stream.

This API currently supports the following EDL event type:

TestProgramStartEventType

TestProgramEndEventType

AppModelLevelStartEventType

AppModelLevelEndEventType

AppModelLevelLoopEventType

AssignmentEventType

SUCCESS will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

PARAMETER_EXCEPTION
  • The value of the parameter "EVENT_TYPE" is empty.
  • The value of the parameter "EVENT_TYPE" can only be "AppModelLevelStartEventType", "AppModelLevelEndEventType", "AppModelLevelLoopEventType", "AssignmentEventType", "TestProgramStartEvent" and "TestProgramEndEvent".
  • The value of the parameter "LEVEL_TYPE" can only be "CUSTOM_LEVEL", "WAFER_LEVEL" and "DEVICE_LEVEL".
  • The value of the parameter "LEVEL_TYPE" or "LEVEL_NAME" is empty.
  • The value of the parameter "VARIABLE_NAME" or "VARIABLE_VALUE" is empty.
  • The value of the parameter "TESTPROGRAM_NAME" is empty.

RECOVERABLE

ILLEGAL_OPERATION

The designated session ID "XXX" does not exist.

RECOVERABLE
Parameter

I/O

Parameter

Description

I

SESSION_ID

The ID of the SmarTest session to work with.

I

EVENT_TYPE

The EDL event type.

I

INPUT_PARAMETER

The input parameters corresponding to the certain EDL event type. For details, see the table below.

EDL event type

Input parameters

TestProgramStartEventType

TESTPROGRAM_NAME: The HVMAPI client executable name.

TestProgramEndEventType

N/A

AppModelLevelStartEventType

LEVEL_TYPE: The level type. It can be CUSTOM_LEVEL, WAFER_LEVEL or DEVICE_LEVEL.

LEVEL_NAME: The level name

AppModelLevelEndEventType

AppModelLevelLoopEventType

AssignmentEventType

VARIABLE_NAME: the variable name

VARIABLE_VALUE: the variable value

Prototype

ParamList inParams;
Status syncCommand("IssueEDLEvent", inParams, sessionId);

Example

string sid;
ParamList inParams;
inParams ["EVENT_TYPE"] = "AppModelLevelStartEventType";
inParams ["LEVEL_TYPE"]  = "CUSTOM_LEVEL";
inParams ["LEVEL_NAME"] = "lot";
syncCommand ("IssueEDLEvent", inParams, sid);

Functional changes

  1. Introduced in SmarTest 6.5.0
