EVENT_CFIM.getLimitHigh()

Reads the upper limit that has been defined by EVENT_CFIM.limits() or EVENT_CFIM.limitHigh().

The value is read from the corresponding EVENT_CFIM object and returned as an EVENT_VALUE_DOUBLE object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

bool getLimitHigh(EVENT_VALUE_DOUBLE & highLimit) const;
Parameter
Parameter Description
highLimit

The programmed upper limit in A (Ampere).

Return value

bool value indicating the state of the limit definition:

  • true: Limit has been defined by EVENT_CFIM.limits() or EVENT_CFIM.limitHigh().
  • false: No limit is defined or the limit has been cleared by EVENT_CFIM.clearLimits().

Example

For an example see EVENT_CFIM.
