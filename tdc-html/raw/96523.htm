DIE_COMPLETED

This asynchronous event indicates the test for a die is completed in the test program execution. It is only available for wafer sort.

Dependency and constraints

  • The test program is in execution.
  • If the application model does not use the standard prober/handler driver function call (ph_die_done) or the equivalent, this event may not be generated.

    The standard naming for the application model variable must be used (not case-sensitive).

    For Lot ID: "ph_LOT_ID" | "LOT_ID"

    For Cassette ID: "ph_CASSETTE_ID" | "CASSETTE_ID" | "ph_CASS_ID" | "CASS_ID"

    For Wafer ID: "ph_WAFER_ID" | "WAFER_ID" | "ph_WAF_ID" | "WAF_ID"

    Otherwise it will fail to response the values.

Parameters

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session this event belongs to.

O

TIME_STAMP

The time point when this event occurs. It contains two long-type parts: SECONDS and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always EXECUTION.

O

EVENT_BODY

The event parameters. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always DIE_COMPLETED.

LOT_ID

The current lot ID. It can be empty.

CASSETTE_ID

The current cassette ID. It can be empty.

WAFER_ID

The current wafer ID. It can be empty.

SITE_ID_FOR_SITES

The list of site IDs.

SITE_SETUP_FOR_SITES

The list of site setups.

DIE_X_FOR_SITES

The list of dies' X coordinates, which is separated by space.

DIE_Y_FOR_SITES

The list of dies' Y coordinates, which is separated by space.

This parameter is represented by ParamList whose key and value are both string type.
