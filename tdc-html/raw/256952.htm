Converting legacy model files

The ModelFileConverter command line tool can be used to convert legacy model files to the latest format.

About this task

To convert legacy model files to the latest format, use the ModelFileConverter tool located at: /opt/hp93000/soc/system/sbin/ModelFileConverter.

Procedure

  1. Enter the following command to convert an existing model file using the legacy syntax to the current SmarTest syntax:

    ModelFileConverter -i <inputFilename> [-o outputFilename]

    Where:

    <inputFilename>: Specifies the legacy model file to be converted.

    <outputFilename>: Specifies the target file for the converted output.

    If <outputFilename> is not specified, the output is printed to stdout.

  2. Open the <outputFilename> file and check the contents.

Results

A model file using the latest syntax is generated.
