readExpect()

Reads data from a specific address and compare the data with your expected data. You can retrieve the test result with the function getPassFail().

If a tag is added to an RDI protocol class, then this function will operate in label-per-port mode. In this mode, you can query the "pass" or "fail" status of each readExpect transaction. If the tag is omitted in the RDI protocol class, then this function will operate in normal mode. In this case, break vectors will not be added to the pattern burst and the operation will be similar to a "read" operation.

Syntax

readExpect(long long iAddr, long long iExp, long long mask = 0x00);
readExpect(long long iAddr, const ARRAY_I& iExp);
readExpect(long long iAddr, const ARRAY_LL& iExp);
readExpect(long long iAddr, const ARRAY_I& iExp, const ARRAY_I& mask);
readExpect(long long iAddr, const ARRAY_LL& iExp, const ARRAY_LL& mask);
List of parameters

Parameter

Description

iAddr

The address to read.

iExp

The expected data.

mask

The value to mask the expected value per bit. The bit value 1 means mask and the bit value 0 means unmask.

By default, all bits are unmasked.

Example

rdi.protocol("id4").pname("i2c").readExpect(0x1,0x03,0x1).execute();

Related information
