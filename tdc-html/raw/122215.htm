SMC_SET_TESTSUITE_NAME()

Sets the name of a test suite that is executed within your SMC_backgroundProcessing() method.

This feature can be used for specific data logging purposes because the test suite name will not be changed permanently.

This means that the test suite keeps the name that is used with SMC_ARM() outside of the SMC_backgroundProcessing() methodd.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Syntax

void SMC_SET_TESTSUITE_NAME(const STRING& name);
Parameter

Parameter

Description

name

The temporary test suite name that is only valid within the SMC_backgroundProcessing() method where it is set.

Note No empty strings allowed!

Return value

There is no return value.

Functional changes

  1. Introduced in SmarTest 6.5.4
