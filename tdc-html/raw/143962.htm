Topic 143962

SOURCESYNC_TEST.copyingMethod()

Lets you select whether to use parallel or sequential copying method. If not specifying a copying method with this function, parallel method will be used by default.

Note This function takes effects only when you have set rapidSourceSync to SOURCE_SYNC::YES.

Syntax

SOURCESYNC_TEST& copyingMethod (SOURCE_SYNC::COPY_TYPE option);
Parameter

Parameter

Description

option

You can select either SOURCE_SYNC::PARALLEL or SOURCE_SYNC::SEQUENTIAL.
Available options of parameter: <option>

Option

Description

SOURCE_SYNC::PARALLEL

(Default) Parallel copying.

SOURCE_SYNC::SEQUENTIAL

Sequential copying.

Related information

SOURCESYNC_TEST.rapidSourceSync()

Functional changes
