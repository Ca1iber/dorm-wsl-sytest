Topic 96405

SETUPFILE_DOWNLOAD_STARTED

This asynchronous event indicates that setup file downloading is started. The event will be notified when:

  • The API DownloadTestprogram is called.
  • The API DownloadTestflow is called.
  • The test is executed when the setup files have not been downloaded.
  • The explicit download operation is made in SmarTest user interface.

Dependency

The downloading of setup files are made.

Parameters

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session this event belongs to.

O

TIME_STAMP

The time point when the event occurs. It contains two long-type parts: SECONDS and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always EXECUTION.

O

EVENT_BODY

The event parameters. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always SETUPFILE_DOWNLOAD_STARTED.

DEVICE_PATH

The current device path.

DEVICE_NAME

The device name in use.

TESTPROGRAM_NAME

The test program name the setup files belong to.

TESTFLOW_NAME

The test flow the setup files belongs to.

SETUPFILE_TYPE

The setup file type can be : PIN, LEVEL, TIMING, VECTOR and ANALOG.

SETUPFILE_NAME

The name of the setup file being downloaded.

This parameter is represented by ParamList whose key and value are both string type.
