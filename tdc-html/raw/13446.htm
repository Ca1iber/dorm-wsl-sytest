Introduction

The routing set connects the required analog pins for each test. Each routing set contains data for specifying the signal mode and the destination of the connection for each analog pin, and the order of the connections.

A routing set corresponds to a test. You can also use a routing set for multiple tests.

The routing setup commands specify the signal mode and connection for each analog pin, and the order of the connections. The commands define these routing settings as a routing set.

This chapter introduces the commands associated with the routing set in the following sections:

  • Defining Routing Set
  • Setting up Routing
  • Defining and Activating Primary Set
