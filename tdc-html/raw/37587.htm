Creating a Scan Test Setup

Scan testing is an approach for reducing the complexity of testing sequential circuits. Its basic idea is to provide direct access to the storage elements of the circuit. This allows you to set the state of the circuit directly before applying a parallel vector to it, and to observe directly the state resulting from the application of this vector.

The concept of scan testing described in the following (Scan Testing in SmarTest (Pin Scale)) only applies to a Pin Scale system in compatibility mode, and the constructs that the ASCII Interface provides for generation of a scan test setup in the ASCII vector file are based on this concept. Accordingly, the exposition in topic Creating a Scan Setup with the ASCII Interface and its subtopics holds only for Pin Scale systems in compatibility mode as well.

However, you can tell the ASCII Interface to convert its Pin Scale oriented scan structures into a binary multi-port setup that can be run on a Smart Scale system (or a Pin Scale system in unified memory mode). For more information see Converting an ASCII Scan Setup Into a Binary Multi-Port Setup.
