Data logging

Data logging and the selection of test limits for judgment purposes can be greatly simplified with two key technologies:

  • TMLimits
  • Data logging profiles

While neither has a direct throughput impact, using these techniques ensures that the correct settings - once specified - are consistently applied, helping to avoid throughput impairments caused by errors or oversights.

Using these techniques also helps to keep test time measurements comparable, ensuring that you can reliably detect when throughput improves or deteriorates.

TMLimits

TMLimits is an API framework that lets you set limits, test numbers, software and hardware binning, and other test parameters in a CSV file

You can use one file to specify parameter for different modes and switch between the modes under program control.

If you use TMLimits, you can perform result judgments using the judgeAndLog function from the TESTSET API.

Data logging profiles

Data Logging Profiles allow you to bundle any number of flag settings and switch them in a single step.

Specifying data logging profiles that optimize the throughput allow you to consistently choose the settings that provide maximum testing speed.
