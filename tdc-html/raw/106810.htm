Topic 106810

Calibration API

Subtopics

  1. How to use the calibration API
  2. Data types
  3. API functions

With this API, you can query

  • the required next calibration date,
  • the information about which parts of the test system have been calibrated.

To implement these functionalities, the following data types and functions are provided.

Data types:
  • CalStatusEvent
  • CalStatusType
  • CalibrationCategory
API functions:
  • calibrationCategoryList_next()
  • calibrationCategoryList_new()
  • calibrationCategoryList_delete()
  • isValidCalibration()
  • getCalibrationDate()
  • getCalibrationHistory()

This interface is provided with the SmarTest installation package. You can find the header files calibration.h and calibration_common.h in the directory /opt/hp93000/soc/pws/include and the library libmcpu.so in the directory /opt/hp93000/soc/pws/sh_lib.

For information on how to perform the calibration, refer to Executing SmarTest 7.10 maintenance activities in the Service documentation.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.0: New API function getCalibrationHistory().
