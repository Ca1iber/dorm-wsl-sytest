Topic 97011

SESSION_CREATED

This asynchronous event indicates that a new Advantest application software session has been created.

The session type (such as SmarTest) and its parameters and user preferences may not be available now and will be notified by the upcoming events like SMARTEST_SESSION_STARTING.

In the future, there will be other application software types besides SmarTest, like test program conversion and low level diagnostic.

Parameters

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session this event belongs to.

O

TIME_STAMP

The time point when this event occurs. It contains two long-type parts: SECONDS and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always SESSION.

O

EVENT_BODY

The event parameters. It contains the following members:

SESSION_STATE

The HVM event type. Here it is always SESSION_CREATED.
