Utility pin editor reference

The utility pin editor contains the following columns:

  • Name: The name of the pin.

    The name can be up to 16 characters long and must not contain the characters: # ; ( ‘ ' ) ? @ ,

  • Operation Mode: The operation mode for the utility line. The r, w, and rw modes are supported.
  • Delay [ms]: The waiting time after the state of the utility line is switched before another action is performed. This parameter is optional, the default is 0 ms.
  • Comment: Any text (optional).
  • Tester Channel: The tester channel to be used.

    The channel is specified with the prefix "UTI" and a three-digit number:

    • First digit: The utility line block on the DUT board (1-8)
    • Second and third digits: The line number within the block (01-16)

      Example: UTI208
