Topic 120101

SMC_GET_COMPLEX_WAVEFORM()

Retrieves the captured waveform data from the hardware memory.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Syntax

const ARRAY_COMPLEX& SMC_GET_COMPLEX_WAVEFORM(const STRING& dgtPinName,
                                              const STRING& resultHandle, INT measurement);
const vector<ARRAY_COMPLEX>& SMC_GET_COMPLEX_WAVEFORM(const STRING& dgtPinName, const STRING& resultHandle,
                                                      INT measurement, INT nWaveforms);

void SMC_GET_COMPLEX_WAVEFORM(Wave<COMPLEX>& wave, DOUBLE samplingRate, const STRING& dgtPinName,
                              const STRING& resultHandle, INT measurement);
void SMC_GET_COMPLEX_WAVEFORM(vector<Wave<COMPLEX> >& waves, DOUBLE samplingRate, const STRING& dgtPinName,
                              const STRING& resultHandle, INT measurement, INT nWaveforms);

Return value

The captured waveform is either returned as data type ARRAY_COMPLEX or a vector of ARRAY_COMPLEX.

If the wave parameter is used, the captured waveform(s) will be stored either in a single or vector of wave object(s) which is referenced by the wave parameter.

Note In case of site interlacing, the interlaced waveform/measurement number has to be used, which is returned by MEAS_DEF().getInterlacedWaveformId().

Example

The following example bursts the captured data of DGTPin (from 1 to NumberOfWaveforms), which is stored in the handle area of the HW memory into the burstWaveforms vector.

void SMC_backgroundProcessing(string DGTPin, string handle, INT NumberOfWaveforms)
{
   // upload multiple waveforms into one vector (burst upload)
   vector<ARRAY_COMPLEX> burstWaveforms= SMC_GET_COMPLEX_WAVEFORM(DGTPin, handle, 1, NumberOfWaveforms);

   // extract the single waveforms form the burst and do some processing
   for(INT currentWaveform=0; currentWaveform < NumberOfWaveforms;++currentWaveform)
   {
      ARRAY_COMPLEX &singleWaveform = burstWaveforms[currentWaveform];
      // Processing...
   }
}

The following example retrieves the captured data of the first sequencer line (1) for the given resultHandle and saves the data in the object CaptWave.

Wave<COMPLEX> CaptWave;
DOUBLE sample_rate = 2.5e6;
SMC_GET_COMPLEX_WAVEFORM(CaptWave , sample_rate, "pinA", "resultHandle", 1);
