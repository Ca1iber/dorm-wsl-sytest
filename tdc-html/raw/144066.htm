SOURCESYNC_SUB_TEST.repeatEdgeOffset()

Specifies the number of the first edge to be displayed on an error map. Use it together with SOURCESYNC_SUB_TEST.repeatEdgeInterval() and SOURCESYNC_SUB_TEST.repeatEdgeLength() to specify which edges will be printed out on an error map.

Note When the repeatEdgeInterval is set to 0, this function does not take effect.

Syntax

SOURCESYNC_SUB_TEST& repeatEdgeOffset (const int offset);
Parameter

Parameter

Description

offset

The number of the first edge to be shown on an error map.

The default number is 0.

Related information

SOURCESYNC_SUB_TEST.repeatEdgeInterval()
SOURCESYNC_SUB_TEST.repeatEdgeLength()

Functional changes
