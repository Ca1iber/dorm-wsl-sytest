Executing Firmware Commands from the Prompt

To execute a command from the task: prompt, type in the command mnemonic and its parameters, followed by Return. The Unix shell window displays any values returned by the command and then gives the task: prompt.

For example, you wish to enter a period resolution of the test system periods. At the prompt you enter:

CLKR 1,,12

For the details of the syntax see CLKR, CLKR? - (CLocK Resolution).

If you are working with pws-hpt, the system responds with:

size: 13

data:

CLKR 1,12,12\x0A

status: 0

The system returns the size of the string you have just entered, repeats the data (your string) and displays the status. A 0 status means that your command has been executed correctly. If you make a mistake entering your command, the system reports a status of -2. The sequence \x0A is the hex code for the "new line" control character.

The fw-hpt utility gives no reply to a command.

You can also send firmware queries to the system. Suppose, for example, that you wish to know the period resolution. At the task: prompt you enter:

CLKR? 1

If you are working with pws-hpt, the system replies with:

size: 8

data:

CLKR? 1\x0A

size: 13

data:

CLKR 1,12,12\x0A

status: 0

Here the procedure is the same as with the command, except that the system also reports the size of the string it is returning, followed by the answer string.

If you are working with fw-hpt, the reply is:

CLKR 1,12,12

Many of the examples for the individual firmware commands have been created with the hpt utilities. Both versions of the tool have been used for that purpose.

To exit the hpt utility, press Break or CTRL+C on the keyboard. This returns you to the command line.

Note This manual lists numerous examples of firmware command listings. Some of these listings contain comments in the right hand column. These comments have been included to improve your understanding of the listings. Please note that it is not possible to include comments in your firmware command files!
