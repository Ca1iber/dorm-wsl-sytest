Topic 98310

Setting switching order modes of level sets and DPS sets

When switching level sets and DPS sets between two test suites, you can set the switching order.

Before you begin

Make sure more than one level sets and DPS sets are defined.

Procedure

  1. On the menu, click Edit > Set Level Switching Order.

    The SLDO - Change IO/DPS Level Switching Order window opens.

  2. Select order type (FDSL or CVDL) and report type (ALL, FLSD, AMBI or NONE).
  3. Click Done.
    Note If you edit the settings in the level master file and save the file, the change will be saved in the GENERAL entry of the level master file. (Refer to Master file format for level setup.)

Results

When executing the testflow, the level sets and DPS sets between test suites are switched as the defined order.

If you want to apply different switching order modes during the execution of a testflow, execute firmware command "SLDO" by using FW_TASK API.

Related information

SLDO - (Switch Level and Dps Order)

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.4: From patch 8, the changes of level switching order in level master file can be saved.
