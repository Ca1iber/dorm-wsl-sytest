Adding a project to the Java build path

If a project contains code that must be known by a Java core program, this project must be added to the Java build path.

About this task

The Java build path is used by the compiler to identify dependent classes for the building of the Java project.

Before you begin

You have a created a project to be added to the Java build path.

You have opened a workspace with your SmarTest program.

Procedure

  1. Import the project to be added into your current workspace.
  2. Right-click the project to be added to open the Java Build Path dialog box with Build Path > Configure Build Path ....
  3. In the Java Build Path dialog box, select the tab Projects.
  4. Click Add....
  5. In the Required Project Selection box, select the project to be added.
  6. Confirm with OK.
  7. In the Java Build Path dialog box, click Apply and close.

What to do next

You have prepared the compilation of your SmarTest program.

Functional changes

  1. Introduced in SmarTest 8.4.4
