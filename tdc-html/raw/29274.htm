DSP_TRANS_MAT

This API is for transposing (interchanging the rows and columns) a matrix.

The row and column dimensions of src and result must be declared as shown in the following table.

Matrix Dimensions

Matrix

Row Dimension

Column Dimension

src

row

column

result

column

row

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_TRANS_MAT(DOUBLE *src, DOUBLE *result, 
 INT row, INT column);
DSP_TRANS_MAT(ARRAY_D& src, ARRAY_D& result, 
 INT row, INT column);
DSP_TRANS_MAT(ARRAY_COMPLEX& src, 
 ARRAY_COMPLEX& result, 
 INT row, INT column);
DSP_TRANS_MAT(COMPLEX *src, COMPLEX *result, 
 INT row, INT column);
Parameters

I/O

Parameter

Description / Range

I

src

Source matrix (two-dimension array)

The declared row and column dimensions must be the same as row and column, respectively.

O

result

Transposed results (two-dimension array)

The declared row and column dimensions must be the same as row and column, respectively.

I

row

Row dimension of source matrix

1 ≤ row

I

column

Column dimension of source matrix

1 ≤ column

1 ≤ row × column ≤ 2097152

Example

  1. To transpose a DOUBLE type matrix1 (20 by 10) into matrix2 (10 by20), you can use the code as shown below:
     DOUBLE matrix1[20][10], matrix2[10][20];
 DSP_TRANS_MAP (*matrix1, *matrix2, 20, 10);

    This example transposesmatrix1(20 by 10) intomatrix2(10 by 20) as follows: 

     DOUBLE matrix1[20][10], matrix2[10][20];
 int i, j;
 for(i=0; i<20; i++)
    for(j=0; j<10; j++)
       matrix2[j][i] = matrix1[i][j];
  2. To transpose an ARRAY_D type matrix, the reference code is as below:
     ARRAY_D matrix1(200),matrix2(200);
 DSP_TRANS_MAT(matrix1,matrix2,20,10);
  3. To transpose an ARRAY_COMPLEX type matrix, the reference code is as below:
     ARRAY_COMPLEX matrix1(200), matrix2(200);
 DSP_TRANS_MAT(matrix1, matrix2, 20, 10);
  4. To transpose a COMPLEX type matrix, the reference code is as below:
     COMPLEX matrix1[20][10], matrix2[10][20];
 DSP_TRANS_MAP (*matrix1, *matrix2, 20, 10);
