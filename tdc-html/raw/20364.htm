High Current DPS (HC-DPS) pogo pin assignments

The High Current DPS is available as a power source for devices requiring low voltages but drawing high currents or having large current swings. Each HC-DPS provides up to 100 A.

Supported V93000 systems : Smart Scale (SmarTest 7), Pin Scale

Two HC-DPSs, for example, can be used in parallel (ganged) to provide up to 200 A. The HC-DPS board contains only one supply channel. Unlike the General Purpose DPS and High Voltage DPS, the HC-DPS does not have multiple performance ranges.

The HC-DPS requires special high power pogo pins which are not compatible with the other DPS types (see High Current DPS (HC-DPS)). A DUT board designed for use on a test head with a HC-DPS requires a coding plug in the stiffener near the HC-DPS pogo pad block. See Hole plug for more information.

The figures show the pogo assembly for the High Current DPS, the pogo pin block of the assembly, and the mating pins on the DUT board.

If you install one or more High Current DPSs:

  • Define the location of the High Current DPS channels as required for your application.
  • If High Current DPSs are used in parallel (ganged), High Voltage DPSs are not supported.
