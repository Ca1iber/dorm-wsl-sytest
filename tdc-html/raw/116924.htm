Measure waveform classes provide functionality to define events that digitize waveforms.

Specialized measure waveform classes are EVENT_WAVEFORM_VM (Voltage Measure Waveform) and

EVENT_WAVEFORM_IM (Current Measure Waveform). Both classes derive from the EVENT_BASE class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

EVENT_WAVEFORM_VM (const STRING & id);
EVENT_WAVEFORM_VM (      INT      id);

This constructs an object of the EVENT_WAVEFORM_VM class. The class derives from the EVENT_BASE class.

Parameter
Parameter Description
id

Identifier of the event.

The identifier may be defined as integer value or as string.

Example

Defines a voltage measurement capture event:

EVENT_WAVEFORM_VM captureEvent("rampCaptureV");
captureEvent.samples(20);
captureEvent.sampleVectorDistance(64);
captureEvent.averages(4);
captureEvent.iClampChecks();
