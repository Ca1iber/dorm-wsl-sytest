Test method snippets for CODEC

The following test method snippets for CODEC test are provided with SmarTest. These test method snippets are included in the file /opt/hp93000/soc/segements/tml/testmethodSnipptets.xml.

They are listed in the alphabetical order.

  • V93000_CODEC_MeasurementSetup

    This snippet sets up and executes CODEC test. It then kicks off the data uploading and result calculation with the smartCalc background post processing function.

  • V93000_CODEC_GAINDISTORTION_SMCPostProcess

    This snippet does the post processing for the CODEC gain and THD test with smartCalc. It uploads the captured data and calculates the gain and THD. The results are judged with the limits in the test table and logged. The snippet can be used together with the snippet V93000_CODEC_GAINTHD_MEAS in the test method.

  • V93000_CODEC_ICN_SMCPostProcess

    This snippet does the post processing for the CODEC idle channel noise measurement with smartCalc. It uploads the captured data and calculates the idle channel noise. The results are judged with the limits in the test table and logged. The snippet can be used together with the snippet V93000_CODEC_ICN_MEAS in the test method.

  • V93000_CODEC_PSRR_SMCPostProcess

    This snippet does the post processing for the CODEC PSRR measurement with smartCalc. It uploads the captured data and calculates the PSRR for ADC and DAC. The results are judged with the limits in the test table and logged. The snippet can be used together with the snippet V93000_CODEC_PSRR_MEAS in the test method.

Functional changes

  1. Introduced in SmarTest 6.5.4
