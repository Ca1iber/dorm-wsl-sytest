Hardware Bin Record (HBR)

The Hardware Bin Record stores a count of the parts "physically" placed in a particular bin after testing. (In wafer testing, physical binning is not an actual transfer of the chip, but rather is represented by a drop of ink or an entry in a wafer map file.) This bin count can be for a single test site (when parallel testing) or a total for all test sites. The STDF specification also supports an SBR for logical binning categories. A part is "physically" placed in a hardware bin after testing.

Location in the file:

The Hardware Bin Record can be located anywhere in the data stream after the Initial sequence and before the MRR. When data is being recorded in real time, this record will usually appear near the end of the data stream.

HBR field name

Field description

Value

93000 data source

HEAD_NUM
  • Test head number
  • One-byte unsigned integer
  • Value = 255

    If the ATR and GDR indicate that there are more than 255 sites in the test, HEAD_NUM is the number of the site divided by 256. For example, in a record for site 384, HEAD_NUM would be 2.
  • For tests with up to 255 sites: hard-coded value

    For tests with more than 255 sites: derived from SiteID

SITE_NUM
  • Test site number
  • One-byte unsigned integer

    If the ATR and GDR indicate that there are more than 255 sites in the test, SITE_NUM is the number of the site modulo 256. For example, in a record for site 600, SITE_NUM would be 88.
  • EDL Event:

    BinReachedEventType

  • EDL Attribute:

    SiteIdAttrType

HBIN_NUM
  • Hardware bin number
  • Two-byte unsigned integer
  • Valid range is 0 - 32767
  • EDL Event:

    BinReachedEventType

  • EDL Attribute:

    BinNumberAttrType

  • Hardware bin number from Testflow Editor Bin Dialog

HBIN_CNT
  • Number of parts in bin
  • Four-byte unsigned integer
  • EDL Event:

    BinReachedEventType

HBIN_PF
  • Pass or fail bin indication
  • One-byte unsigned integer
  • P = Passing bin
  • F = Failing bin
  • <space> = Unknown bin type
  • EDL Event:

    BinReachedEventType

  • EDL Attribute:

    IsGoodBin

HBIN_NAM
  • Name of hardware bin
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • Hardware bin number and hardware bin description from Testflow Editor Bin Dialog.
  • If no hardware bin description exists, just the hardware bin number is used
  • EDL Event:

    BinReachedEventType

  • EDL Attribute:

    BinNumber

    HardwareDescription

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.2.2: Added HEAD_NUM and SITE_NUM conventions for tests on more than 255 sites.
