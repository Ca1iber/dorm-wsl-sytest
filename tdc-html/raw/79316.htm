What is Multi-Port Testing?

A multi-port setup allows you to utilize the tester's per-pin architecture. Since every DUT pin is connected to a separate tester channel, the hardware allows you to associate every DUT pin with its own timing and sequencer program, and still to test all pins in parallel. The multi-port feature of SmarTest provides the software support to make use of this pin-specific hardware architecture.

A port is a group of pins that can be tested in parallel with, but independently of the other configured pins. The system provides a default port which contains all configured pins and is referred to by the "at" sign (@). Ports that do not include all pins must be defined by the user.

How you define the ports, depends on your specific multi-port application.

Broadly speaking, a multi-port test execution is defined for a non-overlapping set of ports that will usually cover all configured pins.

Each of these ports can have its own timing (which must be equation based), and its own sequencer program. The timings for the port set are defined in a multi-port timing specification; the sequencer programs in a multi-port burst.
