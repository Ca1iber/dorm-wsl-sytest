Topic 96453

AbortTestFLow

This remote control command tries to abort the execution of a test flow. When the execution is aborted, the event TESTFLOW_EXEC_ABORTED will be notified.

SUCCESS will be returned if the command is successfully issued. Otherwise an error object indicating the error code, description and severity will be returned.

Code

Description

Severity

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • Can't abort the testflow execution because there is no testflow currently running.

RECOVERABLE

Dependency

A testflow is in the execution.

Parameters

I/O

Parameter

Description

I

SESSION_ID

The ID of the SmarTest session to work with.

Prototype

string sessionId;
Status command("AbortTestflow", ParamList(), sessionId);
