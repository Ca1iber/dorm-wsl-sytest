2nd level protocol wrapper tool

The 2nd level protocol wrapper tool supports the Concurrent test frameworK (CTF). It makes use of the CCTMultiportSync APIs to handle the port synchronization automatically. This tool is very useful in protocol-aware (PA) concurrent testing.

The tool invokes the PA wrapper API to complete the register transactions. It returns the cycles of each PA transaction so that the synchronization with other ports is possible. This tool provides a more user-friendly usability for performing the PA read or write operations.

Note The 2nd level protocol wrapper is not provided with SmarTest. To get this tool, please contact your local Advantest application engineer.
