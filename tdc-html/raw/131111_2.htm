TSHA? - (Timing Setup Has Arming?)

The TSHA? query determines if the ARM action is present in the wavetables that are associated with the specified pins in the specified timing specification.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

TSHA?

TSHA? {specset_id|"multi-port_spec"}, {(pinlist)}

returns:

TSHA {specset_id|"multi-port_spec"},{TRUE|FALSE}, {(pinlist)}

Parameters

specset_id

Derived as follows:

100 * equation_set_no + specset_no

multi-port_spec

To query a multi-port timing specification, specify the name of the specification.

TRUE

The wavetable of at least one of the pins in the pin list contains the ARM action.

FALSE

No wavetable of any pin in the pin list contains the ARM action.

pinlist

The pins whose associated wavetable is to be checked.

Application

Timing Setup GUI.

Example

> TSHA? "MP_1",(pin1)
< TSHA "MP_1",FALSE,(pin1)

Functional changes

  1. Introduced in SmarTest 7.1.4
