DSP_FIR_FILTER1

This API designs a Kaiser-window based, linear-phase FIR filter which can be a standard lowpass, highpass, bandpass, or bandstop filter. The filters are normalized so that the magnitude response of the filter at the center frequency of the passband is 0 dB.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

int DSP_FIR_FILTER1(ARRAY_D & taps, INT filttype, ARRAY_D & fc, DOUBLE beta);
int DSP_FIR_FILTER1(ARRAY_D & taps, INT filttype, ARRAY_D & fc,
                    DOUBLE beta, ARRAY_D & mag_response);
int DSP_FIR_FILTER1(DOUBLE *taps, INT n, INT filttype, DOUBLE *fc, DOUBLE beta);
int DSP_FIR_FILTER1(DOUBLE *taps, INT n, INT filttype, DOUBLE *fc,
                    DOUBLE beta, DOUBLE *mag_response, int m);
Parameters

I/O

Parameter

Description/Range

O

taps

The result array containing the n coefficients of the FIR filter.

size = n

O

mag_response

The result array containing the magnitude response of the FIR filter in dB.

256 ≤ size ≤ 524288

The size must be a power of 2.

I

filttype

Filter type

LP: low pass

HP: high pass

BP: band pass

BS: band stop

I

fc

Normalized cut-off frequencies as fractions of the sampling frequency (e. g. 0.25 corresponds to a quarter of the sampling frequency). Low-pass and high-pass filters require one cut-off frequency, band-pass and band-stop filters require two (begin and end of the pass band or stopband).

0 ≤ fc ≤ 0.5

I

n

Number of filter taps; n = filter order + 1

For high pass and band stop filters, an even filter order is always used, resulting in an odd number of filter taps n. This is because for odd filter orders, the frequency response at the Nyquist frequency is 0, which is inappropriate for high pass and band stop filters. If you specify an even-valued number of taps n for these filters, it is automatically incremented by 1.

1 ≤ n ≤ 65535

I

m

Number of frequency bins of the magnitude response

256 ≤ m ≤ 2097152

The value of m must be a power of 2.

I

beta

Beta parameter for the Kaiser window.

Beta is the Kaiser window ß parameter that affects the sidelobe attenuation of the Fourier transform of the window.

Small beta values result in filters with a steep roll-off but a considerable amount of ripple and a relatively low attenuation in the sidelobes.

Increasing beta widens the main lobe and decreases the amplitude of the sidelobes. So the ripple is reduced and the attenuation in the sidelobes increases.

0 ≤ beta ≤ 500

Example

int n = 63; // FIR length
int m = 4096; // number of frequency bins
double h[n]; // Filter taps 
double freq[m]; // Frequency response
double frequencies[2]; // cutoff frequencies
frequencies[0]= 0.3;
frequencies[1]= 0;
DSP_FIR_FILTER1(h, n, HP, frequencies, 3.5, freq, m);

This example designs a high pass FIR filter. This filter has 63 taps and the cut off frequency is three tenth of the sampling frequency.

Functional changes

  1. Introduced in SmarTest 6.5.2
