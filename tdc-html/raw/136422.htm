Viewing shmoo plots with the Shmoo Tool

After you execute a shmoo test with the Shmoo Tool, a shmoo plot with its title, the related test mode, result pins and site information is displayed on a shmoo page in the shmoo editor.

If you change the test modes, result pins, and sites on the shmoo plot, the corresponding information displayed on the shmoo page also changes. See:

  • View different shmoo plots of different test results
  • View different shmoo plots of different result pins
  • Views different shmoo plots of different sites

To carefully view this shmoo plot:

  • Zoom in and out the shmoo plot
  • Select an area of the plot to view it in detail
  • View different shmoo plots of different test results
  • View different shmoo plots of different result pins
  • Views different shmoo plots of different sites
