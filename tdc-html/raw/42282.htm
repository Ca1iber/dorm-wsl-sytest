Topic 42282

Function: ph_get_id

This function lets you retrieve the identification (ID) of various driver component, of the equipment, and of materials.

When used with the general handler driver, ph_get_id can return the ID of the "driver", "plugin" or "equipment", depending on which of these keywords is used as an argument.

When used with the general prober driver, ph_get_id can return the ID of the "driver", "plugin", "equipment", "lot", "cassette", "wafer", or "probe-card", depending on which of these keywords is used as an argument.

The returned ID is assigned to the calling variable (id in the example below).

This assignment will automatically be logged to the data log stream of event data logging (see the Event Data Logging manual).

Applicable for: handler and prober driver

Example:

id = PROB_HND_CALL (ph_get_id plugin)

See the section Example application models for more examples and for how the logged data appears in the GDF data log file.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.1.0: GDF logging in application mode is obsolete.
