Topic 351252

Utility Card specific setup tasks

This section describes some of the typical setup tasks for the Utility Card of a V93000 EXA Scale system.

The following specific setup tasks are available in this topic:
  • Global compatibility settings
  • UTILITY256 utility card configuration in the tester.model file
  • Switching the utility power supplies on and off

Global compatibility settings

Some characteristics of utility power supplies have been optimized for V93000 EXA Scale systems. For compatibility, the behavior can be adapted to the Pin Scale and Smart Scale systems using global settings. These settings are to be defined in a configuration file that is parsed when the SmarTest Work Center is started.

The compatibility setting are defined in file /opt/hp93000/soc/system/etc/systemPreferences.txt.

Data in the file are defined as key=value pairs.

The following keys are available for the Utility Card:

  • utility_power_featureset
    For the Utility Card, the key controls the global power on/off behavior of the UP5V utility power supply and grouping of the XP pins utility power supply outputs.
    Key: /system/hw_config/utility_power_featureset
    Value: Integer value 2 or 3
    Default: 2
    Example: /system/hw_config/utility_power_featureset=2
    Supported values and functionality:
    2 This value activates the behavior that is compatible with the Pin Scale and Smart Scale systems:
    • UP5V utility power supply:
      • The UP5V utility power supply is enabled as soon as the test head is switched on.
      • The state of the "DSC" utility pin is ignored when switching on the UP5V utility power supply.
      • The UP5V utility power supply automatically recovers after an overload condition.
      The change in behavior applies only to the UP5V utility power supply of the first Utility Card that is routed to utility pogo utility pogo block 165 (UTIL 1) ...  172 (UTIL 8).
    • Grouping of XP pins utility power supply outputs:
      • The three Utility power supply - XP pins outputs +5.0 V, -5.0 V and +3.3 V of the first Utility Card are grouped.
      • The three grouped outputs can be switched on or off only all together.
      • An overload condition disables all three outputs.

      The change in behavior applies only to the XP... pins utility power supply of the first Utility Card that is routed to utility pogo block 165 (UTIL 1) ...  172 (UTIL 8).

    This is the default value and the default behavior if utility_power_featureset is not defined in the systemPreferences.txt file.
    3

    This value enables the new behavior of the V93000 EXA Scale systems running SmarTest 8.

    This value is not supported on V93000 EXA Scale systems running SmarTest 7.

    • UP5V utility power supply:
    • Grouping of XP pins utility power supply outputs:

      This value enables the new behavior of the V93000 EXA Scale systems:

      • The three Utility power supply - XP pins outputs +5.0 V, -5.0 V and +3.3 V can be switched on or off individually.
      • An overload condition disables only the affected output of the Utility power supply - XP pins.
    In SmarTest 8 only, a warning is issued if the key /system/hw_config/utility_power_featureset is not defined:
    WARNING: The '/system/hw_config/utility_power_featureset' preference has not been set.
    Backwards compatible settings will be used.
    The preference can be changed in file '/opt/.../etc/systemPreferences.txt'.
    In SmarTest 7 only, a warning is issued if the key /system/hw_config/utility_power_featureset is set to the unsupported value "3":
    WARNING: This SmarTest version only supports the backwards compatible setting (2) for
the '/system/hw_config/utility_power_featureset' preference.
         The current value (3) is not supported and will be ignored.
         The preference can be changed in file '/opt/.../etc/systemPreferences.txt'.
    SmarTest issues a warning if an invalid parameter value is set:
    UNRECOVERABLE ERROR (CORRECTNESS EXCEPTION): Problems found during hardware detection. ...
The '/system/hw_config/utility_power_featureset' preference must be in the range 2 to 3. ...
  • up5v_voltage_reduction

    The key controls the output voltage reduction of the UP5V utility power supply.

    Key: /system/hw_config/up5v_voltage_reduction
    Value: Boolean value true or false
    Default: false
    Example: /system/hw_config/up5v_voltage_reduction=true
    Supported values and functionality:
    true

    For compatibility with legacy Pin Scale and Smart Scale systems, the output voltage of the Utility power supply UP5V pins is reduced from 5.0 V to 4.75 V.

    The change in behavior applies only to the first Utility Card that is routed to utility pogo block 165 (UTIL 1) ...  172 (UTIL 8).
    false

    This value enables the new behavior of the V93000 EXA Scale systems:

    The output voltage of the Utility power supply UP5V pins is 5.0 V.

    This is the default value and the default behavior if up5v_voltage_reduction is not defined in the systemPreferences.txt file.

    SmarTest issues a warning if an invalid parameter value is set:

    UNRECOVERABLE ERROR (CORRECTNESS EXCEPTION): Problems found during hardware detection. ...
The '/system/hw_config/up5v_voltage_reduction' preference must be set to either 'true' or 'false'. ...

UTILITY256 utility card configuration in the tester.model file

The Utility Card is to be defined at two positions of the tester.model file:
  • GLOBAL section:
    The utility lines are to be defined in this section as follows:
    utility_lines = number_of_lines, type = sequencer_controlled, pogo_size = 32, redirectpogoblocks = redirect_utility_pogoblocks
    with number_of_lines replaced with
    • 256 for the first Utility Card or
    • 512 if two Utility Cards are installed.

    Keyword utility_lines is mandatory for a V93000 EXA Scale system.

    Example:
    utility_lines = 256, type = sequencer_controlled, pogo_size = 32

    Keyword redirectpogoblocks is used to specify available redirect utility pogo blocks only if the dut_interface type is WSMM_I2C or WSMM. If redirectpogoblocks is not specified, no utility pogo blocks will be redirected. If redirectpogoblocks is specified for other DUT interface types, SmarTest will not start. Supported redirect utility pogo blocks for a V93000 EXA Scale system are listed below:

    • First utility board: 4133 (165), 5209 (166), 6217 (167), 7225 (168), 4129 (169), 5205 (170), 6213 (171), 7221 (172)
    • Second utility board: 4333 (265), 5409 (266), 6417 (267), 7425 (268), 4329 (269), 5405 (270), 6413 (271), 7421 (272)
    Example:
    utility_lines = 256, type = sequencer_controlled, pogo_size = 32, redirectpogoblocks = 6217 7221 5209
  • CARD_CONFIGURATION section:
    The Utility Card and the utility pogo blocks must be defined in this section as follows:
    slot = physical_location, HW = UTILITY256, pogoblocks = ppp-ppp, type = UTILITY
    with
    • physical_location replaced with any valid slot specifier and
    • ppp-ppp replaced with a valid pogo block range:
      • 165-172 for the first Utility Card
      • 265-272 for the second Utility Card
    • type set to UTILITY.
    The parameters are all mandatory.
    Example:
    slot = 101, HW = UTILITY256, pogoblocks = 165-172, type=UTILITY
Rules to follow when defining a Utility Card in the tester.model file:
  • The first Utility Card in the tester.model file must always use the pogo block range 165 ... 172.
  • Defining utility_lines = 256 always means that the first Utility Card is installed.
  • The second Utility Card for the pogo block range 265 ... 272 can be defined only if the first Utility Card has also been defined.
  • The pogo block ranges 165 ... 172 and 265 ... 272 must be defined in ascending order and without gaps.
  • All eight pogo blocks must be defined for each installed Utility Card.

Switching the utility power supplies on and off

The utility power supplies can be switched on or off by test method API UTILITY_POWER_STATUS of SmarTest 7.

For more information and valid combinations of the supply identifier and the target resource, refer to UTILITY_POWER_STATUS.state().
