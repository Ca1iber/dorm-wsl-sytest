MTP_MULTI_FILTER

Subtopics

  1. MTP_MULTI_FILTER.addAddressFilter()
  2. MTP_MULTI_FILTER.isValidAddress()

This class defines a filter which consists of several filters defined by MTP_ADDRESS_FILTER individually.

This class is used by MTP_MEMORY_TEST.addAddressFilter().

This API is defined in the heder file /opt/93000mts/mts/execution_engine/include/MtpAddressFilter.h.

Syntax

MTP_MULTI_FILTER();

Creates an object to define this filter.

List of parameters

There are no parameters.

Return value

Using MTP_MULTI_FILTER.isValidAddress(), it returns true or false for an address within the filter range or not.

Otherwise, there is no return value.

Example

MTP_MULTI_FILTER filter;
