SOURCESYNC_TEST.test()

Creates or references to a condition set that sets up a sweep test sweeping from the start to the stop cycles.

  • If the condition set does not exist, this function will create a new set with the specified name.
  • If the condition set exists, this function will reference to it.

Syntax

SOURCESYNC_SUB_TEST& test (const string& testName);
Parameter

Parameter

Description

testName

The name of a condition set that sets up a sweep test sweeping from the start to the stop cycles.

Return value

Returns an object of the SOURCESYNC_SUB_TEST class.

Related information

SOURCESYNC_SUB_TEST

Functional changes

  1. Introduced in MTP 3.2.2
