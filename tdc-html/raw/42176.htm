Parameter: waiting_for_lot_timeout_action

If a timeout occurs while the driver waits for a lot start signal to be sent by the prober, the driver can ask the operator to take action ("operator-help"), or can continue waiting for the lot start signal ("continue"). In the latter case, the driver will stop waiting only if a lot start signal is received (and recognized by the driver), or if one of the SmarTest flags ABORT, PAUSE, RESET, QUIT is set.

Driver default: "continue"

Changeable at run-time: yes

Applicable for: probers and handlers

Example: waiting_for_lot_timeout_action: "operator-help"
