SPMU_PIN_TASK.clamp()

Sets the clamp value of the pins either to Volts or Ampere, depending on the mode set by SPMU_PIN_TASK.mode().

In "IFVM" mode, the clamp will limit the voltage drawn from or supplied to the DUT. If the clamp voltage is higher than the voltage of the DUT pin, the programmed current will flow to the DUT, if it is lower, the current will be drawn from the DUT.

In "VFIM" mode, the clamp limits the current to prevent thermal damage to the DUT.

Each DC supply requires a minimum clamp current to work properly. If necessary, SmarTest automatically adjusts the clamp current settings to the minimum value that is normally defined in the specifications and displays the following warning in the UI report window:

Clamp current limit is smaller than minimum value and will be auto-corrected.
For the minimum clamp current distance, refer to
  • DPS128 / DPS64 specifications and Clamping and forcing current in DPS128 / DPS64 functionality and features
  • Minimum clamp current distance in XPS256 programming - Force and clamp currents

Syntax

SPMU_PIN_TASK& clamp(DOUBLE clamp);
SPMU_PIN_TASK& clamp(DOUBLE sink, DOUBLE source);
SPMU_PIN_TASK& clamp(DOUBLE clampLow, DOUBLE clampHigh);
Note The syntax with two parameters is supported only by the DC Scale DPS128/64 cards and the DC Scale XPS256 card.
Parameters
Parameter Description
clamp Clamp value:
  • "IF..." and "CF..." modes: Sets the clamp voltage in Volt.
  • "VF..." modes: Sets the clamp current in Ampere.
sink Sets the sinking clamp current in Ampere for the "VF..." modes.

Supported only by the DC Scale DPS128/64 cards and the DC Scale XPS256 card.
source Sets the sourcing clamp current in Ampere for the "VF..." modes.

Supported only by the DC Scale DPS128/64 cards and the DC Scale XPS256 card.
clampLow Sets the lower clamp voltage in Volt for the "IF..." and "CF..." modes.

Supported only by the DC Scale DPS128/64 cards and the DC Scale XPS256 card.
clampHigh Sets the upper clamp voltage in Volt for the "IF..." and "CF..." modes.

Supported only by the DC Scale DPS128/64 cards and the DC Scale XPS256 card.

Return value

A reference to the SPMU_PIN_TASK object.
