UDUT - (UnDefine UTility line)

The UDUT (UnDefine UTility line) command removes a defined utility line name from the configuration, thereby setting the output state of write utility lines to 0 (low output).

Syntax

UDUT {(util_name)}

Parameters

util_name

Specifies the utility line name or names to be undefined.

The symbol @ removes all utility line definitions.

If more than one name is to be removed, the names must be separated by a comma.

Application

For details about utility lines, see Configuration Setup Commands.

Errors

An error is generated if the referenced utility line has not been defined before.

Example

UDUT (@)

This command undefines all defined utility line names.

Functional changes

  1. Introduced before SmarTest 6.3.2
