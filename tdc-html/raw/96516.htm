Topic 96516

CASSETTE_COMPLETED

This asynchronous event indicates that the execution of a Cassette level is finished in the test program execution.

Dependency and constraints

  • The test program is in execution.
  • If the application model does not contain the custom Cassette level or does not use the standard prober/handler driver function call (ph_cassette_done) or the equivalent, this event may not be generated. The lot ID variable name should be ph_LOT_ID or LOT_ID. The cassette ID variable name should be ph_CASSETTE_ID, CASSETTE_ID, ph_CASS_ID or CASS_ID.
Parameters

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session this event belongs to.

O

TIME_STAMP

The time point when this event occurs. It contains two long-type parts: SECONDS and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always EXECUTION.

O

EVENT_BODY

The event parameters. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always CASSETTE_STARTED.

LOT_ID

The current lot ID.

CASSETTE_ID

The current cassette ID.

This parameter is represented by ParamList whose key and value are both string type.
