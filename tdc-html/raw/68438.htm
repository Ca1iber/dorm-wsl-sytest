Topic 68438

Null data

The null data value is the value that the DUT interprets as a data word containing a logical zero.

The specified null data value is to used to modify any data before it is sent to the DUT: Any data value is XORed with the null data value you enter before it is sent to the DUT.

The value is specified in the APG pattern file using the :nullData: keyword.

Examples

Specifying the null data value in the APG pattern file

:nullData: 0x555

Using the null data value

Use the generic value (0 or -1) or a fixed value (for example 0x1234) assigned as described above in a function call in the code section of the APG program file, as demonstrated in the example below.

main ()
{
  for (y=yStart; y<=yStop; y+=1)
  {
    for (x=xStart; x<=xStop; x+=1)
    {
      write_access(x,y,0);
      read_access(x,y,0);
    }
  }
  for (y=yStart; y<=yStop; y+=1)
  {
    for (x=xStart; x<=xStop; x+=1)
    {
      write_access(x,y,-1);
      read_access(x,y,-1);
    }
    for (y=yStart; y<=yStop; y+=1)
    {
      for (x=xStart; x<=xStop; x+=1)
      {
        write_access(x,y,0x1234);
        read_access(x,y,0x1234);
      }
    }
  }
}

The XOR operation on the null data value 0x5555 in the APG pattern file and the value in the function call in the code section of the APG program file in the previous example results in these values:

Function call

Result

write_access(x,y,0)

0x5555

read_access(x,y,0)

0x5555

write_access(x,y,-1)

0xAAAA

read_access(x,y,-1)

0xAAAA

write_access(x,y,0x1234)

0x4761

read_access(x,y,0x1234)

0x4761
