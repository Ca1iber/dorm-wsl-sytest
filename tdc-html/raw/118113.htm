CTrainingConfig

The CTrainingConfig class defines constants for the names of the parameters in the GDDR5 training configuration file.

We recommend that you always use these constants to refer to the parameters instead of the names itself.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/training/include/TrainingConfig.h.
