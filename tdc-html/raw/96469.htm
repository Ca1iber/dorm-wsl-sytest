Topic 96469

TESTPROGRAM_EXEC_ABORTED

The asynchronous event indicates that the execution of a test program is aborted (abnormal completion).

Dependency

The execution of the test program is made.

Parameters

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session to work with.

O

TIME_STAMP

The time point when this event occurs. It contains two long-type parts: SECONDS and MICROSECONDS.

O

EVENT_NAME

The HVM event type. Here it is always EXECUTION.

O

EVENT_BODY

The event parameters. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always TESTPROGRAM_EXEC_ABORTED.

DEVICE_PATH

The current device path.

DEVICE_NAME

The name of device in use.

TESTPROGRAM_NAME

The test program name in execution.

This parameter is represented by ParamList whose key and value are both string type.
