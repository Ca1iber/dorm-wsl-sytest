Advanced Find and Replace

Use Find/Replace to search and replace in single vector cells and in series of vector cells. You can also search for comments.

Do not use the Find/Replace dialog if you are searching for sequencer instructions. Click (Hide all vectors in current editor) instead.

If the "Space is Delimiter" is selected as an option, your search will be limited to one cell only. If this option is not selected you search will go over multiple cells.

Example:

  • "Space is Delimiter" selected: The string 111 is interpreted as one string.
  • "Space is Delimiter" not selected: The string 111 is interpreted as a sequence of three consecutive strings of 1.

To search for comments, select the "Space is Delimiter" option. The tooltip displays how the search pattern is interpreted.

To enable the Signal entry fields, select the Signal option in the Scope panel.

To list the available signals, press Ctrl+Space.

If you specify one ore more signals, the search is limited to the specified signals.
