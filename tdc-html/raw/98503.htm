CHRS, CHRS? - (CHeck Routing Set globally)

The CHRS command serves to control the behavior of SmarTest with respect to inconsistent routing requests. The CHRS? query returns the current setting.

Mode of operation

When CHRS is set to OFF, SmarTest tries to make the best of inconsistent requests. But since the result of this effort is not easy to predict, it is not recommended to rely on it. When CHRS is set to ON, conflicting routing requests will not be executed. Instead, SmarTest will issue an error message and keep the previous routing status.

CHRS

CHRS {ON|OFF}

CHRS?

CHRS?

returns:

CHRS {ON|OFF}

Parameters

OFF

SmarTest tries to fulfill an inconsistent request as well as possible. This is the default.

ON

SmarTest issues an error message when a routing request is inconsistent, and retains the previous routing status

Functional changes

  1. Introduced before SmarTest 6.3.2
