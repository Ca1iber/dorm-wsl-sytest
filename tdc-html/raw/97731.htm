PinGroupListAttrType

Contains a list of all pins groups.

Field Name

Data Type

Description

Comments

length

int

Attribute length

These fields form the attribute header.

type

short

Attribute type

name

string

Name of the pin group

These fields form a block, which occurs for every pin group. The number is implicitly specified by the length field.

pin_count

int

Number of pins contained in the pin group

pin_index

short

Index of the pin. This value is repeated pin_count times.
