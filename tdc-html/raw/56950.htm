Topic 56950

Level sets

Subtopics

  1. Pin exclusion
  2. Additional pin qualifier @diff

The level sets module assigns values to the level resources of i, o and io pins using expressions.

The module header starts with the LEVELSET keyword followed by the level set number, an integer in the range 1 to 99, and an optional descriptive name, the description. The level set description is a string of up to 60 characters enclosed in double quotes ("...").

The pins assignment is part of the level sets module and follows the LEVELSET line. Each assignment set is identified by the PINS keyword. You can assign pin resources either to individual I/O pins or to pin groups.

For a list of the available pin resources, see Supported level resources.

Note An expression can be reduced to a fixed value. For example; to specify the high and low compare levels you could enter:
LEVELSET 1 "example levels"
  PINS aclkout
   vil  = vil_level
   vih  = vih_level
   vol  = 0.2
   voh  = Vcc - 0.5

Vcc could be a spec or an equation variable.

There is a limit of 256 level sets across all equation sets.

For detailed reference information on equation sets see Timing equation set reference.
