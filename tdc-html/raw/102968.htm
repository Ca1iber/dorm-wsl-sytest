Key Setup and Debug Workflows

  2. ADC test setup flow

Before starting the test setup, you must consider what the test requirements are and what resources are available.

The following are some examples of the questions that must be answered before you start to setup the test:

  • What category of device do I want to test?
  • What type of tests do I want to perform?
  • Do I already have a test system database for this device?
  • Do I have vectors/patterns available for the test?
  • Do I need to integrate external test equipment?
  • Do I have a suitable test system/DUT interface?
  • Are there any special requirements, maybe due to high clock rate?
  • What data logging requirements do I have?
  • Do I already know what test margins to apply?
  • What throughput do I hope to achieve?

When you have the answers to all such questions you are ready to proceed to the test setup phase.

Some key setup flows are introduced, which are performed in three main steps:

  1. Test planning, such as test methodologies, necessary test system resource performance, necessary system software functionality, and so on. (See Task 1: Test Planning)
  2. Preparation of a variety of test data on the system software. (See Preparing the Test Flow for the Measurement)
  3. Test execution, debugging and DUT characterization. (For examples, see Development procedure and tools and Memory test setup flow)
