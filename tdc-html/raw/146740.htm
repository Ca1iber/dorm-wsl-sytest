sampleCycle()

Specifies the number of tester cycles between two adjacent samples of the waveform to generate.

This function can be used only in pattern‑based mode.

Syntax

dcBase& sampleCycle(int iCycle);
Parameter

Parameter

Description

iCycle

The number of tester cycles.

Valid range:

Minimum is 32 vectors.

Return Value

A reference to the dcBase object.

Example

rdi.dc().pin("DCS_1")
        .vForce().waveform(wav).sampleCycle(1000).execute();

rdi.dc().pin("PS1600_1")
        .vForce(2 V).iMeas().samples(1024).sampleCycle(1000).execute();

Functional changes

  1. Introduced in SmartRDI 2.2.0
  2. SmartRDI 7.5.1: AVI64 supports a sample vector distance of 8 for the high-speed voltage AWG
