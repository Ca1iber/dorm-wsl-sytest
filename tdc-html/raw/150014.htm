Topic 150014

SPMU_PIN_TASK.measFilter()

Sets the measure filter for voltage and current measurements.

This member function is supported only for the DC Scale XPS256 card.

XPS256 channels feature programmable anti-aliasing, low-pass measure filters for voltage and current measurements. This member function sets the measure filter for the selected measurement mode that has been selected by SPMU_PIN_TASK.mode().

Syntax

SPMU_PIN_TASK& measFilter(double filterFrequency);
Paameter
Parameter Description
filterFrequency

Sets the filter to the given frequency in Hz or switches the filter off.

Programmable double values are

  • Value between the card-specific minimum and maximum value: The filter is set to the defined value.
  • 0.0: The filter is set to the card-specific default value.
Card-specific range and default value:
  • XPS256: Refer to section
    • Measurement filters in XPS256 programming - Measure voltages or to section
    • Measurement filters in XPS256 programming - Measure currents.
Return value
A reference to the SPMU_PIN_TASK object.

Application note

Measure filter settling time
The programmable digital low-pass measure filters for all ADCs behave like simple RC filters. A short settling time is to be applied or some samples are to be ignored to settle to an acceptable difference to the input signal.
The required settling time of the filter or the number of samples to be ignored depends on the accepted maximum relative error and the filter settings. The supported DC Scale cards show a slightly different behavior:
  • XPS256: Refer to the related application notes in topics Measure voltages or in Measure currents of the XPS256 programming overview.

Example

The following example shows how to set the measure filter.

SPMU_TASK spmuTask_1;

spmuTask_1.pin("...")
    ...
    ...
    .measFilter(100 kHz) // Set the measure filter to 100 kHz
    ;

Note: The example concentrates on the function described in this topic. More settings are required for an executable SPMU_TASK object.
