Topic 141813

Functional test setup

Subtopics

  1. FUNC
  2. Retrieving match loop results from user patterns

SmartRDI provides the func() class to do functional tests.

The func() class provides a series of functions to identify a burst pattern, assign ID to a pattern burst test, identify a label, specify a runtime label for each site, specify start and stop lines in a user pattern, and other features. See the subtopics for more detailed information.
Overview of func() class functions
Function Description Mode
rdi.func().burst() Specify an existing burst pattern to be executed in functional test. P
rdi.func().burstId() Assign an ID to a pattern burst test. After the testing, this function stores the pass/fail results of a pin, a group of pins, all pins or a port to the buffer. P
rdi.func().burstRunTime() Create an empty burst label and specify the maximum number of labels to be patched. P
rdi.func().label() Specify a label to be executed in functional test. P
rdi.func().labelRunTime() Specify a runtime label for each site. P
rdi.func().perLabelPassFail() Enable the retrieval of per label pass/fail results from the burst in the static mode. C
rdi.port(TA::MULTI_PORT).func() Insert multi-port labels to be combined together to form a new burst. P
rdi.func().startVec() Specify a start vector line in a user pattern. P
rdi.func().stopVec() Insert STOP in user pattern. P
rdi.getBurstPassFail() Retrieve the pass/fail result of a pattern burst test either on all pins or on a specific pin or port.
rdi.id().getLabel() Return the name of the label that is related with a specified result ID.
rdi.id().getBurstPassFail() Retrieve a burst pattern test result (pass/fail). The pass/fail result has been stored in the buffer by rdi.func().burstId().
rdi.id().getMultiPassFail() Retrieve per-label pass/fail results from all patterns in the burst.
rdi.id().getPassFail() Retrieve the pass/fail result of the functional test.
rdi.id().getMatchCount() Return the number of executed loops if a match is found on the specified pin.
rdi.id().getMatchPassFail() Return true if a match is found on the specified pin.
rdi.func().readMatchCount() Return true if a match is found on the specified pin.
rdi.func().readMatchPassFail() Return true if a match is found on the specified pin.

The pass/fail result of the specified label and burst pattern and the pass/fail result of the generated burst pattern can be retrieved by the get functions.

Example

ON_FIRST_INVOCATION_BEGIN(); 
  RDI_BEGIN(); 
      rdi.func("f1").label("PATT1").execute();
      rdi.func().burst("BURST1").execute();
  RDI_END(); 
ON_FIRST_INVOCATION_END(); 
int result1 = rdi.id( "f1" ).getPassFail(); //result for PATT1
int result2 = rdi.getBurstPassFail(); // result for PATT1 and BURST1
