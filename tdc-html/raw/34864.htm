Topic 34864

Data retrieval functions

If the data retrieval process is implemented as a function command set, it can be run by a call from the application model. As there is no designated call for data retrieval, you can use an EXEC_INP_CALL call instead. (See Application Model for further information.) The data retrieval function has to be installed in the appropriate command set directory.

As with any function called from the application model, a data retrieval function cannot be run in parallel like a program. This means that the next application model command will not be executed before the function has terminated.

Permanently retrieving production test result data, as with a program, is not possible with a data retrieval function. Yet, if data log data is required only at certain points of time or at certain levels of a production test, you should use functions instead of data retrieval programs, as functions execute significantly faster. If, for example, only wafer data is of interest, the data retrieval function could be called each time a wafer has been completely processed. The function could then retrieve the wafer specific data and afterwards clear the data log stream.

A data retrieval function can also be called from a test suite as a user procedure (if it is installed in the user procedure directory). This lets you perform a very specific retrieval of data after test suites or bins of special importance, for example.
