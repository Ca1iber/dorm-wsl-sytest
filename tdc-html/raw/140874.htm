The RESULT_AREA_CONFIG_PINS class holds the result area configuration properties of a list of pins. It provides methods to modify and query the settings such as digital and DC result area sizes. It is a sub-class of RESULT_AREA_CONFIG_SET class. You cannot directly create an object with the constructor.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/RESULT_AREA_CONFIG_PINS.h.

Syntax

This class has no constructor.

List of parameters

There are no parameters.

Return value

There is no return value.

Example

Example defining a DC result area and a digital capture area within the same result area config set. (Useful for burst tests, where different results are generated on the same pin).

//
// Define a new config
//
RESULT_AREA_CONFIG_SET burstResultAreaConfig("dc_and_capture_area_config");

//
// Configure the DC result area to be big enough for 16000 values
//
burstResultAreaConfig.pin("meas_pin").setDcValueResultAreaSize(16000);

//
// Configure the error map / digital capture area to be 128000 bytes in size
//
burstResultAreaConfig.pin("meas_pin").setErrorMapResultAreaSize(128000);

//
// Select the config for recording for the next test
//
burstResultAreaConfig.setAsPrimary(); 

EXECUTE_TEST();

//
// Restore recording focus back to the default areas
//
burstResultAreaConfig.deselectGlobally();

// Upload DC results via DC_RESULT_ACCESSOR("dc_and_capture_area_config");
// Upload capture results via SMC_GET_VECTORS(<vector var>, "dc_and_capture_area_config",...)
