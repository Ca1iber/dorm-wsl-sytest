EVENT_RDM.getLimitLow()

Reads the lower limit that has been defined by EVENT_RDM.limits() or EVENT_RDM.limitLow().

The value is read from the corresponding EVENT_RDM object and returned as an EVENT_VALUE_DOUBLE object.

Syntax

bool getLimitLow (EVENT_VALUE_DOUBLE & low)  const;
Parameter
Parameter Description
low The programmed lower limit of the pass range in Volts (V).
Return value
bool value indicating the state of the limit definition:
  • true: Limit has been defined by EVENT_RDM.limits() or EVENT_RDM.limitLow().
  • false: No limit is defined or the limit has been cleared by EVENT_RDM.clearLimits().

Example

For an example see EVENT_RDM.
