fillLeft(), fillRight()

Adds a specified character to a state character sequence to ensure a minimum length.

In combination with head() and tail() functions this can be used to create state character sequences of a defined length and content at the front or back of the sequence.

The function fillLeft() fills the character parameter from the left end till the total length is reached.

The function fillRight() fills the character parameter from the right end till the total length is reached.

The total length parameter has to be an integer value. The fill in character can by any valid state character.

If more than one character is used as fill character, an error is issued.

Syntax

sequence := fillLeft(sequence,total length ,character)
sequence := fillRight(sequence,total length ,character)
Parameter

I/O

Parameter

Description

I

sequence

Initial state character sequence to which the function is applied.

I

total length

Total length of resulting state character sequence.

I

character

Specifies the character to be filled in.

Example

fillLeft("001", 8, "X") results in "XXXXX001".

fillRight("001", 8, "X") results in "001XXXXX".

fillLeft("", 8, "0") results in "00000000".

fillRight("", 8, "0") results in "00000000".

fillLeft("0000", 3, "1") results in "0000".

fillLeft("1", 1+1+1, "1") results in "111".

fillLeft("", 0, "1") results in "".

fillLeft("1", 1, "12") results in "ERROR: more than one character given as 3rd parameter."
