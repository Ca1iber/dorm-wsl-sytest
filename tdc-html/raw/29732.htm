Topic 29732

SET_TEST_FOCUS

This API sets the specified sites in the currently-enabled sites to setup-focus state. This API can also set all enabled sites except for the specified single site to not setup-focus state simultaneously. The API returns also the previous state of sites.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SiteControl.h.

Note Setting the test focus by this API is supported for a limited selection of other APIs. Supported APIs are Primary.getLevelSpec(), Primary.getTimingSpec(), Analog.AWG(), Analog.DGT(), Analog.TIA(), and Vector(). For detailed information refer to Site-Specific Setup. The "each site loop block" or the "semi-parallel testing block" are to be used to manually control the setup focus or the query focus for other APIs. For more information refer to Controlling Multiple Sites.

Application note

  • For the APIs that set up conditions for the setup-focus state sites only and the APIs that always set up conditions for all sites, see API Behavior on Multi-Site Testing.
  • This API specifies which sites are addressed by the Setup APIs that follow, for performing site-specific setup.
  • This API is meaningful for multi-site testing, and is used in the first-invocation block enclosed by ON_FIRST_INVOCATION_BEGIN and ON_FIRST_INVOCATION_END, except for the FOR_EACH_SITE loop block. For single-site testing, this API generates a warning message to the report window, and the program execution continues to the next statement. In this case, the setting by this API except for site 1 is ignored. You can also ignore the warning message by using DISABLE_ERROR_MESSAGE.
  • If this API is executed to any disabled sites for setup-focus setting, it generates a warning message to the report window.
  • Changes of setup-focus state by SET_TEST_FOCUS and UNSET_TEST_FOCUS APIs are canceled automatically when the execution of the test method program finishes in the test suite.

Syntax

Boolean SET_TEST_FOCUS(INT singleSite, Boolean exclusive = TRUE);
ARRAY_I SET_TEST_FOCUS(ARRAY_I& arrayOfSites);
Parameter

I/O

Parameter

Description / Range

I

singleSite

A site to be set to setup-focus state.

I

exclusive

This optional parameter is used to decide whether all enabled sites except for the specified single site will be set to not setup-focus state or will be left unchanged.

You can omit this parameter.

  • TRUE: (Default.) Set other enabled sites to not setup-focus state.
  • FALSE: The state of other enabled sites remains unchanged.

I

arrayOfSites

An array pointed to sites to be set to setup-focus state.

Return value

Return value of syntax Boolean SET_TEST_FOCUS(INT site, Boolean exclusive = TRUE):

If you set a certain site to setup-focus state, this API can return the previous state of the specified site. The previous state is returned in Boolean type. If the previous state was setup-focus state, this API returns TRUE (1). Otherwise, this API returns FALSE (0).

Return value of syntax ARRAY_I SET_TEST_FOCUS(ARRAY_I& sites):

If you have set multiple sites to setup-focus state, the sites that were previously in setup-focus state can be returned to an array variable by this API.

Examples

Example 1: Get, change, and restore the setup focus of a site

ARRAY_I sites;
...
...
ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Get the site numbers of the currently setup-focused
    // sites and store them into the sites array.
    //
    GET_TEST_FOCUS(sites);

    //
    // Enable the setup focus on site 1.
    // Disable the setup focus on all other sites.
    //
    // Note: The setup focus for all other sites is disabled
    //       because the optional parameter "exclusive" is omitted.
    //       The default value = true is applied.
    //
    SET_TEST_FOCUS(1);

    //
    // Apply changes only to site 1.
    //
    AWG("ain").vOffset(5.0 V);

    FLUSH();

    ...
    ...

    //
    // Restores the state of all enabled sites to the original
    // state by using the contents of the sites array.
    //
    SET_TEST_FOCUS(sites);
}
ON_FIRST_INVOCATION_END();

Example 2: Change site focus and return previous site focus simultaneously

ARRAY_I prev_sites, new_sites;
...
...
ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Fill the array new_sites
    //
    new_sites.resize(2);

    new_sites[0] = 1;
    new_sites[1] = 2;

    //
    // Store the previously setup-focused sites into the prev_sites array.
    // Enable the setup-focus for the sites specified by the new_sites array.
    //
    prev_sites = SET_TEST_FOCUS(new_sites);

    //
    // Apply changes only to the sites defined by the new_sites array.
    //
    AWG("Ain").vOffset(2.5 V);

    FLUSH();

    //
    // Restores the setup-focus state of all enabled sites to the
    // original state by using the contents of the p_sites array.
    //
    SET_TEST_FOCUS(prev_sites);
}
ON_FIRST_INVOCATION_END();
