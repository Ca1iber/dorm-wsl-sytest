Topic 119613

Moving nodes

Before you begin

Make sure that the Flow Sequence Editor has been opened and a testflow has been loaded.

Procedure

  1. In the Flow Sequence Editor, select one or more nodes (press Ctrl and then click). The selected nodes are highlighted.
    Note To move the Run and Branch node and Flow control nodes, you must wide select them.
    Note Only nodes at the same level can be selected together.
  2. Select an insertion point not immediately adjacent to the chosen nodes, right-click and select Move.

Results

The chosen nodes have been moved to the location at the chosen insertion point.

What to do next

If you want to undo the moving action, press Ctrl + z.
