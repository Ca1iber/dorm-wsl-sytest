VPIN, VPIN? - (Virtual PIN)

The VPIN (Virtual PIN) command allocates a name for a virtual pin in the software. The virtual pin is not connected to a pogo pin, but can be used to log certain test results. Virtual pins cannot be members of ports or groups. The VPIN? query returns a list of virtual pins that have been defined.

VPIN

VPIN (pinlist)

VPIN?

VPIN? ([(pinlist) | @]}

Parameters

pinlist

The name to be allocated to the pin. The query returns the name of the virtual pins that have been defined. The @ symbol can be used with the VPIN? query to list all pins previously defined by the VPIN command. If you query a non-existent pin name, the system returns nothing.

Application

Creating virtual pins, see Virtual pins.

Errors

An error occurs if:

  • The specified pin name has already been defined for another pin (virtual or not), port, or group.

Example

  1. To define a virtual pin:
    > VPIN (VPIN1)
  2. To define multiple virtual pins:
    > VPIN (VPIN2,VPIN3)
  3. To list all defined virtual pins:
    > VPIN? (@)

    Returns:

    < VPIN (VPIN1,VPIN2,VPIN3)
  4. To check for the existence of specific virtual pins:
    > VPIN? (VPIN2,VPIN4,VPIN6)

    Returns:

    < VPIN (VPIN2)
