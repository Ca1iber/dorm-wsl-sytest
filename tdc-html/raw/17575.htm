Topic 17575

Editing a fixed group

Define a new fixed pin group from scratch or modify an existing fixed pin group.

Before you begin

Make sure that an fixed group has been created.

Procedure

  1. Open the setup editor of the fixed group you want to edit. If the group is a new one, there are no pins in the Group Member area.

    The Available Pin List shows all the defined digital pins and pin aliases in the form of pin_alias_set::pin_alias_name.

  2. Create or modify the list of the group members:
    • To create a group that may contain pins of any type (I, O, or DC), select Mixed Group.
      Note If you use the default configuration, that is, Mixed Group is not selected: If you add pins with different types to the group member list, SmarTest creates one group for each pin type with the same name. When you copy all input pins to a group, for I/O pins this means that only the I-component of the pin is copied to the group. An I/O pin, in that group, is then treated only as an I-pin (the same applies to O-components).
    • To add pins or pin aliases to the group, select one or more items (press Ctrl and then click) in the Available Pin List and click Add >.
    • To add all the pins to the group, click Add All >>.
    • To delete pins from the group, select one or more pins in the Group Members area and click < Remove.
    • To delete all the pins from the group, click << Remove All.
      Note To quickly find the pins you are interested in, filter the displayed pins using Filter line.
    • To change the order of the pins in the group, click ^ Up or v Down.
  3. In the Test Program Explorer, apply the data.
  4. Save the pin configuration file.

Results

You downloaded and saved the pin configuration group, and in the Available Pin List, the pins in the fixed group are indicated with "√".
