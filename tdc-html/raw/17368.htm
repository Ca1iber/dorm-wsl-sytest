Deleting Specification Sets

  1. Click Delete Specification Set in the Change pulldown menu.

    A screen similar to that of the figure below appears.

  2. Highlight the specification set you want to delete and click delete.
  3. Repeat this last step as often as required (for other specification sets), and click done when finished.
