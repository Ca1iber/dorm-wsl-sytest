Selecting a handler configuration file

Please see the user documentation of the handler to establish what the demands are.

Note The selection criteria are different, depending on the interface type.

Selecting a GPIO configuration If you need to select a configuration file for a handler that is to be supported by a GPIO interface, you must consider the following points:

  • Number of sites
  • Presence of global test start signal
  • Binning mode (parallel or serial)
  • Bin coding (explicit or encoded)
  • Number of bin lines
  • Number of bins
  • Definition of input/output lines
  • Test start and bin waveform

Please see the table below to select the driver configuration (plug-in "Universal-GPIO") which is most similar to your handler.

The section General Handler Driver contains detailed information about each handler, including the name and location of the configuration file.

There are two default configuration files for each default driver configuration: The handler-specific configuration and the Universal-GPIO configuration. The Universal-GPIO files are more extensive than the default files (for example, bin maps can be defined) and should be used for new configurations.

Selecting a GPIB configuration The following configuration files are available for the GPIB supported handlers:

  • <model>-GPIB-[1|2|3|4|8].cfg

    where [1|2|3|4|8] represents the number of sites.

The configuration files for each handler differ only regarding the number of sites. Select the configuration file for your handler model with the appropriate number of sites.
