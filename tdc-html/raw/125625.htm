TMU_PINS

Subtopics

  1. TMU_PIN measurement setup
  2. TMU_PIN measurement status
  3. Deprecated TMU_PINS methods

The TMU_PINS class holds the TMU settings for one or multiple pins. It also provides the functions to access and modify the TMU properties.

You cannot directly create the object for it. The member functions need to used after the TMU_TASK.pin() function.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TMUPins.h.

The TMU-PINS class methods are is documented under the following sections:

  • TMU_PIN measurement setup
  • TMU_PIN measurement status
  • Deprecated TMU_PINS methods
    Note The TMU_PINS upload methods are deprecated, but for compatibility reasons they are still usable.

    The recommended way for uploading results is to use the TMU_TASK upload methods, which also provide features for hidden upload:

    • TMU_TASK.uploadPeriodResults()
    • TMU_TASK.uploadRawResults()
    • TMU_TASK.uploadRawResultsFlat()
