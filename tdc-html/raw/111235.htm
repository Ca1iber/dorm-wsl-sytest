This TestsuiteProxy class is defined as a proxy to handle the current test suite. You can retrieve the test suite setup information, change the setup information and query the test suite execution status with it.

Constructor

TestsuiteProxy(const TestsuiteProxy& otherProxy);

This creates an object of TestsuiteProxy with copied content of otherProxy.

TestsuiteProxy& operator = (const TestsuiteProxy& );

This is assignment operator. It assigns the content of an TestsuiteProxy object to another object.
