EVENT_ICIM.getOutOfRangeCheck()

Queries the out-of-range check setting. Per default this check is on. If the check is enabled and the measurement range is exceeded, the event contributes with a FAIL to the global test result.

Syntax

void getOutOfRangeCheck( bool &  failOnOutOfRange ) const;
Parameter
Parameter Description
failOnOutOfRange

Possible values are: true | false

Return value

The setting of the failOnOutOfRange parameter.

Example

For an example see EVENT_ICIM.

Related information

EVENT_ICIM.outOfRangeCheck()

Functional changes

  1. Introduced in SmarTest 7.2.1
