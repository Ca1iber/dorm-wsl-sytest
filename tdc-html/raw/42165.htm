Topic 42165

Setting Up the Global Configuration

Subtopics

  1. Location of the Global Configuration File
  2. Editing the Global Configuration

The global configuration specifies which equipment specific plug-in and which driver configuration will be used by the general equipment driver (see Driver Structure).

At driver start-up, the global configuration file will be read. Then, the specified plug-in will be loaded into the driver, and the driver will be configured according to the definitions of the specified driver configuration file.

You can edit the global configuration file with a designated editor. This is described in Editing the Global Configuration.

The global configuration file contains two global configuration parameters. One holds the plug-in directory and the other the name of the driver configuration file.
