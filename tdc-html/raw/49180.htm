Topic 49180

Managing Test Numbers

Subtopics

  1. Test Number Generator and TMLimits
  2. Working with TMLimits
  3. Working with test tables
  4. Generating per-pin test numbers

V93000 test systems collect many measurements during testing. Each test checks a particular aspect of the device under test (DUT), for example, specific functionality, behavior under different operating conditions, or part functionality.

Because each test evaluates a different aspect of the DUT, test results must be individually identifiable and traceable. This requires that each and every test measurement is assigned a unique identifier.

In accordance with relevant industry standard, this identifier must be numeric, to ensure compatibility of the data with other tools used in the production process. (One example is the STDF standard, which requires a 4-byte unsigned integer.)

Test methods may contain multiple independent tests, with each test requiring its own unique identifier. Sections of a testflow may be looped over a set of differing conditions, and may also contain nested loops. The results from each iteration of the loops must be independently identifiable because of the condition sets being evaluated. This requires the results from each loop to have different test numbers.

SmarTest provides the Test Number Generator to generate test numbers. It is compatible with the popular TMLimits solution.
