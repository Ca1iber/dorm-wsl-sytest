Topic 102857

Test Method Parameters

About this task

If a test flow variable is referred from a Test Method parameter and the values of the variable are different for different sites, the test suite is treated as though it uses different setups for different sites. The sites which use the same testflow variable value are executed in parallel. The sites which use different testflow variable values are executed in serial.

Procedure

To avoid this when referring to a test flow variable, use the GET_USER_DOUBLE API as an alternative. This is shown in the following figure.
