TIMING_OFFSET_SEARCH_PINS.setConfiguration()

This function sets up the data to be used for the configuration.

Syntax

TIMING_OFFSET_SEARCH_PINS&   setConfiguration(TIMING_OFFSET_SEARCH::TimingOffsetConfigDataType & configdata);
Parameter

configdata

The configuration value. It includes the setting for:

search type, edge type, start value, step number, step width, resolution, minimum pass count (optional), transition detection type(optional), error count limit(optional) and restore flag(optional).

Functional changes

  1. Introduced in SmarTest 7.0.1
