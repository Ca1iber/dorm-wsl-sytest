XPS256 programming - Measure voltages

Each channel of an XPS256 card features two combined force, clamp, and measure voltage ranges.

Voltage measurement ranges

Each PMU features two combined force, clamp, and measure voltage ranges:

Variant Range Minimum and maximum voltage
XPS256 1.5 V1) -0.5 V ... 1.5 V
7.0 V -2.5 V ... 7.0 V

The voltage ranges are common for forcing, clamping, and measuring voltages. The force or clamp range is always the same as the measurement range. For specification data, refer to XPS256 voltage specifications. For the maximum current related to the voltage, refer to XPS256 voltage and current capability specifications.

Measurement filters

XPS256 channels feature programmable anti-aliasing, low-pass measurement filters for all ADCs:

  • Voltage measurement ADC of the PMU
  • Current measurement ADC of the PMU
  • Voltage drop measurements on the force line
  • Voltage drop measurements on the return line
Measurement filter characteristics
Minimum cutoff frequency: 10 Hz
Maximum cutoff frequency: 500 kHz
Default cutoff frequency: 30 kHz

The dynamic behavior of the force output is independent of the measurement filters.

Averaging

All channels of the card feature hardware based averaging of measurements. The average of multiple consecutive ADC samples is calculated and stored on board. Hardware based averaging can be utilized for code‑based and pattern‑based measurements.

Hardware-based averaging
Programmable range of samples: 1 ... 262144 (any value supported)
ADC sample frequency: 2 MHz2)

Some hints to consider:

  • The sample time for averaged measurements must be taken into account.
  • Pattern‑based measurements require a minimum number of vectors after the trigger has been initiated. For more information, refer to Timing of DC events and the related sub-topics.
  • The effective maximum sample frequency is the ADC sample frequency of 2 MHz2) divided by the number of averaged samples.
  • The "measurement filter" may be used instead of averaging if a high effective sample frequency is required. This filter behaves like a simple RC filter. The settling time is to be considered but the filter setting has no effect on the effective maximum sample frequency.
  • The dynamic behavior of the force output is independent of the settings for averaging.

SmartRDI overview

Voltage measurements can be controlled by the dc() API and the id() API of SmartRDI. Both the code‑based mode and the pattern‑based mode are supported. For more information refer to Setting up DC Scale pins with SmartRDI and the related member functions of the two APIs.

SmartRDI supports also setting up DC resources like a real digitizer. For more information refer to Using DC resources as digitizer with SmartRDI.

The complete functionality to set up an XPS256 pin to measure voltages is covered by APIs SPMU_TASK and SPMU_PIN_TASK for an XPS256 pin in PMU operating mode or by the Equation based level setup in combination with DPS_PIN_TASK for an XPS256 pin in DPS operating mode.

Pattern‑based measurements are supported by DC events3).

For information on how to perform measurements in digitizer mode refer to XPS256 programming - DGT.

Application notes

Flush vectors at the end of a pattern
Due to inter module communication it is required to keep the pattern running for a short time after the last ADC measurement related DC event. The actual required time or number of flush vectors depends on the setup. In case of insufficient number of vectors before pattern stop, a communication error might occur.

The number of required flush vectors depends on the average count and the pattern cycle time as follows:

Minimum number of vectors = 37 + ( average / (2 MHz * period) )

where: average = Programmed average count
period = Cycle time of the pattern

The calculated number is the minimum number of vectors that is required between the last measure event and the end of the pattern.

Measure filter settling time

The programmable digital low-pass measure filters for all ADCs behave like simple RC filters. A short settling time is to be applied or some samples are to be ignored to settle to an acceptable difference to the input signal.

The required settling time of the filter or the number of samples to be ignored depends on the accepted maximum relative error and the effective filter frequency and is calculated as follows:

Settling time

= -1.0 * ln (Maximum relative error) / (2 * π * Filter frequency)

Number of samples

= Settling time * Sample frequency
where:

Maximum relative error

= Maximum accepted relative error at the end of the settling time

Filter frequency

= Programmed filter frequency

Sample frequency

= ADC sample frequency4)

ln

= Natural logarithm

Functional changes

  1. Introduced in SmarTest 7.10.1
1) A license is required to use the 1.5 V range: See High‑accuracy voltage mode in XPS256 specific setup tasks.
2) The sample frequency of 2 MHz applies only to the hardware based averaging. Transferring the averaged values to the test processor memory is supported for a sample frequency of maximum 1.5 MHz.
3) Since the raw supply of the output stage must also be set, changing of the common range for forcing and measuring voltages is supported only in code‑based mode. In pattern‑based mode, the related DC event is silently ignored and the range is not changed.
4) 1.5 MHz is the maximum programmable sample frequency. Programming a lower sample frequency means that samples of the continuous stream provided by the digital closed loop control are skipped. Although the resulting sample frequency will then be lower than 1.5 MHz and sampling on XPS256 is performed with an ADC frequency of 2 MHz, the settling time derives only from the programmed filter frequency.
