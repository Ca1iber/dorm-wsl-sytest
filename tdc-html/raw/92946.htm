DSP_RF_MOD_POWER()

This function is used to measure the power of a modulated signal. The result is calculated by the following equation:

10*log10( (I^2 + Q^2)/50.0 * 1000.0).

Any losses due to downconversion of the signal are accounted for by the RF calibration.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_RF_MOD_POWER(const ARRAY_COMPLEX & sourceData,
                     const ARRAY_D       & measParams,
                           DOUBLE        * measuredPower_dBm);

    DSP_RF_MOD_POWER(const ARRAY_COMPLEX & sourceData,
                     const ARRAY_D       & measParams,
                     const INT             outputMode,
                           DOUBLE        * measuredPower);

    DSP_RF_MOD_POWER(const ARRAY_COMPLEX & sourceData,
                    const ARRAY_D       & measParams,
                     const INT             outputMode,
                     const INT             site,
                           DOUBLE        * measuredPower);

    DSP_RF_MOD_POWER(const ARRAY_COMPLEX & sourceData,
                     const ARRAY_D       & measParams,
                           DOUBLE        * measuredPower_dBm, 
                           ARRAY_D       & spectrumData);

    DSP_RF_MOD_POWER(const ARRAY_COMPLEX & sourceData,
                     const ARRAY_D       & measParams,
                     const INT             outputMode,
                           DOUBLE        * measuredPower_dBm, 
                           ARRAY_D       & spectrumData);

    DSP_RF_MOD_POWER(const ARRAY_COMPLEX & sourceData,
                     const ARRAY_D       & measParams,
                           DOUBLE        * measuredPower_dBm, 
                           ARRAY_D       & spectrumData,
                           INT           * startBin,
                           INT           * stopBin);

    DSP_RF_MOD_POWER(const ARRAY_COMPLEX & sourceData,
                     const ARRAY_D       & measParams,
                     const INT             outputMode,
                           DOUBLE        * measuredPower_dBm, 
                           ARRAY_D       & spectrumData,
                           INT           * startBin,
                           INT           * stopBin);

    DSP_RF_MOD_POWER(const ARRAY_COMPLEX & sourceData,
                     const ARRAY_D       & measParams,
                     const INT             outputMode,
                     const INT             site,
                           DOUBLE        * measuredPower_dBm, 
                           ARRAY_D       & spectrumData,
                           INT           * startBin,
                           INT           * stopBin);
Parameters

I/O

Parameter

Notes

I

sourceData

A complex array representing the captured waveform data in the time domain.

I

measParams

An array of doubles which contains information about the properties of the measurement definition, together with frequency-dependent calibration data.

O

measuredPower_dBm

Measured waveform power (dBm), integrated over the bandwidth specified in the measParams array

O

spectrumData

An ARRAY_D (array of doubles) representing the source data (in dBm) in the frequency domain.

I

outputMode

set the unit of the result in DB, DBM, VOLT or WATT

I

site

Site ID

O

startBin

The bin number representing the start of the measurement span for spectrumData. The value depends on the bandwidth of the measurement, and can be used in plotting the spectrum data (so that only the valid part of the spectrum is shown.)

O

stopBin

The bin number representing the end of the measurement span for spectrumData. The value depends on the bandwidth of the measurement, and can be used in plotting the spectrum data (so that only the valid part of the spectrum is shown.)

Example

ARRAY_COMPLEX cData = MEAS_DEF("myModPwrMeas").getComplexWaveform(); 
ARRAY_D measParams = MEAS_DEF().getParameters(1,0);  
DOUBLE measuredPower = 0;
DSP_RF_MOD_POWER(cData, measParams, &measuredPower);

The results could be printed to the report window as follows: 

cout << "Measured " << measuredPower << " dBm" << endl;
