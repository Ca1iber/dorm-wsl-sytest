Defining external triggers for DPS measurements

If you plan to perform DPS current measurements using the external trigger, you have to tell the test system software about the connection for the trigger.

Before you begin

The DPS TR+ and TRVB- pins are wired to the required test system channel.

Procedure

  1. In the Digital Pins editor, define a dummy pin for the DUT:
  2. Enter a relevant pin name such as ext_trig.
  3. Set the type as i.
  4. Enter the pre-assigned tester channel number.

Results

The tester channel number can now be referenced in order to apply the vectors.

What to do next

Apply vectors to this dummy pin. These vectors will then be interpreted as a trigger for the DPS current measurement.
