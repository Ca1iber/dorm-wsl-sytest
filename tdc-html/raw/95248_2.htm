Topic 95248

Logging output

To enable you to analyze the results of a Source Sync test method you must save them to the data log.

About this task

To save the Source Sync test results into the data log follow the procedure below.

Before you begin

You have to set the report formatter to Event Formatter, as described in How to Activate the Event Formatter.

Procedure

  1. Set the System flags:

    log_events_enable to On

    data log_to_report_win to On

  2. Set either of the output_on_pass or output_on_failTest suite flags to On.
  3. In the test method's parameter dialog, do either of the following:
    • Enter a margin limit in the result parameter dialog.
    • Enable at least one of the OutputErrorMap, Output Histogram, or OutputMargin debug output options in the parameter dialog.

Results

When you run the test method, data logging is activated.

Example

Results reported in the report window:

Executed Testmethod : PASSED
-------- Source sync group: DQA0_PS,DQS_A_n_PS,DQS_A_p_PS: PASSED --------------
