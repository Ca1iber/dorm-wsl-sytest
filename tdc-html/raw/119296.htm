DSP_RF_GET_RF_MEAS_TYPE()

The DSP_RF_GET_RF_MEAS_TYPE allows the user to get the measurement type from the measurement parameters that belong to the sequence block. The values of 'measType' are the same as above.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_RF_GET_RF_MEAS_TYPE(const ARRAY_D& measParams, INT* measType);

Parameters

I/O

Parameter

Notes

I

measParams

Array of measurement

O

measType

type of measurement;

TM::RF_MEAS_CW_POWER

TM::RF_MEAS_MOD_POWER

TM::RF_MEAS_PHASE_NOISE

TM::RF_MEAS_NOISE_FIGURE

TM::RF_MEAS_SPARAM

TM::RF_MEAS_RETURN_LOSS

 
This allows the user to get the measurement type from the measurement
				parameters that belong to the sequence block. The values of 'measType' are the same as
				above.

		
Example
ARRAY_D measParams = MEAS_DEF("name").getParameters(1,0);
Int measType;
DSP_RF_MEAS_GET_RF_TYPE(measParams;&measType);
if (measType==TM::RF_MEAS_CW_POWER)
{ 
    DSP_RF_CW_POWER(...);
}
else....
