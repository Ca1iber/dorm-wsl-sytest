Topic 99902

Selecting setup files

You must select all elevant setup files for the whole testflow before you can define the test suites in the testflow.

Before you begin

Make sure that the Testflow Tool is open and the setup files have been created.

Procedure

  1. To select the pin configuration file:
    1. On the Setups page of the Flow Data Editor, double-click the File column of the Pin Configuration row to enter the cell editing mode.
    2. Press Ctrl + Space to display the list of existing pin configuration files appears.
    3. Select the desired file in the list.
  2. Select the other setup files in a similar way.

Results

The setup files for the testflow have been selected.

What to do next

Load all setup files.

  • To load all setup files, on the Setups page, right-click and select Load All Setups.
  • To load one setup file, for example, level setup file, on the Setups page, right-click the level file and then select Load Level.

If necessary, you can also edit the setup file by starting the setup tool from the Setups page. For example, to edit the timing setup file, on the Setups page, right-click the timing file and select Open Timing Setup.
