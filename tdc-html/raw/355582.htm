Topic 355582

rdi.id().getAlarmValue()

Gets alarm DC results on specified pins per id.

Syntax

double getAlarmValue(string sPin);
List of parameters
Parameter Description
sPin Pin name.

Example

RDI_BEGIN();
...
  rdi.dc("a").pin("dig").iForce(0).vMeas().execute();
...
RDI_END();

double dVal = rdi.id("a").getAlarmValue("AVI");
ARRAY_D aryVal = rdi.id("a").getAlarmBurstValue("AVI");

Related information

rdi.id().getAlarmPassFail()

Functional changes

  1. Introduced in SmartRDI 7.10.3
