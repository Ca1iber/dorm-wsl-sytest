EVENT_VCIM.vClampLow()

Sets the lower clamp voltage.

Only one of the two values can be set per DC event. The lower clamp voltage, defined by this member function, and the upper clamp voltage, defined by EVENT_VCIM.vClampHigh(), must be set in separate DC events.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

EVENT_VCIM & vClampLow(const EVENT_VALUE_DOUBLE & value);
Parameter
Parameter Description
value

Defines the lower clamp voltage to be set in V (Volt).

Return value

A reference to the corresponding EVENT_VCIM object.

Example

For an example see EVENT_VCIM.
