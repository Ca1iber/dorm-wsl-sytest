Topic 355082

Adding a user account to a virtual machine

Add a user in the virtual machine and configure its connection the virtual machine using the new user account.

About this task

As the creator of the virtual machine, you can add a new user to enable colleagues to also access the virtual machine.

VNC Viewer is used as the VNC client in this procedure. You can use other VNC clients as you prefer. For details on using other VNC clients, see their documentation.

Procedure

  1. Generate a public and private key pair in PuTTYGen and save the key files.

    See Generating and saving key files for details.

  2. Open VNC Viewer.
  3. Log in to the virtual machine.

    See Connecting to a virtual machine via VNC for details.

  4. Right-click the desktop of the virtual machine and click Konsole in the menu.

    The Konsole window opens.

  5. In the Konsole window, enter sudo /usr/sbin/useradd new_user_name to add a new user.

    new_user_name is the user name for the account that you create.

  6. Enter sudo su - new_user_name to switch to the new user.
  7. Enter cd ~/.ssh/ to switch to the .ssh directory of the new user.
  8. Create a key configuration file on the virtual machine.
    1. Enter vi authorized_keys to create a file named authorized_keys.

      The file is opened in the vim editor.

    2. Press i on your keyboard.

      The vim editor switches to edit mode.

    3. Copy the public key content generated in step 1 from your computer, paste it into the vim editor on the virtual machine.
    4. In the vim editor, press esc to exit edit mode.
    5. Enter :wq! and press Enter to save the file and return to the Konsole window.
  9. In the Konsole window of the virtual machine, enter chmod 600 authorized_keys to modify the access permission of the file.

Results

A new user account has been created on the virtual machine and is ready to be used.

What to do next

The colleague now can connect to the virtual machine with the following steps:

  1. Configure the remote connection to the virtual machine with the PPK file generated in step 1.
  2. Connect to the virtual machine via SSH using the user name the creator specified in step 5.
  3. To connect to the virtual machine with a VNC client, set up the VNC connection and connect to the virtual machine via VNC.
