MTP_MEMORY_PATTERN.getPassFailResult()

Retrieves the pass/fail test result of the current pattern that is specified with getMemoryPattern() and tested with MTP_MEMORY_TEST.

Syntax

bool getPassFailResult() const;

List of parameters

There are no parameters.

Return value

Returns true or false.

Related information

MTP_MEMORY_PORT.getMemoryPattern()
MTP_MEMORY_TEST

Functional changes

  1. Introduced in MTP 3.2.1
