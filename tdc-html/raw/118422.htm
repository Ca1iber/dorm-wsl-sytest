Topic 118422

PRDF, PRDF? - (PRBS set DeFinition)

PRDF creates a PRBS set by defining a unique name for it. PRDF? returns the names of all defined PRBS sets.

A PRBS set can be associated with a mode context. The primary PRBS set (as defined with PRPR) must be associated with the same context as the other primary sets.

PRDF

PRDF {"prbs_set_name"} [, "mode_context"]

PRDF?

PRDF? ["prbs_set_name"]

returns:

PRDF {"prbs_set_name"} [, "mode_context"]

Parameters

prbs_set_name

In the command, this is the name of a new PRBS set. In the query, it is a name of an existing PRBS set. If you omit this parameter in the query, PRDF? will return the names of all user defined PRBS sets.

mode_context

The mode context with which the PRBS set is associated. If this parameter is omitted, the DEFAULT context is assumed.

Application

PRBS test.

Errors

An error is generated if a PRBS set with this name already exists.

Example

> PRDF   "prbs_set1"
> PRDF   "prbs_set2"
> PRDF   "prbs_set3"
> PRDF?
< PRDF   "prbs_set1"
< PRDF   "prbs_set2"
< PRDF   "prbs_set3"

Functional changes

  1. Introduced in SmarTest 7.0.1
