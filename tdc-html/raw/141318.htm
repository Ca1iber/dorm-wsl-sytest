Topic 141318

pin()

Specifies the pins for the following DC actions. It indicates the ending of the setups for the previous pin and the start of the setups for the specified pin.

Do not specify different types of pins in the same function pin(). To set up different types of pins in the same line of code, specify different types of pins in separate functions of pin() with the same execute().

Syntax

pin(const string& sPin);
List of parameters
Parameter Description
sPin The pin on which the following setups will be done. Its value can be a pin, a pin group, a port name as a pin group, the pins or pin groups separated with comma, or all pins.

Example

rdi.dc("vMeas").pin("pinA").vMeas().execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 2.4.0: Support a port name as a pin group.
