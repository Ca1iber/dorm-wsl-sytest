TOUD - (Timing Offset UnDefine)

The TOUD command removes the embedded timing search configuration for the specified pins on all sites that have the setup focus (defined with PSFC).

Syntax

TOUD {(pinlist)}

Parameters

pinlist

The pins for which the embedded timing search configuration is to be removed.

Application

Embedded timing search.

Example

TOUD (Pin1, Pin2)

Functional changes

  1. Introduced in SmarTest 7.0.3
