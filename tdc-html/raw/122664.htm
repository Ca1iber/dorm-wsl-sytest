d2s_LABEL_BEGIN

d2s_LABEL_BEGIN() marks the start of a d2s-block.

It defines how the to be generated (multi-)port burst will be named (identifier), if it should be generated (mode) and how the (multi-)port burst will be executed (execMode).

Syntax

void d2s_LABEL_BEGIN(std::string identifier, d2sFrameWorkModeType::Enum mode,
                     d2sExecutionModeType::Enum execMode=d2sExecutionModeType::FUNCTIONAL_TST);
Parameters

I/O

Parameter

Description/Range

I

identifier

Defines the unique name of the burst (single or multi burst) to be generated.

I

mode

Defines the mode of the framework.

d2sFrameWorkModeType::LearningMode :Labels will be saved to the vector directory and the corresponding burst label is generated.

d2sFrameWorkModeType::ProductionMode : framework will skip the protocol transactions between d2s_LABEL_BEGIN and d2s_LABEL_END. It only will execute the burst labels generated during learning mode.

I

execMode

Defines the API that is used to execute the d2s-label.

d2sExecutionModeType::FUNTIONAL_TST: FUNTIONAL_TEST() (default)

d2sExecutionModeType::EXECUTE_TST: EXECUTE_TEST()

d2sExecutionModeType::DIGITAL_CAPTURE_TST: DIGITAL_CAPTURE_TEST()

Example

In learning mode this example will generate two static write pattern and burst them together under MyBurstLabelName.

In production mode only the MyBurstLabelName pattern will be executed.

virtual void run()
{
   d2sFramework fr;
   d2sJTAG& jtag = d2sJTAG::Instance();

   // Register your protocol with the framework
   fr.registerTransactionPort(jtag);

   ON_FIRST_INVOCATION_BEGIN();
      fr.d2s_LABEL_BEGIN("MyBurstLabelName", d2sFrameWorkModeType::LearningMode);
         jtag.write(0xdead, 0xbeaf);
         jtag.write(0xabcd, 0xef);
      fr.d2s_LABEL_END();

      // do your measurement here

   ON_FIRST_INVOCATION_END();
   ...
}
