loadStepMode()

Selects a load step mode to adapt the dynamic behavior of a DC Scale pin.

This function can be used only in the code‑based mode.

This function supports only DC Scale XPS256 card in the PMU operating mode.

Syntax

dcBase& loadStepMode(TA::LOAD_STEP_MODE mode);
Parameter
Parameter Description
mode

Load step mode of type TA::LOADSTEP_MODE to be set.

Supported values:
  • TA::LOADSTEP_STANDARD
  • TA::LOADSTEP_FAST

Default value for the DC Scale XPS256 card is TA::LOADSTEP_STANDARD.
Return Value
A reference to the dcBase object.

Example

rdi.dc().pin("XPS256_PMU_1")
        .iForceRange(50 mA).iForce(5.0 mA)
        .vClamp(-5.0, 5.0 V)
        .loadStepMode(TA::LOADSTEP_FAST)
        .execute();
