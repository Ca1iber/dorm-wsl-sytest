DSP_DIFF

This API calculates the difference between adjacent elements in the specified array.

The DSP_DIFF API calculates the difference between adjacent elements in src and return the results to result as follows:

result [i]  = src [i+1] - src [i]

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_DIFF(ARRAY_I& src, ARRAY_D& result);
DSP_DIFF(INT *src, DOUBLE *result, INT size);
DSP_DIFF(ARRAY_D& src, ARRAY_D& result);
DSP_DIFF(DOUBLE *src, DOUBLE *result, INT size);
Parameters

I/O

Parameter

Description / Range

I

src

Source array

O

result

Difference

size - 1 ≤ size of result

I

size

Number of elements to be processed

2 ≤ size ≤ 2097152

size ≤ (size of source array)

Example

double array1[100], array2[100];
  .
  .
DSP_DIFF( array1, array2, 100 );

DSP_DIFF does the following:

array2[k] = array1[k+1] - array1[k]

k = 0, 1,..., 99
