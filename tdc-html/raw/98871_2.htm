WFDF, WFDF? - (WaveForm DeFinition)

The WFDF command defines a logical waveform with at most 6 edges within a waveform set (fixed timing). The WFDF? query returns the existing logical waveform definitions; note that it only retrieves the first 6 edges of the waveform.

Mode of operation

If the specified waveform index is already in use, WFDF overwrites the previous definition. This causes all previously defined physical waveforms for this logical waveform to be undefined. You have to define all of them for the modified logical waveform again (with the WAVE command).

The command will not be accepted if the edge order restrictions are not fulfilled for the used edges. If the position of an unused edge does not meet the order requirements implied by the new definition string, it will be auto-corrected. Edges which are already used in other waveforms will not be moved. Edge restrictions are discussed in Selecting and ordering edges.

Postrequisites

After you have defined the logical waveform with WFDF, you must specify the physical waveforms that are based on it with the WAVE command. This is required even if the logical waveform contains no data parameters.

WFDF

WFDF {wvf_set}, {wfIndex}, {a1}, {a2}, {a3}, {a4}, {a5}, {a6}, {(pinlist)}

WFDF?

WFDF? {wvf_set|"wavetable"|specset_id|"multiport_spec"}, {wfIndex}, [mode], {(pinlist)}

returns: 

WFDF {wvf_set|"wavetable"|specset_id|"multiport_spec"}, {wfIndex}, {a1}, {a2}, {a3}, {a4}, {a5}, {a6}, {(pinlist)}
Parameters

wvf_set

Waveform set number. Enter an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by WSUS, WSUS? - (Waveform Sets USed). For the query command you can also enter ALL for all waveform sets.

wavetable

The wavetable name. Enter a string of up to 40 alphanumeric characters (upper or lower case) enclosed in double quotes.

specset_id

Derived as follows:

100 * equation_set_no + specset_no

multiport_spec

To query a multiport specification, enter the name of the specification.

wfIndex

Waveform index. Enter an integer between 0 and 31. The index references a waveform in a device cycle. For the query command you can also enter ALL for all waveform DC/DC power units. The waveform index is also used by the WAVE commands.

a1 to a6

Drive and compare actions, one per edge. There are drive actions that are fixed (drive to a certain fixed level) and receive actions that are fixed (compare to a certain fixed level). You can also drive to two drive data parameters (DD1 and DD2), and compare to two expected data parameters (ED1 and ED2).

Note that no tri-state actions, either defined or implied, are allowed on edges 2 or 5. For details, refer to Restrictions for drive edges.

On the drive data side the actions you can define are:

  • N: No action
  • F0N: Drive 0, no tri-state action
  • F1N: Drive 1, no tri-state action
  • FN0: No drive action, tri-state off
  • FNZ: No drive action, tri-state on
  • F00: Drive 0, tri-state off
  • F0Z: Drive 0, tri-state on
  • F10: Drive 1, tri-state off
  • F1Z: Drive 1, tri-state on
  • D1N: Drive parameter 1 (DD1), no tri-state action
  • D1N: Drive parameter 2 (DD2), no tri-state action
  • C1N: Drive complement of parameter 1 (DD1), no tri-state action
  • C2N: Drive complement of parameter 2 (DD2), no tri-state action
  • DN1: No drive action, tri-state parameter 1 (DD1)
  • DN2: No drive action, tri-state parameter 2 (DD2)
  • D11: Drive parameter 1 (DD1), tri-state parameter 1 (DD1)
  • C11: Drive complement of parameter 1 (DD1), tri-state parameter 1 (DD1)
  • D22: Drive parameter 2 (DD2), tri-state parameter 2 (DD2)
  • C22: Drive complement of parameter 2 (DD2), tri-state parameter 2 (DD2)

On the expected data side the actions you can define are:

  • N: No action
  • E0: Edge compare to 0
  • E1: Edge compare to 1
  • EI: Edge compare to intermediate
  • EX: Edge compare to mask
  • EU: Edge compare to unstable
  • C: Capture digital data (selective digital capture)
  • D: Do not capture digital data (selective digital capture)

    Note that waveforms that are to be used for selective digital capture must contain exactly one compare action.

  • W0: Window open with compare to 0
  • W1: Window open with compare to 1
  • WI: Window open with compare to intermediate
  • WX: Window open with compare to mask
  • WU: Window open with compare to unstable
  • WC: Window close
  • EE1: Edge compare to parameter 1 (ED1)
  • EE2: Edge compare to parameter 1 (ED2)
  • WE1: Window open with compare to parameter 1 (ED1)
  • WE2: Window open with compare to parameter 1 (ED2)

pinlist

The name of the pin or pins for which the waveform is to be defined or read back. This parameter can also include groups previously created by DFGP, DFGP? - (DeFine GrouP). The @ symbol can be used to specify all configured pins. If more than one pin is to be included, the names must be separated with commas.

Application

Timing setup, see Timing Setup Commands.

Errors

An error is generated if:

  • wvf_set_no is greater than the range allowed by the WSUS command.
  • wvf_set_no is smaller than one.
  • The waveform index is outside the range of 0-31
  • There is a mismatch between the edge actions and edge order in the specified waveform.
  • You specify a drive action for an output pin.
  • You specify a receive action for an input pin.
  • There is a mismatch in edge direction between the waveform you have defined and existing waveforms.
  • There is a missing window close action between two window open actions.
  • There is a missing window open action between two window close actions.
  • FN0 or FNZ are data parameters of edges 2 or 5, or if there is an implicit generation of a tri-state on edges 2 or 5 (tri-state error).
  • specset_id is invalid because equation_set_no, specset_no, or both are invalid.
  • specset_id does not reference a defined wavetable.
  • multi-port_spec does not reference a defined multiport specification.

Warnings

A warning is generated if edge delays are auto-corrected to fit in with the programmed waveform. The timing sets belonging to the affected waveform set are modified as necessary.

Example

> WFDF 1,2,N,N,D11,N,N,N,(D0,D2,D2,D3)

This example defines a waveform referenced by waveform index 2. The waveform uses the drive data and tri-state parameter 1. Edge number 3 provides the timing for this waveform. The definitions are made for waveform set 1 and for pins D0 to D3.
