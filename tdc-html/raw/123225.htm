Topic 123225

Smith Chart format setting

About this task

This task describes how to change the Smith Chart appearance.

Before you begin

Make sure that the Signal Analyzer is open and you have a Smith Chart in the Signal Analyzer in focus.

Procedure

  1. Open the Format Dialog of the Signal Analyzer tool
  2. Select Smith
  3. Select a Graph Type

    The following picture illustrates how to access the Smith Chart Tool

    By default the reflection coefficients are displayed on Impedance Charts (so-called Z Smith Chart). However it is possible to switch to an Admittance Chart (so-called Y Smith Chart) or to a Gamma Chart (polar form). Even overlaid is allowed. For instance, one can turn on Impedance Chart and Admittance Chart simultaneously by setting the visibilities accordingly. It is also possible to customize the grid color and the grid label visibility.

    You can use the shortcut menu of the of a Smith Chart to quickly change the Chart Type.

    • Right Click the Smith Chart and select menu ->format -> Quick Format to access Quick Format Dialog
    • Select a desired Chart Type.
