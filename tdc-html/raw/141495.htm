MTP_MEMORY_PORT.print()

Prints out the memory test results of the current port.

The port is specified with getMemoryPort().

Syntax

void print (ostream & out = std::cout) const;
Parameter

Parameter

Description

out

The data stream to be printed out. The default output is stdout.

Return value

There is no return value.

Related information

MTP_MEMORY_TEST.getMemoryPort()

Functional changes

  1. Introduced in MTP 3.2.1
