Topic 81302

GeneralPMU

This is a general test method for performing DC measurements with the Pin PMU.

You can force a current and measure the voltage, or you can force a voltage and measure the current. The actual operating mode of the PMU is dependent on the external load as well as the programmed parameters.

For PPMU parallel voltage test, the tester class is retrieved. If the test is on Pin Scale test system, the PPMU clamp voltages will be set according to the parameter ppmuClampLow and ppmuClampHigh. If ppmuClampLow and ppmuClampHigh are specified, clamp low and high are set as input. Otherwise, lower limit value and upper limit value are used accordingly. The PPMU clamp is ON during PPMU relay switching. When the PPMU relay is ON, the clamp is turned OFF and kept OFF during the PPMU measurement. (For details of clamp sequence, refer to PPMU voltage clamp on Pin Scale systems.)

This test method supports test table. But you need to enter the test names manually in the parameter. You can use both test table and testflow limits in a testflow. The test table has higher priority than testflow limits. If a test name used in the test flow is defined in both test table and testflow limits, the value defined in the test table will be used.

This test method also allows you to set the test system state in which the measurement is made. You can use the following test system states:

Test System States in dependency of the Termination

Test System State

Termination OFF

Termination ON

CONNECTED
  • Connects the test system before executing the test method; if the test system is already connected (connect flag set) the connect sequence is not executed.
  • The AC relays are opened before and during the measurement. After the measurement, the AC relays are closed.
  • The PMU is connected to the pogo pin during the measurement. After the measurement, the PMU is disconnected from the pogo pin.
  • Connects the test system before executing the test method; if the test system is already connected (connect flag set) the connect sequence is not executed.
  • The AC relays remain closed during and after the measurement.
  • The PMU is connected to the pogo pin during the measurement. After the measurement, the PMU is disconnected from the pogo pin.

DISCONNECTED
  • Disconnects the test system before executing the test method; if the test system is already disconnected (connect flag not set) the disconnect sequence is not executed.
  • The AC relays remain opened before and during the measurement. After the measurement, the AC relays are closed.
  • The PMU is connected to the pogo pin during the measurement. After the measurement, the PMU is disconnected from the pogo pin.
  • If the tester state was in the DISCONNECT state (connect flag not set) before executing the measurement, the tester state will remain in the DISCONNECT state even though the pins that were part of the measurement will have the AC relays closed (connected) after the measurement.
  • Disconnects the test system before executing the test method; if the test system is already disconnected (connect flag not set) the disconnect sequence is not executed.
  • The AC relays remain opened during and after the measurement.
  • The PMU is connected to the pogo pin during the measurement. After the measurement, the PMU is disconnected from the pogo pin.

UNCHANGED
  • Leaves the state (CONNECTED or DISCONNECTED) unchanged from its previous setting, when the test is executed. This is the fastest option.
  • The AC relays are opened before and during the measurement. After the measurement, the AC relays are closed.
  • The PMU is connected to the pogo pin during the measurement. After the measurement, the PMU is disconnected from the pogo pin.
  • Leaves the state (CONNECTED or DISCONNECTED) unchanged from its previous setting, when the test is executed. This is the fastest option.
  • The AC relays remain unchanged during and after the measurement.
  • The PMU is connected to the pogo pin during the measurement. After the measurement, the PMU is disconnected from the pogo pin.

Dependencies

  • Typically, the device should be kept in a stable condition by applying a suitable waveform.
  • The direction of the current is specified by the sign of the forced value (positive current flows into the DUT pin, negative current flows out of the DUT pin).
Parameters

Parameters

Type

Description

pinlist

PinString

Name of pins to be tested. This can be @ for all applicable pins, or any number of applicable single pins. Valid pin types include all digital pins.

forceMode

string

Selects between forcing a current and forcing a voltage. It will select the units for forceValue and spmuClamp automatically, [mV] for voltage and [uA] for current.

VOLT - force voltage and measure a current.

CURR - force current and measure a voltage.

forceValue

SpecValue

Value of force voltage (for VFIM test) or value of force current (for IFVM test).

precharge

string

Enable/disable precharging.

ON - enable

OFF - disable

prechargeVoltage

SpecValue

Value of precharging voltage.

settlingTime

SpecValue

Value of settling time. The settling time will be in addition to the settling time calculated by the system.

testerState

string

Tester state for the measurement.

CONNECTED - connects the test system before executing the test method; if the test system is already connected (connect flag set) the connect sequence is not executed.

DISCONNECTED - disconnects the test system before executing the test method if the test system is already disconnected (connect flag not set) the disconnect sequence is not executed.

UNCHANGED - leaves the test system state (CONNECTED or DISCONNECTED) unchanged from its previous setting, when the test is executed. This is the fastest option.

termination

string

Select if the test is performed with or without termination.

ON - with termination. The o pins and io pins specified in the pin list of the general PMU test method are terminated with the driver. It will close the AC relays for these pins.

OFF - without termination.

measureMode

string

Defines measurement mode.

PPMUpar - PPMU parallel.

PPMUser - PPMU serial.

relaySwitchMode

string

Used in case of no termination.

BBM - break before measurement(open AC relay, then close PMU relay).

MBB - measure before break (close PMU relay, then open AC relay).

PARALLEL - open AC relay and close PMU relay in parallel.

ppmuClampLow

SpecValue

The PPMU low clamp voltage in V. If the value is 0 or not specified, the low clamp voltage is set to low limit.

It is only available for the test of PPMUpar mode on Pin Scale system. It is ignored in other test conditions.

ppmuClampHigh

SpecValue

The PPMU high clamp voltage in V. If the value is 0 or not specified, the high clamp voltage is set to high limit.

It is only available for the test of PPMUpar mode on Pin Scale system. It is ignored in other test conditions.

output

string

Controls how to output the per pin test result. It can be:

  • None: Do not output the per pin result.
  • ReportUI: Output all the per pin result to the report window.

ShowFailOnly: Only outputs the failed pin result to the report window.

testName

string

The test names to be used as limits. Default is passLimit_uA_mV.

If you want to use the test names defined in the test table or testflow limits, type in the test names manually. Make sure the test names are in the Test name column of the test table (Refer to Structure of a TMLimits CSV file) or in the Test Name column of Tests page of Flow Data Editor.

Limit

passLimit_uA_mV

The pass range of the measured current or voltage

Implementation pseudo code

IF connected state selected THEN
  connect DUT
ELSEIF disconnected state selected THEN
  disconnect DUT
ENDIF
IF PPMU parallel measurement THEN
  program PPMU with specified values
  switch AC, PPMU relays
  set measurement
  execute PPMU measurement
  restore AC, PPMU relays
  retrieve the test result
  IF disconnected selected THEN
    set sequencer off
  ENDIF
ELSEIF PPMU serial measurement THEN
  program PPMU with specified values
  execute PPMU measurement with PMU_VFIM/PMU_IFVM
  retrieve the test result

ENDIF

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.0: Change parameter type of pinList to PinString for UTM library.
  3. SmarTest 6.5.2: Change parameter type of forceValue, spmuClamp, prechargeVoltage, settlingTime, ppmuClampLow and ppmuClampHigh to SpecValue for UTM library.
  4. SmarTest 7.1.1: Test table is supported in TML 2.1.1.
  5. SmarTest 7.1.1: Mixed usage of test table and testflow limits in one testflow is supported in TML 2.1.1.
  6. SmarTest 7.1.1: New parameter testName is added in TML 2.1.1.
  7. SmarTest 7.2.1: New option ShowFailOnly for the parameter output in TML 2.2.0.
