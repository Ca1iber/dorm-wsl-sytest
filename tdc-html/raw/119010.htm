How to create your own snippet

When you want to reuse some of your own codes frequently, you can create snippets for these codes. Next time you use them, you can insert these codes through inserting the snippets.

Procedure

  1. To open the Templates page, click Window > Preferences > C/C++ > Editor > Templates.
  2. In the Templates page, click New. The New Template dialog box will be displayed.
  3. In the dialog, enter the content for each field.
    • In the Name field, enter the snippet name. The name needs to be meaningful and easy to remember for future use.
    • In the Context drop down list, select the context type for the new snippet. It can be either C/C++ or Comment. Select C/C++ except that your snippet is a pure comment.
    • In the Description field, enter a description for the new snippet.
    • In the Pattern field, enter the code to be contained in the snippet.
    • Click Insert Variable to add a variable from the list to your code in the Pattern field if needed.
  4. Click OK.

Results

The new snippet is created and displayed in the Templates page.
