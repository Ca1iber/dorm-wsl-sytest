Name Mapping Record (NMR)

A Name Mapping Record maps PMR indexes to ATPG signal names. This allows the signal names to be preserved even when the PMR records do not contain signal names.

The Name Mapping Record can appear after the Pattern Sequence Record (PSR).

NMR field name

Field description

Value

93000 data source

CONT_FLG

Flag for the existence of NMR continuation records
  • Variable-length bit-encoded field
  • If the value is 1, there is an NMR continuation record after the current record.

    If the value is 0, this NMR is the last record.

 

TOTM_CNT

The total number of entries in the mapping table across all NMRs

Two-byte unsigned integer

 

LOCM_CNT

The number of entries in this NMR

Two-byte unsigned integer

0: There are no PMR_INDX and ATPG_NAM arrays.

 

PMR_INDX

Array of PMR indexes for which there are ATPG names
  • Array with the dimension LOCM_CNT
  • Each value is a two-byte unsigned integer

 

ATPG_NAM

Array of ATPG names corresponding to the PMR indexes
  • Array with the dimension LOCM_CNT
  • Each value is a variable length character string:

    - First byte is unsigned count of bytes to follow

    - Maximum 255 bytes

    - Length byte = 0 if missing or invalid data

 

Functional changes

  1. Introduced in SmarTest 6.5.0
