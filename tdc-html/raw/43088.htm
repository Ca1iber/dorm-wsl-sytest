Specifying the context for levels

Every level equation set is associated with a context which is assigned in the pin configuration. If you do not explicitly specify a context, the context "DEFAULT" is automatically set.

Before you begin

Make sure that you have opened the Level Setup window.

Procedure

  1. In the Level Setup window, click the menu Select > Edit Equations.
  2. The Level Equation editor opens. In the level equations, set the context: 
    MODECONTEXT "context name"
  3. To download the values in the level equations to the test system hardware, in the Level Equation editor, press F8.
  4. To verify the specified context, in the Level Setup window, click the menu Select > Show I/O Eqn. & Specs Results.
