SetBLCProfile()

This API initializes the BLC execution. It must be called at the beginning of the execution.

The behavior of this API includes:

  • Initialize the level model shared memory. The level number will be set to zero and there is no active level.
  • Set the test type, package test or wafer sort.
  • Set the SmarTest state to WAITING.
  • Issue the TESTPROGRAM_STARTED HVM event if the implicit event generation is turned on.
  • Issue the TestProgramStartEventType EDL event if the implicit event generation is turned on.

SUCCESS will be returned if no error occurs. Otherwise an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

PARAMETER_EXCEPTION
  • The value of the parameter "ENABLE_IMPLICIT_EVENT" can only be "TRUE" or "FALSE".
  • The value of the parameter "TEST_TYPE" is empty.
  • The value of the parameter "TEST_TYPE" can only be "WAFER_SORT" and "PACKAGE_TEST".

RECOVERABLE

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • The local session does not exist.
  • Failed to issue the HVM event.
  • The SmarTest state is not "IDLE".
  • Currently there is no device downloaded.

RECOVERABLE

Parameters

I/O

Parameter

Description

I

SESSION_ID

The ID of the SmarTest session to work with.

I

TEST_TYPE

The test type. It can be PACKAGE_TEST or WAFER_SORT. The test type will affect the wafer map parsing, test result display and test result log by FTEST (testflow execution process).

I

ENABLE_IMPLICIT_EVENT

(optional)Enable the implicit event or not. It can be TRUE or FALSE. The default value is TRUE that means the HVM events and the EDL events will be issued implicitly by APIs.

Prototype

ParamList inputParams;
Status syncCommand("SetBLCProfile", inputParams, sessionID);

Example

string sid = LOCAL_SESSION_ID; 
ParamList inputParams; 
inputParams["TEST_TYPE"] = "WAFER_SORT";
inputParams["ENABLE_IMPLICIT_EVENT"] = "FALSE";
Status retVal = syncCommand("SetBLCProfile", inputParams, sid);
if ( retVal.isError() ) 
{
cout<<"error code= " << retVal.code() << " description="
   << retVal.text() << endl;
}

Functional changes

  1. Introduced in SmarTest 6.5.0
