CCTchangeLevelSpec

Changes the value for the specified spec.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

void CCTchangeLevelSpec(const string& old_spec, DOUBLE value);
Parameters

Parameter

Description

old_spec

The name of the spec to change

value

The value to use

Return value

There is no return value.

Example

CCTchangeLevelSpec("spec1", 1.2);

Functional changes

  1. Introduced in SmarTest 7.2.0
  2. SmarTest 7.2.1: Rename the API from CCT_changeLevelSpec to CCTchangeLevelSpec.
