Graph Customization Toolbar

The Graph Customization Toolbar allows you to customize almost all the context information of the graph, such as title, axis, grid, cursor, marker, and trace. See alsoFormat Dialog Box.

Format - The context information such as title, axis label, axis unit, and user comment can be specified with this function.

Auto Scale - All waveforms in the selected Data Display Panel are auto scaled (horizontally, vertically, or both).

Zoom In/Out - Zoom in/out on the selected Data Display Panel in the Waveform Graphs Tool.
