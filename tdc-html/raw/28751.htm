CURRENT_SITE_NUMBER()

This API returns the site number of the current site under test.

Syntax

INT CURRENT_SITE_NUMBER();

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SiteControl.h.

List of parameters
There are no parameters.
Return value
Returns the current site number as integer.

Important points

This API is designed for executing on a single active site. Hence, use this API in the FOR_EACH_SITE block or outside the ON_FIRST_INVOCATION block.

Example

DOUBLE site_voff[4];
...
...
ON_FIRST_INVOCATION_BEGIN();
    ...
    ...
    FOR_EACH_SITE_BEGIN();
        ...
        ...
        AWG("Ain").vOffset(site_voff[CURRENT_SITE_NUMBER()-1]);
        ...
        ...
    FOR_EACH_SITE_END();
    ...
    ...
ON_FIRST_INVOCATION_END();
...
...

If you test devices on four sites, CURRENT_SITE_NUMBER() returns 1, 2, 3, or 4 as the site number of the currently tested site in the each site loop block. On the other hand, the site_voff array has four components, but the index number is from 0 to 3. Hence, you need to align between the site number and the index number of the array by ...[CURRENT_SITE_NUMBER()-1].
