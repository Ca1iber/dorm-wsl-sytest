SHMOO_RESULT.getTestList()

Retrieves test names for the results defined with SHMOO_RESULT.setResult().

Syntax

STRING_VECTOR getTestList();

Parameters

There are no parameters.

Return value

Returns a string vector that stores a list of test names.

Example

double meaValue1;
meaValue1 = ifvmMea.getValue("I/O1");
bool funcResult =GET_FUNCTIONAL_RESULT();

SHMOO_RESULT.pin("I/O1").testName("Voltage").setResult(meaValue1);
SHMOO_RESULT.site(1).pin("dataPins").testName("Function").setResult(funcResult);

STRING_VECTOR testList = SHMOO_RESULT.getTestList(); //testList will store "Voltage" and "Function".
