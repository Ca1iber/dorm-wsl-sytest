rdi.tmu().label()

Specifies the label that you want to insert to the TMU event.

Syntax

tmuGroup& label(const string &sLabel);
Parameter
Parameter Description
sLabel The name of the label.
Note The correct sequence of rdi.tmu().label() and .insertVec() must be respected within the rdi ... execute() block if you want to insert the TMU events into an already existing pattern.

Return Value

A reference to the tmuGroup object.

Example

RDI_BEGIN();

    rdi.tmu("id_1").label("func_1").pin("PVI8_PMU_1")
            .insertVec(100).vth(3.0 V, 5.0 V)
            .insertVec(500).samples(4).measMode(TA::PULSE_HIGH)
            .dataRate(25 MHz)
            .execute();

    rdi.wait(1 ms);

    rdi.tmu("id_2").label("func_2").pin("PS1600_1")
            .insertVec(280)
            .vth(3.0 V)
            .samples(4)
            .measMode(TA::RISE)
            .dataRate(25 MHz)
            .execute();

    .rdi.wait(1 ms);

RDI_END();
