EVENT_WAVEFORM_VC.getVClampLow()

Queries the lower clamp voltage waveform that has been defined by EVENT_WAVEFORM_VC.vClampLow().

The waveform is read from the corresponding EVENT_WAVEFORM_VC object and returned as an ARRAY_D object.

Syntax

const ARRAY_D & getVClampLow() const;
List of parameters
There are no parameters.
Return value

An ARRAY_D object containing the waveform samples that are defined in V (Volt).

Example

For an example see EVENT_WAVEFORM_VC.

Related information
