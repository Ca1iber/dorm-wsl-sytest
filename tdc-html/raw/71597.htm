Topic 71597

Starting the BFM Viewer

Subtopics

  1. BFM Viewer-specific device folder structure

The BFM Viewer can be started from the SmarTest GUI, from the command line, or using an execution file.

Before you begin

SmarTest must be installed.

The DUT must have been set up and there must be a valid map converter library.

Procedure

  1. In the menu bar of SmarTest, click 93000 > Memory Test > Bit Fail Map Viewer.

    Or, in the toolbar of SmarTest, click the Memory Test button and choose Bit Fail Map Viewer. See the following picture:

    Alternatively, you can:

    • Click the BFM Viewer icon from the Memory Test Manager.
    • Or, from the command line, execute the bfm command.

      This executes a shell script located in /opt/93000mts/mts/bfm/bin/.

    • Or, double-click the shell script in the /opt/93000mts/mts/bfm/bin/bfm directory.

      The Set Device Configuration window opens.

  2. In this window, select a directory for:
    • Device Path: The directory of the device you want to use. The default directory is the home directory.
    • Bitmap Path: The directory of the bit maps you want to analyze.

      For example, /home/user/mts/bitmap.

    • Map Converter Library: A compiled map converter library (a .so file), which the BFM Viewer uses to display fail bit maps.

      For example, /<device directory>/mts/bitmap/converters/bin.

  3. Click OK to close this window.

    The Bit Fail Map Viewer window opens.
