GetTmpPath

This procedure retrieves the temporary directory created by the current SmarTest session. By default, it is named like 93k.xxx under the directory /var/opt/hp93000/soc/tmp. (Refer to SmarTest temporary directory.)

Syntax

VOID GetTmpPath(CHAR *tmp_path_p);

Parameters

It returns the character array containing the actual temporary path. The array should be defined of length SA_TMP_PATH_LENGTH (defined in the header file /opt/hp93000/soc/com/include/sa_prc.h).

Example

char tmp_path[SA_TMP_PATH_LENGTH];
GetTmpPath(tmp_path);
cout << "path is " << tmp_path << endl;

Functional changes

  1. Introduced before SmarTest 6.3.2
