DSP_SIN_VEC

This API computes the sine of the elements in a specified array and returns the results to the corresponding elements of result as follows:

result [i] = sin(src [i] )

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_SIN_VEC(ARRAY_D& src, ARRAY_D& result);
DSP_SIN_VEC(DOUBLE *src, DOUBLE *result, 
            INT size);
Parameters

I/O

Parameter

Description / Range

I

src

Source array. Its values must be in radians.

O

result

Computed results

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src)

size ≤ (size of result)

Example

double array1[50], array2[25];
  .
  .
DSP_SIN_VEC(array1, array2, 25);

DSP_SIN_VEC computes the sine of the first 25 elements in the arrayarray1, and returns the results to the corresponding elements of the arrayarray2as follows:

int i;

for(i=0; i<25; i++)

array2[i] = sin(array1[i]);
