Topic 99079

SRPR, SRPR? - (Set Routing PRimary)

The SRPR (Set Routing PRimary) command sets a routing set as the primary routing set, which should be activated with the next command.

The SRPR? query returns the current primary routing set number.

SRPR

SRPR {set}

SRPR?

SRPR?

Parameters

set

An identification number of the routing set. This is an integer from 1 to the maximum number defined by the DSCP command.

If the NONE specifier is specified, no routing statements will be executed by the next command.

Application

Routing setup, see Routing Setup Commands.

Errors

An error occurs if the specified set number exceeds the maximum number defined by the DSCP command.

Example

SRPR 4

This example sets the routing set 4 as the primary routing set.

Functional changes

  1. Introduced before SmarTest 6.3.2
