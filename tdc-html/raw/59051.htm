GET_TESTNUMBER

Description

This API retrieves the reference of the TESTNUMBER class object. From the reference you can use the TESTNUMBER member functions getOffset(), getIncrement(), and getNumberOfCalls() to retrieve the test number offset, increment, and number of call values of the specified test name. (See also: TESTSET)

For an explanation of other factors that can affect test numbering, see the Generating Test Numbers section of Data Logging.

Note If both, offset and increment values of the specified test name, are not set, default values (offset = 0 and increment = 0) are used. In this case, the getNumberOfCalls() method of the TESTNUMBER class returns a value equal to the number of times the default values are used in the test method (which is equal to the number of calls for that test).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

const TESTNUMBER & GET_TESTNUMBER(const char * testname);
Parameter

testname

The test name that is referenced from the

Properties view.
