CCTgetExecMode

This API returns the current execution mode.

The returned value can be:

EXM_NONE, EXM_EXECUTE_TEST, EXM_FUNCTIONAL_TEST, EXM_DIGITAL_CAPTURE_TEST, EXM_EXECUTE_GROUP and EXM_INVALID.

This function is usually used in the preStart(), postStart(), process() and cleanup() function but not used in the init() function of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

EXEC_MODE CCTgetExecMode();

Related information

CCTsetExecMode

Functional changes
