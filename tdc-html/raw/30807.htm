Topic 30807

testprog

Subtopics

  1. Associated Syntax Entities

The testprog keyword is used as an argument for GET_TEST_INFO to return the name of the current test program.

The name is returned in the format <test_program_name> on device<device_full_path>. For example: program1 on device /home/demo/training_lab/74act299.

Functional changes

  1. Introduced before SmarTest 6.3.2
