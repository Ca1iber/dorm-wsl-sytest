DFCT - (DeFine Continuity Test)

The DFCT (DeFine Continuity Test) command sets up a continuity test that uses the active load (programmable load) to generate the force current, and a comparator to generate the result.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Postdependencies

Having defined the parameters with DFCT, you execute the continuity test with the query CTST? - (Continuity TeST).

This command does not support pins in HV mode.

DFCT

DFCT {force_current}, {commutation_voltage}, {pass_volt_min}, {pass_volt_max}, {polarity}, {(pinlist)}

DFCT?

DFCT?

returns: 

DFCT {force_current}, {commutation_voltage}, {pass_volt_min}, {pass_volt_max}, {polarity}, {(pinlist)}

Parameters

force_current

The force_current parameter specifies the current (in [micro ]A) that the active load sources or sinks. The range is 0 to 35 mA for the Pin Scale 800 and P-/Ce- channel boards. The direction of the current is determined by the polarity of the commutation voltage and the pass range.

commutation_voltage

This parameter defines the commutation voltage (in mV) that the active load requires to source/sink the force_current. For the Pin Scale 800, the range is -1.5 V to 5.5 V. For the P-/Ce-channel boards, the range is -2 V to +6 V.

pass_volt_min

This parameter specifies (in mV) the minimum pass value of the test. It defines the low level threshold for the comparator during the measurement.

pass_volt_max

This parameter specifies (in mV) the maximum pass value of the test. It defines the high level threshold for the comparator during the measurement.
Note If pass_volt_min > pass_volt_max, the two parameters are swapped around internally.

polarity

The polarity is as follows:

SPOL

Selecting the SPOL (single polarity) option causes the measurement to be taken with the specified polarity. The specified polarities are set for the commutation voltage and the pass limits.

BPOL

Selecting the BPOL (both polarities) option causes measurements to be taken with both polarities; a pass result is returned if the pin passes the test in both directions.

For using this option, the range of commutation_voltage is -1.5 V to +1.5 V for the Pin Scale 800, and -2 V to +2 V for the P-/Ce-channel boards.

pinlist

The parameters defined by the DFCT command are applied to all the pins named in pinlist. If more than one pin is to be included, the names must be separated with a comma. Pinlist can contain pins configured as O, I, IO, or DC pin types. The @ character can be used to specify all relevant pins.

Application

Continuity tests using the active load, see DC Measurement Commands.

Errors

An error is generated if:

  • The difference between the pass_volt_min and the pass_volt_max is less than 100 mV or greater than 9000 mV.
  • The difference between the pass values and the commutation voltage is smaller than 1000 mV.
  • The pass_volt_min or pass_volt_max is outside the range.

Example

DFCT 10000,1700,200,700,SPOL,(p1,p2,p3,p4)
CTST? GPF

This example sets up the parameters needed to execute a continuity test on pins p1 to p4. The parameters are as follows:

  • Force current = 10 mA
  • Commutation voltage = 1.7 V
  • Voltage minimum pass value = 200 mV
  • Voltage maximum pass value = 700 mV
  • Single polarity measurement selected

The example also includes the CTST? (Continuity TeST) query used to execute the test.
