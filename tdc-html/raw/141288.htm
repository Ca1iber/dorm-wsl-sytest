DPS_AUX_TASK.pin()

The pin() member function instances a DPS_AUX_PIN_TASK to each pin in the list.

The function returns the reference to the DPS_AUX_PIN_TASK class object that represents the measurement conditions for specified DPSs.

Note A call to this member function must be followed by calls to member functions of the DPS_AUX_PIN_TASK class. You cannot call another DPS_AUX_TASK member function after calling pin().

Syntax

DPS_AUX_PIN_TASK & pin(const STRING & pinlist);
Parameter

Parameter

Description

pinlist

Target pin name for which you want to define measurement conditions.

You can specify multiple pins by separating pin entries with a comma.

Return value

A reference to the corresponding DPS_AUX_PIN_TASK object.

Example

In this example the pin dps128pin is used to set the high and low thresholds and to activate the surge tracker.

DPS_AUX_TASK auxTask;

ON_FIRST_INVOCATION_BEGIN();

    auxTask.pin(dps128pin)
           .selectISensorSetThresholds(-1.0, 2.5)
           .setMode("SURGE_TRACKER");

    auxTask.execute();

ON_FIRST_INVOCATION_END();

For an extended example see DPS_AUX_TASK.
