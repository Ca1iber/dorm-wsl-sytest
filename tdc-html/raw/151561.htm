Topic 151561

TMU_TASK.smcUploadRawResults()

The TMU_TASK.smcUploadRawResults is the SmartCalc API used to perform hidden uploads of TMU raw time stamp results from specific shots.

Alternatively, uploads of TMU raw time stamp results from all shots is performed by calling SMC_TMU_UPLOAD_RAW_RESULTS() with additional parameters.

The results are uploaded from the test head card memory to the result cache on the workstation while a new test suite is being executed. This API must be called inside your SMC_backgroundProcessing() method.

The API is not supported with the Pin Scale 5000 card.

Syntax

void smcUploadRawResults(
    const STRING &resultAreaHandle,
    const STRING &dgtPinsName,
    UINT32 shot,
    UINT32 armings = 1,
    UINT32 numsamples = 0,
    UINT32 firstsample = 0,
    Boolean flatupload = FALSE);
void smcUploadRawResults(
    int site,
    const STRING &resultAreaHandle,
    const STRING &dgtPinsName,
    UINT32 shot,
    UINT32 armings = 1,
    UINT32 numsamples = 0,
    UINT32 firstsample = 0,
    Boolean flatupload = FALSE);
Parameters

Parameter

Description

resultAreaHandle

The name of the result area to upload from.

Result areas are defined with TMU_TASK::requestResultAreaHandle(handlename).

If this parameter is not specified, the data from the active result area are uploaded.

dgtPinName

The list of pins for which to upload data.

shot

The number of shots for which the samples are to be uploaded.

For example, if 2 is specified the ''shots 1 and 2'' are uploaded.

armings

The number of armings to be uploaded from the shot. The upload always starts with the first arming. The default value is 1.

For example, if 3 is specified the ''armings 1, 2, and 3'' are uploaded.

numsamples

The number of samples to be uploaded. Specify 0 to upload all samples. The default is 0.

firstsample

The index of the first sample to be uploaded. The index of the first sample in a block is 0. The default value is 0.

flatupload

The structure of the upload:

  • FALSE: Samples are grouped by armings. (Default).
  • TRUE: Samples for all armings are uploaded as one set.

site

Specifies the site for which the data should be uploaded.

Return value

There is no return value.

Example

This example demonstrates how to use the smcUploadRawResults member function of the TMU_TAKS class in the SMC_backgroundProcessing() function.

void SMC_backgroundProcessing()
     {
     TMU_TASK tmuTask;
     tmuTask.smcUploadRawResults( ["yourSite", ] "YourResultAreaHandle","pin1,pin2,pin3",1,1,4);
     
     Wave<double> samples;
     TMU_RESULTS& tmuResult = tmuTask.getResultCache();
     tmuResult.pins("pin1,pin2,pin3").shot(1).getRawData("pin1",&samples);
     
     int  numsamples = samples.getSize();
     cout << "number of samples taken: " << numsamples << endl;
     for (int i = 0 ; i < numsamples; i++)
     {
     cout << "samples " << i << "\t" << samples[i] << endl;
     }
     }
     
     void run()
     {
     TMU_TASK tmuTask;
     static  bool finished;
     ON_FIRST_INVOCATION_BEGIN();
     task.pin("pin1,pin2,pin3").setEdgeSelect(TMU::RISE).setInterSampleDiscard(mInterSampleDiscard)
     .setNumSamples(2).setNumMeasurements(1).setPreScaler(mPrescaler);
     CONNECT() ;
     tmuTask.setAsPrimary();
     tmuTask.setup();
     SMC_FUNCTIONAL_TEST() ;
     tmuTask.waitTmuFinished(1e.6,finished);
     ON_FIRST_INVOCATION_END();
     SMC_ARM();
     SMC_SYNCHRONIZE();
     }

If a TMU_TASK object with parameter "setName" is created, for example, TMU_TASK tmuTask("mySetName"), the same "setName" must be used for the TMU_TASK object in SMC_backroundprocessing().

The TMU_TASK object must not be passed to SMC_backroundprocessing() as a parameter because it is no longer available after leaving the run() method. Instead, create a new TMU_TASK object with parameter "setName" and pass only the "setName" to be used in the new TMU_TASK object.
