The Setup for Digital Capture

  5. Executing and debugging a digital capture setup

The setup for digital capturing starts with the setup of the primaries like pins, levels, and timing.

Additionally you need to define the pins you want the data to be captured from, and set up a vector variable, which defines how to extract (filter) the data of interest from the captured data.

The normal sequence for the setup of Digital Capture is:

  1. Define the pins and the levels.
  2. Define the capture timing.
  3. Create a pattern for Digital Capture in the sequencer memory, and set up the vectors.
  4. Use the Setup wizard to define one or more vector variables for Digital Capture.
