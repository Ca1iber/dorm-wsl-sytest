Reading a List of Wafers

To read a list of wafers, click the Read List button at the top of the Wafer Select screen.

When you click Read List, SmarTest executes a script specified in the GET_WAFERLIST call within your application model file. This script would typically read a list of wafers (from whatever source) and put them in a file also specified by the GET_WAFERLIST call. If no script is specified, the file is simply read.
