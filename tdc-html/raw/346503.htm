SmartRDI 7.5.1

This section summarizes software changes including new features and enhancements in SmartRDI 7.5.1.

Changes and new features

Category

 Description
General A new command rdi.perLabelPassFailNoBreakVec(bool) to control the flag of Pass/Fail per label without break vectors in test method.
Alarm handling for DCVI
  • Alarm handling on other ports.
  • An alarm setup template file is created when the alarm handling feature is enabled in the RDI_Configure file.

  • vMeasRange & iMeasRange auto-handling on DPS128/PVI8.

  • Alarm handling for vPulse/iPulse.

  • Debug value in the Report window.
Routing
  • LINK feature.
  • downloadPmuxMset(), enableOnlyActiveSites(), and handleDisabledSites() optimization.

  • ZIP file support.
ORE
  • A new keyword ORE_TEMPLATE_BY_USER_CODE in the RDI_Configure file to enable the generation of an ORE template file based on user code.
  • An ORE master file can contain several ORE files to support collaborative development.
DC
  • PPMU pattern controller setup with RDI_UNIT_INIT() can be executed in the first run in loops.
  • Parallel DC waveform and sampling with multiple pins.
  • insertVec() supports the same pin in different vector numbers with cont().
  • insertSub() supports waveform sourcing and sampling.
  • dcPowerBudget() assigns a power budget for DC tests.
  • pulseEnergyBudget() assigns an energy budget for pulsed tests.
EMAP Combined fail count with two new functions:
  • combinedFailCount()
  • rdi.id().getCombinedFailCount()
TMU defines the comparator hold-off time.

Supported SmarTest versions

SmartRDI 7.5.1 supports SmarTest 7.5.1.
