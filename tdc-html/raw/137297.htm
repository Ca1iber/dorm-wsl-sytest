Alerts preference setting

Enable Condition: If this box is checked, SmarTest applies the corresponding condition to cells in the summary tabs and raw data views.

First drop-down list: The table column that is compared with the specified value. Only cells in this column can be highlighted by the condition.

Second drop-down list: The comparison operator to use.

Text field: The value with which to compare the value from the chosen column.

Color: Click to set the color with which cells are highlighted.

Highlight Failed Tests: If this option is checked, all rows with failed tests in Raw data views and all rows in summary views that summarize at least one failed test are highlighted in red.
