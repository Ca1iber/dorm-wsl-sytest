DOUBLE_VECTOR

Defines a vector containing double elements. Vector is a standard C++ container. A DOUBLE_VECTOR variable can be processed with all the member functions of a vector.

With the member functions you can query the capacity, access the elements and modify the elements of the vectors. You can find all the member functions of the vector here http://www.cplusplus.com/reference/stl/vector/.

Example

GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
Marker marker = graph.getMarker();
ARRAY_D waveform = Analog.DGT("digitizer").getWaveform();
DOUBLE_VECTOR trace_wave;
Trace trace;
for(int i=0;i<waveform.size();i++)
{
  trace_wave.push_back(waveform[i]);
}
trace.setWaveform(trace_wave);
double min, max;
int min_index, max_index;
DSP_MINMAX(waveform, &min, &max, &min_index, &max_index);
// Find min/max automatically
marker.setUpMarkerPosition(min_index);
marker.setDownMarkerPosition(max_index);
graph.setMarker(marker);
graph.setTrace(trace, 1);
graphManager->setGraph(graph, 1);
