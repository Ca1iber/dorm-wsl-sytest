Topic 137335

ShmooTestInforAttrType

Contains the setups of a shmoo test. The data type is DRLShmooTestInfoAttr.

Comments

Field name

Type

Description

Setups for shmoo plots

title

string

The title for a shmoo plot.

 

testMode

string

The available Test modes on a shmoo plot.

 

resultPins

string

The pins to display pass/fail results on a shmoo plot.

 

resultResolution

double

The resolution to differentiate two results on a shmoo plot.

If the difference between two results is larger than or equal to the specified resolution, their results are considered different. Otherwise, their results are considered the same.

 

otherDescription

string

The descriptions for a shmoo plot.

 

numberOfAxis

unsigned int

The number of dimensions on a shmoo plot.

ParametersType

ShmooParametersType

The data type for the variable to be varied on an axis. The available data types are:

  • DRLShmooSpecVariable: (Default) a spec variable
  • DRLShmooHXInstrument: A HighspeedExtension instrument
  • DRLShmooHXResource: A HighspeedExtension resource
  • DRLShmooUserDefinedParam: User-defined parameters varied in the axes.

spec

string

(For ShmooSpecVariableType) A spec variable and its related pins to be varied on an axis.

setupPins

string

instrumentPin

string

(For ShmooHXInstrumentType)

  • instrumentPin: The analog pin connected to a HighspeedExtension lane.
  • property: The property of a HighspeedExtension instrument.
  • unit: The units include Hz, kHz, MHz, mV, V, fs, ps, ns, us, ms, s.

string

resourceName

(For ShmooHXResourceType)

  • resourceName: The name of a HighspeedExtension resource.
  • property: The property of a HighspeedExtension board or resource.
  • unit: The units include Hz, kHz, MHz, mV, V, fs, ps, ns, us, ms, s.

property

string

unit

string

paramName

string

(For ShmooUserDefinedParamType)

  • paramName: The name of a customer-defined parameter, which will be varied on an axis.

    To define this parameter, use the addParameterType() function.

  • type: The data type of this parameter. It can be int or double.

type

string
Note You can specify any derived unit (such as ns or mA) for EDL data logging. However, when data logs are converted to STDF, all units are converted to their SI equivalents (ns to s, mA to A) and the corresponding values are converted accordingly. (For example, 435 mA is converted to 0.435 A.)
