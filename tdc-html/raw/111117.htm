GET_UTILITY_LINES_STATUS

This API gets the status of all utility input lines.

Utility lines are organized in pogo blocks that provide 32 lines per block on the DUT interface. The blocks can be accessed independently of each other. Several test head configurations are available offering either 32, 64, 256 or 512 utility lines accessible on 1, 2, 8 or 16 utility blocks. For information on this and on the mapping of utility blocks see Utility line assignments.

The utility input line status of the specified block will be returned. "0" means the utility input line is on, "1" means the utility input line is off.

All utility blocks can be read by the API.

Syntax

STRING_VECTOR GET_UTILITY_LINES_STATUS(INT blockId = 0);

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/GetUtilitylinesStatus.h.

Parameter
blockId

The block ID of the utility lines to query. The default value is 0, which means the status of all the utility input lines will be returned.

Valid pogo block numbers:
  • 0 (All  utility  blocks)
  • 1 … 8 (1st Utility Card)
  • 165 ... 272 (1st Utility Card)
  • 265 ... 272 (2nd Utility Card)
Return value
The read state of the utility lines of type STRING_VECTOR.

Example

STRING_VECTOR utilitylineStatus;

utilitylineStatus = GET_UTILITY_LINES_STATUS(1);

for (uint index = 0; index < utilitylineStatus.size(); index++)
{
    cout << "Utility block " << setw(2) << index + 1 << ": "
         << utilitylineStatus.at(index) << endl;
}

In this example, the status of the utility line block 1 is returned.
