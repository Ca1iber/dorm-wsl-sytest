Topic 149923

Check test table setups

Lets you check test table setup related risks.

These risks include:

  • Undefined test suite.
  • Validate test naming and numbering.
  • Column consistency of test mode.
  • Duplicate test and test number.

Undefined test suite

This function checks if test suite name specified in test table does not exist in test flow.

Validate test naming and numbering

This function checks if the length of test name is in the given range.

Column consistency of test mode

Test table master file can contain several individual TMLimits CSV files, this function checks if one of CSV file has different test modes compared to the other CSV files.

Duplicate test and test number

This function checks if there’s duplicate test(test suite name + test name) and test number in test table.
