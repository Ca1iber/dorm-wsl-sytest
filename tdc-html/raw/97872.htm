Topic 97872

Deleting a pin

Before you begin

The pin you want to delete has been defined in the Pin Setting editors.

Procedure

  1. To select the pin (for example, DS7) you want to delete, click the row number of DS7. Then the row is highlighted by the shadow.
  2. To delete DS7, press the Delete key.
  3. The Confirm Delete window is displayed. Click Yes.

Results

DS7 is deleted from Pin Setting Editor.

Functional changes

  1. Introduced before SmarTest 6.3.2
