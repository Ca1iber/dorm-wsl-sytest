Topic 97887

Deleting a port

Before you begin

You have defined at least one port.

Procedure

  1. To select the port you want to delete, in the Test Program Explorer View, click the port name to highlight it. To select multiple ports, press Ctrl and click the port names.
  2. Right-click the selected port names and select Delete.
  3. The Confirm Delete window is displayed. Click Yes.
  4. Apply the data and save the pin configuration file.

Results

The ports have been deleted.

After existing ports are deleted that are used by other expression based groups, these groups are evaluated again because their group members may have changed.
