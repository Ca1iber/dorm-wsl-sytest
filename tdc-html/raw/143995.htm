SOURCESYNC_SUB_TEST.deviceSpec()

Specifies the value of the timing spec variable in the data sheet.

This value can be considered as a limitation.

Syntax

SOURCESYNC_SUB_TEST& deviceSpec (const double val);
Parameter

Parameter

Description

val

The value of the specified timing spec variable in the data sheet. The unit is nanoseconds (ns).

Related information

SOURCESYNC_SUB_TEST.specVar()

Functional changes

  1. Introduced in MTP 3.2.2
