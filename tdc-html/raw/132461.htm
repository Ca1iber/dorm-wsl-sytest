TMU_PINS.setInterSampleDiscard()

Sets the number of events to ignore between samples. If data rate is specified, the value will only take effect if it is greater than the value calculated from setDatarate().

Note This functionality is not supported for DC Scale pins. The function must therefore be omitted or the programmed value must be set to 0.

Syntax

TMU_PINS& setInterSampleDiscard(UINT64 val);
TMU_PINS& setInterSampleDiscard(UINT64 val, TMU::DATARATE_DEPENDENT_VALUES_TYPE& settings);
Parameters

I/O

Parameter

Description

I

val

The number of events to ignore between samples.

I

settings

The calculated value of prescaler and discarded events between measurements.

Return value

A reference to the TMU_PINS is returned.

Related information

TMU_PINS.getInterSampleDiscard()

Functional changes

  1. Introduced in SmarTest 7.1.0
