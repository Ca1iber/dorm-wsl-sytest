Topic 10542

Downloading vectors

There are low level and edit commands for downloading vectors:

Command

Description

VECD

Low level command which must be called with an absolute address. You can download any number of vectors with one call of this command. For an example, see Creating a label with low level commands.

VECC

Same as VECD, except that the vector input data must be in compressed binary format.

VDCP

Edit command which specifies the waveform DC/DC power units by the device cycle names. VDCP must be called with logical vector numbers. You can download one index with VDCP in the pure physical waveform format. For an example, see Creating a label with edit commands.

VDCN

Essentially the same as VDCP.

GETA?

Edit query which can be used as a tool for low level vector download. It returns the absolute address of the vector at a specified logical vector number of the label currently activated for editing.

Functional changes

  1. Introduced before SmarTest 6.3.2
