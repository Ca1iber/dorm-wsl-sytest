DRLErrorMapAttr

A variable of this type holds detailed error information for every error that occurred when a scan test pattern was run.

Syntax

typedef struct _DRLErrorMapAttr {
  DRLPinName pin;
  const char* description;
  int mode;
  unsigned failure_count;
  struct {
    long long cycle_number;
    int instance_id;
    unsigned offset;
    char state_character;
    char received;
  } cycle[1];
} *DRLErrorMapAttr;

Related information
