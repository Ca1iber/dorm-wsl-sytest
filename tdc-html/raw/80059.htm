Topic 80059

Executing a memory test with the Memtest Execute test method

To gather address or cycle-based data of the GDDR memory device you have to execute the ExecutionEngine test method described in the Testing High-Speed Memory Devices manual.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. MTP 3.0.1: The Memtest test methods have been replaced by the ExecutionEngine test method
