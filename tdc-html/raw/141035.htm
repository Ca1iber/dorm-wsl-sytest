DIGITAL_OFFSET_SEARCH_TASK.setup()

Executes the configuration firmware commands for the pins specified with DIGITAL_OFFSET_SEARCH_TASK.pin().

Syntax

void setup();

List of parameters

There are no parameters.

Return value

There is no return value.
