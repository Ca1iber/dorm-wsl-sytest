Topic 135407

Setting up tests manually with the Test Cell Control Tool

Introduces how to set up and perform the HAND test, the PROER test and the HANDLER test manually in the Test Cell Control Tool.

About this task

HAND test means the manual test you usually do in the engineering mode without communicating with the prober and the handler.

HANDLER test means the final test communicating with the handler.

PROBER test means the wafer test communicating with the prober.

Before you begin

Make sure TCCT and the needed SmarTest version are installed.

Procedure

  1. Start SmarTest and TCCT. The following actions are done in TCCT.

    Make sure TCCT session is successfully attached to the SmarTest session. The status is shown in the lowest part of TCCT. "SmarTest XXX Attached" will be shown if it is successfully attached. Otherwise, you will see "SmarTest Session Detached".

  2. To load the testflow to be executed, click the Load Testflowbutton, select the testflow and click OK.

    The selected testflow and all its setup files will be loaded. The location of the loaded testflow file will be displayed in the Lot Summary area below the Load Testflow button.

  3. (For HANDLER or PROBER test) To set the equipment setting, click the Equipment tab and then click the Equipment Setting button.

    Select PROBER or HANDLER as the test type and then select the configuration and click OK. The configurations are defined in the file /etc/opt/hp93000/tcct/equipment.xml. You can edit the file to add your own equipment configurations. (Refer to Equipment configuration file for detailed explanation.)

  4. To configure the data log settings, click the Datalog Setup button in the lower part of TCCT to bring up the Datalog Setup dialog.

    In the dialog, you can set the data log profile, the data log output information and the lot summary information. (Refer to Setting up the data log information for details.)

  5. To start a lot, click New Lot and enter the values for the variables listed in the Lot Information dialog.

    You can edit the configuration file of the dialog to change the variables listed in the dialog.

  6. To execute the loaded testflow, Click Start Test.

    The text data log file is created. The binning information of the execution is displayed in the Binning area and counted in the Binning Statistics area.

  7. (optional)If any error occurs, you can debug the testflow in EWC or disable some sites before further testing. For the PROBER and the HANLER test, you need to click Pause Test before debugging.
  8. (optional) If you want to generate the partial lot summary for the tested devices, click Partial Summary in the lower part of TCCT. For the PROBER and the HANLER test, you need to click Pause Test before this.

    The partial lot summary is generated in the lot summary file you specified in the Datalog Setup dialog.

  9. (optional)To continue the tests for other devices in the lot, click Start Test for the HAND test and click Resume for the PROBER and the HANDLER test.
  10. When the execution of the whole lot is completed, click End Lot.

    The lot summary file and the STDF data log file you specified will be generated.

Results

The lot summary file and the data log files can be generated as specified. The binning statistics and the yield are shown in the main GUI of TCCT.

What to do next

Check and analyze the test results.

Functional changes

  1. Introduced in SmarTest 7.2.0
  2. SmarTest 7.2.0: in patch 2, supports automatic equipment setting for HAND test in TCCT 1.2.
