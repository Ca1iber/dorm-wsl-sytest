DIGITAL_OFFSET_SEARCH_RESULT_PINS.getResultPin()

Returns the defined result pins.

Syntax

STRING getResultPin();

List of parameters

There are no parameters.

Return value

Returns the result pins defined with DIGITAL_OFFSET_SEARCH_RESULT_PINS.setResultPin().
