Test Time Profiling Overview

Test Time Profiling lists test time of test flow, test time of test suite, and a timeline diagram is offered to indicate the difference of time consuming between RDI_BEGIN and RDI_END.

Test time of test flow/test suites

Test Flow
The test flow you are testing. Clicking it opens a detailed test flow test time report.
Test Suite
The test suites you selected to test. Clicking it opens a detailed test suite test time report.
Average test time
Total test time divides loop number.
Loop number
The execution times
Test time breakdown
The details test time of the test time including total, static command, pattern bust, setup command, pattern execution, result upload and not classified.
Select test time type to sort
Total, RDI Static Command, RDI Pattern Burst, Setup Command, Pattern Execution, Result Upload, not classified. The test time will be sorted in descending order when selecting different types.

Flow execution breakdown based on actions

Actions
Flow action
Loop
The test time of current action in this current execution.

Detailed Test Suite Test Time diagram

It displays the test time diagram from suite start to suite end and the action happens in this course are displayed in different color for comparison. You can select from Select loop index to display to choose the loop you want to view. Click an colorful block in the diagram to open an detailed event test time report for a block.

Event Test time

In SmartRDI Pattern-based mode, a burst pattern will be generated with the DC events, analog hardware trigger and analog set in a RDI_BEGIN()/RDI_END() block, and be executed at RDI_END(). All the actions/events in burst pattern executes automatically by sRDI, difficult to know how/when they executes at background. It displays the port name on the left and event types on the diagram in a unique color/.
