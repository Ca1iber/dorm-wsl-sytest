registerSyncPort()

This function is used to register an instance of the class SynchronizedPort. The SynchronizedPort instance handles the sequencer program or pattern on the registered port.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

void registerSyncPort(SynchronizedPort& _syncPort);
Parameter

_syncPort

Specifies the port to be registered to CCTMultiPortSync instance.

Example

CCTMultiportSync    Sync;
CCTtsName = CCTgetTestsuiteName();
GET_TESTSUITE_NAME(tsName);

Sync.registerCCTestMethod(tsName, this);

PatternPort::getInstance().setPort("SH1_Port");
PatternPort::getInstance().setWaitTemplatePatternName("SH1_Port_wait_template");
Sync.registerSyncPort(PatternPort::getInstance());

DCDynamicPort::getInstance().setPort("pDPS128");
Sync.registerSyncPort(DCDynamicPort::getInstance());

Sync.start();
...
Sync.sync();
...
Sync.flush();

Primary.label(Sync.getMultiPortBurstName());
Sync.dumpMPBGraph();
