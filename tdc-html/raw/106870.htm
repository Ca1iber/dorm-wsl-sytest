Folder structure for redundancy analysis files

The various files required for setting up and performing redundancy analysis (RA) have their own folder structure within the device directory.

This structure is created automatically whenever you create a new device.

Structure

<device directory>/

mts/

ra/

config/ - RA configuration file

control_option/ - RA algorithm control file

device_rep/

src/ - DUT representation source file

sh_lib/ - compiled DUT representation shared library

bin/ - compiled DUT representation executable

result/

ra_exec_log/ - execution log of the RA algorithm

ra_solution_log/ - solution output of the RA algorithm

algorithm/

sh_lib/ - shared library for user-written RA algorithm

src/ - source files for user-written RA algorithm

Functional changes

  1. Introduced in MTP 2.6.5
  2. MTP 3.0.4: The structure is created automatically when a new device is created.
