Topic 42356

Saving the Configuration File

A specific driver configuration file may be saved to any directory. However, it is recommended that you store the file in the directory

/etc/opt/hp93000/soc/PH_libs/GenericHandler/plugin_dir_name/

or

/etc/opt/hp93000/soc/PH_libs/GenericProber/plugin_dir_name/

in order to indicate its association with the plug-in.

If you use user-modified attributes definitions, please consider the section Handling an Attributes Definition File.
