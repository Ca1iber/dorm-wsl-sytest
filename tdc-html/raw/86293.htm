Topic 86293

Model file and Device license file

Subtopics

  1. How SmarTest sets the system configuration (for SmarTest 7)

Note This topic is applicable to SmarTest 7 only.

Model file

In the model file, you set the configurations and features of the test system resources for your addressed tests.

For those test system resources and features that require licenses, SmarTest first generates the license requests based on the model file, then checks out the requested licenses from the license server.

Note If a device license file exists, its parameters will be evaluated and any licensing parameters in the model file will be ignored.

The SmarTest report window lists the referenced model file.

Device license file

The device license file defines tester resources as required by the device. It uses the same syntax as the model file and thus extends that licensing concept.

The device license file provides the following advantages:

  • It allows an efficient usage of licenses by defining "per device" the licenses to be used.
  • It supports device testing on different test systems with different hardware resources.
  • It allows to use different licenses in different test scenarios (for example, wafer sort, final test, engineering, quality assurance) for the same device.
  • It is compatible with the model file licensing concept
  • It works at startup and for change device.
  • It works both in offline and online mode.
    Note The device license file defines tester resources as required by the device. It replaces all other licensing information given in the model file. The device license file can only include license relevant entries, like speed, memory, etc. Non-license relevant entries like test head, etc. belong into the model file. If no device license file is specified, the model file based licensing mechanism is used.
