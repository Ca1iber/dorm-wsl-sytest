DRLBitFailMapDescAttr

A variable of this type holds the description of a bit fail map.

Syntax

The description is contained in the label description.

typedef struct _DRLBitFailMapDescAttr {
  const char* description;
} *DRLBitFailMapDescAttr;

Functional changes

  1. Introduced in SmarTest 7.0.3
