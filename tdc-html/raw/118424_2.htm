PRUD - (PRBS set UnDefine)

PRUD deletes a PRBS set.

Syntax

PRUD {"prbs_set_name"|ALL}

Parameters

prbs_set_name

Specifies the name of an existing PRBS set.

ALL

Remove all existing transition tests sets

Application

PRBS test.

Errors

An error is generated if no PRBS set with the specified name exists.

Example

> PRUD   "prbs_set1"

Functional changes

  1. Introduced in SmarTest 7.0.1
