EVENT_WAVEFORM_VC.sampleVectorDistance()

Sets the distance between sample vectors.

Syntax

EVENT_WAVEFORM_VC & sampleVectorDistance(INT vectors);
Parameter
Parameter Description
vectors

Number of vectors defining the distance. Minimum is 32 vectors.
Return value
A reference to the corresponding EVENT_WAVEFORM_VC object.

Example

For an example see EVENT_WAVEFORM_VC.

Related information

EVENT_WAVEFORM_VC.getSampleVectorDistance()

Functional changes
