Shmoo

The shmoo test method gradually increases the values of two parameters of a test and run the test at certain values of these two parameters simultaneously. The result of a shmoo test is a two-dimensional plot where the x-axis and y-axis represent the two parameters respectively. In the shmoo plot, every cell at a (x, y) pair displays a test result of the shmooed test by using colors or texts.

The test to be shmooed can be any functional tests or measurement test suites.

To view the shmoo plot after executing a shmoo test suite or testflow, use the Shmoo view of the Integrated Result Tool. Or, you can use the Event Formatter to view it in the report window.

Note Besides this provided shmoo test method, you also can define your own customized shmoo test method with the shmoo test method template. For details, see Creating a customized shmoo test method.

The results of the tests that can be displayed on each (X, Y) pair are the following test modes:

  • Pass/Fail: (Default) Displays either PASS or FAIL for each (x, y) pair in the shmoo results plots.
  • First failing cycle (used only for functional tests): Displays the first failing cycle number for each (x, y) pair in the shmoo results plots.
  • First failing vector (used only for functional tests): Displays the first failing vector number for each (x, y) pair in the shmoo results plots.
  • Cycle error count (used only for functional tests): Displays the number of the total failed cycles for each(x, y) pair in the shmoo results plots.
  • Edge error count (used only for functional tests): Displays the number of the total failed edges for each (x, y) pair in the shmoo results plots.
  • User defined measurement: Displays a measured value or a bool-type result which you have defined in your test suite for each (x, y) pair in the shmoo result plots.

    For how to display the defined result, see Viewing the test results of a test suite on a shmoo plot.

There are two shmoo algorithms used in the test method.

Linear shmoo algorithm

In linear mode, the test method starts with values entered for x-start and y-start, and then repeats the measurement with specified increments along X-axis, continuing line by line along the Y-axis.

When a linear shmoo runs, the parameter on X-axis is moved by step stepWidthX in every measurement. If its value is larger than stopX, it will be reset to startX and the parameter on the Y axis is moved by the step stepWidthY. When the resource on Y axis is larger than stopY, the shmoo measurement stops.

Binary shmoo algorithm

When a binary shmoo runs, it first performs a linear shmoo. After the linear shmoo finishes, it reduces both the X-axis and Y-axis step width by half and do measurement on the points whose surrounding points' measured results are different to find out the pass/fail transition boundary. The binary shmoo stops when the step width for X-axis and Y-axis equal (stop_value-start_value)/total_step_number.

Execution mode for multiple sites: serial or parallel

This standard shmoo test method ac_tml.AcTest.Shmoo executes multiple sites in serial mode. There is no parameter ready for use with it to change the multi-sites execution mode to parallel.

To let shmoo execute multiple sites in parallel, you need to use customized shmoo test method instead. The customized shmoo test method provides a flexibility to choose between serial and parallel execution modes for multiple sites. The UserDefinedMeasure() function naturally supports parallel execution for multiple sites without requiring an ON_FIRST_INVOCATION_BEGIN()/ON_FIRST_INVOCATION_END() block. It also supports serial execution for multiple sites through using a FOR_EACH_SITE_BEGIN() command. See the example in "The functions of the customized shmoo test method template".

Considerations for interpreting shmoo plots

The specs that are varied by the shmoo test are normally used in various equations, which are set up in the equation object. Therefore, other resources may depend on these specs and change as they are varied. These implicit dependencies must be taken into account when interpreting the results of a shmoo plot.

Parameters

Parameter

Type

Description

title

string

The title for the shmoo plot. The default value is shmoo.

shmooTestSuite

string

The test suites to be shmooed. You can select or enter:

  • Only one test suite name in order to shmoo over this test suite.
  • Multiple test suite names separated with ";" in order to shmoo over each of these test suites one by one. These test suites must have the same primaries. Otherwise, you cannot shmoo.

    The result of shmoo over multiple test suites is one pass/fail shmoo plot. Each shmoo cell is filled up with either Pass or Fail. Pass indicates all test suites are pass at this cell. Fail indicates at least one test suite is failed at this cell.

    To display the shmoo over multiple test suites result, you need to select pass/fail in the testMode parameter field. (See testMode in the following table).

x

string

You can select ON or OFF:

  • ON: There will be an x-axis in the shmoo plot.
  • OFF: No x-axis in the shmoo plot, which becomes a one-dimensional plot.

x.start

double

Start value for x-axis.

x.stop

double

Stop value for x-axis.

x.step

string

The number of intervals (one interval is a step width) between the start and the stop values on x-axis. It can be specified with the following syntaxes:

  • number: The step width.
  • #number: The step number.
  • f#number: One fast shmoo mode, which is equivalent to #<number>/<4>, such as f#96 is the same as #<96>/<4>.
  • #<number1>/<number2>: number1 is the total steps but the result is displayed every number2 steps. For example, #<96>/<2>.

    number2 can only be a power of 2 such as 1, 2, 4, 8, 16, and etc..

x.scale

string

The scale for x-axis. It can be Linear or Logarithmic. The default value is Linear.

x.parameterType

string

The type of the parameter used for x-axis. It can be:

  • SpecVariable: (Default) Represents spec variables.
  • Hardware Resource: Represents for timing edges, level resources, HX instruments and HX resources.
  • Test Method Parameter: (Available and viewable only when a test suite name is selected in the shmooTestSuite field.) An int or double data type test method parameter of the to be shmooed test suite.

testMode

string

The test mode determines what kind of results will be displayed on a shmoo plot.

The available test modes are:

  • pass/fail
  • first failing cycle
  • first failing vector
  • cycle error count, edge error count

The test names to be used as limits. Default is Shmoo.

If you want to use the test names defined in the test table or testflow limits, type in the test names manually. Make sure the test names are in the Test name column of the test table (Refer to Structure of a TMLimits CSV file) or in the Test Name column of Tests page of Flow Data Editor.

Implementation pseudo code

save hardware and software status
IF linear shmoo THEN
  FOR every point of x-axis in specified range DO
    FOR every point of y axis in specified range DO
      change value of x-axis
      change value of y-axis
      do pass/fail or value test accordingly
ELSEIF binary shmoo THEN
  do a linear shmoo and remember result of each point
  WHILE step width is lager than range/step_number DO
    reduce step width of x-axis and y-axis to half
    FOR each point surrounding by points of different results
      do a pass/fail or value test
ENDIF  
display test result according to specified test mode
restore hardware and software status
