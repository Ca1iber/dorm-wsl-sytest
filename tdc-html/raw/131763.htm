FOR_EACH_SHARED_SITE_END

FOR_EACH_SHARED_SITE_END() works together with FOR_EACH_SHARED_SITE_BEGIN() as a pair to declare a block for sequentially testing shared sites.

See more details in FOR_EACH_SHARED_SITE_BEGIN.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/SHARED_UTIL.h.

Syntax

FOR_EACH_SHARED_SITE_END()
