Pins and port for Digital Source Memory

The test system uses normal digital pins (also called digital channels) for data sourcing. No additional hardware is required. This gives you the flexibility to perform data sourcing at any available digital pin of the test system.

Any type of digital pin you define in the pin configuration can be used for sourcing data to the DUT.

When defining the pins of a DUT using the V93000 test system, the software automatically assigns all configured pins to the default port "@".

Normally, when using DSM, it is important to configure a port, or ports, which contain all the pins using source memory. This determines the ports with which the DSRC label is to be associated.

The port used by the DSRC label defines the pins on which source actions will be performed (source pins). Other pins in the configuration are called non-source pins.
