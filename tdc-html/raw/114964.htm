This TIMING_OFFSET_SEARCH_PINS class holds the timing offset search conditions for the specified pins. It is a sub-class of TIMING_OFFSET_SEARCH_TASK. You cannot directly create an object with it.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TimingOffsetSearchPins.h.

There are two sub-classes defined for timing offset search:

  • TimingOffsetConfigDataType:

    This class contains all the configuration data of a timing offset search. You can create an object of the class and use each type of the configuration data.

    The configuration data includes

    • search type
    • edge type
    • start value
    • step number
    • step width

      resolution

    • minimum pass count (optional)
    • transition detection type (optional)
    • error count limit(optional)
    • restore flag (optional)
    • faststop (optional)
  • TimingSetSelector:

    This class refers to a single timing set or all the timing sets in a timing equation set. Two parameters are required. The first one selects a waveform set (fixed timing) or a timing specification (equation based timing) or a multi-port specification. The second parameter selects one or all timing sets from this waveform set or specification. In the case of a multi-port specification, the ports to which the selector refers are determined by the pin list of the TIMING_OFFSET_SEARCH_TASK object.

    The default constructor TimingSetSelector() is defined. It is equal to TimingSetSelector(TIMING_OFFSET_SEARCH::PRM, TIMING_OFFSET_SEARCH::PRM) and refers to the primary timing set.

    The following constructors are defined:

    TimingSetSelector (const TimingSetSelector& rhs);
TimingSetSelector (const TimingSetSelector* rhs);
TimingSetSelector (const STRING& multiportspec, INT timingset);
TimingSetSelector (INT waveformORspecId, INT timingset);
TimingSetSelector (TIMING_OFFSET_SEARCH::PRM_ALL waveformOrSpec,
 INT timingset);

 TIMING_OFFSET_SEARCH::PRM_ALL timingset);

 TIMING_OFFSET_SEARCH::PRM_ALL timingset);
TimingSetSelector (TIMING_OFFSET_SEARCH::PRM_ALL waveformOrSpec, 
 TIMING_OFFSET_SEARCH::PRM_ALL timingset);
TimingSetSelector();
TimingSetSelector(const TimingSetSelector & rhs, INT timingSet);
TimingSetSelector(const STRING& waveformOrSpec, const STRING& timingSet);
TimingSetSelector(const STRING& timingSelector);

    Parameter

    Description

    rhs

    The name of an existing TimingSetSelector object

    multiportspec

    The name of a multi-port specification, in a multi-port setup.

    waveformORspecId (INT)

    In fixed timing setup, it is the waveform set number.

    In equation based timing setup, it is a timing specification ID calculated as follows:

    100*equation_set_no + specset_no

    waveformOrSpec (TIMING_OFFSET_SEARCH::PRM_ALL)

    It can be:

    • TIMING_OFFSET_SEARCH::PRM: select the primary specification
    • TIMING_OFFSET_SEARCH::ALL: select all waveform sets in fixed timing.

      Note that this option is only supported for waveform sets, not for specification ID's.

    timingset

    (INT)

    The timing set number to select.

    timingset

    (TIMING_OFFSET_SEARCH::PRM_ALL)

    It can be:

    • TIMING_OFFSET_SEARCH::PRM: select the current primary timing set.
    • TIMING_OFFSET_SEARCH::ALL: select all the timing sets in a timing equation set.
