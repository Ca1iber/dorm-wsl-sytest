TestsuiteProxy.attachTestmethod()

This function attaches a test method to the test suite. All defined parameters with their default values and all defined limits with empty values will be attached to the test flow in their definition order.

Syntax

bool attachTestmethod(const std::string& name);
Parameters

name

The full name of the test method like "ac_tml.AcTest.FunctionalTest".

Functional changes

  1. Introduced in SmarTest 6.5.2
