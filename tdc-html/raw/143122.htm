rdi.func().burst()

Specifies an existing burst label to be executed in a functional test.

In the pattern‑based mode (dynamic mode), this function also supports combining an existing burst label with several port() actions labels together to form a new multi-port burst label. To retrieve the results from the multi-port burst label, use ARRAY_I& getMultiPassFail(string sPort=="@");. If 1 is returned, the result is pass; if 0 is returned, the result is fail. See the examples in the Example section below.

In the pattern‑based mode (dynamic mode), do not use rdi.func().perLabelPassFail(). rdi.func().perLabelPassFail() is only required in the code‑based mode (static mode).

Syntax

rdi.func().burst(const string& sLabelName);
List of parameters

Parameter

Description

sLabelName

The burst pattern name

Examples

Example 1

Specifying an existing burst label to be executed in the functional test

RDI_BEGIN();
  rdi.dc().pin("dig").vForce(1 V).execute();
  rdi.func().burst("ExistBurst").execute();
  rdi.digCap().pin("dig2").samples(8).execute();
RDI_END();

Example 2 Working together with port() actions

Combining an existing burst label with other port actions, such as dc, digCap, and emap actions.

One port:
RDI_BEGIN();
  rdi.port("pt1")
  rdi.port("pt1").func().burst("ExistBurst").execute();
  rdi.port("pt1")....
RDI_END();
Multiple ports:
RDI_BEGIN();
  rdi.port("pt1").dc().pin("dig").vForce(1 V).execute();
  rdi.port("pt1").func().burst("ExistBurst").execute();
  rdi.portSync();
  rdi.port("pt2").func().burst("ExistBurst").execute();
  rdi.port("pt2").digCap().pin("dig2").samples(8).execute();
RDI_END();

Retrieving the pass/fail results

Use ARRAY_I& getMultiPassFail(string sPort=="@"); to get all pass/fail results for each main label from the burst label on different ports.
RDI_BEGIN();
...
rdi.port("pt1").func("id1").burst("MPBurst1").execute();
...
rdi.port("pt2").func("id2").burst("MPBurst2").execute();
...
RDI_END();

int pf = rdi.id("id1").getPassFail(); // returns 0
ARRAY_I ary2 = rdi.id("id1").getMultiPassFail();  // returns { 0,1,0 } ,1st and 3rd label failed

int pf = rdi.id("id1").getPassFail(); // returns 1
ARRAY_I ary3 = rdi.id("id2").getMultiPassFail();  // returns { 1,1,1 }, all 3 labels passed

Related information

rdi.id().getMultiPassFail()
rdi.port(TA::MULTI_PORT).func()

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 7.10.0: Multi-port burst labels are supported in dynamic mode.
