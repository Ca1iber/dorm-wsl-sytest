Topic 152390

UTILITY_SEQ_STATIC_MASK

Subtopics

  1. UTILITY_SEQ_STATIC_POGO_MODE
  2. UTILITY_SEQ_STATIC_MASK.pogoBlock()
  3. UTILITY_SEQ_STATIC_MASK.execute()

Sets the static mask for sequencer‑controlled utility lines.

The object of UTILITY_SEQ_STATIC_MASK can be added to a TASK_LIST.

This API requires that the dynamic mask mode is enabled by API UTILITY_SEQ_POGO_MODE using the keywords
  • TM::SEQ_POGO_MASK_MODE_RD or
  • TM::SEQ_POGO_MASK_MODE_RW.

The settings done by this API are ignored if other sequencer‑controlled modes of the utility blocks are set.

Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/UtilitySequencerStaticMask.h.

Constructor
UTILITY_SEQ_STATIC_MASK();
List of parameters
The constructor has no parameters.
Return value
The constructor has no return value.
Member functions
  • UTILITY_SEQ_STATIC_MASK.pogoBlock()
  • UTILITY_SEQ_STATIC_POGO_MODE.mask()
  • UTILITY_SEQ_STATIC_MASK.execute()

Example

UTILITY_SEQ_MODE        utiSeqModeOn;
UTILITY_SEQ_MODE        utiSeqModeOff;
UTILITY_SEQ_STATIC_MASK utilitySeqStaticMask;

ON_FIRST_INVOCATION_BEGIN();

    //
    // Set utility block 1      in sequencer‑controlled masked reading and writing mode.
    // Set utility block 2 to 5 in sequencer‑controlled masked reading mode.
    //
    utiSeqModeOn.pogoBlock(1).mode(TM::SEQ_POGO_MASK_MODE_RW );
    utiSeqModeOn.pogoBlock(2,5).mode(TM::SEQ_POGO_MASK_MODE_RD );
    utiSeqModeOn.execute();

    //
    // Set the static mask for pogo blocks 1 and 2
    //
    utilitySeqStaticMask.pogoBlock(1).mask(0x000E);
    utilitySeqStaticMask.pogoBlock(2).mask(0x00E0);
    utilitySeqStaticMask.execute();

    //
    // Perform the functional test
    //
    FUNCTIONAL_TEST();

    //
    // Disable the sequencer‑controlled mode of all utility blocks
    //
    utiSeqModeOff.pogoBlock().mode(TM::SEQ_POGO_MODE_OFF);
    utiSeqModeOff.execute();

ON_FIRST_INVOCATION_END();
