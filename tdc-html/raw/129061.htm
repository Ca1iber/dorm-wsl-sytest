MTP_MEMORY_PATTERN.getFailingAddressList()

Retrieves the number of failing addresses and the failing addresses for the data pins specified with setResultPins().

Syntax

Four syntaxes are used to retrieve failing addresses and the number of the failing addresses for a single data bit, or for a group of data bits.

  • Syntax 1 and syntax 2: Retrieves the number of the failing addresses and the failing addresses for a data bit.

    The order of the retrieved addresses is defined with setFailAddressListOrdering().

  • Syntax 3: Retrieves failing addresses which are different from (x, y, z) for a group of data bits and returns the number of failing addresses.

    x, y, z are the address dimensions. An MTP address is made up of four dimensions (x, y, z, d).

    For example, for the following two addresses:

    (x, y, z, d)
 1  1  1  0
 1  1  1  1

    Syntax 3 will return 1 as the number of failing addresses.

  • Syntax 4: Retrieves the number of failing addresses, the failing addresses, the related cycle numbers, and the data information for a group of data bits.

    The retrieved addresses are returned in the order of failed cycles. Therefore, you must set setFailAddressListOrdering(FAIL_CYCLE) before using syntax 4.

Syntax 1

LONG getFailingAddressList(const int bit_index, const LONG_LONG number_of_addresses, MTP::ARRAY_ADDRESSES& addresses);

Parameter

Description

bit_index

The bit index for which you want to retrieve the failing addresses.

0 represents the first data pin in the data pin lists that are specified with setResultPins().

number_of_addresses

The maximum number of failing addresses that you want to retrieve for that pin.

addresses

The array in which the addresses will be stored.

The addresses are sorted according to the sorting order specified with the setFailAddressListOrdering() function of MTP_MEMORY_TEST.

This function returns the size of the address list.

Syntax 2

LONG getFailingAddressList(const int bit_index, const LONG_LONG number_of_addresses, MTP::ARRAY_ADDRESSES& addresses, int expD);

Parameter

Description

bit_index

The bit index for which you want to retrieve the failing addresses.

0 represents the first data pin in the data pin lists that are specified with setResultPins().

number_of_addresses

The maximum number of failing addresses that you want to retrieve for that pin.

addresses

The array in which the addresses will be stored.

The addresses are sorted according to the sorting order specified with the setFailAddressListOrdering() function of MTP_MEMORY_TEST.

expD

The expected data for the specified bit. The data can be 0, 1, and -1.

  • If you specify 0, the addresses where the bit fails to compare with 0 will be retrieved.
  • If you specify 1, the addresses where the bit fails to compare with 1 will be retrieved.
  • If you specify -1, the addresses where the bit fails to compare with both 0 and 1 will be retrieved.

This function returns the size of the address list.

Syntax 3

LONG getFailingAddressList(const ARRAY_I& dBitGroup, const LONG_LONG number_of_addresses, MTP::ARRAY_ADDRESSES& addresses, int expD);

Parameter

Description

dBitGroup

A group of bit DC/DC power units to represent a group of data pins for which you want to retrieve the failing addresses.

0 represents the first pin in the pin lists that are specified with setResultPins().

number_of_addresses

The maximum number of failing addresses that you want to retrieve for this group of pins.

addresses

An array in which the addresses will be stored.

The addresses are ordered according to the order set with MTP_MEMORY_TEST.getFailAddressListOrdering().

expD

The expected data for all bits in the bit group.

Specify 0, 1, or -1 for this parameter.

  • If you specify 0, the addresses failed to compare with 0 will be retrieved.
  • If you specify 1, the addresses failed to compare with 1 will be retrieved.
  • If you specify -1, the addresses failed to compare with both 0 and 1 will be retrieved.

This function returns the number of failing addresses that are different from (x, y, z) dimensions.

Syntax 4

LONG getFailingAddressList(const LONG_LONG first_N_failing_cycle_number, DeviceCycleToAddrWordMap& cycleAndAddrWord);

Parameter

Description

first_N_failing_cycle_number

Starting from the first failing cycle in a pattern, the total number of failing cycles that you want to get.

cycleAndAddrWord

This is a multimap (see its definition below) that contains the failing cycle numbers, the corresponding failed physical addresses, the received data, and the compared data.

The failing cycle number is used as the key of the map, and the other data items are its values.

Note that:

  • In some cases, one failing cycle may have more than one failing address and associated data.
  • The failing cycle number is the device cycle number, not the tester cycle number.
  • The data type DeviceCycleToAddrWordMap is defined in /opt/93000mts/mts/execution_engine/include/MtpTypes.h.
  • A multimap is a C++ data type.

    Multimaps are a kind of associative container that stores elements formed by the combination of a key value and a mapped value, much like map containers, but allowing different elements to have the same key value.

This function returns the number of failing cycles or the number of failing addresses.

Examples

Example 1

Use Syntax 1 to fetch failed addresses for the first data pin "DQ_00". The address are ordered by the failing cycles.

void MemoryTest::run()
{
  MTP_MEMORY_TEST memoryTest;
  
  memoryTest.enableAddressBasedResults(true);
  memoryTest.setMaxFailingAddressesToReconstructPerPin(1024);
  memoryTest.setFailAddressListOrdering(MTP::ORDERING_CYCLE);

  // Execution is called only for first site
  ON_FIRST_INVOCATION_BEGIN();
  {
    memoryTest.execute();
  }
  ON_FIRST_INVOCATION_END();

  MTP_MEMORY_PATTERN &march6n = memoryTest.getMemroyPort("A").getMemoryPattern("march6n");
  ARRAY_ADDRESSES addressList;
  LONG nr_addresses;

  nr_addresses = march6n.getFailingAddressList(0,1024, &addressList);

  // Loop over address list
  for(int i = 0 ; i  < nr_addresses ; i++)
  {
    MsgStream msg;
    msg << x =  << addressList[i].x << endl;
    msg << y =  << addressList[i].y << endl;
    msg << z =  << addressList[i].z << endl;
    // Print out address to report window  
    cout << msg.c_str(); 
    // Store address in datalog 
    PUT_DATALOG(msg.c_str());
  }

  //generate bitmap file.
  march6n.setBitMapFilePath("/data/bitmaps");
  march6n.addBitMapFileUserComments("Manual Bitmap");
  march6N.setBitMapFileName("march6N");
  march6n.generateBitmapFile();
}

Example 2

Use Syntax 4 to retrieve falling addresses for all data pins.

/*
//Data type "DeviceCycleToAddrWordMap", "DeviceCycleToAddrWordMapIt" are defined in /opt/93000mts/mts/execution_engine/include/MtpTypes.h

typedef struct {
  long x;
  long y;
  long z;
  long long dataWord; // one bit for one data pin, LSB is the most right bit
  long long expWord;  // one bit for one data pin, LSB is the most right bit
} ADDRESS_WORD;

typedef std::multimap<long long, ADDRESS_WORD>   DeviceCycleToAddrWordMap;
*/

void MemoryTest::run() 
{
  MTP_MEMORY_TEST memoryTest;

  memoryTest.enableAddressBasedResults(true).setImmediateBitmapToFile(true);
  memoryTest.setMaxFailingAddressesToReconstructPerPin(-1);
  memoryTest.setFailAddressListOrdering(MTP::FAIL_CYCLE);
  memoryTest.setResultPins("@");
  memoryTest.setMaxFailingAddressesToLogPerPin(10);

  // Execution is called only for first site
  ON_FIRST_INVOCATION_BEGIN();
  {
    memoryTest.execute();
  }
  ON_FIRST_INVOCATION_END();

  DeviceCycleToAddrWordMap cycleToAddrWordMap;
  MTP_MEMORY_PATTERN &march6n = memoryTest.getMemroyPort("A").getMemoryPattern("march6n");

  long nr_addr_word = march6n.getFailingAddressList(10, cycleToAddrWordMap);
  cout << "Listing failing address word:" << endl;
  for (DeviceCycleToAddrWordMapIt wordIt = cycleToAddrWordMap.begin();
      wordIt != cycleToAddrWordMap.end();
      wordIt++)
  {
    cout << "cycle: " << wordIt->first
           << ", address: " << wordIt->second.x << "." 
<< wordIt->second.y << "." << wordIt->second.z
           << ", dataword: " << hex << wordIt->second.dataWord
           << ", expWord:" << wordIt->second.expWord << dec << endl;
  }
  cout << "Address word count is " << nr_addr_word << endl;

  TEST(memoryTest); 
}
