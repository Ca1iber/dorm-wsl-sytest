GETN? - (GEt Testdata Name)

The GETN? query returns the identifiers and namespaces of test point events (td elements) that are associated with the current start pattern for the specified pins. You can either query the names of all events within a cycle range, or only those of the measurement events within a range of measurement events.

Predependencies

A test point pattern must have been executed for DC Scale pins. This pattern must also be the current start label.

Syntax

GETN? {range_type}, {index}, {length}, {(pinlist)}

returns

GETN? {range_type}, {index}, {testdata_name}, {identifier}, {(pinlist)}

Parameters

range_type

This parameter determines how the index and length parameters are to be interpreted. Possible options are:

CYCL index and length refer to cycles

RSLT index and length refer to results

start_index

In the query, this parameter specifies the start of the range to be scanned. In the reply, it specifies the index of the event whose name is reported.

Depending on the range_type parameter, this is a cycle or a result index.

length

Specifies the length of the area to be scanned. Depending on the range_type parameter, this is a number of cycles or of results.

name_space

This reply parameter specifies the name space of the respective event, as defined with DFTD.

identifier

This reply parameter specifies the identifier of the respective event, as defined with DFTD.

pinlist

Only DC Scale pins are taken into account.

Application

DC Dynamic

Example

> FTST?
< FTST P

> VALR? (Sdd)
< VALR CONS,10,(Sdd)
 
> GETN? RSLT,0,1,(Sdd)
< GETN RSLT,0,"powercycle","meaLimV_0.0_0.2",(Sdd)
 
> VALC? (Sdd)
< VALC CONS,0,50000,(Sdd)
 
> GETN? CYCL,0,41000,(Sdd)
< GETN CYCL,63,"powercycle","setRange7V",(Sdd)
< GETN CYCL,40199,"powercycle","meaLimV_0.0_0.2",(Sdd)

Functional changes

  1. Introduced in SmarTest 6.5.2
