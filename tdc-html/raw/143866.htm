pin()

Specifies the pin(s) for the following DC actions. It indicates the ending of the setups for the previous pin(s) and the start of the setups for the specified pin(s).

Do not specify different types of pins in the same function pin(). To set up different types of pins in the same line of code, put different types of pins in separate functions of pin() with the same execute().

In SmartRDI 2.4.4., a single .execute() call is supported with automatic handling of the required serialization for a BADC-HIZ measurement. This is valid for shared BADCs over pins and over sites. See Example 2 and Example 3 at the bottom of this topic.

Syntax

pin(const string& sPin, TA::PinType instrument = TA::PPMU);
List of parameters

Parameter

Description

sPin

The pin on which the following setups will be done. Its value can be a pin, a pin group, a port name as a pin group, the pins or pin groups separated with comma, or all pins.

High voltage pins in static DC value measurements are supported.

 

instrument

(Only for digital pin)

The instrument used to do the measurement. It can be:

  • TA::PPMU (default): Either PPMU is used to measure, or the board ADC connected through PPMU is used to measure.

    When this option is used with high voltage pins, the board ADC connected through PPMU will be used to measure the voltage.

  • TA::BADC: Board ADC connected through DC relays is used to measure.

    When this option is used with high voltage pins, the board ADC will be used to measure the voltage.

Examples

Example 1

rdi.dc("vMeas").pin("pinA", TA::BADC).vMeas().execute();

Example 2: Shared BADCs over pins

Below is an example of BADC-HIZ measurement on multiple pins which share the same BADC. In this example, pins A and B share the same BADC.

RDI_BEGIN();
 rdi.dc().pin("A,B", TA::BADC).vMeas().execute();
RDI_END();

Example 3: Shared BADCs over sites

Below is an example of BADC-HIZ measurement on a single pin across multiple sites which share the same BADC. In this example, we assume pin "DATA36" is over 4 sites: 10308, 10310, 10312 and 10314 sharing the same BADC.

RDI_BEGIN();
 rdi.dc().pin("DATA36", TA::BADC).vMeas().execute();
RDI_END();

Functional changes

  1. Introduced in SmartRDI 2.1.0
  2. SmartRDI 2.3.0: Supports high voltage pins in static DC value measurements.
  3. SmartRDI 2.4.0: Supports a port name as a pin group.
  4. SmartRDI 2.4.4: Supports a single .execute() call for shared BADCs over pins, and for shared BADCs over sites in a BADC-HIZ measurement.
