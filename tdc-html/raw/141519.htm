MTP_MEMORY_TEST.setRAEndAction()

Defines actions after a redundancy analysis is completed.

Use this function only after you have set setRAEnablingMode() to MTP::RA_ENABLE_END.

Syntax

MTP_MEMORY_TEST& setRAEndAction (const MTP::RA_END_MODE & mode);
Parameter

Parameter

Description

mode

The default mode is MTP::RA_END_EXECUTE.

See the available modes in the following table.
Available options of parameter: <mode>

Option

Description

MTP::RA_END_EXECUTE (default)

Ends the redundancy analysis and starts repairing if the repair is specified.

The corresponding RA begin action is MTP::RA_BEGIN_START.

MTP::RA_END_SAVE_BFD

Use this mode only when a redundancy analysis contains multiple testflows (the first testflow has been set to MTP::RA_ENABLE_BEGIN with the setRAEnablingMode() function).

This mode saves the newly generated overlay fail map as a fail bit map file (.bfd). The name of the file is the time stamp and the RA service ID (RA execution name, DUT information, and port name). In addition, a BFDL file whose name is the RA service ID is generated to log the path of the overlay bit map file.

The corresponding RA begin action is MTP::RA_BEGIN_USE_BFD.

Note that, to use this mode, you also need to set setRAGenerateOverlaidBfd() to true.

Return value

There is no return value.
