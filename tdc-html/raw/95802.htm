StartSmartestSession

This command triggers the startup of a new SmarTest session. When the startup procedure reaches the start point, the event SMARTEST_SESSION_STARTING will be notified. If there is no failure during the startup, the event SMARTEST_SESSION_READY will be notified and the newly created session ID will be returned. The event SMARTEST_SESSION_READY means that the SmarTest session is ready for use.

SUCCESS will be returned if the command is successfully issued. Otherwise an error object indicating the error code, description and severity will be returned.

Code

Description

Severity

PARAMETER_EXCEPTION
  • The value of the parameter "ONLINE_MODE" is empty.
  • The value "XXX" of the parameter "ONLINE_MODE" is not valid; only "ONLINE" or "OFFLINE" is allowed.
  • The value of the parameter "USER_MODE" is empty.
  • The value "XXX" of the parameter "USER _MODE" is not valid; only "PROTECTED", "ENGINEER" or "SUPERVISOR" is allowed.

Recoverable

ILLEGAL_OPERATION
  • Online session is already running
  • Can't start a new session because the maximal number of sessions (5) has been reached.

Recoverable

Constraints

  • SmarTest allows only one online session running at a time.
  • Depending on the system controller configuration and the customer device, SmarTest allows a maximum of five simultaneous offline sessions.

Parameters

I/O

Parameter

Description

I

ONLINE_MODE

A string value indicating the online/offline mode. It can be ONLINE or OFFLINE.

I

USER_MODE

A string value indicating the user mode. It can be ENGINEER,SUPERVISOR or PROTECTED.

O

SESSION_ID

The ID of the newly created SmarTest session.

Prototype

ParamList opParams, opResult;
Status operation("StartSmartestSession",opResults, opParams);

Example

This example start an online SmarTest session with the supervisor mode.

ParamList opParams, opResults;
opParams["ONLINE_MODE"] = "ONLINE";
opParams["USER_MODE"] = "SUPERVISOR";
xoc::hvmapi::Status retVal = operation("StartSmartestSession", opResults, opParams);
if(!retVal.isError())
{
  cout <<"Successful startup and the session ID is s%\n" << opResults["SESSION_ID"] <<endl;
}
else
{
  cout <<"\nerror code" << retVal.code() <<"\nerror description"<< retVal.text()<<endl;
}
