TIMING_OFFSET_SEARCH_RESULT_PINS

This class defines the relationship between setup pins and result pins of timing offset search. It is a sub-class of TIMING_OFFSET_SEARCH_TASK. You cannot directly create an object with it.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TimingOffsetSearchResultPins.h.

Class definition

setResultPin(const STRING& resultPin);
setResultPin();
STRING getResultPins();

Member functions

setResultPin()

setResultPin(const STRING& resultPin);

This function defines result pins for the setup pins. The result pins and setup pins must reside on the same physical test processor. Otherwise an exception will be thrown.

Parameter

I

resultPin

The pins contributing to the test result.

setResultPin()

setResultPin();

This function removes the defined relationship between result pins and setup pins. It defines the standard relationship where result pins are the same with setup pins. For pins of differential mode, the result pin is the master pin of the differential pair.

getResultPins()

STRING getResultPins();

This function returns the defined result pins of the timing offset search.
