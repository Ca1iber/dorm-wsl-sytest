Using the Signal Analyzer Tool

Subtopics

  1. Starting Up Signal Analyzer
  2. Passing Waveform into Signal Analyzer
  3. Downloading waveform patterns from the Signal Analyzer
  4. Converting existing waveforms to the new ASCII format

This section tells you how to start the Signal Analyzer Tool and how to pass the waveform into this tool for debugging.

The Signal Analyzer Tool also provides the following functions:

  • Loading a data log file and selecting the waveform contained in the file (Load Datalog... and Select Waveform...)
  • Creating arbitrary waveforms (see Generate)
  • Modifying the waveforms (see Test Mask..., Translate..., Inject Jitter... and Cable Simulation...)
  • Calculating the harmonic distortion and inter-modulation frequencies (see Harmonics...)
  • Setting up vectors for DSM testing (see DSM...)
  • Copying and pasting waveforms (see Copy/Paste Waveforms)
  • Deleting all (see Delete All) waveforms listed in the Result Waveforms table
  • Assigning user defined functions (see Assign User Defined Function) to create a dedicated waveform-analysis function
