Throughput and Test System Resources

The swing adjustment is integrated into the timing setup. For each level set to be adjusted an appropriate timing set is needed. All these sets are downloaded into the test system memory in advance. During the test the sequencer switches between the sets. Therefore swing adjustment does not reduce throughput.

Note Note that swing adjustment can be quite resource consuming. That is because you must create a timing set for each level set you want to adjust. Simply creating all possible permutations of level and timing sets isn‘t the best way. In most cases you can reduce the consumption of test system resources to a minimum with little effort as explained in the next section.
