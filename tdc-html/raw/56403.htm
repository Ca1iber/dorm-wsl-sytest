Editing the model file to optimize license use

Note To optimize license use you could create a variety of model files and switch them as needed. We do not recommend this approach. Instead you should apply the device license file concept. For details see The device license file.

Floating licenses allow multiple users to check-out hardware licenses from a centralized pool of licenses. The model file allows you to specify exactly how many licenses you will request on the basis of channels selected, and to select different hardware parameters for each channel (although the same timing bundle must be used for each channel in the same model file).

Since hardware test licensing is scalable, by specifying the minimum parameters required to execute your tests, you enable other users to access licenses for the remaining available licensed features.

It is good practice to specify the minimum requirements necessary for your test, so other users can optimize their use of the available licensed hardware features.
