Topic 111086

FwEscape

This method executes the setup commands, sets the test system to the specified state and then executes the execution command. The results will be sent to the selected report media.

Parameters

Parameter

Type

Description

setupCommand

STRING

The setup command to execute.

executionCommand

STRING

The execution command to execute.

testerState

STRING

Set system state before executing the FW command. It can be UNCHANGED, CONNECTED or DISCONNECTED.

output

STRING

Whether print the execution result in UI report or not. Its value can be ReportUI or None.
Note When using this test method, the primary sets specified in this test suite are not used. The primary sets of the previously executed test suite are used. To execute this test method with the specified primary sets, insert the firmware command APRM CNL at the beginning of FW execution command.
