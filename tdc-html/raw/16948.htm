This section describes how to set up level equations and specifications in general and for specific configurations.

About this task

With the Level Setup Tool, you can:

  • set the driver levels for the i pins,
  • set the thresholds for the o or io pins,
  • set the termination for the o or io pins,
  • set up the DPS.

Whether you are viewing I/O levels or DPS levels, the Level Setup window always keeps you up to date with the active level settings in the test system hardware. And, conversely, whenever you edit a level value, your changes take effect in the hardware as soon as you exit the field that you are editing.

Procedures

Opening the Level Setup tool

In the Test Program Explorer, double -click the Level icon.

When you first open the Level Setup window, the I/O pins view is shown as default.

The I/O pins view shows a list of the I/O pins and their respective definitions.
