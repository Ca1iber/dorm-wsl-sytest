Topic 123748

Prepare device setup

About this task

This section only provides details to the d2s specific setup of your device. This task needs to be carried out prior to configuring the d2s specific code.

Note The d2s-framework only supports x1 and 1/x (padding)-modes for serial protocols.

Before you begin

Create the setup files for your device. For details on how to set up level and timing for your device as well as vectors and pins, refer to chapter Setup and Result Tools.

Procedure

  1. Generate a write-template label.

    The register write pattern consists of the address and the data to write.

  2. Generate a read-template label.

    The register read pattern consists of the address and the data to read.

    Note Reading from a register always requires to strobe to 'L'.
  3. Generate a wait-template label.

    The register wait pattern has to contain one single repeat statement with the corresponding break state of the device.

    Note The single repeat will be adjusted by the d2s-framework to match the wait time you specify in your test method code.

What to do next

Prepare your test method code.
