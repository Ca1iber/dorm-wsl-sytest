Topic 103248

Install RF cables N2398A-003 in probe card ring

About this task

This task is about installing the RF cables into the Port Scale RF probe card ring.

Before you begin

Make sure you have a Torx T20 and a thread-on tool available. See also 12" Wafer Prober Interface Parts List.

Procedure

  1. Mount the RF cable so that the elbow of the SMP female connector at the other end of the cable points out of the ring.
  2. Secure the RF cable with the nut using the thread-on tool.

What to do next

Mount the probe card ring on the probe card stiffener.
