eventLoopExit

This signature is to exit the HVMAPI internal event loop. It is the only way to quit the HVMAPI internal event loop.

Prototype

xoc::hvmapi::Status eventLoopExit();

Example

This example defines an event listener that exits from the HVMAPI internal thread when the event SMARTEST_SESSION_TERMINATED is notified.

void myGlobalHandler (const string &evName, 
             const ParamList &evParams, 
             unsigned long sec, long usec, 
             const string &sessionId)
{
  if ( evName == "SESSION" ) 
  {
    const string &ssnState = evParams["SESSION_STATE"];
    if ( ssnState == "SMARTEST_SESSION_TERMINATED" ) 
    {
      eventLoopExit(); 
      //this will terminate the HVMAPI internal execution thread
    }
  }
}
