Introduction of the Pin Configuration Tool

Subtopics

  1. Pin
  2. Pin group
  3. Port
  4. Alias set
  5. Utility purpose

With the Pin Configuration tool you edit the pin configuration file.

The pin configuration file is the first setup file that must be completed before you can test a new device. If the pin configuration details have not been entered, the software will not let you enter details about the DUT in any other setup window.

Use the Pin Configuration Tool to define pins, pin groups, ports, and the utility purpose, see Elements of the Pin Configuration Tool
