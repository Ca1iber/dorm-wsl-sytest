TPI functions

The table below identifies some of the functions found in the Test Programming Interface (TPI) library.

Some functions from the TPI library

Function

Description

HpInit()

Initializes Test Programming Interface (TPI). Allocates all required inter-process communication (IPC) resources. This function must be called first by the test shell, but after SmarTest is up and running in supervisor mode.

ChangeDevice()

Lets you change the currently used device to another device.

DataManager()

Allows access from within a program to the Test Program Explorer Process. The programming interface is a mirror image of the Test Program Explorer interface. Therefore, this procedure can be used to load the test program.

HpTerm()

Terminates the Test Program Interface (TPI). This procedure releases IPC resources and must be called at the end of your program (for example, run_supervisor).
