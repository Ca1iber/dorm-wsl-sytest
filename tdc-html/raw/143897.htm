Inserting digital capture actions in an existing pattern with SmartRDI

You can insert some digital capture actions for some specific pins in an existing pattern to do the digital capture test.

Procedure

  1. Create a digital capture test with the class digCap().
  2. Specify the existing label to use with the function label().
  3. Specify the pins to do the digital capture with the function pin().
  4. Specify the vector range to insert the actions with the function addVecRange().
  5. Specify the number of samples to capture with the function samples().
  6. (optional) Specify the number of initial discards, inter discards and bit per word with corresponding functions if needed.

    See bitPerWord(), initDiscard(), and interSkip().

  7. Execute the setups with the function execute().

Results

The code to insert digital capture actions in an existing pattern is created.

Example

RDI_BEGIN();
  rdi.digCap("mps").label("lpDcap_new").pin("DATA2,DATA6").addVecRange(3,15).samples(10).execute();
RDI_END();

In this example, the digital capture actions will be inserted in the vector range (3,15) of the pattern lpDcap_new for the pin DATA2 and DATA6. 10 samples are captured for each pin.
