Topic 141124

DIGITAL_OFFSET_SEARCH_PINS.setConfiguration()

Sets the configuration data for an offset search.

Syntax

DIGITAL_OFFSET_SEARCH_PINS& setConfiguration(DIGITAL_OFFSET_SEARCH::DigitalOffsetSearchConfigDataType & configdata);
Parameter

Parameter

Description

configdata

The configuration data, such as search type, resource type, start value, stop value, etc.. For more data types, see DigitalOffsetSearchConfigDataType.

Return value

A reference to the DIGITAL_OFFSET_SEARCH_PINS object.

Related information

DigitalOffsetSearchConfigDataType

Functional changes

  1. Introduced in SmarTest 7.2.1
