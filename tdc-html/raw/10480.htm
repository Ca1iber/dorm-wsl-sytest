Topic 10480

Introduction

This is a facility that allows you to make current measurements triggered by an external source. This trigger can be connected to a tester channel driver which in turn is controlled by your test pattern. This means that the measurement can be included as part of a functional test.

This function is controlled by the following three firmware commands:

DPSE, DPSE? - (Define Power Supply External trigger measurement)

PSEE - (Power Supply External trigger measurement Execute)

PSER? - (Power Supply External trigger measurement Read results)
