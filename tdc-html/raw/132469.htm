TMU_PINS.uploadPeriodResults()

Upload the period result data into the result cache. (Deprecated)

Note The TMU_PINS upload methods are deprecated, but for compatibility reasons they are still usable. We recommend using the new function TMU_TASK.uploadPeriodResults().
Note Normally all upload methods loads results for all sites except they are called inside a FOR_EACH_SITE block.

Syntax

void uploadPeriodResults(TMU_RESULTS& resultCache, Boolean averaged = TRUE);
void uploadPeriodResults(TMU_RESULTS& resultCache,STRING& ResultHandle,Boolean averaged = TRUE);
void uploadPeriodResults(TMU_RESULTS& resultCache,const char* ResultHandle,Boolean averaged = TRUE);
Parameters

I/O

Parameter

Description

I

resultCache

The TMU_RESULTS object to store the period result data.

I

resultHandle

The result handle to access.

I

averaged

Whether to do the averaging for the result data.

Return value

There is no return value.

Related information

TMU_PINS.uploadRawResults()
