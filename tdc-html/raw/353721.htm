Opening additional signals

You can display more than one signal using multiple instances of the Hardware view.

Before you begin

You have updated the hardware information in the Pin Browser view.

In the Hardware view, Link with Editor and Selection is deselected.

Procedure

  1. Make sure that the Link with Editor and Selection is deselected.
  2. In the Pin Browser view, open the shortcut menu (right-click) for the signal you want to open (P03_SIG_03 in the screenshot below).

  3. From the shortcut menu, select Show in Hardware.

    A new Hardware view tab is opened displaying the hardware diagram for the selected signal.

Results

You have opened a new instance of the Hardware view displaying an additional signal.

Functional changes

  1. Introduced in SmarTest 7.10.0
