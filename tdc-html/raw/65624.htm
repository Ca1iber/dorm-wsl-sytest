To create a DC test program, first, set up the DC resources using the following APIs, depending on the DC resource type and your purpose.

Note Use FlexDC APIs for dc test programming to save test time.

To create a DC test program for pin PMUs

The following APIs can be used as shown in DC Test Programming with PPMU.

  • PPMU_SETTING, PPMU_PIN_SETTING
  • PPMU_RELAY, PPMU_PIN_RELAY
  • PPMU_MEASURE, PPMU_PIN_MEASURE
  • TASK_LIST

Using these APIs, you can program an individual force voltage or current value per pin, apply it to the pin, and perform a measurement.

After the measurement finishes, the pin PMU remains connected to the pin and continues to output. Alternatively, you can set up your program such that the pin PMU stops the output and relays are disconnected after the measurement finishes.

To create a DC test program for DPSs

The following APIs can be used:

  • DPS_TASK
  • DPS_PIN_TASK

The DPS_TASK and DPS_PIN_TASK APIs allow you to set up your DC test program so that you can make DPS measurements in parallel when performing single-site or multi-site testing.

Note If you need to use auto-ranging in DPS current measurements or need to suppress activation of the level/timing-related primaries that are specified in the Testsuite dialog in the DPS measurements, you must use the DPS_VFIM API. In all other cases, it is recommended that you use the DPS_TASK and DPS_PIN_TASK APIs to set up your DC test program for DPS tests. (Auto-ranging and preAction "NPRM" are not supported by the DPS_TASK API.)

The DPS_TASK and DPS_PIN_TASK APIs provide the following benefits in DPS measurements:

  • allow you to make DPS measurements in parallel when performing single-site or multi-site testing. Parallel testing can help you achieve higher throughput.
  • allow you to make different kinds of DPS measurements in parallel when performing single-site or multi-site testing.
  • Both external-triggered and software-triggered DPS measurements are supported when using the DPS_TASK and DPS_PIN_TASK APIs.

The DPS_TASK API forces the voltage defined in the primary DPS set or primary level spec/equation sets and performs the current measurement. If you need to modify the force voltage values for the DPS, change the level-related primaries, (primary level spec/equation sets or primary DPS set). To make these changes, use the PRIMARY_STATUS API or modify the level specification values with the LEVEL_SPEC API.

After the measurement finishes, the DPS keeps the connection to the pin and continue to output the voltage. If you want to stop the DPS outputs, perform the DISCONNECT sequence.

To execute a DC test and retrieve the measurement results, use the appropriate member function of the DC API.

The sub-sections in DC Test Programming explain each step in typical DC test programming and show DC test-specific information only. See the following sections for the information that is in common with AC test.

  • Accessing Test Control Options
  • Computing Measurement Values
    Note You need to execute the CONNECT sequence before the test, to apply the power to DUT and connect the target pins to tester resources. To do this in a test method program, use the CONNECT API. If you perform continuity tests with the DC APIs, you must execute the DISCONNECT sequence before the tests. To do this in a test method program, use the DISCONNECT API.
