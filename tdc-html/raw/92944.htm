DSP_RF_DDC()

In most applications, users will not need to call the DSP_RF_DDC() function, because digital downconversion (if it is needed) is performed automatically by other DSP functions, such as DSP_RF_MOD_POWER(). The DSP_RF_DDC() function is provided for the benefit of users who wish to create their own custom DSP functions within a TestMethod, and therefore need direct access to digital downconversion function.

Normally, captured IF data is processed by the RTSPU (real-time signal processing unit) in the MB-AV8 card, which down-converts the IF to DC (that is, to a signal centered around 0 Hz) and generate a complex array from it. At bandwidths greater than 22 MHz, however, the RTSPU is not used; instead, raw "real" data is captured in the from of an ARRAY_COMPLEX, in which only the real values are valid (r + j0). The DSP_RF_DDC()function performs the necessary data conversion, and fills in the imaginary component (r + jn).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_RF_DDC(const ARRAY_D& sourceData, DOUBLE sampleRate, DOUBLE centerFreq, ARRAY_COMPLEX& result, const INT applyFir);
DSP_RF_DDC(const ARRAY_D& sourceData, DOUBLE sampleRate, DOUBLE centerFreq, ARRAY_COMPLEX& result, const INT applyFir, INT* numValidSamples);
DSP_RF_DDC(const ARRAY_COMPLEX& sourceData, DOUBLE sampleRate, DOUBLE centerFreq, const INT applyFir);
DSP_RF_DDC(const ARRAY_COMPLEX& sourceData, DOUBLE sampleRate, DOUBLE centerFreq, const INT applyFir, INT* numValidSamples);
Parameters

I/O

Parameter

Notes

I

sourceData

An ARRAY_COMPLEX (array of complex numbers) representing the measured "real" data (the imaginary component is not valid).

I

sampleRate

The sample rate of the measured waveform data.

I

centerFreq

The frequency at which the IF is measured.

I

applyFir

Apply a FIR filter to suppress the images after the DDC is applied.

I

numValidSamples

The number of valid samples after the DDC has been applied. This is currently 128 samples less than the length of sourceData
Note The sourceData array is not returned as a result by this function; it is corrected "in place".

Example

DOUBLE measuredPower = 0;
ARRAY_COMPLEX cData = MEAS_DEF("myModPwrMeas").getComplexWaveform(); 
ARRAY_D measParams = MEAS_DEF().getParameters(1,0);
DOUBLE sampleRate = measParams[TM::MEAS_SAMPLE_RATE];
DOUBLE centerFreq = measParams[TM::MEAS_IF_FREQ]; 
DSP_RF_DDC(cData, sampleRate, centerFreq);

Functional changes
