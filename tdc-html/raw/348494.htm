Topic 348494

Adding entitlement IDs and organization to a user account

If you can login to the Advantest License Portal but cannot find a specific entitlement in the portal, it is possible that the subsidiary organization ID is not assigned to your account. The required subsidiary organization is added using the missing entitlement ID.

Before you begin

Make sure that you have the following:

  • Access to the Advantest License Portal.
  • An entitlement ID that is not listed in the Advantest License Portal (the organization is not assigned to you).

Procedure

  1. From the License Portal, select the License Management tab.
  2. Click Activation via entitlement (Simple Activation).

    The Simple Activation page is displayed.

  3. Click Entitlement not listed…

    The Assign new organization dialog is displayed.

  4. Enter the entitlement ID that you want to add and click Assign.

Results

The entitlement is added to the pool of entitlements and your user is associated with the organization to which the entitlement belongs.

Functional changes

  1. Introduced in SmarTest 8.0.8
