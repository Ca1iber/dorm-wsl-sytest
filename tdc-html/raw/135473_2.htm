Address-based results mode for multiple patterns in one main label

A new member function MTP_MEMORY_TEST.setMultiPatternResultMode() and a new parameter Multi_Pattern_Result_Mode for ExecutionEngine test method lets you set the mode to generate and log the address-based test results for all memory patterns belonging to one main label.
