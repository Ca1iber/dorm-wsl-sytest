Topic 142823

average()

Specifies the number of samples used to do the averaging. The result of the measurement has been averaged.

The function can be used in the code‑based mode and in the pattern‑based mode.

Note DC scale cards feature hardware based averaging that is controlled by function average(). Hardware based averaging can be used in pattern‑based mode. The required sample time depends on the sample rate of the ADC and the number of averaged samples. The time between the measurement events of a digitizer wave that is defined by functions FS(), sampleCycle(), or samplePeriod() must always be larger than the time that is required for averaging. Violating this rule will result in lost measurements: A flag "Distance too small" will be set in in this case. The state of the flag can be checked by command TSST? - (TeSt STatus).

For accuracy considerations, refer to member function number of samples() of API PPMU_PIN_MEASURE.

Syntax

average(int iSample);
List of parameters

Parameter

Description

iSample

The number of samples.

The default value is 1.

For DC Scale channels, with exception of XPS256, the number of samples must be a power of 2.

Application notes

Replacing average() with measFilter() on XPS256 pins
The average() function for XPS256 pins utilizes hardware based averaging for calculating the average of multiple consecutive samples on board. Using the average() function limits the effective maximum sample frequency to
  • 1.5 MHz / Number of averaged samples.
The average() function may be replaced by the measFilter() function to avoid this limitation. The digital low-pass measure filter behaves like a simple RC filter. Therefore, not only the signal settling time but also the measure filter settling time must be considered when programming the delay time of the measurement by function measWait().

For more information, refer to application note Measure filter settling time.

Example

rdi.dc("multi1").pin("pinA").vMeas().average(20).execute();
