Physical expected edge action (physical_expected_edge_action)

This can be one of N, E0, E1, EI, EX, EU, W0, W0, W1, WI, WX, WU, WC, . (period), L, H, M, EM, X, U, WL, WH or WM.

N

No action.

E0

Edge compare to 0.

E1

Edge compare to 1.

EI

Edge compare to intermediate.

EX

Edge compare to mask.

EU

Edge compare to unstable.

W0

Window open with compare to 0.

W1

Window open with compare to 1.

WI

Window open with compare to intermediate.

WX

Window open with compare to mask.

WU

Window open with compare to unstable.

WC

Window close.

.

Can be used instead of N.

L

Can be used instead of E0.

H

Can be used instead of E1.

M

Can be used instead of EI.

EM

This can also be used instead of EI.

X

Can be used instead of EX.

U

Can be used instead of EU.

WL

Can be used instead of W0.

WH

Can be used instead of W1.

WM

Can be used instead of WI.
