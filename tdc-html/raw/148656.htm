insertVec()

Specifies a line number in a pattern where you want to apply dynamic DC measurement actions.

Supported DC actions are such as iForce(), iForceRange(), iMeas(), vForce(), vMeas(), and restoreRange(). When using iMeas() or vMeas(), average() and limit() can be used.
Note DC measurement actions cannot be applied to vectors that have Sequencer instructions.

You can apply multiple dynamic DC actions on a pattern. When more than one lines in the pattern are applied with DC actions and the applied pins are the same, the number of lines between any two of these places must be greater than 32. Otherwise, errors will be generated.

To obtain the measured values, use getValue() or getMultiValue().

insertVec() can be used for DC Scale DIG/SIG pins only.

Syntax

insertVec(int iVecNum);
List of parameters

Parameter

Description

iVecNum

The line number in a pattern where you want to perform DC actions.

Examples

RDI_BEGIN();
  rdi.dc("dynamic").label("label")
                   .pin("pinA")
                   .insertVec(55).vForce(5)
                   .insertVec(90).vForce(3) // here, the line number cannot be lower than 87.
                   .pin("pinB")
                   .insertVec(65). vMeas()
                   .insertVec(185).vMeas()  // here, the line number cannot be lower than 97.
                   .execute();
RDI_END();

double value = rdi.id("dynamic").getValue("pinB");        // only the last measurement result

ARRAY_D values = rdi.id("dynamic").getMultiValue("pinB"); // multiple results

insertVec() with cont() for the same pin

rdi.dc().label("sLabel").pin("A").insertVec(50).vForce(1).cont();
rdi.dc().label("sLabel").pin("A").insertVec(100).vForce(2).cont();
......
rdi.dc().label("sLabel").pin("A").insertVec(1000).vForce(5).cont();
rdi.dc().execute();
