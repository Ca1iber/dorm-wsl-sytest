Alarm setup file

Subtopics

  1. Parameters in the alarm setup file
  2. Limit setup of alarm checking

An alarm setup file contains groups of limit setups for all the pins on which alarm checks are applied.

The alarm setup file must be stored in the root path or a sub-folder of the loaded device. We recommend using folder testmethod of the loaded device.

The path to the alarm setup must be defined by keyword ALARM_HANDLING_DCVI_SETUP_FILE of the RDI_Configure file.

Alarm setup file format

In an alarm setup file, a group of setups is called a SET. Each SET has a name and contains pins to be checked, global limit parameters, and local limit parameters.

An example of the file format: 

SET setName # Set name
GlobalLimit... = # Global limit parameter
GlobalLimit... = 
PINS pinName pinName # A pin name or several pin names
Limit... =  # Local limit parameter
Limit... =
  • SET: Specify a set name. The SET name can be any string but DEFAULT is reserved for default setups.
  • GlobalLimit...: Represent a global limit parameter.
  • PINS: Specify a DCVI pin group or pins on which alarm checks are applied.
  • Limit...: Represent a local limit parameter.
Pay attention to the following points:
  • Alarm checks are done only for the pins listed in the active SET.
  • If LimitLo and LimitHi are defined in the file, their values are applied for vClamp/vForce in alarm checking. The values of other specified parameters will be ignored, such as GlobalLimitRelForce, LimitRelForce, GlobalLimitRelClamp, and LimitMinRelClamp.
  • If there is no GlobalLimitRelForce or LimitRelForce specified in the file, the value of GlobalLimitMinDisForce or LimitMinDisForce is applied for vForce checks.
  • If there is no GlobalLimitMinDisForce or LimitMinDisForce, an error is thrown in the first run.
  • If there is no GlobalLimitRelClamp or LimitMinRelClamp, the vClamp values are used as limits for vClamp checks.

Alarm setup template

An alarm setup template file will be generated when the alarm handling is enabled by ALARM_HANDLING_DCVI_ENABLE = TRUE in the RDI_Configure file. Based on the template, you can create your own alarm setup file.

Debug value in the UI report window

You can set DEBUG_VALUE = TRUE in the alarm setup file to enable all the results of vMeas events displayed in the report window. For example, some alarm DC results in the report window are displayed as follows:

ID: id1, pin A = 0.5, pin B = 1.0, pin C = 2.0

ID: id2, pin A = 0.5, pin B = 1.1, pin C = 2.0

ID: id3, pin A = 0.6, pin B = 1.0, pin C = 2.1

The default value of DEBUG_VALUE is FALSE, which means that no results of vMeas events will be displayed.

If set in the alarm setup file, DEBUG_VALUE must be the first setup entry in the file.

Starting from 7.5.2, SmartRDI provides more information in the UI report window for debugging when the DEBUG_VALUE is enabled. See the example below.

Examples

Example 1

An alarm setup file 

DEBUG_VALUE = TRUE  # This must be the first setup entry in the file.

SET DEFAULT  # Applied by default
    GlobalLimitRelForce = 10%
    GlobalLimitMinDisForce = 10 mV
    GlobalLimitRelClamp = 10 mV

    PINS UB_AVI VDD_AVI VDD_PVI
    # No local limit value defined means that global values are applied.

SET A1
    # Alarm checks on VDD_AVI are skipped.

    PINS UB_AVI
    LimitRelForce = 10%
    LimitMinDisForce = 5 mV
    # Used for vForce checks.
    # vClamp settings are used for vClamp checks.
 
    PINS VDD_PVI
    GlobalLimitRelForce = 10% #
    GlobalLimitMinDisForce = 10 mV
    # Used for vForce checks.

    LimitRelClamp = 100 mV
    # Used for vClamp checks.

SET A2
    # Alarm checks on both VDD_AVI and VDD_PVI are skipped.

    PINS UB_AVI 
    LimitLo = 4.7  # default V
    LimitHi = 5.3
    # Used for both vForce and vClamp checks.
...
