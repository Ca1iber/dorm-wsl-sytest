Detailed Description

Enumeration Type Documentation

enum GIO_REASON

Reasons for returning from a read request.

These values are returned by gio_read() to indicate different termination conditions.

Enumerator
GIO_REASON_REQCNT 

Requested number of bytes was read.

GIO_REASON_CHR 

Termination character encountered.

GIO_REASON_END 

END indicator encountered.

Function Documentation

GIO_ERROR gio_clear ( IDID  id)

Clear an interface or device.

The exact behavior of this function depends on the interface type and on the access method which is used. For example, it will send an "SDC" command to a GPIB device session.

Attention
This function must not be used if the intent is to perform an "interface clear" on a GPIB interface. Use gio_gpib_send_IFC() instead.

(The reason for this restriction is that access methods for different types of GPIB interfaces behave differently when gio_clear() is given the IDID of an interface session. This is a protocol issue, not a software bug.)

GIO_ERROR gio_lock ( IDID  id)

Lock an interface or device.

gio_lock() places a device (or an entire interface) in a mode in which access is granted only to the client which locked it. Depending on the state of the lock waiting flag (see gio_set_lock_wait() for more information), all other clients will either hang or encounter errors (GIO_ERR_DEVICE_LOCKED) when they attempt to access a locked device or interface.

Attention
Behavior may differ between access methods when an attempt is made to lock the same interface/device via different IDIDs, or to nest calls to gio_lock() for a single IDID.

size_t  len,
int *  pReasons,
size_t *  pActual

Read data.

The function gio_read() reads a block of data from an interface or device. If no error occurs and the parameter pReasons is not zero, gio_read() returns in *pReasons a value indicating the condition (or conditions) which caused to operation to return; this value consists of separate bits (values of the GIO_REASON enumeration type). gio_read() also returns the number of bytes read in *pActual, if pActual is non-zero.

GIO_ERROR

GIO_ERR_NO_ERROROperation successfully completed.
otherAn error occurred.

pBufferBuffer into which data should be read.
lenSize of buffer.
pReasonsOUT: Reasons for termination.
pActualOUT: Actual number of bytes read.

GIO_ERROR gio_set_status_byte ( IDID  id,
uint8_t  stb 
)

Set status byte.

On a GPIB interface, gio_set_status_byte() sets the status byte which will be delivered to a controller performing a "serial poll". If the SRQ bit in stb is set, the SRQ line on the GPIB bus will be asserted.

Attention
This function may not work on all access methods or interfaces. Even when it works, restrictions may apply.
