Correlating data logs

  1. If the Base option is not grayed out, choose the base log from it.
  2. Check all data logs that you want to correlate with the base log.
  3. Click Finish.

A new correlation log is created that contains all tests from the selected log and all results for the same tests from the checked logs.

A correlation report is written to the console.
