APIs defined for the Concurrent Test Framework

The following APIs are defined in the concurrent test framework.

API to configure the concurrent test framework

CCTenableSMC

CCTregisterDGT

CCTregisterTx

CCTsetExecMode

CCTsetResultArea

CCTsetWaitTimeBeforeStart

CCT_ContinueCurrentTest

CCT_setContextPins

CCTsetConcurrent

CCT_changeLevelSpec

They are usually used in the init() function but not used in the other functions of the CCF test method template.

CCTgetExecMode

CCTgetMistriggeredSite

CCTgetResultArea

CCTgetResultHandle

CCTgetTestsuiteName

CCTgetUploadId

CCTgetLabelName

They are usually used in the preStart(), postStart(), process() and cleanup() function but not in the init() function of the CCF test method template.
