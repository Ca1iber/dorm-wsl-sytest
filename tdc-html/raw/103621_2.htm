SQLA, SQLA? - (SeQuencer Label Attribute)

The SQLA command associates attributes with a label. The attributes define the memory type and the pin mode context. The label must have been defined with the SQLB or APTS command. A change of the memory type is only possible as long as no vectors have been defined for the label.

SQLA

SQLA [type],{"name"},{"attr_key_1=[attr_val_1] [,attr_key_2=[attr_val_2] [,attr_key_3=[attr_val_3]]]"} [,(port)]

SQLA?

SQLA? [type], {"name"|ALL}, {"attr_key"|ALL|SAVE} [, (portlist)]

returns:

SQLAtype, {"name"},{"attr_key_1=attr_val_1, attr_key_2=attr_val_2} [,attr_key_3=attr_val_3]" [,(port)]

Parameters

type

Currently, LBL is the only possible value. This is also the default.

name

A sequencer label. If ALL is specified in the query, then all labels of the specified port are returned together with their attributes.

attr_key_i=

attr_val_i

Attribute-value pairs. Valid attribute names are:

PARA_MEM

Specifies the memory type for parallel vectors. Possible values are:

SM = standard memory (default for MAIN and SVEC)

NONE = no memory for parallel vectors (default for all label types except MAIN and SVEC)

SHMEM = memory shared for different sites of the same pin (only for 7.x, for details see Selecting the memory type.

HSER = memory for SmartLoop™ initialization patterns (see Defining a compliance pattern for pattern‑based SmartLoop testing)

An empty value will delete the attribute definition. This attribute can only be changed if the sequencer program of the label contains no GENV or RPTV instructions.

PARA_MCTX

Specifies the mode context that is associated with the label. A mode context defines a type (I, O, or IO) and a mode (std or fast) for every configured pin. You define mode contexts in the Pin Configuration tool. The default mode context, which sets the mode of every pin to std, has the name DEFAULT.

Note that within a test setup, the label must have the same mode context as the associated timing and level data.

If ALL is specified in the query, all attributes for the given labels are returned. If SAVE or an attribute name is specified in the query, only attributes explicitly defined for the given labels are returned.

port

This parameter is only evaluated if you specify ALL for the second parameter in the query. In this case, SQLA? will return the attributes of those labels that are associated with the ports specified here. The default for this parameter is the default port @ to which all pins belong.

Specify @@ to display attributes for all labels of all ports.

Application

The attributes given to a label determine where the vector data for the sequencer program can be stored.

Example

> APTS LBL,"test","table1" 
> SQPG? ALL,(@)
< SQPG 0,STVA,0,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,RPTV,10,5,,(@)
< SQPG 3,STOP,,,,(@)
< SQPG 4,STVA,16,,,(@)
< SQPG 5,STSA,,,,(@)
< SQPG 6,STOP,,,,(@)
> SQLA ,"test","PARA_MEM=SHMEM"
> SQPG? ALL,(@)
< SQPG 0,STVA,0,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,RPTV,10,5,,(@)
< SQPG 3,STOP,,,,(@)
< SQPG 4,STVA,0,,,(@)
< SQPG 5,STSA,,,,(@)
< SQPG 6,STOP,,,,(@)

This example changes the PARA_MEM attribute of the new label test from SM to SHMEM. Note the change of the address in command line 4.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.1: A new memory type SHMEM is available for sharing vector data between different sites.
