Parameter: temp_active_cooling

Insert the list of active cooling mode. In the case that the equipment comes with heaters and that the heaters have to be activated, you can do so by setting this parameter to "yes." temp_active_cooling will only be active, if temperature_control is set to "active" mode. The number of entries in the list must either match the number of entries of temp_chambers or one single entry may be inserted. In case you insert one single entry only, the active cooling of all chambers will be set to the mode of this entry.

Driver default: empty list

Changeable at run-time: yes

Applicable for: handlers and probers, plug-in dependent

Example 1: temp_active_cooling: ["yes" "no"]

Example 2: temp_active_cooling: "yes"
