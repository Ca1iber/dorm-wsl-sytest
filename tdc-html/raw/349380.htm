cont()

cont() can be used to link actions of different pins or work together with insertVec() and insertSub() in the dc() class, addVecRange() in the digCap() class, and smartVec() commands such as writeData(), readData(), writeBit(), and expectData() to simplify the programming of numerous measurements.

Combining different pins' actions together

When cont() is used to combine actions of different pins, it supports all SmartRDI classes.

For example, two pins are forced with current within an execute() action, the code snippet can be written as follows:
rdi.dc().pin("A").iForce(10 mA).cont();
rdi.dc().pin("B").iForce(100 mA).cont();
rdi.dc().execute();
The code snippet above is equal to 
rdi.dc().pin("A").iForce(10 mA)
        .pin("B").iForce(100 mA)
        .execute();
If an array is used to hold pins and parameters, write the code as follows: 
for (I = 0;I < n;i++)
    rdi.dc().pin(vpin[i]).iForce(iForce[i]).cont();
    rdi.dc().execute();

All the actions that are performed on a pin must be listed in one line.

Working together with insertSub() and insertVec() in the dc() class

cont() supports insertVec() and insertSub() in the dc() class. It can separate actions of different vector numbers on a pin to multiple command lines. Each insertion action with a vector number is listed as a command line with cont()

For insertVec(), inserting DC actions to a label without cont(): 
rdi.dc().label("sLabel").pin("A").insertVec(50).vForce(1)
                                 .insertVec(100).vForce(2)
                                 ....
                                 .insertVec(1000).vForce(5)
                                 .execute();
Using cont() to list each action in a command line:
rdi.dc().label("sLabel").pin("A").insertVec(50).vForce(1).cont();
rdi.dc().label("sLabel").pin("A").insertVec(100).vForce(2).cont();
...
rdi.dc().label("sLabel").pin("A").insertVec(1000).vForce(5).cont();
rdi.dc().execute();
For insertSub(), without cont(), you have to list all the subroutine insertion actions for the same pin as follows:
RDI_BEGIN();
  rdi.dc("meas").label("abc").insertSub(1).pin("pinA").vForce(0).iMeas()
                             .insertSub(2).pin("pinA").vForce(0).iMeas()
                             .insertSub(3).pin("pinA").vForce(0).iMeas()
                             ....
                             .insertSub(200).pin("pinA").vForce(0).iMeas()
                             .execute();
RDI_END();
Using cont() to simplify the code snippet as follows: 
RDI_BEGIN();
  for (i = 0; i < 200; i++)
      rdi.dc("meas").label("abc").insertSub(IddQVec[i]).pin("pinA").vForce(0).iMeas().cont();
      rdi.dc("meas").execute();
RDI_END();

Working together with addVecRange() in the digCap() class

For the digCap() class, cont() can be used together with addVecRange().

Using cont() together with addVecRange() for multiple capture position ranges:
rdi.digCap().pin("A").samples(100).cont();
rdi.digCap().pin("A").addVecRange(3,6).cont();
rdi.digCap().pin("A").addVecRange(10,20).cont();
rdi.digCap().execute();
The code snippet above is equal to the following one without cont(): 
rdi.digCap().pin("A").samples(100).addVecRange(3,6)
                                  .addVecRange(10,20)
                                  .execute();

Adding a vector range from a parameter list: 

rdi.digCap().pin("A").samples(100).cont();
  for (i = 0; i < listSize(); i++)
      rdi.digCap().pin("A").addVecRange(beginVec[i],endVec[i]).cont();
rdi.digCap().execute();

cont() usage in the smartVec() class

The smartVec() class supports cont() on the same pin. So cont() can be used to link actions of a pin in different command lines with or without label().

cont() works together with writeData() and readData() as follows: 
rdi.smartVec("id").pin("A").writeData(0x01,8,0).cont();
rdi.smartVec("id").pin("A").readData(8,10).cont();
...
rdi smartVec ("id").pin("A").writeData(0xff,8,90).cont();
rdi smartVec ("id").pin("A").readData(8,100).cont();

rdi smartVec ("id").execute();
The code snippet above is eual to the following one without cont():
rdi.smartVec("id").pin("A").writeData(0x01,8,0)
                           .readData(8,10)
                           ....
                           .writeData(0xff,8,90)
                           .readData(8,100)
                           .execute();

With label(): 

rdi.smartVec().label("sLabel").pin("A").writeData(0x01,8,0).cont();
rdi.smartVec().label("sLabel").pin("A").writeData(0x02,8,10).cont();
...
rdi.smartVec().label("sLabel").pin("A").writeData(0xff,8,100).cont();
rdi.smartVec().execute();
The code snippet above is equal to the following one without cont(): 
rdi.smartVec().label("sLabel").pin("A").writeData(0x01,8,0)
                                       .writeData(0x02,8,10)
                                       ....
                                       .writeData(0xff,8,100)
                                       .execute();
