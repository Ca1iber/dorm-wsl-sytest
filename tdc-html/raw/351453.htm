Topic 351453

JTAG predefined transactions

The Register Access library provides many predefined transactions for JTAG protocol, which can be used directly in a newly-created protocol.

Overview of predefined transactions for JTAG
Transaction Description
changeSpeed(double freq)

Change the JTAG clock speed. The JTAG speed can be changed in between transactions calls when register read/write sequence is defined.

The speed is adapted to the resolution of the tester period.

freq: The frequency of clock to be changed to.
comment(const string& comments)

Add comments to the generated pattern where the subsequent transaction is located.

For debug into the generated pattern, comments can be issued together with the subsequent transaction, for example, jtag.comment("AAA").toIdle(10).

comments: The user comments in string.
compareBits(RA::ULONG64 sendData, int bitLength, RA::ULONG64 expectedData, RA::ULONG64 mask = 0, const std::string& sendParamName = "")
Shift bits as the bits are being received from DUT, compare them against the expected data, but not terminate the shifting.
Transactions before and after comapreBits
Before After
compareBits() receiveBits()
receiveBits() recieveData()
sendBits() sendBits()
enterDR() sendData()
enterIR() compareBits()
compareData()
compareData(RA::ULONG64 sendData, int bitLength, RA::ULONG64 expectedData, RA::ULONG64 mask = 0, const std::string& sendParamName = "")

Shift bits as the bits are being received from DUT, compare them against the expected data, and terminate the shifting.

This transaction is used in the state of shift IR or shift DR. It receives data from DUT.
Transactions before and after compareData()
Before After
compareBits() exitIR()
receiveBits() exitDR()
sendBits()
enterDR()
enterIR()
Parameters:
  • sendData: The data sent to DUT while data is being received at the same time. JTAG is full duplex and data sent must be specified during receiving actions.
  • bitLength: The bit length of data to be received. It also has the same length of sending data.
  • expectedData: The expected data to compare with from receive actions.
  • mask: The mask setting. Bit 1 stands for mask, 0 stands for no-mask. If not set, no mask applies by default.
  • sendParamName: A tagged string name as reference to sending data if needed.
enterDR()

Enter the JTAG state to shift DR. The last state MUST be JTAG idle.
enterIR()

Enter the JTAG state to shift IR. The last state MUST be JTAG idle.
exitDR()

Exist the JTAG state from shift DR. The last state MUST be JTAG shiftDR.
exitIR()

Exist the JTAG state from shift IR. The last state MUST be JTAG shiftIR.
loopBegin(int numberOfLoops)

Issue the instruction command of loop begin.

A sequencer instruction command is inserted to the generated pattern. This transaction must be used in pair with loopEnd().

numberOfLoops: The number of loops.

For example, 
jtag.loopBegin(10);
jtag.sendByte(0xFF);
jtag.loopEnd();
loopEnd()

Issue an instruction command of loop end. This transaction must be used in pair with loopBegin().
matchLoopBegin(int numberOfLoops, bool continueOnFail = false)

Start a counted match loop.

This transaction must be used in pair with matchLoopEnd().
  • numberOfLoops: The number of loops.
  • continueOnFail: Specify whether the digital sequence continues when the maximum loop number is exceeded and no match is reached.
matchLoopEnd(const string& repeatStateCharacterList = "")

End a block of match loop. It must be used in pair with matchLoopBegin().

repeatStateCharacterList: The state character strings of pins when matching is evaluated. Format is: pinList1@Pattern1:PinList2@Pattern2:........PinListN@PatternN

Where:
  • PinLists are separated by comma.
  • Pattern is DVC name (1 character length) string streams. For example, 1000L1H.
  • Groups of Pinlists and patterns are separated by colon.

By default, it holds the last state of pattern.
receiveData(RA::ULONG64 sendData, int bitLength, const std::string& recParamName, const std::string& sendParamName = "")

Shift bits as the bits are being received from DUT and terminate the shifting.

This transaction is used in the state of shift IR or shift DR. It receives data from DUT. It terminates the data shift and MUST be followed by exitIR or exitDR.

Parameters:
  • sendData; The data sent to DUT while data is being received. JTAG is full duplex and the sent data must be specified during receive actions.
  • bitLength: The bit length of data to be received. It has the same length of sent data.
  • recParamName: A tagged string name in reference to received data. The name must be referenced in composeRegisterReadData().
  • sendParamName: A tagged string name in reference to sent data if required.
receiveBits(RA::ULONG64 sendData, int bitLength, const std::string& recParamName, const std::string& sendParamName = "")
Shift bits as the bits are being received from DUT but not terminate the shifting.
Transactions before and after receiveBits()
Before After
compareBits() receiveBits()
receiveBits() recieveData()
sendBits() sendBits()
enterDR() sendData()
enterIR() compareBits()
compareData()

There should be one of the mentioned transactions used before and after this receiveBits() transaction.
restoreSpeed()

Restore the speed to its specification by getClockSpeed().
sendBits(RA::ULONG64 data, int bitLength, const std::string& name = "")

Shift bits as the bits are being sent to DUT and not terminate the shifting.

This transaction is used in the state of shift IR or shift DR. When it has been executed, the last bit is still in shift IR or shift DR. Therefore it must NOT be followed directly by exitIR and exitDR. During bits are being sent, receives are masked.
Transactions before and after sendBits()
Before After
compareBits() receiveBits()
receiveBits() recieveData()
sendBits() sendBits()
enterDR() sendData()
enterIR() compareBits()
compareData()

There must be one of the above transactions used before and after.

Parameters:

  • data: The data to be shifted by bits. LSB first.
  • bitLength: The bit length of the data. MSBs that exceeds the length are cut.
  • name: A tagged string name as a reference to the data. The name can be used in composeRegisterWriteData().
sendData(RA::ULONG64 data, int bitLength, const std::string& name = "")

Shift bits as the bits are being sent DUT and then terminate the shifting. sendData is used in the state of shift IR or shift DR.

During bits are being sent, the receive actions are masked.
Transactions before and after sendData()
Before After
compareBits() exitIR()
receiveBits() exitDR()
sendBits()
enterDR()
enterIR()

Parameters:

  • data: The data to be shifted by bits. LSB first.
  • bitLength: The bit length of the data. Those MSBs that exceeds the length are cut.
  • name: A tagged string name as a reference to the data. The name can be used in composeRegisterWriteData().
setState(const string& tckState, const string& tmsState, const string& tdiState, const string& tdoState)

Set the state character list of JTAG pins.

The lengths of state characters on all pins must be the same.
  • tckState: The state character of pin TCK.
  • tmsState: The tate character of pin TMS.
  • tdiState: The state character of pin TDI.
  • tdoState: The state character of pin TDO.
shiftIR(RA::ULONG64 data, int bitLength, const std::string& name = "")

JTAG shift on IR data. This transaction behaves as the combination of

enterIR(), sendData(), and exitIR() in sequence.
Pin enterIR shiftData exitIR
TCK RRRR R...R RR
TMS 1100 0...1 10
TDI 0000 D...D 00
TDO XXXX D...D XX
TRST 1111 1...1 11

The previous JTAG state must be idle.
shiftDR(RA::ULONG64 data, int bitLength, const std::string& name = "")

JTAG shift on DR data. This transaction behaves as the combination of

enterDR(), sendData(), and exitDR() in sequence.
Pin enterDR shiftData exitDR
TCK RRR R...R RR
TMS 110 0...1 10
TDI 000 D...D 00
TDO XXX D...D XX
TRST 111 1...1 11
The previous JTAG state must be idle.
toIdle(int resetCycles )

Set to the Idle state. This transaction can be used to force JTAG state to jump to Idle by sourcing enough reset cycles.

TCK RRRR RRRR R
TMS 1111 1111 0
TDI 0000 0000 0
TDO XXXX XXXX X
toReset(int resetCycles )
Set to the idle state. This transaction can be used to force JTAG state to jump to Reset by sourcing enough reset cycles.
TCK RRRR RRRR
TMS 1111 1111
TDI 0000 0000
TDO XXXX XXXX
wait(double waitTime)

Set a hold time.

waitTime: The hold time in seconds.

Example

Transaction definitions for read operations:

virtual void defineReadRegister(JTAG& jtag, ULONG64 address, int numberOfData)
{
  jtag.shiftIR(ADDRESS, 8);
  jtag.shiftDR(address, 16);
  jtag.shiftIR(DATA, 8);
  jtag.enterDR();
  jtag.receiveData 0, 8, "data_out");
  jtag.exitDR();
}
