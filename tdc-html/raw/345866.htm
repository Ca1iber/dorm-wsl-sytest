  1. LAN communication flow for OSAI handlers

The OSAI handler communicates with the driver through LAN interface.

LAN driver configurations are provided for OSAI Neo Modula handlers.

You can find the configuration file here:

/opt/hp93000/phcontrol/drivers/Generic_93K_Driver/GenericHandler/OSAI/
