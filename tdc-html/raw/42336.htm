For each plug-in, there are several default driver configurations available which typically are specific to the individual handler models.

The locations of the default driver configuration files are as follows:

/etc/opt/hp93000/soc/PH_libs/GenericHandler/

and are listed in the sections that follow.

The /etc/opt/hp93000/soc/PH_libs/GenericHandler/ directory also contains the global configuration file Global-handler-config.cfg.

The numbers in the names of the Delta handler configuration files indicate the number of sites which are handled within the multisite testing.

Note The 'debug' driver configurations contain a slower timing and produce more messages (debug_level is higher). They should be used for error analysis in case of handler/driver malfunction, and when first setting up a new test system/handler combination. These configurations should not be used for normal production testing, as they define a slower than possible device handling.
Note For additional information about specific driver configurations, see the Prober/Handler Drivers Configuration Guide.
