Topic 140875

RESULT_AREA_CONFIG_PINS.setErrorMapResultAreaSize();

This function sets the size for the error map (digital capture) result area. If the specified size is too small to capture all results then the acquisition will stop when the end of the recording capacity is reached. The available cycle range can be queried using VALD?.

Syntax

RESULT_AREA_CONFIG_PINS& setErrorMapResultAreaSize(INT sizeInBytes);
Parameter

Parameter

Description

sizeInBytes

The size for the error map area must be specified in bytes.

Return value

A reference to the RESULT_AREA_CONFIG_PINS() object.
