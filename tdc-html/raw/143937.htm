RDI_PORT_BEGIN()

Declares the beginning of a block to set up a specified port. It is used together with RDI_PORT_END() as a pair. The RDI_PORT_BEIGN()/RDI_PORT_END() block needs to be put in the RDI_BEGIN()/RDI_END() block.

Note All pins defined in calls of the pin() function must be a member of the specified port. Otherwise an error message is issued.

Syntax

RDI_PORT_BEGIN(const string& sPort);
List of parameters

Parameter

Description

sPort

The port to set up.

Example

RDI_BEGIN();
  RDI_PORT_BEGIN("ptDATA");
    rdi.protocol().pname("i2c").write(0x03,0x04).execute();
    rdi.protocol().pname("i2c").read(0x03).execute();
  RDI_PORT_END();
  RDI_PORT_BEGIN("ptDATA2");
    rdi.protocol(3).pname("i2c").read(0x03).execute();
  RDI_PORT_END();
RDI_END();

In this example, the actions in the RDI_PORT_BEGIN("ptDATA")/RDI_PORT_END() block equal to the following code without RDI_PORT_BEGIN()/RDI_PORT_END() block:

rdi.port("ptDATA").protocol().pname("i2c").write(0x03,0x04).execute();
rdi.port("ptDATA").protocol().pname("i2c").read(0x03).execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
