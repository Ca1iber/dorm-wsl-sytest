The miscellaneous test method library provides test control methods, sequencer control methods and some other methods. You can create your test method project by copying from the library. You can also use it as a template and modify the source file to suit your project. The source files of the test methods are included in the file /opt/hp93000/soc/testmethod/library/miscellaneous_tml.zip.

The following test methods are included:

  • Test control methods
    • Disconnect: Disconnects the test system from the DUT
    • Connect: Connects the test system to the DUT
    • SetupLevelSet0: Programs the level set of tri-state highZ state.
  • Sequencer control methods
    • TestState: Returns the current sequencer state
    • StartSequencer: Starts the vector sequencer
  • Other test methods
    • TestheadTemperature: Reads the temperature of the test head
    • SetUtilityLines: Sets the status of the utility lines
    • GetUtilityLines: Gets the status of the utility lines
    • FwEscape: Executes a firmware command
    • ExecuteLinuxCommand: Executes a Linux shell command.

Functional changes

  1. Introduced in SmarTest 6.5.2
  2. SmarTest 6.5.3: New test method library SetupLevelSet0
