Topic 26686

InsertEQVariableInCache

For fast access to equation variables, some of them can are cached, thus avoiding time-consuming inter-process communication.

This routine lets you insert a variable into the cache from within your test flow program.

A variable is either

  • a specification (the name is listed in the SPECS section of an equation definition), or
  • a derived value (the name appears left to an "=" sign in the EQUATIONS section).
    Note You can also use GetEQVariableValue to cache a variable and retrieve its value in one call. InsertEQVariableFromCache, however, should be used in combination with GetEQVariableFromCache if you need to ensure constant run-times for your test flow program.

Syntax

VOID InsertEQVariableInCache(
    INT32      equation_system;
    INT32      equation_set;
    INT32      spec_set;
    CHAR     *variable_name;
    INT32     *return_state)

Parameters

Parameters of InsertEQVariableInCache

Parameter

Description

Range

equation_system

type of equation system

TIMING_EQ_SYSTEM or LEVEL_EQ_SYSTEM

equation_set

equation set number

1 ... 99

spec_set

spec set number

1 ... 99

variable_name

name of equation variable

null-terminated string

return_state

execution return state

0 if successful

Example

INT32 re_state;
InsertEQVariableInCache(TIMING_EQ_SYSTEM, 1, 1, "tim_var",&re_state);

Functional changes

  1. Introduced before SmarTest 6.3.2
