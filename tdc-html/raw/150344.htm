EVENT_WAVEFORM_VC.getSamples()

Reads the number of waveform samples that have been defined by EVENT_WAVEFORM_VC.vClampLow() or EVENT_WAVEFORM_VC.vClampHigh().

The number of samples is read from the corresponding EVENT_WAVEFORM_VC object and returned as an integer value.

Syntax

void getSamples(INT & samples) const;
Parameter
Parameter Description
samples

The read number of samples.
Return value
There is no return value.

Example

For an example see EVENT_WAVEFORM_VC.

Related information

EVENT_WAVEFORM_VC.vClampLow()
EVENT_WAVEFORM_VC.vClampHigh()

Functional changes

  1. Introduced in SmarTest 7.4.0
