PADS, PADS? - (Pin Attributes Definition String)

The PADS (Pin Attributes Definition String) command allows you to define offset delays for each individual pin. The PADS? query returns the existing settings.

Note This command replaces the command PATR from release 2.0 onwards.

With this command you configure setups of those sites that have the setup focus: For more information, see also: PSFC, PSFC?.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Note that pin attributes data can be loaded only after loading timing data.

See also PTDS, PTDS? - (Pin attributes Tweaking Definition String).

PADS

PADS [mode], {definition_string}, [drv_adj], [rec_adj], {(pinlist)}

PADS?

PADS? [mode], {(pinlist)}

returns:

PADS [mode], {definition_string}, [drv_adj], [rec_adj], {(pinlist)}

Parameters

mode

Currently not used.

definition_string

Edge delay definition string which consists of delay adjustments for up to all available edges. The valid range (in ns) is from -8 to 8.

All edges which are not explicitly set are not changed but stay at the same value as before.

drv_adj

The driver adjustment contains the sum of any additional driver offset delays that you want to include. The delay (in ns) must be between -5 and +5 and contain a maximum of three digits after the decimal point. The default value is 0.

rec_adj

The receiver adjustment contains the sum of any additional receiver offset delays that you want to include. The delay (in ns) must be between -5 and +5 and contain a maximum of three digits after the decimal point. The default value is 0.

pinlist

The pinlist must include all pins to which the given attributes apply. If more than one pin is to be entered, the names must be separated with a comma. All pins in pinlist must be I, O, or IO pin types.

Application

Pin Attributes window.

Errors

An error is generated if any parameter is out of range.

Example

> PADS ,"d1:0.1 d2:0.2 d3:0.3 d4:0.1 d5:0.2 d6:0.3 d7:0.1 d8:0.2",2,,(clk)

> PADS? ,(@)
< PADS ,"d1:0.1 d2:0.2 d3:0.3 d4:0.1 r1:0.1 r2:0.2 r3:0.3 r4:0.1",,-1,(io)
< PADS ,"d1:0.1 d2:0.2 d3:0.3 d4:0.1 d5:0.2 d6:0.3 d7:0.1 d8:0.2",2,,(clk)

Functional changes

  1. Introduced before SmarTest 6.3.2
