Alias Set Editor reference

The title bar of this view displays the name of the alias set.

The list in the view displays the pin aliases and the corresponding package pin names. Aliases and pin names can be edited here.

The shortcut menu contains the following specific commands:

  • Add: Add a row at the bottom of the table.
  • Delete: Remove the selected row from the table (only available if you right-click a row number.)
  • Aliases Per Pin: Display all aliases for this pin from all alias sets (only available if you right-click a pin name).

    Aliases are displayed in a new window. Each alias listed has the form <alias_set_name>::<alias_Name>.
