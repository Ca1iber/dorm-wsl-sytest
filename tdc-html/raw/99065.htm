RDGC - (Reset DiGital Capture)

The RDGC (Reset DiGital Capture) command dissolves the association between a vector label and a group of pins that was established with the SDGC command as a prerequisite for digital capture from these pins.

Syntax

RDGC {"vector_label"|ALL}[,(portlist)]

Parameters

vector_label

Vector main label. You can specify ALL to dissolve the associations for all vector labels of one or more ports.

portlist

If you specify ALL for vector_label, the association is dissolved for all vector labels of the ports specified here. The default for this parameter is the default port @ to which all pins belong.

Specify @@ to remove the association for all label of all ports.

Application

Digital Capture applications.

Errors

An error occurs if:

  • The referenced vector label is not a main label.
  • The referenced vector label is not in the sequencer memory (SM).

Example

> SDGC? ALL,(@@)
< SDGC "vec_lab_portA_1",STD,(I/O7_1,I/O6_1,I/O5_1)
< SDGC "vec_lab_portA_2",STD,(I/O2_1,I/O1_1,I/O0_1)
< SDGC "vec_lab_portB_1",STD,(I/O7_2,I/O6_2,I/O5_2)
< SDGC "vec_lab_portB_2",STD,(I/O3_2,I/O2_2,I/O1_2)
> RDGC ALL,(port_A)
> SDGC? ALL,(@@)
< SDGC "vec_lab_portB_1",STD,(I/O7_2,I/O6_2,I/O5_2)
< SDGC "vec_lab_portB_2",STD,(I/O3_2,I/O2_2,I/O1_2)

Functional changes

  1. Introduced before SmarTest 6.3.2
