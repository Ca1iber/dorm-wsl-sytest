SHMOO_RESULT.coordinate()

Specifies the position of a shmoo cell whose test result you want to retrieve.

To retrieve the test results, use SHMOO_RESULT.getResult().

Syntax

ShmooResultAdapter& coordinate(const std::vector<INT>& spacePoint);
Parameter

Parameter

Description

spacePoint

The two-dimensional coordinate of a cell on a shmoo plot.

Return value

Returns an instance of the ShmooResultAdapter class.

Example

Points to the shmoo cell at (1, 3) on a shmoo plot.

std::vector<unsigned int> spacePoint;
spacePoint.push_back(1);
spacePoint.push_back(3);
SHMOO_RESULT.coordinate(spacePoint).testName("t1").getResult();

Related information
