HRIT, HRIT? - (High Resolution Interval of Time)

The HRIT command serves two purposes. First, it initiates and terminates a measurement sequence for the high resolution timing diagram (puts the error map into high resolution mode and resets it again). Second, it defines the time interval for which a high resolution timing diagram is to be generated.

The time interval is defined by a start and a stop cycle within a reference port; an additional offset can be specified for both of these. This interval is also applied to all other ports which belong to the same sequencing group as the reference port. Thus, if the period of one of these other ports differs from that for the reference port, then the diagram for this other port may start or/and stop at a different cycle or even in the middle of a cycle. Ports that do not belong to the same sequencing group as the reference port are not displayed in the diagram.

The HRIT? query returns the settings for the current state of HRIT. If the measurement sequence is still active, then the display interval will be returned in terms of the specified port. For the reference port, these are the values that were specified with the start command. For the other ports of the same sequencing group, the calculated start and stop cycle values and the calculated offsets will be returned.

If the measurement sequence has been terminated correctly or aborted due to an error, the query will return a code that indicates the reason for the termination.

Note It is essential that you terminate the measurement sequence with HRIT END. Otherwise the firmware may crash.

With this command you configure setups of those sites that have the setup focus: For more information, see also: PSFC, PSFC?.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

HRIT

HRIT {HRES|SCOP}, {start_cyc}, {start_offs}, {stop_cyc), (stop_offs}, {samples), {(ref_port)}
HRIT END

HRIT?

HRIT? [(port)]

returns: 

HRIT {task}, {param}[, start_offs] [, stop_cyc][, stop_offs][, samples][, (ref_port)]

Parameters

HRES

Indicates the start of a high resolution measurement sequence.

SCOP

Indicates the start of a scope measurement sequence.

END

Indicates the end of a measurement sequence.

task

One of the three HRES, SCOP, or END.

start_cyc

In the command, this is the first cycle of the reference port that is to be displayed.

In the query reply, the parameter contains the (defined or calculated) start cycle of the specified port.

start_offs

In the command, this is a delay (specified in ns) relative to the start of the cycle defined by start_cyc. This allows you to start the measurement in the middle of a cycle of the reference port.

In the query reply, the parameter contains the (defined or calculated) start delay of the specified port.

stop_cyc

In the command, this is the first cycle of the reference port that is to not to be displayed any more.

In the query reply, the parameter contains the (defined or calculated) stop cycle of the specified port.

stop_offs

In the command, this is a delay (specified in ns) relative to the start of the cycle defined by stop_cyc. This allows you to stop the measurement in the middle of a cycle of the reference port.

In the query reply, the parameter contains the (defined or calculated) stop delay of the specified port.

samples

Specifies the number of measurement points for the display interval.

ref_port

Defines the port to which the start and stop cycle refer. The time interval to be displayed will be (if the offsets are 0)

(stop_cyc - start_cyc) * ref_port-period.

For the other port of the same sequencing group, this may mean that the diagram starts or/and stops in the middle of a cycle.

port

The port for which information is requested. If it is the reference port, the parameters specified in the command (HRES or SCOP) are returned. If it is another port of the same sequencing group, the answer will be how many cycles of this port fit into the display interval.

param

This parameter is used in the answer for different purposes:

If the measurement sequence is active it will contain the start cycle of the specified port.

If the measurement sequence was terminated correctly or aborted because of an error, it will contain an error code as follows:

0: No closing action necessary

1: Error. Closing action (HRIT END) required

-1: Severe Error. Closing action required

Example

> HRIT HRES,40,0,42,0,800,(A)
> HRIT? (B)
< HRIT HRES,50,0,52,2,800,(B)
> HREX? (a1,a2,b1)
< HREX (a1),#9000000020199LI199HI199LI199HI
< HREX (a2),#9000000020199LI199HI199LI199HI
< HREX (b1),#9000000025159LI159HI199LI159HI159LI
> HRIT END
> HRIT?
< HRIT 0

In this example, there are two ports A and B that belong to the same sequencing group. A is the reference port. The period length for port A is 5 ns, that for port B is 4 ns. It is assumed that a rising edge occurs exactly in the middle of every cycle, and a falling edge at the end of every cycle for all pins.

The display interval is 2 cycles for port A, and 2 1/2 cycles for port B. This is reflected by the offset of 2 in the answer to the first query.
