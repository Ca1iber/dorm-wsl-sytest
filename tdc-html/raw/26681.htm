HpFwTask

This procedure allows direct access from a C program to the system hardware at firmware level, but will not automatically handle site focus as test method APIs do.

Firmware commands executed via HpFwTask without site focus setup command will not automatically get the system site focus. If you use HpFwTask without a site focus setup command:

  • All setup commands executed via HpFwTask take the default setup focus (usually all sites) and apply setups accordingly
  • All result query commands executed via HpFwTask take the result of default site in focus (the first available site, usually site 1), therefore the result of all sites will be identical.

Syntax

VOID HpFwTask(
    CHAR    *task_str,
    INT32    *task_len,
    CHAR    *answ_str,
    INT32    *answ_len,
    INT32    *ret_state);

Parameters

Parameters for HpFwTask

Parameter

Value

task_str

Command string with one or more commands, each limited by a newline (\n) or by a semicolon. It is an input parameter.

task_len

Length of the command string. It is an input parameter.

answ_str

Answer string. This is an output parameter.

answ_len

As an input parameter: the dimensioned size of the answer string. As an output parameter: the length of the answer string.

ret_state

Status (see Appendix A: Listing of Error Messages). This is an output parameter.

In order to optimize data transfer times, the size of the answer string should be determined in relation to the amount of data to be passed.

Note The SmarTest software allows you to execute firmware commands directly from a terminal. The utility that does this is called hpt and is described in the Command Reference. To use hpt the SmarTest software environment must be running.

Example

The following listing shows an example of how to build the command string for HpFwTask and how to retrieve results from the answer string.

#define FW_TASK_BUF_LEN   1000
#define FW_ANSW_BUF_LEN   1000

 CHAR     TaskBuffer[FW_TASK_BUF_LEN + 1];
 CHAR     *Task;
 INT32    TaskLength;
 CHAR     AnswerBuffer[FW_ANSW_BUF_LEN + 1];
 INT32    AnswerLength;
 INT32    ReturnState;
 double   MeasurementValue;

   /* create and execute the fw-string for */
   /* pmu setup and measurement            */
   Task  = TaskBuffer;
   Task += sprintf(Task,"DFCM %d,%f,%f,%f,%f,%f,%f,%s,(%s);",1,  /* DC set number */
           800.0,        /* force voltage [mA] */
           200000.0,     /* clamp current in [uA] */
           0, 200000.0,  /* PASS/ FAIL treshold */ 
           800.0,        /* precharge voltage */
           1.0,          /* setling time in [ms] */
           "NTERM",      /* termination mode */
           "CP");        /* pin to measure */
    Task += sprintf(Task, "PTST? %d,%s,%s\n",
           1,      /* DC set number */
           "NONE", /* pre action: NO */
           "CVAL"); /* mode: value with Rs comp. */

  TaskLength   = Task - TaskBuffer;
  AnswerLength = FW_ANSW_BUF_LEN;
  HpFwTask(TaskBuffer, &TaskLength, AnswerBuffer, &AnswerLength, &ReturnState);
  AnswerBuffer[AnswerLength] = EOS;  /* truncation of AnswerBuffer string */

   if(ReturnState==0) {
    /* extract the pmu valid code and the measured current */
    /* example answer: PTST 1,3,9697.204,(CP) */
    /* PTST returns the measured current in 'uA' */
     sscanf(AnswerBuffer, "PTST 1,%d,%lf,", &ValidCode,
     &MeasurementValue);

    /* the measured value is now accessible in    */
    /* 'MeasurementValue' for further processing */
    } else {
      /**** HpFwTask ERROR ****/
   }
