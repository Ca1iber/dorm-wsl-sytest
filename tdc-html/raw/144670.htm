Topic 144670

Using the Multiple Equipment Control driver to execute a test program

You need to specify the MEC driver to use, set up the equipment to control and set up the site mapping and timeout information.

About this task

This is performed when you need to control multiple equipment from one 93000 test system.

Before you begin

The device setups and platform setups are available.

Procedure

  1. Set up the test program and specify the MEC driver in the test program file as below. 
    Hp_lib:     /opt/hp93000/soc/PH_libs/Multiple_Equipments_Control

    There is no need to change the application model file. You can use the application model file that is used with the generic prober/handler driver. The PROB_HND_CALL() applies to all the controlled equipment by default. To perform a function on some selected equipment, specify the equipment IDs when calling the function as below:

    PROB_HND_CALL(ph_set_status equipment:1,2 temperature 20);
  2. Set up the equipment to control in the MEC configuration file.
  3. Set up the Generic Driver Plug-in Configuration File
    • Configure the site mapping between the equipment and SmarTest as shown below:

      for equipment 1:

    handler_site_ids:                       [ "A" "B" "C" "D" ]
handler_site_mask:                      [ 1 1 1 1 ]
smartest_site_to_handler_site_map:      [ 1 2 3 4 ]

    for equipment 2:

    handler_site_ids:                       [ "A" "B" "C" "D" ]
handler_site_mask:                      [ 1 1 1 1 ]
smartest_site_to_handler_site_map:      [ 5 6 7 8 ]
    • Configure the timeout related values as shown below:
    waiting_for_parts_timeout_action:       "skip"
waiting_for_parts_timeout:              10
  4. Run the test program.

Results

The test program controlling multiple equipment is running. The execution message will be printed on the UI report window.

Functional changes

  1. Introduced in SmarTest 7.2.2
