Topic 108779

Generating test numbers from the SmarTest GUI

Subtopics

  1. Test table editor
  2. Test Numbering preferences page
  3. Saving test numbers as TMLimits CSV files

Test numbers can be quickly and easily generated using the SmarTest Work Center.

About this task

If the test numbers for your tests are not generated by the test method, you can do so manually through the SmarTest GUI. You can number an entire testflow or just a part of it.

Before you begin

Make sure that the testflow is set up as desired. (For details, see Testflow Tool.)

Procedure

  1. Open the testflow in which you want to number tests with the tabular testflow editor. (Right-click the testflow in the Test Program Explorer and choose Open with Tabular Editor.)
  2. Click the Tests tab.

    Alternatively, you can right-click the test table entry in the test program explorer and choose Open.

  3. Right-click any cell in the Test Number column and choose Test Numbering Preferences from the shortcut menu.

    The Test Numbering pane of the Preferences dialog is displayed.

  4. Check, and if necessary change, the test numbering settings.

    See Test Numbering preferences page for details.

  5. Select all cells in the Test Number column in which you want to generate test numbers.

    You can select multiple adjacent cells by shift-clicking or by holding down the Shift key and pressing the Up Arrow or Down Arrow key. (You cannot select multiple non-adjacent cells.)

    Note that existing test numbers in the selected cells will be overwritten only if the Overwrite existing test numbers during generation option in the test numbering preferences is checked. Otherwise, test numbers will be generated only in the empty selected cells.

  6. Right-click any of the selected cells and choose Generate Test Numbers from the shortcut menu.
  7. If desired, you can alter any of the generated test numbers by double-clicking its cell and entering a different number.

    Note that you can also generate all test numbers manually in this way. If you do so, you can skip steps 3 through 6 of this procedure.

  8. To save the new test numbers in the testflow, right-click the testflow entry in the test program explorer and choose Save.
  9. To verify that the test numbering includes enough space to avoid collisions, run the testflow.

    Any problem cells are marked in the Tests tab of the testflow window with a dotted red border:

  10. Check the Tests tab for any problematic cells.
  11. If there are collisions increase the appropriate loop increments to avoid them.

Results

The selected cells are filled with test numbers, which have been calculated according to the settings in the Test Numbering preferences and optionally modified manually.

What to do next

If desired, you can save the test numbers (along with the rest of the testflow information) as a TMLimits-compatible CSV file, as described in Saving test numbers as TMLimits CSV files.
