As described in EDF data organization, each event record body consists of a set of attribute records. These attribute records hold the characteristics describing the event. The number of attribute records and types of attributes that come with one event depend on the event type (see Event types).

This section lists all attribute types in alphabetical order and describes the data held in the attribute record body for each type.

The Data Retrieval Library provides the data types for holding and processing attribute data.
