Task 4: Setting up a Test

Develop the test program using the Testflow Tool:

  1. Specify all setup data files used in the whole device tests.
  2. Insert a test suite.
  3. Specify the primary sets and vector label to be used.
  4. Select one of your test method programs (see Test Method Programming Essentials).
