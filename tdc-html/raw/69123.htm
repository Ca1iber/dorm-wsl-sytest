File Attributes Record (FAR)

Function:

The File Attributes Record contains the information necessary to determine how to decode the STDF data contained in the file.

Location in the file:

The File Attributes Record must be the first record in the file.

FAR field name

Field description

Value

93000 data source

CPU_TYPE
  • CPU type that wrote this file
  • One-byte unsigned integer
  • Value of 128
  • Hard-coded value

STDF_VER
  • STDF specification version number
  • One-byte unsigned integer
  • Value of 4
  • Hard-coded value

Functional changes

  1. Introduced before SmarTest 6.3.2
