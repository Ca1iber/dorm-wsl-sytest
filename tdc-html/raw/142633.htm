Cyclic redundancy checks

The MTP software now supports cyclic redundancy checks on specified buses or other sets of pins. Both supplying CRC results on pins external to the bus as well as doing so on bus pins is supported.

The sets of pins involved in CRCs and the way the CRC results are calculated from them can be defined in any desired way.

Benefit

Support for CRCs make developing testing solutions for architectures such as GDDR5 using this feature much easier.

More Info

For further details, see Cyclic redundancy checks.
