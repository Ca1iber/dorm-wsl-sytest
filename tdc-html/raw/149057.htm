readData()

Reads a specified length of data from a specified starting position. Usually, readData() is used together with getReadData(). The maximum length of bits that can be specified in readData() is 64.

For the information about two read modes, see rdi.smartVec().readMode() and DEFAULT_SMV_READ_MODE in RDI_Configure file.

Syntax

readData(int bitLength,int startBit);
List of parameters

Parameter

Description

bitLength

The length of the bits (data will be automatically converted into bits) to be read.

startBit

The starting position of the bits to be read. If the startBit parameter missing, the default value is 0.

Example

RDI_BEGIN();
  rdi.smartVec("result").pin("DATA1").readData(4,2).execute();
RDI_END();
...
ARRAY_LL data_result = rdi.id("result").getReadData("DATA1");
