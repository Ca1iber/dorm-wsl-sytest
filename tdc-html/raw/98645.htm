MCNT? - (Match loop CouNT)

The MCNT? query returns the number of the pass in a counted match loop (MACT instruction) after which the match condition was met. Note that if more than one match loop is executed within one test the returned number is the sum of all match loops up to the match.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

MCNT? {(pinlist)}

returns: 

MCNT {match_count},{(pinlist)}

Parameters

match_count

Specifies the number of the pass after which the match condition was met.

pinlist

Pin name or names. If more than one pin is required, the names must be separated with a comma. The @ character can be used to read all configured pins.

Warnings

A warning is generated if any pins in the pin list are undefined.

Example

> MCNT? (CP)
< MCNT 16 (CP)

In this example, a match was obtained after 16 passes.

Functional changes

  1. Introduced before SmarTest 6.3.2
