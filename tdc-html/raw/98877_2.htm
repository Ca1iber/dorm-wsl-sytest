Topic 98877

WSDM, WSDM? - (Waveform Set Display Mode)

The WSDM (Waveform Set Display Mode) command sets the display mode for the Vector Setup.

Equation-based testing

In equation-based testing, you must identify a wavetable instead of a waveform set. This is achieved either by supplying wavetable_name directly, or by supplying a specset_id, calculated from equation set number and spec set number as follows:

100 * equation_set_no + specset_no

The appropriate wavetable is determined by looking at which wavetable is referenced by equation_set_no and specset_no in the Timing Specification File.

WSDM

WSDM {waveform_set}, {display_mode}

WDSM?

WSDM? {waveform_set}

returns:

WSDM {waveform_set}, {display_mode}

Or:

WSDM? {specset_id}

returns:

WSDM {specset_id}, {display_mode}

Or, for multiport specifications:

WSDM? {"multiport_spec"}[, (portlist)]

returns:

WSDM {"multiport_spec"}, {display_mode}

Parameters

waveform_set

Waveform Set Number. Enter ALL for all waveform sets, or an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by the command WSUS, WSUS? - (Waveform Sets USed).

specset_id

Derived as follows:

100 * equation_set_no + specset_no

multiport_spec

To query a multiport specification, enter the name of the specification.

display_mode

Sets the Vector Setup display mode. This can be:

0

The "classic" display mode. A device cycle has the length of one test system cycle.

1

The "single column" display mode. All pins use the same device cycles.

2

The "multi column" display mode. All pins do not use the same device cycles, the device has two or more separate ports with independent signals.

portlist

For multiport specifications, you can specify the ports for which the vector setup display mode is to be returned.

Application

Edit command in Pattern Tool.

Errors

An error is generated if waveform_set is greater than the range allowed by WSUS, WSUS? - (Waveform Sets USed).

Example

> WSDM? "spec_1", (port_1)
< WSDM  "spec_1", 0

This example queries the display mode of port port_1 in the multiport specification spec_1. The reply shows that it is set to the "classic" display mode.

Functional changes

  1. Introduced before SmarTest 6.3.2
