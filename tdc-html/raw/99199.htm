Reference pins

Reference pins are standard MTL pins to which other pins can be aligned, that is, from which they receive their tester cycle counts and maintenance operation interrupts.

All kinds of pins can be aligned to reference pins, but they are most commonly used for DC Scale pins since those pins cannot expressly be mapped to specific tester cycles.

Pins are aligned to reference pins in the Pin mapping file by means of noting the reference pin's name in parentheses after the aligned pin's name.

There are some limitations for reference pins:

  • The reference pin cannot be a pin group.
  • The reference pin cannot be a channel resource used for an HX pin.
  • The reference pin cannot be an HX pin.

Waveform mapping

When a pin is aligned to another pin, it can have only one waveform (in interruptible and non-interruptible versions). All waveforms sent to the reference pin are mapped to either of two waveforms for the aligned pin:

  • Reference pin waveforms with indexes below (hexadecimal) 80 are mapped to waveform 0 for the aligned pin.
  • Waveforms with indexes of (hexadecimal) 80 and above are mapped to waveform (hexadecimal) 80 for the aligned pin.

This feature makes it easy to drive static pins or pins with very simple patterns without having to explicitly program them. It does not apply to DC Scale pins for which no waveforms can be generated.

Example

From the pin mapping file:

CK1=CK  # mapping an MTL pin to a SmarTest pin
VDD(CK)=VDD@(type=dcscale) # mapping the VDD MTL pin to the
                           # VDD SmarTest pin and aligning it
                           # to the CK1 pin
