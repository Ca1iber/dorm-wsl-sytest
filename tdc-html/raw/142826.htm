Topic 142826

set()

Specifies a timing or level set to use.

Syntax

set(int setNum);
List of parameters

Parameter

Description

setNum

The timing or level set number

Example

RDI_BEGIN();
...
rdi.level().set(1);
rdi.timing().set(2);
...
RDI_END();

Functional changes

  1. Introduced in SmartRDI 2.1.0
