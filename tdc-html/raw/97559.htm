IS_DUTBOARD_DOCKED

This API queries the DUT board connection status.

If the DUT board is docked, it returns true. Otherwise it returns false. It will always return false in the offline mode.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

bool IS_DUTBOARD_DOCKED( );

Parameters

There is no parameter for this API.

Example

bool dockStatus;
dockStatus = IS_DUTBOARD_DOCKED();

This example returns the DUT board connection status to the variable dockStatus.
