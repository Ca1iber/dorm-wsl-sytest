Topic 123962

Load and Analysis

During device migration,you can monitor a specific testflow and test program while it is being loaded. All the detected migration items will be listed in the Migration Items View.

About this task

Following migration items will be detected while loading.

  • Obsoleted firmware
  • Wrong timing EEdge
  • Vector using obsoleted CMM pattern
  • Out of range PPMU definition
  • Out of range Level definition

Before you begin

Ensure that SmarTest is running and a cheat sheet is open.

Procedure

  1. Select Load and Analysis.
  2. Load your testflow or test program from the TPE.
  3. Switch to the Migration Items view, and browse through the migration items in the view.
  4. Select one item and browse for detail information and resolution.
  5. Fix migration gap according to resolution description, conversion tool and TDC document support.
  6. Reload the testflow or test program iteratively, until there is no migration item gap captured.
  7. The following picture shows the migration item view and proposed solutions.

Results

Your testflow is analyzed.
