Defining ASCII Vectors

Subtopics

  1. The FORMAT Statement
  2. The ASCII Vector Row
  3. Example 1
  4. Example 2

The ASCII vectors are organized as a table. Every row of the table specifies one ASCII vector; every column contains in temporal order the state characters for one pin. The order of the pins is variable; it is defined by the FORMAT statement which servers as a kind of header to the ASCII vector table. Sequencer instructions can be inserted on separate rows between the vector rows; for more information see Inserting Sequencer Instructions. Every row must be terminated by a semicolon.

For scan testing, the vector rows take a different form, and additional statements defining, for example, the templates and frames must be added (see Defining the Scan Instances).
