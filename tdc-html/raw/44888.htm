Testflow Flag

get

long GetTestflowFlag(char *flag, long *value)

Retrieves the current value of the testflow flag named *flag and deposits it in the long pointed to by *value. Flags are actually declared as int's, but are typecast to long's within this function.

Alternatively you can use a "string" to match the required flag name.

Flags may be assigned one of the following constants:

The returned values are,

0

OK

1

erroneous name

-1

internal error

set

long SetTestflowFlag(char *flag, long value)

Sets the value of the testflow flag named *flag with the value value. Flags are actually declared as int's, but are typecast to long's within this function.

The return values are as for the get function.

Note Do not change the status of the following flags in a testflow via a user procedure. If you want to change the flag status, do it in the application model file. CI_USE_HW_DSP CI_BUFFER_TESTFLOW_LOG

Functional changes
