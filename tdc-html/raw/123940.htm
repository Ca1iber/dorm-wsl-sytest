d2s read

The d2s read method allows to read from a register.

This is done by generating a static read pattern with the specified register address.

The d2s-framework will create the corresponding static pattern and keeps track of executed cycles per port.

The d2s-framework strobes for 'L' causing a read 'H' to be flagged as an error in the error map.These failures are translated to register values.

The error map will be evaluated at d2s_LABEL_END and the read values (per site) are cached for access from outside the ON_FIRST_INVOCATION block.

Syntax

void read(long long address, std::string id);
long long getReadValue(std::string id);
Parameters

I/O

Parameter

Description/Range

I

address

Defines the register's read address.

I

id

Unique identifier to retrieve register results (per site) from the cache. For instance, 'one' could be a unique identifier to read the values after burst execution.

Example

The following excerpt illustrates how the read method is used to created static pattern to read from the corresponding address.

In learning mode it will generate the read label, add it to the burst label MyBurstLabelName and execute the pattern at d2s_LABEL_END().

In production mode only the MyBurstLabelName pattern will be executed at d2s_LABEL_END().

virtual void run()
{
   d2sFramework fr;
   d2sJTAG& jtag = d2sJTAG::Instance();

   // Register your protocol with the framework
   fr.registerTransactionPort(jtag);

   ON_FIRST_INVOCATION_BEGIN();
      fr.d2s_LABEL_BEGIN("MyBurstLabelName", d2sFrameWorkModeType::LearningMode);
         jtag.write(0xdead, 0xbeaf);
         jtag.read(0xdead, "one");
      fr.d2s_LABEL_END();

      // do your measurement here

   ON_FIRST_INVOCATION_END();

   cout << "Result: " << jtag.getReadValue("one") << endl;
}

The static pattern created by the code above for a single port setup would be saved into the device vector directory as:

d2s_jtag_AT_W_0xdead_0xbeaf and d2s_jtag_AT_R_0xdead
