Topic 99468

Deleting bookmarks

Before you begin

Make sure the bookmarks you want to delete has been set.

Procedure

  1. In the Bookmarks view, select the row of the bookmark which you want to delete. To select more than one bookmarks, press Shift while clicking.
  2. To delete the chosen bookmark, press delete.

Results

The selected bookmark has been removed from the Bookmarks view.

Functional changes

  1. Introduced before SmarTest 6.3.2
