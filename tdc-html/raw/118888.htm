Topic 118888

ON_LAST_INVOCATION_BEGIN

This API declares the beginning of a block in which the test method code will be only executed for the last site in multisite testing. In the block, all the active sites are setup focus and the last site is query focus.

ON_LAST_INVOCATION_BEGIN and ON_LAST_INVOCATION_END must be used as a pair.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/MapiUtil.h.

Syntax

ON_LAST_INVOCATION_BEGIN();

List of parameters

There are no parameters.

Return value

There is no return value.

Examples

Example 1: Minimum code

The following example shows the minimum code for a "last-invocation block". The ellipses ("...") are to be replaced with your code.

ON_LAST_INVOCATION_BEGIN();
    ...
    ...
ON_LAST_INVOCATION_END();

Example 2: Optional curly brackets

The example utilizes an optional pair of curly brackets "{" and "}". These optional curly brackets are used for simplifying the correct indentation with assistance of the related Eclipse tool.

ON_LAST_INVOCATION_BEGIN();
{
    ...
    ...
}
ON_LAST_INVOCATION_END();

Example 3

ON_FIRST_INVOCATION_BEGIN();

    //
    // Parallel setup
    //
    ...
    ...

ON_FIRST_INVOCATION_END();

...
...

ON_LAST_INVOCATION_BEGIN();

    Routing.pin("DIG_IP").disconnect();

    FLUSH();

ON_LAST_INVOCATION_END();

This example disconnects the pin "DIG_IP" of all the active sites when the last site is tested.
