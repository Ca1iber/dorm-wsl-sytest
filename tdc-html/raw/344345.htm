SPMU_PIN_TASK.forceDropMax()

Sets the maximum voltage drop on the force line. The channel gets automatically disconnected in case the voltage drop exceeds the programmed voltage.

The voltage drop is measured from the high force pogo pin (P#) to the high sense pogo pin (PS#). The measured voltage drop depends on the actual current and the impedance of the connection to the DUT. The continuously measured voltage drop is compared against the programmed maximum voltage drop and a pin that exceeds the programmed limit is disconnected.

This member function is supported only for the DC Scale XPS256 card.

Syntax

SPMU_PIN_TASK & forceDropMax(DOUBLE forceDrop);
Parameter
Parameter Description
forceDrop

The maximum voltage drop in Volts (V) to be set.

A positive voltage has to be set regardless of the polarity of the actual or programmed current.

Valid range and default value:
  • XPS256:

    For the specification, refer to Voltage drop protection / measurement in XPS256 other performance characteristics.

    The programmable range is 0.0 … 1.0 V for the force line and for the return line but, the total for the two lines must not exceed 1.0 V.

    Default value: 150 mV

    For a maximum voltage drop > 0.5 V, the open loop protection must be set to "NONE" by function openLoopProtection() and in the DC Scale Safety editor the Vdrop Disco parameter must be set to ON.
Return value
A reference to the SPMU_PIN_TASK object.

Example

Maximum voltage drop of XPS256

SPMU_TASK spmuTask_1;

spmuTask_1.pin("...")
    .mode("VFIM")
    ...
    ...
    .forceDropMax    (300 mV)
    .returnDropMax   (200 mV)
    ;
Note: The example concentrates on the function described in this topic. More settings are required for an executable SPMU_TASK object.
