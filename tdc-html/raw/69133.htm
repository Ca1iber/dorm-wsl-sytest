Part Information Record (PIR)

The Part Information Record acts as a marker to indicate where testing of a particular part begins for each part tested by the test program. The PIR and PRR bracket all the stored information pertaining to one tested part.

Location in the file:

The Part Information Record can be located anywhere in the data stream after the Initial sequence and before the corresponding PRR.

PIR field name

Field description

Value

93000 data source

HEAD_NUM
  • Test head number
  • One-byte unsigned integer
  • Value = 1

    If the ATR and GDR indicate that there are more than 255 sites in the test, HEAD_NUM is the number of the site divided by 256. For example, in a record for site 384, HEAD_NUM would be 2.
  • For tests with up to 255 sites: hard-coded value

    For tests with more than 255 sites: derived from SiteID

SITE_NUM
  • Test site number
  • One-byte unsigned integer

    If the ATR and GDR indicate that there are more than 255 sites in the test, SITE_NUM is the number of the site modulo 256. For example, in a record for site 600, SITE_NUM would be 88.
  • EDL Event:

    TestFlowStartEventType

  • EDL Attribute:

    SiteSetAttrType

    Note When parallel testing, these fields are used to associate individual logged results (FTRs and PTRs) with a PIR/PRR pair. An FTR or PTR belongs to the PIR/PRR pair having the same values for HEAD_NUM and SITE_NUM.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.2.2: Added HEAD_NUM and SITE_NUM conventions for tests on more than 255 sites.
