Topic 69074

Settings menu

Subtopics

  1. Global
  2. Analysis Area

The Bit Fail Map Viewer's Settings menu lets you configure global settings for the tool.

The menu contains these commands:

  • Global Settings

    Choosing this command lets you set default display options, as described in Configuring the BFM Viewer. The options themselves are explained in the description of the Global Settings window.

  • Analysis Area

    Choosing this command lets you specify the section of the DUT that the BFM Viewer analyzes for failed cells, as described in Specifying an analysis area. The options are explained in Analysis Area.
