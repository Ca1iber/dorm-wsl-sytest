Choosing a test method for a test suite

A test method can be used by adding it to a test flow and it is assumed here that the test flow already exists. For more information on setting up a test flow see Introduction of the Testflow.

  1. In the test flow, create a new test suite.
  2. Start the test suite configuration window by double-clicking the test suite.
  3. In the Primaries tab, click the radio button test method and then fill in the needed values for Timing Equation, Waveform Set, Timing Set, etc.
  4. Click inside the test method field to select the class and test method, then click the Select button.
  5. In the Select Class/Method window
    1. Select your test method class in the Class window.
    2. Select your test method in the Method window.
    3. Click Select.
  6. The Test Suite Dialog reappears. To accept the default parameters of the test method, click the Done button at the lower right.
  7. The test method can be configured by Setting Parameters and Setting Flags for your selected test method.

See the individual test method descriptions for more details.

Functional changes

  1. Introduced before SmarTest 6.3.2
