SmartRDI functions controlling SmartCalc (SMC)

SmartRDI provides some functions to enable and disable SmartCalc (SMC) and to modify the SMC related behavior.

Enabling and disabling SMC

SmartRDI lets user choose whether to use the SmartCalc (SMC) framework for hidden upload.

By default, SMC is enabled in SmartRDI for pattern‑based tests including functional test and digital capture test. That is to say, during pattern execution the SMC mode is always active for results uploading unless user explicitly disabled this feature using function rdi.disableSmcExec() or using keywords DISABLE_SMC_EXEC_GLOBAL or DISABLE_SMC_SHORT_BURST in the RDI_Configure file.

Hidden upload

The hidden upload must be enabled or disabled by function rdi.hiddenUpload(). This function defines also the type of measurement for which the results are to be uploaded in a background process.

Definition of the site in a common thread

For a Common thread, the rdi.site() API allows you setting the site to be processed in the SMC_backgroundProcessing() function.
