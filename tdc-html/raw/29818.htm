Topic 29818

UNSET_TEST_FOCUS

This API sets the specified site in the currently setup-focused sites to the non-setup-focus state, and returns the previous state of the site.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SiteControl.h.

Note Setting the test focus by this API is supported for a limited selection of other APIs. Supported APIs are Primary.getLevelSpec(), Primary.getTimingSpec(), Analog.AWG(), Analog.DGT(), Analog.TIA(), and Vector(). For detailed information refer to Site-Specific Setup. The "each site loop block" or the "semi-parallel testing block" are to be used to manually control the setup focus or the query focus for other APIs. For more information refer to Controlling Multiple Sites.

Application note

  • This API specifies which site is not addressed by the Setup APIs that follow, for performing site-specific setup.
  • This API is meaningful for multi-site testing, and is used in the first-invocation block enclosed by ON_FIRST_INVOCATION_BEGIN and ON_FIRST_INVOCATION_END, except for the FOR_EACH_SITE loop block. For single-site testing, this API generates a warning message to the report window, and program execution continues to the next statement. In this case, the setting by this API except for site 1 is ignored. You can also ignore the warning message by using DISABLE_ERROR_MESSAGE.
  • If this API is executed to any disabled sites for setup-focus unsetting, it generates a warning message to the report window.
  • Changes of setup-focus state by SET_TEST_FOCUS and UNSET_TEST_FOCUS APIs are canceled automatically when the execution of the test method program finishes in the testsuite.

Syntax

Boolean UNSET_TEST_FOCUS(INT site);
Parameter

I/O

Parameter

Description / Range

I

site

A site to be set to not setup-focus state.

Return value

The previous state of the specified site is returned in boolean type. If the previous state was setup-focus state, this API returns TRUE (1). Otherwise, this API returns FALSE (0).

Example

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Disable the setup-focus for site 2.
    // Read the old setup-focus state of site 2.
    //
    Boolean setup_flag = UNSET_TEST_FOCUS(2);

    //
    // Apply changes to all enabled sites except site 2.
    //
    AWG("Ain").vOffset(2.5 V);
    ...
    ...

    //
    // Restore the previous state setup-focus state of site 2.
    //
    // Note: The 2nd parameter "exclusive" is set to FALSE. Site 2
    //       will be added to the list to the list of sites with
    //       setup-focus enabled. The setup-focus state of other
    //       sites will not be changed.
    //
    if (setup_flag == TRUE)
    {
        Boolean exclusive = FALSE;

        SET_TEST_FOCUS(2, exclusive);
    }
}
ON_FIRST_INVOCATION_END();
