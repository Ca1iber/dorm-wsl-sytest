Topic 145710

SMC_UPLOAD_DC_RESULTS

The SMC_UPLOAD_DC_RESULTS is the SmartCalc API to upload DC results in a single background process.

This API uploads the DC results from the test head card's memory to the result cache on the workstation for the specified pins and sites, while a new test suite is being executed. This API must be called inside your SMC_backgroundProcessing() method.

Syntax

void SMC_UPLOAD_DC_RESULTS( DC_RESULT_ACCESSOR& resultAccessor,
                            const STRING& uploadArea,
                            const STRING& pinList = "@",
                            const TM::RESULT_ADDRESSING_SCHEME& addressingScheme = TM::RESULT_INDEX,
                            const TM::RESULT_RANGE& resultRange = TM::RESULT_RANGE(),
                            bool uploadFailsOnly = false,
                            bool uploadExpectedData = false);

void SMC_UPLOAD_DC_RESULTS( const INT site,
                            DC_RESULT_ACCESSOR& resultAccessor,
                            const STRING& uploadArea,
                            const STRING& pinList = "@",
                            const TM::RESULT_ADDRESSING_SCHEME& addressingScheme = TM::RESULT_INDEX,
                            const TM::RESULT_RANGE& resultRange = TM::RESULT_RANGE(),
                            bool uploadFailsOnly = false,
                            bool uploadExpectedData = false);

void SMC_UPLOAD_DC_RESULTS( const INT site,
                            ResultStorageAccess& resultStorageAccess,
                            const STRING& uploadArea,
                            const STRING& pinList = "@",
                            const TM::RESULT_ADDRESSING_SCHEME& addressingScheme = TM::RESULT_INDEX,
                            const TM::RESULT_RANGE& resultRange = TM::RESULT_RANGE(),
                            bool uploadFailsOnly = false,
                            bool uploadExpectedData = false);

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Parameters
Parameter Description
site The site for which to upload results.
resultAccessor A DC_RESULT_ACCESSOR object.

The DC_RESULT_ACCESSOR is used to upload specific results of a measurement.
resultStorageAccess The data container receiving the uploaded result data.
uploadArea The configured result area
pinList The optional list of pins for which to upload results.

Default value is "@" which means all pins.
addressingScheme

The optional index type to access the results.

The default value and the currently supported value is TM::RESULT_INDEX.
resultRange

The optional range of results to upload defined as TM::RESULT_RANGE.
uploadFailsOnly

If set to true, only the fail results are uploaded to the result accessor.

The default value of the optional parameter is false.
uploadExpectedData

If set to true, the test limits for the specified pins are uploaded.

The default value of the optional parameter is false.
Return value
There is no return value.

Example

This example uploads the results to the result storage and reads the measured values from the result accessor.

protected:

    virtual void run()
    {
        ON_FIRST_INVOCATION_BEGIN();
        {
            RESULT_AREA_CONFIG_SET resSet("dpsCurr");

            resSet.pin("dps1").setDcValueResultAreaSize(8192);
            resSet.setAsPrimary();

            SMC_FUNCTIONAL_TEST();

            resSet.deselectGlobally();

            ARRAY_I sites;
            GET_ACTIVE_SITES(sites);

            SMC_ARM(sites);
        }
        ON_FIRST_INVOCATION_END();

        return;
    }

public:

    virtual void SMC_backgroundProcessing(ARRAY_I& sites)
    {
        DC_RESULT_ACCESSOR result("dpsCurr");

        for ( int i = 0; i < sites.size(); ++i )
        {
            SMC_UPLOAD_DC_RESULTS(sites[i],
                    result.resultStorage(),
                    "dpsCurr",
                    "dps1",
                    TM::RESULT_INDEX,
                    TM::RESULT_RANGE(TM::RESULT_INDEX, 0, 2));

            cout << "result array: " << result.getValues(sites[i], "dps1");
        }
    }
Note

The example above contains a call of cout in function SMC_backgroundProcessing(). cout is not thread safe. In production test cout must never be used in a background process.

When using cout in a background process, you have to expect a mix up of the output in the ui_report window and possibly other unwanted behavior. For more information, refer to Thread safety.
