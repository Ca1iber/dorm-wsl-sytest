Working with result data tables

Subtopics

  1. Sorting tables
  2. Filtering test result data
  3. Highlighting specific data
  4. Selecting similar data
  5. Separating summary results by wafer, site, or pin
  6. Setting table display options

Open data logs can be worked with in various ways to adjust their appearance and exclude data from evaluation.

These procedures are described in detail in:

  • Sorting tables
  • Filtering test results
  • Highlighting specific data
  • Separating summary results by wafer, site, or pin
  • Setting table display options

Note that none of these procedures affect the result charts. The exception is separating summary results, which can change titles and legends of charts.
