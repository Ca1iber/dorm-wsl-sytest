DPS status flags - get...() functions

Subtopics

  1. DPS_AUX_TASK.getIcHacError()
  2. DPS_AUX_TASK.getRangeError()

The DPS_AUX_TASK class features several member functions for reading the accumulated power supply status flags.

The returned result will show the status flags that have been set on tests performed since the previous call of the related DPS_AUX_PIN_TASK.check...() member function.

Member functions

Several get...() member functions are documented in this section. These member functions retrieve the value of all flags or of a single status flag from the test method cache. The related DPS_AUX_PIN_TASK.check...() member function must be called upfront for reading the flags from the hardware into the test method cache.

The member functions return one of the following values of the enumerated type DPS_AUX_TASK_STATUS:

Keyword Value State of the checked flags
TM::AUX_TASK_STATUS_PASS 0 The checked single flag is not set or none of multiple checked flags is set.
TM::AUX_TASK_STATUS_FAIL 1 The checked flag is set or minimum one of multiple checked flags is set.

DPS flag description

The functionality of the flags is largely the same for the various DPS cards.

Flag Description
High voltage or current of surge tracker exceeded The surge tracker has detected a voltage or current above the user defined upper limits.
Low voltage or current of surge tracker exceeded The surge tracker has detected a voltage or current below the user defined lower limits.
Measurement range change failed A range event in dynamic DC tests has failed. Down ranging is not possible.
Clamp current correction failed The clamp current correction for higher accuracy has failed.
Battery full The flag indicates the charge condition of the on-board energy storage. The related bit is set if the on-board energy storage is fully charged.

Note: The flag indicates like the other flags the latched status of the on-board energy storage. So even the flag is set, the on-board energy storage may be in a discharged state. We recommend querying the flag twice. With the first query the flag is cleared and the second query will then obtain the actual state.
Power budget 1 The flags indicate that the utilization of the related power budget has entered a critical condition at run time since the last query.
Power budget 2
Power budget 3
High voltage of surge tracker reached The flags are used for VI surge tracking mode. The surge tracker has detected a voltage or current above(below) the user defined upper(lower) limits.
Low voltage of surge tracker reached
High current of surge tracker reached
Low current of surge tracker reached

DPS flag implementation

The implementation of the flags differs for the various DPS cards, that is, various cards do not support every flag.

Bit Flag DPS128/64 XPS256
0 High voltage or current of surge tracker exceeded + +
1 Low voltage or current of surge tracker exceeded + +
3 Measurement range change failed + +
4 Clamp current correction failed + -
5 Battery full - -
6 Power budget 1 - -
7 Power budget 2 - -
8 Power budget 3 - -

10 Low voltage of surge tracker reached - +

Note The state of the flags "High voltage or current of surge tracker exceeded" and "Low voltage or current of surge tracker exceeded" is to be retrieved by member function DPS_AUX_TASK.getSurgeTrackerStatus() that returns values of the enumerated type TM::SURGE_TRACKER_STATUS.
