Topic 352121

Installing the FLexNet (FNP) license client

Installing a FlexNet Publisher (FNP) license client used to provide the activated licenses to a SmarTest installation on a system controller workstation requires two steps: the installation of the license client software itself on the SmarTest host system, and configuration of the license server configuration file to prioritized the order of server access.

About this task

The following procedure explains how to install the FlexNet client.

Before you begin

The license client is the SmarTest software. The FlexNet license server communicates with SmarTest using the FlexNet client.

Procedure

  1. Download the client install package from the FTP site ftp.advantest.com/Licensing/FNP_SW/ and copy it to /tmp/fnp directory. Package name:

    v93000-fnp-client-<date>-<version>.rpm

    For example: v93000-fnp-client-11.12.1.7-20056.el7.x86_64.rpm

  2. Install the client package using SmartInstall:
    1. Login as root and on the Red Hat menu, click Advantest > V93000 SmartInstall.
    2. Select Install from local source and click Next.
    3. Click Add to display the Open dialog box.
    4. Select the directory that includes the client install package (/tmp/fnp).
    5. Click Next.

      Yum Extender opens.

    6. Select the client install package v93000-fnp-client and click Apply.
      Note If the package you are looking for is not displayed in the Updates list, select the Available list.
    7. Click Process Queue.
    8. To start the installation of the selected software, click OK.
    9. When the installation is complete, click Quit to quit the Yum Extender.
  3. After the installation has completed, configure the license server configuration file where the list of FlexNet Publisher license servers are listed in a prioritized order as described in The System .lic license files and Editing .lic license files.

Results

You have installed the license client software and configured the list of FlexNet Publisher license servers in a prioritized order.

Functional changes

  1. Introduced in SmarTest 8.4.0
