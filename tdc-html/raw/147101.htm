License Renewal Portal Dashboard

The Advantest Renewal Portal Dashboard page provides you a clear overview of the high-level tasks that you must complete to renew all your licenses.

There are three main steps:

  1. Assigning entitlements to your account so that you can renew the associated licenses
  2. Renewing the licenses for which you are responsible
  3. Download the renewed licenses

The License Renewal Dashboard flow chart includes shortcut links to these main pages.
