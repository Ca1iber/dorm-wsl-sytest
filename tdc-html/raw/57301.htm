Topic 57301

The advantage of using level setup file to store all the level sets

Each Level Set is a complete, self-contained, list of level setup definitions for each logic pin of the device you are currently testing. Similarly, each DPS Set contains setup definitions for every dps type pin that you have defined in the Pin Configuration window.

The SmarTest software allows you to create several independent sets of these logic level and DPS definitions and store them all in the same Level Setup file. Organizing your files in this manner can also optimize the throughput of your tests.

Changing the level setup during run-time

The big advantage of having several alternative setups in a single file is that when you load the file, all the setups within that file are loaded into hardware together. So to change the level setup, or DPS setup, you just have to switch one set in the hardware for another set which is already resident in the hardware.

Without complex programming

The Sequencing Instruction set includes a command which you can insert in the vector table for switching between level sets during your test.

So, for example, you can use this facility to set up a single stream of test vectors which performs a number of characterization tests one after the other, perhaps a combined Voh and a Vol test. To change the level setup between the tests, you just type the command CLEV and the new set number in the instruction column of the Pattern Tool. This changes the level setup without manual intervention, and without having to program a complicated reload.

You can specify a different DPS set for each test label

By using several DPS sets in a single file, you have the facility to associate each test label with a different Primary DPS set. This allows you to change the supply rail for each page of test vectors, without reprogramming the DPS setup screen or reloading a complete Level Setup file.
