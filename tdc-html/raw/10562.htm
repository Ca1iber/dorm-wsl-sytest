Endless loops

An endless loop is started with the LBGN (Loop BeGiN) instruction. The end of the loop section is marked by the LEND (Loop END) instruction.

LBGN

[..]

LEND

To break out of an endless loop, force a break with the BRK parameter of the SQST (SeQuencer STate) command.

Nested loops

Within an endless loop or within a counted loop you can nest counted loops and repeated subroutines.

Note You must not nest an endless loop within any loop structure. Endless loops are only allowed as the most outer loop.

Nesting is limited to seven nested levels.

Example

Endless loop

SQPG 7,LBGN,,,,(@)
SQPG 8,GENV,7,,,(@)
SQPG 9,LEND,,,,(@)

The sequence repeats the GENV instruction in command line 8.
