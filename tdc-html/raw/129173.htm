SHARED_CONTINUITY_TEST.judgeAndLog()

The judgeAndLog() member function of SHARED_CONTINUITY_TEST judges and logs the test results of a shared continuity test.

Syntax

void judgeAndLog() const

Example

SHARED_CONTINUITY_TEST mTest;
mTest.judgeAndLog();

Related information
