DCRS? - (Digital Compare Result Size)

The DCRS? query returns the capacity of the error map for a certain result granularity and a certain bit length of the result code in dependence of the current location of the detailed error map (as defined with DCRT).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

DCRS? [answer_type,] {map},[mode],[bits],{(port_list)}

returns:

DCRS {map},{x-mode},{bits},{no_of_cycles},{(port)}
Parameters

answer_type

This parameter specifies whether the current configuration or the configuration of the last executed test is to be returned. Possible values are:

 

CONF

The current configuration is returned. This is the default.

 

EXEC

The configuration of the last executed test is returned.

map

The only allowed value is EMAP (for the detailed error map).

mode

Specifies the level of granularity with which the receive edges of one cycle are recorded. The allowed values are 1, 2, 4, and 8; for Smart Scale, 6 is also possible. If you omit this parameter, the mode set with DCRM is used.

bits

Specifies how detailed the recorded error code is to be in case of failure. If you omit this parameter, the value set with DCRM is used. Possible values are:

PF

Only a one bit Pass/Fail result will be returned. This value is not allowed for Pin Scale cards if mode is set to 1.

PFC

In case of failure, a more detailed two bit code will be returned. PFC is not allowed if mode is set to 8.

no_of_cycles

Returns the number of test system cycles that can be stored in the Error Map.

port_list

Specifies the ports for which the capacity of the Error Map is to be returned. If you specify @@, DCRS? will return the capacity for all ports.

Application

Error Map.

Example

> DCGM ALL,HALT,NONE
> DCRT TP,(P1)
> DCRM EMAP,8,PF,(P1)
> CYRM CYCL,,(P1)
> DCRS? EMAP,,,(P1)
< DCRS EMAP,8,PF,2048,(P1)
> DCRP 3360,(P1)
> FTST?
> EMAP? PPIN,1312,2048,EDGE,8,PF,ALL,BYTE,(P1)

This example shows how to get hold of the first cycles of your area of interest under the following conditions:

  • The area of interest is greater than the capacity of the error map.
  • The acquire mode is set to ALL with DCGM, so that the first recorded cycles will be overwritten when the error map is full before the end of the test.

The solution is to interpret the error map position defined with DCRP as a stop value (by setting the second parameter of DCGM to HALT), and to calculate the last cycle to be recorded as:

first_cycle_of_interest + capacity_of_the_Error_Map

In the example, the first addend is 1312. The second addend is determined with the DCRS? query.

Functional changes

  1. Introduced before SmarTest 6.3.2
