Topic 124648

Setting up the protocol definition

Protocol definitions can either be created from scratch or be imported from an existing protocol definition.

About this task

This task describes how to create a new protocol structure including transactions, pin roles and fields.

It also can be used for editing existing protocol definition either imported or created previously.

Note Further protocol specification, such as transaction, pin role and field details are described in separate tasks.

Before you begin

Ensure you have defined all resource (hardware) pins and created independent ports to be used by your protocol, refer to Protocol based terms put into perspective for a schematic overview.

Note Pins used by a protocol may not be part of a larger group of pins.

Create a new setup component of type 'protocol' as described in Creating a new single setup component.

Procedure

  1. Open your new protocol as described in Opening a protocol in the protocol editor.
  2. Create pin roles by clicking New in the Pin Role section.
  3. Enter the new pin role name, like MCD, and click OK.
  4. Adjust the properties of each pin role to your needs.
  5. Add Pin Role Groups by clicking New in the Pin Role Group section if you set up a parallel protocol, else leave this section empty.
    1. Enter the name of the Pin Role Group and click OK.
    2. Assign Pin Role Group Members within the Properties of the Pin Role Group window by adding Available Pin Roles to your group.
    3. If necessary, correct the order of the pin roles to reflect the MSB and LSB requirements of your parallel protocol.
    4. Click OK when finished.
    5. Correct the Slice depth if necessary.
  6. If required, add constant state character sequences.
    1. Click New in the Constants section and enter the constant's name.
    2. Click OK.
    3. Double-click into the Value field behind your constant's name to enter the constant state character sequence.
  7. Right-click the protocol icon in the overview area of the protocol editor and select New Transaction to create a new transaction like read or write.
  8. Enter the transaction's name and click OK.
  9. Expand the protocol's structure by clicking on the triangle in front of the protocol's name in the overview area of the protocol editor.
  10. Select the transaction you just added and enter transaction details as described in Editing transaction details.
  11. Expand the transaction's structure by clicking on the triangle in front of the transaction's name.
  12. Select a pin role and enter pin role details as described in Editing pin role details.
  13. Right-click the pin role's name to which you like to enter protocol fields and select New Field.
  14. Enter the protocol field's name and click OK.
  15. Select the protocol field you just added and enter field details as described in Editing field details.
  16. Enter all fields required with their corresponding details for all pin roles.
    Note The order of the fields is important and has to reflect your protocol.
  17. In case you have to change the order, right-click the field to be moved and select Move Up or Move Down.
  18. In order to create more transactions with the same structure and pin role and field details, right-click the transaction you just defined and select Copy. Else repeat the previous steps for each transaction, pin role and field to be defined for your protocol and skip the following steps.
  19. Right-click the protocol and select Paste.
  20. Enter a new name for the transaction you are pasting and click OK.
    Note If you paste transactions keep in mind to adapt the encoding/decoding functions and directions of pin roles and fields accordingly.
  21. Save your modifications by pressing the CTRL + S key combination simultaneously.

Results

You now have defined a new protocol and its corresponding transactions, pin roles and fields.

What to do next

Depending on your already existing timing and level setup you may have to enter corresponding protocol specific details.

Use the corresponding tabs of the protocol editor for:

  • Editing protocol specific levels
  • Editing protocol specific wavetable and state map
  • Editing protocol specific timing
