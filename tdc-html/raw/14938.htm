Report Add-ons

The following commands are used to add additional information to the margin report.

<resource type> <sep> <number of top elements> <sep> <delta percentage> 
    "ALL_PASS_ON" | ALL_PASS_OFF" | "TOP" <sep> "ALL"
<number of top elements> = <integer 1..10>
<delta percentage> =  <float value>

TOP lists the top marginal elements of a resource type. ALL means that for every measured resource type the top marginal resources are listed. The list is limited by a maximum number and by a delta percentage - see Summary for an explanation of the delta percentage.

"ECHO" { <sep> "DATE" | "VERSION" }

With ECHO the actual date or the version of the pin margin tool can be added to the report. Defaults are applied unless otherwise specified.
