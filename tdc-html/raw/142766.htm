Text macros

The new :defines: statement in the APG pattern file lets you create text macros, that is, assign text values to a preprocessor variable. These preprocessor variables can be inserted in the program code and are expanded to their text content before the actual compilation takes place.

Benefit

Text macros provide a way to parameterize code, speed up code entry, and make code more human-readable.

More Info

For further details, see Preprocessor statements.
