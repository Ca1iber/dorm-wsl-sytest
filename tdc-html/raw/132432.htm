TMU_TASK.requestResultAreaHandle()

Requests a result area for the TMU results of next functional test.

Syntax

Boolean requestResultAreaHandle(STRING& handle);
Boolean requestResultAreaHandle(const char* handle);
Parameter

I/O

Parameter

Description

I

handle

The user-defined identifier for the result area.

Return value

The execution status of the request is returned. It can be true or false.

True means that the reservation for the result area is successful. The area is created in the next functional test and the TMU results are stored in the area.

False means that the reservation for the result area failed. The actual active result area will be used for the TMU result of the next functional test. So the original content in the result area may be overwritten.

Related information

TMU_TASK.releaseResultAreaHandle()

Functional changes

  1. Introduced in SmarTest 7.1.0
