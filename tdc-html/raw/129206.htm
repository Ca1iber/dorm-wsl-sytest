SHARED_IDD_TEST.waitTime()

The waitTime() member function of SHARED_IDD_TEST lets you specify the time to wait before starting measuring.

Syntax

SHARED_IDD_TEST& waitTime(double time)

Parameter

Description

time

The waiting time before a measurement.

  • The value must be greater than zero.
  • The unit is second [S].
  • The default time value is 0 S.

Example

SHARED_IDD_TEST mTest;
mTest.waitTime(10);
mTest.execute();
