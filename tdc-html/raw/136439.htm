Raw data views

The raw data view displays all individual records that are summarized in the selected row of a loaded data log. You can use the raw data view to examine in detail the results for a particular test, device, wafer, or bin.

In addition to the columns describing each data log entry, a raw data view contains a toolbar, configurable fail and alert marks in the left and right margins, and it has a context menu. All four elements are described below.

Toolbar

The toolbar of a raw data view includes these buttons:

  • Link: Links the display in the view to the selected row in the data navigation view.

    In this mode, if the selection in the data navigation view changes, the display updates automatically.

  • Pin: Freezes the display in the view.

    In this mode, the view keeps displaying the rows it currently displays, even when the selection in the data navigation view changes. Dynamic updating can be resumed by clicking the Link button.

  • New: Creates a new raw data view.
  • Statistics: Displays the summary of the currently displayed rows.

    This display is similar to the contents of the selected row in the data navigation view.

  • Preferences: Opens the Raw Data preference page.
  • Next Annotation: Selects the next row that contains an annotation (fail indicator or alert).

    The drop-down list of the button lets you check an uncheck the annotation types. If an annotation type is unchecked, SmarTest does not jump to this type of annotation.

    For example, if Failed Test is not checked in the drop-down list, SmarTest jumps only to rows containing alerts.

  • Previous Annotation: Selects the previous row that contains an annotation (fail indicator or alert).

    The drop-down list of the button lets you check an uncheck the annotation types. If an annotation type is unchecked, SmarTest does not jump to this type of annotation.

  • Follow Data: Whether the view automatically scrolls to the bottom when new data is added.

    When this button is highlighted, the view automatically scrolls to the bottom to show new data. When it is not highlighted, it does not scroll by itself and always shows the section to which you have scrolled.

Table

The table in the raw data view displays the data from the data log entries that are being summarized in the selected row in the frontmost data navigation view. Each row displays one log entry. Clicking any field in a row selects the entire row (for example, for copying it).

The topmost row in the table (with a cyan background) is the table filter that lets you restrict which rows are displayed in the table by entering conditions. See Table filter for details.

A raw data view table contains these columns:

  • Testflow: The testflow number, which is created by the Integrated Result Tool and increases by 1 every time the testflow is run.
  • Test Suite: The test suite name.
  • Test Method: The test method name.
  • Test: The test name.
  • Test#: The test number.
  • Pattern Name: The name of the pattern used in the test.
  • Wafer: The number of the wafer on which the device is located.
  • Site: The number of the site to which the device belongs.
  • Pin: The name of the tested pin.
  • Device: The number of the device. This number is assigned automatically by the Integrated Result Tool.
  • Device ID: The device ID.
  • Part ID: The part ID.
  • Part Txt: The part description text (PART_TXT).
  • Lower: The lower limit that was specified for the test.
  • Unlabeled column (LS): The comparison operator for the lower limit
  • Value: The measured test value.
  • Unit: The unit for the value.
  • Unlabeled column (US): The comparison operator for the upper limit
  • Upper: The upper limit that was specified for the test.
  • P/F: Whether the test passed or failed.
  • Time: The execution time of the test. (Due to algorithmic overhead, this number may not be the exact actual execution time.)
  • TS Time: The execution time of the test suite. (Due to algorithmic overhead, this number may not be the exact actual execution time.)
  • Print to Datalog: Any text that has been logged with the comment parameter of the PUT_DATALOG API.
  • Test Text: Data logged to the TEST_TXT field in the Multiple-result Parametric - or Parametric Test - Record (see TESTSET).
  • Checkmark column (Include/Exclude): Whether the results of this test are considered for the data displayed in summary views.

Which columns are displayed and the order in which they are displayed can be set in the preferences.

Clicking a column title sort the table by this column in ascending order (rows with smaller values come first). This is indicated by a triangle . Clicking again sorts the table by the column in descending order, which is indicated by an upside-down triangle . Clicking again unsorts the table. (The rows are displayed in the order in which they occur in the data store.)

Marks in the annotation and overview rulers

The left and right margins of the tab contain indicators for failed tests, alerts you have defined, and other special conditions.

The annotation ruler (the left margin) contains icons indicating rows with fails, exclusions and alerts:

  • The test summarized in this row failed for at least one device.
  • This row contains a cell with an alert.
  • This row has been excluded from the summary. (See Excluding data from evaluation for details.)
  • The test summarized in this row contains a shmoo hole.
  • When a row is marked by multiple icons, these icons overlap.

You can disable the different icon categories in the Annotations preference page. By default, all are enabled.

The overview ruler (right margin) contains a small colored rectangle for each row with a failed device and each row with an alert. Clicking a rectangle selects the corresponding row in the table. Hovering over a rectangle with the mouse displays a tooltip with the reason for the alert. Hovering over the small colored square in the upper right corner of the view displays a tooltip with the total numbers of failed rows, excluded rows, and rows with alerts.

You can choose the colors in the Annotations preference page and disable any kind of indicator. By default, indicators are red for fails, blue for exclusions, yellow for alerts, and cyan for shmoo holes; all kinds are enabled.

For more information on configuring fail indicators and alerts, see Highlighting specific data.

Shortcut menu

The shortcut menu of a raw data view contains these commands:

  • Open Definition: Opens the testflow editor and selects the test suite that has generated this log entry.

    The testflow must already be loaded into SmarTest.

  • Open With: This submenu contains the Protocol Monitor command. Choosing it opens the data represented by the selected row in the Protocol Monitor view.
  • Analyze Selection: Includes the selected rows into the summaries based on the data log in which they are contained and exclude all rows that are not selected. In other words, the values in the data navigation view (and the graphs in any charts based on them) will only include the selected rows.

    This is equivalent to checking the checkbox in the checkmark column for these rows and unchecking all other rows.

  • Include: Adds rows to the summaries:
    • Selection: The selected rows are added to the summaries (that is, to the values in the data navigation view and the graphs in any charts based on them).

      This is equivalent to checking the checkbox in the checkmark column for the selected rows.

    • All: All rows in the view are added to the summaries.

      This is equivalent to checking the checkbox in the checkmark column for all rows.

  • Exclude: Excludes rows from the summaries:

    This is equivalent to unchecking the check box in the checkmark column for these rows.

    • Selection: The selected rows are removed from the summaries (that is, from the values in the data navigation view and the graphs in any charts based on them).

      This is equivalent to unchecking the checkbox in the checkmark column for the selected rows.

    • Pass: All rows containing pass results are removed from the summaries.

      This is equivalent to unchecking the checkbox in the checkmark column for passed tests.

    • Fail: All rows containing fail results are removed from the summaries.

      This is equivalent to unchecking the checkbox in the checkmark column for failed tests.

    • All: All rows in the view are removed from the summaries.

      This is equivalent to unchecking the checkbox in the checkmark column for all rows.

  • Filter: This submenu lets you restrict the display to either passed or failed tests. Note that this is purely a display effect; hidden records are not excluded from evaluation as with the Exclude command described above.
    • Show All: Displays all records in the view.

      This is default state; therefore, choosing the command is only necessary when you have previously hidden some records with one of the following commands.

    • Show Only Pass: Displays only records with a pass result.
    • Show Only Fail: Displays only records with a fail result.
  • Width: This submenu includes the Autofit command that lets you make each column just wide enough to show all of its contents.
  • Copy: Copies the selected rows to the clipboard as tab-separated text.
  • Alerts: Opens the Alerts preference page.
  • Preferences: Opens the Raw Data preference page.
