Topic 94105

SharedContinuity syntax

To edit the parameters of the SharedContinuity test method, click it in the tabular test editor. The parameters are displayed in the Test Suite window and you can edit them there.

Parameters

Name

Type

Default

Comment

DriverSharing_Config_File

String

 

Name of sharing configuration file used.

The file should be located in <device directory>/configuration/.

See Sharing configuration file for details on the configuration file.

Shared_Pins

String

 

Shared pins and pin groups that are to be measured. Separate entries with commas.

Force_Voltage

Double

1

The force voltage that is to be applied on the termination DPS.

The unit is volt.

Non_shared_Pins

String

 

Non-shared pins and pin groups that are to be measured. Separate entries with commas.

Force_Current

Double

1

The current forced into non-shared pins.

The unit is μA.

Cross-Terminated Pins

String

 

Cross-terminated pins and pin groups that are to be measured. Separate entries with commas.

Force Current Cross-Terminated

Double

1

The current forced into cross-terminated pins.

The unit is μA.

Daisychain_termination_DPS

String

VTERM1, VTERM2

Name of termination voltage DPS used. Separate multiple DPS by commas.

This parameter is ignored for DPS-shared load boards for which there is a utility_control section in the Sharing configuration file.

Supply_DPS

String

VDD1, VDD2

Names of all supply voltage DPS used. Separate multiple DPS by commas.

This parameter is ignored for DPS-shared load boards for which there is a utility_control section in the Sharing configuration file.

Settling_Time

Double

0

Unit: ms. Additional settling time in milliseconds

Utility control

The keyword for specifying the utility line settings for SharedContinuity in the utility control section of the sharing configuration file is continuity.

For information on the syntax, see Sharing configuration file.
