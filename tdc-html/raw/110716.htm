Assigning a pin name to a digital or DC scale channel

Pin names are assigned to DC Scale channels with with the DFPN or the DFPS command. Which command is to be used depends on the required operation mode. If the channel is to be operated in PMU mode, the name must be assigned with DFPN; if it is to be operated in DPS mode, the assignment must be made with DFPS.

The pin name is the name by which the software identifies the channel. Note that you can use the DFPN command only if the sequencer state is OFF (compare the SQST command). DC Scale channels are identified by a five digit number in the same way as digital channels, see Assigning a pin name to a digital channel.

The operation mode of a DC Scale channel is completely determined by the command with which it was given its name. It cannot be changed with the CONF configuration command. However, the CONF? query shows the operation mode of a DC Scale channel.

You can also configure ganging for DC Scale channels in both operation modes by specifying a channel list in the DFPN or DFPS command.
