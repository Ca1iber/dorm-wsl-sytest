vClamp()

Specifies the clamp voltage.

This function is only for the DC Scale XPS256 card. The function can be used in the code‑based mode and in the pattern‑based mode.

Change range in pattern‑based mode (XPS256)

The force or clamp range of DC Scale XPS256 pins can be changed without disconnecting the channel. In pattern‑based mode, the correct sequence of changing the range and the value must be applied to avoid range overflow warnings.

For more information refer to iForceRange() or vForceRange().

Syntax

dcBase& vClamp(double vClampLow, double vClampHigh);

Syntax for a clamp voltage waveform:

dcBase& vClamp();

Syntax for changing the clamp voltage at runtime:

dcBase& vClamp(const string& runTimeId_vClampLow, const string& runTimeId_vClampHigh);
Parameters

Parameter

Description

vClampLow

vClampHigh

The two double parameters define the low and the high clamp voltage.

runTimeId_vClampLow

runTimeId_vClampHigh

The two string parameters refer to single double values or arrays of type ARRAY_D that have been assigned by function runTimeVal() and are filled with the clamp voltage values.

For more information refer to Changing the parameter value at run-time with SmartRDI.

Return Value

A reference to the dcBase object.

Example

rdi.dc().pin("pinA")
        .iForceRange(50 mA)
        .iForce(5.0 mA)
        .vForceRange(10 V)
        .vClamp(-1.0 V, 7.0 V)
        .execute();
