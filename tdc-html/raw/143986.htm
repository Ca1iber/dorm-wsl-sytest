SOURCESYNC_DOMAIN.bufferPins()

Specifies buffer pins used with a rapid source-sync test in this domain.

Syntax

virtual SOURCESYNC_DOMAIN& bufferPins (const string& pinGroup);
Parameter

Parameter

Description

pinGroup

The buffer pins in this domain, separated with ",".

For example, "clk0, data00, data01".

Related information

SOURCESYNC_TEST.rapidSourceSync()

Functional changes

  1. Introduced in MTP 3.2.2
