Topic 31310

Grid

Class Grid controls the following grid operations:

  • make grid visible/non-visible
  • set grid color
  • set grid step size

Class Grid is related to Class Axis. Each grid is placed on (or belongs to) an axis.

Syntax

Grid obj;

where obj is an object of Grid and func is a member function of Grid.

Constructor

Grid(void);

The above two constructors create a new object of Grid.

Grid(const Grid & grid);
const Grid & operator=(const Grid & grid);

This constructor creates an object of Grid by copying from another one.

Parameter

grid

The Grid object.

Member functions

setVisible()

Grid & setVisible(bool visible);

This function sets the grid to be visible or not.

Parameter

visible

Whether the grid if visible. It can be:

  • true: Make the grid visible.
  • false: Make the grid non-visible

isVisible()

bool isVisible(void) const;

This function returns whether the grid is visible.

setColor()

Grid & setColor(Display::Color color);

This function specifies a color to the grid.

Parameter

color

The color of the grid. It can be:

BLACK, BLUE, CYAN, DARK_GRAY, GRAY, LIGHT_GRAY, GREEN, MAGENTA, ORANGE, PINK, RED or YELLOW.

getColor()

Display::Color getColor(void) const;

This function returns the color of the grid.

setStepSize()

Grid & setStepSize(double stepSize);

This function specifies the step size for the grid.

Parameter

stepSize

Step size of grid.

getStepSize()

double getStepSize(void) const;

This function returns the step size of the grid.

setAutoStepSize()

Grid & setAutoStepSize(bool auto);

This function sets whether the grid step size is automatic or not.

Parameter

auto

whether the step size is automatic. It can be:

  • true: Enable the automatic step size.
  • false: disable the automatic step size.

isAutoStepSize()

bool isAutoStepSize(void) const;

This function returns whether the grid step size is automatic.

Examples

Make the specified grid non-visible temporarily

GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getXAxis(1).getGrid().setVisible(false);
graphManager->setGraph(graph, 1);

This example sets the grid of x-axis in graph 1 to be invisible.

Change grid color

GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getXAxis(1).getGrid().setColor(Display::YELLOW);
graphManager->setGraph(graph, 1);

This example sets the grid of x-axis in graph 1 to be yellow.

Change grid step size

GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getXAxis(1).getGrid().setColor(Display::YELLOW);
graphManager->setGraph(graph, 1);

This example sets the grid step size of x-axis to be 10.
