Recording parameters

Subtopics

  2. Recording position
  3. Result granularity
  4. Resolution of the error code
  5. Possible combinations of CYRM, CYRP, and DCRM
  6. Location of the detailed Error Map
  7. Compression factor for overview Error Map

There are six parameters by which you can control how and where error information is recorded:

  • Recording mode for detailed Error Map
  • Recording position
  • Result granularity
  • Resolution of the error code
  • Location of the detailed Error Map
  • Compression factor for overview Error Map

There are dependencies between the result granularity and the error code resolution. In addition, these dependencies differ on different hardware types. A summary is given in Possible combinations of CYRM, CYRP, and DCRM.
