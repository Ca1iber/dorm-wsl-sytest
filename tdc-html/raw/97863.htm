Topic 97863

Editing a utility purpose

About this task

This editor lets you:

  • Define a new utility purpose from scratch
  • Make changes to an existing utility purpose

The same process applies to both cases.

Before you begin

Make sure that an utility purpose has been created.

Procedure

  1. Open the setup editor of the utility purpose you want to edit. If the utility purpose is new, the Utility Members area is blank.
  2. To add utility lines to the utility purpose, select one or more utility lines (press Ctrl and then click) in Utility Lines areaand click Add >.

    To add all the utility lines to the utility purpose, click Add All >>.

  3. To delete utility lines from the utility purpose, select one or more pins in Utility Members area and click < Remove.

    To delete all the utility lines from the utility purpose, click << Remove All.

    Note To quickly find the utility lines you are interested in, you can use Filter line.
  4. Repeat the step 3 to 4 until all desired utility lines appear in Utility Members area. Here, the setting data (state) for each utility lines is left blank.
  5. To set up the state of the utility lines, double-click the state area and enter the state (1, 0 or X).

    You can also set up the state(s) by copying from the existing ones. Select a rectangle state area, right-click and select Copy or use the keyboard Ctrl+C. Then select the first cell of the area you want to paste, right-click and select Paste or use the keyboard Ctrl+V.

    Before applying the changes, you can undo the changes with the keyboard Ctrl+Z and redo the changes with the key board Ctrl+Y.

  6. Type a value into Settling Time text box if necessary.
  7. Apply the data. The data will be checked before downloading. If anything is wrong, an error message dialog will be displayed. After closing the dialog, the utility purpose with wrong setting will be opened and the first cell with wrong information will be highlighted and focused.
  8. Correct the wrong settings and apply the data again until no error occurs.
  9. Save the pin configuration file.

Results

In the Utility Lines area, the utility lines in the utility purpose are indicated with "√".
