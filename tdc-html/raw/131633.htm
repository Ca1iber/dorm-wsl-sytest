SHARING_CONFIGURATION.hasLoaded()

The hasLoaded() member function of SHARING_CONFIGURATION returns "true" if a configuration file has been loaded, and "false" if not.

  • If true is returned:
    • You can use the data-accessing member functions of SHARING_CONFIGURATION to read the data.
    • The load() and setRefPin() member functions do not load the specified configuration.
  • If false is returned: You can use either load() or setRefPin() to load a sharing configuration. Then you can read its data via the data-accessing member functions of SHARING_CONFIGURATION.

Syntax

bool hasLoaded() const
