UHC4T power modes

The DC Scale UHC4T supports two power modes that define the maximum current capability and the current measurement accuracy.

The two power modes are defined as follows:

  • High-power mode

    In the high-power mode the maximum current capability is 40 A per channel. In high-power mode you can force and measure.

  • Precision mode

    In the precision mode the maximum current capability is 1.5 A per channel, but with a higher current measurement accuracy than in high-power mode. In precision mode you can force and measure small currents for continuity checks and Idd measurements.

You can switch between both modes without limitation. A disconnect is required except for unganged measurements.

Selecting the power modes

The system chooses automatically the applicable power mode depending on the specified current. One of the modes, either the high-power mode or the precision mode, is always active for force and measure. During the range transition from 1.5 A to 40 A both modes are active to avoid glitches.

Selecting the Precision mode temporarily

The following APIs may be applied for measuring the current temporarily in the Precision mode:

  • Use API DPS_PIN_TASK.measurementMode(TM::MEASURE_CURRENT_UNGANGED) for changing to the unganged measurement mode and activating the Precision mode.

    Note: The unganged measurement mode removes temporarily ganged channels from a ganged group and additionally activates the Precision mode for a single channel. The measurement mode must therefore be set to TM::MEASURE_CURRENT_UNGANGED although the measurement is performed on a single channel.

  • Limit the maximum current to a 1500 mA or lower using APIs DPS_PIN_TASK.min().

Selecting the Precision mode permanently

The following setup can be applied for measuring the current permanently in the Precision mode:

  • Specify an iout_clamp_rng = 1500 (or smaller) and connect_state = ungang in the DPSPINS block of the level equations.
  • CONNECT (or DISCONNECT followed by CONNECT if already connected).
