Shutting down or rebooting the system controller

Safely shutting down a system controller must be done from the operating system and requires you to follow a few basic steps.

Before you begin

When shutting down or rebooting a system controller workstation, perform this action from the operating system interface. Do not use the workstation power button.

CAUTION Using the workstation power button to shutdown or reboot might cause damage to the file system.

Procedure

  1. To shut down the SmarTest Work Center, from the menu bar, click File > Exit or click the close button .

    A confirmation window opens.

    To confirm the exit, click OK.

    Alternatively:

    • From UI_report window, click File > Exit.
    • From TCCT GUI window, click Stop SmarTest
    • From the command line:

      /opt/hp93000/soc/system/bin/run -x /opt/hp93000/soc/system/bin/sessionconsole -- -shutdown <session>

      If you are already in a prepared environment (for example, in a script that has been called with run -x), you can use the following command (without --) :

      /opt/hp93000/soc/system/bin/sessionconsole -shutdown <session>

      Note -- is used to prevent run from interpreting these command line arguments itself, instead passing them on to sessionconsole.
  2. Shutdown or reboot the system controller workstation as follows:
    • Red Hat Leave menu entry. From the task bar:

      Red Hat button > Leave > Restart or Shut down

    • From the command line:
      1. Change to user root.
      2. Shut down or reboot using the appropriate command:
        Reboot:
        systemctl reboot
        Shut down:
        systemctl poweroff
