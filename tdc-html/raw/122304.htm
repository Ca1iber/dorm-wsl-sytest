CCTregisterDGT

This function registers the analog digitizers so that data can be later uploaded from these pins with correct upload ID.

Uploading data requires specifying a capture ID, which is not hard coded because it is dependent on the order of tests in concurrent execution. Registering instructs the framework to maintain the correct IDs. Later on in the result upload routines, the correct IDs can be queried from the framework.

This function is usually used in the init() function but not used in the other functions of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

bool CCTregisterDGT(const string& pinName);
Parameter

pinName

The pin name of analog digitizer.

Functional changes

  1. Introduced in SmarTest 6.5.4
