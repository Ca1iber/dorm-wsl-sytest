Topic 137299

Annotations preferences

Table annotation types: Select a type in this list to specify the options for it.

  • Alerts: Conditions set on the Alerts preference page.
  • Excluded: Excluded rows in detail data views or rows in data navigation views for which rows have been included in detail views.
  • Failed Tests: Summaries containing at least one fail test.

Show in Overview Ruler: The selected annotation is displayed as a colored rectangle in the right margin of table views.

Show in Annotation Ruler: The selected annotation is displayed as an icon in the left margin of table views.

Color: Click to set the color with which this annotation is displayed in the right margin of table views.
