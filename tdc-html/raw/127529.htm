Migrating test number

Subtopics

  1. Test number conversion procedure
  2. Test number conversion rules
  3. Test number conversion use cases

With the introduction of the test number generator, all test number manager related flags are disabled and the flags in a testflow file are ignored. The test number generator will be the tool to create test numbers in testflows. The test Numbering conversion tool converts the test numbering settings in test number manager to the ones in test number generator. The Test Numbering Conversion tool is designed to create test numbers in the testflow file based on test number file. As an option, it supports the creation of a test table CSV file as well.
