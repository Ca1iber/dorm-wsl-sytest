UTILITY_POWER_STATUS.execute()

Executes the previously specified actions of the UTILITY_POWER_STATUS object.

The actions are to be defined by member functions state() and wait().

Syntax

virtual void execute();
List of parameters
There are no parameters.
Return value
There is no return value.

Functional changes

  1. Introduced in SmarTest 7.2.1
