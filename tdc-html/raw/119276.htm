Waveform view

This view displays the contents of the array selected in the C/C++ editor.

The heading displays the name and type of the variable being graphed.

Toolbar

Clicking "Clear Waveform" () removes the currently displayed waveform from the view.

Clicking "Show Waveform on Signal Analyzer" () displays the current waveform in the Signal Analyzer Tool.

Choosing Save As from the menu () lets you save the current waveform as an ASCII file in the same format used by the Signal Analyzer Tool.
