GET_SYSTEM_FLAG

This API retrieves the current value of the specified system flag.

Syntax

void GET_SYSTEM_FLAG(const STRING& flag, INT *value);

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Parameters
I/O Parameter Description / Range
I flag A system flag name.
O value The current value of the specified flag is returned to this variable.
Available options of parameter flag
Available system flag names are listed below. For more details on individual flags, see Setting system flags, Flags for data logging, and Using system flags.
  • abort
  • bin_code
  • bin_number
  • calib_age_monitor
  • check_dev
  • current_monitor
  • datalog_formatter
  • datalog_sample_size
  • diag_monitor
  • exit_testflow
  • graphic_result_display
  • hw_response_emulator
  • ink_wafer
  • level_end
  • log_events_enable
  • max_reprobes
  • pause
  • print_wafermap
  • quit
  • reset
  • site_setup
  • state_display
  • temp_monitor
  • test_number
  • update_required

The following are read-only flags which cannot be set by using the SET_SYSTEM_FLAG API.

  • bad_part
  • dev_error
  • dev_hold
  • good_part
  • idle
  • offline

    SmarTest runs in offline mode: 1

    SmarTest runs in online mode: 0

  • ooc_stop
  • ooc_warn
  • reference
  • reprobe_error
  • retest
  • retest_w
  • site_reprobe
  • skip
Return value
There is no return value.

Example

The GET_SYSTEM_FLAG API retrieves the current value of the bin_number flag:

INT binNum;
...
...
GET_SYSTEM_FLAG("bin_number", &binNum);
