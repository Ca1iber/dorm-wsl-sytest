DRLEventGetNoOfAttributes

int DRLEventGetNoOfAttributes (const DRLEventRec *event))

This function lets you find out the number of attribute records which come with event. It is used in conjunction with the DRLEventGetAttribute function.

Return Value

The function returns the number of attribute records coming with event or a negative number indicating an error.

Functional changes

  1. Introduced before SmarTest 6.3.2
