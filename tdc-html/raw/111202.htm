Topic 111202

initializeSession()

This API initialize the working conditions for test suite control. It must be used before all other test suite control APIs.

It connects to a SmarTest session and select the test method executor to use. If it cannot connect to a SmarTest session, a runtime_error exception will be sent out.

Syntax

void initializeSession(const std::string& sessionId = "", 
const int testmethodExecutor = 1);
Parameters

sesionId

The ID of the SmarTest session to work with. Default value is empty, which means the API will automatically gets the SmarTest session ID of the current display.

TestmethodExecutor

The test method executor to be used for execution. Default is the first one.
