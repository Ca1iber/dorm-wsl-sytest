Selecting a Data Bridge

The application file determines what data is to be logged, and when and where it is to be logged. The logged data can be accessed by data-formatting routines located in the data bridge directory. Since you may use different data formats, one or more data bridges can be selected and installed.

  1. In the Test Program Explorer highlight the item Data Bridge.
  2. Right-click and select Load... . All available Data Bridges appear in a browser window.
  3. Highlight your desired Data Bridge, and click OK.
