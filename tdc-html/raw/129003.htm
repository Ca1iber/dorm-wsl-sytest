MTP_MEMORY_TEST.enableFailBitCount()

The enableFailBitCount() member function of MTP_MEMORY_TEST lets you specify that fail bit counts (FBC) instead of functional test results are used to determine the overall pass/fail result.

This is an optional method. The threshold values must be set with the setFBCLimit() function.

Syntax

MTP_MEMORY_TEST& enableFailBitCount(const bool status)

Parameter

Description

status

Whether the overall pass/fail result is determined by the fail bit counts:

  • true: The overall pass/fail result is determined by the fail bit counts. The threshold values are set by the setFBCLimit() function.

    If any of the limits set by this function is exceeded, the test fails.

  • false: The overall pass/fail result is determined by the functional test result.

The default is false.

Example

Switching on the fail bit count as the basis for determining the overall pass/fail result:

MTP_MEMORY_TEST memoryTest();
memoryTest.enableFailBitCount(true);
