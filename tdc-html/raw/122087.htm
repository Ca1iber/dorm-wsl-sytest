Variable PPMU_SETTING objects

The creation of variable PPMU_SETTING objects requires the correct usage of the .setup() API function to avoid running out of MSETs.

Creating MSETs

The example below shows how to apply .setup() to create the required MSETs.

Examples

Description

The .setup() API function tells the software to change a single parameter of an existing MSET and reuse it.

  PPMU_SETTING   pSetVoltage;
  PPMU_RELAY     pRelPPMU_ON;
  TASK_LIST      pTaskLeak;

  ON_FIRST_INVOCATION_BEGIN();
     pSetVoltage.pin( "grpLeak1").vForce(2 V)
                .iRange( 40 mA ).min( 0 mA ).max( 40 mA );

     pRelPPMU_ON.pin ( "grpLeak1,grpLeak2" ).status( "PPMU_ON" );
     pRelPPMU_ON.wait ( 1 ms ) ;
     pTaskLeak .add( pRelPPMU_ON ).add( pSetVoltage ).setup();

     FOR_EACH_SITE_BEGIN()
         pSetVoltage.pin( "grpLeak1" ).vForce( gMeasResult(iSiteNr) );
     FOR_EACH_SITE_END()

     pTaskLeak.execute( ) ;
  ON_FIRST_INVOCATION_END();

Common pitfalls

If variables are passed to the test method to specify, for example, a voltage, the .setup() API function is not needed. In this case the voltage will not change during the production run.
