Topic 69654

Parametric or functional test types

The SmarTest Data Formatter needs to know the type of test for each test function or test method program, in order to place the test suite data in the appropriate record.

Each test event, whether from a test function or test method, has a test type attribute that specifies either a functional, parametric, or unknown test type. Functional test types are placed in an FTR. Parametric test types are placed in a PTR if a single value is given, and placed in an MPR if the per-pin flags were set for that test suite. Unknown test types are placed in an FTR.
