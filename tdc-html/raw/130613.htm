DIGITAL_WAVEFORM.putWaveform()

This function overwrites the integer waveform data retrieved in the previous execution of the method execute() as ARRAY_I for the specified pin.

Syntax

void putWaveform(const STRING& pin, const ARRAY_I& waveform)
Parameter

pin

The pin to apply the waveform.

waveform

The waveform used to overwrite the waveform from the previous execution. The elements in the waveform are integer offset values.

Functional changes

  1. Introduced before SmarTest 6.3.2
