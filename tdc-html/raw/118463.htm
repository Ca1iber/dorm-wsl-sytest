The Preferences window opened by choosing Window > Preferences includes the pages to set how the Eclipse tools operates.

The following Preferences window displays the Advantest V93000 > General preferences.

In the Preferences window, the left pane lists all the preference pages. To find a specific page, you can type the keyword in the filter field.

The right pane displays the preferences for the selected page. In the upper right, the arrows allow you to navigate through the previously viewed pages.

The right pane also has the following functions:

  • Restore Defaults: Reset the dialog pane to the factory default settings.
  • Apply: Save the current dialog pane settings. They remain in effect until they are changed.

This section describes all the preference pages for the SmarTest tools (The preference pages under the Advantest V93000 node in the left pane). The topics are sorted in the ascending order by the preference page name.

Sharing of preferences

After the customization of preferences and perspectives, you may want to save your customization explicitly (for later recovery) or even to share it with others.

  • Save your customization to a configuration file: File > Export > General > Preference
  • Load the configuration from a configuration file: File > Import > General > Preference
