Topic 99457

Deleting variables

Before you begin

Make sure that the variable has been defined and not used in the testflow (the testflow nodes using the variable have been removed).

Procedure

  1. On the Variables page of the Flow Data Editor, click the row number of the variable you want to remove, and then press delete.
  2. The Confirm window opens. Click OK.

Results

The variable is removed.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.2: You can delete variables on the Variables page.
