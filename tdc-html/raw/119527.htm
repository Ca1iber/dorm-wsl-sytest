How to configure the layout of the Pattern Debug Tool

  • Filters (hidden)

    Select the columns you want to hide.

How to link Pattern Label to Display Layout:

  • Specify the layout you want to use for all patterns (Link to the Layout), or just as a template (Link to the per-Label Layout).

    Use Ctrl+Space to list all available layouts.

  • In Restrict maximum signal column width, specify the maximum signal name column width.
    Note This function is valid for the horizontal pattern view only, when the signal names are shown as a column (Ctrl+Alt+H).
  • Show State Number in Default shows an additional column with the user vector number for each signal.
  • Auto Save Display Layout saves the layout automatically when you close the Pattern Editor.
  • Use Store SmarTest 6.3.x compatible Display Layout to save the layout to be compatible with SmarTest 6.3.x.
