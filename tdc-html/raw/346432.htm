FFC and FFV information in GDR records

GDR records that encode first failing cycle and first failing vector information do so in a specific format.

Fields in GDR records that encode FFC and FFV information do not have names; they are identified just by their numbers.

The first 14 fields form a header-like structure. They occur only once.

Fields 15 to 28 describe a pin and are repeated for each pin.

Fields 25 to 28 describe an event and are repeated for each event for the pin in question.

For example, a record describing two pins and two events would have this sequence of fields: 1..14, 15..24, 25..28, 25..28, 15..24, 25..28, 25..28.

The GDR record encoding the FFC and FFV information follows the FTR record. It is generated only if the disableGDRForFTR option is set to false.

GDR record structure for FFC and FFV data
Field Data type Content
1 Variable length character string RESULT (hardcoded)
2 Variable length character string VECTOR(hardcoded)
3 One-byte unsigned integer Site number
4 Four-byte unsigned integer Test number
5 Eight-byte floating point number Cycle number
6 Variable length character string Label
7 One-byte unsigned integer Resolution mode
8 Variable length character string Port name
9 Variable length character string Label type
10 Four-byte unsigned integer Vector number
11 Variable length character string Sequence command
12 Variable length character string Vector comment
13 Two-byte unsigned integer Vector pin size
14 One-byte unsigned integer Number of waveforms
(One occurrence of the pin result section per pin.)
Pin result section
Field Data type Content
15 Variable length character string Pin name
16 One-byte unsigned integer Cycle offset
17 One-byte unsigned integer DD1
18 One-byte unsigned integer DD2
19 One-byte unsigned integer EE1
20 One-byte unsigned integer EE2
21 One-byte unsigned integer Received
22 One-byte unsigned integer Edge number
23 One-byte unsigned integer Parameter
24 One-byte unsigned integer Number of events
(One occurrence of the event result section per event.)
Event result section
Field Data type Content
25 Variable length character string Wave index
26 Variable length character string Event index
27 One-byte unsigned integer Expected
28 Four-byte unsigned integer Received
