Topic 131009

How to create an equation set using the Equation editor

This topic describes how to create an equations set using the Level Setup tool and the equation editor.

Before you begin

You have set up your pin configuration.

Procedure

  1. Start the Level Setup tool
  2. Open the Equation editor
  3. Type your setup data

    For detailed information, see

    • Elements of Equation Based Level Setup
    • Structure of an equation based level setup
    • Level Equations: setup example
  4. Download the data to the tester:
    • On the menu, click Shell > Download
    • Press F8
  5. Save your changes in the Test Program Explorer:
    1. Right-click Levels
    2. Click Save as
    3. In the Enter or select new file name window type the file name (for example: levels)
    4. Click OK
      Note Do not use the File > Save option of NEdit. In order to save your work you must first download the changed data, and then save them from the Test Program Explorer.

Example

  1. In the Test Program Explorer, double-click the <Levels> icon.

    The Level Setup window opens.

  2. In the Level Setup window, click on the menu

    Select > Edit Equations.

    The equation editor (NEdit) opens.

  3. In the first line, type:

    EQNSET 1 "NonSpecs"

  4. Enter data for the DPS pin Vcc:
    DPSPINS Vcc
 vout = 4.5
 ilimit = 1000
 t_ms =4
 offcurr = act
  5. Create the level set (every level set must contain information for all pins defined in your pin configuration)

    LEVELSET 1 "nominal"

  6. Enter information for the input pins:
    PINS ctrl ser_in
 vil = 0
 vih = 4.3
  7. Enter information for the output pins:
    PINS ser_out
 vol = 2.4
 voh = 2.6
  8. Enter information for the I/O pins:
    PINS io_pins
 vil = 0
 vih = 4.3
 vol = 2.4
 voh = 2.6
  9. On the menu, click Shell > Downloadto download the level to the tester hardware and make sure you correct any reported error in the Report window.
  10. Save your changes in the Test Program Explorer:
    1. Right-click <Levels...>.
    2. Click Save As.
    3. In the Enter or select NEW file name window type the file name (for example: levels).
    4. Click OK.

_Do not use the File > Save option of NEdit. In order to save your work you must first download the changed data, and then save them from the Test Program Explorer.
