Copying Specification Sets

  1. Click Copy Specification Set in the Change pulldown menu.

    A screen similar to that of the figure below appears.

  2. Highlight the specification set you want to copy and in the New Spec Set edit box, key in a value for the new set.
  3. Click copy to copy this specification set to the new destination.
  4. Repeat these last steps as often as required (for other specification sets), and click done when finished.

Functional changes

  1. Introduced before SmarTest 6.3.2
