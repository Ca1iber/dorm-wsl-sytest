Topic 112905

EQFC, EQFC? - (EQualization and Filter Configuration)

Use the EQFC command to configure the equalization and the low pass filter parameters.

The level set supports additional properties whereby filter time constants (risetime) and the relative swing offsets can be specified on a per pin base. The values can be specified using Equation based level setup or by using the firmware command EQFC.

Note This command only applies to PS1600 and PS5000 because the equalization feature is not supported on any other cards.

EQFC

EQFC {level_set_no|level_set_id|ALL|PRM} ,{filter_parameter|ALL_specifier}, {offset_value|filter_value}, {(pinList)}

EQFC?

EQFC? {level_set_no|level_set_id|ALL|PRM} ,{filter_parameter|ALL_specifier|ALL}, {value}, {(pinList)}

Parameters

level_set_no

The identification number of the level set (fixed levels) in which you want the filter/equalization values to be included. The number must not exceed the maximum number of level sets allowed (as defined by the DSCP command).

level_set_id

Used in equation based level setup. It is derived as follows:

100000 * equation_set_no + 1000 * specset_no + level_set_no

If you use the command for an equation based level setup, you modify only the runtime values, not the value in the level set

ALL

Sets the given parameters for all existing level sets.

PRM

Sets the equalization for the primary level set.

filter_parameter

See table below: Impact and characteristics of the equalization parameter filter_parameter.

ALL_specifier

Modify multiple parameters by one command, see table below: Possible values for ALL_specifier.

ALL

Selects all low pass filter and equalization parameters.

Query only.

offset_value

filter_value

Defines the value for the specified filter_parameter, see table below: Valid ranges for the equalization parameters (set value using "offset_value").

Time constants (risetime) for the filters are specified in nanoseconds (ns).

If you try to set a value that is out of range, in the Console view, SmarTest issues an error message including the corresponding limit.

pinList

List of pin names to which the command is applied. If a list of more than one pin is required, the names must be separated with a comma.

Application

This command applies to the Level Setup applications.

Errors

An error is generated in case of one or more of the following cases.

  • The level set number is out of range.
  • The specified filter or equalization offset value is out of range.

    The filter values are silently clipped if they are in range but could not be set. An error is generated if the value is outside the range defined in the specification.

  • One of the specified pins does not have the respective capabilities.
