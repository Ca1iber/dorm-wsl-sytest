DRLPinValueResultAttr

A variable of this type is a pointer to a structure named _DRLPinValueResultAttr. In this structure a list of pin value results and pass/fail results is stored (see DRLPinValueResult).

The member unit holds the unit of the measured pin values as a NULL terminated string.

Note You can specify any derived unit (such as ns or mA) for EDL data logging. However, when data logs are converted to STDF, all units are converted to their SI equivalents (ns to s, mA to A) and the corresponding values are converted accordingly. (For example, 435 mA is converted to 0.435 A.)

The member size holds the actual number of elements in the pins array, that is, the number of pin value results in the list.

The member description can hold any additional information as a NULL terminated string.

typedef const struct _DRLPinPFResultAttr{
    char *unit;
    char *description;
    unsigned size;
    DRLPinValueResult pins[1];
   } DRLPinValueResultAttr;
