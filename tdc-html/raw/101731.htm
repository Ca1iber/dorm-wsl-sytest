Topic 101731

DSP_ADC_SINE_LINEAR

This API computes the differential linearity error (DLE) and integral linearity error (ILE) for an A/D converter when the input signal is sine wave.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_ADC_SINE_LINEAR(ARRAY_I& src,
                        LINEARtype *result,
                        ARRAY_D& dle,
                        ARRAY_D& ile,
                        INT *miss_number,
                        ARRAY_I& miss_code,
                        DOUBLE min_code_size); 
DSP_ADC_ SINE_LINEAR(INT *src,
                         LINEARtype *result,
                         DOUBLE *dle,
                         DOUBLE *ile,
                         INT *mis_number,
                         ARRAY_I& miss_code,
                         INT size,
                         DOUBLE min_code_size);
Parameters

I/O

Parameters

Description

I

src

The captured sine wave data array.

O

result

The results for DLE and ILE values. The components of result are declared by LINEARtype. (See the table below.) Unit: LSB

O

dle

DLE data array. Unit: LSB.

O

ile

ILE data array. Unit: LSB.

O

miss_number

The number of missing code.

O

miss_code

The data array of missing codes.

I

size

The size of the src data array.

Note The samples size is limited to 2M samples. For larger sample sizes exceeding 2M samples, use the Wave APIs.

I

min_code_size

The limit value to determine the missing codes.

Example

In this example, 64K digital output is captured from the 10-bit A/D converter. The output data is stored in the variable source. The DSP_ADC_SINE_LINEAR API computes the DLE and ILE of the converter when the input signal is sine wave.

DOUBLE dle[1024], ile[1024];
INT miss_num; 
INT source[65536];
ARRAY_I miss_code;
LINEARtype result;
//execute the ADC linearity test with sine wave 
//and retrieve the output data
      :
      :
 DSP_ADC_SINE_LINEAR(source, &result, dle, ile, &miss_num, miss_code, 65535, 40.0);
