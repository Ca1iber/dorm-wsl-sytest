Creating an Application Data File

  1. Select your application model file as outlined in Selecting a new application model file.
  2. Open the Application Data Editor window by clicking Application in the Main Menu. A screen similar to that of the figure below appears (for the application model package_manual.
  3. edit any appropriate attributes by,
    1. clicking the cursor in the attribute column, to the right of the entity you wish to set/change
    2. key in the desired attribute
