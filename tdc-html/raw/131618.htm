MTP_LEAKAGE_TASK.getValue()

The getValue() member function of MTP_LEAKAGE_TASK lets you get the measured current in ampere ([A]) for a specific pin.

Syntax

double getValue(const string & pin)const

Parameter

Description

pin

The name of pin whose measured current you want to retrieve.

The unit of the retrieved current is ampere ([A]).

Related information

MTP_LEAKAGE_TASK

Functional changes
