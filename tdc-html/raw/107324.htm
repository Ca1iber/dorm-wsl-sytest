UHC4T measurement modes

UHC4T supports current and voltage measurements. Both measurement modes can be programmed as static measurement or as dynamic measurement. And both can be run in high-power mode and in precision mode (see UHC4T power modes).

Static measurement

  • Static current measurements

    When programming a static current measurement for UHC4T, keep in mind:

    • A pin name may refer to a gang.
    • Depending on the DPS-set, different current ranges can be active.
    • All connected channels, except those that are unganged, participate in the measurement.
    • Static current measurements are supported for the connect states norm (normal), and ungang (unganged).
    • For hdig norm_hdig, and himp connect states (sampler/digitizer, normal with sampler/digitizer, high impedance), current measurements are not supported.
    • For static measurements the UHC4T has a special ungang connect state. In this state only those channels of a gang are connected, which are necessary to supply the device with the required current. You can use this connect state, for example, to detect a DUT board or device with shorts. For details on this "unganging" see UHC4T features.
  • Static voltage measurements

    In the connect states norm and himp (normal, high impedance), the master channel of a gang is used for static voltage measurements.

    In the connect states hdig and norm_hdig (sampler/digitizer, normal with sampler/digitizer) you can select the first sampler of a channel gang (master channel) or all connected samplers.

For static measurements refer also to PSLR, PSLR? - (Power Supply Level Ranges) and DPSPINS resources.

Dynamic measurement

To set up dynamic measurements you can use the Pattern Tools. The setup is similar to Pin Scale digital card measurements.

Dynamic measurements are supported for the connect states norm, himp, hdig, and norm_hdig. There is a special "ungang" mode for dynamic measurements which switches to precision mode (see UHC4T power modes). You can use this "unganging" to improve accuracy for current measurements.

  • Dynamic current measurements
    • For hdig and himp connect states, current measurements are not supported.
  • Dynamic voltage measurements
    • For norm and himp connect states the master channel of a gang is used.
    • For hdig and norm_hdig connect states you can select the master channel or all connected channels. In a second step you can select the results of any single channel.
