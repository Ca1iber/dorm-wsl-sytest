Test program template files

Subtopics

  1. Test suite table of a TPT
  2. Bin table of a TPT
  3. Test table of a TPT
  4. Test parameter table of a TPT
  5. Test flag table of a TPT
  6. Test stage table of a TPT
  7. OpenOffice spreadsheet for editing the CSV files

A test program template contains a number of CSV tables that specify various aspects of the template in an easy-to-edit tabular format:

  • Test suite table
  • Bin table
  • Test table
  • Test parameter table
  • Test flag table
  • Test stage table

While all these tables can be edited with text editors, we recommend using the OpenOffice spreadsheet that is also part of the test program template: OpenOffice spreadsheet for editing the CSV files

Functional changes

  1. Introduced in SmarTest 7.0.4
  2. SmarTest 7.2.1: Added test table, test parameter table, and test stage table.
  3. SmarTest 7.2.1: Removed test type table and release management table.
