d2s expectValue

The d2s expectValue method uses the read-template to compare read values to a expected value resulting in a pass or fail.

This is done by comparing the read value with expected value without using the error map.

Thus the expectValue method cannot be combined with a regular read on the same port.

Note In order to get pass/fail results it has to be enabled per port by using .enablePassFailCheckForNextExecution() before the LABEL_BEGIN-LABEL_END block.

The results per port are queried using the hasPassed() method outside of the ON_FIRST_INVOCATION block.

Note All labels of the port are considered for the final pass/fail judgment!

Syntax

void expectValue(long long address, long long value, long long mask=0LL);
void enablePassFailCheckForNextExecution();
bool hasPassed(std::string id);
Parameters

I/O

Parameter

Description/Range

I

address

Defines the register's read address.

I

value

Defines the value the read date is compared to.

I

mask

Optional. Default = 0LL.

The expect value can be masked using a bit mask.

Note 1 is considered to be "do not care".

I

id

Name of the d2s_LABEL-block that is used for pass/fail judgment.

Examples

Explaining the expectValue method

Consider the method jtag.expectValue(0xdead, 0xb, 0xfff0);

Here the read address is 0xdead. The expected value is 0xb, which in binary is 0000 0000 0000 1011.

The applied mask is 0xfff0, which in binary is 1111 1111 1111 0000. As a binary 1 is considered "do not care", applying this mask means, that you are interested in the lower 4 bits only.

Example code

The following excerpt illustrates how the expectValue method is used to create static pattern that reads from the corresponding address and compares the read with the expected value.

In learning mode it will generate a expect value label, add it to the burst label MyBurstLabelName and execute the pattern at d2s_LABEL_END().

In production mode only the MyBurstLabelName pattern will be executed at d2s_LABEL_END().

virtual void run()
{
   d2sFramework fr;
   d2sJTAG& jtag = d2sJTAG::Instance();

   // Register your protocol with the framework
   fr.registerTransactionPort(jtag);

   ON_FIRST_INVOCATION_BEGIN();
      jtag.enablePassFailCheckForNextExecution();
      fr.d2s_LABEL_BEGIN("MyBurstLabelName", d2sFrameWorkModeType::LearningMode);
         jtag.write(0xdead, 0xbeaf);
         jtag.expectValue(0xdead, 0xbeaf);
         // masking the expect value
         jtag.expectValue(0xdead, 0xb, 0xfff0);
      fr.d2s_LABEL_END();

      // do your measurement here

   ON_FIRST_INVOCATION_END();

   if(jtag.hasPassed("MyBurstLabelName"))
      cerr << "Test has PASSED!";

}

The static patterns created by the code above for a single port setup would be saved into the device vector directory as:

d2s_jtag_AT_W_0xdead_0xbeaf, d2s_jtag_AT_EV_0xdead_0xbeaf and d2s_jtag_AT_EV_0xdead_0xb_0xfff0
