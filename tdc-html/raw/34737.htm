DRLFreeEvent

void DRLFreeEvent (DRLEventRec *event))

This function releases the memory allocated for event by the function DRLKeepEvent. DRLFreeEvent should always be called when the data stored with event is no longer used.

Return Value

None.

Functional changes

  1. Introduced before SmarTest 6.3.2
