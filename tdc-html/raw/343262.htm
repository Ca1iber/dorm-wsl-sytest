Fixture delay calibration

Each signal that an IO channel generates must travel through the DUT interface to the pogo pins and then through the wiring on the DUT board itself before it reaches the DUT pins. This path causes signal delays for which compensation must occur.

Fixture delay

The system-level calibration measures the assembly delay, that is, the signal delay between the pin electronics and the pogo pins on the test head. However, from the pogo pins up to the DUT pins, the signal is exposed to another delay due to the wiring of the DUT board. The delay from the pogo pins up to the DUT is called the "Fixture delay".

Fixture delay calibration

The Fixture Delay Tool provides you with the capability to measure the delay contributed by the DUT board wiring. After the delay is measured, compensation for the measured delay is automatically applied.

Measurement principle

The delay in the signal path between a specific pogo pin and the corresponding pin at the device socket is measured using time domain reflectometry (TDR). The DUT is removed during the fixture delay measurement and the Fixture Delay tool recognizes the open device pin as the end of the signal path.

Note If a large impedance mismatch exists within the signal path, it is possible that the Fixture Delay tool measures the signal delay from the pogo pin to this point rather than the complete path to the device socket. This condition can occur when an active device such as a relay exists in the signal path.
