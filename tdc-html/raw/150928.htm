Topic 150928

format()

This function specifies a data format in a digital capture test.

Syntax

format(enum format);
List of parameters

Parameter

Description

format

A data format to be used in a digital capture test.

The data format can be one of:

BIN, COMP1, COMP2, MOD_COMP1, SYMM, MOD_SYMM, GRAY, BCD, ALAW, MOD_ALAW, and MSB.

For more information about the format definition, see Code Format Tables.

Example

RDI_BEGIN()  
rdi.digCap("id1").pin("pinA").format(TA::COMP).samples(1024).bitPerWord(16).execute();
rdi.digCap("id2").pin("GroupB").format(TA::GRAY).capMode(TA::PAR).samples(1000).execute();
RDI_END();
rdi.id("id1").getVector();
rdi.id("id2").getVector();
