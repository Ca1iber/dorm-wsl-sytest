JSUD - (Jitter Set UnDefine)

JSUD deletes a jitter set.

Syntax

JSUD {"js_set_name"|ALL}

Parameters

js_set_name

Specifies the name of an existing jitter set.

ALL

This option removes all defined jitter sets.

Application

Jitter test.

Errors

An error is generated if no jitter set with this name exists.

Example

> JSUD   "js_set1"

Functional changes

  1. Introduced in SmarTest 7.0.1
