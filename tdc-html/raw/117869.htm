GDDR5 training configuration file

The GDDR5 training file contains default values for the various test methods involved in GDDR5 training. It also contains some additional settings.

Default and specific configuration files

The default GDDR5 training configuration file is named .GDDR5Training.cfg and is located in the testflow subdirectory of the device directory.

Instead of using this default configuration file in a testflow, you can also use the LoadConfig test method to specify a different configuration file.

The GDDR5 training uses settings in this order:

  1. If a parameter has been specified in the specific test method (for example, Address Training), that parameter is used.
  2. If a parameter has not been specified in the test method, the default specified in the loaded configuration file is used.

    If a file was specified using the LoadConfig test emthod, that file is used. Otherwise, the standard configuration file .GDDR5Training.cfg configuration file in the testflow directory is loaded.

  3. If the parameter is not specified in the loaded configuration file, a default hardcoded into the test method is used. You can find a list of defaults in the configuration file solution_tools/sh_lib/.GDDR5Training.cfg.

Syntax

The syntax of a GDDR5 training configuration file is simple: Each parameter is specified on one line in the file in the form:

<name> = <value>

<name> is the name of the parameter as given in the table below; <value> is the assigned value. Do not enclose values in quotes.

Comments can be added by starting a line with a # character.

Note For an explanation of the notation used to describe the syntax, see Syntax conventions.

These are the supported parameters:

Parameter

Description

ADDRESS_PIN_GROUP

The default value for the Address Pin Group parameter of the Address Training test method.

ABI_PIN_GROUP

The default value for the ABI Pin Group parameter of the Address Bus Inversion Training test method.

CLOCK_PIN_GROUP

The default value for the Clock Pin Group parameter of the Clock Training test method.

EDC_PIN_GROUP

The default value for the EDC Pin Group parameter of the Clock Training test method.

DATA_INPUT_PIN_GROUP

The default value for the Data Input Pin Group parameter of the Write Training test method.

AddressTraining.DATA_OUTPUT_PIN_GROUP

The default value for the Data Output Pin Group parameter of the Address Training test method.

AddressTraining.OPTIMIZATION

How the address training results are determined for multisite training:

  • NONE: There is no optimization. Training is performed on each site individually in parallel. If two sites share a driver, training is erformed on only one of these sites and results are copied to the other.
  • EXEC_ONE_COPY_TO_REST: Training is performed on only one site and the results are copied for all other sites.

This setting has no effect for single-site training.

The default value is NONE.

ABITraining.DATA_OUTPUT_PIN_GROUP

The default value for the Data Output Pin Group parameter of the Address Bus Inversion Training test method.

ABITraining.OPTIMIZATION

How the ABI training results are determined for multisite training. For details, see AddressTraining.OPTIMIZATION above.

ReadTraining.DATA_OUTPUT_PIN_GROUP

The default value for the Data Output Pin Group parameter of the Read Training test method.

WriteTraining.DATA_OUTPUT_PIN_GROUP

The default value for the Data Output Pin Group parameter of the Write Training test method.

AddressTraining.SWEEP_SPEC_VARS

The default value for the SweepSpecVars parameter of the Address Training test method.

ABITraining.SWEEP_SPEC_VARS

The default value for the SweepSpecVars parameter of the Address Bus Inversion Training test method.

ClockTraining.SWEEP_SPEC_VARS

The default value for the SweepSpecVars parameter of the Clock Training test method.

ReadTraining.SWEEP_SPEC_VARS

The default value for the SweepSpecVars parameter of the Read Training test method.

WriteTraining.SWEEP_SPEC_VARS

The default value for the SweepSpecVars parameter of the Write Training test method.

AddressTraining.TARGET_SPEC_VARS

The default value for the TargetSpecVars parameter of the Address Training test method.

ABITraining.TARGET_SPEC_VARS

The default value for the TargetSpecVars parameter of the Address Bus Inversion Training test method.

ReadTraining.TARGET_SPEC_VARS

The default value for the TargetSpecVars parameter of the Read Training test method.

WriteTraining.TARGET_SPEC_VARS

The default value for the TargetSpecVars parameter of the Write Training test method.

DEFAULT_MIN_OPEN_EYE_FRACTION

The default value for the MinOpenEye parameters of the various test methods.

The minimum open eye width is specified as a fraction of the device cycle time.

DEFAULT_ALIGN_ACCURACY_FRACTION

The default value for the AlignAccuracy parameters of the various test methods.

The align accuracy is specified as a fraction of the device cycle time.

AddressTraining.DEFAULT_PORT

The default value for the DefaultPort parameter of the Address Training test method.

ABITraining.DEFAULT_PORT

The default value for the DefaultPort parameter of the Address Bus Inversion Training test method.

ClockTraining.DEFAULT_PORT

The default value for the DefaultPort parameter of the Clock Training test method.

ReadTraining.DEFAULT_PORT

The default value for the DefaultPort parameter of the Read Training test method.

WriteTraining.DEFAULT_PORT

The default value for the DefaultPort parameter of the Write Training test method.

RIGHT_EDGESEARCH_OFFSET_FRACTION

The distance from the left edge at which the search for the right edge begins.

The distance is specified as a fraction of the device cycle time.

SCAN_START_MARGIN

The number of steps that are added to the first pass point to begin the search for the transition point. (The step size is specified in the MinOpenEye parameter.)

The algorithm starts from point a and scans until it finds a pass point b. It then adds SCAN_START_MARGIN to b to calculate where to start scanning back towards a to find the transition point. So, the algorithm first scans from a to b and then from (b + SCAN_START_MARGIN) back towards a.

This parameter is ignored when fast training is chosen.

INITIAL_WCK_DEFAULT_TIMING

The default timing value for the initial early/late identification functional test in a transition search.

This value is used when no SweepStart is specified for the clock training.

PASS_STRING

This is a string that s output to the report window in case of a pass.

FAIL_STRING

This is a string that s output to the report window in case of a fail.

Example

# GDDR5 Training Config File

# Address Pin Group
ADDRESS_PIN_GROUP = MA0_Pin; MA1_Pin; MA2_Pin; MA3_Pin; MA4_Pin; MA5_Pin;
                                                   MA6_Pin; MA7_Pin; MA8_Pin

# Clock Pin Group
CLOCK_PIN_GROUP = WCK01_Bus; WCK23_Bus

# EDC Pin Group
EDC_PIN_GROUP = EDC0_Pin, EDC1_Pin; EDC2_Pin, EDC3_Pin
