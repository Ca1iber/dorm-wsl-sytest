RCLS? - (ReCeive Level Sensitivity)

The RCLS? (ReCeive Level Sensitivity) query measures the threshold levels at the receiver for the specified output pins.

Syntax

RCLS? {test}, {pass_value}, [limit], {(pinlist)}

returns: 

RCLS {value_specifier}, {result_value}

Parameters

test

This parameter is one of the following:

H

to determine the high level threshold for the DUT output pins.

L

to determine the low level threshold for the DUT output pins.

pass_value

The pass_value parameter defines the expected pass value (in mV) for the threshold measurement.

pass_value must be in the range of the comparator threshold level in the channel board (see RCLV, RCLV? - (ReCeive LeVel)).

limit

The limit parameter specifies the limit (in mV) of the measurement window for value measurements. The range for this parameter is as follows:

  • If you want to determine the high level threshold, the value entered must be between the maximum comparator threshold level of the channel board (see RCLV, RCLV? - (ReCeive LeVel)) and the specified pass value
  • If you want to determine the low level threshold, the value entered must be between the pass value and the minimum comparator threshold level of the channel board.

If a pass/fail test is to be performed, this parameter must be omitted. For both high and low level threshold measurements, the search is performed by varying the comparator threshold from the limit you specify, to the hardware limit.

pinlist

The name of the pin or pins to be tested. This parameter may also include groups previously created using the DFGP command. If more than one pin is to be included, the names must be separated with a comma. pinlist must only contain pins configured as outputs.

value_specifier

This parameter contains one of the following:

LT

(less than) is returned after a high level test to indicate that the first functional test (performed at the value defined by the limit parameter) failed. LT is only returned after a value test.

LE

(less than or equal to) is returned, after a low level test, if all the tests carried out within the window pass. LE is only returned during value measurements.

EQ

Equal to is returned if the first failure of the level test occurs within the measurement window. EQ is only returned after a value measurement.

GE

(greater than or equal to) is returned, after a high level test, if all the tests carried out within the window pass. GE is only returned after a value measurement.

GT

(greater than) is returned after a low level test to indicate that the first functional test (performed at the value defined by the limit parameter) failed. GT is only returned after a value test.

P

A P is returned if the functional test passes. A P can only be returned if the limit parameter has been omitted.

F

An F is returned if the functional test fails. An F can only be returned if the limit parameter has been omitted.

result_value

The result value is the level (in mV) of the last passed test.

Application

AC tests.

Errors

An error is generated if:

  • You set the pass value below the receiver minimum allowed level as stated in the specifications.
  • You set the pass value above the receiver maximum allowed level as stated in the specifications.
  • You set the pass value below the limit value for a low level measurement.
  • You set the pass value above the limit value for a high level measurement.
  • The test was not performed because the programmed voltage level could not be reached.

Example

RCLS? H,3000,6000,(Q0)

returns: 

RCLS EQ,5300

In this example a search was made to find the high level threshold between 3V and 6V. The pass/fail transition was located at 5.3V.

Functional changes

  1. Introduced before SmarTest 6.3.2
