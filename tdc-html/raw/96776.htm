GetTestBoardInfoByID

This data query command gets the information of the test board which is installed in V93000 test head with the specified test board ID.

SUCCESS will be returned if the command is successfully issued. An error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

ILLEGAL_OPERATION
  • The designated session ID "XXX" is not online session ID.
  • The designated board ID "XXX" does not exist.

RECOVERABLE

Dependency

An online smartest session is running.

Parameters

I/O

Parameters

Description

I

SESSION_ID

The ID of the online SmarTest session.

I

BOARD_ID

The ID of the test board to query.

O

qrResults

The query results are represented by a ParamList object. It contains the following members:

  • BOARD_TYPE: The test board type. It can be CHANNEL_BOARD, DPS_BOARD, CLOCK_BOARD, CONTROL_BOARD.
  • SLOT: The pogo block number of the test board.
  • PART_NUMBER: The part number of the test board.
  • SERIAL_NUMBER: The serial number of the test board.
  • VENDOR: The vendor information of the test board.
  • VERSION: The version information of the test board.
  • REPAIR: How many times the test board has been repaired.
  • FPGAREVS: The whole FPGA revisions on a board. The FPGA revision is presented by a hexadecimal number which begins with "0x". The whole FPGA revisons string may have a maximum of 8 FPGA revisions separated by ",".
  • HW_TYPE: The hardware type.

For channel board, it can be C, CE, or P.

For DPS board, it can be DCS-UHC4T or DCS-DPS128.

  • MAX_SPEED: (Only for channel board) The maximal speed of the board.
  • MODULE_ID_LIST: The ID list for the test modules in the board. This is not available for RF board.
  • PHY_LOCATION: The physical location of the board. It is in the format TCSS:

    T: The test head number. It is always 1 for 93000.

    C: The card cage number. It can be an integer from 1 to 8.

    SS: The slot number in the card cage. It can be a two-digit interger from 00 to 14.

Prototype

ParamList qrParams, qrResults;
string sessionId;
Status query("GetTestBoardInfoByID", qrResults,  qrParams, sessionId);

Example

ParamList qrResults, qrParams;
string sid;
qrParams ["BOARD_ID"] = "IID_1" /* value from GetTestHeadInfoByID */
query("GetTestBoardInfoByID", qrResults, qrParams, sid);
printf("the information for the test board BID_1 is:\n");
printf("  <BOARD_TYPE>: %s\n", qrResults ["BOARD_TYPE"]);
printf("  <SLOT>: %s\n", qrResults ["SLOT"]);
printf("  <PART_NUMBER>: %s\n", qrResults ["PART_NUMBER");
printf("  <SERIAL_NUMBER>: %s\n", qrResults ["SERIAL_NUMBER"]);
printf("  <VENDOR>: %s\n", qrResults ["VENDOR"]);
printf("  <VERSION>: %s\n", qrResults ["VERSION"]);
printf("  <REPAIR>: %s\n", qrResults ["REPAIR"]);
printf("  <FPGAREVS>: %s\n", qrResults ["FPGAREVS"]);
printf("  <PHY_LOCATION>: %s\n", qrResults ["PHY_LOCATION"]);
string boardType =  qrResults ["BOARD_TYPE"];
if ( boardType == "CHANNEL_BOARD")
{
printf("  this board is a channel board, its detail:\n");
printf("     <HW_TYPE>: %s\n", qrResults["HW_TYPE"]);
printf("     <MAX_SPEED>: %s\n", qrResults["MAX_SPEED"]);
printf("     <MODULE_ID_LIST>: %s\n", qrResults["MODULE_ID_LIST"]);
vector<string> midList = qrResults.valueArray("ODULE_ID_LIST");
foreach mid in midList{
printf("     %s\n",", mid);
}
