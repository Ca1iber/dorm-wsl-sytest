Data related signals level configuration

Subtopics

  1. Setting up the data signals

Due to bidirectional single-ended data pins on the memory device side a dual transmission line setup (also called "flyby connection") is implemented on the test system side (see following figure).

WRITE: High level in drive situation with vih_T.

WRITE: Low level in drive situation with vil_T.

READ: Termination in receive situation with vt_T.

This causes an impact on the level configuration for the DQi signals and some dedicated memory device features like ODT (On-Die-Termination) as described in the following section.
