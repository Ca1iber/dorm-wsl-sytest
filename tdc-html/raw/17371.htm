Changing the Specification Set Number

  1. Click Change Spec Set in the Change pulldown menu.

    A screen similar to that of the figure below appears.

  2. Highlight the specification set whose number you want to change.
  3. Key in a new number in the New Spec Set # edit field.
  4. Click assign.
  5. Repeat these last steps as often as required (for other specification sets), and click done when finished.

Functional changes

  1. Introduced before SmarTest 6.3.2
