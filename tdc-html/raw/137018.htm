Topic 137018

PS1600 used for mixed-signal testing

Subtopics

  1. How to use PPMU as Arbitrary Waveform Generator (AWG)
  2. How to use the BADC as digitizer
  3. How to use PPMU as AWG and BADC as digitizer together

Pin Scale 1600 card can support low-cost mixed-signal test.

Mixed-signal testing capabilities of the PS1600 card:

  • The PPMU and BADC of it can be used as sequencer‑controlled DC instruments
  • The PPMU of PS1600 can work as Arbitrary Waveform Generator (AWG)
  • The BADC of PS1600 can work as Digitizer
Note Be aware that crosstalk might occur in neighboring channels of the PS1600 when its PPMU is used to:
  • Generate a fast waveform (PPMU used as an AWG)
  • Measure a DC value using successive approximation
