DSP_SUM

The DSP_SUM API sums up the elements of an array.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_SUM(ARRAY_D& src, DOUBLE& result);
DSP_SUM(ARRAY_I& src, INT& result);
DSP_SUM(ARRAY_COMPLEX& src, COMPLEX& result);

DSP_SUM(DOUBLE * src, INT size, DOUBLE& result);
DSP_SUM(INT * src, INT size, INT& result);
DSP_SUM(COMPLEX * src, INT size, COMPLEX& result);
Parameters

I/O

Parameter

Description/Range

I

src

Source array

1 ≤ size ≤ 2097152

 

O

result

Sum of all elements of the src array

 

I

size

Number of elements of the src array

1 ≤ size ≤ 2097152

Example

ARRAY_D data(10);
DOUBLE data_sum;

for (DOUBLE j=0.0; j < 10.0; j=j+1.0)
data[j]=j;
...
DSP_SUM(data, &data_sum);

The example sums up the elements of the data array and gets the result 45.

Functional changes

  1. Introduced in SmarTest 6.5.2
