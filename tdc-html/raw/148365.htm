Topic 148365

Comparing data log files

This task explains how to generate an HTML report that shows the difference between two data log (STDF or EDL) files.

About this task

The following screenshot illustrates the layout of the Compare Data Log Files tab.

Compare Data Log Files can help you find and view the differences between two data log (STDF or EDL) files.

The input requires two data log files.

The output is a hierarchical, multitiered HTML report that shows differences in test results, bin summaries, wafer map, and so on.

Before you begin

Make sure:

  • You use the "S&S_TP360_Plus_SOC" license.
  • You have two valid data log (EDL or STDF) files.

Procedure

  1. Open TP360 and launch Test Program Browser from the App Center tab.
  2. Select the Compare Data Log Files tab, then click the icon or double-click the words in the select data log (EDL or STDF) files for comparison row.

    A new window opens, in which you can select two data log files:

  3. (Optional) Click the icon or double-click the words in the specify one of above selections as reference row.

    A new window opens, in which you can specify the reference data log.

    Note If this procedure is skipped, the first one of the selected data log files is set as the reference.
  4. (Optional) If the test suite name or test name of the same test items between the two data log files is different, you must complete the following additional steps:
    1. Click the Generate Name Mapping File button.
    2. Modify the generated Name mapping file name_mapping.xls to create all the test item mappings.
    3. Specify the modified name mapping file in the Specify name mapping file for comparison row.
  5. (Optional) Click the icon to open the Preference page on Compare Datalog Files to configure the comparison data log report.
  6. Click the Compare Data log Files button to execute the comparison report generation process.

Results

The HTML report is displayed in the Data log Comparison Report view. By default, it is generated in the directory:

/tmp/.vda/username/datalog_utilities/tmp/TP360_Datalog_CMP_Report/

You can save the report to a different directory by clicking the icon in the report view.

You can refer to Viewing the comparison datalog report for a detailed explanation of the report.
