getMultiValue()

Retrieves all the values measured on a specified pin.

You can use it with dynamic DC tests, which can be referenced from label() and insertVec() topics.

The getMultiValue() function can be used to

  • get all DC results of one .execute() used in conjunction with insertVec() or insertSub().
  • get all DC results of one .execute() used in conjunction with sublabel() + insertVec() according to the size defined by the user with resultSize().

    In case of a match failure that prevents the following measurements from executing, getMultiValue() does not resize the result array dependent on the non-executed measurements.

    It cannot return the DC results of a pin of a whole burst.

Syntax

ARRAY_D& getMultiValue(const string& pin);
ARRAY_D& getMultiValue();
Parameter

Parameter

Description

pin

The pin whose measured values to be retrieved.

If no pin is specified, the first pin (decided by pin name) will be used by default.

Return Value

Returns an array storing the measured values.

Example

Retrieving the measured voltages on pinB in a dynamic DC test.

RDI_BEGIN();
  rdi.dc("dynamic").label("label")
                   .pin("pinA")
                     .insertVec(55).vForce(5)
                     .insertVec(90).vForce(3) // here, the line number cannot be lower than 87.
                   .pin("pinB")
                     .insertVec(65). vMeas()
                     .insertVec(185).vMeas() // here, the line number cannot be lower than 97.
                   .execute();
RDI_END();

double value = rdi.id("dynamic").getValue("pinB"); // only the last measurement result

ARRAY_D values = rdi.id("dynamic").getMultiValue("pinB"); // multiple results
If you retrieve all values from several pins, use this function for each pin as follows: 
...
ARRAY_D value1 = rdi.id("id1").getMultiValue("pinA");
ARRAY_D value2 = rdi.id("id1").getMultiValue("pinB");
ARRAY_D value3 = rdi.id("id2").getMultiValue("pinC");
ARRAY_D value4 = rdi.id("id2").getMultiValue("pinD");
