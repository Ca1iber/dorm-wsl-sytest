Topic 16269

Editing technology data

About this task

The hidden .technology file in the root folder of the device defines three basic types of information:

  • The source directory for technology-related settings.
  • Maximum values for certain system parameters.
  • Target test system model for pay-per-use applications.

This task changes the content of the .technology file.

Note Changing the .technology file may lead to problems when loading setup data or executing tests. Technology data specifies allocation of tester resources. If such specification does not match the device's needs, the device cannot be edited or tested later on.

Before you begin

Make sure that the device project exists.

Procedure

  1. On the V93000 menu icon bar click the Change Device button or select menu 93000 > Device > Change Device. The Change Device wizard opens.
  2. In this wizard, enter the name and the full path of the device project in the Device text box. Then click Next.
  3. The Edit Device page of the wizard appears. Enter your changes here.

    All values entered in the Edit Device page are written to the .technology file of the selected device. Refer to rows "Change Device wizard" of table Parameters of the .technology file in Technology file for a device for the relationship between the fields of the Edit Device page and the .technology file.

    Some hints for editing the technology data:

    • In the Device technology field, type in the technology 'family' to which your device belongs. Device Technology Defaults explains more about device technology defaults.

      Default levels are defined by the selected device technology. These default levels can be customized to meet the needs of your device. For more information, refer to Default levels file for a device.

    • In the Licensing file field, enter the name of The device license file.
    • Enter the maximum values for certain system parameters. These values determine the amount of memory reserved for the respective data structures. The detailed description of the parameters is in the topic Technology file for a device.
    • Select Preinitialize vector memory to value and enter an initialization value field to reinitialize the vector memory to the specified value (supported range: 0 to 255).
    • Select the RFI to RFE compatibility mode checkbox, if the RFI (RF Interface) board is restricted to the RFE (RF Front End) card.
    • Select the Pretty-printed analog control file checkbox, to format the XML code in the analog control file.
    • Choose the appropriate Utility block size (16 or 32 utility lines per pogo block) for your test system setup. For further details on this parameter see Technology file for a device.
    • Selecting the Optimized Multiport Memory Allocation checkbox will switch to an improved pattern loading algorithm by which the vector memory will (nearly) be used to full capacity. This may help if not all patterns of a multiport setup can be loaded. Note however that it may possibly prolong the test time.
  4. Click Finish.

Results

The values entered during this task are written to the .technology file of the selected device.
