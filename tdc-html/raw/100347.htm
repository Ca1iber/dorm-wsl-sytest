Synchronization between the Flow Data Editor and the Flow Sequence Editor

The Flow Data Editor automatically keeps the test suite in focus synchronized with the Flow Sequence Editor, and vice versa. Also, the pages of the Flow Data Editor are automatically synchronized with each other.

Note If the alignment does not take effect, please check if you have set the two editors automatically synchronized. See Configuring the Testflow Tool.

Functional changes

  1. Introduced before SmarTest 6.3.2
