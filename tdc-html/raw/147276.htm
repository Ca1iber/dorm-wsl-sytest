DVM_PIN_TASK.setMeasurePoints()

The setMeasurePoints() member function sets the number of measurement points for the measurement.

Syntax

DVM_PIN_TASK & setMeasurePoints( const INT points, const double interval )
Parameters

Parameter

Description

points

The number of measurement points (default = 1).

interval

The interval between measurement points in seconds [s] (default = 1.0 s).

Return value

Returns a reference to the DVM_PIN_TASK object.

Example

See the example in DVM_TASK.
