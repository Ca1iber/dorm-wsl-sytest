Shmoo plot properties

Titles tab

Chart title: The title of the chart, displayed at the top.

X-Title: The label for the x-axis.

Y-Title: The label for the y-axis.

Classes tab

Displayed only when the shmoo plot shows fail count or (user-defined) value results.

Class Count: The number of value categories used in the shmoo plot.

Class: The color used for a value class; not editable.

Condition: Always > for the first class and <= for all others.

Fail Count: The upper limit of each value class. (The lower limit of a class is the upper limit of the next lower class. Definition: The colors and values used for the individual value classes.)

Value: The same as Fail Count; used when the shmoo plot displays values.

Cycles

Displayed only when the shmoo plot shows first failing cycles or vectors.

Cycle Count: The number of value categories used in the shmoo plot.
