UTILITY_SEQ_MODE

Subtopics

  1. UTILITY_SEQ_POGO_MODE
  2. UTILITY_SEQ_MODE.pogoBlock()
  3. UTILITY_SEQ_MODE.wait()
  4. UTILITY_SEQ_MODE.execute()

Sets the sequencer‑controlled mode of the utility blocks.

The object of UTILITY_SEQ_MODE can be added to a TASK_LIST.

Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/UtilitySequencerMode.h.

Constructor
UTILITY_SEQ_MODE();
List of parameters
The constructor has no parameters.
Return value
The constructor has no return value.
Member functions
  • UTILITY_SEQ_MODE.pogoBlock()
  • UTILITY_SEQ_POGO_MODE.mode()
  • UTILITY_SEQ_MODE.wait()
  • UTILITY_SEQ_MODE.execute()

Example

UTILITY_SEQ_MODE utiSeqModeOn, utiSeqModeOff;

ON_FIRST_INVOCATION_BEGIN();

    //
    // Set utility block 1      in RW mode and
    // set utility block 2 to 5 in RD mode
    //
    utiSeqModeOn.pogoBlock(1).mode(TM::SEQ_POGO_MODE_RW );
    utiSeqModeOn.pogoBlock(2,5).mode(TM::SEQ_POGO_MODE_RD ); 
    utiSeqModeOn.execute();

    FUNCTIONAL_TEST();

    //
    // Disable the sequencer‑controlled mode of all utility blocks
    //
    utiSeqModeOff.pogoBlock().mode(TM::SEQ_POGO_MODE_OFF);
    utiSeqModeOff.execute();

ON_FIRST_INVOCATION_END();
