EVENT_WAVEFORM_VFVM.clearVForceCheck()

Clears the error ranges of forced voltages.

For channel cards supporting in-place limit checks you can specify an error range, which is used to validate that the forced voltages of the waveform steps have reached their end value. So this defines limit curves for the force waveform steps.

Syntax

void clearVForceCheck();

List of parameters

There are no parameters.

Return value

There is no return value.

Example

For an example see EVENT_WAVEFORM_VFVM.
