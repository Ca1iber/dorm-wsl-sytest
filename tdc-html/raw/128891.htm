How to make your snippet file imported automatically

The system-provided test method snippets are automatically imported. You can also make you own snippets imported automatically through some configuration.

Before you begin

In the following procedure, it is assumed that your own snippet file is /home/demo/template_example.xml.

Procedure

  1. Insert the whole path of your snippet file into the file /opt/hp93000/soc/segments/eclipse/custom/eclipse/plugins/com.verigy.custom.testmethod_snippet/plugin.xml. The content of plugin.xml looks like: 
    <xml version ="1.0"encoding="UTF-8"?>
<?eclipse version="3.4"?>
<plugin>
  <extension
    point="com.verigy.utm.edtior.testmethod_snippet">
    <include
      file="/home/demo/template_example.xml">
    <include>
  <extension>
</plugin>
  2. Update the version information in file /opt/hp93000/soc/segments/eclipse/custom/eclipse/plugins/com.verigy.custom.testmethod_snippet/META-INF/MANIFEST.MF. The content of MANIFEST.MF looks like below. Update the Bundle-Version when plugin.xml is changed. 
    Manifest-Version: 1.0
Bundle-ManifestVersion: 2
Bundle-Name: Testmethod_snippet
Bundle-SymbolicName: com.verigy.custom.testmethod_snippet;singleton:=true
Bundle-Version: 1.1.0
Bundle-Vendor: VERIGY
Bundle-RequiredExecutionEnvironment: JavaSE-1.6
Require-Bundle: com.verigy.itee.utm.editor
  3. Change the directory name of the plugin.xml file according to the bundle version information specified in the MANIFEST.MF file. If the bundle version is 1.1.0, the directory name com.verigy.custom.testmethod_snippet needs be changed to com.verigy.custom.testmethod_snippet_1.1.0.

Results

Your snippet file will be imported automatically when the EWC is launched.
