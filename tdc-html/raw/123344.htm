DC test methods (multi_group_dc_tml)

The following DC Test Methods are included in the system test method library:

  • Continuity - checks for connectivity and short circuits on the DUT and the DUT interface.
  • DpsConnectivity - checks that the force and sense wires of the DPS are connected properly on the DUT board.
  • Dpstatus - provides status information about DPS pins.
  • GeneralPMU - allows direct control of the Pin PMU, DCScale pin in PPMU mode and board ADC to force a voltage (and measure current) or force a current (and measure voltage).
  • Leakage - measures the leakage current on DUT pins.
  • OperatingCurrent - measures the active operating current of the DUT.
  • OutputDC - measures the output voltage of the DUT under specific current load conditions.
  • ProductionIddq - measures the quiescent power supply current of the DUT.

Comparing with the DC test methods (dc_tml) provided earlier, this set of test methods support different parameter and limit settings for different pins/pin groups. The source files of the DC test methods are included in the file /opt/hp93000/soc/testmethod/library/multi_group_dc_tml.zip.
