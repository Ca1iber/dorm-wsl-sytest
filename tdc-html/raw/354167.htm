XPS256 status flags

The XPS256 card features several mechanisms for the self-protection of the card and for indicating the operating state, unusual operating conditions or test results.

Available XPS256 status flags:
  • Status flags and warnings
    • Clamp distance too low
    • High voltage or current of surge tracker exceeded
    • High voltage of surge tracker reached
    • High current of surge tracker reached
    • Low voltage or current of surge tracker exceeded
    • Low voltage of surge tracker reached
    • Low current of surge tracker reached
    • Measurement range change failed
    • Range overflow
    • Voltage drop force warning
    • Voltage drop return warning
  • Operating state
    • Constant current
    • Constant voltage
  • Safety and self-protection
    • Current limit disconnect
    • DUT board disconnect
    • Overpower / Overcurrent / Power budget exceeded
    • Overtemperature
    • Overvoltage
    • Safety line
    • Unregulated
    • Voltage drop force
    • Voltage drop return

Status flags and warnings

Several flags indicate the state of the XPS256 surge tracker or indicate the occurrence other warnings. For more information refer to DPS status flags - get...() functions, DPS power flags - get...() functions or DPS_AUX_TASK.getSurgeTrackerStatus().

Flag Description
Clamp distance too low Trigger:

The programmed distance between the upper and lower clamp voltage or between the sourcing and sinking clamp current is too low.

The flag is set if the clamp distance is continuously too small for a period of more than 400 μs.
Action:

The applied clamp values are adapted to the minimum clamp distance that is defined be the programmed hardware.

A warning is shown in the UI report window.

Note: In most cases, the flag will be set only if the violation of the minimum clamp distance is caused by DC events in a pattern.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getClampDistanceTooLow()
High voltage or current of surge tracker exceeded Trigger:

The XPS256 surge tracker has detected a voltage or current above the user defined upper limit.

Since the XPS256 surge tracker can simultaneously monitor the voltage and the current, this flag is always set in combination with one or both of the flags High voltage of surge tracker reached or High current of surge tracker reached.
Action: The hardware settings are not changed. The flag represents the test result of the surge tracker.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getSurgeTrackerStatus()
High voltage of surge tracker reached Trigger:

The XPS256 surge tracker has detected a voltage above the user defined upper limit.

This flag is always set in combination with flag High voltage or current of surge tracker exceeded.
Action: The hardware settings are not changed. The flag represents the test result of the surge tracker.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getSurgeTrackerStatus()
High current of surge tracker reached Trigger:

The XPS256 surge tracker has detected a current above the user defined upper limit.

This flag is always set in combination with flag High voltage or current of surge tracker exceeded.
Action: The hardware settings are not changed. The flag represents the test result of the surge tracker.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getSurgeTrackerStatus()
Low voltage or current of surge tracker exceeded Trigger:

The XPS256 surge tracker has detected a voltage or current below the user defined lower limit.

Since the XPS256 surge tracker can simultaneously monitor the voltage and the current, this flag is always set in combination with one of both of the flags Low voltage of surge tracker reached or Low current of surge tracker reached.
Action: The hardware settings are not changed. The flag represents the test result of the surge tracker.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getSurgeTrackerStatus()
Low voltage of surge tracker reached Trigger:

The XPS256 surge tracker has detected a voltage below the user defined lower limit.

This flag is always set in combination with flag Low voltage or current of surge tracker exceeded.
Action: The hardware settings are not changed. The flag represents the test result of the surge tracker.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getSurgeTrackerStatus()
Low current of surge tracker reached Trigger:

The XPS256 surge tracker has detected a current below the user defined lower limit.

This flag is always set in combination with flag Low voltage or current of surge tracker exceeded.
Action: The hardware settings are not changed. The flag represents the test result of the surge tracker.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getSurgeTrackerStatus()
Measurement range change failed Trigger: Automatic down‑ranging in DC measurement cannot set the target current measurement range.
Action: A warning is shown in the UI report window.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getRangeError()
Range overflow Trigger:

An overflow of the force range or the clamp range has been detected.

The flag is also set for comparator range overflows if the related measurement range is determined by the force or clamp range.
Action:

The applied value is limited to the maximum range specific value.

A warning is shown in the UI report window.
Availability: The flag is available per channel.
APIs: DPS_AUX_TASK.getRangeOverflow()
Voltage drop force warning Trigger:

The measured voltage drop on the force line (P#) exceeds the programmed warning threshold.

Default threshold for the force line is 150 mV.

For the DPS operating mode, see warn_voltage_drop_force in DPSPINS resources.

For the PMU operating mode, see SPMU_PIN_TASK.forceDropWarn().
Action:

The flag is for information only.

You should query the flags at least at the end of the testflow.
Availability: The flag is available per channel.
APIs: DPS_AUX_TASK.getVoltageDropForceWarn()
Voltage drop return warning Trigger:

The measured voltage drop on the common return line (GND) referenced to the ground sense line (GS#) exceeds the programmed warning threshold.

Default threshold for the return line is 50 mV.

For the DPS operating mode, see warn_voltage_drop_return in DPSPINS resources.

For the PMU operating mode, see SPMU_PIN_TASK.returnDropWarn()
Action:

The flag is for information only.

You should query the flags at least at the end of the testflow.
Availability: The flag is available per channel.
APIs: DPS_AUX_TASK.getVoltageDropReturnWarn()

Operating state

Two flags indicate the operating state of the channels. These flags are for information only and no additional action is performed if the related state is detected. For more information refer to DPS power flags - get...() functions.

Flag Description
Constant current Trigger: The channel is in constant current operating mode and forces or clamps the current.
Action: The flag is for information only.
Availability: The flag is available per channel.
APIs: DPS_AUX_TASK.getConstantCurrent()

DPS_AUX_TASK.getStatusWithoutConstVol()

DPS_AUX_TASK.getAllStatus()
Constant voltage Trigger: The channel is in constant voltage operating mode and forces or clamps the voltage.
Action: The flag is for information only.
Availability: The flag is available per channel.
APIs: DPS_AUX_TASK.getConstantVoltage()

DPS_AUX_TASK.getStatusWithoutConstCur()

DPS_AUX_TASK.getAllStatus()

Safety and self-protection

The safety of the user, the DUT and DUT board, and the self-protection of the card require that actions are performed automatically by the control logic of the card or channels. These actions cannot be blocked or disabled. Some flags indicate these unusual operating conditions. For more information refer to DPS power flags - get...() functions.

Flag Description
Current limit disconnect Trigger:

The user defined time for constant current mode was reached.

For the DPS operating mode, DPSPINS resources parameter ms_const_curr_time_to_alarm defines the delay time for a pin that is in constant current mode without interruption before this flag is triggered. Parameter ms_const_curr_disconnect defines the delay time until the channel is disconnected. The parameter ms_const_curr_disconnect must be defined in the level setup to enable the disconnection in case the current limit is exceeded. Parameter disable_const_curr_check can be used to disable this status flag.

For the PMU operating mode, see SPMU_PIN_TASK.currentClampTimeToAlarm() and SPMU_PIN_TASK.currentClampTimeToDisconnect().
Action: The related channel or the entire ganging group is disconnected.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getConstantCurrentLimitDisconnect()
DUT board disconnect Trigger: The channel has received DUT board disconnect shutdown signal from an appropriately configured trigger source.
Action: All XPS256 channels are disconnected.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getDutBoardDisconnect()
Note: See also XPS256 programming - Safety line and DUT board disconnect.
Overpower / Overcurrent / Power budget exceeded Trigger:

An overpower or overcurrent condition has been detected.

The flag is triggered when the overcurrent condition has been detected for longer than 50 ms without interruption.
Action: The related channel is disconnected.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getOvercurrent()
Overtemperature Trigger: The temperature of the channel hardware is too high.
Action: The related channel is disconnected.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getOvertemperature()
Overvoltage Trigger:

The applied voltage exceeds the maximum voltage of the active voltage range.
Action: The channel is disconnected.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getOvervoltage()
Safety line Trigger: The channel has received Safety line shutdown signal from an appropriately configured and assigned trigger source.
Action: Only XPS256 channels assigned to the trigger source are disconnected.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getSafetyLine()
Note: See also XPS256 programming - Safety line and DUT board disconnect.
Unregulated Trigger:

The XPS256 channel is in an unregulated state.

The flag is triggered when the output stage is at its limits for longer than 10 ms without interruption.
Action: The channel is disconnected.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getUnregulated()
Voltage drop force Trigger:

The voltage drop on the force (P#) line on the DUT board exceeds the user defined limit.

Default threshold for the force line is 150 mV.

The flag is set if the threshold is exceeded without interruption for the time defined by the Vdrop Hold time parameter for the corresponding pin. Note that the Vdrop Hold time parameter can be set only in the DC Scale Safety editor. The time can be set separately for the force line and for the return line.

For XPS256 channels in DPS operating mode, see max_voltage_drop_force in DPSPINS resources.

For XPS256 channels in PMU operating mode, see SPMU_PIN_TASK.forceDropMax().
Action:

By default, the channel remains connected.

The channel is disconnected if the Vdrop Disco parameter is set to ON for the corresponding pin. Note that the Vdrop Disco parameter can be set only in the DC Scale Safety editor.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getVoltageDropForce()
Voltage drop return Trigger:

The voltage drop on the common return line (GND) on the DUT board exceeds the user defined limit.

Default threshold for the return line is 50 mV.

The flag is set if the threshold is exceeded without interruption for the time defined by the Vdrop Hold time parameter for the corresponding pin. Note that the Vdrop Hold time parameter can be set only in the DC Scale Safety editor. The time can be set separately for the force line and for the return line.

For XPS256 channels in DPS operating mode, see max_voltage_drop_return in DPSPINS resources.

For XPS256 channels in PMU operating mode, see SPMU_PIN_TASK.returnDropMax().
Action:

By default, the channel remains connected.

The channel is disconnected if the Vdrop Disco parameter is set to ON for the corresponding pin. Note that the Vdrop Disco parameter can be set only in the DC Scale Safety editor.
Availability: The flag is available per channel.
API: DPS_AUX_TASK.getVoltageDropReturn()

Enabling a channel after it has been disconnected

The procedure described below should be followed for channels that have been disconnected by the channel controller for reasons of safety or for the self-protection of the card:

  • Ensure that the reason for the disconnection has been eliminated.
  • The following actions are required in case a channel has been disconnected in the testflow:
    • Check the state of the flags using the APIs described in DPS power flags - get...() functions.
    • Disconnect the channel by SmarTest. The related error message will be shown in the report window and the status flags will be cleared.
    • Connect the channel.
  • The following actions are required in case a channel has been disconnected when working with the hardware view:
    • For a channel in the PMU operating mode: Start a dummy measurement in the ADC sub-panel with the relay action set to NT.
    • For a channel in the DPS operating mode: Click onto the Disconnect button in the toolbar of the Eclipse Work Center.
    • Disconnecting the channel will cause that the related error message is shown in the report window and will clear the status flags.
    • Connect the channel.

DC event status

The command TSST? - (TeSt STatus) returns global information about the DC event related results of the last executed test, and also provides the accumulated status information about all recorded measurements. A test point pattern must have been executed for DC Scale pins. The accumulated information is cleared at the begin of a functional test. The accumulated flags remain then valid until the begin of the next functional test.

TSST? returns a twofold reply. One informs about the test results, the other about the test status:

  • Test result flags:

    The functionality of some test result related flags can be enabled or disabled for specific measurement events using member functions of the DC events. Functions to enable or disabled the flags are for example

    • ...clampChecks()
    • ...outOfRangeCheck()

      The flags are cleared with the start of the next functional test.

  • Test status flags:

    The test status related flags cannot be enabled or disabled. These flags are accumulated for the complete functional test. The flags are cleared with the start of the next functional test.

DC Event test result flags supported by XPS256
Bit Flag Description
0 (LSB) Upper limit Set to 1 if all these conditions are true for at least one measurement:
  • A high limit is both specified and activated.
  • The measurement is not masked.
  • The measurement value was greater than the high limit.
1 Lower limit Set to 1 if all these conditions are true for at least one measurement:

  • A low limit is both specified and activated.

  • The measurement is not masked.

  • The measurement value was smaller than the low limit.
2 Global status Set to 1 if at least one of the bits 3, 4, 5, 6, 7, 9 is set to 1.
3 Low clamp violation Set to 1 if all these conditions are true for at least one measurement:
  • Checking low clamp violations is activated.
  • The measurement is not masked.
  • The low clamp was violated (status bit 0 is set to 1).
4 High clamp violation Set to 1 if all these conditions are true for at least one measurement:
  • Checking measurement ranges is activated.
  • The measurement is not masked.
  • An underflow occurred (status bit 4 is set to 1).
5 Range underflow Not supported
6 Range overflow Set to 1 if all these conditions are true for at least one measurement:
  • Checking measurement ranges is activated.
  • The measurement is not masked.
  • A range underflow or a range overflow occurred (status bit 5 is set to 1).

Note: XPS256 supports only one bit for indicating a range underflow or a range overflow.
7 Distance too small or internal buffer overflow Set to 1 if the distance between two consecutive test points (for example, between definition of the range and measurement) is too small, and measurements were interrupted.

The bit is also set to 1 in case too many commands were issued causing internal buffer overflow. This can happen if, for example, the minimum time for changing the force range is not respected.
8 Lost measurementstoBeChecked Set to 1 if not all measurement results were recorded because the test stopped earlier than expected.
9 Type mismatch Set to 1 if at least one measurement has been executed in a range that does not match the requested measurement type.
10 Wrong hardware state Set to 1 if the hardware switched into an unexpected state that caused the test to fail (for example, a disconnect for safety reasons).
DC Event test status flags supported by XPS256
Bit Flag Description
0 (LSB) Current sink limit is reached Set to 1 if current sink limit is reached (Clamp low) for at least one measurement.
1 Current source limit Set to 1 if current source limit is reached (Clamp high) for at least one measurement.
2 Clamp low was reached Set to 1 if clamp low was reached during the test for a DC Scale pin where no measurement was executed.
3 Clamp high was reached Set to 1 if clamp high was reached during the test for a DC Scale pin where no measurement was executed.
4 Range underflow Set to 1 in case of a range underflow has been detected for at least one measurement.
5 Range overflow Set to 1 in case of a range underflow or a range overflow has been detected for at least one measurement.
