STATEMAP section and pattern conversion

If the base wavetable of a pattern contains a STATEMAP section, b2a can convert a pattern (label) into an ASCII vector file using only the base wavetable. The main difference between this option and a standard call of b2a is that no testflow or *.bcf file may be specified. Instead, you must specify the name of the vector setup file (option -V), the pattern name (option -P), a timing setup file (option -t), and the base wavetable (option -w) as command line parameters. The global output name -o must also be specified in order to supply a name for the log file.

Note that when called in this way, b2a does not analyze any CTIM instructions in the sequencer program. It simply copies them into the generated *.avc file. This is in contrast to a standard call, for which see Basic Operation of b2a.

Note also that the selectors of the STATEMAP section (if present) will be used as the ASCII device cycle names in the generated *.avc file. This requires that the same selector must be used for all waveform DC/DC power units that occur in the same vector row.

Functional changes
