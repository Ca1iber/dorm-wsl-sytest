RCLK? - (Reference CLocK source)

The RCLK? (Reference CLocK source) query checks which reference clock is enabled, the external reference clock or the internal reference clock.

Syntax

RCLK?

returns: 

RCLK {clock_string}

Parameters

clock_string

The string shows which clock source is used as reference clock. Possible values are:

EXTERNAL

INTERNAL

Example

RCLK?

returns:

RCLK INTERNAL

Functional changes

  1. Introduced before SmarTest 6.3.2
