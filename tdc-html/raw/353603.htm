Installing software products

The smart-install-3 tool can be used to install SmarTest products available from the Advantest Software Center and packages that are already downloaded to your local system.

Before you begin

Make sue that you have installed the SmartInstall add-on required to install packages from the Software Center. For details, see Downloading and installing the SmartInstall add-on.

Installing a general release software package

To install a released software product available from the Software Center, enter the install command with the --switch-version option using the following structure. This command installs the SmarTest release version 8.3.3.1, which is then also ready for use directly after the installation:

/opt/ate/smart_install_3/smart-install-3 install smartest 8.3.3.1 --switch-version

If you do not include the --switch-version option, run the Switch version tool when the newly installed version is required.

Install with downgrade

To force the downgrade for single installations of a product on the workstation, use the --force-downgrade option.

testcellaccess, smartci_client, smartci_server are single installations.

This command installs the release 8.4.0.0 of Test Cell Access, if a later version was already installed:

/opt/ate/smart_install_3/smart-install-3 install testcellaccess 8.4.0.0 --force-downgrade

Install an rpm package from a local repository

To install a software product available from a local repository, enter the local-install command with the product rpm name using the following structure. This command installs the v93000-TP360-4.3.4.el7.x86_64.rpm package from the current directory (/home/johndoe/tmp/):

/opt/ate/smart_install_3/smart-install-3 local-install v93000-TP360-4.3.4.el7.x86_64.rpm

Run the Switch version tool when the newly installed version is required.

Install a tar.gz package from a local repository

To install a software product available from a local repository, enter the local-install command with the product tar.gz name using the following structure. This command installs the smartest_8.4.1.0_rhel7.tar.gz package from the current directory (/home/johndoe/tmp/):

/opt/ate/smart_install_3/smart-install-3 local-install smartest_8.4.1.0_rhel7.tar.gz

Run the Switch version tool when the newly installed version is required.

Install a product from a yum repository

To install a software product available from a local repository, enter the install command with the location of the yum-repository name using the following structure. This command installs the smartest 8.4.1.0 package from the yum repository file: /tmp/V93000TemporaryRepository815ed76bcf484a10/:

/opt/ate/smart_install_3/smart-install-3 --yum-repository file:/tmp/V93000TemporaryRepository815ed76bcf484a10/ install smartest 8.4.1.0

Results

You have learned how to install smart-install-3 from the Software Center and from local repositories.
