Changing Colors and Fonts

You can change the appearance, like colors or fonts, of the following views and elements:

  • Pattern debug tool
  • System and datalog console
  • Tables
  • Test program explorer

Example

To change colors or/and fonts of the test program explorer:

  1. In the short cut bar of the SmarTest Eclipse window select Window > Preferences....
  2. In the left pane of the Preferences window select General > Appearance > Colors and Fonts.
  3. In the center pane selectAdvantest V93000 > Test Program Explorer View.
  4. Choose one item under Test Program Explorer View, for example, Background color as shown in the example above.
  5. Click the button .

    A window with predefined colors and a color compose tool opens.

  6. Select a color or compose a color and click OK.
  7. In the Preferences window click Apply and then OK.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.0: Change the fonts of tables in SmarTest.
