Topic 137600

Setting up digital capture with STIL Reader

STIL Reader can convert STIL files to V93000 patterns that capture digital data from the DUT and store it for later analysis and processing.

About this task

This is done with the help of two custom STIL extensions, DCapFilter and DCapSetup, as well as the timing edge.

Create digital capture patterns if you want to use the DUT output for later analysis.

Before you begin

Make sure STIL Reader is installed.

Procedure

  1. Create a new, empty STIL file.

    You can create the file in Eclipse, in a suitable text editor, or in the STIL Reader window.

  2. Create a DCapSetup object to specify which pins will be used for the digital capture: 
    DCapSetup <setup_name> {
  Pins "<pin_names>";
}

    Replace <setup_name> with the name you want to give the setup and <pin_names> with the names of the pins from which you want to capture the digital data.

  3. If you want to capture two samples per test system cycle, specify digital_capture_res = double in the STIL Reader setup file.

    If you do not specify the digital_capture_res parameter or specify digital_capture_res = std, one sample will be taken per cycle.

  4. For each data set you want to capture, create one DCapFilter object: 
    DCapFilter <filter_name> {
  Type              Capture;               ## Currently always Capture
  TransferMode      <transfer_mode>;       ## Parallel or Serial
  FrameCount        <number_of_frames>;    ## Number of captured frames
  VectorsPerFrame   <vectors_per_frame>;   ## Number of data bits per pin per frame
  VectorsPerSample  <vectors_per_sample>;  ## Number of vectors per sample
  DiscardOffset     <offset>;              ## Number of vectors discarded at the start
  DiscardVectors    <discard_vectors>;     ## Number of skipped vectors between frames
  DiscardFrames     <discard_frames>;      ## Number of discarded frames at the beginning
}

    If desired, you can create multiple DCapFilter objects. These objects can capture data from the same pins or from different pins.

  5. Add the DCapSetup and DCapFilter objects to the PatternExec object: 
    PatternExec <object_name> {
  DCapSetup <setup_name>    ## Use the name from step 2
  DCapFilter <filter_name>  ## Use the name from step 4
}

    If you have created multiple DCapFilter objects in step 4, include one "DCapFilter" line for each of these objects. Specify the PatternBurst and the other parameters of the PatternExec block as required.

  6. If you want to perform selective capture, update the pin data to use the C edge where you want to capture the data.

    STIL Reader will mask all receive edges to avoid exceeding timing limitations of SmarTest.

    For example:

    Timing {
  WaveformTable t1 {
    Period '100ns';
    Waveforms {
      clk { P  { '0ns'  D; '50ns' D; } }
      data { 01 { '50ns' D/U;         } }
      data { H  { '10ns' Z; '50ns' C; } }
    }
  }
}
  7. Save the file.

Results

You have created a STIL file that can be converted to a test program for digital capture on the V93000 system.

Example

STIL 1.0 { Design D22; }

Header {
  Title "Digital Capture example";
}

Signals {
  clk In;
  data InOut;
}

SignalGroups {
  AllS = 'clk + data';
}

DCapSetup DS1 {
  Pins  "data";
}

DCapFilter DF1 {
  Type             Capture;
  TransferMode     Parallel;
  VectorsPerFrame  8;
}

DCapFilter DF2 {
  Type             Capture;
  TransferMode     Parallel;
  FrameCount       1;
  VectorsPerFrame  8;
  VectorsPerSample 1;
  DiscardOffset    2; 
  DiscardVectors   1; 
}


Timing {
  WaveformTable t1 {
    Period '100ns';
    Waveforms {
      clk { P  { '0ns'  D; '50ns' D; } }
      data { 01 { '50ns' D/U;         } }
      data { H  { '10ns' Z; '50ns' C; } }
    }
  }
}

PatternBurst B1 {
  PatList { 
    P1;
  }
}

PatternExec PE1 {
  DCapSetup    DS1;
  DCapFilter   DF1;
  DCapFilter   DF2;
  PatternBurst B1;
}


Pattern P1 { 
  W t1;
  V { clk = P; data =0; }
  V { clk = P; data =H; }
  V { clk = P; data =H; }
}

What to do next

Convert the file normally using STIL Reader.
