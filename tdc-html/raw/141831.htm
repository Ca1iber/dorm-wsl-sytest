SMC_UPLOAD_STATUS.remainingUploadTime()

Returns the remaining upload time of an SMC task that is stored in a vector which is populated by SMC_GET_UPLOAD_STATUS().

Syntax

DOUBLE remainingUploadTime() const;

List of parameters

There are no parameters.

Return value

Returns the remaining time (in seconds) of the upload task, this is the amount of time that is expected to be required for uploading the remaining number of samples. This value is estimated based on the transfer rate observed from the given environment.

If this figure cannot be determined, NaN (not a number) is returned.

Example

This example shows how to create a vector of type SMC_UPLOAD_STATUS and how to retrieve the total upload size from the vector.

Note As SMC_UPLOAD_STATUS represents a collection, one has to iterate over the collection to obtain the item.
typedef vector<SMC_UPLOAD_STATUS> SmcUploadStatusVector;
DOUBLE remainingUploadTime;

// Obtain the collection
SmcUploadStatusVector statusVector = SMC_GET_UPLOAD_STATUS();

// iterate through collection
for(SmcUploadStatusVector::iterator it = statusVector.begin();
     it != statusVector.end(); ++it) {
        remainingUploadTime = it->remainingUploadTime();
        cout << "SMC remaining upload time:" << remainingUploadTime << endl;
     }
