DGT_Trig

This class contains APIs for the automatic generation of trigger signal for the digitizer used in mixed-signal concurrent testing.

This function is defined in the header file /opt/hp93000/soc/segments/tml/include/ext_include/protocol/DGT_Trig.hpp.

Syntax

write0(UINT64 repeatCount)         //The API is used to write signal 0 to the pattern using the specified count.

Or,

write1(UINT64 repeatCount)       //The API is used to write trigger signal 1 to the pattern using the specified count.
Parameter

Parameter

Description

repeatCount

The repeat times of the trigger signal 0 or 1.

Example

CCTtsName = CCTgetTestsuiteName();
  GET_TESTSUITE_NAME(tsName);
  Sync.registerCCTestMethod(tsName, this);
...
DGT_Trig::getInstance(tsName).setPort("DGTTrig");
DGT_Trig::getInstance(tsName).setWaveTable("DAC_MP_wtb");
DGT_Trig::getInstance(tsName).setIdentifier("DGTTrig_" + tsName);
Sync.registerSyncPort(DGT_Trig::getInstance(tsName));
Sync.start();
...
DGT_Trig::getInstance(tsName).write0(150);
DGT_Trig::getInstance(tsName).write1();
DGT_Trig::getInstance(tsName).write0(170);
