Topic 342556

Alphabetical list of flags

The testflow tool provides access to a range of flags that control numerous aspects of testflow execution.

The state of all flags is stored in the Testflow file. SmarTest performs a range check of parameters when loading the file. For more information, refer to Range check of parameters in Testflow file.

The following table lists the flags available in the testflow tool in alphabetical order. The first column shows two names for the flags:

  • The upper value is the name that is shown in the Flags page or in the Test suite properties view of the Testflow Tool.
  • The lower value is the keyword as it is stored in the Testflow file.

  • Values on and off in the description are for the GUI. These values correspond to 1 and 0 in the testflow file or APIs. The same applies to other labels of the GUI drop-down lists: These labels are represented as integer values in the testflow file or APIs.

  • Integer values in brackets are the values used by the testflow file or APIs.

hidden_datalog_mode

hidden_datalog_mode

 Data logging
Enables compatible or full hidden data logging mode provided by the SmartCalc framework.
0 (off) (0)
Turns hidden data logging off.
1 (on - compatibility mode) (1)

Turns hidden data logging in compatibility mode on.

In this mode, the limits are used that are defined in the SMC_SYNCHRONIZE() test suite.

2 (on - full hidden mode) (2)

Turns full hidden data logging on, including LIMIT support.

In this mode, the limits are used that are defined by the calling test suite.

This is the recommended mode.

Note that activating the hidden mode (value 1 or 2) may cause missing or unexpected data log entries when you interactively execute test suites based on the SMC framework. We therefore recommend that you do not activate hidden data logging in this case.

When you are using the concurrent test framework, the hidden_datalog flag also determines whether the test events are logged separately for each test suite (if the flag is turned on) or all events are logged together in the final CCExecution test suite (if the flag is turned off).
