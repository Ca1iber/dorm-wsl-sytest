MoveEDLStream()

This API saves the EDL data collection file located in the SmarTest temp directory to a specified file. If no destination file is specified, the data collection file will be cleared.

SUCCESS will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

PARAMETER_EXCEPTION
  • The value of the parameter "DEST_EDL_FILE" is not a full path.

RECOVERABLE

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • The local session does not exist.
  • Failed to move the EDL stream to file "XXX".

RECOVERABLE

Parameters

I/O

Parameter

Description

I

SESSION_ID

The ID of the SmarTest session to work with.

I

DEST_EDL_FILE

The full path of the file to save the EDL data. If not specified, the data collection file will be cleared.

Prototype

ParamList inputParams;
Status syncCommand("MoveEDLStream", inputParams, sessionID);

Example

string sid = LOCAL_SESSION_ID;
ParamList inputParams; 
inputParams["DEST_EDL_FILE"] = "/tmp/new_datalog_file.log";

Status retVal = syncCommand("MoveEDLStream", inputParams, sid);
if ( retVal.isError() ) 
{
cout<<"error code= " << retVal.code() << " description="
    << retVal.text() << endl;
}

Functional changes

  1. Introduced in SmarTest 6.5.0
  2. SmarTest 7.2.1: Supports the empty input for the parameter DEST_EDL_FILE.
