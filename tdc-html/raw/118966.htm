DSVS, DSVS? - (Define Spec Value Set)

The DSVS command serves to define a spec value set. A spec value set assigns values to a subset of the spec (base) variables that are declared in the equation set(s) of a certain timing or level specification. The purpose of spec value sets is to enable a changing the runtime values of more than one spec variable so that the equation system needs to be recalculated only once. For more information see Changing the runtime values of base variables.

In order to delete a spec value set, use DSVS with all parameters except the set identifier empty (even the spec_type parameter).

The DSVS? query returns the current definition for a selected or all spec value sets.

Postdependencies

After defining the spec value set, you must:

  1. Define its value assignments with the BSVR command.
  2. Trigger recalculation of the equation system with the BSVE command.

DSVS

DSVS {spec_value_set_id}, ["description"], {"spec_type"}, [equ_set_no|PRM], [spec_set_no|"multi-port_spec"]
DSVS {spec_value_set_id},,,,

DSVS?

DSVS? {spec_value_set_no|ALL}

returns: 

DSVS {spec_value_set_id}, ["description"], {"spec_type"}, [equ_set_no|PRM], [spec_set_no|"multi-port_spec"]

Parameters

spec_value_set_id

This must be an integer between 1 and 216-1.

description

A description of the spec value set.

spec_type

The specification type. Possible values are:

  • TIM: Timing specification
  • LEV: Level specification

equ_set_no

An equation set number, which together with a spec set number identifies a (single-port) specification.

PRM

Instead of an equation set number, you can also specify the keyword PRM, which refers to the current (single- or multi-port) primary specification.

If the primary specification is not equation based, equation set 1 and spec set 1 are used.

spec_set_no

A spec set number, which together with an equation set number identifies a (single-port) specification.

multi-port_spec

Instead of a spec set number, you can also specify the name of a multi-port timing specification. In this case the equ_set_no parameter must be left empty.

Errors

An error is generated if:

  • The spec value set already exists.
  • The spec value set ID is invalid.

Example

> DSVS 1, "per", TIM,PRM,
> DSVS? 1
< DSVS 1,"per",TIM,1,1
> DSVS 1, "per", TIM,1,2
< Error: Failed to execute firmware command: DSVS 1, "per", TIM,1,2
> DSVS 1,,,,
> DSVS 1, "per", TIM,1,2
> DSVS? 1
< DSVS 1,"per",TIM,1,2

This example shows how to redefine a spec value set. Note that you must delete the set before you can change the specification.

Functional changes
