SET_ACTIVE_SITES()

Activates and deactivates sites when testing multisite and updates the test method internal cache. Both the activated and deactivated sites will be tested but only the results of activated sites will be evaluated. Test points for DC tests will be suppressed on inactive sites.

Note This API is designed for expert usage. It is intended for special cases where you change the active sites temporarily, but not for site handling. For how to use this API, refer to the section Example below.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Execute.h.

Syntax

VOID SET_ACTIVE_SITES(TM::MS_SITE_SET active_set);
Parameter

Parameter

Description

active_set

A character array. Each character except active_set [0] will be used to activate or deactivate a site; active_set [0] will be ignored:

  • If active_set [i] is not 0, site i will be activated.
  • If active_set [i] = 0, site i will be deactivated.

i starts from 1 to represent site 1, 2, 3, ...; 0 is not a valid site number.

Do not activate more than the current configured sites.

Return value

There is no return value.

Example

//
// Get number of configured sites
//
INT     numberOfConfiguredSites;
ARRAY_I configuredSites;

numberOfConfiguredSites = GET_CONFIGURED_SITES(configuredSites);

//
// Set active sites
//
TM::MS_SITE_SET activeSiteSet;

for (INT siteIndex = 1; siteIndex <= numberOfConfiguredSites; siteIndex++)
{
    if ((siteIndex == 2) || (siteIndex == 5))
    {
        activeSiteSet[siteIndex] = 0;
    }
    else
    {
        activeSiteSet[siteIndex] = 1;
    }
}

SET_ACTIVE_SITES(activeSiteSet);

//
// Get active sites, 1st syntax, string
//
STRING  activeSitesString;
INT     numberOfActiveSites;

numberOfActiveSites = GET_ACTIVE_SITES(activeSitesString);

cout << "1st syntax, string,  "
     << numberOfActiveSites << " sites active: "
     << activeSitesString << endl;

//
// Get active sites, 1st syntax, ARRAY_I
//
ARRAY_I activeSitesIntArray;

numberOfActiveSites = GET_ACTIVE_SITES(activeSitesIntArray);

cout << "1st syntax, ARRAY_I, "
     << numberOfActiveSites << " sites active: "
     << activeSitesIntArray << endl;

//
// Get active sites, 2nd syntax, TM::MS_SITE_SET
//
TM::MS_SITE_SET activeSitesCharArray;

GET_ACTIVE_SITES(activeSitesCharArray);

cout << "2nd syntax,            "
     << "active sites: ";

for (INT siteIndex = 1; siteIndex <= numberOfConfiguredSites; siteIndex++)
{
    cout << (INT) activeSitesCharArray[siteIndex];
}

cout << endl;

It is assumed that eight sites (site number: 1 to 8) are configured and enabled. Sites 2 and 5 are deactivated by API SET_ACTIVE_SITES(). The modified settings are read back by all three syntax variants of API GET_ACTIVE_SITES(). The code above results in the following output:

1st syntax, string,  6 sites active: 10110111
1st syntax, ARRAY_I, 6 sites active: {	1,	3,	4,	6,	7,	8,	}
2nd syntax,            active sites: 10110111
