TMU_PINS.getDatarate()

Returns the defined data rate of the TMU pin(s).

Syntax

UINT64 getDatarate() const;

List of parameters

There are no parameters.

Return value

The data rate of the TMU pin(s) is returned. The unit is bits/second.

Related information

TMU_PINS.setDatarate()

Functional changes

  1. Introduced in SmarTest 7.1.0
