Bit fail map list file

A bit fail data list file (.bfdl) contains a list of bit fail data (.bfd) files.

BFDL files can be used as input by the offline redundancy analysis if it is to be performed on the results of multiple test suites.

A BFDL file contains the names of the BFD files it references, one name per line. BFD files can be specified in three ways:

  • Name only: If only the name of the BFD file is given, it must be located in the same directory as the BFDL file.
  • Relative path: A relative path uses the directory of the BFDL file as the basis.
  • Absolute path.

Example

2006-09-06_15-52-56-580972-swr_b-mpc002-swr_bank-mpc0021Site1.bfd
2006-09-06_15-52-59-810518-swr_b-mpc003-swr_bank-mpc0031Site1.bfd
2006-09-06_15-53-03-61674-swr_b-mpc004-swr_bank-mpc0041Site1.bfd
2006-09-06_15-53-09-770967-swr_b-mpc005-swr_bank-mpc0051Site1.bfd
2006-09-06_15-53-24-701917-swr_b-mpc006-swr_bank-mpc0061Site1.bfd
2006-09-06_15-53-48-863241-swr_b-mpc007-swr_bank-mpc0071Site1.bfd
