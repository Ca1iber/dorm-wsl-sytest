Topic 29428

GET_TESTSUITE_NAME

This API retrieves the name of the test suite that contains the current test method program.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

GET_TESTSUITE_NAME(STRING& tsname);
Parameter

I/O

Parameter

Description / Range

O

tsname

The name of the test suite that contains the current test method program is returned to this STRING type variable

Example

STRING test_name;
    :
GET_TESTSUITE_NAME(test_name);

The GET_TESTSUITE_NAME API returns the name of the test suite that contains the current test method program to the variable test_name.

Functional changes

  1. Introduced before SmarTest 6.3.2
