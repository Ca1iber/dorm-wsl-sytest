Topic 68695

Expressions with more than 64 bits

Subtopics

  1. Special considerations

MTL supports expressions with a size of more than 64 bits. This is especially useful for testing devices with very wide data paths.

Standard values - variables, constants, and literals - in MTL are considered to have a size of 64 bits, whether they are expressed as decimal (for example, 120) or hexadecimal (for example, 0x78).

A special syntax is available to specify values with sizes of 32 to 320 bits, as described below. These values can be used in the APG program file and in device accesses.

They are signed values and support two's-complement arithmetic. The largest number that can be expressed as a value with n bits is 2^(n-1)-1; the smallest number is -(2^(n-1)).

Addition, subtraction, comparison, bit shift, and bitwise operations (AND, OR, NOT, XOR), are fully supported; multiplication and division are supported only for the least significant 64 bits.

There are some limitations and special behaviors to consider when using values with more than 64 bits. The details are discussed in Special considerations.

Syntax

Values with a size other than 64 bits are specified as:

:<bitSize>: <value>

Parameter

Description

<bitSize>

The size of the value in bits.

Any sizes larger than 320 bits are converted to 320 bits.

<value>

Any value in standard decimal or hexadecimal notation.

Italic text indicates meta-syntax, as described in Syntax conventions.

Examples

Example 1

A 96-bit wide integer with a value of -1, in decimal and hexadecimal:

:96: -1
:96: 0xffffffffffffffffffffffff

Example 2

A variable defined as a 128-bit wide integer:

a = :128: 9223372036854775807;
