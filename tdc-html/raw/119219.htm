Types of testflow variables

  • Userflag

    An integer value (0 or 1). Can be viewed and edited during Test Program execution from within the User Flags window.

  • String

    Text (for the maximum string number see SmarTest character and number limits). String values must be enclosed in double quotes, for example, "abc".

  • Double

    A double number or an expression that represents a double value (available range [-123.456 .. 789.654]).

    Typically, such variables take result values of Test suites.
