Topic 30759

GET_TEST_INFO

Subtopics

  1. Associated Syntax Entities

GET_TEST_INFO returns information about the environment in which the application model is executed;which you can assign to a variable for further processing, for example, to use it as part of a file name.

Which information the function returns is governed by the keyword it is passed as its argument. These keywords are supported:

  • date_time: current date and time
  • dev_name: device name from the testflow's information screen
  • dev_rev: device revision from the testflow's information screen
  • device: device name from the current device directory
  • ooc_stop_rule: elements of the global OOC stop rule
  • ooc_warning_rule: elements of the global OOC warning rule
  • smartest_rev: revision of the active SmarTest
  • test_desc: test description from the testflow's information screen
  • test_rev: test revision from the testflow's information screen
  • tester_id: the id of the tester on which the test program is executed
  • testprog: the name of the current test program
  • user_id: the log-in name of the active user

For examples, see Example application models.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.4: Added device, smartest_rev, tester_id, and user_id keywords
