DSP_ADD_SCL

This API is for adding a scalar value to the specified elements of an array.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_ADD_SCL(DOUBLE scaler, ARRAY_D& src, 
            ARRAY_D& result);
DSP_ADD_SCL(DOUBLE scaler, DOUBLE *src, 
            DOUBLE *result, INT size);
DSP_ADD_SCL(COMPLEX scaler, ARRAY_COMPLEX& src, 
            ARRAY_COMPLEX& result);
DSP_ADD_SCL(COMPLEX scaler, COMPLEX *src, 
            COMPLEX *result, INT size);
Parameters

I/O

Parameter

Description / Range

I

scaler

Addend value

I

src

Addend array

O

result

Addition results

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src)

size ≤ (size of result)

Example

DOUBLE array1[1024], array_sum[1024];
     .
     .
DSP_ADD_SCL(128.0, array1, array_sum, 1024);

DSP_ADD_SCL adds 128.0 to the first 1024 elements of double array array1 and returns the results to the corresponding 1024 elements of double array array_sum as follows:

int i;
for(i=0; i<1024; i++)
  array_sum[i] = array1[i] + 128.0;
