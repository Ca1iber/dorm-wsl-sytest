ExecuteShellCommand

This API executes a Linux shell command.

You can also specify a time limit for the shell command execution. If the shell command has not been executed in the time limit, the API will send out an error message and exit.

If the shell command is executed successfully, 0 will be returned. Otherwise, -1 will be returned.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ExecuteShellCommand.h.

Syntax

INT status = ExecuteShellCommand(const string &command, int timeout_s);
Parameters

command

The shell command to execute.

timeout_s

The time limit of the command execution. The API will send out an error message and exit if the shell command has not been executed before the specified time in second.

Example

INT status;
status = ExecuteShellCommand("ps -ef",5);
