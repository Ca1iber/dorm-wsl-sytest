Use cases for MTL arrays

Subtopics

  1. Accessing burst data
  2. Random address patterns
  3. Random scrambling patterns
  4. Bank interleaved patterns

MTL arrays can help you simplify pattern algorithms, especially for complex patterns.

Four typical examples are introduced to show you how MTL arrays helped you create simple programs for complex patterns:

  • Accessing burst addresses and data
  • Creating random address patterns
  • Creating patterns with random scrambling
  • Creating bank interleaved patterns
