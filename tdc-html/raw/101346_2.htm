Topic 101346

Syntax of the STATEMAP section

The STATEMAP section describes how tester waveforms are to be mapped to DUT waveforms in the DUT view of the Pattern Debug tool. It must be defined separately for every PINS block in the base wavetable of the respective pattern.

Syntax

STATEMAP
<wvf_idx_seq_1> <state_char_seq_1> <x_mode_1> <selector_1>
<wvf_idx_seq_2> <state_char_seq_2> <x_mode_2> <selector_2>
. . .
<wvf_idx_seq_n> <state_char_seq_n> <x_mode_n> <selector_n>

The functions of the individual columns are:

  • <wvf_idx_seq_i>: This column specifies a physical waveform index (for integer x-mode), or a sequence of physical waveform DC/DC power units (for fractional x-mode). The number of DC/DC power units must conform to the x-mode that is specified in the 3rd column. It must be 1 for any integer x-mode, and n for a fractional x-mode 1/n. Note that every waveform index of the respective wavetable section must occur at least once in this column. Note also that in order to secure an unambiguous translation from DC/DC power units to state characters (upload), no triple of index sequence, x-mode, and selector must occur more than once in the STATEMAP table.

    The maximum fractional x-mode is 1/1024. There are two notational abbreviations for repetitions of the same index within a sequence. You can specify a repeat factor in braces after an index, or specify the wild card * (but only once in the sequence). The following is an example for 1/8:

    1,0,0,0,1,1,1,1

    can be abbreviated by

    1,0{3},1{4} or 1,0*,1{4}

    In the second formulation, the repeat factor for 0 is calculated by subtracting 4+1 from the denominator of the x-mode 1/8.

  • <state_char_seq_i>: This column specifies the state character (sequence) by which the DUT vectors are to be represented in the Pattern Debug tool. The length of the sequence must conform to the x-mode that is specified in the 3rd column. It must be 1 for any fractional x-mode, and n for an integer x-mode n. Note also that in order to secure an unambiguous translation from state characters to waveform DC/DC power units (download), no triple of state character sequence, x-mode, and selector must occur more than once in the STATEMAP table.
  • <x_mode_i>: This column specifies the x-mode. The format is xn for integer x-mode, and x1/n for fractional x-mode.
  • <selector_i> (optional): This column specifies a string which serves to distinguish
    • identical pairs of state character (sequence) and x-mode that are mapped to different DC/DC power units (index sequences)
    • identical pairs of index (index sequence) and x-mode that are mapped to different characters (character sequences).

      This is required for a unique translation of state characters to DC/DC power units (download), and from DC/DC power units to state characters (upload).

Example

PINS  I1
0  "d1:1"
1  "d1:0"
2  "d1:1 d2:0"
3  "d1:1 d3:0 d4:1 d5:0"

STATEMAP
#wf_idx   state_char   x_fact
2            1          x1
0,1          1          x1/2
3            11         x2
