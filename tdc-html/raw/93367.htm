Creating a sharing configuration file

This topic explains how you can create a sharing configuration file. This file is needed as input for the fd_merge tool.

About this task

The fd_merge tool requires a sharing configuration file for your shared driver environment as input. This file must have a format as described in Sharing configuration file. To create this file, you can use the example file noted below.

Before you begin

Have the names and value of your setup available.

Procedure

  1. Copy the sharedsites.cfg sharing configuration file from the directory:

    /opt/93000mts/mts/ddr_solution_tools/DriverSharing/examples/fixture

  2. Open a new text file with an editor (for example NEdit).
  3. Paste the sharing configuration file example content into the new file.
  4. Modify the values for the keywords according to your needs.
    Note Do not modify the keywords.

Results

The sharing configuration file is ready to use.

What to do next

Use the fd_merge tool to merge your fixture delay files.
