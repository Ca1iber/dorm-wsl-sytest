Topic 102931

Values

Values in the device access files are always integers. Values in the APG program files can be intergers, strings, and Boolean values.

If integers, by default, they are signed 64-bit integers, resulting in a value range of -9.22 * 1018 to 9.22 * 1018. For special requirements, larger integers up to 320 bits are available. This is discussed in Expressions with more than 64 bits.

While floating-point numbers can be used for parameters in the APG pattern file, these numbers are automatically truncated as soon as they are passed to the APG program file.

Note Shift, Boolean, and increment operations as well as the index operator are not available for floating-point numbers.

Strings, Boolean values, and complex data types such as lists or records are not available in the device access file, except for literal strings.
