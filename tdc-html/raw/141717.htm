Topic 141717

read()

Reads data from an address.

Syntax

read(long long iAddr);
read(long iAddr);
read(int iAddr);
List of parameters

Parameter

Description

iAddr

The address to read data.

Example

rdi.protocol("id1").pname("i2c").read(0x1).execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
