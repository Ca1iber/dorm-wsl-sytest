Topic 31057

User Defined Panel

Subtopics

  1. User Defined Function

Within the toolbar area is the User Defined Panel functions. This feature enables you to create a dedicated waveform-analysis function, apply it to the displayed waveforms of the Signal Analyzer directly from the GUI, and make it portable among all users or all devices. These functions are programmable using the Data Display API and DSP Test Method API. These functions are independent of the test program.

The following default functions are provided:

Function

Description

View Waveform Memory

This function allows you to view the waveform stored in waveform memory of arbitrary analog modules.

Signal Information

Displays signal information, such as:

  • Mean and standard deviation
  • RMS
  • Min.value and max.value
  • Sample rate

The signal information is displayed on the Signal Analyzer console. Note that when a function is selected, the User Configurable Dialog Box appears allowing you to specify the trace ID.

Spectrum Analysis

Provides several functions, such as: signal- to- noise plus distortion (SND), signal-to- noise ratio (SNR), and total harmonic distortion (THD) for the specified waveform. When a function is selected, the User Configurable Dialog Box appears allowing you to specify the trace ID. Note that the following units are supported for the Spectrum Analysis:

  • dB
  • dBm
  • dBV
  • Vp
  • Vpp
  • Vrms
  • Watts

Note that when this function is selected, the Spectrum Analysis Dialog appears allowing you to specify the trace ID, Spectrum Unit, Window function, Carrier Frequency (optional), Carrier Bin (optional). Note that the options Carrier Frequency and Carrier Bin allow you to specify the carrier frequency or bin when SmarTest cannot correctly determine the carrier peak because a peak in the spectrum is higher than the carrier.

Diff. Waveforms

Enables you to calculate the difference between specified waveforms and display it to the selected Data Display Panel. When this function is selected, the User Configurable Dialog Box appears allowing you to specify the trace ID.

Show Histogram

Calculates the histogram of the specified waveform and displays it on a new graph.

Auto Scale

Scales the waveforms in a Data Display Panel to fit into one display.

Clear

Deletes all traces displayed in the selected graph.

Copy

Copies the specified trace of selected graph.

Paste

Pastes the copied trace (using Copy) into selected graph.

Edit Trace

Enables you to edit the data of the specified trace using a default editor. A prerequisite for this is that the environment variable EDITOR is set as in the following example.

export EDITOR=/usr/X11R6/bin/nedit

In this example, the Trace Editor is set to be the NEdit tool. You must restart SmarTest in order that this EDITOR variable takes effect.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.3: The size of the waveform, which is analyzed using FFT, can be any integer.
  3. SmarTest 7.4.0: dBV is supported in Signal Analysis
