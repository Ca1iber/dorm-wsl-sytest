Example: Using sync markers within test methods

About this task

This example shows how to implement sync markers to UTM.

It only points out the sync marker specifics.

Before you begin

Device & Protocol details:

It is presumed that the setup has been done as detailed in Example: Defining a MDIO protocol.

In addition, you should have created a 'control pattern' that runs in the same sync group as your protocol.

UTM details:

An UTM project MDIO_DEV_tml has been created as described in How to create a universal test method project.

An UTM Class MDc_synctest has been created as described in How to create a universal test method class, without entering parameters or limits in the wizard.

Procedure

  1. Add the sync marker mySyncMark1 to your 'control pattern' as described in: Adding synchronization markers.
  2. Open the MDc_synctest class for editing.
  3. Insert the transaction code line that will be executed when mySyncMark1 is reached at your desired location. 
    mdioTest.syncTransaction("write", "poNonMD", "mySyncMark1").set("phyaddr", 0x1F).set("regaddr", 0x1F).set("data", 0xFFFF);
  4. Complete your UTM code and build your UTM project.

Results

You have created a write transaction that will be executed once mySyncMark1 is reached in the 'control pattern'.

Example

This class, together with the example device setup detailed in Example: Defining a MDIO protocol, can be copied to your UTM class and used as a reference to the previous description.

#include "testmethod.hpp"

//for test method API interfaces
#include "mapi.hpp"
using namespace std;

/**
 * Test method class.
 *
 * For each testsuite using this test method, one object of this
 * class is created.
 */
class MDc_synctest: public testmethod::TestMethod {

protected:
  /**
   *Initialize the parameter interface to the testflow.
   *This method is called just once after a testsuite is created.
   *
   *Note: Test Method API should not be used in this method.
   */
  virtual void initialize()
  {
    //Add your initialization code here
  }

  /**
   *This test is invoked per site.
   */
  virtual void run()
  {
     SYNCHRONIZED_TEST mdioTest("poMD");
     SYNCHRONIZED_TEST mdioComplement("poMDc");

     ON_FIRST_INVOCATION_BEGIN();

        cout << " ========== MDIO Simulated ==============" << endl;
        cout << " poMD used as real MDIO port"<< endl;
        cout << " poMDc used to stimulus/reply to poMD" << endl;
        cout << " Phy addr, reg addr and data are written on poMD" << endl;
        cout << " Phy addr, reg addr and data are checked on poMDc" << endl;
        cout << " The roles are then reversed" << endl;
        cout << " Test will pass based on current settings" << endl;
        cout << " Change any of the write addr or data to simulate a failure"  << endl;
        cout <<  endl;

        // Writes data on poMD
        // Verified by "expect" on poMDc below
        mdioTest.transaction("write").set("phyaddr", 0x1F).set("regaddr", 0x1F).set("data", 0xFFFF);
        mdioTest.transaction("write").set("phyaddr", 0x1F).set("regaddr", 0x1F).set("data", 0xFFFF);

        // Reads data from poMDc
        // Compares expect data with what is written
        mdioTest.transaction("read").set("phyaddr", 0x0F).set("regaddr", 0x15).expect("data", 0xA0A0);
        mdioTest.transaction("read").set("phyaddr", 0x0F).set("regaddr", 0x15).expect("data", 0xCCCC);

        cout << "==> performing transaction synchronized to 'mySyncMark1'...."  << endl;
        mdioTest.syncTransaction("write", "poNonMD", "mySyncMark1")
                 .set("phyaddr", 0x1F).set("regaddr", 0x1F).set("data", 0xFFFF);
         cout << "==> synchronized transaction to 'mySyncMark1' - D O N E !!!"  << endl;

        if (!mdioTest.flush()) {
           cerr << "flush error \n";
           ERROR_EXIT(TM::ABORT_FLOW);
        }

        mdioComplement.transaction("checkWrite").expect("phyaddr", 0x1F).expect("regaddr", 0x1F).expect("data", 0xFFFF);
        mdioComplement.transaction("nop");
        mdioComplement.transaction("setForRead").set("data", 0xA0A0);
        mdioComplement.transaction("checkSetForRead").expect("phyaddr", 0x0F).expect("regaddr", 0x15).set("data", 0xCCCC);

        if (!mdioComplement.flush()) {
           cerr << "flush error \n";
           ERROR_EXIT(TM::ABORT_FLOW);
        }

        FUNCTIONAL_TEST();

     ON_FIRST_INVOCATION_END();

     SYNCHRONIZED_TEST::unlink();
     //Add your test code here.
        return;
     }

  /**
   *This function will be invoked once the specified parameter's value is changed.
   *@param parameterIdentifier
   *
   *Note: Test Method API should not be used in this method.
   */
  virtual void postParameterChange(const string& parameterIdentifier)
  {
    //Add your code
    return;
  }

  /**
   *This function will be invoked once the Select Test Method Dialog is opened.
   */
  virtual const string getComment() const 
  {
    string comment = " please add your comment for this method.";
    return comment;
  }
};
REGISTER_TESTMETHOD("MDc_synctest", MDc_synctest);
