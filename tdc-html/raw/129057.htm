MTP_MEMORY_PATTERN.getFailBitCount()

Lets you retrieve fail bit counts for an entire device, or for specific banks, or for specific data pins.

Syntax 1

LONG getFailBitCount(MTP:FBC_DIMENSION dimension, const STRING & entity);

Parameter

Description

dimension

The device dimension for which you want to get the fail bits count:

  • MTP::FBC_DEVICE: The entire device
  • MTP::FBC_DBIT: A data bit
  • MTP::FBC_BANK: A bank

entity

The name of a data bit or a bank, such as "DQ01" and "Bank_01".

Omit this parameter if you have chosen MTP::DEVICE as the dimension.

Syntax 2

LONG getFailBitCount(MTP:FBC_DIMENSION dimension, const int index = -1);

Parameter

Description

dimension

The device dimension for which you want to get the fail bits count:

  • MTP::FBC_DEVICE: The entire device
  • MTP::FBC_DBIT: A data bit
  • MTP::FBC_BANK: A bank

index

An integer used to represent a data bit or a bank, for example, 0.

Omit this parameter or specify -1 (the default value) if you want to retrieve fail bit counts for the entire DUT, for all banks, or for all data bits.

Return value

The number of fail bits.

Example

To perform a test and output the fail bit count for the whole device, the DQ_00 pin, and bank 1:

MTP_MEMORY_TEST memoryTest();
memoryTest.enableFailBitCount(true);
memoryTest.setFBCLimit(MTP::FBC_DEVICE,1024).setFBCLimit(MTP::FBC_BANK,1024,"1,2,3,4").setFBCLimit(MTP::FBC_DBIT,1024,"@");

memoryTest.execute();

MTP_MEMORY_PATTERN &march6N = memoryTest.getMemroyPort("A").getMemoryPattern("march6N");
long fail_count;
fail_count = march6N.getFailBitCount(MTP::FBC_DEVICE);
cout << "Device Fail Bit Count : " <<  fail_count << endl;
fail_count = march6N.getFailBitCount(MTP::FBC_DBIT,0);
fail_count = march6N.getFailBitCount(MTP::FBC_DBIT,"DQ_00");
cout << "DQ_00 Fail Bit Count : " <<  fail_count << endl;
fail_count = march6N.getFailBitCount(MTP::FBC_BANK, 1);
fail_count = march6N.getFailBitCount(MTP::FBC_BANK, "bank_01");
cout << "Bank 1 Fail Bit Count : "  <<  fail_count << endl;
