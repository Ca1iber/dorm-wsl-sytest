The Tools menu provides the following functions:

Command

Description

Generate

Access the waveform editing tools.

Test Mask

Mask an arbitrary area of a graph.

Translate

Transform the waveform located in the Waveform Graphs Tool.

Inject Jitter

Generate jitter signals which are often required when testing LAN devices.

Cable Simulation

Simulate the effects of various cable characteristics.

Coherent Reconstruction

Reconstruct uploaded data as coherent data.

Impedance Matching

Design an impedance matching network graphically.

Port Extension

Compensate for errors (phase shift and loss) caused by the transmission line or fixture between the calibration plane and the port of the device.

Demodulation

Graphical interface for demodulating RF waveforms.

Per-Pin Signal Generator

Generate test patterns for digital channels that source analog signals.

Harmonics

Calculate the harmonic distortion and intermodulation frequencies from given fundamental frequencies.

Load Datalog

Select a log file created by the event data log function.

Select Waveform

Investigate the waveforms contained in the data log file.

My Function

Accesses the User Defined Function dialog box used to define your own functions.
