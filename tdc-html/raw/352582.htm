AIF-related STIL Reader setup options

The AIF-related options in a STIL Reader setup file specify the location of settings files that STIL Reader needs for the conversion.

Syntax

The AIF-related options in alphabetical order:
aic_file='path'

The location of the ASCII Interface global configuration file (.aic) to be used for the conversion.

The path can be absolute or relative to the current directory.

This parameter is mandatory. There is no default.

ascii_pattern_state_hook=function-name

The name of a Python preprocessing function that can replace individual state characters in the ASCII pattern with different characters.

The complete function code must be located within the STIL Reader configuration file. The function must accept these parameters:
  • pin (the affected pin)
  • wft (the waveform table being processed)
  • wfc (the waveform character being processed)
  • default_state (the active default state character)
The function must return a state character. For example:
def clock_replacement(pin,wft,wfc,default_state):
    state = default_state
    if pin == 'clk[0]':
        if wft == 't1' and wfc == 'P':
            state = 'K'
    return state

STIL Reader processes this returned state character in place of the original character from the AVC file.

This parameter is optional. There is no default.

ascii_pattern_state_hook_allow_duplication=boolean
Whether to allow the function specified in the ascii_pattern_state_hook parameter to return states that already exist:
  • 0: Only non-existing states may be returned. If an existing state is returned, the conversion is stopped and an error is reported.
  • 1: The function may return both existing and new states.

This parameter is optional. The default is 0.

avc_dir='path'

The location of the AVC file directory to be used for the conversion.

The path can be absolute or relative to the current directory.

This parameter is optional. There is no default.

dvc_file='path'

The location of the ASCII Interface timing file (.dvc) to be used for the conversion.

The path can be absolute or relative to the current directory.

This parameter is mandatory. There is no default.

pins_file='path'

The location of the pin configuration file to be used for the conversion.

The path can be absolute or relative to the current directory.

This parameter is optional. There is no default.
