iMeasRange()

Specifies a current measurement range.

Syntax

iMeasRange(double dIMeasRange);
List of parameters
Parameter Description
dIMeasRange The range of the current to measure.
iMeasRange() can be used in both code‑based and pattern‑based modes. It is usually used in the pattern‑based mode.

SmartRDI will check the time between iMeasRange() and the next event on the pin. A warning message will issued if the time is not long enough and you need to insert the wait time manually.

Return value
A reference to the dcBase object.

Application notes

Programming both the force and the measurement range of XPS256

XPS256 does not have different force and measurement ranges.

Thus using iForceRange() and iMeasRange() within one SmartRDI command that is terminated by execute() will not result in different ranges, but the current measurement range will finally be active. The applied sequence is

  1. Set current force range (active for a short time)
  2. Set current measurement range (overrides the current force range)
Current measurement range of XPS256 in PMU operating mode

For code‑based programming, the DC Scale XPS256 card does not support automatic down‑ranging in PMU operating mode. Automatic down‑ranging is supported only for pattern‑based programming.

The definition of the current measurement range in code‑based programming is therefore silently ignored in PMU operating mode. We recommend, always programming the current force range instead.

Example

RDI_BEGIN();

    rdi.dc().pin("DPS_1,DPS_2").iMeasRange(100 uA);
    rdi.dc().pin("DPS_1,DPS_2").vForce(0.01 V);

    rdi.wait(3 ms);

    rdi.dc("im1").pin("DPS_1,DPS_2").iMeas().execute();

RDI_END();

Functional changes

  1. Introduced in SmartRDI 2.1.0
