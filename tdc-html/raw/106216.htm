Topic 106216

GetLevelProfile

This data query command returns all the variable names and values contained in the specified level. If no level name is specified, it will return the variable names and values of the current level.

SUCCESS will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

ILLEGAL_OPERATION

The designated session ID "XXX" does not exist.

RECOVERABLE

PARAMETER_EXCEPTION

The value of the parameter "LEVEL_NAME" is invalid.

RECOVERABLE

ILLEGAL_OPERATION
  • Level information is not available because application model level has not been initialized yet.
  • The possible root cause to this error info mation is, AMP is not running, i.e. no testprogram in execution, at the time of query.

RECOVERABLE

Parameters

I/O

Parameter

Description

I

SESSION_ID

The ID of the SmarTest session to work with.

I

LEVEL_NAME

The level name. If no level name is specified, the current active level is used.

O

qrResults

The query results are represented by a ParamList object. It contains the following members:

  • LEVEL_NAME: The level name. It is the specified input level name or the name of the current level if no input level name is specified.
  • LEVEL_TYPE: The type of the specified level or the type of the current level if no input level name is specified.
  • VARIABLE_NAME_LIST: The list of the variables belonging to the level.
  • VARIABLE_VALUE_LIST: The list of the variable values corresponding to the variable name list.

Prototype

ParamList qrResults, qrParams;
qrParams["LEVEL_NAME"] = "device";
Status query("GetLevelProfile", qrResults, qrParams, sessionId);

Example

ParamList qrResults, qrParams;
qrParams["LEVEL_NAME"] = "device";
Status obj = query("GetLevelProfile", qrResults, qrParams, sessionId);

if( obj.isSuccess() )
{
  std::vector<std::string> varList = qrResults.valueArray("VARIABLE_NAME_LIST");
  std::vector<std::string> valueList = qrResults.valueArray("VARIABLE_VALUE_LIST");

  std::cout << "Level "<< qrParams["LEVEL_NAME"]<< "has "
            <<varList.size()<<"variables:"<< std::endl;
  for(int i=0; i<varList.size(); i++) 
  {
    std::cout << varList.at(i) << " : " << valueList.at(i) << std::endl;
  }
}
else {
  //error handling
}

Functional changes

  1. Introduced in SmarTest 6.5.0
