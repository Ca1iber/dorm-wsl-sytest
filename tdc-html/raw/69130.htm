Master Result Record (MRR)

The Master Result Record contains an extension of the MIR. The data can be thought of as belonging with the MIR but it is not available when the MIR information is written.

The Master Result Record must be the last record in the data stream.

MRR field name

Field description

Value

93000 data source

FINISH_T
  • Date and time last part was tested
  • Whether the time is local or UTC depends on the setting of the useUTCTime option in formatter.stdf.main.conf.
  • Four-byte unsigned integer
  • EDL Event:

    AppModelLevelEndEvent

  • EDL Attribute:

    Seconds

DISP_COD
  • Lot disposition code
  • One-byte unsigned integer
  • Valid value is ASCII character

    0 - 9 or A - Z

  • <space> = Missing or invalid data
  • Application model variable1):

    DISP_COD

  • Data source can also be a constant value in the configuration file or a system environment variable.

USR_DESC
  • User defined lot description
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • 0 = Default
  • Application model variable1):

    USR_DESC

  • Data source can also be a constant value in the configuration file or a system environment variable.

EXC_DESC
  • Exec defined lot description
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • 0 = Default
  • Application model variable1):

    EXEC_DESC

  • Data source can also be a constant value in the configuration file or a system environment variable.

Functional changes

  1. Introduced before SmarTest 6.3.2
1) User configurable application model variable. See The application model structure.
