Checking the Base Waveform Set against another Waveform Set

The Base Waveform Set is the waveform set that is currently used to interpret data in the Vector Memory and display it in the Pattern Tool window, see The Significance of the Base Waveform Set. As such, the base waveform set is linked to the test label for the currently displayed test.

The number of the waveform set which is currently used as the base waveform set is displayed in the Status Area of the Pattern Tool window.

This check is useful in that it compares one or more waveform sets with the one that is always in current use.

To run the check, proceed as follows:

  1. In the dialog box in Checking for Compatible Waveform Sets, click the base WFset of test label radio button.
  2. Type the test label into the entry field under the radio button.

    The base waveform set that the label carries with it for the purposes of the check is the last used base waveform set when the label was active.

  3. In the against the WFset browser select one or more waveform sets.
  4. Click check.

The system checks the compatibility of the base waveform set against the waveform sets in the browser according to the rules in Keeping Waveform Sets Compatible. It displays a report in the report window.

If the compatibility check fails, click the select button show incompatible pins of first incompatible WFset. The system includes the failed pins in the compatibility check report.
