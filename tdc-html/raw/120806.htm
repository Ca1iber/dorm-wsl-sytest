How to set up Digital Capture

Subtopics

  1. The Setup for Digital Capture

A growing number of test applications requires the acquiring of large amounts of digital output data of a device at high data rates, and storing this data for later analysis and data processing. This is called digital capturing.

Typical applications for digital capturing are

  • audio, video, and communications devices, where the n-bit output codes of Analog-to-Digital-Converters (ADC), or serial digital data streams must be captured.
  • devices with Built-in-Self-Test (BIST), where the digital result output of the BIST must be captured.

Theory of operation

On the V93000 test system, digital capture is enabled on all digital pins defined as o or io channels, irrespective of the card type. Since capturing uses the card's receivers, the capturing rate (speed) is limited to the maximum speed of the card.

The output from the device is compared for a logical low, and if the output of the particular comparison is a pass, then the bit captured is a zero (0), else a one (1) is stored. This is repeated at every location where a capture is set up in order to construct the bit stream that will be analyzed.

Limited package size

The number of bits that can be packaged together is limited by the structure of the memory where the capture data is stored. Only 32 bits can be packaged together in one word in memory. Therefore, if digital capture is carried out across many pins in parallel, only a maximum for 32 bits can be retrieved at a time (hence data from 32 pins). That means, while more than 32 pins can be set up for digital capture, only data from 32 pins can be transferred as a block.
