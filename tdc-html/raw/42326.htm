phHookWaiting

Subtopics

  1. Parameters:
  2. User-Specific Code:

This hook function is called repeatedly (if activated, see Activating a Hook Function) while the driver waits for actions to be performed by the equipment. For example, device insertion by the handler. The time between two calls is configured with the configuration parameter flag_check_interval.

Note This hook function should NOT be used to handle timeouts while waiting for parts. If a final timeout occurs, the hook function phHookProblem will be called.

The simple example functionality of the hook function template demonstrates how to call a CPI function from a hook function.

To call CPI functions, the driver provides interface functions, which then call CPI function and additionally log that call with the driver's logging capabilities.

For example, to call the CPI function GetSystemFlag the interface function ph_TcomGetSystemFlag must be called.

Appendix B: Man Pages for Driver Functions describes how to get more information about the interface functions to the CPI.

phHookError_t phHookWaiting(
    long elapsedTimeSec /* elapsed time while waiting for this part */,
    phEventResult_t *result   /* the result of this hook call */,
    phTcomUserReturn_t *stReturn  /* proposed SmarTest return
                                  value, if <result> is set to
                                   PHHOOK_RES_ABORT by this hook function */
)
{
#ifdef WAITING_IMPLEMENTED
    long flag;
#endif

    /* do checks and trace the call first */
    CheckInitialized(&hook);
    phLogHookMessage(hook.myLogger, PHLOG_TYPE_TRACE, 
                     "phHookWaiting(%ld, P%p, P%p)", elapsedTimeSec, result,
                      stReturn);

#ifdef WAITING_IMPLEMENTED

    /* Here is a sample implementation which reads SmarTest's
        PAUSE flag and prints a message, if the flag is set */

    if (phTcomGetSystemFlag(hook.myTester, PHTCOM_SF_CI_PAUSE, &flag) ==
        PHTCOM_ERR_OK)
    {
       if (flag)
       {
         phLogHookMessage(hook.myLogger, PHLOG_TYPE_MESSAGE_0,
                         "hook function recognized pause flag set while waiting for parts");
       }
    }

/* set the result value:the framework must continue to wait for parts */
*result = PHEVENT_RES_CONTINUE;

    return PHHOOK_ERR_OK;

#else

    /* hook not activated */
    return PHHOOK_ERR_NA;
#endif
}
Note For all type definitions, see the header files corresponding to the respective type. The header files are located in the directory ... /GenericHandler/include/ and in ... /GenericProber/include For example, for the type phEventResult_t see the header file phEvent.h
