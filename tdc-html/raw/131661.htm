SHARING_CONFIGURATION.domainsGetSiteAtPos()

The domainsGetSiteatPos() member function of SHARING_CONFIGURATION returns the site at the specified (x, y, z) position.

Syntax

int domainsGetSiteAtPos(int x, int y, int z) const

Parameter

Description

x

The position in the X dimension, starts from 0.

y

The position in the Y dimension, starts from 0.

y

The position in the Z dimension, starts from 0.
