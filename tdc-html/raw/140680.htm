Topic 140680

Test parameter table of a TPT

The test parameter table CSV file in an STPM Test program template (TPT) contains information about sets of parameters that can be applied to the tests to be used in the test program.

The file is best edited by importing it into the OpenOffice spreadsheet provided with TPT Admin. Editing is also possible in text editors, but this requires you to make sure yourself that all formatting is correct.

Syntax

Each row in the test suite table describes one set of test parameters. The table contains these columns:

  • Test Suite Name: The name of the test suite in the test program to which the parameters apply. The test suite must be defined with this name in the test suite table.
  • Test Method: The name of the test method being executed in the test suite.
  • Param: Each of these named Param contains the name and value for one parameter that is passed to the test method.

    You can create as many parameter columns as desired. Each column must have the title Param.

    Parameters must be specified in the column the form <name>=<value>, for example, output=None.
