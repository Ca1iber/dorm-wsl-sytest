Equation set review

The creation of a wavetable assigns actions to edges which define the shape of the needed waveforms for each signal pin of the device. The Equation Set defines the position in time for each edge. The syntax used allows each edge to be assigned a time using fixed values and or equations and variables. The flexibility the equation system allows for a variety of definition schemes that are dependent on the complexity of the device's timing requirements and the test application being developed (characterization or production, for example). The following screen shot shows an equation setup for the waveform examples developed for the wavetables. The definition scheme sets the edges to locations scaled from the period. Notice that this timing setup is used with both the physical syntax wavetable and the logical syntax wavetable.

# **************************************************
#  Basic wavetables for an EBT lesson example
# **************************************************

EQNSET 1 "Example Timing"

SPECS
T        [ns]    # Tester cycle time

TIMINGSET 1
period = t

PINS Address_bus
d1 = 0
d1 = T/3
d3 = 2 * (T/3)

PINS Datain_bus
d1 = 0

PINS Dataout_bus
r1 = T/2

PINS CS_
d1 = 0
d2 = T/4
d3 = 3 * (T/4)

PINS WE_
d1 = 0
