PULSE_SEARCHING

Subtopics

  1. init()
  2. setDetectionThreshold()
  3. execute()

When performing measurements on pulsed data, such as EDGE, GSM, 802.11a/b/j/g/n/ac, and WiMax, it is important to compute your results with the ‘ON' portion of the capture. This Test-Method API takes in captured waveform data and searches for pulses.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PulseSearching.h.
