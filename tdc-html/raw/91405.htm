Topic 91405

Set logfile path

The report window allows you to set a path to the data log file.

Procedure

  1. If the Log File menu item is not visible you enable it by selecting the production settings in the Operation Control window. The window Testflow Settings Mode opens.
  2. Select Report Formatter in this window. The Report Formatter window opens.
  3. Select EventFormatter in the Selection field.
  4. Click Select. Now the report window menu bar shows the Log File menu.
  5. Click and select Save Datalog Stream and Clear. The Save & Clear Datalog Stream and Clear window opens.
  6. Select a path and click OK.

Results

Now the path to the data log file is set.

What to do next

Open a terminal and go to the log file directory and look for the data log file.

Note After you have run a test with event logging on, this file should grow in size.
