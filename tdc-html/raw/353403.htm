TDR connectivity checker

Subtopics

  1. Launching TDR connectivity checker
  2. Setting up preferences for TDR measurements
  3. Executing the measurement
  4. TDR measurement report

A TDR connectivity checker examines the connection status of the DUT board or probe card with time domain reflectometry (TDR) measurement.

TDR measurement is a technique to measure the time the signal takes to travel through a transmission line and to be reflected back.

The TDR Connectivity Checker module in TP360 measures the propagation delay of signals going through the electrical trace lines on an application DUT board or probe card, by which potential connectivity issues can be detected.

The TDR measurement is applied in TP360 by the following procedures:
  • Launching TDR connectivity checker: Launch the module in TP360 and select the testflows and sites for connectivity check.
  • Setting up preferences for TDR measurements: Set up level, timing, and limits for each pin for the TDR measurement.
  • Executing the measurement: Run the measurement and view the report for connectivity check.

After the measurement is completed, the TDR measurement report is generated showing the connection status of measured pins.
