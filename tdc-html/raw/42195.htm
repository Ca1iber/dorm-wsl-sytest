Topic 42195

Parameter: handler_bin_ids and prober_bin_ids

Holds the IDs of the equipment bins. The IDs used in the array match the bin names as known to the equipment's communication protocol.

The IDs in the array are used by so-called ‘message based' equipment, which identify bins over the GPIB or RS-232 interface.

When equipment is connected via a GPIO interface, the bin IDs are only used for message and error logging of the driver, and to permit the "mapped-hardbins" or "mapped-softbins" binning modes. For equipment connected via a GPIO interface, the bin naming is free, but it should match the equipment documentation to avoid confusion.

The definition of handler_bin_ids or prober_bin_ids is optional, if the "default" bin mapping is used. It is mandatory, if either the "mapped-hardbins" or the "mapped-softbins" method is used.

Driver default: no bin ids

Changeable at run-time: yes

Applicable for: handlers or probers, respectively

Example: handler_bin_ids: ["A" "B" "C" "D"]
