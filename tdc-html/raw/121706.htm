Topic 121706

RESULT_AREA_CONFIG

The RESULT_AREA_CONFIG API specifies the number and size of result areas used for digital hidden upload.

Note Result areas reduce the available memory and accessing a large number of them may impact your test times. Therefore, the total number of allocated result areas should be minimized and stay below 465 in total. That is, the sum of all TMU, digital, and DC result areas must not exceed 465. Out of this, 15 areas are reserved as minimum for TMU and a maximum of 100 areas can be allocated for TMU.

Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ResultAreaConfig.h.

Constructor
RESULT_AREA_CONFIG(const STRING& pinList)
Parameter

pinList

List of pin or port names, separated by comma.

Use @ for all pins.

The constructor specifies the list of pins to which the result area configuration will be applied.

Member functions
  • appendArea()
  • activate()
  • activateWithoutOverwrite()

Member functions

appendArea()
RESULT_AREA_CONFIG & appendArea(const STRING & areaId, const INT size)
Parameters

areaId

Unique string, cannot use the same identifier twice.

size

Size of the area in bytes.

Creates a result area with the given area identifier and size an appends it to the previously defined result areas.

activate()
RESULT_AREA_CONFIG & activate(void)

Activates the result areas defined beforehand and deletes all currently active area definitions.

activateWithoutOverwrite()
RESULT_AREA_CONFIG & activateWithoutOverwrite(void)

Activates the result areas defined beforehand and appends them to the current active definitions, without deleting active definitions.

release()
void release()

Deletes all active result area definitions.

removeAllAreas()
void removeAllAreas()

Removes the result area configuration for all pins and all sites.

Example

ON_FIRST_INVOCATION_BEGIN();

    // Define resConf for all digital capture pins
    RESULT_AREA_CONFIG resConf("p1,p2,p3,p4,p5,p6,p6,p8");

    // Allocate and map memory to identifier
    resConf.appendArea("16KBITArea",3072).appendArea("128KBitArea",17408).activate();

ON_FIRST_INVOCATION_END();
