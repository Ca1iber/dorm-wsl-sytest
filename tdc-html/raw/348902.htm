download()

Downloads vector data to a pattern in runtime.

This function can only work with runtime data. It cannot be put into RDI_BEGIN/RDI_END() because it can only edit vector data and cannot execute vectors. It does not support insertSub().

Supported runtime commands
Function Data type More information
writeVec(string rtv, int vecPos) vector <ARRAY_I>: Different vectors per site. writeVec()
ARRAY_I: The same vector on all sites.

writeBit(string rtv, int bitPos)

expectBit(string rtv, int bitPos)		 vector <ARRAY_I>: Different bitStream per site. writeBit()

expectBit()
ARRAY_I: The same bitStream on all sites.

writeData(string rtv, int bitNum, int bitPos)

expectData(string rtv, int bitNum, int bitPos)		 ARRAY_I or ARRAY_LL: Different data per site. writeData()

expectData()
Int or long long: The same data on all sites.
writeParData(string rtv, int bitPos) ARRAY_I or ARRAY_LL: The different data per site. writeParData()
Int or long long: The same data on all sites.

Syntax

download();
A statement example that download() works together with write...() and expect...() commands:
rdi.smartVec().pin(pName).write...("rtData",...).download();
rdi.smartVec().pin(pName).expect...("rtData",...).download();

Hidden vector download

If this download() command is used with SmartRDI's NON_BLOCKING execution, it can hide the vector data download during the execution. This action is called Hidden Vector Download (HVD).

If you have used a specific ID for a action in the RDI_BEGIN()/RDI_END(TA::NON_BLOCKING) block, you must use copyLabel(false) together with download() to avoid the concurrence of result uploading and pattern generation.

If you have used dc() or hwRelay commands in the preceding block, the NON_BLOCKING action starts to be executed in the second run. The reason is that HVD can break the MSET and DC event download. See the example.

Examples

download() code structure

ARRAY_LL rtData = ...
rdi.runTimeVal("rtD", rtData);

//Download value into the existing pattern label "abc"
rdi.smartVec().label("abc").copyLabel(false).pin("D1").writeData("rtD",8).download();

//Create a new label "cde" based on code and download runtime data in it. 
rdi.smartVec().pin("D2").defaultBit(1).writeData("rtD",8,10).labelName("cde").download();

Hidden vector download

ARRAY_LL rtData= ...
rdi.runTimeVal("rtData", rtData);

RDI_BEGIN();
...
RDI_END(TA::NON_BLOCKING);

rdi.smartVec().pin(pinA).writeData("rtData",8).labelName("abc").download();
...
RDI_WAIT_TEST_DONE();

Using copyLabel(false) and download() together

RDI_BEGIN(); 
  rdi.func("id1").label("label1").execute(); // measurement
  rdi.digCap().pin(A).samples(5).execute();  // measurement 
RDI_END(TA::NON_BLOCKING);

rdi.smartVec().label("abc").copyLabel(false).pin("pinA").writeData("rtD",8).download();
// HVD to the existing pattern "abc" without creating a new pattern.

RDI_WAIT_TEST_DONE();

NON_BLOCKING starts at the second run

RDI_BEGIN()
  rdi.dc().pin("dig").vForce(1).iMeas().execute();
RDI_END(TA::NON_BLOCKING)

rdi.smartVec() label("abc").copyLabel(false).pin("pinA").writeData("rtD",8).download();

RDI_WAIT_TEST_DONE();
