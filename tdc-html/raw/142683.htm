Memory Pattern Validation Tool Enhancements

  • The operation and assignment type operators are now displayed in a verbose way. For example, a statement like myVar++ is displayed as myVar = myVar + 1.
  • MPVT now detects static refresh patterns and adjusts the compiled cycle information accordingly. If you specify a cycle number in the code selector and click Show Source, the tool assumes that the cycle number you specified includes static refresh cycles. It filters out the static refresh cycles and points to the corresponding source node.
  • In MPVT the Scope Limited Variable Behavior is currently always enabled. To get consistent behavior of test programs between running the program in SmarTest and validating it in MPVT, make sure you compile your program using the -lvs compiler option when you intend to execute it after validation with MPVT. In a future release the Scope Limited Variable Behavior can be disabled.

Benefit

MPVT reflects the new compiler features and helps you finding the source easily even if static refresh is included.

Note MPVT becomes obsolete in MTP 7.5.0, MTP 7.4.5, and future versions.
