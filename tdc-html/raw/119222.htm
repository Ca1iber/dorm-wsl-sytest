Inserting a floating test suite in the testflow sequence

This window displays all the existing floating test suites.

After Creating a floating test suite on the Test Suites page, you can add it to the testflow sequence with this dialog.

Insert Mode

  • Insert the test suite

    The floating test suite is inserted to the testflow sequence as a Run and Branch node.

  • Insert a copy of the test suite

    A new test suite, which is the copy of the floating test suite, is added to the testflow sequence as a Run and Branch node.
