Patterns

Pattern blocks in STIL have a one-to-one relationship to V93000 pattern files (BINL files). Exceptions to this rule occur when a pattern is realized across several V93000 ports. A pattern master file (PMFL) is always generated as well as a pattern burst (BURST) file. The pattern master file is located in the ../vectors directory and the pattern burst and all pattern files are located in the ../vectors/patterns directory.

V93000 pattern files consist of:

  1. Pattern header
  2. Comments
  3. Pin data

Each V93000 pattern defines a vector label based on the STIL Pattern block domain name. Repeating signals, as may be found in a STIL loop pattern statement, are translated to repeat vectors optimized for the target V93000 model. STIL Reader is capable of calculating the optimal number of repeating signals that would warrant the usage of the V93000 repeat statements. If desired, this may be configured through the repeat_break settings file parameter (see Test-processing STIL Reader setup options).

V93000 vector comments can be generated from a variety of STIL sources. By default, only STIL annotations are promoted to V93000 comments. The vector_comment_source setup file parameter can be used to promote a wide variety of STIL comment types to V93000 vector comments (see Translation-related STIL Reader setup options).

V93000 vectors may be compressed in a combination of two ways:

  • Compressing data on a per-pin basis using the ALDC algorithm (use_vecc parameter).
  • Compressing complete pattern files using the GZIP algorithm (gzip_patterns parameter).

STIL Reader supports both compression techniques and is controlled through the settings file (see Test-processing STIL Reader setup options).

Multibit pattern processing

Every time a multibit waveform group is encountered in the vector, the appropriate physical waveform index is used in the pattern.

Example: 

Signals {
 data InOut;
}

SignalGroups {
  Data = 'data' { DataBitCount 2; }
}
VPattern P1 {
  ...
  V { Data = tt; }
  V { Data = TT; }
  V { Data = Tt; }
  V { Data = tT; }
  ...
}

The sample input produces the following data sequence in the VECD or VECC command: 0321.
