GIO_ERROR gio_set_lock_wait ( IDID  id,
bool_t  flag 
)

Set lock waiting flag.

The state of the lock waiting flag affects the behavior of sessions which have been locked using gio_lock(). When flag is true, operations which encounter a locked session will wait for the lock to be released (or for a timeout); when flag is false, these operations will return an error (GIO_ERR_DEVICE_LOCKED) instead.

GIO_ERROR gio_set_termchr ( IDID  id,
int  termChar 
)

Set termination character.

If termChar is non-negative, it becomes the termination character for the session id. The termination character is used to signal the end of data for gio_read().

If termChar is -1, subsequent gio_read() operations will not look for a termination character.

GIO_ERROR gio_set_timeout ( IDID  id,
uint32_t  milliSeconds 
)

Set timeout.

gio_set_timeout() sets the I/O timeout for the session id to milliSeconds. After this call, operations which don't complete within milliSeconds milliseconds will be aborted and will return GIO_ERR_IO_TIMEOUT.

If milliSeconds is zero, timeouts are disabled (i.e., the timeout interval becomes infinite).

Attention
There is no guarantee that any operation will time out after exactly milliSeconds milliseconds. Scheduling delays and timer granularities (which depend on the operating system and/or the system configuration) affect the timeout calculation. It is however guaranteed that a timeout will occur after at least the given interval.
