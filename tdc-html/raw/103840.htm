UpdateResultDisplay()

For wafer sort, this API clears the wafer sort result display before a new wafer is started and updates the header/sub-header of the test result. For package test, this API updates the header/sub-header of the test result before a new package is started.

The following two figures show the header and sub-header of the test result for wafer sort and package test.

SUCCESS will be returned if no error occurred. Otherwise, an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • The local session does not exist.
  • Failed to update the result display.

RECOVERABLE
Parameters

I/O

Parameter

Description

I

SESSION_ID

The ID of the SmarTest session to work with.

I

HEADER

(optional) The header to display on the test result window.

I

SUBHEADER

(optional) The sub-header to display on the test result window, generally the wafer number or the package ID.

Prototype

ParamList inputParams;
Status syncCommand("UpdateResultDisplay", inputParams, sessionID);

Example

string sid = LOCAL_SESSION_ID;
ParamList inputParams; 
inputParams["HEADER"] = "wafermap";
inputParams["SUBHEADER"] = "wafer number: 1";

Status retVal = syncCommand("UpdateWaferDisplay", inputParams, sid);
if ( retVal.isError() ) 
{
cout<<"error code= " << retVal.code() << "description="
    << retVal.text() << endl;
}

Functional changes

  1. Introduced in SmarTest 6.5.0
