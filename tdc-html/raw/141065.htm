DIGITAL_OFFSET_SEARCH_PINS.transitionDetection()

Sets the detection type for the transition search.

Syntax

DIGITAL_OFFSET_SEARCH_PINS& transitionDetection (DIGITAL_OFFSET_SEARCH::TR_DETECTION_TYPE detectiontype);
Parameter

Parameter

Description

detectiontype

The transition detection type.

See the available types in the following table.
List of available options of parameter: <detectiontype>

Option

Description

DIGITAL_OFFSET_SEARCH::PF

Pass/fail transition

DIGITAL_OFFSET_SEARCH::ECL

Use the specified error count limit to consider a test pass or fail.

If the error count of a test is greater than this limit, the test is considered fail. Otherwise, the test is considered pass.

Return value

A reference to the DIGITAL_OFFSET_SEARCH_PINS object.
