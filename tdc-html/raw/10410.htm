Topic 10410

System preparation by firmware commands

Before you create a new test configuration, you must define some control parameters. The command DSCP, DSCP? - (Define System Control Parameter) is provided for this purpose. Its parameters let you set the maximum numbers you can use to identify:

  • device cycles
  • waveform sets
  • timing sets
  • level sets
  • dps sets
  • pmu sets
  • device cycle sets
  • routing sets
  • analog sets

These are collectively referred to as parameter sets.

Note When you execute DSCP, DSCP? - (Define System Control Parameter), all sequencer instructions and all existing sets are reset to the power-on defaults.

You must consider each of these parameters and the consequential effect it has on your test.

At power-on, the DSCP command assumes the following default values.

DSCP 256, 16, 256, 32, 32, 16, 16,32,256, 256

The default values therefore allow you to use:

  • a maximum of 256 device cycles
  • a maximum of 16 waveform sets
  • a maximum of 256 timing sets
  • a maximum of 32 level sets
  • a maximum of 32 DPS sets
  • a maximum of 16 pmu sets
  • a maximum of 16 device cycle sets
  • a maximum of 256 routing sets
  • a maximum of 256 analog sets

The configuration represented by these values is adequate for most applications. It also gives the maximum available values as far as combined memory allocation is concerned. The number of timing sets can be further increased to a maximum of 512, but the numbers of other sets have to be decreased at the same time.

Parameter sets are stored in the Sequencer Memory together with test instructions (see Vector Setup Commands). You can use the DSCP command to set the numbers of sets as required, provided you stay within the fixed maximum amount of memory reserved for them.

You can check the amount of free memory with the query DMAS, DMAS? - (Define Memory Area Size).
