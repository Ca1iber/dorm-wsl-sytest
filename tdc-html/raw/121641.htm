SharedVBump syntax

This test method can change the supply voltage level during a functional test. It is required for the VBump Executor test suite.

Syntax

Name

Type

Default

Comment

DriverSharing Config File

String

 

Name of sharing configuration file used.

The file must be located in the configuration subdirectory of the current device directory.

See Creating a sharing configuration file for details.

Bump Source

String

VDD

The current VBump resource

High Power

String

No

This parameter can be No or Yes.

Set it to No if the DPS32 max current is smaller or equal to 1.5 A and to Yes if the DPS32 max current is greater than 1.5 A.

Result Pin List

PinString

@

The list of result pins for the functional test

RESETn

PinString

 

Name of the reset pin.

This is an optional parameter.

Utility control

Depending on the desired effect, there are different keywords for specifying the utility line settings for SharedVBump in the utility control section of the sharing configuration file:

  • To bump the voltage on VDD:

    vbump_vdd; (<equation>); (<utility setting>); (<pin substitution>)

    For example: vbump_vdd;();(U3=0x000&0xfff);()

  • To bump the voltage on VDDQ:

    vbump_vddq; (<equation>); (<utility setting>); (<pin substitution>)

    For example: vbump_vddq;();(U3=0x777&0xfff);(DEVICE _SUPPLY=VDDQ)

  • To bump the voltage on both VDD and VDDQ:

    vbump_vdd_vddq; (<equation>); (<utility setting>); (<pin substitution>)

    For example: vbump_vdd_vddq;();(U3=0xCCC&0xfff);()

  • To bump the voltage on both VDD and VDDQ to high power:

    vbump_hp_vdd_vddq; (<equation>); (<utility setting>); (<pin substitution>)

    For example: vbump_vdd_vddq;();(U3=0xCCC&0xfff);()

For information on the syntax, see Sharing configuration file.
