INGV - (INsert Generate Vectors)

The INGV (INsert Generate Vectors) command inserts a GENV instruction into the sequencer program of the label currently activated for editing. The parameter of the inserted GENV instruction that specifies the location of the vectors has the same value as the STVA instruction of the label. For more information on the GENV and STVA instructions see the command SQPG, SQPG? - (SeQuencer ProGramming).

In contrast to the SQPG command, INGV readjusts the vector area so that the active vectors of later instructions are preserved. If the additional vectors of the new instruction cannot be accommodated by the inactive vectors within the vector area segment of the label, INGV also expands the vector area and updates the STVA instructions of the labels that use later segments of the vector area.

INGV can only be issued after the label into which the GENV instruction is to be inserted has been activated for editing with the TSTL command.

Syntax

INGV{cmd_No}, {num_vec}

Parameters

cmd_No

The command number before which the GENV instruction is to be inserted.

num_vec

The number of vectors that are to be generated by the GENV sequencer instruction.

Application

Edit command in Pattern Tool.

Errors

An error is generated if:

  • There is insufficient channel memory.
  • There is insufficient disk space (offline operation only).
  • No label has been activated for editing.
  • The number of inserted vectors is zero.
  • The specified command number is out of range.

Example

> SQPG? ALL,(@)
< SQPG 0,STVA,0,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,RPTV,10,5,,(@)
< SQPG 3,STOP,,,,(@)
< SQPG 4,STVA,16,,,(@)
< ...
> TSTL "test_1",(@)
> INGV 3,11
> SQPG? ALL,(@)
< SQPG 0,STVA,0,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,RPTV,10,5,,(@)
< SQPG 3,GENV,11,,,(@)
< SQPG 4,STOP,,,,(@)
< SQPG 5,STVA,32,,,(@)
< ...

This example inserts a GENV instruction for 11 vectors before command 2. Note that the memory type is SM, as in command 0, and that the address of command 5 has been increased.

Functional changes

  1. Introduced before SmarTest 6.3.2
