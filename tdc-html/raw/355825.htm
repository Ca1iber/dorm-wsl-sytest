XPS256 programming - Open loop protection

Open loop protection of the XPS256 means how the force pin (P#) and the sense pin (PS#) ) as well as the ground sense pin (GS#) and the common ground are connected internally to ensure that the feed back input of the control loop or the output stage respectively is not open in case the required connection at the DUT or on the DUT board is (unintentionally) open.

There are two states on which the open loop protection can be set:
  • DIODE:

    The sense pins are internally connected to the force pins via two anti-parallel diodes.

    This is the default state.

    This is the recommended setting if for the voltage drop measurement and monitoring the maximum voltage drop both on the force line and on the return line as been set to be ≤ 0.5 V.
    Note This setting does not make a low‑impedance connection on the DUT or on the DUT board unnecessary. If there is no force to sense connection at the DUT or on the DUT board, the forced or measured voltage will change within the range defined by the forward voltage of the diodes.
  • NONE

    There is no internal connection between the force and sense pins.

    This is the required setting if for the voltage drop measurement and monitoring the maximum voltage drop both on the force line and on the return line as been set to be > 0.5 V.
    Note If the low‑impedance force to sense connection at the DUT or on the DUT board is opened (unintentionally), the output stage and the digital control no longer receive a voltage feedback signal. An active XPS256 channel may then force a voltage up to the supply voltage of the output stage and voltage measurements will be invalid.

Rules

These rules must be considered:
  • For a maximum voltage drop > 0.5 V, the open loop protection must be set to NONE.
  • In the DC Scale Safety editor the Vdrop Disco parameter must be set to ON if the open loop protection is set to NONE.

Programming

The status of the open loop protection can be defined in the default settings for the testflow, in the level setups, and by test method APIs:

  • Default values:

    The default state of the open loop protection can be set in the Open Loop Protection column of the DC Scale Safety editor.

  • Level setup in DPS operating mode:

    Use the openLoopProtection() parameter of the DPSPINS resources.

  • Setup in PMU operating mode:

    Use the openLoopProtection() function of the SPMU_PIN_TASK test method API.

The status can also be changed in the Hardware view for the DPS operating mode and for the PMU operating mode.
