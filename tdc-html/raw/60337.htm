Creating a new format

Procedure

  1. In the timing diagram window select Format > define new format. The Define format window appears.
  2. In the Format name text box, enter a name for the format.
  3. Use Filter (regex) to filter the elements of the pin components, the group list, and the pin pairs:
    1. Type a regular expression, for example: 3
    2. Press Enter

      All elements according to your filter expression are displayed in the lists. Except, for the group list the following conditions must be fulfilled:

    • At least one active group member
    • No DC pins
    • All active group members belong to the same port
    • All active group members must have the same frequency mode
    • IO modes:

      All active group members must have the same IO mode (I, O)

      or

      some active group members are I, the others are IO (O not allowed)

      or

      some active group members are 0, the others are IO (I not allowed)

    • Pins have the same waveforms and timing setup (no mixed edge syntax is supported; all pins need to use "d" or "s/f" syntax when describing the drive edges, but not a mixture of both).
  4. Enter the alias set name in the Pin Alias Set list. Then the pin aliases are shown in the pin components list.

    If you choose DEFAULT from the Pin Alias Set list, no alias set is used and the package pin names are shown in the pin components list.

  5. Select the pins you want to display. For each pin, pin group or pin pair:
    1. Click the pin, pin group or pin pair in the respective list at the left of the window.
    2. Click the Copy button associated with that list.
  6. If you have selected pin pairs, select the desired signal algorithm by choosing None, Differential View or Common Mode from the Signal Algorithm list.
  7. Click Done.
