SOURCESYNC_TEST.startCycle()

Specifies the number of the tester cycle where to start a source-sync test.

Syntax

SOURCESYNC_TEST& startCycle (const string& startCycle);
Parameter

Parameter

Description

startCycle

The number of the tester cycle where to start a source-sync test. 0 represents the first tester cycle.

You can specify multiple start cycles separated with ";" in order to start multiple source-sync tests. For example, "0;129; 258".

Related information

SOURCESYNC_TEST.stopCycle()

Functional changes
