emapLocation()

This function specifies a location where error maps are stored.

For information about the error map size, refer to PS1600 error map size.

Syntax

emapLocation(TA::EMAP_LOCATION loc);
List of parameters

Parameter

Description

TA::EMAP_LOCATION loc

The location where error maps are stored.

List of available options of parameter: <TA::EMAP_LOCATION loc>

Option

Description

TA::TP

The location is the test processor on the card. The default value.

TA::RAM

The location is the unused vector memory on the tester.

Example

rdi.emapLocation(TA::RAM);
rdi.smartVec().readMode(TA::EMAP)

RDI_BEGIN();
  rdi.smartVec().pin("A").readBit(10000).execute();
RDI_END();

Functional changes

  1. Introduced in SmartRDI 2.4.0
