rdi.func().pin()

Specifies the pin(s) for the subsequent FUNC actions. It indicates the ending of the setups for the previous pin and the start of the setups for the specified pin.

Do not specify different types of pins in the same function pin(). To set up different types of pins in the same line of code, specify different types of pins in separate functions of pin() within the same rdi ... execute() block.

Syntax

rdi.func().pin(const string& sPin);
Parameter
Parameter Description
sPin The pin on which the following setups will be done. Its value can be a pin, a pin group, a port name as a pin group, the pins or pin groups separated with comma, or all pins.

Return Value

A reference to the FUNC object.
