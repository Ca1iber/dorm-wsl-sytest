Topic 118824

SmartCalc multithreading considerations

Subtopics

  1. SmartCalc "Thread per site" and "Common thread"
  2. Thread safety

SmartCalc (SMC) uses multithreading techniques, but it goes beyond. It provides high-level APIs that hide most of the internal thread handling allowing convenient parallel multisite calculation and hidden data upload and calculation (while a different test is running).

This section gives a brief overview of requirements, which need to be met in order to having SmartCalc working properly.

Functional changes

  1. Introduced in SmarTest 6.5.3
