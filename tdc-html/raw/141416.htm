MTP_MEMORY_TEST.getMemoryPort()

Returns an object of MTP_MEMORY_PORT, which is used to retrieve the memory test results of the patterns in the specified port.

Syntax

MTP_MEMORY_PORT& getMemoryPort (const STRING & port) const;
Parameter

Parameter

Description

port

A port name.

Related information

Functional changes
