Topic 96733

Deleting a sequencer instruction

The simplest method to delete an instruction is to use the DELI edit command. In the case of a vector generating instruction, however, using DELI will lead to similar difficulties as using INSI and SQPG for insertion: the following GENV and RPTV instructions of the label will refer to incorrect waveform DC/DC power units after the deletion because DELI leaves the vector areas as they are.

Therefore, you should use the DELV edit command to remove vector generating instructions. DELV is primarily intended to reduce the length of sequencer constructs, but if the number of vectors to be deleted equals the length of the instruction, the instruction itself will be overwritten by the dummy instruction NOP. DELV updates the vector areas of the pins as required. Afterwards, you can delete the NOP instruction with DELI.

Procedures

Procedure (general case)

  1. Activate the label for editing with the TSTL command.
  2. Use the edit command DELI to delete the instruction.

Example (general case)

For example, you can remove the CTIM instruction which was introduced in the general case example of Inserting a sequencer instruction from the first label of the standard example as follows:

  1. TSTL "test_1",
  2. DELI 7,1

Procedure (vector generating instructions)

  1. Activate the label for editing with the TSTL command.
  2. Use the DELV command to remove the vector area sub-segment for this instruction.
  3. Delete the resulting NOP instruction with DELI.

Example (vector generating instructions)

If you want to remove again the initial GENV instruction that was added to the program of test_1 in the figure of Inserting a sequencer instruction, proceed as follows:

  1. TSTL "test_1",
  2. DELV 6,10
  3. DELI 6,1
