Filtering test result data

Filtering data hides certain rows in the tables of the Integrated Result Tool without affecting the statistical and graphical evaluations. You can filter data by specifying conditions in the table filter, by showing just rows that are similar to the selected one, or by hiding pass or fail tests directly.

About this task

Filter data in a summary, raw data, or stream data table when you want to concentrate on comparing just some of the rows, without being distracted by the others.

Note When you want to prevent certain records from being included in the evaluation, exclude that data instead of filtering it out.

Before you begin

The data you want to filter must be displayed in one of the tables of the Integrated Result Tool (summary view, raw data view, Stream data view).

Procedures

Filtering rows by setting conditions

  1. In the table you want to filter, double-click in the table filter row, in the column for which you want to set a condition.

    A text insertion mark appears in the field and a drop-down list at the right side.

  2. Enter the desired condition in the field.

    In text fields:

    • To find all rows where the value in the column begins with specific text, enter that text in the table filter field.

      For example, entering READ in the TS column, displays rows with the test suites READ_SINGLE, READ_MULTI, or READDRESS, but not with the test suites Readdress or WRITE_READSTOP.

    • To find all rows where the value in the column contains specific text, enter a regular expression that matches that text in the table filter field.

      For example, entering READ. (with a period) in the TS column displays rows with the test suites READ_SINGLE, READDRESS, Readdress or WRITE_READ_STOP, but not WRITE_READ.

      In number fields:

    • To find all rows containing an exact value, enter that number in the table filter field. (You can enter integers; they are converted to floats before they are compared.)

      For example, entering 2 displays all rows that contain exactly 2 in that column.

    • To find all rows containing one of several exact values, enter those numbers in the table filter field, separated by commas.

      For example, entering 2,3,4 displays all rows that contain exactly 2, exactly 3, or exactly 4 in that column.

    • To find all rows with values larger than a particular number, enter that number followed by a ~ tilde.

      For example, entering 2~ displays all rows that contain a value that is larger than 2 in that column.

    • To find all rows with values equal to or larger than a particular number, enter that number, a comma and the same number followed by a ~ tilde.

      For example, entering 2,2~ displays all rows that contain a value that is equal to or larger than 2 in that column.

      To find all rows with values smaller than a number or smaller or equal, use the method described above but put the tilde before the number.

      For example, entering ~2 displays all rows that contain a value that is smaller than 2 in that column and entering 2,~2 displays all rows with a value that is equal to or smaller than 2.

    • To find all rows with values between two numbers (exclusively), enter those numbers separated by a ~ tilde.

      For example, entering 2~3 displays all rows that contain a value in that column that is between 2 and 3 (but not including either 2 or 3).

    • To find all rows with values between two numbers (inclusively), create a comma-separated list of the range and the two endpoints.

      For example, entering 2,2~3,3 displays all rows that contain a value in that column that is between 2 and 3 (including 2 and 3).

    • To find more complicated intervals, specify individual numbers or ranges separated by commas.

      For example, entering ~5,-2~-1,-1,1~2 displays all rows that contain a value in that column that meets any one of these conditions:

      - Smaller than -5

      - Bigger than -2 and smaller than or equal to -1

      - Bigger than 1 and smaller than 2

      Note that the drop-down list in the fields lets you access the most recently entered conditions and, in some fields, predefined values.

  3. If you want to specify additional conditions in other columns, repeat steps 1 and 2 for those columns.

    Only rows are displayed that match all conditions.

Filtering test by pass/fail result in raw data and stream data views

From the shortcut menu in the view that you want to filter, choose Filter > Show Only Pass or Filter > Show Only Fail (depending on the desired result).

Note This is a shortcut for entering Pass or Fail, respectively, in the P/F column of the table filter.

Filtering by similarity in summary tabs

In test and bin summary tabs, you can restrict the display to only similar rows:

  1. Right-clicke of the rows on which you want to focus.
  2. From the shortcut menu, choose Filter > Show Similar.

    In test summary tabs, this restricts the display to those rows that have the same test suite and test names as the selected row.

    In bin summary tabs, this restricts the display to those rows that have the same Hbin or Sbin value (depending on which tab it is) as the selected row.

    Note This is a shortcut for entering the values for test suite and test name, Hbin, or Sbin from the selected row into the table filter.

Unfiltering

To remove the effect of a filter and again display all records in a table, click the small field at the left of the Table filter in that table.

Results

When you filter a table with any of the methods described, only those rows that match all the specified conditions are displayed in the table. (This does not affect the evaluation of the data; hidden records continue to be considered for statistical evaluations and result graphs.)

When you unfilter a table, all records from the corresponding data store are again displayed.
