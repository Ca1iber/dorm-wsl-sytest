DSP_UNIT_MAT

This API stores a unit matrix of given dimension specified by the second argument into the array specified by the first argument.

result [i][j]  = 1, when i = j or
result [i][j]  = 0, when i ≠ j

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_UNIT_MAT(ARRAY_D& result, INT dim);
DSP_UNIT_MAT(DOUBLE *result, INT dim);
DSP_UNIT_MAT(ARRAY_COMPLEX& result, INT dim);
DSP_UNIT_MAT(COMPLEX *result, INT dim);
Parameters

I/O

Parameter

Description / Range

O

result

Unit matrix (two-dimension array)

I

dim

Row and column dimension of result matrix

1 ≤ dim ≤ 256

Example

DSP_UNIT_MAT(matrix1, 20);

This example creates unit matrix matrix1 (20 by 20) as follows:

DOUBLE matrix1[20][20];
int i, j;
for(i=0; i<20; i++)
  for(j=0; j<20; j++) {
     matrix1[i][j] = 0.0;
     if (i=j)
     {
         matrix1[i][j] = 1.0;
     }
  }
