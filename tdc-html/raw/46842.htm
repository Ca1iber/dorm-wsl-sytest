Parameter: per_wafer_probe_cleaning_rate

If the prober supports probe needle cleaning, an automatic cleaning may be performed every time a given number of wafers (or of die groups in case of multisite probing) have been processed.

This parameter defines the cleaning rate. If the parameter is set to 0, or if it is not defined at all, no automatic probe cleaning will be done based on wafer counts. If set to a positive number, an automatic probe cleaning will be performed after this number of wafers have been processed.

Per wafer probe needle cleaning may be combined with per die or per bin probe needle cleaning (see also the configuration parameters per_die_probe_cleaning_rate probe_cleaning_hardbins and probe_cleaning_softbins).

Driver default: 0

Changeable at run-time: yes

Applicable for: prober

Example: per_wafer_probe_cleaning_rate: 1
