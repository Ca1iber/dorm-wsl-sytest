Topic 104219

Using framework parts in your own tests

You can incorporate parts of the Best Practices frameworks into your own existing testing solutions.

About this task

You may want to add parts of Best Practices frameworks to your own solutions, for example, to add tests or to take advantage of new test system features, code for which is included in the frameworks.

Before you begin

You should have an existing, working testing setup, including test patterns.

Also, make sure that you are using the version of the MTP software with which the Best Practices frameworks you are using were included. (Or a newer version.)

Procedure

  1. Copy the level, timing, and vector setup information for the part of the frameworks in which you are interested to the appropriate device directory.

    The files and their relationships are described in the framework documentation included with each framework.

  2. Adapt the pin names, either by changing the names in your pin configuration file or by changing the names used in the framework files you have copied.
  3. If you are adding new functions, create device accesses and program code as needed.

Results

The chosen parts of the frameworks are now part of your testing solution.

What to do next

Compile and run the test.

Functional changes

  1. Introduced before SmarTest 6.3.2
