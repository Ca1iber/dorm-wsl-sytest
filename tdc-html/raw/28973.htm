DSP_EXPAND

This API copies each element (the specified number of times) of an array to another array.

DSP_EXPAND copies the specified elements of src to result. Each element is copied repeat times.

The following figure shows how each element is copied by DSP_EXPAND:

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_EXPAND(ARRAY_I& src, ARRAY_I& result, 
           INT repeat);
DSP_EXPAND(INT *src, INT *result, INT size, 
           INT repeat);
DSP_EXPAND(ARRAY_D& src, ARRAY_D& result, 
           INT repeat);
DSP_EXPAND(DOUBLE *src, DOUBLE *result, 
           INT size, INT repeat);
Parameters

I/O

Parameter

Description / Range

I

src

Source array

O

result

Result array

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

I

repeat

Number of times to copy each element of source array

repeat ≤ (size of result array) / size

Example

INT  source[4], result[6];
      .
      .
DSP_EXPAND(source, result, 2, 3);

Ifsourcehas the following elements:

 source[0]=5  source[1]=3  source[2]=2  source[3]=4

DSP_EXPAND returns the following toresult:

 result[0]=5, result[1]=5, result[2]=5,  result[3]=3, result[4]=3, result[5]=3

DSP_EXPAND copiessource[0]three times toresult, then copiessource[1]three times toresult. source[2] and source[3]are not copied toresultbecause size is 2.
