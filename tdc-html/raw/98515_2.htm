CYRM, CYRM? - (CYcle Resolution Mode)

The CYRM command serves two purposes:

  • It enables re-execution of a failed test in order to provide two bit error codes for all 8 receive edges. Note that this is only possible if DCRM is set to 1,PFC.
  • It ensures that except DCRM 1,PFC, no DCRM configuration is admitted in which several edges are combined to one recorded result.

CYRM can be issued for pins or pin groups. The pins must be configured as O or IO pins.

The CYRM? query returns the current settings.

CYRM

CYRM {resolution_mode}, [error_limit], {(pinlist)}

CYRM?

CYRM? {(pinlist)}

returns: 

CYRM {resolution_mode},[error_limit], {(pinlist)}

Parameters

resolution_mode

Defines the resolution mode. This can be:

CYCL

This is the normal operation mode. In spite of its name (which was coined at a time when the normal operation mode was one result per cycle), it simply means that the result resolution as defined with DCRM is to be applied. This is the default.

EDGE

This option

  • activates a mechanism by which a test that failed on the cycle level is re-executed in order to enable error map recording on the edge level. For details see Retrieving edge information by repeating the test.

    Note also that re-execution of the test can be blocked with the CYRP command.

  • prevents acceptance of any DCRM configuration that combines more than one edge result into one recorded result, except DCRM 1,PFC.

Note that the EDGE option is not available for pins which take part in a match loop.

error_limit

CURRENTLY NOT USED.

pinlist

The pin or pins to which this mode will be applied. You can also specify one or more pin groups or ports.

Application

Defines the results format of some error map result commands.

Example

CYRM CYCL,,(@)
CYRM CYCL,,(MatchLoopPin)
