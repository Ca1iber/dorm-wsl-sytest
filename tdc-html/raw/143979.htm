SOURCESYNC_DOMAIN

Subtopics

  1. SOURCESYNC_DOMAIN.pins()
  2. SOURCESYNC_DOMAIN.bufferPins()
  3. SOURCESYNC_DOMAIN.getPass()

Creates a domain that a source-sync test will apply to. An object of this class is created only with SOURCESYNC_TEST.domain().

Note Do not create any instances with this class.

This API is defined in the header file /opt/93000/mts/solution_tools/common/include/SOURCESYNC_DOMAIN.h.
