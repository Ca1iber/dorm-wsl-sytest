Topic 142604

Code structure with SmartRDI

Subtopics

  1. Basic rules for SmartRDI
  2. Multiport programming with SmartRDI

Describes how the programming with SmartRDI is structured in the test method.

The test method programmed with SmartRDI looks like below:

#include "testmethod.hpp"
#include "rdi.hpp"
...
void run()
{
    RDI_INIT(); 

    ON_FIRST_INVOCATION_BEGIN();
    {
        // Set up the test to be executed in the pattern‑based mode 
        RDI_BEGIN();
        {
            rdi.class1().pin("pinA").para1().para2().execute(); // With no measurement
            rdi.class2("idA").pin("pinB").para3().para4().execute(); // With measurement
        }
        RDI_END();

        // Set up the test to be executed in the code‑based mode
        rdi.class3().pin("pinC").para5().para6().execute();
    }
    ON_FIRST_INVOCATION_END();

    // Retrieve the test result
    XXX(data type) result=rdi.id("idA").getXXX();

    return();
}

The code above shows the following main elements of the SmartRDI code structure:

#include "rdi.hpp"
You must include the file rdi.hpp for each test suites that uses SmartRDI.
RDI_INIT()
In each test method class, all code programmed with SmartRDI needs to be put after RDI_INIT().
RDI block
The RDI block starts with API RDI_BEGIN() and is closed with RDI_END(). The RDI block holds the RDI commands that are converted as far as possible into individual pattern and are executed as pattern burst if the execution mode of the block has been set to the default value TA::BURST.
Note

DO NOT put any code that you would like to run in EACH execution into the RDI block.

The code inside the RDI block is executed only in the first run after build. This is required for generating pattern content.

The two macros RDI_BEGIN() and RDI_END() already contain the curly brackets { … } that enclose the code within the block. Nevertheless, we recommend using extra brackets as shown in the example above. This improves the readability of the code and simplifies correct indentation using the related Eclipse tool.

RDI command
Normal RDI commands begin with the RDI main class rdi, optionally define an RDI class to be used, followed by one or more member function calls of the defined class and are closed by execute() that is a member function of all RDI classes.

An RDI command can be divided into multiple lines using function cont().
