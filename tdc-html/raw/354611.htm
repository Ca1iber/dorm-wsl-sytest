XPS256 programming - Default values

For XPS256, global default values for parameters relating to the dynamic behavior and the protection of the hardware can be defined in the pin configuration for a test program. These default values override the system‑defined default values and can in turn be overridden by setting these parameters by DPSPINS resource parameters or TM APIs.

The global default values for parameters relating to the dynamic behavior can be defined in the DC Scale Regulation editor. The protection and safety related parameters can be defined in the DC Scale Safety editor.

The DC Scale Regulation editor is used to set global defaults for regulation parameters.

DC Scale Safety editor

The DC Scale Safety editor is used to set global defaults of parameters related to the safety of the hardware. The editor allows also specifying utility pins to be used for the hardware‑controlled shutdown of the pins.

Vdrop Hold time force

Specifies the time to wait when the maximum voltage drop is reached, before the Voltage drop force or Voltage drop return status flags are set.

These two parameters can be defined only in the DC Scale Safety editor.

Vdrop Disco

Specify whether to disconnect when the Voltage drop force or Voltage drop return status flags are set.

This parameter can be defined only in the DC Scale Safety editor.
Open Loop Protection open_loop_protection openLoopProtection()

Mode of the open loop protection to be set to DIODE (default value) or NONE.

The following rules apply to this option:
  • Vdrop Disco must be set to ON if the Open Loop Protection is set to NONE.
  • The parameter needs to be set to NONE if one of the max Vdrop parameters is set to a value ≥ 0.5 V.

See also XPS256 programming - Open loop protection and XPS256 programming - Voltage drop measurement.

Safetyln Pin

Specifies the utility pin to be used for the hardware‑controlled shutdown of the pin. For more information, refer to XPS256 programming - Safety line and DUT board disconnect.

This parameter can be defined only in the DC Scale Safety editor.
Monitor Pin

Specifies the pin to be used as output of the current monitor. For more information, refer to XPS256 programming - Current monitor.

This parameter can be defined only in the DC Scale Safety editor.

For more information, refer to XPS256 programming - Voltage drop measurement and XPS256 programming - Force and clamp currents.
