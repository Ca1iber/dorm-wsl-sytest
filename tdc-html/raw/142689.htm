Memory Test Viewer

The memory test viewer (see chapter Memory Test Viewer in Testing High-Speed Memory Devices) has been enhanced:

  • The user can now export all of data log file to a human readable format text file (ASCII export).
  • A filter function in the executions list reduces the amount of information displayed to Failed executions only (Select a data log file).
  • In a preferences window you can set the device path from the data log file. You can change now the default device path and reconstruction directory as well as the path to the BFM file by entering your own path information (Preferences).
  • To enhance processing time you can now limit the number of addresses for reconstruction (Preferences).
  • The BFM file format can be selected now to be either human readable or binary format (Preferences).
  • To ease your task of analyzing bitmaps you now can select to have the two bitmaps for Fail0 and Fail1 separated or combined (Preferences).
  • To reduce waiting time you now can select if you want to start BFM viewer after reconstruction immediately or not (Reconstruct all).
  • While SmarTest is running you can now access the most recent data log file, without having to save it first, by using the Open Online Datalog dialog. Reconstruction results are written to the online data log if reconstruct has been selected (Selecting a data log file).
