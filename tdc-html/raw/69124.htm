Audit Trail Record (ATR)

The Audit Trail Record records any operation that alters the contents of the STDF file. The name of the program and all its parameters are recorded in the CMD_LINE field.

If this record is used, it must be located immediately after the FAR.

ATR field name

Field description

Value

93000 data source

MOD_TIM
  • Date and time when the data formatter program is started
  • Whether the time is local or UTC depends on the setting of the useUTCTime option in formatter.stdf.main.conf.
  • Four-byte unsigned integer
  • Takes system time from the workstation

CMD_LINE
  • Command line parameters of program
  • Variable length character string
  • Maximum 255 characters
  • The command line, including all of the arguments.
  • This field also has version information included at the end of the command line string.

ATR for tests with more than 255 sites

If a test was performed on more than 255 sites, a special ATR is inserted between the FAR and MIR in the initial sequence.

This record contains two fields:

  • MOD_TIM contains the date and time, as specified above.
  • CMD_LINE contains.a string that consists of the word "EXTENDEDSITES", a space, and the number of sites in the test.

    For example, if the test was performed on 1024 sites, CMD_LINE would contain "EXTENDEDSITES 1024".

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.2.2: Added ATR record for test on more than 255 sites.
