API enhancements

New APIs:

  • MTP_MEMORY_TEST.setBitMapFileName()
  • MTP_MEMORY_PATTERN.getFailingCycleAddresses()
  • SOURCESYNC APIs: Lets you create your own source-sync test method without using the MTP provided source-sync test method.
    • SOURCESYNC_TEST
    • SOURCESYNC_DOMAIN
    • SOURCESYNC_SUB_TEST
    • SOURCESYNC_TEST_DOMAIN
    • SOURCESYNC_HANDLER
  • MTP_RA_ALGORITHM_HOLDER: Eases you to use the legacy RA algorithm.

Enhancements of the existing APIs:

  • MTP_MEMORY_TEST.setFailAddressListOrdering(): Adds a new option, MTP::ORDERING_CYCLE.
  • MTP_MEMORY_PATTERN.setBitMapFileName(): When specifying a file name, you can include a series variables into the file name to show the information like wafer, lot, pattern and etc..
