Topic 351450

Static configurations

These static configurations have global behaviors. All of them are optional and have default values if not specified in test suites.

If required to be set, these configurations must be set before the start of any Register Access operations and must not be changed during the testflow running.

These static configurations can be executed only once in the first test suite at the beginning of the main testflow.

Overview of static configurations
Static configuration Description
RA_CFG.enableCommentsInRegisterOperationPattern(

Enable comments in labels of register operations.

The comments specified in protocol class when defining read/write sequence can be enabled or disabled.

Enabling comments may add more time in label/pattern generation.

Use enable to enable comments in pattern generation.
RA_CFG.enableRegisterTracking()

Enable the register tracking feature for debug.

By default, the tracking function is disabled for throughput concern.

If it is enabled, RA_PRINT_TRACKING can be used to printout the register changing trend grouped by either sequence or register name.

Use enable to set to true for enabling the tracking function.
RA_CFG.getDefaultCheckMode() Retrieve the default check mode.
RA_CFG.getDefaultMode() Retrieve the default RA mode.
RA_CFG.getDefaultProtocol() Retrieve the default protocol instance.
RA_CFG.getLogLevel() Retrieve the log level.
RA_CFG.getMaxNumberOfVectorsForFlatPadding() Retrieve the maximum repeats for a flat padding.
RA_CFG.getPrefixOfReadBackLabelName() Retrieve the prefix of the read-back label name.
RA_CFG.getPrefixOfRMWLabelName() Retrieve the prefix of the RMW register write label name.
RA_CFG.getPrefixRegisterAccessLabelName() Retrieve the prefix of all labels generated by RA.
RA_CFG.getRegisterCacheFilePath() Retrieve the path of the register cache file.
RA_CFG.getRegisterOfflineReadBackValue() Retrieve the register read-back offline value.
RA_CFG.initFromTestFlowVariable()

Initialize a configuration to be set by a testflow variable.

These corresponding testflow variables can be used to simply RA configurations:

  • RA_DEFAULT_MODE
  • RA_DEFAULT_CHECK_MODE
  • RA_DEFAULT_PROTOCOL
  • RA_ENABLE_TRACKING
  • RA_OFFLINE_READ_BACK_VALUE
  • RA_ENABLE_COMMENT_IN_LABEL
  • RA_PREFIX_OF_LABEL
  • RA_MAX_VECTORS_FOR_FLAT_PADDING
  • RA_LOG_LEVEL
  • RA_RCF_PATH
  • RA_DEFAULT_WAVEFORM_INDEX_HOLD
RA_CFG.isCommentsInRegisterOperationPatternEnabled() Retrieve to know whether comments are enabled for label generation by RA.
RA_CFG.isRegisterTrackingEnabled() Retrieve to know whether the tracking feature is enabled.
RA_CFG.setDefaultCheckMode()

Set a default check mode.

This check mode is only applied when the RA::PRODUCTION execution mode is used.

This default check mode is used when no local check mode is defined by RA_SET_CHECK_MODE() in the test method.

Check mode options:
  • RA::CHK_NONE
  • RA::CHK_PF
  • RA::CHK_VAL
RA_CFG.setDefaultMode() Set a default RA execution mode.

This default execution mode is applied when RA_SET_MODE() is not set locally in the test method.

Mode options:
  • RA::LEARNING
  • RA::PRODUCTION
RA_CFG.setDefaultPhysicalWaveformIndex()

Specify a default physical waveform index.

If not specified, the default physical waveform index is 0xF, which is defined as hold with device cycle name of ".".

The default physical waveform index is used in labels generated by RA to fill in pins that have not been defined in the protocol.
RA_CFG.setDefaultProtocol()

Set a default protocol for register operations.

The default protocol can also be specified by RA_SWITCH_PROTOCOL() in the test method.

By default, if not specified, the first register protocol is used as the default protocol.

The protocol name must be the one that has been defined in a protocol class. See Creating a protocol class.
RA_CFG.setLogLevel()

Set an internal log level.

The log information is for internal debug only.
RA_CFG.setMaxNumberOfVectorsForFlatPadding()

Set the maximum number of repeat vectors for a flat padding.

Flat padding means no sequence instruction "RPTV" is used but a physical flat layout vectors for repeat.

If the repeat number exceeds the number specified by this configuration, the instruction command "RPTV" is used. If too many RPTVs are used and close to each other, it might cause "Queue Empty" issue. Therefore this number must be correctly set to fit real cases.

By default, this number is set to 8.
RA_CFG.setNRZWaveform()

Set a device cycle name to map to the required NRZ waveform.

If not configured, by default, device cycle names of "0", "1", "L", "H", "X", "C" and "." are used for register operation labels generated by RA. If the NRZ waveforms have not been defined or defined with other names, you can use this configuration to map them to NRZ waveforms, which can be recognized by RA.
RA_CFG.setPrefixRegisterAccessLabelName()

Set a prefix to all labels generated by RA.

The default prefix is RA.
RA_CFG.setRegisterCacheFilePath()

Set a path to store the register cache file (.rcf) for RMW registers.

The path is related to the device directory.
RA_CFG.setRegisterOfflineReadBackValue()

Specify a read-back value when register offline.

This configuration is used for debug purpose in the offline mode and it is valid only in the RA::LEARNING mode.

For partial bit field write operations (RMW), this value is used as the read-back value.

If specified, it can be used to validate register operations for testing case.

By default, if not specified, it is 0x00.

Example

RA_CFG.setDefaultMode(RA::LEARNING);
RA_CFG.setDefaultCheckMode(RA::CHK_VAL);
RA_CFG.setDefaultProtocol("I2C");
RA_CFG.enableRegisterTracking(true):
RA_CFG.setRegisterOfflineReadBackValue(0xAB);
RA_CFG.enableCommentsInRegisterOperationPattern(true);
RA_CFG.setMaxNumberOfVectorsForFlatPadding(8);
RA_CFG.setRegisterCacheFilePath("./rcf");
RA_CFG.setNRZWaveform(RA::NRZ_0, "0");
RA_CFG.setNRZWaveform(RA::NRZ_1, "1");
RA_CFG.setNRZWaveform(RA::NRZ_L, "L");
RA_CFG.setNRZWaveform(RA::NRZ_H, "L");
RA_CFG.setNRZWaveform(RA::NRZ_X, "X");
RA_CFG.setNRZWaveform(RA::NRZ_C, "C");
RA_CFG.setNRZWaveform(RA::NRZ_HOLD, ".");
