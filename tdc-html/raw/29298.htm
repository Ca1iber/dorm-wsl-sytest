ENABLE_ERROR_MESSAGE

This API enables generation of error messages to the report window. Note that generation of error messages is enabled as the default.

Syntax

ENABLE_ERROR_MESSAGE();

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

List of parameters

There are no parameters.

Example

ENABLE_ERROR_MESSAGE();

The ENABLE_ERROR_MESSAGE API enables error message generation.

Related information

DISABLE_ERROR_MESSAGE

Functional changes

  1. Introduced before SmarTest 6.3.2
