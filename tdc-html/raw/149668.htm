SMC_PIN_ERROR_MAP.getFirstFailingTesterCycles()

Retrieves the failing tester cycles that occur after the specified start tester cycle. This reports failing tester cycles in x1-mode only.

Syntax

LONG getFirstFailingTesterCycles(const LONG_LONG  startCycle,
                                 const LONG_LONG  maxNumberOfFailCycles,
                                 ARRAY_LL        &failingCycles,
                                 bool            &fewerFailsReturnedDueToEmapFull);
Parameters

Parameter

Description

startCycle

The first tester cycle after which the reporting of failing tester cycles starts.

0 represents the first tester cycle.

maxNumberOfFailCycles

The number of failing tester cycles to report.

failingCycles

Container where the failing cycles are reported to.

fewerFailsReturnedDueToEmapFull

A flag that indicates that the error map is full and thus not all failing tester cycles were reported.

true = error map is full, less failing tester cycles reported than requested.

false = error map is not full, the requested failing tester cycles are reported.

Note: If less failing tester cycles occurred in the test than requested and the error map is not full, this flag will be false.

Return value

Returns the number of failing tester cycles that are copied to the referenced failingCycles array.

If the error map runs full and less failing tester cycles can be reported than requested, the referenced fewerFailsReturnedDueToEmapFull parameter returns true.
