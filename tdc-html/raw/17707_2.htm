Topic 17707

Setting up your levels

About this task

The process for setting up equation based levels is very similar to that for setting up equation based timing.

  1. Set up the equations for levels.
  2. Define the specifications.

For detailed information on use cases of level setup, see Level setup related use cases.

Procedure

  1. Open the Level Setup window.
  2. On the menu, click Select > Edit Equations.

    The Level Equation Editor opens.

  3. On the menu, click, depending on whether you want to generate equations for level or DPS pins:
    • Shell > Generate Level
    • Shell > Generate DPS.

      Windows similar to those shown in the figure below open.

  4. Add the sets and pins you want to include:
    1. Select All <Level/DPS> sets or On <Level/DPS> set
    2. Select pins and pin groups and click copy, or click copy all
  5. Click create to finish the setup.

    The windows closes.

  6. If you need to specify both level and DPS sets, repeat steps step 3 to step 5, generating the other required sets.

    For general information on equation based level setup, see How to create an equation set using the Equation editor.

    For detailed information, see:

    • Elements of Equation Based Level Setup
    • Structure of an equation based level setup
    • Level Equations: setup example
  7. Download the values to hardware:
    • In the Level Equation Editor, select Shell > Download.
    • Press F8.
      Note Do not use the File > Save option of NEdit. In order to save your work you must first download the changed data, and then save them from the Test Program Explorer.
  8. Close the Level Equation Editor.
  9. Save the level setup in the Test Program Explorer.
    Note Remember that, if you want to have your level equation file available at a later stage, you must either save it from within the Level Equation Editor, or save the Level Setup.
  10. If you use equation based level setup(s) with spec variables (specs), assign values to these variables in the Spec Tool.
    1. Open the Level Setup window.
    2. On the menu, click Select > Edit Specification.

      The Spec Tool window opens.

    3. Edit your specifications as required.

      For detailed information, refer to General Editing Features of the Spec Tool.

    4. To finish your setup, on the menu, click File > Download.
    5. Save the Level Setup in the Test Program Explorer.
      Note Remember that, if you want to have your level specifications available at a later stage, you must save the Level Setup.
