STILEditor

STILEditor is a command line tool for rule-based modification of STIL files. It can be used as a preprocessor for adapting STIL files before they are converted to V93000 setups using STIL Reader.

STILEditor can perform a number of operations on STIL files based on settings specified in its setup file:
  • Importing pin usage information
  • Merging patterns
  • Adding or masking signals
  • Removing or extracting vectors
  • Compressing patterns using loops
  • Other editing operations

For more information about using STILEditor, including a syntax reference, see the PDF manual.
