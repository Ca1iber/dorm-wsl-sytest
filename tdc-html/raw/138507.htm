Customized shmoo test template

Subtopics

  1. The functions of the customized shmoo test method template

The customized shmoo test template is called "customized shmoo test method class" and used to create a customized shmoo test method.

This template:

  • Contains the ac_tml.AcTest.Shmoo test method class.

    Therefore, a created shmoo test method contains all parameters and functions of the ac_tml.AcTest.Shmoo test method.

  • Contains different functions for you to:
    • Add new test method parameters.
    • Define results to be displayed on shmoo plots.
    • Perform actions before, during or after a shmoo test.
