Topic 123986

Multiple transaction ports

About this task

The d2s-framework allows transactions on multiple ports. In order to use multiple protocols, each protocol has to be registered to the d2sFramework the same way as a single protocol.

The general behavior of the d2s-framework in learning and production mode does not change.

This task shows how to register multiple ports to the framework and how they can be handled independently.

Before you begin

Ensure you have carried out all preparation and configuration steps as described in Prepare device setup, Prepare the test method infrastructure and Configure the protocol for each protocol.

Procedure

  1. Create a d2sFramework handle. 
    d2sFramework fr;

    This framework handle ("fr") will be used to access the d2sFramework methods.

  2. Instantiate your protocols, for example, sbiA and sbiB. 
    d2s_SBIA& sbiA = d2s_SBIA ::Instance();
d2s_SBIB& sbiB = d2s_SBIB ::Instance();

    The corresponding objects reflect your protocols. Each one uses its corresponding protocol file, for example d2s_SBIA.h and d2s_SBIB.h to handle transactions, like write and read.

  3. Register each protocol with the framework. 
    fr.registerTransactionPort(sbiA);
fr.registerTransactionPort(sbiB);
  4. Define the d2s-block's begin API with the appropriate details, like burst label name and mode. 
    fr.d2s_LABEL_BEGIN("concurrentWrite", d2sFrameWorkModeType::LearningMode);
  5. Specify protocol port specific transactions within the d2s-block 
    sbiA.write(0x0, 0x5);
sbiA.read(0x4, "0x4");
sbiB.write(0x0, 0x5);
sbiB.wait(1 ms);
  6. Call the d2s-block's end API.

Example

The following code snippet illustrates how multiple transactions ports can be used with the d2s-framework.

This example creates bursts for each single port which will be combined into a multiport burst. The multiport burst will be executed on d2s_LABEL_END(). This way the transactions are applied to the device concurrently.

virtual void run()
{
   // step 1
   d2sFramework fr;

   // step 2
   d2s_SBIA& sbiA = d2s_SBIA ::Instance();
   d2s_SBIB& sbiB = d2s_SBIB ::Instance();

   // step 3
   fr.registerTransactionPort(sbiA);
   fr.registerTransactionPort(sbiB);
   
   ON_FIRST_INVOCATION_BEGIN();
      // This only for displaying pass/fail after the ON_FIRST_INVOCATION_END()
      sbiB.enablePassFailCheckForNextExecution();

      // step 4
      fr.d2s_LABEL_BEGIN("concurrentWrite", d2sFrameWorkModeType::LearningMode);

         // step 5
         sbiA.write(0x0, 0x5);
         sbiA.read(0x4, "0x4");

         sbiB.write(0x0, 0x5);
         sbiB.wait(1 ms);

      // step 6
      fr.d2s_LABEL_END();

      // do your measurement here

   ON_FIRST_INVOCATION_END();

   if(sbiB.hasPassed("concurrentWrite"))
   {
      cerr << "test has passed on port >>sbiB<<" << endl;
   }
   else
   {
      cerr << "test has failed on port >>sbiB<<" << endl;
   }

    cerr << "read value on sbiA: 0x" << hex << sbiA.getReadValue("0x4") << endl; 
}
