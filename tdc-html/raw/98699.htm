PSIE - (Power Supply Internal trigger Execute)

The PSIE command triggers the start of an internal current or voltage measurement. The measurement itself is defined by the DPSE command.

In contrast to PSEE, PSIE does not execute an internal functional test. The measurement result of PSIE is retrieved by PSER? in the same way as for PSEE.

PSIE retains the current measurement range after the measurement, unless specified differently (keep_range|"RSTO"). This reduces the settling time after changing the current measurement range.

Note The regulation performance of the DPS is negatively affected by the current sense resistor. So after a low current measurement, reset the current measurement range to the highest possible range.

The number of samples taken per measurement depends on the DPS card and the measurement range. For the DC Scale cards (UHC4T) the resulting number of samples is rounded up to the next power of 2. The final result is the average of all the samples.

  • PSER? - (Power Supply External trigger measurement Read results)

Syntax

PSIE [setnr], [current_range] [,{keep_range|"RSTO"}] [,{all_sampler|"CH_ALL"}] [,{primary_act|"NPRM"}], [samples] [,settl_time], {(pinlist)}

Parameters

setnr

The set number defined by the DPSE command. (The range is 1 to 256). This set contains the limits of the measurement point for pass/fail judgment. When this parameter is specified, the corresponding set must already have been defined.

When the setnr parameter is omitted, the current and the pinlist parameters must be specified.

current_range

If the setnr parameter is specified, this parameter will be ignored.

If the setnr parameter is not specified, you must specify the range with a value. In this case, the measurement will be executed in the smallest range that can measure the given value. The unit is Ampere [A].

keep_range

No longer supported.

The measurement range is kept per default.

For DPS128 and XPS256, the parameter is silently ignored and the measurement range is restored to the force or clamp range.

all_sampler

To upload the results of all channels in the gang with sampler connected, and store them, specify CH_ALL. This option can be selected only for DC Scale UHC4 / UHC4T channels.

If called without the all_sampler parameter, the command will upload only the value of the master channel, even if the measurement was done over the sampler, or if a voltage drop on DUT was measured.

primary_act

The conditional primary activation is default.

To avoid the conditional primary activation, specify NPRM.

samples

(Optional) This parameter specifies how often the measurement will be performed under the same test conditions. The default is 1.

For details see the table above.

The value that will be stored is the average of all these measurements.

This parameter can be used both for measurements defined with DPSE and for measurements defined directly with PSIE.

settl_time

The system must wait the settling time before the measurement is executed. If the force range is switched, for example, "unganging during measurement", to avoid glitches the settling time is waited before the small force range is active.

The unit is milliseconds (ms).

pinlist

Names of pins to which this command is applied. The character @ can be used to specify all DPS pins. This parameter will be ignored if setnr is specified.

Errors

There are no errors except parameter checks.

Example

> DPSE 1,(Vcc),#90000000112,0.09,0.11
> PSIE 1,,,(Vcc)
> PSER? 1,PVAL
< PSER 1,F,(Vcc),#9000000006,0.155

In this example, the DPSE command specifies a current limit of 0.9 A to 0.11 A for Vcc. Then the PSIE command starts measurements for the measurement set 1. In this case, the pin name is ignored because the set number is specified with the first parameter. After the measurement, the PSER command retrieves the measurement value for Vcc. In this case, the 300 mA range that is determined by using the specified limit value, is automatically selected for the measurement.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.3.3: New parameters: keep_range | RSTO, introduced with 6.1.5.0 and 6.3.3.
  3. SmarTest 6.5.2: Voltage measurement for MS-DPS supported.
  4. SmarTest 6.5.3: Maximum number of DPS sets increased to 256.
  5. SmarTest 6.5.3: Voltage measurement for all DPS's supported.
