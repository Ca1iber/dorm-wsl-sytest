Differential pins - @diff

You can use the special @diff pin syntax in the timing file.

@diff applies the assigned level values to both legs of a differential pair of pins even when only one connection is defined. This syntax applies the actions to both pins even if the intended application is not differential.

Note The Timing Setup Editor does not allow you to enter this pin syntax, so if you wish to use it, you must enter it directly into the timing file via the file editor.
The example below shows a section of a timing equation file, in which the differential pins have been defined as PINS A0, A0-:
# Timing equation
...
PINS A0,A0-        # I-pins

    period_div=4   # Accepted values: 1,2,3,4,6,8
    d1=...

To give the same result, you could also use the shorthand notation to specify just one of the differential pins (A0) as PINS A0@diff. The complementary pin (A1) is then automatically configured:

# Timing equation
...
PINS A0@diff       # I-pins

    period_div=4   # Accepted values: 1,2,3,4,6,8
    d1=...

Note that with this syntax, you define only the positive pin.
