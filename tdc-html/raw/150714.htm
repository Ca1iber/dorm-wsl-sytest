Topic 150714

Default driver configuration

The parameters in the configuration file determine the behavior of the driver. You must define these parameters first after you have created the configuration file.

The following table lists the important aspects in the configuration file.

Important aspects of the MCT configuration file

Aspect

Used settings

handler_family

MCT

It has no default value and must be defined.

model

FH1200

It has no default value and must be defined.

driver_message_log

The location of the driver message log file.

The default value is "".

debug_level

The debug level of the driver.

The default value is 1. The value range is from -1 to 4.

log_configuration

This parameter records the configuration into the message log file.

The default value is no.

ask_for_configuration_confirmation

This parameter asks for the confirmation of the configuration.

The default value is no. If the parameter log_configuration is set to yes, the configuration will appear in the report window.

If the value is yes, you must check and confirm the configuration, otherwise the test program would be aborted.

interface_type

gpib

The name of the handler interface type. It has no default value and must be defined.

symbolic_interface_name

hpib

The name of the interface device. It has no default value and must be defined.

gpib_port

The GPIB port number of the handler.

It has no default value and must be defined according to the handler's setup.

handler_site_ids

The names of handler sites.

It has no default value and must be defined.

handler_site_mask

The mask of active handler sites.

The entry can be 0 or 1 and the default value is [1 1 1 ... ].

smartest_site_to_handler_site_map

This parameter maps the SmarTest sites to the handler sites.

The entries must be >= 1. The default value is [1 2 3 ...].

bin_mapping

This parameter determines how the driver maps SmarTest bins to handler bins.

For the MCT FH1200 handler, the number of bins is 8.

For more information about bin mapping, see Configuration Parameters for Binning Management.

waiting_for_parts_method

This parameter determines how to wait for the test start signals, polling or interrupt. The default value is interrupt.

For more information about the configuration parameters, see Configuration Parameters.
