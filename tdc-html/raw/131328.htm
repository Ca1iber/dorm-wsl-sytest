MTP_IDD_PIN_TASK

Subtopics

  1. MTP_IDD_PIN_TASK.limits()

The MTP_IDD_PIN_TASK class is a data container holding the IDD measurement setup data for testing VDD and VDDQ pins. It is performed with the MTP_IDD_TASK API and used by the pin() member function.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/MTP_IDD_PIN_TASK.h.
