DPS_MeasCurrentRange()

This API is used to set up a label to hold the measured current range.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTMultiportSync.hpp.

Syntax

void DPS_MeasCurrentRange(const String& _pinName, DOUBLE _currentRange);
Parameters

pinName(string)

Specifies the pin name.

_currenRange(double)

Specifies the current range value.

Example

DCDynamicPort::getInstance().DPS_MeasCurrentRange(mDpsPins, 3.0);
DCDynamicPort::getInstance().DPS_Force("DPS128_2",vin, 50 mA);
DCDynamicPort::getInstance().DPS_MeasCurrent(mDpsPins,2);
