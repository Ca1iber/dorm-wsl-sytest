Topic 55750

Error Map

Subtopics

  1. Detailed error map
  2. Setting the acquisition mode
  3. Aligning Timing Diagram and Error Map tool

The error map is the basis for analyzing the test results. SmarTest uses the error map to record information about failing test cycles.

In fact, SmarTest provides two error maps, a detailed and an overview error map. The Detailed error map provides information on the cycle or even the edge level. The overview error map combines every 2000 or more cycles into one result depending on the number of cycles of the test setup.

Both of these error maps are located within the test processor. The detailed error map can also be located in the external RDRAM. But by default, the internal error map is used. For information on the configuration, see Result Mode.

All result analysis tools (Error Map Tool, Timing Diagram etc.) use the error map to generate different views to the results you obtain when performing tests.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.1: For the test where the Pin Scale 9G pins are used to generate a prbs or compare the DUT data with a prbs, the error map does not work.
