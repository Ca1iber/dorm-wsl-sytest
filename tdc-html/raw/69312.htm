Topic 69312

Default GPIB configuration

This section describes the variables used in the configuration files.

When the configuration files were created, certain aspects had to necessarily be defined. The table below lists these aspects and how they were defined.

Important aspects of the Delta Design Summit configuration files

Aspect

Used setting

Debug level

0, will log only basic messages, may be changed between -1 and 4.

GPIB port used

6, must be changed to correct value based on the handlers setup.

Auto-pausing of handler

Deactivated.

Resume after pause

Deactivated.

Bin mapping

Default.

Number of bins

100 (SmarTest hardbins 0 through 99), bin 0 represents the handlers retest bin.

Retest bin

0

Bin verification

Not defined.

Reprobe mode

Automatic reprobe on a per site mode, if devices fall into SmarTest reprobe bins. See Notes regarding the Summit configuration files for more information.

Temperature control

Set up to manual, may be changed to active with parameter temp_control.

Temperature parameters

Some values are predefined in the configuration and may be activated by changing the parameter temp_control to active. Temperature may be controlled for the testsite area; setpoint, guardbands, and soaktime can be defined.

Recipe file name

TEMPGPIB : This file is created inside the handler by the driver to define and set up temperature control.

Test start detection

Done by interrupt (SRQ), may be changed to pure polling mode with given polling interval for troubleshooting.

End-of-line terminator

Driver sends LF and EOI on the GPIB bus, cannot be changed through configuration file. Driver expects no special end of line code from handler except EOI.

Polling interval

Preset to 100 ms, only used if waiting for parts is done by polling.

Active workarounds

All reprobe operations will result in a reprobe 1 command. start or stop commands will never be sent to the handler. Bin verification mode will never be activated, deactivated or queried from the handler. See Notes regarding the Summit configuration files for more information.
