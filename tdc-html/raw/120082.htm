SMC_WAIT_TIME()

Waits for the end of the execution of the next statement during the time specified by the parameter.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Syntax

void SMC_WAIT_TIME(DOUBLE time = 0);
Parameter

Parameter

Description

time

Wait time in seconds.

Resolution: 1 µs

The accuracy of this parameter is influenced by the overhead time of the operating system.

Example

The SMC_WAIT TIME() waits for 100 ms before executing the next statement.

SMC_WAIT_TIME(100 ms);

Functional changes

  1. Introduced in SmarTest 6.5.3
