Collecting log files if SmarTest crashed

If SmarTest crashed you can manually collect the log files and other related data, which can be relevant for analysis.

About this task

You can collect all available log files, check them for improvements of your device and project data, and, in case of open questions, send them to your Advantest service representative. These log files are required for a detailed analysis of the cause. SmarTest provides the SmarTest Status Snapshot function which collects the most related log files.

Do not perform this procedure when SmarTest did not crash, but shows a hang-up. In this case go to Creating Java dump file if SmarTest shows a hang-up.

Procedure

  1. Copy the following files and directories to a temporary directory, for example, /home/[user name]/errors:
    • The Eclipse log file, located in [user workspace]/.metadata/.log
    • The Eclipse configuration area directory (zipped), located in /home/[user name]/.eclipse
    • The report window dump, located in /tmp/ReportWindow.dump
    • The system logs, located in /tmp/xoc_sessionmanager/log/ and /opt/hp93000/soc/system/log/
    • The Java virtual machine crash log files hs_err_pid<pid>.log , located under [device]/waste or under /tmp
  2. If SmarTest issued error messages, create screenshots of the errors and save the screenshots to

    /home/[user name]/errors.

  3. To create a zipped archive of all the copied files and screenshots, open a terminal and on the command line type

    tar -czvf errors.tar/home/[user name]/errors

  4. Send the archive to the Advantest service representative.

Results

The log files sent to the Advantest service representative allow a detailed error analysis.
