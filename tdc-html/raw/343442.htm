rdi.route().applyState()

Applies an already defined switch state to utility lines and PMUX switches.

The function applies the selected switch state to the supported hardware. The selected state may contain any combination of static utility lines, sequencer‑controlled utility lines. The applied switch state must already be defined by the State Setup editor of the Routing Tools editors.

Only one switch state may be applied and activated at time.

Usage of the function:
  • The function can be called in the code‑based mode or in the pattern‑based mode. For more information, refer to Execution mode in topic SmartRDI.
  • For debugging, we recommend setting the keyword ROUTING_ACK_CHECK of the RDI_Configure file to TRUE to enable a check if the route state is applied successfully to PMUX switches.
Execution sequence:
  • Code-based mode:
    • Combination of static utility lines and sequencer‑controlled utility lines or PMUX switches:

      The setup of the static utility lines is applied first, followed by a pattern that applies the setup of the sequencer‑controlled utility lines and activates a stored PMUX state.

    • Only sequencer‑controlled utility lines or PMUX switches:

      A pattern that applies the setup of the sequencer‑controlled utility lines and activates a stored PMUX state is started.

  • Pattern-based mode:

    A pattern that applies the setup of the sequencer controlled utility lines and activates a stored PMUX state is started within an RDI burst.

    Note Any switch state that contains static utility lines cannot be applied in pattern‑based mode. This restriction ensures that the sequence of applying the switch state corresponds to the source code.

Syntax

routeGroup& applyState(const string &state);
List of parameters
Parameter Description
state The string defines the switch state that is to be applied.

The selected switch state must already be defined by the State Setup editor of the Routing Tools editors.
Return value
A reference to the routeGroup object.
