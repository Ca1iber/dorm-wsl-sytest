Topic 69122

Specifying the data source

Each STDF record created by the SmarTest Data Formatter contains various record fields that are populated with data that comes from either the Event Data Log (EDL) stream, configuration options, environment variables, or the application model. This section describes how each STDF field is populated and lists the data source.

The Record field name column is the name of the record field for that particular STDF record, according to the STDF version 4 specification.

The Field description column is a short description of what the field is or does.

The Value column shows the possible values this field can have.

The 93000 data source column shows how the field is populated in terms of the V93000 test system. The data source can be one, or a combination of, the following types:

  • Event Data Log (EDL) attribute
  • Configuration file attribute
  • Environment variable
  • Application model variable

Functional changes

  1. Introduced before SmarTest 6.3.2
