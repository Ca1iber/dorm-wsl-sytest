Topic 81103

Parameters for multistrobe test methods

Subtopics

  1. SourceSync fast mode
  2. SourceSync standard mode
  3. Error map for the SourceSync test method

The multistrobe test methods are configured in the Test Suite window.

Note For GDDR3 memory devices, the two parameters to be measured translate as follows: SSspecMin = tDQSQmin, SSspecMax = tDQSQmax.

To control the result margins, the test methods allow you to set margin limits in the bottom-most configuration section.

In each of the configuration windows, you can choose whether or not you want to use the Rapid Source Sync to speed up the test.

Note Rapid source sync is not supported on the EXA Scale test systems.
  • RapidSourceSync allows you to switch this function on (YES).

    When switched to YES you must also specify the subsequent two parameters.

  • The BufferPins parameter lets you specify the number of buffer channels you want to use for the Rapid Source Sync function.

    There are some restrictions in which channels are to be used as buffer channels.

  • The CopyingMethod parameter allows you to select Parallel or Serial copying.
  • Optionally, the Sharing Config File lets you specify the sharing configuration file with buffer pin specification. It should be located in <device directory>/configuration/. If the file is located elsewhere, specify its position as an absolute path or a relative path based on <device directory>/configuration/.

    If you specify both BufferPins and Sharing Config File, the BufferPins setting is used.
