DRLBinAttr

A variable of this type is a pointer to a structure named _DRLBinAttr, which stores the specifications of a bin.

The member is_good_bin specifies whether the bin is good or bad (1=good, 0=bad).

The member bin_number holds the hardware number of the bin.

The member bin_name holds the software bin name, which consists of a NULL-terminated string.

The member bin_description holds the description of the bin as a NULL terminated string.

The member hardware_bin_description holds the hardware bin description as a NULL terminated string.

typedef const struct _DRLBinAttr {
  char is_good_bin//1=good;0=bad;
  int bin_number;
  char *bin_name;
  char *bin_description;
  char *hardware_bin_description;
} *DRLBinAttr;
