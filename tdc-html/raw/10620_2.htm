Topic 10620

Setting delays and periods

Subtopics

  1. Specifying the period
  2. Setting the edge delays

The physical waveforms fix the shapes of the signals that can be sent to the DUT. What remains to be done is to determine

  • the period, that is, the length of the tester cycle (see Specifying the period), and
  • the delays of the edges within this period (see Setting the edge delays).

These values are defined in the timing sets and (if the timing set definitions contain variables) the spec set (see Defining the timing specification). The unit is nanoseconds (ns).

You can change the edge delays and the periods during a test by switching to another timing set with the CTIM sequencer instruction. For details, see Changing the timing set.

Functional changes
