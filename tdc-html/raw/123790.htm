Converting Scan Patterns

Subtopics

  1. Conversion Procedure

F330 Scan classical scan patterns need to have Scan vectors stored in the vector memory. UMM does not use vector memory anymore. We recommend to convert the F330 Scan Patterns to the Multiport Parallel Patterns using the ASCII Interface AIF tools.

Scan Pattern Conversion Procedure

To convert F330 based scan vertors using the ASCII Infterface, we recommend the following procedure:

  • Using tool b2a for generating vector ascii (avc) files
  • Using tool ait to generate aiv input files and timing file
  • Using tool aiv to generate multiport parallel patterns
