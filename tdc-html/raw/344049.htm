Topic 344049

Switching the client between FlexNet Embedded and FlexNet Publisher servers

During the SmarTest installation, the FlexNet FlexNet Embedded license client is installed by default on the system controller and is used by default. Installing the FLexNet Publisher (FNP) license client switches to the FlexNet Publisher license technology.

About this task

This topic explains how to switch between FlexNet Publisher and the FlexNet Embedded license technologies, if you are using both technologies.

Before you begin

You have installed the FNE license client on the SmarTest system controller. When installed, the FNE license client is active by default.

For installation information, see FlexNet Embedded license client setup and Installing the FNE license client.

Procedure

  1. To use FNP licensing if the FNE client is installed and active, override the default with the following command:

    export V93000_LICENSING_SUBSYSTEM=/opt/hp93000/soc/system/config/xoc.svc.fm.defaultSubsystem/libfnpss-fallback.so

  2. To switch back to FNE licensing, unset the V93000_LICENSING_SUBSYSTEM variable:

    unset V93000_LICENSING_SUBSYSTEM

Results

You have switched between FNE and FNP licensing technologies.

Functional changes

  1. Introduced in SmarTest 8.4.0
