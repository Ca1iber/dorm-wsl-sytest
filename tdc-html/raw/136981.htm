Managing data logs

Subtopics

  1. Loading and unloading data log files
  2. Opening a data log for examination
  3. Merging data logs
  4. Correlating data logs
  5. Saving the system data log stream
  6. Exporting data logs

Working with the Integrated Result Tool begins with loading and arranging the logs that you want to examine. The tool supports the system data log as well as STDF and EDL data log files. You can combine logs, and you can export data logs as CSV files.

These procedures are described in details in:

  • Loading and unloading data log files
  • Opening a data log for examination
  • Merging data logs
  • Correlating data logs
  • Exporting data logs

What to do next

Adjust the display and data selection or analyze the data.
