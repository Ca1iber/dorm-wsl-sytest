Counted loops

To program a counted loop use the LBGN instruction followed by the number of repetitions. Mark the end of the loop with LEND.

LBGN <number of repetitions>

[..]

LEND

You can also realize a counted loop by repeating subroutine calls. In order to repeat a subroutine call a certain number of times, you must put the RPTJ instruction immediately before the JSUB instruction.

Nested loops

Within an endless loop or within a counted loop you can nest counted loops and repeated subroutines.

Note You must not nest an endless loop within any loop structure. Endless loops are only allowed as the most outer loop.

Nesting is limited to seven nested levels.

Examples

Counted loop

SQPG 7,LBGN,50,,,(@)
SQPG 8,GENV,7,,,(@)
SQPG 9,LEND,,,,(@)

The sequence repeats the GENV instruction 50 times.

Repeated subroutine

SQPG 0,STVA,408,,,(@)
SQPG 1,STSA,,,,(@)
SQPG 2,GENV,6,,,(@)
SQPG 3,RPTJ,10,,,(@)
SQPG 3,JSUB,,"sub",,(@)
SQPG 4,STOP,,,,(@)

In this example, the call of the subroutine sub is repeated ten times.

Nested counted loop

SQPG 0,STVA,408,,,(@)
SQPG 1,STSA,,,,(@)
SQPG 3,LBGN,5,,,(@)
SQPG 4,GENV,7,,,(@)
SQPG 5,LBGN,9,,,(@)
SQPG 6,GENV,3,,,(@)
SQPG 7,LEND,,,,(@)
SQPG 8,LEND,,,,(@)
SQPG 9,STOP,,,,(@)

The outer loop is repeated five times and the inner loop nine times.

Nested counted loop and subroutine

SQPG 0,STVA,408,,,(@)
SQPG 1,STSA,,,,(@)
SQPG 3,LBGN,5,,,(@)
SQPG 4,GENV,7,,,(@)
SQPG 5,LBGN,9,,,(@)
SQPG 6,JSUB,,"sub1",,(@)
SQPG 7,LEND,,,,(@)
SQPG 8,LEND,,,,(@)
SQPG 9,STOP,,,,(@)

Nested repeated subroutine

SQPG 0,STVA,408,,,(@)
SQPG 1,STSA,,,,(@)
SQPG 3,LBGN,5,,,(@)
SQPG 4,GENV,7,,,(@)
SQPG 5,RPTJ,9,,,(@)
SQPG 6,JSUB,,"sub1",,(@)
SQPG 7,LEND,,,,(@)
SQPG 8,STOP,,,,(@)
