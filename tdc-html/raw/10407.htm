Storing and Retrieving Binary Data

A main difference between the two hpt versions concerns the representation of binary data.

pws-hpt

pws-hpt returns binary data below decimal value 32 in hexadecimal representation, values above 31 by the corresponding ASCII character. The binary data is terminated by a linefeed character (\x0A).

Suppose, for example, that you want to display parallel vectors for a certain pin. In pws-hpt, you would have to enter 

VECD? PARA,SM,0,16,(IN1),

and the reply would be

size: 25
data:
VECD? PARA,SM,0,16,(IN1)\x0A
size: 52
data:
VECD PARA,VM,0,16,(IN1),#9000000016\x07&\x07\x07&\x11\x07\x07\x07\x10\x07\x07\x09\x07\x10\x07\x0A
status: 0

The sequence of waveform DC/DC power units is 7, 38, 7, 7, 38, 17, 7, 7, 7, 16, 7, 7, 9, 7, 16, 7. Note that the terminating linefeed character is not counted for the length of the binary data.

fw-hpt

If you are using fw-hpt, you can issue commands that store and retrieve binary data in normal mode or a special ‘binary' mode.

In normal mode, the command input is stored as it is specified, and returned as it is stored. A disadvantage of this mode is that you cannot download or retrieve data with decimal values below 31 or above 124 from the fw-hpt prompt.

In binary mode, the commands accept and return data in a format that represents each of its bits by ASCII 1 or 0. When you issue a command in binary mode from the fw-hpt prompt you must prefix it with a dollar sign ($) to switch on this mode. The following example downloads eight waveform DC/DC power units in descending order from binary 9 to binary 2 at address 0 in the Sequencer Memory:

$VECD PARA,SM,0,8,(S0_1),00001001 00001000 00000111 00000110 00000101 00000100 00000011 00000010

Note that you can enter the blanks between the individual bytes.

You can also issue commands in binary mode from a file. In this case, you must prefix the file name with an exclamation mark when you call it; the dollar prefix before the command must be omitted in this case. Thus, you could put the command displayed above without the dollar sign into a command file where all the relevant commands use the binary format. If the name of the file is vec_comm, then you would have to issue

!vec_comm

at the prompt to execute the file in binary mode.
