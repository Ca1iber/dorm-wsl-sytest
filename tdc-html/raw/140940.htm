SlimBusController.translate()

This function converts the SLIMbus program, which must have been loaded with the loadFromSequenceFile() function (or defined programmatically), into transactions of the specified protocol test.

Syntax

Boolean translate(PROTOCOL_TEST & protocol_test);
Parameter

Parameter

Description

protocol_test

This parameter specifies the protocol test to which the transactions are to be added.

Return value

TRUE or FALSE according as the translation succeeded or failed.

Functional changes

  1. Introduced in SmarTest 7.2.1
