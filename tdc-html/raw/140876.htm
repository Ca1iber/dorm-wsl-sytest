RESULT_AREA_CONFIG_PINS.setDcValueResultAreaSize()

This function sets the size for the DC value result area. The number of results that can be recorded is limited by this value. If a test generates more results than what would fit into the result area, then these results will not be captured. The functional test result will be forced to 'failed' and the DC test status (TSST?) will reflect that measurements have been lost due to insufficient result memory.

Syntax

RESULT_AREA_CONFIG_PINS& setDcValueResultAreaSize(INT numberOfMeasurements);
Parameters

Parameter

Description

numberOfMeasurementResults

For the DC value result area, the size is given in the maximum number of measurement results that need to be stored into the area.

Return value

A reference to the RESULT_AREA_CONFIG_PINS() object.

Note When DPS/DC pins are used to perform TMU measurements, the DC value result area is used to store the TMU events as well. So when using this function to set a size for the DC result value area, consider an extra sufficient space in the area for TMU events. TMU events per channel requires 32 bit in data size while a DC measurement requires 64 bit.
