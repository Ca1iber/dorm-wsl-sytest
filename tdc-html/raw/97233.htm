FAST mode

To be used for devices with speed greater than 2 Gbps.

State of the art GDDR memory devices present a source sync interface with high speeds of up to 3 - 6 Gbps. For example, the data pins DQi and their read or write clock pins RDQSn and WRDQSn comprise the source sync pins or pin groups. Some memory devices work at even higher speeds. Fast mode and X8-mode deliver this speed.

Shmoo FAST mode

To be used for devices with speed greater than 2 Gbps.

Facilitates testing the source sync interfaces with device parameters, for example Vdd, varied after each test run. The tests are repeated automatically. The results of the test runs can be graphically displayed as a shmoo diagram. Shmoo Fast Mode uses fast mode pins.

STD mode

To be used for devices with speed equal or less than 2 Gbps.

Usually, only the source sync pin groups deliver high-speed data and clock signals, where fast mode is required. Other pins or slower devices can use the standard mode.

Shmoo STD mode

To be used for devices with speed equal or less than 2 Gbps.

Shmoo mode facilitates testing the source sync interfaces with device parameters, for example Vdd, varied after each test run. The tests are repeated automatically. The results of the test runs can be graphically displayed as a shmoo diagram. Shmoo standard mode uses standard mode pins.
HVM Solution

Data training

Test method

Comment

 

Data-Training

Data training determines the data skew during a read (output) operation of the device under test. Typically, DQo pins are trained.

Data-Training-Flex

Data Training Flex is an enhanced version of the data training TM. It not only covers read (output) data training, but also write (input) data training.
