Topic 81317

General data content options for STDF files

This topic covers the different options for STDF files.

Summary and detailed files

You can choose to have the software generate summary files, detailed files, or both. See the generateSummaryFile and generateDetailedFile options in Configuring the contents of an STDF file for information on how to select these file types.

Summary file

A summary file can be significantly smaller than the detailed file because it only includes the header and summary records, including the PRR, SBR, HBR, and TSR. It does not contain detailed test results information or records of the following types: PTR, MPR, FTR, DTR, GDR, PMR.

Detailed file

A detailed file contains the detailed test results and includes PTR, MPR, FTR, DTR, GDR, and PMR records.

Lot and Wafer level files

See the stdfFileContentLevel option in Configuring the contents of an STDF file for information about how to produce one file per lot or one file per wafer.

stdfFileContentLevel=lot will produce one STDF file for each lot tested. All of the summary records will contain counts that reflect the entire lot.

The dataformatter determines the lot boundary based on the application model level named "lot". If you have a level in the application model that represents the lot boundary that is not named "lot", specify the name of the lot level in the configuration file. See alternateLotLevelName in Configuring the STDF file locations for information about naming lot levels.

stdfFileContentLevel=wafer will produce one STDF file for each wafer tested. All of the summary records will contain counts that reflect only the wafer test results contained in that file. For example, if you test five wafers in a lot and you are generating one file per wafer, you would get five STDF files (one per wafer).

stdfFileContentLevel=auto will cause the data formatter to generate one file per lot when you are performing package test and one file per wafer when you are performing wafer test.
