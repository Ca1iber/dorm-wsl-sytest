TMU_PINS.suppressOverrunMsg()

This function allows you to suppress any overrun error messages. For more information see Pin Scale 1600 TMU Overrun Errors.

Syntax

void suppressOverrunMsg(Boolean suppress);
Parameter

I/O

Parameter

Description

I

suppress

If set to TRUE, overrun error messages are suppressed.

Return value

There is no return value.

Functional changes

  1. Introduced in SmarTest 7.2.0
