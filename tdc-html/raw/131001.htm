GET_USER_STRING_NAMES

This API retrieves the names of all the user-defined STRING type testflow variables and stores them in the parameter.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

void GET_USER_STRING_NAMES(STRING_VECTOR &allnames);
Parameter

allnames

The names of all the user-defined STRING type testflow variables.

Example

STRING_VECTOR stringVar;
int varSize;
GET_USER_STRING_NAMES(stringVar);
varSize = stringVar.size();
for(int i=0;i<varSize;i++)
{
  cout << stringVar[i] <<endl;
}

Functional changes

  1. Introduced in SmarTest 7.1.3
