Topic 144124

Launching the MTP tools from MTP-EWC

You can quickly lauch the MTP tools from the menu bar or toolbar of SmarTest.

About this task

You can launch the following tools from the MTP-EWC:

  • Bit Fail Map Viewer
  • Memory Test Viewer
  • MTP build configuration

Before you begin

Open the MTP perspective.

Procedure

  • To launch a tool from the menu bar
  • To launch a tool from the toolbar

Results

The selected tool opens.

Functional changes
