CMNT, CMNT? - (CoMmeNT)

The CMNT (CoMmeNT) command allows you to add comments to vectors for download.

Mode of operation

Do not confuse this command with the edit command TCMT. CMNT operates on the port level, TCMT on the label level.

CMNT

CMNT {act_vect_of_port}, {"text"}[, (port)]

CMNT?

CMNT? {act_vect_of_port}, [vect_length][, (port)]

returns: 

CMNT {act_vect_of_port}, {"text"}[, (port)]

Parameters

act_vect_of_port

Specifies the active vector of the referenced port at which the comment is to be inserted, or, in the query, the first vector of which the comment is to be displayed.

Note that you must count the active vectors of the port consecutively across all of its labels, starting from 0. Suppose, for example, that two labels, test_1 and test_2, are associated with the port, where test_1 has 8 active vectors, and test_2 has 3. Then, to insert a comment at the second vector of test_2, you must enter 9.

text

A string of up to 250 characters. The string must be enclosed with double quotes.

Comments can contain any characters with ASCII codes from 32 to 126, that is, all printable ASCII characters. To put a double quote character (", ASCII 34) into a comment, enter two double quote characters.

vect_length

In the query, the range of active vectors to be displayed, starting from act_vect_of_port. It can cross label boundaries.

port

Specifies the port to which the active vectors associated with the comments belong. If you do not specify a port, the comments to the active vectors of the default port @ are set or read.

Application

Download command in Pattern Tool.

Errors

An error is generated if:

  • The specified address exceeds the maximum vector address allowed by the system.
  • You specify a negative vector range.

Example

Display the sequencer area of the default port:

> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,9,,,(@)
< SQPG 3,RPTV,6,5,,(@)
< SQPG 4,STOP,,,,(@)
< SQPG 5,STVA,528,,,(@)
< SQPG 6,STSA,,,,(@)
< SQPG 7,GENV,12,,,(@)
< SQPG 8,STOP,,,,(@)

Add the comment "Start of test_2" to the active vector 15 of the default port @, that is, to the first active vector of the second label:

> CMNT 15,"Start of test_2"

Activate test_2 for editing and display the comments for its vectors with the label specific TCMT? query:

> TSTL "test_2",(@)
> TCMT? 0,11
< TCMT 0,"Start of test_2"

Functional changes

  1. SmarTest 6.5.3: Maximum comment length increased from 40 to 250.
