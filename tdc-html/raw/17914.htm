Getting a Hardcopy of the Timing Setup Window

To obtain a printout of the Timing Setup Window, pick the hardcopy option in the Doc pulldown menu.

The script /etc/opt/hp93000/soc/com/lbin/hp83000_lp is called whenever you send a screendump to the printer. In this script you can specify the default printer. At the time of installation you have to create this script by copying it from the script /opt/hp93000/soc0/com/lbin/hp83000_lp.def.
