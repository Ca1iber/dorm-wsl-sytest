Converting legacy converting memory test pattern

Subtopics

  1. How to convert legacy memory test pattern
  2. Messages related to Memory Test conversion

93000 legacy memory test pattern usually refers to MTST label. MTST labels are built on PPSS label. Executing MTST label typically generate memory test results, e.g, fail addresses. PPSS label can only be used for functional test, and executing PPSS label can only generate failing cycle results. Since the obsolescence of legacy memory test (since smartest 7.x release), MTST label is no longer supported, however PPSS label is still supported.

There is a need to use legacy memory test vectors need in Smartest 7.x for functional test. The solution is to remove all MTST label definitions and keep PPSS label definitions, and replace all MTST label calls by corresponding PPSS calls. The tool mtst2ppss.pl is developed for this requirement.
