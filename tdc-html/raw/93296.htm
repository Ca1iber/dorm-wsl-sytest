Topic 93296

Analyzing Memory Test Results

Subtopics

  1. Bit Fail Map viewer
  2. Memory Test Viewer
  3. Redundancy analysis
  4. Shmooing over a source-sync test with Shmoo Tool
  5. Fail bit count

The analysis of captured results as well as debugging can be accomplished with the help of the following tools:

  • Memory Test Viewer
  • Bit Fail Map viewer

Standard tools available with SmarTest:

  • Error Map

    allows to locate functional failures at a glance. These errors can be displayed on a pin-by-pin or cycle-by-cycle basis.

  • Timing Diagram

    visualizes the pattern (drive data, expected data, as well as received data) as actual signal.

  • Bit Fail Map Viewer

    stores data in an address related fashion; each failing cycle together with its reconstructed memory address and failing data bit is logged and can be viewed for a topological memory array analysis; a user-defined shared library defines the mapping of physical fail data to a pixel address.

    This tool takes the pass/fail information from the Error Map memory and displays all passing and failing addresses. It can display up to 64M-bit addresses.

    The overlay can be thought of as up to seven bitmaps that have been merged together. Each cell of the overlay has information about how many tests that particular cell of the memory passed or failed; this information is conveyed by having different colors for cells that fail more than one test.

  • Shmoo Tool

    On the shmoo tool, you can:

    • Perform fail bit count shmoo tests: For details, see Setting up a shmoo test on the shmoo tool and Viewing fail bit count shmoo plot on the shmoo tool.
    • Shmoo over a source-sync test.

      On the shmoo tool, you can perform fast shmoo by using the fast shmoo command on the tool.

      Note These tools are only enabled if the pattern is executed as ordinary functional test.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.3: Removed Fail Memory tool
  3. MTP 3.2.2: Shmoo Tool starts to support shmoo over a source-synce test.
