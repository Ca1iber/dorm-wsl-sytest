Topic 120304

Printing the hardware configuration and license checkout information

When you start SmarTest, the hardware configuration and license checkout information is displayed in the report window. The information is also saved in the .hw_license.info file located at /var/opt/hp93000/soc/tmp/93k.xxxxx, where 93k.xxxxx is the session name.

To make this information displayed again in the report window, choose Help > HW Config & License.
