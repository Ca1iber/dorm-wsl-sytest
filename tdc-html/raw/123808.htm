Topic 123808

Converting a binary scan setup into a binary multi-port setup

About this task

This task shows you how to convert a binary vector file that contains an F330 scan setup into a binary vector file where the scan setup is realized by multiple ports.

Before you begin

The ASCII Interface must be installed.

Procedure

  1. The working directory is the waste directory of the current device.

    Create two subdirectories tmf_files and avc_files.

  2. Define a b2a configuration file MIDAS.bcf as follows:

    B2A_DIR_FILE

    tmf_dir ./tmf_files

    avc_dir ./avc_files

  3. Call b2a as follows:

    /opt/93000/aif/b2a/bin/b2a -It -b MIDAS.bcf -o MIDAS -f ../testflow/l6b0394pkg

    This is the default location. The path may different on your system.

  4. b2a modifies the configuration file MIDAS.bcf. Edit this file in order to restrict the vector retranslation to the patterns containing scan instructions.
  5. Call b2a as follows:

    /opt/93000/aif/b2a/bin/b2a -Iv -b MIDAS.bcf -o MIDAS

    This is the default location. The path may be different on your system.

  6. Create a new pin configuration file MIDAS.pin_mport, where all scan pins are included in the port SCAN, and all parallel pins in the port PARA.
  7. Copy the global configuration file MIDAS.aic created by b2a to init.aic.
  8. Prepare init.aic for a multi-port setup. This includes:
    • Add the AI_DIR_FILE section to the file as follows:

      AI_DIR_FILE

      tmp_dir ./tmp

      tmf_dir ./tmf_files/

      avc_dir ./avc_files/

      pinconfig_file ../configuration/MIDAS.pin_mport

      single_binary_pattern_dir ./vectors

      pmf_file ./vectors/MIDAS

      pmf_path ../vectors

    • Add the AI_V2B_OPTIONS line to the file as follows:

      AI_V2B_OPTIONS -ALCET -imp -Y 32x60000 -xpi -z C400

    • Create separate patterns <name>_scan and <name>_para for the SCAN and the PARA port for all source patterns <name> that contain SCAN instructions.
    • Specify the <name>.avc file created by b2a as the ASCII vector file for both patterns.
    • Add the definition of the multi-port burst for ports SCAN and PARA.
  9. Run ait as follows:

    ait -FPU -Mwet -z C400 -c init.aic -b MIDAS

    If the conversion fails and you have to rerun ait, be sure to remove all *.vbc files, *.tmf files, as well as MIDAS.tim, MIDAS.aiv, MIDAS.aic.

  10. Run aiv as follows:

    aiv -c MIDAS.aiv 2>&1 | tee aivlog

Results

A multi-port setup that is equivalent to the original F330 scan setup.
