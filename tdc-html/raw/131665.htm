SHARING_CONFIGURATION.getBufferPinMap()

The getBufferPinMap() member function of SHARING_CONFIGURATION returns a reference to the buffer pin map. The buffer pin map maps site numbers to buffer pin lists.

Syntax

const map<int, string> & getBufferPinMap() const
