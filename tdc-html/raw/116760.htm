TTUD - (Transition Test UnDefine)

TTUD deletes a transition test set.

Syntax

TTUD {"tt_set_name"}

Parameters

tt_set_name

Specifies the name of an existing transition test set.

ALL

Remove all existing transition tests sets

Application

Protocol engine test.

Errors

An error is generated if no transition test set with the specified name exists.

Example

> TTUD   "myTTTrckSet1"

Functional changes

  1. Introduced in SmarTest 7.0.1
