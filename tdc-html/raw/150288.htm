EVENT_VCIM.getLimitHigh()

Reads the upper limit that has been defined by EVENT_VCIM.limits() or EVENT_VCIM.limitHigh().

The value is read from the corresponding EVENT_VCIM object and returned as an EVENT_VALUE_DOUBLE object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

bool getLimitHigh(EVENT_VALUE_DOUBLE & high) const;
Parameter
Parameter Description
highLimit

The programmed upper limit in A (Ampere).

Return value

bool value indicating the state of the limit definition:

  • true: Limit has been defined by EVENT_VCIM.limits() or EVENT_VCIM.limitHigh().
  • false: No limit is defined or the limit has been cleared by EVENT_VCIM.clearLimits().

Example

For an example see EVENT_VCIM.
