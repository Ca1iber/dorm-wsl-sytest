TESTSET().testsuite_default()

This member function of TESTSET cancels the test name which has been set by a prior call of the testsuite(const STRING &name) member function and returns to the default mode.

In default mode, the TestSuiteNameAttrType found in the TestSuiteStartEvent is used to identify the test suite, which is the parent test suite of the currently active test method.

Syntax

TESTSET & testsuite_default();

Example

TestSet.testsuite_default();

Related information

TESTSET
