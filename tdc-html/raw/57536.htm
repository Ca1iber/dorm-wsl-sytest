GenericDataEventType

This event is a flexible container that can hold an arbitrary number of attributes (from 0 to 65535 attributes) of the GenericDataFieldAttrType type.

Attributes

  • GenericDataFieldAttrType

    This type of attribute contains three member fields:

    • type: describes the data type pointed to by the data pointer
    • length: the length of the data in bytes
    • data: a pointer to the data for the GenericDataFieldAttrType attribute
  • TimeStampAttrType

    Holds the time when the event was logged.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.3.5.3: New attribute TimeStampAttrType
