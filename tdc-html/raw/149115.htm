Topic 149115

rdi.tmu().interSkip()

Sets the number of events to ignore between the samples that are taken by TMU pin(s). If data rate is specified, the value will only take effect if it is greater than the value calculated from rdi.tmu().dataRate().

Note This functionality is not supported for DC Scale pins. The function must therefore be omitted or the programmed value must be set to 0.

Syntax

tmuBase& interSkip(int iInitSkipSamples);
Parameter
Parameter Description
iInitSkipSamples The number of event to ignore between samples.

Return Value

A reference to the tmuBase object.

Example

RDI_BEGIN();

    rdi.tmu("1").pin("PVI8_PMU_1") // PVI8_TMU
        .measMode(TA::RISE_TIME)
        .interSkip(0)
        .vth(1.0 V, 2.0 V)
        .samples(50)
        .execute();

    rdi.wait(100 us);

    rdi.tmu("2").pin("PS1600_1") // Digital TMU
        .measMode(TA::RISE)
        .interSkip(3)
        .vth(1.0 V)
        .samples(50)
        .execute();

    rdi.wait(100 us);

RDI_END();
Note For supported DC Scale pins, the preScaler() and dataRate() settings must be the same within one RDI_BEGIN() ... RDI_END() block. Functions interSkip() and initDiscard() must be omitted or set to 0.
RDI_BEGIN();

    rdi.tmu("1").pin("PVI8_PMU_1")
        .vth(3.0 V, 5.0 V)
        .samples(4)
        .measMode(TA::PULSE_HIGH)
        .preScaler(2).dataRate(25 MHz)
        .execute();

    rdi.wait(1 ms);

    rdi.tmu("2").pin("PVI8_PMU_1")
        .vth(1.0 V, 3.0 V)
        .samples(8)
        .measMode(TA::RISE_TIME)
        .preScaler(2).dataRate(25 MHz)
        .execute();

    rdi.wait(2 ms);

RDI_END();
Note For a digital pin, all the parameters must be the same within one RDI_BEGIN() ... RDI_END() block.
RDI_BEGIN();

    rdi.tmu("1").pin("PS1600_1").vth(1.0 V).samples(5).measMode(TA::RISE).execute();

    rdi.wait(1 ms);

    rdi.tmu("2").pin("PS1600_1").vth(1.0 V).samples(5).measMode(TA::RISE).execute();

    rdi.wait(2 ms);

RDI_END();
