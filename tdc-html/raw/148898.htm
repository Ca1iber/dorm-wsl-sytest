Parameters for interface identification

The following parameters must be set for the LAN communication between the equipment and the driver:

  • interface_type

    Make sure that you assign lan in the configuration file.

  • symbolic_interface_name

    Make sure the value of this parameter is starting with either TCP or UDP. Set the socket on the equipment side to a passive mode (server).
