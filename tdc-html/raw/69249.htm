Debugging a Driver Configuration

Subtopics

  1. General debugging hints
  2. Debugging a GPIO driver configuration
  3. Debugging a GPIB driver configuration
  4. Debugging a LAN driver configuration
  5. Debugging a handler configuration
  6. Debugging a prober configuration

If your configuration does not work correctly, you may have to edit the configuration file. The configuration files provide detailed information on how to change parameters.

How to debug a configuration To debug a configuration, read through the following topics according to the interface or equipment used:

  • General debugging hints
  • The corresponding interface-dependent debugging hints:
    • Debugging a GPIO driver configuration
    • Debugging a GPIB driver configuration
  • The corresponding equipment-dependent debugging hints:
    • Debugging a handler configuration
    • Debugging a prober configuration
  • The section relating to your configuration as found in the following chapters:
    • General Handler Driver
    • General Prober Driver

Changing the configuration at run-time By calling the function ph_set_configuration from the application model, you can directly change the setting of any parameter that is defined in the attributes definition file of the plug-in, except for those that are not changeable at run-time per definition.

For detailed information on how to troubleshoot and change configurations at run-time, see the Prober/Handler Drivers guide.

"Missing" parameters Not all parameters are available for all configurations. If you cannot find a particular parameter in a configuration file, that means this parameter is not valid for the configuration.

If you cannot solve a problem, or if you run into unusual control situations, increase the debug level in the configuration, try to reproduce the problem, collect all available data and contact your Advantest representative.
