Creating a Digital Capture setup (1)

Procedures

Capture mode:

Depending on the wavetable used by the capture pattern, the capture mode is set to Selective or Sequential

If the pattern uses a wavetable containing selective capture actions ('C' for Capture, or 'D' for Do not Capture), the Selective mode is set, otherwise, the Sequential mode is set.

If none of the device pins is defined as a capture pin, the capture mode is set to Undefined.

Resolution:

  • Standard: One capture sample per test system period.
  • Double: Two capture samples per test system period (for Sequential capture mode only).
  • Statemap: The number of capture samples per test system period are read directly from the X-mode definitions in the STATEMAP section of the pattern's wavetable.
