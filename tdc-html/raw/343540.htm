The <dgt> element

This element stores results of a DAC test performed using the SmartRDI's dgt() class.

The <dgt> element stores DAC test results in its waveform and complexWaveform attributes. The waveform attribute saves waveforms returned by a getWaveform() function, while the complexWaveform attribute saves waveforms returned by getComplexWaveform().

Get Result Function in SmartRDI

ORE File Syntax Example

ARRAY_D& getWaveform(pin);

<dgt waveform = "./ORE/waveform.txt" />

<dgt waveform = "-1.22,1.23,1.33,1.43" />

ARRAY_COMPLEX& getComplexWaveform(pin);

<dgt complexWaveform="./waveI, ./waveQ" /> *
* A complex waveform requires two waveform files, as shown in the following example:

Example

Below is an example of the <dgt> element and its corresponding SmartRDI code block.

An ORE file containing <dgt> elements:

<offlineResultEmulation>
  <id name = "d1">
    <pin name = "audio">
      <dgt Waveform = "./audioWave" />
    </pin>
  </id>   
  <id name = "d2">
    <pin name = "pinI,pinQ">
      <dgt complexWaveform = "./waveI,./waveQ" />
    </pin>
  </id>
</offlineResultEmulation>
The corresponding SmartRDI code block that can generate this ORE file:
RDI_BEGIN();
  rdi.dgt("d1").pin("audio").core(TA::LF)
     .samples(1024).FS(100 KHz).execute();
RDI_END();

RDI_BEGIN();
  rdi.dgt("d2").pin("pinI,pinQ").core(TA::IQ)
     .samples(1024).FS(10 MHz).execute();
RDI_END();

rdi.id("d1").getWaveform("audio");
rdi.id("d2").getComplexWaveform("pinI,pinQ");
