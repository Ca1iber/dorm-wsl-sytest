burstUpload()

If you have multiple digCap() results to upload for the same pin, this function can help reduce the result uploading time. The results of multiple digital capture results to upload within one burstUpload().begin()/burstUpload().end() block will be combined and uploaded together. Individual results can still be separated.

Syntax

burstUpload();

Limitations and Checks for digital capture

In one digCap().burstUpload().begin()/digCap().burstUpload().end() block:

  • One pin cannot
    • be set to both modes "SER" and "PAR"
    • have different values for bitPerWord()
    • join different "PAR" pin combinations
    • have initDiscard() or InterSkip() if digCap() is inserted in an existing label
  • In one execute() with multiple pins, parameters of samples(), initDiscard() and interSkip() should be equal for all pins.
Note

Do not use rdi.digCap() and rdi.smartVec() commands for the same pin in the same rdi.digCap().burstUpload() block. For example,

RDI_BEGIN();
   ...
   rdi.digCap().burstUpload().begin();
      ...
      rdi.digCap().pin(A)....;
      rdi.smartVec().pin(A).readXxx()....; // Read with the DIG_CAP mode
      ...
   rdi.digCap().burstUpload().end();
   ...
RDI_END();

In this example, rdi.smartVec() will read bits or data with the digital capture mode for the same pin "A" as in the rdi.digCap() command. This is NOT allowed and will not work.

Examples

Common upload with separated results retrieval

This example uses burstUpload() to combine multiple results into a common upload, and retrieves results one by one through individual result ID.

RDI_BEGIN();
 ...
   rdi.digCap().burstUpload().begin();
      rdi.smartVec();             // register setting 1
      rdi.digCap("10M").pin(A).samples(1000).execute();
      rdi.smartVec();            // register setting 2
      rdi.digCap("20M").pin(A).samples(2000).execute(); 
      rdi.smartVec();            // register setting 3
      rdi.digCap("30M").pin(A).samples(4000).execute();     
   rdi.digCap().burstUpload().end();
 ...
RDI_END();

ARRAY_I vec1,vec2,vec3;
vec1=rdi.id("10M").getVectorBit();
vec2=rdi.id("20M").getVectorBit();
vec3=rdi.id("30M").getVectorBit();

Common upload with combined results retrieval

This example uses burstUpload() to combine multiple results into a common upload, and retrieves combined results through a common result ID.

RDI_BEGIN();
 ...
   rdi.digCap("bid").burstUpload().begin();
      rdi...
      rdi.digCap().pin(A).samples(1000).execute();
      rdi...
      rdi.digCap().pin(A).samples(2000).execute(); 
      rdi...
      rdi.digCap().pin(A).samples(4000).execute();     
   rdi.digCap().burstUpload().end();
 ...
RDI_END();

rdi.id("bid").getVector();
rdi.id("bid").getVectorBit();
