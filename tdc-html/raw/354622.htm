Topic 354622

Revoking access to a virtual machine

Delete the public key information of a specific user from the key configuration file to prevent that user from accessing the virtual machine.

About this task

When you have given a user access to a virtual machine, you can revoke it when that user should no longer be able to work with that virtual machine.

VNC Viewer is used as the VNC client in this procedure. You can use other VNC clients as you prefer. For details on using other VNC clients, see their documentation.

Procedure

  1. Open VNC Viewer.
  2. Connect to the virtual machine.

    See Connecting to a virtual machine via VNC for details.

  3. Right-click the desktop and click Konsole in the menu.

    The Konsole window opens.

  4. Open the key configuration file authorized_keys.
    1. In the Konsole window, enter cd ~/.ssh/ to switch to the .sshdirectory of the virtual machine.
    2. Enter gedit authorized_keys to open the key configuration file.
  5. Delete the public key of the user whose authorization you want to revoke from the file.
  6. Save the configuration file.

Results

The user whose public key you deleted can no longer access the virtual machine.

Functional changes

  1. Introduced in SmarTest 7.6.2
