Changing pattern tool preferences

The pattern tools provides several adjustable values and optional settings, for example, the display of error annotations and the use of error markers.

About this task

You can change the default values and settings of the pattern tools under "Pattern Debug Tool" in the Preferences window.

Before you begin

Make sure at least the Pattern Explorer is open.

Procedure

  1. In one of the pattern tools, for example the Pattern Explorer, right-click and select Preferences. The Preferences dialog opens.
  2. Adjust the preferences as required.

    Note that the left pane of the Preferences dialog lists additional items related to the pattern tools, for example:

    • Layout
    • Pattern Explorer and
    • Table Annotations
  3. When done, click OK.
