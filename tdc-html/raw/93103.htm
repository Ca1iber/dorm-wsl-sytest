The Pin Configuration tool contains a hierarchical view in the Test Program Explorer and setup editors.

The hierarchical view shows the setup components in the Pin Configuration tool.

Editor

Function

Pin Settings

Define the pin.

Groups

Define the pin group.

Ports

Define the port.

Alias Sets

Define the pin alias sets.

DC Scale Extensions

Request licenses for extended features of DC Scale cards.

DC Scale Limits

Define voltage and current limits for DC Scale cards.
DC Scale Regulation Select regulation settings for DC Scale cards.
DC Scale Safety Select global safety parameters for voltage drop levels.
Ground sense editor Select sites for ground sense pins.

Protocol Assignments

Assign protocols and pin roles to ports and resource pins.
