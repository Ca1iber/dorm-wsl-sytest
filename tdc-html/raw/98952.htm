How to create and execute a universal-test-method-based testflow

The procedure shows you how to create a testflow based on universal test method.

About this task

To create a testflow based on universal testflow, you need to use both the graphical testflow editor and tabular testflow editor.

Before you begin

Make sure you are using SmarTest 6.3 or later, and your universal test method libraries are ready to use.

Procedure

  1. In the test program editor of the 93000 Setup perspective, right-click the testflow icon and choose New from the shortcut menu. Type the testflow name and click OK.
  2. In the test program editor right-click the testflow name and select Open with Flow Sequence Editor from the shortcut menu. The flow sequence editor is opened.
  3. Select and load the test setups for the testflow. Insert the test suites and bins in the testflow. (See Inserting a test suite in the testflow and Inserting a bin in the testflow.)
  4. Right-click the testflow name and select Open with > Flow Data Editor. The testflow is opened in the flow data editor.
  5. To select another test method for the test suite, double click the test method name and click the ... button on its right side. The Select Test Method dialog box will be displayed. You can choose the test method you want from it.
  6. Modify the parameter values and limit values in the Properties view.
  7. Save the testflow. In Test Program Explorer right-click the testflow icon and select Save.
  8. To execute the testflow, right-click in the Flow Sequence Editor or Flow Data Editor and select Run Testflow. You can also right-click the testflow in the Test Program Explorer and select Run.
    Note When you execute a UTM-based testflow, a UTM executor is started. The executor will not be stopped after the testflow execution. The testflow will not be reset to the initial state before execution. To ensure the testflow in the initial state before each execution, you can insert an initialize or a download special test suite to the testflow. In the special test suite, you can use a test method to set the testflow to the initial state.

Results

The testflow is ready for execution and test method debugging.

What to do next

Debug the test method.
