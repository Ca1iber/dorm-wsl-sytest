Topic 123859

Using the d2s-framework

Subtopics

  1. Multiple transaction ports
  2. Transaction ports without a protocol
  3. Global framework mode

About this task

The d2s-framework controls the generation of multiport bursts and the execution of the transaction block. Therefore each protocol needs to be registered with the d2sFramework in order to make the protocol methods available to your test method.

The d2s-block, created by d2s_LABEL_BEGIN() and d2s_LABEL_END(), defines the unique name of the burst pattern and controls the mode of the d2s-framework. All transactions done within the d2s-block will be sent to the device in a single burst.

This task describes the steps necessary for instantiating and registering protocols with the d2sFramework.

Note Do not use any other API calls other than the d2s methods in the d2s-block.

Before you begin

Ensure you have carried out all preparation and configuration steps as described in Prepare device setup, Prepare the test method infrastructure and Configure the protocol.

Procedure

  1. Create a d2sFramework handle. 
    d2sFramework fr;

    This framework handle ("fr") will be used to access the d2sFramework methods.

  2. Instantiate your protocol, for example d2sJTAG. 
    d2sJTAG& jtag = d2sJTAG::Instance();

    The jtag object reflects your protocol. It uses your protocol file, for example d2sJTAG.h to handle transactions, like write and read.

    Note If you are using multiple protocols, each protocol has to be instantiated this way. Refer to Multiple transaction ports.
  3. Register your protocol ("jtag") with the framework.. 
    fr.registerTransactionPort(jtag);
  4. Define the d2s-block's begin API with the appropriate details, like burst label name and mode. 
    fr.d2s_LABEL_BEGIN("my_BurstLabelName", d2sFrameWorkModeType::LearningMode);
  5. Specify protocol port specific transactions within the d2s-block, for example 
    jtag.write(0xdead, 0xbeaf);
  6. Call the d2s-block's end API.

Results

You have completed the implementation of a protocol using d2s.

Example

This example code is based on the example code shown in Prepare the test method infrastructure. It has been enhanced to multisite and by the d2s-block to show where to add d2s code. The modifications mentioned above are highlighted in bold.

#include "testmethod.hpp"

//for test method API interfaces
#include "mapi.hpp"

//for d2s specific interfaces
#include "d2s_files/d2sJTAG.h"        // This is the users protocol template file.
#include "d2s_files/d2sFramework.h"

using namespace std;

/**
 * Test method class.
 *
 * For each testsuite using this test method, one object of this
 * class is created.
 */
class d2sExample: public testmethod::TestMethod {

protected:
  /**
   *Initialize the parameter interface to the testflow.
   *This method is called just once after a testsuite is created.
   */
  virtual void initialize()
  {
    //Add your initialization code here
    //Note: Test Method API should not be used in this method!
  }

  /**
   *This test is invoked per site.
   */
  virtual void run()
  {
    //Add your test code here.
    ...
    //Add the initial d2s framework specific code to your test method.
    //Each protocol needs to be registered with the d2s-framework.

    // step 1
    d2sFramework fr;

    // step 2
    d2sJTAG& jtag = ds2JTAG::Instance();

    // step 3
    fr.registerTransactionPort(jtag);

    //Multi site handling and d2s-block
    ON_FIRST_INVOCATION_BEGIN();

       // step 4
fr.d2s_LABEL_BEGIN("my_BurstLabelName", d2sFrameWorkModeType::LearningMode);
          //LearningMode - creating labels and the burst-label
          //ProductionMode - using predefined burst-labels

          // step 5
jtag.write(0xdead, 0xbeaf);
jtag.write(0xabcd, 0xef);
jtag.read(0x1, "one");

       // step 6
fr.d2s_LABEL_END();

       // do your measurement here
          ...

    ON_FIRST_INVOCATION_END();

    return;
  }

  /**
   *This function will be invoked once the specified parameter's value is changed.
   *@param parameterIdentifier
   */
  virtual void postParameterChange(const string& parameterIdentifier)
  {
    //Add your code
    //Note: Test Method API should not be used in this method!
    return;
  }

  /**
   *This function will be invoked once the Select Test Method Dialog is opened.
   */
  virtual const string getComment() const 
  {
    string comment = " please add your comment for this method.";
    return comment;
  }
};
REGISTER_TESTMETHOD("d2sExample", d2sExample);
