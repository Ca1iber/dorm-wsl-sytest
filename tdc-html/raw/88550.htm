Topic 88550

Automatic waveform generation

Subtopics

  1. Setting up automatic waveform generation

MTL will generate waveforms for you if it detects that you have not defined any waveforms. During compilation it will generate suitable waveforms by analyzing the pattern setups. It will either create new wavetables or complement the existing ones.

When automatic waveform mapping is active, the compiler checks the timing file or the waveform mapping file specified with the :waveformMap: keyword in the APG pattern file. If the waveform is not found in the wavetable, waveforms for pins will be automatically generated.

If the wavetable does not exist, the compiler generates it. For indirect waveform mapping it will generate a waveform file if this does not yet exist. The specification for the waveform file is taken from the :waveformMap: keyword in the APG pattern file.

In generating a new waveform in the timing or waveform mapping file, the MTL compiler assigns each logical state to an edge in the newly created waveform. State characters 0 and 1 (for input pins); H, L, and X (for output pins); and 0, 1, i, o, I, O, A, and z (for I/O pins) are supported. When the waveforms have been generated, you need to check whether they are suitable or not. If not, edit them and recompile the APG pattern.

Data formats (except for the default DNRZ format) and the creation of break vectors are not supported. If break vectors are required you need to add them manually.

Base-replicated wavetables

When a vector pattern requires non-interruptible sequences and the vector mode for maintenance operations is used (as opposed to the sequencer mode), the wavetable needs to include waveforms both for interruptible and for non-interruptible sequences. In this case, waveform indexes from 80h to FFh are reserved for non-interruptible waveforms.

If, in such wavetables, the interruptible waveform with a particular index looks exactly the same as its non-interruptible equivalent (with an index 0x80 higher), the wavetable is called replicated or base-replicated. (For example, the waveform at 0 is the same as at 80, 1 is the same as 81, and so on.)

Each waveform in a pair is called a replica of the other. (For example, the waveform 11 is a replica of 91, and vice versa.)

Wavetables in which some waveforms have replicas but not all are called partially replicated.

Wavetables in which no waveform has a replica are called non-replicated. Wavetables are also considered non-replicated when two corresponding waveforms (that is, waveforms the index of which differs by 0x80) are different from each other. (For example, if waveform 0 is 0110 and waveform 80 is 1100.)

Note There is a limit of 256 waveforms per wavetable. In wavetables containing non-interruptible waveforms there can be up to 128 interruptible and 128 non-interruptible waveforms.

The compiler automatically creates replicated wavetables when needed:

  • If the APG program uses is{} or nis{} instructions.
  • If the APG program uses a device maintenance operation.
    Note Normal, instead of replicated, wavetables are generated when the sequencer mode is used for maintenance operations.

Device cycle names for the added waveforms will be automatically generated by the compiler, which reflect the logical actions of the waveforms. When a non-interruptible waveform is created, the device cycle name for the waveform will be given the suffix _ni.

The compiler adds the minimum number of waveforms that is required to execute the pattern when it adds waveforms to existing wavetables.
