Topic 104084

How to execute a BLC from workorder

The BLC can be executed from a workorder.

About this task

To execute a BLC from workorder, you need to create a workorder with the workorder format for BLC execution.

The table below shows the comparison of the two workorder format.

Workorder format for test program execution

Workorder format for BLC execution

hp93000,workorder,0.1

device: device1

test_prog_rev:

test_prog: testprog

full_usersetting: production_user_setting

licensing_file: license

workorder_variable1=1

workorder_variable2=2

hp93000,workorder,0.1

device: device1

test_prog_rev:

blc_executable: /opt/blc_executable/blc1

blc_input: /opt/blc_input/device1/blc_input1

full_usersetting: production_user_setting

licensing_file: license
Note test_prog_rev: If the test_prog_rev is set and INSTALLED_DUT_PATH in the org file is set, the path of the device will be /INSTALLED_DUT_PATH/device/test_prog_rev.
Note full_usersetting: You can set up the path to a production-settings file that will be applied to the workorder here.

In the workorder format for BCL execution, the parameters blc_input, full_usersetting and licensing_file are optional and other parameters are mandatory. The sequence of the parameters in the workorder file is fixed and must not be changed.

The parameter test_prog and blc_executable/blc_input must not exist in one workorder file. Otherwise, a warning message will be displayed.

  • If the 4th line of the workorder file is test_prog, then the test program will be executed and the parameters blc_executable/blc_input(if exists) will be ignored.
  • If the 4th line of the workorder is blc_executable, then the BLC executable file will be executed and the parameter test_ prog(if exists)will be ignored.

Before you begin

Make sure you are using SmarTest 6.5.0 or above version and your device setups are ready to use.

Procedure

  1. To create a workorder file for BLC execution, create a file manually with nedit or other editing commands and type in the content according to the format above.
  2. Execute the workorder file as usual. (See Executing a Workorder.)

Results

The BLC is executed and the device is tested.

Functional changes

  1. Introduced in SmarTest 6.5.0
