Starting the Memory Test Viewer

You can start the Memory Test Viewer either from SmarTest, or from Memory Test Manager, or use an execution file.

Before you begin

SmarTest must be installed.

The DUT must have been set up and there must be a valid map converter library.

Procedure

  1. In the menu bar of SmarTest, click 93000 > Memory Test > Memory Test Viewer.

    Alternatively, you can:

    • In the toolbar of SmarTest, click the Memory Test button and choose Memory Test Viewer, see the below picture:

      Or,

    • Click the Memory Test Viewer icon in the Memory Test Manager.

      Or,

    • In the file manager, double-click the shell script in the /opt/93000mts/mts/mtest_viewer/bin/MTestViewer directory.

      The Memory Test Viewer window is displayed:

  2. Select a data log file for a specific device using the File menu.
  3. Load the data log file, select the desired result information, and prepare it for analysis with the Bit Fail Map Viewer.
