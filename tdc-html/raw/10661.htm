Topic 10661

Controlling multiple test sites

Subtopics

  1. Activating and masking a site
  2. Setting the setup focus
  3. Defining the query focus
  4. Controlling the site match function

When you perform tests on multiple test sites, you need to be able to:

  • activate and mask the receivers for individual test sites
  • determine which sites will be affected by subsequent setup commands
  • determine which site has the query focus

In addition, if your pattern uses match loops or shared analog modules, you may need to configure the site match function accordingly.

Functional changes

  1. Introduced before SmarTest 6.3.2
