Topic 86697

PPTIA_CONTROL

This API executes the operation specified in the second parameter on the pins specified in the first parameter.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

Syntax

void PPTIA_CONTROL(const STRING & pinlist, TM::PPTIA_ACTION action);
Parameters

I/O

Parameter

Description / Range

I

pinlist

Pins on which the action is to be executed.

I

action

The action to be executed. Possible values are:

 

 

TM::SET_TIA_MODE

Defines the pins for TIA mesurements.

 

 

TM::RESET_TIA_MODE

Restores original setup and undefines pins for TIA measurement.

 

 

TM::RESET_TIA_SETUP

Restores original setup.
