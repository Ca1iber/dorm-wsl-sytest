Executing the measurement

Run the TDR connectivity check and view the report of connectivity.

Before you begin

Finish setting up the configuration preferences.

Procedure

Click the Analyze Test Program button.

The TDR measurement starts running. The execution status is shown in the System Output field of the Console tab.

Results

When the execution is complete, the connectivity check report is displayed at the right of the TP360 window. See TDR measurement report for the report details.

Functional changes

  1. Introduced in SmarTest 7.6.1
