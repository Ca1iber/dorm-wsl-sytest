samplePeriod()

Specifies the sampling period to capture the waveform.

This function can be used only in pattern‑based mode.

The sample rate can be set by one of the functions FS(), sampleCycle(), or samplePeriod(). SmartRDI issues a warning at the first run and selects a sample rate that is defined by the pattern cycle period and the 32 vectors that are required per DC event if none of these functions is used. The programmed sample rate must always be lower than the sample rate that is supported by the hardware.

Syntax

samplePeriod(double dSamplePeriod);
List of parameters

Parameter

Description

dSamplePeriod

The sampling period.

Example

rdi.dc().pin("DPS_pin_1")
        .vForce(2 V).iMeas().samples(1024).samplePeriod(100 us).execute();

Functional changes

  1. Introduced in SmartRDI 2.2.0
