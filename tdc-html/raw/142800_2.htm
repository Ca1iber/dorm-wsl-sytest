Topic 142800

connect()

Connects a DPS pin. Supported DPS pins are the DC Scale pins in the DPS operating mode.

The function can be used only in the code‑based mode.

Note DC Scale pins must be configured for the DPS operating mode in the DPS Pins editor. This function is not supported for the PMU operating mode of DC Scale pins.

Syntax

dcBase& connect();

List of parameters

There are no parameters.

Return Value

A reference to the dcBase object.

Example

rdi.dc().pin("pinA").connect().execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
