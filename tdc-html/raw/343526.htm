Applying Offline Result Emulation in SmartRDI

Subtopics

  1. rdi.enableOre()
  2. rdi.oreFile()
  3. rdi.startNextOreTemp()

Applying Offline Result Emulation in SmartRDI involves enabling ORE mode and specify the ORE file path.

ORE can be applied at a global level or a local level.

Apply ORE for SmartRDI at a global level using RDI_Configure

In SmartRDI 2.5.0, the RDI_Configure file supports two new keywords for the ORE handling. See the new keywords ENABLE_ORE and ORE_FILE in RDI_Configure file.

Apply ORE for SmartRDI at a local level using functions

SmartRDI 2.5.0 supports the selective usage (test suite or code block) of ORE by two new functions. See the new functions rdi.enableOre() and rdi.oreFile().

Functional changes

  1. Introduced in SmartRDI 2.5.0
