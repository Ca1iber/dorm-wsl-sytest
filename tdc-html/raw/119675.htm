Topic 119675

Renaming a utility purpose

Procedure

  1. Right-click the utility purpose in the Test Program Explorer and choose Rename.
  2. In the "Naming a Utility Purpose" dialog, enter the new name in the Utility Purpose Name field.

    Names can be up to 16 characters long and must not contain the characters: # ; ( '' ) ? @ ,

  3. Click OK.
