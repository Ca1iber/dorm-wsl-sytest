Topic 21731

Using the clamp for termination

The clamping is used to smooth the output signal of the device. Peaks generated by reflections of the signal can be limited by specifying the clamp voltage levels. If the DUT is driving into an unmatched environment, you can assign clamp voltages to the relevant o and io pins, thereby eliminating reflections caused by the mismatch.

Before you begin

Make sure that the Level Setup window is open.

Procedure

  1. In the Level Setup window, choose Select > Edit Equations.
  2. The Level Equation editor opens. In the level equations, set the clamp voltage levels for o pin or io pins: 
    vcl = clamp low level
vch = clamp high level
  3. To download the values in the level equations to the test system hardware, in the Level Equation editor, press F8.
  4. To verify the result of clamp voltage level settings, in the Level Setup window, choose Select > Show I/O Eqn. & Specs Results.

    You can also directly set the clamp in the Level Setup window. For the pin of interest, select on in the clamp mode column and type the values in the clamp low [V] and clamp high [V] columns. However, this will result in the inconsistence between the setting in the Level Setup window and the content of the level equation file. See How to restore the equation settings after you change them in the Timing/Level Setup window.

Results

In the Level Setup window, the clamp mode column shows on and the clamp low [V] and clamp high [V] columns display the clamp voltage levels.
