Editors

An editor is typically used to edit or browse a resource.

SmarTest provides dedicated editors that are described in the context of the tasks they are used for:

  • Alias Set Editor
  • C/++ editor
  • Flow Data Editor
  • Flow Sequence Editor
  • Group Editor
  • Multiport Burst Editor
  • Pin setting editors
  • Protocol editor
  • Utility Purpose Editor
