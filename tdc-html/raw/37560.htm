The FORMAT Statement

The FORMAT statement has the following syntax:

FORMAT (<pin_1>|<pin_group_1>|&&&) ... (<pin_n>|<pin_group_n>|&&&);

The function of the individual statements is as follows:

  • FORMAT: This keyword identifies the FORMAT statement.
  • <pin_i>: Specifies the name of a pin.
  • <pin_group_i>: Specifies the name of a pin group. In the vector rows, the state characters for the individual pins of this group can either be stated explicitly or in abbreviated form. See The ASCII Vector Row.
  • &&&: This heading causes the vector translation to ignore the respective column.
