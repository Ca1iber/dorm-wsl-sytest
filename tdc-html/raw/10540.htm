Topic 10540

Controlling the sequencers

The sequencers execute the sequencer program of a label. They can be controlled with the following commands:

Command

Description

SQST

Serves to start and stop the sequencers

FTST?

This query starts the sequencers and stops them again after the test has completed.

SQTO

Defines the SmarTest Work Center value of the sequencers

SQGB

Defines the termination mode of the sequencer

SQSL

Defines the label which the sequencers are to execute

Functional changes

  1. Introduced before SmarTest 6.3.2
