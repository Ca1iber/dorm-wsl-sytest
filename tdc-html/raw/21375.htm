Introduction

Subtopics

  1. Test Method Program Introduction

This manual introduces Universal Test Method and provides detailed information and programming essentials for the Test Method API. The test method API is used to control the V93000 tester hardware and calculate data in your test method programs.

This manual covers the following topics:

  • Universal Test Method

    Introduces the concept of the test method programming style that is available from SmarTest 6.3 and how to create and use the test method programs in the device testing.

  • Test Method Programming Essentials

    Describes the test method API programming in the test method programs.

  • API Reference

    Describes the test method APIs in detail. The APIs are listed in alphabetical order. The APIs which are not used in test method programming like HVM API, BLC API, HVM session info API, digital calibration API and test suite control API can be found in Test Program Management.

  • Test Method Library

    Describes the predefined DC, AC and PPTIA test method library in detail.

  • Test method snippets provided with SmarTest

    Provides an overview of test methods excerpts available with SmarTest.

  • Concurrent test framework

    Describes the concurrent test framework in detail and provides guidelines for implementing the concurrent test framework.

  • d2s-framework

    Describes the dynamic-to-static framework and its implementations for automated generation of static vector labels.

  • SmartCalc framework

    Describes the SmartCalc framework and its implementation for multi threaded hidden operations.
