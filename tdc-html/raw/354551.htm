Creating a TE-Cloud virtual machine

Check the TE-Cloud virtual machine on the myAdvantest portal and create a new one by defining its parameters.

About this task

Creating a cloud virtual machine is the first step in using the TE-Cloud.

Procedure

  1. Open the TE-Cloud dashboard.
  2. Click the Virtual machine label at the left side of the interface.
  3. Click the Launch VM button.

    The Virtual Machine window opens.

  4. Enter the parameters for your new virtual machine.


    Name
    The name that you want to give to your virtual machine which is the identification for this virtual machine.
    User
    The user name that you specify to login the created virtual machine in PuTTY.

    The user name must not contain "demo" anywhere.

    Image
    The desired development environment (Red Hat 5 or Red Hat7) and the SmarTest version (SmarTest 7 or SmarTest 8).
    There are three combinations of the development environment and SmarTest version:
    • RHEL5.11 PDB-254 TEC Build-19 (1600×1400)
    • RHEL7.4 PDB-418 TEC Build-68 (SmarTest 8)
    • RHEL7.4 PDB-418 TEC Build-68 (SmarTest 7)
    Bundle
    Select the desired usage bundle from the list.

    All bundles purchased by the current account are listed.

    The bundle name contains the purchase date and the expiration time. For example, in the name Developer (10 Minutes) 2020-10-12 15:08:45, 10 Minutes is the validity period for using this bundle and 2020-10-12 15:08:45 is the time when this bundle was purchased.

    Public Key
    The full content of the public key file which was saved in Generating and saving key files.
  5. Click the Confirm button in the Virtual Machine window.

    The virtual machine is created in a few minutes and displayed in the table.

Results

A TE-Cloud virtual machine has been created. You can configure the connection to the virtual machine in PuTTY using the specified Login Name and Public IP Address.
