Topic 58780

Configuration commands

There are two competing ways to configure the recording parameters. You can either use the SQGB command, or the set of the DCGM, DCRM, DCRP, DCRT commands.

The SQGB command combines two functions, namely to control the sequencer termination and to configure the Error Map. It should only be used for controlling the sequencer termination. As a means for configuring the Error Map recording, it is only supported for compatibility reasons and should be avoided in new applications.

The DCxx commands provide much more flexibility. Furthermore, the special features of the Pin Scale and Smart Scale Digital Cards (Error Map location, resolution of error code) can only be activated with them.

The following table shows which firmware commands control which recording parameters:

Parameter

Command

Comment

Resolution of error code

DCRM

For dependencies between error code resolution and result granularity see Possible combinations of CYRM, CYRP, and DCRM.

Location of detailed Error Map

DCRT

You can query the size of the Error Map with the DCRS? query.

Recording mode for detailed Error Map

DCGM

You can either select the recording mode yourself, or leave the appropriate selection to SmarTest.

Recording position

DCGM, DCRP

DCRP specifies the recording position, DCGM defines how it is interpreted.

Result granularity

DCRM

For dependencies between error code resolution and result granularity see Possible combinations of CYRM, CYRP, and DCRM.

Compression factor of the overview Error Map

DCRM

This parameter defines how many blocks of 16 cycles are compressed into one result. It can also be set to compress the cycles of every main label within a burst into one result.
