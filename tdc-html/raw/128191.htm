Topic 128191

Prerequisites

This section lists all requirements that have to be met in order to set up and use a protocol successfully:

  1. Use multiport for your device setup.
  2. A system wide software license for enabling protocol based tests needs to be available and enabled in the model file.
  3. The STATEMAP has to be used as it is of significant importance for protocol interpretation respectively generation.
    Note There are special conditions for state maps to be used with protocol definitions, refer to the important information section of the protocol wavetable description.
