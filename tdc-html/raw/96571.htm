The sequencer program

Sequencer programs are coded in a simple language that provides

  • instructions for sending waveforms to the DUT
  • instructions for changing the timing or level setup during the test
  • control structures that allow to repeat a sequence of instructions and to call a subroutine.

In order to explain the basic structure of a sequencer program and its connection to the waveform DC/DC power units, the following little program, which belongs to label test_1 of the standard example, will be used:

SQPG 4,STVA,408,,,(@)
SQPG 5,STSA,,,,(@)
SQPG 6,RPTV,7,5,,(@)
SQPG 7,GENV,9,,,(@)
SQPG 8,STOP,,,,(@)

Every line of the program contains an instruction for the sequencers. The instructions are created with the SQPG command.

Parameters of SQPG

The first parameter of SQPG specifies the command number of the instruction. The command numbers count the instructions of one port (the default port in the example) across all sequencer programs (see Label definition, sequencer program, and sequencer area). The first line of the sample program has command number 4 because this is not the first program of the port. Note that the first and last command number are those specified in the SQLB definition of the label (see The label definition).

The next three parameters define the instruction and its input information.

The fifth parameter is not used.

The last parameter specifies the port to which the label belongs. The sample program belongs to the default port @, which contains all configured pins.

Sequencer instructions

The first line of the sample program contains the STVA instruction that points to the location of the physical waveform DC/DC power units for the label test_1. This instruction will be explained in more detail in Sequencer program and vector areas. The sequencer program of every label that generates parallel vectors must start with an STVA instruction.

The STSA instruction in line 5 is only present for historical reasons.

The next two instructions generate parallel vectors. The RPTV instruction with command number 6 generates 7 vectors and repeats this action 5 times. The following GENV instruction generates 9 vectors. The number of index rows from which these vectors are generated is called the length of the instruction. Thus, the RPTV instruction has length 7, and the GENV instruction has length 9.

The RPTV instruction of the example sends the same vectors more than once to the DUT. Therefore, a distinction must be made between vectors and cycles. A vector is a sequence of waveforms whose DC/DC power units are stored as a row in the index array. A cycle is one of possibly many applications of the same vector to the DUT. Thus the first vector of the example label will be applied 5 times to the DUT with the cycle numbers 0, 7, 14, 21, 28 (cycles are counted per label starting from 0).

Finally, the STOP instruction in line 8 marks the end of the program.
