The SlimBusController class serves to set up a SLIMbus test and to process its results. See also Overview of the SLIMbus solution.

SLIMbus devices are tested within the protocol-aware framework by using a synchronized protocol test. This synchronized test must be explicitly defined in the test method, but its transactions are generated automatically by (an instance of) the SlimBusController class, usually from a sequence file. This SlimBusController instance also prepares the results of the test for further analysis.

The typical sequence of events is as follows (unless explicitly stated otherwise, all functions called are member functions of the SlimBusController class):

  1. Create a SlimBusController instance.
  2. Create the synchronized protocol test ( from the SYNCHRONIZED_TEST class).
  3. Load the sequence file with the loadFromSequenceFile() function (?? this function checks the correctness of the input sequence file ??).
  4. (Optional) Activate storing of the state character sequence (which will be created in step 5) for the Superframe Viewer (see Using the Superframe Viewer) with the activateSuperframeViewerOutput() function.
  5. Convert the sequence file with the translate() function. This conversion comprises two substeps:
    1. Translate the sequence file into parameter values of the PA communication frame (and write these values into the Superframe Viewer file if step 4 has been executed)
    2. Create the transactions of the synchronized PA test with these values.
  6. Convert the test method code into a protocol pattern and integrate it into the multiport burst (flush() member function of the SYNCHRONIZED_TEST instance).
  7. Execute the test (for example, with the FUNCTIONAL_TEST API).
  8. Decode the pattern output with the decode() function of the SlimBusController instance. This is a prerequisite for any result processing. If step 4 was executed, the results will also be integrated into the Superframe Viewer file (see Using the Superframe Viewer).
  9. Prepare the message results with the getMessageResults() function.
  10. Prepare the data channel results with the getDataChannelsWithResult() function.
