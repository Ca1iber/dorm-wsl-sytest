Setting the edge delays

Subtopics

  1. Defining the edge delays for Pin Scale standard pins
  2. Defining the edge delays for Pin Scale 3600 fast pins
  3. Defining edge delays for Smart Scale pins

Edge delays are defined for pins, not for individual waveforms. This implies that for a given pin, the position of an edge is the same in every waveform definition where the edge is used. This holds for both standard and fast pins.

Functional changes

  1. Introduced before SmarTest 6.3.2
