Topic 136698

Viewing the test results of a test suite on the shmoo plot

When shmoo plotting an existing test suite, the test results that are logged with the judgeAndLog API of this test suite will be displayed on the shmoo plot.

About this task

To view other results that are not logged with the judgeAndLog API on the shmoo plot, use the SHMOO_RESULT API in the test method code of the shmooed suite to define these results.

For the test suite to be shmoo plotted, follow the steps below.

Before you begin

  • Open the testflow which contains the test suite to be shmoo plotted.

    Make sure all setups of this testflow are loaded.

  • Open the Shmoo Tool.

Procedure

  1. To view the test results logged with the judgeAndLog API on a shmoo plot, go to step 4.
  2. To view the results that are not logged with the judgeAndLog API on a shmoo plot, in the test method code of the to be shmooed test suite, set up these results with the pin(), site(), testName() and setResult() member functions of the SHMOO_RESULT API.

    For example, SHMOO_RESULT.pin("pin1").site(1).testName("mea1").setResult(measureValue1);

  3. Build the modified test method.
  4. In the Shmoo Tool, set up a shmoo test shmooing over this test suite with the ac_tml.AcTest.Shmoo test method.

    Or, transfer the setup of the shmooed test suite into the Shmoo Tool and in the Shmoo Tool set up the other parameters as the setup a shmoo over test suite.

    When setting up the ac_tml.AcTest.Shmoo test method:

    • For the shmooTestSuite parameter: Do select the name of the test suite to be shmooed.
    • For the testMode parameter: Do select the user defined measurement test mode.

      Alternatively, you can create a new test suite with the ac_tml.AcTest.Shmoo test method and then transfer it to the Shmoo Tool.

  5. In the Shmoo Tool, execute the shmoo test.

    The shmoo plot of one test result is displayed.

  6. To view the shmoo plot of another test result, right-click the plot and select the Test Modes command, and then select the interested result.
  7. To view the shmoo plots of different pins, right-click the plot and select the Result Pin command, and then select the required pin.
  8. To view the shmoo plots of different sites, see Viewing the shmoo plots of different sites.
