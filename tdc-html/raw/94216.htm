Topic 94216

Setting up timing equation for the DataTrainingFlex test method

About this task

Adapt the timing equation file to be used with the test method as described below.

Before you begin

Required is one tsweep spec value for each output and each input pin.

Procedure

  1. Start SmarTest.
  2. Load the test flow.
  3. Edit the timing equation file.
  4. In the editor scroll to the section starting with the text: 
    EQNSet 2 "HSM3600 DataTraining"
  5. Add the specification variables for the device input pins.

    Example:

    tAS_BA0_offset
tAS_BA1_offset
tAS_BA2_offset
...

    and add the spec into the equation for the input pin timing, for example:

    for input pin BA0: d1=tAS + tAS_BA0_offset

    for input pin BA1: d1=tAS + tAS_BA1_offset

    for input pin BA2: d1=tAS + tAS_BA2_offset
