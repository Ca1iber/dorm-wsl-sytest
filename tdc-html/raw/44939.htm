Topic 44939

Override Setup Files

Use

long OverridePinConfiguration(char *file_name)

long OverrideLevels(char *file_name)

long OverrideTimings(char *file_name)

long OverrideVectors(char *file_name)

long OverridePinAttributes(char *file_name)

long OverrideAnalogControl(char *file_name)

long OverrideWaveform(char *file_name)

long OverrideRouting(char *file_name)

Note These functions are only appropriate for use in conjunction with global-setup based testflows.

Use the file_name as an override for the respective setup file stored with the testflow. The file will be loaded just before the next test function is executed.

The return value is always 0 (ok).
