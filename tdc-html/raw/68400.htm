Overview of MTL

Subtopics

  1. Introduction to MTL
  2. Syntax conventions

The Memory Test Language (MTL) is a programming language specifically designed for generating per-pin test patterns for memory devices. It is an APG (algorithmic pattern generator) programming language.

Using MTL you can generate patterns for memory testing on V93000 test systems. MTL fully supports at-speed memory testing to the limits of the available tester hardware.

MTL offers:

  • No limitations of address or data width by relying solely on the available per-pin resources. Any channel resource can be used as an I, O, or I/O pin for clock, address, and data signals.
  • No limitations of loop counters or registers.
  • At-speed testing without the need for APG multiplexing.
  • Usable for any memory access mode supporting any n-bit protocol.
  • Can be applied as a general purpose vector processing language to compress functional memory test patterns as well.
