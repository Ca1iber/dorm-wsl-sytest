Topic 97895

Copying and pasting a utility purpose

About this task

By the function of copying and pasting, you can define a new utility purpose with other utility purpose as a starting point.

Before you begin

Make sure at least one utility purpose is defined.

Procedure

  1. In the Test Program Explorer view, right-click the name of the utility purpose you want to copy and select Copy.
  2. Right-clicke of the utility purposes and select Paste.
  3. Naming a Utility Purpose window opens. Type the new utility purpose name in the Utility Purpose Name text box. Click OK.

Results

The Utility Purpose Editor of the pasted utility purpose opens. The setting of the pasted utility purpose is same as the original utility purpose.

What to do next

Edit the pasted utility purpose.
