CHER? - (CHeck ERrors)

The CHER? query indicates if the last test performed passed or failed on the specified pins. A result is returned for each individual pin.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

CHER? [MUX,] {(pinlist)}

returns:

CHER {res_flag}, [MUX,] {(pinlist)}

Parameters

MUX

If this flag is set, and one of the specified (Pin Scale) pins is multiplexed to an HXA pin, then the result returned for this Pin Scale pin will be combined from all Pin Scale pins multiplexed to the HXA pin.

pinlist

Results will be provided only for the pins specified in pinlist. If more than one pin is included, the names must be separated by a comma. All pins in pinlist must be O or IO pins.

res_flag

The result flag is returned by the system. It can be:

F

The last functional test performed on the specified pins failed.

P

The last functional test performed on the specified pins passed.

Application

Test Results, see Test Result Commands.

Errors

An error is generated if you send the query while the sequencer is running. There is then no result data available.

Example

After a functional test has been performed, sending CHER? returns the result for each pin in pinlist. 

CHER? (@)

returns: 

CHER F,(Q0,Q1)
CHER P,(Q2)
CHER F,(Q3)

Functional changes

  1. Introduced before SmarTest 6.3.2
