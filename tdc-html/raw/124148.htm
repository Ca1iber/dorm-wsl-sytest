Chain Description Record (CDR)

A Chain Description Record describes the input, output, number of cells, and clocks of an individual scan chain. It is identified by its index.

A Chain Description Record can appear after the Scan Structure Record (SSR).

Note Using Chain Description Records can lead to extremely large data sets. We recommend that you carefully evaluate whether they are needed in each case.

CDR field name

Field description

Value

93000 data source

CONT_FLG

Flag for the existence of CDR continuation records

Variable length character string

 

CDR_INDX

The index of the CDR. It is used by the Scan Structure Record.

Two-byte unsigned integer

 

CHN_NAM

A unique name for the scan chain.

This is an optional field.

Variable length character string

First byte is unsigned count of bytes to follow

Maximum 255 bytes

Length byte = 0 if missing or invalid data

 

CHN_LEN

Number of cells in the scan chain. (Any additional cells are listed in continuation CDR records.)

Four-byte unsigned integer

 

SIN_PIN

The PMR record index for the Scan In signal of the scan chain

Two-byte unsigned integer

0: Missing or invalid data

 

SOUT_PIN

The PMR record index for the Scan Out signal of the scan chain

Two-byte unsigned integer

0: Missing or invalid data

 

MSTR_CNT

Number of master clock pins assigned to the scan chain

One-byte unsigned integer

0: M_CLKS is not present

 

M_CLKS

Array of PMR record indexes for the master clock pins of the scan chain

Array with the dimension MSTR_CNT

Each value is a two-byte character.

 

SLAV_CNT

Number of slave clock pins assigned to the scan chain

One-byte unsigned integer

0: S_CLKS is not present

 

S_CLKS

Array of PMR record indexes for the slaveclock pins of the scan chain

Array with the dimension SLAV_CNT

Each value is a two-byte character.

 

INV_VAL

A flag indicating whether the Scan Out signal is inverted from the Scan In signal

One-byte unsigned integer:

  • 0: Scan Out is not inverted
  • 1: Scan Out is inverted
  • 255: Missing or invalid data

 

LST_CNT

Number of cells listed in the CELL_LST of this record.

If there are additional cells in the scan chain, these are listed in continuation CDR records.

Two-byte unsigned integer

0: CELL_LST is not present

 

CELL_LST

Array containing the names of the scan cells

Array with the dimension LST_CNT

Each entry is a variable length character string:

  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • Length byte = 0 if missing or invalid data

 

Functional changes
