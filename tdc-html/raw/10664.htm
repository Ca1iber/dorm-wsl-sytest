Topic 10664

Defining the query focus

Only one site can be queried for its setup data or its results at any time. This is the site that has the query focus. You can control the query focus with the PQFC command.

By default, the first available site has the query focus. But be aware that this need not always be site 1. For example, if a channel that is used for site 1 is defective, then site 2 will have the default query focus (provided that site 2 is available).

CAUTION This command implements the tpi interface for multi-site testing. Use the tpi call instead of the PQFC firmware command.
