Topic 143187

Optimizing the technology file

This topic describes how you get the numbers of used sets to optimize the technology file.

About this task

To optimize the Technology file for a device, you can adapt the number of sets to the number of used sets.

The Testflow Analyzer tool (TAT) provides the number of sets used by the current device in a comment section:

  • Level sets
  • DPS sets
  • Wavetables
  • Timing sets

    Example:

    ################################################
# #
# Number of sets used by this device: #
# Level Sets: 220 #
# DPS Sets: 79 #
# Wavetables: 128 #
# Timing Sets: 726 #
# #
################################################

Procedure

  1. In the technology file edit the set numbers according to the numbers TAT provided, see Editing technology data.
  2. Change the device, see Changing the device with the Change Device button
  3. Load all setup data
  4. Execute TAT to determine the new sequencer memory sizes, see The Testflow Analyzer Tool
