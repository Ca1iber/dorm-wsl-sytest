Error acquisition

This section describes the behavior of error acquisition using the Error Map memory, called the "8k Error Map acquire failure mode". The SmarTest provides another mode for large error acquisition, called the "large acquire failure mode (LAFM)". For more information of both the acquire failure modes, see Acquire failure modes.

With standard tests, the results - Pass and Fail - are read out every 8K cycles. Because the Per-Pin APG executes the test in one go, the Error Map memory is used to collect only the failing cycles of the whole test. If there are more failing cycles than can fit into the Error Map memory, only the first 8K will be recorded. In order to get round this, the memory-specific test functions run the test more than once automatically. When the test is executed a second or subsequent times, the Error Map memory starts recording failing cycles from the last failing cycle of the previous execution. Thus, the memory test may have to be executed several times in order to get a true picture of the number of failing cycles.

The 16 cycles during which the error occurred are acquired, together with the number of the first of these cycles. If no error occurs in a block of 16 cycles, nothing is stored. Thus, if you have a device with only a few failing cycles, the Error Map memory may be able to acquire all of the errors in one go.

If, however, your device has many failures, the space available to acquire error information may not be sufficient and the Error Map memory may only be able to acquire the errors for a small region of the device.

When errors are detected in the receiver channel they are on a cycle-per-cycle basis, that is, the differences between what was received to what was expected in one test system cycle. When these errors are sent to the memory-specific result analysis tools (Fail Memory and Bitmap tools) they are reconstructed onto an address basis.
