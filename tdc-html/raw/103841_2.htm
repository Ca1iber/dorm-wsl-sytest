Topic 103841

IssueHVMExecutionEvent()

This API issues HVM event with the EXECUTION category.

SUCCESS will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

PARAMETER_EXCEPTION
  • The value of the parameter "EXECUTION_STATE" is empty.
  • The value of the parameter "EXECUTION_STATE" is not valid.
  • The value of the parameter "LEVEL_TYPE" can only be "CUSTOM_LEVEL", "WAFER_LEVEL" and "DEVICE_LEVEL".
  • The value of the parameter "LEVEL_TYPE" or "LEVEL_NAME" is empty.
  • The value of the parameter "VARIABLE_NAME" or "VARIABLE_VALUE" is empty.
  • The value of the parameter "TESTPROGRAM_NAME" is empty.
  • The value of the parameter "DIE_X_FOR_SITES" or "DIE_Y_FOR_SITES" or "SITE_ID_FOR_SITES" or "SITE_SETUP_FOR_SITES" is empty.
  • The value of the parameter "SITE_ID_FOR_SITES" or "SITE_SETUP_FOR_SITES" is empty.
  • The value of the parameter "DIE_X_FOR_SITES" or "DIE_Y_FOR_SITES" or "SITE_ID_FOR_SITES" or "SITE_SETUP_FOR_SITES" cannot start with white space.
  • The value of the parameter "PACKAGE_ID_FOR_SITES" or "SITE_ID_FOR_SITES" or "SITE_SETUP_FOR_SITES" cannot start with white space.

RECOVERABLE

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • Failed to issue the HVM event.

RECOVERABLE

Prototype

ParamList inParams;
Status syncCommand("IssueHVMExecutionEvent", inParams, sessionId);

Example

string sid;  
ParamList inParams;
inParams ["EXECUTION_STATE"] = "ACTION_ASSIGNMENT_EVENT";
inParams ["VARIABLE_NAME"]  = "lot_id";
inParams ["VARIABLE_VALUE"] = "123";
syncCommand ("IssueHVMExecutionEvent", inParams, sid);
