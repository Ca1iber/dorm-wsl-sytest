Connecting and disconnecting in DPS operating mode

When connecting and disconnecting in DPS operating mode, DC Scale cards behave like a standard device power supply.

When connected, it forces the programmed power supply voltage (vout). The current is limited to the connect current limit (ilimit).

The DC Scale card must be disconnected before changing any of the following:

  • a voltage force range (vout_frc_rng)
  • a clamp current range (iout_clamp_rng)

If the DC Scale card is still connected, you cannot activate a dps set that contains one of above changes. To avoid damages to your device or the DUT board, the system will display an error message in the report window instead.
