DRLAttributeType

A variable of this type holds the type of an attribute. Such variables are members of type DRLAttributeRec objects. 

typedef DCLAttributeType DRLAttributeType;

Type definition of DCLAttributeType:

typedef unsigned short DCLAttributeType;

Functional changes

  1. Introduced before SmarTest 6.3.2
