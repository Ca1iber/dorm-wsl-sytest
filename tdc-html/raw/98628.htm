HROL, HROL? - (High Resolution Option and Level)

The HROL command is used in the context of a high resolution measurement and serves two purposes. First, it allows you to modify the result resolution (1 bit or 2 bit result) and the method by which High and Low are determined for differential pins. Second, it defines the level for a scope measurement. In this role, it must be issued between a HRIT SCOP command and the HREX? query.

The HROL? query returns the current settings.

With this command you configure setups of those sites that have the setup focus: For more information, see also: PSFC, PSFC?.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

HROL

HROL {PINS|LEVP}, {param1}, [param2], {(pinlist)}

HROL?

HROL? {PINS|LEVP},{(pinlist)}

returns: 

HROL {PINS|LEVP}, {param1}, [param2], {(pinlist)}

Parameters

PINS

Indicates that the result resolution and possibly the High/Low definition for differential pins will be given.

LEVP

Indicates the level for a scope measurement will be defined. This option is only allowed after a HRITSCOP command.

param1

The meaning of this parameter depends on the setting of the first parameter. If the first parameter is set to PINS, then param1 defines the result resolution (1 bit or 2 bits). The default depends on the capabilities of the respective pin.

If the first parameter is set to LEVP, then param1 defines the voltage level for a scope measurememnt in [mV].

param2

If the first parameter is set to PINS, then param2 defines the method by which High and Low are determined for differential pins. Possible values are:

 

NONE

The only value for standard pins, not allowed for differential pins.

 

Vdif

The value that will be compared to the expected value is the difference between the positive and the negative pin. This is the default.

 

Vpos

The value that will be compared to the expected value is the voltage of the positive pin.

 

Vneg

The value that will be compared to the expected value is the voltage of the negative pin.

 

Vcom

The value that will be compared to the expected value is the average of the positive and the negative pin.

 

On the firmware level, the last three options are only available for HXA pins. In the timing diagram they are available for all differential pins.

You can use the SPEC? query to find out which options are available for a given pin.

pinlist

The pins which are to be measured with the specified parameters. All these pins must be O or I/O pins.

Example

> HRIT SCOP,135,0,175,0,800,(A)
> HROL PINS,1,,(HSClck)
> HROL LEVP,100,,(HSClck)
> HROL LEVP,1000,,(D0+,A0+,D0-,A0-)
> HREX? (HSClck,D0+,A0+,D0-,A0-)
> HROL LEVP,110,,(HSClck)
> HROL LEVP,1200,,(D0+,A0+,D0-,A0-)
> HREX? (HSClck,D0+,A0+,D0-,A0-)
> HRIT END

This example shows a measurement sequence for a scope measurement. First, the result resolution for the HSClck pin is set to 1. Then two measurements are taken. Before each measurement execution, the voltage levels are defined. After the second measurement, the measurement sequence is closed with HRIT END.
