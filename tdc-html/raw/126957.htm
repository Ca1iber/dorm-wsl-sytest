Jitter (TIE)

This test method measures the jitter of signals with TMU. That means: TML on TMU measures TIE (Time Interval Error) with the default TML settings.

Sometime stamps of rising edge are captured and compared with the expected time stamps. Jitter is represented by the differences between the captured time stamps and expected time stamps.

Parameters

Parameter

Type

Description

pins

PinString

The digital pin(s) or pin group(s) to be measured

datarate [Mbps]

double

The maximum expected data rate of the signal to be measured in unit [Mbps].

prescaler

int

The pre-scaler of the measurement.

Calculated by datarate.

For an external signal only prescaler = 1 is valid.

jitter mode

CLK | PERIOD1)

The measured signal is a clock

DATA | DATA_PERIOD

The measured signal is a data

sample_per_meas

long

The number of samples to be taken

exit if TMU has not

int

This parameter controls if the test method is exited without uploading results when the TMU has not finished measurement.

wait timeout

int

This parameter specifies the timeout [sec] how long to wait for the TMU to finish the measurement.

ftstResult

int

The flag indicating whether the functional test result is taken into account of the final pass/fail result. It can be:

0: do not include the functional test result

1: include the function test result

Default is 1.

histogram

int

Generate the histogram or not. It can be:

0: do not generate the histogram

1: generate the histogram

Default is 1.

output

string

Output result to UI report or not. It can be:

ReportUI: output to UI report window

None: Do not output to UI report window

Default is None.

testName

string

The test names to be used as limits. Default is rmsJitter.

If you want to use the test names defined in the test table or testflow limits, type in the test names manually. Make sure the test names are in the Test name column of the test table (Refer to Structure of a TMLimits CSV file) or in the Test Name column of Tests page of Flow Data Editor.

Limits

rmsjitter

The pass range of rms jitter.

p2pjitter

The pass range of peak-to-peak jitter.

stddevJitter

The pass range of the standard deviation jitter.

maxJitter

The pass range of the maximum jitter.

minJitter

The pass range of the minimum jitter.

Implementation pseudo code

IF not connected THEN
  connect DUT
ENDIF
Set up TMU with specified parameters
Execute TMU measurement
Upload raw result data
Disable TMU
Retrieve functional test result if specified
Calculate the mean period of signal
FOR all samples
  calculate the difference between captured time stamp and expected time stamp
ENDFOR
Calculate the jitter histogram if specified
Calculate the rms and peak to peak jitter
Judge and log the result
Judge and log the functional test result if specified
