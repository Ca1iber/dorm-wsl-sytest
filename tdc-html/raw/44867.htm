Return Values - a General Note

All return values of the functions assume one of three values which are consistent over all routines:

0: The routine get/set without error

1: The name for the flag or variable is invalid because, the type is inconsistent with the function used (for example, setting a double variable with SetUserFlag), or the value presented to the function exceeds the limits of the flag.

-1: An internal error has occurred (bug condition)
