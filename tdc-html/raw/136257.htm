Topic 136257

Principles of operation of the Integrated Result Tool

Subtopics

  1. Result perspective overview

The Integrated Result Tool summarizes the results of data log files or the system data log stream in various ways and provides statistical values for them. You can filter and arrange the data and display it visually in different graphs to draw conclusions and develop theories about the underlying tests.

To work with data from an STDF or EDL data log file in the Integrated Result Tool, you first load the file into the tool's Data Log Explorer. The system data log is always automatically loaded.

You can display any loaded data log or stream in a data navigation view. Data navigation view display automatically generated summary and statistical information about the contents of a data log in tables. The data is evaluated per test, wafer, device, or bin. These summary views are the core of the Integrated Result Tool. You can sort and filter them, and you can view their contents as raw data or graphs (see below).

You can display the data underlying each summarized item by clicking it and opening a raw data view (or Stream data view, in the case of the system data log) for it. These tables can also be filtered. In addition, you can control to a limited degree which of the raw underlying data is used for the summaries in the data navigation views.

The Analysis views are based on the data from the data navigation views and display the same information in visual or tabular ways. The views allow some control over their formatting.

The Integrated Result Tool is linked to other SmarTest tools:

  • Testflow Tool: From a data navigation view, you can open the definition of a test or bin in the Testflow Tool; you can also open the limit specification for a test. When you right-click a test in the Testflow Tool, you can open its results in the Integrated Result Tool from the shortcut menu.
  • Pattern Explorer: You can open the Pattern Explorer with a shortcut menu command from an FFC Pareto chart to display the selected failing cycle.
