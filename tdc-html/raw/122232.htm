Topic 122232

How to create a CCF block in the testflow

About this task

You can create any number of concurrent test framework blocks in the testflow.

Before you begin

A testflow is already created.

Procedure

  1. In the testflow, create test suites as usual. (See Inserting a test suite in the testflow.) These test suites use concurrent test methods.
  2. Use multi-bin for the all the test suites if needed. (See Inserting a bin into the testflow.)
  3. For the test suites running on the synchronous sequecner,
    • Choose Synchronized for the parameter CCF_ContextType
    • Enter the pins and ports to be run on the synchronous sequencer for the parameter CCF_FocusedPins. The value must be the same for all the test suites running on the synchronous sequencer.
    • Specify the values for the parameters you added.
  4. For the test suites running on the independent sequencer,
    • Choose Independent for the parameter CCF_ContextType
    • Enter the pins and ports to be run on the independent sequencer for the parameter CCF_FocusedPins. The value must be the same for all the test suites running on the independent sequencer.
    • Specify the values for the parameters you added.
      Note Only ONE port can be run on independent sequencer.
  5. If you want to end the block, create a test suite with the provided test method ccf_tml.CCExecution or ccf_tml.CCExecutionMultiGroup. Specify the value for parameter CCF_LabelName and CCF_TimingSpecSetName.
  6. (optional) Group the test suites for concurrent tests.
  7. In the Variables tab of testflow data editor, create the variables CCF_Concurrent, CCF_DevelopMode and CCF_VerboseLevel. Assign values to the variables according to the desired execution mode.

Results

A concurrent test block is created in the testflow as below.

Functional changes

  1. Introduced in SmarTest 6.5.4
  2. SmarTest 7.2.1: in the patch 2, added the test method ccf_tml.CCExecutionMultiGroup in TML 2.2.0.
