Topic 119017

Using the firmware view

Low level firmware (FW) commands are useful when debugging test flow programs, verifying proper download of setups, or reading the results of measurements.

  • Task

    Enter, or copy and paste a firmware command into this field and press Enter.

    You can also select FW commands from the drop down list.

    Multiple firmware commands have to be separated by a semicolon ';'.

  • FW Return Area (below the task field)

    The FW command and its result are displayed here.

    Note Download of binary data is not supported.
