Changing the runtime values of base variables

You can change the runtime value of a base variable that is used in a level or timing specification. Then the equation system will be recalculated with the new value, and the next functional test will be executed with the actualized equation system.

The simplest case is that only one variable must be changed. In this case, use the SVLR command to change the value and to recalculate the equations.

However, often more than one base variable must be changed. In this situation, using SVLR would entail that the recalculation is repeated for every changed variable. To avoid this, SmarTest allows you to divide the modification procedure into two sub-steps. First you assign new values to a subset of the base variables. In the second step, the equation system is recalculated with all the new values. In this way the time consuming calculation needs to be carried out only once. In detail this is implemented as follows:

The new values are contained in a spec value set, which is defined with the DSVS command. Each spec value set is associated with exactly one specification; but the same specification can be associated with more than one spec value set. The entries of the set are defined with the BSVR command, which assigns a value to a base variable of the current level or timing setup in a predefined spec value set. Finally, the recalculation of the equation system with all the definitions of one spec value set is triggered with the BSVE command.

Example

> SVLR? TIM, 1,1,all
< SVLR TIM,1,1,"per1",25
< SVLR TIM,1,1,"per2",50
> DSVS 11, "per", TIM,1,1
> BSVR 11,"per1",30
> BSVR 11,"per2",60
> SVLR? TIM, 1,1,all
< SVLR TIM,1,1,"per1",25
< SVLR TIM,1,1,"per2",50
> BSVE 11
> SVLR? TIM, 1,1,all
< SVLR TIM,1,1,"per1",30
< SVLR TIM,1,1,"per2",60

This example shows how to change the values of the spec (base) variables per1 and per2 simultaneously by utilizing a spec value set. Note that the values only change after BSVE has been issued.

Functional changes

  1. Introduced before SmarTest 6.3.2
