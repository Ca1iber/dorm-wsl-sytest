Topic 103654

ExecBLC

This remote command execute an executable Batch/Lot Control client. The BLC is executed in an asynchronous manner. The caller of this API could wait for the HVM event TESTPROGRAM_EXEC_STARTED to determine whether the BLC program is running or not.

SUCCESS will be returned if no error occurred. Otherwise an error object will be returned indicating the error code, description and severity.

Code

Description

Severity

PARAMETER_EXCEPTION
  • The value of the parameter "BLC_EXECUTABLE_FILE" is empty.
  • The value of the parameter "BLC_EXECUTABLE_FILE " is not a full path.
  • The specified BLC executable file "XXX" does not exist.
  • The value of the parameter "BLC_INPUT_FILE " is not a full path.

Recoverable

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • The specified BLC executable file "XXX" is not executable.
  • The smartest state is not idle.

Recoverable

Parameters

I/O

Parameter

Description

I

SESSION_ID

The ID of the SmarTest session to work with.

I

BLC_EXECUTABLE_FILE

The executable BLC file with the full path.

I

BLC_INPUT_FILE

The BLC input file with the full path.

Prototype

ParamList cmdParams;
Status command("ExecBLC", cmdParams, sessionId);

Example

string sid;
ParamList inputParams; 
inputParams["BLC_EXECUTABLE_FILE"] = "/opt/blc_executable/blc1";
inputParams["BLC_INPUT_FILE"] = "/opt/blc_input/input1";
Status retVal = command("ExecBLC", inputParams, sid);
