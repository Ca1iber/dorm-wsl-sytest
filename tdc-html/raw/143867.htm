vMeas()

Specifies a voltage measurement.

Syntax

vMeas();
Note When you use this function on multiports, if pins from different ports share the same BADC, you must use rdi.portSync() to ensure the sequence of pins' access to the BADC is correct.

Example

rdi.dc("vMeas").pin("pinA",TA::BADC).vMeas().execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
