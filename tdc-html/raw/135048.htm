MTP_ADDRESS_FILTER

Subtopics

  1. MTP_ADDRESS_FILTER.setRange()
  2. MTP_ADDRESS_FILTER.setMode()
  3. MTP_ADDRESS_FILTER.setDbits()
  4. MTP_ADDRESS_FILTER.isValidAddress()

This class defines an address filter to select a certain range of addresses to generate or not to generate memory test results, such as bit map file, fail bit count, and fail addresses list.

This class is used by MTP_MEMORY_TEST.addAddressFilter(), and MTP_MULTI_FILTER.addAddressFilter().

This API is defined in the header file /opt/93000mts/mts/execution_engine/include/MtpAddressFilter.h.

Syntax

MTP_ADDRESS_FILTER();

Creates an object to define an address filter.

List of parameters

There are no parameters.

Return value

Using MTP_ADDRESS_FILTER.isValidAddress(), it returns true or false for an address within the filter range or not.

Otherwise, there is no return value.

Example

MTP_ADDRESS_FILTER filter;

Related information

MTP_MEMORY_TEST.addAddressFilter()
