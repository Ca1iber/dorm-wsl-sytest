Topic 29858

WAVE_LOG

The WAVE_LOG API accesses the data container holding the waveform data with captions.

You can add the captions to the data of the object via the member functions contained in this API.

You can explicitly create a class object of this API by using the constructor function of this API.

The class object of the WAVE_LOG is used for data logging of the array data and for passing the array data. That is to say, the object can be used as a parameter of the PUT_DATALOG or PUT_DEBUG API. For related topics, see PUT_DATALOG and PUT_DEBUG.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/WaveLog.h.

Class definition

Constructor:

WAVE_LOG();

WAVE_LOG(const ARRAY_I& data);

WAVE_LOG(const ARRAY_D& data);

Member Functions:

WAVE_LOG& xAxis();
WAVE_LOG& xAxis(DOUBLE start, DOUBLE end);
WAVE_LOG& xTitle(const STRING& label);
WAVE_LOG& xUnit(const STRING& unit);
WAVE_LOG& yAxis(const ARRAY_I& data);
WAVE_LOG& yAxis(const ARRAY_D& data);
WAVE_LOG& yTitle(const STRING& label);
WAVE_LOG& yUnit(const STRING& unit);
WAVE_LOG& comment(const STRING& comment);

Constructor

WAVE_LOG()

WAVE_LOG();
WAVE_LOG(const ARRAY_I& data);
WAVE_LOG(const ARRAY_D& data);

This default constructor WAVE_LOG() creates an empty class object of the WAVE_LOG API. Executing WAVE_LOG(const ARRAY_I& data) creates the object filled with ARRAY_I type data. In contrast, executing WAVE_LOG(const ARRAY_D& data) creates the object filled with ARRAY_D type data.

Syntax

WAVE_LOG(const ARRAY_I& data).member_func;
WAVE_LOG(const ARRAY_D& data).member_func;

or

WAVE_LOG obj(); //Create an object of WAVE_LOG API
obj.member_func;

member_func: Member function of the WAVE_LOG API.

Member functions

xAxis()

WAVE_LOG& xAxis();
WAVE_LOG& xAxis(DOUBLE start, DOUBLE end);

This member function defines the x-axis data in the object. There are two types of x-axis supported by the WAVE_LOG API: "Nominal" and "StartEnd".

The "Nominal" type indicates that there is no definition of the x-axis. The default is "Nominal".

The "StartEnd" type specifies the start and end values of the x-axis. Assuming that the number of the samples should be the same as the array of the y-axis data, the x-axis will be linearly scaled.

Parameters

start

This is the start value of the x-axis. It is used for the "StartEnd". If you do not specify the parameter, the type is reset to "Nominal" (default).

end

This is the end value of the x-axis.

xTitle()

WAVE_LOG& xTitle(const STRING& label);

This member function gives the title of the x-axis to the object.

Parameter

label

The title label to be put on the x-axis.

xUnit()

WAVE_LOG& xUnit(const STRING& unit);

This member function specifies the unit of the x-axis for the object.

Parameter

unit

The unit to be used on the x-axis.

yAxis()

WAVE_LOG& yAxis(const ARRAY_I& data);
WAVE_LOG& yAxis(const ARRAY_D& data);

This member function defines the y-axis data in the object. If you created an object with array data by the constructor WAVE_LOG, you do not have to define y-axis data. When this member function operates, the predefined y-axis data will be released.

Parameter

data

Array data to be applied on the y-axis.

yTitle()

WAVE_LOG& yTitle(const STRING& label);

This member function gives the title of the y-axis to the object.

Parameter

label

The title label to be put on the y-axis.

yUnit()

WAVE_LOG& yUnit(const STRING& unit);

This member function specifies the unit of the y-axis for the object.

Parameter

unit

The unit to be used on the y-axis.

comment()

WAVE_LOG& comment(const STRING& comment);

This member function attaches the comment string for the object.

Parameter

comment

The comment string to be attached to the WAVE_LOG API.

Examples

Example 1

ARRAY_D wave_array;
WAVE_LOG log_obj(wave_array);
PUT_DATALOG("Aout", "AnaWave", log_obj);

The object log_obj is created in the WAVE_LOG API. The PUT_DATALOG API logs the wave_array array data specified by the object "log_obj". The logged data is transferred to the event data logging stream.

Example 2

ARRAY_D wave_array;
double sampling_period;
WAVE_LOG log_obj(wave_array);
log_obj.xAxis(0.0, 1023.0*sampling_period);
log_obj.xTitle("Time");
log_obj.xUnit("sec");
log_obj.yTitle("Output Voltage");
log_obj.yUnit("V");
PUT_DATALOG("Aout", "AnaWave", log_obj);

The object log_obj is created in the WAVE_LOG API. The data, title and unit of the x-axis, and title and unit of the y-axis are defined by the member functions contained in the WAVE_LOG API. Then the PUT_DATALOG API logs the wave_array array data specified by the object "log_obj"

Example 3

ARRAY_D wave_array;
PUT_DATALOG("Aout", "AnaWave", WAVE_LOG(wave_array).xTitle("Points").yTitle("Output Voltage"));

The PUT_DATALOG API logs the analog waveform with the captions. The WAVE_LOG API contains this analog waveform to be manipulated. The member functions xTitle and yTitle define the some captions.

Example 4

double sampling_period;
ARRAY_D wave1_array,wave2_array;
WAVE_LOG log_obj(wave_array);
log_obj.xAxis(0.0, 1023.0*sampling_period);
log_obj.xTitle("Time");
log_obj.xUnit("sec");
log_obj.yTitle("Output Voltage");
log_obj.yUnit("V");
log_obj.yAxis(wave1_array);
PUT_DATALOG("Aout", "AnaWave1", log_obj);
log_obj.yAxis(wave2_array);
PUT_DATALOG("Aout", "AnaWave2", log_obj);

First of all, the object log_obj is created with the WAVE_LOG API. Captions are defined by the member functions contained in the API. Then, the first PUT_DATALOG logs the wave1_array array data. The second PUT_DATALOG API logs the wave2_array array data.
