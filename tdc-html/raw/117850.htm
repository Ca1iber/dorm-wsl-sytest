CFDF, CFDF? - (Clock Forwarding Set DeFinition)

CFDF creates a clock forwarding set by defining a unique name for it. Only one clock forwarding set can be stored in the hardware. If you change the primary clock forwarding set with CFPR, it will replace the previous primary set in the hardware. For more information on clock forwarding see Forwarding the clock.

CFDF? returns the names of all defined clock forwarding sets.

A clock forwarding set can be associated with a mode context. The primary clock forwarding set (as defined with CFPR) must be associated with the same context as the other primary sets.

CFDF

CFDF {"cf_set_name"} [, "mode_context"]

CFDF?

CFDF? ["cf_set_name"]

returns:

CFDF {"cf_set_name"} [, "mode_context"]

Parameters

cf_set_name

In the command, this is the name of a new clock forwarding set. In the query, it is a name of an existing clock forwarding set. If you omit this parameter in the query, CFDF? will return the names of all user defined clock forwarding sets.

mode_context

The mode context with which the clock forwarding set is associated. If this parameter is omitted, the DEFAULT context is assumed.

Application

Protocol engine test.

Errors

An error is generated if a clock forwarding set with this name already exists.

Example

> CFDF   "cf_set1"
> CFDF   "cf_set2"
> CFDF   "cf_set3"

> CFDF?
< CFDF   "cf_set1"
< CFDF   "cf_set2"
< CFDF   "cf_set3"

Functional changes

  1. Introduced in SmarTest 7.0.1
