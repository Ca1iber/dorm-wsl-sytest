TESTSET().judgeAndLog_SpecSearch()

This member function of TESTSET performs a pass/fail judgment of a spec search measurement specified by a SPEC_SEARCH object and logs the results.

Optional values for this function can be set by prior methods, for example, port(), cont(), reliability(), or testname().

Syntax

bool judgeAndLog_SpecSearch(const SPEC_SEARCH &specSearch, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE);

Parameter

Description

specSearch

The SPEC_SEARCH API class object that specifies a spec search measurement to be judged.

logTestNumber

An optional test number.

If this test number is provided, it overrides the actual test number. If it is not provided, the actual test number is logged.
Note Only the first six digits of values are ensured to be correctly logged into the STDF file.

Return Value

The pass/fail result of the judgment is returned. It can be true for pass or false for fail.

Example

SPEC_SEARCH search_1("freq",TM::TIM);
search_1.specPins("CPandMR").method(TM::Linear).unit("Hz").start(50).stop(70).numberOfSteps(20).resolution(0.01);
search_1.execute();
TESTSET().judgeAndLog_SpecSearch(search_1);

This function executes a spec search test on the pin "CPandMR". The test result is judged and logged with TESTSET API.
