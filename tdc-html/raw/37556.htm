The AI_DIR_FILE Section

In this section of the Vector Configuration File, you can specify directories for the source and target files of the vector translation. The possible entries are:

  • allvec_file: Specifies the name (without extension) and path of the global binary vector file.
  • allvec_file_gzip: Specifies the name (without extension) and path of the global binary vector file in compressed form.
  • allvecbase_file: Specifies the name (without extension) and path of the global binary vector file to which all newly created binary vector data will be appended. The file must be compressed and have the extension bin.gz or binl.gz.
  • pinconfig_file: Specifies the name and path of the pin configuration file. The file specified here has priority over the specifications in the aiv call (-p parameter).
  • pmf_file (optional): specifies the name of a pattern master file. If it is specified, the vector translation will create a pattern management master file. In this case a comprehensive binary vector file will only be created if one of allvec_file, allvec_file_gzip, or allvecbase_file is also specified.
  • pmf_path (optional): specifies a path. If it is specified, the vector translation will enter this path into the pattern management file.
  • single_binary_pattern_dir (optional): specifies the directory where the binary vector files for the individual patterns will be stored.
  • tmf_dir (optional): specifies the directory where the timing map files are stored.
  • tmp_dir (optional): specifies the directory where the temporary files are stored.
