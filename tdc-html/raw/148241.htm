Topic 148241

Defining sample correlation rules

Introduces how to select and edit an existing rule to define a sample correlation.

About this task

You can define your sample correlation process using the default rules or your customized rules.

Procedure

  1. In the Setup tab of Smart Correlation, click the icon to select a rule. Smart Correlation automatically chooses the rule group based on the number of sites of your test program.

    Each default rule group has the default rules as shown in the following figure:

  2. Click Edit Rules to edit the rule in the pop-up window. All items in the Rule Details pane can be edited. You can also clone or delete a rule and change the order of the rules with the corresponding button.
  3. To modify the parameters of a touchdown, expand the rule and highlight the touchdown that you want to change. You can modify the touchdown parameters listed in the right pane.
  4. For each touchdown, you can edit the parameters of each site as shown in the right pane.
  5. If you want to export the modified rule group to an XML file, highlight the rule group, click Export, enter the file name in the pop-up window and click OK.
  6. If you want to import an existing rule file, click Import, then select a rule file in the pop-up window, and click ok, the rule in the rule file will be attached at the bottom of rule list.
  7. Click Apply to apply the changes to the rule.

Results

A sample correlation process with your customized parameters is created.
