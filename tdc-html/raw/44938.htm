Determine the Sites to be Addressed

This function is used during testing of multiple sites to determine which sites should be addressed by a user procedure. It fills a caller-provided list of integers with the site numbers that the user procedure should operate on. A site number must be greater than 0, and a 0 marks the end of the list.

Note that the list must have a minimum size of CI_CPI_MAX_SITES+1.

long GetSitesToBeTested(int *sites_to_be_done)

The following lines show an example of this function:

int to_do[CI_CPI_MAX_SITES+1], i;

.

.

if (GetSitesToBeTested(to_do) == 1) ERROR();

for (i=0; to_do[i] > 0; i++)

do_something_with_site(to_do[i]);

/* to_do[i] is a site number */
