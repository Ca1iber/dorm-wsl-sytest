Topic 144084

Shmooing over a source-sync test with Shmoo Tool

Subtopics

  1. Performing customized source-sync shmoo tests with the shmoo tool

On the shmoo tool, to shmoo over a source-sync test, you must first create a source-sync test suite either with the MTP provided source-sync test method or with the SOURCESYNC_TEST API. Then, you shmoo over this test suite on the shmoo tool.

About this task

Note The source-sync feature is available only with MTP.

Comparing with the conventional shmoo over source-sync method that is configuring the shmoo parameters in the MTP provided source-sync test method, which will display a textual two-dimensional shmoo plot only on the UI report window with shmooing on spec variables and showing results for domain and for the margin min/max/mean/sigma values only, Shmoo Tool will:

  • Display a colorful vivid and operable shmoo plot for you to observe.
  • On the tool, you can easily change the shmoo conditions and manipulate the shmoo plot such as zooming and saving.
  • On the tool, you can perform fast shmoo.
  • If you use APIs (SOURCESYNC_TEST, judgeAndLog, SHMOO_RESULT and etc.) to define your own source-sync test suite, you can view more results other than the domain results and margin min/max/mean/sigma values on the shmoo plot.

The only drawback of shmooing over a source-sync test suite on the shmoo tool is it will take longer time during the multi-site shmoo than the conventional source-sync shmoo. To overcome this, see Performing customized source-sync shmoo tests with the shmoo tool, which is an advanced usage requiring your mastering both C++ and SmarTest.

Before you begin

In your testflow, set up a source-sync test suite either with the MTP provided source-sync test method or with the SOURCESYNC_TEST API.

Procedure

  1. On the shmoo tool, set up shmoo over a test suite as described in Setting up a shmoo test on the Shmoo Tool with the following notifications:
    • In the Testmethod field, choose the ac_tml.AcTest.Shmoo test method.
    • In the shmooTestSuite filed, only select the source-sync test suite you want to shmoo on.
    • In the testMode filed, do select user defined measurement.
  2. On the shmoo tool, execute this shmoo test.

    A shmoo plot shows up on the shmoo tool. The texts above the plot indicate the name (test mode), pins and site of the result currently displayed on the plot.

  3. To view the shmoo plot of another result, right-click the shmoo plot, select Test Modes and select the interested result name.

    Note that:

    • If the test suite is set up with the MTP provided source-sync test method, the available test modes you can select are for the margin min/max/mean/sigma values and domain results.
    • If the test suite is set up with APIs (SOURCESYNC_TEST, judgeAndLog, and SHMOO_RESULT), the available test modes are the results defined with the judgeAndLog and SHMOO_RESULT APIs. For details, see Viewing the test results of a test suite on the shmoo plot.
  4. To view the shmoo plot of another result pin, right-click the shmoo plot, select Result Pins and select the interested pin.

    Note that:

    • If the test suite is set up with the MTP provided source-sync test method, the available pins you can select are the pins you set up for the SourceSyncPinGroups parameter.
    • If the test suite is set up with APIs (SOURCESYNC_TEST, judgeAndLog and SHMOO_RESULT), the available result pins are the ones defined with the judgeAndLog and SHMOO_RESULT APIs. For details, see Viewing the test results of a test suite on the shmoo plot.
  5. To view the shmoo plot of another site, see Viewing shmoo plots of different sites.
  6. To perform fast shmoo, right-click the plot and select the Run Fast command.

    Alternatively, click the shortcut on the toolbar of SmarTest. For details, see Commands on the menu bar and their shortcuts on the toolbar.

  7. To manipulate the plot, such as zooming, right-click the shmoo plot and select a corresponding command from the shortcut menu.

    See the available commands in Commands in the shmoo editor of the Shmoo Tool.

Results

You have carefully viewed the shmoo results of a source-sync test.

What to do next

You may want to:

  • Take a picture of the current shmoo plot and its setups.
  • Transfer this shmoo test to the testflow as a new shmoo test suite.

    After execute this test suite, you may want to log all the generated shmoo plots and their setups into the UI report window, and save all the plots as .png files. See Logging shmoo tests into the report window and saving shmoo plots as png files for the procedure.
