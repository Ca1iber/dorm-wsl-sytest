SharedLeakageParallel syntax

The parameters of the SharedLeakageParallel let you specify the sharing configuration file, the different kinds of pins (shared, non-shared, cross-terminated), and voltage and settling times to use.

Syntax

Driver sharing leakage test method parameters

Parameter

Default

Comment

Sharing Configuration File

 

Name of sharing configuration file used.

The file must be located in the configuration subdirectory of the current device directory.

See Creating a sharing configuration file for details.

Shared Pins

 

Shared pins and pin groups that are to be measured. Separate entries with commas.

Non-Shared Pins

 

Non-shared pins and pin groups that are to be measured. Separate entries with commas.

Cross-Terminated Pins

 

Cross-terminated pins and pin groups that are to be measured. Separate entries with commas.

Force_Voltage

1

The force voltage to be used during leakage measurements.

The unit is volt.

Settling Time

0

The settling time for the measurement.

The unit is milliseconds.

PPMU Precharge

No

Yes or No.

Enable or disable precharging to non-shared pins and cross-terminated pins.

Precharge Voltage

0

The voltage to be precharged to the non-shared pins or cross-terminated pins via the PPMU.

The unit is volt.

This parameter is used:

  • Only for the non-shared, and cross-terminated pins
  • Only when PPMU Precharge is set to Yes

Note that the shared pins are independent of both the "Precharge Voltage" and "PPMU Precharge" parameters. They are automatically precharged to the force voltage by this test method. See details in SharedLeakageParallel test method.

Precharge Time

0

The precharging duration.

The unit is milliseconds.

preFunction

No

Yes or No.

Whether to execute a functional test before the leakage test.
SharedLeakageParallel test method limits

Limit

Comment

Leakage Current Shared Pins [uA]

The current limits for shared pins.

Leakage Current Non-Shared Pins [uA]

The current limits for non-shared pins.

Leakage Current Cross Pins [uA]

The current limits for cross-terminated pins.

Utility control

The keyword for specifying the utility line settings for SharedLeakageParallel in the utility control section of the sharing configuration file is leakage.

For information on the syntax, see Sharing configuration file.
