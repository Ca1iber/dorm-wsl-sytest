SMC_GET_TESTSUITE_NAME()

Retrieves the name of the test suite of the current thread.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Syntax

void SMC_GET_TESTSUITE_NAME(STRING& name);
List of parameters

Parameter

Description

name

 The name of the test suite.

Return value

There is no return value.

Functional changes

  1. Introduced in SmarTest 7.4.4
