Property class

This class provides access the value of a data logging property in a test method considering the active profile and the current system context.

This class is defined in the header file /opt/hp93000/soc/prod_com/include/Property.hpp.

Constructor

Property::Property()

Default constructor for the Property class. Initializes all member variables.

Property::Property(char * propNameIn)

This constructor is used to immediately specify the property name.

Parameter

propNameIn

The name of the new property
