GET_TEST_FOCUS

This API returns the number of the setup-focused sites, and stores the site numbers into the array variable specified as the parameter.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SiteControl.h.

Syntax

INT GET_TEST_FOCUS(ARRAY_I& sites);
Parameter

I/O

Parameter

Description / Range

O

sites

The site numbers of the setup-focused sites are returned to the contents of this array variable.

Note: The size of the array is set to 1 if the API is executed outside of the ON_FIRST_INVOCATION block or inside of a FOR_EACH_SITE loop block.

Return value

This API returns the number of the setup-focused sites.

Examples

Example 1: Using GET_TEST_FOCUS in a semi parallel test block

ARRAY_I                 sitesArray;
ARRAY_I                 configuredSitesArray;
string                  activeSitesString;
INT                     configuredSites;
string                  enabledSitesString;
SEMI_PARALLEL_CONFIG    semiParallelConfig_3_1;

//
// Define the semi parallel test groups
//
semiParallelConfig_3_1.group(1).add(1).add(2).add(4);
semiParallelConfig_3_1.group(2).add(3);

//
// Show the site in focus for the current invocation
//
cout << endl;
cout << "Invocation for site: " << CURRENT_SITE_NUMBER() << endl;
cout << endl;

//
// ON_FIRST_INVOCATION block
//
ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Show the static site information
    //
    GET_ACTIVE_SITES        (activeSitesString);
    GET_ENABLED_SITES       (enabledSitesString);

    configuredSites = GET_CONFIGURED_SITES(configuredSitesArray);

    cout << "\tCONFIGURED_SITES:    " << configuredSites       << endl;
    cout << "\tENABLED_SITES:       " << enabledSitesString    << endl;
    cout << "\tACTIVE_SITES:        " << activeSitesString     << endl;
    cout << endl;

    //
    // Show the sites in setup focus at the begin of the ON_FIRST_INVOCATION block
    //
    GET_TEST_FOCUS(sitesArray);

    cout << "\tBegin of ON_FIRST_INVOCATION block, sites in setup focus:";

    for (int index = 0; index < sitesArray.size(); index++)
    {
        cout << " " << sitesArray[index];
    }

    cout << endl;
    cout << endl;

    //
    // Semi parallel test block
    //
    FOR_SEMI_PARALLEL_TEST_BEGIN (semiParallelConfig_3_1);
    {
        //
        // Show the sites in setup focus within the semi parallel test block
        //
        cout << "\t\tSemi parallel test group " << GET_CURRENT_SEMI_PARALLEL_GROUP_NUMBER();
        cout << ", sites in setup focus:";

        GET_TEST_FOCUS(sitesArray);

        for (int index = 0; index < sitesArray.size(); index++)
        {
            cout << " " << sitesArray[index];
        }

        cout << endl;
        cout << endl;
    }
    FOR_SEMI_PARALLEL_TEST_END();

    //
    // Show the sites in setup focus at the end of the ON_FIRST_INVOCATION block
    //
    GET_TEST_FOCUS(sitesArray);

    cout << "\tEnd of ON_FIRST_INVOCATION block, sites in setup focus:";

    for (int index = 0; index < sitesArray.size(); index++)
    {
        cout << " " << sitesArray[index];
    }

    cout << endl;
    cout << endl;
}
ON_FIRST_INVOCATION_END();

Example 2: Get, change, and restore the setup focus of a site

Note Setting the test focus as show in the following example is supported for a limited selection of APIs. For detailed information refer to Site-Specific Setup. We recommend using the "each site loop block" or the "semi-parallel testing block" to manually control the setup focus or the query focus. For more information refer to Controlling Multiple Sites.
ARRAY_I sites;
...
...
ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Get the site numbers of the currently setup-focused
    // sites and store them into the sites array.
    //
    GET_TEST_FOCUS(sites);

    //
    // Enable the setup focus on site 1.
    // Disable the setup focus on all other sites.
    //
    // Note: The setup focus for all other sites is disabled
    //       because the optional parameter "exclusive" is omitted.
    //       The default value = true is applied.
    //
    SET_TEST_FOCUS(1);

    //
    // Apply changes only to site 1.
    //
    AWG("ain").vOffset(5.0 V);

    FLUSH();

    ...
    ...

    //
    // Restores the state of all enabled sites to the original
    // state by using the contents of the sites array.
    //
    SET_TEST_FOCUS(sites);
}
ON_FIRST_INVOCATION_END();
