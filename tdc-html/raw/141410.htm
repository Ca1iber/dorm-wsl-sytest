MTP_MEMORY_PATTERN.getDeviceSize()

Retrieves the device size of the x, y, z, d dimensions respectively.

Syntax

bool getDeviceSize (long & xBits, long & yBits, long & zBits, long & dBits);
Parameters

Parameter

Description

xBits

A variable used to store the retrieved size for the x dimension.

yBits

A variable used to store the retrieved size for the y dimension.

zBits

A variable used to store the retrieved size for the z dimension.

dBis

A variable used to store the retrieved size for the d dimension.

Return value

Returns true or false to indicate whether the device size has been retrieved or not.

Functional changes

  1. Introduced in MTP 3.2.1
