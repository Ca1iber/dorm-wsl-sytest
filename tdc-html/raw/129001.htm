MTP_MEMORY_TEST.addBitMapFileUserComments()

The addBitMapFileUserComments() member function of MTP_MEMORY_TEST lets you add arbitrary comments to generated bit fail map files.

This is an optional method.

Syntax

MTP_MEMORY_TEST& addBitMapFileUserComments(const STRING& comments)

Parameter

Description

comments

Any text that you want to add as a comment to the bit fail map.

The default is the list of result pins (see also setResultPins()).

Example

To add the text "March6n Manual Filemap" to the generated bit fail map files:

MTP_MEMORY_TEST memoryTest();
memoryTest.addBitMapFileUserComments("March6n Manual Filemap");
