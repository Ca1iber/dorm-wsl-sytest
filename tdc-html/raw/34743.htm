DRLGetNextUnmaskedEvent

int DRLGetNextUnmaskedEvent (DRLDataStream *stream, DRLEventRec *event)

This function reads event records from the data log stream or file stream until the record of an unmasked event or the end of the data log stream or file is encountered. If the record of an unmasked event is found, it is copied to the buffer event which is provided by the function call. The buffer event lets you access all data in this event record. You should not access this data directly, but use the DRLEventGet... functions described below.

For information on how to mask and unmask events, see DRLSetEventMask and DRLEventMask.

If no record of an unmasked event is found, or the end of the data log stream or data log file is reached before an event record could be read completely, an error code is returned. In both cases, the content of event is undefined. For further information on the data type of event, see DRLEventRec.

All masked events are discarded by DRLGetNextUnmaskedEvent, except for the record of an event of type ConfigurationChangedEventType.

Note that the data in the event buffer stays valid only until the next call of the DRLGetNextUnmaskedEvent function on the same stream. Even when the call is performed with another buffer, the contents of event become invalid. This is due to the internal memory management which automatically performs all tasks of allocating and freeing memory.

To keep the event data in the event buffer longer than just until the next call to DRLGetNextUnmaskedEvent, you have to call the DRLKeepEvent function.

Return Value

The return value is zero if the function was successful. Otherwise one of the following error codes is returned (see Error Codes):

  • ERR_NO_EVENT: Either no event record was available or the events related to all available event records were masked by the current event mask.
  • ERR_EOF: The end of the data log stream or data log file was encountered before the event record had been read completely.

Example

void example (void)
{
   DRLEventRec event;
     if (DRLGetNextUnmaskedEvent (&stream,&event))
   { 
      /*  error handler  */
   }
/*   if DRLGetNextUnmaskedEvent was successful, the 
event is now filled with valid data and &event can be 
used for calls of functions which expect an argument of 
the type DRLEventRec* (for example, DRLEventGet... functions)
*/
}
