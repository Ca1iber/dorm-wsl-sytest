enum GIO_RS232_MODEM_CONTROL

Serial interface modem control.

These values are used with gio_rs232_modem_control to control the RTS and DTR lines of an RS-232 interface and with gio_rs232_modem_control_status to inquire their status.

Enumerator
GIO_RS232_MODEM_CONTROL_RTS 

State of RTS (request to send) line.

GIO_RS232_MODEM_CONTROL_DTR 

State of DTR (data terminal ready) line.

enum GIO_RS232_REQUEST

Serial interface control & status.

These values are used with gio_rs232_control to change communication parameters of an RS-232 interface and with gio_rs232_status to inquire the interface status.

Enumerator
GIO_RS232_BAUD 

Baud rate of the interface.

GIO_RS232_PARITY 

Indicate whether a parity bit is transmitted.

GIO_RS232_STOP_BITS 

Number of stop bits.

GIO_RS232_WIDTH 

Number of data bits.

GIO_RS232_FLOW_CONTROL 

Flow control mode.

GIO_RS232_MODEM_STATUS 

State of modem status signals.

GIO_RS232_STATUS 

State of the RS-232 interface.

GIO_RS232_RESET 

Reset the RS-232 interface.

GIO_RS232_READ_EOI 

End-of-message indicator for read operations.

GIO_RS232_WRITE_EOI 

End-of-message indicator for write operations.

GIO_RS232_READ_DAV 

Number of data bytes available for reading.

GIO_RS232_XON_CHAR 

Character signaling (re)start for XON/XOFF flow control.

GIO_RS232_XOFF_CHAR 

Character signaling pause for XON/XOFF flow control.
