Topic 118232

How to load the test program

You can use the DownloadTestprogram API to download the test program to the test system. Before downloading the test program, you need to synchronize with the DEVICE_CHANGE_COMPLETED HVMAPI event.

About this task

You can catch the HVM API events and errors issued during the API execution.

Before you begin

Make sure a SmarTest session is successfully started and changed to the target device.

Procedure

  1. Prepare the parameters for the DownloadTestprogram API.
  2. Download the test program
  3. Report the execution status of this API.

Results

The API is successfully downloaded and the TESTPROGRAM_DOWNLOAD_COMPLETED event is issued. If any error occurs, the error severity, description and code and will be reported.

Example

The following example downloads the test program ft1 to the test system and reports the errors occurred.

void handlerDeviceChangeComplete (const std::string& type,
                                  const xoc::hvmapi::ParamList& params,
                                  unsigned long sec,
                                  long usec,
                                  const std::string& session)
{
  //undefine the Status that is defined in the XWindow header file
  #ifdef Status
  #undef Status
  #endif
  
  xoc::hvmapi::ParamList cmdParam;
  xoc::hvmapi::Status errObj;
  cmdParam.setValue ("TESTPROGRAM_NAME","tp01");

  cout << " received change device completed events " << endl;
  cout << "FA: DownloadTestprogram started: " << endl;
  errObj = xoc::hvmapi::command("DownloadTestprogram",cmdParam,session);
  if ( errObj.isSuccess() )
  {
    cout << "FA: DownloadTestprogram executed: " << endl;
  }
  else
  {
    cout << "FA DownloadTestprogram not executed" << endl;
    cout << "error code is" <<errObj.code() <<endl;
  }
  //define the Status as in XWindow header file
  #define Status
  return;
}
