Port Editor

In this editor, you can select port members for a port.

There are some rules for defining ports:

  • A port must not have the same name as a pin or pin group.
  • Port definitions correspond to fixed group definitions. Expression-based port definitions are not supported.
  • Ports are automatically pin groups. That is, ports in a setup can be used as an ordinary pin group. For example:
    • In the level setup, the port names may be included in all lists from which you can select pin groups.
    • In the pin configuration, you can use ports (as pin groups) in expression based pin group definitions.
