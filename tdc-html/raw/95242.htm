Timestamps in the event data log

The event data log also provides test time information. It supplies a time stamp for the start and the end of every event that is recorded. Note that test suite and test function events are only recorded if the test suite flags Output on pass or Output on fail are set. Note also that the time stamps for test suites and test functions are ignored by the Event Formatter. If you want to view them, you can use the DRLDump tool (see Appendix B: The DRLDump Tool).

DRLDump can also be used as a template for a user written tool that processes the time stamps. Such a tool could be used to produce statistical evaluations that are not supplied by the debug 3 mode. For example, it could calculate the median of the individual measurements.

Of course, if you want to make use of the time stamps in the event data log, you must enable the event data log. Since this slows down the test, test time measurements that are based on the event data log time stamps are not comparable to measurements produced by the debug 3 mode if the event data log is disabled in the latter case.
