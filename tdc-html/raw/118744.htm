PutDebugGraph

This API allows you to create graphs in the Signal Analyzer tool if the debug_analog testflow flag is on. You can also use this API to specify the graph settings in the Signal Analyzer tool, such as title, axis labels, and units, etc.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PutDebugGraph.h.

Syntax

PutDebugGraph().member_function;
PutDebugGraph("myMeas").member_function;

myMeas is the name of the PutDebugGraph object.

member_function is the member function defined in the PutDebugGraph class. For retrieving data, only one member function is available.

Constructor

PutDebugGraph();
PutDebugGraph(const STRING& graphTitle);

This constructor creates a class object that stores the trace data.

Parameter

graphTitle

The title of the graph.

By default, the graph title must be provided unless the DEMODULATION or MEAS_DEF_I object is used. In this case, you need not set a title.

If the graph title set here has existed in other test method, the data is appended to the existing graph.

setXAxis()

PutDebugGraph & setXAxis(const STRING& label, const STRING& unit);

This function specifies a label and a unit for the x-axis.

Parameters

label

The label of the x-axis.

unit

The unit of the x-axis. It can be:

  • Frequency unit: GHz, kHz, and Hz
  • Time unit: s, ms, us, ns, and ps
  • Current unit: A, mA, uA, and nA
  • Voltage unit: V, mV, uV, and nV
  • Power unit: W, kW, MW, and GW
  • Capacitance unit: F, mF, uF, nF, and pF

The unit is not merely a string but a meaningful value. This is related to a sampling parameter of trace data.

This function adds the DEMODULATION or MEAS_DEF_I object to the graph if the debug_analog testflow flag is on.

Parameter

demod

The DEMODULATION object to be passed to the Signal Analyzer tool.

meas

The MEAS_DEF_I object to be passed to the Signal Analyzer tool.

graphSelect

The style of the graph.

Using a DEMODULATION object, the valid values of the graphSelect parameter are:

  • TM::CONSTELLATION: plots the constellation points of a demodulation
  • TM::COMPOSITE: plots the composite error of a demodulation
  • TM::EVM_VS_SYMBOL: plots the EVM (Y-Axis) versus the Symbol Number (X-Axis)
  • TM::ALL_GRAPHS: plots all graphs available for the object
  • TM::ERROR_VECTOR_SPECTRUM: plots the EVM (Y-Axis) versus Frequency Offset (X-Axis)
  • TM::ERROR_VECTOR_TIME: plots the EVM (Y-Axis) versus Time (X-Axis)

 

testSuite

Name of the test suite.

tsNum

Test number.

site

Site number.

Example

  • This example provides the simplest way to show data in its own graph.
    ARRAY_D data;
...   //Assign values to the "data" array
PutDebugGraph("My Graph Name").
setTrace(PutDebugTrace("Trace Name").setWaveform(data)).show();
  • This example shows the IQ data in one graph. By setting the sample rate, Signal Analyzer functions such as "Demodulation" will automatically have access to it.
    ARRAY_COMPLEX iqData;
...   //Assign values to the "iqData" array
PutDebugGraph("My Graph Name").
setTrace(PutDebugTrace("Trace Name").setWaveform(iqData).setSampleRate(10e6)).show();
  • This example shows trace data of the Time-Domain object. It also sets the labels and units for the x-axis and y-axis.
    PutDebugTrace myTrace("Trace Name");
myTrace.setWaveform(data).setSampleRate(10e6);
PutDebugGraph("Time Domain").setTrace(myTrace).
setXAxis("Time","us").setYAxis("Voltage","mV").show();
  • This example shows the RF spectrums.
    // These are return parameters from DSP_RF_MOD_POWER
INT firstBin, lastBin;
ARRAY_D spectrumData;
... //Assign values to "firstBin" and "lastBin"
PutDebugTrace myTrace("My Spectrum");
myTrace.setWaveform(spectrumData).setSampleRate(10e6).setValidSampleRange(firstBin, lastBin).setCenterFrequency(1e9);
PutDebugGraph("Spectrum").setTrace(myTrace).
setXAxis("Frequency","Hz").setYAxis("Power","dBm").show();
  • This example shows a Smith chart with title "smith". The trace data are results of the return loss measurement for "myMeas".
    PutDebugGraph("smith").setObject(MEAS_DEF("myMeas"), TM::REFLECT_COEF_SMITH).show();
  • This example shows a rectangular plot (magnitude in decibel of reflection coefficients versus frequencies) with title "rect". The trace data are results of the return loss measurement for "myMeas". 
    PutDebugGraph("rect").setObject(MEAS_DEF("myMeas"), TM::REFLECT_COEF_RECT).show();
  • The following is a complete example which can be used to execute a return loss measurement over a predefined frequency list and shows the measurement results in Smith chart and rectangular plot. A variable is used as the frequency list index and is changed inside a loop, which avoids adding multiple sequence blocks. 
    // =================================================
// This code goes at the top of your 
// TestMethod Class file (top of the .cpp file)
// -------------------------------------------------
static void myDsp(const STRING& measName, 
                  const ARRAY_D& measParams,
                  ARRAY_D& results,
                  DOUBLE& measuredPower)
{
  // get S11 A-Term Waveform
  ARRAY_COMPLEX s11a = MEAS_DEF(measName).getComplexWaveform(1);
  // get S11 B_Term Waveform
  ARRAY_COMPLEX s11b = MEAS_DEF(measName).getComplexWaveform(2);

  DSP_RF_RETURN_LOSS(s11a, s11b, measParams, results, &measuredPower);

  // Optionally print results to ui.Report window
  cout << "S11 = " << results[TM::S11_MAG_RESULT_IDX] << ", " << results[TM::S11_PHASE_RESULT_IDX] << endl;
  cout << "Measured Power = " << measuredPower << " dBm " << endl;
}


// ==================================================================
// This code goes into your TestMethod Class body
// ------------------------------------------------------------------
virtual void run()
{
   // name of the return loss measurement
  STRING measName = "retloss_1block";

  ON_FIRST_INVOCATION_BEGIN();
  {
    Analog.primary(measName);
    MEAS_DEF(measName).disableAll().connectAll();
    STRING freqListName = "";
    MEAS_DEF(measName).get("FreqList", freqListName);
    ARRAY_D freqList = DATA_DEF(freqListName).getArray();
    INT startIndex = 0;
    INT numOfCaptures = 50; // number of frequencies in sweep

    ARRAY_D freqs(numOfCaptures);
    ARRAY_D magdB(numOfCaptures);
    ARRAY_COMPLEX data(numOfCaptures);

    for (INT listIndex=startIndex;
         listIndex<numOfCaptures+startIndex; 
         listIndex++) 
    {
      // "freqIdx" is the name of the variable for frequency list index
      // in sequence block
      DATA_DEF("freqIdx").set(listIndex);
      // Execute the group here.
      EXECUTE_GROUP(measName);  // SW Triggers the sequence
      freqs[listIndex-startIndex] = freqList[listIndex];
      
      // Fetch the DSP parameters from ADEF
      ARRAY_D measParams = MEAS_DEF(measName).getParameters(1, listIndex);
      ARRAY_D results(TM::RF_DSP_RETURN_LOSS_RESULT_SIZE);
      DOUBLE measuredPower=0;
              
      // Run the DSP on the captured data
      myDsp(measName, measParams, results, measuredPower);
      DOUBLE mag = pow(10, (results[TM::S11_MAG_RESULT_IDX])/20);
      DOUBLE real = mag*cos(results[TM::S11_PHASE_RESULT_IDX]/180*M_PI);
      DOUBLE imag = mag*sin(results[TM::S11_PHASE_RESULT_IDX]/180*M_PI);
      COMPLEX complex(real, imag);
      data[listIndex-startIndex] = complex;
      magdB[listIndex-startIndex] = results[TM::S11_MAG_RESULT_IDX];
    }    

    // plot rectangular plot
    STRING pinName = "";
    MEAS_DEF(measName).get("InputPin", pinName);
    PutDebugGraph myGraph("rectangular plot");
    myGraph.setXAxisUnit("Hz").setXAxisLabel("Freq");
    myGraph.setYAxisUnit("dB").setYAxisLabel("Mag");
    PutDebugTrace myTrace("magdB");
    myTrace.setScatter(freqs, magdB);
    myTrace.setLineStyle("solid");
    myTrace.setPin(pinName);
    myGraph.setTrace(myTrace);
    myGraph.show();

    // plot smith chart. not supported before 7.0.3
    PutDebugGraph myGraph2("smith chart");
    PutDebugTrace myTrace2("reflectCoef");
    myTrace2.setReflectionCoefficients(data,freqs);
    myTrace2.setPin(pinName);
    myGraph2.setTrace(myTrace2);
    myGraph2.show();
    MEAS_DEF(measName).disconnectAll();
  }
  ON_FIRST_INVOCATION_END();
  return;
}
