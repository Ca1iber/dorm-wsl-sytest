SMC__SYNCHRONIZE

The test method waits for the end of the execution of all threads which have been started using test method API SMC_ARM() on the currently active site.

After all threads have finished their upload and calculation task, the queued SMC_TEST() statements will be executed to perform the data logging and binning.

If hidden data logging is used, binning is not handled in this test method, but in the SMC_backgroundProcessing() function.

The run() function of the test method is implemented as
virtual void run()
{
    SMC_SYNCHRONIZE ();
}

List of test method parameters

There are no test method parameters.
