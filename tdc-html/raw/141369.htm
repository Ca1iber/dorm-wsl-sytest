EVENT_WAVEFORM_IC.getIClampLow()

Queries the low clamp current waveform.

Syntax

const & ARRAY_D getIClampLow() const;

List of parameters

There are no parameters.

Return value

The low clamp current waveform as an ARRAY_D (array of doubles).
