Topic 10409

Executing firmware commands from within a program

You can execute firmware commands by an API in a

  • user procedure, or
  • test method.

User procedures

From a user procedure, you can execute firmware commands with the HpFwTask function. For details see HpFwTask.

Test methods

You can execute a firmware command from a test method with the FW_TASK API. For details see FW_TASK.
