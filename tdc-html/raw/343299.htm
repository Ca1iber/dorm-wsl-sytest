SmartRDI 2.5.0

This section summarizes software changes including new features and enhancements in SmartRDI 2.5.0.

Changes and new features

Category

Description
General General Features
  • Pure Generation Mode

    See the new keyword PURE_GENERATION_MODE in RDI_Configure file.

  • Offline Result Emulation

    See Using Offline Result Emulation in SmartRDI.

  • Pass/Fail per label without break vectors (BFLM mode)

    See Pass/Fail per label without break vectors.

  • Burst site upload

    See Controlling burst site upload
General Improvements
  • Test time is improved with:
    • No PPMU/BADC setup after the 1st run (higher than SmarTest 7.4.2)
    • DCScale DC & TMU runTimeValue speed-up
    • RDI_INIT() Xput Improvement
  • Changes to parameters default values in RDI_Configure file to enhance compatibility.
    • Change the default value of PPMU_DEFAULT_VALUE_MODE from SA to BADC because: BADC has a better accuracy than SA mode; BADC is specified for current measurement, while SA mode is not; BADC provides better Xput for low pin counts.
    • Change the default value of PER_LABEL_FUNC_RESULT_MODE from FLBL to ERMP to achieve better throughput, especially for high site counts.
    • Change the default value of DEFAULT_SMV_READ_MODE from EMAP to DIGCAP for better upload performance.
    • Change the default value of VEC_MODE_SAMPLING_WAIT from MSET to PATTERN for more accurate sampling wait of the pattern loop for PPMU DC sampling tests in VEC mode.
Digital Capture Immediate upload

See Using Immediate Upload in SmartRDI.
Relay runTimeValue for digital relays

See the new function setOnRunTime(), setOffRunTime() and runTimeVal().
PMUX
  • A new class route() to support the routing GUI tool new in SmarTest 7.4.3

    See SmartRDI: DUT board connections control by Routing Tools for details of this new route() class.

  • PMUX status report for debug
  • Support of the global pin "ALL" in the mux() and module() classes
Tool Get cycle/vector number of a comment in a pattern

See getCommentCycleNum() and getCommentVectorNum().
