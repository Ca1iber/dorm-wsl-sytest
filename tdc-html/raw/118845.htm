TMLimits backwards compatibility

TMLimits files that have been created for the Apex version can easily be used in the SmarTest version of TMLimits.

The Apex version of TMLimits was a custom implementation that preceded the official release of TMLimits in SmarTest 6.5. It is largely compatible with the official version but some considerations apply, as described below.

File compatibility

CSV files that have been created for the Apex implementation of TMLimits can be used unchanged with the official SmarTest implementation of TMLimits.

To be available to the testflows, the files must be placed in the testtable subdirectory of the device directory. They can then be used as described in Using TMLimits test tables as well as edited as described in Editing TMLimits test tables.

Converting test methods

When you convert test methods that use the Apex implementation to the official implementation, you must:

  1. Remove all explicit include references to the Apex TMLimits.h header file.
  2. Make sure that the include path does not contain the Apex TMLimits header file (named TMLimits.h). It is not necessary to include the official TMLimits header file (also named TMLimits.h).
  3. Define the correct namespace by adding the line using namespace V93kLimits; at the top of every file that includes TMLimits.
  4. Recompile the test method to update the library links.

No modification to the actual test method calls to TMLimits is needed because the APIs of both TMLimits versions are the same.
