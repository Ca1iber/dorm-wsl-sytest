Topic 44953

Primary Sets for User Procedures into Variables

get

long  GetCurrentPrimaries(long *waveform_set,
                          long *timing_set,
 *                        long *level_set,
 *                        long *dps_set,
 *                        char *label)

This function reads the primary sets (these are the parameters for the SPRM and SQSL firmware commands) for the user procedure into the variables provided by the call.

An example of how it should be used is, 

long w_set, t_set, l_set, d_set;
char this_label[CI_CPI_MAX_LABEL_LEN];

GetCurrentPrimaries(&w_set,&t_set,&l_set,&d_set,this_label);
       ...

The returned values are,

0

OK

!=0

no primaries are set

send

long  SendCurrentPrimaries(void)

Reads the primaries (as with GetCurrentPrimaries()), assembles the respective SPRM and SQSL firmware commands, and sends them to the firmware.

The returned values are,

0

OK

!=0

an error occurred (no primaries, error while sending, etc)
Note If primaries are specified for a user procedure, the respective firmware commands will already have been sent to the test system before the user procedure is executed.
