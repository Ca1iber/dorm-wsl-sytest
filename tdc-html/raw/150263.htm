The EVENT_VC class provides the functionality to change the clamp voltage in pattern‑based PMU measurements.

This class is supported only for the DC Scale XPS256 card in PMU operating mode.

Class definition

The class derives from the EVENT_BASE class.

The object that is created by this class has to be assigned to the PATTERN_CONTROLLER which is responsible for further handling.

This class is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

The constructor creates an object of the type EVENT_VC and assigns the given identifier to the object.

Parameter Description
id

Identifier of the event.

The identifier may be defined as integer value or as string.

Return value

The constructor has no return value.

Example

The following example creates a new DC event, sets the data of the DC event and inserts the DC event into an already existing pattern. The programmed data are then read back from the event object and shown in the console window.

PATTERN_CONTROLLER patController;

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Create a new event object
    //
    EVENT_VC event_VC ("VC");

    //
    // Set the event data
    //
    event_VC
        .vClampLow (-5.0 V)
        .vClampHigh(20.0 V);

    //
    // Insert the event into a pattern
    //
    PATTERN & pattern = patController.label("...", "@");

    pattern.vecEvents("pin1").clearAll();

    pattern.vecEvents("pin1")
        .insert(100, event_VC)
        .setup ();

    //
    // Read data from the event object
    //
    EVENT_VALUE_DOUBLE vClampLow, vClampHigh;

    event_VC.getVClampLow (vClampLow);
    event_VC.getVClampHigh(vClampHigh);

    cout << "vClampLow  = " << vClampLow    << endl;
    cout << "vClampHigh = " << vClampHigh   << endl;
}
ON_FIRST_INVOCATION_END();
