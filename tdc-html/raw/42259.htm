Topic 42259

Using driver functions in the application model

Subtopics

  1. Example application models

The general handler driver and the general prober driver each provide a set of driver functions to be called from the application model via PROB_HND_CALLs.

These functions allow you to control the driver and run various driver actions.

This chapter describes all available driver functions and explains how to use them by means of two example application models which use all functions. One application model performs a package test, the other performs a wafer test.

You can find the descriptions of the prober/handler driver functions in the section Driver Functions Description.
