In this chapter, you will learn how to use the Shmoo Tool to

  • Set up and execute shmoo tests.
  • Display shmoo plots of different pins, sites and results.
  • Overlay shmoo plots
  • Interact with a testflow to:
    • Transfer shmoo tests
    • View shmoo plots from the Integrated Result Tool
    • Log shmoo data into the report window and save shmoo plots as .png or ASCII files.
