Topic 95803

ShutdownSmartestSession

This command initiates the shutdown of the specified SmarTest session. When all the components, processes and resources belonging to this session are cleared, the event SMARTEST_SESSION_TERMINATED is notified. If the session cannot be killed, the event SMARTEST_SESSION_TERMINATED will not be generated.

SUCCESS will be returned if the command is successfully issued. Otherwise an error object indicating the error code and error description will be returned.

Description

Severity
