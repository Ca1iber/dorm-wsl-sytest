Test method snippets for RF to RF test

The following test method snippets for RF to RF test are provided with SmarTest. These test method snippets are included in the file /opt/hp93000/soc/segements/tml/testmethodSnipptets.xml.

IQ setup is required for the execution of these snippets. To save test time, the data of ARRAY_X type is not passed as parameters but as private member variables of test method class to the post processing functions.

The snippets are listed in the alphabetical order.

  • V93000_RFtoRF_PhaseNoise_Measure

This snippet sets up and performs a RF to RF loop back phase noise test with SmartCalc. It then uploads the result waveform and kicks off the hidden calculation with the SmartCalc background post processing function.

  • V93000_RFtoRF_PhaseNoise_SMCPostProcess

This snippet does the post processing for the RF to RF loop back phase noise test with SmartCalc. It calculates the phase noise of the result waveform. The result is judged with the limit in the test table and logged. The snippet can be used together with the snippet V93000_RFtoRF_PhaseNoise_Measure in the test method.

  • V93000_RFtoRF_PowerOut_Measure

This snippet sets up and performs a RF to RF CW power out test with SmartCalc. It then uploads the result waveform and kicks off the hidden calculation with the smartCalc background post processing function.

  • V93000_RFtoRF_PowerOut_SMCPostProcess

This snippet does the post processing for the RF to RF CW power out test with SmartCalc. It calculates the power of the result waveform. The result is judged with the limit in the test table and logged. The snippet can be used together with the snippet V93000_RFtoRF_PowerOut_Measure in the test method.

Functional changes

  1. Introduced in SmarTest 6.5.4
