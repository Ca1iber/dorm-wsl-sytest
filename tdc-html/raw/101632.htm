DRLPortPFResultAttr

A variable of this type holds the pass/fail result of a port.

Port_index holds a reference to PortDescAttrType in the last ConfigurationChangedEventType.

The member failure_code can hold the following values:

Failure code values

Value

Description

-2= DRLFailureCode_Fatal

test method execution incomplete or test method crashed

-1= DRLFailureCode_NA

no pass/fail result determined

0 = DRLFailureCode_Pass

passed

1 = DRLFailureCode_Fail

failed

2 = DRLFailureCode_Error

error

3 = DRLFailureCode_Bypass

bypassed (this applies only to test suites)

 
typedef struct _DRLPortPFResultAttr {
    int Port_index;
    unsigned char failure_code
} DRLPortPFResultAttr;

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.4.1: Added error code -2.
