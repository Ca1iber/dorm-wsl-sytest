DSP_EXP_VEC

This API raises "e" to the powers specified by the elements in a specified array.

For the specified elements in source_array, these functions raise "e" to the powers specified by the elements, and return the results to result_array as follows:

For not-complex data processing:

For complex data processing:

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_EXP_VEC(ARRAY_D& src, ARRAY_D& result);
DSP_EXP_VEC(DOUBLE *src, DOUBLE *result, 
            INT size);
DSP_EXP_VEC(ARRAY_COMPLEX& src, 
            ARRAY_COMPLEX& result);
DSP_EXP_VEC(COMPLEX *src, COMPLEX *result, 
            INT size);
Parameters

I/O

Parameter

Description / Range

I

src

Source array

O

result

Raised results

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src)

size ≤ (size of result)

Example

double array1[50], array2[25];
  .
  .
DSP_EXP_VEC(array1, array2, 25);

DSP_EXP_VEC raises "e" to the powers specified by the first 25 elements in the arrayarray1, and returns the results to the corresponding elements in the arrayarray2. For example, if the first element ofarray1is 3, "e" is raised to the power of 3 (exp(3)), and returned to the first element ofarray2. This function does the following:

int i;
for(i=0; i<25; i++)
array2[i] = exp(array1[i]);
