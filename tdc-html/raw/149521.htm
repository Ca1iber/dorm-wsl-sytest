Topic 149521

rdi.func().labelRunTime()

This function specifies a runtime label for each site.

SmartRDI supports per-site runtime labels, which means that you can decide which label (in a burst) to run based on a previous measurement result.

A predefined string "NO_LABEL" is provided to skip label generation on specific site. If user sets "NO_LABEL" as a label name on a specific site with runTimeVal(), during burst execution labelRunTime() generates no runtime label on this specific site.

See the example.

Syntax

rdi.func().labelRunTime(const string& runTimeId);
List of parameters

Parameter

Description

runTimeId

The ID of the label you want to run.

Example

vector <string> siteLabel(siteNum);  // Labels for each site.

siteLabel[0]="A1";        // Change label, site 1.
siteLabel[1]="B1";        // Change label, site 2.
siteLabel[2]="NO_LABEL";  // Change label, site 3.
...
rdi.runTimeVal("rtID", siteLabel);
RDI_BEGIN();
   rdi.func().labelRunTime("rtID").execute(); //Label "A1" and "B1" are generated for site 1 and 2; no label is generated on site 3.
RDI_END();
