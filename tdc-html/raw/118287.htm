Defining the wavetable for a PRBS test

The wavetable for a PRBS test is generated automatically by SmarTest from the primary PRBS set. You only need to tell the system two things. The first is that a PRBS test is to be executed. This is done with the PRBS_I (for generating an input PRBS) or PRBS_O (for checking an output PRBS) keywords. The second is the number of edges per cycle. This is done by specifying an x-mode with Xn. Note that the edges are distributed equidistantly within the tester cycle.

With PRBS_I, the x-mode range is from 1 through 8. Thus, the format is

PRBS_I (X1|X2|X3|X4|X5|X6|X7|X8).

Instead of PRBS_I, you can also specify PRBS_I_INV. In this case the generated PRBS will be inverted. Note that this inverted sequence is no longer a formal PRBS.

For differential pins it is not required to set up the normal and the inverted waveforms with PRBS_I and PRBS_I_INV. Instead use the @diff syntax to define the waveform for differential pairs.

With PRBS_O, only X1, X2, X4, and X8 are allowed. But you can combine a PRBS check with transition tracking (see Combining transition tracking with a PRBS or pattern‑based SmartLoop test). In this case, you must specify TTX4 or TTX6. This results in the following format:

PRBS_O (X1|X2|X4|X8|TTX4|TTX6).

Instead of PRBS_O you can also specify PRBS_O_INV. In this case the PRBS will be inverted for the comparison with the received data stream. Note again that this inverted sequence is no longer a formal PRBS.

If an input PRBS is to be generated, you can also define a break waveform with the usual keyword BRK. The format is

BRK (CLK|HOLD|F10|F1Z|F00|F0Z|F10_IDLE|F1Z_IDLE|F00_IDLE|F0Z_IDLE).

The function of the individual options is as follows:

CLK

A transition from 0 to 1 or from 1 to 0 occurs at every edge. The start value is 0.

HOLD

Nothing is done.

F10, F1Z, F00, F0Z

The pin is kept in the specified state throughout the cycle. Note that F1Z and F0Z are not supported in the STDDIFF mode.

F10_IDLE,

F1Z_IDLE,

F00_IDLE,

F0Z_IDLE

The pin is kept in the specified state throughout the cycle. The difference between the simple and the qualified options is that, for example, F10 is inverted to F00 for the negative connection of a pair of differential pins, whereas with F10_IDLE, no inversion takes place.

Note that for pins in STDDIFF mode, F1Z_IDLE is the only allowed qualified option.

Example

WAVETBL "PRBS"

PINS IN1
PRBS_I X6
BRK CLK

PINS IN2@diff
PRBS_I X6
BRK CLK

PINS OUT1
PRBS_O TTX6

In this example, both the input PRBS and the expected output PRBS are generated by SmarTest. On the output pin, the PRBS check is combined with transition tracking.
