Topic 98398

Leakage test concept

Subtopics

  1. Leakage test for shared lines

Measurement of digital device pins (I, O, and IO) for leakage currents.

This test method measures the leakage current at a device input or output or IO pin. The device pins can be brought into the desired state before the measurement by executing a functional test up to a specific vector or cycle. To perform the leakage measurement you can use the Pin PMU.

The Leakage test method consists of two leakage tests, low level test and high level test. You can execute them individually or together.

If specified, a functional test is executed up to a specific vector or cycle to bring the DUT into the desired state first. After the execution, the sequencer is set to break state with the AC relays closed and DPS set to the voltage programmed in the level setup.

Then, either a parallel or a serial leakage measurement is executed on the specified pins.

If PPMU relays are open, the precharge option can be used to program the PPMU to a voltage before closing the PPMU relay. SmarTest will wait this voltage to be settled and then connect the DUT to the PPMU by closing the relay. Typically the precharge voltage is the same as the voltage used to measure the leakage current.

The PMU current range is determined by the maximum of the absolute limit lower value and absolute limit upper value.

This test method supports test table. But you need to enter the test names manually in the parameter. You can use both test table and testflow limits in a testflow. The test table has higher priority than testflow limits. If a test name used in the test flow is defined in both test table and testflow limits, the value defined in the test table will be used.

Parameters

Parameter

Type

Description

pinlist

PinString

Pins of which the leakage to be measured. This can be @ for all applicable pins, or any number of applicable single pins. Valid pin types include all digital pins.

measure

STRING

Measurement to be taken.

LOW - only take the low level tests

HIGH - only take the high level tests

BOTH - take both low and high level tests.

forceVoltageLow

SpecValue

Value of force voltage for low level test.

It is in the format of value[unit]. Default value is 400[mV].

forceVoltageHigh

SpecValue

Value of force voltage for high level test.

It is in the format of value[unit]. Default value is 3800[mV].

spmuClampCurrentLow

SpecValue

Not used in SmarTest 7.10

Value of clamp current for low level test (SPMU only).

It is in the format of value[unit]. Default value is 0[uA].

spmuClampCurrentHigh

SpecValue

Not used in SmarTest 7.10

Value of clamp current for high level test (SPMU only).

It is in the format of value[unit]. Default value is 0[uA].

ppmuPreCharge

STRING

Enable/disable precharging (PPMU only).

ON - enable.

OFF - disable.

prechargeVoltageLow

SpecValue

Value of precharging voltage for low level test (PPMU only).

It is in the format of value[unit]. Default value is 0[mV].

prechargeVoltageHigh

SpecValue

Value of precharging voltage for high level test (PPMU only).

It is in the format of value[unit]. Default value is 0[mV].

settlingTimeLow

SpecValue

Value of settling time for low level test. The settling time will be in addition to the settling time calculated by the system.

It is in the format of value[unit]. Default value is 0[ms].

settlingTimeHigh

SpecValue

Value of settling time for high level test. The settling time will be in addition to the settling time calculated by the system.

It is in the format of value[unit]. Default value is 0[ms].

preFunction

STRING

Whether to execute functional pre-test. To use this parameter, you must select NO in the controlTestNumOfFunctional field (see the next parameter).

The available options are:

  • NO (Default) - no pre-test.
  • ALL - execute all vectors/cycles
  • ToStopVEC - stop sequencer at a specified vector
  • ToStopCYC - stop sequencer at a specified cycle

Selecting ALL, ToStopVEC, or ToStopCYC will:

  • Disable the controlTestNumOfFunctional parameter.
  • Not let you assign specific test numbers to the pre-functional tests. System will automatically give test numbers.

    To assign specific test numbers, select NO in this field and use controlTestNumOfFunctional.

controlTestNumOfFunctional

STRING

Use this parameter only when you want to assign specific test numbers to the pre-functional tests. Otherwise, select NO in this field and use preFunction (see above).

This parameter has the same functionalities and options as preFunction except for the flexible test numbers for the pre-functional tests. The procedure is:

  1. In the preFunction field, select NO.
  2. In the controlTestNumOfFunctional field, select ALL, or ToStopVEC, or ToStopCYC.
  3. In the test table, enter a test name for the pre-functional test, which must be either PreFunctionTest_High or PreFunctionTest_Low.
  4. In the test table, enter the desired test number.

stopCycVecLow

INT

stop cycle/vector for low level test

stopCycVecHigh

INT

stop cycle/vector for high level tes.

measureMode

STRING

Defines measurement mode.

PPMUpar - PPMU parallel. The test system opens the AC relay and closes the PPMU relay on the channel to be measured. The PMU forces the voltage at this pin, and measures the current flowing into or out of it. This is done for all specified pins in the pinlist in parallel.

PPMUser - PPMU serial. A serial leakage measurement on the specified pins is performed with the Pin PMU

relaySwitchMode

STRING

Relay switching mode used in case of no termination.

BBM - break before measurement (open AC relay, then close PMU relay).

MBB - measure before break (close PMU relay, then open AC relay).

PARALLEL - open AC relay and close PMU relay in parallel.

testName

string

The test names to be used as limits. Default is (passCurrentLow_uA,passCurrentHigh_uA).

If you want to use the test names defined in the test table or testflow limits, type in the test names manually. Make sure the test names are in the Test name column of the test table (Refer to Structure of a TMLimits CSV file) or in the Test Name column of Tests page of Flow Data Editor.

output

STRING

Controls how to output the per pin test result. It can be:

  • None: Do not output the per pin result.
  • ReportUI: Output all the per pin result to the report window.
  • ShowFailOnly: Only outputs the failed pin result to the report window.
Limit

passCurrentLow_uA

The pass range of the measured low level leakage

passCurrentHigh_uA

The pass range of the measured high level leakage

Implementation pseudo code

IF not already connected THEN
  connect DUT
ENDIF
IF low level test selected THEN
  IF functional pre-test selected THEN
    execute a functional test to the specified cycle/vector number
  ENDIF
  IF PPMU parallel selected THEN
    program PPMU with specified values
    Open AC relay and close PPMU relay
    set measurement
    execute PPMU measurement
    open PPMU relay and close AC relay
    retrieve test result
  ELSEIF PPMU serial selected THEN
    program PPMU with specified values
    execute PPMU measurement with PMU_VFIM
    retrieve test result

  ENDIF
ENDIF
IF high level test selected THEN
  IF functional pre-test selected THEN
    execute a functional test to specified cycle/vector number
  ENDIF
  IF PPMU parallel selected THEN
    program PPMU with specified values
    Open AC relay and close PPMU relay
    set measurement
    execute PPMU measurement
    open PPMU relay and close AC relay
    retrieve test result
  ELSEIF PPMU serial selected THEN
    program PPMU with specified values
    execute PPMU measurement with PMU_VFIM
    retrieve test result

  ENDIF  
ENDIF
datalog test results

In a shared driver setup the input pins of several devices are physically interconnected, which is not the case in a non-shared setup. Therefore, Advantest provides a leakage test method that take this shared setup into account.
