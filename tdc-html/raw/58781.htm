Topic 58781

Reporting the results

Subtopics

  1. Retrieving edge information by repeating the test

The recorded data can be analyzed in different ways and reported selectively and in different formats. When a single result is reported for several pins, PASS is only returned if the respective cycle (edge, if edges have been recorded) has passed for all these pins.

Error map data which can be reported is as follows:

  • the cycle area that has been recorded,
  • the error count,
  • the Error Map contents.

The list order corresponds roughly to the order in which the data will be retrieved.

The first step will normally be to check which area has actually been recorded. This is done with the VALD? query, which can be applied to the detailed and the overview Error Map.

There are three queries, ERCC?, ERCT?, and ERCY?, with which you can count errors and display information about them.

You can retrieve the content of the Error Maps with the EMAP? and the ERMP? queries. The EMAP? query is a more powerful variant of ERMP?.

EARE? returns drive and receive edge action data in the requested cycle range, as well as error information.

EARD? also returns drive and received compare data for all used edges in the requested cycle range. It can also return the combined results of all those Pin Scale pins that are mapped to one HXA pin.

EDGE? returns, for selected pins, the edges which failed during a functional test.

Finally, the CYCI? query returns comprehensive information about the progression of the test, and FFCI? returns pin specific information on the first n failing cycles.
