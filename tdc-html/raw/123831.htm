Configure the protocol

Subtopics

  1. Configuring general parameters
  2. Configuring write parameters
  3. Configuring read parameters
  4. Configuring wait parameters

About this task

The details of your protocol are described in your protocol file, for example the d2sJTAG.h file. It can be created from the d2sSerialProtocolTemplate.h. If you create your own protocol file from scratch, you have to ensure that it includes the d2s_Serial.h file.

This task provides an overview to the mandatory steps to modify your protocol file to match your protocol. A detailed description of each step is provided with the respective link.

The examples provided are related to each other the way that they utilize the corresponding previous example.

Before you begin

Import the d2s_tml.zip library to your UTM project and rename the d2sSerialProtocolTemplate.h file to reflect your protocol as described in Prepare the test method infrastructure.

Procedure

  1. Configure general parameters.
  2. Configure write parameters.
  3. Configure read parameters.
  4. Configure wait parameters.

What to do next

Add d2s to your user test method.
