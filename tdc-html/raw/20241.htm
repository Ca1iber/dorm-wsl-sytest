Topic 20241

Deleting nodes

Before you begin

Make sure that a node has been inserted into the testflow.

Note To remove the Run and Branch node or Flow control nodes, you must wide select them (see Narrow selection and wide selection).

Procedure

  1. In the Flow Sequence Editor, select one or more nodes (press Ctrl and then click) you want to delete.
    Note

    If the Run and Branch node or Flow control node is narrow selected, first press Ctrl and then left click to wide select them.

  2. Press delete.
  3. The Confirm Delete window opens. Click OK.

    If the selected node is a test suite node, you can turn it into a floating test suite by clicking Covert to floating in the Confirm Delete window.

    Note The Run and Branch node and Run node can only be deleted in the Flow Sequencer Editor. They cannot be removed in the Test Suites page of the Flow Data Editor. In this page, you can delete the floating test suite and special test suite.

Results

The node and all its subbranches are removed from the testflow.

What to do next

Save the testflow.

Related information

Narrow selection and wide selection

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.2: You can delete the testflow node in the Flow Sequence Editor.
  3. SmarTest 6.5.3: In the Flow Sequencer Editor, you must wide select the Run and Branch node and flow control nodes to delete them.
  4. SmarTest 6.5.3: In the Flow Data Editor, the normal test suites cannot be removed. You can only delete the floating test suite and special test suite.
