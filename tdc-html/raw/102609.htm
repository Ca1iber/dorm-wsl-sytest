Other control structures

In addition to 'for' loops, MTL contains control structures for specifying interruptible and non-interruptible sequences.

Interruptible sequences can contain maintenance operations (refreshes) anywhere; non-interruptible sequences cannot contain any refreshes; refreshes are only possible before or after such sequences.

The is{} and nis{} statements used to specify sequences are similar, but complements of each other:

  • Using is{} indicates that the program is not interruptible in general, except in locations marked by the is{} statement. is{} must not contain anything between the curly braces.
  • Using nis{} indicates that the program can be interrupted at any location, except between the statements contained between the curly braces.

After refreshes have been set (see Setting up a maintenance operation) and enabled (see Enabling and disabling maintenance operations), the program can be interrupted at any location. To mark the non-interruptible locations, you can use either nis{} or is{}.

Note that a program can only contain either is{} or nis{} statements; trying to mix both types will result in a compiler error.

We strongly recommend to use only is{} statements, as nis{} is not compatible with sequencer-based maintenance operations. Furthermore, nis{} is deprecated and support for it will be removed from a future version.

Limitations:

  • One program cannot contain both is{} and nis{} statements.
  • nis{} sequences cannot begin with a for statement, although they may contain for loops in any location after the first statement.
  • nis{} cannot be used when sequencer-based maintenance operations are used, that is, programs containing nis{} cannot be run on pins for which interruptCtrl=SEQ has been specified. (See Maintenance operations for details.)

Syntax

is{}
nis{}

Examples

Example 1

for (z=0; z<zMax; z+=1)
{
  for (x=0; x<xMax; x+=1)
  {
    for (y=0; y<yMax; y+=burstLength)
    {
      WriteTransaction (0, x, y, z));
      is {}    /* device maintenance insertion point */
    }
  }
}

Example 2

main ()
{
  // write device
  for (rowAddr=0 ; rowAddr<rowMax; rowAddr+=1)
  {
     // no maintenance operation allowed during full device write
     nis {
            nop(); // Note the nis body cannot start with a for loop
            for (colAddr=0 ; colAddr<colMax ; colAddr+=1)
            {
               write (rowAddr, colAddr, data);
            }
         }
  }
  
  // read device
  for (rowAddr=0 ; rowAddr<rowMax; rowAddr+=1)
  {
     // no maintenance operation allowed during burst read
     // maintenance operation can occur in between bursts
     for (colAddr=0 ; colAddr<colMax ; colAddr+=burstLength)
     {
        nis {
               read_burst (rowAddr, colAddr, data);
            }
     }
  }
}
