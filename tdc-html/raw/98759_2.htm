SSTR? - (Source Synchronous Testing: Result query)

The SSTR? query returns the final or intermediate results of a global buffer channel for source synchronous testing. It can either return a global PASS/FAIL result or the accumulated (over all shots) values per edge or cycle, depending on the result x-mode.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

SSTR? [ALL_SITES,] {GLO|INV},{(pinlist)}

returns:

SSTR {GLO|INV},{(pinlist)},{glob_res}

Or:

SSTR? {DET},{(pin)}

returns:

SSTR {DET},{(pin)},{#spec(data)}}
Parameters

ALL_SITES

This parameter causes SSTR? to return a global result for all sites. If it is omitted, the result for that site is returned that currently has the result focus.

GLO

One global result is returned for all buffers of the pin list. The result is calculated by combining first all cycle results of the individual buffers with AND, and then the combined buffer results of all buffers again with AND. PASS will be returned if the final result is 1.

This option must be selected if PASS is represented by 1 and FAIL by 0 in all buffer pins.

INV

One global result is returned for all pins of the pin list. The result is calculated in 3 steps:

  1. The cycle results of the individual channels are inverted.
  2. The inverted cycle results are combined with AND.
  3. The global results of the individual channels are again combined with AND

PASS will be returned if the final result is 1.

This option must be selected if PASS is represented by 0 and FAIL by 1 in all buffer pins. A possible application is that one global result is to be returned for one or more global buffers.

DET

The cycle results of the specified buffer pin are returned as they are stored in the buffer.

pinlist

The buffer pins whose results are to be accumulated. More than one pin can only specified for options GLO and INV.

pin

If DET is specified as the first parameter, only one pin may be specified.

glob_res

The global result that is returned for options GLO and INV. "P" signifies PASS, and "F" signifies FAIL.

#spec(data)

The binary data that is returned for option DET. It has a header which specifies the length of the data in the following format:

#Nn1n2n...nNdata_stream,

where the digit N defines the number of the digits ni (1 ≤ i ≤ N) that specify the length of data_stream in bytes.

If you record 8 results per cycle (every edge is recorded) then one bit represents one edge. If only one global result per cycle is recorded, two bits represent one cycle.

Errors

An error is generated if:

  • The specified channels have not been configured with SSAC.
  • The number of configured sites is greater than the licenses allow.

Example

The following example assumes that the global buffer pins G2 and G4 contain the total results of two source synchronous tests that were run in parallel:

> SSTR? INV,(G2)
< SSTR INV,(G2),P
> SSTR? INV,(G4)
< SSTR INV,(G4),F
> $SSTR? DET,(G4)
< SSTR DET,(G4),#9000000008,0000 0000  0001 0000  0000 0000  0000 0100  0000 0000  0000 0000  0000 0000  0000 0000
> SSTR? INV,(G2,G4)
< SSTR INV,(G2,G4),F

Note that the result granularity has been set to 8, so that every bit of the SSTR DET reply represents one receive edge. Note also that SSTR DET simply returns the buffer content. Since the global buffers must represent FAIL by 1 and PASS by 0, the reply indicates that one edge in the second cycle and one edge in the fourth cycle have failed in all shots for one of the two tests. All other edges have passed at least in one shot.
