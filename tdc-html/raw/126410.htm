Topic 126410

Opening a protocol in the protocol editor

About this task

This task describes how to load a protocol into the protocol editor.

Before you begin

Ensure the protocol to open is loaded into the test program explorer. Refer to Loading a single setup component.

Procedure

  1. Select the protocol to open in the test program explorer.
  2. Double-click that protocol.

Results

The protocol editor opens and displays the content of the protocol you have chosen.
