Using Hook Functions

Subtopics

  2. Basic Driver and Hook Function Interaction
  3. Preparing a Driver for Hook Function Use
  4. Using the Provided Hook Function Templates

For some applications, it may be necessary to run functions synchronized with certain driver actions, or to modify or enhance the driver behavior in a way which cannot be achieved by the normal configuration parameters.

To do this, the driver provides a flexible "hook function" mechanism. This mechanism allows for driver controlled execution of user-written functions (hook functions) which complement normal driver functionality.

For example, hook functions can

  • count devices or build statistics on device binning
  • link to a user-specific operator interface
  • access driver and SmarTest variables and flags
  • call SmarTest CPI functions

As described in Driver Structure, each equipment specific plug-in may have its own set of hook functions.

This chapter describes the hook function concept of the driver, how to implement user-specific hook functions, and how to configure the driver to run user-specific hook functions.
