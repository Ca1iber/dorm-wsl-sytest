Topic 37629

Calling v2b Directly

Subtopics

  1. The Parameters of v2b

Normally, the vector translation is performed with the high level tool aiv, which will call the low level tool v2b according to the PATTERNS entries of the vector configuration file. You can specify v2b parameters that do not correspond to a column of the PATTERNS section in the v2b_options column of the vector configuration file. But you can also call v2b directly. v2b processes one ASCII vector file and creates a binary vector file out of it.

v2b writes its messages to stderr. It does not create a log file. However, aiv collects the v2b messages in a file *.v2blog.

The v2b tool is located in /opt/93000/aif/v2b/bin. It is called from the command line by entering v2b with the appropriate parameters. These parameters are described in the following section.

All the parameters must be preceded by a minus sign (-). You can specify several one letter parameters that have no additional values after one minus sign (for example: -AL).
