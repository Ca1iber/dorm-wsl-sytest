CPYV - (CopY Vectors)

The CPYV (CoPY Vectors) command copies the active vectors in a specified range to another position. Source range and target range must be in the same sequencer construct.

Predependencies

CPYV can only be issued after the label to which the sequencer construct belongs has been activated for editing with the TSTL command.

Syntax

CPYV {src_vec_No}, {dst_vec_No}, {vect_length}, {(pinlist)}
Parameters

src_vec_No

The logical vector number that determines the start of the source range.

dst_vec_No

The logical vector number that determines the start of the destination range.

vect_length

The length of the vector range to be copied.

pinlist

The pins for which vectors are to be copied. If more than one pin is required, the names must be separated with a comma. The @ character can be used to modify the vectors of all configured pins.

Application

Edit command in Pattern Tool.

Errors

An error is generated if:

  • You attempt to copy to another sequencer construct.
  • The source range goes over more than one sequencer construct.
  • The destination range goes over more than one sequencer construct.
  • You specify a negative vector length.
  • You specify a negative source vector number.
  • You specify a negative destination vector number.
  • The source vector number is out of range of used vectors.
  • No label has been selected for editing.
  • One of the specified pins does not belong to the port of the selected label.
  • There is insufficient disk space (offline operation only).

Example

> SQPG? all,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,9,,,(@)
< SQPG 3,RPTV,6,5,,(@)
< SQPG 4,STOP,,,,(@)
> $VECD? PARA,SM,504,24,(S0_1)
< VECD PARA,SM,504,24,(S0_1),
  0000 0001  0000 0001  0000 0001  0000 0001  0000 0001  0000 0011  0000 0001  0000 0001
  0000 0001  0000 0000  0000 0000  0000 0000  0000 0000  0000 0000  0000 0000  0000 0000
  0000 0000  0000 0000  0000 0000  0000 0001  0000 0011  0000 0001  0000 0000  0000 0000

The first three active vectors of the RPTV instruction (with the logical vector numbers 9 to 11) are set to 0 for pin S0_1. Now activate the label for editing and copy vectors 12 to 14 to position 9 for S0_1:

> TSTL "test_1",(@)
> CPYV 12,9,3,(S0_1)

Display the result:

> $VECD? PARA,SM,504,24,(S0_1)
< VECD PARA,SM,504,24,(S0_1),

  0000 0001  0000 0000  0000 0000  0000 0000  0000 0000  0000 0000  0000 0000  0000 0000
  0000 0001  0000 0011  0000 0001  0000 0001  0000 0011  0000 0001  0000 0000  0000 0000
