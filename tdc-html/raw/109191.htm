4. Build the project to get the universal test method library

After the universal test method is created, you can create the universal test method library by building the test method.

Procedure

  1. In the Project Explorer, right-click the project Utmmethod and select Build Project from the shortcut menu.
  2. Check the Console view to see whether there is any error occurred.
