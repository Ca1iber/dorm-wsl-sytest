Topic 119519

Settings for read only devices

Automatically manage read only projects

  • When you start or change to a read only device, the device is imported into the workspace as a local project with accessible settings but the original device content is read only.
  • If you are using a read only device and change to a different device, the local project created for the read only device will be deleted from the workspace and the original read only device will remain unchanged.
  • If you clear this option, the importing of read only projects is not supported.
