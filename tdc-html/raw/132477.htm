TMU_RESULTS.shot()

Specifies the shot to retrieve the results.

Syntax

virtual TMU_RESULTS& shot(UINT32 index);
Parameter

I/O

Parameter

Description

I

index

The shot number

Return value

A reference to the TMU_RESULTS object is returned.

Note The term "shot" means the execution of a functional test (pattern or pattern burst) in the context of TMU measurements.

Functional changes

  1. Introduced in SmarTest 7.1.3
