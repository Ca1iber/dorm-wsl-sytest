Topic 351412

Communication flow for YUSHAN handlers

YUSHAN handlers have the following dedicated communication flows in testing.

For other communication flows, see other topics under GPIB communication flow for Advantest handlers.

Message from driver Message from handler Description

DVID?

 

The driver asks for the ID of the device under test from the handler.

 

DVID ddd

The handler returns the ID of the tested device.

For example, DVID 001, in which 001 is the device ID of the tested device.

TLOOP?

 

The driver asks for the number of temperature set points.

 

TLOOP ddd

The handler returns the number of temperature set points.

For example, TLOOP 4, in which 4 is the amount of temperature set points.

TSSET?

 

The driver asks for the test sequence setting (temperature sequence and subloop).

 

TSSETn, ±dd, c...

The handler returns the sequence setting.

Example:

The number in the TLOOP 3 message indicates that there are three sets of temperature in Celsius for cycle temperature testing.

TSSET1,-40,3,2,110,5,3,25,4

The first set is 1,40,3.

  • 1 is the first order number, -40 is the temperature, and 3 is the subloop.

The second set is 2,110,5.

  • 2 is the second order number, 110 is the temperature, and 5 is the subloop.

The third set is 3,25,4.

  • 3 is the third order number, 25 is the temperature, and 4 is the subloop.
CTRLSEL d The driver sets the control mode of Time Control Unit (TCU).
d can be one of the following sensors:
  • NORM: TCU Head RTD.
  • XD (XDiode): The NCT218 implemented on the load board.
  • XA (XAnalog): 4 V analog input.
XANALOGMAP? The driver asks for the parameters of slope and offset of Ext. Analog linear map function.
XANALOGMAP ±ddd.d, ±ddd.d The handler returns the parameters of slope and offset of Ext. Analog linear map function.

For example, XANALOGMAP 82, -204, in which the first parameter 82 is the Ext. Analog slope value of the linear map function; the second parameter -204 is Ext. Analog offset value of the linear map function.
TCUALMCLEAR The driver asks to clear the alarm of Temperature Control Unit.
VERSION? The driver asks for the information of the handler about Company Name, Machine Model, Machine ID, Software Revision.
A,B,C,D The handler returns the information.

A,B,C,D:

  • A stands for Company Name.
  • B stands for Machine Model.
  • C stands for Machine ID.
  • D stands for Software Revision.

For example, ADVANTEST,M4171,ATI2,Rev 2.01P4
2D barcode:
CCD d? The driver asks for the barcode information from devices.
d? is the requested block number:
  • 1: Request for the barcode information on DUT No.1 to 8.
  • 2: Request for the barcode information on DUT No.9 to 16.
CCD n1,barcode;n2, ,barcode29;...;n8, barcode8; The handler returns barcodes:

  • n1 = DUT No.x

    barcode1 = Barcode of DUT No. x

  • n2 = DUT No.n2

    barcode2 = Barcode of DUT No. x+1

    ...

  • n8 = DUT No.n8

    barcode8 = Barcode of DUT No. x + 7

Note This command is available only when the handler is under test.

Functional changes

  1. SmarTest 7.6,0: CTRLSEL, XANALOGMAP, TCUALMCLEAR, IDN, and CCD for YUSHAN handlers.
