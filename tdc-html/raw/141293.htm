DPS_AUX_PIN_TASK.selectISensorSetThresholds()

The DPS_AUX_PIN_TASK.selectISensorSetThresholds() member function selects the current sensor and sets the low and high thresholds.

The input signals to the DPS128/64 comparator pair can be either from the current sensor or the voltage sensor.

The digital closed loop control of DC Scale XPS256 card simultaneously samples voltage and current. The input signals to the XPS256 comparators can be from the voltage sensor, from the current sensor or from both sensors. Both the voltage comparators and the current comparators are active if both thresholds are set.

Syntax

DPS_AUX_PIN_TASK & selectISensorSetThresholds (const DOUBLE& low, const DOUBLE& high)
Parameters
Parameter Description
low Low current threshold
high High current threshold
Return value
A reference to the corresponding DPS_AUX_PIN_TASK object.

Example

The example below shows the setting of the low and high current thresholds and the activation of the surge tracker function.

DPS_AUX_TASK auxTask;
  
ON_FIRST_INVOCATION_BEGIN();

    //
    // Set the current thresholds to -1 mA/1 mA and switch on surge tracker
    //
    auxTask.pin("dps1")
        .selectISensorSetThresholds(-1 mA, 1 mA)
        .setMode(TM::SURGE_TRACKER);

    auxTask.execute();

ON_FIRST_INVOCATION_END();

For an extended example see DPS_AUX_TASK.
