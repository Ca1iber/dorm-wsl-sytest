Topic 119694

Special requirements for freezing the tracker

Suppose that all of the following conditions are true:

  • An IO pin is used as a TT pin.
  • Transition tracking is enabled.
  • The pin switches between compare and drive mode.

Then the tracker must be temporarily disabled ("frozen") while the pin is running in drive mode (see Tracking bi-directional pins).

This switch is only possible if both the following requirements are satisfied:

  • Every compare waveform activates the tracker (by specifying 1 in the window action string).
  • Every drive waveform inactivates it (by 0 in the window action string). This also holds for a dummy waveform which is inserted to give the DUT time to switch into the opposite operation mode.

Example

PINS IO0 IO1
TTMODE X4
#compare waveform
  0 "1......." "1......."  "HLHL" "1..." Hlhl
#drive waveform
  1 "010101.." "0......."  "...." "0..." S1RR
#dummy waveform
  2 "1......." "1......."  "...." "0..." Tttt

Note that the dummy waveform is also treated as a drive waveform.

Functional changes

  1. Introduced in SmarTest 7.0.1
