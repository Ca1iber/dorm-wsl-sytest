Existing test programs require some modifications to execute on SmarTest release 7.1.x due to hardware and software differences. The SmarTest Program Migration Framework intends to simplify the test program migration process.

The V93000 SmarTest Program Migration Framework features a three-step process: scan, resolution and execution. This eases the access of the single conversion tools and supports access to the online help.Using this framework you will be able to:

  • Detect errors and differences between SmarTest 6.5 and 7.x and identify required migration steps.
  • Migrate test programs from SmarTest 6.5 to 7.1 directly within the framework.
  • Identify where manual input is required.
    Note You need a license to execute the migration tools from within SmarTest's graphical user interface.
