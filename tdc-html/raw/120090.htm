Topic 120090

SMC_FUNCTIONAL_TEST()

Executes a functional test that will pass only if all device output data matches the expected data, else this test will fail. This API allows parallel upload of data from the tester under control of SmartCalc.

The primaries or, if defined by measurement setup APIs, the specified measurement setup is activated before starting the sequencer.

Execute the FLUSH API before the SMC_FUNCTIONAL_TEST() if you need to activate:

  • the primary analog set
  • a routing set

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h

Syntax

void SMC_FUNCTIONAL_TEST();
void SMC_FUNCTIONAL_TEST(const STRING & exec_context);
Parameter

I/O

Parameter

Description

I

exec_context

Name of an execution context. The ports of the context must be included in the current start label (which must be a multiport burst). For more information on execution contexts see Using execution contexts .

The context must have been defined on the firmware level (with the SQEC command), or as a SEQUENCER_CONTEXT_ITEM object. In the latter case this object must have been included in a SEQUENCER_CONTEXT object, and must also have been activated on the firmware level with the apply() function of this SEQUENCER_CONTEXT object. If the context has been defined as a SEQUENCER_CONTEXT_ITEM object, you must use the name specified for its name parameter.

Return value

There is no return value.

Note The result can be retrieved by GET_FUNCTIONAL_RESULT().

Example

In the following example the result of PIN1 will be retrieved and stored in the result variable after executing SMC_FUNCTIONAL_TEST().

Boolean result;
SMC_FUNCTIONAL_TEST();
result = GET_FUNCTIONAL_RESULT("PIN1");
