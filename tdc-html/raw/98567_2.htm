DPPC - (Define Per Pin subroutine Configuration)

The DPPC (Define Per Pin subroutine Configuration) command defines the configuration for a PPSS label, i.e. start and length of a subroutine in sequencer memory or start and length of a subroutine in vector memory.

DPPC

DPPC {name}, {parameter}, [value], {(pinlist)}

DPPC?

DPPC? {name}, {parameter}, {(pinlist)}

returns:

DPPC {name}, {parameter}, [value], {(pinlist)}

Parameters

name

Name of the Pin-Per Sequencer Subroutine label. For the query, you can enter ALL to return all PPSS labels.

parameter

There are various parameters for the PPSS labels:

SMSTART

Defines the start of a PPSS label in the sequencer memory (SM).

SMLEN

Defines the length of a PPSS label in SM.

VMSTART

Defines the start of a PPSS label in the vector memory (VM).

VMLEN

Defines the length of a PPSS label in VM.

RELOC

specifies that the subroutine is relocatable.

MWAIT

Used internally.

MAXLEN

Used internally.

ALL

In the query, to display information about all parameters.

value

Value for the parameter specified as parameter.

pinlist

Pins for which a per-pin subroutine is valid.

Application

Memory Tests used by the APG pattern translator.

Errors

An error is generated if:

  • The length in the sequencer memory (SM) is not >=3.
  • The syntax is wrong (address <0, length <=0).
  • The addresses are outside the PPSQ area defined by DMAS.

Functional changes

  1. Introduced before SmarTest 6.3.2
