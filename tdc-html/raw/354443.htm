XPS256 programming - AWG

An XPS256 pin can be used as an arbitrary waveform generator (AWG), supporting both voltage and current waveforms. The AWG functionality is controlled by pattern sequencer DC events.

Refer to XPS256 arbitrary waveform generator (AWG) for a detailed description of the AWG.

Note This topic of the XPS256 programming overview covers only the AWG specific settings. For common settings, refer to XPS256 programming - Force and clamp currents and XPS256 programming - Force and clamp voltages.

Maximum sample frequency

For XPS256, the maximum frequency of the pattern sequencer is 50 MHz and 32 vectors are required per sample. This results in a maximum sample frequency of 1.5625 MHz. See also Minimum period / maximum frequency of the sequencer.

SmartRDI overview

The basic functionality of an XPS256 pin that is used as AWG can be controlled by the dc() API of SmartRDI. The basic AWG setup is supported in the code‑based mode and the AWG core functionality is supported only in the pattern‑based mode. For more information refer to Setting up DC Scale pins with SmartRDI and the related member functions of the dc() API.

SmartRDI supports also setting up DC resources like a real AWG. For more information refer to Using DC resource as AWG with SmartRDI.

API overview

The basic setup of the AWG must be programmed by standard APIs for an XPS256 pin in PMU operating mode or by the Equation based level setup or API DPS_TASK for an XPS256 pin in DPS operating mode.

The API ANALOG_WAVEFORM provides the functionality to define and modify waveform objects.

The AWG core functionality is controlled by force events in a pattern. For more information refer to DC events.

Application note

DC events in reused pattern
For a minimized test time we recommend, not to reuse pattern with DC events that are to be applied for different XPS256 ranges. The recommendation applies to pattern that are manually created using the related test method APIs but not to the automatically created SmartRDI pattern.

The XPS256 channels feature several force ranges. The pattern data of related DC events must be reloaded in case the containing pattern is reused for another range. This may significantly increase the test time.

The recommendation applies to all DC events that change the force- or clamp value or range or the measurement range.
