SPMU_PIN_TASK.forceDropWarn()

Set the warning threshold for the force line.

The voltage drop is measured from the high force pogo pin (P#) to the high sense pogo pin (PS#). The measured voltage drop depends on the actual current and the impedance of the connection to the DUT. The continuously measured voltage drop is compared against the warning threshold, and should pin exceeds the programmed limit, an alarm flag is raised.

This function is similar to SPMU_PIN_TASK.forceDropMax(), which sets the force voltage drop for disconnect.

This member function is supported only for the DC Scale XPS256 card.

Syntax

SPMU_PIN_TASK & forceDropWarn(DOUBLE forceDropWarn);
Parameter
Parameter Description
forceDropWarn

The warning threshold in millivolt (mV) to be set.

A positive voltage has to be set regardless of the polarity of the actual or programmed current.

For the valid range refer to Voltage drop protection / measurement in XPS256 other performance characteristics
Return value
A reference to the SPMU_PIN_TASK object.
