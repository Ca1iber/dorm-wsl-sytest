Field references

Referencing another field is allowed depending on the hierarchy level of a function.

This requires that the value of the referenced field can be calculated without knowing the value of the field containing the reference (no cyclic references).

A field is generally referenced by the construct @<field>. The field identifier can be scoped by frames and Pin Role names to reference fields which are not in the same frame or Pin Role.

Functional changes

  1. Introduced in SmarTest 7.1.0
