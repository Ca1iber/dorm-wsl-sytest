NODV? - (Number Of Displayable Vectors)

The NODV? (Number Of Displayable Vectors) query returns the number of active vectors of the selected label. It can only be issued after a label has been activated for editing with the TSTL command.

NODV? is used to:

  • Calculate the percentage/relative position of the test vectors displayed in the Vector Setup as compared to the total number displayable for the label.
  • Query the number of vectors that are displayable in one label. The number is used to set the size of the scroll bar etc. in the Vector Setup showing the relative size of the vectors that are displayed and the length of the possible displayable vectors.

Syntax

NODV?

returns: 

NODV {num_vec}

Parameters

num_vec

returns the number of active vectors.

Application

Download command in Vector Setup, see Vector Setup Commands.

Errors

An error is generated if no label has been activated for editing.

Example

> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,9,,,(@)
< SQPG 3,RPTV,6,5,,(@)
< SQPG 4,STOP,,,,(@)
> TSTL "test_1",(@)
> NODV?
< NODV 15

Functional changes

  1. Introduced before SmarTest 6.3.2
