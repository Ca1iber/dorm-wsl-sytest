GetTechPath

This procedure lets you determine the currently used technology path (the path where your technology files are stored).

Syntax

VOID GetTechPath (
    CHAR     *tech_path);

Parameters

On return the character array tech_path contains the actual technology path. The array should be defined of length DM_MAX_DEVICE.

Example

CHAR tech_path[DM_MAX_DEVICE];
GetTechPath(tech_path);
cout << "path is " << tech_path << endl;

Functional changes

  1. Introduced before SmarTest 6.3.2
