GeneralPMU

This is a general test method for performing DC measurements with the Pin PMU, DC Scale pin in PPMU mode and board ADC.

You can force current to the DUT and measure the voltage, or you can force voltage to the DUT and measure the current. The actual operating mode of the PMU is dependent on the external load as well as the programmed parameters.

The PPMU clamp is ON during PPMU relay switching. When the PPMU relay is ON, the clamp is turned OFF and kept OFF during the PPMU measurement. For details of clamp sequence, refer to PPMU voltage clamp on Pin Scale systems.

This test method supports test table. But you need to enter the test names manually in the parameter. You can use both test table and testflow limits in a testflow. The test table has higher priority than testflow limits. If a test name used in the test flow is defined in both test table and testflow limits, the value defined in the test table will be used.

Dependencies

  • Typically, the device should be kept in a stable condition by applying a suitable waveform.
  • The direction of the current is specified by the sign of the forced value (positive current flows into the DUT pin, negative current flows out of the DUT pin).
Parameters of measuring with PPMU

UsePPMU

string

Use PPMU to do the measurement or not. Its value can be YES or NO. The following parameters in this table are only available when its value is YES.

UsePPMU.pinlist

PinString

The list of pins or pin groups to be measured with PPMU. The pins or pin groups are separated with comma.

UsePPMU.forceMode

string

The force mode. Its value can be:

VOLT: force voltage

CURR: force current

To specify different settings for different pins or pin groups, separate them with comma.

UsePPMU.forceValue

string

The value of voltage force in [mV] or current force in [uA]. Default is "3800".

To specify different settings for different pins or pin groups, separate them with comma.

UsePPMU.measureMode

string

The measurement mode. Its value can be:

PAR: parallel test

SER: serial test

To specify different settings for different pins or pin groups, separate them with comma.

UsePPMU.precharge

string

Precharge before forcing current/voltage or not. It can be:

ON: enable precharge

OFF: disable precharge

To specify different settings for different pins or pin groups, separate them with comma.

UsePPMU.prechargeVoltage_mV

string

The precharge voltage in [mV]. Default is "0.0".

To specify different settings for different pins or pin groups, separate them with comma.

UsePPMU.relaySwitchMode

string

The relay switching mode. Its value can be:

DEFAULT(BBM): open AC relay and PMU relay, then open ac relay and close PMU relay in parallel.

MBB: close PPMU relay and then open AC relay

PARALLEL: open AC relay and close PPMU relay in parallel

To specify different settings for different pins or pin groups, separate them with comma.

UsePPMU.settlingTime_ms

string

The additional settling time to system in [ms]. Default is "0".

To specify different settings for different pins or pin groups, separate them with comma.

UsePPMU.termination

string

Use termination or not. Its value can be:

ON: use termination

OFF: do not use termination

To specify different settings for different pins or pin groups, separate them with comma.

UsePPMU.testName

string

The test names to be used as limit. You can:

  • Use the test names defined in the test table or testflow limits. Type in the test names manually. Make sure these test names are in the Test name column of the test table (Refer to Structure of a TMLimits CSV file) or in Test Name column of Tests page of Flow Data Editor.
  • Define new test names. After that you need to add the defined test names (limits) to the test suite. (Refer to Adding a limit in the Properties view and Adding a limit on the Tests page.)

To specify different settings for different pins or pin groups, separate them with commas.

Common parameters for all instruments

testerState

string

Tester state for the measurement. Its value can be:

CONNECTED - connects the test system before executing the test method; if the test system is already connected (connect flag set) the connect sequence is not executed.

DISCONNECTED - disconnects the test system before executing the test method if the test system is already disconnected (connect flag not set) the disconnect sequence is not executed.

UNCHANGED - leaves the test system state (CONNECTED or DISCONNECTED) unchanged from its previous setting, when the test is executed. This is the fastest option.

 

preFunction

string

Execute the pattern to the specified vector/cycle or not. It is only available when testerState is CONNECTED. Its value can be:

NO: do not execute the functional test

ALL: execute the whole pattern

ToStopVEC: execute the pattern and stop at the specified vector

ToStopCYC: execute the pattern and stop at the specified cycle

stopVec

int

Number of vector to stop the pattern. It is only available when preFunction is ToStopVEC. It does not support multi-port.

stopCyc

string

Number of cycle to stop the pattern. It is only available when preFunction is ToStopVEC. It supports multi-port. For multi-port pattern, its value is in the format of cycle_number@port_name.

output

string

Controls how to output the per pin test result. It can be:

  • None: Do not output the per pin result.
  • ReportUI: Output all the per pin result to the report window.

ShowFailOnly: Only outputs the failed pin result to the report window.

Limits

If you define new test names in the parameter testName, you need to add limits to the test suite with the same test name. (Refer to Adding a limit in the Properties view and Adding a limit on the Tests page.)

Implementation pseudo code

IF tester state is CONNECTED THEN
  connect to DUT
  execute a functional test to specified vector/cycle
ELSEIF tester state is DISCONNECTED THEN
  disconnect from DUT
ELSEIF tester state is UNCHANGED THEN
  keep tester state unchanged
ENDIF
IF PPMU current measurement THEN
  setup PPMU current measurement conditions
ENDIF
IF PPMU voltage measurement THEN
  setup PPMU voltage measurement conditions
ENDIF
IF SPMU current measurement THEN
  setup SPMU current measurement conditions
ENDIF
IF SPMU voltage measurement THEN
  setup SPMU voltage measurement conditions
ENDIF
IF DCScale SIG mode current measurement THEN
  setup the measurement conditions
ENDIF
IF DCScale SIG mode voltage measurement THEN
  setup the measurement conditions
ENDIF
IF BoardADC voltage measurement THEN
  setup the measurement conditions
ENDIF
execute PPMU, SPMU, DCScale SIG pin and BoardADC measurement in parallel

retrieve measurement results with PPMU, SPMU, DCScale SIG pin and BoardADC
set sequencer state OFF
Judge and log the test results
