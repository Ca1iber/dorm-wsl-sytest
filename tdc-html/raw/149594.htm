wait()

This function with a parameter TA::WAIT_DCDGT specifies a waiting interval that must pass when a digitizer action is executed.

The digitizer can be PPMU or BADC in a capMode(TA::TRIG) mode. This wait(TA::WAIT_DCDGT) has the similar capability as wait(TA::WAIT_DCDGT) for a real digitizer.

Syntax

wait(TA::WAIT_DCDGT)
List of parameters

Parameter

Description

TA::WAIT_DCDGT

Waif for DC-DGT to finish.

Example

RDI_BEGIN( ); 
     rdi.port("pt").dc().pin("pin").samples(1024).capMode(TA::TRIG)...execute(); 
     rdi.port("pt").label(A).execute();  // Pattern running while sampling.
     rdi.port("pt").wait(TA::WAIT_DCDGT);
     rdi. port("pt").func().label(B).execute(); // Pattern running after sampling.
RDI_END();
