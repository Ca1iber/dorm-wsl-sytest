DISABLE_ERROR_MESSAGE

This API disables generation of error messages to the report window. Note that the generation of error messages to the report window is enabled by default.

Syntax

DISABLE_ERROR_MESSAGE();

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

List of parameters

There are no parameters.

Example

DISABLE_ERROR_MESSAGE();

The DISABLE_ERROR_MESSAGE API disables error message generation.

Related information

ENABLE_ERROR_MESSAGE

Functional changes

  1. Introduced before SmarTest 6.3.2
