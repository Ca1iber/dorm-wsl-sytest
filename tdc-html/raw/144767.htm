getPriAnaSet()

Retrieves the primary analog set.

Syntax

string getPriAnaSet();

List of parameters

There are no parameters.

Note DO NOT use this function in SMC_backgroundProcessing(). See Using hidden upload with SmartRDI

Example

string pAnalogSetName = rdi.getPriAnalogset();

Functional changes

  1. Introduced in SmartRDI 2.1.0
