DIGITAL_OFFSET_SEARCH_TASK.uploadResult()

Triggers the DIGITAL_OFFSET_SEARCH_PINS instance to upload timing/level offset search results (the offsets for the first and last passing values of the pass area representing the fail-to-pass and pass-to-fail transitions respectively, or the offsets for the middle of the pass area) found in the latest transition search from the tester into the system controller.

  • To read out the offset for the middle of the pass area, use DIGITAL_OFFSET_SEARCH_PINS.getOffset().
  • To read out the offsets for the boundaries (the first and last passing values of the pass area), use DIGITAL_OFFSET_SEARCH_PINS.getLatestLBTransitionOffset(), and/or DIGITAL_OFFSET_SEARCH_PINS.getLatestRBTransitionOffset().

If you retrieve the offset on multiple pins and those pins have different settings, the exception TESTMETHOD_API::AmbiguityException will be issued.

Syntax

void uploadResult(SetSelector& selector, RESOURCE_TYPE resource) throws TMException;
Parameters

Parameter

Description

selector

It can be:

  • A TimingSetSelector object defined with TimingSetSelector, to select the timing sets for use.
  • A LevelSetSelector object defined with LevelSetSelector, to select the level sets for use.

resource

A timing or level resource whose offset you want to upload. See the following table for the resource types.

Choose a timing or level resource for the timing or level selector respectively. Otherwise, an exception will be thrown.
Available options of parameter: <resource>

Option

Description

DIGITAL_OFFSET_SEARCH::RECEIVE

Receive edges

DIGITAL_OFFSET_SEARCH::DRIVE

Drive edges which contain both FAST_DRIVE and SLOW_DRIVE

DIGITAL_OFFSET_SEARCH::FAST_DRIVE

Fast drive edges

DIGITAL_OFFSET_SEARCH::SLOW_DRIVE

Slow drive edges

DIGITAL_OFFSET_SEARCH::ALL_EDGES

All edges containing FAST_DRIVE, SLOW_DRIVE, and RECEIVE

DIGITAL_OFFSET_SEARCH::VIH

High driver levels

DIGITAL_OFFSET_SEARCH::VIL

Low driver levels

DIGITAL_OFFSET_SEARCH::VIOFFSET

The search of the offsets for VIH and VIL at the same time

DIGITAL_OFFSET_SEARCH::VTH

Receiver thresholds

DIGITAL_OFFSET_SEARCH::VOH

High receiver levels

DIGITAL_OFFSET_SEARCH::VOL

Low receiver levels

DIGITAL_OFFSET_SEARCH::VOOFFSET

The search of the offsets for VOH and VOL at the same time

DIGITAL_OFFSET_SEARCH::VISWING

Driver swings

DIGITAL_OFFSET_SEARCH::VOSWING

Receiver swings

Return value

There is no return value.

Example

DIGITAL_OFFSET_SEARCH_TASK dos;
DIGITAL_OFFSET_SEARCH::LevelSetSelector dest(DIGITAL_OFFSET_SEARCH::ALL);
dos.uploadResult(dest, DIGITAL_OFFSET_SEARCH::VIH);
