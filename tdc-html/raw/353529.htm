Uninstalling SmarTest products

To uninstall a product use the 'uninstall' command together with the product name and the exact version.

About this task

If you want to get an overview which products and product versions are installed use the show command. When you know which version you want to uninstall, enter the appropriate uninstall command similar to the one in the following example:

Procedure

  1. Optional: To get an overview of the products and versions installed, use the show command:

    /opt/ate/smart_install_3/smart-install-3 show

    The following type of list is displayed:

    Installed products (12):
FPGA (1):
        4.1.10r (release)
SmarTest (2):
        7.5.4.0 (release)
        8.3.3.1 (release)
SmarTestDocumentation (1):
        8.3.3 (release)
SmarTestDocumentation7x (1):
        7.5.4 (release)
SmartCI_Client (1):
        8.3.3.0 (release)
SmartInstall (1):
        3.0.4.0 (release)
TCCT (1):
        1.9.7 (release)
TP360 (2):
        4.2.5.3 (release)
        4.3.3 (release)
TP360_3x (1):
        3.10.4 (release)
TestCellAccess (1):
        8.3.3.0 (release)
  2. To uninstall a product use the uninstall command with the product name and the exact version:

    For example, to uninstall SmarTest version 8.3.3.0, enter the command:

    /opt/ate/smart_install_3/smart-install-3 uninstall smartest 8.3.3.0

Results

You have learned how to use the smart-install-3 tool to uninstall SmarTest products.

Functional changes

  1. Introduced in SmarTest 8.4.3
