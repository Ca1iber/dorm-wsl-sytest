UserProcedureStartEventType

An event of this type is logged when a user procedure is called.

Attributes

  • SiteIdAttrType

    Holds the ID of the site for which the user procedure was called.

  • TimeStampAttrType

    Holds the time at which the execution of the user procedure was started.

Functional changes

  1. Introduced before SmarTest 6.3.2
