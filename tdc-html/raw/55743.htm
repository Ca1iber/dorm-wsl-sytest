Address instructions

The STVA instruction determines the start address for the vectors of the label. This is explained in detail in Sequencer program and vector areas. On the older systems, the start address is always specified as param_1 of the SQPG command. On a 7.x system, where the vector areas are port specific, the following rules apply:

  • If all patterns of the vector setup belong to the default port, or if a pattern master file is used, SmarTest stores and displays the address as param_1.
  • If there are patterns for more than one port, and the vector setup is contained in a single file, SmarTest stores and displays the address as param_2.

If you set the address with SQPG, you should specify it in param_2, even if all patterns belong to the default port.

Example

If the vector setup contains only patterns for the default port, the reply of an SQPG? query looks as follows:

> SQPG? "test",(@)
< SQPG 5,STVA,112,,,(@)
< SQPG 6,STSA,,,,(@)
< SQPG 7,GENV,9,,,(@)
< SQPG 8,STOP,,,,(@)

The STVA address is returned as param_1. However, after you have added a pattern for a user defined port to the setup, it will be returned as param_2:

> SQPG? "test",(@)
< SQPG 5,STVA,,112,,(@)
< SQPG 6,STSA,,,,(@)
< SQPG 7,GENV,9,,,(@)
< SQPG 8,STOP,,,,(@)

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.1: The vector areas are now port specific.
