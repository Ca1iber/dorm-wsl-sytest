Wafer Results Record (WRR)

The Wafer Results Record contains the result information related to each wafer tested. The WRR and the WIR bracket all the stored information pertaining to one tested wafer. This record is used only when testing at wafer probe. A WIR/WRR pair will have the same HEAD_NUM and SITE_GRP values.

Location in the file:

The Wafer Results Record can be located anywhere in the data stream after the corresponding WIR. This record is sent after testing each wafer.

WRR field name

Field description

Value

Data definition

HEAD_NUM
  • Test head number
  • One-byte unsigned integer
  • Value = 1
  • Hard-coded value

SITE_GRP
  • Site group number
  • One-byte unsigned integer
  • Value = 255
  • Hard-coded value

FINISH_T
  • Date and time last part was tested
  • Whether the time is local or UTC depends on the setting of the useUTCTime option in formatter.stdf.main.conf.
  • Four-byte unsigned integer
  • Hard-coded value

PART_CNT
  • Number of parts tested
  • Four-byte unsigned integer
  • EDL Event:

    BinReachedEventType

RTST_CNT
  • Number of parts retested
  • 4,294,967,295 = missing or invalid data
  • Hard-coded value

ABRT_CNT
  • Number of aborts during testing
  • 4,294,967,295 = missing or invalid data
  • Hard-coded value

GOOD_CNT
  • Number of good parts tested
  • Four-byte unsigned integer
  • 4,294,967,295 = missing or invalid data
  • EDL Event:

    BinReachedEventType

  • EDL Attribute:

    IsGoodBin

FUNC_CNT
  • Number of functional parts tested
  • 4,294,967,295 = missing or invalid data
  • Hard-coded value

WAFER_ID
  • Wafer ID
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • Length byte = 0 if missing or invalid data
  • Application model variable1):

    WAFER_ID

  • Data source can also be a constant value in the configuration file or a system environment variable.

FABWF_ID
  • Fab wafer ID
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • Length byte = 0 if missing or invalid data
  • Application model variable1):

    FABWF_ID

  • Data source can also be a constant value in the configuration file or a system environment variable.

FRAME_ID
  • Wafer frame ID
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • Length byte = 0 if missing or invalid data
  • Application model variable1):

    FRAME_ID

  • Data source can also be a constant value in the configuration file or a system environment variable.

MASK_ID
  • Wafer mask ID
  • Variable length character string
  • First byte is unsigned count of bytes to follow
  • Maximum 255 bytes
  • Length byte = 0 if missing or invalid data
  • Application model variable1):

    MASK_ID

  • Data source can also be a constant value in the configuration file or a system environment variable.

    (user defined)

  • Maximum 255 bytes

  • Application model variable1):

    USR_DESC

    (exec defined)

  • Application model variable1):
