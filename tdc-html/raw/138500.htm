create_mtp

The create_mtp command for the SmarTest Program Manager MCM (STPM MCM) control file creates an MTP (master test program) from the STPs (source test programs) according to the settings of the MTPT (mapping template).

When STPM MCM executes the command, it combines the STPs specified in the MTPT into one MTP and stores the generated files in the device directory. Any existing MTP created earlier in the same location is overwritten.

To integrate the STPs, STPM MCM iterates over all rows in the Test mapping table and integrates the STP specified in the row into the MTP. Elements of the STP (such as test suites) are integrated according to the settings in the relevant mapping tables.

Note The required device directory is created with generate_device_dir, but this needs to happen only once. When this directory exists, create_mtp can be executed as often as desired.

Syntax

create_mtp(
[ stp_missing_primaries = '<behavior>']
)

Parameter

stp_missing_primaries

What STPM MCM is to do when an STP uses missing primaries.

<behavior> can be any of these:

  • 'error': An error is generated and the creation of the MTP is stopped.
  • 'warning': A warning is generated but the MTP is created. The test suite from the STP is integrated without change; STPM MCM leaves the references to the missing primaries unchanged.
  • 'bypass': STPM behaves differently depending on whether the test suite is bypassed:

    If the test suite is bypassed, STPM behaves as for 'warning'.

    If the test suite is not bypassed, STPM behaves as for 'error'.

STPM considers a test suite bypassed if the local bypass flag of the test suite is set, if the bypass flag is set for it in the MTPT test flag table, or if it is part of a group for which the bypass flag has been set.

This is an optional parameter. If it is not specified, 'bypass' is used.

(The information about the MTPT and device directory to use comes from the mtp_template_dir and mtp_device_testflowsettings in the control file.)

Example

mtp_template_dir    = "/prj/MTPT"
mtp_device_testflow = "/prj/MTP/testflow/rel.tf"
create_mtp(stp_missing_primaries = 'warning')

This example assumes that the device directory (/prj/MTP/) has been created at some earlier time with the generate_device_dir command.
