Topic 118467

Hardware view preference page

You can change the following preferences on the Advantest V93000 > Hardware > Hardware View preference page.

Option

Description

Continuously refresh with an interval delay

Use this option to refresh the hardware information in the Hardware view continuously with a specified interval delay.

Refresh Delay

Specify the interval delay with which the hardware information in the Hardware view is refreshed.

Block Diagram Follows the Site in Focus

Use this option to link the hardware information in the Hardware view always to the site in focus.
