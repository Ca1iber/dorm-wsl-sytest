TESTFLOW_EXEC_COMPLETED

This asynchronous event indicates the execution of a test flow is completed.

Dependency

The execution of testflow is made.

Parameters

I/O

Parameter

Description

O

SESSION_ID

The ID of the SmarTest session this event belongs to.

O

TIME_STAMP

The time point when this event occurs. It contains two long-type parts: SECONDS and MICROSECONDS.

O

EVENT_NAME

The event category. Here it is always EXECUTION.

O

EVENT_BODY

The event parameters. It contains the following members:

EXECUTION_STATE

The HVM event type. Here it is always TESTFLOW_EXEC_COMPLETED.

TESTFLOW_NAME

The test flow that is executed.

SITE_ID_FOR_SITES

The list of site IDs.

SITE_SETUP_FOR_SITES

The list of site setups.

PACKAGE_ID_FOR_SITES

The list of package IDs. Package ID is only a counting for device test. It is empty for wafer sort.

DIE_X_FOR_SITES

The list of dies' X coordinates. It is empty for final test.

DIE_Y_FOR_SITES

The list of dies' Y coordinates. It is empty for final test.

PASS_FAIL_FOR_SITES

The list of all sites' pass/fail results. P means pass, F means fail and X means not tested.

SOFT_BIN_FOR_SITES

The list of all sites' software bin codes. OTHERWISE is used for untested bins.

You can get the actual software bin number of OTHERWISE bin with OTHERWISE_SOFT_BIN.

HARD_BIN_FOR_SITES

The list of all sites' hardware bin codes. OTHERWISE is used for untested bins.

You can get the actual hardware bin number of OTHERWISE bin with OTHERWISE_HARD_BIN.

OTHERWISE_HARD_BIN

The hardware bin number of the OTHERWISE bin defined in the testflow.

OTHERWISE_SOFT_BIN

The software bin number of the OTHERWISE bin defined in the testflow.

This parameter is represented by ParamList whose key and value are both string type.

Related information

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.1.4: in patch 6, adds OTHERWISE_HARD_BIN and OTHERWISE_SOFT_BIN for EVENT_BODY.
