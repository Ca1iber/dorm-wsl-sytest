DIGITAL_OFFSET_SEARCH_PINS.resolutionHistogramSearch()

Defines the step width for the histogram based search.

This function is used together with DIGITAL_OFFSET_SEARCH_PINS.minStableErrorCount().

Syntax

DIGITAL_OFFSET_SEARCH_PINS& resolutionHistogramSearch(DOUBLE res);
Parameter

Parameter

Description

res

The step width for the histogram based search.

Return value

A reference to the DIGITAL_OFFSET_SEARCH_PINS object.

Related information

DIGITAL_OFFSET_SEARCH_PINS.minStableErrorCount()

Functional changes

  1. Introduced in SmarTest 7.2.1
