Wavetables

Logical Waveforms

It is no longer possible to define logical waveforms using the WFDF statement. You have to use WFDS instead. The conversion rule is similar to the WFDF firmware command.

Bidirectional edges with drive actions are converted to drive edges

Bidirectional edges with receive actions are converted to receive edges

WAVETBL "{wavetblName}"
PINS {pinlist}
WFDF 0 {a1} {a2} {a3} {a4} {a5} {a6}
     0 {a1} {a2} {a3} {a4}

Replacement:

WAVETBL "{wavetblName}"
PINS {pinlist}
WFDS 0 "{d1|r1}:{a1} {d2|r2}:{a2} {d3|r3}:{a3} {d4|r4}:{a4} {d5|r5}:{a5} {d6|r6}:{a6}"
     0 {a1} {a2} {a3} {a4}

Pure waveforms

Pure waveform definition string must no longer contain edge specifiers e1 to e6. Similar to the WFDS firmware command, you have to use d1..d6/r1..r6 instead.

Bidirectional edges with drive actions are converted to drive edges

Bidirectional edges with receive actions are converted to receive edges

WAVETBL "{wavetblName}"
PINS {pinlist}
0 "[e1:{a1}] ... [e6:{a6}]" {deviceCycleName}

Replacement:

WAVETBL "{wavetblName}"
PINS {pinlist}
0  "[{d1|r1}:{a1}] ... [{d6|r6}:{a6}]" {deviceCycleName}

Functional changes

  1. Introduced in SmarTest 6.5.4
