Topic 98882

*RST - (ReSeT)

The *RST (ReSeT) command resets the firmware and all calibration data. This causes power-up default values to be loaded in the hardware. For default values see the RSET command.

Syntax

*RST [type]

Parameters

type

not used
  • Enforces a disconnect (AC relay is open)
  • All DPS sets, except the default set, will be deleted.
  • All resources (for example objects defined with RDEF) will be deleted
  • All pin definitions (for example pins defined with DFAN) will be deleted.
  • All instruments will be deleted from the instrument registry and recreated.
  • The instrument will have its reset bit toggled.
  • The instrument will be set to its default state.

 SWR
  • All resources will be deleted
  • All pin definitions will be deleted.
  • The instrument will have its reset bit toggled.
  • The instrument will be set to its default state.

Application

Reset command.

Example

*RST

Resets the software and the hardware.

Functional changes

  1. Introduced before SmarTest 6.3.2
