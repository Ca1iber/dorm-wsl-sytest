SmartRDI: Digital channel relay control

Subtopics

  6. setOnRunTime()

SmartRDI provides the class hwRelay() and the following functions to control AC, DC and PPMU relays in digital channels:

pin(), setOn(), setOff() and execute().

Note For AVI64 pins in I/O mode, this function can be used only in the code‑based mode.

Example

RDI_BEGIN();
  rdi.hwRelay().pin("pinA").setOn("DC,AC").setOff("PPMU").execute();
  rdi.hwRelay().pin("pinB").setOff("ALL").execute();
RDI_END();

See setOn() for more information about AMUX_PPMU and AMUX_BADC relay options.
