Logging GDR records with test methods

To log GDRs and data using test methods, the appropriate calls to the test methods must be made. Refer to Test method API for logging GDRs and DTRs for details.

For complete information about these and other test methods, refer to the GENERIC_DATA_EVENT API, and the TESTSET API.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.1.4: Removed support for logging GDRs with user procedures
