Topic 118445

LBMD? - (LoopBack MoDe)

The LBMD? query returns the SmartLoop™ configuration of one or more wavetables.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Syntax

LBMD? {wvf_set|"wavetable_name"|specset_id|"multi-port_spec"|PRM}, {(pinlist)}

returns:

LBMD {wvf_set|"wavetable_name"|specset_id|"multi-port_spec"|PRM}, {lpbk_mode}, {(pinlist)}

Parameters

wvf_set

Waveform Set Number (range 1 to maximum). Enter ALL for all waveform sets. The maximum number is determined by the command WSUS, WSUS? - (Waveform Sets USed).

This option is needed by some GUIs that use this query. A SmartLoop™ test can only be defined in equation based timing.

wavetable_name

The wavetable name. Enter a string of up to 40 alphanumeric characters (upper or lower case).

specset_id

Derived as follows:

100 * equation_set_no + specset_no

multi-port_spec

To query a multi-port specification, enter the name of the specification.

PRM

The SmartLoop™ configuration of the primary wavetable(s) is returned.

lpbk_mode

 

Possible values are:

LOOP_I

The pin is enabled for resending the received data to the DUT.

LOOP_O

The pin is enabled for routing received data to the corresponding input pin.

LOOP_OFF

The pin is not configured for SmartLoop™ testing.

pinlist

The name of the pin or pins for which the SmartLoop™ configuration is to be retrieved. The symbol @ can be used to specify all configured input and IO pins. If more than one pin is to be included, the names must be separated with a comma.

Application

SmartLoop™ test.

Examples

Example 1

> LBMD? PRM,(@)
< LBMD 101,LOOP_OFF,,(pin1,pin2)
> SPRM 103,1,1,1 
> LBMD? PRM,(@)
< LBMD 103,LOOP_I,2,(pin1)
< LBMD 103,LOOP_O,8,(pin2)

Example 2

> LBMD? "lpbk_1",(@)
< LBMD "lpbk_1",LOOP_O,(pin1,pin2)

This example queries a wavetable.

Functional changes

  1. Introduced in SmarTest 7.0.1
