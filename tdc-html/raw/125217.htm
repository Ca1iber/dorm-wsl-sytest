ARRAY_LL

ARRAY_LL defines an array holding the LONG_LONG type of data and defines the functions to access and process the data.

Constructors

ARRAY_LL (INT size);

This constructs an object of ARRAY_LL with the specified fixed size. If a size larger than zero is specified, the memory for the specified number of elements is allocated and the array cannot be resized.

ARRAY_LL (const ARRAY_LL& array);

This constructs an unresizable object of ARRAY_LL by copying from another ARRAY_LL object. 

ARRAY_LL (const ARRAY_LL& array, INT size, INT offset= 0);

This constructs an unresizable object of ARRAY_LL by sharing the specified elements from another ARRAY_LL object.

ARRAY_LL (LONG_LONG* array, INT size, INT offset= 0);

This constructs an unresizable object of ARRAY_LL by sharing the specified elements from a LONG_LONG array.

Parameters

array

The array to copy from.

size

Size of the new ARRAY_LL object.

offset

(optional) Starting point in original array where to begin copying the elements.

Member functions

init()

void init (LONG_LONG initValue=0);

This function fills the array elements with the specified value.

Parameter

initValue

Value with which to fill the array elements

resize()

INT resize (INT size);

This function changes the size of an array if it is resizable and keeps its data.

Parameter

size

New size of the array

size()

const INT size () const;

This function returns the size of the array.

capacity()

const INT capacity();

This function returns the memory size allocated to the array.

operator =

ARRAY_LL& operator = (const ARRAY_LL& array);

This function copies all the elements of the specified array to the current array and changes its size.

Parameter

array

The array to copy from

operator []

LONG_LONG& operator [] (const INT index);
const LONG_LONG& operator [] (const INT index) const;

These functions access the specified element in the array.

Parameter

index

Index of the element to access

operator const LONG_LONG*

operator const LONG_LONG* () const;

This operator converts ARRAY_LL to LONG_LONG*.
