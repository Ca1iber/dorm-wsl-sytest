Parameter: symbolic_interface_name

The name of the interface device.

Note The standard instrument control library (SICL) has been obsoleted since 7.5. Instead, VXI-11 is used for setting the symbolic_interface_name parameter.

For a GPIB/GPIO interface, this symbolic interface name specifies the protocol, IP address or hostname, and port number. The format of the symbolic interface:

vxi11/IP-address/gpib0

For example:

vxi11/192.168.0.3/gpib0

More information about this configuration file is in the Prober/Handler Drivers Configuration Guide beginning with revision 2.0.

For the LAN interface, this symbolic interface name specifies the protocol (TCP/UDP), IP address or hostname and the port number. The format looks like:

[TCP/UDP]/server_address/server_port

For example:

  • TCP/192.168.1.1/12345
  • UDP/192.168.1.1/12345
  • TCP/server_hostname/12345
  • UDP/server_hostname/12345

Note that the socket on the driver side always works in active mode (client).

Driver default: none; value must be defined in the driver configuration

Changeable at run-time: no

Applicable for: handlers and probers

Example:

symbolic_interface_name: "ngpio_dev_1"
symbolic_interface_name: "hpib1"
symbolic_interface_name: "TCP/server_hostname/12345"
symbolic_interface_name: "UDP/192.168.1.1/12345"

Functional changes

  1. Introduced in SmarTest 7.0.4
  2. SmarTest 7.2.3: LAN supported
  3. SmarTest 7.10.2: SICL removed.
