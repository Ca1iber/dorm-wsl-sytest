Topic 140721

Running MTP testflows with MTP-EWC

To run MTP testflows with the MTP-EWC (SmarTest Work Center), open the Testflow (MTP) page to set up run configurations and run.

About this task

Note Do not use the Run Testflow or Run Selected commands to run MTP tests, because the system will not load vector files, pattern master files and modified timing files for the execution, and will not provide an automatic build for the MTP .apg files.
Note To learn the other features on MTP-EWC, see MTP-EWC.

Before you begin

Make sure:

  • MTP software is installed.
  • An MTP testflow is loaded and open.

Procedure

  1. From the menu bar of SmarTest, select Run > Run Configurations....

    The Run Configuration window opens.

  2. In this window, from the left navigation panel, expand Testflow (MTP) and select a configuration, for example, Testflow (MTP) (the default configuration).

    The run configuration page opens (see the following picture). It contains:

    • Name: Lets you enter a name for the configuration. The default name is Testflow (MTP).
    • Three tabs, MTP, Main and Common.
  3. In the Name filed, enter a new name or keep the default name.
  4. Set up the MTP tab:
    • Build (if required) before launching: Enables or disables an antomatic build before execution. By default, the automatic build is disabled.

      You can select any available build configuration for the automatic build. The default configuration is the active build configuration.

    • Load (if required) before launching: Allows you to load modified timing files, vector files and a pattern master file before execution.

      By default, both Modified Timing File and Vector File or Pattern Master File are checked.

  5. Set up the Main tab.

    Here, you can select a testflow and set the execution scope for the testflow. For details, see "To run a user-defined testflow" in Running a testflow.

  6. Set up the Common tab.

    Here, you can add your run configurations to the Run menu. For details, see Adding user defined testflows to the Run menu.

  7. Click Run.

Results

The MTP testflow is executed. The report window displays the execution results.
