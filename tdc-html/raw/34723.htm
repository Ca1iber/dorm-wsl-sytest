DRLEventGetFirstAttributeByType

int DRLEventGetFirstAttributeByType

           (const DRLEventRec *event, DRLAttributeType type, DRLAttributeRec *attribute)

This function retrieves the first attribute record of the type type and copies the reference to it to the caller-provided buffer attribute (see DRLAttributeRec).

To retrieve the next attribute records of this type, you have to repeatedly call the function DRLEventGetNextAttributeByType until there is no more attribute record of this type in the event record.

If there is no attribute record of the type type found in the event record, the function DRLEventGetFirstAttributeByType returns ERR_NO_ATTR.

Return Value

The return value is zero if the function was successful; otherwise the error code ERR_NO_ATTR (see Error Codes) is returned if the event has no attribute record as specified by type.

Example

void example (void) 
{ 
    DRLEventRec event; 
    DRLAttributeRec attribute; 
    if (DRLGetNextUnmaskedEvent(&event)) 
        { /* error handler*/ 
            break; 
        } 
    if (DRLEventGetFirstAttributeByType(&event, DeviceIdAttrType,
                                        &attribute) == 0) 
        { 
            printf("Device processed: %s\n",
                    attribute.data.device_id_attr.device_id); 
        } 
    else 
        { 
            printf("No DeviceIdAttr found !!!\n"); 
        } 
}
