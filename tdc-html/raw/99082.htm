WSDN - (Wait Setup DoNe)

The WSDN (Wait Setup DoNe) command waits until downloading the settings in the readiness analog set and routing settings triggered by the FLSH command are completed.

If the setup sequence of the FLSH command is not running, the WSDN command has no effect and immediately returns.

Syntax

WSDN

Application

Waiting to complete downloading for analog modules.

Example

FLSH
WSDN

The WSDN command returns if all buffered setup downloading, triggered by the FLSH command, is completed.

Functional changes

  1. Introduced before SmarTest 6.3.2
