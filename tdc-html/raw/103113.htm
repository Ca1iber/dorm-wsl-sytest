Task 2: Pin Configuration Setup

Define the relationship between resource pins and DUT board using the Pin configuration tool.

  1. Define the connections between device pins to tester resources (Digital Pins editor).
    • Defining number of sites
    • Allocating channels to the device pins
    • Specifying of the DPS operating range
  2. Define pin groups, creating utility lines, and utility purposes (optional).
  3. Apply pin configuration data

Functional changes
