Using Device Cycle Setup and Edit Modes

When you open the Timing Setup window, device cycles are displayed in the setup mode.

In order to edit a device cycle, you have to bring it into the edit mode. You do this by clicking it with the mouse. The system highlights the selected device cycle by displaying a light blue frame around it (see the $HOME/.Xdefaults file for your color scheme).

The Timing Entry Area automatically displays the edge delays overlay (see The Timing Setup Window), showing edge delays for the highlighted device cycle.
