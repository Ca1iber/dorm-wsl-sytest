TMU_PINS.print()

Prints out the information in the data stream.

Syntax

std::ostream & print(std::ostream & os) const;
Parameter

I/O

Parameter

Description

I

os

The data stream to print.

Return value

A reference to the data stream is returned.

Functional changes
