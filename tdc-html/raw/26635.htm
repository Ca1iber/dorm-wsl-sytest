GetEQVariableFromCache

For fast access to equation variables, some of them are cached, thus avoiding time-consuming inter-process communication.

This routine lets you retrieve the value of a variable from the cache, provided the variable has already been cached.

A variable is either

  • a specification (the name is listed in the SPECS section of an equation definition) or
  • a derived value (the name appears left to an "=" sign in the EQUATIONS section).
    Note You can also use GetEQVariableValue to cache a variable and retrieve its value in one call. GetEQVariableFromCache, however, should be used in combination with InsertEQVariableInCache if you need to ensure constant run-times for your test flow program.

Syntax

VOID GetEQVariableFromCache(
    INT32      equation_system,
    INT32      equation_set,
    INT32      spec_set,
    INT32      site_number,
    CHAR     *variable_name,
    FLOAT64     *value,
    INT32     *return_state);

Parameters

Parameters of GetEQVariableFromCache

Parameter

Description

Range

equation_system

type of equation system

TIMING_EQ_SYSTEM or LEVEL_EQ_SYSTEM

equation_set

equation set number

1 ... 99

spec_set

spec set number

1 ... 99

site_number

number of appropriate site

1 ... MS_MAX_SITES

variable_name

name of equation variable

null-terminated string

value

on return: actual value of variable

 

return_state

execution return state

0 if successful

Example

FLOAT64 variable_value;
INT32 re_state;
GetEQVariableFromCache(TIMING_EQ_SYSTEM,2,1,2,"var1",&variable_value,&re_state);

Functional changes

  1. Introduced before SmarTest 6.3.2
