Topic 111029

ShmooTestAttrType

Contains the result data of a shmoo plot. The data type is DRLShmooTestAttr. It contains the fields listed in the following table.

Field name

Data type

Description

Comments

length

int

Attribute length

These fields form the attribute header

type

string

Attribute type

title

string

Shmoo plot title

 

testMode

string

Shmoo test mode

 

resultPins

string

The pins contributing to the result.

 

otherDescription

string

Shmoo description

 

resultResolution

double

Result resolution

 

xStart

double

Start value of X axis

 

xStop

double

Stop value of X axis

 

xTotalSteps

unsigned int

Total step number of X axis.

 

xLinearSteps

unsigned int

Linear step number of X axis.

 

xScale

string

Scale of X axis. It can be Linear or Logarithmic.

 

xUnit

string

Unit on X axis

 

xAxisDescription

string

Description of axis

 

yStart

double

Start value of Y axis

 

yStop

double

Stop value of Y axis

 

yTotalSteps

unsigned int

Total step number of Y axis

 

yLinearSteps

unsigned int

Linear step number of Y axis

 

yScale

string

Scale of Y axis. It can be Linear or Logarithmic.

 

yUnit

string

Unit of Y axis

 

yAxisDescription

string

Description of Y axis

 
Note You can specify any derived unit (such as ns or mA) for EDL data logging. However, when data logs are converted to STDF, all units are converted to their SI equivalents (ns to s, mA to A) and the corresponding values are converted accordingly. (For example, 435 mA is converted to 0.435 A.)
