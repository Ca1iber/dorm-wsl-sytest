Single-site-encoded GPIO configuration

Subtopics

  1. Valid combinations of plug-ins and configuration files
  2. Binning map
  3. GPIO box jumpering
  4. Timing diagram (Multitest single-site-encoded)

The Multitest "Single-site" configuration is valid for Multitest single-site handlers.

Supported handler models

  • mt8305
  • mt8501
  • mt8503
  • mt8704

Features

  • 1 site
  • global test start signal
  • encoded binning
  • 32 bin categories
  • no "empty" bin

Required handler cable

There is no preconfigured handler cable available for this configuration. Please see Multitest handler cable with 25-pin SUB-D connector for the information on configuring the cable.
