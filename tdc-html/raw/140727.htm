EMBS (Error Map Block Size)

Configures the internal upload page size of error map data.

The error map results are uploaded in multiple chunks of 4KB in size (default). The EMBS FW command is used to override the internal paging mechanism into a different size.

Note Incorrect usage of the EMBS command (choosing an improper block size) or forgetting to restore the default setting, could adversely affect the results upload performance.

Syntax

EMBS {(Block_size)}, {(pinlist)}
Note After invoking the EMBS command, all subsequent uploads will also utilize the user defined upload chunk size. You have to restore the internal paging mechanism into its default using the EMBS STRD command:

Syntax

EMBSSTRD, {(pinlist)}

You can inquire about the error map block size for list of pins using EMBS? inquiry:

Syntax

EMBS? {(pinlist)}

Parameters

Block_size

Minimum 8 bytes up to a maximum of 16 MB. Resolution of the block size is 1 byte.

The EMBS STRD command must be used to switch back to default size.

pinlist

List of pins that the action will take place on. If more than one pin list is included, the names must be separated by a comma.

Application

Error map data upload.

Functional changes

  1. Introduced in SmarTest 6.5.4
