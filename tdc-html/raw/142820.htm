Topic 142820

Selecting similar data

You can select rows containing results for the selected test in the same view by pressing the space bar and in other views by activating the preference setting to synchronize views.

About this task

Perform these tasks when you want to see additional results for a selected test.

Before you begin

Load the data logs or streams that contain the data you want to examine and open them to see their summary views.

Procedures

Highlighting additional results for the selected test

If a Test summary tab contains multiple rows with results for the same test (a test with the same test suite name, test name, test method, and test number), you can select one of them and then extend the selection to all others by pressing the space bar. The result is the same as if you had manually selected the additional rows by control-clicking them.

Pressing the space bar again returns the selection to the original row.

Note that this procedure does not rearrange the rows in the view. If you have not sorted, filtered, or grouped the table, the additional selected rows may therefore not be visible in the view. However, they are still selected and any open result graph views show their data.

Synchronizing views

You can synchronize the Data navigation views of different open data logs. When views are synchronized, selecting a test in one data navigation view also selects in all other open data navigation views that contain the same test.

To synchronize views:

  1. Open the Result Tool preferences page.
  2. Activate the Synchronize selections in navigation views option.

If you later want to stop the views from synchronizing, deactivate the option again.

Results

When you have highlighted additional results for the same test, all rows containing results for the selected test in the frontmost test summary tab are highlighted.

When you have synchronized views, rows containing results for the selected test are highlighted in other test summary views.
