Topic 141303

iMeas()

Creates a current measurement.

It must be used together with vForce().

Make sure the right mode is set for the current measurement: valueMode(TA::BADC). See valueMode().

Note When you use this function on multiports, if the following measurement conditions exist:
  • valueMode() is set to BADC (the default value since SmartRDI 2.5.0 ).
  • Pins from different ports share the same BADC.

You must use rdi.portSync() to ensure the sequence of pins' access to the BADC is correct.

For accuracy considerations, refer to the number of samples for current measurement in BADC_PIN_MEASURE.

Syntax

iMeas();

Example

rdi.dc("iMeas").pin("pinA").vForce(3 V).iMeas().execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
