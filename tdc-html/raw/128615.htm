CCT_TEST

This API is used to do data logging in the concurrent test framework. It is a wrapper of SMC_TEST and TESTSET. When smartCalc is enabled, SMC_TEST is used to do result judgment and data logging. When smartCalc is not enabled, TESTSET is used to judge the result and do the data logging. The test suite names in the CCF block will also be logged.

If CCT_TEST is used in the test method with several tests, the test results will be put into the first bin number of multi-bin.

This API is used in the process() function to do the data logging. Note that the CCT_TEST API supports full hidden data logging including the use of limits that are defined by the calling test suite. See the flag hidden_datalog_mode, option 2 in Alphabetical list of flags.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

Syntax

void CCT_TEST( string& pinlist, string& testName, V93kLimits::TMLimits& tmLimits,
               double value, bool isSMCEnabled, bool isContinue = true,
               TM::RELIABILITY reliability = TM::RELIABLE);
Parameters

pinlist

The list of pins which result to judge and log.

testName

The test name used in the data logging.

tmLimits

A limit defined in test table.

value

The result value to judge and log.

isSMCEnabled

Whether smartCalc is enabled or not. It can be true or false.

isContinue

Whether to continue the test if the result fails. It can be true (default) or false.

reliability

This parameter enables you to indicate the reliability of the test result for data logging. To indicate the test is reliable, specify TM::RELIABLE. To indicate the test is unreliable, specify TM::UNRELIABLE.

Example

string testname;
testname = "INL";
CCT_TEST(adc_in,testname,tmLimits, ADC_lin_result.damax, false,true,TM::RELIABLE);
