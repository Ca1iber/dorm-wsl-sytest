Topic 119528

Querying the information

To query the testflow information on the Information page, enter the following line in an "ACTIONS" section of the Application Model file.

  • To query the Device Name entry

    *device = GET_TEST_INFO (dev_name);

  • To query the Device Revision entry

    *device = GET_TEST_INFO (dev_rev);

  • To query the Test Revision entry

    *device = GET_TEST_INFO (test_rev);

  • To query the Description entry

    *device = GET_TEST_INFO (test_desc);
