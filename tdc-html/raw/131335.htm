MTP_IDD_TASK.waitTime()

The waitTime() member function of MTP_IDD_TASK lets you specify the time to wait before executing a measurement.

Syntax

void waitTime(double time)

Parameter

Description

time

The time to wait before measuring. The default is 0.

The unit is second.

Related information

MTP_CONTINUITY_TASK
