DSP_SUB_SCL

This API is for subtracting each element of one array from a scalar value.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_SUB_SCL(DOUBLE scalar, ARRAY_D& src, 
            ARRAY_D& result);
DSP_SUB_SCL(DOUBLE scalar, DOUBLE *src, 
            DOUBLE *result, INT size);
DSP_SUB_SCL(COMPLEX scalar, ARRAY_COMPLEX& src, 
            ARRAY_COMPLEX& result);
DSP_SUB_SCL(COMPLEX scalar, COMPLEX *src, 
            COMPLEX *result, INT size);
Parameters

I/O

Parameter

Description / Range

I

scalar

Minuend value

I

src

Subtrahend array

O

result

Subtraction results

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src)

size ≤ (size of result)

Example

DOUBLE array1[1024], array_diff[1024];
    .
    .
DSP_SUB_SCL(128.0, array1, array_diff, 1024);

DSP_SUB_SCL subtracts the first 1024 elements of double array array1 from 128.0 and returns the results to the corresponding 1024 elements of double array array_diff as follows:

int i;
	.
	.
for(i=0; i<1024; i++)
	array_diff[i] = 128.0 - array[i];
