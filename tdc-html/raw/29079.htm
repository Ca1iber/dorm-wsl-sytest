DSP_MUL_SCL

This API is for multiplying each element in an array by a scalar value.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_MUL_SCL(DOUBLE scaler, ARRAY_D& src, 
            ARRAY_D& result);
DSP_MUL_SCL(DOUBLE scaler, DOUBLE *src, 
            DOUBLE *result, INT size);
DSP_MUL_SCL(COMPLEX scaler, ARRAY_COMPLEX& src, 
            ARRAY_COMPLEX& result);
DSP_MUL_SCL(COMPLEX scaler, COMPLEX *src, 
            COMPLEX *result, INT size);
Parameters

I/O

Parameter

Description / Range

I

scaler

Multiplicand value

I

src

Multiplier array

O

result

Multiplication results

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src)

size ≤ (size of result)

Note The size restriction of 2097152 also applies to the syntax without the parameter size.

The same object can be used for both the source and result data. But the soure data will be overwritten by the result data if you use the object this way.

Example

DOUBLE array1[1024], array2[1024];
       .
       .
DSP_MUL_SCL(128.0, array1, array2, 1024);

DSP_MUL_SCL multiplies the first 1024 elements of double array array1 by 128.0, and returns the results to the corresponding 1024 elements of double array array2 as follows:

int i;

.

.

for(i=0; i<1024; i++)

array2[i] = 128.0 * array1[i];

Functional changes

  1. Introduced before SmarTest 6.3.2
