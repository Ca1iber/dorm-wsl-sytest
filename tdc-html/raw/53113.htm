Topic 53113

Compatibility between generic WPI DUT boards

The generic WPI DUT boards are compatible for the first 512 pins. Therefore, you can use the pogo groups at the DUT interface positions 101/S2, 121/S2, 113/S2 and 225/S1 only for those pins that would use these positions in the small test head.

The pogo blocks mentioned above are connected to the pogo tower on the board for the large test head. Although unloaded in the large test head, these pogo block positions cannot be used for anything else.

The pogo blocks 104/S1, 124/S1, 116/S1 and 228/S2 are routed through the pins outside the pogo groups. This results in unused pogo blocks in the pogo segments for groups 4, 5, 6 and 7 on the WPI DUT board for the small test head. To maintain compatibility with the large WPI DUT board, these pins cannot be used for the pogo blocks mentioned above.

Note Pin 17 connections are not supported.
