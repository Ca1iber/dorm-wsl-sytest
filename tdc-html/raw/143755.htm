DCapFilter

DCapFilter objects specify settings for capturing digital data.

To use them, you must reference them in PatternExec objects.

Syntax

DCapFilter <filter_name> {
  Type              <capture_type>;       
  TransferMode      <transfer_mode>;     
  FrameCount        <number_of_frames>;    
  VectorsPerFrame   <vectors_per_frame>;
  VectorsPerSample  <vectors_per_sample>;
  DiscardOffset     <offset>;
  DiscardVectors    <discard_vectors>;
  DiscardFrames     <discard_frames>;
}

The settings are:

  • DCapFilter <filter_name>

    The name of the filter. <filter_name> can be any name that is valid for STIL objects.setup object.

  • Type <capture_type>

    The type of digital capture. Currently, this is always Capture.

  • TransferMode <transfer_mode>

    The type of data stream created, Parallel or Serial.

  • FrameCount <number_of_frames>

    How many frames of data are captured. The default value is 1.

  • VectorsPerFrame <vectors_per_frame>

    How many data bits are captured per frame from each pin. The default value is 1.

  • VectorsPerSample <vectors_per_sample>

    How many frames each sample contains. Parallel captures must always contain 1 frame per sample. Serial captures can contain 1 to 32 frames per sample. The default value is 1.

  • DiscardOffset <offset>

    How many vectors are skipped (not captured) at the beginning of each frame. The default value is 0.

  • DiscardVectors <discard_vectors>

    How many vectors are skipped (not captured) between captured frames. The default value is 0.

  • DiscardFrames <discard_frames>

    How many frames are skipped (not captured) before the first frame is captured. The default value is 0.

Example

DCapSetup DS1 {
  Pins              "data";
}

DCapFilter DF1 {
  Type              Capture;
  TransferMode      Parallel;
  VectorsPerFrame   8;
}

DCapFilter DF2 {
  Type              Capture;
  TransferMode      Parallel;
  FrameCount        4;
  VectorsPerFrame   8;
  VectorsPerSample  1;
  DiscardOffset     2;
  DiscardVectors    1;
 }

PatternExec PE1 {
  DCapSetup         DS1;
  DCapFilter        DF1;
  DCapFilter        DF2;
  PatternBurst      B1;
}
