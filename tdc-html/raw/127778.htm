TESTSET().reliability()

This member function of TESTSET is used to indicate the reliability of a test result.

Syntax

TESTSET & reliability(TM::RELIABILITY rel);

Parameter

Descriptions

rel

This parameter enables you to indicate the reliability of the test result for data logging. To indicate the test is reliable, specify TM::RELIABLE. To indicate the test is unreliable, specify TM::UNRELIABLE.

This parameter is optional. If you omit it, it is the same as specifying TM::RELIABLE.

Example

TestSet.reliability(TM::RELIABLE);

Related information

TESTSET

Functional changes

  1. Introduced before SmarTest 6.3.2
