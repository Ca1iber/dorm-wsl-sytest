DRLAppModelLevelAttr

A variable of this type holds the data which characterizes an application model level.

The member name holds the name of the application model level which is given in the application model file as a NULL terminated string.

The member type specifies the type of application model level. type can be one of the values DRLUserAppLevel, DRLWaferAppLevel, DRLDeviceAppLevel, DRLPauseAppLevel, where DRLUserAppLevel stands for any level above the wafer or device level.

typedef struct _DRLAppModelLevelAttr {
  char *name;
  char type; /* DRLUserAppLevel, DRLWaferAppLevel,
                DRLDeviceAppLevel, DRLPauseAppLevel */
} DRLAppModelLevelAttr;
