GPIB driver configuration

The following configurations are provided for the driver:

TW2XX_GPIB_16.cfg

TW3XX_GPIB_16.cfg

TW250-GPIB-64.cfg

TW250-GPIB-128.cfg

TW250-GPIB-256.cfg

The configurations starting with TW250 are for TW3XX model handlers.

Default GPIB configuration

The variables used in the configuration files are listed below. When the configuration files were created, certain aspects necessarily had to be defined. The table below lists these aspects and how they were defined.

Important aspects of the TechWing configuration files

Aspect

Used setting

Debug level

0, will log only basic messages. It can be changed to a value between -1 and 4.

GPIB port used

22, must be changed to correct value based on the handler's setup.

Bin mapping

default

Number of bins

9

Temperature parameters

Temperature control may be activated

by changing the parameter temp_control to active and setting the temp_setpoint.

Test start detection

Done by interrupt (SRQ). It can be changed to pure polling mode with given polling interval for troubleshooting.

Functional changes

  1. Introduced before SmarTest 6.3.2
