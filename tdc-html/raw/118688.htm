DSP_JITTER_SEPARATION

This API calculates the jitter separation based on the input of error count and timing data. It separates jitter to random and deterministic components via fitting algorithms.

To calculate the jitter separation, you firstly need to capture the error count curves on the left transition and right transition of the data eye to get the bathtub curve. Then Bit Error Rate (BER) per sampling point needs to be calculated by dividing the recorded error count by the total number of bit in the vector stream. The BER vector of left side and right side are the input data to this API.

The bathtub curve of BER data is transferred to the Q-space as in the figure below.

Then a fitting on the two slopes of the Q-space curve will be done. The fitting on the selected range of the Q-space curve will give two straight lines with a certain slope and a certain distance point. The respective slope is determined by the Random Jitter and the distance of the two slopes is determined by the Deterministic Jitter. Therefore, the Random Jitter can be calculated for each side of the data eye. In theory they should be the same for both sides of transition. But in practice this is not always the case. So the Random Jitter is the average slope of the left side and the right side. The Deterministic Jitter is calculated from the mean distance of the slopes. Total Jitter consists of Deterministic Jitter and Random Jitter. The absolute Random Jitter (peak-to-peak) depends on the BER_factor. So the Total Jitter is also related to a BER_factor number.

A new data type JitterSeparationType is defined for jitter separation result. It contains a set of jitter attribute data, including random jitter, deterministic jitter and total jitter.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_JITTER_SEPARATION(const std::vector<DOUBLE>& leftSideBER,
                 const std::vector<DOUBLE>& rightSideBER,
                 const DOUBLE leftSideTimingStart_ns,
                 const DOUBLE rightSideTimingStart_ns, 
                 const DOUBLE timingStepwidth_ns,
                 const DOUBLE UI_width_ns,
                 const DOUBLE transitionDensity,
                 const INT BER_factor,
                 JitterSeparationType& separationDataAttribute,
                 DOUBLE &leftCorrelationCoef,
                 DOUBLE &rightCorrelationCoef,
                 const Boolean movingWindowAveraging = false, 
                 INT windowSize=2);
Parameters

I/O

Parameter

Description

I

leftSideBER

A vector of left side BER data

I

rightSideBER

A vector of right side BER data

I

leftSideTimingStart_ns

The timing point of the first element data of leftSideBER.

I

rightSideTimingStart_ns

The timing point of the first element data of rightSideBER.

I

timingStepwidth_ns

The time step width for error count acquiring

I

transitionDensity

Transition density of the measured pattern (1.0 for bit clock patterns and 0.5 for for random data patterns. For further reading, see [1].

I

UI_width_ns

The time interval of a bit in the test pattern.

I

BER_factor

Target BER for total Jitter calculation.

O

separationDataAttribute

A set of standard result data reflecting the jitter attribute

O

leftCorrelationCoef

Correlation coefficient of the left side linear fitting arithmetic

O

rightCorrelationCoef

Correlation coefficient of the right side linear fitting arithmetic

 

linearInterpolationEnabled

 

I

movingWindowAveraging

The flag to switch on or off the moving window averaging algorithm. By default the algorithm is switched off, and a transitionDensity of 0.5 and a windowSize of 2 are set. For further reading see [2].

I

windowSize

Window size for the moving window averaging algorithm (2, 4, 6).

Example

The following example shows how to query the error counts of both transition side of the bit eye and calculate the jitter separation of pin "HS_TX1" and "HS_TX2".

//assume the bit time of test pattern: UI_width_ns = 5ns;
//assume the total number of bit is :totalBitNumbers
vector<STRING> pinVector;
pinVector.push_back("HS_TX1");
pinVector.push_back("HS_TX2");
DOUBLE totalBitNumbers = BitNumber;
//acquire error count on the left transition side of bit eye
//assume the bit transition is within the [0.0, 0.5] area
ERROR_COUNT_ACQUIRE leftSideErrorCountRetrieve;
//acquire error count on the right transition side of bit eye
//assume the bit transition is within the[1.5,2.0]
ERROR_COUNT_ACQUIRE rightSideErrorCountRetrieve;

ON_FIRST_INVOCATION_BEGIN();

  //setup search condition
  for(int n = 0; n < pinVector.size(); n++)
  {
    STRING pinname = pinVector[n];
    STRING specName = pinname + "_offset";
    //setup for two high speed pins
    leftSideErrorCountRetrieve.pin(pinname)
                              .port("HS_Port")
                              .spec(specName,TM::TIM)
                              .stepWidth(0.01)
                              .start(0.0)
                              .stop(0.5)
                              .errorCountMode (TM::ERROR_PER_EDGE)
                              .enableFastStop(0.05,9,true);
    rightSideErrorCountRetrieve.pin(pinname)
                               .port("HS_Port")
                               .spec(specName,TM::TIM)
                               .stepWidth(0.01)
                               .start(1.5)
                               .stop(2.0)
                               .errorCountMode (TM::ERROR_PER_EDGE)
                               .enableFastStop(0.05,9,true);
  }
  leftSideErrorCountRetrieve.execute(TM::FAST_STOP);
  rightSideErrorCountRetrieve.execute(TM::FAST_STOP);
ON_FIRST_INVOCATION_END();

//get error count for left side transition
ARRAY_I leftErrorCountOfHsTx1, leftErrorCountOfHsTx2;
leftErrorCountOfHsTx1 = leftSideErrorCountRetrieve.getErrorCount("HS_TX1");
leftErrorCountOfHsTx2 = leftSideErrorCountRetrieve.getErrorCount("HS_TX2");
std::vector<DOUBLE> leftErrCountOfHsTx1Vec, leftErrCountOfTx2Vec;
long long sizeOfArray = 0;
for (; sizeOfArray < leftErrorCountOfHsTx1.size(); sizeOfArray++)
{
  DOUBLE BER = leftErrorCountOfHsTx1[sizeOfArray]/totalBitNumbers ;
  leftErrCountOfHsTx1Vec.push_back(BER);
}
sizeOfArray = 0;
for(; sizeOfArray < leftErrorCountOfHsTx2.size(); sizeOfArray++)
{
  DOUBLE BER = leftErrorCountOfHsTx2[sizeOfArray]/totalBitNumbers ;
  leftErrCountOfTx2Vec.push_back(BER);
}

//get error count for right side
ARRAY_I rightErrorCountOfHsTx1,rightErrorCountOfHsTx2;
rightErrorCountOfHsTx1 = rightSideErrorCountRetrieve.getErrorCount("HS_TX1");
rightErrorCountOfHsTx2 = rightSideErrorCountRetrieve.getErrorCount("HS_TX2");
sizeOfArray = 0;
std::vector<DOUBLE> rightErrCountOfHsTx1Vec, righttErrCountOfHsTx2Vec;
for(; sizeOfArray < rightErrorCountOfHsTx1.size(); sizeOfArray++)
{
  DUBLE BER = rightErrorCountOfHsTx1[sizeOfArray]/totalBitNumbers ;
  rightErrCountOfHsTx1Vec.push_back(BER);
}
sizeOfArray = 0;
for(; sizeOfArray < rightErrorCountOfHsTx2.size(); sizeOfArray++)
{
  DOUBLE BER = rightErrorCountOfHsTx2[sizeOfArray]/totalBitNumbers ;
  righttErrCountOfHsTx2Vec.push_back(BER);
}
//calculate the jitter separation
JitterSeparationType separationRes1, separationRes2;
DOUBLE leftCorrelationCoefTx1, rightCorrelationCoefTx1;
DOUBLE leftCorrelationCoefTx2, rightCorrelationCoefTx2;
DSP_JITTER_SEPARATION(leftErrCountOfHsTx1Vec,
                      rightErrCountOfHsTx1Vec,
                      0.0,
                      1.5,
                      0.01,
                      5.0,
                       1.0, // Bit clock pattern
                      -12,
                      separationRes1,
                      leftCorrelationCoefTx1,
                      rightCorrelationCoefTx1);
DSP_JITTER_SEPARATION(leftErrCountOfTx2Vec,
                      righttErrCountOfHsTx2Vec,
                      0.0,
                      1.5,
                      0.01,
                      5.0,
                       1.0, // Bit clock pattern
                      -12,
                      separationRes2,
                      leftCorrelationCoefTx2,
                      rightCorrelationCoefTx2);
//out put result to UIReport window
cout << "jitter separation of HS_TX1: "
     <<"\nRandom Jitter= " << separationRes1.randomJitter
     <<"\nDeterministic Jitter= "<<separationRes1.deterministicJitter 
     <<"\nTotal Jitter= "<<separationRes1.totalJitter
     <<"\n left side linear fitting's rms is " << leftCorrelationCoefTx1
     <<"\n right side linear fitting's rms is " << rightCorrelationCoefTx1<<endl;
cout << "jitter separaiton of HS_TX2: "
     <<"\nRandom Jitter= "<<separationRes2.randomJitter
     <<"\nDeterministic Jitter= "<<separationRes2.deterministicJitter
     <<"\nTotal Jitter= "<<separationRes2.totalJitter
     <<"\n left side linear fitting's rms is " << leftCorrelationCoefTx2
     <<"\n right side linear fitting's rms is " << rightCorrelationCoefTx2<<endl;
