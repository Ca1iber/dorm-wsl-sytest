Creating an MTL pattern

To create an MTL pattern:

  1. Create the Device access file (.dvac) and the Device architecture file (.dvar) according to the data sheet.
  2. Create the Pin mapping file (.pmap).
  3. Create the Pin configuration file (.pin) in SmarTest (only required if you plan to use automatic waveform generation or multiport operation).
  4. Create the APG pattern file (.apg).
  5. If you want to actively drive levels or measure signals on a DC Scale card (for example, using the DC_Scale test method), create the DC event file (.dcev).
  6. Create the APG program file (.prog) using APG accesses, for loops, Subroutines, Variables, and DC events.
  7. Run the compiler from the terminal window (see Starting the MTL compiler from command line) or use the graphical user interface (see MTL compiler started from GUI).
    Note Editing these files is easier if you install syntax highlighting for your editor. For NEdit, the necessary information is provided in Enabling NEdit syntax highlighting.
