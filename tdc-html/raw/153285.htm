Topic 153285

Working with the Routing Tools editors

A defined setup sequence should be followed for successfully defining setups using the Routing Tools editors.

About this task

This task describes the sequence for setting up all configuration data and defining the setups to be applied by the Routing Tools APIs.

Before you begin

  1. Collect the following hardware related information of the DUT board:
    • Assignment and wiring of the utility pogo pins.
    • Configuration and wiring of the digital control pins if sequencer controlled utility lines are used.
  2. Open the Routing Tools Editors as shown in Opening the Routing Tools editors.

Procedure

  1. Define the digital control pins.

    Digital control pins must be defined for controlling utility lines by the pattern sequencer.

    1. Identify the digital control pins for utility pogo blocks that are wired on the DUT board.
    2. Define minimum three digital pins for the signals FRAMn, SCLK, and SINP per utility line control group. For more information refer to Serial interface for sequencer-controlled utility lines.
  2. Load or create an XML file and enter the global configuration data.

    The XML file holds the complete configuration data for the Routing Tools.

    1. Select the Global Setup editor tab.
    2. Create a new XML file or select an existing XML file using the File Path field or the Browse... button. The file extension ".xml", ".zip" or ".rtz" defines whether the file to load is a text file or a compressed file.
    3. Click the Load button for loading the selected file.
    4. Enter the number of configured sites in field Site Number. The number of configured sites must be the same as defined by the Define Site Number dialog of SmarTest. For more information refer to Defining additional test sites.
    5. Select the type of utility pogo blocks in field Pogo block size.... The selected value must be the same as defined as parameter utility_lines_per_pogoblock in the .technology file of the device. For more information refer to Technology file for a device.
    6. If sequencer‑controlled utility lines are used enter a clock frequency in field SPI Max. Clock Rate. The maximum supported clock frequency is defined in Specifications for the serial interface.
  3. Define the control data for utility lines.

    The operating mode of the utility pogo blocks and the assignment of the digital control pins for sequencer‑controlled utility lines need to be defined.

    1. Select the Utility Lines Control editor tab.
    2. Use the Control Table for defining the operating mode for each of the used utility blocks.
    3. Use the Pin Config Table for defining the digital control pins if sequencer‑controlled utility lines are used. The selected digital pins must already be defined in the Digital Pins editor. On the DUT board, the selected pins must be wired to the serial interface for sequencer controlled utility lines.
  4. Define the configuration data for utility lines.

    The assignment from tester channels or utility pogo pins respectively to user defined utility pin names is done in this step.

    1. Open the SmarTest Utility Pins editor.
    2. Define all required utility pin names and assign them to the tester channels UTI## ... UTI## for all configured sites.
    3. Select the Utility Lines Config editor tab of the Routing Tools.
    4. Copy all names and tester channels from the Utility Pins editor to the corresponding cells of the Utility Lines Config editor tab. The utility pins that are defined in this step must be the same as defined in column Name of the Utility Pins editor.
  5. Define the switch states.

    The switch states to be applied to utility lines are defined in this step. The user defined states hold the switch states for all utility pins and PMU pins and represent one of the Routing Tools main functionality.

    1. Select the default switch mode and enter the default wait times in milliseconds in the first four cells of row Execution.
    2. Enter the user defined state name in column State Name.
    3. Select the appropriate switch mode BBM (Break Before Make), MBB (Make Before Break), or IMM (Immediate mode) in column Switch Mode if the value defined in row Execution does not fit.
    4. Enter the appropriate wait time in milliseconds in columns Off Wait [ms], On Wait [ms], or IMM Wait [ms] if the values defined in row Execution does not fit. The three wait times are assigned to the switch modes BBM, MBB, and IMM.
  6. Save your settings.

    The configuration data of the Routing Tools editors must to be saved to an XML file.

    Note Saving the contents of all Routing Tools editor tabs can also be done by clicking the Save button of the or by pressing the CTRL + S key combination simultaneously.
    1. Select the Global Setup editor tab.
    2. Click the Save button. The file extension ".xml" or ".zip" defines whether the configuration data file is saved as text file or as compressed file. The content of the file is always formatted in the human readable XML format.

Results

You have created an XML file that holds all configuration data for utility pins and PMUX pins and the states to be applied.

What to do next

Add the code for loading, selecting, and applying the defined state setups to the test methods of your test suites using the rdi.route() API of SmartRDI.
