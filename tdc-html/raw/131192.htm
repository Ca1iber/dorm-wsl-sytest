SPMU_TASK.preAction()

Defines the action to be performed prior to the DC measurement.

Syntax

SPMU_TASK& preAction(const STRING& action);
Parameter

Parameter

Description

action

The following actions are available:

  • "NONE" - Default. Conditional primary activation.

    The currently loaded digital primary settings will be activated if it is not active already.

  • "NPRM" - No primary activation!

  • "FTST" - Performs a functional test after activating the currently loaded digital primary settings.
Note To activate primary settings specified with PRIMARY_STATUS execute a FLUSH() before calling this function.

Return value

A reference to the SPMU_TASK object.

Note To retrieve the result of the functional test use SPMU_TASK.getFunctionalResult().
