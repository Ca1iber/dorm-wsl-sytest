DRLTimingsAttr

A variable of this type holds the information on the timing used for a test.

The member type specifies whether the timing is set-based or equation-based. type can be one of the values DRLSetBased or DRLEquationBased (see below).

If the timing is set-based, the member timing_set holds the number of the timing set. The member waveform_or_spec_set holds the number of the waveform set. In this case, the member equation_set is undefined.

If the timing is equation-based, the member equation_set holds the number of the equation set. The member waveform_or_spec_set holds the number of the spec set, and the member timing_set holds the number of the timing set. 

typedef struct _DRLTimingsAttr {
  unsigned char type; /* DRLSetBased or DRLEquationBased */
  short
    equation_set,
    waveform_or_spec_set,
    timing_set;
} DRLTimingsAttr;
