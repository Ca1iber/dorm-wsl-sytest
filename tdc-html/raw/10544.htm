Topic 10544

Comments on vectors

The following commands serve to manage comments on vectors:

Command

Description

CMNT

Low level command which serves to add a comment on one vector. Note that, in contrast to most vector related commands, CMNT operates on the port level. It counts active vectors, but of the whole port, not a single label.

BCMT

Similar to CMNT, but can download comments on several vectors with one call.

TCMT

Edit command for adding a comment on one vector.

CMVC

Edit command for moving and deleting comments.

Functional changes

  1. Introduced before SmarTest 6.3.2
