UTILITY_SEQ_STATIC_MASK.pogoBlock()

Specifies the utility pogo block(s) to set up.

Syntax

UTILITY_SEQ_STATIC_POGO_MODE & pogoBlock ( const INT number = 0 );

Specifies a single utility pogo block to set up.

UTILITY_SEQ_STATIC_POGO_MODE & pogoBlock ( const INT startPogo, const INT endPogo );

Specifies a range of utility pogo blocks to set up.

Parameter
Parameter Description
number

The pogo block number.

Valid pogo block numbers:
  • 0 (All  utility  blocks)
  • 1 … 8 (1st Utility Card)
  • 165 ... 272 (1st Utility Card)
  • 265 ... 272 (2nd Utility Card)

If not specified, all the utility pogo blocks will be set.
startPogo

The start pogo block number of the pogo blocks to set up. It must be smaller than the end pogo block number.

For the valid range, refer to parameter number.

startPogo and endPogo must define pogo blocks of the same Utility Card. Defining a range that covers multiple Utility Cards is not supported.
endPogo

The end pogo block number of the pogo blocks to set up. It must be larger than the start pogo block number.

For the valid range, refer to parameter number.

startPogo and endPogo must define pogo blocks of the same Utility Card. Defining a range that covers multiple Utility Cards is not supported.
Note Each pogo block can be defined only once per UTILITY_SEQ_STATIC_MASK object. This applies also for each pogo block within a range from startPogo to endPogo.
Return value
The reference to a UTILITY_SEQ_STATIC_POGO_MODE object is returned.

Example

See the example in UTILITY_SEQ_STATIC_MASK.

Functional changes

  1. Introduced in SmarTest 7.4.2
  2. SmarTest 7.10.1: Pogo block range 165 ... 272 and 265 ... 272 for Utility card
