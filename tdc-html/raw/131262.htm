MTP_CONTINUITY_TASK.pin()

The pin() member function of MTP_CONTINUITY_TASK lets you specify the pins you want to check for continuity. pin() returns the MTP_CONTINUITY_PIN_TASK class object which you use to set up the measurement conditions for these pins.

Syntax

MTP_CONTINUITY_PIN_TASK pin(const string & pinlist)

Parameter

Description

pinlist

The list of the pins or pin groups to be measured in the shared continuity test. Multiple pins or pin groups are separated by commas.
