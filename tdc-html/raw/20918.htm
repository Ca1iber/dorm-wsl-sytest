Computing Measurement Values

The test method APIs provide an extensive set of computation algorithms required for a typical mixed-signal device test. The algorithm covers from simple arithmetic operations (for example, add/subtract arrays) to application-specific calculations (for example, compute ADC linearity errors).

To compute the test result from the raw measurement data, you can use the following Computation APIs. For more information on those APIs, see API Reference.

  • Complex Number Operations

    The following APIs perform arithmetic calculations on complex numbers:

    • DSP_ADD_C
    • DSP_SUB_C
    • DSP_MUL_C
    • DSP_DIV_C
  • Data Conversion

    The following APIs perform array conversions, multiply each element in the array by a scaling factor, and add an offset to each element; they also extract and copy elements to another array, and perform Rectangular and Polar coordinate conversions:

    • DSP_CONV_I_x (x: C, DC, I, and D)
    • DSP_CONV_D_x (x: C, DC, I, and D)
    • DSP_EXTRACT
    • DSP_RECT_POL
    • DSP_POL_RECT
    • DSP_FILL_SCL
    • DSP_EXPAND
    • DSP_SHUFFLE
  • Bit Conversion

    The following APIs perform bit-level data conversion:

    • DSP_COMBINE_BIT
    • DSP_SHIFT
    • DSP_PARA_SERI
    • DSP_SERI_PARA
    • DSP_COMPRESS
  • Arithmetic Operations

    The following APIs perform basic arithmetic operations between two vectors (two arrays) or between a scalar value and a vector:

    • DSP_ADD_VEC
    • DSP_AND_SCL
    • DSP_SUB_VEC
    • DSP_SUB_SCL
    • DSP_MUL_VEC
    • DSP_MUL_SCL
    • DSP_DIV_VEC
    • DSP_DIV_SCL
    • DSP_ABS_VEC
  • Matrix Operations

    The following APIs perform operations on two-dimensional arrays (matrices):

    • DSP_MUL_MAT
    • DSP_TRANS_MAT
    • DSP_UNIT_MAT
  • Bit-Wise Logical Operations

    A bit-wise logical operation is a logical operation performed between a bit in an element of one integer array and the corresponding bit in another integer array.

    The following APIs perform bit-wise logical operations on integer arrays:

    • DSP_AND_VEC
    • DSP_AND_SCL
    • DSP_OR_VEC
    • DSP_OR_SCL
    • DSP_XOR_VEC
    • DSP_XOR_SCL
  • Pattern Search

    The following APIs search for a specified bit pattern in an integer array:

    • DSP_SEARCH_PARA
    • DSP_SEARCH_SERI
  • Statistics

    The following APIs perform statistical processing on arrays:

    • DSP_HISTOGRAM
    • DSP_MEAN
    • DSP_MOVAVG
    • DSP_MINMAX
    • DSP_ABS_MINMAX
    • DSP_RMS
    • DSP_REG1
    • DSP_REG2
  • Trigonometric and Transcendental Functions

    The following APIs perform trigonometric and transcendental array element computations:

    • DSP_SIN_VEC
    • DSP_COS_VEC
    • DSP_TAN_VEC
    • DSP_LOG10_VEC
    • DSP_LOG_VEC
    • DSP_EXP10_VEC
    • DSP_EXP_VEC
    • DSP_POWER_VEC
  • Time Series Analysis

    The following APIs are used for time series analysis:

    • DSP_FFT
    • DSP_BLOCK_FFT
    • DSP_IFFT
    • DSP_IFFT_POLAR
    • DSP_DFT
    • DSP_SPECTRUM
    • DSP_SNR
    • DSP_SND
    • DSP_THD
    • DSP_CONVOL
    • DSP_CORREL
    • DSP_RESPONSE
  • Extended Functions for ADC and DAC Devices

    The following APIs are used for special operations like calculation of the settling time and DG/DP test parameters for A/D and D/A converters:

    • DSP_SETTLING
    • DSP_EDGE
    • DSP_SINFIT
    • DSP_DIFF
    • DSP_LINEAR
    • DSP_TH_QUANTIZE
    • DSP_ADC_HISTOGRAM
    • DSP_AREA
  • Extended Functions for Telecommunication Devices

    The following APIs are used for special operations like A-law and m-law encoding/decoding for telecommunication devices:

    • DSP_MU_ENCODE
    • DSP_MU_DECODE
    • DSP_A_ENCODE
    • DSP_A_DECODE
    • DSP_ASSIGN_FILTER
