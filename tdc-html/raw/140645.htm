DPS128 / DPS64 in PMU operating mode

For PMU operating mode specify the pin type as SIG. In PMU operating mode you can use the DC Scale DPS128/DPS64 card like a standard PMU to temporarily supply power in a single test suite or for a group of test suites.

Each of the 128/64 channels can source and sink current at a programmed voltage, and each channel can measure the voltages and currents supplied. Each high current channel provides up to 1 Amp. Each high voltage channel can provide -6 to +15 Volt. For the maximum source/sink current per card see the DPS128 / DPS64 specifications.

Connect/Disconnect

Note In PMU operating mode, signal pins of a DC Scale DPS128/DPS64 card will not be connected during connect and not disconnected during disconnect.
Note In PMU operating mode a DC Scale DPS128/DPS64 card does not take part in standard connect and disconnect sequences, and cannot take part in the set activation, although you can add DC Scale DPS128/DPS64 cards to user-defined connect and disconnect sequences.

Relay switching in PMU operating mode

The relay() member function of the SPMU_PIN_TASK class selects the termination mode that specifies the relay control pattern of the target pins.

DC-Scale cards support the following relay switching modes:

  • NO
  • NT

The termination modes NTMBB, NTBBM, and TERM are not supported by DC-Scale cards.

VFIM - Voltage Force / Current Measure

In PMU operating mode you can use DC Scale cards like a standard PMU.

In voltage force mode, to perform current measurements you must specify a clamp current. Specify both the minimum and maximum pass current values and units (mA or µA). For further details see "Pass/Fail Pin DC Measurement" and "ADC Pin DC Measurement" in Hardware view for digital pins.

For test method programming details see SPMU_PIN_TASK.

For the voltage and current range specifications of the DC Scale cards see DC Scale Device Power Supplies.

VFIM_UNGANGED - Voltage Force / Current Measure Unganged

To achieve a higher output current, you can gang multiple DC Scale channels. But the higher current of ganged channels has a negative impact on accuracy.

To achieve a higher accuracy, for example for IDDQ-measurements, you can temporarily ungang channels before measurement.

Note that on DPS128/64 and XPS256 you cannot execute a current compare on a ganged group of channels in unganged mode. Already activated comparators are silently disabled in unganged mode. A user notification (Error or warning) is omitted in this case, to avoid any interrupt in the testflow. The previous state of the comparators is automatically restored after the ganged group has been restored.

To temporarily ungang channels in PMU operating mode use the VFIM_UNGANGED parameter of the SPMU_PIN_TASK test method API.

If the current range of a ganging group of DC Scale pins is larger than the measured current, you can use only part of the pins within this group to perform the measurement. Selecting the "VFIM_UNGANGED" mode automatically ungangs not needed channels, based on the min() max() limits.

For details see SPMU_PIN_TASK.

IFVM - Current Force / Voltage Measure

In PMU operating mode you can use DC Scale cards like a standard PMU.

In current force mode, to perform voltage measurements you must specify a clamp voltage. Specify both the minimum and maximum pass voltage values and units (mV or V). For further details see "Pass/Fail Pin DC Measurement" and "ADC Pin DC Measurement" in Hardware view for digital pins.

For the voltage and current range specifications of the DC Scale cards see DC Scale Device Power Supplies.

For test method programming details see SPMU_PIN_TASK .

VM_HIZ - High Impedance Voltage Measure

In PMU operating mode DC Scale cards support high impedance voltage measurements (neither voltage nor current is forced).

In high impedance measurement mode (himp) DC Scale power supply cards act like a voltmeter.

The high impedance measurement mode opens the AC_Force and H_Imp relays, and closes the AC_Sense relay.

Note You cannot use this feature for a DPS-slot DPS.

For details on equations see Level Equations.

For a non-equation based setup you must use the PSLR firmware command.
