MTP_IDD_TASK.execute()

The execute() member function of MTP_IDD_TASK executes the IDD test based on the setup specified using the pin() and samples() member functions.

Syntax

void execute()
Note When testing, you must use the CONNECT API before using execute() since the IDD is measured in connected state.

Related information

MTP_IDD_TASK
CONNECT

Functional changes

  1. Introduced in MTP 3.1.5
