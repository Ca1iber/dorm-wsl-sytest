Topic 71168

Parallel Search and Search Set Management

Subtopics

  1. Reusing Search Conditions
  2. Managing Search Conditions with Variables
  3. Note on cache management

The SEARCH_FUNC_TASK and the SEARCH_FUNC_PIN_TASK API serve to execute different spec variable or edge searches in parallel. The conditions for one parallel search are stored in a so-called search set. A search set can contain only one search condition for any combination of pin and site.

The SEARCH_FUNC_TASK API contains a mechanism that avoids repeated downloading of the same conditions for consecutive executions of a parallel search within a testflow loop (see Reusing Search Conditions). A basic knowledge of this mechanism is required for effective coding of search conditions that use variables (see Managing Search Conditions with Variables).

The management of search sets is similar to the DC set management in optimized test flows.
