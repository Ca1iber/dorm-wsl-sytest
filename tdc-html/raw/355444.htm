SmartRDI 7.10.3

This section summarizes software changes including new features and enhancements in SmartRDI 7.10.3.

Changes and new features
Category Description
General
  • SmartRDI supports up to 1000000 measurement result IDs at the same time.
  • SmartRDI supports automatic mask on inactive sites.
    • assignLabelOnHoldSites()
    • assignLabelOnInactiveSites()
    • clearOnHoldSites()
    • setOnHoldSites()
    • getOnHoldSites()
    • getOnHoldSitesStatus()

    See Site masking.
Alarm handling
  • Alarm handling on pins using runTimeVal() is supported.
  • getAlarmBurstValue() gets alarm DC results on specified pins in burst.
  • getAlarmPassFailPerID() gets pass/fail results on a specified label.
  • getAlarmValue() gets alarm DC results on specified pins per id.
  • getEnabledPins() retrieves the enabled alarm pins.
DC
  • addWaveform() sources multiple different waveforms in one execute().
  • Using a separate MSET, RDI can automatically change the force mode for digital DC waveform.
  • Analog waveform content can be logged.
TMU
  • getPropDelay() automatically calculates the propagation delay time of TMU measurements.
UTIL
  • SmartRDI supports the "-" character to link block numbers for ganged blocks in the UTIL_BLOCK definition of the RDI_Configure file.

Supported SmarTest versions

SmartRDI 7.10.3 supports SmarTest 7.10.3.
