SOURCESYNC_SUB_TEST.repeatEdgeInterval()

Specifies how many edges will be omitted between every two adjacent edges to be shown on an error map. Use it together with SOURCESYNC_SUB_TEST.repeatEdgeLength() and SOURCESYNC_SUB_TEST.repeatEdgeOffset() to specify which edges will be printed out on an error map.

Syntax

SOURCESYNC_SUB_TEST& repeatEdgeInterval (const int interval);
Parameter

Parameter

Description

interval

The number of edges to be omitted between two adjacent edges on an error map.

The default number is 0, which leads to the output of every edge on an error map. When the interval is 0, the setups for RepeatEdgeOffset and RepeatEdgeLength are ignored.
