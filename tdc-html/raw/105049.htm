Topic 105049

SetPackageID()

This API sets the package ID into the shared memory so that the package ID can be recorded in the EDL log for GDF.

Note The package ID is not used in STDF logs. In STDF, devices are identified by setting SITE<N>_PART_ID system variables, as described in The PART_ID field in the PRR., using the SetApplicationVar() function.

SUCCESS will be returned if no error occurs. Otherwise an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

PARAMETER_EXCEPTION
  • The value of the parameter "PACKAGE_ID" is empty.
  • The length of the parameter "PACKAGE_ID" exceeds the max value(75).

RECOVERABLE

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • The local session does not exist.

RECOVERABLE
Parameters

I/O

Parameter

Description

I

SESSION_ID

The local session ID.

I

PACKAGE_ID

The digit for x in the format x.y. If it is set to 2 and there are 4 sites configured, the package ID for each site is: 2.1, 2.2, 2.3 and 2.4.

Prototype

ParamList inputParams;
Status syncCommand("SetPackageID", inputParams, sessionID);

Example

string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams; 
inputParams["PACKAGE_ID"] = "2";

Status retVal = syncCommand("SetPackageID", inputParams, sid);
if ( retVal.isError() ) 
{
cout<<"error code= " << retVal.code() << " description="
    << retVal.text() << endl;
}

Functional changes

  1. Introduced in SmarTest 6.5.0
  2. SmarTest 7.1.0: GDF logging with BLC API is obsolete.
