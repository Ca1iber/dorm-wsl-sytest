SMC_SITE_NUMBER()

Returns the site number of the test that your SMC_backgroundProcessing() method is executing.

Note

This function can be used only if the SMC_backgroundProcessing() function runs as thread per site. The function cannot be used for the common thread.

For more information, refer to SmartCalc "Thread per site" and "Common thread".

Syntax

INT SMC_SITE_NUMBER();

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

List of parameters
There are no parameters.
Return value
Returns the current site number as integer.

Example

If you test devices on four sites, the SMC_SITE_NUMBER() API returns 1, 2, 3, or 4 as the site number of the currently tested site.

void SMC_backgroundProcessing(VOID)
{
    INT site = SMC_SITE_NUMBER();

    DSP_RF_MOD_POWER(cData, measParams, site, &measuredPower)
}
