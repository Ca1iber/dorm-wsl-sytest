Pin assignment for Fast Sync / Fast Match

Serial interfaces on many DUTs require non-deterministic handling. Normally they consist of a small number of pins (1, 2 or 4). Fast Sync enables the local synchronization of the test processor (TP). It enables up to 8 sync ports reacting independently on non-deterministic DUT responses per test processor.

Fast Sync / Fast Match is supported for Smart Scale cards:
  • SmarTest 7: AVI64, DPS128, FVI16, PS1600, PS9G, and PVI8
  • SmarTest 8: AVI64, PS1600, PS5000, PS9G, XPS256

The figure below shows an overview of the Fast Sync / Fast Match feature.

Each test processor supports from 1 to 8 local synchronization, which can be applied in parallel on all the test processors. Therefore, for match loops of SmarTest 7 or SmarTest 8 and conditional jumps, it eliminates the overhead caused by site scaling synchronization.

Although the Smart Scale cards use a test processor per-pin architecture, what is meant in this context is the test processor package: Each test processor package contains eight test processor cores, each of which controls one channel.

Note For pins of a DUT belonging to a match loop, they need to be located on the same test processor. For best throughput, try to minimize the number of independent match loops on a test processor.

Instead of 255 sites only, Fast Sync enables non-deterministic device handling for massive multisites (1024 sites).

Pogo pin assignment

For the fast local synchronization, the synchronized DUT pins must be assigned to the same group of channels respectively to the same test processor.

Although the Smart Scale cards use a test processor per-pin architecture, what is meant in this context is the test processor package: Each test processor package contains eight test processor cores, each of which controls one channel.
