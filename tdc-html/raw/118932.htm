Topic 118932

Debugging SmartCalc multithreading code

All features of the debugger such as setting breakpoints and stepping through multithreaded code work with SmartCalc the same way as with any other code. However, DSP calculations of the different sites may not be executed in logical numerical order for example, site 1, may not be the first execution). To avoid this, SmartCalc features can be disabled (see Disabling SmartCalc).

Functional changes

  1. Introduced in SmarTest 6.5.3
