Creating a Digital Source setup (2)

Type, Option, Variable

These parameters define the frame pattern, when Creating a Digital Source setup:

Type

  • Serial: All variables compose a frame.
  • Parallel: Each variable is a frame for each source pin, or each bit of a variable is a frame for each source pin.
  • Custom: Disables all subsequent buttons. In this case click Next to manually modify the vector variable configuration (VVC).

Option

  • LSB first: The least significant bit of the variable appears in the frame pattern first.
  • MSB first: The most significant bit of the variable appears in the frame pattern first.

Variable

Add the required variables. The variables appear in the frame in the order of creation.

Mapping Data

To set the mapping data, select a device cycle or type the physical waveform index for binary data (%x).
