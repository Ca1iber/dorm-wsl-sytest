Solution Tools Update for HX

With HX setup some parameters for pin lists can be set as HX pins. Using the testflow flag debug mode the output in the report window of SmarTest can be reduced for these solution tools:

  • SourceSync
  • DataTraining
  • EyeFinder
  • ParallelShmoo

For more information refer to Configurable output for HX pins in Testing High-Speed Memory Devices.
