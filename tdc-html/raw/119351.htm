Topic 119351

Copying and inserting with Insert Special

Procedure

  1. To insert one vector row, choose Insert Data from first Selected Vector. This duplicates the first vector row that you previously highlighted.
  2. To insert one or more rows, select Insert Data from Paste Buffer (n lines). In this case you must have copied the vector rows in a previous step.
  3. If you want to insert the copied data without any instructions, clear the Include Instructions check box.
  4. In the Repeat Count field, type how often you want the vectors or data to be inserted.
