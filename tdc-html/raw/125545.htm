Topic 125545

TORR (Timing/level Offset Reset Result)

The TORR command resets the offsets for specific timing or level sets to 0.

To configure or retrieve the offsets, see TOCF, TOCF? and TORS?.

In a multisite setup, TORR respects the setup focus (as defined with PSFC).

To reset timing search offsets

TORR {waveform_set|specset_id|"multiport_spec"|PRM|ALL}, {timing_set|PRM|ALL}, {(pinlist)}

To reset level search offsets

TORR {level_set_id|PRM|ALL}, , {(pinlist)}
Note The second parameter must be left empty.

With this command you configure setups of those sites that have the setup focus: For more information, see also: PSFC, PSFC?.

Parameters

waveform_set

Number of a waveform set. Enter PRM for the primary waveform set, or an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by WSUS, WSUS? - (Waveform Sets USed).

specset_id

The source specification ID (single port). It is derived as follows:

100 * equation_set_no + specset_no

multiport_spec

Name of a multiport specification.

Note that the multi-port specification uniquely determines an equation set for every pin of pinlist, because no pin can belong to more than one port within a multi-port specification.

level_set_id

A level set ID. It can be:

  • A fixed level set ID, which is an integer in the range of 1 to the maximum number of level sets which is defined with the DSCP command.
  • An equation based level set ID, which is derived as follows:

    eqnset * 100000 + specset * 1000 + level_set_no

timing_set

A timing set number.

PRM

This refers to the primary waveform set/specification, or to the primary timing set, or to the primary level set, all as defined with SPRM.

ALL

This refers to all fixed waveform sets, timing sets or level sets.

Note that ALL does not apply to equation based timing or level sets.

pinlist

The pins on which the reset action is to be executed.

Application

Embedded timing search

Example

TORR PRM,ALL,(Pin1)

This example resets the offsets for all timing sets of the current primary specification.

Functional changes

  1. Introduced in SmarTest 7.0.3
  2. SmarTest 7.2.1: Supports the reset of level offsets.
