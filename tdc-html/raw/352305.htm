PS1600 pogo cable assembly E8030PHD: 4 HD pogo blocks

The E8030PHD pogo cable assembly connects the 128 channels of a PS1600 card via 4 high-density (HD) pogo blocks to the DUT board.

This pogo cable has one 128-pin connector at one end to connect to the PS1600 card, but four 32-pin pogo blocks at the other end. This allows you to increase your number of pins from 1408 to 2816 using the standard card filling scheme and from 2816 to 4096 pins using the non-standard scheme.

Basic data and pogo block

Pogo block style: 4-row high-density (HD) pogo block
Pogo blocks: 4
Channels per pogo block: 32
Total channels: 128

The inner rows of pogo pins in the high-density pogo block are completely compatible with the standard pogo layout. To use the two outer rows of pins (see below), you must have designed your DUT board appropriately.

Since the four HD pogo blocks combine eight logical boards of 16 channels each, each logical boards represents either the inner rows of each pogo block, for example 101, or the outer rows, for example 501 (see Pin Scale 1600 pogo pin assignment), when using the high-density pogo cable assembly.

The high-density Pin Scale 1600 pogo assembly uses the same pin layout as the standard-density assembly (see above), but in addition it also uses all spare pogo positions making a total of 32 pins per block. Hence, for one PS1600 card, you only need four high density pogo blocks for the 128 pins.
