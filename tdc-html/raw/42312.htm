Using the Provided Hook Function Templates

Subtopics

  2. Description of the Hook Function Templates
  3. Activating a Hook Function
  4. Compiling the Hook Functions Source
  5. Running Hook Functions

In order to simplify the generation of user-specific hook functions, and to ensure that all hook functions use the correct interface (parameters) to communicate with the driver, hook function source files containing a template for each hook function are provided with each plug-in (the templates for each handler driver plug-in are the same, and also the templates for each prober driver plug-in are the same).

The source files are named ph_hhook.c for the general handler driver, and ph_phook.c for the general prober driver. The files are located in the hook subdirectory of each plug-in, for example

/home/user/mydriver/GenericHandler/Seiko-Epson-GPIO/hook/ph_hhook.c

or

/home/user/mydriver/GenericProber/TEL/hook/ph_phook.c

/home/user/mydriver/Generic*/ is the driver directory created as described in Unpacking the Driver and Hook Sources.

To use a hook function, you must

  1. Add the user-specific code which implements the required functionality in the hook function template.
  2. Activate the hook function.
  3. Compile the hook function source file.
  4. Set up your global configuration file to select the plug-in which contains the new hook function.
  5. Select the general equipment driver which you have installed and compiled as described in Preparing a Driver for Hook Function Use as the Prober/Handler driver of the testprogram.

The above steps are described in detail in the following sections.
