DQUE? - (show Data QUEue low level)

The DQUE? query returns the lowest level of the data queue during the last pattern execution.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

Restrictions

  • The query can only be executed online.
  • DQUE? works reliably only if the length of the pattern exceeds 1000 vectors.
  • Since this query is very time consuming you should use it only for debugging purposes.

Syntax

DQUE?{(pinlist)}

returns: 

DQUE {dqueue_level}, {(pinlist)}

Parameters

dqueue_level

A reply parameter specifying the smallest number of 8-vector blocks that was left in the data queue during the last sequencer run for the specified pins

pinlist

The name of the pin or pins for which the lowest data queue level is queried or returned.

Use the @ character to query all pins.

Example

> DQUE? (p1)
< DQUE 26,(p1)

This example queries the low level of the data queue for pin p1.
