TESTSET().testnumber_none()

This member function of TESTSET causes no test number for the current test to be stored in the EDL, even if the test_number_enable testflow flag is enabled.

Syntax

TESTSET & testnumber_none();

Example

TestSet.testnumber_none();

Related information

  2. SmarTest 7.0.3: Removed test number manager
