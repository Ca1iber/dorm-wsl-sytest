DPPS, DPPS? - (Define Per Pin Subroutine label)

The DPPS (Define Per Pin Subroutine label) command is generated by the MTL compiler. Do not attempt to execute it from the hpt utility! The following information is provided to improve your understanding of any hpt output listings you may make. You may execute the query.

The command is used to start the definition of a Per-Pin Sequencer Subroutine. See also the related command DPSA, DPSA? - (Define per Pin Subroutine Address).

DPPS

DPPS {name}, {cycle_len}

DPPS?

DPPS? {name}

returns:

DPPS {name}, {cycle_len}

Parameters

name

Per-pin Subroutine name. This parameter can be used to call the subroutine from a parallel sequencer program.

For the query, you can also enter ALL to return all per pin subroutine label names

cycle_len

Per-pin cycle length.

Application

Per-pin sequencer subroutines.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 7.0.3: DPPS instructions are no longer generated by SINAS, which has been removed from SmarTest
