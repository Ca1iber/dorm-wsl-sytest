SmarTest Program Manager concepts

The operation of SmarTest Program manager (STPM) involves a number of key elements.

Master test program (MTP)

The master test program is the SmarTest testflow that is being modified by STPM.

Source test program (STP)

A source test program is a test program that STPM integrates or removes from the MTP. It consists of a testflow with one or more test suites, which reference test methods and their related timing, level, and vector data.

Test program template (TPT)

A set of tables that STPM can use to create a new MTP. See Test program template for more information.

Commands

Commands are program statements in the control file (see below) that cause STPm to perform a variety of actions, such as adding or removing test, deleting unused elements, saving the edited MTP, and many more. For a full list of commands, see Structure of an STPM control file.

Control file

The control file is a combination of settings for STPM to use and any number of the commands for modifying the MTP (see above).

Control files are much like programs for altering MTPs using specified STPs.

Merge rules file

Merge rules files specify in detail how STPM is to handle the integration of various types of data - such as new sites or new DPS pins - into MTPs.

Each control file specifies a merge rule file to use. Different control files can specify different merge rule files.
