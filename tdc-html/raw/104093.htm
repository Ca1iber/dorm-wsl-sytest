Topic 104093

How to execute a BLC from a HVM client

About this task

Four HVM APIs are defined for the BLC execution: ExecBLC, AbortBLC, PauseBLC and ResumeBLC.

Before you begin

Make sure you are using SmarTest 6.5.0 or above versions.

Procedure

  1. Create a HVM client and call the BLC with the API ExecBLC, AbortBLC, PauseBLC and ResumeBLC.
  2. Make the HVM client as usual.
  3. Execute the HVM client. (See How to Create and Execute the Application Client using HVM API.)

Results

The BLC are executed and the device is tested.

Functional changes

  1. Introduced in SmarTest 6.5.0
