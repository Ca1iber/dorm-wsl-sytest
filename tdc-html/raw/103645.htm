Reusable maintenance operations

In addition to compiling maintenance operations together with the main() routine, they can also be compiled separately and called from other routines.

Reusable maintenance operations can help save sequencer memory because they need to be loaded only once and can be called from any other test pattern.

Reusable maintenance operations are defined just like standard ones, with the one difference that they must reside in their own separate source file, that is, an APG program file not containing a main() routine.

Compiling them requires checking the Create Reusable Device Maintenance Operation option in the compiler control dialog or using the -m compiler switch.

Defining reusable maintenance operations can save very significant amounts of memory compared to non-reusable maintenance operations.

Example

#include "../../device_defs/access_defs/ddr3_operations.inc"

distributed_refresh_routine() 
{
   // Issue a Refresh command.
   Refresh();
   Idle(tRFC-1);
}

allcore_refresh_routine() 
{
   for (x = xStart ; x < xStop; x+=1)
   {
      // Issue a Refresh command.
      Refresh();
      Idle(tRFC-1);
   }
}

Functional changes

  1. Introduced before SmarTest 6.3.2
