Topic 103883

Reconstruction information

Subtopics

  1. Setting up the generation of reconstruction information

Due to the per-pin architecture (as opposed to a bus-centric architecture) of the V93000 system, results are linked to tester cycles instead of memory addresses. To link results to addresses, which is frequently more useful for debugging, the SmarTest result evaluation tools require so-called reconstruction information.

The compiler can create this reconstruction information automatically when properly set up. The necessary setup is described in Setting up the generation of reconstruction information.

MTL creates binary reconstruction files with the file name extension .apg.rec.so.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. MTP 3.0.1: Removed the -r0 option and support for serialized object tree output (.apg.rec files)
