Setting up an existing DPS128 test system to test a new device

To establish the required arrangement of power supply cards and pogo cable assembly types for an existing DPS128-based test system to test a new device, use the Assign Channel ID into table function.

If the device can be tested with the existing DPS128-based test system, the following associated information is displayed:

  • Routing recommendation for power domains
  • Power supply cards used by the solution
  • Domain power consumption
  • Channel assignments

If the device cannot be tested with the existing DPS128-based test system, the following information is provided:

  • Maximum number of sites that can be supported
  • Number of additional DPS128 cards required
  • Recommendations to make alterations to limit values or changes in the model file

You can use this option, for example, to expand and existing test system to handle a greater number of sites while maintaining backward compatibility with your existing test configurations proposal, how many extra DPS128 and which cables are needed. The calculation result specifies how many extra DPS128 cards are required and which cables are needed.

DPS128-based configuration files for model, limits, and pin configurations are used as the inputs for the DPS128 Power Calculator, which calculates the required:

  • DC-Scale cards
  • Pogo cable assembly types
  • power per domain

The recommended card position and detailed information about pin usage is also displayed by the DPS128 Power Calculator.

To calculate the power requirements for the DPS64 and DPS128 cards for the selected device, complete the following steps:

  1. Load the DPS128-compatible, custom model file and the configuration files for limits and pin configuration using the load file browser (File > Load menu items).
    Note

    A custom model file from your existing DPS128-based test system must be used.

    Limits and pin files are optional. You can create a ".csv"-format files, for example, using Microsoft Excel. Alternatively, you can input values and change pin names manually.

    To display which files are currently selected, click Loaded Files.

  2. Optional: Select a global safety margin value from the Margin drop-down.
  3. Specify the number of sites required from:

    Edit > Define Number of Sites

    The Define Site Number window opens from which you can select the required quantity of sites.

    Note The maximum number of DPS128 boards is limited to 8.

    Click OK to confirm the selection.

  4. Optional: Modify pin data in the Pin Data table, if required.
  5. Edit > Assign Channel ID into Table to determine the required DPS128 cards and cable assemblies.

    Domain power results displayed against a green background are within the available power for the selected card. If the available power is exceeded, the power requirement values are displayed on a red background.

    Selections that are within the overall power availability, but cannot provide sufficient power for individual pins, result in the affected pin data being displayed against a red background. For each affected pin, a tooltip provides information about the underlying problem.

    Note Alternative arrangements of cables may also be possible. Change the cable type for a DC-Scale card selection to check for valid alternatives. Selecting a different pogo cable assembly may result in an alternative DC-Scale card selection.
  6. To recalculate the power required for alternative parameters, change the parameters in the Pin Data table and recalculate using Calculate.
    Note When assigning channels to pins, if the maximum board number is exceeded or no valid blocks can be used, the DPS128 Power Calculator displays only the max. site as according to the given model file.
  7. Optional: Export the calculated results in CSV format to a file using the export file browser (File > Export menu).
Note The DPS128 Power Calculator needs to read some information from the model file and the level specifications before the pin configuration can be processed. You should therefore always import the required files in the following order:
  1. File > Load Model
  2. File > Load limit or spec
  3. File > Load Pin
