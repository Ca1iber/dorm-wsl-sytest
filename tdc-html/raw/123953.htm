Scan Cell Name Record (CNR)

A Scan Cell Name Record maps chain and bit positions to cell and flip-flop names. There is a CNR record for each cell requiring mapping, typically for each failing cell and flip-flop.

If a CNR contains mapping for the same chain and bit position as an earlier one, the newer records overrides the earlier one.

The Scan Cell Name Record can appear after the Name Mapping Record (NMR).
