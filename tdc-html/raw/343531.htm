The <dc> element

This element stores the results of a DC test performed by the SmartRDI's dc() class.

The <dc> element stores value test results in its value and burstValue attributes, and waveform test results in its waveform, currentWaveform and voltageWaveform attributes.

The value attribute saves DC value test results returned by a getValue() or getMultiValue() function, while burstValue attribute saves results returned by getBurstValue().

The waveform attribute saves DC waveform test results returned by a getWaveform() function; the voltageWaveform attribute saves DC waveform test results returned by a getVoltageWaveform() function; the currentWaveform attribute saves DC waveform test results returned by a getCurrentWaveform() function.

Get Result Function in SmartRDI

ORE File Syntax Example

double getValue(pin);

 <dc value = "1.23" />

ARRAY_D& getMultiValue(pin);

Multiple entries of <dc value = "1.23"/>

or

<dc multiValue = "-1.22,1.23"/>

<dc multiValue = "./ORE/waveform"/>

ARRAY_D& getBurstValue(pin);

<dc burstValue = "-1.22,1.23" />

or

<dc burstValue = "./ORE/waveform" />

ARRAY_D& getWaveform(pin);

<dc waveform = "-1.22,1.23" />

or

<dc waveform = "./ORE/waveform" />

Examples

DC value results example

Below is an example of the <dc> element with value results and its corresponding SmartRDI code block.
<id name = "dc1">
  <pin name = "DATA2">
    <dc value = "1.2"/>
  </pin>
</id> 
<id name = "dc2">
  <pin name = "DATA2">
    <dc value = "1.5"/>
    <dc burstValue = "2.5,3.0,2.0"/>
  </pin>
</id>
RDI_BEGIN();
  rdi.dc("dc1").pin("DATA2").vMeas().execute();
  rdi.dc("dc2").pin("DATA2").vMeas().execute();
  rdi.dc().pin("DATA2").vMeas().execute();
RDI_END();
...
rdi.id("dc1").getValue();      // 1.2
rdi.id("dc2").getValue();      // 1.5
rdi.id("dc2").getBurstValue(); // {2.5,3.0,2.0}

multiValue attribute and syntax

<id name = "dc1">
  <pin name = "DATA2">
    <dc value = "1.2"/>
    <dc value = "2.6"/>
  </pin>
</id>
<id name = "dc2">
  <pin name = "DATA2">
    <dc multiValue = "2.5,3.0"/>
  </pin>
</id>
RDI_BEGIN();
  rdi.dc("dc1").label("label1")
     .insertSub(2).pin("DATA2").vMeas()
     .insertSub(6).pin("DATA2").vMeas()
     .execute();
  rdi.dc("dc2").label("label2")
     .insertSub(2).pin("DATA2").vMeas()
     .insertSub(6).pin("DATA2").vMeas()
     .execute();
RDI_END();
...
rdi.id("dc1").getMultiValue();   //{1.2,2.6}
rdi.id("dc2").getMultiValue();   //{2.5,3.0}

If the generated ORE template file contains <dc multiValue = ""/>, it will be filled by dc multiValue results. If there is no <dc multiValue= "" /> in the file, getMutliValue() will still get the ORE results from <dc value = "" />.

DC waveform results example

Below is an example of the <dc> element with waveform results and its corresponding SmartRDI code block.

An ORE file containing <dc> elements:

<id name = "dc1">
  <pin name = "AVI1">
    <dc waveform = "./waveform" />
  </pin>
</id> 
<id name = "dc2">  
  <pin name = "AVI2">
    <dc currentWaveform="./wavC" />
    <dc voltageWaveform="./wavV" />
  </pin>
</id>
The corresponding SmartRDI code block:
RDI_BEGIN();
  rdi.dc("dc1").pin("AVI1").vMeas()
     .sample(200).FS(10 kHz).execute();
  rdi.dc("dc2").pin("AVI2").viMeas()
     .sample(200).FS(10 kHz).execute();
RDI_END();
...
rdi.id("dc1").getWaveform("AVI1");
rdi.id("dc2").getCurrentWaveform("AVI2");
rdi.id("dc2").getVoltageWaveform("AVI2");
...
