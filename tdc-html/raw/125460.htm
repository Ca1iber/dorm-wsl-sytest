Topic 125460

Equation system

Subtopics

  1. Level equation file
  2. Timing equation file
  3. Wavetable file

The equation system has been enhanced to allow the use of protocol specific definitions that may be required by a protocol with respect to level and timing setup.

When an equation file is loaded, it will be scanned for a keyword (USE_PROTOCOL) to determine a dependency to a protocol specification. This dependency will be resolved by integrating the referred level or timing equation fragment into the equation system.

As there might be several protocol definitions used with a device setup, the protocol name also needs to be provided in order to identify the referred equation fragment uniquely.

By specifying a dedicated port list the user can decide if an equation fragment is applied to port resources. Omitting the port list leads to the protocol settings being applied to all ports assigned to the referred protocol.

Several USE_PROTOCOL statements can be specified to incorporate equation content blocks accordingly. They can be inserted to either just one or several equation or timing/level sets.

Equation specification values provided with the protocol setup, can be dynamically accessed and changed during test flow execution. During these integration activities, the specifications are read from the protocol timing and level segments and merged into the equation system. For a protocol based test it will be verified that the currently activated primaries are based on protocol-specific setups at run-time. This is done by analyzing a multi-port burst label to determine its contributing (protocol) ports, respectively the protocols the ports are assigned to.

Error handling:

  • If conflicts are found between the specifications within the level/timing file of the device and the protocol level/timing setup file, an error will be reported.
  • If the maximum number of level sets, timing sets or wavetables is exceeded, an error will be reported.
