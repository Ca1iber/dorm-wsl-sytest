User-Specific Code:

User-specific code should be added below the line

#ifdef POPUP_IMPLEMENTED.

The hook function may, for example,

  • present the a dialog window itself, using the modified or unmodified parameters passed from the driver, return PHEVENT_RES_HANDLED, and provide the values for response and input. In this case, the driver will continue without displaying the dialog window.
  • Completely suppress the dialog window by doing nothing and returning PHEVENT_RES_ABORT (this aborts the execution of the current PROB_HND_CALL)
  • Do something, for example, display some extra information in another dialog window, and let the driver display the dialog window as intended by returning PHEVENT_RES_CONTINUE.
