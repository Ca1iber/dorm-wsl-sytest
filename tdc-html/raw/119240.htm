Topic 119240

Selecting 'Level'

Equation-based level setups (see Equation based level setup) are preferred because they give you more flexibility by allowing you to use variables for the definition of level resources.

You can use the "Equation" and "Set" filters to display items whose names include the string you type in the filter box. Note that a dot "." is used as a wild card.

More information about termination is given in Termination mode and Active Load.
