DSP_MUL_VEC

This API is for multiplying the corresponding elements in two arrays.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_MUL_VEC(ARRAY_D& src1, ARRAY_D& src2, 
            ARRAY_D& result);
DSP_MUL_VEC(DOUBLE *src1, DOUBLE *src2, 
            DOUBLE *result, INT size);
DSP_MUL_VEC(ARRAY_COMPLEX& src1, 
            ARRAY_COMPLEX& src2, 
            ARRAY_COMPLEX& result);
DSP_MUL_VEC(COMPLEX *src1, COMPLEX *src2, 
            COMPLEX *result, INT size);
Parameters

I/O

Parameter

Description / Range

I

src1

Multiplicand array

I

src2

Multiplier array

O

result

Multiplication results

I

size

Number of elements to be processed

1 ≤ size ≤ 2097152

size ≤ (size of src1)

size ≤ (size of src2)

size ≤ (size of result)

Example

COMPLEX array1[1024], array2[1024], array3[1024];
     .
     .
DSP_MUL_VEC(array1, array2, array3, 1024);

DSP_MUL_VEC multiplies the first 1024 elements of COMPLEX array array1 by the corresponding 1024 elements of the COMPLEX array array2 , and returns the results to the corresponding 1024 elements of COMPLEX array array3 as follows:

int i;

.

.

for(i=0; i<1024; i++) {

array3[i].real = array1[i].real * array2[i].real - array1[i].imag * array2[i].imag; array3[i].imag = array1[i].real * array2[i].imag + array2[i].real * array1[i].imag;

}
