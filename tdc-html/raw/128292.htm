Modifying an existing protocol definition

Modifying an existing protocol definition follows the steps pointed out in Setting up the protocol definition.

However, there are to different ways to access an existing protocol definition.

Protocol definition is already part of the device setup

In this case simply load the protocol as described in Loading a single setup component. Then follow the procedure outlined in Opening a protocol in the protocol editor and enter your modifications.

Protocol definition is not yet part of the device setup

First you have to import the protocol to your device as described in Importing a protocol. Then open it and carry out your modifications.
