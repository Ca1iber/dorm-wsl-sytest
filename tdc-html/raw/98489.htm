BDID, BDID? - (BoarD ID)

The BDID (BoarD ID) command writes a string into an X24C04 serial EEPROM. Its main purpose is to access the board ID EEPROM. The BDID? query reads the string from the specified EEPROM.

Mode of operation

This command can be used to specify the name of the file that contains the channel attributes for the mounted DUT board.

BDID can only read and write strings. The I2CA command is more flexible.

BDID

BDID {-1|0|2|3}, {"string"}

BDID?

BDID? {-1|0|2|3|ALL}

returns:

BDID {0|2|3}, {"string"}
Parameters

address

Specifies how the value of the string parameter is to be processed. Possible values are:

0,2,3

Writes to or reads from the EEPROM with the specified logical address. These addresses represent the two address lines of the X24C04 EEPROM. The corresponding physical addresses are:

0 = 160 (= 27+ 25)

2 = 168 (= 27+ 25 + 23)

3 = 172 (= 27+ 25 + 23 + 22)

The logical address 0 is the address of the DUT board EEPROM. The logical address 1 = 164 (= 27+ 25 + 22) is reserved for the DUT interface EEPROM.

-1

Interprets the string as a sequence of command characters and executes the commands. This can be used for debugging purposes.

The following characters are valid:

c: Set SCL to low.

C: Set SCL to high.

d: Set SDA to low.

D: Set SDA to high

?: Print state of SDA to report window.

In the query, BDID? returns the state of the SDA when called with -1.

ALL

Searches for an existing EEPROM in descending address order and returns the content of the first EEPROM that it finds (only for the query).

string

The string that is written to or read from the EEPROM. Its maximal length is 255 bytes.

Application

Provide information about the mounted DUT board.

Functional changes

  1. Introduced before SmarTest 6.3.2
