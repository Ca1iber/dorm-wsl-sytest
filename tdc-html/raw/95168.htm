DSP_RF_FFTW()

This function is used to perform a Fast Fourier Transform on captured data, so that time domain information is brought into the frequency domain. In most applications, users will not need to call the DSP_RF_FFTW() function, because the Fast Fourier Transform is performed automatically by other DSP functions, such as DSP_RF_MOD_POWER(). The DSP_RF_FFTW() function is provided for the benefit of users who wish to create their own custom DSP routines within a TestMethod, and therefore need direct access to an FFT function.

This function does not return an array; the captured data (an array of complex numbers) is converted "in place".

This function does not correct the data to place the center frequency in the middle of the spectrum rather than at 0 Hz, nor does it reverse the spectrum in cases where the LO is higher than the carrier frequency. To make those correction to the data, it is necessary to use the DSP_RF_SWAP() function.

An alternative function is available which converts the captured data to the frequency domain, converts it to an array of doubles representing the spectrum, and performs the spectrum corrections referred to above; see the DSP_RF_SPECTRUM function.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

Syntax

DSP_RF_FFTW (const ARRAY_COMPLEX & source_data,
 ARRAY_COMPLEX & resultData,
 const INT windowFunction)
Parameters

I/O

Parameter

Notes

I

sourceData

A complex array representing the captured waveform data in the time domain.

O

resultData

A complex array representing the frequency domain data produced by the FFT function.

I

windowFunction

Choose the window function to be applied by the DSP_RF_FFTW() function. The choices are:

RECT (Rectangular window)

HANNING (Hanning window)

HAMMING (Hamming window)

FLAT_TOP (Flat-top window)

FBLACKMAN (Blackman window)

See Window functions.

Example

ARRAY_COMPLEX cData = MEAS_DEF("myModPwrMeas").getComplexWaveform();
ARRAY_COMPLEX fftwData(cData.size());
DSP_RF_FFTW(cData, fftwData, RECT);
