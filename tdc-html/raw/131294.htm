MTP_DPS_MEASURE.samples()

The samples() member function of MTP_DPS_MEASURE lets you specify the number of measurements to be averaged.

Syntax

MTP_DPS_MEASURE & samples(size_t samples)

Parameter

Description

samples

The number of measurements to be averaged. This must be a positive integer. (Default is 1)

Note that the real measurement numbers can be different from the value specified here. For an explanation of the details, see DPS_TASK & samples().
