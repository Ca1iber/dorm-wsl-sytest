Displaying array variables

You must view a test method in the C/C++ editor and must have executed it.

In the Editor view, select the desired variable. The content of the variable is displayed in the Waveform view; the variable's name and type are displayed in the title bar.

Supported variable types include:

  • int[ ], unsigned int[ ], short[ ], long[ ], unsigned short[ ], and unsigned long[ ]
  • double[ ] and long double [ ]
  • float[ ]
  • ARRAY_D
  • ARRAY_I

If you select a variable of an unsupported type, it's contents will not be displayed in the Waveform view.
