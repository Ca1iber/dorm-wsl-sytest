Memory Test Execution Guide

The process of analyzing error data is improved by introducing a new tool, the Memory Test Viewer.

Benefit

This tool enables the user to navigate to a device specific data log file and select specific device error data. This data can be reconstructed and viewed with the Bit Fail Map Viewer.

More Info

For details see The Memory Test Viewer in Testing High-Speed Memory Devices.
