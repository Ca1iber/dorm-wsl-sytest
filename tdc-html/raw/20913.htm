Topic 20913

Setting Flags

To set the flags such as testflow flags, system flags, and testsuite flags, you can use the following APIs.

The task to be executed....

Use this API....

Provide access to the testflow flag

SET_TESTFLOW_FLAG(params)

Provide access to the system flag

SET_SYSTEM_FLAG(params)

Provide access to the testsuite flag

SET_TESTSUITE_FLAG(params)
Note params means the parameters to be specified.

Change of any flag state will be valid when the next testsuite is executed.

For details, see SET_TESTFLOW_FLAG, SET_SYSTEM_FLAG, and SET_TESTSUITE_FLAG.
