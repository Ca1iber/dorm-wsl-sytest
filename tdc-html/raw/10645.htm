Example of a Fixed Level Setup File

Note The support for fixed level setups is discontinued with SmarTest version 7.4.1T. We recommend using the Equation based level setup for all releases of SmarTest 7.2 or higher versions.

The following example shows a levels file for a fixed level setup.

hp93330,level,0.1
PSLV 1,-4.5,0.4,HIZ,10,(Vee) - set Power Supply LeVels
DRLV 1,-1700,-950,(CP,D3,D0_NCET,MR,NCEP,P3,P2,P1,P0,S2,S1,S0)-set DRiver LeVels
RCLV 1,-1300,-750,(NQ3,NQ2,NQ1,NQ0,NTC,Q3,Q2,Q1,Q0) - set ReCeiver LeVels
TERM 1,a,-800,3000,4000,I5E3,I5E3,(Q0,Q1,Q2,Q3) - set TERMination mode
