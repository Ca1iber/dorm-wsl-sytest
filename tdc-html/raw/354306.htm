XPS256 programming - Force and clamp currents

Each channel of an XPS256 card features six combined force, clamp, and measure current ranges.

The XPS256 channels feature a real current force mode (CF) with programmable voltage clamp. Other DC Scale cards utilize the current clamp in voltage force mode.

Current ranges

Each PMU features six combined force, clamp, and measure current ranges:

Variant Range Minimum and maximum current
XPS256 1 A -1.0 A ... 1.0 A
100 mA -100.0 mA ... 100.0 mA
10 mA -10.0 mA ... 10.0 mA
1 mA -1.0 mA ... 1.0 mA
100 μA -100.0 μA ... 100.0 μA
10 μA -10.0 μA ... 10.0 μA

The current ranges are common for forcing, clamping, and measuring currents. The force or clamp range is always the same as the measurement range. For specification data, refer to XPS256 voltage specifications.

Minimum clamp current distance

The PMU of an XPS256 channel needs a minimum distance between the positive and negative clamp current to avoid oscillation.
Variant Current range Minimum clamp value Minimum clamp distance
XPS256 1 A 10 mA 100 mA
100 mA 1 mA 10 mA
10 mA 100 μA 1 mA
1 mA 10 μA 100 μA
100 μA 1 μA 10 μA
10 μA 100 nA 1 μA

The minimum clamp distance is the distance from the minimum negative clamp value to the minimum positive clamp value. Asymmetrical clamp current definitions within the ranges defined above are supported as long as the minimum clamp distance between the two values is maintained. For clamp current specifications, refer to table Current clamp in XPS256 current specifications.

Dynamic behavior in force current or clamp current mode

The following force current filters are available for an XPS256 channel:

  • Current bandwidth

    This value defines a current bandwidth that has an effect on the dynamic behavior of an XPS256 channel that is forcing or clamping the current.

    Range Min Max Default
    All current ranges 10 Hz 500 kHz 10 kHz
  • Current slew rate

    The parameter defines the slew rate for changes of the programmed current force value.

    Range Min Max Default
    1 A 10.0 μA/μs 200.0 mA/μs 10.0 mA/μs
    100 mA 1.0 μA/μs 20.0 mA/μs 10.0 mA/μs
    10 mA 100.0 nA/μs 2.0 mA/μs 2.0 mA/μs
    1 mA 10.0 nA/μs 200.0 μA/μs 200.0 μA/μs
    100 μA 1.0 nA/μs 20.0 μA/μs 20.0 μA/μs
    10 μA 100.0 pA/μs 2.0 μA/μs 2.0 μA/μs

    The values defined in the table above apply for a single channel. For ganging groups, the current slew rate of the 1 A range can be multiplied by the number of ganged channels.

Note The following units are to be used for programming the force current filters:
Current bandwidth: Hz (Hertz)
Current slew rate: A / μs (Ampere per microsecond)

DC Scale voltage and current limits

The XPS256 card supports the DC Scale voltage and current limits. SmarTest ensures that the defined voltage and current limits cannot be exceeded by programming higher or lower force or clamp values.

SmartRDI overview

Forcing or clamping a current can be set up by the dc() API of SmartRDI. Both the code‑based mode and the pattern‑based mode are supported. For more information refer to Setting up DC Scale pins with SmartRDI and the related member functions of the API.

SmartRDI supports also setting up DC resources like a real AWG. For more information refer to Using DC resource as AWG with SmartRDI.

API overview

The complete functionality to set up an XPS256 pin to force or clamp currents is covered by APIs SPMU_TASK and SPMU_PIN_TASK for an XPS256 pin in PMU operating mode or by the Equation based level setup for an XPS256 pin in DPS operating mode.

Pattern‑based setups are supported by DC events. For information on how to set up the XPS256 in the AWG mode refer to XPS256 programming - AWG.
