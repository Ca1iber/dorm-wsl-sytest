Running the fd_merge tool to merge fixture delay files

This task describes the use of the fixture delay file merge tool.

About this task

Fixture delay measured on a multi-site fixture produces a number of fixture delay files. These files need to be merged into one fixture delay file that gets used during device testing. To facilitate the merging, a merge tool is provided by Advantest in the driver sharing section of the DDR solution tools.

Before you begin

The merge tool needs the fixture delay files and a sharing configuration file as input files. Prepare these file first.

Procedure

  1. Create a directory, for example /home/demo/fd_merge_test.
  2. Copy your delay files, the config file and the pin_config file specified in the config file to that directory.
  3. Make this directory current in a terminal window and enter this command: 
    opt/93000mts/ddr_solution_tools/DriverSharing/bin/fd_merge.pl <options>

    For a list of available options, see Fd_merge tool.

Results

A merged fixture delay file is generated and a report is displayed.

Example

fd_merge.pl -c config -o fd_output -l fixture_delay_site2_with_load -f fixture_delay_site2_no_load -V 1

The config file contains:

pin_configuration:
pin_config.pin HSM3600

fixture_delay_files:
fixture_delay_site1
fixture_delay_site2

daisy_chain: 2
1  2
4  3

In the directory where you stored the input files you will find a file: fd_output.

What to do next

Store the output file in the ch_attributes directory. This file will be referenced in the test flow as the FXDL file.
