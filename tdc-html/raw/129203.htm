SHARED_IDD_TEST.vdd()

The vdd() member function of SHARED_IDD_TEST lets you specify the power supply pin used.

Syntax

SHARED_IDD_TEST& vdd(const string& pinlist)

Parameter

Description

pinlist

Pin list of VDD used.

This parameter is ignored for DPS-shared load boards for which there is a utility_control section in the Sharing configuration file.

Example

SHARED_IDD_TEST mTest;
mTest.vdd("VDD");

Related information

SHARED_IDD_TEST

Functional changes

  1. Introduced in MTP 3.1.3
