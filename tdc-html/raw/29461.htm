GPIB_ENTER_B

This API gets data from the specified device and stores the binary data into specified variable, and returns 0 on success, non-zero when timeout occurred.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/GpibMapi.h.

For getting data as STRING type:

INT GPIB_ENTER_B(INT address, STRING *result_s,
 INT num_of_data, INT length);

INT GPIB_ENTER_B(INT address, INT address2, 
 STRING *result_s, INT num_of_data,
 INT length);

For getting data as DOUBLE type:

INT GPIB_ENTER_B(INT address, DOUBLE *result_d, 
 INT num_of_data, INT length);

INT GPIB_ENTER_B(INT address, INT address2, 
 DOUBLE *result_d, INT num_of_data, 
 INT length);
Parameters

I/O

Parameter

Description / Range

I

address

GPIB address (or primary GPIB address) of target devices.

Range: 0 to 30 [except 21]

I

address2

(Optional)

GPIB secondary address of target device.

Range: 0 to 30

Default: -1 (Secondary address is not specified)

I

num_of_data

 

Number of data to get from target device(1 to 2147483647). This parameter is required to receive multiple data blocks.

I

length

(Optional)

Number of bytes for a data block. This is used to split a data block into multiple data blocks.

For STRING type, 1 to 256 can be specified.

For DOUBLE type, either 8(Default) or 4 can be specified.

O

result_s

result_d

Pointer for the variable that stores the returned values.

These are used for the data of char type and DOUBLE type respectively

Important points

  • To receive numeric data based on IEEE 754-1985, set the "length" parameter to 8 (for double type) or 4 (for float type) and store it into the DOUBLE type variable (result_d). Received data are converted into DOUBLE type value based on IEEE 754-1985.
  • To receive numeric data not based on the IEEE 754-1985, or STRING type data, set the "length" parameter to desired value and store it into the STRING type variable (result_s). Received data are stored as STRING type value.
  • In the offline mode, this API sets 0 to the output parameter, "result_d" and "result_s".

Examples

Example 1

INT address = 17;
INT num_of_data = 48; 
INT length = 8;
DOUBLE result[48];
GPIB_ENTER_B(address, result, num_of_data, length );

The GPIB_ENTER_B API receives 48 data blocks of data sent from the device at address 17, and stores it into the DOUBLE type array. The data is assumed to be numeric data based on IEEE 754-1985.

Example 2

INT address = 17;
INT num_of_data = 48; 
INT length = 12;
STRING result[48];
GPIB_ENTER_B(address, result, num_of_data, length );

The GPIB_ENTER_B API receives 48 data blocks of data sent from the device at address 17, and stores it into the STRING type array. The length of a data block is set to 12.
