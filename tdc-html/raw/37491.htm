Topic 37491

Mapping State Characters to Waveform DC/DC power units: The FIXMAP Section

Subtopics

  1. Structure of the FIXMAP Section

By default, the DC/DC power units of the physical waveforms created from the ASCII timing file definitions are assigned automatically by the timing translation. There can be situations, however, where it is useful to fix the physical waveform DC/DC power units for the state characters of one or more ASCII device cycles. For example, if you want to apply a new timing to an already translated vector setup, you can avoid retranslating the vector files if you can force the timing translation to use the same mapping of state characters to waveform DC/DC power units as in the previous translation. This can be achieved by inserting a FIXMAP section into the ASCII timing file.

A FIXMAP section includes one or more ASCII device cycles and a mapping of state characters to physical waveform DC/DC power units for every state character occurring in any of these ASCII device cycles. The timing translation will then use these DC/DC power units in the wavetable as well as in the timing map files.

Note that the FIXMAP section cannot be used with an x-mode factor > 1.
