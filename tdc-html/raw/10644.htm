Topic 10644

Set Fixed Power Supply Levels

Note The support for fixed level setups is discontinued with SmarTest version 7.4.1T. We recommend using the Equation based level setup for all releases of SmarTest 7.2 or higher versions.

You can create multiple DPS sets up to the maximum number previously defined by DSCP, DSCP? - (Define System Control Parameter). Each DPS set contains the power supply requirements for one part of your test. At power-on, one DPS set exists, containing the default DPS levels. This set is identified as DPS set 1.

The commands associated with creating a DPS set are as follows:

  • DSUS, DSUS? - (Dps Sets USed)
  • PSLV, PSLV? - (Power Supply LeVel)

Before creating a DPS set, use the DSUS? query to determine the maximum number of sets currently in use. You can then identify the new set using the next available number. The firmware is then updated to include the new number of sets currently in use.

PSLV and PSLV? set and read the DPS output voltage and current limit settings for the specified DPS set. In addition you can specify a setup time which causes the system to wait before the next command is executed.

You can also specify high or low off-state impedance. This sets the DPS outputs when the system is disconnected. Selecting low off-state impedance leaves the DPS at the active (connected) state. Selecting high off-state impedance programs the DPS current limit to the minimum value (close to zero).
