Force Cycle Oriented Mode

In the Force Cycle Oriented Mode, the Overview tab displays the cycle blocks that are also recorded in the detailed error map in normal size, all the others will be shrunk. If the detailed error map is located within the test processor, shrunk blocks will be present for any tests that comprise more than 8K cycles.

Note If the Force Cycle Oriented mode is activated and the number of the following cycles after the initial point is not enough to fill the whole 8K memory a number of cycles in front of the selected cell (cursor position) will be used to fill the whole 8K memory with cycle data.

The advantage of the Force Cycle Oriented Mode when executing a functional test is the very fast acquisition of error information.

For more information, see Analyzing Data in Cycle Oriented or Failure Oriented Mode.
