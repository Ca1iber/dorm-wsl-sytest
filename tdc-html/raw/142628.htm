Bit Fail Map Viewer

Some new features are implemented in the Bit Fail Map Viewer:

  • Start the viewer using the graphical interface "Memory Test Manager" instead of command line input (see Starting the BFM Viewer).
  • Additional column in file list shows all layers a file is already assigned to (see Bit Fail Maps).
  • Online and context help is available.
  • shortcut menu in layer assignment helps to locate files in file list (see Bit Fail Maps).
