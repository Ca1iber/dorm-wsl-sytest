Creating Java dump file if SmarTest shows a hang-up

Use is procedure only if SmarTest did not crash, but hangs up. If SmarTest crashed, go to Collecting log files if SmarTest crashed.

About this task

The following command writes the JVM pid and the stack, to the file JVM_dump.log, which you send to the Advantest service representative to get further support.

Procedure

  1. Open a terminal window
  2. Save the Java process ID and the stack information to the file JVM_dump.log

    jps -l | grep eclipseRE | grep '[0-9]*' -o | xargs bash -c 'jstack -l $1; echo JVM pid: $1' argv0 > JVM_dump.log

  3. Send the JVM_dump.log fileto the Advantest service representative.
