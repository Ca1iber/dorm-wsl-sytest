Creating a Digital Source setup (1)

Data Pattern

Main: Specifies the preselected pattern (type Main) as a digital source (DSRC) pattern for a FLAT DSM setup.

NEW: Creates a new digital source (DSRC) pattern for the source data.

Re-Use: Selects an existing DSRC pattern, containing the source data.

Pins and Matching Port

The list of source pins must match exactly with the selected port.

Offset

Specifies the offset to the first vector in the DSRC pattern. For the first VVC (vector variable configuration) usage for the selected DSRC pattern, the offset must be 0.

Number of Frames

The number of frames is used to allocate the source memory.
