STRING_VECTOR

Defines a vector containing string elements. Vector is a standard C++ container. A STRING_VECTOR variable can be processed with all the member functions of a vector.

With the member functions you can query the capacity, access the elements and modify the elements of the vectors. You can find all the member functions of the vector here http://www.cplusplus.com/reference/stl/vector/.

Example

STRING pinList  = "pin1,pin2,pin3";
STRING_VECTOR pinNameList;
pinNameList = PinUtility.getDigitalPinNamesFromPinList(pinList, TM::IO_PIN, TRUE,TRUE);
for (uint index = 0; index < pinNameList.size(); index++)
{
     cout << pinNameList [index] << endl;
      // pin1
      // pin2
      // pin3
}
