Collision handling for the level master file

The collision that may happen in the level master file is the equation set number collision. The setup management tool can handle the collision automatically. You can also manually resolve the collision.

If you want the setup management tool to handle the collision automatically, the later collision equation set number will be changed to the smallest usable number with the REMAP keyword according to the renaming strategy.

If you want to handle the collision manually, you can define the target equation set number with the REMAP keyword.

If you create new collisions when re-mapping manually, the setup management tool can automatically handle the new collisions according to the renaming strategy.

Split strategy

When you split the loaded setup file according to the level master file, the EQNSET number in the sub-setup files will follow the left column number of the master file.

For example,

EQNSET 1[REMAP 3]: ../../rf/levels/eqnset_01.lev

EQNSET 3 in the combination setup file will be changed to EQNSET 1 of ../../rf/levels/eqnset_01.lev.

Examples

Example1

The original level master file looks like below:

Tester File: combination.lev
EQNSET 1: ../../usb/levels/eqnset_01.lev
EQNSET 1: ../../rf/levels/eqnset_01.lev
EQNSET 3: ../../rf/levels/eqnset_03.lev
  • After the automatic collision handling, it will be changed to:
    Tester File: combination.lev
EQNSET 1: ../../usb/levels/eqnset_01.lev
EQNSET 1[REMAP 2]: ../../rf/levels/eqnset_01.lev
EQNSET 3: ../../rf/levels/eqnset_03.lev
  • You can re-map the collision equation set number to another one like below:
    Tester File: combination.lev
EQNSET 1: ../../usb/levels/eqnset_01.lev
EQNSET 1[REMAP 4]: ../../rf/levels/eqnset_01.lev
EQNSET 3: ../../rf/levels/eqnset_03.lev

Example 2

If you create a new collision when re-mapping manually like below:

Tester File: combination.lev
EQNSET 1: ../../usb/levels/eqnset_01.lev
EQNSET 1[REMAP 3]: ../../rf/levels/eqnset_01.lev
EQNSET 3: ../../rf/levels/eqnset_03.lev
  • After the automatic collision handling, it will be changed to:
    Tester File: combination.lev
EQNSET 1: ../../usb/levels/eqnset_01.lev
EQNSET 1[REMAP 3]: ../../rf/levels/eqnset_01.lev
EQNSET 3[REMAP 2]: ../../rf/levels/eqnset_03.lev
