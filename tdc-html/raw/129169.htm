SHARED_CONTINUITY_TEST.supplyDPS()

The supplyDPS() member function of SHARED_CONTINUITY_TEST lets you specify all the power supply voltage DPS pins used.

Syntax

SHARED_CONTINUITY_TEST& supplyDPS(const string& dps)

Parameter

Description

dps

Pin lists of all the power supply DPS pins used.

Separate multiple DPS pins with commas.

This parameter is ignored for DPS-shared load boards for which there is a utility_control section in the Sharing configuration file.

Example

SHARED_CONTINUITY_TEST mTest;
mTest.supplyDPS("VDD");
mTest.supplyDPS("VDD, VDDQ");
