GPIB_SPOLL

This API gets the serial poll response from the specified device, and returns 0 on success, non-zero when timeout occurred.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/GpibMapi.h.

Syntax

INT GPIB_SPOLL(INT address, INT *result);
INT GPIB_SPOLL(INT address, INT address2, 
 INT *result);
Parameters

I/O

Parameter

Description / Range

I

address

GPIB address (or primary GPIB address) of target devices.

Range: 0 to 30 [except 21]

I

address2

(Optional)

GPIB secondary address of target device.

Range: 0 to 30 [except 21]

Default: -1 (Secondary address is not specified)

O

result

Serial poll response return value.

Return value of this parameter is device-dependent.

(See the manual of each device)

Example

#define STOP_BIT 0x01
INT result;
INT address = 17;
GPIB_SPOLL(address, &result);
if (result & STOP_BIT);
 cout << "Device Stopped.";

The GPIB_SPOLL API gets the serial poll response of the device at address 17. STOP_BIT is defined as 0x01 and if result = 1, the message is displayed to stdout.
