Creating a new utility purpose

  1. In the Test Program Explorer, right-click the Utility Purpose entry of the pin configuration section and choose New.
  2. In the New Utility Purpose dialog, enter the name of the new utility purpose.

    Names can be up to 16 characters long and must not contain the characters: # ; ( '' ) ? @ ,

  3. Click OK.
