Data log flags for STDF

The log_events_enable system flag must be set in order to generate STDF.

The following test suite flags are optional and impact the content of the STDF. For more information about these flags and their use, refer to Appendix A: Data Logging Flags.

Test suite flags:

  • output_on_pass
  • output_on_fail
  • pass_value
  • fail_value
  • per_pin_on_pass
  • per_pin_on_fail
