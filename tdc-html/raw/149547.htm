SmartRDI provides many tool functions. This chapter describes how to use these tools functions.

These tool functions are:

  • Functions related to global variables: These functions allow you to share values cross test suites.
    • setGlobalVar()
    • getGlobalVar()
  • dtos(): Convert a double value to a string.
  • itos(): Convert an integer value to a string.
  • itos_hex(): Convert an integer value to a hexadecimal value.
  • reverseBits(): Reverse bits from MSB-LSB to LSB-MSB.
