getListOfSigGenStandards()

This method retrieves the list of supported standards.

Syntax

static void getListOfSigGenStandards(STRING_VECTOR& standards);
Parameter

Parameter

Description

standards

Supported standards as STRING_VECTOR

Return value

A list of supported standards.

Examples

Example 1

STRING_VECTOR stds;
SIGNAL_GEN::getListOfSigGenStandards(stds);
for (unsigned int i=0; i<stds.size(); i++) {
    cout << stds[i] << endl;
}
