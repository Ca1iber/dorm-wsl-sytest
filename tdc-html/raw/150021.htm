DPS_AUX_PIN_TASK.checkPowerFlags()

Reads the accumulated power supply status flags from the hardware. The flags are supported by DC Scale cards in DPS operating mode, in PMU operating mode.

The member function reads the flags from all active sites. Refer to DPS power flags - get...() functions for more information regarding the supported flags and the meaning of the flags.

Note The flags are latched in the hardware. Reading the state will return the latched state and clear only the read flags. The flags are immediately set again if the triggering condition is still active. The member function must therefore be called twice to read the actual state.
Note Pass / fail results that are retrieved by command PRLT are invalidated by commands CSAS and PSAS. We recommend therefore using the command PRLT directly after the related functional test and before command CSAS or PSAS are performed. This behavior applies not only to the commands but also to the related APIs: Function GET_FUNCTIONAL_RESULT() must be performed before any of the DPS_AUX_PIN_TASK.check...() functions is called or the results of GET_FUNCTIONAL_RESULT() are invalid.

Syntax

DPS_AUX_PIN_TASK& checkPowerFlags(TM::POWER_FLAG flags = TM::ALL_FLAGS);
Parameter
Parameter Description
flags The optional parameter defines a read mask for the power supply flags.

The default value is TM::ALL_FLAGS.
Available options of parameter: flags
Option Description
TM::ALL_FLAGS Enables all flags for reading.

This is the default value.

TM::CONST_VOLTAGE

TM::CONST_CURRENT

TM::UNREGULATED

TM::OVER_VOLTAGE

TM::OVER_CURRENT

TM::OVER_TEMPERATURE

TM::VOL_DROP_FORCE

TM::VOL_DROP_RETURN

TM::DUTBOARD_DISCON

TM::SAFETY_LINE

TM::CONST_CURR_LIMIT_DISCON

TM::LOW_HEADROOM

TM::CURR_LIMIT_PROTECT_DELE

TM::RANGE_OVERFLOW

TM::CLAMP_DISTANCE_TOO_LOW

TM::VOL_DROP_FORCE_WARN

TM::VOL_DROP_RETURN_WARN

 Enables only the selected flag for reading.

Refer to DPS power flags - get...() functions for more information.

Return value

A reference to the corresponding DPS_AUX_PIN_TASK object.

For retrieving the read result see DPS power flags - get...() functions.

Example

The following example reads the actual state of all power flags, clears all flags and evaluates the state of all flags except the "Constant Voltage" flag. The returned value is set to TM::POWER_FLAG_STATUS_FAIL if minimum one of the checked flags is set.

DPS_AUX_TASK dpsAuxTask_1;

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Read actual power flag status of two pins
    //
    dpsAuxTask_1.pin("dps1,dps2").checkPowerFlags(); // Read latched state & clear all flags
    dpsAuxTask_1.pin("dps1,dps2").checkPowerFlags(); // Read actual state & clear all flags
}
ON_FIRST_INVOCATION_END();

//
// Evaluate the state of the first pin
//
if (dpsAuxTask_1.getStatusWithoutConstVol("dps1") == TM::POWER_FLAG_STATUS_PASS)
{
    cout << "dpsAuxTask_1.getStatusWithoutConstVol(\"dps1\") returned TM::POWER_FLAG_STATUS_PASS" << endl;
}
else
{
    cout << "dpsAuxTask_1.getStatusWithoutConstVol(\"dps1\") returned TM::POWER_FLAG_STATUS_FAIL" << endl;
}

return;

The next example reads, clears and evaluates the latched state of the "Low Headroom" flag. The other flags are not cleared or evaluated.

DPS_AUX_TASK dpsAuxTask_2;

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Read and clear latched low headroom flag of two pins
    //
    dpsAuxTask_2.pin("dps1,dps2").checkPowerFlags(TM::LOW_HEADROOM);
}
ON_FIRST_INVOCATION_END();

//
// Evaluate the state of the first pin
//
if (dpsAuxTask_2.getLowHeadroom("dps1") == TM::POWER_FLAG_STATUS_PASS)
{
    cout << "dpsAuxTask_2.getLowHeadroom(\"dps1\") returned TM::POWER_FLAG_STATUS_PASS" << endl;
}
else
{
    cout << "dpsAuxTask_2.getLowHeadroom(\"dps1\") returned TM::POWER_FLAG_STATUS_FAIL" << endl;
}

return;
