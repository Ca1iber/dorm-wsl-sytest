Several APIs are provided to handle the following special events.

These special events are

  • Reprobe: when the device is categorized to a bin which is labeled as reprobe.
  • Pause: when the pause button on the operation control panel is pushed.
  • Abort: when the abort button on the operation control panel is pushed.
  • Reset: when the reset button on the operation control panel is pushed.
  • Level end: when a level completes.
  • Retest Device: when the retest_d button on the application model pause dialog is clicked.
  • Check Device: when the check_dev button on the application model pause dialog is clicked.
  • Retest Wafer: when retest_w button on the application model pause dialog is clicked.
  • Reference Wafer: when the reference button on the application model pause dialog is clicked.

To handle these events, BLC will initiatively query the system status periodically to see if certain events happen and then take actions accordingly.

The following table shows the BLC APIs defined to handle the special events.

Event

BLC API

Current application model behaviors

Reprobe

SetReprobeAction()

Once the device is binned to a reprobe bin, the testflow execution engine FTEST will call the CI function which is registered by the application model keyword REPROBE_ACTION.

Pause

IsPaused()

Pop up a dialog and wait for the operator's intervention if a dialog is specified in the PAUSE section; if no dialog is specified, the test will also be paused until the operator pushed the Pause button again.

Abort

IsInterrupted()

Abort the execution of the test program.

Reset

IsInterrupted()

Abort the execution of the test program.

Level End

IsLotDone()

IsCassetteDone()

IsWaferDone()

IsDeviceDone()

The current generic Prober/Handler driver sets a flag when the driver thinks the test of a lot, wafer, cassette or device level is finished. Application model will exit the current level if this production flag is set.

Retest Device

SetSpecialBLCTestEnv()

Set the production flag to retest the device and then give the control to the testflow execution engine (FTEST) and the handler driver. FTEST will update the bin counting information based on the flag. The prober/handler driver will not get new devices since it is in a retest device cycle.

Check Device

SetSpecialBLCTestEnv()

Set the flag to check the device and then give the control to the testflow execution engine (FTEST) and the prober/handler driver. FTEST will update the bin counting information based on the flag. The handler driver will not get new devices since it is in a check device cycle.

Retest Wafer

SetSpecialBLCTestEnv()

Set the production flag to retest the wafer, jump out the die test level loop, and then restart the test of the wafer. The prober will keep the current wafer.

Reference Wafer

SetSpecialBLCTestEnv()

Set the production flag to reference a wafer, jump out the die test level loop, and then restart the test of the wafer. The prober will load the reference wafer.
