Topic 123830

Configuring general parameters

About this task

This task describes the modifications of the general parameters you need to carry out in your protocol file, for example d2sJTAG.h .

Before you begin

Rename the d2sSerialProtocolTemplate.h template to reflect your protocol, for example. d2sJTAG.h .

Procedure

  1. Replace all occurrences of d2sSerialProtocolTemplate with the name of your protocol, for example d2sJTAG.
    Note Ensure to only replace the identical string, by enabling case sensitive search.
  2. Specify the port to which the protocol shall be applied. Replace the string "sbiA" in the template code line: 
    static d2sJTAG instance("sbiA");

    Specify either the default port "@" for single port setups, or the corresponding port name, for example "sbiA", "sbiParallel" or "my_d2sPort".

  3. Enter the address and data bits to match our protocol.
  4. Enter the physical waveform DC/DC power units matching our waveform table.
  5. Specify the interface name that is used to prefix the generated patterns. You can either keep the default, or replace the string "PA" in the template code line by a prefix of your choice, for example "my_PA". 
    std::string getInterfaceName(){ return "PA";}
  6. Specify the path where the generated patterns are to be stored. You can either keep the default, or replace the path "d2s_Extended/sbiA" in the template code line by a path of your choice, for example "d2s/my_sbiA". 
    std::string getPatternStoragePath() { return "d2s_Extended/sbiA"; }

    Note that the path is always relative to the vectors directory of the current device. If the specified folder does not exist, it will be created.

Example

This example defines 6 address bits and 16 data bits as shown in the figures of topic Prepare device setup. The corresponding wavetable shows:

PINS  di
  0   "d1:F00 r1:X"  0  
  1   "d1:F10 r1:X"  1
  2   "d1:FNZ r1:L"  L
  3   "d1:FNZ r1:H"  H
  4   "d1:FNZ r1:X"  X
  brk "d1:F00"

The above data is highlighted in bold in this d2sJTAG.h file example.

#ifndef D2SSERIALPROTOCOLTEMPLATE_H_
#define D2SSERIALPROTOCOLTEMPLATE_H_
#include "d2s_Serial.h"

class d2sSerialProtocolTemplate : public d2s_Serial{
private:
    // step 1
    d2sJTAG(std::string pName):d2s_Serial(pName){};
    d2sJTAG(const d2sJTAG&);
    d2sJTAG& operator= (const d2sJTAG&);

public:    
    //singleton
    static d2sJTAG& Instance(){
        // step 2
        static d2sJTAG instance("my_d2sPort");
        d2sJTAG& ref = instance;
        return ref;
    }
    
    /*general parameters*/
    // step 3
    int getAddressBits(){ return 6;}
    int getDataBits(){ return 16;}

    // step 4
    int getHighWaveformIndex(){ return 1;}
    int getLowWaveformIndex(){ return 0;}
    int getHighStrobeWaveformIndex(){ return 3;}
    int getLowStrobeWaveformIndex(){ return 2;}
    int getMaskStrobeWaveformIndex(){ return 4;}

    // step 5
    std::string getInterfaceName(){ return "my_PA";}
    
    // step 6
    std::string getPatternStoragePath() { return "d2s/my_sbiA"; }


    /*write parameters*/
    std::string getWriteTemplatePatternName(){ return "d2s_sbiA_write_template";}
    std::string getWritePinName() { return "di_A";}
    int getWriteAddressVectorNumberLSB(){ return 8;}
    int getWriteAddressVectorNumberMSB(){ return 3;}
    int getWriteDataVectorNumberLSB(){ return 24;}
    int getWriteDataVectorNumberMSB(){ return 9;}  

    /*read parameters*/
    std::string getReadTemplatePatternName(){ return "d2s_sbiA_read_template";}
    std::string getReadAddressPinName() { return "di_A";}
    std::string getReadPinName() { return "do_A";}    
    int getReadAddressVectorNumberLSB(){ return 8;}
    int getReadAddressVectorNumberMSB(){ return 3;}
    int getReadDataCycleNumberLSB(){ return 24;}
    int getReadDataCycleNumberMSB(){ return 9;}
    int getReadDataVectorNumberLSB(){ return 24;}
    int getReadDataVectorNumberMSB(){ return 9;} 
    
    /*wait parameters*/
    std::string getTimingPort(){ return "@";}
    std::string getWaitTemplatePatternName(){ return "d2s_sbiA_wait_template";}
};

#endif
