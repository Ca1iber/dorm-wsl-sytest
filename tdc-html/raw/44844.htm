Additional Information

Subtopics

  1. Writing a Program with more than one Sourcefile

CPI functions are obtained if you include the file libcicpi.h at the beginning of each source file. This is automatically included in the pg_templ.c template file. Further information about CPI functions is given in Command Set Programming Interface.

If you have developed a program in a different directory from the Command Set directory, and subsequently copied the program to the Command Set directory, the program automatically becomes available to the Command Set. However, debugging is not possible on such a program.
