Topic 142644

Dynamic power supply and measurements

In addition to the fixed DC events that the MTP software already supports, it is now also possible to define sequences of events that occur alongside specified code passage, for example to model voltage fluctuations.

Benefit

It is now possible to simulate specific voltage conditions and changes during tests, such as noise or uneven power supply under power-up conditions.

More Info

For further details, see Controlling power supply and measurements.
