Creating a Scan Setup with the ASCII Interface (Pin Scale)

Within the ASCII interface, both the scan structure (templates and frames) and the scan instances are defined in the ASCII vector file. Scan sections are not allowed in subpatterns of type SVEC. They may only occur in MAIN patterns and scan subroutines (see Creating a Scan Subroutine).

Note that the following exposition applies only to Pin Scale systems in compatibility mode.
