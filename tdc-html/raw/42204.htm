Topic 42204

Parameter: automatic_reprobe_mode

If devices fall into SmarTest bins that are defined to be reprobe bins and if the driver function ph_reprobe() is defined as reprobe action in the application model, SmarTest automatically requests a reprobe cycle from the equipment driver. Based on the value of this parameter, the driver will either ignore that reprobe request ("off"), will reprobe all devices regardless of their test results ("all"), or will perform a reprobe which is based on the per site test result. Not every type of equipment is able to perform a per site reprobe operation, thus the range of valid settings is plug-in dependent.

Driver default: "all"

Changeable at run-time: yes

Applicable for: handlers and probers, plug-in dependent

Example: automatic_reprobe_mode: "per-site"
