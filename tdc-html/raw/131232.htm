The MTP_CONTINUITY_PIN_TASK class contains the measurement settings for a continuity test. The class is performed with the MTP_CONTIUITY_TASK API and used by the pin() member function.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/MTP_CONTINUITY_PIN_TASK.h.

Class definition

Member functions

  • iForce(double value)
  • vForce(double value)
  • limits(const LIMIT & limit)
  • deviceSupply(const string & pinlist)
  • forceSupply(const string & pinlist)
    Note iForce() is used only for non-shared and cross-terminated pins. vForce() is used only for shared pins. For the details about how to set up tests for shared, non-shared, and cross-terminated pins, see SharedContinuity test method.
