Installing HD pins to Accretech prober's headstage

Follow the procedure to install the hard docking pins to the Accretech prober's headstage.

Before you begin

Tools:
  • Allen key
  • Open-ended wrench
  • Torx screwdriver
Parts:
  • Hard docking pins

Procedure

  1. Hold the hard docking pin with a Open-ended wrench, and remove the top screw with the help of Allen key as shown below.

  2. Disassemble the pin as shown below.

  3. Take the lower part of the pin and place it on the Accretech prober's headstage.

  4. Using Torx screwdriver, affix the pin to the headstage with the three screws provided.

Results

You have attached the hard docking pins to the Accretech prober's headstage.

Functional changes

  1. Introduced in SmarTest 8.4.4
