Topic 86641

PPTIA_TASK

The PPTIA_TASK API holds measurement setups for one or more pins, and executes these measurements in parallel. The API can also be used to retrieve the measurements results.

The PPTIA_TASK API calls objects of the PPTIA_PIN_TASK class. This is a subsidiary data container that holds measurement setups for individual pins.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PpTIATask.h.

Constructor

PPTIA_TASK()

PPTIA_TASK();

This constructor creates an object of the PPTIA_TASK class, which allows the user to define different measurement setups for different pins, to execute all measurements in parallel, and to retrieve the results.

Note Do not create static objects of the class in the test method and do not create test method member variables from this class.

Member functions

pin()

PPTIA_TASK & pin(const STRING & pinlist);

This member function returns the reference to the PPTIA_PIN_TASK object holding the measurement setups for the specified pin list.

Note A call to this function must be followed by calls to member functions of the PPTIA_PIN_TASK class. You cannot call another PPTIA_TASK member function of after calling pin().
Parameter

pinlist

List of pins for which a TIA measurement is to be executed.

numberOfMeasurements()

PPTIA_TASK & numberOfMeasurements(INT measurements);

This member function specifies how many SQPG TIAS instructions occur in the sequencer program of the current start label (pattern). This is effective only if the execMode() function is set to SEQ_PROG.

Parameter

measurements

Number of SQPG TIAS instructions in the sequencer program

delay()

PPTIA_TASK & delay(DOUBLE seconds);

This member function sets a delay time for the TIA measurement. This is effective only if the execMode() function is set to DIRECT.

Parameter

seconds

Delay in seconds. The resolution is ns. The default is 0. The maximum is 2 sec.

disableTimeoutFlag()

PPTIA_TASK & disableTimeoutFlag();

A timeout flag is introduced to support the time out handling. This function disable the timeout flag. Then the test method behaves exactly the same as SmarTest versions before 5.4.4 and the versions between 5.4.4 and 6.1.2. When a timeout occurs, the test method throws an error. The timeout flag is disabled by default. This function has to be called before the member function execute().

enableTimeoutFlag()

PPTIA_TASK & enableTimeoutFlag();

This function enables the timeout flag. When a timeout error occurs, the test method will not throw an error but continue its execution.

functionalTestMode()

functionalTestMode(const STRING& mode);

This function specifies what kind of results are retrieved during the measurement with execute().

Parameter

mode

The measurement mode. There are three options:

NO_RESULT:No result will be retrieved. You cannot call getFunctionalResult() afterwards.

GPF: Only general pass/fail result will be retrieved. You can only call the getFunctionalResult() without pinlist parameter.

PPF: Per pin pass/fail results will be retrieved. You can call getFunctionalResult() both with and without pinlist parameter.

timeout()

PPTIA_TASK & timeout(INT seconds);
PPTIA_TASK & timeout(DOUBLE seconds);

This member function sets a timeout for TIA measurements. When a timeout occurs, execute() issues an error message.

Parameter

seconds

Time out value for the PPTIA measurement. Its unit is second. The default value is 15 sec. The maximum value is 20 sec. The minimum value is 500 us.

setup()

void setup();

This member function downloads the previously defined TIA measurement setup, unless this setup already exists in the firmware. If an instance of the PPTIA_TASK class is added to a TASK_LIST instance, the setup() member function of the TASK_LIST API calls this function.

There are no parameters in this member function.

This function must be used for measurement parameters containing variables.

execute()

void execute();

This member function executes a TIA measurement based on the previously defined measurement setups. If these setups have not yet been downloaded, execute() first downloads them. If the execution mode defined with execMode() is SEQ_PROG, then execute() expects that the current start label contains the appropriate number of SQPG TIAS instructions.

There are no parameters in this member function.

restore()

void restore();

This member function restores the original setup after a TIA measurement. If the restoration is not performed by postAction(), then restore() is called internally when a PPTIA_TASK object is deleted.

There are no parameters in this member function.

This function can only be called if the result type as set with the resultType() function of the PPTIA_TASK API is RAW., and the getId flag has also been set with this function.

getTimeoutFlag()

Boolean getTimeoutFlag();
Boolean getTimeoutFlag(INT measIndex);
Boolean getTimeoutFlag(const STRING& pinlist);
Boolean getTimeoutFlag(const STRING& pinlist, INT measIndex);

These functions retrieve the timeout status. The returned value is valid only when the timeout flag is enabled, otherwise it always returns FALSE. Depending on the parameters, it returns a cumulative status. If one of the specified pins and measurements has a timeout, it returns TRUE. When no pinlist is specified, all pins which take part in a ppTIA measurement are taken into account. When no measIndex is specified, all measurements are taken into account.

Parameter

pinlist

The pins of which timeout status is taken into account.

measIndex

Measurement index. If more than one measurement was executed, this parameter specifies the measurement to be selected.

If the parameter is omitted, all available measurements are taken into account.

Examples

PPTIA frequency test

INT debug;
DOUBLE frequency_MHz , time_s;
PPTIA_TASK task1;
GET_TESTFLOW_FLAG ("debug_analog", &debug );
ON_FIRST_INVOCATION_BEGIN();
  task1.pin(tia_pin).eventASlope(TM::RISE).eventAThreshold(1000 mV).eventACount(0) ;
  task1.pin(tia_pin).eventBSlope(TM::RISE).eventBThreshold(1000 mV).eventBCount(N) ;
  task1.pin(tia_pin).armingMethod(TM::EVENT_A_FIRST) ;
  task1.pin(tia_pin).resultType(TM::MEAN) ;
  task1.preAction(TM::SET_TIA_MODE).execute() ;
ON_FIRST_INVOCATION_END();
  time_s = task1.getValue(tia_pin, TM::MEAN) ;
  frequency_MHz = 1e-6 * (N+1) / time_s ;
  if(debug)
  {
    cout << endl << "--- Frequency ---" << endl ; 
    cout << "Frequency (Site " << CURRENT_SITE_NUMBER() << ") = " << frequency_MHz << "MHz" << endl << endl ;
  }
  TEST ( tia_pin , "FREQ_MHz" , frequency_MHz ) ;

This example performs a frequency test with PPTIA on tia_pin. tia_pin is the test method parameter holding the pin(s) to be measured. N is the test method parameter holding the number of events.

PPTIA jitter test

INT debug;
ARRAY_D raw_result ; raw_result.resize(N_exec);
DOUBLE glob_avg , glob_min , glob_max , glob_stdev;
GET_TESTFLOW_FLAG( "debug_analog" , &debug );
PPTIA_TASK task1;
ON_FIRST_INVOCATION_BEGIN();
  task1.pin(tia_pin).eventASlope(TM::RISE).eventAThreshold(1000 mV).eventACount(0);
  task1.pin(tia_pin).eventBSlope(TM::RISE).eventBThreshold(1000 mV).eventBCount(0);
  task1.pin(tia_pin).numberOfSamples(N_exec);
  task1.pin(tia_pin).sampleRandomizeRatio(0.5);
  task1.pin(tia_pin).armingMethod(TM::EVENT_A_FIRST);
  if (debug)
    task1.pin(tia_pin).resultType(TM::RESULT_ALL | TM::RAW);
  else
    task1.pin(tia_pin).resultType(TM::RESULT_ALL);
    task1.preAction(TM::SET_TIA_MODE).execute();
ON_FIRST_INVOCATION_END();
glob_avg   = task1.getValue(tia_pin , TM::MEAN);
glob_min   = task1.getValue(tia_pin , TM::MIN);
glob_max   = task1.getValue(tia_pin , TM::MAX);
glob_stdev = task1.getValue(tia_pin , TM::STDEV);
if (debug)
{
  cout << endl << "--- Jitter ---" ;
  cout << endl << "(Site " << CURRENT_SITE_NUMBER() << ")"
       << endl << "Period AVG = " << glob_avg * 1e9 << " ns"
       << endl << "Period MIN = " << glob_min * 1e9 << " ns"
       << endl << "Period MAX = " << glob_max * 1e9 << " ns"
       << endl << "Jitter P_P = " << ( glob_max - glob_min ) * 1e9 << " ns"
       << endl << "Jitter_RMS = " << glob_stdev * 1e9 << " ns"
       << endl ;
  raw_result = task1.getResult(tia_pin) ;
  PUT_DEBUG( tia_pin , "RAW_DATA" , raw_result ) ;
}
TEST( tia_pin , "AVERAGE_PERIOD_ns" , glob_avg * 1e9 );
TEST( tia_pin , "PP_JITTER_ns" , ( glob_max - glob_min ) * 1e9 );
TEST( tia_pin , "RMS_JITTER_ns" , glob_stdev * 1e9 );

This example performs a jitter test with PPTIA on tia_pin. tia_pin is the test method parameter holding the pin(s) to be measured. N_exec is the test method parameter holding the number of samples for jitter measurement.

PPTIA pulse width test

INT debug;
DOUBLE time_s;
PPTIA_TASK task1;
GET_TESTFLOW_FLAG ( "debug_analog" , &debug );         
ON_FIRST_INVOCATION_BEGIN();
  task1.pin(tia_pin).eventASlope(TM::RISE).eventAThreshold(1000 mV).eventACount(10) ;
  task1.pin(tia_pin).eventBSlope(TM::FALL).eventBThreshold(1000 mV).eventBCount(0) ;
  task1.pin(tia_pin).armingMethod(TM::EVENT_A_FIRST) ;
  task1.pin(tia_pin).resultType(TM::MEAN);
  task1.preAction(TM::SET_TIA_MODE).execute();
ON_FIRST_INVOCATION_END();    
time_s = task1.getValue(tia_pin, TM::MEAN);
if(debug)
{
  cout << endl << "--- Pulse Width ---" << endl; 
  cout << "Pulse Width (Site " << CURRENT_SITE_NUMBER() << ") = " << time_s * 1e9 << " ns" << endl;
}
TEST ( tia_pin , "PULSE_WIDTH_ns" , time_s * 1e9 );

This example performs a pulse width test with PPTIA on tia_pin. tia_pin is the test method parameter holding the pin(s) to be measured.
