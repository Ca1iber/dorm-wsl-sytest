GetSmarTestExecStatus

This data query command acquires the SmarTest execution status. This status means the period during which a certain status is maintained. The following five status are supported:

  • IDLE: SmarTest is ready for operation. No operation is being performed.
  • DOWNLOADING: The setup files are being downloaded to the test system.
  • WAITING: SmarTest is waiting for external interaction in the test program execution. The external interactions include prober/handler communication, user dialog, execution input call and any other interaction that will cause the pause or waiting of test program execution.
  • TESTING: The test flow is in execution.
  • STOPPED: An unrecoverable alarm occurred or the HOLD flag in the test flow execution is set.

SUCCESS will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

Code

Description

Severity

ILLEGAL_OPERATION

The designated session ID "XXX" does not exist.

RECOVERABLE

Parameters

I/O

Parameters

Description

I

SESSION_ID

The ID of the SmarTest session to query.

O

qrResults

The query results are presented by a ParamList object. It contains the following members:

EXEC_STATUS

The SmarTest execution status. It includes can be IDLE, DOWNLOADING, WAITING, TESTING or STOPPED.

 

Prototype

ParamList qrResults;
string sessionId;
Status query("GetSmartestExecStatus", qrResults, ParamList(), sessionId);
