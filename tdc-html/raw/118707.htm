Topic 118707

Installing STIL Reader

STIL Reader is delivered and installed as part of the STDL RPM.

About this task

Perform this procedure to install STIL Reader for the first time or update to a new version.

Before you begin

STIL Reader requires a license that must be entered in your licensing file.

Note If you already have installed other components of the SmarTest Data Link (STDL) or SmarTest Product Manager tool sets, you may already have installed STIL Reader. Check whether the /opt/93000/stdl/bin/ directory contains the stilreader binary. If it does, you already have installed STIL Reader and can skip this procedure.

Procedure

  1. Log in as root.
  2. Copy the STDL (SmarTest Data Link) installer package to your computer.

    The name of the package is "stdl", followed by version and platform information, for example: stdl_2.2.0.0-1-0.el5.x86_64.rpm

  3. Open a terminal window and make the directory in which the STDL installer package is located the current directory.
  4. In the terminal window, enter and execute this command:

    rpm -ivh package_name

    For example, if the installer package is named stdl_2.2.0.0-1-0.el5.x86_64.rpm, the command would be rpm -ivh stdl_2.2.0.0-1-0.el5.x86_64.rpm.

Results

STIL Reader is installed at /opt/93000/stdl/bin/stilreader (the command line version) and /opt/93000/stdl/bin/stilreader-gui (the window version).

What to do next

Launch STIL Reader and use it as described in Using STIL Reader.
