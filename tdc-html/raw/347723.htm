SmartRDI 7.5.2

This section summarizes software changes including new features and enhancements in SmartRDI 7.5.2.

Changes and new features

Category

 Description
DC
  • insertSub() supports multilayer insertion of user sublabels.
ORE

  • The testflow variable RDI_ORE_FILE can be used to set or change the ORE XML file between loop executions.

  • The flag ORE_FOLDER can be set in the RDI_Configure file to specify an ORE template file path.

  • ORE template file can be generated from online test results.

  • The ENABLE_ORE keyword has a new value TRUE_OFFLINE which can automatically disable ORE in online mode.

  • The dc, emap, and smartVec elements support more attributes and values.
Alarm handling

  • More debug information can be shown in the UI report window. See Debug value in the UI report window.

  • Alarm checking can trigger a hidden port synchronization after alarm compare. See Alarm handling on ports.

  • The ALARM_FAIL_WARNING flag can disable alarm warnings when alarm handling fails. See Alarm handling for DCVI .
Func

  • rdi.func().burstRunTime() can be used for runtime burst content patching.

  • rdi.id().getMultiPassFail() can retrieve per-label results from the burst other than the burst pass/fall result by the rdi.getBurstPassFail() in the STATIC mode.
DigCap
  • vecVar() specifies vector variables from a user label.
  • rdi.id().getVectorFromVV() retrieves results from the specified user-defined vector variables.
SmartVec
  • download() helps to achieve hidden vector download (HVD).
Route
  • downloadPmuxMemSet() can work together with xMode to save vector memory.
Relays
  • setOnRunTime() and setOffRunTime() can be used in the static mode.
TMU
  • Digital tmu result upload speed improvement.

Supported SmarTest versions

SmartRDI 7.5.2 supports SmarTest 7.5.2.
