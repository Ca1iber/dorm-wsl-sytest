Pin Scale 5000 features and functionality

Subtopics

  1. Pin Scale 5000 error map size
  2. Pin Scale 5000 embedded timing search
  3. Pin Scale 5000 ground sensing

The Pin Scale 5000 next generation digital card features a number of card specific functionalities as listed below.

Licensing

A Pin Scale 5000 Base Capability license is required and can be specified in the device license file by adding the digitalFrontEnd license. Details of the available licenses can be found in V93000 License Master Look-up Table (filter with Product description = Pin Scale 5000 and DLF/TPLF definition = digitalFrontend).

Channels

The Pin Scale 5000 card features 256 single ended I/O channels or 128 differential channel pairs. A card consists of eight channel modules with 32 single ended (or 16 differential) channels in each channel module.

Pogo assemblies

The Pin Scale 5000 card supports three different pogo cable assemblies:

  • the standard (STD) compatible 16x16 pogo cable assembly
  • the high-density (HD) 8x32 pogo cable assembly
  • the very-high-density (VHD) 4x64 pogo cable assembly

General features

Data rates

The Pin Scale 5000 digital card can handle data rates up to 5000 Mbit/s drive, receive and capture, given the prerequisites listed in Pin Scale 5000 basic parameters.

Independent clock domains

Independent clock domains per pin enable each pin to run at a different data rate. This allows:

  • Unconstrained routing on the test fixture
  • Concurrent testing of all interfaces at their native data-rates
  • Optimized tester resource utilization with per pin granularity
  • Each pin to synthesize its own and independent data-rate

Sequencer‑controlled board ADC

One sequencer‑controlled ADC for high accuracy voltage measurements is provided for each channel module (Board ADC). This gives you 16 BADCs per PS5000 card, one BADC for 16 pins (see Pin Scale 5000 hardware overview).

Sequencer‑controlled pin PMU (PPMU)

A sequencer‑controlled PPMU is provided for each pin for accurate current and voltage measurements (see Pin Scale 5000 hardware overview).

Pattern synchronous DC value measurements

Pattern synchronous DC value measurements (see Pin Scale 5000 DC value measurements) can be performed during the execution of a pattern using either the board ADC (BADC), the pin PMU (PPMU), or both depending on the accuracy you require. This feature is also referred to as sequencer‑controlled measurement of values.

Embedded timing search (fast adjustment)

Embedded timing search (fast adjustment) per-pin functionality allows you to adjust your timing to the actual behavior of the DUT. As this feature is embedded, it saves test time, as the data does not need to be uploaded to the workstation.

Preventing floating pins

The active load should help to prevent a floating pin rather than a pull-down resistor.
