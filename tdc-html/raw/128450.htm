Serial interface for sequencer-controlled utility lines

The serial interface for sequencer‑controlled utility lines requires up to four digital pins from a test head card installed in the test system to be connected to the pins of a utility block on the DUT board.

Note This section applies to
  • V93000 Pin Scale and Smart Scale systems running SmarTest 7,
  • V93000 Pin Scale and Smart Scale systems running SmarTest 8,
  • V93000 EXA Scale systems running SmarTest 7.
On V93000 EXA Scale systems running SmarTest 8 and equipped with the optional Utility Card, the pattern sequencer controls utility lines via an internal data path. The interface pins provide no functionality but digital pins connected to the interface pins are tolerated.

The pins of the serial interface need to be connected to digital pins as follows:
  • V93000 Pin Scale and Smart Scale systems (SmarTest 8):

    Three digital pins are required for providing the digital signals for sequencer‑controlled switching of utility lines. The three pins need to be connected to pins "SINP", "FRAMn", and "SCLK" on the selected utility block.

  • V93000 Pin Scale and Smart Scale systems (SmarTest 7):

    Three digital pins are required for providing the digital signals for sequencer‑controlled switching of utility lines. The three pins need to be connected to pins "SINP", "FRAMn", and "SCLK" on the selected utility block.

    Optionally, one more digital pin can be connected to "SOUT" on the same pogo block for reading the state of the utility lines.

  • V93000 EXA Scale systems (SmarTest 8):

    Sequencer‑controlled utility lines are supported only with the optional Utility Card. With SmarTest 8, the entire data transfer is handled internally by SmarTest itself and the interface must not be wired to digital pins. Already wired digital pins or other hardware at the interface pins are tolerated but does not have any functionality.

  • V93000 EXA Scale systems (SmarTest 7):

    Similar to V93000 Pin Scale and Smart Scale systems running SmarTest 7, three digital must be wired to "SINP", "FRAMn", and "SCLK". Optionally, one more digital pin can be wired to "SOUT" for reading the state of the utility lines.

Every utility block can be independently controlled by its own serial interface and several interfaces can be operated at the same time. Alternatively, several utility blocks can be ganged together (daisy‑chained) so that a single serial interface controls several blocks, see Ganging utility blocks. The pins for FRAMn and SCLK have not been used prior to the introduction of the serial interface for utility control. They should therefore be disconnected on all legacy DUT boards.

The pins for SINP and SOUT have formerly been used as UGND. They may be tied to ground on legacy DUT board designs.

We recommend that you connect a 100 Ω resistor in series with each control line on your DUT board and position it as close as possible to the digital pogo pads for FRAMn, SCLK, and SINP. This serves to avoid possible problems with fast signal edges and to uphold signal integrity.

Sequencer‑controlled utility lines in the model / tester.model file

The utility_lines entry in the GLOBAL section of the SmarTest 7 model file or in the GLOBAL section of the SmarTest 8 / 7.10 tester.model file must always reflect the capabilities of the hardware currently installed in the test system. If you have older hardware capable only of static access for the utility lines, the model / tester.model file must contain a line such as:

  • utility_lines = 64, type = static, pogo_size = 16

If you have new hardware capable of sequencer‑controlled access for the utility lines, the model file must contain a line such as:

  • utility_lines = 128, type = sequencer_controlled, pogo_size = 16

This is independent of whether you are using the utility lines in the sequencer controlled mode or the static mode.

SmarTest 7 specific behavior

Disabling sequencer control of utility lines in SmarTest 7

To disable sequencer control (and enable static control) of utility lines use the UTILITY_SEQ_POGO_MODE test method API.

The four lines that make up the serial interface revert back to their original states (UGND or Reserved); see the utility pogo block mapping links above.

Use the FLEX_UTILITY_RELAY test method API to set the state of the utility lines and the GET_UTILITY_LINES_STATUS AP to read the current state of the utility lines. Accessing the utility lines using these test method APIs is not synchronized with the pattern‑sequencer and can only be used to control slow devices such as relays.

Pass‑through mode of SmarTest 7
The so‑called pass‑through mode is automatically activated, if you switch to a SmarTest release before 7.2 on a system equipped with the large or DUT Scale interface fitted with 4‑row utility pogo blocks. As the older software does not recognize the new hardware the system automatically defaults into this mode. The behavior is the same as that described in Disabling sequencer control of utility lines in SmarTest 7 above.
