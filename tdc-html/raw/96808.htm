Topic 96808

ALARM_NOTIFICATION

This notification is provided whenever an error occurred in the system.

Dependency

The HVM alarms cover the following warnings and errors:

  • firmware execution warnings and errors
  • SmarTest initialization warnings and errors, like device changing error, TF process start failure error, Xset fp+ /opt/hp93000/soc/prod_pws/fonts error and MCD or calibration data error.
  • Test program execution warnings and errors, like application model parse errors, test flow parse errors, errors occurring during application model execution, errors occurring during testflow execution, test program load errors (Prober/Handler driver library load errors, execute input library load errors etc.) and test method execution errors.
  • Advantest Generic Prober/Handler driver errors and warnings, like GPIB communication error, binning error, incorrect site population information, driver configure file error.
    Note Except for firmware execution warnings and errors, the other warnings and errors generated before the event notification infrastructure started cannot be captured.
Parameters

I/O

Parameters

Description

O

SESSION_ID

The ID of the SmarTest session this event belongs to.

O

TIME_STAMP

The time point when this event occurs. It contains two long-type parts SECONDS and MICROSECOND.

O

EVENT_NAME

The event category. Here it is always ALARM.

O

EVENT_BODY

The event parameters. It contains:

ALARM_SEVERITY

The alarm severity. It can be UNRECOVERABLE: The system is unable to recover from the error because system is in a corrupt or invalid state.

RECOVERABLE: All other errors.

ALARM_CODE

The error sub-classification. See the tables below.

ALARM_TEXT

The detail information of the alarm.

This parameter is represented by ParamList whose key and value are both string type.

List of Unrecoverable Alarm Code

Alarm Code

Description

CORRECTNESS_EXCEPTION

The system has determined a correctness specification that does not hold. The system is not able to continue.

UNKNOWN_FATAL

Unknown fatal error. The system is not able to continue.

UNRECOVERABLE_OUT_OF_MEMORY

The system unexpectedly ran out of memory and cannot recover.

UNSPECIFIED

The error code has not been set.

LICENSING_ERROR

No valid SmarTest offline license

List of Recoverable Alarm Code

Alarm

Description

ABORTED

Signals that the user requested to abort the running operation.

FILE_CORRUPT

The contents of a file were corrupted when attempting to read it.

FILE_ACCESS_DENIED

The file is not accessible for the current user due to security reasons.

FILE_NOT_FOUND

The requested file was not found.

FILE_SIZE_EXCEEDED

The file has exceeded the maximum allowable size.

HARDWARE_EXCEPTION

Hardware errors are usually thrown by driver implementations that encounter non-functioning hardware at runtime.

ILLEGAL_OPERATION

The operation is illegal in the object this operation has been called.

NOT_AVAILABLE

The requested entity is not known to the system.

OUT_OF_DISK_SPACE

The disk is full.

OUT_OF_THREADS

No more threads were available to complete the requested operation.

PARAMETER_EXCEPTION

One or more parameters are incorrect to the operation.

RECOVERABLE_OUT_OF_MEMORY

The system ran expectedly out of memory and can recover from that, provided that memory is freed.

This shall only be thrown if the system assures that it is still in a consistent state.

SETUP_EXCEPTION

The system cannot complete the requested operation because the pending settings required for this operation are conflicting, incomplete, or incorrect.

TIME_OUT_EXCEPTION

Operation timed out.

UNSPECIFIED

The error code has not been set.

CAL_DATA_INVALID

The DC update calibration expired or the auto calibration expired. It will be generated when you start a SmarTest online session or change a device in a SmarTest online session.

LICENSING_ERROR

An licensing error occurs. It may happen when SmarTest is checking out license from server or SmarTest loses connection to the license server.

Functional changes

  1. Introduced before SmarTest 6.3.2
  2. SmarTest 6.5.0: CAL_DATA_INVALID and LICENSING_ERROR are supported.
  3. SmarTest 6.5.2: SmarTest initialization warnings and errors, Test program execution warnings and errors and Advantest Generic Prober/Handler driver errors and warnings are supported.
