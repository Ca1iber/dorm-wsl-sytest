IsCassetteDone()

This API checks all the cassettes are finished.

SUCCESS is returned if no error occurred. Otherwise, an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • The local session does not exist.

RECOVERABLE

Parameters

I/O

Parameter

Description

I

SESSION_ID

The ID of the session to work with.

O

IS_CASSETTE_DONE

If all the cassettes are finished, the value is TRUE. Otherwise, it is FALSE.

Prototype

ParamList outputResults;
Status query("IsCassetteDone", outputResults, ParamList(), sessionID);

Example

string sid = LOCAL_SESSION_ID;
ParamList outputResults;

Status retVal = query("IsCassetteDone", outputResults, ParamList(), sid);
if ( retVal.isSuccess() ) 
{
cout<< "The CASSETTE status = " << outputResults["IS_CASSETTE_DONE"] << endl;
}

Functional changes

  1. Introduced in SmarTest 6.5.0
