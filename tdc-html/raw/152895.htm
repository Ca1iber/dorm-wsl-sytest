Topic 152895

CLKC?

Returns the value of the master clock and the clock resolution (ECLK) for the given specification name or set.

For details on master clock and clock resolution, see Period resolution, clock resolution, and master clock period. Also, see Dealing with rounding problems in multiport setups.

In SmarTest 7.10 the master clock is fixed, and will always return as 375 MHz.

Syntax

CLKC? <specset | specificationName>, (portName)

returns:

CLKC <spscset | specificationName>, mater_clock_ns, edge_clock_ns, (portName)
Parameters

specset

The required specification set.

specificationName

The name of the required specification.

portName

The port name. This can be either a specific port, or all ports. For all ports, you can use @@ if this is a multiport, or only @ to specify all pins if this is not a multiport.
