Topic 105803

Example of Merging Two Separate Test Programs Into One

Subtopics

  1. Making a CCT Plan
  2. Convert to a Multi-Port Setup
  3. Convert Test Functions to Test Methods
  4. Set up the CCT Test Flow

Consider a Device consisting of two independent cores:

  • A digital signal processor core (DSP).
  • A CODEC core consisting of digital and analog pins.

in which the package test program originally consisted of two independent test programs, one for each core.

The task is to merge the tests together into a single test program and run the tests simultaneously to save testing time.

For this purpose, a concurrent test procedure was used (see the section, Concurrent Tests (CCT)), which necessitates generating a multi-port setup from the single port setup.

The following procedure was adopted:

  • Creating a test plan for the concurrent test required (see, Making a CCT Plan).
  • Test setup conversion from single-port to multi-port
    • CCT port definition and pin configuration (see Multi-Port Port Definition and Pin Configuration).
    • CCT vectors (see, Multi-Port Vector Conversion).
  • Conversion to CCT test methods (see, Convert Test Functions to Test Methods).
  • Finalizing the CCT test flow (see, Setup the CCT Test Flow).

The following sections describe these steps.
