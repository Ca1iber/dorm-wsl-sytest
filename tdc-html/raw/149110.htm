Topic 149110

rdi.tmu().samples()

Sets the number of samples for each measurement of TMU pin(s).

This function is only for Smart Scale digital pins. The function can be used only in the pattern‑based mode.

Syntax

tmuBase& samples(int iSamples);
Parameter
Parameter Description
iSamples The number of samples.

Return Value

A reference to the tmuBase object.

Example

RDI_BEGIN();

    rdi.tmu().pin("PVI8_PMU_1")
            .measMode(TA::RISE_TIME)
            .vth(1.0 V,2.0 V)
            .samples(50)
            .execute();

    rdi.wait(100 us);

    rdi.tmu().pin("PS1600_1")
            .measMode(TA::RISE)
            .vth(1.0 V)
            .samples(50)
            .execute();

    rdi.wait(100 us);

RDI_END();
