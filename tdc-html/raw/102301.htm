Topic 102301

FPGA Download Manager

The FPGAs (Field Programmable Gate Array) on the tester hardware boards are used to execute specific algorithms for testing the DUT.

The FPGA Download Manager Tool allows you to access the FPGAs for the purpose of checking their status or uploading binary data to them. This tool is only to be used by persons who have had specific training.

Note Your system controller must have Java 1.5 or above to support this tool.
