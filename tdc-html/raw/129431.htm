PS1600 error map size

There is an error map size difference between previous Pin Scale cards and newer Pin Scale cards of the Smart Scale generation (PS1600, PS9G).

On previous Pin Scale cards, the size of the internal error map (DCRT TP) is 16384 bits. For Smart Scale generation channel cards, the size is 65536 bits. The number of cycles that fit into the error map (in Acquire All mode, DCGM ALL) depends on the selected X mode and the number of bits stored per result:

  • numberOfCycles = errorMapSizeInBits / (xMode * bitsPerResult)

For example, in X1 PFC mode (2 bits/result), Pin Scale cards can store 8192 cycles, Smart Scale generation cards can store 32768 cycles. In X8 mode (1 bit/result), Pin Scale cards can store 2048 cycles, Smart Scale generation cards 8192 cycles. The size of the external error map (DCRT RAM) is not fixed and always depends on the amount of available RAM, for both Pin Scale and Smart Scale generation cards.
