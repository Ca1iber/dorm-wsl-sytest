The function of patterns

A test consists of a pattern (label) and its associated vectors. When you download a vector setup file to the hardware, you will normally have more than one test in memory. The tests follow one another without break, their start (which always occurs on a modulo 28 vector boundary) is marked with a pattern (label).

Patterns are listed in the Pattern Explorer. The Pattern Editor displays the vectors associated with that pattern.

The following occurs. The system reads the part of the memory starting at the selected pattern (label) and ending either at the next pattern (label), or at the first free vector address (if you select the last test). It interprets the data from that part of the memory and displays it as vectors in the Pattern Editor.

Patterns are also used to manipulate tests. You can:

  • introduce sequencer subroutines into your test, to save space in memory,
  • delete a test.
