Topic 10622

Defining the global period

Subtopics

  1. Restrictions for multiport setups

In equation based timing, timing sets are part of an equation set, and are edited within this equation set. The following figure shows an equation set as displayed in the timing equation editor of SmarTest.

The global period of timing set 1 is specified with the period= p statement immediately below the TIMINGSET keyword. p is a derived variable that is defined in the EQUATIONS section from the base variable f which, in its turn, is declared in the SPECS section. If f is set to 100 in the specification then p is 12 ns.

Note Special restrictions hold for

- the period of protocol engine tests in x6 mode (see Defining edge delays and period length for a protocol engine test) and

Related firmware commands

You can use the PCLK command to retrieve and change the period. However, this is only a temporary change of the runtime value, which does not modify the value in the timing set.
