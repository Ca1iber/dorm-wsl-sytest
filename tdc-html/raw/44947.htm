Topic 44947

Generate a List of Bins

Use

long GetBinList(CI_CPI_BIN_LIST *bin_list)

Generates a bin list and copies it to the caller-provided buffer *bin_list. See the definition of CI_CPI_BIN_LIST for a description of the information available with bins.

The value returned is the number of bins or -1 if an error occurred.

For more information, refer to /opt/hp93000/soc/prod_com/include/libcicpi.h.
