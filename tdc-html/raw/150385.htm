EVENT_WAVEFORM_VCIM.getVClampLow()

Queries the lower clamp voltage waveform that has been defined by EVENT_WAVEFORM_VCIM.vClampLow().

The waveform is read from the corresponding EVENT_WAVEFORM_VCIM object and returned as an ARRAY_D object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Syntax

const ARRAY_D & getVClampLow() const;

Return value

An ARRAY_D object containing the waveform samples that are defined in V (Volt).

Example

For an example see EVENT_WAVEFORM_VCIM.

Related information
