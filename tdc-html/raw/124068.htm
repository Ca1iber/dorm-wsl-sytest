Test method snippets for DAC test

The following test method snippets for DAC test are provided by SmarTest. These test method snippets are included in the file /opt/hp93000/soc/segements/tml/testmethodSnipptets.xml.

They are listed in the alphabetical order.

  • V93000_DAC_Distortion_SMCPostProcess

    This snippet does the post processing for the DAC distortion test with smartCalc. It uploads the result waveform and calculates THD of DAC test. The results of SNR and THD are judged with the limits in the test table and logged. The snippet can be used together with the snippet V93000_DAC_MeasumentSetup in the test method.

  • V93000_DAC_Edge_SMCPostProcess

    This snippet does the post processing for the DAC IQ edge EVM test with smartCalc. It uploads the waveform and calculates the edge EVM rms value and peak value. The results are judged with the limits in the test table and logged. The snippet can be used together with the snippet V93000_DAC_IQ_MeasurementSetup in the test method.

  • V93000_DAC_FreqResp_SMCPostProcess

    This snippet does the post processing for the DAC frequency response test with smartCalc. It uploads the DAC output waveform and calculates the frequency at the -3db gain point with smartCalc. The result is judged with the limit in the test table and logged. The snippet can be used together with the snippet V93000_DAC_MeasumentSetup in the test method.

  • V93000_DAC_GainPhase_SMCPostProcess

    This snippet does the post processing for the DAC gain and phase test with smartCalc. It uploads the waveform and calculates the gain error of both channels, gain imbalance of I/Q channel and phase imbalance of I/Q channel. The results are judged with the limits in the test table and logged. The snippet can be used together with the snippet V93000_DAC_IQ_MeasurementSetup in the test method.

  • V93000_DAC_IQ_MeasurementSetup

    This snippet sets up and performs IQ measurement with smartCalc. It then kicks off the data uploading and result calculation with the smartCalc background post processing function. After that, the digitizer is disabled and disconnected.

  • V93000_DAC_Linearity_SMCPostPocess

    This snippet does the post processing for the DAC linearity test with smartCalc. It uploads the result waveform and calculates the DLE, ILE, zero scale error code and full scale error code. The results are judged with the limits in the test table and logged. The snippet can be used together with the snippet V93000_DAC_MeasurementSetup in the test method.

  • V93000_DAC_MeasurementSetup

    This snippet sets up and performs the DAC test with smartCalc. It then kicks off the background data uploading and result calculation with the smartCalc post processing function. After the measurement the digitizer is disabled and disconnected.

Functional changes

  1. Introduced in SmarTest 6.5.4
