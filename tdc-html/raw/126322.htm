TSDF, TSDF? - (TMU Set DeFinition)

TSDF creates a TMU set by defining a unique name for it. TSDF? returns the names of all defined TMU sets.

A TMU set can be associated with a mode context. The primary TMU set (as defined with TSPR) must be associated with the same context as the other primary sets.

TSDF

TSDF {"TMU_set_name"} [, "mode_context"]

TSDF?

TSDF? ["TMU_set_name"]

returns:

TSDF {"TMU_set_name"} [, "mode_context"]

Parameters

TMU_set_name

In the command, this is the name of a new TMU set. In the query, it is a name of an existing TMU set. If you omit this parameter in the query, TSDF? will return the names of all user defined TMU sets.

mode_context

The mode context with which the TMU set is associated. If this parameter is omitted, the DEFAULT context is assumed.

Application

TMU per pin measurements.

Errors

An error is generated if a TMU set with this name already exists.

Example

> TSDF   "TMU_set1"
> TSDF   "TMU_set2"
> TSDF   "TMU_set3"

> TSDF?
< TSDF   "TMU_set1"
< TSDF   "TMU_set2"
< TSDF   "TMU_set3"

Functional changes

  1. Introduced in SmarTest 7.1.0
