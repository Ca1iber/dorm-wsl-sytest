Topic 102429

Best Practice frameworks

Subtopics

  1. Using framework parts in your own tests

Best practice frameworks are sample solutions to common testing problems. The frameworks are included with the Memory Test Plus software.

Best practice frameworks are designed to offer sample implementations of important concepts and algorithms as well as demonstrate how to use relevant features of the SmarTest and Memory Test Plus software.

You can use them to find out how to best employ new or unknown features or to make the best use of the V93000 system in a particular area. If desired, you can also use the framework as a starting point for developing your own testing application.

The frameworks are delivered as part of the standard MTP installation. Each solution includes an extensive Read Me file describing the intended uses as well as highlighting the most important features and algorithms found in the solution.

The frameworks are installed in /opt/93000mts/mts/device_solutions/. The Read Me files are found as PDF files in the framework folders.

Currently, Best Practice frameworks are available for DDR3 and GDDR3 testing.
