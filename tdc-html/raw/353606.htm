smart-install-3 command line tool

Subtopics

  1. Smart-install-3 command examples

Command line tool to download, install and uninstall SmarTest and related software from the Advantest Software Center.

Location

The smart-install-3 tool is installed at /opt/ate/smart_install_3/.

Help

A help page is available for or each command, for example, download, install, or uninstall.

To get a list of all commands and argument parameters run smart-install-3 without any parameters or call:

smart-install-3 --help

To display more information and all options of a specific command, include the option --help. For example:

  • smart-install-3 download --help
  • smart-install-3 install --help
  • smart-install-3 uninstall --help

Usage

smart-install-3 [OPTIONS] COMMAND [ARGS]...
Options:
  --backend [yum|softwarecenter] 
  --version      Show the version and exit 
  -h, --help     Show this message and exit

For example, to download software, use the smart-install-3 download version command.

The help page for each smart-install-3 option providing all options of the specific command is displayed with the --help option.

Options

The smart-intall-3 tool includes the following commands. Detailed information about the usage of each command is available from dedicated help pages accessible with a command of the form:

smart-install-3 command --help

Valid options vary for specific smart-install-3 being used. A high-level summary is provided below. Refer to the dedicated help pages for more details.

Commands

Commands

Description

 Usage Example

download

Downloads an rpm or tgz archive of a product (for example, SmarTest or Test Cell Access) in the specified version.

 smart-install-3 download [OPTIONS] PRODUCT VERSION TARGETDIR

smart-install-3 download smartest 8.2.3.0

install

Installs the specified product (for example, SmarTest or Test Cell Access) in the specified version.

 smart-install-3 install [OPTIONS] PRODUCT VERSION

smart-install-3 install smartestsuite 8.4.3.0

local-install

Installs the specified downloaded product from a local repository. A force downgrade to a older version is possible if a new version is already installed.

 smart-install-3 local-install [OPTIONS] SOURCE... smart-install-3 local-install --force-downgrade path_to_RPM_ package_ or_ tar.gz_archive

local-search

Searches for downloaded products stored in a local repository.

 smart-install-3 local-search [OPTIONS] SOURCE... smart-install-3 local-search path_to_local_RPM_ package_ or_ tar.gz_archive_repository

login

Logs in to the Software Center and stores your access token.

 smart-install-3 login [OPTIONS] smart-install-3 login

logout

Logs out from the Software Center and removes your access token.

 smart-install-3 logout [OPTIONS] smart-install-3 logout

search

Searches for products in the Software Center.

 smart-install-3 search [OPTIONS] PRODUCT [VERSION]

smart-install-3 search --cs smartestsuite 8.4

Searches for customer-specific SmarTest Suite releases with version numbers 8.4x.

show

Shows installed products.

 smart-install-3 show [OPTIONS] smart-install-3 show

uninstall

Uninstalls a specific version of a product.

Details: smart-install-3 uninstall --help

 smart-install-3 uninstall [OPTIONS] PRODUCT VERSION

smart-install-3 uninstall smartest 7.5

Removes all smartest versions starting with 7.5

version

Shows version of YUM, RPM, Smart Install 3, and other system information.

 smart-install-3 version [OPTIONS] smart-install-3 version

VERSION

The version of the specified product.

The "+" sign can be used to define any sign in a search pattern for a product version.

For example, 8.3.0+20200220+DEBUG searches for product versions which start with 8.3.0 followed by any sign, 20200220, followed by any sign, and ending with DEBUG.

Examples

smart-install-3 install PRODUCT VERSION

To install a SmarTest version 8.4.2.0, enter the following command:

smart-install-3 install smartest 8.4.2.0

smart-install-3 install PRODUCT [OPTIONS] VERSION

To install the latest version of SmarTest 8.4, enter the following command:

smart-install-3 install --select-latest smartest 8.4

To install the customer-specific release version of SmarTest suite 8.3.4.1 for customer 3, enter the following command:

smart-install-3 install --cs SmarTestSuite 8.3.4.1.cs.3

Options for smart-install-3 install include:

Options Description
--release Version number of released software.

For example: --select-latest smartest 8.3.2.1
--cs Version number of customer-specific release software.

For example: --cs SmarTestSuite 8.3.4.1.cs.3
--select-latest Selects the latest version of the specified product (ignored for --release).
--switch-version Runs the switch_version tool for SmarTest, SmarTest Suite or TP360. For details about the switch version tool, see .
--force-downgrade Forces a product downgrade if newer version is installed.
