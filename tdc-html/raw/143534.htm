clamp()

Specifies the clamp voltage or clamp current.

clamp() must be used together with iForce() or vForce().

When forcing voltage, the function defines the clamp current.

When forcing current, the function defines the clamp voltage. The clamp voltage additionally determines the direction of the flowing current.

For DPS128 you can specify the clamp current for both sink and source. If one parameter value is specified, a positive value means a force clamp current and a negative value means a sink clamp current.

For XPS256, the clamp() function is not supported. Use the functions vClamp() and iClamp() instead of clamp().

Each DC supply requires a minimum clamp current to work properly. If necessary, SmarTest automatically adjusts the clamp current settings to the minimum value that is normally defined in the specifications and displays the following warning in the UI report window:

Clamp current limit is smaller than minimum value and will be auto-corrected.
For the minimum clamp current distance, refer to
  • DPS128 / DPS64 specifications and Clamping and forcing current in DPS128 / DPS64 functionality and features

Syntax

dcBase& clamp(double dClamp);
dcBase& clamp(double dClampSink, double dClampSource);
Parameters

Parameter

Description

dClamp

The clamp voltage or current.

dClampSink

The sink clamp current.

This parameter is supported only for DPS128 pins.

dClampSource

The source clamp current.

This parameter is supported only for DPS128 pins.

Return Value

A reference to the dcBase object.

Example

rdi.dc().pin("DPS_1,DPS_2").vForce(1 V).iMeas().clamp(100 mA).execute();

Functional changes

  1. Introduced in SmartRDI 2.1.0
