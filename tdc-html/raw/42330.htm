Topic 42330

Parameters:

Note For detailed information about the parameters which define a dialog window, see the manual Command Interface.
  • phEventResult_t *result

    see Common Components of All Hook Functions, and the examples below in the section User-Specific Code.

  • phTcomUserReturn_t *stReturn

    see Common Components of All Hook Functions.

  • int needQuitAndCont

    In case the needQuitAndCont is set to 0, the QUIT and CONTINUE buttons are not to be displayed in the dialog window to be brought up by the driver. If the hook function provides the value of response, this value must not be adapted to a lower count of visible buttons. A response of 2 must always refer to b2s and so on.

  • char *msg

    the message to be displayed in the dialog window

  • char *b2s ... *b7s

    additional buttons with text to be displayed in the dialog window

  • long *response

    the response which button of the dialog window was pressed, ranging from 1 ("quit") over 2 to 7 (b2s to b7s) up to 8 ("continue")

  • char *input

    pointer to input string to be entered by the operator, or NULL if no input is expected.
