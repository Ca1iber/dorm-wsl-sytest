DRLPinIndexToNumber

const char *DRLPinIndexToNumber (DRLPinIndex pin_index)

This function allows mapping of pin DC/DC power units to pin numbers. A pin number is a string specified in the first column of the pin configuration window. (The pin number is the second parameter which is stored to the firmware with the DFPN firmware command.)

For further information on the data types involved see DRLPinIndex and DRLPinType.

Return Value

The function returns the number of the pin with the index pin_index. In case of an error, for example, if pin_index is invalid, the function returns NULL.

Functional changes

  1. Introduced before SmarTest 6.3.2
