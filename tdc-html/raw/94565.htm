Topic 94565

Executing the Workorder

In order to execute the workorder, proceed as follows:

  1. Switch into (or start SmarTest in) supervisor mode. For details see Starting SmarTest with supervisor mode.
  2. Call the workorder.

    Note that if the test program is started from a workorder, then all sites that are defined in the pin configuration will be automatically activated.

  3. Specify a statistically significant number of repetitions.

    If you loop over one device, about 100 repetitions are sufficient. If you test several devices, you could, for example, test 50 devices 2 times. If your testflow branches, increase the number of repetitions.

  4. Execute the work order.

    Note that the first run will usually take considerably longer than the following repetitions. One reason for this is that in an optimized testflow many time consuming operations are performed only in the first run (more precisely, when the respective testsuite is executed for the first time). But even in an unoptimized testflow, the first run will be slower than the following ones because of certain initializations.
