CallPHDriverFunc()

This API executes a PH driver function after the PH library is loaded. The ACTION_PROB_HND_CALL_STARTED/ACTION_PROB_HND_CALL_COMPLETED HVM events will be generated if the implicit event generation is turned on.

SUCCESS is returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

Code

Typical Description

Severity

PARAMETER_EXCEPTION

The value of the "FUNCTION_NAME" is empty.

RECOVERABLE

ILLEGAL_OPERATION
  • The designated session ID "XXX" does not exist.
  • The local session does not exist.
  • There is no shared library loaded.
  • The function "XXX" cannot be found in the loaded shared library.
  • The execution of function "XXX" failed.
  • Failed to issue the HVM event.

RECOVERABLE

Parameters

I/O

Parameter

Description

I

SESSION_ID

The local session ID.

I

FUNCTION_NAME

The PH driver function name.

I

PARAMETER

(optional)The parameter required by the PH driver function.

O

OUTPUT_STRING

The output string of the PH driver function.

Prototype

ParamList inputParams, outputResults;
Status syncOperation("CallPHDriverFunc", outputRestuls, inputParams, sessionID);

Examples

Example 1

This is an example for PH driver function that needs parameters.

string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams, outputResults; 
inputParams["FUNCTION_NAME"] = "ph_set_configuration";
inputParams["PARAMETER"] = 
"handler_site_ids:[ "A" "B" "C" "D" ] handler_site_mask:[ 1 1 1 1] 
smartest_site_to_handler_site_map:[ 1 2 3 4 ]"

Status retVal = syncOperation("CallPHDriverFunc", outputResults,
                          inputParams, sid);
if ( retVal.isError() ) 
{
cout<<"error code= " << retVal.code() << " description=" << retVal.text() << endl;
}

Example 2

This is an example for PH driver function that needs parameters and return values.

string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams, outputResults; 
inputParams["FUNCTION_NAME"] = "ph_get_status";
inputParams["PARAMETER"] = "die_height"

Status retVal = syncOperation("CallPHDriverFunc", outputResults,
                          inputParams, sid);
if ( retVal.isSuccess() ) 
{
cout<<"The "die_height =" <<  outputResults["OUTPUT_STRING"] << endl;
}

Example 3

This is an example for PH driver function that needs no parameter.

string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams, outputResults; 
inputParams["FUNCTION_NAME"] = "ph_die_start";

Status retVal = syncOperation("CallPHDriverFunc", outputResults,
                          inputParams, sid);
if ( retVal.isError() ) 
{
cout<<"error code= " << retVal.code() << " description=" << retVal.text() << endl;
}
