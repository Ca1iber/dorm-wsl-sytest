Topic 31289

Axis

Class Axis controls the following axis operations:

  • make axis visible/non-visible
  • create axis label
  • set frequency, time, or other domain units
  • set minimum and maximum range
  • set color
  • set grid object to the specified x and y axis
  • set axis scale to auto scale, log scale or linear scale

This class object is a member of class Graph.

label of axis.

This function returns the current axis label.

setUnit()

Axis & setUnit(const STRING & unit);

This function specifies a unit for the axis.

Parameter

unit

The unit of the axis. It can be:

  • Frequency Domain Data, "THz" "GHz" kHz" "Hz"
  • Time Domain Data, "s" "ms" us" "ns" "ps"
  • Other Domain Data,

"A" "mA" "uA" "nA" (current)

"V" "mV" "uV" "nV" (voltage)

"W" "kW" "MW" "GW" (power)

"F" "mF" "uF" "nF" "pF" (capacitance)

This unit is not merely a string but a meaningful value. This is related to a sampling parameter of trace data.

Examples

Make the specified axis non-visible

GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getXAxis(1).setVisible(false);
graphManager->setGraph(graph, 1);

This example sets the x-axis 1 to invisible.

Change the x-axis label

GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getXAxis(1).setLabel("sample x-axis");
graphManager->setGraph(graph, 1);

This example changes the label of x-axis 1 to "sample x-axis".

Change the x-axis unit

GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getXAxis(1).setUnit("ms");
graphManager->setGraph(graph, 1);

This example sets the unit of x-axis 1 to "ms".

Change axis range

GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getXAxis(1).setLabel("time domain").setUnit("us")
     .setMinRange(0).setMaxRange(400);
graphManager->setGraph(graph, 1);

This example sets the label of x-axis 1 to "time domain", the unit to "us", and the range as from 0 to 400.

Zoom in/out

GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
Axis x_axis = graph.getXAxis(1);
Axis y_axis = graph.getYAxis(1);
double x_start, x_end, y_start, y_end, x_difference, y_difference;
x_start = x_axis.getMinRange();
x_end = x_axis.getMaxRange();
y_start = y_axis.getMinRange();
y_end = y_axis.getMaxRange();
x_difference = x_end - x_start;
y_difference = y_end -y_start;
// Zoom In x2
x_axis.setMinRange(x_start + x_difference/4);
x_axis.setMaxRange(x_end - x_difference/4);
y_axis.setMinRange(y_start + y_difference/4);
y_axis.setMaxRange(y_end - y_difference/4);
graph.setXAxis(x_axis,1).setYAxis(y_axis,1);
graphManager->setGraph(graph, 1);

This example zooms in the x-axis by 2. You will see half of the graph.

set the axis scale

GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
//auto scale
graph.getXAxis(1).autoScale();
graphManager->setGraph(graph, 1);
//Log scale
graph.getXAxis(1).logScale();
graphManager->setGraph(graph, 1);
//Linear scale
graph.getXAxis(1).linearScale();
graphManager->setGraph(graph, 1);

This example sets the scale of the x-axis 1 to auto, log and linear in sequence.
