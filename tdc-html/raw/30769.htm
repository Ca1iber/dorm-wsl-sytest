Topic 30769

MOVE_EVENT_STREAM

Subtopics

  1. Associated Syntax Entities

Moves the current data log stream which was generated by event data logging (see the Event Data Logging manual for more information) to a specified file, and then deletes the contents of the data log stream.

If no destination file is specified, only the contents of the data log stream will be deleted.

As the data log stream continuously grows in size during a production test run, this function should be used to control the size of the data log stream.

The following examples copies the current data log stream to the file /my_data_storage/dlstream1 and then deletes the contents of the current data log stream.

MOVE_EVENT_STREAM(/my_data_storage/dlstream1);

Without a destination file, only the contents of the data log stream will be deleted.

MOVE_EVENT_STREAM();
