PRTG? - (PmuxRouTinG)

PRTG? is an internally used command, which may be visible in error reporting.

If a PRTG? error appears in the ui Report Window, check the following:
  • If you are calling functions from the rdi.util() class within a block of RDI_BEGIN() and RDI_END(), check that this is correct.
  • If you have defined the keyword PMUX_CTRL in the RDI_Configure file, then ensure you have the PMUX_CTRL pins in the pin configuration.
  • That you have the correct configuration of utility lines / PMUX in the Routing Tools. See also Routing Tools (SmartRDI), SmartRDI: DUT board connections control by Routing Tools, and subtopics.

Functional changes

  1. Introduced in SmarTest 7.10.1
