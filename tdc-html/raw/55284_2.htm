Syntax of fract()

The fract() function can only be used with the period statement within a timing set. The general format is as follows:

period = fract(<numerator>,<denominator>,<global_var>)

The function of the individual parameters is as follows:

  • <numerator>:

    Specifies the numerator of the fraction. This can be a constant or a (base or equation) variable, but the value must be an integer; if you specify decimal places, they will be ignored.

  • <denominator>:

    Specifies the denominator of the fraction. This can be a constant or a (base or equation) variable, but the value must be an integer; if you specify decimal places, they will be ignored.

  • <global_var>:

    Specifies the name of a spec variable. The ports for which the ratios are to be preserved must set this spec variable to a global scope in the multi-port specification (see Global and local scope of base variables).

Functional changes

  1. Introduced before SmarTest 6.3.2
