# Creating a multiport burst

A multiport burst is the combination of one or more port bursts to be executed in parallel in a multiport test.

Name: Unique string without blanks.

Port Bursts:

- Port: Select one or more ports to them to a multiport burst. You cannot assign two or more ports that share the same pins.
- Sync Group (optionally): Specify a sync group per port or use the DEFAULT sync group. The sync group forces all its ports to start at the same point in time.

Folder: Specify the location of the multiport burst file.
