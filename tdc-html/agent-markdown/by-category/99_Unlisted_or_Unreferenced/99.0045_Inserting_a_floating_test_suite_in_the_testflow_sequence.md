# Inserting a floating test suite in the testflow sequence

This window displays all the existing [floating test suites](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.03_Floating_test_suite.md>).

After [Creating a floating test suite](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.04.03_Creating_a_floating_test_suite.md>) on the [Test Suites page](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.01.01_Test_Suites_page.md>), you can add it to the testflow sequence with this dialog.

Insert Mode

- Insert the test suite

The floating test suite is inserted to the testflow sequence as a [Run and Branch](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.01_Run__and__Run_and_Branch__test_suites.md>) node.

- Insert a copy of the test suite

A new [test suite](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01_Test_suites.md>), which is the copy of the floating test suite, is added to the testflow sequence as a Run and Branch node.
