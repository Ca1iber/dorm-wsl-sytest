# Wafer summary tab

Each row contains the information for one wafer.

The details for each row can be displayed:

- In a raw data view by selecting it.
- In a bin wafer map by selecting it and choosing Show In > Bin Wafer Map from the shortcut menu.

The rows can be sorted by clicking the column titles and filtered by entering match conditions in the table filter (top row with blue background).
