# Test summary preferences

Visible columns: Selected columns are displayed in the tabs. For a description of the columns, see [Test summary tab](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.13.03.02.01_Test_summary_tab.md>).

Select All: Check all columns

Deselect All: Uncheck all columns (except those that cannot be deselected)

Up: Moves the selected columns one spot higher

Down: Moves the selected columns one spot lower
