# New Pin Attributes reference

The Name field lets you enter the name of the new pin attributes file.

The Location field displays the location where the configuration file is saved. You cannot modify this field.

You can edit the pin attributes using the [Pin Attribute Setup Expert Tool](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.17_Pin_Attribute_Setup_Expert_Tool.md>).
