# Configuring the Test Suites page

- Table Sort Mode in Test Suites ~ Flags Page

Specify whether the data on [Test Suites page](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.01.01_Test_Suites_page.md>) to [Flags page](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.01.06_Flags_page.md>) are sorted either in a single column or in multiple columns.

- Test Function Name Edit Mode

Specify what happens when you rename a test function shared by several test suites in a testflow.

  - Always Ask: A window opens to ask whether you wish to change the name only in this test suite or in all the test suites sharing the same test function.
  - Apply to One: The test function name is changed only in the test suite where you edited it, without confirmation.
  - Apply to All: The test function name is changed in all the test suites sharing this test function without confirmation.

- Automatic Validate Setups

Check this to highlight the setup file in yellow on the Test suites page if it has not been loaded or the primary set does not exist in the setup files.

- Test Suite Show

Specify which types of test suites are to be displayed on the Test suites page.

  - All: All types of test suites
  - Only Floating: Only [floating test suites](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.03_Floating_test_suite.md>)
  - Only Special: Only [Special test suites](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.02_Special_test_suites.md>)

- Execution Result

Specify whether the results of all the sites, or only of the site in focus are to be shown.

- Visible Columns

Specify which columns are to be displayed on the Test Suite page.
