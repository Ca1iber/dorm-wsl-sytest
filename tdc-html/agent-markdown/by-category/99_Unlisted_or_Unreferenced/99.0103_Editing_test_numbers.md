# Editing test numbers

## Procedure

-  Load the [test table](<../02_System_reference/02.10_Data_Logging/02.10.01.08.03_Working_with_test_tables.md>) in the [Test Program Explorer](<../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02_Test_Program_Explorer.md>).
-  Open the test table.

The table is displayed in the test table editor.

-  Right-click a cell in the Test Number column and open the [Test Numbering preferences](<99.0001_Test_Numbering_preferences.md>).
-  Adjust the settings when needed and click OK.
-  Select all cells in the Test Number column that you want to re-number.
-  Right-click a selected cell and choose Generate Test Numbers.

New test numbers are generated in all selected cells.

-  Manually adjust the numbers if desired.
-  Save the changes using the shortcut menu in the Test Program Explorer.
-  Run the testflow to check for collisions.

Any collisions are marked with a dotted red border in the test table:

  ![Testflow cell with duplicate test number](<../../../raw/110510.png>)
-  If there are collisions, adjust the loop increments to eliminate them.
