# Test correlation preferences

Visible columns: Selected columns are displayed in the tabs. For a description of the columns, see [Test summary tab](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.13.03.02.01_Test_summary_tab.md>) and [Correlation data store structure](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.13.02.02.04.01_Correlation_data_store_structure.md>).

Columns highlighted in cyan cannot be moved below columns without a cyan background.

Select All: Check all columns

Deselect All: Uncheck all columns (except those that cannot be deselected)

Up: Moves the selected columns one spot higher

Down: Moves the selected columns one spot lower
