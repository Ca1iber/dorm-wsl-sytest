# Working with the Pattern Editor

The [Pattern Editor](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.02_Pattern_Editor.md>) has two [display modes](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.02.01_Collapsed_and_expanded_mode.md>): expanded and collapsed. The expanded mode shows the cycles as they are executed and displays failure data. The collapsed mode does not display the dynamic behavior of the sequencer instructions.

For primary patterns (start label), to collapse or expand the display, click ![Expand/collapse button](<../../../raw/99926.png>).

Failing tests are marked in the annotation ruler on the right. A failing test point is highlighted in red. To go directly to a failed test point, click the annotation marker.

In expanded mode, to generate the annotations for a marked line, click ![Refresh result display button](<../../../raw/99927.png>). Markers and annotations must be enabled (Window > Preferences > Advantest V93000 > Pattern Debug Tool).

The ![Align display button](<../../../raw/99929.png>) icon aligns the display with other result analysis tools. Right-click to configure, select, or save an editor layout.

Result details and vector parameters are shown in the [properties view](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.02.03_Pattern_editor_properties_view.md>), which also permits you to change values.

The characters in brackets (SC, DVC, PW, etc.) indicate the [formats](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.02.02_Signal_and_pin_group_representations.md>) of the displayed signals.
