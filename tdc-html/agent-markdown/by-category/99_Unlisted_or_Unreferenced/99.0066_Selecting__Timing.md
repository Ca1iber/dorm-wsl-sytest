# Selecting 'Timing'

To select the desired timing setup.

- Select the timing mode ([Equation based timing setup](<../01_Getting_started/01.07_Testing_a_Basic_Digital_Device/01.07.01.04.01_Equation_based_timing_setup.md>) or [Fixed timing](<../02_System_reference/02.06_Command_Reference/02.06.06.01.07_Fixed_timing.md>))
- Select the Equation and spec set
- Select the timing set

You can use the "Equation" and "Set" filters to display items whose names include the string you type in the filter box. Note that a dot "." is used as a wild card.
