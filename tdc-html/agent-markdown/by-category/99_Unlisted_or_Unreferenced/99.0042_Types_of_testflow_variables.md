# Types of testflow variables

- Userflag

An integer value (0 or 1). Can be viewed and edited during [Test Program](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.31_Test_Program.md>) execution from within the [User Flags](<../02_System_reference/02.09_Test_Program_Management/02.09.01.06.02.01_Setting_User_Flags.md>) window.

- String

Text (for the maximum string number see [SmarTest character and number limits](<../01_Getting_started/01.05_SmarTest_character_and_number_limits/01.05_SmarTest_character_and_number_limits.md>)). String values must be enclosed in double quotes, for example, "abc".

- Double

A double number or an expression that represents a double value (available range [-123.456 .. 789.654]).

Typically, such variables take result values of [Test suites](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01_Test_suites.md>).
