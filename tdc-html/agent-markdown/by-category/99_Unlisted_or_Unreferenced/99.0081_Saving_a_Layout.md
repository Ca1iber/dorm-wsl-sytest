# Saving a Layout

## Procedure

-  To save a layout as a new layout, type a new unique name for the layout.
-  To save a layout under an existing name, press Ctrl+Spacebar and select one of the listed layouts.
-  On the [Layout preference page](<../01_Getting_started/01.01_SmarTest_Work_Center/01.01.14.10_Layout_preference_page.md>) you can also assign a default layout, or individual layouts per pattern.
-  If you have [configured and saved](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.02.06.02_Configuring_the_layout_of_the_editor.md>) several layouts for a pattern in the Pattern Editor, you can [select](<99.0080_Selecting_a_Layout.md>) these layouts also in the Pattern Explorer, in the Layout on Pattern Editor column (you may need to scroll to see the column).
-  Every time you start the Pattern Editor, this layout is used to display the pattern.
