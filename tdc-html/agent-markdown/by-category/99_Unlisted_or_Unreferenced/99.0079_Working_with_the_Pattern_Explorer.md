# Working with the Pattern Explorer

## Procedure

 You can use the Pattern Explorer together with the [Pattern Editor](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.02_Pattern_Editor.md>) to [create](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.01.02_Creating_a_pattern.md>), [clone](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.01.06_Cloning_a_pattern.md>), [edit](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.01.14_Editing_properties_in_the_Pattern_Explorer.md>),and [debug](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.02.06.13_Displaying_failure_data.md>) patterns and [bursts](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.01.03_Viewing_and_editing_bursts_in_the_Pattern_Explorer.md>), and [save partial](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.01.15.05_Saving_patterns_in_separate_files__Save_Partial_As.md>) patterns.

-  To highlight executed patterns with results, click ![Search Result Ready Label Icon](<../../../raw/99522.png>).
-  To link the active editor to the Pattern Explorer selection, click ![Navigator view - link with editor button](<../../../raw/91710.png>).
-  If you have [configured and saved](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.02.06.02_Configuring_the_layout_of_the_editor.md>) several layouts for a pattern in the Pattern Editor, you can [select](<99.0080_Selecting_a_Layout.md>) these layouts also in the Layout on Pattern Editor column (you may need to scroll to see the column).

Every time you start the Pattern Editor, this layout is used to display the pattern.
