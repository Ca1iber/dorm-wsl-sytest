# Inserting a 'Multi Bin' node

The multi bin is used to invoke a test method for bin management, hence, before you insert a multi bin, you have to insert and setup a floating bin. This is done in the Bins page of the Flow Data Editor (see [Adding bins](<99.0049_Adding_bins.md>)).
