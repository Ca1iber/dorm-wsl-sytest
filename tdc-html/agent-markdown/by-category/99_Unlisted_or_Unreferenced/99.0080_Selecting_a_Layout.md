# Selecting a Layout

## Procedure

-  If you have [configured and saved](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.02.06.02_Configuring_the_layout_of_the_editor.md>) several layouts for a pattern in the Pattern Editor, you can select one of these layouts either

  - in the Pattern Editor (with a right-click), or
  - in the Pattern Explorer in the Layout on Pattern Editor column (you may need to scroll to see the column).

-  The Select Layout dialog from the Pattern Editor offers additional sorting features. For example, the list of available layouts can be reduced by typing text into entry field.
