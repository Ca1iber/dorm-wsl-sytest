# Creating a pattern

To [create a new pattern](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.01.02_Creating_a_pattern.md>), consisting of a STOP instruction only, specify:

Pattern Name: Unique string of up to 128 alpha-numeric characters without blanks

Pattern Type:

- Main: Regular pattern, most commonly used
- SJMP: Sub-pattern, jump from a main pattern
- SubRoutine: Sub-pattern, jump to a main pattern
- Burst: Group of main patterns, executed in series without any break. For port bursts (PortBurst) and multiport bursts (MPBurst) see [Multiport Burst Editor](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.03_Multiport_Burst_Editor.md>).
- DSRC: Pattern for Digital SouRCe Memory

Port: The port the new pattern is related to (default is @ (all))

Memory Type: SM (Sequencer Memory - default), SHMEM (Shared Memory)

Wavetable: The base wavetable used for the Pattern Editor to display device cycle names or state characters

Folder:  The location of the pattern file (applies only in combination with a pattern master file)
