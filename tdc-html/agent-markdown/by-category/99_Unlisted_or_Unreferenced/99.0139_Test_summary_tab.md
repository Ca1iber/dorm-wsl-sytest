# Test summary tab

The automatic updates from the system data log stream can be stopped by clickin "pause" on SmarTest's toolbar and resumed by clicking "resume".

Each row contains the information for one test.

The details for each row can be displayed:

- In a stream data view by selecting it.
- In a result graph by selecting it and choosing the desired type from the Show In submenu of the shortcut menu.

The display for each test can be split per wafer, site, and/or pin by clicking the appropriate button on SmarTest's toolbar:

- Group by wafer
- Group by site
- Group by pin

The rows can be sorted by clicking the column titles and filtered by entering match conditions in the table filter (top row with blue background).
