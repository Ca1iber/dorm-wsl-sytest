# Editing an expression-based pin group

To add pins, pin aliases, or pin groups to the pin group

## Procedure

-  Select the desired item in the Available Group/Pin List field.
-  Click one of the three operator buttons:

  - Union: The pins of the selected item are added to the group you are editing.
  - Difference: The pins of the selected item are removed from the group you are editing.
  - Intersection: The group is restricted to those pins that were already in the group and are also part of the new item.

The operator and new item are added to the expression that defines the pin group.

-  If desired, you can manually edit the expression, for example, to add parentheses.
-  From the Component Type menu, choose the type of pins that are to be active in the new group:

  - I: input and IO pins
  - O: output and IO pins
  - IO: input, output, and IO pins
  - DC: DC pins

All pins that match the expression and the selected type become active members of the new pin group.

Pins that match the expression but not the type become inactive members.

If the pin group that is being edited is used in an expression for another pin group with a different type, they may become active members of that group.

-  To verify that the expression produces the desired result, click Evaluate.

The list of pins in the expression-based group is displayed in Group Members.
