# Inserting a good or bad Bin

This topic covers how to insert a good or a bad bin.

In the "Software" section:

- In the Bin Number window, enter an arbitrary number you wish to allocate to the bin.

To be compatible with STDF, the number must be between 0 and 32767.

- In the description window, enter a description name for the bin

The software bin is a virtual bin used for diagnostic purposes, for example, statistical monitoring of production.

You can, however, map several software bins to one hardware bin (hardware bin).

When you enter a bin number in the software section, this software bin will be associated with the hardware bin number you enter in the Hardware Bin Number box.

In the "Hardware" section:

- The hardware bins that have already been defined can be selected by clicking on the arrow at the right end of the selection box. The hardware bin number is a positive integer (0...999), that is used by the Prober/Handler library for physical binning of the DUT after the test.
- The description you enter here (maximum 256 characters) will appear in the Properties view and in the result display (during a production run).

In a normal test floor situation, you normally, do not want too many physical (hardware) bins, however, for the purpose of better differentiation of DUT performance, statistical analysis and monitoring of your production, you may wish to have extra bins (software bins) which you can associate with your few physical bins.

For this purpose you define "Soft" bins and "Hard" bins and associate them with each other via the bin numbers in the "Software" and "Hardware" windows.

In the "Attributes" section:

You can change the bin color from the default (green for good bin and red for bad bin).

You can also select:

- "Reprobe", in which case the device will be tested again after it has been binned.
- "Overon", in which case the testflow continues even if a device falls into a stop bin.

In the "Binning" section:

You can change the pre-selected option (good bin/bad bin) to the alternative type of bin. In this case, you may also wish to change the bin color in the attribute section.
