# Using the Bins page

On this page, you can edit the bins in the testflow.

Three types of bins are displayed on the [Bins page](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.01.04_Bins_page.md>)

- Stop [Bins](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.06_Bins.md>)
- Special bins (displayed with a cyan background)
- Floating bins (displayed with a gray background)

Common tasks on this page

- [Insert a bin in the testflow](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.05_Inserting_a_bin_into_the_testflow.md>)
- Delete a floating bin

The normal bin node can only be deleted in the [Flow Sequence Editor](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.02_Flow_Sequence_Editor.md>).
