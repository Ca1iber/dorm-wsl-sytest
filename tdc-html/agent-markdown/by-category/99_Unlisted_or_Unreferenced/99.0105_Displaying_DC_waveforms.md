# Displaying DC waveforms

You must have executed a dynamic DC test and must not have disconnected the pins.

- Expand the executed pattern to display the results.
- If you want to see the results of a specific site, select the site in the Site Control window.
- In the Pattern Editor, right/click the Sdd column and choose Show in Waveform.

The voltage ramp on the Sdd pin is displayed in the Waveform view.
