# Creating a Digital Capture setup (1)

## Procedures

### Capture mode:

Depending on the wavetable used by the capture pattern, the capture mode is set to [Selective](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.01.02.07.01_Digital_Capture_Modes.md>) or [Sequential](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.01.02.07.01_Digital_Capture_Modes.md>)

If the pattern uses a wavetable containing selective capture actions ('C' for Capture, or 'D' for Do not Capture), the [Selective](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.01.02.07.01_Digital_Capture_Modes.md>) mode is set, otherwise, the [Sequential](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.01.02.07.01_Digital_Capture_Modes.md>) mode is set.

If none of the device pins is defined as a capture pin, the capture mode is set to Undefined.

### Resolution:

- Standard: One capture sample per test system period.
- Double: Two capture samples per test system period (for [Sequential](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.01.02.07.01_Digital_Capture_Modes.md>) capture mode only).
- Statemap: The number of capture samples per test system period are read directly from the X-mode definitions in the STATEMAP section of the pattern's wavetable.

### Finish / Next

To define the capture pins for the pattern only, click Finish.

To define also the pins for the vector variable, click Next.
