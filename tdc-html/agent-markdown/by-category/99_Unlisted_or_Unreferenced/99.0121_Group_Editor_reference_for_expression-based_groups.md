# Group Editor reference for expression-based groups

- Available Group/Pin List: The list of all available pins, pin aliases, and pin groups. Pins with a check mark in front of them are part of the pin group.
- Operator: Clicking one of the three buttons links the selected item (pin, alias, or group) with the existing expression:

  - Union: All pins that are in either the existing expression, or the new item are part of the pin group.
  - Difference: All pins that are in the expression, but not the item are part of the group.
  - Intersection: Only pins that are in both in the expression and the item are part of the group.

- Component Type: The type of pins that are active in the pin group. (Pins matching the group expression, but not the content type, are inactive members of the pin group.)

  - I: input and IO pins
  - O: output and IO pins
  - IO: input, output, and IO pins
  - DC: DC pins

- Group Members: The list of pins in the pin group and their types. The list is not updated automatically when the expression changes; you must click Evaluate.
- Group Expression: This field contains the expression, from which the members of the pin group are calculated. It can be changed by clicking the operator buttons and can also be manually edited (for example, to add parentheses).
- Evaluate: Clicking this button updates the Group Members list.
