# Using the Flow Sequence Editor

The flow sequence editor displays a graphic view of the testflow. For a long testflow, you can easily browse the flow within the Outline view.

- [Inserting a node](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.11.02_Inserting_a_node.md>)
- [Deleting nodes](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.11.03_Deleting_nodes.md>)

To delete the [Run and Branch node](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.01_Run__and__Run_and_Branch__test_suites.md>) and [Flow control nodes](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.02_Flow_control_nodes.md>), [wide select](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.11.01_Narrow_selection_and_wide_selection.md>) them.

- [Cutting, copying and pasting nodes](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.11.04_Cutting__copying_and_pasting_nodes.md>)
- [Moving nodes](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.11.05_Moving_nodes.md>)

To move the Run and Branch node and Flow control nodes, [wide select](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.11.01_Narrow_selection_and_wide_selection.md>) them.

- [Cloning nodes](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.11.06_Cloning_nodes.md>)
- [Grouping nodes](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.11.07_Grouping_nodes.md>)

To group the Run and Branch node and Flow control nodes, [wide select](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.11.01_Narrow_selection_and_wide_selection.md>) them.

Click a node to edit the node's properties in the [Properties view](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.04_Testflow_Properties_view.md>).
