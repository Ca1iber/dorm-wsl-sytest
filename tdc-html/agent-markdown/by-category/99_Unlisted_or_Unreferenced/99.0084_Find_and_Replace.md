# Find and Replace

## Procedure

-  Use Find/Replace to search and replace in single vector cells and in series of vector cells. You can also search for comments.
-  Do not use the Find/Replace dialog if you are searching for [sequencer instructions](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.02.06.10_Inserting__editing__and_deleting_sequencer_instructions.md>). Click ![Hide all vectors in current editor button](<../../../raw/99932.png>) (Hide all vectors in current editor) instead.
-  If the "Space is Delimiter" option is selected, you search will be limited to one cell only. If the option is not selected you search will go over multiple cells.

## Example

"Space is Delimiter" selected: The string 111 is interpreted as one string.

"Space is Delimiter" not selected: The string 111 is interpreted as a sequence of three consecutive strings of 1.

To search for comments, select the "Space is Delimiter" option. The tooltip displays how the search pattern is interpreted.

You may also use the advanced Find/Replace dialog. To enable it, go to Window > Preferences > Advantest V93000 > Pattern Debug Tool.
