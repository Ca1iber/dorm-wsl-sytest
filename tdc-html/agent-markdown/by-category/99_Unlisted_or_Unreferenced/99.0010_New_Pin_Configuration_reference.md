# New Pin Configuration reference

The Name field lets you enter the name of the new pin configuration.

The Location field displays the location where the configuration file is saved. You cannot modify this field.

You can edit the pin configuration using the [Pin configuration tool](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18_Pin_configuration_tool.md>).
