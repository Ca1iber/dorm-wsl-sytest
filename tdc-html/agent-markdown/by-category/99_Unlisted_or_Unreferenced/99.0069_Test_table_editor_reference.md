# Test table editor reference

In this view, you can edit test tables, especially [TMLimits tables](<../02_System_reference/02.10_Data_Logging/02.10.01.08.01.03_Using_TMLimits_to_manage_test_numbers.md>).

Double-click a cell to edit is content or use the shortcut menu:

- Add Row: Add a new row (test)
- Delete Rows: Delete the selected rows
- Add Column: Add a column (field)
- Delete Columns: Delete the selected columns
- Test Numbering Preferences: Specify [numbering settings](<99.0001_Test_Numbering_preferences.md>)
- Generate Test Numbers: [Generate](<../02_System_reference/02.10_Data_Logging/02.10.01.08.01.01_Generating_test_numbers_from_the_SmarTest_GUI.md>) new test numbers in selected cells
- Clear Test Numbers: Remove test numbers from selected cells

The other commands are standard Eclipse commands.
