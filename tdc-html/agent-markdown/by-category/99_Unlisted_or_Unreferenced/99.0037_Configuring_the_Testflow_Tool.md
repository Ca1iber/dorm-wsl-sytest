# Configuring the Testflow Tool

- Resolve name conflicts by adding suffix automatically

  - If you check this option, the name of the pasted node is the original name with "_1" suffix.
  - If you clear this option, pasting a node opens the Name Conflict window prompting you to enter a new name for the pasted node.

- Synchronize selection between [Flow Data Editor](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.01_Flow_Data_Editor.md>) and [Flow Sequence Editor](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.02_Flow_Sequence_Editor.md>)

Check this to synchronize the display of the test component between the two editors.

For example, if you click a test suite in the Flow Sequence Editor, the test suite will also be in focus in the Flow Data Editor.

- Create only UTM based testflow

Check this to allow you only [create a testflow](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.02_Creating_a_testflow.md>) based on [universal test methods](<../02_System_reference/02.07_Test_Method_Reference/02.07.02_Universal_Test_Method.md>), or to insert test suites based on universal test methods.

- Use which UTM executor for single test suite execution

Here you specify which UTM executor is used for single testsuite execution.

- Startup options

Here you specify whether the last opened editor (the Flow Data Editor or the Flow Sequence Editor), or both editors will be opened, when you [open the Testflow Tool](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.01_Opening_the_Testflow_Tool.md>) again.
