# Data Log Explorer view

## Toolbar

![Data Log Explorer view_Load icon](<../../../raw/136276.png>) Load additional logs.

![Data Log Explorer view_Unload All button](<../../../raw/136277.png>) Unload all loaded logs. (The system data log stream cannot be unloaded.)

## Data store icons

![Data Log Explorer view_Data logs icon](<../../../raw/136319.png>) Folder for all data stores (not itself a data store)

![Data Log Explorer view_System data log stream icon](<../../../raw/136320.png>) System data log stream

![Data Log Explorer view_EDL data log icon](<../../../raw/136321.png>) EDL data log

![Data Log Explorer view_STDF data log icon](<../../../raw/136322.png>) STDF data log

![Data Log Explorer view_Correlation data store icon](<../../../raw/136323.png>) Correlation data store (created by correlating two or more other data stores)

## Shortcut menu

Use the shortcut menu to open, load and unload, merge, correlate, and export logs and to pause and restart updates from the system data log stream.
