# Copying and inserting with Insert Special

## Procedure

-  To insert one vector row, choose Insert Data from first Selected Vector. This duplicates the first vector row that you previously highlighted.
-  To insert one or more rows, select Insert Data from Paste Buffer (n lines). In this case you must have copied the vector rows in a previous step.
-  If you want to insert the copied data without any instructions, clear the Include Instructions check box.
-  In the Repeat Count field, type how often you want the vectors or data to be inserted.
