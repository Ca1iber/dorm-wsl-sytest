# How to configure the block diagram output (Follow Site Control)

## Follow Site Control

Select Block Diagram Follows the Site in Focus to always link the hardware information in the Hardware view to the site in focus.

Clear this option to keep the hardware information link with the original site when the focus changes to a different one.
