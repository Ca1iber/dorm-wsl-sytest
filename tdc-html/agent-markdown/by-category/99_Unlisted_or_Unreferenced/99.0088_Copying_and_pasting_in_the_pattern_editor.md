# Copying and pasting in the pattern editor

Pasting cells overwrites the content of existing cells. It does not insert new cells.

## About this task

When [pasting](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.02.06.04_Editing_patterns.md>) copied pattern areas, you must differentiate between the following cases:

## Procedure

-  Copying and pasting one vector line.
-  Copying and pasting more than one vector line.

If the highlighted target vector lines are an exact multiple of the copied lines, the copied lines will be pasted multiple times. Otherwise, the copied lines will be inserted only once.

-  Copying and pasting particular cells of vectors.

The target region can be a single cell, multiple cells equivalent to the source region, or the exact multiple of all cells of the source region. The status line of the Pattern Editor indicates the format of the copy and paste regions.

  - If the target region consists of one cell, the source region will be pasted once. The highlighted target cell will be considered to be the left upper cell of your region to be copied.
  - If the target region consists of an exact multiple of all cells equivalent to the source region, the source region will be pasted multiple times, both vertically and horizontally.
  - If the target region does not consist of an exact multiple of all cells equivalent to the source region, the source region will be pasted only once.

-  Copying and pasting a test point.

Copies the test point only, but not the event. The new test point refers to the same event as the source test point.

-  Cutting and pasting a test point.

Moves the test point. In its new location, the test point refers to the same event as before.

-  Filling a large number of cells with repeating content.
