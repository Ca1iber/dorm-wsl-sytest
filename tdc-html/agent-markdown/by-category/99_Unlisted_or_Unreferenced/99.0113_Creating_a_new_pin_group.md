# Creating a new pin group

- In the Test Program Explorer, right-click the Group entry of the pin configuration section and choose New.
- In the New Group dialog, specify the type of the group - fixed or expression-based.
- Enter the name of the new pin group.
- Click OK.

Depending on the type of the new group:

- [Editing a fixed pin group](<99.0119_Editing_a_fixed_pin_group.md>)
- [Editing an expression-based pin group](<99.0120_Editing_an_expression-based_pin_group.md>)
