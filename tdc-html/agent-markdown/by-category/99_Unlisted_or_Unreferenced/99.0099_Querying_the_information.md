# Querying the information

To query the [testflow](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01_Introduction_of_the_Testflow.md>) information on the [Information page](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.01.08_Information_page.md>), enter the following line in an "[ACTIONS](<../02_System_reference/02.09_Test_Program_Management/02.09.01.02.05.02.14_dev_name.md>)" section of the [Application Model](<../02_System_reference/02.09_Test_Program_Management/02.09.01.02_Application_Model.md>) file.

- To query the Device Name entry

*device = [GET_TEST_INFO](<../02_System_reference/02.09_Test_Program_Management/02.09.01.02.05.02.36_GET_TEST_INFO.md>) ([dev_name](<../02_System_reference/02.09_Test_Program_Management/02.09.01.02.05.02.14_dev_name.md>));

- To query the Device Revision entry

*device = GET_TEST_INFO ([dev_rev](<../02_System_reference/02.09_Test_Program_Management/02.09.01.02.05.02.15_dev_rev.md>));

- To query the Test Revision entry

*device = GET_TEST_INFO ([test_rev](<../02_System_reference/02.09_Test_Program_Management/02.09.01.02.05.02.60_test_rev.md>));

- To query the Description entry

*device = GET_TEST_INFO ([test_desc](<../02_System_reference/02.09_Test_Program_Management/02.09.01.02.05.02.59_test_desc.md>));
