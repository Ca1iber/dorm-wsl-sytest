# Hardware bin summary tab

Each row contains the information for one hardware bin.

The display for each bin can be split per wafer by clicking the ![Data log summary view_Toolbar, Group by Site button](<../../../raw/136463.png>) button on SmarTest's toolbar.

The rows can be sorted by clicking the column titles and filtered by entering match conditions in the table filter (top row with blue background).
