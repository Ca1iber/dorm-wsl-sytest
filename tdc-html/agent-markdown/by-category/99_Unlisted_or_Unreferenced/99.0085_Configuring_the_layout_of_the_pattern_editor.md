# Configuring the layout of the pattern editor

## Procedure

-  Add w/Selector >

Signals in the state character (SC) format can be added with a selector. That is, you can assign SC signals to groups. The signal(s) appear(s) indented underneath the selector name.

-  Add Members >

A Pin Group can be added as such, or you can add the individual members of the Pin Group.

You [save](<99.0081_Saving_a_Layout.md>) and [select](<99.0080_Selecting_a_Layout.md>) a layout in the editor, either the pattern editor or on a sync group page of the multiport burst editor.

 Note In order to list DC Scale signal pins in the Configure Layout dialog, you must set the amount of test points in the .technology file to greater than 0. For instructions see [Editing technology data](<../01_Getting_started/01.01_SmarTest_Work_Center/01.01.10.03.03_Editing_technology_data.md>), and [Technology file for a device](<../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.01.02_Technology_file_for_a_device.md>) for details.
