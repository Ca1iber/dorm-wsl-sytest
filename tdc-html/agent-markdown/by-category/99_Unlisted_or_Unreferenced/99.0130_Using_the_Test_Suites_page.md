# Using the Test Suites page

On this page, you can edit the test suite settings.

Three types of test suites are shown on the [Test Suites page](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.01.01_Test_Suites_page.md>)

- ["Run" and "Run and Branch" test suites](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.01_Run__and__Run_and_Branch__test_suites.md>)
- [Special test suites](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.02_Special_test_suites.md>) displayed with a cyan background
- [Floating test suite](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.03_Floating_test_suite.md>) displayed with a gray background

Common tasks on this page

- Set the [Test suite flags](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.04_Test_suite_flags.md>)
- [Set Up a Special Testsuite](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.04.02_Setting_up_a_special_test_suite.md>)
- [Create a floating test suite](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.04.03_Creating_a_floating_test_suite.md>)
- Delete a floating test suite and special test suite

The Run and Branch node and Run node can only be deleted in the Flow Sequencer Editor.

- [Edit a testsuite in the Flow Data Editor](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.06_Editing_a_test_suite_in_the_Flow_Data_Editor.md>)
- [Run a testflow](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.03_Running_a_testflow.md>)
- Configure this page in the [Test Suites preference page](<../01_Getting_started/01.01_SmarTest_Work_Center/01.01.14.26_Test_Suites_preference_page.md>)
- Configure how the annotation is displayed in the [Table Annotations preference page](<../01_Getting_started/01.01_SmarTest_Work_Center/01.01.14.29_Testflow_Tool_-_Table_Annotations_preference_page.md>)
