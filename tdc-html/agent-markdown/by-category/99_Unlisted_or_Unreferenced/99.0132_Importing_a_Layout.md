# Importing a Layout

## Procedure

-  When importing pattern editor layouts of previous SmarTest versions, you can differentiate them by their type suffix:

  - Classic, Multi, Single: Legacy layouts of the blue-window pattern debug tool
  - STWC-PDT: Legacy layouts of the Java-based Pattern Debug Tool
  - PDT: Current layouts of the Eclipse-based Pattern Debug Tool

-  The Layout Import Wizard provides the following options:

Overwrite existing layouts: Default is on (yes). If switched off, the import will create a copy. A second import with the same setting will overwrite the copy.

Target Location

  - Shared: Saves the layout(s) independently of the current pattern (master) file.
  - Current Vector Context: Binds the layout(s) to the current pattern (master) file.

Signal Modifier

  - DVC, SC, PW: Defines the initial display format in the pattern editor.

The resulting data representation may vary from the original layout.
