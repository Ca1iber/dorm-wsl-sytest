# Waveform view

This view displays the contents of the array selected in the [C/C++ editor](<../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.03.01_C_C___editor.md>).

The heading displays the name and type of the variable being graphed.

## Toolbar

Clicking "Clear Waveform" (![icon - Clear Quick Viewer](<../../../raw/107074.png>)) removes the currently displayed waveform from the view.

Clicking "Show Waveform on Signal Analyzer" (![icon - Run Signal Analyzer](<../../../raw/107075.png>)) displays the current waveform in the [Signal Analyzer Tool](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.26_Signal_Analyzer.md>).

Choosing Save As from the menu (![icon - menu](<../../../raw/64022.png>)) lets you save the current waveform as an ASCII file in the same format used by the Signal Analyzer Tool.
