# Artifact name

The artifact name is the representation of a test method project name in the test method library.

By default it is the same as the test method project name.

When you rename a test method project, you can choose to change the artifact name simultaneously or not. You can also [change the artifact name manually](<99.0122_Changing_the_artifact_name_manually.md>).
