# Histogram properties

## Titles tab

Chart title: The title of the chart, displayed at the top.

Chart subtitle: The subtitle of the chart, displayed below the title.

Frequency Axis (Count): The title for the right frequency axis.

Frequency Axis (Percentage): The title for the left frequency axis.

Value Axis: The title for the data axis.

## Scales tab

Minimum: The lowest value displayed on the axis.

Maximum: The highest value displayed on the axis.

Lower Limit and Upper Limit: The limits with which the displayed test has been executed.

Bin Count: The number of categories into which the data axis is divided.

Bin Width: The value interval of each data category.
