# Sequencer Memory

Modern "high-performance" testers perform composite tests involving a number of different and complex waveforms arranged sequentially such that a number of different tests are performed on the DUT in a "Single Pass" or "One Go" test. Test waveforms of various complexities are generated and arranged sequentially for the purpose of performing multi-parameter tests.

A "Sequencer Program" is an arrangement for the captured (digitized) signal from the DUT relating to the composite contents of the DUT stimulus. Hence for every Set of hardware settings there can be a number of "Sequencer Programs" each containing a sequential arrangement corresponding to the sequential arrangement deployed in the test signal that is applied to the DUT.

Equally, a Sequencer Program can define the sequence of waveforms to be issued to the DUT by an AWG. The individual waveforms are stored in the waveform memory of an AWG.

The "Sequencer Memory" setup window of the Analog Setup Tool allows you to:

- Construct test "Sequencer Programs"
- Review and edit existing "Sequencer Programs"

Additionally, the Analog Setup Tool allows you to perform the following specific tasks:

- Opening, Copying, Searching and Deleting a Sequencer Program
- Editing a Sequencer Program locally
- Editing a Sequencer Program with the pre-configured text editor
- Displaying Waveform Information
- Tracking Sequencer Memory Usage
