# Analog pin editor reference

The digital pin editor contains the following columns:

- Name: The name of the pin.

The name can be up to 16 characters long and must not contain the characters: # ; ( ' ' ) ? @ ,

- No: The number of the pin on the DUT package. Optional.
- Type: The function of the pin:

  - i: DUT input (pins connected to the MCA, MCB, and MCE modules)
  - o: DUT output (pins connected to the MCA, MCB, MCC, and MCE modules)
  - io: DUT input and output

- Instrument: The analog module for the pin:

  - MCA: Multi-site Baseband Analog Source & Measure / Measure
  - MCB: Multi-site BB/VHF Analog Source & Measure / Measure
  - MCC: 6Gig Quad Sampler
  - MCE: Multi-site BB/VHF plus Analog Source & Measure / Measure

- Comment: Any text. Optional.
- Tester Channel: The analog channel that has been wired to the DUT.

For pogo channels, specify five digits:

  - First three digits: The pogo block number (301-332, 401-432)
  - Fourth and fifth digits: The channel number within the block (01-16)

For MCA, MCB, MCC, or MCE modules, specify the slot block used (S1 or S2).
