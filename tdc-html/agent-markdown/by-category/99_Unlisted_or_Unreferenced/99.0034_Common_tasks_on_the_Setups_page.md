# Common tasks on the Setups page

On this page. invalid setup files, which have not been loaded, or do not exist, are highlighted with yellow.

You can perform the following tasks on the [Setups page](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.01.07_Setups_page.md>)

- [Select setup files](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.03_Selecting_setup_files.md>)
- Load the setup files
- Edit the setup files
