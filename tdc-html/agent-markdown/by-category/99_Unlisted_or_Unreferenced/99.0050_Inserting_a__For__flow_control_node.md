# Inserting a "For" flow control node

This is a Flow Control node and represents a conditional branch and loop in the testflow.

It is used as follows: For a certain condition then retest the passing devices but with changed variables

For example, count from 1.. 10:

for(i = 1; i <= 10; i = i+1) then do something; end;)

  ![For Flow Control Node](<../../../raw/120177.png>)

When you insert a flow control node, you must enter, or select, your desired parameters in the dialog window which appears.

"Assign Var":

Here you either select an already defined variable or enter a new one.

Clicking on the slash to the right of the "Assign Var" text box will open a list that contains all the assigned variables defined for the testflow.

"Assign Expr":

Here you assign the initial value by directly giving the value or by giving an expression.

"Condition":

The condition in the flow control nodes is an arithmetic and/or boolean expression which may contain the following operators:

+, -, *, /, >, >=, <, <=, ==, !=, (, ), and, or, not and operands,

路 (<expression>)

路 <var_name>

路 <real_number>

路 "<string>"

路 <string_expression>

Clicking on the slash to the right of the "Condition" text box will open a list that contains all the condition variables defined for the testflow.

Note that the varaibles are preceeded with the symbol @ (see [Flow control nodes](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.02_Flow_control_nodes.md>))

"Increment Var":

The "Increment Var" parameter is an offset value that is used to increment the variable for the next execution of the same test suite within the loop.

Clicking on the slash to the right of the "Increment Var" text box will open a list that contains all the increment variables defined for the testflow.

"Increment Exp":

The "Increment Exp." parameter is an offset value that is used to increment the expression for the next execution of the same test suite within the loop.

"TestNum Inc":

The Test Loop Increment parameter is an offset value that is added to calculate test numbers for two or more sequential executions of the same test suite within a loop.

The loop increment value is multiplied by the number of times the loop has been completed and then added into the final test number calculation. The test loop increment only affects test numbers within the loop and does not change the other test numbers.
