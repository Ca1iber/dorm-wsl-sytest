# Adding a special test suite

Special test suites do not appear as nodes in the Flow Sequence Editor, but in the Flow Data Editor, they are displayed at the end of the Test Suites page when sorting by default.

The seven types of special test suites are described in [Special test suites](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.02_Special_test_suites.md>).

- In this window, select one of the three option buttons according to the executed test type: Test Method, Test Function, or User Procedure.
- Type the test suite name in the Test Suite Name text box.
- Select the test to be executed in the test suite. Selecting a test differs depending on the type of test suite. For details on this, see [Inserting a test suite into the testflow](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.04_Inserting_a_test_suite_into_the_testflow.md>).
- Select the timing setup components, level setup components, and the analog set by clicking on the left of the text box. The descriptions for the setup component are displayed in separate windows.
- Select the pattern.
- Enter the context (see [Context](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18.03.01.01_Context_list.md>))
- Click Finish.
