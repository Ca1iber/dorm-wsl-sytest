# Setting the number of test sites

To set the total number of sites for multisite testing

## Procedure

-  In the Test Program Explorer, right-click the Pin Setting entry of the pin configuration section and choose Define Site.
-  In the Define Site Number dialog, enter the desired number of sites you wish to test.

You can specify any number of sites from 1 to 256.

## Results

Columns for the specified number of sites appear in all pin setting editors.

## What to do next

Specify the test system channels for all sites in the "new site" columns.
