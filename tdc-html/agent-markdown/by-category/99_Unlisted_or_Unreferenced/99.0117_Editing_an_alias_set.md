# Editing an alias set

To add an alias to the set, right-click anywhere and choose Add.

To remove an alias, right-click the row number and choose Delete.

To change the name of an alias, double-click the cell in the Alias column.

To assign a different pin to an alias, double-click the cell in the Pin column.
