# Searching for a test suite

This window only displays the ["Run" and "Run and Branch" test suites](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.01_Run__and__Run_and_Branch__test_suites.md>) in the [Flow Sequence Editor](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.02_Flow_Sequence_Editor.md>).

The [Special test suites](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.02_Special_test_suites.md>) and [Floating test suite](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.03_Floating_test_suite.md>) are excluded.

Select a test suite and then click Go To, it will be highlighted in the Flow Sequence Editor.
