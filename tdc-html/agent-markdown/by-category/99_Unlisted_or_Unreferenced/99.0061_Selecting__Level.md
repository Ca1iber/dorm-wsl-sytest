# Selecting 'Level'

Equation-based level setups (see [Equation based level setup](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.14.02_Equation_based_level_setup.md>)) are preferred because they give you more flexibility by allowing you to use variables for the definition of level resources.

You can use the "Equation" and "Set" filters to display items whose names include the string you type in the filter box. Note that a dot "." is used as a wild card.

More information about termination is given in [Termination mode](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.14.05.01_Termination_mode.md>) and [Active Load](<../02_System_reference/02.07_Test_Method_Reference/02.07.03.02.09.04_Active_Load.md>).
