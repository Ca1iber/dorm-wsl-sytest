# What to consider when assigning a new value node

After you insert a new value node into your testflow, when the testflow passes this node the value you defined in Value will be assigned to the variable name that you have selected.

The variable you assign the value to must have already been defined (see [Defining variables](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.12.01_Defining_variables.md>)).
