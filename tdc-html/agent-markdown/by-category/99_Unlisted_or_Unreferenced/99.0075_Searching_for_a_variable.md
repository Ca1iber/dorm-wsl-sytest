# Searching for a variable

## Procedure

 Select a variable in this window and then click Go To.

- If the variable is used in the [test suite](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01_Test_suites.md>), the related test suite will be highlighted in the [Flow Sequence Editor](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.02_Flow_Sequence_Editor.md>).
- If it is used in the control node ([Flow control nodes](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.02_Flow_control_nodes.md>), [Assign Value node](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.03_Assign_Value_node.md>), [Print nodes](<../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.04_Print_nodes.md>)), the related node is highlighted.
