# Generating failure mode error analyzer reports

Select the enable sites and enabled test suite, click "Analyze Test Program" button and the reports will be generated.

## About this task

To identify a test suite or site which will bring failure to other test suites or sites, Failure Mode Error Analyzer forces fail for each suite and site.

## Before you begin

This module is TP360-Plus module. If you are using "S&S_TP360_Plus_SOC" license, you can use it.

## Procedure

-  Launch SmarTest and import project into the workspace.
-  [Open TP360](<03.13.03_Opening_TP360.md>) and click Failure Mode Error Analyzer from App Center.

The Setup tab of Failure Mode Error Analyzer opens.

-  To select the sites to be analyzed, double-click Select sites for FMEA participation.

Site selection window opens.

-  Select the site number you want to analyze and click OK.

Site selection window is closed.

-  To select the test suites to be analyzed, double-click Select test suites for FMEA participation.

Test suite selection window opens.

-  Select the test suites you want to analyze and click OK.

Test suite selection window is closed.

-  If you want to customize the analysis锛?such as the wait time between each testflow execution, click ![setup icon](<../../../../raw/143086.png>) and configure the reference. See for details.
-  Click Analyze Test Program to begin analyzing.

  - A progress window opens and shows the progress details.
  - The Console view shows any warning and error messages.
  - The Report view displays the analyzing results.

## Results

TP360 compiles an analyze report and displays it in the report view. This report is saved as a file, by default in device_path/TP360_Reports/FMEA_Reports/. To save the report to another desired location, click the Save icon. You can browse this report with Firefox.
