# TP360 3.10.4

The following table summarizes the changes and new features in TP360 3.10.4.

 | Feature  | Description  | More information |
 | Smart Correlation - Release Checker  | You can specify valgrind suppression files to mask known false positives.  | [Preferences for the release check](<03.13.04.07.16_Preferences_for_the_release_check.md>) |
 | You can select to report setups of all DPS pins for thread safe risks.  | [Check level setups](<03.13.04.07.09_Check_level_setups.md>) |
 | You can check the hardware's insufficiency through EDC data.  | [General risks](<03.13.04.07.05_General_risks.md>) |
 | Test Program Browser  | You can view test method libraries and the corresponding revisions.  | [Test method libraries reports](<03.13.04.04.01.08_Test_method_libraries_reports.md>) |
 | Test Program Comparator  | You compare test method libraries' revisions.  | [Comparison reports](<03.13.04.09.03_Comparison_reports.md>)  |
