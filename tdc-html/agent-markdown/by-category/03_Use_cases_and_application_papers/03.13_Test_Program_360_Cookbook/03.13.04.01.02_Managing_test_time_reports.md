# Managing test time reports

To view or delete the test time reports generated or imported with Test Time Utilities, use the Manage Test Time tab on [Test Time Utilities](<03.13.04.01_Test_Time_Utilities.md>).

## Before you begin

You have already:

- [Generated test time reports with Test Time Utilities](<03.13.04.01.01_Measuring_test_time.md>).
- [Imported test time files with Test Time Utilities](<03.13.04.01.03_Importing_test_time_files_to_view.md>).

## Procedure

-  [Open TP360](<03.13.03_Opening_TP360.md>) and launch Test Time Utilities from the App Center tab.
-  Click the Manage Test Time tab.

All the generated and imported test time reports are listed in the order of date and time, as displayed in the following screenshot:

  ![Test time management](<../../../../raw/142993.png>)
-  To view the report of a measurement or a measurement set, expand the generated date and time entries and double-click the measurement name.

The corresponding report is displayed in the Report view.

-  To delete the reports of any date, any time or any measurement, select the corresponding item and click the delete icon ![delete icon](<../../../../raw/143085.png>).
