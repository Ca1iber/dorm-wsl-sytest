# Reviewing report of Test Time Breakdown Analyzer

The following figure shows the layout of the generated test time report:

   ![TestT imeBrAnalyzer._03](<../../../../raw/148528.png>)

This report is divided into three parts:

- Test time analysis reports

Shows the summary report of this analysis. For more details, refer to the following sections:

  - [Test time breakdown based on test action](<03.13.04.11.01.01_Test_time_breakdown_based_on_test_action.md>)
  - [Test time breakdown based on site execution](<03.13.04.11.01.02_Test_time_breakdown_based_on_site_execution.md>)
  - [Highlight code lines with longest test time](<03.13.04.11.01.03_Highlight_code_lines_with_longest_test_time.md>)
  - [Test time summary of focused test actions](<03.13.04.11.01.04_Test_time_summary_of_focused_test_actions.md>)
  - [Timeline of SMC execution](<03.13.04.11.02_Timeline_of_SMC_execution.md>)

- Test time of test suites

Shows the analysis result of each suite. For more details, see [Test time details of code lines](<03.13.04.11.01.05_Test_time_details_of_code_lines.md>).

- Report information

shows general information about this analysis, such as the test program path, testflow name, and enable sites.
