# Executing the measurement

Run the TDR connectivity check and view the report of connectivity.

## Before you begin

Finish [setting up the configuration preferences](<03.13.04.13.02_Setting_up_preferences_for_TDR_measurements.md>).

## Procedure

 Click the Analyze Test Program button.

The TDR measurement starts running. The execution status is shown in the System Output field of the Console tab.

## Results

When the execution is complete, the connectivity check report is displayed at the right of the TP360 window. See [TDR measurement report](<03.13.04.13.04_TDR_measurement_report.md>) for the report details.

## Functional changes

- Introduced in SmarTest 7.6.1
