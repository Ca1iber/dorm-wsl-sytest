# Using the Test Program Cleaner

Test Program Cleaner can find out and clean the redundant files and setups of your test program (device).

## About this task

You can use the Test Program Cleaner when you are preparing to release test programs.

## Before you begin

Make sure:

- You use the license "S&S_tools_package".
- If your test program is UTM based, make sure the source codes can be found by SmarTest.

## Procedure

-  [Open TP360](<03.13.03_Opening_TP360.md>) and launch Test Program Cleaner from the App Center tab.
-  Click the ![setup icon](<../../../../raw/143086.png>) icon to select the clean items. For details, check [Preference page on Test Program Cleaner](<03.13.04.05.03_Preference_page_on_Test_Program_Cleaner.md>).
-  In the Setup tab, click the ![Select directory icon](<../../../../raw/144266.png>) icon to open a testflow selection dialog.
-  Select the device and testflows you want to clean, and click OK.
-  If you want to import the TP360 profile, click the ![Using the Test Program Cleaner (1)](<../../../../raw/149897.png>) icon. See [TP360 Profile](<03.13.04.12_TP360_Profile.md>) for details.
-  If you want to export the TP360 profile, click the ![Using the Test Program Cleaner (2)](<../../../../raw/149898.png>) icon to export the TP360 profile.
-  Click Clean test program to start cleaning your test program.  ![Cleaning_02](<../../../../raw/148544.png>)

## Results

A cleaned device is generated in the directory /tmp/TP360_Cleaned_device or the directory you have specified in the preference page, and a report of this clean is shown in the right report area.

 ![Cleaning_03](<../../../../raw/148545.png>)

## What to do next

After the cleaning process, you can load the cleaned device and compare the setup files before and after cleaning. For further information, see [Programs after cleaning](<03.13.04.05.02_Programs_after_cleaning.md>).
