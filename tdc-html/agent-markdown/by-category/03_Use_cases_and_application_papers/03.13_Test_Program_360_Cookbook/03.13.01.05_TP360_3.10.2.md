# TP360 3.10.2

The following table summarizes the changes and new features in TP360 3.10.2.

 | Feature  | Description  | More information |
 | Smart Correlation - Release Checker  | You can select to show risks types in report view instead of configuring in preference page for Thread Safe Checker.  | |
 | You can select to only show the reports with the keywords in Details pages.  | |
 | You can do filter in Tread Safe Risk Report.  | |
 | You can select and filter the channel or suite in the newly added select view windows.  | |
 | Data Log Utilities  | You can check one-dimension shmoo results.  | |
 | Failure Mode Error Analyzer  | You can check test suites report in execution order.  | |
 | You can check execution rime in the general report.  | |
 | App Center  | You will receive a warning message indicating that your license will be expired in a month.  |   |
