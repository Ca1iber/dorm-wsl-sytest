# Module profile

Module profile is a tar.gz package which stores the configuration of a supported module, for example the Test Program Cleaner. Users can share this package and import it to load the TP360 module profile.

## About this task

There are three modules in TP360 that you can save their configurations in a profile:

- [Test Program Stability Checker](<03.13.04.03_Test_Program_Stability_Checker.md>).
- [Test Program Cleaner](<03.13.04.05_Test_Program_Cleaner.md>).
- [Smart Correlation 鈥?Release Checker](<03.13.04.07.01_Executing_the_Smart_Correlation_release_checker.md>).

## Procedure

-  Open TP360, and launch a module which supports profile.
-  Use "import" to initial the configuration from a tar.gz profile package, or do this configuration manually.
-  Use "export" to export the module鈥檚 configuration to a tar.gz profile package.

## Example

- Taking the [Test Program Cleaner](<03.13.04.05_Test_Program_Cleaner.md>) as an example. Open TP360, Launch Test Program Cleaner.
- Configure Test Program Cleaner by use "import" or manually.
- Click "export" icon to open Export page, and choose "export to the specified directory"
- Choose a tar.gz package, click "finish", and you will get a tar.gz profile package which contains the configuration of Test Program Cleaner. ![Module profile (1)](<../../../../raw/149964.png>)
- (Optional) you can verify the exported profile package by do some changes, then use "import from the specified tar.gz file" to select the profile package you just exported. ![Module profile (2)](<../../../../raw/149965.png>)

This exported tar.gz profile package can be shared between different engineers; they just need to use the import to finish the configuration.

## What to do next

After export the module profile package, you can send it to other engineers so that they can import the profile.
