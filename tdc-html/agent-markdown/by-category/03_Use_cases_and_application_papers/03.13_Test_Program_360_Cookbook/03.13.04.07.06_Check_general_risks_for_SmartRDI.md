Check the general risks for SmarRDI, including the overvoltage or overcurrent programmed to pins, hot-switching on instrument relay, hot-switching on utility or PMUX, illegal connection combination, RDI alarm handling, and general criteria.

 To check the general risks for SmartRDI, you need to set up the preferences, execute the release check, and view the corresponding report. The following items are available to be checked:

- [Overvoltage or overcurrent risk](<03.13.04.07.06.01_Overvoltage_and_overcurrent_risk_report.md>)
- Hot-switching on instrument relay
- Hot-switching on utility or PMUX
- [Illegal connection combination](<03.13.04.07.06.03_Illegal_connection_combination_report.md>)
- [RDI alarm handling risk](<03.13.04.07.06.05_RDI_alarm_handling_risk_report.md>)
- [General criteria](<03.13.04.07.06.07_General_criteria_check_report.md>)
