# Test Program Stability Checker

#### Subtopics

- [Preference pages on Test Program Stability Checker](<03.13.04.03.01_Preference_pages_on_Test_Program_Stability_Checker.md>)
- [The CSV file for checking overvoltage/overcurrent risks](<03.13.04.03.02_The_CSV_file_for_checking_overvoltage_overcurrent_risks.md>)

Test Program Stability Checker helps you to find out programming risks in your test program, for example, hot-switching, and Hi-Z.

## About this task

You can use this tool to check the potential programming risks in your test program.

## Before you begin

Make sure:

- You use the "S&S_tools_package" license.
- Your test program is correct.
- The testflow can be executed successfully.

## Procedure

-  Start SmarTest and load the device.
-  [Open TP360](<03.13.03_Opening_TP360.md>) and launch Test Program Stability Checker on the App Center tab.
-  If you want to customize the options for risk checking, click the ![Step 1: Configure contents to be generated in release report (optional) (3)](<../../../../raw/143004.png>) icon to open a Preference page, on which you can do more configurations about this risk checking.

For details, see [Preference page on Test Program Stability Checker](<03.13.04.03.01_Preference_pages_on_Test_Program_Stability_Checker.md>).

-  Select the risk check item.
-  If you want to import an existing TP360 profile, click the ![Test Program Stability Checker (1)](<../../../../raw/149895.png>) icon.
-  If you want to export current TP360 profile, click the ![Test Program Stability Checker (2)](<../../../../raw/149896.png>) icon.
-  Click Scan Test Program.
-  TP360 starts the analysis of your test program and returns a report on the right.

## Results

An HTML risk report is displayed in the Report view. By default, it is generated in the directory of /tmp/.vda/<host_name>/TPQ/report/.

To save it to a different directory, click ![save as icon](<../../../../raw/143169.png>) in the Report view.

 ![Risk report](<../../../../raw/144391.png>)

In this report:

- The first two columns list the check items you have selected during the setups.

Opening the hyperlinks in the second column, all risks for the associated item are displayed.

  ![StabilityChecker_01](<../../../../raw/148508.png>)
- The third column lists the check results.

The hyperlinks in this column display detailed information about these risks.
