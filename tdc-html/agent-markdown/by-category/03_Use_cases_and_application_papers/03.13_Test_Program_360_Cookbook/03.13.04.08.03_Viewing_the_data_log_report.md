# Viewing the data log report

This task introduces how to view the generated data log report.

## About this task

After executing the report generation process, you can view and save the HTML report in the TP360 report view. You can also use firefox to open the report from the directory you saved report to. The default directory is:

/tmp/.vda/username/datalog_utilities/tmp/TP360_Datalog_Report/

## Procedure

-  View the home page of the data log report.    ![ViewDatalogReport_01](<../../../../raw/148349.png>)
-  In the home page above, click details to view the Test Result Summary.

The test suite name, test name, test number, execution times, fail times, limits, min, max, mean, yield, std dev, cp, cpk are shown in the summary.

  ![ViewDatalogReport_02](<../../../../raw/148350.png>)
-  In the Test Result Summary page, click Global info to view the global information of the data log file.    ![ViewDatalogReport_03](<../../../../raw/148351.png>)
-  In the Test Result Summary page, click Test Detailed Report to view the test result of each device, each site.  ![ViewDatalogReport_04](<../../../../raw/148352.png>)
-  In the Test Result Summary page, click Wafer Map to view the hard bin wafer map and the corresponding fail bin distribution.

You can click the link Soft Bin Wafer Map to view the software bin part:

  ![ViewDatalogReport_05](<../../../../raw/148353.png>)
-  In the Test Result Summary page, click Bin Histogram to view the hardware bin histogram of the whole data log file.

You can click the Soft Bin Histogram link to view the software bin part:

   ![ViewDatalogReport_06](<../../../../raw/148354.png>)
-  In the Test Result Summary page, click Bin Summary or Failure Summary to view the detailed bin distribution information.  ![ViewDatalogReport_07](<../../../../raw/148355.png>)   ![ViewDatalogReport_08](<../../../../raw/148356.png>)
-  If there is shmoo data in the selected data log file, a link named Shmoo info is available in the Test Result Summary page. You can click Shmoo info to view the [shmoo analysis report](<03.13.04.08.04_Viewing_the_shmoo_analysis_report.md>).  Note Shmoo data is only available in EDL with latest SmarTest shmoo test method library. To support shmoo hole information, you need to install the rpm zenith_opencv_2.4.5, which is usually installed before installing Smartest version 7.2.0.0 or above.
