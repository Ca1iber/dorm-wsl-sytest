# Compare Release Reports

Compare the generated release reports to find out the difference between them.

## Before you begin

Make sure:

- You use the "S&S_TP360_Plus_SOC" license.
- You have two release reports generated by [Collect Release Data](<03.13.04.06.01_Collect_Release_Data.md>).

## Procedure

-  [Open TP360](<03.13.03_Opening_TP360.md>) and launch Test Program Browser from the App Center tab.
-  Choose the Compare Release Reports tab.  ![CompareReleaseReports_01](<../../../../raw/148249.png>)
-  Click the ![SelectRuleIcon](<../../../../raw/148242.png>) button in the Specify a release report as reference row.

A dialog opens, in which you can select the reference release report.

-  Click the ![SelectRuleIcon](<../../../../raw/148242.png>) button in the Specify a release report for comparison row.

A a dialog opens in which you can select a comparison release report.

-  If you want to customize the options for report generation, click the ![PreferenceIcon](<../../../../raw/148250.png>) icon to open the [Preference page on Smart Correlation - Release Data Collector](<03.13.04.06.04_Preference_page_of_Smart_Correlation_-_Release_Data_Collector.md>), and then configure the preference setups.
-  Click Compare Release Reports to execute the reports comparison process.

## Results

The Smart Correlation HTML report is generated in the directory /tmp/.vda/username/tpsc/Compare_Report/ and displayed in the report view.

 ![CompareReleaseReports_02](<../../../../raw/148251.png>)

Click Compare Result report to get the details of the differences.

 ![CompareReleaseReports_03](<../../../../raw/148252.png>)

Click Compare resource to get the details of the differences of the hardware resource.

 ![CompareReleaseReports_04](<../../../../raw/148253.png>)
