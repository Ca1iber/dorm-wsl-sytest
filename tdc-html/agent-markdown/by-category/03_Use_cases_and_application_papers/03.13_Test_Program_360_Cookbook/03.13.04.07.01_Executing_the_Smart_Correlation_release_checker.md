# Executing the Smart Correlation release checker

Launch the tool, select the items to be checked, set up the preferences, and execute the check.

## Before you begin

Make sure:

- The S&S_TP360_Plus_SOC license is used.
- SmarTest is launched and the device is loaded.

## Procedure

-  [Open TP360](<03.13.03_Opening_TP360.md>).
-  In the App Center tab, click Smart Correlation - Release Checker.

The Smart Correlation - Release Checker tab opens.

![Release checker interface](<../../../../raw/354150.png>)

-  Click the edit icon ![Edit icon](<../../../../raw/353408.png>) in the Specify testflow file to scan row and follow the onscreen instructions to select the testflow.

The testflow is loaded in the Value column.

If a testflow is open in SmarTest, it is automatically loaded in the Value column.

-  Select the items you want to check for your test program.  Note The items that are marked by the icon ![The SmarTest online session icon](<../../../../raw/354152.png>) in the Min. SMT status column requires that SmarTest is launched in online mode. For other items without this icon, SmarTest in offline mode is enough.   The release check items are divided into various categories based on the purpose of the check. You can:

  - Expand or hide the items under a category.
  - Show the test theory of a check in the Test Theory pane at the right of the TP360 window.

    - Click the name of a category to see the hyperlinks to the test theory of the items in this category.
    - Click the name of a release check item to see the test theory of this check.

-  If you want to add customized check items, [import new customized checkers](<03.13.04.07.03_Customizing_the_release_checker.md>).

The imported checkers are displayed in the check item list. You can select them as other check items.

-  To configure the checks, click the Configure global parameters icon ![Preference icon](<../../../../raw/144338.png>) to open the Preferences window and set up the parameters for specific check items.

For some of the selected check items, you must configure the corresponding preferences before executing the release check. Refer to the instructions of the specific check item for details.

For details of the Preferences window, see [Preferences for the release check](<03.13.04.07.16_Preferences_for_the_release_check.md>).

-  To import the profile, click the ![Import user profile](<../../../../raw/149895.png>) icon.
-  To export the current profile, click the ![Export user profile](<../../../../raw/149896.png>) icon.

See [TP360 Profile](<03.13.04.12_TP360_Profile.md>) for details of the TP360 profile.

-  Click the Scan Test Program button.

The release check starts running. The execution status is shown in the System Output field of the Console tab.

## Results

An HTML report is available in the report view at the right of the TP360 window.
