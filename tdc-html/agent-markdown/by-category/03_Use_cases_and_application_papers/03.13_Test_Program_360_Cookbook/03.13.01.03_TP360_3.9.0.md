# TP360 3.9.0

The following table summarizes the changes and new features in TP360 3.9.0.

 | Feature  | Description  | More information |
 | Smart Correlation - Release Checker  | You can check the overvoltage and overcurrent risks.  | [CSV rule file for checking voltage/current risks](<03.13.04.07.17_CSV_rule_file_for_checking_voltage_current_risks.md>) |
 | You can check connection combination risks.  | [General risks](<03.13.04.07.05_General_risks.md>) |
 | You can check Hot-switching on instrument relay, utility and PMUX. |
 | Failure Mode Error Analyzer  | It is a new module in TP360 and you can use it to identify whether a test interacts across sites incorrectly or unexpectedly.  | [Failure Mode Error Analyzer](<03.13.04.10_Failure_Mode_Error_Analyzer.md>) |
 | Test Program Comparator  | You can compare the setup files in any_directory type.  | [Preference page on Test Program Comparator](<03.13.04.09.01_Preference_page_on_Test_Program_Comparator.md>) |
 | You can see related files and directory comparing in testflow comparison report.  | [Comparison reports](<03.13.04.09.03_Comparison_reports.md>) |
 | Test Time Breakdown Analyzer  | You can check the SmarRDI execution timeline.  | [Test Time Profiling (with SmartRDI)](<03.13.04.11.03_Test_Time_Profiling__with_SmartRDI.md>)  |
