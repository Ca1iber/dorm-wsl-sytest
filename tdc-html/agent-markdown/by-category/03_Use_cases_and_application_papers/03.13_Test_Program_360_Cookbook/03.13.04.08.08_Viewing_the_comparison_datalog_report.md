# Viewing the comparison datalog report

This task introduces how to view the generated comparison data log report.

## About this task

After executing the report generation process, you can view and save the HTML report from the report view. You can also use firefox to open the report from the default report directory or the directory to which you saved the report:

Default directory: /tmp/.vda/username/datalog_utilities/tmp/TP360_Datalog_CMP_Report/

## Before you begin

Make sure:

- You use the "S&S_TP360_Plus_SOC" license.
- You have two valid data log (EDL or STDF) files.

## Procedure

-  The comparison report uses the following color coding:

  - blue - Difference found in row/sub-rows
  - red - Difference in values between first and second columns

You can use the collapse all, hide same setups,and show filter in the report view links to manage the information displayed in the reports.

-  Click diff in the Hard/Soft Bin Wafer Map row to display the overlay wafer map.

  - Green - Bin number of the die is the same. The content in green cells has the "same bin number".
  - Red - Bin number of the die is different. The content in red cell is "reference bin number/comparison bin number". ![ViewCompDatalogReport_08](<../../../../raw/148483.png>)

-  Click bin swap in the Hard Bin Swap row to display the Hard Bin Swap result.  ![ViewCompDatalogReport_09](<../../../../raw/148484.png>)
