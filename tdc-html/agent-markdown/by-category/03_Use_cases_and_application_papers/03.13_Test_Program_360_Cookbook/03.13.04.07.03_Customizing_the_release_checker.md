# Customizing the release checker

#### Subtopics

- [XML file](<03.13.04.07.03.01_XML_file.md>)
- [Perl module file](<03.13.04.07.03.02_Perl_module_file.md>)

Import the XML file defining the check items to add these items to the release checker.

## About this task

In addition to the standard checks in the release checker, you can integrate your own check scripts as custom check items with specified rules. These custom items and their preferences are displayed in the TP360 release checker and the reports are generated as for the other standard check items.

## Before you begin

 Prepare the following files defining custom check items:

- [XML file](<03.13.04.07.03.01_XML_file.md>)
- [Perl module file](<03.13.04.07.03.02_Perl_module_file.md>)

## Procedure

-  [Open TP360](<03.13.03_Opening_TP360.md>).
-  In the App Center tab, click Smart Correlation - Release Checker.
-  Click the edit icon ![Edit icon](<../../../../raw/353408.png>) in the Import new customized checkers row and follow the onscreen instructions to select the XML file defining the custom check items.

In the import window, if you select the Remove checkers that Do not exist in selected XML option, all other customized check items that are not included in the selected XML file will be deleted from the release checker after this XML file is imported.

The check items defined in the imported XML file are displayed under the Customized checker section.

-  If you want to check the preferences of the check item, click the Configure global parameters icon ![Preference icon](<../../../../raw/144338.png>) to open the Preferences window and set up the corresponding parameters under the Customized checker section.
-  If you want to delete a custom checker, click the edit icon ![Edit icon](<../../../../raw/353408.png>) in the Manage existing customized checkers row and deselect the check item in the Manage customized checkers window.

The unchecked check item is deleted from the release checker list.

-  If you want to add a custom checker that has been imported, click the edit icon ![Edit icon](<../../../../raw/353408.png>) in the Manage existing customized checkers row and select the check item in the Manage customized checkers window.

The selected item is displayed in the release checker list.

## Results

The custom check items are added to the release checker. You can select them and run the release check to see the reports.
