# Comparing test time

Using [Test Time Utilities](<03.13.04.01_Test_Time_Utilities.md>), you can compare test time between two test time files.

## About this task

You can compare two of the following test time files:

- Debug mode level 3 file.
- Event data log file.
- csv file dumped from event data log file using the "DRLExecTimes" tool.
- [TP360 test time report](<03.13.04.01.01_Measuring_test_time.md>).

## Procedure

-  [Open TP360](<03.13.03_Opening_TP360.md>) and launch Test Time Utilities from the App Center tab.
-  Click the Manage Test Time tab and select the Compare test time button.  ![Comparing test time](<../../../../raw/142999.png>)

The Compare files(s) window opens:

  ![Select compare sources](<../../../../raw/143000.png>)
-  In this window, select two test time files for comparison.

If you select TP360 report in the Format field, the existing TP360 test time files of the current loaded device are listed in a table as displayed below. In this table, you can select either a measurement set or a measurement for the comparison.

  ![Select a TP360 report](<../../../../raw/143001.png>)

You can also select a TP360 test time file of a different directory by clicking the ![BrowseIcon](<../../../../raw/148326.png>) button as seen in the screenshot above.

-  Click Finish in the Compare files(s) window.

## Results

The comparison report is displayed in the Report view.

 ![Comparing test time (1)](<../../../../raw/149893.png>)

and the details can be viewed in this window as shown in the following:
