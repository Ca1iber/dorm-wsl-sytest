# Defining sample correlation rules

Introduces how to select and edit an existing rule to define a sample correlation.

## About this task

You can define your sample correlation process using the default rules or your customized rules.

## Procedure

-  In the Setup tab of Smart Correlation, click the ![SelectRuleIcon](<../../../../raw/148242.png>) icon to select a rule. Smart Correlation automatically chooses the rule group based on the number of sites of your test program.

Each default rule group has the default rules as shown in the following figure:

  ![SelectRule_01](<../../../../raw/148243.png>)
-  Click Edit Rules to edit the rule in the pop-up window. All items in the Rule Details pane can be edited. You can also clone or delete a rule and change the order of the rules with the corresponding button.  ![SelectRule_02](<../../../../raw/148244.png>)
-  To modify the parameters of a touchdown, expand the rule and highlight the touchdown that you want to change. You can modify the touchdown parameters listed in the right pane.  ![SelectRule_03](<../../../../raw/148245.png>)
-  For each touchdown, you can edit the parameters of each site as shown in the right pane.  ![SelectRule_04](<../../../../raw/148246.png>)
-  If you want to export the modified rule group to an XML file, highlight the rule group, click Export, enter the file name in the pop-up window and click OK.
-  If you want to import an existing rule file, click Import, then select a rule file in the pop-up window, and click ok, the rule in the rule file will be attached at the bottom of rule list.
-  Click Apply to apply the changes to the rule.

## Results

A sample correlation process with your customized parameters is created.
