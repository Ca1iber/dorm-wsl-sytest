# Launching TDR connectivity checker

Launch the tool in TP360 and select the sites for connectivity check.

## Before you begin

Ensure SmarTest is launched online and the DUT board is docked.

## Procedure

-  [Open TP360](<03.13.03_Opening_TP360.md>).
-  In the App Center tab, click TDR Connectivity Checker.

The TDR Connectivity Checker tab opens.

![TDR connectivity checker](<../../../../raw/353822.png>)

-  Click the edit icon ![Edit icon](<../../../../raw/353408.png>) in the Value column of the Specify testflow file to check row and follow the onscreen instructions to select the device and testflow.

If a testflow is open in SmarTest, it is automatically loaded in the Value column.

The testflow is loaded in the Value column, and all sites on the selected device are enabled for execution.

-  To edit the enabled sites for execution, click the edit icon ![Edit icon](<../../../../raw/353408.png>) in the Value column of the Enable site(s) row.

The Enable site(s) window opens.

-  Select the sites for connectivity check and click OK.

## Results

The TDR Connectivity Checker module is launched and the sites for connectivity check are selected. You can now set up the specific parameters for the check.
