On TP360, you can use these function modules to examine your test program:

- [Test Time Utilities](<03.13.04.01_Test_Time_Utilities.md>): Measures and compares test time of your test programs.
- [Executing the test program resource profiler](<03.13.04.02.01_Executing_the_test_program_resource_profiler.md>): Collects the tester, workstation, and SmarTest information when releasing a test program.
- [Test Program Stability Checker](<03.13.04.03_Test_Program_Stability_Checker.md>): Checks programming risks (such as Hi-Z, hot-switching) in your test programs.
- [Test Program Browser](<03.13.04.04_Test_Program_Browser.md>): Generates summary reports for your test program setups and test methods.
- [Test Program Cleaner](<03.13.04.05_Test_Program_Cleaner.md>): Cleans the redundant files and setups in your test program.
- [Smart Correlation –Release Data Collector](<03.13.04.06_Smart_Correlation_-_Release_Data_Collector.md>): Identifies and resolves correlation issues.
- [Smart Correlation –Release Checker](<03.13.04.07.01_Executing_the_Smart_Correlation_release_checker.md>): Performs setups and flow execution related checks for better release quality.
- [Smart Correlation - Datalog Utilities](<03.13.04.08_Smart_Correlation_-_Datalog_Utilities.md>): Reports and compares data log files.
- [Test Program Comparator](<03.13.04.09_Test_Program_Comparator.md>): Compares test programs for you.
- [Test Time Breakdown Analyzer](<03.13.04.11_Test_Time_Breakdown_Analyzer.md>): Calculates the breakdown time in your test suites.
- [TDR connectivity checker](<03.13.04.13_TDR_connectivity_checker.md>): Checks the connection status by measuring propagation delay on electrical trace lines.
 Note TP360 supports sharing the profiles. This is useful to share the TP360 configurations between users, see TP360 profile.
