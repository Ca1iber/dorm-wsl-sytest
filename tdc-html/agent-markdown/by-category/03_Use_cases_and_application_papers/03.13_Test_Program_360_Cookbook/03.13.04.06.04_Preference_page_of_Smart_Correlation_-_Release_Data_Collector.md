# Preference page of Smart Correlation - Release Data Collector

Enables you to customize the process of the Release Data Collector.

## Procedure

-  Open the Preference page by clicking the ![PreferenceIcon](<../../../../raw/148250.png>) icon from the Collect Release Data page or the Compare Release Reports page.  ![PreferencePage](<../../../../raw/148256.png>)
-  Select Generate Excel based reports, if you want to generate reports.

The excel report is placed in the directory: <device_path>/TP360_Reports/ReleaseDatacollector/<testflow_name>_DateStamp/

 Note It is only available for Collect Release Data.
-  Select Arrange test suites if you want to arrange test suites in alphabetical order in the generated report.
-  Click OK to accept the preference selections.
