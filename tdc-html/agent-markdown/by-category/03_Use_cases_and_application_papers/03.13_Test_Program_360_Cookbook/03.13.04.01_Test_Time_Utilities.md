# Test Time Utilities

#### Subtopics

- [Measuring test time](<03.13.04.01.01_Measuring_test_time.md>)
- [Managing test time reports](<03.13.04.01.02_Managing_test_time_reports.md>)
- [Importing test time files to view](<03.13.04.01.03_Importing_test_time_files_to_view.md>)
- [Comparing test time](<03.13.04.01.04_Comparing_test_time.md>)

The Test Time Utilities module supports test time measurement and analysis, which includes:

- Measuring test time and generating test time reports.
- Managing the generated test time reports.
- Importing test time files.

You can import data log files, such as STDF and EDF files, or the generated Test Time Utilities reports.

- Comparing test time.
