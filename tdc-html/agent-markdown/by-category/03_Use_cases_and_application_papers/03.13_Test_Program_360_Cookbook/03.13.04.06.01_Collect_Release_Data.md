# Collect Release Data

To execute a sample correlation process, select and execute an existing rule.

## Before you begin

Make sure:

- You are using SmarTest 6.5.4 version or later.
- You use the "S&S_TP360_Plus_SOC" license.
- The test program is loaded.
- The testflow can be executed.

## Procedure

-  [Open TP360](<03.13.03_Opening_TP360.md>) and launch SmarTest correlation- Release Data Collector form the APP Center tab.
-  To select the correlation process, click the ![SelectRuleIcon](<../../../../raw/148242.png>) icon in the Specify data collection rules for program release row. A dialog opens, in which you can specify the rules. More than one rule can be selected.

For the details of defining the correlation rules, please check [Defining sample correlation rules](<03.13.04.06.02_Defining_sample_correlation_rules.md>).

-  If you want to use the incremental way to collect the release data, click the ![SelectRuleIcon](<../../../../raw/148242.png>) icon in the Specify existing release report for appending row. A dialog opens, in which you can select the report.
-  If you want to customize the options for report generation, click the ![Preference icon](<../../../../raw/144338.png>) icon to open the [Preference page on Smart Correlation - Release Data Collector](<03.13.04.06.04_Preference_page_of_Smart_Correlation_-_Release_Data_Collector.md>), and then configure the preference setups.
-  Click Collect Data and Generate Reports to execute the correlation process.  ![Collect Release Data (1)](<../../../../raw/149900.png>)

After each touchdown, a pop-up window opens to remind you to switch units. Insert the units to the specific sockets following the rule shown in the pop-up window and click Test to execute the next touchdown.

You can re-execute or skip a touchdown by click << or >>, and stop the execution by clicking Exit.

  ![CollectReleaseDataTask](<../../../../raw/148236.png>)

## Results

The Smart Correlation HTML report is generated in the directory <device_path>/TP360_Reports/ReleaseDatacollector/<testflow_name>_DateStamp/, and a hyperlink will be created under the /tmp/.vda/username/tpsc/TPSC_Report/, at last the report will be displayed in the Report view.

The Smart Correlation Excel report is generated in the directory <device_path>/TP360_Reports/ReleaseDatacollector/<testflow_name>_DateStamp/.

 ![CollectReleaseDataTaskResult_01](<../../../../raw/148237.png>)

Click Test Time to open the test time report.

 ![CollectReleaseDataTaskResult_02](<../../../../raw/148238.png>)

Click Test Result Report to view the test result.

 ![CollectReleaseDataTaskResult_03](<../../../../raw/148239.png>)

Click STDF or EDL to save the datalog to a directory of your choice.
