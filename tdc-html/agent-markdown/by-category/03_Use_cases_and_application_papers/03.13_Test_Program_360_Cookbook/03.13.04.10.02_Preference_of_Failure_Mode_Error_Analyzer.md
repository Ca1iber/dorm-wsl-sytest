# Preference of Failure Mode Error Analyzer

You can customize the analysis behavior in the reference window.

 To customize the analysis behavior, click the ![EditIcon](<../../../../raw/148320.png>) and configure the reference settings.

- Alert user if flow loop number is larger than the following value: Enter the quantity of execution you want a warning message to display in order to be warned. Too much execution may take a long time. Zero indicates no warning. Flow loop number = site quantity * test suite quantity.
- Wait time between each tesflow execution: Enter the interval between two sequential testflow to be executed. Too much execution may bring overheat to the board. You can set the interval for the board cooling。/li>
- Pause running if the following keywords of messages occurred in SmarTest UIReport: Enter the keywords in the message of UIReport of SmarTest during executing to display a warning message, for example exeption or error. If some keywords displays in the UIReport, there may be some abnormal which may effect the analyzing result. If you enable this option, once the keywords displays in the UIReport, a warning message will appear and let you to choose whether to continue or not.
