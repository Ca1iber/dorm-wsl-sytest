# Executing the test program resource profiler

Select the desired analysis and generate a detailed report.

## About this task

This report includes the following information:

- Minimum required tester resource of the current test program.
- Minimum required device licenses, such as ppTIA, tmu, loopback and accurate per-pin speed licenses.

However, this tool does not report on the following licenses:

  - Noise figure.
  - Rapid source synch.
  - Jitter injection.
  - Psrf_pa_library.
  - Memory stack.

- The current software information such as SmarTest revision, system controller environment.

This tool supports:

- SmarTest 5.4.3 and later versions on Red Hat 3 and Red Hat 5 (32-bit and 64-bit) operation systems.
- Pin Scale and Smart Scale cards.
- DPS boards and DC Scale: DPS32, DPS128, UHC4 / UHC4T, and VI32.
- Analog boards: MCA, MCB, MCC and MCE.
- RF boards: RF12, RF24.
- Utility blocks.

This tool does not support:

- HSM testers.
- SD testers.

Use the tool when you are going to deliver a test program.

## Before you begin

Make sure:

- You use the "S&S_tools_package" license.
- Your test program is correct and the testflow is executed successfully.

## Procedure

-  In SmarTest, load the testflow and the setups of your test program.
-  [Open TP360](<03.13.03_Opening_TP360.md>).
-  Click Test Program Resource Profiler on the App Center tab.
-  In the Configuration view of TP360, select the items whose information you want to include in the report.    ![Step 1: Configure contents to be generated in the release report](<../../../../raw/143003.png>)

To restore to the default setups, click ![Back to default icon](<../../../../raw/143175.png>) as shown in the screenshot above.

-  (Optional) double-click an item with the ![Step 1: Configure contents to be generated in release report (optional) (3)](<../../../../raw/143004.png>) icon to open the Preference page:  ![Preference page on TP Resource Profiler](<../../../../raw/144397.png>)

On the Preference page:

  - Selecting Generate detailed report for per-pin speed requirement generates a detailed report (can take a long time to complete).

By default, it is not selected.

  - Selecting OK closes this page.

-  In the Test Program Resource Profiler, select Scan Test Program.

The tool starts analyzing your test program to collect the release information for both the tester and the test program.

## Results

A Release Report is available in the Report view. To learn more about the report, see [Test program resource profiler report](<03.13.04.02.02_Test_program_resource_profiler_report.md>).
