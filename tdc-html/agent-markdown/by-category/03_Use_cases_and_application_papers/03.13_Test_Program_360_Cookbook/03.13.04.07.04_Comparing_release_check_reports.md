# Comparing release check reports

Select two release check reports for the same checked items and compare them for identifying the potential risks in the test program.

## About this task

Based on different rule configurations of the release check, different results of the same check item might be generated. By comparing two reports on the same check item, you can analyze the applicability and risk of the settings of the test program.

## Before you begin

Make sure that you have two different release checker reports in which the same items have been checked. See [Executing the Smart Correlation release checker](<03.13.04.07.01_Executing_the_Smart_Correlation_release_checker.md>) for details.

## Procedure

-  [Open TP360](<03.13.03_Opening_TP360.md>).
-  In the App Center tab, click Smart Correlation - Release Checker.
-  Click the Report Compare tab.
![The report compare tab](<../../../../raw/354153.png>)

-  Click the edit icon ![Edit icon](<../../../../raw/353408.png>) in the Select the first TP360 Release checker report for comparison row.

The Please specify a Directory window opens.

-  Follow the onscreen instructions to select the folder of the report generated in a release check.

By default, the reports are saved in the device/TP360_Reports/ReleaseCheck_Reports/ directory.

-  Click the edit icon ![Edit icon](<../../../../raw/353408.png>) in the Select the second TP360 Release checker report for comparison row, and follow the onscreen instructions to select the second report for the comparison. It must have checked the same items as the first report.
-  Click the Compare Report button.

The comparison is performed. A dialog opens showing the progress of the comparison. The status is shown in the System Output field of the Console tab.

## Results

A tab showing the report comparison result is displayed in the report view at the right of the TP360 window.

## What to do next

Check the report comparison result.
