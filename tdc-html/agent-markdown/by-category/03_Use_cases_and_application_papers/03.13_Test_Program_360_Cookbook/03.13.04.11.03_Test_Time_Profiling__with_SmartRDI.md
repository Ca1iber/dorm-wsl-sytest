# Test Time Profiling (with SmartRDI)

#### Subtopics

- [Test Time Profiling Overview](<03.13.04.11.03.01_Test_Time_Profiling_Overview.md>)

Test Time Profiling analyze how the test time is spent between "RDI_BEGIN" and "RDI_END".

## About this task

You can find the test time analysis of setup command, pattern execution and result upload time consuming.

## Procedure

-  Launch SmarTest and import project into the workspace.
-  [Open TP360](<03.13.03_Opening_TP360.md>) and click Test Time Breakdown Analyzer from App Center.

The Setup tab of Test Time Breakdown Analyzer opens.

-  Select Test Time Profiling (with SmartRDI).
-  To select the sites to be analyzed, double-click Enable sites for execution.

Site selection window opens.

-  Select the site number you want to analyze and click OK.

Site selection window is closed.

-  To select the test suites to be analyzed, double-click Select test suites for FMEA participation.

Test suite selection window opens.

-  Select the test suites you want to analyze and click OK.

Test suite selection window is closed.

-  If you want to customize the analysis, click ![setup icon](<../../../../raw/143086.png>) and configure the reference. See [Preference Page on Test Time Breakdown Analyzer](<03.13.04.11.04_Preference_Page_on_Test_Time_Breakdown_Analyzer.md>) for details.
-  Click Analyze Test Time to begin analyzing.

  - A progress window opens and shows the progress details.
  - The Console view shows any warning and error messages.
  - The Report view displays the analyzing results.

## Results

TP360 compiles an analyze report and displays it in the report view. This report is saved as a file, by default in device_path/TP360_Reports/TTM_Reports/. To save the report to another desired location, click the Save icon. You can browse this report with Firefox.
