# Test program resource profiler

#### Subtopics

- [Executing the test program resource profiler](<03.13.04.02.01_Executing_the_test_program_resource_profiler.md>)
- [Test program resource profiler report](<03.13.04.02.02_Test_program_resource_profiler_report.md>)
- [Report for the required resources](<03.13.04.02.03_Report_for_the_required_resources.md>)
- [Report for the resource used when generating reports](<03.13.04.02.04_Report_for_the_resource_used_when_generating_reports.md>)
- [Vector memory usage report](<03.13.04.02.05_Vector_memory_usage_report.md>)

The test program resource profiler generates a report for the hardware resources required by your test program, the hardware resources currently used with your program when generating the report, and the vector memory usage report.

 Three analyzing functions are included in the test program resource profiler:

- Analyze required test resources: Summarizes the minimally required tester resources of the current test program and lists the required licenses. See [Report for the required resources](<03.13.04.02.03_Report_for_the_required_resources.md>) for details.
- Analyze resources used to generate the report: Summarizes the current workstation and tester resources when generating this report. See [Report for the resource used when generating reports](<03.13.04.02.04_Report_for_the_resource_used_when_generating_reports.md>) for details.
- Analyze vector memory usage per signal and per pool: Summarizes the vector memory usage from the signal and memory pool perspective with bar graphs and tables. See [Vector memory usage report](<03.13.04.02.05_Vector_memory_usage_report.md>) for details.

To execute the analysis, perform the steps described in [Executing the test program resource profiler](<03.13.04.02.01_Executing_the_test_program_resource_profiler.md>).
