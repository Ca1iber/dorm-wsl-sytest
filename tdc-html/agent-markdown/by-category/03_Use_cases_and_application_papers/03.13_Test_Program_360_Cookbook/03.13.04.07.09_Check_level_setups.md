# Check level setups

Lets you check level setup related risks.

These risks include:

- Missing/undefined/reduplicate pins in level file.
- DPS setup risk.

## DPS setup risk

For DPS pin of the V93000 platform, when connected, it forces the programmed power supply voltage vout. The current is limited to the connect current limit (ilimit). Current flow driven from DPS that exceeds the DUT's maximum current demand might lead to damage of sensitive devices and customized fixtures, such as probe card tip.

Avoiding risky setup of current limit (ilimit):

- Check the ilimit value of each DPS pin. If the value exceeds the specified value, a warning message may be generated. The user has to double check if the setup is risky or not. If ilimit is too big, it should be adjusted to a suitable value.
