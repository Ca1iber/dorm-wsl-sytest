# TP360 3.10.0

The following table summarizes the changes and new features in TP360 3.10.0.

 | Feature  | Description  | More information |
 | Smart Correlation - Release Checker  | You can add your own check rules for risk checking.  | [Preferences for the release check](<03.13.04.07.16_Preferences_for_the_release_check.md>) |
 | You can check routing tools risks for SmartRDI.  | [Check general risks for SmartRDI](<03.13.04.07.06_Check_general_risks_for_SmartRDI.md>) |
 | Failure Mode Error Analyzer  | You can see waring message if testflow run too many times.  | |
 | You can set wait time between two flows execution.  | [Preference of Failure Mode Error Analyzer](<03.13.04.10.02_Preference_of_Failure_Mode_Error_Analyzer.md>) |
 | You can monitor UIReport and choose to continue or abort if specified keywords occurs. |
 | You can select sites to participate in a rule execution.  | [Generating failure mode error analyzer reports](<03.13.04.10.01_Generating_failure_mode_error_analyzer_reports.md>) |
 | Test Time Breakdown Analyzer  | You can check the SmarRDI event test time report.  | [Test Time Profiling Overview](<03.13.04.11.03.01_Test_Time_Profiling_Overview.md>)  |
