# Check pin setups

Lets you check pin setup related risks.

These risks include:

- No trigger line definition for MCA,MCB,MCC.

## No trigger line definition for MCA,MCB,MCC

This function helps to check missing trigger line definition for MCA,MCB,MCC.

Risk the could happen for HW trigger case:

- No AWG waveform output.
- Read back the previous data left in the DGT memory which is not the expected measurement result.
