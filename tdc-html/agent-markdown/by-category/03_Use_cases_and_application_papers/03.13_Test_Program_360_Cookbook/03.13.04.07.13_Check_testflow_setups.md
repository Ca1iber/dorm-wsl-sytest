# Check testflow setups

Lets you check testflow setup related risks.

These risks include:

- System and flow flags.
- Test suite flags.
- Needless entries, for example, bypassed suites, if(0), and the like.

## System and flow flags

This function checks test flow flags and system flags with your expected value.

You can configure the expected values using an embedded flags rule editor in the preference page.

## Test suite flags

This function checks test suite related flag(s) with your expected value.

You can configure the expected values in the preference page.

## Needless entries

This function checks and reports below needless entries:

- Unused test method links.
- Floating test suites.
- Bypassed test suites.
- Bypassed groups.
- "if(0)" branches.

You can enable or disable checking one or more of these items from the preference page.
