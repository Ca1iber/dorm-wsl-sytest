# How to do disconnect

#### Subtopics

- [Overview of various disconnect methods](<03.04.01_Overview_of_various_disconnect_methods.md>)
- [Avoiding the pass or fail site dependency](<03.04.02_Avoiding_the_pass_or_fail_site_dependency.md>)

This use case illustrates four different disconnect methods provided by SmarTest. It will teach you to choose the appropriate disconnect method in various scenarios.

With the new feature of the special test suite bin_disconnect to do conditional disconnect, you can avoid the pass or fail site dependency behavior in multi-site testing.

 Note On startup SmarTest always performs a standard disconnect.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.2.3: SmarTest startup behavior changed
- SmarTest 7.6.1: Added Multibin SmartDisconnect test suite
