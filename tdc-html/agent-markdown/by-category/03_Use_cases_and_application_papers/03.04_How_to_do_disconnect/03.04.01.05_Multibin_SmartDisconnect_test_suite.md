# Multibin SmartDisconnect test suite

The Multibin SmartDisconnect test suite is a combination of a multibin node and a user defined test suite. Like a multibin node, the Multibin SmartDisconnect test suite is inserted into the fail branch of a Run and Branch test suite. A custom disconnect sequence adapted to the needs of the failed test suite can be implemented using test method APIs or SmartRDI-based code.

Since the Multibin SmartDisconnect test suite covers the functionality of a [multibin node](<../03.02_How_to_do_Multi-Site_Testing/03.02.02.06.07_Use_of_multibins.md>) as well as user defined disconnect sequences it is easier to handle:

- Test method APIs and [SmartRDI](<../../02_System_reference/02.07_Test_Method_Reference/02.07.13_SmartRDI.md>) based code are supported.
- Individual test method classes are supported.
- Each of these test method classes needs to cover only the disconnect sequence for the related Run and Branch test suite.

For more information, refer to [Multibin SmartDisconnect test suite](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.04_Multibin_SmartDisconnect_test_suite.md>) in the [System reference](<../../02_System_reference/02_System_reference.md>).
