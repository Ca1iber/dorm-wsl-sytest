# SmarTest 7 dependencies between static and dynamic access

Static access to utility lines is defined as parallel read/write using test method APIs or firmware commands. Dynamic access to utility lines is defined as serial read/write using the serial interface of utility pogo blocks which has to be set up and stimulated by a user‑defined pattern. Dynamic access must be enabled using test method APIs or firmware commands.

 Note This section applies to V93000 Pin Scale and Smart Scale systems running SmarTest 7.

For the utility blocks that have been configured with the [UTILITY_SEQ_POGO_MODE](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.265.01_UTILITY_SEQ_POGO_MODE.md>) test method API in RW mode it is not possible to set the utility line state via static access (see [FLEX_UTILITY_RELAY](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.68.02_FLEX_UTILITY_RELAY.md>) test method AP). You must disable dynamic access inside the test method first. Refer to the table below for details.
