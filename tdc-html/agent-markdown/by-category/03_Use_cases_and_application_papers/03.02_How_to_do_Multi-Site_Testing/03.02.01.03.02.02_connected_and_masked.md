# connected and masked

The connected and masked state applies if certain sites must be tested one after the other or while a branch must wait for another branch to finish.

A site of this state receives the same vectors as all other sites. The results, however, are ignored (receivers are masked).

## Functional changes

- Introduced before SmarTest 6.3.2
