This chapter deals with embedding user procedures into a multisite testflow, and how to use the CI library, TPI functions and Firmware commands in a multisite setup.

 Note To use a library generated on 32-bit system for a 64-bit system or vice versa, you need recompile the source code to generate the library for the new system. Note User procedures are described here for legacy systems. They should now be replaced by Test Methods.
