# Binning

If a site fails and gets binned (that is, disconnected) during testflow execution, it will no longer receive data or deliver results. Other sites will no longer wait on sites that have been binned. During the disconnect sequence, all other sites are briefly set to SQST OFF (sequencer state OFF). This can cause a device to lose the state acquired during the previous test. For details and solutions to this problem, see [Self-contained Testsuites](<03.02.02.06.05_Self-contained_Testsuites.md>) and [Non Self-contained Testsuites](<03.02.05.01_Porting_Non_Self-contained_Testsuites.md>).
