# PACT, PACT? - (Parallel ACTivities control)

The PACT command allows you to mask or activate specific sites. It is used by the Site Control window, and also during testflow execution if the test suite is requested to run serially, or if after a branch, some sites follow a different execution path.

Note that every execution of the PACT command resets the results of all sites, even if only one site is specified in the command.

The PACT? query returns the current status of the sites.

Note This command implements the tpi interface for multisite testing. Use the tpi call instead of this firmware command.

## PACT

PACT {control}, {site|ALL}

PACT {"site_string"}

## PACT?

```
PACT?
```

returns

```
PACT {control}, {site}
```

Or:

```
PACT?STR
```

returns

```
PACT {"site_string"}
```

## Parameters

 |

control

 |

The control parameter is:

 |
 |

 |

ACTIVE

 |

When a site is ACTIVE it receives all test data, and generates results for the tests.

 |
 |

 |

MASKED

 |

When a site is MASKED, it receives all test data, as with the ACTIVE parameter. However, the receivers for the site are disabled and no result information is available.

 |
 |

site

 |

A single integer representing a site number.

 |
 |

site_string

 |

A string consisting of "0" and "1". One character must be given for every site that is configured in the pin configuration. "0" indicates that the respective site is (to be) masked. "1" indicates that the respective site is (to be) activated.

 |
 |

ALL

 |

means that all configured sites that are available for testing (that is, do not use a channel that is inactivated in the MCDIgnore file) are to be activated or masked.

For the MCDIgnore file see MCDIgnore usage and restrictions in Service Guide Part 1.

 |
 |

STR

 |

forces the query to return a site string instead of a single line for every site.

 |

## Application

Site Control window.

## Warnings

If a site is unavailable, PACT will issue a warning.

## Errors

An error is generated if not all pins at the site have had their channels assigned by the [PALS](<../../02_System_reference/02.06_Command_Reference/02.06.02.02.173_PALS__PALS__-__Pin_ALlocation_for_multiple_Sites.md>) command.

## Example

```
> PACT ACTIVE, 1
> PACT MASKED, 2
> PACT MASKED, 3
```

This example masks site 2 and site 3, and makes site 1 active.

```
> PACT?
< PACT ACTIVE,1
< PACT MASKED,2
< PACT MASKED,3
> PACT? STR
< PACT "100"
```

This example shows the impact of the optional STR parameter for the query.
