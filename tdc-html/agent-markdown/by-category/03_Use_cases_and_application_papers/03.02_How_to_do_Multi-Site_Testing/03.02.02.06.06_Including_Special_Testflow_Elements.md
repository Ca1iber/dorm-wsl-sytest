# Including Special Testflow Elements

#### Subtopics

- [Download Testsuite](<03.02.02.06.06.01_Download_Testsuite.md>)
- [Assignment of User Variables](<03.02.02.06.06.02_Assignment_of_User_Variables.md>)
- [Assignment of Timing and Level Values by Equations](<03.02.02.06.06.03_Assignment_of_Timing_and_Level_Values_by_Equations.md>)

In addition to the regular test suites (containing User Procedures or Test Method Programs), there are some more items of special importance for multisite testing:

- the Download test suite
- the assignment of User Variables
- the assignment of Timing and Level values by Equations
- the use of Bins
  Note Do not throw any exceptions from inside special test suites, as the handling is not compatible with the testflow executor.

## Functional changes

- Introduced before SmarTest 6.3.2
