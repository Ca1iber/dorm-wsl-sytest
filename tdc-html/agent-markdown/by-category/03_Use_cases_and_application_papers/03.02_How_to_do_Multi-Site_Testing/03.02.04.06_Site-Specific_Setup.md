# Site-Specific Setup

#### Subtopics

- [Controlling the Setup/Query-Focus Automatically](<03.02.04.06.01_Controlling_the_Setup_Query-Focus_Automatically.md>)
- [Controlling the Setup-Focus Manually](<03.02.04.06.02_Controlling_the_Setup-Focus_Manually.md>)

Different setup data can be created for each site independently. The following setup parameters are valid for site-specific setup:

- Level spec value
- Timing spec value
- All setup parameters of AWG
- All setup parameters of digitizer/sampler
- All setup parameters of TIA
- All setup parameters of Digital Capture

To achieve the site-specific setup, use the following APIs in the first-invocation block.

- Primary.getLevelSpec().change(param)
- Primary.getLevelSpec().restore()
- Primary.getTimingSpec().change(param)
- Primary.getTimingSpec().restore()
- Analog.AWG(pin).setup_function(param)
- Analog.DGT(pin).setup_function(param)
- Analog.TIA(pin).setup_function(param)
- Vector(variable).setup_function(param)

Where, setup_function means the member functions for setting the given parameter.

The setup-focus state is for performing the site-specific setup, and the `query-focus` state is for performing the site-specific retrieve.

There are two approaches for site-specified setup, as follows:

- [Controlling the Setup/Query-Focus ](<../../02_System_reference/02.07_Test_Method_Reference/02.07.03.13.03.01_Controlling_the_Setup_Query-Focus_Automatically.md>)[Automatically](<../../02_System_reference/02.07_Test_Method_Reference/02.07.03.13.03.01_Controlling_the_Setup_Query-Focus_Automatically.md>)
