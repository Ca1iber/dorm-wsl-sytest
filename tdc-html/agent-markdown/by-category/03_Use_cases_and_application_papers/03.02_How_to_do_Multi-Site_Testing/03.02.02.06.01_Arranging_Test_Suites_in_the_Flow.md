# Arranging Test Suites in the Flow

Within a testflow you do not have to distinguish between different sites - the V93000 manages different sites automatically, letting you set up the testflow as you would for a single site.

However, there are a few aspects you should keep in mind to achieve truly parallel execution - and thus achieve maximum performance. Also, there are some essential testflow elements which must be included for multisite testing. These elements are discussed in [Including Special Testflow Elements](<03.02.02.06.06_Including_Special_Testflow_Elements.md>).

Testsuite Flags, Testflow Flags and System Flags apply to all sites. OOC Rules also apply to all sites, but the system evaluates them for each site individually.

## Functional changes

- Introduced before SmarTest 6.3.2
