# How to do Multi-Site Testing

#### Subtopics

- [Introduction to Multisite Testing](<03.02.01_Introduction_to_Multisite_Testing.md>)
- [Developing a Multisite Test](<03.02.02_Developing_a_Multisite_Test.md>)
- [User Procedures](<03.02.03_User_Procedures.md>)
- [Multisite Test Method Programming](<03.02.04_Multisite_Test_Method_Programming.md>)
- [Application Specific Multisite](<03.02.05_Application_Specific_Multisite.md>)

By running a multi-site test on the SOC Series you can test multiple[1)](<#fntarg_1>) identical devices on one DUT board. All devices are tested simultaneously, thus reducing the overall testing time to a fraction.

You can also make optimum use of your test system's resources when testing devices with fewer pins than the number of channels your test system provides (mixed test floor). The more devices you have to test, the more beneficial multi-site testing becomes.
