# Considerations

As the site match flag is set to OFF for these tests, if a no match condition occurs for one of the sites within the time set up with the SQTO command (see [SQTO, SQTO? - (SeQuencer TimeOut)](<../../02_System_reference/02.06_Command_Reference/02.06.02.02.242_SQTO__SQTO__-__SeQuencer_TimeOut.md>)), a sequencer timeout is produced.

If a sequencer timeout occurs in one site, then all sites will be stopped. This is a global condition, and so you do not know which site actually failed.

The following sections outline how to work around this and other problems.
