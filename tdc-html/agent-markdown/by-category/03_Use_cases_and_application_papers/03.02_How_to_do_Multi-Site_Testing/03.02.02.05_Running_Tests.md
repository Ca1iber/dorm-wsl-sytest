# Running Tests

#### Subtopics

- [Changing the site in focus](<03.02.02.05.01_Changing_the_site_in_focus.md>)

Running tests in an engineering environment is very much the same as with single-site testing. You must, however, use the Site Control to select the Sites you wish to run your test for:

- Load the appropriate setup files.
- Open the testflow.
- Open the Site Control (see, [Site Control Window](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.27_Site_Control_Window.md>)) and select the Sites to be tested. Check the active boxes (this automatically also checks the enable boxes).
- Run the test suite.
- Open one of the result tools, like the Error Map for example, for further analysis.

The result tools always display the results of the Site in focus. To show the results of another Site, see the section [Changing the site in focus](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.27.03_Changing_the_site_in_focus.md>).
