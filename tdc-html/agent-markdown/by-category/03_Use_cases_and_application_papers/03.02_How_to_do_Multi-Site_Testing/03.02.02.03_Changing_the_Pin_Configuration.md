# Changing the Pin Configuration

Changing the pin configuration from a single-site setup to a multisite setup involves two steps:

- Defining additional test sites
- Allocating the test system channels for the additional sites.

This is described in [Defining additional test sites](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18.02.07.04_Defining_additional_test_sites.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
