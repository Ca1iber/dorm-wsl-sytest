# Selecting the sites to run your test

For multisite testing, you can use the Site Control window to select the sites you wish to run your test.

## Before you begin

Make sure that primary sets and the testflow have been defined.

## Procedure

-  In the SmarTest Work Center, click the menu 93000 > System > Site Control.
-  The Site Control window appears.

  - For the required sites, check the active check boxes. This automatically also checks the enable check boxes.
  - For the unrequired sites, uncheck the enable check boxes. This automatically also unchecks the active check boxes.

-  Execute the testflow.

## Results

During the execution of the testflow, sites are activated and deactivated automatically. The result tools always display the results of the site in focus.

## What to do next

Open the result tools for further analysis.
