# Use of SMC_TEST() with multibin

The topic describes the binning rule and the main use cases using [SMC_TEST()](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.231.45_SMC_TEST.md>) and its influence on the multibin.

For using it together with TESTSET objects, see [Use of TESTSET and SMC_TEST() test suites with multibin](<03.02.02.06.07.03_Use_of_TESTSET_and_SMC_TEST___test_suites_with_multibin.md>).

 Note

If you use TESTSET within the [SMC framework](<../../02_System_reference/02.07_Test_Method_Reference/02.07.10_SmartCalc_framework.md>) instead of [SMC_TEST](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.231.45_SMC_TEST.md>), binning happens in [SMC_SYCHRONIZE](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.231.43_SMC_SYNCHRONIZE.md>) according to the binning rules as for SMC_TEST. For details, see the examples below.

If you use, within a testflow, the [SMC framework](<../../02_System_reference/02.07_Test_Method_Reference/02.07.10_SmartCalc_framework.md>) and TESTSET test suites independent of each other, binning happens according to the binning rules explained in [Use of TESTSET and SMC_TEST() test suites with multibin](<03.02.02.06.07.03_Use_of_TESTSET_and_SMC_TEST___test_suites_with_multibin.md>).

The first failing test defines the multibin, which will be logged in [SMC_SYNCHRONIZE()](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.231.43_SMC_SYNCHRONIZE.md>).

## Examples

### Example 1: Single SMC test

The first failing test of SMC_TEST_5 logs to the multibin.

 |    ![Use of SMC_TEST()](<../../../../raw/145110.png>) |

Code snippet from SMC_TEST_5:

```
Virtual void run()
{
    SMC_TEST("cx0","test",V93kLimits::tmLimits,0,true);
    SMC_TEST("cx1","test",V93kLimits::tmLimits,0,true);

    return;
}
```

If both tests fail, the first one (failing cx0) will be logged into the multibin.

 |

### Example 2: Multiple SMC tests

The first failing test of `SMC_TEST_5` and `SMC_TEST_6` logs to the multibin.

 |   ![Flow Sequence Editor_Multiple use of SMC_TEST()](<../../../../raw/145111.png>) |

If all tests fail, the first one of `SMC_TEST_5` will be logged into the multibin.

If all tests of `SMC_TEST_5` pass, the first one of `SMC_TEST_6` will be logged into the multibin.

 |
