# Controlling the Setup-Focus Manually

In addition to auto-controlling the setup/query-focus state of sites, you can also control the state of setup-focus by using the following APIs. The first two APIs specify which sites are addressed by Setup APIs which follow, for performing the site-specific setup.

- [SET_TEST_FOCUS()](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.218_SET_TEST_FOCUS.md>)

Sets the specified sites in the currently-enabled sites to setup-focus state. This can also set all enabled sites except for the specified site to not setup-focus state simultaneously.

- [UNSET_TEST_FOCUS()](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.261_UNSET_TEST_FOCUS.md>)

Sets the specified site in the currently setup-focused sites to not setup-focus state.

- [GET_TEST_FOCUS()](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.97_GET_TEST_FOCUS.md>)

Returns the number of the setup-focused sites and the site numbers.

These APIs are meaningful in the first-invocation block except for the each site loop blocks.

Changes in setup-focus state by SET_TEST_FOCUS and UNSET_TEST_FOCUS APIs are canceled automatically when the execution of the test method program finishes in the test suite.

 Note Setting the test focus by SET_TEST_FOCUS() and UNSET_TEST_FOCUS() is supported for a limited selection of other APIs. Supported APIs are Primary.getLevelSpec(), Primary.getTimingSpec(), Analog.AWG(), Analog.DGT(), Analog.TIA(), and Vector(). For detailed information refer to [Site-Specific Setup](<../../02_System_reference/02.07_Test_Method_Reference/02.07.03.13.03_Site-Specific_Setup.md>). The "each site loop block" or the "semi-parallel testing block" are to be used to manually control the setup focus or the query focus for other APIs. For more information refer to [Controlling Multiple Sites](<../../02_System_reference/02.07_Test_Method_Reference/02.07.03.13_Controlling_Multiple_Sites.md>).

## Examples

### Example 1: Get, change, and restore the setup focus of a site

```
ARRAY_I sites;
...
...
ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Get the site numbers of the currently setup-focused
    // sites and store them into the sites array.
    //
    GET_TEST_FOCUS(sites);

    //
    // Enable the setup focus on site 1.
    // Disable the setup focus on all other sites.
    //
    // Note: The setup focus for all other sites is disabled
    //       because the optional parameter "exclusive" is omitted.
    //       The default value = true is applied.
    //
    SET_TEST_FOCUS(1);

    //
    // Apply changes only to site 1.
    //
    AWG("ain").vOffset(5.0 V);

    FLUSH();

    ...
    ...

    //
    // Restores the state of all enabled sites to the original
    // state by using the contents of the sites array.
    //
    SET_TEST_FOCUS(sites);
}
ON_FIRST_INVOCATION_END();
```

### Example 2: Print list of setup-focused sites

```
ARRAY_I sites;
...
...
ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Get the site numbers of the currently setup-focused
    // sites and store them into the sites array.
    //
    GET_TEST_FOCUS(sites);

    //
    // Print the size and the contents of the sites array
    //
    cout << endl;
    cout << sites.size() << " sites are setup-focused:" << endl;
    cout << endl;

    for (int index = 0; index < sites.size(); index++)
    {
        cout << "\tSite " << sites[index] << " is setup-focused" << endl;
    }

    cout << endl;
}
ON_FIRST_INVOCATION_END();
```
