# Exact Triggering with Shared Resources

As mentioned in the previous section ([Site Match Disabled with Shared Resources](<03.02.05.02.03_Site_Match_Disabled_with_Shared_Resources.md>)), when using match loops exact triggering using shared pins is normally only possible if you set the site match flag to "OFF".

This means that the judgment on whether a match has been obtained will be based on the compare results of all active sites, so that if the match loop fails on one single site, the test will be canceled for all sites even if a match is found for all the remaining sites.
