# Novel Eye Pattern Test Method by Waveform Sampler

Hideo Okawara, Verigy

Paper ID: 107575

## Abstract

A waveform sampler is a measurement instrument used to capture extremely high-speed or high frequency signals. It can do waveform and signal spectrum analysis. The target signal is often a repetitive signal such as a clock. The signal discussed in this paper is a pseudo random binary sequence (PRBS) so it is important to carefully set up a test plan to get successful results. The purpose of the paper is to introduce an easy procedure to capture a PRBS with the 6Gig Quad Sampler (E9726), and describes a method to reconstruct and evaluate an eye pattern. Experiments are provided using a 2.5 Gbps 127-bit PRBS data stream generated by Pin Scale 3600 digital pin drivers. In conclusion, the proposed procedure works effectively and gives satisfactory results.

## Introduction

## Sampler

A waveform sampler is a kind of waveform digitizer integrated into mixed-signal SOC testers. The sampling frequency of the 6Gig Quad Sampler (E9726) option for the V93000 SOC Test System is 20 Msps to 110 Msps. The benefit of this sampler is that it has a very wide analog input bandwidth so it can measure high-speed/high-frequency signals using an under-sampling technique. The sampler has a 6 GHz input bandwidth at the -3 dB point. Actually, it can deal with signals up to 10 GHz. Test conditions must be set up for strict coherency so the sampler can reconstruct a replica of waveform in the baseband. This is the process by which samplers can test very high-speed digital signals and very high frequency analog signals.

## Eye Pattern

In data communication systems, binary or multiple-level digital data is transmitted through transmission lines, which have limited analog bandwidth causing the signals to deteriorate and waveforms to become distorted. An eye pattern is a typical method to evaluate digital signal integrity (Figure 1). An open eye pattern corresponds to minimal signal distortion. Distortion of the waveform due to inter-symbol interference and noise causes the eye pattern to close [1]. Data error relates directly to the eye opening at the decision timing point. Therefore, eye pattern measurement is very useful to test the quality of transmission lines and transmitters. The wider the frequency bandwidth a system has, the more the eye opens. It is one of the indicators of system performance.

Using a digital tester, an eye pattern is created by sweeping the compare threshold voltage against the compare edge timing of a digital channel. By sweeping the threshold level and timing, digital pins give pass/fail results according to the match or mismatch to the expected data. The boarder lines of the pass/fail transition construct an eye opening. Since creation of an eye pattern requires running the functional test a huge number of times, the test time can be very long.

 ![Eye Pattern](<../../../../raw/107578.png>)

For eye pattern measurements, a PRBS is applied which appears as a random signal. Therefore, a sampler may not seem to be a suitable measurement instrument. However, by setting up a precise coherent condition, a sampler can reconstruct an eye pattern from a PRBS. This paper introduces a method to set up a coherent condition for reconstructing an eye pattern. It also introduces methods to test the eye using an eye mask and to calculate jitter.

## Sampler Conditioning

## Under-sampling

In order to discuss the sampling condition, the following parameters are defined:

- Test signal frequency: Ft
- Sampling frequency: Fs
- Number of sampling points: N (integer)
- Number of test signal cycles: M (integer)
- Aliased bin number: Mx (integer)
- Zone number: K (integer)

Figure 2 depicts a frequency spectrum in which a test signal, Ft, is under-sampled with a sampling frequency, Fs, using N points of data:

 ![Under-sampling: Frequency Domain](<../../../../raw/107580.png>)

The coherent condition is expressed with the following equation (1):

![Novel Eye Pattern Test Method by Waveform Sampler (1)](<../../../../raw/107614.png>) ( -N/2 < Mx < N/2 ) (1)

If the combination of Ft and Fs is well controlled relative to the integer ratio of M and N, the test signal located at bin number M is aliased to bin number Mx in the baseband. In this case, M and N should have no common divisor. Figure 3 depicts the process in which a single cycle of the test signal waveform is under-sampled with N=16 points of data and reconstructed. In this example, M/N = 33/16, K = 2 and Mx = 1.

 ![Under-sampling: Time Domain](<../../../../raw/107582.png>)

The test signal waveform is smoothly swept along the trace and captured. Then a single cycle of the waveform is reconstructed as shown in Figure 3 (b) automatically. Mx = 1 is the key of this condition.

## Coherent Conditioning

In digitizer/sampler applications, reshuffling is one of the important data processing techniques. Figure 4 depicts five cycles of a sine waveform sampled with 16 points. Every sampling point is numbered sequentially as shown in Figure 4 (a):

 ![Reshuffling and Reconstruction](<../../../../raw/107584.png>)

Five (cycles) and 16 (points) have no common divisor, so that each sampling point represents a different phase of the sine wave. Each point can then be sorted into phase order. Consequently a single cycle of the sine wave can be reconstructed as shown in Figure 4 (b) [2]. This operation is provided as an Application Programming Interface (API) command in SmarTest, DSP_SHUFFLE() [3].

 ![Reshuffling of 2 loops of 9-bit - Simulation](<../../../../raw/107587.png>)

Figure 5 (a) shows a simulated waveform captured by a sampler. There are 64 points of data including two loops of the nine-bit sequence "101100110". Nine (bits) and 64 (points) have no common divisor. The sample timing smoothly sweeps along the whole trace. Each point is numbered according to its captured order. Two loops of the bit sequence are used to create the two-bit period eye pattern shown here. When capturing the 18-bit waveform, by reshuffling the waveform with a factor of nine (not 18) a good-looking eye pattern can be reconstructed as Figure 5 (b) shows. This strategy is the key of this paper.

In Figure 5 (b), reshuffled data points are connected with the green lines on the basis of standing order. However, the lines are not meaningful so this makes analysis of the eye pattern difficult. By casting a glance, we can easily recognize it as an eye pattern, however, a computer cannot. Another point of this paper is to provide guidance for data processing in this situation.

## Experimental Results

## Test Configuration and Conditioning

Experiments are performed using the V93000 SOC Test System. Figure 6 shows the configuration. A pair of Pin Scale 3600 digital channels generates a 127-bit PRBS in differential mode. The PRBS test signal runs at a speed of 2.5 Gbps. In order to create two-bit period eye pattern, two loops of the PRBS (a total 254 bits) are observed as a whole waveform.

## Coherency Calculator

In a sampler application, precise conditioning is the key to get a successful result. The coherency calculator shown in Figure 7 [4] is a handy tool to aide in this programming. The essence of the tool is Equation (1) containing six parameters: M, Mx, K, N, Ft, and Fs. First, when you enter Fs = 2.5 GHz, N = 254 (bits) and M = 1 (cycle) in the top part of the tool, it derives a precise value of Ft (9.8425...MHz) based on Equation (1). Second, when you enter a target sampling frequency which is slightly less than Ft, such as 9.8 MHz, N = 65536 and Mx = 1, it derives a precise value of Fs (9.8423695...MHz) based on Equation (1). The minimum Fs of the 6Gig Quad Sampler is 20 MHz so the tool is capable of telling you the true sampling frequency and the inter-discard number which is necessary for the actual analog setup of the 6Gig Quad Sampler. The coherent sampling condition is not unique. You can select a different sampling frequency. The coherency calculator helps you resolve the coherency equation.

## Data Processing for Eye Pattern

Using the condition calculated in Figure 7, the sampler captures an entire waveform of 254 bits in 65536 points, which is plotted using dots as shown in Figure 8. There are two loops of the 127-bit PRBS in there.

 ![Captured Waveform 254 bits](<../../../../raw/107607.png>)

The raw data is processed with the following steps to create an eye pattern which can be tested against a mask. The jitter can also be calculated.

- Reshuffle to create the primitive eye pattern.
- Perform histogram analysis to find the high and low voltage decision points.
- Detect the eye edges so the eye can be centered.
- Use a discrete Fourier transform for eye centering.
- Perform an eye mask test.
- Perform a jitter calculation from the eye edge data distribution.

Using DSP_SHUFFLE() with a key of 127 (not 254), The raw waveform from Figure 8 is reconstructed as a primitive eye pattern as shown in Figure 9. In reality the eye location changes from time to time. We can easily recognize the eye opening wherever it resides. However, for computer analysis, the eye location should be adjusted so that it resides in the center of the display.

 ![Reconstructed Primitive Eye Pattern](<../../../../raw/107608.png>)

First, in order to normalize the vertical axis, histogram analysis is applied to the voltage as shown in Figure 10. The minimum and maximum points (Vmin and Vmax) in the primitive eye can be found by taking 1000 slices between Vmin and Vmax. The histogram peaks select the logical 0/1 levels (Vlow and Vhigh).

 ![Level Histogram](<../../../../raw/107609.png>)

Second, as Figure 11 (a) shows, the primitive eye is sliced at the 49% and 51% levels of the voltage span (Vhigh - Vlow). The levels of 49% and 51% were decided through online debug, looking at the captured eye pattern. A dummy 0/1 array is created, and marked when the data points reside between the thresholds. This is an indicator of the edge locations as shown in Figure 11 (b). When the eye is correctly centered, the indicator appears as the square wave as shown in Figure 11 (c). This is the expected location. A technique for finding the eye location is to use a fast Fourier transform (FFT). Applying the FFT to the expected indicator (c), the phase of the second bin (of the two-cycle sine wave in (c)) is 蟺 [radian], which is the target phase. The phase difference between the second bin of the indicator signal and 蟺 [radian] can be interpreted into how many points the eye should be shifted.

 ![Eye Location Search](<../../../../raw/107610.png>)

## Jitter Calculation

Adjusting the primitive location, the eye pattern is centered as Figure 12 shows. Then the eye opening can be analyzed in a systematic manner. First, it is tested with an eye mask.

 ![Eye Pattern Centered](<../../../../raw/107611.png>)

Figure 13 shows the eye mask test. A hexagonal eye mask starts from P0, going through P1, P2, P3, P4, P5 and closes at P0. The data points located from addresses at 1/4 of x-axis (16384) to 3/4 of x-axis (49152) are tested to see that they do not invade the hexagonal area. For instance, the point located at address 2200 is tested to see if it resides above the P0-P1 line or below the P0-P5 line. This is the process by which the eye mask is tested.

 ![Eye Mask Test](<../../../../raw/107612.png>)  ![Jitter: Edge Data Distribution](<../../../../raw/107615.png>)

As Figure 14 shows, by counting up scattered data points residing between the thresholds of 49% and 51% at either edge, peak-to-peak jitter and RMS jitter can be calculated using a statistical method as shown in Figure 14 (b) and (c).

This is the whole process of reconstructing the eye pattern, testing it using an eye mask and calculating the jitter by employing the 6Gig Quad Sampler (E9726).

## Conclusions

A waveform sampler usually takes a repetitive signal such as a clock for an input. Since a PRBS is used in eye pattern measurement, it is not easy for test engineers to set up the correct under-sampling condition. The data processing for an eye pattern using a waveform sampler has been described step by step.

Coherent conditioning is the key to successful measurement when using a sampler/digitizer. The "Coherency Calculator" is introduced to aide in planning a coherent test condition. It is very handy; especially for under-sampling conditions in sampler applications.

The experimental result is demonstrated using the 6Gig Quad Sampler (E9726) using a 2.5 Gbps 127-bit PRBS generated by Pin Scale 3600 digital channels. The point is to capture whole waveform using two loops of the PRBS in a smooth swept sampling mode.

A primitive eye pattern is reconstructed using the reshuffling API. Centering of the primitive eye makes it possible to do a computerized mask test and jitter calculation. A level histogram derives the logical voltage high and low, and then an FFT method is applied to center the eye pattern.

Once the eye is relocated in the center, it can be tested against an eye mask, and a jitter calculation can be achieved by picking the mid range data points and performing statistical analysis.
