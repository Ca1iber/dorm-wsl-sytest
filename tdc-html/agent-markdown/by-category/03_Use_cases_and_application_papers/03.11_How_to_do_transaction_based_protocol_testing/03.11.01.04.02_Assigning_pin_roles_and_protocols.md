# Assigning pin roles and protocols

## About this task

This task describes how to assign a protocol to a port and a resource pin to a pin role of the corresponding protocol.

This way the pin roles of your protocol used for transactions are linked to resource (hardware) pins of the V93000 test system.

## Before you begin

Ensure you have defined the ports you require as described in [Working with ports](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18.02.09_Working_with_ports.md>).

Ensure you have setup the required pin roles as described in [Setting up the protocol definition](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.10.02_Setting_up_the_protocol_definition.md>).

## Procedure

-  In the Protocol Assignment section select a port in the resource column from the content assist list.
-  Assign a protocol form the content assist list in the protocol column. Note If you click New in this section, you can select a port and protocol from the content assist lists of the field resource and protocol.
-  In the Pin Role Assignment section select a pin in the pin column from the content assist list. Note If you click New in this section, you can select a pin from the content assist lists of the pin name field.
-  Assign a pin role from the content assist list in the role column.
-  Repeat the previous steps for all pin roles.
-  Save your pin configuration when you have finished assigning pin roles. Note The protocol assignment details are saved with the pin configuration. If you encounter problems loading your pin configuration, verify that all protocol definitions are loaded first.

## Results

You have assigned (hardware) pins to a protocol. This way the software knows which pins to use when a transaction is performed on a pin role of a that protocol.
