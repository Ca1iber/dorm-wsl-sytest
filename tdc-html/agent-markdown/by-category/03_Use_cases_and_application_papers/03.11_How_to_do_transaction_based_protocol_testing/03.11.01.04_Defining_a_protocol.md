- [Setting up the protocol definition](<03.11.01.04.01_Setting_up_the_protocol_definition.md>)

This chapter describes how to set up a new or modify an existing protocol definition.

Defining a new protocol always has two key elements:

- Transferring the device independent protocol's definition to SmarTest, which is covered in [Setting up the protocol definition](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.10.02_Setting_up_the_protocol_definition.md>).
- Linking device independent and dependent protocol related details together, which is covered in [Assigning pin roles and protocols](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18.03.10.01_Assigning_pin_roles_and_protocols.md>)
