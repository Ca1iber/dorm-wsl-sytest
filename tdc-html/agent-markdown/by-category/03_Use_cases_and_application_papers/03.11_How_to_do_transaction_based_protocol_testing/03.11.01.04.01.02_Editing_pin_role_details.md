# Editing pin role details

## About this task

This task describes how to enter pin role and pin role group specific encode and decode functions.

## Procedure

-  Select a pin role within the structure of the protocol.  ![Pin role details](<../../../../raw/126151.png>)  Note If you rename the pin role here, the protocol structure will be updated accordingly. You may disable this propagation feature in the [preference settings of the protocol editor](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.14.17_Protocol_Editor_preference_page.md>).
-  Enter the Encode function to be used on pin role level or pin role group level respectively.
-  Enter the Decode function to be used on pin role level or pin role group level respectively.
-  Save your modifications by pressing the CTRL + S key combination simultaneously.

## Results

You have entered the encode and decode function to be applied on pin role and pin role group level.

## What to do next
