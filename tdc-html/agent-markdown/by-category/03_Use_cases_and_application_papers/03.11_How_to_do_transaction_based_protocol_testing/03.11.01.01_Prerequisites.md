# Prerequisites

This section lists all requirements that have to be met in order to set up and use a protocol successfully:

- Use multiport for your device setup.
- A system wide software license for enabling protocol based tests needs to be available and enabled in the model file.
- The STATEMAP has to be used as it is of significant importance for protocol interpretation respectively generation.Note There are special conditions for state maps to be used with protocol definitions, refer to the [important information section of the protocol wavetable](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.06_Wavetable_tab.md>) description.
