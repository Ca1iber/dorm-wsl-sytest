# Editing transaction details

## About this task

This task describes how to create or edit protocol transaction details, like parameters and encoding/decoding functions.

## Procedure

-  Select a transaction within the structure of the protocol.
-  Enter the overall length of the transaction in state characters into the Length field.  ![Transaction details](<../../../../raw/126145.png>)  Note If you rename the transaction here, the transaction's name in the protocol structure will be updated accordingly. You may disable this propagation feature in the [preference settings of the protocol editor](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.14.17_Protocol_Editor_preference_page.md>).
-  In the Parameters section click New to enter parameters for the transaction that can be used in your test method.
-  Define the Direction, Length and Decode function of each parameter by clicking into the corresponding field behind the parameter name.
-  If necessary you can change the order of parameters by selecting the parameter and than clicking on Move Up or Move Down. Note The order and the direction of parameters is important for using parameters within your test method.
-  If required, select a parameter and click New in the symbol section to add a new symbol.
-  Double-click into the Value field behind the symbol's name to enter the corresponding value.
-  If required at this level, enter any encode / decode function in the Function section.
-  Save your modifications by pressing the CTRL + S key combination simultaneously.

## Results

You have defined the selected transaction along with the corresponding parameters.

## What to do next

If required, enter the pin role specific encode / decode functions by [Editing pin role details](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.10.05_Editing_pin_role_details.md>).

If your protocol does not need pin role specific encoding/decoding you may enter the required protocol field details by [Editing field details](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.10.06_Editing_field_details.md>).
