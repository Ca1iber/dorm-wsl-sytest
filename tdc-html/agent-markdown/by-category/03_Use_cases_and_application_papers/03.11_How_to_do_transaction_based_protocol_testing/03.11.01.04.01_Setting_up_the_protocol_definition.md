# Setting up the protocol definition

#### Subtopics

- [Editing transaction details](<03.11.01.04.01.01_Editing_transaction_details.md>)
- [Editing pin role details](<03.11.01.04.01.02_Editing_pin_role_details.md>)
- [Editing field details](<03.11.01.04.01.03_Editing_field_details.md>)

Protocol definitions can either be created from scratch or be imported from an existing protocol definition.

## About this task

This task describes how to create a new protocol structure including transactions, pin roles and fields.

It also can be used for editing existing protocol definition either imported or created previously.

Note Further protocol specification, such as transaction, pin role and field details are described in separate tasks.

## Before you begin

Ensure you have defined all resource (hardware) pins and created independent ports to be used by your protocol, refer to [Protocol based terms put into perspective](<03.11.01.03_Protocol_based_terms_put_into_perspective.md>) for a schematic overview.

Note Pins used by a protocol may not be part of a larger group of pins.

Create a new setup component of type 'protocol' as described in [Creating a new single setup component](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02.01.02_Creating_a_new_single_setup_component.md>).

## Procedure

-  Open your new protocol as described in [Opening a protocol in the protocol editor](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.10.01_Opening_a_protocol_in_the_protocol_editor.md>).
-  Create pin roles by clicking New in the Pin Role section.  ![ProtocolEditor_ProtocolDefinitionTab_ProtocoDetails](<../../../../raw/126138.png>)
-  Enter the new pin role name, like MCD, and click OK.
-  Adjust the properties of each pin role to your needs.
-  Add Pin Role Groups by clicking New in the Pin Role Group section if you set up a parallel protocol, else leave this section empty.

  -  Enter the name of the Pin Role Group and click OK.
  -  Assign Pin Role Group Members within the Properties of the Pin Role Group window by adding Available Pin Roles to your group.
  -  If necessary, correct the order of the pin roles to reflect the MSB and LSB requirements of your parallel protocol.
  -  Click OK when finished.
  -  Correct the [Slice depth](<../../02_System_reference/02.07_Test_Method_Reference/02.07.11.01.09.11_Slice_depth.md>) if necessary.

-  If required, add constant state character sequences.

  -  Click New in the Constants section and enter the constant's name.
  -  Click OK.
  -  Double-click into the Value field behind your constant's name to enter the constant state character sequence.

-  Right-click the protocol icon in the overview area of the protocol editor and select New Transaction to create a new transaction like read or write.
-  Enter the transaction's name and click OK.
-  Expand the protocol's structure by clicking on the triangle in front of the protocol's name in the overview area of the protocol editor.
-  Select the transaction you just added and enter transaction details as described in [Editing transaction details](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.10.04_Editing_transaction_details.md>).
-  Expand the transaction's structure by clicking on the triangle in front of the transaction's name.
-  Select a pin role and enter pin role details as described in [Editing pin role details](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.10.05_Editing_pin_role_details.md>).
-  Right-click the pin role's name to which you like to enter protocol fields and select New Field.
-  Enter the protocol field's name and click OK.
-  Select the protocol field you just added and enter field details as described in [Editing field details](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.10.06_Editing_field_details.md>).
-  Enter all fields required with their corresponding details for all pin roles. Note The order of the fields is important and has to reflect your protocol.
-  In case you have to change the order, right-click the field to be moved and select Move Up or Move Down.
-  In order to create more transactions with the same structure and pin role and field details, right-click the transaction you just defined and select Copy. Else repeat the previous steps for each transaction, pin role and field to be defined for your protocol and skip the following steps.
-  Right-click the protocol and select Paste.
-  Enter a new name for the transaction you are pasting and click OK. Note If you paste transactions keep in mind to adapt the encoding/decoding functions and directions of pin roles and fields accordingly.
-  Save your modifications by pressing the CTRL + S key combination simultaneously.

## Results

You now have defined a new protocol and its corresponding transactions, pin roles and fields.
