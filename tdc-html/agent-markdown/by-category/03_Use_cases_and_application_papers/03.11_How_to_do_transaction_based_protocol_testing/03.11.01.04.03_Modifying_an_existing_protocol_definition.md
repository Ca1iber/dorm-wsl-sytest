# Modifying an existing protocol definition

Modifying an existing protocol definition follows the steps pointed out in [Setting up the protocol definition](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.10.02_Setting_up_the_protocol_definition.md>).

However, there are to different ways to access an existing protocol definition.

## Protocol definition is already part of the device setup

In this case simply load the protocol as described in [Loading a single setup component](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02.01.01_Loading_a_single_setup_component.md>). Then follow the procedure outlined in [Opening a protocol in the protocol editor](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.10.01_Opening_a_protocol_in_the_protocol_editor.md>) and enter your modifications.

## Protocol definition is not yet part of the device setup

First you have to import the protocol to your device as described in [Importing a protocol](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02.01.11_Importing_a_protocol.md>). Then [open](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.10.01_Opening_a_protocol_in_the_protocol_editor.md>) it and carry out your modifications.
