# Setting up the pattern and the vectors

Once you have set up the timing, you need to create a pattern and enter the vectors.

## Patterns

You create a pattern for digital capturing with the pattern debug tool just like any other pattern. Keep the following rules in mind:

- The pattern type must be Main, subroutines can be called for the main label.
- The pattern must be stored in sequencer memory (SM).

## Vectors

After you created the pattern, you must enter the actual vectors in the pattern editor. They contain the input data of the device and the expected output data.

The use of loops and REPEAT commands is an efficient way to capture a large number of samples.

## Selective standard capturing vs. HRPF capturing

For selective standard capturing you cannot generate pass/fail results on capture pins. Only C and D actions are allowed.

This is different for selective capturing in High-Resolution-Pass/Fail (HRPF) mode. The HRPF mode allows receive compare actions (like H, L, X, and M), and capture (C) and Do not capture (D) actions on the same capture pins.

In this case you can also use match loops.

For details on the HRPF mode see [Setting up the timing](<03.07.01.02_Setting_up_the_timing_for_digital_capture.md>).
