# Cloning Patterns to Ports

This feature allows you to clone existing vector patterns to various ports. The vector variables will also be automatically cloned with the patterns if they match. In addition the JSUB (Jump sub-patterns) will also be cloned.

This is done in the Pattern Explorer and, how to do it is explained in the section [Cloning a pattern](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.01.06_Cloning_a_pattern.md>).

## Functional changes

- Introduced in SmarTest 6.5.3
