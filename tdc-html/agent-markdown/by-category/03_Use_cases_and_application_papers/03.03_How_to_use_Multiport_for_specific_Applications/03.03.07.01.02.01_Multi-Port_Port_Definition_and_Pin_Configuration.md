# Multi-Port Port Definition and Pin Configuration

The first and most important part of the multi-port conversion, is the assignment of ports.

This is explained in the section [Working with ports](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18.02.09_Working_with_ports.md>) of the Setup and Result Tools manual.

Adding the port definitions can be done using the SmarTest pin configuration tool or by editing the pin configuration file. Also the firmware command DFPT can be used to define ports in the pin configuration file.

In the example discussed here, for each of the DUT's independent cores (DSP and CODEC), you define separate ports containing the digital pins for the respective cores.

In addition to the CODEC digital pins, the pin configuration file also needs to be modified to include the CODEC analog pins.

The analog pins are not defined as ports, but as analog pins.

An example of how the port definitions may look is shown below:

DFPT(awgtrig,csb,digcaptrig,micbias,cmode,cscl,csda,vmid),(control)

DFPT(adcdat,adclrc,bclk,cclkout,dacdat,daclrc,xti_mclk,xto),(audio)

DFPT(a19,a18,a17,a16,a15,...),(dsp)

Note that three ports have been assigned to the two cores

- The digital pins for the DSP (dsp).
- The digital Pins for the CODEC (analog).
- The additional port is for control of the DUT (control).
