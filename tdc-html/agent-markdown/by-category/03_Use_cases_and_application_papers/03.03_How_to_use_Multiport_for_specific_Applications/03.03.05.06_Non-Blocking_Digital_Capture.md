# Non-Blocking Digital Capture

#### Subtopics

- [NB Digital Capture Overview](<03.03.05.06.01_NB_Digital_Capture_Overview.md>)
- [Non-Blocking digital capture application](<03.03.05.06.02_Non-Blocking_digital_capture_application.md>)
- [Test Method API for Executing a Non-Blocking Digital Capture Test](<03.03.05.06.03_Test_Method_API_for_Executing_a_Non-Blocking_Digital_Capture_Test.md>)

The non-blocking feature prevents conflicts between digital and analog sequencers. With non-blocking, the digital sequencer can remain active while analog firmware commands are being executed. This is not a default tester operation.

Non-blocking is utilized with a "handshake" between the digital and analog sequencers.

## Functional changes

- Introduced before SmarTest 6.3.2
