# Using Concurrent Test Timing Specifications

Concurrent test is a test methodology that relies on the multi-port software for easy implementation. As such all timing settings are the same as multi-port settings.

Concurrent test settings are based on the multi-port software. As such, there is no difference on the settings.

## Functional changes

- Introduced before SmarTest 6.3.2
