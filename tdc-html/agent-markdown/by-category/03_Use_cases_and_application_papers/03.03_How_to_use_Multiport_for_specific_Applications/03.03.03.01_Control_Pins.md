# Control Pins

Control pins are used for every test suite to set the device to a certain state.

This normally takes only a relatively small number of vector entries for initialization and stability.

In a serial vector label, it is often the case, that once the control pins have been activated and set to certain state in the device, they remain static in that state until a new state needs to be activated for the next test execution.

In a serial to multi-port conversion for vector memory reduction, these control pins can be assigned a port of their own and the port specific label can be reduced to a vector length that is sufficient to set the device to the desired test state.
