# Incorporating External Modules into V93000 Programs

#### Subtopics

- [Example of Incorporating an External Module into V93000 Programs](<03.03.08.01_Example_of_Incorporating_an_External_Module_into_V93000_Programs.md>)

Using a multi-port setup allows you to incorporate external modules mounted on the DUT board into the DUT test regime. Such modules can be plug in components for which the DUT Board needs to be specially designed.

It does not matter whether the module has its own vector pattern, timing, and levels as these can be set up individually if the module's pins are defined in a separate port.

The software integration is made easy by using the multi-port setup to merge two core tests (one for the external module's pins and one for the DUT's pins) into a singe parallel test execution.

Typically, when converting from a normal setup to one incorporating an external module, you would proceed as follows:

- Update the pin configuration file with pins for the external module and define 2 ports; one for the module and one for the DUT.
- Update the level file with definitions for the external module's pins, such as driving and receiving levels, as well as any required termination settings.
- Update the timing file with information related to the required timing for the module's operation such as frequency and sampling.
- The vectors for the module are processed in a multi-port format to form the device executable label that the measurements are taken from. The DUT executable label is also converted to a multi-port setup to form the executable port burst.
- All other test program patterns are left untouched and in their original default format.
