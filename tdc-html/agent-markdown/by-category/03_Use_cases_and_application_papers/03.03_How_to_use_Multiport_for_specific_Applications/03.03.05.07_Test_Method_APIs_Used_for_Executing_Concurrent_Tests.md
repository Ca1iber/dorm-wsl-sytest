#### Subtopics

- [Properties of the NB_DIGITAL_CAPTURE_START and NB_DIGITAL_CAPTURE_END API function](<03.03.05.07.02_Properties_of_the_NB_DIGITAL_CAPTURE_START_and_NB_DIGITAL_CAPTURE_END_AP.md>)

Only certain API functions can be used to execute concurrent test. The choice of execution APIs depends on the types of tests necessary for the device ports.

The following API functions can be used to execute concurrent tests:

- DIGITAL_CAPTURE_TEST
- NB_DIGITAL_CAPTURE_START and NB_DIGITAL_CAPTURE_END
- START_TEST
- FUNCTIONAL_TEST
- DIGITAL_CAPTURE_TEST

## Functional changes

- Introduced before SmarTest 6.3.2
