# How to Set Up a Multi-Port Test with a DC Sub-pattern

#### Subtopics

- [Configuring Ports, Pins, Timing, Vectors and Test Methods](<03.03.06.02.01_Configuring_Ports__Pins__Timing__Vectors_and_Test_Methods.md>)

## About this task

This describes the steps needed for setting up a test to carry out PPMU (DC) and digital tests in parallel in a multi-port setup.

## Procedure

-  Define the Ports and assign pins to them.
-  Define the timing.
-  Define the main patterns for the multi-port burst.
-  Define a subpattern (not a main pattern) for the port on which the PPMU test is to be run and call this sub-pattern from the main pattern of this port.
-  Integrate the main patterns into a multi-port burst.
-  Create a test method that:

  - uses the PPMU_XXX API's to create a PPMU test for one or more pins of the desired port.
  - uses the PATTERN_CONTROLLER and PATTERN API's to specify a sub-pattern from which this test will be run.

-  Define a test suite that:

  - Specifies the newly created test method in the "Testmethod" field
  - Specifies the multi-port burst in the "Vector Label" field
