# Clock Pins

Most devices are clocked by a fixed set of clocking pins. The device's main clocks normally need to run for all test executions, hence clock pins have the greatest requirement of vector memory.

The advantage of assigning clock pins, is that they normally only need to execute a periodic signal (there are a few exceptions). This allows you to set a clock pulse as a break state while maintaining continuous execution (continuous clock), hence saving vector memory.

The pulse width is set by the spec variable used in the clock port timing equation where the pulse duty cycle is also defined.

If the frequency of the clock pins is different to that of the remaining device pins, then a multi-port timing setup is required.

If there are special requirements related to clock behavior for a given test, the clock can be allocated a port label of its own, to drive data for some vector sets while executing break (clock) cycles in others.
