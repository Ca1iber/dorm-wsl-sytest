# Example of Merging Two Separate Test Programs Into One

#### Subtopics

- [Making a CCT Plan](<03.03.07.01.01_Making_a_CCT_Plan.md>)

Consider a Device consisting of two independent cores:

- A digital signal processor core (DSP).
- A CODEC core consisting of digital and analog pins.

in which the package test program originally consisted of two independent test programs, one for each core.

The task is to merge the tests together into a single test program and run the tests simultaneously to save testing time.

For this purpose, a concurrent test procedure was used (see the section, [Concurrent Tests (CCT)](<03.03.05_Concurrent_Tests__CCT.md>)), which necessitates generating a multi-port setup from the single port setup.

The following procedure was adopted:

- Creating a test plan for the concurrent test required (see, [Making a CCT Plan](<03.03.07.01.01_Making_a_CCT_Plan.md>)).
- Test setup conversion from single-port to multi-port

  - CCT port definition and pin configuration (see [Multi-Port Port Definition and Pin Configuration](<03.03.07.01.02.01_Multi-Port_Port_Definition_and_Pin_Configuration.md>)).
  - CCT vectors (see, [Multi-Port Vector Conversion](<03.03.07.01.02.02_Multi-Port_Vector_Conversion.md>)).

- Conversion to CCT test methods (see, [Convert Test Functions to Test Methods](<03.03.07.01.03_Convert_Test_Functions_to_Test_Methods.md>)).
- Finalizing the CCT test flow (see, [Setup the CCT Test Flow](<03.03.07.01.04_Set_up_the_CCT_Test_Flow.md>)).

The following sections describe these steps.
