# Configuring Migration Profile

## About this task

During device migration, the migration profile will determine how the migration cheatsheet will be used to migrate specific devices.

## Before you begin

Ensure that SmarTest is running and a cheat sheet is open.

## Procedure

-  Click Click to perform to open a migration profile configuration wizard.
-  Select Original Software Version, default is 6.5.X.
-  Select current Hardware Environment, default is P1600.
-  Select Current Software Version, default is 7.1.0.
-  Select Current Hardware Environment, default is PS1600.
-  Select ScanType: Testflow or Test Program.
-  Select Scan File, the specific migration file.
-  Select Conversion Mode, you can choose to backup the original resource while using conversion tool.
-  Click Finish

The following picture illustrates a configured profile

  ![Test Program Migration Profile](<../../../../raw/123975.png>)

## Results

Your Profile is ready.

## What to do next

Screen you testflow or Test Program.
