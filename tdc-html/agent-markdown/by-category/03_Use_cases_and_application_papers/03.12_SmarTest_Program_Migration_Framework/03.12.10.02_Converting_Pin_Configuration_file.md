# Converting Pin Configuration file

DPS32/MS-DPS based pin configuration file can be converted to DPS128 based pin configuration.

## About this task

This task is about converting DSP32/MS-DPS in 8 channel mode based pin configuration to DPS128 based pin configuration.

## Before you begin

Specify and locate the Pin configuration file that needs to be converted and the relevant model file.

## Procedure

 To perform the automatic conversion, in the command line (Shell) invoke the conversion tool as follows:

```
/$HP83000_ROOT/prod_pws/migration/DPS128_conversion/DPS_pogoconfig_conversion.rb
```

The following set of parameters exist:

[-r] Optional, replace the original file without backup

[-h] Optional, help be logged in <logfile>

[-c] Optional, only check if conversion is needed

[-l] Optional, log level 3->DEBUG, 2->INFO, 1->WARN, 0->ERROR, default level is INFO

[-f <logfile>] Optional, conversion result will be logged in <logfile>

<-m model file> specify the model file that needs to be referred.

<pin configure file> specify the setup file that needs to be converted.

 Note When the parameter [-c] is not used , a backup of the original file is also created ( .taco_backup format).

## Results

Based on the input model and pin configuration files, a successful conversion results in the pin configuration file being overwritten as follows:

```
DFPN (211105,21106,21107,21108),"2",(D0)
DFPS (20301, 20302, 20303, 20304), POS, (Vcc)
PALS 2, (23501, 23502, 23503, 23504), POS, (Vcc)
DFPT (p1, p2 ...), {(dc_port)}
DFPT (Vcc, Vee ...), {(dc_port_dps)}
DFPT (p1, p2 ...), {( port_original)}
DFPT (D0, DDD), {( port_converted_msdps )}
DFPT (Vcc), {( port_converted_dps32)}
```

## Example

In this example, the tool takes the file model and pins as the input. The pin configuration file will be overwritten by the modified one and backup old files.

```
$DPS_pin_conversion.rb -m device/model device/configuration/pins
```

The corresponding changes could look like:

```
DFPN (211105,21106,21107,21108),"2",(D0)
DFPS (20301, 20302, 20303, 20304), POS, (Vcc)
PALS 2, (23501, 23502, 23503, 23504), POS, (Vcc)
```

## What to do next

Start SmarTest and load your pin configuration and the remaining setup files.
