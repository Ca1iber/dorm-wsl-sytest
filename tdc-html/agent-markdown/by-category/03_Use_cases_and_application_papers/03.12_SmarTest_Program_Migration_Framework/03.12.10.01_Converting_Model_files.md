# Converting Model files

DPS32 and MS-DPS based model file can be automatically converted to DPS128 based model file.

## About this task

This task is about converting DPS32/MS-DPS in 8ch mode based model file to DPS128 based model file.

## Before you begin

Identify and locate the model file to be converted.

## Procedure

-  To convert a model file from the command line, invoke the model file conversion tool as follow:

```
/$HP83000_ROOT/prod_pws/migration/DPS128_conversion/DPS_model_conversion.rb
```

-  The following options are available:

[-r] Optional, replace the original file without backup

[-h) Optional, help

[-c] Optional, only check if conversion is needed

[-l] Optional, log level 3->DEBUG, 2->INFO, 1->WARN, 0->ERROR, default level is INFO

[-f<logfile>] Optional, conversion result will be logged in <logfile>

<original model file> specify the model file that needs to be converted

## Results

After the conversion, the target model file contains new lines in the sections POGOCABLING and DPS as follow:

```
POGOCABLING
101: pogoblocks = "301,302,303,304,306,307,308,209", type=REDIRECT, subtype=E8023PF, config=" 1=301,302; 3=303,304; 2=306,307; 4=308,209"
103: pogoblocks = "401,402,403,404,405,406,407,408", type=REDIRECT, subtype=E8023PA, config=" 120=401; 220=402;119=403;219=404;320=405;321=406;327=407;329=408"
DPS
30101-30416: type = DCS-DPS128HC
30501-30816: type = DCS-DPS128HC
40101-40816: type = DCS-DPS128HC
```

## What to do next

Start SmarTest and verify that your new model file works properly.
