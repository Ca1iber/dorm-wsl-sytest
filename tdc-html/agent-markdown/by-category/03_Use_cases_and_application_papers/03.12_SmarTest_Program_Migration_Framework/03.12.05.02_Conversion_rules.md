# Conversion rules

The e-edge conversion tool is a one-button tool that converts bidirectional edges to unidirectional edges. It takes a V93000 timing file as input and gives a V93000 timing file as output.

## ETIM Edge Timing

ETIM has 6 parameters, each parameter assigns a timing value to a bidirectional edge. ETIM is replaced by ETDS, which assigns timing values to unidirectional edges. Because from the timing, we cannot tell, whether a bidirectional edge is used as drive or receive, the conversion can assign the timing to both the corresponding drive- and receive edge.

`ETIM {waveform_set},{timing_set}, [t1], [t2], [t3], [t4], [t5], [t6], {(pinlist)}`

replacement:

`ETDS {waveform_set},{timing_set}, "[d1:{t1} r1:{t1}] ... [d6:{t6} r6:{t6}]", {(pinlist)}`

## WFDF Waveform Definition

Similar to ETIM, the six parameters of WFDF assign actions to bidirectional edges. WFDF is replaced by WFDS, which assigns actions to unidirectional edges. Whether a bidirectional edges is converted to a drive- or receive edge, depends on the action, which is assigned to the bidirectional edge. Bidirectional edges with drive actions are converted to drive edges, bidirectional edges with receive actions are converted to receive edges.

`WFDF {wvf_set}, {wfIndex}, {a1}, {a2}, {a3}, {a4}, {a5}, {a6}, {(pinlist)}`

replacement:

`WFDS {wvf_set},{wfIndex},, "{d1|r1}:{a1} ... {d6|r6}:{a6}", {(pinlist)}`

## BWDF Break Waveform Definition

BWDF is replaced by BWDS, conversion rules are similar to WFDF.

`BWDF {wvf_set}, {a1}, {a2}, {a3}, {a4}, {a5}, {a6}, {(pinlist)}`

replacement:

`BWDF {wvf_set},,,"{d1|r1}:{a1} ... {d6|r6}:{a6}", {(pinlist)}`

## ETDS Edge Timing Definition string

The timing definition string must no longer contain bidirectional edges e1 to e6. You have to use d1..d6 / r1..r6 instead. Similar to ETIM, each bidirectional edge will be converted to both a drive edge and a receive edge

`ETDS {waveform_set},{timing_set},,"[e1:{t1}] ... [e6:{t6}]"`

replacement:

`ETDS {waveform_set},{timing_set},,"[d1:{t1} r1:{t1}] ... [d6:{t6} r6:{t6}]"`

## WFDS Waveform Definition String

The waveform definition string must no longer contain bidirectional edges e1 to e6. You have to use d1..d6 / r1..r6 instead. Similar to WFDF, it depends on the action, which edge type to use.

`WFDS {wvf_set},{wfIndex},,"[e1:{a1}] ... [e6:{a6}]",{(pinlist)}`

replacement:

`WFDS {wvf_set},{wfIndex},,"[{d1|r1}:{a1}] ... [{d6|r6}:{a6}]",{(pinlist)}`

## BWDS Break Waveform Definition String

The break waveform definition string must no longer contain bidirectional edges e1 to e6. You have to use d1..d6 / r1..r6 instead. Conversion rules are similar to WFDS.

`BWDS {wvf_set},,,"[e1:{a1}] ... [e6:{a6}]",{(pinlist)}`

replacement:

`BWDS {wvf_set},,,"[{d1|r1}:{a1}] ... [{d6|r6}:{a6}]",{(pinlist)}`
