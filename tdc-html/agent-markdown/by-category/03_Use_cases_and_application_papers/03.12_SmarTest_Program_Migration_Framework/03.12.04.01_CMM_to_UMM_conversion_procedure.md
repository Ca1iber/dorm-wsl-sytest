# CMM to UMM conversion procedure

## About this task

This section shows how to convert device vector from CMM (compatible memory) to UMM (unified memory) using the migration tool cmm2umm.ksh The whole execution log will be generated under device path, named as cmm2umm.log. Once the conversion is done, the original vector file will be backup under [device]/vector/VM. (You can also use the tool conv_vector to convert vector from VM to SM. Refer to [Moving vectors to another memory type](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.01.14.01_Moving_vectors_to_another_memory_type.md>) for details.)

## Before you begin

- Make sure the ASCII interface is installed.
- Verify the memory model used by the device: CMM or UMM. See also [How the Vector Memory Stores Vectors](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.16.04.06_How_Vectors_are_Stored_in_Sequencer_Memory.md>).

## Procedure

-  /$HP83000_ROOT/prod_pws/migration/CMM2UMM_Conversion/cmm2umm.ksh  [-d <device dir>] //Optional, device path. Default is current path

  - [-p <pin config file>] //Optional, pin file for multiport usage
  - [-f <vector/pmf file>] //Optional, vector file or pattern master file. If you are using a master file, it's recommended to convert the master file instead of the whole path. Since the tool will only convert the related partial vectors according to the input master file.
  - [-c] //Optional, the converted vector is compressed.Note This script can be also extended to support all the parameters of conv_vector tool. You could also use the pure conv_vector to do the conversion.

-  Load the setup and verify the results.
