# Migrating TIA per pin to per TMU per pin

If you use Smart Scale hardware you may have to convert ppTIA related tests to ppTMU tests since the TMU hardware is not available on Pin Scale systems. The TMU and the TIA address very similar scope of measurements, for example, period measurements, jitter measurements and so on. Nevertheless, the approach of how the measurement is performed with the TMU is quite different in comparison to TIA.

## ppTIA to ppTMU Conversion Procedure

To convert ppTIA based tests to ppTMU based tests, we recommend the following basic procedure.

- Create a wavetable which contains TMU actions. See also [Starting a TMU measurement from a pattern](<../../02_System_reference/02.06_Command_Reference/02.06.13.01.02_Starting_a_TMU_measurement.md>).
- Create a timing equation which defines time stamps for the TMU actions.
- Create vectors which contains TMU action.
- Create your test method using the class TMU_TASK or using the TMU library.
