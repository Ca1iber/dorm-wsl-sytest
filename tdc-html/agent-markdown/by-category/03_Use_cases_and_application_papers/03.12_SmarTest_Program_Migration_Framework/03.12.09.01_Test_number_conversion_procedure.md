# Test number conversion procedure

## About this task

This section shows how to use the test number conversion tool to migrate test number manager based test numbers to test number generator based test numbers.

## Before you begin

Prior to run the tool, ensure that the following conditions are met.

- SmarTest is running in offline or online mode.
- The specified testflow file is loadable by SmarTest v7.1 or above.
- There is a corresponding test number file for the specified testflow file under the test_numbers directory in the device directory
- If csv TMLimits file is specified, make sure that test numbers in the test method are created based on csv TMLimits file instead of hard-coded.

## Procedure

-  Execute the conversion tool from the command line

```
/$HP83000_ROOT/prod_pws/migration /TNO_conversion/TNO_conversion [-h] [-t TMLimits] [-l log] [-c all/auto/manual] <original file> [new converted file]
```

[-h]:(optional) print the help doc

[-c]:(optional) only check if conversion is needed

-  If auto is specified, tool only checks if auto conversion is needed; If manual is specified, tool only checks if manual conversion is needed;If all is specified, tool checks if both auto and manual conversion are needed.

[-t TMLimits]:(optional) specify the TMLimits file to be created

[-l log]:(optional) specify the log file

<original file>: A V93000 testflow file as an input file that has an equivalent file in the test_numbers directory.

<new converted file>: (optional) Output V93000 testflow file. If not specified, a backup file named <original_file_name>.bak will be created and the original file will be overwritten.

## Results

Your testflow contains test number manager based test numbers.

## Example

```
$TNO_conversion -t device_directory/t_table/convert.csv device_directory /testflow/functional.tf.
```

In this example, the tool takes the file functional.tf as the input. This file will be overwritten by the modified one and a backup testflow file with postfix .bak will be created. Further, a test table file convert.csv will be created.

```
$TNO_conversion -c auto device_directory/testflow/functional.tf
```

In this example, the tool takes the file functional.tf as the input. The tool only check if automation conversion is needed for the specified testflow file.

Load and verify your testflow.
