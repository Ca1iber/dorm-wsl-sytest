# Migrating test number

#### Subtopics

- [Test number conversion procedure](<03.12.09.01_Test_number_conversion_procedure.md>)
- [Test number conversion rules](<03.12.09.02_Test_number_conversion_rules.md>)
- [Test number conversion use cases](<03.12.09.03_Test_number_conversion_use_cases.md>)

With the introduction of the test number generator, all test number manager related flags are disabled and the flags in a testflow file are ignored. The test number generator will be the tool to create test numbers in testflows. The test Numbering conversion tool converts the test numbering settings in test number manager to the ones in test number generator. The Test Numbering Conversion tool is designed to create test numbers in the testflow file based on test number file. As an option, it supports the creation of a [test table](<../../02_System_reference/02.10_Data_Logging/02.10.01.08.03_Working_with_test_tables.md>) CSV file as well.
