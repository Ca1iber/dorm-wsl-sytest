# Conversion Procedure

## About this task

This task is about converting bidirectional edges to unidirectional edges.

## Before you begin

Make sure you have access to the timing file.

## Procedure

-  Execute the conversion tool type from the command line (shell)

```
/$HP83000_ROOT/prod_pws/migration/eedge_conversion/eedgeconvert <original file> <new converted file>
```

<original file>: An equation based V93000 timing file as input file.

<new converted file>: Output V93000 timing file with physical waveform.

-  Load and verify the timing file. Note The default installation path is /$HP83000_ROOT/prod_pws/migration. If you choose to install the migration package somewhere else, make sure you refer to the right installation path.

## Example

The following example shows the usage of the Log2Phy tool.

```
$/$HP83000_ROOT/prod_pws/migration eedgeconver abc.tim /output/abc_converted.tim
```

In this example, the tool takes the file abc.tim as the input and generates the .abc_converted.tim timing file in the ./output/ directory.

You can now load the generated output timing file into SmarTest.

## What to do next

Load the generated output timing file into SmarTest.
