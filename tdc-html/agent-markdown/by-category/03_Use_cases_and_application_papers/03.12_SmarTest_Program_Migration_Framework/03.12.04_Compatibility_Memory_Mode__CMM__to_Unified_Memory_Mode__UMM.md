# Compatibility Memory Mode (CMM) to Unified Memory Mode (UMM)

#### Subtopics

- [CMM to UMM conversion procedure](<03.12.04.01_CMM_to_UMM_conversion_procedure.md>)

Pin Scale channel cards have only one physical RDRAM for storing vector data and sequencer instructions. This physical architecture enables flexible storage. The Pin Scale channel cards support two memory modes: Compatibility mode and Unified mode. The cmm2umm tool converts vector data from the compatible memory mode to the unified memory mode.
