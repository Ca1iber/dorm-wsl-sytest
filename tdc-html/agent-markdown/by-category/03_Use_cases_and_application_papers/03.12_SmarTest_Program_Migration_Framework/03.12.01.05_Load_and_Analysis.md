# Load and Analysis

During device migration,you can monitor a specific testflow and test program while it is being loaded. All the detected migration items will be listed in the Migration Items View.

## About this task

Following migration items will be detected while loading.

- Obsoleted firmware
- Wrong timing EEdge
- Vector using obsoleted CMM pattern
- Out of range PPMU definition
- Out of range Level definition

## Before you begin

Ensure that SmarTest is running and a cheat sheet is open.

## Procedure

-  Select Load and Analysis.
-  Load your testflow or test program from the TPE.
-  Switch to the Migration Items view, and browse through the migration items in the view.
-  Select one item and browse for detail information and resolution.
-  Fix migration gap according to resolution description, conversion tool and TDC document support.
-  Reload the testflow or test program iteratively, until there is no migration item gap captured.
-  The following picture shows the migration item view and proposed solutions.  ![Migration item view](<../../../../raw/123977.png>)

## Results

Your testflow is analyzed.
