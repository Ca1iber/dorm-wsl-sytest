# Migrating to DPS128 based setup

#### Subtopics

- [Converting Model files](<03.12.10.01_Converting_Model_files.md>)
- [Converting Pin Configuration file](<03.12.10.02_Converting_Pin_Configuration_file.md>)
- [Typical issues when converting to DPS128](<03.12.10.03_Typical_issues_when_converting_to_DPS128.md>)

With the introduction of the DPS128, there is a need to convert MS-DPS or DPS32 based setup to DPS128. The DPS128 conversion tools are a series of components that convert the setup files (model file, pin configure file, level file, timing file, pattern file) to DPS128 based setup files.
