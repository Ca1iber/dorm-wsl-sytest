# Execution and Analysis

## About this task

This task is about monitoring migration problems while executing test programs.

## Before you begin

Make sure a migration Cheat Sheet is open and a migration profile is configured.

## Procedure

-  Select Execution and Analysis from the Migration cheat sheet as shown below.  ![Execution and Analysis](<../../../../raw/123983.png>)
-  Check for problems and resolution proposal in the migration item view.  ![Migration item view by category](<../../../../raw/123987.png>)

## Results

You have access to the migration item list.

## What to do next

Solve migration problems.

## Functional changes

- Introduced in SmarTest 7.1.0
