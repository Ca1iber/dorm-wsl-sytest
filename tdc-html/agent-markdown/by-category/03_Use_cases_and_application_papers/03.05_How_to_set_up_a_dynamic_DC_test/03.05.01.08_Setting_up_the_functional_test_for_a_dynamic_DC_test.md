# Setting up the functional test for a dynamic DC test

Generally you will use a test method to execute a dynamic DC test and retrieve the results.

The example below describes the setup of a test method which executes the functional test and uploads the result. The result will include results of the pass/fail limit checks defined previously for the measure events executed on the PMU signal pin (Sdd). Thus it can be used to decide if the actual values need to be uploaded for further analysis.

```
...
static const STRING pmuPinList = "Sdd, Sdd2";
static const STRING pmuPins[2] = { "Sdd", "Sdd2" };
static const INT    numPMUPins = 2;
...

...
virtual void run()
{
  ON_FIRST_INVOCATION_BEGIN();
    FUNCTIONAL_TEST();
  ON_FIRST_INVOCATION_END();
```

The FUNCTIONAL_TEST() call causes the ramp pattern to be executed on all active sites. In order to prevent it from being called multiple times (the test flow calls the test method once for each site), it must be placed in the ON_FIRST_INVOCATION_BEGIN() .. ON_FIRST_INVOCATION_END() block.

```
  bool testPassed = GET_FUNCTIONAL_RESULT();

  if ( ! testPassed ) {
    cout << "Site " << CURRENT_SITE_NUMBER() << " FAILED:" << endl;
```

GET_FUNCTIONAL_RESULT() retrieves the result of the functional test (that is, the pattern run) and will include the results of the limit checks defined in the events for the PMU signal pin (Sdd).

The functional test result is used to determine if it is required to upload the measurement values for further result analysis. The values will only be uploaded if the functional test has failed. This significantly improves the throughput.

```
    DC_RESULT_ACCESSOR resultAccessor;
    resultAccessor.uploadResult(pmuPinList, TM::RESULT_INDEX);
```

The DC_RESULT_ACCESSOR class is used to upload all measurement values from all pins in parallel (the pins Sdd and Sdd2 are provided as pin list parameter). Alternatively you could upload only the values from the failed tests, or a subrange of the measurement values.

```
    for (INT i = 0; i < numPMUPins; ++i) {
      RESULT_POINT::DistanceType numResults =
        resultAccessor.getNumberOfAvailableResults(pmuPins[i]);

      if (numResults > 0) {
        dumpResultCount(pmuPins[i], numResults);

        RESULT_POINT firstPoint(resultAccessor.getFirstResultPoint(pmuPins[i]));
        RESULT_POINT lastPoint(resultAccessor.getLastResultPoint(pmuPins[i]));

        for (RESULT_POINT point = firstPoint; point <= lastPoint; ++point) {
          INT64 index = point.getIndex();
          DOUBLE value              = resultAccessor.getValue(point);
          RESULT_FAIL_INFO failInfo = resultAccessor.getFailInfo(point);
          TM::PHYSICAL_VALUE type   = resultAccessor.getMeasurementType(pmuPins[i], point);

          dumpResult(pmuPins[i], index, value, type, failInfo);
        }
      }
    }
  }
```

After the upload, in the for() loop, the results are examined on a per pin basis.

The example uses iterator based access and provides very fine granular access, not only to measured values, but also to event limit check results, clamp status information, and measurement errors (for example, range overflow).

Alternatively to the example above you can access the values only. In this case you simply read all measurement values of a pin in an array of doubles. Be aware that measurement errors may appear. They can be detected by a magic value lower than -99999 or higher than 99999.

```
        // Simply get all values ignoring all specialties.
        ARRAY_D values(resultAccessor.getValues(pmuPins[i], values);
```

Here the complete functional test and result upload sections of the test method code, including the dump routines. They show the use of the RESULT_FAIL_INFO object.

```
...
static const STRING pmuPinList = "Sdd, Sdd2";
static const STRING pmuPins[2] = { "Sdd", "Sdd2" };
static const INT    numPMUPins = 2;

/**
 *Testmethod class.
 *
 *For each test suite using this test method, one object of this
 *class is created.
 */
class DCDynDemoTests_ramp: public test method::TestMethod
{
protected:
//Add your class member variable here.

protected:
/**
 *Initialize the parameter interface to the testflow.
 *This method is called just once after a test suite is created.
 *
 *Note: TestMethod API should not be used in this method.
 */
virtual void initialize()
{
  //Add your intialization code here.
}

/**
 *This test is invoked per site.
 */
virtual void run()
{
  ON_FIRST_INVOCATION_BEGIN();
    FUNCTIONAL_TEST();
  ON_FIRST_INVOCATION_END();

  bool testPassed = GET_FUNCTIONAL_RESULT();

  if ( ! testPassed ) {
    cout << "Site " << CURRENT_SITE_NUMBER() << " FAILED:" << endl;

    DC_RESULT_ACCESSOR resultAccessor;
    resultAccessor.uploadResult(pmuPinList, TM::RESULT_INDEX);

    for (INT i = 0; i < numPMUPins; ++i) {
      RESULT_POINT::DistanceType numResults =
        resultAccessor.getNumberOfAvailableResults(pmuPins[i]);

      if (numResults > 0) {
        dumpResultCount(pmuPins[i], numResults);

        // Using iterator based access.
        RESULT_POINT firstPoint(resultAccessor.getFirstResultPoint(pmuPins[i]));
        RESULT_POINT lastPoint(resultAccessor.getLastResultPoint(pmuPins[i]));

        for (RESULT_POINT point = firstPoint; point <= lastPoint; ++point) {
          INT64 index = point.getIndex();
          DOUBLE value              = resultAccessor.getValue(point);
          RESULT_FAIL_INFO failInfo = resultAccessor.getFailInfo(point);
          TM::PHYSICAL_VALUE type   = resultAccessor.getMeasurementType(pmuPins[i], point);

          dumpResult(pmuPins[i], index, value, type, failInfo);
        }
      }
    }
  }

  TESTSET().cont(true).judgeAndLog_FunctionalTest();

  return;
}

/**
 *This function will be invoked once the specified parameter's value is changed.
 *@param parameterIdentifier
 *
 *Note: TestMethod API should not be used in this method.
 */
virtual void postParameterChange(const string& parameterIdentifier)
{
  //add your code
}

#define FMT_PASSED_FAILED(t) ((t) ? "FAILED" : "PASSED")
#define FMT_YES_NO(t)        ((t) ? "YES" : "NO")

void dumpResultCount(const STRING & pinName,
    RESULT_POINT::DistanceType numResults)
{
  cout << endl << "-> Number of available results for pin '" << pinName << "': ";
  cout << numResults << endl << endl;
}

void dumpResult(const STRING & pinName, INT64 index, DOUBLE value,
    TM::PHYSICAL_VALUE measurementType, const RESULT_FAIL_INFO & failInfo)
{
  cout << "   Result " << index << " -> Measurement Value: " << value;
  if (measurementType == TM::VOLTAGE) {
    cout << " V" << endl;
  } else {
    cout << " A" << endl;
  }

  if (failInfo.hasFailed()) {
    dumpFailInfo(failInfo);
  }
}

void dumpFailInfo(const RESULT_FAIL_INFO & failInfo)
{
  bool hasLowLimitFailed        = failInfo.hasLowLimitFailed();
  bool hasHighLimitFailed       = failInfo.hasHighLimitFailed();
  bool hasUserStatusCheckFailed = failInfo.hasUserStatusCheckFailed();

  cout << "   -> Low Limit Check  : "
       << FMT_PASSED_FAILED(hasLowLimitFailed) << endl;
  cout << "   -> High Limit Check : "
       << FMT_PASSED_FAILED(hasHighLimitFailed) << endl;
  cout << "   -> User Status Check: "
       << FMT_PASSED_FAILED(hasUserStatusCheckFailed) << endl;

  if (hasUserStatusCheckFailed) {
    dumpStatusCheckInfo(failInfo);
  }
}

void dumpStatusCheckInfo(const RESULT_FAIL_INFO & failInfo)
{
  bool hasLowClampViolation  = failInfo.hasLowClampViolation();
  bool hasHighClampViolation = failInfo.hasHighClampViolation();

  bool hasMeasurementRangeViolation     = failInfo.hasMeasurementRangeViolation();
  bool hasMeasurementTypeViolation      = failInfo.hasMeasurementTypeViolation();
  bool hasMeasurementPlacementViolation = failInfo.hasMeasurementPlacementViolation();

  cout << "   -> Status Information for FAIL:" << endl;

  cout << "      * Low  Clamp Violation           : "
       << FMT_YES_NO(hasLowClampViolation) << endl;
  cout << "      * High Clamp Violation           : "
       << FMT_YES_NO(hasHighClampViolation) << endl;
  cout << "      * Measurement Range Violation    : "
       << FMT_YES_NO(hasMeasurementRangeViolation) << endl;
  cout << "      * Measurement Type Violation     : "
       << FMT_YES_NO(hasMeasurementTypeViolation) << endl;
  cout << "      * Measurement Placement Violation: "
       << FMT_YES_NO(hasMeasurementPlacementViolation) << endl;

  cout << endl;
}

};
REGISTER_TESTMETHOD("DCDynDemoTests.ramp",DCDynDemoTests_ramp);
...
```
