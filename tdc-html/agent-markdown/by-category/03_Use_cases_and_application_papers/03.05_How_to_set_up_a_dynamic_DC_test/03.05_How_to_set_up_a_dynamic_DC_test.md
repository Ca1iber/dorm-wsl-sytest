# How to set up a dynamic DC test

#### Subtopics

- [A dynamic DC test example](<03.05.01_A_dynamic_DC_test_example.md>)
- [DC event application examples](<03.05.02_DC_event_application_examples.md>)

These use case examples illustrate the setup of a dynamic (sequencer‑controlled) DC test and will help you to understand the related user interface concepts, firmware commands, and test methods. Dynamic (sequencer‑controlled) DC tests are opposed to static (set-based) DC tests.

- The [dynamic DC test example](<03.05.01_A_dynamic_DC_test_example.md>) uses one DC signal pin (PMU) and one power pin (DPS). The test will

  - drive a rising voltage signal on the power pin (DPS), using test points on the sequencer.
  - measure the output voltage on the DC signal (PMU) pin.

- Refer to [Event classes and data types](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.63_EVENT_...__DC_events_API_reference.md#_345840__s_Event_classes_and_data_types>) for a list of all DC event related APIs.
