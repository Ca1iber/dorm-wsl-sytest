# DC event example: DAC distortion & noise test

## Setup test method

```
virtual void run()
{
  // Define voltage measurement capture event
  EVENT_WAVEFORM_VM event_DAC_capt("event_DAC_capt");
  event_DAC_capt.samples(num_samples);
  event_DAC_capt.sampleVectorDistance(32);
  event_DAC_capt.averages(4);
  event_DAC_capt.iClampChecks();

  // Insert events on pin "Analog_out" in pattern "DAC_distortion"
  PATTERN_CONTROLLER pc;
  PATTERN & pattern(pc.label("DAC_distortion"));
  VEC_EVENTS & events(pattern.vecEvents("Analog_out"));

  // attach event to the pattern and download
  events.insert(100, event_DAC_capt).setup();
}
```

## Execution test method

```
virtual void run()
{
  ARRAY_D DAC_capt;
  INT      num_samples = 4096;
  THDtype  thd_result;

  EXECUTE_TEST (1.0);

  // upload and retrieve result
  DAC_capt = GET_VALUE_RESULT("Analog_out");

  // Post-processing: Calculate the noise & distortion
  DSP_THD(DAC_capt, &thd_result, 7, 5, DB, 0);

  // Pass/Fail judgment
  TEST("Analog_out", "THD", thd_result.thd, TM::CONTINUE);
  TEST("Analog_out", "SNR", thd_result.snr, TM::CONTINUE);
  TEST("Analog_out", "SND", thd_result.snd);
}
```
