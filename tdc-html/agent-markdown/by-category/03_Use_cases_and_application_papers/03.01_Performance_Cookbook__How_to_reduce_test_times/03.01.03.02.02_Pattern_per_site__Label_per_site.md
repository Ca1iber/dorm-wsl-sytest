# Pattern per site (Label per site)

#### Subtopics

- [How to execute separate patterns per site (Label per site)](<03.01.03.02.02.01_How_to_execute_separate_patterns_per_site__Label_per_site.md>)

The label per site feature allows you to associate different sites with different start labels (patterns). In this way you can execute different tests on different sites in parallel. This can be useful, for example, for trimming tests, where every site may have to be given a different signature.

You can make use of this feature on the firmware level (see [SQSL, SQSL? - (SeQuencer Start Label)](<../../02_System_reference/02.06_Command_Reference/02.06.02.02.240_SQSL__SQSL__-__SeQuencer_Start_Label.md>) in the command reference manual) and on the test method level.

The following section [How to execute separate patterns per site (Label per site)](<../../02_System_reference/02.07_Test_Method_Reference/02.07.03.13.10_How_to_execute_separate_patterns_per_site__Label_per_site.md>) describes this feature.

## Functional changes

- Introduced in SmarTest 6.5.3
