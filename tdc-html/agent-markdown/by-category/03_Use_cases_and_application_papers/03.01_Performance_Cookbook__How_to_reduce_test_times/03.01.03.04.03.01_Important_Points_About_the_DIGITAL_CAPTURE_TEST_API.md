# Important Points About the DIGITAL_CAPTURE_TEST API

- In order for the DIGITAL_CAPTURE_TEST API (or an API that internally executes the FLUSH API) to reflect the changes that are specified by ROUTING_STATUS/ANALOG_STATUS to an analog module hardware, the sequencers in all analog modules must be halted. For more information, see the [FLUSH](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.69_FLUSH.md>) API.
- To execute a test that contains digital capturing, use the DIGITAL_CAPTURE_TEST API.

If you attempt to execute a test containing digital capturing with the EXECUTE_TEST or START_TEST API, the test cannot be done. On the other hand, if you attempt to execute a test in which digital capturing is not used with the DIGITAL_CAPTURE_TEST API, the execution always results in FAIL.

- Before starting test execution, the DIGITAL_CAPTURE_TEST API executes the [FLUSH](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.69_FLUSH.md>) API internally to reflect the changes specified by the following APIs to the hardware of setup data:

  - ANALOG
  - ANALOG_STATUS
  - PRIMARY_STATUS
  - TIMING_SPEC / LEVEL_SPEC / SPECIFICATION
  - ROUTING_STATUS

- This API does not wait until the AWG finishes the output. If an infinite loop sequence (LOOPI or RPTI) is used for AWG, you can use the ABORT_TEST API to stop the infinite loop of the AWG.
- This API does not wait until the Digitizers/Samplers and TIAs finish the measurement. If you want to wait for them, use the WAIT_TEST_DONE API after this API as shown below:

```
              :
    DIGITAL_CAPTURE_TEST();
    WAIT_TEST_DONE(timeout);
               :
```

- The NB_DIGITAL_CAPTURE_START API waits until the digital sequencer has completed before returning, while the NB_DIGITAL_CAPTURE_START(); and NB_DIGITAL_CAPTURE_END(timeout); do not. For details, see [NB_DIGITAL_CAPTURE_START](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.135_NB_DIGITAL_CAPTURE_START.md>) and [NB_DIGITAL_CAPTURE_END](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.134_NB_DIGITAL_CAPTURE_END.md>).
