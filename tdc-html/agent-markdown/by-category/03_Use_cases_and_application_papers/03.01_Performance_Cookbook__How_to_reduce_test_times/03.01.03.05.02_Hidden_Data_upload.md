# Hidden Data upload

SmarTest has the following hidden upload features which can considerably save test time.

1. Hidden Digital Upload

The hidden digital upload feature (available from release 6.5.1 on), allows you to use test methods to set up a test flow to perform a digital capture test and then upload all the results at the end, which can save a lot of time, depending on your test.

This feature is particularly useful when using SmartCalc as it is integrated into SmartCalc. Note, however, that SmartCalc requires UTM (Universal Test Method).

For more details on this see [Using Hidden Upload for Digital Capture](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.01.02.07.04_Using_Hidden_Upload_for_Digital_Capture.md>) in the SmarTest and Key Workflows manual.

2. Hidden Upload of Analog Data

Similar to the hidden digital upload, the hidden analog upload (available from release 6.5.3 on) allows the upload of data from one unit while another unit is still being tested.

Hidden analog upload also enables hidden upload of RF measurements.

3. Hidden Upload of Error Map

This feature (available from release 6.5.2 on), allows you to upload error map data during any digital test run behind a functional test which runs concurrently.

For more detail. see [Hidden Error Map Upload](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.08.05_Hidden_Error_Map_Upload.md>) in the Setup and Results Tools manual (A-R).
