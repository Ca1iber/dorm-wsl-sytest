# Burst upload

Burst upload allows to combine multiple waveforms into one single upload (burst) to reduce upload times.

 Note Burst upload cannot be used together with SmartCalc for analog cards in IQ core function.

When capturing multiple, consecutive waveforms usually each waveform is uploaded separately. This costs at least the time for issuing the appropriate firmware command as well as establishing the link between system controller and tester. Burst upload saves time because multiple waveforms are combined into one array, thus reducing overhead. In addition, the upload speed increases with bigger waveforms.

With burst upload the smaller waveforms become an element in a single array. This results in a large waveform being uploaded.

In order to work with the individual waveforms they can be addressed by their index within the array.

## Example

The following example shows how three consecutive waveforms (NumberOfWaveforms) starting from waveform 1 (MeasurementId) are assembled into an array (burstData) for burst upload. It also illustrates how to work with the index of the array to access the small waveforms for further computation of the results.

```
void run ()
{
   ...
   double measuredPower;
   int    NumberOfWaveforms = 3;
   int    MeasurementId = 1;
   vector<ARRAY_COMPLEX> burstData;
   int site = CURRENT_SITE_NUMBER();

   ARRAY_D measParams = MEAS_DEF("myMeas").getParameters();

   // upload 3 consecutive waveforms into one array
   MEAS_DEF("myMeas").getComplexWaveform(MeasurementId, &burstData, NumberOfWaveforms);

   // work with the small waveforms
   for (int i = 0; i < NumberOfWaveforms; ++i)
   {
      ARRAY_COMPLEX &waveform = burstData[i];
      DSP_RF_CW_POWER(waveform, measParams, site, &measuredPower);
      TEST("dgtz_pin", "Power", measuredPower);
   }
   ...
}

```

The following example shows how to implement burst upload with the two LF cores of one MEAS unit of an analog instrument.

```
void run ()
{
   ...
   int    NumberOfWaveforms = 2;
   int    MeasurementId = 1;
   vector<ARRAY_D> burstData;

   // upload 2 consecutive waveforms into one array
   Analog.DGT("myDigPin").getWaveform(MeasurementId , &burstData, NumberOfWaveforms);

   // work with the small waveforms
   ARRAY_D &waveform_core1 = burstData[0];
   ARRAY_D &waveform_core2 = burstData[1];

      // do processing and judgment
   ...
}
```

Note If a sequencer program uses different LF cores (refer to the sequencer_program_12 example of the above mentioned section), separating the burst has to be done manually. Above example can be adapted accordingly.

The following example bursts the captured data of DGTPin (from 1 to NumberOfWaveforms), which is stored in the handle area of the HW memory into the burstWaveforms vector.

```
void SMC_backgroundProcessing(string DGTPin, string handle, INT NumberOfWaveforms)
{
   // hidden upload of one vector (burst upload) containing multiple waveforms
   vector<ARRAY_D> burstWaveforms= SMC_GET_WAVEFORM(DGTPin, handle, 1, NumberOfWaveforms);

   // extract the single waveforms form the burst and do some processing in the background
   for(INT currentWaveform=0; currentWaveform < NumberOfWaveforms;++currentWaveform)
   {
      ARRAY_D &singleWaveform = burstWaveforms[currentWaveform];
      // Processing...
   }
}
```
