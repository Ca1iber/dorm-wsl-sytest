# Reduce capture time

When measuring a device, you should aim to reduce the capture time and the number of samples as much as possible.

In order to reduce the capture time, and hence tester overhead during capture tests, arrange the measurements so that you can execute and collect a whole range of capture tests with a minimum of setup changes in a minimum number of samples, at best in just a single sample.

This makes post-processing and data extraction faster, and by using hidden calculation and hidden upload, you can achieve further time savings.
