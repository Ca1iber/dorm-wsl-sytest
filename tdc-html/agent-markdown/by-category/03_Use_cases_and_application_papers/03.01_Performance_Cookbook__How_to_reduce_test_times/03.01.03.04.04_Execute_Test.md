# Execute Test

This test contains a FLUSH which automatically activates any hardware changes, so no additional FLUSH is required when using the EXECUTE_TEST test method API. Additional use of FLUSH wasts test time.

For digital tests, use the DIGITAL_CAPTURE_TEST test method API rather than EXECUTE_TEST (see the section [Digital Capture Test](<03.01.03.04.03_Digital_Capture_Test.md>)).
