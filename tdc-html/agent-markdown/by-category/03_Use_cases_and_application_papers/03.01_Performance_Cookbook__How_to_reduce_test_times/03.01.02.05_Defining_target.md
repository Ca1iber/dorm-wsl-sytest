# Defining target

One main target of throughput performance optimization is to reduce the cost of test. One approach of reducing the cost of test is to reduce the test time without compromizing the result repeatability and reproducibility.It is mandatory to keep this in mind while reading the next topics. Following best practices and leveraging the experience of expert will help you to take advantage of the strengths of the V93000 Platform.

Some typical target setting statements:

- Reducing the test time by twenty percent.
- We started by 10 sec and reached 6 sec.
