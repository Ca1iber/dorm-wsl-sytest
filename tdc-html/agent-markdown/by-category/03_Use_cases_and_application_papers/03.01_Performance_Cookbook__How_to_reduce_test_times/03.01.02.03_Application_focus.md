# Application focus

The performance potential of a test program depends on the application area. It s likely that an analog dominant testflow will be approached and analyzed differently than a digital or PMIC dominant testflow. This performance cookbook will focus on production and engineering test programs for Digital, Analog, PMIC, RF or combinations of those in form of SIP or SOC.
