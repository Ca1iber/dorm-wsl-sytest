# Installing third-party plug-ins for a single user

## About this task

CAUTION Do not upgrade any supported SmarTest plug-in or Eclipse plug-in. Failure to comply could result in an unstable or disabled SmarTest installation. When installing third-party plug-ins, you must install plug-in versions that are compatible with SmarTest based on the current Eclipse (3.7.2 Indigo) and CDT plug-in (8.0.2) versions.

This task describes how to install third-party plug-ins in a user dependent directory. Thus, the installation will affect only a single SmarTest installation and not other users. Using this task you can check the features without affecting other users. This kind of installation is also referred to as Per User Administration.

A plug-in consists of one java file (file extension *.jar) or a directory. A feature can consist of multiple plug-ins. File locations:

- The plug-in file, which is always present is located in .../eclipse/plugins
- The features file, which is not always present. If this file is present, then it is located in .../eclipse/features

You must install the plug-ins via update site.

## Before you begin

Either the system controller needs access to an internet based update site or you store the plug-in files locally.

Note If you use an internet based update site, you may need to configure the network connection, like a proxy server (Window > Preferences > General > Network Connections). For details on your network configuration, refer to you network administrator.

Add an update site:

- On the menu click Window > Preferences.
- On the Preferences window click Install/Update > Available Software Sites.
- On the right window pane click Add.
- Type a name.
- Type the location:

  - Type the internet address.
  - Click Local an browse to the local directory or type the file path.
  - If the locally stored plug-in is packed as jar or zip file click Archive and browse to the archive file.

## Procedure

-  In the SmarTest Work Center, choose Help > Install New Software.  ![Install window](<../../../../raw/118320.png>)
-  The Install window opens. The Available Software page is displayed. On this page:

  -  Add new site, if necessary, and select the site in the site drop down list.

All the features in this site is show in the central feature list.

As new site you can configure an internet based site or to a local directory, see above the Before you begin section.

  -  Select the features you need to install by selecting the checkbox before the feature name.
  -  Click Next.

-  The Install Details page of the Install window opens. Click Next.
-  Select I accept the terms of the license agreements option to confirm your agreement about license.
-  Click Finish.

If the feature is not digitally signed, a warning window opens. Make sure the source of the feature is trustworthy.

-  A message window appears, which tells you that you need to restart SmarTest. Click Yes.
-  Start SmarTest again. The plug-in will now be installed automatically.

## Results

The new plug-in is installed.
