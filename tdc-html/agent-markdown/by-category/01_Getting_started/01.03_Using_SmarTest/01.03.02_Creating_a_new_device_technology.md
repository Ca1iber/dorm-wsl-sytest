# Creating a new device technology

Device technology defaults are used as default values when you create a new setup file, see the topic [Device Technology Defaults](<../01.01_SmarTest_Work_Center/01.01.07.02.01_Device_Technology_Defaults.md>).

To create a new device technology:

- Copy either the cmos or ecl directory structure from /opt/hp93000/soc/dev_tech to a new location.
- Edit all relevant default files in the necessary directories.

For example, to change the default ECL levels:

  - Change to the levels directory in the newly created device technology directory.
  - Open the file new for editing.
  - Change the drive and receive levels ([DRLV](<../../02_System_reference/02.06_Command_Reference/02.06.02.02.89_DRLV__DRLV__-__DRive_LeVel.md>) and [RCLV](<../../02_System_reference/02.06_Command_Reference/02.06.02.02.204_RCLV__RCLV__-__ReCeive_LeVel.md>)) to the levels you require (values are in mV).
  - Save the changes.

- Next time you create a device, enter the new device technology name in the appropriate box.

See the [Command Reference](<../../02_System_reference/02.06_Command_Reference/02.06_Command_Reference.md>) manual for details on the firmware commands.
