# Installing third-party plug-ins for all users

## About this task

CAUTION Do not upgrade any supported SmarTest plug-in or Eclipse plug-in. Failure to comply could result in an unstable or disabled SmarTest installation. When installing third-party plug-ins, you must install plug-in versions that are compatible with SmarTest based on the current Eclipse (3.7.2 Indigo) and CDT plug-in (8.0.2) versions.

This task describes how to install third-party plug-ins so that all users can use them upon launch of SmarTest. This type of installation is also referred to as "single-point administration".

A plug-in consists of one Java file (file extension *.jar) or a directory. A feature can consist of multiple plug-ins.

File locations:

- Plug-in file (mandatory) is located in: .../eclipse/plugins.
- Features file (optional), when present, is located in: .../eclipse/features.

Plug-in installation location options:

- Predefined directories
- Custom directories
- Custom directories used to share the plug-ins with multiple SmarTest revisions

Choose one option and perform the related steps.

## Procedures

### Installing in the predefined directories

- Before starting SmarTest for the first time, log in as root and open a terminal window.
- Before installing any new plug-ins, delete the file: ~/.eclipse/com.verigy.itee.ui.ewcProduct_<SmarTestT_version> .
- Copy the feature and plug-in files to the following predefined directories:

/opt/hp93000/soc_<smartest revision>/eclipse/custom/eclipse/features

/opt/hp93000/soc_<smartest revision>/eclipse/custom/eclipse/plugins

- Make sure that normal users do not have write access to the plug-in and feature directories to avoid unwanted changes.

### Installing in custom directories

- Log in as root and open a terminal window.
- Create new plug-in and features file directory at:

/opt/hp93000/soc_<smartest revision>/eclipse

For example:

/opt/hp93000/soc_6.2.0/eclipse/eclipseRE/custom_1/eclipse/features/org.example_1.0.0.jar

- Place the plug-in and features files in the custom directory that you have created in the previous step.
- Create a file containing a path statement specifying the final destination in the following directory:

/opt/hp93000/soc_<smartest revision>/eclipse/eclipseRE/links/<Destination specification file name>

Location example:

 /opt/hp93000/soc_6.2.0/eclipse/eclipseRE/links/custom_1

The destination specification is as follows:

path=<extension location directory>

For example:

 path=/opt/hp93000/soc_6.2.0/eclipse/eclipseRE/custom_1

- Make sure that normal users do not have write access to the plug-in and feature directories to avoid unwanted changes.

### Installing in custom directories to share the plug-ins across SmarTest revisions

- Log in as root and open a terminal window.
- Create new plug-in and features file directory in any directory other than the default directory:

/opt/hp93000/soc_<smartest revision>

For example:

/opt/extensions/eclipse_3.2.1/custom_shared

- Place the plug-in and features files in the custom directory that you have created in the previous step.
- Create a file containing a path statement specifying the final destination in the following directory:

/opt/hp93000/soc_<smartest revision>/eclipse/eclipseRE/links/<Destination specification file name>

Location example:

 /opt/hp93000/soc_6.2.0/eclipse/eclipseRE/links/custom_shared

The destination specification is as follows:

path=<extension location directory>

For example:

 path=/opt/extensions/eclipse_3.2.1/custom_share

- Make sure that normal users do not have write access to the plug-in and feature directories to avoid unwanted changes.

## Results

The new plug-in is installed and will be available for all users when they start SmarTest for the next time.
