# Reverting to a previous configuration

## About this task

This task describes how to revert to a previous SmarTest plug-in configuration if you have problems with the current one. If your SmarTest installation is not running stably and you have installed some third-party plug-ins, use this procedure to check whether the third-party plug-ins cause the instabilities by switching them off.

## Before you begin

The SmarTest software must be running.

## Procedure

-  In the SmarTest Work Center, choose Help > About SmarTest Work Center.

The following window opens.

  ![1](<../../../../raw/118315.png>)
-  In the above window, click the Installation Details button, the SmarTest Work Center Installation Details window opens.   ![Installation History tab](<../../../../raw/118319.png>)
-  On the Installation History tab of the above window, in the Previous configurations list, select one configuration you want to revert. Then click Revert.
-  A confirmation window opens. Click Yes.
-  Start SmarTest again. SmarTest will now be started with the previous configuration.

## Results

SmarTest is running with a previous configuration.
