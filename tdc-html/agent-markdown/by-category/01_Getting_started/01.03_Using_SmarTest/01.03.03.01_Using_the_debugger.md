# Using the debugger

#### Subtopics

- [Debugging test methods: Finding and moving to information](<01.03.03.01.01_Debugging_test_methods__Finding_and_moving_to_information.md>)
- [Debugging patterns efficiently](<01.03.03.01.02_Debugging_patterns_efficiently.md>)

This topic describes in three step how to use the debugger efficiently.

## Procedure

-  Launch the debugger

  -  Click Window > Open Perspective > Debug.

The Debug perspective opens.

  -  In the Debug perspective, click the button Start Test Method Debug ![Start Test Method Debug](<../../../../raw/113592.png>). The test method debugger will be opened.

-  Run the testflow:

  - Press Ctrl+F11.
  - Click ![Run Configurations_Run button](<../../../../raw/130468.png>)   ![Execute testflows](<../../../../raw/130467.png>)

-  Analyze your results:

Step through C++ code by standard debugger navigation.

  ![Debug view for testflow execution](<../../../../raw/125021.png>)
