One of the major concepts of the Eclipse based SmarTest software is the plug-in concept. When you start up SmarTest, you are not starting up a single Java program. You are activating a platform runtime which can dynamically discover registered plug-ins and start them as needed. For more information about the Eclipse plug-in concept refer to the Eclipse help.

You can extend SmarTest by installing additional plug-ins, which you have created or are coming from other vendors. These plug-ins are referred to as third-party plug-ins.

 Note For information on support for third-party plug-ins, see [Support for third-party plug-ins](<01.03.08.06_Support_for_third-party_plug-ins.md>).

## Basic rules for third-party plug-ins

CAUTION Do not upgrade any supported SmarTest plug-in or Eclipse plug-in. Failure to comply could result in an unstable or disabled SmarTest installation. When installing third-party plug-ins, you must install plug-in versions that are compatible with SmarTest based on the current Eclipse (3.7.2 Indigo) and CDT plug-in (8.0.2) versions.

- For a list of all supported SmarTest plug-ins, see the file /opt/hp93000/soc/eclipse/SUPPORTED_PLUGINS.txt.
- In the Error Log view there is a plug-in column. This column indicates the plug-in that caused the error. If an error is caused by a third-party plug-in, contact the vendor of that plug-in for assistance. If you are not able to solve the issue, disable all third-party plug-ins as described in [Reverting to a previous configuration](<01.03.08.04_Reverting_to_a_previous_configuration.md>). If the issue then still exists, call the Verigy support.
