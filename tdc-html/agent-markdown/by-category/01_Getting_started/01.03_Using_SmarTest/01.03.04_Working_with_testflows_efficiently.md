# Working with testflows efficiently

This topic gives tips on how to use SmarTest when working with testflows, like loading, editing, and running them or switch easily to set up details for editing tasks.

## Loading testflows and device setups

- On the Test Program Explorer right-click <Testflow...> and choose Load to select the testflow. ![Load testflow (2)](<../../../../raw/91661.png>)
- Load the device setup:

  - On executing the testflow, SmarTest loads the data automatically
  - On the [Test Program Explorer](<../01.01_SmarTest_Work_Center/01.01.07.02.02_Test_Program_Explorer.md>) right-click the testflow and choose Load all setups
  - On the [Setups page](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.01.07_Setups_page.md>) load dedicated setups and initialize (parse) [The pattern master file](<../../02_System_reference/02.06_Command_Reference/02.06.07.01.05_The_pattern_master_file.md>): ![Load setup, initialize Pattern master file](<../../../../raw/130457.png>)

When executing single test suites SmarTest dynamically loads the missing labels.

## Navigating in testflows and to set up details

On the [Test Suites page](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.01.01_Test_Suites_page.md>) use the arrow keys to navigate between the cells:

 ![Moving around on the Test Suites page](<../../../../raw/130462.png>)

Use the function key F3 to navigate to then next level of setup definition:

- On the [Test Suites page](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.01.01_Test_Suites_page.md>)
 ![Open related setup data](<../../../../raw/130461.png>)

- On the [Properties view](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.04_Testflow_Properties_view.md>)
 ![Open property related editor](<../../../../raw/130460.png>)

## Editing details

- To open the cell editor on the [Test Suites page](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.01.01_Test_Suites_page.md>) (or any other table based editor):

  - Select the cell and press the SPACE key
  - Double click the cell.

- To leave the cell without changing its content press the Esc key.

After activating a cell:

- The light bulb icon indicates that the [content assist](<../../02_System_reference/02.07_Test_Method_Reference/02.07.02.02.02.01_Working_with_Content_Assist.md>) is available.

Press Ctrl+SPACE or start typing the first characters and press Ctrl+SPACE to open the completion list

- Clicking the ... (triple dot) button respectively the ![Navigator view - menu button](<../../../../raw/91711.png>) (triangle) button at the end of the cell opens a select window respectively a completion list ![Content Assist, completion list](<../../../../raw/130463.png>)

## Running (executing) testflows and run configurations

- Execute a full testflow or selected suites or groups from the [Flow Sequence Editor](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.03.02_Flow_Sequence_Editor.md>): ![Execute testflow from the flow sequence editor](<../../../../raw/130465.png>)
- The function Run Configurations (on the menu Run > Run Configurations or use the Run sub-menu on the toolbar) lets you execute a testflow or selected test suites, even if the testflow editor is not visible. ![Run Configurations from menu or toolbar](<../../../../raw/130464.png>)
- [Modify existing selections or create new run configurations](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.03_Running_a_testflow.md>) and use different ways to (re-)execute them: ![Execute testflows](<../../../../raw/130467.png>)
- SmarTest memorizes the last executed run configuration.

To run it, what ever view or editor is currently activated:

  - Click the Run button: ![Run Configurations_Run button](<../../../../raw/130468.png>)
  - Press Ctrl+F11
