# 2. Create a Test Method Class

## Procedure

-  To create a new Test Method Class, right-click the project Utmmethod and select New > Test Method Class from the shortcut menu.
-  In the Create a new Test Method class wizard, type in the class name PspecSearch in the Class Name area.
