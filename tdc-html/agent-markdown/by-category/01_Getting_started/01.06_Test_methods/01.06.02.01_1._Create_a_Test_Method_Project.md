# 1. Create a Test Method Project

To create a Test Method project, you need to open the C/C++ perspective first.

## Procedure

-  To open the C++ perspective, click Open Perspective and select C/C++.  ![Open C/C++ Perspective](<../../../../raw/109211.png>)
-  In the C++ perspective, right-click in the Project Explorer and select New > Test Method Project from the shortcut menu.  ![Create a C++ project](<../../../../raw/109212.png>)
-  Click Finish to use the default project name and default location of the project. The default project name is act299_tml.   ![New Test Method Project wizard](<../../../../raw/109213.png>)
