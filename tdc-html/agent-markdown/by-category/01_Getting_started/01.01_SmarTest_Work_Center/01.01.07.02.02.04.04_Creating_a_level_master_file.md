# Creating a level master file

You can use the same creation procedure to create a master file for timing or for level setup.

## About this task

This task is about how to create a master file for a level setup based on an existing level setup. The reference level setup file levels contains two equation sets: Equation set 1 and Equation set 2.

## Before you begin

Ensure that you have a device in place, load the pin configuration and the level setup file.

## Procedure

-  If not already loaded, Load the level setup file from the Test Program Explorer as shown below.  ![Load level setup file](<../../../../raw/141712.png>)
-  Save the level setup file as file.mfh i.e levels.mfh as illustrated below.  ![Save level setup file as mfh](<../../../../raw/141713.png>)
-  Navigate to the levels subdirectory of your device directory and verify that the following files are created.

  - changelog.txt: contains information about conflicts that come up during the assembling of complex setups.
  - eqnset_01.lev: regular SmarTest level file containing only equation set 1.
  - eqnset_02.lev: regular SmarTest level file containing only equation set 2.
  - levels: regular SmarTest level file containing the complete level setup.
  - levels.mfh: level master file.

## Results

As a result, you have created a levels master file levels.mfh that references the eqnset_01.lev and eqnset_02.lev. See also [Using the Setup Management Tool from the Test Program Explorer](<01.01.07.02.02.04.02_Using_the_Setup_Management_Tool_from_the_Test_Program_Explorer.md>).

## What to do next

Load the level master file levels.mfh or continue to create further setup files.
