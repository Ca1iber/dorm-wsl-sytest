# Utility Line view

The Utility Line View is part of the [Hardware Perspective](<01.01.07.05_Hardware_Perspective.md>) and provides an interface for querying utility line read and write states and setting utility line write states when you are debugging your test setup.

[Utility lines](<../../02_System_reference/02.03_DUT_board_design_reference/02.03.04_Utility_lines.md>) are provided on the V93000 test head to control external devices such as relays and indicators or to read from external devices.

The Utility Line view enables you to monitor or control all utility lines, including those that are not defined in the pin configuration. (Defining utility line names or utility purposes in the pin configuration is required when you control the write states of the utility lines using the routing sets created in the Routing Setup Tool.)

The following screen shot shows the Utility Line view for 32 utility lines per pogo block.

    ![Utility Line View SmarTest 7.10.x](<../../../../raw/354721.png>)

The left column of the Utility Line view represents the utility pogo blocks. For the first eight utility pogo blocks, the displayed identifier is a combination of the legacy "UTI#" and the new three digit pogo block number. The screen shot above also shows eight more pogo blocks of a second [optional Utility Card](<../../02_System_reference/02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>).

For more information, refer to [DUT interface layout](<../../02_System_reference/02.03_DUT_board_design_reference/02.03.03.01_DUT_interface_layout.md>) and to section [Utility pogo block mapping](<../../02_System_reference/02.03_DUT_board_design_reference/02.03.06.08.02_Utility_pogo_block_-_Utility_Card__V93000_EXA_Scale_systems.md#_347642__s_Utility_pogo_block_mapping>) in [Utility pogo block - Utility Card (V93000 EXA Scale systems)](<../../02_System_reference/02.03_DUT_board_design_reference/02.03.06.08.02_Utility_pogo_block_-_Utility_Card__V93000_EXA_Scale_systems.md>).

  Note In the header row of the Utility Line view, SmarTest shows the channel numbers of the utility lines, using the range [01 …nbsp;32] from right to left. The utility line itself are numbered with an offset of -1 in the range [00 …nbsp;31] that corresponds to the scheme "URW##" of the "Utility pogo pin layouts" in the "DUT Board Design Guidelines". For detailed description about utility pogo blocks, see [Utility line assignments](<../../02_System_reference/02.03_DUT_board_design_reference/02.03.04.01_Utility_line_assignments.md>).

## Icons in the Utility Line view

There are three icons at the top of the Utility Line view.

 ![Utility Line View icons](<../../../../raw/70662.jpg>)

- Clicking the Setup Preferences icon opens a preference window with the same settings of the [Utility Line preference page](<01.01.14.31_Utility_Line_preference_page.md>).
- Clicking the Refresh icon performs a manual refresh of the Utility Line View.
- The center icon is used for applying write changes to all utility blocks.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.3: In the Utility Line View, the utility lines are shown with bit numbers 01 to 16.
- SmarTest 7.2.0: Utility Purpose view introduced
- SmarTest 7.10.1: Three-digit utility pogo block designator on EXA Scale systems.
