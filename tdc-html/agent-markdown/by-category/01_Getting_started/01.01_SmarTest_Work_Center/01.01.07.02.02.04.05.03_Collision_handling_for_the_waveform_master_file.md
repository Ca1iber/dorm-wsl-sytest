# Collision handling for the waveform master file

The collision that may happen in waveform master file is the label name collision of sub-files.

The setup management tool can handle the collision automatically by renaming the later collision label name according to the renaming strategy.

You can also specify the new label name manually with the `REMAP` keyword.

The setup management tool support the same waveform label for different cores.

## Split strategy

When you split the loaded setup file according to the waveform master file, the `LABEL` name in the sub-setup files will follow the left column name of the master file.

For example,

```
LABEL label_1 [REMAP label_2] :      files/label_2.wav
```

`LABEL label_2` in the combination setup file will be splitted as `LABEL label_1` of files/label_2.wav.

## Example

Before assembling, the waveform master file looks like below:

```
testerfile: demo.wav
LABEL label_1 :      files/label_1.wav
LABEL label_1 :      files/label_2.wav
LABEL label_3 :      files/label_34.wav
LABELlabel_4 :      files/label_34.wav
```

After assembling, the waveform master file will be changed to:

```
testerfile: demo.wav
LABEL label_1 :      files/label_1.wav
LABEL label_1 [REMAP label_2] :      files/label_2.wav
LABEL label_3 :      files/label_34.wav
LABEL label_4 :      files/label_34.wav
```
