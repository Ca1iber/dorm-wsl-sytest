# Profiling of DC Scale cards with Hardware view

Profiling (DC profiling) allows you to measure and display current and voltage waveforms during pattern execution. The tool is also known as DC Profiler and is available in the Hardware perspective.

## About this task

Current and voltage profiling is supported for all DC Scale channels, both in [DPS mode](<../../02_System_reference/02.05_Test_Head_Cards/02.05.05.04_DPS_operating_mode_of_DC_Scale_cards.md>) and in [PMU mode](<../../02_System_reference/02.05_Test_Head_Cards/02.05.05.05_PMU_operating_mode_of_DC_Scale_cards.md>); although the behavior of the card differs slightly:

- DPS128/64 and UHC4T:

On DC Scale DPS128/64 and UHC4T cards, profiling for multiport setups does not stop when the DPS part is finished. On these cards, profiling stops when the longest running port is finished. This gives the capability to profile the supply voltages/currents during the complete execution. In case you want to reduce memory consumption, you could put DPS pins into an empty port.

On these cards you can also do profiling when the pattern contains CLEV or CTIM commands.
- DPS128:

For the [DC Scale DPS128/DPS64 cards](<../../02_System_reference/02.05_Test_Head_Cards/02.05.05.01_DC_Scale_DPS128_DPS64_cards.md>), changing the current measurement range for profiling is not supported. That is, the measureRange parameter of the [DC_PROFILING_DEFINE](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.24_DC_PROFILING_DEFINE.md>) and [DC_PROFILING_ON](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.27_DC_PROFILING_ON.md>) APIs is ignored when the measureType parameter is set to TM::CURRENT. The profiling measurements are performed in the selected clamp current range.

- XPS256:For [DC Scale XPS256 card](<../../02_System_reference/02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>), changing the voltage range or the current range during profiling is supported, and the currently active range is also taken into account for profiling. The measureRange parameter of the [DC_PROFILING_DEFINE](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.24_DC_PROFILING_DEFINE.md>) and [DC_PROFILING_ON](<../../02_System_reference/02.07_Test_Method_Reference/02.07.04.01.27_DC_PROFILING_ON.md>) APIs is therefore not required for profiling and ignored, but still has to be set to a valid XPS256 range.
Note DC profiling of the current is not supported if a pin is in [UNGANG](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.14.06.01.03_Using_the_UNGANG_connect_state_with_DC_Scale_DPS_cards.md>) mode.

## Before you begin

- Change to the Hardware perspective.
- In the Primary view of the Hardware perspective, select the primaries and the pattern.
- The DC Scale pin must be connected to the DUT.

## Procedure

-  To generate a current or voltage profile waveform, open the Hardware view of your DC Scale card.
-  Make sure the AC_Sense and AC_Force relays are closed (connection to DUT).
-  In the Hardware view, at the bottom, click Profile. The DPS Profile dialog opens.
-  Specify the profile options:

  - Measure Range (V): The expected measurement value in volt.
  - Sampling Rate (ms): The sampling period in milliseconds:

 | DC Scale card  | Condition  | Max. rate  | Min. period |
 | DPS128  | 1  |   | channels per test processor[1)](<#_136105__d2708e223>) |

100 ksps

   | 0.010 ms |
 | 2 ... 8  | 50 ksps  | 0.020 ms |
 | UHC4T  | 1  |   | channels par card  | 100 ksps  | 0.010 ms |
 | 2 ... 4  | 50 ksps  | 0.020 ms |
 | XPS256  |    | 1 Msps  | 0.001 ms |
  - Average Factor: The number of measurements per sample.
  - Current Measurement or Voltage Measurement
  - Single Measurement or Looped Measurement

-  To start the profiling click MEAS.

When the calculation is completed, the Waveform view displays the resulting waveform.

If you have selected the Looped Measurement option, the profiling is constantly repeated until you either close the DPS Profile dialog or select the Single Measurement option.

-  To close the DPS Profile dialog click DONE.

## Example

### Utility serial configuration for DC profiling

The following screen shot shows a part of the DPS128 Hardware view.

 ![Profiling in Hardware view](<../../../../raw/353618.png>)

The Profile button at the bottom is marked in red and opens the DPS Profile dialog.

  ![DPS profile with](<../../../../raw/353741.png>)

You can define the configuration of sequencer鈥慶ontrolled utility lines, which is programmed to hardware before any pattern execution.

The UTSC firmware syntax is one of the following:

- `UTSC [1-8],[RW|RD][,MASK]`
- `UTSC ([-,1-8),[RW|RD][,MASK]`

For example:

UTSC 1,RW; UTSC (2,3),RW,MASK; UTSC (5-8),RD

After the pattern finishes, SmarTest applies: UTSC ALL,OFF.

Multiple serial buses are supported. Each bus can range from 1 single utility block to up to 8 consecutive blocks.

For example:

- Single bus: 1-8. (Block 1 is master. Blocks 2-8 are slaves)
- Two buses: 2-3,5-7 (Blocks 2 and 5 are masters. Others are slaves)

If the Seq Ctrl'd Util Blocks field is empty, no sequencer control is enabled during profiling.

The content of the Seq Ctrl'd Util Blocks field is not stored/restored after closing the dialog.
