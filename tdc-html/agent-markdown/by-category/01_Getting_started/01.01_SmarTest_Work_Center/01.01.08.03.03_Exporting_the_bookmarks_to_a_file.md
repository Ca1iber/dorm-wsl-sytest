# Exporting the bookmarks to a file

You can export the bookmarks to a file for later use.

## Before you begin

You have set bookmarks to the testsuites.

## Procedure

-  In the SmarTest Work Center, choose File > export.
-  The Export Wizard opens. On Select page, choose 93000 Bookmarks from the list and then click Next.  ![Select an export destination](<../../../../raw/113763.png>)
-  The Export Bookmarks page appears. Select the bookmarks you want to export and enter the path and name of the XML file. Then click Finish.  ![Export 93000 Bookmarks to the local XML file](<../../../../raw/113764.png>)

## Results

The current bookmarks are exported to a XML file.
