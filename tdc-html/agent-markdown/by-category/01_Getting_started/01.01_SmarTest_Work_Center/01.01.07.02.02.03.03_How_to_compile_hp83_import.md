# How to compile hp83_import

This topics gives the commands on how to compile the hp83_import file.

## About this task

You can create a template C file and a make file by calling the install_cs script, which resides in the directory /opt/hp93000/soc/prod_env/lbin/, with the parameters -t PROGRAM. The binary must take the following four arguments:

- The complete path of the file to be loaded.
- The type of the file to be loaded. The possible types are:

data_set, config, level, timing, vector, pin_attribute, testfunction, shmoo, error_map, state_list, fail_memory, scan_res, timing_diagram, report, bitmap, chan_attribute, testprog, testflow, wafertyp, applicat, applicmodel, mix_sgnl, bitmap_conf, configuration, production_setting

- The file name, that is, the last component of the first parameter.
- The temporary system directory, which is unique for every session.

After coding the program, compile it by calling make depend all. Then rename it to hp83_import and place it in the appropriate directory (for possible options see [Customizable Scripts](<01.01.07.02.02.02_Customizable_Scripts.md>)).

## Procedure

-  In a terminal, type the following commands in the given sequence:

/opt/hp93000/soc/prod_env/lbin/install_cs -t PROGRAM

-  rm -rf pg_templ.c sc_templ
-  make depend
-  make
-  cp pg_templ hp83_import
