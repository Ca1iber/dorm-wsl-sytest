# When merging analog control files

When merging an analog control file, the sets already loaded are replaced with sets of the merged file that have the same set name.

Analog control sets in the merged file which did not exist in the loaded file before merging are appended.

## Functional changes

- Introduced before SmarTest 6.3.2
