# Saving and resetting a perspective

You can save a perspective as your own perspective or reset it to the default state.

## Procedures

### Save a perspective

- Right-click the perspective header and select Save As.... ![Perspective_Perspective shortcut menu](<../../../../raw/130411.png>)
- Select Window > Save Perspective As....

The Save Perspective As window opens.

- Type in a name for your perspective and click OK. ![Save the perspective](<../../../../raw/109138.png>)

### Reset a perspective

- Right-click the perspective header and select Reset. ![Perspective_Perspective shortcut menu](<../../../../raw/130411.png>)
- Select Window > Reset Perspective from the main bar.
