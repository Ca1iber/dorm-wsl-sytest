# Debug View

This view allows you to control the debugging process of a program or testflow.

If a class or function is suspended, its stack frames are shown as child elements of the program or testflow.

You can also use the corresponding debugging buttons on the main toolbar of the [Setup perspective](<01.01.07.02_Setup_perspective.md>).

## Testflow debugging

For testflow execution, SmarTest automatically displays the Debug view.
