# Utility Purpose view

The Utility Purpose view allows you to apply utility purpose, which you defined previously in the [pin configuration](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18_Pin_configuration_tool.md>).

An [Utility purpose](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18.01.05_Utility_purpose.md>) is defining some values for a subset of utility lines. After applying the utility purpose you can check the specified values in the [Utility Line view](<01.01.07.05.04_Utility_Line_view.md>). Depending on your configured preferences, you need to refresh it.

Note The Utility Purpose view sets a defined utility purpose, but it does not recognized what or if an utility purpose is set.
