# Adapting keyboard shortcuts (key bindings)

## About this task

This topic describes how to adapt keyboard shortcuts using the preferences page Keys.

Note Advantest recommends to use the default keyboard shortcuts which are documented at [Useful keyboard shortcuts](<01.01.16_Useful_keyboard_shortcuts__key_bindings.md>) (key assist) and [Keyboard shortcuts - context related](<01.01.16.01_Keyboard_shortcuts__key_bindings__-_context_related.md>).

## Procedure

-  On the menu click Window > Preferences.
-  In the Preferences window click General > Keys.  ![Preferences page Key](<../../../../raw/124342.png>)
-  Find out the target key from the key list or use the search bar by typing the key text.

For example, type Content to search for Content Assist.

-  Click on the target key and adapt the keyboard shortcut by changing the content of Binding.
-  Click Apply to apply the change.
