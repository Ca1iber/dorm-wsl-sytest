# Window menu

The Windows menu of the SmarTest Work Center contains the controls for navigation and managing views and perspectives.

  ![Window Menu](<../../../../raw/350787.png>)

Window menu items
 |

Menu

 |

Function/Tool

 |
 |

New Window

 |

Opens a window displaying the SmarTest Work Center.

[Using multiple windows](<01.01.15_Using_multiple_windows.md>)

 |
 |

New Editor

   | Opens another instance of the editor in focus. |
 |

Open Perspective

   | Provides links to the commonly used perspectives and access to the Open Perspective dialog box.

[Opening a perspective](<01.01.07.01.01_Opening_a_perspective.md>)

[Perspectives](<01.01.07_Perspectives.md>)

 |
 |

Show View

   | Provides links to the commonly used views and access to the Show View dialog box.

[Opening a view and adding it to the perspective](<01.01.07.01.03_Opening_a_view_and_adding_it_to_the_perspective.md>)

[Views](<01.01.08_Views.md>)

 |
 |

Customize Perspective

   | Displays the Customize Perspective - Setup dialog box, used to configure how the active perspective is to be displayed, for example, which toolbars to be displayed.

[Customizing toolbars and menus](<01.01.07.01.04_Customizing_toolbars_and_menus.md>)

 |
 |

Save Perspective As ...

   | Displays the Save Perspective As ... dialog box, used to assign a name to the active perspective.

[Saving and resetting a perspective](<01.01.07.01.05_Saving_and_resetting_a_perspective.md>)

 |
 |

Reset Perspective

   | Displays the Reset Perspective dialog box, used to reset the perspective to its default configuration.

[Saving and resetting a perspective](<01.01.07.01.05_Saving_and_resetting_a_perspective.md>)

 |
 |

Close Perspective

   | Closes the active perspective. |
 |

 Close All Perspectives

   | Closes all open perspectives. |
 |

Navigation

   | Provides navigation options such as:

- Displaying the Quick Access tool
- Displaying the System or View menus
- Changing the focus to the next or most recently used editor
- Opening the Switch to Editor selection dialog box
- Switching between views and perspectives
 |
 |

Preferences

 |

Opens the Preferences dialog box.

[Preferences window](<01.01.14_Preferences_window.md>)

 |

## Functional changes

- Introduced in SmarTest 7.5.4
