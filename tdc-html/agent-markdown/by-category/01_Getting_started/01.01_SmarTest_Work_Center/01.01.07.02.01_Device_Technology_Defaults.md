# Device Technology Defaults

#### Subtopics

- [Device Technology Directory](<01.01.07.02.01.01_Device_Technology_Directory.md>)
- [Technology file for a device](<01.01.07.02.01.02_Technology_file_for_a_device.md>)

The SmarTest software is supplied with default values for two device technologies, CMOS and ECL. When you create a new device, you are asked to select a device technology. This choice affects, amongst other things, the default values for the high and low levels of your input and output signals.

Default values can, of course, always be changed from within the appropriate menu screen in the SmarTest software. However, circumstances may arise where you want to use other default values instead of only CMOS or ECL (for example, if you always use different Levels).

In this case, it may be easier to create a new copy of either the CMOS or ECL device technology directory, and edit the device technology default values.

For a description of how to define new device technology defaults, see [Creating a new device technology](<../01.03_Using_SmarTest/01.03.02_Creating_a_new_device_technology.md>).
