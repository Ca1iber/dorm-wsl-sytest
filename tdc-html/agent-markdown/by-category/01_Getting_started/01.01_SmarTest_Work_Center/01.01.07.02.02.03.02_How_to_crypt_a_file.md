# How to crypt a file

This topic gives the command how to crypt a file using ccrypt based on the topic [Customized hp83_import for encrypted setup files](<01.01.07.02.02.03.01_Customized_hp83_import_for_encrypted_setup_files.md>).

## Procedure

 echo "VERIGY93K" | ccrypt -e -s -k - <filename>
