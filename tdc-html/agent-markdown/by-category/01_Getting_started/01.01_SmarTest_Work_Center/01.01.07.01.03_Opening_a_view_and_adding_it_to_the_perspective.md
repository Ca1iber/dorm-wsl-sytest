# Opening a view and adding it to the perspective

## Procedure

-  On the menu click Window > Show View > Other.

The Show View window opens and shows all available views.

-  In the filter field, type the name of the view.

When you start typing, SmarTest lists all items whose names include the already typed string.

-  Select the view in the list and click OK.  ![Select Bookmarks in the Show View window](<../../../../raw/110841.png>)  Note To remove a view from the perspective, close the view.
