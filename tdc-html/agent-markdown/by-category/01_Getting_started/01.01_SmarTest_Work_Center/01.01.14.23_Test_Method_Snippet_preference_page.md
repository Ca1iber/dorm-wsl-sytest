# Test Method Snippet preference page

This preference page can be accessed through Window > Preferences > Advantest V93000 > Test Method > Test Method Snippet.

It allows you to determine whether to use the latest system-provided test method snippet file or not. Default setting is yes.

If yes, the current linked test method snippet file will always be automatically imported into workspace to replace the previous one. And the previous snippet file will be backup in the designated directory.

If no, the current linked test method snippet file will not be imported automatically into workspace.

You can also select the directory to backup the original template.

## Functional changes

- Introduced in SmarTest 7.1.3
