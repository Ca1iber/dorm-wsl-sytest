# Loading a single setup component

Before you can load setup components, you have to take the following actions:

- [Importing a device into your workspace](<01.01.08.02.01.01_Importing_a_device_into_your_workspace.md>) and
- [Changing the device in the Project Explorer view](<01.01.08.02.01.02_Changing_the_device_in_the_Project_Explorer_view.md>)

To load a single setup component:

- In the Test Program Explorer View highlight the component you want to load, for example, the Pin Configuration as shown in the figures below. Right-click the highlighted component and select Load....  ![Load a single setup entity (1)](<../../../../raw/91727.png>)
- Select the file and click OK. You can also load a setup file that belongs to another device. The text [external] is then displayed besides the file name. ![Load a single setup entity (2)](<../../../../raw/91728.png>)
- The file name is displayed instead of the component.  ![Load a single setup entity (3)](<../../../../raw/91729.png>)  Note You can load the same setup component repeatedly, the software will not check whether the component has already been loaded. Note When you have changed but not yet saved a setup component, you can discard your changes by using the Reload menu item.
