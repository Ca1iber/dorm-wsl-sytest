# Creating a new single setup component

## About this task

This task applies when you have loaded a device and you want to change one or more setup components, for example, the levels file, pin configuration file, timing file etc.

In the example below is described, how to create a new level file.

## Procedure

-  In the Test Program Explorer View highlight the component you want to create, for example, the Levels as shown in the figures below. Right-click the highlighted component and select New.  ![Create a new single setup component](<../../../../raw/92297.png>)
-  In the New Level Setup window, enter a name for your new file and click OK.  ![Create a new single setup component (2)](<../../../../raw/92298.png>)

## Results

The file name is displayed instead of the component.

The new component (file) is created with the default settings, which are stored in a central directory (which you can also edit if you want). These settings reset the hardware to the power-up default settings, and are stored in the directory:

/opt/hp93000/soc/dev_tech/<device_technology_name>
