# Test method debugger default console

This view shows the output of the execution of your program and enables you to enter input for the program when debugging the test method. You can execute the GDB commands as the standard input when debugging a test method. (Refer to [How to debug a universal test method](<../../02_System_reference/02.07_Test_Method_Reference/02.07.02.02.04_How_to_debug_a_universal_test_method.md>).)

The test method debugger default console is displayed when you start test method debugging. If it is not displayed, click the ![Display Selected Console button](<../../../../raw/116279.png>) icon and select test method debugger default.

You can choose different colors for the text in the console from the preference dialog (Window > Preferences > Run/Debug > Console).
