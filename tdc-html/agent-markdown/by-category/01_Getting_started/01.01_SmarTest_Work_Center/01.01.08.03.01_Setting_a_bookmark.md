# Setting a bookmark

Bookmarks can be set to any test suite node in the testflow.

## Before you begin

Make sure the test suite node has been inserted.

## Procedure

-  To set a bookmark to a test suite, on the Test suites page, right-click the row of the desired test suite and select Add BookMark.
-  The Bookmarks view opens automatically and the bookmark of the selected test suite has been added to this view.
-  On the Test suites page, an annotation of the bookmark is added in front of the row of the test suite which the bookmark is set to.  ![Bookmark annotation](<../../../../raw/111817.png>)

## What to do next

You can use the bookmark to locate the relevant test suite. Double click a bookmark in the Bookmarks view, the related test suite is highlighted on the Test suites page.

After adding the bookmarks, you can save them to a file for later use.

## Related information

[Exporting the bookmarks to a file](<01.01.08.03.03_Exporting_the_bookmarks_to_a_file.md>)

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.2: Bookmarks can only be set to test suite nodes.
