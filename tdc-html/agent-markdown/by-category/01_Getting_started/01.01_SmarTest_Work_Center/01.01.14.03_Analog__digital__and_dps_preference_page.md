# Analog, digital, and dps preference page

You can change the following preferences on the Advantest V93000 > Sample Code > Analog or Digital or Dps preference page.

 |

Option

 |

Description

 |
 |

Continuously refresh with an interval delay

 |

Use this option to refresh the hardware information in the Pin Browser view continuously with a specified interval delay.

 |
 |

Refresh Delay

 |

Specify the interval delay with which the hardware information in the Pin Browser view is refreshed.

 |
