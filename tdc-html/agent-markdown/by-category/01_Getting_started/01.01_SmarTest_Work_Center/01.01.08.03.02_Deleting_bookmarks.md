# Deleting bookmarks

## Before you begin

Make sure the bookmarks you want to delete has been set.

## Procedure

-  In the Bookmarks view, select the row of the bookmark which you want to delete. To select more than one bookmarks, press Shift while clicking.
-  To delete the chosen bookmark, press delete.

## Results

The selected bookmark has been removed from the Bookmarks view.

## Functional changes

- Introduced before SmarTest 6.3.2
