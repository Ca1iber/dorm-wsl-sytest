# Console view: C-Build console

This console displays the test method building messages. It tells the success of test method building or the errors occur in the test method building.

It is displayed when you build a test method project. If it is not displayed, click the ![Display Selected Console button](<../../../../raw/116279.png>) icon and choose C-Build.

The toolbar of the console contains the following icons:

 |

Icon

 |

Function

 |
 |  ![Scroll lock button](<../../../../raw/131721.png>) |

Locks scrolling. When new messages occur, the console does not scroll down to the new messages.

 |
 |  ![Clear Log Viewer button](<../../../../raw/97205.png>) |

Clears the content of the currently opened console.

 |
 |  ![Pin console button](<../../../../raw/97212.png>) |

Forces the console to remain on top of other views.

 |
 |  ![Display Selected Console button](<../../../../raw/97213.png>) |

Selects the console to display if multiple consoles are opened.

 |
 |  ![Open Console button](<../../../../raw/97214.png>) |

Opens a new console.

 |
 |  ![Minimize button](<../../../../raw/107034.png>) |

Minimizes the console view.

 |
 |  ![Maximize button](<../../../../raw/107035.png>) |

Maximizes the console view.

 |
