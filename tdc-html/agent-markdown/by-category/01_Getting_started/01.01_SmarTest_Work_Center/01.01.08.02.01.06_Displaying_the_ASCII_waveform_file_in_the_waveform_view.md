# Displaying the ASCII waveform file in the waveform view

You can display the non-encrypted ASCII waveform file in the waveform view with a shortcut menu of Project Explorer.

## Before you begin

Make sure the ASCII file is valid waveform file and not encrypted.

## Procedure

-  In the Project Explorer
-  Right-click the ASCII waveform file and select Show In > Waveform.

## Results

The Waveform file is displayed in the waveform view.

If the waveform file is encrypted, not accessible or not formatted correctly, an error message will be popped up when you try to show the ASCII waveform file in the waveform view.

## What to do next

You can direct the waveform from the Waveform view to Signal Analyzer Tool. (See [Waveform view](<../../99_Unlisted_or_Unreferenced/99.0073_Waveform_view.md>))

## Functional changes

- Introduced in SmarTest 7.0.3
