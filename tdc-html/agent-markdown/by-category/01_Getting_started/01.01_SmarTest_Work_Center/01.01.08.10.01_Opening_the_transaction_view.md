# Opening the transaction view

## About this task

This task describes how to open the protocol transaction view.

## Before you begin

Open a protocol with the protocol editor, refer to [Opening a protocol in the protocol editor](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.22.10.01_Opening_a_protocol_in_the_protocol_editor.md>).

## Procedure

-  In the overview area of the protocol editor, right-click the protocol icon.
-  Select Show in Transactions. Note The following procedure is also valid if performed on the respective icon of transaction, pin role or field.

## Results

The transaction view opens, displaying the selected content of the protocol, transaction, pin role or field respectively.
