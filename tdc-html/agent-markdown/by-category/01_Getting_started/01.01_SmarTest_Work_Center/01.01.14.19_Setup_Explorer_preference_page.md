# Setup Explorer preference page

You can change the following preferences on the Advantest V93000 > RF > Setup Explorer preference page.

 |

Option

 |

Description

 |
 |

Measurement / Stimulus Deletion

 |

When you delete a RF definition from the RF setup tool, this option allows you to select:

- A dialog opens to confirm the deletion. You can set in this dialog to remember your choice for the Measurement / Stimulus Deletion option.
- Delete the definition and the analog set.
- Delete the definition but keep the analog set.
 |
