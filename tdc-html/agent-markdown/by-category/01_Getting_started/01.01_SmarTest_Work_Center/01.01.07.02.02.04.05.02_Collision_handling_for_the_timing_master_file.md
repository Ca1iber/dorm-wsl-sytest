# Collision handling for the timing master file

The collisions that may happen in timing master file include `EQNSET` number, `WAVETABLE` name, `MULTIPORT` name, `CLOCK_SET` number (contain related MULTIPORT) and `TESTDATA` name (DC Dynamic).

`CLOCK_SET` is not used in SmarTest 7.10, as the MCLK is fixed.

The collisions can be handled automatically by the setup management tool or manually by clearly specifying the new definitions.

When the `WAVETABLE` name collision is resolved, the `EQNSET`(spec included), `MULTIPORT`(spec included) and `CLOCK_SET`(spec included) need to be updated.

When the `EQNSET` number collision is resolved, the related `MULTIPORT`(spec included) and `CLOCK_SET`(spec included) need to be updated.

The above two kinds of Bind can be handled automatically by the tool if the relationship can be identified. If the tool cannot identify the relationships from the timing master file, you need to specify the `Bind` clearly in it. Then the collision can be resolved by the setup management tool.

## Split strategy

When you split the loaded setup file according to the timing master file, the `EQNSET` number, `WAVETABLE` name, `MULTIPORT` name, `CLOCK_SET` name and `TESTDATA` name in the sub-setup files will follow the left column number/name of the master file.

For example,

```
WAVETABLE wtbl_1[REMAP wtbl_2]: ../../rf/timing/part1.tim
```

`WAVETABLE wtbl_2` in the combination setup file will be changed to `WAVETABLE wtbl_1` of ../../rf/timing/part1.tim.

## Examples

### Automatically Bind

In this example, the timing files for usb test are in one directory and the timing files for rf test are in another directory. The collision can be handled automatically and the related parts will be updated automatically.

Before assembling, the master file is:

```
EQNSET 1: ../../usb/timing/eqnset_01.tim
EQNSET 1: ../../rf/timing/eqnset_01.tim
WAVETABLE wtbl_1: ../../usb/timing/part1.tim
WAVETABLE wtbl_1: ../../rf/timing/part1.tim
MULTIPORT_SPEC "spec_1": ../../usb/timing/spec_1.tim
MULTIPORT_SPEC "spec_1": ../../rf/timing/spec_1.tim
CLOCK_SET clset_1: ../../usb/timing/clock_1.tim
CLOCK_SET clset_1: ../../rf/timing/clock_1.tim
```

After assembling, the master file is:

```
EQNSET 1: ../../usb/timing/eqnset_01.tim
EQNSET 1[REMAP 2]: ../../rf/timing/eqnset_01.tim
WAVETABLE wtbl_1: ../../usb/timing/part1.tim
WAVETABLE wtbl_1[REMAP wtbl_2]: ../../rf/timing/part1.tim
MULTIPORT_SPEC "spec_1": ../../usb/timing/spec_1.tim
MULTIPORT_SPEC "spec_1"[REMAP "spec_2"]: ../../rf/timing/spec_1.tim
CLOCK_SET clset_1: ../../usb/timing/clock_1.tim
CLOCK_SET clset_1[Remap clset_2]: ../../rf/timing/clock_1.tim
```

### Manually Bind

In this example all the timing files are located in one directory. The setup management tool does not know which parts need to be updated after collision resolved. You need to clearly specify the Bind files before assembling.

Before assembling, the timing master file looks like below:

```
EQNSET 1: ../../ALL/timing/eqnset_01.tim
EQNSET 1: ../.. /ALL /timing/aaa.tim
       [Bind: ../../ ALL /timing/ddd.tim]

WAVETABLE wtbl_1: ../../ ALL /timing/part1.tim
WAVETABLE wtbl_1: ../../ ALL /timing/ddd.tim

MULTIPORT_SPEC "spec_1": ../../ ALL /timing/spec_1.tim
MULTIPORT_SPEC "spec_1": ../../ ALL /timing/cccc.tim
       [Bind ../../ ALL /timing/ddd.tim;
             ../../ ALL /timing/aaa.tim;]

CLOCK_SET clset_1: ../../ ALL /timing/clock_1.tim
CLOCK_SET clset_1: ../.. /ALL /timing/ffff.tim
       [Bind ../../ ALL /timing/ddd.tim;
             ../../ ALL /timing/aaa.tim;]
```

After assembling, the master file will be changed to:

```
EQNSET 1: ../../ALL/t"iming/eqnset_01.tim
EQNSET 1[REMAP 2]: ../.. /ALL /timing/aaa.tim
                           [Bind: ../../ ALL /timing/ddd.tim]

WAVETABLE wtbl_1: ../../ ALL /timing/part1.tim
WAVETABLE wtbl_1 [REMAP wtbl_2]: ../../ ALL /timing/ddd.tim

MULTIPORT_SPEC "spec_1": ../../ ALL /timing/spec_1.tim
MULTIPORT_SPEC "spec_1" [REMAP "spec_2"]: ../../ ALL /timing/cccc.tim
                           [Bind ../../ ALL /timing/ddd.tim;
                                 ../../ ALL /timing/aaa.tim;]

CLOCK_SET clset_1: ../../ ALL /timing/clock_1.tim
CLOCK_SET clset_1 [REMAP "clset_2"]: ../.. /ALL /timing/ffff.tim
                           [Bind ../../ ALL /timing/ddd.tim;
                                 ../../ ALL /timing/aaa.tim;]
```
