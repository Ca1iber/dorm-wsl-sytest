# Opening additional signals

You can display more than one signal using multiple instances of the Hardware view.

## Before you begin

You have updated the hardware information in the Pin Browser view.

In the Hardware view, Link with Editor and Selection is deselected.

## Procedure

-  Make sure that the Link with Editor and Selection is deselected.
-  In the Pin Browser view, open the shortcut menu (right-click) for the signal you want to open (P03_SIG_03 in the screenshot below).

![Opening channels in the Hardware view - select channel](<../../../../raw/353735.png>)

-   From the shortcut menu, select Show in Hardware.

A new Hardware view tab is opened displaying the hardware diagram for the selected signal.

![Opening channels in the Hardware view - open another instance of the Hardware view containing an alternative channel.](<../../../../raw/353736.png>)

## Results

You have opened a new instance of the Hardware view displaying an additional signal.

## Functional changes

- Introduced in SmarTest 7.10.0
