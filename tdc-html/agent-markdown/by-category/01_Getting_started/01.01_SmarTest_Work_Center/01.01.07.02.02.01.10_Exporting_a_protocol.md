# Exporting a protocol

## About this task

This task describes how to export a protocol definition from your current device.

## Procedure

-  Right-click the Protocols icon in the test program explorer and select Export...
-  Select one or more protocols to be exported from your current device and click Next.  ![Export protocol](<../../../../raw/126366.png>)
-  Browse to the location to which you like to export the selected protocol. Then click Next. Note The location can be either a shared repository or the /protocols directory of a different device directory.
-  Rename the to be exported protocol if needed, i.e. if the same protocol definition exist in your destination already or if you would like to give it a different name.  ![Rename protocol exported](<../../../../raw/126367.png>)  Note Protocols already existing in your destination directory are marked. Note If you do not rename existing protocol definitions they will be overwirtten!
-  Click Finish to import and load the selected protocol.

## Results

The selected protocol has been exported.
