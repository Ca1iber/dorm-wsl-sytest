# Test Program Explorer preference page

You can change the following preferences on the Advantest V93000 > General > Test Program Explorer preference page.

 |

Option

 |

Description

 |
 |

"Save All" saves all setups unconditionally

 |

When you click the Save All icon ![Test program explorer view - save button](<../../../../raw/101679.png>) on the Test Program Explorer view:

- If you enable this option, all the loaded test setup components are saved.
- If you disable this option, only the test setup components which are modified and not yet saved are stored.
 |

The following displays the Test Program Explorer preference page.

 ![Test Program Explorer preference page](<../../../../raw/118510.png>)
