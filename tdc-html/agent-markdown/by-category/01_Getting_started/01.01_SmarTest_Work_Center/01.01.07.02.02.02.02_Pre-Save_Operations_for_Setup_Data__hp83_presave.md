# Pre-Save Operations for Setup Data: hp83_presave

The script hp83_presave is automatically executed every time you save setup data, immediately before the actual save operation takes place.

The default of the script (as you find it in opt/hp93000/soc/com/lbin/hp83_presave.def) generates backup files of the existing setup files (except vector setup files, but you could modify this) before the following save operation overwrites the setup file.

You could also use the script, for example, to generate a protocol of the modifications of the setup files.
