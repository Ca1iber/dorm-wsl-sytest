# Pre- and Post-Operations When Changing the Device

To set custom pre- and post-actions for the "change device" operation, SmarTest supports the following scripts:

- hp83_pre_chdev

This script is automatically executed every time you change the device directory, immediately before the change. You can customize this script, which is empty by default. For example, you can use this script to remove unnecessary files before you exit from the current device directory.

- hp83_post_chdev

This script is automatically executed every time you change the device directory, immediately after the change. You can customize this script, which is empty by default. For example, you can use this script to re-compile and register the test programs of the new device properly.
