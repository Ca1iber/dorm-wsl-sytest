# Console view

#### Subtopics

- [Console view: System console](<01.01.08.05.01_Console_view__System_console.md>)
- [Console view: Data log console](<01.01.08.05.02_Console_view__Data_log_console.md>)
- [Console view: C-Build console](<01.01.08.05.03_Console_view__C-Build_console.md>)
- [Test method debugger default console](<01.01.08.05.04_Test_method_debugger_default_console.md>)

The console view shows the system output message, data log message, test method building message, test method debugging message and other SmarTest output messages in different consoles.

On the console view toolbar, click the drop down menu icon ![Display Selected Console button](<../../../../raw/97213.png>) to select the output of the console:

- Default outputs:

  - [Datalog](<01.01.08.05.02_Console_view__Data_log_console.md>)
  - [System](<01.01.08.05.01_Console_view__System_console.md>)

- When working with test methods:

  - [C-Build](<01.01.08.05.03_Console_view__C-Build_console.md>)
  - [Test method debugger default](<01.01.08.05.04_Test_method_debugger_default_console.md>)

 Note Click the ![icon - console](<../../../../raw/107053.png>) icon to toggle between the two most recently used outputs.

## Functional changes

- Introduced before SmarTest 6.3.2
