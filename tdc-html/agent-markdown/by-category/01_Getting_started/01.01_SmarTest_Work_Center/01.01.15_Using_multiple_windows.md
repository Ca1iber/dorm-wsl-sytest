# Using multiple windows

If you run SmarTest on a dual screen setup, you can create multiple Eclipse windows. Each window can show a different perspective. The layout of multiple windows is kept when you exit SmarTest.

## Procedure

-  To create a new Eclipse window, select Window > New Window. A new window is created showing the current perspective you are using.  ![Open a new window](<../../../../raw/109150.png>)
-  In the new window, open the perspective that you want to use.  ![Open a perspective in the new window](<../../../../raw/109151.png>)
-  If you are using dual screen setup, you can move a window to another screen and see the two Eclipse windows at the same time.

## Functional changes

- Introduced before SmarTest 6.3.2
