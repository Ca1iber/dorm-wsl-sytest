# Test Suites preference page

You can change the following preferences on the Advantest V93000 > Testflow Tool > Test Suites preference page.

 |

Option

 |

Description

 |
 |

Enable alternate coloring for rows

 |

Controls whether to show the background of the rows in the Flow Data Editor in two colors, white and gray.

 |
 |

Automatic Validate Setups

 |

Check this option, the setup file which has not been loaded and the primary set which does not exist will be highlighted in yellow on the Test suites page and the Properties view.

 |
 |

Table Sort Mode in Test Suites ~ Flags Page

 |

Specify whether the data on Test Suites page to Flags page are sorted either on single column or on multiple columns.

 |
 |

Test Name Edit Mode

 |

Specify what happens when you select a different test method in one of the [linked test suites](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.32.02.01.11.06_Cloning_nodes.md#_20244__p_Clones_of_test_suite_nodes>) in a testflow.

- (default) Always Ask: A window opens to ask whether you change the test method only in this test suite or in all the linked test suites.
- Apply to One: The test method is changed only in the test suite where you edited it, without confirmation.
- Apply to All: The test method is changed in all the linked test suites.
 |
 |

Test Suite Show

 |

Specify which types of test suites are displayed on the Test suites page.

- All: All types of test suites are shown.
- Only Floating: Only floating test suites are shown.
- Only Special: Only special test suites are shown.
 |
 |

Execution Result

 |

Specify the results of either all the sites or the site in focus are to be shown.

 |
 |

Visible Columns

 |

Specify the columns which are displayed in the Test Suite page.

 |
