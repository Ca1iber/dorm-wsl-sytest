# Keyboard shortcuts (key bindings) - context related

These keyboard shortcuts reflect the default SmarTest configuration as it is shipped. Because users can change shortcuts, the default shortcuts may be different from the shortcuts on a user configured system.

- For general keyboard shortcuts (key assist: Ctrl+Shift+L), see [Useful keyboard shortcuts](<01.01.16_Useful_keyboard_shortcuts__key_bindings.md>).
- To change keyboard shortcuts on the Key preferences page, see [Adapting keyboard shortcuts (key bindings)](<01.01.16.02_Adapting_keyboard_shortcuts__key_bindings.md>).
