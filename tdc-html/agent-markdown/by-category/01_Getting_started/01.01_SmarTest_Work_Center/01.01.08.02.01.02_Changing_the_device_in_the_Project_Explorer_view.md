# Changing the device in the Project Explorer view

Your workspace can contain one or more devices but only one device can be the active device at a time. Changing the device means that another device will be activated.

## Before you begin

Make sure that the device project has been imported to your workspace as described in [Importing a device into your workspace](<01.01.08.02.01.01_Importing_a_device_into_your_workspace.md>).

## Procedure

-  To activate a certain device, in the Project Explorer view, highlight the device you want to activate
-  Right-click and select 93000 > Change Device.

## Results

After activating the selected device, the system checks if all the referenced projects of the device project exist in the workspace. If not, the Warning window appears to inform the users, that the required projects should be imported.

 ![Warning window](<../../../../raw/113618.png>)

In the Project Explorer view, the activated device is tagged with the text "(current device)".
