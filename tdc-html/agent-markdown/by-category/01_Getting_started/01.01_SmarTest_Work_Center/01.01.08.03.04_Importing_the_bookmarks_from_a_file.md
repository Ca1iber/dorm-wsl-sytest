# Importing the bookmarks from a file

You can import the bookmarks from a XML file.

## Before you begin

Make sure that the XML file including the bookmarks information exists.

## Procedure

-  In the SmarTest Work Center, choose File > export.
-  The Import Wizard opens. On the Select page, choose 93000 Bookmarks from the list and then click Next.  ![Select an import source](<../../../../raw/113766.png>)
-  The Import Bookmarks page opens.

  -  Enter the path and name of the XML file, the bookmarks in this file are shown as a list on the left.
  -  Select the bookmarks you want to import and the target which the bookmarks are imported to (in the following figure, the testflow file is selected).
  -  Click Next.  ![Import 93000 Bookmarks from the local XML file](<../../../../raw/113767.png>)

-  The second Import Bookmarks page opens. The table on this page displays all the bookmarks in the imported XML file. You should select the bookmarks you want to import from them. Then click Finish.  ![Select valid bookmarks to import](<../../../../raw/113768.png>)

## Results

The imported bookmarks are shown in the Bookmarks view.
