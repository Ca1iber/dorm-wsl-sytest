# Defining the pins

Define the relationship between resource pins and DUT board using the [Pin configuration tool](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18_Pin_configuration_tool.md>).

- Define the connections between device pins to tester resources ([Digital Pins editor](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18.03.01.02_Digital_Pins_editor.md>)).

  - Defining number of sites
  - Allocating channels to the device pins
  - Specifying of the DPS operating range

- Define [pin groups](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18.02.08_Working_with_pin_groups.md>), creating utility lines, and [utility purposes](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18.02.10.01_Creating_a_utility_purpose.md>) (optional).
- [Apply pin configuration data](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18.02.05_Applying_pin_configuration_data.md>)

Instead of setting up the pin configuration manually you can import the data, see [Importing the pin configuration from a CSV file](<../../02_System_reference/02.08_Setup_and_Result_Tools/02.08.04.18.02.02_Importing_the_pin_configuration_from_a_CSV_file.md>).
