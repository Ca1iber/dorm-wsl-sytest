Working with SmarTest might require you to access some controls directly on the host workstation.

For example:

- Switch between operating systems being used for different releases of SmarTest
- Switching between versions of SmarTest
- Installing and updating SmarTest

This section provides information on working with your SmarTest workstation.

## Functional changes
