# Installing SmarTest Docker images

Advantest provides an easy way to deploy and run SmarTest with Advantest container images. The container contains the SmarTest components that can be run on a workstation without the need to physically install SmarTest on the workstation itself.

## About this task

Typically, images are stored in a Docker/container registry in your local environment. Advantest supplies the images in the  tar.gz format, which can be downloaded directly from the Software Center. You can import these images directly into your registry.

This procedure describes how to download and import the SmarTest container image into a local Docker environment. Tagging and pushing to your registry can be specific to your company. If you need information about your Docker environment, check with your IT department.

## Before you begin

 Make sure the following prerequisites are met:

- The workstation operating system is Red Hat Enterprise Linux 7.2 or higher, or the required operating system version for the SmarTest versions to be installed, whichever is higher. Older operating systems are not supported.
-

You have a [my.advantest.com](<http://my.advantest.com>) account with access to 'Software Center' and access to 'SmarTest Docker'. You can request an account at: [https://login.advantest.com/](<https://login.advantest.com/>) and ask for access to "Software Center" and "SmarTest Docker".

-

Docker engine is installed (hint: sudo yum install docker-ce docker-ce-cli containerd.io) .

- Start Docker (hint: sudo systemctl start docker).

## Procedure

-  Open the Advantest Software Center in a browser: https://softwarecenter.advantest.com/
-  Login with your credentials.

The Software Center home page is displayed.

-  SmarTest container packages are located under SmarTest Docker.

![Advantest Software Center home page](<../../../../raw/354144.png>)

-  To view the available container packages, select a folder:

For example, smt-released > SmarTestSuite > 8.4.3, to display all the available containers for the released SmarTest 8.4.3. version.

 Note Dedicated docker images are configured for FNE or FNP licensing. Select the appropriate version for your licensing infrastructure.

![Advantest Software Center home page](<../../../../raw/354146.png>)

-  Click on a package to start the download.
-  Download the checksum file matching the selected package.
-  Check that the checksum is correct with the command:

sha256sum -c docker-[...].sha256

For example:

sha256sum -c docker-advantest-smartest-suite-8.4.3.0-pdb422-rh7.4-2021.05-447.tar.gz.sha256

A successful check returns the following type of result:

```
docker-advantest-smartest-suite-8.4.3.0-pdb422-rh7.4-2021.05-447.tar.gz: OK
```

-  Import the image into your local docker with the command:

sudo docker load < docker-advantest[鈥.tar.gz

For example:

sudo docker load < docker-advantest-smartest-suite-8.4.3.0-pdb422-rh7.4-2021.05-447.tar.gz

A successful load returns the following type of result:

```
Loaded image: advantest/smartest-suite:8.4.3.0
```

-  Check the imported image with the command:

sudo docker run advantest/<image name> help

For example:

sudo docker run advantest/smartest-suite:8.4.3.0 help

The Help page is displayed:

```
Usage:
  bash         - do not start any pre-requisite processes and execute bash
                 plus the additional arguments specified.
                 IMPORTANT: do not use /bin/bash, just use "bash"

  headless     - start VNC server and other prerequisites inside container and then
                 start SmarTest with DISPLAY :1.
                 To make use of the VNC server inside the container, you must
                 map the internal port 5901 to some free external port using
                 e.g. "-p 5988:5901". This will make VNC accessible on port 5988.
                 NOTE: the password for VNC is "SmarTest" (without quotes)

  smartest     - requires volume /tmp/.X11-unix to be mapped into the container
                 required the DISPLAY environment to be passed to the container
                 start SmarTest with DISPLAY environment from command line

  everything else - behaves identical to bash

```

## Results

You have installed and validated the installation of a Docker image.
