# Searching the Software Center

The smart-install-3 tool can be used to search for SmarTest products available from the Advantest Software Center and packages that are already downloaded to your local system.

## Before you begin

Make sure that you have installed the SmartInstall add-on required to install packages from the Software Center. For details, see [Downloading and installing the SmartInstall add-on](<01.02.01.03_Downloading_and_installing_the_SmartInstall_add-on.md>).

## Searching for product versions available from the Software Center

To get a list of all products available from the Software Center, enter the command:

/opt/ate/smart_install_3/smart-install-3 search

If you want to only see 8.4 versions of the Test Cell Access products, enter the command:

/opt/ate/smart_install_3/smart-install-3 search testcellaccess 8.4+.0 --release

The following type of list is displayed:

```
...
Available product versions (5):
TestCellAccess:
    8.4.0.0 (release)
    8.4.1.0 (release)
    8.4.2.0 (release)

```

## Searching for product versions available locally in a tar.gz archive or a local directory

To get a list of all products available from a tar.gz archive or a local directory, enter a command of the following form specifying a directory path or archive name and path:

/opt/ate/smart_install_3/smart-install-3 local-search /home/users/product

The following type of list is displayed:

Hello!

Available product versions (4) in specified files / directories: TestCellAccess: 8.3.4.0 (release) 8.4.1.0 (release) SmarTest: 8.4.1.0 (release) SmarTestDocumentation: 8.4.1 (release)

## Results

You have learned how to search the Software Center and local repositories for software products.
