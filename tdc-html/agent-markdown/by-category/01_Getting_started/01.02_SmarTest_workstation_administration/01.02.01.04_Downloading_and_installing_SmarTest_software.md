# Downloading and installing SmarTest software

SmarTest software can be downloaded from the Software Center and installed using the smart-install-3 tool.

## About this task

Installing the SmarTest software is a three step process:

- Download the SmarTest package
- Install the SmarTest package
- Switch version to use the new SmarTest installation

## Before you begin

Make sure the following prerequisites are met:

- The workstation operating system is Red Hat Enterprise Linux 鈮?7.2.x or the required operating system version for the software to be to be installed, whichever is the higher.
-

You have a [my.advantest.com](<http://my.advantest.com>) account with access to 'Software Center' and access to the software areas of interest, such as 'smart install 3' to install SmarTest Work Center software. You can request an account at: [https://login.myadvantest.com/](<https://login.myadvantest.com>) and ask for access to "Software Center" and "smart install 3".

The installation commands for SmartInstall must be run as system administrator (root). The two main command line options are:

- Use `su` and enter the root password when prompted.
- Prefix the command with `sudo` and enter your password when prompted.

## Procedure

-  Open the Advantest Software Center in a browser: [https://softwarecenter.advantest.com/](<https://softwarecenter.advantest.com/>)

Login with your credentials.

-  To get the list of all available SmarTest Suite releases, from the left menu select: SmarTestSuite

 ![Advantest Software Center](<../../../../raw/354076.png>)

Alternatively, to get the list of only the SmarTest releases, from the left menu select: SmarTest

-  Scroll to and select the SmarTest Suite version you want to install (7.10.0.0 in the following example ) and expand to display the details.
-  Download the package by clicking the ![Software Center save button](<../../../../raw/353535.png>) icon.

The SmarTest Suite (tar.gz) package is downloaded to your browser's download folder.

Example package: smartestsuite_7.10.0.0_rhel7.tar.gz

-  Create an empty installation directory. For example: /tmp/smartest_packages

mkdir /tmp/smartest_packages

-  Install the RPM packages from the smartest_packages directory on your workstation:

smart-install-3 local-install smartestsuite_<version>_rhel7.tar.gz

For example:

smart-install-3 local-install smartestsuite_7.10.0.0_rhel7.tar.gz

Installation of the selected SmarTest Suite packages starts and successful installation is confirmed with:

```
Complete!
```

-  Remove the installation directory. For example:

rm -rf /tmp/smartest_packages

## Results

The selected version of SmarTest is installed.

To use the newly installed SmarTest version, switch to it using the [Switch version tool](<01.02.02.03_Switch_version_tool.md>).
