# Before You Start the SmarTest Software...

#### Subtopics

- [SmarTest Software Base Directory](<01.02.02.02.01_SmarTest_Software_Base_Directory.md>)
- [Specifying the Device Path](<01.02.02.02.02_Specifying_the_Device_Path.md>)
- [Setting up Workorder Directories](<01.02.02.02.03_Setting_up_Workorder_Directories.md>)
- [SmarTest environment variables](<01.02.02.02.04_SmarTest_environment_variables.md>)

Before any workorder management can take place, each tester you intend to use must have the appropriate devices and test programs installed on it. See [Specifying the Device Path](<01.02.02.02.02_Specifying_the_Device_Path.md>) for details.

In addition, SmarTest expects workorders to be located in certain directories. This must be considered, before you start executing workorders (see [Setting up Workorder Directories](<01.02.02.02.03_Setting_up_Workorder_Directories.md>)).

  Note Before you start SmarTest, make sure you have selected the desired version. To switch the version to be started, use the [Switch version tool](<01.02.02.03_Switch_version_tool.md>).
