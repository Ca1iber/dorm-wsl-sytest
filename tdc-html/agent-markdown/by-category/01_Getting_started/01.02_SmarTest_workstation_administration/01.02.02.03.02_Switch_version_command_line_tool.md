# Switch version command line tool

#### Subtopics

- [Switching between TML versions](<01.02.02.03.02.01_Switching_between_TML_versions.md>)

## About this task

The tool uses command line parameters to switch between versions of the specified software or to load calibration data files. The parameters are:

  Syntax

/opt/hp93000/soc_common/bin/switch_version <valid software version> [-tml <valid tml version>] [-mtp <valid mtp version>] [-sl <valid sl version>][-rdi <valid rdi version>] [-cal <valid cal version>] [--kill|--no-kill]

 Examples

/opt/hp93000/soc_common/bin/switch_version soc64_8.4.0.0

`/opt/hp93000/soc_common/bin/switch_version soc64_7.3.4.1 -tml tml64_7.3.4.1_2.2.0`

  Help information

/opt/hp93000/soc_common/bin/switch_version -h

 Note The command options documented in the online help but not discussed here (for example, -TP360, apply only to SmarTest 8.

## Before you begin

Before attempting to switch versions, make sure that:

- Two or more versions of SmarTest are installed.
- SmarTest or other tools, such as TML, MTP, and RDI, are not running.

## Procedure

 If you want to switch versions from the command line or under shell script control, enter the following command or insert it into the script:

```
/opt/hp93000/soc_common/bin/switch_version smartest-version
```

where smartest-version - Name of the folder of the required SmarTest version in the /opt/hp93000 directory.

The specified version of SmarTest and, if installed, the matching version of associated tools such as TML, MTP, and SmartRDI are activated.

  Note It is not generally recommended to switch the version of an accompanying tool such as TML, MTP or SmartRDI manually. However, it is possible to specify alternative versions, for example, for testing purposes, using the command:

```
/opt/hp93000/soc_common/bin/switch_version smartest-version [-<tool name> tool-version]
```

where tool--version - Name of the folder of the required tool version in the tool folder. For example, for SmartRDI, the folders are located under: /opt/hp93000/ directory.

## Results

The specified version of SmarTest is activated.

The specified version of SmarTest and additional tools such as RDI or MTP, if selected, are activated.

Starting SmarTest from the Red Hat menu or /opt/hp93000/soc/prod_env/bin/HPSmarTestlaunches the active version.
