# SmarTest Prerequisites

SmarTest running on a RHEL system controller is used to run test programs on V93000 test systems. Suitable workstation hardware, RAM and BIOS versions are detailed for the supported SmarTest versions in the following tables. Some workstations can also be used to install a supported version of both SmarTest 7 and SmarTest 8, should you need to run both versions from the same system controller.

 Note This topic is applicable to SmarTest 7 and SmarTest 8.

## Operating System

SmarTest requires a dedicated Red Hat Enterprise Linux operating system version tested and provided by Advantest. Only these operating system versions and associated operating system and kernel patches provided by Advantest are approved for use wíth Advantest V93000 test systems.

If the currently available operating system patch level from Advantest does not meet the security guidelines required by your IT department (non-Advantest patches required for use in an open environment), run the SmarTest system controller in a protected subnet, for example, using a router with a firewall supporting Internet Protocol Security (IPsec) so that access from the network is not possible.
