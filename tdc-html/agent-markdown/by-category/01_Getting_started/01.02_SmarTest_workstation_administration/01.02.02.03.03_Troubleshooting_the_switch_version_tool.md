# Troubleshooting the switch version tool

The switch_version tool provides feedback in the form of messages to help you to correct problems.

## Syntax, options and examples

It is possible to switch between SmarTest, TP360 versions, and products such as TML, MTP, SL, RDI and Routing Tool.

  Syntax

/opt/hp93000/soc_common/bin/switch_version <valid software version> [-tp360 <valid TP 360 version>] [-tml <valid tml version>] [-mtp <valid mtp version>] [-sl <valid sl version>][-rdi <valid rdi version>] [-cal <valid cal version>] [--kill|--no-kill]

 SmarTest Selects a SmarTest version.

Syntax

`/opt/hp93000/soc_common/bin/switch_version `<SmarTest version>

Example

`/opt/hp93000/soc_common/bin/switch_version `soc64_8.0.6.0

 TP360 -tp360 selects a  TP360 version.

Syntax

`/opt/hp93000/soc_common/bin/switch_version` <SmarTest version> `[-tp360` <TP360 version>`]`

Example

`/opt/hp93000/soc_common/bin/switch_version `soc64_8.4.0.0 `-tp360` TP360_8.4.0

 Test Method Libraries (TML) -tml selects a [Test Method Library](<01.02.02.03.02.01_Switching_between_TML_versions.md>) (TML) version.

Syntax

`/opt/hp93000/soc_common/bin/switch_version` <SmarTest version> `[-tml` <tml version>`]`

Example

`/opt/hp93000/soc_common/bin/switch_version` soc64_7.3.4.1 `-tml` tml64_7.3.4.1_2.2.0

 Memory Test Plus (MTP) -mtp selects a [Memory Test Plus](<../../02_System_reference/02.12_Memory_Test_Plus_7.10.2/02.12_Memory_Test_Plus_7.10.2.md>) (MTP) version.

Syntax

`/opt/hp93000/soc_common/bin/switch_version` <SmarTest version> `[-mtp`<MTP version>`]`

Example

`/opt/hp93000/soc_common/bin/switch_version` soc64_7.3.4.1 `-mtp` mtp64_3.3.4

 Rapid Development Interface (RDI) -rdi selects a version of the [Rapid Development Interface](<../../02_System_reference/02.07_Test_Method_Reference/02.07.13_SmartRDI.md>) (SmartRDI).

Syntax

`/opt/hp93000/soc_common/bin/switch_version` <SmarTest version>`[-rdi`<RDI version>`]`

Example

`/opt/hp93000/soc_common/bin/switch_version` soc64_7.3.2.5 `-rdi` rdi64_7.3.2_2.3.1

See also [Installing and using SmartRDI](<../../02_System_reference/02.07_Test_Method_Reference/02.07.13.02_Installing_and_using_SmartRDI.md>).

 RoutingToolsGUI -gui selects a version of the Routing Tools perspective.

Syntax

`/opt/hp93000/soc_common/bin/switch_version` <SmarTest version> `[-gui` <RoutingToolsGUI version>`]`

Example

`/opt/hp93000/soc_common/bin/switch_version` <SmarTest version> `-gui` RoutingToolsGUI_7.5.0v1.12.1.0`]`

See also [ Opening the Routing Tools editors](<../../02_System_reference/02.07_Test_Method_Reference/02.07.13.15.02.01_Opening_the_Routing_Tools_editors.md>).

 Force (-f) -f Force mode to use a cal data file that is not compatible with the selected version of SmarTest.

Syntax

`/opt/hp93000/soc_common/bin/switch_version` <SmarTest version> `[-cal` <cal_file> `-f]`

Example

`/opt/hp93000/soc_common/bin/switch_version` <SmarTest version> `-cal` std__7.4.0 `-f`

 Help -h Displays the help information.

## Information and problem messages

Common problems reported from the Switch Version tool
 | Message  | Description |
 | No compatible <product> installation found.  | Information only. A compatible version of the product <product> is not present on the system.

Can be ignored unless you are expecting switch to an alternative version of the reported product. In such cases, make sure that you have already installed the version of the product you require.

 |
 | ERROR: The specified <product> directory <dir> does not exist.  | The selected <product> is expected to be found at <dir> but is missing. |
 | ERROR: no compatible cal data version found for the selected SmarTest <version>.  | Happens only in 'auto' mode for switching CAL, as described in the previous comment |
 | ERROR: Unable to switch versions while SmarTest is running.  | Stop SmarTest and add-on products and retry switching versions. |
 | No change of version requested.  | The requested version the same as the currently active version and no switch can be made. |
 | Unable to link <source> to <target>.  | Symbolic link could not be created. Typically due to wrong permissions. |
 | Unable to remove <source>.  | The existing symbolic link could not be removed. Typically caused by a running version of SmarTest locking the file. Stop SmarTest and retry switching versions. |
 | ERROR: No target SmarTest release selected.  | Select a SmarTest version to switch to. |
 | WARNING: <selected_version> older than <n> days. Please recalibrate the system.  | All correction data files (cal files) are incompatible with the selected SmarTest version. Appropriate correction data might not be available for some of the hardware and default data is loaded instead. Any tests performed with default correction data might be inaccurate. |
 | WARNING: The system recommends to activate cal file <cal_version>.  |  A more appropriate correction data file is available for your installation. Select the recommended version. |
 | STD__ version <selected_version> already copied to std__.  | CAL file is already switched (copied/replaced). |
 | ERROR: copy cal data <from> to <to> failed.  | Could not switch CAL file because the previously reported Linux command failed. |
 | INFO: No <post_run> available to execute.  | The post_run script is not present.

post_run is used to install an alternative major version of SmarTest even when the other supported major version is running on RHEL 7 operating systems. Supported major versions: SmarTest 8 and SmarTest 7.

 |
 | Exception: <path> is not a symbolic link. Unable to switch versions.  | Something is wrong with the directory at <path> |
 | Unable to switch versions. <OPT_LINK>, <ETC_LINK> and <VAR_LINK> must all be symbolic links.  | |
 |

WARNING: The selected cal data version <selected_version> does not match the selected SmarTest <selected_version> version.

   | This warning is a known bug in SmarTest 7.10.0. Ignore the warning, and press 'y' when queried whether you are sure you want to use this file. |
