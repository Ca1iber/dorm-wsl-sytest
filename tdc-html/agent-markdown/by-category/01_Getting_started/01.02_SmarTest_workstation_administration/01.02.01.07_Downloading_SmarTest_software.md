# Downloading SmarTest software

The smart-install-3 tool can be used to download SmarTest products available from the Advantest Software Center to your local system.

## Before you begin

Make sue that you have installed the SmartInstall add-on required to install packages from the Software Center. For details, see [Downloading and installing the SmartInstall add-on](<01.02.01.03_Downloading_and_installing_the_SmartInstall_add-on.md>).

## Downloading a software package from the Software Center

To download a software product available from the Software Center to your current directory, enter a command with the following structure. This command downloads the Test Cell Access version 8.4.1.0 package:

/opt/ate/smart_install_3/smart-install-3 download testcellaccess 8.4.1.0 .

On completion, the following type of confirmation is displayed:

```
Downloaded 1 package(s) to .
    testcellaccess-8.4.1.0_RHEL7.tar.gz

```

## Results

You have learned how to download SmarTest products from the Software Center to your local workstation.
