SmartInstall is a tool for SmarTest-related installation tasks.

Installing software can be done using one of the following routes:

- The [Advantest Software Center](<01.02.01.02_Using_the_Advantest_Software_Center.md>)
- The [smart-install-3 command line tool](<01.02.01.05_smart-install-3_command_line_tool.md>)

The SmartInstall add-on is a prerequisite to installing SmarTest software from the Advantest Software Center. For detailed information about installing the SmartInstall add-on, refer to [Downloading and installing the SmartInstall add-on](<01.02.01.03_Downloading_and_installing_the_SmartInstall_add-on.md>).
