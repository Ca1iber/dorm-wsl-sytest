# Running SmarTest

#### Subtopics

- [SmarTest introduction](<01.02.02.01_SmarTest_introduction.md>)
- [Before You Start the SmarTest Software...](<01.02.02.02_Before_You_Start_the_SmarTest_Software.md>)
- [Switch version tool](<01.02.02.03_Switch_version_tool.md>)

SmarTest lets you develop, debug and execute production tests. The software can be started in either operating or development environment:

- In operating environment, operators (but also supervisors and engineers) can run production tests by executing workorders.
- In development environment, workorders can be set up and assigned to operators by the supervisor (see [Working with workorders](<../../02_System_reference/02.09_Test_Program_Management/02.09.01.05_Working_with_workorders.md>)). The engineer's scope of modifying test program flags and building Production Settings files is described in [Modifying Testflow Execution and Data Logging](<../../02_System_reference/02.09_Test_Program_Management/02.09.01.06_Modifying_Testflow_Execution_and_Data_Logging.md>) of this manual.

This chapter covers the following essential procedures you need to know when working with SmarTest:

- Preparing the file structure on your workstation, before you use SmarTest for the first time.
- Launching the SmarTest software in different modes to provide the user with specific capabilities.
- Changing the user mode from within the running software.
