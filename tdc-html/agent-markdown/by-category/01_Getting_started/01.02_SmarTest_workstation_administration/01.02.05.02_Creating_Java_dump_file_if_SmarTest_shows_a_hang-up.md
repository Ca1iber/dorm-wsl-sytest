# Creating Java dump file if SmarTest shows a hang-up

Use is procedure only if SmarTest did not crash, but hangs up. If SmarTest crashed, go to [Collecting log files if SmarTest crashed](<01.02.05.01_Collecting_log_files_if_SmarTest_crashed.md>).

## About this task

The following command writes the JVM pid and the stack, to the file JVM_dump.log, which you send to the Advantest service representative to get further support.

## Procedure

-  Open a terminal window
-  Save the Java process ID and the stack information to the file JVM_dump.log

jps -l | grep eclipseRE | grep '[0-9]*' -o | xargs bash -c 'jstack -l $1; echo JVM pid: $1' argv0 > JVM_dump.log

-  Send the JVM_dump.log fileto the Advantest service representative.
