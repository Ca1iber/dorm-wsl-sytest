# Migrating test programs to SmarTest 7.10

SmarTest 7.10 is, for the most part, compatible with earlier versions of SmarTest. This section summarises what to consider, when migrating to SmarTest 7.10.

 CAUTION THIS TOPIC IS WORK IN PROGRESS!

## Hardware

SmarTest 7.10 supports the new EXA Scale test systems, as well as the Smart Scale test system. EXA Scale is the next generation of Advantest test systems, consisting of the CX, SX, and, LX test heads, see topic [Test heads](<../../02_System_reference/02.03_DUT_board_design_reference/02.03.02_Test_heads.md>) for an overview.

 With EXA Scale comes support of the new EXA Scale generation cards:

- The [DC Scale XPS256 card](<../../02_System_reference/02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>), and
- the [Pin Scale 5000 card](<../../02_System_reference/02.05_Test_Head_Cards/02.05.04.02_Pin_Scale_5000_card.md>).

These cards, as well as the new [Utility Card](<../../02_System_reference/02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>), are not supported with the Smart Scale test system.

The Pin Scale generation cards are no longer supported. See section [Smart Scale vs. Pin Scale](<../../02_System_reference/02.05_Test_Head_Cards/02.05.04.03_Smart_Scale_vs._Pin_Scale.md>) for considerations when upgrading to Smart Scale or EXA Scale generation cards.

The DPS-Slot power supplies and the DC Scale UHC4 and PVI8 cards are no longer supported.

For an overview of supported cards, see section [Test Head Cards](<../../02_System_reference/02.05_Test_Head_Cards/02.05_Test_Head_Cards.md>).

## Software

 Consider the following list when migrating your test program to SmarTest 7.10:

- The EXA Scale test system only supports the [tester.model](<../../02_System_reference/02.04_Model_File_and_Licensing/02.04.01.03.01_Model_file_reference__tester.model.md>) style model files. See [Converting legacy model files](<../../02_System_reference/02.04_Model_File_and_Licensing/02.04.01.04_Converting_legacy_model_files.md>) for how to convert your old model file.
- The High Precision PMU (system PMU) is no longer supported. The Pin PMU must be used instead, see [Per Pin PMU](<../../02_System_reference/02.07_Test_Method_Reference/02.07.03.02.08_Per_Pin_PMU.md>).
- The master clock period is fixed at 8/3 = 2.67 ns (frequency of 375 MHz). The Smart Scale and EXA Scale digital cards still provides an independent clock domain per pin.
- High voltage pins are no longer supported.
- The Memory Stacker is no longer supported. Use instead [Memory pooling and memory sharing](<../../02_System_reference/02.05_Test_Head_Cards/02.05.02_Memory_pooling_and_memory_sharing.md>).

## Other considerations

Maintenance is executed by means of an auxiliary embedded maintenance core, see Executing SmarTest 7.10 maintenance activities.
