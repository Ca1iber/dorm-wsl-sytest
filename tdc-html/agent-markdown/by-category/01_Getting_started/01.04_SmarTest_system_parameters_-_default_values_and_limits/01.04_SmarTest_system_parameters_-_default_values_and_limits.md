## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.4: Upper limit of PDC_set has been increased
- SmarTest 7.2.0: Max number of ports increased to 256
[1)](<>) This parameter was introduced for the 4.3 release. Prior to this release, only 4 decimal places were stored. If you modify a pre-4.3 device with a later software release (or create a new device), the parameter will be inserted into the .technology file with the default value of 9. If you want to keep the old precision, you must change the parameter value to 4 or remove the entry. Note that when you create a new device by copying an existing device, and if the precision is not set to 9 in the.technology file of the existing device, then you will have to change the value manually. Note also that this parameter does not affect a user defined period resolution (for example, by the period_res keyword in the equation set).
