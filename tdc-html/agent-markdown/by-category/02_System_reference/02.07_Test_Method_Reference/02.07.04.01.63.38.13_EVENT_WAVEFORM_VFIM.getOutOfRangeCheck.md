# EVENT_WAVEFORM_VFIM.getOutOfRangeCheck()

Queries the settings of the out-of-range check. Per default this check is on. If this check is enabled and the measurement range is exceeded, the event contributes with a FAIL to the global test result.

## Syntax

```
void getOutOfRangeCheck(bool & failOnOutOfRange) const;
```

Parameter
 | Parameter  | Description |
 | failOnOutOfRange |

Possible values are: true | false

 |

## Return value

The setting of the failOnOutOfRange parameter.
