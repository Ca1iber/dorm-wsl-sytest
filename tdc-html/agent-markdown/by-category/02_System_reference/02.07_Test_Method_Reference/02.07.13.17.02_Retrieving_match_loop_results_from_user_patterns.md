# Retrieving match loop results from user patterns

SmartRDI provides functions to retrieve match loop results from a user pattern for the `func()` class.

If a user pattern contains match loops, you may want to know:

- Whether any match loop has been matched.
- How many loops have been passed before a match is met.

These are the setup and result retrieval functions:

- Setup functions:

  - [rdi.func().readMatchCount()](<02.07.13.17.01.09_rdi.func__.readMatchCount.md>)
  - [rdi.func().readMatchPassFail()](<02.07.13.17.01.10_rdi.func__.readMatchPassFail.md>)

- Result retrieval functions:

  - [rdi.id().getMatchCount()](<02.07.13.17.01.16_rdi.id__.getMatchCount.md>)
  - [rdi.id().getMatchPassFail()](<02.07.13.17.01.17_rdi.id__.getMatchPassFail.md>)

## Example

```
RDI_BEGIN();
   rdi.func("mch").label("abc").readMatchPassFail("pinA")
                               .readMatchCount("pinA").execute();
RDI_END();
rdi.id("mch").getMatchPassFail();
rdi.id("mch").getMatchCount();
```
