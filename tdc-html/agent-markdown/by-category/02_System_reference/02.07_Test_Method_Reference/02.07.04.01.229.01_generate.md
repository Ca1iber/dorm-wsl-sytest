# generate()

Since SIGNAL_GEN class is a child class of DEMODULATION class, it inherits all methods of DEMODULATION, such as getInputParameter(), setInputParameter(), getResult(), presetToStandard(), loadParameterFile() and etc. Besides, SIGNAL_GEN has its own methods as described below.

This method generates signal and saves it to an encrypted waveform of Signal Studio type (*.wfm).

## Syntax

```
SIGNAL_GEN& generate(const STRING& wfmFileName="");
```

Parameter
 |

Parameter

 |

Description

 |
 |

wfmFileName

 |

The file name relative to $DEVICE/waste/ as a STRING. Can also be absolute path when starting with "/"

 |

## Return value

Generated signal.

## Example

```
SIGNAL_GEN sigGen("SG_ZIGBEE_FLEX");
// generate signal and save it to $DEVICE/waste/myWave.wfm
sigGen.generate("myWave.wfm");
```
