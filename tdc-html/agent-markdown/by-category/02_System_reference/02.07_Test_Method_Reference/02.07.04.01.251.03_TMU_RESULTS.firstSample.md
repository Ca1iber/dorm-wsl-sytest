# TMU_RESULTS.firstSample()

Sets the first sample to upload.

## Syntax

```
TMU_RESULTS& firstSample(UINT64 firstsample);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

 |

 |

## Return value

A reference to the TMU_RESULTS object is returned.
