# combinedFailCount()

Returns the total fail counts of multiple pins in one label. The result can be retrieved by rdi.id().getCombinedFailCount().

## Syntax

```
combinedFailCount(long startCycle);
```

List of parameters
 | Parameter  | Description |
 | startCycle  | The number of the first cycle in the label in which the fails are counted.

Default is 0, which means the start of the pattern.

 |

## Example

```
RDI_BEGIN();
  rdi.emap("a").label("pat").pin("@").combinedFailCount().execute();
RDI_END();
int dVal =rdi.id("a").getCombinedFailCount();

```

 Note pin("@") can only be used for the combinedFailCount() command and cannot be used with all the other error map commands.
