# DSP_RF_SPECTRUM()

This function is used to perform a Fast Fourier Transform on captured data, so that time domain information is brought into the frequency domain. In most applications, users will not need to call the `DSP_RF_SPECTRUM()` function, because the Fast Fourier Transform is performed automatically by other DSP functions, such as `DSP_RF_MOD_POWER()`. The `DSP_RF_SPECTRUM()` function is provided for the benefit of users who wish to create their own custom DSP routines within a TestMethod, and therefore need direct access to an FFT function.

This function returns an array of doubles representing the spectrum produced by the FFT process; it is converted from the complex numbers of the captured data using the formula:

```
10 * log10 ( ( (I^2 + Q^2)/50) * 1000.0)
```

The data in the array is automatically corrected so that the center frequency is placed in the middle of the spectrum; the need for this correction is discussed in connection with the function [DSP_RF_SWAP()](<02.07.04.01.53.84_DSP_RF_SWAP.md>), but it is not necessary to call that function when `DSP_RF_SPECTRUM()` is used.

An alternative function is available which converts the captured data to the frequency domain but leaves it in the form of an array of complex numbers; see [DSP_RF_FFTW()](<02.07.04.01.53.71_DSP_RF_FFTW.md>).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_RF_SPECTRUM (const ARRAY_COMPLEX & source_data,
 ARRAY_D & result_data
 const INT windowFunction,
 const INT highSideLO)

DSP_RF_SPECTRUM(const ARRAY_COMPLEX& data,
 ARRAY_D& resultSpectrum,
 const INT outputMode, // DB, DBM, VOLT, WATT
 const INT windowFunc,
 const INT highSideLo,
 const DOUBLE scale); // calFactor in watt/watt
```

Choose the window function to be applied by the `DSP_RF_FFTW()` function. The choices are:

`HANNING`(Hanning window)

`HAMMING` (Hamming window)

`FLAT_TOP` (Flat-top window)

`FBLACKMAN` (Blackman window)

See [Window functions](<02.07.04.05_Window_functions.md>).

 |
 |

I

 |

`outputMode`

 |

The user may want to get the spectrum back in either DB, DBM, VOLT or WATT. DB is the most time consuming.

 |
 |

I

 |

`scale`

 |

Calibration factor in Watts. This factor exists because in this function there is no place for measParams to be passed in. "scale" is intended to be used with DSP_RF_GET_SCALAR_POWER_FACTOR() so that DSP_RF_SPECTRUM can be used to manually do the steps to perform a CW or Mod Power Out measurement instead of using DSP_RF_CW_POWER().

The scale is applied as follows

Power_dB = 10 * log10( (I^2 + Q^2)/50.0 * scale )

Scale = 1.0 means no correction.

Use the following formula to specify the scale factor

 VOLT: sqrt(scale*(I^2+Q^2))

 WATT: scale*(I^2+Q^2)/50

 DB: 10*log10(scale*(I^2+Q^2)/50)

 DBM: 10*log10(scale*1000*((I^2+Q^2)/50))

 |
 |

I

 |

`highSideLO`

 |

If selected, reverse the spectrum left-to-right to correct for the measurement's use of an LO frequency that is above the measured frequency.

1 = correct for use of high-side LO

0 = do not correct for use of high-side LO

## Example

```
ARRAY_COMPLEX cData = MEAS_DEF("myModPwrMeas").getComplexWaveform();
ARRAY_D fftData(cData.size());
DSP_RF_SPECTRUM(cData, fftData, RECT, 0);
```

Since DSP_RF_SPECTRUM does not accept a parameters array (MEAS_DEF().getParameters()), the results returned are uncalibrated. To obtained calibrated results, DSP_RF_SPECTRUM must be used in conjunction with DSP_RF_GET_SCALAR_CAL() as shown below.

```
ARRAY_D measParams = MEAS_DEF("myModPwrMeas").getParameters(1,0); // Same as any other RF measurement DOUBLE CalCorr = 0; DSP_RF_GET_SCALAR_CAL(measParams,1, &CalCorr); // 1 = Site number
ARRAY_COMPLEX cData = MEAS_DEF("myModPwrMeas").getComplexWaveform(1);
ARRAY_D fftData(cData.size());
DSP_RF_SPECTRUM(cData, fftData, WATT, HANNING, 0, CalCorr);
```
