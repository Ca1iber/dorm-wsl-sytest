# DIGITAL_OFFSET_SEARCH_PINS.stepWidth()

Sets the step width for an offset search.

The combination of the [start value](<02.07.04.01.36.01.25_DIGITAL_OFFSET_SEARCH_PINS.start.md>), the [number of search steps](<02.07.04.01.36.01.12_DIGITAL_OFFSET_SEARCH_PINS.numSteps.md>), and the step width defines the range for the initial linear search.

## Syntax

```
DIGITAL_OFFSET_SEARCH_PINS& stepWidth(DOUBLE stepwidth);
```

Parameter
 |

Parameter

 |

Description

 |
 |

stepwidth

 |

The step width of a search. It can be positive or negative.

For timing searches, the unit is seconds [s].

For voltage searches, the unit is Volts [V].

 |

## Return value

A reference to the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) object.
