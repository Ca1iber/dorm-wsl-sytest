# Parameters in the alarm setup file

The parameters used in the alarm setup file can be divided into two categories: global parameters and local parameters.

## Global parameters

A global parameter defines a global limit value for all the pins in the SET.

- GlobalLimitRelForce: Define a global relative limit value for vForce actions. Its unit can be % (percentage), V or mV.
- GlobalLimitMinDisForce: Define a global minimum limit distance when the GlobalLimitRelForce (%) is applied. Its unit is V or mV.
- GlobalLimitRelClamp: Define a global relative limit value for clamp actions. Its unit can be %, V or mV.
- GlobalDisableAlarmIth: Define a global current threshold value for disabling alarm checking actions. Its unit is μA.

## Local parameters

A local parameter defines a limit value for specific pins. This value will overwrite the global value.

- LimitRelForce: Define a relative limit value for vForce actions. Its unit can be %, V or mV.
- LimitMinDisForce: Define a minimum limit distance when LimitRelForce (%) is applied. Its unit is V or mV.
- LimitRelClamp: Define a relative limit value for clamp actions. Its unit can be %, V or mV.
- LimitLo: Define a fixed low limit value. Its unit is V or mV.
- LimitHi: Define a fixed high limit value. Its unit is V or mV.
- DisableAlarmIth: Define a current threshold value per pin for disabling alarm checking on the specific pin. Its unit is μA.

## Functional changes

- Introduced in SmartRDI 7.5.0
- SmartRDI 7.5.3: GlobalDisableAlarmIth and DisableAlarmIth to define a current threshold value for disabling alarm checks globally or per pin.
