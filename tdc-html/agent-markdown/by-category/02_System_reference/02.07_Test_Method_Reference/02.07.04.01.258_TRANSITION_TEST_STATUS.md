# TRANSITION_TEST_STATUS

This `TRANSITION_TEST_STATUS` is a container holding the transition test status and debug information. You can query the transition test status with its member functions.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TransitionTestStatus.h.

### Constructor

```
TRANSITION_TEST_STATUS (const std::string& pin)
```

It constructs an object of `TRANSITION_TEST_STATUS` for a specified pin for which the respective transition test status will be queried.

## Member functions

### getStatus()

```
TRANSITION_TEST_STATUS&  getStatus(unsigned int & status, unsigned int& interrupts);
```

This function returns whether certain transition test conditions occurred during the last sequencer run. It is used to query the status of the last transition test execution for one pin.

Parameters
 |

status

 |

The status of the transition test execution.

 |
 |

interrupts

 |

The interrupt status of the transition test execution.

 |

### getExpectedToDutDeviationValues()

```
void getExpectedToDutDeviationValues (INT& edToDut, INT& dutToEd) const;
```

This function returns the maximum number of bits (UIs) the expected data stream fell behind DUT streams and the maximum number of bits (UIs) the DUT streams fell behind the expected data stream.

Parameters
 |

edToDut

 |

The maximum number of bits(UIs) the expected data streams fell behind DUT streams.

 |
 |

dutToEd

 |

The maximum number of bits(UIs) the DUT streams fell behind the expected data streams.

 |

### getFirstAdjustment()

```
DOUBLE getFirstAdjustment() const;
```

This function returns the first adjustment as fraction of one UI on the initial transition for the last sequencer run.

### getLocationOfFirstFail()

```
INT getLocationOfFirstFail()const;
```

This function returns the number of bits (UIs) in expected data stream that have been processed when the first error occurred. (Remove X tokens are included in this count).

### getLocationOfFirstTrackingError()

```
INT getLocationOfFirstTrackingError()const;
```

This function returns the number of bits (UIs) when the first tracking error occurred. (Remove X tokens are included in this count.)

### getNumberOfRemovedIdleTokens()

```
INT getNumberOfRemovedIdleTokens(INT idleTokenNumber) const;
```

This function returns the number of skipped idle tokens referred by the specified idleTokenNumber during the last sequencer run.

Parameter
 |

idleTokenNumber

 |

The token number to refer the skipped idle tokens. It is an integer between 1 an 6.

 |

### getNumberOfRemovedXTokens()

```
INT getNumberOfRemovedXTokens() const;
```

This function returns the number of X tokens removed from expected stream during last sequencer run.

### getNumberOfRemovedXTokensForEmap()

```
void getNumberOfRemovedXTokensForEmap(INT& atAcquisitionStart, INT& atAcquisitionStop)const;
```

This function returns the number of X tokens when error map acquisition started and stopped.

Parameters
 |

atAcquisitionStart

 |

The position when error map acquisition starts.

 |
 |

atAcquisitionStop

 |

The position when error map acquisition stops.

 |

### getNumberOfRemovedXTokensInInitialSync()

```
INT getNumberOfRemovedXTokensInInitialSync()const;
```

This function returns the number of X tokens removed from expected stream during initial sync.

## Example

```
TRANSITION_TEST_SET myTTSet("TTSetExample");

myTTSet.pin("I/O0,I/O1,I/O2")
       .tokenSize(10)
       .firstInitialSyncMode(true).trackingMode(TRANSITION_TEST::FREEZE_ALWAYS);

myTTSet.setAsPrimary();    // set this set as primary

// execute first functional test (tracker is freezed)
START_TEST();
WAIT_TEST_DONE();
TEST();

//query transition status
TRANSITION_TEST_STATUS ttStatusObj= TRANSITION_TEST_STATUS("I/O0");
unsigned int statusBits;
unsigned int interuptStatusBits;
ttStatusObj.getStatus(statusBits,interuptStatusBits);
if (statusBits)
{
  cerr<<  "transitionError occurred";
}

// modify TT parameters , activate tracker
myTTSet.pin("I/O0,I/O1,I/O2").trackingMode(TRANSITION_TEST::ACTIVE);
 ...
// execute second functional test
START_TEST();
WAIT_TEST_DONE();
TEST();

// set Default setting as primary
TRANSITION_TEST_SET::setDefaultAsPrimary();
// query some configuration data
try
{
  INT tokenSize=myTTSet.pin("I/O1,I/O2").getTokenSize();
}
catch(TESTMETHOD_API::AmbiguityException e)
{
  // .. query the tokenSize on a per pin base
  INT tokenSize2=myTTSet.pin("I/O1").getTokenSize();
  INT tokenSize3=myTTSet.pin("I/O2").getTokenSize();
}

// set default values (for pin1)
myTTSet.pin("I/O0").setToDefault();

// dump configuration of set to stream
cout << myTTSet;

START_TEST();
WAIT_TEST_DONE();
TEST();

// remove this set from SW
myTTSet.remove();
```
