# PropDelay

This test methods measures the propagation delay from the specified drive pin(s) to receive pin(s) with TMU. Some time stamps of rising edges or falling edges of drive pins and receive pins are captured. Propagation delay is the difference between time stamps of receive pins and drive pins.

## Implementation pseudo code

```
IF not connected THEN
 connect DUT
ENDIF
Set up TMU with specified parameters
TMU measurement
Upload the raw result data of drive pins and receive pins
Retrieve functional test result if specified
FOR each pair of drive and receive pins
 Subtract the time stamps of drive pin from the time stamps of receive pins
ENDFOR
Get the min, max, mean value of the delay
Judge and log the measurement result
Judge and log the functional test result if specified
```
