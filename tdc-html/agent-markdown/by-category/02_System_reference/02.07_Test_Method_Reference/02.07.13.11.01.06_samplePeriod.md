# samplePeriod()

Specifies the sampling period to generate the waveform.

## Syntax

```
samplePeriod(double dSamplePeriod);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

dSamplePeriod

 |

The sampling period.

 |

## Example

```
rdi.dc().pin().vForce().waveform(wav).samplePeriod(100 us). execute();
```

## Functional changes

- Introduced in SmartRDI 2.2.0
