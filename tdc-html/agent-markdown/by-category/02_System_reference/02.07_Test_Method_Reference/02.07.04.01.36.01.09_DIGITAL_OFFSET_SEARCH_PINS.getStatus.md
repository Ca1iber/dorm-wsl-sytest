# DIGITAL_OFFSET_SEARCH_PINS.getStatus()

Gets the status for all of the sites tested in the last search. SUCCESS will be returned only if all the sites are pass. If one of these sites is failed, FAILED will be returned.

If you retrieve the status on multiple pins and the pins have different settings, the exception TESTMETHOD_API::AmbiguityException will be issued.

Note You should not use this function inside a FOR_EACH_SITE block because it cannot return the status for each individual site.

## Syntax

```
DIGITAL_OFFSET_SEARCH::STATUS_TYPE getStatus();
```

List of parameters

There are no parameters.

## Return value

Returns the execution status for all of the sites under test, which can be SUCCESS, FAILED, ABORTED or NOT_EXECUTE.

## Functional changes

- Introduced in SmarTest 7.2.1
