# Logging Failed Cycle/Vector for functional test

The TEST API for functional can log the first failing vector (FFV) and first failing cycle (FFC) information. For enabling the FFV, see [Selecting the Items to be Output](<02.07.03.03.07.02_Selecting_the_Items_to_be_Output.md>). For enabling the FFC, enable the FFV and set the testsuite flag ffv_enable to "off".

FFC output the first failing cycle data as shown below when it is enabled:

  ![First failing cycle (FFC) data logging eExample](<../../../../raw/20898.png>)

In the figure below, the first two failed cycles are data logged, numbers (14 and15) mean the failed cycle numbers and strings (I/O1, I/O1, I/O5, I/O6) mean the failed pin names.

FFV output the first failing cycle data as shown below when it is enabled:

  ![First failing vector (FFV) data logging example](<../../../../raw/20899.png>)
