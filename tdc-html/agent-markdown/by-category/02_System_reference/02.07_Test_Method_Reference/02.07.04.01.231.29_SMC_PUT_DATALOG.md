# SMC_PUT_DATALOG()

Logs a specified string into the data log stream by buffering the data log values and executing them as soon as the synchronization point ([SMC_SYNCHRONIZE()](<02.07.04.01.231.43_SMC_SYNCHRONIZE.md>)) is reached. The data log values will be executed in the order of starts of the different background threads.

To log data and display the test report set the report formatter to 'EventFormatter' and enable the following flags:

- system flag `log_events_enable`
- testsuite flag either `output_on_pass` or output_on_fail

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```
void PUT_DATALOG(const char *comment);
```

Parameter
 |

Parameter

 |

Description/Range

 |
 |

comment

 |

A string to be logged. Up to 655365 characters.

 |

## Return value

Returns the content of the parameter comment to the data log stream.

## Example

This example shows hot to add "My comment" to the data log stream using `SMC_PUT_DATALOG()`

```
SMC_PUT_DATALOG("My comment");
```
