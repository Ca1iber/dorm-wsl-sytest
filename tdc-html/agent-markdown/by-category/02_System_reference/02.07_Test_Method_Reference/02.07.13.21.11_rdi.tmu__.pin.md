# rdi.tmu().pin()

Specifies the pins for the following TMU measurements. It indicates the ending of the setups for the previous pin and the start of the setups for the specified pin.

Do not specify different types of pins in the same function pin(). To set up different types of pins in the same line of code, specify different types of pins in separate functions of pin() within the same rdi ... execute() block.

## Syntax

```
tmuBase& pin(const string& sPin);
```

Parameter
 | Parameter  | Description |
 | sPin  | The pin on which the following setups will be done. Its value can be a pin, a pin group, a port name as a pin group, the pins or pin groups separated with comma, or all pins. |

## Return Value

A reference to the tmuBase object.

## Example

```
RDI_BEGIN();

    rdi.tmu().pin("PVI8_PMU_1")
            .measMode(TA::RISE_TIME)
            .connectMode(TA::HIGH_BW)
            .vth(1.0 V,2.0 V).samples(50)
            .execute();

    rdi.tmu().pin("PS1600_1")
            .vth(1.0 V).samples(5).measMode(TA::RISE)
            .execute();

    rdi.wait(100 us);

RDI_END();
```

- Introduced in SmartRDI 2.3.0
