# getPfMap()

This function returns a pass/fail map for a specified pin.

## Syntax

```
ARRAY_BOOL getPfMap(string pin)
```

List of parameters
 |

Parameter

 |

Description

 |
 |

pin

   | The name of the pin for which to return the pass/fail map.Note It can only be a single pin. Do not use multiple pins, a pin group or @ for all pins. |

## Example

```
ARRAY_BOOL map=rdi.id("a").getPfMap("pA");
```
