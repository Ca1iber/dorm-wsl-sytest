# EVENT_WAVEFORM_CFIM.cForce()

Sets the force current waveform as [ANALOG_WAVEFORM](<02.07.04.01.05_ANALOG_WAVEFORM.md>).

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_WAVEFORM_CFIM & cForce (ANALOG_WAVEFORM & waveform);
```

Parameter
 | Parameter  | Description |
 | waveform |

Defines the waveform to be set in A (Ampere).

 |

## Return value

A reference to the corresponding [EVENT_WAVEFORM_CFIM](<02.07.04.01.63.28_EVENT_WAVEFORM_CFIM.md>) object.
