# Shmoo test method customization

#### Subtopics

- [Creating a customized shmoo test method](<02.07.07.01_Creating_a_customized_shmoo_test_method.md>)
- [Customized shmoo test template](<02.07.07.02_Customized_shmoo_test_template.md>)
- [Viewing customized results of a customized shmoo test in the Shmoo Tool](<02.07.07.03_Viewing_customized_results_of_a_customized_shmoo_test_in_the_Shmoo_Tool.md>)
- [Performing customized source-sync shmoo tests with the shmoo tool](<02.07.07.04_Performing_customized_source-sync_shmoo_tests_with_the_shmoo_tool.md>)

The shmoo test method customization is to [create your own shmoo test method](<02.07.07.01_Creating_a_customized_shmoo_test_method.md>) instead of using the provided [ac_tml.AcTest.Shmoo](<02.07.05.01.09_Shmoo.md>) test method.

During the customization, you add additional test method parameters and functions to the [ac_tml.AcTest.Shmoo](<02.07.05.01.09_Shmoo.md>) test method. Therefore, the new test method will:

- Keep all the parameters and functions of the ac_tml.AcTest.Shmoo test method.
- Have new test method parameters.
- Display desired results on a shmoo plot.
- Perform specific actions before, during, or after a shmoo.
