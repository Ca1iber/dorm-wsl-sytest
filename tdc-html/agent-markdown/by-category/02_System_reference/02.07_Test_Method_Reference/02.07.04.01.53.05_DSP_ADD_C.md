# DSP_ADD_C

This API returns the sum of two complex numbers.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_ADD_C(COMPLEX src1, COMPLEX src2, COMPLEX result);
```

Parameters
 |

I/O

 |

Parameter

 |

Description / Range

 |
 |

I

 |

src1

 |

Addend 1

 |
 |

I

 |

src2

 |

Addend 2

 |
 |

O

 |

result

 |

result = addend 1 + addend 2

 |

## Example

```
COMPLEX impedance, imp1, imp2;
      :
DSP_ADD_C(imp1, imp2, impedance);
```

DSP_ADD_C adds the two COMPLEX variables imp1 and imp2, and returns the results to the COMPLEX variable impedance as shown in the following:

```
COMPLEX impedance, imp1, imp2;
      :
impedance.real = imp1.real + imp2.real;
impedance.imag = imp1.imag + imp2.imag;
```
