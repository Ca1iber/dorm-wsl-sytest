# TESTSET().hlmFmt()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) assigns the format for displaying the higher limit in the data formatter output.

Calling this function stores the supplied format string in the C_HLMFMT fields of the [parametric test record](<../02.10_Data_Logging/02.10.03.05.22_Parametric_Test_Record__PTR.md>) (PTR) and the [multiple-result parametric record](<../02.10_Data_Logging/02.10.03.05.23_Multiple-Result_Parametric_Record__MPR.md>) (MPR).

This function is not supported within the SMC_backgroundProcessing() test method when flag [hidden_datalog_mode](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_hidden_datalog_mode>) is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

## Syntax

```
TESTSET & hlmFmt(const STRING &format);
```

 |

Parameter

 |

Description

 |
 |

format

 |

A string describing the desired format. The string is a standard ANSI C format string, for example, "%7.3f".

 |

## Example

```
TestSet.hlmFmt("%7.3f");
```
