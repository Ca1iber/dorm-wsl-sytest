# DIGITAL_OFFSET_SEARCH_PINS.search()

Executes the offset search for the pins specified with [DIGITAL_OFFSET_SEARCH_TASK.pin()](<02.07.04.01.36.03_DIGITAL_OFFSET_SEARCH_TASK.pin.md>), and returns the execution status.

## Syntax

```
DIGITAL_OFFSET_SEARCH::STATUS_TYPE search();
```

List of parameters

There are no parameters.

## Return value

Returns the execution status which can be SUCCESS, FAILED, ABORTED or NOT_EXECUTED.
