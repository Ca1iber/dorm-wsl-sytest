# EVENT_WAVEFORM_VM.getSamples()

Queries the number of samples to capture.

## Syntax

```
void getSamples(INT & samples) const;
```

Parameter
 | Parameter  | Description |
 | samples |

Number of samples.

 |

Return value

There is no return value.
