# EVENT_VFIM

EVENT_VFIM (Voltage Force / Current Measurement Event) is a combined force/measure event class. These classes provide the combined functionality of force and measurement events in a single event.

Available event combinations are EVENT_VFIM and [EVENT_VFVM](<02.07.04.01.63.25_EVENT_VFVM.md>) (Voltage Force / Voltage Measurement Event). You can define combined voltage force/current measure events with all specific functions of [EVENT_VF](<02.07.04.01.63.23_EVENT_VF.md>) and [EVENT_IM](<02.07.04.01.63.12_EVENT_IM.md>).

## Class definition

The class derives from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

Per default these checks are off. If they are enabled and a checked clamp is hit, the event contributes with a FAIL to the global test result.

## Automatic down-ranging

DPS128 and XPS256 support automatic down-ranging current measurements.

Automatic down-ranging means that the current range is automatically changed to the best fit range for the measurement and restored to the original range after the measurement.

 Two parameters define whether the automatic down-ranging is performed or not:

- The force current or clamp current range:

  - Can be set explicitly or (if not defined)
  - is automatically derived from the forced or clamped value.

- The current measurement range:

  - Can be set explicitly or (if not defined)
  - is automatically derived from the pass/fail thresholds.

Automatic down-ranging is performed only if the current measurement range is lower than the force / clamp current range regardless whether the ranges have been set explicitly or have been selected automatically. For more information, refer to

## Example

Defines a combined voltage force / current measure event with limit checks:

```
EVENT_VFIM frcMeasEvent("frcV_MeasA");
frcMeasEvent.vForce(2.3 V);
frcMeasEvent.averages(8);
frcMeasEvent.limitLow(0 mA);
frcMeasEvent.limitHigh(100 mA);
```
