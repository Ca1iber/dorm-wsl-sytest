# Logical operators

The following operators have the semantics as within the C programming language.

## Logical negation - NOT (!)

The '!' operator is defined for boolean, integer and string parameters. It returns the logic negation of its operand.

boolean := ! boolean

boolean := ! integer

boolean := ! sequence

## Logical AND (&&)

The '&&' operator is defined for boolean parameters only. It returns the logic AND function of its operands.

boolean := boolean && boolean

An error is issued if a parameters is not of boolean type, for example, "011" && date[0..2] results in "Error: operators are not of tye boolean."

## Logical OR (||)

The '||' operator is defined for boolean parameters only. It returns the logic OR function of its operands.

boolean := boolean || boolean

An error is issued if a parameters is not of boolean type.
