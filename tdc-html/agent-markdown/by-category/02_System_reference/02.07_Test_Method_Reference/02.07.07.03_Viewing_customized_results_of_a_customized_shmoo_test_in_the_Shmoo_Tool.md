# Viewing customized results of a customized shmoo test in the Shmoo Tool

When you have [created a customized shmoo test method](<02.07.07.01_Creating_a_customized_shmoo_test_method.md>) and have [defined the results to be shown on a shmoo plot](<02.07.07.02.01_The_functions_of_the_customized_shmoo_test_method_template.md>) with the [SHMOO_RESULT](<02.07.04.01.227_SHMOO_RESULT.md>) API, you can use the [Shmoo Tool](<../02.08_Setup_and_Result_Tools/02.08.04.25_Shmoo_Tool.md>) to view the results.

## Before you begin

Open SmarTest.

## Procedure

-  [Create a customized shmoo test method](<02.07.07.01_Creating_a_customized_shmoo_test_method.md>).
-  In the test method file, in the [userDefinedMeasure()](<02.07.07.02.01_The_functions_of_the_customized_shmoo_test_method_template.md>) function, define the results to be displayed on a shmoo plot with the [SHMOO_RESULT](<02.07.04.01.227_SHMOO_RESULT.md>) API.
-  [Use the Shmoo Tool to create a customized shmoo test](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>) based on this test method.

Alternatively, create a shmoo test suite with this customized test method.

When configuring the testMode test method parameter, select "user defined measurement".

-  If the shmoo test is created with the Shmoo Tool, [execute the shmoo test in the Shmoo Tool](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.02.02_Test_modes.md>).

A shmoo plot displays in the corresponding shmoo editor in the editor view.

Go to step 6.

-  If you created a new shmoo test suite, [transfer the setups of the test suite to the Shmoo Tool](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.10.03_Transferring_test_suites_to_the_Shmoo_Tool.md>) and then [execute the shmoo test in the Shmoo Tool](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.02.02_Test_modes.md>).

The shmoo plot displays in the corresponding shmoo editor in the editor view

-  On the shmoo plot:

  - To view different results which you have defined with [SHMOO_RESULT.setResult()](<02.07.04.01.227.05_SHMOO_RESULT.setResult.md>) in the [userDefinedMeasure()](<02.07.07.02.01_The_functions_of_the_customized_shmoo_test_method_template.md>) function, right-click the shmoo plot and select Test Modes, and select your desired result.
  - To view different shmoo plot of different pins or pin groups which you have defined with [SHMOO_RESULT.pin()](<02.07.04.01.227.02_SHMOO_RESULT.pin.md>) in the [userDefinedMeasure()](<02.07.07.02.01_The_functions_of_the_customized_shmoo_test_method_template.md>) function, right-click the shmoo plot and select Result Pin, and select your desired pin or pin group.
  - To view different shmoo plots of different sites which you have defined with [SHMOO_RESULT.site()](<02.07.04.01.227.01_SHMOO_RESULT.site.md>) in the [userDefinedMeasure()](<02.07.07.02.01_The_functions_of_the_customized_shmoo_test_method_template.md>) function, see [Viewing different site's shmoo plot](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.04.07_Viewing_the_shmoo_plots_of_different_sites.md>).

## What to do next

In the Shmoo Tool:

- [Zoom the shmoo plot](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.04.02_Zooming_shmoo_plots.md>), [take a picture of the shmoo plot](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.06_Taking_a_picture_of_a_shmoo_test_in_the_Shmoo_Tool.md>), or [save the shmoo test](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.05_Saving_shmoo_tests_in_the_Shmoo_Tool.md>).
- Debug this shmoo test through adjusting its [setups](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>) in the corresponding Properties view.
