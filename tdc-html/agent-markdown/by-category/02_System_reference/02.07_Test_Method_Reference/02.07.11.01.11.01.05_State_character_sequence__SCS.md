# State character sequence (SCS)

State character sequences are strings of characters that will map to vector data.

Any ASCII character that can occur in the wavetable definition can as well occur in state character sequences.

Note 'R' cannot be used in a SCS because it is a reserved character which marks protocol fields to be read back from the DUT.

The use of state character pairs 0/1 and L/H makes a state character sequence special with regards to enabling specific arithmetic operations on them.
