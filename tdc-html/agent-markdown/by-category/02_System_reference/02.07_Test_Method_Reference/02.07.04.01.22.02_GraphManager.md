# GraphManager

The class `GraphManager` is a singleton server that manages all graphs and serves as the interface for creating, retrieving, modifying, and removing a graph.

Graphs can be modified as desired. However, any changes to a graph will not be reflected unless the setGraph() API is used to set the object into the Signal Analyzer. For example, if a user wants to view and change an axis label, the following steps are required:

- Get the Graph object from the GraphManager.
- If necessary, call Graph::getXAxis() or Graph::getYAxis() to get the Axis object.
- If necessary, call Axis::getLabel() to determine the current label.
- Call Axis::setLabel() to change the axis label.
- Call Graph::setXAxis() or Graph::setYAxis() to set the Axis object into the Graph object.
- CallGraphManager::setGraph().

Steps 2 and 3 are necessary only if the user wants to determine the current axis label.

## Constructors

### getInstance()

```
static GraphManager* getInstance();
```

This function gets an object of GraphManager. Since GraphManager class does not have a public constructor, using this method is the only way to get an object of GraphManager.

## Member functions

The member function are described in alphabetical order.

### createGraph()

```
int createGraph(const Graph & graph);
```

This function creates a graph with the specified `Graph` object. If the current task mode is DISPLAY or BOTH, a new graph will be created in the Data Display Panel and the waveform is displayed in the graph.

If the current task mode is FILE, graph information, including waveform data, will be stored into the directory "<device>/waveform/.result".

Parameter
 |

graph

 |

Graph object reference.

 |

### deleteGraph()

```
void deleteGraph(int id);
```

This function deletes (closes) the specified Data Display Panel. You must specify the graph ID explicitly.

Parameter

id

Identifier of each waveform display area. The value of the identifier is a positive integer. If a non-positive integer is passed, an exception is returned.

### setGraph()

```

```

This function sets a graph object into the specified waveform display area (Data Display Panel). In this method, the users must specify the graph ID explicitly.

If the current task mode is DISPLAY or BOTH, the waveform display area will be redrawn according to the contents of the graph object.

If the current task mode is FILE, graph information, including waveform data, will be stored into the directory "<device>/waveform/.result".

Parameters

graph

 |

 |
 |

id

 |

Identifier of a waveform display area. The value of the identifier is a positive integer. If a non-positive integer is passed, an exception is returned.

 |

### setTaskMode()

```
void setTaskMode(Display::TaskMode mode);
```

This method specifies a task mode used for storing and displaying waveform data.

Parameter
 |

mode

 |

The task mode to store and display waveform data. It can be

- Display::NONE: The Data Display API does nothing.
- (default)Display::FILE: Waveform data is always stored into the directory "<device>/waveform/.result". The waveform data can be viewed in the Waveform Navigator Tool after task execution.
- Display::DISPLAY: Waveform data is directly displayed in a waveform display area, but the waveform data will not be stored.
- Display::BOTH: Waveform data is always stored into the directory "<device>/waveform/.result" and the waveform data is directly displayed in a waveform display area.Note Waveform data can be stored or set into the tool using GraphManager::setGraph(), GraphManager::createGraph(), and GraphManager::setSelectedGraph().
 |

## Examples

### Copy from a graph

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graphManager->setGraph(graph, 2);
```

This example copies graph 1 to graph 2.

### Close graphs

```
try
{
  GraphManager * graphManager = GraphManager::getInstance();
  vector<int> identifiers = graphManager->getGraphIds();
  int size = identifiers.size();
  // Close all existing waveform display areas
  for (int i = 0; i < size; i++)
  {
    graphManager->deleteGraph(identifiers[i]);
  }

}
catch (GraphException & e)
{
  e.printError();
}

```

This example closes all the graphs in the Signal Analyzer. If any error occurs, it will be caught and printed in the UI report window and system console.
