# FOR_EACH_SITE_END

This API declares the end of the each site loop block that is started by FOR_EACH_SITE_BEGIN.

This API is used together with FOR_EACH_SITE_BEGIN as a pair to declare the each site loop block.

For details on the each site loop block enclosed by FOR_EACH_SITE_BEGIN and FOR_EACH_SITE_END, see [FOR_EACH_SITE_BEGIN](<02.07.04.01.70_FOR_EACH_SITE_BEGIN.md>).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/MapiUtil.h.

## Syntax

```
FOR_EACH_SITE_END();
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Example

See the examples in [FOR_EACH_SITE_BEGIN](<02.07.04.01.70_FOR_EACH_SITE_BEGIN.md>).
