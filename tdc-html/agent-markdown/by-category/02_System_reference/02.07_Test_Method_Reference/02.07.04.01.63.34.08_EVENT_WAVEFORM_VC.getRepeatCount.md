# EVENT_WAVEFORM_VC.getRepeatCount()

Reads the number of repeats of the waveform that has been defined by [EVENT_WAVEFORM_VC.vClampLow()](<02.07.04.01.63.34.01_EVENT_WAVEFORM_VC.vClampLow.md>) or [EVENT_WAVEFORM_VC.vClampHigh()](<02.07.04.01.63.34.03_EVENT_WAVEFORM_VC.vClampHigh.md>).

The number of repeats is read from the corresponding [EVENT_WAVEFORM_VC](<02.07.04.01.63.34_EVENT_WAVEFORM_VC.md>) object and returned as an integer value.

## Syntax

```
void getRepeatCount(INT & repeats) const;
```

  Parameter

 | Parameter  | Description |
 | repeats |

The read repeat count.

Note: The member function getRepeatCount() of DC events returns always 1 as repeat count.

  |  Return value There is no return value.

## Example

For an example see [EVENT_WAVEFORM_VC](<02.07.04.01.63.34_EVENT_WAVEFORM_VC.md>).
