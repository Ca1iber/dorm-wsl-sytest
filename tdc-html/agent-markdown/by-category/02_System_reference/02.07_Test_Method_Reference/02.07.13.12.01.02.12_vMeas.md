# vMeas()

Specifies a voltage measurement.

## Syntax

```
vMeas();
```

   Note When you use this function on multiports, if pins from different ports share the same BADC, you must use [rdi.portSync()](<02.07.13.08.08.02_portSync.md>) to ensure the sequence of pins' access to the BADC is correct.

## Example

```
rdi.dc("vMeas").pin("pinA",TA::BADC).vMeas().execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
