# step()

This function specifies how many steps that you want a binary or linear search to go into the pattern. See [Sequencer-controlled searching with cogo](<02.07.13.19.02_Sequencer-controlled_searching_with_cogo.md>) for more information about step.

## Syntax

```
step(int iStep)
```

List of parameters
 |

Parameter

 |

Description

 |
 |

iStep

 |

The number of steps to be executed.

 |

## Example

```
rdi.cogo().search(TA::BINARY).pathPin("pinA").start(0).stop(4.0).init(1.0).step(3).blockBegin();
```

## Functional changes

- Introduced in SmartRDI 2.4.0
