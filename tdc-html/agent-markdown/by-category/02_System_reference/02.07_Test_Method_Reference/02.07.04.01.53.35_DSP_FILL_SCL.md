# DSP_FILL_SCL

This API fills an array with a specified scalar value.

DSP_FILL_SCL stores a scalar value into 0-th to (size-1)-th elements of result.

For processing complex values, DSP_FILL_SCL stores scalar values (value_re and value_im) into 0-th to (size-1)-th elements of result.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_FILL_SCL(INT value, ARRAY_I& result);
DSP_FILL_SCL(INT value, INT *result, INT size);
DSP_FILL_SCL(DOUBLE value, ARRAY_D& result);
DSP_FILL_SCL(DOUBLE value, DOUBLE *result,
             INT size);
DSP_FILL_SCL(DOUBLE value_re, DOUBLE value_im,
             ARRAY_COMPLEX& result);
DSP_FILL_SCL(DOUBLE value_re, DOUBLE value_im,
             COMPLEX *result, INT size);
```

## Example

```
INT  result[1024];
     .
     .
DSP_FILL_SCL(0, result, 512);
```

DSP_FILL_SCL stores the scalar value "0" into the first 512 elements of result as follows:

```
result[0]=0, result[1]=0, ..., result[511]=0
COMPLEX  result[256];
     .
     .
DSP_FILL_SCL(5.0, 7.0, result, 128);
```

The scalar values "5.0" and "7.0" are stored into the first 128 elements of result[].real and result[].imag as follows:

```
result[0].real=5.0,
result[1].real=5.0,
...,
result[127].real=5.0

result[0].imag=7.0,
result[1].imag=7.0,
...,
result[127].imag=7.0
```
