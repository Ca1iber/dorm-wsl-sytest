# DSP_A_DECODE

This API decodes the contents of a specified array using the A-law conversion method.

[Encoding/Decoding Table for A-Law/碌-Law](<02.07.04.03_Encoding_Decoding_Table_for_A-Law__-Law.md>) lists the decoding format of the A-law conversion used by this API. Also, refer to [Code Format Tables](<02.07.04.04_Code_Format_Tables.md>) for the two's complement and A-law code format.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_A_DECODE(ARRAY_I& src, ARRAY_D& result,
             INT input_format);
DSP_A_DECODE(INT *src, DOUBLE *result, INT size,
             INT input_format);
```

## Example

```
int array1[500];
double array2[500];
  .
  .
DSP_A_DECODE(array1, array2, 500, CMPLM2);
```

DSP_A_DECODE decodes INT array array1 , which contains 8-bit A-law data (two's complement code format), and returns the results to DOUBLE array array2. In this example, 500 elements in array1 are decoded.
