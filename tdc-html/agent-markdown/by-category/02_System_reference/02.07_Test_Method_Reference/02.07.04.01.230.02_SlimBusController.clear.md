# SlimBusController.clear()

This function resets the SlimBusController() object for a new SLIMbus test.

## Syntax

```
void clear ();
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Functional changes

- Introduced in SmarTest 7.2.1
