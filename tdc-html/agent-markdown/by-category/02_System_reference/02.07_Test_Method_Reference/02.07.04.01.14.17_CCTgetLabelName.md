# CCTgetLabelName

Returns the label name.

In concurrent mode ([CCF_Concurrent](<02.07.08.05_Testflow_variables.md>) = 1), it returns the merged multiport burst label name specified for [CCF_LabelName](<02.07.08.04_Test_method_parameters.md>) in the execution test suite of the CCF block.

In serial mode ([CCF_Concurrent](<02.07.08.05_Testflow_variables.md>) = 0), it returns the label name specified in the current test suite.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
string CCTgetLabelName();
```

List of parameters

There are no parameters.

## Return value

The label name is returned.

## Functional changes

- Introduced in SmarTest 7.2.0
