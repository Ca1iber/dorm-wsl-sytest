# rdi.func().burstId()

This function assigns ID to a pattern burst test. After the testing, this function stores the pass/fail results of a pin, a group of pins, all pins or a port to buffer.

You must use this function before the setup of a burst pattern test. To read the result from the buffer, use `rdi.id().getBurstPassFail()` at any time in your test method. See [id()](<02.07.13.17.01.14_rdi.id__.getBurstPassFail.md>) and [rdi.getBurstPassFail()](<02.07.13.17.01.13_rdi.getBurstPassFail.md>) for more information.

You must place this function inside an `RDI_BEGIN()/RDI_END()` block, otherwise `rdi.id().getBurstPassFail()` always returns a PASS result.

 Note If the [SmartRDI alarm handling](<02.07.13.09_SmartRDI__Alarm_handling_for_DCVI.md>) is used, the burst pass/fail result is impacted by an alarm fail. This means if an alarm check fails, the burst result will fail too.

## Syntax

```
void rdi.func().burstId(string burstId, string resultPins);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

burstId

 |

The ID assigned to a burst pattern test.

 |
 |

resultPins

 |

A pin, multiple pins, the name of a pin group or a port to generate the pass/fail test result.

If no pin is specified, all pins are used by default.

  Note Any ID specified in rdi.burstId() must match those result IDs specified in getBurstPassFail(). For example, if a pin group ID is specified in burstId(), you must use the group ID in getBurstPassFail(). If you use an ID of a pin from the group, getBurstPassFail() cannot return the result for the pin. |

## Examples

### Generic example

```
{
...
ON_FIRST_INVOCATION_BEGIN();

  RDI_BEGIN();
    rdi.burstId("bid1","pinA,pinB");
    // Burst pattern setups and execution
    ...
  RDI_END();

  RDI_BEGIN();
    rdi.burstId("bid2","pinGrpAB");
    // Burst pattern setups and execution
    ...
  RDI_END();

ON_FIRST_INVOCATION_END();

  int result = rdi.id("bid1").getBurstPassFail("pinA"); // Retrieve the burst pattern test result from pinA.
  int result = rdi.id("bid1").getBurstPassFail("pinB"); // Retrieve the burst pattern test result from pinB.
  int result = rdi.id("bid2").getBurstPassFail("pinGrpAB"); // Retrieve the burst pattern test result from the pin group.
  int resultALL = rdi.id("bid1").getBurstPassFail();    // Retrieve the burst pattern test result from all pins.
...
}
```

### For a port ID

```
RDI_BEGIN();
  rdi.burstId("idA","ptA"); // ptA is a port
  rdi.func()...
  rdi.dc()...
  rdi.smartVec()...
  ...
RDI_END();

rdi.id("idA").getBurstPassFail("ptA");
```
