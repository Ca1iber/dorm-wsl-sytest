# SMC_UPLOAD_STATUS.handle()

Returns the result handle for a WaveformUploadTask. This information is stored in a vector that is populated by [SMC_GET_UPLOAD_STATUS()](<02.07.04.01.231.16_SMC_GET_UPLOAD_STATUS.md>).

## Syntax

```
const STRING& handle() const;
```

List of parameters

There are no parameters.

## Return value

Returns the result handle for a WaveformUploadTask. For all other upload types an empty string is returned.

## Example

This example shows how to create a vector of type `SMC_UPLOAD_STATUS` and how to retrieve the result handle from the vector.

Note As `SMC_UPLOAD_STATUS` represents a collection, one has to iterate over the collection to obtain the item.

```
typedef vector<SMC_UPLOAD_STATUS> SmcUploadStatusVector;
string ResultHandle;

// Obtain the collection
SmcUploadStatusVector statusVector = SMC_GET_UPLOAD_STATUS();

// iterate through collection
for(SmcUploadStatusVector::iterator it = statusVector.begin();
     it != statusVector.end(); ++it) {
        ResultHandle = it->handle();
        cout << "SMC upload type:" << ResultHandle << endl;
     }
```
