# DC_WAVEFORM.sampleVectorDistance()

This function specifies a number of vectors between DC waveform points.

 Note The distance specified by the user has to be a common multiple of 8 and larger than or equal to 16. Otherwise an error message will be issued.

Internally PPMU events cause break vectors. The sample vector distance is internally the number of vectors specified by the customer minus the vectors needed for the PPMU events.

## Syntax

```
DC_WAVEFORM & sampleVectorDistance(INT distance);
```

Parameter
 |

Parameter

 |

Description

 |
 |

distance

 |

The number of vectors between DC waveform points.

 |

## Return value

The number of vectors is returned.
