# passNode()

Defines the pass branch for [insertJmpe()](<02.07.13.24.20_insertJmpe.md>).

## Syntax

```
passNode();
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Example

```
RDI_BEGIN();
...
    rdi.smartVec...
    .insertJmpe(2).passNode().pin("DATA1").writeData(0x0,8,0)...execute();
...
RDI_END();
```
