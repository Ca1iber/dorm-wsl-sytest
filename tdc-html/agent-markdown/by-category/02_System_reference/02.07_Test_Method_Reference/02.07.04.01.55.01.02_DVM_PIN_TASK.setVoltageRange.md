# DVM_PIN_TASK.setVoltageRange()

The setVoltageRange() member function sets the voltage range for the measurement.

## Syntax

```
DVM_PIN_TASK & setVoltageRange ( const double range )
```

Parameter
 |

Parameter

 |

Description

 |
 |

range

 |

Voltage range to be used for the measurement. The default is 10 V.

 |

## Return value

Returns a reference to the [DVM_PIN_TASK](<02.07.04.01.55.01_DVM_PIN_TASK.md>) object.
