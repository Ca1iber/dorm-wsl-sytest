# Color

The Color class is used to encapsulate colors in the RGB color space or colors defined by Display::Color enumeration.

Every color has an implicit alpha value or an explicit one provided in the constructor. The alpha value defines the transparency of a color and can be represented by 0 - 255. An alpha value 255 means that the color is completely opaque and an alpha value 0 means that the color is completely transparent.

## Class definition

### Constructor

```
Color();

Color(int r, int g, int b);
Color(const Color & color);

const Color & operator=(const Color & color);
```

```
int getRed(void) const;
```

### Syntax

```
Color obj;

```

where `obj` is an object of `Color` and `func` is one of the member functions of `Color`.

### Constructor

```
Color();
Color(int rgb);
Color(int r, int g, int b);

```

These constructors create an object of Color. You can specify the color information when creating the object.

## Member functions

### getRed()

```
int getRed(void) const;
```

This function returns the red component of the Color object.

### getGreen()

```
int getGreen(void) const;
```

This function returns the green component of the Color object.

### getBlue()

```
int getBlue(void) const;
```

This function returns the blue component of the Color object.

### getColor()

```
Display::Color getColor(void) const;
```

This function returns the color in the format defined by `Display::Color`. It can be one of the options defined in the `Display::Color` enumeration.

### getRGBColor()

```
const Color & getRGBColor(void) const;
```

This function returns a Color object to represent the RGB color.

### getRGBInteger()

```
int getRGBInteger(void) const;
```

This function returns an integer to represent the RGB color.

## Examples

### Change Cursor Color

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
Cursor cursor = graph.getCursor();
cursor.setXMeasureColor(Display::WHITE);
cursor.setYMeasureColor(Display::GREEN);
cursor.setXReferenceColor(Display::RED);
cursor.setYReferenceColor(Display::BLUE);
graph.setCursor(cursor);
graphManager->setGraph(graph, 1);
```

This example sets the cursors of graph 1 to white, green, red and blue respectively.

### Change Line Color

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getSelectedGraph();
 // The line color of 1st trace is red
graph.getTrace(1).setColor(Display::RED);
// The line color of 2nd trace is blue
graph.getTrace(2).setColor(Display::BLUE);
graphManager->setSelectedGraph(graph);
```

This example changes the color of trace 1 to red and the color trace 2 to blue in the selected graph.
