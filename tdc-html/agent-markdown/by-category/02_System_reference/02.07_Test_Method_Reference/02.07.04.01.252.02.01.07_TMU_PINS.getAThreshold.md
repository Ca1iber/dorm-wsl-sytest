# TMU_PINS.getAThreshold()

Returns the voltage threshold of the first shot is returned.

## Syntax

```
DOUBLE getAThreshold() const;
```

List of parameters

There are no parameters.

## Return value

The voltage threshold of the first shot. The unit is volts.
