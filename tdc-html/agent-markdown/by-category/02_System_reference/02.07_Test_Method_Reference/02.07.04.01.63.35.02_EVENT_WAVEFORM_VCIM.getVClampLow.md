# EVENT_WAVEFORM_VCIM.getVClampLow()

Queries the lower clamp voltage waveform that has been defined by [EVENT_WAVEFORM_VCIM.vClampLow()](<02.07.04.01.63.35.01_EVENT_WAVEFORM_VCIM.vClampLow.md>).

The waveform is read from the corresponding [EVENT_WAVEFORM_VCIM](<02.07.04.01.63.35_EVENT_WAVEFORM_VCIM.md>) object and returned as an [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
const ARRAY_D & getVClampLow() const;
```

## Return value

An [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>) object containing the waveform samples that are defined in V (Volt).
