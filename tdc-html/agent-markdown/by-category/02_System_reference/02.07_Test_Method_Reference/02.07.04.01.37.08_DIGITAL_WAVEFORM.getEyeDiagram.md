# DIGITAL_WAVEFORM.getEyeDiagram()

This function returns the eye diagram data as two ARRAY_D for the specified pin. xdata is the data which represents the relative time at the sampling point. ydata is the voltage data. It's created from the waveform data retrieved in the previous execution of the method execute(). The method resizes ARRAY_D.

## Syntax

```
void getEyeDiagram(const STRING& pin, TM::SE_DIFF_MODE mode,
                   ARRAY_D xdata, ARRAY_D& ydata) const
void getEyeDiagram(const STRING & pin, TM::SE_DIFF_MODE mode,
                   ARRAY_D & xdata,
                   ARRAY_D & ydata,
                   const bool relative2UI) const;
```

Parameters
 |

pin

 |

The pin on which eye mask test is performed.

 |
 |

mode

 |

The signal mode. It can be:

- TM::SINGLE_ENDED: (for single-ended signals) The eye diagram voltage is referenced to the common(digital) ground.
- TM::DIFF_SWING: (for differential signals) The eye diagram voltage is the voltage difference between the positive pin and negative pin (Vpos-Vneg).
- TM::DIFF_COMMON: (for differential signals with common ground) The eye diagram voltage is (Vpos+Vneg)/2.
 |
 |

xdata

 |

The data representing the relative time in 1 UI.

 |
 |

ydata

 |

The voltage values at each time point.

 |
 |

relative2UI

 |

(optional) Whether the eye diagram is 1 UI or 2 UI. It can be

- true: 2 UI
- false or not specified: 1 UI
 |

## Functional changes

- Introduced before SmarTest 6.3.2
