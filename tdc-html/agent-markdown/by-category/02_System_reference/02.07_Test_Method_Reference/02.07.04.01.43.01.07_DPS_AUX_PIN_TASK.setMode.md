# DPS_AUX_PIN_TASK.setMode()

The DPS_AUX_PIN_TASK.setMode() member function sets the surge tracker operating mode or selects the TMU (Time Measure Unit) comparator pair of DC Scale cards.

 Supported DC Scale cards:

- Surge tracker: [DPS128/DPS64](<../02.05_Test_Head_Cards/02.05.05.01.03_DPS128____PS64_functionality_and_features.md>) and [XPS256](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>)
- TMU (Time Measure Unit): Currently not supported.

The setMode() member function can be called without threshold setting. See [selectVSensorSetThresholds()](<02.07.04.01.43.01.06_DPS_AUX_PIN_TASK.selectVSensorSetThresholds.md>) and [selectISensorSetThresholds()](<02.07.04.01.43.01.05_DPS_AUX_PIN_TASK.selectISensorSetThresholds.md>)

If the member function is called within a [FOR_EACH_SITE](<02.07.04.01.70_FOR_EACH_SITE_BEGIN.md>) loop, all active sites will be set to the same mode and a warning is issued in the report window:

```
INFO: calling DPS_AUX_PIN_TASK::setMode() within a ...
   ...FOR_EACH_SITE block will change the mode for all sites!
```

## Syntax

```
DPS_AUX_PIN_TASK & setMode(TM::SURGE_TRACKER_MODE mode);
```

  Parameter

 | Parameter  | Description |
 | mode  | Selects the comparator mode. |

Available options of parameter: mode
 | Option  | Description |
 | TM::DPS_AUX_OFF  | Sets the comparator pair to off. |
 | TM::SURGE_TRACKER  | Sets the surge tracker function to on. The latched status flag is reset. |
 | TM::CMP_HIGH  | Used for match loops. Compares against the thresholds defined by [DPS_AUX_PIN_TASK.selectVSensorSetThresholds()](<02.07.04.01.43.01.06_DPS_AUX_PIN_TASK.selectVSensorSetThresholds.md>) or [DPS_AUX_PIN_TASK.selectISensorSetThresholds()](<02.07.04.01.43.01.05_DPS_AUX_PIN_TASK.selectISensorSetThresholds.md>). |
 | TM::TO_TMU  | Sets the TMU (Time Measure Unit) function to on.  |   Return value A reference to the corresponding [DPS_AUX_PIN_TASK](<02.07.04.01.43.01_DPS_AUX_PIN_TASK.md>) object.

## Example

The example below shows the setting of the low and high current thresholds and the activation of the surge tracker function.

```
DPS_AUX_TASK auxTask;

ON_FIRST_INVOCATION_BEGIN();

    //
    // Set the current thresholds to -1 mA/1 mA and switch on surge tracker
    //
    auxTask.pin("dps1")
        .selectISensorSetThresholds(-1 mA, 1 mA)
        .setMode(TM::SURGE_TRACKER);

    auxTask.execute();

ON_FIRST_INVOCATION_END();
```

For an extended example see [DPS_AUX_TASK](<02.07.04.01.43_DPS_AUX_TASK.md>).
