# rdi.alarm().enable()

Enables or disables alarm checking on all pins. This API only impacts the test suite where it is located. The next test suite will resume the default setting.

## Syntax

```
rdi.alarm().enable(bool);
```

List of parameters
 | Parameter  | Description |
 | true  | Enable alarm checking on all the pins within the alarm set. |
 | false  | Disable alarm checking on pins |

This command can be put either inside or outside an RDI_BEGIN()/RDI_END() block.

When rdi.alarm().enable(false); is put outside an RDI_BEGIN()/RDI_END() block, rdi.id("id").getAlarmPassFail(); returns -1.

 When rdi.alarm().enable(false); is put inside an RDI_BEGIN()/RDI_END() block, rdi.id("id").getAlarmPassFail(); returns the actual result. If the result is pass, 1 is returned; otherwise, 0 returned.
