# Setting Testflow Variables

To set the testflow variables such as user flags, string variables, and double variables, you can use the following APIs:

 |

The task to be executed....

 |

Use this API....

 |
 |

Provide access to the user flag

 |

[SET_USER_FLAG(params)](<02.07.04.01.221_SET_USER_FLAG.md>)

 |
 |

Provide access to the user double variable

 |

[SET_USER_DOUBLE(params)](<02.07.04.01.220_SET_USER_DOUBLE.md>)

 |
 |

Provide access to the user string variable

 |

[SET_USER_STRING(params)](<02.07.04.01.222_SET_USER_STRING.md>)

   |  Note params means the parameters to be specified.
