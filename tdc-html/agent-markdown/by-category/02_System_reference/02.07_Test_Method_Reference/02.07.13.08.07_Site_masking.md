# Site masking

#### Subtopics

- [Automatic masking on inactive sites](<02.07.13.08.07.01_Automatic_masking_on_inactive_sites.md>)
- [Active site on hold](<02.07.13.08.07.02_Active_site_on_hold.md>)

SmartRDI can automatically mask inactive sites within one test suite. These masked inactive sites are on a hold state and remain the state until the end of the test suite execution. When the hold state is cleared, these sites resume their previous conditions in test.

## Functional changes

- Introduced in SmartRDI 7.10.3
