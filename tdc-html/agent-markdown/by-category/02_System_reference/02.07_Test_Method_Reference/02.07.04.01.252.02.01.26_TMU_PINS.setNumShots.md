# TMU_PINS.setNumShots()

Sets the number of shots. The number of shots is used to calculate the amount of result memory needed to store the results of all shots. The calculation is executed directly before the first shot (functional test).

SmarTest automatically toggles the thresholds if they are part of the TMU setup. Threshold B is only used for the second shot. If the number of shots is set to 2, both thresholds must be set. In this case the TMU_TASK must be executed for each shot. All results can be uploaded with the TMU_TASK object or using TMU_PINS object for each shot. For an example of using multiple shots, see [Example 4: TMU pin result flat uploading](<02.07.04.01.252_TMU_TASK.md#_125624__ex_TMU_pin_result_flat_uploading>).

## Syntax
