# runTimeVal()

Specifies the value to be used at runtime.

## For protocol or smartVec test

```
runTimeVal(const string& name, const ARRAY_I& value);
runTimeVal(const string& name, const ARRAY_LL& value);
runTimeVal(const string& name, const long long value);
runTimeVal(const string& name, const ARRAY_D &value);
runTimeVal(const string& name, const double value);
runTimeVal(const string& name, const int value);
runTimeVal(const string& name, vector<ARRAY_I> &value);
runTimeVal(const string& name, vector<ARRAY_LL> &value);
runTimeVal(const string& name, vector<vector<string>> &value);
```

## For digital channel relay control

 Sometimes relay actions are based on a previous result, or needs to be site dependent. For this purpose, SmartRDI provides the following commands to support runtime values for digital relays:

- [setOnRunTime()](<02.07.13.14.06_setOnRunTime.md>)
- [setOffRunTime()](<02.07.13.14.04_setOffRunTime.md>)
- `runTimeVal()`

```
runTimeVal(string runTimeValueString, vector <string> runTimeAction);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

runTimeValueString

 |

The string defines the runtime value.

 |
 |

runTimeAction

 |

The string defines the runtime actions. It can be any combination of the strings:

- "DC"
- "AC"
- "PPMU"

separated by a comma (",").

Only the values introduced here are acceptable.

Starting from SmartRDI 7.6.0, The "NO" action value is supported by [hwRelay](<02.07.13.14_SmartRDI__Digital_channel_relay_control.md>). "NO" means No Change. If you intend to open a type of relay on one site while close the same type of relay on another, you can use "NO" in runtime.

"NO" only works for [setOnRunTime()](<02.07.13.14.06_setOnRunTime.md>) and [setOffRunTime()](<02.07.13.14.04_setOffRunTime.md>). When "NO" is used, [setOnRunTime()](<02.07.13.14.06_setOnRunTime.md>) and [setOffRunTime()](<02.07.13.14.04_setOffRunTime.md>) must be used together.

For the relay of each site, the combination actions of [setOn()](<02.07.13.14.05_setOn.md>) and [setOff()](<02.07.13.14.03_setOff.md>) cannot have NO change.

See the [Example](<02.07.13.08.03.01_runTimeVal.md#_144754__Example_2>)

 |

## Examples

Using different values for different sites

```
ARRAY_D rtv_arr(4);
rtv_arr[0]=1.0;
rtv_arr[1]=1.1;
rtv_arr[2]=1.2;
rtv_arr[3]=1.3;

rdi.runTimeVal("rtv",rtv_arr);
```

Using the same value for all sites

```
double vol; vol=1.5;
rdi.runTimeVal("vvv",vol);
```

Controlling relays

```
vector <string> rtRelay(2); // 2 sites
  rtRelay[0] = "AC";        // AC relay on site 1 is selected
  rtRelay[1] = "PPMU";      // PPMU relay on site 2 is selected

rdi.runTimeVal("rtd", rtRelay);

RDI_BEGIN();
  rdi.hwRelay().pin().setOnRunTime("rtd").execute();
RDI_END();
```

   "NO" action on one site and some action on another in runtime

```
vector<string> vecOn(2), vecOff(2); //2 sites
  vecOn[0]="NO";  vecOn[1]="AC";
  vecOff[0]="AC"; vecOff[1]="NO";

rdi.runTimeVal("rt1",vecOn);
rdi.runTimeVal("rt2",vecOff);

//----------- site1 opens AC; site2 closes AC----------------------------
RDI_BEGIN();
  rdi.hwRelay().pin("A").setOnRunTime("rt1").setOffRunTime("rt2").execute();
RDI_END();
```

   Alarm checking on pins using runTimeVal()

```
...
rdi.runTimeVal("rtvForce", rtvForce);
rdi.dc().pin("rtvPin").vForce(0 V).iClamp(50 uA).execute();

RDI_BEGIN();
  ...
  rdi.dc("id").pin("rtvPin").vForce("rtvForce").iClamp(50 uA)
                            .vMeas().measwait(100 us).execute();
  ...
RDI_END();
```

See [Alarm checking on pins using runTimeVal()](<02.07.13.09_SmartRDI__Alarm_handling_for_DCVI.md#_345141__alarm_check_on_pins_with_runTimeVal>)

   Runtime vector editing

```
ARRAY_I trimData = ... // based on previous measurement.
rdi.runTimeVal("trimValue", trimData);

RDI_BEGIN();
  ...
  rdi.smartVec().pin(pinA).writeData("trimValue",8).execute();
  ...
RDI_END();
```
