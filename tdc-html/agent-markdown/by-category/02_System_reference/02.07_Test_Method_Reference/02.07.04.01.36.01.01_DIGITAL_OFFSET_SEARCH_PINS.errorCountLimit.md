# DIGITAL_OFFSET_SEARCH_PINS.errorCountLimit()

Sets an error count limit for considering a test pass or fail. If the error count of a test is greater than this limit, the test is considered fail.

Use this member function after you have set up DIGITAL_OFFSET_SEARCH::ECL in [DIGITAL_OFFSET_SEARCH_PINS.transitionDetection()](<02.07.04.01.36.01.27_DIGITAL_OFFSET_SEARCH_PINS.transitionDetection.md>).

## Syntax

```
DIGITAL_OFFSET_SEARCH_PINS& errorCountLimit(INT errorcountlimit);
```

Parameter
 |

Parameter

 |

Description

 |
 |

errorcountlimit

 |

A number used as an error count limit. The default number is 1.

If an error count of a test is greater than this limit, the test is considered fail.

 |

## Return value

A reference to the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) object.
