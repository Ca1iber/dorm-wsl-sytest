# Match loop support

#### Subtopics

- [Inserting MACT and MRPT in a smartVec label](<02.07.13.24.49.01_Inserting_MACT_and_MRPT_in_a_smartVec_label.md>)
- [Creating a match loop pattern from logical data](<02.07.13.24.49.02_Creating_a_match_loop_pattern_from_logical_data.md>)
- [Retrieving match loop results](<02.07.13.24.49.03_Retrieving_match_loop_results.md>)

SmartRDI provides functions to support match loops for the `smartVec()` class.

Features:

- Inserting MACT and MRPT in a smartVec label.
- Creating a match loop pattern from logical data.
- Retrieving match loop results.

Functions:

- instruction()
- matchData()
- matchBit()
- matchCycle()
- readMatchCount()
- readMatchPassFail()
- getMatchCount()
- getMatchPassFail()
