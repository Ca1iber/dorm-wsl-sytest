# EVENT_ICIM.averages()

Sets the number of internal DC measurement samples for hardware based averaging.

## Syntax

```
EVENT_ICIM & averages (const EVENT_VALUE_INT & samples);
```

Parameter
 | Parameter  | Description |
 | samples |

Number of internal samples from which the average is created.

For DC Scale channels, with exception of XPS256, the number of samples must be a power of 2.

 |

Return value

There is no return value.
