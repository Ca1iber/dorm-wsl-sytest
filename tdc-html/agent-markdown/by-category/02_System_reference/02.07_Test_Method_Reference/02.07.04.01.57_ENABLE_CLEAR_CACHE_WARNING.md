# ENABLE_CLEAR_CACHE_WARNING

This API restores the default behavior by which a warning is issued when the test method cache is cleared.

It can be used after suppressing the warning with the DISABLE_CLEAR_CACHE_WARNING API.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

## Syntax

```
ENABLE_CLEAR_CACHE_WARNING();
```

List of parameters

There are no parameters.

## Example

```
ENABLE_CLEAR_CACHE_WARNING();
```

The ENABLE_CLEAR_CACHE_WARNING API causes a warning to be issued when the test method cache is cleared. This is also the default behavior, which can be changed with the DISABLE_CLEAR_CACHE_WARNING API.

## Functional changes

- Introduced before SmarTest 6.3.2
