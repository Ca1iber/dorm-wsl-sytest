# DPS_AUX_PIN_TASK.checkPowerFlags()

Reads the accumulated power supply status flags from the hardware. The flags are supported by DC Scale cards in DPS operating mode, in PMU operating mode.

The member function reads the flags from all active sites. Refer to [DPS power flags - get...() functions](<02.07.04.01.43.06_DPS_power_flags_-_get...___functions.md>) for more information regarding the supported flags and the meaning of the flags.

Note The flags are latched in the hardware. Reading the state will return the latched state and clear only the read flags. The flags are immediately set again if the triggering condition is still active. The member function must therefore be called twice to read the actual state. Note Pass / fail results that are retrieved by command [PRLT](<../02.06_Command_Reference/02.06.02.02.183_PRLT__-__request_Parallel_ResuLTs.md>) are invalidated by commands [CSAS](<../02.06_Command_Reference/02.06.02.02.33_CSAS__-__Channel_Slot_Accumulated_Status.md>) and [PSAS](<../02.06_Command_Reference/02.06.02.02.188_PSAS__-__Power_Supply_Accumulated_Status.md>). We recommend therefore using the command PRLT directly after the related functional test and before command CSAS or PSAS are performed. This behavior applies not only to the commands but also to the related APIs: Function [GET_FUNCTIONAL_RESULT()](<02.07.04.01.88_GET_FUNCTIONAL_RESULT.md>) must be performed before any of the [DPS_AUX_PIN_TASK.check...()](<02.07.04.01.43.01_DPS_AUX_PIN_TASK.md>) functions is called or the results of GET_FUNCTIONAL_RESULT() are invalid.

## Syntax

```
DPS_AUX_PIN_TASK& checkPowerFlags(TM::POWER_FLAG flags = TM::ALL_FLAGS);
```

 | flags  | The optional parameter defines a read mask for the power supply flags.

## Return value

A reference to the corresponding [DPS_AUX_PIN_TASK](<02.07.04.01.43.01_DPS_AUX_PIN_TASK.md>) object.

For retrieving the read result see [DPS power flags - get...() functions](<02.07.04.01.43.06_DPS_power_flags_-_get...___functions.md>).

## Example

The following example reads the actual state of all power flags, clears all flags and evaluates the state of all flags except the "Constant Voltage" flag. The returned value is set to TM::POWER_FLAG_STATUS_FAIL if minimum one of the checked flags is set.

```
DPS_AUX_TASK dpsAuxTask_1;

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Read actual power flag status of two pins
    //
    dpsAuxTask_1.pin("dps1,dps2").checkPowerFlags(); // Read latched state & clear all flags
    dpsAuxTask_1.pin("dps1,dps2").checkPowerFlags(); // Read actual state & clear all flags
}
ON_FIRST_INVOCATION_END();

//
// Evaluate the state of the first pin
//
if (dpsAuxTask_1.getStatusWithoutConstVol("dps1") == TM::POWER_FLAG_STATUS_PASS)
{
    cout << "dpsAuxTask_1.getStatusWithoutConstVol(\"dps1\") returned TM::POWER_FLAG_STATUS_PASS" << endl;
}
else
{
    cout << "dpsAuxTask_1.getStatusWithoutConstVol(\"dps1\") returned TM::POWER_FLAG_STATUS_FAIL" << endl;
}

return;
```

The next example reads, clears and evaluates the latched state of the "Low Headroom" flag. The other flags are not cleared or evaluated.

```

DPS_AUX_TASK dpsAuxTask_2;

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Read and clear latched low headroom flag of two pins
    //
    dpsAuxTask_2.pin("dps1,dps2").checkPowerFlags(TM::LOW_HEADROOM);
}
ON_FIRST_INVOCATION_END();

//
// Evaluate the state of the first pin
//
if (dpsAuxTask_2.getLowHeadroom("dps1") == TM::POWER_FLAG_STATUS_PASS)
{
    cout << "dpsAuxTask_2.getLowHeadroom(\"dps1\") returned TM::POWER_FLAG_STATUS_PASS" << endl;
}
else
{
    cout << "dpsAuxTask_2.getLowHeadroom(\"dps1\") returned TM::POWER_FLAG_STATUS_FAIL" << endl;
}

return;
```
