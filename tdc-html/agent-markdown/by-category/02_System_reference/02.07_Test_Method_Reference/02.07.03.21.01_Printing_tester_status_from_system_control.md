# Printing tester status from system control

#### Subtopics

- [Comparing tester status from system console](<02.07.03.21.01.01_Comparing_tester_status_from_system_console.md>)

SmarTest Work Center provides a button to quickly retrieve tester status in the System console.

## About this task

The Print Tester Status button lets you output the current settings of all instruments at any time.

## Before you begin

Check that your SmarTest has a version no less than 7.5.2.

Make sure that your device works properly.

## Procedure

-  In the Test Program Explorer panel, right-click Test Program and load your test program.
-  Right-click Testflow and select Load All Setups.
-  In [System console](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.08.05.01_Console_view__System_console.md>), click the ![Print Tester Status](<../../../../raw/346554.png>) Print Tester Status button from the toolbar:

![System Console Toolbar](<../../../../raw/352551.png>)

## Results

Tester status is printed to the system console for all sites, pins, instruments and with all properties.

## What to do next

You can compare the last two printed testers status logs by clicking Diff Tester Status from the system console toolbar. See [Comparing tester status from system console](<02.07.03.21.01.01_Comparing_tester_status_from_system_console.md>) for details.
