# EVENT_RDM.getOutOfRangeCheck()

Reads the state of the out-of-range check that has been defined by [EVENT_RDM.outOfRangeCheck()](<02.07.04.01.63.17.03_EVENT_RDM.outOfRangeCheck.md>).

The state is read from the corresponding [EVENT_RDM](<02.07.04.01.63.17_EVENT_RDM.md>) object and returned as a bool value.

## Syntax

```
void getOutOfRangeCheck(bool & failOnOutOfRange) const;
```

  Parameter

 | Parameter  | Description |
 | failOnOutOfRange |

The programmed value true or false of the out-of-range check.

- true: The out-of-range check is enabled
- false: The out-of-range check is disabled
  |   Return value There is no return value.

For an example see [EVENT_RDM](<02.07.04.01.63.17_EVENT_RDM.md>).
