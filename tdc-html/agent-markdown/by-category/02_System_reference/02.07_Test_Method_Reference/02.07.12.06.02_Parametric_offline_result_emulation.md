# Parametric offline result emulation

#### Subtopics

- [Offline result emulation for the FlexDC API](<02.07.12.06.02.01_Offline_result_emulation_for_the_FlexDC_API.md>)
- [Sample code for FlexDC API usage - without ORE](<02.07.12.06.02.02_Sample_code_for_FlexDC_API_usage_-_without_ORE.md>)
- [Sample code for FlexDC API usage - with ORE](<02.07.12.06.02.03_Sample_code_for_FlexDC_API_usage_-_with_ORE.md>)
- [Offline result emulation for TMUs](<02.07.12.06.02.04_Offline_result_emulation_for_TMUs.md>)

- Measurements are linked to FlexDC task objects by name (and optionally name of the calling test suite)
- No structural change in test method code required (only names need to be introduced)
- The name is an additional parameter for the `execute()` member functions
- Measurement names in the external setup file need to match names in the test method code

## Example

### XML setup file

```
<offlineResultEmulation>

   <measurementname="myMeasurement1">
     <testSuite name="myTestSuite1">
       <sitenumber="2">
         <pinname="Q2">
           <valueval="1.25"/>
         </pin>
       </site>
     </testSuite>
   </measurement>

   <measurementname="myMeasurement3">
     <pinname="Q4">
       <waveform>
         <value val="1.23"/>
         <value val="1.24"/>
         <value val="1.25"/>
       </waveform>
     </pin>
   </measurement>

   <measurementname="myMeasurement2">
     <pinname="Q3">
       <waveform file="/home/demo/matlab/tx106m1.txt"/>
     </pin>
   </measurement>

</offlineResultEmulation>
```
