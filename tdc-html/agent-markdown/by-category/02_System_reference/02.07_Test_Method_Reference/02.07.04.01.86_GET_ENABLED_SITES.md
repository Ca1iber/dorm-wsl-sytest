# GET_ENABLED_SITES()

This API returns the number of the current enabled sites, and stores the site numbers into the variable specified as the parameter.

Enabled sites mean sites that are intended for multi-site testing. Binned sites in a test flow are disabled (not enabled-sites). This API returns all sites that were initially set up on the Site Control window, except binned sites.

## Syntax 1

```
INT GET_ENABLED_SITES(STRING& sites);
INT GET_ENABLED_SITES(ARRAY_I& sites);
```

This syntax is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SiteControl.h.

Parameter
 |

I/O

 |

Parameter

 |

Description / Range

 |
 |

O

 |

sites

 |

The site numbers of the current enabled sites are returned to this variable as follows:

If the enabled sites are 1 and 3 in four sites:

- STRING: "1010".
- ARRAY_I: sites[0]=1 and sites [1]=3.
 |

## Return value for syntax 1

The number of enabled sites.

## Syntax 2

```
void GET_ENABLED_SITES( TM::MS_SITE_SET& sites );
```

This syntax is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Execute.h.

Parameters
 |

I/O

 |

Parameter

 |

Description / Range

 |
 |

O

 |

sites

 |

A character array. It stores the status of all configured sites. Each element stores the status of one site.

sites[i] stores the status of site i. i starts from 1 to represent site 1, 2, 3, ...; 0 is not a valid site number.

- If sites[i] is not "0", site i is enabled.
- If sites[i] = "0", site i is not enabled.
 |

## Return value for syntax 2

There is no return value.

## Example

```
//
// Get number of configured sites
//
INT     numberOfConfiguredSites;
ARRAY_I configuredSites;

numberOfConfiguredSites = GET_CONFIGURED_SITES(configuredSites);

//
// Set enabled sites
//
TM::MS_SITE_SET enabledSitesSet;

for (INT siteIndex = 1; siteIndex <= numberOfConfiguredSites; siteIndex++)
{
    if ((siteIndex == 1) || (siteIndex == 3))
    {
        enabledSitesSet[siteIndex] = 0;
    }
    else
    {
        enabledSitesSet[siteIndex] = 1;
    }
}

SET_ENABLED_SITES(enabledSitesSet);

//
// Get enabled sites, 1st syntax, string
//
STRING  enabledSitesString;
INT     numberOfEnabledSites;

numberOfEnabledSites = GET_ENABLED_SITES(enabledSitesString);

cout << "1st syntax, string,  "
     << numberOfEnabledSites << " sites enabled: "
     << enabledSitesString << endl;

//
// Get enabled sites, 1st syntax, ARRAY_I
//
ARRAY_I enabledSitesIntArray;

numberOfEnabledSites = GET_ENABLED_SITES(enabledSitesIntArray);

cout << "1st syntax, ARRAY_I, "
     << numberOfEnabledSites << " sites enabled: "
     << enabledSitesIntArray << endl;

//
// Get enabled sites, 2nd syntax, TM::MS_SITE_SET
//
TM::MS_SITE_SET enabledSitesCharArray;

GET_ENABLED_SITES(enabledSitesCharArray);

cout << "2nd syntax,            "
     << "enabled sites: ";

for (INT siteIndex = 1; siteIndex <= numberOfConfiguredSites; siteIndex++)
{
    cout << (INT) enabledSitesCharArray[siteIndex];
}

cout << endl;
```

It is assumed that the eight sites (site number: 1 to 8) are configured. Sites 1 and 2 are disabled by API SET_ENABLED_SITES(). The modified settings are read back by all three syntax variants of API GET_ENABLED_SITES(). The code above results in the following output:

```
1st syntax, string,  6 sites enabled: 01011111
1st syntax, ARRAY_I, 6 sites enabled: {	2,	4,	5,	6,	7,	8,	}
2nd syntax,            enabled sites: 01011111
```
