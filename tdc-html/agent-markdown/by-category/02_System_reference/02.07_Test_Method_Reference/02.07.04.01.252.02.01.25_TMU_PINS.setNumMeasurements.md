# TMU_PINS.setNumMeasurements()

Sets the number of measurements (armings) per shot.

## Syntax

```
TMU_PINS& setNumMeasurements(UINT32 num);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

num

 |

The number of measurements.

 |

## Return value

A reference to the TMU_PINS object is returned.
