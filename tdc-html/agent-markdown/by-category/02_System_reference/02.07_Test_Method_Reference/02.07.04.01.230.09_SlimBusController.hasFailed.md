# SlimBusController.hasFailed()

This function returns the global result of the SLIMbus protocol test for the specified site. It can only be called after decode() has been successfully executed.

## Syntax

```
Boolean hasFailed (int site=-1) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

site

 |

Specifies the site whose test result is to be returned. The default is the current site.

 |

## Return value

TRUE if the test has failed for the specified site, FALSE otherwise.

## Functional changes

- Introduced in SmarTest 7.2.1
