# Using classic test method in the universal test method environment

#### Subtopics

- [How to convert a classic test method project to universal test method project](<02.07.02.04.01_How_to_convert_a_classic_test_method_project_to_universal_test_method_pr.md>)
- [How to import a universal test method project](<02.07.02.04.02_How_to_import_a_universal_test_method_project.md>)
- [How to convert an incomplete classic test method to a universal test method](<02.07.02.04.03_How_to_convert_an_incomplete_classic_test_method_to_a_universal_test_met.md>)

To use classic test methods and testflows in universal test method environment, you must convert the classic test methods to universal test methods and convert the classic testflow to universal-test-method-based testflow. The conversion tools are provided with SmarTest.

## Before you begin

Make sure you are using SmarTest 6.3 or later, and your classic test method libraries and testflows are ready to use.

## Procedure

-  [Convert a classic test method project to a universal test method project](<02.07.02.04.01_How_to_convert_a_classic_test_method_project_to_universal_test_method_pr.md>)
-  [Import the universal test method project in your workspace](<02.07.02.04.02_How_to_import_a_universal_test_method_project.md>)
-  [Convert the classic testflow to the universal-test-method-based testflow](<02.07.02.06.01_How_to_convert_a_classic_testflow_to_universal-test-method-based_testflo.md>).

## Results

The classic test methods are converted to universal test methods and the classic testflows are converted to universal-test-method-based testflows. You can re-use the test method libraries created before in the universal test method environment.
