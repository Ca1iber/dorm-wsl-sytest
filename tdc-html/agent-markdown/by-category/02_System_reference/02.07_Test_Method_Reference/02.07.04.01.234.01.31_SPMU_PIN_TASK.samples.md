# SPMU_PIN_TASK.samples()

Sets the optional number of samples for the DC measurement. The minimum sample required by the HW is 1.

## Syntax

```
SPMU_PIN_TASK& samples(INT numOfSamples);
```

Parameter
 |

Parameter

 |

Description

 |
 |

numOfSamples

 |

The number of samples, only used for averaging, if omitted the HW required minimum sample is used.

For DC Scale channels, with exception of XPS256, the number of samples must be a power of 2.

 |

## Return value

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.
