# EVENT_FILTER.setFilterValue()

Sets the value of the filter.

## Syntax

```
EVENT_FILTER & setFilterValue(const EVENT_VALUE_DOUBLE filterValue);
```

  Parameter

 | Parameter  | Description |
 | filterValue |

The new filter value.

The unit of the filter value is defined by the filter type that has been selected by [EVENT_FILTER.setFilterType()](<02.07.04.01.63.07.01_EVENT_FILTER.setFilterType.md>).

   |   Return value A reference to the corresponding [EVENT_FILTER](<02.07.04.01.63.07_EVENT_FILTER.md>) object.
