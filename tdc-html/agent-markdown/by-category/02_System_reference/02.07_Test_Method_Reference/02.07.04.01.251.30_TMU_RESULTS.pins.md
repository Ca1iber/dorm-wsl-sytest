# TMU_RESULTS.pins()

Specifies the TMU pins to retrieve the results.

## Syntax

```
virtual TMU_RESULTS& pins(STRING& keyname);
virtual TMU_RESULTS& pins(const char* keyname);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

keyname

 |

The TMU pins.

 |

## Return value

A reference to the TMU_RESULTS object is returned.

## Functional changes

- Introduced in SmarTest 7.1.3
