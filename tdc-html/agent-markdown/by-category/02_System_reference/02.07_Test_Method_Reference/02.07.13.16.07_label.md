# label()

Specifies a label to be executed. From the label execution, failing information is retrieved.

The specified label must be the main label, not a burst label or subroutine.

## Syntax

```
label(const string& sLabelName);
```

List of parameters
 | Parameter  | Description |
 | sLabelName  | The label to be executed. |

## Example

```
rdi.emap("a").label("label1").pin("pA").failCount().pfMap()
                             .pin("pC").failCyc(5).execute();
```

## Functional changes

- Introduced in SmartRDI 2.4.0
