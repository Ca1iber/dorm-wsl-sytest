# EVENT_WAVEFORM_IC.getIClampHigh()

Queries the high clamp current waveform.

## Syntax

```
const & ARRAY_D getIClampHigh() const;
```

List of parameters

There are no parameters.

## Return value

The high clamp current waveform as an ARRAY_D (array of doubles).
