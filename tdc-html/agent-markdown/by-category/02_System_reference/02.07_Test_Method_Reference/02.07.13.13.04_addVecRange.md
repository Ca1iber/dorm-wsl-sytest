# addVecRange()

Specifies a vector range within which digital capture actions can be inserted.

You can use this function several times to add digital capture actions in multiple positions in an existing pattern. This function can work together with `cont()` to have several command lines for adding capture positions. You can also specify a range from a parameter list.

## Syntax

```
addVecRange(int iRangeBf, int iRangeAft);
```

Parameter List
 |

Parameter

 |

Description

 |
 |

iRangeBf

 |

The start vector to do the digital capture.

 |
 |

iRangeAft

 |

The end vector to do the digital capture.

 |

## Examples

### Generic example

```
rdi.digCap("norm").label("lpDcap_new").pin("DATA2").addVecRange(3,15).samples(10).execute();
```

Please note that `addVecRange()` should always be used together with `rdi.digCap().label()`.

### For multiple positions with cont()

```
rdi.digCap().pin("A").samples(100).cont();
rdi.digCap().pin("A").addVecRange(3,6).cont();
rdi.digCap().pin("A").addVecRange(10,20).cont();
rdi.digCap().execute();
```

### For multiple positions without cont()

```
rdi.digCap().pin("A").samples(100)
                    .addVecRange(3,6)
                    .addVecRange(10,20)
                    .execute();
```

### A range from a parameter list

```
rdi.digCap().pin("A").samples(100).cont();
   for (i = 0; i < listSize(); i++)
     rdi.digCap().pin("A").addVecRange(beginVec[i],endVec[i]).cont();
rdi.digCap().execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
- SmartRDI 2.4.3: Support cont() and a parameter list.
