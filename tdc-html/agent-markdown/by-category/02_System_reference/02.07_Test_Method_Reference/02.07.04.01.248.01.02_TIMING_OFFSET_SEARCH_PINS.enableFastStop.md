# TIMING_OFFSET_SEARCH_PINS.enableFastStop()

Controls the FASTSTOP mode.

The FASTSTOP mode stops the linear search as soon as the first valid eye or single transition is returned:

- Requesting an eye, the linear search stops as soon as both edges of the first eye are returned.

  - It requires both, a fail/pass and a pass/fail transitions within the search window.
  - It does not acknowledge an open eye as eye.
  - The number of the returned PASS values does not matter.

- Requesting a single transition, the first two subsequent measurements (pass/fail or fail/pass), which show the requested transition, stop the linear search.
- If the requested condition is not fulfilled, it returns the same result as the standard mode.

For more details and examples on search modes, see [Linear search modes](<../02.06_Command_Reference/02.06.09.01.02.01_Linear_search_modes.md>).

## Syntax

```
void TIMING_OFFSET_SEARCH_PINS& enableFastStop(status);
```

Parameter
 |

Parameter

 |

Description

 |
 |

status

 |

- FALSE: The search uses the standard search mode returning the largest pass area.
- TRUE: The search uses the faststop mode, which stops the linear search when the first PASS area is found.
 |

Return value

There is no return value.

## Example

```
TIMING_OFFSET_SEARCH_TASK tos;
TIMING_OFFSET_SEARCH::TimingOffsetConfigDataType searchConfiguration;

tos.pin("pin1,pin2")
   .edgeType(TIMING_OFFSET_SEARCH::RECEIVE)
   .searchType(TIMING_OFFSET_SEARCH::EYE)
   .start(10 ns)
   .numSteps(100)
   .stepWidth(10ns)
   .minPassCount(1)
   .transitionDetection(TIMING_OFFSET_SEARCH::PF)
   .resolution(10ns)
   .errorCountLimit(1)
   .restoreFlag(TIMING_OFFSET_SEARCH::NO)
   .enableFastStop(true);

//
// Query the current setting and check whether enableFastStop is enabled
//
tos.pin("pin1").getConfiguration(searchConfiguration);

if (searchConfiguration.enableFastStop)
{
    // Add your code here
}
```
