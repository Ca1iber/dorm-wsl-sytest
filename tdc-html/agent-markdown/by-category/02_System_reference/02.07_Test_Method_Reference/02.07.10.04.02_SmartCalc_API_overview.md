# SmartCalc API overview

 Note This is only a brief overview of the SmartCalc APIs. Detailed API description can be found in [SmartCalc API reference](<02.07.04.01.231_SMC_...__SmartCalc_API_reference.md>).

## APIs provided with the SmartCalc framework

 | Member function  | Description |
 | [SMC_ARM()](<02.07.04.01.231.01_SMC_ARM.md>)  | Arms your [SMC_backgroundProcessing()](<02.07.04.01.231.01_SMC_ARM.md#_120107__s_SMC_backgroundProcessing>) method with up to 8 arguments of any type. The calculation thread is automatically started. In case a SMC upload is performed, the thread will wait for a SMC upload trigger from, for example, [SMC_WAIT_TIME()](<02.07.04.01.231.53_SMC_WAIT_TIME.md>), ... |
 | [SMC_TEST()](<02.07.04.01.231.45_SMC_TEST.md>)  | Buffers results and delays data log until [SMC_SYNCHRONIZE()](<02.07.04.01.231.43_SMC_SYNCHRONIZE.md>) is called. Syntax and parameters are similar to [TEST](<02.07.04.01.241_TEST.md>). |
 | [SMC_SITE_NUMBER()](<02.07.04.01.231.42_SMC_SITE_NUMBER.md>)  | Gets the site number for which this calculation routine was started. |
 | [SMC_SERIAL_EXECUTION_BEGIN()](<02.07.04.01.231.31_SMC_SERIAL_EXECUTION_BEGIN.md>)  | Forces from this point on the execution in serial instead of parallel. SMC_SERIAL_EXECUTION_BEGIN() always needs to be used together with SMC_SERIAL_EXECUTION_END(). |
 | [SMC_SERIAL_EXECUTION_END()](<02.07.04.01.231.32_SMC_SERIAL_EXECUTION_END.md>)  | Ends a block of serial execution to allow for parallel execution again. SMC_SERIAL_EXECUTION_BEGIN() always has to be called before. |
 | [SMC_PUT_DEBUG()](<02.07.04.01.231.30_SMC_PUT_DEBUG.md>)  | Replacement for the [PUT_DEBUG](<02.07.04.01.175_PUT_DEBUG.md>) API for SmartCalc multithreaded purpose. For details refer to the [PUT_DEBUG](<02.07.04.01.175_PUT_DEBUG.md>) description. |
 | [SMC_BACKGROUND_ENABLE()](<02.07.04.01.231.06_SMC_BACKGROUND_ENABLE.md>)  | Sends SmartCalc the trigger signal to enable background uploads. While this state is enabled, it is not allowed to execute any commands which requires communication with the tester or FW. Need to call SMC_BACKGROUND_DISABLE() at the end. |
 | [SMC_BACKGROUND_DISABLE()](<02.07.04.01.231.05_SMC_BACKGROUND_DISABLE.md>)  | Disables the background upload. Call only when SMC_BACKGROUND_ENABLE() has been called before. |
 | [SMC_GET_VECTORS()](<02.07.04.01.231.17_SMC_GET_VECTORS.md>)  | Performs hidden upload in SMC thread. Return the captured data of the vector memory located by the vector variable to an array. The returned reference is valid until [SMC_SYNCHRONIZE()](<02.07.04.01.231.43_SMC_SYNCHRONIZE.md>) is called for this thread/site. |
 | [SMC_SET_VECTOR_UPLOAD_PACKAGE_SIZE()](<02.07.04.01.231.38_SMC_SET_VECTOR_UPLOAD_PACKAGE_SIZE.md>)  | Sets the package size for the vector upload to the specified number of bytes. This size is valid until the value is changed again. The default implementation assumes a package size of 32 kBytes for all HW including mixed HW. |
 | [SMC_GET_VECTOR_UPLOAD_PACKAGE_SIZE()](<02.07.04.01.231.18_SMC_GET_VECTOR_UPLOAD_PACKAGE_SIZE.md>)  | Returns the current package size for the vector upload in bytes. |
 | [SMC_GET_WAVEFORM()](<02.07.04.01.231.20_SMC_GET_WAVEFORM.md>) |

Performs hidden upload in SMC thread.

Returns the captured waveform data to an array.

The returned reference is valid until [SMC_SYNCHRONIZE()](<02.07.04.01.231.43_SMC_SYNCHRONIZE.md>) is called for this thread/site.

 |
 | [SMC_GET_COMPLEX_WAVEFORM()](<02.07.04.01.231.14_SMC_GET_COMPLEX_WAVEFORM.md>) |

Performs hidden upload in SMC thread.

Returns the captured waveform data to an array of complex.

The returned reference is valid until [SMC_SYNCHRONIZE()](<02.07.04.01.231.43_SMC_SYNCHRONIZE.md>) is called for this thread site.

 |
 | [SMC_SET_WAVEFORM_UPLOAD_PACKAGE_SIZE()](<02.07.04.01.231.40_SMC_SET_WAVEFORM_UPLOAD_PACKAGE_SIZE.md>) |

Sets the package size for the waveform upload to the specified number of bytes.

This size is valid until the value is changed again.

The default implementation assumes a package size of 4 kBytes.

 |
 | [SMC_GET_WAVEFORM_UPLOAD_PACKAGE_SIZE()](<02.07.04.01.231.21_SMC_GET_WAVEFORM_UPLOAD_PACKAGE_SIZE.md>)  | Returns the current package size for the waveform upload in bytes. |
 | [SMC_DISABLE()](<02.07.04.01.231.09_SMC_DISABLE.md>)  | Disables the SMC features like multithreading and hidden upload. This feature is meant for debug purposes. It will disable all the SMC features and execution will continue as without SMC, except the fact that [SMC_TEST()](<02.07.04.01.231.45_SMC_TEST.md>) statements still will be evaluated during [SMC_SYNCHRONIZE()](<02.07.04.01.231.43_SMC_SYNCHRONIZE.md>). |
 | [SMC_SYNCHRONIZE()](<02.07.04.01.231.43_SMC_SYNCHRONIZE.md>) |

Synchronizes the multithreaded execution.

Waits for all calculation threads to be finished or terminate them after the specified timeout. Executes their test statements. Performs internal cleanup.

Has to be called per site and thus outside of an ON_FIRST_INVOCATION_BEGIN/END() block.

The timeout must be greater than or equal to 0. If equal to 0 an infinite wait will be performed (no forced termination of thread).

Returns FALSE when calculation routines had to be aborted or an invocation error occurred. The return value is independent from results of the test statements.

 |
 | [SMC_CLEANUP()](<02.07.04.01.231.07_SMC_CLEANUP.md>) |

Aborts the multithreaded execution.

Waits for all calculation threads to be finished or terminate them after 10 ms timeout. Performs internal cleanup.

Operates on the active site only, so it has to be called outside the ON_FIRST_INVOCATION_BEGIN/END() block.

 |
 | [SMC_PUT_DATALOG()](<02.07.04.01.231.29_SMC_PUT_DATALOG.md>)  | Buffers the data log values and executes them as soon as the synchronization point ([SMC_SYNCHRONIZE()](<02.07.04.01.231.43_SMC_SYNCHRONIZE.md>)) is reached. The data log values will be executed in the order as the different background threads are started. |
 | [SMC_NB_DIGITAL_CAPTURE_END()](<02.07.04.01.231.26_SMC_NB_DIGITAL_CAPTURE_END.md>) |

Declares the end of a test which contains digital capture started by [NB_DIGITAL_CAPTURE_START](<02.07.04.01.135_NB_DIGITAL_CAPTURE_START.md>).

It waits for the digital sequencer completion and performs hidden data upload in between. The specified result area ID must match the area specified in [NB_DIGITAL_CAPTURE_START](<02.07.04.01.135_NB_DIGITAL_CAPTURE_START.md>).

 |
 | [SMC_EXECUTE_DEBUG_ACTION()](<02.07.04.01.231.10_SMC_EXECUTE_DEBUG_ACTION.md>)  | Executes a SmartCalc debug action that can be used for test flow performance optimization by providing hidden upload utilization statistics. |

## Wrapper APIs to control hidden upload in threads

The following APIs are capable to control the upload of the SMC threads and have the same functionality as their non SmartCalc counterparts.

 | SmartCalc wrapper  | non SmartCalc counterpart |
 | [SMC_EXECUTE_TEST()](<02.07.04.01.231.11_SMC_EXECUTE_TEST.md>)  | [EXECUTE_TEST](<02.07.04.01.65_EXECUTE_TEST.md>) |

 | [SMC_WAIT_TIME()](<02.07.04.01.231.53_SMC_WAIT_TIME.md>)  | [WAIT_TIME](<02.07.04.01.272_WAIT_TIME.md>) |
 | [SMC_WAIT_TEST_DONE()](<02.07.04.01.231.52_SMC_WAIT_TEST_DONE.md>)  | [WAIT_TEST_DONE](<02.07.04.01.271_WAIT_TEST_DONE.md>) |
 | [SMC_DIGITAL_CAPTURE_TEST()](<02.07.04.01.231.08_SMC_DIGITAL_CAPTURE_TEST.md>)  | [DIGITAL_CAPTURE_TEST](<02.07.04.01.35_DIGITAL_CAPTURE_TEST.md>) |
 | [SMC_NB_DIGITAL_CAPTURE_END()](<02.07.04.01.231.26_SMC_NB_DIGITAL_CAPTURE_END.md>)  | [NB_DIGITAL_CAPTURE_END](<02.07.04.01.134_NB_DIGITAL_CAPTURE_END.md>) |
