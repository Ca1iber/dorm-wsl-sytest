# Changing spec value in primary level spec set

To change the specified spec value in the current primary level spec set, return the class object of the LEVEL_SPEC API by `Primary.getLevelSpec()` and execute a member function of the LEVEL_SPEC API as follows.

```
Primary.getLevelSpec().<memberFunction>;
```

where, <memberFunction> is a member function of the [LEVEL_SPEC](<02.07.04.01.124_LEVEL_SPEC.md>) API. Only one member function can be specified. You cannot specify other member functions of the [PRIMARY_STATUS](<02.07.04.01.167_PRIMARY_STATUS_-__Primary.md>) API in this statement.

The following member functions of LEVEL_SPEC are available for changing a spec value:

 | Task to be executed  | <memberFunction> |
 | Change the spec value to the specified value  | [change()](<02.07.04.01.124_LEVEL_SPEC.md#_29495__dle_change>) |
 | Restore all the spec values to the original values  | [restore()](<02.07.04.01.124_LEVEL_SPEC.md#_29495__dle_restore>) |
