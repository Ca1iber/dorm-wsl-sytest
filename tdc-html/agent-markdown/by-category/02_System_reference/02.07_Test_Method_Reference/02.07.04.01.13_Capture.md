# Capture()

This API is used to set capture information (digital pins, the input vector variable and sample number).

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTMultiportSync.hpp.

## Syntax

```
void capture(_TM_DC_DYNAMIC::vectorVariable& _VV, const STRING& _pin, INT sampleNum);
```

Parameters
 |

_VV

 |

Specifies the vector variable.

 |
 |

_pin

 |

Specifies the list of digital pin from which data is captured.

 |
 |

cycleNum

 |

Specifies the capture sample number.

 |

## Example

```
CCTMultiportSync     Sync;
...
DigitalCapturePort::getInstance().setPort(mDigCapPort);
DigitalCapturePort::getInstance().setIdentifier(tsName);
Sync.registerSyncPort(DigitalCapturePort::getInstance());
...

Sync.start();
...
vectorVariable adcCap_lin(capture_variable);
```
