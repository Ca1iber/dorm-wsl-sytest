# setSiteResult()

Sets the result of the specified site to true (pass) or false (fail) to enable branching.

This API enables you to branch out failed sites immediately if the test suite is called only once for all sites in the ON_FIRST_INVOCATION block.

## Syntax

```
void setSiteResult (int site, bool result);
```

  Parameters

 | Parameter  | Description |
 | site  | The site number. |
 | result |

Sets the pass/fail result of the specified site.

Use true (pass) or false (fail).

   |  Return value There is no return value.

## Example

```
#include "testmethod.hpp"

#include "mapi.hpp"
using namespace std;

class callOnceStructures: public testmethod::TestMethod {

public:

    virtual void SMC_backgroundProcessing()
    {
        // Enter your code here for hidden upload, calculation, and data logging.
    }

protected:

    virtual void run()
    {
        ON_FIRST_INVOCATION_BEGIN();

            // enable the run once mechanism
            setStopSiteLoop ( true );

            // Execute the test
            FUNCTIONAL_TEST();

            INT site;

            FOR_EACH_SITE_BEGIN();

                site=CURRENT_SITE_NUMBER();

                // retrieve the pass/fail result from the hardware
                bool result = GET_FUNCTIONAL_RESULT();

                // handle failed sites only
                if (!result )
                {
                    // set the result of the site to false (fail)
                    // this enables you to branch out failing sites in your testflow immediately
                    TM::SetSiteResult(site, false);
                }

            FOR_EACH_SITE_END();

        ON_FIRST_INVOCATION_END();

        return;
    }

    virtual void initialize()
    {
    }

    virtual void postParameterChange(const string& parameterIdentifier)
    {
        return;
    }

    virtual const string getComment() const
    {
        string comment = " please add your comment for this method.";
        return comment;
    }
};
REGISTER_TESTMETHOD("callOnceStructures", callOnceStructures);
```
