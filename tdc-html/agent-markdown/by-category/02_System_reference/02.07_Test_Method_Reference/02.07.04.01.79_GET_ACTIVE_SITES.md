# GET_ACTIVE_SITES()

This API returns the number of the current active sites, and stores the site numbers into the variable specified as the parameter.

Active sites mean sites that are intended for execution of the test method program currently.

For parallel execution, this API returns multiple sites as active sites that are the same as enabled sites generally. Outside of the [ON_FIRST_INVOCATION](<02.07.04.01.138_ON_FIRST_INVOCATION_BEGIN.md>) block in the run() function of a test method class, this API returns only one site that calls the program.

For serial execution, this API always returns only the site that is currently in focus.

## Syntax 1

```
INT GET_ACTIVE_SITES(STRING& sites);
INT GET_ACTIVE_SITES(ARRAY_I& sites);
```

This syntax is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SiteControl.h.

  Parameters

 | I/O  | Parameter  | Description / Range |
 | O  | sites |

The site numbers of the current active sites are returned to this variable as follows:

If the current active sites are 1 and 2 in four sites:

- STRING: "1100".
- ARRAY_I: sites[0]=1 and sites [1]=2.
  |  Return value The number of active sites.

## Syntax 2

```
void GET_ACTIVE_SITES(TM::MS_SITE_SET& sites);
```

This syntax is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Execute.h.

  Parameters

 | I/O  | Parameter  | Description / Range |
 | O  | sites |

A character array. It stores the status of all configured sites. Each element stores the status of one site.

sites[i] stores the status of site i. i starts from 1 to represent site 1, 2, 3, ...; 0 is not a valid site number.

- If sites[i] is not 0, site i is active.
- If sites[i] = 0, site i is not active.
  |  Return value There is no return value.

## Example

```
//
// Get number of configured sites
//
INT     numberOfConfiguredSites;
ARRAY_I configuredSites;

numberOfConfiguredSites = GET_CONFIGURED_SITES(configuredSites);

//
// Set active sites
//
TM::MS_SITE_SET activeSiteSet;

for (INT siteIndex = 1; siteIndex <= numberOfConfiguredSites; siteIndex++)
{
    if ((siteIndex == 2) || (siteIndex == 5))
    {
        activeSiteSet[siteIndex] = 0;
    }
    else
    {
        activeSiteSet[siteIndex] = 1;
    }
}

SET_ACTIVE_SITES(activeSiteSet);

//
// Get active sites, 1st syntax, string
//
STRING  activeSitesString;
INT     numberOfActiveSites;

numberOfActiveSites = GET_ACTIVE_SITES(activeSitesString);

cout << "1st syntax, string,  "
     << numberOfActiveSites << " sites active: "
     << activeSitesString << endl;

//
// Get active sites, 1st syntax, ARRAY_I
//
ARRAY_I activeSitesIntArray;

numberOfActiveSites = GET_ACTIVE_SITES(activeSitesIntArray);

cout << "1st syntax, ARRAY_I, "
     << numberOfActiveSites << " sites active: "
     << activeSitesIntArray << endl;

//
// Get active sites, 2nd syntax, TM::MS_SITE_SET
//
TM::MS_SITE_SET activeSitesCharArray;

GET_ACTIVE_SITES(activeSitesCharArray);

cout << "2nd syntax,            "
     << "active sites: ";

for (INT siteIndex = 1; siteIndex <= numberOfConfiguredSites; siteIndex++)
{
    cout << (INT) activeSitesCharArray[siteIndex];
}

cout << endl;
```

It is assumed that eight sites (site number: 1 to 8) are configured and enabled. Sites 2 and 5 are deactivated by API SET_ACTIVE_SITES(). The modified settings are read back by all three syntax variants of API GET_ACTIVE_SITES(). The code above results in the following output:

```
1st syntax, string,  6 sites active: 10110111
1st syntax, ARRAY_I, 6 sites active: {	1,	3,	4,	6,	7,	8,	}
2nd syntax,            active sites: 10110111
```
