# RESULT_AREA_CONFIG_PINS.getDcValueResultAreaSize()

This function returns the currently configured error map result area size in bytes for a given RESULT_AREA_CONFIG_PINS object.

## Syntax

```
INT getDcValueResultAreaSize() const;
```

List of parameters

There are no parameters.

## Return value

Integer value.

## Example

Example for retrieving the currently configured DC result area size for a specific config set and pin.

```
RESULT_AREA_CONFIG_SET burstResultAreaConfig("dc_and_capture_area_config");

burstResultAreaConfig.pin("meas_pin").setDcValueResultAreaSize(16000);

int numberOfConfiguredSamples = burstResultAreaConfig.pin("meas_pin").getDcValueResultAreaSize();
```
