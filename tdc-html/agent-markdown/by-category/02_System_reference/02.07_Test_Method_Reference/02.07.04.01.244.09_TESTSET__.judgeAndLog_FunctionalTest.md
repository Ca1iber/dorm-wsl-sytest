# TESTSET().judgeAndLog_FunctionalTest()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) performs a pass/fail judgment of a functional test and logs the results.

Optional values for this function can be set by prior methods, for example, [port()](<02.07.04.01.244.19_TESTSET__.port.md>), [cont()](<02.07.04.01.244.03_TESTSET__.cont.md>), [reliability()](<02.07.04.01.244.20_TESTSET__.reliability.md>), or [testname()](<02.07.04.01.244.23_TESTSET__.testname.md>).

## Syntax for APIs that retrieve functional pass/fail result by internally calling GET_FUNCTIONAL_RESULT

For more details, see [GET_FUNCTIONAL_RESULT()](<02.07.04.01.88_GET_FUNCTIONAL_RESULT.md>).

   Result logged for current site

- `bool judgeAndLog_FunctionalTest();`
- `bool judgeAndLog_FunctionalTest(const STRING& testname, V93kLimits::TMLimits& tmLimit);`
  Result logged for site provided as a parameter

- `bool judgeAndLog_FunctionalTest(const INT site);`
- `bool judgeAndLog_FunctionalTest(const INT site, const STRING& testname, V93kLimits::TMLimits& tmLimit);`

## Syntax for APIs that take functional pass/fail as a parameter

   Result logged for current site

- `bool judgeAndLog_FunctionalTest(bool result);`
- `bool judgeAndLog_FunctionalTest(const STRING& testname, V93kLimits::TMLimits& tmLimit, bool result);`
- `bool judgeAndLog_FunctionalTest(bool result, const STRING& label);`
- `bool judgeAndLog_FunctionalTest(const STRING& testname, V93kLimits::TMLimits& tmLimit, bool result, const STRING& label);`
  Result logged for site provided as a parameter

- `bool judgeAndLog_FunctionalTest(const INT site, bool result);`
- `bool judgeAndLog_FunctionalTest(const INT site, const STRING& testname, V93kLimits::TMLimits& tmLimit, bool result);`
    Note

To provide functional pass/fail result as a parameter, make sure it is of type bool, not INT:

`bool judgeAndLog_FunctionalTest(bool result);`

Otherwise the wrong API is called:

`bool judgeAndLog_FunctionalTest(const INT site);`

## Parameters

The supported parameters are listed in the following table:

 |

Parameter

 |

Description

 |
 |

result

 |

Pass/fail result of functional test to log.

 |
 |

site

 |

Site number to log.

 |
 |

testname

 |

Test name defined in the test table.

Test names can contain any printable ASCII characters, that is, characters with codes from 32 to 126. This includes the space, digits, lowercase letters, uppercase letters, and these punctuation characters: !"#$%&'()*+,-./:;<=>@?[\]^_`{|}~ There is no fixed maximum length for the names in SmarTest. However, STDF limits test names to 255 characters, so test names should not be longer if STDF data logging is intended.

 |
 |

tmLimit

 |

Object of [TMLimits](<02.07.04.01.250_TMLimits.md>) for the loaded test table. You can use the default instance `tmLimits`.

 |
 |

label

 |

Label to log.

 |

The following function calls can be used within the SMC framework:

`bool judgeAndLog_FunctionalTest(bool result, const STRING& label);`

`bool judgeAndLog_FunctionalTest(const STRING& testname, V93kLimits::TMLimits& tmLimit, bool result, const STRING& label);`

## Return Value

The pass/fail result of the judgment, where true is returned for pass and false for fail.

## Example

```
ON_FIRST_INVOCATION_BEGIN();
  FUNCTIONAL_TEST();
ON_FIRST_INVOCATION_END();
TESTSET().cont(true).judgeAndLog_FunctionalTest("funcTest1", tmLimits);
```
