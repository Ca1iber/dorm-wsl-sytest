# Offline result emulation for the FlexDC API

#### Subtopics

- [Offline result emulation for Class DPS_TASK](<02.07.12.06.02.01.01_Offline_result_emulation_for_Class_DPS_TASK.md>)

Parametric offline result emulation capabilities are provided only for the following parts of the FlexDC API.

The detailed specification can be found in the test method [API Reference](<02.07.04_API_Reference.md>) documentation.

- [PPMU_MEASURE](<02.07.04.01.157_PPMU_MEASURE.md>)

  - [PPMU_PIN_MEASURE](<02.07.04.01.157.01_PPMU_PIN_MEASURE.md>)

- [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>)

  - [DPS_PIN_TASK](<02.07.04.01.50.01_DPS_PIN_TASK.md>)

- [SPMU_TASK](<02.07.04.01.234_SPMU_TASK.md>)

  - [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>)

- [TASK_LIST](<02.07.04.01.240_TASK_LIST.md>)

SmarTest provides offline result emulation capabilities only for parametric measurements on device power supplies (DPS), the system parametric measurement unit (SPMU), and the per-pin parametric measurement unit (PPMU). This required enhancements to the following classes:

- [Class DPS_TASK](<02.07.12.06.02.01.01_Offline_result_emulation_for_Class_DPS_TASK.md>)
- [Class SPMU_TASK](<02.07.12.06.02.01.03_Offline_result_emulation_for_Class_SPMU_TASK.md>)
- [Class PPMU_MEASURE](<02.07.12.06.02.01.02_Offline_result_emulation_for_Class_PPMU_MEASURE.md>)
- [Class TASK_LIST](<02.07.12.06.02.01.04_Offline_result_emulation_for_Class_TASK_LIST.md>)
