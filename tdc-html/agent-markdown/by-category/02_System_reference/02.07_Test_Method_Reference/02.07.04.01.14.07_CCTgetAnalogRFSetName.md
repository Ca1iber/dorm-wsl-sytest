# CCTgetAnalogRFSetName

This function returns the actual analog and RF set name of the current test suite. The set name may be different in concurrent mode and serial mode.

In concurrent mode, it returns the analog/RF set name specified in the execution test suite of the CCF block.

In serial mode, it returns the analog/RF set name specified in the current test suite.

This function is usually used in the `preStart()`, `postStart()`, `process()` and `cleanup()` function but not used in the `init()` function of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
string CCTgetAnalogRFSetName();
```

## Example

```
MEAS_DEF(CCTgetAnalogRFSetName()).disableAll().disconnectAll();
```

In this example, the retrieved analog set name is set as the primary set. It disables all hardware trigger lines and disconnects the instruments.

## Functional changes

- Introduced in SmarTest 6.5.4
