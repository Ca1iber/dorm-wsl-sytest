# rdi.id().getTmuErrorState()

Retrieves the TMU error state of a specified pin.

Besides a pin, you can also specify a site for the command. See [Example 2](<02.07.13.21.21_rdi.id__.getTmuErrorState.md#_351689__example_2_site>).

## Syntax

```
int getTmuErrorState(string pin);
```

getTmuErrorState() retrieves the TMU error state per pin in a burst. For multiple TMU measurements in the burst, it retrieves all the TMU states for the pin.

See [TMU_RESULTS.getPinErrorState()](<02.07.04.01.251.17_TMU_RESULTS.getPinErrorState.md>) for the content and meaning of error states.

## Examples

### Example 1

```
RDI_BEGIN();
  rdi.tmu("id1").pin("dig1").vth(2).samples(5).measMode(TA::RISE).execute(); // 1
  rdi.tmu().pin("dig1").vth(2).samples(10).measMode(TA::RISE).execute();     // 2
  ...
RDI_END();
int errorState = rdi.id("id1").getTmuErrorState("dig1"); // get the result from 1 and 2.
```

### Example 2

 Hidden upload support

```
rdi.hiddenUpload(TA::ALL);
RDI_BEGIN();
  rdi.tmu("id1").pin("dig1").vth(2).samples(5).measMode(TA::RISE).execute();
  ...
RDI_END();

void SMC_backgroundProcessing()
{
  int errorState = rdi.id("id1").getTmuErrorState("dig1");
  int errorState1 = rdi.site(2).id("id1").getTmuErrorState("dig1"); // result for site 2
}
```
