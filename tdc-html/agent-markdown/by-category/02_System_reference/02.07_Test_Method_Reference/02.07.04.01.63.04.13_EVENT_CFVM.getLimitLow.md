# EVENT_CFVM.getLimitLow()

Reads the lower limit that has been defined by [EVENT_CFVM.limits()](<02.07.04.01.63.04.09_EVENT_CFVM.limits.md>) or [EVENT_CFVM.limitLow()](<02.07.04.01.63.04.10_EVENT_CFVM.limitLow.md>).

The value is read from the corresponding [EVENT_CFVM](<02.07.04.01.63.04_EVENT_CFVM.md>) object and returned as an [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
bool getLimitLow (EVENT_VALUE_DOUBLE & lowLimit) const;
```

Parameter
 | Parameter  | Description |
 | lowLimit |

The programmed lower limit in V (Volt).

 |

## Return value

bool value indicating the state of the limit definition:

- true: Limit has been defined by [EVENT_CFVM.limits()](<02.07.04.01.63.04.09_EVENT_CFVM.limits.md>) or [EVENT_CFVM.limitLow()](<02.07.04.01.63.04.10_EVENT_CFVM.limitLow.md>).
- false: No limit is defined or the limit has been cleared by [EVENT_CFVM.clearLimits()](<02.07.04.01.63.04.12_EVENT_CFVM.clearLimits.md>).

## Example

For an example see [EVENT_CFVM](<02.07.04.01.63.04_EVENT_CFVM.md>).
