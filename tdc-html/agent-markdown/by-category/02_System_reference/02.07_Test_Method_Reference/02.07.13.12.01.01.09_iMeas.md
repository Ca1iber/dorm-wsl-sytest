# iMeas()

Creates a current measurement.

It must be used together with vForce().

Make sure the right mode is set for the current measurement: `valueMode(TA::BADC)`. See [valueMode()](<02.07.13.12.01.01.18_valueMode.md>).

  Note When you use this function on multiports, if the following measurement conditions exist:

- [valueMode()](<02.07.13.12.01.01.18_valueMode.md>) is set to BADC (the default value since SmartRDI 2.5.0 ).
- Pins from different ports share the same BADC.

You must use [rdi.portSync()](<02.07.13.08.08.02_portSync.md>) to ensure the sequence of pins' access to the BADC is correct.

For accuracy considerations, refer to [the number of samples](<02.07.04.01.08.01_BADC_PIN_MEASURE.md#_126251__dle_number_of_samples>) for current measurement in [BADC_PIN_MEASURE](<02.07.04.01.08.01_BADC_PIN_MEASURE.md>).

## Syntax

```
iMeas();
```

## Example

```
rdi.dc("iMeas").pin("pinA").vForce(3 V).iMeas().execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
