# rdi.id().getImmediateVector()

Gets the result vector chunk when test is running. This is only needed when users want to put their own calculation behind the current execution.

## Syntax

```
array& getImmdiateVector(int offset, const string & pin = TOOL::NOT_DEF_STRING);
```

List of parameters
 | Parameter  | Description |
 | offset  | The size of data. |
 | pin  | The specified pin name. |

See [Using Immediate Upload in SmartRDI](<02.07.13.13.03_Using_Immediate_Upload_in_SmartRDI.md>) for more information about how to use this function together with [rdi.digCapImmediateUpload()](<02.07.13.13.03.01_rdi.digCapImmediateUpload.md>).

## Example

```
resultChunk = rdi.id("resultId").getImmediateVector(uploadDataOffset[site]);
```

For more examples, see examples in [Using Immediate Upload in SmartRDI](<02.07.13.13.03_Using_Immediate_Upload_in_SmartRDI.md>).
