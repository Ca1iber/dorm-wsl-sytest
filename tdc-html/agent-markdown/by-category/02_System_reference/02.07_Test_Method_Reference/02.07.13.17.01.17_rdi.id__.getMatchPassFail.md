# rdi.id().getMatchPassFail()

This function returns true if a match is found on the specified pin.

## Syntax

```
bool rdi.id().getMatchPassFail(string pin)
```

## Example

```
rdi.id("mch").getMatchPassFail("pinA");
```

## Functional changes

- Introduced in SmartRDI 2.4.0
