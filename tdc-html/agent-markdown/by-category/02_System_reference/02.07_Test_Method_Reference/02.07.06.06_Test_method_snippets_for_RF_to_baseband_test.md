# Test method snippets for RF to baseband test

The following test method snippets for RF to BB test are provided with SmarTest. These test method snippets are included in the file /opt/hp93000/soc/segements/tml/testmethodSnipptets.xml.

IQ setup is required for the execution of these snippets. To save test time, the data of ARRAY_X type is not passed as parameters but as private member variables of test method class to the post processing functions.

The snippets are listed in the alphabetical order.

- V93000_RFtoBB_EVM_Measure

This snippet sets up and performs a RF to baseband EVM test with smartCalc. It then uploads the result waveform and kicks off the hidden calculation with the smartCalc background post processing function.

- V93000_RFtoBB_EVM_SMCPostProcess

This snippet does the post processing for the RF to baseband EVM test with smartCalc. It calculates the EVM rms value and DB value. The snippet can be used together with the snippet V93000_RFtoBB_EVM_Measure in the test method.

- V93000_RFtoBB_Filter_Measure

This snippet sets up and performs a RF to baseband filter test with smartCalc. It then uploads the result waveform and kicks off the hidden calculation with the smartCalc background post processing function.

- V93000_RFtoBB_Filter_SMCPostProcess

This snippet does the post processing for the RF to baseband filter test with smartCalc. It calculates the inband flatness of I channel and Q channel and 3db point of I channel and Q channel. The results are judged with the limits in the test table and logged. The snippet can be used together with the snippet V93000_RFtoBB_Filter_Measure in the test method.

- V93000_RFtoBB_Gain_Measure

This snippet sets up and performs a RF to baseband gain and gain compression test. It then uploads the result waveform and kicks off the hidden calculation with the smartCalc background post processing function.

- V93000_RFtoBB_Gain_SMCPostProcess

This snippet does the post processing for the RF to baseband gain and gain compression test with smartCalc. It calculates the gain of I channel and Q channel and the gain compression of I channel and Q channel. The results are judged and logged with the limits in the test table. The snippet can be used together with the snippet V93000_RFtoBB_Gain_Measure in the test method.

- V93000_RFtoBB_IP3_Measure

This snippet sets up and performs a RF to baseband IP3 test. It then uploads the result waveform and kicks off the hidden calculation with smartCalc background processing function.

- V93000_RFtoBB_IP3_SMCPostProcess

This snippet does the post processing for the RF to baseband IP3 test with smartCalc. It calculates the IP3 for I channel and Q channel. The results are judged and logged with the limits in the test table. The snippet can be used together with the snippet V93000_RFtoBB_IP3_Measure in the test method.

- V93000_RFtoBB_IQBalance_Measure

This snippet sets up and performs a RF to baseband IQ balance test. It then uploads the result waveform and kicks off the hidden calculation with smartCalc background processing function.

- V93000_RFtoBB_IQBalance_SMCPostProcess

This snippet does the post processing for the RF to baseband IQ balance test with SmartCalc. It calculates the amplitude balance, phase balance and RSB. The results are judged and logged with the limits in the test table. The snippet can be used together with the snippet V93000_RFtoBB_IQBalance_Measure in the test method.

- V93000_RFtoBB_NoiseFigure_Measure

This snippet setsup and performs a RF to baseband noise figure test. It then uploads the result waveform and kicks off the hidden calculation with smartCalc background processing function.

- V93000_RFtoBB_NoiserFigure_SMCPostProcess

This snippet does the post processing for the RF to baseband noise figure test. It calculates the noise figure of I channel and Q channel. The results are judged and logged with limits in the test table. The snippets can be used together with the snippet V93000_RFtoBB_NoiseFigure_Measure in the test method.
