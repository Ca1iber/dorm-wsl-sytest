# Offline result emulation setup file

#### Subtopics

- [Setup file: mapping to SmarTest concepts](<02.07.12.05.01_Setup_file__mapping_to_SmarTest_concepts.md>)

In the ORE setup file you can define:

- Digital pattern fails
- Parametric values
- Analog waveforms
- Digital capture waveforms

SmarTest injects emulation waveforms and parametric values on test method level and digital fails on the firmware level. The injection on the firmware level implies that the digital fails are visible on the test method API level as well.

## License overview

Offline result emulation (ORE) is available with the S&S_TOOLS_PACKAGE SW license. If this license is not available ORE is disabled.

For an overview of all licensed V93000 products by Product ID, as they are referenced on the Entitlement Certificates, see [Licensed V93000 products](<../02.04_Model_File_and_Licensing/02.04.02.01_V93000_License_Master_Look-up_Table.md>).
