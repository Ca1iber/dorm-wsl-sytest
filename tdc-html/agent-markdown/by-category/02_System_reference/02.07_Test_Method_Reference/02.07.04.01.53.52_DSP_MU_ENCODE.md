# DSP_MU_ENCODE

This API encodes the contents of a specified array using the 碌=255 law.

If other output formats are required, use the DSP_MU_ENCODE API with output_format = CMPLM2. Then, use the VECTOR API to convert result to the desired format.

[Encoding/Decoding Table for A-Law/碌-Law](<02.07.04.03_Encoding_Decoding_Table_for_A-Law__-Law.md>) lists the encoding format of the 碌=255 law conversion used by this API. Also, refer to [Code Format Tables](<02.07.04.04_Code_Format_Tables.md>) for the two's complement and complementary symmetry code format.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_MU_ENCODE(ARRAY_D& src, ARRAY_I& result, INT output_format);
```
