# Macros to get the SmartRDI version number

There are macros provided to retrieve the SmarRDI version information in test method.

These macros are:

RDI_VERSION_MAJOR: major version number

RDI_VERSION_MINOR: minor version number

RDI_VERSION_QUALITY: quality version number

RDI_VERSION_PATCH: patch version number

These macros will be available when `#include "rdi.hpp"` is included in the test method.

These macros can be used in the test method to control whether to compile a section of test method under a specific version of SmartRDI.

## Example

In the following example, the test method code in between will be compiled only when the SmartRDI version number is not less than 2.4.4.

```
#if ((RDI_VERSION_MAJOR ==2)&&(RDI_VERSION_MINOR>4))| |
  ((RDI_VERSION_MAJOR ==2)&&(RDI_VERSION_MINOR ==4)&&(RDI_VERSION_QUALITY >=4))
  //test method code
  ...
#endif
```

## Functional changes

- Introduced in SmartRDI 2.4.4
