# FS Gain / LSB Gain

To calculate FS Gain and LSB Gain the following formulas are used:

 |

Unit

 |

FS_GAIN

 |

LSB_GAIN

 |
 |

mV

 |

(FSR-FSnom) * 1000

 |

(DevLSB-NomLSB) * 1000

 |
 |

V

 |

FSR-FSnom

 |

DevLSB-NomLSB

 |
 |

%nom

 |

(FSR/FSnom - 1) * 100

 |

(DevLSB/NomLSB -1) * 100

 |
 |

%dev

 |

(FSnom/FSR -1) * 100

 |

(1 - NomLSB/DevLSB) * 100

 |
 |

LSBnom

 |

(FSR-FSnom) / NomLSB

 |

DevLSB/NomLSB -1

 |
 |

LSBdev

 |

(FSR-FSnom) / DevLSB

 |

1 - NomLSB/DevLSB

 |

The full scale range (FSR) of the ADC is calculated as follows:

  ![formula](<../../../../raw/26520.png>)

For the calculation of FS Gain and LSB Gain only the DevLSB calculated with END_PT method can be selected.

FSnom is the nominal full scale input range of the ADC.

TRNV(0) is the first transition voltage of the ADC.

TRNV (N-2) is the last transition voltage of the ADC. N equals 2n, with n = number of bits of the ADC. N is the total number of bins of the histogram.
