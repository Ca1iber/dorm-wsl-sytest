# PinPropertyMonitor.printStatus2File()

Prints tester status to text files that are named as user specified.

Printed files are saved in the waste folder under your project root.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PinPropertyMonitor.h.

## Syntax

```
PinPropertyMonitor & printStatus2File(const string& targetName, openmode openMode=NEW);
```

Parameter
 | Parameter  | Description |
 | targetName |

A string given by user based on which the output files are named.

 |
 | openmode  | Decides how to save the updated tester status when a named file exists.

- NEW keeps the existing file (for example a) and saves the updated tester status to a new file (for example a_1).

Default value.

- OUT overwrites the existing file with the updated tester status.
- APP keeps the old contents in the existing file and appends the updated tester status at the end of the file.
 |

## Example

```
ARRAY_I sites;
GET_ACTIVE_SITES(sites);
PinPropertyMonitor ppm1(sites, "@");
ppm1.printStatus2File("a", PinPropertyMonitor::NEW);
ppm1.printStatus2File("b", PinPropertyMonitor::OUT);
ppm1.printStatus2File("c", PinPropertyMonitor::APP);
```
