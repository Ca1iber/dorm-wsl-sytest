# DPS_AUX_TASK.execute()

The DPS_AUX_TASK.execute() member function calls the [DPS_AUX_TASK.setup()](<02.07.04.01.43.04_DPS_AUX_TASK.setup.md>) member function if the measurement conditions have not downloaded to the firmware layer yet.

It then executes a DC parametric test based on the measurement conditions defined in [DPS_AUX_TASK](<02.07.04.01.43_DPS_AUX_TASK.md>) and [DPS_AUX_PIN_TASK](<02.07.04.01.43.01_DPS_AUX_PIN_TASK.md>). If this class is added to [TASK_LIST](<02.07.04.01.240_TASK_LIST.md>), the execute() member function of the TASK_LIST class calls this member function.

When executing the test method, the primaries will be applied.

The member function is to be called only if setups are changed. The member function must not be called if only get...() member functions like [getRangeError()](<02.07.04.01.43.07.02_DPS_AUX_TASK.getRangeError.md>) or [getSurgeTrackerStatus()](<02.07.04.01.43.05_DPS_AUX_TASK.getSurgeTrackerStatus.md>) are defined in the task.

## Syntax

```
void execute();
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Example

The example below shows the surge tracker activation and execution.

The example below shows the setting of the low and high current thresholds and the activation of the surge tracker function.

```
DPS_AUX_TASK auxTask;

ON_FIRST_INVOCATION_BEGIN();

    //
    // Set the current thresholds to -1 mA/1 mA and switch on surge tracker
    //
    auxTask.pin("dps1")
        .selectISensorSetThresholds(-1 mA, 1 mA)
        .setMode(TM::SURGE_TRACKER);

    auxTask.execute();

ON_FIRST_INVOCATION_END();
```

For an extended example see [DPS_AUX_TASK](<02.07.04.01.43_DPS_AUX_TASK.md>).
