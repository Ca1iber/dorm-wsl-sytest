# DSP_MUL_MAT

Performs matrix product to compute the product of two matrices.

Each result element (R(ij)) in result is calculated by multiplying the row of src1 [i] by the column of src2 [j] as follows:

 ![formula](<../../../../raw/30643.png>)

The column dimension of src1 and the row dimension of src2 must be the same. In the above equation, this dimension is p. The following figure shows this matrix multiplication scheme.

The row and column dimensions of src1, src2, and result must be declared as shown in the following table.

## Syntax

```
DSP_MUL_MAT(ARRAY_D& src1, ARRAY_D& src2,
            ARRAY_D& result, INT row,
            INT column1, INT column2);
DSP_MUL_MAT(DOUBLE *src1, DOUBLE *src2,
            DOUBLE *result, INT row,
            INT column1, INT column2);
DSP_MUL_MAT(ARRAY_COMPLEX& src1,
            ARRAY_COMPLEX& src2,
            ARRAY_COMPLEX& result, INT row,
            INT column1, INT column2);
DSP_MUL_MAT(COMPLEX *src1, COMPLEX *src2,
            COMPLEX *result, INT row,
            INT column1, INT column2);
```

## Example

```
ARRAY_COMPLEX matrix1, matrix2, matrix3;
  .
  .
DSP_MUL_MAT(matrix1, matrix2, matrix3, 15, 10, 20);
```

DSP_MUL_MAT computes the matrix product of matrix1 (15 by 10) and matrix2 (10 by 20), and returns the results to matrix3 (15 by 20) as follows:

```
  COMPLEX matrix1[15][10], matrix2[10][20],
          matrix3[15][20];
  int i, j, k;
  double sumr, sumi;

  for(i=0; <15; i++) {
    for(j=0; j<20; j++) {
       sumr=0.0;
       sumi=0.0;
       for(k=0; k<10; k++) {
       sumr=sumr + matrix1[i][k].real * matrix2[k][j].real
                 - matrix1[i][k].imag * matrix2[k][j].imag;
       sumi=sumi + matrix1[i][k].real * matrix2[k][j].imag
                 + matrix1[i][k].imag * matrix2[k][j].real;
       matrix3[i][j].real=sumr;
       matrix3[i][j].imag=sumi;
       }
    }
  }
```
