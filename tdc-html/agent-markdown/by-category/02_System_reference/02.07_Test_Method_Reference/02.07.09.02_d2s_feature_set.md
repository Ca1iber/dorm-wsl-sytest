# d2s feature set

The d2s-framework simplifies the adoption of serial interfaces like I2C, JTAG, and others, among the build-in features listed below.

- Register writes and reads
- Wait statements
- Executing and adding of arbitrary patterns as part of the d2s-generated burst
- Allows concurrent register transactions (write, read, wait) on different ports in parallel
- Address/Data sizes of 64 bits
- Comparing data within a burst to an expected value
- Combining dynamic writing of values per site with other register transactions within the same burst
- Executing of multiple protocols for example, SPI and JTAG) concurrently in the same multiport burstNote Burst as many register transactions as possible.

## Functional changes

- Introduced in SmarTest 6.5.4
