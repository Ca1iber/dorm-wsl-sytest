# EVENT_RANGE_RESTORE.rangeType

This member function sets the range type to be restored, either voltage or current.

## Syntax

```
EVENT_RANGE_RESTORE & rangeType (const TM::RANGE_RESTORE_TYPE & value);
```

Parameter
 | Parameter  | Description |
 |

value

 |

Possible values are:

- TM::RANGE_RESTORE_CURRENT
- TM::RANGE_RESTORE_VOLTAGE
 |

Return value

There is no return value.
