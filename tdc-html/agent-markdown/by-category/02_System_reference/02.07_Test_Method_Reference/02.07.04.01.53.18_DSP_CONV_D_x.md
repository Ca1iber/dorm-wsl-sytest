# DSP_CONV_D_x

These APIs are for converting a double array to the specified array.

If data conversion from DOUBLE to INT type is performed, the decimal fractions resulting from the multiplication and addition are truncated.

DSP_CONV_D_I:

```
  result[i] = (int)(factor * src[i] + offset)
```

DSP_CONV_D_D:

```
  result[i] = factor * src[i] + offset
```

The DSP_CONV_D_C API returns the results to the real part of result, and fills the imaginary part with zeros.

DSP_CONV_D_C:

```
  result[i].real = factor * src[i] + offset
  result[i].imag = 0
```

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_CONV_D_C(ARRAY_D& src, ARRAY_COMPLEX& result,
             DOUBLE factor, DOUBLE offset);
DSP_CONV_D_C(DOUBLE *src, COMPLEX *result,
             INT size, DOUBLE factor, DOUBLE offset);

DSP_CONV_D_I(ARRAY_D& src, ARRAY_I& result,
             DOUBLE factor, DOUBLE offset );
DSP_CONV_D_I(DOUBLE *src, INT *result, INT size,
             DOUBLE factor, DOUBLE offset );

DSP_CONV_D_D(ARRAY_D& src, ARRAY_D& result,
             DOUBLE factor, DOUBLE offset );
DSP_CONV_D_D(DOUBLE *src, DOUBLE *result,
             INT size,
             DOUBLE factor, DOUBLE offset );
```

## Example

```
ARRAY_D array1(512), array2(512);

DSP_CONV_D_D(array1, array2, 10.0, -0.1);
```

DSP_CONV_D_D multiplies the 512 elements of double array array1 by 10.0 and adds -0.1, and returns the results to double array array2.

```
ARRAY_COMPLEX array2(256);
DOUBLE offset, gain;
ARRAY_D array1(256);

gain = 98.0;
offset = 2.0;
DSP_CONV_D_C(array1, array2, gain, offset);
```

DSP_CONV_D_C returns the results to the real part of ARRAY_COMPLEX array array2, and fills the imaginary part with zeros.
