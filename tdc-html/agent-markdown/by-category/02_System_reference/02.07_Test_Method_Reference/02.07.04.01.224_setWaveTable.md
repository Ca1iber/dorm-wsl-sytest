# setWaveTable()

This API is used to set the wavetable to the RF_Trig.

RF_Trig is a type of SynchronizedPort.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTMultiportSync.hpp.

## Syntax

```
setWaveTable(const STRING& _waveTable);
```

Parameter
 |

_waveTable

 |

Specifies the wavetable to the RF_trig port.

 |

## Example

```
CCTMultiportSync     Sync;
...
GET_TESTSUITE_NAME(tsName);
Sync.registerCCTestMethod(tsName, this);
...

RF_Trig::getInstance(tsName).setPort("RF_Port");
RF_Trig::getInstance(tsName).setWaveTable("wt10_protocol_port");
if(mADCControlPort == "ADCControl")
    RF_Trig::getInstance(tsName).setIdentifier("RF_Trig_" + tsName);
else if(mADCControlPort == "ADC1Control")
    RF_Trig::getInstance(tsName).setIdentifier("RF_Trig1_" + tsName);
Sync.registerSyncPort(RF_Trig::getInstance(tsName));

Sync.start();

    mAnalogSeqGroup.setStimDef(CCTgetAnalogRFSetName());
//        mAnalogSeqGroup.setMeasDef(CCTgetAnalogRFSetName());
const std::vector<AnalogSeqGroup::TimeSlice>& timeSliceRef = mAnalogSeqGroup.getTimeSlices();

    for(int timeSliceIdx=0; timeSliceIdx < (int)timeSliceRef.size(); timeSliceIdx++)
    {
        RF_Trig::getInstance(tsName).trigger(timeSliceRef[timeSliceIdx]);
    }
Sync.sync();
Sync.flush();
Primary.label(Sync.getMultiPortBurstName());
Sync.dumpMPBGraph();
```
