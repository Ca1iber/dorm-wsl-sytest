# SAVE_WAVEFORM_DATA()

The purpose of the SAVE_WAVEFORM_DATA function is to save the waveform data on the system controller. This can either be in a single file or in a file for each I and Q data. This dependents on the file type of the to be saved waveform.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/WaveformFile.h.

## Syntax

```
SAVE_WAVEFORM_DATA(const STRING& fileName, const ARRAY_COMPLEX& iqData, const DOUBLE sampleRate, const TM::WAVEFORM_FILE_TYPE fileType = TM::AGILENT_VSA_89600);
SAVE_WAVEFORM_DATA(const STRING& fileName, const ARRAY_D& iData, const ARRAY_D& qData, const DOUBLE sampleRate, const TM::WAVEFORM_FILE_TYPE fileType = TM::AGILENT_VSA_89600);
SAVE_WAVEFORM_DATA(const STRING& iFileName, const STRING& qFileName, const ARRAY_COMPLEX& iqData, const DOUBLE sampleRate, const TM::WAVEFORM_FILE_TYPE fileType = TM::CUSTOM_WAVEFORM_FORMAT);
SAVE_WAVEFORM_DATA(const STRING& iFileName, const STRING& qFileName, const ARRAY_D& iData, const ARRAY_D& qData, const DOUBLE sampleRate, const TM::WAVEFORM_FILE_TYPE fileType = TM::CUSTOM_WAVEFORM_FORMAT);
SAVE_WAVEFORM_DATA(const STRING& fileName, const ARRAY_D& data);
SAVE_WAVEFORM_DATA(const STRING& fileName, const ARRAY_D& data, const DOUBLE sampleRate, const TM::WAVEFORM_FILE_TYPE fileType = TM::ASCII_TEXT);
```

Parameters
 |

Parameter

 |

Description

 |
 |

fileName

 |

The name of the file in which the data is to be saved, it may be an absolute path or a path relative to the device directory.

 |
 |

iFileName

 |

The name of the file in which the I data is to be saved, it may be an absolute path or a path relative to the device directory.

 |
 |

qFileName

 |

The name of the file in which the Q data is to be saved, it may be an absolute path or a path relative to the device directory.

 |
 |

fileType

 |

The type of the waveform file. Optional. This can be one of the following:

TM::AGILENT_VSA_89600

TM::CUSTOM_WAVEFORM_FORMAT

TM::ASCII_TEXT

 |
 |

iqData

 |

The waveform data.

 |
 |

iData

 |

The I part of the waveform data

 |
 |

qData

 |

The Q part of the waveform data

 |
 |

sampleRate

 |

The sample rate of the waveform data.

 |

Return value

There is no return value.

## Example

```

SAVE_WAVEFORM_DATA("waveform/myWave_I.txt", "waveform/myWave_Q.txt", iqData, 100e6);
```

Note This API is not thread-save.
