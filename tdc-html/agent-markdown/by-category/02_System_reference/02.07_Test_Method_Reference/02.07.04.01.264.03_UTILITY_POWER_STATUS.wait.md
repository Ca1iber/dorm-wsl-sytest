# UTILITY_POWER_STATUS.wait()

Specifies the settling time that is applied after the programmed utility power supply has been switched on or off.

The selected [supply state](<02.07.04.01.264.01_UTILITY_POWER_STATUS.state.md>) and the settling time are applied by executing the [UTILITY_POWER_STATUS](<02.07.04.01.264_UTILITY_POWER_STATUS.md>) member function [execute()](<02.07.04.01.264.04_UTILITY_POWER_STATUS.execute.md>).

## Syntax

```
void wait(const DOUBLE & time);
```

  Parameter

 | Parameter  | Description |
 | time |

The time to wait in seconds [s].

The default value of 0 s is set if the time not has been specified by this member function.

   |  Return value There is no return value.

## Functional changes

- Introduced in SmarTest 7.2.1
