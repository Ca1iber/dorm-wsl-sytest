# ABORT_TEST

This API aborts all of the analog sequencers and digital sequencer. ABORT_TEST also disables the external trigger for all analog modules.

The digital sequencer will turn to the break cycle. The AWG sequencers and digitizer/sampler sequencers stop. The TIAs are reset.

This API can also be used to stop the AWG sequencers after the WAIT_TEST_DONE or test execution API waits for the digital sequencer and analog modules except the AWGs to be halted.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Execute.h.

## Syntax

```
ABORT_TEST();
ABORT_TEST (const TM::ABORT_ACTION, const STRING& context);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

ABORT_ACTION

 |

Either: ABORT_DIGITAL, ABORT_AWG, or _ALL. Which are used to abort the digital sequencers, the analog waveform generators, or both, respectively.

 |
 |

context

 |

The name of the digital sequencer context to be aborted.

 |

## Important points

- If this API is executed just after a test execution, analog modules are in the following status:

  - AWGs:

If the AWG generates waveform after a test execution, this API stops the output. For example, if you program the infinite waveform generation, you must execute this API after a test execution.

  - Digitizers/Samplers:

If this API is executed when the module digitizer/sampler is running, this API stops the measurement. The results of the aborted measurement are corrupt.

If this API is executed after finishing the measurement, the module digitizer/sampler keeps the measurement results on the internal waveform memory.

  - TIAs:

If this API is executed after or during a test execution, the TIA is reset and all measurement results on the TIA are discarded.

- If you use an AWG with the infinite waveform generation and a TIA in a test, execute this API to stop the AWG after getting the TIA results below.

```
EXECUTE_TEST();                 // Test execution
result = TIA("pinA").getXXXX(); // Get TIA result
ABORT_TEST();                   // Stop AWG output
```

- If you use the digital drivers with the infinite vector generation and a TIA in a test, use the use SEQUENCER_STATUS API (Sequencer.abort()) to set the digital sequencer to break state. The measurement results on the TIA are kept.

## Example

- Aborting the test execution when the condition specified in the if-clause is resolved:

```
  :
If (vout > 1.5)
{
  ABORT_TEST();
}
  :
```

- Aborting the digital sequencers in the digital sequencer context "test":

```
ABORT_TEST(TM::ABORT_DIGITAL, "test");
```
