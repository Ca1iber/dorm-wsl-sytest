# How to install a universal test method library for system wide usage

This topic shows how to install a mature test method library for the use of all users of the same SmarTest system.

## About this task

With this task, the users of the same SmarTest system can share and reuse the test method library conveniently.

## Before you begin

Make sure the SmarTest revision in use is 6.3 or later. The universal test method library must be error free and ready to use.

## Procedure

-  If you are normal user, switch to the administrator user using command su .
-  Copy the test method shared library (*.so) to the directory /var/opt/hp93000/soc/testmethod/.

## Results

Now all users of the SmarTest system can directly use the test method library to test their devices.

## Example

To install the test method library my_utm of the demo user for system wide usage open a terminal window and type:

- $su

press Enter and if required, type the password

- $cp /home/demo/workspace/my_utm/Debug/libmy_utm.so /var/opt/hp93000/soc/testmethod/
