# CCTRegisterTMUTask

Merges multiple pattern-controlled TMU tasks in SmartCalc from different test suites into one task, and then runs them in parallel.

This function is usually used in the `init()` function but not used in the other functions of the CCF test method template.

The CCTRegisterTMUTask(TMU_TASK& task) API parses TMU task in each test suite to get the pins and their parameters into the CTF framework. All the pins are added into one, merged TMU task and run with the burst pattern.

For example:

Test suite TS1 runs TMU task T1 for pin1 in Label1

Test suite TS2 runs TMU task T2 for pin2 in Label2

You can use the CCTRegisterTMUTask(TMU_TASK& task) API to merge pin1 and pin2 and add them to a new TMU task and run them with the burst pattern concurrently.

## Limitation

CTF TMU burst only support testing of different TMU pins from different test suites. It cannot be used to test the same pin from different test suites. The following error message is displayed if the same pin is registered in more than one test suite:

```
The tmu pin "xxx" is registered by testsuite "TS_1" and TS_2", this is forbidden in concurrent synchronized testing. Please register a tmu pin in only one testsuite.
```

## Syntax

```
void CCTestMethod::CCTRegisterTMUTask(TMU_TASK& task);
```

Parameter
 |

Parameter

 |

Description

 |
 |

task

 |

A class object of one of the TMU_TASK class.

 |

Return value

There is no return value.

## Examples

### Generic example

```
          CCT_TS1::init()
          {
              TMU_TASK task;
                  task.pin("pin1").
                    setEdgeSelect(TMU::RISE).
                    setNumShots(2).
                    setNumMeasurements(arming).
                    setInitialDiscard(0);
              CCTRegisterTMUTask(task);
          }

```

### CCTtmuTask macro

Returns a reference of merged TMU task:

```
#define CCTtmuTask CCTgetTMUTask
Example:
CCT_TS1::process()
{
  TMU_RESULT results;
         CCTtmuTask.pin("pin1").uploadRawResults(results);
       }
```

### Burst TMU test with hidden upload

This appears to be covered in TDC topic 122306 CCTenableSMC:

```
TS1::init( )
{
  CCTenabelSMC(SMC_AUTO);
  TMU_TASK task;
  task.pin("pin1").setPreScaler(1)
            .setNumShots(2)
            .setNumSamples(5000)
            .setNumMeasurements(2);
  CCTRegisterTMUTASK(task);
}
TS1::Process()
{
    TMU_RESULT result;
    SMC_TMU_UPLOAD_RAW_RESULTS(result,CCTgetResultHandle(),"pin1",2 ,2 ,5000 ,0,true);
    ...
}
```
