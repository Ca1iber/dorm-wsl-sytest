# PutDebugTrace

The `PutDebugTrace` API sends the specified array data to the Signal Analyzer tool if the debug_analog testflow flag is `on`.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PutDebugTrace.h.

### Syntax

```
PutDebugTrace().member_function;
PutDebugTrace("myMeas").member_function;
```

myMeas is the name of the `PutDebugTrace` object.

member_function is the member function defined in the `PutDebugTrace` class. For retrieving data, only one member function is available.

## Member functions

### setLabel()

```
PutDebugTrace& setLabel(const STRING& newLabel);
```

This function specifies a label to identify the array data.

Parameter
 |

label

 |

The label for the trace to identify the array data.

The label is used with the pin parameter in the `setPin` member function to specify the data in the Signal Analyzer tool. You can use the same label for different pins.

 |

### setPin()

```
PutDebugTrace& setPin(const STRING& pin);
```

Parameter

pin

The pin name to identify the array data. It is used with the label parameter in the `setLabel` member function to specify the data in the Signal Analyzer tool.

### setEnable()

```
PutDebugTrace& setEnable(Boolean enable);
```

This function activates or deactivates the execution of the following member functions:

- `setWaveform`
- `setScatter`
- `setReflectionCoefficient`
- `setObject`

It overrides the debug_analog testflow flag.

Parameter
 |

enable

Enable or disable the execution of the following member functions:

- `setWaveform`
- `setScatter`
- `setReflectionCoefficient`
- `setObject`
 |

### setObject()

```
PutDebugTrace& setObject(const DEMODULATION& demod, TM::GRAPH_SELECTION graphSelect);
PutDebugTrace& setObject(const DEMODULATION& demod, const STRING& graphSelect);
PutDebugTrace& setObject(const MEAS_DEF_I& measDef, TM::GRAPH_SELECTION graphSelect);
```

This function takes the `DEMODULATION` or `MEAS_DEF_I` object as an input parameter, and copies its selected trace data into the `PutDebugTrace` object.

Parameters
 |

demod

 |

The `DEMODULATION` object to be passed to the Signal Analyzer tool.

 |
 |

meas

 |

The `MEAS_DEF_I` object to be passed to the Signal Analyzer tool.

 |
 |

graphSelect

 |

The style of the graph.

Using a [DEMODULATION](<02.07.04.01.30_DEMODULATION.md>) object, the valid values of the graphSelect parameter are:

- TM::CONSTELLATION: plots the constellation points of a demodulation
- TM::COMPOSITE: plots the composite error of a demodulation
- TM::EVM_VS_SYMBOL: plots the EVM (Y-Axis) versus the Symbol Number (X-Axis)
- TM::ALL_GRAPHS: plots all graphs available for the object
- TM::ERROR_VECTOR_SPECTRUM: plots the EVM (Y-Axis) versus Frequency Offset (X-Axis)
- TM::ERROR_VECTOR_TIME: plots the EVM (Y-Axis) versus Time (X-Axis)

 |

## Examples

### Display a Wave object

```
Wave<DOUBLE> wave(1024, 1.0);
STRING pin = "Aout";
STRING label = "label";
DGT(pin).getWaveform(wave);
PutDebugTrace (label).setPin(pin).setWaveform(wave).upload();
```

This example displays the defined waveform `wave(1024, 1.0d)` in the Signal Analyzer tool if the debug_analog testflow flag is on.

### Sets the reflection coefficients

```
ARRAY_COMPLEX data;
ARRAY_D freqs;
PutDebugTrace smithTrace("myTrace");
smithTrace.setReflectionCoefficients(data, freqs);
PutDebugGraph("mygraph").setTrace(smithTrace).show();
```

This example sets the reflection coefficients for "`myTrace`" and shows the trace in "`mygraph`".
