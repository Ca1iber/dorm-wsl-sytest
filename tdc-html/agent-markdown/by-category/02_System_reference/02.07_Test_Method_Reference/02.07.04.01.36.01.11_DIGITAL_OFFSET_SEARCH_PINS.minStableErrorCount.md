# DIGITAL_OFFSET_SEARCH_PINS.minStableErrorCount()

Defines a minimum error count to measure a stable search. If the adjacent tests begin to generate the same number of errors, and the number of these tests is equal to or greater than this given count, the search is regarded as stable.

This function is used together with [DIGITAL_OFFSET_SEARCH_PINS.resolutionHistogramSearch()](<02.07.04.01.36.01.17_DIGITAL_OFFSET_SEARCH_PINS.resolutionHistogramSearch.md>) to define a histogram based search, which is performed after binary search to move the left boundary of the PASS area to the left or the right boundary to the right until reaching the stable condition.

## Syntax

```
DIGITAL_OFFSET_SEARCH_PINS& minStableErrorCount(INT minStableErrCount);
```

Parameter
 |

Parameter

 |

Description

 |
 |

minStableErrCount

 |

A number used to define the minimum number of adjacent tests that have the same number of errors.

 |

## Return value

A reference to the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) object.
