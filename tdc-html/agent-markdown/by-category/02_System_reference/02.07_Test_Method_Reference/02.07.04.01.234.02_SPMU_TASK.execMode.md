# SPMU_TASK.execMode()

This member function selects the execution mode of the DC measurement. The execution mode determines specifics, like if the measurement returns global or per pin pass/fail results or per pin values and other options.

## Syntax

```
SPMU_TASK& execMode(const STRING& mode);
SPMU_TASK& execMode(const TM::DCTEST_MODE mode);
SPMU_TASK& execMode(const TM::DCFORCE_MODE mode);
```

 Parameter

 |

Parameter

 |

Description

 |
 |

mode

 |

Default mode is TM:GPF.

Refer to the list of available options of the mode parameter below.

 |

Available options of parameter: mode
 |

mode

 |

Description

 |
 |

"GPF"

TM::GPF

 |

Sets the execution mode to return a global pass/fail result.

 |
 |

"PPF"

TM::PPF

 |

Sets the execution mode to return per pin pass/fail results.

 |
 |

"PVAL"

TM::PVAL

 |

Sets the execution mode to return per pin value and pass/fail results.

 |
 |

"FORCE_ON"

TM::FORCE_ON

 |

Sets the instrument to the DC source in force mode. It does not perform a measurement. The instruments stays in this mode until TM::FORCE_OFF or another DC execution using this instrument occurs.

 |
 |

"FORCE_OFF"

TM::FORCE_OFF

 |

Disables the use of the instrument as DC source.

 |
 |

"FORCE_AUTO"

TM::FORCE_AUTO

 |

Sets the mode to use the instrument as a DC source. Thus it does not perform a measurement. The instruments statys in this mode until the end of the test suite execution.

 |
 |

"DCTEST_AUTO"

TM::DCTEST_AUTO

 |

Sets the execution mode of DC tests to be retrieved from the settings of the [test suit flags](<../02.10_Data_Logging/02.10.01.09.02_Test_suite_flags_for_data_logging.md>).

   | Note Either use the string (i.e. "GPF") or the namespace, (i.e. TM::GPF) for setting the mode. Return value A reference to the SPMU_TASK object.Note To retrieve results use the [SPMU_TASK.getPassFail()](<02.07.04.01.234.05_SPMU_TASK.getPassFail.md>) or [SPMU_TASK.getValue()](<02.07.04.01.234.06_SPMU_TASK.getValue.md>) functions.

## Examples

### Example 1

The following example shows equal settings to set the mode to return per pin pass/fail using the different interfaces.

```
SPMU_TASK IFtask;

IFtask.execMode("PPF");

// is equal to
// IFtask.execMode(TM::PPF);
```

### Example 2

In this example, a SPMU VFIM per-pin value test on the pin HMPU1 is performed via the utility pogo block. The measured current value is retrieved. The pass/fail result are judged and logged. This approach is useful if you want to do Kelvin connection type of measurements.

```
SPMU_TASK spmuTask;

ON_FIRST_INVOCATION_BEGIN();

    CONNECT();

    //
    // The pin name determines that the SPMU is connected via the utility pogo block
    //
    spmuTask.pin("HPMU1").vForce(3 V).clamp(1.5 mA).min(0.5 mA).max(1 mA).relay("NTMBB");

    spmuTask.execMode(TM::PVAL).execute();

ON_FIRST_INVOCATION_END();

//
// Upload results and log data
//
double iMeas;

iMeas = spmuTask.getValue("HPMU1");

cout << iMeas << endl;

TEST( "I/O1", "simpleSpmu", spmuTask.getPassFail("HPMU1")?TM::Pass:TM::Fail, TRUE);
```
