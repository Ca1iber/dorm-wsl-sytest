# TIMING_OFFSET_SEARCH_PINS.minStableErrorCount()

This function defines the minimum number of adjacent measurements with the same number of detected errors to be considered as stable. This function and `resolutionHistogramSearch()` defines a histogram based search, which is performed after the binary search. It moves the left boundary of the PASS area to the left (the right boundary to the right) until the number of errors is the same for the number of search steps specified with minStableErrCount.

## Syntax

```
TIMING_OFFSET_SEARCH_PINS& minStableErrorCount(INT minStableErrCount);
```

Parameter
 |

I

 |

minStableErrCount

 |

The minimum number of search steps needed for the stable area.

 |

## Functional changes

- Introduced in SmarTest 7.1.0
