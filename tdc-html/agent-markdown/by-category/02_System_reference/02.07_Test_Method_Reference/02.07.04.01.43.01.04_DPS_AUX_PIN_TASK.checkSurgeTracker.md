# DPS_AUX_PIN_TASK.checkSurgeTracker()

This member function retrieves the flags "High voltage or current of surge tracker exceeded" or "Low voltage or current of surge tracker exceeded" from the hardware.

For [XPS256](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>), the member function retrives the status of the flags "High voltage of surge tracker reached", "High current of surge tracker reached", "Low voltage of surge tracker reached", and "Low current of surge tracker reached". For more information, refer to [XPS256 status flags](<../02.05_Test_Head_Cards/02.05.05.03.10.02_XPS256_status_flags.md>).

 The checkSurgeTracker() member function

- checks if any voltage or current surge goes beyond the thresholds,
- writes the accumulated status to the test method cache, which can be read by the [DPS_AUX_TASK.getSurgeTrackerStatus()](<02.07.04.01.43.05_DPS_AUX_TASK.getSurgeTrackerStatus.md>) function,
- resets the status, and
- checks whether the surge tracker is in active state. If it is not, it triggers a warning message.

The read values are stored in the test method cache. As long as the test method is loaded, the stored values in the test method cache are valid and can be retrieved for the site in focus.

The surge tracker monitors the voltage via sense lines or the output current.

 Note

Pass/fail results that are retrieved by command [PRLT](<../02.06_Command_Reference/02.06.02.02.183_PRLT__-__request_Parallel_ResuLTs.md>) are invalidated by commands [CSAS](<../02.06_Command_Reference/02.06.02.02.33_CSAS__-__Channel_Slot_Accumulated_Status.md>) and [PSAS](<../02.06_Command_Reference/02.06.02.02.188_PSAS__-__Power_Supply_Accumulated_Status.md>).

We recommend therefore using the command PRLT directly after the related functional test and before command CSAS or PSAS are performed.

This behavior applies not only to the commands but also to the related APIs: Function [GET_FUNCTIONAL_RESULT()](<02.07.04.01.88_GET_FUNCTIONAL_RESULT.md>) must be performed before any of the [DPS_AUX_PIN_TASK.check...()](<02.07.04.01.43.01_DPS_AUX_PIN_TASK.md>) functions is called or the results of GET_FUNCTIONAL_RESULT() are invalid.

## Syntax

```
DPS_AUX_PIN_TASK & checkSurgeTracker(TM::SURGE_TRACKER_CHECK check = TM::AGAINST_BOTH);
```

  Parameters

 | Parameter  | Description |
 | check  | Selects the comparator to be checked. |

Available options of parameter: check
 | Parameter  | Description |
 | TM::AGAINST_BOTH  | Checks if any voltage or current surge goes beyond the high and low thresholds.

This is the default state.

 |
 | TM::AGAINST_HIGH  | Checks if any voltage or current surge goes beyond the high threshold. |
 | TM::AGAINST_LOW  | Checks if any voltage or current surge goes beyond the low threshold.  |   Return value

A reference to the corresponding [DPS_AUX_PIN_TASK](<02.07.04.01.43.01_DPS_AUX_PIN_TASK.md>) object.

For retrieving the read result see [DPS_AUX_TASK.getSurgeTrackerStatus()](<02.07.04.01.43.05_DPS_AUX_TASK.getSurgeTrackerStatus.md>).

## Example

The example below sets current thresholds, activates the surge tracker, checks the status against the current thresholds, and retrieves the result.

```
DPS_AUX_TASK auxTask;

ON_FIRST_INVOCATION_BEGIN();

    //
    // Set the current thresholds to -1 mA/1 mA and switch on surge tracker
    //
    auxTask.pin("dps1")
        .selectISensorSetThresholds(-1 mA, 1 mA)
        .setMode(TM::SURGE_TRACKER);

    auxTask.execute();

    auxTask.pin("dps1").checkSurgeTracker(TM::AGAINST_BOTH);

ON_FIRST_INVOCATION_END();

//
// Get the result of surge tracker
//
TM::SURGE_TRACKER_STATUS surgeTrackerStatus = auxTask.getSurgeTrackerStatus("dps1");

switch (surgeTrackerStatus)
{
    case TM::SURGE_TRACKER_NONE_DETECTED:

        cout << "DPS_AUX_TASK::getSurgeTrackerStatus for pin dps1: SURGE_TRACKER_NONE_DETECTED"
             << endl << endl;

        break;

    case TM::SURGE_TRACKER_HIGH_DETECTED:

        cout << "DPS_AUX_TASK::getSurgeTrackerStatus for pin dps1: SURGE_TRACKER_HIGH_DETECTED"
             << endl << endl;

        break;

    case TM::SURGE_TRACKER_LOW_DETECTED:

        cout << "DPS_AUX_TASK::getSurgeTrackerStatus for pin dps1: SURGE_TRACKER_LOW_DETECTED"
             << endl << endl;

        break;

    case TM::SURGE_TRACKER_BOTH_DETECTED:

        cout << "DPS_AUX_TASK::getSurgeTrackerStatus for pin dps1: SURGE_TRACKER_BOTH_DETECTED"
             << endl << endl;

        break;

    default:

        break;
};
```
