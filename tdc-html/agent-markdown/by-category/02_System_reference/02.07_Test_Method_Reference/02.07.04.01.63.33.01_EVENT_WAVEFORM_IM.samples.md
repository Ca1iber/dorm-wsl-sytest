# EVENT_WAVEFORM_IM.samples()

Sets the number of samples to capture.

## Syntax

```
EVENT_WAVEFORM_IM & samples(INT samples);
```

Parameter
 | Parameter  | Description |
 | samples |

Number of samples

 |

Return value

There is no return value.
