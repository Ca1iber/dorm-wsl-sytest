# Test program requirements for offline result emulation

The usage of the offline result emulation requires a software license, see [The Software .lic license files](<../02.04_Model_File_and_Licensing/02.04.05.02_The_Software_.lic_license_files.md>), and, depending on the use case, different test program configurations, see below.

- A setup file which is read by an activation test method is required in any case.
- Test method changes are required for the parametric use case.
- Test methods implementing analog or digital capture need to be changed to using the SmartCalc API, if they not already do so.

## License overview

Offline result emulation (ORE) is available with the S&S_TOOLS_PACKAGE SW license. If this license is not available ORE is disabled.

For an overview of all licensed V93000 products by Product ID, as they are referenced on the Entitlement Certificates, see [Licensed V93000 products](<../02.04_Model_File_and_Licensing/02.04.02.01_V93000_License_Master_Look-up_Table.md>).
