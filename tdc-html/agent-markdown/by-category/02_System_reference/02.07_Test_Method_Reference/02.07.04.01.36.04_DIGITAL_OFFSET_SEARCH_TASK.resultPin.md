# DIGITAL_OFFSET_SEARCH_TASK.resultPin()

Returns the reference to a [DIGITAL_OFFSET_SEARCH_RESULT_PINS](<02.07.04.01.36.02_DIGITAL_OFFSET_SEARCH_RESULT_PINS.md>) object, which is used to define the result pins that will return pass/fail test result for the specified setup pins.

The default result pins are:

- If the setup pins specified in this function are IO pins, the result pins are the same pins.
- If the setup pins specified in this function are I pins, the result pins will be O or IO pins automatically found with this function.
- If the setup pins specified in this function are the pins with differential mode, the result pin is the master pin of the differential pair.

## Syntax

```
DIGITAL_OFFSET_SEARCH_RESULT_PINS& resultPin(const STRING& setupPin);
```

Parameter
 |

Parameter

 |

Description

 |
 |

setupPin

 |

The pins for which you want to create a DIGITAL_OFFSET_SEARCH_RESULT_PINS object.

 |

## Return value

Returns a reference to the [DIGITAL_OFFSET_SEARCH_RESULT_PINS](<02.07.04.01.36.02_DIGITAL_OFFSET_SEARCH_RESULT_PINS.md>) object so that you can use its member functions to define different result pins or retrieve defined result pins.

## Examples

### Example 1

Define the result pin as the same as the setup pin "pcie_tx1n". "pcie_tx1n" is an IO pin.

```
STRING strpins1("pcie_tx1n");

DIGITAL_OFFSET_SEARCH_TASK dos;

dos.resultPin(strpins1);
```

### Example 2

Define "pcie_tx2n" as the result pin while the setup pin is "pcie_tx1n".

```
STRING strpins1("pcie_tx1n");
STRING strpins2("pcie_tx2n");

DIGITAL_OFFSET_SEARCH_TASK dos;

dos.resultPin(strpins1).setResultPin(strpins2);
```
