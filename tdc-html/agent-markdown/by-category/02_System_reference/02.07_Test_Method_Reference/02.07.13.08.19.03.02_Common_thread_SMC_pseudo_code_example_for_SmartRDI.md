# Common thread SMC pseudo code example for SmartRDI

Background threads using SmartCalc (SMC) in SmartRDI can be implemented as "thread per site" or as "common thread" (also known as "single thread"). The following example shows the pseudo code for implementing a "common thread" for all sites.

The "common thread" is defined by calling [SMC_ARM()](<02.07.04.01.231.01_SMC_ARM.md>) or a variant of this function inside of the [ON_FIRST_INVOCATION](<02.07.04.01.138_ON_FIRST_INVOCATION_BEGIN.md>) block. This creates one single thread for all active sites. Results for all active sites can be uploaded within this thread [Using hidden upload with SmartRDI](<02.07.13.08.19.01_Using_hidden_upload_with_SmartRDI.md>).

You must pass an array, holding the numbers of all active sites to the background process. The background process must parse this array and process only the active sites.

For more information, refer to [SmartCalc "Thread per site" and "Common thread"](<02.07.10.02.01_SmartCalc__Thread_per_site__and__Common_thread.md>).

## Example

### Common thread pseudo code example

The pseudo code below shows the typical code structure of a hidden upload using a "common thread" for all active sites:

```
ARRAY_I sites;

GET_ACTIVE_SITES(sites);

ON_FIRST_INVOCATION_BEGIN();
{
    rdi.hiddenUpload(TA::ALL)

    RDI_BEGIN();
    {
        ...
         rdi.dc("Result_ID").pin("..."). 鈥?.execute();
        ...
    }
    RDI_END();

    SMC_ARM(sites);

ON_FIRST_INVOCATION_END();
...
```

Background process of the same test suite:

```
public:

void SMC_backgroundProcessing(ARRAY_I sites)
{
    double result;

    for(int i = 0; i < sites.size(); i++)
    {
        result = rdi.site(sites[i]).id("Result_ID").getValue();
        ...
        ...
    }
}
```

For information on how to transfer data like the array of active sites to the background process, refer to section [Passing data to the background process](<02.07.04.01.231.01_SMC_ARM.md#_120107__dle_SMC_ARM_Passing_data_to_the_background_process>) in [SMC_ARM()](<02.07.04.01.231.01_SMC_ARM.md>).

For a compilable, none-SmartRDI example, see [SmartCalc common thread example](<02.07.10.02.01.02_SmartCalc_common_thread_example.md>).
