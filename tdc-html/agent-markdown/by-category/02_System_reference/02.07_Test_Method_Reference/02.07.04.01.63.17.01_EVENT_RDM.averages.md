# EVENT_RDM.averages()

Sets the number of internal DC measurement samples for hardware based averaging.

## Syntax

```
EVENT_RDM & averages(const EVENT_VALUE_INT & samples);
```

  Parameter

 | Parameter  | Description |
 | samples  | Number of internal samples from which the average is created.  |  Return value A reference to the corresponding [EVENT_RDM](<02.07.04.01.63.17_EVENT_RDM.md>) object.
