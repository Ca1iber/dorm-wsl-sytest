# Supported SmarTest Versions

The tables below show the relationship between supported SmarTest versions and SmartRDI versions.

Starting from SmartRDI 7.4.4, SmartRDI is only compatible with its correspondent SmarTest version and does not support any other SmarTest versions. For example, SmartRDI 7.4.4 only supports SmarTest 7.4.4.
