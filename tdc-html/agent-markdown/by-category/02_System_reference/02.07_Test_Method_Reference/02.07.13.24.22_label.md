# label()

Specifies the name of a pattern鈥慴ased on which a copy of the pattern is to be generated.

The specified label must be the main label, not a burst label or subroutine.

 This function does not support most of the instruction related commands such as [repeat()](<02.07.13.24.31_repeat.md>), [matchBit()](<02.07.13.24.49.02.01_matchBit.md>), [matchCycle()](<02.07.13.24.49.02.02_matchCycle.md>), [matchData()](<02.07.13.24.49.02.03_matchData.md>) and [instruction()](<02.07.13.24.49.01.01_instruction.md>). It supports the sublabel related commands such as [insertSub()](<02.07.13.24.21_insertSub.md>), [insertJmpe()](<02.07.13.24.20_insertJmpe.md>) and [repeatSub()](<02.07.13.24.32_repeatSub.md>).Note When readMode(TA::EMAP) is used, the specified label must contain just flat vectors before the position where smartVec commands begin to be effective and it must not have any instruction such as RPTV.

## Syntax

```
label(const string& sLabelName);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

sLabelName

 |

The label to be executed / pattern on which measurement is performed.

 |

Return value

There is no return value.

## Example

```
RDI_BEGIN();
...
  rdi.smartVec().label("label4").pin("D3").writeData(0x55,8,0).execute();
...
RDI_END();
```
