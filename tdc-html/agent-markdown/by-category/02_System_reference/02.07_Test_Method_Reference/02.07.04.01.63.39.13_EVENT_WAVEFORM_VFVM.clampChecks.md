# EVENT_WAVEFORM_VFVM.clampChecks()

Enables or disables the current clamp checks.

Per default these checks are off. If they are enabled and a checked clamp is hit, the event contributes with a FAIL to the global test result.

Both this member function and [EVENT_WAVEFORM_VFVM.iClampChecks()](<02.07.04.01.63.39.15_EVENT_WAVEFORM_VFVM.iClampChecks.md>) control the same functionality of the hardware.

## Syntax

```
EVENT_WAVEFORM_VFVM & clampChecks(bool failOnLow = true, bool failOnHigh = true);
```

Parameters
 | Parameter  | Description |
 | failOnLow |

Enables or disables the lower clamp check.

- true: The lower clamp check is enabled.
- false: The lower clamp check is disabled.

Default value: The clamp check is disabled.

 |
 | failOnHigh |

Enables or disables the upper clamp check.

- true: The upper clamp check is enabled.
- false: The upper clamp check is disabled.

Default value: The clamp check is disabled.

 |

## Return value

A reference to the corresponding [EVENT_WAVEFORM_VFVM](<02.07.04.01.63.39_EVENT_WAVEFORM_VFVM.md>) object.
