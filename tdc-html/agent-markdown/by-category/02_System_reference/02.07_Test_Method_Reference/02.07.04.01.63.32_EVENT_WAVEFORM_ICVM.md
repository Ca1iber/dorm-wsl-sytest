Combined setting/measure waveform classes provide functionality to define events, which generate waveforms, and measure at the same point in time.

Specialized setting/measure waveform classes are EVENT_WAVEFORM_ICIM (clamp current setting / current measure waveform) and EVENT_WAVEFORM_ICVM (clamp current setting / voltage measure waveform).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_WAVEFORM_ICVM ( const STRING & id);
EVENT_WAVEFORM_ICVM ( INT & id);
```

This constructs an object of the EVENT_WAVEFORM_ICVM class. The class derives from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

Parameter
 | Parameter  | Description |
 | id |

Event identifier

 |

Return value

There is no return value.

## Example

```
    PATTERN_CONTROLLER cleanUpPattern;
    PATTERN_CONTROLLER pc;

    EVENT_WAVEFORM_ICVM iClampVMeasWaveform("iClampVMeasWaveform");

    ANALOG_WAVEFORM rampUp1("rampUp1"), rampUp2("rampUp2");
        rampUp1.definition(TM::RAMP).min(0.).max(3.)
                                    .direction(TM::POS).samples(10);
        rampUp2.definition(TM::RAMP).min(1.).max(4.)
                                    .direction(TM::POS).samples(10);

    ON_FIRST_INVOCATION_BEGIN();

      cleanUpPattern.label("patEvents", "@")
                    .vecEvents("dps1")
                    .clearAll()
                    .setup();

      iClampVMeasWaveform.iClampLow(rampUp1)
                         .iClampHigh(rampUp2).averages(3)
                         .sampleVectorDistance(100);

      // insert events into pattern
      PATTERN & pattern(pc.label("patEvents", "@"));

         pattern.vecEvents("dps1")
                .insert(1400, iClampVMeasWaveform)

         pc.setup();

    ON_FIRST_INVOCATION_END();
```
