The d2s framework provides the flexibility to program one or more registers to meet your application needs.

## About this task

The user can insert one or more framework command lines. Each of these lines will write the given value to the specified register. Depending on the mode of operation (learning or production mode) this will either create static labels, that can be burst later (learning mode), or execute already burst labels (production mode).

The following procedure provides an overview on the steps necessary to implement a serial protocol using the d2s-framework. A detailed description of each step is provided with the respective link.

The examples provided are related to each other the way that they utilize the corresponding previous example.
