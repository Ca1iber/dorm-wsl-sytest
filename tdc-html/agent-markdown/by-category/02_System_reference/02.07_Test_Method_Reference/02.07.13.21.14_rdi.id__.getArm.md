# rdi.id().getArm()

Extracts the arm time and saves it to a double value. The arm time is the time from the beginning of the used pattern to the position where the arming of the TMU is done. This time is the reference point for the time stamper measurements.

## Syntax

```
double getArm(const string &sPin);
```

Parameter
 | Parameter  | Description |
 | sPin  | The pin that returns the arm time. |

## Return Value

Double value that represents the time from the beginning of the used pattern to the position where the arming of the TMU is done.

## Example

```
ON_FIRST_INVOCATION_BEGIN();

    RDI_BEGIN();

        rdi.tmu("result_1").pin("PVI8_PMU_1")
              .measMode(TA::RISE_TIME).vth(1.0 V, 2.0 V).samples(50).execute();

        rdi.wait(100 us);

        rdi.tmu("result_2").pin("PS1600_1")
                .measMode(TA::RISE).vth(1.0 V).samples(50).execute();

        rdi.wait(100 us);

    RDI_END();

ON_FIRST_INVOCATION_END();

double value_1 = rdi.id("result_1").getArm("PVI8_PMU_1");
double value_2 = rdi.id("result_2").getArm("PS1600_1");
```
