# EVENT_RANGE_RESTORE

#### Subtopics

- [EVENT_RANGE_RESTORE.rangeType](<02.07.04.01.63.15.01_EVENT_RANGE_RESTORE.rangeType.md>)
- [EVENT_RANGE_RESTORE.getRangeType](<02.07.04.01.63.15.02_EVENT_RANGE_RESTORE.getRangeType.md>)

This event class restores the very first measurement range specified in the pattern.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_RANGE_RESTORE (const STRING & id);
EVENT_RANGE_RESTORE (INT & id);
```

This constructs an object of the EVENT_RANGE_RESTORE class. The class derives from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

Parameter
 | Parameter  | Description |
 |

id

 |

Event identifier

 |

Return value

There is no return value.

## Example

```
PATTERN_CONTROLLER pc;

EVENT_RANGE_RESTORE eventRangeRestore("eventRangeRestore");

ON_FIRST_INVOCATION_BEGIN();

    eventRangeRestore.rangeType(TM::RANGE_RESTORE_CURRENT);

    //
    // Insert events into pattern
    //
    PATTERN & pattern(pc.label("patEvents", "@"));

    pattern.vecEvents("dps1").clearAll().setup();
    pattern.vecEvents("dps1").insert(3800, eventRangeRestore);

    pc.setup();

ON_FIRST_INVOCATION_END();
```
