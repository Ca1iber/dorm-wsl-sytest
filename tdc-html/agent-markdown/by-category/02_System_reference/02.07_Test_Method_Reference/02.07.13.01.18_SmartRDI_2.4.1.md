# SmartRDI 2.4.1

This section summarizes the changes and new features in SmartRDI 2.4.1.

Changes and new features
 |

Category

 |

Description

 |
 |

General

 |

- [Sync group support](<02.07.13.08.17_Sync_group_support_with_SmartRDI.md>) for multiport bursts.

  - [syncGroup()](<02.07.13.08.17.02_syncGroup.md>)
  - [addPort()](<02.07.13.08.17.01_addPort.md>)

- Pin context support.
 |
 |

func()

 |

- An ERMP option for pass-fail-per-label results in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>).
 |
 |

dc()

 |

- PPMU or BADC setups run only in the first iteration of loops. See [firstRunInLoop()](<02.07.13.12.01.01.06_firstRunInLoop.md>).
- Insertion of sublabels with DC events.See [insertSub()](<02.07.13.12.02.20_insertSub.md>).
- Runtime current clamp for DC tests. See [Changing the parameter value at runtime with SmartRDI](<02.07.13.08.03_Changing_the_parameter_value_at_runtime_with_SmartRDI.md>).
- One-side limit for DC Scale pins. See [limit()](<02.07.13.12.01.01.13_limit.md>).
 |
 |

smartVec()

 |

- Match CONTINUE support for sequencer instructions. See [instruction()](<02.07.13.24.49.01.01_instruction.md>) and [matchData()](<02.07.13.24.49.02.03_matchData.md>).
- An SHMEM option in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>) for support of SHMEM memory in pattern generation.
 |
 |

digCap()

 |

- Data format support enhancement. See [format()](<02.07.13.13.10_format.md>).
 |
 |

cogo()

 |

- Cogo pass/fail judgment enhancement for DC Scale pins. See [SmartRDI: Pattern-based conditional jump - cogo](<02.07.13.19_SmartRDI__Pattern-based_conditional_jump_-_cogo.md>).
  |
