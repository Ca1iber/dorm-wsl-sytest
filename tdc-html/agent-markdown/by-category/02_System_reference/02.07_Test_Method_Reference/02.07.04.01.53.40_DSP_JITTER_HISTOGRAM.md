# DSP_JITTER_HISTOGRAM

This API calculates the jitter histogram based on the input of error count and timing data. The jitter API returns the following values: mean, rms, peak2peak, median and medist.

## JitterHistogramType

This type is defined for jitter histogram result. It contains a set of jitter histogram attribute data.

```
typedef struct
{
  DOUBLE mean; //the mean value
  DOUBLE rms; //the RMS value
  DOUBLE peak2peak; //the peak to peak value
  DOUBLE median; //the middle line of the edge positions list
  DOUBLE medist; //the maximum edge distance from the jitter median.
} JitterHistogramType;
```

## Moving window averaging

In this API you can choose to use a moving window averaging to processs the error count curve before calculation. For further reading, see "Numerical Recipes 3rd Edition: The Art of Scientific Computing" by William Press, Saul Teukolsky, William Vetterling and Brian Flannery, Cambridge University Press 2007, ISBN 0-521-88068-8.

Depending on the "N" parameter, different moving window averages are used.

```
N=2    y(n) = 1/3x(n) + 1/3x(n+1) + 1/3x(n-1)

N=4    y(n) = 1/5x(n) + 1/5x(n+1) + 1/5x(n+2) + 1/5x(n-1) + 1/5x(n-2)

N=6    y(n) = 1/7x(n) + 1/7x(n+1) + 1/7x(n+2) + 1/7x(n+3) + 1/7x(n-1) + 1/7x(n-2) + 1/7x(n-3)
```

Note On the edges of the error count curve, no averaging is done to keep the peak-peak jitter value constant.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_JITTER_HISTOGRAM(const std::vector<INT>& errorCount,
                     const DOUBLE start,
                     const DOUBLE stepWidth
                     std::vector<INT>& histogramData,
                     JitterHistogramType& histogramDataAttribute,
                     const Boolean movingWindowAveraging = false,
                     INT windowSize=2);
```

## Example

This example calculates the jitter histogram via left side of bit eye after acquiring the error count on the left transition side of bit.

```
//acquire error count on the left transition side of bit
//assume the bit transition is within the [0.0, 0.5] area
  ERROR_COUNT_ACQUIRE ercAcquire;

  STRING_VECTOR pinVector =
  PinUtility.getDigitalPinNamesFromPinList("HS_TX1,HS_TX2",TM::ALL_DIGITAL);

  ON_FIRST_INVOCATION_BEGIN();
//setup search condition
//The spec name should be the pin name plus the "_offset" suffix!
string pinname;
  for (int n = 0; n < pinVector.size(); n++)
  {
    pinname = pinVector[n];
    STRING specName =  pinname + "_offset";
//setup for two high-speed pins
    ercAcquire.pin("HS_TX1,HS_TX2")
                     .port("HS_Port")
                     .spec(specName,TM::TIM)
                     .stepWidth(0.01)
                     .start(0.0)
                     .stop(0.5)
                     .errorCountMode(TM::ERROR_PER_EDGE)
                     .enableFastStop(0.05,9);
  }
  ercAcquire.execute(TM::FAST_STOP);
  ON_FIRST_INVOCATION_END();

//get error count for pins
  ARRAY_I ercOfHsTx1, ercOfHsTx2;
  ercOfHsTx1 = ercAcquire.getErrorCount("HS_TX1");
  ercOfHsTx2 = ercAcquire.getErrorCount("HS_TX2");

//log the error count data
  PUT_DATALOG("HS_TX1", "errorCountHsTx1", WAVE_LOG(ercOfHsTx1));
  PUT_DATALOG("HS_TX2", "errorCountHsTx2", WAVE_LOG(ercOfHsTx2));

//calculate the jitter histogram via left side of bit eye
  JitterHistogramType histogram1, histogram2;
  std::vector<INT> errorCountVec1,errorCountVec2;
  std::vector<INT> jitterHistogramDataVec1,jitterHistogramDataVec2;
  for(int loop = 0; loop < ercOfHsTx1.size(); ++loop)
  {
      errorCountVec1.push_back(ercOfHsTx1[loop]);
  }
  for(int loop = 0; loop < ercOfHsTx2.size(); ++loop)
  {
      errorCountVec2.push_back(ercOfHsTx2[loop]);
  }
  std::vector<INT> jitterHistogramData1,jitterHistogramData2;
  DSP_JITTER_HISTOGRAM(errorCountVec1,0.1,0.01,jitterHistogramDataVec1,histogram1,false,2);
  DSP_JITTER_HISTOGRAM(errorCountVec2,0.1,0.01,jitterHistogramDataVec2,histogram2,false,2);

//output result to the report window
  cout<<"Jitter histogram of HS_TX1:"
      <<"\nmean= "<<histogram1.mean
      <<"\nrms jitter= "<<histogram1.rms
      <<"\npeaktopeak Jitter= "<<histogram1.peak2peak <<endl;
  cout<<"Jitter histogram of HS_TX2:"
      <<"\nmean= "<<histogram2.mean
      <<"\nrms jitter= "<<histogram2.rms
      <<"\npeaktopeak Jitter= "<<histogram2.peak2peak <<endl;

//generate timing axis before display data
  ARRAY_I timingAxis;
  for (int m = 0; m < jitterHistogramData1.size(); m++)
  {
    timingAxis[m] = m;
  }
// translate std::vector<INT> to ARRAY_I
  ARRAY_I jitterHistogramDataArray1,jitterHistogramDataArray2;
  int size1=jitterHistogramDataVec1.size();
  int size2=jitterHistogramDataVec2.size();
  jitterHistogramDataArray1.resize(size1);
  jitterHistogramDataArray2.resize(size2);

  for(int loop = 0; loop < size1; ++loop)
  {
     jitterHistogramDataArray1[loop] = jitterHistogramDataVec1[loop];
  }
  for(int loop = 0; loop < size2; ++loop)
  {
    jitterHistogramDataArray2[loop] = jitterHistogramDataVec2[loop];
  }
//debug the histogram data on signal analyzer tool
  PUT_DEBUG("HS_TX1","Jitter Histogram",jitterHistogramDataArray1,timingAxis);
  PUT_DEBUG("HS_TX2","Jitter Histogram",jitterHistogramDataArray2,timingAxis);

//log the histogram data to the datalog stream
  PUT_DATALOG("HS_TX1","JitterHistogramHsTx1",WAVE_LOG(jitterHistogramDataArray1));
  PUT_DATALOG("HS_TX2","JitterHistogramHsTx2",WAVE_LOG(jitterHistogramDataArray2));

```
