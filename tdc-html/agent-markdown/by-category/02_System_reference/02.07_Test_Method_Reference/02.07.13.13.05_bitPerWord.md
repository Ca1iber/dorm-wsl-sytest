# bitPerWord()

Specifies the number of [bits per word](<../02.08_Setup_and_Result_Tools/02.08.01.02.07.02.05.01_Creating_a_Digital_Capture_setup.md>) for the serial transfer mode.

## Syntax

```
bitPerWord(int iBit);
```

Parameter List
 |

Parameter

 |

Description

 |
 |

iBit

 |

The number of bits. The default value is 32.

 |

## Example

```
rdi.digCap("norm").label("lpDcap_new").pin("DATA2").addVecRange(3,15).samples(10).bitPerWord(4).execute();
```
