# TMU_TASK.setup()

Sets up the configurations for all the TMU pins in the TMU set.

## Syntax

```
void setup();
```

## List of parameters

There are no parameters associated with this class.

Return value

There is no return value.

## Functional changes

- Introduced in SmarTest 7.1.0
