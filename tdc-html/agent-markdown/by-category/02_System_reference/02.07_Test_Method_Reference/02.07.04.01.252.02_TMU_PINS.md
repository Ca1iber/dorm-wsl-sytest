# TMU_PINS

#### Subtopics

- [TMU_PIN measurement setup](<02.07.04.01.252.02.01_TMU_PIN_measurement_setup.md>)
- [TMU_PIN measurement status](<02.07.04.01.252.02.02_TMU_PIN_measurement_status.md>)
- [Deprecated TMU_PINS methods](<02.07.04.01.252.02.03_Deprecated_TMU_PINS_methods.md>)

The TMU_PINS class holds the TMU settings for one or multiple pins. It also provides the functions to access and modify the TMU properties.

You cannot directly create the object for it. The member functions need to used after the [TMU_TASK.pin()](<02.07.04.01.252.09_TMU_TASK.pin.md>) function.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TMUPins.h.

The TMU-PINS class methods are is documented under the following sections:

- [TMU_PIN measurement setup](<02.07.04.01.252.02.01_TMU_PIN_measurement_setup.md>)
- [TMU_PIN measurement status](<02.07.04.01.252.02.02_TMU_PIN_measurement_status.md>)
- [Deprecated TMU_PINS methods](<02.07.04.01.252.02.03_Deprecated_TMU_PINS_methods.md>) Note The TMU_PINS upload methods are deprecated, but for compatibility reasons they are still usable.

The recommended way for uploading results is to use the TMU_TASK upload methods, which also provide features for hidden upload:

  - [TMU_TASK.uploadPeriodResults()](<02.07.04.01.252.18_TMU_TASK.uploadPeriodResults.md>)
  - [TMU_TASK.uploadRawResults()](<02.07.04.01.252.19_TMU_TASK.uploadRawResults.md>)
  - [TMU_TASK.uploadRawResultsFlat()](<02.07.04.01.252.20_TMU_TASK.uploadRawResultsFlat.md>)
