# defaultVec()

The vectors that are not covered by writeVec(),writePat() and fillVec() in one pattern will be filled with the specified value of the defaultVec(). If you do not specify the defaultVec(), RDI will automatically specify those vectors with "f" or the value of "DEFAULT_STATUS_INDEX" in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>). The generic recommendation is to specify defaultVec() for each pin.

## Syntax

```
defaultVec(int index);
defaultVec(string dvc);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

index

 |

The physical index you want to write to the pattern .

 |
 |

dvc

 |

The device cycle you want to write to the pattern.

 |

## Example

```
RDI_BEGIN();
rdi.smartVec().pin("DATA1").defaultVec(0).vecLength(10).execute();   // index
rdi.smartVec().pin("DATA3").defaultVec("1").vecLength(10).execute(); // device cycle
RDI_END();
```
