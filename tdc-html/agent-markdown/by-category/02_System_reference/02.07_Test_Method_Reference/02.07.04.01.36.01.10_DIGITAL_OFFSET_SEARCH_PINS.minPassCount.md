# DIGITAL_OFFSET_SEARCH_PINS.minPassCount()

Sets the minimum consecutive pass count to stop binary search. When the consecutive pass count is equal to or greater than the minimum count, the binary search stops.

## Syntax

```
DIGITAL_OFFSET_SEARCH_PINS& minPassCount(INT minpasscount);
```

Parameter
 |

Parameter

 |

Description

 |
 |

minpasscount

 |

A number used as the minimum consecutive pass count to stop a binary search.

When a consecutive pass count is larger than or equal to the minimum count, the binary search stops.

 |

## Return value

A reference to the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) object.

## Functional changes

- Introduced in SmarTest 7.2.1
