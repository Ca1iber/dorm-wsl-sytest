# DIGITAL_OFFSET_SEARCH_PINS.resolution()

Sets the resolution for the binary search. If the resolution is not specified, the [step width](<02.07.04.01.36.01.26_DIGITAL_OFFSET_SEARCH_PINS.stepWidth.md>) will be used to stop the binary search.

## Syntax

```
DIGITAL_OFFSET_SEARCH_PINS& resolution(DOUBLE res);
```

Parameter
 |

Parameter

 |

Description

 |
 |

res

 |

The resolution of the binary search.

For timing searches, the unit is seconds [s].

For voltage searches, the unit is Volts [V].

 |

## Return value

A reference to the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) object.
