# Bitwise complement

The '~' operator calculates the bitwise inverse of a state character sequence.

When applied to a state character sequence the operator will convert state characters 'H' to 'L' and '0' to '1' and vice versa.

The resulting state character sequence has the same length as its operand.

Note Characters different from '0', '1', 'L' and 'H' are ignored by this operator.

## Syntax

sequence := ~ sequence

## Example

~ "010011" results in `"101100"`

~ "0L1H0L" results in `"1H0L1H"`

~ "000Z" results in `"111Z"`

## Functional changes

- Introduced in SmarTest 7.1.0
