# setWaitTemplatePatternName()

This API is used to specify the wait template pattern name to the PatternPort.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTMultiportSync.hpp.

## Syntax

```
void setWaitTemplatePatternName(const STRING& _waitTemplate);
```

Parameter
 |

_waitTemplate

 |

Specifies the wait template pattern name.

 |

## Example

```
CCTMultiportSync     Sync;
...
GET_TESTSUITE_NAME(tsName);
Sync.registerCCTestMethod(tsName, this);
...
PatternPort::getInstance().setPort(Port);
PatternPort::getInstance().setWaitTemplatePatternName(WaitTemplate);
Sync.registerSyncPort(PatternPort::getInstance());

Sync.start();

if(CCTgetDevelopMode()!=0)
{
        PatternPort::getInstance().playPattern(FlatPatt);
}
Sync.sync();
Sync.flush();
Primary.label(Sync.getMultiPortBurstName());
Sync.dumpMPBGraph();
```
