# SlimBusController.getDataChannelsWithResults()

This function returns the channel numbers of all data channels for which results exist on the specified site.

## Syntax

```
const vector< int > & getDataChannelsWithResult (int site=-1) const
```

Parameter
 |

Parameter

 |

Description

 |
 |

site

 |

Specfies the site that is to be processed. If no site is specified, the current site under test is taken.

 |

## Return value

A list of channel numbers.

## Functional changes

- Introduced in SmarTest 7.2.1
