The Test Method Library is a collection of test methods that are provided with SmarTest. In the test methods:

- Throughput is optimized as much as possible with easy to read code.
- Multisite testing is supported.
- Comments are provided to help you understand the code.

To make the test methods easy to understand and reuse, all test methods in the library are in the same code structure. The structure consists of four main blocks:

- Process parameters

Parse, pre-process the test method input parameters and store them in a parameter object. This allows the following blocks to be more independent from the test method input parameters.

- Make a measurement

Do the measurement using the parameter object from the previous block and output a result object.

This is the core of the test method, which does the actual measurement. You can leverage the code to do the same or similar measurements in your own test method.

- Report results to report window

Prints the results in the result object on the UI report window. You can replace or modify this part to meet your specific report output needs.

- Data log

Data log the results in the result object based on test method limits. You can replace or modify this part to meet your specific data logging needs.

You can directly use the test method library as it is or customize the test method according to your needs. For details, see [Using the predefined universal Test Method Libraries](<02.07.02.07_Using_the_predefined_universal_Test_Method_Libraries.md>). You can also reuse part of the source code by copying it to your own test method source code.

  Test method library packages The test method libraries are released in an independent rpm package that is part of the SmarTest Suite bundle. The package is named like

- smartest64_tml_x.y.z.p-r.s.t-suffix.rpm.
In the package name

- `x.y.z.p` is the SmarTest version number,
- `r.s.t` is the TML version number and
- `suffix` x is the suffix of the whole SmarTest package.
A TML package can be only used for the specified version of SmarTest. Using the codes of a TML package for a specific SmarTest version on other SMT releases is not supported. Installed packages:

Multiple TML packages can be installed on the system controller.

 The libraries are installed in the directory

- /opt/hp93000/tml64_x.y.z.p_r.s.t
where `x.y.z.p` is the SmarTest version number and `r.s.t` is the TML version number.  Active package

Using the [Switch version tool](<../../01_Getting_started/01.02_SmarTest_workstation_administration/01.02.02.03_Switch_version_tool.md>), only one of the test method library packages can be active together with the SmarTest version from the same SmarTest suite bundle.

 The compiled files of the currently active package are located in the directory

- /opt/hp93000/soc/testmethod/library/sh_lib
The source files one level higher in the directory

- /opt/hp93000/soc/testmethod/library
