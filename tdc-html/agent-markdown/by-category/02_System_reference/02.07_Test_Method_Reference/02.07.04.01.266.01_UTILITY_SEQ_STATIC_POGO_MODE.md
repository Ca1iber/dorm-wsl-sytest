# UTILITY_SEQ_STATIC_POGO_MODE

The class provides the function to specify a static mask for a utility pogo block.

## Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/UtilitySequencerStaticMask.h.

  Constructor This class has no public constructor. The UTILITY_SEQ_STATIC_POGO_MODE object can only be accessed via the function [UTILITY_SEQ_STATIC_MASK.pogoBlock()](<02.07.04.01.266.02_UTILITY_SEQ_STATIC_MASK.pogoBlock.md>) of the [UTILITY_SEQ_STATIC_MASK](<02.07.04.01.266_UTILITY_SEQ_STATIC_MASK.md>) class  Member function

- [mask()](<02.07.04.01.266.01_UTILITY_SEQ_STATIC_POGO_MODE.md#_152393__dle_mask>)

## Member function

  mask()

```
void mask (unsigned int mask);
```

  Parameter

 | Parameter  | Description |
 | mask |

The mask value to be set.

The functionality of the single bits is defined as follows:

 |

- Bit set to 0:
 |

The related utility line control bit is masked.

 |
 |

- Bit set to 1:
 |

The related utility line control bit is NOT masked.

   | The range and default value of parameter mask is defined as follows:

 |

- Minimum value:
 |

0 (0x0)

 |
 |

- Maximum value:
   |  32 utility lines per pogo block:

- 4鈥?94鈥?67鈥?95鈥?0xFFFFFFFF)
 |
 |

- Default value:
   |  No bit is masked

- 0xFFFFFFFF for 32 utility lines per pogo block
   | The assignment of the mask bits to the control bits and utility lines corresponds to the scheme that is shown in [Setting up sequencer control of utility lines](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01.05_Setting_up_sequencer_control_of_utility_lines.md>):

 |

- Bit 0 (LSB):
 |

Specifies the mask for utility line 1.

 |
 |

- Bit 31 (MSB):
 |

Specifies the mask for utility line 32 for 32 utility lines per pogo block.

   |    |   Return value There is no return value.
