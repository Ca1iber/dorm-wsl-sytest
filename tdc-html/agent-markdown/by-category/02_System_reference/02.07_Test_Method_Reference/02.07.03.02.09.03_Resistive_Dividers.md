# Resistive Dividers

If you apply the resistive divider technique, the voltage drop across the series resistor (between pogo pin and DUT pin) is not compensated for, when performing measurements with the PPMU.

To cope with the signal attenuation due to the resistive divider, you have to adjust your voltage levels accordingly.
