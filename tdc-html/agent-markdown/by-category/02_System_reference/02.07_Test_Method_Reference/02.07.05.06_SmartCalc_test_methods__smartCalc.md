# SmartCalc test methods (smartCalc)

#### Subtopics

- [SMC__SYNCHRONIZE](<02.07.05.06.01_SMC__SYNCHRONIZE.md>)
- [SMC__SYNCHRONIZE_ALL](<02.07.05.06.02_SMC__SYNCHRONIZE_ALL.md>)
- [SMC__CLEANUP](<02.07.05.06.03_SMC__CLEANUP.md>)

The smartCalc test method library provides some utility methods for synchronizing and cleaning up SmartCalc based test flows.

Background threads that are defined in the [SMC_backgroundProcessing()](<02.07.04.01.231.01_SMC_ARM.md#_120107__s_SMC_backgroundProcessing>) function of a test method class and armed by calling test method API [SMC_ARM()](<02.07.04.01.231.01_SMC_ARM.md>) in the run() function, must be synchronized or, in some cases also cleaned up.

 This can be done using the appropriate test method APIs of the SmartCalc framework or by implementing the test methods of the smartCalc test method library:

- [SMC__SYNCHRONIZE](<02.07.05.06.01_SMC__SYNCHRONIZE.md>)
- [SMC__SYNCHRONIZE_ALL](<02.07.05.06.02_SMC__SYNCHRONIZE_ALL.md>)
- [SMC__CLEANUP](<02.07.05.06.03_SMC__CLEANUP.md>)

The smartCalc test method library is fully integrated into the SmarTest software and does not need to be installed separately. Unlike other test method libraries, the source code is not provided as a ZIP file but the implementation is explained in the subtopics: The codeblock of the sub-topics contains the complete source code of the run() function.
