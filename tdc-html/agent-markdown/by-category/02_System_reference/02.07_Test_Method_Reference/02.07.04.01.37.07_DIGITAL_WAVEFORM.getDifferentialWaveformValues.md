# DIGITAL_WAVEFORM.getDifferentialWaveformValues()

This function returns differential waveform data retrieved in the previous execution.

## Syntax

```
void getDifferentialWaveformValues(const STRING& pin,
                                   DIFF_WAVEFORM_RESULT & result,
                                   BOOLEAN calc_rms_flag)
```

Parameters
 |

pin

 |

One pin of the differential pin pair to access the differential waveform.

 |
 |

result

 |

The captured differential waveform result data.

The definition of DIFF_WAVEFORM_RESULT is:

struct DIFF_WAVEFORM_RESULT

{

 WAVEFORM_RESULT positive;//for positive connection waveform

 WAVEFORM_RESULT negative;//for negative connection waveform

 WAVEFORM_RESULT diff;//for differential swing waveform

 WAVEFORM_RESULT common;//for differential common waveform

}

 |
 |

calc_rms_flag

 |

The flag indicates whether the rms value will be calculated.

 |

## Functional changes

- Introduced before SmarTest 6.3.2
