# TESTSET().judgeAndLog_Dps()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) performs a pass/fail judgment of a DPS test specified by a DPS_TASK object and logs the results.

Optional values for this function can be set by prior methods, for example, [port()](<02.07.04.01.244.19_TESTSET__.port.md>), [cont()](<02.07.04.01.244.03_TESTSET__.cont.md>), [reliability()](<02.07.04.01.244.20_TESTSET__.reliability.md>), or [testname()](<02.07.04.01.244.23_TESTSET__.testname.md>).

## Syntax

```
bool judgeAndLog_Dps(const DPS_TASK &dpsTask, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE);
```

 |

Parameter

 |

Description

 |
 |

dpsTask

 |

Specifies a [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) object to be judged.

 |
 |

logTestNumber

 |

An optional test number.

If this test number is provided, it overrides the actual test number. If it is not provided, the actual test number is logged.

   | Note Only the first six digits of values are ensured to be correctly logged into the STDF file.

## Return Value

The pass/fail result of the judgment is returned. It can be true for pass or false for fail.

## Example

The following example performs a DPS global pass/fail measurement on pin Vcc and Vee with the current primary set.

```
DPS_TASK dpsTask;
static STRING tsName;
ON_FIRST_INVOCATION_BEGIN();
  CONNECT();
  GET_TESTSUITE_NAME(tsName);
  dpsTask.pin("Vcc").min(0 A).max(0.1 A);
  dpsTask.pin("Vee").min(0 A).max(0.2 A);
  dpsTask.execMode(TM::GPF);
  dpsTask.trigMode(TM::INTERNAL);
  dpsTask.execute();
ON_FIRST_INVOCATION_END();
TESTSET().judgeAndLog_Dps(dpsTask);
```
