# Deprecated TMU_PINS methods

#### Subtopics

- [TMU_PINS.uploadPeriodResults()](<02.07.04.01.252.02.03.01_TMU_PINS.uploadPeriodResults.md>)
- [TMU_PINS.uploadRawResults()](<02.07.04.01.252.02.03.02_TMU_PINS.uploadRawResults.md>)
- [TMU_PINS.uploadRawResultsFlat()](<02.07.04.01.252.02.03.03_TMU_PINS.uploadRawResultsFlat.md>)

The TMU_PINS upload methods are deprecated, but for compatibility reasons they are still usable.

The recommended way for uploading results is to use the TMU_TASK upload methods, which also provide features for hidden upload:

- [TMU_TASK.uploadPeriodResults()](<02.07.04.01.252.18_TMU_TASK.uploadPeriodResults.md>)
- [TMU_TASK.uploadRawResults()](<02.07.04.01.252.19_TMU_TASK.uploadRawResults.md>)
- [TMU_TASK.uploadRawResultsFlat()](<02.07.04.01.252.20_TMU_TASK.uploadRawResultsFlat.md>)

## Functional changes

- Introduced in SmarTest 7.4.3
