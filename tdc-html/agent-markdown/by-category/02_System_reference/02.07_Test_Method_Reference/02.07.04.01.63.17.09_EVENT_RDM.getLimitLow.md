# EVENT_RDM.getLimitLow()

Reads the lower limit that has been defined by [EVENT_RDM.limits()](<02.07.04.01.63.17.05_EVENT_RDM.limits.md>) or [EVENT_RDM.limitLow()](<02.07.04.01.63.17.06_EVENT_RDM.limitLow.md>).

The value is read from the corresponding [EVENT_RDM](<02.07.04.01.63.17_EVENT_RDM.md>) object and returned as an [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) object.

## Syntax

```
bool getLimitLow (EVENT_VALUE_DOUBLE & low)  const;
```

  Parameter

 | Parameter  | Description |
 | low  | The programmed lower limit of the pass range in Volts (V).  |  Return value bool value indicating the state of the limit definition:

- true: Limit has been defined by [EVENT_RDM.limits()](<02.07.04.01.63.17.05_EVENT_RDM.limits.md>) or [EVENT_RDM.limitLow()](<02.07.04.01.63.17.06_EVENT_RDM.limitLow.md>).
- false: No limit is defined or the limit has been cleared by [EVENT_RDM.clearLimits()](<02.07.04.01.63.17.08_EVENT_RDM.clearLimits.md>).
