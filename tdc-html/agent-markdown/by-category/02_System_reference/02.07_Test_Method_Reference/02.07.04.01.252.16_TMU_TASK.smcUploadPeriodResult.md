# TMU_TASK.smcUploadPeriodResult()

Uploads and calculates the TMU periods for the last shot together with their statistical values by calling [SMC_TMU_UPLOAD_PERIOD_RESULTS()](<02.07.04.01.231.48_SMC_TMU_UPLOAD_PERIOD_RESULTS.md>) with additional parameters.

The results are uploaded from the test head card's memory to the result cache on the workstation while a new test suite is being executed. This API must be called inside your SMC_backgroundProcessing() method.

The API is not supported with the [Pin Scale 5000 card](<../02.05_Test_Head_Cards/02.05.04.02_Pin_Scale_5000_card.md>).

## Syntax

```
void smcUploadPeriodResults(
    const STRING &resultAreaHandle,
    const STRING &dgtPinsName,
    Boolean avaragedOnly = TRUE,
    UINT32 armings = 1,
    UINT32 numsamples = 0);
void smcUploadPeriodResults(
    int site,
    const STRING &resultAreaHandle,
    const STRING &dgtPinsName,
    Boolean avaragedOnly = TRUE,
    UINT32 armings = 1,
    UINT32 numsamples = 0);
```

Parameters
 |

Parameter

 |

Description

 |
 |

resultAreaHandle

 |

The name of the result area to upload from.

Result areas are defined with [TMU_TASK::requestResultAreaHandle(handlename)](<02.07.04.01.252.13_TMU_TASK.requestResultAreaHandle.md>).

If this parameter is not specified, the data from the active result area are uploaded.

 |
 |

dgtPinName

 |

The list of pins for which to upload data.

 |
 |

avaragedOnly

 |

The type of the returned results:

- TRUE: Only statistical values of the periods of the timestamps will be uploaded.
- FALSE: Both the periods and their statistical values will be uploaded.
 |
 |

armings

 |

The number of armings to be uploaded from the shot. The upload always starts with the first arming. The default value is 1.

For example, if 3 is specified the ''armings 1, 2, and 3'' are uploaded.

 |
 |

numsamples

 |

The number of samples to be uploaded. Specify 0 to upload all samples. The default is 0.

 |
 |

site

 |

Specifies the site for which the data should be uploaded.

 |

Return value

There is no return value.
