# postWait()

Specifies a time period to wait after a action.

This action is usually not required because SmartRDI provides a default wait time to make sure that the measurement is finished before the next command. It is only required when you need to hide the DC measurement time behind other events.

Whenever postWait() is used, the default wait time is overwritten and the postWait() time becomes effective.

If serial measurements are automatically performed on pins that share the same BADC, the postWait() time becomes effective after each single measurement.

## Syntax

```
postWait(double dWaitAfterMeas);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

dWaitAfterMeas

 |

The time period to wait.

 |

## Example

```
rdi.dc().pin("DATA1",TA::BADC).vMeas().postWait(100 us).execute();
```
