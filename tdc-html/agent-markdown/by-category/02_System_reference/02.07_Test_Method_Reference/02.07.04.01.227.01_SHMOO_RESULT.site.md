# SHMOO_RESULT.site()

This member function defines the specific site for the results to be displayed on a shmoo plot.

The displayed results are defined with the [setResult()](<02.07.04.01.227.05_SHMOO_RESULT.setResult.md>) member function.

If you do not define a site with this member function, use the current focused site.

If you have defined more than one site, use the Shmoo Tool to view the shmoo plots of different sites. For details, see [Viewing different site's shmoo results plot](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.04.07_Viewing_the_shmoo_plots_of_different_sites.md>).

## Syntax

```
ShmooResultAdapter& site (INT site);
```

Parameter
 |

Parameter

 |

Description

 |
 |

site

 |

The number of a site.

 |

## Return Value

Returns an instance of ShmooResultAdapter.

## Example

```
double meaValue1;
SHMOO_RESULT.site(CURRENT_SITE_NUMBER()).setResult(meaValue1);
```
