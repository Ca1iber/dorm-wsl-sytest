# DIGITAL_OFFSET_SEARCH_TASK.uploadOffset()

Triggers the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) instance to upload the timing or level offsets for the middle of the pass area from the tester to the workstation.

If you retrieve the offset on multiple pins and those pins have different settings, the exception TESTMETHOD_API::AmbiguityException will be issued.

## Syntax

```
void uploadOffset(SetSelector& selector, RESOURCE_TYPE resource) throws TMException;
```

Parameters
 |

Parameter

 |

Description

 |
 |

selector

 |

It can be:

- A TimingSetSelector object defined with [TimingSetSelector](<02.07.04.02.17_TimingSetSelector.md>), to select the timing sets to be used. Or,
- A LevelSetSelector object defined with [LevelSetSelector](<02.07.04.01.123_LevelSetSelector.md>), to select the level sets to be used.
 |
 |

resource

 |

It can be a timing resource or a level resource whose offset you want to upload.

Choose a timing or level resource for the timing or level selector respectively. Otherwise, an exception will be thrown.

For the resource types, see the following table.

 |

Available options of parameter: <resource>
 |

Option

 |

Description

 |
 |

DIGITAL_OFFSET_SEARCH::RECEIVE

 |

Receive edges

 |
 |

DIGITAL_OFFSET_SEARCH::DRIVE

 |

Drive edges which contain both FAST_DRIVE and SLOW_DRIVE

 |
 |

DIGITAL_OFFSET_SEARCH::FAST_DRIVE

 |

Fast drive edges

 |
 |

DIGITAL_OFFSET_SEARCH::SLOW_DRIVE

 |

Slow drive edges

 |
 |

DIGITAL_OFFSET_SEARCH::ALL_EDGES

 |

All edges containing FAST_DRIVE, SLOW_DRIVE, and RECEIVE

 |
 |

DIGITAL_OFFSET_SEARCH::VIH

 |

High driver levels

 |
 |

DIGITAL_OFFSET_SEARCH::VIL

 |

Low driver levels

 |
 |

DIGITAL_OFFSET_SEARCH::VIOFFSET

 |

The search of the offsets for VIH and VIL at the same time

 |
 |

DIGITAL_OFFSET_SEARCH::VTH

 |

Receiver thresholds

 |
 |

DIGITAL_OFFSET_SEARCH::VOH

 |

High receiver levels

 |
 |

DIGITAL_OFFSET_SEARCH::VOL

 |

Low receiver levels

 |
 |

DIGITAL_OFFSET_SEARCH::VOOFFSET

 |

The search of the offsets for VOH and VOL at the same time

 |
 |

DIGITAL_OFFSET_SEARCH::VISWING

 |

Driver swings

 |
 |

DIGITAL_OFFSET_SEARCH::VOSWING

 |

Receiver swings

 |

Return value

There is no return value.

## Example

```
DIGITAL_OFFSET_SEARCH_TASK dos;
DIGITAL_OFFSET_SEARCH::LevelSetSelector dest(DIGITAL_OFFSET_SEARCH::ALL);
dos.uploadOffset(dest, DIGITAL_OFFSET_SEARCH::VIH);
```
