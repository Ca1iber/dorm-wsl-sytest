# reverseBits()

This function inverts the bit sequence from MSB-LSB to LSB-MSB.

## Syntax

```
long long rdi.reverseBits(long long data, int bitLen);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

bitLen

 |

Bit length.

 |

## Functional changes

- Introduced in SmartRDI 2.4.0
