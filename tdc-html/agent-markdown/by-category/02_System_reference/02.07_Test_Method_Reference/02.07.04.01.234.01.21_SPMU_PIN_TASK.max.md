# SPMU_PIN_TASK.max()

Sets the high threshold for evaluating the pass/fail result.

 Note Both thresholds (min and max) must be specified regardless of the measurement mode.

## Syntax

```
SPMU_PIN_TASK& max(DOUBLE max);
```

Parameter
 |

Parameter

 |

Description

 |
 |

max

 |

High threshold value.

 The unit depends on the selected [measurement mode](<02.07.04.01.234.01.24_SPMU_PIN_TASK.mode.md>):

- "IFVM" mode and other VM modes: The high threshold voltage in Volt.
- "VFIM" mode and other IM modes::The high threshold current in Ampere.
 |

## Return value

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.
