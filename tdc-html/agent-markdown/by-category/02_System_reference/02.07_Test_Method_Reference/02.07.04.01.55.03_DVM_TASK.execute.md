# DVM_TASK.execute()

The execute() member function executes the DVM measurement with the settings defined by the member functions of [DVM_PIN_TASK](<02.07.04.01.55.01_DVM_PIN_TASK.md>).

## Syntax

```
void execute()
```

List of parameters

There are no parameters.

Return value

There is no return value.

To retrieve results use the [DVM_TASK.getValues()](<02.07.04.01.55.05_DVM_TASK.getValues.md>) function.

## Example

See the example in [DVM_TASK](<02.07.04.01.55_DVM_TASK.md>).
