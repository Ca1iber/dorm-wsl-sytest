# EVENT_VFVM

EVENT_VFVM (Voltage Force / Voltage Measurement Event) is a combined force/measure event class. These classes provide the combined functionality of force and measurement events in a single event.

Available event combinations are EVENT_VFVM and [EVENT_VFIM](<02.07.04.01.63.24_EVENT_VFIM.md>) (Voltage Force / Current Measurement Event).

You can define combined voltage force/voltage measure events with all specific functions of [EVENT_VF](<02.07.04.01.63.23_EVENT_VF.md>) and [EVENT_VM](<02.07.04.01.63.26_EVENT_VM.md>).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

### clampChecks(), iClampChecks(), getClampChecks(), getIClampChecks()

```
EVENT_VFVM & clampChecks (bool failOnLow = true, bool failOnHigh = true);
EVENT_VFVM & iClampChecks(bool failOnLow = true, bool failOnHigh = true);

void getClampChecks (bool & failOnLow, bool & failOnHigh) const;
void getIClampChecks(bool & failOnLow, bool & failOnHigh) const;
```

These member functions set and query the current clamp checks.

Per default these checks are off. If they are enabled and a checked clamp is hit, the event contributes with a FAIL to the global test result.

Both the clampChecks() member function and the iClampChecks() member function control the same functionality of the hardware. The same behavior applies for the two get...() member functions.

Parameters
 | failOnLow |

Possible values are: true | false

 |
 |

failOnHigh

 |

Possible values are: true | false

 |

### outOfRangeCheck(), getOutOfRangeCheck()

```
EVENT_VFVM & outOfRangeCheck(bool failOnOutOfRange = true);
void getOutOfRangeCheck(bool & failOnOutOfRange) const;
```

These member functions set and query the out-of-range check. Per default this check is on. If this check is enabled and the measurement range is exceeded, the event contributes with a FAIL to the global test result.

Parameters
 |

failOnOutOfRange

 |

Possible values are: true | false

 |

## Example

Defines a voltage force/measure event with limit checks:

```
EVENT_VFVM frcMeasEvent("frcV_MeasV");
frcMeasEvent.vForce(2.3 V);
frcMeasEvent.averages(2);
frcMeasEvent.limitLow(0 mV);
frcMeasEvent.limitHigh(100 mV);
```
