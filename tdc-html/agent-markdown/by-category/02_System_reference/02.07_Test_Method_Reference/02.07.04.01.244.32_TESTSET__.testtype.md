# TESTSET().testtype()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) sets the test type.

This function is not supported within the SMC_backgroundProcessing() test method when flag [hidden_datalog_mode](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_hidden_datalog_mode>) is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

## Syntax

```
TESTSET & testtype(TM::TEST_TYPE type);
```

 |

Parameter

 |

Description

 |
 |

type

 |

The test type can be TM::FUNCTIONAL, TM::PARAMETRIC`,` or TM::SCAN.

 |

## Example

```
TestSet.testtype(TM::PARAMETRIC);
```
