# DPS_AUX_TASK.getRangeError()

The DPS_AUX_TASK.getRangeError() member function retrieves the execution status of DC measurements that use automatic down鈥憆anging from the test method cache.

Refer to [DPS status flags - get...() functions](<02.07.04.01.43.07_DPS_status_flags_-_get...___functions.md>) for more information regarding the supported flags and the meaning of the flags.

The [DPS_AUX_PIN_TASK.checkSetRangeError()](<02.07.04.01.43.01.03_DPS_AUX_PIN_TASK.checkSetRangeError.md>) member function must be called upfront for reading the flags from the hardware into the test method cache.

This member function must be called outside of the [ON_FIRST_INVOCATION](<02.07.04.01.138_ON_FIRST_INVOCATION_BEGIN.md>) block or within a [FOR_EACH_SITE](<02.07.04.01.70_FOR_EACH_SITE_BEGIN.md>) block.

## Syntax

```
TM::DPS_AUX_TASK_STATUS getRangeError(const STRING & pin);
```

  Parameter

 | Parameter  | Description/Range |
 | pin  | Single pin for which the status flags should be retrieved.  |   Return value

The member function returns one of the following values of the enumerated type DPS_POWER_FLAG_STATUS:

 | Keyword  | Value  | State of the checked flags |
 | TM::AUX_TASK_STATUS_PASS  | 0  | The checked flag is not set. |
 | TM::AUX_TASK_STATUS_FAIL  | 1  | The checked flag is set. |

Return value in offline mode is TM::AUX_TASK_STATUS_PASS.

## Example

```
DPS_AUX_TASK auxTask;

ON_FIRST_INVOCATION_BEGIN();

    auxTask.pin("dps2").checkSetRangeError();

ON_FIRST_INVOCATION_END();

if ( auxTask.getRangeError("dps2") == TM::AUX_TASK_STATUS_PASS )
{
    cout << "auxTask.getRangeError(\"dps2\") returned TM::AUX_TASK_STATUS_PASS" << endl;
}
else
{
    cout << "auxTask.getRangeError(\"dps2\") returned TM::AUX_TASK_STATUS_FAIL" << endl;
}
```
