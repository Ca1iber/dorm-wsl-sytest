# DSP_JITTER_STARDUST

This API is defined to calculate the jitter stardust based on a sequence of pass/fail result data. It transforms the signal's time-domain information to frequency-domain information.

The input of the jitter stardust calculation is a pass/fail sequence (error density signal) where 1 stands for pass and -1 for fail. The power density spectrum is calculated from this sequence through FFT arithmetic.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_JITTER_STARDUST(const std::vector<INT>& passFailSequenceData,
                    const DOUBEL bitTime_ns,
                    std::vector<DOUBLE>& spectrumAmplitude,
                    std::vector<DOUBLE>& frequency,
                    const INT filterWindow = RECT);
```

## Example

The following example shows how to do a functional test, get the error map data and use the error map result data to calculate the jitter start dust.

```

//assume the bit time of test pattern: UI_width_ns = 5ns,
//acquisition_depth = 4096 ;
vector<STRING> pinVector;
pinVector.push_back("HS_TX1");
pinVector.push_back("HS_TX2");

ON_FIRST_INVOCATION_BEGIN();
  FW_TASK("PSFC ALL;");
  FUNCTIONAL_TEST();
ON_FIRST_INVOCATION_END();
ERROR_MAP_TEST emap(TM::XMODE_CYCLES);
ARRAY_BOOL passFailSequenceTx1,passFailSequenceTx2;
emap.pin("TX1").getPassFailResultsInRange(0, 4096, passFailSequenceTx1);
emap.pin("TX2").getPassFailResultsInRange(0, 4096, passFailSequenceTx2);
std::vector<INT>  passFailDataTx1,passFailDataTx2;
for ( int i = 0; i < passFailSequenceTx1.size(); i ++)
{
  if ( passFailSequenceTx1[i])
  {
    passFailDataTx1.push_back(1);
  }
  else
  {
    passFailDataTx1.push_back(-1);
  }
  if ( passFailSequenceTx2[i])
  {
    passFailDataTx2.push_back(1);
  }
  else
  {
    passFailDataTx2.push_back(-1);
  }
}
std::vector<DOUBLE>  amplitudeSpectrumTx1, amplitudeSpectrumTx2;
std::vector<DOUBLE>  frequencyTx1, frequencyTx2;
DSP_JITTER_STARDUST(passFailDataTx1,5,amplitudeSpectrumTx1,frequencyTx1);
DSP_JITTER_STARDUST(passFailDataTx2,5,amplitudeSpectrumTx2,frequencyTx2);
//out put result to UIReport window
cout << "site " << CURRENT_SITE_NUMBER() << " : " <<endl;
cout <<"jitter stardust of HS_TX1: " <<endl;
for(int i = 0; i < amplitudeSpectrumTx1.size(); i ++)
{
  cout <<"frequency  = "<< frequencyTx1[i] << ", "
       <<"the amplitude is: "<<amplitudeSpectrumTx1[i] <<endl;
}
cout <<"jitter stardust of HS_TX2: " <<endl;
for(int i = 0; i < amplitudeSpectrumTx2.size(); i ++)
{
  cout <<"frequency  = "<< frequencyTx2[i] << ", "
  <<"the amplitude is: "<<amplitudeSpectrumTx2[i] <<endl;
}
```
