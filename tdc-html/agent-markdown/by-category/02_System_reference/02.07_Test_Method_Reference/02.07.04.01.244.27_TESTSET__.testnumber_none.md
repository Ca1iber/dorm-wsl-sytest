# TESTSET().testnumber_none()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) causes no test number for the current test to be stored in the EDL, even if the [test_number_enable](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_test_number_enable>) testflow flag is enabled.

## Syntax

```
TESTSET & testnumber_none();
```

## Example

```
TestSet.testnumber_none();
```
