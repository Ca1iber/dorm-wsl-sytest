# CCTgetFrequencyListName

Gets the name of the executed frequency list. If the RF definition in the test suite is merged, it will return the merged frequency list name. Otherwise, the originial frequency list name is returned.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
string CCTgetFrequencyListName();
```

List of parameters

There are no parameters.

## Return value

The name of executed frequnecy list is returned.

## Example

Before merging of RF definition

```
int iFreq_Index_Gain = 2;    // original frequency list index
```

After merging of RF definition

```
int iFreq_Index_Gain_merged; //new frequency list index of the newly merged RF definition
STRING sFreqListName = CCTgetFrequencyListName();// new frequency list name of merge RF definition
iFreq_Index_Gain_merged = CCTgetFrequencyIndex(iFreq_Index_Gain);
```
