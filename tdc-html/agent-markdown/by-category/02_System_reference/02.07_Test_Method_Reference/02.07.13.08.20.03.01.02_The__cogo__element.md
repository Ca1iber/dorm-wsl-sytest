# The <cogo> element

This element stores results of COGO judgment performed using the SmartRDI's `cogo()` class.

The <cogo> element stores COGO judgment results in its searchResult, searchRiseResult, searchFallResult and searchPath attributes. The searchResult attribute saves COGO judgment results returned by a `getSearchResult()` function; the searchRiseResult attribute saves COGO judgment results returned by a `getSearchRiseResult()` function; the searchFallResult attribute saves COGO judgment results returned by a `getSearchFallResult()` function; the searchPath attribute saves COGO judgment results returned by a `getSearchPath()` function.

## Example

Below is an example of the <cogo> element and its corresponding SmartRDI code block.

An ORE file containing <cogo> elements:

```
<id name = "cogo1">
  <cogo searchResult= "3.15" />
  <cogo searchPath= "0,0,0,1" />
</id>
```

 The corresponding SmartRDI code block that can generate this ORE file:

```
RDI_BEGIN();
  rdi.cogo("cogo1").search(TA::LINEAR)
     .pathPin("DATA3").start(0).stop(3)
     .step(6).blockBegin();
...
  rdi.cogo().search().blockEnd();
RDI_END();
...
rdi.id("cogo1").getSearchResult(); // {3.15}
rdi.id("cogo1").getSearchPath();   // {0,0,0,1}
```

<pin> is inapplicable for the COGO results, because the COGO results is not pin-based.
