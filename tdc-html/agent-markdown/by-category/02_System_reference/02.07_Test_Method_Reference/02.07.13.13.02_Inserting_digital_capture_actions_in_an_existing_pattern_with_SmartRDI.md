# Inserting digital capture actions in an existing pattern with SmartRDI

You can insert some digital capture actions for some specific pins in an existing pattern to do the digital capture test.

## Procedure

-  Create a digital capture test with the class `digCap()`.
-  Specify the existing label to use with the function [label()](<02.07.13.13.13_label.md>).
-  Specify the pins to do the digital capture with the function [pin()](<02.07.13.13.14_pin.md>).
-  Specify the vector range to insert the actions with the function [addVecRange()](<02.07.13.13.04_addVecRange.md>).
-  Specify the number of samples to capture with the function [samples()](<02.07.13.13.15_samples.md>).
-  (optional) Specify the number of initial discards, inter discards and bit per word with corresponding functions if needed.

See [bitPerWord()](<02.07.13.13.05_bitPerWord.md>), [initDiscard()](<02.07.13.13.11_initDiscard.md>), and [interSkip()](<02.07.13.13.12_interSkip.md>).

-  Execute the setups with the function [execute()](<02.07.13.08.01.02_execute.md>).

## Results

The code to insert digital capture actions in an existing pattern is created.

## Example

```
RDI_BEGIN();
  rdi.digCap("mps").label("lpDcap_new").pin("DATA2,DATA6").addVecRange(3,15).samples(10).execute();
RDI_END();
```

In this example, the digital capture actions will be inserted in the vector range (3,15) of the pattern `lpDcap_new` for the pin `DATA2` and `DATA6`. 10 samples are captured for each pin.
