# DIGITAL_OFFSET_SEARCH_PINS.numSteps()

Sets up the number of search steps excluding the start value.

The combination of the [start value](<02.07.04.01.36.01.25_DIGITAL_OFFSET_SEARCH_PINS.start.md>), the number of search steps, and the [step width](<02.07.04.01.36.01.26_DIGITAL_OFFSET_SEARCH_PINS.stepWidth.md>) defines the range for the initial linear search.

## Syntax

```
DIGITAL_OFFSET_SEARCH_PINS& numSteps(INT numstep);
```

Parameter
 |

Parameter

 |

Description

 |
 |

numstep

 |

The number of search steps excluding the start value.

 |

## Return value

A reference to the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) object.
