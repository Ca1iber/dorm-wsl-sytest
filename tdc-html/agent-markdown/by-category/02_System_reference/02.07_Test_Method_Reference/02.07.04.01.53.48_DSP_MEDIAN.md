# DSP_MEDIAN

The DSP_MEDIAN API calculates the median, which is defined as the number separating the higher half of a list of data from the lower half.

This API sorts the list of data in ascending order and picks the middle one as the median. For the complex array, the elements are sorted by ascending magnitudes.

If there are an even number of data samples, the median is the mean of the two middle values.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_MEDIAN(ARRAY_D& src, DOUBLE* result);
DSP_MEDIAN(ARRAY_I& src, INT* result);
DSP_MEDIAN(ARRAY_COMPLEX& src, COMPLEX* result);
DSP_MEDIAN(DOUBLE * src, INT size, DOUBLE* result);
DSP_MEDIAN(INT * src, INT size, INT* result);
DSP_MEDIAN(COMPLEX * src, INT size, COMPLEX* result);
```

## Example

```
ARRAY_D data(100);
DOUBLE data_median;
...
DSP_MEDIAN(data, &data_median);
```

This example sorts the `data` array in ascending order and picks the mean of the sorted 49th and 50th elements as the median `data_mean`.
