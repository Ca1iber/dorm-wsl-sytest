# LOOPBACK_OPERATION_TASK

The LOOPBACK_OPERATION_TASK class is a container that associates pins with a certain operation mode and for direct and direct retimed SmartLoop based loopback. It also executes the loopback test. It is derived from the TASK class and can therefore be used with the [TASK_LIST](<02.07.04.01.240_TASK_LIST.md>) class.Note that direct and direct retimed SmartLoop based loopback is currently not supported.

## Class definition

LOOPBACK_OPERATION_TASK();

### Constructor

```
LOOPBACK_OPERATION_TASK();
```

This constructor creates an object of the LOOPBACK_OPERATION_TASK class.

## Member functions

### pin()

```
LOOPBACK_OPERATION_PINS& pin(const STRING& pinlist);
```

This function returns a reference to a LOOPBACK_OPERATION_PINS object for the specified pins. You can use the member functions of the LOOPBACK_OPERATION_PINS class subsequently.

Parameter
 |

pinlist

 |

The pins for which a LOOPBACK_OPERATION_PINS object is created. Every specified pin is treated as a representative of both the differential pair to which it belongs and also of the corresponding differential pair.

 |

### setup()

```
void setup();
```

This function executes the configuration firmware commands for all pins that are specified in any call of the  pin() function from the respective LOOPBACK_OPERATION_TASK object.

### execute()

```
void execute();
```

This function executes the loopback test for all pins that are specified in any call of the pin() function from the respective LOOPBACK_OPERATION_TASK object.

### print()

```
void print();
```

This function prints the current setting information.

## Example

```
LOOPBACK_OPERATION_TASK lpb;
    lpb.pin("OUT+").setOperationMode(LOOPBACK_OPERATION::PARAMETRIC_LOOP);
    lpb.execute();
    return;
```

This example defines a LOOPBACK_OPERATION_TASK object `lpb` and sets the operation mode of the differential output pin `OUT+` to PARAMETRIC_LOOP. If `OUT+` is associated with channel 10102, then the pins that are associated with channels 10101, 10103, and 10104 will also be set to PARAMETRIC_LOOP. After configuring the loopback mode, `lpb` executes the direct or direct retimed SmartLoop鈩?based loopback test for these four pins with the execute() function.
