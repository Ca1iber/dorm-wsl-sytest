# Creating a customized shmoo test method

You can create your own shmoo test method based on a [customized shmoo test method template](<02.07.07.02_Customized_shmoo_test_template.md>).

## About this task

You can create your own shmoo test method when the [ac_tml.AcTest.Shmoo](<02.07.05.01.09_Shmoo.md>) test method cannot meet your needs. For example, if you want device training before a shmoo, which is normally done with two test suites, you can do it with one test suite by creating a customized shmoo test method.

## Before you begin

Make sure:

- The ac_tml test method library is imported. Refer to [Using the predefined universal Test Method Libraries](<02.07.02.07_Using_the_predefined_universal_Test_Method_Libraries.md>) for how to import the ac_tml test method library.

## Procedure

-  In the Project Explorer view of the C++ perspective, right-click the ac_tml test method project and select New > Test Method Class.

The Create a new TestMethod Class wizard opens.

-  In the Templates field, select Customized shmoo test method class.
-  In the Class Name field, enter a name for your shmoo test method.
-  Complete the other setups as described in [How to create a universal test method class](<02.07.02.02.02_How_to_create_a_universal_test_method_class.md>) and click Finish.

  - A new test method file opens.
  - The new file is added to the ac_tml project.
  - If you have already added parameters in step 4, you will see these parameters in the [addParameters()](<02.07.07_Shmoo_test_method_customization.md>) function of the new file.

-  In the new test method file, program [the functions which are provided with the customized shmoo test method template](<02.07.07.02.01_The_functions_of_the_customized_shmoo_test_method_template.md>).
-  [Build the project](<../../01_Getting_started/01.03_Using_SmarTest/01.03.03.02.03_Building_projects.md>).

## Results

A new shmoo test method is created with [the customized parameters and functions](<02.07.07.02.01_The_functions_of_the_customized_shmoo_test_method_template.md>) and the parameters of the [ac_tml.AcTest.Shmoo](<02.07.05.01.09_Shmoo.md>).

## What to do next

Use this test method to create a shmoo test with the [Shmoo Tool](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>), or to create [a shmoo test suite in a testflow](<../02.08_Setup_and_Result_Tools/02.08.04.32.02.01.04_Inserting_a_test_suite_into_the_testflow.md>).
