# EVENT_WAVEFORM_VM.iClampChecks()

Enables or disables the current clamp checks or the voltage clamp checks.

The selected clamp checks for current or voltage are defined by the active force mode of the target pin:

- The current clamp checks are set if the pin is forcing voltage.
- The voltage clamp checks are set if the pin is forcing current.

Per default these checks are off. If they are enabled and a checked clamp is hit, the event contributes with a FAIL to the global test result.

Both this member function and [EVENT_WAVEFORM_VM.clampChecks()](<02.07.04.01.63.40.07_EVENT_WAVEFORM_VM.clampChecks.md>) set the same functionality of the hardware.

## Syntax

```
EVENT_WAVEFORM_VM & iClampChecks(bool failOnLow = true, bool failOnHigh = true);
```

Parameters
 | Parameter  | Description |
 | failOnLow |

Enables or disables the lower clamp check.

- true: The lower clamp check is enabled.
- false: The lower clamp check is disabled.

Default value: The clamp check is disabled.

 |
 | failOnHigh |

Enables or disables the upper clamp check.

- true: The upper clamp check is enabled.
- false: The upper clamp check is disabled.

Default value: The clamp check is disabled.

 |

## Return value

A reference to the corresponding [EVENT_WAVEFORM_VM](<02.07.04.01.63.40_EVENT_WAVEFORM_VM.md>) object.
