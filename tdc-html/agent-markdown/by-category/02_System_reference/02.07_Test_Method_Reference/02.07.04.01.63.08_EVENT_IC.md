# EVENT_IC

#### Subtopics

- [EVENT_IC.getIClampHigh()](<02.07.04.01.63.08.04_EVENT_IC.getIClampHigh.md>)

Current clamp (IC) event classes provide functionality to define events specifying and querying clamp current values.

There are functions to set and query both low and high clamp current values. You can specify either one of the values or both.

In case you try to get a non-defined value, the software returns `999999/-999999`. This NaN (not a number) indicates an undefined or unrepresentable value.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_IC ( const STRING &id );
EVENT_IC ( INT &id );
```

This constructs an object of the EVENT_IC class. The class derives from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

Parameter
 | Parameter  | Description |
 | id |

Event identifier

 |

Return value

There is no return value.

## Example

The example sets the low and high clamp current values to 1 mA and 100 mA.

```
PATTERN_CONTROLLER cleanUpPattern;
PATTERN_CONTROLLER pc;

EVENT_IC iClampEvent("iClampEvent1");

ON_FIRST_INVOCATION_BEGIN();

    cleanUpPattern.label("patEvents", "@")
                  .vecEvents("dps1")
                  .clearAll()
                  .setup();

    iClampEvent.iClampLow(1 mA);
    iClampEvent.iClampHigh(100 mA);

    // insert events into pattern
    PATTERN & pattern(pc.label("patEvents", "@"));
    pattern.vecEvents("dps1").insert(32, iClampEvent)

    pc.setup();

ON_FIRST_INVOCATION_END();
```
