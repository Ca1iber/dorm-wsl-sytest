# TESTSET().testname()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) sets a test name for a test result that is specified by the name parameter directly, which is then stored in the EDL as a [TestName](<../02.10_Data_Logging/02.10.01.06.05.61_TestNameAttrType.md>) attribute.

It is useful for assigning a desired test name to a test result, instead of using a value that is automatically assigned in the [TEST()](<02.07.04.01.241_TEST.md>) API, which does not have a test name, such as a functional test result, when you have used the [testnumber (INT number)](<02.07.04.01.244.25_TESTSET__.testnumber.md>) member function or the [testnumber (TESTNUMBER &testnumber)](<02.07.04.01.244.25_TESTSET__.testnumber.md>) member function to assign numerical values to the corresponding test result.

This function is not supported within the SMC_backgroundProcessing() test method when flag [hidden_datalog_mode](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_hidden_datalog_mode>) is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

## Syntax

```
TESTSET & testname(const STRING &name);
TESTSET & testname(const STRING &name, const bool forceSTDFTestName);
```

 |

Parameter

 |

Description

 |
 |

name

 |

The test name that is stored in the EDL as a [TestNameAttribute](<../02.10_Data_Logging/02.10.01.06.05.61_TestNameAttrType.md>) for a test result. Used when one of the [TEST](<02.07.04.01.241_TEST.md>) methods is subsequently called.

Test names can contain any printable ASCII characters, that is, characters with codes from 32 to 126. This includes the space, digits, lowercase letters, uppercase letters, and these punctuation characters: !"#$%&'()*+,-./:;<=>@?[\]^_`{|}~ There is no fixed maximum length for the names in SmarTest. However, STDF limits test names to 255 characters, so test names should not be longer if STDF data logging is intended.

 |
 |

forceSTDFTestName

 |

If this parameter is true, the data formatter writes the name value name directly into the TEST_NAM field of the [TSR record](<../02.10_Data_Logging/02.10.03.05.26_Test_Synopsis_Record__TSR.md>).

If the parameter is false, the data formatter calculates the content of the TEST_NAM field from the test suite name, test name, and pin name.

This parameter is optional. The default is false.

 |

## Example

```
TESTSET().testname("Sample_test");
```
