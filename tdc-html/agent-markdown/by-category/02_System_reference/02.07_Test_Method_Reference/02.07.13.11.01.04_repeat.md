# repeat()

Specifies the repeat number of the waveform.

## Syntax

```
repeat(int num);
```

List of parameters
 | Parameter  | Description |
 | num  | The number |

## Example

```
anaWaveform sine("sine");
  sine.definition(TM::SINE).periods(7).samples(1024).amplitude(1.5);

RDI_BEGIN();
  rdi.port("port1").dc().pin("pin1").vForce().waveform(sine).repeat(2).FS(10 KHz).execute();
RDI_END();
```

## Functional changes

- Introduced in SmartRDI 2.4.3
