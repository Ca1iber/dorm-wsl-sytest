# SMC_SERIAL_EXECUTION_BEGIN()

Marks the start of a SMC_SERIAL_EXECUTION block which forces SmartCalc to execute tests within your SMC_backgroundProcessing() method in serial.

The serial execution will have an effect on your test time and therefore should be used only rarely.

Note This API is meaningful only inside your [SMC_backgroundProcessing()](<02.07.04.01.231.01_SMC_ARM.md#_120107__s_SMC_backgroundProcessing>) method.Note [SMC_GET_WAVEFORM()](<02.07.04.01.231.20_SMC_GET_WAVEFORM.md>), [SMC_GET_COMPLEX_WAVEFORM()](<02.07.04.01.231.14_SMC_GET_COMPLEX_WAVEFORM.md>) and [SMC_GET_VECTORS()](<02.07.04.01.231.17_SMC_GET_VECTORS.md>) should not be used inside a serial block.

## Syntax

```
void SMC_SERIAL_EXECUTION_BEGIN();
```

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

  List of parameters There are no parameters. Return value There is no return value.

## Example

As counter is static this is not thread safe and could cause problems in your code. The SMC_SERIAL_EXECUTION block tells the SmartCalc framework that the content of this block has to be executed serially. So that the increment of counter has no effect on other running threads.

```
public:

    void SMC_backgroundProcessing(...)
    {
        static int counter = 0;
        ...
        ...
        SMC_SERIAL_EXECUTION_BEGIN();

            counter++;

            switch(counter)
            {
                case 1: ... break;
                case 2: ... break;
                default: break;
            }

        SMC_SERIAL_EXECUTION_END();
        ...
        ...
    } // void SMC_backgroundProcessing ...
```
