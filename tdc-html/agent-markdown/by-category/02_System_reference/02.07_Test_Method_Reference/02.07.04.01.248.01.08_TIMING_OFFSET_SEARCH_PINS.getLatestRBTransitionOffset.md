# TIMING_OFFSET_SEARCH_PINS.getLatestRBTransitionOffset()

This function returns the offset of the latest RB transition if found. If you retrieve the offset of multiple pins and the pins have different settings, the exception `TESTMETHOD_API::AmbiguityException` will be issued.

## Syntax

```
DOUBLE getLatestRBTransitionOffset();
```

## Return value

The offset of the latest RB transition is returned. The returned value is in the unit second.

## Functional changes

- Introduced in SmarTest 7.0.1
