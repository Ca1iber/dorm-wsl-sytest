# EVENT_WAVEFORM_ICIM.sampleVectorDistance()

Sets the distance between sample vectors.

## Syntax

```
EVENT_WAVEFORM_ICIM & sampleVectorDistance(INT vectors);
```

Parameter
 | Parameter  | Description |
 | vectors |

Number of vectors defining the distance. Minimum is 32 vectors.

 |

## Return value

A reference to the corresponding [EVENT_WAVEFORM_ICIM](<02.07.04.01.63.31_EVENT_WAVEFORM_ICIM.md>) object.
