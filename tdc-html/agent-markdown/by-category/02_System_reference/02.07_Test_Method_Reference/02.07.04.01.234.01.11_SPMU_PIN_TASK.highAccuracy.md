# SPMU_PIN_TASK.highAccuracy()

Selects for DC Scale XPS256 pins for the current task the high鈥慳ccuracy mode for voltage.

  Only the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) in the [PMU operating mode](<../02.05_Test_Head_Cards/02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md>) is supported:

- Forcing, clamping, and measuring voltage is performed in the 1.5 V voltage range: See the [XPS256 voltage specifications](<../02.02_Specifications/02.02.05.03.02_XPS256_voltage_specifications.md>).
