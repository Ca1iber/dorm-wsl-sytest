# AWG_Trig

This class contains APIs for the automatic generation of the trigger signal for the AWG used in mixed-signal concurrent testing.

This function is defined in the header file /opt/hp93000/soc/segments/tml/include/ext_include/protocol/AWG_Trig.hpp.

## Syntax

```
write0(UINT64 repeatCount)         //The API is used to write signal 0 to the pattern using the specified count.
```

Or,

```
write1(UINT64 repeatCount)       //The API is used to write trigger signal 1 to the pattern using the specified count.
```

List of parameters
 |

Parameter

 |

Description

 |
 |

repeatCount

 |

The repeat times of the trigger signal 0 or 1.

 |

## Example

```
CCTtsName = CCTgetTestsuiteName();
  GET_TESTSUITE_NAME(tsName);
  Sync.registerCCTestMethod(tsName, this);
...
AWG_Trig::getInstance(tsName).setPort("AwgTrig");
AWG_Trig::getInstance(tsName).setWaveTable("ADC_MP_wtb");
AWG_Trig::getInstance(tsName).setIdentifier("AwgTrig_" + tsName);
Sync.registerSyncPort(AWG_Trig::getInstance(tsName));
Sync.start();
...
AWG_Trig::getInstance(tsName).write0(150);
AWG_Trig::getInstance(tsName).write1();
AWG_Trig::getInstance(tsName).write0(170);
```
