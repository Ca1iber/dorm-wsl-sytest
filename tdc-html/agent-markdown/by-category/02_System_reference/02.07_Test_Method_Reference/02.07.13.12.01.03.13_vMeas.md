# vMeas()

Specifies a voltage measurement.

## Syntax

```
vMeas();
```

## Example

```
rdi.dc("vMeas").pin("pinA",TA::SPMU).vMeas().execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
