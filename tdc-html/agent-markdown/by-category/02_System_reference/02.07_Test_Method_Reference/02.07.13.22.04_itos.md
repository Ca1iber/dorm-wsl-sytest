# itos()

This function converts an integer value to a string.

## Syntax

```
string rdi.itos(integerVal);
```

## Example

```
long long l = 100;
string str = rdi.itos(l); // str = "100"
```

## Functional changes

- Introduced in SmartRDI 2.4.0
