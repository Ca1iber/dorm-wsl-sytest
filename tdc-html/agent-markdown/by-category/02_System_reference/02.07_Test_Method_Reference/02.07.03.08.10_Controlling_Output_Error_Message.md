# Controlling Output Error Message

To enable or disable the output error message to the report window, you can use the following APIs.

 |

The task to be executed....

 |

Use this API....

 |
 |

Disable the output error message to the report window

 |

DISABLE_ERROR_MESSAGE()

 |
 |

Enable the output error message to the report window

 |

ENABLE_ERROR_MESSAGE()

 |

For details, see [DISABLE_ERROR_MESSAGE](<02.07.04.01.40_DISABLE_ERROR_MESSAGE.md>) and [ENABLE_ERROR_MESSAGE](<02.07.04.01.58_ENABLE_ERROR_MESSAGE.md>).
