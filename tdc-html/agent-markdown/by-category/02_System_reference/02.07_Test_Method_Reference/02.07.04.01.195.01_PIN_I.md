# PIN_I

The member functions of the PIN_I class sets a new multiplexer setting data for the target pin specified by the pin member function of the ROUTING_STATUS API because the PIN_I class is always called as the subsidiary data container of the ROUTING_STATUS API. Therefore, the PIN_I class does not have a constructor. You cannot create an object of it. For related topics, see [ROUTING_STATUS - (Routing)](<02.07.04.01.195_ROUTING_STATUS_-__Routing.md>).

The enumeration ROUTE_MODE is supported, SINGLE means single-ended mode and DIFFERENTIAL means differential mode.

This class is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PinI_I.h.

## Member functions

### connect()

```
void connect(TM::ROUTE_MODE mode = TM::SINGLE, INT core = 1, INT coreIO = 1);
```

This member function connects the pin to the core of the analog module (input or output route).

- The E9825A hardware requires the default values for the input arguments core and coreIO.

At this time, the E9825A hardware will only support TM::SINGLE for the mode argument (TM::DIFFERENTIAL is not supported). Once this function has been called for a DGT pin, the system will set a path within the IF Multiplexer board in the RF subsystem. Therefore, while this pin remains connected, RF measurements will not be available. The E9825A AWG core is always connected to the pin, therefore this function does nothing for E9825A AWG channels.

Parameters
 |

`mode`

 |

The connect mode; TM::SINGLE, or TM::DIFFERENTIAL. The default is TM::SINGLE.

 |
 |

`core`

 |

(Legacy option) Omit this parameter or specify the default value, 1. If you omit this parameter, the core number 1 will be selected.

This parameter can be omitted together with the coreIO parameter. You cannot omit this parameter only.

 |
 |

`coreIO`

 |

(Legacy option.) Omit this parameter or specify the default value, 1.

 |

### fwd()

```
void fwd(const STRING& pin_name, TM::ROUTE_MODE mode = TM::SINGLE);
```

This member function connects the pin to another pin in the loopback route.

Parameters
 |

`pin_name`

 |

The name of the pin to be connected.

 |
 |

`mode`

 |

The connect mode; TM::SINGLE or TM::DIFFERENTIAL. The default is TM::SINGLE.

 |

This function is not supported by the E9825A hardware.

### trigger()

```
void trigger(INT core = 1);
```

This member function connects the pin to the SYNC_CLK pin (DC route).

This function is not supported by the E9825A hardware.

Parameter
 |

`core`

 |

(Legacy option) Omit this parameter or specify the default value, 1. If you omit this parameter, the core number 1 will be selected.

 |

### disconnect()

```
void disconnect();
```

This member function disconnects the pin from the core of the module.

For an E9825A DGT pin, this will release the paths set in the IF Multiplexer board in the RF subsystem. This will make RF measurements available. For the E9825A AWG channels, this command will stop a waveform that is in "RPTI" (infinitely repeating sequencer command).

There are no parameters in this member function.

### getConnectMode()

```
TM::ROUTE_MODE getConnectMode() const;
```

This member function returns the connection mode of an analog pin. The connection mode can be `SINGLE` or `DIFFERENTIAL`.

### isConnected()

```
Boolean isConnected();
```

The member function returns the connection state of a pin.

There are no parameters in this member function.

### getMode()

```
int getMode();
```

The member function returns the connection mode (single ended or differential) of a core.

There are no parameters in this member function.

Return code
 |

0

 |

The core is not connected at all.

 |
 |

1

 |

The core is in a single-ended connection.

 |
 |

2

 |

The core is in a differential connection.

 |

### getResource()

```
STRING getResource();
```

This member function returns the resource a pin is connected to.

There are no parameters in this member function.

Return code
 |

NC

 |

The pin is not connected at all.

 |
 |

GND

 |

The pin is connected to GND.

 |
 |

CORE

 |

The pin is connected to a core.

 |

## Example

- This example connects the "Aout" pin to the analog module's core with single-ended mode.

```
Routing.pin("Aout").connect(TM::SINGLE);
```

- This example returns the connection mode of Vin pin.

```
int Vin_mode = Routing.pin("Vin").getMode();
```

- This example returns the resource which Vin pin is connected to.

```
STRING Vin_resource = Routing.pin("Vin").getResource();
```
