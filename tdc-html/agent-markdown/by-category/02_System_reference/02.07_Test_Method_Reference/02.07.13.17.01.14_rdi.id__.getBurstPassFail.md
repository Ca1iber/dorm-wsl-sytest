# rdi.id().getBurstPassFail()

Retrieves a burst pattern test result (pass/fail). The pass/fail result has been stored in buffer by [rdi.func().burstId()](<02.07.13.17.01.02_rdi.func__.burstId.md>).

   Note If [SmartRDI alarm handling](<02.07.13.09_SmartRDI__Alarm_handling_for_DCVI.md>) is used, the burst pass/fail result is impacted by an alarm fail. This means if an alarm check fails, the burst result will fail too.

## Syntax

```
rdi.id(string burstId);
rdi.id(int burstId);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

burstId

 |

The same ID that you have given in a [rdi.func().burstId()](<02.07.13.17.01.02_rdi.func__.burstId.md>). It supports both string and int types.

 |
