# CCTregisterTx

This API registers the RF Tx pins so that data can be later uploaded from these pins with current upload ID. True will be returned if registered successfully. False will be returned if the pin name has been registered before.

This function is usually used in the `init()` function but not used in the other functions of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
bool CCTregisterTx(const string& pinName);
```

Parameter
 |

pinName

 |

The pin name of the RF Tx.

 |
