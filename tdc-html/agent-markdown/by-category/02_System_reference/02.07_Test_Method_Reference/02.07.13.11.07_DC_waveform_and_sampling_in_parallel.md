# DC waveform and sampling in parallel

#### Subtopics

- [Forcing waveform on a pin and sampling on the same pin](<02.07.13.11.07.01_Forcing_waveform_on_a_pin_and_sampling_on_the_same_pin.md>)
- [Forcing waveform on a pin and sampling on another pin](<02.07.13.11.07.02_Forcing_waveform_on_a_pin_and_sampling_on_another_pin.md>)
- [Forcing waveform and sampling in parallel on multiple pins](<02.07.13.11.07.03_Forcing_waveform_and_sampling_in_parallel_on_multiple_pins.md>)

SmartRDI supports parallel waveform and sampling on pins.

Starting from 2.4.4, SmartRDI can force a waveform on a pin while take samples on another pin.

Starting from 7.5.1, SmartRDI also can force a waveform and take samples in parallel on multiple pins defined in the same execute() .

## Examples

### Forcing a waveform on a pin and taking samples on another pin

```
RDI_BEGIN();
rdi.port("portC").dc().pin("A").waveform(sine).FS(100 KHz)
                      .pin("B").samples(1024).FS(100 KHz)
                      .execute();
RDI_END();
```

### Forcing a waveform and taking samples in parallel on multiple pins

```
RDI_BEGIN();
  rdi.dc().pin("AVI1").vForce().waveform(sine1).sampleCycle(1000)
          .pin("AVI2").iForce().waveform(sine2).sampleCycle(1000).execute();
RDI_END();
```

### Forcing a waveform and taking samples on the same DC Scale pin

```
RDI_BEGIN();
  rdi.dc("id1").pin().vForce().iMeas().waveform(wav).FS(10 KHz).execute();
  rdi.dc("id2").pin().vForce().vMeas().waveform(wav).FS(10 KHz).execute();
  rdi.dc("id3").pin().iForce().iMeas().waveform(wav).FS(10 KHz).execute();
  rdi.dc("id4").pin().iForce().vMeas().waveform(wav).FS(10 KHz).execute();
RDI_END();
```
