# dtos()

This function converts a double value into a string value.

## Syntax

```
string rdi.dtos(double)
```

## Example

```
double d =100.001;
string str=rdi.dtos(d); // str = "100.001"
```

## Functional changes

- Introduced in SmartRDI 2.4.0
