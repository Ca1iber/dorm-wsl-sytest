# SET_TESTFLOW_FLAG()

Sets the specified testflow flag to a particular value.

 Note Changing the flag state will be valid at the execution of the next test suite.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

## Syntax

```
SET_TESTFLOW_FLAG(const STRING& flag, INT value);
```

Parameters
 |

Parameter

 |

Description

 |
 |

flag

 |

The name of the testflow flag to be set.

For a detailed list of the testflow flags, refer to [Alphabetical list of flags](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md>). Select Testflow in the filter settings of column Area to show only the testflow flags.

 |
 |

value

 |

The value the specified flag shall be set to.

 |

Return value

There is no return value.

## Example

The next example shows how to set the debug_mode flag to display all details (mode 3).

```
SET_TESTFLOW_FLAG("debug_mode", 3);
```
