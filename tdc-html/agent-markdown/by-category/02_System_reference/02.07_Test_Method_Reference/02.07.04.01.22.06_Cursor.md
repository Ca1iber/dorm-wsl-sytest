# Cursor

Class Cursor controls the following cursor operations:

- make cursor visible/non-visible
- center cursors
- measure between x-reference and x-measure cursors
- measure between y-reference and y-measure cursors
- set cursor colors
- synchronize measure cursor with reference cursor
- specify on which axes to place x and y cursors

Class Cursor consists of four cursors: x-measure cursor, x-reference cursor, y-measure cursor, and y-reference cursor. You can operate or customize these cursors individually.

If the Graph has multiple axes, the Cursor object must belong to one of the axes.

## Examples

### Make cursors/markers non-visible temporarily

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getCursor().setVisible(false);
graphManager->setGraph(graph, 1);
```

This example sets the cursors in graph 1 to be invisible.

### Move cursors and display cursor positions

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
Cursor cursor = graph.getCursor();
ARRAY_D waveform = Analog.DGT("digitizer").getWaveform();
DOUBLE_VECTOR trace_wave;
Trace trace;
for(int i=0;i<waveform.size();i++)
{
  trace_wave.push_back(waveform[i]);
}
trace.setWaveform(trace_wave);
double min, max;
int min_index, max_index;
DSP_MINMAX(waveform, &min, &max, &min_index, &max_index);
cursor.setYMeasurePosition(min_index);
cursor.setYReferencePosition(max_index);
graph.setCursor(cursor);
graph.setTrace(trace, 1);
graphManager->setGraph(graph, 1);
```

This example moves the Y measure cursor to the minimum value of the waveform and the Y reference cursor to the maximum value of the waveform.

### Change cursor color

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
Cursor cursor = graph.getCursor();
cursor.setXMeasureColor(Display::WHITE);
cursor.setYMeasureColor(Display::GREEN);
cursor.setXReferenceColor(Display::RED);
cursor.setYReferenceColor(Display::BLUE);
graph.setCursor(cursor);
graphManager->setGraph(graph, 1);
```

This example changes the color of the four cursors to white, green, red and blue respectively.

### Synchronize cursors

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getCursor().setYTrackMode(Display::TRACK_ON);
graphManager->setGraph(graph, 1);
```

This example sets the track mode of the Y axis cursors to `ON`. These two cursors will be moved simultaneously.
