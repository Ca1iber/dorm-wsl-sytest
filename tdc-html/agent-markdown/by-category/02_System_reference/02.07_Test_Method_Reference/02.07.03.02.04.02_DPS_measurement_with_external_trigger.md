# DPS measurement with external trigger

You can measure the current using DPS triggered by an external source. The trigger is connected to a digital channel which is controlled by test pattern.This means that the measurement can be included as part of a functional test.

## About this task

DPS measurement with external trigger does not exist for DC Scale cards.

## Before you begin

- The DPS TR+ and TRVB- pins are wired to the required test system channel.
- A dummy digital pin has been defined in the pin configuration tool. (For details, see [Defining External Trigger for DPS Measurements](<../02.08_Setup_and_Result_Tools/02.08.04.18.02.07.07_Defining_external_triggers_for_DPS_measurements.md>))
- The trigger signal waveform has been defined. (For the signal limitation, see [Setting Up the External Trigger](<../02.06_Command_Reference/02.06.10.01.06.03_Setting_Up_the_External_Trigger.md>) )

## Procedure

-  Define the multiple limits used in the measurement.

  - You can use [MULTI_LIMITS](<02.07.04.01.133_MULTI_LIMITS.md>) API to add the same limit for different measurement as below:

```
MULTI_LIMITS mLimits;
mLimits.add(limit, 8);
```

where `limit` is already defined.

  - You can also use [MULTI_LIMITS](<02.07.04.01.133_MULTI_LIMITS.md>) API to define different limit values for different measurement as below:

```
MULTI_LIMITS mLimits;
mLimits.add("limit1").add("limit2").add("limit3");
```

where `limit1`, `limit2` and `limit3` are some defined limits.

-  Define the DPS measurement conditions with the member functions of [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) and [DPS_PIN_TASK](<02.07.04.01.50.01_DPS_PIN_TASK.md>).

```
DPS_TASK obj;
obj.pin("pinName").func1.func2...funcN;
```

where `pin("pinName")` is a member function of [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) API and `func1-N` are the member functions of [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) and [DPS_PIN_TASK](<02.07.04.01.50.01_DPS_PIN_TASK.md>).

-  Execute the DPS measurement with the `execute()` member function.

```
obj.execute();
```

-  Retrieve the measurement results with `getWaveform()` of DPS_TASK as below:

```
ARRAY_D valueArrayD;
valueArrayD = obj.getWaveform("Vcc");
```

-  Judge and log the test results.

```
for( i = 0 ; i < valueArrayD.size(); i++ )
{
  TESTSET().judgeAndLog_ParametricTest("Vcc", mLimits.get(i), valueArrayD[i]);
}
```

## Example

In the following example, eight triggers are issued in the digital pattern. And a limit is defined and used eight times in the DPS measurement with external trigger.

```
DPS_TASK dpsTask;
ARRAY_D valueArrayD;
INT i;
static LIMIT limit;

ON_FIRST_INVOCATION_BEGIN();
  CONNECT();
  limit.unit("A");
  limit.low(TM::GE, -4 uA);
  limit.high(TM::LE, 175 uA);
  MULTI_LIMITS templ; // Waveform contains 8 points
  templ.add(limit,8); // Make sure that your pattern issues 8 triggers,
                      // otherwise you will get an error message
  dpsTask.pin("Vcc").limits(templ);
  dpsTask.trigMode(TM::EXTERNAL).execMode(TM::PVAL);
  dpsTask.execute();
ON_FIRST_INVOCATION_END();
valueArrayD = dpsTask.getWaveform("Vcc");
for ( i = 0 ; i < valueArrayD.size(); i++ )
{
  TESTSET().judgeAndLog_ParametricTest("Vcc","DPS_ext", limit, valueArrayD[i]);
}
```
