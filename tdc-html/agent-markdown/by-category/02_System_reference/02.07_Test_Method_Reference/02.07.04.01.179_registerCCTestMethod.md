# registerCCTestMethod()

This API is used to register the current test method to CCTMultiPortSync.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTMultiportSync.hpp.

## Syntax

```
void registerCCTestMethod(const STRING& tsName,cct::CCTestMethod* _pCCTestMethod, bool _isSupportPAPort = true);)
```

Parameters
 |

tsName

 |

Returns the value of "GET_TESTSUITE_NAME"

 |
 |

_pCCTestMethod

 |

Returns the current test method point.

 |
 |

_isSupportPAPort

 |

Used to set support of protocol-aware port for the multi-port sync.

 |

## Example

```
CCTMultiportSync    Sync;
CCTtsName = CCTgetTestsuiteName();
GET_TESTSUITE_NAME(tsName);

Sync.registerCCTestMethod(tsName, this);

PatternPort::getInstance().setPort("SH1_Port");
PatternPort::getInstance().setWaitTemplatePatternName("SH1_Port_wait_template");
Sync.registerSyncPort(PatternPort::getInstance());

DCDynamicPort::getInstance().setPort("pDPS128");
Sync.registerSyncPort(DCDynamicPort::getInstance());

Sync.start();
...
Sync.sync();
...
Sync.flush();

Primary.label(Sync.getMultiPortBurstName());
Sync.dumpMPBGraph();
```
