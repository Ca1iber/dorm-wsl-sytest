This section introduces to DAC Tests on the V93000 test system. It describes the various static and dynamic characteristics and provides the formula that are used to calculate these characteristics.

  Note SmarTest 7.10 does not yet support DAC tests.

Basically, we distinguish between static and dynamic DAC characteristics.

These characteristics are calculated from the processed waveform.

The following static DAC characteristics can be calculated:

- [Differential Non-Linearity (DNL)](<02.07.03.05.02_Differential_Non-Linearity__DNL.md>)
- [Integral Non-Linearity (INL)](<02.07.03.05.03_Integral_Non-Linearity__INL.md>)
- [Offset](<02.07.03.05.04_Offset.md>)
- [Full Scale Gain (FS Gain)](<02.07.03.05.05_Full_Scale_Gain__FS_Gain.md>)
- [LSB Gain](<02.07.03.05.06_LSB_Gain.md>)
- [Gain Mismatch (Match)](<02.07.03.05.07_Gain_Mismatch__Match.md>)Note For all static DAC tests n refers to the DAC resolution in terms of the number of bits.

The following dynamic characteristics can be calculated:

- [Total Harmonic Distortion (THD)](<02.07.03.05.08_Total_Harmonic_Distortion__THD.md>)
- [Signal to Noise plus Distortion (SND)](<02.07.03.05.09_Signal_to_Noise_plus_Distortion__SND.md>)
- [Signal to Noise Ratio (SNR)](<02.07.03.05.10_Signal_to_Noise_Ratio__SNR.md>)
- [Spurious Free Dynamic Range (SFDR)](<02.07.03.05.11_Spurious_Free_Dynamic_Range__SFDR.md>)
- [Signal](<02.07.03.05.12_Signal.md>)Note For all dynamic DAC tests, n refers to the nth harmonic of the DAC output signal.
