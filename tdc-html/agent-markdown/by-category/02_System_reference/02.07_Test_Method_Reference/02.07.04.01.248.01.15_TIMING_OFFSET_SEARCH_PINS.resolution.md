# TIMING_OFFSET_SEARCH_PINS.resolution()

This function sets the resolution for the binary search. If it is not specified, the step width will be used to stop the binary search.

## Syntax

```
TIMING_OFFSET_SEARCH_PINS& resolution(DOUBLE res);
```

Parameter
 |

Parameter

 |

Description

 |
 |

res

 |

The resolution of the binary search.

The unit is seconds [s].

 |

## Return value

A reference to the [TIMING_OFFSET_SEARCH_PINS](<02.07.04.01.248.01_TIMING_OFFSET_SEARCH_PINS.md>) object.

## Functional changes

- Introduced in SmarTest 7.0.1
