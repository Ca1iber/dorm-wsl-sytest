# start()

This function sets the start limit of a search range.

The meaning is different for linear and binary algorithms:

- For a linear search, it is the start value of the search.
- For a binary search, it is the outermost value (limit) of the search range that causes a pass result. This might be the minimum or the maximum value of the search range.

See [Sequencer-controlled searching with cogo](<02.07.13.19.02_Sequencer-controlled_searching_with_cogo.md>) for more information about the relation between `start()`, `stop()` and `init()`.

## Syntax

```
start(double dPass)
```

List of parameters
 |

Parameter

 |

Description

 |
 |

dPass

 |

The start limit of your search range. See explanation above for linear and binary algorithms.

 |

## Example

```
rdi.cogo().search(TA::LINEAR).pathPin("pinA").start(0).stop(4.0).step(10).blockBegin();
```
