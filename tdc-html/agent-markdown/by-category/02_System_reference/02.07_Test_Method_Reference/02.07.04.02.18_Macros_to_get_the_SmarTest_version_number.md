# Macros to get the SmarTest version number

There are macros provided to retrieve the SmarTest version information in test method.

These macros are:

SMARTEST_VERSION_MAJOR: major version number

SMARTEST_VERSION_MINOR: minor version number

SMARTEST_VERSION_QUALITY: quality version number

SMARTEST_VERSION_PATCH: patch version number

These macros will be available when `#include "testmethod.hpp"` is included in the test method.

These macros can be used in the test method to control whether to compile a section of test method under a specific version of SmarTest.

## Example

In the following example, the test method code in-between will only be compiled when SmarTest version number larger than or equal to 7.1.2.

```
#if ((SMARTEST_VERSION_MAJOR ==7)&&(SMARTEST_VERSION_MINOR>1))| |
  ((SMARTEST_VERSION_MAJOR ==7)&&(SMARTEST_VERSION_MINOR ==1)&&(SMARTEST_VERSION_QUALITY >1))
  //test method code
  ...
#endif
```

## Functional changes

- Introduced in SmarTest 7.1.0
