# Creating a protocol class

#### Subtopics

- [I2C predefined transactions](<02.07.13.08.12.02.04.01_I2C_predefined_transactions.md>)
- [JTAG predefined transactions](<02.07.13.08.12.02.04.02_JTAG_predefined_transactions.md>)
- [SPI predefined transactions](<02.07.13.08.12.02.04.03_SPI_predefined_transactions.md>)

A protocol class can be created from scratch or customized from a template.

## About this task

This topic describes how to create a protocol class from scratch.

## Procedure

-  Open a C++ text editor and create a new file.
-  Define a protocol class at the beginning of the file.

For example, `class MyI2C : public ProtocolI2C`

-  Define required elements, for example, protocol name, pin name, and clock speed.
-  Define logical operations, for example, read, write or compare through predefined transactions.
-  Use `REGISTER_PROTOCOL` at the end of the code.
-  Save the file to a .cpp file.
-  Put the .cpp file to the test method project.

## Results

The protocol class is ready to be used by the device in test methods.

## Example

In the protocol: No header file is required.

```
#include "RA_protocols.h"

namespace {

using namespace RA;
using namespace std;

/**
 * This is a template of an I2C protocol class which defines the basic properties
 * and operation logics of the protocol.
 */
class I2CTemplate : public ProtocolI2C {
public:
  I2CTemplate() {}
  virtual ~I2CTemplate() {}

  const static int SLAVE_ADDRESS = 0xE8;

  /**
   * (Mandatory)
   * Create a singleton.
   */
  RA_CREATE_SINGLETONE(I2CTemplate);

  /**
   * (Mandatory)
   * Give a reasonable name as an ID to identify this protocol class.
   * This name can be used in Test Method to switch to this protocol,
   * e.g. RA_SWITCH_PROTOCOL("I2CTemplate");
   */
  virtual std::string getName() const { return "I2CTemplate"; }

  /**
   * (Mandatory)
   * Define the speed of this protocol.
   */
  virtual double getClockSpeed() const { return 2.5 MHz ; }

protected:
  /**
   * (Mandatory)
   * Define the logics of the register write operation.
   */
  virtual void defineWriteRegister(I2C& i2c, ULONG64 address, ULONG64 data) {
    i2c.startCondition();
    i2c.sendByteWithAck(SLAVE_ADDRESS);
    i2c.sendByteWithAck(address / 256);
    i2c.sendByteWithAck(address % 256);
    i2c.sendByteWithAck(data, "inData"); //"inData" is a named parameter
    i2c.stopCondition();
  }

  /**
   * (Mandatory)
   * Define the logics of the register read operation.
   */
  virtual void defineReadRegister(I2C& i2c, ULONG64 address, int numberOfData) {
    i2c.startCondition();
    i2c.sendByteWithAck( SLAVE_ADDRESS);
    i2c.sendByteWithAck( address / 256);
    i2c.sendByteWithAck( address % 256);
    i2c.startCondition();
    i2c.sendByteWithAck( SLAVE_ADDRESS + 1);

  if(numberOfData <= 1) {
      // One data
      i2c.receiveByteNoAck("outData");
    } else {
      // Burst read
      i2c.loopBegin(numberOfData - 1);
          i2c.receiveByteAckLow("outData");
      i2c.loopEnd();
      i2c.receiveByteNoAck("outData");
    }

    i2c.stopCondition();
  }

  /**
   * (Mandatory)
   * Define the logics of the register compare operation.
   */
  virtual void defineCompareRegister(I2C& i2c, ULONG64 address, ULONG64 expectData, ULONG64 maskData) {
    i2c.startCondition();
    i2c.sendByteWithAck(SLAVE_ADDRESS);
    i2c.sendByteWithAck(address / 256);
    i2c.sendByteWithAck(address % 256);
    i2c.startCondition();
    i2c.sendByteWithAck(SLAVE_ADDRESS + 1);
    i2c.compareByteNoAck(expectData, maskData);
    i2c.stopCondition();
    }

  /**
   * (Mandatory)
   * Define how the data and/or the address is set into parameter(s).
   */
  virtual void composeRegisterWriteData(ParameterSetter& param, ULONG64 address, ULONG64 data) {
    param.setValue("inData", data);
  }

  /**
   * (Mandatory)
   * Define how parameters are assembled to the result of a register read operation.
   */
  virtual RA::ULONG64 composeRegisterReadData(ParameterGetter& param) {
    return param.getValue("outData");
  }

  /**
   * (Mandatory)
   * Define the pin to be used as SCL.
   */
  virtual std::string getPinName_SCL() const { return "I2C_SCL"; }

  /**
   * (Mandatory)
   * Define the pin to be used as SDA.
   */
  virtual std::string getPinName_SDA() const { return "I2C_SDA"; }

  /**
   * (Optional)
   * Define the logics of the register array-write operation.
   */
  virtual void defineWriteArray(I2C& i2c, ULONG64 address, const vector<ULONG64>& arrayData) {
    i2c.startCondition();
    i2c.sendByteWithAck(SLAVE_ADDRESS);
    i2c.sendByteWithAck(address / 256);
    i2c.sendByteWithAck(address % 256);
    for(unsigned int i=0;i<arrayData.size();++i) {
        i2c.sendByteWithAck(arrayData.at(i));
    }
    i2c.stopCondition();
  }
};

/**
 * (Mandatory)
 * Register this protocol class to the RA lib.
 */
REGISTER_PROTOCOL(I2CTemplate);
}
```

 In the test method: No `#include` is required.

```
RDI_BEGIN();
  ...
  RA_SWITCH_PROTOCOL("I2C"); // Call the protocol directly.
  ...
RDI_END();
```
