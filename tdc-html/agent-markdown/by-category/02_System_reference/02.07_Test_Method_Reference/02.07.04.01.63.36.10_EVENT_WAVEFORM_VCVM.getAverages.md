# EVENT_WAVEFORM_VCVM.getAverages()

Queries the number of internal samples to average.

The value is read from the corresponding [EVENT_WAVEFORM_VCVM](<02.07.04.01.63.36_EVENT_WAVEFORM_VCVM.md>) object and returned as an [EVENT_VALUE_INT](<02.07.04.01.63.19_EVENT_VALUE_INT.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getAverages(EVENT_VALUE_INT & samples) const;
```

Parameter
 | Parameter  | Description |
 | samples  | Number of internal samples from which the average is created. |

Return value

There is no return value.
