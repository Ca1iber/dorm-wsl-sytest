# EVENT_WAVEFORM_VCIM.sampleVectorDistance()

Sets the distance between sample vectors.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_WAVEFORM_VCIM & sampleVectorDistance(INT vectors);
```

Parameter
 | Parameter  | Description |
 | vectors |

Number of vectors defining the distance. Minimum is 32 vectors.

 |

## Return value

A reference to the corresponding [EVENT_WAVEFORM_VCIM](<02.07.04.01.63.35_EVENT_WAVEFORM_VCIM.md>) object.
