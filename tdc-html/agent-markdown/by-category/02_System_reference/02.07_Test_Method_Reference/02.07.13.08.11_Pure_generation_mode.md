# Pure generation mode

#### Subtopics

- [rdi.pureGenerationMode()](<02.07.13.08.11.01_rdi.pureGenerationMode.md>)

When pure generation mode is enabled, SmartRDI only generates setups for pattern, burst, DC event, analog set, and others. At the same time SmartRDI skips pattern execution and result upload.

 As a result, all `rdi...getXxxx()` calls such as `getVector()`, `getReadBit()`, `getWaveform()` return dummy results. The size of result arrays = 0.

This pure generation mode is supported through the keyword [PURE_GENERATION_MODE](<02.07.13.04_RDI_Configure_file.md#_146692__row_PURE_GENERATION_MODE>) in [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>) or [rdi.pureGenerationMode()](<02.07.13.08.11.01_rdi.pureGenerationMode.md>) in SmartRDI code.

[PURE_GENERATION_MODE](<02.07.13.04_RDI_Configure_file.md#_146692__row_PURE_GENERATION_MODE>) works globally for SmartRDI actions while [rdi.pureGenerationMode()](<02.07.13.08.11.01_rdi.pureGenerationMode.md>) targets a test suite locally at one time.

When this feature is enabled, Viasco bind is omitted by the execution in the first run, which can shorten the total first run time. The generated setups for pattern, burst, DC event, analog set, and others can be saved for reuse later or in other test programs.

To enable the pure generation mode, set the [PURE_GENERATION_MODE](<02.07.13.04_RDI_Configure_file.md#_146692__row_PURE_GENERATION_MODE>) keyword to true in your [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>) as follows:

```
PURE_GENERATION_MODE = true
```

To control the pure generation in a test suite, refer to [rdi.pureGenerationMode()](<02.07.13.08.11.01_rdi.pureGenerationMode.md>)
