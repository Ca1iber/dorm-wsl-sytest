The miscellaneous test method library provides test control methods, sequencer control methods and some other methods. You can create your test method project by copying from the library. You can also use it as a template and modify the source file to suit your project. The source files of the test methods are included in the file /opt/hp93000/soc/testmethod/library/miscellaneous_tml.zip.

The following test methods are included:

- Test control methods

  - [Disconnect](<02.07.05.04.02_Disconnect.md>): Disconnects the test system from the DUT
  - [Connect](<02.07.05.04.01_Connect.md>): Connects the test system to the DUT
  - [SetupLevelSet0](<02.07.05.04.06_SetupLevelSet0.md>): Programs the level set of tri-state highZ state.

- Sequencer control methods

  - [TestState](<02.07.05.04.10_TestState.md>): Returns the current sequencer state
  - [StartSequencer](<02.07.05.04.08_StartSequencer.md>): Starts the vector sequencer

- Other test methods

  - [TestheadTemperature](<02.07.05.04.09_TestheadTemperature.md>): Reads the temperature of the test head
  - [SetUtilityLines](<02.07.05.04.07_SetUtilityLines.md>): Sets the status of the utility lines
  - [GetUtilityLines](<02.07.05.04.05_GetUtilityLines.md>): Gets the status of the utility lines
  - [FwEscape](<02.07.05.04.04_FwEscape.md>): Executes a firmware command
  - [ExecuteLinuxCommand](<02.07.05.04.03_ExecuteLinuxCommand.md>): Executes a Linux shell command.
