# SmartRDI 2.5.1

This section summarizes software changes including new features and enhancements in SmartRDI 2.5.1.

Changes and new features
 |

Category

   | Description |
 | SmartVec  | Support pattern generation with per-site data no matter whether the site is enabled or not. See [writeBit()](<02.07.13.24.35_writeBit.md>), [writeData()](<02.07.13.24.36_writeData.md>), [writeParData()](<02.07.13.24.38_writeParData.md>), and [writeVec()](<02.07.13.24.41_writeVec.md>) |
 | DC  | Support inserting a wait pattern as a sublabel to control the waiting time between actions. See the example in [insertSub()](<02.07.13.12.02.20_insertSub.md>). |
 | UTIL  | The default value for UTIL_DYN_MASK_UNSPECIFIED_PIN is changed to TRUE. Therefore, the default behavior of sequencer‑controlled utility is changed. See [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>).  |
