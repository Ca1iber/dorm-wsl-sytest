# TMU_RESULTS.measurement()

Sets the measurement ID for which the samples are uploaded.

## Syntax

```
TMU_RESULTS& measurement(UINT32 meas);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

meas

 |

An integer that defines a measurement block (identified by the ARM keyword within a waveform that is executed in the pattern) from which time stamps are (to be) retrieved. If no measurement block is specified, the query refers to all measurement blocks. The default value is 1.

   | Note If the first sample, number of samples and measurement ID are not specified, all samples will be uploaded with `uploadRawResults()` of TMU_PINS.

## Return value

A reference to the TMU_RESULTS object is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
