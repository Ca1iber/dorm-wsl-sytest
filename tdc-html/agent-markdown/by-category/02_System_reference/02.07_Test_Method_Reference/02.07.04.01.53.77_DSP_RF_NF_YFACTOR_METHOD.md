# DSP_RF_NF_YFACTOR_METHOD()

To extract the noise based on the Y-factor method, you need 2 captures, 1 Hot (Noise Stim On), and 1 Cold (DUT Input 50-Ohm Terminated) Capture 1 = Hot, Capture 2 = Cold.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_RF_NF_YFACTOR_METHOD(const ARRAY_COMPLEX & sourceDataHot,
const ARRAY_COMPLEX & sourceDataCold,
const ARRAY_D & measParamsHot,
const ARRAY_D & measParamsCold,
const DOUBLE deviceGain_Watt,
const DOUBLE ENR_lin,
const INT doSidebandCorrection,
DOUBLE * noiseFigure_dBm);

DSP_RF_NF_YFACTOR_METHOD(const ARRAY_COMPLEX & sourceDataHot,
const ARRAY_COMPLEX & sourceDataCold,
const ARRAY_D & measParamsHot,
const ARRAY_D & measParamsCold,
const DOUBLE deviceGain_Watt,
const DOUBLE ENR_lin,
const INT doSidebandCorrection,
const INT site,
DOUBLE * noiseFigure_dBm);
```

## Example

```
//Get MeasParams from a NoiseFigure type of measurement
ARRAY_D hotNoiseParams  = MEAS_DEF(measName).getParameters(1,freqListIndex);
ARRAY_D coldNoiseParams = MEAS_DEF(measName).getParameters(2,freqListIndex);
// Get Capture Data from the NoiseFigure measurement.
ARRAY_COMPLEX hotData  = MEAS_DEF(measName).getComplexWaveform(1);
ARRAY_COMPLEX coldData = MEAS_DEF(measName).getComplexWaveform(2);
//Get the actual ENR of your ENR source. Convert it to linear units
DOUBLE actualENR_dB = STIM_DEF(stimName).getActualENR(freqListIndex, enrListIndex);
DOUBLE actualENR_lin = pow(10.0, actualENR_dB/10.0);
// Decide if you need to apply sideband corrections. This is only needed if you are measuring a BW wide enough that the LO image does not include the Hot Noise.
//if you use the Noise Diode, then do not use this correction.
INT doSidebandCorrection = 0;
//If you use the AWG stim, then you need to consider your BW and your IF Frequency. The BW of the ENR signal is 40MHz.
// If your (IF Frequency + (Measurement BW / 2)) > 20MHz, then you need to use the sideband correction.
  INT doSidebandCorrection = 1;
//Most setups do not need to use sideband correction, Typically a measurement BW of 8MHz can use an IF of 8MHz and stay within the AWG Noise BW.
  INT doSidebandCorrection = 0;
// Run the DSP
DOUBLE deviceGain_Watts = 1; // This is in watts, to compute from dB use -> Watts = pow(10.0, (gain_dB)/10.0)
DOUBLE measNF_Gain = 0;
DSP_RF_NF_YFACTOR_METHOD(hotData, coldData, hotNoiseParams, coldNoiseParams, deviceGain_Watts, actualENR_lin, doSidebandCorrection, &measNF_Gain);
```
