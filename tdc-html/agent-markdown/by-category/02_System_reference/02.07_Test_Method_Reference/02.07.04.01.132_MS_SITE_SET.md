# MS_SITE_SET

A defined data type. It is a character array with the length of MS_MAX_SITES + 1, used to access the status of all configured sites. Each element will contain the status of a site.

MS_SITE_SET is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/MapiBasic.h.

For example, if you define an MS_SITE_SET variable siteSet, used by SET_ACTIVE_SITES() or GET_ACTIVE_SITES(), siteSet[i] will contain the status of site i. i starts from 1 to represent site 1, 2, 3, ...; 0 is not a valid site number. siteSet[0] will be ignored.

- If siteSet[i] is not 0, site i will be activated. (i = 1, 2, 3, ...)
- If siteSet[i] = 0, site i will be deactivated. (i = 1, 2, 3, ...)

## Syntax

```
typedef char MS_SITE_SET[MS_MAX_SITES+1];
```

For the definition of MS_MAX_SITES, refer to [Number of sites](<../../01_Getting_started/01.04_SmarTest_system_parameters_-_default_values_and_limits/01.04_SmarTest_system_parameters_-_default_values_and_limits.md#_116532__r_numberOfSites>) in [SmarTest system parameters - default values and limits](<../../01_Getting_started/01.04_SmarTest_system_parameters_-_default_values_and_limits/01.04_SmarTest_system_parameters_-_default_values_and_limits.md>).
