# CCTgetContextPins

Returns the pins and ports to be executed on the synchronous or independent sequencer.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
string CCTgetContextPins();
```

List of parameters

There are no parameters.

## Return value

The pins and ports defined specified to be run on the synchronous or independent sequencer are returned.

## Example

```
STRING contextPins;
contextPins=CCTgetContextPins();
```

## Functional changes

- Introduced in SmarTest 7.2.0
- SmarTest 7.2.1: Rename the API from CCT_getContextPins to CCTgetContextPins.
