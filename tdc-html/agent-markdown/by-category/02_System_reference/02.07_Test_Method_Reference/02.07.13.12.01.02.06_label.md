# label()

Specifies a name of a pattern on which dynamic DC measurements can be performed.

You can use [insertSub()](<02.07.13.12.01.01.10_insertSub.md>) to insert one or more subroutines to an existing pattern.

The specified label must be the main label, not a burst label or subroutine.

## Syntax

```
label(const string& sLabelName);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

sLabelName

 |

The name of the pattern on which dynamic DC measurements can be performed.

 |

## Examples

### Example 1

```
RDI_BEGIN();
  rdi.dc().label("dc_label").insertSub(10).pin("pinA").vForce(1)
                            .insertSub(20).pin("pinB").vForce(2).iMeas()
                            .execute();
RDI_END();
rdi.dc().pin("pinA").vForce(2 V).iMeas().iMeasRange(1 mA).execute();
```

### Example 2

```
RDI_BEGIN();
  rdi.dc().label("mainlabel")
     .insertSub(10).pin(A).vForce(1)
     .insertSub(15).label("sublabel")
     .insertSub(10,2).pin(B).vForce(2)
     .insertSub(20).pin(C).iForce(1 mA).vMeas()
     .execute();
RDI_END();
```
