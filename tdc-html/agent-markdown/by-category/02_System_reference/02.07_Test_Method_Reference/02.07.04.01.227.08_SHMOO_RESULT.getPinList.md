# SHMOO_RESULT.getPinList()

Retrieves result pins of the shmoo test results that have been defined with [SHMOO_RESULT.setResult()](<02.07.04.01.227.05_SHMOO_RESULT.setResult.md>).

## Syntax

```
STRING_VECTOR getPinList();
```

List of parameters

There are no parameters.

## Return value

Returns a string vector that stores the retrieved result pins.

## Example

```
double meaValue1;
meaValue1 = ifvmMea.getValue("I/O1");
bool funcResult =GET_FUNCTIONAL_RESULT();

SHMOO_RESULT.pin("I/O1").testName("Voltage").setResult(meaValue1);
SHMOO_RESULT.site(1).pin("dataPins").testName("Function").setResult(funcResult);

STRING_VECTOR pinList = SHMOO_RESULT.getPinList(); //pinList will store both "I/O1" and "dataPins".
```
