# JITTER_INJECTION_SET

#### Subtopics

- [JITTER_INJECTION_PINS](<02.07.04.01.122.01_JITTER_INJECTION_PINS.md>)

The JITTER_INJECTION class holds the setup information of a jitter injection set. It is used to set up the jitter modulator within Smart Scale cards.

## Class definition

### Constructor

```
JITTER_INJECTION_SET (const std::string& setName,const std::string& modeContext)

```

### Constructor

```
JITTER_INJECTION_SET (const std::string& setName,const std::string& modeContext)
JITTER_INJECTION_SET(const std::string& setName,TESTMETHOD_API::TMAPICTXT_TYPE ctxt = TESTMETHOD_API::TMAPI_CURR);
```

This constructor creates an object of the `JITTER_INJECTION_SET class` for the specified jitter set. If the specified jitter set does not exist, it is automatically created.

## Member functions

The member functions are operated on an object of JITTER_INJECTION_SET.

### pin()

```
JITTER_INJECTION_PINS& pin(const STRING& pinList);
```

This function returns a reference to the `JITTER_INJECTION_PINS` object with the specified pin list. You can call the member functions of `JITTER_INJECTION_PINS` after it.

Parameter
 |

pinList

 |

The pin list to work with.

 |

### setAsPrimary()

```
void  setAsPrimary();
```

This function sets the current jitter set as the primary set. The jitter set will be activated with the next FTST? query (which means before start sequencer). It calls the JSPR firmware command to define the jitter set as primary. Note that the mode context of the jitter set must be the same as for all other components of the primary setup.

### remove()

```
void remove();
```

This member function will remove the current jitter set from the firmware. It calls the JSUD firmware command. It makes the jitter set invalid and calling other functions after it will cause an exception.

## Class functions

The class functions Do not relate to a specific jitter injection set. You can use them without an object of JITTER_INJECTION_SET.

### resetJitterModulator()

```
static void resetJitterModulator(const STRING& pinList);
```

This function forces the jitter modulator back to its default state, so that the jitter waveform starts reproducible with the pattern. Normally, it is used for all pins(@).

Parameter
 |

pinList

 |

The pin list for which to reset the jitter modulator.

 |

### getPrimarySet()

```
static const STRING& getPrimarySet();
```

This function returns the name of the current primary set. If the default setting is the primary set, it will return an empty string.

### getListofSets()

```
static void getListofSets(STRING_VECTOR & setNames)
```

This function returns the list of jitter set names you have defined.

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

The returned set names.

 |

### deselectGlobally()

```
static void deselectGlobally();
```

This function disables jitter injection globally.

### removeAll()

```
static void removeAll();
```

This function removes all the jitter injection sets from the firmware.
