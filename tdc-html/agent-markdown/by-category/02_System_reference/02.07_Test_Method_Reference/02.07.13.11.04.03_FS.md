# FS()

Specifies the sampling frequency when PPMU, board ADC or DC Scale pin is used as digitizer.

This function can be used only in pattern鈥慴ased mode.

The sample rate can be set by one of the functions FS(), sampleCycle(), or samplePeriod(). SmartRDI issues a warning at the first run and selects a sample rate that is defined by the pattern cycle period and the 32 vectors that are required per DC event if none of these functions is used. The programmed sample rate must always be lower than the sample rate that is supported by the hardware.

Note DC scale cards feature hardware based averaging that is controlled by function average(). Hardware based averaging can be used in pattern鈥慴ased mode. The required sample time depends on the sample rate of the ADC and the number of averaged samples. The time between the measurement events of a digitizer wave that is defined by functions FS(), sampleCycle(), or samplePeriod() must always be larger than the time that is required for averaging. Violating this rule will result in lost measurements: A flag "Distance too small" will be set in in this case. The state of the flag can be checked by command [TSST? - (TeSt STatus)](<../02.06_Command_Reference/02.06.02.02.280_TSST__-__TeSt_STatus.md>).

## Syntax

```
FS(double dSampleFreq);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

dSampleFreq

## Example

```
rdi.dc().pin("DATA1")
        .vMeas().samples(1024).capMode(TA::VEC)
        .valueMode(TA::SA).FS(1 KHz).execute();

rdi.port("ptPin1").dc().pin("DATA1",TA::BADC)
        .samples(1024). capMode(TA::TRIG).FS(10KHz).execute();

rdi.dc().pin("DPS_pin_1")
        .vForce(2 V).iMeas().samples(1024).FS(10 KHz).execute();
```
