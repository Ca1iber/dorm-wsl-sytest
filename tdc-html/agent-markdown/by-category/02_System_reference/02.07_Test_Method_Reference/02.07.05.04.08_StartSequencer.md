# StartSequencer

This test method starts the vector sequencer. It runs a functional test but does not return a pass/fail result and does not block firmware communication. You can thus modify timing or level parameters while the sequencer is running.

Note It is only available for universal test method.

The sequencer is started at the supplied sequencer label. The break key can be used at any time. It brings about an asynchronous sequencer stop. When the sequencer stops, it is either due to the programmed instruction sequencer or due to a break.

The main application of this test method is to output test vectors in an endless loop and thus allow measurements on the DUT with a scope or other external equipment under running conditions. How the sequencer is stopped depends on the mode selected.

## Dependencies

- Starting any other test (except the test to retrieve the current sequencer state) will cause the current sequencer to stop before the new sequencer is started.
- If a sequencer label other than DEFAULT is specified, it must be defined in the Pattern tool. Note This test method does not support multi-port test.

## Functional changes

- Introduced in SmarTest 6.5.2
