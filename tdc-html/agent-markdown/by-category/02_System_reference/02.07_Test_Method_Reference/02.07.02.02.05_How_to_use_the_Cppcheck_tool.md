# How to use the Cppcheck tool

## About this task

Test methods in SmarTest 7 are written in the C++ programming language. C++ lacks default protection mechanisms such as garbage collection or automated memory management. So programmes must be carefully inspected for problems.

Manual inspection of test methods is necessary, but it can be easy to overlook bugs, as the methods grow in size and complexity. To supplement this inspection then, the Cppcheck tool provides a static code analysis of the test methods, and reports bugs and run-time errors, which are not detected by the compiler, such as out of bound array access, uninitialized variables, and memory leaks.

## Before you begin

 You can install the tool from SmarTest for the Cppcheck tool version 1.56 or higher:

- Click Help > Install New Software.
- Add the new update site https://dl.bintray.com/cppcheclipse/p2/updates/.
- Uncheck Group items by category.
- Select cppcheclipse and click Next.
- Follow the installation wizard, until the installation is complete.
- Restart Eclipse.

Alternatively, you can install the Cppcheck tool using the command line interface:

For RHEL7:

> yum install cppcheck-1.83-3.el7.x86_64.rpm tinyxml2-2.1.0-2.20140406git6ee53e7.el7.x86_64.rpm.

This requires the tinyxml rpm to be installed.

The cppcheck installation file is available with the latest SmarTest Platform Delta Bundles (PDBs).

## Procedure

-  In the Project Explorer, right-click the test method you want checked, and click cppcheck > Run cppcheck.

![Run cppcheck from Eclipse](<../../../../raw/349248.png>)

-  You will now see the potential errors indicated, both in the editor if your test method is open, and in the Problems view, as shown below.

![Errors found with cppcheck](<../../../../raw/349249.png>)

Alternatively, you can run Cppcheck from the command line, by navigating to the folder with your test method and typing cppcheck. The results are now printed in the terminal window.

## Results

You have now used the Cppcheck tool to locate bugs and errors in your test method.

## What to do next

For a complete check of your code, the static analysis tool Cppcheck must be complemented with a dynamic tool, such as [Valgrind](<02.07.02.02.06_How_to_use_valgrind_with_UTM.md>).
