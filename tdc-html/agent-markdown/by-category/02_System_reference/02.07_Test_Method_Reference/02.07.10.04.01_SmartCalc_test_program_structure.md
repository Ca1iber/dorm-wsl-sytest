# SmartCalc test program structure

SmartCalc works only within the Universal Test Method (UTM) framework. It supports hidden (segmented) upload of digital capture.

UTM is a C++ based test method framework. Each test method is one class and each test suite is represented as one object. For each site the `void run(void)` method is called. The test method parameters are handled as member variables.

Since SmartCalc APIs are part of the MAPI, they are available for use after including the MAPI header (`#include "mapi.hpp"`) in the source file.

The macro SMC_VERSION identifies the version of SmartCalc.

## Functional changes

- Introduced in SmarTest 6.5.3
- SmarTest 7.1.0: SmarTest requires Red Hat Enterprise Linux 5 update 6
