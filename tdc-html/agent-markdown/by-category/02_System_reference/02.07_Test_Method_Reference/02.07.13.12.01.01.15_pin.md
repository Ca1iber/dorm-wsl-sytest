# pin()

Specifies the pin(s) for the following DC actions. It indicates the ending of the setups for the previous pin(s) and the start of the setups for the specified pin(s).

Do not specify different types of pins in the same function `pin()`. To set up different types of pins in the same line of code, put different types of pins in separate functions of `pin()` with the same `execute()`.

## Syntax

```
pin(const string& sPin, TA::PinType instrument = TA::PPMU);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

sPin

 |

The pin on which the following setups will be done. Its value can be a pin, a pin group, a port name as a pin group, the pins or pin groups separated with comma, or all pins.

 |
 |

instrument

(Only for digital pin)

 |

The instrument used to do the measurement. It can be:

- TA::PPMU (default): Either PPMU is used to measure, or the board ADC connected through PPMU is used to measure.
- TA::BADC: Board ADC connected through DC relays is used to measure.
 |

## Examples

Using PPMU to measure a pin "pinA".

```
rdi.dc("vMeas").pin("pinA").vMeas().execute();
```

Using a port name as a pin group.

```
rdi.dc().pin("DPS_port").vForce(3).execute()
```

## Functional changes

- Introduced in SmartRDI 2.1.0
- SmartRDI 2.3.0: Supports high voltage pins in static DC measurement.
- SmartRDI 2.4.0: Supports a port name as a pin group.
