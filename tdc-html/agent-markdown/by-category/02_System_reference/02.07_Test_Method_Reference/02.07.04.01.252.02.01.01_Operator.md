# Operator <<

Outputs the settings of the associated pin in the TMU_TASK object.

## Syntax

```
std::ostream & operator << (std::ostream & os, const TMU_PINS & rhd);
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

os

 |

The data stream to output

 |
 |

I

 |

rhd

 |

The related TMU_PINS object

 |

## Return Value

A reference to the data stream is returned.

## Example

```
TMU_TASK task;
...
cout <<task.pin("pinA") <<endl;
```

## Functional changes

- Introduced in SmarTest 7.1.0
