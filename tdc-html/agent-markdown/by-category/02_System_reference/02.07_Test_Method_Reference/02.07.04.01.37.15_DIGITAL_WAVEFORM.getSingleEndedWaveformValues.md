# DIGITAL_WAVEFORM.getSingleEndedWaveformValues()

This function returns the single-ended waveform data (min, max, mean or rms) retrieved in the previous execution.

## getSingleEndedWaveformValues()

```
void getSingleEndedWaveformValues(const STRING& pin,
                                  WAVEFORM_RESULT& result,
                                  BOOLEAN calc_rms_flag)
```

Parameters
 |

pin

 |

The pin to access the single-ended waveform.

 |
 |

result

 |

The captured single-ended waveform result data.

The definition of WAVEFORM_RESULT is:

struct WAVEFORM_RESULT

{

 DOUBLE min;

 DOUBLE max;

 DOUBLE mean;

 DOUBLE rms;

}

 |
 |

calc_rms_flag

 |

The flag indicates that the rms value will be calculated.

 |

## Functional changes

- Introduced before SmarTest 6.3.2
