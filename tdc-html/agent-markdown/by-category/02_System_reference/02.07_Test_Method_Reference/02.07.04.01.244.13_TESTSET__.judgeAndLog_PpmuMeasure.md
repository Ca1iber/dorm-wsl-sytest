# TESTSET().judgeAndLog_PpmuMeasure()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) performs a pass/fail judgment of a flexible DC test specified by a [PPMU_MEASURE](<02.07.04.01.157_PPMU_MEASURE.md>) constructor and logs the results.

Optional values for this function can be set by prior methods, for example, [port()](<02.07.04.01.244.19_TESTSET__.port.md>), [cont()](<02.07.04.01.244.03_TESTSET__.cont.md>), [reliability()](<02.07.04.01.244.20_TESTSET__.reliability.md>), or [testname()](<02.07.04.01.244.23_TESTSET__.testname.md>).

## Syntax

```
bool judgeAndLog_PpmuMeasure(const PPMU_MEASURE &ppmuMeas, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE);
```

 |

Parameter

 |

Description

 |
 |

ppmuMeas

 |

The [PPMU_MEASURE](<02.07.04.01.157_PPMU_MEASURE.md>) constructor specifies a flexible DC test to be judged.

 |
 |

logTestNumber

 |

An optional test number.

If this test number is provided, it overrides the actual test number. If it is not provided, the actual test number is logged.

   | Note Only the first six digits of values are ensured to be correctly logged into the STDF file.

## Return Value

The pass/fail result of the judgment is returned. It can be true for pass or false for fail.

## Example

```
PPMU_MEASURE ppmuMeasure;
ON_FIRST_INVOCATION_BEGIN();
  PPMU_SETTING ppmuSetting;
  PPMU_RELAY   ppmuRelayOn, acRelayOn;
  TASK_LIST    simpleFlexDc;
  ppmuSetting.pin("I/O1").vForce(0 V).iRange(1 uA).max(1 uA).min(-1 uA);
  ppmuSetting.pin("I/O2").iForce(1 uA).iRange(1 uA).max(0.5 V).min(1 V);
  ppmuRelayOn.pin("I/O1,I/O2").status("PPMU_ON");
  ppmuRelayOn.wait(1.3 ms);
  ppmuMeasure.pin("I/O1").execMode(TM::PPF);
  ppmuMeasure.pin("I/O2").execMode(TM::PVAL);
  acRelayOn.pin("I/O1,I/O2").status("AC_ON");
  simpleFlexDc.add(ppmuSetting).add(ppmuRelayOn).add(ppmuMeasure).add(acRelayOn);
  simpleFlexDc.execute();
ON_FIRST_INVOCATION_END();
TESTSET().judgeAndLog_PpmuMeasure(ppmuMeasure);
```
