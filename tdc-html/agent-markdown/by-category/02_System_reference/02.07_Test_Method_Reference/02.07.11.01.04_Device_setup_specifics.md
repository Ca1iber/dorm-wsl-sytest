# Device setup specifics

Transaction based protocol testing on V93000 requires some settings you need to consider when setting up or converting a device, like:

- only UTM is supported for test methods
- only UMM is supported for labels
- the device setup has to follow multi port guidelines
- model and/or license files need to be updated for memory size and pogo cabling
