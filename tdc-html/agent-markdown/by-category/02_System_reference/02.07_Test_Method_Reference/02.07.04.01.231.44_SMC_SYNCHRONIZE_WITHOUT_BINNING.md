# SMC_SYNCHRONIZE_WITHOUT_BINNING()

Waits for the end of the execution of all threads which have been started using [SMC_ARM()](<02.07.04.01.231.01_SMC_ARM.md>).

This API simply ensures that all background threads have completed all hidden uploads and execution in general.

SMC_SYNCHRONIZE_WITHOUT_BINNING() may be called inside or outside of the [ON_FIRST_INVOCATION](<02.07.04.01.138_ON_FIRST_INVOCATION_BEGIN.md>) block. The parameter syncAllSites has to be set accordingly.

To properly synchronize a test flow with the ["thread per site" or the "common thread"](<02.07.10.02.01_SmartCalc__Thread_per_site__and__Common_thread.md>) implementation and also a mixture of both, refer to [Synchronize a test flow with any use model](<02.07.10.05_SmartCalc_recommendations.md#_119876__s_Synchronize_a_test_flow_with_any_use_model>) in [SmartCalc recommendations](<02.07.10.05_SmartCalc_recommendations.md>).

## Syntax

```
Boolean SMC_SYNCHRONIZE_WITHOUT_BINNING(DOUBLE timeout = 0, Boolean syncAllSites=false);
```

  Parameters

 | Parameter  | Description |
 | timeout |

Time in seconds after which a thread should be canceled and SMC_SYNCHRONIZE() should not wait for its completion.

Resolution: 1 µs

The accuracy of this parameter is influenced by the overhead time of the operating system.

The default value is 0.0 seconds which means that no timeout is set.

 |
 | syncAllSites |

The optional parameter selects the sites to synchronize:

- false: Only the site in focus is synchronized.
- true: All active sites are synchronized.

Default value: Only the site in focus is synchronized.

   |   Return value Returns false in case threads had to be terminated or an invocation error occurred, else true is returned.

## Example

Waits for all calculations to be finished within 100 ms. After the timeout of 100 ms all other still running calculation threads will be terminated!

```
SMC_SYNCHRONIZE_WITHOUT_BINNING(100 ms);
```
