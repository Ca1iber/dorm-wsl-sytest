# CCTsetResultArea

This function sets the required area for hidden digital capture data upload or for dynamic (sequencer‑controlled) DC test data upload. It performs the similar functionality as [RESULT_AREA_CONFIG_SET](<02.07.04.01.190_RESULT_AREA_CONFIG_SET.md>).

This function is usually used in the `init()` function but not used in the other functions of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

 Note Result areas reduce the available memory and accessing a large number of them may impact your test times. Therefore, the total number of allocated result areas should be minimized and stay below 465 in total. That is, the sum of all TMU, digital, and DC result areas must not exceed 465. Out of this, 15 areas are reserved as minimum for TMU and a maximum of 100 areas can be allocated for TMU.

## Syntax

```
void CCTsetResultArea(const string& pinList, const int size, const RESULT_AREA_TYPE & resultType = DEFAULT)
```

Parameters
 |

pinList

 |

The list of pins to which the result area will be configured. The pins are separated with comma (,).

 |
 |

size

 |

Size of the result area in bytes.

 |
 |

resultType

 |

The SMC result area type. It can be:

DIG: The result area for digital capture.

DC: The result area for dynamic DC test.

DEFAULT: The type of the result area is set according to the type of the pin(s) specified for the pinList.

 |

## Example

Setup for digital capture data upload

```
CCTsetExecMode(EXM_EXECUTE_TEST);
CCTregisterDGT(dac_out);
CCTsetResultArea("ADC.DB0", 1024);
CCTenableSMC(SMC_AUTO);
```

Setup for dynamic DC test data upload

```
CCTsetExecMode(EXM_SYNC_DC);
CCTRegisterDCPins("dc_pin1,dc_pin2");
CCTsetResultArea("dc_pin2", 1024, DC);
CCTenableSMC(SMC_AUTO);
```
