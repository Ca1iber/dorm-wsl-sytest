# DVM_PIN_TASK.doAcal()

The doAcal() member function sets the automatic calibration (acal) mode for the DMM (digital multimeter).

If more than one DMM is used, the automatic calibration (ACAL) is done in parallel for all DMMs.

## Syntax

```
DVM_PIN_TASK & DVM_PIN_TASK::doAcal (const TM::DVM_MODE mode)
```

Parameter
 |

Parameter

 |

Description

 |
 |

mode

 |

The calibration mode. Use one of

- TM::DO_ACAL_IF_NECESSARY (default)
- TM::FORCE_ACAL
- TM::SKIP_ACAL
 |

## Return value

Returns a reference to the [DVM_PIN_TASK](<02.07.04.01.55.01_DVM_PIN_TASK.md>) object.
