# d2s writeDynamic

The d2s writeDynamic method allows to write different values to different sites.

These values will be modified right before execution of the burst. The modifications will be done by `VEC_LABEL_EDIT()`.

Note writeDynamic should only be used if the write values differ per site and/or are only available at runtime for example, based on a previous measurement/read action or an unique device id).

In learning mode a 'place holder' pattern will be created and added to the burst. This place holder pattern will be modified for each test method execution by `VEC_LABEL_EDIT()`.

In production mode only the place holder pattern within the burst will be modified.

Note This method has to be called from within a `FOR_EACH_SITE`-block.

## Syntax

```
void writeDynamic(long long address, long long data, std::string id);
```

## Example

The following excerpt illustrates how the writeDynamic method is used to write different values to different sites.

In learning mode it will generate a write placeholder label `MySiteValue` and add it to the burst label `MyBurstLabelName`.

In production mode the `MySiteValue ` pattern will be modified in the vector memory prior to execution at `d2s_LABEL_END()`.

```
virtual void run()
{
   int MAX_SITES = 2;
   int valuePerSite[MAX_SITES];
   valuePerSite[0] = 0xaffe;
   valuePerSite[1] = 0xbeaf;

   d2sFramework fr;
   d2sJTAG& jtag = d2sJTAG::Instance();

   // Register your protocol with the framework
   fr.registerTransactionPort(jtag);

   ON_FIRST_INVOCATION_BEGIN();
      fr.d2s_LABEL_BEGIN("MyBurstLabelName", d2sFrameWorkModeType::LearningMode);
         FOR_EACH_SITE_BEGIN();
            jtag.writeDynamic(0xdead, valuePerSite[CURRENT_SITE_NUMBER()-1], "MySiteValue");
         FOR_EACH_SITE_END();
      fr.d2s_LABEL_END();

      // do your measurement here

   ON_FIRST_INVOCATION_END();
   ...
}
```

The static write patterns created by the code above for a single port setup would be saved into the device vector directory as:

`d2s_jtag_AT_WD_MySiteValue`
