# EVENT_VALUE_INT

The EVENT_VALUE_INT helper class encapsulates the different handling of values, which may either be a fixed value, a spec, or an equation name. The class is not intended to retrieve the actual values from the equation system. It specifies the value source from where the final value will be retrieved at execution time.

All events support specs and equation variables defined in a level equation set. These variables can be addressed by the LEV: prefix (see example below), which refers to the current level equation set by the primaries.

See also the second value class [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>). The separation into two value classes enforces type safety at compile time.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

```
EVENT_VALUE_INT(const INT      value);
```


This constructs an object of the EVENT_VALUE_INT class.

 | Parameter  | Description |

 |

 |

## Member functions

### isExpression()

```
bool isExpression() const;
```

This member function returns whether the object represents an expression (TRUE) or a fixed value (FALSE).

### getExpresssion()

```
const STRING & getExpression() const;
```

This member function returns the expression. If the object represents a fixed value the expression string will be empty.

### getValue()

```
INT getValue() const;
```

This member function returns the value. If the object represents an expression, the returned value is 0. The expression is not resolved here!

## Example

Defines a fixed double value:

```
EVENT_VALUE_INT fixedValue(1);
```

Defines an equation variable reference:

```
EVENT_VALUE_INT eqnValue("LEV:frc1");
```
