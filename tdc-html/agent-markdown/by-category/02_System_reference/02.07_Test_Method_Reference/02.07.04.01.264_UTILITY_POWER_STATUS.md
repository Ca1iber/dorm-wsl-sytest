# UTILITY_POWER_STATUS

#### Subtopics

- [UTILITY_POWER_STATUS.state()](<02.07.04.01.264.01_UTILITY_POWER_STATUS.state.md>)
- [UTILITY_POWER_STATUS.checkState()](<02.07.04.01.264.02_UTILITY_POWER_STATUS.checkState.md>)

- [UTILITY_POWER_STATUS.execute()](<02.07.04.01.264.04_UTILITY_POWER_STATUS.execute.md>)

Switches a utility power supply on or off or queries the state of a utility power supply.

The utility power supplies that can be controlled or queried are the utility power supplies of the [optional Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>) or the [Internal utility power supplies](<../02.05_Test_Head_Cards/02.05.08.03.02_Internal_utility_power_supplies.md>).

The UTILITY_POWER_STATUS object can be added to a [TASK_LIST](<02.07.04.01.240_TASK_LIST.md>).

## Example

```
UTILITY_POWER_STATUS utilityPowerOn;

ON_FIRST_INVOCATION_BEGIN();

    if ( firstRun == true )
    {
        //
        // Switch the [Utility power supply - XP pins (V93000 EXA Scale systems)](<../02.03_DUT_board_design_reference/02.03.05.02_Utility_power_supply_-_XP_pins__V93000_EXA_Scale_systems.md>) of the first Utility Card on
        //
        utilityPowerOn.state(TM::POWER_ON);
        utilityPowerOn.wait(10 ms);
        utilityPowerOn.execute();

        firstRun = false;
    }

ON_FIRST_INVOCATION_END();
```
