# Test method snippets for ADC test

The following snippets are provided for ADC test. These test method snippets are included in the file /opt/hp93000/soc/segements/tml/testmethodSnipptets.xml.

They are listed in the alphabetical order.

- V93000_ADC_Distortion_SMCPostProcess

This snippet does the post processing for ADC distortion test with smartCalc. It uploads the captured data and calculates the THD, SNR, SND, H2 and H3 of the captured data with smartCalc. Then the calculated SNR and THD are compared with the limits in the test table and logged. The snippet can be used together with the snippet V93000_ADC_MeasurementSetup in the test method.

- V93000_ADC_FreqResp_SMCPostProcess

This snippet does the post processing for ADC frequency response test with smartCalc. It uploads the captured data and calculates the spectrum of the captured data with smartCalc and then analyzes the spectrum to calculate the frequency at -3db. The result is judged with the limit in the test table and logged. The snippet can be used together with the snippet V93000_ADC_MeasurementSetup in the test method.

- V93000_ADC_GainPhase_SMCPostProcess

This snippet does the post processing for ADC IQ gain and phase test. It uploads the captured data and calculates the gain and phase of I channel and Q channel with smartCalc. Then the gain errors of I channel, the gain error of Q channel, the gain imbalance between I and Q channel and the phase imbalance between I and Q channel are calculated, compared with the limits in test table and logged. The snippet can be used together with the snippet V93000_ADC_IQ_MeasurementSetup in the test method.

- V93000_ADC_IQ_MeasurementSetup

This snippet sets up and executes an ADC I/Q measurement. Then it kicks off the data uploading and result calculation with the smartCalc background post processing function. After that the settings of AWG are disabled and disconnected.

- V93000_ADC_LinearityRamp_SMCPostProcess

This snippet does the post processing for ADC linearity test using ramp wave with smartCalc. It retrieves the captured data and calculates the DLE, ILE and missing code with smartCalc. The calculated DLE, ILE and missing code are judged with the limits in test table and logged. The snippet can be used together with the snippet V93000_ADC_MeasurementSetup in the test method.

- V93000_ADC_LinearitySine_SMCPostProcess

This snippet does the post processing for ADC linearity test using sine wave with smartCalc. It retrieves the captured data and calculates the DLE, ILE and missing with smartCalc. The calculated DLE, ILE and missing code are judged with the limits in test table and logged. The snippet can be used together with the snippet V93000_ADC_MeasurementSetup in the test method.

- V93000_ADC_MeasurementSetup

This snippet sets up and executes an ADC test. Then it kicks off the data uploading and result calculation with the smartCalc background post processing function. After that the settings of AWG are disabled and disconnected.
