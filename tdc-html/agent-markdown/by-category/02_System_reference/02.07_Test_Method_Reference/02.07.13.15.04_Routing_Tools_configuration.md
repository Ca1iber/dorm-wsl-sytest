# Routing Tools configuration

The digital control pins for sequencer鈥慶ontrolled utility lines, the configuration of the PMUX cards and the digital control pins for the PMUX cards and the XML file, which holds the complete setup and state data of the Routing Tools editors, must be defined.

## Sequencer鈥慶ontrolled utility lines

The serial interface of [Sequencer-controlled utility lines](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01_Sequencer-controlled_utility_lines.md>) is to be connected to four digital pins. One set of four digital pins controls the serial interface of one single utility pogo block or up to eight utility pogo blocks if ["ganging" of utility blocks](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01.03_Ganging_utility_blocks.md>) is used.

Unlike shown in [SmartRDI: Utility lines control](<02.07.13.23_SmartRDI__Utility_lines_control.md>), the control pins for the sequencer controlled utility lines must be defined in the [Routing Tools - Utility Lines Control editor](<02.07.13.15.01.02_Routing_Tools_-_Utility_Lines_Control_editor.md>) if the Routing Tools are to be used.

## Routing Tools setup file

The Routing Tools setup file holds all configuration data for software controlled utility lines, sequencer鈥慶ontrolled utility lines and the MUX cards. The predefined switch states are also stored in this file. The file is created and stored by the [Routing Tools editors](<02.07.13.15.01_Routing_Tools_editors.md>).

The setup file to be loaded must be defined in the RDI_Configure file. For more information, refer to keyword [ROUTING_SETUP_FILE](<02.07.13.04_RDI_Configure_file.md#_146692__row_ROUTING_SETUP_FILE>) in topic [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>).

Function [rdi.route().downloadPmuxMemSet()](<02.07.13.15.05.02_rdi.route__.downloadPmuxMemSet.md>) must be called at least once in the test program flow. The function does not only download the PMUX switch states but also reads and processes the setup file.Note The function [rdi.route().downloadPmuxMemSet()](<02.07.13.15.05.02_rdi.route__.downloadPmuxMemSet.md>) must be called at least once in the test program flow even if only utility lines are controlled by the Routing Tools.
