# DSP_MUL_C

This API returns the product of two complex numbers.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_MUL_C(COMPLEX src1, COMPLEX src2,
          COMPLEX result);
```

## Example

```
COMPLEX impedance, imp1, imp2;
      :
DSP_MUL_C(imp1, imp2, impedance);
```

DSP_MUL_C multiplies the COMPLEX variables imp1 and imp2, and returns the results to the COMPLEX variable impedance as shown in the following:

```
COMPLEX impedance, imp1, imp2;
      :
impedance.real = imp1.real*imp2.real-imp1.imag*imp2.imag;
impedance.imag = imp1.imag*imp2.real+imp1.real*imp2.imag;
```
