# TIMING_OFFSET_SEARCH_PINS.start()

This function sets the start position for the timing offset search. It is a point in time, relative to the start of the edge.

The combination of the start value, the [number of search steps](<02.07.04.01.248.01.13_TIMING_OFFSET_SEARCH_PINS.numSteps.md>), and the [step width](<02.07.04.01.248.01.24_TIMING_OFFSET_SEARCH_PINS.stepWidth.md>) defines the range for the initial linear search.

## Syntax

```
TIMING_OFFSET_SEARCH_PINS& start(DOUBLE startval);
```

Parameter
 |

Parameter

 |

Description

 |
 |

startval

 |

The start position of the search, relative to the start of the edge.

The unit is seconds [s].

 |

## Return value

A reference to the [TIMING_OFFSET_SEARCH_PINS](<02.07.04.01.248.01_TIMING_OFFSET_SEARCH_PINS.md>) object.
