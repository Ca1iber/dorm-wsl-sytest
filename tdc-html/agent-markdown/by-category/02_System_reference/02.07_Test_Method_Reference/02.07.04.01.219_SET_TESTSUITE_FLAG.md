# SET_TESTSUITE_FLAG

This API sets the specified testsuite flag to a particular value.

 Note Change of any flag state will be valid when the next testsuite is executed. Use this API with this point in mind.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

## Syntax

```
SET_TESTSUITE_FLAG(const STRING& tsname, const STRING& flag, INT value);
```

Parameters
 |

I/O

 |

Parameter

 |

Description / Range

 |
 |

I

 |

tsname

 |

A testsuite name

 |
 |

I

 |

flag

 |

A testsuite flag name. For more details, see [GET_TESTSUITE_FLAG](<02.07.04.01.100_GET_TESTSUITE_FLAG.md>).

 |
 |

I

 |

value

 |

An integer value for the specified flag.

   | Note There are several read-only flags which cannot be set using the SET_TESTSUITE_FLAG API. For more information refer to [GET_TESTSUITE_FLAG](<02.07.04.01.100_GET_TESTSUITE_FLAG.md>).

## Example

```
SET_TESTSUITE_FLAG("SampleTest", "set_pass", 1);
```

The SET_TESTSUITE_FLAG API sets the set_pass flag of the SampleTest testsuite to 1 ("on").
