## Examples

### Generic example

The demodulation engine is continually updated as new modulation types emerge. It is good practice to ensure that the application you are writing checks the version of the demodulation library before actual calculations are performed. This will ensure that the application works at multiple manufacturing sites. If you need to find out the version of the library in use, the following code phrase will let you know.

```
STRING demodLibVersion = "";
DEMODULATION::getVersion(demodLibVersion);
cout << "The Demod Library Version is " << demodLibVersion << endl;
```

The following are other valid return variables from getVersion

```
int release majorVer, minorVer, patchVer;
DEMODULATION::getVersion (release, majorVer, minorVer, patchVer);
cout << "rev = " << release << endl;
cout << "major = " << majorVer << endl;
cout << "minor = " << minorVer << endl;
cout << "patch = " << patchVer << endl;
```

### Parameter File Format

```
INPUT, ofdmSymbolTimeAdjust, Float, 10.0
RESULT, ofdmBurstSearchStart, Int, 23754
```

The format for this file is:

 `<INPUT/RESULT>, <parameterName>, <parameterType>, <value>`

 |

INPUT,RESULT

 |

Denotes if it is an INPUT or RESULT parameter

 |
 |

parameterName

 |

Name of the input parameter. This string is case-sensitive

 |
 |

parameterType

 |

The type associated with the parameter

 |
 |

value

 |

The value of the parameter
