# SetUtilityLines

This test method sets a maximum of 512 utility lines.

 Note It is only available for universal test method.

You can also change the status of the utility line using the Utility Line view write mode of 93000 Hardware perspective.

Note When using this test method, the primary sets specified in this test suite are not used. The primary sets of the previously executed test suite are used.

## Parameters

 |

Parameter

 |

Type

 |

Description

 |
 | type  | STRING |

The type of the utility line. It can be:

-

UtilitylineName: The utility line name defined in the [Pin setting editors](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01_Pin_setting_editors.md>).

 The utility lines to be set to on or to off can be defined by parameters

  - utilityLineNameOn,
  - utilityLineNameOff, or
  - utilityPurpose.

All three parameters can be filled with data at the same time.

-

UtilitylineChannel: Utility lines are defined by the channel number.

 The utility channels to be set to on or to off can be defined by parameters

  - utilityLineChannelOn or
  - utilityLineChannelOff.

Both parameters can be filled with data at the same time.

 |

A single utility pin or a comma鈥憇eparated list of utility pins to be set to on or to off.

Valid names are defined in the [Utility Pins editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.04_Utility_Pins_editor.md>).

 |
 | utilityLineNameOff |
 | utilityPurpose  | STRING |

Valid names are defined in the [Pin setting editors](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01_Pin_setting_editors.md>) and configured in the [Utility Purpose Editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.05_Utility_Purpose_Editor.md>).

 |
 | utilityLineChannelOn  | STRING |

A single utility channel or a comma鈥憇eparated list of utility channels to be set to on or to off.

The utility channels are to be defined like `UTI101`, `UTI102`.

The format using three digits for the pogo blocks is also supported. For this format, the utility pins are to be defined as `UTI16501` or `UTI16502`, for example.

For the second optional [Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>) of EXA Scale systems, the utility pins can be defined only using the three鈥慸igit format of the pogo blocks. The valid range for the second card is `UTI26501` ... `UTI27232`.

Default value is 0.0.
