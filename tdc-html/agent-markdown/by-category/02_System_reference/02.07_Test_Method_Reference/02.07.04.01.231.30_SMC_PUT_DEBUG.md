# SMC_PUT_DEBUG()

Passes the specified array to the signal analyzer if the debug_analog testflow flag is on.

Two array parameters ( xseries and yseries) can be passed to the signal analyzer to put different data to the x and y axis.

Use this API inside your `SMC_backgroundProcessing()` method, because [PUT_DEBUG](<02.07.04.01.175_PUT_DEBUG.md>) is not thread safe.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```

void SMC_PUT_DEBUG(const STRING& pin, const STRING& label, const ARRAY_D& waveform);
void SMC_PUT_DEBUG(const STRING &pin, const STRING& label, const WAVE_LOG& waveform);
void SMC_PUT_DEBUG(const STRING& pin, const STRING& label, const ARRAY_I& xseries,
              const ARRAY_I& yseries);
void SMC_PUT_DEBUG(const STRING& pin, const STRING& label, const ARRAY_I& xseries,
              const ARRAY_I& yseries, const ARRAY_I& colors);
void SMC_PUT_DEBUG(const STRING& pin, const STRING& label, const ARRAY_D& xseries,
              const ARRAY_D& yseries);
void SMC_PUT_DEBUG(const STRING& pin, const STRING& label, const ARRAY_D& xseries,
              const ARRAY_D& yseries, const ARRAY_I& colors);
void SMC_PUT_DEBUG(const STRING& pin, const STRING& label, DEMODULATION& demod,
              const TM::GRAPH_SELECTION graphSelect);
void SMC_PUT_DEBUG(const STRING& pin, const STRING& label, const Wave<INT>& waveform);
void SMC_PUT_DEBUG(const STRING& pin, const STRING& label, const Wave<FLOAT>& waveform);
void SMC_PUT_DEBUG(const STRING& pin, const STRING& label, const Wave<DOUBLE>& waveform);
void SMC_PUT_DEBUG(const STRING& pin, const STRING& label, const Wave<COMPLEX>& waveform);
void SMC_PUT_DEBUG(const MEAS_DEF_I& def, const STRING& label, const Wave<INT>& waveform);
void SMC_PUT_DEBUG(const MEAS_DEF_I& def, const STRING& label, const Wave<FLOAT>& waveform);
void SMC_PUT_DEBUG(const MEAS_DEF_I& def, const STRING& label, const Wave<DOUBLE>& waveform);
void SMC_PUT_DEBUG(const MEAS_DEF_I& def, const STRING& label, const Wave<COMPLEX>& waveform);
```

## Example

Here `SMC_PUT_DEBUG()` passes the wave_array data to the signal analyzer. The Aout and AnaWave are used to specify the data in the signal analyzer.

```
ARRAY_D wave_array;
SMC_PUT_DEBUG("Aout", "AnaWave", wave_array);
```

In this example `SMC_PUT_DEBUG()` passes the x and y axis arrays x_array and y_array to the signal analyzer. The Aout name and frequ_domain are used to specify the data in the signal analyzer.

```
ARRAY_D x_array, y_array
SMC_PUT_DEBUG("Aout", "frequ_domain", x_array, y_array);
```
