# How to import the CCF files in an existing project

## About this task

This is not needed when creating a new concurrent test method. When you already have the concurrent test method from previous implementation and need to import the concurrent test framework files, follow the procedure below.

The source files are stored in the file /opt/hp93000/soc/testmethod/library/ccf_tml.zip.

## Procedure

-  Unzip the file ccf_tml.zip.
-  Import the CCF related files to your test method project

  -  Right-click the test method project and select Import.
  -  In the Import wizard, select General > File System and click Next.
  -  Select the directory where the files are located with Browse button.
  -  Select the subfolders and click Finish.  ![Import the ccf_tml files](<../../../../raw/122471.png>)

-  Include the CCF header files to your project.

  -  Right-click the test method project and select Properties.
  -  In the Properties dialog, select C/C++ General > Paths and symbols > Includes.
  -  Click Add.  ![Include the CCF header files](<../../../../raw/123743.png>)
  -  In the Add directory path dialog, click Workspace.
  -  Select the <current_project>/ccf_include folder from the pop-up window and click OK.
  -  Check all the three boxes in the Add directory path dialog and click OK.  ![Add directory path](<../../../../raw/124409.png>)

-  Copy the file ccf_tml/ccf_lib/libccf_core.so into the directory $device/testmethod/sh_lib-EL7-64bit/preload. If the preload directory does not exist, create it manually.
-  Build the test method project. If any errors occurred, correct the errors and rebuild it until no error occurs.
