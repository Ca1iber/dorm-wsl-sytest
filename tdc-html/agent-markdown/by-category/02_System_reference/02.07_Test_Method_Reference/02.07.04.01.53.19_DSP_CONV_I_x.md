# DSP_CONV_I_x

These APIs are for converting an integer array to the specified array.

The DSP_CONV_I_C API returns the results to the real part of result, and fills the imaginary part with zeros.

DSP_CONV_I_I or _D:

```
  result[i] = factor * src[i] + offset
```

DSP_CONV_I_C:

```
  result[i].real = factor * src[i] + offset
  result[i].imag = 0
```

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_CONV_I_C(ARRAY_I& src, ARRAY_COMPLEX& result,
             DOUBLE factor, DOUBLE offset );
DSP_CONV_I_C(INT *src, COMPLEX *result,
             INT size, DOUBLE factor,
             DOUBLE offset);

DSP_CONV_I_I(ARRAY_I& src, ARRAY_I& result,
             DOUBLE factor, DOUBLE offset );
DSP_CONV_I_I(INT *src, INT *result, INT size,
             DOUBLE factor, DOUBLE offset );

DSP_CONV_I_D(ARRAY_I& src, ARRAY_D& result,
             DOUBLE factor, DOUBLE offset );
DSP_CONV_I_D(INT *src, DOUBLE *result, INT size,
             DOUBLE factor, DOUBLE offset );
```

## Example

```
ARRAY_I array1(512);
ARRAY_D array2(512);
DSP_CONV_I_D(array1, array2, 10.0, -0.1);
```

DSP_CONV_I_D converts the 512 elements of array1 from INT type to DOUBLE type, then multiplies each element by 10.0 and adds -0.1, and returns the results to double array array2.

```
ARRAY_I array1(256);
ARRAY_COMPLEX array2(256);
DOUBLE offset, gain;
gain = 98.0;
offset = 2.0;
DSP_CONV_I_C(array1, array2, gain, offset);
```

DSP_CONV_I_C returns the results to the real part of ARRAY_COMPLEX array array2, and fills the imaginary part with zeros.
