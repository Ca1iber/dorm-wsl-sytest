# EVENT_RANGE_RESTORE.getRangeType

This member function queries the range type (voltage or current) to be restored.

## Syntax

```
EVENT_RANGE_RESTORE & getRangeType (TM::RANGE_RESTORE_TYPE & value) const;
```

Parameter
 | Parameter  | Description |
 |

value

 |

Possible values are:

- RANGE_RESTORE_VOLTAGE
- RANGE_RESTORE_CURRENT
 |

## Return value

Returns the RANGE_RESTORE_TYPE as reference "value".

## Example

```
TM::RANGE_RESTORE_TYPE type;
eventRangeRestore.getRangeType(type);
switch ( type )
{
  case TM::RANGE_RESTORE_VOLTAGE:
    cout << "Range restore type is voltage" << endl;
    break;
  case TM::RANGE_RESTORE_CURRENT:
    cout << "Range restore type is current" << endl;
    break;
default:
    break;
};
```
