# Testflow flags of SmartRDI

SmartRDI provides some flags that can be used in testflows to control correspondent setups.

Testflow flags of SmartRDI
 | No.  | Flag  | Purpose |
 | 1  | [RDI_CONFIGURE_FILE](<02.07.13.04_RDI_Configure_file.md#_146692__RDI_CONFIGURE_FILE>)   | Select a customized [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>) for a testflow. |
 | 2  | [RDI_BURST_POSTFIX](<02.07.13.08.10.02_RDI_BURST_POSTFIX.md>)  | Specify a name to be appended to the names of all SmartRDI-generated burst patterns in the testflow.

The purpose of this option is to differentiate burst pattern generations from different testflows in which test suite names can be the same one.

When BURST_NAME_MD5 = TRUE is set, an MD5 postfix is used to differentiate patterns and the RDI_BURST_POSTFIX option is no longer required.

This keyword is also described by [Postfix in burst pattern names](<02.07.13.08.10_Postfix_in_burst_pattern_names.md>) as a testflow variable.

 |
 | 3  | RDI_DISABLE_WARNING |

Specify TRUE or FALSE to hide or show warnings from SmartRDI.

This flag is an optional variable flag and can be defined as Userflag on the [Variables page](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.01.05_Variables_page.md>) of [Flow Data Editor](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.01_Flow_Data_Editor.md>).

  Note If this flag is set to true, all SmartRDI warnings are hidden and not displayed in the UI report window. Therefore using it during code development and debugging phases may cause you to overlook errors in SmartRDI code. Use it as necessary.

See also [SmartRDI warning handling](<02.07.13.08.16_SmartRDI_warning_handling.md>).

 |
 | 4  | [RDI_INFO_LEVEL](<02.07.13.06_RDI_INFO_LEVEL.md>)  | Control the level of SmartRDI related information that is shown in the SmarTest UI report window. |
 | 5  | [RDI_ORE_FILE](<02.07.13.08.20_Using_Offline_Result_Emulation_in_SmartRDI.md#_343520__testflow_variable>)  | Specify an ORE file for each execution.  |
