# TESTSET().testtext_none()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) stores no test text for the current test in the EDL.

## Syntax

```
TESTSET & testtext_none();
```

## Example

```
TestSet.testtext_none();
```
