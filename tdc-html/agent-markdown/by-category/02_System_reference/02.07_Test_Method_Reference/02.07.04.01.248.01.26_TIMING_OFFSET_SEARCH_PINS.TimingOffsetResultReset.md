# TIMING_OFFSET_SEARCH_PINS.TimingOffsetResultReset()

This function resets the offset of the specified timing set to its default value.

## Syntax

```
void TimingOffsetResultReset(TIMING_OFFSET_SEARCH::TimingSetSelector& target);
```

Parameter
 |

target

 |

The timing set to reset.

 |

## Functional changes

- Introduced in SmarTest 7.0.1
