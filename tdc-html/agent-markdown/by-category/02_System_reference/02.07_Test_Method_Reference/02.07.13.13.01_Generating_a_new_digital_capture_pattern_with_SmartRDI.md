# Generating a new digital capture pattern with SmartRDI

You can generate a new digital capture pattern with the functions provided by SmartRDI.

## Procedure

- Create a digital capture test with the class `digCap()`.
- Specify the pins to do digital capture with the function [pin()](<02.07.13.13.14_pin.md>).
- Specify the number of samples to capture with the function [samples()](<02.07.13.13.15_samples.md>).
- (optional) Specify the number of initial discards, inter discards and bit per word with the corresponding functions if needed.

See [bitPerWord()](<02.07.13.13.05_bitPerWord.md>), [initDiscard()](<02.07.13.13.11_initDiscard.md>), and [interSkip()](<02.07.13.13.12_interSkip.md>).

- Execute the setups with the function [execute()](<02.07.13.08.01.02_execute.md>).

## Results

The code to generate a new pattern to do the digital capture is created.

  Note For X-mode, keep the number specified in initDiscard(), interSkip() and samples() to be multiple of the X-mode number.

## Examples

### Digital capture without hidden upload

```
ON_FIRST_INVOCATION_BEGIN();
  RDI_BEGIN();
    rdi.digCap("cap").pin("DO").samples(100).initDiscard(10).interSkip(1,2).execute();
  RDI_END( );
ON_FIRST_INVOCATION_END();
const  ARRAY_I& aiData = rdi.id("cap").getVector("DO");
```

### Digital capture with hidden upload

```
run()
{
  ON_FIRST_INVOCATION_BEGIN();
    rdi.hiddenUpload(TA::DIGCAP);
    RDI_BEGIN();
      rdi.digCap("id2").pin("A").samples(1024).execute();
    RDI_END();
  ON_FIRST_INVOCATION_END();
  SMC_ARM();
}
...
public:
void SMC_backgroundProcessing()
{
  ARRAY_I bits = rdi.id("id2").getVectorBit();
}
```
