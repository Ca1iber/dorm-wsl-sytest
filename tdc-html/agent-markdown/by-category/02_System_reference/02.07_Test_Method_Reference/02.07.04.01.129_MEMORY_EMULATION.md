# MEMORY_EMULATION

The MEMORY_EMULATION class provides objects that control setup, execution, and result processing of a memory emulation. Note that the setup focus for sites is ignored, that is, all sites will be set up the same way.

A memory emulation is always in one of three states: OFF, ENABLED, or ACTIVE. Roughly, the ENABLED state is intended for setup and result processing, and ACTIVE for execution. In the ENABLED or ACTIVE state, the pins of the memory emulation port cannot be used for standard/normal tests. In the ACTIVE state, ERAM and XRAM can be accessed only by the DUT.

### enable()

```
void enable();
```

This member function sets the memory emulation to the ENABLED state. In this state, you can configure the emulation, and analyze the result after completion of the test. Setting the emulation to ENABLED will also have the effect that the required FPGA image is loaded. The function has no parameters.

### flush()

```
void flush();
```

This function loads all relevant setup data to the hardware. This includes initialzation of the ERAM by the memory image specified as the ERAM content by setStartConfiguration(). Note that flush() is internally called by the start() function.

### disable()

```
void disable();
```

This member function sets the memory emulation into the OFF state. This means that the pins of the memory emulation port can be used for standard/normal tests again. The function has no parameters.

### start()

```
void start();
```

This member function sets the state of the emulation object to ACTIVE. If a timing adjustment has been required (adjustTiming parameter of setStartConfiguration()) this adjustment will be executed before the actual emulation test. If a logic trace has been required (startTrace parameter of setStartConfiguration()), it will be started after completion of the timing adjustment at the earliest, but you can define an additional delay.

### setAdjustmentParameters()

```
void setAdjustmentParameters(DOUBLE timeout, DOUBLE maxCompletionTime, INT numberOfSamples, Boolean measureDqsOnly);
```

This member function defines the parameters for the timing adjustment.

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

timeout

 |

If not all required samples (numberOfSamples parameter) have been captured within the time specified by this parameter, the emulation can be stopped with the waitAdjustmentDone() member function, and then the state of the MEMORY_EMULATION object will be reset to ENABLED. The unit is seconds, the default is 1s, which is also the maximum.

Note that the specified timeout will only be effective if waitAdjustmentDone() is called.

 |
 |

I

 |

maxCompletionTime

 |

This parameter defines the time span that is to be used for completion of the timing adjustment, starting from the first sample. Aftter that, the emulation proper will be started.

If only DQS pins are to be adjusted (measureDqsOnly set to TRUE), the specified value should not be smaller than 200 μs. If DQ pins are also adjusted (measureDqsOnly set to FALSE), the specified value should not be smaller than 300 μs. The unit is seconds, the default is 0.0002 s.

If the timing adjustment has not been completed within this time, the memory emulation proper will start anyway, but an error will be generated.

 |
 |

I

 |

numberOfSamples

 |

The number of samples to be captured for the timing adjustment. The default is 5.

 |
 |

I

 |

measureDqsOnly

 |

If this parameter is set to TRUE, only DQS pins will be adjusted. If it is set to FALSE, DQ pins will also be adjusted. The default is TRUE.

 |

### waitAdjustmentDone()

```
void waitAdjustmentDone();
```

This member function checks if the timing adjustment is completed within the time specified by the timeout parameter of the setAdjustmentParameters() member function. If it is not, memory emulation will be stopped, and the state of the MEMORY_EMULATION object reset to ENABLED. This function has no parameters.

### getError()

```
INT getError(INT siteNumber = -1);
Boolean getError(ARRAY_I &siteError);
```

This member function provides error information either for a single site, or for all active sites. In the latter case it will return TRUE, if at least one site produced an error. The integer(s) it returns must be converted into binary format for interpretation. The bits of the binary number are mapped to error types as follows:

 |

Bit

 |

Error description

 |
 |

0

 |

No sample has been detected by the timing adjustment within the time span specfied by the timeout parameter of setAdjustmentParameters().

 |
 |

1

 |

The timing adjustment (after capturing the first sample) was not finished within the time specified by the maxCompletionTime parameter of setAdjustmentParameters().

 |
 |

2

 |

The maximum deviation of any sample from the average sample value exceeds 1000000 ps.

 |
 |

3

 |

The number of read accesses to the first sequential memory exceeds the size (in bursts) of this sequential memory.

 |
 |

4

 |

The number of read accesses to the second sequential memory exceeds the size (in bursts) of this sequential memory.

 |
 |

25

 |

The FPGA image has been changed while the memory emulation was in either the ENABLED or the ACTIVE state.

 |
 |

26

 |

A memory image (content block) used by the memory emulation was deleted while the memory emulation was in the ACTIVE state.

 |
 |

27

 |

The master clock was turned off while the memory emulation was in the ACTIVE state.

 |

### compareWithERAM()

```
Boolean compareWithERAM(const STRING& memoryImageName, INT &firstMismatch, INT &lastMismatch, INT& numberOfMismatches);
Boolean compareWithERAM(const STRING& memoryImageName, INT eramOffset, INT eramWords, INT &firstMismatch, INT &lastMismatch, INT& numberOfMismatches);
Boolean compareWithERAM(const STRING& memoryImageName, INT eramOffset, INT eramWords, INT &firstMismatch, INT &lastMismatch, INT& numberOfMismatches, ERAM_COMPARE_MASK maskMode = NO_MASK, int wordMask = 0);
```

This function compares the complete actual ERAM content or part of it with a memory image that represents the expected state. It can only be called after completion of the test (in ENABLED state). It is possible to mask selected bits so that they will not be considered for the outcome of the comparison.

The function will return TRUE if no mismatch was found. It will also specify the segment in which the errors occur, and the total numbers of mismatches. The segment can be uploaded from ERAM into a memory image with the uploadEramContent() function for more detailed analysis.

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

memoryImageName

 |

The name of the memory image that is to be compared with the actual ERAM content.

 |
 |

I

 |

eramOffset

 |

The first 32-bit ERAM word that is to be compared

 |
 |

I

 |

eramWords

 |

The number of 32-bit ERAM words that are to be compared

 |
 |

O

 |

firstMismatch

 |

The first ERAM word that does not match the corresponding word of the specified memory image.

 |
 |

O

 |

lastMismatch

 |

The last ERAM word that does not match the corresponding word of the specified memory image.

 |
 |

O

 |

numberOfMismatches

 |

The number of mismatches in the compared part of ERAM.

 |
 |

I

 |

maskMode

 |

With this parameter, you can mask bits of an ERAM word so that they will not contribute to the PASS/FAIL result for this word. Possible values are:

 |
 |

 |

 |

NO_MASK

 |

No bit will be masked. This is the default.

 |
 |

 |

 |

WORD_MASK

 |

The same mask will be applied to all compared words. In this case you must specify the mask with the wordMask parameter. The bits of the value words that correspond to a set bit of the mask will be ignored for the PASS/FAIL result.

 |
 |

 |

 |

IMAGE_MASK

 |

An individual mask is specified for every expected value word. This word specific mask is defined in the same memory image that also supplies the expected values. This image must in this case have twice the size of the ERAM segment to be compared. The words with an even address (starting from 0) contain the expected values. The words with an odd address contain the mask for the preceding expected value word. The bits of the value word that correspond to a set bit of the mask will be ignored for the PASS/FAIL result.

 |
 |

I

 |

wordMask

 |

This parameter specifies the mask for the WORD_MASK mask mode. The default is 0, which means that no bit will be masked.

### getDramAddressMapper()

```
DRAM_ADDRESS_MAPPER& getDramAddressMapper(void);
```

This function creates a DRAM address mapper object. The mapper already contains a mapping of all DRAM rows. This default mapping assigns the first 32 rows of a DRAM bank to the first 32 rows of the corresponding ERAM bank, and all other DRAM addresses to fixed data, which is set to 0 by default. You can modify the default mapping with the member functions of the DRAM_ADDRESS_MAPPER object.

The fixed data can be modified with the setFixDataMemoryContent() function of MEMORY_EMULATION. The function has no parameters.
