# CCTgetTestsuiteName

This function returns the test suite name where this API is used. In concurrent test mode, the [GET_TESTSUITE_NAME](<02.07.04.01.101_GET_TESTSUITE_NAME.md>) API will always return the CCF execution test suite name of a CCF block.

This function is usually used in the `preStart()`, `postStart()`, `process()` and `cleanup()` function but not used in the `init()` function of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
string CCTgetTestsuiteName();
```

## Example

```
string tsName=CCTgetTestsuiteName();
cout << "INFO: testsuite name: " << tsName << endl;
```
