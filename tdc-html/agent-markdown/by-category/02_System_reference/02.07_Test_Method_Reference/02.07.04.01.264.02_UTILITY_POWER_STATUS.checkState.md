# UTILITY_POWER_STATUS.checkState()

Retrieves the current state of a utility power supply.

## Syntax

```
TM::UTILITY_POWER_STATE checkState() const;
TM::UTILITY_POWER_STATE checkState(TM::UTILITY_BOARD_POWER_SUPPLY supplyId, int resourceId) const;
```

The first syntax queries the state of the [Utility power supply - XP pins (V93000 EXA Scale systems)](<../02.03_DUT_board_design_reference/02.03.05.02_Utility_power_supply_-_XP_pins__V93000_EXA_Scale_systems.md>) of the first [optional Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>). The second syntax queries the state of the other utility power supplies of the first Utility Card, all utility power supplies of the second Utility Card, or the [Internal utility power supplies](<../02.05_Test_Head_Cards/02.05.08.03.02_Internal_utility_power_supplies.md>).

 Parameters

 | Parameter  | Description |
 | supplyId |

The parameter of type TM::UTILITY_BOARD_POWER_SUPPLY defines the utility power supply to be queried.

Available options of the parameter:

- TM::UP5V: The [+5 V supply on UP5V pins](<../02.03_DUT_board_design_reference/02.03.05.01_Utility_power_supply_-_UP5V_pins__V93000_EXA_Scale_systems.md>) of the optional Utility Card or the internal utility resources.
- TM::XPP5V: The [+5 V supply on XPP5V pins](<../02.03_DUT_board_design_reference/02.03.05.02_Utility_power_supply_-_XP_pins__V93000_EXA_Scale_systems.md>) of the optional Utility Card.
- TM::XPM5V: The [-5 V supply on XPM5V pins](<../02.03_DUT_board_design_reference/02.03.05.02_Utility_power_supply_-_XP_pins__V93000_EXA_Scale_systems.md>) of the optional Utility Card.
- TM::XPP3V3: The [+3.3 V supply on XPP3V3 pins](<../02.03_DUT_board_design_reference/02.03.05.02_Utility_power_supply_-_XP_pins__V93000_EXA_Scale_systems.md>) of the optional Utility Card.
- TM::P15V: The [+15 V supply on UPP15V pins](<../02.03_DUT_board_design_reference/02.03.05.03_Utility_power_supply_-_UPP15V___UPM15V___F24V_pins__V93000_EXA_Scale_sys.md>) of the optional Utility Card.
- TM::M15V: The [-15 V supply on UPM15V pins](<../02.03_DUT_board_design_reference/02.03.05.03_Utility_power_supply_-_UPP15V___UPM15V___F24V_pins__V93000_EXA_Scale_sys.md>) of the optional Utility Card.
- TM::F24VA: The [floating 24 V supply on F24VA pins](<../02.03_DUT_board_design_reference/02.03.05.03_Utility_power_supply_-_UPP15V___UPM15V___F24V_pins__V93000_EXA_Scale_sys.md>) of the optional Utility Card.
- TM::F24VB: The [floating 24 V supply on F24VB pins](<../02.03_DUT_board_design_reference/02.03.05.03_Utility_power_supply_-_UPP15V___UPM15V___F24V_pins__V93000_EXA_Scale_sys.md>) of the optional Utility Card.
- TM::UDPS: The [Internal Utility Power Option](<../02.03_DUT_board_design_reference/02.03.05.04_Internal_Utility_Power_Option__V93000_EXA_Scale_systems.md>) of the internal utility resources that replaces the legacy [SE-UDPS](<../02.03_DUT_board_design_reference/02.03.05.07_Internal_Utility_Power_Supply__SE-UDPS___V93000_systems.md>).
 |
 | resourceId |

The integer parameter defines the utility power resource to be queried.

Available options of the parameter:

- 1: First [optional Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>) or the [Internal utility power supplies](<../02.05_Test_Head_Cards/02.05.08.03.02_Internal_utility_power_supplies.md>) of the first card cage.
- 2: Second [optional Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>) or the [Internal utility power supplies](<../02.05_Test_Head_Cards/02.05.08.03.02_Internal_utility_power_supplies.md>) of the second card cage.
   |  Some hints and restrictions for setting the supplyId and resourceID parameters:

- For compatibility with the [Internal utility power supply (V93000 systems)](<../02.03_DUT_board_design_reference/02.03.05.05_Internal_utility_power_supply__V93000_systems.md>), the TM::UP5V supply of the first Utility Card or the internal TM::UP5V supply of the first card cage is always switched on.
- For compatibility with PinScale and SmartScale systems, the [Utility power supply - XP pins (V93000 EXA Scale systems)](<../02.03_DUT_board_design_reference/02.03.05.02_Utility_power_supply_-_XP_pins__V93000_EXA_Scale_systems.md>) of the first [optional Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>) can be queried only using the first syntax `TM::UTILITY_POWER_STATE checkState() const;` without the additional parameters defined. The supplyId parameter set to TM::XPP5V, TM::XPM5V, or TM::XPP3V3 in combination with the resourceID parameter set to 1 is not supported.
- Independently querying the TM::XPP5V, TM::XPM5V, or TM::XPP3V3 supply is supported only for the second Utility Card with resourceID parameter set to 2.
- The supplyId parameter set to UDPS is supported only in combination with the resourceID parameter set to 1: Since, the second [optional Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>) occupies all (legacy) DPS pogo blocks, the [Internal Utility Power Option](<../02.03_DUT_board_design_reference/02.03.05.04_Internal_Utility_Power_Option__V93000_EXA_Scale_systems.md>) cannot be used if a second Utility Card is installed.
  Return value The state of the utility power supply is returned as enum of type TM::UTILITY_POWER_STATE. It can be:

- TM::UTIL_POWER_STATE_OFF: The utility power supply is switched off.
- TM::UTIL_POWER_STATE_ON: The utility power supply is switched on.
- TM::UTIL_POWER_STATE_OFF_TRIP: The utility power supply was shut down automatically because the load-board was undocked or an overcurrent happened.
 For more information, refer to [Utility power supplies](<../02.03_DUT_board_design_reference/02.03.05_Utility_power_supplies.md>). For a description of the "power good signal", refer to the description of the "XDCGD" pin in [Pogo pin assignment - Utility pogo blocks](<../02.03_DUT_board_design_reference/02.03.06.08_Pogo_pin_assignment_-_Utility_pogo_blocks.md>).

## Example

### Example: Retrieving the state of the External utility power supply

```
UTILITY_POWER_STATUS    utilityPowerEnum;
vector<STRING>          utilityPowerString;

utilityPowerString.push_back("UTIL_POWER_STATE_OFF");
utilityPowerString.push_back("UTIL_POWER_STATE_ON");
utilityPowerString.push_back("UTIL_POWER_STATE_OFF_TRIP");
utilityPowerString.push_back("UTIL_POWER_STATE_ON_TRIP");

ON_FIRST_INVOCATION_BEGIN();
{
    cout << endl;

    utilityPowerEnum.state(TM::POWER_ON);
    utilityPowerEnum.wait(10 ms);
    utilityPowerEnum.execute();

    cout << "Utility power switched on, state = " << utilityPowerString.at(utilityPowerEnum.checkState()) << endl;

    WAIT_TIME (1.0);

    utilityPowerEnum.state(TM::POWER_OFF);
    utilityPowerEnum.wait(10 ms);
    utilityPowerEnum.execute();

    cout << "Utility power switched off,state = " << utilityPowerString.at(utilityPowerEnum.checkState()) << endl;
    cout << endl;
}
ON_FIRST_INVOCATION_END();
```

  The code above results in the following output in the ui_report window if the DUT board is docked and the "power good signal" indicates that all voltages are settled:

```
Utility power switched on,  state = UTIL_POWER_STATE_ON
Utility power switched off, state = UTIL_POWER_STATE_OFF
```
