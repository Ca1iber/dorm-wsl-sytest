# rdi.id().getMultiValue()

Retrieves all the values measured on the specified pins.

You can use it to retrieve the values from an ID within an execute(). It can be used for both [insertVec()](<02.07.13.12.02.21_insertVec.md>) and [insertSub()](<02.07.13.12.02.20_insertSub.md>) to retrieve the measured values.

The getMultiValue() function can be used to

- get all DC results of one .execute() used in conjunction with insertVec() or insertSub().
- get all DC results of one .execute() used in conjunction with sublabel() + insertVec() according to the size defined by the user with resultSize().

In case of a match failure that prevents the following measurements from executing, getMultiValue() does not resize the result array dependent on the non-executed measurements.

It cannot return the DC results of a pin of a whole burst.

## Syntax

```
ARRAY_D& getMultiValue(const string& pin);
ARRAY_D& getMultiValue();
```

List of parameters
 |

Parameter

 |

Description

 |
 |

pin

 |

The pins whose measured values to be retrieved.

If no pin is specified, all the pins will be used by default.

 |

## Return value

Returns an array holding the measured values.

## Example

Retrieving the measured current values from pinA.

```
RDI_BEGIN();
  ...
  rdi.dc("meas").label("abc").insertSub(10).pin("pinA").vForce(0).iMeas().measWait(0.1 ms)
                             .insertSub(20).pin("pinB").vForce(1 V)
                                           .pin("pinC").vForce(2 V)
                             .insertSub(30).pin("pinA").vForce(0).iMeas().measWait(0.2 ms)
                                           .execute();
  ...
RDI_END();
ARRAY_D results = rdi.id("meas").getMultiValue("pinA");
```

Retrieving the measured voltages from pinB in a dynamic DC test.

```
RDI_BEGIN();
  rdi.dc("dynamic").label("label")
                   .pin("pinA")
                     .insertVec(55).vForce(5)
                     .insertVec(90).vForce(3) // here, the line number cannot be lower than 87.
                   .pin("pinB")
                     .insertVec(65). vMeas()
                     .insertVec(185).vMeas()  // here, the line number cannot be lower than 97.
                   .execute();
RDI_END();

double value = rdi.id("dynamic").getValue("pinB");         // only the last measurement result
ARRAY_D values = rdi.id("dynamic").getMultiValue("pinB");  // all the measurement results
```
