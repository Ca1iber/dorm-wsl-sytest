# Working with the Routing Tools editors

A defined setup sequence should be followed for successfully defining setups using the Routing Tools editors.

## About this task

This task describes the sequence for setting up all configuration data and defining the setups to be applied by the Routing Tools APIs.

## Before you begin

- Collect the following hardware related information of the DUT board:

  - Assignment and wiring of the utility pogo pins.
  - Configuration and wiring of the digital control pins if [sequencer controlled utility lines](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01_Sequencer-controlled_utility_lines.md>) are used.

- Open the Routing Tools Editors as shown in [Opening the Routing Tools editors](<02.07.13.15.02.01_Opening_the_Routing_Tools_editors.md>).

## Procedure

-  Define the digital control pins.

Digital control pins must be defined for [controlling utility lines by the pattern sequencer](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01_Sequencer-controlled_utility_lines.md>).

  -  Identify the digital control pins for utility pogo blocks that are wired on the DUT board.
  -  Define minimum three digital pins for the signals FRAMn, SCLK, and SINP per utility line control group. For more information refer to [Serial interface for sequencer-controlled utility lines](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01.01_Serial_interface_for_sequencer-controlled_utility_lines.md>).

-  Load or create an XML file and enter the global configuration data.

The XML file holds the complete configuration data for the Routing Tools.

  -  Select the [Global Setup editor](<02.07.13.15.01.01_Routing_Tools_-_Global_Setup_editor.md>) tab.
  -  Create a new XML file or select an existing XML file using the File Path field or the Browse... button. The file extension ".xml", ".zip" or ".rtz" defines whether the file to load is a text file or a compressed file.
  -  Click the Load button for loading the selected file.
  -  Enter the number of configured sites in field Site Number. The number of configured sites must be the same as defined by the Define Site Number dialog of SmarTest. For more information refer to [Defining additional test sites](<../02.08_Setup_and_Result_Tools/02.08.04.18.02.07.04_Defining_additional_test_sites.md>).
  -  Select the type of utility pogo blocks in field Pogo block size.... The selected value must be the same as defined as parameter utility_lines_per_pogoblock in the .technology file of the device. For more information refer to [Technology file for a device](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.01.02_Technology_file_for_a_device.md>).
  -  If [sequencer鈥慶ontrolled utility lines](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01_Sequencer-controlled_utility_lines.md>) are used enter a clock frequency in field SPI Max. Clock Rate. The maximum supported clock frequency is defined in [Specifications for the serial interface](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01.02_Specifications_for_the_serial_interface.md>).

-  Define the control data for utility lines.

The operating mode of the utility pogo blocks and the assignment of the digital control pins for sequencer鈥慶ontrolled utility lines need to be defined.

  -  Select the [Utility Lines Control editor](<02.07.13.15.01.02_Routing_Tools_-_Utility_Lines_Control_editor.md>) tab.
  -  Use the Control Table for defining the operating mode for each of the used utility blocks.
  -  Use the Pin Config Table for defining the digital control pins if [sequencer鈥慶ontrolled utility lines](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01_Sequencer-controlled_utility_lines.md>) are used. The selected digital pins must already be defined in the [Digital Pins editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.02_Digital_Pins_editor.md>). On the DUT board, the selected pins must be wired to the [serial interface for sequencer controlled utility lines](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01.01_Serial_interface_for_sequencer-controlled_utility_lines.md>).

-  Define the configuration data for utility lines.

The assignment from tester channels or utility pogo pins respectively to user defined utility pin names is done in this step.

  -  Open the SmarTest [Utility Pins editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.04_Utility_Pins_editor.md>).
  -  Define all required utility pin names and assign them to the tester channels UTI## ... UTI## for all configured sites.
  -  Select the [Utility Lines Config editor](<02.07.13.15.01.03_Routing_Tools_-_Utility_Lines_Config_editor.md>) tab of the Routing Tools.
  -  Copy all names and tester channels from the Utility Pins editor to the corresponding cells of the Utility Lines Config editor tab. The utility pins that are defined in this step must be the same as defined in column Name of the [Utility Pins editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.04_Utility_Pins_editor.md>).

-  Define the switch states.

The switch states to be applied to utility lines are defined in this step. The user defined states hold the switch states for all utility pins and PMU pins and represent one of the Routing Tools main functionality.

  -  Select the default switch mode and enter the default wait times in milliseconds in the first four cells of row Execution.
  -  Enter the user defined state name in column State Name.
  -  Select the appropriate switch mode BBM (Break Before Make), MBB (Make Before Break), or IMM (Immediate mode) in column Switch Mode if the value defined in row Execution does not fit.
  -  Enter the appropriate wait time in milliseconds in columns Off Wait [ms], On Wait [ms], or IMM Wait [ms] if the values defined in row Execution does not fit. The three wait times are assigned to the switch modes BBM, MBB, and IMM.

-  Save your settings.

The configuration data of the Routing Tools editors must to be saved to an XML file.

 Note Saving the contents of all Routing Tools editor tabs can also be done by clicking the Save button of the or by pressing the CTRL + S key combination simultaneously.

  -  Select the [Global Setup editor](<02.07.13.15.01.01_Routing_Tools_-_Global_Setup_editor.md>) tab.
  -  Click the Save button. The file extension ".xml" or ".zip" defines whether the configuration data file is saved as text file or as compressed file. The content of the file is always formatted in the human readable XML format.

## Results

You have created an XML file that holds all configuration data for utility pins and PMUX pins and the states to be applied.

## What to do next

Add the code for loading, selecting, and applying the defined state setups to the test methods of your test suites using the [rdi.route()](<02.07.13.15.05_rdi.route.md>) API of [SmartRDI](<02.07.13_SmartRDI.md>).
