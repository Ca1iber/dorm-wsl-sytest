# TMU_RESULTS.getNumberOfMeasurements()

Returns the number of measurements of the specified pin, application type and site.

## Syntax

```
UINT32 getNumberOfMeasurements(STRING&     pin, TMU::ApplicationType appType, UINT32 site = 0);
UINT32 getNumberOfMeasurements(const char* pin, TMU::ApplicationType appType, UINT32 site = 0);
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

pin

 |

The pin to query.

 |
 |

I

 |

appType

 |

The application type. It currently can only be APP_PERIOD or APP_RAW.

 |
 |

I

 |

site

 |

The site to query. Default is 0, which means the current site.

 |

## Return value

The number of measurements is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
