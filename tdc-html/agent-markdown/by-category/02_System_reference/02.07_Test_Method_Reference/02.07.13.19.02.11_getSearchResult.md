# getSearchResult()

Retrieves the search result from the final node.

## Syntax

```
double getSearchResult()
```

## Example

```
RDI_BEGIN();
  rdi.cogo("B1").search(TA::LINEAR).pathPin("pinA")
                .start(0).stop(4.0).step(10).blockBegin();
       rdi....(rdi.searchInput()).execute();
       rdi....execute() // With pass/fail judgment.
  rdi.cogo().search().blockEnd();
RDI_END();

rdi.id("B1").getSearchResult();
```
