# SMC_UPLOAD_STATUS.remainingUploadSize()

Returns the remaining upload size of an SMC task that is stored in a vector which is populated by [SMC_GET_UPLOAD_STATUS()](<02.07.04.01.231.16_SMC_GET_UPLOAD_STATUS.md>).

## Syntax

```
INT remainingUploadSize() const;
```

List of parameters

There are no parameters.

## Return value

The remaining size of the upload task, that is, the number of samples that still have to be uploaded.

If this figure cannot be determined, -1 is returned.

## Example

This example shows how to create a vector of type SMC_UPLOAD_STATUS and how to retrieve the total upload size from the vector.

Note As `SMC_UPLOAD_STATUS` represents a collection, one has to iterate over the collection to obtain the item.

```
typedef vector<SMC_UPLOAD_STATUS> SmcUploadStatusVector;
INT remainingUploadSize;

// Obtain the collection
SmcUploadStatusVector statusVector = SMC_GET_UPLOAD_STATUS();

// iterate through collection
for(SmcUploadStatusVector::iterator it = statusVector.begin();
     it != statusVector.end(); ++it) {
        remainingUploadSize = it->remainingUploadSize();
        cout << "SMC remaining upload size:" << remainingUploadSize << endl;
     }
```
