# CCTgetDCResults()

Retrieves the measurement results from DC instruments, DC Dynamic pattern (DC Scale Pin), or sequence controlled DC (Digital Pin).

The concurrent test framework (CTF) automatically returns the correct DC results for the respective test suites in the CCT group with DC burst measurement.

## Syntax

int CCTgetDCResults(const string &``pin`);`

Parameter
 |

Parameter

 |

Description

 |
 |

pin

 |

The digital pin to retrieve the DC results from.

 |

## Example

```
virtual void process() {
  ARRAY_D MeasResult;
  MeasResult = CCTgetDCResults(MeasPin);
  int dcResultsize = MeasResult.size();
  for (int I = 0; I <= dcResultsize; i++) {
    Val [nSite] [i] = MeasResult [i];
    cout << "====>>>>pin " << MeasPin << " test result : " << Val[nSite] [i] << endl;
  }
}
```
