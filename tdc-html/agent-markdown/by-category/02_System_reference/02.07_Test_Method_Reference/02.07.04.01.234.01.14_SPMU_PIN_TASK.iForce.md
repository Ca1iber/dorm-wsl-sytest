# SPMU_PIN_TASK.iForce()

Sets the value of the current to be forced and the measurement mode to "IFVM".

 Note The direction of the current flow has to be set by [SPMU_PIN_TASK.clamp()](<02.07.04.01.234.01.01_SPMU_PIN_TASK.clamp.md>).

## Syntax

```
SPMU_PIN_TASK& iForce(DOUBLE current);
```

Parameter
 |

Parameter

 |

Description

 |
 |

current

 |

Forced current in Ampere.

 |

## Return value

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.
