SmartRDI provides the class `dc()` and related functions to measure the voltage of a digital pin directly with board ADC.

The code鈥慴ased mode is supported on all Smart Scale cards.

The pattern鈥慴ased mode is supported on Smart Scale cards.

If measurements are done on more than one pin sharing the same board ADC, the measurements will be done serially in the pattern.

 Note When serial measurements are being done on multiple pins that share the same board ADC, SmartRDI adds a default setting time between consecutive measurements that is long enough waiting for a single measurement done. For more information, see [MSET timing of digital pins](<02.07.04.01.63.01.04_MSET_timing_of_digital_pins.md>). CAUTION In the high impedance mode, the board ADC may generate a spike when the DC relay of a digital bin is being closed. To avoid the spike occurrence, discharge the board ADC or force a voltage before the next measurement. Note If the BADC is shared over sites, make sure to set Site Match = OFF in the related test suite.

## Overview of dc() class functions for BADC setups

 | API  | Description  | Mode |
 | [amux()](<02.07.13.12.01.02.01_amux.md>)  | Control the multiplexer to switch or to hold the signal to the board ADC.  | P |
 | [average()](<02.07.13.12.01.02.02_average.md>)  | Specify a sample number to do averaging.  | P, C |
 | [copyLabel()](<02.07.13.12.01.01.04_copyLabel.md>)  | Specify to edit an existing pattern or copy and edit the pattern.  | P |
 | [enPassFail()](<02.07.13.13.09_enPassFail.md>)  | Work together with getPassFail() to retrieve the pass/fail results of the pattern specified by label().  | P |
 | [firstRunInLoop()](<02.07.13.12.01.01.06_firstRunInLoop.md>)  | Control the running of PPMU pattern setups and relays to be done only within the first iteration of loops.  | C |
 | [limit()](<02.07.13.12.01.01.13_limit.md>)  | Add a pair of limits for judging the pass/fail result of a dynamic DC measurement on digital pins or DC Scale pins.  | P |
 | [measWait()](<02.07.13.12.01.01.14_measWait.md>)  | Specify a period of time to wait between the previous event and measuring the value.  | P, C |
 | [pin()](<02.07.13.12.01.02.09_pin.md>)  | Specify pin(s) for the subsequent DC actions.  | P, C |
 | [postWait()](<02.07.13.12.01.02.10_postWait.md>)  | Specify a time period to wait after a action.  | P, C |
 | [relay()](<02.07.13.12.01.02.11_relay.md>)  | Specify relay actions before and after a measurement.  | P, C |
 | [vMeas()](<02.07.13.12.01.02.12_vMeas.md>)  | Specify a voltage measurement  | P, C |
 | [getValue()](<02.07.13.12.01.01.23_getValue.md>)  | Retrieve the measure value from a pin.  | C |

In the Mode column: C = Code-based, P = Pattern-based.

## Example

```
ON_FIRST_INVOCATION_BEGIN();
  RDI_BEGIN();
    rdi.dc("rly1").pin("DATA1",TA::BADC).vMeas().execute();
  RDI_END();
ON_FIRST_INVOCATION_END();
double val;
val=rdi.id("rly1").getValue("DATA1");
```
