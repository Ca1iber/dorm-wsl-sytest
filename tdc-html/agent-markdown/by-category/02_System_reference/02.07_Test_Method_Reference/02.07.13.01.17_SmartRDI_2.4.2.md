# SmartRDI 2.4.2

This section summarizes the changes and new features in SmartRDI 2.4.2.

Changes and new features
 |

Category

 |

Description

 |
 |

General

 |

- Full support to AVI64.
- Result retrieval enhancements:

  - Non-hidden upload result retrieval commands can be put in an [SMC_BackgroundProcessing()](<02.07.04.01.231.01_SMC_ARM.md>) block.
  - No unique result ID is required for a hidden upload process.
  - No location limitation for a result retrieval command in [RDI_UNIT_INIT](<02.07.13.08.01.07_RDI_UNIT_INIT.md>).

- Error map hidden upload. See [rdi.hiddenUpload()](<02.07.13.08.19.02.03_rdi.hiddenUpload.md>).
- Support to Fast Sync. See [Fast Sync setup with SmartRDI](<02.07.13.08.05_Fast_Sync_setup_with_SmartRDI.md>).

  - [fastSyncOn()](<02.07.13.08.05.02_fastSyncOn.md>)
  - [fastSyncOff()](<02.07.13.08.05.01_fastSyncOff.md>)
  - [fastSyncPortNum()](<02.07.13.08.05.03_fastSyncPortNum.md>)

  |
