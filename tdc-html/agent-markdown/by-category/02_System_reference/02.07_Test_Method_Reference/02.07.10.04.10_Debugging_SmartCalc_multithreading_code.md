# Debugging SmartCalc multithreading code

All features of the debugger such as setting breakpoints and stepping through multithreaded code work with SmartCalc the same way as with any other code. However, DSP calculations of the different sites may not be executed in logical numerical order for example, site 1, may not be the first execution). To avoid this, SmartCalc features can be disabled (see [Disabling SmartCalc)](<02.07.10.04.11_Disabling_SmartCalc.md>).

## Functional changes

- Introduced in SmarTest 6.5.3
