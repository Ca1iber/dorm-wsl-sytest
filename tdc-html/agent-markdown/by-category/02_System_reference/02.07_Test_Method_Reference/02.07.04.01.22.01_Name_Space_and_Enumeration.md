# Name Space and Enumeration

The enumerations defined in the name space `Display` include:

`TaskMode`, `TrackMode`, `GraphStyle`, `LineStyle`, `Color`, `Symbol` and `DataType`. These enumerations are used in all the data display API classes.

## Display::TaskMode

This enumeration defines the task modes of the Data Display API. It has the following options:

- NONE

The Data Display API does nothing.

- FILE

Waveform data is always stored into the directory "<device>/waveform/.result". The waveform data can be viewed in the Waveform Navigator Tool after task execution.

- DISPLAY

Waveform data is directly displayed in a waveform display area, but the waveform data will not be stored.

- BOTH

Waveform data is always stored into the directory "<device>/waveform/.result" and the waveform data is directly displayed in a waveform display area.

## Display::TrackMode

This enumeration defines the track modes of the markers and cursors in the Data Display API. It has the following options:

- TRACK_ON

An up marker is synchronized with a down marker.

A measure cursor is synchronized with a reference cursor.

- TRACK_OFF

An up marker is not synchronized with a down marker.

A measure cursor is not synchronized with a reference cursor.

## Display::GraphStyle

This enumeration defines the graph styles of a graph in the Data Display API. It has the following options:

- PLOT_LINE

This style supports general chart.

- PLOT_BAR

This style supports bar chart.

## Display::LineStyle

This enumeration defines the line styles of a trace. It has the following options:

- NONE_LINE
- DASH_DOT
- LONG_DASH
- SHORT_DASH
- SOLID

## Display::Color

This enumeration defines the colors of each component part of the display such as background, axis, grid, and trace. It has the following options: BLACK, BLUE, CYAN, DARK_GRAY, GRAY, LIGHT_GRAY, GREEN, MAGENTA, ORANGE, PINK, RED, YELLOW, WHITE and AUTO.

This list provides an overview of the color enumeration:

```

{
     BLACK = 0,
     BLUE = 255,

```

## Display::Symbol

This enumeration defines the pointer symbols of a trace. It has the following options: NONE_SYMBOL, BOX, CIRCLE, CROSS, DIAMOND, DOT, HORIZONTAL_LINE, VERTICAL_LINE, TRIANGLE, STAR and SQUARE.

## Display::DataType

This enumeration defines the data types for traces. It has the following options:

- WAVEFORM

This type indicates the current trace is a waveform

- VECTOR

This type indicates the current trace is a vector.

- SCATTER

This type indicates the current trace is a scatter graph.

## Display::GraphType

This enumeration defines the type of a graph in the Data Display API. It has the following options:

- NORMAL_GRAPH

This type supports normal graph (non-Smith chart).

- SMITH_GRAPH

This type supports Smith chart.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.0.3: New enumeration Display::GraphType is defined.
