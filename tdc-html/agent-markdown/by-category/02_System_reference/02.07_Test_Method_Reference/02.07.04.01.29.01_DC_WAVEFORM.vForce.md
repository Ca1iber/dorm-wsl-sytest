# DC_WAVEFORM.vForce()

This function is used to create a voltage force waveform out of an analog waveform.

## Syntax

```
DC_WAVEFORM & vForce(ANALOG_WAVEFORM & waveform);
```

Parameter
 |

Parameter

 |

Description

 |
 |

waveform

 |

The name of an analog waveform object.

 |

## Return value

A DC waveform
