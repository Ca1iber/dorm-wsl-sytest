# SmartRDI 7.10.3

This section summarizes software changes including new features and enhancements in SmartRDI 7.10.3.

Changes and new features
 | Category  | Description |
 | General |

- SmartRDI supports up to 1000000 measurement result IDs at the same time.
- SmartRDI supports automatic mask on inactive sites.

  - assignLabelOnHoldSites()
  - assignLabelOnInactiveSites()
  - clearOnHoldSites()
  - setOnHoldSites()
  - getOnHoldSites()
  - getOnHoldSitesStatus()

See [Site masking](<02.07.13.08.07_Site_masking.md>).

 |
 | [Alarm handling](<02.07.13.09_SmartRDI__Alarm_handling_for_DCVI.md>) |

- Alarm handling on pins using [runTimeVal()](<02.07.13.08.03.01_runTimeVal.md>) is supported.
- [getAlarmBurstValue()](<02.07.13.09.02.06_rdi.id__.getAlarmBurstValue.md>) gets alarm DC results on specified pins in burst.
- [getAlarmPassFailPerID()](<02.07.13.09.02.08_rdi.id__.getAlarmPassFailPerId.md>) gets pass/fail results on a specified label.
- [getAlarmValue()](<02.07.13.09.02.09_rdi.id__.getAlarmValue.md>) gets alarm DC results on specified pins per id.
- [getEnabledPins()](<02.07.13.09.02.04_rdi.alarm__.getEnabledPins.md>) retrieves the enabled alarm pins.
 |
 | [DC](<02.07.13.11_SmartRDI__DC_resource_AWG_DGT_usage.md>) |

- [addWaveform()](<02.07.13.11.01.01_addWaveform.md>) sources multiple different waveforms in one execute().
- Using a separate MSET, RDI can automatically change the force mode for [digital DC waveform](<02.07.13.11.01.07_waveform.md>).
- Analog waveform content can be logged.
 |
 | [TMU](<02.07.13.21_SmartRDI__TMU_test_setup.md>) |

- [getPropDelay()](<02.07.13.21.19_rdi.id__.getPropDelay.md>) automatically calculates the propagation delay time of TMU measurements.
 |
 | [UTIL](<02.07.13.23_SmartRDI__Utility_lines_control.md>) |

- SmartRDI supports the "-" character to link block numbers for ganged blocks in the UTIL_BLOCK definition of the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md#_146692__row_UTIL_BLOCK>).
 |

## Supported SmarTest versions

SmartRDI 7.10.3 supports SmarTest 7.10.3.
