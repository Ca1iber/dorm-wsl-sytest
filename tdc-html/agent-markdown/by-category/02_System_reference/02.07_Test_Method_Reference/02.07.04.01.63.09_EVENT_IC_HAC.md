# EVENT_IC_HAC

#### Subtopics

- [EVENT_IC_HAC.iClampLow()](<02.07.04.01.63.09.01_EVENT_IC_HAC.iClampLow.md>)
- [EVENT_IC_HAC.iClampHigh()](<02.07.04.01.63.09.02_EVENT_IC_HAC.iClampHigh.md>)
- [EVENT_IC_HAC.getIClampLow()](<02.07.04.01.63.09.03_EVENT_IC_HAC.getIClampLow.md>)
- [EVENT_IC_HAC.getIClampHigh()](<02.07.04.01.63.09.04_EVENT_IC_HAC.getIClampHigh.md>)

Current clamp high accuracy (IC_HAC) event classes provide functionality to define events specifying and querying clamp current values.

EVENT_IC_HAC functions are supported in PMU operating mode (pin type SIG) on DC Scale DPS128/64 cards only. They are not supported in DPS mode (pin type DPS+).

There are functions to set and query either the low or the high clamp current value. You cannot specify both!

In case you try to get a non-defined value, the software returns `999999/-999999`. This NaN (not a number) indicates an undefined or unrepresentable value.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_IC_HAC ( const STRING &id );
EVENT_IC_HAC ( INT &id );
```

This constructs an object of the EVENT_IC_HAC class. The class derives from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

Parameter
 | Parameter  | Description |
 | id |

Event identifier

 |

Return value

There is no return value.

## Example

```
PATTERN_CONTROLLER cleanUpPattern;
PATTERN_CONTROLLER pc;
EVENT_IC_HAC iClampHacEvent("iClampHacEvent1");

ON_FIRST_INVOCATION_BEGIN();
    cleanUpPattern.label("patEvents", "@")
                  .vecEvents("dps1")
                  .clearAll()
                  .setup();
    iClampHacEvent.iClampLow(1 mA);

    // insert events into pattern
    PATTERN & pattern(pc.label("patEvents", "@"));
    pattern.vecEvents("dps1").insert(32, iClampHacEvent)
    pc.setup();
ON_FIRST_INVOCATION_END();
```
