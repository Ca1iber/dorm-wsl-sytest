# clearPinStatus()

Clears the status of a specified pin. The default index of this pin will be reset to the status defined in the [RDI_Configure](<02.07.13.04_RDI_Configure_file.md>) file. If no default status is defined in the [RDI_Configure](<02.07.13.04_RDI_Configure_file.md>) file, the default index of the pin will be reset to f.

## Syntax

```
clearPinStatus(const string& sPin);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

sPin

 |

The pin name.

 |

## Example

```
rdi.clearPinStatus("pinA");
```

## Functional changes

- Introduced in SmartRDI 2.1.0
