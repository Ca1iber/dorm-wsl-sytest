# SEMI_PARALLEL_GROUP.getGroupId()

Gets the ID of the current semi-parallel group.

## Syntax

```
int getGroupId() const;
```

List of parameters

There are no parameters.

## Return value

The current semi-parallel group ID is returned.

## Functional changes

- Introduced in SmarTest 7.2.0
