# SMC_DIGITAL_CAPTURE_TEST()

Executes a test which contains digital capture by starting the digital sequencer and waits for the test to complete or till the specified timeout is reached (except for AWG). It allows hidden upload of data controlled by SmartCalc.

In addition a resultAreaId can be specified to set up hidden digital capture upload. The resultAreaId has to be defined beforehand using [RESULT_AREA_CONFIG](<02.07.04.01.189_RESULT_AREA_CONFIG.md>).

This API internally executes [FLUSH()](<02.07.04.01.69_FLUSH.md>) to reflect all changes of the hardware setup data that might be altered.

A test execution will fail if this API is used but if the test does not perform a digital capture.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```
void SMC_DIGITAL_CAPTURE_TEST(const STRING& resultAreaId);
void SMC_DIGITAL_CAPTURE_TEST(const STRING& resultAreaId, const STRING& context);
void SMC_DIGITAL_CAPTURE_TEST(DOUBLE timeout = 360000);
void SMC_DIGITAL_CAPTURE_TEST(const TM::WAIT_ACTION& wait_action);
void SMC_DIGITAL_CAPTURE_TEST(DOUBLE timeout, const TM::WAIT_ACTION& wait_action);
void SMC_DIGITAL_CAPTURE_TEST(DOUBLE timeout, const STRING& resultAreaId);
void SMC_DIGITAL_CAPTURE_TEST(DOUBLE timeout, const STRING& resultAreaId, const STRING& context);
void SMC_DIGITAL_CAPTURE_TEST(const TM::WAIT_ACTION& wait_action,
                              const STRING& resultAreaId);
void SMC_DIGITAL_CAPTURE_TEST(const TM::WAIT_ACTION& wait_action,
                              const STRING& resultAreaId, const STRING& context);
void SMC_DIGITAL_CAPTURE_TEST(DOUBLE timeout, const TM::WAIT_ACTION& wait_action,
                              const STRING & resultAreaId);
void SMC_DIGITAL_CAPTURE_TEST(DOUBLE timeout, const TM::WAIT_ACTION& wait_action,
                              const STRING & resultAreaId, const STRING& context);
```

Parameters
 |

Parameter

 |

Description

 |
 |

timeout

 |

Timeout in seconds.

If you omit this parameter, the default timeout is 360000 s.

 |
 |

wait_action

 |

Selects the sequencer the API shall wait for completion. Options can be combined by using '|' (bitwise OR).

Default: TM::WAIT_DIGITAL `| `TM::WAIT_DGT `| `TM::WAIT_TIA

Refer to the list of available options of the wait_action parameter below.

 |
 |

resultAreaId

 |

Specifies the resultAreaId in which the data will be captured.

 |
 |

context

 |

Name of an execution context. The ports of the context must be included in the current start label (which must be a multiport burst). For more information on execution contexts see [Using execution contexts](<../02.06_Command_Reference/02.06.07.01.08.05.03.02.03_Using_execution_contexts.md>) .

The context must have been defined on the firmware level (with the SQEC command), or as a SEQUENCER_CONTEXT_ITEM object. In the latter case this object must have been included in a SEQUENCER_CONTEXT object, and must also have been activated on the firmware level with the apply() function of this SEQUENCER_CONTEXT object. If the context has been defined as a SEQUENCER_CONTEXT_ITEM object, you must use the name specified for its name parameter.

 |

List of available options of parameter: wait_action
 |

Option

 |

Description

 |
 |

TM::WAIT_ALL

 |

Wait until all HW used with the test completed their current sequencer program.

 |
 |

TM::WAIT_DIGITAL

 |

Wait until all used digital channels complete the current sequencer program.

 |
 |

TM::WAIT_AWG

 |

Wait until all used AWGs complete the current sequencer programs.

 |
 |

TM::WAIT_DGT

 |

Wait until all used digitizers and samplers complete the current sequencer programs.

 |
 |

TM::WAIT_TIA

 |

Wait until all used TIAs complete the current measurements.

 |
 |

TM::WAIT_TMU

 |

Wait until all all running TMUs have finished their measurements.

 |

Return value

There is no return value.
