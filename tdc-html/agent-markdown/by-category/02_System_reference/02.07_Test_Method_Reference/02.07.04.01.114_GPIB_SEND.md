# GPIB_SEND

This API sends data or GPIB commands, and returns 0 on success, non-zero when timeout occurred.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/GpibMapi.h.

## Syntax

```
INT GPIB_SEND(GPIB_ACTION action);
INT GPIB_SEND(GPIB_ACTION action, INT address, INT address2);
INT GPIB_SEND(GPIB_ACTION action, const STRING& command);
```

GPIB_ACTION is a system-defined data type to set a GPIB action.

## Actions

- ABORT

Aborts all activities on the GPIB interface by setting the IFC and REN lines to true, and setting the ATN line to FALSE. This action clears all talker and listener assignments. If you specify the "address" parameter in other case, error occurs at execution.

- CLEAR

If the "address" parameter is specified, this action initializes the specified device, and sends the MTA UNL LAG SDC mnemonics onto the GPIB with the ATN line set to true. The initial state depends on each device type.

If the "address" parameter is not specified, this action initializes all devices which accept the CLEAR action, and sends the DCL mnemonic onto the GPIB with the ATN line set to true. The initial state depends on each device type.

The table below lists the all GPIB mnemonics.

- LOCAL

If the "address" parameter is specified, this action sets the specified device to its local control state, and sends the MTA UNL LAG GTL mnemonics with ATN line set to true.

If the "address" parameter is not specified, this action sets all devices that have remote/local control capabilities to the local control state by setting the REN line to false. Any existing LLOCKOUT states are canceled.

- LLOCKOUT

This action locks out the local button of all devices on the GPIB, thus preventing anyone from interfering with system operations by pressing the local button, and sends LLO onto the GPIB with the ATN line set to true. If a device is in the local control state, the device is not set to the local lockout state. Error occurs if the "address" parameter is specified.

- REMOTE

If the "address" parameter is specified, this action sets the specified device to the remote control state, and sets the REN line to true, and sends MTA UNL LAG onto the GPIB with the ATN line set to true.

If the "address" parameter is not specified, this action sets all devices that have remote/local control capabilities to the remote control state, and sets the REN line to true.

- TRIGGER

If the "address" parameter is specified, this action lets the specified listener device to start some device-dependent action, and sends the UNL LAG GET mnemonics onto the GPIB with the ATN line set to true.

If the "address" parameter is not specified, this action lets all listener devices to start some device-dependent action, and sends the GET mnemonics onto the GPIB with the ATN line set to true.

- COMMAND

Sends the "command" parameter (GPIB_xxxx) onto the GPIB with the ATN line set to true. The second table below lists the all parameters for this action. Error occurs if the "address" parameter is specified.

- DATA

Sends the "command" parameter onto the GPIB with the ATN line set to false. If you use this action, you must set GPIB command, for example, "*RST". Error occurs if the "address" parameter is specified.

## Example

-

```
GPIB_ACTION action = LLOCKOUT;
GPIB_SEND( action );
```

The GPIB_SEND API Locks out local buttons of all devices.

-

```
GPIB_ACTION action = REMOTE;
INT address = 17;
GPIB_SEND( action, address );
```

The GPIB_SEND API sets the device at address 17 to the remote control state.

-

```
STRING command;
command += GPIB_UNT; //untalk command
command += GPIB_UNL; //unlisten command
command += GPIB_TA21; //talker address
 (testercontroller)
command += GPIB_LA17; // listener address
command += GPIB_SDC; // selected device clear
GPIB_ACTION action = COMMAND;
GPIB_SEND( action, command);
```

The GPIB_SEND API sends the 5 bytes of the command array onto the GPIB. The GPIB_SDC (selected device clear) command is sent to the device at GPIB address 17.

In this case, you can also use decimal expressions to specify the "command" parameter.

 STRING command;

 command += 95;

 command += 63;

 command += 85;

 command += 49;

 command += 04;

 GPIB_ACTION action = COMMAND;

 GPIB_SEND(GPIB_ACTION action, command );

-

```
STRING command;
command += "*RST";
GPIB_ACTION action = DATA;
GPIB_SEND( action, command );
```

The GPIB_SEND API sends the "*RST" command to the all GPIB instruments connected to the GPIB card for user.
