# SetupLevelSet0

This test method allows you to change the clamp settings and active load settings of level set 0 (high-z state).

The default clamp voltage levels and active load settings of the different channel cards are:

 |

Parameter

 |

PS1600 / PS5000

 |
 |

Vcl

 |

-2.00 V

 |
 |

Vch

 |

7.00 V

 |
 |

Active load

 |

disabled

   |  Note Pin Scale 9G cards do not have clamps and active load. If you try to apply clamp levels and active load settings on PS9G, the settings will be ignored.

Fixed level set "1" is the SmarTest default level set: whenever the sequencer is put into a/the "BRK"- or "RUN"-state, and the user does not specify any other fixed or equation-based level set as primary, this level set is used as level primary; the currently selected primaries can be checked by executing the SPRM?-firmware command.

## Parameters

 |

Pins[]

 |

string

 |

array of pins

Separate pins with semicolon (;). Valid pin types include I, O, or IO digital pin.

 |
 |

ClampVoltage.Mode[]

 |

string

 |

array of clamp mode. It can be:

ON: Clamp is set to on with low/high voltage.

OFF: Clamp is set to off.

To specify different configuration for different pins, separate the values with semicolon (;).

 |
 |

ClampVoltage.Low_V[]

 |

string

 |

array of low clamp voltage in unit [V]

To specify different configuration for different pins, separate the values with semicolon (;).

 |
 |

ClampVoltage.High_V[]

 |

string

 |

array of high clamp voltage in unit [V]

To specify different configuration for different pins, separate the values with semicolon (;).

 |
 |

ActiveLoad.Mode[]

 |

string

 |

array of active load mode. It can be:

ON: set up active load setting, Vt, Iol and Ioh

OFF: turn off active load

To specify different configuration for different pins, separate the values with semicolon (;).

 |
 |

ActiveLoad.CommutationVoltage_V[]

 |

string

 |

array of commutation voltage (Vcom), in unit [V]

To specify different configuration for different pins, separate the values with semicolon (;).

 |
 |

ActiveLoad.SourceCurrent_A[]

 |

string

 |

array of active load source current (Ioh), in unit [A]

To specify different configuration for different pins, separate the values with semicolon (;).

 |
 |

ActiveLoad.SinkCurrent_A[]

 |

string

 |

array of active load sink current (Iol), in unit [A]

To specify different configuration for different pins, separate the values with semicolon (;).

 |

## Implementation pseudo code

```
IF first run OR parameter changed THEN
 FOR all sites in parallel DO
 IF SmarTest version before 6.3.6 THEN
 issue message
 ELSEIF not PinScale system THEN
 issue message
 ELSE
 //process parameter
 split all string-type parameter values
 validate pin types
 validate the integration of dependent parameters
 //set up Level Set 0 configuration
 IF not already disconnected THEN
 disconnect DUT
 ENDIF
 FOR all pins in pinlist DO
 set up clamp for level set 0
 set termination mode for level set 0
 ENDIF
 set first Run true
END-IF
```
