Combined force/measure waveform classes provide functionality to define events, which generate waveforms, and measure at the same point in time when the samples are applied to the frontend.

Specialized force/measure waveform classes are EVENT_WAVEFORM_VFIM (Voltage Force / Current Measure Waveform) and [EVENT_WAVEFORM_VFVM](<02.07.04.01.63.39_EVENT_WAVEFORM_VFVM.md>) (Voltage Force / Voltage Measure Waveform).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
class EVENT_WAVEFORM_VFIM : public EVENT_BASE

    EVENT_WAVEFORM_VFIM(const STRING & id);
    EVENT_WAVEFORM_VFIM(      INT      id);
    EVENT_WAVEFORM_VFIM();
```

This constructs an object of the EVENT_WAVEFORM_VFIM class. The class derives from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

When using the EVENT_WAVEFORM_VFIM() constructor, the event ID is implicitly derived from the name of the assigned ANALOG_WAVEFORM. The event ID will look like: WAV_waveformName

Parameter
 | Parameter  | Description |
 | id |

Identifier of the event.

The identifier may be defined as integer value or as string.

 |

## Example

- Describes the waveform of a voltage ramp:

```
ANALOG_WAVEFORM rampUp("rampUp");

rampUp.definition(TM::RAMP)
      .direction(TM::POS)
      .samples(4)
      .min(0.1).max(1.6);
```

- Defines a force voltage ramp waveform:

```
EVENT_WAVEFORM_VF rampUpEvent;
rampUpEvent.vForce(rampUp);
rampUpEvent.sampleVectorDistance(64);
```
