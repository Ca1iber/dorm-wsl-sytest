# TIMING_OFFSET_SEARCH_PINS.search()

This function executes the timing offset search for the specified pins and returns the execution status. The execution status can be `SUCCESS`, `FAILED`, `ABORTED` or `NOT_EXECUTED`.

## Syntax

```
TIMING_OFFSET_SEARCH::STATUS_TYPE search();
```

## Functional changes

- Introduced in SmarTest 7.0.1
