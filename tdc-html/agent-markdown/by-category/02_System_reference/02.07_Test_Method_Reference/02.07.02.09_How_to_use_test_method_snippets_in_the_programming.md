The test method snippets are used and managed via the EWC C/C++ Templates feature. This feature can be accessed in the EWC through Window > Preferences > C/C++ > Editor > Templates.

## About this task

The system-provided test method snippets are imported automatically in the current workspace from the file /opt/hp93000/soc/segements/tml/testmethodSnipptets.xml. You can directly use it in your test method programming.

If you switch to another workspace or create a new workspace, the system-provided snippets will be imported automatically too.

## Before you begin

To use the provided test method snippets, make sure you are using SmarTest 6.5.4 or later versions.

## Procedure

-  In the test method editor, type in the first several letters of the snippet and press the key Ctrl + Space. A list of snippets started with the letters you typed in will be displayed.
-  Highlight a snippet in the list. You will see the content of the snippet as in the figure below.  ![Content Assist](<../../../../raw/119287.png>)
-  Double click the snippet you want to use in the list. The code of the snippet will be inserted in the test method.

You can also create your own test method snippets and reuse them somewhere else. For details, see [How to create a snippet](<02.07.02.09.02_How_to_create_your_own_snippet.md>) and [How to export the snippets to an xml file](<02.07.02.09.03_How_to_export_the_snippets_to_an_xml_file.md>).
