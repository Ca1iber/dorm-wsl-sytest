# DPS_POWER_PIN_STATUS

The `DPS_POWER_PIN_STATUS` class is a subsidiary data container of the `DPS_POWER_STATUS` class. You can access the class object via the `pin()` member function of `DPS_POWER_STATUS` by specifying the DPS pin list. You cannot directly construct any objects of this class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/DpsPowerPinStatus.h.

## Member functions

### on()

`void on();`

This function connect the specified DPS pins for all enable sites.

### off()

`void off();`

This function disconnect the specified DPS pins for all enable sites.

### isOn()

`bool isOn();`

This function retrieves the connection status of a single DPS pin of the focus site. It returns true if the specified pin is connected. Otherwise it returns false.
