# TMU_PINS.getFunctestResult()

Returns the functional test result of the pins in the last execution.

## Syntax

```
Boolean getFunctestResult();
```

List of parameters

There are no parameters.

## Return value

True is returned if the execution passed. Otherwise, false is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
