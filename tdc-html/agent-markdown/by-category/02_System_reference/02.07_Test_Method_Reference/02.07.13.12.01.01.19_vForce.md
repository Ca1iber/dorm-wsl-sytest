# vForce()

Specifies the voltage to force.

## Syntax

```
vForce(double dV);
vForce(const string& sData);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

dV

 |

The voltage to force

 |
 |

sData

 |

The string containing the value to be used at run-time. (Refer to [Changing the parameter value at run-time with SmartRDI](<02.07.13.08.03_Changing_the_parameter_value_at_runtime_with_SmartRDI.md>).)

 |

## Example

```
rdi.dc().pin("pinA").vForce(2.5 V).execute();
```
