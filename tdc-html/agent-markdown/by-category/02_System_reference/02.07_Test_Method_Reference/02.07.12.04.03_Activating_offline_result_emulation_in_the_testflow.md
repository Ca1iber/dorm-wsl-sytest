# Activating offline result emulation in the testflow

This topic describes how to activate offline result emulation using the [Flow Sequence Editor](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.02_Flow_Sequence_Editor.md>).

## Before you begin

The setup meets the requirements according to [Test program requirements for ORE](<02.07.12.03_Test_program_requirements_for_offline_result_emulation.md>).

 Note Offline result emulation (ORE) is available with the S&S_TOOLS_PACKAGE SW license. If this license is not available, ORE is disabled.

For an overview of all licensed V93000 products by product ID, as they are referenced on the Entitlement Certificates, see [Licensed V93000 products](<../02.04_Model_File_and_Licensing/02.04.02.01_V93000_License_Master_Look-up_Table.md>).

## Procedure

-  Create a single [ORE setup file](<02.07.12.05_Offline_result_emulation_setup_file.md>) that contains all pattern cycle failures or parametric data that you want to inject.
-  Create a [corresponding activation test method](<02.07.04.01.137_OfflineResultEmulationConfig.md>) that references this setup file.

Examples are provided in [Examples on how to use offline result emulation](<02.07.12.06_Examples_on_how_to_use_offline_result_emulation.md>).

-  [Open the testflow](<../02.08_Setup_and_Result_Tools/02.08.04.32.02.01.01_Opening_the_Testflow_Tool.md>) in the [Flow Sequence Editor](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.02_Flow_Sequence_Editor.md>).
-  [Insert a test suite](<../02.08_Setup_and_Result_Tools/02.08.04.32.02.01.04_Inserting_a_test_suite_into_the_testflow.md>) at the beginning of the testflow.

Note that inserting the ORE-enabling test suite anywhere except at the beginning of the testflow may cause unwanted effects.

-  Configure the test suite:

  -  Type a name.
  -  Optionally, type a comment.
  -  Select the test method that you created in step [2](<02.07.12.04.03_Activating_offline_result_emulation_in_the_testflow.md#_128960__step-create-test-method>).
  -  Click Finish.

## Results

The testflow is prepared for the offline result emulation.
