# NB_FUNCTIONAL_TEST()

This API starts a functional test and returns immediately without waiting for the end of the functional test. The result can be returned by the GET_FUNCTIONAL_RESULT() or TEST API (in TEST, specify TM::CONTINUE) after the functional test has been finished.

## Application note

- Before starting the digital sequencer, NB_FUNCTIONAL_TEST() activates the timing/level-related primaries specified on the Testsuite dialog window, and activates the changes specified in the PRIMARY_STATUS(), TIMING_SPEC, LEVEL_SPEC, and SPECIFICATION APIs.
- If you need to activate the primary analog set (specified in the Testsuite dialog window or the ANALOG_STATUS API) and activate a routing set (specified in the ROUTING_STATUS API), execute the FLUSH API before FUNCTIONAL_TEST().
- You can observe the test result of the NB_FUNCTIONAL_TEST() API on the following software tools after the execution of the functional test is completed and before the next test is executed or the tester resources are disconnected from DUT:

  - Error Map
  - Timing Diagram
  - Pattern Tool

## Syntax

```
void NB_FUNCTIONAL_TEST();
void NB_FUNCTIONAL_TEST(const STRING& context);
void NB_FUNCTIONAL_TEST(const STRING& context, const STRING& resultAreaConfigSetName);
```

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Execute.h.

  Parameter

 | I/O  | Parameter  | Description |
 | I  | context |

Name of an execution context. The ports of the context must be included in the current start label (which must be a multiport burst). For more information on execution contexts see [Using execution contexts](<../02.06_Command_Reference/02.06.07.01.08.05.03.02.03_Using_execution_contexts.md>).

The context must have been defined on the firmware level (with the SQEC command), or as a SEQUENCER_CONTEXT_ITEM object. In the latter case this object must have been included in a SEQUENCER_CONTEXT object, and must also have been activated on the firmware level with the apply() function of this SEQUENCER_CONTEXT object. If the context has been defined as a SEQUENCER_CONTEXT_ITEM object, you must use the name specified for its name parameter.

 |
 | I  | resultAreaConfigSetName  | The name of a [RESULT_AREA_CONFIG_SET()](<02.07.04.01.190_RESULT_AREA_CONFIG_SET.md>).  |   Return value There is no return value.
