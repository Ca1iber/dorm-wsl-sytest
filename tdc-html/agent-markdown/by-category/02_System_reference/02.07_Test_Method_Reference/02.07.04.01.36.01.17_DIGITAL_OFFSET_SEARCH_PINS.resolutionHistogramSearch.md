# DIGITAL_OFFSET_SEARCH_PINS.resolutionHistogramSearch()

Defines the step width for the histogram based search.

This function is used together with [DIGITAL_OFFSET_SEARCH_PINS.minStableErrorCount()](<02.07.04.01.36.01.11_DIGITAL_OFFSET_SEARCH_PINS.minStableErrorCount.md>).

## Syntax

```
DIGITAL_OFFSET_SEARCH_PINS& resolutionHistogramSearch(DOUBLE res);
```

Parameter
 |

Parameter

 |

Description

 |
 |

res

 |

The step width for the histogram based search.

 |

## Return value

A reference to the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) object.
