# DSP_RF_DECIMATE()

In most applications, users will not need to call the DSP_RF_DECIMATE() function, because decimation (if it is needed) is performed automatically by other DSP functions, such as DSP_RF_MOD_POWER(). The DSP_RF_DECIMATE() function is provided for the benefit of users who wish to create their own custom DSP routines within a TestMethod, and therefore need direct access to a decimation function.

Captured IF data is processed by the RTSPU (real-time signal processing unit) in the MB-AV8 card, which down-converts the IF to DC (that is, to a signal centered around 0 Hz) and generate a complex array from it. Sometimes the bandwidth specified in the measurement definition is narrower than the minimum bandwidth of the RTSPU. In such cases, decimation is required (as indicated by a decimation factor, shown in the sequence block for the capture, which is greater than 1). The DSP_RF_DECIMATE() function can be used to apply a decimation algorithm to the results (so that the effective bandwidth of the results matches the requested bandwidth of the measurement definition).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_RF_DECIMATE(const ARRAY_COMPLEX   & sourceData,
                const int               decimationFactor,
                int                   * numValidPts);
```

## Example

```
INT numValidPts = 0;
ARRAY_COMPLEX cData = MEAS_DEF("myModPwrMeas").getComplexWaveform();
ARRAY_D measParams = MEAS_DEF().getParameters(1,0);
INT swDeci = (INT) measParams[TM::MEAS_SW_DECI];
DSP_RF_DECIMATE(cData, swDeci, &numValidPts);
```

The results could be printed to the report window as follows:

```
cout << "Valid Result Samples " << numValidPts << endl;
```
