# SPMU_PIN_TASK.vSlewRate()

Sets the force voltage slew rate.

This member function is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

The force voltage slew rate is used to modify the rise time and the fall time when the force voltage is changed. The slew rate has no effect if the clamp voltage is changed.

 Note XPS256 pins, the slew rate settings are applied only in connected mode. The maximum slew rate, limited by the programmed bandwidth, is applied when a disconnected channel is connected. We recommend therefore connecting an AVI64 or FVI16 channel with the forced value set to 0 V or 0 A respectively and changing the forced value to the target value after the channel has been connected. The bandwidth can be set by test method APIs [SPMU_PIN_TASK.vFilter()](<02.07.04.01.234.01.33_SPMU_PIN_TASK.vFilter.md>) and [SPMU_PIN_TASK.iFilter()](<02.07.04.01.234.01.13_SPMU_PIN_TASK.iFilter.md>) or by SmartRDI functions [rdi.dc().vFilter()](<02.07.13.12.02.40_vFilter.md>) or [rdi.dc().iFilter](<02.07.13.12.02.15_iFilter.md>).

## Syntax

```
SPMU_PIN_TASK& vSlewRate (const DOUBLE vSlewRate);
```

Parameter
 | Parameter  | Description |
 | vSlewRate  | Defines the voltage slew rate in Volts per microsecond (V / µsec).

Programmable double values are

- Value between the card-specific minimum and maximum value: The slew rate is set to the defined value.
- 0.0: The slew rate is set to the card-specific default value.
Card-specific range and default value:

- XPS256: Refer to section [Dynamic behavior](<../02.05_Test_Head_Cards/02.05.05.03.10.09_XPS256_programming_-_Force_and_clamp_voltages.md#_354305__s_Dynamic_behavior>) in [XPS256 programming - Force and clamp voltages](<../02.05_Test_Head_Cards/02.05.05.03.10.09_XPS256_programming_-_Force_and_clamp_voltages.md>).
 |

## Return value

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.

## Example

The following example shows how to set the force voltage slew rate.

```
SPMU_TASK spmuTask_1;

spmuTask_1.pin("...")
    .mode("VFIM")
    ...
    ...
    .vSlewRate(20 mV) // [V/us]
    ;
```

Note: The example concentrates on the function described in this topic. More settings are required for an executable SPMU_TASK object.
