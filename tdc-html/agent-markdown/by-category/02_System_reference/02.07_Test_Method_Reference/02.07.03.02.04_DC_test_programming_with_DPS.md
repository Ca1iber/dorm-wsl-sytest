# DC test programming with DPS

#### Subtopics

- [Using the "wait" Settling Time Within a DPS_TASK](<02.07.03.02.04.01_Using_the__wait__Settling_Time_Within_a_DPS_TASK.md>)
- [DPS measurement with external trigger](<02.07.03.02.04.02_DPS_measurement_with_external_trigger.md>)

To program a DC test with DPS, you can use the [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) and [DPS_PIN_TASK](<02.07.04.01.50.01_DPS_PIN_TASK.md>) API.

## Procedure

-  Setting up measurement conditions

To set up measurement conditions, first, define a class object of the [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) API as shown below:

```
DPS_TASK obj;
```

To set up measurement conditions for each pin, use the member functions of the [DPS_PIN_TASK](<02.07.04.01.50.01_DPS_PIN_TASK.md>) class that is called as a subsidiary data container of the [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) API as shown below:

```
obj.pin("pinName").func1.func2...funcN;
```

where, `pin("pinName")` is a member function of the [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) API to specify the target pin or pins to be set up. `func1-N` are the member functions of the [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) or [DPS_PIN_TASK](<02.07.04.01.50.01_DPS_PIN_TASK.md>) class.

-  Performing a measurement

Use the `execute()` member function of the DPS_TASK API as below:

```
obj.execute();
```

You can also add the DPS_TASK object to a TASK_LIST and execute it together with other DC measurement.

```
TASK_LIST task_obj;
task_obj.add(obj).execute();
```

-  Retrieving measurement result

Use the result-retrieving member functions of DPS_TASK API to get the measurement result.

```
result = obj.func;
```

Where func is one of the result-retrieving member functions, `getPassFail()`, `getValue()`, `getValues()`, `getWaveform()` or `getFunctionalResult()`.

-  Judging the result and data logging

You can judge the test result with the [TESTSET](<02.07.04.01.244_TESTSET.md>) API like below:

```
TESTSET().judgeAndLog_Dps(obj);
```

The member function performs data logging if the system flag "log_events_enable" and either test suite flag "output_on_pass" or test suite flag "output_on_fail" is "on".

## Example

The following example performs a DPS global pass/fail measurement on pin Vcc and Vee with the current primary set.

```
DPS_TASK dpsTask;
static STRING tsName;
ON_FIRST_INVOCATION_BEGIN();
  CONNECT();
  GET_TESTSUITE_NAME(tsName);
  dpsTask.pin("Vcc").min(0 A).max(0.1 A);
  dpsTask.pin("Vee").min(0 A).max(0.2 A);
  dpsTask.execMode(TM::GPF);
  dpsTask.trigMode(TM::INTERNAL);
  dpsTask.execute();
ON_FIRST_INVOCATION_END();
TESTSET().judgeAndLog_Dps(dpsTask);
```
