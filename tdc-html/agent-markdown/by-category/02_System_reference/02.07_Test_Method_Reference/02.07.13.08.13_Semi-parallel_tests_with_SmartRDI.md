This section describes semi-parallel tests with SmartRDI.

SmartRDI supports semi-parallel tests in three ways:

- [Test suite level](<02.07.13.08.13.01_Test_suite_level.md>)
- [Test block level](<02.07.13.08.13.02_Test_block_level.md>)
- [Pattern-based mode](<02.07.13.08.13.03_Pattern-based_semi-parallel_test.md>)
 For [Test block level](<02.07.13.08.13.02_Test_block_level.md>) and [Pattern-based mode](<02.07.13.08.13.03_Pattern-based_semi-parallel_test.md>), if you use FOR_SEMI_PARALLEL_TEST_BEGIN()/FOR_SEMI_PARALLEL_TEST_END() or RDI_SEMI_PARALLEL_TEST_BEGIN()/RDI_SEMI_PARALLEL_TEST_END(), you must set the following two items under the Site Control of the test suite property in advance:

- Select the Allow Parallel check-box.
- Set Site Control to PARALLEL.

## Functional changes

- Introduced in SmartRDI 2.4.3
