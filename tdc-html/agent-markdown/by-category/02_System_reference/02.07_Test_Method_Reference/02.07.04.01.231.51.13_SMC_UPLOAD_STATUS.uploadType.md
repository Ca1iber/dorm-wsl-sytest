# SMC_UPLOAD_STATUS.uploadType()

Returns the upload type of an SMC task that is stored in a vector which is populated by [SMC_GET_UPLOAD_STATUS()](<02.07.04.01.231.16_SMC_GET_UPLOAD_STATUS.md>).

## Syntax

```
const STRING& uploadType() const;
```

List of parameters

There are no parameters.

## Return value

The type of the upload task.

Possible types are: VectorUploadTask`, `WaveformUploadTask`, `HiddenExecutionTask, UploadTask`.`

## Example

This example shows how to create a vector of type `SMC_UPLOAD_STATUS` and how to retrieve the type of upload from the vector.

Note As `SMC_UPLOAD_STATUS` represents a collection, one has to iterate over the collection to obtain the item.

```
typedef vector<SMC_UPLOAD_STATUS> SmcUploadStatusVector;
string UpLoadType;

// Obtain the collection
SmcUploadStatusVector statusVector = SMC_GET_UPLOAD_STATUS();

// iterate through collection
for(SmcUploadStatusVector::iterator it = statusVector.begin();
     it != statusVector.end(); ++it) {
        UploadType = it->uploadType();
        cout << "SMC upload type:" << UploadType << endl;
     }
```
