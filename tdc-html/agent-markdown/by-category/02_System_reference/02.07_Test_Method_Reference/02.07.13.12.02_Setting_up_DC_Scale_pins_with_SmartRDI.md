SmartRDI supports both static and dynamic DC tests with DC Scale cards. Both the PMU (SIG) operating mode and the DPS operating mode are supported.

## Code-based mode and pattern‑based mode

In the static code‑based mode, the level setting is changed. The following list shows a selection of functions that are provided for the code‑based mode:

`vForce()`, `iForce()`, `vMeas()`, `iMeas()`, `relay()`, `vForceRange()`, `iForceRange()`, `vMeasRange()`, `iMeasRange()`, `average()`, `clamp()`, `measWait()`, `connectSense()`, `ungang()`, `preCharge()`, [execute()](<02.07.13.08.01.02_execute.md>).

In the dynamic pattern‑based mode, test points will be created in the pattern. The following list shows a selection of functions that can be used in the pattern‑based mode:

`iForce()`, `vForce()`, `iMeas()`, `vMeas()`, `vForceRange()`[1)](<#_141515__fn1>), `iForceRange()`[1)](<#_141515__fn1>), `iMeasRange()`, `vMeasRange()`, `restoreRange()`[2)](<#fntarg_2>), `average()`, `clamp()`[3)](<#fntarg_3>), `measWait()`, and [execute()](<02.07.13.08.01.02_execute.md>).

Relays cannot be switched in the pattern‑based mode. So make sure the relay connection is programmed in the code‑based mode and is correct before the burst execution of the pattern‑based mode.

## Order of setting parameters

In DC test, multiple functions are often used together to set up a certain DC Scale pin. For example:

```
rdi.dc().pin("DCS_PIN").vForce(1.3 V).clamp(-195 mA).iMeasRange(200 mA).average(8).iMeas().measWait(0.5*1 ms).execute();
```

These functions can be arranged in an arbitrary order after pin(), but SmartRDI always follows its own order of setting parameters as follows:

## Connecting DC Scale signal pins

Function [connect()](<02.07.13.12.01.03.03_connect.md>) is to be used only for DC Scale pins that are configured for the DPS operating mode in the [DPS Pins editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.03_DPS_Pins_editor.md>).

There is no connect() function for DC Scale signal pins in the PMU (SIG) operating mode. Use [iForce()](<02.07.13.12.02.16_iForce.md>) or [vForce()](<02.07.13.12.02.41_vForce.md>) to connect a pin.

## Measurements and relay settings

The measurement functions [iMeas()](<02.07.13.12.02.18_iMeas.md>) and [vMeas()](<02.07.13.12.02.43_vMeas.md>) are supported for both the code‑based mode and the pattern‑based mode. Controlling the relays differs for the two modes:

- Code-based mode: Functions [iForce()](<02.07.13.12.02.16_iForce.md>) or [vForce()](<02.07.13.12.02.41_vForce.md>) are to be used to connect a DC Scale pin in the PMU operating mode. Three more issues are to be considered in this mode:

  - The pin remains connected until the function [disconnect()](<02.07.13.12.01.03.04_disconnect.md>) is executed for the pin.
  - The first code‑based measurement must be separated from the initial [iForce()](<02.07.13.12.02.16_iForce.md>) or [vForce()](<02.07.13.12.02.41_vForce.md>) that connects the pin or the pin will be disconnected immediately after the measurement: The initial force function and the code‑based measurement must be placed in separate RDI command lines, each terminated with function [execute()](<02.07.13.08.01.02_execute.md>).
  - Code-based measurements and the force functions can be combined in one RDI command line if the pin is already connected.

- Pattern-based mode: Relays are not changed in the pattern‑based mode. The measurement functions define just test points in the pattern.

Starting from SmartRDI 7.5.2, some execution times are changed:

- For AVI64: The setting time of rdi.dc().pin(pin).iMeas()/vMeas() is changed from 1 us to maximum (1 us, 8 cycles). This is important for slow cycle times.
-  For FVI16:

  - rdi.dc().pin(pin).iMeas()/vMeas(): The settling time is changed from 1 us to maximum (1 us, 8 cycles). This is important for slow cycle times.
  - Force mode change between vForce and iForce: 0 us to 10 u

## Examples

### PMU (SIG) operating mode

```
rdi.dc().pin("DCS_SIG").vForce(2 V).vForceRange(25 V).iForceRange(100 uA).execute();

RDI_BEGIN();

    rdi.dc().pin("DCS_SIG").iMeasRange(100 uA).execute();
    rdi.dc().pin("DCS_SIG").vForce(10 V).execute();
    rdi.dc().pin("DCS_SIG").iMeas().execute();
    rdi.dc().pin("DCS_SIG").vForce(8 V).execute();
    rdi.dc().pin("DCS_SIG").iMeas().execute();

RDI_END();

rdi.dc().pin("DCS_SIG").disconnect().execute();
```

### DPS operating mode

```
rdi.dc().pin("DCS_DPS").connect().execute();

RDI_BEGIN();

    rdi.dc().pin("DCS_DPS").vForce(10 V).execute();
    rdi.dc().pin("DCS_DPS").iMeas().execute();
    rdi.dc().pin("DCS_DPS").vForce(8 V).execute();
    rdi.dc().pin("DCS_DPS").iMeas().execute();

RDI_END();

rdi.dc().pin("DCS_DPS").disconnect().execute();
```
