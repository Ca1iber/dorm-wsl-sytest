# ARRAY_I

ARRAY_I defines an array holding the INT type of data and defines the functions to access and process the data.

## Constructors

```
ARRAY_I (INT size);
```

This constructs an object of ARRAY_I with the specified fixed size. If a size larger than zero is specified, the memory for the specified number of elements is allocated and the array cannot be resized.

```
ARRAY_I (const ARRAY_I& array);
```

This constructs an unresizable object of ARRAY_I by copying from another ARRAY_I object.

```
ARRAY_I (const ARRAY_I& array, INT size, INT offset= 0);
```

This constructs an unresizable object of ARRAY_I by sharing the specified elements from another ARRAY_I object.

```
ARRAY_I (INT* array, INT size, INT offset= 0);
```

This constructs an unresizable object of ARRAY_I by sharing the specified elements from a double array.

Parameters
 |

array

 |

The array to copy from.

 |
 |

size

 |

Size of the new ARRAY_I object.

 |
 |

offset

 |

(optional) Starting point in original array where to begin copying the elements.

 |

## Member functions

### init()

```
void init (INT initValue= 0);
```

This function fills the array elements with the specified value.

Parameter
 |

initValue

 |

Value with which to fill the array. Default is 0.

 |

### resize()

```
INT resize (INT size);
```

This function changes the size of the array if it is resizable and keeps its data.

Parameter
 |

size

 |

New size of the array

 |

### size()

```
const INT size () const;
```

This function returns the size of the array.

### capacity()

```
const INT capacity();
```

This function returns the memory size allocated to the array.

### operator =

```
ARRAY_I& operator = (const ARRAY_I& array);
```

This operator copies all the elements of the specified array to the current array and changes its size.

Parameter
 |

array

 |

The array to copy from

 |

### operator []

```
INT& operator [] (const INT index);
const INT& operator [] (const INT index) const;
```

This operator accesses the specified element in the array.

Parameter
 |

index

 |

Index of the element to access

 |

### operator const INT* ()

```
operator const INT* () const;
```

This operator converts the data type ARRAY_I to INT *.

### operator==

```
bool operator== (const ARRAY_I&) const;
```

This operator compares two array objects and judges whether they are the same.

## Example

```
ARRAY_I a_i1;
ARRAY_I a_i2(1024);
for (INT j=0; j < 1024; j++)
  a_i2[j]=j;
a_i1.resize(200);
ARRAY_I a_i3 (a_i2, 100, 30);
cout << a_i3 <<endl;
```

Three variables of ARRAY_I are defined in this example. `a_i1` is defined with zero buffer and can be resized. `a_i2` is defined with fixed 1024 buffers and cannot be resized. `a_i3` is defined with 100 elements from `a_i2` and its elements are printed to the UI report window.
