# vForce()

Specifies a voltage to force.

In the code‑based mode, it also closes the relay to output the voltage for the pin in the PMU (SIG) mode.

## Syntax

```
vForce(dCouble dV);
vForce(const string& sData);
vForce(string SpecName,TA::LEVEL_SPEC);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

dV

 |

The voltage to force.

 |
 |

sData

 |

The string containing the value to be used at runtime.

 |
 | SpecName  | The spec variable name in Level setup. |

## Example

```
RDI_BEGIN();
  rdi.dc().pin("pinA").vForce(2.5 V).execute();
  rdi.dc().pin("VDD_1").vForce("VDD",TA::LEVEL_SPEC).execute();
RDI_END();
```
