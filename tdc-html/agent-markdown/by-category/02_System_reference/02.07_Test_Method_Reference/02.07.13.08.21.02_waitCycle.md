# waitCycle()

Specifies the number of cycles to wait.

## Syntax

```
void waitCycle(unsigned long long iCycle);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

iCycle

 |

The number of cycles.

 |

## Example

```
rdi.waitCycle(10);
```
