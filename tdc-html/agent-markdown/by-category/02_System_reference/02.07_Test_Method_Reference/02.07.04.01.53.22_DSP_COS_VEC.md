# DSP_COS_VEC

This API computes the cosine of the elements in a specified array.

This API computes the cosine of the specified elements in src, and returns the results to the corresponding elements of result as follows:

result [i] = cos(src [i] )

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_COS_VEC(ARRAY_D& src, ARRAY_D& result);
DSP_COS_VEC(DOUBLE *src, DOUBLE *result,
            INT size);
```

## Example

```
double array1[25],array2[25];
  .
  .
DSP_COS_VEC(array1, array2, 25);
```

DSP_COS_VEC computes the cosine of the first 25 elements in the array array1, and returns the results to the corresponding elements of the array array2 as follows:

```
int i;
for(i=0; i<25; i++)
array2[i] = cos(array1[i]);
```
