# DSP_LOG10_VEC

This API computes the common logarithm (base 10) of the elements in a specified array.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_LOG10_VEC(ARRAY_D& src, ARRAY_D& result);
DSP_LOG10_VEC(DOUBLE *src, DOUBLE *result,
                    INT size);
```

## Example

```
double array1[50],array2[25];
  .
  .
DSP_LOG10_VEC(array1, array2, 25);
```

DSP_LOG10_VEC computes the common logarithm of the first 25 elements in the arrayarray1, and returns the results to the corresponding elements of the arrayarray2as follows:

```
int i;
for(i=0; i<25; i++)
 array2[i] = log(array1[i])/log(10.0);
```
