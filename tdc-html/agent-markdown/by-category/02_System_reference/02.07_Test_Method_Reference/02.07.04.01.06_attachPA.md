# attachPA()

This function is used to attach PA pattern to the MPB (Assembled the multiport burst).

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
void attachPA();
```

## Example

```
CCTMultiportSync    Sync;
GET_TESTSUITE_NAME(tsName);
CCTtsName = CCTgetTestsuiteName();
Sync.registerCCTestMethod(tsName, this);

//set PA port. Need add tsName for getInstance otherwise loop test will show error
Lshift::getInstance(tsName).setPort("port_PA");
Lshift::getInstance(tsName).setIdentifier(tsName);
Sync.registerSyncPort(Lshift::getInstance(tsName));

Sync.start();

Lshift::getInstance(tsName).write(write_str);
Lshift::getInstance(tsName).read();

Sync.sync();
Sync.flush();
......

        Sync.attachPA();

Sync.dumpMPBGraph();
```
