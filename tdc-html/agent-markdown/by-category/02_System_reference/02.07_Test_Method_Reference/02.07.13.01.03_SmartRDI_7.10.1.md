# SmartRDI 7.10.1

This section summarizes software changes including new features and enhancements in SmartRDI 7.10.1.

Changes and new features
 | Category  | Description |
 | [DC](<02.07.13.12.02_Setting_up_DC_Scale_pins_with_SmartRDI.md>)  | New static commands for setting DC Scale pins:

- [forceDropWarn()](<02.07.13.12.02.09_forceDropWarn.md>)
- [hiAccuracy()](<02.07.13.12.02.10_hiAccuracy.md>)
- [iClampTimeToAlarm()](<02.07.13.12.02.13_iClampTimeToAlarm.md>)
- [iClampTimeToDisconnect()](<02.07.13.12.02.14_iClampTimeToDisconnect.md>)
- [loadStepMode()](<02.07.13.12.02.27_loadStepMode.md>)
- [pulldown()](<02.07.13.12.02.33_pulldown.md>)
- [returnDropWarn()](<02.07.13.12.02.37_returnDropWarn.md>)

In SmartRDI 7.10.1, these member functions only support [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) in the [PMU operating mode](<../02.05_Test_Head_Cards/02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md>).

[iClamp()](<02.07.13.12.02.11_iClamp.md>) for [DC Scale pin setups](<02.07.13.12.02_Setting_up_DC_Scale_pins_with_SmartRDI.md>) supports the HAC IF mode for XPS256 cards.

 |

## Supported SmarTest versions

SmartRDI 7.10.1 supports SmarTest 7.10.1.
