The EVENT_CFIM (Current Force / Current Measurement) is a combined force current / current measure event class. This class provides the combined functionality of setting and measurement events in a single event.

This class is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) in PMU operating mode.

## Class definition

The class derives from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

The object that is created by this class has to be assigned to the [PATTERN_CONTROLLER](<02.07.04.01.142_PATTERN_CONTROLLER.md>) which is responsible for further handling.

This class is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

EVENT_CFIM (const STRING & id);

## Automatic down-ranging

DPS128 and XPS256 support automatic down-ranging current measurements.

Automatic down-ranging means that the current range is automatically changed to the best fit range for the measurement and restored to the original range after the measurement.

 Two parameters define whether the automatic down-ranging is performed or not:

- The force current or clamp current range:

  - Can be set explicitly or (if not defined)
  - is automatically derived from the forced or clamped value.

- The current measurement range:

  - Can be set explicitly or (if not defined)
  - is automatically derived from the pass/fail thresholds.

Automatic down-ranging is performed only if the current measurement range is lower than the force / clamp current range regardless whether the ranges have been set explicitly or have been selected automatically. For more information, refer to

- [DPS128鈥? DPS64 specific setup tasks](<../02.05_Test_Head_Cards/02.05.05.01.09_DPS128____PS64_specific_setup_tasks.md>) and [DC Scale DPS128/64 HC/HV Cookbook](<../../03_Use_cases_and_application_papers/03.06_DC_Scale_Cards_Use_Cases/03.06.01_DC_Scale_DPS128_64_HC_HV_Cookbook.md>) - Section 4.2.1
- [XPS256 measure currents](<../02.05_Test_Head_Cards/02.05.05.03.07.02_XPS256_measure_currents.md>) and [XPS256 programming - Measure currents](<../02.05_Test_Head_Cards/02.05.05.03.10.13_XPS256_programming_-_Measure_currents.md>)

## Example

The following example creates three new DC events, sets the data of the DC events and inserts the DC events into an already existing pattern. The programmed data are then read back from the event objects and shown in the console window.

event_CFIM_1 uses member functions limitLow() and limitHigh() to define the limits.

event_CFIM_2 uses the class LIMIT and the member function limits() to define the limits.

event_CFIM_3 uses member functions limitLow() and limitHigh() to define the limits but the limits are cleared by member function clearLimits() to demonstrate how this function works.

```
PATTERN_CONTROLLER patController;

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Create new event objects
    //
    EVENT_CFIM event_CFIM_1 ("CFIM_1");
    EVENT_CFIM event_CFIM_2 ("CFIM_2");
    EVENT_CFIM event_CFIM_3 ("CFIM_3");

    //
    // Set the event data
    //
    event_CFIM_1
        .cForce             (30.0 mA)
        .averages           (50)
        .outOfRangeCheck    (true)
        .clampChecks        (true, false)
        .limitLow           (15.0 mA)
        .limitHigh          (20.0 mA);

    LIMIT event_CFIM_2_limits;

    event_CFIM_2_limits.low     (TM::GE, 17.0 mA);
    event_CFIM_2_limits.high    (TM::LE, 22.0 mA);
    event_CFIM_2_limits.unit    ("mA;-3;mA;-3");

    event_CFIM_2
        .cForce             (32.0 mA)
        .averages           (50)
        .outOfRangeCheck    (true)
        .clampChecks        (false, true)
        .limits             (event_CFIM_2_limits);

    event_CFIM_3
        .limitLow           (15.0 mA)   // Cleared with clearLimits()
        .limitHigh          (20.0 mA)   // Cleared with clearLimits()
        .clearLimits        ();

    //
    // Insert the events into a pattern
    //
    PATTERN & pattern = patController.label("...", "@");

    pattern.vecEvents("pin1").clearAll();

    pattern.vecEvents("pin1")
        .insert(100, event_CFIM_1)
        .insert(150, event_CFIM_2)
        .insert(200, event_CFIM_3)
        .setup ();

    //
    // Read data from the event object
    //
    EVENT_VALUE_DOUBLE  forceValue_1, lowLimit_1, highLimit_1;
    EVENT_VALUE_INT     averages_1;
    bool                lowLimitDefined_1, highLimitDefined_1, outOfRangeCheck_1;
    bool                clampCheckLow_1, clampCheckHigh_1;

    event_CFIM_1.getCForce          (forceValue_1);
    event_CFIM_1.getAverages        (averages_1);
    event_CFIM_1.getOutOfRangeCheck (outOfRangeCheck_1);
    event_CFIM_1.getClampChecks     (clampCheckLow_1, clampCheckHigh_1);

    lowLimitDefined_1  = event_CFIM_1.getLimitLow   (lowLimit_1);
    highLimitDefined_1 = event_CFIM_1.getLimitHigh  (highLimit_1);

    cout << "forceValue_1          = " << forceValue_1                                      << endl;
    cout << "averages_1            = " << averages_1                                        << endl;
    cout << "outOfRangeCheck_1     = " << outOfRangeCheck_1                                 << endl;
    cout << "clampCheckLow_1       = " << clampCheckLow_1                                   << endl;
    cout << "clampCheckHigh_1      = " << clampCheckHigh_1                                  << endl;
    cout << "lowLimit_1  (defined) = " << lowLimit_1  << " (" << lowLimitDefined_1  << ")"  << endl;
    cout << "highLimit_1 (defined) = " << highLimit_1 << " (" << highLimitDefined_1 << ")"  << endl;
    cout << endl;

    EVENT_VALUE_DOUBLE  lowLimit_2, highLimit_2;
    bool                lowLimitDefined_2, highLimitDefined_2;

    lowLimitDefined_2  = event_CFIM_2.getLimitLow   (lowLimit_2);
    highLimitDefined_2 = event_CFIM_2.getLimitHigh  (highLimit_2);

    cout << "lowLimit_2  (defined) = " << lowLimit_2  << " (" << lowLimitDefined_2  << ")"  << endl;
    cout << "highLimit_2 (defined) = " << highLimit_2 << " (" << highLimitDefined_2 << ")"  << endl;
    cout << endl;

    EVENT_VALUE_DOUBLE  lowLimit_3, highLimit_3;
    bool                lowLimitDefined_3, highLimitDefined_3;

    lowLimitDefined_3  = event_CFIM_3.getLimitLow   (lowLimit_3);
    highLimitDefined_3 = event_CFIM_3.getLimitHigh  (highLimit_3);

    cout << "lowLimit_3  (defined) = " << lowLimit_3  << " (" << lowLimitDefined_3  << ")"  << endl;
    cout << "highLimit_3 (defined) = " << highLimit_3 << " (" << highLimitDefined_3 << ")"  << endl;
}
ON_FIRST_INVOCATION_END();
```
