The SmartRDI Vector class supports the generation of vector and patterns with simple commands. It provides an easy way to read digital outputs of a device.

The typical vector and pattern operations you can perform using the smart vector class are listed below:

- 3 different data input options for the pattern creation (data block, bit stream, vector stream).
- Automatic handling of the x mode and 1/x mode.
- Creation of patterns with structured burst data.
- Creation of patterns with a parallel data burst for multiple ports.
- Creation of big patterns for a series of pattern creation commands.
- Data retrieval is handled in different ways for test time optimization (digital capture and error map).
- The number of upload actions is minimized in case of multiple data retrievals.

The vector generation class provides APIs and commands for different "layers": Vector layer, stream layer and data block layer.
