# SPMU_TASK.execute()

Executes the DC measurement with the settings defined by the member functions of [SPMU_TASK](<02.07.04.01.234_SPMU_TASK.md>). If the settings have not been downloaded to the firmware already it first performs a [SPMU_TASK.setup()](<02.07.04.01.234.09_SPMU_TASK.setup.md>).

 Note If the pins defined for this measurement are within the same card cage, the measurement will be executed sequentially per pin!

## Syntax

```
void execute();
virtual void execute(const string& measurementName)
```

Parameter
 |

Parameter

 |

Description

 |
 |

measurementName

 |

The measurementName is used with the Offline Result Emulation (ORE) feature of SmarTest. It refers to the corresponding offline measurement result specified in the ORE setup file.

 |

Return value

There is no return value.

Note To retrieve results use the [SPMU_TASK.getPassFail()](<02.07.04.01.234.05_SPMU_TASK.getPassFail.md>) or [SPMU_TASK.getValue()](<02.07.04.01.234.06_SPMU_TASK.getValue.md>) functions.
