# TESTSET().testsuite()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) lets you specify a test suite for determining the limits and the test numbers as well as for logging purposes.

The limits and test numbers for the executed test are taken from the specified test suite (instead of the default test suite). The specified test suite is is also logged in the [TestSuiteNameAttrType](<../02.10_Data_Logging/02.10.01.06.05.64_TestSuiteNameAttrType.md>) attribute of a [TestEventType](<../02.10_Data_Logging/02.10.01.06.03.12_TestEventType.md>) value instead of the default test suite.

## Syntax

```
TESTSET & testsuite(const STRING &name);
```

 |

Parameter

 |

Description

 |
 |

name

 |

The name of the test suite that you wish to use as the source for test limits and test numbers and include in the data log.

Note that the test suite name must be listed in the test table.

 |

## Example

```
TestSet.testsuite("Functional_test");
```
