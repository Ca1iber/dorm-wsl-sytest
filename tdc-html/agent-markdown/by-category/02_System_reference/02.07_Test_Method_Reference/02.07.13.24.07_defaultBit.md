# defaultBit()

The bits which are not covered by writeBit() and fillBit() in one pattern will be filled with the specified value of the defaultBit(). If you do not specify the defaultBit(), RDI will automatically specify those bits with "f" or the value of "DEFAULT_STATUS_INDEX" in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>) . The generic recommendation is to specify defaultBit() for each pin.

## Syntax

```
defaultBit(int bit);
defaultBit(string bit);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

bit

 |

The bit or string you want to write into the pattern.

 |

## Example

```
RDI_BEGIN();
  rdi.smartVec().pin("DATA1").bitLength(20).defaultBit(0).execute();
RDI_END();
```

Supporting a string

```
RDI_BEGIN();
  rdi.smartVec().pin("DATA1").bitLength(20).defaultBit("L").execute();
RDI_END();
```
