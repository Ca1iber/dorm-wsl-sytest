# RDI_BURST_POSTFIX

This testflow string variable specifies a name to be appended to the names of all SmartRDI-generated burst patterns in the testflow.

Set up this string variable in the [Flow Data Editor](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.01_Flow_Data_Editor.md>). As an option in the [Editor](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.01_Flow_Data_Editor.md>), this testflow variable differentiates the burst pattern generations from different testflows in which the test suite names can be the same..

When BURST_NAME_MD5 = TRUE is set in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>), an MD5 postfix is used to differentiate patterns; and then this RDI_BURST_POSTFIX variable option is no longer required.
