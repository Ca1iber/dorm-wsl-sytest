# CCTgetPAResultId()

Retrieves the remembered PA result id list (remembered using the [CCTaddPAResultId()](<02.07.04.01.14.01_CCTaddPAResultId.md>) API).

## Syntax

vector<string>& CCTgetPAResultId();

## Example

```
virtual void init()
{
    vector<string> resultID = CCTgetPAResultId();
          PROTOCOL_TEST_RESULT_VECTOR result;
result = 2ndWapper::getInstance(tsName).getPAImpResults(resultID);

}
```
