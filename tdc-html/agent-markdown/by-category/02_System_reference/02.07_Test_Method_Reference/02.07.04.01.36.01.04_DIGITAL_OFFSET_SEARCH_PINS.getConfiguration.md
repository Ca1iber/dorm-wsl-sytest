# DIGITAL_OFFSET_SEARCH_PINS.getConfiguration()

Gets the offset search configurations for pins specified with [DIGITAL_OFFSET_SEARCH_TASK.pin()](<02.07.04.01.36.03_DIGITAL_OFFSET_SEARCH_TASK.pin.md>).

## Syntax

```
void getConfiguration(DIGITAL_OFFSET_SEARCH::[DigitalOffsetSearchConfigDataType](<02.07.04.01.36.01.32_DigitalOffsetSearchConfigDataType.md>) & configdata);
```

Parameter
 |

Parameter

 |

Description

 |
 |

configdata

 |

A data used for storing the retrieved configurations, such as search type, resource type, start value, and stop value. See more data type in [DigitalOffsetSearchConfigDataType](<02.07.04.01.36.01.32_DigitalOffsetSearchConfigDataType.md>).

 |

Return value

There is no return value.
