# TIMING_OFFSET_SEARCH_PINS.getTimingOffset()

This function returns the timing offset of the specified spec ID/spec variable,timing set and edge type from the internal cache. If you retrieve the timing offset of multiple pins and the pins have different settings, the exception `TESTMETHOD_API::AmbiguityException` will be issued.

## Syntax

```
DOUBLE getTimingOffset(TIMING_OFFSET_SEARCH::TimingSetSelector& target, TIMING_OFFSET_SEARCH::EDGE_TYPE edge);
DOUBLE getTimingOffset(INT specId,INT timingSet, TIMING_OFFSET_SEARCH::EDGE_TYPE edge);
DOUBLE getTimingOffset(const STRING& specStr, INT timingSet, TIMING_OFFSET_SEARCH::EDGE_TYPE edge);
```

Parameters
 |

specId

 |

In fixed timing setup, it is the waveform set number.

In equation based timing setup, it is a timing specification ID calculated as follows:

`100*equation_set_no + specset_no`

 |
 |

specStr

 |

The spec variable to query.

 |
 |

timingSet

 |

The timing set to query.

 |
 |

edge

 |

The edge type to query. It can be:

- TIMING_OFFSET_SEARCH::RECEIVE: receive edges
- TIMING_OFFSET_SEARCH::FAST_DRIVE: fast drive edges
- TIMING_OFFSET_SEARCH::SLOW_DRIVE: slow drive edges
- TIMING_OFFSET_SEARCH::DRIVE: drive edges
- TIMING_OFFSET_SEARCH::ALL_EDGES: all edges
 |

## Functional changes

- Introduced in SmarTest 7.0.1
