# EVENT_WAVEFORM_CFIM.getCForce()

Queries the force current waveform that has been defined by [EVENT_WAVEFORM_CFIM.cForce()](<02.07.04.01.63.28.01_EVENT_WAVEFORM_CFIM.cForce.md>).

The waveform is read from the corresponding [EVENT_WAVEFORM_CFIM](<02.07.04.01.63.28_EVENT_WAVEFORM_CFIM.md>) object and returned as an [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
const ARRAY_D & getCForce() const;
```

List of parameters

There are no parameters.

## Return value

An [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>) object containing the waveform samples that are defined in A (Ampere).
