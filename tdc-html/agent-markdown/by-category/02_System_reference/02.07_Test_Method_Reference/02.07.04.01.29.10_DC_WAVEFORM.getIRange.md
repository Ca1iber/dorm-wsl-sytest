# DC_WAVEFORM.getIRange()

This function returns the input current range of a DC waveform.

## Syntax

```
void getIRange(DOUBLE & iRange) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

iRange

 |

The parameter returns the value of input current range for a DC waveform specified by the [DC_WAVEFORM.iRange()](<02.07.04.01.29.09_DC_WAVEFORM.iRange.md>) function.

 |

Return value

There is no return value.
