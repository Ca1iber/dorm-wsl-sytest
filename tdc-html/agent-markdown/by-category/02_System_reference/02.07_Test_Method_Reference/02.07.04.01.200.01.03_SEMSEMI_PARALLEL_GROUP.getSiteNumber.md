# SEMSEMI_PARALLEL_GROUP.getSiteNumber()

Gets the number of sites in the semi-parallel group.

## Syntax

```
int getSiteNumber() const;
```

List of parameters

There are no parameters.

## Return value

The number of sites in this semi-parallel group is returned.

## Functional changes

- Introduced in SmarTest 7.2.0
