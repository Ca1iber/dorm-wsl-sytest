To do the static DC measurement with SPMU, the class dc() and the following functions are provided.

## Overview of dc() class functions for SPMU setups

 | API  | Description  | Mode |
 | [average()](<02.07.13.12.01.03.01_average.md>)  | Specify a sample number to do the averaging.  | P, C |
 | [clamp()](<02.07.13.12.01.03.02_clamp.md>)  | Specify a clamp voltage or current.  | P |
 | [connect()](<02.07.13.12.01.03.03_connect.md>)  | Connect a DPS pin.  | C |
 | [disconnect()](<02.07.13.12.01.03.04_disconnect.md>)  | Open the Force/Sense relay of a DC Scale pin.  | C |
 | [iForce()](<02.07.13.12.01.03.05_iForce.md>)  | Specify a current to force.  | P, C |
 | [iMeas()](<02.07.13.12.01.03.06_iMeas.md>)  | Create a current measurement.  | P, C |
 | [iMeasRange()](<02.07.13.12.01.03.07_iMeasRange.md>)  | Specify a range of current for a measurement with SPMU.  | p |
 | [iRange()](<02.07.13.12.01.03.08_iRange.md>)  | Specify a range of current to measure.  | P, C |
 | [measWait()](<02.07.13.12.01.03.09_measWait.md>)  | Specify a period of time to wait between the previous event and measuring the value.  | P, C |
 | [pin()](<02.07.13.12.01.03.10_pin.md>)  | Specify pin(s) for the subsequent DC actions.  | P, C |
 | [relay()](<02.07.13.12.01.03.11_relay.md>)  | Specify relay actions.   | P, C |
 | [vForce()](<02.07.13.12.01.03.12_vForce.md>)  | Specify a voltage to force.  | P, C |
 | [vMeas()](<02.07.13.12.01.03.13_vMeas.md>)  | Create a voltage measurement.  | P, C |
 | [getValue()](<02.07.13.12.01.01.23_getValue.md>)  | Retrieve the measured value for a pin.  | C |

## Example

```
ON_FIRST_INVOCATION_BEGIN();
  rdi.dc(0).pin("DATA1",TA::SPMU).iForce(2 mA).vMeas().execute();
ON_FIRST_INVOCATION_END();
double val;
val=rdi.id(0).getValue("DATA1");
```
