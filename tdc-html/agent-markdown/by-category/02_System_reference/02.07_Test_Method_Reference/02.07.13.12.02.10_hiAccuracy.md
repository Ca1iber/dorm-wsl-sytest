# hiAccuracy()

Selects for DC Scale XPS256 pins the high‑accuracy mode for voltage.

 Only the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) in the [PMU operating mode](<../02.05_Test_Head_Cards/02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md>) is supported:

- Forcing, clamping, and measuring voltage is performed in the 1.5 V voltage range: See the [XPS256 voltage specifications](<../02.02_Specifications/02.02.05.03.02_XPS256_voltage_specifications.md>).
- A license is required to use the 1.5 V range: See [High‑accuracy voltage mode](<../02.05_Test_Head_Cards/02.05.05.03.10.01_XPS256_specific_setup_tasks.md#_350709__s_High_accuracy_mode_for_voltage>) in [XPS256 specific setup tasks](<../02.05_Test_Head_Cards/02.05.05.03.10.01_XPS256_specific_setup_tasks.md>).
This function can be only used in the [code‑based mode](<02.07.13_SmartRDI.md#_142069__dle_Code-based_mode>).

The selection of the high‑accuracy voltage mode applies only to the current [RDI command](<02.07.13.05_Code_structure_with_SmartRDI.md#_142604__dle_RDI_command>).

## Syntax

```
dcBase& hiAccuracy();
```

  List of parameters There are no parameters. Return Value A reference to the dcBase object. Errors An error message is displayed in the UI report window if the high‑accuracy license is missing or is not enabled in the [DC Scale Extensions editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.05_DC_Scale_Extensions_editor.md>):

```
Connection state HC_HAC not supported or no license for pin ...
```

## Example

```
rdi.dc().pin("XPS256_PMU_1").iForceRange(50 mA).iForce(5.0 mA).vClamp(-5.0, 5.0 V).hiAccuracy().execute();
```

## Functional changes

- Introduced in SmartRDI 7.10.1
