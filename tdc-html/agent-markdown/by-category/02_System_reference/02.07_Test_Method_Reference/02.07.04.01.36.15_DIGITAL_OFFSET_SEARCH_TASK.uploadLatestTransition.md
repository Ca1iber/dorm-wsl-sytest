# DIGITAL_OFFSET_SEARCH_TASK.uploadLatestTransition()

Triggers the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) instance to upload the offsets at the fail-to-pass and pass-to-fail transition points (the offsets of the first and last passing values of the pass area) found in the latest transition search from the tester into the system controller.

To retrieve those offsets, use [DIGITAL_OFFSET_SEARCH_PINS.getLatestLBTransitionOffset()](<02.07.04.01.36.01.06_DIGITAL_OFFSET_SEARCH_PINS.getLatestLBTransitionOffset.md>), and [DIGITAL_OFFSET_SEARCH_PINS.getLatestRBTransitionOffset()](<02.07.04.01.36.01.07_DIGITAL_OFFSET_SEARCH_PINS.getLatestRBTransitionOffset.md>).

If you retrieve the offset on multiple pins and those pins have different settings, the exception TESTMETHOD_API::AmbiguityException will be issued.

## Syntax

```
void uploadLatestTransition();
```

List of parameters

There are no parameters.

Return value

There is no return value.
