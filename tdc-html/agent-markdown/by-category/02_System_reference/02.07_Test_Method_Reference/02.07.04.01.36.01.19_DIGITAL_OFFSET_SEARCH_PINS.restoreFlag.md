# DIGITAL_OFFSET_SEARCH_PINS.restoreFlag()

Enables or disables the restore flag.

If the restore flag is enabled, the timing or level offsets will have the values before the offset searches.

If the restore flag is disabled, the timing or level offsets will be modified according to the offset search:

- If the search type is EYE:

The offset will be set to the middle of eye, MV= (RB - LB)/2.

RB and LB are the right and left boundaries of the pass area.

- If the search type is RB or LB:

The offset will be set to the PASS value next to the FAIL value.

See the setup of search types in [DIGITAL_OFFSET_SEARCH_PINS.searchType()](<02.07.04.01.36.01.21_DIGITAL_OFFSET_SEARCH_PINS.searchType.md>).

- If the search does not find an eye, the offsets will not be changed.

## Syntax

```
DIGITAL_OFFSET_SEARCH_PINS& restoreFlag(DIGITAL_OFFSET_SEARCH::YES_NO restoreflag);
```

Parameter
 |

Parameter

 |

Description

 |
 |

restoreflag

 |

It can be:

- DIGITAL_OFFSET_SEARCH::YES: Enables the restore flag.
- DIGITAL_OFFSET_SEARCH::NO: (Default) Disables the restore flag.
 |

## Return value

A reference to the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) object.
