# rdi.id().getMultiArm()

Retrieves the multiple arm time of the same ID and saves it to an array of type ARRAY_D. The arm time is the time from the beginning of the used pattern to the position where the arming of the TMU is done. This time is the reference point for the following time stamper measurements.

Multiple arming events are supported only by digital pins. Only one arming event per pattern or pattern burst can be defined for the supported DC Scale pins.

## Syntax

```
ARRAY_D getMultiArm(const string &sPin);
```

List of parameters
 | Parameter  | Description |
 | sPin  | The pin to get the multiple arm time from. |

## Example

```
ON_FIRST_INVOCATION_BEGIN();

    RDI_BEGIN();

        rdi.tmu("result_2").label("tmu_label").pin("PS1600_1")
                .measMode(TA::RISE).vth(1.0 V)
                .insertVec(10).samples(50)
                .insertVec(20).samples(50).execute();

        rdi.wait(100 us);

    RDI_END();

ON_FIRST_INVOCATION_END();

ARRAY_D value_4 = rdi.id("result_2").getMultiArm("PS1600_1");
```
