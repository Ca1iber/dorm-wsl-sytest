# SlimBusController.activateSuperframeViewerOutput()

This function deactivates further actualization of the currently active Superframe Viewer files.

## Syntax

```
void deactivateRawViewerOutput();
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Functional changes

- Introduced in SmarTest 7.2.1
