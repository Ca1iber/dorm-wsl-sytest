# EVENT_FDM.getOutOfRangeCheck()

Reads the state of the out-of-range check that has been defined by [EVENT_FDM.outOfRangeCheck()](<02.07.04.01.63.06.03_EVENT_FDM.outOfRangeCheck.md>).

The state is read from the corresponding [EVENT_FDM](<02.07.04.01.63.06_EVENT_FDM.md>) object and returned as a bool value.

## Syntax

```
void getOutOfRangeCheck(bool & failOnOutOfRange) const;
```

  Parameter

 | Parameter  | Description |
 | failOnOutOfRange |

The programmed value true or false of the out-of-range check.

- true: The out-of-range check is enabled
- false: The out-of-range check is disabled
  |   Return value There is no return value.

For an example see [EVENT_FDM](<02.07.04.01.63.06_EVENT_FDM.md>).
