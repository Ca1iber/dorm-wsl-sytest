# RESET_MULTIBIN

Resets the multibin information of the testflow.

The software bin number will be reset to an empty string. The hardware bin number will be reset to -1.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

## Syntax

```
void RESET_MULTIBIN();
```

List of parameters

There are no parameters.

Return value

There is no return value.
