# Global framework mode

## About this task

The d2s-framework can be easily controlled by a testflow variable in order to switch between learning and production mode.

This task describes how to implement a testflow variable to your test method, that already uses d2s, for conveniently switching between the d2s modes.

Note In learning mode you have to go through all the if-branches of your test program at least once to generate the static patterns and the burst label.

## Before you begin

Ensure that you have set up your protocol and that your test method is executed correctly.

Add a testflow variable, for example "d2sMode", of type USERFLAG to your testflow. Refer to [defining testflow variables](<../02.08_Setup_and_Result_Tools/02.08.04.32.02.01.12.01_Defining_variables.md>). Assign a value from this list:

- Learning mode is represented by the integer value 1.
- Production mode is represented by the integer value 2.

## Procedure

-  Open your test method that contains the d2s code.
-  Add the `GET_USER_FLAG()` aPI right after the `ON_FIRST_INVOCATION_BEGIN()` call. Use the testflow variable's name as first parameter, for example "d2sMode". Enter an identifier for the retrieved value behind the reference operator, for example "`&d2sGlobalMode`".

```
GET_USER_FLAG("d2sMode", &d2sGlobalMode);
```

-  Replace the second parameter of the d2s_LABEL_BEGINN() API by the identifier you specified in step 2.

```
fr.d2s_LABEL_BEGIN("my_BurstLabelName", d2sGlobalMode);
```

## Example

This example code is based on the example code shown in [Prepare the test method infrastructure](<02.07.09.04.02_Prepare_the_test_method_infrastructure.md>). It has been enhanced to multisite and by the d2s-block to show where to add d2s code.

```
#include "testmethod.hpp"

//for test method API interfaces
#include "mapi.hpp"

//for d2s specific interfaces
#include "d2s_files/d2sJTAG.h"        // This is the users protocol template file.
#include "d2s_files/d2sFramework.h"

using namespace std;

/**
 * Test method class.
 *
 * For each testsuite using this test method, one object of this
 * class is created.
 */
class d2sExample: public testmethod::TestMethod {

protected:
  /**
   *Initialize the parameter interface to the testflow.
   *This method is called just once after a testsuite is created.
   */
  virtual void initialize()
  {
    //Add your initialization code here
    //Note: Test Method API should not be used in this method!
  }

  /**
   *This test is invoked per site.
   */
  virtual void run()
  {
    //Add your test code here.
    ...
    //Add the initial d2s framework specific code to your test method.
    //Each protocol needs to be registered with the d2s-framework.
    d2sFramework fr;
    d2sJTAG& jtag = ds2JTAG::Instance();
    fr.registerTransactionPort(jtag);

    //Multi site handling and d2s-block
    ON_FIRST_INVOCATION_BEGIN();

       // step 2
       GET_USER_FLAG("d2sMode", &d2sGlobalMode);

       // step 3
       fr.d2s_LABEL_BEGIN("my_BurstLabelName", d2sGlobalMode);
          //LearningMode - creating labels and the burst-label
          //ProductionMode - using predefined burst-labels
          jtag.write(0xdead, 0xbeaf);
          jtag.write(0xabcd, 0xef);
          jtag.read(0x1, "one");
       fr.d2s_LABEL_END();

       // do your measurement here
          ...

    ON_FIRST_INVOCATION_END();

    return;
  }

  /**
   *This function will be invoked once the specified parameter's value is changed.
   *@param parameterIdentifier
   */
  virtual void postParameterChange(const string& parameterIdentifier)
  {
    //Add your code
    //Note: Test Method API should not be used in this method!
    return;
  }

  /**
   *This function will be invoked once the Select Test Method Dialog is opened.
   */
  virtual const string getComment() const
  {
    string comment = " please add your comment for this method.";
    return comment;
  }
};
REGISTER_TESTMETHOD("d2sExample", d2sExample);
```
