# RDI_PORT_END()

Declare the ending of a block to set up a specific port. It is used together with `RDI_PORT_BEGIN()` as a pair.

## Syntax

```
RDI_PORT_END();
```

## Example

```
RDI_BEGIN();
  RDI_PORT_BEGIN("ptDATA");
    rdi.protocol().pname("i2c").write(0x03,0x04).execute();
    rdi.protocol().pname("i2c").read(0x03).execute();
  RDI_PORT_END();
  RDI_PORT_BEGIN("ptDATA2");
    rdi.protocol(3).pname("i2c").read(0x03).execute();
  RDI_PORT_END();
RDI_END();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
