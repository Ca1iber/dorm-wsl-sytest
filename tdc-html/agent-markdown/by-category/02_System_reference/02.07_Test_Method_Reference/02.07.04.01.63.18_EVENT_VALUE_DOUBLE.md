# EVENT_VALUE_DOUBLE

The EVENT_VALUE_DOUBLE helper class encapsulates the different handling of values, which may either be a fixed value, a spec, or an equation name. The class is not intended to retrieve the actual values from the equation system. It specifies the value source from where the final value will be retrieved at execution time.

All events support specs and equation variables defined in a level equation set. These variables can be addressed by the LEV: prefix (see example below), which refers to the current level equation set by the primaries.

See also the second event value class [EVENT_VALUE_INT](<02.07.04.01.63.19_EVENT_VALUE_INT.md>). The separation into two value classes enforces type safety at compile time.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Member functions

### isExpression()

```
bool isExpression() const;
```

This member function returns whether the object represents an expression (TRUE) or a fixed value (FALSE).

### getExpression()

```
const STRING & getExpression() const;
```

This member function returns the expression. If the object represents a fixed value the expression string will be empty.

### getValue()

```
DOUBLE getValue() const;
```

This member function returns the value. If the object represents an expression, the returned value is 0. The expression is not resolved here!

## Operators

### Assignment operators

```
EVENT_VALUE_DOUBLE & operator = (const EVENT_VALUE_DOUBLE &);
EVENT_VALUE_DOUBLE & operator = (INT);
EVENT_VALUE_DOUBLE & operator = (FLOAT);
EVENT_VALUE_DOUBLE & operator = (DOUBLE);
EVENT_VALUE_DOUBLE & operator = (const STRING &);
EVENT_VALUE_DOUBLE & operator = (const CHAR   *);
```

These assignment operators allow to change the objects value. Both, fixed values and expressions are supported.

### Compare operators

```
bool operator == (const EVENT_VALUE_DOUBLE &) const;
bool operator != (const EVENT_VALUE_DOUBLE &) const;
```

These compare operators compare two objects for identity.

## Example

Define a fixed double value:

```
EVENT_VALUE_DOUBLE fixedValue(1.3);
```

Defines an equation variable reference:

```
EVENT_VALUE_DOUBLE eqnValue("LEV:frc1");
```
