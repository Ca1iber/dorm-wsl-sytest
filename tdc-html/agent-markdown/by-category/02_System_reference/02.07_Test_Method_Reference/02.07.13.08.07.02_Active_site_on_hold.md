# Active site on hold

SmartRDI provides multiple commands to put active sites to be on hold and assign labels to them.

When INACTIVE_SITE_AUTO_MASK = true is set in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>), the following commands can be used to handle active sites.

RDI commands for setting active sites on hold and other actions
 | Category  | Command  | Description |
 | Setup  | rdi.setOnHoldSites(ARRAY_I sites)  | Set sites to be on a hold state.

Only active sites can be set to be on the hold state.

 |
 | rdi.assignLabelOnHoldSites(string sLabel,string port)  | Specify a dummy label to be run on sites that are on the hold state.

The default port is "@".

 |
 | rdi.clearOnHoldSites()  | Bring all sites that are on the hold state back to their normal operations. |
 | Query and result retrieval  | rdi.id().getOnHoldSites()  | Query which sites are on hold.

An Array_I value is returned.

 |
 | rdi.id().getOnHoldSitesStatus()  | Retrieve the status of the current site.

A Boolean value is returned.

 |

setOnHoldSites(), assignLabelOnHoldSites(), and assignLabelOnInactiveSites() CANNOT be used in an RDI_BEGIN/RDI_END block.

Only actives sites can be set to be on hold. For on-hold sites, RDI will give dummy results.

## Result for active site

If a pin is shared, RDI gets result from the first active site. Other active sites that share the same channel have the same results as the first active site.

 For pin configuration example:

 | Pin  | Site 1  | Site 2 (inactive)  | Site 3  | Site 4 |
 | DATA1  | 10101  | 10101  | 10101  | 10101 |
 | DATA2  | 10102  | 10102   | 10102  | 10102 |
 | DATA3  | 10103  | 10103  | 10105  | 10105 |
 | DATA4  | 10104  | 10104  | 10106  | 10106 |
 | DATA5  | 20101  | 20102  | 20103  | 20104 |
 | DATA6  | 20105  | 20106  | 20107  | 20108  |  For code example based on the pin configuration above:

```
RDI_BEGIN();
  rdi.smartVec("id1").pin("DATA1").writeData()
                     .pin("DATA2").readData().execute();
  rdi.smartVec("id2").pin("DATA3").writeData()
                     .pin("DATA4").readData().execute();
RDI_END();

// Get result from site 1; the result of site 3 and site 4 is the same with site 1.
rdi.id("id1").getReadData("DATA2");
// Get result from site 1 and site 3; the result of site 4 is the same with site 3.
rdi.id("id2").getReadData("DATA4");
```

If a pin is not shared, RDI gets results as usual.

 For the digCap PAR mode, if INACTIVE_SITE_AUTO_MASK = true, the pin list must have:

- Pins that are not shared; or
- A pin that is shared must use the same channel for the sites.

Pin combination: Support or Not support:

```
RDI_BEGIN();
  // Support: pins that are not shared.
  rdi.digCap("1").pin("DATA5,DATA8").capMode(TA::PAR).samples(100).execute();
  // Support: shared pins with the same channel combination.
  rdi.digCap("2").pin("DATA3,DATA4").capMode(TA::PAR).samples(100).execute();
  // Not support: shared pins with different channel combination.
  rdi.digCap("3").pin("DATA1,DATA3").capMode(TA::PAR).samples(100).execute();
  // Not support: a shared pin with a pin that is not shared.
  rdi.digCap("4").pin("DATA1,DATA5").capMode(TA::PAR).samples(100).execute();
```

## Example

### Setting sites to be on hold, assigning labels to the sites,

```
ON_FIRST_INVOCATION_BEGIN();

// Set sites to be on hold and assign labels to these sites.
ARRAY_I holdSites(2);
holdSites[0] = 2;
holdSites[1] = 4;
rdi.setOnHoldSites(holdSites);
rdi.assignLabelOnHoldSites("holdLabel","pt1");

RDI_BEGIN();
  rdi.port("pt1").smartVec("id1").pin("pinA").writeData()
                                 .pin("pinB").readData().execute();
  rdi.port("pt2").emap()....execute();
RDI_END();

ON_FIRST_INVOCATION_END();

rdi.id("id1").getOnHoldSites(); // Return array_I={2,4}
If(!rdi.id("id1").getOnHoldSitesStatus())
{
      rdi.id("id1").getReadData("pinB"); // Site 1 and site 3 return {xx}
}
else
{
     // For on hold sites, RDI gives dummy results.
     rdi.id("id1").getReadData("pinB"); // Sites 2 and 4 return{} 鈫?dummy
}

rdi.clearOnHoldSites(); // Sites 2 and 4 return back to normal state.
```
