# EVENT_WAVEFORM_VFVM.outOfRangeCheck()

Enables or disables the out-of-range check. Per default this check is enabled. If the check is enabled and the measurement range is exceeded, the event contributes with a FAIL to the global test result.

## Syntax

```
EVENT_WAVEFORM_VFVM & outOfRangeCheck(bool failOnOutOfRange = true);
```

Parameter
 | Parameter  | Description |
 | failOnOutOfRange |

Possible values are: true | false

 |

Return value

There is no return value.
