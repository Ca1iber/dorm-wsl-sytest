# SPMU_PIN_TASK.execMode()

Sets the mode of a DC measurement to parallel or serial. The SmarTest SW optimizes the measurements of shared resources in both modes in order to perform as much parallel measurements as possible.

For the "SER" mode this means, that serial measurements are performed per device, but in multisite tests multiple sites are tested in parallel whenever possible.

For the "PAR" mode this means, that parallel measurements are performed per device, but in multisite tests multiple sites are tested in parallel whenever possible.

For the "SER_HAC" and "PAR_HAC" modes this means, that the "high accuracy force current" feature is used by the DPS128. "PAR_HAC" and "SER_HAC" are not supported for ganged DPS128 channels.

Note All pins defined by [SPMU_TASK](<02.07.04.01.234_SPMU_TASK.md>) have to be in the same mode.

## Syntax

```
SPMU_PIN_TASK& execMode(const STRING& mode);
```

Parameter
 |

Parameter

 |

Description

 |
 |

mode

 |

The parameter defines the execution mode:

- "PAR" - Parallel measurement mode.
- "SER" - Serial measurement mode, not for HIZ measurement on digital pins.
- "PAR_HAC" - Parallel measurement mode with high accuracy force current.
- "SER_HAC" - Serial measurement mode with high accuracy force current, not for HIZ measurement on digital pins.

Default mode is "PAR".

"PAR_HAC" and "SER_HAC" are not supported for ganged DPS128 channels.

 |

## Return value

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.2.2: New parameters: PAR_HAC, SER_HAC
- SmarTest 7.5.4.1: Execution modes "PAR_HAC" and "SER_HAC" are no longer supported for ganged DPS128 channels.
