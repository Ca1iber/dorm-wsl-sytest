# TMU_RESULTS.firstSample()

Returns the first sample (to be) uploaded.

## Syntax

```
UINT64 firstSample();
```

List of parameters

There are no parameters.

## Return value

The first sample is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
