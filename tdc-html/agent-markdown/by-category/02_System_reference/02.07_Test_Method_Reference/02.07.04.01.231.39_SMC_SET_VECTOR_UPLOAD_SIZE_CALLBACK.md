# SMC_SET_VECTOR_UPLOAD_SIZE_CALLBACK()

Registers a user defined callback function within the [SmartCalc framework](<02.07.10_SmartCalc_framework.md>). This allows to define a user specified callback function for computing the maximum package size for the next upload operation based on remaining sequencer run time. This is only required if the automatically determined package size turns out to be not sufficient.

It has to be explicitly 'typedefed' as shown here: `typedef INT (*SMC_UPLOAD_SIZE_CALLBACK) (DOUBLE execTime);`

It has to take the estimated test execution time as execTime.parameter and has to return an integer value representing the maximum number of bytes that can be uploaded within the specified time. The way the return value is calculated has to be specified by the user as shown in the example of a user defined callback function in the examples section below.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```
void SMC_SET_VECTOR_UPLOAD_SIZE_CALLBACK(SMC_UPLOAD_SIZE_CALLBACK func);
```

Parameter
 |

Parameter

 |

Description

 |
 |

func

 |

A pointer to a user defined callback function that computes the upload package size.

 |

Return value

There is no return value.

## Examples

### User defined callback function

The following example shows a user defined callback function that computes the upload package size. It assumes that 32 kBytes of data can be uploaded in 1 millisecond (10e3) and calculates the package size accordingly.

```
INT vector_upload_size_callback(DOUBLE execTime)
{
   DOUBLE size = 32 * 1024 * execTime * 10e3;
   return (INT)size;
}
```

### Using the user defined callback function within the SmartCalc framwork

In order to use the callback function defined above, it needs to be registered within the SmartCalc framework as the following examples shows.

```
SMC_SET_VECTOR_UPLOAD_SIZE_CALLBACK(&vector_upload_size_callback);
```
