# EVENT_CFVM.getCForce()

Reads the force current that has been defined by [EVENT_CFVM.cForce()](<02.07.04.01.63.04.01_EVENT_CFVM.cForce.md>).

The value is read from the corresponding [EVENT_CFVM](<02.07.04.01.63.04_EVENT_CFVM.md>) object and returned as an [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getCForce(EVENT_VALUE_DOUBLE & value) const;
```

Parameter
 | Parameter  | Description |
 | value |

The programmed force current in A (Ampere).

 |

Return value

There is no return value.
