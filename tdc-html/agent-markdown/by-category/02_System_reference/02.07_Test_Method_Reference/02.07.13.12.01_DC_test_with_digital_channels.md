# DC test with digital channels

#### Subtopics

- [Setting up PPMU with SmartRDI](<02.07.13.12.01.01_Setting_up_PPMU_with_SmartRDI.md>)
- [Setting up Board ADC with SmartRDI](<02.07.13.12.01.02_Setting_up_Board_ADC_with_SmartRDI.md>)
- [Setting up SPMU with SmartRDI](<02.07.13.12.01.03_Setting_up_SPMU_with_SmartRDI.md>)
- [PS5000 MSET timing](<02.07.13.12.01.04_PS5000_MSET_timing.md>)

SmartRDI provides functions to set up DC tests with PPMU, board ADC, and SPMU. You can specify a test with different instruments with the `pin()` function like below and set up the test with the provided functions for each type of instrument.

- `pin("pinA")` or `pin("pinA",TA::PPMU)` for PPMU test. TA::PPMU is the default value if not specified.
- `pin("pinA",TA::BADC)` for board ADC test.
- `pin("pinA",TA::SPMU)` for SPMU test.
  Note

If you use PPMU or BADC MAPI commands together with SmartRDI commands, you must put the MAPI commands' object declarations inside the `ON_FIRST_INVOCATION_BEGIN` and `ON_FIRST_INVOCATION_END` block. The MAPI classes that follow this rule include:

- HV_DC_TASK
- PPMU_MEASURE

Starting from SmartRDI 7.5.2, some execution times are changed:

- For rdi.dc().pin(pin, TA::BADC): The execution time of wait(dcRelay) is changed from 100 us to 320 us for closing and 0 us to 70 us for opening.
- For PPMU setups such as iRange, vForce/iForce, limitLo/Hi: The execution time is changed from 4 us to 40 us.
