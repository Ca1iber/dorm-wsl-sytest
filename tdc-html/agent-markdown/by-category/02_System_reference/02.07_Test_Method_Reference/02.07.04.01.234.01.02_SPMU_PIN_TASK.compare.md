# SPMU_PIN_TASK.compare()

Sets the comparison mode to either intermediate, low or high to evaluate a measurement.

## Syntax

```
SPMU_PIN_TASK& compare(const STRING& compare);
```

Parameter
 |

Parameter

 |

Description

 |
 |

compare

 |

Default mode is "I".

The test results will be evaluated pass, if the following condition per mode is met:

"I" - Intermediate - the measured value is between the low and the high threshold.

"L" - low - the measured value is below the low threshold.

"H" - high - the measured value is above the high threshold.

 |

## Return value

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.
