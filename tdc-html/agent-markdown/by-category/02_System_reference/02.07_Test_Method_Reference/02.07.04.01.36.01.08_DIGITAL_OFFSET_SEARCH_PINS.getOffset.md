# DIGITAL_OFFSET_SEARCH_PINS.getOffset()

Retrieves the timing or level offsets for the middle of the pass area found in the latest transition search.

Before retrieving values, you must upload the offsets into the workstation with [DIGITAL_OFFSET_SEARCH_PINS.uploadOffset()](<02.07.04.01.36.01.30_DIGITAL_OFFSET_SEARCH_PINS.uploadOffset.md>).

If you retrieve the offset on multiple pins and those pins have different settings, the exception TESTMETHOD_API::AmbiguityException will be issued.

## Syntax

```
DOUBLE getOffset(SetSelector& selector, RESOURCE_TYPE resource) throws TMException;
```

Parameters
 |

Parameter

 |

Description

 |
 |

selector

 |

It can be:

- A TimingSetSelector object defined with [TimingSetSelector](<02.07.04.02.17_TimingSetSelector.md>), specifies the timing sets. Or,
- A LevelSetSelector object defined with [LevelSetSelector](<02.07.04.01.123_LevelSetSelector.md>), specifies the level sets.
 |
 |

resource

 |

It can be a timing resource or a level resource whose offset you want to get. Choose a timing or level resource for the timing or level selector respectively. Otherwise, an exception will be thrown.

For the resource types, see the following table.

 |

 |

Option

 |

Description

 |
 |

 |

Receive edges

 |
 |

DIGITAL_OFFSET_SEARCH::FAST_DRIVE

 |

Fast drive edges

 |
 |

DIGITAL_OFFSET_SEARCH::SLOW_DRIVE

 |

 |
 |

 |

 |
 |

 |

   |  Note On PS1600 cards both DIGITAL_OFFSET_SEARCH::VOH and  DIGITAL_OFFSET_SEARCH::VOL are supported for retrieving the level offsets.

## Return value

A reference to the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) object.

## Example

Do a VIH search with a positive step width. The search will start from Fail until Pass, intending to do a left (or lower) boundary search. The setup and result pins are the same. Set the RestoreFlag to NO.

```
STRING strpins("PS1600_pin_1");

DIGITAL_OFFSET_SEARCH_TASK dos;

dos.pin(strpins)
        .resourceType(DIGITAL_OFFSET_SEARCH::VIH)
        .searchType(DIGITAL_OFFSET_SEARCH::RB)
        .start(15 mV)
        .numSteps(120)
        .stepWidth(15 mV)
        .restoreFlag(DIGITAL_OFFSET_SEARCH::NO);

dos.execute();

DIGITAL_OFFSET_SEARCH::LevelSetSelector dest(101001);

dos.pin(strpins).uploadOffset(dest, DIGITAL_OFFSET_SEARCH::VIH);

DOUBLE offset;

offset = dos.pin(strpins).getOffset(dest, DIGITAL_OFFSET_SEARCH::VIH);
```
