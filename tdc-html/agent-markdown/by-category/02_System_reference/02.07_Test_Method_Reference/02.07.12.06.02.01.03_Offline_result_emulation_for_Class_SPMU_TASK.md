# Offline result emulation for Class SPMU_TASK

The `execute()` method of the `SPMU_TASK` class takes a measurement name as additional parameter. The name is required to refer to the corresponding offline measurement result specified in the setup file.

```
virtual void execute(FwStream* = NULL)
```

This function is the existing measurement execution method of `SPMU_TASK`.

```
virtual void execute(const string& measurementName)
```

Parameter

 |

measurementName

 |

Associate the measurement with offline data

 |
