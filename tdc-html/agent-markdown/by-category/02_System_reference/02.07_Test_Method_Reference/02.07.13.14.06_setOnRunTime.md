# setOnRunTime()

Enables runtime actions for the relays of digital pins or DC Scale pins in Digital I/O operating mode.

  Sometimes relay actions are based on a previous result or site dependent. For this purpose, SmartRDI provides the following commands to support runtime values for digital relays:

- `setOnRunTime()`
- `setOffRunTime()`
- `runTimeVal()`

## Syntax

```
setOnRunTime(string runTimeValueString);
```

Parameter
 |

Parameter

 |

Description

 |
 |

runTimeValueString

 |

The string defines the runtime value.

 |

## Examples

### In the dynamic mode

```
vector <string> rtRelay(2); // 2 sites
   rtRelay[0] = "AC";       // AC relay on site 1 is selected
   rtRelay[1] = "PPMU";     // PPMU relay on site 2 is selected

rdi.runTimeVal("rtd", rtRelay);

RDI_BEGIN();
   rdi.hwRelay().pin().setOnRunTime("rtd").execute();
RDI_END();
```

### In the static mode

```
vector <string> rtRelay(2); // 2 sites
  rtRelay[0] = "AC";        // AC relay on site 1 is selected
  rtRelay[1] = "PPMU";      // PPMU relay on site 2 is selected

rdi.runTimeVal("rtd", rtRelay);
rdi.hwRelay().pin(A).setOnRunTime("rtd").execute();  //static
```
