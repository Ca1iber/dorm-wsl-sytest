# getFFC()

Returns the first failing cycle.

## Syntax

```
int getFFC(string pin);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

pin

 |

Specifies a pin for which to get the first failing cycle.

 |

## Return value

The return value is an integer indicating the first failing cycle.
