# Computing Measurement Values

The test method APIs provide an extensive set of computation algorithms required for a typical mixed-signal device test. The algorithm covers from simple arithmetic operations (for example, add/subtract arrays) to application-specific calculations (for example, compute ADC linearity errors).

To compute the test result from the raw measurement data, you can use the following Computation APIs. For more information on those APIs, see [API Reference](<02.07.04_API_Reference.md>).

- Complex Number Operations

The following APIs perform arithmetic calculations on complex numbers:

  - [DSP_ADD_C](<02.07.04.01.53.05_DSP_ADD_C.md>)
  - [DSP_SUB_C](<02.07.04.01.53.100_DSP_SUB_C.md>)
  - [DSP_MUL_C](<02.07.04.01.53.50_DSP_MUL_C.md>)
  - [DSP_DIV_C](<02.07.04.01.53.26_DSP_DIV_C.md>)

- Data Conversion

The following APIs perform array conversions, multiply each element in the array by a scaling factor, and add an offset to each element; they also extract and copy elements to another array, and perform Rectangular and Polar coordinate conversions:

  - [DSP_CONV_I_x](<02.07.04.01.53.19_DSP_CONV_I_x.md>) (x: C, DC, I, and D)
  - [DSP_CONV_D_x](<02.07.04.01.53.18_DSP_CONV_D_x.md>) (x: C, DC, I, and D)
  - [DSP_EXTRACT](<02.07.04.01.53.33_DSP_EXTRACT.md>)
  - [DSP_RECT_POL](<02.07.04.01.53.61_DSP_RECT_POL.md>)
  - [DSP_POL_RECT](<02.07.04.01.53.59_DSP_POL_RECT.md>)
  - [DSP_FILL_SCL](<02.07.04.01.53.35_DSP_FILL_SCL.md>)
  - [DSP_EXPAND](<02.07.04.01.53.31_DSP_EXPAND.md>)
  - [DSP_SHUFFLE](<02.07.04.01.53.92_DSP_SHUFFLE.md>)

- Bit Conversion

The following APIs perform bit-level data conversion:

  - [DSP_COMBINE_BIT](<02.07.04.01.53.15_DSP_COMBINE_BIT.md>)
  - [DSP_SHIFT](<02.07.04.01.53.91_DSP_SHIFT.md>)
  - [DSP_PARA_SERI](<02.07.04.01.53.58_DSP_PARA_SERI.md>)
  - [DSP_SERI_PARA](<02.07.04.01.53.88_DSP_SERI_PARA.md>)
  - [DSP_COMPRESS](<02.07.04.01.53.16_DSP_COMPRESS.md>)

- Arithmetic Operations

The following APIs perform basic arithmetic operations between two vectors (two arrays) or between a scalar value and a vector:

  - [DSP_ADD_VEC](<02.07.04.01.53.07_DSP_ADD_VEC.md>)
  - [DSP_AND_SCL](<02.07.04.01.53.10_DSP_AND_SCL.md>)
  - [DSP_SUB_VEC](<02.07.04.01.53.102_DSP_SUB_VEC.md>)
  - [DSP_SUB_SCL](<02.07.04.01.53.101_DSP_SUB_SCL.md>)
  - [DSP_MUL_VEC](<02.07.04.01.53.55_DSP_MUL_VEC.md>)
  - [DSP_MUL_SCL](<02.07.04.01.53.54_DSP_MUL_SCL.md>)
  - [DSP_DIV_VEC](<02.07.04.01.53.28_DSP_DIV_VEC.md>)
  - [DSP_DIV_SCL](<02.07.04.01.53.27_DSP_DIV_SCL.md>)

- Matrix Operations

The following APIs perform operations on two-dimensional arrays (matrices):

  - [DSP_MUL_MAT](<02.07.04.01.53.53_DSP_MUL_MAT.md>)
  - [DSP_TRANS_MAT](<02.07.04.01.53.107_DSP_TRANS_MAT.md>)
  - [DSP_UNIT_MAT](<02.07.04.01.53.108_DSP_UNIT_MAT.md>)

- Bit-Wise Logical Operations

A bit-wise logical operation is a logical operation performed between a bit in an element of one integer array and the corresponding bit in another integer array.

The following APIs perform bit-wise logical operations on integer arrays:

  - [DSP_AND_VEC](<02.07.04.01.53.11_DSP_AND_VEC.md>)
  - [DSP_AND_SCL](<02.07.04.01.53.10_DSP_AND_SCL.md>)
  - [DSP_OR_VEC](<02.07.04.01.53.57_DSP_OR_VEC.md>)
  - [DSP_OR_SCL](<02.07.04.01.53.56_DSP_OR_SCL.md>)
  - [DSP_XOR_VEC](<02.07.04.01.53.110_DSP_XOR_VEC.md>)
  - [DSP_XOR_SCL](<02.07.04.01.53.109_DSP_XOR_SCL.md>)

- Pattern Search

The following APIs search for a specified bit pattern in an integer array:
