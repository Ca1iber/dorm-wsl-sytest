# EVENT_RANGE_CF.getIRange()

Reads the minimum and maximum value that has been defined by [EVENT_RANGE_CF.iRange()](<02.07.04.01.63.13.01_EVENT_RANGE_CF.iRange.md>).

The values are read from the corresponding [EVENT_RANGE_CF](<02.07.04.01.63.13_EVENT_RANGE_CF.md>) object and returned as [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) objects.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getIRange(EVENT_VALUE_DOUBLE & minValue,
               EVENT_VALUE_DOUBLE & maxValue) const;
```

Parameters
 | Parameter  | Description |
 |

minValue

 |

The programmed minimum force current in A (Ampere).

 |
 |

maxValue

 |

The programmed maximum force current in A (Ampere).

 |

Return value

There is no return value.
