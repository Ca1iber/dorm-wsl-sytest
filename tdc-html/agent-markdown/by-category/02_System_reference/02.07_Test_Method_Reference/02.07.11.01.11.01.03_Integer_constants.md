# Integer constants

For specific operators it is allowed to use constant integer values directly coded into the encode/decode expression.

The syntax is equivalent to the C programming language.

## Syntax

```
integer_constant := [0..9]*
```

## Functional changes

- Introduced in SmarTest 7.1.0
