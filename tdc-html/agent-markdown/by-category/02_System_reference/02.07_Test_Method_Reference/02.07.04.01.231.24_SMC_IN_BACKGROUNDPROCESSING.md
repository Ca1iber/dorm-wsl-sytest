# SMC_IN_BACKGROUNDPROCESSING()

The API returns whether it is called from a SMC background process or not.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```
Boolean SMC_IN_BACKGROUNDPROCESSING();
```

List of parameters

There are no parameters.

## Return value

The functions returns true if called within a SMC background process.

## Example

In the following example, the protected function reusedFunction() is called directly from the run() function of a test method and from the public background processing function SMC_backgroundProcessing() of the same test method.

Function reusedFunction() shows whether the function is called from a background process or not and utilizes this information to skip calling CURRENT_SITE_NUMBER() that cannot be used within a background process.

Another test suite that runs test method smartCalc.SMC__SYNCHRONIZE is to be used to wait for the end of the background process.

```
protected:
...
...
virtual void run()
{
    cout << "Begin of run() function:" << endl;

    reusedFunction();

    ON_FIRST_INVOCATION_BEGIN();
    {
        FUNCTIONAL_TEST();

        SMC_ARM();

        cout << "run() function:";

        for (int index = 0; index < 30; index++)
        {
            cout <<  " " << index;

            WAIT_TIME (1.0 ms);
        }

        cout << " done" << endl << endl;
    }
    ON_FIRST_INVOCATION_END();

    return;
}

virtual void reusedFunction()
{
    cout << "\t\tSMC_IN_BACKGROUNDPROCESSING() returns " << SMC_IN_BACKGROUNDPROCESSING() << endl << flush;

    if (SMC_IN_BACKGROUNDPROCESSING() == false)
    {
        cout << "\t\tCURRENT_SITE_NUMBER() returns " << CURRENT_SITE_NUMBER() << endl << flush;
    }
    else
    {
        cout << "\t\tCURRENT_SITE_NUMBER() is not supported in a background process." << endl << flush;
    }

    cout << endl << flush;
}

public:

void SMC_backgroundProcessing()
{
    cout << endl << endl << "\tBegin of background processing: Waiting 10 ms" << endl << endl << flush;

    WAIT_TIME (10.0 ms);

    cout << endl << endl << "\tBackground processing: 1st call of the reused function." << endl << endl << flush;

    reusedFunction();

    WAIT_TIME (50.0 ms);

    cout << "\tBackground processing: 2nd call of the reused function after 50 ms" << endl << endl << flush;

    reusedFunction();

    WAIT_TIME (20.0 ms);

    cout << "\tBackground processing finished." << endl << endl << flush;
}
```
