# SPMU_PIN_TASK.preCharge()

Sets the pre-charge voltage for pins used for DC measurements to avoid glitches on the DUT and hot switching of relays.

Programs the DC instrument to the precharge voltage first or enables the Smart Connect feature before closing the output relay to the DUT.

Note No relay action will be performed if [SPMU_PIN_TASK.relay()](<02.07.04.01.234.01.28_SPMU_PIN_TASK.relay.md>) is set to "NO".

## Syntax

```
SPMU_PIN_TASK& preCharge(DOUBLE voltage);
```

Parameters
 | Parameter  | Description |
 | voltage  | Precharge voltage of the SPMU pin in Volt. |
 | safe_con |

Enables the safe connecting mode.

The string parameter safe_con is supported only by the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>). The following value is available:

"SAFE_CON"

 |

## Return value

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.
