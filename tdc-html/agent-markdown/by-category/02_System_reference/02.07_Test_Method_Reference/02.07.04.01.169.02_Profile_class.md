# Profile class

A profile determines the data logging behavior of SmarTest. You can easily determine this behavior by activating different profiles during test program execution.

A profile is a container for data logging properties (such as datalog_level) and associated rules that determine the value of a property depending on the circumstances (for example `datalog_level=2 if testsuite=leakage`). The class includes methods to access the properties and edit the contents of a profile.

This class is defined in the header file /opt/hp93000/soc/prod_com/include/Profile.hpp.

## Constructor

```
Profile::Profile()[inline]
```

The constructor for the Profile class. It initializes all member variables.

## Member functions

### addSelector

```
virtual void Profile::addSelector(SelectorType selector)[pure virtual]
```

Adds a selector by combining it with the selector bitmask using the `OR` function. A selector is added whenever a rule contained by this profile contains a selector field (such as group, test suite, etc.) that has a value other than "*".

Return Code: none

Parameter
 |

selector

 |

The selector to add

 |

### clearRules

```
virtual void Profile::clearRules()[pure virtual]
```

Clears all rules associated with this profile.

Return code: none

Parameters: none

### createRule

```
virtual Rule* Profile::createRule(char * rule)[pure virtual]
```

Creates a new rule to be associated with this profile instance and returns a pointer to the new rule.

This variant allows the rule string to be specified during creation of the Rule object. The rule is first registered in the rule list and is then returned to the caller.

Return code: pointer to the newly created rule upon success; 0 otherwise.

Parameter
 |

rule

 |

the rule string to associate with the new Rule object

 |

### createRule

```
virtual Rule* Profile::createRule()[pure virtual]
```

Creates a new rule to be associated with this profile instance and returns a pointer to the new rule.

The rule is first registered in the rule list and is then returned to the caller. Ideally, the caller would then specify the context the property resides in and the name and the value of the property.

Return code: pointer to the newly created rule upon success; 0 otherwise.

Parameters: none

### deleteRule

```
virtual bool Profile::deleteRule(Rule * rule)[pure virtual]
```

Deletes the rule passed in as an argument by first deregistering the rule from the list and then by freeing (with delete) the memory allocated to it.

Return code: `true` if the rule was deleted successfully; `false` if an error was encountered.

Parameter
 |

rule

 |

The rule to delete

 |

### isReloadNeeded

```

```

Checks if a reload of this profile file is necessary based on the timestamp information.

Parameters: none

### isSelectorDefined

```
virtual bool Profile::isSelectorDefined(SelectorType selector)[pure virtual]
```

Determines if at least one rule in the profile defines the specified selector, meaning a rule defining a field that has a value other than "*".

This method is defined for performance reasons to prevent the update of flags based on a specific selector criteria when no selectors of that type are defined anyway.

Return code: `true` if a at least one rule in the profile uses the specified selector; `false` otherwise.

Parameters: none

### load

```
virtual bool Profile::load(char * filename)[pure virtual]
```

Loads a profile from disk. A new Rule object is created for each successfully read rule, that is, each rule matching the expected format of the rule syntax.

Return code: `true` upon success; `false` if an error was encountered.

Parameter
 |

filename

 |

The file name of the file to load

 |

### save

```
virtual bool Profile::save(char * filename)[pure virtual]
```

Saves a profile to disk. The individual rules are written one by one in a format that corresponds to the rule syntax.

Return code: `true` upon success; `false` if an error was encountered.

Parameter

filename

The name of the file to which to save

Return code: `true` if the rule could be successfully set; `false` if the offset refers to uninitialized memory.

Parameters

### setRuleMapDirty

```
virtual void Profile::setRuleMapDirty(bool dirty)[pure virtual]
```

Sets whether the rule map is "dirty" or not, that is, whether the content of the rule map has been modified and the rule map will therefore need updating before it is accessed again.

Return code: none

Parameter
 |

dirty

 |

The "dirty" flag

 |

### value

```
virtual int Profile::value(char * property)[pure virtual]
```

Returns the value of the specified property within this profile.

This method is essentially the heart of the rule engine that goes through the individual rules and determines the value of the property based on those rules. The order of rule scan is important, as the first match will always be taken.

Return code: the value of the property as an integer or `INT_MIN` if the property was not defined in this context.

Parameter
 |

property

 |

the property string

 |
