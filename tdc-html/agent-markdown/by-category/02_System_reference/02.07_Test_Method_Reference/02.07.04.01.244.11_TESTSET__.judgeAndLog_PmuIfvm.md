# TESTSET().judgeAndLog_PmuIfvm()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) performs a pass/fail judgment of an I-force V-measure DC test with a Pin PMU and logs the results.

Optional values for this function can be set by prior methods, for example, [port()](<02.07.04.01.244.19_TESTSET__.port.md>), [cont()](<02.07.04.01.244.03_TESTSET__.cont.md>), [reliability()](<02.07.04.01.244.20_TESTSET__.reliability.md>), or [testname()](<02.07.04.01.244.23_TESTSET__.testname.md>).

## Syntax

```
bool judgeAndLog_PmuIfvm(const PMU_IFVM &pmuIfvm, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE);
```

 |

Parameter

 |

Description

 |
 |

pmuIfvm

 |

The [PMU_IFVM](<02.07.04.01.151_PMU_IFVM.md>) constructor which specifies a DC test to be judged.

 |
 |

logTestNumber

 |

An optional test number.

If this test number is provided, it overrides the actual test number. If it is not provided, the actual test number is logged.

   | Note Only the first six digits of values are ensured to be correctly logged into the STDF file.

## Return Value

The pass/fail result of the judgment is returned. It can be true for pass or false for fail.
