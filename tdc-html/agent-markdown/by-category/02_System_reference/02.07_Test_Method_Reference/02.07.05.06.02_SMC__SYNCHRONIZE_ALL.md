# SMC__SYNCHRONIZE_ALL

The test method waits for the end of the execution of all threads which have been started using test method API SMC_ARM() on any site.

After all threads have finished their upload and calculation task, the queued [SMC_TEST()](<02.07.04.01.231.45_SMC_TEST.md>) statements will be executed to perform the data logging and binning.

If hidden data logging is used, binning is not handled in this test method, but in the [SMC_backgroundProcessing()](<02.07.04.01.231.01_SMC_ARM.md#_120107__s_SMC_backgroundProcessing>) function.

See also [Synchronize a test flow with any use model](<02.07.10.05_SmartCalc_recommendations.md#_119876__s_Synchronize_a_test_flow_with_any_use_model>) in topic [SmartCalc recommendations](<02.07.10.05_SmartCalc_recommendations.md>).

 The run() function of the test method is implemented as

```
virtual void run()
{
    [ON_FIRST_INVOCATION_BEGIN](<02.07.04.01.138_ON_FIRST_INVOCATION_BEGIN.md>) ()
    {
        [SMC_SYNCHRONIZE_WITHOUT_BINNING](<02.07.04.01.231.44_SMC_SYNCHRONIZE_WITHOUT_BINNING.md>) (0, true);
    }
    [ON_FIRST_INVOCATION_END](<02.07.04.01.139_ON_FIRST_INVOCATION_END.md>) ();

    [SMC_SYNCHRONIZE](<02.07.04.01.231.43_SMC_SYNCHRONIZE.md>)();
}
```

List of test method parameters

There are no test method parameters.
