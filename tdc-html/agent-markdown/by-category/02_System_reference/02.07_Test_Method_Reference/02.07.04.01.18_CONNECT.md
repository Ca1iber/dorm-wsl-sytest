# CONNECT

The CONNECT API connects the tester resources to the DUT and sets the tester to the "connect" state unless they are already connected. If the test resources are already connected, this API performs no action. This API works the same as Connect item of the main menu, and performs the following sequences:

- Connects the AC relays to the DUT pins
- Powers up the supplies to the DUT
- Sets the sequencer to break/on state.Note For multi-site testing, the CONNECT API must be used in the first-invocation block except the "each site" loop block. The CONNECT API cannot work correctly in the "each site" loop block.
 Note Do not mix the global `CONNECT()`/`DISCONNECT()` with individual relay switching. Manually switching relays (see for example [SmartRDI: Digital channel relay control](<02.07.13.14_SmartRDI__Digital_channel_relay_control.md>) and [PPMU_RELAY](<02.07.04.01.158_PPMU_RELAY.md>)) will not change the global connect state, and so `CONNECT()/DISCONNECT()` will see no action to perform. The relays which initially have been switched manually, must again be individually and manually switched to change their state.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

See the test control method [Connect](<02.07.05.04.01_Connect.md>) for more information about the CONNECT.

## Syntax

```
CONNECT();
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Example

```
CONNECT();
...
...
PMU_IFVM("PIN1,PIN2").iForce(100 uA).settling(5 ms);

PMU_IFVM("PIN1,PIN2").limits("limit1").execute();
...
...
```

To use the [PMU_IFVM](<02.07.04.01.151_PMU_IFVM.md>) API, you must set the tester to the CONNECT status. This example connects the tester resources to the DUT with the CONNECT API before DC measurement.
