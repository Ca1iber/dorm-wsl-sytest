# EVENT_RANGE_CF.iRange()

Sets the force current range.

The best fit force range is selected from the given minimum and maximum value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_RANGE_CF & iRange(
    const EVENT_VALUE_DOUBLE & minValue,
    const EVENT_VALUE_DOUBLE & maxValue);
```

Parameters
 | Parameter  | Description |
 |

minValue

 |

Defines the minimum force current in A (Ampere).

 |
 |

maxValue

 |

Defines the maximum force current in A (Ampere).

 |

## Return value

A reference to the corresponding [EVENT_RANGE_CF](<02.07.04.01.63.13_EVENT_RANGE_CF.md>) object.
