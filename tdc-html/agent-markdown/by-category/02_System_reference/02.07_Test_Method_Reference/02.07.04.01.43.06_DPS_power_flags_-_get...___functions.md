The DPS_AUX_TASK class features several member functions for reading the accumulated power supply status flags of the Device Power Supplies (DPS) in DPS operating mode, in PMU operating mode or in Digital I/O operating mode.

The returned result will show the status flags that have been set on tests performed since the previous call of the [DPS_AUX_PIN_TASK.checkPowerFlags()](<02.07.04.01.43.01.02_DPS_AUX_PIN_TASK.checkPowerFlags.md>) member function, or since the last connect or disconnect sequence was executed.

## Member functions

Several get...() member functions are documented in this section. These member functions retrieve the value of all flags or of a single flag from the test method cache. The [DPS_AUX_PIN_TASK.checkPowerFlags()](<02.07.04.01.43.01.02_DPS_AUX_PIN_TASK.checkPowerFlags.md>) member function must be called upfront for reading the flags from the hardware into the test method cache.

The member functions return one of the following values of the enumerated type DPS_POWER_FLAG_STATUS:

 | Keyword  | Value  | State of the checked flags |
 | TM::POWER_FLAG_STATUS_PASS  | 0  | The checked single flag is not set or none of multiple checked flags is set. |
 | TM::POWER_FLAG_STATUS_FAIL  | 1  | The checked single flag is set or minimum one of multiple checked flags is set. |

## DPS flag reset

All DPS status flags are reset to 0 at connect (PSST ON) and disconnect (PSST OFF). But when calling the [DPS_AUX_PIN_TASK.checkPowerFlags()](<02.07.04.01.43.01.02_DPS_AUX_PIN_TASK.checkPowerFlags.md>), the flag "Constant Voltage" is not independent. It is 1 when all other flags are 0.

Note that a reset to 0 is only effective if the condition for the flag is no longer true. The flag is not reset, if the condition is still true at the time of the connect/disconnect or a query by [DPS_AUX_PIN_TASK.checkPowerFlags()](<02.07.04.01.43.01.02_DPS_AUX_PIN_TASK.checkPowerFlags.md>).
