# ENABLE_CHANGE_NOTIFICATION

This API enables the clearing of test method caches when certain firmware commands are executed in order to maintain consistency. The DISABLE_CHANGE_NOTIFICATION is used to disable this API when you do not want the cache to reset.

After using the DISABLE_CHANGE_NOTIFICATION API, you can use the ENABLE_CHANGE_NOTIFICATION API to restore the test method to its default behavior.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

## Syntax

```
ENABLE_CHANGE_NOTIFICATION();
```

## Parameter

```
ENABLE_CHANGE_NOTIFICATION();
```

The ENABLE_CHANGE_NOTIFICATION API enables cache resetting between test method program executions.

## Example

```
ENABLE_CHANGE_NOTIFICATION();
```

The ENABLE_CHANGE_NOTIFICATION API enables cache resetting between test method program executions.

## Functional changes

- Introduced before SmarTest 6.3.2
