# rdi.tmu().disable()

Defines the position of the TMU disable event in the created pattern burst.

For the TMU of supported DC Scale pins, due to hardware reason, you may want to add additional vector lines after the TMU disable event to ensure that the results can be correctly transferred. In other situations, you might want to stop the TMU capture earlier. The disable() API lets you customize the location of TMU disable event.

## Syntax

```
tmuBase& disable();
```

Note If there is no disable() in the RDI_BEGIN() ... RDI_END() block, the TMU disable event will still be put at the end of the created pattern burst.

## Return Value

A reference to the tmuBase object.

## Example

```
RDI_BEGIN();

    rdi.tmu().pin("PVI8_PMU_1")
        .vth(3.0 V, 5.0 V).samples(4).measMode(TA::PULSE_HIGH).execute();

    rdi.wait(1 ms);

    rdi.tmu().pin("PVI8_PMU_1").disable().execute();

    rdi.wait(2 ms);

RDI_END();
```

The code above results in the following sequence in the created pattern burst:

- TMU arm
- TMU threshold, measurement mode, samples
- Wait 1 ms
- TMU disable
- Wait 2 ms
