# EVENT_VC.vClampHigh()

Sets the upper clamp voltage.

Both the upper clamp voltage, defined by this member function, and the lower clamp voltage, defined by [EVENT_VC.vClampLow()](<02.07.04.01.63.20.01_EVENT_VC.vClampLow.md>), can be set in one DC event.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_VC & vClampHigh(const EVENT_VALUE_DOUBLE & value);
```

Parameter
 | Parameter  | Description |
 | value |

Defines the upper clamp voltage to be set in V (Volt).

 |

## Return value

A reference to the corresponding [EVENT_VC](<02.07.04.01.63.20_EVENT_VC.md>) object.
