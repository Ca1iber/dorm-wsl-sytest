# DSP_LOG_VEC

This API computes the natural logarithm (base "e") of elements in a specified array.

For not-complex data processing:

 ![formula](<../../../../raw/30639.png>)

For complex data processing:

 ![formula](<../../../../raw/30640.png>)

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_LOG_VEC(ARRAY_D& src, ARRAY_D& result);
DSP_LOG_VEC(DOUBLE *src, DOUBLE *result,
            INT size);
DSP_LOG_VEC(ARRAY_COMPLEX& src,
            ARRAY_COMPLEX& result);
DSP_LOG_VEC(COMPLEX *src, COMPLEX *result,
            INT size);
```

## Example

```
double array1[50],array2[25];
  .
  .
DSP_LOG_VEC(array1, array2, 25);
```

DSP_LOG_VEC computes the natural logarithm of the first 25 elements in the arrayarray1, and returns the results to the corresponding elements of the arrayarray2as follows:

```
int i;
for (i=0; i<25; i++)
 array2[i] = log(array1[i]);
```
