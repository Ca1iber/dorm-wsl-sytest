# SmartRDI 7.5.3

This section summarizes software changes including new features and enhancements in SmartRDI 7.5.3.

Changes and new features
 |

Category

   | Description |
 | [General](<02.07.13.08_SmartRDI__General_topics_and_functions.md>) |

- [rdi.pureGenerationMode()](<02.07.13.08.11.01_rdi.pureGenerationMode.md>) helps control the pure generation mode in a test suite only.
 |
 | [Alarm handling](<02.07.13.09_SmartRDI__Alarm_handling_for_DCVI.md>) |

- New parameter [GlobalDisableAlarmIth](<02.07.13.09.01.01_Parameters_in_the_alarm_setup_file.md#_345144__li_wbv_wzn_xjb>) defines a global current threshold value in the [Alarm setup file](<02.07.13.09.01_Alarm_setup_file.md>) for globally disabling alarm handling actions.
- New parameter [DisableAlarmIth](<02.07.13.09.01.01_Parameters_in_the_alarm_setup_file.md#_345144__li_xxd_yzn_xjb>) defines a current threshold value per pin in the [Alarm setup file](<02.07.13.09.01_Alarm_setup_file.md>) for disabling alarm handling on a specific pin.
- New commands [globalDisableAlarmIth()](<02.07.13.09.02_Alarm_handling_commands.md#_345173__li_drg_bzn_xjb>) or [disableAlarmIth()](<02.07.13.09.02_Alarm_handling_commands.md#_345173__li_gjm_dzn_xjb>) defines a current threshold value for disabling alarm handling globally or per pin.
 |
 | Analog |

- [getAnaResultHandle()](<02.07.13.08.14.01_getAnaResultHandle.md>) retrieves the name of the analog result handler.
 |
 | [COGO](<02.07.13.19_SmartRDI__Pattern-based_conditional_jump_-_cogo.md>) |

- SmartRDI provides a new solution to retrieve cogo search result without the [pathPin()](<02.07.13.19.02.02_pathPin.md>) command.
 |
 | [DC](<02.07.13.12_SmartRDI__DC_test_setup.md>) |

- New option [TA::PF_ONLY](<02.07.13.12.01.01.18_valueMode.md#_141304__title_gzm_ph1_yjb>) to allow [valueMode()](<02.07.13.12.01.01.18_valueMode.md>) work together with [limit(min, max)](<02.07.13.12.01.01.13_limit.md>) for the cases when the burst pass/fail result of dynamic DC measurements on digital pins is required only.
- New FVI16 connection state TA::FORCE_SENSE_LINK_KEEPcan keep the internal force to sense (FS) link closed after pattern execution.
- BADC digitizing performance with trigger mode is optimized through a new internal transfer mode without any impact on existing test methods.
- The default average values for both [vMeas](<02.07.13.12.01.01.20_vMeas.md>) and iMeas of PPMU and BADC modules is changed. For [vMeas](<02.07.13.12.01.01.20_vMeas.md>), the average value is 16 now; for iMeas, the average value is not fixed but based on the [iRange](<02.07.13.12.01.01.11_iRange.md>) value.
 |
 | [EMAP](<02.07.13.16_SmartRDI__Error_map_results_from_user_patterns.md>) |

- New API [FFV()](<02.07.13.16.06_FFV.md>) specifies a start cycle number for retrieving the first fail vector.
- New API [rdi.id().getFFV()](<02.07.13.16.18_rdi.id__.getFFV.md>) retrieves the number of the first fail vector in pattern for a specified pin.
 |
 | [ROUTE](<02.07.13.15_SmartRDI__DUT_board_connections_control_by_Routing_Tools.md>) |

- New parameter [ROUTING_ACK_CHECK](<02.07.13.04_RDI_Configure_file.md#_146692__row_ROUTING_ACK_CHECK>) of the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>) to enable or disable a check if the route state is applied successfully.
 |
 | [Runtime values](<02.07.13.08.03_Changing_the_parameter_value_at_runtime_with_SmartRDI.md>) |

- New parameter [FAST_PPMU_LEVEL_TRANSFER](<02.07.13.04_RDI_Configure_file.md#_146692__row_FAST_PPMU_LEVEL_TRANSFER>) of the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>) to enable or disable DC fast download. This reduces the time required for high-site-count applications.

For more information, refer to [PPMU fast transfer mode of SmartRDI](<02.07.13.08.03.02_PPMU_fast_transfer_mode_of_SmartRDI.md>).

 |
 | [TMU](<02.07.13.21_SmartRDI__TMU_test_setup.md>) |

- New API [rdi.id().getTmuFinished()](<02.07.13.21.22_rdi.id__.getTmuFinished.md>) helps check whether TMU measurements have been finished or not.
 |

## Supported SmarTest versions

SmartRDI 7.5.3 supports SmarTest 7.5.3.
