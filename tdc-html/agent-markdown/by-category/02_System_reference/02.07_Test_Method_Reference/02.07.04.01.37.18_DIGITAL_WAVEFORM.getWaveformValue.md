# DIGITAL_WAVEFORM.getWaveformValue()

This function retrieves the actual voltage values of the waveform data for the specified pin.

## Syntax

```
void getWaveformValue(const STRING & pin, ARRAY_D & waveformValue) const
```

Parameters
 |

pin

 |

The pin which waveform to be retrieved.

 |
 |

waveformValue

 |

The actual voltage values of the waveform data. The unit of the values is [V].

 |
