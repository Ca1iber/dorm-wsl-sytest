# DIGITAL_WAVEFORM.timingResolution()

This function specifies the timing resolution for data retrieval. The default value is 1 UI. You can specify a timing resolution or a number of sampling points per bit. If the number of sampling points per bit is specified afterwards, the timing resolution is overridden.

## Syntax

```
DIGITAL_WAVEFORM& timingResolution(DOUBLE time_resolution);
```

Parameter
 |

time_resolution

 |

The timing resolution for data retrieval in seconds.

 |
