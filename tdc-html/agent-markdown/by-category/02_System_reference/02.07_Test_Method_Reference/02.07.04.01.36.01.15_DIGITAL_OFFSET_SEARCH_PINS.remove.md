# DIGITAL_OFFSET_SEARCH_PINS.remove()

Removes the offset search configurations for the pins specified with [DIGITAL_OFFSET_SEARCH_TASK.pin()](<02.07.04.01.36.03_DIGITAL_OFFSET_SEARCH_TASK.pin.md>).

## Syntax

```
void remove() const;
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Functional changes

- Introduced in SmarTest 7.2.1
