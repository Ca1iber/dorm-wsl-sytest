# rdi.func().label()

Specifies a label to be executed in a functional test.

The specified label must be the main label, not a burst label or subroutine.

## Syntax

```
rdi.func().label(const string& sLabelName);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

sLabelName

 |

The label to be executed.

 |

## Example

```
rdi.func().label("PATT1").execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
