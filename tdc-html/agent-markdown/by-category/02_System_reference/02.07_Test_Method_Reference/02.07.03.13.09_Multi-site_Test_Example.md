# Multi-site Test Example

The following program is a multi-site test version of the AC test example program shown in [A dynamic analog test example](<02.07.03.03.09_A_dynamic_analog_test_example.md>). There are only two differences from the single test version, namely, the addition of ON_FIRST_INVOCATION_BEGIN and ON_FIRST_INVOCATION_END.

A block enclosed by these APIs is executed for all sites in parallel when the program is executed for the first site. The outside of this block is executed sequentially for all sites.

```
string  digitizerPin    = "DGT_pin_1";
ARRAY_D AnaWave;
THDtype thd_result;
DOUBLE  sampling_period, sn_ratio,s_power,n_power;
string  digitizerPin    = "DGT_pin_1";
ARRAY_D AnaWave;
THDtype thd_result;
DOUBLE  sampling_period, sn_ratio,s_power,n_power;

ON_FIRST_INVOCATION_BEGIN();                        // <=== ADD!
{                                                   // <=== Optional
    //
    // Parallel Execution for All sites - BEGIN
    //

    //
    // Connect and Enable trigger line of analog module
    //
    Routing.pin(digitizerPin).connect(TM::SINGLE);
    Analog.DGT(digitizerPin).enable();

    //
    // Execute a test
    //
    EXECUTE_TEST(0.1 sec);

    //
    // Disconnect and Disable trigger line of analog module
    //
    Analog.DGT(digitizerPin).disable();
    Routing.pin(digitizerPin).disconnect();

    FLUSH();

    //
    // Parallel Execution for All Sites - END
    //
}                                                   // <=== Optional
ON_FIRST_INVOCATION_END();                          // <=== ADD!

//
// Retrieve measured analog waveform
//
AnaWave = Analog.DGT(digitizerPin).getWaveform();

...
...

//
// Get the current sampling frequency
//
sampling_period = Analog.DGT(digitizerPin).getConvClock();

//
// Calculate for THD and SNR
//
DSP_THD(AnaWave, &thd_result, 1, 3, DB, NULL);

//
// Setup for logging raw waveform data
//
WAVE_LOG logwave(AnaWave);

logwave.xAxis(0.0,1023.0*sampling_period);
logwave.xTitle("Time");
logwave.xUnit("sec");
logwave.yTitle("Output Voltage");
logwave.yUnit("V");

PUT_DATALOG(digitizerPin,"AnaWave", logwave);

//
// Judge THD result
//

TEST(digitizerPin,"THD", thd_result.thd, TRUE);

//
// Judge SNR result
//
TEST(digitizerPin, "SNR", thd_result.snr);
```
