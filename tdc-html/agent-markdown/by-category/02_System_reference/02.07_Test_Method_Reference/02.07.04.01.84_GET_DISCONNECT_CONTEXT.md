# GET_DISCONNECT_CONTEXT()

This API returns the disconnection context, which enables you to determine whether a disconnect test suite is executed as normal test suite or in a special context.

Supported test suites are the [Special test suite bin_disconnect](<../../03_Use_cases_and_application_papers/03.04_How_to_do_disconnect/03.04.01.04_Special_test_suite_bin_disconnect.md>) or the [Multibin SmartDisconnect test suite](<../../03_Use_cases_and_application_papers/03.04_How_to_do_disconnect/03.04.01.05_Multibin_SmartDisconnect_test_suite.md>). Normal test suites can also use this API but the API will return only the enum TM::IN_FLOW, which means the context of the normal testflow execution.

## Syntax

```
TM::DISCONNECT_CONTEXT GET_DISCONNECT_CONTEXT();
```

  List of parameters There are no parameters. Return value The disconnect context is returned as enum of type TM::DISCONNECT_CONTEXT:

 | TM::IN_FLOW |

Normal testflow execution.

 This value is also returned if a

- normal test suite is executed in the fail branch of a Run and Branch node and
- if a test method, created for a [Multibin SmartDisconnect test suite](<../../03_Use_cases_and_application_papers/03.04_How_to_do_disconnect/03.04.01.05_Multibin_SmartDisconnect_test_suite.md>) is reused at the end of the flow do disconnect the remaining sites.
 |
 | TM::GOOD_BINNING |

Disconnect of successful sites.

This value is returned if the [Special test suite bin_disconnect](<../../03_Use_cases_and_application_papers/03.04_How_to_do_disconnect/03.04.01.04_Special_test_suite_bin_disconnect.md>) disconnects the remaining sites at the end of the testflow.

 |
 | TM::FAIL_BINNING |

Disconnect of failed sites.

This value is returned if sites are disconnected in the fail branch of a Run and Branch node using the [Special test suite bin_disconnect](<../../03_Use_cases_and_application_papers/03.04_How_to_do_disconnect/03.04.01.04_Special_test_suite_bin_disconnect.md>) or the [Multibin SmartDisconnect test suite](<../../03_Use_cases_and_application_papers/03.04_How_to_do_disconnect/03.04.01.05_Multibin_SmartDisconnect_test_suite.md>).

 |
 | TM::DEFAULT_BINNING  | Disconnect of unbinned sites after testflow end. |
 | TM::TESTMETHOD_ERROR  | Disconnect after test method error. |
 | TM::TESTFLOW_ABORT  | Disconnect after aborting a testflow. |

## Example

### GET_DISCONNECT_CONTEXT() in final disconnect

The following code shows the usage of GET_DISCONNECT_CONTEXT() in the run() function of a test method class.

```
STRING testSuiteName;

GET_TESTSUITE_NAME(testSuiteName);

TM::DISCONNECT_CONTEXT disconnectContext = GET_DISCONNECT_CONTEXT();

cout << "Disconnect context of \"" << testSuiteName << "\": " << disconnectContext << endl;
```

 If used in the [Special test suite bin_disconnect](<../../03_Use_cases_and_application_papers/03.04_How_to_do_disconnect/03.04.01.04_Special_test_suite_bin_disconnect.md>) and performed for the final disconnect of the remaining sites, the code results in the following output in the SmarTest UI report window:

```
Disconnect context of "bin_disconnect": 1
```
