# CCTsetTestuiteDevelopMode()

Sets the development mode for the test suite.

This function is used in the init() function of the test method. It is only used when the CCF block is executed in serial mode. If the specified value is different from the value specified with CCF_DevelopMode, the larger value will be used.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
void CCTsetTestuiteDevelopMode(const int mode);
```

Parameter
 |

Parameter

 |

Description

 |
 |

mode

 |

The development mode. Refer to [Testflow variables](<02.07.08.05_Testflow_variables.md>) for the detailed explanation of the development modes.

 |

List of available options of parameter: mode
 |

Option

 |

Description

 |
 |

0

 |

Production mode

 |
 |

1

 |

Learning mode

 |
 |

2

 |

Development mode

 |
 |

3

 |

Generate only mode

 |

Return value

There is no return value.

## Example

```
CCTsetTestuiteDevelopMode(2);
```

## Functional changes

- Introduced in SmarTest 7.2.1
