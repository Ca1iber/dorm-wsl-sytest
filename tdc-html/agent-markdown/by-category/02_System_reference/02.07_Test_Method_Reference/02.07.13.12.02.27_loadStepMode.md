# loadStepMode()

Selects a load step mode to adapt the dynamic behavior of a DC Scale pin.

This function can be used only in the [code‑based mode](<02.07.13_SmartRDI.md#_142069__dle_Code-based_mode>).

This function supports only [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) in the [PMU operating mode](<../02.05_Test_Head_Cards/02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md>).

## Syntax

```
dcBase& loadStepMode(TA::LOAD_STEP_MODE mode);
```

  Parameter

 | Parameter  | Description |
 | mode |

Load step mode of type TA::LOADSTEP_MODE to be set.

 Supported values:

- TA::LOADSTEP_STANDARD
- TA::LOADSTEP_FAST

Default value for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) is TA::LOADSTEP_STANDARD.

   |  Return Value A reference to the dcBase object.

## Example

```
rdi.dc().pin("XPS256_PMU_1")
        .iForceRange(50 mA).iForce(5.0 mA)
        .vClamp(-5.0, 5.0 V)
        .loadStepMode(TA::LOADSTEP_FAST)
        .execute();
```
