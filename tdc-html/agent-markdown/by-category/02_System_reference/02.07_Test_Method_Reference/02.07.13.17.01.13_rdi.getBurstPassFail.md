# rdi.getBurstPassFail()

Retrieves the pass/fail result of a pattern burst test either on all pins, or on a specific pin or port.

You must use this function:

- Immediately after the `RDI_BEGIN()`/`RDI_END()` block that is performing a pattern burst test.

Or,

- Together with [rdi.id()](<02.07.13.17.01.14_rdi.id__.getBurstPassFail.md>) to retrieve the result that has been stored in buffer with [rdi.func().burstId()](<02.07.13.17.01.02_rdi.func__.burstId.md>) at any desired time in test methods. (Available only for SmartRDI 2.3 or later.) See [rdi.id().getBurstPassFail()](<02.07.13.17.01.14_rdi.id__.getBurstPassFail.md>).
  Note If the [SmartRDI alarm handling](<02.07.13.09_SmartRDI__Alarm_handling_for_DCVI.md>) is used, the burst pass/fail result is impacted by an alarm fail. This means if an alarm check fails, the burst result will fail too.

## Retrieving the result on all pins

```
int rdi.getBurstPassFail();
```

## Retrieving the result on a specific pin or port

```
int getBurstPassFail(string pin);
```

Parameter
 |

Parameter

 |

Description

 |
 |

pin

 |

The pin or port on which you want to retrieve the burst pattern pass/fail result.

 |

## Return Value

Returns:

- 1 if the result is pass.
- 0 if the result is fail.

## Examples

### Example 1

Retrieving the result as soon as the burst pattern test is executed

```
{
ON_FIRST_INVOCATION_BEGIN();
  RDI_BEGIN();
  //burst pattern test setup and execution
  ...
  RDI_END();

  FOR_EACH_SITE_BEGIN();
    int result = rdi.getBurstPassFail("pinB");
  FOR_EACH_SITE_END();

  RDI_BEGIN();
  //another burst pattern test setup and execution
  ...
  RDI_END();

  FOR_EACH_SITE_BEGIN();
    int resultALL = rdi.getBurstPassFail();
  FOR_EACH_SITE_END();
ON_FIRST_INVOCATION_END();
}
```

### Example 2

Retrieving the result at the end of the test method

```
{
...
ON_FIRST_INVOCATION_BEGIN();

  RDI_BEGIN();
    rdi.burstId("bid","A");
    //burst pattern setups and execution
    ...
  RDI_END();

  RDI_BEGIN();
    ...
    ...
  RDI_END();

ON_FIRST_INVOCATION_END();

  int result = rdi.id("bid").getBurstPassFail("A"); //Retrieve the burst pattern test result from Pin A.
  int resultALL = rdi.id("bid").getBurstPassFail(); //Retrieve burst pattern test result from all pins.
}
```
