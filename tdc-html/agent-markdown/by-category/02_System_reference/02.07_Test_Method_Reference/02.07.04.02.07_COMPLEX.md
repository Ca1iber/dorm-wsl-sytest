# COMPLEX

COMPLEX is defined to handle the complex data type in the test method.

## Class definition

```
COMPLEX (DOUBLE real=0.0, DOUBLE imag= 0.0);
COMPLEX (const COMPLEX& obj);
DOUBLE& real();
DOUBLE& imag();
const DOUBLE& real();
const DOUBLE& imag();
COMPLEX& operator = (const COMPLEX&);
const COMPLEX operator + (const COMPLEX&) const;
const COMPLEX operator - (const COMPLEX&) const;
const COMPLEX operator * (const COMPLEX&) const;
const COMPLEX operator / (const COMPLEX&) const;
const INT operator == (const COMPLEX&) const;
const INT operator != (const COMPLEX&) const;
```

## Constructors

```
COMPLEX (DOUBLE real=0.0, DOUBLE imag= 0.0);
```

This constructs a COMPLEX object with the specified values of real and imaginary part. If no specified, the object will be initialized with 0.0.

Parameter
 |

real

 |

The real part of the complex data

 |
 |

imag

 |

The imaginary part of the complex data

 |

```
COMPLEX (const COMPLEX& obj);
```

This constructs a COMPLEX object with an existing COMPLEX object.

Parameter
 |

obj

 |

The COMPLEX object to copy from

 |

## Member functions

### real()

```
DOUBLE& real();
const DOUBLE& real();
```

This function returns the real part of the COMPLEX object.

### imag()

```
DOUBLE& imag();
const DOUBLE& imag();
```

This function returns the imaginary part of the COMPLEX object.

### operator =

```
COMPLEX& operator = (const COMPLEX&);
```

You can use it in the same manner as the C++ standard data types. The real and imaginary parts of the variable on the left of the assignment operator are changed to the real and imaginary values of the variable on the right of the assignment operator.

### operator +

```
const COMPLEX operator + (const COMPLEX&) const;
```

You can use it in the same manner as the C++ standard data types. It performs addition for two complex values.

`cd3=cd1+cd2` performs

```
cd3.real()=cd1.real()+cd2.real()
cd3.imag()=cd1.imag()+cd2.imag()
```

### operator -

```
const COMPLEX operator - (const COMPLEX&) const;
```

You can use it in the same manner as the C++ standard data types. It performs subtraction for two complex values.

`cd3=cd1-cd2` performs

```
cd3.real()=cd1.real()-cd2.real()
cd3.imag()=cd1.imag()-cd2.imag()
```

### operator *

```
const COMPLEX operator * (const COMPLEX&) const;
```

You can use it in the same manner as the C++ standard data types. It performs multiplication for two complex values.

`cd3=cd1*cd2` performs

```
cd3.real()=cd1.real()*cd2.real()-cd1.imag()*cd2.imag()
cd3.imag()=cd1.imag()*cd2.real()+cd1.real()*cd2.imag()
```

### operator /

```
const COMPLEX operator / (const COMPLEX&) const;
```

You can use it in the same manner as the C++ standard data types. It performs division for two complex values.

`cd3=cd1/cd2` performs

```
cd3.real()={cd1.real()*cd2.real()+cd1.imag()*cd2.imag()}/
           {cd2.real()*cd2.real()+cd2.imag()*cd2.imag()}
cd3.imag()={cd1.imag()*cd2.real()-cd1.real()*cd2.imag()}/
           {cd2.real()*cd2.real()+cd2.imag()*cd2.imag()}
```

### operator ==

```
const INT operator == (const COMPLEX&) const;
```

You can use it in the same manner as the C++ standard data types. It judges whether two complex values are equal.

### operator !=

```
const INT operator != (const COMPLEX&) const;
```

You can use it in the same manner as the C++ standard data types. It judges whether two complex values are not equal.

## Example

```
COMPLEX cd1();            // cd1=0.0+0.0i
COMPLEX cd2(3.1);         // cd2=3.1+0.0i
COMPELX cd3(10.3, 23.4);  // cd3=10.3+23.4i
cd4=cd1+cd2;
DOUBLE d=(cd3/cd4).real();
cout <<d <<endl;
```
