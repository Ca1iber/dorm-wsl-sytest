# IS_FIRST_RUN()

Use this function to query whether the run is the first run in a loop.

If the run is the first run, true will be returned. Else false will be returned.

## Syntax

```
bool IS_FIRST_RUN();
```

## Example

```
virtual void run()
  {
   cout << "is firstRunInLoop? " << this->IS_FIRST_RUN() << endl;
   return;
  }
```

## Functional changes

- Introduced in SmarTest 7.4.2
