# ARRAY_CHAR

ARRAY_CHAR defines an array holding the CHAR type of data and defines the functions to access and process the data.

## Constructors

```
ARRAY_CHAR (INT size);
```

This constructs an object of ARRAY_CHAR with the specified fixed size. If a size larger than zero is specified, the memory for the specified number of elements is allocated and the array cannot be resized.

```
ARRAY_CHAR (const ARRAY_CHAR& array);
```

This constructs an unresizable object of ARRAY_CHAR by copying from another ARRAY_CHAR object.

```
ARRAY_CHAR (const ARRAY_CHAR& array, INT size, INT offset= 0);
```

This constructs an unresizable object of ARRAY_CHAR by sharing the specified elements from another ARRAY_CHAR object.

```
ARRAY_CHAR (CHAR* array, INT size, INT offset= 0);
```

This constructs an unresizable object of ARRAY_CHAR by sharing the specified elements from a CHAR array.

Parameters
 |

array

 |

The array to copy from.

 |
 |

size

 |

Size of the new ARRAY_CHAR object.

 |
 |

offset

 |

Starting point in original array where to begin copying the elements. This parameter can be omitted.

 |

## Member functions

### init()

```
void init (CHAR initValue);
```

This function fills the array elements with the specified value.

Parameter
 |

initValue

 |

Value with which to fill the array. Default is empty.

 |

### resize()

```
INT resize (INT size);
```

This function changes the size of the array if it is resizable and keeps its data.

Parameter
 |

size

 |

New size of the array

 |

### size()

```
const INT size () const;
```

This function returns the size of the array.

### capacity()

```
const INT capacity();
```

This function returns the memory size allocated to the array.

### operator =

```
ARRAY_CHAR& operator = (const ARRAY_CHAR& array);
```

This function copies all the elements of the specified array to the current array and changes its size.

Parameter
 |

array

 |

The array to copy from

 |

### operator []

```
CHAR& operator [] (const INT index);
const CHAR& operator [] (const INT index) const;
```

These functions access the specified element in the array.

Parameter
 |

index

 |

Index of the element to access

 |

### operator const CHAR*

```
operator const CHAR* () const;
```

This operator converts ARRAY_CHAR to CHAR *.
