# EVENT_WAVEFORM_IC.getSamples()

Queries the number of samples of the waveform.

## Syntax

```
void getSamples(INT & samples) const;
```

Parameters
 | Parameter  | Description |
 | samples |

The number of samples.

 |

## Return value

The number of samples of the waveform.
