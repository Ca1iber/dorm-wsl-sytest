# TIMING_OFFSET_SEARCH_TASK

#### Subtopics

- [TIMING_OFFSET_SEARCH_PINS](<02.07.04.01.248.01_TIMING_OFFSET_SEARCH_PINS.md>)
- [TIMING_OFFSET_SEARCH_RESULT_PINS](<02.07.04.01.248.02_TIMING_OFFSET_SEARCH_RESULT_PINS.md>)

The `TIMING_OFFSET_SEARCH_TASK` class holds the timing offset search conditions for one or multiple pins. You can use it to set up and execute a timing offset search and query the execution status. It can be used with the [TASK_LIST](<02.07.04.01.240_TASK_LIST.md>) class.

 Note We recommend you use the [DIGITAL_OFFSET_SEARCH_TASK](<02.07.04.01.36_DIGITAL_OFFSET_SEARCH_TASK.md>) API instead of this API, as the former provides more functionality and can search for both timing and level offsets. Currently, the TIMING_OFFSET_SEARCH_TASK exists because of the compatibility reason.

It calls the object of [TIMING_OFFSET_SEARCH_PINS](<02.07.04.01.248.01_TIMING_OFFSET_SEARCH_PINS.md>) class. This class is a subsidiary data container holding the search conditions for the specified pins.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TimingOffsetSearchTask.h.

### Constructor

```
TIMING_OFFSET_SEARCH_TASK();
```

This constructor creates an object of the TIMING_OFFSET_SEARCH_TASK() class. It allows you to define different conditions for different pins, execute the search and query the execution status.

Note Do not create static objects of the class in the test method and do not create test method member variables from this class.

## Member functions

### pin()

```
TIMING_OFFSET_SEARCH_PINS&  pin(const STRING& pinlist);
```

This function returns the reference to a `TIMING_OFFSET_SEARCH_PINS` object with the specified pins. You can use the member functions of `TIMING_OFFSET_SEARCH_PINS` class after it.

Parameter
 |

pinlist

 |

The pins for which a `TIMING_OFFSET_SEARCH_PINS` object is created.

 |

### resultPin()

```
TIMING_OFFSET_SEARCH_RESULT_PINS& resultPin(const STRING& setupPins);
```

This function returns the reference to a `TIMING_OFFSET_SEARCH_RESULT_PINS` object which maintains the relationship between setup pins and result pins.

Parameter
 |

I

 |

setupPins

 |

The setup pins for which the `TIMING_OFFSET_SEARCH_RESULT_PINS` object is created.

 |

### setExecutionContext()

```
void setExecutionContext(const STRING& context);
```

This function refers to an [execution context](<../02.06_Command_Reference/02.06.07.01.08.05.03.02.03_Using_execution_contexts.md>) that has been defined with the [SEQUENCER_CONTEXT](<02.07.04.01.201_SEQUENCER_CONTEXT.md>) API or the [SQEC](<../02.06_Command_Reference/02.06.02.02.231_SQEC__SQEC__-__SeQuencer_Execution_Context.md>) firmware command, so that you can apply the timing offset search on the ports that the execution context refers to.

Parameter
 |

context

 |

An execution context that you have defined with the [SEQUENCER_CONTEXT](<02.07.04.01.201_SEQUENCER_CONTEXT.md>) API or the [SQEC](<../02.06_Command_Reference/02.06.02.02.231_SQEC__SQEC__-__SeQuencer_Execution_Context.md>) firmware command.

 |

### getExecutionContext()

```
const STRING& getExecutionContext();
```

This function retrieves the context name that has been referenced with `setExecutionContext()`. If no execution context had been referenced, this function would return an empty string.

### setup()

```
void setup();
```

This function executes the configuration firmware commands for all pins specified in the `pin()` function.

### execute()

```
void execute();
```

This function executes the timing offset search for all pins specified in the `pin()` function.

### remove()

```
void remove(const STRING& pinlist);
```

This function removes the `TIMING_OFFSET_SEARCH_PINS` instance of the specified pin list from the TIMING_OFFSET_SEARCH_TASK.

### getStatus()

```
TIMING_OFFSET_SEARCH::STATUS_TYPE getStatus();
```

This function gets the state of the last `execute()`. The status type can be `SUCCESS`, `FAILED`, `ABORTED` or `NOT_EXECUTED`.

Note The returned result is global for all involved sites. In multi-site applications, this could lead to wrong pass/fail assignment. In such a case, it is recommended to retrieve the result of all involved sites using TIMING_OFFSET_SEARCH_PINS.TransitionOffsetFound().

### uploadLatestTransition()

```
void uploadLatestTransition();
```

This function triggers the TIMING_OFFSET_SEARCH_PINS instances to upload the transition values of the last executed search to the cache.

### uploadTimingOffset()

```
void uploadTimingOffset(TIMING_OFFSET_SEARCH::TimingSetSelector& target,
                        TIMING_OFFSET_SEARCH::EDGE_TYPE edgetype);
```

This function triggers the TIMING_OFFSET_SEARCH_PINS instances to upload the measured timing offsets of the specified timing set and edge type.

Parameters
 |

target

 |

The timing set to work with.

 |
 |

edgetype

 |

The edge type to use. It can be:

- TIMING_OFFSET_SEARCH::RECEIVE: receive edges
- TIMING_OFFSET_SEARCH::FAST_DRIVE: fast drive edges
- TIMING_OFFSET_SEARCH::SLOW_DRIVE: slow drive edges
- TIMING_OFFSET_SEARCH::DRIVE: drive edges
- TIMING_OFFSET_SEARCH::ALL_EDGES: all edges
 |

### uploadResult()

```
void uploadResult(TIMING_OFFSET_SEARCH::TimingSetSelector& target,
                  TIMING_OFFSET_SEARCH::EDGE_TYPE edgetype);
```

This function triggers the TIMING_OFFSET_SEARCH_PINS instances to upload the transition values of the last executed search to the cache and upload the measured timing offsets of the specified timing set and edge type.

Parameters
 |

target

 |

The timing set to work with.

 |
 |

edgetype

 |

The edge type to use. It can be:

- TIMING_OFFSET_SEARCH::RECEIVE: receive edges
- TIMING_OFFSET_SEARCH::FAST_DRIVE: fast drive edges
- TIMING_OFFSET_SEARCH::SLOW_DRIVE: slow drive edges
- TIMING_OFFSET_SEARCH::DRIVE: drive edges
- TIMING_OFFSET_SEARCH::ALL_EDGES: all edges
 |

## Example

### Define and execute a TIMING_OFFSET_SEARCH_TASK

```
STRING strpins1("pcie_tx1n,pcie_tx2n");
STRING strpins2("pcie_rx1n,pcie_rx2n");
TIMING_OFFSET_SEARCH_TASK tos;
TIMING_OFFSET_SEARCH_TASK tos1;
TASK_LIST list1;

```

```

ON_FIRST_INVOCATION_BEGIN();

    //
    // Set up and execute the timing offset search
    //
    tos.pin(strpins2)
        .edgeType(TIMING_OFFSET_SEARCH::RECEIVE)
        .searchType(TIMING_OFFSET_SEARCH::EYE)
        .start(10 ns)
        .numSteps(100)
        .stepWidth(10 ns)
        .minPassCount(1)
        .transitionDetection(TIMING_OFFSET_SEARCH::PF)
        .resolution(10 ns)
        .errorCountLimit(1)
        .restoreFlag(TIMING_OFFSET_SEARCH::NO);

    tos1.pin(strpins1)
        .edgeType(TIMING_OFFSET_SEARCH::RECEIVE)
        .searchType(TIMING_OFFSET_SEARCH::EYE)
        .start(15 ns)
        .numSteps(120)
        .stepWidth(15 ns)
        .restoreFlag(TIMING_OFFSET_SEARCH::NO);

    list1.add(tos).add(tos1).setup();
    list1.execute();

```

```
    //
    // Upload the result for all sites at once
    //
    TIMING_OFFSET_SEARCH::TimingSetSelector dest("multi_port",TIMING_OFFSET_SEARCH::ALL);

    tos.uploadResult (dest,TIMING_OFFSET_SEARCH::ALL_EDGES);
    tos1.uploadResult(dest,TIMING_OFFSET_SEARCH::ALL_EDGES);

    FOR_EACH_SITE_BEGIN();

        //
        // Show the result per site
        //
        int site = CURRENT_SITE_NUMBER();

        TIMING_OFFSET_SEARCH::RESULT_FOUND result;

        result = tos.pin(strpins2).TransitionOffsetFound();

        if(result != TIMING_OFFSET_SEARCH::NOT_FOUND)
        {
            if(result != TIMING_OFFSET_SEARCH::LB_NOT_FOUND)
            {
                cout << "lbOffset = " << tos.pin(strpins2).getLatestLBTransitionOffset() << endl;
            }
            else
            {
                cout << "lbOffset = NOT_FOUND"  << endl;
            }

            if(result != TIMING_OFFSET_SEARCH::RB_NOT_FOUND)
            {
                cout << "rbOffset = " << tos.pin(strpins2).getLatestRBTransitionOffset() << endl;
            }
            else
            {
                cout << "rbOffset = NOT_FOUND"  << endl;
            }
        }
        else
        {
            cout << "lb/rb offsets NOT_FOUND"  << endl;
        }

        //
        // Retrieve the timing offset of the spec variable,timing set and edge type
        //
        cout << "site " << site << ": " <<  tos.pin(strpins2).getTimingOffset("multi_port",1,TIMING_OFFSET_SEARCH::FAST_DRIVE) << endl;
        cout << "site " << site << ": " <<  tos.pin(strpins2).getTimingOffset("multi_port",1,TIMING_OFFSET_SEARCH::SLOW_DRIVE) << endl;
        cout << "site " << site << ": " <<  tos.pin(strpins2).getTimingOffset("multi_port",1,TIMING_OFFSET_SEARCH::RECEIVE)    << endl;
        cout << "site " << site << ": " <<  tos.pin(strpins2).getTimingOffset("multi_port",2,TIMING_OFFSET_SEARCH::FAST_DRIVE) << endl;
        cout << "site " << site << ": " <<  tos.pin(strpins2).getTimingOffset("multi_port",2,TIMING_OFFSET_SEARCH::SLOW_DRIVE) << endl;
        cout << "site " << site << ": " <<  tos.pin(strpins2).getTimingOffset("multi_port",2,TIMING_OFFSET_SEARCH::RECEIVE)    << endl;
        cout << "site " << site << ": " << tos1.pin(strpins1).getTimingOffset("multi_port",1,TIMING_OFFSET_SEARCH::FAST_DRIVE) << endl;
        cout << "site " << site << ": " << tos1.pin(strpins1).getTimingOffset("multi_port",1,TIMING_OFFSET_SEARCH::SLOW_DRIVE) << endl;
        cout << "site " << site << ": " << tos1.pin(strpins1).getTimingOffset("multi_port",1,TIMING_OFFSET_SEARCH::RECEIVE)    << endl;

    FOR_EACH_SITE_END();

ON_FIRST_INVOCATION_END();
```

The above example shows how to define and execute a TIMING_OFFSET_SEARCH_TASK and how to upload the search result. Note that the TEST statement must be outside the first invocation block.
