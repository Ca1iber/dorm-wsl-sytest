# SPMU_PIN_TASK.connectState()

Specifies a connection state. The connection state defines the mode of connecting a pin to the DUT or defines the bandwidth and reaction time of the pin.

This member function is currently used only for the [DC Scale DPS128/DPS64 cards](<../02.05_Test_Head_Cards/02.05.05.01_DC_Scale_DPS128_DPS64_cards.md>) and the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

 The functionality of the member function is different for the supported cards:

- DPS128-HC: The function is used to select a voltage drop measurement on the force or return line.
- XPS256: The function is used to select a voltage drop measurement on the force or return line.

## Syntax

```

SPMU_PIN_TASK& connectState (const STRING& DPS128_connectionState);
SPMU_PIN_TASK& connectState (const STRING& XPS256_connectionState);
```

## Example

The following example shows how to set the connection state.

```
SPMU_TASK spmuTask;

spmuTask.pin("...")
    ...
    ...
    .connectState("...")
    ;
```

Note: The example concentrates on the function described in this topic. More settings are required for an executable SPMU_TASK object.

## Functional changes

- Introduced in SmarTest 7.3.1
- SmarTest 7.4.0: New AVI64 connection state "SENSE_ONLY"
- SmarTest 7.4.1: New AVI64 connection states "KELVIN_REVERSE" and "FORCE_ONLY"
- SmarTest 7.5.0: New FVI16 connection states "MEAS_KELVIN_HIGH", "MEAS_KELVIN_LOW", and "MEAS_BATT_LEVEL"
- SmarTest 7.5.1: New FVI16 connection state "FS_OVERRIDE"
- SmarTest 7.5.3: New FVI16 connection state "FS_OVERRIDE_ALWAYS"
- SmarTest 7.6.0: New connection states for HC variant of DPS128: "MEAS_KELVIN_HIGH", "MEAS_KELVIN_LOW"
