The EVENT_RDM class provides the functionality to define events doing return drop measurements. The return voltage drop depends on the actual current and the impedance of the connection to the DUT.

The voltage drop is measured from the low sense pogo pin to the low force pogo pin or the common ground.

This class is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) in PMU operating mode or in DPS operating mode.

## Class definition

The class derives from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

The object that is created by this class has to be assigned to the [PATTERN_CONTROLLER](<02.07.04.01.142_PATTERN_CONTROLLER.md>) which is responsible for further handling.

This class is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Example

The following example creates a new DC event, sets the data of the DC event and inserts the DC event into an already existing pattern. The programmed data are then read back from the event object and shown in the console window.

```
PATTERN_CONTROLLER patController;

ON_FIRST_INVOCATION_BEGIN();
{
    cout << endl;
    cout << "DC Scale event example - EVENT_RDM" << endl;
    cout << endl;

    //
    // Create a new event object
    //
    EVENT_RDM event_RDM_1 ("RDM_1");

    //
    // Set the event data
    //
    LIMIT event_RDM_1_limits;

    event_RDM_1_limits.low  (TM::GE, 1.0 V);
    event_RDM_1_limits.high (TM::LE, 3.0 V);
    event_RDM_1_limits.unit  ("V;0;V;0");

    event_RDM_1.averages    (10)
            .outOfRangeCheck(true)
            .limits         (event_RDM_1_limits);

    //
    // Insert the event into a pattern
    //
    PATTERN & pattern = patController.label("Events_example_pattern", "@");

    pattern.vecEvents("pin_1_PMU").clearAll();
    pattern.vecEvents("pin_2_DPS").clearAll();

    pattern.vecEvents("pin_1_PMU")
            .insert(100, event_RDM_1)
            .setup ();

    pattern.vecEvents("pin_2_DPS")
            .insert(100, event_RDM_1)
            .setup ();

    //
    // Read data from the event object
    //
    EVENT_VALUE_INT     averages_1;
    EVENT_VALUE_DOUBLE  upperLimit_1;
    EVENT_VALUE_DOUBLE  lowerLimit_1;
    bool                outOfRangeCheck_1;

    event_RDM_1.getAverages         (averages_1);
    event_RDM_1.getOutOfRangeCheck  (outOfRangeCheck_1);
    event_RDM_1.getLimitHigh        (upperLimit_1);
    event_RDM_1.getLimitLow         (lowerLimit_1);

    cout << "\tAverages           = " << averages_1         << endl;
    cout << "\tOut of range check = " << outOfRangeCheck_1  << endl;
    cout << "\tUpper limit        = " << upperLimit_1       << endl;
    cout << "\tLower limit        = " << lowerLimit_1       << endl;
    cout << endl;
}
ON_FIRST_INVOCATION_END();
```
