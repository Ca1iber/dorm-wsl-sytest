# capMode()

Specifies the digital capture mode.

If one pin is specified in the `pin()` function, the default mode is serial mode.

If multiple pins are specified in the `pin()` function, the default mode is parallel mode. In this mode, 32 bits at most can be captured. The pin order is MSB to LSB.

## Syntax

```
capMode(TA::DCAP_MODE mode);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

mode

 |

The digital capture mode.

 |

List of available options of parameter: mode
 |

Option

 |

Description

 |
 |

TA::SER

 |

The serial digital capture mode.

A vector variable is created for each capture pin with the specified number of bits per word.

 |
 |

TA::PAR

 |

The parallel digital capture mode.

A vector variable is created for all capture pins with one sample per word.

 |

## Example

```
rdi.digCap("cap").pin("DATA1,DATA2").capMode(TA::SER).samples(100).execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
