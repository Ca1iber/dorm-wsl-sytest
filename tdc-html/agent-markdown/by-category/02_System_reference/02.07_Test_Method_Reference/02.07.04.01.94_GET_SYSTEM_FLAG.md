# GET_SYSTEM_FLAG

This API retrieves the current value of the specified system flag.

## Syntax

```
void GET_SYSTEM_FLAG(const STRING& flag, INT *value);
```

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

  Parameters

 | I/O  | Parameter  | Description / Range |
 | I  | flag  | A system flag name. |
 | O  | value  | The current value of the specified flag is returned to this variable.  |  Available options of parameter flag Available system flag names are listed below. For more details on individual flags, see [Setting system flags](<../02.12_Memory_Test_Plus_7.10.2/02.12.02.05.10.01_System_flags.md>), [Flags for data logging](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.03_Testflow_flags_for_data_logging.md>), and [Using system flags](<../02.09_Test_Program_Management/02.09.01.08.05.04.03_System_Flag.md>).

## Example

The GET_SYSTEM_FLAG API retrieves the current value of the bin_number flag:

```
INT binNum;
...
...
GET_SYSTEM_FLAG("bin_number", &binNum);
```
