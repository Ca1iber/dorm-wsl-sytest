# TMU_PINS.uploadRawResults()

Uploads the raw result data for a specified shot into the result cache. You need a TMU_RESULTS object for each shot. (Deprecated)

  Note The TMU_PINS upload methods are deprecated, but for compatibility reasons they are still usable. We recommend using the new function [TMU_TASK.uploadRawResults()](<02.07.04.01.252.19_TMU_TASK.uploadRawResults.md>). Note Normally all upload methods loads results for all sites except they are called inside a FOR_EACH_SITE block.

## Syntax

```
void uploadRawResults(TMU_RESULTS& resultCache,UINT32 shotnum = 0);
void uploadRawResults(TMU_RESULTS& resultCache,STRING& ResultHandle,UINT32 shotnum = 0);
void uploadRawResults(TMU_RESULTS& resultCache,const char* ResultHandle,UINT32 shotnum = 0);
```
