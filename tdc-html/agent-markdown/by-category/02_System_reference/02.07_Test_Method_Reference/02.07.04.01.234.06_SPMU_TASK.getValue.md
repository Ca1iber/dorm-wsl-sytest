# SPMU_TASK.getValue()

Returns the measured value of the specified pin. The unit depends on the type of measurement and can be either Ampere or Volt.

## Syntax

```
DOUBLE getValue(const STRING& pin) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

pin

 |

Pins for which per pin value result should be retrieved.

   | Note Apply the corresponding mode with [SPMU_TASK.execMode()](<02.07.04.01.234.02_SPMU_TASK.execMode.md>) to retrieve per pin value results.

## Return value

The result of the measurement as data type DOUBLE in either Ampere or Volt.

In case the result is out of range 999999999 is returned when used with DC Scale cards.
