# DIGITAL_OFFSET_SEARCH_TASK.remove()

Removes the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) instance for the specified pins from the [DIGITAL_OFFSET_SEARCH_TASK](<02.07.04.01.36_DIGITAL_OFFSET_SEARCH_TASK.md>).

## Syntax

```
void remove(const STRING& pinlist);
```

Parameter
 |

Parameter

 |

Description

 |
 |

pinlist

 |

The pins whose DIGITAL_OFFSET_SEARCH_PINS instance you want to remove from DIGITAL_OFFSET_SEARCH_TASK.

 |

Return value

There is no return value.
