# EVENT_WAVEFORM_VCVM.vClampHigh()

Sets the upper clamp voltage waveform as [ANALOG_WAVEFORM](<02.07.04.01.05_ANALOG_WAVEFORM.md>).

Only one of the two clamp waveforms can be set per DC event. The upper clamp voltage waveform, defined by this member function, and the lower clamp voltage, defined by [EVENT_WAVEFORM_VCVM.vClampLow()](<02.07.04.01.63.36.01_EVENT_WAVEFORM_VCVM.vClampLow.md>), must be set in separate DC events.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_WAVEFORM_VCVM & vClampHigh(ANALOG_WAVEFORM & waveform);
```

Parameter
 | Parameter  | Description |
 | waveform |

Defines the waveform to be set in V (Volt).

 |

## Return value

A reference to the corresponding [EVENT_WAVEFORM_VCVM](<02.07.04.01.63.36_EVENT_WAVEFORM_VCVM.md>) object.
