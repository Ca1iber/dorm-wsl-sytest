# enPassFail()

This function retrieves the pass/fail result of the specified pattern in .label() for the digCap() class.

When enPassFail() is used together with [selective digital capture](<../02.08_Setup_and_Result_Tools/02.08.01.02.07.02.04.02.03_For_Selective_Capturing.md>), follow the "multiple of 8 cycles" rule. Refer to the [Note in the For Selective Capturing topic](<../02.08_Setup_and_Result_Tools/02.08.01.02.07.02.04.02.03_For_Selective_Capturing.md>) for more information.

If required, set the [High-Resolution-Pass/Fail (HRPF)](<../../03_Use_cases_and_application_papers/03.07_How_to_set_up_Digital_Capture/03.07.01.02_Setting_up_the_timing_for_digital_capture.md#_121751__timing_HRPF_selective_capture>) mode in the timing for all pins. See [High-Resolution-Pass/Fail (HRPF)](<../../03_Use_cases_and_application_papers/03.07_How_to_set_up_Digital_Capture/03.07.01.02_Setting_up_the_timing_for_digital_capture.md#_121751__timing_HRPF_selective_capture>) for how to set HRPF. If HRPF is set, burst pass/fail results can be retrieved.

The pins used for digital capture are not recorded by the error map; as a result, they do not contribute to the per-label pass/fail result. See also [Combining selective digital capture with a functional test](<../02.06_Command_Reference/02.06.06.01.03.01.03_Combining_selective_digital_capture_with_a_functional_test.md>) for more information.

## Syntax

```
enPassFail();
```

## Example

```
RDI_BEGIN();
  rdi.tmu("a").label("label1").pin("A")....enPassFail().execute()
  rdi.dc("b").label("label2").pin("B")....enPassFail().execute();
  rdi.digCap("c").label("label3").pin("C")....enPassFail().execute();
RDI_END();

rdi.id("a").getPassFail();
rdi.id("b").getPassFail();
rdi.dc("c").getPassFail();
```
