# How to use valgrind with UTM

A script restart_utm_with_valgrind.ksh is provided to use detect the memory leakage with valgrind in UTM. The script is located in the directory /opt/hp93000/soc/testmethod/lbin/.

## About this task

This script mainly uses the script /opt/hp93000/soc/system/sbin/amendProcessCmd.py. The amendProcessCmd.py is used to manipulate the run-time process configuration of SmarTest component processes. For more information about it, type `amendProcessCmd.py -h` in the command line.

## Before you begin

Make sure you are using SmarTest 6.5.3 or later.

## Procedure

-  Change to the directory to where you want to save the valgrind log files and start SmarTest from command line.
-  To generate valgrind logs for UTM tasks, run the following script in the command line:

```
/opt/hp93000/soc/system/bin/run -S /opt/hp93000/soc/testmethod/lbin/restart_utm_with_valgrind.ksh
```

-  After the above scripts are finished, execute your test method.
-  When the execution finished, stop UTM process by running the script

```
/opt/hp93000/soc/system/bin/run -S /opt/hp93000/soc/testmethod/lbin/stop_utm.ksh
```

A full valgrind log file `log_utm_xxx.vgrind` is dumped in the current directory.

-  Open the log file to review the results and fix the issue in the code. Note There are cases valgrind regards as leakages which may not be true. More information, consult the valgrind website http://valgrind.org/.

## Functional changes

- Introduced in SmarTest 6.5.3
