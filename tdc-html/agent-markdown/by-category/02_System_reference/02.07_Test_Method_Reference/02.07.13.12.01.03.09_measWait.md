# measWait()

Specifies the time to wait between the previous event and measuring the value.

## Syntax

```
measWait(double dMeasWait);
```

List of parameters
 | Parameter  | Description |
 | dMeasWait  | The time to wait  |    Note This command must work together with measurement commands, for example, vMeas(), iMeas(), and vPulse().

## Example

```
rdi.dc().pin("pinA",TA::SPMU).vForce(2.5 V).iMeas().measWait(1 ms).execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
