# BADC_MEASURE

#### Subtopics

- [BADC_PIN_MEASURE](<02.07.04.01.08.01_BADC_PIN_MEASURE.md>)

The BADC_MEASURE class is a data container holding the contents of the task for setting up measurement operations of BADCs. This class can be used to call the [BADC_PIN_MEASURE](<02.07.04.01.08.01_BADC_PIN_MEASURE.md>) class that is a subsidiary data container to set up per pin measurement mode for BADCs. This class also contains the member functions to retrieve test results.

Measurements defined with this class, will be performed with the [PATTERN_CONTROLLER](<02.07.04.01.142_PATTERN_CONTROLLER.md>) class. Results of this measurement are available with the [DC_RESULT_ACCESSOR](<02.07.04.01.28_DC_RESULT_ACCESSOR.md>).

 Note

The typical time required for a BADC or PPMU measurement can be calculated as follows:

 |   | twait = (25 渭s + N * 4 渭s) |
 |   | where:  | 25 渭s is a one-time overhead |
 |   |   | "N" is the number of samples |

After the measurement is performed, SmarTest needs an additional time (typical) of 20 渭s * N, where N is the number of samples, to fetch the results. For this additional duration of time, the BADC cannot be used to perform a new measurement.

In additional, an extra wait time of, at least, 60 渭s must be added for the first BADC measurement after switching the measurement mode on one channel for EXA Scale digital cards or Smart Scale digital cards in Exa Scale compatibility mode.

    CAUTION You must turn off site matching (see [Controlling the site match function](<../02.06_Command_Reference/02.06.03.01.10.04_Controlling_the_site_match_function.md>)) when sharing BADC(s) over sites, to ensure proper pattern-controlled DC value measurements with the BADC.

## Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/BadcMeasure.h.

  Constructor

```
BADC_MEASURE();
```

This constructor defines a Board ADC measurement task holding the number of samples for the measurement.

  Parameters There are no parameters associated with the constructor. Member functions

- [pin()](<02.07.04.01.08_BADC_MEASURE.md#_126248__dle_pin>)
- [wait()](<02.07.04.01.08_BADC_MEASURE.md#_126248__dle_wait>)
  Using the API

For creating an object:

```
BADC_MEASURE <object>;
```

For setting up measurement mode of BADCs:

```
<object>.pin("pinlist").<member_func>;
```

 | <object>  | Object name to be defined |
 | pinlist  | Target pin name or pin group name of this class. You can specify multiple pins and pin groups by separating with a comma or using "@" which means all pins. "@" includes the digital pins that are wired to an analog module on the DUT board for a trigger source. |
 | <member_func>  | Member functions of the BADC_PIN_MEASURE class |

## Member functions

  pin()

```
BADC_PIN_MEASURE & pin(const STRING &pinlist);
```

This function returns the reference to the [BADC_PIN_MEASURE](<02.07.04.01.08.01_BADC_PIN_MEASURE.md>) class object that represents the number of samples for the specified pin. To add an action to the task, use the member functions of the [BADC_PIN_MEASURE](<02.07.04.01.08.01_BADC_PIN_MEASURE.md>) class.

  Parameter

 | Parameter  | Description |
 | pinlist  | Target pin name or pin group name of this class. You can specify multiple pins and pin groups by separating with a comma or using "@" which means all pins. "@" includes the digital pins that are wired to an analog module on the DUT board for a trigger source.  |   Return value A reference to the [BADC_PIN_MEASURE](<02.07.04.01.08.01_BADC_PIN_MEASURE.md>) object.   wait()

```
void wait(const DOUBLE time);
```

This function sets a time to wait when the task defined with BADC_MEASURE is executed.

 | Parameter  | Description |
 | time  | The time to wait. Default unit is [s] |

## Example

### Set to per pin value measurement

```
...
BADC_MEASURE meas1;
meas1.pin("p1");
...
```

This example defines a task to set the "p1" pin to execute a board ADC value measurement.
