# TMU_PINS.getPinsNotFinished()

Retrieves the pins that did not finish sampling and stores the pins in the parameter.

## Syntax

```
UINT32 getPinsNotFinished(STRING_VECTOR& pinvec, STRING& str, INT site)
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

pinvec

 |

A vector of string containing the pins that did not finish sampling.

 |
 |

O

 |

str

 |

A string containing the pins that did not finish sampling. The pins are separated with comma.

 |
 |

I

 |

site

 |

(optional)The site to retrieve. The default value is 0, representing all sites.

 |

## Return value

The number of pins which did not finish sampling is returned.
