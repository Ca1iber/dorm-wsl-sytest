# Passing Analog Waveform to Signal Analyzer

For debugging and analyzing the measurement result, it is a good habit to observe the waveform data and operation result data in the Signal Analyzer.

To pass the analog waveform (or array data) to the Signal Analyzer, you can use the PUT_DEBUG API. For details, see [PUT_DEBUG](<02.07.04.01.175_PUT_DEBUG.md>).

Example:

1)

```
PUT_DEBUG("Aout", "AnaWave", wave_array);
```

The API PUT_DEBUG passes the wave_array analog waveform data to the Signal Analyzer. "Aout" and "AnaWave" are used to identify the data in the Signal Analyzer.

2)

```
WAVE_LOG log_obj(wave_array);
    log_obj.xAxis(0.0, 1023.0*sampling_period);
    log_obj.xTitle("Time");
    log_obj.xUnit("sec");
    log_obj.yTitle("Output Voltage");
    log_obj.yUnit("V");

PUT_DEBUG("Aout", "AnaWave", log_obj);
```

The class object log_obj of the WAVE_LOG API contains captions such as the x-axis data, the x-axis title, the x-axis unit, the y-axis title, and the y-axis unit, other than the wave_array data as the y-axis. Then the API PUT_DEBUG passes this log_obj analog waveform data to the Signal Analyzer.
