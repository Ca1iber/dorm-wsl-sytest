# EVENT_CFVM.clampChecks()

Enables or disables the clamp voltage checks. Per default these checks are disabled. If they are enabled and a checked clamp is hit, the event contributes with a FAIL to the global test result.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_CFVM & clampChecks(bool failOnLow = true, bool failOnHigh = true);
```

Parameters
 | Parameter  | Description |
 | failOnLow |

Enables or disables the clamp voltage check for the lower clamp voltage.

- true: The lower voltage clamp check is enabled
- false: The lower voltage clamp check is disabled

Default value: The clamp check is disabled.

 |
 | failOnHigh |

Enables or disables the clamp voltage check for the upper clamp voltage.

- true: The upper clamp voltage check is enabled
- false: The upper clamp voltage check is disabled

Default value: The clamp check is disabled.

 |

## Return value

A reference to the corresponding [EVENT_CFVM](<02.07.04.01.63.04_EVENT_CFVM.md>) object.
