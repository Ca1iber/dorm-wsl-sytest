The RESULT_AREA_CONFIG_SET holds the setup information for configuring user defined result areas for digital and DC results.

 Digital results consist of error map and digital capture data generated by digital pins. DC results, that can be stored in a DC result area, are pattern controlled value measurements results. For DPS pins such results are generated via events, whereas for digital pins, DC value results can only be generated via [MSET](<../02.06_Command_Reference/02.06.02.02.164_MSET__MSET__-__definition_of_Measurement_SET.md>) based VMUM measurements. Result areas make it possible to use hidden upload for accessing the results stored in such areas.

## Syntax

```
RESULT_AREA_CONFIG_SET::RESULT_AREA_CONFIG_SET (const std::string& setName);
```

This constructor creates an object of RESULT_AREA_CONFIG_SET for the specified name. If the specified result area configuration set does not exist, it is automatically created.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/RESULT_AREA_CONFIG_SET.h.

  Parameters

 | Parameter  | Description |
 | setName  | The name of the result area configuration set to be created or edited.  |  Return value The constructor has no return value.

## Example

Example for using only the DC value result area. This will create a DC value result area for the pin "meas_pin" big enough to hold 16000 value measurement results:

```
//
// Define a new result area configuration set
//
RESULT_AREA_CONFIG_SET badcResultArea("badc_result_area_config");

//
// Configure a DC result area for pin "meas_pin" that can hold 16000 value results
//
badcResultArea.pin("meas_pin").setDcValueResultAreaSize(16000);

//
// Select the newly defined result area configuration to be used for the next test
//
badcResultArea.setAsPrimary();

EXECUTE_TEST();

//
// Switch recording focus back to the default areas (else the next test will overwrite the results)
//
badcResultArea.deselectGlobally();

//
// Upload results by providing the result area config name to the DC_RESULT_ACCESSOR
//
DC_RESULT_ACCESSOR badcResults("badc_result_area_config");

badcResults.uploadResult("meas_pin", TM::RESULT_INDEX);

ARRAY_D patternSamples = badcResults.getValues("meas_pin");
```
