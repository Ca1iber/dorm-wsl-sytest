# Obtaining Name of Currently-Running Testsuite

To obtain the name of the currently-running testsuite, you can use the GET_TESTSUITE_NAME API. For details, see [GET_TESTSUITE_NAME](<02.07.04.01.101_GET_TESTSUITE_NAME.md>).
