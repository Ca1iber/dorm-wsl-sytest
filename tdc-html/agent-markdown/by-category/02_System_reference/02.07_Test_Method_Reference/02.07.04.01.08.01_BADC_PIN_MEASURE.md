# BADC_PIN_MEASURE

The BADC_PIN_MEASURE class is the data container holding the object reflecting the BADC measurement modes. The BADC_PIN_MEASURE object can only be accessed via the [BADC_MEASURE](<02.07.04.01.08_BADC_MEASURE.md>) class.

The API allows to [measure voltage and current waveforms with board ADC of PS1600](<../02.05_Test_Head_Cards/02.05.04.01.07.06.02_How_to_use_the_BADC_as_digitizer.md>) in two ways: Sequencer based measurement and trigger based measurement.

  CAUTION You must turn off site matching (see [Controlling the site match function](<../02.06_Command_Reference/02.06.03.01.10.04_Controlling_the_site_match_function.md>)) when sharing BADC(s) over sites, to ensure proper pattern-controlled DC value measurements with the BADC.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/BadcPinMeasure.h.

```

```

This function defines how many samples are taken for a value measurement. In static measurements, a minimum number of samples is automatically applied.

For dynamic BADC measurements on the PS1600 the default number of samples is one. It can be increased to fulfill the [PS1600 Board ADC specification](<../02.02_Specifications/02.02.04.01.07_PS1600_board_ADC.md>). To achieve the specified accuracy you need to specify the number of samples according to the table below.

## Examples

### Example 1: Defining a BADC value measurement

This example defines a task to set the "p1" pin to per pin value measurement mode and to take 25 samples for this measurement.

```
...
BADC_MEASURE meas1;
meas1.pin("p1").numberOfSamples(25);
...
```

### Example 2: Pattern controlled high impedance voltage measurement with FLEX_RELAY path control

This example forces a voltage with pin PMU on pin "pin_force". This pin is cross-connected with pin "pin_meas". The "pin_meas" pin uses the high impedance (HIZ) measurement path to measure the voltage of "pin_force". The measurement path is configured with the [FLEX_RELAY](<02.07.04.01.68_FLEX_RELAY.md>) API.

```
virtual void run()
{
    DC_RESULT_ACCESSOR result;
    static STRING_VECTOR pinList;
    static string measPins = "pin_meas";

    if(firstRun)
    {
        PATTERN_CONTROLLER pc;
        FLEX_RELAY badcConnect;
        PPMU_SETTING ppmuForce;
        PPMU_RELAY ppmuOn,ppmuOff;
        BADC_SETTING badcSetting;
        BADC_MEASURE badcMeasure;

        ON_FIRST_INVOCATION_BEGIN();

            badcConnect.pin(measPins).set("DC","PMU","MUX_VM_HIZ");
            badcConnect.execute();

            ppmuForce.pin("pin_force")
                    .vForce(forceVoltage.getValueAsTargetUnit("V"))
                    .iRange(1 uA).min(0 uA).max(2 uA);
            ppmuForce.wait(1 ms);

            ppmuOn.pin("pin_force").status("PPMU_ON");
            ppmuOn.wait(1 ms);

            ppmuOff.pin("pin_force").status("AC_ON");
            ppmuOff.wait(1 ms);

            badcSetting.pin(measPins).min(0 V).max(5 V);
            badcSetting.wait(1 ms);

            badcMeasure.pin(measPins).numberOfSamples(16);
            badcMeasure.wait(100 us);

            pc.label("MeasBADC","@").add(ppmuForce)
                    .add(ppmuOn)
                    .add(badcSetting)
                    .add(badcMeasure)
                    .add(ppmuOff);

            pc.setup();

        ON_FIRST_INVOCATION_END();

        firstRun=false;
    }

    ON_FIRST_INVOCATION_BEGIN();

        FUNCTIONAL_TEST();

        result.uploadResult(measPins ,TM::RESULT_INDEX);

        pinList = PinUtility.getDigitalPinNamesFromPinList(measPins,TM::ALL_DIGITAL);

    ON_FIRST_INVOCATION_END();

    //
    // Results
    //
    int numberPins = pinList.size();

    for(int i=0; i<numberPins; i++)
    {
        ARRAY_D values      = result.getValues(pinList[i]);
        int numberOfResults = values.size();

        for (int j = 0; j< numberOfResults; j++)
        {
            double value = values[j];

            cout << "PF: " << result.getPassFail() << endl;
            cout << "NumVal: " << result.getNumberOfAvailableResults(pinList[i]) << endl;
            cout << "FailInfo: " << result.getFailInfo() << endl;
            cout << "PPMU VMHIZ BADC Measurement result: " << value << endl;
        }
    }

    return;
}
```

### Example 3: Pattern controlled Pin PMU voltage measurement using Board ADC and FLEX_RELAY path control

This example does two value measurements with the Board ADC, connected to the Pin PMU.

The measurements validate the voltage forced with Pin PMU on pin "pin_force". This pin is cross connected with pin "pin_meas". The measurement path is configured with the [FLEX_RELAY](<02.07.04.01.68_FLEX_RELAY.md>) API.

```
virtual void run()
{
    DC_RESULT_ACCESSOR result;
    static STRING_VECTOR pinList;
    static string measPins = "pin_meas";

    if(firstRun)
    {
        PATTERN_CONTROLLER pc;
        FLEX_RELAY badcConnect;
        PPMU_SETTING ppmuSetMeasVolt, ppmuSetMeasVolt2;
        PPMU_RELAY ppmuOn,ppmuOff;
        BADC_MEASURE badcMeasure;

        ON_FIRST_INVOCATION_BEGIN();

            badcConnect.pin(measPins).set("PPMU","X","MUX_PPMU");
            badcConnect.execute();

            ppmuOn.pin("pin_force").status("PPMU_ON");
            ppmuOn.wait(1 ms);

            ppmuOff.pin("pin_force").status("AC_ON");
            ppmuOff.wait(1 ms);

            ppmuSetMeasVolt.pin("pin_force").vForce(3 V).iRange(10 uA).min(1 uA).max(2 uA);
            ppmuSetMeasVolt.pin(measPins).iForce(1 uA).iRange(10 uA).min(2 V).max(4 V);
            ppmuSetMeasVolt.wait(1 ms); // ppmu settling

            badcMeasure.pin(measPins).numberOfSamples(16);
            badcMeasure.wait(100 us);

            ppmuSetMeasVolt2.pin("pin_force").vForce(300 mV).iRange(1 mA).min(1 uA).max(2 uA);
            ppmuSetMeasVolt2.pin(measPins).iForce(1 uA).iRange(1 mA).min(250 mV).max(350 mV);

            ppmuSetMeasVolt2.wait(1 ms); //ppmu settling

            pc.label("MeasPPMU_ADC","@").add(ppmuOn)
                                .add(ppmuSetMeasVolt)
                                .add(badcMeasure)
                                .add(ppmuSetMeasVolt2)
                                .add(badcMeasure)
                                .add(ppmuOff);

           pc.setup();

        ON_FIRST_INVOCATION_END();

        firstRun=false;
    }

    ON_FIRST_INVOCATION_BEGIN();

        FUNCTIONAL_TEST();

        result.uploadResult(measPins ,TM::RESULT_INDEX);

        pinList = PinUtility.getDigitalPinNamesFromPinList(measPins,TM::ALL_DIGITAL);

    ON_FIRST_INVOCATION_END();

    //
    // Results
    //
    int numberPins = pinList.size();

    for(int i=0; i<numberPins; i++)
    {
        ARRAY_D values      = result.getValues(pinList[i]);
        int numberOfResults = values.size();

        for (int j = 0; j< numberOfResults; j++)
        {
            double value = values[j];

            cout << "PF: " << result.getPassFail() << endl;
            cout << "NumVal: " << result.getNumberOfAvailableResults(pinList[i]) << endl;
            cout << "FailInfo: " << result.getFailInfo() << endl;
            cout << "PPMU PPMU BADC Measurement result: " << value << endl;
        }
    }

    return;
}
```

### Example 4: Using BADC of PS1600 for mixed-signal testing

This example uses BADC of PS1600 as digitizer to measure the voltage of a waveform.

```
virtual void initialize()
{
    firstRun = true;

} // virtual void initialize(

virtual void connectInstruments()
{
    BADC_SETTING badcSetting;
    FLEX_RELAY connectPpmu;
    TASK_LIST taskList;

    badcSetting.pin("p8").min(-2 V).max(6 V);
    connectPpmu.pin("p1").set("ACDC");
    connectPpmu.pin("p8").set("DC","OFF","MUX_VM_HIZ");
    connectPpmu.wait(1 ms);
    taskList.add(badcSetting).add(connectPpmu).execute();

} // virtual void connectInstruments()

virtual void disconnectInstruments()
{
    FLEX_RELAY disconnectPpmu;

    disconnectPpmu.pin("p1,p8").set("IDLE","OFF");
    disconnectPpmu.execute();

} // virtual void disconnectInstruments()

virtual void run()
{
    DC_RESULT_ACCESSOR result;

    if (firstRun)
    {
        PATTERN_CONTROLLER patternControllerBadcMeasure;

        ON_FIRST_INVOCATION_BEGIN();

            BADC_MEASURE badcMeasure;

            badcMeasure.pin("portBadc").waveformSize(waveformSize).waveformSamplePeriod(samplePeriod us);
            patternControllerBadcMeasure.label("miniDigitizerSub","portBadc").add(badcMeasure);
            patternControllerBadcMeasure.setup();

        ON_FIRST_INVOCATION_END();

        createMiniDigitizerSetup();

        firstRun = false;
    }

    ON_FIRST_INVOCATION_BEGIN();

        connectInstruments();

        FUNCTIONAL_TEST();

        disconnectInstruments();

        result.uploadResult("p8",TM::RESULT_INDEX);

    ON_FIRST_INVOCATION_END();

    ARRAY_D waveform = result.getValues("p8");

    PUT_DEBUG("p8","miniDigitzer",waveform);

    return;

} // virtual void run()
```
