# DSP_XOR_VEC

This API performs a bit-wise logical XOR (exclusive OR) operation between the corresponding elements in two arrays.

```
result [i]  = src1 [i]  XOR src2 [i]
```

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_XOR_VEC(ARRAY_I& src1, ARRAY_I& src2,
            ARRAY_I& result);
DSP_XOR_VEC(INT *src1, INT *src2, INT *result,
            INT size);
```

## Example

```
int array1[10],array2[10], array3[3];
  .
  .
DSP_XOR_VEC(array1, array2, array3, 3);
```

If array1 and array2 have the following elements:

 array1[0] = 7 = 0 ... 0111

 array1[1] = 5 = 0 ... 0101

 array1[2] = 3 = 0 ... 0011

and so on

array2[0] = 2 = 0 ... 0010

array2[1] = 4 = 0 ... 0100

array2[2] = 6 = 0 ... 0110

and so on

then, the XORed results returned to array3 are as follows:

array3[0] = 5 = 0 ... 0101

array3[1] = 1 = 0 ... 0001

array3[2] = 5 = 0 ... 0101

Only the first three elements of each array are processed and returned to array3. The remaining elements in array3 are not changed.
