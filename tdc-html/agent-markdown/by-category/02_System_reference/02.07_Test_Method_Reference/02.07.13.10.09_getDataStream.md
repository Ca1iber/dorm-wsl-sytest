# getDataStream()

Retrieves multiple data from a specified address. The function `read()` must be used to read the data before this.

## Syntax

```
ARRAY_LL& getDataStream();
```

## Example

```
ARRAY_LL result;
result=rdi.id("1").getDataStream();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
