# TMU_RESULTS.numSamples()

Returns the number of samples (to be) uploaded.

## Syntax

```
UINT64 numSamples();
```

List of parameters

There are no parameters.

## Return value

The number of samples is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
