# Sample code for FlexDC API usage - with ORE

This sample assumes that you already have activated offline result emulation (see [Activation and deactivation of the offline result emulation](<02.07.12.04.02_Activation_and_deactivation_of_the_offline_result_emulation.md>) and [Activating offline result emulation in the testflow](<02.07.12.04.03_Activating_offline_result_emulation_in_the_testflow.md>)).

```
voidrun() {
   xyz_TASK task;

   ON_FIRST_INVOCATION_BEGIN();
     // setup
     task.execute("myMeasurement");
   ON_FIRST_INVOCATION_END();

   DOUBLE val = task.getValue("pin1");
   // judge and log
 }

voidrun() {
xyz_TASK task1, task2;
   TASK_LIST tasks;

   ON_FIRST_INVOCATION_BEGIN();
     // setup
     tasks.add(task1, "myMeasurement1");
     tasks.add(task2, "myMeasurement2");
     tasks.execute();
   ON_FIRST_INVOCATION_END();

   DOUBLE val1 = task1.getValue("pin1");
   DOUBLE val2 = task2.getValue("pin1");
   // judge and log
 }
```

- `getValue()` methods return values from external storage.
- Measurements have to be tagged with identifiers.
- Identifiers associate the measurements to data in the external storage.
