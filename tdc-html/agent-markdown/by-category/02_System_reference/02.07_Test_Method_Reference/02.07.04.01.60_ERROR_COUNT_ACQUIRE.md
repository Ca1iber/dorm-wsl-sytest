# ERROR_COUNT_ACQUIRE

#### Subtopics

- [ERROR_COUNT_ACQUIRE_PIN](<02.07.04.01.60.01_ERROR_COUNT_ACQUIRE_PIN.md>)

The class serves as an interface to set up, execute and retrieve spec search result.

The `ERROR_COUNT_ACQURIE` API calls objects of the ERROR_COUNT_ACUQIRE_PIN class, which is a subsidiary data container that holds search conditions for individual pins or spec variables.

```

```

New data types ARRAY_I_TABLE, and ARRAY_LL_TABLE (for 64-bit integers) are defined for the API:

- The definition of ARRAY_I_TABLE is:

```
typedef std::vector<ARRAY_I> ARRAY_I_TABLE.
```

- The definition of ARRAY_LL_TABLE (for 64-bit integers) is:

```
typedef std::vector<ARRAY_LL> ARRAY_LL_TABLE;
```

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ErrorCountAcquire.h.

## Class definition

### Constructor

```
ERROR_COUNT_ACQUIRE();
```

### Member Functions

```
ERROR_COUNT_ACQUIRE_PIN & pin(const STRING & pinlist);
void execute(const TM::ERROR_COUNT_ACQUIRE_STOP_MODE mode);
INT getErrorCount(const STRING & pinList, ARRAY_I_TABLE &result);
INT getErrorCount(const STRING & pinList, ARRAY_LL_TABLE& result);
```

### Constructor

```
ERROR_COUNT_ACQUIRE();
```

This constructor creates an object of the `ERROR_COUNT_ACQUIRE` class. You can define different search conditions for different pins or different sites. All measurements are executed in parallel and the search results are retrieved.

Note You cannot create an object of `ERROR_COUNT_ACQUIRE` class in `IN_FIRST_INVOCATION` block.

## Member functions

### pin()

```
ERROR_COUNT_ACQUIRE_PIN& pin(const STRING& pinlist);
```

This member function specifies the pin list on which the error count is retrieved. It returns a reference of ERROR_COUNT_ACQUIRE_PIN object for further acquisition conditions setup of the `pinlist`.

Parameter
 |

pinlist

 |

The pin list on which the error count is retrieved. The member of pin list needs to be O or IO digital pins or pin groups, which are delimited by commas. For differential pins, you only need to input the positive pins.

 |

### execute()

```
void execute(TM:: ERROR_COUNT_ACQUIRE_STOP_MODE mode);
```

This member function executes the error count acquisition in the specified stop mode.

Parameter
 |

mode

 |

The execution mode. The value can be:

 |
 |

TM::NORMAL_STOP (default)

 |

Acquire the error count from start to stop with the specified step width.

 |
 |

TM::FAST_STOP

 |

Acquire the error count from start with the last step width specified in the member function enableFastMode() of [ERROR_COUNT_ACQUIRE_PIN](<02.07.04.01.60.01_ERROR_COUNT_ACQUIRE_PIN.md>). The acquisition will stop if it enters stable status.

 |

### getErrorCount()

This member function retrieves the error count array per strobe position for:

-  The specified pin list or pin group:

```
INT getErrorCount(const STRING& pinList, ARRAY_I_TABLE& result);
```

- The specified pin:

```
ARRAY_I getErrorCount(const STRING & pin) const;
```

- Also, the specified pin (for 64-bit integers):

```
ARRAY_LL getErrorCountInt64(const STRING & pin) const;
```

The return value is the pin number of the specified pin, pin list, or pin groups.

Parameters
 |

pin

 |

The pin name.

 |
 |

pinList

 |

The pin list or pin groups, separated by a comma.

 |
 |

result

 |

An `ARRAY_I` type array. The result sequence for the pin list is the same as the sequence of the pins. The result sequence for the pin groups is the same as the pin sequence in the result of `DFGP?` command.

 |

## Example

In this example, the error count of pin `HS_TX1` and the error count of pin `HS_TX2` are retrieved.

```
//define instance of ERROR_COUNT_ACQUIRE
ERROR_COUNT_ACQUIRE ercAcquire;

ON_FIRST_INVOCATION_BEGIN()
//setup for the pin
ercAcquire.pin("HS_TX1,HS_TX2")
           .port("HS_Port")
           .spec("offset", TM::TIM)
           .stepWidth(0.01)
           .errorCountMode(TM::ERROR_PER_EDGE)
           .start(0.1)
           .stop(0.3);

//execute retrieving error count
ercAcquire.execute();
ON_FIRST_INVOCATION_END();

// to get error count for each pin
ERROR_COUNT_ACQUIRE::ARRAY_I_TABLE ercOfHsTxPins;
INT numofPins;
numofPins = ercAcquire.getErrorCount("HS_TX1,HS_TX2", ercOfHsTxPins);
```
