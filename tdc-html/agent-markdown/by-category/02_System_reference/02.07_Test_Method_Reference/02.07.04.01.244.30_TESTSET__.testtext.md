# TESTSET().testtext()

Appends additional comments or overwrites the content of the [TEST_TXT](<../02.10_Data_Logging/02.10.03.05.17_Scan_Test_Record__STR.md>) field.

How the text you specify is handled depends on the setting of the [disableTestTxtOverride](<../02.10_Data_Logging/02.10.03.04.03_Configuring_the_contents_of_the_STDF_file.md>) configuration option:

- If set false (default), the text you specify will overwrite the entire content of the [TEST_TXT](<../02.10_Data_Logging/02.10.03.05.17_Scan_Test_Record__STR.md>) field.
- If set true, the specified text is appended to [TEST_TXT](<../02.10_Data_Logging/02.10.03.05.17_Scan_Test_Record__STR.md>).

## Syntax

```
TESTSET & testtext(const STRING &text);
```

 |

Parameter

 |

Description

 |
 |

text

 |

String of text stored in the EDL as a [TestDescriptionAttrType](<../02.10_Data_Logging/02.10.01.06.05.55_TestDescriptionAttrType.md>).

 |

## Example

The following example appends the comment 'trail_test' to [TEST_TXT](<../02.10_Data_Logging/02.10.03.05.17_Scan_Test_Record__STR.md>) if the [disableTestTxtOverride](<../02.10_Data_Logging/02.10.03.04.03_Configuring_the_contents_of_the_STDF_file.md>) is set to true.

```
{
    ...
    TestSet.testtext("trial_test").testnumber(50).judgeAndLog_ParametricTest("pin1", "limit1", TM::Pass, 0);
    ...
}
```
