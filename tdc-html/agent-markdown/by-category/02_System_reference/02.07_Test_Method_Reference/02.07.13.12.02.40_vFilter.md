# vFilter()

Sets the filter frequency of the force or clamp voltage filter.

This function is only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>). The function can be used in the code鈥慴ased mode. In addition to that, it can be used in the pattern鈥慴ased mode for XPS256 pins in PMU operating mode.

The set value defines a bandwidth filter that has an effect on the dynamic behavior of an XPS256 pin that is forcing or clamping the voltage.

## Syntax

```
dcBase& vFilter(double vFilter);
```

  Parameter

 | Parameter  | Description |
 | vFilter |

Defines the filter frequency in Hertz (Hz).

Programmable double values are

- Value between the card-specific minimum and maximum value: The filter is switched on and set to the defined filter frequency.
- 0.0: The filter is set to the card-specific default value.
 Card-specific range and default value:

- XPS256: Refer to section [Dynamic behavior](<../02.05_Test_Head_Cards/02.05.05.03.10.09_XPS256_programming_-_Force_and_clamp_voltages.md#_354305__s_Dynamic_behavior>) in [XPS256 programming - Force and clamp voltages](<../02.05_Test_Head_Cards/02.05.05.03.10.09_XPS256_programming_-_Force_and_clamp_voltages.md>).
  |  Return Value A reference to the dcBase object.

## Example

```
rdi.dc().pin("Pin_1")
        .vForce(20.0 V)
        .iClamp(-10.0 mA, 80.0 mA)
        .vSlewRate(500 mV)
        .vFilter(20.0 kHz)
        .execute();
```
