# EVENT_ICIM.limitHigh()

Sets the upper current limit to compare against threshold.

## Syntax

```
EVENT_ICIM & limitHigh(const EVENT_VALUE_DOUBLE & value );
```

Parameter
 | Parameter  | Description |
 | value |

Upper value of current range

 |

Return value

There is no return value.
