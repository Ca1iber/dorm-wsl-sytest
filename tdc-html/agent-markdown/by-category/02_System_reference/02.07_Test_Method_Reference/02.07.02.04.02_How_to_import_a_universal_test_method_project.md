# How to import a universal test method project

If you want to use an existing test method project, you need to first import it in your workspace.

## Before you begin

Make sure you are using SmarTest 6.3 or later.

## Procedure

-  To import the converted test method project:

  -  In SmarTest Work Center click File > Import. The Import window is displayed.
  -  Select 93000 > Test Method Project and click Next.  ![Import window](<../../../../raw/100059.png>)
  -  Select the test method project with Browse and click Finish. The initial search directory is the default UTM project location of the device or the parent directory of the device if the default UTM project location does not exist. If the project name contains dot(.), it will be changed to underline (_) when you import it.  ![Import the project](<../../../../raw/100060.png>)
  -  If the imported project is not referenced by the current device, the following dialog will pop up to help make a reference to the project. Click OK.  ![Make a reference to the imported project](<../../../../raw/120316.png>)

-  (Optional) If you did not reference the imported project with the Missing Project References dialog, you can create a reference to the project manually.

  -  Right-click the device in the C/C++ perspective and choose Properties from the shortcut menu. The device Properties window will pop up.
  -  In the Properties window click the Project References, select the project that will be used by the device, and click OK. The project reference is created.  ![Refer to the test method project](<../../../../raw/100053.png>)

-  To build the project and use it in the current device, click Project > Build All or press the shortcut key CTRL+B.

If two UTM libraries used by the device have the same name, a dialog like below will pop up. To use both libraries for the project, you need to change the library name for one of them.

  ![Library name conflict checking](<../../../../raw/113210.png>)

If the library is ready to use, this build action will copy the test method library to the testmethod/sh_lib-EL7-64bit sub-directory of the device directory. If the test method library has not been built before, it will build the test method project and copy the library to the testmethod/sh_lib-EL7-64bit sub-directory of the device directory.

 Note You will find a red cross on the UTM project if some errors occurs during the building. If there are errors occurred, you can go to the console or problems view to check the details.

## Results

The universal test method project can be used in the current device.
