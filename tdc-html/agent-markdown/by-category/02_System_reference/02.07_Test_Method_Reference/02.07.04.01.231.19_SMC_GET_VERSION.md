# SMC_GET_VERSION()

The SmartCalc APIs are implemented as shared library. The function returns the version of this library.

## Syntax

```
void SMC_GET_VERSION(INT& major, INT& minor);
```

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

  Parameters

 | Parameter  | Description |
 | major  | The returned major version number. |
 | minor  | The returned minor version number.  |  Return value There is no return value.

## Example

The following code shows the SMC version in the ui_report window.

```
INT major;
INT minor;

ON_FIRST_INVOCATION_BEGIN();
{
    SMC_GET_VERSION(major, minor);

    cout << "SMC version: " << major << "." << minor << endl;
}
ON_FIRST_INVOCATION_END();
```
