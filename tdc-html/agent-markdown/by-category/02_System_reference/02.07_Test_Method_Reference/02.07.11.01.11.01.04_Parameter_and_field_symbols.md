# Parameter and field symbols

Symbolic names for special state character sequences can be defined for each parameter and each field in the protocol editor.

Meaningful symbolic names can be used in encode or decode functions instead of referencing SCS constants. This enhances readability and prevents duplication of SCS constants.

Each symbol consists of a name and a value, whereas the value can be specified in different formats.

Parameter symbols are referenced by <parameter>.<symbolName>.

Field symbols are referenced by <@field>.<symbolName>.

The syntax <symbolName> can be used

- when referencing a parameter symbol inside of the parameter's decode function
- when referencing a field symbol inside of the field's encode function
