# Applying Offline Result Emulation in SmartRDI

#### Subtopics

- [rdi.enableOre()](<02.07.13.08.20.01.01_rdi.enableOre.md>)
- [rdi.oreFile()](<02.07.13.08.20.01.02_rdi.oreFile.md>)
- [rdi.startNextOreTemp()](<02.07.13.08.20.01.03_rdi.startNextOreTemp.md>)

Applying Offline Result Emulation in SmartRDI involves enabling ORE mode and specify the ORE file path.

ORE can be applied at a global level or a local level.

## Apply ORE for SmartRDI at a global level using RDI_Configure

In SmartRDI 2.5.0, the RDI_Configure file supports two new keywords for the ORE handling. See the new keywords ENABLE_ORE and ORE_FILE in [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>).

## Apply ORE for SmartRDI at a local level using functions

SmartRDI 2.5.0 supports the selective usage (test suite or code block) of ORE by two new functions. See the new functions [rdi.enableOre()](<02.07.13.08.20.01.01_rdi.enableOre.md>) and [rdi.oreFile()](<02.07.13.08.20.01.02_rdi.oreFile.md>).

## Functional changes

- Introduced in SmartRDI 2.5.0
