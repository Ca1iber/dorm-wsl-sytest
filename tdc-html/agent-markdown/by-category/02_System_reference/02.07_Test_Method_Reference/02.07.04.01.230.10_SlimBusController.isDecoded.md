# SlimBusController.isDecoded()

This function returns information about execution of the decode() function.

## Syntax

```
Boolean isDecoded(int site=-1) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

site

 |

Specifies the site whose test result is to be returned. The default is the current site.

 |

## Return value

TRUE if the protocol test has been decoded successfully, FALSE if decode() was not yet called or did its execution failed.

## Functional changes

- Introduced in SmarTest 7.2.1
