# setOff()

Opens the relays of digital pins or DC Scale pins in Digital I/O operating mode.

This function can be used only in the code‑based mode for the DC scale pin digital I/O mode.

## Syntax

```
setOff(const string& sRelays);
```

Parameter
 |

Parameter

 |

Description

 |
 |

sRelays

 |

The string defines the relays to open. It can be any combination of the strings

- "DC",
- "AC" or
- "PPMU"

separated by a comma (",").

You can also use "ALL" to open all three relays.

 |

## Example

```
rdi.hwRelay().pin("pinA")
        .setOn("DC,AC")
        .setOff("PPMU")
        .execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
- SmartRDI 2.4.2: AVI64 added.
