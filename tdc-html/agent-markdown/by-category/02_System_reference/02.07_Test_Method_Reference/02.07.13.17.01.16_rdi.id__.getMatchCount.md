# rdi.id().getMatchCount()

This function returns the number of executed loops if a match is found on the specified pin.

## Syntax

```
int rdi.id().getMatchCount(string pin)
```

## Example

```
int rdi.id("mch").getMatchCount();
```

## Functional changes

- Introduced in SmartRDI 2.4.0
