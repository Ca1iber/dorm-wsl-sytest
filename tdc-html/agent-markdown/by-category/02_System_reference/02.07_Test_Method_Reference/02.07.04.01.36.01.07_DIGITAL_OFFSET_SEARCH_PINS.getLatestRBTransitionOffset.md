# DIGITAL_OFFSET_SEARCH_PINS.getLatestRBTransitionOffset()

Retrieves the offset at the right boundary of the pass area, found in the latest transition search. This offset records the pass-to-fail transition. Before using this function, you must upload the boundary offsets into the system controller with [DIGITAL_OFFSET_SEARCH_PINS.uploadLatestTransition()](<02.07.04.01.36.01.29_DIGITAL_OFFSET_SEARCH_PINS.uploadLatestTransition.md>).

If you retrieve the offset on multiple pins and the pins have different settings, the exception TESTMETHOD_API::AmbiguityException will be issued.

## Syntax

```
DOUBLE getLatestRBTransitionOffset();
```

## Parameter

There is no parameter.

## Return value

Returns the offset at the right boundary of the pass area in the latest transition search:

- For timing offset searches, the units of the returned values are [s].
- For level offset searches, the units of the returned values are [V].

If the offset search had been applied on multiple pins, this function only returns the smallest offset among these pins' in order to form the smallest eye (a pass area).
