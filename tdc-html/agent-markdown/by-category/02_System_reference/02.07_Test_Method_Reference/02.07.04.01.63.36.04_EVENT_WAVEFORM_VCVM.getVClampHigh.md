# EVENT_WAVEFORM_VCVM.getVClampHigh()

Queries the upper clamp voltage waveform that has been defined by [EVENT_WAVEFORM_VCVM.vClampHigh()](<02.07.04.01.63.36.03_EVENT_WAVEFORM_VCVM.vClampHigh.md>).

The waveform is read from the corresponding [EVENT_WAVEFORM_VCVM](<02.07.04.01.63.36_EVENT_WAVEFORM_VCVM.md>) object and returned as an [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
const ARRAY_D & getVClampHigh() const;
```

List of parameters

There are no parameters.

## Return value

An [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>) object containing the waveform samples that are defined in V (Volt).
