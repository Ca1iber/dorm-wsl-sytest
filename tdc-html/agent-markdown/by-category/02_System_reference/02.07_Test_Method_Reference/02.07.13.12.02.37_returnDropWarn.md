# returnDropWarn()

Sets a return drop voltage as a warning threshold for the return line (GND).

This function can be only used in the [code‑based mode](<02.07.13_SmartRDI.md#_142069__dle_Code-based_mode>).

This function only supports [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) in the [PMU operating mode](<../02.05_Test_Head_Cards/02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md>).

## Syntax

```
dcBase& returnDropWarn(double value);
```

## Example

```
rdi.dc().pin("XPS256_PMU_1").iForceRange(50 mA).iForce(5.0 mA).vClamp(-5.0, 5.0 V).returnDropWarn(2 V).execute();
```

## Functional changes

- Introduced in SmartRDI 7.10.1
