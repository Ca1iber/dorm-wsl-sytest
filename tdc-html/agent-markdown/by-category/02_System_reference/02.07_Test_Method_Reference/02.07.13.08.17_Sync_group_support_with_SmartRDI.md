# Sync group support with SmartRDI

#### Subtopics

- [addPort()](<02.07.13.08.17.01_addPort.md>)
- [syncGroup()](<02.07.13.08.17.02_syncGroup.md>)

In multiport bursts, a synchronization group (sync group) forces related ports to start always at the same point in time. For more information about sync groups, see [Working with sync groups](<../02.08_Setup_and_Result_Tools/02.08.04.16.03.04_Working_with_sync_groups.md>).

In SmartRDI, you can use [syncGroup()](<02.07.13.08.17.02_syncGroup.md>) and [addPort()](<02.07.13.08.17.01_addPort.md>) to assign one or more ports to a sync group.

## Example

```
rdi.syncGroup("sg1").addPort("ptA");
rdi.syncGroup("sg2").addPort("ptB").addPort("ptC");

RDI_BEGIN();
  rdi.port("ptA")...
  rdi.port("ptB")...
  rdi.port("ptC")...
RDI_END();
```
