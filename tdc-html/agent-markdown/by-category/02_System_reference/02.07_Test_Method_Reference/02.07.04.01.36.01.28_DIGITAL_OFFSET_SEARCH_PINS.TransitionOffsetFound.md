# DIGITAL_OFFSET_SEARCH_PINS.TransitionOffsetFound()

Returns the status of the last transition offset search.

## Syntax

```
DIGITAL_OFFSET_SEARCH::RESULT_FOUND TransitionOffsetFound();
```

## Parameters

There is no parameters.

## Return value

Returns the status of the last transition offset search. It can be FOUND, NOT_FOUND, LB_NOT_FOUND, or RB_NOT_FOUND.
