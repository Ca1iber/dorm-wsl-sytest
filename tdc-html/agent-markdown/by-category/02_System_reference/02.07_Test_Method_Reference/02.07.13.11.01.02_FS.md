# FS()

Specifies the sampling frequency when the PPMU or the DC Scale pin is used as AWG.

## Syntax

```
FS(double dSampleFreq);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

dSampleFreq

 |

The sampling frequency.

 |

## Functional changes

- Introduced in SmartRDI 2.1.0
- SmarTest 7.5.1: New syntax for high-speed AWG of AVI64.
