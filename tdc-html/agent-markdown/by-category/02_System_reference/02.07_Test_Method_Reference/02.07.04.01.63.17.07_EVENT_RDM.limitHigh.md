# EVENT_RDM.limitHigh()

Sets the upper limit to compare against threshold.

## Syntax

```
EVENT_RDM & limitHigh(const EVENT_VALUE_DOUBLE & high);
```

  Parameter

 | Parameter  | Description |
 | high  | The upper limit of the pass range in Volts (V).The polarity of the measured force drop and return drop measurement corresponds to the polarity of the current:

- Sourcing current from the PMU channel to the DUT will result in positive force drop and return drop voltage.
- Sinking current from the DUT into the PMU channel will result in negative force drop and return drop voltage.
The limits for the force drop and return drop measurements are to be set accordingly.  |  Return value A reference to the corresponding [EVENT_RDM](<02.07.04.01.63.17_EVENT_RDM.md>) object.
