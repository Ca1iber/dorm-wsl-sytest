# Cursor/Marker Analysis

The Cursor/Marker Analysis use cases include sample programs using the Data Display API for moving, synchronizing, finding min/max, and making cursors/markers non-visible.

## Move Cursors and Display Cursor Positions

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
Cursor cursor = graph.getCursor();
ARRAY_D waveform = Analog.DGT("digitizer").getWaveform();
double min, max;
int min_index, max_index;
DSP_MINMAX(waveform, &min, &max, &min_index, &max_index);
cursor.setYMeasurePosition(min_index);
cursor.setYReferencePosition(max_index);
graph.setCursor(cursor);
graphManager->setGraph(graph, 1);
```

This example moves the measurement cursor of Y-axis to the position of the minimum value and moves the reference cursor of Y-axis to the position of the maximum value of the waveform.

## Synchronize Cursors

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getCursor().setYTrackMode(Display::TRACK_ON);
graphManager->setGraph(graph, 1);
```

This example synchornizes the cursors. When you move one cursor, the other one will be moved simultaneously.

## Move Markers and Display Marker Positions

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
Marker marker = graph.getMarker();

ARRAY_D waveform = Analog.DGT("digitizer").getWaveform();
double min, max;
int min_index, max_index;
DSP_MINMAX(waveform, &min, &max, &min_index, &max_index);

// Find min/max automatically
marker.setUpMarkerPosition(min_index);
marker.setDownMarkerPosition(max_index);
graph.setMarker(marker);
graphManager->setGraph(graph, 1);
```

This example moves the markers' potisions of graph 1. It moves the up-marker to the minimum value of waveform and moves the down marker to the maximum value of waveform.

## Synchronize Markers

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getMarker().setTrackMode(Display::TRACK_ON);
graphManager->setGraph(graph, 1);
```

This example synchonize the markers. When you move one marker, the other one will also be moved simultaneously.

## Find Min/Max with Markers

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
Marker marker = graph.getMarker();

ARRAY_D waveform = Analog.DGT("digitizer").getWaveform();
double min, max;
int min_index, max_index;
DSP_MINMAX(waveform, &min, &max, &min_index, &max_index);

// Find min/max automatically
marker.setUpMarkerPosition(min_index);
marker.setDownMarkerPosition(max_index);
graph.setMarker(marker);
graphManager->setGraph(graph, 1);
```

This example retrieves the waveform data from digitizer and finds the minimum and maximum values in the waveform. Then it puts the up marker at the minimum value and the down marker at the maximum value.

## Make Cursors/Markers Non-Visible Temporarily

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getCursor().setVisible(false);
graph.getMarker().setVisible(false);
graphManager->setGraph(graph, 1);
```
