# EVENT_ICIM.getLimitLow()

Queries the lower current limit to compare against threshold.

## Syntax

```
EVENT_ICIM & getLimitLow( EVENT_VALUE_DOUBLE & value ) const;
```

Parameter
 | Parameter  | Description |
 | value |

Lower value of current range

 |

## Return value

Returns EVENT_VALUE_DOUBLE as reference.
