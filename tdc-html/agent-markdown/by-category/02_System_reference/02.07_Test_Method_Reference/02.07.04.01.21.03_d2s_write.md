# d2s write

The d2s write method allows to write to a register. This is done by generating a static write pattern with the specified register address and data. The d2s-framework will create the corresponding static pattern.

## Syntax

```
void write(long long address, long long data);
```

Parameters
 |

I/O

 |

Parameter

 |

## Example

The following excerpt illustrates how the write method is used to created static pattern to write the corresponding data to the given address.

In learning mode it will generate two write labels and burst them together under `MyBurstLabelName`.

In production mode only the `MyBurstLabelName ` pattern will be executed at `d2s_LABEL_END()`.

```
virtual void run()
{
   d2sFramework fr;
   d2sJTAG& jtag = d2sJTAG::Instance();

   // Register your protocol with the framework
   fr.registerTransactionPort(jtag);

   ON_FIRST_INVOCATION_BEGIN();
      fr.d2s_LABEL_BEGIN("MyBurstLabelName", d2sFrameWorkModeType::LearningMode);
         jtag.write(0xdead, 0xbeaf);
         jtag.write(0xabcd, 0xef);
      fr.d2s_LABEL_END();

      // do your measurement here

   ON_FIRST_INVOCATION_END();
   ...
}
```

The static patterns created by the code above for a single port setup would be saved into the device vector directory as:

`d2s_jtag_AT_W_0xdead_0xbeaf` and `d2s_jtag_AT_W_0xabcd_0xef`
