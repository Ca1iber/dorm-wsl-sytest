# TMU_RESULTS.getPeriodRange()

Retrieves the range of the measured period of the specified pin, measurement ID and site. The member function `uploadPeriodResults()` of TMU_PINS needs to be used before using this function.

## Syntax

```
Boolean getPeriodRange(STRING& pin, ARRAY_D& array, UINT64& firstperiod, UINT32 meas = 1,UINT32 site = 0);
Boolean getPeriodRange(const char* pin, ARRAY_D& array, UINT64& firstperiod, UINT32 meas = 1,UINT32 site = 0);
```

## Return value

The execution status of the function is returned. It can be true or false.

- Introduced in SmarTest 7.1.0
