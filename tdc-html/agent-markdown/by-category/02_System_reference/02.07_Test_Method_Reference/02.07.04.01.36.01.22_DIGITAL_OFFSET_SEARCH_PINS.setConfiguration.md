# DIGITAL_OFFSET_SEARCH_PINS.setConfiguration()

Sets the configuration data for an offset search.

## Syntax

```
DIGITAL_OFFSET_SEARCH_PINS& setConfiguration(DIGITAL_OFFSET_SEARCH::[DigitalOffsetSearchConfigDataType](<02.07.04.01.36.01.32_DigitalOffsetSearchConfigDataType.md>) & configdata);
```

Parameter
 |

Parameter

 |

Description

 |
 |

configdata

 |

The configuration data, such as search type, resource type, start value, stop value, etc.. For more data types, see [DigitalOffsetSearchConfigDataType](<02.07.04.01.36.01.32_DigitalOffsetSearchConfigDataType.md>).

 |

## Return value

A reference to the [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) object.

[DigitalOffsetSearchConfigDataType](<02.07.04.01.36.01.32_DigitalOffsetSearchConfigDataType.md>)
