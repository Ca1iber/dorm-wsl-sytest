# EVENT_... (DC events API reference)

DC events allow you to control initiate measurements as well as control voltage or current on DC Scale pins and PMUs on standard pins.

 The [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class is the base class for all other specific event types.
