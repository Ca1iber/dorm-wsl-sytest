# RESULT_AREA_CONFIG_SET.pin()

This function returns a reference to the RESULT_AREA_CONFIG_PINS object for the specified pin list.

You can call the member functions of RESULT_AREA_CONFIG_PINS after creating a pin object. This API is supported by Smart Scale pins for sequencer based DC value measurement results and for DPS pins supporting DC dynamic measurements such as UHC4T and DPS128.

## Syntax

```
RESULT_AREA_CONFIG_PINS& pin(const STRING& pinList);
```

Parameter
 |

Parameter

 |

Description

 |
 |

pinList

 |

The list of pins for which to configure the result area. For the error map result area, unless the area is used for digital capture results, all pins of a port must have the same configuration.

 |

## Return value

Reference to the [RESULT_AREA_CONFIG_PINS()](<02.07.04.01.190.01_RESULT_AREA_CONFIG_PINS.md>) object for the specified pin list.
