# DIGITAL_WAVEFORM.levelStop()

This function specifies the stop offset for the level search. The default value is the maximum level value that the system supports.

## Syntax

```
DIGITAL_WAVEFORM& levelStop(INT level_offset);
```

Parameter
 |

level_offset

 |

The stop offset level. This is a relative value.

For STD mode: Actual voltage = vol + level_offset * levelResolution

For FAST mode: Actual voltage = vth+ level_offset * levelResolution

 |
