# getAnaSet()

Retrieves the analog set used by a specific test.

## Syntax

```
string getAnaSet();
```

List of parameters

There are no parameters.

## Example

```
string analogSetName = rdi.id("AWG_1").getAnaSet();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
