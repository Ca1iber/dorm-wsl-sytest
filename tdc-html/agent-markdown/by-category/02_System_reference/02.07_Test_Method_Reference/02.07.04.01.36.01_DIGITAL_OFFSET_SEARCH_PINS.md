Holds the timing/level offset search conditions for the pins specified with [DIGITAL_OFFSET_SEARCH_TASK.pin()](<02.07.04.01.36.03_DIGITAL_OFFSET_SEARCH_TASK.pin.md>).

It is a subclass of [DIGITAL_OFFSET_SEARCH_TASK](<02.07.04.01.36_DIGITAL_OFFSET_SEARCH_TASK.md>). You cannot directly create an object for it. An instance of this class is returned by DIGITAL_OFFSET_SEARCH_TASK.pin().

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/DigitalOffsetSearchPins.h.

## Syntax

This class has no constructor.

List of parameters

There are no parameters.

Return value

There is no return value.
