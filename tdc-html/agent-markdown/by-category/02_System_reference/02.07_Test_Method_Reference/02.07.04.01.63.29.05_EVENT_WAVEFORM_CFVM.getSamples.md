# EVENT_WAVEFORM_CFVM.getSamples()

Reads the number of waveform samples that have been defined by [EVENT_WAVEFORM_CFVM.cForce()](<02.07.04.01.63.29.01_EVENT_WAVEFORM_CFVM.cForce.md>).

The number of samples is read from the corresponding [EVENT_WAVEFORM_CFVM](<02.07.04.01.63.29_EVENT_WAVEFORM_CFVM.md>) object and returned as an integer value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getSamples(INT & samples) const;
```

Parameter
 | Parameter  | Description |
 | samples |

The read number of samples.

 |

Return value

There is no return value.

## Example

For an example see [EVENT_WAVEFORM_CFVM](<02.07.04.01.63.29_EVENT_WAVEFORM_CFVM.md>).
