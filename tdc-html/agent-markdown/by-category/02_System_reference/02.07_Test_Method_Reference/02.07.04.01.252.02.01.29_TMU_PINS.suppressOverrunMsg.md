# TMU_PINS.suppressOverrunMsg()

This function allows you to suppress any overrun error messages. For more information see [Pin Scale 1600 TMU Overrun Errors. ](<../02.05_Test_Head_Cards/02.05.04.01.07.07.01_Pin_Scale_1600_TMU_overrun_errors.md>)

## Syntax

```
void suppressOverrunMsg(Boolean suppress);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

suppress

 |

If set to TRUE, overrun error messages are suppressed.

 |

Return value

There is no return value.

## Functional changes

- Introduced in SmarTest 7.2.0
