# CALC_COHERENCY

The coherent sampling equation is:

```
Signal_Frequency / Sampling_Frequency = N_Periods / N_Samples
```

If three parameters are provided, the `CALC_COHERENCY` API calculates the fourth parameter to fulfill the coherency condition.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Calc_Coherency.h.

## Calculate the coherent signal frequency

```
void CALC_COHERENCY (DOUBLE fs, DOUBLE * fa, INT N, INT M);
void CALC_COHERENCY (DOUBLE fs, DOUBLE * fa, INT N, DOUBLE desired_fa);
void CALC_COHERENCY (DOUBLE fs, DOUBLE * fa, INT N, DOUBLE desired_fa,
                     enum TM::CALC_COHERENCY_OPT option = TM::CLOSEST);
```

## Calculate the coherent sampling frequency

```
void CALC_COHERENCY (DOUBLE * fs, DOUBLE fa, INT N, INT M);
void CALC_COHERENCY (DOUBLE * fs, DOUBLE fa, INT N, DOUBLE desired_fs);
void CALC_COHERENCY (DOUBLE * fs, DOUBLE fa, INT N, DOUBLE desired_fs,
                     enum TM::CALC_COHERENCY_OPT option = TM::CLOSEST);
```

`option`

This parameter specifies how approximate `fa` is to `desired_fa`.

- `TM::CLOSEST`: default value. The closest `fa` is chosen, no matter its value is lower or higher than `desired_fa`.
- `TM::LOWER`: the closest `fa` which is lower than `desired_fa` is chosen.
- `TM::HIGHER`: the closest `fa` which is bigger than `desired_fa` is chosen.
 |

## Example

- This example calculates the closest coherent signal frequency. The digitizer's sampling rate is 110 Msps, 4096 samples are captured and the desired signal frequency is 22.7 MHz. The result is a signal frequency `fa` of 22.6928 MHz.

```
DOUBLE Fa_ADC_test1;
CALC_COHERENCY (110E6, &Fa_ADC_test1, 4096, 22.7E6, TM::CLOSEST);
```

- This example calculates the highest possible coherent sampling frequency lower than the desired sampling frequency 200 Ksps. The result is a sampling frequency `fs` of 186.1818 kHz.

```
DOUBLE freqs;
CALC_COHERENCY (&freqs, 1E3, 2048, 200E3, TM::LOWER);
```
