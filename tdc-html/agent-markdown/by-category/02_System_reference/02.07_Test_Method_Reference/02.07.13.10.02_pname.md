# pname()

Specifies a protocol to be used in a protocol test.

## Syntax

```
pname(const string& sProtocolName);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

sProtocolName

 |

The defined protocol to use.

 |

## Example

```
rdi.protocol().pname("i2c").write(0x1,0x2).execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
