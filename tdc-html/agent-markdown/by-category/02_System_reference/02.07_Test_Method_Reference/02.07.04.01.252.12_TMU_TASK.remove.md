# TMU_TASK.remove()

Removes the TMU object defined for the specified pin list.

## Syntax

```
void remove(const STRING& pinlist);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

pinlist

 |

 |

Return value

There is no return value.
