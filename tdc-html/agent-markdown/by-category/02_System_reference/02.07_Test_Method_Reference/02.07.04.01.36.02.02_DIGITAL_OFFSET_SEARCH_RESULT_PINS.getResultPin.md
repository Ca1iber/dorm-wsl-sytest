# DIGITAL_OFFSET_SEARCH_RESULT_PINS.getResultPin()

Returns the [defined result pins](<02.07.04.01.36.02.01_DIGITAL_OFFSET_SEARCH_RESULT_PINS.setResultPin.md>).

## Syntax

```
STRING getResultPin();
```

List of parameters

There are no parameters.

## Return value

Returns the result pins defined with [DIGITAL_OFFSET_SEARCH_RESULT_PINS.setResultPin()](<02.07.04.01.36.02.01_DIGITAL_OFFSET_SEARCH_RESULT_PINS.setResultPin.md>).
