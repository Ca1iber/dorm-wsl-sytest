# rdi.id().getAlarmPassFailPerId()

Gets pass/fail results on a specified label.

## Syntax

```
bool getAlarmPassFailPerId();
```

## Example

```
RDI_BEGIN();
...
  rdi.dc("a").pin("dig").iForce(0).vMeas().execute();
...
RDI_END();

bool bPF = rdi.id("a").getAlarmPassFail("AVI");
bool bPPF = rdi.id("a").getAlarmPassFailPerId("AVI");
```
