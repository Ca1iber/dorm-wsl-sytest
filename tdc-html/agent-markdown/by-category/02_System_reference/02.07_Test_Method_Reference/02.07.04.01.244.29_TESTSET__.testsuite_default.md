# TESTSET().testsuite_default()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) cancels the test name which has been set by a prior call of the [testsuite(const STRING &name)](<02.07.04.01.244.28_TESTSET__.testsuite.md>) member function and returns to the default mode.

In default mode, the [TestSuiteNameAttrType](<../02.10_Data_Logging/02.10.01.06.05.64_TestSuiteNameAttrType.md>) found in the [TestSuiteStartEvent](<../02.10_Data_Logging/02.10.01.06.03.20_TestSuiteStartEventType.md>) is used to identify the test suite, which is the parent test suite of the currently active test method.

## Syntax

```
TESTSET & testsuite_default();
```

## Example

```
TestSet.testsuite_default();
```
