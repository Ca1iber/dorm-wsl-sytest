# Calling C-Source Functions

Test method program is written in C++. However, you may want to call C-source functions from your test method program. To do this, follow the procedures below.

## Procedures

### Using the C-source files in the test method

- Create a C-source file (for example, myCfunctions.cpp) such as below in your project directory and name it with the suffix ".cpp" although it is written in C.

```
// myCfunctions.cpp

  :
void SetTimer()
{
  // code
}

double GetLap(int total)
{
  // code
}
  :
```

- Create a header file (for example, myCfunctions.h) corresponding to the C-source file in your project directory and declare the C-source functions as below:

```
// myCfunctions.h

extern void SetTimer();
extern double GetLap(int *);
  :
```

- Create your test method source file, include the header file and use the C-source functions in the test method as below:

```
// Test1kHz1V.cpp
  :
#include "myCfunctions.h"
  :
 virtual void run()
 {
      :
    //use your C-source functions here
      :
}
  :
```

- Build the test method project.

### Calling the functions from an existing C-source library

- Copy the existing C-source library in the directory device/testmethod/sh_lib-EL7-64bit/preload.
- Create a test method source file and add the extern statements with keyword "C" in the header of the test method file as below:

```
// Test1kHz1V.cpp

  :

extern "C" void SetTimer();
extern "C" double GetLap(int *);

```

- Write your test method program in the test method source file and use the C-functions in it.
- Build your test method project.

## Functional changes

- Introduced before SmarTest 6.3.2
