# Routing Tools hardware

The Routing Tools support sequencer鈥慶ontrolled utility lines. These resources are controlled via serial interfaces that must be wired on the DUT board.

The [Sequencer-controlled utility lines](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01_Sequencer-controlled_utility_lines.md>) can be controlled by digital pins that are connected to the inputs of the serial interfaces.

## Sequencer鈥慶ontrolled utility lines

The utility lines feature a four-wire serial interface as shown below. ![Generation of utility lines on active wiring board](<../../../../raw/137348.png>)

To make use of sequencer鈥慶ontrolled utility lines you need to route four digital pins on the DUT board to the appropriate serial interface pins. For more information, refer to [Sequencer-controlled utility lines](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01_Sequencer-controlled_utility_lines.md>).

For the pogo pin assignment of the utility pogo blocks refer to [Pogo pin assignment - Utility pogo blocks](<../02.03_DUT_board_design_reference/02.03.06.08_Pogo_pin_assignment_-_Utility_pogo_blocks.md>). The following signals are required for sequencer controlled utility lines:

- FRAMn: Frame, active low
- SINP: Serial input to the FPGA on active wiring board
- SCLK: Serial clock
- SOUT: Optional serial output from the FPGA on active wiring board
The serial interface for sequencer鈥慶ontrolled utility lines can handle the data stream for more than one utility block. This cascading of serial interfaces of utility blocks is called "ganging" in the context of the sequencer鈥慶ontrolled utility lines. For more information, refer to [Ganging utility blocks](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01.03_Ganging_utility_blocks.md>).
