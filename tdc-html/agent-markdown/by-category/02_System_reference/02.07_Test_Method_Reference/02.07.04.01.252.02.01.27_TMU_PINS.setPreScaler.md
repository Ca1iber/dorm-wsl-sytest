# TMU_PINS.setPreScaler()

Sets the prescaler for the TMU pin(s). The specified prescaler is ignored when the data rate is specified with [TMU_PINS.setDatarate()](<02.07.04.01.252.02.01.19_TMU_PINS.setDatarate.md>).

## Syntax

```
TMU_PINS& setPreScaler(UINT32 val);
TMU_PINS& setPreScaler(UINT32 val, TMU::DATARATE_DEPENDENT_VALUES_TYPE& settings);
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

val

 |

The value of prescaler.

 |
 |

I

 |

settings

 |

DATA_RATE_DEPENDENT_VALUES_TYPE is a data structure designed to receive the values for the prescaler (prescaler member) and the interdiscard (Interdiscard member).

 |

## Return value

A reference to the TMU_PINS object is returned.
