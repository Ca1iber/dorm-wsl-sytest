# rdi.disableWarning()

Disables SmartRDI warnings from the execution of a specific code segment to be shown in the UI report window.

You must put this function outside the RDI_BEGIN and RDI_END block which holds the specific segment.

This function can only disable the SmartRDI warnings to be shown in the UI report window, but cannot impact any warnings from MAPI or firmware commands.

## Syntax

```
rdi.disableWarning();
```

Return value

There is no return value.

## Example

```
rdi.disableWarning();
   RDI_BEGIN();
      ...
   RDI_END();
```
