# Changing spec value in primary timing spec set

To change the specified spec value in the current primary timing spec set, return the class object of the TIMING_SPEC API by `Primary.getTimingSpec()` and execute a member function of the TIMING_SPEC API as follows.

```
Primary.getTimingSpec().<memberFunction>;
```

where, <memberFunction> is a member function of the [TIMING_SPEC](<02.07.04.01.249_TIMING_SPEC.md>) API. Only one member function can be specified. You cannot specify other member functions of the [PRIMARY_STATUS](<02.07.04.01.167_PRIMARY_STATUS_-__Primary.md>) API in this statement.

The following member functions of the TIMING_SPEC API are available for changing a spec value.

 | Task to be executed  | <memberFunction> |
 | Change the spec value to the specified value  | [change()](<02.07.04.01.249_TIMING_SPEC.md#_29809__dle_change>) |
 | Restore all the spec values to the original values  | [restore()](<02.07.04.01.249_TIMING_SPEC.md#_29809__dle_restore>) |
