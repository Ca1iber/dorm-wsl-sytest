# TMU_PINS.binaryUpload()

Enables or disables the binary upload of the TMU pin(s).

## Syntax

```
TMU_PINS& binaryUpload(Boolean flag = TRUE);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

flag

 |

Enables or disables the binary upload. It can be:

- TRUE: enables the binary upload
- FALSE: disables the binary upload

Default is TRUE.

 |

## Return value

A reference to the TMU_PINS object is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
