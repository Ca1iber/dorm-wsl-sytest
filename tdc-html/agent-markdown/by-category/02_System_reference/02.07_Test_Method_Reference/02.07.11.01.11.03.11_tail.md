# tail()

Extracts a specified number of characters from the right end of a state character sequence.

The length parameter specifies the number of characters to extract.

Errors will be issued if the length parameter

- is not an integer number or
- is larger then the sequence length.

## Syntax

```
sequence := tail(sequence, length)
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

sequence

 |

Source state character sequence from which the tailing characters will be extracted.

 |
 |

I

 |

length

 |

Specifies the number of state characters to be extracted.

 |

## Example

`tail("10ZR", 2)` results in "`ZR`".

`tail("10ZR", 4)` results in "`10ZR`".

`tail(`data`, 3)` results in data[`2..0`].

`tail("001LHR", 7)` results in "ERROR: length parameter too large."

`tail("001LHR", "01Z")` results in "ERROR: "01Z" is not convertible to integer."
