# SmartRDI 7.5.1

This section summarizes software changes including new features and enhancements in SmartRDI 7.5.1.

Changes and new features
 |

Category

   | Description |
 | General  | A new command rdi.perLabelPassFailNoBreakVec(bool) to control the flag of [Pass/Fail per label without break vectors](<02.07.13.08.09.02_Pass_Fail_per_label_without_break_vectors.md>) in test method. |
 | [Alarm handling for DCVI](<02.07.13.09_SmartRDI__Alarm_handling_for_DCVI.md>) |

- Alarm handling on other ports.
- An [alarm setup template file](<02.07.13.09.01_Alarm_setup_file.md>) is created when the alarm handling feature is enabled in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>).
-

vMeasRange & iMeasRange auto-handling on DPS128/PVI8.

- Alarm handling for vPulse/iPulse.
-

Debug value in the Report window.

 |
 | Routing |

- LINK feature.
- [downloadPmuxMset()](<02.07.13.15.05.02_rdi.route__.downloadPmuxMemSet.md>), [enableOnlyActiveSites()](<02.07.13.15.05.03_rdi.route__.enableOnlyActiveSites.md>), and handleDisabledSites() optimization.
-

ZIP file support.

 |
 | [ORE](<02.07.13.08.20_Using_Offline_Result_Emulation_in_SmartRDI.md>) |

- A new keyword ORE_TEMPLATE_BY_USER_CODE in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>) to enable the generation of an ORE template file based on user code.
- An [ORE master file](<02.07.13.08.20_Using_Offline_Result_Emulation_in_SmartRDI.md>) can contain several ORE files to support collaborative development.
 |
 | DC |

- [PPMU](<02.07.13.12.01_DC_test_with_digital_channels.md>) pattern controller setup with [RDI_UNIT_INIT()](<02.07.13.08.01.07_RDI_UNIT_INIT.md>) can be executed in the first run in loops.
- Parallel DC waveform and sampling with multiple pins.
- [insertVec()](<02.07.13.12.02.21_insertVec.md>) supports the same pin in different vector numbers with cont().
- insertSub() supports waveform sourcing and sampling.
- dcPowerBudget() assigns a power budget for DC tests.
- pulseEnergyBudget() assigns an energy budget for pulsed tests.
 |
 | EMAP  | Combined fail count with two new functions:

- [combinedFailCount()](<02.07.13.16.01_combinedFailCount.md>)
- [rdi.id().getCombinedFailCount()](<02.07.13.16.17_rdi.id__.getCombinedFailCount.md>)
 |
 | TMU  |  defines the comparator hold-off time. |

## Supported SmarTest versions

SmartRDI 7.5.1 supports SmarTest 7.5.1.
