# Synchronization

#### Subtopics

- [Vector based synchronization](<02.07.11.01.10.01_Vector_based_synchronization.md>)

The synchronization of protocol based testing varies per type of protocol test.

Synchronized protocol tests are synchronized to vectors being generated by the simulation-based pattern of other ports.

This section describes the concepts used with SmarTest.
