# vForceRange()

Specifies the range of forcing voltage for DC Scale pins. The function is supported by DPS128 and XPS256 pins.

- XPS256 pins:

The function can be used in the code‑based mode and in the pattern‑based mode. The pin must not be disconnected for changing the current force range.

- Other DC Scale pins:

The function can be used only in the code‑based mode. It needs to be used with the function [vForce()](<02.07.13.12.02.41_vForce.md>) or [iForce()](<02.07.13.12.02.16_iForce.md>). Disconnect the pin before changing the range.

## Syntax

```
dcBase& vForceRange(double dVForceRange);
dcBase& vForceRange(string SpecName,TA::LEVEL_SPEC);
```

  Parameters

Parameters
 | Parameter  | Description |
 | dVForceRange  | The range of the forcing voltage. |
 | SpecName  | The spec variable name in Level setup.  |   Return value A reference to the dcBase object.

## Examples

### Set force range in code‑based mode

```
rdi.dc().pin("DPS_1").vForce(1 V).vForceRange(8 V).execute();
```

### Change range of AVI64 or FVI16 without disconnecting

For an example that shows the correct sequence of programming the force or clamp value and the force or clamp range in pattern‑based mode, refer to AVI64 Use Case - Change range without disconnecting in the SmarTest 7.6.x documentation.
