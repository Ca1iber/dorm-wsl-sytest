# DISABLE_CLEAR_CACHE_WARNING

This API suppresses the warning that is issued by default whenever the test method cache is cleared.

After using the DISABLE_CLEAR_CACHE_WARNING API, you can use the ENABLE_CLEAR_CACHE_WARNING API to restore the default behavior.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

## Syntax

```
DISABLE_CLEAR_CACHE_WARNING();
```

List of parameters

There are no parameters.

## Example

```
DISABLE_CLEAR_CACHE_WARNING();
```

The DISABLE_CLEAR_CACHE_WARNING API suppresses the warning that is issued when the test method cache is cleared.

## Functional changes

- Introduced before SmarTest 6.3.2
