# EVENT_CFVM.limits()

Sets voltage limits to compare against thresholds.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_CFVM & limits(const LIMIT & limits);
```

Parameter
 | Parameter  | Description |
 | limits |

A [LIMIT](<02.07.04.01.126_LIMIT.md>) object that already has been filled with the values for the lower and upper limits.

 |

## Return value

A reference to the corresponding [EVENT_CFVM](<02.07.04.01.63.04_EVENT_CFVM.md>) object.

## Example

For an example see [EVENT_CFVM](<02.07.04.01.63.04_EVENT_CFVM.md>).
