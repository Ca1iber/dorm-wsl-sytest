# EVENT_WAVEFORM_VCIM.getSamples()

Reads the number of waveform samples that have been defined by [EVENT_WAVEFORM_VCIM.vClampLow()](<02.07.04.01.63.35.01_EVENT_WAVEFORM_VCIM.vClampLow.md>) or [EVENT_WAVEFORM_VCIM.vClampHigh()](<02.07.04.01.63.35.03_EVENT_WAVEFORM_VCIM.vClampHigh.md>).

The number of samples is read from the corresponding [EVENT_WAVEFORM_VCIM](<02.07.04.01.63.35_EVENT_WAVEFORM_VCIM.md>) object and returned as an integer value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getSamples(INT & samples) const;
```

Parameter
 | Parameter  | Description |
 | samples |

The read number of samples.

 |

Return value

There is no return value.

For an example see [EVENT_WAVEFORM_VCIM](<02.07.04.01.63.35_EVENT_WAVEFORM_VCIM.md>).
