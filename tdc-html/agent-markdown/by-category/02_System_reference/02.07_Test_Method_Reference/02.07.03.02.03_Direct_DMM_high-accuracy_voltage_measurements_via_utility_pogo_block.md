# Direct DMM high-accuracy voltage measurements via utility pogo block

The  Smart Scale test system has BNC (Bayonet Neill-Concelman) connectors for the DC-rail of each card cage, while the EXA Scale test system has a DSUB-9 connection on the front panel for an Ext. DC-rail. This allows connecting the Keysight 3458A Digital Multimeter (DMM) to the V93000 and doing high-accuracy voltage measurements through utility pogo pins.

## About this task

To force a voltage and measure it with a digital multimeter (DMM), requires integrating the DMM in the model file, defining pins for the measurement, and setting up a test method.

## Before you begin

These high-accuracy voltage measurements require the Agilent 3458A Digital Multimeter (DMM). On Smart Scale test systems, the DMM must be connected to the card cage of the utility pogo pins to be used for the measurement. On the EXA Scale test system, the DMM must be connected at the front panel of the System control board (marked "Ext. DC-rail").

## Procedures

### Modifying the model file

To integrate the DMM in the [model file](<../02.04_Model_File_and_Licensing/02.04.01_The_model_file.md>) you need to specify the GPIB interface (hpib_interface) in the GLOBAL section and add a DMM section:

- In the [GLOBAL section](<../02.04_Model_File_and_Licensing/02.04.01.03.02.01_GLOBAL_section.md>) type, for example:

```
GLOBAL
...
  hpib_interface = vxi11/192.168.0.100/gpib0
...
```

- To add the [DMM section](<../02.04_Model_File_and_Licensing/02.04.01.03.02.07_DMM_section.md>) type, for example:

```
DMM
  1: cardcage=1, type=HP3458A, address=22
...
```

 Note For EXA Scale test systems the "cardcage=X" should be omitted.
- Save the model file and restart SmarTest.

### Defining the Utility DCpins

To access the DMM via the utility pogo pins, you need to define Utility DC pins in the Digital Pins configuration tool:

- According to your design of the DUT board you have already selected the utility block where your Utility DC measurement will be connected to the DUT (On EXA Scale test systems, you can connect the DC-rail only to utility block 1).
- The naming of the Utility DC tester channel is "UTIDC" + utility block number.

### Setting up the test method

In the test method, set up the utility connections and measurement parameters and execute the [DVM_TASK](<02.07.04.01.55_DVM_TASK.md>). In this example, for a Smart Scale test systems, the EXT and the DUT relay on the clock board are closed by setting dc_target to EXT in [FLEX_PIN_RELAY](<02.07.04.01.68.01_FLEX_PIN_RELAY.md>) (see [RLYC, RLYC? - (ReLaY Control)](<../02.06_Command_Reference/02.06.02.02.206_RLYC__RLYC__-__ReLaY_Control.md>) for details).

For example:

```
DVM_TASK   measDVM;
FLEX_RELAY connectDVM, disconnectDVM;
TASK_LIST  taskList;

ON_FIRST_INVOCATION_BEGIN();

    connectDVM.pin   ("Utility_Pogo_1").set("X","EXT");
    disconnectDVM.pin("Utility_Pogo_1").set("X","OFF");

    measDVM.pin("Utility_Pogo_1")
           .doAcal(TM::DO_ACAL_IF_NECESSARY);

    taskList.add(connectDVM)
            .add(measDVM)
            .add(disconnectDVM)
            .execute();

ON_FIRST_INVOCATION_END();

ARRAY_D result = measDVM.getValues("Utility_Pogo_1");

for ( int i = 0; i < result.size(); ++i )
{
    cout << "Measured Value: " << result[i] << endl;
}
```
