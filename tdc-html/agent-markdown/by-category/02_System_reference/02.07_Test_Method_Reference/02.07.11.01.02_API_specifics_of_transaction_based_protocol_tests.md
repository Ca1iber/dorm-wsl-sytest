# API specifics of transaction based protocol tests

Setting and retrieving values are generally done on the site in focus. Thus it is possible to perform a trimming test by evaluating and modifying per site results and parameter values.

 Note Setting a parameter to site specific values must not cause two different lengths of pattern.

If a parameter value influences the length of a transaction, and thus the length of pattern, it must be the equal on all sites.

 Note Any inconsistency will only be detected when the test is bound to hardware, for example, a `flush()` command is executed.
