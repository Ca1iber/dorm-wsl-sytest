# Execution Speed of the PPMU

The execution performance of the PPMU measurements depends on the selected period (PCLK).

The reason for this is that during a PPMU measurement, breakvectors are generated (to keep the device in a stable state). If the period is slow, the measurement becomes slower, because each break vector needs more time.

The recommendation is to select the period for DC measurements as small as possible. For this purpose, you you should select a timing value for the highest device speed in a DC measurement testsuite.

## Functional changes

- Introduced before SmarTest 6.3.2
