# FLEX_UTILITY_CHANNEL_RES

This class is a data container holding the settings of utility line channel resources.

In one [FLEX_RELAY](<02.07.04.01.68_FLEX_RELAY.md>) task, if you make different settings for a utility line channel resource by using multiple FLEX_UTILITY_CHANNEL_RES member functions or by using a member function multiple times, only the latest setting is downloaded to hardware when the task is executed.

You can specify a necessary wait time by using the [wait()](<02.07.04.01.68_FLEX_RELAY.md#_74892__dle_wait>) member function of FLEX_RELAY.

## Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/FlexUtilChannelRes.h.

  Constructor This class is always called as the subsidiary data container of the [FLEX_RELAY](<02.07.04.01.68_FLEX_RELAY.md>), API. Therefore, the FLEX_UTILITY_CHANNEL_RES class does not have a public constructor. Member functions In this class, the following public member functions are defined:

- [set()](<02.07.04.01.68.04_FLEX_UTILITY_CHANNEL_RES.md#_111118__dle_set>)
- [on()](<02.07.04.01.68.04_FLEX_UTILITY_CHANNEL_RES.md#_111118__dle_on>)
- [off()](<02.07.04.01.68.04_FLEX_UTILITY_CHANNEL_RES.md#_111118__dle_off>)

## Member functions

  set()

```
FLEX_UTILITY_CHANNEL_RES& set(const STRING& conditions);
```

This member function defines the setting for each of the specified utility line channel resources.

  Parameter

 | Parameter  | Description |
 | conditions  | The settings of the utility line channel resources in the same order as the resources specified in the [util_channelRes()](<02.07.04.01.68_FLEX_RELAY.md#_74892__dle_util_channelRes>) member function of [FLEX_RELAY](<02.07.04.01.68_FLEX_RELAY.md>). It is a list of "0", "1" or "x" separated with commas or spaces. "0" means setting the relay to off. "1" means setting the relay to on. "x" means no status change for the relay.  |   Return value A reference to the FLEX_UTILITY_CHANNEL_RES class object.   on()

```
FLEX_UTILITY_CHANNEL_RES& on();
```

This member function sets the specified utility line channel resources to on.

  List of parameters There are no parameters. Return value A reference to the FLEX_UTILITY_CHANNEL_RES class object.   off()

```
FLEX_UTILITY_CHANNEL_RES& off();
```

This member function sets the specified utility line channel resources to off.

  List of parameters There are no parameters. Return value A reference to the FLEX_UTILITY_CHANNEL_RES class object.

## Example

```
FLEX_RELAY flexRelay;
flexRelay.util_channelRes("UTI101,UTI102,UTI201").set("110");
flexRelay.util_channelRes("UTI301,UTI302").on();
flexRelay.util_channelRes("UTI401,UTI402").off();
flexRelay.execute();
```

This example sets the utility channel 101, 102, 301 and 302 to on and sets the utility channel 201, 401 and 402 to off.
