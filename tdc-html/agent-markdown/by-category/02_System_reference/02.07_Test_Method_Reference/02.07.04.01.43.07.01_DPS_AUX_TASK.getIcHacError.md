# DPS_AUX_TASK.getIcHacError()

The DPS_AUX_TASK.getIcHacError() member function retrieves the execution status of IcHac (current clamp high accuracy) events from the test method cache.

Refer to [DPS status flags - get...() functions](<02.07.04.01.43.07_DPS_status_flags_-_get...___functions.md>) for more information regarding the supported flags and the meaning of the flags.

The [DPS_AUX_PIN_TASK.checkIcHacError()](<02.07.04.01.43.01.01_DPS_AUX_PIN_TASK.checkIcHacError.md>) member function must be called upfront for reading the flags from the hardware into the test method cache.

This member function must be called outside of the ON_FIRST_INVOCATION_BEGIN() ... ON_FIRST_INVOCATION_END() block or within a FOR_EACH_SITE_BEGIN() ... FOR_EACH_SITE_END() block.

## Syntax

```
TM::DPS_AUX_TASK_STATUS getIcHacError(const STRING& pin);
```

Parameter
 | Parameter  | Description/Range |
 | pin  | Single pin for which the status flags should be retrieved. |

## Return value

The member function returns one of the following values of the enumerated type DPS_POWER_FLAG_STATUS:

 | Keyword  | Value  | State of the checked flags |
 | TM::AUX_TASK_STATUS_PASS  | 0  | The checked flag is not set. |
 | TM::AUX_TASK_STATUS_FAIL  | 1  | The checked flag is set. |

Return value in offline mode is TM::AUX_TASK_STATUS_PASS.

## Example

```
DPS_AUX_TASK auxTask;

ON_FIRST_INVOCATION_BEGIN();

    auxTask.pin("dps2").checkIcHacError();

ON_FIRST_INVOCATION_END();

if ( auxTask.getIcHacError("dps2") == TM::AUX_TASK_STATUS_PASS )
{
    cout << "auxTask.getIcHacError(\"dps2\") returned TM::AUX_TASK_STATUS_PASS" << endl;
}
else
{
    cout << "auxTask.getIcHacError(\"dps2\") returned TM::AUX_TASK_STATUS_FAIL" << endl;
}
```
