# EVENT_FILTER.getFilterValue()

Queries the value of the filter that has been defined by [EVENT_FILTER.setFilterValue()](<02.07.04.01.63.07.03_EVENT_FILTER.setFilterValue.md>).

## Syntax

```
void getFilterValue(EVENT_VALUE_DOUBLE &filterValue) const;
```

  Parameter

List of parameters
 | Parameter  | Description |
 | filterValue |

The filter value that has been programmed by [EVENT_FILTER.setFilterValue()](<02.07.04.01.63.07.03_EVENT_FILTER.setFilterValue.md>).

   |   Return value There is no return value.

## Example

For an example, see [EVENT_FILTER](<02.07.04.01.63.07_EVENT_FILTER.md>).
