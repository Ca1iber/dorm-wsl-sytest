# LEV_TRANSFER_PIN_TASK

The LEV_TRANSFER_PIN_TASK class is a data container that holds the object which reflects the level spec value. The LEV_TRANSFER_PIN_TASK class is called as a subsidiary data container of the LEV_TRANSFER_TASK class.

## Syntax

```
LEV_TRANSFER_PIN_TASK &specVal(const double &val);
```

Sets the level spec to the new value.

Parameter
 |

Parameter

 |

Description

 |
 |

val

 |

The new value of the level spec.

 |

Return value

A reference to the LEV_TRANSFER_PIN_TASK object.
