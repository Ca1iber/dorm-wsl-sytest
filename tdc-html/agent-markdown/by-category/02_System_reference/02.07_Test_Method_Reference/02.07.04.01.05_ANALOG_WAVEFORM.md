# ANALOG_WAVEFORM

The ANALOG_WAVEFORM API accesses the data container holding the contents of the waveform object.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Waveform.h.

## Class definition

### Constructor

```
ANALOG_WAVEFORM waveform_name (const STRING& label);
```

### Syntax

For creating an analog waveform object:

```
ANALOG_WAVEFORM waveform_name (const STRING& label);
```

For changing settings of a waveform object:

```
waveform_name.sub_func;
```

 |

waveform_name

 |

The created waveform object. (maximum length of waveform name is 256 characters).

 |
 |

sub_func

 |

Member function of the waveform data container. For retrieving data, only one member function is available.

 |

For retrieving settings:

```
return_value = waveform_name.sub_func;
```

### Constructor

```
ANALOG_WAVEFORM waveform_name (const STRING& label);
```

This constructor creates a class object that reflects an analog waveform. Here Waveform_name is the waveform object name and label is the waveform label name in the firmware. These names are independent. It is recommended to use identical names for easier waveform recognition.

Parameter
 |

label

 |

The waveform name which is downloaded to the firmware (maximum length of waveform name is 256 characters).

 |

## Member functions

The member function are described in alphabetical order.

### add()

```
ANALOG_WAVEFORM& add(ANALOG_WAVEFORM& p_waveform);
```

This member function creates the waveform component which can be concatenated along the time axis.

Note Before executing `FLUSH()` outside the `if-or-else` statement, it is recommended to use the `add()` function also outside the `if-or-else` statement. The `add() ` function adds a reference not a copy of the waveform object into the sequence object. Therefore, when a waveform object is added within the `if-or-else` statement, execute `FLUSH()` outside will lead to ERROR.

Parameter
 |

p_waveform

 |

The created waveform component.

 |

### amplitude()

```
ANALOG_WAVEFORM& amplitude(const DOUBLE amp);
ANALOG_WAVEFORM& amplitude(const INT amp);
```

This member function rescales the amplitude of the waveform. In case your waveform data exceeds the full scale of the selected core function, it will be automatically rescaled to full scale. But in this case you will see a warning message indicating that the rescaling will happen.

The signal amplitude is usually defined by the attenuator setting in the hardware setup. This setup offers maximum resolution and thus maximum signal quality.

The waveform amplitude should only be rescaled in case the required signal amplitude cannot be achieved with pure hardware attenuation or if the waveform is used for digital source.

Parameter
 |

amp

 |

The signal amplitude in [Vpk] (peak voltage). The signal range is 2 x amp.

 |

### rescale()

```
ANALOG_WAVEFORM& rescale(DOUBLE ratio);
```

This member function rescales the amplitude of the waveform. The new amplitude is calculated as follows:

- First, the offset (if any) of the original waveform is removed: new_value=value-offset.
- Then, the original waveform without any offset is rescaled according to the specified ratio: new_value *=ratio.
- Finally, The offset is added back to the rescaled waveform: new_value +=offset. This means, the offset remains as it is in the original and the rescaled waveform.

The signal amplitude is usually defined by the attenuator setting in the hardware setup. This setup offers maximum resolution and thus maximum signal quality.

The waveform amplitude should only be rescaled in case the required signal amplitude cannot be achieved with pure hardware attenuation or if the waveform is used for digital source.

Parameter
 |

ratio

 |

The factor that the waveform amplitude is rescaled with. The new amplitude is calculated as: new_value= ((value-offset)*ratio)+offset (see the details above).

For example, assume you have a waveform with:

- maximum amplitude=2.0V
- minimum amplitude=-1.0V
- offset= 0.5V

Rescaling this waveform by a factor of two would result in a new waveform with:

- maximum amplitude=((2.0V-0.5V)*2)+0.5V=3.5V
- minimum amplitude=((-1.0-0.5V)*2)+0.5V=-2.5V
- offset= 0.5V (the offset remains as it is in both the original and the rescaled waveforms)
 |

### samples()

```
ANALOG_WAVEFORM& samples(INT samples);
```

This member function defines the number of samples of the waveform.

If a waveform has been generated, calling this member function will perform the following actions:

- If the waveform size is greater than the parameter samples, the last samples are cut off until the size of the new waveform is equal to the parameter samples.
- If the waveform size is less than the parameter samples, zero is added after the last sample until the size of the new waveform is equal to the parameter samples.

Parameter
 |

samples

 |

The number of samples.

 |


This member function specifies the number of stairs, when the wave_type parameter in definition() is set TM:STAIRCASE.

Parameter

num

 |

The number of stairs.

## Example

- This example creates a new waveform object sine_dual of the ANALOG_WAVEFORM class. The waveform is downloaded to the firmware with the name of sine_dual.

```
ANALOG_WAVEFORM sine_dual ("sine_dual");
```

- This example rescales the amplitude of waveform1 to range from 0.0 to 0.3.

```
ARRAY_D arr_sine(4096);
ARRAY_D wave_data;
DOUBLE ampl = 10.0;
ANALOG_WAVEFORM waveform1("waveform1");
for (INT i = 0; i < 4096; i++)
{
arr_sine[i] = ampl*sin(2.0*M_PI*(double)i*37.0/4096.0);
}
wave_data = waveform1.definition(arr_sine).min(0.0).max(0.3);
```

- This example rescales the amplitude of waveform1 to range from 0.2 to 0.8.

```
ARRAY_D arr_sine(4096);
ARRAY_D wave_data;
ANALOG_WAVEFORM waveform1("waveform1");
...
wave_data = waveform1.definition(arr_sine).amplitude(0.3).offset(0.5);
```

- This example rescales the amplitude of waveform1 to range from -0.4 to 0.4.

```
ARRAY_D arr_sine(4096);
ARRAY_D wave_data;
ANALOG_WAVEFORM waveform1("waveform1");
...
wave_data = waveform1.definition(arr_sine).rescale(0.8);
```

- This example creates a new waveform object sine_dual of the ANALOG_WAVEFORM class and assigns it to the ADC_IN pin. The pin statement is only required if the waveform object is not assigned to an analog set, either directly or via a sequencer program.

When the waveform is assigned to a sequencer program or analog set, it is automatically downloaded to the pin.

```
ANALOG_WAVEFORM sine_dual ("sine_dual");
sine_dual.pin ("ADC_IN");
```

- This example creates a waveform object sine_dual composed of sine_5MHz and sine_10MHz. This waveform is downloaded to the firmware with the name of sine_dual.

```
ANALOG_WAVEFORM sine_dual("sine_dual");
sine_dual_freq.add(sine_5MHz).add(sine_10MHz);
```

```
ARRAY_D wave_data;

wave_data = sine_50.definition(TM::ASCII, "../waveform/arr_sine_1.txt");
```

- This example defines the sine_50 waveform by referencing an array `arr_sine_1.`

```
const INT nSamples = 1024;
const INT nBits = 10;
const DOUBLE maxAmplitude = (1 << (nBits-1)) - 1;
ARRAY_I arr_sine_1 (nSamples);
ARRAY_D wave_data;

for (INT i=0; i<nSamples; i++) {
arr_sine_1[i] = round(sin(i*2*M_PI/nSamples)*maxAmplitude);}

wave_data = sine_50.definition(arr_sine_1);
```

- This example defines a DC waveform `dc_0p2` for the LF AWG with the DC value of 0.2 V.

```
ARRAY_D wave_data;
wave_data = dc_0p2.definition(TM::DC).dc(0.2).coreFunction(TM::LF);
```

- This example defines a ramp waveform ramp_neg. It has 16 samples and goes from 1.6V down to 0.1V.

```
ARRAY_D wave_data;
wave_data = ramp_neg.definition(TM::RAMP).direction(TM::NEG).samples(16).min(0.1).max(1.6);
```

- This example defines a sine waveform `sine_50` for the VIDEO or HF AWG. Within this waveform, there are 50 periods and the initial phase is 90 degrees.

```
ARRAY_D wave_data;
wave_data = sine_50.definition(TM::SINE).periods(50).phase(90).coreFunction(VIDEO);
```

- This example defines a stair waveform Staircase_1. It has 32 samples, 8 stairs. The amplitude is from 0.5V to 1.9V; this means an increase of 0.2V every 4 samples.

```
ARRAY_D wave_data;
wave_data = Staircase_1.definition(TM::STAIRCASE).samples(32).stairs(8).min(0.5).max(1.9);
```

-  This example sets up an analog set for ADC and DAC linearity test with APIs. ANALOG_WAVEFORM is used to create the ramp wave for ADC linearity test.

```
ANALOG_SET Analog_Set_1("1");
// Waveforms
ANALOG_WAVEFORM Wave_ADC_Ramp("ADC_Ramp");
Wave_ADC_Ramp.definition(TM::RAMP).direction(TM::POS).samples(256).min(-3.0).max(3.0);
// Sequencer Programs
ANALOG_SEQUENCER Seq_ADC_Ramp_seq("ADC_Ramp_seq");
Seq_ADC_Ramp_seq.add(TM::HALT,Wave_ADC_Ramp);
ANALOG_SEQUENCER Seq_DAC_Ramp_seq("DAC_Ramp_seq");
// Commands,Trigger,Size,Disc,Core
Seq_DAC_Ramp_seq.add(TM::HALT,TM::POST,256,0,TM::BOTH);
// Master Clock Settings
Analog_Set_1.CLOCK_DOMAIN(2,TM::ANALOG).clock(TM::MCLK_AUTO);
// Conversion Clock Settings
Analog_Set_1.AWG("ADC_AWGav8").clockDomain(2).rule(TM::AUTOFS).frequency(1.0000e+05);
Analog_Set_1.DGT("DAC_DGTav8").clockDomain(2).rule(TM::AUTOFS).frequency(1.0000e+05);
// Hardware Settings
Analog_Set_1.AWG("ADC_AWGav8").coreFunction(TM::LF).sequencerProgram(Seq_ADC_Ramp_seq)
            .attn(10.850).vOffset(1.3399).filter("30K").dutImpedance(1.0000e+06);
Analog_Set_1.DGT("DAC_DGTav8").coreFunction(TM::LF).sequencerProgram(Seq_DAC_Ramp_seq);
FLUSH();

```

## Functional changes

- Introduced in SmarTest 6.5.0
- SmarTest 6.5.2: You can directly assign the waveform data of the analog waveform object to a variable of the ARRAY_D or ARRAY_I type.
- SmarTest 7.1.3: The new VHFIQ core function of the MCE is added to coreFunction().
- SmarTest 7.2.2: Analog waveform name (or, label) can be up to 256 characters long
