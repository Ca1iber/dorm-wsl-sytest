# d2s execLabel

The d2s execLabel method adds any existing pattern with the same port configuration to the burst.

 Note The exact amount of cycles of that pattern needs to be specified by the user.

This method uses the same mechanism as the `expectValue` method returning only pass/fail results.

Thus it cannot be combined with a read in the same `LABEL_BEGIN-LABEL_END` block.

## Syntax

```
virtual void execLabel(std::string labelName, unsigned long long cycles=0);
```

## Example

The following excerpt illustrates how the execLabel method is used to add an arbitrary pattern to the d2s-burst.

In learning mode it will generate a write label, add the arbitrary pattern to the burst label `MyBurstLabelName` and execute the pattern at `d2s_LABEL_END()`.

In production mode only the `MyBurstLabelName ` pattern will be executed at `d2s_LABEL_END()`.

```
virtual void run()
{
   d2sFramework fr;
   d2sJTAG& jtag = d2sJTAG::Instance();

   // Register your protocol with the framework
   fr.registerTransactionPort(jtag);

   ON_FIRST_INVOCATION_BEGIN();
      fr.d2s_LABEL_BEGIN("MyBurstLabelName", d2sFrameWorkModeType::LearningMode);
         jtag.write(0xdead, 0xbeaf);
         jtag.execLabel("arbPattern", 1024);
      fr.d2s_LABEL_END();

      // do your measurement here

   ON_FIRST_INVOCATION_END();
   ...
}
```

The static write patterns created by the code above for a single port setup would be saved into the device vector directory as:

`d2s_jtag_AT_W_0xdead_0xbeaf`

Note The arbitrary pattern will be added to the burst label only!
