To create a DC test program, first, set up the DC resources using the following APIs, depending on the DC resource type and your purpose.

 Note Use [FlexDC APIs](<02.07.03.02.01.01_FlexDC_APIs.md>) for dc test programming to save test time.

## To create a DC test program for pin PMUs

The following APIs can be used as shown in [DC Test Programming with PPMU](<02.07.03.02.02_DC_Test_Programming_with_PPMU.md>).

- [PPMU_SETTING](<02.07.04.01.160_PPMU_SETTING.md>), [PPMU_PIN_SETTING](<02.07.04.01.160.01_PPMU_PIN_SETTING.md>)
- [PPMU_RELAY](<02.07.04.01.158_PPMU_RELAY.md>), [PPMU_PIN_RELAY](<02.07.04.01.158.01_PPMU_PIN_RELAY.md>)
- [PPMU_MEASURE](<02.07.04.01.157_PPMU_MEASURE.md>), [PPMU_PIN_MEASURE](<02.07.04.01.157.01_PPMU_PIN_MEASURE.md>)
- [TASK_LIST](<02.07.04.01.240_TASK_LIST.md>)

Using these APIs, you can program an individual force voltage or current value per pin, apply it to the pin, and perform a measurement.

After the measurement finishes, the pin PMU remains connected to the pin and continues to output. Alternatively, you can set up your program such that the pin PMU stops the output and relays are disconnected after the measurement finishes.

## To create a DC test program for DPSs

The following APIs can be used:

- [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>)
- [DPS_PIN_TASK](<02.07.04.01.50.01_DPS_PIN_TASK.md>)

The [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) and [DPS_PIN_TASK](<02.07.04.01.50.01_DPS_PIN_TASK.md>) APIs allow you to set up your DC test program so that you can make DPS measurements in parallel when performing single-site or multi-site testing.

Note If you need to use auto-ranging in DPS current measurements or need to suppress activation of the level/timing-related primaries that are specified in the Testsuite dialog in the DPS measurements, you must use the [DPS_VFIM](<02.07.04.01.51_DPS_VFIM.md>) API. In all other cases, it is recommended that you use the [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) and [DPS_PIN_TASK](<02.07.04.01.50.01_DPS_PIN_TASK.md>) APIs to set up your DC test program for DPS tests. (Auto-ranging and preAction "NPRM" are not supported by the [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) API.)

The [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) and [DPS_PIN_TASK](<02.07.04.01.50.01_DPS_PIN_TASK.md>) APIs provide the following benefits in DPS measurements:

- allow you to make DPS measurements in parallel when performing single-site or multi-site testing. Parallel testing can help you achieve higher throughput.
- allow you to make different kinds of DPS measurements in parallel when performing single-site or multi-site testing.
- Both external-triggered and software-triggered DPS measurements are supported when using the [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) and DPS_PIN_TASK APIs.

The DPS_TASK API forces the voltage defined in the primary DPS set or primary level spec/equation sets and performs the current measurement. If you need to modify the force voltage values for the DPS, change the level-related primaries, (primary level spec/equation sets or primary DPS set). To make these changes, use the [PRIMARY_STATUS](<02.07.04.01.167_PRIMARY_STATUS_-__Primary.md>) API or modify the level specification values with the [LEVEL_SPEC](<02.07.04.01.124_LEVEL_SPEC.md>) API.

After the measurement finishes, the DPS keeps the connection to the pin and continue to output the voltage. If you want to stop the DPS outputs, perform the DISCONNECT sequence.

To execute a DC test and retrieve the measurement results, use the appropriate member function of the DC API.

The sub-sections in DC Test Programming explain each step in typical DC test programming and show DC test-specific information only. See the following sections for the information that is in common with AC test.

- [Accessing Test Control Options](<02.07.03.08_Accessing_Test_Control_Options.md>)
- [Computing Measurement Values](<02.07.03.09_Computing_Measurement_Values.md>)Note You need to execute the CONNECT sequence before the test, to apply the power to DUT and connect the target pins to tester resources. To do this in a test method program, use the [CONNECT](<02.07.04.01.18_CONNECT.md>) API. If you perform continuity tests with the DC APIs, you must execute the DISCONNECT sequence before the tests. To do this in a test method program, use the [DISCONNECT](<02.07.04.01.41_DISCONNECT.md>) API.
