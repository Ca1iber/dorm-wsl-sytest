# failNode()

Defines the fail branch for [insertJmpe()](<02.07.13.24.20_insertJmpe.md>).

## Syntax

```
failNode();
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Example

```
RDI_BEGIN();
...
  rdi.smartVec...
	.insertJmpe(2).failNode().pin("DATA1").writeData(0xf,8,0)...execute();
...
RDI_END();
```
