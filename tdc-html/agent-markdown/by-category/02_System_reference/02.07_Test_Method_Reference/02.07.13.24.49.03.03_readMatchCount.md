# readMatchCount()

This function returns true if a match is found on the specified pin.

## Syntax

```
readMatchCount(string pin)
```

## Example

```
rdi.smartVec("abc").pin(pinA).defaultBit(0)
                   .matchData(0x36,8,10).matchCycle(10)
                   .readMatchCount(pinA)
                   .readMatchPassFail(pinA)
                   .execute();
```

## Functional changes

- Introduced in SmartRDI 2.4.0
