# HW_PIN_STATE

This class is a subsidiary data container of the `HW_STATE` class.

## Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/HwPinState.h.

  Constructor

This class has no constructor.

You can access this class object via the [pin()](<02.07.04.01.117_HW_STATE.md#_105633__dle_pin>) member function of the [HW_STATE](<02.07.04.01.117_HW_STATE.md>) class by specifying the pin name. You cannot directly construct any objects of this class.

## Member functions returning DOUBLE

  getCompHoldOff()

```
DOUBLE getCompHoldOff() const;
```

This function queries the comparator hold off time of the specified pin. It returns the real value of the hardware. The unit of the returned value is ns (Nanoseconds).

If this setting of the hardware is not applicable, NaN (Not a Number) is returned.

```
DOUBLE getCompHysteresis() const;
```

  getConstCurrTimeToAlarm()

```
DOUBLE getConstCurrTimeToAlarm() const;
```

This function queries the time until the "Constant current" flag is set for a channel that is in constant current mode without interruption. It returns the real value of the hardware.

The function is supported only with DC Scale XPS256 card.

  getConstCurrTimeToDisconnect()

```
DOUBLE getConstCurrTimeToDisconnect() const;
```

This function queries the delay time before a channel that is in constant current mode without interruption is disconnected. It returns the real value of the hardware.

The function is supported only with DC Scale XPS256 card.

  getCurrentClampFilter()

## Member functions returning STRING

  getCompSelector()

```
STRING  getCompSelector() const;
```

This function queries the comparator selector of the specified pin. It returns the real value of the hardware.

 | Returned value  | Meaning  | Supported pin types |
 | "na"  | The comparator selector is not applicable or not defined.  | DPS, SIG |
 | "LS"  | The high-resolution voltage or current comparator.

This is the default comparator for an AVI64 channel in the PMU operating mode.

  | SIG (AVI64 only) |
 | "LS_DIFFVM"  | High-resolution voltage comparator of the differential voltmeter.  | SIG (AVI64 only) |
 | "HS"  | High-speed digital voltage comparator.  | SIG (AVI64 only) |
 | "HS_TERM"  | Terminated high-speed digital voltage comparator. Input signal is terminated to ground via 50 O.  | SIG (AVI64 only) |
 | "HS_DIFFERENTIAL"  | Differential high-speed digital voltage comparator.  | SIG (AVI64 only)  |  getConnectState()

```
STRING  getConnectState() const;
```

This function queries the connection state setting of the specified pin. It returns the real value of the hardware.

 | Returned value  | Meaning  | Supported pin types |
 |   | "FAST"  | The fast VI mode.  | SIG |
 | "NORMAL"  | The default mode for DPS application.  | DPS, SIG |
 | "PULSE"  | The high-current mode.  | DPS, SIG  |  getLoadStepMode()

```
STRING  getLoadStepMode() const;
```

This function queries the loadstep mode of the specified pin. It returns the real value of the hardware.

Possible return values are "STD" or "FAST".

The function is supported only for the DC Scale XPS256 card.

If this setting of the hardware is not applicable, "na" is returned.

 getOpenLoopProtection()

```
STRING  getOpenLoopProtection() const;
```

This function queries the setting of the open loop protection for the specified pin. It returns the real value of the hardware.

Possible return values are "DIODE" or "NONE".

The function is supported only for the DC Scale XPS256 card.

 getReferencePin()

```
STRING  getReferencePin() const;
```

This function queries the reference pin of the specified pin. It returns the real value of the hardware. The function returns "GND" if the reference pin is not defined or is defined as TM::REF_GND for measure modes that support a reference pin.

If this setting of the hardware is not applicable, "na" is returned.
