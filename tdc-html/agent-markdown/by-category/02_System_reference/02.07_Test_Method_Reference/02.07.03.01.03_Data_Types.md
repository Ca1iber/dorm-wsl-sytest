# Data Types

The normal data types supported in the C++ language are used to declare variables and arrays. Besides these native C++ data types, data types are defined in the test method program. Here, these kinds of data types are referred to as the "system-defined data types". The system-defined data types are classified into two major categories: Data types used for variables or arrays and those used only for arrays. These categories are introduced briefly in the following subsections.

## Data types for variables or arrays

The data types below are used to declare variables or arrays. For arrays we recommend using ARRAY_x data types as defined in the following subsection. If you define arrays using the following data types use the "[ ]" (square brackets).

```
Boolean
```

Data of bool type, one byte. This data type behaves in the same manner as the normal bool data type.

```
CHAR
```

Data of character type, one byte. This data type behaves in the same manner as the char supported by the standard library of C++. We recommend using the uppercase data type CHAR to keep readability with other data types.

```
COMPLEX
```

This class has two members; "real" and "imag". The "real" member is used for the real part of a complex value, and the "imag" member is used for the imaginary part of a complex value. For more information refer to [How to handle COMPLEX Data Type](<02.07.03.01.05_How_to_handle_COMPLEX_Data_Type.md>).

```
DOUBLE
```

Data of real type, eight bytes. The approximate range is -1.79769E+308 to 1.79769E+308. This data type behaves in the same manner as the normal double data type. We recommend using the uppercase data type DOUBLE to keep readability with other data types.

```
INT
```

Data of integer type, four bytes. The range is -2 147 483 648 to 2 147 483 647. This data type behaves in the same manner as the normal int data type. We recommend using the uppercase data type INT to keep readability with other data types.

```
LONG
LONG_LONG
```

Data of integer type, eight bytes. The range is -9 223 372 036 854 775 808 to 9 223 372 036 854 775 807. This data type behaves in the same manner as the normal long data type. We recommend using the uppercase data type, i.e. LONG to keep readability with other data types.

```
STRING
```

Data of string type. This data type behaves in the same manner as the string supported by the standard library of C++. We recommend using the uppercase data type STRING to keep readability with other data types.

## Data types for arrays - ARRAY_x

For arrays, we recommend using the following data types that are implemented as C++ classes.

Note The "x" is a placeholder only for this documentation and is to be replaced by valid types as shown below.

The ARRAY_x data types can be defined with the size # already set:

```
ARRAY_x (#)
```

The definition without specifying the size is also supported:

```
ARRAY_x
```

If the ARRAY_x data types are used, the system automatically allocates memory area by the number of elements assigned to the data. Afterward, you can check the number of array elements and resize the array if necessary. For more information refer to [How to handle ARRAY_x data type](<02.07.03.01.06_How_to_handle_ARRAY_x_data_type.md>).

```
ARRAY_BOOL
```

One-dimensional array data of Boolean type.

```
ARRAY_CHAR
```

One-dimensional array data of CHAR type.

```
ARRAY_COMPLEX
```

One-dimensional array data of COMPLEX type.

```
ARRAY_D
```

One-dimensional array data of DOUBLE type.

```
ARRAY_I
```

One-dimensional array data of INT type.

```
ARRAY_LL
```

One-dimensional array data of LONG_LONG type.

## Data types related to Computation APIs

You can use data types other than described above in the Computation APIs.

```
DGDPtype
```

This C++ class type has six members. It is used for handling the calculation results of the DSP_DGDP API. For details, see [DSP_DGDP](<02.07.04.01.53.24_DSP_DGDP.md>).

```
LINEARtype
```

This C++ class type has twelve members. It is used for handling the calculation results of the DSP_ADC_HISTGRAM and DSP_LINEAR APIs. For details, see [DSP_ADC_HISTOGRAM](<02.07.04.01.53.03_DSP_ADC_HISTOGRAM.md>) and [DSP_LINEAR](<02.07.04.01.53.43_DSP_LINEAR.md>).

```
THDtype
```

This C++ class type has six members. It is used for handling the calculation results of the DSP_THD API. For details, see [DSP_THD](<02.07.04.01.53.105_DSP_THD.md>).

## Data types handled as references

The STRING data type or the array data types ARRAY_x are handled as references.

If the data is the STRING or ARRAY_x type:

- The Ampersand (&) is used in the syntax notation of the API.
- The Ampersand (&) is not used in the actual programming.

Example syntax:

```
GET_USER_STRING (const STRING& name, STRING& value);
```

Related code example:

```
STRING returnedOperatorNameVar;
...
...
GET_USER_STRING ("OperatorName", returnedOperatorNameVar);
```
