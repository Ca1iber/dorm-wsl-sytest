# insertSub()

This function inserts one or more subroutines with DC, PPMU or BADC actions into an existing pattern.

You can use this function to add multiple measurements to one pin in a pattern. To retrieve the result, use [getMultiValue()](<02.07.13.12.02.50_getMultiValue.md>).

You can also use this function to insert an existing sublabel to a user-defined pattern and DC actions to the sublabel.

## Syntax

```
insertSub(int lineNum);
insertSub(int VecNo,int level);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

lineNum

 |

The number of a vector line where one or more subroutines to be inserted in a specified label.

 |
 | VecNo  | The vector number. |
 | level  | 2 means the sublabel is inserted to a user-defined pattern.

1 is the default value.

 |

## Examples

```
RDI_BEGIN();
  ...
  rdi.dc("meas").label("abc").insertSub(10).pin("pinA").vForce(0).iMeas().measWait(0.1 ms)
                             .insertSub(20).pin("pinB").vForce(1 V)
                                           .pin("pinC").vForce(2 V)
                             .insertSub(30).pin("pinA").vForce(0).iMeas().measWait(0.2 ms)
                                           .execute();
  ...
RDI_END();
ARRAY_D results = rdi.id("meas").getMultiValue("pinA");
```

   Use wait() to insert a period of time between actions:

```
RDI_BEGIN();
  rdi.dc().label("funcPass").insertSub(10).pin("A").vForce(3 V)
                            .insertSub(12).wait(10 ms)
                            .insertSub(12).pin("B").vMeas().execute();
RDI_END();
```

Starting from 7.5.1, this function supports waveform sourcing and sampling:

```
RDI_BEGIN;
  ...
  rdi.dc().label("label3").insertSub(30)
          .pin("AVI").vForce()
          .waveform(wav).FS(100 KHz).execute();  //force waveform
  rdi.dc().label("label4").insertSub(40)
          .pin("AVI2").vMeas()
          .samples(1024).sampleCycle(100).execute();//sampling
  rdi.dc().label("label5").insertSub(40)
          .pin("AVI3"). vForce()
          .waveform(wav).vMeas().FS(100 KHz).execute();//force waveform with sampling
RDI_END;
```

    Inserting an existing sublabel to a pattern:

```
RDI_BEGIN();
  rdi.dc().label("mainlabel")
     .insertSub(10).pin(A).vForce(1)
     .insertSub(15).label("sublabel")
     .insertSub(10,2).pin(B).vForce(2)
     .insertSub(20).pin(C).iForce(1 mA).vMeas().execute();
RDI_END();
```

## Functional changes

- Introduced in SmartRDI 2.4.1
- SmartRDI 2.4.3: Support for inserting subroutines with PPMU or BADC actions into an existing pattern.
- SmartRDI 2.5.1: Support wait() for inserting a dummy waiting pattern.
- SmartRDI 7.5.1: Support waveform sourcing and sampling.
- SmartRDI 7.5.2: Support an existing sublabel to be inserted to a user-defined pattern and DC actions to be inserted to a sublabel.
