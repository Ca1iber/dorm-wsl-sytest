# TMU_PINS.uploadRawResultsFlat()

Uploads the raw results of all armings in one line as results of arming 0. (Deprecated)

  Note The TMU_PINS upload methods are deprecated, but for compatibility reasons they are still usable. We recommend using the new function [TMU_TASK.uploadRawResultsFlat()](<02.07.04.01.252.20_TMU_TASK.uploadRawResultsFlat.md>).

This makes it possible for a quick access to the results of multiple armings with the [TMU_RESULTS.getPinResultFlat()](<02.07.04.01.251.19_TMU_RESULTS.getPinResultsFlat.md>) function.

Note Normally all upload methods loads results for all sites except they are called inside a FOR_EACH_SITE block.

## Syntax

```
void uploadRawResultsFlat(TMU_RESULTS& resultCache,UINT32 shotnum = 0);
void uploadRawResultsFlat(TMU_RESULTS& resultCache,STRING& ResultHandle,UINT32 shotnum = 0);
void uploadRawResultsFlat(TMU_RESULTS& resultCache,const char* ResultHandle,UINT32 shotnum = 0);
```
