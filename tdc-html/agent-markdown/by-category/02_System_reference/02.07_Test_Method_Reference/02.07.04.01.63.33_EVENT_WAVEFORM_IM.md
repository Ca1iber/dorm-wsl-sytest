Measure waveform classes provide functionality to define events that digitize waveforms.

Specialized measure waveform classes are EVENT_WAVEFORM_IM (Current Measure Waveform) and

[EVENT_WAVEFORM_VM](<02.07.04.01.63.40_EVENT_WAVEFORM_VM.md>) (Voltage Measure Waveform). Both classes derive from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_WAVEFORM_IM (const STRING & id);
EVENT_WAVEFORM_IM (INT id);
```

This constructs an object of the EVENT_WAVEFORM_IM class. The class derives from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

Parameter
 | Parameter  | Description |
 | id |

Identifier of the event.

The identifier may be defined as integer value or as string.

 |

## Example

Defines a current measurement capture event:

```
EVENT_WAVEFORM_IM captureEvent("rampCaptureA");
captureEvent.samples(20);
captureEvent.sampleVectorDistance(64);
captureEvent.averages(4);
```
