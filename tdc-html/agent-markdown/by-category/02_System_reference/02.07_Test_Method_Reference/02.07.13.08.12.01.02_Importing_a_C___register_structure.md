# Importing a C++ register structure

Before using the RA library, if you intend to use a register structure, the SVD file for your device must be converted first. Then the converted register structure must be imported to a test method program.

## About this task

- Converting an SVD file to a C++ register structure.

For an SVD file example, see [An SVD file example](<02.07.13.08.12.01.01_Register_structure.md#_351643__SVD_file_example>) in the [Register structure](<02.07.13.08.12.01.01_Register_structure.md>) topic.

- Importing the structure to a test method program.Note This task is optional. You can do most of register access setups without a register structure. But without register structure definitions, you cannot perform RMW (Read-Modify-Write) operations.

## Before you begin

The register access library has been implemented.

## Procedure

-  Create a folder in the working directory, for example gen.
-  Use the provided script RegisterAccessRegisterGen to convert your device's SVD file (*.svd) to a C++ register structure, for example:

/opt/hp93000/soc64_7.6.0_*_*/prod_com/rdi/lbin/RegisterAccessRegisterGen -i <svd file path> -o ./gen -N Example

If the conversion is successful, the following message shows: RegisterAccess Gen is successfully finished!.

The converted register structure files will show in the gen folder, including the peripherals folder, registers folder, Example_AllDevices.cpp, and Example_AllDevices.h.

 For example,  ![gen_folder](<../../../../raw/351503.png>)

The RegisterAccessRegisterGen script is located in /opt/hp93000/soc*.*/prod_com/rdi/lbin/.

You can use /opt/hp93000/soc/prod_com/rdi/lbin/RegisterAccessRegisterGen --help to show the definition of -i, -o, and -N.

-  Copy the converted source files to your test method source folder.
-  Build this test method project.
-  Include AllDevices.h at the beginning of your test methods which use the register structure.

The entry of the register structure in test methods is the singleton Example_AllDevices::getInstance().

## Results

The register structure is ready to be used in your test method.
