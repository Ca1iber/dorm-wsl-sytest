# FORMAT_GRAPH class

This class allows specifying the way a graph is shown. An object of this class is instantiated and filled with desired parameters and then passed as the last parameter to [PUT_DEBUG](<02.07.04.01.175_PUT_DEBUG.md>) API.

## Member functions

### setUserComment

```
FORMAT_GRAPH & setUserComment (const std::string comment)
```

Sets a comment that is shown at the top right area of the graph.

Parameter
 |

comment

 |

A comment that will be shown in top right area of the graph.

 |

 |
