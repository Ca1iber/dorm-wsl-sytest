# EVENT_WAVEFORM_VC.getSampleVectorDistance()

Reads the distance between sample vectors that has been defined by [EVENT_WAVEFORM_VC.sampleVectorDistance()](<02.07.04.01.63.34.05_EVENT_WAVEFORM_VC.sampleVectorDistance.md>).

The sample vector distance is read from the corresponding [EVENT_WAVEFORM_VC](<02.07.04.01.63.34_EVENT_WAVEFORM_VC.md>) object and returned as an integer value.

## Syntax

```
void getSampleVectorDistance(INT & vectors) const;
```

  Parameter

 | Parameter  | Description |
 | vectors |

The sample vector distance.

  |  Return value There is no return value.

## Example

For an example see [EVENT_WAVEFORM_VC](<02.07.04.01.63.34_EVENT_WAVEFORM_VC.md>).
