# SmartRDI 2.4.3

This section summarizes the changes and new features in SmartRDI 2.4.3.

Changes and new features
 |

Category

 |

Description

 |
 |

General

 |

- New keywords in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>):

  - ANALOG_SET_NAME_MD5: Add an MD5 checksum at the end of the generated analog set names.
  - BURST_NAME_MD5: Add an MD5 checksum at the end of the generated pattern burst names.
  - REPORT_RESULT_IN_SINGLE_MODE: Enable the results in the single mode to be shown in the UI report window.

- RDI_Configure file template.
- Retrieve the value of a specific option in the RDI_Configure file:

  - [getRdiConfig()](<02.07.13.04.02_getRdiConfig.md>)

- Semi-parallel test enhancements:

  - [Semi-parallel tests with SmartRDI](<02.07.13.08.13_Semi-parallel_tests_with_SmartRDI.md>)
  - [RDI_SEMI_PARALLEL_TEST_BEGIN()](<02.07.13.08.13.04_RDI_SEMI_PARALLEL_TEST_BEGIN.md>)
  - [RDI_SEMI_PARALLEL_TEST_END()](<02.07.13.08.13.05_RDI_SEMI_PARALLEL_TEST_END.md>)

- Disable or enable SmartRDI warnings:

  - [disableWarning()](<02.07.13.08.16.01_rdi.disableWarning.md>)
  - [enableWarning()](<02.07.13.08.16.02_rdi.enableWarning.md>)

 |
 |

dc()

 |

- Support inserting PPMU or BADC actions into an existing pattern. See [insertSub()](<02.07.13.12.02.20_insertSub.md>).
- An option for a deterministic sampling rate on PPMU or BADC in the VEC mode: VEC_MODE_SAMPLING_WAIT.

See the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>).

- New functions for combined voltage and current measurements in digitizer mode:

  - getVoltageWaveform
  - getCurrentWaveform() Note: The function is currently only for DC Scale AVI64 cards.

 |
 |

smartVec()

 |

- A new function for selecting one vector editing mode for one pattern while another mode for another pattern in the code level:

  - [vecEditMode()](<02.07.13.24.33_rdi.smartVec__.vecEditMode.md>)

- X-mode enhancements. See [xMode()](<02.07.13.24.42_xMode.md>).
 |
 |

func()

 |

- Burst functional result on port. See [rdi.func().burstId()](<02.07.13.17.01.02_rdi.func__.burstId.md>).
 |
 |

digCap()

 |

- Support [addVecRange()](<02.07.13.13.04_addVecRange.md>) with cont().
 |
 |

cogo()

 |

- HYST_LINEAR mode for cogo searches. See [Sequencer-controlled searching with cogo](<02.07.13.19.02_Sequencer-controlled_searching_with_cogo.md>).
- A new function for retrieving the result path:

  - [getSearchPath()](<02.07.13.19.02.10_getSearchPath.md>)

 |
 |

tmu()

 |

- Support existing arm actions in pattern:

  - [measNum()](<02.07.13.21.10_rdi.tmu__.measNum.md>)

  |
