# EVENT_CFIM.getCForce()

Reads the force current that has been defined by [EVENT_CFIM.cForce()](<02.07.04.01.63.03.01_EVENT_CFIM.cForce.md>).

The value is read from the corresponding [EVENT_CFIM](<02.07.04.01.63.03_EVENT_CFIM.md>) object and returned as an [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getCForce(EVENT_VALUE_DOUBLE & value) const;
```

Parameter
 | Parameter  | Description |
 | value |

The programmed force current in A (Ampere).

 |

Return value

There is no return value.
