# TMU_RESULTS.getNumberOfMeasuredPins()

Retrieves the measured pins and returns the number of pins.

## Syntax

```
UINT32 getNumberOfMeasuredPins(STRING_VECTOR& pinvec,TMU::ApplicationType appType,  UINT32 site = 0);
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

pinvec

 |

The measured pins.

 |
 |

I

 |

appType

 |

The application type. The application type. It currently can be APP_PERIOD, APP_RAW or APP_RAW_FLAT.

 |
 |

I

 |

site

 |

The site to query. Default is 0, which means the current site.

 |

## Return value

The number of measured pins is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
- SmarTest 7.1.3: Support the application type APP_RAW_FLAT.
