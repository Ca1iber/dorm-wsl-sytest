# TESTSET().cont()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) is used to decide whether or not the test should continue after a test result fails. See parameters in the table below.

This is an optional method.

## Syntax

```
TESTSET & cont (bool overon);
```

 |

Parameter

 |

Description

 |
 |

overon

 |

This parameter is used to decide whether or not the test should be continued if a test result fails:

If you want to continue the test even if the test fails, set this flag to TRUE. When the test result is pass, the test program continues to execute. Instead of the expressions, TRUE or FALSE, you can use an enumerator supported by the system.

Note that the API behaves differently for the first site in a multisite setup. In this special situation, the test is always continued, even if the test result fails and the parameter is set to FALSE. For the following sites, the test is terminated under these conditions.

 |

## Example

With the following setting, the test will be continued even if the test fails.

```
TestSet.cont(true);
```
