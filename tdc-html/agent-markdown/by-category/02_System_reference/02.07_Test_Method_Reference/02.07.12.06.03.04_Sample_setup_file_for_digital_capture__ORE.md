# Sample setup file for digital capture (ORE)

<offlineResultEmulation>

```

   <measurement name="Rx_ADC_SNR">
```

 Note No <pin> element

```
     <site number="1">
```

 Note This element is optional

```
       <waveform file="/home/demo/MATLAB/tx106m1s1.txt"/>
     </site>
     <site number="2">
       <waveform file="/home/demo/MATLAB/tx106m1s2.txt"/>
     </site>
   </measurement>

</offlineResultEmulation>
```

Waveform files are ASCII files and may consist of just one value per line, but no header. For example:

```
0.9384127738399521
0.90442446110833
0.861447503687353
0.8120801816825381
0.7546371242146311
0.6935424298416738
0.6282343082705816
0.5615217109667776
[..]
```

or

```
208
199
188
177
163
150
135
122
106
[..]
```
