# Example of Multi-port Test in Test Method Program

The following is a test method program example for a multi-port test using the two ports, where a digital functional test is executed at a port ("port1") and a mixed signal test is executed in another port ("port2").

```
//port1: Functional Test, port2: Mixed Signal Test
DOUBLE Tsmpl;
ARRAY_D Wave;
THDtype thdRslt;
Routing.pin(dzPin).connect(TM::SINGLE);  //port2: Connect pin to analog module
Analog.DGT(dzPin).enable();              //port2: Enable trigger of analog module
FLUSH();                                 //port2: Activate analog set&routes
FUNCTIONAL_TEST();                       //port1&port2: Execute multi-port test

Analog.DGT(dzPin).disable();             //port2: Disable trigger of analog module
Routing.pin(dzPin).disconnect();         //port2: Disconnect from analog module
FLUSH();                                 //port2: Activate above changes
Wave = Analog.DGT(dzPin).getWaveform();  //port2: Retrieve measured analog wave
Tsmpl = Analog.DGT(dzPin).getConvClock();//port2: Get current sampling frequency
DSP_THD(Wave, &thdRslt, 1, 3, DB, 0);    //port2: Calculate THD and SNR

TEST("port1",TM::CONTINUE);                     //port1: Judge&log functional test
TEST(dzPin, "THD", thdRslt.thd, TM::CONTINUE);  //port2: Judge&log THD result
TEST(dzPin, "SNR", thdRslt.snr);                //port2: Judge&log SNR result
```

In this example, the variable dzPin is a pin name where a waveform digitizer is used, and is defined in the Parameter Dialog window as the input parameter of the Func_plus_Mixed test-method program.

The multi-port unique statement in this example is the TEST API only, where the port name is specified to get the digital functional test result of the specified port. As this example shows, the programming of the analog pins is the same as for the non-multi-port test.
