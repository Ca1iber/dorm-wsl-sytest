# vMeasRange()

Specifies a range (maximum possible value) for the voltage to measure on the DC Scale pins in the signal mode.

The function can be used in both code‑based and pattern‑based modes. It is usually used in the pattern‑based mode.

SmartRDI will check the time between vMeasRange() and [vMeas()](<02.07.13.12.02.43_vMeas.md>), because changing measurement range requires reaction time. A warning message will be issued if the time is not long enough and you need to insert the wait time manually.

## Syntax

```
vMeasRange(double dVMeasureRange);
```

  List of parameters

 | Parameter  | Description |
 | dVMeasureRange  | The maximum voltage to measure.  |   Return value A reference to the dcBase object.

## Functional changes

- Introduced in SmartRDI 2.1.0
