# MODULATION_SET_TIMING

The MODULATION_SET_TIMING class defines a timing modulation waveform. In order to be applicable to a set of pins, this waveform must be linked to a JITTER_INJECTION_SET object.

## Class definition

### Constructor

```
MODULATION_SET_TIMING(const std::string& setName);
```

This creates an object of MODULATION_SET_TIMING for the specified modulation set. If the specified set does not exist, it will be created.

Parameter
 |

I

 |

setName

 |

The name of the modulation set.

 |

### Member functions

```
MODULATION_SET_TIMING& setPeriod(DOUBLE period);
MODULATION_SET_TIMING& setPhase(INT phase);
MODULATION_SET_TIMING& setShape(MODULATION_SHAPE shape);
MODULATION_SET_TIMING& setShape(const STRING& freehandshape);
MODULATION_SET_TIMING& setAmplitude(DOUBLE amplitude);
void remove();
static void removeAll();
static void getListOfSets(STRING_VECTOR& setNames);
```

## Member functions

### setPeriod()

```
MODULATION_SET_TIMING& setPeriod(INT period);
```

This function sets the period for the modulation waveform.

Parameter
 |

period

 |

The waveform period. The unit is second [s]. In general, the maximum depends on the clock resolution (ECLK) and is as follows:

2 * clock_resolution * 512 * 1024

 |

### setPhase()

```
MODULATION_SET_TIMING& setPhase(INT phase_deg);
```

This function sets the phase for the jitter.

Parameter
 |

phase

 |

This parameter defines a phase offset for the RESTART mode (the mode is defined with JSCF). This value must be specified as a degree. The maximum is 360掳.

 |

### setShape()

```
MODULATION_SET_TIMING& setShape(MODULATION_SHAPE shape);
```

This function sets the waveform for the jitter with specified values.

Parameter
 |

shape

 |

The allowed values are:

 |
 |

 |

JITTER_INJECTION::MODULATION_SHAPE_SINE

 |

 Creates a sinusoidal waveform.

 |
 |

 |

JITTER_INJECTION::MODULATION_SHAPE_RANDOM

 |

Generates random jitter within delay - amplitude and delay + amplitude.

 |

### setAmplitude()

```
MODULATION_SET_TIMING& setAmplitude(DOUBLE amplitude);
```

This function sets the amplitude of the waveform.

Parameter
 |

amplitude

 |

The amplitude (half of peak-to-peak value) of a SINE or RANDOM waveform, or the maximum required value for a free hand shape. The unit is in seconds.

 |

### remove()

```
void remove();
```

This function removes the modulation set on the firmware level. It has no parameters.

### removeAll()

```
static void removeAll();
```

This function removes all modulation sets. It has no parameters

### getListOfSets()

```
static void getListOfSets(STRING_VECTOR& setNames);
```

This function returns the names of all timing modulation sets.

Parameter
 |

setNames

 |

This output parameter specifies the string vector into which the set names will be written.

 |

## Example

In this example, two modulation sets are associated with the same pins in the same jitter set in order to generate a combined signal.

```
virtual void run()
  {
    MODULATION_SET_TIMING mset1("MT1");
    mset1.setAmplitude(30e-5).setPeriod(10e-6)
           .setShape(JITTER_INJECTION::MODULATION_SHAPE_SINE);
    MODULATION_SET_TIMING mset2("MT2");
    mset2.setAmplitude(15e-5).setPeriod(5e-6)
           .setShape(JITTER_INJECTION::MODULATION_SHAPE_SINE);

    JITTER_INJECTION_SET j_set(mSetname,mContext);
    j_set.pin("p1,p2").linkModulationSets(mset1,mset2)
         .setMode(JITTER_INJECTION::RESTART);

    j_set.setAsPrimary();
    return;
  }
```
