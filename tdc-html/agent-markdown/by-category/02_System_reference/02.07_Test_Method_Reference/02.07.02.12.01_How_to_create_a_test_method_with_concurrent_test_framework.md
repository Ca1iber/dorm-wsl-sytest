## About this task

To create a test method with concurrent test framework, you can follow the same procedure as creating a normal test method.

## Procedure

-  Create a test method project with New Test Method Project wizard, see [How to create a universal test method project](<02.07.02.02.01_How_to_create_a_universal_test_method_project.md>).
-  Create a concurrent test method with Create a new test method class wizard and select the Concurrent test method class as the template, see [How to create a universal test method class](<02.07.02.02.02_How_to_create_a_universal_test_method_class.md>).

Test method library ccf_tml will be imported from /opt/hp93000/soc/testmethod/library into the path you specified. The library file libccf_core.so will be copied to the directory device/testmethod/sh_libxxx/preload.

The path ccf_tml/ccf_include will be added to the include directory in your UTM project property. (property-> paths and Symbols -> Includes)

To get the concurrent test framework version information, you can use the predefined string type variables MAJOR_RELEASE, ENHANCE_RELEASE and FIX_BUG_RELEASE. These variables are included in the file ccf_tml/ccf_include/internal/CCVariables.hpp.

-  Implement your concurrent test method following the provided template, see [How to implement a concurrent test method](<02.07.02.12.01.01_How_to_implement_a_concurrent_test_method.md>).
-  Build the test method project. If any errors occurred, correct the errors and rebuild it until no error exists.
