# Setting and retrieving the setup name with SmartRDI

#### Subtopics

- [getAnaResultHandle()](<02.07.13.08.14.01_getAnaResultHandle.md>)
- [getAnaSet()](<02.07.13.08.14.02_getAnaSet.md>)
- [getPriAnaSet()](<02.07.13.08.14.03_getPriAnaSet.md>)
- [setAnaSet()](<02.07.13.08.14.04_setAnaSet.md>)
- [setPatBurst()](<02.07.13.08.14.05_setPatBurst.md>)

In the pattern鈥慴ased mode, one analog set will be generated for the analog tests in each `RDI_BEGIN()`/`RDI_END()` block. The generated analog set is named as <testsuite name>+ <block number in this test suite>. You can get the generated analog set name and set your own analog set name if needed.

- You can retrieve the analog set name of a specific test with `getAnaSet()` and retrieve the primary analog set name with `getPriAnaSet()`.
- You can set the analog set name for the next `RDI_BEGIN()`/`RDI_END()` block with `setAnaSet()`.
- You can set the burst pattern name for the next `RDI_BEGIN()`/`RDI_END()` block with `setPatBurst()`.

## Example

Retrieving the analog set name

```
string analogSetName = rdi.id("AWG_1").getAnaSet();
string pAnalogSetName = rdi.getPriAnalogset();
```

Setting the analog set name and pattern burst name

```
rdi.setAnaSet("set1");
rdi.setPatBurst("pattBurst1");
RDI_BEGIN();
  ...
RDI_END();
```
