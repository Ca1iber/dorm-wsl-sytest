# TIMING_OFFSET_SEARCH_PINS.getConfiguration()

This function gets the current setting of the configuration. If you retrieve the configuration of multiple pins and the pins have different settings, the exception `TESTMETHOD_API::AmbiguityException` will be issued.

## Syntax

```
void getConfiguration(TIMING_OFFSET_SEARCH::TimingOffsetConfigDataType & configdata);
```

Parameter
 |

I/O

 |

Parameter

 |

description

 |
 |

O

 |

configdata

 |

The configuration setting currently in use.

 |

## Functional changes

- Introduced in SmarTest 7.0.1
- SmarTest 7.1.0: Enhanced to support the configuration parameters of histogram based search.
