# DSP_RF_ACLR()

This function is used to measure adjacent channel leakage ratio (also known as adjacent channel power ratio). It returns power at the carrier frequency and power relative to the carrier for up to four adjacent channels (upper and lower).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

The syntax varies in length according to the number of channels (offset frequency pairs) to be measured. The parameters for higher-order offsets (both data and results) and be omitted if all four channels are not needed.

```
DSP_RF_ACLR (const ARRAY_COMPLEX & carrierData,
             const ARRAY_COMPLEX & ch1LowerData,
             const ARRAY_COMPLEX & ch1UpperData,
             const ARRAY_COMPLEX & ch2LowerData,
             const ARRAY_COMPLEX & ch2UpperData,
             const ARRAY_COMPLEX & ch3LowerData,
             const ARRAY_COMPLEX & ch3UpperData,
             const ARRAY_COMPLEX & ch4LowerData,
             const ARRAY_COMPLEX & ch4UpperData,
             const ARRAY_D       & measParams,
             const INT site,
                   ARRAY_D       & results);
```

## Example

```
ARRAY_COMPLEX carrierData = MEAS_DEF("myAcMeas").getComplexWaveform(1);
ARRAY_COMPLEX ch1LowerData = MEAS_DEF("myAcMeas").getComplexWaveform(2);
ARRAY_COMPLEX ch1UpperData = MEAS_DEF("myAcMeas").getComplexWaveform(3);
ARRAY_D measParams = MEAS_DEF().getParameters(TM::RF_MEAS_ACLR,0);
ARRAY_D results(TM::RF_DSP_ACLR_RESULT_SIZE);
DSP_RF_ACLR(carrierData, ch1LowerData, ch1UpperData,
    measParams, 1, results);
```

The results could be printed to the report window as follows:

```
cout << "Carrier Power " << results[0] << " dBm" << endl;
cout << "Channel 1 Lower Power " << results[1] << " dBc";
cout << "    Channel 1 Upper Power " << results[2] << " dBc" << endl;
```
