# ARRAY_D

ARRAY_D defines an array holding the DOUBLE type of data and defines the functions to access and process the data.

## Constructors

```
ARRAY_D (INT size);
```

This constructs an object of ARRAY_D with the specified fixed size. If a size larger than zero is specified, the memory for the specified number of elements is allocated and the array cannot be resized.

```
ARRAY_D (const ARRAY_D& array);
```

This constructs an unresizable object of ARRAY_D by copying from another ARRAY_D object.

```
ARRAY_D (const ARRAY_D& array, INT size, INT offset= 0);
```

This constructs an unresizable object of ARRAY_D by sharing the specified elements from another ARRAY_D object.

```
ARRAY_D (DOUBLE* array, INT size, INT offset= 0);
```

This constructs an unresizable object of ARRAY_D by sharing the specified elements from a DOUBLE array.

Parameters
 |

array

 |

The array to copy from.

 |
 |

size

 |

Size of the new ARRAY_D object

 |
 |

offset

 |

(optional) Starting point in original array where to begin copying the elements.

 |

## Member functions

### init()

```
void init (DOUBLE initValue= 0);
```

This function fills the array elements with the specified value.

Parameter
 |

initValue

 |

Value with which to fill the array elements. Default is 0.0.

 |

### resize()

```
INT resize (INT size);
```

This function changes the size of the array if it is resizable and keeps its data.

Parameter
 |

size

 |

New size of the array

 |

### resizeNoKeep()

```
INT resizeNoKeep(INT size);
```

This function changes the size of the array if it is resizable and deletes its data.

Parameter
 |

size

 |

New size of the array

 |

### size()

```
const INT size () const;
```

This function returns the size of the array.

### capacity()

```
const INT capacity();
```

This function returns the memory size allocated to the array.

### operator =

```
ARRAY_D& operator = (const ARRAY_D& array);
```

This operator copies all the elements of the specified array to the current array and changes the size of the current array.

Parameter
 |

array

 |

The array to copy from

 |

### operator []

```
DOUBLE& operator [] (const INT index);
const DOUBLE& operator [] (const INT index) const;
```

This operator accesses the specified element in the array.

Parameter
 |

index

 |

Index of the element to access

 |

### operator DOUBLE*

```
operator const DOUBLE* () const;
```

This operator converts the data type from ARRAY_D to DOUBLE *.

### operator *

```
ARRAY_D& operator * (DOUBLE factor);
```

This operator multiplies all elements of the array with the specified constant.

Parameter
 |

factor

 |

The factor to be multiplied

 |

### operator *=

```
ARRAY_D& operator *= (DOUBLE factor);
```

This operator multiplies all the elements of the array with the specified factor and replace the elements in the array with the results.

Parameter
 |

factor

 |

The factor to be multiplied

 |

### operator==

```
bool operator== (const ARRAY_D&) const;
```

This operator compares two array objects and judges whether they are the same.

## Example

```
ARRAY_D a_i1;
ARRAY_D a_i2(1024);
for (INT j=0; j < 1024; j++)
  a_i2[j]=j*0.1;
a_i1.resize(200);
ARRAY_D a_i3 (a_i2, 100, 30);
cout << a_i3 <<endl;
```

Three variables of ARRAY_D are defined in this example. `a_i1` is defined with zero buffer and can be resized. `a_i2` is defined with fixed 1024 buffers and cannot be resized. `a_i3` is defined with 200 elements from `a_i2` and its elements are printed to the UI report window.
