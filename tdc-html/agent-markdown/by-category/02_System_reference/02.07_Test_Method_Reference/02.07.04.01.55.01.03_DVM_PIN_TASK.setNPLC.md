# DVM_PIN_TASK.setNPLC()

The setNPLC() member function sets the number of power-line-cycles (NPLC) for the measurement.

## Syntax

```
DVM_PIN_TASK & setNPLC ( const double nplc )
```

Parameter
 |

Parameter

 |

Description

 |
 |

nplc

 |

Number of power-line cycles (default = 1).

 |

## Return value

Returns a reference to the [DVM_PIN_TASK](<02.07.04.01.55.01_DVM_PIN_TASK.md>) object.
