# rdi.route().showPmuxSensorStatus()

Reads the actual sensor values for temperature and humidity of all available MUX cards and displays the values in the UI report window.

 The functions displays additionally the thresholds for temperature and humidity alarms and the alarm status. The alarm status is cleared when it is read and is therefore read twice to get the latched status and the actual status:

- Alarm History: The latched alarm status of the first read.
- Alarm Actual: The current status of the alarm from the second read. The alarm condition is still active if this value is not equal to 0x83.
Note A PMUX01 card will automatically open all switches if the temperature threshold or the humidity threshold is exceeded.

Usage of the function:

- The function can be called only in the code鈥慴ased mode. For more information, refer to [Execution mode](<02.07.13_SmartRDI.md#_142069__s_Execution_mode>) in topic [SmartRDI](<02.07.13_SmartRDI.md>).
- The function displays suitable results only in online mode.
- Calling this function requires about 500 milliseconds due to the internal sensor cycle time.

## Syntax

```
routeGroup& showPmuxSensorStatus();
```

 List of parameters There are no parameters. Return value A reference to the [routeGroup](<02.07.13.15.05_rdi.route.md>) object.
