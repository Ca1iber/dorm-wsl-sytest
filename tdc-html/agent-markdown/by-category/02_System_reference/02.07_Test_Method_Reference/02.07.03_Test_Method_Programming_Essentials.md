SmarTest supports a variety of test method APIs to perform the following tasks:

- For executing DC test.

  - Set up the measurement conditions
  - Execute test/measurement
  - Retrieve raw result data (optional)
  - Perform DSP calculations (optional)
  - Compare a result to predefined test limits then judge it to pass or fail

- For executing AC test.

  - Change setup data (optional)
  - Execute test/measurement
  - Retrieve raw result data
  - Perform DSP calculations
  - Compare a result to predefined test limits then judge it to pass or fail

- Control the test sequence or the flow of the test method

program such as follows:

- Controlling the sequencer or monitoring the status
- Waiting the program execution
- Accessing the flags and variables
- Set up multi-site test.
- Achieve a multi-port test.
- Control GPIB instruments connected to GPIB interface for users (not for system).
- Execute firmware commands from the test method program.
- Handle API fatal errors.

This section explains the individual programming tasks using APIs more clearly for the programmer.
