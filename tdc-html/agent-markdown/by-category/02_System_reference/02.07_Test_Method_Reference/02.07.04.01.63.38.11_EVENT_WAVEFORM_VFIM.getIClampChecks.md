# EVENT_WAVEFORM_VFIM.getIClampChecks()

Queries the settings of the current clamp checks.

Per default these checks are off. If they are enabled and a checked clamp is hit, the event contributes with a FAIL to the global test result.

Both this member function and [EVENT_WAVEFORM_VFIM.getClampChecks()](<02.07.04.01.63.38.09_EVENT_WAVEFORM_VFIM.getClampChecks.md>) query the same functionality of the hardware.

## Syntax

```
void getIClampChecks(bool & failOnLow, bool & failOnHigh) const;
```

Parameters
 | Parameter  | Description |
 | failOnLow |

The programmed value of the lower clamp check.

- true: The lower clamp check is enabled.
- false: The lower clamp check is disabled.
 |
 | failOnHigh |

The programmed value of the upper clamp check.

- true: The upper clamp check is enabled.
- false: The upper clamp check is disabled.
 |

Return value

There is no return value.
