# Retrieving match loop results

#### Subtopics

- [getMatchCount()](<02.07.13.24.49.03.01_getMatchCount.md>)
- [getMatchPassFail()](<02.07.13.24.49.03.02_getMatchPassFail.md>)
- [readMatchCount()](<02.07.13.24.49.03.03_readMatchCount.md>)
- [readMatchPassFail()](<02.07.13.24.49.03.04_readMatchPassFail.md>)

SmartRDI provides functions for retrieving match loop results for the `smartVec()` class.

These functions are:

- Setup functions:

  - readMatchPassFail()
  - readMatchCount()

- Result retrieval functions:

  - getMatchPassFail()
  - getMatchCount()

## Example

```
RDI_BEGIN();
 rdi.smartVec("abc").pin("pinA").defaultBit(0)
             .matchData(0x36,8,10).matchCycle(10)
             .readMatchCount("pinA")
             .readMatchPassFail("pinA").execute();
RDI_END();
 int pf = rdi.id("abc").getMatchPassFail();
 int cnt= rdi.id("abc").getMatchCount();
```
