# SHMOO_RESULT.setResult()

This member function defines the test results (either measured values or pass/fail results) to be displayed on a shmoo plot.

After you defined a result with this member function, which you want to view on a shmoo plot, the system will automatically assign a test name to this shmoo test. Refer to the default name mentioned in [testName()](<02.07.04.01.227.03_SHMOO_RESULT.testName.md>). Or, you can define your own name with the [testName()](<02.07.04.01.227.03_SHMOO_RESULT.testName.md>) member function.

To view the defined test results on a shmoo plot, you can use the Shmoo Tool. For details, see [Viewing the test results of a test suite on the shmoo plot](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.04.05_Viewing_the_test_results_of_a_test_suite_on_the_shmoo_plot.md>).

## Syntax

```
void setResult(DOUBLE result);
void setResult(INT result);
void setResult(Boolean isPass);
```

Parameters
 |

Parameter

 |

Description

 |
 |

result

 |

A variable for a measured value to be displayed on a shmoo plot.

 |
 |

isPass

 |

A variable for a pass/fail result to be displayed on a shmoo plot.

 |

## Return value

There is no return value.

## Examples

### Example 1

```
double meaValue1;
meaValue1 = ifvmMea.getValue("I/O1");
SHMOO_RESULT.pin("I/O1").testName("Voltage").setResult(meaValue1);
```

### Example 2

```
bool funcResult =GET_FUNCTIONAL_RESULT();
SHMOO_RESULT.site(1).pin("dataPins").testName("Function").setResult(funcResult);
```
