# SMC_GET_VECTORS()

Retrieves the captured data of the vector memory identified by the vector name and a result area id.

This API can be used only inside your `SMC_backgroundProcessing()` method to make use of hidden upload.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```
const ARRAY_I& SMC_GET_VECTORS(const STRING& name,
                               const STRING& area,
                               INT samples = -1,
                               INT bits = -1,
                               INT offset = 0,
                               const STRING& format = "BIN",
                               VECTOR::INPUT_MODE mode = VECTOR::NORM,
                               VECTOR::SOC_VECTOR_BYTE_ORDER order = VECTOR::SOC_VECTOR_BIG_ENDIAN);

const ARRAY_I& SMC_GET_VECTORS(const INT site,
                               const STRING& name,
                               const STRING& area,
                               INT samples = -1,
                               INT bits = -1,
                               INT offset = 0,
                               const STRING& format = "BIN",
                               VECTOR::INPUT_MODE mode = VECTOR::NORM,
                               VECTOR::SOC_VECTOR_BYTE_ORDER order = VECTOR::SOC_VECTOR_BIG_ENDIAN);

const ARRAY_I& SMC_GET_VECTORS(const STRING& name,
                               const INT instanceIndex,
                               const STRING& area,
                               INT samples = -1,
                               INT bits = -1,
                               INT offset = 0,
                               const STRING& format = "BIN",
                               VECTOR::INPUT_MODE mode = VECTOR::NORM,
                               VECTOR::SOC_VECTOR_BYTE_ORDER order = VECTOR::SOC_VECTOR_BIG_ENDIAN);

const ARRAY_I& SMC_GET_VECTORS(const INT site,
                               const STRING& name,
                               const INT instanceIndex,
                               const STRING& area,
                               INT samples = -1,
                               INT bits = -1,
                               INT offset = 0,

                               VECTOR::INPUT_MODE mode = VECTOR::NORM,
                               VECTOR::SOC_VECTOR_BYTE_ORDER order = VECTOR::SOC_VECTOR_BIG_ENDIAN);
```

## Return value

Returns an array of the captured data of the vector memory identified by the vector name and a result area id.

The returned array is valid till [SMC_SYNCHRONIZE()](<02.07.04.01.231.43_SMC_SYNCHRONIZE.md>) is called.

## Example

This example starts a background process and downloads the vector results.

```
protected:

    virtual void initialize()
    {
    }

    virtual void run()
    {
        STRING testName;

        GET_TESTSUITE_NAME(testName);

        ON_FIRST_INVOCATION_BEGIN();
        {
            RESULT_AREA_CONFIG resultAreaConfig("dig1,dig2,dig3,dig4");

            resultAreaConfig.appendArea("16KBITArea",3072).activate();

            SMC_DIGITAL_CAPTURE_TEST("16KBITArea");

            ARRAY_I activeSites;

            GET_ACTIVE_SITES(activeSites);

            SMC_ARM(activeSites);
        }
        ON_FIRST_INVOCATION_END();

        return;

    } // virtual void run()

public:

    virtual void SMC_backgroundProcessing(ARRAY_I& activeSites)
    {
        for (int siteIndex = 0; siteIndex < activeSites.size(); ++siteIndex)
        {
            INT currentSite = activeSites[siteIndex];

            ARRAY_I vectorArray = SMC_GET_VECTORS(currentSite, "cap1", "16KBITArea");

            cout << "Vector data: " << vectorArray << endl;
        }

    } // virtual void SMC_backgroundProcessing(ARRAY_I& activeSites)
```
