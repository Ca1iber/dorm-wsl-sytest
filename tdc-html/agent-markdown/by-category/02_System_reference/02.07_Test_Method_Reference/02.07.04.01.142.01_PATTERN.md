# PATTERN

The PATTERN class is a subsidiary data container that holds elements of individual subpatterns.

The API cannot be instantiated directly, but can only be accessed by the [label(...)](<02.07.04.01.142_PATTERN_CONTROLLER.md#_71357__dlentry_label>) member function of the [PATTERN_CONTROLLER](<02.07.04.01.142_PATTERN_CONTROLLER.md>) class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Pattern.h.

## Member functions

  add(TASK)

```
PATTERN & add(TASK & task));
```

This member function allows to execute Board ADC tests in parallel with digital test for different ports, and also to alternate (switch) between digital tests, PinPMU tests, and Board ADC tests in one pattern run without the need to stop the sequencer. The API

- downloads measurement sets defined with the PPMU_xxx and BADC_xxx APIs.
- inserts instructions (which will execute these sets) into a predefined subpattern.
- executes the current primary sets.

Parameter
 | task  | A class object of one of the PPMU_xxx or BADC_xxx classes. The pins for which the task is defined must be a subset of the pins of the port to which the subpattern belongs.  |  add(PPMU_TASK)

```
PATTERN & add(PPMU_TASK & task);
```

This member function assigns a class object of one of the PPMU_SETTING, PPMU_RELAY, PPMU_MEASURE, or PPMU_CLAMP API's to a subpattern. The measurement sets generated from these objects will be executed from within the specified subpattern.

Parameter
 | task  | A class object of one of the PPMU_xxx classes. The pins for which the task is defined must be a subset of the pins of the port to which the subpattern belongs.  |  add(BADC_TASK)

```
PATTERN & add(BADC_TASK & task);
```

This member function assigns a class object of one of the [BADC_SETTING](<02.07.04.01.09_BADC_SETTING.md>) and [BADC_MEASURE](<02.07.04.01.08_BADC_MEASURE.md>) API's to a subpattern. The measurement sets generated from these objects will be executed from within the specified subpattern.

Parameter
 | task  | A class object of one of the BADC_xxx classes. The pins for which the task is defined must be a subset of the pins of the port to which the subpattern belongs.  |  add(DC_WAVEFORM)

```
PATTERN & add(DC_WAVEFORM & waveform);
```

This member function assigns a DC waveform to the pattern.

Parameter
 | waveform  | An object of the DC_WAVEFORM class.  |  vecEvents(...)

```
VEC_EVENTS & vecEvents(const STRING & pinlist);
```

This member function returns the vector event editing interface for the specified pins. Using the [VEC_EVENTS](<02.07.04.01.267_VEC_EVENTS.md>), you can define events on DC Scale channels in the vectors of a pattern.

Note The interface is valid for only one pinlist at a time. It is valid as long as the pattern is not changed via label(), or until the next call to vecEvents(). Each call to vecEvents() will invalidate a previously retrieved VEC_EVENTS reference.

Parameter
 | pinlist  | The pin list to work with.  |  getClampHighCurrent(...) and getClampLowCurrent(...)

```
bool getClampHighCurrent(const STRING & singlePin,
                                   INT      refVector,
                                   DOUBLE & current) const;

bool getClampLowCurrent(const STRING & singlePin,
                                   INT      refVector,
                                   DOUBLE & current) const;
```

These member functions find the last current clamp that is defined before or at the specified vector in this pattern. Also samples generated by a waveform will be analyzed. If the force current cannot be determined, false is returned. This might for instance happen if no force event exists or an equation variable is referenced that cannot be resolved to a value.

Parameters
 | singlePin  | The pin to be analyzed. |
 | refVector  | The vector for which the currently active force voltage will be searched. |
 | current  | The found force current value. If no value is set, return value is 999999 for iClampHigh and -999999 for iClampLow. |

Return value
 | true  | The force current was successfully resolved. |
 | false  | No force current between pattern start and refVector was found.  |  getForceVoltage(...)

```
  bool getForceVoltage(const STRING & singlePin, INT refVector,
                       DOUBLE & voltage) const;
```

This member function finds the force voltage that is defined before or at the specified vector in this pattern. Also samples generated by a waveform will be analyzed. If the force voltage cannot be determined, false is returned. This might for instance happen if no force event exists, or if an equation variable is referenced that cannot be resolved to a value.

Note that this function operates on setup data only! It may be used for fast setup backtracking, for example, to lookup the force voltage at a specific cycle. Be aware that this function operates on vectors, not cycles!

Parameters
 | singlePin  | The pin to work with. |
 | refVector  | Reference vector. |
 | voltage  | Voltage at reference vector. |

## Examples

### Example 1

 The example shows how to lookup the force voltage at a specific vector in the "myRamp" pattern.

```
// Get the PATTERN the events will be placed on
PATTERN_CONTROLLER patternController;
PATTERN & pattern(patternController.label("myRamp"));

// Get the force voltage at vector 100
DOUBLE voltage;

if (pattern.getForceVoltage("Vdd", 100, voltage))
{
    cout << "Voltage at vector 100: " << voltage << " V" << endl;
}
```

### Example 2

 The example shows how to add a DC waveform to the designated label.

```
//
// Define an analog waveform
//
ANALOG_WAVEFORM ramp("ramp");
ramp.definition(TM::RAMP)
    .direction(TM::POS)
    .min(-1 V)
    .max(5.5 V)
    .samples(2048);

//
// Integrate the analog waveform into the DC waveform
//
DC_WAVEFORM dcWaveform;

dcWaveform.vForce(ramp)
    .vRange(6 V)
    .iRange(1 mA)
    .sampleVectorDistance(1024);

//
// Add the DC waveform to a label
//
PATTERN_CONTROLLER patternControllerDcWaveForm;
patternControllerDcWaveForm.label("ppmuSubRamp","portPpmu").add(dcWaveform);
patternControllerDcWaveForm.setup(); //This function is only needed for the first run.
```

### Example 3

 The example below shows how to get the last current clamp that was defined before or at the specified vector in a pattern.

```
PATTERN_CONTROLLER pc;
PATTERN & pattern(pc.label("patEvents", "@"));

EVENT_IC iClampEvent1("iClampEvent1");
EVENT_RANGE_RESTORE eventRangeRestore("eventRangeRestore");

ON_FIRST_INVOCATION_BEGIN();

    iClampEvent1.iClampLow(1 mA);

    pattern.vecEvents("dps1").clearAll().setup();

    pattern.vecEvents("dps1")
            .insert(32, iClampEvent1)
            .insert(150, eventRangeRestore);

    pc.setup();

ON_FIRST_INVOCATION_END();

DOUBLE current = 0.;

if ( pattern.getClampHighCurrent("dps1", 32, current) )
{
    cout << "High current clamp at vector 32 (expect 999999): " << current << " A" << endl;
}

if ( pattern.getClampLowCurrent("dps1", 32, current) )
{
    cout << "Low current clamp at vector 32 (expect 0.001): " << current << " A" << endl;
}
```
