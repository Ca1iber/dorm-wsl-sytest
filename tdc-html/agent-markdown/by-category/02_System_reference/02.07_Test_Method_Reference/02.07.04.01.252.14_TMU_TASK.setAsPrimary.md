# TMU_TASK.setAsPrimary()

Sets the current TMU set as primary set. The primary set is used for the next functional test.

## Syntax

Using the constructor of TMU_TASK, an empty TMU set is generated.

```
TMU_TASK& setAsPrimary();
```

List of parameters

There are no parameters.

## Return value

A reference to the TMU_TASK object is returned.
