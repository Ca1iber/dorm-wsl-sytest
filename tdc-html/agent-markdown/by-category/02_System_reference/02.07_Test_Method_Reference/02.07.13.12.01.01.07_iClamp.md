# iClamp()

Specifies the high and low clamp current for PPMU.

The function can be used in the code‑based mode and in the pattern‑based mode.

## Syntax

```
dcBase& iClamp(double iClampLow, double iClampHigh);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

iClampLow

iClampHigh

 |

The parameters set the low and high current values for the clamp.

 |

## Example

```
RDI_BEGIN()

  rdi.dc().pin("DATA1").iClamp(0,1).execute();
  rdi.dc().pin("DATA1").vMeas().execute();
  rdi.dc().pin("DATA1").clampOff().execute();

RDI_END();
```
