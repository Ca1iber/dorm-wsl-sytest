# TESTSET().testname_default()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) cancels the test name which has been set by a prior call of the [testname(const STRING &name)](<02.07.04.01.244.23_TESTSET__.testname.md>) member function and returns to the default mode.

In default mode the test name that is given to the [TEST()](<02.07.04.01.241_TEST.md>) method, or that is automatically generated in the TEST() API, based on the test name given to the TEST() method, is stored into the EDL as a [TestName](<../02.10_Data_Logging/02.10.01.06.05.61_TestNameAttrType.md>) attribute. This member function is used only after the [testname](<02.07.04.01.244.23_TESTSET__.testname.md>) function has been executed.

This function is not supported within the SMC_backgroundProcessing() test method when flag [hidden_datalog_mode](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_hidden_datalog_mode>) is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

## Syntax

```
TESTSET & testname_default();
```

## Example

```
TestSet.testname_default();
```
