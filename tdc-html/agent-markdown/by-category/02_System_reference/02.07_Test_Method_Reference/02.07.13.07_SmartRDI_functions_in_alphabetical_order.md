# SmartRDI functions in alphabetical order

The following table lists the SmartRDI functions in alphabetical order.

  The Type column briefly describes the command type:

- Status: The command is used for setting status.
- Execution: The command is used for executing actions.
- Result retrieval: The command is used for retrieving results.
- Structure: The command is used for constructing the code frame.
 The Mode column indicates the execution mode for those commands that are marked as Execution in the Type column:

- P = Pattern-based
- C = Code-based
- N/A = Not Applicable for non-execution commands

The Class column lists the class to which the function belongs. For a list of supported classes see [SmartRDI classes](<02.07.13_SmartRDI.md#_142069__s_SRDI_classes>).

For detailed information about each function, click the function name to see its specific topic.
