# UI_SUSPEND

This API suspends and resumes updates of the user interface (SmarTest Work Center). It can be helpful for example, when executing the [SREC ACT,(@)](<../02.06_Command_Reference/02.06.02.02.243_SREC__SREC__-__Set_RECeiver_mask.md>) command, which may cause excessive overhead.

 CAUTION Use this API with care. When applied, any results displayed by the user interface (UI) are unreliable, as the UI is not constantly updated.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Execute.h.

## Syntax

```
void UI_SUSPEND( TM::ON_OFF onOff);
```

Parameter
 |

I/O

 |

Parameter

 |

Description / Range

 |
 |

I

 |

onoff

 |

The action to be executed. Possible values are:

 |
 |

 |

 |

TM::_ON

 |

Suspends user interface updates.

 |
 |

 |

 |

TM::_OFF

 |

Resumes user interface updates.

 |

## Examples

### Suspend user interface updates

```
UI_SUSPEND(TM::_ON);
```

### Resume user interface updates

```
UI_SUSPEND(TM::_OFF);
```
