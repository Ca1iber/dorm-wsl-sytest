# TIMING_OFFSET_SEARCH_PINS.errorCountLimit()

This function sets the error count limit. It is only needed if the detection type is `TIMING_OFFSET_SEARCH::ECL` or `TIMING_OFFSET_SEARCH::ECG`.

## Syntax

```
TIMING_OFFSET_SEARCH_PINS& errorCountLimit(INT errorcountlimit);
```

Parameter
 |

errorcountlimit

 |

The error count limit. Default value is 1.

 |

## Functional changes

- Introduced in SmarTest 7.0.1
