# search()

Searches the first occurrence of a specified pattern and returns the last character of the found search pattern in the direction of search. The returned value is the index of the last character of the pattern in search direction. The direction of the search is determined by the direction parameter.

If the search pattern is not found, the function will return -1.

Errors will be issued if,

- parameter types are wrong or
- an invalid direction value has been entered.

## Syntax

```
integer := search(sequence, pattern, direction)
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

sequence

 |

State character sequence to be searched.

 |
 |

I

 |

pattern

 |

Specifies the search pattern.

 |
 |

I

 |

direction

 |

Specifies the search direction.

+1 search from right to left, i.e increasing index.

-1 search from left to right, i.e. decreasing index.

 |

## Example

search`("00000000`0010`HLHLHLHL", "`0010`",`-1`)` returns 8.

search`("0000000000`10`HLHLHLHL", "`10`",`-1`)` returns 8.

search`("00000000`0010`HLHLHLHL", "`0010`",`1`)` returns 11.

search`("0000000000`10`HLHLHLHL", "`10`",`1`)` returns 9.

search`("000000000010`HLHLHLHL`", "`HLHLHLHL`", `-1`)` returns 0.

search`("`01010`0000010HLHLHLHL", "`01010`",`1`)` returns 19.

search`("000000000010HLHLHLHL", "`0110`",`-1`)` returns -1.

search`("000000000010HLHLHLHL", "`0110`",`1`)` returns -1.

search`("000000000010HLHLHLHL", "", `-1`)` returns -1.

search`("000000000010HLHLHLHL", "", `1`)` returns -1.

search`("1", "`101`", `-1`)` returns -1.

search`("10", "`101`", `1`)` returns -1.

search`("", "`1`", `-1`)` returns -1.

search`("", "`0`", `1`)` returns -1.

search`("000010HLHLHLHL", "`0110`", 0)` results in an "ERROR: Parameter 'direction' must be +1 or -1."

The following example extracts a 32 bits state character sequence from a field's value (rawData) using the [subSCS()](<02.07.11.01.11.03.10_subSCS.md>) function behind the matching pattern "0010", searching from left to right.

```
subSCS(rawData, search(rawData, "0010", -1) -1, 32, -1)
```
