# SEMI_PARALLEL_CONFIG.getGroupNumber()

Gets the number of groups in the current semi-parallel configuration.

## Syntax

```
int getGroupNumber() const;
```

List of parameters

There are no parameters.

## Return value

The number of groups in the semi-parallel configuration is returned.

## Functional changes

- Introduced in SmarTest 7.2.0
