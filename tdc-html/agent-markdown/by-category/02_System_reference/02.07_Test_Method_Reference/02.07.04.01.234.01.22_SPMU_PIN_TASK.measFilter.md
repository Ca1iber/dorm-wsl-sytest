# SPMU_PIN_TASK.measFilter()

Sets the measure filter for voltage and current measurements.

This member function is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

XPS256 channels feature programmable anti-aliasing, low-pass measure filters for voltage and current measurements. This member function sets the measure filter for the selected measurement mode that has been selected by [SPMU_PIN_TASK.mode()](<02.07.04.01.234.01.24_SPMU_PIN_TASK.mode.md>).

## Syntax

```
SPMU_PIN_TASK& measFilter(double filterFrequency);
```

  Paameter

 | Parameter  | Description |
 | filterFrequency |

Sets the filter to the given frequency in Hz or switches the filter off.

Programmable double values are

- Value between the card-specific minimum and maximum value: The filter is set to the defined value.
- 0.0: The filter is set to the card-specific default value.
 Card-specific range and default value:

- XPS256: Refer to section

  -  [Measurement filters](<../02.05_Test_Head_Cards/02.05.05.03.10.14_XPS256_programming_-_Measure_voltages.md#_354459__s_Measure_filters>) in [XPS256 programming - Measure voltages](<../02.05_Test_Head_Cards/02.05.05.03.10.14_XPS256_programming_-_Measure_voltages.md>) or to section
  - [Measurement filters](<../02.05_Test_Head_Cards/02.05.05.03.10.13_XPS256_programming_-_Measure_currents.md#_354458__s_Measure_filters>) in [XPS256 programming - Measure currents](<../02.05_Test_Head_Cards/02.05.05.03.10.13_XPS256_programming_-_Measure_currents.md>).

  |   Return value A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.

## Application note

  Measure filter settling time The programmable digital low-pass measure filters for all ADCs behave like simple RC filters. A short settling time is to be applied or some samples are to be ignored to settle to an acceptable difference to the input signal.The required settling time of the filter or the number of samples to be ignored depends on the accepted maximum relative error and the filter settings. The supported DC Scale cards show a slightly different behavior:

- XPS256: Refer to the related application notes in topics [Measure voltages](<../02.05_Test_Head_Cards/02.05.05.03.10.14_XPS256_programming_-_Measure_voltages.md#_354459__dle_Measure_filter_settling_time>) or in [Measure currents](<../02.05_Test_Head_Cards/02.05.05.03.10.13_XPS256_programming_-_Measure_currents.md#_354458__dle_Measure_filter_settling_time>) of the XPS256 programming overview.

## Example

The following example shows how to set the measure filter.

```
SPMU_TASK spmuTask_1;

spmuTask_1.pin("...")
    ...
    ...
    .measFilter(100 kHz) // Set the measure filter to 100 kHz
    ;
```

Note: The example concentrates on the function described in this topic. More settings are required for an executable SPMU_TASK object.
