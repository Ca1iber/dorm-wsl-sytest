# Pass/Fail per label with digital capture

SmartRDI automatically changes to the ERMP mode when both digital capture and per-label pass/fail exist in the same RDI_BEGIN/RDI_END block.

The reason is that the FW command FLBL cannot work together with DIGITAL_CAPTRUE_TEST().

In addition, ERMP cannot work with a pin for digital capture. Therefore, if you use the per-label Pass/Fail feature to retrieve pass/fail results on a digital capture pin, you cannot get the right pass/fail results. A warning will pop up when this happens.

Also, the keyword PER_LABEL_FUNC_RESULT_NO_BREAK_VEC must be set to `TRUE`, see [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>).

The Pass/Fail label must contain 8 or more vectors to work with digital capture.

## Example

```
RDI_BEGIN();
  rdi.func("id").label("label1").execute();
  // or others with enPassFail or rdi.smartVec().expect
  rdi.digCap("id2").pin("DATA2").samples(5).execute();
  // or use with smartVec read with digcap mode
  rdi.smartVec()...
RDI_END();
...
rdi.id("id").getPassFail();// will not cover DATA2 pin
```

## Functional changes

- Introduced in SmartRDI 2.4.4
