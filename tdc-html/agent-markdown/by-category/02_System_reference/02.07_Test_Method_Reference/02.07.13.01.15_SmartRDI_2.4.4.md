# SmartRDI 2.4.4

This section summarizes the changes and new features in SmartRDI 2.4.4.

Changes and new features
 |

Category

 |

Description

 |
 |

General

 |

General features:

- A new `copyLabel()` command supports overwriting existing patterns instead of editing copied patterns for all commands with `label()`. See the following new commands:

  - [copyLabel()](<02.07.13.12.01.01.04_copyLabel.md>)
  - [rdi.tmu().label().copyLabel()](<02.07.13.21.08_rdi.tmu__.label__.copyLabel.md>) for `tmu()`

- Supporting Shmoo serial execution. See the new ALLOW_SAME_RESULT_ID_ACROSS_RDI_BLOCK keyword in the [RDI_Configure](<02.07.13.04_RDI_Configure_file.md>) file.

General Improvements:

- 1st-run speed improvement.
- Run-time vector download speed improvement.

  - Supports the combination of run-time accesses for the VTT mode within a `burstLabel().begin()`/`burstLabel().end()` block. See [burstLabel()](<02.07.13.24.03_burstLabel.md>).

 |
 |

SmartVec

 |

- Supporting pattern generation based on user pattern. See the new [label()](<02.07.13.24.22_label.md>) and [copyLabel()](<02.07.13.12.01.01.04_copyLabel.md>) commands.
- Switching run-time pattern edit mode in TM code. See "Example 2" in [rdi.smartVec().vecEditMode()](<02.07.13.24.33_rdi.smartVec__.vecEditMode.md>).
- Supporting JSUB / JMPE / RPTJ instruction invocation.

  - See the new command [insertSub()](<02.07.13.24.21_insertSub.md>) for JSUB instruction invocation.
  - See the new command [repeatSub()](<02.07.13.24.32_repeatSub.md>) for RPTJ instruction invocation, which should be used together with [insertSub()](<02.07.13.24.21_insertSub.md>).
  - See the new commands [insertJmpe()](<02.07.13.24.20_insertJmpe.md>), [passNode()](<02.07.13.24.25_passNode.md>) and [failNode()](<02.07.13.24.16_failNode.md>) for JMPE instruction invocation.

- Supporting fail count, fail cycle, first failing cycle.

  - See the new commands [failCount()](<02.07.13.16.03_failCount.md>) and [getFailCount()](<02.07.13.16.13_getFailCount.md>) for falil count.
  - See the new commands [failCyc()](<02.07.13.16.04_failCyc.md>) and [getFailCyc()](<02.07.13.16.14_getFailCyc.md>) for fail cycle.
  - See the new commands [FFC()](<02.07.13.16.05_FFC.md>) and [getFFC()](<02.07.13.16.15_getFFC.md>) for first failing cycle.

- More flexible [repeat()](<02.07.13.24.31_repeat.md>) command.
- Default read mode option in the RDI_Configure file. See the DEFAULT_SMV_READ_MODE keyword in the [RDI_Configure](<02.07.13.04_RDI_Configure_file.md>) file.
 |
 |

Emap

 |

Error map for AVI64 digital pin.

 |
 |

DC

 |

- Shared BADC-HIZ measurement support in pattern. See "Example 2" and "Example 3" in [pin()](<02.07.13.12.01.02.09_pin.md>). Also see "Board ADC example 2" in [measWait()](<02.07.13.12.01.01.14_measWait.md>).
- Serial/semi-parallel execution of PPMU/BADC digitizing for shared BADC over sites. See [Serial/Semi-parallel execution of BADC as digitizer over sites](<02.07.13.11.06_Serial_Semi-parallel_execution_of_BADC_as_digitizer_over_sites.md>).
- DCS SIG disconnect(min, max) enhancement for ganged pins. See the enhanced [disconnect()](<02.07.13.12.01.03.04_disconnect.md>) command.
- AWG- & DGT-functionality for different pins within the same `execute()`. See [Forcing waveform on a pin and sampling on another pin](<02.07.13.11.07.02_Forcing_waveform_on_a_pin_and_sampling_on_another_pin.md>).
- New connect modes for AVI64 SIG pin (SmarTest 7.4.1).
- Support of multiple `insertSub()` in one vector line. See the enhanced [insertSub()](<02.07.13.12.01.01.10_insertSub.md>) command.
 |
 |

TMU

 |

- TMU runtime value support for threshold setting. See the enhanced command.
- Support TMU hidden upload for PVI8/AVI64 (SmarTest 7.4.1). See "Example 2" in [rdi.hiddenUpload()](<02.07.13.08.19.02.03_rdi.hiddenUpload.md>).
- Common thread TMU hidden upload (SmarTest 7.4.1). See "Example 3" in [rdi.hiddenUpload()](<02.07.13.08.19.02.03_rdi.hiddenUpload.md>)
 |
 |

PMUX

 |

Support PMUX sensors.Not supported with SmarTest 7.10

 |
 |

UTIL

 |

Maximum speed option for sequencer‑controlled utility lines. See the new UTIL_CTRL_MAX_SPEED keyword in the [RDI_Configure](<02.07.13.04_RDI_Configure_file.md>) file.

 |
 |

Auxiliary

 |

Get user label's cycle number. See the new command [getLabelCycleNum()](<02.07.13.22.01_getLabelCycleNum.md>).
