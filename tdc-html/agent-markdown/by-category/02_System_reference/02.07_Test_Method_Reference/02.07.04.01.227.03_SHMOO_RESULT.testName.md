# SHMOO_RESULT.testName()

This member function defines the test name for a result to be displayed on a shmoo plot.

This result is defined with the [setResult()](<02.07.04.01.227.05_SHMOO_RESULT.setResult.md>) member function.

If you do not define a test name with this member function, the test name will be "resultX". X is an integer increasing from 1.

For example, having defined two results to be displayed on a shmoo plot, by default, the test name for the first result is "result1" and for the second result is "result2".

## Syntax

```
ShmooResultAdapter& testName(const STRING& testName);
```

Parameter
 |

Parameter

 |

Description

 |
 |

testName

 |

A test name for a result to be displayed on a shmoo plot.

 |

## Return value

Returns an instance of the ShmooResultAdapter class.

## Example

```
double meaValue1;
SHMOO_RESULT.testName("meaVoltage1").setResult(meaValue1);
```
