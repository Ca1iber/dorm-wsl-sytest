# DISABLE_CHANGE_NOTIFICATION

This API disables the clearing of test method caches between test method program executions.

After using the DISABLE_CHANGE_NOTIFICATION API, you can use the ENABLE_CHANGE_NOTIFICATION API to restore the test method to its default behavior.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

## Syntax

```
DISABLE_CHANGE_NOTIFICATION();
```

## Parameters

No parameter in this API.

## Example

```
DISABLE_CHANGE_NOTIFICATION();
```

The DISABLE_CHANGE_NOTIFICATION API disables cache resetting between test method program executions.

## Functional changes

- Introduced before SmarTest 6.3.2
