# PPMU voltage clamp on Pin Scale systems

In addition to the clamp circuit in the Pin Scale channel board front end, the PPMU on the Pin Scale boards also has a voltage clamp circuit. This is to avoid unexpected spikes or overvoltage during the current force/voltage measurement.

To use this clamp circuit, set up the high and low clamp voltages in your programs. You can use the precharge parameter in the DC test methods (current force/voltage measurement) using the PPMU, the PPMU_CLAMP test method API, and the DFVM firmware command to set them up.

If you specify the precharge value, the Pin Scale Systems set up the high and low clamp voltages with the precharge value 卤100 mV instead of the precharge voltage. For example, if you specify 1 V as the precharge parameter, the high and low clamp voltages are set to +1.1 V and +0.9 V. At this time, the range of the precharge parameter is -2 to +7 V for the Pin Scale 800 channel board, and -1 to +4.3 V for the Pin Scale 3600 channel board.

Then the following sequence is executed in each PPMU's current force/voltage measurement test internally.

- Force the desired current in the specified range.
- Set the voltage limits for test result.
- Set the clamp voltages and switch it ON.
- Switch the relays on the channel board to make the PPMU path.
- Switch the clamp OFF.
- Measure the voltage.
- Switch the relays to cancel the PPMU path.
