# SPMU_PIN_TASK.iFilter()

Sets the force current or clamp current filter as frequency.

This member function is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

Both this member function and [SPMU_PIN_TASK.iClampFilter()](<02.07.04.01.234.01.12_SPMU_PIN_TASK.iClampFilter.md>) control the same functionality of the hardware.

The force current filter or clamp current filter is set as frequency. The set value defines a bandwidth filter that has an effect on the dynamic behavior of an XPS256 channel that is forcing or clamping the current.

## Syntax

```
SPMU_PIN_TASK& iFilter(DOUBLE filterFrequency);
SPMU_PIN_TASK& iFilter(const STRING & filterFrequency);
```

Parameter
 | Parameter  | Description |
 | filterFrequency  | Sets the filter to the given frequency in Hertz (Hz) or switches the filter off. The parameter can be defined as double value or as string.

Programmable double values or strings are

- Value between the card-specific minimum and maximum value: The filter is switched on and set to the defined value.
- 0.0: The filter is set to the card-specific default value.

Programmable strings are

- "OFF": The filter is set to the card-specific default value.
Card-specific range and default value:

- XPS256: Refer to section [Dynamic behavior](<../02.05_Test_Head_Cards/02.05.05.03.10.08_XPS256_programming_-_Force_and_clamp_currents.md#_354306__s_Dynamic_behavior>) in [XPS256 programming - Force and clamp currents](<../02.05_Test_Head_Cards/02.05.05.03.10.08_XPS256_programming_-_Force_and_clamp_currents.md>).
 |

## Return value

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.

## Example

The following example shows how to set the voltage filter and the current filter.

```
SPMU_TASK spmuTask_1;

spmuTask_1.pin("...")
    ...
    ...
    .vFilter("OFF") // Switch the voltage filter off
    .iFilter(1000) // Set the current filter to 1 kHz
    ;
```

Note: The example concentrates on the function described in this topic. More settings are required for an executable SPMU_TASK object.
