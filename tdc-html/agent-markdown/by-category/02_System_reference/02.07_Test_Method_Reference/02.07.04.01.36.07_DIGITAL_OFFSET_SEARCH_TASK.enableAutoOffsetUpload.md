# DIGITAL_OFFSET_SEARCH_TASK.enableAutoOffsetUpload()

Uploads the offset for the middle of the pass area found in the latest offset search from the tester to the system controller.

It functions the same as [DIGITAL_OFFSET_SEARCH_TASK.uploadOffset()](<02.07.04.01.36.16_DIGITAL_OFFSET_SEARCH_TASK.uploadOffset.md>) but used in different scenarios:

- When using [TASK_LIST](<02.07.04.01.240_TASK_LIST.md>) to execute one or more DIGITAL_OFFSET_SEARCH_TASK objects, if you want to retrieve the found offsets, before adding those objects to a TASK_LIST, you must have set up this member function instead of uploadOffset() for every object to upload the offsets to the system controller. Otherwise, you cannot get the correct offset values.
- In the other cases, use uploadOffset().

## Syntax

```
void enableAutoOffsetUpload(SetSelector& selector, RESOURCE_TYPE resource) throws TMException;
```
