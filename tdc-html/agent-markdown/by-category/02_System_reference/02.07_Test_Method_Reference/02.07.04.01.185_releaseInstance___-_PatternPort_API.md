# releaseInstance() - PatternPort API

This function is used to release the instance of the PatternPort.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
void releaseInstance();
```

## Example

```
CCTMultiportSync    Sync;
PatternPort::getInstance().setPort("SH1_Port");
PatternPort::getInstance().setWaitTemplatePatternName("SH1_Wait_Template");
Sync.registerSyncPort(PatternPort::getInstance());

Sync.start();
PatternPort::getInstance().playPattern("SH1_Func");

Sync.sync();
Sync.flush();
......

PatternPort::releaseInstance();
```
