# Using a DC Scale resource as a digitizer while sourcing a waveform on the same pin

When you use the DC Scale pin as a digitizer to capture the waveform generated by the same pin, you will capture a sample for each point in the forcing waveform.

## About this task

The result waveform can be retrieved with the function [getWaveform()](<02.07.13.11.04.09_getWaveform.md>).

It can be used to:

- Force voltage waveform and measure the current waveform on the same pin
- Force current waveform and measure the voltage waveform on the same pin
- Force voltage waveform and measure the voltage waveform on the same pin
- Force current waveform and measure the current waveform on the same pin

## Procedure

-  Define the waveform with the class anaWaveform.
-  Set up the pin to work as AWG.

  -  Create a test with the class dc().
  -  Specify the pin(s) to work as AWG with pin().
  -  Specify the type of waveform with vForce() for voltage waveform or iForce() for current waveform. It is voltage waveform by default.
  -  Specify the waveform to force with the function waveform().
  -  Specify the sampling frequency with FS(), samplePeriod() or sampleCycle().

-  Specify the waveform to capture with iMeas() or vMeas().
-  Execute the setup with execute().

## Results

The DC Scale pin can be used as AWG to generate a waveform and used as digitizer to capture a waveform.

## Example

```
rdi.dc("id").pin().vForce().iMeas().waveform(wav).FS(10 KHz).execute();
rdi.dc("id").pin().vForce().vMeas().waveform(wav).FS(10 KHz).execute();
rdi.dc("id").pin().iForce().iMeas().waveform(wav).samplePeriod(100 us).execute();
rdi.dc("id").pin().iForce().vMeas().waveform(wav).sampleCycle(1000).execute();
```
