# EVENT_VCIM.getLimitLow()

Reads the lower limit that has been defined by [EVENT_VCIM.limits()](<02.07.04.01.63.21.09_EVENT_VCIM.limits.md>) or [EVENT_VCIM.limitLow()](<02.07.04.01.63.21.10_EVENT_VCIM.limitLow.md>).

The value is read from the corresponding [EVENT_VCIM](<02.07.04.01.63.21_EVENT_VCIM.md>) object and returned as an [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
bool getLimitLow (EVENT_VALUE_DOUBLE & low) const;
```

Parameter
 | Parameter  | Description |
 | lowLimit |

The programmed lower limit in A (Ampere).

 |

## Return value

bool value indicating the state of the limit definition:

- true: Limit has been defined by [EVENT_VCIM.limits()](<02.07.04.01.63.21.09_EVENT_VCIM.limits.md>) or [EVENT_VCIM.limitLow()](<02.07.04.01.63.21.10_EVENT_VCIM.limitLow.md>).
- false: No limit is defined or the limit has been cleared by [EVENT_VCIM.clearLimits()](<02.07.04.01.63.21.12_EVENT_VCIM.clearLimits.md>).

## Example

For an example see [EVENT_VCIM](<02.07.04.01.63.21_EVENT_VCIM.md>).
