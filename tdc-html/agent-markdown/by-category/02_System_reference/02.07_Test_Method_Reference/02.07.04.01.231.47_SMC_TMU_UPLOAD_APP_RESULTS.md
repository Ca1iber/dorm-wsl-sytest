# SMC_TMU_UPLOAD_APP_RESULTS()

The SMC_TMU_UPLOAD_APP_RESULTS() is the SmartCalc API to compute TMU values for a particular application and upload them in the background.

This API computes and uploads the TMU appType values for the last shot, it uploads from the test head card's memory to the result cache on the system controller while a new test suite is being executed. The embedded computing is performed in parallel for the specified pins for all sites. This API must be called inside your `SMC_backgroundProcessing()` method.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Parameters
 |

Parameter

 |

Description

 |
 |

results

 |

The name of the result cache on the system controller to which the results are uploaded.

If this parameter is not specified, the default result cache is used.

 |
 |

resultAreaHandle

 |

The name of the result area to upload from.

Result areas are defined with [TMU_TASK::requestResultAreaHandle(handlename)](<02.07.04.01.252.13_TMU_TASK.requestResultAreaHandle.md>).

If this parameter is not specified, the data from the active result area are uploaded.

 |
 |

dgtPinName

 |

The list of pins for which to upload data.

 |
 |

appType

 |

The application type. Currently only APP_PERIOD is supported.

 |
 |

avaragedonly

 |

The type of the returned results:

- TRUE: Only statistical values of the periods of the timestamps will be uploaded.
- FALSE: Both the periods and their statistical values will be uploaded.
 |
 |

armings

 |

The number of armings to be uploaded from the shot. The upload always starts with the first arming. The default value is 1.

For example, if 3 is specified the ''armings 1, 2, and 3'' are uploaded.

 |
 |

numsamples

 |

The number of samples to be uploaded. Specify 0 to upload all samples. The default is 0.

 |
 |

firstsample

 |

The index of the first sample to be uploaded. The index of the first sample in a block is 0. The default value is 0.

 |
 |

keyName

 |

The name of the related TMU_TASK object.

 |
 |

syncErrors

 |

Controls the error synchronization. This should normally be set to TRUE to synchronize the TMU errors.

The errors are stored in the TMU_PINS objects after waitTMUFinished(). They need to be synchronized with the ResultCache.

 |
 |

site

 |

Specifies the site for which the data should be uploaded.

 |

Return value

There is no return value.
