# SEMI_PARALLEL_GROUP.getSite()

Gets the site number by index in the semi-parallel group.

## Syntax

```
int getSite(int index) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

index

 |

The index in the semi-parallel group.

 |

## Return value

The site number is returned.

## Functional changes

- Introduced in SmarTest 7.2.0
