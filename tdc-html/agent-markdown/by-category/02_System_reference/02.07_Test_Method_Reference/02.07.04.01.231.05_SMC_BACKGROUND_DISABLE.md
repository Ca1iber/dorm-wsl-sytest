# SMC_BACKGROUND_DISABLE()

The SMC_BACKGROUND block in the run() function of a test method class is defined by SMC_BACKGROUND_ENABLE() and SMC_BACKGROUND_DISABLE(). The block encloses non-SMC APIs and marks a time slot where the SmartCalc framework can initiate hidden uploads. The code inside of the block is executed in parallel to hidden uploads and must not access the hardware.

[SMC_BACKGROUND_ENABLE()](<02.07.04.01.231.06_SMC_BACKGROUND_ENABLE.md>) and SMC_BACKGROUND_DISABLE() are intended to be used in the run() function of a test method class and must always be implemented together.

For more information, refer to [SMC_BACKGROUND_ENABLE()](<02.07.04.01.231.06_SMC_BACKGROUND_ENABLE.md>).

## Syntax

```
void SMC_BACKGROUND_DISABLE();
```

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

  List of parameters There are no parameters. Return value There is no return value.
