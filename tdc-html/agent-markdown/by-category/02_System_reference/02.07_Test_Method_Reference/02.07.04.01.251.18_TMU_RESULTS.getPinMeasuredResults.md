# TMU_RESULTS.getPinMeasuredResults()

Retrieves the cached results for a specific pin, application and site.

## Syntax

```
Boolean getPinMeasuredResults(STRING& pin, ARRAY_D& value_array,
                             ARRAY_LL& sampleid_array, TMU::ApplicationType appType,
                             UINT32 meas = 1, UINT32 site = 0);
Boolean getPinMeasuredResults(const char* pin, ARRAY_D& value_array,
                             ARRAY_LL& sampleid_array, TMU::ApplicationType appType,
                             UINT32 meas = 1, UINT32 site = 0);
Boolean getPinMeasuredResults(STRING& pin, ARRAY_D& value_array,
                             TMU::ApplicationType appType, UINT32 meas = 1, UINT32 site = 0);
Boolean getPinMeasuredResults(const char* pin, ARRAY_D& value_array,
                             TMU::ApplicationType appType, UINT32 meas = 1, UINT32 site = 0);
```

Parameters
 |

 |

Parameter

 |

Description

 |

 |
 |

 |

 |

 |

O

 |

The reference to an array to store the sample ID.

 |
 |

I

 |

appType

 |

The application type. It currently can only be TMU::APP_PERIOD and TMU::APP_RAW.

 |
 |

I

 |

meas

 |

The measurement ID.

 |
 |

I

 |

site

 |

The site number. Default is 0, which means the current site.

 |

## Return value

The execution status of the function is returned. True is returned if the result data is available. Otherwise, false is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
