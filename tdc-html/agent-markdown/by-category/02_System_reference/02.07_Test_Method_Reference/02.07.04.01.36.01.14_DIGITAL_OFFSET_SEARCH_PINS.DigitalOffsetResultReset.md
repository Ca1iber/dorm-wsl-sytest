# DIGITAL_OFFSET_SEARCH_PINS.DigitalOffsetResultReset()

Resets the offsets of specific timing or level sets to the default value.

Alternatively, use the [TORR](<../02.06_Command_Reference/02.06.02.02.264_TORR__Timing_level_Offset_Reset_Result.md>) firmware command to reset.

## Syntax

```
void DigitalOffsetResultReset (DIGITAL_OFFSET_SEARCH::SetSelector & selector);
```

Parameter
 |

Parameter

 |

Description

 |
 |

selector

 |

It can be:

- A TimingSetSelector object defined with [TimingSetSelector](<02.07.04.02.17_TimingSetSelector.md>), selects timing sets. Or,
- A LevelSetSelector object defined with [LevelSetSelector](<02.07.04.01.123_LevelSetSelector.md>), selects level sets.
 |

Return value

There is no return value.
