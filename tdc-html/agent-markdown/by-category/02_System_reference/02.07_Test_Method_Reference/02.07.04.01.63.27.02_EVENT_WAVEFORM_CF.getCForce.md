# EVENT_WAVEFORM_CF.getCForce()

Queries the force current waveform that has been defined by [EVENT_WAVEFORM_CF.cForce()](<02.07.04.01.63.27.01_EVENT_WAVEFORM_CF.cForce.md>).

The waveform is read from the corresponding [EVENT_WAVEFORM_CF](<02.07.04.01.63.27_EVENT_WAVEFORM_CF.md>) object and returned as an [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>) object.

## Syntax

```
const ARRAY_D & getCForce() const;
```

  List of parameters There are no parameters. Return value An [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>) object containing the waveform samples that are defined in A (Ampere).

## Example

For an example see [EVENT_WAVEFORM_CF](<02.07.04.01.63.27_EVENT_WAVEFORM_CF.md>).
