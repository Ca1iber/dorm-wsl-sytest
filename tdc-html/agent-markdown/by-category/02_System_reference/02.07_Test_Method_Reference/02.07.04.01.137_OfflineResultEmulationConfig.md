# OfflineResultEmulationConfig

`OfflineResultEmulationConfig` represents a singleton object that holds the global offline result emulation configuration.

## Purpose

- Load and unload the emulation data
- Enable and disable the offline result emulation mode

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/OfflineResultEmulationConfig.h.

## Class definition

### Member functions

```
instance()
load();
unload();
enable();
disable();
```

## Member functions

### instance()

```
OfflineResultEmulationConfig& OfflineResultEmulationConfig::instance()
```

This static function provides access to the singleton object holding the offline result emulation configuration.

- Return value

A reference to the singleton object of class `OfflineResultEmulationConfig`

### load()

```
void load(const STRING& configFile)
```

This member function loads the offline result emulation setup data into SmarTest.

Note This function does not automatically enable the offline result emulation. To enable it call separately the `enable()` function.

The setup file format is specified in [Setup file: mapping to SmarTest concepts](<02.07.12.05.01_Setup_file__mapping_to_SmarTest_concepts.md>).

The function replaces any previously loaded setup data with data from the currently assigned setup file, see table Parameter below.

Parameter
 |

configFile

 |

Path to the configuration file. The path can be either relative to the device directory or absolute.

 |

### unload()

```
void unload()
```

This member function unloads any offline result emulation setup data that has previously been loaded with the `load()` member function.

### enable()

```
void enable()
```

This member function enables the global offline result emulation mode.

It should be called at the beginning of the testflow to avoid unwanted side effects.

### disable()

```
void disable()
```

This member function disables the global offline result emulation mode. Any loaded configuration data is left untouched.

The function should by called at the end of the testflow, after all tests have been concluded.

## Example

```
OfflineResultEmulationConfig& oreConfig =
  OfflineResultEmulationConfig::instance();

oreConfig.load("ore/ore.xml");
oreConfig.enable();
oreConfig.disable();
oreConfig.unload();
```
