# rdi.route().pin().setOff()

Switches off a utility line or a Power MUX (PMUX) switch or a list of utility lines or PMUX switches without using the stored states and keeps the status of the remaining switches.

This function provides direct access to the utility lines and does not use the stored switch states. The function works similar to function [rdi.util().setOff](<02.07.13.23.02_setOff.md>), but expects a switch name or a list of switch names that have been defined in the [Utility Lines Config editor](<02.07.13.15.01.03_Routing_Tools_-_Utility_Lines_Config_editor.md>) of the Routing Tools editors.

The "off" state is defined as follows:

- Utility line open collector output is off
- PMUX switch is open

 | Software鈥慶ontrolled (static) utility lines:  | Code鈥慴ased mode only |
 | Sequencer鈥慶ontrolled (dynamic) utility lines:   | Pattern鈥慴ased mode only |
 | PMUX switches:  | Pattern鈥慴ased mode only |

For more information, refer to [Execution mode](<02.07.13_SmartRDI.md#_142069__s_Execution_mode>) in topic [SmartRDI](<02.07.13_SmartRDI.md>).

- For information regarding the execution sequence for the combination of software controlled and sequencer鈥慶ontrolled utility lines or PMUX switches, refer to the [Execution sequence](<02.07.13.15.05.05_rdi.route__.pin.md#_343443__p_Execution_sequence>) in [rdi.route().pin()](<02.07.13.15.05.05_rdi.route__.pin.md>).
- The utility lines and PMUX switches are to be defined by function [rdi.route().pin()](<02.07.13.15.05.05_rdi.route__.pin.md>).

## Syntax

```
ROUTE& setOff();
```

   List of parameters There are no parameters. Return value A reference to the [ROUTE](<02.07.13.15.05.05_rdi.route__.pin.md>) object.
