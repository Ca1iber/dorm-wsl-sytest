# Output Data Hold Time conversion

The output data hold time can be pass/fail test or value test.

## About this task

For pass/fail test, you can convert it to an `ac_tml.AcTest.functionalTest` test method using the pass value in the test function.

For value test, you can convert it to an `ac_tml.AcTest.` parametricFunctionalTest test method. Firstly, you need to define a timing spec to control the right neighbor edge (shifted edge) of the measured edge. Then you can use it in a`c_tml.AcTest.parametricFunctionalTest` as the parameter to shift.

In value test, the Output Data Hold Time test function tries to find the minimum time for which the output signals must retain their present state after the reference signal has validated new data. The definition of propagation delay time (tpd) and output data hold time (tdh) are shown in the figure below.

 ![Propagation Delay and Output Data Hold Time Evaluation](<../../../../raw/28218.png>)

## Procedure

-  Define a timing spec as output data hold time to control the shifted edge:

`shifted_edge = reference_time + period + output_data_hold_time`

-  Calculate the range of the spec according to the search range of the shifted edge. (`output_data_hold_time = shifted_edge - reference_time - period`)

Start position of the shifted edge is defined as `reference_time + period + pass_output_data_hold_time.`

The left boundary of the shifted edge is

  - For edge compare, the last receive edge minus one period (if exists) or the start position minus one period
  - For window compare, the window open edge

The right boundary of the shifted edge is

  - for edge compare, the start position plus one period
  - for window compare, next window compare edge in the same test system cycle or the start position plus one period.

-  Enter the parameter value for the ac_tml.AcTest.parametricFunctionalTest.

## Example

The following example shows how to convert a output data hold time to ac_tml.AcTest.parametricFunctionalTest. The timing setup used in the test function is shown on the left side of the test function.

  ![Output data hold time example](<../../../../raw/118611.png>)

In the example, the output data hold time is measured for edge r1 of pin group ser_out. The reference time is edge d1 of pin CP. If the measured output data hold time is larger than 1 ns, the measurement is pass.

To convert the output data hold time to `ac_tml.AcTest.parametricFunctionalTest`, you need to:

- Define a spec output_hold to control the moved edge r2`:`

```
PINS all_out
r1 = 45
r2 = output_hold + 70
```

- The left boundary of r2 search range is nominal setup of r2 minus one period and the right boundary of r2 search range is nominal setup of r2 plus one period. The following figure shows the search range of r2.
  ![Search range](<../../../../raw/118850.png>)

Start position is pass_data_hold + period + reference_time = 1

+50+20 =71. So the search range of r2 is from start - period to start + period, which is from 21 to 121.

output_hold = r2 -70. So the search range of r2 is from -49 to 51.

Enter the parameter values for `ac_tml.AcTest.parametricFunctionalTest`.
