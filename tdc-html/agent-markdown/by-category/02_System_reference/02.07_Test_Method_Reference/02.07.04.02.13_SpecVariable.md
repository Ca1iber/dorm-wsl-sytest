# SpecVariable

The parameter type SpecVariable is defined to represent the spec variables defined in the level and timing setup files in universal test method. It contains the information of spec type, equation set number, spec name and unit of the spec variable. Its value is in the format of "`specType.equationSetNumber.specName[unit]`".

For example, it can be:

`"LEV.1.fooSpec[mV]"` means the spec variable is `fooSpec` in equation set 1 of level file, with the unit `[mV]`.

`"TIM.3.barSpec@port1[A]"` means the spec variable is `barSpec` in equation set 3 for port `port1` of timing file, with unit `[A]`.

A SpecVariable parameter includes the following fields:

`mFullName`: The full name of the SpecVariable parameter.

`mType`: The type of the spec variable.

`mEquationSetId`: The equation set number the spec variable belongs to.

`mName`: The spec variable name.

`mUnit`: The unit of the spec variable.

You can call the value of a field with th format "`SpecVariable.field`". For example the parameter name is `spec`, `spec.mUnit` calls the unit of the spec variable.

There are three member functions defined for SpecVariable. These functions can be used in the test method to process and change the SpecVariable parameter.

## Member function

### parseFullName()

```
void parseFullName();
```

This function parses the input string to fill in the specific field of a SpecVariable parameter, including type, equation set number, spec name and unit.

### Reset()

```
void Reset();
```

This function resets the value of a SpecVariable to empty.

### operator =

```
SpecVariable& operator = (const SpecVariable& rhl)
```

This function sets the value for a SpecVariable parameter by copying from another SpecVariable parameter.

Parameter
 |

rhl

 |

The SpecVariable parameter to copy from.

 |

## Example

The following example shows how to define a SpecVariable parameter and how to use it in the test method. Some functions used in the run() function are defined in the file SpecSearchUtil.hpp. This example is intercepted from SpecSearch test in the AC test method library.

```
//for testmethod framework interfaces
#include "testmethod.hpp"
//for testmethod API interfaces
#include "mapi.hpp"

#include "SpecSearchUtil.hpp"
class SpecSearch: public testmethod::TestMethod
{
protected:
  testmethod::SpecVariable spec;
  ...

protected:
  /**
   *Initialize the parameter interface to the testflow.
   *This method is called just once after a testsuite is created.
   */
  virtual void initialize()
  {
    addParameter("spec",
                 "SpecVariable",
                 &spec)
    .setComment("this parameter's format like:\n"
                "LEV.1.fooSpec[mV]\n"
                "type is LEV, equationSetId is 1\n"
                "name is fooSpec, unit is mV");
    ...
  }

  /**
   *This test is invoked per site.
   */
  virtual void run()
  {
    static SpecSearchUtil::SpecSearchUtilParam param;

    SpecSearchUtil::SpecSearchUtilResult result;

    /*----------------------------
     * 1. prepare for test
     *----------------------------
     */
    ON_FIRST_INVOCATION_BEGIN();
      /*process all parameters needed in test*/
      SpecSearchUtil::processParameters(spec.mName,
                                        spec.mType,
                                        setupPinlist,
                                        spec.mUnit,
                                        method,
                                        min,
                                        max,
                                        step,
                                        resolution,
                                        resultPinlist,
                                        param);
    ON_FIRST_INVOCATION_END();
    ...

    return ;
  }
};

REGISTER_TESTMETHOD("AcTest.SpecSearch", SpecSearch);
```
