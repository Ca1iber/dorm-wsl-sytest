# TMU_TASK.uploadPeriodResults()

Upload the period result data of all the pins and shots into the result cache.

## Syntax

```
TMU_RESULTS& uploadPeriodResults(averaged = TRUE);
TMU_RESULTS& uploadPeriodResults(const char *ResultHandle, averaged = TRUE);
TMU_RESULTS& uploadPeriodResults(STRING &ResultHandle, averaged = TRUE);
```

Parameters
 |

Parameter

 |

Description

 |
 |

resultHandle

 |

The result handle to access.

 |
 |

averaged

 |

Whether to do the averaging for the result data.

 |

## Return value

A reference to the TMU_RESULTS object.
