# loadCap()

Sets the load capacitance in Farad (F).

The load capacitance of the DUT or on the DUT board has an effect on the dynamic behavior of a DPS channel. The function is used to adapt the dynamic behavior of the channel to the load capacitance.

 Some rules must be respected when changing the load capacitance. The rules are different for the supported DC Scale cards:

- DPS128 / DPS64:

  -

DPS128 allows for cap-less operation that is defined as working with some bypass capacitor network 鈮?nbsp;10 nF.

  - The cap-less mode is enabled if the load capacitance is set to 0.0 渭F by this API.
  - The cap-less mode is disabled and up to 470 渭F per channel are supported if the load capacitance is set to any value > 0.0 渭F[1)](<#_149349__d2708e1305>).
  - The reset value for the load capacitance is 1.0 渭F: The cap-less mode is disabled and a load capacitance of up to 470 渭F per channel is supported.
  - Default value if this API is omitted: The last programmed value is kept until it is (in disconnected state) explicitly programmed or the system is reset. This applies also if another setup is applied or the channel is disconnected and reconnected again.
  - The pin must be disconnected to set the load capacitance.
  - The function can be used only in the code鈥慴ased mode.
  - Function loadCap() can be used in combination with other functions that connect the channel.
  - The set load capacitance must be maintained in all following code鈥慴ased commands until the pin is disconnected. With cap-less mode already enabled by setting the load capacitance once to 0.0 渭F, you can omit this API for the following setups.
  - Pattern鈥慴ased commands do not change the connection state. Therefore, connection state changes are supported with the load capacitance set in the code鈥慴ased mode.

For further details, refer to [Load capacitance connected to the DC Scale DPS128/DPS64](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.03.02_Load_capacitance_connected_to_the_DC_Scale_DPS128_DPS64.md>).

- XPS256:

  - The programmed analog load capacitance value is used to adapt the dynamic behavior of a pin to the load capacitance.
  - The default value for the load capacitance is 0.0 渭F.
  - The load capacitance can be set with connected or disconnected pin.
  - The function can be used in code鈥慴ased mode and in pattern鈥慴ased mode.
  - Function loadCap() can be used in combination with all other functions.

## Syntax

The value of the load capacitor(s) in F (Farad).

 Card-specific default value and range:

- DPS128 / 64:

  - Range:

    - 0.0 渭F: Enables the cap-less mode
    - > 0.0 渭F: Enables the standard mode that supports a load capacitance of up to 470 渭F per channel[1)](<#_149349__d2708e1305>).

  - Default value after reset: 1.0 渭F - standard mode with load capacitance.
  - Default value if not programmed: The last programmed value or the reset value of 1 渭F

- XPS256: Refer to section [Dynamic behavior](<../02.05_Test_Head_Cards/02.05.05.03.10.09_XPS256_programming_-_Force_and_clamp_voltages.md#_354305__s_Dynamic_behavior>) in [XPS256 programming - Force and clamp voltages](<../02.05_Test_Head_Cards/02.05.05.03.10.09_XPS256_programming_-_Force_and_clamp_voltages.md>).

## Return Value
