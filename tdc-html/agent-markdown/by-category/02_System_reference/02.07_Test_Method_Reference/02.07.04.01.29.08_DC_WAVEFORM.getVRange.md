# DC_WAVEFORM.getVRange()

This function returns the input voltage range of the DC waveform.

## Syntax

```
void getVRange(DOUBLE & vRange) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

vRange

 |

The parameter returns the value of input voltage range specified by the [DC_WAVEFORM.vRange()](<02.07.04.01.29.07_DC_WAVEFORM.vRange.md>) function.

 |

Return value

There is no return value.
