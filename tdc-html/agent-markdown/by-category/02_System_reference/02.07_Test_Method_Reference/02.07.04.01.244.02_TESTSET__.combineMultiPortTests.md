# TESTSET().combineMultiPortTests()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) lets you specify one summary [FTR record](<../02.10_Data_Logging/02.10.03.05.24_Functional_Test_Record__FTR.md>) in multiport testing instead of individual FTR records for each port.

This function is not supported within the SMC_backgroundProcessing() test method when flag [hidden_datalog_mode](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_hidden_datalog_mode>) is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

## Syntax

```
TESTSET & combineMultiPortTests(bool combine);
```

 |

Parameter

 |

Description

 |
 |

combine

 |

Whether to combine the result FTR records into one for multiport tests:

- true: One combined FTR record is created.
- false: A separate FTR record is created for each port.

The default setting is false.

 |
