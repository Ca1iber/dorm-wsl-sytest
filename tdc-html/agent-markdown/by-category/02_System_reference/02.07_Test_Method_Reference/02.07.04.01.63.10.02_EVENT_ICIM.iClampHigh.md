# EVENT_ICIM.iClampHigh()

Sets the high clamp current value.

You can specify both the low and the high clamp current values or just one.

## Syntax

```
EVENT_ICIM & iClampHigh ( const EVENT_VALUE_DOUBLE & value );
```

Parameter
 | Parameter  | Description |
 | value |

High clamp current

 |

Return value

There is no return value.
