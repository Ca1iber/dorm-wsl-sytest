# SPMU_TASK.pin()

Returns the reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) class object that represents the measurement conditions for the specified pin(s).

## Syntax

```
SPMU_PIN_TASK& SPMU_TASK::pin(const STRING& pinlist);
```

 Parameter

 |

Parameter

 |

Description/Range

 |
 |

pinlist

 |

Target pin name for digital pin for which the user wants to define measurement conditions.

Users can specify multiple pins by separating pin entries with a comma.

   |  Return value A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.

## Example

In this example, the pin I/O0 is used as DC source to provide 10 uA current for the connected DUT pin.

```
SPMU_TASK spmuTask;

ON_FIRST_INVOCATION_BEGIN();

    CONNECT();

    //
    // Setup
    //
    spmuTask.pin("I/O0").iForce(10 uA).clamp(3.5 V).min(1.5 V).max(3 V).relay("NTMBB");

    //
    // Force 10uA
    //
    spmuTask.execMode(TM::FORCE_ON).execute();

ON_FIRST_INVOCATION_END();
```
