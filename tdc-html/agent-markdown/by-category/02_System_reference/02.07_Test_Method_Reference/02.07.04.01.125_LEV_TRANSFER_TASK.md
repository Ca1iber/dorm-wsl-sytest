# LEV_TRANSFER_TASK

#### Subtopics

- [LEV_TRANSFER_PIN_TASK](<02.07.04.01.125.01_LEV_TRANSFER_PIN_TASK.md>)

The LEV_TRANSFER_TASK class is a data container that holds the contents of the task for setting levels per site.

This class is used to call the [LEV_TRANSFER_PIN_TASK](<02.07.04.01.125.01_LEV_TRANSFER_PIN_TASK.md>) class, which is a subsidiary data container, to set the level specs per site very efficiently by using the [Fast Transfer Buffer](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.01.02_Technology_file_for_a_device.md#_49363__row_fast_transfer_buffer_size>).

Objects of the class LEV_TRANSFER_TASK can be added to a [TASK_LIST](<02.07.04.01.240_TASK_LIST.md>) container.

## Constructor

```
LEV_TRANSFER_TASK();
```

This constructor creates an object of the LEV_TRANSFER_TASK class, which allows the user to modify level specs for different pins and sites. The LEV_TRANSFER_TASK API can be used in protected mode.

## Member functions

 pin()

```
LEV_TRANSFER_PIN_TASK &pin(const STRING &pinlist);
```

Defines the list of pins for which the level data transfer shall happen.

  set()

```
LEV_TRANSFER_TASK &set(const STRING &set);
```

Selects the level spec set or primary set (PRM) for which the level data will be modified.

```
LEV_TRANSFER_TASK &set(const LEVEL_SPEC &sp);
```

Specifies the level spec set for which the data will be modified.

  specName()

```
LEV_TRANSFER_TASK &specName(const STRING &name);
```

Specifies the spec name for which the value will be modified.

  execute

```
void execute();
```

Updates the level set with the specified data, but does not activate the setting.

Parameters
 | Parameter  | Description |
 | pinlist  | The list of pins for which the level spec will be set. Can be a digital or DPS pin. |
 | set  | The name of the level spec set or "PRM" (primary set). |
 | sp  | The name of the level equation and spec set to apply. |
 | name  | The level spec name to apply. |

Return value

There is no return value for member function execute().

The member function pin() returns a reference to the LEV_TRANSFER_PIN_TASK object.

Other member functions return a reference to the LEV_TRANSFER_TASK object.

## Example

This example shows how to set the level per site.

```
virtual void run()
{
    ON_FIRST_INVOCATION_BEGIN();

        LEV_TRANSFER_TASK levTransferTask;

        // this uses set method with the 'sp' parameter
        // levelTransferTask.set(LEVEL_SPEC (1,1).specName(specName));

        // this uses set method with the primary set parameter 'PRM'
        levTransferTask.set("PRM").specName(specName);

        static double offset = 0.2;

        FOR_EACH_SITE_BEGIN();

            levTransferTask.pin(mPinName).specVal((offset + specVal)/CURRENT_SITE_NUMBER());

        FOR_EACH_SITE_END();

        levTransferTask.execute();

        FLUSH(TM::APRM,false);

    ON_FIRST_INVOCATION_END();

    return;
}
```
