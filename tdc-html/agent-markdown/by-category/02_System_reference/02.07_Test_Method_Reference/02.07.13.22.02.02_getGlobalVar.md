# getGlobalVar()

This function reads the value of a SmartRDI variable into a specified program variable.

## Syntax

```
bool rdi.getGlobalVar(variable_name,value);
```

Parameters
 |

Parameter

 |

Description

 |
 |

variable_name

 |

The name of the variable to which you want to assign the value. A string.

 |
 |

value

 |

The value to assign to the variable. The value must have one of these data types:

- int
- double
- ARRAY_I
- ARRAY_D
- vector<ARRAY_I>
- vector<ARRAY_D>
 |

## Return Value

This function returns true if the specified SmartRDI variable exists. Otherwise, it returns false.

## Example

```
if (rdi.getGlobalVar("abc",b))  cout<<b<<end;
```
