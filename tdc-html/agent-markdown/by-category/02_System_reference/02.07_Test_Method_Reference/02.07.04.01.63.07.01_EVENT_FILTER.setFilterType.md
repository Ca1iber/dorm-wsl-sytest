# EVENT_FILTER.setFilterType()

Selects the type of the filter to be changed.

The filter value itself is to be set by [EVENT_FILTER.setFilterValue()](<02.07.04.01.63.07.03_EVENT_FILTER.setFilterValue.md>).

## Syntax

```
EVENT_FILTER & setFilterType(const TM::FILTER_TYPE filterType);
```

  Parameter

 | Parameter  | Description |
 | filterType  | Selects the filter to be changed.

The type of the parameter is TM::FILTER_TYPE.

 |

Available options of parameter: filterType
 | Option  | Description |
 | TM::LOAD_CAP  | Selects the load capacitance. The filter value is to be defined in Farad [F]. |
 | TM::CURRENT_SLEW  | Defines the current slew rate in Ampere per microsecond (A / µsec). |
 | TM::VOLTAGE_SLEW  | Defines the voltage slew rate in Volts per microsecond (V / µsec). |
 | TM::CURRENT_BANDWIDTH  | Sets the current bandwidth to the given frequency in Hertz (Hz). |
 | TM::VOLTAGE_BANDWIDTH  | Sets the voltage bandwidth to the given frequency in Hertz (Hz). |
 | TM::MEASURE_FILTER  | Sets the low‑pass filter for measurements to the given frequency in Hertz (Hz).

For the settling time of the filter, refer to application note [Measure filter settling time](<02.07.04.01.63.07.01_EVENT_FILTER.setFilterType.md#_152195__dle_Measure_filter_settling_time>) below.

  |   Return value A reference to the corresponding [EVENT_FILTER](<02.07.04.01.63.07_EVENT_FILTER.md>) object.

## Application note

  Measure filter settling time The programmable digital low-pass measure filters for all ADCs behave like simple RC filters. A short settling time is to be applied or some samples are to be ignored to settle to an acceptable difference to the input signal.The required settling time of the filter or the number of samples to be ignored depends on the accepted maximum relative error and the filter settings. The supported DC Scale cards show a slightly different behavior:

- XPS256: Refer to the related application notes in topics [Measure voltages](<../02.05_Test_Head_Cards/02.05.05.03.10.14_XPS256_programming_-_Measure_voltages.md#_354459__dle_Measure_filter_settling_time>) or in [Measure currents](<../02.05_Test_Head_Cards/02.05.05.03.10.13_XPS256_programming_-_Measure_currents.md#_354458__dle_Measure_filter_settling_time>) of the XPS256 programming overview.
