# EVENT_VCVM.getLimitLow()

Reads the lower limit that has been defined by [EVENT_VCVM.limits()](<02.07.04.01.63.22.09_EVENT_VCVM.limits.md>) or [EVENT_VCVM.limitLow()](<02.07.04.01.63.22.10_EVENT_VCVM.limitLow.md>).

The value is read from the corresponding [EVENT_VCVM](<02.07.04.01.63.22_EVENT_VCVM.md>) object and returned as an [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
bool getLimitLow (EVENT_VALUE_DOUBLE & low) const;
```

Parameter
 | Parameter  | Description |
 | lowLimit |

The programmed lower limit in V (Volt).

 |

## Return value

bool value indicating the state of the limit definition:

- true: Limit has been defined by [EVENT_VCVM.limits()](<02.07.04.01.63.22.09_EVENT_VCVM.limits.md>) or [EVENT_VCVM.limitLow()](<02.07.04.01.63.22.10_EVENT_VCVM.limitLow.md>).
- false: No limit is defined or the limit has been cleared by [EVENT_VCVM.clearLimits()](<02.07.04.01.63.22.12_EVENT_VCVM.clearLimits.md>).

For an example see [EVENT_VCVM](<02.07.04.01.63.22_EVENT_VCVM.md>).
