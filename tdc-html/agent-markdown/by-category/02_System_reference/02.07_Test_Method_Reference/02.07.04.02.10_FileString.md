# FileString

This parameter type is defined to enter the file names as the value of a test method parameter.

The valid value for the variables of the FileString type can be one file name or mutiple file names separated by comma. The file name can be a pure file name or the absolute path of the file. You can also use the (), [], {} containing numbers, letters, "-" and "|" to represent multiple files with similar names. For example, the file "abcde1, abcde2, abcde3" can be entered as "abcde(1-3)" and the file name "abcde, abcdf" can be entered as "abcd(e|f)". The numbers and letters in the (), [] and {} are expanded in the order of (), [] and {} when you retrieve the file names.

To set and retrieve the values for the variables of this type, the following functions are provided.

## Member functions

### getFileNames()

```
std::vector<std::string> getFileNames();
```

Retrieve the file names of the variable in the FileString type.

### getFileNamesWithPath()

```
std::vector<std::string> getFileNamesWithPath();
```

Retrieves the file names of the variable in the FileString type with their absolute paths.

### getFileNameWithRelativePath()

```
std::vector<std::string> getFileNamesWithRelativePath();
```

Retrieves the file names of the variable in the FileString type with their relative path to the current device.

### getFileNamesWithPathNoExp()

```
std::vector<std::string> getFileNamesWithPathNoExp();
```

Retrieves the file names of the variable in the FileString type without expanding the numbers and letters in (), [] and {}.

### setFileString()

```
void setFileString(const std::string &value);
```

Sets the value for the variable of the FileString type. It can be one file name or multiple file names separated by comma. The file name can be a pure file name or the absolute path of a file.

### operator=

```
FileString& operator=(const FileString &obj);
```

Copies a FilesString object to another object.

## Example

In this example, mFile1 is a variable of the FileString type. The file names containing in mFile1 are retrieved.

```
STRING_VECTOR fileNames, fileNamesWithPath, fileNamesWithRelativePath;
fileNames=mFile1.getFileNames();
fileNamesWithPath=mFile1.getFileNamesWithPath();
fileNamesWithRelativePath=mFile1.getFileNamesWithRelativePath();
for (INT index = 0; index < fileNames.size(); index++)
{
  cout << "--------The " <<index+1 << " file-----------"<< endl;
  cout << fileNames [index] << endl;
  cout << fileNamesWithPath [index] << endl;
  cout << fileNamesWithRelativePath [index] << endl;
}
```
