# Printing tester status

#### Subtopics

- [Printing tester status from system control](<02.07.03.21.01_Printing_tester_status_from_system_control.md>)
- [Printing tester status from testflow](<02.07.03.21.02_Printing_tester_status_from_testflow.md>)
- [Printing tester status from test method](<02.07.03.21.03_Printing_tester_status_from_test_method.md>)

There are several ways to print tester status for debug purpose. You can choose to print tester status to system console or text files, at default or customized settings.

## Before you begin

Check that your SmarTest has a version no less than 7.5.2.

## Procedure

Choose one from the following ways to read and print tester status (the current settings of all instruments).

- Use the Print Tester Status button in the System Console toolbar. See [Printing tester status from system control](<02.07.03.21.01_Printing_tester_status_from_system_control.md>).
- Automatically print tester status to files when test suite execution completes. See [Printing tester status from testflow](<02.07.03.21.02_Printing_tester_status_from_testflow.md>).
- Customize tester status outputs through test method. See [Printing tester status from test method](<02.07.03.21.03_Printing_tester_status_from_test_method.md>).

## Functional changes

- Introduced in SmarTest
- SmarTest 7.5.3: A new user flag "enableAccumulatedStateLogging" and a new button "Diff Tester Status" in the system console toolbar.
- SmarTest 7.6.0: New instrument "UTILITY" is supported.
