# DVM_PIN_TASK

The DVM_PIN_TASK class is a data container holding the object reflecting the setup data for high-accuracy direct voltage measurements (DVM) using a digital multimeter (DMM).

You access this class object via the pin() member function of the [DVM_TASK](<02.07.04.01.55_DVM_TASK.md>) class. You cannot directly construct any objects of this class.

The DVM_PIN_TASK API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/DvmPinTask.h.

## Syntax

This class has no constructor.

DVM_PIN_TASK objects are created using the pin() member function of [DVM_TASK](<02.07.04.01.55_DVM_TASK.md>).

List of parameters

There are no parameters.

Return value

There is no return value.

## Example

The example specifies a pin for a direct voltage measurement (`measDVM`) using a digital multimeter (DMM). If required, the calibration (doAcal) is executed automatically.

```
DVM_TASK   measDVM;
FLEX_RELAY connectDVM, disconnectDVM;
TASK_LIST  taskList;

ON_FIRST_INVOCATION_BEGIN();

    connectDVM.pin   ("Utility_Pogo_1").set("X","EXT");
    disconnectDVM.pin("Utility_Pogo_1").set("X","OFF");

    measDVM.pin("Utility_Pogo_1")
           .doAcal(TM::DO_ACAL_IF_NECESSARY);

    taskList.add(connectDVM)
            .add(measDVM)
            .add(disconnectDVM)
            .execute();

ON_FIRST_INVOCATION_END();

ARRAY_D result = measDVM.getValues("Utility_Pogo_1");

for ( int i = 0; i < result.size(); ++i )
{
    cout << "Measured Value: " << result[i] << endl;
}
```
