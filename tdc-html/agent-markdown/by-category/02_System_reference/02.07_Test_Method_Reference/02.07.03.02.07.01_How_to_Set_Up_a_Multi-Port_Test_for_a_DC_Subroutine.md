# How to Set Up a Multi-Port Test for a DC Subroutine

In order to create and execute a multi-port burst that executes a PPMU test for one port, you must perform the following steps:

- Define the main patterns for the multi-port burst.
- Define a subpattern and insert a call of this subpattern into the main pattern of that port on which the DC test is to be executed.Note It is essential that the DC pattern is a subpattern. If you specify a main pattern as the DC pattern, SmarTest will issue an error message. Note Do not insert any sequencer instruction or vectors into the subpattern. This will be done by the PATTERN_CONTROLLER API.
- Define a multi-port burst with the main patterns for the individual ports.
- Create a test method that

  - uses the PPMU_XXX API's to define a PPMU test for one or more pins of the port on which the PPMU test is to run
  - uses the PATTERN_CONTROLLER and PATTERN API's to specify a subpattern which will execute the previously defined PPMU test.

The PATTERN_CONTROLLER API takes the place of the TASK_LIST API which is used in standard applications of the PPMU_XXX API's.

- Define a test method based testsuite which specifies the newly created test method in the Testmethod field, and the multi-port burst in the Vector Label field (which will make it the primary (start) label for the testsuite).
