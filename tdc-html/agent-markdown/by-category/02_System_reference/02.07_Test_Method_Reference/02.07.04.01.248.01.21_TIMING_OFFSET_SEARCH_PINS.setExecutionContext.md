# TIMING_OFFSET_SEARCH_PINS.setExecutionContext()

Refers to an execution context that has been defined with the [SEQUENCER_CONTEXT](<02.07.04.01.201_SEQUENCER_CONTEXT.md>) API or the [SQEC](<../02.06_Command_Reference/02.06.02.02.231_SQEC__SQEC__-__SeQuencer_Execution_Context.md>) firmware command, so that you can apply the timing offset search on the ports that the execution context refers to.

## Syntax

```
void setExecutionContext(const STRING& context);
```

Parameter
 |

Parameter

 |

Description

 |
 |

context

 |

An execution context you have already defined with the [SEQUENCER_CONTEXT](<02.07.04.01.201_SEQUENCER_CONTEXT.md>) API or the [SQEC](<../02.06_Command_Reference/02.06.02.02.231_SQEC__SQEC__-__SeQuencer_Execution_Context.md>) firmware command.

 |

Return value

There is no return value.
