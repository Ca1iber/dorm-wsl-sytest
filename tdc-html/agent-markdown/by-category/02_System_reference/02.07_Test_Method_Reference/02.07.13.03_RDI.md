# RDI

SmartRDI (Rapid Development Interface) provides a high level of programming interface to create your test method program. Use the [classes](<02.07.13_SmartRDI.md#_142069__s_SRDI_classes>) listed below to setup your tests.

## SmartRDI classes

SmartRDI provides classes to set up different types of tests, including dc, digital capture, functional test, protocol, mixed signal, RF, utility control, timing and level. For each class, functions are provided to set up the test and retrieve the test result. You can refer to the [Code structure with SmartRDI](<02.07.13.05_Code_structure_with_SmartRDI.md>) for the general programming with SmartRDI. The following classes are supported:

- `cogo()` class: [SmartRDI: Pattern-based conditional jump - cogo](<02.07.13.19_SmartRDI__Pattern-based_conditional_jump_-_cogo.md>)
- `dc()` class: [SmartRDI: DC test setup](<02.07.13.12_SmartRDI__DC_test_setup.md>) and [Using a DC resources as an AWG/DGT with SmartRDI](<02.07.13.11_SmartRDI__DC_resource_AWG_DGT_usage.md>)
- `digCap()` class: [SmartRDI: Digital capture test setup](<02.07.13.13_SmartRDI__Digital_capture_test_setup.md>)
- `emap()` class: [Getting error map information from user pattern](<02.07.13.16_SmartRDI__Error_map_results_from_user_patterns.md>)
- `func()` class: [Functional test setup](<02.07.13.17_Functional_test_setup.md>)
- `hiddenUpload()` class: [Using hidden upload with SmartRDI](<02.07.13.08.19.01_Using_hidden_upload_with_SmartRDI.md>)
- `hwRelay()` class: [SmartRDI: Digital channel relay control](<02.07.13.14_SmartRDI__Digital_channel_relay_control.md>)
- `level()/timing()` class: [SmartRDI: Level and timing set changes](<02.07.13.18_SmartRDI__Level_and_timing_set_changes.md>)
- `protocol()` class: [Setting up protocol tests with SmartRDI](<02.07.13.10_SmartRDI__d2s-like_protocol_test_setup.md>)
- `route()` class: [rdi.route()](<02.07.13.15.05_rdi.route.md>)
- `smartVec()` class: [Generating vector with SmartRDI](<02.07.13.24_SmartRDI__Vector_and_protocol_programming.md>)
- `tmu()` class: [SmartRDI: TMU test setup](<02.07.13.21_SmartRDI__TMU_test_setup.md>)
- `util()` class: [Controlling the utility lines with SmartRDI](<02.07.13.23_SmartRDI__Utility_lines_control.md>)
- `alarm()` class: [SmartRDI: Alarm handling for DCVI](<02.07.13.09_SmartRDI__Alarm_handling_for_DCVI.md>).
