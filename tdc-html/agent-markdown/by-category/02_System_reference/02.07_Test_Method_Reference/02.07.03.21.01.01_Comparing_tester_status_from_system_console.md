# Comparing tester status from system console

## About this task

The Diff Tester Status button lets you compare hardware changes between the last two saved tester status.

## Before you begin

Check that your SmarTest has a version no less than 7.5.3.

Make sure that your device works properly.

## Procedure

-  In the Test Program Explorer panel, right-click Test Program and load your test program.
-  Right-click Testflow and select Load All Setups.
-  In [System console](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.08.05.01_Console_view__System_console.md>), click the ![Print Tester Status](<../../../../raw/346554.png>) Print Tester Status button from the toolbar.

The tester status before change are saved.

-  In the [Firmware view](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.08.08_Firmware_view.md>), make some changes to hardware properties by sending firmware commands.
-  In [System console](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.08.05.01_Console_view__System_console.md>), click the ![Print Tester Status](<../../../../raw/346554.png>) Print Tester Status button from the toolbar.

The tester status after change are saved.

-  In [System console](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.08.05.01_Console_view__System_console.md>), click the ![Diff Tester Status](<../../../../raw/349941.png>) Diff Tester Status button from the toolbar.

## Results

A delta report of the tester status change is printed with details to the system console.

## Example

Below is a sample output in System console. Tester status changes between the last two saved tester status are saved to a log file in the waste folder under your device root.

```

-------------------------------------------------------------------------------------------------------------------------
HW logging data was saved to file /<current_device_home>/waste/PreAndPostHWStateButton/currentHWState_20191010_140025.log
```
