# SmartRDI 7.6.0

This section summarizes software changes including new features and enhancements in SmartRDI 7.6.0.

Changes and new features
 | Category  | Description |
 | [Register Access library](<02.07.13.08.12_Register_Access_library.md>)  | The Register Access library can be used in test methods to perform register operations. |
 | [Alarm handling](<02.07.13.09_SmartRDI__Alarm_handling_for_DCVI.md>)  | Alarm check per result ID. See [rdi.alarm().check().execute()](<02.07.13.09.02.02_rdi.alarm__.check__.execute.md>). |
 | AWG  | addWaveform() adds multiple waveforms to an analog set. |
 | [Cogo](<02.07.13.19.02_Sequencer-controlled_searching_with_cogo.md>)  | Before 7.6.0, each search step in a linear search is a subroutine.

SmartRDI 7.6.0 supports the entire linear search with only one subroutine in pattern.

 |
 | [DC](<02.07.13.12.02_Setting_up_DC_Scale_pins_with_SmartRDI.md>)  | [vMeasForceDrop()](<02.07.13.12.02.44_vMeasForceDrop.md>) and [vMeasReturnDrop()](<02.07.13.12.02.46_vMeasReturnDrop.md>) support HC channels of [DC Scale DPS128 cards](<../02.05_Test_Head_Cards/02.05.05.01_DC_Scale_DPS128_DPS64_cards.md>). |
 | [EMAP](<02.07.13.16_SmartRDI__Error_map_results_from_user_patterns.md>)  | [rdi.func().startVec()](<02.07.13.16.10_rdi.func__.startVec.md>) and [rdi.func().stopVec()](<02.07.13.16.11_rdi.func__.stopVec.md>) are enhanced to be used by the emap() class for splitting a pattern to create a new partial pattern and get the EMPA result. |
 | [Relays](<02.07.13.14_SmartRDI__Digital_channel_relay_control.md>)  | The "NO" value can be used for opening a type of relay on one site and closing the same type of relay on another in runtime. See [runTimeVal()](<02.07.13.08.03.01_runTimeVal.md>). |
 | [smartVec](<02.07.13.24_SmartRDI__Vector_and_protocol_programming.md>)  | New flag [SMV_IGNORE_COMMENT](<02.07.13.04_RDI_Configure_file.md#_146692__row_SMV_IGNORE_COMMENT>) in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>) to skip comments generated in pattern. |
 | [TMU](<02.07.13.21_SmartRDI__TMU_test_setup.md>)  | [rdi.id().getTmuErrorState()](<02.07.13.21.21_rdi.id__.getTmuErrorState.md>) for retrieving the error state of specified pins and sites. |
 | [Utility line control](<02.07.13.23_SmartRDI__Utility_lines_control.md>)  | Wait time can be added to pins in Pin Configuration for [sequencer‑controlled utility lines](<02.07.13.23.04_Sequencer_Controlled_Utility_Mask_with_SmartRDI.md>). |

## Supported SmarTest versions

SmartRDI 7.6.0 supports SmarTest 7.6.0.
