# DPS_Force()

This API is used to set up a label to hold the voltage force or current clamp function from DCScale.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTMultiportSync.hpp.

## Syntax

```
void DPS_Force(const String& _pinName, DOUBLE _voltage, DOUBLE _iClamp = 1.0 A);
```

Parameters
 |

pinName(string)

 |

Specifies the pin name.

 |
 |

_voltage(double)

 |

Specifies the voltage value.

 |
 |

_iClamp(double)

 |

Specfies the current of the clamp.

 |

## Example

```
DCDynamicPort::getInstance().DPS_MeasVoltageRange(mDpsPins, 3.0);
DCDynamicPort::getInstance().DPS_Force("DPS128_2",vin, 50 mA);
DCDynamicPort::getInstance().DPS_MeasVoltage(mDpsPins,2);
```
