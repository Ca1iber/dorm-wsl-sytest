# TMU_TASK.getStatus()

Returns the status of the last execution. It can be SUCCESS, FAILED, ABORTED or NOT_EXECUTED.

## Syntax

```
TMU::STATUS_TYPE getStatus();
```

List of parameters

There are no parameters.

## Return value

The status of last execution is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
