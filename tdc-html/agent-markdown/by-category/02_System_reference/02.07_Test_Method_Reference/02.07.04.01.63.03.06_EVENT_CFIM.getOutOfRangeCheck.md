# EVENT_CFIM.getOutOfRangeCheck()

Reads the state of the out-of-range check that has been defined by [EVENT_CFIM.outOfRangeCheck()](<02.07.04.01.63.03.05_EVENT_CFIM.outOfRangeCheck.md>).

The state is read from the corresponding [EVENT_CFIM](<02.07.04.01.63.03_EVENT_CFIM.md>) object and returned as a bool value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getOutOfRangeCheck(bool & failOnOutOfRange) const;
```

Parameter
 | Parameter  | Description |
 | failOnOutOfRange |

The programmed value true or false of the out-of-range check.

- true: The out-of-range check is enabled
- false: The out-of-range check is disabled
 |

Return value

There is no return value.
