# DIGITAL_OFFSET_SEARCH_TASK.execute()

Executes the timing or level offset search for the pins specified with [DIGITAL_OFFSET_SEARCH_TASK.pin()](<02.07.04.01.36.03_DIGITAL_OFFSET_SEARCH_TASK.pin.md>).

## Syntax

```
void execute();
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Related information

[DIGITAL_OFFSET_SEARCH_TASK.pin()](<02.07.04.01.36.03_DIGITAL_OFFSET_SEARCH_TASK.pin.md>)

## Functional changes

- Introduced in SmarTest 7.2.1
