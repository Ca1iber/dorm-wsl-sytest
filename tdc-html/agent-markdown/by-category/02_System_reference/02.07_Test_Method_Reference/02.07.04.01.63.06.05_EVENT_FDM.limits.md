# EVENT_FDM.limits()

Sets limits to compare against thresholds.

## Syntax

```
EVENT_FDM & limits(const LIMIT & limits);
```

  Parameter

 | Parameter  | Description |
 | limits |

A [LIMIT](<02.07.04.01.126_LIMIT.md>) object that already has been filled with the values for the lower and upper limits.

The limits define the pass range in Volts (V).

 The polarity of the measured force drop and return drop measurement corresponds to the polarity of the current:

- Sourcing current from the PMU channel to the DUT will result in positive force drop and return drop voltage.
- Sinking current from the DUT into the PMU channel will result in negative force drop and return drop voltage.
The limits for the force drop and return drop measurements are to be set accordingly.  |  Return value A reference to the corresponding [EVENT_FDM](<02.07.04.01.63.06_EVENT_FDM.md>) object.
