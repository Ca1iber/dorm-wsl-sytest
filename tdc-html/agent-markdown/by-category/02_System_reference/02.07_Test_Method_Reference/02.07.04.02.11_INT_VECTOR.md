# INT_VECTOR

Defines a vector containing integer elements. Vector is a standard C++ container. An INT_VECTOR variable can be processed with all the member functions of a vector.

With the member functions you can query the capacity, access the elements and modify the elements of the vectors. You can find all the member functions of the vector here http://www.cplusplus.com/reference/stl/vector/.

## Example

```
GraphManager * graphManager = GraphManager::getInstance();
ARRAY_D waveform = Analog.DGT("digitizer").getWaveform();
Graph graph;
Trace trace;
trace.setPinName("digitizer").setTestLabel("sample");
ARRAY_I histogram;
INT_VECTOR vec;
// Calculate the histogram of captured waveform
DSP_HISTOGRAM(waveform, histogram, -5.0, 5.0, 10);
for(int i=0;i<histogram.size();i++)
{
  vec[i]=histogram[i];
}
trace.setVector(vec);
graph.setTitle("Histogram");
graph.setTrace(trace,1);
graph.setGraphStyle(Display::PLOT_BAR);
graphManager->setGraph(graph, 1);
```
