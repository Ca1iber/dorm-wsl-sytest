# SPMU_TASK.setup()

Downloads measurement conditions defined by the member functions of [SPMU_TASK](<02.07.04.01.234_SPMU_TASK.md>) to the hardware.

Use this function only if the measurement setup changes per test flow run.

Do not use this function with standard cases where the measurement setup will not change per test flow run.

## Syntax

```
void setup();
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Example

The following example performs two measurements, spmuVMeas and spmuIMeasa. The spmuVMeas is setup and executed on all sites first. Then spmuIMeasa is defined and downloaded to the HW using `SPMU_TASK.setup()`. The per site value of the voltage measured is set as parameter of [SPMU_PIN_TASK.vForce()](<02.07.04.01.234.01.34_SPMU_PIN_TASK.vForce.md>) before the spmuIMeasa measurement is performed on all sites.

```
SPMU_TASK spmuVMeas, spmuIMeas;

ON_FIRST_INVOCATION_BEGIN();
   // Measure Voltage
   spmuVMeas.pin("dc_pin").iForce(1 mA).min(1 V).max(2 V).mode("IFVM").relay("NTMBB");
   spmuVMeas.execMode("PVAL").execute();

   // Define measurement placeholder
   spmuIMeas.pin("dc_pin").vForce(1 V).min(-1 mA).max(1 mA).mode("VFIM").relay("NTMBB");
   spmuIMeas.execMode(TM::FORCE_ON);
   // write measurement definition to HW
   spmuIMeas.setup();

   // setup force voltage per site
   FOR_EACH_SITE_BEGIN();
     spmuIMeas.pin("dc_pin").vForce(spmuVMeas.getValue("dc_pin"));
   FOR_EACH_SITE_END();

   // force voltage per site
   spmuIMeas.execute();

ON_FIRST_INVOCATION_END();
```
