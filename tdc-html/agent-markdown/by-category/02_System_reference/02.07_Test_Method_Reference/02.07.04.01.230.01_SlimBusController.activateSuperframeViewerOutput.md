# SlimBusController.activateSuperframeViewerOutput()

This function activates creation and maintenance of a Superframe Viewer file. The file name must be passed to the function. In a multi-site setup, a separate Superframe Viewer file is created for every site. These files are distinguished by a suffix consisting of an underscore and the site number. The Superframe Viewer files are stored in the report directory of the current device.

```
void activateSuperframeViewerOutput (const STRING &filename);
```

Parameter
 |

Parameter

 |

Description

 |
 |

filename

 |

Specifies the name of the Superframe Viewer file. In a multi-site setup, the files for the individual sites are distinguished by adding an underscore and the site number to this name.

 |

Return value

There is no return value.

## Functional changes

- Introduced in SmarTest 7.2.1
