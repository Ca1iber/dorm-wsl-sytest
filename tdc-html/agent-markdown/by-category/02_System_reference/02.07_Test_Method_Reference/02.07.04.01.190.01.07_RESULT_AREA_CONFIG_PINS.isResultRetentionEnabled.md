# RESULT_AREA_CONFIG_PINS.isResultRetentionEnabled()

This function queries whether the result retention is enabled or not.

Per default, once a user defined result area has been configured and selected for recording, the results are automatically made persistent after the test execution, allowing for a later upload of these results using hidden upload for example. In other words, result retention is per default enabled for all user defined result areas. In some cases though, result retention is not really needed, as the result area may have only been defined to allow for recording of less than 4096 DC value measurement results on a digital pin. In such a scenario result retention can be disabled to save around 100us of overhead using this member function and specifying ‘false鈥?as the parameter value.

## Syntax

```
bool isResultRetentionEnabled() const;
```

List of parameters

There are no parameters.

## Return value

bool: true or false.
