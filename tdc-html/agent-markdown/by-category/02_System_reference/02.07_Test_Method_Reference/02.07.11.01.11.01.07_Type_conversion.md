# Type conversion

Parameter and field symbols can be specified as integer values (in binary, decimal or hexadecimal format). In the course of conversion these must be mapped to state character sequences by interpretation of individual bits.

The conversion operation will simply map individual bits of an integer value to state characters. The following state characters are used for

- input parameters: 鈥?' or '1'
- expected fields: 鈥楲' or 'H'
- device output parameters: 鈥楻'

The most significant bit (MSB) will be read first.

Conversion from state character sequence to integer happens when an output parameter of a transaction is explicitly converted in test method code.

Some operators (comparison and logical) evaluate to boolean type. Their result may only be used with logical operators or with the conditional operator else an error will be generated.

State character sequences cannot be used where boolean parameters are expected. You need to explicitly compare two sequences to obtain a boolean value, for example, use the expression `sequence > "0"` for integer semantics or `sequence != ""` for non-empty string semantics.

Note Protocol constants can only be specified as state character sequences. Integer value representation is not supported.
