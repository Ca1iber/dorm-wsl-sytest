# getVectorBit()

Retrieves the captured data in an array of bits.

It is only available for the serial capture mode to get the bits from word. The bit captured early is MSB and the bit captured late is LSB.

## Syntax

```
ARRAY_I& getVectorBit(const string& pin);
```

Parameter List
 |

Parameter

 |

Description

 |
 |

pin

 |

The pin to retrieve.

 |

## Example

```
ARRAY_I arr;
arr=rdi.id("norm").getVectorBit("pinA");
```

## Functional changes

- Introduced in SmartRDI 2.1.0
