# EVENT_WAVEFORM_VC.getVClampHigh()

Queries the upper clamp voltage waveform that has been defined by [EVENT_WAVEFORM_VC.vClampHigh()](<02.07.04.01.63.34.03_EVENT_WAVEFORM_VC.vClampHigh.md>).

The waveform is read from the corresponding [EVENT_WAVEFORM_VC](<02.07.04.01.63.34_EVENT_WAVEFORM_VC.md>) object and returned as an [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>) object.

## Syntax

```
const ARRAY_D & getVClampHigh() const;
```

  List of parameters There are no parameters. Return value

An [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>) object containing the waveform samples that are defined in V (Volt).

For an example see [EVENT_WAVEFORM_VC](<02.07.04.01.63.34_EVENT_WAVEFORM_VC.md>).
