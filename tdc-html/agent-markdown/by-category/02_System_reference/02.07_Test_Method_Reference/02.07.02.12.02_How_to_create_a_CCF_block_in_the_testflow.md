# How to create a CCF block in the testflow

## About this task

You can create any number of concurrent test framework blocks in the testflow.

## Before you begin

A testflow is already created.

## Procedure

-  In the testflow, create test suites as usual. (See [Inserting a test suite in the testflow](<../02.08_Setup_and_Result_Tools/02.08.04.32.02.01.04_Inserting_a_test_suite_into_the_testflow.md>).) These test suites use concurrent test methods.
-  Use multi-bin for the all the test suites if needed. (See [Inserting a bin into the testflow](<../02.08_Setup_and_Result_Tools/02.08.04.32.02.01.05_Inserting_a_bin_into_the_testflow.md>).)
-  For the test suites running on the synchronous sequecner,

  - Choose Synchronized for the parameter CCF_ContextType
  - Enter the pins and ports to be run on the synchronous sequencer for the parameter CCF_FocusedPins. The value must be the same for all the test suites running on the synchronous sequencer.
  - Specify the values for the parameters you added.

-  For the test suites running on the independent sequencer,

  - Choose Independent for the parameter CCF_ContextType
  - Enter the pins and ports to be run on the independent sequencer for the parameter CCF_FocusedPins. The value must be the same for all the test suites running on the independent sequencer.
  - Specify the values for the parameters you added.Note Only ONE port can be run on independent sequencer.

-  If you want to end the block, create a test suite with the provided test method `ccf_tml.CCExecution` or `ccf_tml.CCExecutionMultiGroup`. Specify the value for parameter  CCF_LabelName and CCF_TimingSpecSetName.
-  (optional) Group the test suites for concurrent tests.
-  In the Variables tab of testflow data editor, create the variables CCF_Concurrent, CCF_DevelopMode and CCF_VerboseLevel. Assign values to the variables according to the desired execution mode.
