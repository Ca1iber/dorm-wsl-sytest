# TIMING_OFFSET_SEARCH_PINS.getExecutionContext()

Retrieves the context name that has been referenced with [setExecutionContext()](<02.07.04.01.248.01.21_TIMING_OFFSET_SEARCH_PINS.setExecutionContext.md>).

## Syntax

```
const STRING& getExecutionContext();
```

List of parameters

There are no parameters.

## Return value

Returns a context name, or an empty string if no execution context had been referenced.
