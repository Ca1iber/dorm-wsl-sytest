# getMatchPassFail()

This function returns true if a match is found on the specified pin.

## Syntax

```
bool getMatchPassFail(string pin);
```

## Example

```
bool pf = rdi.id("abc").getMatchPassFail("pinA");
```

## Functional changes

- Introduced in SmartRDI 2.4.0
