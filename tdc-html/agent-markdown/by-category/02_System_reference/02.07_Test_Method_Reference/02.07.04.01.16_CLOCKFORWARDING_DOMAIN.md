# CLOCKFORWARDING_DOMAIN

This `CLOCKFORWARDING_DOMAIN` contains the properties of the clock forwarding domain. It is a sub-class of `CLOCKFORWARDING_SET`. You cannot directly create an object with it.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ClockForwardingDomain.h.

## Class definition

### Member functions

```
CLOCKFORWARDING_DOMAIN& sink(const STRING& multiplePins);
CLOCKFORWARDING_DOMAIN& speed(INT speed);
```

## Member functions

### sink()

```
CLOCKFORWARDING_DOMAIN& sink(const string& multiplePins);
```

This function defines the sink pins for a clock forwarding domain.

Parameter
 |

mutiplePins

 |

The sink pins of a clock forwarding domain.

 |

### speed()

```
CLOCKFORWARDING_DOMAIN& speed(int speed);
```

This function defines the minimal tracking speed required for this clock forwarding domain.

Parameter
 |

speed

 |

The minimal tracking speed.

 |

## Example

```
CLOCKFORWARDING_SET mySet("ClockForwardingSet");
mySet.source("pin1").sink("pin2,pin3,pin4");
mySet.source("pin10").sink("pin11,pin12");
// display clockforwarding setting
cout << mySet;
mySet.setAsPrimary(); // set this set as primary
// execute first functional test
START_TEST();
WAIT_TEST_DONE();
TEST();
// remove this set from SW
mySet.remove();
```
