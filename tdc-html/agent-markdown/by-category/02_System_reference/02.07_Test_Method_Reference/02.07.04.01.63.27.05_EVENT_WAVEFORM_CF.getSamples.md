# EVENT_WAVEFORM_CF.getSamples()

Reads the number of waveform samples that have been defined by [EVENT_WAVEFORM_CF.cForce()](<02.07.04.01.63.27.01_EVENT_WAVEFORM_CF.cForce.md>).

The number of samples is read from the corresponding [EVENT_WAVEFORM_CF](<02.07.04.01.63.27_EVENT_WAVEFORM_CF.md>) object and returned as an integer value.

## Syntax

```
void getSamples(INT & samples) const;
```

  Parameter

 | Parameter  | Description |
 | samples |

The read number of samples.

  |  Return value There is no return value.

## Example

For an example see [EVENT_WAVEFORM_CF](<02.07.04.01.63.27_EVENT_WAVEFORM_CF.md>).
