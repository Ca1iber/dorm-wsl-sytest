# TMU_PINS.setNumSamples()

Sets the number of samples for each measurement.

## Syntax

```
TMU_PINS& setNumSamples(UINT64 num);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

num

 |

The number of samples.

 |

## Return value

A reference to the TMU_PINS object is returned.
