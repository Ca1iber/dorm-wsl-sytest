# TMU_PINS.setup()

Sets up the configuration for the measurement.

## Syntax

TMU_PINS.setup() iterates over the TMU_PINS objects and force them to write the setup information to the firmware set management, by executing the [TSCF](<../02.06_Command_Reference/02.06.02.02.270_TSCF__TSCF__-__TMU_Set_ConFiguration.md>) command.

```
void setup();
```

## List of parameters

There are no parameters associated with this class.

Return value

There is no return value.

## Functional changes

- Introduced in SmarTest 7.1.0
