The SlimBusController class serves to set up a SLIMbus test and to process its results. See also [Overview of the SLIMbus solution](<02.07.11.01.12_Overview_of_the_SLIMbus_solution.md>).

SLIMbus devices are tested within the protocol-aware framework by using a synchronized protocol test. This synchronized test must be explicitly defined in the test method, but its transactions are generated automatically by (an instance of) the SlimBusController class, usually from a sequence file. This SlimBusController instance also prepares the results of the test for further analysis.

The typical sequence of events is as follows (unless explicitly stated otherwise, all functions called are member functions of the SlimBusController class):

- Create a SlimBusController instance.
- Create the synchronized protocol test ( from the SYNCHRONIZED_TEST class).
- Load the sequence file with the loadFromSequenceFile() function (?? this function checks the correctness of the input sequence file ??).
- (Optional) Activate storing of the state character sequence (which will be created in step 5) for the Superframe Viewer (see [Using the Superframe Viewer](<../02.08_Setup_and_Result_Tools/02.08.04.29.02_Using_the_Superframe_Viewer.md>)) with the activateSuperframeViewerOutput() function.
- Convert the sequence file with the translate() function. This conversion comprises two substeps:

  - Translate the sequence file into parameter values of the PA communication frame (and write these values into the Superframe Viewer file if step 4 has been executed)
  - Create the transactions of the synchronized PA test with these values.

- Convert the test method code into a protocol pattern and integrate it into the multiport burst (flush() member function of the SYNCHRONIZED_TEST instance).
- Execute the test (for example, with the FUNCTIONAL_TEST API).
- Decode the pattern output with the decode() function of the SlimBusController instance. This is a prerequisite for any result processing. If step 4 was executed, the results will also be integrated into the Superframe Viewer file (see [Using the Superframe Viewer](<../02.08_Setup_and_Result_Tools/02.08.04.29.02_Using_the_Superframe_Viewer.md>)).
- Prepare the message results with the getMessageResults() function.
- Prepare the data channel results with the getDataChannelsWithResult() function.
