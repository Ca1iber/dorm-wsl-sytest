# setPinStatus()

Specifies the status for a specified pin in a generated pattern.

## Syntax

```
setPinStatus(const string& sPin, int iWfIndex);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

sPin

 |

The pin name.

 |
 |

iWfIndex

 |

The waveform index.

   |    Note The pin status setting is valid only for the current test suite. This means that even without calling [clearPinStatus()](<02.07.13.08.02.01_clearPinStatus.md>), the following test suite will use the [default pin status](<02.07.13.08.02_Changing_the_default_pin_status_with_SmartRDI.md>).

## Example

```
rdi.setPinStatus("pinA",3)
```

## Functional changes

- Introduced in SmartRDI 2.1.0
