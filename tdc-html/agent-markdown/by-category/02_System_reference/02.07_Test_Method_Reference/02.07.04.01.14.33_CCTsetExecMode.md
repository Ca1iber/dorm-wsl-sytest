# CCTsetExecMode

This function sets the execution mode of the concurrent test framework. Based on the specified mode, the concurrent test framework (CCF) decides how to execute the test.

This function is usually used in the `init()` function but not used in the other functions of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
void CCTsetExecMode(EXEC_MODE execMode)
```

Parameter
 |

execMode

 |

The CCF execution mode. One of the following options:

EXM_NONE

EXM_SYNC_DC

EXM_EXECUTE_TEST

EXM_FUNCTIONAL_TEST

EXM_DIGITAL_CAPTURE_TEST

EXM_EXECUTE_GROUP

EXM_SMC_FUNCTIONAL_TEST

EXM_START_TEST

Refer to the table above for more details.

 |
