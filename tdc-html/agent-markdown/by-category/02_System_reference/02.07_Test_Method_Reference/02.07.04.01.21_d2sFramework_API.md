The d2sFramework provides classes and member functions to generate multiport burst pattern and to execute register transactions. These member functions can be categorized in general and transaction port specific member functions.

General member functions provide d2s-framework handles, like the d2s_LABEL block.

Transaction port specific member function provide transaction port handles within a d2s_Label block. These methods will apply the necessary modifications to the labels as defined in [Configure the protocol](<02.07.09.04.03_Configure_the_protocol.md>).

Each protocol to be used in the test program has to be registered with the d2s-framework. This is done by the method `registerTransactionPort()`, that tells the d2s-framework which protocol port(s) will take part in the framework execution. This can be a single transaction port or up to 63 transaction ports. Each transaction port needs to be configured individually and will be represented as a single port-burst of the multiport burst.

## Syntax

```
d2sFramework frameworkhandle;
bool registerTransactionPort(TransactionPort &port);
```

## Example

This example highlights the necessary modifications to a test method template in bold. The d2s-framework and the protocol template file have been included. All d2s specific files have been copied to the ./d2s_files directory of the current UTM project.

```
#include "testmethod.hpp"

//for test method API interfaces
#include "mapi.hpp"

//for d2s specific interfaces
#include "d2s_files/d2sJTAG.h"        // This is the users protocol template file.
#include "d2s_files/d2sFramework.h"

using namespace std;

/**
 * Test method class.
 *
 * For each testsuite using this test method, one object of this
 * class is created.
 */
class d2sExample: public testmethod::TestMethod {

protected:
  /**
   *Initialize the parameter interface to the testflow.
   *This method is called just once after a testsuite is created.
   */
  virtual void initialize()
  {
    //Add your initialization code here
    //Note: Test Method API should not be used in this method!
  }

  /**
   *This test is invoked per site.
   */
  virtual void run()
  {
    //Add your test code here.
    ...
    //Add the initial d2s framework specific code to your test method.
    //Each protocol needs to be registered with the d2s-framework.
    d2sFramework fr;
    d2sJTAG& jtag = ds2JTAG::Instance();
    fr.registerTransactionPort(jtag);

   ...   // more d2s specific code will be added here.

    return;
  }

  /**
   *This function will be invoked once the specified parameter's value is changed.
   *@param parameterIdentifier
   */
  virtual void postParameterChange(const string& parameterIdentifier)
  {
    //Add your code
    //Note: Test Method API should not be used in this method!
    return;
  }

  /**
   *This function will be invoked once the Select Test Method Dialog is opened.
   */
  virtual const string getComment() const
  {
    string comment = " please add your comment for this method.";
    return comment;
  }
};
REGISTER_TESTMETHOD("d2sExample", d2sExample);
```
