# Editing test method from a testflow

A shortcut menu Open Test Method is provided to open and edit the test method from a testflow.

## About this task

The shortcut menu Open Test Method

## Before you begin

Make sure you are using SmarTest 6.5.3 or later versions.

## Procedure

-  In the flow data editor, right-click the test method you want to modify and select Open Test Method.  ![Open Test Method](<../../../../raw/119587.png>)
-  Modify the test method and then build the project.

  - If no error occurs, the test method source file is opened. You can modify the test method and build the project.
  - If some error occurs, an error message or a warning message will be popped up. You need to fix the error or warning first and open the test method again to modify the build the test method. The following messages may be popped up due to different conditions.

If you want to modify a system test method which is not imported, you will see the message below:

  ![Test Method Project is not accessible (system TML)](<../../../../raw/119588.png>)

If you want to modify one of your test method projects that are not imported, you will see the message below:

  ![Test Method Project is not accessible](<../../../../raw/119589.png>)

If the test method library cannot be found, the following message will be popped up.

  ![Test Method does not exist](<../../../../raw/119590.png>)

If the test method you want to modify is imported but not referenced by the device, the source code will be opened with the following warning message popped up.

  ![Missing project reference](<../../../../raw/119591.png>)

If the location of the test method file you want to modify does not match with the location of the test method project imported, the following warning message will be popped up.

  ![Test Method library path mismatch](<../../../../raw/119592.png>)

## Functional changes

- Introduced in SmarTest 6.5.3
