# SMC_TEST_TEXT()

Adds text to the previously called [SMC_TEST()](<02.07.04.01.231.45_SMC_TEST.md>) to be added to the data log stream`.`

The way the text is handled depends on the setting of the disableTestTxtOverride configuration within the STDF configuration file.

- If it is false (the default), the text you specify is the entire content of the TEST_TXT field.
- If it is true, the specified text is appended at the end of the field as a comment.Note [SMC_TEST()](<02.07.04.01.231.45_SMC_TEST.md>) has to be called before `SMC_TEST_TEXT()` for logging the test text to the data log stream.
Note This API cannot be used with [Hidden data logging](<02.07.10.04.09_Hidden_data_logging.md>).

Use the [TESTSET.testtext()](<02.07.04.01.244.30_TESTSET__.testtext.md>) function instead, if you need this functionality with hidden data logging.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```
void SMC_TEST_TEXT(const STRING& text);
```

Parameter
 |

Parameter

 |

Description

 |
 |

text

 |

String of text stored in the EDL as a TestDescriptionAttrType.

 |

Return value

There is no return value.

## Example

The following example shows how to add text to the data log stream of the first [SMC_TEST()](<02.07.04.01.231.45_SMC_TEST.md>) call.

```
SMC_backgroundProcessing()
{
   ...
   //add text to the data log stream
   SMC_TEST("pin","testname",6);
   SMC_TEST_TEXT("some additional test text");

   SMC_TEST(...)
   ...
}
```
