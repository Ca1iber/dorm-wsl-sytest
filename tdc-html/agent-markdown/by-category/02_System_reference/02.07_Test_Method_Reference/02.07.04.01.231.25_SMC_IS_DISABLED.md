# SMC_IS_DISABLED()

Queries the status of SMC to check if it is disabled. If SMC is disabled it also queries the state of the immediate synchronization flag.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```
Boolean SMC_IS_DISABLED(Boolean *synchImmediately=NULL);
```

Parameter
 |

Parameter

 |

Description/Range

 |
 |

synchImmediately

 |

If SMC is disabled and the immediate synchronization flag is set to true, SmartCalc will immediately execute [SMC_TEST()](<02.07.04.01.231.45_SMC_TEST.md>) at the end of your SMC_backgroundProcessing() method without waiting for the next call of [SMC_SYNCHRONIZE()](<02.07.04.01.231.43_SMC_SYNCHRONIZE.md>).

 |

## Return value

Returns true if SMC is disabled and allows to also query the synchronization flag.

If SmartCalc has not been disabled, false will be returned.

## Example

In this example the SMC status is retrieved and put into the data log.

```
Boolean synchFlag=FALSE;
if(SMC_IS_DISABLED(&synchFlag))
{
   SMC_PUT_DATALOG("SMC is disabled!");
   if(synchFlag)
   {
      SMC_PUT_DATALOG("Immediate synchronization is enabled!");
   }
}
```
