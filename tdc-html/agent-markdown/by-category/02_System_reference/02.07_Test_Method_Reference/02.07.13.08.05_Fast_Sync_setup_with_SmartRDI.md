# Fast Sync setup with SmartRDI

#### Subtopics

- [fastSyncOff()](<02.07.13.08.05.01_fastSyncOff.md>)
- [fastSyncOn()](<02.07.13.08.05.02_fastSyncOn.md>)
- [fastSyncPortNum()](<02.07.13.08.05.03_fastSyncPortNum.md>)

Fast Sync enables the local synchronization of the test processor. For more information, see [Fast Sync](<../02.06_Command_Reference/02.06.07.01.08.04.03.03_Fast_Sync.md>).

SmartRDI provides the following functions to set up the Fast Sync feature in the code‑based mode:

`fastSyncOn()`, `fastSyncOff()`, and `fastSyncPortNum()`.
