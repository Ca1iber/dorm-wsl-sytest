# UTILITY_SEQ_POGO_MODE

The class provides the function to specify the mode for the utility pogo block.

## Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/UtilitySequencerMode.h.

  Constructor This class has no public constructor. The UTILITY_SEQ_POGO_MODE object can only be accessed via the function [UTILITY_SEQ_MODE.pogoBlock()](<02.07.04.01.265.02_UTILITY_SEQ_MODE.pogoBlock.md>) of the [UTILITY_SEQ_MODE](<02.07.04.01.265_UTILITY_SEQ_MODE.md>) class. Member function
