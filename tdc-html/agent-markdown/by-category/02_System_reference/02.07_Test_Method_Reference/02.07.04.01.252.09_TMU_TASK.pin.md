# TMU_TASK.pin()

Returns the reference to a TMU_PINS object for the specified pins. The member functions of [TMU_PINS](<02.07.04.01.252.02_TMU_PINS.md>) can be called after this function to do the settings.

## Syntax

```
TMU_PINS& pin(const STRING& pinlist);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

pinlist

 |

The list of pins

 |

## Return value

A reference to the TMU_PINS object is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
