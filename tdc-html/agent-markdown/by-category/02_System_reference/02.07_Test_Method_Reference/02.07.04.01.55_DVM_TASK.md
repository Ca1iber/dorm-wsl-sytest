# DVM_TASK

#### Subtopics

- [DVM_PIN_TASK](<02.07.04.01.55.01_DVM_PIN_TASK.md>)

The DVM_TASK class is a data container for high-accuracy direct voltage measurements (DVM) via utility pogo pins using the Keysight Technologies 3458A Multimeter.

This class can be used to call the [DVM_PIN_TASK](<02.07.04.01.55.01_DVM_PIN_TASK.md>) class, which is a subsidiary data container of the DVM_TASK class.

Note The DVM_TASK class accepts Utility DC pins only.

This class can be added to TASK_LIST, so all kinds of DC measurement (using PPMU, DPS and DC Scale pins) can be seamlessly executed.

The DVM_TASK API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/DvmTask.h.

## Syntax

```
DVM_TASK();
```

Creates an object to define different conditions for DVM measurements and to execute them concurrently.

List of parameters

There are no parameters.

Return value

There is no return value.

## Multimeter interface

### Status check

The following interfaces provide the communication with the commands specified in the 3458A Multimeter User's Guide. The guide and other product related documents are available on the Keysight Technologies web site.

```
static DVM_STATUS write (const STRING & pinlist, const STRING & task);
static DVM_STATUS read (const STRING & pinlist, STRING & answ);
static DVM_STATUS readError (const STRING & pinlist, STRING & errorMessage);
```

Definition of DVM_STATUS:

```
typedef enum
{
  DVM_STATUS_OK,
  DVM_STATUS_FAIL
} DVM_STATUS;
```

## Example

The example specifies a pin for a direct voltage measurement (measDVM) using the digital multimeter (DMM). If required, the calibration (doAcal) is executed automatically.

```
DVM_TASK   measDVM;
FLEX_RELAY connectDVM, disconnectDVM;
TASK_LIST  taskList;

ON_FIRST_INVOCATION_BEGIN();

    connectDVM.pin   ("Utility_Pogo_1").set("X","EXT");
    disconnectDVM.pin("Utility_Pogo_1").set("X","OFF");

    measDVM.pin("Utility_Pogo_1")
           .doAcal(TM::DO_ACAL_IF_NECESSARY);

    taskList.add(connectDVM)
            .add(measDVM)
            .add(disconnectDVM)
            .execute();

ON_FIRST_INVOCATION_END();

ARRAY_D result = measDVM.getValues("Utility_Pogo_1");

for ( int i = 0; i < result.size(); ++i )
{
    cout << "Measured Value: " << result[i] << endl;
}
```
