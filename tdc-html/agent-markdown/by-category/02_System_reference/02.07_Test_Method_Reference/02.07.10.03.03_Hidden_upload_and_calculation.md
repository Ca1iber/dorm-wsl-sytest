# Hidden upload and calculation

As soon the [Hidden upload](<02.07.10.04.05_Hidden_upload.md>) has finished the [calculation](<02.07.10.04.06_Hidden_calculation.md>) thread continues on different CPU cores in parallel hidden behind the test currently being executed.

Once the test result data is captured, the SMC background thread is called and the flow continues with the next test and the next capture. The background thread handles the upload to and the calculation on the system controller independently. It just requires the capture label (what data needs to be uploaded) and the corresponding test limits. The calculation results are buffered and logged at a later synchronization point.

 Note All test times shown are just examples. ![Hidden upload and calculation](<../../../../raw/118898.png>)

This concept theoretically allows a multisite efficiency (MSE) of 100 % as shown in the figure above. An MSE of > 95 % can be achieved with properly designed test programs.
