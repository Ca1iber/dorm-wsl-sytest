# GPIB_SET

This API sets a timeout time and a data terminator for data input, and returns 0 on success, non-zero when timeout occurred.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/GpibMapi.h.

## Syntax

```
INT GPIB_SET(char terminator, DOUBLE timeout);
INT GPIB_SET(DOUBLE timeout);
```

Parameters
 |

I/O

 |

Parameter

 |

Description / Range

 |
 |

I

 |

terminator

(Optional)

 |

Data terminator for data input.

Range: 0 to 127 (ASCII character code).

Default: 10 ('\n').

 |
 |

I

 |

timeout

(Optional)

 |

Timeout time in sec.

Range: 0 to 2147.48

Default : 10.

 |

## Example

```
char terminator = 59;
DOUBLE timeout = 15.0;
GPIB_SET( terminator, timeout );
```

The GPIB_SET API sets the terminator to semicolon (;), which is 59 in ASCII code, and sets the timeout time to 15 seconds.
