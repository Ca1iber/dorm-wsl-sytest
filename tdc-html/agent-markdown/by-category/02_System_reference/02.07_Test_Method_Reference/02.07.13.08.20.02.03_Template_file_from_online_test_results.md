# Template file from online test results

Starting from 7.5.2, SmartRDI allows you to generate an ORE template file from online test results.

If you set ORE_TEMPLATE_BY_USER_CODE = TRUE in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>), SmartRDI can add real test results into the template file rdi_ore_template_by_user_code.xml.

 If you have a piece of SmartRDI code as follows:

```
RDI_BEGIN();
  rdi.func("id1").label("abc")...;
  rdi.smartVec("id2").pin("P1")...;
  ...
RDI_END();
```

 It will generate an ORE template file as follows:  ![ORE template file generated from online test results](<../../../../raw/348900.png>)  From the original code and the generated template file, you can see:

-

All measurements with ID in the SmartRDI code are converted to ore result frames in the template file.

-

SmartRDI automatically fills the real active sites information in the template file.

-

SmartRDI automatically fills the real test result (only the first site result) in the template file.

If you are going to use this template, add </offlineResultEmulation> at the end of the rdi_ore_template_by_user_code.xml file.

You can also use ORE_FOLDER in the RDI_Configure file to specify a location for the rdi_ore_template_by_user_code.xml file. For more information, see [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md#_146692__dle_ORE_setup>).

## Test results of all sites to the template file

 Just like adding real test results on the first site to the template file, SmartRDI can also add real test results of all sites to the template file. The template file for all sites is similar to that for the first site results, but it is more adaptive to get runtime ORE values. For example,

```
<offlineResultEmulation>
  <testSuite name = "offline_ORE">
    <id name = "id">
      <site num = "1">
        <pin name = "DATA1">
          <smartVec readData = "12,"/> // Site 1 real result
        </pin>
      </site>
    </id>
    <id name = "id">
      <site num = "2">
        <pin name = "DATA1">
          <smartVec readData = "16,"/>
        </pin>
      </site>
    </id>
  </testSuite>
```

## ARRAY results in the template file

 For ARRAY value type, the result size may be very big. It is not possible to check all the results in the template file.

- If the result size is less than 200, SmartRDI inserts all the results to the XML file.
- If the result size is equal to or greater than 200, SmartRDI inserts all the results into a .txt file which is located in the same folder as the rdi_ore_template_by_user_code.xml. SmartRDI also adds the path information in the .xml file.
 For example, the result of following code will be greater than 200:

```
RDI_BEGIN();
  rdi.tmu("id1").pin("P1").vth().sample(4)...;
  rdi.tmu("id2").pin("P2").vth().sample(1024)...; // result size > 200
  ...
RDI_END();
```

 SmartRDI will generate the template file (.xml) as follows:  ![Oversized results in the template file](<../../../../raw/348901.png>)

For the .txt result file, its naming convention: testSuiteName_idString_pinName_className_resultType_result_file. For example, TestPlay_id1_DATA1_tmu_stamp_result_file.

SmartRDI offers a flag [ORE_TEMPLATE_DATA_FILE_SIZE_THRESHOLD](<02.07.13.04_RDI_Configure_file.md#_146692__row_ORE_TEMPLATE_DATA_FILE_SIZE_THRESHOLD>), which can be used in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>) to set a threshold of the result size. See [ORE_TEMPLATE_DATA_FILE_SIZE_THRESHOLD](<02.07.13.04_RDI_Configure_file.md#_146692__row_ORE_TEMPLATE_DATA_FILE_SIZE_THRESHOLD>) for how to set the threshold.

## Functional changes

- Introduced in SmartRDI 7.5.2
- SmartRDI 7.10.0: Real test results of all sites can be added to the template file.
