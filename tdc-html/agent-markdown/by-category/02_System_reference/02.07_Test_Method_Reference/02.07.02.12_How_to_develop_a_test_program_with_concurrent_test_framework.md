# How to develop a test program with concurrent test framework

#### Subtopics

- [How to create a test method with concurrent test framework](<02.07.02.12.01_How_to_create_a_test_method_with_concurrent_test_framework.md>)
- [How to create a CCF block in the testflow](<02.07.02.12.02_How_to_create_a_CCF_block_in_the_testflow.md>)

## Before you begin

Make sure you are using SmarTest 6.5.4 or later versions.

## Procedure

-  Create the setup files following the [Guidelines of using concurrent test framework](<02.07.08.07_Guidelines_of_using_concurrent_test_framework.md>).
-  Create the test method and testflow with concurrent test framework. For details, see

  - [How to create a test method class with concurrent test framework](<02.07.02.12.01_How_to_create_a_test_method_with_concurrent_test_framework.md>)
  - [How to implement a concurrent test method](<02.07.02.12.01.01_How_to_implement_a_concurrent_test_method.md>)
  - [How to create a CCF block in the testflow](<02.07.02.12.02_How_to_create_a_CCF_block_in_the_testflow.md>)

-  Execute and debug the testflow in development and serial mode. Enable the output of debugging information.

  -  Start with single site and no smartCalc execution. Make the testflow single execution pass.
  -  Enable multi-sites, testflow loop execution and smartCalc (if needed) and make the testflow pass.

-  Execute and debug the testflow in development and concurrent mode. Enable the output of debugging information.

  -  Start with single site and no smartCalc execution. Make the testflow single execution pass.
  -  Enable multi-site, testflow loop and smartCalc (if needed) and make the testflow pass.

-  Save the merged multi-port burst label and multi-port timing file generated in development mode explicitly with the name specified in the parameter CCT_LabelName and CCF_TimingSpecSetName.
-  Save the loaded level setup file.
-  Set the CCF variables as concurrent mode, production mode and no debugging information output.
-  Execute the test program.

## Results

A test program using concurrent test framework is ready.

## Functional changes

- Introduced in SmarTest 6.5.4
