# DVM_TASK.getValues()

The getValues() member function returns an array of measurement result values for the specified pin.

## Syntax

```
ARRAY_D getValues ( const STRING& pin) const
```

Parameter
 |

Parameter

 |

Description

 |
 |

pin

 |

The pin for which you want to retrieve the result values.

 |

## Return value

Returns an array of measurement result values to the [DVM_TASK](<02.07.04.01.55_DVM_TASK.md>) object.

## Example

See the example in [DVM_TASK](<02.07.04.01.55_DVM_TASK.md>).
