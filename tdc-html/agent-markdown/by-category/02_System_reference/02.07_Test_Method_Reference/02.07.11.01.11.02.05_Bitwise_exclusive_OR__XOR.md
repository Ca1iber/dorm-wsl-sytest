# Bitwise exclusive OR (XOR)

The '^' operator calculates the bitwise XOR of two state character sequences.

It has the same semantics as the C programming language.

If the parameters differ in length, the shorter sequence is filled with state character '0' or 'L', depending on the corresponding state character of the longer sequence.

If a state characters is used which cannot be converted to integer, an error is issued.

## Syntax

integer := integer ^ integer

## Example

"001" ^ "101" results in `"100"`

"HHHH0001" ^ "H0101" results in `"HHHH0100"`

"LLL" ^ "HL0" results in "ERROR: cannot calculate result of "L" ^ "0"."

"L1" ^ "ZZ" results in "ERROR: "ZZ" is not convertible to integer."

"011" ^ 2 results in "ERORR: operator parameters of different types."
