# EVENT_CF.getCForce()

Reads the force current that has been defined by [EVENT_CF.cForce()](<02.07.04.01.63.02.01_EVENT_CF.cForce.md>).

The value is read from the corresponding [EVENT_CF](<02.07.04.01.63.02_EVENT_CF.md>) object and returned as an [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getCForce(EVENT_VALUE_DOUBLE & value) const;
```

Parameter
 | Parameter  | Description |
 | value  | The programmed force current in A (Ampere). |

Return value

There is no return value.
