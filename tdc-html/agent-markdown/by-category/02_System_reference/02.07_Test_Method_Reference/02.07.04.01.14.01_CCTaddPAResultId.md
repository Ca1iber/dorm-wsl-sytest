# CCTaddPAResultId()

Remembers the input PA result id to the current test method instance. This id can be retrieved using the [CCTgetPAResultId()](<02.07.04.01.14.19_CCTgetPAResultId.md>) API.

## Syntax

void CCTaddPAResultId(const string &id`);`

Parameter
 |

Parameter

 |

Description

 |
 |

id

 |

PA result id. Call the 2ndWrapper::getResultId() member function to retrieve the PA result id (see example below).

 |

## Example

```
virtual void createBurst()
{

     2ndWrapper:: getInstance(tsName). write(str);
     2ndWrapper::getInstance(tsName).read();
     CCTaddPAResultId(2ndWrapper::getInstance(tsName).getResultId());
     2ndWrapper:: getInstance(tsName). write(str1);
     2ndWrapper:: getInstance(tsName). read();
     CCTaddPAResultId(2ndWrapper::getInstance(tsName).getResultId());

}
```
