# resolution()

This function specifies a value that represents the resolution between steps in cogo searches. For a binary search, it equals the value of the width between the two final steps; for a linear search, it equals a step width. See [Sequencer-controlled searching with cogo](<02.07.13.19.02_Sequencer-controlled_searching_with_cogo.md>) for more information about `resolution()` and `step()`.

## Syntax

```
resolution(double dRes)
```

List of parameters
 |

Parameter

 |

Description

 |
 |

dRes

 |

For a binary search: The width between the two final steps.

For a linear search: A step width.

 |

## Example

```
RDI_BEGIN();

  rdi.cogo("bin_vf_r").search(TA::BINARY).pathPin("DATA9").start(0).stop(3).init(1.5).resolution(0.375).blockBegin();
  rdi.dc().pin("pinA").vForce(rdi.searchInput()).execute();
  rdi.dc().pin("pinB").iForce(0 mA).vMeas().measWait(100 us).limit(0,1.4).execute();
    rdi.wait(1 ms);
  rdi.cogo().blockEnd();

RDI_END();
```
