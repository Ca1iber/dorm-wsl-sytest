# getFFC()

This function returns the number of the first failing cycle for a specified pin.

  Note Retrieval of xMode results is supported if the xMode value is set accordingly with [xMode()](<02.07.13.16.12_xMode.md>). For example, xMode(4) and FFC result = 6, then edge 3 of the vector 2 is the first fail.

```
int getFFC(string pin);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

pin

   | The name of the pin for which to return the number of the first failing cycle. Note It can only be a single pin. Do not use multiple pins, a pin group or @ for all pins |

## Return value

The return value is an integer indicating the first failing cycle.

## Example

```
int ffc=rdi.id("b").getFFC("pA");
```
