# SEQUENCER_CONTEXT_ITERATOR

The objects of this class serve to simplify a loop over all sequencer context items (execution contexts) that are contained in a sequencer context. An iterator object is created by the getList() member function of the SEQUENCER_CONTEXT class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SequencerContextIterator.h.

## Syntax

### Member functions

```
bool hasNext(void);
SEQUENCER_CONTEXT_ITEM& next(void);
```

## Member functions

### hasNext()

```
bool hasNext(void);
```

This member function returns TRUE, if there is still a sequencer context item to be processed. The function has no parameters.

### next()

```
SEQUENCER_CONTEXT_ITEM& next(void);
```

This member function returns a sequencer context item unless all the sequencer context items of the SEQUENCER_CONTEXT object have already been processed. The function has no parameters.

## Example

The following code fragment shows how a sequencer context iterator is typically used (`test` is a SEQUENCER_CONTEXT object):

```
SEQUENCE_CONTEXT_ITERATOR it = test.getList();
    while(it.hasNext())
    {
        SEQUENCER_CONTEXT_ITEM& t = it.getNext();
              // process sequencer context item
    }
```
