# TMU_RESULTS.invalidate()

Invalidates the result cache. It releases all the cached results.

## Syntax

```
void invalidate();
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Functional changes

- Introduced in SmarTest 7.1.0
