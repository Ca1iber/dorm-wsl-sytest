# rdi.tmu().dataRate()

Sets the expected data rate for TMU pins.

## Syntax

```
tmuBase& dataRate(double iDataRate);
```

Parameter
 | Parameter  | Description |
 | dataRate  | The data rate in bits/second or Hertz (Hz).  | Note The functions rdi.tmu().dataRate() and [rdi.tmu().preScaler()](<02.07.13.21.12_rdi.tmu__.preScaler.md>) cannot be used together for the same pin in one rdi ... execute() block.

## Return Value

A reference to the tmuBase object.

## Example

```
RDI_BEGIN();

    rdi.tmu().pin("PVI8_PMU_1") // PVI8_TMU
        .measMode(TA::RISE_TIME)
        .dataRate(25 MHz)
        .vth(1.0 V, 2.0 V)
        .samples(50)
        .execute();

    rdi.wait(100 us);

    rdi.tmu().pin("PS1600_1") // Digital TMU
        .measMode(TA::RISE)
        .dataRate(10 MHz)
        .vth(1.0 V)
        .samples(50)
        .execute();

    rdi.wait(100 us);

RDI_END();
```

Note For supported DC Scale pins, the initDiscard(), interSkip(), preScaler(), and dataRate() settings must be the same within one RDI_BEGIN() ... RDI_END() block.

```
RDI_BEGIN();

    rdi.tmu("1").pin("PVI8_PMU_1")
        .vth(3.0 V, 5.0 V)
        .samples(4)
        .measMode(TA::PULSE_HIGH)
        .interSkip(2).initDiscard(3).dataRate(25 MHz)
        .execute();

    rdi.wait(1 ms);

    rdi.tmu("2").pin("PVI8_PMU_1")
        .vth(1.0 V, 3.0 V)
        .samples(8)
        .measMode(TA::RISE_TIME)
        .interSkip(2).initDiscard(3).dataRate(25 MHz)
        .execute();

    rdi.wait(2 ms);

RDI_END();
```

Note For a digital pin, all the parameters must be the same within one RDI_BEGIN() ... RDI_END() block.

```
RDI_BEGIN();

    rdi.tmu("1").pin("PS1600_1")
        .vth(1.0 V).samples(5).measMode(TA::RISE).execute();

    rdi.wait(1 ms);

    rdi.tmu("2").pin("PS1600_1")
        .vth(1.0 V).samples(5).measMode(TA::RISE).execute();

    rdi.wait(2 ms);

RDI_END();
```
