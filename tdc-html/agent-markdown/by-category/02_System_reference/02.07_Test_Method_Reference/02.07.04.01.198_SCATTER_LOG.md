# SCATTER_LOG

This class contains scattered data with captions. This class is supposed to be passed to [PUT_DEBUG](<02.07.04.01.175_PUT_DEBUG.md>) or [PUT_DATALOG](<02.07.04.01.174_PUT_DATALOG.md>) API.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ScatterLog.h.

## Syntax

```
SCATTER_LOG().member_function1().member_function2()...
```

## Class definition

### Constructors

```
SCATTER_LOG();
SCATTER_LOG(const ARRAY_I& xseries, const ARRAY_I& yseries);
SCATTER_LOG(const ARRAY_D& xseries, const ARRAY_D& yseries);
SCATTER_LOG(const ARRAY_LL & xseries, const ARRAY_LL & yseries);

```


### Constructors

```
SCATTER_LOG();
SCATTER_LOG(const ARRAY_I& xseries, const ARRAY_I& yseries);
SCATTER_LOG(const ARRAY_D& xseries, const ARRAY_D& yseries);
SCATTER_LOG(const ARRAY_LL& xseries, const ARRAY_LL& yseries);
SCATTER_LOG(const SCATTER_LOG& xydata);
```

This constructs an object of class `SCATTER_LOG`. It allows you to define the sequence, unit, title, comment and colors of data.

Parameters
 |

xseries

 |

The array data for x-axis.

 |
 |

yseries

 |

The array data for y-axis.

 |
 |

xydata

 |

The SCATTER_LOG class object to copy from.

 |
