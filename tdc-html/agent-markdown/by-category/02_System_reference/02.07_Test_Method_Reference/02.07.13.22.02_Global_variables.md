# Global variables

#### Subtopics

- [setGlobalVar()](<02.07.13.22.02.01_setGlobalVar.md>)
- [getGlobalVar()](<02.07.13.22.02.02_getGlobalVar.md>)

SmartRDI provides global variables to share values across test suites.

SmartRDI includes two functions to handle these variables:

- setGlobalVar()
- getGlobalVar()
 To call a global variable command in the [SMC_backgroundProcessing()](<02.07.04.01.231.01_SMC_ARM.md#_120107__s_SMC_backgroundProcessing>) function, you must set an SMC_SYNCHRONIZE after the command's test suite. For example,

```
// Suite 1:
SMC_backGroundProcessing()
{
rdi.setGlobalVar("str",value);
}

// Suite 2:
SMC_SYNCHRONIZE();

// Suite 3:
SMC_backGroundProcessing()
{
rdi.getGlobalVar("str");
}
```
