# setGlobalVar()

This function assigns a value to a SmartRDI variable. If the variable does not yet exist, it is created. If it already exists, its current value is overwritten.

## Syntax

```
void rdi.setGlobalVar(variable_name, value)
```

List of parameters
 |

Parameter

 |

Description

 |
 |

variable_name

 |

The name of the variable to which you want to assign the value. A string.

 |
 |

value

 |

The value to assign to the variable. The value must have one of these data types:

- int
- double
- ARRAY_I
- ARRAY_D
- vector<ARRAY_I>
- vector<ARRAY_D>
 |

## Example

This example assigns the value of a program variable (myVar) to the SmartRDI variable abc.

```
int myVar = 100;
rdi.setGlobalVar("abc",myVar);
```
