This section describes the procedure of developing a universal test method library in SmarTest.

## About this task

The procedure is to create a universal test method library from scratch. If you have already some classic test method libraries, you can convert them to universal test method libraries. (See [How to convert a classic test method project to universal test method project](<02.07.02.04.01_How_to_convert_a_classic_test_method_project_to_universal_test_method_pr.md>))

## Before you begin

Make sure you are using SmarTest 6.3 or later, and the device primary setups are ready to use.

## Procedure

-  [Create a universal test method project](<02.07.02.02.01_How_to_create_a_universal_test_method_project.md>).
-  [Create a universal test method class for the universal test method project](<02.07.02.02.02_How_to_create_a_universal_test_method_class.md>).
-  [Create a universal-test-method-based testflow](<02.07.02.02.03_How_to_create_and_execute_a_universal-test-method-based_testflow.md>).
-  [Debug a universal test method](<02.07.02.02.04_How_to_debug_a_universal_test_method.md>).

## Results

The universal test method libraries are error free and ready to use.
