# SlimBusController.decode()

This function converts the results of the SmarTest protocol test into SLIMbus objects. Calling it is a necessary prerequisite for processing both compare and capture results. If the Superframe Viewer file exists, the results will also be integrated into this file. decode() also checks if the period defined in the primary timing is compatible with the timing in the sequence file header (CLK element within the InitialConfig block).

## Syntax

```
Boolean decode (PROTOCOL_TEST &protocolTest);
```

Parameter
 |

Parameter

 |

Description

 |
 |

protocolTest

 |

Specifies the SLIMbus protocol test that is to be decoded.

 |

## Return value

TRUE if the conversion was successful, FALSE otherwise.

## Functional changes

- Introduced in SmarTest 7.2.1
