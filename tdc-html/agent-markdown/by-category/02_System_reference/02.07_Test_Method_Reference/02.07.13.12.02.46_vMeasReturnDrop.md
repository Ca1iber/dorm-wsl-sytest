# vMeasReturnDrop()

Specifies a voltage drop measurement on the return line and initiates the transfer of an available measurement value from the front-end to the test processor.

 The voltage drop is measured from the low sense pogo pin to the low force pogo pin or common ground. The measured voltage drop depends on the actual current and the impedance of the connection to the DUT. For ganged channels, the voltage drop is measured on the master channel.

This member function is supported for HC channels of [DC Scale DPS128/DPS64 cards](<../02.05_Test_Head_Cards/02.05.05.01_DC_Scale_DPS128_DPS64_cards.md>) and the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) both in PMU and DPS operating mode and for the [DC Scale UHC4T card](<../02.05_Test_Head_Cards/02.05.05.02_DC_Scale_UHC4T_card.md>) in DPS operating mode.

For more information on DPS128 voltage drop measurements, refer to [Voltage drop measurement](<../02.05_Test_Head_Cards/02.05.05.01.03_DPS128____PS64_functionality_and_features.md#_140638__s_Voltage_drop_measurement>) in [DPS128鈥?鈥奃PS64 functionality and features](<../02.05_Test_Head_Cards/02.05.05.01.03_DPS128____PS64_functionality_and_features.md>).

For more information on XPS256 voltage drop measurements, refer to [XPS256 voltage drop measurement](<../02.05_Test_Head_Cards/02.05.05.03.03.08_XPS256_voltage_drop_measurement.md>).
