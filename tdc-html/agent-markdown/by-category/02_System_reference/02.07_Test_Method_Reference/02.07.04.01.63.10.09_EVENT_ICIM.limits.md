# EVENT_ICIM.limits()

Sets current limits to compare against thresholds.

## Syntax

```
EVENT_ICIM & limits (const LIMIT & limits);
```

Parameter
 | Parameter  | Description |
 | limits |

Current limits of the specified LIMIT object

 |

Return value

There is no return value.
