# CCTgetCycleOffset()

Retrieves the cycle offsets of all labels for each native test suite, or the first cycle of the first label and the last cycle of the last label of the native test suite.

This function is usually used in the `preStart()`, `postStart()`, `process()` and `cleanup()` function but not used in the `init()` function of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

Getting the first cycle offset:

```
INT CCTgetCycleOffset(const STRING& port);
```

Getting the cycle offsets of all labels:

```
void CCTgetCycleOffset(const string& port, std::vector<BurstLabelInfo> vLabelOffset)
```

Getting the first and the last cycle:

```
int CCTgetCycleOffset(const string& port, int& lastCyc);
```

Parameters
 |

Parameter

 |

Description

 |
 |

port

 |

The port to be queried

 |
 |

vLabelOffset

 |

The vector containing the label name and index, the cycle offset and the cycle number of all the labels of the specified port in this native test suite

 |
 |

lastCyc

 |

The last cycle of the last label

 |

## Return value

For getting the first cycle offset, it returns the first cycle offset of the specified port.

For getting all the cycle offset, there is no return value. The result is contained in the parameter vLabelOffset of the type BurstLabelInfo.

For getting the first and last cycle, it returns the start cycle of the first label of the specified port. Thevalue of the last cycle is contained in the parameter lastCyc.

The struct BurstLabelInfo is defined as below:

```
struct BurstLabelInfo
{
    string labelName;
    int id;        // the label index in the merged pattern
    int startCyc;
    int numberOfCycles;   //the number of cycles of this label
}
```

## Examples

### Getting the cycle offsets

The following example returns all label names, their offset, and their index in the burst pattern on portA belonging to the current test suite.

```
process()
{
  vector<BurstLabelInfo> vLabelOffset;
  CCTgetCycleOffset("portA", vLabelOffset);
  for(vector<BurstLabelInfo>::iterator it = vLabelOffset.begin(); it != vLabelOffset.end(); it++)
  {
    cout << "label name" << it->labelName << endl;
    cout << "label offset" << it->startCyc << endl;
    cout << "label index" << it->id       << endl;
    cout << "total cycles of the label" << it->numberOfCycles <<endl;
  }
  }
```

### Getting the first and the last cycle

Assume that the test suite runs a burst of label A, label A1 and label A2 on portA. In the following `process()` function, the `CCTgetCycOffset()` returns the start cycle of label A and the stores the last cycle of label A2 in lastCyc for the test suite.

```
Process()
{
  int start, lastCyc;
  start = CCTgetCycOffset("portA", lastCyc);
}
```
