# TMU_TASK operator <<

Outputs the settings in the TMU_TASK object.

## Syntax

```
std::ostream & operator << (std::ostream & os, const TMU_TASK & rhd);
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

os

 |

The data stream to ouput.

 |
 |

I

 |

rhd

 |

The related TMU_TASK object

 |

## Return value

A reference to the data stream is returned.

## Example

```
TMU_TASK task;
...
cout << task << endl;
```
