# SMC_GET_WAVEFORM()

Retrieves the captured waveform data from the hardware memory.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```
const ARRAY_D& SMC_GET_WAVEFORM(const STRING& dgtPinName, const STRING& resultHandle, INT measurement);
const vector<ARRAY_D>& SMC_GET_WAVEFORM(const STRING& dgtPinName, const STRING& resultHandle,
                                        INT measurement, INT nWaveforms);
void SMC_GET_WAVEFORM(Wave<DOUBLE>& wave, DOUBLE samplingRate, const STRING& dgtPinName,
                      const STRING& resultHandle, INT measurement);
void SMC_GET_WAVEFORM(vector<Wave<DOUBLE> >& waves, DOUBLE samplingRate, const STRING& dgtPinName,
                      const STRING& resultHandle, INT measurement, INT nWaveforms);
```

## Return value

The captured waveform is either returned as data type [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>) or a vector of [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>).

If the wave parameter is used, the captured waveform(s) will be stored either in a single or vector of wave object(s) which is referenced by the wave parameter.

## Example

The following example bursts the captured data of DGTPin (from 1 to NumberOfWaveforms), which is stored in the handle area of the HW memory into the burstWaveforms vector.

```
void SMC_backgroundProcessing(string DGTPin, string handle, INT NumberOfWaveforms)
{
   // hidden upload of one vector (burst upload) containing multiple waveforms
   vector<ARRAY_D> burstWaveforms= SMC_GET_WAVEFORM(DGTPin, handle, 1, NumberOfWaveforms);

   // extract the single waveforms form the burst and do some processing in the background
   for(INT currentWaveform=0; currentWaveform < NumberOfWaveforms;++currentWaveform)
   {
      ARRAY_D &singleWaveform = burstWaveforms[currentWaveform];
      // Processing...
   }
}
```

The following example retrieves the captured data of the first sequencer line (1) for the given resultHandle and stores the data in the CaptWave object.

```
Wave<DOUBLE> CaptWave;
DOUBLE sample_rate = 2.5e6;
SMC_GET_WAVEFORM (CaptWave, sample_rate, "pinA", "resultHandle", 1);
```
