# EVENT_VCIM.getOutOfRangeCheck()

Reads the state of the out-of-range check that has been defined by [EVENT_VCIM.outOfRangeCheck()](<02.07.04.01.63.21.07_EVENT_VCIM.outOfRangeCheck.md>).

The state is read from the corresponding [EVENT_VCIM](<02.07.04.01.63.21_EVENT_VCIM.md>) object and returned as a bool value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getOutOfRangeCheck(bool & failOnOutOfRange) const;
```

Parameter
 | Parameter  | Description |
 | failOnOutOfRange |

The programmed value true or false of the out-of-range check.

- true: The out-of-range check is enabled
- false: The out-of-range check is disabled
 |

Return value

There is no return value.
