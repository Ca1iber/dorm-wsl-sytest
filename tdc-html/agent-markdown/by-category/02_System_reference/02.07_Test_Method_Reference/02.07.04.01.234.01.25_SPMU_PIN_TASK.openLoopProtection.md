# SPMU_PIN_TASK.openLoopProtection()

Selects the open loop protection of a DC Scale pin.

Open loop protection means how the force pin (P#) and the sense pin (PS#) ) as well as the ground sense pin (GS#) and the common ground are connected internally to ensure that the feed back input of the control loop or the output stage respectively is not open in case the required connection at the DUT or on the DUT board is (unintentionally) open.

This member function is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

## Syntax

```
SPMU_PIN_TASK & openLoopProtection(const STRING & openLoopProtection);
```

 Parameter

 | Parameter  | Description |
 | openLoopProtection  |  Mode of the open loop protection to be defined as string. Valid strings are

- "DIODE" (default)

The internal force to sense connections are made via anti鈥憄arallel diodes.

This is the default state if the parameter is not defined.

This is the recommended setting if both parameters the [maximum force drop](<02.07.04.01.234.01.09_SPMU_PIN_TASK.forceDropMax.md>) and the [maximum return drop](<02.07.04.01.234.01.29_SPMU_PIN_TASK.returnDropMax.md>) are set to a value < 0.5 V.

- "NONE"

The internal force to sense connections are open.

The output stage no longer has any voltage feedback if the force to sense connection on the DUT or the DUT board is (unintentionally) open.

The following rules apply to this option:

  - The [Vdrop Disco](<../02.05_Test_Head_Cards/02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_Vdrop_Disco>) parameter must be set to ON in the [DC Scale Safety editor](<../02.05_Test_Head_Cards/02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__s_DC_Scale_Safety_editor>).
  - This is the required setting if one of the parameters [maximum force drop](<02.07.04.01.234.01.09_SPMU_PIN_TASK.forceDropMax.md>) or [maximum return drop](<02.07.04.01.234.01.29_SPMU_PIN_TASK.returnDropMax.md>) is set to a value 鈮?nbsp;0.5 V.
