# EVENT_WAVEFORM_VCVM.getOutOfRangeCheck()

Reads the state of the out-of-range check that has been defined by [EVENT_WAVEFORM_VCVM.outOfRangeCheck()](<02.07.04.01.63.36.11_EVENT_WAVEFORM_VCVM.outOfRangeCheck.md>).

The state is read from the corresponding [EVENT_WAVEFORM_VCVM](<02.07.04.01.63.36_EVENT_WAVEFORM_VCVM.md>) object and returned as a bool value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getOutOfRangeCheck(bool & failOnOutOfRange) const;
```

Parameter
 | Parameter  | Description |
 | value |

The programmed value true or false of the out-of-range check.

- true: The out-of-range check is enabled
- false: The out-of-range check is disabled
 |

Return value

There is no return value.
