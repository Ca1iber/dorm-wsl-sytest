# EVENT_VCVM.limitLow()

Sets the lower voltage limit to compare against threshold.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_VCVM & limitLow (const EVENT_VALUE_DOUBLE & low);
```

Parameter
 | Parameter  | Description |
 | lowLimit |

The lower limit to be set in V (Volt).

 |

## Return value

A reference to the corresponding [EVENT_VCVM](<02.07.04.01.63.22_EVENT_VCVM.md>) object.
