# PPMU_PIN_SETTING

The PPMU_PIN_SETTING class is a data container holding the object reflecting the pin PMU's measurement setup data. The target pin PMU can be specified via the [PPMU_SETTING](<02.07.04.01.160_PPMU_SETTING.md>) class because the PPMU_PIN_SETTING class can be called as a subsidiary data container of the [PPMU_SETTING](<02.07.04.01.160_PPMU_SETTING.md>) class.

## Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PpmuPinSetting.h.

  Constructor

There is no constructor available for this class.

The PPMU_PIN_SETTING class can be called as a subsidiary data container of the [PPMU_SETTING](<02.07.04.01.160_PPMU_SETTING.md>) class.

## Member functions

  mode()

```
PPMU_PIN_SETTING & mode(const STRING& mode)
```

This function selects the measurement mode from current measurement or voltage measurement. Note that IFVM will automatically be set when force current is set with the iForce() function to the task, and VFIM will automatically be set when force voltage is set with the vForce() function to the task.

Parameter
 | mode |

Measurement mode. The following types are available:

- "IFVM" I-force V-measure
- "VFIM" V-force I-measure
  |  iForce()

```
PPMU_PIN_SETTING & iForce(const DOUBLE val)
```

This function sets the pin to I-force V-measure mode and specifies the current to be forced.

Parameter
 | val |

Current to be forced.

The default unit is [A].

   |  vForce()

```
PPMU_PIN_SETTING & vForce(const DOUBLE val)
```

This function sets the pin to V-force I-measure mode and specifies the voltage to be forced.

Parameter
 | val |

Voltage to be forced.

The default unit is [V].

   |  iRange()

```
PPMU_PIN_SETTING & iRange(const STRING& range)
PPMU_PIN_SETTING & iRange(const DOUBLE val)
```

This function sets the measurement current range and force current range for a PPMU.

Parameters
 | range |

String corresponding to current range, "10uA", "100 uA", "1000uA" or "40mA".

 |
 | val |

Range value in [A] to be converted to the current range. The smallest possible range will be selected from 10 uA, 100 uA, 1000 uA or 40 mA.

   |  min()

```
PPMU_PIN_SETTING & min(DOUBLE val)
```

This function sets the lower limit current or voltage for pass/fail judgment.

Parameter
 | val |

Lower limit current or voltage.

The default unit is [A] or [V].

   |  max()

```
PPMU_PIN_SETTING & max(const DOUBLE val)
```

This function sets the upper limit current or voltage for pass/fail judgments.

Parameter
 | val |

Upper limit current or voltage.

 The default unit is [A] or [V].

   | Note Both the minimum and the maximum limit must be specified with the min and max functions. If not, an error is reported at the start of the measurement program. limits()

```
PPMU_PIN_SETTING & limits(const STRING& testname)
PPMU_PIN_SETTING & limits(LIMIT& limitobj)
PPMU_PIN_SETTING & limits(V93kLimits::TMLimits& tmlimit, const STRING& limitparaname)
```

This function sets the lower and upper limit values using a testflow limit name, a [LIMIT](<02.07.04.01.126_LIMIT.md>) class object, or a TMLimits class object.

If a [TMLimits](<02.07.04.01.250_TMLimits.md>) object is specified, the unit for the limits is taken into account. For [LIMIT](<02.07.04.01.126_LIMIT.md>) class, no units are considered (that is, the specified numbers are considered to refer to default units).

Limit values can also be set directly by using the min() and max() functions (see above).

Parameters
 | testname  | Name of a testflow that can be referred from the Properties view |
 | limitobj  | Name of an object of the [LIMIT](<02.07.04.01.126_LIMIT.md>) class |
 | tmlimit  | Name of an object of the [TMLimits](<02.07.04.01.250_TMLimits.md>) class |
 | limitparaname |

Name of the test whose limits are to be used.

This parameter corresponds to the value of the limitParamName parameter of the [getLimitObj()](<02.07.04.01.250_TMLimits.md#_110432__dle_getLimitObj>) member function of [TMLimits](<02.07.04.01.250_TMLimits.md>).

 |

## Example

```
...
PPMU_SETTING setting1;

setting1.pin("p1, p2").iForce(1 mA).iRange(40 mA)
                      .min(50 mV).max(100 mV);
...
```

This example defines an object that holds measurement parameters of the "p1" and "p2" pin.
