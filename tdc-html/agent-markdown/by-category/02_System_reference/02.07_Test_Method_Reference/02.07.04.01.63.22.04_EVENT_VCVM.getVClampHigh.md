# EVENT_VCVM.getVClampHigh()

Reads the upper voltage clamp value that has been defined by [EVENT_VCVM.vClampHigh()](<02.07.04.01.63.22.03_EVENT_VCVM.vClampHigh.md>).

The value is read from the corresponding [EVENT_VCVM](<02.07.04.01.63.22_EVENT_VCVM.md>) object and returned as an [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getVClampHigh(EVENT_VALUE_DOUBLE & value) const;
```

Parameter
 | Parameter  | Description |
 | value |

The programmed upper voltage clamp value in V (Volt).

Note: Only one of the two clamp voltages can be set per DC event. The parameter value is set to 999999 V if the upper clamp is not defined for the queried DC event object.

 |

Return value

There is no return value.
