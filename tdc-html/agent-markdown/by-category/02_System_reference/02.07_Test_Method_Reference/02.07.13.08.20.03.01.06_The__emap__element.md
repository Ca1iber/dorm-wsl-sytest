# The <emap> element

This element stores error map results performed by using the SmartRDI's `emap()` class.

The <emap> element stores emap results in its failCyc attribute. This attribute saves failing information in user patterns returned by a `getFailCount()`, `getFFC()` or `getFailCyc()` function.

## Examples

Below is an example of the <emap> element and its corresponding SmartRDI code block.

An ORE file containing <emap> elements:

```
<offlineResultEmulation>
  <id name = "id">
    <pin name = "A">
      // Fail cycle = 1,3,5,8,9,10,11,12
      <emap failCyc = "1" />
      <emap failCyc = "3,5" />
      <emap failCyc = "8" to = "12" />
    </pin>
  </id>
</offlineResultEmulation>
```

 The corresponding SmartRDI code block from which the ORE gets the result:

```
RDI_BEGIN();
  rdi.emap("id").label("label1").pin("A")
     .failCount(2,9).FFC(2).pfMap(2,9)
     .failCyc(2,9).execute();
  ...
RDI_END();
...
rdi.id("id").getFailCount();  //5
rdi.id("id").getFFC();        //3
rdi.id("id").getPfMap();      //{1,0,1,0,1,1,0,0,0}
rdi.id("id").getFailCyc();    //{3,5,8,9,10}
```

 Note `<emap failCyc = "" />` means no fail cycle.

### More attributes and syntax can be used in SmartRDI 7.5.2

 An EMAP ORE result example:

```
<offlineResultEmulation>
  <id name = "id">
    <pin name = "A">
      <emap FFC = "3"/>
      <emap failCount = "5"/>
      <emap failCyc = "3,5,6,8"/>
      <emap pfMap = "0,1,1,0,1,0"/>
      <emap multiFFC = "2,3,5"/>
    </pin>
    <emap combinedFailCount = "5"/>
  </id>
</offlineResultEmulation>
```

 The corresponding SmartRDI code block from which the ORE gets the result:

```
RDI_BEGIN();
  rdi.emap("id").label("label1").pin("A")
     .failCount(2,9).FFC(2).pfMap(2,9)
     .failCyc(2,9).execute();
  ...
RDI_END();
...
rdi.id("id").getFailCount();         //5
rdi.id("id").getFFC();               //3
rdi.id("id").getPfMap();             //{0,1,1,0,1,0}
rdi.id("id").getFailCyc();           //{3,5,6,8}
rdi.id("id").getCombinedFailCount(); //5
rdi.id("id").getMultiFFC();          //2,3,5
```
