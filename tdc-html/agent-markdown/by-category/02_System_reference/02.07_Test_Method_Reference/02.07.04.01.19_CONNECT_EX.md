# CONNECT_EX

This API is used to control the powering up sequence of the DPS pins.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ConnectEx.h.

## Class definition

### Constructor

```
CONNECT_EX();
```

### Member functions

```
void connect();
void force(const STRING &pinList="@");
```

### Syntax

```
CONNECT_EX obj;
obj.mem_func;
```

or

```
CONNECT_EX().mem_func;
```

Obj is an object of `CONNECT_EX`. `mem_func` is an member function of `CONNECT_EX`.

### Constructor

```
CONNECT_EX();
```

It creates an object of the CONNECT_EX class.

## Member functions

### connect()

```
void connect();
```

This function connects the test system to the DUT. It is the same with the [CONNECT](<02.07.04.01.18_CONNECT.md>) API.

### force()

```
void force(const STRING &pinList="@");
```

This function connects the specified DPS pins to the DUT in the sequence defined in the current primary set no matter their previous connect status is on or off.

Parameter
 |

pinList

 |

The DPS pins to connect.

 |

## Examples

### Connect all pins

```
CONNECT_EX().force();
```

This example connects all the DPS pins in the sequence defined in the current primary set no matter their previous connect status is on or off.

### Connect the specified pins

```
CONNECT_EX().force("pinA, pinB");
```

This function connects the target DPS pins `pinA` and `pinB` in the sequence defined in the current primary set no matter their previous connect status is on or off.
