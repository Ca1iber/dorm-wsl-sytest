# DIGITAL_WAVEFORM.samplesPerBit()

This function specifies the number of sampling points for data retrieval in 1 UI. The default value is 1. You can specify a timing resolution or a number of sampling points per bit. If the timing resolution is specified afterwards, the number of sampling points per bit is overriden. If the range specified between `sampleSotp()` and `sampleStart()` is larger than the value of `samplesPerBit()`, the `sampleStop()` value will be corrected automatically to match the value of `samplesPerBit()`.

## Syntax

```
DIGITAL_WAVEFORM& samplesPerBit(INT samples)
```

Parameter
 |

samples

 |

The number of sampling points for data retrieval in 1 UI.

 |
