# GET_VALUE_RESULT

This function uploads the results and returns the measured values for the specified pin.

This API is deifined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ResultAccessor.h.

## Syntax

```
ARRAY_D GET_VALUE_RESULT( const STRING& singlePin );
```

Parameter
 |

singlePin

 |

The pin for which the result to be returned.

 |

## Example

```
ARRAY_D values = GET_VALUE_RESULT("pin1);
```

The above line returns the measured value of pin1.

## Functional changes

- Introduced in SmarTest 6.3.2
