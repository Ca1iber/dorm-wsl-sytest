# EVENT_VC.getVClampLow()

Reads the lower clamp voltage that has been defined by [EVENT_VC.vClampLow()](<02.07.04.01.63.20.01_EVENT_VC.vClampLow.md>).

The value is read from the corresponding [EVENT_VC](<02.07.04.01.63.20_EVENT_VC.md>) object and returned as an [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getVClampLow(EVENT_VALUE_DOUBLE & value) const;
```

Parameter
 | Parameter  | Description |
 | value |

The programmed lower clamp voltage in V (Volt).

 |

Return value

There is no return value.
