# DSP_SUB_VEC

This API is for subtracting two arrays.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_SUB_VEC(ARRAY_D& src1, ARRAY_D& src2,
            ARRAY_D& result);
DSP_SUB_VEC(DOUBLE *src1, DOUBLE *src2,
            DOUBLE *result, INT size);
DSP_SUB_VEC(ARRAY_COMPLEX& src1,
            ARRAY_COMPLEX& src2,
            ARRAY_COMPLEX& result);
DSP_SUB_VEC(COMPLEX *src1, COMPLEX *src2,
            COMPLEX *result, INT size);
```

## Example

```
COMPLEX array1[1024], array2[1024],
          array_diff[1024];
       .
       .
DSP_SUB_VEC(array1, array2, array_diff, 1024);
```

DSP_SUB_VEC subtracts the first 1024 elements of COMPLEX array array2 from the corresponding 1024 elements of COMPLEX array array1 , and returns the results to the corresponding 1024 elements of COMPLEX array array_diff  as follows:

```
int i;
     .
     .
for(i=0; i<1024; i++) {
  array_diff[i].real=array1[i].real-array2[i].real;
  array_diff[i].imag=array1[i].imag-array2[i].imag;
}
```
