# addParameterType

addParameterType() is used only in the [addParameterTypes()](<02.07.07.02.01_The_functions_of_the_customized_shmoo_test_method_template.md>) function, one of the provided functions in the [Customized shmoo test template](<02.07.07.02_Customized_shmoo_test_template.md>).

addParameterType() adds parameters to be varied for x-axis and y-axis in a shmoo test. The added parameters will become the options of [parameterType](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.02.01_The_parameters_for_the_x_y-axis_setups_for_a_shmoo_test.md>) which is a test method parameter of [ac_tml.AcTest.Shmoo](<02.07.05.01.09_Shmoo.md>).

## Syntax

```
addParameterType("parameterIdentifier","parameterType", &pValueObject)
```

List of parameters
 |

Parameter

 |

Description

 |
 |

parameterIdentifier

 |

The name of a parameter to be varied for x-axis and y-axis on a shmoo plot.

 |
 |

parameterType

 |

The parameter's data type. The available types are int and double.

 |
 |

pValueObject

 |

(optional) A pointer to an another defined variable whose data type is the same as the data type specified in parameterType.

 |

## Example

Define a variable which points to the "mVlotage" variable and will be varied for x-axis and y-axis on a shmoo plot.

```
double mVoltage;
addParameterType("param1","double",&mVoltage)
```
