# DIGITAL_WAVEFORM.execute()

This function executes the level search for each sampling point, uploads the data from hardware and then calculates the voltage value for all sampling points.

## Syntax

```
void execute()
```

## Functional changes

- Introduced before SmarTest 6.3.2
