# GET_USER_DOUBLE_NAMES

This API retrieves the names of all the user-defined DOUBLE type testflow variables and stores them in the parameter.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

## Syntax

```
void GET_USER_DOUBLE_NAMES(STRING_VECTOR &allnames);
```

Parameter
 |

allnames

 |

The names of all the double type testflow variables.

 |

## Example

```
STRING_VECTOR doubleVar;
int varSize;
GET_USER_DOUBLE_NAMES(doubleVar);
varSize =  doubleVar.size();
for(int i=0;i<varSize;i++)
{
  cout << doubleVar[i] <<endl;
}
```

## Functional changes

- Introduced in SmarTest 7.1.3
