# TESTSET().testnumber_default()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) creates a default test ID that is passed to any called method of [TEST()](<02.07.04.01.241_TEST.md>) when the [test_number_enable](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_test_number_enable>) testflow flag is enabled for storing in the [TestId](<../02.10_Data_Logging/02.10.01.06.05.60_TestIdAttrType.md>) EDL attribute.

If the limit defined in the [test table](<../02.10_Data_Logging/02.10.01.08.03_Working_with_test_tables.md>) is used, the default test number is the sum of the test number value defined in the test table and the test number value specified in the Flags area of the [Properties view](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.04_Testflow_Properties_view.md>).

If the test table is not used, the default test number is the sum of the test number value specified in the Limits area and the test number value specified in the Flags area of the [Properties view](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.04_Testflow_Properties_view.md>).

## Syntax

```
TESTSET & testnumber_default();
```

## Example

```
TestSet.testnumber_default();
```
