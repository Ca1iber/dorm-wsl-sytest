# RESULT_AREA_CONFIG_PINS.getErrorMapResultAreaSize()

This function returns the currently configured error map result area size in bytes.

## Syntax

```
INT getErrorMapResultAreaSize() const;
```

List of parameters

There are no parameters.

## Return value

This function returns the currently configured error map result area size in bytes.
