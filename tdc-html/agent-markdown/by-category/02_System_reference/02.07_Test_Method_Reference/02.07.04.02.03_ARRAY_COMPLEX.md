# ARRAY_COMPLEX

ARRAY_COMPLEX defines an array holding the COMPLEX type of data and defines the functions to access and process the data.

## Constructors

```
ARRAY_COMPLEX (INT size=0);
```

This constructs an object of ARRAY_COMPLEX with the specified fixed size. If a size larger than zero is specified, the memory for the specified number of elements is allocated and the array cannot be resized.

```
ARRAY_COMPLEX (const ARRAY_COMPLEX& array);
```

This constructs an unresizable object of ARRAY_COMPLEX by copying from another ARRAY_COMPLEX object.

```
ARRAY_COMPLEX (const ARRAY_D& real, const ARRAY_D& imag);
```

This constructs an unresizable object of ARRAY_COMPLEX by copying the elements of two ARRAY_D objects.

```
ARRAY_COMPLEX (const ARRAY_COMPLEX& array, INT size, INT offset= 0);
```

This constructs an unresizable object of ARRAY_COMPLEX by sharing the specified elements from another ARRAY_COMPLEX object.

```
ARRAY_COMPLEX (COMPLEX* array, INT size, INT offset= 0);
```

This constructs an unresizable object of ARRAY_COMPLEX by sharing the specified elements from a COMPLEX array.

Parameters
 |

array

 |

The array to copy from.

 |
 |

size

 |

Size of the new ARRAY_COMPLEX object

 |
 |

offset

 |

(optional) Starting point in the original array where to begin copying the elements.

 |
 |

real

 |

The array to be used as real part of the complex array

 |
 |

imag

 |

The array to be used as imaginary part of the complex array

 |

## Member functions

### init()

```
void init (COMPLEX initValue= 0.0);
```

This function fills the array elements with the specified value.

Parameter
 |

initValue

 |

Value with which to fill the array. Default is 0.0.

 |

### resize()

```
INT resize (INT size);
```

This function changes the size of the array if it is resizable and keeps its data.

Parameter
 |

size

 |

New size of the array

 |

### resizeNoKeep()

```
INT resizeNoKeep(INT size);
```

This function changes the size of an array if it is resizable and delets its data.

Parameter
 |

size

 |

New size of the array

 |

### size()

```
const INT size () const;
```

This function returns the size of the array.

### capacity()

```
const INT capacity();
```

This function returns the memory size allocated to the array.

### getReal()

```
const ARRAY_D getReal() const;
```

This function returns the real part of the complex array.

### getImag()

```
const ARRAY_D getImag() const;
```

This function returns the imaginary part of the complex array.

### operator =

```
ARRAY_COMPLEX& operator = (const ARRAY_COMPLEX& array);
```

This function copies all the elements of the specified array to the current array and changes its size.

Parameter
 |

array

 |

The array to copy from

 |

### operator []

```
COMPLEX& operator [] (const INT index);
const COMPLEX& operator [] (const INT index) const;
```

These functions access the specified element in the array.

Parameter
 |

index

 |

Index of the element to access

 |

### operator COMPLEX*

```
operator const COMPLEX* () const;
```

This operator converts the data type from ARRAY_COMPLEX to COMPLEX*.

## Example

```
ARRAY_D a_d1(1024), a_d2(1024);
ARRAY_COMPLEX cmpWave(a_d1,a_d2);
```

...

```
ARRAY_D real_array = cmpWave.getReal();
ARRAY_D imag_array = cmpWave.getImag();
```

The ARRAY_COMPLEX object `cmpWave` is defined with two ARRAY_D objects `a_d1` and `a_d2`. At last the real part and imaginary part of `cmpWave` are retrieved separately.
