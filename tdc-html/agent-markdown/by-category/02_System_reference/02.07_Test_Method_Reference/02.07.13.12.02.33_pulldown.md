# pulldown()

Enables or disables the pull‑down circuit after disconnect.

This function can be used only in the [code‑based mode](<02.07.13_SmartRDI.md#_142069__dle_Code-based_mode>).

This function supports only [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) in the [PMU operating mode](<../02.05_Test_Head_Cards/02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md>).

The setting of the pull‑down circuit applies only to the current [RDI command](<02.07.13.05_Code_structure_with_SmartRDI.md#_142604__dle_RDI_command>).

## Syntax

```
dcBase& pulldown(TA::PULLDOWN_MODE mode);
```

  Parameter

 | Parameter  | Description |
 | mode |

The pull‑down mode of type TA::PULLDOWN_MODE to be set.

 Supported values:

- TA::PULLDOWN_ON
- TA::PULLDOWN_OFF

Default value for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) is TA::PULLDOWN_ON.

   |   Return Value A reference to the dcBase object.

## Example

```
rdi.dc().pin("XPS256_PMU_1").iForceRange(50 mA).iForce(5.0 mA).vClamp(-5.0, 5.0 V).pulldown(TA::PULLDOWN_ON).execute();
```
