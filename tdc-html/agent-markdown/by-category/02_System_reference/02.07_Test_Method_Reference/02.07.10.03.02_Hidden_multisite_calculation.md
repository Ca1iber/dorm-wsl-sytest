# Hidden multisite calculation

SmartCalc provides support for hidden (parallel) calculation of multisite data.

 Note All test times shown are examples.  ![Hidden multisite calculations](<../../../../raw/118897.png>)

In the figure above, compared to the original structure in [SmartCalc use models](<02.07.10.03_SmartCalc_use_models.md>), the overall test time will be reduced by 60 % resulting in a multisite efficiency around 90 %.

## Functional changes

- Introduced in SmarTest 6.5.3
