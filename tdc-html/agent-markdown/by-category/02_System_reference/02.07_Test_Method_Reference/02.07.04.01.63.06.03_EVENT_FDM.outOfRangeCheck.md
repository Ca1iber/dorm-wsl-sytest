# EVENT_FDM.outOfRangeCheck()

Enables or disables the out-of-range check. Per default this check is enabled. If the check is enabled and the measurement range is exceeded, the event contributes with a FAIL to the global test result.

## Syntax

```
EVENT_FDM & outOfRangeCheck(bool failOnOutOfRange = true);
```

  Parameter

 | Parameter  | Description |
 | failOnOutOfRange |

Enables or disables the out-of-range check.

- true: The out-of-range check is enabled
- false: The out-of-range check is disabled

Default value: true

  |  Return value A reference to the corresponding [EVENT_FDM](<02.07.04.01.63.06_EVENT_FDM.md>) object.
