# Aborting Test Running

To abort test running, you can use the ABORT_TEST API. For details, see [ABORT_TEST](<02.07.04.01.01_ABORT_TEST.md>).

The APIs that execute a test (except the START_TEST API) is usually programmed so that it waits at least until the digital sequencer stops.

If you skip waiting that the AWG sequencers stop in a test, stop the AWGs by executing the ABORT_TEST API after the API that executes a test.
