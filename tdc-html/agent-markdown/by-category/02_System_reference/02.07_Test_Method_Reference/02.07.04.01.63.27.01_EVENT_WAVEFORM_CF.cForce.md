# EVENT_WAVEFORM_CF.cForce()

Sets the force current waveform as [ANALOG_WAVEFORM](<02.07.04.01.05_ANALOG_WAVEFORM.md>).

## Syntax

```
EVENT_WAVEFORM_CF & cForce (ANALOG_WAVEFORM & waveform);
```

  Parameters

 | Parameter  | Description |
 | waveform |

Defines the waveform to be set in A (Ampere).

  |   Return value A reference to the corresponding [EVENT_WAVEFORM_CF](<02.07.04.01.63.27_EVENT_WAVEFORM_CF.md>) object.
