# add()

Adds two state character sequences which must be convertible to integer values.

The resulting state character sequence represents the arithmetic sum of both parameters. The length of the result is at least the same length as the longer parameter. If an overflow occurs the length of the resulting sequence is extended accordingly.

Note It is not sufficient that each individual parameter is convertible to integer! Both parameters must use the same coding ('L'/'H' or '0'/'1').

If an exact length of the result is required and the overflow should be ignored, you need to apply the tail function to the result.

Errors will be issued if,

- a parameter is not convertible to integer or
- parameter coding is inconsistent.

## Syntax

```
integer :=add(integer1,integer2)
```

## Example

add`("001", "001")` results in "010".

add`("1", "100")` results in "101".

add`("100", "1")` results in "101".

add`("LH", "HHL")` results in "HHH".

add`("111", "1")` results in "1000", which reflects an allowed overflow.

add`("", "1")` results in "ERROR: "" is no valid number."

add`("LLH", "HHZ")` results in "ERROR: "HHZ" is not convertible to integer."

add`("001", "LLH")` results in "ERROR: inconsistent coding."
