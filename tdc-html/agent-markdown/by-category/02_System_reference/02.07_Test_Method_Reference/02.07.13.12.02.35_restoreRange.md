# restoreRange()

Restores the very first current measurement range specified in the [RDI_BEGIN()](<02.07.13.08.01.04_RDI_BEGIN.md>) ... RDI_END() block.

The function is to be used to restore the current range after an auto-ranging current measurement.

Supported only by [DC Scale DPS128/DPS64 cards](<../02.05_Test_Head_Cards/02.05.05.01_DC_Scale_DPS128_DPS64_cards.md>) and the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>). The function can be used only in the pattern‑based mode.

## Syntax

```
dcBase& restoreRange();
```

## Return Value

A reference to the dcBase object.

## Example

```
RDI_BEGIN();

    rdi.dc().pin("DSP128_1").iMeas().execute();
    rdi.dc().pin("DSP128_1").restoreRange().execute();

RDI_END();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
- SmartRDI 2.4.2: DC Scale AVI64 card added.
- SmartRDI 7.5.0: DC Scale FVI16 card added.
- SmartRDI 7.10.1: DC Scale XPS256 card added.
