# DSP_ABS_MINMAX

This API searches for the minimum and maximum absolute value of the elements in a specified array and returns the actual values and their DC/DC power units.

If any of these maximum or minimum absolute values occur more than once, the lowest relative subscript for the value is returned to min_index and max_index.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_ABS_MINMAX(ARRAY_I& src, INT *min, INT *max,
 INT *min_index, INT *max_index);
DSP_ABS_MINMAX(INT *src, INT *min, INT *max,
 INT *min_index, INT *max_index,
 INT size);
DSP_ABS_MINMAX(ARRAY_D& src, DOUBLE *min,
 DOUBLE *max, INT *min_index,
 INT *max_index);
DSP_ABS_MINMAX(DOUBLE *src, DOUBLE *min, DOUBLE *max,
 INT *min_index, INT *max_index,
 INT size);
```

## Example

```
ARRAY_D array1;
double min,max;
int minindex,maxindex;
 .
 .
DSP_ABS_MINMAX(array1, &min, &max, &minindex, &maxindex, 60);
```

This example searches for the minimum and maximum absolute value among the 60 elements in the array array1, then returns the original values to min and max and returns the corresponding relative subscripts to minindex and maxindex.
