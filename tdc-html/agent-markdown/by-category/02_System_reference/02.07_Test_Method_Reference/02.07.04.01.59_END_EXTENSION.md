# END_EXTENSION

This API declares the end of the extension block that is started by BEGIN_EXTENSION. This API is used together with BEGIN_EXTENSION as a pair to declare the extension block.

For details on the extension block enclosed by BEGIN_EXTENSION and END_EXTENSION, see [BEGIN_EXTENSION](<02.07.04.01.10_BEGIN_EXTENSION.md>).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Extension.h.

## Syntax

```
void END_EXTENSION();
```

List of parameters

There are no parameters.

See the Examples section of [BEGIN_EXTENSION](<02.07.04.01.10_BEGIN_EXTENSION.md>).
