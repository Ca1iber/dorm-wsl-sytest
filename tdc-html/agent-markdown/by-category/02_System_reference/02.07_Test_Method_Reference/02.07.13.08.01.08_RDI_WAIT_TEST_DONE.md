# RDI_WAIT_TEST_DONE()

Aligns the end of a non-blocking pattern execution started by [RDI_END(TA::NON_BLOCKING)](<02.07.13.08.01.05_RDI_END.md>).

If not specified, the `RDI_BEGIN/RDN_END()` block is executed in the blocking mode, which means no other jobs can be executed while the pattern is running.

The non-blocking execution mode is supported by:

- The TA::NON_BLOCKING option in [RDI_END()](<02.07.13.08.01.05_RDI_END.md>) to start the non-blocking execution;
- `RDI_WAIT_TEST_DONE()` to align the end of the pattern execution.

## Syntax

```
RDI_WAIT_TEST_DONE();
```

## Example

```
RDI_BEGIN();
    ...
RDI_END(TA::NON_BLOCKING);    //Non-blocking execution starts.

...    //actions during pattern execution

RDI_WAIT_TEST_DONE();    //Non-blocking execution ends.
```
