# EVENT_WAVEFORM_CFVM.getRepeatCount()

Reads the number of repeats of the waveform that has been defined by [EVENT_WAVEFORM_CFVM.cForce()](<02.07.04.01.63.29.01_EVENT_WAVEFORM_CFVM.cForce.md>).

The number of repeats is read from the corresponding [EVENT_WAVEFORM_CFVM](<02.07.04.01.63.29_EVENT_WAVEFORM_CFVM.md>) object and returned as an integer value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getRepeatCount(INT & repeats) const;
```

Parameter
 | Parameter  | Description |
 | repeats |

The read repeat count.

Note: The member function getRepeatCount() of DC events returns always 1 as repeat count.

 |

Return value

There is no return value.
