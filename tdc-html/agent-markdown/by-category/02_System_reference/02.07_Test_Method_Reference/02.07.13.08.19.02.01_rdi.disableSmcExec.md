# rdi.disableSmcExec()

Disables the SmartCalc (SMC) execution for the following RDI blocks.

When the SmartCalc (SMC) execution is disabled, SmartRDI replaces calls of the SmartCalc wrapper APIs with calls of the related standard test method APIs. For more information, refer to [Wrapper APIs to control hidden upload in threads](<02.07.10.04.02_SmartCalc_API_overview.md#_118901__s_Wrapper_APIs>) in [SmartCalc API overview](<02.07.10.04.02_SmartCalc_API_overview.md>).

The SMC execution is enabled by default.

## Syntax

```
void disableSmcExec();
```

  List of parameters There are no parameters. Return value There is no return value. Using the function The function can be accessed only via the main SmartRDI class rdi.

## Example

```
rdi.disableSmcExec();
```
