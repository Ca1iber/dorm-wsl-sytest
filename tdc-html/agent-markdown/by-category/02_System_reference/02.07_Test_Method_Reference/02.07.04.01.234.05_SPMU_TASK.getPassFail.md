# SPMU_TASK.getPassFail()

Returns either a global or a pin specific pass/fail result of a DC measurement.

 Note If no pinlist is passed to this function, it returns the global pass/fail result.Note Apply the corresponding mode with [SPMU_TASK.execMode()](<02.07.04.01.234.02_SPMU_TASK.execMode.md>) to retrieve global or per pin results.

## Syntax

```
Boolean getPassFail() const;
Boolean getPassFail(const STRING& pinlist) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

pinlist

 |

List of pins for which the a per pin pass/fail result should be retrieved.

 |

Return Value

Returns a Boolean true for pass or false for fail result of the measurement.
