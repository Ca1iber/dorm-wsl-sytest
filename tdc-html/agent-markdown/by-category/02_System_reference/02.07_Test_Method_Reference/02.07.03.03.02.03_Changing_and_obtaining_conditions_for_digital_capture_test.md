# Changing and obtaining conditions for digital capture test

To change the conditions used for capturing digital data, use the VECTOR API.

```
VECTOR(vectorVarLabel).<memberFunction_1>.<memberFunction_2>. ... .<memberFunction_N>;
```

where, <memberFunction_1> to <memberFunction_N> mean the member functions of the [VECTOR](<02.07.04.01.269_VECTOR.md>) API. For changing conditions, you can describe multiple member functions. For obtaining a parameter value, you can describe only one member function per statement.

The following member functions are available for changing the particular condition:

 | The task to be executed  | <memberFunction_#> for ... |
 | ... changing a condition  | 鈥?obtaining a condition |
 | Encode format  | [format()](<02.07.04.01.269_VECTOR.md#_29830__dle_format>)  | [getFormat()](<02.07.04.01.269_VECTOR.md#_29830__dle_getFormat>) |
 | Set the input mode of the code to be applied to the device  | [inputMode()](<02.07.04.01.269_VECTOR.md#_29830__dle_inputMode>)  | [getInputMode()](<02.07.04.01.269_VECTOR.md#_29830__dle_getInputMode>) |
 | Set the byte order of device  | [byteOrder()](<02.07.04.01.269_VECTOR.md#_29830__dle_byteOrder>)  | [getByteOrder()](<02.07.04.01.269_VECTOR.md#_29830__dle_getByteOrder>) |
 | Set the data bit width  | [bits()](<02.07.04.01.269_VECTOR.md#_29830__dle_bits>)  | [getBits()](<02.07.04.01.269_VECTOR.md#_29830__dle_getBits>) |
 | Set the data offset  | [offset()](<02.07.04.01.269_VECTOR.md#_29830__dle_offset>)  | [getOffset()](<02.07.04.01.269_VECTOR.md#_29830__dle_getOffset>) |
