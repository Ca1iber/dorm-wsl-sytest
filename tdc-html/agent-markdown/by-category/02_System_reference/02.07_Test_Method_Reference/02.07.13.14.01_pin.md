# pin()

Specifies one or more digital pins to switch relays.

## Syntax

```
pin(const string& sPin);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

sPin

 |

One or more digital pin names.

For more pin names, separate them with comma.

 |

## Example

```
rdi.hwRelay().pin("pinA").setOn("DC,AC").setOff("PPMU").execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
