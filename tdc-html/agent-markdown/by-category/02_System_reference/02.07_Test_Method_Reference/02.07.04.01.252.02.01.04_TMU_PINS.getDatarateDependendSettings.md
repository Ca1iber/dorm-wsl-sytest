# TMU_PINS.getDatarateDependendSettings()

 Retrieves the datarate dependent configuration data, the prescaler and the interdiscard.

## Syntax

```
TMU_PINS& getDatarateDependendSettings(TMU::DATARATE_DEPENDENT_VALUES_TYPE& settings);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

settings

 |

DATA_RATE_DEPENDENT_VALUES_TYPE is a data structure designed to receive the calculated values for the prescaler (prescaler member) and the interdiscard (Interdiscard member).

 |

## Return value

A reference to the TMU_PINS object is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
