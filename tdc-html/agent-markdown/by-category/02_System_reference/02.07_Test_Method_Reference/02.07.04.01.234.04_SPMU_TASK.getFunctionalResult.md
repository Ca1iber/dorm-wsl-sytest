# SPMU_TASK.getFunctionalResult()

Returns either a global or a pin specific pass/fail result of a functional test that had been executed based on the corresponding setting of [SPMU_TASK.preAction()](<02.07.04.01.234.08_SPMU_TASK.preAction.md>).

## Syntax

```
Boolean getFunctionalResult() const;
Boolean getFunctionalResult(const STRING& pinlist) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

pinlist

 |

List of pins for which per pin pass/fail result should be retrieved.

   | Note Apply the corresponding mode with [SPMU_TASK.execMode()](<02.07.04.01.234.02_SPMU_TASK.execMode.md>) to retrieve per pin value results.

Return Value

Returns a Boolean true for pass or false for fail result of the measurement.
