The source files of the DC test methods are included in the file /opt/hp93000/soc/testmethod/library/dc_tml.zip. The following DC Test Methods are included in the predefined class source files:

- continuity - checks for connectivity and short circuits on the DUT and the DUT interface.
- dpsConnectivity - checks that the force and sense wires of the DPS are connected properly on the DUT board.
- dpsStatus - provides status information about DPS pins.
- DVM - measures the voltage at any pin.
- generalPMU - allows direct control of the Parametric Measurement Unit (PMU) in order to force a voltage (and measure current) or force a current (and measure voltage).
- highZ - measures the leakage current of outputs in high-z condition.
- leakage - measures the leakage current on DUT pins.
- operatingCurrent - measures the active operating current of the DUT.
- outputDC - measures the output voltage of the DUT under specific current load conditions.
- productionIddq - measures the quiescent power supply current of the DUT.
- StandbyCurrent - measures the standby current of the DUT.
