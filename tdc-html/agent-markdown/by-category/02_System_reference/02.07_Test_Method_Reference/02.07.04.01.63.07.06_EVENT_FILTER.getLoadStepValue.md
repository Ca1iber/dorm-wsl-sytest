# EVENT_FILTER.getLoadStepValue()

Queries the load step value set by [EVENT_FILTER.setLoadStepValue()](<02.07.04.01.63.07.05_EVENT_FILTER.setLoadStepValue.md>).

## Syntax

```
void getLoadStepValue(TM::LOADSTEP_VALUE &value) const;
```

  Parameter

List of parameters
 | Parameter  | Description |
 | value |

The load step mode value that has been set by [EVENT_FILTER.setLoadStepValue()](<02.07.04.01.63.07.05_EVENT_FILTER.setLoadStepValue.md>).

   |   Return value There is no return value.

[EVENT_FILTER.setLoadStepValue()](<02.07.04.01.63.07.05_EVENT_FILTER.setLoadStepValue.md>)
