# pin()

Specifies the pin to do the digital capture.

## Syntax

```
pin(const string& sPin);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

sPin

 |

The digital capture pin.

 |

## Example

```
rdi.digCap("cap").pin("DO").samples(100).execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
