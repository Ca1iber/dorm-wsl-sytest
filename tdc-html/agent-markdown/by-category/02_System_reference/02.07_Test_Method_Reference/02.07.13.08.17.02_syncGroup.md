# syncGroup()

`syncGroup()` specifies a synchronization group (sync group) for one or more ports.

## Syntax

```
syncGroup(string syncGroup)
```

## Example

```
rdi.syncGroup("sg1").addPort("ptA");
rdi.syncGroup("sg2").addPort("ptB").addPort("ptC");

RDI_BEGIN();
  rdi.port("ptA")...
  rdi.port("ptB")...
  rdi.port("ptC")...
RDI_END();
```
