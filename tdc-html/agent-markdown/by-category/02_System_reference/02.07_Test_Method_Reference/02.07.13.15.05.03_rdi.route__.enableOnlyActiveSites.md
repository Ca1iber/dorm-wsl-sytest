# rdi.route().enableOnlyActiveSites()

Enables the utility line settings on active sites and disables them on inactive sites.

Usage of the function:

- To ensure the site masks are correctly set, this API must be called at the beginning of a testflow when the testflow is executed for each time.
- The function can be called only in the code‑based mode. For more information, refer to [Execution mode](<02.07.13_SmartRDI.md#_142069__s_Execution_mode>) in topic [SmartRDI](<02.07.13_SmartRDI.md>).
- The function can work together with [FOR_SEMI_PARALLEL_TEST_BEGIN](<02.07.04.01.73_FOR_SEMI_PARALLEL_TEST_BEGIN.md>)/[FOR_SEMI_PARALLEL_TEST_END](<02.07.04.01.74_FOR_SEMI_PARALLEL_TEST_END.md>) to set different utility relay states on different sites. See the [example](<02.07.13.15.05.03_rdi.route__.enableOnlyActiveSites.md#_345122__set_diff_states_on_sites>) below.
 Note This function only affects states that have been defined by the [Routing Tools editors](<02.07.13.15.01_Routing_Tools_editors.md>). The function has no effect on the manipulation of utility lines by [rdi.route().pin()](<02.07.13.15.05.05_rdi.route__.pin.md>).

## Syntax

```
routeGroup& enableOnlyActiveSites();
```

  Note Although this command must not be called inside of an [RDI block](<02.07.13.05_Code_structure_with_SmartRDI.md#_142604__dle_RDI_block>), it generates and executes a pattern and thus can be called with port().  List of parameters There are no parameters. Return value A reference to the [routeGroup](<02.07.13.15.05_rdi.route.md>) object.

## Examples

```
rdi.route().enableOnlyActiveSites().execute();
rdi.port("RouteCtrlPort").route().enableOnlyActiveSites().execute(); // The port "RouteCtrlPort" includes UTIL digital control pins.
```

   Setting different utility relay states on different sites in [FOR_SEMI_PARALLEL_TEST_BEGIN](<02.07.04.01.73_FOR_SEMI_PARALLEL_TEST_BEGIN.md>)/[FOR_SEMI_PARALLEL_TEST_END](<02.07.04.01.74_FOR_SEMI_PARALLEL_TEST_END.md>):

```
...
FOR_SEMI_PARALLEL_TEST_BEGIN();
  If(GET_CURRENT_SEMI_PARALLEL_GROUP_NUMBER()==1)  // For example, site 1, 3 active
  {
    rdi.route().enableOnlyActiveSite().execute();  // Mask site 2, 4
    rdi.route().applyState("s1").execute();        // "s1" will apply on site 1, 3
    rdi.route().pin("pin1").setOn().execute();     // pin1 will setOn on site 1, 3
  }
  else  // For example, site 2, 4 active
  {
    rdi.route().enableOnlyActiveSite().execute();  // Mask site 1, 3
    rdi.route().applyState("s2").execute();        // "s2" will apply on site 2, 4
    rdi.route().pin("pin2").setOn().execute();     // pin2 will setOn on site 2, 4
  }
FOR_SEMI_PARALLEL_TEST_END();

rdi.route().enableOnlyActiveSite().execute();      // Unmask all active sites
```
