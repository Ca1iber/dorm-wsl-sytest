# Setting up the Register Access library

#### Subtopics

- [Register structure](<02.07.13.08.12.01.01_Register_structure.md>)
- [Importing a C++ register structure](<02.07.13.08.12.01.02_Importing_a_C___register_structure.md>)

The Register Access library needs to be set up before it can be used to execute register operations in a test method project.

## About this task

Two required steps are introduced for setting up the Register Access library.

## Procedure

-  Set up a protocol for register access. See [Protocol management](<02.07.13.08.12.02_Protocol_management.md>) for detailed information.
-  (Optional) Import the register structure of a device. See [Register structure](<02.07.13.08.12.01.01_Register_structure.md>) and [Importing a C++ register structure](<02.07.13.08.12.01.02_Importing_a_C___register_structure.md>).

## Results

The Register Access library is ready to be used in test methods.

## What to do next

Use the library's member functions in your test method.

## Functional changes

- Introduced in SmartRDI 7.6.0
