# Automatic masking on inactive sites

SmartRDI provides an INACTIVE_SITE_AUTO_MASK flag in the RDI_Configure file to enable automatic masking on all inactive sites for a test suite. Its default state is FALSE.

If you set INACTIVE_SITE_AUTO_MASK = TRUE, all inactive sites will be masked and remain in a hold state. A dummy label will be executed on the inactive sites. For active sites, their normal labels will be executed.

Results can only be retrieved from the unmasked sites.

 For example, assuming: there are four sites: sites 1, 3, and 4 are active; site 2 is inactive; INACTIVE_SITE_AUTO_MASK = TRUE is set in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>). For the following code:

```
RDI_BEGIN();
  rdi.smartVec("id1").pin("pinA").writeData()
                     .pin("pinB").readData()
                     .execute();

rdi.emap("id2").pin()....execute();

RDI_END();
```

Normal burst labels will be executed on sites 1, 3, and 4; a dummy label will be executed on site 2.

RDI provides assignLabelOnInactiveSites() to specify a dummy label for masked inactive sites. Its syntax is rdi.assignLabelOnInactiveSites("label","port"). The default port is "@".

## Key attention points

INACTIVE_SITE_AUTO_MASK = TRUE does not support:

- [Hidden upload](<02.07.13.08.19.01_Using_hidden_upload_with_SmartRDI.md>).
- [digCap immediate upload](<02.07.13.13.03_Using_Immediate_Upload_in_SmartRDI.md>).
- [Register access](<02.07.13.08.12_Register_Access_library.md>).
- [FAST_PPMU_LEVEL_TRANSFER](<02.07.13.04_RDI_Configure_file.md#_146692__row_FAST_PPMU_LEVEL_TRANSFER>).
- [func.burstRunTime()](<02.07.13.17.01.03_rdi.func__.burstRunTime.md>).
- [DIGCAP_BURST_SITE_UPLOAD](<02.07.13.04_RDI_Configure_file.md#_146692__row_DIGCAP_BURST_SITE_UPLOAD>).

INACTIVE_SITE_AUTO_MASK = TRUE while shared pins used in any RDI block:

- [combinedFailCount()](<02.07.13.16.01_combinedFailCount.md>) cannot retrieve results for shared pins.
- Do not use protocol and cogo actions in the RDI block.
   rdi.setOnHoldSites():

- Do not use rdi.setOnHoldSites() with [func().labelRunTime()](<02.07.13.17.01.06_rdi.func__.labelRunTime.md>) together.

## Example

### Defining a dummy label for inactive sites

```
rdi.assignLabelOnInactiveSites("userlabel","pt1");

RDI_BEGIN();
  rdi.port("pt1")....execute();  // For pt1, use a user label.
  rdi.port("pt2")....execute();  // For pt2, run a dummy label created by RDI.
RDI_END()
```
