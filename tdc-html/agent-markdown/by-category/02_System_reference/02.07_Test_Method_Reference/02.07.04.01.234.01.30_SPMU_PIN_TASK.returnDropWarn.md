# SPMU_PIN_TASK.returnDropWarn()

Set the warning threshold for the return line.

The voltage drop is measured from the common ground (GND) to the ground sense pogo pin (GS#). The measured voltage drop depends on the actual current and the impedance of the connection to the DUT. The continuously measured voltage drop is compared against the warning threshold, and should pin exceeds the programmed limit, an alarm flag is raised.

This member function is similar to [SPMU_PIN_TASK.returnDropMax()](<02.07.04.01.234.01.29_SPMU_PIN_TASK.returnDropMax.md>), which sets the return voltage drop for disconnect.

This function is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

## Syntax

```
SPMU_PIN_TASK & returnDropWarn(DOUBLE returnDropWarn);
```

 Parameter

 | Parameter  | Description |
 | returnDropWarn |

The warning threshold in millivolt (mV) to be set.

A positive voltage has to be set regardless of the polarity of the actual or programmed current.

For the valid range refer to [Voltage drop protection / measurement](<../02.02_Specifications/02.02.05.03.07_XPS256_other_performance_characteristics.md#_350739__s_Voltage_drop_protection>) in [XPS256 other performance characteristics](<../02.02_Specifications/02.02.05.03.07_XPS256_other_performance_characteristics.md>)

   |   Return value A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.
