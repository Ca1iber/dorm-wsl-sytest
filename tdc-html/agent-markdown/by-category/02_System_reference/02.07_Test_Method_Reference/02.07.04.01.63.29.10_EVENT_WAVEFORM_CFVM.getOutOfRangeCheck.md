# EVENT_WAVEFORM_CFVM.getOutOfRangeCheck()

Reads the state of the out-of-range check that has been defined by [EVENT_WAVEFORM_CFVM.outOfRangeCheck()](<02.07.04.01.63.29.09_EVENT_WAVEFORM_CFVM.outOfRangeCheck.md>).

The state is read from the corresponding [EVENT_WAVEFORM_CFVM](<02.07.04.01.63.29_EVENT_WAVEFORM_CFVM.md>) object and returned as a bool value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getOutOfRangeCheck(bool & value) const;
```

Parameter
 | Parameter  | Description |
 | value |

The programmed value true or false of the out-of-range check.

- true: The out-of-range check is enabled
- false: The out-of-range check is disabled
 |

Return value

There is no return value.
