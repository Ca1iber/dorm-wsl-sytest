# SMC_PIN_ERROR_MAP.setUploadChunkSize()

Sets the raw error map upload chunk size.

## Syntax

```
SMC_PIN_ERROR_MAP& setUploadChunkSize(const LONG chunkSize);
```

Parameter
 |

Parameter

 |

Description

 |
 |

chunkSize

 |

Defines the chunk size used for uploading raw error map data. The default chunk size is 512 KB.

 |

Return value

There is no return value.
