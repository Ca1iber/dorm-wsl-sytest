# port()

Specifies a port to set up.

  Note All pins defined in calls of the pin() function must be a member of the specified port. Otherwise an error message is issued.

## Syntax

```
port(const string& sPort);
```

Parameter List
 |

Parameter

 |

Description

 |
 |

sPort

 |

The port name.

 |

## Example

```
rdi.port("ptDATA_half1").func().label("funcPass_half1").execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
