# EVENT_IC.iClampHigh()

Sets the high clamp current value.

You can specify both the low and high clamp current values or just one.

## Syntax

```
EVENT_IC & iClampHigh ( const EVENT_VALUE_DOUBLE & value );
```

Parameter
 | Parameter  | Description |
 | value |

High clamp current

 |

Return value

There is no return value.
