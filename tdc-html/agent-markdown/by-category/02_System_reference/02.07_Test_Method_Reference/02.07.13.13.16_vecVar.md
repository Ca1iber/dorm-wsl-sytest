# vecVar()

Specifies a user-defined vector variable.

The vector variable specified by this function must already exist in the user pattern.

You can use multiple vecVar() for a label. See the example below.

Use [rdi.id().getVectorFromVV()](<02.07.13.13.20_rdi.id__.getVectorFromVV.md>) to retrieve results from specified vector variables.

## Syntax

```
vecVar(string);
```

## Example

```
RDI_BEGIN();
  rdi.digCap("id").label("userLabel").vecVar("vvName1").vecVar("vvName2").execute();
RDI_END(); // "vvName1" and "vvName2" must already exist in the user pattern.

ARRAY_I ary = rdi.id("id").getVectorFromVV("vvName1");
ARRAY_I ary2 = rdi.id("id").getVectorFromVV("vvName2");
```
