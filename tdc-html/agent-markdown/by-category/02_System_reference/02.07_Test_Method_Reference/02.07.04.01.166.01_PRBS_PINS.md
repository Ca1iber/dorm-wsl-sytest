# PRBS_PINS

`PRBS_PINS` class is used to configure the PRBS properties for individual pins. It is a sub-class of PRBS_SET. You cannot directly create an object with it.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PRBS_PINS.h.

## Class definition

### Member functions

```
PRBS_PINS& polynomial(const STRING& ipolynomial);
PRBS_PINS& seed(const STRING& iseed);
STRING getPolynomial();
STRING getSeed();
void setToDefault()const;
```

## Member functions

### polynomial()

```
PRBS_PINS& polynomial(const std::string& ipolynomial);
```

This function sets the polynomial used to generate PRBS.

Parameter
 |

polynomial

 |

The polynomial to generate PRBS. It is a bit string. The constant term of the polynomial, which is always 1, must be omitted. The last bit is supposed to determine the degree `n` of the polynomial. Therefore, the length of the string must be `n`, and its last bit must be "1". (Refer to [PRCF, PRCF? - (Pseudo Random bit sequence ConFiguration)](<../02.06_Command_Reference/02.06.02.02.181_PRCF__PRCF__-__Pseudo_Random_bit_sequence_ConFiguration.md>).)

 |

### seed()

```
PRBS_PINS&  seed(const STRING& iseed);
```

This function sets the initial state for the PRBS generator.

Parameter
 |

iseed

 |

The initial state.

 |

### getPolynomial()

```
STRING getPolynomial();
```

This function returns the polynomial used to generate PRBS.

### getSeed()

```
STRING getSeed();
```

This function returns the initial state of the PRBS generator.

Note getPolynomial() and `getSeed()` can only return one value. This means one result value for one pin or the same value for multiple pins. Therefore if the container refers to multiple pins, it is expected that these pin have the same result. If there are different results for multiple pins, an exception `TESTMETHOD_API::AmbiguityException` will be issued.

### setToDefault()

```
void setToDefault()const;
```

This function sets the polynomial and seed to default setting.

## Examples

### Configure a PRBS test

The following example shows how to configure a PRBS test. In the example, there are two pin groups `Tx` and `Rx` defined, containing two pins Tx1, Tx2 and Rx1, Rx2 respectively.

```
//
// Create a PRBS set
//
PRBS_SET prbsSet1("PRBS_7_BER3");

//
// Configure parameters common for all pins
//
prbsSet1.pin("Tx,Rx").polynomial("0000011");

//
// Configure parameters for individual Rx pins, different seeds for each pin
//
prbsSet1.pin("Rx1").seed("1111000");
prbsSet1.pin("Rx2").seed("0000111");

//
// Create another set
//
PRBS_SET prbsSet2("PRBS_31_BER3");

//
// Configure
//
prbsSet2.pin("Tx,Rx").polynomial("0000000000000000000000000001001");
prbsSet2.pin("Rx1").seed("1111100000111110000011111000001");
prbsSet2.pin("Rx2").seed("0010010110111100010100000000011");

//
// Create and configure the PRBS label
//
prbsSet1.label("prbs_label_rx","@").length(125);
prbsSet2.label("prbs_label_tx","@").length(10000000).delay(125);
```

### Access the PRBS sets

The following example shows how to access the PRBS sets defined in the example above. PRBS sets are kept in firmware and their lifetime does not correspond to the lifetime of the PRBS_SET object.

```
//
// Access the set defined in test method A
//
PRBS_SET mySet("PRBS_7_BER3");

//
// Modify only the polynomial for pin Rx1
//
mySet.pin("Rx1").polynomial("1001001");

```
