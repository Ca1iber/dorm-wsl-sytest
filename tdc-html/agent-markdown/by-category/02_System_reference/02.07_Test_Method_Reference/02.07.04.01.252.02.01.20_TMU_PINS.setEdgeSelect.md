# TMU_PINS.setEdgeSelect()

Sets the edge type that triggers the event.

If the edge type is changed when data rate is specified, the values of prescaler and discarded events between measurements will be recalculated.

## Syntax

```
TMU_PINS& setEdgeSelect(TMU::EdgeType edgeselect);
TMU_PINS& setEdgeSelect(TMU::EdgeType edgeselect, TMU::DATARATE_DEPENDENT_VALUES_TYPE& settings);
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

edgeselect

 |

The edge type to trigger the event. It can be

- RISE: rising edge
- FALL: falling edge
- RISE_FALL: alternate rising and falling edges. This option is used for pulse and jitter measurements.

In this case, the [prescaler](<02.07.04.01.252.02.01.27_TMU_PINS.setPreScaler.md>) must be set to a value > 1 and < 17. Moreover, if an [event discard](<02.07.04.01.252.02.01.21_TMU_PINS.setInitialDiscard.md>) is specified, it must be even (including 0). For conceptual information about the operation mode of the TMU with this option, see example [Example 2: Pulse width measurement](<../02.06_Command_Reference/02.06.13.01.01_TMU_per_Pin_overview.md#_125212__e_Pulse_width_measurement>) in [TMU per Pin overview](<../02.06_Command_Reference/02.06.13.01.01_TMU_per_Pin_overview.md>).

 |
 |

O

 |

settings

 |

The recalculated values of prescaler and discarded events between measurements.

 |

## Return value

A reference to the TMU_PINS object is returned.
