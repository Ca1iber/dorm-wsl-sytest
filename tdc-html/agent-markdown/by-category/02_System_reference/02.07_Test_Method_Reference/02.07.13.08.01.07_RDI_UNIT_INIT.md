# RDI_UNIT_INIT()

RDI_UNIT_INIT() is used for conditional code execution. It ensures that the code in a RDI_UNIT_INIT() block is correctly executed and used for setup generation, even if the code has been skipped in the first run due to an if-else condition.

For conditional executions, some execute() and rdi.wait() commands may not be called in each run of the test suite. You need to use RDI_UNIT_INIT() to ensure that these commands are to be executed.

## Syntax

 Note RDI_UNIT_INIT() is required for both pattern‑based and code‑based commands including pure code‑based commands.

```
RDI_UNIT_INIT(const string &sName);
```

Parameter
 |

Parameter

 |

Description

 |
 |

sName

 |

A string as an identifier.

 |

For a "live-branch" case, the `RDI_UNIT_INIT(string)` is for this purpose.

```
   RDI_BEGIN(TA::BURST);
      .... // do block1 actions
   RDI_END();
   if (skip_block) {
           // do nothing
   } else {
       RDI_UNIT_INIT("anystring");
       RDI_BEGIN(TA::BURST);
      .... // do block2 actions
       RDI_END();
   }
   RDI_BEGIN(TA::BURST);
      .... // do block3 actions
   RDI_END();
```

 Note RDI can only have 1000 runtime branches in one test suite.

## Examples

### Example 1

```
 if(user_variable)
    {
      RDI_UNIT_INIT("string1");
      rdi.dc().pin("DATA1").iForce(1 mA).execute();

      RDI_BEGIN();
        rdi.dc().pin("DATA1").vForce(1.5 V).execute();
        rdi.dc().pin("DATA2").iForce(0 mA).vMeas().execute();
      RDI_END();
    }
 else
    {
      RDI_UNIT_INIT("string2");
      rdi.dc().pin("DATA1").iForce(2 mA).execute();

      RDI_BEGIN();
        rdi.dc().pin("DATA1").vForce(2.5 V).execute();
        rdi.dc().pin("DATA2").iForce(0 mA).vMeas().execute();
      RDI_END();
    }
```

### Example 2

```
 while(user_variable)
        {
            RDI_UNIT_INIT("string1");
            RDI_BEGIN();
            rdi.dc().pin("DATA1").vForce(1.5 V).execute();
            rdi.dc().pin("DATA2").iForce(0 mA).vMeas().execute();
            RDI_END();
         }
```

### Example 3

You can put a result retrieval command of a measurement anywhere for RDI_UNIT_INIT().

```
static int lastResult=2;

ON_FIRST_INVOCATION_BEGIN();
If (lastResult>2.0)
{
RDI_UNIT_INIT("string1");
RDI_BEGIN();
  rdi.dc("d1").vMeas().execute();
RDI_END();

FOR_EACH_SITE_BEGIN();
  rdi.id("d1").getValue(); // You can put the getXXX() command here.
FOR_EACH_SITE_END();
}

lastResult++;
if(lastResult==4) { lastResult =0;}
...
ON_FIRST_INVOCATION_END();

rdi.id("d1").getValue(); // You also can put the getXXX() command here.
```
