# DIGITAL_OFFSET_SEARCH_PINS.uploadLatestTransition()

Executes the [TORT?](<../02.06_Command_Reference/02.06.02.02.266_TORT__-__Timing_Level_Offset_search_Result_Transitions.md>) firmware command to upload the offsets at the fail-to-pass and pass-to-fail transition points from the tester to the system controller. These offsets are the offsets of the first and last passing values of the pass area found in the latest transition search.

Later on, you can read out the offset values with [DIGITAL_OFFSET_SEARCH_PINS.getLatestLBTransitionOffset()](<02.07.04.01.36.01.06_DIGITAL_OFFSET_SEARCH_PINS.getLatestLBTransitionOffset.md>), and [DIGITAL_OFFSET_SEARCH_PINS.getLatestRBTransitionOffset()](<02.07.04.01.36.01.07_DIGITAL_OFFSET_SEARCH_PINS.getLatestRBTransitionOffset.md>).

If you retrieve the offset on multiple pins and those pins have different settings, the exception TESTMETHOD_API::AmbiguityException will be issued.

Note Transition values (offsets for left and right boundaries of the pass area) will not be saved in level sets.

## Syntax

```
void uploadLatestTransition();
```

List of parameters

There are no parameters.

Return value

There is no return value.
