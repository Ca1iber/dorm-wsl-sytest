Register operations can be performed in test methods through the RA library. The register operation commands must be put in an RDI_BEGIN/RDI_END block.

Register operations can be done even when no register structure definitions exist. But without the help of register structure definitions, RMW operations cannot be performed.

The RA library supports the structure of a register to be represented in the code. For example, PERIPHERAL0 stands for a peripheral, REGISTER0 stands for a register under the peripheral. Therefore the WRITE command for the REGISTER0 in test methods can be `reg.PERIPHERAL0().REGISTER0().setValue(0x55).write();`.

In the WRITE command example above, reg is a user-defined macro and must be already defined at the beginning of your test methods, for example, `#define reg RA::<className in your xxx_AllDevices.h>::getInstance()`. You can name the macro any name that is suitable.

## Examples

### Example 1

Register operations without register structure definitions

```
RDI_BEGIN();

  // Write register
  RA_WRITE(0x1234, 0x55);
  // Read a register under ID : READ_ID_1
  RA_READ("READ_ID_1", 0x1234);
  // Read a register and compare against an expected value without a mask
  RA_COMPARE(0x1234, 0x55);
  // Read a register and compare against an expected value with a mask
  RA_COMPARE(0x1234, 0x55, 0xFE);
  // Write runtime value per site data
  RA_WRITE_DYNAMIC("DYN_ID_1", 0x1234);
  // Read a register again
  RA_READ("READ_ID_2", ADDR1);
  // Compare by reading register
  RA_COMPARE("COMP_ID_1", ADDR1, DATA1);

  rdi.wait(10 ms);

RDI_END();
```

### Example 2

Register operations with register structure definitions

```

RDI_BEGIN();

  // Register Write
  reg.PERIPHERAL0().REGISTER0().setValue(0x55).write();
  // Field Write [3:2]
  reg.PERIPHERAL0().REGISTER0().setField_MIOF_CNT(1).write();
  // Write Dynamic
  reg.PERIPHERAL0().REGISTER0().writeDynamic("DYN_ID");
  // Read Back
  reg.PERIPHERAL0().REGISTER0().read("READ_ID");
  // Compare value (PF)
  reg.PERIPHERAL0().REGISTER0().setValue(0x55).compare();
  // Compare field (PF)
  reg.PERIPHERAL0().REGISTER0().setField_MIF_CNT(1).compare();
  // Compare with ID
  reg.PERIPHERAL0().REGISTER0().setValue(0x55).compare("COMP_ID_1");
  reg.PERIPHERAL0().REGISTER0().setField_CNT(1).compare("COMP_ID_2");

RDI_END();
```
