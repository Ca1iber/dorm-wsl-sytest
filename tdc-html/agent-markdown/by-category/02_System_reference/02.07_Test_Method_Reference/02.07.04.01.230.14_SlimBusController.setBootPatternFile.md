# SlimBusController.setBootPatternFile()

With this function, you can store a programmatically created SLIMbus program as a sequence file.

## Syntax

```
Boolean saveAsSequenceFile(const STRING &sequenceFile) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

sequenceFile

 |

Specifies the name of the sequence file to be created.

 |

## Return value

TRUE if the file was created successfully, FALSE if this is not the case.

## Functional changes

- Introduced in SmarTest 7.2.1
