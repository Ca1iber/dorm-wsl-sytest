# rdi.id().getPropDelay()

Retrieves the propagation delay of TMU measurements.

getPropDelay() automatically calculates the propagation delay time.

Propagation delay time is the difference between time stamps measured from specified drive pin(s) to receiving pin(s) with TMU.

## Syntax

```
rdi.id("id").getPropDelay(sPin1,sPin2); // For one ID.
```

```
rdi.id("id1","id2").getPropDelay(sPin1,sPin2); // For different IDs.
```

 Note rdi.id("id1","id2")... can be used only for getPropDelay().

## Examples

### One ID

```
RDI_BEGIN();
  rdi.tmu("id1").pin("DATA1")....;
                .pin("DATA2")....;
  ...
RDI_END();

double propDelay = rdi.id("id1").getPropDelay("DATA1","DATA2");
```

### Different IDs

```
RDI_BEGIN();
  rdi.tmu("id1").pin("DATA1")....;
  rdi.tmu("id2").pin("DATA2")....;
  ...
RDI_END();

double propDelay = rdi.id("id1","id2").getPropDelay("DATA1","DATA2");
```

## Functional changes

- Introduced in SmartRDI 7.10.3
