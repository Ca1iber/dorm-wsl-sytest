# SHMOO_RESULT.getSiteList()

Retrieves test sites of the shmoo results that have been defined with [SHMOO_RESULT.setResult()](<02.07.04.01.227.05_SHMOO_RESULT.setResult.md>).

## Syntax

```
std::vector<unsigned int> getSiteList();
```

List of parameters

There are no parameters.

## Return value

Returns a vector which stores a list of site numbers.

## Example

```
double meaValue1;
meaValue1 = ifvmMea.getValue("I/O1");
bool funcResult =GET_FUNCTIONAL_RESULT();

SHMOO_RESULT.site (2).pin("I/O1").testName("Voltage").setResult(meaValue1);
SHMOO_RESULT.site(1).pin("dataPins").testName("Function").setResult(funcResult);

std::vector<unsigned int> siteList = SHMOO_RESULT.getSiteList(); //siteList will store 2 and 1.
```
