# rdi.route().execute()

The function will create the label for the setups defined by the rdi.route() functions. The related burst pattern will be generated and the burst pattern will be executed when RDI_END() is executed.

  Usage of the function:

- The function can be called in the code鈥慴ased mode or in the pattern鈥慴ased mode. For more information, refer to [Execution mode](<02.07.13_SmartRDI.md#_142069__s_Execution_mode>) in topic [SmartRDI](<02.07.13_SmartRDI.md>).

## Syntax

```
void execute();
```

   List of parameters There are no parameters. Return value There is no return value.

## Example

### Example 1

```
RDI_INIT();
...
...
ON_FIRST_INVOCATION_BEGIN();
{
    ...
    ...
    RDI_BEGIN();
    {
        ...
        ...
        rdi.route().applyState("Connect_load").execute();
        ...
        ...
    }
    RDI_END();
    ...
    ...
}
ON_FIRST_INVOCATION_END();
...
...
```
