# rdi.route().reset()

Resets all switches to the default state.

The function resets all switches, bypassing the possibly set masks.

The default state is defined as follows:

- Utility line open collector output is off
- PMUX switch is open
 The stored states of the PMUX cards are not cleared.Note The reset() function also clears the global mask defined with the [enableOnlyActiveSites()](<02.07.13.15.05.03_rdi.route__.enableOnlyActiveSites.md>) function.

Usage of the function:

- The function can be called only in the code‑based mode. For more information, refer to [Execution mode](<02.07.13_SmartRDI.md#_142069__s_Execution_mode>) in topic [SmartRDI](<02.07.13_SmartRDI.md>).

## Syntax

```
routeGroup& reset();
```

   List of parameters There are no parameters. Return value A reference to the [routeGroup](<02.07.13.15.05_rdi.route.md>) object.
