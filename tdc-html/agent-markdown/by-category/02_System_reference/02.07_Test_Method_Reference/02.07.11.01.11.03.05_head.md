# head()

Extracts a specified number of characters from the left end of a state character sequence.

The length parameter specifies the number of characters to extract.

Errors will be issued if the length parameter

- is not an integer number or
- is larger then the sequence length.

## Syntax

```
sequence := head(sequence, length)
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

sequence

 |

State character sequence to which the function is applied.

 |
 |

I

 |

length

 |

Specifies the number of state characters to be extracted.

 |

## Example

head`("10ZR", 2)` results in "`10`".

head`("10ZR", 4)` results in "`10ZR`".

head`(`data`, 3)` results in data`[0..2].`

head`("001LHR", 7)` results in "ERROR: length parameter too large."

head`("001LHR", "01Z")` results in "ERROR: "01Z" is not convertible to integer."
