# EVENT_ICVM.limitHigh()

Sets the upper voltage limit to compare against threshold.

## Syntax

```
EVENT_ICVM & limitHigh(const EVENT_VALUE_DOUBLE & value );
```

Parameter
 | Parameter  | Description |
 | value |

Upper value of range

 |

## Return value

A reference to the corresponding [EVENT_ICVM](<02.07.04.01.63.11_EVENT_ICVM.md>) object.

For an example see [EVENT_ICVM](<02.07.04.01.63.11_EVENT_ICVM.md>).
