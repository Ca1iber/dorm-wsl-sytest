# SPMU_PIN_TASK.iSlewRate()

Sets the force current slew rate.

This member function is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

The force current slew rate is used to modify the rise time and the fall time when the force current is changed. The slew rate has no effect if the clamp current is changed.

 Note For XPS256 pins, the slew rate settings are applied only in connected mode. The maximum slew rate, limited by the programmed bandwidth, is applied when a disconnected channel is connected. We recommend therefore connecting an XPS256 pin with the forced value set to 0 V or 0 A respectively and changing the forced value to the target value after the channel has been connected. The bandwidth can be set by test method APIs [SPMU_PIN_TASK.vFilter()](<02.07.04.01.234.01.33_SPMU_PIN_TASK.vFilter.md>) and [SPMU_PIN_TASK.iFilter()](<02.07.04.01.234.01.13_SPMU_PIN_TASK.iFilter.md>) or by SmartRDI functions [rdi.dc().vFilter()](<02.07.13.12.02.40_vFilter.md>) or [rdi.dc().iFilter](<02.07.13.12.02.15_iFilter.md>).

## Syntax

```
SPMU_PIN_TASK& iSlewRate (const DOUBLE iSlewRate);
```

Parameter
 | Parameter  | Description |
 | iSlewRate  | Defines the current slew rate in Ampere per microsecond (A / 碌sec).

Programmable double values are

- Value between the card-specific minimum and maximum value: The filter is switched on and set to the defined filter frequency.
- 0.0: The filter is set to the card-specific default value.
Card-specific range and default value:

- XPS256: Refer to section [Dynamic behavior](<../02.05_Test_Head_Cards/02.05.05.03.10.08_XPS256_programming_-_Force_and_clamp_currents.md#_354306__s_Dynamic_behavior>) in [XPS256 programming - Force and clamp currents](<../02.05_Test_Head_Cards/02.05.05.03.10.08_XPS256_programming_-_Force_and_clamp_currents.md>).
 |

## Return value

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.

## Example

The following example shows how to set the force current slew rate.

```
SPMU_TASK spmuTask_1;

spmuTask_1.pin("...")
    .mode("CFVM")
    ...
    ...
    .iSlewRate(20 mA) // [A/us]
    ;
```

Note: The example concentrates on the function described in this topic. More settings are required for an executable SPMU_TASK object.
