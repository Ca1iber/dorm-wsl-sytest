# emapLocation()

This function specifies a location where error maps are stored.

If this function is used in a test suite to specify an error map location, the test suite uses the location to store error maps. If this function is not used , the error map location is determined by the [DEFAULT_EMAP_LOCATION](<02.07.13.04_RDI_Configure_file.md#_146692__row_DEFAULT_EMAP_LOCATION>) keyword setup in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>).

## Syntax

```
emapLocation(TA::EMAP_LOCATION location);
```

List of parameters
 |

Parameter

 |

Description

 |
 | location |

The location of type TA::EMAP_LOCATION that defines where error maps are stored.

 |

List of available options of parameter: location
 |

Option

 |

Description

 |
 |

TA::TP

 |

The location is the internal test processor memory.

 |
 |

TA::RAM

 |

The location is the unused vector memory.

 |

## Example

```
rdi.emapLocation(TA::RAM);
```

## Functional changes

- Introduced in SmartRDI 2.4.0
- SmartRDI 2.4.5: Default error map location changes from TA::TP (test processor) to TA::RAM (unused vector memory on the tester).
