# TMU_PINS.setAThreshold()

Sets the voltage threshold for the first shot.

Within the test-processor, the TMU input is connected to the VOH comparator output of the front-end. Therefore, setting the voltage threshold for the TMU by this API means that the VOH threshold for digital functional tests is also changed while a TMU test is being performed. The VOH level defined by the active setup is restored after the TMU measurement has been completed.

Omitting this API means that the VOH threshold of the active setup is also used as the TMU voltage threshold.

## Syntax

```
TMU_PINS& setAThreshold(DOUBLE Athr);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

Athr

 |

The voltage threshold of the first shot. The unit is Volt.

## Return value

A reference to the TMU_PINS object is returned.
