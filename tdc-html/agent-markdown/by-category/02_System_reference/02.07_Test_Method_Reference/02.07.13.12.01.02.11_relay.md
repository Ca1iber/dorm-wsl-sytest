# relay()

Specifies relay actions before and after the measurement with board ADC.

## Syntax

```
relay(TA::BADC_RELAY_ACTION rly);
```

Parameter
 |

Parameter

 |

Description

 |
 |

rly

 |

The board ADC relay setting.

 |

Static relay options
 |

Option

   | Description |
 | TA::badcRly_offAC_onDCBADC_MEAS_offBADCDC_onAC |

Before the measurement, open AC relay, close DC relay and then close BADC relay.

After the measurement, open BADC relay, open DC relay and then close AC relay.

This is the default relay.

 |
 | TA::badcRly_onDCBADC_MEAS_offBADCDC |

Before the measurement, close DC relay and close BADC relay.

After the measurement, open BADC relay and open DC relay.

 |
 |

TA::badcRly_onDCBADC_offAC_MEAS_onAC_offBADCDC

 |

Before the measurement, close DC relay, close BADC relay and then open AC relay.

After the measurement, close AC relay, open BADC relay and open DC relay.

 |
 | TA::badcRly_NO  | Do not switch the relay. |

Dynamic (pattern鈥慴ased) relay options
 | Option  | Description |
 | TA::badcRly_onDC_offACPPMU_MEAS_offDC |

Before the measurement, close DC relay and open AC relay and PPMU relay

After the measurement, open DC relay.

This is the default relay.

 |
 | TA::badcRly_onDC_MEAS_offDC |

Before the measurement, close DC relay

After the measurement, open DC relay.

 |
 | TA::badcRly_NO  | Do not switch the relay.  | In this mode, the AMUX and BADC relays are switched automatically. CAUTION In the high impedance mode, the board ADC may generate a spike when the DC relay of a digital bin is being closed. To avoid the spike occurrence, discharge the board ADC or force a voltage before the next measurement.

## Example

```
RDI_BEGIN();
  rdi.dc().pin("pinA",TA::BADC).vMeas().relay(TA::badcRly_NO).execute();
RDI_END();
```
