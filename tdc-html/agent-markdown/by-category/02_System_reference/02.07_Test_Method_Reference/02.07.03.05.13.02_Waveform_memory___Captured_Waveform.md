# Waveform memory: "Captured Waveform"

Data points that are not initially discarded or inter discarded are stored in the waveform memory of the waveform digitizer. This is done at real time. Subsequently the 'Captured Waveform' is uploaded to the system controller via a high-speed fiber optic link for further data processing.
