# EVENT_BASE

The EVENT_BASE class is the base class for all other specific event types. It provides the interface for generic handling of all kinds of events, for example, downloading or binding to a test point in a pattern.

The following event types are provided by specialized event classes:

- Force Events
- Measurement Events
- Combined Force & Measure Events
- Set Measurement Range Events
- Force Waveform Events
- Measure Waveform Events
- Combined Force & Measure Waveform Events

Specialized event classes are similarly displayed in the graphical user interface.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.
