# sampleCycle()

Specifies the number of tester cycles between two adjacent samples to capture.

This function can be used only in pattern‑based mode.

The sample rate can be set by one of the functions FS(), sampleCycle(), or samplePeriod(). SmartRDI issues a warning at the first run and selects a sample rate that is defined by the pattern cycle period and the 32 vectors that are required per DC event if none of these functions is used. The programmed sample rate must always be lower than the sample rate that is supported by the hardware.

Note DC scale cards feature hardware based averaging that is controlled by function average(). Hardware based averaging can be used in pattern‑based mode. The required sample time depends on the sample rate of the ADC and the number of averaged samples. The time between the measurement events of a digitizer wave that is defined by functions FS(), sampleCycle(), or samplePeriod() must always be larger than the time that is required for averaging. Violating this rule will result in lost measurements: A flag "Distance too small" will be set in in this case. The state of the flag can be checked by command [TSST? - (TeSt STatus)](<../02.06_Command_Reference/02.06.02.02.280_TSST__-__TeSt_STatus.md>).

## Syntax

```
dcBase& sampleCycle(int iCycle);
```

Parameter
 |

Parameter

 |

Description

 |
 |

iCycle

 |

The number of tester cycles.

For a DC Scale card, this number is >= 32 for standard voltage or current measurements.

 |

## Return Value

A reference to the dcBase object.

## Example

```
rdi.dc().pin("DPS_pin_1").vForce(2 V).iMeas().samples(1024).sampleCycle(1000).execute();
rdi.dc().pin("PS1600_1").vForce(2 V).iMeas().samples(1024).sampleCycle(1000).execute();
```
