# SEMI_PARALLEL_CONFIG.getGroupById()

Accesses a semi-parallel test group by its ID in the semi-parallel configuration.

## Syntax

```
const SEMI_PARALLEL_GROUP* getGroupById(int id);
```

Parameter
 |

Parameter

 |

Description

 |
 |

id

 |

The ID of the group in the semi-parallel configuration.

 |

## Return value

A pointer to the semi-parallel group is returned.

## Functional changes

- Introduced in SmarTest 7.2.0
