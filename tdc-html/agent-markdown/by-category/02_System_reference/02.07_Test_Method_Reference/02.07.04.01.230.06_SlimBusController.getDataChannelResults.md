# SlimBusController.getDataChannelResults ()

This function extracts the captured values of the specified data channel for the specified site across superframes and returns them as a SLIMbus data vector. The function can only be called after decode().

## Syntax

```
const SlimBusDataVector & getDataChannelResults(INT channelId, int site=-1) const
```

Parameters
 |

Parameter

 |

Description

 |
 |

channelId

 |

Specifies the data channel whose results are to be extracted.

 |
 |

site

 |

Specfies the site that is to be processed. If no site is specified, the current site under test is taken.

 |

## Return value

A SLIMbus data vector that contains all data of the specified channel on the specified site.

## Functional changes

- Introduced in SmarTest 7.2.1
