# amux()

Controls the multiplexer to switch or to hold the signal to the board ADC.

In SmartRDI 2.2.0, the multiplexer switches the signal to the board ADC every time the board ADC is used, which is unnecessary when measuring signals with a different board ADC. To reduce the unnecessary switching, amux() is created in SmartRDI 2.3.0 for controlling the multiplexer's switching of signals manually.

## Syntax

```
amux(bool iFlag);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

iFlag

 |

Either 1 or 0:

- 1: Transfers another signal to the board ADC.
- 0: Holds the signal to the board ADC.
 |

## Examples

### Example 1

Measuring pinA with the board ADC through the PPMU

```
RDI_BEGIN();
  rdi.dc().pin("pinA").vMeas().amux(0).valueMode(TA::BADC).execute();
RDI_END();
```

### Example 2

Measuring pinA with the board ADC connected through DC relays.

```
RDI_BEGIN();
  rdi.dc().pin("pinA",TA::BADC).vMeas().amux(0).execute();
RDI_END();
```

### Example 3

Measuring pinA with the board ADC through PPMU for three times. The following example demonstrates the different setups between SmartRDI 2.2.0. and 2.3.0. The SmartRDI 2.3.0 setups reduce the relay switching time by using the amux() function.

- Setups in SmartRDI 2.2.0

```
RDI_BEGIN();
  rdi.dc().pin("pinA").vMeas().valueMode(TA::BADC).execute();
  rdi.dc().pin("pinA").vMeas().valueMode(TA::BADC).execute();
  rdi.dc().pin("pinA").vMeas().valueMode(TA::BADC).execute();
RDI_END();
```

- Setups in SmartRDI 2.3.0

```
RDI_BEGIN();
  rdi.hwRelay().pin("pinA").setOn("AMUX_PPMU,PPMU").execute();
  rdi.dc().pin("pinA").vMeas().valueMode(TA::BADC).amux(0).relay(TA:ppmuRly_NO).execute();
  rdi.dc().pin("pinA").vMeas().valueMode(TA::BADC).amux(0).relay(TA:ppmuRly_NO).execute();
  rdi.dc().pin("pinA").vMeas().valueMode(TA::BADC).amux(0).relay(TA:ppmuRly_NO).execute();
RDI_END();
```

## Functional changes

- Introduced in SmartRDI 2.3.0
