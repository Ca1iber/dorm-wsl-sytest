# SMC_GET_WAVEFORM_UPLOAD_PACKAGE_SIZE()

Returns the package size for the waveform upload in bytes.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```
INT SMC_GET_WAVEFORM_UPLOAD_PACKAGE_SIZE();
```

List of parameters

There are no parameters.

## Return value

Returns the package size for the waveform upload in bytes.

## Example

The following example shows how retrieve the package size.

```
INT upld_size = SMC_GET_WAVEFORM_UPLOAD_PACKAGE_SIZE();
```

## Functional changes

- Introduced in SmarTest 6.5.3
