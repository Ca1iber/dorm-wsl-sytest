# execute()

Executes the pulse searching.

The number of samples extracted are (symbolCount * samplesPerSymbol). The samples are extracted from the center of the pulse.

- First the pulseStart and pulseEnd is located.
- Then the pulseCenter is computed (pulseEnd + pulseStart) / 2
- burstStart is computed as pulseCenter - (symbolCount * samplesPerSymbol / 2)
- burstEnd is computed as burstStart + (symbolCount * samplesPerSymbol)

## Syntax

```
PlsState execute(const ARRAY_COMPLEX& srcData, int offset, std::vector<ARRAY_COMPLEX>& result, bool useSymbolCount = true);
PlsState execute(const ARRAY_COMPLEX& srcData, int offset, int& burstStart, int& burstEnd, bool useSymbolCount = true);
```

## Returned Value

Pulse state indicated by enumeration PlsState. Possible values:

- PULSE_OK = 0
- PULSE_NOT_FOUND = 1
- PULSE_CARRIER_OFF = 2
- PULSE_PLS_START = 4
- PULSE_PLS_STOP = 8

## Examples

### Example 1

The following code illustrates a GSM Pulse Search example.

```
ARRAY_COMPLEX wfData = MEAS_DEF().getComplexWaveform(1);
PULSE_SEARCHING gsmPulseSearch;
// I want 156 symbols
// Also need to set the number of captured samples per symbol. (Sample Rate / Symbol Rate)
gsmPulseSearch.init(156, sampleRate / 270.833e3);
//Find the location of the first pulse
INT burstStart=0, burstEnd=0;
PlsState status = gsmPulseSearch.execute(wfData, 0, burstStart, burstEnd, true);
ARRAY_COMPLEX pulseData;
If(PULSE_OK == status)
{
    // extract the pulse DSP_EXTRACT(src, result, src offset, res offset, length)
    DSP_EXTRACT(wfData, pulseData, burstStart, 0, burstEnd-burstStart);
}
```

### Example 2

This is a multiple GSM Pulse Search example.

```
ARRAY_COMPLEX wfData = MEAS_DEF().getComplexWaveform(1);
PULSE_SEARCHING gsmPulseSearch;
// I want 156 symbols
// Also need to set the number of captured samples per symbol. (Sample Rate / Symbol Rate)
gsmPulseSearch.init(156, sampleRate / 270.833e3);
vector<ARRAY_COMPLEX> allPulses;
PlsState status = gsmPulseSearch.execute(wfData, 0, allPulses, true);
```

- Each element of 鈥榓llPulses' is an ARRAY_COMPLEX that contains the pulsed data.
- Each ARRAY_COMPLEX will have 156 symbols worth of data. If samplesPerSymbol == 4, then there would be 624 complex samples in each array.

### Example 3

This is a variable length GSM Pulse Search example. Each element of 鈥榓llPulses' is an ARRAY_COMPLEX that contains the pulsed data. Each ARRAY_COMPLEX may have different length.

```
ARRAY_COMPLEX wfData = MEAS_DEF().getComplexWaveform(1);
PULSE_SEARCHING gsmPulseSearch;
vector<ARRAY_COMPLEX> allPulses;
PlsState status = gsmPulseSearch.execute(wfData, 0, allPulses);
```
