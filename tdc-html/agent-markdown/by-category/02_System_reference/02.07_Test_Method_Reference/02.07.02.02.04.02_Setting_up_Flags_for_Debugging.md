# Setting up Flags for Debugging

The Testflow Editor supports the following flag types:

- The testflow flags primarily help you to debug the testflow.

To open the flags window where you can define the system flags, click the SYS button, or select the System Flags option from the Select menu of the Testflow Editor.

- A system flag is a tool that allows you to control test program execution. This flag defines global information relating to the entire test program.

To open the flags window where you can define the testflow flags, select the Testflow Flags option from the Select menu of the Testflow Editor.

- A testsuite flag controls the output of the testsuite. With this flag, you can set which result will be acquired during execution of the test method program.

To open the flags window where you can define the testsuite flags, click the Flags tab of the Testsuite Dialog for the testmethod-based test suite.

Below, the flags related to the test method are briefly discussed.

- debug analog testflow flag

If this testflow flag is turned on, the PUT_DEBUG API transfers information to the Signal Analyzer Tool if you have already opened that tool.

Even if the Signal Analyzer Tool is not open, you can view transferred information when you open the tool later.

- log events enable system flag

If you are turning this system flag on together with the output on pass or output on fail testsuite flag, the general event data log capability activates in the test method API.

- Log MX Waveforms testsuite flag

If this testsuite flag is turned on together with the log events enable system flag, and the output on pass or output on fail testsuite flag, the PUT_DATALOG API transfers waveform data including array data to the event data log stream.

- output on pass/output on fail testsuite flags

These testsuite flags determine whether the testsuite returns an overall pass and/or fail message. These flags must be set if the output needs to be sent to the event data log stream. On one hand, output on pass or output on fail is used together with log events enable to activate the general event data log capability. On the other hand, output on pass or output on fail is used together with Log MX Waveforms and log events enable flags to let the PUT_DATALOG API transfer waveform data to the event data log stream.

Use these flags according to your testing purpose. For detailed procedures to set up these flags, refer to the Test Setup manual.
