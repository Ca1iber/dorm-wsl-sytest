# Leakage

This test method measures the leakage current at a device input or output or IO pin. The device pins can be brought into the desired state before the measurement by executing a functional test up to a specific vector or cycle. To perform the leakage measurement use the Pin PMU.

The Leakage test method consists of two leakage tests, low level test and high level test. You can execute them individually or together.

If specified, a functional test is executed up to a specific vector or cycle to bring the DUT into the desired state first. After the execution, the sequencer is set to break state with the AC relays closed and DPS set to the voltage programmed in the level setup.

Then, either a parallel or a serial leakage measurement is executed on the specified pins.

If PPMU relays are open, the precharge option can be used to program the PPMU to a voltage before closing the PPMU relay. SmarTest will wait this voltage to be settled and then connect the DUT to the PPMU by closing the relay. Typically the precharge voltage is the same as the voltage used to measure the leakage current.

The PMU current range is determined by the maximum of the absolute limit lower value and absolute limit upper value.

This test method supports test table. But you need to enter the test names manually in the parameter. You can use both test table and testflow limits in a testflow. The test table has higher priority than testflow limits. If a test name used in the test flow is defined in both test table and testflow limits, the value defined in the test table will be used.

## Implementation pseudo code

```
IF not already connected THEN
  connect DUT
ENDIF
IF low level test selected THEN
  IF functional pre-test selected THEN
    execute a functional test to the specified cycle/vector number
  ENDIF
  IF PPMU parallel selected THEN
    program PPMU with specified values
    Open AC relay and close PPMU relay
    set measurement
    execute PPMU measurement
    open PPMU relay and close AC relay
    retrieve test result
  ELSEIF PPMU serial selected THEN
    program PPMU with specified values
    execute PPMU measurement with PMU_VFIM
    retrieve test result

  ENDIF
ENDIF
IF high level test selected THEN
  IF functional pre-test selected THEN
    execute a functional test to specified cycle/vector number
  ENDIF
  IF PPMU parallel selected THEN
    program PPMU with specified values
    Open AC relay and close PPMU relay
    set measurement
    execute PPMU measurement
    open PPMU relay and close AC relay
    retrieve test result
  ELSEIF PPMU serial selected THEN
    program PPMU with specified values
    execute PPMU measurement with PMU_VFIM
    retrieve test result

  ENDIF
ENDIF
datalog test results

```

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.0: Change parameter type of pinlist to PinString for UTM library.
- SmarTest 6.5.2: Change parameter type of forceVoltageLow, forceVOltageHigh, spmuClampCurentLow, spmuClampCurrentHigh, prechargeVoltageLow, prechargeVoltageHigh, settlingTimeLow and settlingTimeHigh to SpecValue for UTM library.
- SmarTest 7.0.3: Classic test method library is removed.
- SmarTest 7.1.1: Test table is supported in TML 2.1.1.
- SmarTest 7.1.1: Mixed usage of test table and testflow limits in one testflow is supported in TML 2.1.1.
- SmarTest 7.1.1: New parameter testName is added in TML 2.1.1.
- SmarTest 7.2.1: New parameter controlTestNumOfFunctional in TML 2.2.0.
- SmarTest 7.2.1: New option ShowFailOnly for the parameter output in TML 2.2.0.
