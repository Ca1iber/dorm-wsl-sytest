# UTILITY_SEQ_STATIC_MASK

#### Subtopics

- [UTILITY_SEQ_STATIC_POGO_MODE](<02.07.04.01.266.01_UTILITY_SEQ_STATIC_POGO_MODE.md>)

Sets the static mask for sequencer鈥慶ontrolled utility lines.

The object of UTILITY_SEQ_STATIC_MASK can be added to a [TASK_LIST](<02.07.04.01.240_TASK_LIST.md>).

 This API requires that the dynamic mask mode is enabled by API [UTILITY_SEQ_POGO_MODE](<02.07.04.01.265.01_UTILITY_SEQ_POGO_MODE.md>) using the keywords

- TM::SEQ_POGO_MASK_MODE_RD or
- TM::SEQ_POGO_MASK_MODE_RW.

The settings done by this API are ignored if other sequencer鈥慶ontrolled modes of the utility blocks are set.

## Example

```
UTILITY_SEQ_MODE        utiSeqModeOn;
UTILITY_SEQ_MODE        utiSeqModeOff;
UTILITY_SEQ_STATIC_MASK utilitySeqStaticMask;

ON_FIRST_INVOCATION_BEGIN();

    //
    // Set utility block 1      in sequencer鈥慶ontrolled masked reading and writing mode.
    // Set utility block 2 to 5 in sequencer鈥慶ontrolled masked reading mode.
    //
    utiSeqModeOn.pogoBlock(1).mode(TM::SEQ_POGO_MASK_MODE_RW );
    utiSeqModeOn.pogoBlock(2,5).mode(TM::SEQ_POGO_MASK_MODE_RD );
    utiSeqModeOn.execute();

    //
    // Set the static mask for pogo blocks 1 and 2
    //
    utilitySeqStaticMask.pogoBlock(1).mask(0x000E);
    utilitySeqStaticMask.pogoBlock(2).mask(0x00E0);
    utilitySeqStaticMask.execute();

    //
    // Perform the functional test
    //
    FUNCTIONAL_TEST();

    //
    // Disable the sequencer鈥慶ontrolled mode of all utility blocks
    //
    utiSeqModeOff.pogoBlock().mode(TM::SEQ_POGO_MODE_OFF);
    utiSeqModeOff.execute();

ON_FIRST_INVOCATION_END();
```
