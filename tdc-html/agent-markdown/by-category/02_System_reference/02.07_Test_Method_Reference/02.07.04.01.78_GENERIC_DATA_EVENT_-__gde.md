# GENERIC_DATA_EVENT - (gde)

The GENERIC_DATA_EVENT class allows logging of [GDR](<../02.10_Data_Logging/02.10.03.05.27_Generic_Data_Record__GDR.md>) records within test methods.

You can use the system-prepared class object "gde" when using member functions. You can also create a new class object. If a function sets up a parameter, the parameter setting is kept until you reset it or return it to a default setting.

Note To log [DTR](<../02.10_Data_Logging/02.10.03.05.29_Datalog_Text_Record__DTR.md>) records instead of GDR records, use the [PUT_DATALOG](<02.07.04.01.174_PUT_DATALOG.md>) API.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/GenericData.h.

### flush()

```

```

## Examples

### Use of FLUSH

```
GENERIC_DATA_EVENT gde;
char sdata[100];
int idata;
...
gde.add(sdata, 100);
gde.add(idata);
..
gde.flush();
```

### Copy an GENERIC_DATA_EVENT object

```
GENERIC_DATA_EVENT gde, gde2;
char sdata[100];
int idata;
...
gde.add(sdata, 100);
gde.add(idata);
...
gde2 = gde;
gde2.flush();
```

### Log the GENERIC_DATA_EVENT object

```
GENERIC_DATA_EVENT gde;
char sdata[100];
int idata;
...
gde.add(sdata, 100);
gde.add(idata);
...
PUT_DATALOG(gde);
```
