# UTILITY_SEQ_MODE.pogoBlock()

Specifies the utility pogo block(s) to set up.

## Syntax

```
UTILITY_SEQ_POGO_MODE & pogoBlock ( const INT number = 0 );
```

Specifies a single utility pogo block to set up.

```
UTILITY_SEQ_POGO_MODE & pogoBlock ( const INT startPogo, const INT endPogo );
```

Specifies a range of utility pogo blocks to set up. The pogo blocks are defined as group with startPogo set as master block. For more information refer to [Ganging utility blocks](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01.03_Ganging_utility_blocks.md>).

  Parameters

 | Parameter  | Description |
 | number |

The pogo block number.

 Valid pogo block numbers:

- 0 (All utility blocks)
- 1 …nbsp;8 (1st [Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>))
- 165 ... 272 (1st Utility Card)
- 265 ... 272 (2nd Utility Card)

If not specified, all the utility pogo blocks will be set.

 |
 |

startPogo

 |

The start pogo block number of the pogo blocks to set up. It must be smaller than the end pogo block number.

For the valid range, refer to parameter number.

startPogo and endPogo must define pogo blocks of the same Utility Card. Defining a range that covers multiple Utility Cards is not supported.

This pogo block is set up as master for the group from startPogo to endPogo. The digital pins that you will be using to supply the control signals are to be wired to this pogo block. For more information refer to [Ganging utility blocks](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01.03_Ganging_utility_blocks.md>).

 |
 | endPogo |

The end pogo block number of the pogo blocks to set up. It must be larger than the start pogo block number.

For the valid range, refer to parameter number.

startPogo and endPogo must define pogo blocks of the same Utility Card. Defining a range that covers multiple Utility Cards is not supported.

   |  Note Each pogo block can be defined only once per [UTILITY_SEQ_MODE](<02.07.04.01.265_UTILITY_SEQ_MODE.md>) object. This applies also for each pogo block within a range from startPogo to endPogo.  Return value The reference to a [UTILITY_SEQ_POGO_MODE](<02.07.04.01.265.01_UTILITY_SEQ_POGO_MODE.md>) object is returned.
