# getFailCyc()

This function returns failing cycle positions.

  Note Retrieval of xMode results is supported if the xMode value is set accordingly with [xMode()](<02.07.13.16.12_xMode.md>). For example, xMode(4) and FFC result = 6, then edge 3 of the vector 2 is the first fail.

## Syntax

```
ARRAY_LL getFailCyc(string sPin);
```

Parameter
 |

Parameter

 |

Description

 |
 |

sPin

   | The name of the pin for which to return the failing cycle positions.Note It can only be a single pin. Do not use multiple pins, a pin group or @ for all pins. |

## Return value

An ARRAY_LL object containing failing cycle positions is returned.

## Example

```
ARRAY_LL fcPostion=rdi.id("a").getFailCyc("pC");
```
