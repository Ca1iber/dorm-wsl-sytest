# Decoding

For input parameters the decode functions describes how parameter values form the fields of a protocol frame.

For output parameters the decode function describes how parameter values are derived from the received bits.

The decode function commonly refers to defined fields of a pin role. Before defining the decode function the layout/structure of the protocol should by specified using fields.

## Example

A frequently used decode function refers to a field of a specific pin role:

@<pinRole>.@<field>

@<Transaction>.@<pinRole>.@<field>
