# SIGNAL_GEN()

#### Subtopics

- [generate()](<02.07.04.01.229.01_generate.md>)
- [getListOfSigGenStandards()](<02.07.04.01.229.02_getListOfSigGenStandards.md>)

SIGNAL_GEN class is used for generating modulation standard specific signals (complex waveforms) and saving the generated signals to encrypted Signal Studio waveform files (*.wfm). These .wfm files can be loaded into the V93000 AWG memory, and directly into modulated RF sources. Files created by this class can also be viewed directly in the Signal Analyzer tool.

The constructor of creates a SIGNAL_GEN object for the given standard. If the default constructor is used, then the user must call presetToStandard() before any other method is called. Currently, the SIGNAL_GEN supports the following standards: 802.11b, AM, FM, EDGE, GSM, NADC, PDC, PHS, Tetra, WCDMA and Zigbee. The keywords for declaring these mod types are as follows:

- SG_80211B_FLEX
- SG_AM
- SG_EDGE_FLEX
- SG_FLEX
- SG_FM
- SG_GSM_FLEX
- SG_NADC_FLEX
- SG_PDC_FLEX
- SG_PHS_FLEX
- SG_TETRA_FLEX
- SG_WCDMA_FLEX
- SG_ZIGBEE_FLEX

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SignalGen.h.

## Syntax

```
SIGNAL_GEN();
SIGNAL_GEN(const STRING& stdStr);
```

## Return value

Files created by this class can be viewed directly in the Signal Analyzer tool.

## Example

```
SIGNAL_GEN sigGen("SG_ZIGBEE_FLEX");
```
