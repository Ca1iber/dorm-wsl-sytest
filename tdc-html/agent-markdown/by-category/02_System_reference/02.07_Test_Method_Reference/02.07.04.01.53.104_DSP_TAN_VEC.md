# DSP_TAN_VEC

This API computes the tangent of the elements in a specified array and returns the results to the corresponding elements of result as follows:

result [i] = tan(src [i] )

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_TAN_VEC(ARRAY_D& src, ARRAY_D& result);
DSP_TAN_VEC(DOUBLE *src, DOUBLE *result,
            INT size);
```

## Example

```
double array1[50],array2[25];
  .
  .
DSP_TAN_VEC(array1, array2, 25);
```

DSP_TAN_VEC computes the tangent of the first 25 elements in the array array1 , and returns the results to the corresponding elements of the array array2 as follows:

```
 int i;
  for(i=0; i<25; i++)
   array2[i] = tan(array1[i]);
```
