# GET_USER_DOUBLE

This API retrieves the current value of the user-defined testflow variable, which can have been stored at a defined site. The variable must have been previously declared as type DOUBLE, and the site must have been previously declared as type INT.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

## Syntax

```
GET_USER_DOUBLE(const STRING& name, DOUBLE *value);
GET_USER_DOUBLE(const STRING& name, INT site, DOUBLE *value);
```

Parameters
 |

I/O

 |

Parameter

 |

Description / Range

 |
 |

I

 |

name

 |

A user-defined variable name.

 |
 |

I

 |

site

 |

Site number, must be in the range [1 ... MAX_SITES], where MAX_SITES is the maximum number of sites allowed by SmarTest.

 Note This is not the number of enabled or active sites. |
 |

O

 |

value

 |

The current value of the specified variable is returned to this variable.

 |

## Examples

### For the current site only

The `GET_USER_DOUBLE` API retrieves the current value of the user-defined variable specified by the parameter delay of the current site.

```
DOUBLE delay_var;
    :
GET_USER_DOUBLE("delay", &delay_var);
```

### For a particularly set site

You can get the variable in a later called test method even if you executed the initialization test method for different sites:

```
...
DOUBLE plant_factor;
SET_USER_DOUBLE("plantFactor", 1, plant_factor); // site-independent value is stored at site 1
...
```

Get the variable:

```
...
DOUBLE plant_factor;
GET_USER_DOUBLE("plant", 1, &plant_factor);
report_stream << "Plant factor: " << plant_factor << endl;
...
```
