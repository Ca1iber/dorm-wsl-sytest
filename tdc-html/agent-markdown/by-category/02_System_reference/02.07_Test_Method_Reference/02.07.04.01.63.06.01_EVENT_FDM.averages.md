# EVENT_FDM.averages()

Sets the number of internal DC measurement samples for hardware based averaging.

## Syntax

```
EVENT_FDM & averages(const EVENT_VALUE_INT & samples);
```

  Parameter

 | Parameter  | Description |
 | samples  | Number of internal samples from which the average is created.  |  Return value A reference to the corresponding [EVENT_FDM](<02.07.04.01.63.06_EVENT_FDM.md>) object.
