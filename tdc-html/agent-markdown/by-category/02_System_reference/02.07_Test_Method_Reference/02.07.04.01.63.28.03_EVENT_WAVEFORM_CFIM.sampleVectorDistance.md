# EVENT_WAVEFORM_CFIM.sampleVectorDistance()

Sets the distance between sample vectors.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_WAVEFORM_CFIM & sampleVectorDistance(INT vectors);
```

Parameter
 | Parameter  | Description |
 | vectors |

Number of vectors defining the distance. Minimum is 32 vectors.

 |

## Return value

A reference to the corresponding [EVENT_WAVEFORM_CFIM](<02.07.04.01.63.28_EVENT_WAVEFORM_CFIM.md>) object.
