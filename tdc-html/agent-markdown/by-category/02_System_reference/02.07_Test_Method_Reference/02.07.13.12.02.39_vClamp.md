# vClamp()

Specifies the clamp voltage.

This function is only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>). The function can be used in the code鈥慴ased mode and in the pattern鈥慴ased mode.

## Change range in pattern鈥慴ased mode (XPS256)

The force or clamp range of DC Scale XPS256 pins can be changed without disconnecting the channel. In pattern鈥慴ased mode, the correct sequence of changing the range and the value must be applied to avoid range overflow warnings.

For more information refer to [iForceRange()](<02.07.13.12.02.17_iForceRange.md>) or [vForceRange()](<02.07.13.12.02.42_vForceRange.md>).

## Syntax

```
dcBase& vClamp(double vClampLow, double vClampHigh);
```

Syntax for a clamp voltage waveform:

```
dcBase& vClamp();
```

Syntax for changing the clamp voltage at runtime:

```
dcBase& vClamp(const string& runTimeId_vClampLow, const string& runTimeId_vClampHigh);
```

Parameters
 |

Parameter

 |

Description

 |
 |

vClampLow

vClampHigh

 |

The two double parameters define the low and the high clamp voltage.

 |
 |

runTimeId_vClampLow

runTimeId_vClampHigh

 |

The two string parameters refer to single double values or arrays of type [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>) that have been assigned by function [runTimeVal()](<02.07.13.08.03.01_runTimeVal.md>) and are filled with the clamp voltage values.

For more information refer to [Changing the parameter value at run-time with SmartRDI](<02.07.13.08.03_Changing_the_parameter_value_at_runtime_with_SmartRDI.md>).

 |

## Return Value

A reference to the dcBase object.

## Example

```
rdi.dc().pin("pinA")
        .iForceRange(50 mA)
        .iForce(5.0 mA)
        .vForceRange(10 V)
        .vClamp(-1.0 V, 7.0 V)
        .execute();
```
