# EVENT_IC_HAC.getIClampLow()

Queries the low clamp current value.

EVENT_IC_HAC functions are supported in PMU operating mode (pin type SIG) on DC Scale DPS128/64 cards only. They are not supported in DPS mode (pin type DPS+).

## Syntax

```
void getIClampLow ( EVENT_VALUE_DOUBLE & value ) const;
```

Parameter
 | Parameter  | Description |
 | value |

Low clamp current

 |

## Return value

Returns EVENT_VALUE_DOUBLE as reference.
