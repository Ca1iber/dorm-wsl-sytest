# DSP_SUB_C

This API returns the difference between two complex numbers.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_SUB_C(COMPLEX src1, COMPLEX src2,
          COMPLEX result);
```

result = minuend - subtrahend

 |

## Example

```
COMPLEX impedance, imp1, imp2;
      :
 DSP_SUB_C(imp1, imp2, impedance);
```

DSP_SUB_C subtracts the COMPLEX variable imp2 from imp1 , and returns the results to the COMPLEX variable impedance as shown in following:

```
COMPLEX impedance, imp1, imp2;
      :
impedance.real = imp1.real - imp2.real;
impedance.imag = imp1.imag - imp2.imag;
```
