# EVENT_WAVEFORM_VFIM.sampleVectorDistance()

Sets the distance between sample vectors.

## Syntax

```
EVENT_WAVEFORM_VFIM & sampleVectorDistance(INT vectors);
```

Parameter
 | Parameter  | Description |
 | vectors |

Number of vectors defining the distance. Minimum is 32 vectors.

 |

## Return value

A reference to the corresponding [EVENT_WAVEFORM_VFIM](<02.07.04.01.63.38_EVENT_WAVEFORM_VFIM.md>) object.
