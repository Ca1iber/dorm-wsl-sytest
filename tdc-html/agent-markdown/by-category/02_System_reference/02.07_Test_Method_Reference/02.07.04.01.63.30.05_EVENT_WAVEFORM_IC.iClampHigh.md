# EVENT_WAVEFORM_IC.iClampHigh()

Sets the high clamp current waveform.

You can specify both the low and high clamp current waveforms or just one.

## Syntax

```
EVENT_WAVEFORM_IC &iClampHigh ( ANALOG_WAVEFORM & waveform);
```

Parameter
 | Parameter  | Description |
 | waveform |

Waveform definition object

 |

Return value

There is no return value.
