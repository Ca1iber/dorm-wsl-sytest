# EVENT_WAVEFORM_VFVM.getSamples()

Queries the number of samples of the waveform.

## Syntax

```
void getSamples(INT & samples) const;
```

Parameter
 | Parameter  | Description |
 | samples |

Number of samples

 |

Return value

There is no return value.
