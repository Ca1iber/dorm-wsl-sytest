# Bitwise AND

The '&' operator calculates the bitwise AND of two state character sequences.

It has the same semantics as the C programming language.

If the parameters differ in length, the shorter sequence is filled with state character '0' or 'L', depending on the corresponding state character of the longer sequence.

If a state characters is used that cannot be converted to integer, an error is issued.

## Syntax

integer := integer & integer

## Example

"1" & "101" results in `"001"`

"HHHH0001" & "101" results in `"LLLL0001"`

"01LH" & "11HH" results in `"01LH"`

"00H" & "101" results in "ERROR: cannot calculate result of "H" & "1"."

"Z1" & "L0" results in "ERROR: "Z1" is not convertible to integer."

"Z1" & "0" results in "ERROR: "Z1" is not convertible to integer."

"011" & 2 results in "ERROR: operator parameters of different types."
