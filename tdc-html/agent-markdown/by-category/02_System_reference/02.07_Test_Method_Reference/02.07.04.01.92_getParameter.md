# getParameter

Used in the postParameterChange() function of the test method to access and modify the properties of the defined test method parameters.

It returns a [TestMethodParameterProxy](<02.07.02.13.05_TestMethodParameterProxy.md>) object for the parameter you specified. Then you can use the member functions of [TestMethodParameterProxy](<02.07.02.13.05_TestMethodParameterProxy.md>) after it to retrieve and set the settings of the parameters as below:

```
getParameter("param_id").function1().function2()...;
```

This API is defined in the header file /opt/hp93000/soc/testmethod/include/testmethod.hpp.

## Syntax

```
TestMethodParameterProxy getParameter(const std::string& parameterIdentifier);
```

Parameter
 |

 |

## Example

In the following example, the test method parameter `vForce_high` is set to be invalid when its specified value is larger than 4.3.

```
virtual void postParameterChange(const string& parameterIdentifier)
  {
     //  Add your code
     if(vForce_high > 4.3)
     {
        getParameter("vForce_high").setValid(false);
     }
     return;
  };
```
