# viMeas()

Specifies a combined voltage and current measurement.

This function is only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>). The function can be only used in the pattern‑based mode.

Two measurement events (one is for the voltage measurement, and the other is for the current measurement) are inserted into the related SmartRDI pattern. The maximum sample rate is therefore defined by the required time for 64 vectors. The sample values are taken from the continuous stream of voltage measurement samples and current measurement samples that are simultaneously provided by the digital closed loop control of XPS256channels.

The function must always be programmed in combination with function [samples()](<02.07.13.11.04.06_samples.md>) and the related functions for setting the sample rate: [FS()](<02.07.13.11.04.03_FS.md>), [sampleCycle()](<02.07.13.11.04.04_sampleCycle.md>), or [samplePeriod()](<02.07.13.11.04.05_samplePeriod.md>).

 Using the viMeas() function in combination with [average()](<02.07.13.11.04.01_average.md>) is supported but the following issues must be observed:

- Without averaging, the time difference between the two measurement is defined by the time for transferring the 32 vectors and for capturing the value for the second measurement event from the continuous stream of data. The delay will be about 1 μs for a pattern sequencer frequency higher than 32 MHz.
- With averaging enabled, the two measurements are pulled apart by the time required for averaging if this exceeds the time for transferring the 32 vectors of the second measurement event.
- The maximum sample rate is not only defined by the required time for 2 * 32 vectors but also by the time required for averaging as far as it exceeds the time for the 32 vectors per measurement event.

The measured values can be retrieved by three functions returning the results as an array of type [ARRAY_D](<02.07.04.02.02_ARRAY_D.md>):

- Function [getWaveform()](<02.07.13.11.04.09_getWaveform.md>) returns both the voltage measurement values and the current measurement values in one array. The size of the array is twice the number of samples that has been set by function [samples()](<02.07.13.11.04.06_samples.md>): Even elements [0, 2, 4, ...] are the voltage measurement values; odd elements [1, 3, 5, ...] are the current measurement values.
- The two functions [getCurrentWaveform()](<02.07.13.11.04.10_getCurrentWaveform.md>) and [getVoltageWaveform()](<02.07.13.11.04.11_getVoltageWaveform.md>) return the current measurement values or the voltage measurement values in a single array. The size of the array corresponds to the number of samples that has been set by function [samples()](<02.07.13.11.04.06_samples.md>).

## Syntax

```
dcBase& viMeas();
```

  List of parameters There are no parameters. Return value A reference to the dcBase object.

## Example

```
ON_FIRST_INVOCATION_BEGIN();
{
    rdi.dc().pin("Pin_1")
            .vForce(0.0 V).vForceRange(10.0 V)
            .iClamp(-20.0 mA, 20.0 mA).iForceRange(50 mA)
            .execute();

    RDI_BEGIN();
    {
        rdi.dc("viDGT").pin("Pin_1")
                .viMeas()
                .samples(20)
                .FS(10 kHz)
                .execute();
    }
    RDI_END();
}
ON_FIRST_INVOCATION_END();

ARRAY_D measuredValues;
double measuredVoltage_1, measuredVoltage_2;
double measuredCurrent_1, measuredCurrent_2;

measuredValues = rdi.id("viDGT").getWaveform("Pin_1");

measuredVoltage_1 = measuredValues[0];
measuredCurrent_1 = measuredValues[1];
measuredVoltage_2 = measuredValues[2];
measuredCurrent_2 = measuredValues[3];
```
