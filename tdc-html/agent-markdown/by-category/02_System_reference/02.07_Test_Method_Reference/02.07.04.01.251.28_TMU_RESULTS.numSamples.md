# TMU_RESULTS.numSamples()

Sets the number of samples to upload.

## Syntax

```
TMU_RESULTS& numSamples (UINT64 num);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

num

 |

The number of samples to upload. If the end segment of the measurement block defined by `firstSample()` is smaller than the specified number, only this end segment is returned.

 |

## Return value

A reference to the TMU_RESULTS object is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
