# clampOff()

Sets the clamp to OFF in the current test item.

## Syntax

```
clampOff();
```

## Example

```
RDI_BEGIN()
rdi.dc().pin("A").clamp(0,1).execute();
rdi.dc("id").pin("A").vMeas().execute();
rdi.dc().pin("A").clampOff().execute();
RDI_END();
```
