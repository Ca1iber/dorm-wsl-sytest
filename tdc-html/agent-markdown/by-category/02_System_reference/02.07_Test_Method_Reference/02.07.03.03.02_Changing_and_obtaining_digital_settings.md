# Changing and obtaining digital settings

#### Subtopics

- [Changing spec value in primary timing spec set](<02.07.03.03.02.01_Changing_spec_value_in_primary_timing_spec_set.md>)
- [Changing spec value in primary level spec set](<02.07.03.03.02.02_Changing_spec_value_in_primary_level_spec_set.md>)
- [Changing and obtaining conditions for digital capture test](<02.07.03.03.02.03_Changing_and_obtaining_conditions_for_digital_capture_test.md>)

To perform multiple tests by switching different conditions in a test method program, use the APIs shown in the following table. The first test generally uses the primaries that you set in the Testsuite dialog of the Testflow Editor. From the second test, each test uses the setup data that you set in the test method program.

To change the conditions of the current primaries, use any of the following APIs before starting the test.

You can change the digital primaries to any of the existing sets (digital primaries means the waveform set, timing set, timing spec set, timing equation, level set, level spec set, level equation, DPS set, and start label). To execute these tasks, use the system-prepared class object Primary of the [PRIMARY_STATUS - (Primary)](<02.07.04.01.167_PRIMARY_STATUS_-__Primary.md>) API. Based on the normal programming syntax of the C++ language, you can describe the multiple member functions after the system-prepared class object Primary.

```
Primary.<memberFunction_1>.<memberFunction_2>. ... .<memberFunction_N>;
```

where, <memberFunction_1> to <memberFunction_N> are member functions of the PRIMARY_STATUS API. For obtaining primary set number/name, you can describe only one member function in the one statement.

The following member functions of the PRIMARY_STATUS API are available for changing/obtaining the particular settings:
