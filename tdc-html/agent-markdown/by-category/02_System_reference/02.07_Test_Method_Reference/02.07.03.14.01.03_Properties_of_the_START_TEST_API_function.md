# Properties of the START_TEST API function

- Accessed through the Execute API menu
- Followed by the WAIT_TEST_DONE function
- Used only with the TEST function format for port-specific judgment and data logging
- Must be used to execute analog tests (except digital capture)
- Executes all functional vectors defined for the primary Multi-port Burst label

## Functional changes

- Introduced before SmarTest 6.3.2
