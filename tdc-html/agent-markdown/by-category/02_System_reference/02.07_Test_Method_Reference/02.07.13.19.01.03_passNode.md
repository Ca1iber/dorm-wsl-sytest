# passNode()

This function specifies the name of the node to go if the result of the cogo() judgment is pass.

## Syntax

```
passNode(string nodeId);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

nodeId

 |

The name of the node with which the execution continues if the cogo() judgment returns pass.

The special value RETURN returns the execution with the main label instead of jumping to another node.

 |

## Example

```
rdi.cogo().node("abc"),TA::ROOT).passNode("RETURN").failNode("id1").begin()
```

## Functional changes

- Introduced in SmartRDI 2.4.0
