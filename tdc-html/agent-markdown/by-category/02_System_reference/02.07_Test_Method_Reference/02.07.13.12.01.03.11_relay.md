# relay()

Specifies relay actions for SPMU.

## Syntax

```
relay(TA::SPMU_RELAY_ACTION relay);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

relay

 |

The relay actions for an SPMU measurement. The default value is TA::spmuRly_NO. If not specified, the connection state will not be changed.

 |

## List of available options of parameter: relay

 |

Option

 |

Description

 |
 |

TA::spmuRly_offAC_onDCSPMU_MEAS_offDCSPMU_onAC

 |

Open AC relay; close DC, ISOL and SPMU relay; measure; open SPMU, ISOL and DC relay; and close AC relay.

 |
 |

TA::spmuRly_onDCSPMU_offAC_MEAS_onAC_offDCSPMU

 |

Open DC relay; close SPMU, DC and ISOL relay; open AC relay; measure; close AC relay; open ISOL, DC and SPMU relay.

 |
 |

TA::spmuRly_onDCSPMU_MEAS_offDCSPMU

 |

Open DC relay; close High PrecPMU relay; close DC relay; measure; open DC relay; open High PrecPMU relay.

 |
 |

TA::spmuRly_NO

 |

No relay switching. The connection state is not changed.

 |

## Example

```
rdi.dc("relay").pin("DATA1",TA::SPMU).iForce(0).relay(TA::spmuRly_offAC_onDCSPMU_MEAS_offDCSPMU_onAC).vMeas().execute();
```
