# EVENT_FDM.getLimitHigh()

Reads the upper limit that has been defined by [EVENT_FDM.limits()](<02.07.04.01.63.06.05_EVENT_FDM.limits.md>) or [EVENT_FDM.limitHigh()](<02.07.04.01.63.06.07_EVENT_FDM.limitHigh.md>).

The value is read from the corresponding [EVENT_FDM](<02.07.04.01.63.06_EVENT_FDM.md>) object and returned as an [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) object.

## Syntax

```
bool getLimitHigh(EVENT_VALUE_DOUBLE & high) const;
```

  Parameter

 | Parameter  | Description |
 | high  | The programmed upper limit of the pass range in Volts (V).  |   Return value bool value indicating the state of the limit definition:

- true: Limit has been defined by [EVENT_FDM.limits()](<02.07.04.01.63.06.05_EVENT_FDM.limits.md>) or [EVENT_FDM.limitHigh()](<02.07.04.01.63.06.07_EVENT_FDM.limitHigh.md>).
- false: No limit is defined or the limit has been cleared by [EVENT_FDM.clearLimits()](<02.07.04.01.63.06.08_EVENT_FDM.clearLimits.md>).
