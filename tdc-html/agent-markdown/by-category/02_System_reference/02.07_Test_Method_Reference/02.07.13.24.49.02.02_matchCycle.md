# matchCycle()

This function specifies how many waiting cycles to be executed after each match.

## Syntax

```
matchCycle(int cycle);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

cycle

 |

The number of waiting cycles between matches.

 |

## Example

```
rdi.smartVec().pin("DATA1").defaultBit(0).matchData(0x36,8,10,6).matchCycle(8).execute();
```

## Functional changes

- Introduced in SmartRDI 2.4.0
