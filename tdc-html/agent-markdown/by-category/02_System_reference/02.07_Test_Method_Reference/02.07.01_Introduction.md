# Introduction

#### Subtopics

- [Test Method Program Introduction](<02.07.01.01_Test_Method_Program_Introduction.md>)

This manual introduces [Universal Test Method](<02.07.02_Universal_Test_Method.md>) and provides detailed information and programming essentials for the Test Method API. The test method API is used to control the V93000 tester hardware and calculate data in your test method programs.

This manual covers the following topics:

- [Universal Test Method](<02.07.02_Universal_Test_Method.md>)

Introduces the concept of the test method programming style that is available from SmarTest 6.3 and how to create and use the test method programs in the device testing.

- [Test Method Programming Essentials](<02.07.03_Test_Method_Programming_Essentials.md>)

Describes the test method API programming in the test method programs.

- [API Reference](<02.07.04_API_Reference.md>)

Describes the test method APIs in detail. The APIs are listed in alphabetical order. The APIs which are not used in test method programming like HVM API, BLC API, HVM session info API, digital calibration API and test suite control API can be found in [Test Program Management](<../02.09_Test_Program_Management/02.09_Test_Program_Management.md>).

- [Test Method Library](<02.07.05_Test_Method_Library.md>)

Describes the predefined DC, AC and PPTIA test method library in detail.

- [Test method snippets provided with SmarTest](<02.07.06_Test_method_snippets_provided_with_SmarTest.md>)

Provides an overview of test methods excerpts available with SmarTest.

- [Concurrent test framework](<02.07.08_Concurrent_test_framework.md>)

Describes the concurrent test framework in detail and provides guidelines for implementing the concurrent test framework.

- [d2s-framework](<02.07.09_d2s-framework.md>)

Describes the dynamic-to-static framework and its implementations for automated generation of static vector labels.

- [SmartCalc framework](<02.07.10_SmartCalc_framework.md>)

Describes the SmartCalc framework and its implementation for multi threaded hidden operations.
