# ExecuteLinuxCommand

This method allows you to execute a single Linux shell command from test method. Any results will be sent to the selected report media.

 Note It is only available for universal test method.

Parameters
 |

Parameter

 |

Type

 |

Description

 |
 |

command

 |

STRING

 |

The shell command and proper parameters to execute.

 |
 |

timeout_s

 |

INT

 |

The test method aborts if the Linux shell command does not execute within the specified time (the unit is second).

 |

## Functional changes

- Introduced in SmarTest 6.5.2
