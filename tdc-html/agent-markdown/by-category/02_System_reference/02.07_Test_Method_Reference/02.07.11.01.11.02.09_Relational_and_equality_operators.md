# Relational and equality operators

The following operators have the semantics as within the C programming language.

## Equal to (==)

The '==' operator compares operands resulting in a true or false statement.

boolean := sequence == sequence

An error is issued if the parameters are of different type, for example, "011" == 3 results in "Error: operator parameter of different types.".

## Not equal to (!=)

The '!=' operator compares its operands for inequality. Its function is reverse to the '==' operator.

boolean := sequence != sequence

An error is issued if the parameters are of different type, for example, "011" != 3 results in "Error: operator parameter of different types.".

## Less than (<)

The '<' operator compares its operands and returns whether the left hand side is lower than the right hand side.

boolean := integer < integer

An error is issued if a parameters is not of integer type, for example,

- "011" < 1 results in "Error: operator parameter of different types."
- "011" < "" results in "Error: "" is not convertible to integer."
- "011" < "XLL" results in "Error: "XLL" is not convertible to integer."

## Greater than (>)

The '>' operator compares its operands and returns whether the left hand side is greater than the right hand side.

boolean := integer > integer

An error is issued if a parameters is not of integer type, for example,

- "011" > 1 results in "Error: operator parameter of different types."
- "011" > "" results in "Error: "" is not convertible to integer."
- "011" > "Z" results in "Error: "Z" is not convertible to integer."

## Less than or equal to (<=)

The '<=' operator compares its operands and returns whether the left hand side is lower than or equal to the right hand side.

boolean := integer <= integer

An error is issued if a parameters is not of integer type, for example,

- "011" <= 1 results in "Error: operator parameter of different types."
- "011" <= "" results in "Error: "" is not convertible to integer."
- "011" <= "Z" results in "Error: "Z" is not convertible to integer."

## Greater than or equal to (>=)

The '>=' operator compares its operands and returns whether the left hand side is greater than or equal to the right hand side.

boolean := integer >= integer

An error is issued if a parameters is not of integer type, for example,

- "011" >= 1 results in "Error: operator parameter of different types."
- "011" >= "" results in "Error: "" is not convertible to integer."
- "011" >= "Z" results in "Error: "Z" is not convertible to integer."
