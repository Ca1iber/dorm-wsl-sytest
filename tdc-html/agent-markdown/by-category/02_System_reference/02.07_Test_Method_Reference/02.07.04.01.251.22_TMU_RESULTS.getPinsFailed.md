# TMU_RESULTS.getPinsFailed()

Retrieves the pins which failed with overrun errors.

## Syntax

```
UINT32 getPinsFailed(STRING_VECTOR& pinvec, STRING& str, INT site)
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

pinvec

 |

A vector of string containing the pins that failed with overrun errors.

 |
 |

O

 |

str

 |

A string containing the pins that failed with overrun errors. The pins are separated by comma.

 |
 |

I

 |

site

 |

(optional) The site to retrieve. The default value is 0, representing all sites.

 |

## Return value

The number of pins that failed with overrun errors is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
