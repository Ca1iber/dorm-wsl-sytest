# TMU_RESULTS.getPeriodPP()

Returns the peak-to-peak period of the specified pin, measument ID and site. The member function `uploadPeriodResults()` of TMU_PINS needs to be used before using this function.

## Syntax

```
DOUBLE getPeriodPP(STRING& pin, UINT32 meas = 1,UINT32 site = 0);
DOUBLE getPeriodPP(const char* pin,UINT32 meas = 1,UINT32 site = 0);
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

pin

 |

 |
 |

I

 |

meas

 |

The measurement ID.

 |
 |

I

 |

site

 |

The site to query. Default is 0, which means the current site.

 |

## Return value

The peak-to-peak period is returned in the unit second.

## Functional changes

- Introduced in SmarTest 7.1.0
