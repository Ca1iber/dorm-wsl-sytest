# TMU_RESULTS.checkSiteAppTypeStored()

Checks whether the results for a specific application was uploaded and cached inside the TMU_RESULTS object.

## Syntax

```
Boolean checkSiteAppTypeStored(TMU::ApplicationType type, UINT32 site = 0);
```

Parameters
 | I/O  | Parameter  | Description |
 | I  | type  | The application type to check. It currently can be

- TMU::APP_PERIOD
- TMU::APP_RAW
- TMU::APP_RAW_FLAT
 |
 | I  | site  | The site to check. The result of the current site is checked by default. |

## Return value

true is returned if the result of the application type is available. Otherwise, false is returned.

If false is retuned and you want to know what went wrong before uploading, waitTMUfinished() must be executed before uploading the result. Then you can check on which pins the error occurred with the following functions of TMU_RESULTS and TMU_PINS: getPinsFinishedButMayFailed(), getPinsFinishedNotFailed(), getPinsFailed(), getPinsNotFinished(). You can get the error state of a single pin with the function getPinErrorState() of TMU_RESULTS.

## Example

```
STRING          pinList         = "...,...";
int             initDiscard     = ...;
TMU_TASK        tmuTask;
...
...

ON_FIRST_INVOCATION_BEGIN();
{
    tmuTask.pin(pinList)
            .setEdgeSelect      (...)
            ...
            ...
            .setInitialDiscard  (initDiscard);

    tmuTask.setAsPrimary();
    tmuTask.setup();

    FUNCTIONAL_TEST();

    bool taskFinished = false;

    tmuTask.waitTMUfinished(tmuTimeout, taskFinished);

    ...
    ...
}
ON_FIRST_INVOCATION_END();

//
// Upload the results into the result cache
//
tmuTask.uploadRawResults();

//
// Get the reference to the resultCache
//
TMU_RESULTS&  tmuResults = tmuTask.getResultCache().pins(pinList).shot(1);

if ( !tmuResults.checkSiteAppTypeStored(TMU::APP_RAW))
{
    cout << "ERROR!! No results uploaded for TMU RAW measurement" << endl;

    return;
}

//
// Continue processing of results for the TMU RAW measurement
//
...
...
```

For a compilable example, refer to [Example 1: TMU raw result](<02.07.04.01.252_TMU_TASK.md#_125624__ex_TMU_raw_result>) in [TMU_TASK](<02.07.04.01.252_TMU_TASK.md>).
