# DSP_IFFT_POLAR

This API computes the inverse FFT of polar coordinate data.

DSP_IFFT_POLAR first converts amplitude and phase from polar coordinate data to rectangular coordinate data in the frequency domain.

freq_array[i].real = amplitude[i] × cos (phase[i])

freq_array[i].imag = amplitude[i] × sin (phase[i])

Then, DSP_IFFT_POLAR performs the inverse FFT of the rectangular coordinate data.

freq_array

 [0].real: DC component

 [0].imag: Zero

 [1].real: Cosine component of fundamental frequency

 [1].imag: Sine component of fundamental frequency

 . .

 . .

 [N-1].real: Cosine component of (N-1)-th harmonic

 [N-1].imag: Sine component of (N-1)-th harmonic

 [N].real: 0 is set

 [N].imag: 0 is set

 [N+1].real: Negative cosine component of (N-1)-th

 harmonic

 [N+1].imag: Negative sine component of (N-1)-th

 harmonic

 . .

 . .

 [N-1].real: Negative cosine component of

 fundamental frequency

 [N-1].imag: Negative sine component of

 fundamental frequency

where N is size.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_IFFT_POLAR(ARRAY_D& amplitude,
               ARRAY_D& phase, ARRAY_D& result);
DSP_IFFT_POLAR(DOUBLE *amplitude, DOUBLE *phase,
               DOUBLE *result, INT size);
```
