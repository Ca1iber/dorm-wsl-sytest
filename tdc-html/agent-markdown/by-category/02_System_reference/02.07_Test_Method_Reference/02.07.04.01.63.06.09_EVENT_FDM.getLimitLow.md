# EVENT_FDM.getLimitLow()

Reads the lower limit that has been defined by [EVENT_FDM.limits()](<02.07.04.01.63.06.05_EVENT_FDM.limits.md>) or [EVENT_FDM.limitLow()](<02.07.04.01.63.06.06_EVENT_FDM.limitLow.md>).

The value is read from the corresponding [EVENT_FDM](<02.07.04.01.63.06_EVENT_FDM.md>) object and returned as an [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) object.

## Syntax

```
bool getLimitLow (EVENT_VALUE_DOUBLE & low)  const;
```

  Parameter

 | Parameter  | Description |
 | low  | The programmed lower limit of the pass range in Volts (V).  |  Return value bool value indicating the state of the limit definition:

- true: Limit has been defined by [EVENT_FDM.limits()](<02.07.04.01.63.06.05_EVENT_FDM.limits.md>) or [EVENT_FDM.limitLow()](<02.07.04.01.63.06.06_EVENT_FDM.limitLow.md>).
- false: No limit is defined or the limit has been cleared by [EVENT_FDM.clearLimits()](<02.07.04.01.63.06.08_EVENT_FDM.clearLimits.md>).
