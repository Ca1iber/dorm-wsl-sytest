# getBurstValue()

You can put any ID inside the `RDI_BEGIN/RDI_END()`/ block to retrieve all measurement results of a related pin in the same `RDI_BEGIN/RDI_END()` block.

## Syntax

```
ARRAY_D& getBurstValue(const string &sPin);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

sPin

 |

A pin name.

   |    Note If an alarm pin has a user-defined measurement, all value results including alarm measurement values will get uploaded. [getValue()](<02.07.13.12.01.01.23_getValue.md>) and [getMultiValue()](<02.07.13.12.02.50_getMultiValue.md>) will not be impacted. But [getBurstValue()](<02.07.13.12.01.01.21_getBurstValue.md>) will include voltage measurement values and results of alarm events.

## Example

```
ON_FIRST_INVOCATION_BEGIN();
  RDI_BEGIN();
    rdi.dc("a").pin("A").iForce(0).vMeas().execute(); //1
    rdi.dc().pin("A").iForce(0).vMeas().execute();    //2
    rdi.dc("b").pin("B").iForce(0).vMeas().execute(); //3
    rdi.dc().pin("A").iForce(0).vMeas().execute();    //4
  RDI_END();
ON_FIRST_INVOCATION_END();

// Get all values of pin A.
ARRAY_D vals = rdi.id("a").getBurstValue("A"); // get the result from 1, 2, and 4.
```
