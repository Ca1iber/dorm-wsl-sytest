# DIGITAL_OFFSET_SEARCH_RESULT_PINS

#### Subtopics

- [DIGITAL_OFFSET_SEARCH_RESULT_PINS.setResultPin()](<02.07.04.01.36.02.01_DIGITAL_OFFSET_SEARCH_RESULT_PINS.setResultPin.md>)
- [DIGITAL_OFFSET_SEARCH_RESULT_PINS.getResultPin()](<02.07.04.01.36.02.02_DIGITAL_OFFSET_SEARCH_RESULT_PINS.getResultPin.md>)

Defines the result pins for the setup pins specified in [resultPin()](<02.07.04.01.36.04_DIGITAL_OFFSET_SEARCH_TASK.resultPin.md>).

The result pins will return pass/fail test results.

## Syntax

This class has no constructor. You cannot directly create an object with this class. It is a sub-class of [DIGITAL_OFFSET_SEARCH_TASK](<02.07.04.01.36_DIGITAL_OFFSET_SEARCH_TASK.md>).

An instance of this class is created with [DIGITAL_OFFSET_SEARCH_TASK.resultPin()](<02.07.04.01.36.04_DIGITAL_OFFSET_SEARCH_TASK.resultPin.md>).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/DigitalOffsetSearchResultPins.h.

List of parameters

There are no parameters.

Return value

There is no return value.
