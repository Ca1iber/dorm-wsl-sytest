# DC_WAVEFORM.iForce()

This function is used to create a current force waveform out of an analog waveform.

## Syntax

```
DC_WAVEFORM & iForce(ANALOG_WAVEFORM & waveform);
```

Parameter
 |

Parameter

 |

Description

 |
 |

waveform

 |

The name of an analog waveform.

 |

## Return value

A DC waveform
