# DriftEyeOpening

This test method measures the eye-opening of signals with TMU. Some time stamps of rising edges and falling edges of the signal are captured. The difference between captured time stamps and expected time stamps are calculated. The eye opening values are got by adding the differences to or subtracted the differences from the measured average pulse width.

## Implementation pseudo code

```
IF not connected THEN
 connect DUT
ENDIF
Set up TMU measurement with specified parameters
Execute TMU measurement
Upload raw data from TMU
Disable TMU
FOR each measured pin
 calculate period of signal
 calculate high pulse width and low pulse width of signal
 calculate differences between captured time stamps and expected time stamps
 calculate eye opening values
ENDFOR
Judge and log test results
```
