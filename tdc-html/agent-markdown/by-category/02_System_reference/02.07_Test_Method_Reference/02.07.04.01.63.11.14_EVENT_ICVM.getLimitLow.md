# EVENT_ICVM.getLimitLow()

Queries the lower voltage limit to compare against threshold.

## Syntax

```
bool getLimitLow (EVENT_VALUE_DOUBLE & lowLimit) const;
```

Parameter
 | Parameter  | Description |
 | value |

Lower value of range

 |

## Return value

bool value indicating the state of the limit definition:

- true: Limit has been defined by [EVENT_ICVM.limits()](<02.07.04.01.63.11.09_EVENT_ICVM.limits.md>) or [EVENT_ICVM.limitLow()](<02.07.04.01.63.11.12_EVENT_ICVM.limitLow.md>).
- false: No limit is defined.

## Example

For an example see [EVENT_ICVM](<02.07.04.01.63.11_EVENT_ICVM.md>).
