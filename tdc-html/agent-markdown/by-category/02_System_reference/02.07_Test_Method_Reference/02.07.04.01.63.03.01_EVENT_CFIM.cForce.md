# EVENT_CFIM.cForce()

Sets the force current.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_CFIM & cForce(const EVENT_VALUE_DOUBLE & value);
```

Parameter
 | Parameter  | Description |
 | value |

Defines the force current in A (Ampere) to be set.

 |

## Return value

A reference to the corresponding [EVENT_CFIM](<02.07.04.01.63.03_EVENT_CFIM.md>) object.
