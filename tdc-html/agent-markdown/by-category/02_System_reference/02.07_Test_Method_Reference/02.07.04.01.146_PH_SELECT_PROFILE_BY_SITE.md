# PH_SELECT_PROFILE_BY_SITE()

You can use this API to specify profiles for each site.

## Syntax

```
bool PH_SELECT_PROFILE_BY_SITE(const string & profile_name, map<int, int>& site_profile_id, string&err_msg)
```

Parameters
 |

Parameter

 |

Type

 |

Description

 |
 |

profile_name

 |

const string &

 |

Profile name. The name can be up to 256 characters with letters A to Z, numbers from 0 to 9, underscore '_' and ignore case, just like a test suite name.

 |
 |

site_profile_id

 |

map<int, int>

 |

Profile IDs by each site. The ID value is from 0 to 10. To disable a site, specify 0 for that site. The site number is the key of the map and the profile ID is the value.

 |
 |

err_msg

 |

string &

 |

The return value of the function whether it has succeeded or failed.

 |

## Return value

 |

Parameter

 |

Description

 |
 |

true

 |

Profiles for each site have been selected successfully.

 |
 |

false

 |

Selecting profiles for each site failed.

 |
