# getVector()

Retrieves the captured data in an array of words.

In the [serial transfer mode](<../../03_Use_cases_and_application_papers/03.07_How_to_set_up_Digital_Capture/03.07.01.04_Setting_up_and_deleting_a_vector_variable.md>), each word contains the data of bits. The number of bits is defined by [bitPerWord()](<02.07.13.13.05_bitPerWord.md>) and the default bit number is 32. The first captured data is MSB and the last captured data is LSB. That means the order of bits in the result array is from MSB to LSB.

Note If you set the number of bits to 32 with [bitPerWord()](<02.07.13.13.05_bitPerWord.md>), for example `bitPerWord(32)`, the result returned by `getVector()` will be < 0 when bit 32 = 1 due to the integer value range.

## Syntax

```
ARRAY_I& getVector(const string& pin);
```

Parameter
 |

Parameter

 |

Description

 |
 |

pin

 |

The pin to query.

 |

## Return value

The reference to an ARRAY_I object containing the captured data of words.

## Examples

```
const ARRAY_I& aiData = rdi.id("cap").getVector("DATA1");
```

```
...
// gpDATA is a pin group which has DATA1 and DATA2.
rdi.digCap("cap").pin("gpDATA").samples(100).execute();
...
// Do not use a pin group name here and must use a pin list.
ARRAY_I ar = rdi.id("cap").getVector("DATA1,DATA2");
```

 Note For the parallel transfer mode, the pin list must be used in getVector() even though the pin group has been used in the setup part.
