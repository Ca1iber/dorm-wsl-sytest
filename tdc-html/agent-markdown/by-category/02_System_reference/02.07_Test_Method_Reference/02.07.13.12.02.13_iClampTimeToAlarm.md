# iClampTimeToAlarm()

Sets a period of current clamp time in seconds. When the current clamp action spends a time longer than the time period, the "" status flag is set.

This function can be only used in the [code鈥慴ased mode](<02.07.13_SmartRDI.md#_142069__dle_Code-based_mode>).

This function only supports [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) in the [PMU operating mode](<../02.05_Test_Head_Cards/02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md>).

See also [Current limit disconnect](<../02.05_Test_Head_Cards/02.05.05.03.10.02_XPS256_status_flags.md#_354167__r_Current_limit_disconnect>) in [XPS256 status flags](<../02.05_Test_Head_Cards/02.05.05.03.10.02_XPS256_status_flags.md>).

## Syntax

```
dcBase& iClampTimeToAlarm(double timeToAlarm);
```

## Example

```
rdi.dc().pin("XPS256_PMU_1").iForceRange(50 mA).iForce(5.0 mA).vClamp(-5.0, 5.0 V).iClampTimeToAlarm(1 s).execute();
```

## Functional changes

- Introduced in SmartRDI 7.10.1
