# EVENT_FILTER.getFilterType()

Queries the type of the filter that has been defined by [EVENT_FILTER.setFilterType()](<02.07.04.01.63.07.01_EVENT_FILTER.setFilterType.md>).

## Syntax

```
void getFilterType(TM::FILTER_TYPE &filterType) const;
```

  Parameter

 | Parameter  | Description |
 | filterType |

The filter type that has been programmed by [EVENT_FILTER.setFilterType()](<02.07.04.01.63.07.01_EVENT_FILTER.setFilterType.md>).

  |   Return value There is no return value.

## Example

For an example see [EVENT_FILTER](<02.07.04.01.63.07_EVENT_FILTER.md>).
