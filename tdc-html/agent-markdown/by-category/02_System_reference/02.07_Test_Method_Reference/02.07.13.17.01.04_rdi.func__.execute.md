# rdi.func().execute()

Executes the previous specified setups in this line of code.

In the code鈥慴ased mode, the setups will be executed immediately.

In the pattern鈥慴ased mode, it will create the label for the specified setups. The burst pattern will be generated and the burst pattern will be executed when `RDI_END()` is executed.

## Syntax

```
rdi.func().execute();
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Example

```
  RDI_BEGIN();
      rdi.func("f1").label("PATT1").execute();
      rdi.func().burst("BURST1").execute();
  RDI_END();
```

```
rdi.func("id2").burst("MP_burstLabel").perLabelPassFail(true).execute();
```
