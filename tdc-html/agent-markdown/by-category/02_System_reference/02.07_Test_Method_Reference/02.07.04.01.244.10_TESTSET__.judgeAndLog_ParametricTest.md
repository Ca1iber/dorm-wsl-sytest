# TESTSET().judgeAndLog_ParametricTest()

Performs a pass/fail judgment of a parametric test and logs the results.

Optional values for this function can be set by prior methods, for example, [port()](<02.07.04.01.244.19_TESTSET__.port.md>), [cont()](<02.07.04.01.244.03_TESTSET__.cont.md>), [reliability()](<02.07.04.01.244.20_TESTSET__.reliability.md>), or [testname()](<02.07.04.01.244.23_TESTSET__.testname.md>).

 Note [TESTSET().judgeAndLog_ParametricTest()](<02.07.04.01.244.10_TESTSET__.judgeAndLog_ParametricTest.md>) uses [SMC_TEST()](<02.07.04.01.231.45_SMC_TEST.md>) internally if [Hidden data logging](<02.07.10.04.09_Hidden_data_logging.md>) is disabled.

## Syntax

```

bool judgeAndLog_ParametricTest(const STRING& pin, const STRING& testname, V93kLimits::TMLimits& tmLimit, double value, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE, char* softBin = "", INT hardbin = -1);
bool judgeAndLog_ParametricTest(const STRING& pinList, const STRING& testname, const LIMIT& limit, ARRAY_D& values, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE, char* softBin = "", INT hardbin = -1);
bool judgeAndLog_ParametricTest(const STRING& pinList, const STRING& testname, V93kLimits::TMLimits& tmLimit, ARRAY_D& values, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE, char* softBin = "", INT hardbin = -1);
bool judgeAndLog_ParametricTest(const STRING_VECTOR& pins, const STRING& testname, ARRAY_D& values, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE, char* softBin = "", INT hardbin = -1);
bool judgeAndLog_ParametricTest(const STRING_VECTOR& pins, const STRING& testname, const LIMIT& limit, ARRAY_D& values, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE, char* softBin = "", INT hardbin = -1);
bool judgeAndLog_ParametricTest(const STRING_VECTOR& pins, const STRING& testname, V93kLimits::TMLimits& tmLimit, ARRAY_D& values, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE, char* softBin = "", INT hardbin = -1);
```

Parameters

Description

testname

 |

For `bool TEST(const STRING& pin, const STRING& testname, double value);`: The test name that is referred from the Properties view.

For `bool TEST(const STRING& pin, const STRING& testname, const LIMIT& limit, double value);`: The test name that is used to create a [TestNameAttr](<../02.10_Data_Logging/02.10.01.06.05.61_TestNameAttrType.md>).

Test names can contain any printable ASCII characters, that is, characters with codes from 32 to 126. This includes the space, digits, lowercase letters, uppercase letters, and these punctuation characters: !"#$%&'()*+,-./:;<=>@?[\]^_`{|}~ There is no fixed maximum length for the names in SmarTest. However, STDF limits test names to 255 characters, so test names should not be longer if STDF data logging is intended.

The test result value.

 |

The limit value to be used for the judgment. This parameter is a [LIMIT](<02.07.04.01.126_LIMIT.md>) API class object. Hence, you can specify TM::Pass or TM::Fail to make the test result pass or fail intentionally.

This parameter is optional, except in the case of `bool TEST(const STRING& pin, const STRING& testname, const LIMIT& limit, double value);`.

The following function calls can be used within the SMC framework:

`bool judgeAndLog_ParametricTest(const STRING& pin, const STRING& testname, double value);`

`bool judgeAndLog_ParametricTest(const STRING& pin, const STRING& testname, const LIMIT& limit, double value);`

`bool judgeAndLog_ParametricTest(const STRING& pin, const STRING& testname, V93kLimits::TMLimits& tmLimit, double value);`

`bool judgeAndLog_ParametricTest(const STRING_VECTOR& pins, const STRING& testname, ARRAY_D& values);`

`bool judgeAndLog_ParametricTest(const STRING_VECTOR& pins, const STRING& testname, const LIMIT& limit, ARRAY_D& values);`

`bool judgeAndLog_ParametricTest(const STRING_VECTOR& pins, const STRING& testname, V93kLimits::TMLimits& tmLimit, ARRAY_D& values);`

## Return Value

The pass/fail result of the judgment, where true is returned for pass and false for fail.
