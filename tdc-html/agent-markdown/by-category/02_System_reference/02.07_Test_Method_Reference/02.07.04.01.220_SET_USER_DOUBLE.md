# SET_USER_DOUBLE

This API sets the specified user-defined testflow variable to a particular value, which can be stored at a defined site. The variable must have been previously declared as type DOUBLE, and the site must have been previously declared as type INT.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

## Syntax

```
SET_USER_DOUBLE(const STRING& name, DOUBLE value);
SET_USER_DOUBLE(const STRING& name, INT site, DOUBLE value);
```

Parameters
 |

I/O

 |

Parameter

 |

Description / Range

 |
 |

I

 |
 |

site

 |

Site number, must be in the range [1 ... MAX_SITES], where MAX_SITES is the maximum number of sites allowed by SmarTest.

 Note This is not the number of enabled or active sites. |

 |

## Examples

### For the current site only

The `SET_USER_DOUBLE` API sets the variable specified by the delay parameter to 0.00001 of the current site (first example) or of site 5 (second example).

```
SET_USER_DOUBLE("delay", 0.01 ms);
```

### For a particularly set site

You can get the variable in a later called test method even if you executed the initialization test method for different sites:

```
...
DOUBLE plant_factor;
SET_USER_DOUBLE("plantFactor", 1, plant_factor); // site-independent value is stored at site 1
...
```

Get the variable:

```
...
DOUBLE plant_factor;
GET_USER_DOUBLE("plant", 1, &plant_factor);
report_stream << "Plant factor: " << plant_factor << endl;
...
```
