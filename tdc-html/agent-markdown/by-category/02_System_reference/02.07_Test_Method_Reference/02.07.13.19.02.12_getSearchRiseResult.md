# getSearchRiseResult()

Retrieves the search result from a rising hysteresis linear search.

## Syntax

```
double getSeachRiseResult();
```

## Example

```
RDI_BEGIN();
   rdi.cogo("result").search(TA::HYST_LINEAR).pathPin("pinA")...blockBegin();
       ...
  rdi.cogo().search().blockEnd();
RDI_END();

rdi.id("result").getSearchRiseResult();
```
