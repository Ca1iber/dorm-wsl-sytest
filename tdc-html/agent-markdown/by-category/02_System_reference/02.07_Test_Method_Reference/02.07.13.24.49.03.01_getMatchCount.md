# getMatchCount()

This function returns the number of executed loops if a match is found on the specified pin.

## Syntax

```
int getMatchCount(string pin);
```

## Example

```
int cnt= rdi.id("abc").getMatchCount("pinA");
```

## Functional changes

- Introduced in SmarTest 2.4.0
