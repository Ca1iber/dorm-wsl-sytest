EVENT_ICIM (Current Clamp / Current Measurement Event) is a combined clamp current setting / current measure event class. These classes provide the combined functionality of setting and measurement events in a single event.

You can define combined clamp current setting / current measure events with all specific functions of [EVENT_IC](<02.07.04.01.63.08_EVENT_IC.md>) and [EVENT_IM](<02.07.04.01.63.12_EVENT_IM.md>), except for the EVENT_IM functions iClampChecks() and getIClampChecks().

## Automatic down-ranging

DPS128 and XPS256 support automatic down-ranging current measurements.

Automatic down-ranging means that the current range is automatically changed to the best fit range for the measurement and restored to the original range after the measurement.

 Two parameters define whether the automatic down-ranging is performed or not:

- The force current or clamp current range:

  - Can be set explicitly or (if not defined)
  - is automatically derived from the forced or clamped value.

- The current measurement range:

  - Can be set explicitly or (if not defined)
  - is automatically derived from the pass/fail thresholds.

Automatic down-ranging is performed only if the current measurement range is lower than the force / clamp current range regardless whether the ranges have been set explicitly or have been selected automatically. For more information, refer to

## Example

```
PATTERN_CONTROLLER cleanUpPattern;
PATTERN_CONTROLLER pc;

EVENT_ICIM iClampCurrMeas("iClampIMeas");

ON_FIRST_INVOCATION_BEGIN();

    cleanUpPattern.label("patEvents", "@")
              .vecEvents("dps1")
              .clearAll()
              .setup();

    iClampCurrMeas.averages(2).limitHigh(4 mA)
                  .iClampHigh(3 mA).iClampLow(2 mA);

    // insert events into pattern
    PATTERN & pattern(pc.label("patEvents", "@"));

    pattern.vecEvents("dps1").clearAll().setup();
    pattern.vecEvents("dps1")
           .insert(200, iClampCurrMeas)

    pc.setup();

ON_FIRST_INVOCATION_END();
```
