# TMU_TASK.releaseResultAreaHandle()

Releases the result area for the specified handle.

## Syntax

```
Boolean releaseResultAreaHandle(STRING& handle);
Boolean releaseResultAreaHandle(const char* handle);
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

handle

 |

The result area handle to release

 |

## Return value

True is returned if the release is successful. Otherwise, false is returned.
