# rdi.pureGenerationMode()

Controls the pure generation mode locally in a test suite.

This function only impacts the code encircled by it in the current test suite. The next test suite is not affected by it and still follows the default setup by the keyword [PURE_GENERATION_MODE](<02.07.13.04_RDI_Configure_file.md#_146692__row_PURE_GENERATION_MODE>) in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>).

## Syntax

```
rdi.pureGenerationMode(bool);
```

## Example

```
rdi.pureGenerationMode(true);
RDI_BEGIN();
  rdi.smartVec().pin("A").writeData(0x12,8).labelName("label_A").execute();
RDI_END();

rdi.pureGenerationMode(false);

```

## Functional changes

- Introduced in SmartRDI 7.5.3
