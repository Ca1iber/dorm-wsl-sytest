# Leakage

This test method measures the leakage current at a device input, output, IO, DC or mixed pin.

To perform the leakage measurement you can use the Pin PMU or DC Scale pins in PMU operating mode. You need to explicitly specify the instruments to use in the parameter.

This test method consists of both low level test and high level test. You can execute them individually or together.

If specified, a functional test is executed up to a specific vector or cycle to bring the DUT into the desired state first. After the execution, the sequencer is set to break state with the AC relays closed and DPS set to the voltage programmed in the level setup.

Then, either a parallel or a serial current measurement is executed on the specified pins.

When measuring with PPMU, the precharge option can be used to program the PPMU to a voltage prior to closing the PPMU relay. The SW will then wait this voltage to be settled and then connect the DUT to the PPMU by closing the relay. Typically this precharge voltage is the same as the voltage used to measure the leakage current.

The PMU current range is determined by the maximum of the absolute lower limit value and absolute upper limit value.

This test method supports different parameter settings and different limit settings for different pins or pin groups. Multi-port setup is supported.

This test method supports test table. But you need to enter the test names manually in the parameter. You can use both test table and testflow limits in a testflow. The test table has higher priority than testflow limits. If a test name used in the test flow is defined in both test table and testflow limits, the value defined in the test table will be used.

## Implementation pseudo code

```
IF low level test THEN
  IF pre-function specified THEN
    execute functional test to specified vector/cycle
    retrieve test result
  ENDIF
  IF PPMU low level measurement THEN
    set up PPMU measurement with specified parameters
  ENDIF
  IF SPMU low level measurement THEN
    set up SPMU measurement with specified parameters
  ENDIF
  IF DCScale SIG mode low level measurement THEN
    set up DCScale pin in SIG mode with specified parameters
  ENDIF
  execute PPMU measurement/SPMU measurement/DCScale SIG mode measurement in parallel
  IF MCx-PMU low level measurement THEN
    set up MCx-PMU measurement with specified parameters
    execute MCx-PMU low level measurement
    retrieve MCx-PMU measurement result
  ENDIF
  retrieve PPMU measurement result
  retrieve SPMU measurement result
  retrieve DCScale SIG mode measurement result
ENDIF
IF high level test THEN
  IF pre-function specified THEN
    execute functional test to specified vector/cycle
    retrieve test result
  ENDIF
  IF PPMU high level measurement THEN
    set up PPMU measurement with specified parameters
  ENDIF
  IF SPMU high level measurement THEN
    set up SPMU measurement with specified parameters
  ENDIF
  IF DCScale SIG mode high level measurement THEN
    set up DCScale pin in SIG mode with specified parameters
  ENDIF
  execute PPMU measurement/SPMU measurement/DCScale SIG mode measurement in parallel
  retrieve PPMU measurement result
  retrieve SPMU measurement result
  retrieve DCScale SIG mode measurement result
ENDIF
Judge and log the test results
```
