# SPMU_PIN_TASK.returnDropMax()

Sets the maximum voltage drop on the return line. The channel gets automatically disconnected in case the voltage drop exceeds the programmed voltage.

The voltage drop is measured from the common ground (GND) to the ground sense pogo pin (GS#). The measured voltage drop depends on the actual current and the impedance of the connection to the DUT. The continuously measured voltage drop is compared against the programmed maximum voltage drop and a pin that exceeds the programmed limit is disconnected.

This member function is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

## Syntax

```
SPMU_PIN_TASK & returnDropMax(DOUBLE returnDrop);
```

  Parameter

 | Parameter  | Description |
 | returnDrop |

The maximum voltage drop in Volts (V) to be set.

A positive voltage has to be set regardless of the polarity of the actual or programmed current.

 Valid range and default value:

- XPS256:

For the specification, refer to [Voltage drop protection / measurement](<../02.02_Specifications/02.02.05.03.07_XPS256_other_performance_characteristics.md#_350739__s_Voltage_drop_protection>) in [XPS256 other performance characteristics](<../02.02_Specifications/02.02.05.03.07_XPS256_other_performance_characteristics.md>).

The programmable range is 0.0 鈥?nbsp;1.0 V for the force line and for the return line but, the total for the two lines must not exceed 1.0 V.

Default value: 50 mV

For a maximum voltage drop > 0.5 V, the open loop protection must be set to "NONE" by function [openLoopProtection()](<02.07.04.01.234.01.25_SPMU_PIN_TASK.openLoopProtection.md>) and in the [DC Scale Safety editor](<../02.05_Test_Head_Cards/02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__s_DC_Scale_Safety_editor>) the [Vdrop Disco](<../02.05_Test_Head_Cards/02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_Vdrop_Disco>) parameter must be set to ON.

   |   Return value A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.

## Example

### Maximum voltage drop of XPS256

```
SPMU_TASK spmuTask_1;

spmuTask_1.pin("...")
    .mode("VFIM")
    ...
    ...
    .forceDropMax    (300 mV)
    .returnDropMax   (200 mV)
    ;
```

Note: The example concentrates on the function described in this topic. More settings are required for an executable SPMU_TASK object.
