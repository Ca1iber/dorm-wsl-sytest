# multiFFC()

Specifies a start cycle and a number of failing cycles for retrieving a limited number of failing cycles from a certain pattern cycle.

## Syntax

```
multiFFC(int startCycle, int FailNumber);
```

List of parameters
 | Parameter  | Description |
 | startCycle  | The number of the first cycle to start the action. |
 | FailNumber  | The number of failing cycles within a pattern to acquire. |

Use the following functions to collect the result:

- getMultiFFC(string resultPin)
- getMultiFFC():Use this command if only one result pin exists.
   Note

- The fail count and fail position are about "compare edge" (not tester cycle). So they supports [xMode](<02.07.13.24.42_xMode.md>) directly.
- The [xMode](<02.07.13.24.42_xMode.md>) parameter for a pin must be correct, otherwise the result for the pin will not be correct.
- The parameter specified in the function, such as startCyc and cycRange, is about user cycles (edge), not tester cycles. This setting is critical when [xMode](<02.07.13.24.42_xMode.md>) is set to be greater than 1.
- For one pin, [xMode](<02.07.13.24.42_xMode.md>) must remain the same in different labels in burst; otherwise the results might be wrong.

## Example

```
RDI_BEGIN();
   rdi.emap("mffc").label("abc")
                   .pin("inA")
                   .multiFFC(0,100)
                   .execute();
   /* For smartVec():
   rdi.smartVec("mffc").label("abc")
                       .pin("inA")
                      .multiFFC(0,100)
                     .execute();
   */

RDI_END();

rdi.id("mffc").getMultiFFC();
```
