# RDI_SEMI_PARALLEL_TEST_END()

Declares the end of the semi-parallel testing block.

It needs to be used in pair with [RDI_SEMI_PARALLEL_TEST_BEGIN()](<02.07.13.08.13.04_RDI_SEMI_PARALLEL_TEST_BEGIN.md>). The semi-parallel testing block needs to be within an RDI_BEGIN and RDI_END block.

## Syntax

```
RDI_SEMI_PARALLEL_TEST_END();
```

See the example in the [RDI_SEMI_PARALLEL_TEST_BEGIN()](<02.07.13.08.13.04_RDI_SEMI_PARALLEL_TEST_BEGIN.md>) topic for its usage.

## Functional changes

- Introduced in SmartRDI 2.4.3
