# Customization

The Customization use cases include sample programs using the Data Display API for customizing almost all the context information of the graph, such as title, axis, grid, cursor, marker, and trace.

## Change Title

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.setTitle("Sample");
graphManager->setGraph(graph, 1);
```

This example change the title of graph 1 to "`Sample`".

## Change Background Color

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.setBackGroundColor(Display::BLACK);
graphManager->setGraph(graph, 1);
```

This example change the background color of graph 1 to black.

## Change Axis Label

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getXAxis(1).setLabel("sample x-axis");
graphManager->setGraph(graph, 1);
```

This example changes the label of X axis to `"sample x-axis"`.

## Change Axis Range

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getXAxis(1).setLabel("time domain")
     .setUnit("us").setMinRange(0).setMaxRange(400);
graphManager->setGraph(graph, 1);
```

This example changes the range the X axis to 0us to 400us.

## Change Line Style

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
// The line style of 1st trace is solid
graph.getTrace(1).setLineStyle(Display::SOLID);
// The line style of 2nd trace is dash dot
graph.getTrace(2).setLineStyle(Display::DASH_DOT);
// The line style of 3rd trace is none (only display data points)
graph.getTrace(3).setLineStyle(Display::NONE_LINE);
graphManager->setGraph(graph, 1);
```

This example sets the line style of trace 1 to `SOLID`, the line style of trace 2 to `DASH_DOT` and the line style of trace 3 to `NONE_LINE`.

## Change Sampling Frequency

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getSelectedGraph();
double frequency;
string unit;
// Get the current sampling frequency of x-coordinate of 1st trace
graph.getTrace(1).getSamplingFrequency(&frequency, unit);
// Double the sampling frequency
if (unit.find("s") != string::npos)
{
  graph.getTrace(1).setSamplingFrequency(frequency*2, unit);
}
graphManager->setSelectedGraph(graph);
```

This example gets the sampling frequency of the first trace. If the unit includes "s", double the sampling frequency.

## Zoom In/Out

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
Axis x_axis = graph.getXAxis(1);
Axis y_axis = graph.getYAxis(1);
double x_start, x_end, y_start, y_end, x_difference, y_difference;
x_start = x_axis.getMinRange();
x_end = x_axis.getMaxRange();
y_start = y_axis.getMinRange();
y_end = y_axis.getMaxRange();
x_difference = x_end - x_start;
y_difference = y_end - y_start;

// Zoom In x2
x_axis.setMinRange(x_start + x_difference/4);
x_axis.setMaxRange(x_end - x_difference/4);
y_axis.setMinRange(y_start + y_difference/4);
y_axis.setMaxRange(y_end - y_difference/4);
graph.setXAxis(x_axis,1).setYAxis(y_axis,1);
graphManager->setGraph(graph, 1);
```

This example retrieves the range of current X axis and Y axis. Then it zooms in the graph by two.
