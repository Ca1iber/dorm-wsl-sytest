# Code Example and Resulting Firmware Commands

The following is a simple code example where the input for the second search task depends on the outcome of the first task. The numbers 1 through 4 on the left margin refer to the steps of [Managing Search Conditions with Variables](<02.07.03.03.08.01.02_Managing_Search_Conditions_with_Variables.md>). Step 0 supplies the value for the variable s_v.

```
    SEARCH_FUNC_TASK t1, t2;

0	 t1.spec("f",TM::TIM).method(TM::Binary).start(30).stop(130);
0	 t1.execute();

	 //Define input value for task2 from result of task1:
	 DOUBLE s_v = (t1.getPassValue() + t1.getFailValue()) / 2;
	 // Define dummy search condition without variables:
1	 t2.spec("del",TM::TIM).method(TM::Binary).start(50).stop(150);
	 // Download but do not execute dummy search condition:
2	 t2.setup();
	 // Modify conditions using result of task1:
3	 t2.pin("O1").spec("del",TM::TIM).method(TM::Binary).
			start(s_v).stop(s_v + 100);
3	 t2.pin("I1").spec("del",TM::TIM).method(TM::Binary).
			start(s_v - 50).stop(s_v);
	 // Download and execute modified conditions:
4	 t2.execute();

```

The resulting firmware commands for the first two testflow executions will look as follows:

```
First execution:
0 > DPSR 3,,,FUNC,#9000000019,TIM,"f",B,30,130,,
0 > EXSR 3
. . .
2 > DPSR 4,,,FUNC,#9000000022,TIM,"del",L,50,150,1,
4 > DPSR 4,(I1),,FUNC,#9000000025,TIM,"del",L,1794,1944,1,
4 > DPSR 4,(O1),,FUNC,#9000000025,TIM,"del",L,1844,1944,1,
4 > EXSR 4
. . .
Restore > DPSR 4,,,FUNC,#9000000022,TIM,"del",L,50,150,1,

Second execution:
0 > EXSR 3;
 . . .
4 > DPSR 4,(I1),,FUNC,#9000000023,TIM,"del",L,836,986,1,
4 > DPSR 4,(O1),,FUNC,#9000000023,TIM,"del",L,886,986,1,
4 > EXSR 4
. . .
Restore > DPSR 4,,,FUNC,#9000000022,TIM,"del",L,50,150,1,
```

The numbers indicate which of the steps described above issue the respective firmware commands. Note that in the second testflow loop, only the modifications for the search conditions of t2 are downloaded. At the end of both loops, the original dummy search condition is restored. For more information on the firmware commands DPSR and EXSR, see [DPSR, DPSR? - (Define Parallel SeaRch)](<../02.06_Command_Reference/02.06.02.02.86_DPSR__DPSR__-__Define_Parallel_SeaRch.md>) and [EXSR - (EXecute SeaRch)](<../02.06_Command_Reference/02.06.02.02.121_EXSR_-__EXecute_SeaRch.md>).
