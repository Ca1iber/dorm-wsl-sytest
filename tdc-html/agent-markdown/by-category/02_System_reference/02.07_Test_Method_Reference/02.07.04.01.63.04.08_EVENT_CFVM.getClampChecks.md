# EVENT_CFVM.getClampChecks()

Reads the state of the clamp voltage checks that have been defined by [EVENT_CFVM.clampChecks()](<02.07.04.01.63.04.07_EVENT_CFVM.clampChecks.md>).

The state is read from the corresponding [EVENT_CFVM](<02.07.04.01.63.04_EVENT_CFVM.md>) object and returned as two bool values for the lower clamp voltage and for the upper clamp voltage.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getClampChecks(bool & failOnLow, bool & failOnHigh) const;
```

Parameters
 | Parameter  | Description |
 | failOnLow |

The programmed value of the lower clamp check.

- true: The lower clamp check is enabled.
- false: The lower clamp check is disabled.
 |
 | failOnHigh |

The programmed value of the upper clamp check.

- true: The upper clamp check is enabled.
- false: The upper clamp check is disabled.
 |

Return value

There is no return value.
