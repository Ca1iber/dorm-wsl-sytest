SmartRDI provides the class `dc()` and related functions to set up tests with PPMU.

## Overview of dc() class functions for PPMU setups

 | API  | Description  | Mode |
 | [average()](<02.07.13.11.04.01_average.md>)  | Specify a number of samples to do averaging.  | P, C |
 | [clamp()](<02.07.13.12.02.02_clamp.md>)  | Specify a clamp current or voltage.  | P |
 | [clampOff()](<02.07.13.12.01.01.03_clampOff.md>)  | Set the clamp to OFF in the current test item.  | P |
 | [copyLabel()](<02.07.13.12.01.01.04_copyLabel.md>)  | Specify to edit an existing pattern or copy and edit the pattern.  | P |
 | [enPassFail()](<02.07.13.13.09_enPassFail.md>)  | Work together with getPassFail() to retrieve the pass/fail results of the pattern specified by label().  | P |
 | [firstRunInLoop()](<02.07.13.12.01.01.06_firstRunInLoop.md>)  | Control the running of PPMU pattern setups and relays to be done only within the first iteration of loops.  | C |
 | [iClamp()](<02.07.13.12.01.01.07_iClamp.md>)  | Specify a clamp current value, low and high clamp values.  | P, C |
 | [iForce()](<02.07.13.12.02.16_iForce.md>)  | Specify a current value to force.  | P, C |
 | [iMeas()](<02.07.13.12.02.18_iMeas.md>)  | Create a current measurement.  | P, C |
 | [insertSub()](<02.07.13.12.01.01.10_insertSub.md>)  | Insert subroutines with DC, PPMU or BADC actions to an existing pattern.  | P |
 | [iRange()](<02.07.13.12.01.01.11_iRange.md>)  | Specify a range value to measure the current. The value is usually the possible maximum current.   | P, C |
 | [limit()](<02.07.13.12.01.01.13_limit.md>)  | Add a pair of limits for judging the pass/fail result of a dynamic DC measurement on digital pins or DC Scale pins.  | P |
 | [loadCap()](<02.07.13.12.02.26_loadCap.md>)  | Specify a load capacitance.  | P, C |
 | [measWait()](<02.07.13.12.01.01.14_measWait.md>)  | Specify a period of time to wait between the previous event and measuring the value.  | P, C |
 | [pin()](<02.07.13.12.01.01.15_pin.md>)  | Specify pin(s) for the subsequent DC actions.  | P, C |
 | [postWait()](<02.07.13.12.01.02.10_postWait.md>)  | Specify a period of time to wait after a action.  | P, C |
 | [relay()](<02.07.13.12.01.01.17_relay.md>)  | Specify relay actions before and after a PPMU measurement  | P, C |
 | [valueMode()](<02.07.13.12.01.01.18_valueMode.md>)  | Specify a method for measuring voltage or current on pins with PS1600 or PS9G cards.  | P; C for PS9G card |
 | [vForce()](<02.07.13.12.01.01.19_vForce.md>)  | Specify a voltage to force.  | P, C |
 | [vMeas()](<02.07.13.12.01.01.20_vMeas.md>)  | Measure voltage on pin(s).  | P, C |
 | [getBurstValue()](<02.07.13.12.01.01.21_getBurstValue.md>)  | Retrieve all measurement results for a pin specified in the same RDI_BEGIN/RDI_END block.   | C |
 | [rdi.id().getMultiValue()](<02.07.13.12.01.01.22_rdi.id__.getMultiValue.md>)  | Retrieve all the values measured on the specified pins.  | C |
 | [getValue()](<02.07.13.12.01.01.23_getValue.md>)  | Retrieve the measure value from a pin.  | C |

In the Mode column: C = Code-based, P = Pattern-based.

## Example

```
ON_FIRST_INVOCATION_BEGIN();
  RDI_BEGIN();
    rdi.dc("id1").pin("PinA").vForce(0 V).valueMode(TA::BADC).iMeas().execute();
    rdi.dc("id2").pin("pinB").iForce(1 mA).vMeas().execute();
  RDI_END();
ON_FIRST_INVOCATION_END();

double res1=rdi.id("id1").getValue();
double res2=rdi.id("id2").getValue();
```
