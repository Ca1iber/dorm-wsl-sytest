# TIMING_OFFSET_SEARCH_PINS.stepWidth()

This function sets the step width of the search.

The combination of the [start value](<02.07.04.01.248.01.23_TIMING_OFFSET_SEARCH_PINS.start.md>), the [number of search steps](<02.07.04.01.248.01.13_TIMING_OFFSET_SEARCH_PINS.numSteps.md>), and the step width defines the range for the initial linear search.

## Syntax

```
TIMING_OFFSET_SEARCH_PINS& stepWidth(DOUBLE stepwidth);
```

Parameter
 |

Parameter

 |

Description

 |
 |

stepwidth

 |

The step width of a search.

The unit is seconds [s].

 |

## Return value

A reference to the [TIMING_OFFSET_SEARCH_PINS](<02.07.04.01.248.01_TIMING_OFFSET_SEARCH_PINS.md>) object.
