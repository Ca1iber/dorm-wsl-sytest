# TestTableMgr

The TestTableMgr class allows you to manage instances of the [TestTable](<02.07.04.01.245_TestTable.md>) class.

There are two modes of using TestTableMgr:

- Using it with the default object. That object represents the active test table used by SmarTest, and this mode is therefore reserved for internal purposes. If you want to work with active test tables, we recommend that you use [TMLimits](<02.07.04.01.250_TMLimits.md>).

Several member functions are related only to this mode and are therefore also reserved for internal purposes. Using TestTableMgr in this mode or any of these related member functions in user test methods is not supported. We strongly recommend that you do not do so to avoid interfering with SmarTest's internal test table handling.

- Using it to work with one or more normal instances (each of which can contain any number of test tables). In this mode, you can use the class function to manipulate test tables that in turn can contain any kind of tabular data.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/TestTableMgr.hpp.

## Constructors

### TestTableMgr()

```
TestTableMgr()
```

The constructor function for the class. It initializes all member variables. You can create instances using the createInstance() function (see below).

### createInstance()

```
TestTableMgr* createInstance()
```

Creates a TestTableMgr instance object.

All objects created with this function must be destroyed with freeInstance() (see below) when they are no longer needed.

## Destructor

### freeInstance()

```
void freeInstance(TestTableMgr* table)
```

Destroys the specified TestTableMgr object.

This function cannot be used to destroy the default TestTableMgr instance (see getDefaultInstance(), below).

### clearActiveTables()

```
void clearActiveTables()
```

This function is reserved for internal use.

### createTestTables()

```
bool createTestTables(const char* filename=ACTIVE_FILE)
```

This function creates a TestTable object from the data in the specified CSV file and adds in to the TestTableMgr object.

If you specify a master file (with a .mfh extension), the function creates a TestTable object from each CSV file listed in the master file.

The function returns true on success and false if it could not create and populate all tables.

Parameter
 |

fileName

 |

The name and path of the file to add to the TestTableMgr object.

If the file is a CSV file, a TestTable object is created from it.

If the file is a master file, a TestTable is created from every CSV file listed in it.

 |

### freeTestTables()

```
void freeTestTables()
```

This function deletes all TestTable objects managed by this TestTableMgr object and frees up their memory. However, the singleton TestTable object obtained by TestTable::getDefaultInstance() is never deleted.

### getDefaultInstance()

```
TestTableMgr* getDefaultInstance()
```

Returns a pointer to the default instance of the TestTableMgr class. This function is reserved for internal use.

### getTestTable()

```
TestTable* getTestTable(const char* lookupKey)
TestTable* getTestTable(unsigned int offset)
```

This function returns a pointer to one of the TestTable objects managed by the TestTableMgr object.

There are two ways to call it:

- By specifying a lookup key. This version of the function is reserved for internal use.
- By specifying an index.

Parameters
 |

lookupKey

 |

This parameter is reserved for internal use.

 |
 |

offset

 |

The index of the desired TestTable object.

Note that the index is 0-based, so to get the third table, you would specify 2 as the offset.

 |

### getTestTableCount()

```
unsigned int getTestTableCount()
```

This function returns the number of TestTable objects contained in the TestTableMgr object.

### isContentComplete()

```
bool isContentComplete()
```

This function checks whether all cells in all tables contained in the TestTableMgr instance are completely filled:

- true: Every cell in every table contains a value.
- false: There are one or more empty cells in at least one of the tables.

### isMasterFile()

```
bool isMasterFile(const char* filename=ACTIVE_FILE)
```

This function checks whether the specified file is a master file. Master files have the .mfh extension and contain a list of other setup files.

Parameter
 |

fileName

 |

The name and path of the file to check.

 |
