# TMU_RESULTS.[ ]

Used to access the specified element of the TMU_RESULTS object.

## Syntax

```
virtual TMU_RESULTS& operator[](unsigned short index);
virtual TMU_RESULTS& operator[](STRING& keyname);
virtual TMU_RESULTS& operator[](const char* keyname);
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

index

 |

The index number of the element.

 |
 |

I

 |

keyname

 |

The index string of the element.

 |

## Return value

A reference to the TMU_RESULTS object is returned.

## Functional changes

- Introduced in SmarTest 7.1.3
