# DIGITAL_WAVEFORM.levelResolution()

This function specifies the voltage level resolution for level search. The default value is 20 mV.

## Syntax

```
DIGITAL_WAVEFORM& levelResolution(DOUBLE level_resolution);
```

Parameter
 |

level_resolution

 |

The resolution of voltage level.

 |
