# EVENT_ICVM.getIClampLow()

Queries the low clamp current value.

## Syntax

```
void getIClampLow ( EVENT_VALUE_DOUBLE & value );
```

Parameter
 | Parameter  | Description |
 | value |

Low clamp current

 |

Return value

There is no return value.
