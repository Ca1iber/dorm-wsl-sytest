# HW_STATE.checkKelvinStatusParallel()

This member function initiates a sense connection test on the defined pins to verify that the force lines and sense lines are connected together on the DUT board or at the DUT pins.

The test is performed in parallel for all active sites. The member function returns a go/no-go result for each configured site in a single integer array.

The test is started for the connection between the high force lines and the high sense lines (positive power lines) and for the connection between the low force lines and low sense lines or ground sense lines and ground (negative power lines).

The tested pins must be disconnected for the sense connection test.

The member function should be called within the [ON_FIRST_INVOCATION](<02.07.04.01.138_ON_FIRST_INVOCATION_BEGIN.md>) block.

## Syntax

```
bool checkKelvinStatusParallel(const STRING pinlist, ARRAY_I &result);
bool checkKelvinStatusParallel(const STRING pinlist, const INT samples, ARRAY_I &result);
```

 The following syntax is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>):

```
bool checkKelvinStatusParallel(const STRING pinlist, const INT samples,
        const DOUBLE maxResistance, ARRAY_I &result);

bool checkKelvinStatusParallel(const STRING pinlist, const INT samples,
        const DOUBLE maxResistancePos, const DOUBLE maxResistanceNeg, ARRAY_I &result);

```

## Return value

The returned bool value indicates the state of the conversion from the read data to the data in the array:

  true No error found false Invalid data read

## Example

The following example performs a sense connection test on three pins "pin1", "pin2", "pin3" in parallel on all active sites. Failing sites are re-tested in the [FOR_EACH_SITE](<02.07.04.01.71_FOR_EACH_SITE_BEGIN_WITH_QUERY.md>) block to identify the failing pins and lines. Note that the FOR_EACH_SITE_BEGIN_WITH_QUERY() API must be used to set the query focus within the block.

```
SPMU_TASK       spmuTask;
HW_STATE        hwState;
ARRAY_I         goNogoResult;
ARRAY_I         statusPosArray;
ARRAY_I         statusNegArray;
STRING          pinlist          = "pin1, pin2, pin3";

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Disconnect the tested pins
    //
    spmuTask.pin(pinlist).vForce(0.0 V).min(-1.0 A).max(1.0 A).relay("NT");

    spmuTask.execMode(TM::FORCE_OFF).execute();

    //
    // Perform the Kelvin test in parallel on all active sites
    //
    hwState.checkKelvinStatusParallel(pinlist, goNogoResult);

    //
    // Evaluate the go/no-go results, re-test failing sites
    //
    cout << "Parallel Kelvin tests GoNogo results per site:" << endl << endl;

    FOR_EACH_SITE_BEGIN_WITH_QUERY();
    {
        cout << "\tSite " << CURRENT_SITE_NUMBER() << ": ";

        if (goNogoResult[CURRENT_SITE_NUMBER() -1] == 1)
        {
            cout << "PASS" << endl;
        }
        else
        {
            cout << "FAIL, serial test on site " << CURRENT_SITE_NUMBER() << endl << endl;

            //
            // Serial test identifies failing pins
            //
            hwState.checkKelvinStatus(pinlist, statusPosArray, statusNegArray);

            for (int arrayIndex = 0; arrayIndex < statusPosArray.size(); arrayIndex++)
            {
                cout << "\t\tPin " << arrayIndex + 1
                     << ": positive = " << statusPosArray[arrayIndex]
                     << ", negative = " << statusNegArray[arrayIndex] << endl;
            }

            cout << endl;
        }
    }
    FOR_EACH_SITE_END();

    cout << endl;
}
ON_FIRST_INVOCATION_END();
```
