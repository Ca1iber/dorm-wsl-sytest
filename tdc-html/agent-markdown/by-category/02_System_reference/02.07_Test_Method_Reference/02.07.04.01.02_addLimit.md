# addLimit

This API adds a limit to the test method. The default values ('NA') will be added to the limit. You need to add the limit values in the tabular testflow editor (See [Limits tab](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.01.03_Tests_page.md>)) or [Properties view](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.04_Testflow_Properties_view.md>)).

This API is defined in the header file /opt/hp93000/soc/testmethod/include/testmethod.hpp.

## Syntax

```
TestMethodLimitProxy& addLimit(const std::string& testName)
```
