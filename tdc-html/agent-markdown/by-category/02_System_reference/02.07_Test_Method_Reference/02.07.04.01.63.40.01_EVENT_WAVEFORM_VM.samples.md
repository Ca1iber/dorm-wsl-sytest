# EVENT_WAVEFORM_VM.samples()

Sets the number of samples to capture.

## Syntax

```
EVENT_WAVEFORM_VM & samples(INT samples);
```

Parameter
 | Parameter  | Description |
 | samples |

Number of samples.

 |

Return value

There is no return value.
