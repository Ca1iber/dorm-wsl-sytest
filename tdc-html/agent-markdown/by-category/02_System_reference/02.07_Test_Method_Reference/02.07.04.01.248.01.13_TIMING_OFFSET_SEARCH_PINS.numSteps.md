# TIMING_OFFSET_SEARCH_PINS.numSteps()

This function sets the number of the search steps excluding the start value.

The combination of the [start value](<02.07.04.01.248.01.23_TIMING_OFFSET_SEARCH_PINS.start.md>), the number of search steps, and the [step width](<02.07.04.01.248.01.24_TIMING_OFFSET_SEARCH_PINS.stepWidth.md>) defines the range for the initial linear search.

## Syntax

```
TIMING_OFFSET_SEARCH_PINS& numSteps(INT numstep);
```

Parameter
 |

Parameter

 |

Description

 |
 |

numstep

 |

The number of search steps excluding the start value.

 |

## Return value

A reference to the [TIMING_OFFSET_SEARCH_PINS](<02.07.04.01.248.01_TIMING_OFFSET_SEARCH_PINS.md>) object.
