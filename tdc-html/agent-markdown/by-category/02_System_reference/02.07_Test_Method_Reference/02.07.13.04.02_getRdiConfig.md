# getRdiConfig()

Retrieves the current value of a specified setup option being used in the RDI_Configure file.

## Syntax

```
string rdi.getRdiConfig(string optionName);
```

Parameter
 |

Parameter

 |

Description

 |
 |

optionName

 |

The option name to be queried.

 |

## Return Value

The option value returns.

## Example

```
rdi.getRdiConfig("RF_CAL_DEFAULT");
```

For the option RF_CAL_DEFAULT, one of the three values will return: ON, OFF, and SYSTEM_CAL.

## Functional changes

- Introduced in SmartRDI 2.4.3
