# TESTSET().judgeAndLog_PptiaTask()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) performs a pass/fail judgment of a test specified by a PPTIA_TASK object and logs the results.

Optional values for this function can be set by prior methods, for example, [port()](<02.07.04.01.244.19_TESTSET__.port.md>), [cont()](<02.07.04.01.244.03_TESTSET__.cont.md>), [reliability()](<02.07.04.01.244.20_TESTSET__.reliability.md>), or [testname()](<02.07.04.01.244.23_TESTSET__.testname.md>).

## Syntax

```
bool judgeAndLog_PptiaTask(const PPTIA_TASK & pptiaTask, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE);
```

 |

Parameter

 |

Description

 |
 |

pptiaTask

 |

The [PPTIA_TASK](<02.07.04.01.165_PPTIA_TASK.md>) object from which the test data is taken.

 |
 |

logTestNumber

 |

An optional test number.

If this test number is provided, it overrides the actual test number. If it is not provided, the actual test number is logged.

   | Note Only the first six digits of values are ensured to be correctly logged into the STDF file.

## Return Value

The pass/fail result of the judgment is returned. It can be true for pass or false for fail.

## Example

```
INT debug;
PPTIA_TASK task1;
GET_TESTFLOW_FLAG ("debug_analog", &debug);
ON_FIRST_INVOCATION_BEGIN();
  task1.pin(tia_pin).eventASlope(TM::RISE).eventAThreshold(1000 mV).eventACount(0) ;
  task1.pin(tia_pin).eventBSlope(TM::RISE).eventBThreshold(1000 mV).eventBCount(N) ;
  task1.pin(tia_pin).armingMethod(TM::EVENT_A_FIRST) ;
  task1.pin(tia_pin).limits("per_s",TM::MEAN) ;
  task1.preAction(TM::SET_TIA_MODE).execute() ;
ON_FIRST_INVOCATION_END();
TESTSET().judgeAndLog_PptiaTask(task1);
```

This example performs a period measurement with PPTIA on `tia_pin`. `tia_pin` is the test method parameter holding the pin(s) to be measured. `N` is the test method parameter holding the number of events.
