# SMC_TMU_UPLOAD_RAW_RESULTS()

The SMC_TMU_UPLOAD_RAW_RESULTS is the SmartCalc API used to perform hidden uploads of TMU raw time stamp results.

 Alternatively, uploads of TMU raw time stamp results from specific shots is performed by calling [TMU_TASK.smcUploadRawResults()](<02.07.04.01.252.17_TMU_TASK.smcUploadRawResults.md>).

This API uploads the TMU raw results from specific shots or all shots from the test head card's memory to the result cache on the workstation. This is done in the background while a new test suite is being executed. The hidden upload improves the overall performance. The upload takes place concurrently for the specified pins for all sites. This API must be called inside your SMC_backgroundProcessing() method.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

Parameters
 |

Parameter

 |

Description

 |
 |

results

 |

The name of the result cache on the workstation to which the results are uploaded.

If this parameter is not specified, the default result cache is used.

 |
 |

resultAreaHandle

 |

The name of the result area to upload from.

Result areas are defined with [TMU_TASK::requestResultAreaHandle(handlename)](<02.07.04.01.252.13_TMU_TASK.requestResultAreaHandle.md>).

If this parameter is not specified, the data from the active result area are uploaded.

 |
 |

dgtPinName

 |

The list of pins for which to upload data.

 |
 |

shot

 |

The number of shots for which the samples are to be uploaded.

For example, if 2 is specified the ''shots 1 and 2'' are uploaded.

 |
 |

armings

 |

The number of armings to be uploaded from the shot. The upload always starts with the first arming. The default value is 1.

For example, if 3 is specified the ''armings 1, 2, and 3'' are uploaded.

 |
 |

numsamples

 |

The number of samples to be uploaded. Specify 0 to upload all samples. The default is 0.

 |
 |

firstsample

 |

The index of the first sample to be uploaded. The index of the first sample in a block is 0. The default value is 0.

 |
 |

flatupload

 |

The structure of the upload:

FALSE: Samples are grouped by armings. (Default).

TRUE: Samples for all armings are uploaded as one set.

 |
 |

keyName

 |

The name of the related TMU_TASK object.

 |
 |

syncErrors

 |

Controls the error synchronization. This should normally be set to TRUE to synchronize the TMU errors.

The errors are stored in the TMU_PINS objects after waitTMUFinished(). They need to be synchronized with the ResultCache.

 |
 |

site

 |

Specifies the site for which the data should be uploaded.

 |

Return value

There is no return value.

An example of performing hidden uploads of TMU raw time stamp results is available here: [smcUploadRawResults example](<02.07.04.01.252.17_TMU_TASK.smcUploadRawResults.md#_151561__example>).

Exchange the TMU_TASK.smcUploadRawResults() method for the SMC_TMU_UPLOAD_RAW_RESULTS() method and use it with the related parameter.
