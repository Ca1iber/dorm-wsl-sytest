# How to develop UTM library outside of SmarTest

You may want to develop the universal test method in your own environment. This topic introduces how to develop UTM library outside the SmarTest Work Center.

## Before you begin

Because the UTM related header files need to be used, make sure SmarTest is installed and switched to the correct version.

## Procedure

-  Create a UTM class source file in the custom environment according to the class source file format (See Universal Test Method Class in [Universal test method concept](<02.07.02.01_Universal_test_method_concept.md>)).
-  Make the UTM class source file to generate the shared library. Include the following paths and options when making the file:

  - paths for header files: -I /opt/hp93000/soc/prod_com/include -I/opt/hp93000/soc/prod_com/include/MAPI -I/opt/hp93000/soc/testmethod/include
  - macro definition for your source code path to be searched by debugger: _TM_CDIR="\"$$(/bin/pwd)\""
  - option "-m32" for both compiler and linker if you are building for 32-bit binaries on the Red Hat 5 64-bit OS.

## Results

The UTM library is generated in the directory you specified. Copy the UTM library to the directories where it is needed (See the universal test method library deployment location in [Universal test method concept](<02.07.02.01_Universal_test_method_concept.md>)).
