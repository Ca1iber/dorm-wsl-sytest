# Style of Test Method APIs

The test method APIs consist of function type APIs and C++ class type APIs as below.

## Function Type APIs

Most test method APIs are the function type (C function style). An example of this type is as follows:

```
DSP_FFT(source_array, result_array, window);
```

## C++ Class Type APIs

Some of test method APIs are the C++ class type. There are two kinds of uses as shown below.

Example 1:

Call the constructor of the API, and the desired member functions in one statement, without creating the class object explicitly. This is orthodox programming style with the C++.

```
ANALOG(1).DGT("Vout").vOffset(0.5 V).vRange("6");
// V offset = 0.5V, V range = [-3V, 3V]
```

Example 2:

Call the constructor to create an object explicitly, then call the desired member functions in another statement.

```
//Create a class object of ANALOG API called "set"
ANALOG set(1);
//Change parameter setting using the object "set"
set.DGT("Vout").vOffset(0.5 V).vRange("6");
// V offset = 0.5V, V range = [-3V, 3V]
```

Generally, you can call more than one member functions by connecting the member functions with "dot".
