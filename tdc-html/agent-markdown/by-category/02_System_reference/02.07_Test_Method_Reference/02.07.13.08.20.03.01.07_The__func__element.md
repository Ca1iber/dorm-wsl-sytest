# The <func> element

This element stores results of a functional test performed using the SmartRDI's `func()` class.

The <func> element stores functional test results in its passFail attribute. This attribute saves functional test results returned by a `getPassFail()` or a `getBurstPassFail()` function.

 | Get Result Function in SmartRDI |

ORE File Syntax Example

 |
 |

int getPassFail();

   | <func passFail = "0" /> |
 |

int getBurstPassFail();

   | <func passFail = "0" /> |

## Example

Below is an example of the <func> element and its corresponding SmartRDI code block.

An ORE file containing <func> elements:

```
<offlineResultEmulation>
  <id name = "id1">
    <func passFail = "0"/>
    <pin name = "A">
      <func passFail = "0"/>
    </pin>
    <pin name = "B">
      <func passFail = "1"/>
    </pin>
  </id>
  <id name = "id2">
    <func passFail = "0"/>
  </id>
</offlineResultEmulation>
```

 The corresponding SmartRDI code block that can generate this ORE file:

```
RDI_BEGIN();
  rdi.burstId( "id1" ,"A,B");
  rdi.func("id2").label("label1").execute();
  ...
RDI_END();
...
rdi.id("id1").getBurstPassFail();      //0
rdi.id("id1").getBurstPassFail("A");   //0
rdi.id("id1").getBurstPassFail("B");   //1
rdi.id("id1").getBurstPassFail("A,B"); // rslt(A) & rslt(B) = 0
rdi.id("id2").getPassFail();           // 0
```

<pin> is inapplicable for the functional result which is not based on pin.
