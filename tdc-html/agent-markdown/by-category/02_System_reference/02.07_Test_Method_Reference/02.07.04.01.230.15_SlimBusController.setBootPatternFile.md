# SlimBusController.setBootPatternFile()

This function specifies the file for user defined booting. If it is not called, or called with an empty string, the boot process will be carried out dynamically. For more information on dynamical and user defined booting see [Overview of the SLIMbus solution](<02.07.11.01.12_Overview_of_the_SLIMbus_solution.md>).

## Syntax

```
Boolean setBootPatternFile (const STRING &filename);
```

Parameter
 |

Parameter

 |

Description

 |
 |

filename

 |

Specifies the boot pattern file. You can also enter an empty string; in this case the booting will be dynamical.

 |

## Return value

TRUE if the file can be accessed successfully, FALSE if this is not the case.

## Functional changes

- Introduced in SmarTest 7.2.1
