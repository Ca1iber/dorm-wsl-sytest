# RESULT_AREA_CONFIG_SET.remove()

This member function will remove the current result area configuration set from the firmware. It calls the RSUD firmware command. It makes the result area configuration set invalid and calling any other functions on this instance afterwards will cause an exception. This also removes any results stored in the corresponding area(s).

## Syntax

```
void remove();
```

List of parameters

There are no parameters.

Return value

There is no return value.
