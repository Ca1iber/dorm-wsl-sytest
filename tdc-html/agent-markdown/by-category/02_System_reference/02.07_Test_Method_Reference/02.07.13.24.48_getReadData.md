# getReadData()

Retrieves all read data blocks and put them into an array of type ARRAY_LL. Usually, `getReadData()` is used with [readData()](<02.07.13.24.29_readData.md>).

  Note If you set the length of bits to 64 with [readData()](<02.07.13.24.29_readData.md>), for example `readData(64,2)`, the result returned by `getReadData()` will be < 0 when bit 64 = 1 due to the long integer value range.

For both TA::EMAP and TA::DIGCAP [read modes](<02.07.13.24.30_rdi.smartVec__.readMode.md>), the result in ARRAY_LL is the same.

## Syntax

```
ARRAY_LL  getReadData(const string &pin);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

pin

 |

The pin to query.

 |

## Example

```
ON_FIRST_INVOCATION_BEGIN();
RDI_BEGIN();
   rdi.smartVec("result").pin("DATA1").readData(4,2).execute();
RDI_END();
ON_FIRST_INVOCATION_END();
ARRAY_LL data_result = rdi.id("result").getReadData("DATA1");
```
