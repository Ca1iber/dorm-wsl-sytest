# DIGITAL_WAVEFORM.getTimingResolution()

This function returns the timing resolution for waveform retrieval in seconds. It can be only used for one single pin.

## Syntax

```
DOUBLE getTimingResolution() const
```

## Functional changes

- Introduced before SmarTest 6.3.2
