# EVENT_CF.cForce()

Sets the force current.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

```
EVENT_CF & cForce(const EVENT_VALUE_DOUBLE & value);
```

Parameter
 | Parameter  | Description |
 | value  | Defines the force current to be set in A (Ampere). |

## Return value

A reference to the corresponding [EVENT_CF](<02.07.04.01.63.02_EVENT_CF.md>) object.
