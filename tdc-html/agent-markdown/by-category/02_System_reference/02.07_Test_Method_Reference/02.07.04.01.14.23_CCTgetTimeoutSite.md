# CCTgetTimeoutSite

This function returns the SmarTest Work Center flags for all sites in the execution. The returned flag maps to sites in binary format.

This function is usually used in the `preStart()`, `postStart()`, `process()` and `cleanup()` function but not used in the `init()` function of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
int CCTgetTimeoutSite();
```

## Example

If the returned flag is 13, it is 1101 in binary. This means the SmarTest Work Center sites are site 1, 3 and 4.
