# Pass/Fail per label

#### Subtopics

- [Pass/Fail per label with digital capture](<02.07.13.08.09.01_Pass_Fail_per_label_with_digital_capture.md>)
- [Pass/Fail per label without break vectors](<02.07.13.08.09.02_Pass_Fail_per_label_without_break_vectors.md>)

SmartRDI provides the Pass/Fail-per-Label feature to return functional test results per label.

If you intend to use this feature, you must assign result IDs first in your code. The feature depends on a result ID used together with any one of the following functions:

- [expectBit()](<02.07.13.24.12_expectBit.md>) or [expectData()](<02.07.13.24.13_expectData.md>) in the smartVec() class
- [enPassFail()](<02.07.13.13.09_enPassFail.md>) in the dc(), digCap(), and smartVec() class
- id in the func() class
- [enPassFail()](<02.07.13.21.03_rdi.tmu__.enPassFail.md>) in the tmu() class

## Result modes

SmartRDI provides two modes FLBL and ERMP to get Pass/Fail per label.

You must define one of the two modes in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>) as follows:

- PER_LABEL_FUNC_RESULT_MODE = FLBL; or
- PER_LABEL_FUNC_RESULT_MODE = ERMP

The ERMP mode has better multisite efficiency (MSE) than FLBL.

  Note For the SmartRDI versions earlier than 2.5.0, FLBL is the default value. Instead, ERMP becomes the default value from SmartRDI 2.5.0.

## Examples

### Returning functional test results per label

```
RDI_BEGIN();
  rdi.smartVec("1").pin("Pin2")
                   .expectData(20,2)
                   .execute();
  rdi.dc("2").label("pat1")
             .insertSub(10)
             .pin("VI1")
             .vForce(1)
             .enPassFail()
             .execute();
  rdi.func("3").label("Label1")
               .execute();
RDI_END();
```

### No ID, no Pass/Fail result per label

```
RDI_BEGIN();
  rdi.smartVec().pin("Pin1")
                .writeData(20,8,2)
                .pin("Pin2")
                .expectData(20,2)
                .execute();
  rdi.func().label("Label1")
            .execute();
RDI_END();
```
