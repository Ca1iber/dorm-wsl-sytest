# SMC_UPLOAD_STATUS.toString()

Returns a formatted representation of all attributes of a SMC task stored in a vector that is populated by [SMC_GET_UPLOAD_STATUS()](<02.07.04.01.231.16_SMC_GET_UPLOAD_STATUS.md>).

## Syntax

```
STRING toString() const;
```

List of parameters

There are no parameters.

## Return value

A formatted representation of all attributes as string.

## Example

This example shows how to create a vector of type `SMC_UPLOAD_STATUS` and how to retrieve all attributes from the vector.

Note As `SMC_UPLOAD_STATUS` represents a collection, one has to iterate over the collection to obtain the item.

```
typedef vector<SMC_UPLOAD_STATUS> SmcUploadStatusVector;
string Info;

// Obtain the collection
SmcUploadStatusVector statusVector = SMC_GET_UPLOAD_STATUS();

// iterate through collection
for(SmcUploadStatusVector::iterator it = statusVector.begin();
     it != statusVector.end(); ++it) {
        Info = it->toString();
        cout << "SMC upload type:" << Info << endl;
     }
```
