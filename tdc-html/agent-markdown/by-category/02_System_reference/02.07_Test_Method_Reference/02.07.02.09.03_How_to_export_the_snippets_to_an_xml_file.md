# How to export the snippets to an xml file

To reuse your snippets somewhere else, you need to export the snippets to an xml file and then import the file where you need it.

## About this task

The .xml file is in the format below. Below is a `` template file containing the snippet `V93000_ADC_MeasurementSetup`.

```
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<templates>
<template autoinsert="true" context="org.eclipse.cdt.ui.text.templates.c" deleted="false" description="[Version]: tml1.2.0_6.5.4" enabled="true" name="V93000_ADC_MeasurementSetup">
string awgPin = "awgPin";
string vecVarForAwgPin = "vecForAwgPin";
string resultArea = "adcBitArea";
int resultAreaSize = 128000;
string capturePinlist = "dig1,dig2,dig3";
ON_FIRST_INVOCATION_BEGIN();
  Routing.pin(awgPin).connect(TM::SINGLE);
  Analog.AWG(awgPin).enable();
  RESULT_AREA_CONFIG resultConfig(capturePinlist);
  resultConfig.appendArea(resultArea,resultAreaSize).activate();
  SMC_DIGITAL_CAPTURE_TEST(100 ms, resultArea);
  Analog.AWG(awgPin).disable();
  Routing.pin(awgPin).disconnect();
ON_FIRST_INVOCATION_END();

// kick off upload and caculation
SMC_ARM(vecVarForAwgPin,resultArea,awgPin);</template></template>
```

## Procedure

-  To open the Templates page, click Window > Preferences > C/C++ > Editor > Templates.
-  In the Templates page, select the snippets you want to export and click Export. The Export Templates dialog box will be displayed. You can use the Shift or Ctrl key to select multiple templates.
-  In the Export Templates dialog, enter the file name and select the folder to save the file.
-  Click OK.

## Results

An xml file is created containing the snippets you selected.

## What to do next

Import the snippet file where you need it.
