# TESTSET().judgeAndLog_DpsVfim()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) performs a pass/fail judgment of an V-force I-measure DC test with the DPS and logs the results.

Optional values for this function can be set by prior methods, for example, [port()](<02.07.04.01.244.19_TESTSET__.port.md>), [cont()](<02.07.04.01.244.03_TESTSET__.cont.md>), [reliability()](<02.07.04.01.244.20_TESTSET__.reliability.md>), or [testname()](<02.07.04.01.244.23_TESTSET__.testname.md>).

## Syntax

```
bool judgeAndLog_DpsVifm(const DPS_VFIM &dpsVfim, INT logTestNumber = DEFAULT_LOGTESTNUMBER_VALUE);
```

 |

Parameter

 |

Description

 |
 |

dpsVifm

 |

The [DPS_VIFM](<02.07.04.01.51_DPS_VFIM.md>) constructor which specifies a DC test to be judged.

 |
 |

logTestNumber

 |

An optional test number.

If this test number is provided, it overrides the actual test number. If it is not provided, the actual test number is logged.

   | Note Only the first six digits of values are ensured to be correctly logged into the STDF file.

## Return Value

The pass/fail result of the judgment is returned. It can be true for pass or false for fail.

## Example

```
DPS_VFIM dps("@");
dps.min_current(1).max_current(3).preAction("NONE");
dps.execute();
bool rslt = dps.getPassFail();
if(rslt)
  cout << "GPF: PASS" << endl;
else
  cout << "GPF: FAIL" << endl;
TESTSET().judgeAndLog_DpsVfim(dps);
```
