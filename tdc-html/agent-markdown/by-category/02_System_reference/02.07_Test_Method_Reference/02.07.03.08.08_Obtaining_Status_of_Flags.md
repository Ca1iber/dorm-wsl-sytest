# Obtaining Status of Flags

To obtain the current status of the flags such as testflow flags, system flags, and testsuite flags, you can use the following APIs.

 |

The task to be executed....

 |

Use this API....

 |
 |

Provide access to the testflow flag

 |

GET_TESTFLOW_FLAG(params)

 |
 |

Provide access to the system flag

 |

GET_SYSTEM_FLAG(params)

 |
 |

Provide access to the testsuite flag

 |

GET_TESTSUITE_FLAG(params)

   |  Note params means the parameters to be specified.

For details, see [GET_TESTFLOW_FLAG](<02.07.04.01.96_GET_TESTFLOW_FLAG.md>), [GET_SYSTEM_FLAG](<02.07.04.01.94_GET_SYSTEM_FLAG.md>), and [GET_TESTSUITE_FLAG](<02.07.04.01.100_GET_TESTSUITE_FLAG.md>).
