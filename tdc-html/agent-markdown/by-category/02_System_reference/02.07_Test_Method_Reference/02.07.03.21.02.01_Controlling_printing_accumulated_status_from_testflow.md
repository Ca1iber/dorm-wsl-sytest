# Controlling printing accumulated status from testflow

By setting up a user flag in testflow, you can control whether to include the accumulated status in the automatically saved tester status outputs (ASCII files) when testflow execution completes.

## About this task

When the user flag enableTestsuitesPreAndPostHWStateLogging is enabled in testflow, tester status are automatically saved to text files when testflow execution completes. See [Printing tester status from testflow](<02.07.03.21.02_Printing_tester_status_from_testflow.md>) for details. A user flag enableAccumulatedStateLogging provides further control of whether accumulated status are included in the outputted tester status. This flag controls two types of accumulated status: the Power Supply Accumulated Status, as which is retrieved by the [PSAS?](<../02.06_Command_Reference/02.06.02.02.188_PSAS__-__Power_Supply_Accumulated_Status.md>) firmware command and the Channel Slot Accumulated Status, as which is retrieved by the [CSAS?](<../02.06_Command_Reference/02.06.02.02.33_CSAS__-__Channel_Slot_Accumulated_Status.md>) firmware command.

## Before you begin

Check that your SmarTest has a version no less than 7.5.3.

Make sure that your device works properly.

Make sure the enableTestsuitesPreAndPostHWStateLogging user flag is enabled, as described in [Printing tester status from testflow](<02.07.03.21.02_Printing_tester_status_from_testflow.md>).

## Procedure

-  In the Test Program Explorer panel, right-click Test Program and load your test program.
-  Right-click Testflow and select Load All Setups.
-  Right-click Testflow and select Open With > Flow Data Editor.
-  Select the Variables tab.
-  Add the user flag enableAccumulatedStateLogging.

  -  In the Variables tab, right-click and select Add Variable....
  -  On the Add Variable window displayed, select USERFLAG for Type.
  -  Enter enableAccumulatedStateLogging for Name.
  -  Enter a value for Value.

Enter 1 to include the accumulated status in the tester status outputs, or enter 0 to exclude them from the tester status outputs.

-  Right-click Testflow and select Open With > Flow Sequence Editor.
-  Right-click the testflow displayed in the flow sequence editor and select Run Testflow.

## Results

After testflow execution, tester status are printed to text files in the TestsuitesPreAndPostHWStateLog folder under <your device root>/waste.

For each site, a pair of pre-run and post-run hardware status logs are saved.

## Example

If you open the saved files with a text editor, the outputs look the same as what you print to System console using the Print Tester Status button. See [Printing tester status from system control](<02.07.03.21.01_Printing_tester_status_from_system_control.md>) for an example of outputs.

## What to do next

See also [Printing tester status from test method](<02.07.03.21.03_Printing_tester_status_from_test_method.md>) if you need to customize your outputs.
