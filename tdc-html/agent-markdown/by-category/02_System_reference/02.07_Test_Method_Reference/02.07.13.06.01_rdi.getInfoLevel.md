# rdi.getInfoLevel()

Retrieves the information level value that has been specified by setInfoLevel().

This function works together with [setInfoLevel()](<02.07.13.06.02_rdi.setInfoLevel.md>) in test method.

## Syntax

```
int getInfoLevel();
```

## Example

Changing the RDI_INFO_LEVEL to 2

```
...
cout<<"RDI_INFO_LEVEL ="rdi.getInfoLevel()<<endl;
rdi.setInfoLevel(2);

RDI_BEGIN();
  rdi.dc().pin("DATA1").vForce(3 V).execute();
  rdi.dc().pin("DATA2").iForce(0 mA).vMeas().measWait(100 us).execute();
RDI_END();

cout<<"RDI_INFO_LEVEL ="rdi.getInfoLevel()<<endl;

rdi.setInfoLevel(0);
```
