# getLabelCycleNum()

Retrieves the cycle number of an existing pattern (label).

This function only supports retrieving a single label's cycle number. It cannot be used with a burst pattern.

## Syntax

```
int getLabelCycleNum(string Label);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

Label

 |

A single label's name.

 |

Return value

There is no return value.

 Note This command is not thread-safe. DO NOT put it into the [SMC_backgroundProcessing()](<02.07.04.01.231.01_SMC_ARM.md#_120107__s_SMC_backgroundProcessing>) function.

## Example

```
int iCycle=rdi.getLabelCycleNum("Label");
```

## Functional changes

- Introduced in SmartRDI 2.4.4
