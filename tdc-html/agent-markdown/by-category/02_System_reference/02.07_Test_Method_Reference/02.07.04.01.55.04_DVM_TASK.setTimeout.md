# DVM_TASK.setTimeout()

The setTimeout() member function sets the timeout in seconds when trying to establish a communication to the DMM (digital multimeter).

The default timeout for DVM_TASK is 50 seconds.

## Syntax

```
void setTimeout ( DOUBLE seconds )
```

Parameter
 |

Parameter

 |

Description

 |
 |

seconds

 |

The timeout in seconds [s]. The default is 50 seconds.

 |

Return value

There is no return value.
