# DC_WAVEFORM.vRange()

This function defines the input voltage range, for which the DC waveform gets created.

 Note To execute the waveform, the PPMU needs to be connected in the range.

## Syntax

```
DC_WAVEFORM & vRange (DOUBLE vRange);
```

Parameter
 |

Parameter

 |

Description

 |
 |

vRange

 |

The value of input voltage range for a DC waveform.

 |

## Return value

A DOUBLE data representing the input voltage range is returned.
