# GET_CONFIGURED_SITES

This API returns the number of sites set up in the pin configuration, and stores the site numbers into the array variable specified as the parameter.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SiteControl.h.

## Syntax

```
INT GET_CONFIGURED_SITES(ARRAY_I& sites);
```

Parameter
 |

I/O

 |

Parameter

 |

Description / Range

 |
 |

O

 |

sites

 |

The site numbers set up in the pin configuration are returned to the contents of this array variable.

 |

## Example

```
INT i, num_of_sites;
ARRAY_I sites;
...
...
num_of_sites = GET_CONFIGURED_SITES(sites);

for (i=0; i<num_of_sites; ++1)
{
    cout << sites[i] << "is configured\n";
}
...
...
```

If you have set up the four sites of the pin configurations (site number: 1 to 4), the GET_CONFIGURED_SITES returns 4 to the num_of_sites variable and stores the site number 1, 2, 3, and 4 into the contents of the sites variable. You can also describe this program as follows:

```
INT i;
ARRAY_I sites;
...
...
GET_CONFIGURED_SITES(sites);

for (i=0; i<sites.size(); ++1)
{
    cout << sites[i] << "is configured\n";
}
...
...
```
