# getFailCount()

This function returns the number of failed cycles for a specified pin.

## Syntax

```
int getFailCount(string pin)
```

List of parameters
 |

Parameter

 |

Description

 |
 |

pin

   | The name of the pin for which to count the fails.Note It can only be a single pin. Do not use multiple pins, a pin group or @ for all pins. |

## Example

### General example

```
int fcount=rdi.id("a").getFailCount("pinA");
```
