# UNSOLICITED_EVENT

The UNSOLICITED_EVENT class represents an event that is generated by the device, but is not the expected response to a request. Instances of this class cannot be created independently, but are defined by the hasUnsolicitedEvents() and getUnsolicitedEvents() functions of a SERIAL_LINK_TEST object. They can be accessed with the help of the UNSOLICITED_EVENT_ITERATOR object that is created by getUnsolicitedEvents().

## Syntax

### Member functions

```
Boolean hasFailed();
const& STRING getFailInfo();
UNSOLICITED_EVENT_TYPE getType();
Sequence<Byte> getData();
STRING getTransactionIdString();
STRING dump();
```

## Member functions

### hasFailed()

```
Boolean hasFailed();
```

This function returns TRUE if the respective unsolicited event caused the test to fail. The function has no parameters.

### getFailInfo()

```
const& STRING getFailInfo();
```

This function returns more information about an unsolicited event that caused the test to fail. The function has no parameters.

### getType()

```
UNSOLICITED_EVENT_TYPE getType();
```

This function returns the type of the unsolicited event. Possible types are:

 |

Event type

 |

Description

 |
 |

UE_ERROR_RESPONSE

 |

Events of this type can (but need not) be related to one or more transactions. They differ from events of the UE_DEBUG_RESPONSE in that they may have an effect on the continuation of the test.

 |
 |

UE_DEBUG_RESPONSE

 |

Events of this type can (but need not) related to one or a number of transactions They differ from events of the UE_ERROR_RESPONSE type in that they do not have an effect on the continuation of the test.

 |
 |

UE_TIMESTAMP_RESPONSE

 |

Events of this type provide a time stamp which can serve to structure the sequence of unsolicited events.

 |
 |

UE_UNKNOWN_TYPE

 |

This type refers to events that do not belong to one of the other three types.

 |

The function has no parameters.

### getTransactionIdString()

```
STRING getTransactionIdString();
```

This function returns a transaction ID. This is either the ID of the transaction with which the event is associated, or the ID of the last transaction before the event occurred. The transaction ID has the format:

transaction_sequence_type:occurrence_no:transactionIdString,

where transaction_sequence_type is the name of a persistent pattern (transaction sequence) or, if the transaction is MAPI generated, the string __MAPI_GENERATED_TS__, and occurrence_no counts either the instances of the persistent pattern, or the MAPI generated transaction sequences within the test method, starting from 0. If no transaction ID has been defined for the transaction, it will be automatically generated from information about the transaction, including its consecutive number within the test method.

The function has no parameters.

### dump()

```
STRING dump();
```

This function returns the internal data of the event. The function has no parameters.
