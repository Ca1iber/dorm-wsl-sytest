# Customized shmoo test template

#### Subtopics

- [The functions of the customized shmoo test method template](<02.07.07.02.01_The_functions_of_the_customized_shmoo_test_method_template.md>)

The customized shmoo test template is called "customized shmoo test method class" and used to [create a customized shmoo test method](<02.07.07.01_Creating_a_customized_shmoo_test_method.md>).

This template:

- Contains the [ac_tml.AcTest.Shmoo](<02.07.05.01.09_Shmoo.md>) test method class.

Therefore, a created shmoo test method contains all parameters and functions of the ac_tml.AcTest.Shmoo test method.

- Contains [different functions](<02.07.07.02.01_The_functions_of_the_customized_shmoo_test_method_template.md>) for you to:

  - Add new test method parameters.
  - Define results to be displayed on shmoo plots.
  - Perform actions before, during or after a shmoo test.
