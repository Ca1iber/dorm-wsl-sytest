# GPIB_OUTPUT

This API sends device-dependent GPIB command to the specified device, and returns 0 on success, non-zero when timeout occurred.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/GpibMapi.h.

## Syntax

```
INT GPIB_OUTPUT(INT address, STRING& command,
 TERM_COND term_condition,
 STRING& terminator);

INT GPIB_OUTPUT(INT address, INT address2,
 STRING& command,
 TERM_COND term_condition,
 STRING& terminator);
```

## Important points

- TERM_COND is a system-defined data type for setting a termination condition. The following specifiers can be set for this function.

TERM_COND data type
 |

Specifier

 |

Description

 |
 |

CRLF_EOI

 |

Adds CR+LF characters to the end of data and set EOI signal to true when lf character is output.(Default)

 |
 |

TERM_CRLF

 |

Adds CR+LF characters to the end of data.

 |
 |

TERM_EOI

 |

Sets the EOI signal to true at the last character of the data.

 |
 |

TERM_CHAR

 |

Adds the characters defined as the "terminator" parameter to the end of data.

 |

## Examples

### Send ASCII commands

```
INT address = 23;
STRING ascii_data = "BIAS 1.2V;FREQ 1MHz";
GPIB_OUTPUT( address, ascii_data );
```

The GPIB_OUTPUT API sends ASCII commands (or data) to the device at address 23.

### Send binary commands

```
STRING bin_data = "\255\69\20\35\253\254\255\16";
INT address = 23;
TERM_COND term_condition = TERM_EOI;
GPIB_OUTPUT( address, bin_data, term_condition );
```

The GPIB_OUTPUT API sends binary commands (or data) to the device at address 23.
