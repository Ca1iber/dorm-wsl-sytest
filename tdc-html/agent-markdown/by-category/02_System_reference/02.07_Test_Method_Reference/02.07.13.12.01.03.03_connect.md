# connect()

Connects a DPS pin. Supported DPS pins are the DC Scale pins in the DPS operating mode.

The function can be used only in the code鈥慴ased mode.

Note DC Scale pins must be configured for the DPS operating mode in the [DPS Pins editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.03_DPS_Pins_editor.md>). This function is not supported for the PMU operating mode of DC Scale pins.

## Syntax

```
dcBase& connect();
```

List of parameters

There are no parameters.

## Return Value

A reference to the dcBase object.

## Example

```
rdi.dc().pin("pinA").connect().execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
