# TIMING_OFFSET_SEARCH_PINS.TransitionOffsetFound()

This function returns the result status of the latest transition offset. It can be `NOT_FOUND`, `LB_NOT_FOUND`, `RB_NOT_FOUND` or `FOUND`.

## Syntax

```
TIMING_OFFSET_SEARCH::RESULT_FOUND TransitionOffsetFound();
```

## Functional changes

- Introduced in SmarTest 7.0.1
