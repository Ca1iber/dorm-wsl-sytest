# TESTSET().judgeAndLog_ScanTest()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) performs a pass/fail judgment of the scan test results specified by a SCAN_TEST_RESULT object and logs the results.

Optional values for this function can be set by prior methods, for example, [port()](<02.07.04.01.244.19_TESTSET__.port.md>), [cont()](<02.07.04.01.244.03_TESTSET__.cont.md>), [reliability()](<02.07.04.01.244.20_TESTSET__.reliability.md>), or [testname()](<02.07.04.01.244.23_TESTSET__.testname.md>).

This function creates entries in the data log only if some requirements are met:

- SmarTest must be set to create STDF V4/2007 or V4/2007.1 by specifying `stdfVersion="V4/2007"` or `stdfVersion="V4/2007.1"` in the [formatter.stdf.main.conf](<../02.10_Data_Logging/02.10.03.04.03_Configuring_the_contents_of_the_STDF_file.md>) file.
- An error must have occurred.

If no errors occur, no STR records are created.

- For pattern‑based logging, the test pattern must include the [VCAT](<../02.06_Command_Reference/02.06.02.02.318_VCAT__VCAT__-__VeCtor_ATtachment.md>) firmware command.

## Syntax

```
bool judgeAndLog_ScanTest(const SCAN_TEST_RESULT& scanTest);
```

 |

Parameter

 |

Description

 |
 |

scanTest

 |

The [SCAN_TEST_RESULT](<02.07.04.01.197_SCAN_TEST_RESULT.md>) object from which the scan test result is taken.

   | Note Only the first six digits of values are ensured to be logged to the STDF file correctly.

## Return Value

The pass/fail result of the judgment, where true is returned for pass and false for fail.

## Example

In the following example, scanPins, maxFailsPerPin, cycleBased, includeExpectedData and testerCycleMode are input parameters defined for the test method.

```
ERROR_MAP_TEST emap(testerCycleMode ? TM::TESTER_CYCLES : TM::XMODE_CYCLES);
SCAN_TEST_RESULT log(cycleBased ? TM::CYCLE_BASED_LOGGING : TM::PATTERN_BASED_LOGGING);

ON_FIRST_INVOCATION_BEGIN();
/* Setup the error map */
  emap.pin(scanPins).setLocation(TM::RAM)
      .setRecordingMode(TM::PF).setStartCycle(0);
  /* Execute functional test */
  CONNECT();
  FUNCTIONAL_TEST();
ON_FIRST_INVOCATION_END();

/* If functional test has passed, no further processing has to be done */
if(GET_FUNCTIONAL_RESULT())
{
  return S_OK;
}

/* Retrieve the overall failures for this site */
log.totalFailures(emap.getErrorCount());
log.totalCyclesExecuted(emap.getLastCycleExecuted());

STRING_VECTOR pins =
PIN_UTILITY::getDigitalPinNamesFromPinList(scanPins,TM::O_PIN | TM::IO_PIN);

/* Retrieve the failing cycles per pin for this site */
for(int i=0; i<pins.size(); i++)
{
  INT failsToUpload = 1;
  if(-1 == maxFailsPerPin)
  {
    failsToUpload = emap.pin(pins[i]).getErrorCount();
  }
  else {
    failsToUpload = maxFailsPerPin;
  }

  ARRAY_LL cycles;
  emap.pin(pins[i]).getFirstFailingCycles(0, failsToUpload, cycles);
  log.pin(pins[i]).failingCycles(cycles);

  if(includeExpectedData)
  {
    ARRAY_CHAR expected;
    emap.pin(pins[i]).getExpectedDataForCycles(cycles, expected);
    log.pin(pins[i]).expectedData(expected);
  }
}
/* Push the failures to datalog */
TESTSET().cont(true).judgeAndLog_ScanTest(log);
```
