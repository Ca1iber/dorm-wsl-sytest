# PPMU_BADC_PIN_MEASURE

The PPMU_BADC_PIN_MEASURE class is the data container holding the object reflecting the BADC measurement modes. The PPMU_BADC_PIN_MEASURE object can only be accessed via the [PPMU_BADC_MEASURE](<02.07.04.01.153_PPMU_BADC_MEASURE.md>) class.

 CAUTION You must turn off site matching (see [Controlling the site match function](<../02.06_Command_Reference/02.06.03.01.10.04_Controlling_the_site_match_function.md>)) when sharing BADC(s) over sites, to ensure proper pattern-controlled DC value measurements with the BADC.

## Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/PpmuBadcPinMeasure.h.

  Constructor This class has no constructor. Member functions

- [execMode()](<02.07.04.01.153.01_PPMU_BADC_PIN_MEASURE.md#_144109__dle_execMode>)

## Member functions

  execMode()

```
PPMU_BADC_PIN_MEASURE & execMode( const TM::DCTEST_MODE& mode);
```

This function selects the measurement mode.

  Parameters

 | Parameter  | Description  |   | |
 | mode |

The measurement mode of type TM::DCTEST_MODE.

The following values are supported:

 |
 |   | TM::PVAL |

This mode selects a per-pin value measurement. In this mode, also the Global Pass/Fail result and the Per-pin Pass/Fail result are set.

This is the default mode.

 |
 | TM::OVAL |

This measurement mode delivers only a measurement value, but no pass/fail information.

This measurement mode is faster than the measurement in the TM::PVAL mode. Use it when throughput is important.

   |   Return value A reference to the PPMU_BADC_PIN_MEASURE object.   numberOfSamples()

```
PPMU_BADC_PIN_MEASURE & numberOfSamples (const INT numberOfSamples);
```

This function defines how many samples are taken for a value measurement.

  Parameter

 | Parameter  | Description |
 | numberOfSamples |

The number of samples to be taken for a value measurement.

For dynamic BADC measurements on the PS1600 the default number of samples is 1. It can be increased to fulfill the [PS1600 Board ADC specification](<../02.02_Specifications/02.02.04.01.07_PS1600_board_ADC.md>).

   |  Return value A reference to the PPMU_BADC_PIN_MEASURE object.
