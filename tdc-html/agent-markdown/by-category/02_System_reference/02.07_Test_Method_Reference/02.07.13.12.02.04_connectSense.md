# connectSense()

Connects only the sense line of a DC Scale pin.

This connection mode is used for [high impedance voltage measurements](<../02.05_Test_Head_Cards/02.05.05.05.02_Measuring_current_or_voltage_in_PMU_operating_mode.md>) with the DC Scale pin in PMU operating mode.

The function can be used only in the code鈥慴ased mode.

## Syntax

```
dcBase& connectSense();
```

## Return Value

A reference to the dcBase object.

## Example

```
rdi.dc().pin("DPS128_SIG_1").connectSense().execute();

RDI_BEGIN();

    rdi.dc().pin("DPS128_SIG_1").vMeas().execute(); // High-impedance measurement

RDI_END();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
- SmartRDI 2.4.2: AVI64 added.
