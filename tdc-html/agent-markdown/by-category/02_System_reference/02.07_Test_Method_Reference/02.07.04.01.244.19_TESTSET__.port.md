# TESTSET().port()

This member function of [TESTSET](<02.07.04.01.244_TESTSET.md>) applies only to multiport testing. The port name specified by the name parameter is judged and logged into the event data log stream.

This function is not supported within the SMC_backgroundProcessing() test method when flag [hidden_datalog_mode](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_hidden_datalog_mode>) is set to 0. (It is supported with hidden_datalog_mode set to 1 or 2.)

## Syntax

```
TESTSET & port(const STRING &name);
```

 |

Parameter

 |

Descriptions

 |
 |

name

 |

The port name defined in the pin configuration whose functional test result is judged and logged.

 |

## Example

```
TestSet.port("port1");
```
