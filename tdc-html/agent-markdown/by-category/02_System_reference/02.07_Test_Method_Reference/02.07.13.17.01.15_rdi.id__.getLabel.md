# rdi.id().getLabel()

This function returns the name of the label that is related with a specified result ID.

With SmartRDI, you can retrieve a result through a result ID. In a functional test, you can use this function to better understand the relation between a result ID and a label name.

## Syntax

```
string rdi.id().getLabel()
```

## Example

```
RDI_BEGIN();
  ...
  rdi.func("id1").label("abcd").execute();
  ...
RDI_END();

rdi.id("id1").getLabel() // Returns "abcd".
```

## Functional changes

- Introduced in SmartRDI 2.4.0
