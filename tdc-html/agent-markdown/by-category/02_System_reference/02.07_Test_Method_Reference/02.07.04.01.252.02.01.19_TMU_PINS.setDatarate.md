# TMU_PINS.setDatarate()

Sets the maximum expected data rate for the TMU pin(s).

SmarTest will calculate the proper values for prescaler and interdiscard. Interdiscard can be changed to a higher value. If a higher interdiscard is already set, it will not be changed to the calculated value. Interdiscard needs to be changed to a higher value for period and frequency measurement to get accurate results.

## Syntax

```
TMU_PINS& setDatarate(UINT64 rate);
TMU_PINS& setDatarate(UINT64 rate, TMU::DATARATE_DEPENDENT_VALUES_TYPE& settings);
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

rate

 |

The data rate. Its unit is bits/second.

 |
 |

O

 |

settings

 |

DATA_RATE_DEPENDENT_VALUES_TYPE is a data structure designed to receive the calculated values for the prescaler (prescaler member) and the interdiscard (Interdiscard member).

 |

## Return value

A reference to the TMU_PINS object is returned.
