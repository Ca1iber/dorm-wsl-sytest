# waveform()

Specifies the waveform to generate when used as AWG.

The waveform needs to be defined with SmartRDI class anaWaveform.

The function can be used only in the pattern‑based mode.

Refer to the compatible class [ANALOG_WAVEFORM](<02.07.04.01.05_ANALOG_WAVEFORM.md>) for the functions and description of SmartRDI class anaWaveform.

Starting from 7.10.3, RDI uses a separate MSET to achieve automatic switch between force modes for digital DC waveform. For example, if iForce() is used in a statement and vForce() and waveform() are used in the subsequent statement, RDI will automatically handle the mode change for the waveform generation.

  Note This function has some limitations on the pin()...pin()... parallel action structure. For the supported cases, refer to [DC waveform and sampling in parallel](<02.07.13.11.07_DC_waveform_and_sampling_in_parallel.md>).

## Syntax

```
dcBase& waveform(anaWaveform& waveform);
```

```
dcBase& waveform(string rtWave);
```

Parameter
 |

Parameter

 |

Description

 |
 |

waveform

 |

The waveform to generate.

 |
 | rtWave  | Runtime waveform. See [Runtime DC waveform](<02.07.13.11.02_Runtime_DC_waveform.md>). |

## Return value

A reference to the dcBase object.

 Note Do not use the same name for different waveform objects. For example,

```
anaWaveform wavSin("wavSin");
wavSin.definition(TM::SINE).periods(1).samples(256).amplitude(2.0 V);

anaWaveform wavSin2("wavSin"); // The same name "wavSin" used for this waveform is not allowed
wavSin2.definition(TM::SINE).periods(3).samples(1024).amplitude(3.0 V);
```

## Example

```
//generating sine waveform with digital pin and DPS pin
anaWaveform wavSin("wave");

wavSin.definition(TM::SINE).periods(19).samples(2048).amplitude(3 V).offset(3.5);

rdi.port("pt_DATA1").dc().pin("DATA1").waveform(wavSin).FS(100 KHz).vForce().execute();
rdi.dc().pin("DPS_SIG_1").vForce().waveform(wavSin).FS(10 KHz).execute();

//generating ramp waveform with digital pin
ramp.definition(TM::RAMP).periods(1).phase(180).direction(TM::POS).samples(270).min(0).max(3);
rdi.port("pt_DATA17").dc().pin("DATA17").vForce().waveform(ramp).FS(10 KHz).execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
- SmartRDI 7.10.3: RDI can automatically change the force mode for digital DC waveform.
