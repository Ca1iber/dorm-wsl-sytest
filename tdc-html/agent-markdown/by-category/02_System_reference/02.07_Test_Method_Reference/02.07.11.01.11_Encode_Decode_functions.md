# Encode/Decode functions

#### Subtopics

- [Syntax](<02.07.11.01.11.01_Syntax.md>)

Encoding and decoding are part of the protocol specification.

Both allow bit manipulations and the use of conditional expressions, arithmetic functions and a predefined set of functions/operators.

## Encode function

Describes how transaction and field parameter values are combined with data to form a state character sequence to be passed to the DUT.

## Decode function

Describes how parameter values are derived from bits received from the DUT or simulated patterns, to be translated to fields and transactions.

- Introduced in SmarTest 7.1.0
