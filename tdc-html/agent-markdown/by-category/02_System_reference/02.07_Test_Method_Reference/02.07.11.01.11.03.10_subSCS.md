# subSCS()

Extracts a part of a state character sequence.

It is able to reverse the order of the sequence characters.

The result is a state character sequence representing a part of the given sequence. The result can be fed into function toINT().

The parameters "start" and "length" must be integer constants. Parameter "direction" can be either +1 or -1.

In contrast to string operations, subSCS() counts the characters from the right side of the character sequence. The right most position has index position '0'.

The parameter "start" gives the index position of the start of the sequence to be extracted.

The parameter "length" specifies how many state characters are to be extracted. Extracting a part with length "0" is allowed and returns an empty string.

The parameter "direction" specifies in what direction the state characters are extracted.

- "-1" means from the start position to the right (towards index position '0').
- "+1" means from the start position to the left (away from index position '0').

Errors will be issued if,

- start is outside the sequence pr
- the end position ("start" + "length") is outside the sequence or
- parameter types are incorrect.

## Syntax

```
sequence := subSCS(sequence, start, length , direction)
```

## Example

subSCS`("abcd", 0, 2, +1)` results in "`dc`".

subSCS`("abcd", 2, 3, -1)` results in "`bcd`".

subSCS`("abcd", 2, 0, -1)` results in "".

subSCS`("abcd", 2, -2, 1)` results in "ERROR: Parameter 'length' must be >= 0."

subSCS`("abcd", 2, 0, -2)` results in "ERROR: Parameter 'direction' must be +1 or -1."

subSCS`("abcd", 2, 2, 1)` results in "ERROR: access outside string boundaries" (because index 4 is invalid).
