# TIMING_OFFSET_SEARCH_PINS.uploadTimingOffset()

This function uploads the measured timing offsets of the specified timing set and edge type.

## Syntax

```
void uploadTimingOffset(TIMING_OFFSET_SEARCH::TimingSetSelector& target,
                        TIMING_OFFSET_SEARCH::EDGE_TYPE edgetype);
```

Parameters
 |

target

 |

The timing set to work with.

 |
 |

edgetype

 |

The edge type to use. It can be:

- TIMING_OFFSET_SEARCH::RECEIVE: receive edges
- TIMING_OFFSET_SEARCH::FAST_DRIVE: fast drive edges
- TIMING_OFFSET_SEARCH::SLOW_DRIVE: slow drive edges
- TIMING_OFFSET_SEARCH::DRIVE: drive edges
- TIMING_OFFSET_SEARCH::ALL_EDGES: all edges
 |

## Functional changes

- Introduced in SmarTest 7.1.0
