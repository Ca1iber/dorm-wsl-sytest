# MEMORY_IMAGE

The MEMORY_IMAGE class provides data blocks that can be loaded into the XRAM. The memory images can be used to

- initialize the ERAM,
- provide the expected final state of the ERAM, to be compared to the actual state,
- supply sequential memory for the emulation,
- serve as a container into which ERAM data can be uploaded.

The images are cached by the software and loaded automatically into the XRAM if required, that is, only if the respective image is not already present in the XRAM.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/MemoryImage.h.

## Syntax

### Member functions

```
static MEMORY_IMAGE& getReference(const STRING& memoryImageName);
void initialize(INT size, unsigned int value = 0);
void set(INT xramAddress, INT value);
void set(INT xramAddress, const ARRAY_I& values);
void set(INT xramAddress, const MEMORY_IMAGE& image);
INT get(INT xramAddress);
void get(INT xramAddress, ARRAY_I& values);
void get(INT xramAddress, MEMORY_IMAGE& image);
void load(const STRING& filename);

void save(const STRING& filename);
```

## Constructor

There is no constructor for this class.You must use the following class functions to create, access or delete a memory image:

### getReference()

```
static MEMORY_IMAGE& getReference(const STRING& memoryImageName);
```

This function returns a reference to the specified memory image. If no memory image with the specified name exists, it will be created.

### set()

```
void set(INT xramAddress, INT value);
void set(INT xramAddress, const ARRAY_I& values);
void set(INT xramAddress, const MEMORY_IMAGE& image);
```

This function

- sets the word at the specified absolute address to the specified value, or
- sets a segment of the image which starts at the specified address to the values specified in the array, or
- copies the content of a specified image to the specified address in the calling memory image object.

### get()

```
INT get(INT xramAddress);
void get(INT xramAddress, ARRAY_I& values);
void get(INT xramAddress, MEMORY_IMAGE& image);
```

This function

- returns the value of the word at the specified absolute address, or
- copies the values of n consecutive words, starting at the specified address, into an array of length n, or
- copies the values of n consecutive words, starting at the specified address, into an image of size n.
