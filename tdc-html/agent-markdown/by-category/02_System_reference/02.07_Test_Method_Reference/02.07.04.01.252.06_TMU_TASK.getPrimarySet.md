# TMU_TASK.getPrimarySet()

Returns the name of the current primary TMU set.

## Syntax

```
static const STRING& getPrimarySet();
```

List of parameters

There are no parameters.

## Return value

The name of the current primary set is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
