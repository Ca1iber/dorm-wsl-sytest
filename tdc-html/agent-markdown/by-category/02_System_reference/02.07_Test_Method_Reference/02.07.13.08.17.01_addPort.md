# addPort()

`addPort()` adds one or more ports into a specific sync group.

## Syntax

```
addPort(string port)
```

## Example

```
rdi.syncGroup("sg1").addPort("ptA");
rdi.syncGroup("sg2").addPort("ptB").addPort("ptC");

RDI_BEGIN();
  rdi.port("ptA")...
  rdi.port("ptB")...
  rdi.port("ptC")...
RDI_END();
```
