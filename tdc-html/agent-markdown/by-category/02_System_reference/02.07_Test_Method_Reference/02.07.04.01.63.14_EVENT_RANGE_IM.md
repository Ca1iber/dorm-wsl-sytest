# EVENT_RANGE_IM

Measurement range classes provide functionality to define events to select measurement ranges.

Specialized measurement range classes are EVENT_RANGE_IM (Current Measurement Range Event) and [EVENT_RANGE_VM](<02.07.04.01.63.16_EVENT_RANGE_VM.md>) (Voltage Measurement Range Event). Both classes derive from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

EVENT_RANGE_IM defines the current range measurements.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Member functions

### iRange(), getIRange()

```
EVENT_RANGE_IM & iRange(
        const EVENT_VALUE_DOUBLE & minValue,

        EVENT_VALUE_DOUBLE & maxValue,

```

These member functions set and query the current range.

Parameters
 |

minvalue

 |

Minimum current. The default unit is A.

 |
 |

maxvalue

 |

Maximum current. The default unit is A.

 |
 |

accuracy

 |

Possible values are:

TM::RANGE_ACCURACY_STD

TM::RANGE_ACCURACY_HIGH

 |

## Example

Defines an event to select a high accuracy current measurement range from 0 uA to 50 uA:

```
EVENT_RANGE_IM measRngEventA("setRange50uA");
measRngEventA.iRange(0 uA, 50 uA, TM::RANGE_ACCURACY_HIGH);
```
