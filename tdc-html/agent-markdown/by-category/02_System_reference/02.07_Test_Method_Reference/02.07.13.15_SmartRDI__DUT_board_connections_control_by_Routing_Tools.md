The Routing Tools feature native multisite handling, user friendly table based configuration editors and a unified programming interface for controlling utility lines.

The Routing Tools are a combination of the [Routing Tools editors](<02.07.13.15.01_Routing_Tools_editors.md>) and the [rdi.route()](<02.07.13.15.05_rdi.route.md>) class of SmartRDI. The rdi.route() class, which is described in this section, applies the data, that are defined using the Routing Tools editors, to the controlled hardware.

The Routing Tools provide additionally the following features:

- Static and pattern鈥慴ased control of utility lines
- Definition of switch behavior and wait time handling
- Automatic generation and download of control pattern supported by SmartRDI
  ![Routing Tools overview](<../../../../raw/153247.png>)

The Routing Tools consist of the combination of the Routing Tools editors as shown above and corresponding APIs of SmartRDI. that are described in this section. Configuration data exchange between the editors and SmartRDI is realized by an XML file.

 Note The editors of the Routing Tools are a plug-in for the SmarTest Eclipse Work Center. The Routing Tools require that SmartRDI is installed. For information on how to install SmartRDI refer to [Installing and using SmartRDI](<02.07.13.02_Installing_and_using_SmartRDI.md>). Note The PMUX cards are currently not supported with SmarTest 7.10.x

## Overview of the Routing tools APIs

 | API  | Description  | Mode |
 | [rdi.route().downloadPmuxMemSet()](<02.07.13.15.05.02_rdi.route__.downloadPmuxMemSet.md>)  | Download PMUX states.  | C |
 | [rdi.route().applyState()](<02.07.13.15.05.01_rdi.route__.applyState.md>)  | Apply selected state for utility lines or PMUX switches.  | C + P |
 | [rdi.route().pin().setOn()](<02.07.13.15.05.05.02_rdi.route__.pin__.setOn.md>)  | Close single PMUX switch or a list of PMUX switches.  | P |
 | [rdi.route().pin().setOff()](<02.07.13.15.05.05.01_rdi.route__.pin__.setOff.md>)  | Open single PMUX switch or a list of PMUX switches.  | P |
 | [rdi.route().reset()](<02.07.13.15.05.06_rdi.route__.reset.md>)  | Reset all PMUX switches and utility lines.

The reset state is defined as follows:

- Utility line switch to UGND is open
- PMUX switch is open
  | C |
 | [rdi.route().enableOnlyActiveSites()](<02.07.13.15.05.03_rdi.route__.enableOnlyActiveSites.md>)  | Enables the utility line and PMUX switch settings on active sites and disables them on inactive sites.  | C  | Mode: C = Code鈥慴ased, P = Pattern鈥慴ased
