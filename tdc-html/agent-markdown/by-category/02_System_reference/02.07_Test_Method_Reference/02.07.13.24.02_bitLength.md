# bitLength()

Specifies the length of the bit stream. If not specify, the bitLength is automatically determined by [writeBit()](<02.07.13.24.35_writeBit.md>)/ [readBit()](<02.07.13.24.28_readBit.md>)/ [fillBit()](<02.07.13.24.18_fillBit.md>)/[expectBit()](<02.07.13.24.12_expectBit.md>).

## Syntax

```
bitLength(int length);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

length

 |

The length of the bit stream.

   | Note If the pattern contents exceed the length defined by the bitLength() parameter, the length of the generated pattern refers to the actual contents' length.

## Example

```
RDI_BEGIN();
  rdi.smartVec().pin("DATA1").defaultBit(0).bitLength(10).execute();
RDI_END();
```
