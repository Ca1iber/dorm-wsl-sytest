# Transaction ports without a protocol

## About this task

The d2s-framework allows to add static pattern that do not use a protocol to a burst label. The protocol-less port does not need to inherit the d2s protocol methods, because it is not used for read and write transactions.

The general behavior of the d2s-framework in learning and production mode does not change.

This task shows how to register a static pattern to the d2s-framework using the [execLabel()](<02.07.04.01.21.07_d2s_execLabel.md>) method.

## Before you begin

You have to have a static pattern prepared.

Ensure you have carried out all preparation and configuration steps as described in [Prepare device setup](<02.07.09.04.01_Prepare_device_setup.md>), [Prepare the test method infrastructure](<02.07.09.04.02_Prepare_the_test_method_infrastructure.md>) and [Configure the protocol](<02.07.09.04.03_Configure_the_protocol.md>).

## Procedure

-  Create a d2sFramework handle.

```
d2sFramework fr;
```

This framework handle ("`fr`") will be used to access the d2sFramework methods.

-  Instantiate your protocol, for example. `d2sJTAG`.

```
d2sJTAG& jtag = d2sJTAG::Instance();
```

The `jtag ` object reflects your protocol. It uses your protocol file, for example `d2sJTAG.h` to handle transactions, like write and read.

-  Create a transaction port handle or your static protocol.

```
TransactionPort io("IO_PORT");
```

-  Register your protocol and the transaction port handle with the framework.
-  Enable pass/fail results for your static pattern, if required.

```
io.enablePassFailCheckForNextExecution();
```

-  Define the d2s-block's begin API with the appropriate details, like burst label name and mode. For example

```
fr.d2s_LABEL_BEGIN("concurrentWrite", d2sFrameWorkModeType::LearningMode);
```

-  Specify each port specific transactions within the d2s-block.

```
jtag.write(0x0, 0x5);
jtag.read(0x4, "0x4");
jtag.execLabel("arbPassPattern_jtag", 1024);
```

-  Call the `execLabel()` method within the d2s-block for your static pattern.

```
io.execLabel("resetPattern", 16);
io.execLabel("prbsPattern", 1024);
```

-  Call the d2s-block's and API.

## Example

The following code snippet illustrates how a static pattern can be executed within the d2s-framework.

```
virtual void run()
{
   // step 1
   d2sFramework fr;

   // step 2
   d2sJTAG& jtag = d2sJTAG::Instance();

   // step 3
   TransactionPort io("IO_PORT");

   // step 4
   fr.registerTransactionPort(jtag);
   fr.registerTransactionPort(io);

    ON_FIRST_INVOCATION_BEGIN();

       // step 5
       io.enablePassFailCheckForNextExecution();

       // step 6
       fr.d2s_LABEL_BEGIN("concurrentWrite", d2sFrameWorkModeType::LearningMode);

          //step 7
          jtag.write(0x0, 0x5);
          jtag.read(0x4, "0x4");
          jtag.execLabel("arbPassPattern_jtag", 1024);

          // step 8
          io.execLabel("resetPattern", 16);
          io.execLabel("prbsPattern", 1024);

       // step 9
       fr.d2s_LABEL_END();
   ON_FIRST_INVOCATION_END();

   if(io.hasPassed("concurrentWrite"))
   {
      cerr << "test has passed on port >>IO_PORT<<" << endl;
   }
   else
   {
      cerr << "test has failed on port >>IO_PORT<<" << endl;
   }

   cerr << "read value on jtag: 0x" << hex << jtag.getReadValue("0x4") << endl;
}
```
