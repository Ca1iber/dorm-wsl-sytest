# EVENT_VM

Measurement event classes provide functionality to define events doing measurements. There are functions to set and query limits or to configure clamp and out-of-range checks.

EVENT_VM allows voltage measurements without limits, with high and low voltage limits, and with clamp checks.

## Classs definition

Specialized measurement event classes are EVENT_VM (Voltage measurement event) and [EVENT_IM](<02.07.04.01.63.12_EVENT_IM.md>) (Current measurement event).

Both classes derive from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

   |     clampChecks(), iClampChecks(), getClampChecks(), getIClampChecks()

```
EVENT_VM & clampChecks (bool failOnLow  = true, bool failOnHigh = true);
EVENT_VM & iClampChecks(bool failOnLow  = true, bool failOnHigh = true);

void getClampChecks (bool & failOnLow, bool & failOnHigh) const;
void getIClampChecks(bool & failOnLow, bool & failOnHigh) const;
```

These member functions set and query the current clamp checks or the voltage clamp checks.

The selected clamp checks for current or voltage are defined by the active force mode of the target pin:

- The current clamp checks are set and queried if the pin is forcing voltage.
- The voltage clamp checks are set and queried if the pin is forcing current.

Per default these checks are off. If they are enabled and a checked clamp is hit, the event contributes with a FAIL to the global test result.

Both the clampChecks() member function and the iClampChecks() member function control the same functionality of the hardware. The same behavior applies for the two get...() member functions.

## Example

Defines a voltage measure event without limit checks:

```
EVENT_VM measEventV("measV");
measEventV.averages(1);
```

Defines a voltage measure event with limit and clamp checks:

```
EVENT_VM checkedMeasEventV("measV_lim1");
checkedMeasEventV.averages(4);
checkedMeasEventV.limitLow(0 V);
checkedMeasEventV.limitHigh(3 V);
checkedMeasEventV.iClampChecks();
```
