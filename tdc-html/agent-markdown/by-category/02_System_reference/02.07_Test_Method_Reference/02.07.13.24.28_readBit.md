# readBit()

Reads the specified length of bits from the specified starting position. Usually, readBit() is used with [getReadBit()](<02.07.13.24.47_getReadBit.md>).

## Syntax

```
readBit(int bitLength,int startBit);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

bitLength

 |

The length of the bits to be read

 |
 |

startBit

 |

The starting position of the bits to be read. If the "startBit" parameter missing, the default value is 0.

 |

## Example

```
RDI_BEGIN();
rdi.smartVec().pin("DATA1").readBit(4,2).execute();
RDI_END();
```
