# SET_MULTIBIN

This API is used to set the multi-bin information of the testflow.

The last SET_MULTIBIN call with passed = false overwrites the results of previous ones in the same test method, see last example in the Example > Behavior section.

Note Do not use the API in the SmartCalc framework.

## Requirements

- A multibin icon inserted in the fail branch of the test suite, see the Multibin section in [Inserting a bin into the testflow](<../02.08_Setup_and_Result_Tools/02.08.04.32.02.01.05_Inserting_a_bin_into_the_testflow.md>).
- The bin used in SET_MULTIBIN() is a normal or a floating bin in the testflow.

## Syntax

```
void SET_MULTIBIN(const char* softbin, int hardbin);
void SET_MULTIBIN(const STRING& softbin, int hardbin);
void SET_MULTIBIN(const char *softbin);
void SET_MULTIBIN(const STRING& softbin);
void SET_MULTIBIN(const int softbin);
```

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

  Parameters

 | I/O  | Parameter  | Description |
 | I  | softbin |

The software bin number of the multibin.

To be compatible with STDF, the number must be between 0 and 32767.

 |
 | I  | hardbin  | The hardware bin number of the multibin.  |  Return value There is no return value.

## Examples

### Example 1: General usage

```
bool passed=true;

ON_FIRST_INVOCATION_BEGIN();

    CONNECT();

    FUNCTIONAL_TEST();

ON_FIRST_INVOCATION_END();

//Functional results are cached for each site by the API
if (!TESTSET().cont(true).judgeAndLog_FunctionalTest())
{
    SET_MULTIBIN("22", 12);

    //The devices which fail at the first functional test fall in bin 12.
    passed = false;
}
```

The devices, which fail at the first functional test fall in bin 12.

### Example 2: Behavior

```
if (!TESTSET().cont(true).judgeAndLog_ParametricTest(pin,"param1",limit,value1))
{
    SET_MULTIBIN("22", 2);
}

if (!TESTSET().cont(true).judgeAndLog_ParametricTest(pin,"param2",limit,value2))
{
    SET_MULTIBIN("33", 3);
}
```
