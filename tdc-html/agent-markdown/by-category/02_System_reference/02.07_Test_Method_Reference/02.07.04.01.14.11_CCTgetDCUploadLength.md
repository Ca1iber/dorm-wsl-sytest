# CCTgetDCUploadLength

Retrieves the number of DC values for the native test suite in the combined DC test results generated by the merged burst pattern.

This function is usually used in the `preStart()`, `postStart()`, `process()` and `cleanup()` function but not used in the `init()` function of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
RESULT_POINT::DistanceType CCTgetDCUploadLength(const string& pin);
```

Parameter
 |

Parameter

 |

Description

 |
 |

pin

 |

The pin name. It can be a Smart Scale pin or a DC Scale pin.

 |

## Return value

The number of DC result values for the native test suite is returned.

## Example

```
DC_RESULT_ACCESSOR dcResultAccessor;
TM::RESULT_RANGE dcRange;
dcRange.first = CCTgetDCUploadStartIdx("pin1");
dcRange.length = CCTgetDCUploadLength("pin1");
dcResultAccessor.uploadResult("Pin1", dcRange);
ARRAY_D dc_pin1(dcRange.length);
dc_pin1 = dcResultAccessor.getValue("Pin1");
```
