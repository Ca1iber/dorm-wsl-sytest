# d2s-framework

#### Subtopics

- [Introduction](<02.07.09.01_Introduction.md>)

The d2s-framework (d2s: dynamic-to-static) enables the automated generation of static, highly test time efficient, vector labels while still maintaining the ability to dynamically change them during development.

This chapter describes the concept and a use case of the dynamic-to-static (d2s) framework.

## Functional changes

- Introduced in SmarTest 6.5.4
