# TMU_PINS.getPinsFinishedNotFailed()

Retrieves the pins that finished sampling without overrun errors and stores the pins in the parameter.

## Syntax

```
UINT32 getPinsFinishedNotFailed(STRING_VECTOR& pinvec, STRING& str, INT site)
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

pinvec

 |

A vector of string containing the pins that finished sampling without overrun errors.

 |
 |

O

 |

str

 |

A string containing the pins that finished sampling without overrun errors. The pins are separated with comma.

 |
 |

I

 |

site

 |

(optional)The site to retrieve. The default value is 0, representing all sites.

 |

## Return value

The number of pins that finished sampling without overrun errors is returned.
