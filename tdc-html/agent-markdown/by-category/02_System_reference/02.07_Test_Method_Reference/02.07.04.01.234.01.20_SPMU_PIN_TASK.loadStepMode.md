# SPMU_PIN_TASK.loadStepMode()

Selects a load step mode to adapt the dynamic behavior of a DC Scale pin.

For [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>), the FAST load step mode provides a shorter reaction time to load steps.

This member function is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

## Syntax

```
SPMU_PIN_TASK & loadStepMode(const STRING& mode);
```

 Parameter

 | Parameter  | Description |
 | mode |

Load step mode to be defined as string.

 Valid strings are

- "STD" (default) or
- "FAST"
See also [XPS256 programming - Load step response](<../02.05_Test_Head_Cards/02.05.05.03.10.11_XPS256_programming_-_Load_step_response.md>).   |   Return value A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.
