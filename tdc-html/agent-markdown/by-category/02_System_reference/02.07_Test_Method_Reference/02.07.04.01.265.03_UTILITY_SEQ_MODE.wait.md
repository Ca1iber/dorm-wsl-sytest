# UTILITY_SEQ_MODE.wait()

Specifies the time to wait before the setup of the utility pogo blocks is performed.

## Syntax

```
void wait(const DOUBLE& time);
```

  Parameter

 | Parameter  | Description |
 | time  | The time in the seconds [s].  |   Return value There is no return value.

## Functional changes

- Introduced in SmarTest 7.2.1
