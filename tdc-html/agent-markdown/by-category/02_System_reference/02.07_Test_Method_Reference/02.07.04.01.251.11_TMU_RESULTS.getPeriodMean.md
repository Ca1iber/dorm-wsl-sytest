# TMU_RESULTS.getPeriodMean()

Returns the mean period of the specified pin, measurement ID and site. The member function `uploadPeriodResults()` of TMU_PINS needs to be used before using this function.

## Syntax

```
DOUBLE getPeriodMean(STRING& pin, UINT32 meas = 1,UINT32 site = 0);
DOUBLE getPeriodMean(const char* pin,UINT32 meas = 1,UINT32 site = 0);
```

Parameters
 |

 |

Parameter

 |

Description

 |

 |

 |
 |

 |

The measurement ID.

 |
 |

I

 |

site

 |

The site to query. Default is 0, which means the current site.

 |

## Return value

The mean period is returned in the unit second.

## Functional changes

- Introduced in SmarTest 7.1.0
