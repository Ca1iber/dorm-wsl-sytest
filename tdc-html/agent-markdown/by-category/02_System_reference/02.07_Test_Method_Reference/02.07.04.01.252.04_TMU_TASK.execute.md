# TMU_TASK.execute()

Executes the TMU measurement for all pins defined in this task.

## Syntax

In practice, this means that it runs a [FTST?](<../02.06_Command_Reference/02.06.02.02.127_FTST__-__Functional_TeST.md>) command.

```
void execute();
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Functional changes

- Introduced in SmarTest 7.1.0
