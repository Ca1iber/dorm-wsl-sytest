# relay()

Specifies the relay action before and after the measurement for PPMU.

## Syntax

```
relay(TA::PPMU_RELAY_ACTION rly_before,TA::PPMU_RELAY_ACTION rly_after);
relay(TA::PPMU_RELAY_ACTION rly_before);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

rly_before

 |

The relay actions before PPMU measurement. Default value is `TA::ppmuRly_onPPMU_offACDC`.

 |
 |

rly_after

 |

The relay actions after the PPMU measurement. The default value is `TA::ppmuRly_NO`. If not specified, the relay will not be changed after the measurement.

 |

List of available options of parameter: rly_before & rly_after
 |

Option

 |

Description

 |
 |

TA::ppmuRly_onPPMU_offACDC

 |

Close the PPMU relay, open the AC relay and DC relay.

 |
 |

TA::ppmuRly_onAC_offDCPPMU

 |

Close the AC relay, open the DC relay and the PPMU relay.

 |
 |

TA::ppmuRly_onDC_offACPPMU

 |

Close the DC relay, open the AC relay and the PPMU relay.

 |
 |

TA::ppmuRly_onPPMU

 |

Close the PPMU relay and keep the state of other relays.

 |
 |

TA::ppmuRly_onAC

 |

Close the AC relay and keep the state of other relays.

 |
 |

TA::ppmuRly_onDC

 |

Close the DC relay and keep the state of other relays.

 |
 |

TA::ppmuRly_onACPPMU_offDC

 |

Close the AC relay and PPMU relay and open the DC relay.

 |
 |

TA::ppmuRly_onACDC_offPPMU

 |

Close the AC relay and DC relay and open the PPMU relay.

 |
 |

TA::ppmuRly_onDCPPMU_offAC

 |

Close the DC relay and PPMU relay and open the AC relay.

 |
 |

TA::ppmuRly_onALL

 |

Close all the relays of the digital pin.

 |
 |

TA::ppmuRly_offALL

 |

Open all the relays of the digital pin.

 |
 |

TA::ppmuRly_NO

 |

No relay switching.

 |

## Example

```
rdi.dc().pin("DATA1").relay(TA::ppmuRly_onPPMU,TA::ppmuRly_offALL).iForce(1 mA).vMeas().execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
- SmartRDI 2.2.0: Supports the syntax relay(TA::PPMU_RELAY_ACTION rly_before)
