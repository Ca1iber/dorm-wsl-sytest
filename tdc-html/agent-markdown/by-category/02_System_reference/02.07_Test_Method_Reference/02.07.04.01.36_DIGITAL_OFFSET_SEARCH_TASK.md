Varies the offset to a given level or to a given timing edge in order to find pass/fail transitions.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/DigitalOffsetSearchTask.h.

You can add multiple DIGITAL_OFFSET_SEARCH_TASK objects to one [TASK_LIST](<02.07.04.01.240_TASK_LIST.md>) and use TASK_LIST.execute() to execute those searches. If you also want to retrieve the results for each test, each object must have used one of the following three member functions before added to TASK_LIST.

- [DIGITAL_OFFSET_SEARCH_TASK.enableAutoOffsetUpload()](<02.07.04.01.36.07_DIGITAL_OFFSET_SEARCH_TASK.enableAutoOffsetUpload.md>)
- [DIGITAL_OFFSET_SEARCH_TASK.enableAutoTransitionUpload()](<02.07.04.01.36.08_DIGITAL_OFFSET_SEARCH_TASK.enableAutoTransitionUpload.md>)
- [DIGITAL_OFFSET_SEARCH_TASK.enableAutoResultsUpload()](<02.07.04.01.36.09_DIGITAL_OFFSET_SEARCH_TASK.enableAutoResultsUpload.md>)

## Comparisons between this API and SEARCH_FUNC_TASK

Both the two APIs are used to search for the pass area for timings/levels and to return the values at the fail-to-pass and pass-to-fail transition points. However, their searched timing/level setups and searching speed are different:

- [SEARCH_FUNC_TASK](<02.07.04.01.199_SEARCH_FUNC_TASK.md>) varies values of spec variables or of timing hardware resources to find out their pass areas, and returns those values at the fail-to-pass and pass-to-fail transitions. However, it cannot search the level hardware resources, such as VIL, VIH, VTH, VOL, VOH, and etc.
- DIGITAL_OFFSET_SEARCH_TASK varies offsets but not the absolute values of timing or level hardware resources. It returns the offsets at the fail-to-pass and pass-to-fail transitions. However, it cannot search the spec variables.
- Searching speed is quite different when searching for multiple sites. For the sites more than eight, DIGITAL_OFFSET_SEARCH_TASK is better. For the sites less than eight, SEARCH_FUNC_TASK is better.

## Usage of DIGITAL_OFFSET_SEARCH_TASK

It calls an object of:

- The [DIGITAL_OFFSET_SEARCH_PINS](<02.07.04.01.36.01_DIGITAL_OFFSET_SEARCH_PINS.md>) class to set up the search conditions for specific pins.
- The [DIGITAL_OFFSET_SEARCH_RESULT_PINS](<02.07.04.01.36.02_DIGITAL_OFFSET_SEARCH_RESULT_PINS.md>) class to set up the result pins for returning pass/fail.
Note To do timing offset search, you can also use [TIMING_OFFSET_SEARCH_TASK](<02.07.04.01.248_TIMING_OFFSET_SEARCH_TASK.md>).

## Syntax

```
DIGITAL_OFFSET_SEARCH_TASK();
```

This constructor creates an object of the DIGITAL_OFFSET_SEARCH_TASK() class.

List of parameters

There are no parameters.

Return value

There is no return value.

## Examples

### Example 1

Do a VIL search with a positive step width. The search will start from Pass until Fail, intending to do a right boundary search. The setup and result pins are the same. Set the RestoreFlag to YES.

```
STRING setupPins("pcie_tx1n");
STRING resultPins("pcie_rx1n");

DIGITAL_OFFSET_SEARCH_TASK dos;

ON_FIRST_INVOCATION_BEGIN();

    dos.pin(setupPins)
            .resourceType(DIGITAL_OFFSET_SEARCH::VIL)
            .searchType(DIGITAL_OFFSET_SEARCH::RB)
            .start(-0.5 V)
            .numSteps(4)
            .stepWidth(0.25 V)
            .minPassCount(1)
            .transitionDetection(DIGITAL_OFFSET_SEARCH::PF)
            .resolution(0.05 V)
            .errorCountLimit(1)
            .restoreFlag(DIGITAL_OFFSET_SEARCH::YES);

    dos.resultPin(setupPins).setResultPin(resultPins);

    dos.setup();
    dos.execute();

    dos.uploadLatestTransition();

ON_FIRST_INVOCATION_END();

DIGITAL_OFFSET_SEARCH::RESULT_FOUND result;

result = dos.pin(setupPins).TransitionOffsetFound();

if( result != DIGITAL_OFFSET_SEARCH::NOT_FOUND )
{
    if( result != DIGITAL_OFFSET_SEARCH::RB_NOT_FOUND )
    {
        cout << "rbOffset = " << dos.pin( setupPins ).getLatestRBTransitionOffset() << endl;
    }
    else
    {
        cout << "rbOffset = NOT_FOUND" << endl;
    }
}
```

### Example 2

Do an EYE search for VTH in order to bring the threshold to the middle. The VTH needs to pass for VIL/VIH between 'VTH + 1.5V' and 'VTH - 1.0V'. The setup and result pins are the same. Set the RestoreFlag to NO.

```
STRING setupPins("pcie_tx1n");

DIGITAL_OFFSET_SEARCH_TASK dos;

ON_FIRST_INVOCATION_BEGIN();

    dos.pin(setupPins)
            .resourceType(DIGITAL_OFFSET_SEARCH::VTH)
            .searchType(DIGITAL_OFFSET_SEARCH::EYE)
            .start(1.5 V)
            .numSteps(5)
            .stepWidth(-0.5 V)
            .minPassCount(1)
            .transitionDetection(DIGITAL_OFFSET_SEARCH::PF)
            .resolution(0.05 V)
            .errorCountLimit(1)
            .restoreFlag(DIGITAL_OFFSET_SEARCH::NO);

    dos.setup();
    dos.execute();

ON_FIRST_INVOCATION_END();
```

### Example 3

Do a timing offset search.

```
STRING pinTX1("pcie_tx1n");
STRING pinRX1("pcie_rx1n");
STRING pinRX2("pcie_rx2n");

DIGITAL_OFFSET_SEARCH_TASK dos_search;
DIGITAL_OFFSET_SEARCH_TASK dos_alignment;

ON_FIRST_INVOCATION_BEGIN();

    //
    // Timing alignment: searches new receive edge position between
    // (current poistion - 100ns) to (current position + 100ns)
    //
    dos_alignment.pin(pinRX2)
            .resourceType(DIGITAL_OFFSET_SEARCH::RECEIVE)
            .searchType(DIGITAL_OFFSET_SEARCH::EYE)
            .start(-100 ns)
            .numSteps(10)
            .stepWidth(20 ns)
            .restoreFlag(DIGITAL_OFFSET_SEARCH::NO);

    //
    // Search for a driver resource (move TX1 depending on PASS/FAIL of RX1)
    //
    dos_search.pin(pinTX1)
            .resourceType(DIGITAL_OFFSET_SEARCH::DRIVE)
            .searchType(DIGITAL_OFFSET_SEARCH::EYE)
            .start(-10 ms)
            .numSteps(100)
            .stepWidth(10 ms)
            .minPassCount(1)
            .transitionDetection(DIGITAL_OFFSET_SEARCH::PF)
            .resolution(10 ms)
            .errorCountLimit(1)
            .restoreFlag(DIGITAL_OFFSET_SEARCH::YES);

    dos_search.resultPin(pinTX1).setResultPin(pinRX1);

    dos_alignment.setup();
    dos_search.setup();

    dos_alignment.execute();
    dos_search.execute();

```

```
ON_FIRST_INVOCATION_END();

DIGITAL_OFFSET_SEARCH::TimingSetSelector dest;

dos_search.uploadResult(dest, DIGITAL_OFFSET_SEARCH::DRIVE);

DIGITAL_OFFSET_SEARCH::RESULT_FOUND result;

result = dos_search.pin(pinTX1).TransitionOffsetFound();

if (result != DIGITAL_OFFSET_SEARCH::NOT_FOUND)
{
    if (result != DIGITAL_OFFSET_SEARCH::LB_NOT_FOUND)
    {
        cout << "leftTranstition = "
             << dos_search.pin(pinTX1).getLatestLBTransitionOffset() << endl;
    }
    else
    {
        cout << "leftTranstition = NOT_FOUND" << endl;
    }
    if (result != DIGITAL_OFFSET_SEARCH::RB_NOT_FOUND)
    {
        cout << "rightTranstition = "
             << dos_search.pin(pinTX1).getLatestRBTransitionOffset() << endl;
    }
    else
    {
        cout << "rightTranstition = NOT_FOUND" << endl;
    }
}
else
{
    cout << "lb/rb transition/boundaries NOT_FOUND" << endl;
}

int site = CURRENT_SITE_NUMBER();

cout << "site " << site << ": "
     << dos_search.pin(pinTX1).getOffset(dest, DIGITAL_OFFSET_SEARCH::DRIVE) << endl;
```
