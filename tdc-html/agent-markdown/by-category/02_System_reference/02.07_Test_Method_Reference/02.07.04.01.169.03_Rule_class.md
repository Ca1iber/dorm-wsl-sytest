# Rule class

A rule describes the assignment of a value to a property under certain conditions.

Rule example:

```
datalog_level=0 for test numbers in the range of 0 to 1000
```

The value 0 is assigned to the data logging property datalog_level, if the test number is in the range of 0 to 1000.

This class is defined in the header file /opt/hp93000/soc/prod_com/include/Rule.hpp.

## Constructor

```
Rule::Rule()[inline]
```

Default constructor for the Rule class. Initializes all member variables to have meaningful values.
