# Using the Routing Tools editors

#### Subtopics

- [Opening the Routing Tools editors](<02.07.13.15.02.01_Opening_the_Routing_Tools_editors.md>)
- [Working with the Routing Tools editors](<02.07.13.15.02.02_Working_with_the_Routing_Tools_editors.md>)

The Routing Tools editors are available as Eclipse plug-in and opened as SmarTest work center perspective.

The Routing Tools editors provide the configuration data that is processed by the [related functions](<02.07.13.15_SmartRDI__DUT_board_connections_control_by_Routing_Tools.md>) of [SmartRDI](<02.07.13_SmartRDI.md>):

- For information on how to open the Routing Tools editors refer to [Opening the Routing Tools editors](<02.07.13.15.02.01_Opening_the_Routing_Tools_editors.md>).
- For a short description of the working sequence refer to [Working with the Routing Tools editors](<02.07.13.15.02.02_Working_with_the_Routing_Tools_editors.md>).
