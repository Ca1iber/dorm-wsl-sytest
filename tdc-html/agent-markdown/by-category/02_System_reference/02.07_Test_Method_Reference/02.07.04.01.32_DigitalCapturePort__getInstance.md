# DigitalCapturePort& getInstance()

This API is used to get the instance of the DigitalCapturePort.

If the instance exists, it is returned, otherwise a new instance is created.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTMultiportSync.hpp.

## Syntax

```
DigitalCapturePort& getInstance();
```
