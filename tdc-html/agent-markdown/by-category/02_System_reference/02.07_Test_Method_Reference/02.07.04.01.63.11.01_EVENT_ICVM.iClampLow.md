# EVENT_ICVM.iClampLow()

Sets the low clamp current value.

You can specify both the low and high clamp current values or just one.

## Syntax

```
EVENT_ICVM & iClampLow  (const EVENT_VALUE_DOUBLE & value );
```

Parameter
 | Parameter  | Description |
 | value |

Low clamp current

 |

## Return value

A reference to the corresponding [EVENT_ICVM](<02.07.04.01.63.11_EVENT_ICVM.md>) object.

## Example

For an example see [EVENT_ICVM](<02.07.04.01.63.11_EVENT_ICVM.md>).
