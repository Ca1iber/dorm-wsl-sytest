# EVENT_WAVEFORM_VF

Waveform classes provide functionality to define events that generate waveforms. EVENT_WAVEFORM_VF (Voltage Force Waveform) is a specialized event class.

 Note ANALOG_WAVEFORMs that use a number of periods are supported, but it is highly recommended to use sequencer instructions to repeat waveforms instead. Using sequencer instructions improves performance and significantly reduces the memory consumption.Note The ANALOG_WAVEFORM member functions pin() and coreFunction() are not supported for DC Scale cards.

## Class definition

The class derives from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

This class is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Example

- Describes the waveform of a voltage ramp:

```
ANALOG_WAVEFORM rampUp("rampUp");

rampUp.definition(TM::RAMP)
      .direction(TM::POS)
      .samples(4)
      .min(0.1).max(1.6);
```

- Defines a force voltage ramp waveform:

```
EVENT_WAVEFORM_VF rampUpEvent;

rampUpEvent.vForce(rampUp);
rampUpEvent.sampleVectorDistance(64);
```
