# EVENT_WAVEFORM_VCVM.getSampleVectorDistance()

Reads the distance between sample vectors that has been defined by [EVENT_WAVEFORM_VCVM.sampleVectorDistance()](<02.07.04.01.63.36.05_EVENT_WAVEFORM_VCVM.sampleVectorDistance.md>).

The sample vector distance is read from the corresponding object [EVENT_WAVEFORM_VCVM](<02.07.04.01.63.36_EVENT_WAVEFORM_VCVM.md>) and returned as an integer value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getSampleVectorDistance(INT & vectors) const;
```

Parameter
 | Parameter  | Description |
 | vectors |

The sample vector distance.

 |

Return value

There is no return value.
