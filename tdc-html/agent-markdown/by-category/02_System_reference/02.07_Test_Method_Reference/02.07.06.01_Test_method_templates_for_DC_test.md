# Test method templates for DC test

The following test method snippets for DC test are provided with SmarTest. These test method snippets are included in the file /opt/hp93000/soc/segments/tml/testmethodSnipptets.xml.

The test method snippets are listed in the alphabetical order.

- V93000_DC_IFVM_DCScale

This snippet sets up and performs a parallel IFVM test with DC Scale.

- V93000_DC_IFVM_MCX

This snippet sets up and performs a parallel IFVM test with MCx PMU.

- V93000_DC_IFVM_PPMU_Parallel

This snippet sets up and performs a parallel IFVM test with PPMU.

- V93000_DC_IFVM_PPMU_Serial

This snippet sets up and performs a serial PPMU IFVM test.

- V93000_DC_IFVM_SPMU

This snippet sets up and performs a parallel IFVM test with SPMU.

- V93000_DC_VFIM_DCScale

This snippet sets up and performs a parallel VFIM test with DC Scale.

- V93000_DC_VFIM_DPS

This snippet sets up and performs a parallel VFIM test with DPS.

- V93000_DC_VFIM_MCX

This snippet sets up and performs a parallel VFIM test with MCx PMU.

- V93000_DC_VFIM_PPMU_Parallel

This snippet sets up and performs a parallel VFIM test with PPMU.

- V93000_DC_VFIM_PPMU_Serial

This snippet sets up and performs a serial VFIM test with PPMU.

- V93000_DC_VFIM_SPMU

This snippet sets up and performs a parallel VFIM test with SPMU.

- V93000_DC_VForce_DCScale

This snippet sets up and performs a parallel VFIM test with DC Scale.

## Functional changes

- Introduced in SmarTest 6.5.4
