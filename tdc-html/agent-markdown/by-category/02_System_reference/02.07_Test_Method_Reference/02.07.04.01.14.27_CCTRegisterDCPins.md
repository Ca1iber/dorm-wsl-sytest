# CCTRegisterDCPins

Register the pins that will be used to do dynamic (sequencer‑controlled) DC test.

This function is usually used in the `init()` function but not used in the other functions of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
void CCTRegisterDCPins(const string& pins);
```

Parameter
 |

Parameter

 |

Description

 |
 |

pins

 |

The list of pins or pin groups separated by comma. They can be Smart Scale pins or DC Scale pins.

 |

Return value

There is no return value.

## Example

```
CCTRegisterDCPins("pin1, pin2");
```
