# TMU_TASK.uploadRawResultsFlat()

Uploads the raw results of all armings in one line as results of arming 0 for all pins in the TMU set.

This makes it possible for a quick access to the results of multiple armings with [TMU_RESULTS.getPinResultsFlat()](<02.07.04.01.251.19_TMU_RESULTS.getPinResultsFlat.md>).

## Syntax

```
TMU_RESULTS& uploadRawResultsFlat(shotnum = 0);
TMU_RESULTS& uploadRawResultsFlat(const char* ResultHanlde,shotnum = 0);
TMU_RESULTS& uploadRawResultsFlat(STRING&  ResultHanlde,shotnum = 0);
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

ResultHandle

 |

The result handle to access.

 |
 |

I

 |

shotnum

 |

The shot number which result to be uploaded.

The default value is 0, which means the results of all shots will be uploaded.

 |

## Return value

A reference to the TMU_RESULTS object is returned.
