# DIGITAL_OFFSET_SEARCH_PINS.uploadResult()

Uploads the results for the latest transition search from the tester to the workstation.

Those results include:

- The offsets for the boundaries of the pass area relative to the searched edges or levels. (Boundaries are the first and last passing values of the pass area representing the fail-to-pass and pass-to-fail transitions respectively.)
- The offsets for the middle of the pass area relative to the searched edges or levels.

Later on, to read out the offsets for the middle of the pass area, use [DIGITAL_OFFSET_SEARCH_PINS.getOffset()](<02.07.04.01.36.01.08_DIGITAL_OFFSET_SEARCH_PINS.getOffset.md>).

To read out the offsets for the boundaries, use [DIGITAL_OFFSET_SEARCH_PINS.getLatestLBTransitionOffset()](<02.07.04.01.36.01.06_DIGITAL_OFFSET_SEARCH_PINS.getLatestLBTransitionOffset.md>), and/or [DIGITAL_OFFSET_SEARCH_PINS.getLatestRBTransitionOffset()](<02.07.04.01.36.01.07_DIGITAL_OFFSET_SEARCH_PINS.getLatestRBTransitionOffset.md>).

If you retrieve the offset on multiple pins and those pins have different settings, the exception TESTMETHOD_API::AmbiguityException will be issued.

## Syntax

```
void uploadResult(SetSelector& selector, RESOURCE_TYPE resource) throws TMException;
```

Parameters
 |

Parameter

 |

Description

 |
 |

selector

 |

It can be:

- A TimingSetSelector object defined with [TimingSetSelector](<02.07.04.02.17_TimingSetSelector.md>), to select timing sets. Or,
- A LevelSetSelector object, defined with [LevelSetSelector](<02.07.04.01.123_LevelSetSelector.md>), to select level sets.
 |
 |

resource

 |

It can be a timing resource or a level resource whose offset and/or boundaries of the pass area you want to upload.

Use a timing or level resource for the timing or level selector accordingly. Otherwise, an exception will be thrown.

## Example

```
STRING strpins("pcie_rx1n");

DIGITAL_OFFSET_SEARCH_TASK dos;

dos.pin(strpins)
        .resourceType(DIGITAL_OFFSET_SEARCH::VIH)
        .searchType(DIGITAL_OFFSET_SEARCH::EYE)
        .start(15 mV)
        .numSteps(120)
        .stepWidth(15 mV)
        .restoreFlag(DIGITAL_OFFSET_SEARCH::NO);

dos.execute();

DIGITAL_OFFSET_SEARCH::LevelSetSelector dest(DIGITAL_OFFSET_SEARCH::ALL);

dos.pin(strpins).uploadResult(dest, DIGITAL_OFFSET_SEARCH::VIH);
```
