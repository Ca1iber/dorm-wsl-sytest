# vMeas()

Specifies a voltage measurement.

The function can be used in the code‑based mode and in the pattern‑based mode.

## Syntax

```
dcBase& vMeas();
```

## Return Value

A reference to the dcBase object.

## Example

### Example 1: Simple voltage measurement

```
rdi.dc("vMeCas").pin("pinA").vMeas().execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
- SmartRDI 7.5.0: New syntax for "LAST" measurements of FVI16.
