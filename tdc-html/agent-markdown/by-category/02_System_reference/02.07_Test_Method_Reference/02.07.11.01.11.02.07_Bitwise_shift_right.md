# Bitwise shift right

The '>>' operator shifts a parameter by a given number of bits to the right.

The operator appends state character '0' or 'L' to the left end of the sequence and removes the same number of characters from the right end.

The 'number' operand determines the number of bits to shift and can be specified in the form of an integer constant or a SCS, which will be interpreted as integer constant for example, "LHH" is interpreted as integer value 3).

The state character to insert is derived from the last state character in the sequence operand according to following table:

Errors will be issued if,

- shift count is not an integer parameter
- sequence [n] contains an unsupported state character.

## Syntax

integer := integer >> number

## Example

"001" >> "101" equals to `"001" >> 3` and results in `"000"`

"10L" >> "1" results in `"010"`

"L10" >> "10" results in `"LLL"`

"RRR" >> 2 results in `"LLR"`

"100" >> "Z1" results in "ERROR: "Z1" is not convertible to integer."

"Z11" >> 1 results in "ERROR: cannot determine fill character."
