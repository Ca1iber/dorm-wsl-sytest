# tmm_console

tmm_console can be used to get the information from the test method executor shared memory or perform certain simple operation on the test method executors. It is located in the directory /opt/hp93000/soc/testmethod/bin.

Its frequently-used parameters include:

stopAll - terminates both test method executors.

pid - prints the process id of the current test method executor if it is running.

list types - lists all the available test methods for this device.

dumpTimeLogger - dumps the log of the test method execution time.

dump types - dumps the detail information of all the available test methods for this device.

It can be executed in the following two ways.

- batch parameters

/opt/hp93000/soc/testmethod/bin/tmm_console -e <parameter>

- interactive parameters

/opt/hp93000/soc/testmethod/bin/tmm_console

The task prompt is shown. You can enter the parameters after the prompt.

task: <parameter>

To get the information of all the parameters, you can enter help after the task prompt.
