# UTILITY_POWER_STATUS.execute()

Executes the previously specified actions of the [UTILITY_POWER_STATUS](<02.07.04.01.264_UTILITY_POWER_STATUS.md>) object.

The actions are to be defined by member functions [state()](<02.07.04.01.264.01_UTILITY_POWER_STATUS.state.md>) and [wait()](<02.07.04.01.264.03_UTILITY_POWER_STATUS.wait.md>).

## Syntax

```
virtual void execute();
```

  List of parameters There are no parameters. Return value There is no return value.

## Functional changes

- Introduced in SmarTest 7.2.1
