# SMC_UPLOAD_STATUS.area()

Returns the result area for a VectorUploadTask. This information is stored in a vector that is populated by [SMC_GET_UPLOAD_STATUS()](<02.07.04.01.231.16_SMC_GET_UPLOAD_STATUS.md>).

## Syntax

```
const STRING& area() const;
```

List of parameters

There are no parameters.

## Return value

Returns the result area for a VectorUploadTask. For all other upload types an empty string is returned.

## Example

This example shows how to create a vector of type `SMC_UPLOAD_STATUS` and how to retrieve the result area from the vector.

Note As `SMC_UPLOAD_STATUS` represents a collection, one has to iterate over the collection to obtain the item.

```
typedef vector<SMC_UPLOAD_STATUS> SmcUploadStatusVector;
string ResultArea;

// Obtain the collection
SmcUploadStatusVector statusVector = SMC_GET_UPLOAD_STATUS();

// iterate through collection
for(SmcUploadStatusVector::iterator it = statusVector.begin();
     it != statusVector.end(); ++it) {
        ResultArea = it->area();
        cout << "SMC upload type:" << ResultArea << endl;
     }
```
