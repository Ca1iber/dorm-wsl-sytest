# EVENT_WAVEFORM_CFIM.averages()

Sets the number of internal DC measurement samples for hardware based averaging.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_WAVEFORM_CFIM & averages(const EVENT_VALUE_INT & samples);
```

Parameter
 | Parameter  | Description |
 | samples |

Number of internal samples from which the average is created.

For DC Scale channels, with exception of XPS256, the number of samples must be a power of 2.

 |

## Return value

A reference to the corresponding [EVENT_WAVEFORM_CFIM](<02.07.04.01.63.28_EVENT_WAVEFORM_CFIM.md>) object.
