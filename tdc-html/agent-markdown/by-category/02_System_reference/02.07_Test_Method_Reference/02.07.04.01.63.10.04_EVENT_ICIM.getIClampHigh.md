# EVENT_ICIM.getIClampHigh()

Queries the high clamp current value.

## Syntax

```
void getIClampHigh (EVENT_VALUE_DOUBLE & value) const;
```

Parameter
 | Parameter  | Description |
 | value |

High clamp current

 |

## Return value

Returns EVENT_VALUE_DOUBLE as reference.
