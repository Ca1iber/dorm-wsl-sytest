# TMU_RESULTS.getPinResultsFlat()

Retrieves the results of all armings for the specified pin and store it in a double array.

## Syntax

```
Boolean getPinResultsFlat(STRING& pin, ARRAY_D& value_array, TMU::ApplicationType appType, Boolean collectBadSamples = FALSE, UINT32 site = 0);
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

pin

 |

The pin to query the result.

 |
 |

O

 |

value_array

 |

The reference to the double array to store the values. The unit is seconds.

 |
 |

I

 |

appType

 |

The application type.

Use TMU::APP_RAW_FLAT if the results are uploaded with [TMU_PINS.uploadRawResultsFlat()](<02.07.04.01.252.02.03.03_TMU_PINS.uploadRawResultsFlat.md>).

Use TMU::APP_RAW if the results are uploaded with [TMU_PINS.uploadRawResults()](<02.07.04.01.252.02.03.02_TMU_PINS.uploadRawResults.md>).

 |
 |

I

 |

collectBadSamples

 |

Whether to indicate the armings with missing or wrong number of samples in the result array. It can be:

- true: The function will return only 1 sample with the value of -9999 second for the armings with missing or wrong number of samples.

or

- false: No indication of the armings with missing or wrong number of samples in the result array.

This is the default value.

 |
 |

I

 |

site

 |

The site to query. Default is 0, which means the current site.

 |

## Return value

It will return true if the result values are available. Otherwise false is returned.

## Functional changes

- Introduced in SmarTest 7.1.3
