# Getting the Site Numbers

Get the site number information by using the following APIs during execution of your test method program:

- [CURRENT_SITE_NUMBER()](<02.07.04.01.20_CURRENT_SITE_NUMBER.md>)

Returns the site number of the current site under execution.

- [GET_CONFIGURED_SITES](<02.07.04.01.81_GET_CONFIGURED_SITES.md>)

Returns the number of sites that were set up in the pin configuration, and the site numbers.

The CURRENT_SITE_NUMBER API is designed for executing on a single site. Hence, use this API in the each site loop block or outside the first-invocation block, as follows:

```
//
// Define an array of site specific offset values
//
// Note:    MAX_NR_OF_SITE is a system defined macro.
//          The macro is defined in file SiteControl.h
//
DOUBLE awgSiteOffset[MAX_NR_OF_SITE];

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Fill the array with the site specific values
    //
    ...
    ...

    //
    // Set site specific offset
    //
    FOR_EACH_SITE_BEGIN();
    {
        AWG("AWG").vOffset(awgSiteOffset[CURRENT_SITE_NUMBER() - 1]);

        FLUSH();
    }
    FOR_EACH_SITE_END();

    ...
    ...
}
ON_FIRST_INVOCATION_END();
```

The following example gets site information of the original multisite pin configuration. The original multisite pin configuration has been defined in the [Pin settings](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01_Pin_setting_editors.md>) as shown in [Defining additional test sites](<../02.08_Setup_and_Result_Tools/02.08.04.18.02.07.04_Defining_additional_test_sites.md>).

```
ARRAY_I configuredSitesArray;
int     numberOfConfiguredSites;

ON_FIRST_INVOCATION_BEGIN();

    numberOfConfiguredSites = GET_CONFIGURED_SITES(configuredSitesArray);

    cout << numberOfConfiguredSites << " sites are configured:" << endl;

    for (int arrayIndex = 0; arrayIndex < configuredSitesArray.size(); arrayIndex++)
    {
        cout << "\tSite " << configuredSitesArray[arrayIndex] << " is configured." << endl;
    }

ON_FIRST_INVOCATION_END();
```

The following example sets the site specific offset of an AWG pin as shown in the first example above but limits the size of the array to the really required value.

```
//
// Define an array of site specific offset values
//
ARRAY_I configuredSites;
ARRAY_D awgSiteOffset;

awgSiteOffset.resize(GET_CONFIGURED_SITES(configuredSites));

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Fill the array with the site specific values
    //
    ...
    ...

    //
    // Set site specific offset
    //
    FOR_EACH_SITE_BEGIN();
    {
        AWG("AWG").vOffset(awgSiteOffset[CURRENT_SITE_NUMBER() - 1]);

        FLUSH();
    }
    FOR_EACH_SITE_END();

    ...
    ...
}
ON_FIRST_INVOCATION_END();
```
