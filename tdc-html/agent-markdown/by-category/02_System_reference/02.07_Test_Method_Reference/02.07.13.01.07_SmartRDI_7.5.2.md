# SmartRDI 7.5.2

This section summarizes software changes including new features and enhancements in SmartRDI 7.5.2.

Changes and new features
 |

Category

   | Description |
 | [DC](<02.07.13.12_SmartRDI__DC_test_setup.md>) |

- [insertSub()](<02.07.13.12.02.20_insertSub.md>) supports multilayer insertion of user sublabels.
 |
 | [ORE](<02.07.13.08.20_Using_Offline_Result_Emulation_in_SmartRDI.md>) |

-

The testflow variable [RDI_ORE_FILE](<02.07.13.08.20_Using_Offline_Result_Emulation_in_SmartRDI.md#_343520__testflow_variable>) can be used to set or change the ORE XML file between loop executions.

-

The flag ORE_FOLDER can be set in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md#_146692__dle_ORE_setup>) to specify an ORE template file path.

-

[ORE template file](<02.07.13.08.20.02.03_Template_file_from_online_test_results.md>) can be generated from online test results.

-

The [ENABLE_ORE](<02.07.13.04_RDI_Configure_file.md#_146692__dle_ORE_setup>) keyword has a new value TRUE_OFFLINE which can automatically disable ORE in online mode.

- The [dc](<02.07.13.08.20.03.01.03_The__dc__element.md>), [emap](<02.07.13.08.20.03.01.06_The__emap__element.md>), and [smartVec](<02.07.13.08.20.03.01.10_The__smartVec__element.md>) elements support more attributes and values.
 |
 | [Alarm handling](<02.07.13.09_SmartRDI__Alarm_handling_for_DCVI.md>) |

-

More debug information can be shown in the UI report window. See [Debug value in the UI report window](<02.07.13.09.01_Alarm_setup_file.md#_345140__debug_value>).

-

Alarm checking can trigger a hidden port synchronization after alarm compare. See [Alarm handling on ports](<02.07.13.09_SmartRDI__Alarm_handling_for_DCVI.md#_345141__s_Alarm_handling_on_ports>).

-

The ALARM_FAIL_WARNING flag can disable alarm warnings when alarm handling fails. See [Alarm handling for DCVI](<02.07.13.04_RDI_Configure_file.md#_146692__dle_Alarm_handling_for_DCVI>) .

 |
 | [Func](<02.07.13.17_Functional_test_setup.md>) |

-

[rdi.func().burstRunTime()](<02.07.13.17.01.03_rdi.func__.burstRunTime.md>) can be used for runtime burst content patching.

-

[rdi.id().getMultiPassFail()](<02.07.13.17.01.18_rdi.id__.getMultiPassFail.md>) can retrieve per-label results from the burst other than the burst pass/fall result by the [rdi.getBurstPassFail()](<02.07.13.17.01.13_rdi.getBurstPassFail.md>) in the STATIC mode.

 |
 | [DigCap](<02.07.13.13_SmartRDI__Digital_capture_test_setup.md>) |

- [vecVar()](<02.07.13.13.16_vecVar.md>) specifies vector variables from a user label.
- [rdi.id().getVectorFromVV()](<02.07.13.13.20_rdi.id__.getVectorFromVV.md>) retrieves results from the specified user-defined vector variables.
 |
 | [SmartVec](<02.07.13.24_SmartRDI__Vector_and_protocol_programming.md>) |

- [download()](<02.07.13.24.09_download.md>) helps to achieve hidden vector download (HVD).
 |
 | [Route](<02.07.13.15_SmartRDI__DUT_board_connections_control_by_Routing_Tools.md>) |

- [downloadPmuxMemSet()](<02.07.13.15.05.02_rdi.route__.downloadPmuxMemSet.md>) can work together with xMode to save vector memory.
 |
 | [Relays](<02.07.13.14_SmartRDI__Digital_channel_relay_control.md>) |

- [setOnRunTime()](<02.07.13.14.06_setOnRunTime.md>) and [setOffRunTime()](<02.07.13.14.04_setOffRunTime.md>) can be used in the static mode.
 |
 | [TMU](<02.07.13.21_SmartRDI__TMU_test_setup.md>) |

- Digital tmu result upload speed improvement.
 |

## Supported SmarTest versions

SmartRDI 7.5.2 supports SmarTest 7.5.2.
