# EVENT_WAVEFORM_CF.getSampleVectorDistance()

Reads the distance between sample vectors that has been defined by [EVENT_WAVEFORM_CF.sampleVectorDistance()](<02.07.04.01.63.27.03_EVENT_WAVEFORM_CF.sampleVectorDistance.md>).

The sample vector distance is read from the corresponding [EVENT_WAVEFORM_CF](<02.07.04.01.63.27_EVENT_WAVEFORM_CF.md>) object and returned as an integer value.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
void getSampleVectorDistance(INT & vectors) const;
```

  Parameter

 | Parameter  | Description |
 | vectors |

The sample vector distance.

  |  Return value There is no return value.

For an example see [EVENT_WAVEFORM_CF](<02.07.04.01.63.27_EVENT_WAVEFORM_CF.md>).
