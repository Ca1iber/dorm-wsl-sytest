AC Test Method library provides several test methods to perform AC tests. You can create your test method project by copying from the library. You can also use it as a template and modify the source file to suit your project. The source files of the AC test methods are included in the file /opt/hp93000/soc/testmethod/library/ac_tml.zip.

The following AC Test Methods are included in the test method source files:

- `Frequency_byDigitalCapture` - measures frequency by digital capture on the designated DUT pins.
- `FunctionalTest` - examines the DUT at nominal level and timing settings.
- `JitterHistogram` - measures the jitter on the output of a device.
- `JitterSeparation` - measures the jitter on the device output and separates the random jitter and deterministic jitter.
- `JitterSeparationHS` - improves the test throughput of `JitterSpearation` test method.
- `JitterStardust` - measures the jitter on the output of a device and calculates the jitter frequency and spectrum.
- `ParametricFunctionalTest` - characterizes the DUT with a customized functional test.
- `SetBasedSpecSearch` - performs spec search based on the pre-calculated level/timing set and burst label.
- `Shmoo` - performs a shmoo measurement in the specified range of X-axis parameter and Y-axis parameter.
- `SpecSearch` - characterizes the device by shifting the specs defined in the equation-based test setup.Note In every AC test method which needs clear sequencer state as precondition, Sequencer.reset() or FW_TASK("SQGB ACQF,0;") is executed to to clear the sequencer state before a measurement. `Frequency_byDigitalCapture` is an exception because the sequencer state is cleared in `DIGITAL_CAPTURE_TEST`.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.2: New test method library Shmoo and CustomizedShmoo.
- SmarTest 6.5.3: New test method library JitterSeparation and JitterStardust.
- SmarTest 7.0.3: New test method library SetBasedSpecSearch.
- SmarTest 7.1.0: New test method library JitterHistogramHX, JitterSeparationHX and JitterStardustHX.
- SmarTest 7.2.0: Removed the CustomizedShmoo test method library which is replaced with a ready-made customized shmoo test method template.
- SmarTest 7.3.2: New test method JitterSeparationHS.
- SmarTest 7.10.0: Test method libraries JitterHistogramHX, JitterSeparationHX and JitterStardustHX not supported
