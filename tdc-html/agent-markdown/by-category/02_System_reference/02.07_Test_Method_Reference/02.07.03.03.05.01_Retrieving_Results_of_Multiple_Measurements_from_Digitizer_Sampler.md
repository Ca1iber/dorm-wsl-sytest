# Retrieving Results of Multiple Measurements from Digitizer/Sampler

In one test method program, if you perform multiple measurements in the digitizer/sampler by switching the analog set, specify the analog set used at the measurement whenever you retrieve measurement data.

For example, if you perform two measurements by switching the analog set "1" and "2".

## Example:

```
Analog.primary(1);
EXECUTE_TEST();
ARRAY_D data1 = Analog.DGT("Vout").getWaveform();
Analog.primary(2);
EXECUTE_TEST();
ARRAY_D data2 = Analog.DGT("Vout").getWaveform();
```

In above example, the primary analog set at measurement is kept until you retrieve measurement data. Therefore, use the ANALOG_STATUS API (Analog object) to retrieve the measurement data.
