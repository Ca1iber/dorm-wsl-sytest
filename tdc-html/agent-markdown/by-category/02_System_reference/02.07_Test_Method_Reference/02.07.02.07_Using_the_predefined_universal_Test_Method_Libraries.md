# Using the predefined universal Test Method Libraries

Some predefined test method libraries are delivered with the SmarTest software.

## About this task

The predefined [Test Method Libraries](<02.07.05_Test_Method_Library.md>) reside in the directory

- /opt/hp93000/soc/testmethod/library/sh_lib/
The predefined test method library in SmarTest currently includes

 |

- [AC test methods (ac_tml)](<02.07.05.01_AC_test_methods__ac_tml.md>),
- [DC test methods (dc_tml)](<02.07.05.02_DC_test_methods__dc_tml.md>),
- [DC test method (multi_group_dc_tml)](<02.07.05.02_DC_test_methods__dc_tml.md>),
 |

- [Miscellaneous test methods (miscellaneous_tml)](<02.07.05.04_Miscellaneous_test_methods__miscellaneous_tml.md>),
- [ScanTest (scan_tml)](<02.07.05.05_ScanTest__scan_tml.md>),
- [TMU test methods (tmu_tml)](<02.07.05.07_TMU_test_methods__tmu_tml.md>).
 |

You can

- directly use the libraries to test your device by selecting a test method for a test suite in the tabular testflow editor (For more information, see [How to create and execute a universal-test-method-based testflow](<02.07.02.02.03_How_to_create_and_execute_a_universal-test-method-based_testflow.md>)) or
- modify the source file and build your own customized universal test method libraries.

The second application is described in detail below.

Location of the predefined test method library source files:

- /opt/hp93000/soc/testmethod/library

They are packed in .zip files each containing a set of tests, such that, for instance, all DC test methods are included in the file dc_tml.zip. When following the procedure below, the files are unpacked to your device directory, but in their own sub-folder, so as not to interfere with the existing system. All your modifications will be saved and contained there.

## Before you begin

Make sure you are using SmarTest 6.3 or later. Your device setups must be ready to use.

## Procedure

-  Import the archived package of the test method source files.

  -  In C/C++ perspective, right-click in the Project Explorer view and choose New > Test Method Project.
  -  In the New Test Method Project wizard, enter the location directory for the project.
  -  Check the option Import a system Test Method project and select the archived Test Method Library source file from the list.
  -  Click Finish.  ![Import a system test method library](<../../../../raw/113143.png>)

If leaving the Use Default Location box checked, the files are unpacked to a subfolder under your device directory.

-  In the C/C++ Perspective, open the test method source file (*.cpp) and modify it according to your needs.
-  Build the test method and use it in your device testing.

## Results

The predefined Test Method Libraries are customized according to your needs.

## What to do next

Use the customized test method library in your testflow.
