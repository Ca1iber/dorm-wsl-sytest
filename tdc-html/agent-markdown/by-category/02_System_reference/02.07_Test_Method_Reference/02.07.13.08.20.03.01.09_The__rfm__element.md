# The <rfm> element

This element stores results of a RF measurement performed by using the SmartRDI's `rfm()` class.

The <rfm> element stores RF measurement results in its complexWaveform, power, aclr, phaseNoise, noiseFigure attributes. The complexWaveform attribute saves RF measurement results returned by a `getComplexWaveform()`, `getMultiComplexWaveform()` or `getSpectrum()` function; the power attribute saves RF measurement results returned by a `getPower()` function; the aclr attribute saves RF measurement results returned by a `getAclr()` function; the phaseNoise attribute saves RF measurement results returned by a `getPhaseNoise()` function; the noiseFigure attribute saves RF measurement results returned by a `getNoiseFigure()` function;

## Example

Below is an example of the <rfm> element and its corresponding SmartRDI code block.

An ORE file containing <rfm> elements:

```
<offlineResultEmulation>
  <id name = "rf1">
    <pin name = "RX1">
      <rfm complexWaveform  = "./waveform1./waveform2" />
     <rfm power = "2.56" />
    </pin>
  </id>
</offlineResultEmulation>

```

 The corresponding SmartRDI code block that can generate this ORE file:

```
RDI_BEGIN();
rdi.rfm("rf1").pin("RX1")
     .signal(TA::MOD_OUT).freq(2e9)
     .bw(2e6).execute();
rdi.wait(TA::WAIT_RFDGT);
RDI_END();
rdi.id("rf1").getComplexWaveform();
rdi.id("rf1").getSpectrum ();
rdi.id("rf1").getPower(); //2.56

```

ORE does not support `getParameters()` which is not a result retrieving function.
