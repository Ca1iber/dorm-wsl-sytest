# Forcing waveform and sampling in parallel on multiple pins

SmartRDI 7.5.1 supports parallel waveform and sampling actions with multiple pin().

Before RDI 7.5.1, parallel waveform and sampling for different DC Scale pins in one SmartRDI command is NOT supported with .pin()...pin(). If you intend to do parallel waveform for different pins, you have to use a [multiport command](<02.07.13.08.08.01_port.md>). For example,

```
RDI_BEGIN();
  rdi.dc().port("pt1").pin("A1").vForce().waveform(sine1).sampleCycle(1000).execute();
  rdi.dc().port("pt2").pin("A2").iForce().waveform(sine2).sampleCycle(1000).execute();
RDI_END();
```

Starting from 7.5.1, SmartRDI supports parallel waveform and sampling actions with multiple pin().

## Parallel DC actions on DC Scale pins

For DC Scale pins, SmartRDI supports the following scenarios of parallel waveform and sampling:

- Parallel waveform sourcing on two pins:

```
rdi.dc().pin("A").vForce().waveform(sine1).FS(10e3).
        .pin("B").iForce().waveform(sine2).FS(10e3).execute();
```

- Parallel sampling on two pins

```
rdi.dc().pin("A").iMeas().samples(1024).FS(10e3)
        .pin("B").vMeas().samples(1024).FS(10e3).execute();

```

- Parallel waveform sourcing on a pin while sampling on another pin:

```
rdi.dc().pin("A").vForce().waveform(wav).FS(10 kHz)
        .pin("B").|vMeas()|iMeas()|.samples(100).FS(10 kHz).execute();
```

- Parallel waveform sourcing and sampling on a pin while sampling on another pin:

```
rdi.dc().pin("A").vForce().waveform(wave).iMeas().FS(10 kHz)
        .pin("B").vMeas().samples(100).FS(10 kHz)
        .execute();
```

 ![Parallel_waveform_sampling_aPin_sampling_anoPin](<../../../../raw/353980.png>)

- Parallel waveform sourcing and sampling on a pin while waveform sourcing on another pin:

```
rdi.dc().pin("A").vForce().waveform(wave1).iMeas().FS(10 kHz)
        .pin("B").iForce().waveform(wave2).FS(10 kHz)
        .execute();
```

 ![Parallel_waveform_sampling_onPin_waveform_on_anPin](<../../../../raw/353979.png>)
- Parallel waveform sourcing on a pin, sampling on a pin, and waveform sourcing and sampling on a pin:

```
rdi.dc().pin("A").vForce().waveform(wave1).FS(10 kHz)
        .pin("B").vMeas().samples(100).FS(10 kHz)
        .pin("C").iForce().waveform(wave2).vMeas().FS(10 kHz)
        .execute();
```

 ![Parallel_waveform_sampling_waveform_sampling_on_DCSpins](<../../../../raw/353978.png>)
 You must follow these rules when using parallel waveform and sampling on multiple pins with pin()....pin()....execute():

- The following setups can be different for different pins.

  - Waveform in content and size
  - Voltage or current force type: [vForce()](<02.07.13.12.02.41_vForce.md>), [iForce()](<02.07.13.12.02.16_iForce.md>), and [iClamp()](<02.07.13.12.02.11_iClamp.md>)
  - Voltage or current measurement type: [vMeas()](<02.07.13.12.02.43_vMeas.md>), [iMeas()](<02.07.13.12.02.18_iMeas.md>)

- The following commands and parameter must have the same value for different pins.

  - FS()
  - samplePeriod()
  - sampleCycle()
  - Sampling size
  - measWait()

- DO NOT use the [repeat()](<02.07.13.24.31_repeat.md>) command in parallel waveform and sampling.

## Parallel sampling on digital channels

For digital channels, SmartRDI 7.5.1 supports parallel sampling only and does not support parallel waveform. For example,

```
RDI_BEGIN();
  //VEC mode
  rdi.dc().pin("PPMU1").iMeas().samples(1024).capMode(TA::VEC).FS(10 KHz)
          .pin("PPMU2").vMeas().samples(1024).capMode(TA::VEC).FS(10 KHz).execute();

  //TRIG mode
  rdi.dc().pin("PPMU1").vMeas().samples(1024).capMode(TA::TRIG).FS(10 KHz)
          .pin("PPMU2").iMeas().samples(1024).capMode(TA::TRIG).FS(10 KHz).execute();
RDI_END();
```

   Note

- capMode() must have the same value for all the specified pins.
- Do not do parallel sampling for pure BADC and PPMU actions.
   In 7.10.0, parallel PPUM/BADC sampling can be performed in the same execute(). Based on the capMode() sampling modes, parallel PPMU/BADC sampling scenarios are as follows:

- TRIG capMode:

```
rdi.dc().pin("A").vMeas().samples(10).FS(10 kHz).capMode(TA::TRIG)
        .pin("B",TA::BADC).vMeas().samples(10).FS(10 kHz).capMode(TA::TRIG)
        .execute();
```

```
rdi.dc().pin("A",TA::BADC).vMeas().samples(10).FS(10 kHz).capMode(TA::TRIG)
        .pin("B",TA::BADC).vMeas().samples(10).FS(10 kHz).capMode(TA::TRIG)
        .execute();
```

```
rdi.dc().pin("A").vMeas().samples(10).FS(10 kHz).capMode(TA::TRIG)
        .pin("B").vMeas().samples(10).FS(10 kHz).capMode(TA::TRIG)
        .execute();
```

- VEC capMode:

```
rdi.dc().pin("A").vMeas().samples(100).FS(10 kHz).capMode(TA::VEC).valueMode(TA::BADC)
        .pin("B").iMeas().samples(100).FS(10 kHz).capMode(TA::VEC).valueMode(TA::BADC)
        .execute();
```

```
rdi.dc().pin("A",TA::BADC).vMeas().samples(100).FS(10 kHz).capMode(TA::VEC)
        .pin("B",TA::BADC).iMeas().samples(100).FS(10 kHz).capMode(TA::VEC)
        .execute();
```

```
rdi.dc().pin("A").vMeas().samples(100).FS(10 kHz).capMode(TA::VEC).valueMode(TA::SA)
        .pin("B").iMeas().samples(100).FS(10 kHz).capMode(TA::VEC).valueMode(TA::SA)
        .execute();
```

 ![Parallel_sampling_on_dcChannel_VEC](<../../../../raw/353977.png>)
Note In the VEC mode, pin A and pin B must use the same DC resource.

Follow these rules when using parallel PPMU/BADC sampling:

- The capMode() values for different pins must be the same: TA::TRIG or TA::VEC.
- PPMU and BADC sampling actions can be mixed in the same execute() (new in 7.10.0).
- Multiple digital channels cannot share the same BADC.
- The following commands and parameter must have the same value for different pins.

  - FS()
  - samplePeriod()
  - sampleCycle()
  - Sampling number
  - measWait()

- DO NOT use the [repeat()](<02.07.13.24.31_repeat.md>) command in parallel waveform and sampling.

## Parallel PPMU/BADC sampling with DC Scale sampling or waveform

 In 7.10.0, SmartRDI supports PPMU/BADC TRIG-mode sampling in parallel with DCS sampling or waveform in the same execute().

- PPMU sampling with DC Scale sampling:

```
rdi.dc().pin("A").iMeas().samples(100).FS(30 kHz).capMode(TA::TRIG)
        .pin("B").vMeas().samples(250).FS(40 kHz)
        .execute();
```

 ![PPMU_sampling_DCS_sampling](<../../../../raw/353976.png>)
- PPMU sampling with DC Scale waveform:

```
rdi.dc().pin("A").iMeas().samples(100).FS(20 kHz).capMode(TA::TRIG)
        .pin("B").vForce().waveform(wave).FS(50 kHz)
        .execute();
```
