# clamp()

Specifies the high clamp voltage and low clamp voltage for PPMU.

It will enable the clamp functionality.

- If this function is used alone, the clamp remains active.
- If this function is used in combination with the [relay()](<02.07.13.12.01.01.17_relay.md>) function, the clamp will be disabled after the relay action. That is to say, the clamp is on before the relay action and off after the relay action.

The `relay()` function is active by default, which means that even without being put in the user code, it still triggers the clamp on/off setting when `clamp()` is called together with a measurement command such as `vForce()`.

In SmartRDI 2.3.0, you must use the PPMU voltage clamp together with other commands and put it right before or after the relay event for preventing hot switching. This still works in later versions.

Since SmartRDI 2.3.1, you can directly use `clamp(low,high)` or `clampOff()` only to set up the clamp.

## Syntax

```
clamp(double dClampLow, double dClampHigh);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

dClampLow

 |

The low clamp voltage

 |
 |

dClampHigh

 |

The high clamp voltage

 |

## Example

```
rdi.dc("clamp2").pin("pinA").clamp(0,3.2).iForce(0).vMeas().execute();
// clamp() can be used independently since SmartRDI 2.3.1
RDI_BEGIN();
  rdi.dc().pin("DATA1").clamp(0,1).execute();
  rdi.dc().pin("DATA1").vForce(0.5 V).execute();
  rdi.dc().pin("DATA1").clampOff().execute();
RDI_END();
```
