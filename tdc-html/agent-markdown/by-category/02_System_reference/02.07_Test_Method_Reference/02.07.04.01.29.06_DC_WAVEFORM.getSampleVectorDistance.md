# DC_WAVEFORM.getSampleVectorDistance()

This function returns the specified value of vectors between DC waveform points.

## Syntax

```
void getSampleVectorDistance(INT & distance) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

distance

 |

The parameter returns the number of vectors specified by the [DC_WAVEFORM.sampleVectorDistance()](<02.07.04.01.29.05_DC_WAVEFORM.sampleVectorDistance.md>) member function.

 |

Return value

There is no return value.
