# BADC_PIN_SETTING

The BADC_PIN_SETTING class is a data container holding the object reflecting the BADC's measurement setup data. The target BADC can be specified via the [BADC_SETTING](<02.07.04.01.09_BADC_SETTING.md>) class because the BADC_PIN_SETTING class can be called as a subsidiary data container of the [BADC_SETTING](<02.07.04.01.09_BADC_SETTING.md>) class.

## Class definition

### Member functions

They are listed in alphabetical order.

```
BADC_PIN_SETTING & limits(const STRING& testname);
BADC_PIN_SETTING & limits(const LIMIT& limitobj);
BADC_PIN_SETTING & max(const DOUBLE val);
BADC_PIN_SETTING & min(const DOUBLE val);
```

## Member functions

The member function are described in alphabetical order.

### limits()

```
BADC_PIN_SETTING & limits(const STRING& testname);
BADC_PIN_SETTING & limits(LIMIT& limitobj);
```

This function sets the lower and upper limit values using a testflow limit name or a LIMIT class object. Limit values are set by using this function or the min and max function.

Parameters
 |

testname

 |

Test name that can be referred from the Properties view

 |
 |

limitobj

 |

Object name of the LIMIT class

 |

### max()

```
BADC_PIN_SETTING & max(const DOUBLE val);
```

This function sets the upper limit voltage for pass/fail judgment.

Parameter
 |

val

 |

Upper limit voltage. The default unit is [V].

   | Note Both minimum and maximum limit must be specified by the min and max function. If not, error occurs at the starting of the measurement program.

### min()

```
BADC_PIN_SETTING & min(DOUBLE val);
```

This function sets the lower limit voltage for pass/fail judgment.

Parameter
 |

val

 |

Lower limit voltage. The default unit is [V].

 |

## Example

```
    :
BADC_SETTING setting1;
setting1.pin("p1, p2").min(50 mV).max(100 mV);
    :
```

This example defines an object that holds measurement parameters of the "p1" and "p2" pin.

For a more detailed example see also [BADC_SETTING](<02.07.04.01.09_BADC_SETTING.md>).
