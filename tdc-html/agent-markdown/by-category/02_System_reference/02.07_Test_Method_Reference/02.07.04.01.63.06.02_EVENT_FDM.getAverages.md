# EVENT_FDM.getAverages()

Queries the number of internal samples to average.

The value is read from the corresponding [EVENT_FDM](<02.07.04.01.63.06_EVENT_FDM.md>) object and returned as an [EVENT_VALUE_INT](<02.07.04.01.63.19_EVENT_VALUE_INT.md>) object.

## Syntax

```
void getAverages(EVENT_VALUE_INT & samples) const;
```

  Parameter

 | Parameter  | Description |
 | samples  | Number of internal samples from which the average is created.  |  Return value There is no return value.

## Example

For an example see [EVENT_FDM](<02.07.04.01.63.06_EVENT_FDM.md>).
