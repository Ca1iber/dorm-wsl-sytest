# Performing customized source-sync shmoo tests with the shmoo tool

After you have created your own shmoo test method for shmooing over a source-sync test by using the SmarTest provided [customizd shmoo test template](<02.07.07.02_Customized_shmoo_test_template.md>), on the shmoo tool you can perform this shmoo over source-sync test.

## About this task

Note The source-sync feature is available only with MTP.

Use this method when [shmooing over a source-sync test suite on the shmoo tool](<../02.12_Memory_Test_Plus_7.10.2/02.12.02.07.04_Shmooing_over_a_source-sync_test_with_Shmoo_Tool.md>) cannot meet your expectations. For example, you want to do parallel shmoo for multi-site on the shmoo tool.

Note This is an advanced usage requiring your mastering both C++ and SmarTest.

## Before you begin

Load the testflow and its setups.

Make sure the ac_tml test method library is imported.

## Procedure

-  Create a source-sync shmoo test method based on the SmarTest provided customized shmoo test template as the description of [Creating a customized shmoo test method](<02.07.07.01_Creating_a_customized_shmoo_test_method.md>).

When setting up the userDefinedMeasure() function in the new test method file, do define the source-sync test that you want to shmoo on with the [SOURCESYNC_TEST](<../02.12_Memory_Test_Plus_7.10.2/02.12.06.29_SOURCESYNC_TEST.md>) and [SHMOO_RESULT](<02.07.04.01.227_SHMOO_RESULT.md>) APIs. Take the following code as an example:

```
bool userDefinedMeasure()
  {
    // Create a Source Sync test
    SOURCESYNC_TEST ssTest;
    string pinGroup = "DQA0_PS,DQA1_PS,DQA2_PS,
                       DQA3_PS,DQS_A_p_PS,DQS_A_n_PS";
    string subTestA = "SSspecMin";

    // Use source sync APIs to configure source sync test
   ssTest.outputMargin(SOURCE_SYNC::DISTRIBUTION)
          .outputErrorMap(SOURCE_SYNC::YES)
          .startCycle("128").stopCycle("143");
    ssTest.test(subTestA)
        .edgeList("1,2,3,4")
        .specVar("t_dut_a")
        .deviceSpec(0)
        .sweepSpecVar("tsweep_a")
        .sweepStart("-0.5")
        .sweepStop("1.5")
        .sweepStepSize(0.1);
    ssTest.domain("A").pins(pinGroup);
    ssTest.execute();

    FOR_EACH_SITE_BEGIN();  // to get value per site
    // Define the results you want to show on the shmoo plot
    SHMOO_RESULT.site(CURRENT_SITE_NUMBER())
                .testName("Domain Result").pin(pinGroup)
                .setResult(ssTest.domain("A").getPass());
    FOR_EACH_SITE_END();
    return true;
  }
```

Note For the results you want to view on the shmoo plot, you can only use the SHMOO_RESULT API to define them.
-  On the shmoo tool, [set up a shmoo test](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>) as setting up a shmoo over a functional test with the following exceptions:

  - In the Testmethod field, choose the shmoo test method you have created in step 1.
  - In the shmooTestSuite filed, do not select any test suite.
  - In the testMode filed, do select user defined measurement.
  - Keep the default values for the resultPins and perPinResult parameters which have no effect on the customized shmoo tests.

-  On the shmoo tool, [execute the shmoo test](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>).

A shmoo plot shows up on the shmoo tool. The texts above the plot indicate the name (test mode), pins and site of the result currently displayed on the plot.

-  To view shmoo plots of different results, right-click the shmoo plot, select Test Modes and select an interested result name.

These results are defined with [SHMOO_RESULT.setResult()](<02.07.04.01.227.05_SHMOO_RESULT.setResult.md>) in step 2.

-  To view shmoo plots of different result pins or pin groups, right-click the shmoo plot, select Result Pin and select an interested pin or pin group.

These pins and pin groups are defined with [SHMOO_RESULT.pin()](<02.07.04.01.227.02_SHMOO_RESULT.pin.md>) in step 2.

-  To view shmoo plots of different sites, see [Viewing different site's shmoo plot](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.04.07_Viewing_the_shmoo_plots_of_different_sites.md>).

These sites are defined with [SHMOO_RESULT.site()](<02.07.04.01.227.01_SHMOO_RESULT.site.md>) in step 2.

-  To perform fast shmoo, right-click the plot and select the Run Fast command.

Alternatively, click the ![fast execution button in the Shmoo Tool](<../../../../raw/136389.png>) shortcut on the toolbar of SmarTest. For details, see [Commands on the menu bar and their shortcuts on the toolbar](<../02.08_Setup_and_Result_Tools/02.08.04.25.04.02_Commands_in_the_menu_bar_and_the_shortcuts_in_the_toolbar.md>).

-  To manipulate the plot, such as zooming, right-click the shmoo plot and select a corresponding command from the shortcut menu.

See the available commands in [Commands in the shmoo editor of the Shmoo Tool](<../02.08_Setup_and_Result_Tools/02.08.04.25.04.03_Commands_in_the_shmoo_editor_of_the_Shmoo_Tool.md>).

## Results

You shmooed over a source-sync test on the shmoo tool with your own shmoo test method.
