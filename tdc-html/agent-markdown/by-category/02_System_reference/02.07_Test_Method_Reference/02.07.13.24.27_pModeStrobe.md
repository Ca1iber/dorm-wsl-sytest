# pModeStrobe()

Defines the strobe position within pMode cycles. The default position is in the middle of pMode cycles. In 2.3.0, for pMode, the expectBit()/expectData() and readBit()/readData() will put the strobe in middle.

## Syntax

```
pModeStrobe(int strobePos);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

strobePos

 |

The strobe position within pMode cycles.

 |

## Example

```
RDI_BEGIN();
  rdi.smartVec().pin("DATA7").readData(8,4).pMode(4).pModeStrobe(3).execute();
RDI_END();
```

The following code illustrates the operation of pModeStrobe.

```
rdi.smartVec().pin("A").expectBit(arr).pMode(4).pModeStrobe(2).execute();
```

expect bit : 001-> LLH

vec: XLXXXHXXXHXX
