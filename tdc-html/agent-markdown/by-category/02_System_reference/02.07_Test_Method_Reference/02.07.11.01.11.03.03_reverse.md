# reverse()

Reverts a given state character sequence.

An error will be issued if the parameter types are wrong.

## Syntax

```
integer := reverse(sequence)
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

sequence

 |

State character sequence to be reversed.

 |

## Example

`reverse("000000000010HLHLHLHL")` results in "`LHLHLHLH010000000000`".

`reverse("")` results in"".

## Functional changes

- Introduced in SmarTest 7.1.4
