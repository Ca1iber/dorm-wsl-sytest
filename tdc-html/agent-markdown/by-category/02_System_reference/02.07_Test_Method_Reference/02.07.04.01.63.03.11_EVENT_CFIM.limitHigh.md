# EVENT_CFIM.limitHigh()

Sets the upper current limit to compare against threshold.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_CFIM & limitHigh(const EVENT_VALUE_DOUBLE & highLimit);
```

Parameter
 | Parameter  | Description |
 | highLimit |

The upper limit to be set in A (Ampere).

 |

## Return value

A reference to the corresponding [EVENT_CFIM](<02.07.04.01.63.03_EVENT_CFIM.md>) object.

## Example

For an example see [EVENT_CFIM](<02.07.04.01.63.03_EVENT_CFIM.md>).
