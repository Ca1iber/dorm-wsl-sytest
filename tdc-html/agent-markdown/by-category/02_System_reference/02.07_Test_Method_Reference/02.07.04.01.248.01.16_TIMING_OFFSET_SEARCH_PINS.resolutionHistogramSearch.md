# TIMING_OFFSET_SEARCH_PINS.resolutionHistogramSearch()

This function defines the step width for the histogram based search.

## Syntax

```
TIMING_OFFSET_SEARCH_PINS& resolutionHistogramSearch(DOUBLE res);
```

Parameter
 |

I

 |

res

 |

The step width of the histogram based search.

 |
