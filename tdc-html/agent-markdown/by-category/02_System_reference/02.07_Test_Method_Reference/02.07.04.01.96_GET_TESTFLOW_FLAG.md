# GET_TESTFLOW_FLAG()

Retrieves the current value of the specified testflow flag.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

## Syntax

```
GET_TESTFLOW_FLAG(const STRING& flag, INT *value);
```

Parameters
 |

Parameter

 |

Description

 |
 |

flag

 |

The name of the testflow flag to query.

For a detailed list of the testflow flags, refer to [Alphabetical list of flags](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md>). Select Testflow in the filter settings of column Area to show only the testflow flags.

 |
 |

value

 |

The current value of the specified flag.

 |

## Return value

Returns the current value of the corresponding flag. The data type of the returned value depends on the testflow flag queried.

## Example

The following example show how to use GET_TESTFLOW_FLAG() to retrieves the current value of the debug_mode flag into the debugflag_state variable.

```
INT debugflag_state;
GET_TESTFLOW_FLAG("debug_mode", &debugflag_state);
```
