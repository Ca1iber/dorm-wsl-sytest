# Marker

Class Marker controls the following marker operations:

- make markers visible/non-visible
- specify which axes to place markers
- center markers
- set marker positions on the trace
- specify an "up" and "down" marker
- set marker colors
- synchronize "up" marker with "down" marker

Class Marker consists of two markers: up marker and down marker. You can control or customize these markers individually.

If the Graph has multiple traces, A Marker object must belong to one of the traces.

## Examples

### Make markers non-visible temporarily

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getMarker().setVisible(false);
graphManager->setGraph(graph, 1);
```

This example makes the markers of graph 1 invisible.

### Move markers and display marker positions

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
Marker marker = graph.getMarker();
ARRAY_D waveform = Analog.DGT("digitizer").getWaveform();
DOUBLE_VECTOR trace_wave;
Trace trace;
for(int i=0;i<waveform.size();i++)
{
  trace_wave.push_back(waveform[i]);
}
trace.setWaveform(trace_wave);
double min, max;
int min_index, max_index;
DSP_MINMAX(waveform, &min, &max, &min_index, &max_index);
// Find min/max automatically
marker.setUpMarkerPosition(min_index);
marker.setDownMarkerPosition(max_index);
graph.setMarker(marker);
graph.setTrace(trace, 1);
graphManager->setGraph(graph, 1);

```

This example moves the up marker to the minimum value of the waveform and the down marker to the maximum value the waveform.

### Change marker color

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
Marker marker = graph.getMarker();
marker.setUpMarkerColor(Display::WHITE);
marker.setDownMarkerColor(Display::GREEN);
graph.setMarker(marker);
graphManager->setGraph(graph, 1);
```

This example sets the color of the up marker to white and the color of the down marker to green.

### Synchronize markers

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getMarker().setTrackMode(Display::TRACK_ON);
graphManager->setGraph(graph, 1);
```

This example sets the track mode of the markers to ON. The two markers will be moved simultaneously.
