# OperatingCurrent

This test method measures the current supplied to a DUT while it is undergoing a functional test. The functional test pattern will be repeated endlessly and aborted after the current measurement is finished.

This test method supports test table. But you need to enter the test names manually in the parameter. You can use both test table and testflow limits in a testflow. The test table has higher priority than testflow limits. If a test name used in the test flow is defined in both test table and testflow limits, the value defined in the test table will be used.

Type

Description

PinString

 |

Name of pins to be tested. This can be @ for all applicable pins, or any number of applicable single pins.Valid pin types include DPS pins.

 |

 |

INT

 |

Samples for the DPS measurement. The default is 4. This value must be a positive integer.

 |

SpecValue

 |

Extra delay time in ms between sequence starting and the measurement execution.

It is in the format of value[unit]. Default value is 0[ms].

 |
 |

termination

 |

string

 |

Enable/disable termination.

ON - measure terminated pins.

OFF - disconnect terminated pins.

 |
 |

testName

 |

string

 |

The test names to be used as limits. Default is passCurrLimit_uA.

If you want to use the test names defined in the test table or testflow limits, type in the test names manually. Make sure the test names are in the Test name column of the test table (Refer to [Structure of a TMLimits CSV file](<../02.10_Data_Logging/02.10.01.08.01.01.03.01_Structure_of_a_TMLimits_CSV_file.md>)) or in the Test Name column of Tests page of Flow Data Editor.

 |
 |

output

 |

string

 |

Controls how to output the per pin test result. It can be:

- None: Do not output the per pin result.
- ReportUI: Output all the per pin result to the report window.

ShowFailOnly: Only outputs the failed pin result to the report window.

 |

## Limits

 |

passCurrLimit_uA

 |

The pass range of the measured current.

 |

## Implementation pseudo code

```
IF not already connected THEN
    connect DUT
ENDIF
IF terminated off THEN
  disconnect terminated pins
  run the sequencer in endless mode
  measure current on the specified DPS pins
  abort the sequencer
  connect the terminated pins
ELSE
  run the sequencer in endless mode
  measure current on the specified DPS pins
  abort the sequencer
ENDIF
datalog test results
```

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.0: Change parameter type of dpsPins to PinString for UTM library.
- SmarTest 6.5.2: Change parameter type of delayTime to SpecValue for UTM library.
- SmarTest 7.0.3: Classic test method library is removed.
- SmarTest 7.1.1: Test table is supported in TML 2.1.1.
- SmarTest 7.1.1: Mixed usage of test table and testflow limits in one testflow is supported in TML 2.1.1.
- SmarTest 7.1.1: New parameter testName is added in TML 2.1.1.
- SmarTest 7.2.1: New option ShowFailOnly for the parameter output in TML 2.2.0.
