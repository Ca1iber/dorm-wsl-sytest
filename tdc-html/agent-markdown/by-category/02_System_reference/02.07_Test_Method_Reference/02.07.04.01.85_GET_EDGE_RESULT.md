# GET_EDGE_RESULT

This API returns the functional test results by using string pattern (for example, ".fff.."). Each character means a pass/fail result of each edge and "f" means a fail, comma (.) means a not fail.

## Application note

- The EYE_EDGE_TBL, GET_EDGE_RESULT and FIND_EYE_EDGE API are related each other to find the center point of the DUT output signal. The center point is called EYE EDGE of the DUT output signal. The EYE EDGE is used to synchronize the DUT output signal whose phase is unknown with the tester. For more details of these APIs' concept, see [EYE_EDGE_TBL](<02.07.04.01.66_EYE_EDGE_TBL.md>).
- The GET_EDGE_RESULT API returns the result for the site that is in [query focus](<../02.06_Command_Reference/02.06.03.01.10.03_Defining_the_query_focus.md>). Use this API within a [FOR_EACH_SITE](<02.07.04.01.70_FOR_EACH_SITE_BEGIN.md>) block to retrieve results per site.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/EyeEdgeTbl.h.

## Example

```
EYE_EDGE_TBL et;

et.add("ppfffp", 1).
   add("pffffp", 1).
   add("pppfff", 2).
   add("ppffff", 2).
   add("fpppff", 3).
   add("fppfff", 3).
   add("ffpppf", 4).
   add("ffppff", 4).
   add("fffppp", 5).
   add("fffppf", 5).
   add("pfffpp", 6).
   add("ffffpp", 6);

FUNCTIONAL_TEST();
INT edge = FIND_EYE_EDGE(GET_EDGE_RESULT("clock"),et);
```

This example defines the edge table "et". Then executes functional tests on edge1-6. The FIND_EYE_EDGE finds the pass/fail pattern from the edge table and returns the EYE EDGE number.
