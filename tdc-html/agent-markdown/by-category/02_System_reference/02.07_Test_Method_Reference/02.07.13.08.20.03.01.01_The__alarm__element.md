# The <alarm> element

This element stores the results of alarm checking performed through the SmartRDI's alarm() class.

## Retrieving the ORE result of alarm handling

 The <alarm> element stores alarm checking results in its passFail attribute. The attribute saves the pass/fail information which will be retrieved by the [getAlarmPassFail()](<02.07.13.09.02.07_rdi.id__.getAlarmPassFail.md>) function.

 | Get Result Function in SmartRDI  | ORE File Syntax Example |
 | [int getAlarmPassFail ();](<02.07.13.09.02.07_rdi.id__.getAlarmPassFail.md>)  | <alarm passFail = "1"/> |

See the [Example 1](<02.07.13.08.20.03.01.01_The__alarm__element.md#_352227__example_1>).

## Generating an ORE template for alarm handling

 For the alarm class, if [ORE_TEMPLATE_BY_USER_CODE = TRUE](<02.07.13.04_RDI_Configure_file.md#_146692__row_ORE_TEMPLATE_BY_USER_CODE>) is set in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>), SmartRDI will add alarming handling results to the rdi_ore_template_by_user_code.xml path.Note SmartRDI can only add the alarm handling result which has been specified by the rdi.id("id").getAlarmPassFail("*"); in the test method.

See the [Example 2](<02.07.13.08.20.03.01.01_The__alarm__element.md#_352227__example_2>).

## Examples

### Example 1

<alarm> elements in an ORE file:

```
<offlineResultEmulation>
  <id name = "id">
    <site num = "1,2,3,">
      <pin name = "A">
        <alarm passFail = "0"/>
      </pin>
    </site>
  </id>
  <id name = "id">
    <site num = "1,2,3,">
       <alarm passFail = "1"/>
    </site>
  </id>
</offlineResultEmulation>
```

 The corresponding SmartRDI code block:

```
RDI_BEGIN();
  rdi.dc().pin("A").vForce(0.1).execute();
  rdi.func("id").label("abc").execute();
  ...
RDI_END();
...
rdi.id("id").getAlarmPassFail("A");
rdi.id("id").getAlarmPassFail();
```

The pin name "A" must have been defined in the alarm handling setup file.

### Example 2

 Generated ORE file:

```
<offlineResultEmulation>
  <testSuite name = "offline_ORE">
    <id name = "id">
      <site num = "1,2,">
        <pin name = "DATA">
          <smartVec readData = "12,"/>
        </pin>
      </site>
    </id>
    <id name = "id">
      <site num = "1,2,">
        <alarm passFail = "0">
      </site>
    </id>
    <id name = "id">
      <site num = "1,2,">
        <pin name = "A">
          <alarm passFail = "1"/>
        </pin>
      </site>
    </id>
  </testSuite>
</offlineResultEmulation>
```

 SmartRDI code block:

```
RDI_BEGIN();
  rdi.smartVec("id").pin("DATA1").readData(8,2).execute()
  ...
RDI_END();
...
rdi.id("id").getAlarmPassFail();
rdi.id("id").getAlarmPassFail("A");
```
