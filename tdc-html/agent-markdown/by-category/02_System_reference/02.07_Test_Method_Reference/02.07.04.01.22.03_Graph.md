# Graph

Class Graph controls graph level operations such as axis control, cursor and marker operations, and trace manipulation. This class has the following class objects as members:

- Axis
- Grid
- Cursor
- Marker
- Trace
- TestMask

## Member functions

The member function are described in alphabetical order.

### setGraphStyle()

```
Graph & setGraphStyle(Display::GraphStyle style);
```

This function specifies a style for the graph. The default style is PLOT_LINE.

Parameter
 |

style

 |

The graph style. It can be:

- PLOT_LINE: This style supports general chart.
- PLOT_BAR: This style supports bar chart.
 |

### getGraphStyle()

```
Display::GraphStyle getGraphStyle(void) const;
```

This function returns the current style of graph. It can be PLOT_LINE or PLOT_BAR.

### getTitle()

```
const char* getTitle(void) const;
```

This function returns the graph title.

### getComment()

```
const char* getComment(void) const;
```

This function returns the comment of the graph.

### setBackGroundColor()

```
Graph & setBackGroundColor(Display::Color color);
```

This function sets the background color for the graph.

Parameter
 |

color

 |

The background color of the graph. It can be BLACK, BLUE, CYAN, DARK_GRAY, GRAY, LIGHT_GRAY, GREEN, MAGENTA, ORANGE, PINK, RED, YELLOW or WHITE.

 |

### getBackGroundColor()

```
Display::Color getBackGroundColor(void) const;
```

This function returns the background color of the graph.

### createTrace()

```
int createTrace(const Trace & trace);
```

This function creates a trace object on the graph so that the trace can be overlaid. The trace ID is automatically assigned and is returned.

### setTrace()

```
Graph & setTrace(const Trace & trace, int id);
```

This function sets a trace object to the graph. The graph object can have multiple traces to overlay waveforms. Thus, an identifier is needed for each trace of the graph. You must specify the trace ID explicitly.

Parameters
 |

trace

 |

Trace object reference.

 |
 |

id

 |

ID of a trace. The value of the identifier is a positive integer. If a non-positive integer is passed, an exception is returned.

 |

### setLegend()

```
Graph & setLegend(bool visible);
```

This function creates a legend of the graph visible or non-visible. The legend is determined automatically by the pin name and test label, as "Pin: (pin name), Label: (test label)"

The pin name is specified by Trace::setPinName. The test label is specified by Trace::setTestLabel.

Parameter
 |

visible

 |

It can be:

- true: Make a legend of graph visible.
- false: Make a legend of graph non-visible.
 |

```

```

 |

## Examples

### Change title

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.setTitle("Sample");
graphManager->setGraph(graph,1);
```

This example changes the title of graph 1 in the Signal Analyzer to "`Sample`".

### Set test condition

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.setComment("Sample Comment");
graphManager->setGraph(graph,1);
```

This example changes the comment of the graph in the Signal Analyzer to "`Sample Comment`".

### Change background color

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.setBackGroundColor(Display::BLACK);
graphManager->setGraph(graph,1);
```

This example changes the background color of graph 1 in the Signal Analyzer to black.

### Get trace IDs and delete traces

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
vector<int> identifiers = graph.getTraceIds();
int size = identifiers.size();
for (int i = 0; i < size; i++)
{
  graph.deleteTrace(identifiers[i]);
}
graphManager->setGraph(graph,1);
```

This example gets all the trace IDs on graph 1 and delete all the existing traces on the graph.

### Clear waveforms

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.init();
graphManager->setGraph(graph,1);
```

This example clears all the information of graph 1.
