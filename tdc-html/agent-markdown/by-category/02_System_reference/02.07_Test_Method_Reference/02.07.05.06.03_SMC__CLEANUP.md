# SMC__CLEANUP

The test method terminates all threads of the currently active site and deletes all corresponding queued data.

It ensures that all data in the background queue of this site will be deleted and will not further be uploaded nor evaluated whenever that site is running into a fail bin.

The run() function of the test method is implemented as

```
virtual void run()
{
    [SMC_CLEANUP](<02.07.04.01.231.07_SMC_CLEANUP.md>) (true);
}
```

List of test method parameters

 | Parameter  | Type  | Description |
 | disconnect  | int  | The parameter allows to execute a standard disconnect of the currently active site. |
