# DIGITAL_OFFSET_SEARCH_PINS.setup()

Executes the firmware commands [TOCF, TOCF?](<../02.06_Command_Reference/02.06.02.02.260_TOCF__TOCF__-__Timing_Level_Offset_search_ConFiguration.md>) to set up offset search configurations for the pins specified with [DIGITAL_OFFSET_SEARCH_TASK.pin()](<02.07.04.01.36.03_DIGITAL_OFFSET_SEARCH_TASK.pin.md>).

## Syntax

```
void setup();
```

List of parameters

There are no parameters.

Return value

There is no return value.
