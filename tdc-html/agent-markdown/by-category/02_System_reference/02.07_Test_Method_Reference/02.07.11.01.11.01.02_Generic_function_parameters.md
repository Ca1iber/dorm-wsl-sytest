# Generic function parameters

The following parameters are allowed in any encode/decode function:

- Transaction specific parameters (<parameter>)
- Transaction symbols
- Field symbols
- Named protocol constants (<constant>)

These parameters can be accessed in an encode/decode function by their name. It is not supported to use the same name for a parameter and a symbol.

Using the same parameter name in different transactions is permitted.

Fields in a protocol frame (transaction) have their own namespace and are prefixed with the '@' character (@<field>).

## Functional changes

- Introduced in SmarTest 7.1.0
