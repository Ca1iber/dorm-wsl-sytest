# SPMU_PIN_TASK.relay()

Sets the relay switching mode that automatically also executes a specific relay control pattern. Measurements performed with the shared resources like the BADC are automatically serialized.

 Note The same relay mode may result in a different relay control pattern determined by the underlying HW.Note Although Board ADC measurements can be done with this function, it is recommend using the [FLEX_RELAY](<02.07.04.01.68_FLEX_RELAY.md>) class instead.

## Syntax

```
SPMU_PIN_TASK& relay(const STRING& relay);
```

Supported only in PMU operating mode of DC Scale pins.

Relay actions depend on the settings of [SPMU_PIN_TASK.mode()](<02.07.04.01.234.01.24_SPMU_PIN_TASK.mode.md>) with [SPMU_TASK.execMode()](<02.07.04.01.234.02_SPMU_TASK.execMode.md>) set to "FORCE_ON":

- mode() set to "IFVM", "VFIM":

  - Connect DC Scale card by closing AC_Force, H_IMP and AC_Sense relays.
  - Measure
  - Open AC_Force, H_IMP and AC_Sense relays.

- mode() set to "VM_HIZ":

  - Connect DC Scale card by closing H_IMP and AC_Sense relays.
  - Measure
  - Open H_IMP and AC_Sense relays.

- mode() set to "VFIM_UNGANGED":

  - Connect DC Scale card by closing AC_Force, H_IMP and AC_Sense relays.
  - Measure (not needed pins will be disconnected)
  - Open AC_Force, H_IMP and AC_Sense relays.

   | |

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.
