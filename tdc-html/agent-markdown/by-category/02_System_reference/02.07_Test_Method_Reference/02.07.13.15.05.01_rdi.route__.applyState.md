# rdi.route().applyState()

Applies an already defined switch state to utility lines and PMUX switches.

The function applies the selected switch state to the supported hardware. The selected state may contain any combination of static utility lines, [sequencer鈥慶ontrolled](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01_Sequencer-controlled_utility_lines.md>) utility lines. The applied switch state must already be defined by the [State Setup editor](<02.07.13.15.01.04_Routing_Tools_-_State_Setup_editor.md>) of the [Routing Tools editors](<02.07.13.15.01_Routing_Tools_editors.md>).

Only one switch state may be applied and activated at time.

 Usage of the function:

- The function can be called in the code鈥慴ased mode or in the pattern鈥慴ased mode. For more information, refer to [Execution mode](<02.07.13_SmartRDI.md#_142069__s_Execution_mode>) in topic [SmartRDI](<02.07.13_SmartRDI.md>).
- For debugging, we recommend setting the keyword [ROUTING_ACK_CHECK](<02.07.13.04_RDI_Configure_file.md#_146692__row_ROUTING_ACK_CHECK>) of the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>) to TRUE to enable a check if the route state is applied successfully to PMUX switches.
 Execution sequence:

- Code-based mode:

  - Combination of static utility lines and sequencer鈥慶ontrolled utility lines or PMUX switches:

The setup of the static utility lines is applied first, followed by a pattern that applies the setup of the sequencer鈥慶ontrolled utility lines and activates a stored PMUX state.

  - Only sequencer鈥慶ontrolled utility lines or PMUX switches:

A pattern that applies the setup of the sequencer鈥慶ontrolled utility lines and activates a stored PMUX state is started.

- Pattern-based mode:

A pattern that applies the setup of the sequencer controlled utility lines and activates a stored PMUX state is started within an RDI burst.

Note Any switch state that contains static utility lines cannot be applied in pattern鈥慴ased mode. This restriction ensures that the sequence of applying the switch state corresponds to the source code.

## Syntax

```
routeGroup& applyState(const string &state);
```

  List of parameters

 | Parameter  | Description |
 | state  | The string defines the switch state that is to be applied.

The selected switch state must already be defined by the [State Setup editor](<02.07.13.15.01.04_Routing_Tools_-_State_Setup_editor.md>) of the [Routing Tools editors](<02.07.13.15.01_Routing_Tools_editors.md>).

  |  Return value A reference to the [routeGroup](<02.07.13.15.05_rdi.route.md>) object.

### Example 1

```

...
...

    ...
    ...
    RDI_BEGIN();

        ...

        rdi.route().applyState("Connect_load").execute();

    }
    RDI_END();
    ...
    ...

...

  RDI_END();

FOR_SEMI_PARALLEL_TEST_END();

rdi.route().enableOnlyActiveSites().execute();
```
