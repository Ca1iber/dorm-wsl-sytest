# Trace

The Trace class controls the waveform data and its properties (line color, line style, etc.) displayed on a graph:

- Make a waveform visible or hide it
- Associate a pin name to the trace
- Create a test label for the waveform
- Set waveform color
- Set line style
- Set pointer symbol
- Set sampling period
- Set sampling frequency
- Set waveform data into trace
- Set vector data into trace
- Set scattered data points
- Mask an arbitrary area of graph
- Specify the ID of the x-axis assigned to the trace
- Specify the ID of the y-axis assigned to the trace
- Set a text label into a specified point of the trace
- Set scattered data points into trace with different colors

The Graph class has multiple traces to display multiple waveforms.

If the graph has multiple axes and multiple traces, each trace must be assigned to one of the axes.

## Examples

### Make specified waveform non-visible temporarily

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getSelectedGraph();
// Make the 3rd trace non-visible temporarily
graph.getTrace(3).setVisible(false);
graphManager->setSelectedGraph(graph);
```

This example hides trace 3 on the currently selected graph.

### Change the color of the traces

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getSelectedGraph();
graph.getTrace(1).setColor(Display::RED);
graph.getTrace(2).setColor(Display::BLUE);
graphManager->setSelectedGraph(graph);
```

This example sets the color of trace 1 to red and the color of trace 2 to blue on the currently selected graph.

### Change line style of trace

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getTrace(1).setLineStyle(Display::SOLID);
graph.getTrace(2).setLineStyle(Display::DASH_DOT);
graph.getTrace(3).setLineStyle(Display::NONE_LINE);
graphManager->setGraph(graph, 1);
```

This example sets the line style of trace 1 to `SOLID`, the line style of trace 2 to `DASH_DOT` and the line style of trace 3 to `NONE` on the graph 1.

### Change the ponit symbol

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getGraph(1);
graph.getTrace(1).setPointSymbol(Display::DIAMOND);
graph.getTrace(2).setPointSymbol(Display::STAR);
graphManager->setGraph(graph, 1);
```

This example sets the point symbol of trace 1 to `DIAMOND` and the point symbol of trace 2 to `STAR` on the graph 1.

### Change sampling frequency

```
GraphManager * graphManager = GraphManager::getInstance();
graph = graphManager->getSelectedGraph();
string unit;
// Get the current sampling frequency of x-coordinate of 1st trace
graph.getTrace(1).getSamplingFrequency(&frequency, unit);
// Double the sampling frequency
if (unit.find("s") != string::npos)
{
  graph.getTrace().setSamplingFrequency(frequency*2, unit);
}
graphManager->setSelectedGraph(graph);
```

This example doubles the sampling frequency of the trace if the unit is in time domain.

### Execute user defined signal computation

```
GraphManager * graphManager = GraphManager::getInstance();
Graph graph = graphManager->getSelectedGraph();
Trace trace = graph.getTrace(1);
Display::DataType type = trace.getDataType();
// If the trace is a time domain waveform data, calculate the SND
if (type == Display::WAVEFORM)
{
  double period;
  string unit;
  trace.getSamplingValue(&period, unit);
  if (unit.find("s") != string::npos)
  {
    vector<double> src = trace.getWaveform();
    ARRAY_D sigwave(src.size());
    for(int i=0;i<src.size();i++)
    {
      sigwave[i]=src[i];
    }
    double snd, signalPower, otherPower;
    DSP_SND(sigwave, &snd, &signalPower, &otherPower, 1024, 1, 0, NULL);
    // Display results to the system message area
    cout << "SND: " << snd << endl;
    cout << "Signal Power: " << signalPower << endl;
    cout << "Other Power: " << otherPower << endl;
  }
  else
  {
    graph.print("This trace is not a time domain waveform !");
  }
}
```

This example calculates the SND of trace 1 if it is in time domain.

### Generate a Smith chart with data trace

```
Graph graph;
graph.setGraphType(Display::SMITH_GRAPH);
graph.init();
graph.setTitle("my Smith chart");

Trace trace;
DOUBLE_VECTOR vReal, vImag, vFreq;
trace.setPinName("my1A1").setTestLabel("myTrace");
trace.setScatter(vReal, vImag, vFreq);
trace.setElectricalDelay(5e-9).setLoss(1.5);
graph.createTrace(trace);
```

In this example, a Graph object is created and its type is set to Smith chart. The graph's title is set to "my Smith chart". Then a trace object is created with the label "myTrace". The reflection coefficients, electrical delay and loss of the trace are set. The trace "myTrace" is created on the graph "my Smith chart".
