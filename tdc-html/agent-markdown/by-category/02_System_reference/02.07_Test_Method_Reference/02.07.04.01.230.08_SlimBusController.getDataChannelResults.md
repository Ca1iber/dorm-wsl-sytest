# SlimBusController.getDataChannelResults()

This function returns the message values on the specfied site across superframes and returns them as a SLIMbus result vector. This function can only be called after the decode() function.

## Syntax

```
const SlimBusDataVector & getDataChannelResults (INT channelId, int site=-1) const
```

Parameter
 |

Parameter

 |

Description

 |
 |

site

 |

Specifies the site that is to be processed. If no site is specified, the current site under test is taken.

 |

## Return value

A SLIMbus result vector that contains all message results on the specified site.

## Functional changes

- Introduced in SmarTest 7.2.1
