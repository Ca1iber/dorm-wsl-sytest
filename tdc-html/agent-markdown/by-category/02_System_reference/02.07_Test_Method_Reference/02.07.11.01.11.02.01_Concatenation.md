# Concatenation

The '+' operator concatenates two state character sequences.

The length of the result of this operation is the sum of the parameters' lengths.

## Syntax

sequence := sequence + sequence

## Example

"0100" + "11" results in `"010011"`

"01" + "LLZH" results in `"01LLZH"`

"01" + ""results in `"01"`

"011" + 2 results in an error: "Operator parameters of different types."

## Functional changes

- Introduced in SmarTest 7.1.0
