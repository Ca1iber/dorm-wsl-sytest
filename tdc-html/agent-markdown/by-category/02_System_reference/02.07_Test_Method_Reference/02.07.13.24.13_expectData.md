# expectData()

Specifies the expected data from the captured pin. If the expected data and an ID are used together, the result of pass/fail per label will be retrieved.

## Syntax

```
expectData(long long data, int bitLength, int startBit=0);
expectData(string rtv, int bitLength, int startBit=0);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

data

 |

The expected data you want to get from the captured pin.

 |
 |

bitLength

 |

The length of the bits (data will be automatically converted into bits) to be written.

 |
 |

startBit

 |

The starting position of the bits to be compared. If the startBit parameter missing, the default value is 0.

 |
 |

rtv

 |

The value to be used at runtime.

 |

## Examples

### Example 1

```
RDI_BEGIN();
  rdi.smartVec().pin("DATA3").expectData(0x54,8,2).execute();
RDI_END();
```

### Example 2

This example demonstrates how to use `expectData()` at runtime.

```
ARRAY_I outputSite = ...
rdi.runTimeVal("rtValue", outputSite);
RDI_BEGIN();
  ...
  rdi.smartVec("a").pin("pinA").expectData("rtValue",8).execute();
  ...
RDI_END();

int result = rdi.id("a").getPassFail();
```
