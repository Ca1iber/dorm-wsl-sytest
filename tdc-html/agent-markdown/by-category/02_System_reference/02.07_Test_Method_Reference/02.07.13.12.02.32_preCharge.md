# preCharge()

Specifies the precharge voltage for the DC measurement.

This function is only for DC Scale pins in the PMU operating mode and used only in the code鈥慴ased mode.

## Syntax

```
dcBase& preCharge(double dPreChargeVoltage);
```

Parameters
 | Parameter  | Description |
 | dPreChargeVoltage  | The precharge voltage to set. |

## Return Value

A reference to the dcBase object.

## Example

```
//
// All DC Scale cards
//
rdi.dc().pin("pinA")
    .preCharge(1 V)
    .vForce(2 V)
    .clamp(1 mA)
    .execute();

```

## Functional changes

- Introduced in SmartRDI 2.2.0
- SmartRDI 2.4.2: DC Scale AVI64 card added.
- SmartRDI 7.5.0: DC Scale FVI16 card added.
