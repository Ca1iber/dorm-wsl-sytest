# Write array

Protocols can support burst write and read. The write array operation is performed through the RA_WRITE_ARRAY() command. The command needs a start address on which the first array data is written. The address is automatically incremented.

  To use write array in your test methods, you must define defineWriteArray() in your protocol class in advance. For example,

```
virtual void defineWriteArray(I2C& i2c, ULONG64 address,
                              const vector<ULONG64>& arrayData)
{
  i2c.startCondition();
  i2c.sendByteWithAck(0xD0);
  i2c.sendByteWithAck(address / 256);
  i2c.sendByteWithAck(address % 256);
  for(unsigned int i=0; i<arrayData.size(); ++i) {
      i2c.sendByteWithAck(arrayData.at(i));
  }
  i2c.stopCondition();
}
```

After you have added the definition in your protocol, you can use RA_WRITE_ARRAY() in your test methods to write array data. See [Example 1](<02.07.13.08.12.03.07_Write_array.md#_351502__example_1>) below for how to use write array in test methods.

## Write array with digital source memory

[Digital Source Memory (DSM)](<../02.08_Setup_and_Result_Tools/02.08.01.03.01_Overview_of_Digital_Source_Memory__DSM.md>) can be used when mass data needs to be written with dynamic array data.

 Define DSM in the protocol before using write array with DSM, for example,

```
class I2C_arrayDSM : public ProtocolI2C {
public:
...
virtual std::string getName() const
{return "I2C_arrayDSM";}

virtual void defineWriteArray(I2C& i2c, ULONG64 address, const vector<ULONG64>& arrayData) {

  i2c.startCondition();
  i2c.sendByteWithAck(SLAVE_ADDRESS);
  i2c.sendByteWithAck(address / 256);
  i2c.sendByteWithAck(address % 256);

  // Use instruction loop for DSM
  i2c.loopBegin(arrayData.size());
      i2c.sendByteWithAck(0, "inData");
  i2c.loopEnd();
  i2c.stopCondition();
}
};

REGISTER_PROTOCOL(I2C_arrayDSM);
```

After you have added the definition in your protocol, you can use RA_WRITE_ARRAY() in your test methods to perform the write array with DSM. See [Example 2](<02.07.13.08.12.03.07_Write_array.md#_351502__example_2>) below.

## Examples

### Example 1

Write array in test methods

```
RDI_BEGIN();
  vector<ULONG64> arrayData(256);
  for(unsigned int i=0;i<arrayData.size();++i) {
      arrayData[i] = i;
  }

  RA_WRITE_ARRAY(START_ADDR, arrayData);

RDI_END();
```

### Example 2

 Write dynamic array in test methods

```
// Set data array
MultiSite<vector<ULONG64> > mlData;

FOR_EACH_SITE_BEGIN();
  int siteIndex = CURRENT_SITE_NUMBER() -1;
  vector<ULONG64> aa(10);
  for(unsigned int i=0;i<aa.size();++i)
      aa[i] = rand() % 256;
  mlData[siteIndex] = aa;

FOR_EACH_SITE_END();

RA_SET_DYNAMIC_DATA("DynamicID", mlData);

// Write DSM

RDI_BEGIN();
  RA_WRITE_ARRAY(START_ADDR, "DynamicID");
RDI_END();
```
