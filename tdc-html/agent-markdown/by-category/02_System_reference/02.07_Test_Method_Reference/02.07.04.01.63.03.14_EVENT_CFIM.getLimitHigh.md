# EVENT_CFIM.getLimitHigh()

Reads the upper limit that has been defined by [EVENT_CFIM.limits()](<02.07.04.01.63.03.09_EVENT_CFIM.limits.md>) or [EVENT_CFIM.limitHigh()](<02.07.04.01.63.03.11_EVENT_CFIM.limitHigh.md>).

The value is read from the corresponding [EVENT_CFIM](<02.07.04.01.63.03_EVENT_CFIM.md>) object and returned as an [EVENT_VALUE_DOUBLE](<02.07.04.01.63.18_EVENT_VALUE_DOUBLE.md>) object.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
bool getLimitHigh(EVENT_VALUE_DOUBLE & highLimit) const;
```

Parameter
 | Parameter  | Description |
 | highLimit |

The programmed upper limit in A (Ampere).

 |

## Return value

bool value indicating the state of the limit definition:

- true: Limit has been defined by [EVENT_CFIM.limits()](<02.07.04.01.63.03.09_EVENT_CFIM.limits.md>) or [EVENT_CFIM.limitHigh()](<02.07.04.01.63.03.11_EVENT_CFIM.limitHigh.md>).
- false: No limit is defined or the limit has been cleared by [EVENT_CFIM.clearLimits()](<02.07.04.01.63.03.12_EVENT_CFIM.clearLimits.md>).

## Example

For an example see [EVENT_CFIM](<02.07.04.01.63.03_EVENT_CFIM.md>).
