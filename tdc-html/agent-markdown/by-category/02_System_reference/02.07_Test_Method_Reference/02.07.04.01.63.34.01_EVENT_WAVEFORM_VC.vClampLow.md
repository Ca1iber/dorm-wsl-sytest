# EVENT_WAVEFORM_VC.vClampLow()

Sets the lower clamp voltage waveform as [ANALOG_WAVEFORM](<02.07.04.01.05_ANALOG_WAVEFORM.md>).

 Note Both the waveform for the lower clamp voltage, defined by this member function, and the waveform for the upper clamp voltage, defined by [EVENT_WAVEFORM_VC.vClampHigh()](<02.07.04.01.63.34.03_EVENT_WAVEFORM_VC.vClampHigh.md>), can be set in one DC waveform event. We strongly recommend using the same size for the two waves. The related clamp voltage will be set to 0.0 V for missing samples if the size of the two waveforms differs.

## Syntax

```
EVENT_WAVEFORM_VC & vClampLow(ANALOG_WAVEFORM & waveform);
```

  Parameter

 | Parameter  | Description |
 | waveform |

Defines the waveform to be set in V (Volt).

  |   Return value A reference to the corresponding [EVENT_WAVEFORM_VC](<02.07.04.01.63.34_EVENT_WAVEFORM_VC.md>) object.
