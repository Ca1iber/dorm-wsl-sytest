# SPMU_PIN_TASK.vForceRange()

Selects the voltage range based on the expected voltage passed in by the rangeValue parameter.

## Syntax

```
SPMU_PIN_TASK& vForceRange(DOUBLE rangeValue);
```

Parameter
 |

Parameter

 |

Description

 |
 |

rangeValue

 |

Expected value in Volt.

SmarTest determines the voltage range automatically from the programmed force- or clamp-voltage if the range has not been defined by this API.

   | Note The voltage range depends on the underlying hardware.

## Return value

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.
