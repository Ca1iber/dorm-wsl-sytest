# setMeasDef()

This API is used to set the analog sequencer group to the RF measurement definition.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTMultiportSync.hpp.

## Syntax

```
virtual void setMeasDef(const STRING& _measName);
```

Parameter
 |

_measName

 |

Specifies the measure definition name.

 |

## Example

```
AnalogSeqGroup     mAnalogSeqGroup;

mAnalogSeqGroup.setStimDef(CCTgetAnalogRFSetName());

mAnalogSeqGroup.setMeasDef(CCTgetAnalogRFSetName());

mAnalogSeqGroup.setAWG("awg_pin");

mAnalogSeqGroup.setDGT("dgt_pin");
```
