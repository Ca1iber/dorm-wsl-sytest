# PROB_HND_CALL()

You can use this API to execute the function provided by the driver.

## Syntax

```
PROB_HND_CALL(const string &ph_call)
```

Parameter
 |

Parameter

 |

Type

 |

Description

 |
 |

ph_call

 |

const string &

 |

The function name and parameters to be executed.

For example, `ph_get_status DEVICEID 1`, which is used to get the device ID of site 1.

 |

Return value
 |

Type

 |

Description

 |
 |

string

 |

Return the result of the executed function.

 |

## Example

```
string lotID = PROB_HND_CALL("ph_exec_gpib_cmd LOTNAME?")
PROB_HND_CALL("ph_exec_gpib_cmd SOUNDOFF");
```

## Functional changes

- Introduced in SmarTest 7.2.3
