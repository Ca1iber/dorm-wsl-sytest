SmartRDI provides some functions to enable and disable SmartCalc (SMC) and to modify the SMC related behavior.

## Enabling and disabling SMC

SmartRDI lets user choose whether to use the SmartCalc (SMC) framework for hidden upload.

By default, SMC is enabled in SmartRDI for pattern‑based tests including functional test and digital capture test. That is to say, during pattern execution the SMC mode is always active for results uploading unless user explicitly disabled this feature using function [rdi.disableSmcExec()](<02.07.13.08.19.02.01_rdi.disableSmcExec.md>) or using keywords [DISABLE_SMC_EXEC_GLOBAL](<02.07.13.04_RDI_Configure_file.md#_146692__row_DISABLE_SMC_EXEC_GLOBAL>) or [DISABLE_SMC_SHORT_BURST](<02.07.13.04_RDI_Configure_file.md#_146692__row_DISABLE_SMC_SHORT_BURST>) in the [RDI_Configure file](<02.07.13.04_RDI_Configure_file.md>).

## Hidden upload

The hidden upload must be enabled or disabled by function [rdi.hiddenUpload()](<02.07.13.08.19.02.03_rdi.hiddenUpload.md>). This function defines also the type of measurement for which the results are to be uploaded in a background process.

## Definition of the site in a common thread

For a [Common thread](<02.07.13.08.19_Using_SmartCalc__SMC__with_SmartRDI.md#_149335__dle_Common_thread>), the [rdi.site()](<02.07.13.08.19.02.04_rdi.site.md>) API allows you setting the site to be processed in the [SMC_backgroundProcessing()](<02.07.04.01.231.01_SMC_ARM.md#_120107__s_SMC_backgroundProcessing>) function.
