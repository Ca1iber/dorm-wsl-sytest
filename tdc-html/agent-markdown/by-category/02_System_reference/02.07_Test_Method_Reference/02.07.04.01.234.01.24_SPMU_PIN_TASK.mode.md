# SPMU_PIN_TASK.mode()

Sets the measurement mode, like fore current measure voltage or force voltage measure current and connects the BADC or PPMU if required.

A resource conflict error will be issued in case multiple pin PMUs are connected to the BADC.

Note Although Board ADC measurements can be done with this function, it is recommend using the [FLEX_RELAY](<02.07.04.01.68_FLEX_RELAY.md>) class instead.

## Syntax

```
SPMU_PIN_TASK& mode(const STRING& mode);
```

Parameter
 | Parameter  | Description |
 | mode  | Default mode is "IFVM".

Refer to the list of available options of the mode parameter below.

 |

Available options of parameter: mode
 | mode  | Description |
 | "IFVM" |

Force current and measure voltage.

This mode is set so that voltage is forced and the required current is defined via symmetrical set current clamp values. Therefore, you must observe the minimum clamp current distance for setting the forced current in the "IFVM" mode.

AVI64 and FVI16 support the real current forcing modes ["CFVM" and "CFIM"](<02.07.04.01.234.01.24_SPMU_PIN_TASK.mode.md#_131275__r_AVI64_FVI16>) in which the minimum clamp distance does not have to be observed.

 |
 | "VFIM"  | Force voltage and measure current. |
 | "VM_HIZ"  | High impedance voltage measurement. |
 | "VM_HIZ_HAC"  | High impedance voltage measure with high accuracy. The voltage range is selected via [SPMU_PIN_TASK.min()](<02.07.04.01.234.01.23_SPMU_PIN_TASK.min.md>) and [SPMU_PIN_TASK.max()](<02.07.04.01.234.01.21_SPMU_PIN_TASK.max.md>). |
 | "IFVM_UNGANGED"  | Force current and measure voltage by temporarily separating ganged channels for this measurement.

The ganged channels are temporarily unganged to the minimum number of channels that is required to force the programmed current. The voltage measurement is always performed on the first channel of the ganged group. Temporarily unganging for voltage measurements will improve the stability of the forced current and therefore improve the stability of the voltage measurement.

 |
 | "VFIM_UNGANGED"  | Force voltage and measure current by temporarily separating ganged channels for this measurement.

See also [Number of channels in unganged mode](<02.07.04.01.234.01.24_SPMU_PIN_TASK.mode.md#_131275__s_Number_of_channels_unganged>) below.

Note that on DPS128/64 and XPS256 you cannot execute a current compare on a ganged group of channels in unganged mode. Already activated comparators are silently disabled in unganged mode. A user notification (Error or warning) is omitted in this case, to avoid any interrupt in the testflow. The previous state of the comparators is automatically restored after the ganged group has been restored.

 |
 | "PPMU_BADC" |

Connects the board ADC (BADC) with the pin PMU (PPMU) for static measurements.

Mapped to "IFVM" for DC Scale cards without a separate board ADC.

 |
 | The following measurement modes are supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>). |
 | "VFVM"  | Force voltage and measure voltage. |
 | "CFVM" |

Force current directly and measure voltage or current.

Both the lower and the upper clamp must be set by function [SPMU_PIN_TASK.clamp()](<02.07.04.01.234.01.01_SPMU_PIN_TASK.clamp.md>) if these modes are selected.

 |
 | "CFIM"  | Note If the [SPMU_PIN_TASK.iForce()](<02.07.04.01.234.01.14_SPMU_PIN_TASK.iForce.md>) or [SPMU_PIN_TASK.vForce()](<02.07.04.01.234.01.34_SPMU_PIN_TASK.vForce.md>) is used, the corresponding mode("IFVM" or "VFIM") is set automatically.

## Return value

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.

## Number of channels in unganged mode

When using "VFIM_UNGANGED", the values assigned for the [max()](<02.07.04.01.234.01.21_SPMU_PIN_TASK.max.md>), [min()](<02.07.04.01.234.01.23_SPMU_PIN_TASK.min.md>) or [limits()](<02.07.04.01.234.01.18_SPMU_PIN_TASK.limits.md>) pass/fail limits determine the measurement range. The values also define the number of channels to be temporary unganged respectively remaining in case of an unganged current measurement.

The following rule is applied:

- No. of remaining ganged channels = CEIL [ P/F limit / (ilimitPerChannel ]

The ilimitPerChannel is to be calculated as follows:

- ilimitPerChannel = (programmedIlimit / totalNumberOfGangedChannels) - clampError
with

- programmedIlimit = Current limit specified in A in [SPMU_PIN_TASK.clamp()](<02.07.04.01.234.01.01_SPMU_PIN_TASK.clamp.md>)
- totalNumberOfGangedChannels = Original number of ganged channels as defined in the pins editor
- clampError = Maximum error, defined in the current clamp specification of the used DPS

The current limit per channel is defined by the programmed current limit and the total number of ganged channels. For calculating the number of remaining ganged channels, the current limit per channel is lowered by the maximum specified error for the selected range. This will ensure that the requested current can flow in temporary unganged mode.

Note We recommend always, verifying current measurements in temporarily unganged mode carefully. Automatic unganging of channels may result in current measurements directly at the range boundaries or close to the programmed clamp current.

## Example

In the example below "VM_HIZ" selects the Board ADC for a voltage measurement.

```
SPMU_TASK badc_task;

ON_FIRST_INVOCATION_BEGIN();
 badc_task.pin("pinName").mode("VM_HIZ");
 badc_task.pin("pinName").settling(1 ms).samples(1);
 badc_task.pin("pinName").relay("TERM");
 badc_task.pin("pinName").min(0 V).max(5 V);
 badc_task.preAction("NONE").execMode("PVAL").execute();
ON_FIRST_INVOCATION_END();

cout << badc_task.getValue("pinName") << endl;
```
