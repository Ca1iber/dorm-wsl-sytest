# getValue()

Retrieves the measured value.

## Syntax

```
double getValue(const string& sPin);
double getValue();
```

List of parameters
 |

Parameter

 |

Description

 |
 |

sPin

 |

The pin to query.

 |

## Example

```
double val=rdi.id("iRange_1").getValue("pinA");
```
