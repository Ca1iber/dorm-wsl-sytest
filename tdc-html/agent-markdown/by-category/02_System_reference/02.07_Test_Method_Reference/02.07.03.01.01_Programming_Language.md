# Programming Language

You can use the C++ programming language for writing your test method programs. The SmarTest software is delivered with an gC++ compiler. which provides you with a powerful debugging tool.

This manual does not explain how to use the C++ programming language. Refer to the standard textbooks on C++ programming.
