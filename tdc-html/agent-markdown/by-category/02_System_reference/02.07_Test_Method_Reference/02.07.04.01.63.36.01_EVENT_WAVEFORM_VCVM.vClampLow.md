# EVENT_WAVEFORM_VCVM.vClampLow()

Sets the lower clamp voltage waveform as [ANALOG_WAVEFORM](<02.07.04.01.05_ANALOG_WAVEFORM.md>).

Only one of the two clamp waveforms can be set per DC event. The lower clamp voltage waveform, defined by this member function, and the upper clamp voltage, defined by [EVENT_WAVEFORM_VCVM.vClampHigh()](<02.07.04.01.63.36.03_EVENT_WAVEFORM_VCVM.vClampHigh.md>), must be set in separate DC events.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_WAVEFORM_VCVM & vClampLow(ANALOG_WAVEFORM & waveform);
```

Parameter
 | Parameter  | Description |
 | waveform |

Defines the waveform to be set in V (Volt).

 |

## Return value

A reference to the corresponding [EVENT_WAVEFORM_VCVM](<02.07.04.01.63.36_EVENT_WAVEFORM_VCVM.md>) object.
