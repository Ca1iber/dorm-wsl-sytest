# GET_USER_FLAG_NAMES

This API retrieves the names of all the user-defined user flags and stores them in the parameter.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/TestControl.h.

## Syntax

```
void GET_USER_FLAG_NAMES(STRING_VECTOR &allnames);
```

Parameter
 |

allnames

 |

The names of all the user-defined user flags.

 |

## Example

```
STRING_VECTOR userFlag;
int varSize;
GET_USER_FLAG_NAMES(userFlag);
varSize =  userFlag.size();
for(int i=0;i<varSize;i++)
{
  cout << userFlag[i] <<endl;
}
```

## Functional changes

- Introduced in SmarTest 7.1.3
