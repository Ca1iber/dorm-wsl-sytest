# labelName()

Specifies the name of the generated label. By default, SmartRDI will assign a label name based on the content.

## Syntax

```
labelName(const string &name);
labelName(const string &name, TA::MD5_OPTION);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

name

 |

User specified name for the label.

 |
 |

TA::MD5_OPTION

 |

The option which defines to use an MD5 postfix string or not.

 |

List of available options of parameter: <TA::MD5_OPTION>
 |

Option

 |

Description

 |
 |

TA::MD5_ON

   | With an MD5 postfix string in the label name.

With MD5_ON, the maximum length of a valid "targetLabelName" in the generated pattern name is 74.

 |
 |

TA::MD5_OFF

 |

Without an MD5 postfix string in the label name. This is the default value.

With MD5_OFF, the maximum length of a valid "targetLabelName" in the generated pattern name is 111.

 |

## Example

```
RDI_BEGIN();
rdi.smartVec().pin("DATA1,DATA3").writeData(0x54,8,2).readData(8,20).labelName("label_name").execute();
RDI_END();
```

Note If a label with the same name exists, the pattern will not be re-generated. So make sure that the label name will change if the content changes.
