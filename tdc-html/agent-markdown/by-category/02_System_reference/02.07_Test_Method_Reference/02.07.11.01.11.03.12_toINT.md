# toINT()

#### Subtopics

- [toSCS()](<02.07.11.01.11.03.12.01_toSCS.md>)

Calculates the value of a state character sequence and returns it as an integer value.

Valid state characters are 0/1 and L/H. Mixing of 0/1 with L/H is not supported.

Errors will be issued if,

- an invalid state character is in the sequence or
- in case of inconsistency (mixing of state characters).

## Syntax

```
number := toINT( sequence )
```

Parameter
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

sequence

 |

 |

## Example

`toINT("001")` results in `1`.

`toINT("HLLH")` results in `9`.

`toINT ("")` results in `0`.

`toINT("00Z0")` results in "ERROR: invalid state character "Z"."

`toINT("1H0L)` results in "ERROR: inconsistent coding."
