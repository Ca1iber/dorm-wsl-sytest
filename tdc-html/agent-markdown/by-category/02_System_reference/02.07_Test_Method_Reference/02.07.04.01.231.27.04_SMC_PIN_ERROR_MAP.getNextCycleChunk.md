# SMC_PIN_ERROR_MAP.getNextCycleChunk()

Uploads error map edge results. These results are stored as [CYCLE_CHUNK](<02.07.04.02.08_CYCLE_CHUNK.md>) data structures.

## Syntax

```
bool getNextCycleChunk(CYCLE_CHUNK& cycleChunk);
```

Parameter
 |

Parameter

 |

Description

 |
 |

cycleChunk

 |

A structure containing cycle information (edge results).

 |

## Return value

True: when cycle chunk is successfully uploaded. False: when there is no additional data to upload.
