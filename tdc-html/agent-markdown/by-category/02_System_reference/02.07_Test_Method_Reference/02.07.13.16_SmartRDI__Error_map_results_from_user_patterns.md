The emap() class provides failing information in user patterns.

 The `emap()` class provides the following functions:

Overview of emap() class functions
 | Function  | Description  | Mode |
 | [combinedFailCount()](<02.07.13.16.01_combinedFailCount.md>)  | Return the total fail counts of many pins in one pattern label.  | P |
 | [emapLocation()](<02.07.13.16.02_emapLocation.md>)  | Specify a location where error maps are stored.  | |
 | [failCount()](<02.07.13.16.03_failCount.md>)  | Return the number of failed cycles within a specified cycle range.  | P |
 | [failCyc()](<02.07.13.16.04_failCyc.md>)  | Return all failed cycles' positions within a specified cycle range.  | P |
 | [FFC()](<02.07.13.16.05_FFC.md>)  | Return the number of the first failing cycle from a specified cycle range.  | P |
 | [FFV()](<02.07.13.16.06_FFV.md>)  | Specify a cycle number, starting from which the cycles in range are to be checked for finding and retrieving the number of the first fail vector in pattern.  | P |
 | [label()](<02.07.13.16.07_label.md>)  | Specify a label to be executed.  | P |
 | [multiFFC()](<02.07.13.16.08_multiFFC.md>)  | Specify a start cycle and a number of failing cycles for retrieving a limited number of failing cycles from a certain pattern cycle.  | P |
 | [pfMap()](<02.07.13.16.09_pfMap.md>)  | Return a pass/fail map for a specified cycle range.  | P |
 | [rdi.func().startVec()](<02.07.13.16.10_rdi.func__.startVec.md>)  | Specify a start vector line in a user pattern.  | P |
 | [rdi.func().stopVec()](<02.07.13.16.11_rdi.func__.stopVec.md>)  | Insert STOP in user pattern.  | P |
 | [xMode()](<02.07.13.16.12_xMode.md>)  | Set the X-mode value for the pin that gets the error map result.  | P |
 | [getFailCount()](<02.07.13.16.13_getFailCount.md>)  | Return the number of failed cycles for a specified pin.  | |
 | [getFailCyc()](<02.07.13.16.14_getFailCyc.md>)  | Return failing cycle positions.  | |
 | [getFFC()](<02.07.13.16.15_getFFC.md>)  | Return the number of the first failing cycle for a specified pin.  | |
 | [getPfMap()](<02.07.13.16.16_getPfMap.md>)  | Return a pass/fail map for a specified pin.  | |
 | [rdi.id().getCombinedFailCount()](<02.07.13.16.17_rdi.id__.getCombinedFailCount.md>)  | Retrieve the total fail counts of many pins in just one label.  | |
 | [rdi.id().getFFV()](<02.07.13.16.18_rdi.id__.getFFV.md>)  | Retrieve the number of the first fail vector in pattern for a specified pin.  | |
 | [rdi.id().getMultiFFC()](<02.07.13.16.19_rdi.id__.getMultiFFC.md>)  | Retrieve the number of failing cycles specified by multiFCC().  | |

You can use them to retrieve:

- Fail count
- Fail cycle position
- Pass/fail map
- First failing cycle position
  Note

- The fail count and fail position are about "compare edge" (not tester cycle). So they supports xMode directly.
- The xMode parameter for a pin must be correct, otherwise the result for the pin will not be correct.
- The parameter specified in the functions, such as startCyc and cycRange, is about user cycles (edge), not tester cycles. This setting is critical when xMode is set to be greater than 1.
- For one pin, the xMode must remain the same in different labels in burst; otherwise the results might be wrong.

To improve performance, SmartRDI uses [SMC_PIN_ERROR_MAP](<02.07.04.01.231.27_SMC_PIN_ERROR_MAP.md>) to upload the error map result.

## Example

This diagram shows an error map example.

 ![emap result](<../../../../raw/149581.png>)

In this example, results are:

- `failCount`= 3
- `failCyc`= 10, 14, 17
- `pfMap`= 1,1,1,1,0,1,1,1,0,1,1,0,1
- `FFC`= 10

The cycle number starts from "0".

The following example includes all functions of the emap() class:

```
ON_FIRST_INVOCATION_BEGIN();
rdi.emapLocation(TA::RAM);
RDI_BEGIN();
   rdi.emap("a").label("label1").pin("pA").failCount().pfMap()
                                .pin("pC").failCyc(5).execute();
   rdi.emap("b").label("label2").pin("pB").FFC(150).execute();
RDI_END();
ON_FIRST_INVOCATION_END();

int fcount=rdi.id("a").getFailCount("pA");
ARRAY_BOOL map=rdi.id("a").getPfMap("pA");
ARRAY_LL fcPostion=rdi.id("a").getFailCyc("pC");
int ffc=rdi.id("b").getFFC();
```
