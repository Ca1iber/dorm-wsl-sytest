# EVENT_ICVM.limits()

Sets voltage limits to compare against thresholds.

## Syntax

```
EVENT_ICVM & limits (const LIMIT & limits);
```

Parameter
 | Parameter  | Description |
 | limits |

Voltage limits of the specified LIMIT object

 |

## Return value

A reference to the corresponding [EVENT_ICVM](<02.07.04.01.63.11_EVENT_ICVM.md>) object.

## Example

For an example see [EVENT_ICVM](<02.07.04.01.63.11_EVENT_ICVM.md>).
