# Condition

The '? :' operator evaluates its condition and returns the first of its operands, if the result is true, else it returns its second operand.

It has the same semantics as within the C programming language.

The parameters themselves can be any complex expression referring to parameters or other fields.

An error is issued if a parameters is not of boolean type.

## Syntax

sequence := boolean ? sequence1 : sequence2

## Example

The following example will return "`XXX`" if the bits in `data[0..2]` are equal to "`LLL`", else it will return the value of `data[0..2]`:

(data[0..2] == "LLL") ? "XXX" : data[0..2]

The following example will return the value of `@field` if the length of `@field` is less than `10 ` bits, else it will return "`X`":

(length(@field) < 10) ? @field : "X"

## Functional changes

- Introduced in SmarTest 7.1.0
