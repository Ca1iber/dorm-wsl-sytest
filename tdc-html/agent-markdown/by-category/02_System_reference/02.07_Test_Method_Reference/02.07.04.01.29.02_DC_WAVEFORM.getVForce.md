# DC_WAVEFORM.getVForce()

This function copies the DC waveform into an ARRAY_D.

## Syntax

```
void getVForce (ARRAY_D & waveform) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

waveform

 |

The parameter stores the values of the DC waveform.

 |

Return value

There is no return value.
