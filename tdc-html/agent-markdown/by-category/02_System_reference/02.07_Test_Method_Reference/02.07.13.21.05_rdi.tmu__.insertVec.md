# rdi.tmu().insertVec()

Creates TMU events in specified pattern.

## Syntax

```
tmuBase& insertVec(int iVecNum);
```

Parameter
 | Parameter  | Description |
 | iVecNum  | The line number of the vector where you want to insert the TMU event.  | Note The correct sequence of [rdi.tmu().label()](<02.07.13.21.07_rdi.tmu__.label.md>) and .insertVec() must be strictly followed within the rdi ... execute() block if you want to insert TMU events into an already existing pattern.

## Return Value

A reference to the tmuBase object.

## Example

```
RDI_BEGIN();

    rdi.tmu("id_1").label("func_1").pin("PVI8_PMU_1")
        .insertVec(100).vth(3.0 V, 5.0 V)
        .insertVec(500).samples(4).measMode(TA::PULSE_HIGH)
       .dataRate(25 MHz)
       .execute();

    rdi.wait(1 ms);

    rdi.tmu("id_2").label("func_2").pin("PS1600_1")
        .insertVec(280)
        .vth(3.0 V)
        .samples(4)
        .measMode(TA::RISE)
        .dataRate(25 MHz)
        .execute();

    rdi.wait(1 ms);

RDI_END();

RDI_BEGIN();

    rdi.tmu("id").label("func")
        .pin("PVI8_PMU_1")
            .insertVec(100).vth(3.0 V, 5.0 V)
            .insertVec(500).samples(4).measMode(TA::PULSE_HIGH)
            .dataRate(25 MHz)
        .pin("PS1600")
            .insertVec(200)
            .vth(1.5 V)
            .samples(2)
            .measMode(TA::RISE_FALL)
            .execute();

    rdi.wait(1 ms);

RDI_END();
```
