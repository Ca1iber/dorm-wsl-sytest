# FFC()

Captures the first failing cycle (FFC) starting from a specified cycle.

This function is used together with [getFFC()](<02.07.13.24.45_getFFC.md>) to retrieve the result.

The smartVec() class does not support the [pfMap()](<02.07.13.16.09_pfMap.md>) function, use [readBit()](<02.07.13.24.28_readBit.md>) instead to return equivalent results.

## Syntax

```
FFC(int startCyc);
FFC();
```

List of parameters
 |

Parameter

 |

Description

 |
 |

startCyc

 |

The number of the first cycle in a cycle range in which fails are counted.

An integer. Cycle counting starts from zero.

This is an optional parameter. If it is omitted, the cycle range starts with the first cycle.

 |

Return value

There is no return value.

  Note

- The fail count and fail position are about "compare edge" (not tester cycle). So they supports xMode directly.
- The xMode parameter for a pin must be correct, otherwise the result for the pin will not be correct.
- The parameter specified in the function, such as startCyc and cycRange, is about user cycles (edge), not tester cycles. This setting is critical when xMode is set to be greater than 1.
- For one pin, xMode must remain the same in different labels in burst; otherwise the results might be wrong.
