# DPS_VFIM

The DPS_VFIM API accesses a data container for creating, executing a DC set for current measurement with DPS, and retrieving the test results. DC set is a set of measurement conditions for DC measurement.

 Note It is recommended to use [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) instead of DPS_VFIM API, as [DPS_TASK](<02.07.04.01.50_DPS_TASK.md>) provides shorter test time.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Dps.h.

DPS_VFIM supports the following DPS instruments/boards: DPS128-HC/DPS64-HC and UHC4T.

## Class definition

```
DPS_VFIM(STRING pinlist);
```

### Member Functions

```
DPS_VFIM& preAction(STRING preAct = "NONE");

```

### Constructor

```
DPS_VFIM(STRING pinlist);
```

This constructor defines a DC set which is a set of measurement conditions for V-force I-measure test with DPS.

You cannot create a class object explicitly with a user-defined name.

Parameters
 |

pinlist

 |

DPS pin name to be used for the measurement. You can specify multiple pins by separating with a comma or using "@" which means the all DPS pins. The DPS_VFIM API can perform only serial measurement for multiple pins.

 |

## Member functions

### preAction()

```
DPS_VFIM& preAction(STRING preAct = "NONE");
```

This member function sets the action to be performed prior to the DC measurement.

Parameters
 |

preAct

 |

Action type to be performed prior to the DC measurement. The following types are available.

 |
 |

 |

"NONE"

 |

(Default) This option defines no pre-action. However, this option activates digital primaries specified on the Testsuite dialog prior to the DC measurement. To activate the primaries specified with the PRIMARY_STATUS API or primary analog set, put the FLUSH API prior to this statement.

 |
 |

 |

"FTST"

 |

Performs a functional test prior to the DC measurement with activating the digital primaries specified in the Testsuite dialog. This option is used to perform a DC measurement with applying a break vector defined in the primaries. To activate the primaries specified with the PRIMARY_STATUS API or primary analog set, put the FLUSH API prior to this statement.

 |
 |

 |

"NPRM"

 |

This option defines no pre-action. Also, the primaries are not activated before the DC test.

 |

### min_current()

```
DPS_VFIM& min_current(DOUBLE min);
```

This member function sets the lower limit current for pass/fail judgment. Lower and upper limits must be set by using this member function or the limits member function.

Parameter
 |

min

 |

Lower limit current in [A]

 |

### max_current()

```
DPS_VFIM& max_current(DOUBLE max);
```

This member function sets the upper limit current for pass/fail judgment. Lower and upper limits must be set by using this member function or the limits member function.

Parameter
 |

max

 |

Upper limit current in [A]

 |

### limits()

```
DPS_VFIM& limits(STRING testname);
DPS_VFIM& limits(LIMIT limit);
```

This member function sets the lower and upper limit values using a test name or using a class object of the LIMIT API. Limit current for pass/fail judgment must be set by using this member function or the min_current and max_current member function.

Parameter
 |

testname

 |

Test name that can be referred from Properties view.

 |
 |

limit

 |

Class object name of the LIMIT API.

 |

### execute()

```
void execute(TM::DCTEST_MODE mode = TM::GPF);
```

This member function downloads the DC set to the hardware and executes the DC test. At the end of the test, continues the output and keeps the connection.

Parameter
 |

mode

 |

Test mode to be selected from the following items:

TM::GPF - Executes a Global Pass/Fail test which records a judgment of all pins. The result can be retrieved with the getPassFail() member function.

TM::PPF - Executes Per pin Pass/Fail tests which record judgments per pin. The results can be retrieved with the getPassFail(pin) member function.

TM::PVAL - Executes Per pin Value tests which records measured values per pin. The results can be retrieved with the getValue() member function.

TM::DCTEST_AUTO - Executes the DC test according to the test suite flags.

If the flag Pass value or Fail value is on, the DC test will executes in the same way as the mode TM::PVAL.

If the flag Pass value and Fail value are off and the flag Per pin on pass or Per pin on fail is on, the DC test will executes in the same way as the mode TM::PPF.

If the flag Pass value and Fail value are off and the flag Per pin on pass and Per pin on fail are off, the DC test will executes in the same way as the mode TM::GPF.

 |

### getMin()

```
DOUBLE getMin() const;
```

This member function returns the current setting value of the lower limit current for pass/fail in [A]. The lower limit is set with the min_current or limit member function.

There are no parameters in this member function.

### getMax()

```
DOUBLE getMax() const;
```

This member function returns the current setting value of the upper limit current for pass/fail in [A]. The lower limit is set with the max_current or limit member function.

There are no parameters in this member function.

### getPassFail()

```
Boolean getPassFail();
Boolean getPassFail(STRING pin);
```

This member function returns a Pass/Fail judgment for the all pins or specified pin.

Parameters

 |

pin

 |

Pin name whose Pass/Fail judgment will be retrieved. If this parameter is not set, this member function returns TRUE if the all pins are passed, or FALSE if any of pins are failed.

 |

Return Value

Returns a Boolean true for pass or false for fail result of the measurement.

### getValue()

```
DOUBLE getValue(STRING pin);
```

This member function returns a measurement value for the specified pin.

Parameter
 |

pin

 |

Pin name to retrieve the measurement value.

 |

## Examples

### Global pass/fail measurement

```
 :
DPS_VFIM dps("Vcc, Vss");
dps.limits("limit1").execute();
TEST(dps);
 :
```

The DPS_VFIM API defines DPS pins Vcc and Vss to be used for measurement, and the limits member function specifies limits by using the class object name of the LIMIT API, and the execute member function starts the measurement with two DPSs sequentially. Then the TEST API gets the global pass/fail judgment of this measurement.

### Per pin pass/fail measurement

```
:
Boolean rslt1, rsrl2;
DPS_VFIM("Vcc,Vss").min_current(0.10).
max_current(0.30);
DPS_VFIM("Vcc,Vss").execute(TM::PPF);
rslt1 = DPS_VFIM("Vcc").getPassFail("Vcc");
rslt1 = DPS_VFIM("Vss").getPassFail("Vss");
 :
```

The DPS_VFIM API defines DPS pins Vcc and Vss to be used for measurement, and the member functions set the lower limit and upper limit. Then the execute member function starts the measurement on per pin pass/fail mode with two DPSs sequentially. Then the getPassFail member function gets the per pin pass/fail judgment for Vcc and Vss.

### Value measurement

```
 :
DOUBLE rslt1, rslt2;
DPS_VFIM("Vcc, Vss").limits("limit1");
DPS_VFIM("Vcc, Vss").execute(TM::PVAL);
rslt1 = DPS_VFIM("Vcc, Vss").getValue("Vcc");
rslt2 = DPS_VFIM("Vcc,Vss").getValue("Vss");
 :
```

The DPS_VFIM API defines DPS pins Vcc and Vss to be used for measurement, and limits member function specifies limits by using the class object name of the LIMIT API. Then the execute member function starts the measurement on per pin value test mode with two DPSs sequentially. Then the getValue member function gets the per pin measurement value for Vcc and Vss.
