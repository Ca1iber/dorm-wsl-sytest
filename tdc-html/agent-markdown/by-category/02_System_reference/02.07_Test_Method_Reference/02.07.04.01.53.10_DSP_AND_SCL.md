# DSP_AND_SCL

This API performs a bit-wise logical AND between a scalar value and each element of a specified array.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_AND_SCL(INT scalar, ARRAY_I& src,
            ARRAY_I& result);
DSP_AND_SCL(INT scalar, INT *src, INT *result,
            INT size);
```

## Example

```
int array1[10], result[3];
  .
  .
DSP_AND_SCL(4, array1, result, 3);
```

If array1 elements and variable are as follows:

```
array1[0] = 7 = 0 ... 0111
array1[1] = 5 = 0 ... 0101
array1[2] = 3 = 0 ... 0011
```

and so on

```
scalar    = 4 = 0 ... 0100
```

then, the ANDed results returned to result are as follows:

```
result[0] = 4 = 0 ... 0100
result[1] = 4 = 0 ... 0100
result[2] = 0 = 0 ... 0000
```

Only the first three elements of array1 are processed and returned to result. The remaining elements in result are not changed.
