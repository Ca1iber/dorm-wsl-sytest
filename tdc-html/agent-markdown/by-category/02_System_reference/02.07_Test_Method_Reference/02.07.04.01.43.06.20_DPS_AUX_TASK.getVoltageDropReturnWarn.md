# DPS_AUX_TASK.getVoltageDropReturnWarn()

The member function retrieves the "Voltage drop return warning" accumulated power supply status flag from the test method cache.

Refer to [DPS power flags - get...() functions](<02.07.04.01.43.06_DPS_power_flags_-_get...___functions.md>) for more information regarding the supported flags and the meaning of the flags.

The [DPS_AUX_PIN_TASK.checkPowerFlags()](<02.07.04.01.43.01.02_DPS_AUX_PIN_TASK.checkPowerFlags.md>) member function must be called upfront for reading the flags from the hardware into the test method cache.

This member function must be called outside of the ON_FIRST_INVOCATION_BEGIN() ... ON_FIRST_INVOCATION_END() block or within a FOR_EACH_SITE_BEGIN() ... FOR_EACH_SITE_END() block.

## Syntax

```
TM::DPS_POWER_FLAG_STATUS getVoltageDropReturnWarn(const STRING& pin);
```

Parameter
 | Parameter  | Description/Range |
 | pin  | Single pin for which the status flags should be retrieved. |

## Return value

The member function returns one of the following values of the enumerated type DPS_POWER_FLAG_STATUS:

 | Keyword  | Value  | State of the checked flags |
 | TM::POWER_FLAG_STATUS_PASS  | 0  | The checked flag is not set. |
 | TM::POWER_FLAG_STATUS_FAIL  | 1  | The checked flag is set. |
