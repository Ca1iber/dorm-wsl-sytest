# SPMU_PIN_TASK.currentClampTimeToDisconnect()

Specifies the delay time before disconnect, after the clamp current is reached.

This member function is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

## Syntax

```
SPMU_PIN_TASK & currentClampTimeToDisconnect(DOUBLE currClampTimeToDisconnect);
```

 Parameter

 | Parameter  | Description |
 | currClampTimeToDisconnect |

The delay time in milliseconds (ms) to be set.

   |   Return value A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.

## Functional changes

- Introduced in SmarTest 7.10.1
