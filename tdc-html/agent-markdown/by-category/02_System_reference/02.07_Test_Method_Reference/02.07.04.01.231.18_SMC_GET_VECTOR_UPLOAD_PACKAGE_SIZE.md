# SMC_GET_VECTOR_UPLOAD_PACKAGE_SIZE()

Returns the size of the current package for the vector upload in bytes.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```
INT SMC_GET_VECTOR_UPLOAD_PACKAGE_SIZE();
```

List of parameters

There are no parameters.

## Return value

Returns the size of the current package for the vector upload in bytes.

## Example

The following example shows how a the upload size can be set to 512kb.

```
INT upld_size = SMC_GET_VECTOR_UPLOAD_PACKAGE_SIZE();
```

## Functional changes

- Introduced in SmarTest 6.5.3
