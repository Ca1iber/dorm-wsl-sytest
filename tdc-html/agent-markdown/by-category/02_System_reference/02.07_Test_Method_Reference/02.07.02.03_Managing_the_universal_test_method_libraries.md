If your test method libraries are bug free and ready to use, you can share it with other users of the same SmarTest system. See [How to install a universal test method library for system wide usage](<02.07.02.03.01_How_to_install_a_universal_test_method_library_for_system_wide_usage.md>).

If you have some test method libraries located under different directories, you can use them for one device testing by setting the system environment variable 93000_TM_LIBRARY_PATH. See [How to use universal test method libraries under multiple directories](<02.07.02.03.02_How_to_use_universal_test_method_libraries_under_multiple_directories.md>).
