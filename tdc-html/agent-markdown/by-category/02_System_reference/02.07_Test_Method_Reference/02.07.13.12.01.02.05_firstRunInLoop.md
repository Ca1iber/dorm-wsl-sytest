# firstRunInLoop()

This function controls the running of PPMU or BADC pattern setups and relays to be run only within the first iteration of loops. For the remaining loop iterations, the test program invokes the first run result labels directly and will not run the pattern setups again.

This function works together with the TestMethod class. You must set the initialize() of the TestMethod class to be true at the beginning of your code. firstRunInLoop() checks the flag and control the execution of PPMU or BADC setups in the first run.

  Note This function is not required if the SmartRDI version is higher or equal to 2.5.0 while the SmarTest version is higher or equal to 7.4.2.1.

## Syntax

```
firstRunInLoop(bool)
```

## Example

```
class User_TM_Class: public testmethod::TestMethod {
protected:
bool firstRun;
// This test method is called just once after a testsuite has been created.
virtual void initialize()
{
firstRun=true;
}
// Add your initialization code here.
virtual void run()
{
   RDI_INIT();
   rdi.firstRunInLoop(firstRun);
   RDI_BEGIN();
     rdi.dc().pin("A").vForce(1 V).iMeas().execute();
   RDI_END()
   ...
}
```

## Functional changes

- Introduced in SmartRDI 2.4.1
