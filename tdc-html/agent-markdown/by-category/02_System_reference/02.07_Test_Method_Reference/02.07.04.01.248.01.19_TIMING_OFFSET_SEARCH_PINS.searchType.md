# TIMING_OFFSET_SEARCH_PINS.searchType()

This function sets the search type for the timing offset search. The search type decides which detail result value (left boundary, right boundary or the eye center` ((right-left)/2)` of the eye) is stored as offset value. (See the `restoreFlag()` function below for the usage of offset value.)

## Syntax

```
TIMING_OFFSET_SEARCH_PINS& searchType(TIMING_OFFSET_SEARCH::SEARCH_TYPE stype);
```

Parameter
 |

stype

 |

The search type. It can be:

- TIMING_OFFSET_SEARCH::EYE: returns the largest pass area of an eye.
- TIMING_OFFSET_SEARCH::LB: returns the Fail/Pass transition on the left side.
- TIMING_OFFSET_SEARCH::RB: returns the Pass/Fail transition on the right side.
 |

## Functional changes

- Introduced in SmarTest 7.0.1
