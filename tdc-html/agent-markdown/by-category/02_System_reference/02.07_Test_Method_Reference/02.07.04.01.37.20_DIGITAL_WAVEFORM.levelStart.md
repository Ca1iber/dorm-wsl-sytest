# DIGITAL_WAVEFORM.levelStart()

This function specifies the start offset for the level search. The default value is 0.

## Syntax

```
DIGITAL_WAVEFORM& levelStart(INT level_offset)
```

Parameter
 |

level_offset

 |

The start offset level. This is a relative value.

For STD mode: Actual voltage = vol + level_offset * levelResolution

For FAST mode: Actual voltage = vth+ level_offset * levelResolution

 |
