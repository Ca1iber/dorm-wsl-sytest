# EVENT_RANGE_CF

#### Subtopics

- [EVENT_RANGE_CF.iRange()](<02.07.04.01.63.13.01_EVENT_RANGE_CF.iRange.md>)
- [EVENT_RANGE_CF.getIRange()](<02.07.04.01.63.13.02_EVENT_RANGE_CF.getIRange.md>)

The EVENT_RANGE_CF class provides the functionality to change the force current range in pattern鈥慴ased PMU measurements.

This class is supported only for the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) in PMU operating mode.

## Class definition

The class derives from the [EVENT_BASE](<02.07.04.01.63.01_EVENT_BASE.md>) class.

The object that is created by this class has to be assigned to the [PATTERN_CONTROLLER](<02.07.04.01.142_PATTERN_CONTROLLER.md>) which is responsible for further handling.

This class is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Example

The following example creates a new DC event, sets the data of the DC event and inserts the DC event into an already existing pattern. The programmed data are then read back from the event object and shown in the console window.

```
PATTERN_CONTROLLER patController;

ON_FIRST_INVOCATION_BEGIN();
{
    //
    // Create a new event object
    //
    EVENT_RANGE_CF eventRange_CF ("Range_CF");

    //
    // Set the event data
    //
    eventRange_CF.iRange (-10.0 mA, 30.0 mA);

    //
    // Insert the event into a pattern
    //
    PATTERN & pattern = patController.label("...", "@");

    pattern.vecEvents("pin1").clearAll();

    pattern.vecEvents("pin1")
        .insert(100, eventRange_CF)
        .setup ();

    //
    // Read data from the event object
    //
    EVENT_VALUE_DOUBLE minCurrent, maxCurrent;

    eventRange_CF.getIRange(minCurrent, maxCurrent);

    cout << "minCurrent = " << maxCurrent << endl;
    cout << "maxCurrent = " << maxCurrent << endl;
}
ON_FIRST_INVOCATION_END();
```
