# Printing tester status from testflow

#### Subtopics

- [Controlling printing accumulated status from testflow](<02.07.03.21.02.01_Controlling_printing_accumulated_status_from_testflow.md>)

By setting up a user flag in testflow, you can have tester status automatically saved to text files when testflow execution completes.

## About this task

A user flag enableTestsuitesPreAndPostHWStateLogging controls outputs for tester status.

## Before you begin

Check that your SmarTest has a version no less than 7.5.2.

Make sure that your device works properly.

## Procedure

-  In the Test Program Explorer panel, right-click Test Program and load your test program.
-  Right-click Testflow and select Load All Setups.
-  Right-click Testflow and select Open With > Flow Data Editor.
-  Select the Variables tab.
-  Add the user flag enableTestsuitesPreAndPostHWStateLogging.

  -  In the Variables tab, right-click and select Add Variable....
  -  On the Add Variable window displayed, select USERFLAG for Type.
  -  Enter enableTestsuitesPreAndPostHWStateLogging for Name.
  -  Enter 1 for Value.

You must set value to 1, otherwise tester status output is disabled.

-  Right-click Testflow and select Open With > Flow Sequence Editor.
-  Right-click the testflow displayed in the flow sequence editor and select Run Testflow.

## Results

After testflow execution, tester status are printed to text files in the TestsuitesPreAndPostHWStateLog folder under <your device root>/waste.

For each site, a pair of pre-run and post-run hardware status logs are saved.

## Example

If you open the saved files with a text editor, the outputs look the same as what you print to System console using the Print Tester Status button. See [Printing tester status from system control](<02.07.03.21.01_Printing_tester_status_from_system_control.md>) for an example of outputs.

## What to do next

The printed tester status do not include the accumulated status. You need to explicitly set the enableAccumulatedStateLogging user flag in the testflow if you also want to print the accumulated status. See [Controlling printing accumulated status from testflow](<02.07.03.21.02.01_Controlling_printing_accumulated_status_from_testflow.md>).

See also [Printing tester status from test method](<02.07.03.21.03_Printing_tester_status_from_test_method.md>) if you need to customize your outputs.

## Functional changes

- Introduced in SmarTest 7.5.2
- SmarTest 7.5.3: The user flag "enableTestsuitesPreAndPostHWStateLogging" no more prints accumulated status. A new user flag "enableAccumulatedStateLogging" is available to provide separate control of printing accumulated status.
