# CCTPreCondition()

Specifies the test suites to be executed before retesting the current test suite.

This function is usually used in the `preStart()`, `postStart()`, `process()` and `cleanup()` function but not used in the `init()` function of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
void CCTPreCondition(const string &testSuiteNames);
```

Parameter
 |

Parameter

 |

Description

 |
 |

testSuiteNames

 |

The list of the test suites separated by comma.

 |

Return value

There is no return value.

## Example

```
CCTPreCondition("ts1, ts2");
```
