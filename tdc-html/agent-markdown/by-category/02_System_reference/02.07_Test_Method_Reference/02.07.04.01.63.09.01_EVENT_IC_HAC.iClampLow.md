# EVENT_IC_HAC.iClampLow()

Sets the low clamp current value.

You can specify either the low or the high clamp current value.

EVENT_IC_HAC functions are supported in PMU operating mode (pin type SIG) on DC Scale DPS128/64 cards only. They are not supported in DPS mode (pin type DPS+).

## Syntax

```
EVENT_IC_HAC & iClampLow  (const EVENT_VALUE_DOUBLE & value );
```

Parameter
 | Parameter  | Description |
 | value |

Low clamp current

 |

Return value

There is no return value.
