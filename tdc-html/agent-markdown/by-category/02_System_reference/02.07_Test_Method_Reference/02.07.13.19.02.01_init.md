# init()

This function specifies a value between the `start()` and `stop()` values as the start point of a binary search. See [Sequencer-controlled searching with cogo](<02.07.13.19.02_Sequencer-controlled_searching_with_cogo.md>) for more information about the relation between `start()`, `stop()` and `init()`.

If the value set by init() is not the middle of the value range defined by start() and stop(), the resolution for search on the right side differs from that on the left side.

## Syntax

```
init(double dInit)
```

List of parameters
 |

Parameter

 |

Description

 |
 |

dInit

 |

The initial value for a binary search. It has to be a value between the `start()` and `stop()` values.

Only for a binary search.

 |

## Example

```
rdi.cogo().search(TA::BINARY).pathPin("pinA").start(0).stop(4.0).init(1.0).step(3).blockBegin();
```

## Functional changes

- Introduced in SmartRDI 2.4.0
