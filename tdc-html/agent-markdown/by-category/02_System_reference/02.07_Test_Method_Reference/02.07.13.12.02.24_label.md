# label()

Specifies a name of a pattern on which dynamic DC measurements can be performed.

You can use [insertVec()](<02.07.13.12.02.21_insertVec.md>) to set a specific line in the pattern to start dynamic DC measurements.

The function can also work together with [insertSub()](<02.07.13.12.02.20_insertSub.md>) to insert subroutines, existing sublabel or DC actions to the main label or a sublabel.

The specified label must be the main label, not a burst label or subroutine.

## Syntax

```
label(const string& sLabelName);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

sLabelName

 |

The name of the pattern on which dynamic DC measurements can be performed.

 |

## Examples

### Example 1

Working together with insertVec()

```
RDI_BEGIN();
  rdi.dc("dynamic").label("label")
                   .pin("pinA")
                   .insertVec(55).vForce(5)
                   .insertVec(90).vForce(3) // here, the line number cannot be lower than 87.
                   .pin("pinB")
                   .insertVec(65). vMeas()
                   .insertVec(185).vMeas()  // here, the line number cannot be lower than 97.
                   .execute();
RDI_END();

double value = rdi.id("dynamic").getValue("pinB");        // only the last measurement result

ARRAY_D values = rdi.id("dynamic").getMultiValue("pinB"); // multiple results
```

### Example 2

Working together with insertSub()

```
RDI_BEGIN();
  ...
  rdi.dc("meas").label("abc")
                .insertSub(10).pin("pinA").vForce(0).iMeas().measWait(0.1 ms)
                .insertSub(20).pin("pinB").vForce(1 V)
                              .pin("pinC").vForce(2 V)
                .insertSub(30).pin("pinA").vForce(0).iMeas().measWait(0.2 ms)
                .execute();
  ...
RDI_END();
ARRAY_D results = rdi.id("meas").getMultiValue("pinA");
```

### Example 3

 Working together with insertSub() to insert an existing sublabel to a pattern:

```
RDI_BEGIN();
  rdi.dc().label("mainlabel")
          .insertSub(10).pin(A).vForce(1)
          .insertSub(15).label("sublabel")
          .insertSub(10,2).pin(B).vForce(2)
          .insertSub(20).pin(C).iForce(1 mA).vMeas()
          .execute();
RDI_END();
```
