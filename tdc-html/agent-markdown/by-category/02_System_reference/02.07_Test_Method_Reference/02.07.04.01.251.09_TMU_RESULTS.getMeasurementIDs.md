# TMU_RESULTS.getMeasurementIDs()

Fills a given vector with the arming IDs for which samples have been uploaded and returns the number of IDs.

## Syntax

```
UINT32 getMeasurementIDs (STRING&     pin, TMU::ApplicationType appType, std::vector<UINT32>& idvec, UINT32 site = 0);
UINT32 getMeasurementIDs (const char* pin, TMU::ApplicationType appType, std::vector<UINT32>& idvec, UINT32 site = 0);
```

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

pin

 |

The pin to query.

 |
 |

I

 |

appType

 |

The application type. It currently can only be APP_PERIOD or APP_RAW.

 |
 |

O

 |

idvec

 |

The vector that is filled with the arming IDs.

 |
 |

I

 |

site

 |

The site to query. Default is 0, which means the current site.

 |

## Return value

The number of IDs is returned.

## Functional changes

- Introduced in SmarTest 7.3.1
