# Routing Tools editors

The Routing Tools editors are the graphical user interface of the Routing Tools. Global setup data, control and configuration data for utility lines and finally the switch states to be applied can be defined in the editors.

   ![Routing Tools overview](<../../../../raw/153247.png>)

## Global Setup editor

The [Global Setup editor](<02.07.13.15.01.01_Routing_Tools_-_Global_Setup_editor.md>) of the Routing Tools enables you defining, loading and saving the XML file that contains all configuration data. In addition, the number of sites and other configuration parameters for utility lines are to be defined in this editor.

## Utility Lines Control editor

The [Utility Lines Control editor](<02.07.13.15.01.02_Routing_Tools_-_Utility_Lines_Control_editor.md>) of the Routing Tools enables you selecting static or [sequencer‑controlled utility Lines](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01_Sequencer-controlled_utility_lines.md>) and defining the digital control pins for the sequencer‑controlled utility lines.

## Utility Lines Config editor

The assignment from utility tester channels to utility pins is defined in the [Utility Lines Config editor](<02.07.13.15.01.03_Routing_Tools_-_Utility_Lines_Config_editor.md>).

## State Setup editor

The states to be applied can be defined in the [State Setup editor](<02.07.13.15.01.04_Routing_Tools_-_State_Setup_editor.md>). The user defined states hold the switch states for all utility pins and represent one of the Routing Tools main functionality.

## Debugger

The [Debugger](<02.07.13.15.01.05_Routing_Tools_-_Debugger.md>) allows you interactively loading and applying stored setups or modifying the active setup of the hardware.
