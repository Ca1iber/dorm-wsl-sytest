# failNode()

This function specifies the name of the node to go if the result of the cogo() judgment is fail.

## Syntax

```
failNode(string nodeId);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

nodeId

 |

The name of the node with which the execution continues if the cogo() judgment returns fail.

The special value RETURN returns the execution with the main label instead of jumping to another node.

 |

## Example

```
rdi.cogo().node("id1").passNode("RETURN").failNode("RETURN").begin()
```

## Functional changes

- Introduced in SmartRDI 2.4.0
