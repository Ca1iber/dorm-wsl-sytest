# repeat()

Create the whole pattern in a RPTV loop. This helps to save vector memory in some cases.

## Syntax

```
repeat(int rptNum);
repeat(int rptNum, int vecSize, int startVec); // relevant only for the Vector class
```

List of parameters
 |

Parameter

 |

Description

 |
 |

rptNum

 |

The loop / repeat number.

 |
 |

vecSize

 |

Only Vector class: Vector size. Used together with startVec to define the sector for repetition.

 |
 |

startVec

 |

Only Vector class: Start vector. Used together with vecSize to define the sector for repetition.

 |

## Examples

### Example 1

```
// Have some content repeats in pattern, for example, clock signal
RDI_BEGIN();
rdi.port("clk").smartVec().pin("CLK").writePat("0,1,1").repeat(1000).execute();
RDI_END();
// readBit()/readData() with a huge number
RDI_BEGIN();
rdi.smartVec().pin("dout").readBit(10000).execute(); // original
RDI_END();
RDI_BEGIN();
rdi.smartVec().pin("dout").readBit(1).repeat(10000).execute();
RDI_END();
```

### Example 2

```
RDI_BEGIN();
  rdi.smartVec()...repeat(5,10,2).repeat(4,5,20).execute();
  // add RPTV to 2 different segments of the pattern
RDI_END();
```

## Functional changes

- Introduced in SmartRDI 2.3.1
- SmartRDI 2.4.4: Enhanced flexibility by adding repeat(int rptNum, int vecSize, int startVec) to allow selecting a sector for repetition and adding multiple RPTV invocations into a pattern.
