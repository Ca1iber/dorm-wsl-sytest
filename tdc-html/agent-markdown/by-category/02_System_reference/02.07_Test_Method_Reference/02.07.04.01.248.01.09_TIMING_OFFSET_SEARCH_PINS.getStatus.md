# TIMING_OFFSET_SEARCH_PINS.getStatus()

This function returns the status of the last timing offset search. If you retrieve the status of multiple pins and the pins have different settings, the exception `TESTMETHOD_API::AmbiguityException` will be issued.

## Syntax

```
TIMING_OFFSET_SEARCH::STATUS_TYPE getStatus();
```

## Functional changes

- Introduced in SmarTest 7.0.1
