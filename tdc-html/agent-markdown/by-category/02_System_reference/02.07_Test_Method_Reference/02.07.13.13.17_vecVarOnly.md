# vecVarOnly()

Creates one line dummy pattern with the vector variable which contains information in parameters.

 For retrieving the result when vecVarOnly() is used, you must apply the digCap result ID in the retrieval command. See the example. The ID `"dcap"` is used in the retrieval command.

## Syntax

`vecVarOnly()`

## Example

```
RDI_BEDIN();
  rdi.digCap("dcap").vecVarOnly().pin("pinA").samples(100).execute();
  rdi.func("id2").label("label").execute();
RDI_END();

const ARRAY_I& aiData = rdi.id("dcap").getVector()
```

## Functional changes

- Introduced in SmartRDI 2.4.1
