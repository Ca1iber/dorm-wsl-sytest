# BADC_SETTING

#### Subtopics

- [BADC_PIN_SETTING](<02.07.04.01.09.01_BADC_PIN_SETTING.md>)

The BADC_SETTING class is a data container holding the contents of the task for setting up measurement conditions of BADCs. This class can be used to call the [BADC_PIN_SETTING](<02.07.04.01.09.01_BADC_PIN_SETTING.md>) class that is a subsidiary data container to set up per pin measurement conditions for the BADC.

Only dynamic measurements defined with this class, will be performed with the [PATTERN_CONTROLLER](<02.07.04.01.142_PATTERN_CONTROLLER.md>) class.

The BADC_SETTING API is required for pattern controlled high impedance (HIZ) measurements. The BADC_SETTING API is not required for a Pin PMU Value measurement with the Board ADC, where all necessary information is specified in the [PPMU_SETTING](<02.07.04.01.160_PPMU_SETTING.md>) / [PPMU_PIN_SETTING](<02.07.04.01.160.01_PPMU_PIN_SETTING.md>) APIs.

## Class definition

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/BadcSetting.h.

  Constructor

```
BADC_SETTING();
```

This constructor defines a task that is a set of measurement conditions for the min, max and limits.

  List of parameters There are no parameters. Return value The constructor has no return value.   Member functions

- [pin()](<02.07.04.01.09_BADC_SETTING.md#_126272__dle_pin>)
- [wait()](<02.07.04.01.09_BADC_SETTING.md#_126272__dle_wait>)
  Using the API

For creating an object:

`BADC_SETTING <object>;`

For setting up per pin measurement conditions:

`<object>.pin("pinlist").<member_func>;`

For setting a wait time from when the execution of the task defined with the BADC_SETTING is started:

 `object.wait(time);`

 | <object>  | Object name to be defined |
 | pinlist  | Target pin name or pin group name of this class. You can specify multiple pins and pin groups by separating with a comma or using "@" which means all pins. "@" includes the digital pins that are wired to an analog module on the DUT board for a trigger source. |
 | <member_func>  | Member functions of the BADC_PIN_SETTING class |
 | time |

Waiting time

The next task execution will be started after the wait time.

## Examples

### Example 1: Defining an object

This example defines an object that holds measurement parameters of the "p1" pin.

```
...
BADC_SETTING setting1;
setting1.pin("p1").min(50 mV).max(100 mV);
...
```

### Example 2: Pattern controlled high impedance voltage measurement with FLEX_RELAY path control

This example forces a voltage with pin PMU on pin "pin_force". This pin is cross-connected with pin "pin_meas". The "pin_meas" pin uses the high impedance (HIZ) measurement path to measure the voltage of "pin_force". The measurement path is configured with the [FLEX_RELAY](<02.07.04.01.68_FLEX_RELAY.md>) API.

```
virtual void run()
{
    DC_RESULT_ACCESSOR result;
    static STRING_VECTOR pinList;
    static string measPins = "pin_meas";

    if(firstRun)
    {
        PATTERN_CONTROLLER pc;
        FLEX_RELAY badcConnect;
        PPMU_SETTING ppmuForce;
        PPMU_RELAY ppmuOn,ppmuOff;
        BADC_SETTING badcSetting;
        BADC_MEASURE badcMeasure;

        ON_FIRST_INVOCATION_BEGIN();

            badcConnect.pin(measPins).set("DC","PMU","MUX_VM_HIZ");
            badcConnect.execute();

            ppmuForce.pin("pin_force")
                    .vForce(forceVoltage.getValueAsTargetUnit("V"))
                    .iRange(1 uA).min(0 uA).max(2 uA);
            ppmuForce.wait(1 ms);

            ppmuOn.pin("pin_force").status("PPMU_ON");
            ppmuOn.wait(1 ms);

            ppmuOff.pin("pin_force").status("AC_ON");
            ppmuOff.wait(1 ms);

            badcSetting.pin(measPins).min(0 V).max(5 V);
            badcSetting.wait(1 ms);

            badcMeasure.pin(measPins).numberOfSamples(16);
            badcMeasure.wait(100 us);

            pc.label("MeasBADC","@").add(ppmuForce)
                    .add(ppmuOn)
                    .add(badcSetting)
                    .add(badcMeasure)
                    .add(ppmuOff);

            pc.setup();

        ON_FIRST_INVOCATION_END();

        firstRun=false;
    }

    ON_FIRST_INVOCATION_BEGIN();

        FUNCTIONAL_TEST();

        result.uploadResult(measPins ,TM::RESULT_INDEX);

        pinList = PinUtility.getDigitalPinNamesFromPinList(measPins,TM::ALL_DIGITAL);

    ON_FIRST_INVOCATION_END();

    //
    // Results
    //
    int numberPins = pinList.size();

    for(int i=0; i<numberPins; i++)
    {
        ARRAY_D values      = result.getValues(pinList[i]);
        int numberOfResults = values.size();

        for (int j = 0; j< numberOfResults; j++)
        {
            double value = values[j];

            cout << "PF: " << result.getPassFail() << endl;
            cout << "NumVal: " << result.getNumberOfAvailableResults(pinList[i]) << endl;
            cout << "FailInfo: " << result.getFailInfo() << endl;
            cout << "PPMU VMHIZ BADC Measurement result: " << value << endl;
        }
    }

    return;
}
```
