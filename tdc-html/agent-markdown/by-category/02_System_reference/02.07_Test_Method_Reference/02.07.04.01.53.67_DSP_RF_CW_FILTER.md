# DSP_RF_CW_FILTER()

This function exports the raw functionality of a cw power measurement

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_RF_CW_FILTER( const ARRAY_COMPLEX& source_data,
const INT averageNum,
const INT swDecimation,
COMPLEX* result)
```
