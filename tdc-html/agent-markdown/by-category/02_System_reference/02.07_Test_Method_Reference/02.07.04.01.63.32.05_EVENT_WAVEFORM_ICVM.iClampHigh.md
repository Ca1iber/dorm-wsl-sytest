# EVENT_WAVEFORM_ICVM.iClampHigh()

Sets the high clamp current waveform.

You can specify both the low and the high clamp current values or just one.

## Syntax

```
EVENT_WAVEFORM_ICVM &iClampHigh ( ANALOG_WAVEFORM & waveform);
```

Parameter
 | Parameter  | Description |
 | waveform |

Waveform definition object

 |

Return value

There is no return value.
