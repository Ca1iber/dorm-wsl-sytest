# Defining Global Functions and Variables

To use the global variables and functions in a test method project, follow the procedure below.

## Procedure

-  Declare the variable(s) and function(s) in a hearder file (for example Common.hpp) as below

```
extern int var1;
extern double var2;
void myPrint(int var3, double var4);
```

-  Define the function(s) in a source file (for example Common.cpp) like below and include the header file in it:

```
#include "Common.hpp"
void myPrint(int var3, double var4)
{
  ....
}
```

-  Include the header file in the test method source files that will use the global variables and functions.

```
#include "common.hpp"
```

-  Define the variables in one of the test method source files that use it.

```
int var1 = 0;
double var2 =0.2;
```

-  Use the global variables and functions in other test method source files without defining the variable again.
-  Build the test method project.
