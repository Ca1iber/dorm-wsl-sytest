# EVENT_ICVM.getLimitHigh()

Queries the upper voltage limit to compare against threshold.

## Syntax

```
bool getLimitLow (EVENT_VALUE_DOUBLE & low) const;
bool getLimitHigh(EVENT_VALUE_DOUBLE & high) const;
```

Parameter
 | Parameter  | Description |
 | value |

Upper value of range

 |

## Return value

bool value indicating the state of the limit definition:

- true: Limit has been defined by [EVENT_ICVM.limits()](<02.07.04.01.63.11.09_EVENT_ICVM.limits.md>) or [EVENT_ICVM.limitHigh()](<02.07.04.01.63.11.11_EVENT_ICVM.limitHigh.md>).
- false: No limit is defined.

## Example

For an example see [EVENT_ICVM](<02.07.04.01.63.11_EVENT_ICVM.md>).
