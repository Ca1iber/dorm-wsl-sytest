# SMC_SET_TEST_EXECUTION_TIME()

Sets the execution time to a user defined value, which reflects the estimated sequencer run time of the next test for customizing hidden upload.

Use this API only if the automatically calculated execution times of the SmartCalc framework are not sufficient.

The execTime parameter defines the time in which a hidden upload can be performed. The value gets reset after the test is done, thus it needs to be set again for the next test.

The uploadAfterTestExec parameter only takes effect if the automatically predicted execution time has elapsed. It allows to control whether upload should be continued (with default package size or user package size if specified) after the predicted time has elapsed but the sequencer is still running.

During hidden upload SmartCalc checks if the predicted execution time has not elapsed. In this case and if a user defined callback function (vector or waveform) exists, the corresponding function is called to obtain the optimal package size for the next upload. If no user defined callback function has been specified in the test method, an internal algorithm is used to compute the upload size.

If the predicted execution time has elapsed, but the sequencer is still running, and the uploadAfterTestExec parameter is set to TRUE , it checks if a user defined package size (vector or waveform) is set. If the user has specified a package size, the corresponding package size is used for the next upload. Else SmartCalc uses the package size that fits into a 1ms time slot.

Use the [SMC_EXECUTE_DEBUG_ACTION()](<02.07.04.01.231.10_SMC_EXECUTE_DEBUG_ACTION.md>) API for debugging and optimizing the execTime parameter value.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```
void SMC_SET_TEST_EXECUTION_TIME(DOUBLE execTime, Boolean uploadAfterTestExec = FALSE);
```

Parameters
 |

Parameter

 |

Description

 |
 |

execTime

 |

Expected test execution time in seconds of the next test.

 |
 |

uploadAfterTestExec

 |

Default: FALSE

If set TRUE the upload will be performed after the test execution time has elapsed.

 |

Return value

There is no return value.

## Example

The following example specifies that the expected execution time of the next test to be 5 milliseconds and executes a digital test with hidden upload:

```
// set estimated sequencer run time to 5ms
SMC_SET_TEST_EXECUTION_TIME(5 ms);
SMC_EXECUTE_TEST(TM::WAIT_DIGITAL);
```
