# SmartRDI: Level and timing set changes

#### Subtopics

- [set()](<02.07.13.18.01_set.md>)

SmartRDI provides the class `level()` and `timing()` and the function `set()` to change the level set and timing set to be used.

In the pattern‑based mode, it will create dummy patterns with CTIM or CLEV in the pattern.

In the code‑based mode, it will change the primary timing set or level set.

 Note If you are dealing with multiport, the number of level or timing change actions on different ports needs to be the same.

## Limitation

The `level().set()` or `timing().set()` command do not work in the following cases:

- When it is used in the code‑based mode, that is, outside the `RDI_BEGIN()`/`RDI_END()` block.
- When it is used in the pattern‑based mode and with single step execution enabled. That is to say, it is inside a `RDI_BEGIN(`TA::SINGLE`)`/`RDI_END()` block.

As a workaround, you can add additional flush after the SmartRDI instruction, as follows:

`rdi.level().set(1);`

`FLUSH(TM::APRM);`

## Example

```
RDI_BEGIN();
  rdi.level().set(1);
  rdi.func().label("aaa").execute();
  rdi.timing().set(1);
  rdi.func().label("bbb").execute();
RDI_END();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
