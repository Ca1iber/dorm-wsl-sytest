# TMU_RESULTS.measurement()

Returns the measurement ID for which the samples are uploaded.

## Syntax

```
UINT32 measurement();
```

List of parameters

There are no parameters.

## Return value

The measurement ID is returned.

## Functional changes

- Introduced in SmarTest 7.1.0
