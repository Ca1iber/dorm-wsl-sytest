# SMC_UPLOAD_STATUS.site()

Returns the site number of an SMC task that is stored in a vector which is populated by [SMC_GET_UPLOAD_STATUS()](<02.07.04.01.231.16_SMC_GET_UPLOAD_STATUS.md>).

## Syntax

```
const INT site() const;
```

List of parameters

There are no parameters.

## Return value

The site number of a SMC task in the upload queue.

## Example

This example shows how to create a vector of type `SMC_UPLOAD_STATUS` and how to retrieve the site number from the vector.

Note As `SMC_UPLOAD_STATUS` represents a collection, one has to iterate over the collection to obtain the item.

```
typedef vector<SMC_UPLOAD_STATUS> SmcUploadStatusVector;
int SiteNumber;

// Obtain the collection
SmcUploadStatusVector statusVector = SMC_GET_UPLOAD_STATUS();

// iterate through collection
for(SmcUploadStatusVector::iterator it = statusVector.begin();
     it != statusVector.end(); ++it) {
        SiteNumber = it->site();
        cout << "SMC upload type:" << SiteNumber << endl;
     }
```
