# iMeas()

Creates a current measurement.

It must be used together with vForce().

## Syntax

```
iMeas();
```

## Example

```
rdi.dc("iMeas").pin("pinA",TA::SPMU).vForce(3 V).iMeas().execute();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
