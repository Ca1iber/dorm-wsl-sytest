# Retrieving AC Test Results

#### Subtopics

- [Retrieving Results of Multiple Measurements from Digitizer/Sampler](<02.07.03.03.05.01_Retrieving_Results_of_Multiple_Measurements_from_Digitizer_Sampler.md>)
- [Retrieving Result from Vector Memory](<02.07.03.03.05.02_Retrieving_Result_from_Vector_Memory.md>)
- [Retrieving Functional Test Results](<02.07.03.03.05.03_Retrieving_Functional_Test_Results.md>)

When the measured analog waveform data is retrieved, the analog waveform data requires the used measurement condition, that is, the used analog set. This is because the measurement data will be compensated with the used analog set data before the measurement data is returned.

This section describes how to retrieve measurement data of analog module in the following topics.

- [Retrieving Results of Multiple Measurements from Digitizer/Sampler](<02.07.03.03.05.01_Retrieving_Results_of_Multiple_Measurements_from_Digitizer_Sampler.md>)
- [Retrieving Result from Vector Memory](<02.07.03.03.05.02_Retrieving_Result_from_Vector_Memory.md>)

This section also describes how to retrieve a functional test result in the following topic.

- [Retrieving Functional Test Results](<02.07.03.03.05.03_Retrieving_Functional_Test_Results.md>)

For the following analog modules, you can check the status whether the analog modules have received one or more triggers (0) in a test or not (1). For details of this function, see [Error Handling on Missing Trigger Input](<02.07.03.16.03_Error_Handling_on_Missing_Trigger_Input.md>).

- MCA Audio Digitizer (ADGT) / Video Digitizer (VDGT)
- MCB LF Digitizer / VHF Digitizer
- MCC Sampler
- MCE LF Digitizer / VHF Digitizer

For debugging and analyzing the measurement result, you can pass the analog waveform (or array data) to Signal Analyzer by using the PUT_DEBUG API in order to display it on the Signal Analyzer. For details, see [Passing Analog Waveform to Signal Analyzer](<02.07.03.08.11_Passing_Analog_Waveform_to_Signal_Analyzer.md>) or [PUT_DEBUG](<02.07.04.01.175_PUT_DEBUG.md>).

You can also process the retrieved data using the Computation APIs. See [Computing Measurement Values](<02.07.03.09_Computing_Measurement_Values.md>).
