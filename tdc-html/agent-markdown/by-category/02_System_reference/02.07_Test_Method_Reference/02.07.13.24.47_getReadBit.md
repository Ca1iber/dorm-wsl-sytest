# getReadBit()

Retrieves all read-bit blocks and save them to an array of type ARRAY_I. Usually, getReadBit() is used with [readBit()](<02.07.13.24.28_readBit.md>).

## Syntax

```
ARRAY_I getReadBit(const string &pin);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

pin

 |

The pin to query.

   | Note If the pin parameter is missing, the default pin will be used.

## Example

```
ON_FIRST_INVOCATION_BEGIN();
RDI_BEGIN();
rdi.smartVec("result").pin("DATA1").readBit(4,2).execute();
RDI_END();
ON_FIRST_INVOCATION_END();
ARRAY_I bit_result = rdi.id("result").getReadBit("DATA1");
```
