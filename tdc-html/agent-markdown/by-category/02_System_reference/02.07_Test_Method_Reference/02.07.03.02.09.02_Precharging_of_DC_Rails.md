# Precharging of DC Rails

The dc rail is precharged to a voltage so as to avoid hot switching of the PPMU relay when it closes. This precharge voltage can be specified for the [Leakage](<02.07.05.02.07_Leakage.md>) and [GeneralPMU](<02.07.05.02.05_GeneralPMU.md>) test method.

And also, the Continuity test can force 0 V as the precharge voltage optionally before the current forcing.

Precharging prevents sudden high currents flowing through the DUT and the associated spikes on the DC Rail.
