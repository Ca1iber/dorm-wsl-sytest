The DC instruments use the DC_WAVEFORM class to create voltage and current waveforms, and the waveforms are derived from analog waveforms.

The total length of a DC waveform is given as number of samples * sample-vector distance (see the example below).

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/DcWaveform.h.

## Constructor

```
DC_WAVEFORM();
```


## Example

Define an analog waveform and integrate it into a DC waveform. The length of the DC waveform is 4*64= 256 vectors (that is, number of samples times the specified sample-vector distance).

```
//Define an analog ramp waveform
ANALOG_WAVEFORM rampUp("rampUp");
rampUp.definition(TM::RAMP)
           .direction(TM::POS)
           .samples(4).
           .min(0.1).max(1.6);
//Define a DC waveform based on the analog waveform, and adapt it to the PPMU.
DC_WAVEFORM dcWaveform;
dcWaveform.vForce(rampUp)
          .vRange(6 V)
          .iRange(10 mA)
          .sampleVectorDistance(64);
```
