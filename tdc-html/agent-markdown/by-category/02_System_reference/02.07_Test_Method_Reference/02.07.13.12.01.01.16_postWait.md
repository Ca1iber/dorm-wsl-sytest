# postWait()

Specifies a time period to wait after a action.

This action is usually not required because there is a default wait time to make sure that the measurement is finished before the next command. It is only required when you need to hide the DC measurement time behind other events. Whenever postWait() is used, the default wait time is overwritten and the postWait() time becomes effective.

## Syntax

```
postWait(double dWaitAfterMeas);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

dWaitAfterMeas

 |

The time period to wait.

 |

## Example

```
rdi.dc().pin("DATA1").vMeas().postWait(0).execute();
```

## Functional changes

- Introduced in SmartRDI 2.2.0
