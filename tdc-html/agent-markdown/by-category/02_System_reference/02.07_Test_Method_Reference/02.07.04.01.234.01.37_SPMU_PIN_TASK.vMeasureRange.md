# SPMU_PIN_TASK.vMeasureRange()

Selects the voltage range based on the expected current passed in by the rangeValue parameter.

## Syntax

```
SPMU_PIN_TASK& vMeasureRange(DOUBLE rangeValue);
```

Parameter
 |

Parameter

 |

Description

 |
 |

rangeValue

 |

Expected value in Volt.

SmarTest determines the voltage range automatically from the pass/fail thresholds [min()](<02.07.04.01.234.01.23_SPMU_PIN_TASK.min.md>) and [max()](<02.07.04.01.234.01.21_SPMU_PIN_TASK.max.md>) if the expected value has not been defined by this API.

   | Note The voltage range depends on the underlying hardware.

## Return value

A reference to the [SPMU_PIN_TASK](<02.07.04.01.234.01_SPMU_PIN_TASK.md>) object.
