# wait()

Specifies a time period or an action to wait before the next action.

## Syntax

```
wait(double dWait);
wait(const TA::WAIT_ACTION& waitAction);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

dWait

 |

The time period to wait.

 |
 |

waitAction

 |

The action to wait.

 |

List of available options of parameter: waitAction
 |

Option

 |

Description

 |
 |

TA::WAIT_DGT

 |

Wait for the digitizer to finish.

 |
 |

TA::WAIT_AWG

 |

Wait for the AWG to finish.

 |
 |

TA::WAIT_RFAWG

 |

Wait for the RF source waveform to finish.

 |
 |

TA::WAIT_RFDGT

 |

Wait for the RF measurement to finish.

 |
 |

TA::WAIT_DCDGT

 |

Wait for DC-DGT to finish.

 |

## Example

```
rdi.wait(TA::WAIT_DGT);
rdi.wait(5 ms);
```

## Functional changes

- Introduced in SmartRDI 2.1.0
- SmartRDI 2.4.0: One option TA::WAIT_DCDGT is added.
