# RDI_INIT()

Initializes an environment for SmartRDI.

After the execution of the test suite is done, the environment is cleared.

## Syntax

```
RDI_INIT();
```

RDI_INIT() must be called before [ON_FIRST_INVOCATION_BEGIN();](<02.07.04.01.138_ON_FIRST_INVOCATION_BEGIN.md>).

## Functional changes

- Introduced in SmartRDI 2.1.0
