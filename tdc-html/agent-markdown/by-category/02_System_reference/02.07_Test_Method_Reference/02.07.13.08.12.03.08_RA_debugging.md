# RA debugging

The RA library provides register dump, register tracking, and register cache memory print for debugging purposes.

## Register dump

 The RA library uses RA_REGISTER_DUMP() in test methods to control register dump. If not specified, RA_REGISTER_DUMP() dumps all related registers in the RDI_BEGIN/RDI_END block. When a specific register list is set, this API dumps for the specified register list only. See the example as follows:

 | `RA_REGISTER_DUMP()` in the test method: |
 |

```
RDI_BEGIN();
    // Register Write
    reg.PERIPHERAL0().REGISTER0().setValue(INIT_VALUE).write();
    // Field Write [3:2]
    reg.PERIPHERAL0().REGISTER1().setField_FIELDB(1).write();
    // Write Dynamic
    reg.PERIPHERAL0().REGISTER2().writeDynamic(DYN_ID);
    // Read Back
    reg.PERIPHERAL0().REGISTER3().read(READ_ID);
    // Compare value (PF)
    reg.PERIPHERAL0().REGISTER4().setValue(INIT_VALUE).compare();
    // Pattern call
    rdi.func().label("test").execute();
    // DC tests
    rdi.dc(ID_DC_MEAS).pin("DATA1").iForce(0).vMeas().measWait(2 ms).execute();
    rdi.hwRelay().pin("DATA1").setOff("ALL").execute();

    /// Debug : Dump Register
    RA_REGISTER_DUMP("ID_DUMP1");

    RA_REGISTER_DUMP("ID_DUMP2", [vector<ULONG64>& addressList]);

    /// Continue with Register Operation
    reg.PERIPHERAL1().REGISTER0().setValue(INIT_VALUE).write();

RDI_END();
```

## Register tracking

 The RA library uses RA_PRINT_TRACKING() for printing changed values from all the registers in the last RDI_BEGIN/RDI_END block.

 | `RA_PRINT_TRACKING()` in test methods: |
 |

```
RDI_BEGIN();
  ...
  // Register Write
  reg.PERIPHERAL0().REGISTER2().setValue(INIT_VALUE).write();

  // Field Write [3:2]
  reg.PERIPHERAL0().REGISTER1().setField_FIELDB(1).write();
  ...
  // Continue with Register Operation
  reg.PERIPHERAL1().REGISTER0().setValue(INIT_VALUE).write();
RDI_END();

RA_PRINT_TRACKING(RA::GROUP_BY_OPERATION);
RA_PRINT_TRACKING(RA::GROUP_BY_REGISTER);
```

## Register Cache Memory Print

 The RA library uses RA_PRINT_REGISTER_MEMORY() to print the register cache memory for Partial Bit Field Write operation (RMW).

 | RA_PRINT_REGISTER_MEMORY() in test method: |
 |

```
RDI_BEGIN();
  reg.PERIPHERAL().REGISTER0().setField_FIELDB(1).write();
RDI_END();

// print register mem
RA_PRINT_REGISTER_MEMORY();

```

 |
 | Printing cache memory |
 |

```
========================================================

========================================================

PERIPHERAL0.REGISTER3     , Ax2091, Value : 0xeb

```
