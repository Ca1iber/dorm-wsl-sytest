# rdi.tmu().enPassFail()

Enable retrieving of the functional test result for a user defined pattern.

This API can be used together with APIs [rdi.tmu().label()](<02.07.13.21.07_rdi.tmu__.label.md>) and [rdi.tmu().insertVec()](<02.07.13.21.05_rdi.tmu__.insertVec.md>) if the functional test result of the user defined pattern should be retrieved after the RDI_BEGIN() ... RDI_END() block.

## Syntax

```
tmuBase& enPassFail()
```

## Return Value

A reference to the tmuBase object.

## Example

```
RDI_BEGIN();

    rdi.tmu("a").label("label1").pin("A")    ... .enPassFail().execute();
    rdi.dc("b").label("label2").pin("B")     ... .enPassFail().execute();
    rdi.digCap("c").label("label3").pin("C") ... .enPassFail().execute();

RDI_END();

int testResult_a = rdi.id("a").getPassFail();
int testResult_b = rdi.id("b").getPassFail();
int testResult_c = rdi.id("c").getPassFail();
```
