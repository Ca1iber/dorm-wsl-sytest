# EVENT_VCVM.vClampHigh()

Sets the upper clamp voltage.

Only one of the two values can be set per DC event. The upper clamp voltage, defined by this member function, and the lower clamp voltage, defined by [EVENT_VCVM.vClampLow()](<02.07.04.01.63.22.01_EVENT_VCVM.vClampLow.md>), must be set in separate DC events.

This member function is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/Events.h.

## Syntax

```
EVENT_VCVM & vClampHigh(const EVENT_VALUE_DOUBLE & value);
```

Parameter
 | Parameter  | Description |
 | value |

Defines the upper clamp voltage to be set in V (Volt).

 |

## Return value

A reference to the corresponding [EVENT_VCVM](<02.07.04.01.63.22_EVENT_VCVM.md>) object.
