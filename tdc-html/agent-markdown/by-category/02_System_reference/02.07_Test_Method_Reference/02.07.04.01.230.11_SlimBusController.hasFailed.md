# SlimBusController.hasFailed()

This function returns TRUE if automatic booting is active.

## Syntax

```
Boolean isDynamicBootActive(void);
```

List of parameters

There are no parameters.

## Return value

TRUE if dynamic booting is active, FALSE otherwise.

## Functional changes

- Introduced in SmarTest 7.2.1
