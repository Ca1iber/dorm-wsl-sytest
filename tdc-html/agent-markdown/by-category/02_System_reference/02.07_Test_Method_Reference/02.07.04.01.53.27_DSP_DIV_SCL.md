# DSP_DIV_SCL

This API is for dividing a scalar value by each element in an array.

result [i] = scaler / src [i]

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_DIV_SCL(DOUBLE scaler, ARRAY_D& src,
            ARRAY_D& result);
DSP_DIV_SCL(DOUBLE scaler, DOUBLE *src,
            DOUBLE *result, INT size);
DSP_DIV_SCL(COMPLEX scaler, ARRAY_COMPLEX& src,
            ARRAY_COMPLEX& result);
DSP_DIV_SCL(COMPLEX scaler, COMPLEX *src,
            COMPLEX *result, INT size );
```

## Example

```
DOUBLE array1[1024], array2[1024];
     .
     .
DSP_DIV_SCL(128.0, array1, array2, 1024);
```

DSP_DIV_SCL divides 128.0 by the first 1024 elements of double array array1, and returns the results to the corresponding 1024 elements of double array array2 as follows:

```
int i;
     .
     .
for(i=0; i<1024; i++)
  array2[i] = 128.0/array1[i];
```
