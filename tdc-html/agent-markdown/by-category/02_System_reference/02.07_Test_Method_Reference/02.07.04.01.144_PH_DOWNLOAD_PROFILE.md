# PH_DOWNLOAD_PROFILE()

You can use this API to download temperature profiles into the handler.

## Syntax

```
bool PH_DOWNLOAD_PROFILE(int profile_id, const string& profile_name, int pretrigger_time, int num_samples, map<int, double>& samples, string&err_msg)
```

Parameters
 |

Parameter

 |

Type

 |

Description

 |
 |

profile_id

 |

int

 |

Profile ID. The value is from 1 to 10,

 |
 |

profile_name

 |

const string &

 |

Profile name. The name can be up to 256 characters with letters from A to Z, numbers from 0 to 9, underscore '_' and ignore case, just like a test suite name.

 |
 |

pretrigger_time

 |

int

 |

Pretrigger timing in milliseconds. The value is from 100 to 1000 milliseconds.

 |
 |

num_samples

 |

int

 |

Number of samples. The value is from 6 to 250, such as 50 to 2490 milliseconds. It must match the map size of samples.

 |
 |

samples

 |

map<int, double>

 |

Timestamp in milliseconds. The value is from 0 to 2490 in 10 steps. For example, ee(0)=10, ee(1)=20, ee(2)=30, ...etc. The sample temperature in Celsius is from -327.6 to 327.6.

 |
 |

err_msg

 |

string &

 |

The return value of the function whether it has succeeded or failed.

 |

## Return value

 |

Parameter

 |

Description

 |
 |

true

 |

The temperature profiles have been downloaded successfully.

 |
 |

false

 |

Downloading the temperature profiles failed.

 |
