# SMC_SET_LLM_FORMAT()

Formats the lower limit of the previous [SMC_TEST()](<02.07.04.01.231.45_SMC_TEST.md>) in the data formatter output.

Calling this function stores the supplied format string in the C_LLMFMT fields of the [parametric test record](<../02.10_Data_Logging/02.10.03.05.22_Parametric_Test_Record__PTR.md>) (PTR) and the [multiple-result parametric record](<../02.10_Data_Logging/02.10.03.05.23_Multiple-Result_Parametric_Record__MPR.md>) (MPR).

Note This API cannot be used with [Hidden data logging](<02.07.10.04.09_Hidden_data_logging.md>).

Use the [TESTSET.llmfmt()](<02.07.04.01.244.18_TESTSET__.llmFmt.md>) function instead, if you need this functionality with hidden data logging.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

## Syntax

```
void SMC_SET_LLM_FORMAT(const STRING& format);
```

Parameter
 |

Parameter

 |

Description

 |
 |

format

 |

A string describing the desired format. The string is a standard ANSI C format string, for example, "%7.3f".

 |

Return value

There is no return value.
