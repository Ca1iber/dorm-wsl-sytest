# Activating an Existing Routing Set

If you have prepared a routing set for DC test, you can activate the routing set in your test method program as follow:

```
Routing.primary(set);
FLUSH();
```

where, Routing is a system-prepared class object of the ROUTING_STATUS API, and set is the routing set number. The FLUSH API is necessary to download the settings defined in the routing set to the hardware.
