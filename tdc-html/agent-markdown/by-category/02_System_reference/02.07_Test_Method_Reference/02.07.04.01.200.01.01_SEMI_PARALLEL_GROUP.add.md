# SEMI_PARALLEL_GROUP.add()

Adds a site to the current semi-parallel group. The sites added in one group will be tested in parallel.

## Syntax

```
SEMI_PARALLEL_GROUP & add(int site);
```

Parameter
 |

Parameter

 |

Description

 |
 |

site

 |

The site number to add.

 |

## Return value

A reference to the current group is returned.

## Functional changes

- Introduced in SmarTest 7.2.0
