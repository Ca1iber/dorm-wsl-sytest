# SlimBusController.hasFailed()

This function returns TRUE if creation of the superframe viewer file is activated.

## Syntax

```
Boolean isSuperframeViewerOutputEnabled() const;
```

List of parameters

There are no parameters.

## Return value

TRUE if creation of the superframe viewer file is activated, FALSE otherwise.

## Functional changes

- Introduced in SmarTest 7.2.1
