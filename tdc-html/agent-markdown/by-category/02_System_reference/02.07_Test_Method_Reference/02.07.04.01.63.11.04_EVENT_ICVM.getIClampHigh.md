# EVENT_ICVM.getIClampHigh()

Queries the high clamp current value.

## Syntax

```
void getIClampHigh ( EVENT_VALUE_DOUBLE & value );
```

Parameter
 | Parameter  | Description |
 | value |

High clamp current

 |

Return value

There is no return value.
