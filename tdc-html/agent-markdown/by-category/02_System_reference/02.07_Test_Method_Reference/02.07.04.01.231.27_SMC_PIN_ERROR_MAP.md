# SMC_PIN_ERROR_MAP

Uploads the error map data for the specified pin and result area. It provides SmartCalc support and [Hidden upload](<02.07.10.04.05_Hidden_upload.md>). Also, it is compatible with pin scale cards.

  Note The API expects the standard receive edge to result mapping for recording modes X2, and X4:

- Recording mode X1: All edges are mapped to result 1.
- Recording mode X2:

  - Edge 1 …4 are mapped to result 1.
  - Edge 5 …8 are mapped to result 2.

- Recording mode X4:

  - Edge 1 and 2 are mapped to result 1.
  - Edge 3 and 4 are mapped to result 2.
  - Edge 5 and 6 are mapped to result 3
  - Edge 7 and 8 are mapped to result 4

Other receive edge to result mappings can be defined using API RESULT_CONFIGURATION. For more information, refer to [setEdgeToResultMapping()](<02.07.04.01.191_RESULT_CONFIGURATION.md#_130383__dle_setEdgeToResultMapping>) in [RESULT_CONFIGURATION](<02.07.04.01.191_RESULT_CONFIGURATION.md>).

## Syntax

```
SMC_PIN_ERROR_MAP(                const STRING &pinName, const STRING &resultArea);
SMC_PIN_ERROR_MAP(const int site, const STRING &pinName, const STRING &resultArea);
```

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/SMART_CALC2.h.

 Parameters

 | Parameter  | Description |
 | pinName  | The pin for which the error map will be uploaded. |
 | resultArea  | The name of the result area which is used to acquire the fail data. |
 | site  | The site number.  |  Return value The constructor has no return value.

## Example

The following example shows how to upload a pin error map data. The default upload chunk size of 512KB is used.

```
virtual void run()
{
    ON_FIRST_INVOCATION_BEGIN();

        // Variables.
        STRING mPinaName = "PinA";
        STRING mAreaId = "Area1";

        // Select result area for storing results.
        RESULT_AREA_CONFIG_SET resArea(mAreaId);
        resArea.setAsPrimary();

        //Configure result mode
        RESULT_CONFIGURATION resConfig;
        resConfig.setResultStorageLocation(RESULT_CONFIGURATION::RAM);
        resConfig.setResultGranularity(RESULT_CONFIGURATION::cycle,"@");
        resConfig.setNumberOfResultsPerCycle(RESULT_CONFIGURATION::RPC8);
        resConfig.setResultWidth(RESULT_CONFIGURATION::_1Bit);
        resConfig.enable();

        // Run functional test.
        SMC_FUNCTIONAL_TEST();

        // Loop over all sites and upload results
        FOR_EACH_SITE_BEGIN();

            SMC_ARM(mPinName, mAreaId);

        FOR_EACH_SITE_END();

        // A newly created result configuration contains the default settings.
        // This can be used to reset the result configuration:

        RESULT_CONFIGURATION  defaultConfig;
        defaultConfig.enable();
        resArea.deselectGlobally();

    ON_FIRST_INVOCATION_END();

    return;
}

public:

void SMC_backgroundProcessing(string pin, string Area)
{
    CYCLE_CHUNK cycles;

    SMC_PIN_ERROR_MAP errorMap(pin,Area);

    while ( true == errorMap.getNextCycleChunk(cycles))
    {
        // Outputs result information, only needed for debug information
        cout << cycles;

        // do post processing
    }
}
```
