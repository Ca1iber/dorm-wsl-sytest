# Getting the SmartRDI revision information

#### Subtopics

- [getBuildDate()](<02.07.13.08.06.01_getBuildDate.md>)
- [Macros to get the SmartRDI version number](<02.07.13.08.06.02_Macros_to_get_the_SmartRDI_version_number.md>)
- [rdi.getActiveRdiRev()](<02.07.13.08.06.03_rdi.getActiveRdiRev.md>)
- [rdi.getCompileRdiRev()](<02.07.13.08.06.04_rdi.getCompileRdiRev.md>)

SmartRDI provides functions and macros that help user to retrieve SmartRDI revision information including:

- major, minor, quality and patch version numbers. See [Macros to get the SmartRDI version number](<02.07.13.08.06.02_Macros_to_get_the_SmartRDI_version_number.md>).
- build date of the current beta revision. See [getBuildDate()](<02.07.13.08.06.01_getBuildDate.md>).
- currently selected revision. See [rdi.getActiveRdiRev()](<02.07.13.08.06.03_rdi.getActiveRdiRev.md>).
- revision in use for compilation. See [rdi.getCompileRdiRev()](<02.07.13.08.06.04_rdi.getCompileRdiRev.md>).

## Functional changes

- Introduced in SmartRDI 2.4.5
