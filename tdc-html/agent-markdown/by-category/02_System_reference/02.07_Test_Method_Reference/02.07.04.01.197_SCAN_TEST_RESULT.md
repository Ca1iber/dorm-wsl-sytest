# SCAN_TEST_RESULT

#### Subtopics

- [SCAN_TEST_PIN_RESULT](<02.07.04.01.197.01_SCAN_TEST_PIN_RESULT.md>)

This class holds the result data of a scan test. `SCAN_TEST_RESULT` and [SCAN_TEST_PIN_RESULT](<02.07.04.01.197.01_SCAN_TEST_PIN_RESULT.md>) are used to send data to the datalog that will show up as STR ([Scan Test Record](<../02.10_Data_Logging/02.10.03.05.17_Scan_Test_Record__STR.md>)). An instance of the class `SCAN_TEST_RESULT` can be sent to datalog by calling `judgeAndLog_ScanTest()` of [TESTSET](<02.07.04.01.244_TESTSET.md>) API.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/ScanTestResult.h.

## Class definition


Member functions

```

```

## Syntax

```
SCAN_TEST_RESULT obj(mode);
obj.func(param1);
obj.pin(scanPin).funcPin(param2);
```

where `func(param1)` and `pin(scanPin)` are the member functions of `SCAN_TEST_RESULT` and `funcPin(param2)` is the member function of `SCAN_TEST_PIN_RESULT`.

## Constructor

```
SCAN_TEST_RESULT(TM::SCAN_TEST_RESULT_MODE mode);
```

This creates an object of SCAN_TEST_RESULT to hold the scan test result.

Parameter
 |

mode

 |

The failure data logging mode. It can be:

- CYCLE_BASED_LOGGING: log the failure data in a cycle based mode. The cycles are logged in which failures have occurred, but no references to the actual ATPG pattern are included.
- or PATTERN_BASED_LOGGING: log the failure data in a pattern based mode. The failing cycle and pin information are mapped back to pattern, chain or bit information.
 |

## Example

In the following example, `scanPins`, `maxFailsPerPin`, `cycleBased`, `includeExpectedData` and `testerCycleMode` are input parameters defined for the test method. This example is from the scan_tml source file.

```
ERROR_MAP_TEST emap(testerCycleMode ? TM::TESTER_CYCLES : TM::XMODE_CYCLES);
SCAN_TEST_RESULT log(cycleBased ? TM::CYCLE_BASED_LOGGING : TM::PATTERN_BASED_LOGGING);
string subLabel;
map <string,string> testConditions;

ON_FIRST_INVOCATION_BEGIN();
  /* Setup the error map */
  emap.pin(scanPins).setLocation(TM::RAM)
      .setRecordingMode(TM::PF).setStartCycle(0);
  /* Execute functional test */
  CONNECT();
  FUNCTIONAL_TEST();
ON_FIRST_INVOCATION_END();

/* If functional test has passed, no further processing has to be done */
if(GET_FUNCTIONAL_RESULT())
{
  return;
}

/* Retrieve the overall failures for this site */
log.totalFailures(emap.getErrorCount());
log.totalCyclesExecuted(emap.getLastCycleExecuted());
subLabel="myLabel";
log.setLabelName(subLabel);

testConditions["SHIFT_FREQ"] = "50 MHz";
testConditions["CAPTURE_FREQ"] = "750 MHz";
log.setTestConditionList(testConditions);

STRING_VECTOR pins =
PIN_UTILITY::getDigitalPinNamesFromPinList(scanPins,TM::O_PIN | TM::IO_PIN);

/* Retrieve the failing cycles per pin for this site */
for(int i=0; i<pins.size(); i++)
{
  INT failsToUpload = 1;
  if(-1 == maxFailsPerPin)
  {
    failsToUpload = emap.pin(pins[i]).getErrorCount();
  }
  else {
    failsToUpload = maxFailsPerPin;
  }

  ARRAY_LL cycles;
  emap.pin(pins[i]).getFirstFailingCycles(0, failsToUpload, cycles);
  log.pin(pins[i]).failingCycles(cycles);

  if(includeExpectedData)
  {
    ARRAY_CHAR expected;
    emap.pin(pins[i]).getExpectedDataForCycles(cycles, expected);
    log.pin(pins[i]).expectedData(expected);
  }
}
/* Push the failures to datalog */
TESTSET().cont(true).judgeAndLog_ScanTest(log);
```
