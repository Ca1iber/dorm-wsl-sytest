# ARRAY_BOOL

ARRAY_BOOL defines an array holding the BOOL type of data and defines the functions to access and process the data.

## Constructors

```
ARRAY_BOOL (INT size);
```

This constructs an object of ARRAY_BOOL with the specified fixed size. If a size larger than zero is specified, the memory for the specified number of elements is allocated and the array cannot be resized.

```
ARRAY_BOOL (const ARRAY_BOOL& array);
```

This constructs an unresizable object of ARRAY_BOOL by copying from another ARRAY_BOOL object.

```
ARRAY_BOOL (const ARRAY_BOOL& array, INT size, INT offset= 0);
```

This constructs an unresizable object of ARRAY_BOOL by sharing the specified elements from another ARRAY_BOOL object.

```
ARRAY_BOOL (bool* array, INT size, INT offset= 0);
```

This constructs an unresizable object of ARRAY_BOOL by sharing the specified elements from a BOOL array.

Parameters
 |

array

 |

The array to copy from.

 |
 |

size

 |

Size of the new ARRAY_BOOL object.

 |
 |

offset

 |

(optional) Starting point in original array where to begin copying the elements.

 |

## Member functions

### init()

```
void init (bool initValue=false);
```

This function fills the array elements with the specified value.

Parameter
 |

initValue

 |

Value with which to fill the array. Default is false.

 |

### resize()

```
INT resize (INT size);
```

This function changes the size of the array if it is resizable and keeps its data.

Parameter
 |

size

 |

New size of the array

 |

### size()

```
const INT size () const;
```

This function returns the size of the array.

### capacity()

```
const INT capacity();
```

This function returns the memory size allocated to the array.

### operator =

```
ARRAY_BOOL& operator = (const ARRAY_BOOL& array);
```

This function copies all the elements of the specified array to the current array and changes its size.

Parameter
 |

array

 |

The array to copy from

 |

### operator []

```
bool& operator [] (const INT index);
const bool& operator [] (const INT index) const;
```

These functions access the specified element in the array.

Parameter
 |

index

 |

Index of the element to access

 |

### operator const bool*

```
operator const bool* () const;
```

This operator converts ARRAY_BOOL to BOOL*.
