# rdi.digCapImmediateUpload()

Defines the digital capture for which data should be uploaded immediately while test is running.

## Syntax

```
rdi.digCapImmediateUpload(bool val, const string resultId);
```

Parameters
 |

Parameter

 |

Description

 |
 |

resultId

 |

The ID of the digital capture for which captured data is uploaded immediately.

 |

## Example

```
rdi.digCapImmediateUpload("resultId");
```

```
rdi.digCapImmediateUpload(true, "resultId");
```

See also [Using Immediate Upload in SmartRDI](<02.07.13.13.03_Using_Immediate_Upload_in_SmartRDI.md>).
