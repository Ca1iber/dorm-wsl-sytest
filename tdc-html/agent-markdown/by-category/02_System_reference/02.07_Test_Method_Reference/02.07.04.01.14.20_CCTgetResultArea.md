# CCTgetResultArea

This function returns the result area name for hidden upload of digital capture.

This function is usually used in the `preStart()`, `postStart()`, `process()` and `cleanup()` function but not used in the `init()` function of the CCF test method template.

This function is defined in the header file /opt/hp93000/soc/testmethod/include/CCTestMethod.hpp.

## Syntax

```
string CCTgetResultArea();
```

## Example

```
ARRAY_I data = SMC_GET_VECTORS("capt_variable1",CCTgetResultArea());
```

In this example, `CCTgetResultArea()` is used to retrieve the result area name. Then the vectors in this result area are retrieved and stored in the array `data`.
