# getPriAnaSet()

Retrieves the primary analog set.

## Syntax

```
string getPriAnaSet();
```

List of parameters

There are no parameters.

 Note DO NOT use this function in SMC_backgroundProcessing(). See [Using hidden upload with SmartRDI](<02.07.13.08.19.01_Using_hidden_upload_with_SmartRDI.md>)

## Example

```
string pAnalogSetName = rdi.getPriAnalogset();
```

## Functional changes

- Introduced in SmartRDI 2.1.0
