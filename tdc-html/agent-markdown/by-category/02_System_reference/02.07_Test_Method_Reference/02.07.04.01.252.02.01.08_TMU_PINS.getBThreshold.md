# TMU_PINS.getBThreshold()

Returns the voltage threshold of the second shot.

## Syntax

```
DOUBLE getBThreshold() const;
```

List of parameters

There are no parameters.

## Return value

The voltage threshold of the second shot is returned. The unit is volts.
