# DSP_RF_GET_SCALAR_CAL()

This function returns the calibration correction for the current site in focus. The measParams array has cal data all sites in its contents. This method simply extracts the cal correction for the site and returns it as a double correction watts/watts. It can be used directly in functions which accept calCorrection, such as DSP_RF_SPECTRUM.

This API is defined in the header file /opt/hp93000/soc/prod_com/include/MAPI/libdsp.h.

## Syntax

```
DSP_RF_GET_SCALAR_CAL( const ARRAY_D & measParams, const INT site, DOUBLE * calFactor);
```

## Examples

```
Array_D measParams = MEAS_DEF("name").getParameters(1,0);
DOUBLE CalCorr = 0;
DSP_RF_GET_SCALAR_CAL(measParams,1, &CalCorr);
ARRAY_COMPLEX cData =MEAS_DEF("name").getComplexWaveform(1);
ARRAY_D real = cData.getReal();
ARRAY_D img = cData.getImag();
for (i=0; i<real.size().size(); i++)
{
real[i]= real[i] * sqrt(calCorr);
imag[i] = imag[i] * sqrt(calCorr);
}

```

Since DSP_RF_SPECTRUM does not accept a parameters array (MEAS_DEF().getParameters()), the results returned are uncalibrated. To obtain calibrated results, DSP_RF_SPECTRUM must be used in conjunction with DSP_RF_GET_SCALAR_CAL() as shown below.

```
ARRAY_D measParams = MEAS_DEF("myModPwrMeas").getParameters(1,0);// Same as any other RF measurement
DOUBLE CalCorr = 0;
DSP_RF_GET_SCALAR_CAL(measParams,1, &CalCorr); // 1 = Site number
ARRAY_COMPLEX cData = MEAS_DEF("myModPwrMeas").getComplexWaveform(1);
ARRAY_D fftData(cData.size());
DSP_RF_SPECTRUM(cData, fftData, WATT, HANNING, 0, CalCorr);
```

### Calibrated Demodulation Results

EVM measurements do not require calibrated time domain data to be sent to the demodulation algorithm, but some demodulation results return power measurements over different regions of the payload, for example. To send calibrated time domain data to the demodulation algorithm, use the following example:

```
TimeData = SMC_GET_COMPLEX_WAVEFORM(mDgtPinName, tsuite_name, 1);
DOUBLE CalCorr = 0.0;
DSP_RF_GET_SCALAR_CAL(measParams, 1, &CalCorr);
cout << "Scalar Cal Factor: " << CalCorr << endl;
ARRAY_D rData = TimeData.getReal();
ARRAY_D iData = TimeData.getImag();
ARRAY_COMPLEX TimeDataCal;
TimeDataCal.resize(rData.size());
int i;
for (i=0; i<rData.size(); i++)
{
rData[i] = rData[i] * sqrt(CalCorr);
iData[I] = iData[I] * sqrt(CalCorr);
TimeDataCal[i].real() = rData[i];
TimeDataCal[i].imag() = iData[i];
}
DEMODULATION demod("BLUETOOTH");
demod.execute(TimeDataCal, d_sampleFrequency);
```
