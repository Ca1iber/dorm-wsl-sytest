The parameter `request` selects one of a number of state variables of the RS-232 interface. `[gio_rs232_status()](<02.13.07.04_Operations_specific_to_RS-232_devices.md#ga702d374f6e023c0200b0d2f07167548d>)` returns the corresponding value in `*pResult`.

| GIO_ERR_NO_ERROR | Operation successfully completed. |
| other | An error occurred.  |    Parameters

| id | Interface ID. |
| request | Type of status report. |
| pResult | OUT: Current state.  |
