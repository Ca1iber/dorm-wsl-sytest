 | [GIO_ERROR](<02.13.07.07_Error_handling.md#ga307753a7be5d06f3eaf383ca94efd15a>) gio_clear   | (  | IDID   | id | )  | |

Clear an interface or device.

The exact behavior of this function depends on the interface type and on the access method which is used. For example, it will send an "SDC" command to a GPIB device session.

 AttentionThis function must not be used if the intent is to perform an "interface clear" on a GPIB interface. Use `[gio_gpib_send_IFC()](<02.13.07.03_Operations_specific_to_GPIB_devices.md#gac412964b605b33bd1b60acaa8c6bae91>)` instead.

(The reason for this restriction is that access methods for different types of GPIB interfaces behave differently when `[gio_clear()](<02.13.07.02_Operations_applicable_to_diverse_interface_or_device_types.md#ga3ffa3bd02beca7fc651b3eeb0f82d86c>)` is given the `IDID` of an interface session. This is a protocol issue, not a software bug.)

 | [GIO_ERROR](<02.13.07.07_Error_handling.md#ga307753a7be5d06f3eaf383ca94efd15a>) gio_lock   | (  | IDID   | id | )  | |

Lock an interface or device.

`[gio_lock()](<02.13.07.02_Operations_applicable_to_diverse_interface_or_device_types.md#ga281f1e0664bd2ea69456e1f38bc93b61>)` places a device (or an entire interface) in a mode in which access is granted only to the client which locked it. Depending on the state of the lock waiting flag (see `[gio_set_lock_wait()](<02.13.07.06_Session_parameters.md#gabcc62403c25ffbe6199d0b4459614370>)` for more information), all other clients will either hang or encounter errors (`GIO_ERR_DEVICE_LOCKED`) when they attempt to access a locked device or interface.

 AttentionBehavior may differ between access methods when an attempt is made to lock the same interface/device via different `IDIDs`, or to nest calls to `[gio_lock()](<02.13.07.02_Operations_applicable_to_diverse_interface_or_device_types.md#ga281f1e0664bd2ea69456e1f38bc93b61>)` for a single `IDID`. Read data.

The function `[gio_read()](<02.13.07.02_Operations_applicable_to_diverse_interface_or_device_types.md#gac927c44b656660a6150cd7564b98f13c>)` reads a block of data from an interface or device. If no error occurs and the parameter `pReasons` is not zero, `[gio_read()](<02.13.07.02_Operations_applicable_to_diverse_interface_or_device_types.md#gac927c44b656660a6150cd7564b98f13c>)` returns in `*pReasons` a value indicating the condition (or conditions) which caused to operation to return; this value consists of separate bits (values of the `GIO_REASON` enumeration type). `[gio_read()](<02.13.07.02_Operations_applicable_to_diverse_interface_or_device_types.md#gac927c44b656660a6150cd7564b98f13c>)` also returns the number of bytes read in `*pActual`, if `pActual` is non-zero.
