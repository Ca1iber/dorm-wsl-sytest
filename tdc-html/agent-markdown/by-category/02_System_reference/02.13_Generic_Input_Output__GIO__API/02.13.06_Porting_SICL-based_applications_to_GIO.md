# Porting SICL-based applications to GIO

If there are test applications invoking functions of SICL, these must be rewritten to use GIO library API functions instead.

## About this task

SmarTest releases 7.5 and onwards based on RHEL 7.4 do not support SICL anymore.

If your test application is based on SICL, it has to be rewritten using the functions offered by the GIO library API.

In order to ease this migration, both functions and function names of the GIO library adhere to the SICL standard. However, there is not everywhere a plain one-to-one mapping of SICL to GIO functions. Consider the individual description of the GIO library function as defined in [GIO API reference](<02.13.07_GIO_API_reference.md>).

## Before you begin

Get the source code of your test application.

## Procedure

-  Identify the SICL functions and their context used in your test application.
-  Replace them with the appropriate GIO library API functions.

Replace the SICL declaration of instrument or device identifiers based on the `INST` type by the one based on the `IDID` of GIO. See also [Introduction to the GIO library API](<02.13.02_Introduction_to_the_GIO_library_API.md>).

Modify your test application wherever applicable in order to fit the functionality of the GIO library API function provided.

-  Produce the rewritten test application.

## Results

Your formerly SICL-based test application is ready to be used with the GIO library.
