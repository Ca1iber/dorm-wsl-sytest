# Adding a project to the Java build path

If a project contains code that must be known by a Java core program, this project must be added to the Java build path.

## About this task

The Java build path is used by the compiler to identify dependent classes for the building of the Java project.

## Before you begin

You have a created a project to be added to the Java build path.

You have opened a workspace with your SmarTest program.

## Procedure

-  Import the project to be added into your current workspace.
-  Right-click the project to be added to open the Java Build Path dialog box with Build Path > Configure Build Path ....
-  In the Java Build Path dialog box, select the tab Projects.
-  Click Add....
-  In the Required Project Selection box, select the project to be added.
-  Confirm with OK.
-  In the Java Build Path dialog box, click Apply and close.

## What to do next

You have prepared the compilation of your SmarTest program.

## Functional changes

- Introduced in SmarTest 8.4.4
