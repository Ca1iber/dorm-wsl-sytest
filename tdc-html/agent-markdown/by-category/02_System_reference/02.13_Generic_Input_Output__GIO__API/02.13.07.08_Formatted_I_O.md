Send a formatted string to a device or interface.

 AttentionUnlike SICL, this function doesn't buffer I/O. The caller must pass a buffer which is large enough to hold the formatted string. The format string will be interpreted according to the rules for `printf(3)`, not according to SICL's formatting rules. ReturnsGIO_ERROR  Return values

| other | An error occurred.  |    Parameters

| pBuffer | Formatting buffer. |
