# Installing the GIO library API from the command line

The GIO library API can be installed on the system controller from the command line using the rpm command.

## About this task

The GIO library API is provided as a Red Hat Package Manager (RPM) package (.rpm file) to be installed.

This topic describes how to install the package from the command line.

As an alternative, you can use V93000 SmartInstall to install the GIO library API if your operating system is RHEL 7.4 (SmarTest releases 7.5 and onwards) or higher. SmartInstall is a tool provided by Advantest to install .rpm packages on the system controller. Advantest recommends to use V93000 SmartInstall.

## Before you begin

Make sure that your workstation is clean without any previous version of the GIO library API installed and you have an account with the root privilege to run the installation commands.

If you have installed one version before, you must uninstall it first by using the similar commands as follows (query all .rpm files, but piping it with the string gio before listing the query result, and erase the old .rpm using the name gio-xxxxxxxx of the old .rpm found):

rpm -qa|grep "gio"

rpm -e v93000_gio-xxxxxxxx

with gio-xxxxxxxx as the name of the previous GIO library API package to be removed.

The following procedure relies on your account being configured to make use of the sudo command. If this is not the case, you will have to switch to the root user account using the su - root command prior to your installation work. Run the commands listed below without the preceding input sudo in this case. Another option is to switch to an interactive root shell with the command sudo -i and then to proceed as in the su case. However, the procedure described below is the preferred one in order to have the user's root sphere limited.

## Procedure

-  Open a terminal window.
-  Copy the GIO library API package to your system controller workstation, for instance in your /tmp directory.
-  Identify the directory in which the GIO library API package to be installed is located.

If you do not know this location from step 2, get a list of all present GIO related packages using the query-all command rpm -qa|grep gio. This list shall show one row only, the one of the package to be installed.

If the GIO library API is provided as a tarball, for instance with the qualifier .tar.gz, you will have to use standard Linux tools or commands to search for the file location. Examples are the GNOME tool, or find / "*gio*.tar.gz" to get all tarballs with the string "gio" in the file name, or grep --include=\*.tar.gz -Ri "gio" to get all tarballs with the string "gio" inside.

-  Using the cd command switch to the directory in which the GIO library API package is located.
-  (Optional) Decompress the GIO library API package to get a file of type .rpm, for instance with the tool [Ark](<https://kde.org/applications/utilities/ark/>).
-  Using the sudo rpm -ivh package_filename command install the .rpm package with verbose output and display of hash marks. Enter the password once being prompted for.

Type for example: sudo rpm -ivh v93000_gio-2.1.0-el7.x86_64.rpm

The names of your installation package (package_filename) may be different for different versions. Use the name of the .rpm package that you have downloaded.

## Results

The GIO library API is installed on the V93000 system controller.

For the location of the shared library file and the related header file, see [Using the GIO library API from a C/C++ test application](<02.13.04_Using_the_GIO_library_API_from_a_C_C___test_application.md>).
