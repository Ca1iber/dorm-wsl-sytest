# SmartProd (0.1.0-17 with PDB 425)

The following table summarizes software changes including new features and enhancements in SmartProd 0.1.0-17 with PDB 425.

Changes and new features
 | Module  | Description |
 | FPGA class  | The class provides functions to execute FPGA Download Manager for monitoring FPGA versions of all testers; automatically upgrading or downgrading FPGA versions if required.  |   Note The FPGA class supports SmarTest 8 only.
