SmartProd is an external interface tool with a set of APIs.

You can use SmartProd API to create a client to monitor switch_version operations. With the SmartProd client, you can timely get notification when a switch_version operation has been performed between two SmarTest versions on the same host workstation.

## Installation

SmartProd is installed as part of SmarTest Platform Delta Bundle (PDB). It can also be installed by the command rpm -ivh v93000_smartprod-package_name through a SmartProd RPM package.

  Note SmartProd only supports RHEL7.x operating systems on SmarTest system controllers.

## Functional changes

- Introduced in SmarTest 7.10.0
