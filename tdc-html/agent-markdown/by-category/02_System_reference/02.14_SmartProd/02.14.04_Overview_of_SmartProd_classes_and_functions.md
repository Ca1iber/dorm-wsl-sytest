# Overview of SmartProd classes and functions

SmartProd has a set of classes and member functions. See the table below.

Overview of SmartProd classes and functions
 | Class  | Function  | Description |
 | FPGA  | fpgadlm()  | Execute the FPGA Download Manager. |
 | getInstance()  | Get an FPGA instance. |
 | SmartMonitor  | start()  | Start monitoring on SmarTest switch_version. |
 | stop()  | Terminate monitoring on SmarTest switch_version. |
 | consume()  | Consume switch_version events. |
 | SoftwareVersion  | installationPath()  | Hold the absolute path of a SmarTest version. |
 | isDefault()  | Indicate if the selected version is default or not.

1 indicates the SmarTest version is default at the moment. 0 indicates the SmarTest version is not default at the moment.

 |
 | version  | Hold the SmarTest version. |
 | TestCell  | getCurrentTesterVersion()  | Retrieve the current SmarTest version. |
 | getTesterVersion()  | Retrieve all installed SmarTest versions in a list. |

For more information about SmartProd classes and functions, see [SmartProd API reference](<02.14.05_SmartProd_API_reference.md>).

You can use these classes and member functions to create your own switch_version monitoring client. You can also implement SmartProd APIs to the program of some SmarTest tools, such as EM360, to allow the tool to get notified whenever a switch_version operation happens.

For a SmartProd client example, see [Creating a SmartProd client](<02.14.02_Creating_a_SmartProd_client.md>).
