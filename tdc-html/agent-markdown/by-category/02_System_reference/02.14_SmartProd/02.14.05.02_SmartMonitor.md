Starts to monitor test cell events.

When an event is received, the function [SmartMonitor::consume()](<02.14.05.02_SmartMonitor.md#a8b18a8a908bf65508bd9d5151b6424c3>) will be called back. This function will be blocked until [SmartMonitor::stop](<02.14.05.02_SmartMonitor.md#a86142729332f00492ac53851b1002716>) is called.

 ReturnsThe reference to the invoked [SmartMonitor](<02.14.05.02_SmartMonitor.md>) instance.

#### Example

In this example, monitor is an invoked [SmartMonitor](<02.14.05.02_SmartMonitor.md>) instance.

 MyMonitor monitor; monitor.start();    [](<>)
