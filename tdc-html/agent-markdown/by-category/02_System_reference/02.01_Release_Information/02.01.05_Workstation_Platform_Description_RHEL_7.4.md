# Workstation Platform Description - RHEL 7.4 - Revision 425.0 -

Document generation date : Thu Jul 29 11:44:00 2021 (2107291144)

SmarTest is the V93000 system software required to operate the V93000 family of semiconductor test systems. SmarTest requires a dedicated Redhat Enterprise Linux operating system RHEL 7.4 tested and provided by Advantest. Only these operating system versions and associated operating system and kernel patches provided by Advantest are approved for use wíth Advantest V93000 test systems. For installation instructions see "Installing SmarTest" or "Updating SmarTest" section in the "System Controller and Software Installation Guide Linux".

The Workstation platform consists of:

- the supported controller hardware
- the supported platform software which includes:

  - the operating system RHEL 7.4
  - the Platform Delta Bundle revision 425.0

## Z4G4 (Workstation bundle E7039PA/PC/PT)

- HP Z4G4, Intel Xeon W-2145 3.7 2666MHz 11 8C CPU
- Memory configuration

  - 64GB (2x32GB) DDR4 2666 DIMM ECC Registered Memory; optional: 128GB, 256GB
  - Two HP Z Turbo Drive M.2 1TB SSD

- NVIDIA Quadro P400 2GB (3)mDP GFX graphics adapter (supports 3 displays)
- HP i350-T2 PCIe Dual Port Gigabit NIC
- 9.5 mm slim Blu-Ray writer
- USB keyboard
- USB scroll mouse

- Z4VM is not supported for V93000 SD tester systems.

## Red Hat RHEL 7.4 Operating System

- RHEL 7.4 is a 64-bit operating system
- RHEL 7.4 is the standard V93000 OS version starting with release 8.0.5_T
- RHEL 7.4 is recommended for upgrade of older RHEL 7 installations.
(see "Platform versions vs. SmarTest versions" for supported SmarTest revisions with RHEL 7.4)

Note: Install the operating system using the Advantest Linux Recovery DVD : E8000-13425

### Update : How to prepare my current operating system for latest SmarTest version

To use the latest SmarTest Revision you need to make sure your system controller :

-  Is based on RHEL 7.4 and
-  was installed with Advantest Linux Recovery DVD (E8000-13424)
( see `/etc/PDB-release-workstation` on your controller for this information )

 To update a virtualized system (Z640VM and later) you must update the VM before the HV to avoid blank screens on RHEL7 VM!

There are two ways to update your old platform. One is to use a Recovery DVD and the second one is to use a Platform Delta Bundle.

- Use the latest V93000 Linux Recovery DVD RHEL 7.4 (E8000-13425.0) and execute the update_platform.sh script.
- Use the latest Platform Delta Bundle version : 425.0 and update your platform with the command smart-install-3.
 For examples on how to use smart-install-3, see Topic 354177 in the TDC.
 Note: See Topic 353526 in the TDC on how to install smart-install-3

See also the "Updating SmarTest" section in the "System Controller and Software Installation Guide Linux".
