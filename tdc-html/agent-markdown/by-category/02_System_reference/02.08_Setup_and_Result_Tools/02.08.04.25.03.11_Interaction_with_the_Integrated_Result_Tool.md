# Interaction with the Integrated Result Tool

After you [transfer a shmoo test from the Shmoo Tool to a testflow](<02.08.04.25.03.10.02_Transferring_the_shmoo_tests_from_the_Shmoo_Tool_to_testflows.md>), you can use [the Integrated Result Tool](<02.08.04.13.03.04.08_Shmoo_view.md>) to view the shmoo plots generated by this shmoo test.

## About this task

Displays shmoo plots of shmoo test suites or testflows.

## Before you begin

- A testflow is loaded with full setups and is opened with both the [Flow Sequence Editor](<02.08.04.32.03.02_Flow_Sequence_Editor.md>) and [Flow Data Editor](<02.08.04.32.03_Elements_of_the_Testflow_Tool.md>).
- [Set up a shmoo test in the Shmoo Tool](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>).

## Procedure

-  [Transfer the shmoo test from the Shmoo Tool to the testflow](<02.08.04.25.03.10.02_Transferring_the_shmoo_tests_from_the_Shmoo_Tool_to_testflows.md>) as a new test suite.
-  In the [Flow Sequence Editor](<02.08.04.32.03.02_Flow_Sequence_Editor.md>), enable the following test suite flags:

  - Output on pass
  - Output on fail
  - Pass value
  - Fail value
  - Per pin on pass
  - Per pin on fail

-  In the [Flow Data Editor](<02.08.04.32.03_Elements_of_the_Testflow_Tool.md>), on the Flags tab, enable the log_events_enable system flag.
-  [Open the Integrated Result Tool](<02.08.04.13.02.01_Opening_the_Integrated_Result_Tool.md>).
-  Run this shmoo test suite or the whole testflow.
-  In the test summary window of the Integrated Result Tool, right-click the shmoo test suite name and select Show In > Shmoo View.

## Results

The shmoo plot is displayed in the [shmoo view of the Integrated Result Tool](<02.08.04.13.03.04.08_Shmoo_view.md>).
