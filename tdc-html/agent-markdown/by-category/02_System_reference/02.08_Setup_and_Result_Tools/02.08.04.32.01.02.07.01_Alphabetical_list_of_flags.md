# Alphabetical list of flags

The testflow tool provides access to a range of flags that control numerous aspects of testflow execution.

The state of all flags is stored in the [Testflow file](<02.08.04.32.03.05_Testflow_file.md>). SmarTest performs a range check of parameters when loading the file. For more information, refer to [Range check of parameters](<02.08.04.32.03.05_Testflow_file.md#_43086__s_Range_check_of_parameters>) in [Testflow file](<02.08.04.32.03.05_Testflow_file.md>).

The following table lists the flags available in the testflow tool in alphabetical order. The first column shows two names for the flags:

- The upper value is the name that is shown in the [Flags page](<02.08.04.32.03.01.06_Flags_page.md>) or in the [Test suite properties view](<02.08.04.32.03.04_Testflow_Properties_view.md#_99279__s_Test_suite_properties_view>) of the [Testflow Tool](<02.08.04.32_Testflow_Tool.md>).
- The lower value is the keyword as it is stored in the [Testflow file](<02.08.04.32.03.05_Testflow_file.md>).
-

Values on and off in the description are for the GUI. These values correspond to 1 and 0 in the testflow file or APIs. The same applies to other labels of the GUI drop-down lists: These labels are represented as integer values in the testflow file or APIs.

- Integer values in brackets are the values used by the testflow file or APIs.
