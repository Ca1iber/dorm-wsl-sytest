# Calculating yields for modified limits

The Yield Calculator dialog lets you determine how changing the limits for a test would affect the yields that the test would have produced.

## About this task

Perform these calculations to determine the yields for a given set of limits.

## Before you begin

[Load the data log](<02.08.04.13.02.02.01_Loading_and_unloading_data_log_files.md>) of the test for which you want to perform the calculation and [open it](<02.08.04.13.02.02.02_Opening_a_data_log_for_examination.md>).

## Procedure

-  In the [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>) of the data navigation view of the test, right-click the row that you want to analyze and choose Yield Calculator from the context menu.

The Yield Calculator dialog opens.

  ![Yield Calculator](<../../../../raw/143030.png>)
-  Enter the new upper and lower limit values in the two white fields of the dialog.
-  Click Calculate Yield.

## Results

In the Test Count column at the right of the dialog, the numbers of devices that would have tested over the new upper limit, between the new limits, and below the new lower limit are displayed. In addition, the yield that would result from the new limits is displayed at the bottom right of the dialog.

## What to do next

When you have found the limits that work best for your situation, you can modify the test setup to use those limits.
