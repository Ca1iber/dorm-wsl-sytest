# Load capacitance connected to the DC Scale DPS128/DPS64

For the DPS128/DPS64, SmarTest automatically sets the performance range considering the value of the load capacitor(s) connected to the DUT power pin on the DUT board.

Entering a capacitance value in the C[uF] column of the [DPS Pins editor](<02.08.04.18.03.01.03_DPS_Pins_editor.md>) has an effect for a DPS128/DPS164 channel in DPS mode.

For DPS128/DPS64 channels in PMU mode (SIG), you optionally can set the load capacitance in the [DPS128/DPS64 hardware view](<../02.05_Test_Head_Cards/02.05.05.01.04_DPS128____PS64_hardware_overview.md>) in the LoadCap field and with the [SPMU_PIN_TASK.loadCap()](<../02.07_Test_Method_Reference/02.07.04.01.234.01.19_SPMU_PIN_TASK.loadCap.md>) test method API function.

For the supported load capacitance ranges see  [Load capacitance range](<../02.02_Specifications/02.02.05.01_DC_Scale_DPS128_Device_Power_Supply__E8023CS_E8023CSH__-_high_current_sp.md#_141967__s_Other_specs>) in [DPS128-HC specifications](<../02.02_Specifications/02.02.05.01_DC_Scale_DPS128_Device_Power_Supply__E8023CS_E8023CSH__-_high_current_sp.md>).
