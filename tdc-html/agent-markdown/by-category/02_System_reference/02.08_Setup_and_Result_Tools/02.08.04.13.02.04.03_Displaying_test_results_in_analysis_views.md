# Displaying test results in analysis views

Test results are displayed as analysis views by selecting summary rows in data navigation views and choosing the desired view type from the shortcut menu.

## About this task

Display numeric data log summaries as graphs or tables to more easily detect interesting or problematic data points or get a global overview of the results.

## Before you begin

[Open a data log](<02.08.04.13.02.02.02_Opening_a_data_log_for_examination.md>).

## Procedures

### Opening a result graphs for selected test results

- In the data navigation view of the data log, select the rows that you want to display in an analysis view.

Depending on the type of view, different selections are required or possible:

  - [Trend chart](<02.08.04.13.03.04.01_Trend_chart_view.md>): One or more rows in a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>).

If all rows share the same test suite, test method, and test, the limits are displayed in the graph.

  - [Histogram](<02.08.04.13.03.04.02_Histogram_view.md>): One or more rows in a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>). All rows must share the same test suite, test method, and test.

If all rows share the same test suite, test method, and test, the limits are displayed in the graph.

  - [Probability chart](<02.08.04.13.03.04.03_Probability_chart_view.md>): One or more rows in a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>). All rows must share the same test suite, test method, and test.

If all rows share the same test suite, test method, and test, the limits are displayed in the graph.

  - [Box chart](<02.08.04.13.03.04.04_Box_chart_view.md>): One or more rows in a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>). All rows must share the same test suite, test method, and test.

If all rows share the same test suite, test method, and test, the limits are displayed in the graph.

  - [Scatter chart](<02.08.04.13.03.04.05_Scatter_chart_view.md>): Two rows in a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>). Both rows must share the same device. Additional conditions apply, as described in [Scatter chart view](<02.08.04.13.03.04.05_Scatter_chart_view.md>).
  - [Range chart](<02.08.04.13.03.04.05_Scatter_chart_view.md>) (special scatter chart mode): Three or more rows in a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>). (Or two rows, followed by clicking the Switch button in the scatter chart.)
  - [FFC Pareto chart](<02.08.04.13.03.04.06_FFC_Pareto_chart_view.md>): One row in a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>).
  - [Protocol Monitor view](<02.08.04.13.03.04.07_Protocol_Monitor_view.md>): One or more rows that contain test results with the type Protocol in a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>).
  - [Shmoo plot](<02.08.04.13.03.04.08_Shmoo_view.md>): One row that summarizes shmoo test results in a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>).

See the description of the various modes in [Shmoo graph modes](<02.08.04.13.03.04.08.01_Shmoo_graph_modes.md>) for details of the available shmoo variants.

Note that the data logs to be displayed as shmoo plots must have been created by SmarTest 7.2.0 or higher. The Integrated Result Tool cannot create shmoo plots from logs created with SmarTest 7.1.4 or earlier.

  - [Parametric wafer map](<02.08.04.13.03.04.09_Parametric_wafer_map_view.md>): One row in a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>).
  - [Scan view](<02.08.04.13.03.04.10_Scan_view.md>): One row that contains test results with the type Scan in a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>).
  - [Bin wafer map](<02.08.04.13.03.04.11_Bin_wafer_map_view.md>): One or more rows in a [Wafer summary tab](<02.08.04.13.03.02.02_Wafer_summary_tab.md>).

If an analysis view of the desired type is already open, the selection is automatically displayed in that view, unless the view is pinned as described below. If no unpinned view is open, you must open the chart view as described in the next step.

Note that there is a maximum number of rows that can be displayed in a chart at the same time. This number is set in the [Result Tool preferences](<02.08.04.13.03.05_Preference_settings_for_the_Integrated_Result_Tool.md>).

- Right-click the selected row and choose the desired view type from the Show In submenu of the shortcut menu.

The selected data is displayed as a view of the chosen type.

- For parametric wafer maps and shmoo plots: Right-click the chart and choose from the Accumulation submenu of the shortcut menu whether you want to display the minimum, mean, or maximum test result values in the chart.
- For shmoo plots: Right-click the chart and choose the pin whose results you want to display from the Pin submenu of the shortcut menu and the result type from the Result Types submenu.
- If you want to freeze the data displayed in the analysis view, click the Pin button ![Trend Chart view_Pin button](<../../../../raw/137362.png>) in the graph's toolbar.

By default, an analysis view always displays the current selection in the frontmost [data navigation view](<02.08.04.13.03.02_Data_navigation_views.md>). If the selection changes, the display in the view changes as well.

If you click the Pin button ![Trend Chart view_Pin button](<../../../../raw/137362.png>), this dynamic update is interrupted, and the analysis view continues to display the same data even if the selection in the summary tabs changes. Clicking the Link button ![Trend Chart view_Link button](<../../../../raw/137363.png>) unfreezes the update, and the display changes once again with the selection.

- If you are displaying the system data log stream in an analysis view, the view is by default not updated when new log entries arrive. if you want to enable dynamic updates, you can do so by choosing the appropriate shortcut menu commands:

  - In the [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>), choose Auto Update Chart.
  - In the [Wafer summary tab](<02.08.04.13.03.02.02_Wafer_summary_tab.md>), choose Auto Update Wafer Chart.

These commands do not apply to EDL or STDF data log files.

### Opening an additional graph for the same data

If you already display data in a graph and you would like an additional graph of the same type (in which later to display different data), click the New button ![Trend Chart view_New button](<../../../../raw/137364.png>) in the graph view.

## Results

The selected information form the summary tabs is displayed as a graph of the chosen type.
