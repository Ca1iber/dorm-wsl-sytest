# Connecting a floating test suite to the testflow

After adding a [Floating test suite](<02.08.04.32.01.02.01.03_Floating_test_suite.md>) on the Test suites page, you can run this test suite for debugging. When you finish debugging it, you can add it to the testflow sequence.

## Before you begin

Make sure that a floating test suite has been created.

## Procedure

-  In the Flow Sequence Editor, select an insertion point where you want to insert a floating test suite. Right-click and select Insert Floating Test Suite.

The Select Floating Test Suite window opens, which displays all the existing floating test suites.

  ![Select Floating Test Suite dialog](<../../../../raw/353727.png>)

An extended version of the window opens if the insertion point for the fail branch of a Run and Branch node is selected:

   ![Select Floating Test Suite dialog SD version](<../../../../raw/353733.png>)
-  Select the floating test suite you want to insert.
-  Choose the Insert Mode option, which allows you to insert the floating test suite itself or its copy.
-  Choose the Node Type option, which allows you to insert the floating test suite as Run node, Run and Branch node or as [Multibin SmartDisconnect test suite](<02.08.04.32.01.02.01.04_Multibin_SmartDisconnect_test_suite.md>).
-  Click OK.

## Results

If you select the Insert the test suite mode, the floating test suite is added to the testflow sequence.

If you select the Insert a copy of the test suite mode, a new test suite, which is the copy of the floating test suite, is added to the testflow sequence.
