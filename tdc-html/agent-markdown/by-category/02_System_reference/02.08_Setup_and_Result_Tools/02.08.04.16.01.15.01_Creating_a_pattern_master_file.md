# Creating a pattern master file

The pattern master file contains a list of file names and their paths. These define and reference the set of pattern files to be used for a testflow. The use of pattern master files gives you flexibility to organize your patterns.

## About this task

To create a pattern master file you use the New Pattern Setup wizard.

The [ASCII Interface](<../02.11_Data_Conversion_and_Bridges/02.11.02.01_Introduction_to_the_ASCII_Interface.md>) will also automatically generate a pattern master file containing a list of pattern files.

## Procedure

-  Open the New Pattern Setup wizard. You have the following options:

  - Click File > New > Pattern
  - In the Test Program Explorer, at the Pattern node, right-click and select New.

The New Pattern Setup wizard opens.

-  In the Name field, type the file name of the pattern master file.
-  In the Type field, select "Pattern Master File".

This deactivates the Location field. The default location of the pattern master file is the vectors folder of the current device.

-  Click Finish.

## Results

This creates the pattern master file in the vectors folder of the device directory. At this stage it contains only the header line:

```
hp93000,pattern_master_file,0.1
```

Working with the Pattern Explorer on your test setup will complete the pattern master file with paths and file names. For example:

```
hp93000,pattern_master_file,0.1

path:
  ../data/patterns_a

files:
  pattern1
  pattern2
  pattern3
  pattern4

path:
  ../data/patterns_b

files:
  pattern5
  pattern6
```

Note When adding comments to a pattern master file, start each comment line with "--" (2 times the minus sign).
