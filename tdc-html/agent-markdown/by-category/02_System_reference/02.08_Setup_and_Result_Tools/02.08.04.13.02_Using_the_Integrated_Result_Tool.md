#### Subtopics

You analyze data logs using the Integrated Result Tool by loading them into the tool, opening them in tabular views, and examining their underlying data or displaying the logs as a variety of graphs.

For details, see:

- [Opening the Integrated Result Tool](<02.08.04.13.02.01_Opening_the_Integrated_Result_Tool.md>)
- [Managing data logs](<02.08.04.13.02.02_Managing_data_logs.md>)

The result data stream is not saved to disc automatically. See [Saving the system data log stream](<02.08.04.13.02.02.05_Saving_the_system_data_log_stream.md>).
