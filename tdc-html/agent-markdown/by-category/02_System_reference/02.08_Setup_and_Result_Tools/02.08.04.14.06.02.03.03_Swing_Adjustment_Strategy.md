# Swing Adjustment Strategy

In order to clarify the importance of a good strategy, an example is given below.

Suppose you have 3 timing sets each with 10 level sets. To adjust the swing for all possible permutations you need 30 timing sets, thus an additional 27 timing sets must be stored in the test system memory. In most cases you would not need all of them for your test and could easily save timing sets with little effort.

Select all the combinations of timing and level sets with mixed level signals for which you want to perform a measurement and adjust only their swings. Be aware of the fact that you are responsible for a suitable adjustment which exactly meets your test requirements.
