# In General

- An efficient way to capture a large number of samples is to use loops and REPEAT commands in the pattern.
- The number of the captured vectors can be an arbitrary value.Note In SmarTest earlier than 5.0.0, the number of the captured vectors must be an integer multiple of 64.
