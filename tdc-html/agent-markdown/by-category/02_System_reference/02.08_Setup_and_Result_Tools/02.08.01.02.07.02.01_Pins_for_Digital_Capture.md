# Pins for Digital Capture

The test system uses normal digital pins (also called digital channels) for data capturing. No additional capture hardware is required. This gives you the flexibility to perform data capturing at any available digital pin of the test system.

Any digital pin you define as an o or i/o pin in the pin configuration can later on be used for capturing of DUT output.

Pins to be used for data capturing need no further specifications in the pin configuration.

Which of the configured digital pins will later on be used as capture pins is defined in the capture settings, which are part of the pattern setup for digital capture. The pattern setup is described in [Setting up the Vectors](<02.08.01.02.07.02.04_Setting_up_the_Vectors.md>).

To make the rest of the setup easier, it is recommended that you create a pin group containing the pins on which you want to capture.
