# Task 5: Executing a Test and Obtaining the Results

#### Subtopics

- [Setting up flags](<02.08.01.01.05.01_Setting_up_flags.md>)
- [Test Debugging and Data Logging](<02.08.01.01.05.02_Test_Debugging_and_Data_Logging.md>)

- Build up a test, then execute the test using the [Testflow Tool](<02.08.04.32_Testflow_Tool.md>)

  -  Set up the system/testflow/testsuite flags.
  - Execute the test.

- Obtain the test results and debug the test using the [Testflow Tool](<02.08.04.32_Testflow_Tool.md>), [Timing Diagram Tool](<02.08.04.33_Timing_Diagram_Tool.md>), and [Error Map Tool](<02.08.04.08_Error_Map_Tool.md>).

  - Examine pass/fail results.
  - Obtain the digital operation using the Result Analysis tools such as Timing Diagram, Error Map, and so on.
  - If there are some bugs in the test, fix them and then execute it again.

## Functional changes

- Introduced before SmarTest 6.3.2
