The Integrated Result Tool includes several specialized views for viewing logged test results. The views are dynamically linked to the current selection in the frontmost [summary tab](<02.08.04.13.03.02_Data_navigation_views.md>).

Available graphs include:

- [Trend chart view](<02.08.04.13.03.04.01_Trend_chart_view.md>)

Trend charts are used to visualize how the test value varies over a series of tests.

- [Histogram view](<02.08.04.13.03.04.02_Histogram_view.md>)

Histograms display how the test results are distributed among devices - that is, how many devices fall into each result range.

- [Probability chart view](<02.08.04.13.03.04.03_Probability_chart_view.md>)

Probability charts display for each value in the measured range the probability that a result in the charted test was at or below this value.

- [Box chart view](<02.08.04.13.03.04.04_Box_chart_view.md>)

Box chart display the statistical distribution of the values in one ore more sets of test results. They visualize the ranges in which the results deviate form the mean.

- [Scatter chart view](<02.08.04.13.03.04.05_Scatter_chart_view.md>)

Scatter charts display one test value on the x-axis and another on the y-axis, visualizing relationships between the two values. They can also display the relationship of means, minimums, and maximums between a larger number of test series.

- [FFC Pareto chart view](<02.08.04.13.03.04.06_FFC_Pareto_chart_view.md>)

FFC Pareto charts display the most frequent first failing cycles as bar graphs.

- [FFC Pareto chart view](<02.08.04.13.03.04.06_FFC_Pareto_chart_view.md>)

Protocol Monitor views display the transactions of Protocol tests as a table..

- [Shmoo view](<02.08.04.13.03.04.08_Shmoo_view.md>)

Shmoo views display the results of shmoo tests in a two-dimensional shmoo plot.

- [Parametric wafer map view](<02.08.04.13.03.04.09_Parametric_wafer_map_view.md>)

Parametric wafer maps display the distribution of good and bad dies on one or more wafers.

- [Scan view](<02.08.04.13.03.04.10_Scan_view.md>)

Scan views display a graphical overview of scan chain failures.

- [Bin wafer map view](<02.08.04.13.03.04.11_Bin_wafer_map_view.md>)

Bin wafer maps display the distribution of good and bad dies on one or more wafers.
