# Alias set

You can define multiple aliases for a single pin and organize the aliases for different pins into a set.

Complicated device, for example, SIP (System In Package) devices, can contain multiple cores in one package. Many different cores multiplex the same pins. You can use different pin aliases for different cores.

With the Pin Configuration Tool, you can create alias sets (see [Alias Set Editor](<02.08.04.18.03.04_Alias_Set_Editor.md>)) and use the pin aliases as pin group members.

The following files support pin aliases:

- Pin configuration file
- Level and timing equation setup file (see [Pin alias set (PIN_ALIAS_SET)](<02.08.04.14.02.03.05_Pin_alias_set__PIN_ALIAS_SET.md>))
- Pin configuration master file (see [Pin configuration master file](<02.08.04.18.05_Pin_configuration_master_file.md>))
- Setup files using setup APIs (analog control file, waveform file)
- Test method source file

Note that you cannot use aliases to [Define ports](<../02.06_Command_Reference/02.06.03.01.07_Defining_ports.md>), but they are supported for [Defining pin groups](<../02.06_Command_Reference/02.06.03.01.06_Defining_pin_groups.md>).

In the setup files (level equation setup file, timing equation setup file, setup files using APIs, and test method), except for the pin configuration file, use the pin alias by specifying:

```
pin_alias_set_name::pin_alias_name
```

The following tools support pin aliases:

- With the Timing Diagram Tool, the pin alises can be selected in the Define format window and the tool displays all these names. You can also mix the pin aliases and package pin names.
- With the Pattern Debug Tool, the pin aliases can be added to the layout of the Pattern Editor to display the pattern.
