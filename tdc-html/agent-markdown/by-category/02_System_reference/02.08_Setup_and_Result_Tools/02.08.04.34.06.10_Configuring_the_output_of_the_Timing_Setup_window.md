# Configuring the output of the Timing Setup window

#### Subtopics

- [Displaying the Timing Setup in Double Size](<02.08.04.34.06.10.01_Displaying_the_Timing_Setup_in_Double_Size.md>)
- [Getting a Hardcopy of the Timing Setup Window](<02.08.04.34.06.10.02_Getting_a_Hardcopy_of_the_Timing_Setup_Window.md>)

You can configure the output of the Timing Setup window in the following ways.

- Display the window in the standard size (the default)
- Display the window in double size
- Printout the current view of the window.
- Take a snapshot of the window and display it on the screen

## Functional changes

- Introduced before SmarTest 6.3.2
