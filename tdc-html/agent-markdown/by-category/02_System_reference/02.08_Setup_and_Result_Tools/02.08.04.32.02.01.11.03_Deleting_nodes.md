# Deleting nodes

## Before you begin

Make sure that a node has been inserted into the testflow.

Note To remove the Run and Branch node or [Flow control nodes](<02.08.04.32.01.02.02_Flow_control_nodes.md>), you must wide select them (see [Narrow selection and wide selection](<02.08.04.32.02.01.11.01_Narrow_selection_and_wide_selection.md>)).

## Procedure

-  In the Flow Sequence Editor, select one or more nodes (press Ctrl and then click) you want to delete.   Note

If the Run and Branch node or [Flow control node](<02.08.04.32.01.02.02_Flow_control_nodes.md>) is narrow selected, first press Ctrl and then left click to wide select them.

![Toogle narrow/wide selection](<../../../../raw/354678.png>)

-  Press delete.
-  The Confirm Delete window opens. Click OK.

![Delete Node](<../../../../raw/354676.png>)

If the selected node is a test suite node, you can turn it into a floating test suite by clicking Covert to floating in the Confirm Delete window.

 Note The Run and Branch node and Run node can only be deleted in the Flow Sequencer Editor. They cannot be removed in the Test Suites page of the Flow Data Editor. In this page, you can delete the floating test suite and special test suite.

## Results

The node and all its subbranches are removed from the testflow.

## What to do next

Save the testflow.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.2: You can delete the testflow node in the Flow Sequence Editor.
- SmarTest 6.5.3: In the Flow Sequencer Editor, you must wide select the Run and Branch node and flow control nodes to delete them.
- SmarTest 6.5.3: In the Flow Data Editor, the normal test suites cannot be removed. You can only delete the floating test suite and special test suite.
