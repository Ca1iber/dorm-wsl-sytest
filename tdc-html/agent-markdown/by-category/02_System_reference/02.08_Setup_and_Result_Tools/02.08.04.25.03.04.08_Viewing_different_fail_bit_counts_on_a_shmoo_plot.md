# Viewing different fail bit counts on a shmoo plot

## About this task

Note The fail bit count shmoo is available only for MTP.

In the Shmoo Tool, when you [set up a fail bit count shmoo test](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>) with the [MTP_FailBitCountShmoo.Execute](<../02.12_Memory_Test_Plus_7.10.2/02.12.02.05.06.02_Fail_bit_count_shmoo_test_method.md>) test method, if you have selected multiple [fail bit count test modes](<02.08.04.25.03.02.02_Test_modes.md>) in the testMode field, you can view different types of fail bit counts on the shmoo plot after execution.

## Before you begin

- Make sure the MTP software is installed.
- Make sure the "debug_mode" testflow flag is set to 2, so that the FBC results are shown in the Shmoo Tool.
- [Set up a fail bit count shmoo test in the Shmoo Tool](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>). Or, [transfer a fail bit count shmoo test suite to the Shmoo Tool](<02.08.04.25.03.10.03_Transferring_test_suites_to_the_Shmoo_Tool.md>). Both the two manners use the MTP_FailBitCountShmoo.Execute test method.

Make sure, for the testMode parameter, you have selected multiple [fail bit count test modes](<02.08.04.25.03.02.02_Test_modes.md>).

- [Execute the shmoo test in the Shmoo Tool](<02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>).

## Procedure

-  In the editor viewer, right-click the shmoo plot and select Test Modes.

A shortcut menu opens listing the available fail bit count types:

  - fail bit count on device: Appears if you have selected fail bit count on device in the testMode filed during [setting](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>).
  - fail bit count on bank-0, fail bit count on bank-1, ..., until fail bit count on bank-N (N represents the last bank of the memory DUT):

Appear if you have selected fail bit count per bank in the testMode filed during [setting](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>).

  - fail bit count on dq-0, fail bit count on dq-1, ..., until fail bit count on dq-N, (N represents the last dq pin of a memory DUT):

Appear if you have selected fail bit count per dq in the testMode filed during [setting](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>).

-  Select a desired fail bit count type.

## Results

The number of the fail bits either for the whole memory DUT, or for the specified bank, or for the specified dq pin is displayed on each shmoo cell.
