# Shmoo graph modes

The display of shmoo graphs in the Integrated Result Tool varies according to the result type chosen and by single or overlay shmoo plot.

You select the result type displayed from the Test Modes submenu of the shortcut menu. The mode is determined automatically, as described below in Single mode and overlay mode.

## Single mode and overlay mode

A shmoo graph always displays the results of one selected row in a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>). Whether the graph is displayed in single or overlay mode depends on the data underlying the test summary:

- Single mode: If only one row is displayed in the [raw data view](<02.08.04.13.03.03.01_Raw_data_views.md>) when the test summary row is selected or if multiple rows are displayed but only one is selected, the shmoo graph is displayed in single mode. (For more information on selecting and deselecting rows in the raw data view, see [Excluding data from evaluation](<02.08.04.13.02.04.02_Excluding_data_from_evaluation.md>).)
- Overlay mode: In all other cases (that is, if the raw data view for the selected test summary row contains at least two selected raw data rows), the shmoo graph is displayed in overlay mode.

An empty plot is displayed if either the selected row in the test summary tab does not contain shmoo test result data, or if the row contains raw data for more than one shmoo test, but these tests do not all have the x,y-dimensions (for example, if one 6x6 and one 3x3 shmoo test are selected).

## Pass/fail data

When displaying pass/fail data, the shmoo graph shades the cells by the percentage of shmoo tests that have a pass result at this location. (In single mode, there are only two possibilities - pass and fail - with no intermediate percentages.)

If text in cells is activated in the [preferences](<02.08.04.13.03.05.16_Shmoo_preference_settings.md>), each cell shows the percentage of failed tests.

## Cycle error count and edge error count data

When displaying fail count data, the shmoo graph shows:

- In single mode: Cells are shaded by the number of fails in the test they represent.
- In overlay mode: This is similar to single mode, but instead of showing the fails from one test, a cell shows the minimum, mean, or maximum number of fails in this location in all overlaid shmoo tests, the total number of fails from all tests combined. (Which value is shown can be configured using the Accumulation shortcut menu submenu; the default is showing mean values.)

In both modes, if text in cells is activated in the [preferences](<02.08.04.13.03.05.16_Shmoo_preference_settings.md>), each cell shows the percentage of failed tests.

## First failing cycle and first failing vector data

When first failing cycles or vectors, the shmoo graph shows:

- In single mode: Each first failing cycle or vector is assigned a color (red for the ones that occur most often) and a cell in the graph is colored according to the cycle or vector in which the first fail in this test occurred.

For example, if vector 43 is assigned the color orange, all cells in which the first fail occurred in vector 43 are colored orange.

- In overlay mode: This is similar to single mode, but instead of showing the value from one test, a cell shows:

  - Min: The earliest cycle or vector where a first fail occurred in any of the overlaid tests.
  - Max: The latest cycle or vector where a first fail occurred.
  - Most frequent failing cycle/vector: The cycle or vector where the first fail occurred most frequently (when all overlaid tests are considered together).

Each cell is colored according to the number of first fails that occurred in the displayed cycle or vector, with red representing the most fails, yellow the fewest, and green a pass result in all overlays.

In both modes, the legend indicates which color represents which cycle or vector. Because the colors are assigned dynamically depending on the number of first fails in a cycle or vector, the assignment of colors to cycles or vector can change from one test execution to the next.

If text in cells is activated in the [preferences](<02.08.04.13.03.05.16_Shmoo_preference_settings.md>), each cell shows the number of the cycle or vector it represents.

## Value data

When (user-defined) value result data is displayed, the shmoo graph shows:

- In single mode: Cells are shaded by the result value they represent.
- In overlay mode: This is similar to single mode, but instead of showing the value from one test, a cell shows the minimum, mean, or maximum value from all overlaid shmoo tests. (Which value is shown can be configured using the Accumulation shortcut menu submenu; the default is showing mean values.)

In both modes, if text in cells is activated in the [preferences](<02.08.04.13.03.05.16_Shmoo_preference_settings.md>), each cell shows the value it represents.
