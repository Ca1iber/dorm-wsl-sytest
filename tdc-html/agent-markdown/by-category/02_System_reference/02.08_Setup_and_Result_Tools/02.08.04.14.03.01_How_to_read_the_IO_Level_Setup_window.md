# How to read the IO Level Setup window

The I/O levels in this setup window display the high- and low-logic threshold levels for the DUT input and output pins. The power-on default values are a set of levels compatible with the device technology that you selected when you created the device directory. See [Equation based level setup](<02.08.04.14.02_Equation_based_level_setup.md>), on how to change these defaults.

  ![Level Setup window displaying I/O pins](<../../../../raw/116503.png>)

## pin/group name and pin type

The first two columns pin/group name and pin type show the data you define in the Pin Configuration window, you cannot edit these columns from the Level Setup window. However, you can use the pin/group name column to search for a pin (if you have a long list of pins), as described in [Pin configuration tool](<02.08.04.18_Pin_configuration_tool.md>).

Inputs to the DUT are indicated by the type i, and outputs are indicated by o.

## level low and level high

The two columns level low and level high show the drive levels for input pins and the receive thresholds for the output pins. The levels are normally defined in volts (V) but are to be defined in milliampere (mA) if a current comparator like hrc is selected in column HR mode.

## termination

 The termination panel shows the selected termination mode for device output pins, and the output part for bidirectional pins. The power-on default is off to indicate that none of the available modes have been activated. The remaining columns remain empty until the termination mode is set.

An incomplete selection of the available modes:

- Output pins:

  - off
  - load
  - term

- Bidirectional pins:

  - off
  - high
  - low
  - load
  - term

Refer to [TERM, TERM? - (TERMination mode)](<../02.06_Command_Reference/02.06.02.02.257_TERM__TERM__-__TERMination_mode.md>) for a complete definition of the available termination modes.

The termination panel shows also the settings for the active load if enabled. The diagram below shows the principle of the active load circuitry that is connected to each of the digital pins.

  ![Simplified Active Load Circuit](<../../../../raw/25798.png>)  This circuit will source or sink current to the pin depending on the relationship between the commutation voltage that you set and the voltage at the DUT pin:

- VDUT < Vcommutation: The active load will source the current Isource.
- VDUT > Vcommutation: The active load will sink the current Isink.
- VDUT = Vcommutation: This condition is only possible if the active load sees an 'open' end, for instance if the pin is a high Z output pin. In this case, no current would flow.

## clamp

Clamping is used to smooth the output signal of the device. Peaks generated by reflections of the signal can be limited by specifying the clamp voltage levels (vch = voltage clamp high; vcl = voltage clamp low). The clamp panel shows the clamp mode and the two clamp voltages vcl and vch.

## range

The range column shows the drive range or the receive / threshold range. The value is to be defined in V (Volts).

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.4.0: New columns "HR mode" and "range" .
