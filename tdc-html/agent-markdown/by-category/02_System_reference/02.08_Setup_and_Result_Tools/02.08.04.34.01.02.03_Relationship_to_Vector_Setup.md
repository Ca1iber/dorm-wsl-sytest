# Relationship to Vector Setup

In the Vector Setup the first waveform of a device cycle is called the Initial Vector. It is specified there by the device cycle Name. The continuation waveforms, if any, are called Continuation Vectors. These are marked in the Vector Setup with a "c". Thus a device cycle containing, say, four waveforms has one Initial Vector and three Continuation Vectors. The separation into initial and continuation vectors is necessary in order to allow interpretation of device cycles by the Vector Setup.
