# Adding a New Spec/Variable

- From within the Timing or Level Setup, choose edit equations from the Select menu.
- Add the new specs/variables - in the SPEC section - in all desired equation sets (EQNSET).
- When you have made your changes, download them to firmware by clicking Download.
- In the Spec Tool main window, choose Upload from the File menu.

The new specs now appear in the Spec Tool table, with initial values set to zero.

- Change the values of these specs as necessary, as described in [Changing Spec Values](<02.08.04.30.02.14_Changing_Spec_Values.md>).
- If necessary perform a sort, and download these settings to firmware.

## Functional changes

- Introduced before SmarTest 6.3.2
