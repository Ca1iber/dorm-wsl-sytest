# PPSG operation

The Per-Pin Signal Generator (PPSG) generates specific types of regular analog waveforms as digital bit streams using pulse-width modulation. It also generates the required timings and levels.

To operate the tool, you enter the required specifications for the desired signal (see for details).

The tool then checks the values for validity. If it finds all values valid, it uses pulse-width modulation (PWM) to calculate the required pattern, pin and port information, timing and levels, and outputs all as a STIL file.

It then triggers STIL Reader (which must be installed and properly licensed) to translate this STIL file to a V93000 test program containing one test suite with the pattern and primaries.

This test suite can be integrated into existing test programs either manually or in an automated way using SmarTest Program Manager.

The test suite sends a digital pattern to the low-pass filter on the DUT board, which converts it to an analog signal that is sent to the DUT. The DUT, in turn, converts the analog signal into a digital output signal that you can test as usual.
