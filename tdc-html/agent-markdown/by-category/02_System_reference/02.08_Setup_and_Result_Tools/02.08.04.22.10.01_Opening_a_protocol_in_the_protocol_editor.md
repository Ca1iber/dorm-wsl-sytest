# Opening a protocol in the protocol editor

## About this task

This task describes how to load a protocol into the protocol editor.

## Before you begin

Ensure the protocol to open is loaded into the test program explorer. Refer to [Loading a single setup component](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02.01.01_Loading_a_single_setup_component.md>).

## Procedure

-  Select the protocol to open in the test program explorer.
-  Double-click that protocol.

## Results

The protocol editor opens and displays the content of the protocol you have chosen.
