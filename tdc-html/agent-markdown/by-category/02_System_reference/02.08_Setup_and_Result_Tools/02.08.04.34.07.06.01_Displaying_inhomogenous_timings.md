# Displaying inhomogenous timings

The display of the device cycles in the Device Cycle Edit area presupposes that the timing is homogenous in the following sense:

- All device cycles must be based on the same period length.
- The same device cycles must be defined for all pins in a pin group.
- The definitions of these device cycles must be identical for all pins of the group.

The Timing Setup tool responds to violations of these requirements as follows:

## First case

The period of a pin is different from the global period as defined in the equation set / waveform set. Then the timing setup tool does not display any device cycle for this pin. Instead, it displays the code ?P? to indicate that this pin has a different period length.

## Second case

A global row is defined for a pin group in the display format, and a device cycle for this group is inhomogenous, that is, not defined for all pins of the group or defined differently for different pins. Here two cases must be distinguished:

- If you select such a device cycle for the global row, the timing setup tool will write an error message to the report window, and the previously displayed device cycle or code will be shown again.
- If the currently displayed device cycle becomes inhomogenous because of a timing switch or a change in the current wavetable / waveform set, then the timing setup tool will display the code ?W? in the global row to indicate that the device cycle is inhomogenous within the group, and will also write an error message to the report window.
