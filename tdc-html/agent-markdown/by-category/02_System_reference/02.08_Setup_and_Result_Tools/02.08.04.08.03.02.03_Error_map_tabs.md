# Error map tabs

#### Subtopics

- [Overview tab](<02.08.04.08.03.02.03.01_Overview_tab.md>)
- [Cycles tab](<02.08.04.08.03.02.03.02_Cycles_tab.md>)
- [Edges tab](<02.08.04.08.03.02.03.03_Edges_tab.md>)
- [Per Pin tab](<02.08.04.08.03.02.03.04_Per_Pin_tab.md>)

The Error Map tool (see the figure below) consist of the following tabs:

- [Overview](<02.08.04.08.03.02.03.01_Overview_tab.md>)
- [Cycles](<02.08.04.08.03.02.03.02_Cycles_tab.md>)
- [Edges](<02.08.04.08.03.02.03.03_Edges_tab.md>)

The error map tabs present the errors of a particular test setup on a different level of detail. The edge view is only available if the result granularity is on the edge level. The errors are displayed as red marked cells in three different tabs.

The Error Map tool allows you to analyze an 8K/2K section of the test in more detail via the [Detailed error map](<02.08.04.08.01.01_Detailed_error_map.md>).

For detailed error information per pin, the Error Map Tool provides a [Per Pin tab](<02.08.04.08.03.02.03.04_Per_Pin_tab.md>).
