# Test modes

In the Shmoo Tool, the test modes selected in the testMode field during [settings](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>) determine what kind of results will be displayed on the shmoo plots.

The test modes are different between you have selected the [Shmoo](<../02.07_Test_Method_Reference/02.07.05.01.09_Shmoo.md>) test method and the [MTP_FailBitCountShmoo.Execute](<../02.12_Memory_Test_Plus_7.10.2/02.12.02.05.06.02_Fail_bit_count_shmoo_test_method.md>) test method.

## Test modes for the ac_tml.AcTest.shmoo

- pass/fail: (default) Displays either PASS or FAIL on shmoo cells of the shmoo plots.

Do select this mode for shmoo over multiple test suites, which will display the Pass/Fail of all test suites tested at shmoo cells:

  - Pass indicates all test suites are pass at the tested cell.
  - Fail indicates at least one test suite is failed at the tested cell.

- first failing cycle (used only for functional tests): Displays the first failing cycle number on every shmoo cell of the shmoo plot.
- first failing vector (used only for functional tests): Displays the first failing vector number on every shmoo cell of the shmoo plots.
- cycle error count (used only for functional tests): Displays the number of the total failed cycles on every shmoo cell of the shmoo plots.
- edge error count (used only for functional tests): Displays the number of the total failed edges on every shmoo cell of the shmoo plots.
- user defined measurement: (Used only for shmoo over a test suite and for customized shmoo test) Displays an interested test result of a shmooed test suite on every shmoo cell of the shmoo plot.

To define this result, use the [judgeAndLog](<../02.07_Test_Method_Reference/02.07.04.01.244_TESTSET.md>) API or the [SHMOO_RESULT](<../02.07_Test_Method_Reference/02.07.04.01.227_SHMOO_RESULT.md>) API in the test method code of the shmooed test suite. For details, see [Viewing the test results of a test suite on the shmoo plot](<02.08.04.25.03.04.05_Viewing_the_test_results_of_a_test_suite_on_the_shmoo_plot.md>).

## Test modes for the MTP_FailBitCountShmoo.Execute test method

- fail bit count on device (default): Displays the number of failing bits of an entire memory DUT on every shmoo cell of the shmoo plots.
- fail bit count per bank: Displays the number of failing bits of a bank for a memory DUT on every shmoo cell of the shmoo plots.

Once you have selected this type, you can view the shmoo plot of any bank. The manner is you right-click the shmoo plot and select Test Modes. Then, in the opened shortcut menu, select a bank.

- fail bit count per dq: Displays the number of failing bits of a dq pin (IO data bit) for a memory DUT on every shmoo cell of the shmoo plots.

Once you have selected this type, you can view the shmoo plot of any dq pin. The manner is you right-click shmoo plot and select Test Modes. Then, in the opened shortcut menu, select a dq bit.

Note You can select multiple test modes in the testMode field. To view different shmoo plots of different test modes, see [Viewing different types of results on a shmoo plot](<02.08.04.25.03.04.04_Viewing_different_types_of_results_on_a_shmoo_plot.md>).
