# Creating a "One-Shot" high resolution diagram

- Scroll to the cycles that you want to examine. If necessary, reduce the number of cycles being displayed (using the Cycles edit box) so that just the cycles you need to examine are in the display.
- Click the high res button in the Timing Diagram window.

The cycles in the display are now shown in high resolution.
