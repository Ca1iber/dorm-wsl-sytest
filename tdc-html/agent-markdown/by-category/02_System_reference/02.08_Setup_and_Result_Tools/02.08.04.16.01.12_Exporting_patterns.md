# Exporting patterns

The pattern export function allows you to export any pattern of the MAIN type in the ASCII Interface format or in the STIL (Standard Test Interface Language) format. The pattern export uses either the ASCII Interface tool b2a (binary to ascii conversion), or the STIL tool bin2stil (binary to STIL) respectively.

## About this task

The pattern is translated using the [STATEMAP section](<../02.11_Data_Conversion_and_Bridges/02.11.02.04.01.01_STATEMAP_section_and_pattern_conversion.md>) of the pattern's associated base wavetable in the timing file.

You can export (and import) patterns using various SmarTest user interface areas: via the File menu, via the Test Program Explorer, and via the Pattern Explorer. The result will be the same.

The STIL export requires the bin2stil tool of the SmarTest Data Link (STDL) tool suite.

## Before you begin

To export a pattern,

- it must be loaded in the test system,
- it must be of the MAIN type
- the pin configuration must be loaded, and
- the timing file that contains the base wavetable of the pattern must be loaded.

The pattern export also requires a [STATEMAP section](<../02.11_Data_Conversion_and_Bridges/02.11.02.04.01.01_STATEMAP_section_and_pattern_conversion.md>) in the pattern's associated base wavetable (timing file).

Note The STATEMAP sections must be consistent in the sense that all the waveform DC/DC power units in one vector row must be associated with the same (possibly the empty) selector for all pins. This is because the selector name will be used as the ASCII device cycle name in the created *.avc file. This requirement is always warranted if the STATEMAP section was generated by the ASCII Interface, but STATEMAP sections that were created manually may be in conflict with this requirement.

## Procedure

-  To start an export operation do one of the following:

  - On the main menu bar, click File > Export > 93000 > Pattern.
  - In the Test Program Explorer, right-click the pattern icon and select Export.
  - In the Pattern Explorer, right-click a pattern and select Export.

-  For an ASCII Interface export:

In the dialog box, the Ascii Converter option is already preselected, click Next.

For an STIL export:

In the dialog box, select the Stil Converter option and click Next.

-  In the Target Location field define the target directory. You may click the Browse button to select a directory.
-  In the Pattern field type a pattern name or use the Pattern field's ![Selection box button](<../../../../raw/121799.png>) selection box button. The selection box lists all patterns that can be exported.

When exporting directly from the Pattern Explorer (as opposed to the two other starting points) the pattern name is already preselected.

The dialog box also shows the pin configuration and timing files used.

-  To complete the export click Finish.

## Results

ASCII Interface export:

Exporting a pattern to the Ascii Interface format creates the following files:

- <pattern_name>.avc (ASCII vector file)
- <pattern_name>.tmf (timing map file)
- <pattern_name>.wtb

This file contains only the name of the base wavetable of the exported pattern. It is not used by the ASCII Interface, but needed for a re-import.

A log file is created too: <pattern_name>.b2alog

If a translation error occurs, the log file opens automatically.

STIL export:

Exporting a pattern to the STIL format creates the following files:

- <pattern_name>.pat.stil

A log file is created too: <pattern_name>.stilExplog

If a translation error occurs, the log file opens automatically .
