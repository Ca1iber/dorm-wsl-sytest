# Configuring value categories in result graphs

In several types of result graphs, you can specify how the individual results are grouped into categories.

## About this task

Configure the value categories to display the underlying data more finely or more coarsely differentiated.

## Before you begin

[Open a result graph](<02.08.04.13.02.04.03_Displaying_test_results_in_analysis_views.md>) of the desired type.

## Procedures

### Configuring the number of categories charted on an axis

This procedure applies to [histograms](<02.08.04.13.03.04.02_Histogram_view.md>) and [FFC Pareto](<02.08.04.13.03.04.06_FFC_Pareto_chart_view.md>) charts.

- Click the Properties button ![Trend Chart view_Properties button](<../../../../raw/136931.png>) on the chart's toolbar or choose Properties from the context menu.

The chart's properties dialog opens.

- Click the Scales tab.
- In the Bin Count field, enter the desired number of categories.
- Click OK.

In the histogram, the test results are sorted into the specified number of categories. In the FFC Pareto chart, the specified number of first failing cycles are displayed. (The chart displays the cycles that had the greatest numbers of first fails.)

You can also set the number of categories from submenus of the context menus in these charts: the [Bin Count](<02.08.04.13.03.04.02_Histogram_view.md>)[ submenu in a histogram](<02.08.04.13.03.04.02_Histogram_view.md>) and the [Failing Cycle Axis](<02.08.04.13.03.04.06_FFC_Pareto_chart_view.md>)[ submenu in a FFC Pareto chart](<02.08.04.13.03.04.06_FFC_Pareto_chart_view.md>).

### Configuring the value categories in a parametric wafer map

- Click the Properties button ![Trend Chart view_Properties button](<../../../../raw/136931.png>) on the chart's toolbar or choose Properties from the context menu.

The [chart's properties dialog](<02.08.04.13.03.04.08.02_Shmoo_view_properties_in_the_result_tool.md>) opens.

- Click the Classes tab.
- In the Minimum and Maximum fields, enter the lower and upper limits of the value range that you want to divide into classes.
- In the Class Count field, enter the desired number of classes.

All classes have the same size; you can see in the Class Width field how big the range of each class is.

- Click OK.

The cells in the parametric wafer map are assigned to the classes and colored according to the new specifications.

## Results

The chart display is updated according to your settings.
