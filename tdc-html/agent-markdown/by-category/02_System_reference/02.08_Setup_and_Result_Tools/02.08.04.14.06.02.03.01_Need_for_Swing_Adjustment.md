# Need for Swing Adjustment

The following cases are conceivable:

- All input pins of your device have a swing of 3V.

You already have ideal test conditions. No further adjustment is needed.

- All input pins of your device have the same swing, other than 3V.

This has no impact for measurements on the input side (i.e. setup time, input data hold time), but will lead to implications while performing input-output measurements (i.e. propagation delay time). To eliminate the time shift on the input side you have to create a timing setup with an appropriate swing adjustment.

- Your device has mixed levels.

A swing adjustment is reasonable in most cases. Nevertheless, there might be some exceptions. For example an adjustment is not needed for pins which are asynchronously related, pins with no defined timing relationship for example. A further example is static pins: as they are not involved in measurements their swing is irrelevant.
