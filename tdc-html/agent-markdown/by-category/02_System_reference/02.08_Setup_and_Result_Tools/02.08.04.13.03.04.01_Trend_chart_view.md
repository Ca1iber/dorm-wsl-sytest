# Trend chart view

#### Subtopics

- [Trend chart properties](<02.08.04.13.03.04.01.01_Trend_chart_properties.md>)

The trend chart lets you visualize the development of the test value over a series of tests. You can also compare similar trend graphs.

A trend chart is opened by choosing Show In > Trend Chart from the shortcut menu of a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>). It can also be opened using the New button (see below) from the toolbar of another trend chart or using the Window > Show View > Trend Chart menu command.

 ![Trend Chart view_Annotated view](<../../../../raw/136583.png>)

These are the elements in the main area of the chart (for the toolbar and shortcut menu, see below):

- Title: By default, the name of the test being displayed and its number in parentheses. You can edit this label in the [chart properties](<02.08.04.13.03.04.01.01_Trend_chart_properties.md>).
- Subtitle: By default, the grouping in effect, if any. You can edit this label in the [chart properties](<02.08.04.13.03.04.01.01_Trend_chart_properties.md>).
- Toolbar: The action buttons of the chart. See the Toolbar section, below, for details.
- Value axis label: By default, this label shows the unit for the numbers displayed on the y-axis. You can edit this label in the [chart properties](<02.08.04.13.03.04.01.01_Trend_chart_properties.md>).
- Value axis: The value axis displays the magnitude of the measured values. You can specify the range of this axis in the [chart properties](<02.08.04.13.03.04.01.01_Trend_chart_properties.md>).
- Data axis: The data axis with the indexes of the tests being displayed. You can specify the range of this axis in the [chart properties](<02.08.04.13.03.04.01.01_Trend_chart_properties.md>).
- Values. The measured values. If you have selected more than one series of tests, each series is displayed in a different color. (Multiple series can only be displayed in one graph if they have the same test suite, test method, and test name.)
- Limits: These zones indicate areas outside the specified test limits.
- Legend: A description of the individual test series that are displayed. You can configure the display of the legend in the [preferences](<02.08.04.13.03.05.22_Trend_preference_settings.md>).

You can zoom in on the chart by drawing a rectangle around the area you want to enlarge (in addition to using the Zoom In button described below). You can reset the zoom level to its default by double-clicking anywhere in the chart area.

## Toolbar

 ![Trend Chart View_Toolbar, annotated](<../../../../raw/136584.png>)

The toolbar of a trend chart view includes these buttons:

- Link: Links the display in the view to the selected row in the [data navigation view](<02.08.04.13.03.02_Data_navigation_views.md>).

In this mode, if the selection in the data navigation view changes, the display updates automatically.

- Pin: Freezes the display in the view.

In this mode, the view keeps displaying the rows it currently displays, even when the selection in the data navigation view changes. Dynamic updating can be resumed by clicking the Link button.

- New: Creates a new trend chart view.
- Zoom In: Enlarges a section of the chart to show more detail.
- Zoom Out: Reduces the scale of the chart to show more data.
- Properties: Opens the [Trend Chart Properties dialog](<02.08.04.13.03.04.01.01_Trend_chart_properties.md>).
- Statistics: Displays the data that underly the graph. The information categories are the same as the columns in [test summary tabs.](<02.08.04.13.03.02.01_Test_summary_tab.md>) Clicking the button again hides the values and displays the chart.
- Image: Clicking this buttons lets you save the current chart display as a PNG or JPEG image.
- Switch Legend: Switches the position of the legend between the bottom and the right side of the chart.

## Shortcut menu

The shortcut menu of a trend chart view contains these commands:

- Zoom In: Enlarges a section of the chart to show more detail.
- Zoom Out: Reduces the scale of the chart to show more data.
- X Axis: The commands in this submenu let you set the range of the data axis:

  - Auto: Scales the axis so that all data points are displayed. (This is the default setting.)
  - Double: The range of the axis around its midpoint is doubled.
  - Half: The range of the axis around its midpoint is halved.

- Y Axis: The commands in this submenu let you set the range of the value axis:

  - Min/Max: The axis begins with the smallest measured value and ends with the largest measured value.
  - Limits: The axis begins with a value slightly below the lower limit and ends with a value slightly above the upper limit. (This is the default setting.)
  - Double: The range of the axis around its midpoint is doubled.
  - Half: The range of the axis around its midpoint is halved.

- Show in Raw Data: Right-clicking on a data point and choosing this command highlights the row in the [raw data view](<02.08.04.13.03.03.01_Raw_data_views.md>) that contains the data point's underlying data.

This command is only available when you click a data point, not in other regions of the chart.

- Restore Defaults: Resets the zoom level and axis settings to their defaults.
- Properties: Opens the [Trend Chart Properties dialog](<02.08.04.13.03.04.01.01_Trend_chart_properties.md>).
