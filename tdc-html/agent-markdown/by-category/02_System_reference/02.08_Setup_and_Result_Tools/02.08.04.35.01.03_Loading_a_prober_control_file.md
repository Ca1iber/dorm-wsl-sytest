# Loading a prober control file

You can store prober specific commands or reference text (to set up or control a prober, for example) transparently, within the Wafer Description Editor's buffer. When you then save the wafer description from within the Test Program Explorer, these prober-specific instructions will also be saved as part of the wafer file.

To load a prober control file:

- In the Test Program Explorer highlight the item Wafer.
- Double-click to open the Wafer Description Editor.
- In the Wafer Description Editor choose Select > Load Prob.Int.
- In the dialog box that appears select the appropriate path and file, and click Load.

The Prob. Int. Loaded message in the wafer description editor screen will change to YES.
