# Positioning Edges

#### Subtopics

- [Setting Edge Snapping](<02.08.04.34.06.06.04.01_Setting_Edge_Snapping.md>)

Positioning an edge means moving it inside a test system cycle to a certain delay.

 Note Moving an edge in any test system cycle causes all edges of the same number in all the other test system cycles of the selected device cycle to move too. This is true for all device cycles that you have generated for a pin.

There are two ways to move an edge:

- click it with the mouse and drag it to another position. The appropriate edge delay entry field shows the new delay.
- type the new delay directly into the edge delay entry field. The associated edge moves to the new position.

You can move any edge across test system cycle boundaries in either direction. Note however the dependencies with other edges as well as edge movement range limits. These are laid out in [Edge Ranges](<02.08.04.34.01.01.03_Edge_Ranges.md>).

It is not possible to change a given edge drive order by moving edges. This can only be done by editing the device cycle, see [Using Device Cycle Setup and Edit Modes](<02.08.04.34.06.07.02_Using_Device_Cycle_Setup_and_Edit_Modes.md>).
