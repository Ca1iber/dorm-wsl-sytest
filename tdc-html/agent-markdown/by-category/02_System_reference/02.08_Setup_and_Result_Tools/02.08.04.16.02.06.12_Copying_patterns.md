# Copying patterns

The Pattern Explorer and the Pattern Editor allow you to copy complete patterns or an arbitrary region of a pattern.

## About this task

You copy a pattern by creating a new pattern, highlighting and copying the cells you want to copy, creating new lines in the new pattern and pasting the copied cells into the new pattern.

To be able to copy patterns, they must be in the same port.

## Before you begin

The Pattern Explorer must be open, see [Opening the Pattern Explorer](<02.08.04.16.01.01_Opening_the_Pattern_Explorer.md>).

## Procedure

-  Create a new pattern as described in [Creating a new pattern](<02.08.04.16.01.02_Creating_a_pattern.md>).
-  Open the new pattern and the source pattern as described in [Opening the Pattern Editor](<02.08.04.16.02.06.01_Opening_the_Pattern_Editor.md>). The new pattern contains only one line with the STOP instruction.
-  In the Pattern Editor of the source pattern, highlight all vectors you want to copy, right-click and select Copy. You can select complete vector lines or an arbitrary region of vector cells.
-  In the Pattern Editor of the new pattern, highlight the line containing the STOP instruction, right-click and select Insert Special.
-  In the Insert Special window choose the Insert Data from Paste Buffer (n lines) option. n indicates the number of vector lines currently in your buffer.

In the Repeat Count field, type how many times you want the copied lines to be inserted. Click OK.

The copied vectors are inserted, including instructions and comments.
