# Methodology for Generating Complex Device Cycles

#### Subtopics

- [Considering Tri-state Switching Accuracy](<02.08.04.34.06.04.01_Considering_Tri-state_Switching_Accuracy.md>)

Proceed by taking device cycles from a data sheet.

- Check which device cycles are active at the same time for the pins of interest (for instance the data bus).
- Examine each device cycle for these pins. Obtain the position of each edge in every test system cycle on the data sheet. Reference the position of each edge to the beginning of the test system cycle (the clock leading edge). If edges are referenced to other parts of a test system cycle in the data sheet (such as the clock trailing edge, or another signal), use an offset.

- Examine the Test System Cycle column and the Delay column. The difference between the biggest and the smallest edge delays in a particular test system cycle must be less than one period. If it is not, add one test system cycle in the Test System Cycle column.Note Note that for SmarTest 7.10,there is only one test system cycle per device cycle.
- Order the delays from the smallest to the biggest. Check if some delays are identical, or similar - the edges with these delays can perhaps be reused. In general, an edge can be reused if you are running only pass/fail tests, that is, the edges are not being moved. Additionally, edges can be reused if:

  - their delays are identical and they are used for tight timing for the same type of tested parameter (for instance the setup time, but not the hold time).
  - their delays are similar and no more than one is used for tight timing.
  - their delays are similar and they are used for loose timing.

- Use the one pin display option in the Timing Setup. You can now set up all device cycles for the pin or pin group of interest. Select edges from the "unused edge box" in an ascending order and assign delays to them from your table in the order determined in the previous step.
- Select the proper edge actions from the "Shapes" window. Do this for the drive and/or the receive side, as necessary.
- Select the format pins display option in the Timing Setup. You can now examine all the pins to which the current device cycle applies. Do not make any changes in this display mode, just see if some edges can be reused.
