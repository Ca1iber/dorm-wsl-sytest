# Task 1: Test Planning

#### Subtopics

- [Verifying Available Test System Resources](<02.08.01.01.01.01_Verifying_Available_Test_System_Resources.md>)
- [Overview of DUT Board Design Considerations](<02.08.01.01.01.02_Overview_of_DUT_Board_Design_Considerations.md>)
- [Preliminary Checklist](<02.08.01.01.01.03_Preliminary_Checklist.md>)

Plan your device tests and design the DUT board.

- Assess the DUT Resource Requirements:

  - Study the test device.
  - What tests are needed?
  - What parameters to measure?
  - What test methodologies to use?
  - How many digital channels you will need.

- Verify the available test system resources.
- Design test circuits and a DUT board.
