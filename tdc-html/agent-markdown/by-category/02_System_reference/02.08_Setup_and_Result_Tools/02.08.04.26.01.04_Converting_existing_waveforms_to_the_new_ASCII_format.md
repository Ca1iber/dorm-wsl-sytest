# Converting existing waveforms to the new ASCII format

Generic waveforms like ramps or sine waves should be generated by the corresponding definition() member function of ANALOG_WAVEFORM API. If the mathematical description of a waveform is unknown you can do a sample based conversion to the new ASCII format.

## Before you begin

Make sure that at least a waveform is held in the waveform memory.

## Procedure

-  Open the Signal Analyzer tool.
-  Load the waveform into the Signal Analyzer: click the ![Drop down button](<../../../../raw/106218.png>) button and select View Waveform Memory. The View Waveform Memory window is displayed.   ![User defined panel](<../../../../raw/106219.png>)

  -  Select pin name and core index.
  -  Enter the waveform label name and size.
  -  Click OK.

The waveform is loaded into the Signal Analyzer.

-  To store the data to an ASCII file, in the Signal Analyzer tool, click the menu File > Save Trace as...
-  The Save Trace As... window is displayed. Enter the file name and select the file type ASCII Format File. Then click Save.

## Results

The waveform existing in the waveform memory is converted to the ASCII format.

## What to do next

You can modify the waveform ASCII file.
