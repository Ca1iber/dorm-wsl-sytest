# Result menu

 |

Menu item

 |

Action

 |
 |

First Failure

  ![Menu Command Result-First Failure](<../../../../raw/128373.png>) |

Set the cursor to the position where the first failure is located

 |
 |

Previous Failure

  ![Menu Command Result-Previous Failure](<../../../../raw/128374.png>) |

Set the cursor to the position where the previous is located

 |
 |

Next Failure

  ![Menu command Result-Next Failure](<../../../../raw/128375.png>) |

Set the cursor to the next failure from the current cursor location.

 |
 |

Last Failure

  ![Menu Command Result-Last Failure](<../../../../raw/128376.png>) |

Set the cursor to the previous failure from the current cursor location

 |
 |

Result Configuration

 |

Open the result configuration window. For details, see [Result Configuration](<02.08.04.08.04_Result_Configuration.md>).

 |
 |

Execute

  ![Menu Command Result-Execute](<../../../../raw/128377.png>) |

Start the test

 |
 |

Break

  ![Menu Command Result-Break](<../../../../raw/128378.png>) |

Stop the execution of the test

 |
 |

Acquisition Mode

 |

Set how the error data will be acquired in the Error Map and displayed in the error map tool. See [Setting the acquisition mode](<02.08.04.08.01.02_Setting_the_acquisition_mode.md>).

 |

- SmarTest 7.1.2: Configuration window Bandwidth Related Settings introduced
