# Overlaying shmoo tests in the Shmoo Tool

In the Shmoo Tool, to overlay shmoo plots, use the [Overlay](<02.08.04.25.04.04_Commands_in_the_bottom_bar_of_the_Shmoo_Tool.md>)[ command in the bottom bar of the shmoo editor](<02.08.04.25.04.04_Commands_in_the_bottom_bar_of_the_Shmoo_Tool.md>).

## Before you begin

- [Create shmoo tests in the Shmoo Tool](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>). Or, [transfer shmoo test suites to the Shmoo Tool](<02.08.04.25.03.10.03_Transferring_test_suites_to_the_Shmoo_Tool.md>).
- [Execute](<02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>) these shmoo tests in the Shmoo Tool.

## Procedure

-  In the shmoo editor, right-click the bottom bar and select Overlay.

The Overlay window opens:

  ![Overlay window of the Shmoo Tool](<../../../../raw/136568.png>)
-  In the Overlay Name field, enter a name for a new shmoo page to display an overlay shmoo plot.
-  In the Overlay Title field, give a title for the overlay shmoo plot.
-  In this window, select the shmoo tests you want to overlay.

You can overlay shmoo plots (represented by shmoo page names) of different sites different pins.

  - To overlay shmoo plots of different pins, you must enable perPinResult[when setting](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>).
  - To overlay shmoo plot of different sites, you must [enable multiple sites](<02.08.04.25.03.04.07_Viewing_the_shmoo_plots_of_different_sites.md>) before executing the shmoo tests.
  - Error message will show up if the selected the shmoo tests have different steps, or have no common [Test modes](<02.08.04.25.03.02.02_Test_modes.md>).

-  In the Test Mode field, select the [test mode](<02.08.04.25.03.02.02_Test_modes.md>) for overlay.

This box:

  - Becomes available only after you have selected the shmoo tests in step 4.
  - Lists only the common test modes among the selected shmoo tests.

-  In the Calculate Type field, select the type for the result to be displayed on the overlay shmoo plot. This box becomes available only after you have selected the shmoo tests in step 4

The available types are:

  - percentage: Displays the percentage of pass tests on each cell on the overlay plot if you have selected pass/fail in step 5.
  - max: Displays the maximum number or the maximum measured value on each cell on the overlay plot.
  - mean: Displays the average number or the average measured value on each cell on the overlay plot.
  - min: Displays the minimum number or the minimum measured value on each cell on the overlay plot.
  - sum: Displays the total numbers on each cell on the overlay plot.

-  Click OK.

## Results

- An overlay shmoo plot is generated on a new shmoo page in the shmoo editor.

Different cells may have different colors. See [Colors on shmoo plots](<02.08.04.25.03.04.01_Colors_in_shmoo_plots.md>).

- The Properties view for the overlay shmoo page displays the configurations for this overlay, such as the name of each shmoo test, the test modes for overlay, and the calculation types.

## What to do next

You can:

- Overlay another shmoo plot on the current overlay plot.

To do this, use the [AddToOverlay](<02.08.04.25.04.04_Commands_in_the_bottom_bar_of_the_Shmoo_Tool.md>)[ command](<02.08.04.25.04.04_Commands_in_the_bottom_bar_of_the_Shmoo_Tool.md>) in the bottom bar of the shmoo editor.

- [Zoom](<02.08.04.25.03.04.02_Zooming_shmoo_plots.md>), or [take a picture of the overlay shmoo plot](<02.08.04.25.03.06_Taking_a_picture_of_a_shmoo_test_in_the_Shmoo_Tool.md>).
