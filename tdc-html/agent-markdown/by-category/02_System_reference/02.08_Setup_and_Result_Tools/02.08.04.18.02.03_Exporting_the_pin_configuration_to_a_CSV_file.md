# Exporting the pin configuration to a CSV file

The CSV (Comma-Separated Values) file format is a file type storing tabular data. The CSV files are common on all computer platforms. The Pin Configuration tool lets you export the pin configuration to a CSV file easily. The export function gives you a convenient way for reporting and documentation.

## Before you begin

Make sure a pin configuration file has been loaded.

## Procedure

-  In the Test Program Explorer, right-click the pin item and choose Export.

The Export 93000 Setup window opens.

-  In this window, click Browse.

The Enter or select file to export window opens.

-  Choose the location where you wish to save the CSV file, enter a file name and click OK.

You return to the Export 93000 Setup window.

-  In the Setups section, choose the items you want to export and then click Finish.  ![Select exproted items](<../../../../raw/108685.png>)

## What to do next

Now you can open the CSV file with Excel to check its content.
