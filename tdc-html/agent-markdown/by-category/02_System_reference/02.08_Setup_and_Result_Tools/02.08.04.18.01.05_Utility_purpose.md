# Utility purpose

The utility purpose is a group of utility lines together with their setting data (0, 1 or Do not care). The utility purpose is also supported by the Routing Setup Tool and test method program. Therefore, you can handle these groups similarly to the way you handle individual utility lines.

The important difference from the individual utility line definitions is that a utility purpose has the setting data for all utility lines in the group, in order to apply an arbitrary setting data to the desired utility lines at the same time. This is useful for controlling many user relays on a DUT board and is adapted for multi-site testing. For multi-site testing, a utility purpose can have different setting data for each site.
