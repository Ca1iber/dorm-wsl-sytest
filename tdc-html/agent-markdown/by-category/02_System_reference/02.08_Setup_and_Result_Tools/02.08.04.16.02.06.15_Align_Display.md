# Align Display

Using the align function you can coordinate the displays of all result analysis tools.

## About this task

For an easier error evaluation you can use the Pattern Editor along with other result analysis tools, for example the [Timing Diagram Tool](<02.08.04.33_Timing_Diagram_Tool.md>).

This topic exemplifies how to align the display of the Timing Diagram with the display of the Pattern Editor. The procedure can also be applied to align the Error Map Tool.

## Before you begin

Make sure

- the Pattern Editor is opened with the pattern you want to evaluate,
- the pattern is displayed in the expanded mode, and
- the test was executed with failures,

as described in [Displaying failure data](<02.08.04.16.02.06.13_Displaying_failure_data.md>).

## Procedure

-  To align the Timing Diagram with the Pattern Editor, open the Timing Diagram.
-  In the Pattern Editor highlight the cycle you want to evaluate.
-  Click the ![Align display button](<../../../../raw/99929.png>) button (Align display). Note If you have several patterns of different types (MAIN, Burst or multiport burst etc), ensure that the burst pattern is in focus prior to all the Align display tool.

## Results

The focus of the Timing Diagram shifts to the same cycle and signal as in the Pattern Editor.
