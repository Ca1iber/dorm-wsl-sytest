# Specifying the Period Resolution

In equation based timing, you can specify the period resolution in the equation set with the keyword period_res (see also [Timing equation set reference](<../02.06_Command_Reference/02.06.06.01.02.01_Timing_equation_set_reference.md>)). In this case the periods of all timing sets will be adjusted if they are not integer multiples of the specified resolution. Note that if the period resolution is explicitly specified, the system will no longer recalculate the resolution when the global period in timing set 1 has been changed with PCLK.

You can also use CLKR to change the period resolution in equation based timing. However, this is only a temporary change of the runtime value, which does not set or modify the value of the equation set.

The range for the explicit definition of the period resolution has no upper limit. It can always be set to the length of the period specified for timing set 1 of the equation set that is associated with the respective timing specification (see [Defining the timing specification](<../02.06_Command_Reference/02.06.06.01.05_Defining_the_timing_specification.md>)). The lower limit is the same as for the automatic calculation.
