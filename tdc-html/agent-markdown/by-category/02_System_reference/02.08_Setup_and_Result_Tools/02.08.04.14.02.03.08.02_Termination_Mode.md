# Termination Mode

The termination mode is not specified directly. It is determined from the presence (or absence) of the vch, vcl, ioh, iol and vt group of resources.

- if vch, vcl, ioh, iol and vt are all absent, termination mode is set to off (off).
- if only vt is specified, termination mode is set to terminated (t).
- if vt=vih is specified, termination mode is set to high terminated (h).
- if vt=vil is specified, termination mode is set to low terminated (l).
- if ioh, iol and vt are specified, termination mode is set to clamp (c).Note No other combination of resources in this group is permitted.

## Functional changes

- Introduced before SmarTest 6.3.2
