# Checking the execution flow

If you have a multiple-path testflow, you may want to know how often a device had gone down a particular path before being binned.

## About this task

There are two ways to achieve this:

- Previously setting the pass/fail state for each test suite by [using HW response files for execution](<02.08.04.32.02.06.02_Using_hardware_response_files_for_execution.md>).
- Inserting different Assign Value nodes in each individual path of the testflow, and have these logged, for example, by defining them in various bin descriptions. This method is described below.

## Before you begin

Make sure that the testflow has been created.

## Procedure

-  Determine the paths in your testflow you wish to monitor, and the bins in which you want to have these paths monitored.
-  In the Flow Sequence Editor, insert an Assign Value node into the first path.
-  In the New Assign Value Node Wizard window, set the Variable to automatically increment each time the path is taken. For example, for the variable path_1 whose initial value is 0, set the Value to path_1 + 1.
-  Click the bin node where you want the path to be logged and then modify the Description in the Properties view: enter the expression that counts the various paths. For example, to record the two paths of the figure below in bin AA, enter the following as AA's Description:

`path_1=@{path_1}, path_2=@{path_2}`

  ![A testflow where two paths are monitored](<../../../../raw/110994.png>)

## Results

After execution, the data log file contains an entry showing how many times the particular paths were taken.
