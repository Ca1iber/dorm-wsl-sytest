# Editing properties in the Pattern Explorer

#### Subtopics

- [Moving vectors to another memory type](<02.08.04.16.01.14.01_Moving_vectors_to_another_memory_type.md>)

## About this task

The Pattern Explorer allows you to edit the properties of patterns, port bursts, and multiport bursts. You can:

- Create, rename, delete an item
- Create or change the sync group of a port burst
- Change the type of a pattern (main or subroutine)
- Change the wavetable
- Change the memory
- Change the location of pattern files (in a pattern master file setup)
- Select a layout for the Pattern Editor

For details on creating items see [Creating a pattern](<02.08.04.16.01.02_Creating_a_pattern.md>), [Creating a port burst](<02.08.04.16.01.05_Creating_and_assigning_a_port_burst.md>), and [Creating a multiport burst](<02.08.04.16.01.04_Creating_a_multiport_burst.md>).

If you want to move the vectors of a pattern to another memory type, see [Moving vectors to another memory type](<02.08.04.16.01.14.01_Moving_vectors_to_another_memory_type.md>).

Note The Port property cannot be edited.

## Before you begin

Make sure the Pattern Explorer is open, see [Opening the Pattern Explorer](<02.08.04.16.01.01_Opening_the_Pattern_Explorer.md>).

## Procedures

### Deleting an item

- In the Pattern Explorer, to highlight the item you want to delete, click its name.
- Right-click and select Delete.

### Renaming an item

- In the Pattern Explorer, to highlight the item you want to rename, click its name.
- Right-click and select Rename.
- Type the new name and click OK.

### Creating or changing the sync group

- To create or change the sync group of a port burst (PortBurst) in the Pattern Explorer, unfold a multiport burst (MPBurst).
- In the Sync Group cell of the port burst, either type the name of a new sync group or use content assist (Ctrl + spacebar) to list the existing sync groups.
- Press Enter.

### Changing the pattern type

If the pattern is of the type Main or SubRoutine, you can change the type from Main to SubRoutine and vice versa. The following restrictions apply:

- A main pattern cannot be changed to a sub routine, if the main pattern is referenced in a burst.
- A sub routine cannot be changed to a main pattern, if the sub routine is referenced by the JSUB sequencer instruction in another pattern.

All other pattern types cannot be changed.

To change the pattern type:

- In the Pattern Explorer double-click the corresponding field in the Type column. This activates a content assist.
- To display the valid values press Ctrl+Spacebar and clear the content of the field.
- Select the new pattern type.

### Changing the wavetable

You can change the wavetable in the Pattern Explorer.

Note The wavetable displayed in the Pattern Explorer is not necessarily the same wavetable used for test execution. The wavetable displayed in the Pattern Explorer is only used to display the device cycle names or state characters in the Pattern Editor. The wavetable that is used for test execution is defined in the test suite dialog. See also [Function of the base wavetable](<02.08.04.16.04.05.01_Function_of_the_base_wavetable.md>).

To change the wavetable:

- In the Pattern Explorer double-click the corresponding field in the WaveTable column. This activates a content assist.
- To display the valid values press Ctrl+Spacebar and clear the content of the field.
- Select the new wavetable.

### Changing the memory

- To change the memory type of a pattern in the Pattern Explorer, go to the Memory cell of the pattern.
- In the Memory cell, either enter the memory type or use content assist (Ctrl + spacebar) to list the available memory types. See also [Moving vectors to another memory type](<02.08.04.16.01.14.01_Moving_vectors_to_another_memory_type.md>).

### Changing the location of pattern files and port burst files to create copy

You can create a copy of pattern files and port burst files, that are part of a pattern master file setup, by changing the location:

- In the Pattern Explorer, highlight the current entry in the corresponding field in the Location column.
- Press Ctrl+Spacebar to activate a content assist and a ![Selection box button](<../../../../raw/121799.png>) selection button.
- Choose either way to specify the new location.

This creates a copy of the file at the new location.

### Selecting a layout for the Pattern Editor

In the Pattern Editor you can configure and save several layouts, which define which pins and pin groups are displayed and in which format they are displayed. For a description of how to configure such a layout see [Configuring the layout of the Pattern Editor](<02.08.04.16.02.06.02_Configuring_the_layout_of_the_editor.md>).

If you have configured and saved several layouts in the Pattern Editor, you can select one of these layouts in the Pattern Explorer. Every time you start the Pattern Editor, this layout is used to display the pattern.

To select a layout:

- In the Pattern Explorer double-click the corresponding field in the Layout on Pattern Editor column. This activates a content assist.
- To display the valid values press Ctrl+Spacebar and clear the content of the field.
- Select the new layout.

### Merging pattern files

- To merge pattern files in a pattern master file setup, refer to [Merging pattern files](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02.01.07_Merging_and_splitting_pattern_files.md>).
- To merge other pattern files to a single loaded pattern file, you do not do this with the pattern tools but with the Test Program Explorer. For more information see [Appending a file to a loaded file (Merge)](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02.01.08_Appending_a_file_to_a_loaded_file__Merge.md>).
