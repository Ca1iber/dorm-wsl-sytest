# Displaying data in the signal analyzer tool

You can plot De-embedding cit files on the signal analyzer tool.

## Procedure

-  Select one or more rows of interest.
-  Right-click the row.
-  On the shortcut menu, select Signal Analyzer.  ![DeEmbedding page: shortcut menu](<../../../../raw/125255.png>)

Signal Analyzer tool opens displaying the corresponding graph or graphs (see [Elements of the Signal Analyzer Tool](<02.08.04.26.02_Elements_of_the_Signal_Analyzer_Tool.md>)).
