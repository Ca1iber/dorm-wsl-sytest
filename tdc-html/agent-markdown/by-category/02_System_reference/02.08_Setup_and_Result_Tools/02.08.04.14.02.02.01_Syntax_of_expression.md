# Syntax of expression

In the following syntax sections, where the syntax of the Equation Based Testing components are described, expression is used frequently to express mathematical expressions and relationships. It has a complex syntax, and is therefore described independently here.

 Note There is a limit of one "?...:" pair per expression.
