# EVCK? - (EVent ClocK)

The EVCK? query returns the event clock periods for the ports of a multi-port timing specification. In many situations, this event clock period equals the system clock period, but it can be different from the system clock period if the port is associated with a user defined clock group in the specification. For more information on clock groups see [Avoiding rounding problems with different clock groups](<../02.06_Command_Reference/02.06.06.01.06.02_Avoiding_rounding_problems_with_different_clock_groups.md>).

 Note When the event clock period must be different from the system clock period, it is calculated at runtime. Therefore, EVCK? will in this case return a meaningful value only after execution of a functional test.

## Syntax

```
EVCK? {"multi-port_spec"}, {(port_list)}
```

returns:

```
EVCK {"multi-port_spec"}, event_clock_per, {(port)}
```

## Parameters

 |

multi-port_spec

 |

Name of a multi-port timing specification.

 |
 |

port_list

 |

This query parameter specifies a list of ports that belong to the respective multi-port timing specification.

 |
 |

port

 |

This reply parameter specifies a port that belongs to the respective multi-port timing specification.

 |
 |

event_clock_per

 |

This reply parameter returns the event clock period of the respective port.

 |

## Application

Timing setup command.

## Example

```
>  SCLK? "mu_burst"
<  SCLK "mu_burst",480
>  EVCK? "mu_burst",(@@)
<  EVCK "mu_burst",2448,(PortA)
<  EVCK "mu_burst",2448,(PortB)
<  EVCK "mu_burst",480,(PortD)
<  EVCK "mu_burst",480,(PortE)
```

This example returns the system clock period and the event clock periods for the multi-port timing specification `mu_burst`. The event clock periods of `PortD` and `PortE` equal the system clock period, those of `PortA` and `PortB` are different.
