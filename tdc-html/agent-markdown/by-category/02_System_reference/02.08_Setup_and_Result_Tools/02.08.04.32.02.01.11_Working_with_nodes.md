Test suites and other test flow related operations such as data reporting/logging, sorting, flow control, and values assignment are represented by test flow nodes. You find the following node types when creating your test flow in SmarTest:

- Test suite nodes

  - Run
  - Run and branch

For more information see ["Run" and "Run and Branch" test suites](<02.08.04.32.01.02.01.01_Run__and__Run_and_Branch__test_suites.md>).

- Sorting nodes:

  - Good bin
  - Bad bin
  - Multibin

For more information see [Bins](<02.08.04.32.01.02.06_Bins.md>).

- Print nodes:

  - Print
  - Print to Datalog

For more information see [Print nodes](<02.08.04.32.01.02.04_Print_nodes.md>).

- Flow control nodes:

  - If/Then
  - Repeat Loop
  - While Loop
  - For Loop

For more information see [Flow control nodes](<02.08.04.32.01.02.02_Flow_control_nodes.md>).

- Value assignment nodes:

  - Assign Value
  - Assign Level Value
  - Assign Timing Value

For more information see [Assign Value node](<02.08.04.32.01.02.03_Assign_Value_node.md>).

The operations of the nodes (including [Test suites](<02.08.04.32.01.02.01_Test_suites.md>) and testflow nodes) in this section are completed in the Flow Sequence Editor.

 Note The following operations cannot be performed in the Flow Data Editor: inserting, cutting, moving, cloning, and deleting nodes or node groups, and grouping the nodes.
