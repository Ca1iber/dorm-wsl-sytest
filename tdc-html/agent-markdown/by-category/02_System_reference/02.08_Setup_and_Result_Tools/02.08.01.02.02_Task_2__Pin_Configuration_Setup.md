This task is the very first step in any test development, be it mixed-signal tests otherwise. The purpose of this operation is to inform the software of your DUT board pin allocations in relation to the tester resources.

The mixed-signal devices has the following pins relating to the internal analog circuits generally. So, define these pins in the Pin Configuration Tool, in addition to the pin definitions for logic device:

- Analog input and/or output pins

For example, analog input pin for an ADC, analog output pin for a DAC, and both analog input and output pins for a buffer amplifier.

You have to use the "Mode" column to specify the physical pins of analog modules on a DUT board, and use the "Tester Channel" column to specify the physical slot locations of the analog modules.

 Note For differential signal, you need to define the non-inverse signal pin only, but you Do not have to define the inverse signal pin.
- Fixed voltage pins

For example, reference voltage pins (positive and negative) for an ADC or DAC. Generally, DPSs are connected to these pins.

- Power supply pins for analog circuits in the device

Generally, DPSs are connected to these pins.

And, to activate an analog module connected to an analog pin, you can apply a digital signal from a digital channel as the trigger signal to the analog module. So, you need also to configure a trigger pin for each used analog module in this tool.

Further, if your DUT board has some relays that are controlled by the utility lines, it is recommended to define the utility lines in this tool. By this definition, you can control the user relays easily with using your defined routing set defined in the Routing Setup Tool and from your test method programs.
