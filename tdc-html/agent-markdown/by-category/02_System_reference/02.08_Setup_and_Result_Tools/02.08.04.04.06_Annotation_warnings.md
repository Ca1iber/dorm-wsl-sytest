# Annotation warnings

Warning annotations are generated under the following conditions.

- Channel is not reported by the firmware
- Port is not reported by the firmware
- File cannot be found from the specified cit file path
- Firmware download status for a row generates a report.Note Move the mouse over the respective annotation to display the warning in a yellow pop-up window. Warnings are also displayed on the Problems and the Markers view.
