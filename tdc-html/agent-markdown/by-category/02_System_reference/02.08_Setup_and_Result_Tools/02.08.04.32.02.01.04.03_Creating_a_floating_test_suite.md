# Creating a floating test suite

#### Subtopics

- [Connecting a floating test suite to the testflow](<02.08.04.32.02.01.04.03.01_Connecting_a_floating_test_suite_to_the_testflow.md>)

You can add a test suite on the Test suites page of the Flow Data editor as a [Floating test suite](<02.08.04.32.01.02.01.03_Floating_test_suite.md>).

## About this task

For SmarTest any test suite, which you add on the Test Suite page of the Flow Data editor, is a floating test suite

## Before you begin

Make sure that the primary setup files have been loaded.

Open the testflow in the [Flow Data Editor](<02.08.04.32.03.01_Flow_Data_Editor.md>).

## Procedures

### Creating a floating test suite from scratch

- On the Test suites page, right-click and select Add Test Suite.

The New Test Suite Wizard window opens.

- Enter the information for the floating test suite in the same way as described in [Inserting a test suite into the testflow](<02.08.04.32.02.01.04_Inserting_a_test_suite_into_the_testflow.md>).
- Click Finish.

SmarTest displays the floating test suite with a dark gray background.

### Creating a floating test suite based on an existing test suite

- On the Test suites page, right-click the line number of the test suite you want to copy and select Copy.
- Right-click the Test suites page and select Paste as New Test suite.

The floating test suite is added.

- Edit the test suite settings if necessary.

SmarTest displays the floating test suite with a dark gray background.

## What to do next

You can run it for debugging.

You can [connect it to the testflow](<02.08.04.32.02.01.04.03.01_Connecting_a_floating_test_suite_to_the_testflow.md>) in the [Flow Sequence Editor](<02.08.04.32.03.02_Flow_Sequence_Editor.md>) (then the floating test suite becomes a normal test suite).
