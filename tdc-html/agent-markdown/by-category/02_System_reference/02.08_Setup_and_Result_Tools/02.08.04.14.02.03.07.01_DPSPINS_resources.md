## Resource parameter table

 | Resource parameter  | Expression  | Description |
 | capacitance  | Capacitance in microfarads (μF) |

Specifies the load capacitance on the DUT board.

This optional parameter is supported only by the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

For the programmable range, refer to section [Dynamic behavior in force voltage or clamp voltage mode](<../02.05_Test_Head_Cards/02.05.05.03.06.01_XPS256_force_and_clamp_voltages.md#_351115__s_Dynamic_behavior>) in [XPS256 force and clamp voltages](<../02.05_Test_Head_Cards/02.05.05.03.06.01_XPS256_force_and_clamp_voltages.md>).

Default value if not defined: 0 μF

 |
 | connect_state  | Keyword:

- himp
- hdig
- norm_hdig
- ungang
 |

Defines which current to apply if the DC Scale pins in DPS mode are connected.

This parameter is only for [DC Scale cards](<../02.05_Test_Head_Cards/02.05.05_DC_Scale_cards.md>).

 | norm[1)](<#fntarg_1>)  | The default state for all DC Scale cards. |
 | himp |

Activates the high-impedance measurement mode.

This mode allows you using the DC Scale card as a voltmeter.

This parameter is for all DC Scale cards.

 |
 | hdig |

Activates the digitizer mode.

This parameter is only for the [DC Scale UHC4T card](<../02.05_Test_Head_Cards/02.05.05.02_DC_Scale_UHC4T_card.md>).

 |
 | norm_hdig |

Activates the normal DPS mode with digitizer mode.

This parameter is only for the [DC Scale UHC4T card](<../02.05_Test_Head_Cards/02.05.05.02_DC_Scale_UHC4T_card.md>).

 |
 | ungang |

Specifies to connect only necessary channels.

This parameter is for all DC Scale cards. See also [Using UNGANG connect state with DC Scale DPS cards](<02.08.04.14.06.01.03_Using_the_UNGANG_connect_state_with_DC_Scale_DPS_cards.md>).

Note that on DPS128/64 and XPS256 you cannot execute a current compare on a ganged group of channels in unganged mode. Already activated comparators are silently disabled in unganged mode. A user notification (Error or warning) is omitted in this case, to avoid any interrupt in the testflow. The previous state of the comparators is automatically restored after the ganged group has been restored.

 | max_voltage_drop_force  | Voltage in volts (V) |

Defines a threshold for the voltage drop on the force line above which a channel is disconnected. Regardless of the voltage drop polarity, the threshold is to defined as absolute value.

This optional parameter is supported only by the [DC Scale UHC4T card](<../02.05_Test_Head_Cards/02.05.05.02_DC_Scale_UHC4T_card.md>) and the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

The [DC Scale UHC4T card](<../02.05_Test_Head_Cards/02.05.05.02_DC_Scale_UHC4T_card.md>) and the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) can measure the voltage drop of the force line on the DUT board.

Card specific behavior:

-

UHC4T: A comparator defines if the voltage drop is small enough or not. This means to measure the drop of the pogo cable (see specifications) plus the drop of the DUT board. Value/flag available for all channels ganged. The range is 0.0 ... 0.5 V with a resolution of 1 mV. Default is 0.25 V.

Two rules apply for the two parameters max_voltage_drop_force and [max_voltage_drop_return](<02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__max_voltage_drop_return>) and the programmed force voltage:

  - Both max_voltage_drop_force and max_voltage_drop_return must be between 0.0 and 0.5 V.
  - The sum of max_voltage_drop_force and max_voltage_drop_return is limited by the programmed force voltage according to the [diagram below](<02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__s_Maximum_voltage_drop_UHC4>). Only values within the red area are allowed.

-

XPS256: An ADC measures the voltage drop on the force line. A comparator evaluates the absolute value of the measured voltage and triggers the disconnection of the channel if the maximum value is reached.

For the specification, refer to [Voltage drop protection / measurement](<../02.02_Specifications/02.02.05.03.07_XPS256_other_performance_characteristics.md#_350739__s_Voltage_drop_protection>) in [XPS256 other performance characteristics](<../02.02_Specifications/02.02.05.03.07_XPS256_other_performance_characteristics.md>).

The programmable range is 0.0 鈥?nbsp;1.0 V for the force line and for the return line but, the total for the two lines must not exceed 1.0 V.

For a maximum voltage drop > 0.5 V, the [openLoopProtection](<../02.06_Command_Reference/02.06.02.02.303_UHCM__UHCM__-__Ultra_High_Current_power_supply_Modes.md#_106910__r_openLoopProtection>) parameter must be set to none and in the [DC Scale Safety editor](<../02.05_Test_Head_Cards/02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__s_DC_Scale_Safety_editor>) the [Vdrop Disco](<../02.05_Test_Head_Cards/02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_Vdrop_Disco>) parameter must be set to ON.

The measurement range covers positive and negative voltages for source and sink currents but only the absolute value is to be programmed.

 |
 | max_voltage_drop_return  | Voltage in volts (V) |

Defines a threshold for the voltage drop on the force line above which a channel is disconnected. Regardless of the voltage drop polarity, the threshold is to defined as absolute value.

This optional parameter is supported only by the [DC Scale UHC4T card](<../02.05_Test_Head_Cards/02.05.05.02_DC_Scale_UHC4T_card.md>) and the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

The [DC Scale UHC4T card](<../02.05_Test_Head_Cards/02.05.05.02_DC_Scale_UHC4T_card.md>) and the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) can measure the voltage drop of the force line on the DUT board.

Card specific behavior:

-

UHC4T: A comparator defines if the voltage drop is small enough or not. This means to measure the drop of the pogo cable (see specifications) plus the drop of the DUT board. Value/flag available for all channels ganged. The range is 0.0 ... 0.5 V with a resolution of 1 mV. Default is 0.25 V.

Two rules apply for the two parameters [max_voltage_drop_force](<02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__max_voltage_drop_force>) and max_voltage_drop_return and the programmed force voltage:

  - Both max_voltage_drop_force and max_voltage_drop_return must be between 0.0 and 0.5 V.
  - The sum of max_voltage_drop_force and max_voltage_drop_return is limited by the programmed force voltage according to the [diagram below](<02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__s_Maximum_voltage_drop_UHC4>). Only values within the red area are allowed.

-

XPS256: An ADC measures the voltage drop on the common return line referenced to the channel specific ground sense pin (GS#). A comparator evaluates the absolute value of the measured voltage and triggers the disconnection of the channel if the maximum value is reached.

For the specification, refer to [Voltage drop protection / measurement](<../02.02_Specifications/02.02.05.03.07_XPS256_other_performance_characteristics.md#_350739__s_Voltage_drop_protection>) in [XPS256 other performance characteristics](<../02.02_Specifications/02.02.05.03.07_XPS256_other_performance_characteristics.md>).

The programmable range is 0.0 鈥?nbsp;1.0 V for the force line and for the return line but, the total for the two lines must not exceed 1.0 V.

For a maximum voltage drop > 0.5 V, the [openLoopProtection](<../02.06_Command_Reference/02.06.02.02.303_UHCM__UHCM__-__Ultra_High_Current_power_supply_Modes.md#_106910__r_openLoopProtection>) parameter must be set to none and in the [DC Scale Safety editor](<../02.05_Test_Head_Cards/02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__s_DC_Scale_Safety_editor>) the [Vdrop Disco](<../02.05_Test_Head_Cards/02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_Vdrop_Disco>) parameter must be set to ON.

 | offcurr  | Keyword:

- min
- act
- open
- act_min
- act_open
 |

The parameter defines which current to apply if the pins in the DPS pin list are disconnected.

This parameter is for both DPS-slot DPS and DC Scale pins.

 One of the following specifiers can be set:

 | min |

Use min (minimum current) for high impedance (HIZ in the [PSLV](<../02.06_Command_Reference/02.06.02.02.195_PSLV__PSLV__-__Power_Supply_LeVel.md>) command).

 |
 | act |

Use act (actual current) for low impedance (LOZ in the [PSLV](<../02.06_Command_Reference/02.06.02.02.195_PSLV__PSLV__-__Power_Supply_LeVel.md>) command).

 Note This is the recommended default setting for the off-state of DPS pins. Only act discharges capacitors on the DUT board. Use min or open carefully and only for selected tests. |
 | open  | Use open for high impedance with opening output relay (HIZ_R in the [PSLV](<../02.06_Command_Reference/02.06.02.02.195_PSLV__PSLV__-__Power_Supply_LeVel.md>) command). |
 | act_min |

Combines act and min. First, the DPS is switched to 0 V with an unchanged current limit. After the output voltage has reached 0 V (±50 mV) or after a timeout of 1 second, the DPS pin is switched to high impedance.

 Note The HC-DPS cannot go down to 0 V output voltage. Here the DPS pin is switched to high impedance at 200 mV (+/-50mV) or after a timeout of 1 second.

Using act_min is safer when changing the DUT or DUT board after a disconnect (LOZ_HIZ in the [PSLV](<../02.06_Command_Reference/02.06.02.02.195_PSLV__PSLV__-__Power_Supply_LeVel.md>) command).

 |
 | act_open |

Combines act and open. First, the DPS is switched to 0 V with an unchanged current limit. After the output voltage has reached 0 V (±50 mV) or after a timeout of 1 second, the DPS pin is switched to open.

Using act_open is safer when changing the DUT or DUT board after a disconnect (LOZ_HIZ_R in the [PSLV](<../02.06_Command_Reference/02.06.02.02.195_PSLV__PSLV__-__Power_Supply_LeVel.md>) command).

 | open_loop_protection  | Keyword:

- diode
- none

The parameter selects the status of the internal force to sense connections.

The internal force to sense connections are available between the P# pin and the PS# pin and between the GS# pin and the common GND pin.

 One of the following specifiers can be set:

The internal connections are made via anti-parallel diodes.

This is the default state if the parameter is not defined.

This is the recommended setting if both parameters [max_voltage_drop_force](<02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__max_voltage_drop_force>) and [max_voltage_drop_return](<02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__max_voltage_drop_return>) are set to a value < 0.5 V.

 |
 | none |

The internal connections are open. The output stage no longer has any voltage feedback if the force to sense connection on the DUT or the DUT board is (unintentionally) open.

 The following rules apply to this option:

- This is the required setting if one of the parameters [max_voltage_drop_force](<02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__max_voltage_drop_force>) or [max_voltage_drop_return](<02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__max_voltage_drop_return>) is set to a value 鈮?nbsp;0.5 V.
   | This optional parameter is supported only by the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>). |
