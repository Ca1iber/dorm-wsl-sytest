# Using the Error Map Tool

This section describes the different modes and options of the error map tool. It gives you an idea how to work with the error map tool.

## Procedure

-  On the menu, click 93000 > Results > Error Map.

The error map tool opens, see [Elements of the Error Map Tool](<02.08.04.08.03_Elements_of_the_Error_Map_Tool.md>).

-  Choose the result mode (Result > Acquisition Mode). This mode determines how the results are acquired in the detailed error map. You have the following options:

  - Force Cycle Oriented
  - Force Failure Oriented
  - Follow Current Mode

For a detailed description see [Acquisition Modes](<02.08.04.08.01.02_Setting_the_acquisition_mode.md>).

-  Choose the result granularity and the location of the detailed Error Map (Result > Result Configuration). For details see [Result Mode](<02.08.04.08.04.01_Result_Mode.md>).
-  To perform the test, on the menu select Result > Execute.
-  In the Overview tab you can see which cycle blocks contain errors. You can switch to the Cycles tab (or the Edges tab depending on the used configuration, see [Result Mode](<02.08.04.08.04.01_Result_Mode.md>)) to analyze the errors.
-  If not all errors are in the scope of the detailed error map, choose a later cycle block in the overview tab and repeat the steps 4. to 5. as often as required.

## Functional changes

- Introduced before SmarTest 6.3.2
