# Creating a testflow

## About this task

There are two methods to create the sequence of the testflow:

- Use the Flow Sequence Editor to create the sequence of the testflow. Then use the Flow Data Editor to set up the attributes of all test suites.
- Add the test suites and bins in the Flow Data Editor as floating test suites and floating bins. Then connect the floating test suites to the testflow. The floating bins can be used for the multi-bin.

You can use either method or combine both methods to create the testflow. This topic describes the first method.

## Before you begin

Make sure that

- All the test setups have been loaded.
- All the required test methods have been built.

## Procedure

-  In the Test Program Explorer view, right-click the testflow item and select New.

The New Testflow window opens.

-  In this window,

  -  Enter the testflow name. The directory of the testflow file is automatically set to device_directory/testflow and uneditable.
  -  The Ignore unsaved setup check box appears in the New Testflow window when some loaded setup files are changed and unsaved. Select this check box.
  -  Click Finish.

-  Open the Flow Data Editor for the new created testflow.
-  On the Setups page of the Flow Data Editor, select and load the setup files. (See [Selecting setup files](<02.08.04.32.02.01.03_Selecting_setup_files.md>).)
-  In the Flow Sequence Editor, create the sequence of the testflow:

  -  Insert the first test suite into the testflow. (See [Inserting a test suite in the testflow](<02.08.04.32.02.01.04_Inserting_a_test_suite_into_the_testflow.md>).)
  -  Copy the first test suite and paste it where you want it to be. The name of the second test suite is the name of the first test suite plus a number. Edit this name as desired. (See [Cutting, copying & pasting nodes](<02.08.04.32.02.01.11.04_Cutting__copying_and_pasting_nodes.md>).)
  -  Insert the other test suites in the same way.
  -  Insert the bins in the same way: insert the first bin, copy and paste it to create the other bins, then change the bin names. (See [Inserting a bin in the testflow](<02.08.04.32.02.01.05_Inserting_a_bin_into_the_testflow.md>).)

Now the attributes of all the test suites are the same. And so are the bins. You need to modify their attributes according to the test plan.

-  In the Flow Data Editor:

  -  Edit the attributes of the test suites and bins. (See [Editing a test suite in the Flow Data Editor](<02.08.04.32.02.01.06_Editing_a_test_suite_in_the_Flow_Data_Editor.md>).)
  -  Set the test suite flags, testflow flags, and system flags.

-  Save the testflow. (See [Changing setup data and saving the changes](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02.01.03_Changing_setup_data_and_saving_the_changes.md>).)

## Results

The testflow has been created.

## What to do next

Debug the testflow.
