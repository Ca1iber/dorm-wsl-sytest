# Determining the period resolution

#### Subtopics

- [Automatic calculation of period resolution for single-port setups](<02.08.04.34.02.01.04.01.02.01_Automatic_calculation_of_period_resolution_for_single-port_setups.md>)
- [Specifying the Period Resolution](<02.08.04.34.02.01.04.01.02.02_Specifying_the_Period_Resolution.md>)
- [Period resolution, clock resolution, and master clock period](<02.08.04.34.02.01.04.01.02.03_Period_resolution__clock_resolution__and_master_clock_period.md>)
- [Period resolution for a multi-port setup (Smart Scale)](<02.08.04.34.02.01.04.01.02.04_Period_resolution_for_a_multi-port_setup__Smart_Scale.md>)

All periods for all pins in all timing sets belonging to the same single-port timing specification or waveform set must be integer multiples of a value that is called period resolution.

In the case of a multi-port specification every Smart Scale port can have a different period resolution (see [Period resolution for a multiport setup (Smart Scale)](<../02.06_Command_Reference/02.06.06.01.04.01.02.04_Period_resolution_for_a_multi-port_setup__Smart_Scale.md>)).
