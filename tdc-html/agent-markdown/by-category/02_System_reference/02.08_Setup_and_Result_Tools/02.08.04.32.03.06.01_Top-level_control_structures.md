# Top-level control structures

This topic describes the top level control structure of the testflow master file.

During the assembly, a control structures can be added to the top-level groups. These control structures are ignored during the split.

## if statement

```
  if @myvar = 1

  group mygroup:   myfile.tfl
  ...

endif
```

- Testflow variables must be prefixed by '@'

## for loop

```
  for @myvar = 0; @myvar < 10 ; @myvar = @myvar + 1

  group mygroup:   myfile.tfl
  ...

endfor
```

- Testflow variables must be prefixed by '@'
- The `testnumber` increment for the STDF test numbering engine can be specified by the optional keyword `testnumber_increment = <number>` at the end of the `for...` line, separated by another semicolon.

## while loop

```
  while @myvar <= 10

  group mygroup:   myfile.tfl
  ...

endwhile
```

- Testflow variables must be prefixed by '@'
- The `testnumber` increment for the STDF test numbering engine can be specified by the optional keyword `testnumber_increment = <number>` at the end of the `while...` line, separated by a semicolon.

## repeat until loop

```
  repeat until @myvar = 0

  group mygroup:   myfile.tfl
  ...

endrepeat
```

- Testflow variables must be prefixed by '@'
- The `testnumber` increment for the STDF test numbering engine can be specified by the optional keyword `testnumber_increment = <number>` in the `if`, `for`, `while`, respectively the `repeat` section (for example, in between `if [..] endif`), separated by a semicolon.

## Example

```
  WHILE @Levels <= @FullFlow
  GROUP VDDchanges:     VDDchanges.tfl

  if @prefix_DIG == 1
    GROUP DIG:          DIG.tfl
  endif

endwhile
```
