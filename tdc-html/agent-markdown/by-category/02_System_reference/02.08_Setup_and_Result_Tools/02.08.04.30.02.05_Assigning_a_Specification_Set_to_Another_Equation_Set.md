# Assigning a Specification Set to Another Equation Set

- Click Change Equation in the Change menu.

A window similar to that of the figure below opens.

  ![Assigning the Specification Set to a Different Equation Set](<../../../../raw/22029.png>)
- Highlight the specification set you want to assign to another equation set.
- Highlight the new equation set from the Equation list.
- Click assign.
- Repeat these last steps as often as required (for other specification sets), and click done when finished.

## Functional changes

- Introduced before SmarTest 6.3.2
