# Moving nodes

## Before you begin

Make sure that the Flow Sequence Editor has been opened and a testflow has been loaded.

## Procedure

-  In the Flow Sequence Editor, select one or more nodes (press Ctrl and then click). The selected nodes are highlighted. Note To move the Run and Branch node and [Flow control nodes](<02.08.04.32.01.02.02_Flow_control_nodes.md>), you must wide select them. Note Only nodes at the same level can be selected together.
-  Select an insertion point not immediately adjacent to the chosen nodes, right-click and select Move.

## Results

The chosen nodes have been moved to the location at the chosen insertion point.

## What to do next

If you want to undo the moving action, press Ctrl + z.
