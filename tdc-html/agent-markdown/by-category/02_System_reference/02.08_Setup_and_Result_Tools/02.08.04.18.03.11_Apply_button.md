# Apply button

The Apply button is in the shortcut menu.

  ![Apply Button](<../../../../raw/97822.png>)

Clicking this button downloads the pin configuration data in the setup editor to the hardware.

## Functional changes

- Introduced before SmarTest 6.3.2
