# Method 1: Using the Mouse to Create Your Stepping Pattern

You can use this method to create a pattern for the whole wafer, or just select individual die that you want to probe.

- Choose DieSelect > START Cursor Select.
- Position the pointer over the desired die and click the left mouse button.
- Move to the next die, and click the mouse button.
- Repeat step 2 until all valid dies have been defined and sequenced. Alternatively, keep holding the left mouse button down and move the cursor over the desired die, in the required order.
- Choose DieSelect > END Cursor Select. Note Pressing the shift keyboard button in combination with the left mouse button de-selects a die.
