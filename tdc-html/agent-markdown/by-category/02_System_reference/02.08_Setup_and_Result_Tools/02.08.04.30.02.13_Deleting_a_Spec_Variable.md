# Deleting a Spec/Variable

- From within the Timing or Level Setup, click edit equations in the Select pulldown menu.
- Locate the spec you wish to delete and if it is used as part of an evaluation elsewhere in the equation set, replace it with a fixed value.
- Download these settings to firmware.

These last two manoeuvres represent an initial debugging check; provided they do not reveal errors (in the report window) you can continue in deleting the variables.

- If errors are revealed at this stage, repeat steps 2 and 3 with another value that does not yield errors.
- Delete the spec and download the new settings to hardware.
- In the Spec Tool main window, click Upload in the File pulldown menu.

The error report window (see [Error Checking Facilities](<02.08.04.30.02.19_Error_Checking_Facilities.md>)) appears, indicating that the spec is unknown.

- Delete each of the references to the spec, and click done when finished.
- Download these new settings to firmware.

## Functional changes

- Introduced before SmarTest 6.3.2
