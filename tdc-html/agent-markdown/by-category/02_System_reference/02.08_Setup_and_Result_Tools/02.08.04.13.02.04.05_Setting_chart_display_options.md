# Setting chart display options

#### Subtopics

- [Configuring value categories in result graphs](<02.08.04.13.02.04.05.01_Configuring_value_categories_in_result_graphs.md>)
- [Zooming the display of charts](<02.08.04.13.02.04.05.02_Zooming_the_display_of_charts.md>)

The display options of result charts in the Integrated Result Tool can be customized in various ways, using shortcut menu command, property dialog options, and preference settings.

## About this task

For information on zooming chart displays to set the detail view as desired, see [Zooming the display of charts](<02.08.04.13.02.04.05.02_Zooming_the_display_of_charts.md>).

Set the display options of charts to optimally adjust them to your purposes.

## Before you begin

[Create a result chart](<02.08.04.13.02.04.03_Displaying_test_results_in_analysis_views.md>) from the desired rows in the data navigation view.

## Procedures

### Specifying titles and labels

All charts are generated with default titles and axis labels. You can customize them:

- In the chart view, click the Properties button ![Trend Chart view_Properties button](<../../../../raw/136931.png>) on the toolbar or choose Properties from the context menu.

The properties dialog for the respective chart type opens.

- Click the Titles tab.
- Edit the available titles and labels as desired.

In general, labels are available for a title, a subtitle, and both axes. However, some charts may have additional or fewer titles. For details, check the property page of the appropriate [chart type](<02.08.04.13.03.04_Analysis_views.md>).

- Click OK.

The new titles and labels are displayed. Note that (if the Link button in the toolbar is activated) changing the selection in the data navigation view will reset the titles and labels to their defaults, except when you select another [grouped subitem](<02.08.04.13.02.03.05_Separating_summary_results_by_wafer__site__or_pin.md>) from the same main item. Changing the selection back also restores the titles and labels to your customized versions. When you unload a data log or quit SmarTest, the customized titles and labels are lost.

### Setting up the axes

For a description of how to set the start and end values of axes, see Numerically specifying the display area in [Zooming the display of charts](<02.08.04.13.02.04.05.02_Zooming_the_display_of_charts.md>).

Note that other ways of zooming the chart area also change the values displayed by the axes.

### Specifying the value categories

In several chart types, you can specify how many categories are displayed and, in shmoo plots, how they should be defined.

This is explained in [Configuring value categories in result graphs](<02.08.04.13.02.04.05.01_Configuring_value_categories_in_result_graphs.md>).

### Displaying or hiding the legend

Most charts have a legend that describes the color and symbol coding used in the graph. (This procedure does not apply to chart types that do not have a legend, such as FFC Pareto charts.) To set the visibility of the legend:

- Choose Window > Preferences.

The Preferences window opens.

- Open the Advantest 93000 > Result Tool category.

The list of preference pages for the Integrated Result Tool is displayed.

- Click the entry of the chart type you want to configure.

The chart type's preference page is displayed.

Note that not all chart types may have a preference page.

- To display the legend, activate the Show Legend option. To hide the legend, deactivate the option.
- Click OK.

### Repositioning the legend

You can have the legend displayed to the right of the chart or underneath it:

- If the legend is at the right, click the ![Trend Chart view_Switch Legend to Bottom button](<../../../../raw/140972.png>) toolbar button to display it below the chart.
- If the legend is below the chart, click the ![Trend Chart view_Switch Legend to Right button](<../../../../raw/140973.png>) toolbar button to display it at the right.

### Rotating the display

Some chart types let you rotate the display by 90 degrees, to allow a more useful presentation of the data or simply to meet personal preferences.

Depending on the chart type, the chart is rotated in different ways:

- For a [histogram](<02.08.04.13.03.04.02_Histogram_view.md>) or an [FFC Pareto chart](<02.08.04.13.03.04.06_FFC_Pareto_chart_view.md>), open the chart type's preferences page and choose the Bar option.

(For information on opening the preferences page, see steps 1 to 3 of Displaying or hiding the legend, above.)

- For a [parametric wafer map](<02.08.04.13.03.04.09_Parametric_wafer_map_view.md>) or a [bin wafer map](<02.08.04.13.03.04.11_Bin_wafer_map_view.md>), open the chart type's preferences page and activate the Exchange axes option.

(For information on opening the preferences page, see steps 1 to 3 of Displaying or hiding the legend, above.)

- For a [scatter chart](<02.08.04.13.03.04.05_Scatter_chart_view.md>), right-click anywhere in the chart and choose Swap Axes from the shortcut menu.

### Other settings

In [histograms](<02.08.04.13.03.04.02_Histogram_view.md>), you can display or hide lines that mark the mean, the two-sigma values, and the three-sigma values in the chart. These settings are available in the [chart properties](<02.08.04.13.03.04.02.01_Histogram_properties.md>) and the chart's shortcut menu.

In [box charts](<02.08.04.13.03.04.04_Box_chart_view.md>), you can specify the interval which is indicated by the whiskers. To do so, specify the desired value in the Whiskers tab in the [chart properties](<02.08.04.13.03.04.04.01_Box_chart_properties.md>) or through the chart's context menu.

In [shmoo plots](<02.08.04.13.03.04.08_Shmoo_view.md>), you can show or hide the values for each cell. This is set in the [shmoo preferences](<02.08.04.13.03.05.16_Shmoo_preference_settings.md>) and affects all shmoo plots.

In [parametric wafer maps](<02.08.04.13.03.04.09_Parametric_wafer_map_view.md>), you can mark all dies that belong to a particular site. To do so, specify the site in the Marks tab in the [chart properties](<02.08.04.13.03.04.09.01_Parametric_wafer_map_properties.md>) or choose it from the Mark site submenu of the shortcut menu.

In [scan views](<02.08.04.13.03.04.10_Scan_view.md>), you can:

- View each scan instance individually by choosing Group by Instance from the view's shortcut menu.
- View only a particular pin or instance by entering the name of the pin or instance in the Filter tab of the [Scan view properties dialog](<02.08.04.13.03.04.10.01_Scan_view_properties.md>). (Filtering by instance has only an effect if Group by Instance is active.

## Results

The chart display is updated according to your settings.
