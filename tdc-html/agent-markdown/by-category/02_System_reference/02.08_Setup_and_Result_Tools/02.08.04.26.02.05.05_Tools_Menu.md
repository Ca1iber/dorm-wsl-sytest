The Tools menu provides the following functions:

 |

Command

 |

Description

 |
 |

[Generate](<02.08.04.26.02.05.05.01_Generate.md>)

 |

Access the waveform editing tools.

 |
 |

[Test Mask](<02.08.04.26.02.05.05.02_Test_Mask.md>)

 |

Mask an arbitrary area of a graph.

 |
 |

[Translate](<02.08.04.26.02.05.05.03_Translate.md>)

 |

Transform the waveform located in the Waveform Graphs Tool.

 |
 |

[Inject Jitter](<02.08.04.26.02.05.05.04_Inject_Jitter.md>)

 |

Generate jitter signals which are often required when testing LAN devices.

 |
 |

[Cable Simulation](<02.08.04.26.02.05.05.05_Cable_Simulation.md>)

 |

Simulate the effects of various cable characteristics.

 |
 |

[Coherent Reconstruction](<02.08.04.26.02.05.05.06_Coherent_Reconstruction.md>)

 |

Reconstruct uploaded data as coherent data.

 |
 |

[Impedance Matching](<02.08.04.26.02.05.05.07_Impedance_Matching.md>)

 |

Design an impedance matching network graphically.

 |
 |

[Port Extension](<02.08.04.26.02.05.05.08_Port_Extension.md>)

 |

Compensate for errors (phase shift and loss) caused by the transmission line or fixture between the calibration plane and the port of the device.

 |
 |

[Demodulation](<02.08.04.26.02.05.05.09_Demodulation__Signal_Analyzer.md>)

 |

Graphical interface for demodulating RF waveforms.

 |
 |

[Per-Pin Signal Generator](<02.08.04.26.02.05.05.10_Per-Pin_Signal_Generator.md>)

 |

Generate test patterns for digital channels that source analog signals.

 |
 |

[Harmonics](<02.08.04.26.02.05.05.11_Harmonics.md>)

 |

Calculate the harmonic distortion and intermodulation frequencies from given fundamental frequencies.

 |
 |

[Load Datalog](<02.08.04.26.02.05.05.12_Load_Datalog.md>)

 |

Select a log file created by the event data log function.

 |
 |

[Select Waveform](<02.08.04.26.02.05.05.13_Select_Waveform.md>)

 |

Investigate the waveforms contained in the data log file.

 |
 |

[My Function](<02.08.04.26.02.05.05.14_My_Function.md>)

 |

Accesses the User Defined Function dialog box used to define your own functions.

 |

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.0.3: Impedance matching introduced
- SmarTest 7.0.3: Port Extension introduced
- SmarTest 7.1.2: Demodulation introduced
- SmarTest 7.2.0: Per-Pin Signal Generator introduced
