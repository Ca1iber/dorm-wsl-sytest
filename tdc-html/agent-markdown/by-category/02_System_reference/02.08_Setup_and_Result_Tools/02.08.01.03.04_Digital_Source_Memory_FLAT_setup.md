# Digital Source Memory FLAT setup

#### Subtopics

- [Creating a Digital Source Setup for DSM FLAT setup](<02.08.01.03.04.01_Creating_a_Digital_Source_Setup_for_DSM_FLAT_setup.md>)
- [Download the waveform data to the vector variables for DSM FLAT setup](<02.08.01.03.04.02_Download_the_waveform_data_to_the_vector_variables_for_DSM_FLAT_setup.md>)
- [Viewing and editing content in the MAIN label](<02.08.01.03.04.03_Viewing_and_editing_content_in_the_MAIN_label.md>)

The source data is downloaded to the MAIN label. It is called FLAT setup. This section introduces the FLAT setup flow, which is same to the DSM normal setup, except for the following points:

- You need not define the DSRC label.
- The setting of the Digital Source Setup is different.
- You need not insert the `SSRC` and `SRCV` instructions in the MAIN label.

The normal sequence for sourcing data form the MAIN label is:

- Define the pins (Tool: Pin Configuration Tool). For FLAT setup, you need not define a specific port for source pins.
- Define the Timing and Levels (Tool: Timing and Level Setup Tool). See [Timing and Levels](<02.08.01.03.03.03_Timing_and_Levels.md>).
- Create a MAIN label, which is for Digital Source Memory in the sequencer or vector memory. (Tool: Pattern Tool). See [Defining the MAIN Label](<02.08.01.03.03.04_Defining_the_Main_pattern.md>).
- Define the Digital Source setup including the vector variable configuration and its usage (Tool: Pattern Tool). See [Creating a Digital Source Setup for FLAT DSM setup](<02.08.01.03.04.01_Creating_a_Digital_Source_Setup_for_DSM_FLAT_setup.md>).
- Download the waveform data to the vector variables (Tool: Signal Analyzer, Test Methods). See [Download the waveform data to the vector variables for SDM FLAT setup](<02.08.01.03.04.02_Download_the_waveform_data_to_the_vector_variables_for_DSM_FLAT_setup.md>).
- Run the MAIN label for the test.
