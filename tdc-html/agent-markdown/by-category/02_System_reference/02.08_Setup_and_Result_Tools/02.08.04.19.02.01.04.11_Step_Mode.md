# Step Mode

The step mode option lets you specify how many steps you want between your positive and negative limits. Another feature is that when it comes to a transition, no more points are tested, see ["Only Test to First Transition" selected](<02.08.04.19.01.03.01_Only_Test_to_First_Transition__selected.md>). This can be useful as fast check of your pin margin.

- Select Step Mode in the Settings pulldown menu. A screen similar to that of the figure below appears. ![The Step Mode Dialog Box](<../../../../raw/24283.png>)
- Activate the Only Test to First Transition check box.
- Key in the number of steps required, and click done when finished.
