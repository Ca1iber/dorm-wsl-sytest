# derived_spec

An equation set contains one or more equation, each of which is defined according to the following syntax:

  ![derived_spec](<../../../../raw/21970.png>)

 |

spec_name

 |

An identifier (see [Common Syntax Elements](<02.08.04.14.02.02.02_Common_Syntax_Elements.md>)) defining the derived spec (variable) name. This is the name by which the derived spec is referenced throughout the equation set.

 |
 |

expression

 |

See [Syntax of expression](<02.08.04.14.02.02.01_Syntax_of_expression.md>).

 |
