# Changing Compatibility Options

The compatibility options allow to achieve period resolution compatibility among channel cards by enforcing a minimum allowed period resolution. They also allow to specify a period resolution limit.

## Procedure

-  In the Timing Setup window, click Select > Edit Specifications. This opens the SpecTool.
-  In the SpecTool click Change > Change Compatibility Options.
-  Select a specification.

The options vary depending on the selected specification. The "disable period resolution per port" option is only available for multiport specifications.

  ![Change Compatibility Options](<../../../../raw/127822.png>)
-  In the data entry field at the bottom, type the minimum period resolution (in nano seconds (ns)).

If available you may activate the "disable period resolution per port" option.

-  Click assign or done.

## Functional changes

- Introduced in SmarTest 7.1.2
