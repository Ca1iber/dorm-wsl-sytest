# DPS Margin Options

- Select which dps sets you want in your test.

If you want to specify individual sets rather than All or Primary a selection field appears.

- From the list of dps sets, highlight the ones you want to use, and click done when satisfied with your choice.Note Independent from your selection only those level sets will be used that are actually used in the vector pattern (either as primaries or by changing sets with the help of the sequencer command CLEV).
- Select whether to use the levels or current or both for the margin test.
