# Inserting a node

## Before you begin

The Flow Sequence Editor must be open.

## Procedure

-  In the Flow Sequence Editor, click an insertion point to highlight it. It appears red.
-  On the Palette, click the node you want to insert. The corresponding wizard window appears.
-  Fill in the wizard window, entering all desired variables and parameters, and setting any appropriate flags.
-  Click Finish.

## Results

The node appears in the testflow.

## What to do next

If necessary, edit the attributes of the nodes in the Properties view.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.2: You can insert a testflow node in the Flow Sequence Editor.
