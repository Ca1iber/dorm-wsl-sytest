# Downloading Your Timing Setup into the Firmware

When you finish creating the waveform, enter it into the firmware by clicking a different device cycle.

If you've used up more resources than are available, the system refuses to download your setup and issues an error message in the report window. See also [Watching System Resources](<02.08.04.34.06.06.01_Watching_System_Resources.md>).
