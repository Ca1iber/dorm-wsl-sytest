# Creating a port

## Before you begin

Make sure your pins are defined.

## Procedure

-  In the Test Program Explorer view, right-click Ports and choose New.

The New Port window opens.

-  Type the port name (for example, Port_IO) in the New Port field.
-  Click OK.

## Results

The Port Setup Editor for the new port opens. The Port Members area is blank.

 ![New port example](<../../../../raw/97847.png>)

## What to do next

Edit the port.

## Functional changes

- Introduced before SmarTest 6.3.2
