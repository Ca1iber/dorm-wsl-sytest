# Setting the period

#### Subtopics

- [Minimum period / maximum frequency of the sequencer](<02.08.04.34.06.05.01_Minimum_period___maximum_frequency_of_the_sequencer.md>)

Click period on the Select pulldown menu of the [Timing Setup window](<02.08.04.34.07_The_Timing_Setup_Window.md>).

Enter the desired period (in ns) into the period entry field. The allowed range depends on the type of system you have. For the minimum period or the maximum frequency, refer to [Minimum period / maximum frequency of the sequencer](<02.08.04.34.06.05.01_Minimum_period___maximum_frequency_of_the_sequencer.md>).

 Note If you have already set up some timing settings and subsequently changed the period to a smaller value, SmarTest may automatically correct the existing settings. In this case SmarTest displays a message in the report window.

## Functional changes

- Introduced before SmarTest 6.3.2
