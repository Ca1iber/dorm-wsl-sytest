# Separating summary results by wafer, site, or pin

Test summaries can be split into summaries for the tested wafers, sites, or pins using toolbar buttons or shortcut menu commands. In a similar way, you can split bin summaries into individual sites.

## About this task

Separate summary results if you want to examine the wafers, sites or pins separately or create graphs (such as trend charts) comparing them.

## Before you begin

[Open the data log](<02.08.04.13.02.02.02_Opening_a_data_log_for_examination.md>) that contains the summaries you want to examine.

## Procedure

-  Click the desired tab:

  - [Test Summary](<02.08.04.13.03.02.01_Test_summary_tab.md>): You can split test summaries by wafer, site, or pin.
  - [HW Bin Summary](<02.08.04.13.03.02.04_Hardware_bin_summary_tab.md>): You can split test summaries by site.
  - [SW Bin Summary](<02.08.04.13.03.02.05_Software_bin_summary_tab.md>): You can split test summaries by site.

-  Choose the desired grouping from the Group By submenu of the context menu or click the corresponding toolbar button:

  - ![Data log summary view_Toolbar, Group by Site button](<../../../../raw/136462.png>) Group by wafer
  - ![Data log summary view_Toolbar, Group by Site button](<../../../../raw/136463.png>) Group by site
  - ![Data log summary view_Toolbar, Group by Pin button](<../../../../raw/136464.png>) Group by pin

-  If you want to split the results by an additional category, repeat step 2.

Results that are already grouped by one category can be grouped by an additional category. For example, grouping a test summary that contains two wafers and two sites by both wafer and site will create four rows for each test:

  - Wafer 1, site 1
  - Wafer 1, site 2
  - Wafer 2, site 1
  - Wafer 2, site 2

## Results

The test or bin summaries in the tab are divided into one row per test(or bin) for each wafer, site, or pin (depending on the grouping chosen). If multiple groupings are chosen for test summaries, each test is divided into one row for each combination of the chosen categories. (For example, one row for each combination of site and pin.)
