# Default Settings

Unless you specify settings for a pin margin test, the defaults are used. These default pin margin settings are as follows:

- All used edges, pins, timing and level sets and level resources (vih, vil, voh, vol, vch, vcl, vt, ioh, iol, v3h, vth, swing, offset) will be used.
- Periods are used, with the exception of mutiport setups, in which case they are not used
- The current testsuite (dataset, label, testmethod and primary sets) and result focus site will be used
- There will be no DPS variations
- Parallel evaluation will be used - that is, all pins with the same setup settings are measured together. The edge delay range is relative to the actual settings (±5 % of period)
- The period range is ±1 % of the actual period
- The level range of ±0.2 V is relative to actual settings
- Load value of 0 to 30 mA (absolute values)

How to change the default settings is described in the subsequent modules.
