# Spec Variables

- In the Selections panel, sub panel Timing Options or Level Options select the SpecVar radio button.
- Click the All check box or select the spec variables you want to use for the pin margin test.

An example is shown in the figure below, which shows the selection of timing spec variables.

 ![Spec Variable Selection Window](<../../../../raw/24271.png>)
- From the Settings drop down menu select Timing Spec Vars or Level Spec Vars.

The window shown in the figure below will appear and you can then define the margins applicable to the spec variable that you have chosen. See [Example: Absolute and Relative Settings](<02.08.04.19.02.01.04.02_Example__Absolute_and_Relative_Settings.md>).

 ![Spec Variable Margins Selection](<../../../../raw/24272.png>)
