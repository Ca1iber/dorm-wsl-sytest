# Living machine concept

The [Channel Attributes Editor](<02.08.04.04_Channel_Attributes_Editor.md>) employs the living machine concept.

- SmarTest downloads complete entries to the firmware.
- The firmware status is reported via the annotation bars, and the markers and problems views.
