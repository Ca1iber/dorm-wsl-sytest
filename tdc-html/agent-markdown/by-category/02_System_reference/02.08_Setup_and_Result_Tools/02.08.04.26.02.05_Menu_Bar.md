The Menu Bar along the top of the main window includes a series of pull-down menus:

![Menu Bar](<../../../../raw/45894.png>)

- File (retrieving, printing, exporting, and saving data)
- Edit (finding and modifying data)
- View (controlling toolbars and how the Waveform Navigator Tool is presented)
- Format (changing context information of graph in Waveform Graphs Tool)
- Tools (opening waveform editing, complex functions, and user defined functions)
- Actions (downloading and uploading functions)
- Window (arranging and taking snapshots of graphs)
- Help (on-line information)
