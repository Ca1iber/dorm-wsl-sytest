# DPS Pins editor

#### Subtopics

- [DC Scale pin (DPS mode) setup](<02.08.04.18.03.01.03.01_DC_Scale_pin__DPS_mode__setup.md>)
- [Load capacitance connected to the DC Scale DPS128/DPS64](<02.08.04.18.03.01.03.02_Load_capacitance_connected_to_the_DC_Scale_DPS128_DPS64.md>)
- [Load capacitance connected to the DC Scale XPS256](<02.08.04.18.03.01.03.03_Load_capacitance_connected_to_the_DC_Scale_XPS256.md>)

The following table describes the parameters of DPS Pins editor.

![DPS Pins editor](<../../../../raw/354609.png>)

 | Name  | A descriptive name for the DUT Pin.

The pin name can have up to 16 alphanumeric characters. Spaces and the following characters are not allowed:

 # ; ( ' ' ) ? @ ,

Other SmarTest windows will always display the Pin name when they refer to a pin of the DUT.

 |
 | Pol  | This specifies the polarity of the DPS pin: POS. |
 | C[uF]  | The load capacitance. Either keep this field blank or fill it in depending on the DPS. See

- [Load capacitance connected to the DC Scale DPS128/DPS64](<02.08.04.18.03.01.03.02_Load_capacitance_connected_to_the_DC_Scale_DPS128_DPS64.md>)
- [Load capacitance connected to the DC Scale XPS256](<02.08.04.18.03.01.03.03_Load_capacitance_connected_to_the_DC_Scale_XPS256.md>)
 |
 | HW  | This column is not editable. After you enter the tester channel, it automatically shows the hardware information of this channel. In the DPS Pins editor, the following items may be displayed:

- DCS-DPS128HC, DCS-UHC4T, DCS-XPS256
 |
 | Comment  | Optional parameter.

You can add a description of the DPS pin in this column.

 |
 | Tester Channel  | Specify a DPS channel. |

## Functional changes

- Introduced in SmarTest 6.5.0
- SmarTest 7.1.3: Changed the parameter Polarity to Pol.
- SmarTest 7.1.3: Changed the parameter Load Capacitor [uF]/V-Ramp [us] to C[uF].
- SmarTest 7.1.3: Changed the parameter Instrument to HW.
- SmarTest 7.3.1: DC Scale PVI8 card added.
- SmarTest 7.3.2: DC Scale UHC4T card added.
- SmarTest 7.4.0: DC Scale AVI64 card added.
- SmarTest 7.5.0: DC Scale FVI16 card added.
- SmarTest 7.10.1: DC Scale XPS256 card added.
