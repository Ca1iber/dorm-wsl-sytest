# Changing the Description of Specification Sets

- Click Change Name in the Change pulldown menu.

A screen similar to that of the figure below appears.

  ![Changing a Specification Description](<../../../../raw/22028.png>)
- Highlight the specification set whose description you want to change.
- Key in a new description in the Description edit field. note that it must not contain a semicolon.
- Repeat this last step as often as required (for other specification sets), and click done when finished.

## Functional changes

- Introduced before SmarTest 6.3.2
