# SPECSET

Each spec set starts with a header, identified by the SPECSET keyword, and contains one or more spec definitions.

  ![specset](<../../../../raw/21978.png>)

 |

specset_number

 |

An integer in the range 1 to 99. The combination of this and the equation set number must be unique. This means that both equation set 1 and equation set 2 may contain a spec set numbered 4. In this instance, 2 spec sets will be created. Spec set numbers do not have to be consecutive, and gaps in the sequence are permitted. Thus it is perfectly legal do define spec sets 1,9,3 and then 4 for example.

 |
 |

specset_description

 |

A string of up to 60 characters. If it is enclosed in double quotes ("..."), everything inside the quotes is taken as the description - even spaces. If the description is not enclosed in double quotes, all characters up to but not including the first space is taken as the description.

 |

## Functional changes

- Introduced before SmarTest 6.3.2
