# Editing protocol specific wavetable and state map

## About this task

This task describes how to create or modify a protocol specific wavetable and state map.

Note This task is optional and only needed if you do not specify the protocol relevant definitions in the device wavetable already.Note The wavetable and state map you define here will be saved with the protocol definition. Thus they will be available if the protocol is imported to a new device.

## Before you begin

Utilizing port-based setups is not required. However, it is recommended that it is utilized to simplify the leverage and reuse of protocol setups.

## Procedure

-  Open the Wavetable view by clicking on the Wavetable tab of the protocol editor.  ![Wavetable of protocol definition](<../../../../raw/126264.png>)
-  Click into the content space to enter a new or modify existing wavetable and state map specifications. Note The syntax is equivalent to the one used within the device wavetable. Note Use pin roles only to define the wavetable and state map unique to your protocol here.
-  Save your modifications by pressing the CTRL + S key combination simultaneously.

## Results

You have defined the protocol specific wavetable and state map.

## What to do next

In order to use these wavetable segment you have to add the line USE_PROTOCOL "<protocolName>" [<portList>] to your device wavetable file.
