# Importing patterns

The pattern import function allows you to import patterns that were previously exported in the ASCII Interface format or in the STIL (Standard Test Interface Language) format. The pattern import uses either the ASCII Interface tool v2b (vector to binary conversion), or the STIL tool stil2bin (STIL to binary) respectively.

## About this task

You can import (and export) patterns using various SmarTest user interface areas: via the File menu, via the Test Program Explorer, and via the Pattern Explorer. The result will be the same.

The STIL import requires the stil2bin tool of the SmarTest Data Link (STDL) tool suite.

## Before you begin

To be able to import a pattern, the following files are required.

For the ASCII Interface format:

- <pattern_name>.avc (ASCII vector file)
- <pattern_name>.tmf (timing map file)
- <pattern_name>.wtb (contains only the name of the base wavetable for the imported pattern)

For the STIL format:

- <pattern_name>.pat.stil

## Procedure

-  To start an import operation do one of the following:

  - On the main menu bar, click File > Import > 93000 > Pattern.
  - In the Test Program Explorer, right-click the pattern icon and select Import.
  - In the Pattern Explorer, right-click a pattern and select Import.

-  For an ASCII Interface import:

  -  In the Import dialog box, the Ascii Converter option is already preselected, click Next.
  -  Select the Source Location directory. You may click the Browse button to select a directory. The Source Pattern field automatically displays the first import pattern found in the selected directory.
  -  To display a list of all possible import patterns, click the Source Pattern field's ![Selection box button](<../../../../raw/121799.png>) selection box button.
  -  In the Target Pattern field either accept the name or type a new name for the imported pattern.
  -  The Import dialog box also shows the wavetable name and the pin configuration file used.

-  For an STIL import:

  -  In the Import dialog box, select the Stil Converter option and click Next.
  -  Select the Source Location directory. You may click the Browse button to select a directory. The Source Pattern field automatically displays the first import pattern found in the selected directory.
  -  To display a list of all possible import patterns, click the Source Pattern field's ![Selection box button](<../../../../raw/121799.png>) selection box button.

-  To complete the import click Finish.

## Results

The imported pattern is merged to the existing set of loaded patterns using the specified Target Pattern name. For STIL imports, the target pattern name is predefined in the STIL file.

If the target pattern name already exists, then the existing pattern is first renamed before the merge takes place. The renamed (already existing) pattern gets a system generated name like <pattern_name>_______________________________________________0000001

The import operation also creates a log file and saves it in the source directory, together with the related input files:

- <pattern_name>.v2blog for the ASCII Interface format
- <pattern_name>.stilImplog for the STIL import
