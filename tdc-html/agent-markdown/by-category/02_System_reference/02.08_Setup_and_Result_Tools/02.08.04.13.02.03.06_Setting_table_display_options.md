# Setting table display options

Which columns are visible in a table and the order in which they are displayed are configured in the preferences. Column widths and grouping by wafer, site, or pin are set in the table itself.

## About this task

Set up the table as desired to best be able to focus on the relevant data in the table.

## Before you begin

[Open a data log](<02.08.04.13.02.02.02_Opening_a_data_log_for_examination.md>) and click the view and tab you want to configure.

## Procedures

### Specifying the visible columns and column order

- Open the preferences page that corresponds to the view or tab you want to configure:

  - [Test Summary preference settings](<02.08.04.13.03.05.21_Test_Summary_preference_settings.md>)
  - [Test Correlation preference settings](<02.08.04.13.03.05.20_Test_Correlation_preference_settings.md>) (for test summary tabs displaying [correlated data](<02.08.04.13.02.02.04_Correlating_data_logs.md>) stores)
  - [Device Summary preference settings](<02.08.04.13.03.05.05_Device_Summary_preference_settings.md>)
  - [Wafer Summary preference settings](<02.08.04.13.03.05.23_Wafer_Summary_preference_settings.md>)
  - [HW Bin Summary preference settings](<02.08.04.13.03.05.09_HW_Bin_Summary_preference_settings.md>)
  - [Hardware Bin Correlation preference settings](<02.08.04.13.03.05.07_Hardware_Bin_Correlation_preference_settings.md>) (for hardware bin summary tabs displaying [correlated data](<02.08.04.13.02.02.04_Correlating_data_logs.md>) stores)
  - [SW Bin Summary preference settings](<02.08.04.13.03.05.19_SW_Bin_Summary_preference_settings.md>)
  - [Software Bin Correlation preference settings](<02.08.04.13.03.05.17_Software_Bin_Correlation_preference_settings.md>) (for software bin summary tabs displaying [correlated data](<02.08.04.13.02.02.04_Correlating_data_logs.md>) stores)
  - [Raw Data preference settings](<02.08.04.13.03.05.14_Raw_Data_preference_settings.md>)
  - [Stream Data preference settings](<02.08.04.13.03.05.18_Stream_Data_preference_settings.md>)

- In the list of columns displayed, check those columns you want to appear in the table and uncheck the others.

Columns whose names are displayed in gray cannot be unchecked; they are always visible in the table.

You can click Select All to show all columns and Deselect All to hide all columns (except those that cannot be hidden).

- To rearrange columns, click a column you want to move to a different location and move it up or down in the list by clicking the Up and Down buttons.

The higher up a column is in the list, the further left it appears in the table.

Some columns in the test correlation preferences have a cyan background. These columns can be rearranged among themselves, but they cannot be mixed with normal columns (with a white background). These columns always appear at the left of the table.

- Click OK.

The columns are arranged in any open views as you have specified. They will be arranged the same way in any new views of the same type that you open.

### Adjusting the widths of table columns

You can adjust the widths of columns either individually or globally:

- To adjust the width of single column, drag the right border of its title.
- To adjust all columns at the same time, choose Width > Auto-Fit from the shortcut menu.

This makes each column just wide enough to fully show its contents.

- To have all columns automatically scaled to fit (as with the previous option) whenever you first open a data store, open the Advantest V93000 and go to the [Result Tool](<02.08.04.13.03.05_Preference_settings_for_the_Integrated_Result_Tool.md>)[ preference panel](<02.08.04.13.03.05_Preference_settings_for_the_Integrated_Result_Tool.md>) and switch on the Enable auto fit column width of table option. (THis does not affect currently open views, only views that you will open in the future.)

Adjusting columns only affects the view in which you perform the adjustment, not other open views of the same type.

### Grouping summaries

Certain [Data navigation views](<02.08.04.13.03.02_Data_navigation_views.md>) let you group test results, that is, you can separate one summary row into several rows, one for each wafer, site, or pin in the summary.

Test summaries can be grouped by wafer, site, and/or pin. Bin summaries can be grouped by site.

For details, see [Separating summary results by wafer, site, or pin](<02.08.04.13.02.03.05_Separating_summary_results_by_wafer__site__or_pin.md>).

## Results

The display of the view or tab you have arranged is adjusted according to your settings.
