# Opening a data log for examination

A data log that has been loaded into the [Data Log Explorer](<02.08.04.13.03.01_Data_Log_Explorer_view.md>) can be opened via double-clicking or a shortcut menu command into a [data navigation view](<02.08.04.13.03.02_Data_navigation_views.md>) where you can explore it. Opening a log automatically creates the statistical evaluations of the data it contains.

## About this task

Load a data log to examine the statistical summaries of its content.

## Before you begin

[Load the data log file](<02.08.04.13.02.02.01_Loading_and_unloading_data_log_files.md>). (This is not necessary if you want to examine the system data log stream, which is always automatically loaded.)

## Procedure

-  In the [Data Log Explorer](<02.08.04.13.03.01_Data_Log_Explorer_view.md>), select the data log that you want to open.

You can select more than one log by shift-clicking or control-clicking additional loaded logs.

-  Use any of these actions to open the selected log or logs:

  - Right-click and choose Open.
  - Press F3.
  - Double-click the log.

Double-clicking does not work for opening multiple logs at the same time.

## Results

Each selected log opens into one [data navigation view](<02.08.04.13.03.02_Data_navigation_views.md>) which displays the contents of the log in several tables containing statistical summaries.

Note that opened data log files are static (their content does not change), but the system data log stream is dynamic: If new data log entries are generated by a running test, they are immediately added to the open log. The summaries and result displays are updated accordingly.
