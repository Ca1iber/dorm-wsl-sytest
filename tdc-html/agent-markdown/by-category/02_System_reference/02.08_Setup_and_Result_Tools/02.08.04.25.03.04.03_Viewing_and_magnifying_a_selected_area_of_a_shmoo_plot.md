# Viewing and magnifying a selected area of a shmoo plot

On a shmoo plot, drag the mouse and select a range of cells. To view these cells in detail, right-click them and choose commands to perform the following actions:

- [Zoom out](<02.08.04.25.03.04.02_Zooming_shmoo_plots.md>) this range. The selected range is enlarged to occupy the whole shmoo page.

The other cells are also enlarged but hided. To view them, use the scroll bar around the shmoo plot.

- [Execute the shmoo test](<02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>). Only the selected cells are executed.
- Increase the resolution of the selected range and replace the current shmoo plot with this range.

To do this, right-click the selected area, select Magnify, and select:

  - 2x: On both the x-axis and y-axis, the amount of the intervals (step width) between the start and stop positions on axes will be twice that of the current one.
  - 5x: On both the x-axis and y-axis, the amount of the intervals (step width) between the start and stop positions on axes will be five times that of the current one.
  - 10x: On both the x-axis and y-axis, the amount of the intervals (step width) between the start and stop positions on axes will be ten times that of the current one.

After that:

  - The number of shmoo cells on the selected range is increased to 4 or 25 or 100 times depending on 2x, 5x, 10x you have selected.
  - The current shmoo plot is replaced with this magnified area.
  - In the Properties view, the values in the start, stop and step fields for the x-axis and y-axis setups are changed to the corresponding values of the magnified area.
  - You cannot return to the original settings and shmoo plots unless you manually change the settings back.

- If you have selected one cell, you can replace the primary settings in the Properties view with the primaries of this cell.

  - To do this, right-click this cell and select Apply to HW.
  - To return to the original settings, right-click this cell and select Restore.

- To view the boundary positions of this range, see the Selected Info panel in the Properties view.
- To view failing pins information, hover the mouse over a cell in the shmoo plot. A tooltip displays a list of all failing pins.

## Functional changes

- Introduced in SmarTest 7.2.0
- SmarTest 7.2.1: Adds a new command Magnify, which will replace the current shmoo plot with the selected area and increase the resolution as well as the number of the shmoo cells of the selected area.
- SmarTest 7.5.0: Adds a tooltip to display failing pin information in cells.
