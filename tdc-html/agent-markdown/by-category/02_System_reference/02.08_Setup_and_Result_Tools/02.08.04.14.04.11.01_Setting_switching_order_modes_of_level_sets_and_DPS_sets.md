# Setting switching order modes of level sets and DPS sets

When switching level sets and DPS sets between two test suites, you can set the switching order.

## Before you begin

Make sure more than one level sets and DPS sets are defined.

## Procedure

-  On the menu, click Edit > Set Level Switching Order.

The SLDO - Change IO/DPS Level Switching Order window opens.

-  Select order type (FDSL or CVDL) and report type (ALL, FLSD, AMBI or NONE).
-  Click Done.  ![SLDO - Change IO/DPS Level Switching Order window](<../../../../raw/98311.png>)  Note If you edit the settings in the level master file and save the file, the change will be saved in the GENERAL entry of the level master file. (Refer to [Master file format for level setup](<02.08.04.14.02.05.01_Master_file_format_for_level_setup.md>).)

## Results

When executing the testflow, the level sets and DPS sets between test suites are switched as the defined order.

If you want to apply different switching order modes during the execution of a testflow, execute firmware command "SLDO" by using FW_TASK API.
