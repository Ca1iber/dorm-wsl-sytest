# Level spec set

An equation based spec set contains one or more spec, each of which is defined according to the following syntax:

  ![spec](<../../../../raw/21967.png>)

 |

spec_name

 |

An identifier. This must refer to a spec name defined in the respective specification component.The variable names must not begin with a keyword for the level or timing setup file. These keywords are:

   | |
 |

unit

 |

Optional, and contains up to 3 characters defining the spec's unit. These characters must be enclosed within square brackets ([...]).

 Note This defines also the unit shown in the spec name area of the spec tool, see [The Spec Tool window](<02.08.04.30.01_The_Spec_Tool_window.md>).

The unit of the spec defined in the equation set will be used

   | Note When defining these specs in the respective specification component, they must be declared under the same equation sets in which they are referenced here. If they are not, an error will be reported.
