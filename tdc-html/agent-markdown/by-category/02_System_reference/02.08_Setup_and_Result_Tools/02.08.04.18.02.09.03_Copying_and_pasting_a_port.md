# Copying and pasting a port

## About this task

By the function of copying and pasting, you can define a new port with other port as a starting point.

## Before you begin

Make sure at least one port is defined.

## Procedure

-  In the Test Program Explorer view, right-click the port name you want to copy and select Copy.
-  Right-clicke of the ports and select Paste...
-  Naming a Port window is displayed. Type the new port name in the Port Name text box. Click OK.

## Results

The Port Editor of the pasted port opens. The setting of the new port is same as the original port.

## What to do next

Edit the pasted port.
