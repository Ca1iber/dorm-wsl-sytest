# Watching System Resources

If your device needs complex timing, you have to keep an eye on the system's resources, and if necessary, take steps to preserve them.

Whenever you are entering waveforms, you are using up system resources. You can optimize the use of the system's resources by careful selection of edges and allocation of actions to edges, as well as utilizing the waveform reuse and the waveform index reuse functions.

A complete list of the system's resources is provided in [Timing edges](<02.08.04.34.01.01_Timing_edges.md>). A discussion of the use of the system's resources and the various dependencies is included as part of a worked example at the end of this chapter.
