# Result Configuration

#### Subtopics

- [Result Mode](<02.08.04.08.04.01_Result_Mode.md>)
- [Execution Mode](<02.08.04.08.04.02_Execution_Mode.md>)
- [Advanced](<02.08.04.08.04.03_Advanced.md>)

![Bandwidth Related Settings](<../../../../raw/128339.png>)

- The Result Mode tab of this window allows you

  - to configure result granularity and error code resolution of the detailed error map,
  - to define the location of the detailed error map,

- The Execution Mode tab lets you switch off the option to retrieve edge information by repeating the test.
- The Advanced tab lets you define the system response to a possible recording abort if the detailed error map is located in the external memory.

Such a recording abort can occur when the amount of data to be written becomes too large for the bandwidth of the memory. It will have the effect that not all requested results can be stored. For more information, and also possible remedies, see [Dealing with storage problems on Smart Scale systems](<../02.06_Command_Reference/02.06.11.01.02.01.05_Dealing_with_storage_problems_on_Smart_Scale_systems.md>).
