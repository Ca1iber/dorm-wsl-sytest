# Deleting variables

## Before you begin

Make sure that the variable has been defined and not used in the testflow (the testflow nodes using the variable have been removed).

## Procedure

-  On the Variables page of the Flow Data Editor, click the row number of the variable you want to remove, and then press delete.
-  The Confirm window opens. Click OK.

## Results

The variable is removed.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.2: You can delete variables on the Variables page.
