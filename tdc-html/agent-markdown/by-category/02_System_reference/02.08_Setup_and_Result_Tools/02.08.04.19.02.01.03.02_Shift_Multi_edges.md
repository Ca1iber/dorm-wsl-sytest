# Shift Multi edges

The Shift Multi-edges check box allows you to shift more than one edge at a time. Consider the example of cases A and B below, where d1 is shifted from 4.5 ns to 5.5 ns, and d2 from 9 ns to 11 ns, in 50 steps:

Case A: Shift Multi-edge is not selected. The following steps will proceed:

- d1 is set to 4.50 ns, then the functional test is performed, and a pass/fail result for step 1 is generated.
- d1 is set to 4.52 ns, then the functional test is performed, and a pass/fail result for step 2 is generated.
- d1 is set to 4.54 ns, then the functional test is performed, and a pass/fail result for step 3 is generated. This pattern repeats until step 50, as shown in 4, the next step shown.
- d1 is set to 5.50 ns, then the functional test is performed and pass/fail results are generated.

After d1 has completed step 50, d2 completes its sequence in the same way, as shown in the following steps:

- For step 1, d2 is set to 9.00 ns, then the functional test is performed, and a pass/fail result for step 1 is generated.
- For step 2, d2 is set to 9.04 ns, then the functional test is performed, and a pass/fail result for step 2 is generated.
- For step 3, d2 is set to 9.08 ns, then the functional test is performed, and a pass/fail result for step 3 is generated.This pattern continues until step 50, as shown in 4 below.
- d2 is set to 11 ns, then the functional test is performed, and a pass/fail result for step 50 is generated.

Case B: When Shift Multi-edge is selected. The following steps will proceed:

- d1 is set to 4.50 ns. d2 is set to 9.00 ns. The functional test is performed and a pass/fail result is generated.
- d1 is set to 4.52 ns. d2 is set to 9.04 ns. The functional test is performed and a pass/fail result is generated.
- d1 is set to 4.54 ns. d2 is set to 9.08 ns. The functional test is performed and a pass/fail result is generated.

This pattern continues until step 50, as shown below:

- di is set to 5.50 ns. d2 is set to 11 ns. The functional test is performed and a pass/fail result generated.
