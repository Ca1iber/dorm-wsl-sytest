# Adding a limit on the Tests page

## About this task

You can add or delete limits (including default limits) for any test suite based on a test method in these locations:

- The [Tests page](<02.08.04.32.03.01.03_Tests_page.md>) of the Flow Data Editor
- The Properties view

This topic describes adding a limit on the Tests page.

## Before you begin

Make sure that your testflow includes at least one test suite based on a test method.

## Procedure

-  On the Tests page, right-click the editable region and select Add Limit.
-  The Add a Test window opens. In the Select a TestSuite list, select the test suite to which you want to add the limit.  ![Add a Test window](<../../../../raw/110958.png>)
-  Add a limit:

  - To add a default limit, choose one of the six default limits from the Test Name list. You cannot modify these limits' ranges.
  - To add a custom limit, type a name in the Test Name text box. Then edit the limit range. You can add a unit string to each limit value. You can use the system-defined unit specifiers listed in [Unit Identifiers](<../02.07_Test_Method_Reference/02.07.03.01.02_Unit_Identifiers.md>) or specify a new unit specifier. A unit string takes on the following formats: 1.05[mV] or 1.05 mV.

-  (Optional) Fill in the Test Number text box.
-  Click OK.

## Results

The new limit is shown on the Tests page and in the Properties view.

## What to do next

Use this limit in the test method.
