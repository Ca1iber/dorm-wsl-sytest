# DPS connect setup time and voltage ramps

#### Subtopics

- [DPS pins with connect setup time](<02.08.04.14.06.01.02.01_DPS_pins_with_connect_setup_time.md>)
- [DPS pins with voltage ramps](<02.08.04.14.06.01.02.02_DPS_pins_with_voltage_ramps.md>)

To specify setup times and delays for DPS pins you have two options:

- [DPS connect setup times](<02.08.04.14.06.01.02.01_DPS_pins_with_connect_setup_time.md>), or
- [Voltage ramps](<02.08.04.14.06.01.02.02_DPS_pins_with_voltage_ramps.md>)

Both are supported for all DPS channels (DPS-slot DPS and DC Scale DPS).

## DPS connect setup time

With the connect setup time you specify the timing sequence or delay from the connect of a pin to a common reference time point.

## Voltage ramps

The voltage ramp parameters (vout_rise_..., vout_fall_...) allow to specify setup times and slew rates separately for rising and falling DPS voltage transitions. They can be used for all DPS voltage changes, regardless whether they are caused by a connect, disconnect, a change within the same DPS set, or a switch between DPS sets.

Note Within one DPS-set of one channel, you can specify either a connect setup time or a voltage ramp. You cannot specify both within the same set.
