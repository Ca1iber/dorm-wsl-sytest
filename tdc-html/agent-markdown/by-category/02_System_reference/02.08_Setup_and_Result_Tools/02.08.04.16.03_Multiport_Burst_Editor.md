# Multiport Burst Editor

#### Subtopics

- [Creating a multiport burst](<02.08.04.16.03.01_Creating_a_multiport_burst.md>)
- [Creating and assigning a port burst](<02.08.04.16.03.02_Creating_and_assigning_a_port_burst.md>)
- [Editing a multiport burst setup](<02.08.04.16.03.03_Editing_a_multiport_burst_setup.md>)
- [Working with sync groups](<02.08.04.16.03.04_Working_with_sync_groups.md>)

A multiport editor is one of the pattern tools. It gives access to multiport bursts and the individual port bursts. Port bursts are pattern sequences for a specific port (group of pins). A port burst is always part of a multiport burst.

You can open any number of multiport burst editors. Every instance of the multiport burst editor provides an Overview page plus one or more tabbed pages. These tabbed pages display the individual port bursts and the sync groups.

  ![Multiport burst editor](<../../../../raw/128878.png>)

- The ![Show Multiport Burst in Hierarchy](<../../../../raw/128874.png>) Overview page is always visible and shows all port burst on one page. In expanded mode the Overview page can show start cycle and start time per call as additional columns (must be set as Appearance option on the [Pattern Tool preference page](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.14.12_Pattern_Debug_Tool_preference_page.md>)). The tooltip of these columns will show cycle count and duration per call.
- The ![Multiport burst](<../../../../raw/120065.png>)port burst pages show the individual port bursts. The port burst tabs are ordered alphabetically. These pages can be hidden.
- The ![sync/sequencer group tab](<../../../../raw/128935.png>) sync group pages (named DEFAULT unless differently named) show the port bursts per assigned synchronization group. Multiple sync group tabs are ordered alphabetically. These pages can be hidden.
- The blue-white marker ![Results](<../../../../raw/129291.png>) indicates a current primary and expandable item.
- The red-green marker ![Results](<../../../../raw/129292.png>) indicates an item with results.

## Main toolbar icons

To a large extend, the icons for the multiport burst editor functions on the main toolbar are identical to those for the [Pattern Editor](<02.08.04.16.02_Pattern_Editor.md>). That includes the red cell coloring and [icons indicating failure data](<02.08.04.16.02.06.13_Displaying_failure_data.md>). The following icons are provided for the multiport burst editor in addition or have an additional function:

 |

Icon

 |

Function

 |
 |  ![Expand/collapse button](<../../../../raw/99926.png>) |

Expands / collapses the current editor page. The other pages of the editor are not affected. The expanded mode shows

- the number of cycles per port burst on the Overview page.
- the Vector#, Instruction, and Comment column on a port burst page.
- the vectors of a sync group aligned in timeline.
- fail information per pattern on the Overview and the sync pages.

To activate the icon you must execute the testflow.

 |
 |  ![Enable expand selection mode](<../../../../raw/129178.png>) |

Available only for the burst pages of a multiport burst editor.

Enables / disables the expanding (![Expand/collapse button](<../../../../raw/99926.png>)) of only the selected CALL instructions of a port burst ([or burst](<02.08.04.16.02_Pattern_Editor.md>)). If enabled, the expanded port burst page will show the "Expand Selection Mode" entry.

 |
 |  ![Hide/Show all Sync Group Tabs](<../../../../raw/128933.png>) |

Hides / shows (toggles) the sync group tabs (pages) on the current multiport burst editor.

 |
 |  ![Hide/Show all PortBurst tabs](<../../../../raw/128934.png>) |

Hides / shows (toggles) the port burst tabs (pages) on the current multiport burst editor.

 |
