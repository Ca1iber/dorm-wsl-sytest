# How Match Loops are represented

A Match Loop is identified in the Timing Diagram by a vertical line headed by MTCH. Note that if the pattern contains more than one Match Loop, the timing diagram can reconstruct the results only until the start of the first Match Loop.

## Functional changes

- Introduced before SmarTest 6.3.2
