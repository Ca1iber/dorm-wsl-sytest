# Transferring the shmoo tests from the Shmoo Tool to testflows

Once you [set up a shmoo test in the Shmoo Tool](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>), you can transfer it to a testflow either as a new test suite or to replace an existing test suite.

## Before you begin

Make sure:

- A testflow is loaded with full setups and is opened with [Flow Sequence Editor](<02.08.04.32.03.02_Flow_Sequence_Editor.md>).
- [The Shmoo Tool is open](<02.08.04.25.01_Opening_the_Shmoo_Tool.md>) and a shmoo page is displayed in the shmoo editor.

If no shmoo pages are displayed, create a new shmoo page by right-clicking the bottom bar of the shmoo editor and select New.

## Procedure

-  Click a shmoo page in the shmoo editor.
-  In this shmoo page related Properties view, [set up a shmoo test](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>).
-  To insert the shmoo test to the opened testflow, right-click a node in the testflow, select Shmoo > Insert Test Suite From Shmoo Tool, and then select the shmoo page name.

  - Below the node, a new test suite is created with the same name as the shmoo page.
  - The setups of the new test suite is the same setups as the shmoo test in the Shmoo Tool.

-  To replace an existing test suite in the testflow with the shmoo test, right-click this test suite and select Shmoo > Overwrite Test Suite From Shmoo Tool, and then select the shmoo page name.

  - The test suite is replaced with a new test suite, which has the same setups as the shmoo test in the Shmoo Tool.
  - The name of the new test suite is the name of the shmoo page.
