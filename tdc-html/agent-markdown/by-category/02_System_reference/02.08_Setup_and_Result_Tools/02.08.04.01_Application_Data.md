# Application Data

#### Subtopics

- [Selecting a new application model file](<02.08.04.01.01_Selecting_a_new_application_model_file.md>)
- [Creating an Application Data File](<02.08.04.01.02_Creating_an_Application_Data_File.md>)
- [Loading/Saving an Application Data File](<02.08.04.01.03_Loading_Saving_an_Application_Data_File.md>)
- [Editing the Application Data File](<02.08.04.01.04_Editing_the_Application_Data_File.md>)

The application data file consists of the data within the application model file which is used as parameters for the test program, test site, temperature, and so on. The values you entered in the application data editor can be accessed with [APPLIC_DATA_EDITOR_INPUT](<../02.09_Test_Program_Management/02.09.01.02.05.02.03_APPLIC_DATA_EDITOR_INPUT.md>). The retrieved data can be used as a regular application model variable. For example, it can be used to construct a file name.

The application data file can be displayed and edited within the Application Data Editor Window. The application model file together with the data in the application data file, is called the Application.
