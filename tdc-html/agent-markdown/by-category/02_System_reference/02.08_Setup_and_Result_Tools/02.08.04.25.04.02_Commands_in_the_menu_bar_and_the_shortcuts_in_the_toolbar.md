# Commands in the menu bar and the shortcuts in the toolbar

In the menu bar and toolbar of SmarTest, the following commands and shortcuts are added for Shmoo Tool.

In the menu bar of SmarTest, after you select Shmoo, you will see these commands:

- ZoomIn: To enlarge a shmoo plot or the selected area of a shmoo plot.

The shortcut in the toolbar of SmarTest is ![Zoom in icon](<../../../../raw/136469.png>).

- ZoomOut: To reduce an enlarged shmoo plot.

The shortcut in the toolbar of SmarTest is ![Zoom out button](<../../../../raw/136470.png>).

Refer to [Zooming the shmoo plots](<02.08.04.25.03.04.02_Zooming_shmoo_plots.md>).

- SnapShot: To take a picture of a shmoo plot with its setups and save the picture as a .png file.

The shortcut in the toolbar of SmarTest is ![Snapshot icon](<../../../../raw/136525.png>).

Refer to [Taking a picture of a shmoo plot in the Shmoo Tool](<02.08.04.25.03.06_Taking_a_picture_of_a_shmoo_test_in_the_Shmoo_Tool.md>).

- Magnify: To increase the resolution of the selected area of a shmoo plot and replace the shmoo plot with this area. For details, refer to the descriptions about "Magnify" in [Viewing and magnifying a selected area of a shmoo plot](<02.08.04.25.03.04.03_Viewing_and_magnifying_a_selected_area_of_a_shmoo_plot.md>).
- Run Shmoo: To execute a shmoo test set up in the Shmoo Tool.

The shortcut in the toolbar of SmarTest is ![execution button](<../../../../raw/136388.png>).

- Run Fast Shmoo: Its shortcut in the toolbar of SmarTest is ![fast execution button in the Shmoo Tool](<../../../../raw/136389.png>).

  - If you have input #number or number in [the ](<02.08.04.25.03.02.01_The_parameters_for_the_x_y-axis_setups_for_a_shmoo_test.md>)[step](<02.08.04.25.03.02.01_The_parameters_for_the_x_y-axis_setups_for_a_shmoo_test.md>)[ field for the x-axis or y-axis](<02.08.04.25.03.02.01_The_parameters_for_the_x_y-axis_setups_for_a_shmoo_test.md>), the Fast Execute Shmoo command will execute as you would have input #<total steps>/<2> in the step field.
  - If you have input #<number1>/<number2> or f#number in the step field for the x-axis or y-axis, this command does not take effect.

For the above syntaxes that can be input to the step field, see [The parameters of x-axis setups and y-axis setups in the setup panel](<02.08.04.25.03.02.01_The_parameters_for_the_x_y-axis_setups_for_a_shmoo_test.md>).

- Abort Run: To abort a running shmoo test.

The shortcut in the toolbar of SmarTest is ![aborting execution buttion in the Shmoo Tool](<../../../../raw/136390.png>).
