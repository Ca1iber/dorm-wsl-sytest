# The Cursor and Marker Overlay

The marker overlay provides:

- a cursor for absolute and relative timing settings
- a marker for absolute and relative timing settings. ![Timing Setup Window: Timing Entry - Cursor and Marker Area](<../../../../raw/21818.png>)

You select the marker or the cursor by clicking the appropriate radio button in the overlay. Alternatively click the appropriate sign in the Marker/Cursor Selection Space.

The cycle entry field displays the number of the cycle where the marker (or the cursor) is currently located. Similarly, the offset [ns] entry field gives its offset from the beginning of that test system cycle.

The time delta [ns] readout gives you the time difference between the positions of the marker and the cursor, and can be positive or negative, depending on the relative positions of the marker and the cursor.

See also [Using the Marker and Cursor](<02.08.04.34.06.08_Using_the_Marker_and_Cursor.md>).
