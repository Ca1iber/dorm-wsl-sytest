# Fixture Delay Tool

#### Subtopics

- [Fixture delay calibration](<02.08.04.10.01_Fixture_delay_calibration.md>)
- [Measuring fixture delays](<02.08.04.10.02_Measuring_fixture_delays.md>)
- [Fixture Delay Tool window](<02.08.04.10.03_Fixture_Delay_Tool_window.md>)

This section describes how to use the Fixture Delay Tool to measure the signal delay contributed by the DUT board wiring.

For a general description of the fixture delay calibration, refer to [Fixture delay calibration](<02.08.04.10.01_Fixture_delay_calibration.md>).

To open the Fixture Delay Tool, on the [Test Program Explorer](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02_Test_Program_Explorer.md>), right-click Channel Attributes, and choose the editor from the context menu.

## General recommendations

Note The Fixture Delay Tool measures the delay in the signal path between a specific pogo pin and the corresponding pin at the device socket. The DUT is removed during the fixture delay measurement and the Fixture Delay Tool recognizes the open device pin as the end of the signal path. If a large impedance mismatch exists within the signal path, it is possible that the Fixture Delay Tool will measure the signal delay from the pogo pin to this point rather than the complete path to the device socket. This condition can occur when an active device such as a relay exists in the signal path.Note The fixture delay calibration will keep the utility line configuration throughout the whole calibration. It will also not reset the utility lines to the default state before starting the calibration.Note If you want to run the fixture delay with any relays or other hardware energized by the utility lines, you must carefully select the utility line configuration before performing the fixture delay calibration. Refer to [Using the Utility Line View](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.05.05_Using_the_Utility_Line_View.md>) and [Utility line control software](<../../99_Unlisted_or_Unreferenced/99.0190_Utility_line_control_software.md>) for the utility lines for more information on setting them up.
