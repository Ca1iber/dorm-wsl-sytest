# Deleting a vector variable

## Before you begin

The vector variable has been created.

## Procedure

-  In the Pattern Explorer, double click a pattern which the vector variable to be removed is attched to.

The pattern is opened in the Pattern Editor. The attached vector variable is displayed in the Outline view.

-  In the Outline view, right-click the vector variable and select Delete.  Note If you delete the last vector variable associated with a pattern, a dialog will ask you to confirm whether you want to remove the corresponding capture setting or not.

## Functional changes

- Introduced in SmarTest 6.5.2
