# Execute menu

The functions in the Execute menu allow you to set up and perform fixture delay measurements.

 |

Item

 |

Function

 |
 |

Measure

 |

Use the Measure selection to perform a regular fixture delay measurement on the selected channels.

 |
 |

Measure with dual transmission lines

 |

In some test applications a DUT board is designed such that two pogo pins are connected to one device pin. For example, one pogo pin is used for the drive signal and the other pogo pin is used for the receive signal. This is done to eliminate the "round trip" signal delay. To measure the fixture delay on this type of DUT board, select the channels for measurement, then use the Measure with Dual Transmission Lines selection from the Execute menu. This measurement requires you to place a short device on the DUT board. The short device is a pseudo-device that connects all signal pins to ground.
