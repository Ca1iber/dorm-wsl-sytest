# Focusing the Timing Diagram

Positioning the Timing Diagram on a section of your test:

- Scroll the Timing Diagram to the area of the test that you want to view.
- If there is no data for the Timing Diagram in this part of the test, perform the following actions:

  - Start the [Error Map Tool](<02.08.04.08_Error_Map_Tool.md>) if not yet done:

On the menu, click 93000 > Results > Error Map.

  - On the Timing Diagram menu click Display > align displays
  - On the Error Map tool menu click Result > Execute

The Timing Diagram now has data for the section that you have selected.
