# Saving the system data log stream

The system data log stream can be saved to disk as an EDL file by choosing the Save and Clear shortcut menu command in a [data navigation view](<02.08.04.13.03.02_Data_navigation_views.md>).

## About this task

Save the data log stream when you want to preserve it for future examination.

## Procedure

-  [Open](<02.08.04.13.02.02.02_Opening_a_data_log_for_examination.md>) the system data log for examination.
-  In any tab of the [data navigation view](<02.08.04.13.03.02_Data_navigation_views.md>), right-click and choose Save and Clear from the shortcut menu.

A standard Save dialog is displayed.

-  Specify the name and location for the EDL file and click OK.

## Results

The current system data log stream is saved as an EDL file in the specified location. The system data log stream is cleared.

## What to do next

If you want to analyze the saved file, load it as described in [Loading and unloading data log files](<02.08.04.13.02.02.01_Loading_and_unloading_data_log_files.md>) and open it as described in [Opening a data log for examination](<02.08.04.13.02.02.02_Opening_a_data_log_for_examination.md>).
