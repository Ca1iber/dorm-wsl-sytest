# Principles of operation of the Integrated Result Tool

#### Subtopics

- [Result perspective overview](<02.08.04.13.01.01_Result_perspective_overview.md>)

The Integrated Result Tool summarizes the results of data log files or the system data log stream in various ways and provides statistical values for them. You can filter and arrange the data and display it visually in different graphs to draw conclusions and develop theories about the underlying tests.

To work with data from an STDF or EDL data log file in the Integrated Result Tool, you first [load](<02.08.04.13.02.02.01_Loading_and_unloading_data_log_files.md>) the file into the tool's [Data Log Explorer](<02.08.04.13.03.01_Data_Log_Explorer_view.md>). The system data log is always automatically loaded.

You can display any loaded data log or stream in a [data navigation view](<02.08.04.13.03.02_Data_navigation_views.md>). Data navigation view display automatically generated summary and statistical information about the contents of a data log in tables. The data is evaluated per test, wafer, device, or bin. These summary views are the core of the Integrated Result Tool. You can sort and filter them, and you can view their contents as raw data or graphs (see below).

You can display the data underlying each summarized item by clicking it and opening a [raw data view](<02.08.04.13.03.03.01_Raw_data_views.md>) (or [Stream data view](<02.08.04.13.03.03.02_Stream_data_view.md>), in the case of the system data log) for it. These tables can also be filtered. In addition, you can control to a limited degree which of the raw underlying data is used for the summaries in the data navigation views.

The [Analysis views](<02.08.04.13.03.04_Analysis_views.md>) are based on the data from the data navigation views and display the same information in visual or tabular ways. The views allow some control over their formatting.

The Integrated Result Tool is linked to other SmarTest tools:

- [Testflow Tool](<02.08.04.32_Testflow_Tool.md>): From a data navigation view, you can open the definition of a test or bin in the Testflow Tool; you can also open the limit specification for a test. When you right-click a test in the Testflow Tool, you can open its results in the Integrated Result Tool from the shortcut menu.
- [Pattern Explorer](<02.08.04.16.01_Pattern_Explorer.md>): You can open the Pattern Explorer with a shortcut menu command from an FFC Pareto chart to display the selected failing cycle.
