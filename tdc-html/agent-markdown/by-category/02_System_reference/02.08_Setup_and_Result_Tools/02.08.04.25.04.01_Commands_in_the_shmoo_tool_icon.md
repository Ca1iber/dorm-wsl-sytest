# Commands in the shmoo tool icon

After you right-click the [shmoo tool icon](<02.08.04.25.02_The_interface_of_the_Shmoo_Tool.md>) (![Shmoo Tool Icon](<../../../../raw/136506.png>)), which is in the Test Results folder in the Test Program Explorer view, you will see these commands:

- New: To create a new shmoo file to be opened with the Shmoo Tool. The new file will be saved in the <device directory>/shmoo directory.
- Open: To open the Shmoo Tool. Refer to [Opening the Shmoo Tool](<02.08.04.25.01_Opening_the_Shmoo_Tool.md>).
- Load: To load an existing shmoo file.
- Reload: To load a loaded file again.
- Save: To save all shmoo pages related shmoo setups, results and plots to the current file. See [Saving shmoo tests in the Shmoo Tool](<02.08.04.25.03.05_Saving_shmoo_tests_in_the_Shmoo_Tool.md>).
- Save As: To save all shmoo pages related shmoo setups, results and plots to a new file. See [Saving shmoo tests in the Shmoo Tool](<02.08.04.25.03.05_Saving_shmoo_tests_in_the_Shmoo_Tool.md>).
- Save Setup: To only save all shmoo pages related shmoo setups to the current file. See [Saving shmoo tests in the Shmoo Tool](<02.08.04.25.03.05_Saving_shmoo_tests_in_the_Shmoo_Tool.md>).
- Save Setup As: To only save all shmoo pages related shmoo setups to a new file. See [Saving shmoo tests in the Shmoo Tool](<02.08.04.25.03.05_Saving_shmoo_tests_in_the_Shmoo_Tool.md>).
