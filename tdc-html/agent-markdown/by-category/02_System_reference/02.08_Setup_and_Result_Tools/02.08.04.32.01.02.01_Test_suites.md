# Test suites

#### Subtopics

- ["Run" and "Run and Branch" test suites](<02.08.04.32.01.02.01.01_Run__and__Run_and_Branch__test_suites.md>)
- [Special test suites](<02.08.04.32.01.02.01.02_Special_test_suites.md>)
- [Floating test suite](<02.08.04.32.01.02.01.03_Floating_test_suite.md>)
- [Multibin SmartDisconnect test suite](<02.08.04.32.01.02.01.04_Multibin_SmartDisconnect_test_suite.md>)

This is the collective name given to individual, independent, executable device tests (a functional test, for example). The test suite contains the various timing and level sets and equations and the set of test suite flags.

  There are several types of test suites:

- ["Run" and "Run and Branch" test suites](<02.08.04.32.01.02.01.01_Run__and__Run_and_Branch__test_suites.md>)

"Run" test suites offer only one path, while "Run and Branch" test suites offer branching depending on the test result.

- [Special test suites](<02.08.04.32.01.02.01.02_Special_test_suites.md>)

Special test suites are executed at a particular point in time, which can be either dependent or independent of the testflow.

- [Multibin SmartDisconnect test suite](<02.08.04.32.01.02.01.04_Multibin_SmartDisconnect_test_suite.md>)

The Multibin SmartDisconnect test suite is a combination of a multibin node and a user defined test suite.

- [Floating test suite](<02.08.04.32.01.02.01.03_Floating_test_suite.md>)

The floating test suite is not connected to the testflow sequence and can be used for debugging.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.6.1: Added Multibin SmartDisconnect test suite.
