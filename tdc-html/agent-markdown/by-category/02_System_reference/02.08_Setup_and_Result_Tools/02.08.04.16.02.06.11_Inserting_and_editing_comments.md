# Inserting and editing comments

The Pattern Editor provides two columns for comments: the header Comment column and the signal Comments column. Both can be visible or hidden. The cells of these two columns are linked. Any comments you add, appear in both columns.

## About this task

The comment columns allow you to enter comments corresponding to each vector. You may enter up to 250 characters.

- To display or hide the signal Comments column, you use the [Configure Layout](<02.08.04.16.02.06.02_Configuring_the_layout_of_the_editor.md>) dialog.
- To display or hide the header Comment column, you use the ![Hide all comments in current editor button](<../../../../raw/99936.png>) icon in the main toolbar.

Any entries appear identically in both comment columns. Choose the one that fits best for your task.

## Before you begin

Make sure the Pattern Editor is open with the pattern where you want to add or edit comments, see [Opening the Pattern Editor](<02.08.04.16.02.06.01_Opening_the_Pattern_Editor.md>).

## Procedure

-  In the Pattern Editor check, whether or not the comments columns are visible.
-  If the header Comment column is not visible, click the ![Hide all comments in current editor button](<../../../../raw/99936.png>) icon. It toggles the display of the header Comment column.
-  If the signal Comments column is not visible, right-click in the signal area, select Configure Layout, and [adjust the layout](<02.08.04.16.02.06.02_Configuring_the_layout_of_the_editor.md>).  ![Comment column](<../../../../raw/101291.png>)
-  To enter a comment, click the cell, type the comment, then press Enter.

Comments can contain any characters with ASCII codes from 32 to 126, that is, all printable ASCII characters.

-  To change a comment, double-click the comments field.
-  To copy and paste a complete comment, right-click the source and target cell.
-  To copy and paste a comment partially, double-click the source and target cell.
