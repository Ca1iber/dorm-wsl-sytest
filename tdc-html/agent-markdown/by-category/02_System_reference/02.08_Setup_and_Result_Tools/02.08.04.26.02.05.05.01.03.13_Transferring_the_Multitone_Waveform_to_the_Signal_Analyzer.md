# Transferring the Multitone Waveform to the Signal Analyzer

When you are satisfied with the multitone waveform as displayed in the Generated Waveform dialog window, click the Finish button at the bottom of the window to conclude the waveform generation. This transfers the waveform to the Generated Waveform display.
