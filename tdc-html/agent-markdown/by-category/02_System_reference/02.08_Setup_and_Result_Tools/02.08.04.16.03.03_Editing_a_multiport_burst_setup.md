# Editing a multiport burst setup

Editing a multiport burst setup means, for example, inserting CALL and NOP instructions or changing the sync group.

You can edit a multiport burst setup both in a multiport burst editor and in the Pattern Explorer. The editing options vary.

Most tasks like Open, Cut, Copy and Paste, Insert, Delete, Up and Down, etc. are identical to [Pattern Editor tasks](<02.08.04.16.02.06_Pattern_Editor_tasks.md>) and [Pattern Explorer](<02.08.04.16.01_Pattern_Explorer.md>) tasks. These are not described here. This topic covers only the multiport burst specific editing tasks.

To edit a multiport burst you must have created a multiport burst, see [Creating a multiport burst](<02.08.04.16.01.04_Creating_a_multiport_burst.md>). For adding port bursts see [Creating and assigning a port burst](<02.08.04.16.01.05_Creating_and_assigning_a_port_burst.md>).

Common edit

 |

You can commonly edit multiple cells in a row:

- Open the Overview page or a sync group page of a multiport burst editor.
- Select either multiple cells next to each other in a row, or a complete row.
- Right-click and select Insert Instruction.

The cells below the selection move down and new cells are inserted. The focus is on the leftmost of the new cells.

- Insert an instruction including

- <port><some other text>, or

- <some other text><port>.

All other open new cells automatically receive related CALL instructions.

The following rules apply:

- The edited cell must belong to port <port>.
- If the entered instruction does not include the <port> at the beginning or end, the other cells are filled with NOP (No Operation) instructions instead, and a warning is displayed.
- If the instruction uses a <port> which is not part of a target port burst, the instruction is replaced by a NOP instruction (No Operation) in the target cell.
 |

Editing in the Pattern Explorer
 |

Sync Group

 |

To change the Sync Group of a port burst, you edit the table cell in the Sync Group column of the Pattern Explorer. You may use Content Assist (Ctrl + spacebar) to list the valid options.

 |
 |

General tasks

You can use the Cut, Copy, Paste, Insert, Delete, Up and Down functions to edit calls in port bursts just like [editing normal bursts](<02.08.04.16.01.03_Viewing_and_editing_bursts_in_the_Pattern_Explorer.md>) in the Pattern Explorer.
