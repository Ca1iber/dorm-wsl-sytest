# Adding user defined testflows to the Run menu

You may add your own testflows (user defined) to the Run menu.

## Procedure

-  Open the Run testflow configuration window:

  -  On the menu choose Run > Open Run Dialog

-  For every user defined testflow you want to add to the menu:

  -  Select the testflow
  -  On the configuration pane select the Common tab
  -  On the Display in the favorite menu area select Run  ![Add user defined testflow to menu](<../../../../raw/120733.png>)
  -  Click Apply
  -  Close the Run window
