# Introduction of the Pin Configuration Tool

#### Subtopics

- [Pin](<02.08.04.18.01.01_Pin.md>)
- [Pin group](<02.08.04.18.01.02_Pin_group.md>)
- [Port](<02.08.04.18.01.03_Port.md>)
- [Alias set](<02.08.04.18.01.04_Alias_set.md>)
- [Utility purpose](<02.08.04.18.01.05_Utility_purpose.md>)

With the Pin Configuration tool you edit the pin configuration file.

The pin configuration file is the first setup file that must be completed before you can test a new device. If the pin configuration details have not been entered, the software will not let you enter details about the DUT in any other setup window.

[Use the Pin Configuration Tool](<02.08.04.18.02_Using_the_Pin_Configuration_Tool.md>) to define pins, pin groups, ports, and the utility purpose, see [Elements of the Pin Configuration Tool](<02.08.04.18.03_Elements_of_the_Pin_Configuration_Tool.md>)
