# Pin configuration master file

A pin configuration can be organized as one single file, or different parts of the pin configuration can be stored in separate files. In the latter case, the respective pin configuration files can be merged through a master file which contains references to the individual files. The [Setup Management Tool](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02.04_Setup_Management_Tool.md>) uses the master file to assemble the in configuration files.

One of the individual pin configuration files is the "package file", which contains the specification for the complete package. The other files are referred to as "alias files". The pin names in the alias files are taken as pin aliases in the assembled file.

Splitting the pin configuration into multiple individual files allows multiple users to work on the configuration in parallel.

The Setup Management Tool verifies that the following conditions are true for all files:

- The numbers of sites specified in different files are same.
- All the channels in the alias files occur in the package file.
- The contexts specified in different files are not same, except for the "DEFAULT" context.
- The channel must be defined as I/O in the package file to allow both I and O directions for the different alias pins. If the channel is defined to be either only I or only O, then all aliases must have the same specification. None of the aliases must have the opposite direction or I/O.

If any of the rules is violated, the assembly process is aborted and an error message is generated.

## Header rows

A pin configuration master file always begins with a header row that must have this content:

```
hp93000,config_master_file,0.1
```

The second line specifies the tester file which is to be divided. It has the format:

```
testerfile: <tester_file_name>
```

It specifies the tester setup file which is to be split.

The subsequent lines in the pin configuration master file associate each part of the pin configuration with a subfile.

The paths for the subfiles can be relative or absolute. The reference directory for relative paths is the directory of the master file.

You can insert comments anywhere in the file. They are identified by the hash (#) character at the start of a line.

## Format of entries

The entry format for the parts is as follows:

```
Package: <package_file_name.cfg>
alias_set_name_1: <alias_file_name_1.cfg>
...
alias_set_name_X: <alias_file_name_X.cfg>
```

The Package keyword refers to the package file. The pin names specified in this file are all used in the assembled file.

The subsequent lines in the master file specify that the alias set named with "alias_set_name_X" is generated with the information extracted from the file "alias_file_name_X.cfg".

## Examples

### package.cfg

The following example shows how the Setup Management Tool assembles three pin configuration files according to the master file.

The file `package.cfg` is the package file, and the other two files, `TRANSIO.cfg` and `USB.cfg,` are the alias files.

```
hp93000,config,0.1
DFPN 10201,"",(Data_in_2)
DFPN 10202,"",(Data_in_1)
DFPN 10212,"",(Data_in_5)
DFPN 10213,"",(Data_in_4)
DFPN 10214,"",(Data_in_3)
PSTE 1
CONF OFF,F160,(Data_in_2,Data_in_1,Data_in_5,Data_in_4,Data_in_3)
RDIV 0,(Data_in_2,Data_in_1,Data_in_5,Data_in_4,Data_in_3)
NOOP "6.5.2",,,
```

### transio_file.cfg

```
hp93000,config,0.1
DFPN 10202,"",(Data1)
DFPN 10201,"",(Data2)
PSTE 1
CONF IO,F160,(Data1,Data2)
RDIV 0,(Data1,Data2)
NOOP "6.5.2",,,
```

### usb_file.cfg

```
hp93000,config,0.1
DFPN 10214,"",(Data3)
DFPN 10213,"",(Data4)
DFPN 10212,"",(Data5)
PSTE 1
CONF IO,F160,(Data3,Data4,Data5)
RDIV 0,(Data3,Data4,Data5)
NOOP "6.5.2",,,
```

The pin configuration master file is the following:

```
hp93000,config_master_file,0.1
testerfile:demo.cfg

Package:package.cfg

TRANSIO:transio_file.cfg
USB:usb_file.cfg
```

The pin configuration file assembled from the above files looks like this:

```
hp93000,config,0.1
DFPN 10201,"",(Data_in_2)
DFPN 10202,"",(Data_in_1)
DFPN 10212,"",(Data_in_5)
DFPN 10213,"",(Data_in_4)
DFPN 10214,"",(Data_in_3)
DFPR "TRANSIO","Data2",(Data_in_2)
DFPR "TRANSIO","Data1",(Data_in_1)
DFPR "USB","Data5",(Data_in_5)
DFPR "USB","Data4",(Data_in_4)
DFPR "USB","Data3",(Data_in_3)
PSTE 1
CONF OFF,F160,(Data_in_2,Data_in_1,Data_in_5,Data_in_4,Data_in_3)
RDIV 0,(Data_in_2,Data_in_1,Data_in_5,Data_in_4,Data_in_3)
NOOP "6.5.2",,,
```
