# Synchronization between the Flow Data Editor and the Flow Sequence Editor

The [Flow Data Editor](<02.08.04.32.03.01_Flow_Data_Editor.md>) automatically keeps the test suite in focus synchronized with the [Flow Sequence Editor](<02.08.04.32.03.02_Flow_Sequence_Editor.md>), and vice versa. Also, the pages of the Flow Data Editor are automatically synchronized with each other.

 Note If the alignment does not take effect, please check if you have set the two editors automatically synchronized. See [Configuring the Testflow Tool](<02.08.04.32.02.07_Configuring_the_Testflow_Tool.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
