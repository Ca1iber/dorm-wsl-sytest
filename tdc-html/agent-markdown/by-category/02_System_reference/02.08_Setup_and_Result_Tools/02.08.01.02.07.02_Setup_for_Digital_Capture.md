# Setup for Digital Capture

You can set up the pin configuration, levels, timing, and vectors for a Digital Capture test with the standard setup tools of SmarTest. The setup for Digital Capture requires some additional settings like the definition of the pins you want the data to be captured from, and the setup of a vector variable which defines how to extract (filter) the data of interest from the captured data.

The normal sequence for the setup of Digital Capture is:

- Define the pins.
- Define the capture thresholds.
- Define the capture timing.
- Create a vector label for Digital Capture in the sequencer memory, and set up the vectors.
- Define one or more vector variables.
- Define in the capture settings for the pins on which the data is to be captured from.
