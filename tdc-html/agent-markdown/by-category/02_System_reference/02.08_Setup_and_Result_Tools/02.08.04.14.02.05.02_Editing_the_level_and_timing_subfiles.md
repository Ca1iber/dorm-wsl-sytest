# Editing the level and timing subfiles

Equation based level and timing setups are stored in the setup file as a string parameter of the [EQSP](<../02.06_Command_Reference/02.06.02.02.109_EQSP__EQSP__-__EQuation_SPecification_transfer.md>) firmware command, which serves to download the setup data to the tester. One parameter of this command is the number of bytes that are to be downloaded. If the actual size of the setup data does not match the specified number, [EQSP](<../02.06_Command_Reference/02.06.02.02.109_EQSP__EQSP__-__EQuation_SPecification_transfer.md>) issues an error. This makes it difficult to edit a normal setup file outside of SmarTest, because you will usually have to adjust the number of bytes when you change the data.

In contrast, the subfiles created by the Setup Management tool can be edited with an ASCII editor without any difficulty. The byte numbers can be left unchanged. When the subfiles are merged into a tester setup file, the Setup Management tool will calculate the correct number of bytes for the [EQSP](<../02.06_Command_Reference/02.06.02.02.109_EQSP__EQSP__-__EQuation_SPecification_transfer.md>) calls.

The tool also adapts the byte number when the tester setup file is split. Thus, you can load a single subfile. But if you change the data of a subfile with an ASCII editor and then want to load this single subfile, you must adjust the byte number manually.
