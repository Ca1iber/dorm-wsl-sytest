Step

 |

Your Task

 |

Software Tool

 |
 |

1.

 |

Plan your device tests and design the DUT board.

DSM does not depend on load board design. Sourcing can be done on any I or I/O pins.

 |

 |
 |

 |

a. Assess the DUT Resource Requirements:

Study the test device.

- What tests are needed?
- What parameters to measure?
- What test methodologies or test patterns to use?
- How many of digital and analog channels you will need.

b. Verify the available test system resources.

c. Design test circuits and a DUT board.

 |

 |
 |

2.

 |

Define the pins and port for sourcing.

See [Pins and port for Digital Source Memory](<02.08.01.03.03.02_Pins_and_port_for_Digital_Source_Memory.md>)

 |

Pin Configuration Tool

 |
 |

3.

 |

Set up levels for digital i/o pins and power supply voltages to DUT.

See [Timing and Levels](<02.08.01.03.03.03_Timing_and_Levels.md>)

 |

Level Setup Tool

 |
 |

4.

 |

Set up timing (waveform and edges) for digital i/o pins.

See [Timing and Levels](<02.08.01.03.03.03_Timing_and_Levels.md>)

 |

Timing Setup Tool

 |
 |

5.

 |

Create the MAIN label.

The MAIN label has to be the label the user wants to run, containing sections that will be dynamically modified by the DSM.

See [Defining the MAIN Label](<02.08.01.03.03.04_Defining_the_Main_pattern.md>)

 |

Pattern Tool

 |
 |

6.

 |

Create a DSRC label for Digital Source Memory in the sequencer or vector memory.

The DSRC label contain the dynamic vector data that will be called from the MAIN label.

See [Defining the Source Label](<02.08.01.03.03.05_Defining_the_DSRC_source_pattern.md>)

 |

 |
 |

7.

 |

Create a Digital Source setup including the vector variable configuration and the VVC usage.

See [Creating a Digital Source setup](<02.08.04.16.02.06.16_Creating_a_Digital_Source_setup.md>).

 |

 |
 |

8.

 |

Download the waveform data to the vector variables.

See [Downloading the waveform data to the vector variables](<02.08.01.03.03.06_Downloading_the_waveform_data_to_the_vector_variables.md>)

 |

Signal Analyzer Tool

Test Method Perspective

 |
 |

9.

 |

Enter the vectors and the proper sequencer instructions in the MAIN label.

 |

Pattern Tool

 |
 |

 |
