# Setting the acquisition mode

#### Subtopics

- [Follow Current Mode](<02.08.04.08.01.02.01_Follow_Current_Mode.md>)
- [Analyzing Data in Cycle Oriented or Failure Oriented Mode](<02.08.04.08.01.02.02_Analyzing_Data_in_Cycle_Oriented_or_Failure_Oriented_Mode.md>)

You can define how the test results are recorded in the Error Map. This definition can be done in the test suite or in the Error Map Tool.

This section describes the three options for controlling the acquisition of of test results with the Error Map Tool.
