# Cutting, copying and pasting nodes

## Before you begin

Make sure that the node you want to copy has been inserted into the testflow.

## Procedure

-  In the Flow Sequence Editor, select one or more nodes (press Ctrl and then click). The selected nodes are highlighted. Note Only nodes at the same level can be selected together.
-  Right-click the selected nodes and select Cut or Copy as needed.
-  Select an insertion point in your testflow. Right-click the chosen insertion point and select Paste.

## Results

The pasted node is inserted at the desired position.

If you copy the Run node and Run and Branch node, a numbered suffix is added to the pasted node's name. This allows you to distinguish the pasted node from its original.

When you paste a test suite, a numbered suffix is added to the test suite name. This means that pasted test suites refer to a copy of the original test suite. This is different from the cloned test suites, which refer to the same test suite as their originals.

When you copy a bin, the pasted bin has the same settings with the original bin.

## What to do next

Save the testflow.
