# Deleting a utility purpose

## Before you begin

You have defined at least one utility purpose.

## Procedure

-  To select the utility purpose you want to delete, in the Test Program Explorer view, click the utility purpose name to highlight it. To select multiple utility purposes, press Ctrl and click the names.
-  Right-click the selected utility purpose names and select Delete.
-  The Confirm Delete window is displayed. Click Yes.
-  Apply the data and save the pin configuration file.

## Results

The utility purposes have been deleted.
