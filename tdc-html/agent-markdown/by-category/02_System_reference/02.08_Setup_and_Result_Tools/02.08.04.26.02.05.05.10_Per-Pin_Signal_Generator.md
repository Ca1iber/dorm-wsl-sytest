# Per-Pin Signal Generator

#### Subtopics

- [PPSG operation](<02.08.04.26.02.05.05.10.01_PPSG_operation.md>)
- [Starting the Per-Pin Signal Generator](<02.08.04.26.02.05.05.10.02_Starting_the_Per-Pin_Signal_Generator.md>)
- [Generating a pattern with PPSG](<02.08.04.26.02.05.05.10.03_Generating_a_pattern_with_PPSG.md>)

The Per-Pin Signal Generator (PPSG) is a tool that generates test patterns for digital channels that source analog signals. It can generate patterns for sine, ramp, and triangle waveforms with user-definable characteristics.

The tool generates the patterns as STIL files that can be translated with [STIL Reader](<../02.11_Data_Conversion_and_Bridges/02.11.01_STIL_Reader.md>) into single-test-suite test programs for manual integration into test flows or that can be automatically integrated using [SmarTest Program Manager](<../02.09_Test_Program_Management/02.09.02_SmarTest_Program_Manager.md>) (STPM).

PPSG is integrated into the [Signal Analyzer](<02.08.04.26_Signal_Analyzer.md>).
