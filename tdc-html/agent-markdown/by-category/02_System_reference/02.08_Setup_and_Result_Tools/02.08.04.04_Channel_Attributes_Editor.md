This chapter describes the DeEmbedding page of the Channel Attributes editor.

Depending on your concern you can edit channel attributes using the following editors:

- [Fixture Delay Tool](<02.08.04.10_Fixture_Delay_Tool.md>)
- Channel Attributes Editor

To open the respective editor, on the [Test Program Explorer](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02_Test_Program_Explorer.md>), right-click channel attributes and choose the editor from the shortcut menu.
