This menu item accesses the Multitone Setup tool. You can use the Multitone Setup tool to easily generate multitone waveforms to be used for multitone testing.

- You can define a multitone waveform in the frequency domain by specifying the individual tone frequencies, amplitudes and phase offsets (optional). The calculated waveform can then be viewed in the time domain.
- Multitone waveform definitions can be saved and re-loaded for later usage or modifications.
- Three different algorithms can be used to calculate the phase distribution of the tones in the multitone waveform.

Creating a multitone waveform is done using three dialog windows which allow you to

- Specify the tones in the frequency domain.
- Run the calculation of the multitone waveform in the time domain, using a selected algorithm to determine the phase distribution.
- View the generated multitone waveform in the frequency and in the time domain.

You can switch back and forth between these dialog windows to make modifications of the waveform definition and see the calculated results until you finally transfer the multitone waveform to the Generated Waveform display of the Signal Analyzer.
