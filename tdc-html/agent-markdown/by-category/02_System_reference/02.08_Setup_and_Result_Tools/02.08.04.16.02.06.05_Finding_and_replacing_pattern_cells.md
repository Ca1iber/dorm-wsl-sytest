# Finding and replacing pattern cells

The Pattern Editor provides a find and replace function you can use to search for single vector cells and for series of vector cells. You can also search for comments.

## About this task

This task describes how to find and replace pattern cells in the Pattern Editor.

If you are searching for sequencer instructions, do not use the Find/Replace dialog described here. Click ![Hide all vectors in current editor button](<../../../../raw/99932.png>) (Hide all vectors in current editor) instead.

## Before you begin

Make sure the Pattern Editor is open with the pattern you want to change, see [Opening the Pattern Editor](<02.08.04.16.02.06.01_Opening_the_Pattern_Editor.md>).

## Procedure

-  In the Pattern Editor right-click and select Find/Replace... .The Find/Replace window appears.  ![Find and replace dialog box](<../../../../raw/101320.png>)
-  In the Find field type a search pattern.
-  If you want to replace the search pattern by another pattern, type the new pattern in the Replace With field. Otherwise leave it blank.
-  To start the search click Find.

To narrow the scope to one or more signals, highlight the signals you want to scan and click the Selection option.

In the Options panel you can select, how the search pattern is to be interpreted:

  - Space is Delimiter checked: Search for the pattern in one cell. Example: The string 111 is interpreted as one string.
  - Space is Delimiter not checked: Search for the pattern over multiple cells. Example: The string 111 is interpreted as a sequence of three consecutive strings 1.
  - Regular expressions: Check to search using [regular expressions](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.14.14_Pin_Browser_preference_page.md>).

To evaluate, how the search pattern will be interpreted, use the tooltip. The tooltip displays the search pattern in a simulated vector view. You get the tooltip by hovering the cursor over the Find field.

If you want to search for comments, type the comment in the Find field and check Space is Delimiter.
