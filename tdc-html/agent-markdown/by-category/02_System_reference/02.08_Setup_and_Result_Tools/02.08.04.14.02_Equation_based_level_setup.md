# Equation based level setup

The goal of a level setup is to assign values to the level resources like drive levels, compare levels, load currents, power supply voltage.

Equation based level setup allows you to define dependencies between different parameters in a general form and provides more flexibility. With this setup, the levels are determined by expressions that are built up from variables (and constants) by arithmetic and logical operators.

In equation based level setup, the setup elements are part of larger data blocks which are downloaded to the test system as a whole.
