# Drive actions

Every (unabbreviated) specification of a drive action (except a single N) consists of three characters. The first character is F, for historical reasons. The second character specifies the logical drive value, and the third controls the tri-state.

The syntax for specifying drive actions is as follows:

  ![Syntax diagram for specifying a drive action](<../../../../raw/10602.png>)

The character codes have the following meaning:

 |

Code

 |

Explanation

 |
 |

F

 |

For 'Fixed action'.

 |
 |

N

 |

For 'No action', the current settings are not changed.

 |
 |

Z

 |

Switch tri-state on.

 |
 |

0

 |

Drive to 0 (in second position), or switch tri-state off (in third position).

 |
 |

1

 |

Drive to 1.

 |

Some fixed specifications can be abbreviated as specified in the following table:

 |

Action

 |

Abbreviation

 |
 |

F00

 |

0

 |
 |

F10

 |

1

 |
 |

FN0

 |

!Z

 |
 |

FNZ

 |

Z

 |
 |

N

 |

. (period)

 |
