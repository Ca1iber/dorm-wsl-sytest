# Routing Tools (SmartRDI)

The Routing Tools feature native multisite handling, user friendly table based configuration editors and a unified programming interface for controlling utility lines and MUX card switches. The Routing Tools are a part of the SmartRDI (Rapid Development Interface).

The Routing Tools are a combination of the [Routing Tools editors](<../02.07_Test_Method_Reference/02.07.13.15.01_Routing_Tools_editors.md>) and the [rdi.route()](<../02.07_Test_Method_Reference/02.07.13.15_SmartRDI__DUT_board_connections_control_by_Routing_Tools.md>) class of [SmartRDI](<../02.07_Test_Method_Reference/02.07.13_SmartRDI.md>). The Routing Tools editors, are the central place for configuring the handling of utility lines and MUX card switches and for defining complete states that are applied by SmartRDI class rdi.route().
