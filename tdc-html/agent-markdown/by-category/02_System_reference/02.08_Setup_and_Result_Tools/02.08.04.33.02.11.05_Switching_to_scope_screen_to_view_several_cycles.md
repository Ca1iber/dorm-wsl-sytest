# Switching to scope screen to view several cycles

If you want to view several cycles in detail, but they do not all fit into the display at the same time, you can switch the mode of the entire Timing Diagram to [Softscope](<02.08.04.33.02.12_Softscope_function_of_the_Timing_Diagram.md>).

## Procedure

-  Scroll to the beginning of the area you want to examine.
-  On the menu click Select > scope.

Again, the softscope function builds up all output waveforms in the display.
