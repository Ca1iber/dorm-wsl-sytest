# The Control File

#### Subtopics

- [Control File Syntax](<02.08.04.19.03.01_Control_File_Syntax.md>)
- [Control File Examples](<02.08.04.19.03.02_Control_File_Examples.md>)

As mentioned earlier, you can also specify all your pin margin settings, and run the test itself with a control file. This control file manages the measurements and outputs results to either stdout or a specified report file.

The main advantages of a control file are:

- it contains all pin margin settings and commands to load the appropriate data sets - for details of the syntax see [Control File Syntax](<02.08.04.19.03.01_Control_File_Syntax.md>)
- it can easily be created by using the control log feature of the user interface - see [Creating a Control File](<02.08.04.19.02.03.06_Creating_a_Control_File.md>)
- It is repeatable and it can be transported easily to another machine.

The Pin Margin measurement can be called using the following syntax:

```
<HP93000_BASE_DIR>/pws/bin/pm -c <control file> -o <report file>
```
