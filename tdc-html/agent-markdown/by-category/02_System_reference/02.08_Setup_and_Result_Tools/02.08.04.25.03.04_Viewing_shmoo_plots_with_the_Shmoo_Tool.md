After you [execute a shmoo test with the Shmoo Tool](<02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>), a shmoo plot with its title, the related test mode, result pins and site information is displayed on a shmoo page in the shmoo editor.

If you change the test modes, result pins, and sites on the shmoo plot, the corresponding information displayed on the shmoo page also changes. See:
