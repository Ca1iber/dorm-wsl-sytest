# Creating a Control File

The pin margin tool logs all operations of the user during the interactive use. This log file can be saved as a control file to repeat exactly these steps when you run the pin margin tool with the control file.

To create a control file proceed as follows:

- Open the Pin Margin tool and the Testflow Editor.
- In the Pin Margin Tool, select Clear Control Log from the Options menu.
- Execute the testsuite with the setups you want to use in your pin margin test.
- Setup and run the margin test.
- Repeat steps 3 and 4 for other testsuites as required.
- In the Pin Margin tool, select Save Control Log from the File menu.

All steps are stored in the control log file and can be repeated by executing this file. You can also edit the control file and adapt it to your needs.

The default directory to store this file is: device_directory/setup/pm

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.3: The device_directory/setup/pm directory instead of the user home directory is used as the default directory to store the control log file.
