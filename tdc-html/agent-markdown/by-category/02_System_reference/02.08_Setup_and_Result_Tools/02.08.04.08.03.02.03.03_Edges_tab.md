# Edges tab

The Edges tab gives you a pass/fail result for each of the 8 available edges. Edges that are not used in the waveform count as passed. These results are recorded in the detailed error map.

One cycle per row and each column is displayed.

 ![The Edges Folder](<../../../../raw/24125.png>) Note To show the edge results in this view, you need to choose the P/F(1 bit) and the Edge Mode in the [Result Mode](<02.08.04.08.04.01_Result_Mode.md>) tab and choose EDGE Granularity Required in the [Execution Mode](<02.08.04.08.04.02_Execution_Mode.md>) tab of [Result Configuration](<02.08.04.08.04_Result_Configuration.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
