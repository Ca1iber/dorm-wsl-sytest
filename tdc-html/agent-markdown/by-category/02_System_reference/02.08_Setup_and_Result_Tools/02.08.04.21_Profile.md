# Profile

A data logging profile is a logical container for specific data logging rules that determine which data is logged within the test system and how.

Data logging profiles provide a very easy and powerful way to control data logging.

With data logging profiles you can change the flag settings for optimized test flows in production without deleting the optimization.

With the Profile Editor you can create your own custom data logging profiles and/or modify existing ones.
