# Creating/Saving a Test Program

To create or save a test program:

- In the Test Program Explorer view highlight the item Test Program.
- Right-click and select New or Save / Save as....

A test program does not need all the individual components, but must have at least a testflow and an application file.

Note that you can use absolute paths for the test program and the various components in it.
