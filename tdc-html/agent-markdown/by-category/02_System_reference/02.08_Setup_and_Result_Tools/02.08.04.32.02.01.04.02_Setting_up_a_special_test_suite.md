# Setting up a special test suite

## Before you begin

Make sure that the primary setup files have been loaded and the required test method has been built.

## Procedure

-  On the Test Suites page of the Flow Data Editor, right-click and select Add Special Test Suite > Download (assume that you want to set up a download special test suite).

The New Test Suite Wizard window opens.

-  Enter the information for the special test suites in the same way as described in [Inserting a test suite into the testflow](<02.08.04.32.02.01.04_Inserting_a_test_suite_into_the_testflow.md>).
-  Click Finish.

## Results

The special test suite has been inserted into the testflow. It only appears on the Test suites page of the Flow Data Editor, displayed with a cyan background.

To delete the special test suite, on the Test suites page, select the line of the special test suite, and then press delete.

- Introduced before SmarTest 6.3.2
- SmarTest 6.3.2: Special test suites are now displayed in the Tabular Testflow Editor.

- SmarTest 6.5.3: The procedure of setting up a special test suite is changed.
