# Defining variables

You must create a variable on the Variables page before using it in the testflow.

## Before you begin

Make sure that the Flow Data Editor is open.

## Procedure

-  On the [Variables page](<02.08.04.32.03.01.05_Variables_page.md>) of the Flow Data Editor, right-click anywhere on the page and select Add Variable. The Add Variable window appears.    ![Add Variable window](<../../../../raw/110968.png>)
-  Choose the variable type and enter the name for the new variable and its desired value. (String values have to be entered in quotes, like "String".)

Userflag

An integer value (0 or 1). Can be viewed and edited during [Test Program](<02.08.04.31_Test_Program.md>) execution from within the [User Flags](<../02.09_Test_Program_Management/02.09.01.06.02.01_Setting_User_Flags.md>) window.

String

Text (for the maximum string number see [SmarTest character and number limits](<../../01_Getting_started/01.05_SmarTest_character_and_number_limits/01.05_SmarTest_character_and_number_limits.md>)). String values must be enclosed in double quotes, for example, "abc".

Double

A double number or an expression that represents a double value (available range [-123.456 .. 789.654]).

Typically, such variables take result values of [Test suites](<02.08.04.32.01.02.01_Test_suites.md>).

-  Click OK.

## Results

The new variable appears on the Variables page. You can modify its value on this page.

## What to do next

Use the variable in the testflow.

You can retrieve the value of the defined variable by following [Obtaining Values of Testflow Variables](<../02.07_Test_Method_Reference/02.07.03.08.06_Obtaining_Values_of_Testflow_Variables.md>).

 To, for example, get the current value of the double type variable set above, use [GET_USER_DOUBLE](<../02.07_Test_Method_Reference/02.07.04.01.102_GET_USER_DOUBLE.md>):

```
    ...
    DOUBLE print_example ;
    GET_USER_DOUBLE("X", &print_example);
    report_stream << "User-defined variable: " << print_example << endl;
    ...
```
