# Creating a Digital Source Setup for DSM FLAT setup

Creating a Digital Source setup for DSM FLAT setup is same as the DSM normal setup, except for the following points:

- Before you create the Digital Source setup, make sure that the number of vectors in the MAIN label is at least:

```
offset + frame_size * number_of_frames
```

- Select Main`[main_label_name]` button on the Data Pattern panel as the sourced data is in the MAIN label.
- Set all the defined pins as source pins.
- The Offset means where the source data starts in the MAIN label.

The settings for the other parameters are same to the normal test.

After you created the Digital Source setup, you can see it in the Outline view if you enable the editor of the MAIN label where you start the Setup Wizard.

After you finish, the Digital Source setup `audio_flat_vcc` appears in the Outline view. Open it, the VVC `audio_flat_vvc` is shown as the following:

```
ATTR DIGDATA FLAT   #Source type is for FLAT setup

#Declaration of variables
VARIABLES CLK, CTRL, DATAIN, DATAOUT

PINS clk
    SOURCE_DATA_TEMPLATE CLK[25-0]
    MAPPING
    0  %0
    1  %1

PINS ctrl
    SOURCE_DATA_TEMPLATE CTRL[25-0]
    MAPPING
    0  %0
    1  %1

PINS datain
    SOURCE_DATA_TEMPLATE DATAIN[25-0]
    MAPPING
    0  %0
    1  %1

PINS dataout
    SOURCE_DATA_TEMPLATE DATAOUT[25-0]
    MAPPING
    0  %0
    1  %1
```
