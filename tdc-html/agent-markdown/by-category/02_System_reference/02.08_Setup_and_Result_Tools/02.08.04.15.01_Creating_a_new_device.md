# Creating a new device

With this task you create a new device directory and a link to your workspace. If you want to import an existing device to your workspace, follow the instructions given in [Importing a device into your workspace](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.08.02.01.01_Importing_a_device_into_your_workspace.md>).

## Before you begin

If you have worked on another device before, perform the following actions before creating a new device:

- Save the setup data.
- Stop or finish any active test.

## Procedure

-  On the menu, click 93000 > Device > New Device

The [New Device wizard](<02.08.04.15_New_Device_wizard.md>) opens.

Error guidance is provided in the top pane of the New Device window. For example:

   ![New Device wizard](<../../../../raw/353373.png>)    ![New Device wizard](<../../../../raw/353431.png>)

An alternative way to open the [New Device wizard](<02.08.04.15_New_Device_wizard.md>): Click File > New > Project > 93000 > New Device

  Note If you are starting SmarTest for the first time on the current system controller, the Select device dialog box is displayed.

However, even if there are valid SmarTest devices located in the selected directory, the Create Device button only becomes active after a new or empty directory is specified.

![Select device dialog box](<../../../../raw/350664.png>)

-  In this wizard:

  -  Select Change to new device after creation if you want this new device to be activated after creation.
  -  In the Device Path text box, specify the path and the name of the new device.
  -  In the Device technology list, choose the semiconductor process of your device. Normally cmos is entered here.
  -  Select Preinitialize vector memory to value and enter an initialization value field to reinitialize the vector memory to the specified value (supported range: 0 to 255). For more information, see [row_init_vectors_with_value](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.01.02_Technology_file_for_a_device.md#_49363__row_init_vectors_with_value>).

-  Expand the extra options and edit the device settings.    ![New Device wizard](<../../../../raw/353431.png>)

  -  Enter the maximum values for certain system parameters. These values determine the amount of memory reserved for the respective data structures.

If a parameter value is specified that is not suitable, the associated value field is highlighted and an error message is displayed in the top pane. For example, if an invalid Fast Transfer Buffer Size is entered:

   ![New Device wizard](<../../../../raw/353374.png>)

A corresponding message with valid values is displayed in the top pane.

   ![New Device wizard](<../../../../raw/353375.png>)
  -  Choose the appropriate Utility block size (16 or 32 utility lines per pogo block) for your test system setup. For further details on this parameter see [Technology file for a device](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.01.02_Technology_file_for_a_device.md>).
  -  Set the Fast Transfer Buffer Size to a minimum of 131072.

-  Click Finish.

## Results

SmarTest creates a set of data for your new device and activates the device.

The values you entered during this task are written to the [Technology file for a device](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.01.02_Technology_file_for_a_device.md>).

- SmarTest 7.2.2: New parameter: Result Area Size
