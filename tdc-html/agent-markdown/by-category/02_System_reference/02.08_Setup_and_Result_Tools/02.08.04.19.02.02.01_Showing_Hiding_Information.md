# Showing/Hiding Information

Using the two right-most [Buttons](<02.08.04.19.02.02.02_Buttons.md>) you can display or hide the following two sections of the Pin Margin window to view the result data in the Results section:

- the Primary Sets section and
- the Selections section.

Alternatively, you can use the Display pulldown menu, to display or hide the two sections.

## Functional changes

- Introduced before SmarTest 6.3.2
