# Setting the edge delays

#### Subtopics

- [Defining the edge delays for Pin Scale standard pins](<02.08.04.34.02.01.04.02.01_Defining_the_edge_delays_for_Pin_Scale_standard_pins.md>)
- [Defining the edge delays for Pin Scale 3600 fast pins](<02.08.04.34.02.01.04.02.02_Defining_the_edge_delays_for_Pin_Scale_3600_fast_pins.md>)
- [Defining edge delays for Smart Scale pins](<02.08.04.34.02.01.04.02.03_Defining_edge_delays_for_Smart_Scale_pins.md>)

Edge delays are defined for pins, not for individual waveforms. This implies that for a given pin, the position of an edge is the same in every waveform definition where the edge is used. This holds for both standard and fast pins.

## Functional changes

- Introduced before SmarTest 6.3.2
