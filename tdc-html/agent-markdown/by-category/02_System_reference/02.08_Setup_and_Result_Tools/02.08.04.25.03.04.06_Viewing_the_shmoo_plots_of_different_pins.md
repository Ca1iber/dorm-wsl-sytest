# Viewing the shmoo plots of different pins

You can view the shmoo plots of different result pins or pin groups by right-clicking the shmoo plot and selecting the desired pin or pin group.

## About this task

- When [you set up a shmoo over a functional test](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>), if you have selected multiple result pins in the resultPins field and enabled the perPinResult parameter, after execution, you can view the shmoo plot of each result pin.
- When you [set up a shmoo over test suite test](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>), if you have defined results with the [judgeAndLog](<../02.07_Test_Method_Reference/02.07.04.01.244_TESTSET.md>) API or the [SHMOO_RESULT](<../02.07_Test_Method_Reference/02.07.04.01.227_SHMOO_RESULT.md>) API in the test method code of the to be shmooed test suite, after execution, you can view the shmoo plots of the defined result pins or pin groups.

## Procedures

### For shmoo over functional tests

- When [setting up shmoo tests](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>), in the resultPins field, select pins or pin groups.

Do not select @ (all pins). Otherwise, you cannot view the shmoo plot of different pins.

- In the perPinResult field, select ON.
- Finish the other setups for shmoo over functional tests as described in [Setting up shmoo tests in the Shmoo Tool](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>).
- [Execute the shmoo test](<02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>).

A shmoo plot of one result pin is displayed in the Shmoo Tool. The name of this result pin is displayed in the plot title.

- To view the shmoo plot of another pin, right-click the shmoo plot, select Result Pin, and select the desired pin.

### For shmoo over an existing test suite

Refer to [Viewing the test results of a test suite on a shmoo plot](<02.08.04.25.03.04.05_Viewing_the_test_results_of_a_test_suite_on_the_shmoo_plot.md>) for the detailed procedure.
