# Build feature of the protocol editor and test program explorer

Once a protocol has been defined from scratch or an existing one has been modified its definition should be checked for formal errors.

This build feature takes the constants, variables, pin roles and pin role groups and applies them to the transaction specifications of the corresponding protocol definition.

This way SmarTest checks the consistency and validity of pin resources and protocols by performing a pre-execution build of the selected protocol.

The same checks will be carried out any time the testflow is executed.

 Note This build feature for protocols is different to the build actions of the Project's menu! It cannot be controlled by the Build Automatically option of the Project's menu!

Errors are reported in the [Problems View](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.08.09_Problems_View.md>).
