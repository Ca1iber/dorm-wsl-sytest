# Timing and Levels

There are no specific requirements for timing and level setup when using DSM. Timing and level setup are performed in the normal manner. The following is the timing setup for the audio demo device.

Wavetable

```
WAVETBL "dsm wavetable"
DISPLAY multi

PINS clk
0    "d1:1    d2:0"    clk
brk    ""

PINS ctrl
0    "d1:0"        0
1    "d1:1"        1
brk    ""

PINS datain
0    "d1:0"        d0
1    "d1:1    d3:0"    d1
brk    ""

PINS dataout
0    "r1:C"        cap
1    "r1:D"        nocap
```

Timing Equation set

```
EQNSET 1 "timing equation set 1"

SPECS
T [ns]

TIMINGSET 1 "timing set 1"
period = T

PINS clk ctrl datain
d1 = 0
d2 = 0.5 * T
d3 = 0.8 * T

PINS dataout
r1 = 0.5 * T
```
