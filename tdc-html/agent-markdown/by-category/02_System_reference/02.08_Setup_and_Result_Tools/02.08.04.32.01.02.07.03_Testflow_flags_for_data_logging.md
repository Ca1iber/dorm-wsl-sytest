# Testflow flags for data logging

The data logging flags (sometimes referred to as system flags) constitute an additional set of tools that allow you to control the test program. They define global information, relevant to the whole test. The flags are available per testflow.

These flags are most relevant to data logging:

- [calib_age_monitor](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_calib_age_monitor>)
- [current_monitor](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_current_monitor>)
- [datalog_formatter](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_datalog_formatter>)
- [datalog_sample_size](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_datalog_sample_size>)
- [diag_monitor](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_diag_monitor>)
- [graphic_result_display](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_graphic_result_displa>)
- [hidden_datalog_mode](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_hidden_datalog_mode>)
- [ink_wafer](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_ink_wafer>)
- [log_events_enable](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_log_events_enable>)
- [max_reprobes](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_max_reprobes>)
- [print_wafermap](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_print_wafermap>)
- [state_display](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_state_display>)
- [temp_monitor](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_temp_monitor>)
- [tm_crash_as_fatal](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_tm_crash_as_fatal>)

For a detailed list of the flags for data logging, refer to [Alphabetical list of flags](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md>). Select Data logging in the filter settings of column Area to show only the flags for data logging.

The data logging flags are stored in the `flags` section of the [Testflow file](<02.08.04.32.03.05_Testflow_file.md>).

The flag names denoted above represent the string to be used in test methods.
