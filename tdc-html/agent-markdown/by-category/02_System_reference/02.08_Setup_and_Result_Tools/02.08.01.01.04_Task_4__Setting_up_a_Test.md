# Task 4: Setting up a Test

Develop the test program using the [Testflow Tool](<02.08.04.32_Testflow_Tool.md>):

- Specify all setup data files used in the whole device tests.
- Insert a test suite.
- Specify the primary sets and vector label to be used.
- Select one of your test method programs (see [Test Method Programming Essentials](<../02.07_Test_Method_Reference/02.07.03_Test_Method_Programming_Essentials.md>)).
