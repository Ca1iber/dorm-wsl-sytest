# Creating Waveform and Timing Sets

To create a new waveform set:

- enter its number into the WFset # entry field.

The Tset # entry field displays a 1, to tell you, that you are using the default Timing Set 1. The system clears the Device Cycle Edit Area.

- Set up the timing for the new waveform set and Timing Set 1.

The new timing remains valid for Timing Set 1 in the waveform set you've just created until you modify or delete it.

To create a new timing set, enter its number into the Tset # entry field.

The system copies the timing to the new timing set.

The timing remains valid for the new timing set until you modify or delete it.

 Note Remember, you can change the period and edge delays from one timing set to another, not the waveforms or the edge order. If you change a waveform in one timing set (assign a different shape), or swap a pair of edges round, the change affects all the other timing sets within their waveform set.
