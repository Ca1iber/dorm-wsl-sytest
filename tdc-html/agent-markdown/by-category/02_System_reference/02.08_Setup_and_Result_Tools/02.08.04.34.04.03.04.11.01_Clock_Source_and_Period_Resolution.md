# Clock Source and Period Resolution

You can specify the clock source (internal or external clock) and the period resolution (period_res) in the equation sets. The syntax is the following:

```
EQNSET <eqn_set_number> "<eqn_set_name>"
    SPECS
        <SpecName1>
        <SpecName2>
        <SpecName3>
        . . .
        <SpecNameN>

    EQUATIONS
        <EquationVariable1> = <Expression1>
        <EquationVariable2> = <Expression2>
        <EquationVariable3> = <Expression3>
        . . .
        <EquationVariableM> = <ExpressionM>
        period_res = <ExpressionM>
        clockSrc   = INT | AMC

    TIMINGSET 1 "<TimingSet1Description>"
        period = <PeriodExpression>
        PINS  <Pin1_Name>|<PinGroup1_Name> ... <PinN_Name>|<PinGroupN_Name>
                      . . .
```

The period resolution and the clock source are specified in the EQUATIONS block of the equation set.

Period Resolution
 |

Keyword

 |

period_res

 |
 |

Value

 |

Expression specifying a value in ns. The range of valid entries depends on the test system model. It is specified in the corresponding test system spec sheet.

 |
 |

Position

 |

The keyword "period_res" has to follow the last equation with an equation variable on the left-hand side (see syntax description above).

 |

Clock Source
 |

Keyword

 |

clockSrc

 |
 |

Value

 |

INT: internal clock

AMC: alternate master clock

 |
 |

Position

 |

The keyword "clockSrc" has to follow the keyword "period_res" (see syntax description above).

   |  Note The position of the keywords "period_res", "clockSrc", "clock_fraction" and "sync_label" in the EQUATION block is important. You have to put them at the positions specified above.
