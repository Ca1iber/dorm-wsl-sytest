# Discarding the changes in the pin configuration tool

The Revert functionality is provided to discard the change made in the pin configuration tool before applying it.

The pin configuration file is loaded and changed but not applied.

 Note If the applying changes failed, the Revert action will be disabled and the changes cannot be discarded.

- In the SmarTest Work Center, click File > Revert.

or

- Right-click the modified setting groups (like Pin Settings, Groups and etc.) and select Revert from the shortcut menu.

The changes made but not applied in the pin configuration will be discarded.

## Functional changes

- Introduced in SmarTest 7.1.3
