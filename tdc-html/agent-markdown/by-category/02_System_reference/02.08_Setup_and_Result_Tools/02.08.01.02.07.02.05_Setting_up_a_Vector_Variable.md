# Setting up a Vector Variable

#### Subtopics

- [Creating a Digital Capture setup](<02.08.01.02.07.02.05.01_Creating_a_Digital_Capture_setup.md>)
- [Deleting a vector variable](<02.08.01.02.07.02.05.02_Deleting_a_vector_variable.md>)
- [Vector variable examples](<02.08.01.02.07.02.05.03_Vector_variable_examples.md>)

After the capturing of data is complete, the captured data (samples) needs to be read from the memory (uploaded to the system controller) and be analyzed as required. For example, if the samples are the output codes of an ADC, they can be analyzed for ADC linearity, ADC distortion or missing codes. If the captured data is the failure data generated by a Built-in-Self-Test (BIST), the data must be analyzed to deduce the information about the exact device failure that occurred.

A vector variable allows you to define an arbitrary sub-set of the captured and downloaded data (a special sub-set could also be the complete data).

In order to retrieve captured data for further processing (see [Running Digital Capture and Retrieving Capture Results](<02.08.01.02.07.03_Running_Digital_Capture_and_Retrieving_Capture_Results.md>) for details) you must always refer to a vector variable. Only the sub-set of captured data defined by that vector variable will then be read, and, for example, be processed by a test method.

By defining several vector variables, it is also possible to retrieve different views of the same captured data, as the captured data itself remains unchanged until the next capturing is performed.

The pattern editor provides a wizard to set up vector variables and to specify digital capture parameters. For a description of the setup wizard and the parameters see [Creating a Digital Capture setup](<02.08.01.02.07.02.05.01_Creating_a_Digital_Capture_setup.md>).
