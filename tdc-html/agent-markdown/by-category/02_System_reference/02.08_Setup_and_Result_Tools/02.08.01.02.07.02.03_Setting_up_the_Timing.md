# Setting up the Timing

#### Subtopics

- [Setting up the Timing for Sequential Capturing](<02.08.01.02.07.02.03.01_Setting_up_the_Timing_for_Sequential_Capturing.md>)
- [Setting up the timing for selective capturing](<02.08.01.02.07.02.03.02_Setting_up_the_timing_for_selective_capturing.md>)

As the test system uses normal digital pins for data capturing, the timing for a capture pin can be defined in the same way and with the same tools as for any other digital pin.

Setting up the timing for Digital Capture is different for the two Capture Modes Sequential and Selective.

This is because in Sequential Mode capturing will be performed on edges with normal compare actions, while in Selective Mode the capturing will be performed on edges with a designated 鈥榗apture' action (C for capture and D for do not capture).

 Note In both modes, capturing can only be performed on single edge actions, that is, capturing using window compare is not possible.
