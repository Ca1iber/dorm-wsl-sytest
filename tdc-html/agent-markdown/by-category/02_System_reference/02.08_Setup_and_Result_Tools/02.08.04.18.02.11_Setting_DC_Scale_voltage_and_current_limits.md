# Setting DC Scale voltage and current limits

DC Scale Limits is a safety feature for the DC Scale power supply cards. The limits cannot be exceeded. If the voltage or current is programmed too high or too low, an error message is triggered.

## About this task

Setting the limits appropriately, protects the device against too high or low voltage or current levels.

## Before you begin

Make sure you have defined all required pins and all DC Scale cards used.

For appropriate voltage and current limits check the specifications for [DC Scale Device Power Supplies](<../02.02_Specifications/02.02.05_DC_Scale_Device_Power_Supplies_and_VI_Cards.md>).

## Procedure

-  Open the [DC Scale Limits editor](<02.08.04.18.03.06_DC_Scale_Limits_editor.md>).
-  In the Max Volt[V] and Min Volt[V] fields, type the maximum and minimum voltage levels.
-  In the Max Source[A] and Max Sink[A] fields, type the maximum source and sink current values.  ![dc-scale_limits](<../../../../raw/142045.png>)
-  Apply the data and save the pin configuration file.
