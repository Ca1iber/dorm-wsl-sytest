# Protocol details

The protocol details are shown if you select the protocol in the protocol editor's overview area.

  ![ProtocolEditor_ProtocolDefinitionTab_ProtocoDetails](<../../../../raw/126138.png>)

The protocol details are divided into different sections like pin roles, pin role groups and global constants.

## Pin Roles

A pin role is the protocol specific name of a (hardware) pin which is used in transactions. Pin roles have to be defined here first, before they can be assigned to physical pins in the protocol assignments editor. Each pin role has specific properties, which will be set to default upon definition.

Properties
 |

Property

 |

Description

 |
 |

differential

 |

Defines the pin role as differential pin pair or a single ended pin.

Possible values are

false: pin role is a single ended (default)

true: pin role is differential

 |
 |

idleSequence

 |

Defines the state of the pin role if the interface is idle. In can be set to any state character.

The default is 'X'.

 |

## Pin Role Groups

Pin role groups are used with parallel protocols only. The properties editor allows to edit the group members and to specify which of the pin roles is used as LSB or MSB respectively.

## Constants

Here you can define protocol constants. Global constants will be used throughout the protocol during encoding and decoding. A constant can be either a state character sequence (SCS) or a constant numerical (integer) definition.
