# Pin Margin Test Report - Titles

Titles provide global information, and are automatically inserted by the pin margin tool as and when needed.

```
<title> = "#" <sep> <timingset>| <levelset> | <dpsset> | <site> | <date>
    | <version> | <dps> | <range> | <summary> | <seqlabel>
    | <testfunc> | <dataset>
<range> = (PERIOD | EDGE | LOAD | LEVEL | TERM | HIGH | LOW)
    "RANGE"  <sep> "ABSOLUTE"|"RELATIVE" <sep>
    <from value> <sep> <to value>
```

RANGE  is specified either as absolute or relative to the current test system settings.

```
<site> = "SITE" <sep> <site no>
```

SITE specifies the current site, that has setup and result focus.

```
<seqlabel> = "LABEL" <sep> <label name (max. 40 characters)>
```

LABEL  specifies the current sequencer start label.

```
<testfunc> = "TESTFUNC"  <sep> <testfunction type>
<testfunction type> = "FUNCTIONAL" [ <sep> """ <parameter string> """]
```

TESTFUNC specifies the current testmethod with its parameter.

```
<timingset> = [ "PRIMARY" <sep> ] "TIMING" <sep>  <waveform set>
    | <specset> "SET"  <sep> <set no> [ <sep> """ <description>  """" ]
<specset> = """ <eqnset no> <sep> <specset no> [ <sep> <description> ] """
<levelset> = [ "PRIMARY" <sep> ] <levelsetF> | <levelsetE>
<levelsetF> = "LEVELSET"  <sep> <set no>
<levelsetE> = "LEVEL" <sep> <specset> <sep> "SET"
    <sep> <set no> [ <sep> """ <description> """ ]
<dpsset> = "PRIMARY"  <sep> "DPSSET" <sep> <set no>
```

levelset, timingset and dpsset specify the measured set or the current primary set.

dpsset always specifies the primary set.

```
<dps> = "DPS" <sep> <dpsrange> <sep> <dpssteps> <sep> <dpspin>
    | "@" { <sep> <dpspin> }
<dpsrange> = "2.5%" |  "5%" | "10%" | "20%"
<dpssteps> = "2"  |  "4" | "10"
<dpspin> = <max. 16 characters except @ # " , tab space newline>
```

If With DPS is specified, the actual number of measurements will be one more than the dpsstep, and the value of the DPS voltage shown on the report will be the absolute value.

```
<dataset> = "DATASET" <sep> <dataset filename>
```

DATASET specifies the current data set with its filename.

```
<date> = "DATE" <sep> <DD> <sep> <MM> <sep> <DD> <sep> <HH:MM:SS> <sep> <YYYY>
```

DATE specifies the current local date and time.

```
<version> = "VERSION" <sep> """" <version id> """"
```

TEST SUMMARY precedes a list of the most marginal measurements. The criteria for the list is the delta percentage - see the first figure in [Summary](<02.08.04.19.02.01.04.10_Summary.md>).

```
<summary> = "TEST SUMMARY" <sep> <number of top elements>
        <sep> <delta percentage> "%"
<number of top elements> = <integer 1..10>
<delta percentage> = <float value>
```
