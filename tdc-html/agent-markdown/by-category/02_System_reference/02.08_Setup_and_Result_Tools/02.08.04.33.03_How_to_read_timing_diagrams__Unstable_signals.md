# How to read timing diagrams: Unstable signals

This topic explains how to understand the diagram an unstable clock signal in the [different resolution modes](<02.08.04.33.02.13_Comparing_resolution_modes_of_the_Timing_Diagram.md>).

Sometimes, the timing diagram shows results that are hard to understand at a glance. For example, see the following high resolution and scope diagrams.

  ![Timing Diagrams Tool_HiRes and Scope unstable signal example](<../../../../raw/141909.png>)

These diagrams are based on the an unstable clock signal as visualized in the following scope figure.

  ![Timing Diagrams Tool_unstable signal](<../../../../raw/141901.png>)

## Displaying with Standard Size

Because in the standard size SmarTest draws the standard diagram from a single execution only. The results, retrieved from functional test execution, can shift from run to run.

 ![Timing Diagrams Tool_Stand unstable signal](<../../../../raw/141902.png>)

## Displaying with Double Size

In this example, SmarTest draws the [high resolution](<02.08.04.33.02.11_High_resolution_mode_of_the_Timing_Diagram.md>) diagram from multiple executions (800 points across 10 cycles).

Because of the unstable signal, the diagram shows multiple transitions.

 ![Timing Diagrams Tool_HiRes unstable signal](<../../../../raw/141903.png>)

## Displaying with Scope Size

In this example, SmarTest draws the [scope function](<02.08.04.33.02.12_Softscope_function_of_the_Timing_Diagram.md>) diagram from 35 VOL levels, with 800 pts across 10 cycles each.

Because of the multiple different transition levels, the diagram gets blurred.

 ![Timing Diagrams Tool_Scope unstable signal](<../../../../raw/141908.png>)
