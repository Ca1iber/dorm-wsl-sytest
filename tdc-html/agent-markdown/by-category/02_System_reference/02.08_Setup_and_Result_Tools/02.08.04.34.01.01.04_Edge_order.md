# Edge order

You have to observe the following edge order rules:

For drive edges:

- All tri-state edges, which are used at least once in the same waveform have to be arranged in ascending order. Tri-state action can be assigned to all drive edges.
- The positions of edges using either the data formatter or the tri-state formatter are independent of each other.

For receive edges:

- In waveforms without window actions (window open or window close) no edge order is required.
- In waveforms with at least one window action, all receive edges have to be ordered regardless of whether they are used for window compare or edge compare. Note, that there may also be unused edges, or edges used only in other test system cycles. Their position is not relevant for the test system cycle, where a window occurs, as they are not being used there.
- Overlaid or nested windows, or edges within windows are not allowed.
- Windows can be open for several test system cycles in a device cycle.
 Note The following general rule is valid across different test processor generations (ensured by design): minimum distance between a window open and close, 1 nsec is a safe value. Note that the pin electronics front-end bandwidth might further limit this.
