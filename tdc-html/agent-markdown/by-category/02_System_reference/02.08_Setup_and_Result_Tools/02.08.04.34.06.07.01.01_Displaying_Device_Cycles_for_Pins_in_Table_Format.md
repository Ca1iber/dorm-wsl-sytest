# Displaying Device Cycles for Pins in Table Format

In the Select pulldown menu pick the option format pins.

The device cycle edit area displays all pins that are set up in the current table format and the device cycles that have been generated for them. Depending on the setting made in the Table Format, the device cycles can have:

- different names (since they are different device cycles)
- the same name, where they are different from each other, since they have been generated for different pins.
