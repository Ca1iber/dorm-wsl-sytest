# Data File

Standardized file formats make data portable over a variety of soft-/hardware. In order to support importing and exporting reflection coefficient data two widely used file formats are supported by the Signal Analyzer: CITI file format and Touchstone file format.

## Open Graph

Data files can be opened from the File menu using the option Open Graph. In the file browser dialog you can then set Files of Type to "Touchstone Format File" (*.s1p, *.s2p, *.ts) or "CITI Format File" (*.cti, *.cit, *.citi) to filter out desired files. Upon opening a valid file a new graph will be opened. Depending on the data contained in the file there could be one trace (S11) or two traces (S11 and S22) displayed in the graph. Up to 2-port network data are supported.

## Save Trace as

To save trace data to a file you can access File menu->Save Trace As. Only one data trace can be saved to a file at a time. So if there are multiple traces present in the graph, a selection dialog box is displayed that asks which trace should be saved. After selecting the target trace you can set Files of Type to "Touchstone Format File" or "CITI Format File" for reflection coefficient data.

Note An error is thrown when attempting to save a normal 2-dimensional waveform to CITI format file or Touchstone format file. Attempting to save a reflection coefficient data trace to other types of files for example, ASCII format) will cause a warning and the frequency data will be lost if you proceed.

## Save Graph as

For internal storage of a Smith Chart in the Signal Analyzer the XML format can also be used. It stores not only the trace data but also the graph format settings. For Smith Chart in particular, the characteristic impedance, electrical delay and loss are also stored in the XML format file.
