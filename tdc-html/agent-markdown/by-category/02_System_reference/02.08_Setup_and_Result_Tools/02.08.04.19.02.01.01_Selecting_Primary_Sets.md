# Selecting Primary Sets

You can change the timing, level, waveform and DPS primary sets by changing either the set number or the set name. You can change the timing set for each individual port using the Select > Multiport Timing Specification function.

 Note Only sets of the actually downloaded dataset are available for selection.

The Vector Label displayed below is informational only and requires no user entry.
