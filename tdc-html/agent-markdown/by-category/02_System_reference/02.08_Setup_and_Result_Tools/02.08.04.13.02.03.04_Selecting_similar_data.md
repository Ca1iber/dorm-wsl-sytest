# Selecting similar data

You can select rows containing results for the selected test in the same view by pressing the space bar and in other views by activating the preference setting to synchronize views.

## About this task

Perform these tasks when you want to see additional results for a selected test.

## Before you begin

[Load the data logs](<02.08.04.13.02.02.01_Loading_and_unloading_data_log_files.md>) or streams that contain the data you want to examine and [open](<02.08.04.13.02.02.02_Opening_a_data_log_for_examination.md>) them to see their summary views.

## Procedures

### Highlighting additional results for the selected test

If a [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>) contains multiple rows with results for the same test (a test with the same test suite name, test name, test method, and test number), you can select one of them and then extend the selection to all others by pressing the space bar. The result is the same as if you had manually selected the additional rows by control-clicking them.

Pressing the space bar again returns the selection to the original row.

Note that this procedure does not rearrange the rows in the view. If you have not [sorted](<02.08.04.13.02.03.01_Sorting_tables.md>), [filtered](<02.08.04.13.02.03.02_Filtering_test_result_data.md>), or [grouped](<02.08.04.13.02.03.05_Separating_summary_results_by_wafer__site__or_pin.md>) the table, the additional selected rows may therefore not be visible in the view. However, they are still selected and any open result graph views show their data.

### Synchronizing views

You can synchronize the [Data navigation views](<02.08.04.13.03.02_Data_navigation_views.md>) of different open data logs. When views are synchronized, selecting a test in one data navigation view also selects in all other open data navigation views that contain the same test.

To synchronize views:

- Open the [Result Tool preferences page](<02.08.04.13.03.05_Preference_settings_for_the_Integrated_Result_Tool.md>).
- Activate the Synchronize selections in navigation views option.

If you later want to stop the views from synchronizing, deactivate the option again.

## Results

When you have highlighted additional results for the same test, all rows containing results for the selected test in the frontmost test summary tab are highlighted.

When you have synchronized views, rows containing results for the selected test are highlighted in other test summary views.
