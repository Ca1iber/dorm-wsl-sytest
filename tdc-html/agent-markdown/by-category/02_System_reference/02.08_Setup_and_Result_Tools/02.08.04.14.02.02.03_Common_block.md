# Common block

A common block is a section of a timing or level component defined in such a way that it can be called from anywhere else within that component. Its purpose is to cut down on the amount of typing required if, for example, the same syntax is required more than once within a component.

Components become easier to maintain when using common blocks, as they reduce the amount of editing necessary when a change to a common block is required.

It is possible to define common blocks in any of the equation based testing components.

A common block is defined using the following syntax:

```
#begin <description>
.
.
.
#end
```

It is called using the following syntax:

```
#include <description>
```

<description> is a string of up to 60 characters, excluding `#`. If it is enclosed in double quotes ("..."), everything inside the quotes is taken as the description - even spaces. If the description is not enclosed in double quotes, all characters up to but not including the first space is taken as the description. If it is not unique, an error is reported at the point that it is defined (`#begin`).

A common block can only be called from within the component in which it is defined.

Any part of a component's syntax can be made into a common block.

A `#include` can be placed anywhere in the component after the common block it references has been defined. Forward referencing is not allowed.

For an example, see [Timing Wavetables - Example](<02.08.04.34.04.04.01_Timing_Wavetables_-_Example.md>).
