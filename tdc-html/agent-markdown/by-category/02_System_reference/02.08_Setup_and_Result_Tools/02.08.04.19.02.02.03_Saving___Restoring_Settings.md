# Saving & Restoring Settings

You can save or recall selection information - for example, the pins and groups selected, levels and timing sets selected, and so on - by clicking the appropriate selection in the File pulldown menu. A dialog box appears in which you specify the path and filename of the file you want to load from or save to.
