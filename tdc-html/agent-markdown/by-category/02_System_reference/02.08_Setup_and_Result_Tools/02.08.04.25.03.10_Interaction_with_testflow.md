# Interaction with testflow

#### Subtopics

- [Displaying the shmoo plot of a shmoo test suite](<02.08.04.25.03.10.01_Displaying_the_shmoo_plot_of_a_shmoo_test_suite.md>)
- [Transferring the shmoo tests from the Shmoo Tool to testflows](<02.08.04.25.03.10.02_Transferring_the_shmoo_tests_from_the_Shmoo_Tool_to_testflows.md>)
- [Transferring test suites to the Shmoo Tool](<02.08.04.25.03.10.03_Transferring_test_suites_to_the_Shmoo_Tool.md>)

The Shmoo Tool and the testflow can interact with each other:

- The shmoo tests set in the Shmoo Tool can be transferred to a testflow as a shmoo test suite.

See [Transferring shmoo tests from the Shmoo Tool to testflows](<02.08.04.25.03.10.02_Transferring_the_shmoo_tests_from_the_Shmoo_Tool_to_testflows.md>).

- A test suite can be transferred to the Shmoo Tool.

See [Transferring test suites to the Shmoo Tool](<02.08.04.25.03.10.03_Transferring_test_suites_to_the_Shmoo_Tool.md>).

- The Shmoo Tool can display the shmoo plot of a shmoo test suite only after you have transfterred the shmoo test suite setup into the Shmoo Tool. For details, see [Displaying the shmoo plot a shmoo test suite](<02.08.04.25.03.10.01_Displaying_the_shmoo_plot_of_a_shmoo_test_suite.md>).Note The Shmoo Tool cannot display the shmoo plots of a running shmoo test suite or a running testflow. To view these shmoo plots, use the Integrated Result Tool. For details, see [Interaction with the Integrated Result Tool](<02.08.04.25.03.11_Interaction_with_the_Integrated_Result_Tool.md>).
