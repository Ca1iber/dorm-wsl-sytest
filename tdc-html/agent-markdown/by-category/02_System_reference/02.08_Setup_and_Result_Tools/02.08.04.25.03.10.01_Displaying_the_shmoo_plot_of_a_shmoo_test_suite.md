# Displaying the shmoo plot of a shmoo test suite

The Shmoo Tool can display the shmoo plot of a shmoo test suite only after you have [transferred the setups of the shmoo test suite into the Shmoo Tool](<02.08.04.25.03.10.03_Transferring_test_suites_to_the_Shmoo_Tool.md>).

## About this task

However, the Shmoo Tool cannot display the shmoo plots for a running shmoo test suite or a testflow. To view these shmoo plots, use the Integrated Result Tool. For details, see [Interaction with the Integrated Result Tool](<02.08.04.25.03.11_Interaction_with_the_Integrated_Result_Tool.md>).

## Before you begin

- Make sure a shmoo test suite has been set up in the testflow you want to load.
- Load such testflow with its full setups and open it with [Flow Sequence Editor](<02.08.04.32.03.02_Flow_Sequence_Editor.md>).
- [Open the Shmoo Tool](<02.08.04.25.01_Opening_the_Shmoo_Tool.md>).

## Procedure

-  In the testflow, right-click the shmoo test suite, select Shmoo > Show In Shmoo Tool.

  - A new shmoo page opens in the shmoo editor with the name "<the shmoo test suite name>_shmoo".
  - All setups of the shmoo test suite are transferred to the Properties view related to this shmoo page.

-  In the Shmoo Tool, [execute the shmoo test](<02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>).

## Results

- The shmoo plot shows up in the shmoo page.
- When you click the shmoo page in the Shmoo Tool, the shmoo test suite in the testflow is highlighted automatically.
- When you select the shmoo test suite in the testflow, the corresponding shmoo page in the Shmoo Tool opens automatically.

- [View the shmoo plots of different test results](<02.08.04.25.03.04.04_Viewing_different_types_of_results_on_a_shmoo_plot.md>).

- Debug this shmoo test through modifying the [settings](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>) in the Properties view.

## Functional changes

- Introduced in SmarTest 7.2.0
- SmarTest 7.2.1: The Shmoo Tool dose not display shmoo plots for a running test suites nor displays the shmoo plots during the execution of a testflow.
- SmarTest 7.2.1: After you transferred a shmoo test suite to the Shmoo Tool, the shmoo test suite and the corresponding shmoo page are linked. If you clicke, the other one is selected automatically.
