# Automatic level adjustment for series resistance

 Note For Pin Scale systems the series resistance is not supported in the pin configuration. If you add any serial resistance value for Pin Scale systems, SmarTest issues a warning.

If you have entered in the [Pin Configuration](<02.08.04.18.04_Pin_configuration_file.md>) the value of a resistor that is wired on the DUT board in series with a DUT pin, the Level Setup tool automatically compensates for the level attenuation that is caused by this resistor. The Level Setup tool reads the resistor values, and adjusts the signal levels that the test system expects from the DUT, and the [clamp levels](<../02.06_Command_Reference/02.06.05.01.03_Clamping.md>). Drive levels do not get adjusted, as they are defined into open, that is, for no current flow into the DUT pin. Thus, if you have entered the resistor value in the Level Setup tool, you just enter all signal levels at the DUT output itself.

 Note The output voltage at the DUT output pin depends on the load current and the internal resistance of the DUT. Of course, the software cannot automatically compensate the voltage drop over the internal resistance of the DUT. This you have take into account.

The automatic level adjustment is only capable of compensating for the attenuation of a pure resistance. If you use more complex circuitry (R,L,C) in series with a DUT pin, you have to calculate the receive levels on your own. In this case, do not specify a series resistor value in the pin configuration.

If your device has a significant input current (typical for non-CMOS devices), the voltage drop at a series resistor must be taken into consideration when defining the input drive levels.

 Note The component tolerances of circuitry in series with the DUT pin have an impact on the accuracy of received signals, and a high signal attenuation caused by series resistor that is >> 50 Ohm, reduces the accuracy of the level comparison performed by the comparator of the pin electronics.
