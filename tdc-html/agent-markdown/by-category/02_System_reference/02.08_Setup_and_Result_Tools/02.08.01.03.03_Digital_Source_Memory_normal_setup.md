There are two kinds of DSM setups:

- The source data is downloaded to the DSRC label, and the MAIN label sources data from the DSRC label. This is normal setup.
- The source data is downloaded to the MAIN label. This setup is called FLAT setup.

This section introduce the DSM normal setup.

You can define the pin and port configuration, vector variable configuration and usage, and MAIN label for a Digital Source Memory test with the standard setup tools of SmarTest.

The setup for DSM, using the DSRC label, requires some additional settings, such as the definition of the port from which you want the data to be sourced, and the setup of a vector variable configuration which defines how the data of interest is stored in source memory.

The normal sequence for the setup of Digital Source Memory is:

- Define the pins and port for sourcing (Tool: Pin Configuration Tool). See [Pins and port for Digital Source Memory](<02.08.01.03.03.02_Pins_and_port_for_Digital_Source_Memory.md>)
- Define the Timing and Levels (Tool: Timing and Level Setup Tool). See [Timing and Levels](<02.08.01.03.03.03_Timing_and_Levels.md>)
- Create a MAIN label and a DSRC label, which is for Digital Source Memory in the sequencer or vector memory. (Tool: Pattern Tool). See [Defining the MAIN Label](<02.08.01.03.03.04_Defining_the_Main_pattern.md>) and [Defining the Source Label](<02.08.01.03.03.05_Defining_the_DSRC_source_pattern.md>).
- Define the vector variable configuration and its usage for the DSRC label (Tool: Pattern Tool). See [Creating a Digital Source setup](<02.08.04.16.02.06.16_Creating_a_Digital_Source_setup.md>).
- Download the waveform data to the vector variables (Tool: Signal Analyzer, Test Methods). See [Downloading the waveform data to the vector variables](<02.08.01.03.03.06_Downloading_the_waveform_data_to_the_vector_variables.md>).
- Enter the vector and the proper sequencer instructions in the MAIN label (Tool: Pattern Tool). The Wizard automatically adds the STARTSOURCE (`SSRC`) instruction at the top of the label. SOURCE (`SRCV`) instructions need to be added manually. See [Entering the vectors in the MAIN label](<02.08.01.03.03.08_Entering_the_vectors_in_the_Main_pattern.md>).
- Run the MAIN label for the test.
