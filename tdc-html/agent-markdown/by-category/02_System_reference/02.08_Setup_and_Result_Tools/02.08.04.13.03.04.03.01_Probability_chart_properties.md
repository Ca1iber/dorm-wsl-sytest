# Probability chart properties

The Probability Chart Properties dialog lets you specify certain aspects of the look of a [Probability chart view](<02.08.04.13.03.04.03_Probability_chart_view.md>), including the labels and the settings for the axes.

The dialog has two tabs, both of which are described below.

## Titles

 ![Probability Chart Properties dialog_Titles tab](<../../../../raw/136916.png>)

The Titles tab contains these elements:

- Chart Title: This field contains the title displayed at the top of the chart.

By default, this is the test name and the test number in parentheses.

- Chart Subtitle: The subtitle displayed beneath the title of the chart.

By default, this is the grouping of the displayed tests. If there is no grouping, the field is empty.

- X-Axis: The label for the x-axis.

By default, this is "Value".

- Y-Axis: The label for the y-axis.

By default, this is "Probability [%]".

## Scales

 ![Probability Chart Properties dialog_Scales tab](<../../../../raw/136917.png>)

The Scales tab contains these elements:

- X Axis Scale:

  - Minimum: The lowest value displayed on the value axis.
  - Maximum: The highest value displayed on the value axis.

- Y Axis Scale:

The Lower Limit and Upper Limit fields display the limits with which the displayed test has been executed.

  - Minimum: The lowest value displayed on the probability axis.
  - Maximum: The highest value displayed on the probability axis.
