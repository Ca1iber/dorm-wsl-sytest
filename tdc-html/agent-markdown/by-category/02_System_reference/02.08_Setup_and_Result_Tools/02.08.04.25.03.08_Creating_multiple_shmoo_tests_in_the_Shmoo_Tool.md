# Creating multiple shmoo tests in the Shmoo Tool

In the Shmoo Tool, you can create different independent shmoo tests. Each shmoo test requires you to create a new shmoo page in the shmoo editor (The Shmoo editor is displayed in the editor view after you open the Shmoo Tool).

## Before you begin

[Open the Shmoo Tool](<02.08.04.25.01_Opening_the_Shmoo_Tool.md>).

## Procedure

-  In the shmoo editor, right-click the bottom area under the scroll bar (see the following picture) and select New.
-  Enter a name for a new shmoo page and click OK.

The new shmoo page is created and its name shows on the bottom bar.

  ![Shmoo pages](<../../../../raw/136532.png>)
-  Click the new page name and set up a shmoo test in the related Properties view. For details, see [set up a shmoo test in the Shmoo Tool](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>).

## What to do next

[Execute](<02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>) the shmoo test and [view](<02.08.04.25.03.04_Viewing_shmoo_plots_with_the_Shmoo_Tool.md>) the shmoo plot on this new shmoo page.
