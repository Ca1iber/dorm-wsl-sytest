The specification combines the port-specific timing setups (port-specific equation sets and port-specific wavetables) to a complete timing setup of the device, and defines spec values for the spec variables declared in the equation sets.

## About this task

To create a multiport specification, you can utilize common specification settings.

## Procedure

-  From the Timing Setup window, open the SpecTool window.
-  On the menu, click Change > Create Multiport Specification.

The Create a multiport timing specification window opens.

  !["Create New Timing Specification" Dialog](<../../../../raw/35641.png>)  Note Defined Ports lists the ports in a specific order. This order is of importance when SmarTest will be used for automatic assignment of port periods through the selection of a period_res.
-  On Defined Ports, select the ports you want to assign to the specification.
-  In Specification Name, type a name.
-  Click Create.

SmarTest creates the new multiport specification.

The Spec Tool shows the specification page for a multiport setup.

  ![Spec Tool Showing New Specification](<../../../../raw/57517.png>)

Wavetable shows the first wavetable defined in the wavetable setup (default).

Equation shows equation set 1 (default).

 Note If SmarTest does not show this page: On the menu, select Display > Show Equation Info.
-  Adapt the ports:

  -  In the Port List, click a port.
  -  Select an equation and a wavetable set.

The Name column shows all spec variables declared in the selected equation set.

  -  In the Actual column, assign a value to a spec variable and click run.
  -  Repeat the above for every port.
  -  Specify the scope of the Spec variable ([Global and Local Spec Values](<02.08.04.30.02.16.01_Global_and_local_spec_values__scope_of_the_spec_variable.md>)). For every spec variable you specify the scope per port.

  - To specify the scope of a variable as global. in the column Scope type g.
  - To specify the scope of a variable as local. in the column Scope type l. ![Global and Local Spec Values](<../../../../raw/57518.png>)

Once the data is entered in the newly generated multiport specification, the data needs to be downloaded for temporary use and saved through the timing file for permanent use.
