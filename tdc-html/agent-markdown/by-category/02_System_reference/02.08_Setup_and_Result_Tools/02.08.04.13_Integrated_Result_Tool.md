# Integrated Result Tool

#### Subtopics

- [Principles of operation of the Integrated Result Tool](<02.08.04.13.01_Principles_of_operation_of_the_Integrated_Result_Tool.md>)
- [Using the Integrated Result Tool](<02.08.04.13.02_Using_the_Integrated_Result_Tool.md>)
- [Integrated Result Tool reference](<02.08.04.13.03_Integrated_Result_Tool_reference.md>)

The Integrated Result Tool supports the statistical and graphical evaluation of saved data log files and the system data log stream.

Using the tool, you can load and open data logs. The logs are automatically summarized, and you can create a variety of result graphs to easily spot data of interest.

## Functional changes

- Introduced in SmarTest 7.2.0
