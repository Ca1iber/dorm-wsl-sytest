# Advanced

This tab allows you to define how the system is to react to a recording abort when the error map is located in the external memory. There are three options, which are shortly described in the tab. For more information see [Dealing with storage problems on Smart Scale systems](<../02.06_Command_Reference/02.06.11.01.02.01.05_Dealing_with_storage_problems_on_Smart_Scale_systems.md>).
