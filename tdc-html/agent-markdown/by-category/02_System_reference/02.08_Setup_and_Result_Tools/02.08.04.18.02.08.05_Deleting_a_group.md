# Deleting a group

## Before you begin

You have defined at least one pin group.

## Procedure

-  To select the pin group you want to delete, in the Test Program Explorer view, click the group name to highlight it. To select multiple groups, press Ctrl and click the group names.
-  Right-click the selected pin group names and select Delete.
-  The Confirm Delete window is displayed. Click Yes.
-  Apply the data and save the pin configuration file.

## Results

The group has been deleted.

After deleting an existing group, if it is used by other expression based groups, these groups are evaluated again because their group members may have changed.
