# Saving shmoo plots to png or ASCII files

When executing a shmoo test suite or testflow, to log its shmoo setups and plots into the [report window](<../02.10_Data_Logging/02.10.02.02_Report_window_menus.md>), and to save the generated shmoo plots as .png files or as ASCII files, use the [Event Formatter](<../02.10_Data_Logging/02.10.02_Event_Formatter.md>).

## Before you begin

In SmarTest, open a testflow and load its full setups.

## Procedure

-  [Activiate the Event Formatter](<../02.10_Data_Logging/02.10.02.01_Activating_the_Event_Formatter.md>).
-  To save shmoo plots as .png files, copy the [Event Formatter configuration file (](<../02.10_Data_Logging/02.10.02.13_Appendix_B__Event_Formatter_Defaults.md>)[.formatterrc.def](<../02.10_Data_Logging/02.10.02.13_Appendix_B__Event_Formatter_Defaults.md>)[)](<../02.10_Data_Logging/02.10.02.13_Appendix_B__Event_Formatter_Defaults.md>) to your home directory with the new file name .formatterrc. Then, change the value of shmoo_picture_generation to 1.

After executing the shmoo test suite or testflow, you will see the file path in both the Console view and the Event Formatter output window.

-  To save shmoo plots and results as ASCII files, copy the [Event Formatter configuration file (](<../02.10_Data_Logging/02.10.02.13_Appendix_B__Event_Formatter_Defaults.md>)[.formatterrc.def](<../02.10_Data_Logging/02.10.02.13_Appendix_B__Event_Formatter_Defaults.md>)[)](<../02.10_Data_Logging/02.10.02.13_Appendix_B__Event_Formatter_Defaults.md>) to your home directory with the new file name .formatterrc. Then, change the value of shmoo_txt_generation to 1.

After executing the shmoo test suite or testflow, you will see the file path in both the Console view and the Event Formatter output window.

-  In the test flow, set up a shmoo test suite with the [Shmoo](<../02.07_Test_Method_Reference/02.07.05.01.09_Shmoo.md>) test method or with the [Fail Bit Count Shmoo](<../02.12_Memory_Test_Plus_7.10.2/02.12.02.05.06.02_Fail_bit_count_shmoo_test_method.md>) test method, which is available only for MTP.

Alternatively, you can [set up a shmoo test in the Shmoo Tool](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>) and then [transfer it to the testflow](<02.08.04.25.03.10.02_Transferring_the_shmoo_tests_from_the_Shmoo_Tool_to_testflows.md>) as a shmoo test suite.

-  In the testflow, enable the following test suite flags for this shmoo test suite:

  - Output on pass
  - Output on fail
  - Pass value
  - Fail value
  - Per pin on pass
  - Per pin on fail

-  Execute the shmoo test suite or testflow.

## Results

- The shmoo test setups and plots are displayed on both the report window and the Console view.

See [Shmoo output of the Event Formatter](<../02.10_Data_Logging/02.10.02.04_Shmoo_output_of_the_Event_Formatter.md>).

- If you have enabled shmoo picture generations as described in step 2, shmoo plots named with time stamps are saved as .png files to the <the current device>/shmoo/shmooPNG/ directory.

You will find this directory in both the Console view and the Event Formatter output window which is in the report window.

- If you have enabled shmoo ASCII file generations as described in step 3, shmoo plots and results are saved as ASCII files.

You will find the file directory in both the Console view and the Event Formatter output window which is in the report window.

## What to do next

In the report window, you can view, save and print these data logs. For details, see [Report window menus](<../02.10_Data_Logging/02.10.02.02_Report_window_menus.md>).

## Functional changes

- Introduced in SmarTest 7.2.0
- SmarTest 7.2.1: The Event Formatter can log the fail bit count shmoo tests to the report window.
- SmarTest 7.2.1: The Event Formatter can save shmoo plots as .png files.
- SmarTest 7.2.2: The Event Formatter can save shmoo plots and results as ASCII files.
