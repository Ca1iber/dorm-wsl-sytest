# Automatic calculation of period resolution for single-port setups

If the period resolution is not specified, SmarTest calculates it from the timing setup. In the single-port case, it uses the global period specified in timing set 1 of the equation set that is associated with the respective timing specification (see [Defining the timing specification](<../02.06_Command_Reference/02.06.06.01.05_Defining_the_timing_specification.md>)). The calculation is done dynamically: every time you change the global period for timing set 1, the system recalculates the period resolution. All the period values that are specified in any timing set will be corrected to a multiple of the new period resolution, if necessary.

The period resolution must lie within a range that is determined by the board type. The following table shows these ranges for the different boards:

 | PS5000  | 1.0 ns  | 100 μs |

If the lower limit of the period resolution is denoted by L and the upper limit by U, then the period resolution is calculated from the period p of timing set 1 as the largest number r with L ≤r ≤U which satisfies the equation

p = r *N

for a natural number N.

The formula for determining r is most easily given if p is written as M*U + x where M ≥0 is a natural number and 0 ≤x < U is real. Then

r = p/(M+1) for x > 0, and r = p/M  for x = 0

Note that this calculation depends on L only insofar as L ≤p must be satisfied. Thus the period resolution and auto-correction of the timing sets > 1 will be the same for the same p on all systems with the same U, provided that p ≥ L also holds in all these systems.

Note also that this description applies only to single-port setups. For multiport setups, see [Period resolution for a multi-port setup (Smart Scale)](<../02.06_Command_Reference/02.06.06.01.04.01.02.04_Period_resolution_for_a_multi-port_setup__Smart_Scale.md>).

If you combine boards with different resolution ranges then the resulting range is determined by the greatest lower limit and the smallest upper limit of these ranges.
