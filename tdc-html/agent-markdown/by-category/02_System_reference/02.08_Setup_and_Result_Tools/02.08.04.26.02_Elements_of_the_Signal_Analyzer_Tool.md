The main window of the Signal Analyzer is divided into two sub panels:

  ![Main Screen](<../../../../raw/353435.png>)

- The Waveform Navigator Tool (WNT) displays the list of waveforms stored in the current device file directory.
- The Waveform Graphs Tool (WGT) is used to create, view, download, upload, and analyze waveforms. This tool not only shows setup data, but also result data in a unified manner.

The Navigator allows users to start applications. This window can be collapsed to maximize the size of the other panels.

The functions of the Signal Analyzer are accessed via the menu bar.

 ![Menu Bar](<../../../../raw/45894.png>)

## User Defined Functions

Within the toolbar area is the [User Defined Panel](<02.08.04.26.02.03_User_Defined_Panel.md>) functions. These functions are programmable using the Data Display API and DSP Test Method API. These functions are independent of the test method program.

 ![User Defined Panel Toolbar](<../../../../raw/45966.png>)

For more information on the provided functions see [User Defined Panel](<02.08.04.26.02.03_User_Defined_Panel.md>).

Much of the functionality can also be controlled programmatically using the [Data Display API](<../02.07_Test_Method_Reference/02.07.04.01.22_Data_Display_API.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.3: The size of the waveform, which is analyzed using FFT, can be any integer.
