# Executing a Test Program

It is useful to execute a test program without any workorder generation as a quick check that your test program works as expected. The test program will be executed in just the same way as it would in a production test.

To execute a test program:

- In the Test Program Editor view highlight the item Test Program.
- Right-click and select Run.
