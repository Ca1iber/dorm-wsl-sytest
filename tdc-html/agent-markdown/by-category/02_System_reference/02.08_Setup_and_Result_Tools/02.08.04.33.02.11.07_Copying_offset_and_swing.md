# Copying offset and swing

This topic describes how to copy the offset and swing (Range) of One Channel to All Output Channels: when using the [softscope function](<02.08.04.33.02.12_Softscope_function_of_the_Timing_Diagram.md>).

## Procedure

-  Highlight the pin name of the channel you want to copy from.
-  On the menu click Edit > copy range.
-  When the selection is done click copy in the resulting dialog box.
