# Creating a pin group

You can create a pin group of fixed type or expression-based type.

## Before you begin

You have defined pins.

## Procedure

-  In the Test Program Explorer view, right-click Groups and select New.

The New Group window opens.

  ![New Group Editor](<../../../../raw/126827.png>)
-  Select the group type:

  - Fixed Group (default)
  - Expression Based Group

See [Defining pin groups](<../02.06_Command_Reference/02.06.03.01.06_Defining_pin_groups.md>) for a description of the group types.

-  In the New Group, type the group name.
-  Click OK.

## Results

The Group Editor for the new group opens. The Group Members area is blank.

## What to do next

Edit the group.
