# Configuring the Testflow Tool

You can configure the Testflow Tool in the [Preferences window](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.14_Preferences_window.md>). You can open this window by choosing Window > Preferences in the SmarTest Work Center.
