# TSUX, TSUX? - (Timing Sets Used eXtended)

The TSUX (Timing Sets Used eXtended) command is only for use by the system, not the user. Do not attempt to execute it from the hpt utility! You may execute the query. The following information is provided to improve your understanding of any hpt output listings you may make.

During test flow optimization the TSUX command is used internally by the Test Flow Optimizer to generate additional (optimized) timing sets. The [TSUS?](<../02.06_Command_Reference/02.06.02.02.283_TSUS__TSUS__-__Timing_Sets_USed.md>) query returns the number of all timing sets, including those that are optimized. Thus TSUX? is used to return the original number of timing sets, that is, those before optimization. The Test Flow Executor then calculates the number of optimized timing sets.

The command is not active unless optimized test flows are used.

## TSUX

```

TSUX {waveform_set},{timing_set}
```

## TSUX?

```

TSUX? {waveform_set}
```

returns:

```
TSUX {waveform_set},{timing_set}
```

## Parameters

 |

waveform_set

 |

Waveform set number. Enter ALL for all waveform sets in the query command.

 |
 |

timing_set

 |

Timing set number. In the command, TSUX is set to this value for the specified waveform set, if the number is smaller than the current value of [TSUS](<../02.06_Command_Reference/02.06.02.02.283_TSUS__TSUS__-__Timing_Sets_USed.md>) for this set. Otherwise, it is set to the current value of TSUS.

 |
 |

SWAP

 |

This command parameter causes the values set by [TSUS](<../02.06_Command_Reference/02.06.02.02.283_TSUS__TSUS__-__Timing_Sets_USed.md>)and TSUX to be switched, that is, TSUS is set to the current value of TSUX , and TSUX to that of TSUS for the specified waveform set.

 |
 |

NONE

 |

This command parameter sets the value of TSUX back to 1 for the specified waveform set.

 |

## Application

Optimized testflows.

## Functional changes

- Introduced before SmarTest 6.3.2
