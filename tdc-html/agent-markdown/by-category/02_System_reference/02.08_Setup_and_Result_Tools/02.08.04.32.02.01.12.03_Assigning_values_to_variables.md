# Assigning values to variables

## About this task

There are two possible ways to assign values to variables:

- Enter the desired values on the [Variables page](<02.08.04.32.03.01.05_Variables_page.md>).
- Use Assign Value nodes in the testflow (described below). This changes the current value of a variable.

## Before you begin

Make sure that the variable to which you want to assign a value has been defined.

## Procedure

-  In the Flow Sequence Editor, insert an Assign Value node into the testflow. The Assign Value Dialog window opens.  ![New Assign Value Node Wizard window](<../../../../raw/110635.png>)
-  From the Variable list, choose the variable to which you want to assign a value.
-  Enter the desired value in the Value text box. (String values have to be entered in quotes, like "String".)
-  Click OK.

## Results

The Assign Value node appears in the testflow displaying the variable name. Whenever the testflow passes this node, the specified value is assigned to the indicated variable.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.2: You cannot define new variables by entering a new variable name in the Assign Value node. Defining new variables can only be done on the Variables page.
