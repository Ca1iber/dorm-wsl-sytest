# Merging and splitting pattern files

The Merge Pattern dialog is used to merge or and split pattern files.

## About this task

You can merge individual pattern files into an existing [pattern master file](<02.08.04.16.01.15_Working_with_pattern_master_files.md>) setup.

And you can split large pattern files and save the single patterns in individual files.

You can merge files from multiple locations in your file system into one pattern file at any location. You can also split a large pattern file into multiple pattern files and save those at any location. The actual split of the file happens when you save the file, not during the merge operation.

## Before you begin

To be able to reload your current setup (before merging any patterns) in case you are not satisfied with the result, you must have saved all modified patterns prior to attempting the merge. If there are any modified but unsaved patterns, the system prompts you to save them.

## Procedure

-  In the Test Program Explorer right-click the ![Pattern Icon](<../../../../raw/92199.png>) Pattern component and select Merge (Pattern Files). The Merge Pattern dialog opens.   ![Merge Pattern](<../../../../raw/344380.png>)
-  If required, you can limit the number of patterns displayed in the dialog.

  - In the top field you can change to the top folder of the pattern files to be merged.
  - In the list box on the left you can select one or more sub-folders whose content you want listed.

-  In the list box on the right, select those patterns you want to merge.

Click the checkbox of a folder in the list box on the left and all pattern files contained in the folder are selected.

-  For pattern master file setups only: The dialog provides several options at the bottom. ![Merge Pattern Master](<../../../../raw/344415.png>)  You can select the following options:

  - Keep original pattern location

Adds the selected pattern files to a pattern master file while maintaining the pattern files at their original location.

  -

Copy pattern files

Copies the selected pattern files into a specified folder.
  -

Split into individual files for each pattern

Splits the selected pattern files into individual files for each pattern.

-  Specify the directory where you want the new pattern files to be created. This entry field is disabled if, in the previous step, you selected Keep original pattern location or if you are not using a pattern master file.
-  When done, click Finish.

## Results

The resulting files will be marked with the asterisk (*) symbol. The actual split or merge of the files happens when you save the files, not during the split or merge operation.

The system will load the patterns in the appropriate order (subroutines > main patterns > bursts).
