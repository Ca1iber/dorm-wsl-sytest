# Loading and unloading data log files

STDF and EDL data log files are loaded and unloaded using toolbar buttons or context menu commands in the [Data Log Explorer](<02.08.04.13.03.01_Data_Log_Explorer_view.md>).

## About this task

Load data log files to be able to [open](<02.08.04.13.02.02.02_Opening_a_data_log_for_examination.md>) them for statistical analysis or combine them by [merging](<02.08.04.13.02.02.03_Merging_data_logs.md>) or [correlating](<02.08.04.13.02.02.04_Correlating_data_logs.md>) them with other logs.

Unload data logs to free up the memory that they use.

Note This procedure does not apply to the system data log stream, which is always automatically loaded and cannot be unloaded.

## Before you begin

[Open the Integrated Result Tool](<02.08.04.13.02.01_Opening_the_Integrated_Result_Tool.md>).

## Procedures

### Loading a data log file

- In the [Data Log Explorer](<02.08.04.13.03.01_Data_Log_Explorer_view.md>), click the Load button ![Data Log Explorer view_Load icon](<../../../../raw/136276.png>).

You can also right-click anywhere in the view and choose Load.

A standard Eclipse file selection dialog opens.

- Select one or more STDF or EDL files and click OK.

Each selected file is opened in a [data navigation view](<02.08.04.13.03.02_Data_navigation_views.md>).

### Unloading one or more data log files

- In the [Data Log Explorer](<02.08.04.13.03.01_Data_Log_Explorer_view.md>), select all files you want to unload.

Shift-click or control-click to select multiple files.

- Right-click any of the selected files and choose Unload.

The selected files are unloaded. If any [Data navigation views](<02.08.04.13.03.02_Data_navigation_views.md>) are open for these files, they are closed.

### Unloading all loaded data log files

In the [Data Log Explorer](<02.08.04.13.03.01_Data_Log_Explorer_view.md>), perform either of these actions:

- Click the Unload All button ![Data Log Explorer view_Unload All button](<../../../../raw/136277.png>).
- Right-click anywhere and choose Unload All.

All data log files (but not the system data log stream) are unloaded. If any [Data navigation views](<02.08.04.13.03.02_Data_navigation_views.md>) are open for these logs, they are closed.

## Results

The [Data Log Explorer](<02.08.04.13.03.01_Data_Log_Explorer_view.md>) contains all files you have loaded and no files you have unloaded. (It also contains the system data log stream.)
