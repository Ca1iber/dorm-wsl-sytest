# CLKR, CLKR? - (CLocK Resolution)

The CLKR command defines the period resolution for a (single-port or multi-port) timing specification or a waveform set.

## Postdependencies

Note that if you define the period resolution with CLKR, the system will no longer recalculate it when you change the tester period of timing set 1 with the [PCLK](<../02.06_Command_Reference/02.06.02.02.175_PCLK__PCLK__-__Pin_CLocK.md>) command globally, that is, for all pins. Note also in connection with equation based timing that CLKR only changes the runtime value of the period resolution. A definition within an equation set (with the period_res keyword) will not be changed.

## CLKR

```
CLKR {waveform_set|specset_id|"multi-port_spec"}, [ref_period],{period_res}
```

## CLKR?

```
CLKR?[type,] {waveform_set|specset_id|"multi-port_spec"}
```

returns:

```
CLKR {waveform_set|specset_id|"multi-port_spec"}, [ref_period],{period_res|clock_res}
```

## Parameters

 |

waveform_set

 |

Waveform Set Number. Enter an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by [WSUS, WSUS? - (Waveform Sets USed)](<../02.06_Command_Reference/02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>). For the query command you can also enter ALL for all waveform sets.

 |
 |

specset_id

 |

Derived as follows:

100 * equation_set_no + specset_no

 |
 |

multi-port_spec

 |

To set or query the resolution of a multi-port timing specification, specify the name of the specification.

 |
 |

ref_period

 |

Not used. (Ignored)

 |
 |

period_res

 |

The period resolution (in ns) for the specified specification or waveform set.

If necessary, period_res is rounded to nine digits after the decimal point. The allowable maximum period resolution is the maximum tester period value. The minimum period resolution is determined by the hardware (see [Automatic calculation of period resolution for single-port setups](<../02.06_Command_Reference/02.06.06.01.04.01.02.01_Automatic_calculation_of_period_resolution_for_single-port_setups.md>)).

 |
 |

type

 |

In the query, the type parameter specifies which resolution is queried. The allowed values are:

VIRTUAL: The period resolution (period_res) is queried. This is the default.

EXACT: The clock resolution (clock_res) is queried.

 |
 |

clock_res

 |

In the answer to the query, the clock resolution is returned if type is set to EXACT in the query.

 |

## Application

Timing Setup, see [Timing Setup Commands](<../02.06_Command_Reference/02.06.06_Timing_Setup_Commands.md>).

## Errors

An error is generated if:

- waveform_set is less than 1.
- waveform_set is greater than the range allowed by the [WSUS](<../02.06_Command_Reference/02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>) command.
- period_res is outside the allowed range.

## Example

```
> CLKR 1,,10
> CLKR? 1
< CLKR 1,1000,10

```

This example sets and queries the period resolution (10 ns) for waveform set 1. Ignore the returned value of the ref_period parameter.

```
> CLKR? "spec_port_1_port_2"
< CLKR "spec_port_1_port_2",50,5.555555556
```

This example queries the period resolution for the multi-port specification `spec_port_1_port_2`.
