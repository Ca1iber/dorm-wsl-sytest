# File menu

 |

Item

 |

Function

 |
 |

Open

 |

To open an existing channel attributes file for the current device.

 |
 |

Save

 |

To save fixture delay measurement results or changes you make using the Import or Edit features in the Fixture Delay Tool window.

Note that you cannot save changes to the default channel attributes file. If you use this file as a basis for creating a new file of channel attributes, you must use the Save As command and save your changes to a file with a new name.

 |
 |

Save as

 |

To create a file with a new name. The file is saved in the channel attributes directory of the current device. Use Save As if you use the default channel attributes file as the basis for creating a new channel attributes file. The default channel attributes file cannot be overwritten.

 |
 |

Save Configured

 |

Save the values for [Configured channels](<02.08.04.10.03.03.01_Configured_channels.md>).

 Note A pin configuration must be loaded. |
 |

Import

 |

To convert a selected comma separated values (CSV) file to active fixture delay data. Note that each line of the CSV file must define the fixture delay of a single channel as follows:

`<channel>, <value>`

where `<channel>` specifies a five digit channel number and `<value>` defines a fixture delay value in nanoseconds in floating or fixed decimal point format.

 |
 |

Export

 |

To convert the currently selected channel's fixture delay data to CSV file format.

 |
