# Changing the Version Header of the Specification Set File

- Click Change Version Header in the Change menu.

A screen similar to that of the figure below appears.

  ![Changing the Version Header](<../../../../raw/22032.png>)
- Edit the text in the edit field.
- Click save.

## Functional changes

- Introduced before SmarTest 6.3.2
