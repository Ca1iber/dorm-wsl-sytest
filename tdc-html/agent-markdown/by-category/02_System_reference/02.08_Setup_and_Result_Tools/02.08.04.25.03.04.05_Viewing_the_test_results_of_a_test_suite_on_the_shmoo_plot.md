# Viewing the test results of a test suite on the shmoo plot

When shmoo plotting an existing test suite, the test results that are logged with the [judgeAndLog](<../02.07_Test_Method_Reference/02.07.04.01.244_TESTSET.md>) API of this test suite will be displayed on the shmoo plot.

## About this task

To view other results that are not logged with the judgeAndLog API on the shmoo plot, use the [SHMOO_RESULT](<../02.07_Test_Method_Reference/02.07.04.01.227_SHMOO_RESULT.md>) API in the test method code of the shmooed suite to define these results.

For the test suite to be shmoo plotted, follow the steps below.

## Before you begin

- Open the testflow which contains the test suite to be shmoo plotted.

Make sure all setups of this testflow are loaded.

- [Open the Shmoo Tool](<02.08.04.25.01_Opening_the_Shmoo_Tool.md>).

## Procedure

-  To view the test results logged with the [judgeAndLog](<../02.07_Test_Method_Reference/02.07.04.01.244_TESTSET.md>) API on a shmoo plot, go to step 4.
-  To view the results that are not logged with the judgeAndLog API on a shmoo plot, in the test method code of the to be shmooed test suite, set up these results with the [pin()](<../02.07_Test_Method_Reference/02.07.04.01.227.02_SHMOO_RESULT.pin.md>), [site()](<../02.07_Test_Method_Reference/02.07.04.01.227.01_SHMOO_RESULT.site.md>), [testName()](<../02.07_Test_Method_Reference/02.07.04.01.227.03_SHMOO_RESULT.testName.md>) and [setResult()](<../02.07_Test_Method_Reference/02.07.04.01.227.05_SHMOO_RESULT.setResult.md>) member functions of the [SHMOO_RESULT](<../02.07_Test_Method_Reference/02.07.04.01.227_SHMOO_RESULT.md>) API.

For example, `SHMOO_RESULT.pin("pin1").site(1).testName("mea1").setResult(measureValue1)`;

-  Build the modified test method.
-  In the Shmoo Tool, [set up a shmoo test shmooing over this test suite](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>) with the [ac_tml.AcTest.Shmoo](<../02.07_Test_Method_Reference/02.07.05.01.09_Shmoo.md>) test method.

Or, [transfer the setup of the shmooed test suite into the Shmoo Tool](<02.08.04.25.03.10.03_Transferring_test_suites_to_the_Shmoo_Tool.md>) and in the Shmoo Tool set up the other parameters as the setup a shmoo over test suite.

When setting up the ac_tml.AcTest.Shmoo test method:

  - For the shmooTestSuite parameter: Do select the name of the test suite to be shmooed.
  - For the testMode parameter: Do select the user defined measurement test mode.

Alternatively, you can create a new test suite with the ac_tml.AcTest.Shmoo test method and then [transfer it to the Shmoo Tool](<02.08.04.25.03.10.03_Transferring_test_suites_to_the_Shmoo_Tool.md>).

-  In the Shmoo Tool, [execute the shmoo test](<02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>).

The shmoo plot of one test result is displayed.

-  To view the shmoo plot of another test result, right-click the plot and select the Test Modes command, and then select the interested result.
-  To view the shmoo plots of different pins, right-click the plot and select the Result Pin command, and then select the required pin.
-  To view the shmoo plots of different sites, see [Viewing the shmoo plots of different sites](<02.08.04.25.03.04.07_Viewing_the_shmoo_plots_of_different_sites.md>).
