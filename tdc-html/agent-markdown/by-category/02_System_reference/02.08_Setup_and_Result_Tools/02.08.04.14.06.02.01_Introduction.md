# Introduction

Many devices to be tested use mixed level signals on their input side.A typical device would be a chipset connected to a CPU and various buses. CPU and different buses have standardized level settings and swings for their input and output signals which must be fulfilled by the device. Thus, you need mixed level signals and different swings.

Another example would be a high-speed device (i.e. SRAM realized in ECL technology). For several reasons, a clock pin with a low swing, and data pins with a higher swing are desirable in that case.

These mixed level signals affect some basic consequences on measurements, which can be traced back to physical laws. However the user should be aware of these implications, in order to get reliable test results.

Vice versa, for devices with the same swing for all pins and groups of pins, these implications have no impact on the received results, and so no further adjustments are needed.

The aims of the following sections are threefold:

- to make you aware of the technical issue caused by different swings
- to describe how to handle different swings
- to describe some criteria of when to perform swing adjustment

If you are already familiar with the testing of mixed level devices you can set your swing adjustment directly.

- Automatic swing adjustment directly be switched on or off in the timing setup or for single specs.

See [Using Automatic Swing Adjustment](<02.08.04.14.06.02.05_Using_Automatic_Swing_Adjustment.md>)

- Adjusting swings directly via firmware commands. Several firmware commands are provided to either switch on automatic swing adjustment or to set up swing adjustment by yourself.

See [Related Firmware Commands](<02.08.04.14.06.02.06_Related_Firmware_Commands.md>)
