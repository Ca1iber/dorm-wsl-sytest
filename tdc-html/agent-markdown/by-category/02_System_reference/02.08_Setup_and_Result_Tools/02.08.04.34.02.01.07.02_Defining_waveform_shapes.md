# Defining waveform shapes

In fixed timing, the only waveform format is pairs of logical and physical waveforms. The logical waveforms are defined with the WFDS command, the associated physical waveforms with the WAVE command, and the break waveform with the BWDS command. The following listing is an example:

WFDS 1,0,,"d1:F00 d2:D11 d3:F0N",(IN1)

WAVE 1,0,F00,,,,0,(IN1)

WAVE 1,0,F10,,,,1,(IN1)

WFDS 1,1,,"d1:FN0 d2:D11 d3:F0N",(IN1)

WAVE 1,1,F00,,,,2,(IN1)

WAVE 1,1,F10,,,,3,(IN1)

WFDS 1,2,,"d2:F1N d3:F0N",(IN1)

WAVE 1,2,,,,,4,(IN1)

WFDS 1,3,,"",(IN1)

WAVE 1,3,,,,,5,(IN1)

WFDS 1,4,,"d4:D22",(IN1)

WAVE 1,4,,F00,,,6,(IN1)

WAVE 1,4,,F10,,,7,(IN1)

WFDS 1,5,,"d5:C2N",(IN1)

WAVE 1,5,,F0N,,,8,(IN1)

WAVE 1,5,,F1N,,,9,(IN1)

BWDS 1,,,"",(IN1)

The WAVE command generates physical waveforms out of logical waveforms by assigning concrete actions to the data parameters. For details, see the descriptions of the individual commands.

Note that in contrast to the wavetables, the logical and physical waveform DC/DC power units must be specified in decimal notation in the WFDS and WAVE commands.
