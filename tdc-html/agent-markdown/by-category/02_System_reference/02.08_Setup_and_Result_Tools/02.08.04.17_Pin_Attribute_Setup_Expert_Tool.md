# Pin Attribute Setup Expert Tool

#### Subtopics

- [Pin Attribute user interface](<02.08.04.17.01_Pin_Attribute_user_interface.md>)
- [Using the Pin Attribute Setup Expert Tool](<02.08.04.17.02_Using_the_Pin_Attribute_Setup_Expert_Tool.md>)

The Pin Attribute Setup Expert Tool is an Engineering Tool that be used to correct non-DUT board related and non-DUT related inaccuracies in the timing system of V93000 test systems.

## What is the Pin Attribute Setup Expert Tool?

The Pin Attributes Setup Tool enables you to set and/or edit pin attributes. This is necessary, in some cases, because there could be a time delay between the DUT and the tester pin. It includes a graphical user interface (GUI) to easily edit the pin attributes.

## Why do we need the Pin Attribute Setup Expert Tool?

The pin attributes are the edge delays per pin used to fine-tune the calibration of the device setup. The test system supports 8 drive and 8 receive edge delays per pin.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.0.1: For Pin Scale 9G pins, 16 drive deges including 8 slow edges and 8 fast edges are supported in the Pin Attribute Setup Expert Tool.
