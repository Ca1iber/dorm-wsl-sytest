# Resource Selection

The next set of commands deal with resources on which the measurements are performed.

```
"PINS" <sep> "@" | <pin/group> { <sep> <pin/group> }
```

PINS lets you select your pins/groups for the measurements. @ specifies that all pins are selected.

```
"TIMINGSET" <sep> "ALL"|"PRM"|<setno> [<sep> """" <description> """"]
     {<sep> <setno> [<sep> """" <description> """"]}
```

TIMINGSET specifies all the timing sets on which the measurements are performed. ALL means all used timing sets in the current pattern.

```
"LEVELSET" <sep> "ALL"|"PRM"|<setno> [ <sep> """" <description> """"]
    { <sep> <setno> [ <sep> """" <description> """" ]}
```

LEVELSET specifies all the level sets on which the measurements are performed. ALL means all used level sets in the current pattern.

```
"DPSSET" <sep> "ALL"|"PRM"|<setno> [<sep> """" <description> """"]
    { <sep> <setno> [ <sep> """" <description> """" ] }
```

DPSSET specifies all the dps sets on which the measurements are performed. ALL means all used dps sets in the current pattern.

```
"RESOURCES" <sep> "ALL" | <resource> { <sep> <resource> }
<resource> = "period" |"d1" | "d2" | "d3" | "d4" |"d5"|"d6"|"d7"|"d8"
    | "r1" | "r2" | "r3" | "r4" |"r4" | "r5" | "r6"
    | "vih" | "vil" | "voh" | "vol" | "vt" | "iol" | "ioh"
    | "vcl" | "vch" | "level" | "current"
```

With RESOURCES ALL all the resources that are applicable will be used. The next commands describe "how the measurement will be carried out".

```
"METHOD" <sep> "PARALLEL" | "SERIAL" | "BYGROUPS"
```

PARALLEL means that pins that are of the same type and have the same settings are measured together, that is, their values are changed together.

SERIAL means each pin gets its own measurement.

```
"RANGE" <sep> "RELATIVE" | "ABSOLUTE" <sep> <resource type> <sep> <from value> <sep> <to value>
<resource type> =  "EDGEDELAY" | "CURRENT" | "PERIOD" | "LEVEL" | "LOWLEVEL"
    | "HIGHLEVEL" | "TERMLEVEL"
<from value> | <to value> = <float value> "V" | "ns" | "mA" | "%"
```

The RANGE for the measurements of the different resource types can be specified either RELATIVE to their original setup position or as an ABSOLUTE value.

For the range definitions, the resources are grouped into four types - EDGEDELAY, CURRENT, PERIOD, and LEVEL. Only for the absolute range definition do the levels get divided into the subtypes, LOWLEVEL, HIGHLEVEL and TERMLEVEL.

The range limits of the edge delays can be specified in ns or% - that is, as a percentage of the actual period setup. The range limits of the period can be specified in ns or as a percentage of the actual period setup. The range limits for the levels can only be specified in V. The range limits of currents must be specified in mA.

```
<dps> = "DPS" <sep> <dpsrange> <sep> <dpssteps> <sep> "@" | <dpspin> { <sep> <dpspin> }
<dpsrange> = "2.5%" |  "5%" | "10%" | "20%"
<dpssteps> = "2"  |  "4" | "10"
<dpspin> = <max. 16 characters except @ # " , tab space newline>
```

If With DPS is specified, the actual number of measurements will be one more than the dpsstep, and the value of the DPS voltage shown on the report will be the absolute value.

Step Mode is defined thus:

```
"STEPMODE" <sep> ("TEST_ALL_STEPS") <sep> <no_of_steps>
<no_of_steps> = <integer 2 .. 50>)
```

The default value for no_of_steps is 50. TEST_ALL_STEPS results in all measurement points being tested. FAST_TEST will only test to the first transition.
