# DC Scale pin (DPS mode) setup

DC Scale pins in DPS operating mode are set up in the DPS Pins editor. In DPS operating mode, you use the DC Scale card like a standard DPS, to supply devices with power during the execution of a test flow.

![DPS Pins editor](<../../../../raw/354609.png>)

Its configuration contains the following information.

 | Name  | A unique name for the DC Scale pin. |
 | Pol  | This specifies the polarity of the DC Scale pin in DPS operating mode. It must be POS. |
 | C[uF] |

For DPS128/DPS64 or XPS256 cards you may enter a load capacitance value. For more information refer to

- [Load capacitance connected to the DC Scale DPS128/DPS64](<02.08.04.18.03.01.03.02_Load_capacitance_connected_to_the_DC_Scale_DPS128_DPS64.md>)
- [Load capacitance connected to the DC Scale XPS256](<02.08.04.18.03.01.03.03_Load_capacitance_connected_to_the_DC_Scale_XPS256.md>)
 |
 | HW  | This column is not editable. After you enter the tester channel, it automatically shows the hardware information of this channel. In the DPS Pins editor, the following DC Scale cards may be displayed:

- DCS-DPS128HC, DCS-UHC4T, DCS-XPS256
 |
 | Comment  | Optional parameter.

You can provide additional description of the DPS pin in this column.

 |
 | Tester Channel  | Specify a DPS channel.

The DC Scale card can reside in any I/O channel card slot. So the numbering convention for DC Scale channels is same as that for IO channels.

  Ganging of channels Unless otherwise defined below, the following rules are to be followed for defining ganging groups:

- With exception of XPS256, you can gang (parallel connect) only successive channels within a DC Scale card.
- The gang chain can start at any channel and have a minimum of 2 successive channels.
- You can specify the range of channels to be ganged by "-" (hyphen) or each channel separated by "," (comma).
- With exception of XPS256, to gang DC Scale channels, you must specify a consecutive number of channels, for example 10105-10106 (the test channel assigned for Vdd_DPS2 in the example below). The first channel in this sequence is automatically set as master channel, the others are set as slave channels.

Some other rules are to be followed for DC Scale cards:

- DPS128, DPS64:

Ganging is possible for any number of successive channels within a card, but not across cards.

DPS128/DPS64 channels must be of the same type (HC or HV).

- UHC4T:

Ganging is possible for any number of successive channels within a card and any number of cards within a test head.

To specify ganging across UHC4T cards, separate the channel ranges on the cards by comma (,).

See also [UHC4T specific setup tasks](<../02.05_Test_Head_Cards/02.05.05.02.05_UHC4T_specific_setup_tasks.md>).
- XPS256:

See section [Ganging characteristics](<../02.05_Test_Head_Cards/02.05.05.03.08_XPS256_ganged.md#_350922__s_Ganging_characteristics>) in [XPS256 ganged](<../02.05_Test_Head_Cards/02.05.05.03.08_XPS256_ganged.md>).

Note that on DPS128/64 and XPS256 you cannot execute a current compare on a ganged group of channels in unganged mode. Already activated comparators are silently disabled in unganged mode. A user notification (Error or warning) is omitted in this case, to avoid any interrupt in the testflow. The previous state of the comparators is automatically restored after the ganged group has been restored.

 |

## Example

The following table shows the configuration for DC Scale pins.

 | Name  | Pol  | C[uF]  | HW  | Comment  | Tester Channel |
 | Site 1  | Site 2 |
 | Vdd_DPS1  | POS  | 0.0  | DCS-DPS128HC  |   | 10101  | 10104 |
 | Vdd_DPS2  | POS  | 0.0  | DCS-DPS128HC  | 2 channels ganged  | 10102-10103  | 10105-10106 |

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.0: The DC Scale pin of DPS mode is set in the DPS Pins editor.
- SmarTest 7.1.3: Changed the parameter Polarity to Pol in the DPS Pins editor.
- SmarTest 7.1.3: Changed the parameter Load Capacitor [uF]/V-Ramp [us] to C[uF] in the DPS Pins editor.
- SmarTest 7.1.3: Changed the parameter Instrument to HW in the DPS Pins editor.
- SmarTest 7.3.1: DC Scale PVI8 card added.
- SmarTest 7.4.0: DC Scale AVI64 card added.
- SmarTest 7.5.0: DC Scale FVI16 card added.
