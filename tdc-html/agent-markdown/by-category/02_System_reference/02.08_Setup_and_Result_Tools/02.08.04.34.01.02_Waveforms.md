# Waveforms

#### Subtopics

- [The Physical Waveform Table](<02.08.04.34.01.02.01_The_Physical_Waveform_Table.md>)
- [The Break Waveform](<02.08.04.34.01.02.02_The_Break_Waveform.md>)
- [Relationship to Vector Setup](<02.08.04.34.01.02.03_Relationship_to_Vector_Setup.md>)

Waveforms are built up from edge actions. An action is an event such as set drive signal to zero, or make window compare to one. A waveform is the contents of one test system cycle.

In addition, you can set up a break waveform for every channel.
