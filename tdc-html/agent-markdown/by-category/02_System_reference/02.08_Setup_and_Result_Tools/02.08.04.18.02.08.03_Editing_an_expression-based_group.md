# Editing an expression-based group

## About this task

Whichever action you selected:

- to define a new expression-based group from scratch
- to make changes to an existing expression-based group

the way you edit the group is always the same.

Expression-based groups are defined by group expressions and the process consists of three basic steps:

- Defining the group expression
- Selecting the component type
- Evaluating the group expression

## Before you begin

Make sure that an expression-based group has been created.

## Procedure

-  Open the setup editor of the expression-based group you want to edit. If the group is new created, there are no pins in the Group Members area.  ![New Expression Based Group](<../../../../raw/55496.png>)
-  The Available Group/Pin List shows all the defined digital pins, pin groups, and pin aliases in the form of `pin_alias_set::pin_alias_name`. To define the group expression, click an item in the Available Group/Pin List and clicke group operator (+ Union, - Difference or * Intersection). Note To quickly find the pins or groups you are interested in, you can use [Filter line](<02.08.04.18.03.13_Filter_line.md>).
-  Repeat step 2 until you finish the group expression.

The group expression can also be typed directly in the Group Expression text box (see the figure below).

  ![Group Expression text box](<../../../../raw/21666.png>)
-  To determine the type of active pins in the group, select the component type (I, O, IO and DC) in the Component Type list.
-  To evaluate the group expression, click Evaluate.
-  Apply the data and save the pin configuration file.

## Results

After the expression is evaluated, the pins in the group are indicated in the Group Members area. Considering the chosen component type, inactive pins in the list are marked with "*".

In the Available Group/Pin List, the pins in the group are indicated with "鈭?.

 ![The expression based group example](<../../../../raw/97842.png>)

## Example

A group contains all the input pins (all_in), without the pin I/O7. So the expression is all_in - I/O7.

After selecting I type, the steps for building such expression are:

- Click group all_in in the Available Group/Pin List and then click operator + Union. This results in the following group expression. ![Edit an Group Expression (1)](<../../../../raw/21668.png>)
- Click pin I/O7 in the Available Group/Pin List and then click operator - Difference. This results in the final group expression. ![Edit an Group Expression (2)](<../../../../raw/21669.png>)
- To evaluate the group expression, click Evaluate. The pins are printed to the Group Members area. ![Group Expression Result](<../../../../raw/21667.png>)
