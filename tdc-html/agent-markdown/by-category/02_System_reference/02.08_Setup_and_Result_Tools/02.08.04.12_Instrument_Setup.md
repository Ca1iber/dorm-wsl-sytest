# Instrument Setup

Settings for the V93000 which have an impact on RF hardware, RF paths, and RF calibration must be selected prior to runtime.

These settings are captured in a set of data objects known as lists and resources.

The Instrument Setup tool provides editors and dialogs for resources, lists, and bindings.
