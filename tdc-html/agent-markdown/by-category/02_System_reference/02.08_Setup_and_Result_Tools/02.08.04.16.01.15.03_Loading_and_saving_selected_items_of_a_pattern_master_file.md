# Loading and saving selected items of a pattern master file

When working with a pattern master file you can load and save the referenced individual patterns, port bursts, multiport burst, even complete folders, in the Pattern Explorer.

## About this task

To load or save items in the Pattern Explorer, they must belong to a pattern master file. The load and save functions of the Pattern Explorer are not available for standard pattern setup files.

The State column of the Pattern Explorer and the icons indicate the current status of the patterns, port bursts, multiport burst, and folders.

 |

Uptodate

 |

Unchanged from when it was opened or saved.

 |
 |

 |

Was changed.

 |
 |

 |

 |
 |

 |

 |

## Before you begin

You must have loaded or initialized a pattern master file (*.pmfl) referencing the individual items.

## Procedure

-  To save a selected item:

In the Pattern Explorer right-click the item and select Save.

This saves it with any modifications you may have applied.

-  To load a selected item:

In the Pattern Explorer right-click a pattern and select Load.

This forces the selected item to be loaded from the file system and replace any modifications you may have applied to the current item.
