# Editing a port

## About this task

Whatever action you selected:

- to define a new port from scratch,
- to make changes to an existing port,

the way to edit the port is always the same.

## Before you begin

Make sure that a port has been created.

## Procedure

-  Open the setup editor of the port you want to edit. If the port is a new one, there are no pins in the Port Members area.  ![New port example](<../../../../raw/97847.png>)
-  To add pins to the port, select one or more pins (press Ctrl and then click) in the Available Pin List and click Add>.

To add all the pins to the port, click Add All >>.

-  To delete pins from the port, select one or more pins in the Port Members area and click < Remove.

To delete all the pins from the port, click << Remove All.

 Note To quickly find the pins you are interested in, you can use [Filter line](<02.08.04.18.03.13_Filter_line.md>).
-  Repeat the steps 2 to 3 until your group is set up completely.
-  Apply the data and save the pin configuration file.
