# Flags page

On this page, you can set the system flags and testflow flags.

  ![Flags page](<../../../../raw/110705.png>) Note You can also access the system flags and testflow flags through the Operation Control window (via Production Settings), when running SmarTest in engineering mode (see [Activating event data logging](<../02.10_Data_Logging/02.10.01.01.04_Activating_event_data_logging.md>)). To actually make changes to the flags, all windows must be set to Testflow settings mode (not to Production settings mode) from the Operation Control window.
