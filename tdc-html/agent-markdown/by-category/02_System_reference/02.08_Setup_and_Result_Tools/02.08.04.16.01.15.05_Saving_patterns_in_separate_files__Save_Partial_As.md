# Saving patterns in separate files (Save Partial As)

To simplify pattern management you can split up pattern files and save one or more patterns in a separate pattern file.

## About this task

This procedure also allows to reduce the number of patterns and minimize loading time when you hand over the test program to production. You can use Save Partial As for example, to save only those patterns of a large pattern master file, which are associated with a specific test suite.

## Before you begin

Have both the Test Program Explorer and the Pattern Explorer open.

## Procedure

-  In the Pattern Explorer highlight the patterns you want to save.
-  In the Test Program Explorer highlight the pattern item, right-click and select Save Partial As.

The Save Partial Patterns dialog opens. The patterns you selected in Pattern Explorer are preselected.

  ![Save Partial Patterns](<../../../../raw/129167.png>)
-  If required, select additional patterns to be saved.
-  Under Pattern file name, either accept the suggested file name (..._partial), select an existing pattern file, or type a new file name.
-  If you want any referenced subroutines and calls automatically included, select that option.
-  When done, click OK.

## Results

You have saved the selected patterns in a separate pattern file.
