# Executing shmoo tests with the Shmoo Tool

There are three manners for you to execute a shmoo test with the Shmoo Tool.

## Before you begin

- [Set up a shmoo test in the Shmoo Tool](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>).

Or,

- [Transfer a shmoo test from a shmoo test suite into the Shmoo Tool](<02.08.04.25.03.10.03_Transferring_test_suites_to_the_Shmoo_Tool.md>).

## Procedures

### Manner A

From the toolbar of SmarTest, click ![execution button](<../../../../raw/136388.png>) (the Run Shmoo shortcut).

For the other shortcuts in the toolbar, see [Commands in the menu bar and their shortcuts in the toolbar](<02.08.04.25.04.02_Commands_in_the_menu_bar_and_the_shortcuts_in_the_toolbar.md>).

### Manner B

From the menu bar of SmarTest, select Shmoo > Run Shmoo.

For the other commands in the Shmoo menu, see [Commands in the menu bar and their shortcuts in the toolbar](<02.08.04.25.04.02_Commands_in_the_menu_bar_and_the_shortcuts_in_the_toolbar.md>).

### Manner C

On the shmoo page related to the shmoo test, right-click anywhere on the shmoo page and select Run.

For the other commands, see [Commands in the shmoo editor of the Shmoo Tool](<02.08.04.25.04.03_Commands_in_the_shmoo_editor_of_the_Shmoo_Tool.md>).

## Results

A shmoo plot is displayed on the related shmoo page in the shmoo editor.

Different cells on the shmoo plot may have different colors. For details, see [Colors on shmoo plots](<02.08.04.25.03.04.01_Colors_in_shmoo_plots.md>).

## What to do next

View the shmoo plot with zooming, changing result pins, [Test modes](<02.08.04.25.03.02.02_Test_modes.md>) and sites, or viewing a selected area of the plot. For details, see [Viewing shmoo plots with the Shmoo Tool](<02.08.04.25.03.04_Viewing_shmoo_plots_with_the_Shmoo_Tool.md>).
