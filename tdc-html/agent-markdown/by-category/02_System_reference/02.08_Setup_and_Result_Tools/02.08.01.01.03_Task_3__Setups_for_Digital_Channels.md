# Task 3: Setups for Digital Channels

- Set up levels using the [Level setup tool](<02.08.04.14_Level_setup_tool.md>):

  - Set up power supply voltages to DUT.
  - Set up digital drive signals and receiving conditions for digital pins.

- Set up timing using the [Timing Setup Tool](<02.08.04.34_Timing_Setup_Tool.md>):

Define digital waveform shapes for digital pins.

- Set up the vectors for the digital pins using the [Pattern Tools](<02.08.04.16_Pattern_Tools.md>).
