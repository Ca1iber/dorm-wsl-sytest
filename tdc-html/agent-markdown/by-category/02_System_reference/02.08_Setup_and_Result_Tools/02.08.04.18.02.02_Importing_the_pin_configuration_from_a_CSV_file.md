# Importing the pin configuration from a CSV file

The CSV (Comma-Separated Values) file format is a file type storing tabular data. The CSV files are common on all computer platforms. The Pin Configuration tool lets you import the pin configuration from a CSV file easily. In this way, you can create your pin configuration based on other device. The CSV file also helps to exchange the formats of the pin configuration files between different tester platforms.

## Before you begin

Make sure that the CSV file exists and you have loaded a new empty pin configuration file.

## Procedure

-  In the Test Program Explorer, right-click the pin item and select Import.

The Import 93000 Setup window opens.

-  In this window, click Browse.

The Enter or select file to import window opens.

-  Select the file you want to import and click OK.

You return to the Import 93000 Setup window.

-  In the Setups list, select the items you want to import and then click Finish.  ![Select imported items](<../../../../raw/108682.png>)

## Results

The pin configuration is imported from a CSV file.

## What to do next

Edit the pin configuration.
