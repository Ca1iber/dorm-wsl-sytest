# Digital Capture Modes

There are two capture modes.

## Sequential Mode

Capturing will be carried out at every vector of a label for Digital Capture.

Sequential Mode capturing can be combined with three resolution modes:

- Standard Mode: One capture sample will be taken per test system period.
- Double Mode: Two capture samples will be taken per test system period.
- Statemap: The number of samples to be taken per test system period are read directly from the X-mode definitions in the STATEMAP section of the primary wavetable.

## Selective Mode

Capturing will only be carried out at vectors with device cycles containing designated capture edge actions.

Selective Mode capturing can be used on all edges, i.e. the number of capture samples taken per test system period is flexible between one and eight. You can selectively capture if the channel is configured to work in STD (standard) mode as well as in FAST mode.

Selective Mode capturing can be combined with two resolution modes:

- Standard Mode: The number of capture samples taken per test system period is flexible between one and eight.
- Statemap: The number of samples to be taken per test system period are read directly from the X-mode definitions in the STATEMAP section of the pattern's wavetable.

## Defining the capture mode

The capture mode is determined by the selected resolution mode and the primary wavetable of the capture pin. If you select double mode (Double in the Capture Setup) window, capturing will be executed sequentially. If you select one of the other two resolution modes, it depends on the primary wavetable which capture mode will be used. If the wavetable contains a C or D action, capturing will be carried out selectively; if it contains no such action, sequential capturing will be employed.
