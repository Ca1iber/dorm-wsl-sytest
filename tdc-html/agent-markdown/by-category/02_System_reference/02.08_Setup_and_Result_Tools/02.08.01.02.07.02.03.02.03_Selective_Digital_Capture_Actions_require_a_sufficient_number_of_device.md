# Selective Digital Capture Actions require a sufficient number of device cycle sets

For every wavetable that contains selective digital capture actions (C and D actions), a device cycle set must be available in the system. The total number of available device cycle sets must not be smaller than

number_of_wavetables_containing_selective_capture_actions+ 1.

When loading a timing that requires more than the currently defined device cycle sets, the following error message will be displayed:

ERROR: couldn't allocate a new Device Cycle Set: no more available.

Increase their number from the 'Change Device' screen, or use DSCP command

You can increase the number of device cycle sets by selecting menu 93000 > Device > Change Device. The [Change Device wizard](<02.08.04.03_Change_Device_wizard.md>) opens. Click button Next for adjusting the Device cycles in the [Technology file](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.01.02_Technology_file_for_a_device.md>) or adjust this number with the [DSCP](<../02.06_Command_Reference/02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) firmware command.
