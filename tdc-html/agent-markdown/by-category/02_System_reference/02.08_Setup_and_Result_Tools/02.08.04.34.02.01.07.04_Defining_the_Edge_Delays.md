# Defining the Edge Delays

If you want to define for timing set 1 of waveform set 1 the edge delays that result from setting the variable f shown in [Defining the global period](<../02.06_Command_Reference/02.06.06.01.04.01.01_Defining_the_global_period.md>) to 100, issue the following command:

ETDS 1,1,,"d1:2 d2:4 d3:8 d4:6 d5:10",(IN1)

## Functional changes

- Introduced before SmarTest 6.3.2
