# SPECSET

Each spec set starts with a header, identified by the SPECSET keyword, and contains zero or more spec definition.

 ![specset](<../../../../raw/22013.png>)

 |

specset_number

 |

An integer in the range 1 to 99. This must be unique within the equation set, but does not have to be unique between equation sets. This means that both equation set 1 and equation set 2 may contain a spec set numbered 4. In this instance, 2 spec sets will be created. Spec set numbers do not have to be consecutive, and gaps in the sequence are permitted. Thus it is perfectly legal do define spec sets 1,9,3 and then 4 for example.

 |
 |

specset_description

 |

A string of up to 60 characters. If it is enclosed in double quotes ("..."), everything inside the quotes is taken as the description - even spaces. If the description is not enclosed in double quotes, all characters up to but not including the first space is taken as the description.

   |
