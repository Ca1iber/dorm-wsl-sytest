# The Physical Waveform Table

For every test system channel the hardware contains a physical waveform table. The signals that the test system sends to, or receives from the DUT are referenced in the Vector Memory by an index to the physical waveform table. This index has a range of 0 to 255, and is called the physical waveform index. Along with the index the table contains a waveform without data. This waveform determines the state of the signal that will be used to test the device. The waveform and the index are called a physical waveform.

The index is read by the sequencer during test. This enables only the selected waveform states to take part in the device test. The physical waveform index is discussed in [How the Vector Memory Stores Vectors](<02.08.04.16.04.06_How_Vectors_are_Stored_in_Sequencer_Memory.md>).

As you create new waveforms you use up system resources. The Timing Setup window informs you of the number of physical waveforms that you still can create. This number is displayed in the free column in the device cycle edit area under Wf, see [Relationship between waveform sets and timing sets](<02.08.04.34.03.01_Relationship_between_waveform_sets_and_timing_sets.md>). The free column is available only in the double size display mode. Thus if the free column displays Wf 5, then you have defined eleven of the available 16 physical waveforms for a particular pin. The free column is discussed later in the chapter in [Device Cycles](<02.08.04.34.01.03_Device_Cycles.md>) and [Setting up the Table Format](<02.08.04.34.06.09_Setting_up_the_Table_Format.md>).

You can save system resources by actively reusing physical waveforms.
