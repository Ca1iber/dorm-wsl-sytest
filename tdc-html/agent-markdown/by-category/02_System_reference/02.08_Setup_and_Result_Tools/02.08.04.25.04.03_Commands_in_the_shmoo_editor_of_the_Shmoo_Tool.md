# Commands in the shmoo editor of the Shmoo Tool

In the Shmoo Tool, after you right-click a shmoo plot, which is displayed on a shmoo page of the shmoo editor (see [The interface of the Shmoo Tool](<02.08.04.25.02_The_interface_of_the_Shmoo_Tool.md>)), you will see these commands:

- Run, Run Fast, Abort Run: The same as the [Run Shmoo, Run Fast Shmoo, and Abort Run](<02.08.04.25.04.02_Commands_in_the_menu_bar_and_the_shortcuts_in_the_toolbar.md>) commands and their shortcuts ![execution button](<../../../../raw/136388.png>), ![fast execution button in the Shmoo Tool](<../../../../raw/136389.png>), ![aborting execution buttion in the Shmoo Tool](<../../../../raw/136390.png>).
- Apply to HW and Restore: Available only when you select one cell on a shmoo plot.

  - Apply to HW: The primary settings of the selected cell will replace the current hardware settings in the Primaries group in the related Properties view.
  - Restore: To return to the original settings in the Primaries group.

- Zoom In, Zoom Out: The same as the [ZoomIn and ZoomOut](<02.08.04.25.04.02_Commands_in_the_menu_bar_and_the_shortcuts_in_the_toolbar.md>) commands and their shortcuts ![Zoom in icon](<../../../../raw/136469.png>), ![Zoom out button](<../../../../raw/136470.png>).
- Full Size: To display the whole shmoo plot from (x-start, y-start) to (x-end, y-end) on the shmoo page.

The full size plot is the default plot after an execution.

- Magnify: To increase the resolution of the selected area of a shmoo plot and replace the shmoo plot with this area. For details, refer to the descriptions about "Magnify" in [Viewing and magnifying a selected area of a shmoo plot](<02.08.04.25.03.04.03_Viewing_and_magnifying_a_selected_area_of_a_shmoo_plot.md>).
- Test Modes: If you have selected multiple [Test modes](<02.08.04.25.03.02.02_Test_modes.md>) during [settings](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>), this command lets you view different types of results on the shmoo plot.

For details, see [Viewing different results on a shmoo plot](<02.08.04.25.03.04.04_Viewing_different_types_of_results_on_a_shmoo_plot.md>).

- Result Pin: Lets you [view the shmoo plots of different result pins](<02.08.04.25.03.04.06_Viewing_the_shmoo_plots_of_different_pins.md>).

## Functional changes

- Introduced in SmarTest 7.2.0
- SmarTest 7.2.1: Adds a new command: Magnify.
