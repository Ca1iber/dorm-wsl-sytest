# Syntax of the Pin Margin Test Report

#### Subtopics

- [Pin Margin Test Report - Titles](<02.08.04.19.02.03.01.01_Pin_Margin_Test_Report_-_Titles.md>)

The pin margin test report is in ASCII format, thus allowing for easy documentation and saving to file.

Symbols used in the syntax are explained in the table below.

The whole test report consists of report lines that are separated by newlines.

<reportline> = <title> | <pin list> | <pin result> | <comment line>

<title> contains global information about the pin results.

<pin list> is used if parallel evaluation of pin resources is specified, more than one pin/group name is selected and the following <pin result> entry contains "@" instead of a single pin name.

The order of the test results is

- all selected sets per resource type
- all selected pins/groups per set
- all selected resources per pin/groupNote If a resource is selected but not used in the desired testsuite, no measurements will be performed on those resources.

```
<pin list> = "#" <sep> "PINS" <sep> "@" | <pin/group> { <sep> <pin/group> }
<pin result> = [ [ <sep> ] <dps volts> "V" <sep> ] <pin/group> | "@" <sep>
    "per" | "d1" | "d2" | "d3" | "d4" | "d5" | "d6" | "d7" | "d8"
    |"r1" | "r2" | "r3" | "r4" | "r5" | "r6" | "vih" | "vil"
    | "voh" | "vol" | "vt" | "iol" | "ioh" | "vcl" | "vch" <sep>
    < 50 characters of "V" | "*" | " . " | "-" >   <sep>
    <minimum value> | "----" <sep> <current value> <sep>
    <maximum value> | "----" <sep>
    <minimum cycle> | "----" <sep> <maximum cycle>|"----"
<sep> = <space|tab> { <space|tab> }
<pin/group> = <max. 16 characters except @ # " , tab space newline>
    <minimum value> | <current value> | <maximum value> |
    <from value>|<to value> = <float value> "V"|"ns" |"mA"
    <integer value> = <minimum cycle> | <maximum cycle>
```

In the pin results the 50 characters represent the 50 measurements steps.

*= passed

. = failed

V = current value

- = no test can be performed.

The minimum value gives the next pass/fail transition below the current value and the minimum cycle the corresponding first failing cycle. The maximum value gives the next pass/fail transition above the current value and maximum cycle the corresponding first failing cycle.

 Note The period is always modified for all pins simultaneously. This implies that "@" is used instead of a pin or group name.
