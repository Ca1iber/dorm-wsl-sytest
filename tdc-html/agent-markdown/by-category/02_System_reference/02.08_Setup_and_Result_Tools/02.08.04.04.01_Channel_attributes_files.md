# Channel attributes files

#### Subtopics

- [ACTCatr](<02.08.04.04.01.01_ACTCatr.md>)

The section describes the format of the channel attributes files.

The channel attributes file can have any name and reside in any directory.

 Note Advantest recommends to store channel attributes files in the ch_attributes subdirectory of the device: <device>/ch_attributes/<FileName>

The lines consist of a keyword followed by parameters, which depend on the type of the entry.

- Fixture delay entries in [ns] (use the [Fixture Delay Tool](<02.08.04.10_Fixture_Delay_Tool.md>) for editing):

FXDL<channel>,<delay>

- De-embedding entries (use the [DeEmbedding page of the Channel Attribute Editor](<02.08.04.04.02_De-Embedding_page_of_the_Channel_Attributes_Editor.md>) for editing):

FXDE<channel>,<"port">,<"tag">,<".cit file path">
