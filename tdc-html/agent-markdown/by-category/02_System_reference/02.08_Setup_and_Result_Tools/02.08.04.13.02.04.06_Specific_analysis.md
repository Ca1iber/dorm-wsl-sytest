# Specific analysis

The various views of the Integrated Result Tool let you analyze data logs in a great variety of ways.

This list briefly describes how to perform some common analytical tasks. For details, see the pages linked in the individual descriptions.

- Determining the test time

In the [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>), check the displayed times in the T$ and TS$ columns.

(For greater detail, you can also check the same information in a raw data or stream data view. See [Examining the underlying data of a summary](<02.08.04.13.02.04.01_Examining_the_underlying_data_of_a_summary.md>) for more information on displaying detail data for a summary.)

You can also check the T$ column in [wafer summary tabs](<02.08.04.13.03.02.02_Wafer_summary_tab.md>) or [device summary tabs](<02.08.04.13.03.02.03_Device_summary_tab.md>).

- Comparing test results for different sites

In the test summary tab, [group](<02.08.04.13.02.03.05_Separating_summary_results_by_wafer__site__or_pin.md>) the tests summaries by site. Select the sites you are interested in and [display them](<02.08.04.13.02.04.03_Displaying_test_results_in_analysis_views.md>) a suitable result graph, for example, [trend chart](<02.08.04.13.03.04.01_Trend_chart_view.md>) or [histogram chart](<02.08.04.13.03.04.02_Histogram_view.md>).

- Comparing test results from two data logs

[Open](<02.08.04.13.02.02.02_Opening_a_data_log_for_examination.md>) both logs.

To compare the results numerically, arrange the two [views](<02.08.04.13.03.02_Data_navigation_views.md>) so that you can compare the values you are interested in.

To compare the results graphically, [open](<02.08.04.13.02.04.03_Displaying_test_results_in_analysis_views.md>) the same kind of [graphs](<02.08.04.13.03.04_Analysis_views.md>) for the corresponding rows from the two logs and pin them to prevent unwanted automatic changes in the graphs when the selection changes. (See [Displaying test results as result graphs](<02.08.04.13.02.04.03_Displaying_test_results_in_analysis_views.md>) for more information on pinning.)

- Comparing two different transaction protocols

To compare two PCI Express transaction protocols, open the first protocol in the [Protocol Monitor view](<02.08.04.13.03.04.07_Protocol_Monitor_view.md>) and click that view's Create baseline toolbar button. Then open the second protocol. All cells that are different from the baseline are marked by ![Data log summary view_Search match icon](<../../../../raw/147832.png>) annotations in the left-hand margin and the cells themselves are highlighted.

You can configure the columns that are to be considered for the comparison by clicking the ![Analysis perspective_Protocol Monitor view, Search Configuration button (50%)](<../../../../raw/147017.png>) button beside the search field in the Protocol Monitor view. You can switch the comparison mode on and off by clicking the Toggle Compare Mode toolbar button.

- Viewing basic statistical information

In tables, you can display this information numerically by displaying - depending on the desired information - the Min, Max, Mean, Sdev, Cp, Cpk, P%, F%, or Dev% columns.

To see the mean, two-sigma, or three-sigma points of a test graphically, [display the test](<02.08.04.13.02.04.03_Displaying_test_results_in_analysis_views.md>) in a [histogram](<02.08.04.13.03.04.02_Histogram_view.md>) and enable the corresponding lines in the [chart properties](<02.08.04.13.03.04.02.01_Histogram_properties.md>) or the chart's shortcut menu.

To see the statistical distribution of values within a test, [display it](<02.08.04.13.02.04.03_Displaying_test_results_in_analysis_views.md>) as a [box chart](<02.08.04.13.03.04.04_Box_chart_view.md>).

- Finding outlier test results

To find outlier results graphically, [display the test](<02.08.04.13.02.04.03_Displaying_test_results_in_analysis_views.md>) in a [box chart](<02.08.04.13.03.04.04_Box_chart_view.md>) and set the whiskers in the [chart properties](<02.08.04.13.03.04.04.01_Box_chart_properties.md>) so that the outliers are outside the whisker range.

For example, when you consider values in the top 10% and bottom 15% to be outliers, set the whiskers to 90% and 15%.

The outliers are displayed as red dots in the chart.

- Displaying the correlation of two independent test results

To see how values measured in different test correlate with each other, [display the two tests](<02.08.04.13.02.04.03_Displaying_test_results_in_analysis_views.md>) in a [scatter chart](<02.08.04.13.03.04.05_Scatter_chart_view.md>).
