# Using Digital Capture

Many test applications in the field of V93000 testing require the test system to be capable of acquiring large amounts of digital output data of a device at a high data rate, and storing this data for later analysis and data processing. This is called digital capturing.

Typical applications for digital capturing are

- audio, video, and communications devices, where the n-bit output codes of Analog-to-Digital-Converters (ADC), or serial digital data streams must be captured.
- devices with Built-in-Self-Test (BIST), where the digital result output of the BIST must be captured.

The Digital Capture feature allows you to perform digital capturing with every normal digital pin. This provides maximum flexibility for your DUT board design, and at the same time an unmatched ease of use, as the setups for Digital Capture can be done in virtually the same way as for an ordinary functional test.
