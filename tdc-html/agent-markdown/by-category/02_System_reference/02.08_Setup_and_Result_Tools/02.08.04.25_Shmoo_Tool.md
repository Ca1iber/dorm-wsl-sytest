# Shmoo Tool

#### Subtopics

- [Opening the Shmoo Tool](<02.08.04.25.01_Opening_the_Shmoo_Tool.md>)
- [The interface of the Shmoo Tool](<02.08.04.25.02_The_interface_of_the_Shmoo_Tool.md>)
- [Using Shmoo Tool](<02.08.04.25.03_Using_Shmoo_Tool.md>)
- [Appendix: Commands in the Shmoo Tool](<02.08.04.25.04_Appendix__Commands_in_the_Shmoo_Tool.md>)

The Shmoo Tool helps you to create shmoo tests and view shmoo plots.

You use the Shmoo Tool to:

- Perform shmoo over a functional test, shmoo over an existing test suite or multiple test suites, fail bit count shmoo for MTP, and customized shmoo tests.

When shmooing a test suite, you can [view value results on the shmoo plot](<02.08.04.25.03.04.05_Viewing_the_test_results_of_a_test_suite_on_the_shmoo_plot.md>).

For details, see [set up](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>), [execute](<02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>) and [view](<02.08.04.25.03.04_Viewing_shmoo_plots_with_the_Shmoo_Tool.md>) shmoo tests.

- [Peform multisite shmoo tests](<02.08.04.25.03.04.07_Viewing_the_shmoo_plots_of_different_sites.md>).
- [Overlay shmoo plots](<02.08.04.25.03.09_Overlaying_shmoo_tests_in_the_Shmoo_Tool.md>).
- [Interact with the Testflow Tool](<02.08.04.25.03.10_Interaction_with_testflow.md>) to:

  - Display the shmoo plot of a shmoo test suite.
  - Transfer a shmoo setup between the Shmoo Tool and a test suite.
  - [Log shmoo data into the report window and save shmoo plots as PNG or ASCII files](<02.08.04.25.03.07_Saving_shmoo_plots_to_png_or_ASCII_files.md>): To do this, you must transfer the shmoo tests from the Shmoo Tool to a testflow first.

- [Interact with the Integrated Result Tool](<02.08.04.25.03.11_Interaction_with_the_Integrated_Result_Tool.md>) to display shmoo plots in the Integrated Result Tool: To do this, you must transfer the shmoo tests from the Shmoo Tool to a testflow first.
