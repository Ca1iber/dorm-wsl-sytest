# Task 2: Pin Configuration Setup

Define the relationship between resource pins and DUT board using the [Pin configuration tool](<02.08.04.18_Pin_configuration_tool.md>).

- Define the connections between device pins to tester resources ([Digital Pins editor](<02.08.04.18.03.01.02_Digital_Pins_editor.md>)).

  - Defining number of sites
  - Allocating channels to the device pins
  - Specifying of the DPS operating range

- Define [pin groups](<02.08.04.18.02.08_Working_with_pin_groups.md>), creating utility lines, and [utility purposes](<02.08.04.18.02.10.01_Creating_a_utility_purpose.md>) (optional).
- [Apply pin configuration data](<02.08.04.18.02.05_Applying_pin_configuration_data.md>)
