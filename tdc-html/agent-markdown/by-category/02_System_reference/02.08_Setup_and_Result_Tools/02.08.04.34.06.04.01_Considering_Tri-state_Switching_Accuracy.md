# Considering Tri-state Switching Accuracy

Note that an edge used to switch a pin into tri-state is subject to the tri-state accuracy, not the system accuracy. The tri-state accuracy is a function of the DUT loading.

If you need to make accurate timing tests or measurements on pins that switch into tri-state (for instance a microprocessor data bus), use the Surround-by-complement format to switch from tri-state to the complement of the required signal first. Then you get system accuracy when switching from the complement to the signal itself. This applies also when going back to tri-state, to achieve system accuracy you should switch first to the complement of the signal and then to tri-state.
