# Control File Syntax

#### Subtopics

- [Mutiport Timing Setup](<02.08.04.19.03.01.01_Mutiport_Timing_Setup.md>)
- [Testsuite Selection](<02.08.04.19.03.01.02_Testsuite_Selection.md>)
- [Resource Selection](<02.08.04.19.03.01.03_Resource_Selection.md>)
- [Report Add-ons](<02.08.04.19.03.01.04_Report_Add-ons.md>)

The control file can be used instead of the pin margin user interface to control your pin margin measurements. The purpose of this file is to make pin margin measurements repeatable and to provide an interface that can be used from automated test programs.

The control file consists of one or more tests, which are executed sequentially. Each of these tests does the following:

- Loads any datasets if necessary, selects resources for the measurements, and sets up the margin restraints.
- RUNs the test.

The control file lines can be:

```
<control file line> = <comment line> | <report comment line> | <command line>
<comment line> = "#" <any sequence of characters except newline>
<report comment line> = "##" <any sequence of characters except newline>
<command line> = <command> [<sep> <parameters>]
<command> = "RUN" | "PINS" | "ECHO" | "DATASET" | "TESTERSTATE" | "TOP"
    | "TIMINGSET |"DPSSET" | "RANGE" | "SITE" | "LABEL" | "TESTFUNC"
    | "PRIMARY" | "LEVELSET" | "METHOD" | "RESOURCES" | "DPS" | "STEPMODE"
    | "DEFAULT"
```

The report comment line is a user comment, that occurs also in the report at the same place.
