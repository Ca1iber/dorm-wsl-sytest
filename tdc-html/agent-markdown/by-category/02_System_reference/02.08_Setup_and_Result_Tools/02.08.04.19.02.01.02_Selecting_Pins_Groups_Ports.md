# Selecting Pins/Groups/Ports

The pin margin test can be done on pins, groups of pins, or ports. Select all the appropriate pins, groups or ports that will be included in your test.

- Select pins, groups, or ports by clicking the appropriate column in the Ports, Groups, and Pins window on the right side of the display.

If you want to select Dps pins only, click the Use DPS Pins check box that is located on the top-right of the Selections window. If you select DPS pins the group and port columns will be greyed-out, indicating that they are not available.

If a group is selected, pins associated with that group are also selected. If a group is cleared, pins associated with that group are also cleared.

If a port is selected, groups and pins associated with that port are also selected. If a port is cleared, groups and pins associated with that port are also cleared.

- If you have selected Pins, Groups, or Ports you can include the DPS pins, by selecting the With DPS check box.
- If you have selected Pins or Groups you can include the DPS pins, by activating the with DPS button.Note Varying the Dps lets you observe the influence of the power supply on the margins. This is especially interesting if the margins are already very tight when using the nominal power supply voltage.
- If you have selected the With DPS check box (in step 3) a window similar to that of the figure below pops up. ![Specifying DPS Pins](<../../../../raw/24268.png>)

This figure shows the default settings. For the default settings (steps=2, range=5%) a margin test is performed for each selected timing and level resource with the following DPS values:

  - 0.95*Vcc
  - Vcc
  - 1.05*Vcc
  - Select the DPS pins.
  - Select the number of steps to be taken over the chosen range.Note Selecting several DPS pins to be varied in 2, 4 or even 10 steps will drastically increase your test time.
  - Select the range.

After the pins, groups or ports are selected, the resource (settings in the sections of Timing, Level and DPS Margin Option) specified in the primary sets are checked automatically.
