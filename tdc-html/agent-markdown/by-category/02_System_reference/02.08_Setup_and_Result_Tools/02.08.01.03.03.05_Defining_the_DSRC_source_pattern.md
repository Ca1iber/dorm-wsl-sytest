# Defining the DSRC source pattern

To define the DSRC source pattern (label):

- In the Pattern Explorer, right-click and select New. The New Pattern window opens.
- Specify the following:

 |

Pattern Name:

 |

dsm_src

 |
 |

Pattern Type:

 |

DSRC

 |
 |

Port:

 |

dataport

 |
 |

Memory Type

 |

SM (Sequencer Memory)

 |
 |

Wavetable:

 |

dsm_wavetable

 |
- Click Finish. The source pattern is created and listed in the Pattern Explorer. Note The newly created source pattern (type: DSRC) is empty and the Pattern Editor lists no vectors. You cannot append, insert, or delete vectors of DSRC patterns directly in the Pattern Editor. You must use the Test Method API or the Signal Analyzer Tool to download or upload data. After downloading, the Pattern Editor only allows you to change the individual device cycle for a DSRC pattern. For details see [Viewing and Editing Content in DSRC pattern](<02.08.01.03.03.07_Viewing_and_editing_content_in_the_DSRC_source_pattern.md>).
