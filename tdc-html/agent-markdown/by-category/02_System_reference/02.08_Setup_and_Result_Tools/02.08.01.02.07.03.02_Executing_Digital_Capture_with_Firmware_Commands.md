# Executing Digital Capture with Firmware Commands

 Note For a detailed description of the DGCT? command and its usage, see the manual [Command Reference](<../02.06_Command_Reference/02.06_Command_Reference.md>).

The firmware command DGCT? (DiGital Capture Test) executes a Digital Capture Test according to the current primary settings defined. The pattern for digital capture gets executed and the results at the device output get captured and stored in the memory.

DGCT? returns a pass or fail result (DGCT P or DGCT F).

The result is determined in the same way as for a functional test (FTST?). A fail, therefore, does not mean that the capturing failed, but only that the received (captured) and expected data did not match. For Digital Capture this often is of no significance. See [Setting up the Timing](<02.08.01.02.07.02.03_Setting_up_the_Timing.md>) for more information about pass/fail results of Digital Capture, and how to handle them.
