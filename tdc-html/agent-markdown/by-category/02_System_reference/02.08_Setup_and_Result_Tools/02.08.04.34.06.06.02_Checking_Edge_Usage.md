# Checking Edge Usage

The i/o column (see the first figure in [Selecting Edges](<02.08.04.34.06.06.03_Selecting_Edges.md>)) tells you what type of pins have been set up: an i for input, an o for output. Note that IO pins are split into their i and o components and displayed in separate rows.

To scroll through the unused edges repeatedly click the L-shaped area containing an i, or an o. The unused edge box displays the numbers of the unused edges. An i channel will scroll through 8 drive edges if they are unused, and an o channel will scroll through 8 receive edges if they are unused.
