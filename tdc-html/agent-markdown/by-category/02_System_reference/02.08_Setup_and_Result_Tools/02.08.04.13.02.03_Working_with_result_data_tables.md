#### Subtopics

- [Sorting tables](<02.08.04.13.02.03.01_Sorting_tables.md>)

[Open data logs](<02.08.04.13.02.02.02_Opening_a_data_log_for_examination.md>) can be worked with in various ways to adjust their appearance and exclude data from evaluation.

These procedures are described in detail in:

- [Sorting tables](<02.08.04.13.02.03.01_Sorting_tables.md>)
- [Filtering test results](<02.08.04.13.02.03.02_Filtering_test_result_data.md>)
- [Highlighting specific data](<02.08.04.13.02.03.03_Highlighting_specific_data.md>)
- [Separating summary results by wafer, site, or pin](<02.08.04.13.02.03.05_Separating_summary_results_by_wafer__site__or_pin.md>)
- [Setting table display options](<02.08.04.13.02.03.06_Setting_table_display_options.md>)

Note that none of these procedures affect the result charts. The exception is separating summary results, which can change titles and legends of charts.
