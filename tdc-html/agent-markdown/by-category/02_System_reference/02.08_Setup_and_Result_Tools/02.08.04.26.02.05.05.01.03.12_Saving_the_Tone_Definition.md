# Saving the Tone Definition

Clicking the Save Setup button at the bottom of the dialog window lets you save the complete tone definition for the calculated waveform, including the phase shifts that were determined by the selected Phase Algorithm.

A saved tone definition can be re-loaded at a later time. See [Loading a Tone Definition](<02.08.04.26.02.05.05.01.03.07_Loading_a_Tone_Definition.md>).
