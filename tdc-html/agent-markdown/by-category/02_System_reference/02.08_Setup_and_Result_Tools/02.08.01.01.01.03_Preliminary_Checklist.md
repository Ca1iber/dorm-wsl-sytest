# Preliminary Checklist

You can now proceed with setting up the test and to help you accomplish the task smoothly, you need first to check the following:

- You know how to start the V93000 test system and run the SmarTest software on the system controller.
- You are familiar with the SmarTest software, its tools (see list below), and the various windows and menus.

  - [Create a new](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.10.03.01_Creating_a_new_device.md>) or [select an existing device](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.08.02.01.02_Changing_the_device_in_the_Project_Explorer_view.md>)
  - [Pin configuration tool](<02.08.04.18_Pin_configuration_tool.md>)
  - [Level setup tool](<02.08.04.14_Level_setup_tool.md>)
  - [Timing Setup Tool](<02.08.04.34_Timing_Setup_Tool.md>)
  - [Pattern Tools](<02.08.04.16_Pattern_Tools.md>)
  - [Testflow Tool](<02.08.04.32_Testflow_Tool.md>)

You have all the necessary and detailed information regarding the DUT specifications and the required tests such that you are ready to start the test development.
