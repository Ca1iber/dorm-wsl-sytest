# Defining edge delays for a pattern鈥慴ased SmartLoop test

The edges for a pattern鈥慴ased SmartLoop鈩?test are distributed equidistantly within the tester cycle. This holds for both input and output pins. But you can define a start delay for the first (drive or receive) edge. You must specify the number of edges per cycle with the period_div keyword. This number must correspond to the x-mode in the wavetable.

## Combining pattern鈥慴ased SmartLoop鈩?with transition tracking

You can also combine a pattern鈥慴ased SmartLoop鈩?test with transition tracking on the output pins for both x4-mode and x6-mode. In both cases, you must specify the respective TTMODE statement instead of period_div in the timing set of the output pins. With TTMODE X6, the input pin must also be set to x-mode 6. But with x4-mode, a more elaborate setup is required:

- The input pin must be set to `period_div=8`,
- The two pins must be put into different ports.
- The period of the input port must be twice as long as the period of the output port.

For details of setting up the transition tracking, see [Combining transition tracking with a PRBS or pattern鈥慴ased SmartLoop test](<../02.06_Command_Reference/02.06.15.02.01_Combining_transition_tracking_with_a_PRBS_or_pattern__ased_SmartLoop_tes.md>).

## Examples

### Example 1

```
EQNSET 3 "lpbk"
. . .
TIMINGSET 1 "eqs 3 ts 1"
PINS IN1
period_div = 6
d1 = 0.5
. . .
PINS OUT1
TTMODE X6
r1 = 1.0
. . .
```

This example can be combined with the first example of [Defining the wavetable for a pattern鈥慴ased SmartLoop test](<../02.06_Command_Reference/02.06.06.01.03.02.03_Defining_the_wavetable_for_a_pattern__ased_SmartLoop_test.md>) in one timing specification.

### Example 2

```
EQNSET 1 "lpbk1"

DEFINES in

TIMINGSET 1 "eqs 1 ts 1"
period = 8
PINS IN1
period_div = 8
d1 = 0.5
. . .

EQNSET 2 "lpbk2"

DEFINES out

TIMINGSET 1 "eqs 2 ts 1"
period = 4

PINS OUT1
TTMODE X4
r1 = 1.0
. . .
```

This example can be combined with the second example of [Defining the wavetable for a pattern鈥慴ased SmartLoop test](<../02.06_Command_Reference/02.06.06.01.03.02.03_Defining_the_wavetable_for_a_pattern__ased_SmartLoop_test.md>) in one timing specification. Note that the two pins are associated with different ports (indicated by the DEFINES statements), and that the period length of pin `IN1` is twice the length of `OUT1`.
