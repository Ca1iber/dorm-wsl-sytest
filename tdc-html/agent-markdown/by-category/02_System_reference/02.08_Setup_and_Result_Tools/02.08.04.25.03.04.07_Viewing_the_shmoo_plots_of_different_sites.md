# Viewing the shmoo plots of different sites

In the Shmoo Tool, to view the shmoo plot of another site, use the [Site Control Window](<02.08.04.27_Site_Control_Window.md>) to change the site.

## About this task

The shmoo test for a multisite testflow is a multisite shmoo test as well. After execution, you can view the shmoo plots of different sites.

## Before you begin

- Make sure the loaded testflow is multisite.
- [Set up a shmoo test in the Shmoo Tool](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>), or set up a shmoo test suite in the testflow.

## Procedure

-  To view the shmoo plot of each site, in the menu bar of SmarTest, select 93000 > System > Site Control.

The [Site Control Window](<02.08.04.27_Site_Control_Window.md>) opens.

-  In the Site Control window, enable and active all sites, and focus on your desired site (you only can focus on one site). For Details, see [Site Control Window](<02.08.04.27_Site_Control_Window.md>).
-  If you have created a shmoo test suite in the testflow, [transfer the shmoo test suite to the Shmoo Tool](<02.08.04.25.03.10.03_Transferring_test_suites_to_the_Shmoo_Tool.md>).
-  [Execute the shmoo test with the Shmoo Tool](<02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>).

The shmoo plot of the current site is displayed in the Shmoo Tool. The corresponding site number is displayed in the plot title.

-  To view the shmoo plot of another site, change the focused site in the Site Control Window.

The shmoo plot of the new site replaces the previous shmoo plot in the Shmoo Tool. The new site number replaces the previous site number in the plot title.
