# Unloading a protocol

## About this task

This task describes how to unload a protocol from the test program explorer.

## Procedure

-  Select the protocol to unload from the test program explorer.
-  Right-click that protocol.
-  Select Unload.

## Results

The protocol you chosen has been unloaded.
