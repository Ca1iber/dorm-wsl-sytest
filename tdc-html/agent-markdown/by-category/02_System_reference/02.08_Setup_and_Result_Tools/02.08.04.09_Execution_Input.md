# Execution Input

#### Subtopics

- [Selecting an Execution Input](<02.08.04.09.01_Selecting_an_Execution_Input.md>)

The Execution Input is the user-definable interface to data coming from the production process. This data can be, for example, ID's or other numbers that are only available at run-time.

 Note To use a library generated on 32-bit system for a 64-bit system or vice versa, you need recompile the source code to generate the library for the new system.
