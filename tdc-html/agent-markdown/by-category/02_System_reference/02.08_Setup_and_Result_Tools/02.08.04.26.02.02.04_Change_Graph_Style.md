# Change Graph Style

The Waveform Graphs Tool (WGT) allows you to select from normal or bar graph styles. These styles are selectable via the [Format Dialog Box](<02.08.04.26.02.05.04.01_Format_Dialog_Box.md>) or the [Data Display API](<../02.07_Test_Method_Reference/02.07.04.01.22_Data_Display_API.md>).
