# Searching for test suites, bins and variables

This topic describes finding each individual test suites, test suite groups, bins, or variables in the testflow sequence.

## About this task

If you want to search on some pages of the Flow Data Editor, you can enter the string in the Find/Replace window. This window is opened by pressing Ctrl + F.

## Before you begin

The testflow must have been loaded.

## Procedure

-  Switch to the Flow Sequence Editor.
-  In the SmarTest Work Center, choose one of the commands from the Navigate > Go To submenu - Test Suite, Bin, Group, or Variable, depending on what you are looking for.

The corresponding window opens. The figure below shows the window opened by choosing Navigate > Go to > Test Suite. This window shows all the test suites in the testflow.

  ![Go to a test suite window](<../../../../raw/111417.png>)
-  In this window:

  -  Select the element you are looking for from the list. You can also type the element name as filter text to narrow your search.
  -  Click OK.

## Results

The found element is highlighted in the activated editor (Flow Sequencer Editor or Flow Data Editor).

## Functional changes

- Introduced before SmarTest 6.3.2
