The protocol editor is the graphical user interface used to set up and edit protocols as well es protocol specific levels, timing and wavetable.

It opens with the Protocol Definition tab per default.

## Details area

The details area (right side) will show different sections with different content related to the selected element.

Depending on the currently selected element of the protocol structure the detail area will show

- [Protocol details](<02.08.04.22.01_Protocol_details.md>)
- [Transaction details](<02.08.04.22.02_Transaction_details.md>)
- [Pin role details](<02.08.04.22.03_Pin_role_details.md>)
- [Field details](<02.08.04.22.04_Field_details.md>)Note The [protocol editor's preference settings](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.14.17_Protocol_Editor_preference_page.md>) control if sections are displayed extended or collapsed.

In case the protocol definition is erroneous the details area will provide further information when moving the mouse over the highlighted field.

 ![Error if symbol's directions is left undefined.](<../../../../raw/129383.png>)

Alternatively you may also use the [Problems View](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.08.09_Problems_View.md>). By double-clicking on a Protocol Marker type of error the cursor jumps to the error in the corresponding editor.

## Protocol editor tabs

The tabs at the bottom of the protocol editor allow you to quickly switch between:

- Protocol Definition (default)
- [Level](<02.08.04.22.05_Level_tab.md>)
- [Wavetable](<02.08.04.22.06_Wavetable_tab.md>)
- [Timing](<02.08.04.22.07_Timing_tab.md>)

This way you can enter protocol relevant details, such as specific levels, timing, etc. very efficiently without leaving the protocol editor.
