# Using the Overon feature while running a testflow

The Overon feature allows the testflow to continue after the stop bin. It is useful when developing a testflow.

## Before you begin

Make sure the testflow has been loaded.

## Procedure

-  On the [Flags page](<02.08.04.32.03.01.06_Flags_page.md>), set the testflow flag [global_overon](<02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_global_overon>) to on.
-  Deactivate the overon flag in the bin where you do not want the Overon feature to take effect for this bin (the overon flag is active by default).
-  Run the testflow.

## Results

The testflow continues after the stop bin.

If a particular stop bin is the last bin in the flow, and the global_overon flag and bin overon are set, once a device goes into this bin, it will then continue to the otherwise bin.

You can also use the Overon feature in a conditional expression.
