# Download the waveform data to the vector variables for DSM FLAT setup

You can use the test method API to download and upload waveform data to the vector variables of the source pins. For DSM FLAT setup, you need to download the waveform data to the vector variables of all defined pins.

Below a C++ program example for an audio device.

```
virtual void run()
{
    //Add your test code here.

    ARRAY_I clkData(16), ctrlData(16), datainData(16), dataoutData(16);
    int i;

    for (i=0; i<16; i++) {
        clkData[i]=0;
        ctrlData[i]= 2788000;  //00001010101000101010100000

        datainData[i]= 46145539 + i*16384 + (15-i)*16;
        //1011 left_data[8] 10 right_data[8] 0011

        dataoutData[i]= 62926863;  //1111 00000000 11 00000000 1111
      }

    VECTOR("CLK").format("BIN").bits(26).setVectors(clkData);
    VECTOR("CTRL").format("BIN").bits(26).setVectors(ctrlData);
    VECTOR("DATAIN").format("BIN").bits(26).setVectors(datainData);
    VECTOR("DATAOUT").format("BIN").bits(26).setVectors(dataoutData);

    cout << "FLAT Digital Source Memory: data downloaded" << endl;

    return;
}
```
