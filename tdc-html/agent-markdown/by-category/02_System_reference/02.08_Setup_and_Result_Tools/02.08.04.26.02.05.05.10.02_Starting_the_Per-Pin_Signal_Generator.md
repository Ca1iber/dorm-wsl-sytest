# Starting the Per-Pin Signal Generator

The Per-Pin Signal Generator (PPSG) is started from the Tool menu of the [Signal Analyzer Tool](<02.08.04.26_Signal_Analyzer.md>).

## About this task

Start the PPSG to create a new pattern for simulating analog signals over digital channels.

## Before you begin

Make sure that STIL Reader is installed and you have a license for it.

## Procedure

-  [Start the Signal Analyzer Tool](<02.08.04.26.01.01_Starting_Up_Signal_Analyzer.md>).
-  Choose Tools > Per-Pin Signal Generator.

## Results

The Per-Pin Signal Generator window is displayed.

 ![Per-Pin Signal Generator_Tool window](<../../../../raw/136244.png>)

## What to do next

Generate the desired pattern, as described in [Generating a pattern with PPSG](<02.08.04.26.02.05.05.10.03_Generating_a_pattern_with_PPSG.md>).
