# Wavetable header

![wavetable_header](<../../../../raw/21984.png>)

 |

wavetable_name

 |

Up to 40 characters defining the wavetable name. If enclosed in double quotes ("..."), everything inside the quotes is taken as the name - even spaces. If not enclosed in quotes, all characters up to but not including the first space are taken as the name. Note that semicolons are not allowed in the name.
