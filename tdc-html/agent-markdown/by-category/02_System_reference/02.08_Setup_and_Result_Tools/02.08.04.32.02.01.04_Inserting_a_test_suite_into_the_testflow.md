# Inserting a test suite into the testflow

#### Subtopics

- [Setting up a multiport testsuite](<02.08.04.32.02.01.04.01_Setting_up_a_multiport_testsuite.md>)
- [Setting up a special test suite](<02.08.04.32.02.01.04.02_Setting_up_a_special_test_suite.md>)
- [Creating a floating test suite](<02.08.04.32.02.01.04.03_Creating_a_floating_test_suite.md>)

You can insert a test suite in the Flow Sequence Editor and then use the Flow Data Editor or the Properties view to edit the attributes of the test suite. You can also add a test suite in the Flow Data Editor as a floating test suite, and then connect it to the testflow.

## About this task

There are two ways to insert a test suite in the Flow Sequence Editor:

- Enter the test suite name, select the primary sets and the executed test in the New RunAndBranch Node Wizard or New Run Node Wizard.
- Enter only the test suite name and the test method name in the New RunAndBranch Node Wizard or New Run Node Wizard, and leave the other fields blank. The inserted test suite uses the primary set of the preceding test suite in the current testflow. That means, if you move a test suite from testflow A to testflow B without specifying primary sets, the test suite uses the primary sets of the preceding test suite in testflow B. This allows you to move test suites between testflows easily.

This topic describes the first method.

## Before you begin

Make sure that the primary setup files have been loaded and the required test method has been built.

## Procedure

-  In the Flow Sequence Editor, click an insertion point to highlight it. The point becomes red.
-  On the Palette, click Run Test (or Run and Branch) according to your requirement. The New Run Node Wizard opens.
-  Type the test suite name in the Test Suite Name text box.
-  Enter a string describing the test suite in the Comment text box.
-  Select the test to be executed in the test suite. Selecting a test differs depending on the type of test suite. See Selecting a test to be executed, below, for details.
-  Enter the numbers of the timing setup components, level setup components, and the analog set. The descriptions for the setup component are displayed automatically in the filed to the right of the setup component numbers.
-  Enter the pattern name.
-  Click Finish.

## Results

A test suite has been inserted in the testflow.

You can convert a run node to a run-and-branch node and vice versa. For example, to switch a run-and-branch node to a run node, right-click this node in the Flow Sequence Editor and then select Convert to Run Node.

Note Converting a run-and-branch node to a run node, automatically removes the nodes in the failed branch of the converted node.

## What to do next

Edit the test resources and test suite flags in the Flow Data Editor.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.3.2: New way of inserting a test suite by entering the name and the executed test in the Test test suitesuite Dialog window.

- SmarTest 6.5.3: New added Comment text box in the New Run Node Wizard and New RunAndBranch Node Wizard.
