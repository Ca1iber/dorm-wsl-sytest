# Testsuite Selection

The following section describes each command (and its parameters) in more detail. The first group of commands describe the testsuite, on which the measurements are performed.

These are

- `DATASET`
- `PRIMARY`
- `LABEL`
- `TESTFUNC`

```
"PRIMARY" <sep> <timingset> | <levelset> | <dpsset>
<timingset> = "TIMING" <sep>  <waveform set> | <specset> <sep>
    "SET" <sep> <set no> [ <sep> """ <description> """"]
<specset> = """ <eqnset no> <sep> <specset no> [ <sep> <description> ] """
<description> = <max. 60 characters except " and newline>
```

<eqnset no> or <specset no> or <set no> are integer numbers.

```
<levelset> = <levelsetF> | <levelsetE>
<levelsetF> = "LEVELSET"  <sep> <set no>
<levelsetE> = "LEVEL" <sep> <specset> <sep>
    "SET" <sep> <set no> [<sep> """ <description> """]
<dpsset> = "DPSSET" <sep> <set no>
    "LABEL" <sep> <label name (max. 40 characters)>
    "TESTFUNC"  <sep>
    "FUNCTIONAL" [ <sep> """ <parameter string> """ ]
    "DATASET" <sep> <dataset filename>
    "TESTERSTATE" <sep> "CONNECT" | "DISCONNECT"
```
