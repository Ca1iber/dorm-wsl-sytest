# Diagnostic

The diagnostic performs tests on the system hardware, checking for faults. It is designed to identify faulty hardware at a field replaceable unit (FRU) level. If several hardware modules are likely to be causing a problem, the diagnostic suggests a troubleshooting strategy to help you isolate the defective FRU.

 Note The diagnostic is not capable of reporting whether the test system is working within its published specifications. That task is performed by the calibration process.

SmarTest provides the Diagnostic tool for verifying the integrity of the test system. This tool helps you localize faults in the hardware.
