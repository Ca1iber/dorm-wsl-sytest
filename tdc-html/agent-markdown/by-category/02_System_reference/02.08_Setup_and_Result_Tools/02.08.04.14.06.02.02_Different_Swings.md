# Different Swings

#### Subtopics

- [Estimate the time shift between two swings](<02.08.04.14.06.02.02.01_Estimate_the_time_shift_between_two_swings.md>)
- [Compensation of Different Swings](<02.08.04.14.06.02.02.02_Compensation_of_Different_Swings.md>)

The swing is defined as the voltage difference between the upper and lower voltage level of a pin or a group of pins. In a mixed level device it can vary from a fraction of a volt up to several volts.

## Functional changes

- Introduced before SmarTest 6.3.2
