# Displaying the Timing Setup in Double Size

To get the Timing Setup window in double size, pick the option double size in the Code pulldown menu. Alternatively hit CTRL+d.

To go back to standard size pick the option standard size in the Code pulldown menu. Alternatively hit CTRL+s.

The following features are available only in double size:

- the free resources column
- the previous/next device cycle column.
