# Validating a protocol definition

Once a protocol has been defined from scratch or an existing one has been modified its definition should be checked for formal errors.

## About this task

This task describes how to validate a protocol definition using the protocol's Build feature within the Protocol Editor or the Test Program Explorer.

## Before you begin

Ensure you have followed either of the descriptions [Setting up the protocol definition](<02.08.04.22.10.02_Setting_up_the_protocol_definition.md>) or [Modifying an existing protocol definition](<../../03_Use_cases_and_application_papers/03.11_How_to_do_transaction_based_protocol_testing/03.11.01.04.03_Modifying_an_existing_protocol_definition.md>).

## Procedure

-  Follow either of the two options:

  -  In the [Protocol editor](<02.08.04.22_Protocol_editor.md>), right-click the protocol icon and select Build.  ![ProtocolWrapper_RightMouseMenu](<../../../../raw/126277.png>)
  -  In the [Test Program Explorer](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02_Test_Program_Explorer.md>), right-click the Protocols node and select Build all to validate all protocols loaded.  ![TestProgramExplorer_ProtocolsNode_RightMouseMenu_BuildAll](<../../../../raw/130391.png>)  Note If you select a single protocol here, you can perform a build on that protocol only.

-  If the icons in the details area of the [Protocol editor](<02.08.04.22_Protocol_editor.md>) indicate an error, either

  -   click through the elements of the protocol's definition showing an error or
  -  check the [Problems View](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.08.09_Problems_View.md>) for Protocol Marker type of errors alternatively.  ![ProblemView_ProtocolMarkerType_Error](<../../../../raw/130394.png>)

-  Resolve the issues described in the Description column of the Problems view. Note The problem description will also be displayed when moving the mouse over the problem highlighted int the [Protocol editor](<02.08.04.22_Protocol_editor.md>).

## Results

You have performed a pre-execution build to identify generic protocol definition problems and resolved them.
