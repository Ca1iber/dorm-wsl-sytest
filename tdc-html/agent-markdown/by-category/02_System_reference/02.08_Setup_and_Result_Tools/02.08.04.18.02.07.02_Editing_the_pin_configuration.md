# Editing the pin configuration

## Before you begin

Make sure that a new pin configuration file has been created or an existing pin configuration file has been loaded.

## Procedure

-  Open one of the Pin Setting editors, for example, Digital Pins editor. For a new pin configuration file, the pin configuration area is empty.
-  Enter the information for the first pin according to the spec sheet. When you finish the edition of the first pin, select the Tester Channel cell of this pin and press Enter, a new line for a new pin appears. You can continue to enter the information of the second pin.
-  Repeat step 3 until you have entered the information of all pins.
-  Edit the pins in the other Pin Setting editors.
-  Apply the data and save the pin configuration file.

## Results

The pin configuration has been set up.
