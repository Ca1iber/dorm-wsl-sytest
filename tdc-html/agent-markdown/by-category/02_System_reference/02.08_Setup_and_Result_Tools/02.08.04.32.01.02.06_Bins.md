# Bins

During a test, the tested devices normally need to be sorted according to their test results.

This is done by assigning the devices to different bins. For example, all devices that fail in a certain test suite will end up in one bin and not be tested any further.

A bin in a testflow can generate exactly one hardware bin and one software bin. For more information on bins in multisite tests see [Use of bins with multisite tests](<../../03_Use_cases_and_application_papers/03.02_How_to_do_Multi-Site_Testing/03.02.02.06.08_Use_of_bins_with_multisite_tests.md>) and [Multibin SmartDisconnect test suite](<02.08.04.32.01.02.01.04_Multibin_SmartDisconnect_test_suite.md>).

There are several types of bins:

 |

stop bin

 |

The bins (which appear in the testflow) into which you put either all good or all bad devices. Stop bins are inserted at points in the testflow, and appear as either

- triangular green good bins, or
- octagonal red bad bins.

When using the [Flow Sequence Editor](<02.08.04.32.03.02_Flow_Sequence_Editor.md>) to insert the stop bin into your testflow, you can define it to be a good bin, or bad bin. The number of parts falling into these bins are included in yield calculations.

 |
 |

otherwise bin

 |

A bin for all devices that do not fall into a stop bin. This bin node is not displayed in the testflow.

 |
 |

floating bin

 |

The floating bin is defined in the Bins page of the [Flow Data Editor](<02.08.04.32.03.01_Flow_Data_Editor.md>) and is used as a predefined bin for the multi-bin. The floating bin is not displayed in the [Flow Sequence Editor](<02.08.04.32.03.02_Flow_Sequence_Editor.md>) but the associated multibin that you subsequently insert (using the [Flow Sequence Editor](<02.08.04.32.03.02_Flow_Sequence_Editor.md>)) does show up.

 |

## Example

If for some reason your production run should stop unexpectedly, all devices that have not ended up in either a good or bad bin will be assigned to the otherwise bin. This bin is also included in yield calculations, as it can be defined as a good or a bad bin.
