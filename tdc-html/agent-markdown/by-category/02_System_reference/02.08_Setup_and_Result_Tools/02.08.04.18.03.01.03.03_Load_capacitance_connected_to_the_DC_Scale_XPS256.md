# Load capacitance connected to the DC Scale XPS256

For the DC Scale XPS256, SmarTest automatically sets the performance range considering the value of the load capacitor(s) connected to the DUT power pin on the DUT board.

For the supported load capacitance ranges, refer to section [Dynamic behavior in force voltage or clamp voltage mode](<../02.05_Test_Head_Cards/02.05.05.03.10.09_XPS256_programming_-_Force_and_clamp_voltages.md#_354305__s_Dynamic_behavior>) in [XPS256 programming - Force and clamp voltages](<../02.05_Test_Head_Cards/02.05.05.03.10.09_XPS256_programming_-_Force_and_clamp_voltages.md>).

## Load capacitance in the DPS operating mode

Entering a capacitance value in the C[uF] column of the [DPS Pins editor](<02.08.04.18.03.01.03_DPS_Pins_editor.md>) has an effect for an XPS256 channel in DPS mode.

Note The supported maximum load capacitance depends on the selected current for range of the XPS256 channel. SmarTest automatically limits the load capacitance value which has been set in the [DPS Pins editor](<02.08.04.18.03.01.03_DPS_Pins_editor.md>), to the maximum value that is defined in section [Dynamic behavior in force voltage or clamp voltage mode](<../02.05_Test_Head_Cards/02.05.05.03.10.09_XPS256_programming_-_Force_and_clamp_voltages.md#_354305__s_Dynamic_behavior>) of [XPS256 programming - Force and clamp voltages](<../02.05_Test_Head_Cards/02.05.05.03.10.09_XPS256_programming_-_Force_and_clamp_voltages.md>).

## Load capacitance in the PMU operating mode

For XPS256 channels in PMU operating mode, you optionally can set the load capacitance using the [SPMU_PIN_TASK.loadCap()](<../02.07_Test_Method_Reference/02.07.04.01.234.01.19_SPMU_PIN_TASK.loadCap.md>) test method API function.
