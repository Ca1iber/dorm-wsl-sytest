# Deleting Specification Sets

- Click Delete Specification Set in the Change pulldown menu.

A screen similar to that of the figure below appears.

  ![Deleting a Specification Set](<../../../../raw/22027.png>)
- Highlight the specification set you want to delete and click delete.
- Repeat this last step as often as required (for other specification sets), and click done when finished.

## Functional changes

- Introduced before SmarTest 6.3.2
