# Logging test results with Datalog Control tool in EWC

- [Setting the data log output information in the Datalog Control tool](<02.08.04.06.01.02_Setting_the_data_log_output_information_in_the_Datalog_Control_tool.md>)
- [Generating the (partial) lot summary file with the Datalog Control tool](<02.08.04.06.01.03_Generating_the__partial__lot_summary_file_with_the_Datalog_Control_tool.md>)

## About this task

Datalog control tool is only used to log the testflow execution results. Do not use it to log the results of test programs. Otherwise, the results may be messed up.

## Before you begin

SmarTest is started and the testflow is ready for execution.

## Procedure

-  In the SmarTest Work Center, [load the testflow and its setup files](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02.01.05_Loading_a_testflow_and_all_setup_components.md>).
-  To open the Datalog Control tool, click 93000 > Datalog > Datalog Control in the EWC.
-  In the Setup tab of Datalog Control tool, [set the data log profile and the lot information](<02.08.04.06.01.01_Setting_the_data_log_general_information_in_the_Datalog_Control_tool.md>).
-  In the File tab of Datalog Control tool, [set the data log and lot summary output information](<02.08.04.06.01.02_Setting_the_data_log_output_information_in_the_Datalog_Control_tool.md>).
-  To start the data log for the following executions, click Start Lot in the Datalog Control tool .
-  In the EWC, execute the testflow. The text data log file is created as you specified.
-  To test another device, change the DUT and execute the testflow again.
-  (optional) If needed, you can [generate the partial lot summary](<02.08.04.06.01.03_Generating_the__partial__lot_summary_file_with_the_Datalog_Control_tool.md>) for the tested devices.
-  After the whole lot is tested, [generate the lot summary](<02.08.04.06.01.03_Generating_the__partial__lot_summary_file_with_the_Datalog_Control_tool.md>) for the tested devices. The specified STDF data log file and the lot summary file in the Datalog Control tool are generated.

## Results

The data log files and the lot summary file you specified are generated.

## What to do next

Check and analyze the test results
