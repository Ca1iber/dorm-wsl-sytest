# Adding a limit in the Properties view

## About this task

You can add or delete limits (including default limits) for any test suite based on a test method in these locations:

- The Tests page
- The [Properties view](<02.08.04.32.03.04_Testflow_Properties_view.md>)

This topic describes adding a limit in the Properties view.

## Before you begin

Make sure that your testflow includes at least one test suite based on a test method.

## Procedure

-  On the Test suites page of the Flow Data Editor, select the test suite based on a test method to which you want to add a limit. The parameters of this test suite are shown in the Properties view.
-  In the Properties view, right-click the Test Suite > Test Method > Limits entry, and select New.

The Add a Test window opens.

  ![Add a Test window opened from the Properties view](<../../../../raw/110962.png>)
-  Add a limit:

  - To add a default limit, choose the desired default limit from the Test Name list. You cannot modify these limits' ranges. (The Limit Range text box becomes gray.)
  - To add a custom limit, type a name in the Test Name text box. Then edit the limit range. You can use the system-defined unit specifiers listed in [Unit Identifiers](<../02.07_Test_Method_Reference/02.07.03.01.02_Unit_Identifiers.md>) or specify a new unit specifier. A unit string takes on the following formats: 1.05[mV] or 1.05 mV.

-  (Optional) Fill in the Test Number text box.
-  Click OK.

## Results

A limit is created under the Test Suite > Test Method > Limits entry in the Properties view. This limit is also displayed on the Tests page.

## What to do next

Use this limit in the test method.
