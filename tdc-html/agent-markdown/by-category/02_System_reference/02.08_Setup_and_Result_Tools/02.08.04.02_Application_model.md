# Application model

Each Testflow describes how ONE device is to be tested. However, additional information is required that tells the software about things like,

- how the device stream is organized - in wafers or packages
- what data the operator should enter, and when
- what data is to be logged

This information is described in the application model file. This file together with the data in the application data file, is called the application.

## Example

Some example application model files are provided in the /opt/hp93000/soc/applic_models/ directory, for example,

- wafer_autoprobe
- wafer_manual
- package_handler
- package_manual
- sublevel_dialog
