# Viewing different types of results on a shmoo plot

If you have selected multiple [Test modes](<02.08.04.25.03.02.02_Test_modes.md>) in the testMode field when [setting](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>), you can view the results related to each test mode on the shmoo plot.

## Before you begin

- Make sure you have selected multiple [Test modes](<02.08.04.25.03.02.02_Test_modes.md>) in the testMode field when [Setting up a shmoo test in the Shmoo Tool](<02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>).
- [Executing the shmoo test](<02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>) to display its shmoo plot on a shmoo page.

## Procedure

-  Right-click the shmoo plot and select Test Modes.

A shortcut menu opens. All the selected [Test modes](<02.08.04.25.03.02.02_Test_modes.md>) during setting are listed.

-  Select your desired test mode.

## Results

- The new results for the selected test mode are dispalyed on the shmoo plot.
- The name of the selected test mode is displayed in the plot title.
