# My Function...

This menu item accesses the User Defined Function dialog box shown below. This dialog box allows you to define your own functions.

  ![User Defined Function](<../../../../raw/45962.png>)   ![User Defined Panel Toolbar](<../../../../raw/45966.png>)

You can either have your functions appear in the User Defined Function Toolbar (see [User Defined Function Toolbar](<02.08.04.26.02.05.03.01.05_User_Defined_Function_Toolbar.md>)) using the Toolbar tab of the User Defined Function dialog box, or you can have your functions appear in a shortcut menu in the Waveform Graphs Tool using the Shortcut Menu tab. The following figure shows the Shortcut Menu tab selected with corresponding pop-up menus.

  ![User Defined Function Shortcut Menus](<../../../../raw/45965.png>)   ![User Defined Popup 1](<../../../../raw/45967.png>)   ![User Defined Popup 2](<../../../../raw/45968.png>)   ![User Defined Popup 3](<../../../../raw/45969.png>)

The row with "Exe" on the right side is the filter function. The filter function allows you to view only those functions corresponding to the filter criteria. You simply input a string in the filter row under the table heading of choice, then click the Exe button on the right side of the filter tool above the scroll bar.

The row below the filter function is the search function. You can search for a specified row using the search function. You simply input a string in the search row under the table heading of choice, then click the Search Previous (upward triangle) or Search Next button (downward triangle) on the right side of the search tool above the scroll bar. Then, the row found during the search will be highlighted.

Add creates a new line in the table.

OK activates the current setting of this dialog box and closes the dialog box.

Cancel aborts the current modification of this dialog box and closes the dialog box.

Back to Default restores the default setting of this dialog box.

For information on how to create a user defined function, see [User Defined Function](<02.08.04.26.02.03.01_User_Defined_Function.md>).
