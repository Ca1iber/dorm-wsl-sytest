# Downloading the waveform data to the vector variables

The DSM feature provides an alternative way of using the test method API to download and upload waveform data to the vector variables.

The following are C++ program examples for the demo devices.

## For audio device

```
virtual void run()
{
    ARRAY_I leftData(256), rightData(256);
    int i;

    //Generate up and down ramp waveform data
    for (i=0; i < 256; i++) {
    leftData[i] = i;
    rightData[i] = 255-i;
    }

    //Download up ramp to vector variable "VVLeft"
    VECTOR("VVLeft").format("BIN").bits(8).setVectors(leftData);

    //Download down ramp to vector variable "VVRight"
    VECTOR("VVRight").format("BIN").bits(8).setVectors(rightData);

    cout << "Digital Source Memory: data downloaded " << endl;

    return;
}
```

## For video device

```

{
    ARRAY_I R_Data(256), G_Data(256), B_Data(256);
    int i;

    //Generate up and down sinewave data
    for(i = 0; i < 256; i++) {
    R_Data[i] = sin(2*M_PI*i/256)*(1+0.02*rand()/RAND_MAX);
    G_Data[i] = sin(2*M_PI*i/256)*(1+0.02*rand()/RAND_MAX);
    B_Data[i] = sin(2*M_PI*i/256)*(1+0.02*rand()/RAND_MAX);

    //Download sinewave to vector variable "VV_Red"

    VECTOR("VV_Green").format("BIN").bits(8).setVectors(G_Data);
```
