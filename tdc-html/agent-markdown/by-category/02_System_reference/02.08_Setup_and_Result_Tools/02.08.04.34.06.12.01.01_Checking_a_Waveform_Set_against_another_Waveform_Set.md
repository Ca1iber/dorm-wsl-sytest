# Checking a Waveform Set against another Waveform Set

This is a general check that compares a waveform set against any other waveform set. To run it, proceed as follows:

- In the dialog box in [Checking for Compatible Waveform Sets](<02.08.04.34.06.12.01_Checking_for_Compatible_Waveform_Sets.md>) click the WFset radio button.
- In the entry field labeled with a hash (#) type the waveform set number you wish to check.
- In the against the WFset browser select one or more waveform sets.
- Click check.

The system checks the compatibility of the entered waveform set against the waveform sets in the browser according to the rules in [Keeping Waveform Sets Compatible](<02.08.04.34.06.11.02_Keeping_Waveform_Sets_Compatible.md>). It displays a report in the report window.

If the compatibility check fails, click the select button show incompatible pins of first incompatible WFset. The system includes the failed pins in the compatibility check report.
