# Timing edges

#### Subtopics

- [Drive Edges and Actions](<02.08.04.34.01.01.01_Drive_Edges_and_Actions.md>)
- [Receive Edges and Actions](<02.08.04.34.01.01.02_Receive_Edges_and_Actions.md>)
- [Edge Ranges](<02.08.04.34.01.01.03_Edge_Ranges.md>)
- [Edge order](<02.08.04.34.01.01.04_Edge_order.md>)

There are 16 edge generators for every test system channel (pin). 8 of these can be used to produce 8 drive edges and 8 of them used to produce 8 receive edges:

- Drive edges can be used by the Drive Data Formatter to produce drive edges and the Tri-state Formatter to produce tri-state edges.
- Receive edges can be used by the Data Sampler or the Window Formatter to produce receive edges. The edges used by the data sampler are required for edge compares, the edges used by the window formatter are required for window compares.

The activities associated with each edge are called edge actions.

Every edge can be programmed individually as a drive or a receive edge, however its direction depends on the pin type. An input pin uses edges with drive and tri-state actions, an output pin uses edges with receive actions; see below. An I/O pin can use edges with all three actions.
