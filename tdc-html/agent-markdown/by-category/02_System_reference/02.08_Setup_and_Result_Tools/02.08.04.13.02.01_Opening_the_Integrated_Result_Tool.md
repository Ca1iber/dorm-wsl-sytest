# Opening the Integrated Result Tool

To open and use the Integrated Result Tool, open the Result perspective.

## About this task

Open the Integrated Result Tool to access any of its analysis functions and other capabilities.

## Procedures

### From the toolbar

Click the Result perspective's icon ![SmarTest Eclipse Workcenter toolbar_Result Perspective button](<../../../../raw/136268.png>) on the SmarTest toolbar.

### From the menu

- In the SmarTest Work Center, choose Window > Open Perspective > Other.

You can also click the Open Perspective button ![Open Perspective button](<../../../../raw/123065.png>) on the toolbar and choose Other from the drop-down list.

In either case, the Open Perspective dialog opens.

- In the dialog, click the Result perspective and click OK.

The various views of the result perspective open.

### From the Testflow Tool

Opening the Integrated Result Tool from the Testflow tool displays the results of a particular test. It requires that you already have loaded the data log with the test's results.

- In the Flow Sequence Editor or Flow Data Editor, right-click the test the results of which you want to display.
- From the shortcut menu, choose Show In Result Tool.

## Results

The views of the Integrated Result Tool are open. (For a description of the perspective's basic layout, see [Result perspective overview](<02.08.04.13.01.01_Result_perspective_overview.md>).)

If you have opened the Integrated Result Tool from the menu or the toolbar, no data navigation view is open. (For information on opening these views, see [Opening a data log for examination](<02.08.04.13.02.02.02_Opening_a_data_log_for_examination.md>).)

If you have opened the Integrated Result Tool from the Testflow Tool, the results of the selected test are highlighted in the [data navigation view](<02.08.04.13.03.02_Data_navigation_views.md>).
