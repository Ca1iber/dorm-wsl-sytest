# Commands in the bottom bar of the Shmoo Tool

Right-click a shmoo page name located at the bottom bar of [the shmoo editor](<02.08.04.25.02_The_interface_of_the_Shmoo_Tool.md>), you will see these commands:

- Rename: Renames the shmoo page.
- Duplicate: Creates a new shmoo page which has the same setups and shmoo plots as this shmoo page.
- New: Lets you create a new shmoo page in the shmoo editor.
- Delete: Deletes the shmoo page.
- Delete All: Deletes all the shmoo pages in the shmoo editor.
- Overlay: Lets you overlay shmoo plots of different shmoo pages in the shmoo editor. For details, see [Overlaying shmoo tests in the Shmoo Tool](<02.08.04.25.03.09_Overlaying_shmoo_tests_in_the_Shmoo_Tool.md>).
- AddToOverlay: Adds the current shmoo plot displayed on this shmoo page to an existing overlay shmoo plot displayed in the same shmoo editor.
