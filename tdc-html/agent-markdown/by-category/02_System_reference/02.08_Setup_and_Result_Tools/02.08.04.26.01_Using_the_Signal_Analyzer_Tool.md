# Using the Signal Analyzer Tool

#### Subtopics

- [Starting Up Signal Analyzer](<02.08.04.26.01.01_Starting_Up_Signal_Analyzer.md>)
- [Passing Waveform into Signal Analyzer](<02.08.04.26.01.02_Passing_Waveform_into_Signal_Analyzer.md>)
- [Downloading waveform patterns from the Signal Analyzer](<02.08.04.26.01.03_Downloading_waveform_patterns_from_the_Signal_Analyzer.md>)
- [Converting existing waveforms to the new ASCII format](<02.08.04.26.01.04_Converting_existing_waveforms_to_the_new_ASCII_format.md>)

This section tells you how to start the Signal Analyzer Tool and how to pass the waveform into this tool for debugging.

The Signal Analyzer Tool also provides the following functions:

- Loading a data log file and selecting the waveform contained in the file ([Load Datalog...](<02.08.04.26.02.05.05.12_Load_Datalog.md>) and [Select Waveform...](<02.08.04.26.02.05.05.13_Select_Waveform.md>))
- Creating arbitrary waveforms (see [Generate](<02.08.04.26.02.05.05.01_Generate.md>))
- Modifying the waveforms (see [Test Mask...](<02.08.04.26.02.05.05.02_Test_Mask.md>), [Translate...](<02.08.04.26.02.05.05.03_Translate.md>), [Inject Jitter...](<02.08.04.26.02.05.05.04_Inject_Jitter.md>) and [Cable Simulation...](<02.08.04.26.02.05.05.05_Cable_Simulation.md>))
- Calculating the harmonic distortion and inter-modulation frequencies (see [Harmonics...](<02.08.04.26.02.05.05.11_Harmonics.md>))
- Setting up vectors for DSM testing (see [DSM...](<02.08.04.26.02.05.06.02_DSM.md>))
- Copying and pasting waveforms (see [Copy/Paste Waveforms](<02.08.04.26.02.01.03_Copy_Paste_Waveforms.md>))
- Deleting all (see [Delete All](<02.08.04.26.02.01.04_Delete_All.md>)) waveforms listed in the Result Waveforms table
- Assigning user defined functions (see [Assign User Defined Function](<02.08.04.26.02.03.01.03_Assign_User_Defined_Function.md>)) to create a dedicated waveform-analysis function
