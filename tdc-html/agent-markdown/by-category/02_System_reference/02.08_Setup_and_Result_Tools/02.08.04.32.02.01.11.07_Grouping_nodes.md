# Grouping nodes

The group node can be used to simplify (schematically, not functionally!) your testflow. You can group together several consecutive nodes - provided they are all within the same level of your testflow - and have them displayed by one node, the [Group node](<02.08.04.32.01.02.05_Group_node.md>).

## Before you begin

Make sure that the testflow contains more than one node.

## Procedure

-  In the Flow Sequence Editor, select one or more nodes (press Ctrl and then click) you want to group. Note To group the Run and Branch node and [Flow control nodes](<02.08.04.32.01.02.02_Flow_control_nodes.md>), you must wide select them. Note Only nodes at the same level can be selected together.
-  Right-click and select Group.

The chosen nodes are replaced with a group node. The default group node name appears in the group node's top left corner.

-  Optionally, you can edit the group properties (see [Group node](<02.08.04.32.01.02.05_Group_node.md>)):

  -  Change the group node's name:

In the Properties view, type the new name in the Group Name field.

The new name replaces the default name in the top left corner of the group node.

  -  Add a comment:

In the Properties view, type the comment text in the Group Comment field.

  -  Determine whether the group shall be skipped when running the testflow:

In the Properties view, select or clear the Group Bypass flag.

Note that if Group Bypass is selected the testflow (file) is not backward compatible with SmarTest versions before 7.1.3.

## Results

The selected nodes are grouped.

## What to do next

To ungroup the nodes, right-click the group node and select Ungroup.

To hide the contents of a group node, right-click the group node and select Collapse.

To show the contents of a group node, right-click the group node and select Expand.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.2: You can group the testflow nodes in the Flow Sequence Editor.
- SmarTest 6.5.2: You can edit the group name in the Properties view.
- SmarTest 6.5.3: To group the Run and Branch node and Flow control nodes, you must wide select them.
- SmarTest 7.1.3: Flag Group Bypass introduced
