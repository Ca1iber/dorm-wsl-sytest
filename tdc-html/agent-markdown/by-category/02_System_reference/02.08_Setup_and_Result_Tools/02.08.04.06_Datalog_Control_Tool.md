# Datalog Control Tool

#### Subtopics

- [Logging test results with Datalog Control tool in EWC](<02.08.04.06.01_Logging_test_results_with_Datalog_Control_tool_in_EWC.md>)

The Datalog Control tool provides a central place to configure the data log related settings. It allows to select the data log profile, input the lot information, specify the output data log files and control the generation of the lot summary file. But it is only used to control the data log for the testflow execution.

To open the Datalog Control tool, click 93000 > Datalog > Datalog Control in the EWC.
