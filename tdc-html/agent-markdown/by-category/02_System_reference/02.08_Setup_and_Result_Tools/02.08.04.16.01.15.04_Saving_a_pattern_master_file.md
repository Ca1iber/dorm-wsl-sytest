# Saving a pattern master file

You can save a pattern master file with its original file name, or as single pattern pattern file containing all referenced patterns.

## Before you begin

The pattern master file must be loaded.

## Procedures

### Save it with its original name

Click File > Save.

### Save it as a single pattern file

- Click File > Save As. The Save As dialog appears.
- In the Name field type the new file name.
- If required, change the target folder in the Location field.
- Click Finish.

## Results

The file is saved either as a pattern master file or as a single pattern file.
