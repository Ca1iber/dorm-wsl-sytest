# EQNSET (Level equation set header)

Each new equation set within the Level Equation Component must start with an equation set header line.

  ![EQNSET](<../../../../raw/21964.png>)

 |

equation_set_number

 |

An integer in the range 1 to 256. This number must be unique.

 |
 |

equation_set_description

 |

Optional. A string of up to 60 characters. If it is enclosed in double quotes ("..."), everything inside the quotes is taken as the description - even spaces. If the description is not enclosed in double quotes, all characters up to but not including the first space is taken as the description. The equation set description does not have to be unique. However, an error is generated if the Level Specification Component references a non-unique equation set.

Note that semicolons are not allowed in the description.

 |

See from [Level Equations - Example](<02.08.04.14.02.04_Equation_based_level_setup_example.md>) onwards for an example.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.0.1: Range of equation_set_number extended
