# Source and target testflows

When testflows are merged, elements can always be copied in just one direction - from a source to a target testflow. While the target testflow is to be modified, the source testflow stays unchanged.

## Source testflow

Valid operations:

- Copying testflow elements to the clipboard
- Loading a new testflow as a source
- Search with the Flow Sequence Editor
- Opening the Properties view of any testflow elements, for example, the test suite node, to look at the settings

You cannot:

- Create new bookmarks in the source testflow
- Execute the source testflow, or any of its test suites
- Make changes to the source testflow with respect to either its structure or the settings of testflow elements, setup files, or flags

## Target testflow

The target testflow has exactly the same status as a "normal" testflow on which you work with the Flow Sequence Editor not in merge mode. This means that, in addition to the special merge operations, you can use the full range of operations provided by the Flow Sequence Editor.

The target testflow fully complies with the living machine concept of the V93000, that is, each modification you make is downloaded immediately into the test system hardware.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.2: You cannot group testflow elements in the source testflow.
