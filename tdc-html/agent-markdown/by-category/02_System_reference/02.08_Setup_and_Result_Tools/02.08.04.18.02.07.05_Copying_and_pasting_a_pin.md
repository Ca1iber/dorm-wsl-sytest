# Copying and pasting a pin

Some pins have similar configuration, for example, the pins of a data bus. Defining these pins, you can use the function of copying and pasting to simplify the input.

## Before you begin

The pin you want to copy has been defined in the Pin Setting editors.

## Procedure

-  To select the pin (for example, DS7) you want to copy, click the row number of DS7. Then the row is highlighted by the shadow.  ![Select a Pin](<../../../../raw/97869.png>)
-  To copy the configuration of DS7, right-click and choose Copy.
-  Select the Tester Channel cell of the last pin (DS7) and press Enter, a blank row appears. Right-click the row number of the new created row and select Paste.   ![Select the row to paste](<../../../../raw/97870.png>)

## Results

The configuration of DS7 is pasted into the third row. The pin name is automatically set to CopyOf_DS7.

 ![Paste Pin Configuration of DS7](<../../../../raw/97871.png>)

## What to do next

Edit the configuration data of the pasted pin.
