# Pin role details

The pin role details are shown if you select a pin role in the protocol editor's overview area.

  ![Pin role details](<../../../../raw/126151.png>)

The pin role details show only the functions section.

 Note Do not change the pin role name here!

If the pin role name defined in the protocol details does not match the one displayed here you will see a ![Undefined protocol element icon](<../../../../raw/126152.png>) in the protocol structure shown in the overview area of the protocol editor.

## Functions

During encoding the pin role function is applied before the encode function of the transaction level to generate a state character sequence.

While decoding the pin role level function is applied to the state character sequence resulting from the transaction decode function.
