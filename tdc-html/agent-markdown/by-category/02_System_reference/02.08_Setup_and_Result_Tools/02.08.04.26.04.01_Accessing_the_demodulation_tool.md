# Accessing the demodulation tool

## About this task

This task describes how to access the demodulation tool.

## Before you begin

Make sure that the Signal Analyzer is open.

## Procedure

-  Select Tools >Demodulation (or use the shortcut Ctrl-D)
-  The opened dialog looks like the following:  ![demodulation dialog](<../../../../raw/127694.png>)  Note The demodulation dialog can be opened no matter which graph has the focus or whether there are opening graphs in Signal Analyzer at all.The opened dialog is non-blocking, which means you can move mouse focus to anywhere else in Signal Analyzer with the Demodulation dialog opening. For instance, you can open/close graphs or edit data traces. The dialog will be notified and refresh itself automatically.

## What to do next

Specify waveform and standard.
