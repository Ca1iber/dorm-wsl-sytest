# Force Failure Oriented Mode

In the Force Failure Oriented Mode, only failing cycles are recorded in the detailed error map. If the detailed error map is located within the test processor, its 8K memory will be filled with the data of the failing pins until the memory is full or the test is finished.

For more information, see [Analyzing Data in Cycle Oriented or Failure Oriented Mode](<02.08.04.08.01.02.02_Analyzing_Data_in_Cycle_Oriented_or_Failure_Oriented_Mode.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
