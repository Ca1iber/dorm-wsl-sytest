# Setting up the timing for selective capturing

#### Subtopics

- [Selective Capture with Equation based timing](<02.08.01.02.07.02.03.02.01_Selective_Capture_with_Equation_based_timing.md>)
- [Selective Capture with Fixed Timing](<02.08.01.02.07.02.03.02.02_Selective_Capture_with_Fixed_Timing.md>)
- [Selective Digital Capture Actions require a sufficient number of device cycle sets](<02.08.01.02.07.02.03.02.03_Selective_Digital_Capture_Actions_require_a_sufficient_number_of_device.md>)

In contrast to sequential capturing, the selective mode lets you define for every vector of a capture label whether you want data to be captured or not.

For selective capturing you use two specific edge actions in the waveforms to define when and when not capturing will be performed:

- Action C - Capture Data on this edge
- Action D - Do not capture Data on this edge

The "C" action will compare the received value to 0 to determine the capture value; see [Setting up the Levels](<02.08.01.02.07.02.02_Setting_up_the_Levels.md>) for details. Again in contrast to sequential capturing, selective capturing can be performed on any receive edge.

 Note If the "C" action is inserted inside a match loop, the size of the captured data is different for the [PS5000 card](<../02.05_Test_Head_Cards/02.05.04.02_Pin_Scale_5000_card.md>), compared to the [PS1600](<../02.05_Test_Head_Cards/02.05.04.01_Pin_Scale_1600_digital_card__Smart_Scale.md>). The PS5000 captures the data in the capture action during the match loop, unlike the PS1600. For PS5000, set [check_exa_scale_seq_restrictions](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.01.02_Technology_file_for_a_device.md#_49363___Toc73527999>) in the [.technology file](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.01.02_Technology_file_for_a_device.md>) to on to check if the selective capture pattern contains a match loop. When this parameter is on, a warning is shown in the Report window when a selective capture pattern containing a match loop is executed.

## Application aspects

A typical application for the Selective Mode is the capturing of serial framed data of a single device output pin. Capturing of undesired data between frames can be completely suppressed.

Especially when highest speed of capturing is needed, this mode is to be preferred over the Sequential Mode, as the transfer of undesired data to the workstation and later blending out of this data by means of a vector variable can be avoided.

Of course, the full data filtering capabilities of a vector variable can also be applied to data captured in Selective Mode, if this is desired.
