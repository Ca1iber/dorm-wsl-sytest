# Setting the data log output information in the Datalog Control tool

## About this task

The data log can be output to an EDL file, a STDF file, a text file, a custom data log file or the data log console. The lot summary file or partial lot summary file can be generated. This is done in the File tab of Datalog Control tool.

 ![DataLog tab of Datalog Control tool](<../../../../raw/136936.png>)

## Before you begin

Make sure the Datalog Control tool is started.

## Procedure

-  Open the File tab.
-  Specify the full path of the EDL file to be logged
-  Specify the full path of the text file to be logged. To output the text file content to the data log console, check the option console.

You can also specify the width of the test name and choose whether to show the column of pin name in the text data log.

-  Specify the full path of the STDF file to be logged

Multiple STDF and text data log files can be generated for one lot. To do this, specify a new file name when you want to log the following test results in another file.

-  If you want to generate the data log file with your own formatter, specify the full path of the data log file and choose the library of your data log formatter.
-  Specify the full path of the text lot summary file and the per-wafer lot summary file. To output the lot summary content in a pop-up window, check the option Window.

The per-wafer lot summary file can only be specified when Per Wafer is checked for PROBER test. The wafer ID will be automatically added to the name of the generated files.

-  Choose which tests are included in the lot summary file. It can be All Tests, Fail Tests or No Tests.
-  Choose whether to generate summary by site. If the by site option is checked, the test results will be summarized by site in the lot summary. Otherwise, the test results of all sites will be summarized together.
-  Click the Apply button to make the settings effective. Note If you specify the data log files here, the log_events_enable flag must be set to on. Otherwise you will get an error message asking you to turn on the flags when you click Start Lot.

## Results

The data log output settings are done. The changes will take effect since the next execution of the testflow.

## Functional changes

- Introduced in SmarTest 7.2.0
- SmarTest 7.2.0: in patch 2, supports per wafer lot summary file in TCCT 1.1
- SmarTest 7.2.1: New option Test Name Width and Show Pin Column to control the text data log files in TCCT 1.3
- SmarTest 7.2.1: All the variables defined in the newlotuiconfiguration.xml file can be used in the data log file name in TCCT 1.3
- SmarTest 7.2.2: Supports logging the EDL data log file in TCCT 1.4
- SmarTest 7.2.2: Supports logging the content with customized data log formatter in TCCT 1.4
- SmarTest 7.4.5: Removed stdf_generation flag
