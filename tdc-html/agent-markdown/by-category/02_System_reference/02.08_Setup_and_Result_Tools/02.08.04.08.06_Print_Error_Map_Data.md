# Print Error Map Data

## About this task

This window is used to write error map data to a file or to print them directly.

The file is saved in the /device/report directory.

## Procedure

-  On the Error Map Tool menu, click File > Print Error Map Data.
-  The Print Error Map Data window opens.  ![Print Error Map Data Tool](<../../../../raw/105960.png>)

  - If All executed ports selected, the failures of all executed ports will be printed.
  - If Selected port selected, only the failures of the selected port in the Error Map Tool will be printed.
  - If All recorded failures selected, all the recorded failures will be printed.
  - If Abort after maximum failure count selected, only the first N failures will be printed. N is specified in the edit box following the radio button. If the number of all recorded failures is less than N, all of the failures will be printed.
  - If Receive data selected, a column containing the actual received data will be printed.
  - If Expected data selected, a column containing the expected data will be printed.
  - If Print to file selected, the File name edit box is enabled. You can specify the file name to store the error map data to be printed. Otherwise, the data will be printed to the console directly.

-  Select the data you wish to see and click OK.

## Results

The printed error map data may contain three to five columns like below. The first three columns are fixed and the Expected data and Received data are dependent on the settings in the Print Error Map Data window.

```
label1@port1:
Error number | Cycle number| Pinname | Expected data | Received data
            1|           70|     Sdo1|              1|            0
            2|           98|     Sdo1|              1|            0
            3|          110|     Sdo2|              1|            0
            4|          111|     Sdo2|              0|            1
            5|          112|     Sdo2|              0|            1
            6|          113|     Sdo2|              0|            1
            7|          117|     Sdo3|              1|            0
            8|          118|     Sdo2|              1|            0
            9|          118|     Sdo3|              1|            0
```

The characters in the Expected data and Received data column means:

 |

0

 |

The data is 0.

 |
 |

1

 |

The data is 1.

 |
 |

I

 |

The data is intermediate.

 |
 |

U

 |

The data is unstable.

 |
 |

N

 |

The data is not reconstructed due to multiple compare edges in one cycle. This happens when testing in x-mode.

 |
