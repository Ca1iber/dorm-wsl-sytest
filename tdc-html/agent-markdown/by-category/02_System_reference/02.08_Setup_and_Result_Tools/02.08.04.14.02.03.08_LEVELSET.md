# LEVELSET

#### Subtopics

- [IO PINS resources](<02.08.04.14.02.03.08.01_IO_PINS_resources.md>)
- [Termination Mode](<02.08.04.14.02.03.08.02_Termination_Mode.md>)

Each new level set within an equation set has the following syntax:

  ![LEVELSET](<../../../../raw/21974.png>)

 |

level_set_number

 |

An integer in the range 1 to 99.

 |
 |

level_set_description

 |

Optional. Up to 60 characters defining the level set description. If enclosed in double quotes ("..."), everything inside the quotes is taken as the description - even spaces. If not enclosed in quotes, all characters up to but not including the first space are taken as the description.

 |

## Functional changes

- Introduced before SmarTest 6.3.2
