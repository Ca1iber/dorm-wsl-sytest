# Renaming events and test points

You rename an event and its related test points in the Rename Event dialog of the Pattern Editor.

## About this task

You can rename an event only in the Rename Event dialog. You cannot rename it in the properties view.

When applying the default setting, all related test points are renamed with the event.

## Procedure

-  In the pattern editor, highlight the cell of the event name, then right-click the event name, and select Rename Event. The Rename Event dialog pops up.
-  Type the new name.  ![Renaming an event](<../../../../raw/113743.png>)
-  To continue:

  - If you want to rename the event and all related test points in one step, make sure the "Update test points" option is selected (default), and click Finish.
  - If you want to exclude individual test points from renaming, click Next and continue.
  - If you want to rename the event only, but none of the test points, clear the "Update test points" check box, and click Finish.

-  To exclude individual test points from renaming, in the second step of the dialog, clear the check boxes of the test points you Do not want to rename, and click Finish.  ![Renaming individual test points](<../../../../raw/113745.png>)

## Results

The selected events and test points are renamed. Any test point left without reference to an existing event is highlighted in the pattern editor.

 ![Test point without reference to an event](<../../../../raw/113752.png>)

## What to do next

Make sure all test points refer to an event.
