# Cooling requirements

Cooling unit E2760FU Small liquid-liquid cooling unit
 |

Cooling capability

 |

6.6 kW @ 30°C regulated secondary water temperature

 |
 |

Cooling medium

 |

De-ionized water

 |
 |

Primary chilled water temperature range

 |

5°C to 20°C (41°F to 68°F)

 |

- For use with one A-test head.

Cooling unit E2760FAL Liquid-liquid cooling unit for compact and small test heads
 |

Cooling capability

 |

28 kW @ 30°C regulated secondary water temperature

 |
 |

Cooling medium

 |

De-ionized water

 |
 |

Primary chilled water temperature range

 |

5°C to 20°C (41°F to 68°F)

 |

- For use with one small / compact test head.

Cooling unit E2760FC Large liquid-liquid cooling unit mainframe
 |

Cooling capability

 |

56 kW @ 30°C regulated secondary water temperature

 |
 |

Cooling medium

 |

De-ionized water

 |
 |

Primary chilled water temperature range

 |

5°C to 20°C (41°F to 68°F)

 |

- Recommended program value of secondary water temperature: 30°C.
- Large test head distribution unit (E2760FD) for use with one large test head.
- Quad-density distribution and interface unit for four cooler hose pairs (E2760FQ) for use with up to four compact test heads with independent shut down of test heads for repair or maintenance.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.0: Replaced cooling unit E2760FA with E2760FU and E2760FAL
