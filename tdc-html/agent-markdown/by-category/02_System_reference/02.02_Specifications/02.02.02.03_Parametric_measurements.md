Direct DVM Access (at utility pogo block)

- Supported DMM: Keysight 3458A with option 002
- Absolute voltage measurement accuracy: ±40µV + DMM specification
- Input voltage range: -5 V to 7.5 V

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.0: Added A-test head
- SmarTest 7.3.2: Added direct DVM access specification
[1)](<#fnsrc_1>) Over-programming up to +8 V.[2)](<#fnsrc_2>) Add ±(Ia * R) if connected through digital pin. Ia is the actual current; R is the wiring resistance of the digital channel. See specification of [digital card](<02.02.04_Digital_Cards.md>) for potential additional card-specific terms.
