## Eye height

Eye height is measured with the following figures:

- Vswing = 500 mV into 50 Ωat a single connection (single-ended signaling)
- Vswing = 1000 mV into 100 Ωat a pair of legs (differential signaling).

For a graphical representation refer to [Pin Scale 5000 terms](<02.02.04.03.14_Pin_Scale_5000_terms.md>).
