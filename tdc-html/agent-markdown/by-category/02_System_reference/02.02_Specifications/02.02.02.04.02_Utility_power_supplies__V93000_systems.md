# Utility power supplies (V93000 systems)

The utility power supplies support DUT boards with additional active components. Typical examples for these active components are relays, switches, operational amplifiers, and buffers.

## Overview

Three utility power supplies featuring different voltage and current capabilities are available on V93000 systems.

 | Voltages  | Interface  | V93000 systems |
 | +5 V  | UP5V pin on all utility blocks  | [Internal utility power supply](<02.02.02.04.02_Utility_power_supplies__V93000_systems.md#_346945__s_Internal_utility_supply_V93000_systems>) |
 | +5 V, +3.3 V, -5 V  | XP... pins on all 4-row utility blocks  | [External utility power supply](<02.02.02.04.02_Utility_power_supplies__V93000_systems.md#_346945__s_External_utility_power_supply_V93000_systems>) |
 | +5 V, +12 V, +15 V, -15 V  | DPS pogo block  | [Internal Utility Power Supply (SE-UDPS)](<02.02.02.04.02_Utility_power_supplies__V93000_systems.md#_346945__s_SE-UDPS_V93000_systems>) |

## Internal Utility Power Supply (SE-UDPS) (E7002US)

The optional "Internal Utility Power Supply (SE-UDPS)" is a product from Salland Engineering (Europe) BV. The SE-UDPS is routed to a 3-row DPS-slot pogo block.
