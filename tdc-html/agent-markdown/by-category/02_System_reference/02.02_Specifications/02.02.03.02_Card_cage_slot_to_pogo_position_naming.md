# Card cage slot to pogo position naming

With the introduction of pogo mapping (supported with SW rev. 5.2.7 and higher) the "Card Cage" slot and DUT board "pogo locations" is not a fixed relationship anymore.

Board and pogo locations are therefore documented as shown in the following example:

- "Pogo slot 101/102" means: group 1, pogo location 101/S1 and 102/S1  ![Card cage to pogo slot assignment 1](<../../../../raw/98104.png>)
- "Board slot 3-1" means: card cage 3, slot 1 ![Card cage to pogo slot assignment 2](<../../../../raw/98105.png>)
