# Card compatibility

## Basic Smart Scale configuration rules

The rules defined below do not apply to V93000 EXA Scale systems. The rules defined below apply only to V93000 Smart Scale systems.

The V93000 power system requires that the adjacent slots (even/odd slot) in the card cages MUST be filled with the same type of card. For details which card can pair up with which other card please refer to the tables below. (x = cards can sit side-by-side)

 |   | Pin Scale  | DC Scale |
 | 1600(A/B)  | DPS128  | UHC4T |
 | Pin Scale 1600(A/B)  | X[1)](<#fntarg_1>)  |   | |
 | DC Scale DPS 128  |   | X  | |
 | DC Scale UHC4T  |   |   | X  |    [1)](<#fnsrc_1>) We strongly recommend configuring pure PS1600A or PS1600B systems only, and not mixing them in a test head. The reason for this recommendation is easier fleet management at OSAT service providers. Here, systems are often configured as super set configuration to serve many devices and customers, and a mix of A and B cards makes super set configurations very challenging, if not impossible. Advantest standard configuration rules do not support mixing because of this reason.
