# Pin Scale 1600B Digital Card

The PS1600 Rev. B supersedes the PS1600 Rev. A and features 224 MB max. memory versus 112 MB of the PS1600A. All other specifications are identical with [Pin Scale 1600](<02.02.04.01_PS1600_specifications.md>).
