# Smart Scale device power supplies

Supported channel slot device power supplies
 | Maximum channel count  | CX test head  | SX test head  | LX test head |
 | Number of slots  | 9  | 18  | 27 |
 | DC Scale DPS128-HC (E8023CS)  | 1152  | 2048[1)](<#_347656__fn_DPS128>)  | 2048[1)](<#_347656__fn_DPS128>) |
 | DC Scale DPS64-HC (E8023CSH)  | 576  | 1152  | 1728 |
 | DC Scale UHC4T (E8024UH)  | 36  | 72  | 108 |
 | DC Scale XPS256  | 2304  | 4096[2)](<#_347656__fn_XPS256>)  | 4096[2)](<#_347656__fn_XPS256>)  |   Note

Mixing different device power supply types within one Test Head is supported.

Refer to DC Scale device power supply specification sheet for more information.
