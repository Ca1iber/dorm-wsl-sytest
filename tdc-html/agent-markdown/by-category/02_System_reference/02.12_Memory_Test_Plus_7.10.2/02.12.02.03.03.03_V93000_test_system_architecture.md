# V93000 test system architecture

#### Subtopics

- [Word versus pin slice](<02.12.02.03.03.03.01_Word_versus_pin_slice.md>)

The V93000 test system architecture is able to execute both vector-based patterns and algorithmic patterns. The test system is able to interleave the execution of the two types of patterns without changing the hardware resource being used to source the pattern. This enables a change between the two types of patterns without causing dead cycles to occur.

The V93000 test system is designed with a per-pin architecture where each channel of the test system has its own timing and level generating resources. Each test system channel also has its own memory that can be used to store vector-based information. The figure below shows a functional diagram of the per-pin architecture.

  ![Per-pin architecture](<../../../../raw/67624.png>)

In a test system with a hardware APG, a program could be written that loads the address register with 0 and then increments the register 7 times to produce the eight addresses (0-7). In the per-pin test system we could continue to use the channel memory as vectors and store the binary code for each channel from the table.

The figure below shows that the eight cycles of information fits easily in the channel memory of each address pin.
