# convertTestflow

#### Subtopics

- [Converting MTP testflows to UTM](<02.12.04.06.01_Converting_MTP_testflows_to_UTM.md>)

The convertTestflow tool is a script that converts classic testflows to UTM-based testflows. This conversion is required if you want to use testflows that include classic test methods to testflows using universal test methods (UTM).

While the standard SmarTest installation contains a version of this tool, a special MTP version is required for converting MTP testflows.

Therefore, make sure to always use the version of convertTestflow at /opt/93000mts/mts/utilities/bin. Never use the version at /opt/hp93000/soc/testmethod/bin to convert MTP testflows.

Converting MTP testflows is described in [Converting MTP testflows to UTM](<02.12.04.06.01_Converting_MTP_testflows_to_UTM.md>).

## Functional changes

- Introduced in MTP 3.0.1
