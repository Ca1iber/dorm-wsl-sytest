# Pattern List File

It is possible to save and load a pattern list file containing several pattern files. Therefore two buttons are introduced in the MTL Compiler Control dialog window.

## Benefit

Maintaining many test patterns in a single file.

## More Info

For further details, see [MTL Compiler Control dialog](<02.12.03.02.04.01_MTL_Compiler_Control_dialog.md>).
