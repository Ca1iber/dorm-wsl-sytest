# DPS Sharing Diagnostic

#### Subtopics

- [Using DPS Sharing Diagnostic](<02.12.04.07.01_Using_DPS_Sharing_Diagnostic.md>)
- [DPS Sharing Diagnostic test scopes](<02.12.04.07.02_DPS_Sharing_Diagnostic_test_scopes.md>)
- [Diagnostic configuration file](<02.12.04.07.03_Diagnostic_configuration_file.md>)

DPS Sharing Diagnostic is a tool to test and diagnose the electronics of a DPS-sharing load board, such as relay, cabling and control circuit.

DPS Sharing Diagnostic is installed as part of MTP on HSM in /opt/93000mts/mts/utilities/bin/shared_dps_diag. It is not available in MTP on SOC.

## Functional changes

- Introduced in MTP 3.0.3
