The SHARED_IDD_TEST class provides an API for measuring the IDD and IDDQ for the DUTs with [driver sharing](<02.12.02.05.06.07.01_Driver_sharing_concepts.md>). It tests shared and non-shared pins.

When you use this API to create your own custom test method, you should:

- Add either or both of the following limits according to the requirement:

  - "IDD(VDD), [mA]": Defines the minimum and maximum IDD current in (mA).
  - "IDDQ(VDDQ), [mA]": Defines the minimum and maximum IDDQ current in (mA).

For how to add limits and their values to a test method, see [How to create a universal test method class](<../02.07_Test_Method_Reference/02.07.02.02.02_How_to_create_a_universal_test_method_class.md>).

- Include the driver sharing API library and header file to complete a test method code. For details, see [Setting up for using driver sharing APIs](<02.12.02.05.06.07.09.04_Setting_up_for_using_driver_sharing_APIs.md>).
Note The SHARED_IDD_TEST API is available only for MTP.

There are two other methods to check the shared IDD:

- A [SharedIDD test method](<02.12.02.05.06.07.09.14_SharedIDD_syntax.md>) included with MTP: Use it when you Do not have special requirements such as a customized testing algorithm or a special output format. See [SharedIDD syntax](<02.12.02.05.06.07.09.14_SharedIDD_syntax.md>).

It is the easiest way to develop a test.

- The [MTP_IDD_TASK](<02.12.06.13_MTP_IDD_TASK.md>) API: Use it when you want to test the pins (either for IDDs or IDDQs) with different test conditions in one test method.

More differences between the SharedIDD test method, SHARED_IDD_TEST, and MTP_IDD_TASK are described in [MTP_IDD_TASK](<02.12.06.13_MTP_IDD_TASK.md>).

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/SHARED_IDD_TEST.h.

## Examples

### Note

The following examples demonstrate how to use this API within a test method. If you want to see a complete test method code via SHARED_IDD_TEST, find it in /opt/93000mts/mts/solution_tools/common/sh_lib/DriverSharing.tar.gz.

### Example 1

Measuring both IDD and IDDQ.

```
#include "solution_tools.h"
#include "testmethod.hpp"
#include "mapi.hpp"

class CSharedIDD: public testmethod::TestMethod
{
    virtual void run()
    {
      ON_FIRST_INVOCATION_BEGIN();
      {
        // Always do initialization at the beginning of test
        mTest.init();

        // hand over the parameters to the test class
        mTest.sharingConfigFile("default.cfg")
             .vdd("VDD")
             .vddq("VDDQ")
             .resetPin("RESETn")
             .waitTime(10);

        // execute the test
        mTest.execute();
      }
      ON_FIRST_INVOCATION_END();

      // set result
      mTest.judgeAndLog();
      // Print out in the UI Report Window.
      mTest.print();
    }

private:
    SHARED_IDD_TEST mTest;
};
```

### Example 2

Customizing output.

```
#include "solution_tools.h"
#include "testmethod.hpp"
#include "mapi.hpp"

class CSharedIDD: public testmethod::TestMethod
{
    virtual void run()
    {
      ON_FIRST_INVOCATION_BEGIN();
      {
        // Always do initialization at the beginning of test
        mTest.init();

        // hand over the parameters to the test class
        mTest.sharingConfigFile("default.cfg")
             .vdd("VDD")
             .vddq("VDDQ")
             .resetPin("RESETn")
             .waitTime(10);

        // execute the test
        mTest.execute();
      }
      ON_FIRST_INVOCATION_END();

      // set result
      mTest.judgeAndLog();
      // Print out in the UI Report Window.
      cout << "Test result of site " << CURRENT_SITE_NUMBER() << ": " << mTest.getPassFail() << endl;

      cout << "PIN (" << "VDD" << ")\t" << mTest.getPassFail("VDD") << "\t" << mTest.getValue("VDD") << endl;
      cout << "PIN (" << "VDDQ" << ")\t" << mTest.getPassFail("VDDQ") << "\t" << mTest.getValue("mVDDQ") << endl;
    }

private:
    SHARED_IDD_TEST mTest;
  };
```
