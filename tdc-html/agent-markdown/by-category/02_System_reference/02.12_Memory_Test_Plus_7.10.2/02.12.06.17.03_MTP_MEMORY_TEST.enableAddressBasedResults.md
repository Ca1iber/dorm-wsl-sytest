# MTP_MEMORY_TEST.enableAddressBasedResults()

The enableAddressBasedResults() member function of [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) lets you switch on and off the creation of address-based results.

This is an optional method.

## Syntax

```
MTP_MEMORY_TEST& enableAddressBasedResults(const bool status)
```

 |

Parameter

 |

Description

 |
 |

status

 |

This parameter is used to activate or deactivate the generation of address-based results:

- true: The test generates address-based results.
- false: The test does not generate address-based results.

The default is false.

 |

## Example

Switching on address-based results:

```
MTP_MEMORY_TEST memoryTest();
memoryTest.enableAddressBasedResults(true);
```
