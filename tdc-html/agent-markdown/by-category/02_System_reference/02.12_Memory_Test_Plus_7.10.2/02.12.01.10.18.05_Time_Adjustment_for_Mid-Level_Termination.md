# Time Adjustment for Mid-Level Termination

Some devices (for example DDR devices) need for correct operation mid-level termination during read cycles: prior to the state where the device sends out data its driving pins need to be mid-level terminated on the receiving side.

For more information refer to Time adjustment for mid-level termination in Testing High-Speed Memory Devices.
