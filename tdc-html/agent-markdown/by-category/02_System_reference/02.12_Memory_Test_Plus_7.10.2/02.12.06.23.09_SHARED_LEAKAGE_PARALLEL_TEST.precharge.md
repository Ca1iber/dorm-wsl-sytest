# SHARED_LEAKAGE_PARALLEL_TEST.precharge()

The precharge() member function of [SHARED_LEAKAGE_PARALLEL_TEST](<02.12.06.23_SHARED_LEAKAGE_PARALLEL_TEST.md>) enables or disables the precharge to the non-shared and cross-terminated pins.

 Note The shared pins are independent of this member function. Shared pins are automatically precharged to the force voltage via PPMU by the [SharedLeakageParallel test method](<02.12.02.05.06.07.09.11_SharedLeakageParallel_test_method.md>).

## Syntax

```
SHARED_LEAKAGE_PARALLEL_TEST& precharge(MTP::OPTION_TYPE option)
```

 |

Parameter

 |

Description

 |
 |

option

 |

MTP::OPTION_YES or MTP::OPTION_NO.

- MTP::OPTION_YES: Enables precharging to non-shared and cross-terminated pins.
- MTP::OPTION_NO (default): Disables precharging to non-shared and cross-terminated pins.Note For setting the precharge-voltage values to non-shared and cross-terminated pins, see the [prechargeVoltage()](<02.12.06.23.10_SHARED_LEAKAGE_PARALLEL_TEST.prechargeVoltage.md>) member function.
 |
