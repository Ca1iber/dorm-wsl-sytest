# SHARED_LEAKAGE_PARALLEL_TEST.prechargeTime()

The prechargeTime() member function of [SHARED_LEAKAGE_PARALLEL_TEST](<02.12.06.23_SHARED_LEAKAGE_PARALLEL_TEST.md>) lets you specify the duration time for precharging.

## Syntax

```
SHARED_LEAKAGE_PARALLEL_TEST& prechargeTime(double time)
```

 |

Parameter

 |

Description

 |
 |

time

 |

The precharing duration.

- The unit is second [S].
- The default duration time value is 0 S.
 |

## Example

```
SHARED_LEAKAGE_PARALLEL_TEST mTest;
mTest.prechargeTime(10);
mTest.execute();
```
