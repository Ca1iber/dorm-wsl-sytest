# Converting MTP testflows to UTM

Testflows written with classic test methods must be converted before they can be used in MTP 3.0, as described in [convertTestflow](<02.12.04.06_convertTestflow.md>).

## Procedure

-  Convert all user-written test methods used in the testflow to UTM as described in [How to convert a classic test method project to universal test method project](<../02.07_Test_Method_Reference/02.07.02.04.01_How_to_convert_a_classic_test_method_project_to_universal_test_method_pr.md>).
-  Convert the testflow itself using the procedure described in [How to convert a classic testflow to universal-test-method-based testflow](<../02.07_Test_Method_Reference/02.07.02.06.01_How_to_convert_a_classic_testflow_to_universal-test-method-based_testflo.md>). However, instead of the convertTestflow tool at /opt/hp93000/soc/testmethod/bin, use the convertTestflow tool at /opt/93000mts/mts/utilities/bin.

## Functional changes

- Introduced in MTP 3.0.1
