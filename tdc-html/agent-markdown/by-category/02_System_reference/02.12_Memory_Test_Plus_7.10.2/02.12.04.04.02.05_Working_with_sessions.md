# Working with sessions

#### Subtopics

- [Creating, saving and restoring sessions](<02.12.04.04.02.05.01_Creating__saving_and_restoring_sessions.md>)

A range of settings of the BFM Viewer are tied to sessions. Closing a session - for example, by exiting the BFM Viewer or switching the device - discards those settings. However, you can save sessions to store and re-use the settings, basically allowing you to continue where you stopped.

These settings in the BFM Viewer are specific to a session:

- The assignment of bit fail maps to layers in the [Bit Fail Maps tab](<02.12.04.04.03.02.01.01_Bit_Fail_Maps.md>).

Note, however, that the bit fail maps assigned to layers are not actually loaded when a session is opened.

Note, too, that the actual bit fail map data is not saved as part of the session. This means that the BFM Viewer cannot access the fail data when a map file referenced in the session has been moved or deleted. Appropriate error messages are displayed in the BFM Layer Assignment list in the [Bit Fail Maps tab](<02.12.04.04.03.02.01.01_Bit_Fail_Maps.md>) or in the [Messages tab](<02.12.04.04.03.02.01.06_Messages.md>).

- [Detail views](<02.12.04.04.03.02.01.02.01_Detail_view.md>) and the [analysis area](<02.12.04.04.02.04.03_Specifying_an_analysis_area.md>).
- [Marked cells](<02.12.04.04.02.04.04_Marking_and_unmarking_cells.md>).
- The colors assigned to the various elements in the [Colors tab](<02.12.04.04.03.02.01.05_Colors.md>).
- The filter rules and conditions specified in the [Filters tab](<02.12.04.04.03.02.01.04_Filters.md>).

These settings are lost when you exit the BFM Viewer or close a session, for example, by switching to a different device. To keep them, you can store the session in a file, as described in [Creating, saving and restoring sessions](<02.12.04.04.02.05.01_Creating__saving_and_restoring_sessions.md>). Such files can then be reloaded when you want to resume the session, restoring all the saved settings.

 Note Working with sessions is not possible in [Autoload mode](<02.12.04.04.02.03.01_Loading_bit_fail_maps_automatically.md>).
