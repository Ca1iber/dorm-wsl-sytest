# SHARED_CONTINUITY_TEST.execute()

The execute() member function of [SHARED_CONTINUITY_TEST](<02.12.06.21_SHARED_CONTINUITY_TEST.md>) lets you execute a shared continuity test based on your previous setup.

## Syntax

```
void execute() const
```

## Example

```
SHARED_CONTINUITY_TEST mTest;
mTest.execute();
```

[SHARED_CONTINUITY_TEST](<02.12.06.21_SHARED_CONTINUITY_TEST.md>)
