# MTP_MEMORY_PORT.generateBitMapFile()

Generates fail bit map files (.bfd files) for the patterns in the current port.

The port is specified with the [getMemoryPort()](<02.12.06.17.08_MTP_MEMORY_TEST.getMemoryPort.md>) function of the [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) class.

## Syntax

```
void generateBitmapFile () const;
```

Return value

There is no return value.

## Related information

[MTP_MEMORY_PORT.getMemoryPattern()](<02.12.06.16.01_MTP_MEMORY_PORT.getMemoryPattern.md>)

## Functional changes

- Introduced in MTP 3.2.1
