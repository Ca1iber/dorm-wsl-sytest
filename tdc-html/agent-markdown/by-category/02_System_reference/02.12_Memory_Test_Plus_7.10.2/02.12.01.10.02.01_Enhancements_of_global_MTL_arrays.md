# Enhancements of global MTL arrays

Instead of defining global MTL array as constant tables outside of any functions, the global MTL arrays now can be initialized or assigned integer values in the main() function or a subroutine before the arrays are first used in accessing the array's elements and passing the array to functions or device accesses.
