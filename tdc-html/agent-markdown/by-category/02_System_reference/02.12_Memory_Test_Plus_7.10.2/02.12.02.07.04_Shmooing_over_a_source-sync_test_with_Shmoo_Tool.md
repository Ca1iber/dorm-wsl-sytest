# Shmooing over a source-sync test with Shmoo Tool

#### Subtopics

- [Performing customized source-sync shmoo tests with the shmoo tool](<02.12.02.07.04.01_Performing_customized_source-sync_shmoo_tests_with_the_shmoo_tool.md>)

On the shmoo tool, to shmoo over a source-sync test, you must first create a source-sync test suite either with [the MTP provided source-sync test method](<02.12.02.05.06.06.02.05.01_SourceSync_fast_mode.md>) or with the [SOURCESYNC_TEST](<02.12.06.29_SOURCESYNC_TEST.md>) API. Then, you shmoo over this test suite on the shmoo tool.

## About this task

Note The source-sync feature is available only with MTP.

Comparing with the conventional shmoo over source-sync method that is configuring the shmoo parameters in the MTP provided source-sync test method, which will display a textual two-dimensional shmoo plot only on the UI report window with shmooing on spec variables and showing results for domain and for the margin min/max/mean/sigma values only, Shmoo Tool will:

- Display a colorful vivid and operable shmoo plot for you to observe.
- On the tool, you can easily change the shmoo conditions and manipulate the shmoo plot such as zooming and saving.
- On the tool, you can [perform fast shmoo](<../02.08_Setup_and_Result_Tools/02.08.04.25.04.02_Commands_in_the_menu_bar_and_the_shortcuts_in_the_toolbar.md>).
- If you use APIs ([SOURCESYNC_TEST](<02.12.06.29_SOURCESYNC_TEST.md>), [judgeAndLog](<../02.07_Test_Method_Reference/02.07.04.01.244_TESTSET.md>), [SHMOO_RESULT](<../02.07_Test_Method_Reference/02.07.04.01.227_SHMOO_RESULT.md>) and etc.) to define your own source-sync test suite, you can view more results other than the domain results and margin min/max/mean/sigma values on the shmoo plot.

The only drawback of shmooing over a source-sync test suite on the shmoo tool is it will take longer time during the multi-site shmoo than the conventional source-sync shmoo. To overcome this, see [Performing customized source-sync shmoo tests with the shmoo tool](<../02.07_Test_Method_Reference/02.07.07.04_Performing_customized_source-sync_shmoo_tests_with_the_shmoo_tool.md>), which is an advanced usage requiring your mastering both C++ and SmarTest.

## Before you begin

In your testflow, set up a source-sync test suite either with [the MTP provided source-sync test method](<02.12.02.05.06.06.02.05.01_SourceSync_fast_mode.md>) or with the [SOURCESYNC_TEST](<02.12.06.29_SOURCESYNC_TEST.md>) API.

## Procedure

-  On the shmoo tool, set up shmoo over a test suite as described in [Setting up a shmoo test on the Shmoo Tool](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>) with the following notifications:

  - In the Testmethod field, choose the [ac_tml.AcTest.Shmoo](<../02.07_Test_Method_Reference/02.07.05.01.09_Shmoo.md>) test method.
  - In the shmooTestSuite filed, only select the source-sync test suite you want to shmoo on.
  - In the testMode filed, do select user defined measurement.

-  On the shmoo tool, [execute this shmoo test](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.03_Executing_shmoo_tests_with_the_Shmoo_Tool.md>).

A shmoo plot shows up on the shmoo tool. The texts above the plot indicate the name (test mode), pins and site of the result currently displayed on the plot.

-  To view the shmoo plot of another result, right-click the shmoo plot, select Test Modes and select the interested result name.

Note that:

  - If the test suite is set up with [the MTP provided source-sync test method](<02.12.02.05.06.06.02.05.01_SourceSync_fast_mode.md>), the available test modes you can select are for the margin min/max/mean/sigma values and domain results.
  - If the test suite is set up with APIs ([SOURCESYNC_TEST](<02.12.06.29_SOURCESYNC_TEST.md>), [judgeAndLog](<../02.07_Test_Method_Reference/02.07.04.01.244_TESTSET.md>), and [SHMOO_RESULT](<../02.07_Test_Method_Reference/02.07.04.01.227_SHMOO_RESULT.md>)), the available test modes are the results defined with the judgeAndLog and SHMOO_RESULT APIs. For details, see [Viewing the test results of a test suite on the shmoo plot](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.04.05_Viewing_the_test_results_of_a_test_suite_on_the_shmoo_plot.md>).

-  To view the shmoo plot of another result pin, right-click the shmoo plot, select Result Pins and select the interested pin.

Note that:

  - If the test suite is set up with [the MTP provided source-sync test method](<02.12.02.05.06.06.02.05.01_SourceSync_fast_mode.md>), the available pins you can select are the pins you set up for the SourceSyncPinGroups parameter.
  - If the test suite is set up with APIs ([SOURCESYNC_TEST](<02.12.06.29_SOURCESYNC_TEST.md>), [judgeAndLog](<../02.07_Test_Method_Reference/02.07.04.01.244_TESTSET.md>) and [SHMOO_RESULT](<../02.07_Test_Method_Reference/02.07.04.01.227_SHMOO_RESULT.md>)), the available result pins are the ones defined with the judgeAndLog and SHMOO_RESULT APIs. For details, see [Viewing the test results of a test suite on the shmoo plot](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.04.05_Viewing_the_test_results_of_a_test_suite_on_the_shmoo_plot.md>).

-  To view the shmoo plot of another site, see [Viewing shmoo plots of different sites](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.04.07_Viewing_the_shmoo_plots_of_different_sites.md>).
-  To perform fast shmoo, right-click the plot and select the Run Fast command.

Alternatively, click the ![fast execution button in the Shmoo Tool](<../../../../raw/136389.png>) shortcut on the toolbar of SmarTest. For details, see [Commands on the menu bar and their shortcuts on the toolbar](<../02.08_Setup_and_Result_Tools/02.08.04.25.04.02_Commands_in_the_menu_bar_and_the_shortcuts_in_the_toolbar.md>).

-  To manipulate the plot, such as zooming, right-click the shmoo plot and select a corresponding command from the shortcut menu.

See the available commands in [Commands in the shmoo editor of the Shmoo Tool](<../02.08_Setup_and_Result_Tools/02.08.04.25.04.03_Commands_in_the_shmoo_editor_of_the_Shmoo_Tool.md>).

## Results
