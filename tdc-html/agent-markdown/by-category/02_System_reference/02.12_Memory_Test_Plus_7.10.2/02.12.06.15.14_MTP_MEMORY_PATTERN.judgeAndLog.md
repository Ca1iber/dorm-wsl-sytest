# MTP_MEMORY_PATTERN.judgeAndLog()

Judges and logs the memory test results of the current pattern that is specified with [getMemoryPattern()](<02.12.06.16.01_MTP_MEMORY_PORT.getMemoryPattern.md>).

## Syntax

```
void judgeAndLog () const;
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Related information

[MTP_MEMORY_PORT.getMemoryPattern()](<02.12.06.16.01_MTP_MEMORY_PORT.getMemoryPattern.md>)

## Functional changes

- Introduced in MTP 3.2.1
