- [Defining memory test patterns with multiple data words](<02.12.02.04.01.01_Defining_memory_test_patterns_with_multiple_data_words.md>)

The following basic elements need to be defined for a memory test pattern.

- [Define the address stepping sequence](<02.12.02.04.01.02_Define_the_address_stepping_sequence.md>).
- [Define the memory device operations performed on each step](<02.12.02.04.01.03_Define_the_memory_device_operations_performed_on_each_step.md>).
- [Define the dataword used by each operation](<02.12.02.04.01.04_Define_the_data_word_used_by_each_operation.md>).
- [Define the data sequencing](<02.12.02.04.01.05_Define_the_data_sequencing.md>) (for example solid or checkerboard).
- [Defining memory test patterns using x-modes](<02.12.02.04.02_Defining_memory_test_patterns_using_x-modes.md>).
- [Defining memory test patterns for devices with data latency](<02.12.02.04.01.06_Defining_memory_test_patterns_for_devices_with_data_latency.md>).
- [Defining memory test patterns for devices with a burst data mode](<02.12.02.04.01.07_Defining_memory_test_patterns_for_devices_with_a_burst_data_mode.md>)

The memory test language syntax supports the definition of each of the elements listed above.
