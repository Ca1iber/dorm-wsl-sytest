# MTP De-Installation

A de-install shell script for all MTP tools is part of the Linux Recovery DVD.

## Benefit

It is much more comfortable to remove the whole MTP tool package at once instead of removing every component one by one.

## More Info

For details see Removing an installed Version in System Controller and Software Installation Guide.
