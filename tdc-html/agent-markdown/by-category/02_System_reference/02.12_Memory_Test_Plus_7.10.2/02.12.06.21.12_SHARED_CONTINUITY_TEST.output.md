# SHARED_CONTINUITY_TEST.output()

The output() member function of [SHARED_CONTINUITY_TEST](<02.12.06.21_SHARED_CONTINUITY_TEST.md>) lets you choose where to display the output, either from the UI report window, or none.

## Syntax

```
SHARED_CONTINUITY_TEST& output(MTP::OUTPUT_TYPE output)
```

 |

Parameter

 |

Description

 |
 |

output

 |

The place to show the output, either none or UI report window.

Accordingly, the output types are:

- MTP::OUTPUT_NONE.
- MTP::OUTPUT_REPORT_UI
 |

## Example

```
SHARED_CONTINUITY_TEST mTest;
mTest.output(MTP::OUTPUT_REPORT_UI);
mTest.ouput(MTP::OUTPUT_NONE);
```
