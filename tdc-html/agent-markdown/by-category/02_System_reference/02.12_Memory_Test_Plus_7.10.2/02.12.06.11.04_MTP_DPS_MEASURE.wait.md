# MTP_DPS_MEASURE.wait()

The wait() member function of [MTP_DPS_MEASURE](<02.12.06.11_MTP_DPS_MEASURE.md>) lets you specify the wait time before the measurements.

## Syntax

```
MTP_DPS_MEASURE & wait(DOUBLE waitTime_s)
```

 |

Parameter

 |

Description

 |
 |

waitTime_s

 |

The wait time before the measurements.

The unit is second ([s]).

 |
