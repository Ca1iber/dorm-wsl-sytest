# SOURCESYNC_SUB_TEST.repeatEdgeInterval()

Specifies how many edges will be omitted between every two adjacent edges to be shown on an error map. Use it together with [SOURCESYNC_SUB_TEST.repeatEdgeLength()](<02.12.06.28.06_SOURCESYNC_SUB_TEST.repeatEdgeLength.md>) and [SOURCESYNC_SUB_TEST.repeatEdgeOffset()](<02.12.06.28.05_SOURCESYNC_SUB_TEST.repeatEdgeOffset.md>) to specify which edges will be printed out on an error map.

## Syntax

```
SOURCESYNC_SUB_TEST& repeatEdgeInterval (const int interval);
```

Parameter
 |

Parameter

 |

Description

 |
 |

interval

 |

The number of edges to be omitted between two adjacent edges on an error map.

The default number is 0, which leads to the output of every edge on an error map. When the interval is 0, the setups for [RepeatEdgeOffset](<02.12.06.28.05_SOURCESYNC_SUB_TEST.repeatEdgeOffset.md>) and [RepeatEdgeLength](<02.12.06.28.06_SOURCESYNC_SUB_TEST.repeatEdgeLength.md>) are ignored.

 |
