# MTP_MEMORY_TEST.setRAExecutionName()

Assigns a name to the test suites sharing the same redundancy analysis.

The test suites can be in different testflows.

All test suites belonging to the same redundancy analysis must have the same redundancy analysis execution name.

## Syntax

```
MTP_MEMORY_TEST& setRAExecutionName (const STRING & execution_name);
```

Parameter
 |

Parameter

 |

Description

 |
 |

execution_name

 |

The name which you give for the test suites sharing the same redundancy analysis.

The default name is RAStd.

 |

Return value

There is no return value.

## Functional changes

- Introduced in MTP 3.2.1
