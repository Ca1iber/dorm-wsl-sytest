# MTP_DPS_MEASURE.execute()

The execute() member function of [MTP_DPS_MEASURE](<02.12.06.11_MTP_DPS_MEASURE.md>) executes the DPS measurement with the test conditions set with the [pin()](<02.12.06.11.01_MTP_DPS_MEASURE.pin.md>), [execMode(](<02.12.06.11.02_MTP_DPS_MEASURE.execMode.md>)), and [samples()](<02.12.06.11.03_MTP_DPS_MEASURE.samples.md>) member functions.

## Syntax

```
virtual void execute() [virtual]
```
