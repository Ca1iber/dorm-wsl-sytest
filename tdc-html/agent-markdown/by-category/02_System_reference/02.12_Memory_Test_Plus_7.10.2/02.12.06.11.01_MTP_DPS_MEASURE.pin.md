# MTP_DPS_MEASURE.pin()

The pin() member function of [MTP_DPS_MEASURE](<02.12.06.11_MTP_DPS_MEASURE.md>) lets you specify the DPS pins you want to measure. pin() returns the [DPS_PIN_TASK](<../02.07_Test_Method_Reference/02.07.04.01.50.01_DPS_PIN_TASK.md>) class object which you use to set up the measurement conditions for these pins.

## Syntax

```
[DPS_PIN_TASK](<../02.07_Test_Method_Reference/02.07.04.01.50.01_DPS_PIN_TASK.md>) & pin(const STRING & pinname)
```

 |

Parameter

 |

Description

 |
 |

pinname

 |

The names of the DPS pins to be measured.

The different DPS pins are separated by commas.

 |
