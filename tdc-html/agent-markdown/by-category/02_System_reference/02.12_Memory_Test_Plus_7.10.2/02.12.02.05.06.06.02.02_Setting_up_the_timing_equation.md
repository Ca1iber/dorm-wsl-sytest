# Setting up the timing equation

The Multi-Strobe test methods require a set of specification variables. Add a timing equations set for the test method as described below, to declare and use those variables.

## Procedure

-  Open the timing equations using the timing equation editor.
-  Scroll to the section starting with the text:

```
EQNSet 3 "HSM3600 MultiStrobe"
```

-  Add the specification variables to the SPECS section in the `MultiStrobe ` timing equation file, for example:

```
Tsweep [ns]
TDQSQmin [ns]
TDQSQmax [ns]
```

The file may now look like this:

```
EQNSET 3 "MultiStrobe"

MODECONTEXT "HsmMode"

SPECS # starts the declaration of the specs
tCK   [ns] # NOTE: no checks are performed on the base of the unit
tAS_offset [ns]
tDS_offset [ns]
tCS_offset [ns]
tAC_offset [ns]
tDQSCK_offset [ns]
WL # write latency
CL # column latency
AL # additive latency note: CAS = CL + AL
refresh_time [ms]
tsweep [ns]
tDQSQmax [ns]
tDQSQmax [ns]

EQUATIONS
refresh_ns = 1000000 * refresh_time
tIS_Addr = (tCK/4)
...
TIMINGSET 1 "basic"
period=4*tCK
maintop_time_a= refresh_ns
# ------------------------------------------
#                  Clock Pins
# ------------------------------------------
PINS Clock_Bus
...
# ------------------------------------------
#   Output Data Pin and Data Strobe Pins
# ------------------------------------------
PINS DQ_Bus
period_div = 8
r1= tAC_DQ + tAC_offset + RL_tCK + tsweep + tDQSQmax

PINS RDQS_Bus
period_div = 8
r1=  tAC_DQ + tDQSCK_offset + RL_tCK + tsweep + tDQSQmin
# ------------------------------------------
#                 OTHER Pin
# ------------------------------------------
PINS Reset_Pin Vref_Pin
period_div = 8
d1= 0
```

-  In the timing equation file, add the specification variables to the PINS DQ_Bus and PINS RDQS_Bus output pin definitions. (See code example above.)

In this example, all pin timings are varied using the same variable. You may modify this in your application by declaring a tsweep variable for each byte of the data bus.

-  To save the modified timing equation file, choose Shell > Download. Then close the file.

## Results

The timing equations for measuring tDQSQmin and tDQSQmax are now prepared.
