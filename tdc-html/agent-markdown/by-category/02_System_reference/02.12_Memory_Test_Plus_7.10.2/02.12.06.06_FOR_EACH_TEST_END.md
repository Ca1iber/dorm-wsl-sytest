# FOR_EACH_TEST_END

FOR_EACH_TEST_END() works together with [FOR_EACH_TEST_BEGIN()](<02.12.06.04_FOR_EACH_TEST_BEGIN.md>) or [FOR_EACH_TEST_BEGIN_WITH_RESET()](<02.12.06.05_FOR_EACH_TEST_BEGIN_WITH_RESET.md>) as a pair to declare a block to test the shared sites.

For details, see [FOR_EACH_TEST_BEGIN()](<02.12.06.04_FOR_EACH_TEST_BEGIN.md>) and [FOR_EACH_TEST_BEGIN_WITH_RESET()](<02.12.06.05_FOR_EACH_TEST_BEGIN_WITH_RESET.md>).

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/SHARED_UTIL.h.

## Syntax

```
FOR_EACH_TEST_END()
```
