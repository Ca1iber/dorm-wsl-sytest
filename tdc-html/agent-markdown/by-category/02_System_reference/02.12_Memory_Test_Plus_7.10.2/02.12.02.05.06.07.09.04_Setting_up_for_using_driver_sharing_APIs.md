# Setting up for using driver sharing APIs

To use driver sharing APIs, you must include the API header file and the API library to the test method property.

## About this task

Note From MTP 3.3.2, using [Driver Sharing APIs](<02.12.02.05.06.07.09.03_Driver_Sharing_APIs.md>) does not require these pre-settings as described in this topic. After installing MTP 3.3.2 and restarting the computer, the pre-settings will be automatically set up.

You should do the following settings when you use the [Driver Sharing APIs](<02.12.02.05.06.07.09.03_Driver_Sharing_APIs.md>).

## Before you begin

Make Sure:

- [A universal test method project is created.](<../02.07_Test_Method_Reference/02.07.02.02.01_How_to_create_a_universal_test_method_project.md>)
- SmarTest is open with MTP tape installed.

## Procedure

-  In Project Explorer, right-click the test method project you have created and choose Properties from the shortcut menu.

The properties dialog is displayed.

-  In the left-hand sidebar, click C/C++ Build > Settings.
-  In the Tool Settings tab, click GCC C++ Compiler > Directories.
-  Add the path of the API header file to the Include paths field: /opt/93000mts/mts/solution_tools/common/include.
-  In the Tool Settings tab, click GCC C++ Linker > Libraries.
-  Add SolutionToosAPI to the Libraries field.
-  Add the path of this API library to the Library search path field:

/opt/93000mts/mts/solution_tools/common/sh_lib.

-  In the Tool Settings tab, click GCC C++ Linker > Miscellaneous.
-  In the Other options field, enter:

-rpath

-  Still in the Other options field, enter another option:

/opt/93000mts/mts/solution_tools/common/sh_lib/

-  Manually add this line at the beginning of your test method code file:

```
#include "solution_tools.h"
```

## Results

You can now use the [driver sharing APIs](<02.12.02.05.06.07.09_Test_methods_for_driver_sharing.md>) in your test method code.

## What to do next

Program the test method as usual.
