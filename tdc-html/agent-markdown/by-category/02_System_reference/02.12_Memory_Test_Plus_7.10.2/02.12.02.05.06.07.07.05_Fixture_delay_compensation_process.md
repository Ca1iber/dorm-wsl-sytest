# Fixture delay compensation process

#### Subtopics

- [Measuring fixture delay](<02.12.02.05.06.07.07.05.01_Measuring_fixture_delay.md>)
- [Creating an FXDL file for a repaired fixture](<02.12.02.05.06.07.07.05.02_Creating_an_FXDL_file_for_a_repaired_fixture.md>)

Driver sharing, by necessity, introduces differences in signal transmission times between different devices on a shared bus. Accurate testing requires these differences to be compensated for.

## About this task

Perform this task to calibrate you test system to the signal propagation delays introduced by driver sharing.

## Before you begin

Set up driver sharing, in particular the [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>).

## Procedure

-  Measure the device loading delay as described in [Measuring fixture delay](<02.12.02.05.06.07.07.05.01_Measuring_fixture_delay.md>).
-  Decide whether to use the FXDL file delivered by the manufacturer of the load board or create your own.

If you want to create your own FXDL file, do so as described in [Creating an FXDL file for a repaired fixture](<02.12.02.05.06.07.07.05.02_Creating_an_FXDL_file_for_a_repaired_fixture.md>). If you want to use the manufacturer-supplied file, continue as described below.

The fixture delay file contains the calibration data for the inherent shared-bus delay. It is usually included with the load board and can be assumed to be accurate for the new board. You may want to create your own FXDL file, for example, when you have made repairs to the load board.

-  Merge the files as described in [Running the fd_merge tool to merge fixture delay files](<02.12.02.05.06.07.07.06.01_Running_the_fd_merge_tool_to_merge_fixture_delay_files.md>).

## Results

An FXDL file is created that is ready to use for compensating measurements.
