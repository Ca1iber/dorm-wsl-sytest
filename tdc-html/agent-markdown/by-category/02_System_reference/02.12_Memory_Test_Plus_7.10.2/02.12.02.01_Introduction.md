# Introduction

This section introduces the outline of memory testing using the MTP software as memory test software environment in the SmarTest software.

The following topics are covered:

- [Memory Test Basics](<02.12.02.02_Memory_Test_Basics.md>)

Presents basic information about memory devices, the terminology for memory arrays and the basic process to test memory devices.

- [Defining a memory test pattern](<02.12.02.04_Defining_a_Memory_Pattern.md>)

Gives you the necessary knowledge for creation and execution of a memory test program using available test methods and explains the prerequisites, the pattern generation, the test flow creation for memory testing with focus on generating results that are easy to analyze.

For memory test purposes, your device is defined by:

  - The ports of your memory, and the pins used by each
  - The access definition cycles (read/write, for example), including multiplexed and pipelined cycles
  - The address and data bits.

You can apply the pattern to a particular region of the memory and analyze the results in either the traditional cycle-oriented result tools, or the address-oriented result tools.

- [Performing a Memory Test](<02.12.02.05_Performing_a_Memory_Test.md>)

You can test your device by any of the following:

  - Selecting one of the standard library patterns
  - Creating a fully-customized pattern
  - Creating test flows and using test methods

- [Analyzing Memory Test Results](<02.12.02.07_Analyzing_Memory_Test_Results.md>)

To support and ease analyzing results of your tests a set of tools is provided.

How to use the tools to generate data for analysis and how to select and display relevant data is shown.
