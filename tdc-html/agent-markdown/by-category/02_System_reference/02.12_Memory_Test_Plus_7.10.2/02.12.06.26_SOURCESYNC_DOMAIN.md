Creates a domain that a source-sync test will apply to. An object of this class is created only with [SOURCESYNC_TEST.domain()](<02.12.06.29.02_SOURCESYNC_TEST.domain.md>).

 Note Do not create any instances with this class.

This API is defined in the header file /opt/93000/mts/solution_tools/common/include/SOURCESYNC_DOMAIN.h.
