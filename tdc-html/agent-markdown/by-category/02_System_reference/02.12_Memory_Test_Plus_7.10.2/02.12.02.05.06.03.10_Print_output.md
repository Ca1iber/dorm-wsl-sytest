# Print output

The GDDR5 test methods generate print output of the eye or the transition. The output can be controlled by setting the testflow and test suite flags.

## Testflow flag

Full testflow execution

- An eye or transition printout is generated.

Single test suite execution

- The debug mode setting is ignored.

## Test suite flag

Output on pass or Output on fail

- If Output on pass or Output on fail is activated, an overall pass message or a fail message, respectively, is printed.
- Otherwise no printout is generated

Pass/fail value

If the Output on pass or Output on fail flag is activated, the current pass or fail values are printed.

Per pin on pass/fail

If the Output on pass or Output on fail flag is activated, the current pass or fail messages per pin are printed.

## Event logging

If log_events_enable is on, limit information is logged.
