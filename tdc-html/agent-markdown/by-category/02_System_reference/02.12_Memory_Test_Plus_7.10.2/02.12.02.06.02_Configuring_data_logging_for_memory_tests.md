# Configuring data logging for memory tests

Event data logging of memory tests is governed by the same system and test suite flags as logging other kinds of tests.

## About this task

Perform this procedure when you want to log memory tests.

## Before you begin

Set up your memory tests as required.

## Procedure

-  Activate event data logging as described in [Activating event data logging](<../02.10_Data_Logging/02.10.01.01.04_Activating_event_data_logging.md>).
-  Set the relevant test suite flags as required, either in the data logging profile (recommended) or manually. Activating the flags has te following consequences:

  - Output on pass: When the test is passed, the global pass result is logged.
  - Per-pin on pass: When the test is passed, pass results for individual pins are logged.
  - Pass value: When the test is passed, pass values and limits are logged per bank and per pin, as well as the address list for DQ pins.
  - Output on fail: When the test is failed, the global fail result is logged.
  - Per-pin on fail: When the test is failed, fail results for individual pins are logged.
  - Fail value: When the test is failed, fail values and limits are logged per bank and per pin, as well as the address list for DQ pins.

-  Set the [log_first](<02.12.02.05.06.01.03.01_Parameters_for_the_ExecutionEngine_test_method.md>)[ parameter](<02.12.02.05.06.01.03.01_Parameters_for_the_ExecutionEngine_test_method.md>) in the ExecutionEngine test method to the desired value.

## Results

You have activated and configured event data logging for your memory tests.

## What to do next

Run the memory test.

## Functional changes

- SmarTest 7.0.4: Logging memory tests events is available only in MTP on HSM.
- MTP 3.1.4: Logging memory tests events is available both in MTP on HSM and MTP on SOC.
