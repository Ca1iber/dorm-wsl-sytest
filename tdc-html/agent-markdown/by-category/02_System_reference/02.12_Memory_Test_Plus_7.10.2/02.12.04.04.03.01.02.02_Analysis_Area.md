# Analysis Area

Choosing Analysis Area opens the Analysis Area window:

  ![Analysis Area](<../../../../raw/69019.png>)

The window contains these options:

- Analyze All: If this option is checked, the specified analysis area is ignored and failed cells from the entire DUT are displayed in the Failed Cells list instead. If the option is unchecked, only failed cells from the area specified from "Area topological" are shown.
- Hex: If it is checked, numbers entered in "Area topological" are hexadecimal. If unchecked, these numbers are decimal.
- Start x: The pixel coordinate of the analysis area's left border.
- Start y: The pixel coordinate of the analysis area's top border.
- End x: The pixel coordinate of the analysis area's right border.
- End y: The pixel coordinate of the analysis area's bottom border.

## Functional changes

- Introduced before SmarTest 6.3.2
- MTP 3.2.1: The hexadecimal numbers are allowed.
