# SHARING_CONFIGURATION.getBufferPinMap()

The getBufferPinMap() member function of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) returns a reference to the buffer pin map. The buffer pin map maps site numbers to buffer pin lists.

## Syntax

```
const map<int, string> & getBufferPinMap() const
```

## Related information

[SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>)
