# Prerequisites

Before you start developing your test program make sure SmarTest and MTP are installed.

Before you can run a test program you must inform the SmarTest software about the specifics of your device.

In general, all devices have pins. In the device spec sheet these pins are named according to their function. You will find it easier to use the same names for the pins as in the device specification.
