# MTP_DPS_MEASURE.samples()

The samples() member function of [MTP_DPS_MEASURE](<02.12.06.11_MTP_DPS_MEASURE.md>) lets you specify the number of measurements to be averaged.

## Syntax

```
MTP_DPS_MEASURE & samples(size_t samples)
```

 |

Parameter

 |

Description

 |
 |

samples

 |

The number of measurements to be averaged. This must be a positive integer. (Default is 1)

Note that the real measurement numbers can be different from the value specified here. For an explanation of the details, see [DPS_TASK & samples()](<../02.07_Test_Method_Reference/02.07.04.01.50_DPS_TASK.md>).

 |
