# MTP_MEMORY_PORT.print()

Prints out the memory test results of the current port.

The port is specified with [getMemoryPort()](<02.12.06.17.08_MTP_MEMORY_TEST.getMemoryPort.md>).

## Syntax

```
void print (ostream & out = std::cout) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

out

 |

The data stream to be printed out. The default output is stdout.

 |

Return value

There is no return value.

## Related information

[MTP_MEMORY_TEST.getMemoryPort()](<02.12.06.17.08_MTP_MEMORY_TEST.getMemoryPort.md>)

## Functional changes

- Introduced in MTP 3.2.1
