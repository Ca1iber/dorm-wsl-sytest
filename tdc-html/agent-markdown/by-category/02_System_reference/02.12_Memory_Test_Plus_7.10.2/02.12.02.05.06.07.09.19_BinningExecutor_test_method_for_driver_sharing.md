# BinningExecutor test method for driver sharing

At the end of a test flow, all previous software binning information is collected and spread out in a multibin. For more details see [Inserting a bin into a testflow](<../02.08_Setup_and_Result_Tools/02.08.04.32.02.01.05_Inserting_a_bin_into_the_testflow.md>).

The BinningExecutor test suite performs the final binning based on the multibin concept and evaluates the binning information provided by the binning handler.

Multi-binning information is managed in the master bin list:

- All required combinations of software and hardware are specified.
- If a device has an undefined combination, it is placed in the Otherwise bin (-1).
- ensures the bin combination was intentionally planned
