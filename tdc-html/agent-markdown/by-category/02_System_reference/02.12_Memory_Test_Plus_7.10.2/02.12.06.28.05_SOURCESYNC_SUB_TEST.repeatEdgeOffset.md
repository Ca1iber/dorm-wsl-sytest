# SOURCESYNC_SUB_TEST.repeatEdgeOffset()

Specifies the number of the first edge to be displayed on an error map. Use it together with [SOURCESYNC_SUB_TEST.repeatEdgeInterval()](<02.12.06.28.04_SOURCESYNC_SUB_TEST.repeatEdgeInterval.md>) and [SOURCESYNC_SUB_TEST.repeatEdgeLength()](<02.12.06.28.06_SOURCESYNC_SUB_TEST.repeatEdgeLength.md>) to specify which edges will be printed out on an error map.

 Note When the [repeatEdgeInterval](<02.12.06.28.04_SOURCESYNC_SUB_TEST.repeatEdgeInterval.md>) is set to 0, this function does not take effect.

## Syntax

```
SOURCESYNC_SUB_TEST& repeatEdgeOffset (const int offset);
```

Parameter
 |

Parameter

 |

Description

 |
 |

offset

 |

The number of the first edge to be shown on an error map.

The default number is 0.

 |
