# Eyefinder Enhancement

Controlling the amount of output messages in the report window is possible by setting the testflow flags:

- Output on fail
- Output on pass.

For more information refer to [Using EyeFinder](<02.12.02.05.06.04.02_Using_EyeFinder.md>) in Testing High-Speed Memory Devices.
