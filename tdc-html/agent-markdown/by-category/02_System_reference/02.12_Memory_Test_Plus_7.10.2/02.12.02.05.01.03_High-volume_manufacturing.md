# High-volume manufacturing

For the high-volume manufacturing (HVM) use case you need to run the test flow with pass/fail information only:

  ![HVM workflow using the ExecutionEngine test method](<../../../../raw/118226.png>)

Set the parameters for the test method as described in [Parameters for the ExecutionEngine test method](<02.12.02.05.06.01.03.01_Parameters_for_the_ExecutionEngine_test_method.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
- MTP 3.0.1: The ExecuteEngine test method replaces the Memtest test methods.
