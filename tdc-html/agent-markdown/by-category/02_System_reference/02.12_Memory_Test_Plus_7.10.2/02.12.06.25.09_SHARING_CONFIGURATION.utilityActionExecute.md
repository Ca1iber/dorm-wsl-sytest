# SHARING_CONFIGURATION.utilityActionExecute()

The utilityActionExecute() member function of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) executes the settings of the specified utility control line indicated by its location in the utility_control block.

## Syntax

```
int utilityActionExecute(int index) const
```

 |

Parameter

 |

Description

 |
 |

index

 |

The location of a utility control line within the utility_control block in the [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>).

0 represents the first line.

 |
