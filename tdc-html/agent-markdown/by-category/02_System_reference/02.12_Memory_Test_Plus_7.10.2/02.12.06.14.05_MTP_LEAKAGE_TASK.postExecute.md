# MTP_LEAKAGE_TASK.postExecute()

The postExecute() member function of [MTP_LEAKAGE_TASK](<02.12.06.14_MTP_LEAKAGE_TASK.md>) must be called at the end of leakage test after all pins have been measured. postExecute() will restore the settings as specified in the [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>).

## Syntax

```
void postExecute()
```
