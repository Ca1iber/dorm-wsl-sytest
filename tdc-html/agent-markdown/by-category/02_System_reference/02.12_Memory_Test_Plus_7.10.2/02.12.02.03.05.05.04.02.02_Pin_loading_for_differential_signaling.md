# Pin loading for differential signaling

For differential signaling, the programmable load (discussed under [Pin loading](<02.12.02.03.05.05.04.01.02_Pin_loading.md>)) is not activated. The Ioh and Iol parameters are therefore not relevant. However, the correct termination voltage Vt does need to be provided to DUT output pins.
