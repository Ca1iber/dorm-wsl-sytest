# BfdGenerator.addFailmap()

The addFailmap member function of the [BfdGenerator](<02.12.06.01_BfdGenerator.md>) class lets you add additional bit fail maps to existing BfdGenerator objects.

When you add a new bit fail map, you specify a name for the file to be generated, the dimensions of the fail data.

## Syntax

```
addFailmap(const string& fail_map_name, long long fail_accesses, long long fail_cells, const Address address_list[], unsigned long size, int fail_map_type, bool ignore_type);
```

 |

Parameter

 |

Description

 |
 |

file_map_name

 |

The name under which the bit fail map file is to be stored in the BfdGenerator object.

 |
 |

fail_accesses

 |

The number of failed accesses contained in this bit fail map.

 |
 |

fail_cells

 |

The number of failed cells contained in this bit fail map.

 |
 |

address_list

 |

A list of failed addresses.

Each address consists of these elements:

- x: The x-coordinate of the failed bit
- y: The y-coordinate of the failed bit
- z: The z-coordinate of the failed bit
- d: The d-coordinate of the failed bit
- expD: The expected value of the failed bit (0 or 1)
 |
 |

size

 |

The number of failed addresses in address_list.

 |
 |

fail_map_type

 |

The type of fail bit map:

- FAIL_ON_0: The bit fail map contains only fail-on-0 errors.
- FAIL_ON_1: The bit fail map contains only fail-on-1 errors.
- COMBINED: The bit fail map contains both kinds of errors.
 |
 |

ignore_type

 |

Whether the fail bit map type is ignored:

- true: All failed bit from address_list are stored in the BfdGenerator object, even if they do not fit the type of fail bit map specified in fail_map_type.
- false: Only failed bits that fit the map type are stored.
 |
