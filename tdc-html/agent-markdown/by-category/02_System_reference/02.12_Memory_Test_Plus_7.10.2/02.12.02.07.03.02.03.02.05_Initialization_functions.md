# Initialization functions

Initialization functions of the DUT Representation Language (DRL) let you describe the current state of the DUT.

They are system-defined functions that initialize data structures describing the device. They do not return values and so cannot be used in the right-hand side of assignments.

See the syntax descriptions for details on the way each function works.

## Syntax

These functions are available:

 |

Function

 |

Syntax

 |

Description

 |
 |

dg

 |

`dg(`i`) = (`begin`, `end`)`

 |

Specify data bit groups: Data bit group i includes all data bits from begin to end.

begin: The data bit with which the group starts.

end: The data bit with which the group ends.

For example: `dg(0) = (1,8)` - Data group 0 includes all bits from 1 through 8.

Currently, only one data bit group - dg(0) - is supported.

 |
 |

sg

 |

`sg(`i`) = (`group`,`x-origin`, `y-origin`,`numrows`, `numcols`)`

 |

Specify segment properties: Segment i belongs to data group group, its origin coordinates are x-origin,y-origin, and it has numrows rows and numcols columns.

group: The data bit group to which the segment belongs

x-origin: The x coordinate of the segment's origin

y-origin: The y coordinate of the segment's origin

numrows: The number of spare rows in the segment

numcols: The number of spare columns in the segment

For example: s`g(2) = (1,0,7,16,8)` - Segment 2 belongs to data group 1; it begins at 0,7; and it has 16 rows and 8 columns.

 |
 |

sra_col

 |

`sra_col(`i`) = (`group`, `spareColNum`, `spareColID`)`

 |

Assign spare columns to segments: Spare column spareColID is assigned to segment i and data bit group group as the spare number spareColNum.

group: The data bit group to which the column belongs

spareColNum: The index of the assigned spare column within the segment' spare columns. This can be a loop.

spareColID: The ID of the spare column being assigned

For example: `sra_col(1) = (3,0,5)` - For segment 1 and data group 3, the spare column with the ID 5 is assigned as the first (index 0) available spare column.

 |
 |

sra_row

 |

`sra_row(`i`) = (`group`, `spareRowNum`, `spareRowID`)`

 |

Assign spare rows to segments: Spare row spareRowID is assigned to segment i and data bit group group as the spare number spareRowNum.

group: The data bit group to which the row belongs

spareRowNum: The index of the assigned spare row within the segment' spare columns. This can be a loop.

spareRowID: The ID of the spare row being assigned

For example: `sra_row(0) = (2,1,1)` - For segment 0 and data group 2, the spare row with the ID 1 is assigned as the second (index 1) available spare row.

 |
 |

sru_col

 |

`sru_col(`i`) = (`group`,`shareLen`, `linkLen`, `segIDs`)`

 |

Specify the usage details of spare columns: Spare column number i belongs to data bit group group, is shared by shareLen segments, links linkLen segments, and can be used to repair the segments listed in segIDs.

group: The data bit group to which the column belongs

shareLen: The number of segments that share this repair column. This can be a loop.

linkLen: The number of segments that are linked by this column, that is, that are repaired together when this column is used. This can be a loop.

segIDs: A tuple with the IDs of the segments that can be repaired using this column

For example: `sru_col(0) = (4, 2, 1, (0,1,2,3,8,9,10,11))` - Spare column 0 belongs to data bit group 4, is shared by two segments and links one segment, and can repair segments 0, 1, 2, 3, 8, 9, 10, or 11.

 |
 |

sru_row

 |

`sru_row(`i`) = (`group`,`shareLen`, `linkLen`, `segIDs`)`

 |

Specify the usage details of spare rows: Spare row number i belongs to data bit group group, is shared by shareLen segments, links linkLen segments, and can be used to repair the segments listed in segIDs.

group: The data bit group to which the row belongs

shareLen: The number of segments that share this repair row. This can be a loop.

linkLen: The number of segments that are linked by this row, that is, that are repaired together when this row is used. This can be a loop.

segIDs: A tuple with the IDs of the segments that can be repaired using this row

For example: `sru_row(0) = (0, 1, 8, (0,1,2,3,4,5,6,7))` - Spare row 0 belongs to data bit group 0, is shared by one segment and links eight segments, and can repair segments 0 through 7.

 |

Note that i is always the index of the function in the syntax descriptions above, similar to the index of a variable.
