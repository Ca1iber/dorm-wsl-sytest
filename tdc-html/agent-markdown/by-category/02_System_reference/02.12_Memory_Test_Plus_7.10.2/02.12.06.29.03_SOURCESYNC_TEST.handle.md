# SOURCESYNC_TEST.handle()

Executes the handler operation which you have defined with [SOURCESYNC_HANDLER](<02.12.06.27_SOURCESYNC_HANDLER.md>).

## Syntax

```
void handle (SOURCESYNC_HANDLER& handler);
```

Parameter
 |

Parameter

 |

Description

 |
 |

handler

 |

An instance of a handler operation defined with [SOURCESYNC_HANDLER](<02.12.06.27_SOURCESYNC_HANDLER.md>).

 |

Return value

There is no return value.

## Example

This example demonstrates the basic flow to use SOURCESYNC_HANDLER to create a handler.

In this example, a handler operation, MyHandler, is created to output a customized error map.

File: MyHandler.h

```
#include "SOURCESYNC_HANDLER.h"
class MyHandler : public SOURCESYNC_HANDLER
{
  public:
  virtual void OPERATION_PRE_ITERATE_EACH_CYCLE(const EMAPVars& emap);
  virtual void OPERATION_PRE_ITERATE_EACH_EDGE(const EMAPCycleVars& emap);
  virtual void OPERATION_ITERATE_EACH_EDGE(const EMAPEdgeVars& emap);
  virtual void OPERATION_POST_ITERATE_EACH_EDGE(const EMAPCycleVars& emap);
  virtual ~MyHandler()
  {
  }
};

```

File: MyHandler.cpp

```
#include "MyHandler.h"
#include <iostream>

using namespace std;

void MyHandler::OPERATION_PRE_ITERATE_EACH_CYCLE(const EMAPVars& emap)
{
  cout << "Cycle Range: " << emap.startCycle << " - " << emap.startCycle + emap.cycleNum - 1 << endl;
  cout << " ";
  for (unsigned int iShotNo = 0; iShotNo < emap.shotNum; iShotNo++)
  {
    cout << iShotNo % 10;
  }
  cout << endl;
}

void MyHandler::OPERATION_PRE_ITERATE_EACH_EDGE(const EMAPCycleVars& emap)
{
}

void MyHandler::OPERATION_ITERATE_EACH_EDGE(const EMAPEdgeVars& emap)
{
  char szLine[16];
  sprintf(szLine, "%8d:%1d ", (int)emap.cycleNO, emap.edgeNO);
  cout << szLine;
  // For all shots of one edge.
  for (unsigned int iShotNo = 0; iShotNo < emap.shotNum; iShotNo++)
  {
    const char symbol = (emap.shotsState[iShotNo] == SOURCE_SYNC::EMAP_PASS) ? '.' : '#';
    cout << symbol;
  }
  cout << " ";
  // Print summary.
  if (emap.accumulatedState == SOURCE_SYNC::EMAP_PASS)
  {
    if (emap.marginState == SOURCE_SYNC::UNREASONABLE)
    {
      // unreasonable
      cout << " - " << emap.marginValue;
    }
    else
    {
      // pass
      cout << " . " << emap.marginValue;
    }
  }
  else
  {
    cout << " FAIL " << emap.marginValue;
  }
  cout << endl;
}

void MyHandler::OPERATION_POST_ITERATE_EACH_EDGE(const EMAPCycleVars& emap)
{
}
```

```
class CSourceSyncTest: public testmethod::TestMethod

            .sweepSpecVar("tsweep_a").sweepStart(0.5).sweepStop(0.70).sweepStepSize(0.1);
      ssTest.test("Hold").edgeList("2,4,6,8").specVar("tHold")
            .sweepSpecVar("tsweep_a").sweepStart(0.5).sweepStop(0.70).sweepStepSize(0.1);

      ssTest.execute();
    }
    ON_FIRST_INVOCATION_END();
    ssTest.judgeAndLog();

    // Use MyHandler to handle user-specified case.
    MyHandler handler;
    ssTest.handle(handler);
  }
}
```
