# MTP_LEAKAGE_TASK.settlingTime()

The settlingTime() member function of [MTP_LEAKAGE_TASK](<02.12.06.14_MTP_LEAKAGE_TASK.md>) lets you specify the additional settling time for the test system.

## Syntax

```
void settlingTime(double time)
```

 |

Parameter

 |

Description

 |
 |

time

 |

The additional time for a test. The default is 0.

The unit is second.

 |
