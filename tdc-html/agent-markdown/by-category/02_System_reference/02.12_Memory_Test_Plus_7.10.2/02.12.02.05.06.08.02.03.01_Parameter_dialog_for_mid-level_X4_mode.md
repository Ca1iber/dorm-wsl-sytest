# Parameter dialog for mid-level X4 mode

- Select the CrossCalibrate_X4 test method in the tabular testflow editor.

The test method's parameters are displayed in the Test Suite window.

- Edit parameters as desired.

The available parameters are described in the table below.

- Right-click the test method and choose Execute Selected.

The result file x4_atr (name given in previous step as output file) is stored in <device>/pin_attributes.

- In a terminal window, enter

```
ddr_solution_tools/TermTimeAdj/bin/updatePinAttributes.pl -c <pin_config_file> -p <pinAttributeFile>
```

This generates the pin attribute file with the new pin names using the original pin configuration file of the test device plus the pin attribute file (x4_atr) generated by the test method.
