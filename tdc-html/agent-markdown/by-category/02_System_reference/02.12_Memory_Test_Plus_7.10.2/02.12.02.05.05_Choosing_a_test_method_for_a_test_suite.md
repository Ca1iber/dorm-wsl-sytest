# Choosing a test method for a test suite

A test method can be used by adding it to a test flow and it is assumed here that the test flow already exists. For more information on setting up a test flow see [Introduction of the Testflow](<../02.08_Setup_and_Result_Tools/02.08.04.32.01_Introduction_of_the_Testflow.md>).

- In the test flow, create a new test suite.
- Start the test suite configuration window by double-clicking the test suite.
- In the Primaries tab, click the radio button test method and then fill in the needed values for Timing Equation, Waveform Set, Timing Set, etc.
- Click inside the test method field to select the class and test method, then click the Select button.
- In the Select Class/Method window

  - Select your test method class in the Class window.
  - Select your test method in the Method window.
  - Click Select.

- The Test Suite Dialog reappears. To accept the default parameters of the test method, click the Done button at the lower right.
- The test method can be configured by Setting Parameters and Setting Flags for your selected test method.

See the individual test method descriptions for more details.

## Functional changes

- Introduced before SmarTest 6.3.2
