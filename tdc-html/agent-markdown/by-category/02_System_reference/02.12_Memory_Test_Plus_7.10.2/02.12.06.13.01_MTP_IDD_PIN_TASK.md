# MTP_IDD_PIN_TASK

#### Subtopics

- [MTP_IDD_PIN_TASK.limits()](<02.12.06.13.01.01_MTP_IDD_PIN_TASK.limits.md>)

The MTP_IDD_PIN_TASK class is a data container holding the IDD measurement setup data for testing VDD and VDDQ pins. It is performed with the [MTP_IDD_TASK](<02.12.06.13_MTP_IDD_TASK.md>) API and used by the [pin()](<02.12.06.13.02_MTP_IDD_TASK.pin.md>) member function.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/MTP_IDD_PIN_TASK.h.
