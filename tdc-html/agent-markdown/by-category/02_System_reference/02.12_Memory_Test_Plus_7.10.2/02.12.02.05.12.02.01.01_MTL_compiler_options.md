# MTL compiler options

The options on the Compilation Option tab of [The Compiler Options page](<02.12.02.05.12.02.01_The_Compiler_Options_page.md>) are:

- Output Vector Directory: Lets you select a directory for receiving vectors from the compiled .apg files.

The default directory is ../vectors/mempats/.

- Reconstruction Directory: Lets you select a directory for receiving the generated reconstruction files during compilation.

The default directory is ../mts/recon_datalib/.

Reconstruction files convert error cycle numbers to addresses.

Note Below options will generate the same effects as the command line options in [apgc command syntax](<02.12.03.02.05.01_apgc_command_syntax.md>).

- Expansion Size (-e): The maximum size to which for loops can be expanded. Higher settings reduce the probability of [data queue empty](<02.12.03.05.02.01_Data_Queue_Empty_error.md>) errors but increase memory consumption.

This setting corresponds to the -e command line option.

- Generate Reconstruction File (-r2): Checking this option will generate reconstruction files in the directory that you have specified in the Reconstruction Directory field.

By default, this option is selected.

This setting corresponds to the -r2 command line option.

- Verbose Mode (-v): Checking this option will display status information throughout the compilation process.

By default, this option is selected.

This setting corresponds to the -v command line option.

- Automatic Waveform Generation (-w): Checking this option creates new waveforms where required. For the pre-requisites and limitations, see [Automatic waveform generation](<02.12.03.04.03.03_Automatic_waveform_generation.md>).

This setting corresponds to the -w command line option.

If you activate the verbose mode (equivalent to the -vw command line option), the compiler generates a report for the waveforms in the wavetable. For more information, see [Setting up automatic waveform generation](<02.12.03.04.03.03.01_Setting_up_automatic_waveform_generation.md>).

- Print Wavetable Usage (-vw): Checking this option produces a detailed report about the wavetable usage.
- Generate Parallel Vector (-para): Checking this option instructs the compiler to output a parallel vector program. This option is helpful when you need to convert the output to Verilog format or manually edit it.

However, this option does not support the generation of:

  - [Dynamic refresh](<02.12.03.04.12_Maintenance_operations.md>).
  - Pin ratio that has been set up within a port with the [cycleratio](<02.12.03.03.06.01_Pin_mapping_file_syntax.md>)[ pin attribute](<02.12.03.03.06.01_Pin_mapping_file_syntax.md>).
  - [DC events](<02.12.03.03.08_DC_event_file.md>).
  - Multiplexed pins.

- Create Reusable Device Maintenance Operation (-m): Checking this option will compile a maintenance operation (refresh) that is stored in memory separately from the main pattern. Details are available in [Maintenance operations](<02.12.03.04.12_Maintenance_operations.md>).

This setting corresponds to the -m command line option.

- Limit Variable Scope (-lvs), Extend Variable Scope (-evs), and Fast Extend Variable Scope (-fevs):

  - Limit Variable Scope makes variables in a `for` loop behave like in the earlier versions of MTL (being reset in each loop iteration).

By default, Limit Variable Scope is checked.

  - Extend Variable Scope makes variables in a `for` loop behave like standard C variables (preserving their values from one iteration to the next).

This pair of settings corresponds to the -lvs and -evs command line compiler options.

For global variables, their scopes are always extended no matter you select Limit Variable Scope or Extend Variable Scope.

  - Fast Extend Variable Scope: Similar to Extend Variable Scope but with faster speed and smaller memory consumption during the early phase compilation. It corresponds to the -fevs command-line option.

Use this option only when Extend Variable Scope is too slow and MTL (using the Verbose Mode (-v) option) prints out the message "Start creating per-pin programs".

- Disable Padding (-dp):

Checking this option will disable padding according to your selection:

  - Disable For-loop Only: Disables padding directly before and at the end of for loops. This corresponds to the -dp0 command line option.
  - Disable For-loop and Is/Nis: Disables padding directly before and at the end of for loops as well as directly before and after [is{}](<02.12.03.03.03.01.04_Other_control_structures.md>)[ and ](<02.12.03.03.03.01.04_Other_control_structures.md>)[nis{}](<02.12.03.03.03.01.04_Other_control_structures.md>) instructions. This corresponds to the -dp1 command line option.

- Optimize Memory Usage (-O):

Checking this option will compress vectors according to your selection:

  - O0: The shortest compile time but no vector compression. This setting is recommended for small patterns.
  - O2: The greatest compression but the longest compile time. This setting is not recommended for small patterns.
  - O1: Between O0 and O2. This setting is not recommended for small patterns.

This corresponds to the -O0, -O1, and -O2 command line options.

Note that:

  - Compressing small patterns may increase their size, so O1 and O2 are not recommended for small patterns.
  - In rare cases, O1 can compress more than O2. Therefore, when the greatest compression is important, try both O1 and O2 for the better one.

## Functional changes

- Introduced in MTP 3.1.1
- MTP 3.1.3: The Optimize Memory Usage option is now set through a pop-up menu.
- MTP 3.1.3: The padding options have been consolidated.
- MTP 3.2.1: The MTL compiler opitons page is integrated into the MTP Build page.
- MTP 3.3.2: Adds new options: Print Wavetable Usage (-vw), Generate Parallel Vector (-para), Fast Extend Variable Scope (-fevs), and Transaction ID Filter (--genidFilter).
