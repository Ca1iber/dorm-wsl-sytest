# Content assistant in the MTP editor

Content assistant is the feature to provide you all the closest setups (APIs, keywords, wavetables, DC sets and etc.) in a pop-up window at where you want to insert a defined setup.

Right-click anywhere in an MTP editor, you will see these content assistant commands:

- Content Assist: Selecting it after typing in specific characters will list all setups started with these characters. The setups can be APIs, keywords that are surrounded with ":", preprocessors, subroutines, device access names, device parameters, variables that have been defined by :define:, wavetables, and DC sets.

Alternatively, select Ctrl+Space after typing in characters.

Note that:

  - To list wavetables of a waveform file: Select this command after entering the file path of a [waveform mapping file (.wmap)](<02.12.03.03.07_Waveform_mapping_file.md>).
  - To list DC events of a DC event file: Select this command after entering the file path of a [DC event file (.dcev)](<02.12.03.03.08_DC_event_file.md>).

- Content AssistFilter > Keyword: Selecting it will list all keywords that are surrounding with ":", for example, :defines:.

If you select this command after typing in ":" followed with some specific letters, it will list all the keywords starting with both ":" and these letters.

- Content AssistFilter > Subroutine: Selecting it after a subroutine will show the content of the subroutine.
- Content AssistFilter > Device Access: Selecting it will list all the defined [device access names](<02.12.03.03.04.01_Device_access_file_syntax.md>).
- Content AssistFilter > Device Parameter: Selecting it will list all device parameters defined in the [Device architecture file](<02.12.03.03.05_Device_architecture_file.md>).
- Content AssistFilter > Program Parameter: Selecting it will list all program parameters that have been defined with the [:programParam:](<02.12.03.03.02.01_APG_pattern_file_syntax.md>) keyword in the .apg files.
- Content AssistFilter > MTL Define: Selecting it will list all variables that have been defined by :define:.
- Content AssistFilter > Macro Define: Selecting it will list all macros that have been defined by #define.

## Functional changes

- Introduced in MTP 3.2.2
- MTP 3.3.1: Adds subroutine and device parameter content assistants.
- MTP 3.3.1: "Ctrl + space" can list all kinds of content assistants.
- MTP 3.3.2: Adds a new shortcut menu command Content Assist Filter to fast access various content assistants.
- MTP 3.3.2: Obsoletes the opening of content assistants with keyboard characters.
