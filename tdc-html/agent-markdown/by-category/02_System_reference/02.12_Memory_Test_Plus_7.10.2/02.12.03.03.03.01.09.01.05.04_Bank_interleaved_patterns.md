# Bank interleaved patterns

To interleave data accesses between different banks, you must first activate these banks.

 Note For DDR2 and DDR3 devices, data only can be accessed after the respective banks are activated.

Without MTL arrays, you cannot use loop functions to activate the banks, because the bank activation order is arbitrary. So you only can program such patterns in a flat style, which creates lengthy and hard to maintain code.

With MTL arrays, you can loop to activate the banks.

- Create a mapping table which contains the bank addresses with the same arbitrary order.
- Iterate over the table elements sequentially.

For example, use the loop variable ‘z' as an array index.
