# SOURCESYNC_DOMAIN.bufferPins()

Specifies buffer pins used with a [rapid source-sync test](<02.12.06.29.08_SOURCESYNC_TEST.rapidSourceSync.md>) in this domain.

## Syntax

```
virtual SOURCESYNC_DOMAIN& bufferPins (const string& pinGroup);
```

Parameter
 |

Parameter

 |

Description

 |
 |

pinGroup

 |

The buffer pins in this domain, separated with ",".

For example, "clk0, data00, data01".

 |

[SOURCESYNC_TEST.rapidSourceSync()](<02.12.06.29.08_SOURCESYNC_TEST.rapidSourceSync.md>)
