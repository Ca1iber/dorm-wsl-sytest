# Executing a memory test with the Memtest Execute test method

To gather address or cycle-based data of the GDDR memory device you have to execute the [ExecutionEngine test method](<02.12.02.05.06.01_Memory_testing_test_method.md>) described in the [Testing High-Speed Memory Devices](<02.12.02_Testing_High-Speed_Memory_Devices.md>) manual.

## Functional changes

- Introduced before SmarTest 6.3.2
- MTP 3.0.1: The Memtest test methods have been replaced by the ExecutionEngine test method
