# SHARED_LEAKAGE_PARELLEL_TEST.execute()

The execute() member function of [SHARED_LEAKAGE_PARALLEL_TEST](<02.12.06.23_SHARED_LEAKAGE_PARALLEL_TEST.md>) lets you execute a parallel shared leakage test based on your previous setup.

## Syntax

```
void execute() const
```

## Example

```
SHARED_LEAKAGE_PARALLEL_TEST mTest;
mTest.execute();
```
