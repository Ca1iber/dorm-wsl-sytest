# MTP_RA_ALGORITHM_HOLDER.init()

Initializes the object that created by the [MTP_RA_ALGORITHM_HOLDER](<02.12.06.20_MTP_RA_ALGORITHM_HOLDER.md>) constructor.

 Note Do not use this member function for the MTP_RA_ALGORITHM_HOLDER (path) constructor.

## Syntax

```
MTP_RA_ALGORITHM_HOLDER& init (const STRING& path);
```

Parameter
 |

Parameter

 |

Description

 |
 |

path

 |

The file name and the path of the shared library of the legacy RA algorithm.

 |
