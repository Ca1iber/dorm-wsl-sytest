# MTP_MEMORY_TEST.setMaxFailingAddressesToReconstructPerPin()

The setMaxFailingAddressesToReconstructPerPin() member function of [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) lets you specify how many failing addresses will be reconstructed for each result pin.

This is an optional method.

## Syntax

```
MTP_MEMORY_TEST& setMaxFailingAddressesToReconstructPerPin(const LONG64 number)
```

 |

Parameter

 |

Description

 |
 |

number

 |

This parameter specifies the maximum number of failing addresses that will be reconstructed for each result pin.

Normally, there is no reason to limit that number. However, characterization and failure analysis may not require all addresses to be reconstructed, and in that case, limiting the number improves performance.

The default is to reconstruct all failing addresses (that is, there is no limit when you do not expressly set it).

 |

## Example

To limit the number of reconstructed addresses per pin to 1024:

```
MTP_MEMORY_TEST memoryTest();
memoryTest.setMaxFailingAddressesToReconstructPerPin(1024);
```
