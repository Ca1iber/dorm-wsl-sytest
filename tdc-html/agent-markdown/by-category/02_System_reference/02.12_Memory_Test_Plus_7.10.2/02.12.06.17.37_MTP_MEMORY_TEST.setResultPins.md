# MTP_MEMORY_TEST.setResultPins()

The setResultPins() member function of [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) lets you specify for which pins address-based results are to be calculated.

This is an optional method.

## Syntax

```
MTP_MEMORY_TEST& setResultPins(const STRING& result_pins)
```

 |

Parameter

 |

Description

 |
 |

result_pins

 |

A comma-separated list of pins for which the results are to be calculated. @ specifies all pins.

The default is @, that is, creating address-based results for all pins.

 |

## Example

Setting the result pins to DQ00, DQ01, DQ02, and DQ03:

```
MTP_MEMORY_TEST memoryTest();
memoryTest.setResultPins("DQ00,DQ01,DQ02,DQ03");
```
