# MTP_IDD_TASK.execute()

The execute() member function of [MTP_IDD_TASK](<02.12.06.13_MTP_IDD_TASK.md>) executes the IDD test based on the setup specified using the [pin()](<02.12.06.13.02_MTP_IDD_TASK.pin.md>) and [samples()](<02.12.06.13.04_MTP_IDD_TASK.samples.md>) member functions.

## Syntax

```
void execute()
```

Note When testing, you must use the [CONNECT](<../02.07_Test_Method_Reference/02.07.04.01.18_CONNECT.md>) API before using execute() since the IDD is measured in connected state.
