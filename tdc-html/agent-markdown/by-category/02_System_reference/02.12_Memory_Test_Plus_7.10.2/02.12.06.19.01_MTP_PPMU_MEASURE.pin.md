# MTP_PPMU_MEASURE.pin()

The pin() member function of [MTP_PPMU_MEASURE](<02.12.06.19_MTP_PPMU_MEASURE.md>) lets you specify the pins you want to measure with per-pin PMUs. pin() returns the [PPMU_PIN_MEASURE](<../02.07_Test_Method_Reference/02.07.04.01.157.01_PPMU_PIN_MEASURE.md>) class object which you use to set measurement and compare modes for the per-pin PMUs.

## Syntax

```
[PPMU_PIN_MEASURE](<../02.07_Test_Method_Reference/02.07.04.01.157.01_PPMU_PIN_MEASURE.md>) & pin(const STRING & pinname)
```

 |

Parameter

 |

Description

 |
 |

pinname

 |

Names of the pins or pin groups which you want to measure using per-pin PMUs.

If you specify multiple pins, separate their names with commas.

To test all PPMU pins, use "@". Note that "@" includes the digital pins that are wired to an analog module on the DUT board for trigger sources.

 |
