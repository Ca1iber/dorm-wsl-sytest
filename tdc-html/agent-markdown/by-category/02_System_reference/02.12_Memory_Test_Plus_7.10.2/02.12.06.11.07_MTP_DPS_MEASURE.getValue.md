# MTP_DPS_MEASURE.getValue()

The getValue() member function of [MTP_DPS_MEASURE](<02.12.06.11_MTP_DPS_MEASURE.md>) lets you retrieve the measured voltage in volts for a specific pin.

## Syntax

```
double getValue(const string & pin)const
```

 |

Parameter

 |

Description

 |
 |

pin

 |

The name of a pin whose measured voltage you want to retrieve.

The unit of the retrieved voltage is volt ([V]).

 |
