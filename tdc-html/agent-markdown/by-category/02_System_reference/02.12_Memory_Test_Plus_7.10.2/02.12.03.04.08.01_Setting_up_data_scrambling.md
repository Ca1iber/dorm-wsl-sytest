# Setting up data scrambling

Data scrambling requires setting up a bit inversion or a bit ordering table (or both) in the device architecture file, referencing it in the APG pattern file, and adding data scrambling information to the device access file.

## About this task

This task describes setting up data scrambling from scratch.

## Before you begin

Make sure that the correct [device access](<02.12.03.03.04_Device_access_file.md>) and [device architecture files](<02.12.03.03.05_Device_architecture_file.md>) are specified in the [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>).

## Procedures

### Setting up data scrambling

- If you want to use bit inversion, add a bit inversion table to the [Device architecture file](<02.12.03.03.05_Device_architecture_file.md>) using the :bitInversion: keyword.

The syntax of the :bitInversion: keyword is described in [Device architecture file syntax](<02.12.03.03.05.01_Device_architecture_file_syntax.md>).

If desired, you can add multiple bit inversion tables to the device architecture file.

- If you want to use bit ordering, add a bit ordering table to the [Device architecture file](<02.12.03.03.05_Device_architecture_file.md>) using the :bitOrdering: keyword.

The syntax of the :bitOrdering: keyword is described in [Device architecture file syntax](<02.12.03.03.05.01_Device_architecture_file_syntax.md>).

If desired, you can add multiple bit ordering tables to the device architecture file.

- Specify the desired bit inversion and bit ordering tables in the [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>) using the :bitInversion: and :bitOrdering: keywords.

The syntax of these keyword is described in [APG pattern file syntax](<02.12.03.03.02.01_APG_pattern_file_syntax.md>).

- In the [Device access file](<02.12.03.03.04_Device_access_file.md>), modify the device accesses that you want to use with data scrambling: Make sure that they use the data macro in the :data: column.

This macro calculates the scrambled data words using the bit inversion and bit ordering tables that you created in steps 1 and 2 and specified in step 3.

 Note If the data macro is not used in the :data: column, no data scrambling is performed.

### Disabling data scrambling

If you wish to temporarily disable data scrambling, replace the argument of the :bitInversion: and :bitOrdering: keywords in the APG pattern file with a tilde (~).

## Results

All device accesses to data pins (as specified in the device access file) are transparently scrambled using the data macro.
