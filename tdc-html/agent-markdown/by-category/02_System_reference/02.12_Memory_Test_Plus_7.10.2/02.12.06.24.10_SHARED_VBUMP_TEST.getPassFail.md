# SHARED_VBUMP_TEST.getPassFail()

The getPassFail() member function of [SHARED_VBUMP_TEST](<02.12.06.24_SHARED_VBUMP_TEST.md>) retrieves pass/fail results for all pins, or a specified pin in a shared Vbump test.

## Syntax

- Retrieve the pass/fail results for all pins tested.

```
bool getPassFail(void) const
```

- Retrieve a pass/fail result for a given pin tested.

```
bool getPassFail(const string& pin) const
```

 |

Parameter

 |

Description

 |
 |

pin

 |

The name of a measurement pin.

 |

Return Value

Returns a Boolean true for pass or false for fail result of the measurement.

## Example

```
SHARED_VBUMP_TEST mTest;
bool resultsAll, result;
resultsAll = mTest.getPassFail();
result = mTest.getPassFail("DO_Bus");
```
