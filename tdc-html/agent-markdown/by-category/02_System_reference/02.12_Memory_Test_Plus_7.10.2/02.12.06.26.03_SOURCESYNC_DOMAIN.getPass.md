# SOURCESYNC_DOMAIN.getPass()

Retrieves the pass/fail result of this domain.

## Syntax

```
virtual bool getPass();
```

List of parameters

There are no parameters.

## Return values

Returns true or false to represent pass and fail.

## Functional changes

- Introduced in MTP 3.2.2
