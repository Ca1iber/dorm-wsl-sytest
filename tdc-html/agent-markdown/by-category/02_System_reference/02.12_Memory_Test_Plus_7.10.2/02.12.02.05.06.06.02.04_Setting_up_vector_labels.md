# Setting up vector labels

## About this task

Create a vector label each for the additional wavetables for tDQSQmax and tDQSQmin created in the previous section. You need to do that only if you do not want to use one of the standard test patterns, for example the march6n pattern.

## Before you begin

Make sure your source code generates toggle patterns for clock and data that match your wavetables.

## Procedure

-  Using the data manager of SmarTest, save the timing equation file.
-  Open the vector setup tool.
-  Select the vector label by clicking, for example, mtl_gapless.
-  Right-click the vector label mtl_gapless and choose Copy from the menu.
-  Right-click the same area and choose Paste from the menu. The Paste Pattern window opens.
-  Rename the pattern in the Name field to, for example, DQSQmaxtime_mtl_gapless.
-  Click OK to apply your changes and to close the window.
-  Select the vector label by clicking, for example, mtl_gapless.
-  Right-click the vector label mtl_gapless and choose Copy from the menu.
-  Right-click the same area and choose Paste from the menu. The Paste Pattern window opens.
-  Rename the pattern in the Name field to, for example DQSQmintime_mtl_gapless.
-  Click OK.

## Results

Now the vector label is ready for use with this test methods.
