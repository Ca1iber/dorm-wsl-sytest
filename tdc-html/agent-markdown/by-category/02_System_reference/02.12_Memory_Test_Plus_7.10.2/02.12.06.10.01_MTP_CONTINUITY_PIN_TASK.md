The MTP_CONTINUITY_PIN_TASK class contains the measurement settings for a continuity test. The class is performed with the [MTP_CONTIUITY_TASK](<02.12.06.10_MTP_CONTINUITY_TASK.md>) API and used by the [pin()](<02.12.06.10.02_MTP_CONTINUITY_TASK.pin.md>) member function.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/MTP_CONTINUITY_PIN_TASK.h.
