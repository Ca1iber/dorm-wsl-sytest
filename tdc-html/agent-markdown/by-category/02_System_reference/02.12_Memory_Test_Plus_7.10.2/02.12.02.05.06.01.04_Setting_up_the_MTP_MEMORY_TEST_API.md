# Setting up the MTP_MEMORY_TEST API

For MTP versions earlier than 3.3.2, you must complete the following configuration steps if want to use the [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) and [MTP_MEMORY_PATTERN](<02.12.06.15_MTP_MEMORY_PATTERN.md>) classes in test methods.

## About this task

Note From MTP version 3.3.2, you do not need to perfrom the settings as described in this topic. After installing MTP 3.3.2 and restarting the computer, the configurations required for the MTP_MEMORY_TEST API are automatically set up.

Using the MTP_MEMORY_TEST API requires you to include its header and library files in the programming project configuration.

## Procedure

-  Right-click anywhere in your project file and choose Properties from the shortcut menu.

The Settings dialog is displayed.

-  In the left-hand sidebar, click C/C++ Build > Settings.
-  In the Tool Settings tab, click GCC C++ Compiler > Directories.
-  Add the path of the API header file to the Include paths field:

/opt/93000mts/mts/execution_engine/include/

-  Click GCC C++ Linker > Libraries.
-  Add HSMapi to the Libraries field.
-  Add the path of the API library file to the Library search path field:

/opt/93000mts/mts/execution_engine/sh_lib/

-  Click GCC C++ Linker > Miscellaneous.
-  In the Other options field, enter:

```
-rpath
```

-  Enter another option in the Other options field:

/opt/93000mts/mts/execution_engine/sh_lib/

-  Include the API in your test method by adding this line to it:

```
#include "MtpTest.hpp"
```

## Results

You can now use the [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) and [MTP_MEMORY_PATTERN](<02.12.06.15_MTP_MEMORY_PATTERN.md>) classes in your test method code.

## What to do next

Program the test method as usual.
