# MTP_MEMORY_PATTERN.getFailingCycleAddresses()

Stores all failing addresses for a specific data pin failed at different cycles to an array. Those addresses are stored in the failed cycles order.

Before using this function, you must specify [setFailAddressListOrdering(MTP::ORDERING_CYCLE)](<02.12.06.17.18_MTP_MEMORY_TEST.setFailAddressListOrdering.md>).

## Syntax

```
const CYCLE_ADDRESSES& getFailingCycleAddresses (int bit_index) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

bit_index

 |

An integer which represents the bit whose failing addresses you want to retrieve.

0 represents the first data pin in the data pin list that has been specified with [setResultPins()](<02.12.06.17.37_MTP_MEMORY_TEST.setResultPins.md>).

 |

## Return value

Returns the array that stores the addresses failed at different cycles for that data pin.

## Example

```
void MemoryTest::run()
{
  MTP_MEMORY_TEST memoryTest;

  memoryTest.enableAddressBasedResults(true);
  memoryTest.setMaxFailingAddressesToReconstructPerPin(1024);
  memoryTest.setFailAddressListOrdering(MTP::ORDERING_CYCLE);

  ON_FIRST_INVOCATION_BEGIN();
  {
    memoryTest.execute();
  }
  ON_FIRST_INVOCATION_END();

  MTP_MEMORY_PATTERN &march6n = memoryTest.getMemoryPattern("march6n");
  const CYCLE_ADDRESSES &addressList = march6n.getFailingCycleAddresses(0);
  LONG nr_addresses = addressList.size();

  // Loop over address list
  for(int i = 0 ; i  < nr_addresses ; i++)
  {
    stringstream msg;
    msg << "cycle = " << addressList[i].cycle << endl;
    msg << "x = " << addressList[i].x << endl;
    msg << "y = " << addressList[i].y << endl;
    msg << "z = " << addressList[i].z << endl;
    // Print out address to report window
    cout << msg.str();
    // Store address in datalog
    PUT_DATALOG(msg.str());
  }
}
```
