# MTP_CONTINUITY_TASK

#### Subtopics

- [MTP_CONTINUITY_PIN_TASK](<02.12.06.10.01_MTP_CONTINUITY_PIN_TASK.md>)

- [MTP_CONTINUITY_TASK.execute()](<02.12.06.10.04_MTP_CONTINUITY_TASK.execute.md>)
- [MTP_CONTINUITY_TASK.postExecute()](<02.12.06.10.05_MTP_CONTINUITY_TASK.postExecute.md>)

The MTP_CONTINUITY_TASK class provides an API for performing continuity tests for DUTs with driver sharing. It provides similar functionality to the [SharedContinuity test method](<02.12.02.05.06.07.09.09_SharedContinuity_syntax.md>) and the [SHARED_CONTINUITY_TEST](<02.12.06.21_SHARED_CONTINUITY_TEST.md>) API but can test different shared, non-shared, and cross-terminated pins which have different test conditions within one test method. All tested pins are measured in parallel.

The three methods each have advantages and disadvantages:

- SharedContinuity test method: A ready-made test method included with MTP.

  - Advantage: Quickest and easiest way to develop a test program with support for logging results. See [SharedContinuity syntax](<02.12.02.05.06.07.09.09_SharedContinuity_syntax.md>).
  - Disadvantage: May not meet any special requirements such as testing more than one group of shared, non-shared, or cross-terminated pins, or a special output format.

- SHARED_CONTYINUITY_TEST API:

  - Advantages: You can develop your own custom test method, from setting measurement conditions, executing measuring, and logging results.

Creating a test program is easy because no other APIs are needed to complete a continuity test.

  - Disadvantage: The test method based on this API cannot test more than one group of shared, non-shared, or cross-terminated pins.

- MTP_CONTINUITY_TASK API:

  - Advantage: This is the most flexible method. You can test any number of pins with any types of measurement conditions within one test method.
  - Disadvantages: Results logging is not supported but you can retrieve the results and manually log them.

Creating a test program is complex because other APIs needed to complete a continuity test, such as [DISCONNECT](<../02.07_Test_Method_Reference/02.07.04.01.41_DISCONNECT.md>), [FOR_EACH_TEST_BEGIN](<02.12.06.04_FOR_EACH_TEST_BEGIN.md>), [FOR_EACH_TEST_BEGIN_WITH_RESET](<02.12.06.05_FOR_EACH_TEST_BEGIN_WITH_RESET.md>), [FOR_EACH_TEST_END](<02.12.06.06_FOR_EACH_TEST_END.md>), [FOR_EACH_SHARED_SITE_BEGIN](<02.12.06.02_FOR_EACH_SHARED_SITE_BEGIN.md>), and [FOR_EACH_SHARED_SITE_END](<02.12.06.03_FOR_EACH_SHARED_SITE_END.md>).

Note The MTP_CONTINUITY_TASK API is available only for MTP.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/MTP_CONTINUITY_TASK.h.

## Example

This example tests the continuity for the shared, non-shared, and cross-terminated pins.

Assume the sharing configuration file (default.cfg) is as below:

```
domains: 8
4 3 2 1 ; 5 6 7 8
12 11 10 9 ; 13 14 15 16
utility_control:
continuity;(y<1);(U3=0x666&0xfff);(DEVICE_SUPPLY=VDD,FORCE_SUPPLY=(VDDQ,VDD,VTERM))
continuity;(y>=1);(U3=0x999&0xfff);(DEVICE_SUPPLY=VDD,FORCE_SUPPLY=(VDDQ,VDD,VTERM))
oc_reset;(U2=0x000&0x400,U2=0x400&0x400,U3=0x000&0xfff,U2=0x000&0x401)
default;(U3=0x000&0xfff,U2=0x000&0x401)
```

The program is:

```
#include "solution_tools.h"
#include "testmethod.hpp"
#include "mapi.hpp"
class CSharedContinuity: public testmethod::TestMethod
{
protected:
  virtual void run()
  {
    ON_FIRST_INVOCATION_BEGIN();
    {
      // get limits
      LIMIT limit, limitDM;

      // set up for non-shared pins: DQ_Bus and DQS_DIffBus
      mTest    .pin("DQ_Bus,DQS_DiffBus")
              .iForce(100 uA)
              .limits(limit);
      // set up for non-shared pins: DM
      mTest    .pin("DM")
              .iForce(80 uA)
              .limits(limitDM);
     // set up for cross-terminated pins
     mTest    .pin("Clock_Bus")
              .iForce(90 uA)
              .limits(limit);
      // set up for shared pins
      mTest    .pin("Addr_Bus,Command_Bus")
              .vForce(1.1)
              .limits(limit)
              .deviceSupply("VDD")
              .forceSupply("VDDQ,VDD,VTERM");
      mTest.settlingTime(10);

      // Continuity in general is measured in disconnect state and DUTs not powered
      DISCONNECT();

      FOR_EACH_TEST_BEGIN("default.cfg", "continuity");
      {
        FOR_EACH_SHARED_SITE_BEGIN();
        {
          // measurement of continuity
          // It will test in 8 steps with sites (4, 12), (3, 11),
          // (2, 10), (1, 9), (5, 13), (6, 14), (7, 15), (8, 16).
          // Without utility control setting, it will still test
          // in 8 steps but without utility setting change.
          mTest.execute();
        }
        FOR_EACH_SHARED_SITE_END();
      }
      FOR_EACH_TEST_END();

      // at the end of continuity test, do post execution
      mTest.postExecute();
    }
    ON_FIRST_INVOCATION_END();
  }
private:
  MTP_CONTINUITY_TASK mTest;
};
```
