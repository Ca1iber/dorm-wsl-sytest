# Improved Loop Handling

Loop variables can now increase by values other than powers of 2. For example, you can now use a loop statement like for (x = 0; x < 100; x += 3) { ... code ... }.

It is also possible to use multiplication, division, bitwise, and shift operations on loop variables.

## Benefit

FOR loops now allow skipping rows and other advanced techniques

Note FOR loops now also support diagonal patterns with scrambling, thanks to the ability to use a variable multiple times in an expression.
