# SHARING_CONFIGURATION.load()

The load() member function of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) lets you load a sharing configuration file when no sharing configuration has been down loaded before. After the sharing configuration is loaded, you can read the data using the data-accessing member functions of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>).

Another way to load a sharing configuration is using the [setRefPin()](<02.12.06.25.04_SHARING_CONFIGURATION.setRefPin.md>) member function which parses the sharing configuration information from a pin's physical connections.

Note load() dose not load the specified file if a sharing configuration has already been down loaded.

## Syntax

```
void load(const string & config)
```

 |

Parameter

 |

Description

 |
 |

config

 |

The name of the sharing configuration file which you want to load.

The file must be located in the <device directory>/configuration/ directory.

 |
