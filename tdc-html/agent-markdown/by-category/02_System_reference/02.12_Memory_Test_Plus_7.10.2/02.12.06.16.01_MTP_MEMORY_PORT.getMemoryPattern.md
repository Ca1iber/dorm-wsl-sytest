# MTP_MEMORY_PORT.getMemoryPattern()

Returns an object of [MTP_MEMORY_PATTERN](<02.12.06.15_MTP_MEMORY_PATTERN.md>), which is used to access the fail bit results and the functional test results of a specified memory pattern (a per pin subroutine generated by the MTL compiler).

## Syntax

```
MTP_MEMORY_PATTERN& getMemoryPattern (const STRING & pattern);
```

Parameter
 |

Parameter

 |

Description

 |
 |

pattern

 |

A pattern name.

 |

[MTP_MEMORY_PATTERN](<02.12.06.15_MTP_MEMORY_PATTERN.md>)
