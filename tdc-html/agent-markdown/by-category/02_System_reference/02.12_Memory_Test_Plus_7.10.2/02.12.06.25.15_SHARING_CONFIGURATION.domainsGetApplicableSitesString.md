# SHARING_CONFIGURATION.domainsGetApplicableSitesString()

The domainsGetApplicableSitesString() member function of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) returns a string containing all sites at the specified (x, y) position.

## Syntax

```
string domainsGetApplicableSitesString(int x, int y) const
```

 |

Parameter

 |

Description

 |
 |

x

 |

The position in the X dimension, starts from 0.

 |
 |

y

 |

The position in the Y dimension, starts from 0.

 |
