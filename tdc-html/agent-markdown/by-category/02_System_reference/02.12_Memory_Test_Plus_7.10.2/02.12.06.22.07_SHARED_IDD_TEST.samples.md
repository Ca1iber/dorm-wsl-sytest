# SHARED_IDD_TEST.samples()

The samples() member function of [SHARED_IDD_TEST](<02.12.06.22_SHARED_IDD_TEST.md>) lets you specify the number of measurements to be averaged.

## Syntax

```
SHARED_IDD_TEST& samples(int samples)
```

 |

Parameter

 |

Description

 |
 |

samples

 |

The number of measurements to be measured.

- The default value is 8.
 |

## Example

```
SHARED_IDD_TEST mTest;
mTest.samples(10);
```
