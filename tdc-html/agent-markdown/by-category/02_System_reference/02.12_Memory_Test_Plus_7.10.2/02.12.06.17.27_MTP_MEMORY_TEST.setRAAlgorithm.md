# MTP_MEMORY_TEST.setRAAlgorithm()

Determines whether and when to execute the redundancy analysis algorithm that is defined in the [Redundancy analysis configuration file](<02.12.02.07.03.01.03.01_Redundancy_analysis_configuration_file.md>).

Therefore, before using this function, you must select an RA configuration file with [setRAConfigFile()](<02.12.06.17.29_MTP_MEMORY_TEST.setRAConfigFile.md>).

## Syntax

```
MTP_MEMORY_TEST& setRAAlgorithm (const MTP::RA_EXECUTE_MODE & mode);
```

Parameter
 |

Parameter

 |

Description

 |
 |

mode

 |

The default mode is MTP::RA_EXECUTE_ENABLE_ON_CONCURRENT_MODE.

See all the modes in the table below.

 |

Available options of parameter: <mode>
 |

Option

 |

Description

 |
 |

MTP::RA_EXECUTE_DISABLE

 |

Does not execute the RA algorithm.

 |
 |

MTP::RA_EXECUTE_ENABLE_ON_CONCURRENT_MODE (default)

 |

Executes the algorithm each time when a fail map is ready.

 |

Return value

There is no return value.

## Related information

[MTP_MEMORY_TEST.setRAConfigFile()](<02.12.06.17.29_MTP_MEMORY_TEST.setRAConfigFile.md>)

## Functional changes

- Introduced in MTP 3.2.1
- MTP 3.3.2: Obsoletes the MTP::RA_EXECUTE_ENABLE_ON_DELAYED_MODE option for the mode parameter.
