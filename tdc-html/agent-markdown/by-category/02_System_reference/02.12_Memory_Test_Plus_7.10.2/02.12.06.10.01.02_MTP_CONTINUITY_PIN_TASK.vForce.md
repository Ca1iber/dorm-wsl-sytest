# MTP_CONTINUITY_PIN_TASK.vForce()

The vForce() member function of [MTP_CONTINUITY_PIN_TASK](<02.12.06.10.01_MTP_CONTINUITY_PIN_TASK.md>) lets you specify the voltage to be forced.

The vForce() member function is used for testing shared pins (see the details in [SharedContinuity test method](<02.12.02.05.06.07.09.08_SharedContinuity_test_method.md>)). It cannot be used for non-shared and cross-terminated pins.

## Syntax

```
MTP_CONTINUITY_PIN_TASK& vForce(double value)
```

 |

Parameter

 |

Description

 |
 |

value

 |

The voltage to be forced.

The default unit is [V].

 |
