#### Subtopics

- [Timing setup for system clock domain](<02.12.02.03.05.05.05.02.01_Timing_setup_for_system_clock_domain.md>)
- [Timing setup for strobe clock domain](<02.12.02.03.05.05.05.02.02_Timing_setup_for_strobe_clock_domain.md>)

The GDDR timing architecture implements two logical clock domains:

- The system clock domain, covering address, command and clock signals.
- The strobe clock domain, covering all data related signals like DQi/o, WDQS, RDQS and DM.

The following sections describe the timing setup for both clock domains.
