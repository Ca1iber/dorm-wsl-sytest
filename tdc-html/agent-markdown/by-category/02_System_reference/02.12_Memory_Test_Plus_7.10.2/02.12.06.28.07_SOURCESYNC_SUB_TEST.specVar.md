# SOURCESYNC_SUB_TEST.specVar()

Specfies a timing spec variable used to set up offsets for all [sweeping edges](<02.12.06.28.01_SOURCESYNC_SUB_TEST.edgeList.md>).

## Syntax

```
SOURCESYNC_SUB_TEST& specVar (const string& val);
```

Parameter
 |

Parameter

 |

Description

 |
 |

val

 |

The name of a timing spec variable.

 |
