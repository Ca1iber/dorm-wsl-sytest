# Write Training test method

You can configure the Write Training test method using a set of parameters that are explained below. During write training, the memory controller (ATE) adjusts its DQ drive timing in a way that at the DUT, the correct data is latched into the device. After write training, the rising and falling edges of the associated WCK signals are center aligned to the DQ data eyes. This alignment is achieved by independent driver timing modification of the DQ signals in the memory controller (ATE).

Parameters for the Write Training test method
 |

Name

 |

Comment

 |
 |

TrainingAlgorithm

 |

FullTraining, FastTraining, or EmbeddedTraining. The training mode for the training:

- Full training searches for both edges of the data eye and calculates the center of the eye from these edges. Any values specified in the PinOffsets parameter are added to the position of the first edge to find the starting value for searching for the second edge.
- Fast training searches only for the first edge of an eye. The center of the eye is calculated by adding the PinOffsets value to the position of this edge.
- Embedded training means uses the training logic embedded in HSM3G and HSM6800 cards. This training logic is similar to the one [used by SmarTest](<../02.06_Command_Reference/02.06.09.01.02_Using_embedded_timing_and_level_search_on_a_Smart_Scale_system.md>).

Default value: FullTraining.

 |
 |

Data Input Pin Group

 |

<list of pin groups>. List of setup pin groups, separated by semicolons. Each group consists of one or more pins separated by commas. For example: `A0_Pin; A1_Pin`.

 |
 |

Data Output Pin Group

 |

<list of pin groups>. List of data output result pins or pin groups, separated by semicolons. Each group consists of one or more pins separated by commas. The number of data output pin groups must be equal to the number of address pin groups.

The default for this parameter is specified in the [GDDR5 training configuration file](<02.12.02.05.06.03.01_GDDR5_training_configuration_file.md>).

 |
 |

SweepSpecVars

 |

<list of variable names>. List of timing spec variables for the setup pin groups specified above, one variable per pin group. For example: `A0_ADDRtrng, A1_ADDRtrng`. The number of timing specification variables must be equal to the number of pin groups.

For multiport timing, add @port to the variable name. Or, set the DefaultPort parameter (below) to `@`.

If the EdgeCentering value is Yes (Pin attr), the unit for the SweepSpecVars values must be nanoseconds.

The default for this parameter is specified in the [GDDR5 training configuration file](<02.12.02.05.06.03.01_GDDR5_training_configuration_file.md>).

If the training algorithm is EmbeddedTraining, the SweepSpecVars parameter is not used.

 |
 |

TargetSpecVars

 |

<list of variable names>. A list of variables in which the results of the training (that is, the final values of the sweep spec variables) are stored. For example: `A0_ADDRtrngRep, A1_ADDRtrngRep`. The number of variables must be the same as for SweepSpecVars.

The default for this parameter is specified in the [GDDR5 training configuration file](<02.12.02.05.06.03.01_GDDR5_training_configuration_file.md>).

If the training algorithm is EmbeddedTraining, the TargetSpecVars parameter is not used.

 |
 |

PinOffsets

 |

<number or list of numbers>. This parameter specifies one or more offset values that are added to the values of the first edges found.

Its use is different depending on the training mode:

- In full training mode, the pin offset is added to the value of the first edge to calculate the starting value for finding the second edge.
- In fast training, the pin offset is added to the value of the first edge to calculate the location of the eye center.

The syntax for the parameter is the same as for SweepStart, below.

This parameter is optional.

If the training algorithm is EmbeddedTraining, the PinOffsets parameter is not used.

 |
 |

SweepStart

 |

<number or list of numbers>. The starting point of the specification search.

The unit is the same as the unit specified in the timing equation for the sweep specification variable.

There are different ways of specifying the sweep start values:

- If you specify only one value, it applies to all setup pins.
- If you specify a list of values separated by commas, each applies to one pin group only. In this case, the number of sweep start values must be the same as the number of pin groups.
- To specify a sweep start for a particular pin group, enter <number>`@`<pin_group>. A mixture of <number> and <number>`@`<pin_group> notation is possible; in this case, the single value applies to all pin groups, except for those for which an individual value has been specified.

If you do not specify a number, the sweep starts at -4 test system periods from the expected location of the edge.

 |
 |

SweepStop

 |

<number or list of numbers>. The ending point of the specification search.

The syntax is the same as for SweepStart, above.

If you do not specify a number, the sweep ends at 12 test system periods after the expected location of the edge.

 |
 |

MinOpenEye

 |

<number>. The step size in nanoseconds for the linear search. The specified time must be significantly shorter than the minimum eye open time.

The default for this parameter is specified in the [GDDR5 training configuration file](<02.12.02.05.06.03.01_GDDR5_training_configuration_file.md>).

 |
 |

AlignAccuracy

 |

<number>. Specify the resolution of the binary search in nanoseconds.

The default for this parameter is specified in the [GDDR5 training configuration file](<02.12.02.05.06.03.01_GDDR5_training_configuration_file.md>).

 |
 |

EdgeCentering

 |

Yes (Spec), Yes (Pin attr), Yes (Embedded), or No. Whether and how to use the edge center timing value for further measurements:

- Yes (Spec): Centering by setting spec values is performed.
- Yes (Pin attr): Centering by setting pin attributes is performed.
- Yes (Embedded): Centering is done in the test head card. The method used is similar to the one the SmarTest [EyeFinder](<02.12.02.05.06.04_EyeFinder.md>) uses.
- No: No further centering is performed.

If this parameter is set to Yes (Pin attr), the unit for the sweep spec variables must be nanoseconds.

If the training algorithm is EmbeddedTraining, only the values Yes (Embedded) and No are available for this parameter.

Default value: No

 |
 |

DefaultPort

 |

<Port_name>. The default port applied to sweep specification variables for which no individual port has been specified using the @port notation.

The default for this parameter is specified in the [GDDR5 training configuration file](<02.12.02.05.06.03.01_GDDR5_training_configuration_file.md>).

 |
 |

SweepType

 |

Absolute or Relative. Which values to use for the sweep:

- Absolute: The sweep begins at SweepStart and ends at SweepStop.
- Relative: The sweep begins at (SweepStart + current value of SweepSpecVars) and ends at (SweepStop + current value of SweepSpecVars).

Default value: Absolute

 |

A setup pin is a pin to which a timing variation is applied.
