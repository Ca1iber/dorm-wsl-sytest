# Dynamic bus inversion

#### Subtopics

- [Setting up dynamic bus inversion](<02.12.03.04.10.01_Setting_up_dynamic_bus_inversion.md>)

Dynamic bus inversion (DBI) inverts data on a bus when a specified condition is met. Bus inversion is applied after scrambling.

Dynamic bus inversion settings are defined in the device architecture file. The desired setting is activated in the APG pattern file. The bus inversion is applied in the device access file by using the dbi macro in the :operation: column of device accesses.
