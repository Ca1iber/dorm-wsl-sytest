# Memory Test Cards

The description of the latest Memory Test Card HSM2200 is introduced.

HSM2200 is a speed-binned hardware version of HSM3600. HSM2200 offers 2.2 Gbps at-speed IO and at-speed memory core test.

It provides a cost-effective final test solution for DDR3 and GDDR3.
