Eases you to use the legacy RA algorithm.

This API is defined in the header file /opt/93000mts/mts/execution_engine/include/MtpRaAlgorithmHolder.h.

## Syntax

```
MTP_RA_ALGORITHM_HOLDER;
MTP_RA_ALGORITHM_HOLDER (const STRING& path);
```

Both are constructors. Either one can be used to create MTP_RA_ALGORITHM_HOLDER objects.

- If using the first one, you must use the [init()](<02.12.06.20.01_MTP_RA_ALGORITHM_HOLDER.init.md>) member function to initialize it.
- If using the second one, do not use the [init()](<02.12.06.20.01_MTP_RA_ALGORITHM_HOLDER.init.md>) member function.

Parameter
 |

Parameter

 |

Description

 |
 |

path

 |

The file name and the path of the shared library of the legacy RA algorithm.
