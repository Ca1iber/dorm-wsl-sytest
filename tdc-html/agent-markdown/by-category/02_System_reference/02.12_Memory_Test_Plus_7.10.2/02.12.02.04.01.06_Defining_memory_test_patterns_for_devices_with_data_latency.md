# Defining memory test patterns for devices with data latency

Some memory devices require a delay in time between when the operation is initiated and when the data is received from or driven into a device. This delay can often be multiple cycles in duration. It is recommended that the test system timing edges are used to generate this delay and to not program the delay into the pattern. The memory test pattern should be programmed as if there is no delay. The test system edges can be delayed up to 12 cycles later.
