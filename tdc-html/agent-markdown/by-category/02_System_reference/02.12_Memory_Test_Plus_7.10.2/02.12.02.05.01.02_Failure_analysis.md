# Failure analysis

To execute your test flow with delayed availability of address-based data for all testsuites in a test flow, follow the workflow shown in the figure below.

  ![FA case workflow using the ExecutionEngine test method](<../../../../raw/118225.png>)

You need to initiate the creation of address data from the saved data log and the [BFM Viewer](<02.12.04.04_Bit_Fail_Map_Viewer.md>) file (.bfm).

Set the parameters for the test method as described in [Parameters for the ExecutionEngine test method](<02.12.02.05.06.01.03.01_Parameters_for_the_ExecutionEngine_test_method.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
- MTP 3.0.1: The ExecuteEngine test method replaces the Memtest test methods.
