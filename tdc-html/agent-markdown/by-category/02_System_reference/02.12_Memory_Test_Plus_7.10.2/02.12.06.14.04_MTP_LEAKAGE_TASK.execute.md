# MTP_LEAKAGE_TASK.execute()

The execute() member function of [MTP_LEAKAGE_TASK](<02.12.06.14_MTP_LEAKAGE_TASK.md>) executes the shared parallel leakage test based on the measurement conditions set with the [pin()](<02.12.06.14.02_MTP_LEAKAGE_TASK.pin.md>) member function.

Note that when using this member function, you must:

- Use the [CONNECT](<../02.07_Test_Method_Reference/02.07.04.01.18_CONNECT.md>) API before using execute() since the leakage test is measured in a connected state.
- Call the [postExecute()](<02.12.06.14.05_MTP_LEAKAGE_TASK.postExecute.md>) member function at the end of the leakage test after all pins have been measured.

## Syntax

```
void execute()
```
