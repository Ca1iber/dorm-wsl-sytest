# MTL Device Access File Simplification

In the device access file (*.dvac) no quotes are needed in the :states: column.

For more information refer to Device access examples in [Memory Test Language (MTL) Programming Reference](<02.12.03_Memory_Test_Language__MTL__Programming_Reference.md>).
