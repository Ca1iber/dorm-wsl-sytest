# MTP_MEMORY_TEST.print()

prints out the test results.

## Syntax

```
void print (ostream & out = std::cout) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

out

 |

The data stream to be printed out. The default stream is stdout.

 |

Return value

There is no return value.
