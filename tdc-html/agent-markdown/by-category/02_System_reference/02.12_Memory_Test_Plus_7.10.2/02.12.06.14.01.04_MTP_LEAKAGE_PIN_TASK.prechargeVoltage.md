# MTP_LEAKAGE_PIN_TASK.prechargeVoltage()

The prechargeVoltage() member function of [MTP_LEAKAGE_PIN_TASK](<02.12.06.14.01_MTP_LEAKAGE_PIN_TASK.md>) lets you specify the precharge voltage for shared, non-shared, or cross-terminated pins.

For shared pins, you must specify the precharge voltage, and the voltage value is equal to the force voltage which is set by the [vForce()](<02.12.06.14.01.01_MTP_LEAKAGE_PIN_TASK.vForce.md>) member function.

For non-shared and cross-terminated pins, setting the precharge voltage is optional.If a precharge is required, set it close to 0 V.

## Syntax

```
MTP_LEAKAGE_PIN_TASK& prechargeVoltage(double value)
```

 |

Parameter

 |

Description

 |
 |

value

 |

The precharge voltage for PPMU in volts.

The default is 0 V.

 |
