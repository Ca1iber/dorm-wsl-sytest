# Debugging

For debugging you can interactively execute one [test suite](<02.12.02.05.06.01.01_Adding_the_ExecutionEngine_test_method_to_a_testflow.md>) with immediate availability of address-based data for the [BFM Viewer](<02.12.04.04_Bit_Fail_Map_Viewer.md>). To [save the data log file](<02.12.02.05.09_Saving_the_data_log_file.md>), click in the report window on Log File and Save Datalog Stream and Clear. This workflow is shown in the figure below.

  ![Debug use case workflow using the ExecutionEnginet test method](<../../../../raw/118224.png>)

Set the test method parameters as described in [Setting parameters for the ExecutionEngine test method](<02.12.02.05.06.01.03_Setting_parameters_for_the_ExecutionEngine_test_method.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
- MTP 3.0.1: The ExecuteEngine test method replaces the Memtest test methods.
