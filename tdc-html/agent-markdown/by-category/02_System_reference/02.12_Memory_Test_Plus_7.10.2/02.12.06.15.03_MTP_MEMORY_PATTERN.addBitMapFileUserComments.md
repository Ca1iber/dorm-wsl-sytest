# MTP_MEMORY_PATTERN.addBitMapFileUserComments()

The addBitMapFileUserComments() member function of [MTP_MEMORY_PATTERN](<02.12.06.15_MTP_MEMORY_PATTERN.md>) lets you add arbitrary comments to generated bit fail map files.

This is an optional method.

## Syntax

```
MTP_MEMORY_PATTERN& addBitMapFileUserComments(const STRING& comments)
```

 |

Parameter

 |

Description

 |
 |

comments

 |

Any text that you want to add as a comment to the bit fail map generated with [generateBitmapFile()](<02.12.06.15.04_MTP_MEMORY_PATTERN.generateBitmapFile.md>).

The default is the list of result pins.

 |

## Example

To add the text "March6n Manual Filemap" to the generated bit fail map file:

```
MTP_MEMORY_TEST memoryTest;
MTP_MEMORY_PATTERN &march6N = memoryTest.getMemroyPort("A").getMemoryPattern("march6N");
march6N.setBitMapFilePath("/data/Bitmaps/").addBitMapFileUserComments("March6n Manual Failmap");
```
