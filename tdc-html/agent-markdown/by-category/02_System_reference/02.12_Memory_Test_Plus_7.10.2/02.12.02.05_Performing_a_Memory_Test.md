This section describes the process of setting up:

- A memory device for testing
- The Memtest test methods to execute the memory test

## Preliminary steps

Before you set up a Memtest test method for use with a new memory device, you need to set up:

- [Vectors](<02.12.02.05.02_Generate_vectors_and_reconstruction_information.md>)
- [Reconstruction information](<02.12.02.05.02_Generate_vectors_and_reconstruction_information.md>)
- [Address scrambling](<02.12.02.05.03_Setting_up_address_scrambling.md>)

After the above preliminary steps, follow the procedure below:

- Add a [test suite to the test flow](<02.12.02.05.06.01.01_Adding_the_ExecutionEngine_test_method_to_a_testflow.md>) containing a test method.
- [Set the test suite flags](<02.12.02.05.06.01.02_Setting_test_suite_flags_for_the_ExecutionEngine_test_method.md>) depending on your [use case](<02.12.02.05.01_Use_cases.md>).
- [Set the test method parameter](<02.12.02.05.06.01.03_Setting_parameters_for_the_ExecutionEngine_test_method.md>) depending on your [use case](<02.12.02.05.01_Use_cases.md>).
- Execute the test suite or [test flow](<../02.08_Setup_and_Result_Tools/02.08.04.32.01_Introduction_of_the_Testflow.md>).Note This step applies only to debugging on immediate execution and for failure analysis with delayed execution.
- Analyze the data using the [BFM Viewer](<02.12.04.04_Bit_Fail_Map_Viewer.md>).Note This step applies only to debugging on immediate execution and for failure analysis with delayed execution.
