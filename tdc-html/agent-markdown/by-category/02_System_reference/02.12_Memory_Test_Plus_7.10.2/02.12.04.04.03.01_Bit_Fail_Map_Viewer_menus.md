# Bit Fail Map Viewer menus

#### Subtopics

- [Session menu](<02.12.04.04.03.01.01_Session_menu.md>)
- [Settings menu](<02.12.04.04.03.01.02_Settings_menu.md>)
- [Extras menu](<02.12.04.04.03.01.03_Extras_menu.md>)
- [Help menu](<02.12.04.04.03.01.04_Help_menu.md>)

The menus of the BFM Viewer let you set up the program, manage sessions, export data, and get help.

The BFM Viewer has these menus:

- [Session](<02.12.04.04.03.01.01_Session_menu.md>) for setting the device and managing sessions
- [Settings](<02.12.04.04.03.01.02_Settings_menu.md>) for configuring the program
- [Extras](<02.12.04.04.03.01.03_Extras_menu.md>) for additional configuration and for exporting bit fail maps as text
- [Help](<02.12.04.04.03.01.04_Help_menu.md>)
