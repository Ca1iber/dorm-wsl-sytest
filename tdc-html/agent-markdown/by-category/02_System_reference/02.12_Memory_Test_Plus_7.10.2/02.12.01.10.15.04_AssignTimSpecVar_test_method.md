# AssignTimSpecVar test method

For XDR memory testing, use the AssignTimSpecVar test method (in class testmethodlib.XDR_Tools) instead of several EyeFinder test suites.

## Benefit

In a high volume manufacturing (HVM) environment it gives more flexibility and saves execution time.

## More Information

For more information, refer to AssignTimSpecVar test method.
