# SOURCESYNC_SUB_TEST.sweepStop()

Specifies the stop value for the sweeping spec variable specified with [SOURCESYNC_SUB_TEST.sweepSpecVar()](<02.12.06.28.11_SOURCESYNC_SUB_TEST.sweepSpecVar.md>).

Once you set up this function, the sweeping of every edge will stop at the point by assigning [the sweeping spec variables](<02.12.06.28.11_SOURCESYNC_SUB_TEST.sweepSpecVar.md>) to this value.

## Syntax

```
SOURCESYNC_SUB_TEST& sweepStop (const string& sweepStop);
```

Parameter
 |

Parameter

 |

Description

 |
 |

sweepStop

 |

The stop value of the[ sweeping spec variable](<02.12.06.28.11_SOURCESYNC_SUB_TEST.sweepSpecVar.md>).

- If you have specified multiple sweeping spec variables with [SOURCESYNC_SUB_TEST.sweepSpecVar()](<02.12.06.28.11_SOURCESYNC_SUB_TEST.sweepSpecVar.md>), specify multiple stop values here accordingly separated with ";". For example, "7; 8; 9".
- If [UsePredefinedTimingFile is NO](<02.12.06.28.13_SOURCESYNC_SUB_TEST.usePredefinedTimingFile.md>), the unit in ns.
- If [UsePredefinedTimingFile is YES](<02.12.06.28.13_SOURCESYNC_SUB_TEST.usePredefinedTimingFile.md>), the number here is an integer.
 |
