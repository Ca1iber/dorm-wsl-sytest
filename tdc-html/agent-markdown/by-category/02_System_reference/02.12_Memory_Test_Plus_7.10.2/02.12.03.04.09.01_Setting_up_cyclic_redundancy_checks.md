# Setting up cyclic redundancy checks

Setting up cyclic redundancy checks (CRC) requires defining the settings, activating the desired settings, and accessing the CRC result in the device access file.

## About this task

Set up CRCs to quickly check data buses for errors.

## Before you begin

Make sure that the [pin configuration](<02.12.03.03.09.01_Pin_configuration_file.md>) and [pin mapping files](<02.12.03.03.06_Pin_mapping_file.md>) are properly set up.

## Procedure

-  Define the CRC settings in the [Device architecture file](<02.12.03.03.05_Device_architecture_file.md>).

  -  Add a :crc: block and name it.
  -  Add a :bitSequence: block for each set of pins from which the CRC is to be calculated.
  -  Add a :bitexpression: block for each way you want to calculate a CRC from a data stream.
  -  Add a :configuration: block for each combination of a bit sequence and a bit expression that you want to use as a argument for the crc macro.

Repeat steps a through d for each additional group of CRC settings that you want to create.

-  Specify the desired CRC setting in the [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>) by adding the :crc: keyword and the name of the desired CRC setting (from step 1a) to the file.
-  Apply the crc macro in the :operation: column of every device access where you want to use it. More information on this is available in [Macros and functions in device accesses](<02.12.03.03.04.02_Macros_and_functions_in_device_accesses.md>).

## Results

When the compiled program is run, cyclic redundancy checks are calculated for the specified buses.

Note Using the crc macro in the :operation: column disables the data column in that :apgAccess: element.
