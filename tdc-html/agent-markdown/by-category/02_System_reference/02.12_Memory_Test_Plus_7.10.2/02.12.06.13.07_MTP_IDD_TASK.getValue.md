# MTP_IDD_TASK.getValue()

The getValue() member function of [MTP_IDD_TASK](<02.12.06.13_MTP_IDD_TASK.md>) returns the measured current in ampere ([A]) for a specified pin.

## Syntax

```
double getValue(const string & pin)const
```

 |

Parameter

 |

Description

 |
 |

pin

 |

The name of a pin whose measured current you want to retrieve.

The unit for the retrieved current is ampere ([A]).

 |
