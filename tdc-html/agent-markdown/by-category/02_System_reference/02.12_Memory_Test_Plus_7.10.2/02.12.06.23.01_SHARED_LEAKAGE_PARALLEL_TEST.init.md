# SHARED_LEAKAGE_PARALLEL_TEST.init()

The init() member function of [SHARED_LEAKAGE_PARALLEL_TEST](<02.12.06.23_SHARED_LEAKAGE_PARALLEL_TEST.md>) lets you do initializations for a test.

You must invoke this member function ahead of any other functions when you create a test method with the SHARED_LEAKAGE_PARALLEL_TEST API.

## Syntax

```
SHARED_LEAKAGE_PARALLEL_TEST& init()
```
