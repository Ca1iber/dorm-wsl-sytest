# SHARED_VBUMP_TEST.sharingConfigFile()

The sharingConfigFile() member function of [SHARED_VBUMP_TEST](<02.12.06.24_SHARED_VBUMP_TEST.md>) lets you specify the name of the [driver sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>) used which should be located in <device directory>/configuration/.

## Syntax

```
SHARED_VBUMP_TEST& sharingConfigFile(const string& filename)
```

 |

Parameter

 |

Description

 |
 |

filename

 |

Name of the driver sharing configuration file used.

This file should be in <device directory>/configuration/.

 |

## Example

```
SHARED_VBUMP_TEST mTest;
mTest.sharingConfigFile("default.cfg");
```
