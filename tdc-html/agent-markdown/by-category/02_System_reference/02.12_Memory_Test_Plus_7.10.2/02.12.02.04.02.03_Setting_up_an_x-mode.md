# Setting up an x-mode

X-modes are used to test devices at very high rates by executing several device cycles in one tester cycle.

## About this task

Setting up an x-mode requires specifying appropriate parameters in the device access file. No modifications to any of the other setup or program files are needed.

## Before you begin

Make sure that the :devCyc: and :stateParam: keywords are not used in the device access file. They are incompatible with transparent x-modes.

## Procedure

-  Open the device access file with a text editor.
-  Add this code to the file:

```
:xModeDefinition:
{
  :default: <default_x-mode>
}
```

<default_x-mode`>` is the x-mode you want to specify; 1, 2, 3, 4, 6, and 8 are supported.

-  If you want to run individual pins in x-modes other than the default mode (specified above), add a table after the declaration of the default x-mode:

```
:xModeDefinition:
{
  :default: <default_x-mode>
  :table:
  {
    :format:
    { :pin:       :xMode:      }
    { <pin-name><pin_x-mode> }
  }
}
```

<pin-name> is the name of the desired pin as specified in the pin mapping file; <pin_x-mode> is the x-mode you want to specify for that pin. Multipliers of 1, 2, 3, 4, 6, and 8 are supported.

You can specify as many pins and corresponding x-modes as desired in the table; to do so, add a new line for each pin.

-  Save and close the device access file.

## Results

The compiled test pattern will run the test on all pins with the multiplier specified after the :default: keyword. If pins have been specified after the :table: keyword, the pattern will run at the specified multipliers for these pins.

## Example

```
:xModeDefinition:
{
  :default: 2
  :table:
  {
    :format:
    { :pin:       :xMode:      }
    { CFM         8            }
  }
}
```
