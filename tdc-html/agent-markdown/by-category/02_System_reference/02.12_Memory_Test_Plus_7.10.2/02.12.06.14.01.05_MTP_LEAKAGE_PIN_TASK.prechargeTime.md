# MTP_LEAKAGE_PIN_TASK.prechargeTime()

The prechargeTime() member function of [MTP_LEAKAGE_PIN_TASK](<02.12.06.14.01_MTP_LEAKAGE_PIN_TASK.md>) lets you specify the precharging duration.

For shared pins, you must specify the precharge time.

For non-shared and cross-terminated pins, you only need to specify the precharging time when you have specified a precharge voltage greater than 0 V. The precharge voltage is set by [prechargeVoltage()](<02.12.06.14.01.04_MTP_LEAKAGE_PIN_TASK.prechargeVoltage.md>).

## Syntax

```
MTP_LEAKAGE_PIN_TASK& prechargeTime(double time)
```

 |

Parameter

 |

Description

 |
 |

time

 |

The time for precharge. The unit is second ([s]).

 |
