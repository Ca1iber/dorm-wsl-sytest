# Introduction

V93000 HSM series is targeted at final test of high-speed memories offering 3.6 at-speed I/O and at-speed memory core test to the full extent of the available hardware's capabilities to ensure the required test quality and fast yield learning at competitive cost-of-test.

It offers dedicated features for GDDR but also the flexibility to address all future DRAM technologies ensuring investment protection.

GDDR (and DDR) memory uses a different I/O concept called source synchronous strobe. All groups of eight I/O pins have device-dependent timing and skew. Traditional memory ATE has a shared timing strobe across all sites and all groups and devices, resulting in significantly reduced timing margins. The V93000 uses its per-pin timing to adjust its per-pin strobes dependent on those groups per device and site. Thus the per-pin timing offers natural support new I/O concepts and enlarging the available timing margins for highest manufacturing yields.
