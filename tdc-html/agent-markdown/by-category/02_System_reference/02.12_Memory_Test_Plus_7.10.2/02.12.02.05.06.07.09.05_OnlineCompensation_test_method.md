# OnlineCompensation test method

The test method compensates the delay effect stemming from test sites in shared setups that do not contain a device.

The merged fixture delay file that you generated using the fd_merge tool contains delay data for a fully populated daisy chained test sites. If the device sockets on the socket board are not fully populated during test, the delays on the shared driver lines change for devices that are populating sockets which are "later" in the daisy chain. The reason is the change in capacitive load on the empty socket.

The OnlineCompensation test method, available in the ddr_solution_tools/DriverSharing directory, re-measures the absence of a device in a socket and corrects the fixture delay for the sockets behind the empty socket accordingly.

The test suite containing the OnlineCompensation method must be inserted in the test flow before functional test but after the continuity test. The test method has no fail exit, therefore you insert a run test suite.

Note the following rules. Perform compensation only:

- For enabled test sites
- If the new fixture delay is different from current setup
- For channels with same context as that of the test suite
- If the configuration of current test suite is different from that of the previous OnlineCompensation test suite
