# ResetOverCurrentProtection test method

This test method resets overcurrent protection relays. It should aways be used at the beginning of a testflow.

Some load boards with DPS sharing contain overcurrent protection relays to prevent damage to sockets and load boards from currents exceeding the allowable maximum.

Once triggered, these relays stay open until they are reset. This test method allows you to reset them.

The utility line settings needed to reset the relays are specified in the utility control section of the [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>).

This test method is useful only when DPS sharing is implemented.

The keyword for specifying the utility line settings for ResetOverCurrentProtection in the utility control section of the sharing configuration file is oc_reset.

For information on the syntax for utility line settings, see [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>).
