# MTP_MULTI_FILTER

#### Subtopics

- [MTP_MULTI_FILTER.addAddressFilter()](<02.12.06.18.01_MTP_MULTI_FILTER.addAddressFilter.md>)
- [MTP_MULTI_FILTER.isValidAddress()](<02.12.06.18.02_MTP_MULTI_FILTER.isValidAddress.md>)

This class defines a filter which consists of several filters defined by [MTP_ADDRESS_FILTER](<02.12.06.09_MTP_ADDRESS_FILTER.md>) individually.

This class is used by [MTP_MEMORY_TEST.addAddressFilter()](<02.12.06.17.01_MTP_MEMORY_TEST.addAddressFilter.md>).

This API is defined in the heder file /opt/93000mts/mts/execution_engine/include/MtpAddressFilter.h.

## Syntax

```
MTP_MULTI_FILTER();
```

Creates an object to define this filter.

List of parameters

There are no parameters.

## Return value

Using [MTP_MULTI_FILTER.isValidAddress()](<02.12.06.18.02_MTP_MULTI_FILTER.isValidAddress.md>), it returns true or false for an address within the filter range or not.

Otherwise, there is no return value.

## Example

```
MTP_MULTI_FILTER filter;
```
