# SHARED_CONTINUITY_TEST.forceVoltage()

The forceVoltage() member function of [SHARED_CONTINUITY_TEST](<02.12.06.21_SHARED_CONTINUITY_TEST.md>) lets you specify the force voltage to be applied on the termination DPS.

## Syntax

```
SHARED_CONTINUITY_TEST& forceVoltage(double voltage)
```

 |

Parameter

 |

Description

 |
 |

voltage

 |

The force voltage to be applied on the termination DPS.

- The unit is V.
- The default voltage value is 1 V.

 |

## Example

```
SHARED_CONTINUITY_TEST mTest;
mTest.forceVoltage(1.3);
mTest.forceVoltage(1300 mV);
```
