# DataTrainingFlex

#### Subtopics

- [Setting up timing equation for the DataTrainingFlex test method](<02.12.05.04.06.04.01_Setting_up_timing_equation_for_the_DataTrainingFlex_test_method.md>)
- [Parameters for the DataTrainingFlex test method](<02.12.05.04.06.04.02_Parameters_for_the_DataTrainingFlex_test_method.md>)

The DataTrainingFlex test method expands on the DataTraining test method by providing training for both device write (input) as well as read (output) operations. You can select:

- Read-only training
- Write-only training
- Read-and-then-write training
- Write-and-then-read training
