The SHARED_CONTINUITY_TEST class provides an API for checking the continuity and finding the short circuits for the DUTs with [driver sharing](<02.12.02.05.06.07.01_Driver_sharing_concepts.md>). It tests shared, non-shared, and cross-terminated pins in a single pass.

When you use this API to create your own custom test method, you should:

- Add the following limits according to the test pins:

  - "Shared Voltage(mv)": Defines the minimum and maximum pass voltages (mv) for the shared pins.
  - "Non-Shared Voltage(mv)": Defines the minimum and maximum pass voltages (mv) for the non-shared pins.
  - "Cross-Terminated Voltage(mv)": Defines the minimum and maximum pass voltages (mv) for the cross-terminated pins.

For how to add limits and their values to a test method, see [How to create a universal test method class](<../02.07_Test_Method_Reference/02.07.02.02.02_How_to_create_a_universal_test_method_class.md>).

- Include the driver sharing API library and header file to complete a test method code. For details, see [Setting up for using driver sharing APIs](<02.12.02.05.06.07.09.04_Setting_up_for_using_driver_sharing_APIs.md>).Note The SHARED_CONTINUITY_TEST API is available only for MTP.

There are two other methods to check the shared continuity:

- A [SharedContinuity test method](<02.12.02.05.06.07.09.09_SharedContinuity_syntax.md>) included with MTP: Use it when you Do not have special requirements such as a customized testing algorithm or a special output format. See [SharedContinuity syntax](<02.12.02.05.06.07.09.09_SharedContinuity_syntax.md>).

It is the easiest way to develop a test.

- The [MTP_CONTINUITY_TASK](<02.12.06.10_MTP_CONTINUITY_TASK.md>) API: Use it when you want to test the pins (either shared, non-shared or cross-terminated pins) with different test conditions in one test method.

More differences between the SharedContinuity test method, SHARED_CONTINUITY_TEST, and MTP_CONTINUITY_TASK are described in [MTP_CONTINUITY_TASK](<02.12.06.10_MTP_CONTINUITY_TASK.md>).

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/SHARED_CONTINUITY_TEST.h.

## Examples

### Note

The following examples demonstrate how to use this API within a test method. If you want to see a complete test method code via SHARED_CONTNUITY_TEST, find it in /opt/93000mts/mts/solution_tools/common/sh_lib/DriverSharing.tar.gz.

### Example 1

Performing the continuity and short circuits test for the shared, and non-shared pins.

```
#include "solution_tools.h"
#include "testmethod.hpp"
#include "mapi.hpp"

class CSharedContinuity: public testmethod::TestMethod
{
protected:
  virtual void run()
  {
    ON_FIRST_INVOCATION_BEGIN();
    {
      // Always do initialization at the beginning of test
      mTest.init();

      // hand over the parameters to the test class
        mTest.pinNonShared("DQ_Bus,DQS_DiffBus,DM")
             .forceCurrentNonShared(100 uA)
             .pinCross("Clock_Bus")
             .forceCurrentCross(100 uA)
             .sharingConfigFile("default.cfg")
             .pinShared("Addr_Bus,Command_Bus")
             .forceVoltage(1.1)
             .terminationDPS("VTERM")
             .supplyDPS("VDD,VDDQ")
             .settlingTime(0)
             .output(MTP::OUTPUT_REPORT_UI);

      // execute the test
      mTest.execute();
    }
    ON_FIRST_INVOCATION_END();

    // set result
    mTest.judgeAndLog();

    // Print out in the UI Report Window.
    mTest.print();
  }

private:
  SHARED_CONTINUITY_TEST mTest;
};
```

### Example 2

Customizing the output.

```
#include "solution_tools.h"
#include "testmethod.hpp"
#include "mapi.hpp"

class CSharedContinuity: public testmethod::TestMethod
{
protected:
    virtual void run()
    {
      ON_FIRST_INVOCATION_BEGIN();
      {
        // Always do initialization at the beginning of test
        mTest.init();

        // hand over the parameters to the test class
        mTest.pinNonShared("DQ_Bus,DQS_DiffBus,DM")
             .forceCurrentNonShared(100 uA)
             .pinCross("Clock_Bus")
             .forceCurrentCross(100 uA)
             .sharingConfigFile("default.cfg")
             .pinShared("Addr_Bus,Command_Bus")
             .forceVoltage(1.1)
             .terminationDPS("VTERM")
             .supplyDPS("VDD,VDDQ")
             .settlingTime(0)
             .output(MTP::OUTPUT_REPORT_UI);

        // execute the test
        mTest.execute();
      }
      ON_FIRST_INVOCATION_END();

      // set result
      mTest.judgeAndLog();

      // Print out in the UI Report Window.
      STRING_VECTOR pinSharedNames =
        PinUtility.getDigitalPinNamesFromPinList("Addr_Bus,Command_Bus", TM::ALL_DIGITAL, TRUE);
      STRING_VECTOR pinNonSharedNames =
        PinUtility.getDigitalPinNamesFromPinList("DQ_Bus,DQS_DiffBus,DM", TM::ALL_DIGITAL, TRUE);
      STRING_VECTOR pinCrossNames =
        PinUtility.getDigitalPinNamesFromPinList("Clock_Bus", TM::ALL_DIGITAL, TRUE);

      cout << "Test result of site " << CURRENT_SITE_NUMBER() << ": " << mTest.getPassFail() << endl;

      for (STRING_VECTOR::const_iterator it = pinSharedNames.begin();
           it != pinSharedNames.end(); ++it)
      {
        cout << "PIN (" << *it << ")\t" << mTest.getPassFail(*it) << "\t" << mTest.getValue(*it) << endl;
      }

      for (STRING_VECTOR::const_iterator it = pinNonSharedNames.begin();
           it != pinNonSharedNames.end(); ++it)
      {
        cout << "PIN (" << *it << ")\t" << mTest.getPassFail(*it) << "\t" << mTest.getValue(*it) << endl;
      }

      for (STRING_VECTOR::const_iterator it = pinCrossNames.begin();
           it != pinCrossNames.end(); ++it)
      {
        cout << "PIN (" << *it << ")\t" << mTest.getPassFail(*it) << "\t" << mTest.getValue(*it) << endl;
      }
    }

private:
    SHARED_CONTINUITY_TEST mTest;
};
```
