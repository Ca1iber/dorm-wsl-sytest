# MTP_MEMORY_TEST.setMaxFailingAddressesToLogPerPin()

The setMaxFailingAddressesToLogPerPin() member function of [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) lets you specify how many failing addresses will be logged for each result pin.

This is an optional method.

## Syntax

```
MTP_MEMORY_TEST& setMaxFailingAddressesToLogPerPin(const LONG64 number)
```

 |

Parameter

 |

Description

 |
 |

number

 |

This parameter specifies the maximum number of failing addresses that will be logged for each result pin.

We recommend that you specify the same value in this function as in [setMaxFailingAddressesToReconstructPerPin()](<02.12.06.17.23_MTP_MEMORY_TEST.setMaxFailingAddressesToReconstructPerPin.md>).

The default is to log no failing addresses (that is, the default value is 0).

 |

## Example

To limit the number of reconstructed addresses and of logged addresses per pin to 1024 each:

```
MTP_MEMORY_TEST memoryTest();
memoryTest. setMaxFailingAddressesToReconstructPerPin(1024). setMaxFailingAddressesToLogPerPin(1024);
```
