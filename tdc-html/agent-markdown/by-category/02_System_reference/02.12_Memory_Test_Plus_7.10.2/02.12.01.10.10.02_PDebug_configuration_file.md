# PDebug configuration file

PDebug can now be controlled through a configuration file.

## Benefit

The pDebug configuration file lets you access some options that are not available in the graphical user interface. It also enables you to quickly switch between different groups of settings.

  Note PDebug becomes obsolete in MTP 7.5.0, MTP 7.4.5, and future versions.
