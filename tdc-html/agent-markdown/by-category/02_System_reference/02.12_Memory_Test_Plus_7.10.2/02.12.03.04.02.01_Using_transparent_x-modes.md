# Using transparent x-modes

Using x-modes requires very little changes to the setup files. You do need to observe some guidelines, however.

## About this task

This task describes what you need to do when you want to activate x-modes, deactivate them, or switch between them.

## Before you begin

The [MTL Configuration Files](<02.12.03.03_MTL_Configuration_Files.md>) should be set up correctly. [Indirect waveform mapping](<02.12.03.04.03.02_Setting_up_indirect_waveform_mapping.md>) must not be used.

## Procedures

### Activating transparent x-modes

- Add the using defaultxmode statement to the [Pin mapping file](<02.12.03.03.06_Pin_mapping_file.md>).
- If there are pins that need to run at a different x-mode, add `xmode` attributes to their definitions in the pin mapping file.

Note that all pins grouped in one PINS section of the [Pin configuration file](<02.12.03.03.09.01_Pin_configuration_file.md>) must share the same x-mode.

- Set up a wavetable for the desired x-mode in the [Timing file](<02.12.03.03.09.02_Timing_file.md>) and reference it in the [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>) using the :waveformMap: keyword.

To do so, either fill the wavetable yourself by defining all combinations of logical states or let the compiler do it by using the `-w`[compiler switch](<02.12.03.02.05.01_apgc_command_syntax.md>). (In the [MTL Compiler Control dialog](<02.12.03.02.04.01_MTL_Compiler_Control_dialog.md>), this is the Automatic Waveform Generation option.)

### Deactivating transparent x-modes

- Remove any using defaultxmode statements and xmode attributes from the [Pin mapping file](<02.12.03.03.06_Pin_mapping_file.md>).
- In the APG pattern file, use the :waveformMap: keyword to specify a wavetable from the timing file that is set up for no x-mode. (See step 3 in "Activating x-modes", above.)

### Switching transparent x-modes

- Change the parameters of the using defaultxmode and xmode= statements in the [Pin mapping file](<02.12.03.03.06_Pin_mapping_file.md>) as required.
- In the APG pattern file, use the :waveformMap: keyword to specify a wavetable from the timing file that is set up for the new x-mode. (See step 3 in "Activating transparent x-modes", above.)

## Results

The transparent x-mode is set up as required.

## What to do next

Setting up padding, as described in [Setting up padding](<02.12.03.04.02.02_Setting_up_padding.md>).
