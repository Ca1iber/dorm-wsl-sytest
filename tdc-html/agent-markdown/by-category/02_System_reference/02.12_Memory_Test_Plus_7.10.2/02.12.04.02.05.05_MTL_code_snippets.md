# MTL code snippets

This topic introduces the MTL code snippets that you can call to use when you edit your configuration files in the MTP editor.

These code snippets are designed for setups in APG pattern file, device access file, device architecture file, and DC event file.

Code snippets for the APG pattern file:

- MTP_MTL_APG_DEFINES
- MTP_MTL_PROG_PARAMETER

Code snippets for the device access file:

- MTP_MTL_APG_ACCESS
- MTP_MTL_COUNTED_MATCH_PAD
- MTP_MTL_CONSTANTS

Code snippets for the device architecture file:

- MTP_MTL_MAINTENANCE_OPERATION
- MTP_MTL_SCRAMBLE
- MTP_MTL_BIT_ORDERING
- MTP_MTL_BIT_INVERSION
- MTP_MTL_DBI
- MTP_MTL_CRC

Code snippets for the DC event file:

- MTP_MTL_DC_SET

## Code snippets

### MTP_MTL_APG_DEFINES

```
:defines:
  {
    :format:
    { :name:        :value:  }
    { ${defineName}    ${defineValue} }
  }
```

### MTP_MTL_PROG_PARAMETER

```
:programParam:
  {
    :format:
    { :name:     :value: }
  ## Device density based parameters
  ## example: {  xStart    0 }
    { ${paraName}   ${paraValue} }
  }
```

### MTP_MTL_APG_ACCESS

```
:apg+Access:
  {
     :name: ${accessName}
     :interface: {  ${interfaceParam} }
     :table:
     {
     :format:
     { :instruction:   :pin:    :states:     :data:    :operation:    :comment:  }
     { ${instrExpr}       ${pinId}    ${i0_or_i1}     ${data}      ${op}             ${comment}   }
     }
  }
```

### MTP_MTL_COUNTED_MATCH_PAD

```
:countedMatchPad:
  {
     :name: ${paddingName}
     :table:
     {
     :format:
     { :subroutine:       :port:   }
     { ${paddingRoutine}     ${port}  }
     }
  }
```

### MTP_MTL_CONSTANTS

```
:constants:
  {
    :format:
    {  :name:       :bits:      :value:    }
    {  ${constantName} ${numBits}     ${int_hexValue}  }
  }
```

### MTP_MTL_MAINTENANCE_OPERATION

```
:maintenanceOperation:
  {
    :name:  ${maintenanceOperationTableName}
    :table:
    {
      :format:
      { :operation:    :subroutine:       :timerMode:   :intervalMode:  }
      { ${operationName}  ${subroutineName}     ${timerMode}     ${intervalMode} }
    }
  }
```

### MTP_MTL_SCRAMBLE

```
:scramble:
  {
    :name:  ${scramblingTableName}
    :table:
    {
       :format:
       {  :bit:            :expression:      }
       {  ${scrambledBits}    ${scramblingExpr}  }
    }
  }
```

### MTP_MTL_BIT_ORDERING

```
:bitOrdering:
  {
    :name:  ${bitOrderingName}
    :table:
    {
      :format:
      {  :bit:       :expression:  }
      {  ${bitInfo}     ${bitExpressionInfo}}
    }
  }
```

### MTP_MTL_BIT_INVERSION

```
:bitInversion:
  {
    :name:  ${bitInversionName}
    :table:
    {
      :format:
      {  :bit:       :expression:  }
      {  ${bitInfo}     ${expressionInfo} }
    }
  }
```

### MTP_MTL_DBI

```
## dynamic bus inversion definitions
:dbi:
  {
    :name:       ${dbiName}
    :configuration:
    {
    :name:       ${dbiConfigureName}
    :condition:  ${dbiConfigureCondition}
    :table:
    {
      :format:
      { :bus:                :flag:   }
  ## example:  { "DQi[0..7]"     DBIni[0] }
      { ${busInfo}              ${FlagInfo} }
    }
    }
  }
```

### MTP_MTL_CRC

```
## CRC definitions
  :crc:
  {
    :name: ${crcName}

    :bitSequence:
    {
      :name:   ${crcBitSequenceName}
    :table:
    {
      :format:
      { :pinList:               :sequence:    }
  ## example: { DQi.000,DQi.008,DQi.016,DQi.024     [0..7] }
      { ${pinList}                 ${sequence} }
    }
    }

    :bitExpression:
    {
      :name:   ${crcBitExpressionName}
      :table:
      {
    :format:
    { :bit:         :expression:     }
  ## example: { 0       "e[14]^e[12]^e[8]^e[7]^e[6]^e[0]"}
    { ${bit}           ${bitExpression}     }
      }
    }

    :configuration:
    {
      :name:            ${crcConfigurationName}
      :bitSequence:     ${crcBitSequence}
      :bitExpression:   ${crcBitExpression}
    }
  }
```

### MTP_MTL_DC_SET

```
:dcSet:
  {
      :name: ${dcSetName}
      :table:
      {
          :format:
          { :dcEvent:              :pinList:      :dcSetup:              :type:     }
  ## example: { dcEventName        pinList        "namespace, ID"        dcScale    }
  ## example: { dcEventName        PinList         "LBL subroutine"      pmu        }
          { ${dcEventName}            ${PinList}        "${dcSetups}"             ${dcType} }
      }

  #Defines a sequence of DC events for use by the DC_EVENT_RANGE function
      :dcSequence:
      {
        :name: ${dcSequenceName}
        :interface:  { ${Parameters} }
        :period: "${Period}"
        :table:
        {
          :format:
          { :dcEvent:    :offset:    }
          { ${dcEvent}      "${offset}" }
        }
      }
  }
```

## Using code snippets

With the help of the content assistant in the MTP editor, you can follow either of the following methods to insert a code snippet into your configuration file:

- Press Ctrl+Space, select the supported code snippet, and press Enter to insert the snippet.
- Use a quick filter MTP_MTL: Type MTP_MTL and press Ctrl+Space. Only the snippets which names start with MTP_MTL are listed.

When the list appears, if you move the mouse pointer to a snippet, its content pops up right to the name.

See [Content assistant in the MTP editor](<02.12.04.02.05.02_Content_assistant_in_the_MTP_editor.md>) for more information about the content assistant.

## Customizing the code snippets

These code snippets are customizable. You can edit them for your operations.

 ![Code Snippet preference page](<../../../../raw/149822.png>)

When you edit the code snippets, you must follow these rules:

- The snippet name starts with MTP_MTL.
- The template indentation is two characters wide.
- The comment example starts with ## example:.
