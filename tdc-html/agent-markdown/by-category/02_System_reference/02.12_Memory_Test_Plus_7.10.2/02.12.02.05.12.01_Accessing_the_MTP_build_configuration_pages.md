# Accessing the MTP build configuration pages

There are three ways to access the [MTP build configuration pages](<02.12.02.05.12.02_The_MTP_build_configuration_pages.md>), via the toolbar, menu bar, or Project Explorer of SmarTest.

## About this task

Open the [MTP build configuration pages](<02.12.02.05.12.02_The_MTP_build_configuration_pages.md>) when you want to set up or edit configurations for building MTP .apg files.

## Before you begin

Make sure:

- MTP is installed.
- A memory device is loaded in SmarTest.

## Procedures

### Method A: from the toolbar of SmarTest

Select MTP Build Configuration as displayed in the following picture:

 ![Accessing MTP build configuration from toolbar](<../../../../raw/140956.png>)

### Method B: from the menu bar of SmarTest

Select 93000 > Memory Test > MTP Build Configuration.

### Method C: from the Project Explorer of SmarTest

- In the Project Explorer view, select an MTP device.
- In the menu bar of SmarTest, select Project > Properties.

The property window opens.

- In this window, expand Advantest V93000.
- Expand MTP Build.

## Results

You see the MTP build configuration pages which contains three pages: MTP Build, Compiler Options and Environment. For details, see [The MTP build configuration pages](<02.12.02.05.12.02_The_MTP_build_configuration_pages.md>).

 ![The MTP Build main page](<../../../../raw/140796.png>)

## What to do next

Set up or edit build configurations on these pages, see [The MTP build configuration pages](<02.12.02.05.12.02_The_MTP_build_configuration_pages.md>).
