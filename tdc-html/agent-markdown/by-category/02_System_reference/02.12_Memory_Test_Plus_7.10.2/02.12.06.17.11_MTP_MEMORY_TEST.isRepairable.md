# MTP_MEMORY_TEST.isRepairable ()

Retrieves the repairable information for the current site.

## Syntax

```
bool isRepairable () const;
```

List of parameters

There are no parameters.

## Return value

Returns:

- true: The current site is repairable.
- false: The current site is not repairable.

## Functional changes

- Introduced in MTP 3.2.1
