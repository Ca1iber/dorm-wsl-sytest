# Multiport support in Source Sync test method

The source sync test methods now support multiport source synchronously operating interfaces.

The existing test methods have been enhanced allowing a user to specify source sync groups for several ports in the parameter specifications dialog.

For more information refer to [Parameters for multistrobe test methods](<02.12.02.05.06.06.02.05_Parameters_for_multistrobe_test_methods.md>).
