# Acquire failure modes

In contrast to the 8k Error Map acquire failure mode, which relies on the called "8k Error Map memory" (which is embedded in the test processor), the large acquire failure mode (LAFM) acquires failing cycles in the much larger vector memory.

As a consequence, a single execution of a memory test is sufficient in almost all cases since much more failing cycles can be acquired within a single shot (the actual number depends on the size of the physical vector memory as well as on the available space therein, that is, the memory depth minus parallel vectors stored in the memory). Thus, LAFM further exploits the V93000 hardware capabilities, resulting in a dramatic reduction in test times predominantly for memory devices having a significant number of failing bits, or where the failing cycles are widely spaced within the vector pattern.
