# Interruptible/non-interruptible Sequences

Non-interruptible sequences ('nis') and interruptible sequences ('is') can be defined in a pattern file.

If device maintenance is specified the interruptible sequence is the default.

See Interruptible and non-interruptible sequences in [Memory Test Language (MTL) Programming Reference](<02.12.03_Memory_Test_Language__MTL__Programming_Reference.md>) for detailed information.
