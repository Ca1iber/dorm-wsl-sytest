# Per-pin pass/fail details

Clicking Detail in the [Testsuite/Site tab](<02.12.02.07.02.05_Testsuite_Site_tab.md>) opens the Detail window (see following figure). It displays the current execution, test suite, site triplet (as displayed in the windows title bar) information on a per-pin basis. The Result column contains the accumulated (logical AND) results for the patterns executed and listed in the columns further to the right.

  ![Per-pin details](<../../../../raw/85831.png>)

Click Close to close this window.
