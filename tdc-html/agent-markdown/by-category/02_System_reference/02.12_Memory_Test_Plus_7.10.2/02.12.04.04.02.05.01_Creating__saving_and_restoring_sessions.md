# Creating, saving and restoring sessions

Sessions are collections of settings that can be saved, for example, before exiting the BFM Viewer and later loaded to restore the working environment.

## About this task

You can create new sessions to start with a clean slate, save sessions that you wish to resume later as files, and load saved sessions.

The contents of a saved session are described in [Working with sessions](<02.12.04.04.02.05_Working_with_sessions.md>).

## Procedures

### Creating a new session

Creating a new session will cause all current session-related settings to be lost. Make sure to save them first if you do not want to lose them.

- In the main BFM Viewer window choose Session > New.
- Click OK in the confirmation message.

The BFM Viewer opens a new session with default settings. Continue with assigning bit fail maps, as described in [Loading bit fail maps into the BFM Viewer](<02.12.04.04.02.03_Loading_bit_fail_maps_into_the_BFM_Viewer.md>).

### Saving a session

- In the main BFM Viewer window choose Session > Save As.

A standard Save dialog is displayed.

- Choose a location for the session file and enter its name.

Make sure to give the file the .xfd filename extension.

- Click Save.
- If you later want to update the session file with changes to the session, choose Session > Save.

### Loading a saved session

This procedure overwrites all current session-related settings. Make sure to save them first if you do not want to lose them.

- In the main BFM Viewer window choose Session > Open.

A standard Open dialog is displayed.

- Choose the desired session (.xfd) file and click Open.

The current session settings are discarded and the settings from the chosen file are loaded.

- In the [Bit Fail Maps tab](<02.12.04.04.03.02.01.01_Bit_Fail_Maps.md>), click Apply to load the bit fail maps into the BFM Viewer.
