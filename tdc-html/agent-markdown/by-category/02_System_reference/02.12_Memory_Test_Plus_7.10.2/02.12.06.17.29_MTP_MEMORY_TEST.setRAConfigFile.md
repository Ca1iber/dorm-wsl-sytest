# MTP_MEMORY_TEST.setRAConfigFile()

Chooses a [Redundancy analysis configuration file](<02.12.02.07.03.01.03.01_Redundancy_analysis_configuration_file.md>) for the redundancy analysis.

This file configures the redundancy analysis algorithm.

## Syntax

```
MTP_MEMORY_TEST& MTP_MEMORY_TEST (const STRING & config_file);
```

Parameter
 |

Parameter

 |

Description

 |
 |

config_file

 |

The file path of the redundancy analysis configuration file to be used.

- You can specify either an absolute path or a relative path. The relative path uses the mts/ra/config directory in the current device directory.
- The file name must contain the .xml suffix.
 |

Return value

There is no return value.
