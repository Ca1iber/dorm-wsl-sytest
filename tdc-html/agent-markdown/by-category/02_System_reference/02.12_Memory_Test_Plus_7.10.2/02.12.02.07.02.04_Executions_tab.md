# Executions tab

An example of the Memory Test Viewer window with some device data is shown in the figure below. The Executions tab opens the view on a table which lists for each test execution the results for all test sites (see list headings). In the figure below the Executions tab is selected.

  ![Data log file ready for review](<../../../../raw/89300.png>)

The executions are listed with the execution numbers sorted in ascending order. In the upper area of the list window the current execution number is shown as selected. You may select any other row in the list. The execution number selected will also be displayed in the Current execution field right above the list.

The columns to the right of the execution number column are:

- Result: Indicates a pass or a fail for this execution
- LotNo: Identifies the lot tested

The area further to the right allows to view two types of data (of type hexadecimal):

- HardBin: Click to view the hardware bin information
- SoftBin: Click here to see the software bin information

The numbered columns identify site numbers. If there are more site numbers than can be shown in the viewing area, use the horizontal scroll bar to see more.

The data in the columns are color coded:

- Green indicates "pass"
- Red indicates "fail"
- Grey indicates "site not tested".

If there are more executions to be displayed than fit in the viewing area you may use the vertical scroll bar (not shown in the figure above) to see more.

The Testsuite/Site tab displays a table that lists the results per test site for all test suites. When you click Next (see previous figure) you proceed to the test suite per test site view.
