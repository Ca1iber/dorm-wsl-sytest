# MTP_CONTINUITY_PIN_TASK.iForce()

The iForce() member function of [MTP_CONTINUITY_PIN_TASK](<02.12.06.10.01_MTP_CONTINUITY_PIN_TASK.md>) lets you specify the current to be forced.

The iForce() member function is used only for testing non-shared and cross-terminated pins. It cannot be used for the shared pins. See the setup details in [SharedContinuity test method](<02.12.02.05.06.07.09.08_SharedContinuity_test_method.md>).

## Syntax

```
MTP_CONTINUITY_PIN_TASK& iForce(double value)
```

 |

Parameter

 |

Description

 |
 |

value

 |

The current to be forced.

The default unit is [A].

 |
