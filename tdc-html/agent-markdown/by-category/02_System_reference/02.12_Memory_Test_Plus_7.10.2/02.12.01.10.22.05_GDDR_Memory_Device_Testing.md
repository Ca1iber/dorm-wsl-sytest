# GDDR Memory Device Testing

To enhance the performance of the source synchronous test methods the rapid source sync (RSS) functions is introduced. The solution package for GDDR memory device testing including Source Synchronous for characterization and production has been expanded by new easy to use test methods.

## Benefit

The user can choose while specifying the parameters for the test method whether RSS is enabled. This requires, though, that additional pins get configured for the test which cannot be used for the device signals. The RSS puts some restriction on the use of digital channels for the purpose of buffering error information in the channel before results get uploaded.
