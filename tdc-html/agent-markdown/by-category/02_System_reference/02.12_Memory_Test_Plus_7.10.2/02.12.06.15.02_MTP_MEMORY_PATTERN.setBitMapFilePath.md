# MTP_MEMORY_PATTERN.setBitMapFilePath()

The setBitMapFilePath() member function of [MTP_MEMORY_PATTERN](<02.12.06.15_MTP_MEMORY_PATTERN.md>) lets you specify where the generated bit fail map files are saved.

This is an optional method.

## Syntax

```
MTP_MEMORY_PATTERN& setBitMapFilePath(const STRING& path)
```

 |

Parameter

 |

Description

 |
 |

path

 |

The location where the bit fail map file generated with the [generateBitmapFile()](<02.12.06.15.04_MTP_MEMORY_PATTERN.generateBitmapFile.md>) member function is to be stored.

You can specify either:

- An absolute path
- A relative path based on the device directory.

The default is <device directory>/mts/bitmap/bitmap_data/.

 |

## Example

To specify the absolute path /data/Bitmaps/ as the location for bit fail map files generated from the memory pattern named "march6N":

```
MTP_MEMORY_TEST memoryTest;
MTP_MEMORY_PATTERN &march6N = memoryTest.getMemroyPort("A").getMemoryPattern("march6N");
march6N.setBitMapFilePath("/data/Bitmaps/");
```
