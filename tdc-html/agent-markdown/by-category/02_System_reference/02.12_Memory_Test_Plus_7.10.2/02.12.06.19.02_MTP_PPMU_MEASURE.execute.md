# MTP_PPMU_MEASURE.execute()

The execute() member function of [MTP_PPMU_MEASURE](<02.12.06.19_MTP_PPMU_MEASURE.md>) executes the measurements using the per-pin PMUs for the pins defined in the [pin()](<02.12.06.19.01_MTP_PPMU_MEASURE.pin.md>) member function.

## Syntax

```
virtual void execute() [virtual]
```
