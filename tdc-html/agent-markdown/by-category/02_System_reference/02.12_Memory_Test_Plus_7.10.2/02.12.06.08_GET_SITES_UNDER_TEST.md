# GET_SITES_UNDER_TEST

The GET_SITES_UNDER_TEST() function lets you know which sites are requested to test or not in the current iteration of a for-each block. For sites that need to test in this iteration, "1" is returned. For sites do not need in this iteration, "0" is returned.

You can use GET_SITES_UNDER_TEST() in one of these three types of for-each blocks:

- [FOR_EACH_TEST_BEGIN](<02.12.06.04_FOR_EACH_TEST_BEGIN.md>) and [FOR_EACH_TEST_END](<02.12.06.06_FOR_EACH_TEST_END.md>)
- [FOR_EACH_TEST_BEGIN_WITH_RESET](<02.12.06.05_FOR_EACH_TEST_BEGIN_WITH_RESET.md>) and [FOR_EACH_TEST_END](<02.12.06.06_FOR_EACH_TEST_END.md>)
- [FOR_EACH_SHARED_SITE_BEGIN](<02.12.06.02_FOR_EACH_SHARED_SITE_BEGIN.md>) and [FOR_EACH_SHARED_SITE_END](<02.12.06.03_FOR_EACH_SHARED_SITE_END.md>)

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/SHARED_UTIL.h.

## Syntax

```
void GET_SITES_UNDER_TEST(string & sites)
```

 |

Parameter

 |

Description

 |
 |

sites

 |

Stores the returned string flags which represent sites under test.

"1" indicates the site needs to test in this for-each iteration. "0" indicates the site dose not need to test in this for-each iteration.

 |

## Example

There are four sites in total. In the first for-each iteration, only the first and second sites need to test. In the second iteration, only the third and forth sites need to test.

The results are:

The returned string for the first iteration is: "1100".

The returned string for the second iteration is: "0011".
