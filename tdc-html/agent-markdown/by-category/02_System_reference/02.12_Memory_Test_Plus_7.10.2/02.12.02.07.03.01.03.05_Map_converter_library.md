# Map converter library

#### Subtopics

- [get_ra_layout()](<02.12.02.07.03.01.03.05.01_get_ra_layout.md>)
- [phys_to_layout()](<02.12.02.07.03.01.03.05.02_phys_to_layout.md>)

When you set up the map converter library, make sure the library contains the required functions. If the functions do not exist, add them and recompile the library. For more information about recompiling the library, see [Setting up address scrambling](<02.12.02.05.03_Setting_up_address_scrambling.md>).

The required functions are:

- [get_ra_layout](<02.12.02.07.03.01.03.05.01_get_ra_layout.md>) and [phys_to_layout](<02.12.02.07.03.01.03.05.02_phys_to_layout.md>) for the RA_LAYOUT_BASED type.
- get_map_size and phys_to_map for the TOPO_ADDR_BASED type.
