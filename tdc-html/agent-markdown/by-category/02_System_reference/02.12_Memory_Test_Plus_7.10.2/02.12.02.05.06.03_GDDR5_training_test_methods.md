A GDDR5 device requires the memory controller to periodically adapt the write timing to the device's needs. During a read operation the memory controller adapts to the device's data out timing. Automatic test equipment must emulate the behavior of the memory controller by applying a series of training steps to the device.

MTP provides a set of test methods for easily performing this device training. You insert the training test methods at the beginning of the functional test into your test flow. With parameters you control the way the training results are propagated to the functional tests. The training results can either be put in the specification variables or in the pin attributes for further usage.

GDDR5 device operation is based on two types of clock signals the device receives. Both clock types are implemented as differential clocks. The CK clock signal serves as a general reference clock for the device. Address and command signals need to be center aligned at the DUT to the CK signal (rising edges of CK clock signal at center of command data eyes; rising and falling edges of CK clock signal at center of address data eyes). The WCK clock signals serve as reference for the DQ (data) signals of the GDDR5 device. There are two differential WCK clocks, each serving as a reference for one 16-bit group of the 32 DQ signals. For write operations, the DQ signals need to be center aligned at the DUT to the WCK signal they are associated to (rising and falling edges of the WCK signal is in the center of the associated DQ data eyes). For read operations, the memory controller (ATE system) needs to adapt its strobe position to the center of the DQ data eyes it receives from the DUT. The timing relationship between the clock signals (both WCKs and CK) at the DUT needs to be set up in a way that the rising edges of these clock signals are aligned at the DUT.

Advantest provides test methods that implement the training procedures:

- Address training

During address training, address signal timing is aligned to the timing of the CK reference clock. After address training, address signals are center aligned at the DUT to the rising and falling edges of the CK clock.

- ABI training

ABI training is similar to address training but aligns the timing of ABI (address bus inversion) signals instead of address signals.

- Clock training

Clock phase adjust training adjusts the phases of the WCK clock signals to the phase of the CK reference clock signal at the DUT. After clock phase adjustment, the rising edges of CK and both WCK signals are aligned at the DUT.

- Write training

During write training, the memory controller (ATE) adjusts its DQ drive timing in a way that at the DUT, the correct data is latched into the device. After write training, the rising and falling edges of the associated WCK signals are center aligned to the DQ data eyes. This alignment is achieved by independent driver timing modification of the DQ signals in the memory controller (ATE).

- Read training

Read training adjusts the DQ compare strobe positions at the memory controller (ATE) to the data eyes received from the DUT. Individual timing control for each DQ signal is required to adjust to electrical length differences of the connecting PCB/DUT board traces between memory device and memory controller (ATE). After the read training, the DQ compare strobe positions of the memory controller (ATE) are aligned to the data eye centers of the DQ signals.

- GDDR5 training, a summary method containing all of the above methods

MTP contains an additional test method to change the specification sets and a test method to load a specific configuration file.

These training processes determine a timing offset that can be used in further testing, for example, to place the timing edges in the center of the data eye. Depending on what you specify in the test method parameters, the test suite that follows the training test suite will either use the specification variables for eye centering or eye centering is achieved via the pin attributes.The latter applies to all test suites following the training test suite.
