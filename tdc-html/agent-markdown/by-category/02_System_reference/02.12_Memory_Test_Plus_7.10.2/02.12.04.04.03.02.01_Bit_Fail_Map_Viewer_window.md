# Bit Fail Map Viewer window

- [Bit Fail Maps](<02.12.04.04.03.02.01.01_Bit_Fail_Maps.md>)

The Bit Fail Map Viewer window is the tool's main window. In its tabs, most of the work with the tool takes place.

The window contains the menu bar that is described in [Bit Fail Map Viewer menus](<02.12.04.04.03.01_Bit_Fail_Map_Viewer_menus.md>). It also contains these tabs:

- Bit Fail Maps: In this tab, the available bit fail maps are displayed and can be assigned to layers of the BFM Viewer. See [Bit Fail Maps](<02.12.04.04.03.02.01.01_Bit_Fail_Maps.md>) for details.
- Chip Overview: This tab displays the loaded bit fail maps, failed and marked cells, and filters. See [Chip Overview](<02.12.04.04.03.02.01.02_Chip_Overview.md>) for details.
- Fail Combinations: This tab displays a report on how many cells contain defects on one or more overlays. It also lets you hide certain error combinations in the Chip Overview tab. See [Fail Combinations](<02.12.04.04.03.02.01.03_Fail_Combinations.md>) for details.
- Filters: This tab displays all filter rules that have been defined and lets you edit, create, and delete them. See [Filters](<02.12.04.04.03.02.01.04_Filters.md>) for details.
- Colors: This tab lets you set up the colors for the various elements in the Chip Overview tab. See [Colors](<02.12.04.04.03.02.01.05_Colors.md>) for details.
- Messages: This tab is the BFM Viewer console which displays all warnings and error notifications from the tool. See [Messages](<02.12.04.04.03.02.01.06_Messages.md>) for details.

## Functional changes
