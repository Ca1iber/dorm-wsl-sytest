# API enhancements

New APIs:

- [MTP_MEMORY_TEST.setBitMapFileName()](<02.12.06.17.15_MTP_MEMORY_TEST.setBitMapFileName.md>)
- [MTP_MEMORY_PATTERN.getFailingCycleAddresses()](<02.12.06.15.10_MTP_MEMORY_PATTERN.getFailingCycleAddresses.md>)
- SOURCESYNC APIs: Lets you create your own source-sync test method without using [the MTP provided source-sync test method](<02.12.02.05.06.06.02.05.01_SourceSync_fast_mode.md>).

  - [SOURCESYNC_TEST](<02.12.06.29_SOURCESYNC_TEST.md>)
  - [SOURCESYNC_DOMAIN](<02.12.06.26_SOURCESYNC_DOMAIN.md>)
  - [SOURCESYNC_SUB_TEST](<02.12.06.28_SOURCESYNC_SUB_TEST.md>)
  - [SOURCESYNC_TEST_DOMAIN](<02.12.06.30_SOURCESYNC_TEST_DOMAIN.md>)
  - [SOURCESYNC_HANDLER](<02.12.06.27_SOURCESYNC_HANDLER.md>)

- [MTP_RA_ALGORITHM_HOLDER](<02.12.06.20_MTP_RA_ALGORITHM_HOLDER.md>): Eases you to use the legacy RA algorithm.

Enhancements of the existing APIs:

- [MTP_MEMORY_TEST.setFailAddressListOrdering()](<02.12.06.17.18_MTP_MEMORY_TEST.setFailAddressListOrdering.md>): Adds a new option, MTP::ORDERING_CYCLE.
- [MTP_MEMORY_PATTERN.setBitMapFileName()](<02.12.06.15.01_MTP_MEMORY_PATTERN.setBitMapFileName.md>): When specifying a file name, you can include a series variables into the file name to show the information like wafer, lot, pattern and etc..
