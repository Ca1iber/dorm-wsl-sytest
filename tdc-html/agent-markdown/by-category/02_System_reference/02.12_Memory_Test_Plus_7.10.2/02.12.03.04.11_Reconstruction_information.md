# Reconstruction information

#### Subtopics

- [Setting up the generation of reconstruction information](<02.12.03.04.11.01_Setting_up_the_generation_of_reconstruction_information.md>)

Due to the per-pin architecture (as opposed to a bus-centric architecture) of the V93000 system, results are linked to tester cycles instead of memory addresses. To link results to addresses, which is frequently more useful for debugging, the SmarTest result evaluation tools require so-called reconstruction information.

The compiler can create this reconstruction information automatically when properly set up. The necessary setup is described in [Setting up the generation of reconstruction information](<02.12.03.04.11.01_Setting_up_the_generation_of_reconstruction_information.md>).

MTL creates binary reconstruction files with the file name extension .apg.rec.so.

## Functional changes

- Introduced before SmarTest 6.3.2
- MTP 3.0.1: Removed the -r0 option and support for serialized object tree output (.apg.rec files)
