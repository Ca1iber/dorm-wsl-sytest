# SHARED_CONTINUITY_TEST.pinShared()

The pinShared() member function of [SHARED_CONTINUITY_TEST](<02.12.06.21_SHARED_CONTINUITY_TEST.md>) lets you specify the shared pins or pin groups that are to be measured.

## Syntax

```
SHARED_CONTINUITY_TEST& pinShared(const string& pinlist)
```

 |

Parameter

 |

Description

 |
 |

pinlist

 |

The list of the shared pins or pin groups to be measured.

Separate entries with commas.

 |

## Example

```
SHARED_CONTINUITY_TEST mTEST;
mTEST.pinShared("Addr_Bus");
mTEST.pinShared("Addr_Bus,Command_Bus");
```
