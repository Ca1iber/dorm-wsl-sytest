# MTP_CONTINUITY_TASK.postExecute()

The postExecute() member function of [MTP_CONTINUITY_TASK](<02.12.06.10_MTP_CONTINUITY_TASK.md>) must be called at the end of a continuity test after all pins have been measured. postExecute() will restore the settings as specified in the [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>).

## Syntax

```
void postExecute()
```
