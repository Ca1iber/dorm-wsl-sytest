# SOURCESYNC_SUB_TEST.deviceSpec()

Specifies the value of the [timing spec variable](<02.12.06.28.07_SOURCESYNC_SUB_TEST.specVar.md>) in the data sheet.

This value can be considered as a limitation.

## Syntax

```
SOURCESYNC_SUB_TEST& deviceSpec (const double val);
```

Parameter
 |

Parameter

 |

Description

 |
 |

val

 |

The value of the specified [timing spec variable](<02.12.06.28.07_SOURCESYNC_SUB_TEST.specVar.md>) in the data sheet. The unit is nanoseconds (ns).

 |
