# SHARED_IDD_TEST.judgeAndLog()

The judgeAndLog() member function of [SHARED_IDD_TEST](<02.12.06.22_SHARED_IDD_TEST.md>) judges and logs the test results of a shared IDD test.

## Syntax

```
void judgeAndLog() const
```

## Example

```
SHARED_IDD_TEST mTest;
mTest.judgeAndLog();
```
