# SHARING_CONFIGURATION.utilitySubstitutePins()

The utilitySubstitutePins() member function of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) returns the names which will replace the other pins's names as defined in the specified utility control line. The utility control line is specified as its location in the utility_control block in the [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>) .

## Syntax

```
void utilitySubstituePins(int index, const string & pinsFrom, string & pinsTo) const
```

 |

Parameter

 |

Description

 |
 |

index

 |

The location of a utility control line within the utility_control block in a [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>). In this line, pins' substitutions are defined.

0 represents the first line in the utility_control block.

 |
 |

pinsFrom

 |

The pin names which will be substituted with new names. Multiple names are separated with commas.

Both the pin names and the new names have already been defined in the utility control line

 |
 |

pinsTo

 |

This variable stores the returned new names which replace the pin names in pinsFrom.

The new names have already been defined in the utility control line.

 |
