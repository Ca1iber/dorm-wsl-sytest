# SHARED_CONTINUITY_TEST.init()

The init() member function of [SHARED_CONTINUITY_TEST](<02.12.06.21_SHARED_CONTINUITY_TEST.md>) lets you do initializations for a test.

You must invoke this member function ahead of any other functions when you create a test method with the SHARED_CONTINUITY_TEST API.

## Syntax

```
SHARED_CONTINUITY_TEST& init()
```
