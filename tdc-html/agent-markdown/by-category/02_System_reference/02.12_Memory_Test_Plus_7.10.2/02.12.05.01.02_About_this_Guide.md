# About this Guide

This guide comprises all procedures required to test GDDR memory devices with the V93000 test system. References to the general V93000 documentation are added wherever general V93000 software and hardware knowledge is required.

To demonstrate the capabilities and the procedures involved to execute a GDDR3 testflow this section provides the links to the sections describing a GDDR3 demo testflow consisting of:

- [Setting up a GDDR memory device](<02.12.05.02_Setting_up_a_GDDR_memory_device.md>).
- [Executing and Analyzing a GDDR Memory Device](<02.12.05.03_Executing_and_Analyzing_a_GDDR_Memory_Device.md>). Different [Memory test patterns](<02.12.02.04.07.01_Memory_test_patterns.md>) with [functional test](<02.12.05.03.01_Executing_as_a_functional_test.md>) and several [shmoo plots](<02.12.05.05_GDDR_Memory_Device_Maintenance_Operation.md>) (see [Setting up an MTL pattern](<02.12.05.02.04_Setting_up_an_MTL_pattern_for_a_GDDR_memory_device.md>)) are provided.
- [Analyzing the results using the Bit Fail Map Viewer](<02.12.05.03.06_Analyzing_results_using_the_Bit_Fail_Map_Viewer.md>).
- [GDDR Source Synchronous](<02.12.05.04_GDDR_source-synchronous_testing.md>) for [characterization](<02.12.02.05.06.06.02.05_Parameters_for_multistrobe_test_methods.md>) and [production](<02.12.02.05.06.06.03.05_Using_DataTraining_for_production.md>).
- [GDDR Memory Device Maintenance Operation](<02.12.05.05_GDDR_Memory_Device_Maintenance_Operation.md>) example.
