# MTP_MEMORY_TEST.execute()

The execute() member function of [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) lets you execute the functional test as the conditions set in the [setup functions](<02.12.06.17_MTP_MEMORY_TEST.md>) and generate the test results.

Note that this member function dose not connect tester resources to DUTs automatically. You must ensure the tester and DUTs are already connected, for example, using the [CONNECT()](<../02.07_Test_Method_Reference/02.07.04.01.18_CONNECT.md>) API prior to using execute().

## Syntax

```
void execute()
```

## Example

Enabling address-based results and executing the test:

```
MTP_MEMORY_TEST memoryTest();
memoryTest.enableAddressBasedResults(true);
CONNECT();
memoryTest.execute();
```
