MTP-EWC is one of the SmarTest perspectives. It is the environment for MTP tests, offering all kinds of MTP features and tools. You will use it to develop MTP test programs, perform MTP tests and debug.

To open it, from the menu bar of SmarTest, select Window > Open Perspective > Other > MTP.

From there, you can:

- [Launch the MTP tools easily](<02.12.04.02.01_Launching_the_MTP_tools_from_MTP-EWC.md>).
- [Create MTL setup files instantly](<02.12.04.02.02_Creating_MTL_files_with_the_MTP_wizard.md>).
- Develop and edit setups easily. For details, see [Features for the editor of MTP-EWC](<02.12.04.02.05_Features_for_the_editor_of_MTP-EWC.md>).
- [Build the MTP files with flexible and multiple build configurations](<02.12.02.05.12_Building_MTP_files_with_MTP-EWC.md>).

Especially, you can set up a build configuration containing different compilers for different sets of .apg files.

- [Run MTP testflows with customized run configurations](<02.12.02.05.13_Running_MTP_testflows_with_MTP-EWC.md>).

## User interface

The MTP perspective contains views and editors, demonstrated in the following picture:

- The Project Explorer view: Lets you navigate projects and files.

  - The mts folder contains all [MTL setup files](<02.12.03.03.01_Overview_of_configuration_files.md>) and .apg files.
  - Folders containing the MTP .apg files are presented with ![The pattern folder icon](<../../../../raw/140852.png>).
  - MTP .apg files are presented with ![The MTP pattern file icon](<../../../../raw/140853.png>).

- Editors: Let you develop and edit test programs.

Various features have been offered in the editors to ease your programming. See [Features in the editor view of MTP-EWC](<02.12.04.02.05_Features_for_the_editor_of_MTP-EWC.md>).

- The MTP Build Console view: Displays compilation and build information for MTP files.

When an error occurs, a link to its location is provided in the console as a hyperlink. The hyperlink opens the associated at the line and column containing the error.
