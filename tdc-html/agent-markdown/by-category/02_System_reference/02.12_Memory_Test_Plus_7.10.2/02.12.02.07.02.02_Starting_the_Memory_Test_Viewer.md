# Starting the Memory Test Viewer

You can start the Memory Test Viewer either from SmarTest, or from [Memory Test Manager](<02.12.04.03.02_Memory_Test_Manager.md>), or use an execution file.

## Before you begin

SmarTest must be installed.

The DUT must have been set up and there must be a valid map converter library.

## Procedure

-  In the menu bar of SmarTest, click 93000 > Memory Test > Memory Test Viewer.

Alternatively, you can:

  - In the toolbar of SmarTest, click the Memory Test button and choose Memory Test Viewer, see the below picture: ![Memory Test button with menu](<../../../../raw/127325.png>)

Or,

  - Click the Memory Test Viewer icon in the [Memory Test Manager](<02.12.04.03.02_Memory_Test_Manager.md>). ![Memory Test Viewer button in the Memory Test Manager window](<../../../../raw/89354.png>)

Or,

  - In the file manager, double-click the shell script in the /opt/93000mts/mts/mtest_viewer/bin/MTestViewer directory.

The Memory Test Viewer window is displayed:

  ![Executions panel of the Memory Test Viewer window](<../../../../raw/86575.png>)

-  Select a data log file for a specific device using the File menu.
-  Load the data log file, select the desired result information, and prepare it for analysis with the Bit Fail Map Viewer.
