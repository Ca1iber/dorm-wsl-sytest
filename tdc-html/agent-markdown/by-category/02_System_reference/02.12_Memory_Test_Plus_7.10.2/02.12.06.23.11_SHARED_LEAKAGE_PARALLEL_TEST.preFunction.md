# SHARED_LEAKAGE_PARALLEL_TEST.preFunction()

The preFunction() member function of [SHARED_LEAKAGE_PARALLEL_TEST](<02.12.06.23_SHARED_LEAKAGE_PARALLEL_TEST.md>) controls whether a functional test is executed before measuring leakage.

## Syntax

```
SHARED_LEAKAGE_PARALLEL_TEST& preFunction(MTP::OPTION_TYPE option)
```

 |

Parameter

 |

Description

 |
 |

option

 |

MTP::OPTION_YES or MTP::OPTION_NO.

- MTP::OPTION_YES: A functional test is executed before measuring leakage.
- MTP::OPTION_NO (default): No functional test is executed before measuring leakage.
 |
