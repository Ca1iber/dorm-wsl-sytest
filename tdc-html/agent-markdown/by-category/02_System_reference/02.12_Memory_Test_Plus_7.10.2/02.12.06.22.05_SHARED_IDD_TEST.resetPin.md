# SHARED_IDD_TEST.resetPin()

The resetPin() member function of [SHARED_IDD_TEST](<02.12.06.22_SHARED_IDD_TEST.md>) lets you specify the reset pin which is used to prevent the untested site from working.

## Syntax

```
SHARED_IDD_TEST& resetPin(const string& pin)
```

 |

Parameter

 |

Description

 |
 |

pin

 |

Name of the reset pin.

 |

## Example

```
SHARED_IDD_TEST mTest;
mTest.resetPin("RESETn");
```
