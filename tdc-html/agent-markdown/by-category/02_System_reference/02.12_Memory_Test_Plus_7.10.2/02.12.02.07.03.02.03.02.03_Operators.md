# Operators

The DUT Representation Language (DRL) supports the standard C set of arithmetic operators. For example: +, -, *, /, %, +=.

Results of division operations are truncated (see [Values](<02.12.02.07.03.02.03.02.01_Values.md>) for details).

In addition to the arithmetic operators, the assignment operator = is supported. Later assignments overwrite earlier ones.

Note Non-arithmetic operators, including bitwise operators, are not supported by DRL. Neither are any arithmetic C operators supported that require special header files or libraries.

## Example

```
myVar = 16 + 3;
```
