# SHARED_LEAKAGE_PARALLEL_TEST.forceVoltage()

The forceVoltage() member function of [SHARED_LEAKAGE_PARALLEL_TEST](<02.12.06.23_SHARED_LEAKAGE_PARALLEL_TEST.md>) lets you specify the force voltage to be used during leakage measurement.

## Syntax

```
SHARED_LEAKAGE_PARALLEL_TEST& forceVoltage(double voltage)
```

 |

Parameter

 |

Description

 |
 |

voltage

 |

The force voltage to be applied on the shared pins.

- The unit is V.
- The default voltage value is 1 V.

 |

## Example

```
SHARED_LEAKAGE_PARALLEL_TEST mTest;
mTest.forceVoltage(1.3);
mTest.forceVoltage(1300 mV);
```
