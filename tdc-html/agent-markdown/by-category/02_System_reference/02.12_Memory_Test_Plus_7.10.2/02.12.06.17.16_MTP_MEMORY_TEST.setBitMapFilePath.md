# MTP_MEMORY_TEST.setBitMapFilePath()

The setBitMapFilePath() member function of [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) lets you specify where generated bit fail map files are saved.

This is an optional method.

## Syntax

```
MTP_MEMORY_TEST& setBitMapFilePath(const STRING& path)
```

 |

Parameter

 |

Description

 |
 |

path

 |

The location where the test method stores any bit fail map files it generates.

You can specify either:

- An absolute path
- A relative path based on the device directory.

The default is <device directory>/mts/bitmap/bitmap_data/.

 |

## Example

To specify the absolute path /data/Bitmaps/ as the location for generated bit fail map files:

```
MTP_MEMORY_TEST memoryTest();
memoryTest.setBitMapFilePath("/data/Bitmaps/");
```
