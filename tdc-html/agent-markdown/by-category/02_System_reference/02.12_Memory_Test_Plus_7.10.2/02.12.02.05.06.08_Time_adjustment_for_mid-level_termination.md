# Time adjustment for mid-level termination

#### Subtopics

- [Supported x-modes](<02.12.02.05.06.08.01_Supported_x-modes.md>)
- [Preparations for the test device](<02.12.02.05.06.08.02_Preparations_for_the_test_device.md>)

Some devices (for example, DDR devices) need mid-level termination during read cycles for correct operation: prior to the state where the device sends out data its driving pins need to be mid-level terminated on the receiving side.

## Functional changes

- Introduced before SmarTest 6.3.2
- MTP 3.0.1: Dynamic driver high level shift is also supported by HSM3G and HSM6800 boards
