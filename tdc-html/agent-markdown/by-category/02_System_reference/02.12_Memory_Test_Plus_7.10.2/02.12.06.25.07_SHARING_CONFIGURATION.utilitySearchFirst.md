# SHARING_CONFIGURATION.utilitySearchFirst()

The utilitySearchFirst() and [utilitySearchNext()](<02.12.06.25.08_SHARING_CONFIGURATION.utilitySearchNext.md>) member functions of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) find the locations of the specified utility control line within the utility_control block in the [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>). If it is the first line, 0 will be returned.

utilitySearchFirst() returns the first matched location; [utilitySearchNext()](<02.12.06.25.08_SHARING_CONFIGURATION.utilitySearchNext.md>) returns the next matched location.

## Syntax

```
int utilitySearchFirst(const string & name) const
```

 |

Parameter

 |

Description

 |
 |

name

 |

The name of a utility control line which you want to find in the [utility control block](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>).

 |
