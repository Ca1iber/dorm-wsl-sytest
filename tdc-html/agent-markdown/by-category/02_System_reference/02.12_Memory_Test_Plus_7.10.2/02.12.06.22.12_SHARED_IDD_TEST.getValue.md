# SHARED_IDD_TEST.getValue()

The getValue() member function of [SHARED_IDD_TEST](<02.12.06.22_SHARED_IDD_TEST.md>) retrieves the measured voltage value in [V] of a specified pin in a shared IDD test.

## Syntax

```
double getValue(const string& pin) const
```

 |

Parameter

 |

Description

 |
 |

pin

 |

The name of a pin whose measured voltage value you want to get the in [V].

 |

## Example

```
SHARED_IDD_TEST mTest;
double Value;
Value = mTest.getValue("DO_Bus");
```
