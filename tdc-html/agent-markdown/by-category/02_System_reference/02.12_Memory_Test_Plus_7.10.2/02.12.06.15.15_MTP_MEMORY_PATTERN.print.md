# MTP_MEMORY_PATTERN.print()

Prints out the memory test results of the current pattern that is specified with [getMemoryPattern()](<02.12.06.16.01_MTP_MEMORY_PORT.getMemoryPattern.md>).

## Syntax

```
void print (ostream & out = std::cout) const;
```

Parameter
 |

Parameter

 |

Description

 |
 |

out

 |

The data stream to be printed out. The default output is stdout.

 |

Return value

There is no return value.

## Related information

[MTP_MEMORY_PORT.getMemoryPattern()](<02.12.06.16.01_MTP_MEMORY_PORT.getMemoryPattern.md>)

## Functional changes

- Introduced in MTP 3.2.1
