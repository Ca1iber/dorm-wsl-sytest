# MTP_MEMORY_TEST.setRAEnablingMode()

Enables or disables the redundancy analysis.

## Syntax

```
MTP_MEMORY_TEST& setRAEnablingMode (const MTP::RA_ENABLING_MODE & mode);
```

Parameter
 |

Parameter

 |

Description

 |
 |

mode

 |

The mode to enable or disable the redundancy analysis. The default mode is MTP::RA_DISABLE.

See the available modes in the following table.

 |

Available options of parameter: <mode>
 |

Option

 |

Description

 |
 |

MTP::RA_DISABLE (default)

 |

Disables redundancy analysis.

 |
 |

MTP::RA_ENABLE_STANDALONE

 |

Enables redundancy analysis only for the current test suite.

 |
 |

MTP::RA_ENABLE_BEGIN

 |

Enables redundancy analysis and the redundancy analysis will:

- Start from the current test suite.
- Continue in the subsequent test suites that have the MTP::RA_ENABLE_CONTINUE modes (see below).
- Complete in the test suite that has the MTP::RA_ENABLE_END mode (see below).
 |
 |

MTP::RA_ENABLE_CONTINUE

 |

The current test suite will continue with the redundancy analysis from the earlier test suites with MTP::RA_ENABLE_BEGIN or MTP::RA_ENABLE_CONTINUE.

 |
 |

MTP::RA_ENABLE_END

 |

The current test suite will finish the redundancy analysis that begins in the earlier test suites.

 |

Return value

There is no return value.

## Functional changes

- Introduced in MTP 3.2.1
