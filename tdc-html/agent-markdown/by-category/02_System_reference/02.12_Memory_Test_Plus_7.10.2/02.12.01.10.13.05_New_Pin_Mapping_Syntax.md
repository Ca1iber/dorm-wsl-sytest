# New Pin Mapping Syntax

The syntax of the pin mapping file has been expanded to allow for specifying the pin configuration file, the default x-mode, and the mode context.

You can also set parameters for individual pins that override the general settings:

- Clock ratio
- Expansion size
- Pin type (digital or DC Scale)
- Pin-specific x-mode

## Benefit

Moving some of the configuration settings from other files to the pin mapping file makes for a more logical and streamlined development process.

The ability to set individual pin attributes lets you solve many practical development issues more flexibly.
