# MTL compiler directories and file name extensions

This overview describes the installation directories used by the MTL compiler and the file extensions for the various file types it uses.

## Installation directories

 |

Directory

 |

Description

 |
 |

/opt/93000mts/mts/mtl/bin

 |

Contains the binary files.

 |
 |

/opt/93000mts/mts/mtl/sh_lib

 |

Contains the shared libraries.

 |
 |

/opt/93000mts/mts/mtl/msg

 |

Contains the error message files.

 |
 |

/opt/93000mts/mts/mtl/93k_import

 |

Contains external shared libraries.

 |
