# Creating an MTL pattern

To create an MTL pattern:

- Create the [Device access file](<02.12.03.03.04_Device_access_file.md>) (.dvac) and the [Device architecture file](<02.12.03.03.05_Device_architecture_file.md>) (.dvar) according to the data sheet.
- Create the [Pin mapping file](<02.12.03.03.06_Pin_mapping_file.md>) (.pmap).
- Create the [Pin configuration file](<02.12.03.03.09.01_Pin_configuration_file.md>) (.pin) in SmarTest (only required if you plan to use automatic waveform generation or multiport operation).
- Create the [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>) (.apg).
- If you want to actively drive levels or measure signals on a DC Scale card (for example, using the DC_Scale test method), create the [DC event file](<02.12.03.03.08_DC_event_file.md>) (.dcev).
- Create the [APG program file](<02.12.03.03.03_APG_program_file.md>) (.prog) using [APG accesses](<02.12.03.03.04_Device_access_file.md>), [for loops](<02.12.03.03.03.01.02_Loops.md>), [Subroutines](<02.12.03.03.03.01.07_Subroutines.md>), [Variables](<02.12.03.03.03.01.05_Variables.md>), and [DC events](<02.12.03.03.03.01.08_Macros_and_functions_in_program_files.md>).
- Run the compiler from the terminal window (see [Starting the MTL compiler from command line](<02.12.03.02.05_Using_the_MTL_compiler_from_the_command_line.md>)) or use the graphical user interface (see [MTL compiler started from GUI](<02.12.03.02.04_Using_the_MTL_compiler_from_the_GUI.md>)).Note Editing these files is easier if you install syntax highlighting for your editor. For NEdit, the necessary information is provided in Enabling NEdit syntax highlighting.
