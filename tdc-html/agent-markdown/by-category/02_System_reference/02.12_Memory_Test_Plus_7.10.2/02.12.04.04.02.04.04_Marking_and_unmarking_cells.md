# Marking and unmarking cells

Marking cells lets you highlight them for later examination or other purposes.

## About this task

You can mark and unmark cells in the [Chip Overview tab](<02.12.04.04.03.02.01.02_Chip_Overview.md>) or a [detail view window](<02.12.04.04.03.02.01.02.01_Detail_view.md>). You can also hide marked cells temporarily instead of unmarking them.

The information which cells are marked is specific to a session. When you close a session - for example, by exiting the BFM Viewer or by switching the device - this information is lost. To preserve it, you must save the session, as described in [Creating, saving and restoring sessions](<02.12.04.04.02.05.01_Creating__saving_and_restoring_sessions.md>).

## Before you begin

The bit fail maps must have been loaded, as described in [Loading bit fail maps into the BFM Viewer](<02.12.04.04.02.03_Loading_bit_fail_maps_into_the_BFM_Viewer.md>).

## Procedures

### Marking cells

- In the Chip Overview tab or a detail view window, right-click and choose Mark/Unmark Cell from the shortcut menu.
- Click all cells that you want to mark.

Clicked cells appear in the Marked Cells list and, by default, are indicated by a dot and the cell's address and any comments in the bit fail map display. Note, however, that the dot as well as the address and comment can be switched off using, respectively, the Display > Cell Markers and Display > Marker Text options from the shortcut menu.

Note that you cannot mark a cell that is covered by the address label of another cell. To mark such covered cells, drag the address label to a different position.

- If desired, add a comment to the marked cell by double-clicking it in the Remarks row in the marked Cells list and entering the comment.

Comments appear next to the marker in the bit fail map when marker text is shown (left figure below; the right figure is a marked cell without text shown).

  ![Bit Fail Map Viewer_Chip Overview tabs_Marked cells with and without text](<../../../../raw/112658.png>)

### Unmarking cells

- In the Chip Overview tab or a detail view window, right-click and choose Mark/Unmark Cell from the shortcut menu.
- For each cell that you want to unmark, use either of these methods:

  - Click the cell's dot in the bit fail map display.
  - Select the cell in the Marked Cells list, right-click it, and choose Remove Markers from the shortcut menu.

You can also select multiple cells (by shift-clicking or control-clicking) before choosing the command.

Unmarking a cell removes it from the Marked Cells list.

### Hiding marked cells

Instead of unmarking cells you wish to remove from the bit fail maps list (which is permanent), you can also hide them temporarily.

To hide a cell, use either of these methods:

- Uncheck the cell in the S column of the Marked Cells list.
- Select the cell in the Marked Cells list, right-click it, and choose Hide Markers from the shortcut menu.

You can also select multiple cells (by shift-clicking or control-clicking) before choosing the command.

### Redisplaying hidden marked cells

To redisplay a hidden cell, use one of the methods described in Hiding marked cells, above, but check the cell in the S column or choose Display Markers, respectively.

## Results

The cells are marked and displayed as desired.
