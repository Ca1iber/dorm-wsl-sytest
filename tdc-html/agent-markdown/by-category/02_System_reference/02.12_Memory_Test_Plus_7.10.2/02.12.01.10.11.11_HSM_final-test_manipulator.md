# HSM final-test manipulator

The final-test manipulator (E6979K) is the latest type of manipulator available with the HSM test system.

It enables accurate positioning of the test head for precise docking to a front-docking handler and rotating the test head for convenient and save access of its components during test fixture exchange and maintenance.

## Benefit

The final-test manipulator was designed to fit into various test cell layouts optimizing the floor space required.
