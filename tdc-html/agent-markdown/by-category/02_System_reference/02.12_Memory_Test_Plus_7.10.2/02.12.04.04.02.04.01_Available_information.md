# Available information

To enable you to quickly analyze bit fail maps, the BFM Viewer displays information on individual cells as well as statistical information.

## Graphical information on individual cells or cell clusters

The BFM Viewer displays the loaded bit fail maps in a combined graphical display where the color of each pixel indicates a specific combination of failures in the loaded bit fail maps.

For example, one color might indicate cells that have failed in the first and third bit fail map layers, another might indicate failures in the second and third layers, and still another failures in the first layer only.

These displays are available in the [Chip Overview tab](<02.12.04.04.03.02.01.02_Chip_Overview.md>) and in additional [display views](<02.12.04.04.03.02.01.02.01_Detail_view.md>), which you can create and which are displayed in their own windows, as described in [Creating and managing detail views](<02.12.04.04.02.04.02_Creating_and_managing_detail_views.md>).

These figures show the entire bit fail maps from the chip overview and a detail view of the same maps, respectively.

 ![Bit fail maps displayed in the Chip Overview tab](<../../../../raw/112650.png>)  ![Detail view of bit fail maps](<../../../../raw/112651.png>)

Which colors indicate which fail combinations is explained in the [Fail Combinations tab](<02.12.04.04.03.02.01.03_Fail_Combinations.md>). Assigning different colors is described in [Changing the color scheme](<02.12.04.04.02.04.06_Changing_the_color_scheme.md>).

Note When one pixel on screen represents multiple cells, a failure in any of these cells is enough to display the entire pixel as containing a failure in the respective layer.

## Numerical information on individual cells or cell clusters

For failed cells, the BFM Viewer displays the logical, physical, or topological x, y, and Z coordinates as well as the data values (d) in the Failed Cells list in the [Chip Overview tab](<02.12.04.04.03.02.01.02_Chip_Overview.md>). (For topological addresses, only the x and y coordinates are displayed.) You can add remarks to each listed failed cell.

Similar information is available for marked cells. Marking cells is described in [Marking and unmarking cells](<02.12.04.04.02.04.04_Marking_and_unmarking_cells.md>).

## Statistical information

The BFM Viewer displays the numbers of failed cells for several objects and regions:

- Total failed cells in unloaded and loaded bit fail maps: in the [Bit Fail Maps tab](<02.12.04.04.03.02.01.01_Bit_Fail_Maps.md>)'s Available BFMs list.
- Total failed cells in loaded bit fail maps: in the Bit Fail Maps tab's BFM States list.
- Numbers of cells that have failures in a specific combination of layers: in the [Fail Combinations tab](<02.12.04.04.03.02.01.03_Fail_Combinations.md>).

This tab displays several different fail combination counts:

  - Number of cells with fails in the same layers: in the Unfiltered Incl. and Filtered Incl. columns.
  - Number of cells with fails and passes in the same layers: in the Unfiltered Excl. and Filtered Excl. columns.

The numbers in the two "Filtered" columns indicate how many cells have the specified fails, or fails and passes, and also match the current filter rules in the [Filters tab](<02.12.04.04.03.02.01.04_Filters.md>).

If an [analysis area](<02.12.04.04.02.04.03_Specifying_an_analysis_area.md>) is defined and the Analyze All option in the [Analysis Area window](<02.12.04.04.03.01.02.02_Analysis_Area.md>) is unchecked, the numbers in the four columns in the [Fail Combinations tab](<02.12.04.04.03.02.01.03_Fail_Combinations.md>) show only the counts of the various types of failed cells in the analysis area.

If no analysis area is defined or if Analyze All is checked, the numbers reflect the entire DUT.
