# Multiport timing conventions

Specifying the timing for multiport operation requires you to follow certain conventions.

## Conventions

In the [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>), assign timing sets to ports using the @ character and separate port definitions with commas in the :tims: declaration. For example:

```
:tims: "timingset1@port1,timingset2@port2"
```

Do not use spaces around the @ or the comma.

The ports you specify must be the same as the ports declared in the [Pin mapping file](<02.12.03.03.06_Pin_mapping_file.md>).

Note When you specify multiple timing sets with the :tims: keyword, the parameters specified for :eqns: are ignored. Instead, the equation set is extracted from the provided specification.Note You do not need to specify the port for a timing set in single-port operation.
