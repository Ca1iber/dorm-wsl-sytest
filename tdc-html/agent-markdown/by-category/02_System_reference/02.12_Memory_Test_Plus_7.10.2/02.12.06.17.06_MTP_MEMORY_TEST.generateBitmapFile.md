# MTP_MEMORY_TEST.generateBitmapFile ()

Generates fail bit map files (.bfd files) for the patterns in the current site.

## Syntax

```
void generateBitmapFile () const;
```

List of parameters

There are no parameters.

Return value

There is no return value.

## Functional changes

- Introduced in MTP 3.2.1
