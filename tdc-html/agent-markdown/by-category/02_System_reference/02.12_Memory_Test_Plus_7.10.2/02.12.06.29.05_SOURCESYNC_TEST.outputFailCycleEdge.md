# SOURCESYNC_TEST.outputFailCycleEdge()

Enables or disables the output of failure cycle edges. If not specifying with this function, no failure cycle edges will be output.

## Syntax

```
SOURCESYNC_TEST& outputFailCycleEdge (SOURCE_SYNC::JUDGE_TYPEoption);
```

Parameter
 |

Parameter

 |

Description

 |
 |

option

 |

Lets you specify whether to output failure cycle edges.

 |

Available options of parameter: <option>
 |

Option

 |

Description

 |
 |

SOURCE_SYNC::YES

 |

Outputs failure cycle edges.

 |
 |

SOURCE_SYNC::NO

 |

(Default) does not output failure cycle edges.

 |

List of parameters

There are no parameters.

## Functional changes

- Introduced in MTP 3.2.2
