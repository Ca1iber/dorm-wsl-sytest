# SHARED_VBUMP_TEST.execute()

The execute() member function of [SHARED_VBUMP_TEST](<02.12.06.24_SHARED_VBUMP_TEST.md>) lets you execute a Vbump test based on your previous setup.

## Syntax

```
void execute() const
```

## Example

```
SHARED_VBUMP_TEST mTest;
mTest.execute();
```
