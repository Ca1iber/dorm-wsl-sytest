# SmarTest structure

To execute a memory test and then analyze the result failing cells of your memory device, you need to prepare the following two kinds of data (see following figure).

- Memory Test Pattern
- Shared Library for address construction
  ![Memory test structure overview](<../../../../raw/37176.png>)

SmarTest provides setup tools in the APG (Algorithmic Pattern Generator) software, to prepare these data and set up your memory test, and also analysis tools for analyzing failing cells in address-oriented form.
