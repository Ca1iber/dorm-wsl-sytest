# SOURCESYNC_SUB_TEST.usePredefinedTimingFile()

Lets you specify whether to use a predefined timing file or not. If not specifying with this function, it will not use predefined timing files by default.

## Syntax

```
SOURCESYNC_SUB_TEST& usePredefinedTimingFile (SOURCE_SYNC::JUDGE_TYPE use);
```

Parameter
 |

Parameter

 |

Description

 |
 |

use

 |

You can select either SOURCE_SYNC::YES or SOURCE_SYNC::NO.

 |

Available options of parameter: <use>
 |

Option

 |

Description

 |
 |

SOURCE_SYNC::NO

 |

(Default) does not use a predefined timing file.

 |
 |

SOURCE_SYNC::YES

 |

Uses a predefined timing file.

 |

## Functional changes

- Introduced in MTP 3.2.2
