# Extended Operator Support in MTL

Support for arithmetic operators in the APG program file and the device access file has been expanded and made more consistent.

## Benefit

You can now use the supported operators more in line with standard C practice; the number of special cases to take into account has been significantly reduced.

For further details, see [Operators](<02.12.03.03.03.01.01_Operators.md>).
