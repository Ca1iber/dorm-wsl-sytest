# Floating-point values in the APG pattern file

Values in the APG pattern file - whether literal values or the content of variables - can now be floating-point numbers. When these values are passed to the APG program file or other files, they are converted to integer numbers.

## Benefit

Floating-point values make it easier to accurately calculate timing values.
