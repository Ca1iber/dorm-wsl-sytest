This chapter lists the release information of MTP software packages.

- MTP 3.2.1 and above: Lists the release information of each MTP <x.x.x> software package.

Starting from MTP 3.2.1, MTP-on-SOC and MTP-on-HSM become one software package, called "MTP <version number>" and released together with SmarTest.
