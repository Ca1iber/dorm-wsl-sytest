# SHARED_CONTINUITY_TEST.settlingTime()

The settlingTime() member function of [SHARED_CONTINUITY_TEST](<02.12.06.21_SHARED_CONTINUITY_TEST.md>) lets you specify the additional settling time for a test.

## Syntax

```
SHARED_CONTINUITY_TEST& settlingTime(double time)
```

 |

Parameter

 |

Description

 |
 |

time

 |

The additional settling time.

- The unit is second (S).
- The default time value is 0 S.
 |

## Example

```
SHARED_CONTINUITY_TEST mTest;
mTest.settlingTime(0);
mTest.settlingTime(1);
```
