# MTP_CONTINUITY_PIN_TASK.forceSupply()

The forceSupply() member function of [MTP_CONTINUITY_PIN_TASK](<02.12.06.10.01_MTP_CONTINUITY_PIN_TASK.md>) lets you specify the supply pins to which the force voltage will apply during the continuity test. (The supply pins must include the device supply pins and termination DPS pins.)

This member function is used only when checking the shared pins' continuity.

## Syntax

```
MTP_CONTINUITY_PIN_TASK& forceSupply(const string & pinlist)
```

 |

Parameter

 |

Description

 |
 |

pinlist

 |

Pin lists of the supply pins to which the force voltage applies during continuity test.

These supply pins include the device supply pins and termination DPS pins.

 |
