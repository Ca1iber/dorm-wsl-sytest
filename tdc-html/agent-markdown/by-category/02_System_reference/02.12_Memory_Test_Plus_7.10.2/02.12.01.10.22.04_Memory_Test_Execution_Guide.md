# Memory Test Execution Guide

The process of analyzing error data is improved by introducing a new tool, the [Memory Test Viewer](<02.12.02.07.02_Memory_Test_Viewer.md>).

## Benefit

This tool enables the user to navigate to a device specific data log file and select specific device error data. This data can be reconstructed and viewed with the Bit Fail Map Viewer.

## More Info

For details see [The Memory Test Viewer](<02.12.02.07.02_Memory_Test_Viewer.md>) in [Testing High-Speed Memory Devices](<02.12.02_Testing_High-Speed_Memory_Devices.md>).
