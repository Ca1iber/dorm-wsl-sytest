# MTP_MEMORY_PATTERN.getBitMapFileName()

The getBitMapFileName() member function of [MTP_MEMORY_PATTERN](<02.12.06.15_MTP_MEMORY_PATTERN.md>) retrieves the name that is currently set for a bit fail map file to be generated (see also [setBitMapFileName()](<02.12.06.15.01_MTP_MEMORY_PATTERN.setBitMapFileName.md>)). If setBitMapFileName() has not been called, the default name is returned.

## Syntax

```
STRING getBitMapFileName(void);
```

## Example

To store the currently set bit fail map file name in a variable:

```
MTP_MEMORY_TEST memoryTest();
MTP_MEMORY_PATTERN &march6N = memoryTest.getMemroyPort("A").getMemoryPattern("march6N");
STRING bfm_name;
bfm_name = march6N.getBitMapFileName();
```
