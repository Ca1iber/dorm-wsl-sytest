# ChangeSpecification test method

Using the ChangeSpecification test method you can change the timing sets for the later test suites in the test flow. You configure this test method using the parameters described below.

The test method copies the resulting values of the sweep specification variables that are stored in the TargetSpecVars parameter of the training test method when the training is completed to another timing set that can then be used in a later test suite. If no target spec variables have been specified, it copies the content of the variables specified in the SweepSpecVars parameter.

You can copy the training results to several timing sets at the same time. Multi-port setups are supported.

 |

Name

 |

Comment

 |
 |

CopyTargets

 |

Single-port setup: <timing_equation_no>,<timing_spec_set_no>

For example, `1,2` specifies equation 1 in timing spec set 2.

To copy the values to multiple targets, separate them with pipe characters (|).

For example, `1,2 | 2,1`.

Multi-port setup: <timing_spec_name> | <timing_spec_name> | ...

For example, 'Data_Rate_0.25'|'Data_Rate_0.5'

This parameter is optional. If it is not specified, the primaries are changed.
