# SHARING_CONFIGURATION.getDomain()

The getDomain() member function of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) returns the domain of the specified site.

## Syntax

```
vector <int> getDomain(int site) const
```

 |

Parameter

 |

Description

 |
 |

site

 |

The site number from which you want to get the domain.

 |
