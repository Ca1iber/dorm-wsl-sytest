# SOURCESYNC_SUB_TEST.sweepStart()

Specifies the start value for the sweeping spec variable specified with [SOURCESYNC_SUB_TEST.sweepSpecVar()](<02.12.06.28.11_SOURCESYNC_SUB_TEST.sweepSpecVar.md>).

Once you set up this function, the sweeping of every edge will start at the point by assigning [the sweeping spec variable](<02.12.06.28.11_SOURCESYNC_SUB_TEST.sweepSpecVar.md>) to this value. The original value of the sweeping spec variable will be overwritten.

## Syntax

```
SOURCESYNC_SUB_TEST& sweepStart (const string& sweepStart);
```

Parameter
 |

Parameter

 |

Description

 |
 |

sweepStart

 |

A number to represent the start value of the [sweeping spec variable](<02.12.06.28.11_SOURCESYNC_SUB_TEST.sweepSpecVar.md>).

- If you have specified multiple sweeping spec variables with [SOURCESYNC_SUB_TEST.sweepSpecVar()](<02.12.06.28.11_SOURCESYNC_SUB_TEST.sweepSpecVar.md>), specify multiple start values here accordingly separated with ";". For example, "1; 2; 3".
- If [UsePredefinedTimingFile is NO](<02.12.06.28.13_SOURCESYNC_SUB_TEST.usePredefinedTimingFile.md>), the unit in ns.
- If [UsePredefinedTimingFile is YES](<02.12.06.28.13_SOURCESYNC_SUB_TEST.usePredefinedTimingFile.md>), the number here is an integer.
 |
