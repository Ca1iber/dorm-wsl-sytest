# Wavetables for maintenance operations

Reusable maintenance operations using the vector mode require wavetables that contain every waveform twice, once for use in interruptible sequences, once for use in non-interruptible sequences. (This is not true for maintenance operations in sequencer mode, which works with standard wavetables.)

Interruptible waveforms have waveform indexes from 0 through 7F; non-interruptible waveforms have indexes from 80 through FF.

 Note Although these indexes are hexadecimal numbers, they must be written without the usual 0x at the beginning.

This required duplication of waveforms in vector mode halves the number of distinct waveforms available to 128. In sequencer mode, all 256 waveforms remain available.

The relationship between the standard (interruptible) and duplicated (non-interruptible) waveforms in the same table is highly constrained:

- Both waveforms must have the same edges and events.
- The non-interruptible waveform must have an index exactly 0x80 larger than the index of the standard waveform. For example, if the standard waveform has an index of (hexadecimal) 12, the non-interruptible copy must have an index of 92.
- The cycle name of the non-interruptible waveform must be the cycle name of the standard waveform with "_ni" appended.

## Automatic waveform generation

If a device maintenance routine is specified in the APG pattern file, the compiler automatically generates any non-interruptible waveforms that are missing from the wavetable. This is explained further in [Automatic waveform generation](<02.12.03.04.03.03_Automatic_waveform_generation.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
- MTP 3.0.1: Sequencer mode requires no special wavetables
