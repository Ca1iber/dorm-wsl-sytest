# SHARING_CONFIGURATION.isFXDLIgnorePin()

The isFXDLIgnorePin() member function of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) returns "true" if the specified pin is in the ignore list of the fixture delay settings and "false" if it is not.

## Syntax

```
bool isFXDLIgnorePin(const string & pinname) const
```

 |

Parameter

 |

Description

 |
 |

pinName

 |

The name of a pin for which you want to know whether it is ignored by the fixture delay settings.

 |
