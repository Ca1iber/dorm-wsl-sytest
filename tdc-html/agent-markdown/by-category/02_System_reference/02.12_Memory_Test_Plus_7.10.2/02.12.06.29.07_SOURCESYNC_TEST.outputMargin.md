# SOURCESYNC_TEST.outputMargin()

Selects what kind of margin data to be output. If not specifying with this function, no margin data will be output.

## Syntax

```
SOURCESYNC_TEST& outputMargin (SOURCE_SYNC::OUTPUT_MARGIN_TYPE option);
```

Parameter
 |

Parameter

 |

Description

 |
 |

option

 |

Controls whether to output margin data and what kind of margin data to be output.

See the options for this parameter in the next table.

 |

Available options of parameter: <option>
 |

Option

 |

Description

 |
 |

SOURCE_SYNC::DISTRIBUTION

 |

Outputs the margin distribution.

 |
 |

SOURCE_SYNC::TOTAL_MARGIN

 |

Outputs the total margin.

 |
 |

SOURCE_SYNC::NO_OUTPUT

 |

(Default) does not output margin data.

 |

## Functional changes

- Introduced in MTP 3.2.2
