# Values

Values in the device access files are always integers. Values in [the APG program](<02.12.03.03.03_APG_program_file.md>) files can be intergers, strings, and Boolean values.

If integers, by default, they are signed 64-bit integers, resulting in a value range of -9.22 * 10^18 to 9.22 * 10^18. For special requirements, larger integers up to 320 bits are available. This is discussed in [Expressions with more than 64 bits](<02.12.03.04.15_Expressions_with_more_than_64_bits.md>).

While floating-point numbers can be used for parameters in the [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>), these numbers are automatically truncated as soon as they are passed to the APG program file.

 Note Shift, Boolean, and increment operations as well as the index operator are not available for floating-point numbers.

Strings, Boolean values, and complex data types such as lists or records are not available in the device access file, except for literal strings.
