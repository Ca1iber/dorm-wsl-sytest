# Settings menu

#### Subtopics

- [Global](<02.12.04.04.03.01.02.01_Global.md>)
- [Analysis Area](<02.12.04.04.03.01.02.02_Analysis_Area.md>)

The Bit Fail Map Viewer's Settings menu lets you configure global settings for the tool.

The menu contains these commands:

- Global Settings

Choosing this command lets you set default display options, as described in [Configuring the BFM Viewer](<02.12.04.04.02.02_Configuring_the_BFM_Viewer.md>). The options themselves are explained in the description of the [Global Settings window](<02.12.04.04.03.01.02.01_Global.md>).

- Analysis Area

Choosing this command lets you specify the section of the DUT that the BFM Viewer analyzes for failed cells, as described in [Specifying an analysis area](<02.12.04.04.02.04.03_Specifying_an_analysis_area.md>). The options are explained in [Analysis Area](<02.12.04.04.03.01.02.02_Analysis_Area.md>).
