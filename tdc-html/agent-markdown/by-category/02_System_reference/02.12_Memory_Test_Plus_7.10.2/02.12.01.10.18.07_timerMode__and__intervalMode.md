# :timerMode: and :intervalMode:

These keywords in the device architecture file (*.dvar) are both optional and define how a refresh request is treated during the execution of a NIS operation.

For more information refer to Timer mode and interval mode in [Memory Test Language (MTL) Programming Reference](<02.12.03_Memory_Test_Language__MTL__Programming_Reference.md>).
