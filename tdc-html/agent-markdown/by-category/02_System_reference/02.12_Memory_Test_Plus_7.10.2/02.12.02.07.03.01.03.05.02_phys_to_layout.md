# phys_to_layout()

This function converts a specified physical address into an RA layout address. It is contained in the map converter shared library. It works together with the functions [get_ra_layout](<02.12.02.07.03.01.03.05.01_get_ra_layout.md>) for the map converter in an RA execution.

## Syntax

```
void phys_to_layout(long x_addr, long y_addr, long z_addr, long data_bit, long *dbitg, long *segm, long *row, long *col);
```

List of parameters
 |

Parameter

 |

Description

 |
 |

x_addr

 |

The x dimensional value of the specified physical address.

 |
 |

y_addr

 |

The y dimensional value of the specified physical address.

 |
 |

z_addr

 |

The z dimensional value of the specified physical address.

 |
 |

data_bit

 |

The number of the data bit.

 |
 |

dbitg

 |

The number of the data bit group. It must be 0.

 |
 |

segm

 |

The number of the specified segment which allocation is defined in the [DUT representation file](<02.12.02.07.03.02.03_DUT_representation_file.md>).

 |
 |

row

 |

The number of the row in the segment.

 |
 |

col

 |

The number of the column in the segment.

 |

## Example

```
// RA functions

// Convert the arrangement of memory cells in one segment into an RA layout.
void phys_to_layout ( long x_addr, long y_addr, long z_addr, long data_bit, long *dbitg, long *segm, long *row, long *col)
{

    // This parameter must be 0 for all the time.
    *dbitg = 0;

    // Specify which segment. The segment allocation is defined in the DUT representation file.
    *segm = z_addr * 4 + data_bit % 4;

    // Specify an address position in one segment.
    *row = x_addr;
    *col = y_addr;

}
```

For more information about the DUT representation, see [DUT representation file](<02.12.02.07.03.02.03_DUT_representation_file.md>).
