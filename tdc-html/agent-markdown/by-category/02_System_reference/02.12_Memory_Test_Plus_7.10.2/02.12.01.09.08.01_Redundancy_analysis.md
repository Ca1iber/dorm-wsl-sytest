# Redundancy analysis

Redundancy analysis evaluates memory test results to see if failed DUTs can be repaired by substituting built-in spare cells for failed cells. If there are repair possibilities, one of them is suggested.

## Benefit

You can drive the automatic repair of faulty memory sections of DUTs from within the test workflow.
