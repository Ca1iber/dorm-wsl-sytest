# MTP_IDD_TASK.pin()

The pin() member function of [MTP_IDD_TASK](<02.12.06.13_MTP_IDD_TASK.md>) lets you specify the shared or non-shared VDD or VDDQ pins you want to check for IDD test. pin() returns the [MTP_IDD_PIN_TASK](<02.12.06.13.01_MTP_IDD_PIN_TASK.md>) class object which you use to set up the measurement conditions for these pins.

## Syntax

```
[MTP_IDD_PIN_TASK](<02.12.06.13.01_MTP_IDD_PIN_TASK.md>) pin(const string & pinlist)
```

 |

Parameter

 |

Description

 |
 |

pinlist

 |

The list of the VDD or VDDQ pins to be measured in the IDD test. Multiple pins or pin groups are separated with commas.

 |
