# Comments

The DUT Representation Language supports both end-of-line and multi-line comments.

## Syntax

End-of-line comments begin with double slashes. Everything after the slashes until the next line feed is ignored by the compiler. For example:

```
myVar = 12;  // This is a comment.
```

Multi-line comments begin with /* and end with */. They can contain any number of line feeds. For example:

```
/* This is a comment introducing the next
statement. It extends across multiple lines
because it is so long.
The next statement is an assignment: */
myVar = 12;
```

## Functional changes

- Introduced in MTP 2.6.5
