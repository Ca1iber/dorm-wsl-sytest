# Overview of configuration files

The MTL compiler processes several optional and mandatory configuration files in addition to the source code file itself.

This section provides a brief overview of all mandatory and optional files.

This is a graphical display of the files and their relationships:

  ![MTL configuration file dependencies](<../../../../raw/102052.png>)

## File descriptions

The files and their relationships are described in detail in [MTL Configuration Files](<02.12.03.03_MTL_Configuration_Files.md>); here is a brief overview:

- [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>) (.apg)

The control file referencing all other files to be used. It also may contain general parameter definitions.

- [APG program file](<02.12.03.03.03_APG_program_file.md>) (.prog)

The actual program that is compiled into the test pattern.

- [Device access file](<02.12.03.03.04_Device_access_file.md>) (.dvac)

Specifications of all device accesses, that is, signals on pins and signal combinations on groups of pins that can be called by name in the [program file](<02.12.03.03.03_APG_program_file.md>). Optionally, the file also specifies MUX modes for HX pins.

- [Device architecture file](<02.12.03.03.05_Device_architecture_file.md>) (.dvar)

A description of the memory device's low-level characteristics, such as scrambling and maintenance operations.

- [Pin mapping file](<02.12.03.03.06_Pin_mapping_file.md>) (.pmap)

A mapping of pin names used in the device access file to pin names used in SmarTest. All pins for which per-pin subroutines are to be created must be listed in this file. The file also specifies the default x-mode as well as, optionally, the mode context for automatic waveform generation and per-pin [x-modes](<02.12.03.04.02_Transparent_x-modes.md>), expansion sizes, and cycle ratios.

- [Waveform mapping file](<02.12.03.03.07_Waveform_mapping_file.md>) (.wmap)

Optional; required for [Indirect waveform mapping](<02.12.03.04.03.02_Setting_up_indirect_waveform_mapping.md>). Maps sequences of state characters (device accesses) to indexes into a wavetable in the timing file.

- [DC event file](<02.12.03.03.08_DC_event_file.md>) (.dcev)

Optional; required for actively driving levels and measurements on DC Scale pins. Specifies parameters for the DC_Scale testmethod.

- [Pin configuration file](<02.12.03.03.09.01_Pin_configuration_file.md>) (.pin)

Optional; required for [Automatic waveform generation](<02.12.03.04.03.03_Automatic_waveform_generation.md>) and [Multiport operation](<02.12.03.04.14_Multiport_operation.md>). This file is generated in SmarTest.

- [Timing file](<02.12.03.03.09.02_Timing_file.md>) (.tim)

Definitions of the actual waveforms driving the pins. This file is generated in SmarTest.

For details on the files, see the respective sections referenced above.
