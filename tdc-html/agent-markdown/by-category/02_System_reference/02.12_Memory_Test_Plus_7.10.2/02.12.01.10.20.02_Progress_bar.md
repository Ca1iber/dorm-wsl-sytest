# Progress bar

A progress bar shows the ongoing activity of the

- Execution engine (online reconstruction during execution of a testflow)
- Result server (offline reconstruction, triggered via Memory Test Viewer in SmarTest).

See [Memory Test Manager](<02.12.04.03.02_Memory_Test_Manager.md>) in [Memory Test Plus Tools Reference](<02.12.04_Memory_Test_Plus_Tools_Reference.md>) for detailed information.
