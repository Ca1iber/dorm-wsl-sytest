# Parameters of the Successive algorithm

The Successive algorithm is included with MTP for use with redundancy analysis.

The algorithm's execution is controlled through a range of parameters, as described below. For more information about the other related parameters, see [Redundancy analysis configuration file](<02.12.02.07.03.01.03.01_Redundancy_analysis_configuration_file.md>).

Parameters are separated by commas or colons and are identified by their positions.That is, there are no keywords, just a sequence of values.

## Syntax

 |

Pos.

 |

Parameter

 |

Values and Description

 |
 |

1

 |

Fail bit detail selector

 |

`0`: No detailed fail bit information is included in the output. This is the default value.

`1`: Detailed fail bit information, such as row and column, is included in the output.

 |
 |

2

 |

Solution output selector

 |

`0`: Do not generate a solution output file.

`1`: Generate a solution output file in the first format. This is the default value.

`2`: Generate a solution output file in the second format.

The two solution file formats are described in the "Solution file" section of [Output of the Successive algorithm](<02.12.02.07.03.02.04_Output_of_the_redundancy_analysis_algorithm.md>).

 |
 |

3

 |

(Reserved)

 |

This parameter is reserved for future use.

 |
 |

4

 |

Report level

 |

A number from 0 through 7. The higher the number, the more detail is included in the reports.

The default is 0.

 |
 |

5

 |

Log level

 |

A number from 0 through 7. The higher the number, the more detail is included in the logs.

The default is 0.

 |
