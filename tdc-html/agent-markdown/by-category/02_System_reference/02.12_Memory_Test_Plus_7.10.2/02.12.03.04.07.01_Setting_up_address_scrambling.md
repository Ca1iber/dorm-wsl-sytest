# Setting up address scrambling

Address scrambling requires setting up a scrambling table in the device architecture file, referencing it in the APG pattern file, and adding address scrambling information to the device access file.

## About this task

This task describes setting up address scrambling from scratch.

## Before you begin

Make sure that the correct [device access](<02.12.03.03.04_Device_access_file.md>) and [device architecture files](<02.12.03.03.05_Device_architecture_file.md>) are specified in the [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>).

## Procedure

-  Add an address scrambling table to the [Device architecture file](<02.12.03.03.05_Device_architecture_file.md>) using the :scramble: keyword.

The syntax of the :scramble: keyword is described in [Device architecture file syntax](<02.12.03.03.05.01_Device_architecture_file_syntax.md>).

Enter a line for each scrambled (physical) address bit, specifying how to calculate it from the unscrambled (logical) address bits. For example:

```
{  :bit:    :expression:  }
{  xa1      "x0 or x2"    }
```

To indicate the bits of the logical addresses, use xn, yn, and zn (where n is the number of the bit); to indicate the bits of the physical address, use xan, yan, and zan.

You can use the AND, OR, NOT, and XOR operators in the scrambling expressions.

If desired, you can add multiple scrambling tables to the device architecture file.

-  Specify the desired scrambling table in the [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>) using the :scramble: keyword.

The syntax of the :scramble: keyword is described in [APG pattern file syntax](<02.12.03.03.02.01_APG_pattern_file_syntax.md>).

-  In the [Device access file](<02.12.03.03.04_Device_access_file.md>), modify the device accesses that you want to use with address scrambling: Make sure that they use the xaddr, yaddr, and zaddr address scrambling macros in the :data: column.

These macros calculate the scrambled x-, y-, and z-addresses using the scrambling table that you created in step 1 and specified in step 2.

 Note If these macros are not used in the :data: column, no address scrambling is performed.

## Results

All device accesses to address pins (as specified in the device access file) are transparently scrambled using the scrambling macros, ensuring that logical addresses are correctly transformed into physical addresses.

Disabling address scrambling

If you wish to temporarily disable address scrambling, replace the argument of the :scramble: keyword in the APG pattern file with a tilde (~).
