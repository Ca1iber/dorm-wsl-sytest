# SHARED_CONTINUITY_TEST().print()

The print() member function of [SHARED_CONTINUITY_TEST](<02.12.06.21_SHARED_CONTINUITY_TEST.md>) prints the test results of a shared continuity test to a standard output (It is the UI report window in SmarTest), or others.

## Syntax

```
void print(const ostream& out=std::cout) const
```

 |

Parameter

 |

Description

 |
 |

out

 |

Specify where to print the test results.

- The type for the output place is osteram&.
- The default output place is std::out, which is the UI report window in SmarTest.

 |

## Example

```
SHARED_CONTINUITY_TEST mTest;
mTest.print(); //Print the test results to the default stdout (UI report window).
```
