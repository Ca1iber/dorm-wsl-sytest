# Result Pins

The user can specify the pins for which the errors should be uploaded and reconstructed.

## Benefit

This makes it possible to focus the result view on just the pins of interest. Furthermore the upload and reconstruction time gets reduced.

## More Info

For further details see [Parameters for the ExecutionEngine test method](<02.12.02.05.06.01.03.01_Parameters_for_the_ExecutionEngine_test_method.md>) in [Testing High-Speed Memory Devices](<02.12.02_Testing_High-Speed_Memory_Devices.md>).
