# Creating and editing filter rule conditions

Each filter rule in the BFM Viewer consists of a number of conditions. Changing the effect of a rule involves adding, deleting, or editing these conditions.

## About this task

Any changes to filter rule conditions are automatically saved but become active only after you click the Apply button.

When a filter rule is evaluated for a given cell, all its conditions are evaluated and the rule applies if - and only if - all its conditions evaluate to true for this cell. (Conditions are combined by logical and.) The order of the conditions are unimportant.

## Before you begin

You must have created the rule whose conditions you want to edit, as described in [Creating and editing filter rules](<02.12.04.04.02.04.05.01_Creating_and_editing_filter_rules.md>).

## Procedures

### Creating a new condition

- In the Filters tab's Filter Rules list, click the filter rule to which you want to add a condition.

The rule's conditions are displayed at the right in the Selected Filter Rule Condition list.

- Right-click an existing condition and choose either of these commands from the shortcut menu:

  - Insert Condition to create a new condition above the condition on which you clicked.
  - Append Condition to create a condition below the condition on which you clicked.

If you right-click in the empty area below the existing conditions, only the Append Condition command is available; choosing it creates a new condition at the end of the list.

The newly created condition is selected. It contains default settings.

- Set the desired parameters for the condition:

  - To set the mask, double-click the condition in the Mask column and enter the desired mask.

The mask is applied to the specified coordinate (see below) of the evaluated cell by logical and before the condition is evaluated to true or false. It lets you evaluate only part of the coordinate. (For example, a mask of 1 lets you distinguish between even and odd cells.)

The mask display can be switched between hexadecimal and decimal via the shortcut menu.

  - To choose the coordinate which the conditions is to evaluate, double-click the condition in the Coordinate column and choose the desired cell coordinate from the shortcut menu.

The condition compares the chosen coordinate with the value (see below).

  - To choose a comparison operator, double-click the condition in the Operator column and choose the desired operator from the shortcut menu.
  - To enter a comparison value, double-click the condition in the Value column and enter the desired value.

The condition is evaluated by comparing the chosen cell coordinate (see above) with this value.

The value display can be switched between hexadecimal and decimal via the context menu.

  - If desired, enter a comment by double-clicking the condition in the Remarks column and entering text. The remark has no effect on the evaluation of the condition.

To evaluate a condition for a cell, the BFM Viewer checks whether the following statement is true for the cell: (<chosen coordinate> & <mask>) <operator> <value>.

For example, with a mask of FF, the coordinate phys y the operator >, and the value 4, the BFM Viewer would check for each cell whether its physical y address, masked by FF, is greater than 4.

- Click Apply to activate the new condition.

### Editing an existing condition

- In the Filters tab's Filter Rules list, click the filter rule whose conditions you want to edit.

The rule's conditions are displayed at the right in the Selected Filter Rule Condition list.

- Click the condition that you want to edit.
- Set the parameters for the condition as desired.

See step 3 of Creating a new condition, above, for details.

- Click Apply to activate the change to the filter rule.

### Deleting a condition

- In the Filters tab's Filter Rules list, click the filter rule from which you want to delete a condition.

The rule's conditions are displayed at the right in the Selected Filter Rule Condition list.

- Right-click the condition that you want to delete and choose Remove Condition from the shortcut menu.
- Click Apply to activate the changes to the condition.

## Results

The filter rule is set up as desired.
