# SHARED_LEAKAGE_PARALLEL_TEST.prechargeVoltage()

The prechargeVoltage() member function of [SHARED_LEAKAGE_PARALLEL_TEST](<02.12.06.23_SHARED_LEAKAGE_PARALLEL_TEST.md>) sets the precharge voltage to the non-shared and cross-terminated pins.

 Note The shared pins are independent of this member function. Shared pins are automatically precharged to the force voltage via PPMU by the [SharedLeakageParallel test method](<02.12.02.05.06.07.09.11_SharedLeakageParallel_test_method.md>).

## Syntax

```
SHARED_LEAKAGE_PARALLEL_TEST& prechargeVoltage(double value)
```

 |

Parameter

 |

Description

 |
 |

value

 |

The voltage to be precharged to non-shared pins or cross-terminated pins.

The unit is volt.

The default is 0 V.

 |

Note that this member function is:

- Used only for the non-shared and cross-terminated pins.
- Effective only when precharging has been enabled by the [precharge()](<02.12.06.23.09_SHARED_LEAKAGE_PARALLEL_TEST.precharge.md>) member function.
