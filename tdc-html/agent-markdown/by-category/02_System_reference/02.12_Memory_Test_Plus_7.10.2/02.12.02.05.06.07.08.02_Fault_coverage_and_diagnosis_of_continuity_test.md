# Fault coverage and diagnosis of continuity test

A specialized DC-based (pin PMU) test method is available to address all needs for driver sharing continuity testing.

The specialized method for continuity testing addresses all hurdles of the sharing individually, except for physical limitations inherent to sharing. Additionally, the test method is able to treat all non-shared pins in parallel, which reduces test time. The test coverage for the different fault models is summarized in the table below.
