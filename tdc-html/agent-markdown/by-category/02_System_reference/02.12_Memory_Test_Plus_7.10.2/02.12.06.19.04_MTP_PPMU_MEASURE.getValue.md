# MTP_PPMU_MEASURE.getValue()

The getValue() member function of [MTP_PPMU_MEASURE](<02.12.06.19_MTP_PPMU_MEASURE.md>) lets you get the measured voltage in volt for a specific pin.

## Syntax

```
double getValue(const string & pin)const
```

 |

Parameter

 |

Description

 |
 |

pin

 |

The name of a pin whose measured voltage you want to retrieve.

The unit for the retrieve voltage is volt ([V]).

 |
