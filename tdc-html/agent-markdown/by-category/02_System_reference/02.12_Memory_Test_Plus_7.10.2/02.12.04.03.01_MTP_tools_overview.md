# MTP tools overview

MTP comes with the following tools:

MTP Tools
 |

Tool name

 |

Description

 |
 |

[Bit Fail Map Viewer](<02.12.04.04_Bit_Fail_Map_Viewer.md>)

 |

The Bit Fail Map Viewer (BFM Viewer) is a tool displays the errors occurring during the test of a memory device as configurable graphics.

The Bit Fail Map Viewer is located in /opt/93000mts/mts/bfm.

 |
 |

[Memory Test Viewer](<02.12.02.07.02_Memory_Test_Viewer.md>)

 |

The memory test viewer provides the functionality to select and convert cycle-based failure data of memory tests to an address-based representation that can be used to display failure maps or to create failure lists.

The Memory Test Viewer is located in /opt/93000mts/mts/mtest_viewer.

 |
 |

[Memory Test Manager](<02.12.04.03.02_Memory_Test_Manager.md>)

 |

A graphical user interface started from command line as one access point for the above mentioned MTP tools.

The Memory Test Manager is located in /opt/93000mts/mts/mtest_manager.

 |
 |

Solution Tools

 |

The following memory test solution tools are available:

- [Eye Finder](<02.12.02.05.06.04_EyeFinder.md>)

A tool for performing skew calibration on a DUT; that is, it makes adjustments to the timing of drive and receive edges in order to correct for tiny differences of transmission time through the DUT pins. The skew calibration is DUT-specific: it must be performed each time another device is loaded for testing. The Eye Finder is designed specifically to meet the needs of XDR memory testing.

- [Parallel Shmoo](<02.12.02.05.06.05_Parallel_Shmoo_test_method.md>)

An enhancement of the current shmoo tool, which makes it possible to run shmoo plots simultaneously on multiple sites.

- [Source Synchronous Test Method](<02.12.05.04.06_Test_solutions_for_devices_with_source-sync_interface.md>)

The source synchronous test solution can be used for characterization.

- [Driver Sharing Test Methods](<02.12.02.05.06.07.09_Test_methods_for_driver_sharing.md>)

The driver sharing test methods are used to create a testflow for the driver sharing applications.

- [GDDR5 training test methods](<02.12.02.05.06.03_GDDR5_training_test_methods.md>)

A test method used for testing GDDR5 device.

The solution tools are located in /opt/93000mts/mts/solution_tools.

 |
 |

[ExecutionEngine](<02.12.02.05.06_Test_methods.md>)

 |

A test method to create address-based results from a memory test execution.

The test method is located in /opt/93000mts/mts/execution_engine.

 |
 |

[MTS Version Switch Utility](<02.12.04.01_Switching_to_a_different_MTP_version_on_SmarTest.md>)

 |

The MTS Version Switch Utility is a tool that allows you to select one of multiple installed versions of MTP to work with.

It is found at /opt/93000mts/mts/utilities/bin.

 |
 |

[Automatic Map Converter](<02.12.04.05_Automatic_Map_Converter.md>)

 |

A tool to automatically create map converter libraries to convert between physical and geometrical addresses for the Bit Fail Map Viewer.

It is found at /opt/93000mts/mts/utilities/macConvWizard.

 |
 |

[DPS Sharing Diagnostic](<02.12.04.07_DPS_Sharing_Diagnostic.md>)

 |

A tool to test and diagnose the electronics of a DPS-sharing load board.

 |
 |

[Building MTP files](<02.12.02.05.12_Building_MTP_files_with_MTP-EWC.md>)

 |

You can set up build configurations and build MTP .apg files directly with the SmarTest Work Center.

 |
 |

[Running MTP Testflow](<02.12.02.05.13_Running_MTP_testflows_with_MTP-EWC.md>)

 |

The run MTP testflow setup page is added into SmarTest Work Center.

 |
 |

[Converting legacy memory test pattern](<../../03_Use_cases_and_application_papers/03.12_SmarTest_Program_Migration_Framework/03.12.08_Converting_legacy_converting_memory_test_pattern.md>)

 |

A script tool to convert legacy memory patterns with MTST labels to patterns with PPSS labels.

   |  Note Before you use a MTP tool, make sure you have done the following checks:

- Your account have been authorized to execute /etc/profile.d/ mtp_execution_engine.sh.
- $V93000_TM_LIBRARY_PATH has contained the path /opt/93000mts/mts/execution_engine/UTM/sh_lib/.

## Functional changes

- Introduced before SmarTest 6.3.2
- MTP 3.0.1: The Memtest test methods have been consolidated into the ExecutionEngine test method
- MTP 3.0.1: The MTDC tool has been added
- MTP 3.0.1: The PDebug tool has been added
- MTP 3.1.3: The Automatic Map Converter has been added
- MTP 3.2.0: The MTDC tool has been removed
- MTP 3.2.1: SmarTest Work Center provides dedicated functions for building MTP .apg files and running MTP testflows.
- MTP 3.2.1: The legacy memory pattern converter has been added.
- MTP 3.2.2: Removes Result Server.
- MTP 7.5.0: Memory Pattern Validation Tool (MPVT) has been removed.
