# MTP_CONTINUITY_PIN_TASK.limits()

The limits() member function of [MTP_CONTINUITY_PIN_TASK](<02.12.06.10.01_MTP_CONTINUITY_PIN_TASK.md>) lets you set the low and high limit values.

## Syntax

```
MTP_CONTINUITY_PIN_TASK& limits(const LIMIT & limit)
```

 |

Parameter

 |

Description

 |
 |

limit

 |

A [LIMIT](<../02.07_Test_Method_Reference/02.07.04.01.126_LIMIT.md>) class object that contains the limits you want to use.

 |
