# MTP_LEAKAGE_PIN_TASK.vForce()

The vForce() member function of [MTP_LEAKAGE_PIN_TASK](<02.12.06.14.01_MTP_LEAKAGE_PIN_TASK.md>) lets you specify the voltage to be forced.

## Syntax

```
MTP_LEAKAGE_PIN_TASK& vForce(double value)
```

 |

Parameter

 |

Description

 |
 |

value

 |

The voltage to be forced.

The default unit is [V].

 |
