Creates your own handler operation. You must inherit all its member functions to create your own handler class for use. For the detailed usage, see the example code in [SOURCESYNC_TEST.handle()](<02.12.06.29.03_SOURCESYNC_TEST.handle.md>).

To execute the defined handler operation, use [SOURCESYNC_TEST.handle()](<02.12.06.29.03_SOURCESYNC_TEST.handle.md>).

Note You cannot create any instances with this class.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/SOURCESYNC_HANDLER.h.

## Syntax

```
virtual SOURCESYNC_HANDLER::~SOURCESYNC_HANDLER ( );
```

This is a deconstructor. When using SOURCESYNC_HANDLER to create your own class, a deconstructor is mandatory for your class.
