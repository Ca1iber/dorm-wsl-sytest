# Configuring a test suite

To select a source synchronous test method for a test suite follow the procedure below.

## Procedure

-  Insert a run or run and branch test suite into the testflow.

The Test Suite Dialog window opens.

-  Click the Test Method button at the top of the window.
-  To define the test suite's name, type the name for your test suite into the Test suite name entry field, for example Multistrobe_GDDR3.
-  Select the basic timing and level equations and the vector label, for example march6n.
-  Edit the timing file and the wavetables as described in topic [Setting up the timing file](<02.12.02.05.06.06.02.01_Setting_up_the_timing_file.md>).
-  Click the Test method entry field at the bottom of the test suite window.
-  Click Select in the right pane.

The Select Class/Method window opens.

  ![Select_fast_mode](<../../../../raw/92892.png>)
-  In the Class list box, select DEV ss_lib.
-  Choose a method from the Method list, for example FastMode.
-  To close the window, click Select at the bottom of the Select Class/Method window.

## What to do next

Configure the parameters for the test method.
