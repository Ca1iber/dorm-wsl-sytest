Accesses the memory test results of a port that is specified with [getMemoryPort()](<02.12.06.17.08_MTP_MEMORY_TEST.getMemoryPort.md>) and tested with the [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) class.

This API is defined in the header file /opt/93000mts/mts/execution_engine/include/MtpMemoryPort.h.

Note This API is available only for MTP.

## Syntax

There is no constructor.

Instances of this class are created with the [getMemoryPort()](<02.12.06.17.08_MTP_MEMORY_TEST.getMemoryPort.md>) function of the [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) class.

List of parameters

There are no parameters.

Return value

There is no return value.
