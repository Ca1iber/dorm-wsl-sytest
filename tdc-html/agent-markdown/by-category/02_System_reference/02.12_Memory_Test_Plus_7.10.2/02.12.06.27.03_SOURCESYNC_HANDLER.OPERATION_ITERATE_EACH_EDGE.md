# SOURCESYNC_HANDLER.OPERATION_ITERATE_EACH_EDGE()

Defines the contents to be output on an error map for each edge.

 Note You must inherit this function when defining your own [SOURCESYNC_HANDLER](<02.12.06.27_SOURCESYNC_HANDLER.md>) class. If you do not have operations for this function, program it as an empty function. See the example in [SOURCESYNC_TEST.handle()](<02.12.06.29.03_SOURCESYNC_TEST.handle.md>).

## Syntax

```
virtual void OPERATION_ITERATE_EACH_EDGE (const EMAPEdgeVars& emap)=0;
```

Parameter
 |

Parameter

 |

Description

 |
 |

emap

 |

References to an EMAPEdgeVars structure:

- long int cycleNO: The cycle number that the current edge belongs to.
- int edgeNO: The current edge number.
- unsigned int shotNum: (Mandatory) The number of shots (steps) for each edge on an error map.
- SOURCE_SYNC::EMAP_STATE accumulatedState: The pass/fail result after accumulating the results at all shots of the current edge. The possible results are:

SS_HANDLER::EMAP_PASS: The final result is pass.

SS_HANDLER::EMAP_FAIL: The final result is fail.

- SOURCE_SYNC::EMAP_STATE *shotsState: An array saving the result at every shot of the current edge. The possible results for each short are:

SS_HANDLER::EMAP_PASS: The result is pass.

SS_HANDLER::EMAP_FAIL: The result is fail.

SS_HANDLER::EMAP_INVALID: The result is invalid.

- SOURCE_SYNC::MARGIN_STATE marginState: The margin status of the current edge. The possible statuses are:

SS_HANDLER::REASONABLE: The margin result is reasonable.

SS_HANDLER::UNREASONABLE: The margin result is unreasonable.

SS_HANDLER::MARGIN_INVALID: The margin result is invalid.

- int marginValue: The margin value of the current edge.
 |

Return value

There is no return value.
