# MTP_MEMORY_TEST.setRAGenerateOverlaidBfd()

Controls whether to generate an overlay fail bit map file (.bfd), which will be used for redundancy analysis.

If you want to generate each individual fail bit map file (.bfd) during a redundancy analysis, use [setImmediateBitmapToFile()](<02.12.06.17.21_MTP_MEMORY_TEST.setImmediateBitmapToFile.md>).

## Syntax

```
MTP_MEMORY_TEST& setRAGenerateOverlaidBfd (const bool & status);
```

Parameter
 |

Parameter

 |

Description

 |
 |

status

 |

The status can be:

- true: Generates an overlay fail bit map file (.bfd) for redundancy analysis.

You must set to true if a redundancy analysis contains multiple testflows (the first testflow has been set to MTP::RA_ENABLE_BEGIN with the [setRAEnablingMode()](<02.12.06.17.31_MTP_MEMORY_TEST.setRAEnablingMode.md>) function).

- false: Does not generate an overlay fail bit map file (.bfd).
 |

Return value

There is no return value.
