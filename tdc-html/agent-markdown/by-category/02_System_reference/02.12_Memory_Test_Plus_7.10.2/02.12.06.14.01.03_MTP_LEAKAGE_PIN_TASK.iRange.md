# MTP_LEAKAGE_PIN_TASK.iRange()

The iRange() member function of [MTP_LEAKAGE_PIN_TASK](<02.12.06.14.01_MTP_LEAKAGE_PIN_TASK.md>) lets you set the measurement range for the current.

Setting the range for the current is optional. If you Do not set a range, the upper current limit set by [limits()](<02.12.06.14.01.02_MTP_LEAKAGE_PIN_TASK.limits.md>) will be used as the range for the current.

## Syntax

```
MTP_LEAKAGE_PIN_TASK& iRange(double value)
```

 |

Parameter

 |

Description

 |
 |

value

 |

The value in [A] used as the measurement range for current.

 |
