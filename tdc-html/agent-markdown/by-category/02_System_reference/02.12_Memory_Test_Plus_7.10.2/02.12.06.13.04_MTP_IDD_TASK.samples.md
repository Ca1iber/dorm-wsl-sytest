# MTP_IDD_TASK.samples()

The samples() member function of [MTP_IDD_TASK](<02.12.06.13_MTP_IDD_TASK.md>) lets you specify the number of measurements to average.

## Syntax

```
void samples(int samples)
```

 |

Parameter

 |

Description

 |
 |

samples

 |

The number of measurements to average.

The default value is 8.

 |

## Related information

[MTP_IDD_TASK](<02.12.06.13_MTP_IDD_TASK.md>)

## Functional changes

- Introduced in MTP 3.1.5
