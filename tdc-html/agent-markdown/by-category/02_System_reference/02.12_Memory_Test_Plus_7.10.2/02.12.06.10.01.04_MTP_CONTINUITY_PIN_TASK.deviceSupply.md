# MTP_CONTINUITY_PIN_TASK.deviceSupply()

The deviceSupply() member function of [MTP_CONTINUITY_PIN_TASK](<02.12.06.10.01_MTP_CONTINUITY_PIN_TASK.md>) lets you specify the pins of the device supply.

This member function is used only when checking the shared pins' continuity.

## Syntax

```
MTP_CONTINUITY_PIN_TASK& deviceSupply(const string & pinlist)
```

 |

Parameter

 |

Description

 |
 |

pinlist

 |

Pin list specifying the device supply pins.

 |
