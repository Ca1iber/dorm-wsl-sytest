# The V93000 HSM Series hardware

#### Subtopics

- [Large test head (LTH) system](<02.12.02.03.04.01.01_Large_test_head__LTH__system.md>)
- [Compact test head system](<02.12.02.03.04.01.02_Compact_test_head_system.md>)

The HSM test system is available in several versions aimed at different customer requirements:

- The [Large test head system](<02.12.02.03.04.01.01_Large_test_head__LTH__system.md>) (LTH) featuring:

  - The linear manipulator (E6979H) for low-volume manufacturing or design verification.
  - The final-test manipulator (E6979K) for high-volume manufacturing with optimized test cells.
  - The Evo manipulator (E6979F), described in LTH/STH Manipulator Installation Guide, for high-volume manufacturing (HVM).

- [Compact test head system](<02.12.02.03.04.01.02_Compact_test_head_system.md>) (CTH) featuring the low cost manipulator (E6979LC) for low-volume manufacturing and design verification (DV).

## Functional changes

- Introduced before SmarTest 6.3.2
