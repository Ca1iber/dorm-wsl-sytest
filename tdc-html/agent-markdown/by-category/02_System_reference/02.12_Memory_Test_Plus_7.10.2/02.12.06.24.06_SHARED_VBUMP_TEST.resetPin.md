# SHARED_VBUMP_TEST.resetPin()

The resetPin() member function of [SHARED_VBUMP_TEST](<02.12.06.24_SHARED_VBUMP_TEST.md>) lets you specify the reset pin which is used to prevent the untested sites from working.

This member function is valid only when:

- VBump resource is VDDQ;
- VBump resource is both VDD and VDDQ, and the high power option is "yes".

## Syntax

```
SHARED_VBUMP_TEST& resetPin(const string& pin)
```

 |

Parameter

 |

Description

 |
 |

pin

 |

The name of the reset pin.

 |

## Examples

### Example 1

```
SHARED_VBUMP_TEST mTest;
mTest.bumpSource(SHARED_VBUMP_TEST::VBUMP_VDD);
mTest.resetPin("RESETn");
```

### Example 2

```
SHARED_VBUMP_TEST mTest;
mTest.bumpSource(SHARED_VBUMP_TEST::VBUMP_VDD_VDDQ);
mTest.highPower(MTP::OPTION_YES);
mTest.resetPin("RESETn");
```
