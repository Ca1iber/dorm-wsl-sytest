# Solution tools enhancements

- Save margin results of source sync test method in a customer defined format.

For more information refer to Logging output .

- Provide margin limit settings for source sync test methods.

For more information refer to [Parameters for Multi-Strobe testmethod](<02.12.02.05.06.06.02.05_Parameters_for_multistrobe_test_methods.md>).

- For HX card testing a configurable output is available.

For more information refer to Configurable output for HX pins.
