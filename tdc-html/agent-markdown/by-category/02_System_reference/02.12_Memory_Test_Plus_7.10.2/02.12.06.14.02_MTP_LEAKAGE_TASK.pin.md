# MTP_LEAKAGE_TASK.pin()

The pin() member function of [MTP_LEAKAGE_TASK](<02.12.06.14_MTP_LEAKAGE_TASK.md>) lets you specify the pins you want to check for leakage. pin() returns the [MTP_LEAKAGE_PIN_TASK](<02.12.06.14.01_MTP_LEAKAGE_PIN_TASK.md>) class object which you use to set up the measurement conditions for these pins.

## Syntax

```
[MTP_LEAKAGE_PIN_TASK](<02.12.06.14.01_MTP_LEAKAGE_PIN_TASK.md>) pin(const string & pinlist)
```

 |

Parameter

 |

Description

 |
 |

pinlist

 |

The list of the pins or pin groups to be measured in the shared parallel leakage test.

Multiple pins or pin groups are separated by commas.

 |
