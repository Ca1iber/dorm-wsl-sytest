The DQ data pins are mapped to different pogo pins for input and output definitions due to the [dual transmission line](<02.12.05.02.02.02_Data_related_signals_level_configuration.md>) used.

- Define the additional pins:

  - Digital pins: RESET and VREF
  - DPS pins: VDDA,VDDQ, and VDD.

- Set up the digital signal pin groups with same functionality using the pin group names in the example table above.
