Testing GDDR Memory Devices is updated:

- The [DataTrainingFlex](<02.12.02.05.06.06.04_DataTrainingFlex.md>) test method was added.
- [Multiport support](<02.12.02.05.06.06.02.05_Parameters_for_multistrobe_test_methods.md>) for source sync test methods was added.
