# Enhancements of the maintenance operation

The maintenance operation supports multiple static refreshes operations.

To support this feature:

- [New refresh control instructions](<02.12.03.04.12.02_Enabling_and_disabling_maintenance_operations_in_APG_program_file.md>) are developed.
- Multiple rows are needed in the :maintenanceOperation: table of the [Device architecture file syntax](<02.12.03.03.05.01_Device_architecture_file_syntax.md>).
- [Additional configurations](<02.12.03.04.12.01_Setting_up_a_maintenance_operation.md>) for setting up a multiple refreshes operation.
