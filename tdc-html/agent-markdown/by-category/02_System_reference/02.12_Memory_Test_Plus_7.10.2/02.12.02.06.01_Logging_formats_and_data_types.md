# Logging formats and data types

Memory tests are logged to [EDL](<../02.10_Data_Logging/02.10.01.01_Event_Data_Logging_Concepts.md>) with the TEST_TYPE_MEMORY event type and can be formatted as [STDF](<../02.10_Data_Logging/02.10.03.01_Standard_Test_Data_Format__STDF__Overview.md>).

## EDL data types

In particular, the following EDL data types are used to log memory tests:

- [DRLPatternLabelAttr](<../02.10_Data_Logging/02.10.01.04.02.42_DRLPatternLabelAttr.md>)
- [DRLBitFailMapDescAttr](<../02.10_Data_Logging/02.10.01.04.02.08_DRLBitFailMapDescAttr.md>)
- [DRLFailingAddressCountAttr](<../02.10_Data_Logging/02.10.01.04.02.22_DRLFailingAddressCountAttr.md>)
- [DRLResultPinName](<../02.10_Data_Logging/02.10.01.04.02.62_DRLResultPinName.md>)
- [DRLBankSpecificCounts](<../02.10_Data_Logging/02.10.01.04.02.05_DRLBankSpecificCounts.md>)
- [DRLPinSpecificCounts](<../02.10_Data_Logging/02.10.01.04.02.52_DRLPinSpecificCounts.md>)
- [DRLFailingAddressesAttr](<../02.10_Data_Logging/02.10.01.04.02.24_DRLFailingAddressesAttr.md>)
- [DRLPinSpecificAddresses](<../02.10_Data_Logging/02.10.01.04.02.51_DRLPinSpecificAddresses.md>)
- [DRLRARepairResultsAttr](<../02.10_Data_Logging/02.10.01.04.02.61_DRLRARepairResultsAttr.md>)

## STDF record types

STDF formats memory tests as [FTR records](<../02.10_Data_Logging/02.10.03.05.24_Functional_Test_Record__FTR.md>).

## Event formatter

The [Event Formatter](<../02.10_Data_Logging/02.10.02_Event_Formatter.md>) logs events with the TEST_TYPE_MEMORY type, and supports the DRLPinSpecificAddresses and DRLRARepairResultsAttr data types.

## Functional changes

- SmarTest 7.0.4: Logging memory tests events is available only in MTP on HSM.
- MTP 3.1.4: Logging memory tests events is available both in MTP on HSM and MTP on SOC.
- MTP 3.2.2: Adds a new EDL data type, DRLRARepairResults.
- MTP 3.2.2: The event formatter logs events with the TEST_TYPE_MEMORY type, and supports the DRLPinSpecificAddresses and DRLRARepairResultsAttr data types.
