# MTP_MEMORY_PORT.isRepairable()

Queries whether the current port is repairable.

The port is specified with [getMemoryPort()](<02.12.06.17.08_MTP_MEMORY_TEST.getMemoryPort.md>).

## Syntax

```
bool isRepairable () const;
```

List of parameters

There are no parameters.

## Return value

true: The port is repairable.

false: The port is not repairable.

## Related information

[MTP_MEMORY_TEST.getMemoryPort()](<02.12.06.17.08_MTP_MEMORY_TEST.getMemoryPort.md>)

## Functional changes

- Introduced in MTP 3.2.1
