# MTP_CONTINUITY_TASK.execute()

The execute() member function of [MTP_CONTINUITY_TASK](<02.12.06.10_MTP_CONTINUITY_TASK.md>) executes the continuity test based on the measurement conditions set with the [pin()](<02.12.06.10.02_MTP_CONTINUITY_TASK.pin.md>) member function.

Note that when using this member function, you must:

- Use the [DISCONNECT](<../02.07_Test_Method_Reference/02.07.04.01.41_DISCONNECT.md>) API before using execute() since the continuity test requests powering down the DUTs and disconnecting the digital pins before measuring.

The measurement procedure is described in [SharedContinuity test method](<02.12.02.05.06.07.09.08_SharedContinuity_test_method.md>).

- Call the [postExecute()](<02.12.06.10.05_MTP_CONTINUITY_TASK.postExecute.md>) member function at the end of the continuity test after all pins have been measured.

## Syntax

```
void execute()
```
