Retrieves the fail bit results and the functional test results of the pattern that is specified with [getMemoryPattern()](<02.12.06.16.01_MTP_MEMORY_PORT.getMemoryPattern.md>) and is tested with the [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) class.

 Note This API is available only for MTP.

This API is defined in the header file /opt/93000mts/mts/execution_engine/include/MtpMemoryPattern.h.

## Syntax

This class has no constructor. Instances of this class are created by using the [getMemoryPattern()](<02.12.06.16.01_MTP_MEMORY_PORT.getMemoryPattern.md>) function of the [MTP_MEMORY_PORT](<02.12.06.16_MTP_MEMORY_PORT.md>) class.
