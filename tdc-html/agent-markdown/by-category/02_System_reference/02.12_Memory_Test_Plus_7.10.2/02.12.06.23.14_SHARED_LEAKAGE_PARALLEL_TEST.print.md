# SHARED_LEAKAGE_PARALLEL_TEST.print()

The print() member function of [SHARED_LEAKAGE_PARALLEL_TEST](<02.12.06.23_SHARED_LEAKAGE_PARALLEL_TEST.md>) prints the test results of a shared parallel leakage test to a standard output (It is the UI report window in SmarTest), or others.

## Syntax

```
void print(const ostream& out=std::cout) const
```

 |

Parameter

 |

Description

 |
 |

out

 |

Specify where to print the test results.

- The type for the output place is osteram&.
- The default output place is std::out, which is the UI report window in SmarTest.

 |

## Example

```
SHARED_LEAKAGE_PARALLEL_TEST mTest;
mTest.print(); //Print the test results to the default stdout (UI report window).
```
