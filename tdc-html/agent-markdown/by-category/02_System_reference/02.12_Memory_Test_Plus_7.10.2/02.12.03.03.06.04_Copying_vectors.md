# Copying vectors

The bitseq attribute, which always has the value `copy`, allows you to instruct the MTL compiler to copy the vector from the reference pin instead of compiling a new vector for a pin, thereby speeding up the compilation process.

## Syntax

The attribute is included as a normal pin attribute in the [Pin mapping file](<02.12.03.03.06_Pin_mapping_file.md>):

```
<mtlPinName>(<refPinName>)=<smartestPinName>@(bitseq=copy)
```

The reference pin (<refPinName>) can be:

- An MTL pin: The vector is copied from the specified pin.
- A reference macro: The macro is defined in the [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>) and the vector is copied from the pin named in the macro. See Reference macros, below, for more information.

If no reference pin is specified or if a reference macro is used and an empty string is specified for it in the APG pattern file, the bitseq attribute is ignored. In this case, the MTL compiler compiles the vector for the pin normally.

The attributes of the specified MTL pin must match the attributes of the reference pin from which the vector is copied.

The reference pin must not itself reference another pin.

## Reference macros

A reference macro lets you define the actual reference pin name in the APG pattern file and include only a macro reference in the pin mapping file. This allows you to use the same pin mapping file for different purposes and make only changes to the pattern file.

The syntax in this case is:

<mtlPinName>({<pinNameMacro>})=<smartestPinName>@(bitseq=copy)

The macro <pinNameMacro> must be defined in the [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>) using the :define: statement, with the name <pinNameMacro> specified in the :name: column and the pin name you want to associate with it specified in the :value: column.

## Examples

### MTL pin

```
DQo.003(DQo.000)=DQ_o.03@(bitseq=copy)
```

This statement instructs the compiler to equate the MTL pin name DQo.003 with the SmarTest pin name DQ_o.03 and, instead of compiling the vector for this pin, copy the vector from the pin with the MTL name DQo.000.

### Reference macro

In the pin mapping file:

```
DQo.003({$myRefPin})=DQ_o.03@(bitseq=copy)
```

In the APG pattern file:

```
:defines:
{
  :format:
  { :name:     :value: }
  { myRefPin   DQo.000 }
}
```

This statement instructs the compiler to equate the MTL pin name DQo.003 with the SmarTest pin name DQ_o.03 and, instead of compiling the vector for this pin, copy the vector from the pin that is specified in the macro myRefPin.

The current value of this macro is DQo.000 (so the compiler copies the vector from the pin with the MTL name DQo.000), but you could specify a different pin in the APG pattern file without having to change the pin mapping file at all.
