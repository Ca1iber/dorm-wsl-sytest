# SHARING_CONFIGURATION.getTerminatedPinList()

The getTerminatedPinList() member function of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) returns a list of pins that are terminated by the specified termination pin in the [topology block](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>).

## Syntax

```
string getTerminatedPinList(const string & vterm) const
```

 |

Parameter

 |

Description

 |
 |

vterm

 |

The termination pin terminates the pins you want to retrieve.

 |
