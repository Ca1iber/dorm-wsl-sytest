# GDDR5 Training test method

The GDDR5 Training test method combines the previous five test methods, allowing you to apply them in one step instead of individually. You can configure the GDDR5 Training test method using a set of parameters that are explained below.

Additional parameters as well as defaults are configured in the [GDDR5 training configuration file](<02.12.02.05.06.03.01_GDDR5_training_configuration_file.md>).
