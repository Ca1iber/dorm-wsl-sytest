# MTP_MEMORY_TEST.setImmediateBitmapToFile()

The setImmediateBitmapToFile() member function of [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) lets you switch on and off the generation if bit fail map files.

This is an optional method.

## Syntax

```
MTP_MEMORY_TEST& setImmediateBitmapToFile(const bool status)
```

 |

Parameter

 |

Description

 |
 |

status

 |

Whether a bit map file will be generated:

- true: The test method automatically generates a bit failmap file for further analysis.
- false: No bit fail map file is generated.

The default is false.

 |

## Example

To switch on bit fail map file generation:

```
MTP_MEMORY_TEST memoryTest();
memoryTest.setImmediateBitmapToFile(true);
```
