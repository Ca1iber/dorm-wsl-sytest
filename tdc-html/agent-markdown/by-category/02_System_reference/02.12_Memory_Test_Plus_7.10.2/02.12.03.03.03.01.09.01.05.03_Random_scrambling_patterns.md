# Random scrambling patterns

Random scrambling is scrambling that cannot be described by Boolean expressions but follows an irregular scheme.

Without MTL arrays, the only way to implement random scrambling is using vertical bit shifting which is rather cumbersome.

With MTL arrays, you can create a mapping table to provide one-to-one mapping of the original addresses or data and their scrambled results:

- The mapping table stores the scrambled values for the original addresses or data.
- The original addresses or data are used as the index of the table.

From the index you find the corresponded scrambled values.
