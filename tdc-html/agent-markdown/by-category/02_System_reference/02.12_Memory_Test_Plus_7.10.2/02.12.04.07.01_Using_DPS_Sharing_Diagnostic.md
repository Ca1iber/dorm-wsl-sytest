# Using DPS Sharing Diagnostic

Using the DPS Sharing Diagnostic tool is a simple step-by-step process. The GUI guides you through all the test steps.

## About this task

Use this tool when you want to verify a DPS sharing load board before releasing it or when you want to test a board in the field to find defects.

## Before you begin

You need:

- A [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>)

Make sure these items are defined in the file:

  - oc_reset utility control setting
  - default utility control setting
  - idd utility controls
  - Topology settings with the actterm termination parameter

If any of these items are missing, some or all diagnostics may not be available.

- A [Diagnostic configuration file](<02.12.04.07.03_Diagnostic_configuration_file.md>)
- A [Pin configuration file](<02.12.03.03.09.01_Pin_configuration_file.md>)

## Procedure

-  In SmarTest, choose 93000 > System > Site Control and activate the sites that you want to test with the DPS Sharing Diagnostic.
-  Start DPS Sharing Diagnostic, for example, by entering `/opt/93000mts/mts/utilities/bin/shared_dps_diag` on the command line.

By default, the tool only displays fail information in the Diagnostic Process report window. To see both pass and fail information, add the -verbose command line option, for example, `/opt/93000mts/mts/utilities/bin/shared_dps_diag -verbose`.

The start screen is displayed:

  ![DPS Sharing Diagnostic start screen](<../../../../raw/123195.png>)
-  Select the sharing configuration file and the diagnostic configuration file from their pop-up menus.
-  Choose the pin configuration file from the Pin Configuration list.

Three options are available for choosing the pin configuration file:

  - In SmarTest loaded Pin configuration: The pin configuration file which is already loaded in SmarTest
  - From Sharing Configuration file: The pin configuration file specified in the sharing configuration file
  - Select file: This option lets you choose a pin configuration file from the shortcut menu.

-  Click Next.

The Diagnostic Steps screen is displayed:

  ![DPS Sharing Diagnostic diagnostics steps screen](<../../../../raw/123197.png>)
-  Select all diagnostics steps you want to perform. For details on the various tests, see [DPS Sharing Diagnostic test scopes](<02.12.04.07.02_DPS_Sharing_Diagnostic_test_scopes.md>).

Note that the Overcurrent Protection option is reserved for future expansion and cannot currently be enabled.

If any diagnostics steps are disabled, the Messages box displays the reason.

Except for the Vterm Relays test, all tests require you to insert a short device. The diagnostic will prompt you when and where to insert it.

-  If you want to perform measurements in parallel, specify how many short devices are available. (The default value is 1.)

Parallel operation lets you simultaneously test sites in different domains (but not within the same domain). You need multiple short devices (one for each site to be tested in parallel).

-  Click Next.

The Diagnostic Progress screen is displayed:

  ![DPS Sharing Diagnostic diagnostic progress screen](<../../../../raw/123201.png>)
-  Click Execute to start the tests.

The Execute button changes to the Break button while the tests are running.

You can stop the tests by clicking Break. Any errors found are displayed in the window. You can save the report by clicking Save As.

## Results

The found errors, if any, are displayed in the program window.

## What to do next

If the load board is found to be OK, no action is required.

If any errors are found, repair or exchange the load board.
