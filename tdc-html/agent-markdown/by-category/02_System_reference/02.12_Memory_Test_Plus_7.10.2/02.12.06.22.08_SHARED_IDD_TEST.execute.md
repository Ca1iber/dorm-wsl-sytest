# SHARED_IDD_TEST.execute()

The execute() member function of [SHARED_IDD_TEST](<02.12.06.22_SHARED_IDD_TEST.md>) lets you execute a shared IDD test based on your previous setup.

## Syntax

```
void execute() const
```

## Example

```
SHARED_IDD_TEST mTest;
mTest.execute();
```

[SHARED_IDD_TEST](<02.12.06.22_SHARED_IDD_TEST.md>)
