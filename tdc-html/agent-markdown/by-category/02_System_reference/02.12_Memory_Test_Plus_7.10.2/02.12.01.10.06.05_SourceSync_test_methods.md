# SourceSync test methods

Shmoo settings have been added to the SourceSync fast mode and standard mode test methods.

The SourceSync shmoo fast mode and SourceSync shmoo standard mode test methods have been deprecated. That means that they are still included with MTP but may be removed in the future.
