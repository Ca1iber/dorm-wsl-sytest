# Operators

#### Subtopics

- [Data types relevant to operators](<02.12.03.03.03.01.01.01_Data_types_relevant_to_operators.md>)
- [Index operator](<02.12.03.03.03.01.01.02_Index_operator.md>)
- [Select operator](<02.12.03.03.03.01.01.03_Select_operator.md>)

The MTL compiler supports most of the operators available in C. There are, however, some restrictions as to their usage.

The below table lists the operators supported by the MTL compiler. They are listed in decreasing order of precedence; all operators between a pair of lines have the same precedence. For example, * and / (multiply and division) have the same precedence, which is higher than that of & (bitwise AND) and lower than that of ~ (bitwise NOT).

Note Data types for the operands used with each operator are described in [Data types relevant to operators](<02.12.03.03.03.01.01.01_Data_types_relevant_to_operators.md>).

&&

 |

Logical AND.

Compares two expressions/operands and returns true only if both evaluate to true. Returns false if one or both evaluate to false. The following list shows all possible combinations:

- true && false // Evaluates false because the second is false
- false && true // Evaluates false because the first is false
- true && true // Evaluates true because both are true
- false && false // Evaluates false because both are false
 |
 |

| |

 |

Logical OR.

Compares two expressions/operands and returns true if one or both evaluate to true. Returns false only if both evaluate to false. The following list shows all possible combinations:

true || false // Evaluates true because the first is true

false || true // Evaluates true because the second is true

true || true // Evaluates true because both are true

false || false // Evaluates false because both are false

 |
 |

!

 |

Logical NOT.

Inverts the Boolean value of an expression/operand. Returns true if the expression/operand is false and returns false if the expression/operand is true.

For example, if the expression (a>b) evaluates to true, then !(a>b) evaluates to false.

 |
 |

? :

 |

Conditional operator, used only in the [APG program file](<02.12.03.03.03_APG_program_file.md>). Its syntax is:

- `condition ? first_expression/operand : second_expression/operand`

The condition must evaluate to true or false. If condition is true, first_expression/operand is evaluated and becomes the result. If condition is false, second_expression/operand is evaluated and becomes the result. Only one of the two expressions is evaluated.

The first_expression/operand and second_expression/operand must have the same type, which determines the type of the whole expression.

Note that you can use loop dependent variables in the expressions of this operator, which is different from [the if statement](<02.12.03.03.03.01.03_Conditional_execution.md>). (In an if statement, you cannot use loop dependent variables.) See the example in [Conditional execution](<02.12.03.03.03.01.03_Conditional_execution.md>).

It is not possible to assign values to loop variables inside the loop (that is, anywhere except the loop initialization statement).
