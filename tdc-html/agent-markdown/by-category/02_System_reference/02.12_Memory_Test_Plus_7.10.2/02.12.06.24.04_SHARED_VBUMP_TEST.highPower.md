# SHARED_VBUMP_TEST.highPower()

The highPower() member function of [SHARED_VBUMP_TEST](<02.12.06.24_SHARED_VBUMP_TEST.md>) lets you specify whether the high power is supplied or not. This member function is valid only when both VDD and VDDQ as the VBump resource.

## Syntax

```
SHARED_VBUMP_TEST& hightPower(MTP::OPTION_TYPE option)
```

 |

Parameter

 |

Description

 |
 |

option

 |

This parameter can be MTP::OPTION_YES or MTP::OPTION_NO.

- MTP::OPTION_YES: When the DPS32 max current is greater than 1.5 A.
- MTP::OPTION_NO: When the DPS32 max current is smaller or equal to 1.5 A.

 |

## Example

```
SHARED_VBUMP_TEST mTest;
mTest.bumpSource(SHARED_VBUMP_TEST::VBUMP_VDD_VDDQ);
mTest.highPower(MTP::OPTION_YES);
```
