# Enhancements of the MTP_MEMORY_PATTERN API

There are several enhancements of the MTP_MEMORY_PATTERN_API.

These enhancements are:

- Adds new member functions: [getDeviceSize()](<02.12.06.15.09_MTP_MEMORY_PATTERN.getDeviceSize.md>), [getFailingCycleAddressList()](<02.12.06.15.11_MTP_MEMORY_PATTERN.getFailingCycleAddressList.md>), [getPassFailResult()](<02.12.06.15.12_MTP_MEMORY_PATTERN.getPassFailResult.md>), [judgeAndLog()](<02.12.06.15.14_MTP_MEMORY_PATTERN.judgeAndLog.md>), and [print()](<02.12.06.15.15_MTP_MEMORY_PATTERN.print.md>).
- The member function [setBitMapFileName()](<02.12.06.15.01_MTP_MEMORY_PATTERN.setBitMapFileName.md>) is enhanced to support multiport.
- Adds new syntaxes to the [getFailBitCount()](<02.12.06.15.07_MTP_MEMORY_PATTERN.getFailBitCount.md>) member function.
- Adds new syntaxes to the [getFailingAddressList()](<02.12.06.15.08_MTP_MEMORY_PATTERN.getFailingAddressList.md>) member function.
