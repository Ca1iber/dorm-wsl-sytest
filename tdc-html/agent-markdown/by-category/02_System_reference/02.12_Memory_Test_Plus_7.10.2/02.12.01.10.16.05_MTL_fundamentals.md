# MTL fundamentals

MTL fundamentals are examples provided for GDDR3 devices on your system controller.

These examples are coded for industry standard devices. You can use them for a rapid start to test the device.

You can find the MTL fundamentals in this directory: /opt/93000mts/mts/device_solutions.
