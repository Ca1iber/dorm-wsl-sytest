The MTP_DPS_MEASURE class provides an API for measuring DPS under test in parallel for the DUTs in driver sharing.

MTP_DPS_MEASURE provides the same functionality as the [DPS_TASK](<../02.07_Test_Method_Reference/02.07.04.01.50_DPS_TASK.md>) API. But DPS_TASK cannot be used for driver sharing test since the multiple executions will overwrite the previous results.

Note MTP_DPS_MEASURE is available only for MTP.

## Syntax

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/MTP_DPS_MEASURE.h.
