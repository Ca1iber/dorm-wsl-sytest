# SHARED_VBUMP_TEST.resultPin()

The resultPin() member function of [SHARED_VBUMP_TEST](<02.12.06.24_SHARED_VBUMP_TEST.md>) lets you specify the result pins for a functional test.

## Syntax

```
SHARED_VBUMP_TEST& resultPin(const string& pinlist)
```

 |

Parameter

 |

Description

 |
 |

pinlist

 |

The list of the results pins.

 |

## Example

```
SHARED_VBUMP_TEST mTest;
mTest.resultPin("@"); // The results pins are all pins
mTest.resultPin("Out_pins");
```
