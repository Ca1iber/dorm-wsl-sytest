# Building MTP files with MTP-EWC

#### Subtopics

- [Accessing the MTP build configuration pages](<02.12.02.05.12.01_Accessing_the_MTP_build_configuration_pages.md>)
- [The MTP build configuration pages](<02.12.02.05.12.02_The_MTP_build_configuration_pages.md>)
- [MTP build commands in the shortcut menu](<02.12.02.05.12.03_MTP_build_commands_in_the_shortcut_menu.md>)

The MTP build functions offered in [MTP-EWC](<02.12.04.02_MTP-EWC.md>) (SmarTest Work Center) are the [MTP build configuration pages](<02.12.02.05.12.02_The_MTP_build_configuration_pages.md>) and [MTP build commands](<02.12.02.05.12.03_MTP_build_commands_in_the_shortcut_menu.md>). To build MTP .apg files, you first set up build configurations on [The MTP build configuration pages](<02.12.02.05.12.02_The_MTP_build_configuration_pages.md>), and then build those files with [MTP build commands](<02.12.02.05.12.03_MTP_build_commands_in_the_shortcut_menu.md>).

## About this task

The advantages of using MTP_EWC to build are:

- You can create multiple build configurations.
- You can create multiple compilers in one build configuration. Each compiler will compile a group of .apg files.
- Incremental build

During a SmarTest session, the MTP .apg files which have been built will not be built again by the same build configuration unless you modify the .apg files, the related [MTL setup files](<02.12.03.03.01_Overview_of_configuration_files.md>), or the compiler options.

 Note To learn the other features on MTP-EWC, see [MTP-EWC](<02.12.04.02_MTP-EWC.md>).

## Procedure

-  [Open the MTP build configuration pages](<02.12.02.05.12.01_Accessing_the_MTP_build_configuration_pages.md>).

You will see the configuration pages, which include the MTP Build main page and two subpages: Compiler Options and Environment. For details, see [The MTP build configuration pages](<02.12.02.05.12.02_The_MTP_build_configuration_pages.md>).

-  On the MTP Build page, create as many build configurations as you want and activate the one you want to use.

For details, see the "MTP Build page" section in [The MTP build configuration pages](<02.12.02.05.12.02_The_MTP_build_configuration_pages.md>).

-  On the Compiler Options page, select a created build configuration and set up compiler options for it.

You can set up different compilers for this build configuration. Each compiler, set up as a Compiler Group on this page, has its own compiler options and .apg files. When build, each compiler will compile its contained .apg files according to its compiler options.

For details, see [The Compiler Options page](<02.12.02.05.12.02.01_The_Compiler_Options_page.md>).

-  On the Environment page, select a created build configuration and set up environment variables for it.

For details, see [The Environment page](<02.12.02.05.12.02.02_The_Environment_page.md>).

-  If you have created multiple build configurations in step 2, repeat step 3 and 4 for each build configuration.
-  Click on OK to finish setup.

All configuration pages close.

-  In the Project Explorer view, right-click the .apg files or the MTP project containing the .apg files you want to build to display the [MTP build commands](<02.12.02.05.12.03_MTP_build_commands_in_the_shortcut_menu.md>).
-  Select Build By Active (its keyboard shortcut is Alt + B) or Build MTP Pattern(s) Using to build the MTP .apg files.
