# CTrainingConfig

The CTrainingConfig class defines constants for the names of the parameters in the [GDDR5 training configuration file](<02.12.02.05.06.03.01_GDDR5_training_configuration_file.md>).

We recommend that you always use these constants to refer to the parameters instead of the names itself.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/training/include/TrainingConfig.h.

## Syntax

### Constants

The names of the constants are similar to the parameters they reference, with a prefix of PARA_.

