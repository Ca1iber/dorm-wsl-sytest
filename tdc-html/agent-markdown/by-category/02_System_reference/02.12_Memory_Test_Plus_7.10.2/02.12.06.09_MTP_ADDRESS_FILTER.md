# MTP_ADDRESS_FILTER

#### Subtopics

- [MTP_ADDRESS_FILTER.setRange()](<02.12.06.09.01_MTP_ADDRESS_FILTER.setRange.md>)
- [MTP_ADDRESS_FILTER.setMode()](<02.12.06.09.02_MTP_ADDRESS_FILTER.setMode.md>)
- [MTP_ADDRESS_FILTER.setDbits()](<02.12.06.09.03_MTP_ADDRESS_FILTER.setDbits.md>)
- [MTP_ADDRESS_FILTER.isValidAddress()](<02.12.06.09.04_MTP_ADDRESS_FILTER.isValidAddress.md>)

This class defines an address filter to select a certain range of addresses to generate or not to generate memory test results, such as bit map file, fail bit count, and fail addresses list.

This class is used by [MTP_MEMORY_TEST.addAddressFilter()](<02.12.06.17.01_MTP_MEMORY_TEST.addAddressFilter.md>), and [MTP_MULTI_FILTER.addAddressFilter()](<02.12.06.18.01_MTP_MULTI_FILTER.addAddressFilter.md>).

This API is defined in the header file /opt/93000mts/mts/execution_engine/include/MtpAddressFilter.h.

## Syntax

```
MTP_ADDRESS_FILTER();
```

Creates an object to define an address filter.

List of parameters

There are no parameters.

## Return value

Using [MTP_ADDRESS_FILTER.isValidAddress()](<02.12.06.09.04_MTP_ADDRESS_FILTER.isValidAddress.md>), it returns true or false for an address within the [filter range](<02.12.06.09.01_MTP_ADDRESS_FILTER.setRange.md>) or not.

Otherwise, there is no return value.

## Example

```
MTP_ADDRESS_FILTER filter;
```
