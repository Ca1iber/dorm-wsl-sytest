# GET_CURRENT_UTILITY_CONTROL

GET_CURRENT_UTILITY_CONTROL() takes the name of a utility control line and returns an index for that utility control line in the utility_control block of the sharing configuration file. The index represents the location within the utility_control block. If the location is the first line of the utility_control block, the index 0 will be returned.

The function must be used in the for-each-test loop block. It returns an index of the utility control line that applies to the current loop iteration (as specified by the utility control's conditions). With the returned result you can execute this utility control line by using [SHARING_CONFIGURATION.utilityActionExecute()](<02.12.06.25.09_SHARING_CONFIGURATION.utilityActionExecute.md>).

If there is no utility control line with the specified name that applies to the current loop iteration, -1 will be returned.

There are two types of for-each-test blocks:

- [FOR_EACH_TEST_BEGIN](<02.12.06.04_FOR_EACH_TEST_BEGIN.md>) and [FOR_EACH_TEST_END](<02.12.06.06_FOR_EACH_TEST_END.md>)
- [FOR_EACH_TEST_BEGIN_WITH_RESET](<02.12.06.05_FOR_EACH_TEST_BEGIN_WITH_RESET.md>) and [FOR_EACH_TEST_END](<02.12.06.06_FOR_EACH_TEST_END.md>)

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/SHARED_UTIL.h.

## Syntax

```
GET_CURRENT_UTILITY_CONTROL(testName)
```

 |

Parameter

 |
