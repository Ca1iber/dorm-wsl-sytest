# MTP_ADDRESS_FILTER.isValidAddress()

This member function checks whether an address is in the filter range (set by [MTP_ADDRESS_FILTER.setRange()](<02.12.06.09.01_MTP_ADDRESS_FILTER.setRange.md>)) or not, and returns the result.

## Syntax

```
bool isValidAddress(ADDRESS address);
```

Parameter
 |

Parameter

 |

Description

 |
 |

address

 |

The address you want to check whether it is in the filter range or not.

 |

## Return value

true: If the address is in the filter range.

false: If the address is not in the filter range.

## Example

```
//Define a filter
MTP_ADDRESS_FILTER filter;
filter.setRange(MTP::X_ADDRESS,0,1024);
filter.setRange(MTP::Y_ADDRESS,0,1024);
filter.setMode(MTP::EXCLUDE);

ADDRESS addr;
addr.x = 0;
addr.y = 0;
//According the filter setup above, (x = 0, y = 0) is within the filter range although
//this address is set to not generate a memory test result.

if (true == filter.isValidAddress(addr))
{
   cout << addr << " Valid" << endl;
}
//The (x = 0, y = 0) address will be output since this address is within the address range of the filter.
```
