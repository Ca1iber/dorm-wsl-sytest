The V93000 test system memory test software supports the definition of algorithmic patterns using the [Memory Test Language (MTL)](<02.12.03.01_Overview_of_MTL.md>).

The topic [Memory test pattern definition elements](<02.12.02.04.01_Memory_test_pattern_definition_elements.md>) shows with examples how each the definition elements are supported by the common MTL syntax.

[Creating an MTL pattern](<02.12.02.04.04_Creating_an_MTL_pattern.md>) is the central information point to finally get to your test program using MTL compiler.

During pattern creation you have to define the compiler input files:

- Create device access
- Create device architecture
- Create pattern file
- Create program file
- Pin Mapping (one pin mapping file per device)

When the set of MTL files for the compiler are created you run the compiler using the options available. See [Using the MTL compiler from the GUI](<02.12.03.02.04_Using_the_MTL_compiler_from_the_GUI.md>) and [Using the MTL compiler from the command line](<02.12.03.02.05_Using_the_MTL_compiler_from_the_command_line.md>) for details.
