# SHARED_VBUMP_TEST.bumpSource()

The bumpSource() member function of [SHARED_VBUMP_TEST](<02.12.06.24_SHARED_VBUMP_TEST.md>) lets you specify the current Vbump resources.

## Syntax

```
SHARED_VBUMP_TEST& bumpSource(SHARED_VBUMP_TEST::VBUMP_SOURCE_TYPE source)
```

 |

Parameter

 |

Description

 |
 |

source

 |

Name of the current Vbump resource.

It can be any type of VBUMP_SOURCE_TYPE:

- SHARED_VBUMP_TEST::VBUMP_VDD
- SHARED_VBUMP_TEST::VBUMP_VDDQ
- SHARED_VBUMP_TEST::VBUMP_VDD_VDDQ

See the definitions of VBUMP_SOURCE_TYPE in "Public types" in [SHARED_VBUMP_TEST](<02.12.06.24_SHARED_VBUMP_TEST.md>)

 |

## Example

```
SHARED_VBUMP_TEST mTest;
mTest.bumpSource(SHARED_VBUMP_TEST::VBUMP_VDD);
```
