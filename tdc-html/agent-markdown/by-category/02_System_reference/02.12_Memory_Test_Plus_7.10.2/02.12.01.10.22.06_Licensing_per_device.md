# Licensing per device

The new licensing-per-device concept is based on a licensing file for each device, the device license file. Licensing-per-device does not break the known model file concept and mechanisms. It is rather an add-on and enhancement of that concept.

## Benefit

This concept allows you to better utilize your licenses by requesting only those licenses from the license server that are really required for a device.
