# MTP_CONTINUITY_TASK.settlingTime()

The settlingTime() member function of [MTP_CONTINUITY_TASK](<02.12.06.10_MTP_CONTINUITY_TASK.md>) lets you specify the additional settling time for the test system.

## Syntax

```
void settlingTime(double time)
```

 |

Parameter

 |

Description

 |
 |

time

 |

The additional time for a test.

The time unit is second.

If you Do not specify a settling time, 0 is used.

 |
