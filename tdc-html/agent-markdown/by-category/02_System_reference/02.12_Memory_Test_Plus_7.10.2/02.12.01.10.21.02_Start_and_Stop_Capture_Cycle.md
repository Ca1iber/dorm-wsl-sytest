# Start and Stop Capture Cycle

Within the testsuite panel "Parameter Dialog" a start and stop capture cycle can be defined.

## Benefit

Many memory patterns execute a large number of cycles. By default all failing cycles are captured. The new parameters Start Capture Cycle and Stop Capture Cycle allow the user to focus the error capture to a portion of the entire memory pattern execution.
