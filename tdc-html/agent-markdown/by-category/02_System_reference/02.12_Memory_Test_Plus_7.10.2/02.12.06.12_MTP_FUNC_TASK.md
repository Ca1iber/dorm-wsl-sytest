# MTP_FUNC_TASK

#### Subtopics

- [MTP_FUNC_TASK.pin()](<02.12.06.12.01_MTP_FUNC_TASK.pin.md>)
- [MTP_FUNC_TASK.execute()](<02.12.06.12.02_MTP_FUNC_TASK.execute.md>)
- [MTP_FUNC_TASK.getPassFail()](<02.12.06.12.03_MTP_FUNC_TASK.getPassFail.md>)

The MTP_FUNC_TASK class provides an API for executing a functional test.

MTP_FUNC_TASK provides the same function as the [FUNCTIONAL_TEST](<../02.07_Test_Method_Reference/02.07.04.01.75_FUNCTIONAL_TEST.md>) API. But FUNCTIONAL_TEST cannot be used for driver sharing test since the multiple executions will overwrite the previous results.

Note MTP_FUNC_TASK is available only for MTP.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/MTP_FUNC_TASK.h.
