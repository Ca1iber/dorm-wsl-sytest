# ParallelShmoo_MTS_2_2 testmethod

The new ParallelShmoo_MTS_2_2 testmethod allows you to define, which ASCII characters represent passed and failed tests in the plot.

## Benefit

You can evaluate the test result with several existing scripts which have different hard coded passed/failed characters.

## More Info

For further details, see [Parallel Shmoo testmethods](<02.12.02.05.06.05_Parallel_Shmoo_test_method.md>).
