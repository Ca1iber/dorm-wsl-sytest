# Array in MTL

#### Subtopics

- [Using MTL arrays](<02.12.03.03.03.01.09.01_Using_MTL_arrays.md>)

Array in MTL is a C-like array.

MTL array is used in [the .prog file](<02.12.03.03.03_APG_program_file.md>) for programming patterns. Its advantage is you can access any array elements via the array indexes, with which you can simplify pattern algorithms.

For example, writing a checkerboard pattern becomes simple by using array.

```
DW[2] = {0x55, 0xAA};

for (bank = 0; bank < MAX_BANK; bank += 1)
{
  for (row = 0; row < MAX_ROW; row += 1)
  {
    for (col = 0; col < MAX_COL; col += 1)
    {
      write(DW[row & 0x01], col, row, bank);
    }
  }
}
```

You even can create more complicated patterns, such as:

- Non-sequential burst order (for DDR3 or DDR4)
- Random scrambling (vertical bit shift)
- Random pattern with loops
