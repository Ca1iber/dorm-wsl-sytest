# Logging output

To enable you to analyze the results of a Source Sync test method you must save them to the data log.

## About this task

To save the Source Sync test results into the data log follow the procedure below.

## Before you begin

You have to set the report formatter to Event Formatter, as described in [How to Activate the Event Formatter](<../02.10_Data_Logging/02.10.02.01_Activating_the_Event_Formatter.md>).

## Procedure

-  Set the [System flags](<02.12.02.05.10.01_System_flags.md>):

log_events_enable to On

data log_to_report_win to On

-  Set either of the output_on_pass or output_on_fail[Test suite flags](<02.12.02.05.10.03_Test_suite_flags.md>) to On.
-  In the test method's parameter dialog, do either of the following:

  - Enter a margin limit in the result parameter dialog.
  - Enable at least one of the OutputErrorMap, Output Histogram, or OutputMargin debug output options in the parameter dialog.

## Results

When you run the test method, data logging is activated.
