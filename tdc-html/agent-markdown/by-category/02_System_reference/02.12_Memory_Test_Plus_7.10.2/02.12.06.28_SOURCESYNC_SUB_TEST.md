Sets up a sweep test, which will sweep from the [start cycle](<02.12.06.29.12_SOURCESYNC_TEST.startCycle.md>) to the [stop cycle](<02.12.06.29.13_SOURCESYNC_TEST.stopCycle.md>). The object of this class can only be crated with [SOURCESYNC_TEST.test()](<02.12.06.29.14_SOURCESYNC_TEST.test.md>).

 Note Do not create any instance with this class.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/SOURCESYNC_SUB_TEST.h.
