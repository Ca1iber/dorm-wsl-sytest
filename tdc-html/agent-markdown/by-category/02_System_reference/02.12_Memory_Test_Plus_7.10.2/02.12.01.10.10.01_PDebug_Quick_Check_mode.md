# PDebug Quick Check mode

A new automated mode has been added to PDebug. The Quick Check mode is based on the TDR mode and can automatically find pins with deviating characteristics.

## Benefit

The Quick Check mode enables you to verify DUT boards with little effort.

  Note From 7.5.0, PDebug is obsoleted from MTP.
