# Device Access Simplification

To simplify the :apgAccess: section in the device access file (.dvac) the two columns :devCyc: and :stateParam: are optional (:devCyc: is mandatory if indirect waveform mapping is used).

See Device Access Simplification in [Memory Test Language (MTL) Programming Reference](<02.12.03_Memory_Test_Language__MTL__Programming_Reference.md>) for detailed information.
