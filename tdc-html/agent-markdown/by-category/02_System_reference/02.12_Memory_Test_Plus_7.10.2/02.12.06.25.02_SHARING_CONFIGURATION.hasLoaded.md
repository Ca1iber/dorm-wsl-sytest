# SHARING_CONFIGURATION.hasLoaded()

The hasLoaded() member function of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) returns "true" if a configuration file has been loaded, and "false" if not.

- If true is returned:

  - You can use the data-accessing member functions of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) to read the data.
  - The [load()](<02.12.06.25.03_SHARING_CONFIGURATION.load.md>) and [setRefPin()](<02.12.06.25.04_SHARING_CONFIGURATION.setRefPin.md>) member functions do not load the specified configuration.

- If false is returned: You can use either [load()](<02.12.06.25.03_SHARING_CONFIGURATION.load.md>) or [setRefPin()](<02.12.06.25.04_SHARING_CONFIGURATION.setRefPin.md>) to load a sharing configuration. Then you can read its data via the data-accessing member functions of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>).

## Syntax

```
bool hasLoaded() const
```
