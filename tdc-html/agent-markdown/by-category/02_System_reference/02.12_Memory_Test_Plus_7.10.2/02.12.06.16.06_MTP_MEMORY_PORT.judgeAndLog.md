# MTP_MEMORY_PORT.judgeAndLog()

Judges and logs the memory test results of the current port.

The port is specified with the [getMemoryPort()](<02.12.06.17.08_MTP_MEMORY_TEST.getMemoryPort.md>) member function of [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>).

## Syntax

```
void judgeAndLog () const;
```

List of parameters

There are no parameters.

Return value

There is no return value.
