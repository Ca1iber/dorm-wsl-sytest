# BFM Viewer updates and enhancements

The following list shows updates and enhancements in the Bit Fail Map Viewer (see [Memory Test Plus Tools Reference](<02.12.04_Memory_Test_Plus_Tools_Reference.md>)).

- Several slight screen changes improve handling (for example headlines on table columns etc.)
- New feature Autoload: the BFM Viewer expects messages from the Result Server when it puts new BFMs on disk.

For more informationrefer to [Extras](<02.12.04.04.03.01.03_Extras_menu.md>).

- Overview and detailed view windows have up/down arrows to change address type, numerical base and desired action. This functions are also available in the context menu.

For more informationrefer to [Chip Overview](<02.12.04.04.03.02.01.02_Chip_Overview.md>).

- In addition the detailed view windows have up/down arrows to change Cells/pixel and Zoom.

For more informationrefer to [Creating and managing detail views](<02.12.04.04.02.04.02_Creating_and_managing_detail_views.md>).

- Assign to Layer function available: select a bitmap and use the shortcut menu to assign a layer (A ... G) to the bitmap.

For more information refer to [Bit Fail Maps](<02.12.04.04.03.02.01.01_Bit_Fail_Maps.md>).

- Fast View in the shortcut menu directly assigns the selected bitmap to layer A and loads it immediately for viewing in Chip Overview.

For more informationrefer to [Bit Fail Maps](<02.12.04.04.03.02.01.01_Bit_Fail_Maps.md>).

- A crosshair can be activated by shortcut or shortcut menu in the overview and all detailed views windows.

For more information refer to [Global](<02.12.04.04.03.01.02.01_Global.md>).
