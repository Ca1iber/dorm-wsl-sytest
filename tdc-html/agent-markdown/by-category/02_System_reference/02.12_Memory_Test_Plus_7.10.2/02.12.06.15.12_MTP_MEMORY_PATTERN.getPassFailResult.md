# MTP_MEMORY_PATTERN.getPassFailResult()

Retrieves the pass/fail test result of the current pattern that is specified with [getMemoryPattern()](<02.12.06.16.01_MTP_MEMORY_PORT.getMemoryPattern.md>) and tested with [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>).

## Syntax

```
bool getPassFailResult() const;
```

List of parameters

There are no parameters.

## Return value

Returns true or false.

## Related information

[MTP_MEMORY_PORT.getMemoryPattern()](<02.12.06.16.01_MTP_MEMORY_PORT.getMemoryPattern.md>)[MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>)

## Functional changes

- Introduced in MTP 3.2.1
