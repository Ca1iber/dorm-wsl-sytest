# Conditional execution

Execution of parts of a compiled pattern can now be made conditional using the standard if , and else statements.

## Benefit

Conditional execution allows for more parameterized patterns that can, for example, automatically adapt to architectural differences. These more flexible patterns are more easily reusable, which results in quicker development and lower maintenance efforts,
