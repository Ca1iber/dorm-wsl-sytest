# SOURCESYNC_TEST.outputErrorMap()

Enables or disables the output of error maps. If not specifying with this function, no error maps will be output.

## Syntax

```
SOURCESYNC_TEST& outputErrorMap (SOURCE_SYNC::JUDGE_TYPEoption);
```

Parameter
 |

Parameter

 |

Description

 |
 |

option

 |

Lets you specify whether to output error maps.

 |

Available options of parameter: <option>
 |

Option

 |

Description

 |
 |

SOURCE_SYNC::YES

 |

Outputs error maps.

 |
 |

SOURCE_SYNC::NO

 |

(Default) does not output error maps.

 |

## Functional changes

- Introduced in MTP 3.2.2
