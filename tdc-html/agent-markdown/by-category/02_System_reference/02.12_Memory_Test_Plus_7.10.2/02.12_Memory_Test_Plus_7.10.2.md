The Memory Test Plus (MTP) documentation describes the software and hardware aspects of performing memory tests by using SmarTest and the separate MTP add-on modules.

This MTP documentation describes the MTP 7.10.2 version for SmarTest 7.10.2.

The HSM test head cards are not supported with SmarTest 7.10.
