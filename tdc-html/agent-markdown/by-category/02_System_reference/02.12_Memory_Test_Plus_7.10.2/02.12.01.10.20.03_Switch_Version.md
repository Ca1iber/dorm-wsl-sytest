# Switch Version

You can use a terminal window or a graphical interface to switch to any version of the MTP Software that is installed on your system controller.

See [Switching to a different MTP version](<02.12.04.01_Switching_to_a_different_MTP_version_on_SmarTest.md>) in System Controller and Software Installation Guide for detailed information.
