# New features on the MTP perspective (MTP-EWC)

There are new features provided on the MTP perspective.

- A variety of features have been provided with the MTP editor to ease your programming, such as syntax highlight, content assistant and etc.

For details, see [Features in the editor view of MTP-EWC](<02.12.04.02.05_Features_for_the_editor_of_MTP-EWC.md>).

- MTL Wizard is created for generating MTP .apg file and the corresponding MTL setups files automatically.

For details, see [Creating MTL files with the MTP wizard](<02.12.04.02.02_Creating_MTL_files_with_the_MTP_wizard.md>).

- Add a new option "Enable MTP License Caching" on the MTP Build configuration page.

For details, see [The MTP build configuration pages](<02.12.02.05.12.02_The_MTP_build_configuration_pages.md>).
