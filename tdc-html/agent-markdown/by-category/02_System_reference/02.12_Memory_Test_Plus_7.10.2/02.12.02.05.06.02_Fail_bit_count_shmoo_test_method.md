# Fail bit count shmoo test method

This test method (MTP_FailBitCountShmoo.Execute) [shmoos](<../02.07_Test_Method_Reference/02.07.05.01.09_Shmoo.md>) a [memory test](<02.12.02.05.06.01_Memory_testing_test_method.md>) to display the number of fail bits at every specified (x, y) on a shmoo plot.

It can display the number of fail bits of:

- An entire memory DUT
- Any bank of a memory DUT
- Any dq pin (a bidirectional data pin) of a memory DUT

The parameters of this test method include the parameters of the [Shmoo test method](<../02.07_Test_Method_Reference/02.07.05.01.09_Shmoo.md>) and the [ExecutionEngine](<02.12.02.05.06.01.03.01_Parameters_for_the_ExecutionEngine_test_method.md>) test method:

- The parameters of the [Shmoo test method](<../02.07_Test_Method_Reference/02.07.05.01.09_Shmoo.md>) will construct a shmoo plot which contains the plot title, the axes and the results to be displayed.

To set up these parameters for fai bit count shmoo tests, refer to the description in [Shmoo](<../02.07_Test_Method_Reference/02.07.05.01.09_Shmoo.md>) except for these parameters:

  - shmooTestSuite: Do not enter a test suite name.
  - x.setupPins and y.setupPins: Select @ (all pins) only.
  - testMode: You can choose:

fail bit count on device: Displays the number of fail bits of an entire memory DUT at every specified (x, y) on a shmoo plot.

fail bit count per bank: Displays the number of fail bits of a bank at every specified (x, y) on a shmoo plot .

fail bit count per dq: Displays the number of fail bits of a dq pin (a bidirectional data pin) at every specified (x, y) on a shmoo plot.

  - resultPins: The selected pins must include the dq pins. Otherwise, you will not see the number of fail bits on the shmoo plot.
  - perPinResult: You will not see this parameter.

- The parameters of the [ExecutionEngine](<02.12.02.05.06.01.03.01_Parameters_for_the_ExecutionEngine_test_method.md>) test method will execute a memory test and count the fail bits.

To set up these parameters for the fail bit count shmoo tests, refer to the [ExecutionEngine](<02.12.02.05.06.01.03.01_Parameters_for_the_ExecutionEngine_test_method.md>) test method. And you must:

  - Enable the parameters Create_Bitmap and Fail_count_enabling.

## Viewing the results of fail bit count shmoo tests

You can:

- Create a test suite with this test method in a testflow, and view the outputs in the report window.

To create the test suite, see [Inserting a test suite into a testlfow](<../02.08_Setup_and_Result_Tools/02.08.04.32.02.01.04_Inserting_a_test_suite_into_the_testflow.md>).

To view the result in the report window, see [Logging shmoo tests in the report window](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.07_Saving_shmoo_plots_to_png_or_ASCII_files.md>) and [Shmoo output of the Event Formatter](<../02.10_Data_Logging/02.10.02.04_Shmoo_output_of_the_Event_Formatter.md>).

- Use the Shmoo Tool to set up a fail bit count shmoo test with this test method and view the plot.

For details, see [Setting up a shmoo test in the Shmoo Tool](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.02_Setting_up_a_shmoo_test_with_the_Shmoo_Tool.md>) and [Viewing fail bit count shmoo plot](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.04.08_Viewing_different_fail_bit_counts_on_a_shmoo_plot.md>).
