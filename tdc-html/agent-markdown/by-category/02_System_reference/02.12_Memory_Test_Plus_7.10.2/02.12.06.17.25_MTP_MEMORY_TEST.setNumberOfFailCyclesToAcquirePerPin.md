# MTP_MEMORY_TEST.setNumberOfFailCyclesToAcquirePerPin()

The setNumberOfFailCyclesToAcquirePerPin() member function of [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) lets you specify how many failing cycles will be captured for each result pin.

This is an optional method.

## Syntax

```
MTP_MEMORY_TEST& setNumberOfFailCyclesToAcquirePerPin(const LONG64 cycles)
```

 |

Parameter

 |

Description

 |
 |

cycles

 |

This parameter specifies how many failing cycle the test method will acquire.

Normally, there is no reason to limit that number. However, characterization and failure analysis may require repetitive test with large patterns that often produce large numbers of failing cycles. In that case, limiting the number of failing cycles acquired can improve performance.

The default is to capture all failing cycles (that is, there is no limit when you do not expressly set it).

 |

## Example

To limit the number of failing cycles per pin to 1024:

```
MTP_MEMORY_TEST memoryTest();
memoryTest.setNumberOfFailCyclesToAcquirePerPin(1024);
```
