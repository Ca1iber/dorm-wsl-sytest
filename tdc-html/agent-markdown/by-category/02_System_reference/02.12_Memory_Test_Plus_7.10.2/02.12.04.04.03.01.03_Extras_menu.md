# Extras menu

The Bit Fail Map Viewer's Extras menu lets you enable miscellaneous settings and export an ASCII bitmap.

The menu contains these commands:

- Failed Cells List Enabled

If this menu command is checked, the BFM Viewer displays the failed cells in the Failed Cells list of the Chip Overview tab. If the command is unchecked, the list remains empty.

- Autoload Mode

If this menu command is checked, the Autoload mode is enabled. The Autoload mode causes the BFM Viewer to automatically load bit fail maps as they become available and blocks manual assignments of bit fail maps to layers. See [Loading bit fail maps automatically](<02.12.04.04.02.03.01_Loading_bit_fail_maps_automatically.md>) for more information.

- Save ASCII Bitmap

Choosing this command saves the currently loaded bit fail maps as a composite ASCII file, in which failed sectors are indicated by a hash (#) and failure-free sector by a dot (.).
