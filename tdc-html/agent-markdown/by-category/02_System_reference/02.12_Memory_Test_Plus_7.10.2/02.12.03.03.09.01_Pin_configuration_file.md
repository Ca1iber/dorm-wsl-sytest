# Pin configuration file

A pin configuration file specifies which pins are available on the DUT.

  ![Miniature scheme of file dependencies with .pin file highlighted](<../../../../raw/102576.png>)

The pin configuration file has the .pin file name extension. It is optionally referenced from the [Pin mapping file](<02.12.03.03.06_Pin_mapping_file.md>) with the using pinconfig keyword. The reference is needed when a port is specified, usually for [multiport operations](<02.12.03.04.14_Multiport_operation.md>) or [Automatic waveform generation](<02.12.03.04.03.03_Automatic_waveform_generation.md>).

 Note The pin mapping file always implicitly references the pin configuration file that is currently chosen in SmarTest because, in that file, DUT pin names are assigned to the SmarTest pin names as defined in the pin configuration file.

Pin configuration files are generated within SmarTest when the pins of the device are defined (see [Setting the DUT Pin Configuration](<../02.08_Setup_and_Result_Tools/02.08.04.18_Pin_configuration_tool.md>) for more information).
