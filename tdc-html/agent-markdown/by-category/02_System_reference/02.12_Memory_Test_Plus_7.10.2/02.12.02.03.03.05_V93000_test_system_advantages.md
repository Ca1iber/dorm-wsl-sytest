# V93000 test system advantages

The V93000 test system presents some advantages over the hardware based APG architecture listed in the table below.

The hardware APG implementation requires much of the test system hardware to be used as a central resource. It makes this architecture more difficult to design for signal fidelity for high frequency applications. The centralized resource architecture must distribute at-speed signaling inside the test system to provide the shared APG pattern data to all of the test system's pins. The V93000 test system integrates an entire test system onto each channel. This minimizes the need for the complicated signal distribution network required by the central resource test system.

The bus width capabilities are fixed to a limited size on a hardware APG test system. That is, the X-address bus, the Y-address bus and the dataword bus are fixed in size by the hardware design of the test system. The V93000 test system can create patterns for devices with configurations up to a 64-bit X-address bus, a 64-bit Y-address bus, and a 512-bit dataword bus. If you are using 32-bit system, the configuration for X and Y addresses is up to 32 bits.

The fact that the V93000 test system can switch between vectors and APG patterns so easily provides a significant advantage over the historical architectures. As standalone memory devices become more complex and embedded memories become more difficult to access there will be more of a need for a test system that can execute both kinds of patterns.

A traditional memory test system is designed to efficiently test the memory devices being manufactured at the time of the test system's design. As memory devices evolve into more complex devices, their testing requirements surpass the capabilities of the test system. Therefore, at some point a new test system that can test the newer, more complex devices is needed. This causes a repeating cycle of device evolution and test system purchases, which will increase in occurrence as product design cycle times decrease. A more desirable solution would be a test system that is flexible and robust enough to handle the challenges of today's device as well as the next generation's device. You will see in the next section that the V93000 test system APG is implemented in software which gives the advantage of an APG that can change over time and adapt to new device technologies.
