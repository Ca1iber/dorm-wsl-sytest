# SHARED_VBUMP_TEST.init()

The init() member function of [SHARED_VBUMP_TEST](<02.12.06.24_SHARED_VBUMP_TEST.md>) lets you do initializations for a test.

You must invoke this member function ahead of any other functions when you create a test method with the SHARED_VBUMP_TEST API.

## Syntax

```
SHARED_VBUMP_TEST& init()
```
