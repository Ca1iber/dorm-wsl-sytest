# SHARED_LEAKAGE_PARALLEL_TEST.judegeAndLog()

The judgeAndLog() member function of [SHARED_LEAKAGE_PARALLEL_TEST](<02.12.06.23_SHARED_LEAKAGE_PARALLEL_TEST.md>) judges and logs the test results of a shared leakage parallel test.

## Syntax

```
void judgeAndLog() const
```

## Example

```
SHARED_LEAKAGE_PARALLEL_TEST mTest;
mTest.judgeAndLog();
```
