# DC Scale test method

This new test method allows you to trigger DC events in combination with a DC Scale DPS32 (Digital Power Supply) directly from a MTL memory pattern by defining trigger points in the pattern flow.

For information on the test method itself see DC Scale.

In addition you must set up several MTL files accordingly prior to compilation to use this test method.

For more information, see:

- Interaction between MTL files
- [APG pattern file](<02.12.03.03.02_APG_pattern_file.md>)
