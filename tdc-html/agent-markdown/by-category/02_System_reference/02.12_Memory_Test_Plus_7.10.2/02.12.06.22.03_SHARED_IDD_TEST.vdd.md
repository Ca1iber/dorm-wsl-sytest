# SHARED_IDD_TEST.vdd()

The vdd() member function of [SHARED_IDD_TEST](<02.12.06.22_SHARED_IDD_TEST.md>) lets you specify the power supply pin used.

## Syntax

```
SHARED_IDD_TEST& vdd(const string& pinlist)
```

 |

Parameter

 |

Description

 |
 |

pinlist

 |

Pin list of VDD used.

This parameter is ignored for DPS-shared load boards for which there is a utility_control section in the [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>).

 |

## Example

```
SHARED_IDD_TEST mTest;
mTest.vdd("VDD");
```
