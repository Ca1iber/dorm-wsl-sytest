# SHARED_LEAKAGE_PARALLEL_TEST.getValue()

The getValue() member function of [SHARED_LEAKAGE_PARALLEL_TEST](<02.12.06.23_SHARED_LEAKAGE_PARALLEL_TEST.md>) retrieves the measured voltage value in [V] of a specified pin in a shared parallel leakage test.

## Syntax

```
double getValue(const string& pin) const
```

 |

Parameter

 |

Description

 |
 |

pin

 |

The name of a pin whose measured voltage value you want to get in [V].

 |

## Example

```
SHARED_LEAKAGE_PARALLEL_TEST mTest;
double Value;
Value = mTest.getValue("DO_Bus");
```
