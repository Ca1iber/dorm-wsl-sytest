# Development procedure and tools

The tasks involved in setting up a complete memory test are performed in three main steps:

- Test planning, such as test methodologies, necessary test system resource performance, necessary system software functionality, and so on.
- Preparation of a variety of test data on the system software.
- Test execution, debugging and DUT characterization.
