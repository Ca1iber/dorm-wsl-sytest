# SOURCESYNC_TEST.outputHistogram()

Enables or disables the output of histogram data. If not specifying with this function, no histogram data will be output.

## Syntax

```
SOURCESYNC_TEST& outputHistogram (SOURCE_SYNC::JUDGE_TYPE option);
```

Parameter
 |

Parameter

 |

Description

 |
 |

option

 |

Lets you specify whether to output histogram data.

 |

Available options of parameter: <option>
 |

Option

 |

Description

 |
 |

SOURCE_SYNC::YES

 |

Outputs histogram data.

 |
 |

SOURCE_SYNC::NO

 |

(Default) does not output histogram data.

 |

## Functional changes

- Introduced in MTP 3.2.2
