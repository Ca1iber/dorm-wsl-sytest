# MTP_PPMU_MEASURE

#### Subtopics

- [MTP_PPMU_MEASURE.pin()](<02.12.06.19.01_MTP_PPMU_MEASURE.pin.md>)

- [MTP_PPMU_MEASURE.getPassFail()](<02.12.06.19.03_MTP_PPMU_MEASURE.getPassFail.md>)
- [MTP_PPMU_MEASURE.getValue()](<02.12.06.19.04_MTP_PPMU_MEASURE.getValue.md>)

The MTP_PPMU_MEASURE class provides an API for measuring specific pins with per-pin PMUs. You can define the measurement modes for the per-pin PMUs, execute the measurements in parallel, and retrieve the pins' test results.

MTP_PPMU_MEASURE provides the similar functionality to the [PPMU_MEASURE](<../02.07_Test_Method_Reference/02.07.04.01.157_PPMU_MEASURE.md>) API. But PPMU_MEASURE cannot be used for driver sharing test since the multiple executions will overwrite the previous results.

Note MTP_PPMU_MEASURE is available only for MTP.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/MTP_PPMU_MEASURE.h.
