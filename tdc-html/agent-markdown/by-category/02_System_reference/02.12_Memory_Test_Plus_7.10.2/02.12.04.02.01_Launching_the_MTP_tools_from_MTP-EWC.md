# Launching the MTP tools from MTP-EWC

You can quickly lauch the MTP tools from the menu bar or toolbar of SmarTest.

## About this task

You can launch the following tools from the MTP-EWC:

- [Bit Fail Map Viewer](<02.12.04.04_Bit_Fail_Map_Viewer.md>)
- [Memory Test Viewer](<02.12.02.07.02_Memory_Test_Viewer.md>)
- [MTP build configuration](<02.12.02.05.12.02_The_MTP_build_configuration_pages.md>)

## Before you begin

[Open the MTP perspective](<02.12.04.02_MTP-EWC.md>).

-  To launch a tool from the toolbar  ![Accessing MTP build configuration from toolbar](<../../../../raw/140956.png>)

## Results

The selected tool opens.
