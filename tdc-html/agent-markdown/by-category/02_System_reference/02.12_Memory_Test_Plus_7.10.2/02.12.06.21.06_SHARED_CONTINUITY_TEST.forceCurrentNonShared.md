# SHARED_CONTINUITY_TEST.forceCurrentNonShared()

The forceCurrentNonShared() member function of [SHARED_CONTINUITY_TEST](<02.12.06.21_SHARED_CONTINUITY_TEST.md>) lets you specify the current to be forced into the non-shared pins.

## Syntax

```
SHARED_CONTINUITY_TEST& forceCurrentNonShared(double current)
```

 |

Parameter

 |

Description

 |
 |

current

 |

The current to be forced into the non-shared pins.

- The unit is A.
- The default current value is 1 A.

 |

## Example

```
SHARED_CONTINUITY_TEST mTest;
mTest.forceCurrentNonShared(100 uA);
mTest.forceCurrentNonShared(0.0001);
```
