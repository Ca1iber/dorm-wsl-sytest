# Controlling power supply and measurements

#### Subtopics

- [Setting up a DC event](<02.12.03.04.13.01_Setting_up_a_DC_event.md>)
- [Setting up DC event sequences](<02.12.03.04.13.02_Setting_up_DC_event_sequences.md>)

Power supply and voltage and current measurements on both DC Scale cards and per-pin PMUs can be controlled from with compiled patterns. This is done through so-called DC events. The type of these events - DCScale or pmu - determines which kind of power supply is controlled as well as the syntax of the event detail descriptions.

There are two functions for controlling power and measurements:

- DC_EVENT lets you set the power or initiate a measurement by calling a so-called DC event defined in the [DC event file](<02.12.03.03.08_DC_event_file.md>). Configuring this is described in [Setting up a DC event](<02.12.03.04.13.01_Setting_up_a_DC_event.md>).
- DC_EVENT_RANGE lets you execute predefined periodic sequences of DC events alongside the standard program code, for example to test the DUT's behavior in case of voltage fluctuations. Configuring this is described in [Setting up DC event sequences](<02.12.03.04.13.02_Setting_up_DC_event_sequences.md>).

Both functions can be employed in the [APG program file](<02.12.03.03.03_APG_program_file.md>). They are discussed in [Macros and functions in program files](<02.12.03.03.03.01.08_Macros_and_functions_in_program_files.md>).

There are some differences between DCScale type events which are executed on DC Scale cards and pmu type events which are executed on the PMUs of standard test head cards. These differences are described in [Differences between DCScale type and PMU type events](<02.12.03.04.13.01.02_Differences_between_DCScale_type_and_PMU_type_events.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
- MTP 2.4.0: Sequences of DC events introduced
- MTP 3.0.1: DC events now support also PMUs
