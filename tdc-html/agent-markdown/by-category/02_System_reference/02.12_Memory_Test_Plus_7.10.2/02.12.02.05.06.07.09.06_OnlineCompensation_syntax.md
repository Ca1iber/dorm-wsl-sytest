# OnlineCompensation syntax

This topic explains the parameters of the OnlineCompensation test method.

To edit the parameters of the OnlineCompensation test method, click it in the tabular test editor. The parameters are displayed in the Test Suite window and you can edit them there.

Online delay compensation parameters
 |

Parameter

 |

Type

 |

Default

 |

Comment

 |
 |

Fxdl_File

 |

STRING

 |

 |

The name of the currently used fixture delay file.

 |
 |

DriverSharing_Config_File

 |

STRING

 |

 |

The driver sharing configuration file name. The same file is used as input for the fd_merge tool.

 |
 |

Comp_Value

 |

DOUBLE

 |

 |

Unit is ns. Additional delay due to loading effect. The loading effect is always a positive number. The delay will only be added for enabled sites.

 |
 |

Comp_Fxdl_File

 |

STRING

 |

NO

 |

If Fxdl File is already compensated for all sites loaded: YES, otherwise NO.

If YES, fixture delay is restored to value before compensation for all sites loaded with "golden" devices. Then the delay specified for "comp_value" is added for all enabled sites.

 |
