# SHARING_CONFIGURATION.getModeContext()

The getModeContext() member function of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) lets you retrieve the mode context in the loaded sharing configuration.

## Syntax

```
const string & getModeContext() const
```
