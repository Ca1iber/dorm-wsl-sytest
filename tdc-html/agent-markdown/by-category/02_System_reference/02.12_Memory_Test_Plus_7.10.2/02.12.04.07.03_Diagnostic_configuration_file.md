# Diagnostic configuration file

The diagnostic configuration file is specific to the DPS Sharing Diagnostic tool. It enables the tool to set the relays as required for the individual tests.

There are two sections in the diagnostic configuration file, pin_mapping and utility_control.

- pin_mapping: The pin names for TDQSN and VDDQ defined in the pin configuration file must be defined here again.

```
pin_mapping:
PIN_TDQSN=pin_name_for_tdqsn
PIN_VDDQ=pin_name_for_vddq
```

If one of these mappings is omitted, all the diagnostic steps using the missing pin cannot be selected.

- utility_control: This section is used to set the relays for the DPS sharing diagnostic steps.

The available keywords are listed below. The same syntactic options as for other utility control statements in the [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>) apply, that is, you can specify names, equations and utility settings. Pin substitution is not required in the diagnostic configuration file.

## Syntax

 |

Keyword

 |

Description

 |
 |

diag_accterm_close

 |

The utility line settings to close the vterm relays.

 |
 |

diag_accterm_open

 |

The utility line settings to open the vterm relays.

 |
 |

diag_ocp_block_a

 |

The utility line settings to block VDD channel for overcurrent protection.

 |
 |

diag_splyrly_block_a

 |

The utility line settings to block the VDD supply channel. The VDDQ test channel supplies both the VDD and VDDQ DUT pins.

 |
 |

diag_splyrly_block_b

 |

The utility line settings to block the VDDQ supply channel. The VDD test channel supplies both the VDD and VDDQ DUT pins.

 |
 |

diag_splyrly_nrml

 |

The utility line settings to set the VDD/VDDQ relays to their normal state (that is, with VDD routed to VDD and VDDQ to VDDQ).

 |
 |

diag_splyrly_swp

 |

The utility line settings to set the VDD/VDDQ relays to swap supply channels (that is, route VDDQ to VDD and VDD to VDDQ).

 |
 |

diag_tdqsn

 |

The utility line settings to close the TDQS# relay to a specific DUT in one donmain. Use equations to specify the setting for different DUTs:

- DUT1: x=0, y=0
- DUT2: x=1, y=0
- DUT3: x=2, y=0
- DUT4: x=3, y=0
- DUT5: x=0, y=1
- DUT6: x=1, y=1
- DUT7: x=2, y=1
- DUT8: x=3, y=1

For example, the setting to connect DUT2 begins with

`diag_tdqsn ; (x==1 && y==0) ;`

 |
 |

diag_tdqsn_open

 |

The utility line settings to open all the TDQS# relays

 |

Note that if the diagnostic steps cannot be selected due to an incomplete diagnostic configuration file, this will be reported in the Diagnostic Steps Message box.

## Example

```
####################################################################
#
# Example for a Diagnostic Configuration File
#
####################################################################

# Mapping of pin names
pin_mapping:
PIN_TDQSN=TDQS
PIN_VDDQ=VDDQ

# Definitions of utility settings
utility_control:
#Vterm relay diagnostics
diag_actterm_close;();(U2=0x000&0x001)
diag_actterm_open;();(U2=0x001&0x001)
#VDD/VDDQ relay diagnostics
diag_splyrly_nrml;();(U3=0x000&0xfff)
diag_splyrly_swp;();(U3=0xfff&0xfff)
diag_splyrly_block_a;();(U3=0x333&0xfff)
diag_splyrly_block_b;();(U3=0xccc&0xfff)
#Overcurrent protection diagnostics
diag_ocp_block_a;();(U3=0x303&0xfff)
#TDQS# relay diagnostics
diag_tdqsn_open;();(U2=0x0&0x1FE)
diag_tdqsn;(x==0 && y==0);(U2=0x2&0x1FE)
diag_tdqsn;(x==1 && y==0);(U2=0x4&0x1FE)
diag_tdqsn;(x==2 && y==0);(U2=0x8&0x1FE)
diag_tdqsn;(x==3 && y==0);(U2=0x10&0x1FE)
diag_tdqsn;(x==4 && y==0);(U2=0x20&0x1FE)
diag_tdqsn;(x==5 && y==0);(U2=0x40&0x1FE)
diag_tdqsn;(x==6 && y==0);(U2=0x80&0x1FE)
diag_tdqsn;(x==7 && y==0);(U2=0x100&0x1FE)
```
