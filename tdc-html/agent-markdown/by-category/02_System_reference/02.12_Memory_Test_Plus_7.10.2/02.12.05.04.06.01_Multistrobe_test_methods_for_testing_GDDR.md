The multistrobe test methods are intended to be used by development engineering for device characterization.

 Note The measured data is shown in the report window. To also direct the measured values into the data log you need to set various flags.

To get measured data from the test runs to enable you to analyze the results, you can log the output as explained in [Logging TM output](<02.12.02.05.06.06.01_Logging_output.md>).
