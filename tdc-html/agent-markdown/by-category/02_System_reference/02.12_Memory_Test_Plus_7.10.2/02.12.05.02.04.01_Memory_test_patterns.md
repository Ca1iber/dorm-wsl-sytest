# Memory test patterns

The [demo test flow](<02.12.05.01.02_About_this_Guide.md>) shown in the figure below contains the following memory test pattern types all implementing functional tests and different shmoos:

  ![Memory test pattern sequence in GDDR3 demo testflow](<../../../../raw/84317.png>)

- MTL Gapless memory test pattern to write and read all banks in sequence implemented with ODT off, ODT 60, ODT 120.
- MTL XM6N memory test pattern for x march algorithm on all banks in sequence implemented with ODT off.
- MTL Interleaved memory test pattern to write and read interleaved to all banks implemented with ODT off.

All above memory test patterns implement:

- Functional tests
- RDQS frequency shmoo
- DQ data to frequency shmoo
- Single DQ data to frequency shmoo
- DQ power to frequency shmoo
