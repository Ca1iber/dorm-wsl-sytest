# Non data related signals level configuration

The level configuration for non data related signals is a straight forward level configuration. Level configuration with the SmarTest software independent of the memory device is described in [Setting the Levels](<../02.08_Setup_and_Result_Tools/02.08.04.14_Level_setup_tool.md>).

The offset value is equal to half of the input swing value on the memory device (see following figure).

  ![Relationship between configurable offset value and input swing value on memory device](<../../../../raw/81369.png>)

In addition to the general level configuration you need to specify Spec variables to define the offset value for each signal group that need to be added to the Vref value as specified in the data sheet of the memory device (see following figure).

  ![Level setup for non-data related signals](<../../../../raw/81166.png>)
