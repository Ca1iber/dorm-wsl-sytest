# SOURCESYNC_TEST.domain()

Specifies application domains for source-sync tests.

- If the specified domain exists, this function references to that domain.
- If the specified domain does not exist, this function creates a new domain with the specified domain name.

## Syntax

```
SOURCESYNC_DOMAIN& domain (const string& domainName);
```

Parameter
 |

Parameter

 |

Description

 |
 |

domainName

 |

The name of a domain.

 |

## Return value

Returns an [SOURCESYNC_DOMAIN](<02.12.06.26_SOURCESYNC_DOMAIN.md>) object.

[SOURCESYNC_DOMAIN](<02.12.06.26_SOURCESYNC_DOMAIN.md>)
