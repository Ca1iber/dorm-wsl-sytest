# Test methods enhancements

MTP 3.2.2 adds a new parameter, "bitmap_file_path", to the ExecutionEngine test method.

This new parameter not only allows you to specify a specific name to the generated BFD file but also can display information like wafer, port, site, and etc. with the file name.
