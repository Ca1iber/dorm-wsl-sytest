# Bit Fail Map Viewer

Some new features are implemented in the [Bit Fail Map Viewer](<02.12.04.04_Bit_Fail_Map_Viewer.md>):

- Start the viewer using the graphical interface "Memory Test Manager" instead of command line input (see [Starting the BFM Viewer](<02.12.04.04.02.01_Starting_the_BFM_Viewer.md>)).
- Additional column in file list shows all layers a file is already assigned to (see [Bit Fail Maps](<02.12.04.04.03.02.01.01_Bit_Fail_Maps.md>)).
- Online and context help is available.
- shortcut menu in layer assignment helps to locate files in file list (see [Bit Fail Maps](<02.12.04.04.03.02.01.01_Bit_Fail_Maps.md>)).
