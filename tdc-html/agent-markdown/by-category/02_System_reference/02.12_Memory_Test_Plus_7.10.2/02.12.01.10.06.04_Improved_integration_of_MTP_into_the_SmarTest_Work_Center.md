# Improved integration of MTP into the SmarTest Work Center

The enhancements for building and running MTP files via SmarTest Work Center are:

- An MTP Build console view was added for displaying the MTP prebuilding information, and the information on the compilation of pattern files.
- The configurations for MTL compiler, once set up, will remain in effect until you chang them.
- [Three options in the MTL compiler dialog have been updated](<02.12.02.05.12.02.01.01_MTL_compiler_options.md>):

  - The options for disabling padding have been consolidated into one shortcut menu.
  - The compression options are now set in a shortcut menu instead of a slider.

- Some MTP-related options in the Run Configurations dialog have been renamed.
