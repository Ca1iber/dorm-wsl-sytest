# SHARED_IDD_TEST.init()

The init() member function of [SHARED_IDD_TEST](<02.12.06.22_SHARED_IDD_TEST.md>) lets you do initializations for a test.

You must invoke this member function ahead of any other functions when you create a test method with the SHARED_IDD_TEST API.

## Syntax

```
SHARED_IDD_TEST& init()
```

[SHARED_IDD_TEST](<02.12.06.22_SHARED_IDD_TEST.md>)
