# CTransitionAlign

This class provides functions for identifying the mean locations of transitions by performing an error count scan over the possible transition area and evaluating the error counts obtained.

It can execute searches in parallel.

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/training/include/TransitionAlign.h.

## Class definition

### Constructor

```
CTransitionAlign(TrainingType trainingType,
                 const string &trainingAlgorithm,
                 const string &edgeCentering)
```

Parameters
 |

trainingType

 |

The kind of training to be performed.

For possible values, see the TrainingType definition in the [CSearchTask](<02.12.06.31.02_CSearchTask.md>) class.

 |
 |

trainingAlgorithm

 |

The training method to be used:

- Full training searches for both edges of the data eye and calculates the center of the eye from these edges. Any values specified in the PinOffsets parameter are added to the position of the first edge to find the starting value for searching for the second edge.
- Fast training searches only for the first edge of an eye. The center of the eye is calculated by adding the PinOffsets value to the position of this edge.

We recommend that you use the constants defined in the [CSearchTask](<02.12.06.31.02_CSearchTask.md>) class.

 |
 |

edgeCentering

 |

Yes (Spec), Yes (Pin attr), or No. Whether and how to use the edge center timing value for further measurements:

- Yes (Spec): Centering by setting spec values is performed.
- Yes (Pin attr): Centering by setting pin attributes is performed.
- Yes (Embedded): Centering is performed in the test head card. The method used is similar to the one the SmarTest [EyeFinder](<02.12.02.05.06.04_EyeFinder.md>) uses.
- No: No further centering is performed.

If this parameter is set to Yes (Pin attr), the unit for the sweep spec variables must be nanoseconds.

Default value: No

We recommend that you use the constants defined for the various settings (see the Constants section in Class definition in [CSearchTask](<02.12.06.31.02_CSearchTask.md>)) for specifying this value.

 |
