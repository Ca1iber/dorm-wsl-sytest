# SOURCESYNC_SUB_TEST.domain()

Retrieves an [SOURCESYNC_TEST_DOMAIN](<02.12.06.30_SOURCESYNC_TEST_DOMAIN.md>) object in order to get the margin values of the source-sync test in the specified domain.

## Syntax

```
SOURCESYNC_TEST_DOMAIN& domain (const string& domainName);
```

Parameter
 |

Parameter

 |

Description

 |
 |

domainName

 |

The name of a [created domain](<02.12.06.29.02_SOURCESYNC_TEST.domain.md>).

If the domain does not exist, warning message will be issued.

 |

## Return value

Returns an object of the [SOURCESYNC_TEST_DOMAIN](<02.12.06.30_SOURCESYNC_TEST_DOMAIN.md>) class.
