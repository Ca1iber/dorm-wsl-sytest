# Accessing elements of an MTL array

The elements of an MTL array are accessed individually by array index which is made up of the array's name, and a series of indexes - one for each dimension of the array - to identify the element's location within the array.

## About this task

The syntax of the array index is ArrayName[index_1]...[index_N].

You can access different array elements through changing indexes values.

## Before you begin

[Define the MTL arrays](<02.12.03.03.03.01.09.01.01_Defining_MTL_arrays.md>).

## Procedures

### To access an element of an MTL Array

Use the array index syntax: ArrayName[index_1]...[index_N] to access.

The number of indexes depends on the array dimensions. One dimension requires one index value.

- Specify the array name.
- Specify each index value for the array dimensions.

  - The index value ranges from 0 to the corresponding dimension size - 1.

If any index value exceeds its array dimension, error messages will be generated when compiling.

  - Each index can be a constant, a variable, or an expression.

Variables and expressions can be used for looping purposes.

### To access a single bit of an MTL Array element

Put the element access in parenthesis followed by an [Index operator](<02.12.03.03.03.01.01.02_Index_operator.md>).

Note If the array access is not put in parenthesis, error messages will be generated when compiling.

The syntax is: (ArrayName[index_1]...[index_N])[index operator].

Note that:

- The index operator is used to access an individual bit of a result datum. See [Index operator](<02.12.03.03.03.01.01.02_Index_operator.md>) and [Select operator](<02.12.03.03.03.01.01.03_Select_operator.md>) for more information.
- The array index is used to access an element of an MTL array which is an integer.

## Example

```
main()
{
    dwSequence [8] = {dw3, dw1, dw2, dw0, dw4, dw5, dw6, dw7};
    arrayIndex1 = 0;
    arrayIndex2 = 3;

    dwMapped1 = dwSequence [arrayIndex1];        //dwMaaped1 will get dw3
    dwMapped2 = dwSequence [arrayIndex2];        //dwMaaped1 will get dw0

    bit1 = (dwSequence [0]) [0];            //bit1 will get the least bit of dw3
    bit2 = (dwSequence [3]) [0];            //bit2 will get the least bit of dw0
}
```
