# MTP_CONTINUITY_TASK.getValue()

The getValue() member function of [MTP_CONTINUITY_TASK](<02.12.06.10_MTP_CONTINUITY_TASK.md>) lets you retrieve the measured voltage in volts for a specific pin.

## Syntax

```
double getValue(const string & pin)const
```

 |

Parameter

 |

Description

 |
 |

pin

 |

The name of a pin whose measured voltage you want to retrieve.

The unit for the retrieved voltage is volt.

 |
