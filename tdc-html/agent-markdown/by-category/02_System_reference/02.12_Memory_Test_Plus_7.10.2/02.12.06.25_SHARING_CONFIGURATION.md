The SHARING_CONFIGURATION class provides an API for accessing the data contained in the [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>).

 Note The SHARING_CONFIGURATION API is available only for MTP.

This API is defined in the header file /opt/93000mts/mts/solution_tools/import/SHARING_CONFIGURATION.h.
