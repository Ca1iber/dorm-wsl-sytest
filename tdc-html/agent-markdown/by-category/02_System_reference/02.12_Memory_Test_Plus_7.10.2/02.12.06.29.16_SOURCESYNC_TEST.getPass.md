# SOURCESYNC_TEST.getPass()

Retrieves the pass/fail status of the test.

## Syntax

```
bool getPass( );
```

## Return value

Returns true or false to represent the pass and fail status.

## Functional changes

- Introduced in MTP 3.2.2
