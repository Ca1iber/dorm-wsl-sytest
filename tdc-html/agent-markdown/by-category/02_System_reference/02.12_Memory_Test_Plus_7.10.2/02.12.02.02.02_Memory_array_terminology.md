# Memory array terminology

When speaking of the memory array, several terms are used to describe the way data is laid out or presented. The table below lists these terms and their descriptions.

Memory array terminology
 |

Term

 |

Description

 |
 |

bit

 |

Represents each cell in a memory array, and can have a logical value of 1 or 0.

 |
 |

word

 |

The contents of a memory address. The V93000 test system can define data words up to 512 bits in word width.

 |
 |

device address

 |

The address applied to the external pins of the memory device (one dimensional).

 |
 |

logical address

 |

The address applied to the inputs of the X- and Y-decoders and the bank decoder (three dimensional x,y,z). The device address after the first level of address scrambling at the input of the decoders.

 |
 |

physical address

 |

The physical address is the address of a cell in the memory core. This address appears at the output of the address decoders (three dimensional x,y,z).

 |
 |

topological address

 |

The graphical location of a memory cell within the memory core (two dimensional x,y). The graphical origin must be defined.

   |
