# Bit Fail Map viewer

The Bit Fail Map Viewer (often called BFM Viewer for short) is a tool that topologically shows the errors occurring during the test of a memory device. It is described in [Bit Fail Map Viewer](<02.12.04.04_Bit_Fail_Map_Viewer.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
