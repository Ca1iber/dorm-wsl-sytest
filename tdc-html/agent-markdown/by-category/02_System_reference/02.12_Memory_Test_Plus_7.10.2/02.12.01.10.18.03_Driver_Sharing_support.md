# Driver Sharing support

Sharing drivers between several devices leads to significant reduction of CoT, because less channels needed for testing multiple devices in parallel. Or you can test more devices using the same resources than without driver sharing.

To support driver sharing Advantest supplies

- a shared library with test methods
- programs and procedures to calibrate fixtures with shared driver test sites.

For more information refer to [Driver Sharing](<02.12.02.05.06.07.01_Driver_sharing_concepts.md>) in [Testing High-Speed Memory Devices](<02.12.02_Testing_High-Speed_Memory_Devices.md>).
