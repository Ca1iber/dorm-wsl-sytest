# MTP_MEMORY_PORT.getPassFailResult()

Retrieves the overall pass/fail test result of a specific port.

The port is specified with [getMemoryPort()](<02.12.06.17.08_MTP_MEMORY_TEST.getMemoryPort.md>).

## Syntax

```
bool getPassFailResult ();
```

List of parameters

There are no parameters.

## Return value

Returns true or false.

## Related information

[MTP_MEMORY_TEST.getMemoryPort()](<02.12.06.17.08_MTP_MEMORY_TEST.getMemoryPort.md>)

## Functional changes

- Introduced in MTP 3.2.1
