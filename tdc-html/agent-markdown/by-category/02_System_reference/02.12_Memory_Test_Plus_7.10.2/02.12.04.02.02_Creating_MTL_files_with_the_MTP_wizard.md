# Creating MTL files with the MTP wizard

#### Subtopics

- [The APG Pin Mapping Generation wizard](<02.12.04.02.02.01_The_APG_Pin_Mapping_Generation_wizard.md>)

By using MTP wizard, creating [MTL setup files](<02.12.03.03.01_Overview_of_configuration_files.md>) will be easy. All [MTL setup files](<02.12.03.03.01_Overview_of_configuration_files.md>) (an MTP .apg file and its related MTL setup files) will be automatically created with compilable coding templates .

## About this task

A fast way to create MTP .apg files and the setup files.

## Before you begin

[Open the MTP perspective](<02.12.04.02_MTP-EWC.md>).

## Procedure

-  Open the MTP wizard as the picture demonstrates:  ![Opening MTL wizard](<../../../../raw/144231.png>)

Alternatively, you can right-click the desired MTP device in the Project Explorer, and select New > MTP Wizard.

-  From the opened window, in the File name and Container fields enter the name and file path for the .apg file you want to create.

The name must contain the .apg suffix. Otherwise, you will get an error message.

-  Click on Next.

The New APG Set window opens:

  ![New MTL Set window](<../../../../raw/144232.png>)
-  In this window:

  - Enter names for different MTL setup files.

To change directories or select an existing file, use the Browse button.

  - If you want to create a DC event file, check Enable Optional Set and enter the file name in the DC Test field. To change the directory or select an existing file, use the Browse button.Note You must enter file names with suffixes, such as .prog, .dvac, .dvar, and .pmap. Otherwise, you will get error messages.

-  If clicking on Finish, all those files will be created with standard compilable coding templates in each. However, the generated pin mapping file does not reference the SmarTest pin configuration file.
-  If clicking on Next, a new wizard, APG Pin Mapping Generation, opens, which can map pins in a SmarTest pin configuration file to the pin mapping file.

Note that this wizard does not create any pin mapping if you selected an existing pin mapping file in step 4. In this case, the content in the existing pin mapping file will not be changed and a warning message will be shown on the wizard.

  ![APG Mapping Generation Wizard](<../../../../raw/147940.png>)
-  From this wizard, add pins from the pin configuration file (the left table) to the pin mapping file (the right table), and then click Finish. (More details about the wizard are described in [The APG Pin Mapping Generation wizard](<02.12.04.02.02.01_The_APG_Pin_Mapping_Generation_wizard.md>).)

## Results

An .apg file and its related MTL setup files are created in the desired directories with compilabe coding templates in each file. If the step 6 and 7 described in the Procedure section above have been performed, the generated pin mapping file contained pins mapped from a SmarTest pin configuration file.

Opening the .apg file from the MTP editor will also open its all related MTL setup files in the editor as the following picture shows.

 ![MTP files set](<../../../../raw/144194.png>)
