# MTL Program File Simplification

The keywords

- :version:
- :apgAccess:
- :format:
- :name:
- :interface:
- :deviceParam:
- :programParam:
- :code:

are not needed anymore in the program file (*.prog).

For more informationrefer to [APG program file](<02.12.03.03.03_APG_program_file.md>) in [Memory Test Language (MTL) Programming Reference](<02.12.03_Memory_Test_Language__MTL__Programming_Reference.md>).
