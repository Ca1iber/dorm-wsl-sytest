# SOURCESYNC_SUB_TEST.sweepSpecVar()

Specifies sweeping spec variables sweeping from [sweepStart()](<02.12.06.28.10_SOURCESYNC_SUB_TEST.sweepStart.md>) to [sweepStop()](<02.12.06.28.08_SOURCESYNC_SUB_TEST.sweepStop.md>) for every [edge](<02.12.06.28.01_SOURCESYNC_SUB_TEST.edgeList.md>).

## Syntax

```
SOURCESYNC_SUB_TEST& sweepSpecVar (const string& sweepSpecVar);
```

Parameter
 |

Parameter

 |

Description

 |
 |

sweepSpecVar

 |

The name of the sweeping spec variable. You can specify multiple variables separated with ";".

It supports multiport. For example, "sweep_a@port_a".

 |
