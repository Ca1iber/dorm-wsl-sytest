# SHARED_LEAKAGE_PARALLEL_TEST.pinNonShared()

The pinNonShared() member function of [SHARED_LEAKAGE_PARALLEL_TEST](<02.12.06.23_SHARED_LEAKAGE_PARALLEL_TEST.md>) lets you specify the non-shared pins, pin groups that are to be measured.

## Syntax

```
SHARED_LEAKAGE_PARALLEL_TEST& pinNonShared(const string& pinlist)
```

 |

Parameter

 |

Description

 |
 |

pinlist

 |

The list of the non-shared pins, pin groups that are to be measured.

Separate entries with commas.

 |

## Example

```
SHARED_LEAKAGE_PARALLEL_TEST mTEST;
mTEST.pinNonShared("DQ_Bus");
mTEST.pinNonShared("DQ_Bus,DM");
```
