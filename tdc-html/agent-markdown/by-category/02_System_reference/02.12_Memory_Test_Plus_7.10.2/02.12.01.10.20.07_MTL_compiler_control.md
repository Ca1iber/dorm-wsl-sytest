# MTL compiler control

When the MTL compiler is started from the Memory Test Manager window you can control the compiler options via a dialog window. This window has been improved to allow specifying the options faster and easier than in the previous version. The new functions and options are described in [Memory Test Language (MTL) Programming Reference](<02.12.03_Memory_Test_Language__MTL__Programming_Reference.md>).

- The memory test manager window provides an execution button now which lets you enter the execution dialog directly ([Execution Dialog window](<02.12.03.02.04.01.02_Execution_Dialog_window.md>)).
- The execution dialog allows you to specify whether to execute functional test or to generate a bitmap via testflow.
- The MTL compiler output window's content has been improved for readability as well as functionality by providing a re-execution button.

For more information refer to [Compiler control dialog](<02.12.03.02.04.01_MTL_Compiler_Control_dialog.md>) in [Memory Test Language (MTL) Programming Reference](<02.12.03_Memory_Test_Language__MTL__Programming_Reference.md>).
