# Logging memory tests

#### Subtopics

- [Logging formats and data types](<02.12.02.06.01_Logging_formats_and_data_types.md>)
- [Configuring data logging for memory tests](<02.12.02.06.02_Configuring_data_logging_for_memory_tests.md>)
- [Memory test data log event structure](<02.12.02.06.03_Memory_test_data_log_event_structure.md>)

Memory test can be logged in a similar way to other tests using the event data log.

No special setup is required (beyond setting up logging in general), and the general settings regarding the level of logging detail also apply to the logged memory test events.

## Functional changes

- SmarTest 7.0.4: Logging memory test evens is available only in MTP on HSM.
- MTP 3.1.4: Logging memory tests events is available both in MTP on HSM and MTP on SOC.
