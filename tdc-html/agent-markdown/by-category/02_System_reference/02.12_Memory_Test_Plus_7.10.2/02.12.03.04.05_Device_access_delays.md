# Device access delays

The execution of device accesses can be dynamically delayed, either for the entire access or for a range of instruction within an access.

## Delaying an entire device access

To delay an entire device access, use the `delay()` member function. For example:

```
myAccess.delay(3) // Delays the entire access by three edges
```

This delays the execution of the device access by the specified number of edges, in this case by three edges.

Instead of a fixed number, an expression can also be provided as the argument of `delay()`. For example:

```
myAccess.delay(myLatency)
```

## Delaying part of a device access

To delay just a range of operations within an access, use the delay() ... delayend instruction described in [Control instructions in device accesses](<02.12.03.03.04.03_Control_instructions_in_device_accesses.md>).

This instructions delays the operations enclosed between delay and delayend by the number of edges that have been provided as an argument to delay().

It is possible to insert multiple `delay ... delayend` blocks in a single device access. If you do so, note that an earlier delay block must not be delayed so much that it is executed after a later delay block. (See [Control instructions in device accesses](<02.12.03.03.04.03_Control_instructions_in_device_accesses.md>) for an example.)

## Examples

### Delaying an entire access

```
Read(bank, row, col, ...)
{
  CMD(REDC); ADDR_Y(bank1, row); DQ_BurstRead().delay(2);  // delay by 2 tCK
  CMD(DESL); ADDR_IDLE();
  CMD(DESL); ADDR_IDLE();
  CMD(DESL); ADDR_IDLE();
}
```

### Delaying part of a device access

```
...
:interface: { myDelay }
:table:
{ :instruction:  :pin:  :states:  :data:  :operation:             }
{ ~              DQi_0  {0 1}     0       dbi(gddr5_DBI)          }
{ ~              DQi_1  {0 1}     1       dbi(gddr5_DBI)          }
{ ~              DQi_2  {0 1}     0       dbi(gddr5_DBI)          }
{ ~              DQi_3  {0 1}     1       dbi(gddr5_DBI)          }
{ ~              DQi_4  {0 1}     0       dbi(gddr5_DBI)          }
{ ~              DQi_5  {0 1}     1       dbi(gddr5_DBI)          }
{ ~              DQi_6  {0 1}     0       dbi(gddr5_DBI)          }
{ ~              DQi_7  {0 1}     1       dbi(gddr5_DBI)          }
{ ~              DBI.0  {0 1}     0       dbi(gddr5_DBI)          }
{ delay(myDelay) EDC.0  {L H}     0       crc(gddr5_crc_write,0)  }
{ ~              ~      {L H}     0       crc(gddr5_crc_write,1)  }
{ ~              ~      {L H}     0       crc(gddr5_crc_write,2)  }
{ ~              ~      {L H}     0       crc(gddr5_crc_write,3)  }
{ ~              ~      {L H}     0       crc(gddr5_crc_write,4)  }
{ ~              ~      {L H}     0       crc(gddr5_crc_write,5)  }
{ ~              ~      {L H}     0       crc(gddr5_crc_write,6)  }
{ ~              ~      {L H}     0       crc(gddr5_crc_write,7)  }
{ delayend       ~      ~         ~       ~                       }
```
