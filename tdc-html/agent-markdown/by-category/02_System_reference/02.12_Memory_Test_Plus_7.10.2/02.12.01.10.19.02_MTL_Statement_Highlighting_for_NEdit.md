# MTL Statement Highlighting for NEdit

The NEdit editor is the preferred editing tool for MTL programs and other associated files used to create a memory test pattern. Usability for program editing is increased if context sensitive highlighting is supported.

You can enhance the editing with NEdit if you amend it's preferences with MTL highlighting support.

## More Info

For further details, see Enabling NEdit syntax highlighting.
