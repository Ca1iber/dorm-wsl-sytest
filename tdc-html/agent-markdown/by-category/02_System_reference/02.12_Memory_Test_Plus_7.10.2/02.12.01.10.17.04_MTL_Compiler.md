# MTL Compiler

The following list shows updates and enhancements in the MTL Compiler (see [Memory Test Language (MTL) Programming Reference](<02.12.03_Memory_Test_Language__MTL__Programming_Reference.md>)).

- Syntax simplification: any values, names and expressions can be written without quotes if they do not contain white spaces.

For more informationrefer to General MTL syntax conventions.

- Transparent X-Mode: there is no need to have the same number of edges/events per pin as the defined X-Mode requires.

For more informationrefer to Transparent X-Mode.

- If transparent X-Mode access definitions are used the memory pattern could require padding at the end of a pattern if it does not match a complete tester cycle.

For more informationrefer to [Padding Control](<02.12.03.04.02.02_Setting_up_padding.md>).

- If transparent X-Mode access definitions are used there are consequences for refresh statements.

For more informationrefer to Transparent X-Mode and Refresh.
