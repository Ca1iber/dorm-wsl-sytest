# Summary of test system architectures

This section has reviewed three different architectures, the two historical architectures and the V93000 test system architecture. All three architectures are able to execute patterns that perform a memory test with the vector-based architecture, having the most limitations due to its finite vector memory size. The hardware APG implementation and the V93000 test system processor implementation are both capable of executing tests that use memory test patterns.
