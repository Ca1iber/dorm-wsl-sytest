# MTP_MEMORY_TEST.addAddressFilter()

The addAddressFilter() member function of [MTP_MEMORY_TEST](<02.12.06.17_MTP_MEMORY_TEST.md>) adds a defined address filter to select certain addresses to generate or not to generate memory test results, such as fail bit map, fail bit count, and fail addresses list.

The address filter is defined either by the [MTP_ADDRESS_FILTER](<02.12.06.09_MTP_ADDRESS_FILTER.md>) class or the [MTP_MULTI_FILTER](<02.12.06.18_MTP_MULTI_FILTER.md>) class.

## Syntax

Two syntaxes are available for adding a filter with single address range, and a filter with multiple address ranges:

- MTP_MEMORY_TEST& addAddressFilter([MTP_ADDRESS_FILTER](<02.12.06.09_MTP_ADDRESS_FILTER.md>) filter`)`
- MTP_MEMORY_TEST& addAddressFilter([MTP_MULTI_FILTER](<02.12.06.18_MTP_MULTI_FILTER.md>) filter`)`

 |

Parameter

 |

Description

 |
 |

filter

 |

The name of the filter which you want to use.

 |

## Example

Take the test results of data bit 0 from the X-address 0 to 63, and the test results of data bit 1 from the X-address 512 to 1024 into the bit map file. Other data bits are ignored for the bit map file.

```
void MemoryTest::run()
{
   //Define filters
   MTP_ADDRESS_FILTER filter1,filter2;
   filter1.setRange(MTP::X_ADDRESS,0,63).setDbits("0", MTP::INCLUDE);
   filter2.setRange(MTP::X_ADDRESS,512,1024).setDbits("1", MTP::INCLUDE);
   //Add filters
   MTP_MEMORY_TEST memoryTest;
   memoryTest.enableAddressBasedResults(true).setImmediateBitmapToFile(true);
   memoryTest.addAddressFilter(filter1).addAddressFilter(filter2);

   //Execution is called only for first site
   ON_FIRST_INVOCATION_BEGIN();
   {
     CONNECT();
     memoryTest.execute();
   }
   ON_FIRST_INVOCATION_END();

   //Test API is used for judging and logging Memory Test results.
   TEST(memoryTest);
}
```
