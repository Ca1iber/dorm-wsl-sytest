# Using RaServer for offline analysis

The RaServer is performing the redundancy analysis. You only can use it for offline analysis.

## About this task

Perform this task whenever you want to start RaServer for offline analysis.

## Before you begin

Make sure that the redundancy analysis is properly set up, as described in [Setting up and performing a redundancy analysis](<02.12.02.07.03.01_Setting_up_and_performing_a_redundancy_analysis.md>).

Make sure that SmarTest is running.

## Procedure

 Enter this command in a terminal window:

RaServer -o <ra_config_file>

Where <ra_config_file> is the [Redundancy analysis configuration file](<02.12.02.07.03.01.03.01_Redundancy_analysis_configuration_file.md>).

## Results

The RaServer performs the redundancy analysis as specified in the configuration file.
