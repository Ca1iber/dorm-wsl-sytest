# MTP_FUNC_TASK.pin()

The pin() member function of [MTP_FUNC_TASK](<02.12.06.12_MTP_FUNC_TASK.md>) lets you specify the pins whose functional test results you want to retrieve.

## Syntax

```
void pin(const string & pinname)
```

 |

Parameter

 |

Description

 |
 |

pinname

 |

The names of the result pins. Multiple pins are separated by commas.

 |
