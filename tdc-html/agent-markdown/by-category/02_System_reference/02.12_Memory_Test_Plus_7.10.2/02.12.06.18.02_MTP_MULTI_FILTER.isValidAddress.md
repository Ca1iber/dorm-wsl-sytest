# MTP_MULTI_FILTER.isValidAddress()

This member function checks whether an address is in the filter range or not, and returns the result.

Each filter range is defined by [MTP_ADDRESS_FILTER.setRange()](<02.12.06.09.01_MTP_ADDRESS_FILTER.setRange.md>).

## Syntax

```
bool isValidAddress(ADDRESS address);
```

Parameter
 |

Parameter

 |

Description

 |
 |

address

 |

The address which you want to check whether it is in the filter range or not.

 |

## Return value

true: If the address is in the filter range.

false: If the address is not in the filter range.

## Example

```
MTP_ADDRESS_FILTER filter1,filter2;
MTP_MULTI_FILTER multi_filter;

filter1.setRange(MTP::X_ADDRESS,0,1024).setRange(MTP::Y_ADDRESS,0,1024);
filter2.setRange(MTP::X_ADDRESS,1024,2048).setRange(MTP::Y_ADDRESS,0,1024).setMode(MTP::EXCLUDE);
multi_filter.addAddressFilter(filter1).addAddressFilter(filter2);

ADDRESS addr;
addr.x = 0;
addr.y = 0;
addr.z = 0;
addr.d = 0;   //addr.d is used for data bits address.

//The address (x = 0, y = 0, z= 0) is in the range of filter1, so this address will be output.

if (true == multi_filter.isValidAddress(addr))
{
   cout << addr << " Valid" << endl;
}
```
