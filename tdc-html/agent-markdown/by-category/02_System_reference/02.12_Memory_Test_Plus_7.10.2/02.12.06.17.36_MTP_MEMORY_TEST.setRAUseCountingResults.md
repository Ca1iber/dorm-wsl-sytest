# MTP_MEMORY_TEST.setRAUseCountingResults()

Determines whether the redundancy analysis algorithm will use the counting results calculated from [setRACounting()](<02.12.06.17.30_MTP_MEMORY_TEST.setRACounting.md>).

The redundancy analysis algorithm is specified in a [Redundancy analysis configuration file](<02.12.02.07.03.01.03.01_Redundancy_analysis_configuration_file.md>).

Therefore, to use this function, you must select an RA configuration file with [setRAConfigFile()](<02.12.06.17.29_MTP_MEMORY_TEST.setRAConfigFile.md>) and enable the RA algorithm with [setRAAlgorithm()](<02.12.06.17.27_MTP_MEMORY_TEST.setRAAlgorithm.md>).

## Syntax

```
MTP_MEMORY_TEST& setRAUseCountingResults (const bool & status);
```

Parameter
 |

Parameter

 |

Description

 |
 |

status

 |

The status can be:

- true: The RA algorithm will use the counting results calculated from [setRACounting()](<02.12.06.17.30_MTP_MEMORY_TEST.setRACounting.md>).

Do not set `setRAAlgorithm(concurrent mode)` with `setRACounting(delay mode)`, because the concurrent RA algorithm cannot use the delayed counting results.

- false: The RA algorithm will not use the counting results calculated from [setRACounting()](<02.12.06.17.30_MTP_MEMORY_TEST.setRACounting.md>).
 |

List of parameters

There are no parameters.

Return value

There is no return value.
