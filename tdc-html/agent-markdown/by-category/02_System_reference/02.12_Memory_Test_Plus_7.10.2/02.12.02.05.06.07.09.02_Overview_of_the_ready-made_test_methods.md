# Overview of the ready-made test methods

Advantest provides a range of ready-made test methods for driver-sharing tests.

This is a brief overview:

- [BinningExecutor](<02.12.02.05.06.07.09.19_BinningExecutor_test_method_for_driver_sharing.md>): Evaluates the binning information provided by the BinningHandler test method and bins the devices accordingly.
- [BinningHandler](<02.12.02.05.06.07.09.17_BinningHandler_test_method_for_driver_sharing.md>): Provides softt-binning information for failed devices that allows them to continue being tested and binned at the end of a testflow.
- [OnlineCompensation](<02.12.02.05.06.07.09.05_OnlineCompensation_test_method.md>): Compensates for delay effects caused by empty test sites.
- [ResetOverCurrentProtection](<02.12.02.05.06.07.09.07_ResetOverCurrentProtection_test_method.md>): Resets the overcurrent protection circuits that may have been triggered in earlier tests.
- [SharedContinuity](<02.12.02.05.06.07.09.08_SharedContinuity_test_method.md>): Verifies continuity of test signals and checks for short circuits.
- [SharedIDD](<02.12.02.05.06.07.09.13_SharedIDD_test_method.md>): Measures IDD and IDDQ on sharing load boards
- [SharedLeakage](<02.12.02.05.06.07.09.10_SharedLeakage_test_method.md>): Measures the leakage on shared pins.
- [SharedLeakageParallel](<02.12.02.05.06.07.09.11_SharedLeakageParallel_test_method.md>): Measures the leakage on shared, non-shared, and cross-terminated pins that are terminated by a common DPS.
- [SharedVBump](<02.12.02.05.06.07.09.15_SharedVBump_test_method.md>): Changes the supply voltage levels on VDD and/or VDDQ.
