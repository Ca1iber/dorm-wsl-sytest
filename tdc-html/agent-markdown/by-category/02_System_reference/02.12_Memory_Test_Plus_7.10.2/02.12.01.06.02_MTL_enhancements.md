# MTL enhancements

- Adds new data types for variables, values, and arrays. For details, see [Variables](<02.12.03.03.03.01.05_Variables.md>), [Values](<02.12.03.03.03.01.06_Values.md>), and [Defining MTL arrays](<02.12.03.03.03.01.09.01.01_Defining_MTL_arrays.md>).
- Adds new operators and specifies the data types for the operands and expressions regarding operators. For details, see [Operators](<02.12.03.03.03.01.01_Operators.md>) and [Data types relevant to operators](<02.12.03.03.03.01.01.01_Data_types_relevant_to_operators.md>).
