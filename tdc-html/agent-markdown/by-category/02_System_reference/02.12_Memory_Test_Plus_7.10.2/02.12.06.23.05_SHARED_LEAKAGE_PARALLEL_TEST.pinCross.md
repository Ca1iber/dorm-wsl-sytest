# SHARED_LEAKAGE_PARALLEL_TEST.pinCross()

The pinCross() member function of [SHARED_LEAKAGE_PARALLEL_TEST](<02.12.06.23_SHARED_LEAKAGE_PARALLEL_TEST.md>) lets you specify the cross-terminated pins, pin groups that are to be measured.

## Syntax

```
SHARED_LEAKAGE_PARALLEL_TEST& pinCross(const string& pinlist)
```

 |

Parameter

 |

Description

 |
 |

pinlist

 |

The list of the cross-terminated pins, pin groups to be measured.

Separate entries with commas.

 |

## Example

```
SHARED_LEAKAGE_PARALLEL_TEST mTEST;
mTEST.pinCross("Clock_Bus");
mTEST.pinCross("Clock_Bus1,Clock_Bus2");
```
