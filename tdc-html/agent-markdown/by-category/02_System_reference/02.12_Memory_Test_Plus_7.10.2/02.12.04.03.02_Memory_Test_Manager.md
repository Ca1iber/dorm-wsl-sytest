# Memory Test Manager

#### Subtopics

- [Starting the Memory Test Manager](<02.12.04.03.02.01_Starting_the_Memory_Test_Manager.md>)

The Memory Test Manager (MTM) is one access point for MTP tools.

When the MTM launches, it displays a single button bar:

 ![Memory Test Manager (MTM)](<../../../../raw/89381.png>)

## Buttons

Clicking one of the buttons launches the corresponding tool:

![MTM compiler control button](<../../../../raw/105625.png>) [Compiler control dialog](<02.12.03.02.04.01_MTL_Compiler_Control_dialog.md>). You can also use [the MTP Build page](<02.12.02.05.12_Building_MTP_files_with_MTP-EWC.md>) to set up compiler options as well as others for build.

![MTM execution dialog button](<../../../../raw/105626.png>) [Execution dialog](<02.12.03.02.04.01.02_Execution_Dialog_window.md>). If you want to execute an MTP testflow, use the [MTP Launch](<02.12.02.05.12_Building_MTP_files_with_MTP-EWC.md>) page.

![MTM BFM Viewer button](<../../../../raw/105627.png>) [Bit Fail Map Viewer](<02.12.04.04_Bit_Fail_Map_Viewer.md>).

![MTM memory test viewer button](<../../../../raw/105628.png>) [Memory Test Viewer](<02.12.02.07.02_Memory_Test_Viewer.md>).

![MTM MPVT button](<../../../../raw/105629.png>) Memory Pattern Validation Tool becomes obsolete in MTP 7.5.0, MTP 7.4.5, and future versions.

![MTM documentation button](<../../../../raw/105630.png>) MTP (Memory Test Plus) documentation.

## Progress bar

During lengthy operations, a progress bar is displayed at the bottom of the MTM window:

 ![Progress bar with Result Server](<../../../../raw/98363.png>)

The progress bar displays:

- The currently running tool (the Result Server, in the above illustration)
- The name of the file being processed (2006-09-15_08:16:46:227792, in the example)
- The completed percentage (50%, in the example), both as a number and by gradually filling the background

## Menus

The Memory Test Manager has three menus:

- File

  - The Exit command lets you close the MTM.

- Tools: The commands in the Tools menu duplicate the functions of the first five buttons described above.
- Help

  - The MTP Help command duplicates the sixth button in the MTM window.
  - The About command displays copyright and version information on the MTM.

## Launching the MTM

The MTM can be launched from the terminal window or a GUI file manager, as described in [Starting the Memory Test Manager](<02.12.04.03.02.01_Starting_the_Memory_Test_Manager.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
- MTP 3.1.1: Accessing the main MTP tools from SmarTest Work Center is added.
