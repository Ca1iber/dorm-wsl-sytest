# SharedLeakage test method

Leakage test in a shared driver environment is supported by the SharedLeakage test method. The parameters for this test method are described in this topic.

The concepts behind the shared leakage tests are described in [Leakage test for shared lines](<02.12.02.05.06.07.05.01_Leakage_test_for_shared_lines.md>).

## Usage

Whether the SharedLeakage or the [SharedLeakageParallel](<02.12.02.05.06.07.09.11_SharedLeakageParallel_test_method.md>) test method is appropriate depends on the load board characteristics:

- SharedLeakage can test only shared pins. If you need to test non-shared pins or cross-terminated pins, use SharedLeakageParallel.
- SharedLeakageParallel can only test shared pins that are terminated by a common DPS. If you need to test address bus and command bus pins that are terminated by separate DPS, use SharedLeakage.

## Selection

The SharedLeakage test method is available in the DriverSharing class contained in the ddr_solution_tools directory.
