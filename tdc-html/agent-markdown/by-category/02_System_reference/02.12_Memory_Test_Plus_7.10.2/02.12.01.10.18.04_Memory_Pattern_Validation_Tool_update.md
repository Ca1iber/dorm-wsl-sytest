# Memory Pattern Validation Tool update

Enhancements to the MPV Tool are:

- The MPV Tool now supports transparent x-mode.
- The compiled cycle information window informs now about all generated edges.
- Enhancement to the user interface facilitate to trace back a particular device access to the source code by highlighting the corresponding source line.
- Cycle number input field is now directly accessible. Together with a new Show Source button this eases navigation to a particular cycle in focus.
  Note MPVT becomes obsolete in MTP 7.5.0, MTP 7.4.5, and future versions.
