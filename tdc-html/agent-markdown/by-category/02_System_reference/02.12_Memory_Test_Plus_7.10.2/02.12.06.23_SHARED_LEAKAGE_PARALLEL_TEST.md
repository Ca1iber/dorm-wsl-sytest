The SHARED_LEAKAGE_PARALLEL_TEST class provides an API for doing parallel leakage test for the DUTs with [driver sharing](<02.12.02.05.06.07.01_Driver_sharing_concepts.md>). It tests non-shared pins, cross-terminated pins, and the shared pins terminated by a common DPS in a single pass.

When you use this API to create your own custom test method, you should:

- Add the following limits according to the test pins:

  - "Leakage Current Shared Pins [uA]": Defines the current limits [uA] for the shared pins.
  - "Leakage Current Non-Shared Pins [uA]": Defines the current limits [uA] for the non-shared pins.
  - "Leakage Current Cross Pins [uA]": Defines the current limits [uA] for the cross-terminated pins.

For how to add limits and their values to a test method, see [How to create a universal test method class](<../02.07_Test_Method_Reference/02.07.02.02.02_How_to_create_a_universal_test_method_class.md>).

- Include the driver sharing API library and header file to complete a test method code. For detail procedures, see [Setting up for using driver sharing APIs](<02.12.02.05.06.07.09.04_Setting_up_for_using_driver_sharing_APIs.md>).Note The SHARED_LEAKAGE_PARALLEL_TEST API is available only for MTP.

There are two other methods to check the shared leakage:

- A [SharedLeakageParallel test method](<02.12.02.05.06.07.09.12_SharedLeakageParallel_syntax.md>) include with MTP: Use it when you Do not have special requirements such as a customized testing algorithm or a special output format. See [SharedLeakageParallel syntax](<02.12.02.05.06.07.09.12_SharedLeakageParallel_syntax.md>).

It is the easiest way to develop a test.

- The [MTP_LEAKAGE_TASK](<02.12.06.14_MTP_LEAKAGE_TASK.md>) API: Use it when you want to test the pins (either shared, non-shared or cross-terminated pins) with different measurement conditions in one test method.

More differences between the SharedLeakageParallel test method, SHARED_LEAKAGE_PARALLEL_TEST, and MTP_LEAKAGE_TASK are described in [MTP_LEAKAGE_TASK](<02.12.06.14_MTP_LEAKAGE_TASK.md>).

This API is defined in the header file /opt/93000mts/mts/solution_tools/common/include/SHARED_LEAKAGE_PARALLEL_TEST.h.

## Examples

### Note

The following examples demonstrate how to use this API within a test method. If you want to see a complete test method code via SHARED_LEAKAGE_PARALLEL_TEST, find it in /opt/93000mts/mts/solution_tools/common/sh_lib/DriverSharing.tar.gz.

### Example 1

Doing the parallel leakage test for the shared, non-shared and cross-terminated pins.

```
#include "solution_tools.h"
#include "testmethod.hpp"
#include "mapi.hpp"

class CSharedLeakageParallel: public testmethod::TestMethod
{
    virtual void run()
    {
      // The following block only executes for the first site of
      // multi-site setup
      ON_FIRST_INVOCATION_BEGIN();
      {
        // Always do initialization at the beginning of test
        mTest.init();

        // hand over the parameters to the test class
        mTest.sharingConfigFile("default.cfg")
             .pinShared("Addr_Bus,Command_Bus")
             .pinNonShared("DQ_Bus,DQS_DiffBus,DM")
             .pinCross("Clock_Bus")
             .forceVoltage(1.2)
             .settlingTime(10)
             .prechargeTime(10);

        // execute the test
        mTest.execute();
      }
      ON_FIRST_INVOCATION_END();

      // set result
      mTest.judgeAndLog();
      // Print out in the UI Report Window.
      mTest.print();
    }

private:
    SHARED_LEAKAGE_PARALLEL_TEST mTest;
};
```

### Example 2

Customizing output

```
#include "solution_tools.h"
#include "testmethod.hpp"
#include "mapi.hpp"

class CSharedLeakageParallel: public testmethod::TestMethod
{
    virtual void run()
    {
      // The following block only executes for the first site of
      // multi-site setup
      ON_FIRST_INVOCATION_BEGIN();
      {
        // Always do initialization at the beginning of test
        mTest.init();

        // hand over the parameters to the test class
        mTest.sharingConfigFile("default.cfg")
             .pinShared("Addr_Bus,Command_Bus")
             .pinNonShared("DQ_Bus,DQS_DiffBus,DM")
             .pinCross("Clock_Bus")
             .forceVoltage(1.2)
             .settlingTime(10)
             .prechargeTime(10);

        // execute the test
        mTest.execute();
      }
      ON_FIRST_INVOCATION_END();

      // set result
      mTest.judgeAndLog();
      // Print out in the UI Report Window.
      STRING_VECTOR pinSharedNames =
        PinUtility.getDigitalPinNamesFromPinList("Addr_Bus,Command_Bus", TM::ALL_DIGITAL, TRUE);
      STRING_VECTOR pinNonSharedNames =
        PinUtility.getDigitalPinNamesFromPinList("DQ_Bus,DQS_DiffBus,DM", TM::ALL_DIGITAL, TRUE);
      STRING_VECTOR pinCrossNames =
        PinUtility.getDigitalPinNamesFromPinList("Clock_Bus", TM::ALL_DIGITAL, TRUE);

      cout << "Test result of site " << CURRENT_SITE_NUMBER() << ": " << mTest.getPassFail() << endl;

      for (STRING_VECTOR::const_iterator it = pinSharedNames.begin();
           it != pinSharedNames.end(); ++it)
      {
        cout << "PIN (" << *it << ")\t" << mTest.getPassFail(*it) << "\t" << mTest.getValue(*it) << endl;
      }

      for (STRING_VECTOR::const_iterator it = pinNonSharedNames.begin();
           it != pinNonSharedNames.end(); ++it)
      {
        cout << "PIN (" << *it << ")\t" << mTest.getPassFail(*it) << "\t" << mTest.getValue(*it) << endl;
      }

      for (STRING_VECTOR::const_iterator it = pinCrossNames.begin();
           it != pinCrossNames.end(); ++it)
      {
        cout << "PIN (" << *it << ")\t" << mTest.getPassFail(*it) << "\t" << mTest.getValue(*it) << endl;
      }
    }

private:
    SHARED_LEAKAGE_PARALLEL_TEST mTest;
};
```
