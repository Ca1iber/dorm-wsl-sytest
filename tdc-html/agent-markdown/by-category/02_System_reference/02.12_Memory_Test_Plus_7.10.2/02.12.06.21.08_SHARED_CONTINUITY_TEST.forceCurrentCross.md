# SHARED_CONTINUITY_TEST.forceCurrentCross()

The forceCurrentCross() member function of [SHARED_CONTINUITY_TEST](<02.12.06.21_SHARED_CONTINUITY_TEST.md>) lets you specify the current to be forced in the cross-terminated pins.

## Syntax

```
SHARED_CONTINUITY_TEST& forceCurrentCross(double current)
```

 |

Parameter

 |

Description

 |
 |

current

 |

The current to be forced into the cross-terminated pins.

- The unit is A.
- The default current value is 1 A.

 |

## Example

```
SHARED_CONTINUITY_TEST mTEST;
mTEST.forceCurrentCross(100 uA);
mTEST.forceCurrentCross(0.0001);
```
