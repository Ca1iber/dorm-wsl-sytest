# SOURCESYNC_DOMAIN.pins()

Specifies pins in this domain.

## Syntax

```
virtual SOURCESYNC_DOMAIN& pins (const string& pinGroup);
```

Parameter
 |

Parameter

 |

Description

 |
 |

pinGroup

 |

Pins in this domain, separated with ",". The pins must include one clock output pin and at least one data output pin.

For example, "clk0, data00, data01".

 |

## Functional changes

- Introduced in MTP 3.2.2
