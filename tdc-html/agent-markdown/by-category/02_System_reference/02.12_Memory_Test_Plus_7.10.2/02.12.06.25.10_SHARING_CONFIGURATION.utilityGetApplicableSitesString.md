# SHARING_CONFIGURATION.utilityGetApplicableSitesString()

The utilityGetApplicableSitesString() member function of [SHARING_CONFIGURATION](<02.12.06.25_SHARING_CONFIGURATION.md>) returns a string containing all sites to which the specified utility control line applies.

## Syntax

```
string utilityGetApplicableSitesString(int index) const
```

 |

Parameter

 |

Description

 |
 |

index

 |

The location of a utility control line within the utility_control block in the [Sharing configuration file](<02.12.02.05.06.07.07.02_Sharing_configuration_file.md>).

0 represents the first line.

 |
