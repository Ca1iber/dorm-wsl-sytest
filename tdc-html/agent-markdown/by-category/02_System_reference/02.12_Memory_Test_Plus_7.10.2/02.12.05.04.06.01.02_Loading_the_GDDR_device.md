# Loading the GDDR device

## Procedure

-  In SmarTest, import and select the GDDR3 device.
-  Make the device current.
-  Choose a test flow (if one exists already) and click Load.
-  If the device file does not contain a test flow, create a test flow. Note Make sure no error message is displayed in the report window of SmarTest.

## Results

The test flow is opened in the test flow editor.
