# Adding a user account to a virtual machine

Add a user in the virtual machine and configure its connection the virtual machine using the new user account.

## About this task

As the creator of the virtual machine, you can add a new user to enable colleagues to also access the virtual machine.

VNC Viewer is used as the VNC client in this procedure. You can use other VNC clients as you prefer. For details on using other VNC clients, see their documentation.

## Procedure

-  Generate a public and private key pair in PuTTYGen and save the key files.

See [Generating and saving key files](<02.16.03.01_Generating_and_saving_key_files.md>) for details.

-  Open VNC Viewer.
-  Log in to the virtual machine.

See [Connecting to a virtual machine via VNC](<02.16.03.06_Connecting_to_a_virtual_machine_via_VNC.md>) for details.

-  Right-click the desktop of the virtual machine and click Konsole in the menu.

The Konsole window opens.

-  In the Konsole window, enter `sudo /usr/sbin/useradd new_user_name` to add a new user.

new_user_name is the user name for the account that you create.

-  Enter `sudo su - new_user_name` to switch to the new user.
-  Enter `cd ~/.ssh/` to switch to the .ssh directory of the new user.
-  Create a key configuration file on the virtual machine.

  -  Enter `vi authorized_keys` to create a file named authorized_keys.

The file is opened in the vim editor.

  -  Press i on your keyboard.

The vim editor switches to edit mode.

  -  Copy the public key content generated in step [1](<02.16.03.12_Adding_a_user_account_to_a_virtual_machine.md#_355082__key>) from your computer, paste it into the vim editor on the virtual machine.
  -  In the vim editor, press esc to exit edit mode.
  -  Enter :wq! and press Enter to save the file and return to the Konsole window.

-  In the Konsole window of the virtual machine, enter `chmod 600 authorized_keys` to modify the access permission of the file.

## Results

A new user account has been created on the virtual machine and is ready to be used.

## What to do next

The colleague now can connect to the virtual machine with the following steps:

- [Configure the remote connection to the virtual machine](<02.16.03.03_Configuring_a_remote_connection_to_a_virtual_machine.md>) with the PPK file generated in step [1](<02.16.03.12_Adding_a_user_account_to_a_virtual_machine.md#_355082__key>).
- [Connect to the virtual machine via SSH](<02.16.03.04_Connecting_to_a_virtual_machine_via_SSH.md>) using the user name the creator specified in step [5](<02.16.03.12_Adding_a_user_account_to_a_virtual_machine.md#_355082__newuser>).
- To connect to the virtual machine with a VNC client, [set up the VNC connection](<02.16.03.05_Setting_up_a_VNC_connection.md>) and [connect to the virtual machine via VNC](<02.16.03.06_Connecting_to_a_virtual_machine_via_VNC.md>).
