# Installing software to the virtual machine

Use the sudo command to install software to the virtual machine.

## About this task

Since no root account is available for the virtual machine, you can install software using the `sudo` command.

## Procedure

-  Enter the following command:

```
sudo rpm -ivh installation_package
```

-  Press Enter.

## Results

The software is installed.

## Functional changes

- Introduced in SmarTest 7.6.2
