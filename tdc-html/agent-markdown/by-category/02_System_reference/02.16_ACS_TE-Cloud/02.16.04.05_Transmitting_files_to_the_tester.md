# Transmitting files to the tester

Use the command line to transmit a file from the virtual machine to the tester.

## Procedure

-  [Connect to the virtual machine via SSH](<02.16.03.04_Connecting_to_a_virtual_machine_via_SSH.md>) or [via VNC](<02.16.03.06_Connecting_to_a_virtual_machine_via_VNC.md>).
-  In the terminal window, enter the following command to transfer the file:

```
scp -P 8022 -i PEM_file_name transmit_file_name login_name@tester_IP锛?var class="varname">target_directory
```

    PEM_file_name Name of the PEM file for the tester.   transmit_file_name The file to be transmitted to the tester.   login_name The login name to connect the tester.   tester_ip The IP address of the tester.   target_directory The directory in the tester to save the transmitted file.

## Results

The file is transmitted to the target tester at the designated location.

## Functional changes

- Introduced in SmarTest 7.6.2
