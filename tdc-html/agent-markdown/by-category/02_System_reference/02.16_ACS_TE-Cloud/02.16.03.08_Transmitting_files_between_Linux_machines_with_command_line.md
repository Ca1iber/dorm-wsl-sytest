# Transmitting files between Linux machines with command line

Modify the access permission of the PEM file and transmit files with command line.

## Before you begin

 Requirements for the computers or virtual machines to transmit files using command line:

- Linux.
- Internet connection.
- The SFTP protocol is supported.
- Port 22 is open.

## Procedure

-  Open PuTTY.
-  Connect to the virtual machine [via SSH](<02.16.03.04_Connecting_to_a_virtual_machine_via_SSH.md>) or [via VNC](<02.16.03.06_Connecting_to_a_virtual_machine_via_VNC.md>).
-  Modify the access permission of the PEM file:

```
chmod 600 PEM_file_name
```

PEM_file_name is the name of the PEM file which is saved in [Generating and saving key files](<02.16.03.01_Generating_and_saving_key_files.md>) for the target virtual machine.

-  Transfer the file:

```
scp -i PEM_file_name transmit_file_name login_name@public_IP：var class="varname">target_directory
```

    PEM_file_name Name of the PEM file which is saved in [Generating and saving key files](<02.16.03.01_Generating_and_saving_key_files.md>).   transmit_file_name The file to be transmitted to the target machine.   login_name [User name](<02.16.03.02_Creating_a_TE-Cloud_virtual_machine.md#_354551__username>) of the target machine.   public_ip The [public IP address](<02.16.01.01_Virtual_Machine_page.md#_355180__publicIP>) of the target machine.   target_directory The directory in the target machine to save the transmitted file.

## Results

The file is transmitted to the target Linux machine at the designated location.

## Example

```
chmod 600 vicky_VM.pem
```

```
scp -i vicky_VM.pem transmission_test.tar.gz vicky_demo@66.79.4.76:~
```
