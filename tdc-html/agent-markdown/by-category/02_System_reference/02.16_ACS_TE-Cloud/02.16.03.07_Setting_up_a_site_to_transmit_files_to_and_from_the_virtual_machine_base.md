# Setting up a site to transmit files to and from the virtual machine based on SFTP

Configure the site in FileZilla and transmit files between your computer and the virtual machine based on SFTP.

## About this task

To transmit files between you computer and the virtual machine, you can use the file transmitting tools.

FileZilla is used as the SFTP file transmission client in this procedure. You can use other SFTP file transmission clients as you prefer. For details on using other SFTP file transmission clients, see their documentation.

## Before you begin

Download and install [FileZilla](<https://filezilla-project.org/>) 3.27.1 or a newer version.

## Procedure

-  Open FileZila.
-  Choose File > Site Manager.

The Site Manager window opens.

-  Click the New Site button.

A site named New site is added to the My Sites list.

-  If you want to edit the site name, click the name and click the Rename button.
-  Set up the following parameters for the new site:

  - Protocol: Select SFTP - SSH File Transfer Protocol.
  - Host: The [public IP address](<02.16.01.01_Virtual_Machine_page.md#_355180__publicIP>) of the virtual machine.
  - Logon Type: Select Key file.
  - User: The [user name](<02.16.03.02_Creating_a_TE-Cloud_virtual_machine.md#_354551__username>) for the virtual machine.
  - Key file: The private key file (.ppk) which you saved in [Generating and saving key files](<02.16.03.01_Generating_and_saving_key_files.md>).

-  Click OK to save the settings.
-  In the FileZilla window, choose the site that you have added for the virtual machine from the site manager list ![The site manager button](<../../../../raw/354919.png>).

The selected site is displayed in the Remote site field.

## Results

You can now transfer files between your computer and the virtual machine. For details, see the FileZilla documentation.
