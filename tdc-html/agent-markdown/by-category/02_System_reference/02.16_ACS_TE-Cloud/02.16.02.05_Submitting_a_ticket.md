# Submitting a ticket

To submit a ticket, fill in the information for the reported issue and click Submit.

## About this task

For some simple and urgent issues, you can contact the TE-Cloud support team by [online chat](<02.16.02_Help_Center.md#_355181__chat>). When you come across an issue which needs to be clarified by links, images, etc., or the urgency of the issue is not so high, you can submit a ticket.

## Before you begin

You must be [logged in to the help center](<02.16.02.04_Opening_the_help_center.md>).

## Procedure

-  In the help center, click the Submit a ticket button.

The [ticket submission](<02.16.02.03_Ticket_submission_page.md>) page opens.

-  Enter the subject and description of the issue.
-  Select a product name.
-  Click the Submit button.

## Results

The ticket is created with the status Open.

When the support team responds to the ticket, you will get an e-mail with the reply.

If you do not take any action to the ticket for a long time, the status turns to On Hold.

## What to do next

To add a reply to the ticket, [reply to the ticket](<02.16.02.06_Replying_to_a_ticket.md>).

If the issue has been resolved, [close the ticket](<02.16.02.06_Replying_to_a_ticket.md>).
