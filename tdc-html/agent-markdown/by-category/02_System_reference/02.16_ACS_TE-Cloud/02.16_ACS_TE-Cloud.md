The Advantest cloud solution (ACS) TE-Cloud platform provides a one-stand test engineering environment for test engineers. With the cloud virtual machine, you can get remote access to tester resources at Advantest labs and partner labs.

A cloud virtual machine provides secure computing capabilities based on the cloud services. With a cloud virtual machine, you can get access to and set up the computing resources per your needs.

To TE-Cloud platform consists of [TE-Cloud dashboard](<02.16.01_The_TE-Cloud_dashboard.md>) and [Help Center](<02.16.02_Help_Center.md>).

 To set up and connect to a TE-Cloud virtual machine, follow these steps:

- [Configuring a remote connection to a virtual machine](<02.16.03.03_Configuring_a_remote_connection_to_a_virtual_machine.md>)
