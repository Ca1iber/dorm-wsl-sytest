# Adding a public SSH key

To add the key information of the tester, you must generate the key pair and save the public key on the TE-Cloud dashboard.

## About this task

Before you book a tester time for the first time, you must add the public key information generated for connecting to the tester on the SSH Key page. This is not required when you use the same tester again.

If you deleted the key which has been used to create your tester account and want to add a new key, the connection to the tester would be unavailable. Contact the ETC (engineering test center) operator to reopen the tester after you add the new key.

## Procedure

-  Generate a public and private key pair in PuTTYGen and save the key files.

See [Generating and saving key files](<02.16.03.01_Generating_and_saving_key_files.md>) for details.

-  [Open the TE-Cloud dashboard](<02.16.01.04_Opening_the_TE-Cloud_dashboard.md>).
-  Click SSH Key.

The SSH Key page is displayed.

-  Click the Add button.

The Public SSH Key window opens.

-  Enter a name for the key in the Name field.
-  In the Public Key field, paste the public key you created in step [1](<02.16.04.02_Adding_a_public_SSH_key.md#_355216__key>).

With the public key, the ETC operator creates a user account for you on the tester, and you will be able to connect to the tester.

-  Click the Confirm button.

The public key is saved and the Public SSH Key window is closed.

## Results

The key information is displayed on the SSH Key page.

You can delete it by clicking the Delete button. If you delete the key, you can no longer book the testing time for the tester on which it was used to create accounts, but the booked sessions are still available.
