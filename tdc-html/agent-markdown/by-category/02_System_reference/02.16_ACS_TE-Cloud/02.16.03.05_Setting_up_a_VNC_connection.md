# Setting up a VNC connection

Create a VNC connection using an existing SSH connection.

## About this task

To access the virtual machine desktop, you first set up the VNC connection and then connect to the virtual machine via a VNC client.

## Procedure

-  [Connect to the virtual machine via SSH](<02.16.03.04_Connecting_to_a_virtual_machine_via_SSH.md>).
-  In the command window, create a VNC port by entering the following command and tapping Enter:

```
vncserver -geometry resolution_ratio
```

resolution_ratio: The resolution ratio which is appropriate for your screen, for example, 1920x1200.

-  Enter the VNC password and press Enter.

If this is the first time you log in, enter the password twice to set up the VNC password.

The port to the VNC server is created and the port number is returned.

![The created VNC port](<../../../../raw/354867.png>)

You can create at most three ports for a virtual machine. The VNC port numbers are automatically assigned (1 for the first port, 2 for the second, 3 for the third).

-  Open PuTTY.
-  In the PuTTY Configuration window, click the session name in the Saved Sessions field and click the Load button.

The session is the one you created in [Configuring a remote connection to a virtual machine](<02.16.03.03_Configuring_a_remote_connection_to_a_virtual_machine.md>).

The information of the selected session is loaded and displayed.

-  In the Category field, choose SSH > Tunnels.
-  In the Source port field, enter the port number for the port you created in step [3](<02.16.03.05_Setting_up_a_VNC_connection.md#_354951__password>).

The port number is 5901 for port 1, 5902 for port 2, and 5903 for port 3.

-  In the Destination field, enter 127.0.0.1:port_number.
-  Click the Add button.

The port information is displayed in the Forwarded ports field.

-  In the Category field, select Session.
-  Enter a name in the Saved Sessions field, and click Save.

## Results

A new session with the settings of the VNC port is created. It is displayed under the existing session names.

This is a one-time setup. Every time when you open PuTTY, the saved session is displayed.
