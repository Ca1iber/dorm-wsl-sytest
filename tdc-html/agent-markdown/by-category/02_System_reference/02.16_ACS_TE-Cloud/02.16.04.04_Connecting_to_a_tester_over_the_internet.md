# Connecting to a tester over the internet

To use the online tester, you need to log into the TE-Cloud virtual machine and connect to the tester through the virtual machine.

## About this task

FileZilla is used as the SFTP file transmission client in this procedure. You can use other SFTP file transmission clients as you prefer. For details on using other SFTP file transmission clients, see their documentation.

## Procedure

-  On your computer, open FileZilla.
-  If you have not set up the virtual machine as a site in FileZilla, [set up the site](<02.16.03.07_Setting_up_a_site_to_transmit_files_to_and_from_the_virtual_machine_base.md>) for it.
-  From the site manager list ![The Site manager button](<../../../../raw/354919.png>), choose the site that you have added for the virtual machine.

The selected site is displayed in the Remote site field.

-  Transmit the [PEM file](<02.16.03.01_Generating_and_saving_key_files.md#_354550__PEMfile>) which was generated for the tester in [Adding a public SSH key](<02.16.04.02_Adding_a_public_SSH_key.md>) to the virtual machine.

For details on transmitting files, see the FileZilla documentation.

-  [Connect to the virtual machine via VNC](<02.16.03.06_Connecting_to_a_virtual_machine_via_VNC.md>).
-  Right-click the desktop of the virtual machine and click Konsole in the menu.

The Konsole window opens.

-  In the Konsole window, modify the access permissions of the PEM file:

```
chmod 600 PEM_file_name
```

PEM_file_name is the name of the PEM file for the tester.

-  To control the tester through the command line, connect to the tester by entering the command:

```
ssh login_name@tester_IP -p 8022 -i PEM_file_name
```

 You can see the information of login_name (the login name for the tester) and tester_IP (the IP address) that you received in the booking confirmation e-mail. See [Booking a tester for a specific time slot](<02.16.04.03_Booking_a_tester_for_a_specific_time_slot.md>) for details.

The connection to the tester is completed. You can now control the tester through the command line.

-  If you want to connect to the tester via VNC, perform the following steps:

  -  Connect to the tester by entering the command:

```
ssh -L 5922:127.0.0.1:port_number login_name@tester_IP -p 8022 -i PEM_file_name

```

port_number is 5901 for VNC port 1, 5902 for VNC port 2, and 5903 for VNC port 3. It should match with the VNC port number you defined in step [9.b](<02.16.04.04_Connecting_to_a_tester_over_the_internet.md#_355217__vncport>).

  -  Create the VNC port for the tester.

```
vncserver -geometry resolution_ratio:VNC_port_number
```

resolution_ratio: The screen resolution of the VNC connection, for example, 1920x1200.

VNC_port_number: Specify a VNC port number for the tester, that is, 1 for port 1, 2 for port 2, and 3 for port 3.

If this is the first time you create a VNC port, enter the password twice to set up the VNC password.

  -  Open another Konsole window.
  -  Connect to the tester via VNC Viewer.

```
vncviewer 127.0.0.1:5922
```

The desktop of the tester is displayed in VNC Viewer.

## Results

You are connected to the tester. You can now control the tester through the command line or from the tester desktop.
