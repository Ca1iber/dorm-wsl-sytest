# Revoking access to a virtual machine

Delete the public key information of a specific user from the key configuration file to prevent that user from accessing the virtual machine.

## About this task

When you have [given a user access to a virtual machine](<02.16.03.09_Authorizing_another_user_for_a_virtual_machine.md>), you can revoke it when that user should no longer be able to work with that virtual machine.

VNC Viewer is used as the VNC client in this procedure. You can use other VNC clients as you prefer. For details on using other VNC clients, see their documentation.

## Procedure

-  Open VNC Viewer.
-  Connect to the virtual machine.

See [Connecting to a virtual machine via VNC](<02.16.03.06_Connecting_to_a_virtual_machine_via_VNC.md>) for details.

-  Right-click the desktop and click Konsole in the menu.

The Konsole window opens.

-  Open the key configuration file authorized_keys.

  -  In the Konsole window, enter `cd ~/.ssh/` to switch to the .sshdirectory of the virtual machine.
  -  Enter `gedit authorized_keys` to open the key configuration file.

-  Delete the public key of the user whose authorization you want to revoke from the file.
-  Save the configuration file.

## Results

The user whose public key you deleted can no longer access the virtual machine.
