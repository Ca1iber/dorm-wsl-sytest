# SSH Key page

This page displays the public SSH key you added for the tester.

![The SSH Key page](<../../../../raw/355230.png>)
  SSH key name The name you specified when you added the key. Creation time The date and time when you added the key. Available action The only available action is deleting the key. You can click the Delete button to delete this key.

If you have not added any key information on this page, only an Add button is displayed and the table is empty. You can [add a public SSH key](<02.16.04.02_Adding_a_public_SSH_key.md>).
