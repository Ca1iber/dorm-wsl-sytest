# Connecting to a virtual machine via SSH

Connect to the TE-Cloud virtual machine through SSH and control it with the command line.

## Before you begin

Finish the configuration in [Configuring a remote connection to a virtual machine](<02.16.03.03_Configuring_a_remote_connection_to_a_virtual_machine.md>).

PuTTY is used as the SSH client in this procedure. You can use other SSH clients as you prefer. For details on using other SSH clients, see their documentation.

## Procedure

-  Open PuTTY.
-  In the Category field, select Session.
-  In the Saved Sessions field, double-click the name of the session which was created in [Configuring a remote connection to a virtual machine](<02.16.03.03_Configuring_a_remote_connection_to_a_virtual_machine.md>).

A terminal window opens.

-  Enter the [user name](<02.16.03.02_Creating_a_TE-Cloud_virtual_machine.md#_354551__username>) and press Enter.

## Results

The connection to the virtual machine is established. You can control the virtual machine through the command line.
