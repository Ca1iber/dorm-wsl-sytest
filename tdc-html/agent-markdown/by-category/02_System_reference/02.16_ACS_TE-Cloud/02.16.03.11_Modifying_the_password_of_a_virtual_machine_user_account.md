# Modifying the password of a virtual machine user account

To change the password for a user account, modify the public key and modify the VNC login password.

## About this task

To change the password of the virtual machine, you can disable the old one and replace it with a new password.

VNC Viewer is used as the VNC client in this procedure. You can use other VNC clients as you prefer. For details on using other VNC clients, see their documentation.

## Procedure

-  Generate a public and private key pair in PuTTYGen and save the key files.

See [Generating and saving key files](<02.16.03.01_Generating_and_saving_key_files.md>) for details.

-  Open VNC Viewer.
-  Login to the virtual machine.

See [Connecting to a virtual machine via VNC](<02.16.03.06_Connecting_to_a_virtual_machine_via_VNC.md>) for details.

-  Right-click the desktop and click Konsole in the menu.

The Konsole window opens.

-  If you have not enabled the copy and paste function cross systems, do so as described in [authorizing another user for a virtual machine](<02.16.03.09_Authorizing_another_user_for_a_virtual_machine.md#_354621__enablecopy>).
-  Open the key configuration file authorized_keys.

  -  In the Konsole window, enter `cd ~/.ssh/` to switch to the .ssh directory of the virtual machine.
  -  Enter `gedit authorized_keys` to open the key configuration file.

-  Delete the public key you generated before creating the virtual machine from the configuration file.

Do not delete other public keys which are used to authorize other users for the virtual machine.

-  Copy the public key content generated in step [1](<02.16.03.11_Modifying_the_password_of_a_virtual_machine_user_account.md#_354658__key>) into the configuration file.
-  Save the configuration file.

Do not close VNC Viewer before you have verified the new key as described in steps [10](<02.16.03.11_Modifying_the_password_of_a_virtual_machine_user_account.md#_354658__configure>) to [14](<02.16.03.11_Modifying_the_password_of_a_virtual_machine_user_account.md#_354658__verify>).

-  [Configure the connection to the virtual machine](<02.16.03.03_Configuring_a_remote_connection_to_a_virtual_machine.md>) with PuTTY.
-  [Connect to the virtual machine via SSH](<02.16.03.04_Connecting_to_a_virtual_machine_via_SSH.md>).
-  Enter vncpasswd in the Konsole window.
-  Enter the new password and press Enter.
-  Enter the new password again to verify it.

## Results

The password has been changed to the new one.

If you cannot login with the new password, contact the TE-Cloud support team (PDL-ATC-TECloud@advantest.com).
