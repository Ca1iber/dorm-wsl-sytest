# Getting contact information for an engineering test center

To contact an engineering test center, you can find the desired engineering test center on the Tester Booking page and get the contact information.

## About this task

ETC (engineering test center) is the provider of online tester resources. On the TE-Cloud dashboard, you can find the ETC which is applicable for your test tasks and contact the ETC for using the online tester.

## Procedure

-  [Open the TE-Cloud dashboard](<02.16.01.04_Opening_the_TE-Cloud_dashboard.md>).
-  Click Tester Booking.

The [Tester Booking page](<02.16.01.02_Tester_Booking_page.md>) is displayed.

![The Tester Booking page](<../../../../raw/355219.png>)

-  Choose options in the filters to search for the desired ETC.

  - Select ETC
  - Select location
  - Select cards

The ETCs that match the selected filters are displayed.

-  If you want to see the details of an ETC, click the information icon ![ETC information icon](<../../../../raw/355220.png>) for the ETC.

The ETC window opens. It shows the profile of the ETC and the cards applicable in this ETC.

-  If you find an ETC that matches your needs, click the Contact button beside this ETC name.

The contact information, including contact person, E-mail address, and phone number, is displayed.

## Results

You have found an ETC which is suitable for your requirements and can contact the ETC to arrange the test.

## What to do next

- If you come to an agreement with the ETC, [add an SSH key](<02.16.04.02_Adding_a_public_SSH_key.md>).
- If you cannot come to an arrangement, repeat the above procedure to find another suitable ETC.
