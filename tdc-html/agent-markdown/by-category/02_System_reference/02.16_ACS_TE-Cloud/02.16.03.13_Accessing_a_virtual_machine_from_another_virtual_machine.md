# Accessing a virtual machine from another virtual machine

Connect to the target virtual machine with its PEM file within the TE-Cloud environment.

## About this task

When you have two or more cloud virtual machines in the TE-Cloud environment, accessing a virtual machine from another one within the TE-Cloud intranet is much faster than that through the public internet.

FileZilla is used as the SFTP file transmission client in this procedure. You can use other SFTP file transmission clients as you prefer. For details on using other SFTP file transmission clients, see their documentation.

In this procedure, the virtual machine that is used to access another one is called virtual machine A, and the one to be accessed is called virtual machine B.

## Before you begin

Ensure you have two cloud virtual machines created for the same TE-Cloud account, and have the [PEM file](<02.16.03.01_Generating_and_saving_key_files.md#_354550__PEMfile>) for the virtual machine to be accessed.

## Procedure

-  In your computer, open FileZilla.
-  If you have not set up virtual machine A in FileZilla, [set up the site](<02.16.03.07_Setting_up_a_site_to_transmit_files_to_and_from_the_virtual_machine_base.md>) for it.
-  Choose the site that you have added for the virtual machine A from the site manager list ![The site manager button](<../../../../raw/354919.png>).

The selected site is displayed in the Remote site field.

-  Transmit the PEM file of virtual machine B which is saved in your computer to virtual machine A.

For details, see the FileZilla documentation.

-  [Connect to virtual machine A via SSH](<02.16.03.04_Connecting_to_a_virtual_machine_via_SSH.md>).
-  In the terminal window of virtual machine A, modify the access permission of the PEM file:

```
chmod 600 PEM_file_name
```

PEM_file_name is the name of the PEM file of virtual machine B.

-  Connect to virtual machine B from virtual machine A:

```
ssh -i PEM_file_name user_nameB@intranet_IP_B
```

  user_nameB The [user name](<02.16.03.02_Creating_a_TE-Cloud_virtual_machine.md#_354551__username>) of virtual machine B. intranet_IP_B The TE-Cloud intranet IP address of virtual machine B.

To get the TE-Cloud intranet IP address, [connect to virtual machine B via SSH](<02.16.03.04_Connecting_to_a_virtual_machine_via_SSH.md>), and the address is displayed in the terminal window. For example, for test01@ip-10-3-44-153 ~, the IP address is 10.3.44.153.

To connect to virtual machine B within the TE-Cloud environment is recommended because the data transmission is fast and stable.

You can replace intranet_IP_B with the [public IP address](<02.16.01.01_Virtual_Machine_page.md#_355180__publicIP>) of virtual machine B to connect to virtual machine B through the public internet.

## Results

The connection from virtual machine A to virtual machine B is completed. You can now control virtual machine B in the terminal window of virtual machine A.
