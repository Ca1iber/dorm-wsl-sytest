# My Area

The My Area page lists the tickets you have submitted to the TE-Cloud team.

![The My Area page](<../../../../raw/355401.png>)
   Search box Entering the search term or ticket number and pressing Enter displays tickets containing the entered term or number. Ticket status Clicking Open, Closed, or On Hold displays tickets that have the respective status. Ticket list The tickets you have submitted that match the selected status and the specified search terms. Add ticket Clicking this button opens the [Submit a ticket](<02.16.02.03_Ticket_submission_page.md>) page.

## Functional changes

- Introduced in SmarTest 7.6.2
