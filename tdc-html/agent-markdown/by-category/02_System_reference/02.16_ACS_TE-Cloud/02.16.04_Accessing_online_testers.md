# Accessing online testers

#### Subtopics

- [Getting contact information for an engineering test center](<02.16.04.01_Getting_contact_information_for_an_engineering_test_center.md>)
- [Adding a public SSH key](<02.16.04.02_Adding_a_public_SSH_key.md>)
- [Booking a tester for a specific time slot](<02.16.04.03_Booking_a_tester_for_a_specific_time_slot.md>)
- [Connecting to a tester over the internet](<02.16.04.04_Connecting_to_a_tester_over_the_internet.md>)
- [Transmitting files to the tester](<02.16.04.05_Transmitting_files_to_the_tester.md>)

To access an online tester, you need to get in touch with the an engineering test center, book the tester on the TE-Cloud dashboard, and connect to the tester.

The TE-Cloud platform is integrated with ETCs (engineering test centers) which provide the connection to online testers through SSH.

 To access an online tester, perform the following steps:

- [Getting contact information for an engineering test center](<02.16.04.01_Getting_contact_information_for_an_engineering_test_center.md>)
- [Adding a public SSH key](<02.16.04.02_Adding_a_public_SSH_key.md>)
- [Booking a tester for a specific time slot](<02.16.04.03_Booking_a_tester_for_a_specific_time_slot.md>)
- [Connecting to a tester over the internet](<02.16.04.04_Connecting_to_a_tester_over_the_internet.md>)

After the connection, you can use the tester for online test and [transmit files to the tester](<02.16.04.05_Transmitting_files_to_the_tester.md>).
