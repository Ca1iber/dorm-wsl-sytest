# Configuring a remote connection to a virtual machine

Set up the parameters in PuTTY to connect to the TE-Cloud virtual machine.

## About this task

Before you can connect to the TE-Cloud virtual machine, you must configure the parameters for the remote connection.

## Before you begin

Download and install PuTTY. See [External tools needed for working with virtual machines](<02.16.05_External_tools_needed_for_working_with_virtual_machines.md>) for details.

## Procedure

-  Open PuTTY.
-  In the Host Name field, enter the [public IP address](<02.16.01.01_Virtual_Machine_page.md#_355180__publicIP>) of the virtual machine to be connected.
-  In the Category field, choose SSH > Auth, and choose the private key file (.ppk) to import.

See [Generating and saving key files](<02.16.03.01_Generating_and_saving_key_files.md>) for more information about the private key file.

The file directory and its name are displayed in the field beside the Browse button.

-  In the Category field, select Connection, and enter 10 in the Seconds between keepalives (0 to turn off) field.

If no operation is performed in a certain period, the VNC connection is terminated by the server. With this setting, you can specify how often PuTTY should simulate activity to prevent this from happening. Unless you experience repeated disconnections caused by inactivity, we recommend to set 10 seconds.

-  In the Category field, select Session.
-  Enter a name in the Saved Sessions field, and click Save.

The entered session name is displayed under Default Settings.

## Results

The configuration of the session to the virtual machine is completed.

This is a one-time setup. Every time when you open PuTTY, the saved session is displayed.
