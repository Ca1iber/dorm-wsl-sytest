# Connecting to a virtual machine via VNC

Connect to the virtual machine through PuTTY and access its desktop in a VNC client.

## About this task

VNC Viewer is used as the VNC client in this procedure. You can use other VNC clients as you prefer. For details on using other VNC clients, see their documentation.

## Before you begin

[Set up the VNC port](<02.16.03.05_Setting_up_a_VNC_connection.md>) of the virtual machine.

## Procedure

-  Open PuTTY.
-  In the Category field, select Session.
-  In the Saved Sessions field, double-click the name of the session which was created in [Setting up a VNC connection](<02.16.03.05_Setting_up_a_VNC_connection.md>).

A terminal window opens.

-  Enter the [user name](<02.16.03.02_Creating_a_TE-Cloud_virtual_machine.md#_354551__username>) and press Enter.
-  Open VNC Viewer.   Note Ensure PuTTY is connected.
-  Enter the [port address](<02.16.03.05_Setting_up_a_VNC_connection.md#_354951__portnumber>) 127.0.0.1:port_number.

The port number is 5901 for port 1, 5902 for port 2, and 5903 for port 3.

The Authentication window opens.

-  Enter the [password](<02.16.03.05_Setting_up_a_VNC_connection.md#_354951__password>) you set when you set up the VNC port.
-  Click OK.

## Results

The desktop of the virtual machine is displayed in VNC Viewer.
