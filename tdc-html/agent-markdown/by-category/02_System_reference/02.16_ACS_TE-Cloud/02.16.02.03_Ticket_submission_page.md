# Ticket submission page

This page presents a form that you can use to submit a ticket for TE-Cloud.

![The ticket submission page](<../../../../raw/355404.png>)
    Subject The title of the ticket to summarize your issue.

You must fill in this field for the ticket.

 Description Enter the details of your issue.

You can use the tools on the toolbar to format the text, and insert images, tables, code, links, HTML, and rules.

![Toolbar options](<../../../../raw/355405.png>)

- Clicking Insert opens the menu with options to insert links, HTML, tables, horizontal lines, and code.
![Insert options](<../../../../raw/355435.png>)

- Clicking Plain text switches to plain text mode, hiding the formatting tools. Clicking Rich text switches to formatted-text mode and displays the tools again.
 Product Name The product you selected for which you are reporting an issue. Priority The priority of this issue. The default value is High. Attachment You can attach files such as screenshots or setup files with your ticket. To attach a file, click Attach a file. Submit Clicking this button submits the ticket. Discard Clicking this button cancels the submission and close the ticket submission page.
