# Booking a tester for a specific time slot

To book a tester, you can select the tester and the time slot you want to book, and the request is automatically sent to the engineering test center.

## About this task

Booking a time slot on a tester is required for connecting to it and performing a test on it.

## Before you begin

The [public SSH key](<02.16.04.02_Adding_a_public_SSH_key.md>) must have been added on the SSH Key page, and the engineering test center (ETC) operator must have created an account for you on the tester.

It is recommended to contact the ETC operator to confirm your permission to the tester before you book it.

## Procedure

-  [Open the TE-Cloud dashboard](<02.16.01.04_Opening_the_TE-Cloud_dashboard.md>).
-  Click Tester Booking.

The Tester Booking page is displayed.

-  Click the tester booking icon ![The tester booking icon](<../../../../raw/355226.png>) for the ETC where you want to perform the test.

The window for booking the tester opens.

![The tester booking window](<../../../../raw/355227.png>)

-  Book the time slot to use the tester.

It is recommended to contact your ETC operator for available testers and time slots in advance.

  -  Select the tester from the menu.

All testers available for your account are listed.

  -  Select the date you want to book.
  -  Select the time slot you want to book.
  -  Click the Confirm button.

The booking request is sent to the corresponding ETC e-mail box and the window is closed.

  If the tester is available during the selected time slot, within one week, you will receive an e-mail from the ETC confirming the booking. The following information is provided in the e-mail:

  - The ID of this booking event
  - The IP address of the tester
  - The login name for the tester
  - The name of the public key with which you verify your account (as specified in [Adding a public SSH key](<02.16.04.02_Adding_a_public_SSH_key.md>))
  - The name of the tester
  - The start and end time you booked

- Optional:  If you want to view all testing sessions you have booked, [open the TE-Cloud dashboard](<02.16.01.04_Opening_the_TE-Cloud_dashboard.md>), click the Tester Booking label, and select View my booking.

The testers that you have successfully booked are displayed. The reserved tester time are shown in bar graphs.

## Results

You have successfully booked a tester at the desired time slot.
