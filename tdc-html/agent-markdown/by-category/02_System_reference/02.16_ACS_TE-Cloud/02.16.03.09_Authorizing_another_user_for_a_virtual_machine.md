# Authorizing another user for a virtual machine

Generate the key pair, add it to the key configuration file of the virtual machine, and verify the connection.

## About this task

By default, only you as the creator of a virtual machine can access it. If you authorize additional users, they can also access it. You can [revoke their access](<02.16.03.10_Revoking_access_to_a_virtual_machine.md>) when they should no longer be able to work with that virtual machine.

VNC Viewer is used as the VNC client in this procedure. You can use other VNC clients as you prefer. For details on using other VNC clients, see their documentation.

## Before you begin

Ensure you have [created a TE-Cloud virtual machine](<02.16.03.02_Creating_a_TE-Cloud_virtual_machine.md>) and [configured the connection](<02.16.03.02_Creating_a_TE-Cloud_virtual_machine.md>) to it successfully.

## Procedure

-  Generate a public and private key pair in PuTTYGen and save the key files.

See [Generating and saving key files](<02.16.03.01_Generating_and_saving_key_files.md>) for details.

-  Open VNC Viewer.
-  Connect to the virtual machine.

See [Connecting to a virtual machine via VNC](<02.16.03.06_Connecting_to_a_virtual_machine_via_VNC.md>) for details.

-  Right-click the desktop of the virtual machine and click Konsole in the menu.

The Konsole window opens.

-  Enable the copy and paste function cross systems.

  -  In the Konsole window, enter `vncconfig` and press Enter.

The VNC config window opens.

![The VNC config window](<../../../../raw/355081.png>)

  -  Select all the four options.
  -  Close the window.

-  Open the key configuration file authorized_keys.

  -  In the Konsole window, enter `cd ~/.ssh/` to switch to the .sshdirectory of the virtual machine.
  -  Enter `gedit authorized_keys` to open the key configuration file.

-  Copy the public key content generated in step [1](<02.16.03.09_Authorizing_another_user_for_a_virtual_machine.md#_354621__generatekey>) and paste it into the key configuration file below the original content of the file.

Do not edit or delete the existing content of the key configuration file.

-  Save the key configuration file.

This new public key is available on the virtual machine.

-  To verify the authorization, follow these steps from the computer of the authorized user:

The verification procedure might be performed by the authorized user. You should provide the authorized user with the private key file (.ppk) you saved in step [1](<02.16.03.09_Authorizing_another_user_for_a_virtual_machine.md#_354621__generatekey>), the [user name](<02.16.03.02_Creating_a_TE-Cloud_virtual_machine.md#_354551__username>) and [public IP address](<02.16.01.01_Virtual_Machine_page.md#_355180__publicIP>) of the virtual machine.

  -  Open PuTTY.
  -  In the Host Name field, enter the [public IP address](<02.16.01.01_Virtual_Machine_page.md#_355180__publicIP>) of the virtual machine to be connected.
  -  In the Category field, choose SSH > Auth, and choose the private key file (.ppk) you saved in step [1](<02.16.03.09_Authorizing_another_user_for_a_virtual_machine.md#_354621__generatekey>).
  -  In the Category field, select Session, enter a name in the Saved Sessions field, and click Save.

This step defines a new session name in PuTTY for the new user.

  -  [Connect to the virtual machine via SSH](<02.16.03.04_Connecting_to_a_virtual_machine_via_SSH.md>) using the [user name](<02.16.03.02_Creating_a_TE-Cloud_virtual_machine.md#_354551__username>).

## Results

If logging in successfully, you have authorized the user to access the virtual machine.
