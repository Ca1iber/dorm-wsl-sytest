# Managing files to compare

The Comparison Tool supports you in the annual license renewal process. It displays the download records, the license inventory of your license servers, and any mismatching in a tabular format.

The License Renewal Comparison Tool requires the following input files:

- One or more license server inventory file or files (*.txt) generated by the getOrderNumbers tool.
- Portal download file of already renewed licenses (Renewed.csv)

Optionally, you can load the portal download file of still to be renewed licenses (To-Be-Renewed.csv).

The comparison tool processes these files against the data in the Product Number Key tab. This data is provided with the yearly updated license product list (see [Installing and starting the Comparison Tool](<02.04.08.02.01_Installing_and_updating_the_Comparison_Tool.md>)).

## License server inventory .txt files

In most cases, you will have a single license server inventory file (getOrderNumbers output file).

This is the case for the following licensing server setups:

- one FLEXlm license server
- three-license-server redundancy configuration
- multiple independent license servers in a network

For these configurations you will have one license server inventory file showing the installed licenses for all license servers.

Only in case of multiple license servers in independent networks you will have one license server inventory file per network. In this case you must run the [getOrderNumbers tool](<02.04.08.02.05_getOrderNumbers_tool.md>) on a server in each network.

You must use a .txt file name extension for each file, for example license-inventory-server01.txt.

## Renewed.csv files

Download a record file, which lists the already renewed licenses (Renewed.csv), from the License Renewal Portal before running the Comparison Tool.

## To-Be-Renewed.csv files

Download the record file of not-renewed licenses (To-Be-Renewed.csv) from the License Renewal Portal before running the Comparison Tool. This file is optional, but it can provide helpful information in the case the renewal process does not run as smoothly as expected.

## Collect in single directory

The License Renewal Portal writes both .csv record files into a License-Comparison-<date>.zip file. For further processing you need to extract them.

Advantest recommends you to create a common directory or folder, for example advantest-license-renewal-<year>, and collect all these files in this directory. If all input files are available in your local file system, you can run the Comparison Tool stand-alone.

The directory of your collected input files may look as follows:

```
advantest-license-renewal-2009/license-inventory-server01.txt
advantest-license-renewal-2009/Renewed.csv
advantest-license-renewal-2009/To-Be-Renewed.csv
```
