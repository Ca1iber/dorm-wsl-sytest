# InstaCard licensing

InstaCard licensing provides the flexibility and cost control to enable only the hardware features you need for your measurement characteristics (for example, memory, speed, bandwidth).

Advantest InstaCard test head cards require a base capability license to enable operation. For some cards, there are base capability extension licenses, for example, to provide more channels. A base capability license is required for each card installed in the system. Advanced features are available through the application of additional upgrade licenses and can be applied as and when extra capability is required.

Base capability and InstaCard versions of a card carry dedicated product numbers.

 InstaCard versions are available for the following types of cards: Legacy cards Cards such as PS1600A/B, PS9G, DPS128/64, UHC4T, AVI64, originally only available as base capability cards are also available as InstaCards without base capabilities. Only allocate the licenses you need to access the functionality required by your test program. Note InstaCard variants of legacy cards are supported from SmarTest Rev. 7.4.4 and above.  New SmarTest 8 cards New cards such as the Wave Scale RF, Wave Scale MX, and Wave Scale Precision Source cards for SmarTest 8 installations are only available as InstaCards, giving you the freedom to apply them as you need at the lowest possible cost. New SmarTest 7 cards New cards such as the FVI16 cards for SmarTest 7.5 and later installations are only available as InstaCards, giving you the freedom to apply them as you need at the lowest possible cost.   Note You can mix base capability cards and InstaCards.    ![The structure of InstaCards and their licensing requirements.](<../../../../raw/354280.png>)

## Card combinations

- Base capability cards and InstaCards can be used together.
- DUT board definition files and model files do not need to be changed when swapping between base capability and InstaCard versions of a card.

The Report window differentiates between base capability cards and InstaCards. InstaCards include the -OP product suffix and InstaCard is displayed in the misc column.

![InstaCard hardware reported in the Report window.](<../../../../raw/354385.png>)

- Upgrade feature licenses (for example, speed and memory upgrades) can be used on both InstaCards and base capability cards.

## License options

InstaCards can be purchased in the following arrangements:

- Without a license. No functionality is initially accessible.
- With a perpetual base capability license.
- With an annual base capability license.
  Note Annual and perpetual licenses can be combined and used simultaneously.

Base capability cards (legacy cards) are still available with a base capability license. Hardware-enabled base capabilities work in both SmarTest 7 and SmarTest 8.

## Missing licenses

Licenses checks are carried out during the bind and not reflected in the instrument model. If a license is required but not available, a bind error is reported.
