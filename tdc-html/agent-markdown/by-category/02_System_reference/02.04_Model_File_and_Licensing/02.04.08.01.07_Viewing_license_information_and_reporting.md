# Viewing license information and reporting

#### Subtopics

- [Creating a report](<02.04.08.01.07.01_Creating_a_report.md>)
- [Exporting a report](<02.04.08.01.07.02_Exporting_a_report.md>)

The Overview and Reports page helps you to get an overview about the status of your product licenses and entitlements that are assigned to your user account. The following preconfigured reports are included:

- Entitlement by organization report
- Product by organization report
- Product by server report
- Splitted entitlements overview
- Download csv file with renewal data

You can also use the export tools available from the Overview and Reports page to create simple reports in Microsoft Excel or CSV formats.

Even outside of the renewal period, the Reports page gives you an overview about your licenses (only perpetual, renewable licenses).
