# The Software .lic license files

#### Subtopics

- [Enabling software licenses](<02.04.05.02.01_Enabling_software_licenses.md>)

Software *.lic license files cover SmarTest release streams, and service and support software tools.

You will receive one software license file per test head with your Service and Support contracts.

The software *.lic license file resides by default in the /opt/flexlm/license directory on both the license client and the license server, just like the system *.lic license file(s).

Software licenses are locked to the serial number of a test system. Its online license component is tied to the SmarTest version and includes all patches of a release stream. Its online value package components are valid for the duration of the initial warranty period and subsequently for the duration of the support contract.

## Release stream

The second digit in the revision number defines the SmarTest release stream. That is, all releases and patches from, for example, SmarTest 7.1.0 to 7.1.n belong to the same release stream and show the same master release date. All are covered by the online component of the software license.

## System serial number and master release date

The report window shows the system serial number and the master release date. For example:

```
V93000
...
System serial number: DExxxxxxx
Master release date: 2011.1
```
