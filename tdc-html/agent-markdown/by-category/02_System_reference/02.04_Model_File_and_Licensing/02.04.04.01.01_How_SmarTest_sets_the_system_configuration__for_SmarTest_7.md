# How SmarTest sets the system configuration (for SmarTest 7)

At startup SmarTest automatically compares the installed hardware, the hardware parameters defined in the model file or device license file, and SmarTest license availability. These checks ensure compatibility. They are identical in offline and online mode, except for the last steps, as explained below.

 Note This topic is applicable to SmarTest 7 only.

When SmarTest is started up in online mode, it reports the detected test system hardware in the report window in the MAXIMUM POSSIBLE CONFIGURATION table. In offline mode it shows the requested configuration defined by the model file.

SmarTest performs the following checks:

- Parser syntax check: Determines if all required parameters are defined (some parameters are optional). If a required entry is missing, an error message is displayed and the software terminates. For an explanation of possible errors and the steps you can take to correct them, see [Model file error messages](<02.04.05.09.01_Model_file_error_messages.md>).
- Feature dependency check: Determines whether SmarTest supports the parameter settings defined in the model file. For example, if a memory parameter is insufficient for the memory required, the feature dependency check fails. Another example: The timing bundle must be the same for all channels. If a model file specifies different timing bundles for tests in different channels, an error message is displayed and the software terminates.

In offline mode, if no error has occurred, the requested system configuration and capability is set at this point. The subsequent checks are not performed.

In online mode the process continues:

- Hardware status check: The hardware parameters must be supported by actual hardware capabilities. If an incompatibility is detected an error appears in the report window. The error message says which hardware is installed and which hardware is required for the test.

In this step, the capability requested in the model file is shown in the REQUESTED CONFIGURATION table in the report window. Error messages are displayed just below this table. See [Hardware error](<02.04.05.09.01.03_Hardware_error.md>).

- License check: In online mode enough licenses must be available for all requested configurations and capabilities on the specified channels. If the number of licenses is not sufficient, an error message appears in the report window and the software starts with minimum hardware base capabilities. In offline mode the license for SmarTest offline must be available. If the SmarTest offline license is not available an error message appears and SmarTest terminates.

Based on the model file and device license file, SmarTest generates license requests, sends them to the license server, and checks out the necessary licenses. If the necessary licenses are available, the channels and channel capabilities required in the model or device license file will be enabled. If SmarTest fails to check out the licenses, an error message appears in the report window below the REQUESTED CONFIGURATION table.
