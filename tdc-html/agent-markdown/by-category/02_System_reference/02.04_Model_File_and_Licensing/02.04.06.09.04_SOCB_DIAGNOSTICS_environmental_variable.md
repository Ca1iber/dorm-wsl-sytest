# SOCB_DIAGNOSTICS environmental variable

The SOCBU_DIAGNOSTICS environmental variable is used to diagnose license check out problems. It includes the debug information available with the deprecated FLEXLM_DIAGNOSTCS environmental variable.

Setting this variable to any value provides detailed information about the checkout process for each license.

## Functional changes

- Introduced in SmarTest 7.3.2
