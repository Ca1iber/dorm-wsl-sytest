The web-based Advantest License Renewal Portal is your single access point for renewing your licenses. Renewing licenses usually involves only a few steps; and if your environment did not change, you are done with just four clicks.

- Login to the Advantest site in starting your Web browser and connecting to the Advantest site at [www.advantest.com](<http://www.advantest.com>).
- The Advantest License Renewal Portal is located at: [www.advantest.com/licensing](<http://www.advantest.com/licensing>).
- Click on the V93000 SoC / Smart Scale link.
- Select Renew/Reactivate license (Advantest Renewal Portal) and after logging in, you have access to all tasks belonging to the renewal of licenses.

The Advantest Renewal Portal enables you to:

- Renew and reactivate licenses
- Assign entitlements and check their assignment status
- Download the renewed licenses
- Download records for the License Renewal Comparison Tool Note You can only renew licenses using the License Renewal Portal. For information about activating licenses, see [Activating your licenses](<02.04.05.01.01_Activating_system_licenses.md>).
