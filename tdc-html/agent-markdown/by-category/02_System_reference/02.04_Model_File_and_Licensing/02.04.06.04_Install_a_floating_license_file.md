# Install a floating license file

A copy of the SmarTest floating-license file must be stored on each computer upon which you will want to execute the SmarTest feature.

 Note This topic is applicable to SmarTest 7 and SmarTest 8.

- On each of these computers, create the following directory path:

/opt/flexlm/license

Optionally, you can set the environment variable as follows to specify a different directory to contain Advantest license files:

SOCBU_LICENSE_FILE=<license_file_path>

Set permissions in the new directory so all users have read access.

- Extract the attached file from your license activation (redemption) email message and copy it into this directory on each of the computers and on the license server.
- Give each file a name such as <today's date>.lic and set permissions so all users have read privileges.

The bracketed portion of the license file name can be set to the user's preference or to your company standard. FLEXlm simply looks for files with a .lic extension.

- After installing the license, restart SmarTest.
