# ETC section

The ETC section of the model file can be used to define several parameters that are not appropriate for the other more specific sections. The following are explained here:

## REFERENCECLOCK

The REFERENCECLOCK parameter defines which 10 MHz reference clock signal is used.

## Syntax

```
ETC
  REFERENCECLOCK : input = clock_signal
```

Parameters
 |

input

 |

Specifies which clock signal is used as reference clock signal.

input = INTERNAL | EXTERNAL

where:

 |

INTERNAL

 |

The internal source is used for 10 MHz reference clock signal. This is the default.

 |
 |

EXTERNAL

 |

The external (RF) source is used for 10 MHz reference clock signal. An external clock generator must be connected.

 |

If the reference clock entry is missing, the internal reference clock is used.

 |

## Example

```
REFERENCECLOCK : input = INTERNAL
```
