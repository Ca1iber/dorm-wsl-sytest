# Tagging a pin configuration file with a license lock

When applying Device Specific Licensing (DSL), you add a secure DSLT signature to the pin configuration file. This signature gives access to the device specific license bundle, which has the same license tag, and locks the pin configuration file to one or a group of specific device setups.

To add the signature and lock the set of licenses, you use a command line based tagging tool. The dsltg tool allows you

- to add a secure signature to a pin configuration file,
- to update an existing signature,
- to remove an existing signature, and
- to verify an existing signature.

For these functions, the dsltg tagging tool requires a company specific FLEXlm license, which is provided by Advantest. Only the verification option (verify_tag) requires no license and can be executed anytime.

Before you begin

- Make sure that the line model database is installed (smartest_aslmed*).
- You need to know your license tag, and you must have a complete and correct pin configuration file.

To execute the command

- Open a terminal and change directory to /opt/hp93000/soc/pws/bin
- Type:

dsltg {--tag DevFam} [--list-tag DevFam] [--remove-tag] [--verify-tag] {pin_configuration}

where

 |

[ ]

 |

Brackets indicate optional and extra parameters.

 |
 |

{ }

 |

Braces indicate mandatory parameters.

 |

Parameters
 |

--tag DevFam

 |

Optional parameter. Specifies the license tag.

 |
 |

--list-tag DevFam

 |

Optional parameter. Displays the content of the license tag. It does not require a pin configuration file.

 |
 |

--remove-tag

 |

Optional parameter. Removes an existing signature from the pin configuration file.

 |
 |

--verify-tag

 |

Optional parameter. Verifies if an existing signature in the pin configuration file is still valid, and that the pin configuration was not changed. If yes, it displays the license tag. This parameter requires no license!

 |
 |

pin_configuration

 |

Required parameter (except for --list-tag). Specifies the absolute or relative path to the pin configuration file which should be tagged with a signature or should be checked for the correct signature.

 |

Except for the verify-tag option, the dsltg tagging tool requires a license.

## Example

```
dsltg --tag DevFam /home/user/device/configuration/myPinCon
```

This command adds the DevFam tag and a secure signature to the pin configuration file (myPinCon).

```
dsltg --verify-tag /home/user/device/configuration/myPinCon
```

This command checks the licensing tag and the signature of the pin configuration file (myPinCon).
