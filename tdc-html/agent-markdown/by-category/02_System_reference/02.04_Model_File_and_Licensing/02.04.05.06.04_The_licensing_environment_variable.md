# The licensing environment variable

You can use the V93000_LICENSING environment variable to specify a device license file. It works the same way as the V93000_MODEL variable, which specifies a model file.

You can use the V93000_LICENSING variable in SmarTest startup scripts to provide custom functionalities similar to using the Workorder Manager. For example:

```
#My SmarTest Startup Script
export V93000_LICENSING=./license/<my_test>.license
/opt/hp93000/soc/prod_env/bin/HPSmarTest
```

When using the V93000_LICENSING environment variable, you have several options to specify the path:

- a leading slash ( / ) specifies an absolute path.
- a leading dot -slash ( ./ ) specifies a path relative to the SmarTest startup path.

In all other cases, the specified path is relative to the current device's license directory.

 CAUTION Potential conflict!

When applying the V93000_LICENSING variable, there is a possible conflict between the setting of the licensing environment variable and modifications that may be done in the "Edit Device" user interface dialog.

If the V93000_LICENSING variable is set, the entry in the "Edit Device" dialog is still displayed and can be modified, but it is ignored. That means, the contents of the user interface dialog is kept synchronized with the .technology file, but not evaluated.

The content of the V93000_LICENSING environment variable has higher priority than the configuring with a user interface dialog, for example, using the Workorder Manager, or the configuration stored in the .technology file.

Despite any modification in the "Edit Device" dialog or .technology file, the V93000_LICENSING environment variable has priority and overrules any file name specified in the dialog or in the .technology file.
