# Create a SmarTest license server

An important part of this process involves your identification of a computer that can function effectively as a license server. For an overview of considerations that may affect your choice of a license server that fits your specific test setup, refer to FLEXlm Floating License Server Selection Guide in the LTH/STH Site Planning and Preparation Guide.

 Note This topic is applicable to SmarTest 7 and SmarTest 8. Note If you have previously established a FLEXlm license server for a SmarTest software feature, go to the section [If you have previously installed a FLEXlm license](<02.04.06.03_If_you_have_previously_installed_a_FLEXlm_license.md>).

To create a license server manually on Linux or Sun Solaris, follow these steps:

- Find the FLEXlm license server software on the protected Services & Support web page: https://www.advantest.com/service-support/ic-test-systems/products-list/v93000-licensing > FLEXlm License Server Software Downloads and Documents. The following license server installation files are available for download.

  - flex_install-11.12.1.7_v6-9.el<RHEL version>.x86_64.rpm
  - flex_install-11.12.1.6_v6.u9-1.sun4.tar.gz

- Download the license server installation file according to your operating system. To download the file, click the appropriate item.

## On Linux

- For Red Hat Enterprise Linux 5 or 7 operation systems, install the license server package: Red Hat 5 flex_install-11.12.1.7_v6-9.el5.x86_64.rpm Red Hat 7 flex_install-11.12.1.7_v6-9.el7.x86_64.rpm
- Start the license server (see [License server basic operations](<02.04.06.07_SmarTest_License_server_basic_operations.md>)).

## On Sun Solaris

- For Sun Solaris, make sure that the following directories are created on the computer you have designated as your license server.

 /opt/flexlm/license

 /opt/flexlm/bin

 /opt/flexlm/log

Set permissions on these directories so that all users have read access.

- To unzip and unpack the flex_install-11.12.1.6_v6.u9-1.sun4.tar.gz file use the tar xvzf command. You get the following files:

- lmgrd:the license server executable

- lmutil: the license server utility

- socbu: the license vendor daemon

- Set permissions for each file so that the appropriate user who will start the license server, can execute the files.
- Copy the lmgrd, lmutil`, ` andsocbu executable files to the directory /opt/flexlm/bin.
- Start the license server (see [License server basic operations](<02.04.06.07_SmarTest_License_server_basic_operations.md>)).
