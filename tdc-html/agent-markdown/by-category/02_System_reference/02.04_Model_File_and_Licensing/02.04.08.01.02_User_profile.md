# User profile

After logging in to the Advantest Licensing Renewal Portal, you can access the User profile page, which displays information about your Advantest License Renewal account.

## About this task

You can display the following information about your Advantest customer account name:

- User name
- E-Mail address associated with your Advantest License Renewal account
- Roles assigned to you and their associated organizations

## Before you begin

Log in to the Advantest License Renewal Portal.

## Procedure

 To display information about your Advantest License Renewal account, click your user name at the upper-right of the License Renewal Portal.

## Results

You User Profile page is displayed.
