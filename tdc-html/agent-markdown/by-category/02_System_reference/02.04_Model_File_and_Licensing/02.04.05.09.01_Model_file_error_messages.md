# Model file error messages

#### Subtopics

- [Parser syntax error](<02.04.05.09.01.01_Parser_syntax_error.md>)
- [Feature dependency error](<02.04.05.09.01.02_Feature_dependency_error.md>)
- [Hardware error](<02.04.05.09.01.03_Hardware_error.md>)
- [License number error](<02.04.05.09.01.04_License_number_error.md>)

Model file error messages, also called IOCHANNEL error messages, belong to one of four types:

- parser syntax error
- feature dependency error
- hardware compatibility error
- license number error

These error types are explained in the topics of this section, along with the steps to correct the problem.

## Functional changes

- Introduced before SmarTest 6.3.2
