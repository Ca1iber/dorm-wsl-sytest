# Channel range conversion

This topic describes the channel range conversion script for SmarTest model files.

You can address IO channels in a range from x0001 to x6416, with x= [1..8].

A range, in which the first digit (x) changes, for example, 10101 - 23216,. includes the channels x13216 - x16416, in this example: 13216 - 16416.

For compatibility reasons with older model files, the channel numbers of a range must start with the same digit. Refer to MCDIgnore syntax and usage for the background.

In the example from above, the range 10101 - 23216 must be split up into the following two ranges:

10101 - 13216

20101 - 23216

The ChannelRangeConversion.perl script converts older model files that they apply to the syntax.

## Syntax

```
ChannelRangeConversion.perl [-r] [-c] [-l <logfile>] <original model file> [converted model file]
```

## Parameters

 |

r

 |

Replace the original file without creating a backup

 |
 |

c

 |

Checks, if a conversion is needed

 |
 |

l <logfile>

 |

Logs the conversion result to <logfile>

 |
 |

<original model file>

 |

Specifies the model file that shall be converted

 |
 |

converted model file

 |

Specifies the converted model file

 |
 |

h

 |

Shows the help

 |

## Example

```
ChannelRangeConversion.perl -l ChConvMF.log model_714 model_720
```

In this example the script converts the content of the model file model_714, saves it to the file model_720, and writes the conversion results to the file ChConvMF.
