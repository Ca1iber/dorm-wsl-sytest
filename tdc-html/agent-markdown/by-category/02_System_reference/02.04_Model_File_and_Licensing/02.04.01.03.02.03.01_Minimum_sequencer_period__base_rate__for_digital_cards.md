# Minimum sequencer period (base rate) for digital cards

## Digital cards

The minimum sequencer period (base rate) depends on the digital card (hardware), the available speed license, and the number of actions (edges) used in a waveform. The tables below show the minimum sequencer period for individual digital cards. Read the tables as follows:

 |

For example, on the Pin Scale 1600 card with a 533 Mbps speed license and 3 actions (edges) per waveform, your minimum sequencer period is 5.628 ns.

For details on the setting of the sequencer period and the minimum period restrictions of DPS128/DPS64 cards, see [Minimum period / maximum frequency of the sequencer](<../02.08_Setup_and_Result_Tools/02.08.04.34.06.05.01_Minimum_period___maximum_frequency_of_the_sequencer.md>), [Defining the period](<../02.06_Command_Reference/02.06.06.01.07.03_Defining_the_period.md>) (for fixed timing), and [Defining the global period](<../02.06_Command_Reference/02.06.06.01.04.01.01_Defining_the_global_period.md>) (equation based timing).

## Data rate licensing

While drive actions (edges) are licensed on the PS9G card, receive actions (edges) are "free" on PS1600 cards starting with SmarTest 7.1.3.

## Functional changes

- SmarTest 7.0.1: New cards: HSM6800 and HSM3G
- SmarTest 7.1.0: New cards: PS9G, PS1600
- SmarTest 7.1.0: Extended base capability for Pin Scale 3600
- SmarTest 7.1.3: Receive actions not licensed for PS1600
- SmarTest 7.1.3: New card: HSM8G
- SmarTest 7.10.0: HSM cards not supported
