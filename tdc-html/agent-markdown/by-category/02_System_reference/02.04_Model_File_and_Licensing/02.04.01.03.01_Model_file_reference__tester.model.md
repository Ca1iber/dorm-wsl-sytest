# Model file reference (tester.model)

#### Subtopics

- [GLOBAL section](<02.04.01.03.01.01_GLOBAL_section.md>)
- [CARD_CONFIGURATION section](<02.04.01.03.01.02_CARD_CONFIGURATION_section.md>)
- [ETC section](<02.04.01.03.01.03_ETC_section.md>)
- [DMM section](<02.04.01.03.01.04_DMM_section.md>)

Configuration files called model files are used by SmarTest to set the test head hardware configuration - equipped cards, pogo cable assemblies, and their connections to pogo blocks. The default name of the model file is tester.model.

 Note If you require information about the legacy model file, refer to [Model file reference (model/legacy)](<02.04.01.03.02_Model_file_reference__model_legacy.md>). To convert legacy model files to the latest format, use the ModelFileConverter tool located at: /opt/hp93000/soc/system/sbin/ModelFileConverter. For details, see [Converting legacy model files](<02.04.01.04_Converting_legacy_model_files.md>).

## tester.model file structure

The tester.model file is organized in the following sections:

  [GLOBAL](<02.04.01.03.01.01_GLOBAL_section.md>)  Specifies what kind of system is used and what features are available system-wide. [CARD_CONFIGURATION](<02.04.01.03.01.02_CARD_CONFIGURATION_section.md>) Specifies the physical position of all the cards and the mapping between card slots (the physical position of the cards) and pogo blocks on the DUT interface. [ETC](<02.04.01.03.01.03_ETC_section.md>) Defines several general parameters, for example the reference clock. [DMM (Digital Multimeter)](<02.04.01.03.01.04_DMM_section.md>) Section specifies optionally installed external digital multimeters.

## Example

The following is an example of a tester.model file:

```
GLOBAL
   testhead = TH_8CC
   dut_interface = SOC_8GROUP
   hpib_interface = vxi11/e5810a/192.168.0.100/gpib0
   utility_lines = 64, type=static, pogo_size=16
   mux_boards = 8, type=PMUX01, pogoblocks=866,868,870,872,881,883,885,887

CARD_CONFIGURATION
   slot = 301, HW=PS1600, pogoblocks=101-108
   slot = 303, HW=WSMX,   pogoblocks=HS:(231 631) HR:(233 633), type=HD2x32
   slot = 310, HW=DPS128, pogoblocks=HC:(201-208)
   slot = 116, HW=WSRF,   pogoblocks=901-902, source=933

```

The default tester.model provided in /etc/opt/hp93000/soc/ is a template model file for illustration purposes only. For example, the PS5000 card can only be used in EXA Scale™test systems. PS1600 and PS5000 cards cannot be installed simultaneously in an EXA Scale™test system. For details, refer to the dedicated model file sections for each card using the links in the section [Detailed model file information](<02.04.01_The_model_file.md#_55954__model_file_links>).
