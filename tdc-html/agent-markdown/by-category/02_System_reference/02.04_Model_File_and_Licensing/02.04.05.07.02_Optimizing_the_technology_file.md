# Optimizing the technology file

This topic describes how you get the numbers of used sets to optimize the technology file.

## About this task

To optimize the [Technology file for a device](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.01.02_Technology_file_for_a_device.md>), you can adapt the number of sets to the number of used sets.

The [Testflow Analyzer tool (TAT)](<02.04.05.07_The_Testflow_Analyzer_Tool__TAT.md>) provides the number of sets used by the current device in a comment section:

- Level sets
- DPS sets
- Wavetables
- Timing sets

Example:

```
################################################
# #
# Number of sets used by this device: #
# Level Sets: 220 #
# DPS Sets: 79 #
# Wavetables: 128 #
# Timing Sets: 726 #
# #
################################################
```

## Procedure

-  In the technology file edit the set numbers according to the numbers TAT provided, see [Editing technology data](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.10.03.03_Editing_technology_data.md>).
-  Change the device, see [Changing the device with the Change Device button](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.10.03.02_Changing_the_device_with_the_Change_Device_button.md>)
-  Load all setup data
-  Execute TAT to determine the new sequencer memory sizes, see [The Testflow Analyzer Tool](<02.04.05.07_The_Testflow_Analyzer_Tool__TAT.md>)
