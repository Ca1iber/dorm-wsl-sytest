SmarTest licensing concepts and mechanisms are manifold and allow you to optimize license usage and license requirements at your site.

## Managing licenses

For Pin Scale hardware all SmarTest and V93000 test card features are controlled by FlexNet licensing. This third-party license management software allows for efficient use of licenses as it makes software licenses available anywhere on a network.

For the underlying concepts of providing licenses in a network see [License clients and license servers](<02.04.04.03_License_clients_and_license_servers.md>). For further insights see [Maximizing Advantest's V93000 Per Pin Tester Optimal FLEXlm License Server Setup](<../../03_Use_cases_and_application_papers/03.14_Application_Papers/03.14.07.01_Maximizing_Verigy_s_V93000_Per_Pin_Tester_Optimal_FLEXlm_License_Server.md>). This application paper outlines different ways to set up license servers to maximize their benefit. For the required editing of license files in a network see also [Editing .lic license files](<02.04.05.01.04_Editing_.lic_license_files.md>).

## Two license types: System licenses and Software licenses

You must differentiate between two license types:

- [System licenses](<02.04.05.01_The_System_.lic_license_files.md>), which allow you to scale test system capabilities like speed and memory.
- [Software licenses](<02.04.05.02_The_Software_.lic_license_files.md>), which enable SmarTest release streams and service and support software tools.

## Activating and renewing System licenses

System licenses must be activated before you can use the corresponding licensed V93000 product or feature. For details see [Activating your licenses](<02.04.05.01.01_Activating_system_licenses.md>).

Besides this first activation, you must renew your system licenses annually. That is, while a system license gives you a permanent right-to-use, you must renew your system licenses annually during the month of January. For details, see [License Renewal Process](<02.04.08_License_Renewal_Process.md>).

## Handling Software licenses

A software license, also referred to as Software and Support (S&S) license, is built from several components:

- SmarTest online license (`Smartest SOC socbu ... permanent uncounted`).

This component is required to start SmarTest in online mode and tied to the SmarTest version. It is permanent and includes all patches of a release stream.

- Software online value packages (`S&S value package SOC socbu 2.0 ...`) for example, for the calibration data converter.

These components are valid for the duration of the initial warranty period and subsequently for the duration of the support contract.

Both above components are locked to the serial number of the test system. They do not need to be activated and they are not part of the annual renewal process.

- Software offline tools package (`S&S tools package socbu 1.0 ...`).

This component is not locked to a serial number. For the specification of a license server for the offline tools package see [Editing .lic license files](<02.04.05.01.04_Editing_.lic_license_files.md>).

## Requesting licenses

SmarTest system feature licensing is based on two concepts:

- The model file concept
- The device license file concept

In the model file, you set the configurations and features of the test system and thus scale the resources required for your addressed tests.

In the device license file, you define the test system resources as required by the device. The device license file uses the same syntax as the model file and thus extends that concept. For optimum license usage, you should apply the Testflow Analyzer Tool (TAT) which analyzes the test flow and generates a device license file.
