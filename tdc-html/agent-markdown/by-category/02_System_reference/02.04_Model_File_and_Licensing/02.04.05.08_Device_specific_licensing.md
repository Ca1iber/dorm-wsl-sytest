# Device specific licensing

#### Subtopics

- [Tagging a pin configuration file with a license lock](<02.04.05.08.01_Tagging_a_pin_configuration_file_with_a_license_lock.md>)
- [Disabling a pin configuration license lock](<02.04.05.08.02_Disabling_a_pin_configuration_license_lock.md>)

Device Specific Licensing (DSL) combines a predefined bundle of licensed features and locks it to a specific test program and device setup. Before releasing a test program, you can tag it with a company-specific secure signature. This signature gives access to the device specific license bundle. In certain outsourcing situations this provides additional security.

All other licensing related aspects are the same as with standard perpetual InstaPin licenses. That is, for example, the license bundle is perpetual and must be reactivated (renewed) annually.

## Tools, commands and files

Device Specific Licensing uses a secure signature (DSLT - DeviceSpecificLicenseTag) in the pin configuration file to lock a license bundle to a specific test program.

You use the command-line-based dsltg tagging tool to add a DSLT signature to the pin configuration. Besides that, the tool allows you to update, remove, and verify DSLT signatures.

Except for the verification, the tagging tool requires a company specific license, which is provided by Advantest. For details see [Tagging a pin configuration file with a license lock](<02.04.05.08.01_Tagging_a_pin_configuration_file_with_a_license_lock.md>).

The DSLT signature assures that the given license tag is consistent with the license tag specified in the device license file, and that the signature is valid based on the configured pins.

The DSLT signature is added as the last command in a pin configuration file. Once it is executed, the pin configuration can no longer be changed. To disable a device specific license lock you can use several firmware commands: *RST (ReSeT), UDAN (UnDefine ANalog pin), UDEF (UnDEFine pin), and UDPS (Undefine DPS pin). For details see [Disabling a pin configuration license lock](<02.04.05.08.02_Disabling_a_pin_configuration_license_lock.md>).

The SmarTest report window shows the number of licenses acquired via DSL. For details see [Configuration information in the report window](<02.04.05.05_Configuration_information_in_the_report_window.md>).

Note All DSL based setups require a device license file and the DSL entry for device specific licensing. For details see [Device license file syntax](<02.04.05.06.02_Device_license_file_syntax.md>).
