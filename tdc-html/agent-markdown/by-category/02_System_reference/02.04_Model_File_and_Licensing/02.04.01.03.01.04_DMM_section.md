# DMM section

In the DMM (Digital Multimeter) section you specify optionally installed external digital multimeters.

## Syntax

```
DMM
  unit: cardcage= CC_number, type= DMM_type, address= GPIB_address
```

Parameters
 |

unit

 |

The unit number (1: ... 8:) is the unique identifier of the digital multimeter (DMM) definition.

 |
 |

cardcage

 |

The number specifies the card cage to which the digital multimeter is connected. Only one instrument can be connected per card cage.

 |
 |

type

 |

Describes the digital multimeter type. For example, `type=HP3458A` specifies the Agilent 3458A Digital Multimeter.

 |
 |

address

 |

Configures the multimeters GPIB address, which is used for the communication with the multimeter. The GPIB interface must be defined in the GLOBAL section.

 |

## Example

The example specifies a DMM for card cage 1.

```
GLOBAL
...
  hpib_interface = vxi11/192.168.0.100/gpib0
...
DMM
  1: cardcage=1,type=HP3458A,address=22
...
```
