# Single License server installation, upgrades and updates

Installation procedure for a single FlexNet Embedded license server to provide activated licenses. Applicable to fresh installations, and applying upgrades to add major functionality and patch updates installing the latest packages on an existing server.

## About this task

The license server install script is available from the V93000 Linux RHEL 7 Recovery DVD for RHEL 7 Workstations DVD or can be downloaded from the Advantest FTP server:

[ftp.advantest.com/Licensing/FNE_SW](<ftp://ftp.advantest.com/Licensing/FNE_SW>).

All customers with support contracts may access the ftp.advantest.com site. A username and password for access to the ftp.advantest.com site can be requested from:

https://www.advantest.com/en/service-support/ic-test-systems/products-list/v93000-smartest-system-software-downloads

 The script name takes the following form: install-fne-<date>-<version>.sh.Note If you are upgrading an existing installation, a running license server is automatically stopped as part of the new software installation.

The following procedure is applicable to installation, upgrades and updates. However, registering the server is only required for initial installation. This steps should be omitted for upgrades and updates.

  Note During upgrading and updating, the installation script can be called without any option. All installed packages are detected automatically and updated if applicable.

## Before you begin

 CAUTION For failover arrangements, do not follow this procedure. Refer to [Failover license server installation, upgrades and updates](<02.04.13.01.02_Failover_license_server_installation__upgrades_and_updates.md>). Make sure that the system hosting the FlexNet Embedded license server host system meets the hardware and operating system prerequisites. For details, see [FlexNet Embedded license server setup](<02.04.13.01_FlexNet_Embedded_license_server_setup.md>).

## Procedure

-  Load the V93000 Linux RHEL 7 Recovery DVD for RHEL 7 Workstations DVD or download the install-fne-<date>-<version>.sh script to: /tmp/fne.
-  If dowloading the package, check it for integrity:

./install-fne-<date>-<version>.sh test

-  Start the installation:

  -

Standard installation with support for SmarTest 8 and older SmarTest releases (FNE and FNP licenses):

sudo sh install-fne-<date>-<version>.sh fnx

The FNX front-end server that converts legacy lmgrd FNP license calls into FNE license call is also installed, providing support for SmarTest versions 5, 6 and 7.

  -

Standard installation with support for SmarTest 8 only (FNE licenses only):

sudo sh install-fne-<date>-<version>.sh server

After installation, the FNE license server is automatically started.

  This also installs the [FNE Server Viewer](<02.04.13.04_Monitoring_license_servers_using_the_FNE_Server_Viewer.md>).
-  To display the readme file:

sh install-fne-<date>-<version>.sh readme

## Results

The FNE license server and the FNE Server Viewer are installed.

To check if the FNE license server is running:

/opt/flexnetls/socbu/fne-status

If the FNE license server is running, the following type of output is displayed:

```
* advantest-fne-server.service - Flex Net Embedded license server adapted for Advantest
   Active: active (running) since Mon 2019-05-20 11:08:14 CEST; 3 days ago
* advantest-fne-server-viewer.service - Advantest Flex Net Embedded License Server Viewer
   Active: active (running) since Mon 2019-05-20 11:06:48 CEST; 3 days ago
* advantest-fne-proxy.service - Advantest FNP2FNE proxy
   Active: active (running) since Mon 2019-05-20 11:07:36 CEST; 3 days ago

```

To check if the FNE Server Viewer is running, enter the following URL in a browser:

http://<serverName>:7077
