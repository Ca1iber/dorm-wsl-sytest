# The Testflow Analyzer Tool (TAT)

This topic describes the function and general usage of the Testflow Analyzer Tool (TAT).

With the TAT you can generate device license files (DLF) for every hardware combination to determine the required license minimum. This information you can use to optimize your license usage.

The TAT generates a device license file (.licenses) based on the given testflow and the hardware definition file (HDF) or model file. The [hardware definition file](<02.04.05.07.04_The_hardware_definition_file__HDF.md>) describes the hardware of your tester (type, cards, memory mode).

TAT is a command line tool. Some of its optional parameters require the installation of a [line model encrypted database](<02.04.05.07.01_Installing_the_line_model_encrypted_database.md>) (smartest_aslmedb*).

Before starting TAT, make sure that:

- SmarTest is running
- A testflow is loaded

To start TAT and generate the device license file enter the following:

- `/opt/hp93000/soc/prod_pws/bin/tat -f <filename>`

`-f` is a must parameter. <filename> is either the hardware definition file (HDF), a model file, or an already existing device license file. For other optional parameters see [How to generate and provide a device license file](<02.04.05.07.03_How_to_generate_and_provide_a_device_license_file.md>).

The testflow analyzer tool (TAT) analyzes the testflow and generates a device license file (.licenses) in the current directory. The generated device license file lists only the minimum needed capabilities for the given testflow.

 Note TAT does not change and optimize the technology file, see [Optimizing the technology file](<02.04.05.07.02_Optimizing_the_technology_file.md>), but provides the number of used sets:

The [Testflow Analyzer tool (TAT)](<02.04.05.07_The_Testflow_Analyzer_Tool__TAT.md>) provides the number of sets used by the current device in a comment section:

- Level sets
- DPS sets
- Wavetables
- Timing sets

Example:

```
################################################
# #
# Number of sets used by this device: #
# Level Sets: 220 #
# DPS Sets: 79 #
# Wavetables: 128 #
# Timing Sets: 726 #
# #
################################################
```

TAT will not list the following SmarTest features:

- Per Pin TIA (ppTIA)
- Rapid Source Sync (RSS)
- Xpress Data Mode (xpressdata)
