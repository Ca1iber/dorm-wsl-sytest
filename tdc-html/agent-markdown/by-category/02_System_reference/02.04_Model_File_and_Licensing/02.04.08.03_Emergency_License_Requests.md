# Emergency License Requests

#### Subtopics

- [Logging in](<02.04.08.03.01_Logging_in.md>)

- [Installing emergency licenses after failure and replacement of the license server](<02.04.08.03.03_Installing_emergency_licenses_after_failure_and_replacement_of_the_licen.md>)
- [Installing emergency licenses for license servers unavailable due to network problems](<02.04.08.03.04_Installing_emergency_licenses_for_license_servers_unavailable_due_to_net.md>)

The web-based, Advantest Emergency License feature, accessed from the Advantest homepage, is your access point for requesting emergency licenses. You can obtain, with the minimum of delay, emergency application software licenses or hardware feature licenses, to solve a manufacturing problem caused by a failed or otherwise inoperable or in accessible license server.

To access the Advantest Emergency License feature, you must login with your Advantest customer login.

 Note Emergency licenses are available for emergency circumstances only and are valid for 10 days only, providing you with time to rehost your full licenses.

## When to request emergency licenses

Emergency licenses are required and will be provided in the following cases:

- The license server suffers a serious malfunction (for example, motherboard or hard disc drive failure). See also [Installing emergency licenses after failure and replacement of the license server](<02.04.08.03.03_Installing_emergency_licenses_after_failure_and_replacement_of_the_licen.md>).

In the case of a server that has been catastrophically damaged, you will also have to rehost your original licenses. See [Replacing licenses after a server problem](<02.04.06.09.08_Replacing_licenses_after_a_server_problem.md>). Rehosting can take several days during which time emergency licenses can be used to allow your testers to continue running.

- Your network is not accessible. See also [Installing emergency licenses for license servers unavailable due to network problems](<02.04.08.03.04_Installing_emergency_licenses_for_license_servers_unavailable_due_to_net.md>).

## What you should do before requesting emergency licenses

When applying for emergency licenses, you should be aware of the following:

- Notify your Advantest sales representative as soon as possible by voice or email before you apply for a license.
- Take all reasonable steps to restore operation to your original license server or rehost your licenses.

## What you should know when requesting emergency licenses

To receive an emergency license, you must provide the following information:

- Valid user account to login to the Advantest Emergency License feature. Alternatively you can login with a valid entitlement ID.
- Host ID and hostname of the system controller hosting the replacement license server.
