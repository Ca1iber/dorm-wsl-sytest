# Error handling

#### Subtopics

- [Model file error messages](<02.04.05.09.01_Model_file_error_messages.md>)

There are several kinds of error messages you may see while running device tests:

- Model file errors

Model file error messages, or IOCHANNEL error messages, relate to your test setup. They can be either either parser syntax errors, feature dependency errors, hardware compatibility errors, or license number errors. For details see [Model file error messages](<02.04.05.09.01_Model_file_error_messages.md>).

- FlexNet licensing errors

These are either license server, license client, or license file errors. FlexNet provides error messages that can help guide you in diagnosing the problem. For details see [FLEXlm license error messages](<02.04.06.09.01_FLEXlm_license_error_messages.md>).

Status and error messages of the FlexNet license server can be written to a debug log, see [Using the FLEXlm debug log](<02.04.06.09.03_Using_the_FLEXlm_debug_log.md>). For a complete listing of possible debug log messages see Appendix G of the FlexNet Licensing End User Guide. You can find the guide at the [Advantest Web Site](<http://www.advantest.com>).

FLEXnet Licensing End User Guide at the [Advantest Web Site](<http://www.advantest.com>): Advantest Home > Service & Support > V93000 SOC/HSM > Licensing > FLEXIm License Server Software Downloads and Documents > FLEXlm End Users Guide.
