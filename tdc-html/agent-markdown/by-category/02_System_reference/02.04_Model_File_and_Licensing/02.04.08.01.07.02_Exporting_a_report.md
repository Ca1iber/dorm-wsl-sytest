# Exporting a report

You can export the results of the preconfigured license reports available from the dropdown menu. The reports show you the renewal completion result related to the entitlement IDs assigned to your user account.

## About this task

You will export the displayed report results to a file in Microsoft Excel or CSV format. To export the displayed report, complete the steps listed below.

## Before you begin

Make sure that the report results that you want to export are displayed.

## Procedure

-  In the Reports tab of the Advantest Renewal Portal, make sure that the report results that you want to export are displayed.
-  Click Excel or CSV to select the format of the report file to be exported.
-  Download and save the report file to your computer.

## Results

The selected report results are saved to a file in the selected format and downloaded to your computer or storage location.
