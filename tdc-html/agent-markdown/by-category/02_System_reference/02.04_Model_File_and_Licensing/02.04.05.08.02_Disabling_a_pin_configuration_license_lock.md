# Disabling a pin configuration license lock

Device Specific Licensing (DSL) adds a secure signature to the pin configuration file. This signature gives access to the device specific license bundle, which has the same license tag, and locks the pin configuration file to one or a group of specific device setups.

## About this task

Several firmware commands can disable a device specific license lock, in other words, disable a pin configuration file. These firmware commands are *RST (ReSeT), UDAN (UnDefine ANalog pin), UDEF (UnDEFine pin), UDPS (Undefine DPS pin), UDUP (UnDefine Utility Purpose), and UDUT (UnDefine UTility line).

CAUTION When you execute *RST, UDAN, UDEF, UDPS, UDUP, or UDUT, you invalidate the device-specific-license signature and disable all setup related firmware commands (VECC, VECD, SQLB, DMAS). To reactivate the commands you must reload the pin configuration. At the same time you enable again all pin configuration related commands: CONF (CONFiguration), CTXT (ConTeXT), DDSL (Define Dps SLaves), DFAN (DeFine ANalog pin), DFPN (DeFine Pin Name), DFPS (DeFine Power Supply), DFUT (DeFine UTility line), DFUP (DeFine Utility Purpose), and PALS (Pin ALlocation for multiple Sites).Note Although locked with a DSLT signature, you can change the pin configuration within limits. You cannot delete pins, but other modifications like moving pins, are allowed. You can change the pin configuration up to 5 times. Each change triggers a warning. Exceeding the limit of 5 modifications triggers an error that to many pins failed. In this case you must create a new DSLT signature.

## Before you begin

Check that the pin configuration file is tagged with a license lock. For details see [Tagging a pin configuration file with a license lock](<02.04.05.08.01_Tagging_a_pin_configuration_file_with_a_license_lock.md>).

## Procedure

 To disable a device specific license lock in a pin configuration file, execute one of the following commands:

- [*RST - (ReSeT)](<../02.06_Command_Reference/02.06.02.02.345_RST_-__ReSeT.md>)
-
- [UDEF - (UnDEFine pin)](<../02.06_Command_Reference/02.06.02.02.295_UDEF_-__UnDEFine_pin.md>)
- [UDPS - (Undefine DPS pin)](<../02.06_Command_Reference/02.06.02.02.298_UDPS_-__Undefine_DPS_pin.md>)
- [UDUP - (UnDefine Utility Purpose)](<../02.06_Command_Reference/02.06.02.02.301_UDUP_-__UnDefine_Utility_Purpose.md>)
- [UDUT - (UnDefine UTility line)](<../02.06_Command_Reference/02.06.02.02.302_UDUT_-__UnDefine_UTility_line.md>)

## Results

The device-specific-license signature is no longer valid, the pin configuration file is unlocked, and the pin configuration related commands are enabled again.
