# The device license file

#### Subtopics

- [License evaluation](<02.04.05.06.01_License_evaluation.md>)
- [Device license file syntax](<02.04.05.06.02_Device_license_file_syntax.md>)
- [Defining the device license file to be used](<02.04.05.06.03_Defining_the_device_license_file_to_be_used.md>)
- [The licensing environment variable](<02.04.05.06.04_The_licensing_environment_variable.md>)

The concept of licensing-per-device is based on a licensing file for each device, the device license file. This concept allows you to better utilize your licenses by requesting only those licenses from the license server that are really required for a device.

Licensing-per-device does not break the known [model file concept](<02.04.01_The_model_file.md>) and mechanisms. It is rather an add-on and enhancement of that concept. Therefore the device license file must contain only license relevant entries. To ensure compatibility the device license file uses the same syntax as the [model file](<02.04.01.03_Model_file_sections.md>).

Licensing-per-device works both offline and online.

 Note If a device license file (.license) exists, make sure it is not empty.

The content of a device license file overrides all license specific entries in the model file. If for example, you specify a device license file without any licensing capabilities, the license definitions in the model file will simply be ignored.

If you work with several device license files, you must specify the one to use. For details see [Defining the device license file to be used](<02.04.05.06.03_Defining_the_device_license_file_to_be_used.md>).

## The structure

The structure of the device license file is a subset of the model file. The device license file does not replace the model file, but extends it. It lists those features that need to be licensed, like speed, memory, etc. Non-license relevant entries like test head, etc. belong into the model file.

For a list of licensed V93000 features and products see [Licensed V93000 products](<02.04.02.01_V93000_License_Master_Look-up_Table.md>).

For parameters to be used in the device license file only, see [Device license file syntax](<02.04.05.06.02_Device_license_file_syntax.md>).

To use licensing-per-device, a directory named "license" must exist in your device-directory, and your device license files must reside in this sub-directory: <device-directory>/license.

Alternatively you can specify a device license file using the V93000_LICENSING environment variable.

For the device license files in the license directory Advantest recommends to use the file name extension ".license". The file base name may reflect your different test scenarios, for example "finalTest.license", "waferSort.license", etc.

The "example device license file" at /opt/hp93000/soc_<version>/pws/data/per-device-license.defdocuments the device license file syntax and serves as device license file example.

## The Testflow Analyzer Tool (TAT)

You can either develop your own device license files based on the provided example file or use the [Testflow Analyzer Tool (TAT)](<02.04.05.07_The_Testflow_Analyzer_Tool__TAT.md>). The latter is recommended.
