This section describes the model file structure and associated syntax for the legacy type model file. This model file is used only with the V93000 Smart Scale systems.

## Legacy model file structure:

  [GLOBAL](<02.04.01.03.02.01_GLOBAL_section.md>)  Specifies what kind of system is used and what features are available system-wide. [POGOCABLING](<02.04.01.03.02.02_POGOCABLING_section.md>) Specifies the mapping between the physical position of the channel cards and the pogo blocks of the DUT interface. [IOCHANNEL](<02.04.01.03.02.03_IOCHANNEL_section.md>) Specifies the master configuration for the test system. [ETC](<02.04.01.03.02.05_ETC_section.md>) Defines several general parameters. [DPS](<02.04.01.03.02.06_DPS_section.md>) Specifies each available DPS card, including DC Scale cards. [DMM (Digital Multimeter)](<02.04.01.03.02.07_DMM_section.md>) Specifies optionally installed external digital multimeters.
