# Installing emergency licenses for license servers unavailable due to network problems

If your network is not reachable, you must install a local license server and emergency license on each of your test system controllers (workstations).

## Before you begin

Provide the host ID and host name of every controller and obtain one (1) emergency license for each controller.

If, for example, you have a network problem and 5 workstations are affected, you must get 5 emergency licenses to establish 5 local license servers (one on each workstation).

For details, see [Requesting emergency licenses](<02.04.08.03.02_Requesting_emergency_licenses.md>).

After you have received the emergency licenses, complete the following steps on each test system controller (tester workstation):

## Procedure

-  Stop any other running local license servers.
-  If not already available, install the FLEXlm executables (lmgrd, lmutil, ...) in the directory: /opt/flexlm/bin.

If you do not have the executables, download them from:

[https://www.advantest.com/service-support/ic-test-systems/products-list/v93000-licensing](<http://www.advantest.com>) and go to FLEXlm License Server Software Downloads and Documents

-  Create the directory: /opt/flexlm/ELF
-  Copy the emergency licenses to the /opt/flexlm/ELF directory.
-  Start lmgrd pointing to the /opt/flexlm/ELF directory:

```
/opt/flexlm/bin/lmgrd 鈥揷 /opt/flexlm/ELF 鈥搇 /opt/flexlm/log/<logfilename>
```

-  To ensure that SmarTest accesses the emergency license, set the SOCBU_LICENSE_FILE environment variable to the /opt/flexlm/ELF directory.

## What to do next

After the network problems are fixed:

- Emergency licenses and any backups must be deleted.
- SOCBU_LICENSE_FILE environment variable must be reset on every test system controller (workstation).
- License server process lmgrd, pointing to the /opt/flexlm/ELF directory, must be stopped.
