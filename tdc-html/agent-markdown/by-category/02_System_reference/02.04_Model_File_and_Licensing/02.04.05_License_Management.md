Configuration and license management on a license client means, efficiently administering the licenses you use with your test system, diagnosing licensing problems, and being familiar with tools and utilities to optimize license usage.

For these tasks you must differentiate between two license types:

- [System licenses](<02.04.05.01_The_System_.lic_license_files.md>), which allow you to scale test system capabilities like speed and memory.
- [Software licenses](<02.04.05.02_The_Software_.lic_license_files.md>), which cover SmarTest release streams and service and support software tools.

For the handling of Service and Support (S&S) licenses see [Enabling software licenses](<02.04.05.02.01_Enabling_software_licenses.md>).

For information on how to define scalable system license usage see

- [The model file](<02.04.01_The_model_file.md>),
- [The device license file](<02.04.05.06_The_device_license_file.md>), and
- [The Testflow Analyzer Tool (TAT)](<02.04.05.07_The_Testflow_Analyzer_Tool__TAT.md>).

For information on installing licenses see also the "Installing your FLEXlm license" chapter of the "Site Planning and Preparation Guide" in the SmarTest Service Documentation.
