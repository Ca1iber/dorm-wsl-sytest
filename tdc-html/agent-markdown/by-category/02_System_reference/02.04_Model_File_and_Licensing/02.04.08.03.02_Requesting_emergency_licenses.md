# Requesting emergency licenses

Requesting emergency license requires you to complete a short web-based form, supplying some basic information about the affected license servers, host system names, and some contact information.

## Before you begin

Before you can request emergency licenses, you must be logged in at the Advantest Emergency License feature and you must have information about the affected license servers that need emergency licenses.

## Procedure

-  To request emergency licenses for a license server, complete the Emergency License Facility form and send the request to Advantest:
-  Enter the server ID of the license server that needs to be replaced.

If the affected license server is configured as a three-redundancy license server (Triad), enter the Server ID of only ONE of the three license servers.

 Note If you have a login with a user name, there will be license servers listed in the selection list belonging to your assigned organizations. If the affected license server is not listed, you can enter it manually.
-  For the replacement license server, select the server type (Single or Triad) and specify the Host ID and hostname. Note If a single license server must be replaced (affected license server) and it is also used as a SmarTest workstation on which there are node-locked licenses installed locked to that workstation, you must select Single license server as the server. This ensures that the node-locked licenses are also rehosted on the replacement shared SmarTest workstation/license server.
-  Enter the name of the organization for which the Emergency license is to be generated.
- Optional:  Add city and country location information.
-  Enter the reason for requesting emergency licenses. Use one of the available options from the dropdown list or enter an alternative reason in the associated field.
-  Enter the name and email address of your local Advantest representative.
-  If you would like to send the emergency licenses to additional personnel, for example, your system administrator, add their email address to the Send license to other email addresses field.
-  When you have entered all required information, click Get License. Note The Get License button is active only if all mandatory fields are correctly completed. Clear Form clears all fields.
-  Read the Terms and Conditions. To accept, click Agree and Proceed.

A message window opens informing you that the emergency license has been sent successfully.

-  Log out or repeat the above steps to get another emergency license.

## Results

The emergency license request is sent to Advantest.

## What to do next

You will receive your emergency licenses as an attachment by email (license.zip). Install these emergency licenses on your license server. The expiration date of the emergency license is stated in the email.
