# License evaluation

In a licensing-per-device setup, licenses are requested in the following cases:

- at software start-up
- at "change-device" operations

In both cases license evaluation is a two-step-process:

## Step 1:

First the model file is evaluated. The model file must be either at its default location or as specified by the V93000_MODEL environment variable.

## Step 2:

Second - if specified - the device license file is evaluated. The device license file must be either at its default location in the licenses directory, or as specified by the V93000_LICENSING environment variable.

All previously given licensing information in the model file becomes invalid. Only the license requests of the device license file are considered.

Note Make sure the device license file is not empty!

The content of a device license file overwrites any specifications in the model file. If for example, you specify a device license file without any licensing capabilities, the license definitions in the model file will simply be ignored.

 ![Licensing evaluation sequence](<../../../../raw/85737.png>)

To use licensing-per-device you must have a device directory named "license". This directory contains the device license files. As file name extension of a device license file we recommend ".license". The file base name may reflect your different test scenarios, for example, "finalTest.license", "waferSort.license", etc.

If a specified device license file cannot be loaded, an error is generated and the licensing information given in the model file stays valid. The same is true if a device license file is not specified at all.

The model file must be loaded as well, as it contains configuration data for the test system (for example the DUT interface or the cabling of analog boards).

Evaluating both the model file and the device license file ensures compatibility with setups that use the model file only.

## Functional changes

- Introduced before SmarTest 6.3.2
