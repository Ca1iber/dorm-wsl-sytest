The model file contains the tester hardware configuration. It specifies what test head cards are installed, their features, and the mapping of these cards to pogo pins on the DUT board interface. For those test system resources and features that require licenses, SmarTest first generates the license requests based on the model file, then reads the *.lic license files to check out the requested licenses from the license server.
