# DPS section

In the DPS section, each available device power supply (DPS) card must be defined. "DPS card" in this context means the DC Scale cards.

  Note This section is for Smart Scale system model files only.

In the DPS section, each available device power supply (DPS) card must be defined. "DPS card" in this context means the DPS-slot cards and the DC Scale cards.

For the device power supplies that require a license, the model file or [the device license file](<02.04.05.06_The_device_license_file.md>) enables the required resources and features.

If a device license file exists, its parameters will be evaluated and any licensing parameters in the model file will be ignored. If no device license file is provided, the relevant licensing parameters in the model file will be evaluated.

For a DPS-slot device power supply you must specify the slot number. For DC Scale cards you use the channel numbers of the pogo blocks specified in the [POGOCABLING section](<02.04.01.03.02.02_POGOCABLING_section.md>). For all cards you must specify the type.

For the UHC4T you use the channel numbers of the S1 pogo block. The software assigns the channel numbers of the S2 pogo block automatically.

## Syntax

Use the following syntax:

```
[dps_range](<02.04.01.03.02.06_DPS_section.md#_79176__r_dps_range>) : [type](<02.04.01.03.02.06_DPS_section.md#_79176__r_type>) {, [dps_feature_list](<02.04.01.03.02.06_DPS_section.md#_79176__r_dps_feature_list>) }
```

Parameters
 | dps_range  | Parameter dps_range specifies the addressed device power supplies:

dps_range = dps_number | dps_number - dps_number

 | where:  | dps_number  | [1...8]  | For DPS-slot device power supplies:

The DPS slot number of the installed device power supply.

 |
 | [DPS channel numbers]  | For DC Scale cards:

The six digit channel numbers of the pogo blocks specified in the [POGOCABLING section](<02.04.01.03.02.02_POGOCABLING_section.md>).

  | |
 | type  | This parameter defines the DPS type:

- `type = DCS-DPS128HC | DCS-UHC4T | SE-UDPS`

 |   | DCS-DPS128HC  | [DC Scale DPS128](<../02.05_Test_Head_Cards/02.05.05.01_DC_Scale_DPS128_DPS64_cards.md>)-HC and

DC Scale DPS64-HC (both DCS-DPS128HC)

 |
 |   | DCS-UHC4T  | [DC Scale UHC4T](<../02.05_Test_Head_Cards/02.05.05.02_DC_Scale_UHC4T_card.md>) |
 |   | SE-UDPS  | E7002US [Internal Utility Power Supply (SE-UDPS)](<../02.05_Test_Head_Cards/02.05.08.02_Internal_Utility_Power_Supply__SE-UDPS.md>) |

type must be specified. If not specified, the DPS will not be used.

 |
 | dps_feature_list  | Parameter dps_feature_list enables or specifies additional features for the DPS channels dps_feature_list = `feature_1 { , feature_2 }`

with feature_1 to feature_2 to replaced with the available DPS features as listed in the following examples.

 |

## Example

- DC Scale DPS128 / DPS64

  - DPS128 entries for the E8023PA pogo assembly with 8 IO-pogo blocks.

```
DPS
    #DPS128-HC / E8023PA
    22501-22516: type = DCS-DPS128HC
    42501-42516: type = DCS-DPS128HC
    22901-22916: type = DCS-DPS128HC
    42901-42916: type = DCS-DPS128HC
    30301-30316: type = DCS-DPS128HC
    30401-30416: type = DCS-DPS128HC
    30701-30716: type = DCS-DPS128HC
    30801-30816: type = DCS-DPS128HC
```

  - DPS64 entries for the E8023PA pogo assembly with 8 IO-pogo blocks. Note that the type is DCS-DPS128HC.

```
DPS
    #DPS64 HC / E8023PA
    22501-22516: type = DCS-DPS128HC
    42501-42516: type = DCS-DPS128HC
    22901-22916: type = DCS-DPS128HC
    42901-42916: type = DCS-DPS128HC
```

  - DPS128 entries for the E8023PC pogo assembly with 4 IO-pogo blocks.

```
DPS
    #DPS128-HC / E8023PC
    22501-22516: type = DCS-DPS128HC
    65701-65716: type = DCS-DPS128HC
    42501-42516: type = DCS-DPS128HC
    85701-85716: type = DCS-DPS128HC
    22901-22916: type = DCS-DPS128HC
    66101-66116: type = DCS-DPS128HC
    42901-42916: type = DCS-DPS128HC
    86101-86116: type = DCS-DPS128HC
```

  - DPS64 entries for the E8023PD pogo assembly with 2 IO-pogo blocks. Note that the type is DCS-DPS128HC.

```
DPS
    #DPS64-HC / E8023PD
    22501-22516: type = DCS-DPS128HC
    65701-65716: type = DCS-DPS128HC
    42501-42516: type = DCS-DPS128HC

```

    34501-34516: type = DCS-DPS128HC
    34601-34616: type = DCS-DPS128HC

```

  - DPS64 entries for the E8023PF pogo assembly with 2 MS-DPS style pogo blocks. Note that the type is DCS-DPS128HC.

```

    34101-34116: type = DCS-DPS128HC
    34201-34216: type = DCS-DPS128HC

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.3: DPS32 requires no license.
- SmarTest 7.2.1: DPS128/64-HC supported.
- SmarTest 7.2.1: Support of E8023PG pogo assembly for the 7.2.1 release stream.starts with SmarTest 7.2.1.5.
- SmarTest 7.2.2: DPS128-HC/HV supported.
- SmarTest 7.2.2: Support of E8023PG pogo assembly for the 7.2.2 release stream starts with SmarTest 7.2.2.1.
- SmarTest 7.3.1: PVI8 supported.
- SmarTest 7.3.2: UHC4T supported.
- SmarTest 7.4.0: AVI64 supported.
- SmarTest 7.4.3: SE-UDPS supported.
- SmarTest 7.4.4: Support of E8023PH pogo assembly.
- SmarTest 7.5.0: FVI16 supported.
