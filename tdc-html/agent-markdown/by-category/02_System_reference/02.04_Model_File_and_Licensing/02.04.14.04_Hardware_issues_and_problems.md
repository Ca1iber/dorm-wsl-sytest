# Hardware issues and problems

## Is there anything I can do to minimize the impact of a server that is out of operation?

- If you use multiple license servers you will be better protected in case a single server becomes unavailable for use. In the case of temporary outages, this will minimize overall impact.
- Be sure to make backup copies of your license files and keep them in a safe location in case there is a problem with your hard drive or motherboard. This will make it easier to reinstall licenses if needed.
- In the event of the destruction of a license server, the emergency license capability can be utilized to keep your operation running while the licenses are rehosted to a new computer. For more detail see [Emergency licenses](<02.04.06.09.09_Providing_emergency_licenses.md>) and [Replacing licenses after a server problem](<02.04.06.09.08_Replacing_licenses_after_a_server_problem.md>).

## What is "rehosting" licenses?

- Rehosting a license file is the process where all licenses you have originally locked to one license server are reissued by Advantest so a different computer can be used as a replacement license server. Rehosting is only justified by catastrophic loss of a server or the verifiable obsolescence of the server you have been using.

## What is "recovering" a license?

- Recovering a license is when you need to reinstall a license file on the same computer the license file was originally installed on, that has been out of operation for one reason or another. The process is the same as installing a license for the first time. Note that keeping a backup copy of the license file will be very useful if you ever need to recover a license.

## If a catastrophic disaster destroys my server, how do I rehost my license file so that a different computer can function as my server?

- See the procedure for requesting [Replacing licenses after a server problem](<02.04.06.09.08_Replacing_licenses_after_a_server_problem.md>).

## If my server suffers serious - but not catastrophic - damage, so that the system can be fixed but the license cannot be used, is there anyway I can reload the license?

- See the procedure for [Replacing licenses after a server problem](<02.04.06.09.08_Replacing_licenses_after_a_server_problem.md>), and for requesting an [emergency license](<02.04.06.09.09_Providing_emergency_licenses.md>).
- Note that tests already loaded will continue to run until they are complete, independently of the server. However, no new licenses can be checked out and testing will stop when a new DUT load takes place.

## If network problems interfere with testing, is there anything I can do about it?

- See the [Server and network crash diagnostic table](<02.04.06.09.05_Server_and_network_crash_diagnostic_table.md>) for a summary of what you can do if a server and/or the network goes down during test.
- Note that tests already loaded will continue to run until they are complete, independently of the server. However, no new licenses can be checked out and testing will stop when a new device load takes place.

## If my server hard drive is destroyed what can I do?

- If the server crash is due to a hard drive failure, you should repair the hard drive, reinstall the license server software, restore a backup copy of the license file, and start lmgrd. (For a copy of lmgrd, see under Hardware/Software Licensing at [V93000 SOC/HSM Licensing](<http://www.advantest.com>)).

## If computer hardware failures occur, other than a hard drive (explained in 7 above), is there anything I can do?

- Other kinds of computer failures may or may not affect the integrity of the hostid. If the computer can be repaired without changing the hostid, simply reinstall the software and licenses, as needed, and start the license server. If the computer repair alters the hostid, then the licenses must be rehosted (see [Replacing licenses after a server problem](<02.04.06.09.08_Replacing_licenses_after_a_server_problem.md>)).

## Can I rehost my computer for any reason other than the destruction of my server or its obsolescence?

- No. Rehosting is strictly limited to catastrophic damage to the server or obsolescence.

## If I am unable to use my licenses for a significant period of time due to problems with Advantest equipment that I have purchased, am I warranted use of the license for the full time period for which the license is designated?

- No. Licenses expire on a specific date regardless of usage. For extenuating circumstances, contact your Advantest sales representative.
