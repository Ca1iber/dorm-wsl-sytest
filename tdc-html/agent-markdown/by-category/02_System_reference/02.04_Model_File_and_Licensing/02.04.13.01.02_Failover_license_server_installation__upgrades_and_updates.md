# Failover license server installation, upgrades and updates

Installation procedure for a failover FlexNet Embedded license server arrangement to provide activated licenses. Applicable to fresh installations, and applying upgrades to add major functionality and patch updates installing the latest packages on an existing server.

## About this task

  Note It is possible to set up an emergency FNE license server, listed at the end of the client.conf file. In an emergency where the normal license servers are inaccessible, install the emergency licenses on the emergency license server. All clients automatically connect to the emergency FNE license server.

The license server install script is available from the V93000 Linux RHEL 7 Recovery DVD for RHEL 7 Workstations DVD or can be downloaded from the Advantest FTP server:

[ftp.advantest.com/Licensing/FNE_SW](<ftp://ftp.advantesst.com/Licensing/FNE_SW>).

All customers with support contracts may access the ftp.advantest.com site. A username and password for access to the ftp.advantest.com site can be requested from:

[https://www.advantest.com/en/service-support/ic-test-systems/products-list/v93000-smartest-system-software-downloads](<https://www.advantest.com/en/service-support/ic-test-systems/products-list/v93000-smartest-system-software-downloads>)

 The script name takes the following form: install-fne-<date>-<version>.sh.Note If you are upgrading an existing installation, a running license server is automatically stopped as part of the new software installation.

The following procedure is applicable to installation, upgrades and updates. However, associating the servers (step [6](<02.04.13.01.02_Failover_license_server_installation__upgrades_and_updates.md#_345952__Assoc_Servers>)), registering the primary server (step [7](<02.04.13.01.02_Failover_license_server_installation__upgrades_and_updates.md#_345952__Register_Prime_Server>)), and synchronizing the servers (step [8](<02.04.13.01.02_Failover_license_server_installation__upgrades_and_updates.md#_345952__Sync_Servers>)) are only required for initial installation. These steps should be omitted for upgrades and updates.

  Note During updating, the installation script can be called without any option. All installed packages are detected automatically and updated if applicable.

## Before you begin

- Make sure that the system hosting the FlexNet Embedded license server host system meets the hardware and operating system prerequisites. For details and check procedures, see [FlexNet Embedded license server setup](<02.04.13.01_FlexNet_Embedded_license_server_setup.md>).
- Ports 7070 and 7077 must be open (firewall) and not be in use by other applications.
- If installing n FNX server, ports 27000 and 27020 must also be open (firewall) and not be in use by other applications.
- License servers must use fully qualified hostnames. For further details, see [Setting the host name of a system controller running RHEL 7](<02.04.13.01.01_Setting_the_host_name_of_a_system_controller_running_RHEL_7.md>).
- To detect any license server problems early, we strongly recommend that you plan to include the FNE license servers in your availability monitoring setup. SmarTest cannot inform you about the failure of a license server.

A redundant FNE failover setup consists of two servers; the primary production system and the failover standby system. If the primary system stops working, for example, due to a hardware defect, the failover system assumes the production workload and handles all requests. The period of each failover substitution is limited to a maximum of 5 days. During these 5 days you must repair and recommission the primary server or set up a new server.

 Note If the failover system goes down while the primary system is handling the production workload, there is no mandatory time limit for getting it running again. However, during this period there is no redundancy backup.

## Procedure

-  Load the V93000 Linux RHEL 7 Recovery DVD for RHEL 7 Workstations DVD or download the install-fne-<date>-<version>.sh script to: /tmp/fne.
-  If dowloading the package, check it for integrity:

./install-fne-<date>-<version>.sh test

-  Start the installation on the primary server:

For FNE-only environments: sudo sh install-fne-<date>-<version>.sh server

For mixed FNE-FNP environments: sudo sh install-fne-<date>-<version>.sh fnx

This also installs the [FNE Server Viewer](<02.04.13.04_Monitoring_license_servers_using_the_FNE_Server_Viewer.md>).

-  Start the installation on the failover server:

For FNE-only environments: sudo sh install-fne-<date>-<version>.sh server

For mixed FNE-FNP environments:sudo sh install-fne-<date>-<version>.sh fnx

-  For mixed FNE-FNP environments: Start the installation on the FNP tertiary server:

sudo sh install-fne-<date>-<version>.sh tertiary

-  Not for upgrades or updates: Associate the failover FNE license server with the primary FNE license server, using a user other than root, on the primary server execute the command:

/opt/flexnetls/socbu/fne-failover-setup <secondary-hostname>.<domain>

-  Not for upgrades or updates: Register the primary FNE license server with the Advantest Licensing Back-Office:

register-fne-server <Unique_Activation_ID>

For details see [Registering the license server](<02.04.13.01.04_Registering_the_license_server.md>).

-  Not for upgrades or updates: Synchronize the FNE license servers:

For FlexNet Embedded license servers that are connected to the internet, an automatic synchronization should occur immediately. If this is not the case, you can perform a sync-fne-server action on the license server.

For FlexNet Embedded license servers not connected to the internet, registering the servers from the primary server (uploading the registration-request-file to the Advantest Licensing Back-Office) provides you with a downloadable license container file.

Unpack and apply the license container file to the primary AND the failover systems using the following command on each license server:

register-fne-server <unpacked zip-file>

For full details see [Registering the license server](<02.04.13.01.04_Registering_the_license_server.md>).

-  On the primary license server check the status of the failover system:

/opt/flexnetls/socbu/fne-failover-status

The following displays an example of the status output:

![Example of FNE failover status output](<../../../../raw/345953.png>)

-  Activate the licenses to the new FNE license server. For details, see [Activating licenses](<02.04.10.01_Activating_licenses.md>) or [Downloading licenses](<02.04.11_Downloading_licenses.md>) as appropriate for your environment.

## Results

The FNE primary and secondary license servers are installed, synchronized and licenses are activated.

To check if an FNE license server is running:

/opt/flexnetls/socbu/fne-status

If the FNE license server is running, the following type of output is displayed:

```
* advantest-fne-server.service - Flex Net Embedded license server adapted for Advantest
   Active: active (running) since Mon 2019-05-20 11:08:14 CEST; 3 days ago
* advantest-fne-server-viewer.service - Advantest Flex Net Embedded License Server Viewer
   Active: active (running) since Mon 2019-05-20 11:06:48 CEST; 3 days ago
* advantest-fne-proxy.service - Advantest FNP2FNE proxy
   Active: active (running) since Mon 2019-05-20 11:07:36 CEST; 3 days ago

```

To check that the installation is complete, open a browser to view the FNE Server Viewer from the primary FNE license server system:

http://<serverName>:7077

Click on link Features.

You should see the licenses activated to your license server.

Check the connections of the primary and failover FNE license server systems with:

- https://<fne-server-hostname>:7070/api/1.0/health
- https://<failover-fne-server-hostname>:7070/api/1.0/health
 Note To uninstall the FNE License Server and FNE Server Viewer, execute the command:

sudo yum remove advantest-fne-server advantest-fne-server-viewer
