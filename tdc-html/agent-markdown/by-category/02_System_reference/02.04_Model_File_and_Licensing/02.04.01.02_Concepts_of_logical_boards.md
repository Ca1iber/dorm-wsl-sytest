# Concepts of logical boards

For cards that provide more than 16 channels, the channels will be divided into units of 16 channels.

A group of 16 digital channels forms a logical board.

- Each logical board requires up to 16 unique addresses (unique address= only used once, therefore not used to address any other resource in the test system).
- The address range is `1 01 01 ... 8 64 16`.
- Typically these addresses also define the physical location of the channel's pogo block in the DUT interface.
- If a pogo block provides pogo pins for more than 16 channels (equals 1 logical board), 2 or more unique addresses are required. For example, from within the above mentioned range:

  - `4 31 01 ... 4 63 16`: physical location of the channel's pogo block in the DUT interface.
  - `5 32 01 ... 5 64 16`: virtual pogo block, not physically used in the DUT interface, but required by the software to address the channels.

## Virtual pogo blocks
