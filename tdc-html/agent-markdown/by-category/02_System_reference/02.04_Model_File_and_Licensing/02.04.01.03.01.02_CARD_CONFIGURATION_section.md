# CARD_CONFIGURATION section

The CARD_CONFIGURATION section describes the setup of physical cards in the tester. It includes the physical location, card name and also the mapping between card slots (the physical position of the cards) and pogo blocks on the DUT interface.

## Syntax

```
CARD_CONFIGURATION
    [slot](<02.04.01.03.01.02_CARD_CONFIGURATION_section.md#_255461__r_slot>) = physical_location, [HW](<02.04.01.03.01.02_CARD_CONFIGURATION_section.md#_255461__r_HW>) = card_name, [pogoblocks](<02.04.01.03.01.02_CARD_CONFIGURATION_section.md#_255461__r_pogoblocks>) = pogo_cabling
        [type](<02.04.01.03.01.02_CARD_CONFIGURATION_section.md#_255461__r_type>) = cable_type {, [subtype](<02.04.01.03.01.02_CARD_CONFIGURATION_section.md#_255461__r_subtype>) = sub_type, [config](<02.04.01.03.01.02_CARD_CONFIGURATION_section.md#_255461__r_config>) = pogo_config }
```

Parameters
 |

slot

 |

Specifies the physical card position.

The format of the number is CSS. C represents the control segment (from 1 to 4) and SS represents the slot number (from 01 to 18). The slot for a clock board is not counted.

For details, see [pogo mapping](<../02.05_Test_Head_Cards/02.05.01.04_Pogo_mapping.md>).

 |
 |

HW

 |

Specifies the installed hardware type for the specified channels.

The HW parameter must be specified. Any card not specified is ignored.

The following cards are supported:

- EXA Scale systems:

  - Digital cards: PS1600, PS1600B, PS5000
  - Power supply cards: DPS64, DPS128, UHC4T, XPS256
  - Utility resources: UTILITY256

For more information, refer to [UTILITY256 utility card configuration in the tester.model file](<../02.05_Test_Head_Cards/02.05.08.04.04_Utility_Card_specific_setup_tasks.md#_351252__s_Utility_card_in_the_tester_model_file>) in [Utility Card specific setup tasks](<../02.05_Test_Head_Cards/02.05.08.04.04_Utility_Card_specific_setup_tasks.md>).

- Smart Scale systems:

  - Digital cards: PS1600, PS1600B
  - Power supply cards: DPS64, DPS128, UHC4T, SE-UDPS

 |
 |

pogoblocks

 |

Specifies the pogo pin blocks.

The parameter pogo_cabling can be

- listOfPogoBlocks or
- module_type: (listOfPogoBlocks)

where:

-

listOfPogoBlocks is an ordered list of pogo blocks or pogo block ranges.

  -

Use spaces to separate list items, for example, 101 103 104.

  -

Use hyphens (-) to specify a pogo block range, for example, 101-104.

  -

You can also mix pogo blocks and pogo ranges, for example, 101 102 210-212.

Pogo block ranges:

  - 101 to 164, 201 to 264, 301 to 364, 401 to 464, 501 to 564, 601 to 664, 701 to 764, 801 to 864, depending on the installed pogo cable type.
  - For the legacy SE-UDPS[1)](<#fntarg_1>), the parameter can also be the one digit DPS pogo block number 1 … 8.
  - Valid pogo blocks for the [Utility Card](<02.04.01.03.01.02_CARD_CONFIGURATION_section.md#_255461__li_type_UtilityCard>) are 165 ... 172 for the first card and 265 ... 272 for the second card.

For details, refer to [UTILITY256 utility card configuration in the tester.model file](<../02.05_Test_Head_Cards/02.05.08.04.04_Utility_Card_specific_setup_tasks.md#_351252__s_Utility_card_in_the_tester_model_file>) in [Utility Card specific setup tasks](<../02.05_Test_Head_Cards/02.05.08.04.04_Utility_Card_specific_setup_tasks.md>).

See also [DUT interface layout](<../02.03_DUT_board_design_reference/02.03.03.01_DUT_interface_layout.md>).

-

module_type: (listOfPogoBlocks) is an ordered list of pogo blocks or pogo block ranges associated with a module type.

Currently the supported module types are:

  - Power supply cards: HV (high voltage) and HC (high current).

For details on DPS128 cards, refer to [DPS128 and DPS64 card configuration in the model file](<../02.05_Test_Head_Cards/02.05.05.01.09.01_DPS128_and_DPS64_pogo_cabling_and_model_file_configuration.md#_140649__s_Examples>) in [DPS128 and DPS64 pogo cabling and model file configuration](<../02.05_Test_Head_Cards/02.05.05.01.09.01_DPS128_and_DPS64_pogo_cabling_and_model_file_configuration.md>).

 |
 |

type

 |

Specifies the pogo cable assembly.

The type parameter is optional for the following pogo cables.

- PS1600 pogo cable:

  - type = HD4x32 describes a PS1600 pogo cable with four HD pogo blocks and 32 channels per pogo block.

See also [High-density (HD) pogo blocks](<../02.05_Test_Head_Cards/02.05.04.01.07.02_PS1600_card_configuration_in_the_model_file.md#_351201__dle_HD_block>) in [PS1600 card configuration in the model file](<../02.05_Test_Head_Cards/02.05.04.01.07.02_PS1600_card_configuration_in_the_model_file.md>).

If not specified, the system defaults to the [SD (standard density) pogo block](<../02.05_Test_Head_Cards/02.05.04.01.07.02_PS1600_card_configuration_in_the_model_file.md#_351201__dle_SD_block>).

  - type = VHD1x128 describes a PS1600 pogo cable with two VHD pogo blocks and 64 channels per pogo block that is to be used for special configurations only.

For more information, refer to [Very-high-density (VHD) pogo blocks](<../02.05_Test_Head_Cards/02.05.04.01.07.02_PS1600_card_configuration_in_the_model_file.md#_351201__dle_VHD_block>) in [PS1600 card configuration in the model file](<../02.05_Test_Head_Cards/02.05.04.01.07.02_PS1600_card_configuration_in_the_model_file.md>).

- PS5000 pogo cable:

  - type = HD8x32 describes a PS5000 pogo cable with eight HD pogo blocks and 32 channels per pogo block.
  - type = VHD4x64 describes a PS5000 pogo cable with four VHD pogo blocks and 64 channels per pogo block.

- DC Scale DPS64 and DPS128 pogo cable:

  - type = REDIRECT
  - If not specified, the system defaults to SD (standard density).
  - For details, refer to [DPS128 and DPS64 card configuration in the model file](<../02.05_Test_Head_Cards/02.05.05.01.09.01_DPS128_and_DPS64_pogo_cabling_and_model_file_configuration.md#_140649__s_Examples>) in [DPS128 and DPS64 pogo cabling and model file configuration](<../02.05_Test_Head_Cards/02.05.05.01.09.01_DPS128_and_DPS64_pogo_cabling_and_model_file_configuration.md>).

- DC Scale XPS256:

  - type = REDIRECT
  - If not specified, the system defaults to HD (high density).
  - For details, refer to [XPS256 card configuration in the tester.model file](<../02.05_Test_Head_Cards/02.05.05.03.10.01_XPS256_specific_setup_tasks.md#_350709__s_XPS256_in_the_tester_model_file>) in [XPS256 specific setup tasks](<../02.05_Test_Head_Cards/02.05.05.03.10.01_XPS256_specific_setup_tasks.md>).

Note When the type is REDIRECT, the definition of subtype and config is also required.

The type parameter is mandatory for the following cards or pogo cable assemblies:

- UTILITY256 utility card: type = UTILITY

For details, refer to [UTILITY256 utility card configuration in the tester.model file](<../02.05_Test_Head_Cards/02.05.08.04.04_Utility_Card_specific_setup_tasks.md#_351252__s_Utility_card_in_the_tester_model_file>) in [Utility Card specific setup tasks](<../02.05_Test_Head_Cards/02.05.08.04.04_Utility_Card_specific_setup_tasks.md>).

 |
 |

subtype

 |

Specifies the cable subtype:

- DPS128/DPS64, REDIRECT category of cables:

  - subtype = [E8023PC | E8023PD | E8023PE | E8023PF | E8023PG | E8024UHPS]
  - For details about pogo cable assemblies, see [DPS128鈥? DPS64 pogo cable assemblies and pogo pin assignments](<../02.03_DUT_board_design_reference/02.03.06.02.02_DPS128____PS64_pogo_cable_assemblies_and_pogo_pin_assignments.md>) and [DPS128 and DPS64 pogo cabling and model file configuration](<../02.05_Test_Head_Cards/02.05.05.01.09.01_DPS128_and_DPS64_pogo_cabling_and_model_file_configuration.md>).

- UHC4:

  - The cable E8024UHPS is used by UHC4T.

- XP256, REDIRECT category of cables:

  - subtype = [EK751HDA | EK751VHDA]
  - For details, refer to [XPS256 card configuration in the tester.model file](<../02.05_Test_Head_Cards/02.05.05.03.10.01_XPS256_specific_setup_tasks.md#_350709__s_XPS256_in_the_tester_model_file>) in [XPS256 specific setup tasks](<../02.05_Test_Head_Cards/02.05.05.03.10.01_XPS256_specific_setup_tasks.md>).

 |
 |

config

 |

Describes the detailed cable configuration.

It depends on the subtype.

Format:

pogo:(pogo_range) { pogo:(pogo_range) }

Where:

- pogo can be a DPS number [1...8], or a pogo block number [101...964] or a pogo pin number [10101...96416].
- pogo_range is a pogo block range, which uses hyphen (-) to connect.
 |

## Example

```
CARD_CONFIGURATION

    #-------------------------------------------------------------
    # Digital pin cards
    #-------------------------------------------------------------
    slot = 101, HW = PS1600,     pogoblocks = 101-108
    slot = 102, HW = PS5000,     pogoblocks = 101-116, type=SD
    slot = 101, HW = PS5000,     pogoblocks = 101 501 102 502 103 503 104 504
                                 105 505 106 506 107 507 108 508, type = HD8x32
    slot = 101, hw = PS5000,     pogoblocks = 101 501 133 533 102 502 134 534
                                 103 503 135 535 104 504 136 536, type = VHD4x64

    #-------------------------------------------------------------
    # DC Scale cards
    #-------------------------------------------------------------
    slot = 105, HW = DPS64,      pogoblocks=HC:(341 342 459 460),
                                 type=REDIRECT, subtype=E8023PF,
                                 config=1:(341-342) 2:(459-460)

    slot = 107, HW = UHC4T,      pogoblocks = 230
                                 # UHC4T assignment for E8013UHP cable:
                                 # Pogo Block A: 230 & Pogo Block B: 430

    slot = 108, HW = UHC4T,      pogoblocks = 319,
                                 type = REDIRECT, subtype = E8024UHPS,
                                 config = 319:(319) 319:(322)
                                 # UHC4T assignment for E8024UHPS cable,
                                 # which allows configuration of non-adjacent Pogo Blocks

    slot = 107, HW = XPS256,     pogoblocks = 417-432, type = REDIRECT, subtype = EK751HDA
```

Note: The example code above is just a collection of various entries, which do not lead to a valid configuration.
