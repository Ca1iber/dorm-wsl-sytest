# License expiration

## Will I receive a message indicating my licenses are going to expire before they expire?

- Yes. You will be notified when a license that has an expiration date within 31 days is accessed during the DUT load process. This notification appears in the report window.

## If I use a license server located in one time zone and that checks out licenses to a computer located in another time zone, will this affect the number of hours I have available for test?

- No. Once all required, valid licenses are checked out, the test will run until the next device load or until SmarTest is shut down.
- License validity, with regard to the expiration date, is determined by the time in the time zone where the license server is located.

## If my license expires while a test is in process what happens?

- The test will continue to run until it is complete but no new DUTs can load that depend on the license that has expired.
- Base capabilities are always available (release 5.4.2 and later), even without license file.

## Functional changes

- Introduced before SmarTest 6.3.2
