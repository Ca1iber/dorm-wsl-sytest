# Using the FLEXlm debug log

In case of problems with the license server, the status and error messages of the FLEXlm debug log will be useful.

When starting the license server (lmgrd), you can direct any lmgrd text output into a debug log, so you can examine the log if a problem arises. The lmgrd output contains

- configuration problem messages,
- daemon software messages, and
- informational messages.

These status and error messages will be useful when you need to debug the license server.

The output of the debug log describes events specific to lmgrd and to the current license vendor daemon. You can capture debug information for a particular license daemon by directing the output into a file you specify (see [lmutil lmswitch](<02.04.06.10.01_lmutil.md>)).

For a listing of possible debug log messages see Appendix G of the FLEXlm End User Guide.

You can find the FLEXlm End User Guide at the [Advantest Web Site](<http://www.advantest.com>): Advantest Home > Global Services > Product Support > V93000 > V93000 Licensing > FLEXIm License Server Software Downloads and Documents > FLEXlm End Users Guide.
