# Assigning an entitlement

When an entitlement is assigned to your user account, you get the rights of that entitlement, with all its licenses.

## About this task

Note The main prerequisite for all renewal activities is that you have assigned the appropriate entitlement IDs to your user account.

Entitlements are identified using entitlement IDs. You find the entitlement ID in the upper-right corner of the entitlement certificate that accompanies each purchase.

 ![Eintitlement ID_2](<../../../../raw/150452.png>) CAUTION The entitlement ID is the security key to your licenses. Do not make the entitlement ID public. If other users have the entitlement ID, they can assign it to their account and assume ownership of the license.

## Before you begin

- Make sure that you know which entitlement ID you want to assign to yourself.
- Log in to the Advantest License Renewal Portal.Note Entitlement IDs are case sensitive.

## Procedure

-  In the Advantest Renewal Portal start page, select the Assign entitlements tab.

The Assign Entitlement page opens.

-  From the Available entitlements list, select the entitlements that you want to assign to yourself.

You can also use the Select all and Unselect all buttons to simplify selection.

-  Click Assign.

The list on the left shows those entitlements you assigned to your user account. The list also shows whether an entitlement is assigned to you only, or to others as well. In this case the ![Entitlements_Users](<../../../../raw/147049.png>) icon is displayed. A mouse-over text box will display the names of the other users.

## Results

The selected entitlements are now assigned to your user account and appear in the list on the left.

Note If you have the complete entitlement ID, you can assign an entitlement that belongs to another legal entity to your user account using the Add new entitlement ID button, for example, licenses for systems leased from a leasing company. This entitlement will appear in the Assigned Entitlements list on the left, but never in the list on the right.  ![Add_Entitlement_ID](<../../../../raw/147250.png>)

## What to do next

You can renew the licenses belonging to the assigned entitlement.
