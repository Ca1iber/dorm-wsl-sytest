# The System .lic license files

#### Subtopics

- [Activating system licenses](<02.04.05.01.01_Activating_system_licenses.md>)
- [Activating licenses advanced](<02.04.05.01.02_Activating_licenses_advanced.md>)
- [Find out HostID and HostName](<02.04.05.01.03_Find_out_HostID_and_HostName.md>)
- [Editing .lic license files](<02.04.05.01.04_Editing_.lic_license_files.md>)

System *.lic licenses allow you to scale test system capabilities like speed and memory.

All *.lic license files reside by default in the /opt/flexlm/license directory on both the license client and the license server.

The system .lic license file on the client provides the hostname or IP address of the license server for SmarTest and the correct vendor daemon (in this case "socbu"). The vendor daemon is required as the FLEXlm licensing software is used also by other software vendors.

To receive a system *.lic license file, you must activate the corresponding license. For details see [Activating system licenses](<02.04.05.01.01_Activating_system_licenses.md>).

 Note Service and Support (S&S) licenses do not need to be activated.

## Checking out licenses from a license server

At startup SmarTest reads the model and device license file and resolves the requested capability into required licenses.

Then SmarTest looks into the /opt/flexlm/license directory on the same machine and reads the *.lic license file(s). The *.lic license file(s) specifies the host name of the license server. That can be the same machine in case of a local license server, or another machine in case of a central license server. See [Editing .lic license files](<02.04.05.01.04_Editing_.lic_license_files.md>).

SmarTest then contacts the license server to check if the licenses are available. If yes, it checks-out the licenses and enables the features. If no, SmarTest runs the script license_checkout_failure, see [Customizable Scripts](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02.02_Customizable_Scripts.md>).

Base capabilities are always available (release 5.4.2 and later), even without license.

## Checking licenses back into a server

Licenses are automatically checked back into the license server when SmarTest is shut down.
