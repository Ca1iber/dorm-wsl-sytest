# DPS128鈥? DPS64 in DPS operating mode

For the DPS mode specify the pin type as DPS+. In DPS mode you can use the DC Scale DPS128/DPS64 card like a DPS-slot DPS, to supply devices with power during the execution of a test flow.

Each of the 128/64 channels can source and sink current at a programmed voltage, and each channel can measure the voltages and currents supplied. Each high current channel provides up to 1 Amp. Each high voltage channel can provide -6 to +15 Volt. For the maximum source/sink current per card see the [DPS128鈥? DPS64 specifications](<02.05.05.01.02_DPS128____PS64_specifications.md>).

## Equations

Note To use all features of the DC Scale DPS128/DPS64 card in DPS mode you should use equations. For details see [Level Equations](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03_Structure_of_an_equation_based_level_setup.md>).

## Connecting and disconnecting in DPS operating mode

When connecting and disconnecting in DPS operating mode, the DPS128/DPS64 card behaves like a DPS-slot device power supply.

When connected, it forces the programmed power supply voltage (vout). The current is limited to the connect current limit (ilimit).

The DPS128/DPS64 must be disconnected before changing any of the following:

- a voltage force range (vout_frc_rng)
- a clamp current range (iout_clamp_rng)

If the card is still connected, you cannot activate a dps set that contains one of above changes. To avoid damages to your device or DUT board, the system will display an error message in the report window instead.

## Current and voltage measurement

In DPS operating mode, each channel of a DC Scale card can measure the supplied current or voltage. See also [Hardware view for DPS and VI pins](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.05.03.04_Hardware_view_for_DPS_and_VI_pins.md>).

## Unganged current measurement in DPS mode

To achieve a higher output current, you can gang multiple DC Scale channels (see [DFPS, DFPS? - (DeFine Power Supply)](<../02.06_Command_Reference/02.06.02.02.65_DFPS__DFPS__-__DeFine_Power_Supply.md>). But the higher current of ganged channels has a negative impact on current-measurement accuracy.

To achieve a higher accuracy, for example for IDDQ-measurements, you can temporarily ungang channels during measurement.

To temporarily ungang channels in DPS mode, use the MEASURE_CURRENT_UNGANGED parameter in the [DPS_TASK](<../02.07_Test_Method_Reference/02.07.04.01.50_DPS_TASK.md>) test method API.

Note that on DPS128/64 and XPS256 you cannot execute a current compare on a ganged group of channels in unganged mode. Already activated comparators are silently disabled in unganged mode. A user notification (Error or warning) is omitted in this case, to avoid any interrupt in the testflow. The previous state of the comparators is automatically restored after the ganged group has been restored.

For further details see the [DPS_TASK](<../02.07_Test_Method_Reference/02.07.04.01.50_DPS_TASK.md>) test method API.
