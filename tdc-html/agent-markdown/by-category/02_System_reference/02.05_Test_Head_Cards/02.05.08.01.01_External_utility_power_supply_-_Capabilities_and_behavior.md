# External utility power supply - Capabilities and behavior

The external utility power supply provides extra power for active components like relays, operational amplifiers, and buffer on the DUT board or probe card. The supply provides three power lines +5.0 V, +3.3 V, and -5.0 V.

## Capabilities

The external utility power supply provides three power lines:

- +5.0 V (0 % ... +3 %) at 8 A
- +3.3 V (0 % ... +3 %) at 6 A
- -5.0 V (0 % ... +3 %) at 6 A

The three power lines feature remote sensing per line and a common power OK signal. The three power lines are switched off together if the power OK signal indicates an error for a time span of more than 100 ms.

Overcurrent protection for the power lines are provided by polyfuses mounted directly on the 4-row utility pogo blocks. If triggered, a polyfuse needs a short time to reset.

## Pogo blocks

The power lines are available on row C of the [4-row utility pogo blocks](<../02.03_DUT_board_design_reference/02.03.04.01_Utility_line_assignments.md>) on the DUT board. They are routed via the wiring board. For mapping information refer to the topics

- [Utility Pogo-block - LTH](<../02.03_DUT_board_design_reference/02.03.06.08.03_Utility_pogo_block_-_LTH_large_DUT_interface.md>),
- [Utility Pogo-block - STH DUT Scale interface](<../02.03_DUT_board_design_reference/02.03.06.08.04_Utility_pogo_block_-_STH_DUT_Scale_interface.md>),
- [Utility Pogo-block - CTH DUT Scale interface](<../02.03_DUT_board_design_reference/02.03.06.08.05_Utility_pogo_block_-_CTH_DUT_Scale_interface.md>), and
- [Utility Pogo-block - ATH DUT Scale interface](<../02.03_DUT_board_design_reference/02.03.06.08.06_Utility_pogo_block_-_ATH_DUT_Scale_interface.md>).

All utility blocks have the same capabilities, each providing

- +5.0 V wired to three pogo pins "XPP5V"
- +3.3 V wired to two pogo pins "XPP3V3"
- -5.0 V wired to two pogo pins "XPM5V"
- Common power OK signal "XDCGD"
- Sense line for each of the three power linesNote One and only one sense pin of each voltage (-5 V, +3.3 V and +5 V) must be connected on the DUT board near the most powerful load. The sense pins on the other utility blocks must not be connected.

The power pogo pins of the same name and output voltage on all utility blocks used should be connected to common power planes of the DUT board. Note: The maximum allowed current per pogo pin is 1 A. This limit is not exceeded with evenly distributed currents. However, in case of a shortcut on a single pogo block, the current might be higher. To protect the power pogo pins from damage, polyfuses are mounted directly on the 4-row utility pogo blocks. In addition, polyfuses are available on the wiring board to protect the sense lines. When triggered, a polyfuse needs a short time to reset.

## Behavior

  Powering down The external utility power supply gets powered down if any of the following occurs:

- Device is changed
- Test Method API [UTILITY_POWER_STATUS](<../02.07_Test_Method_Reference/02.07.04.01.264_UTILITY_POWER_STATUS.md>) or the [UPOW](<../02.06_Command_Reference/02.06.12.02.06_UPOW__UPOW__-__Utility_POWer.md>) command is used to switch it off
- The DUT board is undockedCAUTION

Damage of the DUT and equipment damage.

Hot undocking of the DUT board can damage the DUT and the DUT board and will increase wear on the pogo pins.

Always power down the supply before the DUT board is undocked.

- The mode "16 utility lines per pogo" block is selected
- Start, normal shutdown, or unexpected shutdown of SmarTest
- Power cycle of the test system
- Overcurrent condition for more than 100 ms
 Powering up

The external utility power supply can be powered up with the Test Method API [UTILITY_POWER_STATUS](<../02.07_Test_Method_Reference/02.07.04.01.264_UTILITY_POWER_STATUS.md>) or the [UPOW](<../02.06_Command_Reference/02.06.12.02.06_UPOW__UPOW__-__Utility_POWer.md>) firmware command.

The supply does not power up on docking the DUT board (you have to do this via the software).

 Note Switching on the external utility power supply is possible only if you have a DUT board installed and the pogo pins "DSC" and "POG4R" are connected to "UGND".

## External utility power supply compared with the internal UP5V supply

 There are big differences between the external utility power supply and the [Internal utility power supply](<../02.03_DUT_board_design_reference/02.03.05.05_Internal_utility_power_supply__V93000_systems.md>) on UP5V pins that not only affect the maximum current and the pogo pin assignment:

- The output voltage of the internal utility voltage supply is only about 4.85 V.
- For the external utility power supply, we recommend connecting the XP... power output pins of the same name and output voltage on all utility blocks to common power planes on the DUT board. In contrast, the UP5V pins on different pogo blocks may be supplied by different clock boards and can be connected together on the DUT board only if they are supplied by the same Clock board.[1)](<#fntarg_1>)
- The UPV5 supply is automatically switched on as soon as the test head is powered up and SmarTest is loaded, while the external utility power supply must be enabled using the API mentioned above.
