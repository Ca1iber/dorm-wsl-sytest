# XPS256 programming - AWG

An XPS256 pin can be used as an arbitrary waveform generator (AWG), supporting both voltage and current waveforms. The AWG functionality is controlled by pattern sequencer DC events.

Refer to [XPS256 arbitrary waveform generator (AWG)](<02.05.05.03.03.01_XPS256_arbitrary_waveform_generator__AWG.md>) for a detailed description of the AWG.

 Note This topic of the XPS256 programming overview covers only the AWG specific settings. For common settings, refer to [XPS256 programming - Force and clamp currents](<02.05.05.03.10.08_XPS256_programming_-_Force_and_clamp_currents.md>) and [XPS256 programming - Force and clamp voltages](<02.05.05.03.10.09_XPS256_programming_-_Force_and_clamp_voltages.md>).

## Maximum sample frequency

For XPS256, the maximum frequency of the pattern sequencer is 50 MHz and 32 vectors are required per sample. This results in a maximum sample frequency of 1.5625 MHz. See also [Minimum period / maximum frequency of the sequencer](<../02.08_Setup_and_Result_Tools/02.08.04.34.06.05.01_Minimum_period___maximum_frequency_of_the_sequencer.md>).

## API overview

The basic setup of the AWG must be programmed by standard APIs for an XPS256 pin in [PMU operating mode](<02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md>) or by the [Equation based level setup](<../02.08_Setup_and_Result_Tools/02.08.04.14.02_Equation_based_level_setup.md>) or API [DPS_TASK](<../02.07_Test_Method_Reference/02.07.04.01.50_DPS_TASK.md>) for an XPS256 pin in [DPS operating mode](<02.05.05.03.10.07_XPS256_programming_-_DPS_operating_mode.md>).

The API [ANALOG_WAVEFORM](<../02.07_Test_Method_Reference/02.07.04.01.05_ANALOG_WAVEFORM.md>) provides the functionality to define and modify waveform objects.

The AWG core functionality is controlled by force events in a pattern. For more information refer to [DC events](<../02.07_Test_Method_Reference/02.07.04.01.63_EVENT_...__DC_events_API_reference.md#_345840__s_Event_classes_and_data_types>).

## Application note

  DC events in reused pattern For a minimized test time we recommend, not to reuse pattern with DC events that are to be applied for different XPS256 ranges. The recommendation applies to pattern that are manually created using the related test method APIs but not to the automatically created [SmartRDI](<../02.07_Test_Method_Reference/02.07.13_SmartRDI.md>) pattern.

The XPS256 channels feature several force ranges. The pattern data of related DC events must be reloaded in case the containing pattern is reused for another range. This may significantly increase the test time.

The recommendation applies to all DC events that change the force- or clamp value or range or the measurement range.
