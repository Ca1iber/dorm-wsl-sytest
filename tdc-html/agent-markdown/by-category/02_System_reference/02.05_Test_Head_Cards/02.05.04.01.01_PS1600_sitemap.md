# PS1600 sitemap

The Pin Scale 1600 (PS1600) is the Smart Scale generation digital base card providing per-pin capabilities such as individual clock domain, high accuracy DC and industry-leading digital performance.

With 128 channels per card, the PS1600 supports higher pin count and higher multisite testing, enabling smaller infrastructure usage and cost.
