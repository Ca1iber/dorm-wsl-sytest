# UHC4T functionality and features

#### Subtopics

- [UHC4T power modes](<02.05.05.02.03.01_UHC4T_power_modes.md>)
- [UHC4T measurement modes](<02.05.05.02.03.02_UHC4T_measurement_modes.md>)
- [UHC4T features](<02.05.05.02.03.03_UHC4T_features.md>)

The DC Scale UHC4T has four channels per card, which provide a maximum current of 40 A each (160 A per card).

The UHC4T can be used configured for the [DPS operating mode](<02.05.05.04_DPS_operating_mode_of_DC_Scale_cards.md>) and used as device power supply (DPS) and as voltmeter. Unlike the other DC Scale cards, the UHC4 / UHC4T does not support the PMU operating mode.

The UHC4T supports static and dynamic (sequencer鈥慶ontrolled) measurements mode. In DPS operating mode you can use UHC4T like a standard DPS to supply devices with power during a test flow. It takes part, for example, in connect/disconnect sequences and in the set activation.

## Power modes

Furthermore the DC Scale UHC4T operates in two power modes:

- High power mode with a maximum current capability of 40 A
- Precision mode with a maximum current capability of 1.5 A, but with a higher current measurement accuracy

For details see [UHC4T power modes](<02.05.05.02.03.01_UHC4T_power_modes.md>).

## Measurement modes

UHC4T supports current and voltage measurements. Both measurement modes can be programmed as static measurement or as dynamic measurement.

For details see [UHC4T measurement modes](<02.05.05.02.03.02_UHC4T_measurement_modes.md>).

For voltage measurements you must apply the high impedance (himp) connect state.

## UHC4T features

Special features of the UHC4T include:

- Ganging of any number of installed channels across either UHC4T cards in a free selectable sequence to achieve even higher currents
- High-speed sampler (digitizer) on each channel for differential voltage measurements and waveform capturing
- Protection features like alarms and measurement of voltage drops
- Fast preload mode
- Peak mode

For details see [UHC4T features](<02.05.05.02.03.03_UHC4T_features.md>).

## Equations

To use all features of DC Scale UHC4 / UHC4T cards you must use equations. The equation based level setup provides UHC4T specific parameters, for example several connect states. For details see [Equation based level setup](<../02.08_Setup_and_Result_Tools/02.08.04.14.02_Equation_based_level_setup.md>) and [DPSPINS resources](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>).

## Channel sharing

You can share the same DC Scale UHC4T channel or gang of channels between several sites. This allows to save DPS channels by supplying external circuits on the DUT board with just one channel. See also [Test Method Programs](<../../03_Use_cases_and_application_papers/03.02_How_to_do_Multi-Site_Testing/03.02.04_Multisite_Test_Method_Programming.md>) and [Sharing Channels Between Several Sites](<../02.07_Test_Method_Reference/02.07.03.13.03.01.01_Sharing_Channels_Between_Several_Sites.md>).

## Profiling in Hardware view

Profiling ([DC profiling](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.05.03.05_Profiling_of_DC_Scale_cards_with_Hardware_view.md>)) allows you to measure and display current and voltage waveforms during pattern execution in the Hardware perspective. Current and voltage profiling is supported for all channels.

On DC Scale UHC4T cards, profiling for multiport setups does not stop when the DPS part is finished. On these cards, profiling stops when the longest running port is finished. This allows to minimize DPS memory consumption. You need to create an empty port pattern though.

On UHC4T cards you can also do profiling when the pattern contains CLEV or CTIM commands.

## Software identifier

The return of the [OPT?](<../02.06_Command_Reference/02.06.02.02.344_OPT__-__hardware_OPTions.md>) query is the software identifier DCS-UHC4T
