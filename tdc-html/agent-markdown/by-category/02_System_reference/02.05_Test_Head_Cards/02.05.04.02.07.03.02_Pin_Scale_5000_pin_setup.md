# Pin Scale 5000 pin setup

## Independent clock domains per pin

To set up independent clock domains per pin, you put the respective pins into ports (a port can contain only one pin if desired) and use a multiport setup.

## Modes

 In the pin setup tool, you must select the correct mode depending on the speed you want. There are two modes you can select here:

- Standard (std) mode supports single-ended and differential i, o and io pins.Note io pins (both single-ended and differential) are only supported with a center tap termination, with a cross termination, only o pins are supported.
- FAST mode gives you speeds of up to 5.0 Gbit/s. It supports single-ended and differential i and o (not io) pins.

For each mode, depending on your requirements, there are various termination possibilities that you define in the level setup (see the table in [Definition of terminations in the level file](<02.05.04.02.07.03.03.01_Definition_of_terminations_in_the_level_file.md>)).

## Contexts

In addition to selecting a mode, you must also assign a "Context" to a pin setup.

A "context" is just an arbitrary name which you associate to the pin configuration you have set up.

You can define various pin configurations with different mode assignments and assign different context names to them.

The only exception to this, is the context name "DEFAULT" which automatically defines pins as std mode.

The use of contexts in the pin configuration allows you to associate timing, level, and vector setups to the particular pin configuration.

For this reason, the same context must be allocated to the level, timing and vector setups for a particular test suite.
