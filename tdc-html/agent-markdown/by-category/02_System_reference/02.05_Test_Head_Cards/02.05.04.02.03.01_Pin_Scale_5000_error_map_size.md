# Pin Scale 5000 error map size

The error map size is the same for Smart Scale generation cards (PS1600, PS9G) and EXA Scale generation cards (PS5000).

The size of the internal error map ([DCRT TP](<../02.06_Command_Reference/02.06.02.02.49_DCRT__DCRT__-__Digital_Compare_Result_Target.md>)) is 65536 bits. The number of cycles that fit into the error map (in Acquire All mode, [DCGM ALL](<../02.06_Command_Reference/02.06.02.02.44_DCGM__DCGM__-__Digital_Compare_Global_Mode.md>)) depends on the selected X mode and the number of bits stored per result:

- numberOfCycles = errorMapSizeInBits / (xMode * bitsPerResult)

For example, in X1 PFC mode (2 bits/result), EXA Scale generation cards can store 32768 cycles. In X8 mode (1 bit/result), EXA Scale generation cards can store 8192 cycles. The size of the external error map ([DCRT RAM](<../02.06_Command_Reference/02.06.02.02.49_DCRT__DCRT__-__Digital_Compare_Result_Target.md>)) is not fixed and always depends on the amount of available RAM.

There is a difference in the overview error map size between Smart Scale generation cards (PS1600, PS9G) and EXA scale generation cards (PS5000). For Smart Scale generation cards, the size of the overview error map is 8191 bits. For EXA Scale generation cards, the size is 32767 bits.

- Introduced in SmarTest 7.10.2
