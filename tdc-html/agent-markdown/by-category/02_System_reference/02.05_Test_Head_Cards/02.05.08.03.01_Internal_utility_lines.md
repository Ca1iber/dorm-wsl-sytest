# Internal utility lines

32 statically controlled utility lines are provided by the internal utility resources of a V93000 EXA Scale system in the basic configuration. Optionally, 32 more lines can be installed in the second card cage of the SX and LX test heads.

In the following table, only the "Basic configuration" columns with "Optional Utility Card (EK051A)" set to "none" apply to the internal utility lines. For the other columns, at least one optional [Utility Card](<02.05.08.04_Utility_Card.md>), which replaces the internal utility lines, must be installed.
