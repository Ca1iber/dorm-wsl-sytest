# Digital capturing

Digital capturing can be done with every normal digital pin on Smart Scale generation cards and on Pin Scale cards. But there are differences for both digital capturing modes.

## Sequential capturing

If you want to use sequential capturing on a Pin Scale system, the channel used for capturing must be set up to work in STD (standard) mode. If the channel is in FAST mode, sequential capturing is not available.

Similarly, you cannot use a wavetable in the [native Smart Scale format](<../02.06_Command_Reference/02.06.06.01.03.02_Defining_waveform_shapes_for_Smart_Scale_pins.md>) for sequential capturing on a Smart Scale system. The wavetable must be coded in the [modified standard format](<../02.06_Command_Reference/02.06.06.01.03.02_Defining_waveform_shapes_for_Smart_Scale_pins.md>).

For details see [Setting up the Timing for Sequential Capturing](<../02.08_Setup_and_Result_Tools/02.08.01.02.07.02.03.01_Setting_up_the_Timing_for_Sequential_Capturing.md>).

## Selective capturing

On a Pin Scale system, you can capture selectively on both standard and PS3600 fast pins. With standard pins, you can also select whether you want to run a pure capture test, or to combine capturing with a functional test (HRPF mode).

On a Smart Scale system, pure selective capture is possible with both the modified standard format and the native Smart Scale format; the HRPF mode is currently only supported for the modified standard format.

For details see [Selective Capture with Pin Scale Cards](<../02.08_Setup_and_Result_Tools/02.08.01.02.07.02.03.02.01_Selective_Capture_with_Equation_based_timing.md>). and [For Selective Capturing](<../02.08_Setup_and_Result_Tools/02.08.01.02.07.02.04.02.03_For_Selective_Capturing.md>).
