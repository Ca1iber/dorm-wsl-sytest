# XPS256 force, clamp, and measure currents

#### Subtopics

- [XPS256 force and clamp currents](<02.05.05.03.07.01_XPS256_force_and_clamp_currents.md>)
- [XPS256 measure currents](<02.05.05.03.07.02_XPS256_measure_currents.md>)

An XPS256 card features a PMU per channel for forcing, clamping, and measuring currents. Each PMU provides six combined force, clamp, and measure current ranges.

## Forcing and clamping current

The XPS256 PMUs are digitally regulated VI supplies with remote sense lines and a common return path. Each PMU is able to force or clamp voltages or to force or clamp currents and features six combined force and measure current ranges.

The digital controller of a PMU in force current mode will adjust the control value so that the output current at the high force pogo pin (P#) is equal to the programmed current as long as the voltage between the high sense pogo pin (PS#) and the ground sense pogo pin (GS#) stays within the programmed clamp voltage limits.

For more information, refer to [XPS256 force and clamp currents](<02.05.05.03.07.01_XPS256_force_and_clamp_currents.md>).

## Current measurements

The current is measured at the output of the force amplifier. The digital controller continuously measures voltages and currents, uses the measured values as feedback for the control loop, and provides the values for all user-defined measurements.

For more information, refer to [XPS256 measure currents](<02.05.05.03.07.02_XPS256_measure_currents.md>).

## Power budget

Unlike legacy similar cards, XPS256 does not require distributing a power budget across the active pins.

Nevertheless, the available power of an XPS256 card limits the maximum current for the 256 channel high-current variant XPS256 (EK751HC) in some cases as can be seen in [XPS256 voltage and current capability specifications](<../02.02_Specifications/02.02.05.03.04_XPS256_voltage_and_current_capability_specifications.md>).

To prevent the power budget from being exceeded and one or more channels having to be switched off, SmarTest checks the required power budget before downloading the settings and issues an error message if the required power budget exceeds the available power budget.
