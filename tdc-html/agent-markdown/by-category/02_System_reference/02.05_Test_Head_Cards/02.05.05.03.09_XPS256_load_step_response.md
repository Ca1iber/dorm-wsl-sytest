# XPS256 load step response

The load step response achieved for the XPS256 depends on several settings of the instrument, the capacitors on the DUT board, and finally the height and slew rate of the load step.

## Load step response

The load step response of XPS256 depends on several programmable settings, the actual current range, the impedance of the high force and low force traces on the DUT board, the [capacitors on the DUT board](<../02.03_DUT_board_design_reference/02.03.08.01.07.02_XPS256_capacitor_requirements.md>) and on the height and the slew rate of the load step.

 In addition to the current range, the following programmable settings have an effect on the load step response:

 |   | Load step mode:  | Independent of the digital control loop, the dynamic behavior of the output stage can be adapted directly by modifying the analog feedback path of the output stage. |
 | Voltage bandwidth:  | The selected voltage bandwidth has an effect on the load step response for a pin that is forcing or clamping voltage. |
 | Current bandwidth:  | The selected current bandwidth has an effect on the load step response for a pin that is forcing or clamping current. |
 | Load capacitance:  | The set load capacitance also has an effect on the load step response for a pin that is forcing or clamping voltage. |

The Voltage slew rate and the Current slew rate are also programmable parameters. These settings have an effect only for changes of the programmed force value. However, if changing the force value also changes the DUT voltage or the load current, the slew rate will also have an indirect effect on the load step response of XPS256.

Information on programming the settings for optimizing the load step response can be found in sections [SmartRDI overview](<02.05.05.03.10.11_XPS256_programming_-_Load_step_response.md#_352356__s_SmartRDI_overview_SMT7>) and [API overview](<02.05.05.03.10.11_XPS256_programming_-_Load_step_response.md#_352356__s_API_overview_SMT7>) in topic [XPS256 programming - Load step response](<02.05.05.03.10.11_XPS256_programming_-_Load_step_response.md>).

See also [Dynamic behavior in force voltage or clamp voltage mode](<02.05.05.03.06.01_XPS256_force_and_clamp_voltages.md#_351115__s_Dynamic_behavior>) and [Dynamic behavior in force current or clamp current mode](<02.05.05.03.07.01_XPS256_force_and_clamp_currents.md#_351117__s_Dynamic_behavior>).

## Recommendations for optimizing the load step response

General recommendation for usage as DUT power supply
 | Usage  | Load step mode  | Ganged channels  | Voltage bandwidth  | Note |
 | Current ranges < 1 A  | standard  | n.a.  | 10 kHz  | Normal load step response |
 | 1 A current range with capacitors on the DUT board  | standard  | 1 鈥?n  | 10 kHz |
 | fast  | 1 鈥?n  | 30 kHz  | Faster load step response; switches automatically to standard for current measurement in unganged mode |

Recommendation for regulation setting for any gang size
 | Capacitance per channel  | Load step mode  | Voltage bandwidth  | |
 | 0 ... 10 μF  | standard  | 10 kHz  | Normal load step response |
 | 10 μF ... 1 mF  | fast  | 30 kHz  | Faster load step response; switches automatically to standard for current measurement in unganged mode and current ranges < 1 A |
 | > 1 mF  | standard  | 10 kHz  | Normal load step response |

Recommended decoupling capacitance for DPS usage for optimize step response: 100 μF per channel. See also [XPS256 capacitor requirements](<../02.03_DUT_board_design_reference/02.03.08.01.07.02_XPS256_capacitor_requirements.md>).

As already mentioned, the load step response is impacted by many factors. Therefore, the above recommendations are a starting point and could be adjusted during correlation.

 Note For ganged pins, the best load step response can be achieved only if all channels of the ganging group are used.
