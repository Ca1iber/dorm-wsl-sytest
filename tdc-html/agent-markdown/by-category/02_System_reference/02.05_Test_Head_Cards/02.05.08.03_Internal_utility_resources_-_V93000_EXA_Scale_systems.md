# Internal utility resources - V93000 EXA Scale systems

#### Subtopics

- [Internal utility lines](<02.05.08.03.01_Internal_utility_lines.md>)
- [Internal utility power supplies](<02.05.08.03.02_Internal_utility_power_supplies.md>)
- [Internal utility resources specific setup tasks](<02.05.08.03.03_Internal_utility_resources_specific_setup_tasks.md>)

Internal utility resources of a V93000 EXA Scale system in the basic configuration consist of 32 statically controlled utility lines, a +5 V utility power supply and the Internal Utility Power Option. For the SX and LX test heads, the internal utility resources can optionally be extended by 32 more utility lines and one +5 V supply. Internal utility resources can be replaced and extended by an optional Utility Card.

## Overview

The internal utility resources are available for the basic configuration of V93000 EXA Scale systems:

- Utility lines:

[32 statically controlled utility lines](<02.05.08.03.01_Internal_utility_lines.md>) are provided as internal resources of the basic configuration. Optionally, 32 more lines can be installed in the second card cage of the SX and LX test heads.

The 32 utility lines are routed to one 4-row utility pogo block.

These resources can be replaced and extended by the optional [Utility Card](<02.05.08.04_Utility_Card.md>).

- Utility power supplies

  - [+5 V utility power supply on UP5V pins](<02.05.08.03.02_Internal_utility_power_supplies.md#_351298__dle_Utility_power_supply_UP5V>):

One +5 V utility power supply is provided as internal resource of the basic configuration. An additional optional +5 V supply can be installed in the second card cage of the SX and LX test heads.

The supply is routed to one 4-row utility pogo block.

The supply can be replaced by the +5 V UP5V supply of the optional [Utility Card](<02.05.08.04_Utility_Card.md>) that provides a higher current capability and is routed to eight utility pogo blocks.

  - [Internal Utility Power Option](<02.05.08.03.02_Internal_utility_power_supplies.md#_351298__dle_Internal_Utility_Power_Option>):

This supply replaces the legacy [Internal Utility Power Supply (SE-UDPS)](<02.05.08.02_Internal_Utility_Power_Supply__SE-UDPS.md>). This internal utility resource is routed to a 3-row DPS-slot pogo block. Since an optional second [Utility Card](<02.05.08.04_Utility_Card.md>) occupies the required DPS-slot pogo block, the Internal Utility Power Option is available only in the basic configuration or with maximum one optional Utility Card installed.

Note: In contrast to the legacy SE-UDPS, the Internal Utility Power Option remains switched off when the DUT board is docked.

## Pogo pin assignment

For the pogo pin assignment of the internal utility resources, refer to [Utility pogo block - Basic configuration (V93000 EXA Scale systems)](<../02.03_DUT_board_design_reference/02.03.06.08.01_Utility_pogo_block_-_Basic_configuration__V93000_EXA_Scale_systems.md>).
