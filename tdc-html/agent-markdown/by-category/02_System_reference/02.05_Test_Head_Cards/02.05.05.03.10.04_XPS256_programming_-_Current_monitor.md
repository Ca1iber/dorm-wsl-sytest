# XPS256 programming - Current monitor

DC Scale XPS256 cards offer the functionality to monitor the output current of ganging groups via other XPS256 pins. The monitor output pins can be configured in such a way that they drive a voltage proportional to the total current of the assigned ganging group.

  The following rules must be observed when using the monitor output pins:

- Each monitor output pin needs an XPS256 tester channel assigned per site. Sharing of tester channels between sites is not supported.
- A monitor output pin can be assigned to only one ganged XPS256 pin in the [DC Scale Safety editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.08_DC_Scale_Safety_editor.md>). Assigning a monitor output pin to more than one ganged XPS256 pin or to none鈥慻anged pins is not supported.
- For each site, an XPS256 channel used as monitor output pin must be on the same XPS256 card as the master channel of the assigned ganged pin[1)](<#fntarg_1>).

For more information, refer to [XPS256 current monitor](<02.05.05.03.03.02_XPS256_current_monitor.md>).

## Defining the monitor output pin

XPS256 pins are configured as monitor output pin in the [Digital Pins editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.02_Digital_Pins_editor.md>).

   ![Digital Pins editor XPS256 CMON](<../../../../raw/354983.png>)   Monitor output pins must be configured as follows:

- An XPS256 monitor output pin is to be set to dc in the Type column and to CMON in the Mode column.
- The Scaling factor in volts per ampere (V/A) must be defined in the Scaling column.

  - The programmable range of the scaling factor is 2e-5 ... 200.
  - The factor is to be defined in Volts per ampere (V/A).
  - The monitor output voltage is scalable to a range of 卤2 V.

- Different tester channels are to be assigned for all sites. Sharing tester channels between sites is not supported.

Note that a pin configured as current monitor output pin will not be visible in the [Hardware view](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.05.03_Hardware_view.md>).

## Assigning the monitor output pin

A configured monitor output pin needs to be assigned to a ganged XPS256 pin. The assignment must be configured in the Current Monitor Pin column of the [DC Scale Safety editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.08_DC_Scale_Safety_editor.md>):

   ![DC Scale Safety editor](<../../../../raw/354623.png>)

Each configured monitor output pin can be assigned to only one ganged XPS256 pin. The monitor output pin can be assigned to ganged XPS256 pins in both the [PMU operating mode](<02.05.05.03.05.02_XPS256_in_PMU_operating_mode.md>) and the [DPS operating mode](<02.05.05.03.05.01_XPS256_in_DPS_operating_mode.md>).

 In the PMU operation mode, you can use the current monitor for temporarily unganged pins, but the monitor outputs only 0 V. In the DPS operating mode, the monitor outputs a voltage proportional to the current of the assigned ganged pin also for a pin that is temporarily unganged.

Note that a monitor output pin gets automatically connected or disconnected when the assigned ganged XPS256 pin is connected or disconnected. Disconnected means the monitor output pin is set to a high impedance state and the pull down circuit is enabled.
