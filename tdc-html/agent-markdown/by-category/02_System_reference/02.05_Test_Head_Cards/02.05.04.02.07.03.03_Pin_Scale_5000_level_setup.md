# Pin Scale 5000 level setup

#### Subtopics

- [Definition of terminations in the level file](<02.05.04.02.07.03.03.01_Definition_of_terminations_in_the_level_file.md>)
- [Definition of contexts in level file](<02.05.04.02.07.03.03.02_Definition_of_contexts_in_level_file.md>)

The level setup of the Pin Scale 5000 card is similar to that of the Pin Scale 1600 card.

  Note FAST mode is a pre-release version on SmarTest 7.10.3 and has been enabled only for evaluation purposes. The Pin Scale 5000 card provides a:

- Three-level driver (vil, vih, and driver termination voltage vt) in standard (std) mode.
- Four-level driver in FAST mode only (vih and vil, v3h and `v3l = v3h - (vih - vil)`).
- Active load pin line discharge
- Differential threshold

In the "Hardware View" (see [Hardware Perspective](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.05_Hardware_Perspective.md>)), the pin channel of the PS5000 card is displayed as shown below.

 Note The AC relay shown in the Hardware view does not represent a real relay. SmarTest uses here a generalized schematic diagram.  ![Typical Hardware View of the Pin Scale 5000 Card](<../../../../raw/354935.PNG>)

## Differential comparator single voltage threshold (vth)

 The PS5000 comparator in differential mode supports the single threshold voltage vth. Note The differential comparator also supports a dual voltage threshold, namely: vol and voh. For details, see the section "Differential comparator dual voltage thresholds (vol and voh)" below.You can enable the comparator to operate in differential mode by specifying the keyword term center_tap in the level set. Specifying the threshold voltage (vth) is optional. If vth is not specified, the PS5000 defaults to 0V:

```
LEVELSET 1 "io_diff_ctrtap"
PINS P1@diff
#---------------------------
#Enable termination voltage
#---------------------------
term center_tap
```

You specify the single differential threshold (vth) for your differential measurement in the level set as shown below:

```
LEVELSET 1 "io_diff_ctrtap"
PINS P1@diff
#---------------------------
#Enable termination voltage
#---------------------------
term center_tap

vih = 1.8
vil = 0
#---------------------------
# Differential comparator single voltage threshold
#---------------------------
vth = 0.9

```

 The following figure illustrates this on the hardware view:Note When you specify a single voltage threshold, namely: vth, SmarTest automatically sets the dual voltage thresholds vol and voh such that vol=voh=vth.   ![Differential comparator single voltage threshold (vth)](<../../../../raw/124811.png>)

## Differential comparator dual voltage thresholds (vol and voh)

 The comparator in differential mode supports dual differential thresholds, namely: vol and voh. For details on how to generally setup differential connections, see [How to set up differential connections](<../../03_Use_cases_and_application_papers/03.10_How_to_set_up_differential_connections/03.10_How_to_set_up_differential_connections.md>).Note The differential comparator also supports a single voltage threshold, namely: vth. For details, see the section "Differential comparator single voltage threshold (vth)" above.

You can enable the comparator to operate in differential mode using the keyword term center_tap in your level set:

```
LEVELSET 1 "io_diff_ctrtap"
PINS P1@diff
#---------------------------
#Enable termination voltage
#---------------------------
term center_tap
```

## Single-ended comparator dual voltage thresholds (vol and voh)

You specify the dual voltage thresholds (vol and voh) for your differential measurement in the level set as shown below:

```
LEVELSET 1 "io_diff_ctrtap"
PINS P1@diff
#---------------------------
#Enable termination voltage
#---------------------------
term center_tap

vih = 1.8
vil = 0
#---------------------------
# Differential comparator dual voltage thresholds
#---------------------------
vt = 1.8
vol = -1
voh=1
```

## Driver levels in standard mode

The following applies to the normal driver, which is set up as for the PS1600 card.

In addition to the high (Vih) and low (Vil) levels, the PS5000 card allows you to set up a third driver level (Vt). The following figure shows an example.

  ![PS 1600 Third level Drive level](<../../../../raw/124916.png>)

## Driver levels in FAST mode

In addition to the standard three-level driver, the PS5000 card in FAST mode allows you to set up a fourth level (v3h and v3l), where v3l is calculated as `v3l = v3h - (vih - vil)`.

   ![PS5000 Four-level driver](<../../../../raw/356071.png>)
