# DPS128 Power Calculator - Menus and buttons

The following table lists and describes the operation of the controls of the DPS128 Power Calculator.

![DPS128 Power Calculator tool](<../../../../raw/349031.png>)

 | Area  | Name  | Description |
 | Help menu  | Help > Guide  | Opens the documentation of the DPS128 Power Calculator tool. |
 | File menu |

File > Load Pin

File > Load Model

File > Load limit or spec

 |

Opens a file browser to select the pin, model, and limit input data files. All three files are required and must be defined correctly. Files that cannot be loaded may not belong to the same set.

 |
 |

File > Load Default Model

 |

Loads the default model file supplied with the DPS128 Power Calculator, which uses PA cables and up to eight DPS128 cards.

 |
 |

File > Export

 |

Exports the valid calculated results in CSV format to a file.

 |
 | Edit menu |

Edit > Define Number of Sites

 |

Opens the Define Site Number window from which you can select the required quantity of sites.

 |
 |

Edit > Assign Channel ID into Table

 |

Determine the required DPS128 cards and cables assemblies for DPS128-based test systems.

 |
 | Control |

# % Margin

 |

Globally applies a safety margin that reduces the available power per domain used for the calculations by the selected percentage.

 |
 |

Display Loaded Files

 |

Displays the path and names of the files selected as input data.

 |
 |

Max. Power per Domain

 |

Displays the power in Watts per domain available from the selected card after applying any selected margin.

 |
 | Results |

DC-Scale

 |

Device power supply card designation.

Available cards:

- DPS128-HC
- DPS64-HC
 |
 | Cable Type  | Pogo cable assembly required for the selected device power supply.

Available pogo cable assemblies:

- E8023PA
- E8023PC
- E8023PD
- E8023PE
- E8023PF
- E8023PG
- E8023PH
 |
 | Card Position  | Card slot location number. |
 |

Domain 1

Domain 2

   | Power requirement for the associated domain in Watts. |
 | Pin Data table  | Pin  | Pin names |
 | Type   | Type of pin (Signal or DPS) |
 | Vmax/V  | Maximum input voltage in Volts |
 | Imax/A  | Maximum input current in Ampere |
 | Isource/A  | Input current in Ampere |
 | Isink/A  | Output current in Ampere |
 | DUT board ganging  | Pin defines ganging group |
 | Used Channels  | Number of channels used by the associated Pin |
 | Pmax/W  | Maximum power required |
 | Site #  | Device location  |
