# DUT Scale interface

Advantest offers several different test head sizes with a common DUT interface to provide DUT board compatibility across all test heads. The DUT Scale interface allows you to fully use the large DUT board on all V93000 test head types.

The figure below gives an overview of the compatibility of large and small DUT interfaces across all V93000 Pin Scale and Smart Scale test head classes. For a large DUT board on STH, CTH or ATH with DUT Scale interface, 8 groups (using active wiring board) are supported. A small DUT board is supported on CTH and ATH. However, the number of groups in this case is 4:

   ![DUT board compatibility (overview)](<../../../../raw/138228.jpg>)   Note The LTH DUT interface supports the use of large and small DUT boards.

The [POGOCABLING section](<../02.04_Model_File_and_Licensing/02.04.01.03.02.02_POGOCABLING_section.md>) in the model file maps the physical position of a card with the pogo block numbering of the DUT interface. The mapping of pogo blocks to card slots is explained in [Pogo mapping](<02.05.01.04_Pogo_mapping.md>).

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.0: ATH DUT interface added.
- SmarTest 7.3.4: Support of Scalable A-Class.
- SmarTest 7.4.1: Support of Scalable A-Class.
- SmarTest 7.6.0 / 8.3.4: Support of V93000 EXA Scale test heads.
- SmarTest 8.4.3: Support of LX test head of V93000 EXA Scale systems.
