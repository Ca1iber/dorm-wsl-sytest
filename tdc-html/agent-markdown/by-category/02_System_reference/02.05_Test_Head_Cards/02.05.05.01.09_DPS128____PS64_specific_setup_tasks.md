## DPS128 in the model file

For more information, refer to [DPS128 and DPS64 pogo cabling and model file configuration](<02.05.05.01.09.01_DPS128_and_DPS64_pogo_cabling_and_model_file_configuration.md>).

## Pin configuration

The pin configuration of channel-slot DC Scale cards is slightly different to that of a DPS-slot device power supply.

To configure a DC Scale pin for DPS operating mode you must specify the pin type as DPS+. For details see [DC Scale pin (DPS mode) setup](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.03.01_DC_Scale_pin__DPS_mode__setup.md>).

## Multisite setup

In case of a multisite setup you must strictly differentiate between high-current (HC) and high-voltage (HV) channels. The same device pin on the various sites must be allocated to a channel of the same type (HC or HV). A device pin cannot be an HV pin on one site and an HC pin on another site.

## Multiport setup

The total channel memory of DPS128/DPS64 cards is 28 MB. If you run out of available channel memory, it is recommended to use a separate port for the DPS128/DPS64. For details see [Typical issues when converting to DPS128 ](<../../03_Use_cases_and_application_papers/03.12_SmarTest_Program_Migration_Framework/03.12.10.03_Typical_issues_when_converting_to_DPS128.md>).

The minimum period for DPS128/DPS64 is 20 ns. In case of period incompatibilities in a test program, it is recommended to use a separate timing port for the DPS128/DPS64. For details see [Typical issues when converting to DPS128 ](<../../03_Use_cases_and_application_papers/03.12_SmarTest_Program_Migration_Framework/03.12.10.03_Typical_issues_when_converting_to_DPS128.md>).

For further details see also [Minimum period / maximum frequency of the sequencer](<../02.08_Setup_and_Result_Tools/02.08.04.34.06.05.01_Minimum_period___maximum_frequency_of_the_sequencer.md>).

## DC Scale Limits

DC Scale Limits is a safety feature for the DC Scale power supply cards. The limits cannot be exceeded. If the voltage or current is too high or too low, an error message is triggered. See also [Setting DC Scale voltage and current limits](<../02.08_Setup_and_Result_Tools/02.08.04.18.02.11_Setting_DC_Scale_voltage_and_current_limits.md>).

## Level Setup tool

The Level Setup tool displays the currently active [DPSPINS resource](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>) settings of the DC Scale card as follows:

- Force voltage (vout)
- Clamp current (ilimit)

  - Source current limit (ilimit_source) (see also below)
  - Sink current limit (ilimit_sink) (see also below)

- Setup time (t_ms)
- Off current state (offcurr)
- Force voltage range (vout_frc_rng)
- Clamp current range (iout_clamp_rng)
- Constant current check (disable_const_curr_check)
- Connect state (connect_state)

For a more detailed description see [How to read the DPS Setup window](<../02.08_Setup_and_Result_Tools/02.08.04.14.03.02_How_to_read_the_DPS_Setup_window.md>).

## Different limits for source and sink current

For DC Scale DPS128/DPS64 cards, the maximum source current per card or channel is different to the maximum sink current per card or channel. For the exact values see [DPS128鈥?鈥奃PS64 specifications](<02.05.05.01.02_DPS128____PS64_specifications.md>).

To use all features of the power supply card in DPS mode, especially when operating close to the power limits, you must use equations. The following [DPSPINS resources](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>) were either changed or introduced with the DPS128/DPS64:

 |
 |

 |

Sets only the source current limit

 |

 |

 |

Any specified current limits must be within the current force (clamp) ranges listed in the [DPS128鈥?鈥奃PS64 specifications](<02.05.05.01.02_DPS128____PS64_specifications.md>). For DPS128/DPS64 cards, the iout_clamp_rng is rounded up to the next current force (clamp) range. If ilimit falls into this range there is no error or warning if ilimit is larger than the iout_clamp_rng.

For further details see [Setting DC Scale voltage and current limits](<../02.08_Setup_and_Result_Tools/02.08.04.18.02.11_Setting_DC_Scale_voltage_and_current_limits.md>), [Level Equations](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03_Structure_of_an_equation_based_level_setup.md>), and [DPSPINS resources](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>) (also [DPSPINS](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07_DPSPINS.md>)).

## Parallel dynamic and static DC actions

The DPS128/DPS64, when starting the sequencer with the [SQST RUN](<../02.06_Command_Reference/02.06.02.02.241_SQST__SQST__-__SeQuencer_STate.md>) firmware command or with the [SEQUENCER_STATUS run()](<../02.07_Test_Method_Reference/02.07.04.01.204_SEQUENCER_STATUS_-__Sequencer.md>) member function, cannot execute dynamic and static DC actions in parallel. For measurements during a sequencer run use profiling. [Profiling](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.05.03.05_Profiling_of_DC_Scale_cards_with_Hardware_view.md>) allows to measure in parallel to a dynamic pattern.

## Compare event for counted match loops in Pattern editor

The DPS128/DPS64 supports compare events for the last compare vector of counted match loops. In the Properties view of the event you can set the Compare Type to either High or Low. ## Automatic down-ranging

DPS128/DPS64 channels feature automatic down-ranging for current measurements.

Automatic down-ranging means that the current range is automatically changed to the best fit range for the measurement and restored to the original range after the measurement.

 Two parameters define whether the automatic down-ranging is performed or not:

- The force current or clamp current range:

  - Can be set explicitly or (if not defined)
  - is automatically derived from the forced or clamped value.

- The current measurement range:

  - Can be set explicitly or (if not defined)
  - is automatically derived from the pass/fail thresholds.

Automatic down-ranging is performed only if the current measurement range is lower than the force / clamp current range regardless whether the ranges have been set explicitly or have been selected automatically.

Automatic down-ranging is supported for both [code鈥慴ased](<../02.07_Test_Method_Reference/02.07.01.01.02_Code-based_and_pattern-based_programming.md#_355202__s_Code-based_programming>) programming using the [SPMU_TASK](<../02.07_Test_Method_Reference/02.07.04.01.234_SPMU_TASK.md>) and [DPS_TASK](<../02.07_Test_Method_Reference/02.07.04.01.50_DPS_TASK.md>) test method APIs and the [pattern鈥慴ased](<../02.07_Test_Method_Reference/02.07.01.01.02_Code-based_and_pattern-based_programming.md#_355202__s_Pattern-based_programming>) programming using the [DC events](<../02.07_Test_Method_Reference/02.07.04.01.63_EVENT_...__DC_events_API_reference.md>) and is also supported by [SmartRDI](<../02.07_Test_Method_Reference/02.07.13.12.02_Setting_up_DC_Scale_pins_with_SmartRDI.md>).

For more information, refer to the [DC Scale DPS128/64 HC/HV Cookbook](<../../03_Use_cases_and_application_papers/03.06_DC_Scale_Cards_Use_Cases/03.06.01_DC_Scale_DPS128_64_HC_HV_Cookbook.md>), section 4.2.1 Auto-Ranging Use Model.
