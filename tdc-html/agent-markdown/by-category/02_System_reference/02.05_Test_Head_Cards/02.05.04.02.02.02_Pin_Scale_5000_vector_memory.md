# Pin Scale 5000 vector memory

## General

The maximum amount of memory to be used for storing vectors is 448 MiByte per pin. The usable amount of memory depends on the given memory license. For maximum vector memory license, vector memory will be shared with a configurable amount of memory for sequencer instructions, result buffers, and level/timing sets.

Vector memory content can be shared across pins within a group of 8 pins for input, output. Result and capture memory for an output and input/output pin will still be available per individual pin. With current SmarTest software, sharing of memory content across pins is only supported for the same pin across sites.

## Scan vector modes

Every pin can be used as scan-in or scan-out pin. Switching between scan-in and scan-out within a pattern burst is supported. Scan vector mode means that due to the reduced states set, the vectors can be stored with better efficiency using either X8 (scan-in) or X5 (scan-out) mode.
