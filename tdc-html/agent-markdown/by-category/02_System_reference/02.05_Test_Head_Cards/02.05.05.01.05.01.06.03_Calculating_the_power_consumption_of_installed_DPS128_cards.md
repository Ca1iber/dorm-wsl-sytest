# Calculating the power consumption of installed DPS128 cards

To be able to calculate the power requirements for existing DPS64 or DPS128 cards, the configuration files for model, limits, and pin configurations from the existing DPS64/12832-based test system are used as the inputs for the DPS128 Power Calculator.

The DPS128 Power Calculator calculates from the provided inputs the

- required DC-Scale cards,
- the pogo cable assembly types, and the
- power per domain.

The recommended card position and detailed information about pin usage is also displayed by the DPS128 Power Calculator.

To calculate the power requirements for predefined DPS64 and DPS128 cards, complete the following steps:

- Load the DPS128-compatible configuration files for model, limits, and pin configuration using the load file browser (File > Load menu items).

To display which files are currently selected, click Loaded files.

- Click the Calculate button to determine the required DPS128 cards and cables assemblies.

Domain power results displayed against a green background are within the available power for the selected card. If the available power is exceeded, the power requirement values are displayed on a red background.

Selections that are within the overall power availability, but cannot provide sufficient power for individual pins, result in the affected pin data being displayed against a red background. For each affected pin, a tooltip provides information about the underlying problem.

- Optional: Select a global safety margin value from the Margin dropdown.

The total power available per domain is recalculated and displayed in the top line of the DPS128 Power Calculator main window. If you select a margin value before clicking Calculate, the calculation is executed simultaneously.

- Optional: Export the calculated results in CSV format to a file using the export file browser (File > Export menu).
 Note The DPS128 Power Calculator needs to read some information from the model file and the level specifications before the pin configuration can be processed. You should therefore always import the required files in the following order:

- File > Load Model
- File > Load limit or spec
- File > Load Pin
