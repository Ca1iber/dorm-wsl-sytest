# PS1600 jitter injection

The PS1600 card allows you to inject jitter into the drive signal for stress testing of the DUT.

## Modes

The jitter modulator has three global modes: off, restart, and continuous.

In off mode, no jitter is injected. This is the default. In restart mode, the jitter modulator stops after each functional test and restarts with the next. In continuous mode, the jitter modulator starts with the first functional test and keeps running.

Smart Scale cards also support the pattern controlled start and stop of jitter injection within one functional test. See the JTIN instruction in [Sequencer instructions](<../02.08_Setup_and_Result_Tools/02.08.04.16.02.06.10.02_Sequencer_instructions.md>).

## Jitter waveforms

Jitter injection can be setup up either manually with specified waveform values, or using predefined jitter waveforms.

Predefined jitter waveforms are sine waveforms, rectangular waveforms, or triangular waveforms.

## Jitter Sets

The jitter settings are stored in jitter sets.

Jitter sets are global to the system. Only one jitter set can be active at a time. However, within the set the jitter settings are defined per pin. This allows different jitter parameters for different pins.

The jitter sets are included in the primary activation sequence and are thus automatically used for the next functional test. Up to 128 jitter sets can be stored in the hardware.
