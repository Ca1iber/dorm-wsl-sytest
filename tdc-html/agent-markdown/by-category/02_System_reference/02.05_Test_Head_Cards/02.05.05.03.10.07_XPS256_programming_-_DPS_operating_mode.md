## Pin definition

An XPS256 pin is configured to operate in DPS operating mode if it is defined as a device power supply using the [DPS Pins editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.03_DPS_Pins_editor.md>). As for all other DC Scale cards, the parameter Pol is to be set to POS.

## Hardware view

[Hardware view](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.05.03_Hardware_view.md>) of XPS256 in DPS operating mode:

 |

- Measure

Performs a single or looped voltage or current measurement.

- [Check Status Flags](<02.05.05.03.10.02_XPS256_status_flags.md>)

Reads and clears the latched status flags.

- [Profiling](<02.05.05.03.03.05_XPS256_profiling.md>)

Starts profiling of the voltage or current and displays the sampled waveform.

- [Force Sense Check](<02.05.05.03.10.12_XPS256_programming_-_Kelvin_test___sense_connection_test.md>)

 |

- [Surge Tracker](<02.05.05.03.10.17_XPS256_programming_-_Surge_tracker.md>)

Reads and clears the latched status of the surge tracker.

- [Max Voltage Drop](<02.05.05.03.10.19_XPS256_programming_-_Voltage_drop_measurement.md>)

Reads the latched maximum voltage drop for the force line and for the return line and resets the two values.

- [Measure Voltage Drop](<02.05.05.03.10.19_XPS256_programming_-_Voltage_drop_measurement.md>)

Performs a single or looped voltage drop measurement for the force line and for the return line.

- [Check Gang Connection](<02.05.05.03.10.10_XPS256_programming_-_Ganging.md#_354657__s_Checking_the_gang_connections>)

Performs a connection check for all ganged channels of the pin.

  |   Measure dialog and other sub‑dialogs

 |

In the Measure dialog you cannot only set the standard parameters, but also switch a capacitance on the DUT board for the measurement.

The related utility pin, the target state of the pin, and the target capacitance can be defined in the Measure dialog:

   ![XPS256 HW view DPS Measure dialog](<../../../../raw/355120.png>) |

Several other fields that are marked in white can be changed in several sub‑dialogs.

An example for the other sub‑dialogs is the DPS Protection dialog that allows you changing parameters such as the maximum voltage drop or the status of the internal force to sense connection, which is named Open Loop Protection:

   ![XPS256 HW view DPS Protection dialog (355804)](<../../../../raw/355804.png>) |

See also the related information in the [API overview](<02.05.05.03.10.13_XPS256_programming_-_Measure_currents.md#_354458__r_switchableCap>) of [XPS256 programming - Measure currents](<02.05.05.03.10.13_XPS256_programming_-_Measure_currents.md>).

  Site selection The XPS256 hardware view for the DPS operating offers at the top a selection for the sites to be set or displayed:

- Focus Site Only: Measured results are displayed only for the site in focus. Settings in fields marked in white that are changed in a sub‑dialog are applied only to the site in focus.
- All Active Sites: Measured results are displayed for all active sites. Settings in fields marked in white that are changed in a sub‑dialog are applied to all active sites.

Settings that differ on the sites are highlighted in yellow. When you hover the cursor over such a field, the different settings are displayed in a tooltip.

  ![XPS256 HW view DPS All active sites](<../../../../raw/355929.png>)    Multisite results table

If All Active Sites is activated and a measurement is triggered by on of the measure dialogs, the measurement is executed on all active sites and a table with all results opens on the right. The results table is available for measurements made using the Measure, Max Voltage Drop, Measure Voltage Drop, Force Sense Check, or Check Gang Connection buttons.

   ![XPS256 HW view DPS Multisite results](<../../../../raw/355930.png>)

The result table shows the results of only the last measurement. You can sort the table by each column and also use a filter term in the top row marked in blue. The results can be exported as CSV file using the Export button ![Export](<../../../../raw/353795.png>) on the hardware view toolbar.

## Setup

We recommend programming the basic settings with the [level setup](<../02.08_Setup_and_Result_Tools/02.08.04.14_Level_setup_tool.md>) and applying changes in the pattern‑based mode of SmartRDI or with [DC events](<../02.07_Test_Method_Reference/02.07.04.01.63_EVENT_...__DC_events_API_reference.md#_345840__s_Event_classes_and_data_types>).

## Level setup overview

Force and clamp settings and the dynamic behavior of an XPS256 pin in the DPS operating mode are controlled by the [level setup](<../02.08_Setup_and_Result_Tools/02.08.04.14_Level_setup_tool.md>). To access all features of the card you must use equations. For details see the [Equation based level setup](<../02.08_Setup_and_Result_Tools/02.08.04.14.02_Equation_based_level_setup.md>) and [DPSPINS resources](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>).

## SmartRDI overview

The complete functionality to set up an XPS256 pin in the DPS operating mode is covered by the dc() API of SmartRDI. Both the code‑based mode and the pattern‑based mode are supported. For more information refer to [Setting up DC Scale pins with SmartRDI](<../02.07_Test_Method_Reference/02.07.13.12.02_Setting_up_DC_Scale_pins_with_SmartRDI.md>) and the related member functions of the dc() API.

## API overview

Voltage or current measurements of an XPS256 pin in the DPS operating mode are covered by API [DPS_TASK](<../02.07_Test_Method_Reference/02.07.04.01.50_DPS_TASK.md>).

Pattern‑based setups and measurements are supported by the [DC events](<../02.07_Test_Method_Reference/02.07.04.01.63_EVENT_...__DC_events_API_reference.md#_345840__s_Event_classes_and_data_types>). For the maximum pattern frequency, refer also to [Minimum period / maximum frequency of the sequencer](<../02.08_Setup_and_Result_Tools/02.08.04.34.06.05.01_Minimum_period___maximum_frequency_of_the_sequencer.md>).
