# Clock board specific setup tasks

## Master clock board configuration

Small test head: In the small test head, the clock board in card cage 1 will automatically configure itself as the master.

Large test head: In the large test head, the clock board in card cage 5 will be the master. In this configuration, you have the option of using the Local PLL or the external clock source.

The clock boards in the other card cages will all be classed as slave clock boards.

## Functional changes

- Introduced before SmarTest 6.3.2
