# Card types

#### Subtopics

- [DC-DC granularity](<02.05.01.02.01_DC-DC_granularity.md>)

A V93000 test head can be equipped with different types of test head cards.

A test head primarily contains the following cards:

- [Digital cards](<02.05.04_Digital_cards.md>)
- Device Power Supplies and VI Cards

  - [DC Scale cards](<02.05.05_DC_Scale_cards.md>) (residing in channel card slots)

- DC/DC converter

  - For the power supply to the card cage slots.
  - In Smart Scale systems, each DC/DC converter card supplies power to two adjacent slots in the card cage.
  - For Smart Scale systems, see also [DC/DC granularity](<02.05.01.02.01_DC-DC_granularity.md>).

Configuration guidelines:

Configuration of the test system involves assigning digital channel cards and power supplies to specific channels of the test head.

The [Card Cage to Pogo Block Standard Assignments](<../02.02_Specifications/02.02.03_Card_Cage_to_Pogo_Block_Standard_Assignments.md>) and the [Card compatibility](<../02.02_Specifications/02.02.03.01_Card_compatibility.md>) topic provide an overview of the rules for configuring products and hardware to ensure compatibility and scalability of the test system.
