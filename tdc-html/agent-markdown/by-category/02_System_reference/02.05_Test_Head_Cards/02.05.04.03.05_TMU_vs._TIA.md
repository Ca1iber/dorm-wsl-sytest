# TMU vs. TIA

The TMU (Time Measurement Unit) and the TIA (Time Interval Analyzer) address a very similar scope of measurements, for example, period measurements, jitter measurements, and so on.

But because the TIA (Time Interval Analyzer) per pin is not available on Smart Scale generation cards and the TMU (Time Measurement Unit) per pin is not available on elder Pin Scale cards, you must use

- TMU per pin on Smart Scale cards, and
- TIA per pin on Pin Scale cards.

For details see [Concepts of the ppTMU](<../02.06_Command_Reference/02.06.13.01_Concepts_of_the_TMU_per_pin.md>).

If you use Smart Scale generation cards you may have to convert ppTIA related tests to ppTMU tests. For details on the conversion procedure see [Migrating TIA per pin to TMU per pin](<../../03_Use_cases_and_application_papers/03.12_SmarTest_Program_Migration_Framework/03.12.06_Migrating_TIA_per_pin_to_per_TMU_per_pin.md>).
