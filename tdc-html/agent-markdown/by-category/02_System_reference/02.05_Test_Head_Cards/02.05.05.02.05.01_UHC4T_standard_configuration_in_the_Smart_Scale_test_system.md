# UHC4T standard configuration in the Smart Scale test system

Each DC Scale UHC4T card occupies two pogo block locations

The standard configuration for UHC4T pogo blocks is in group 8, in location 227/427 and location 230/430 (S1/S2).

In the recommended standard configurations, these pogo locations are reflected in the POGOCABLING section of the legacy model file.

## Restrictions

The UHC4T pogo blocks are not allowed in outer segments of groups 4, 5, 6, and 7, as marked in the graphic below.
