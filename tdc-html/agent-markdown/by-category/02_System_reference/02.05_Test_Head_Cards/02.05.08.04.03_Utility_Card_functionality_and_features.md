# Utility Card functionality and features

The EK051A Utility Card extends the utility lines and utility power supplies of a V93000 EXA Scale system.

## Key characteristics of a EK051A Utility Card

A Utility Card provides the following resources:

- 256 utility lines:

  - Open drain output
  - 100 mA per line
  - Dynamical (sequencer) control

- Multiple utility power supplies:
