# Identifying Pin Scale vs. Smart Scale test systems

If you do not know whether your test system is of the 2nd generation (Pin Scale) or 3rd generation (Smart Scale) you can use the table below listing some differentiating criteria to identify the test system generation.

 Note Pin Scale is not supported in SmarTest 8.

There are as well criteria to differentiate Pin Scale from single-density test systems. This is out of scope here.

For information on hardware revision, refer to Reading the result file edc_codes.
