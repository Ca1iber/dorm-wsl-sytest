# Pin Scale 5000 feature scope

The following features of the Pin Scale 5000 digital card are not supported by SmarTest 7.10.3 but subject to a later release:

- [time measurement unit](<../02.02_Specifications/02.02.04.03.06_Pin_Scale_5000_time_measurement_unit.md>)
- FAST mode capable of speeds up to 5.0 Gbps Note A pre-release version of FAST mode has been enabled on SmarTest 7.10.3 only for evaluation purposes.
- Using PPMU as arbitrary waveform generator (AWG)

## Functional changes

- Introduced in SmarTest 7.10.2
