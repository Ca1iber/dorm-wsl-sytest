# Pin Scale 1600 TMU overrun errors

When doing measurements on the PS1600, several kinds of overrun errors can occur.

- VDL Busy Error

This happens if the samples arrive too frequently. This can occur if you specify a data rate which is lower than the actual data rate. For most measurement, this is fatal and the results are invalid.

- Arming Early Error

When this error is flagged, not enough events made it through the TMU between two armings. This means, that the number of samples required could not be taken. This may not be a problem if you can accept a non deterministic number of samples. However, this should be avoided by increasing the time between to armings or by reducing the number of samples to be acquired.

- Deglitcher Error

This error can occur, if the prescaler is programmed incorrectly.

-  NOT_FINISHED Error

 Indicates that the TMU is still busy because it did not receive any or not enough events. This can be caused, for example, by a wrong threshold level.
