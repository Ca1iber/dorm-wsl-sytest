# XPS256 programming - Load step response

The load step response achieved for the XPS256 depends on several settings of the instrument, the capacitors on the DUT board, and finally the height and slew rate of the load step.

## Load step response

The load step response of XPS256 depends on several programmable settings, the actual current range, the impedance of the high force and low force traces on the DUT board, the [capacitors on the DUT board](<../02.03_DUT_board_design_reference/02.03.08.01.07.02_XPS256_capacitor_requirements.md>) and on the height and the slew rate of the load step.

 In addition to the current range, the following programmable settings have an effect on the load step response:

 |   | Load step mode:  | Independent of the digital control loop, the dynamic behavior of the output stage can be adapted directly by modifying the analog feedback path of the output stage. |
 | Voltage bandwidth:  | The selected voltage bandwidth has an effect on the load step response for a pin that is forcing or clamping voltage. |
 | Current bandwidth:  | The selected current bandwidth has an effect on the load step response for a pin that is forcing or clamping current. |
 | Load capacitance:  | The set load capacitance also has an effect on the load step response for a pin that is forcing or clamping voltage. |

The Voltage slew rate and the Current slew rate are also programmable parameters. These settings have an effect only for changes of the programmed force value. However, if changing the force value also changes the DUT voltage or the load current, the slew rate will also have an indirect effect on the load step response of XPS256.

For more information, refer also to [Recommendations for optimizing the load step response](<02.05.05.03.09_XPS256_load_step_response.md#_352239__s_Recommendation>) in topic [XPS256 load step response](<02.05.05.03.09_XPS256_load_step_response.md>).

## Bandwidth, slew rate, and load capacitance settings of XPS256

The following settings are available for the XPS256 card:

- Voltage bandwidth

The voltage bandwidth has an effect on the load step response for an instrument that is forcing or clamping voltage.

 | Range  | Min  | Max  | Default |
 | 1.5 V  | 2 Hz  | 50 kHz  | 10 kHz |
 | 7 V  | 2 Hz  | 50 kHz  | 10 kHz |
- Voltage slew rate

The parameter defines the slew rate for changes of the programmed voltage force value.

 | Range  | Min  | Max  | Default |
 | 1.5 V  | 10 渭V/渭s  | 2 V/渭s  | 50.0 mV/渭s |
 | 7 V  | 45 渭V/渭s  | 2 V/渭s  | 50.0 mV/渭s |
- Current bandwidth

The current bandwidth has an effect on the load step response for an instrument that is forcing or clamping current.

 | Range  | Min  | Max  | Default |
 | All current ranges  | 10 Hz  | 500 kHz  | 10 kHz |
- Current slew rate

The parameter defines the slew rate for changes of the programmed current force value.

 | Range  | Min  | Max  | Default |
 | 1 A  | 10.0 渭A/渭s  | 200.0 mA/渭s  | 10.0 mA/渭s |
 | 100 mA  | 1.0 渭A/渭s  | 20.0 mA/渭s  | 10.0 mA/渭s |
 | 10 mA  | 100.0 nA/渭s  | 2.0 mA/渭s  | 2.0 mA/渭s |
 | 1 mA  | 10.0 nA/渭s  | 200.0 渭A/渭s  | 200.0 渭A/渭s |
 | 100 渭A  | 1.0 nA/渭s  | 20.0 渭A/渭s  | 20.0 渭A/渭s |
 | 10 渭A  | 100.0 pA/渭s  | 2.0 渭A/渭s  | 2.0 渭A/渭s |

The values defined in the table above apply for a single channel. For ganging groups, the current slew rate of the 1 A range can be multiplied by the number of ganged channels.

- Load capacitance

The load capacitance settings have an effect on an instrument that is forcing or clamping voltage.

 | Range  | Min  | Max[1)](<#fntarg_1>)  | Default |
 | 1 A  | 0.0 mF  | 1.0 mF  | 0.0 mF |

 | 10 mA  | 0.0 渭F  | 10.0 渭F  | 0.0 渭F |
