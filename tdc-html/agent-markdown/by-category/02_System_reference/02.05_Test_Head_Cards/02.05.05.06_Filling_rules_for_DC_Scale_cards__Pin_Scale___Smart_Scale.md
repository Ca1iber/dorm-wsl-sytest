# Filling rules for DC Scale cards (Pin Scale & Smart Scale)

DC Scale cards can reside in any channel card slot of a card cage but the following filling rules must be respected for V93000 Smart Scale and Pin Scale systems:

- A pair of adjacent odd and even slots must be filled with the same card type. For details see [Card compatibility](<../02.02_Specifications/02.02.03.01_Card_compatibility.md>).
- On the large DUT interface, no UHC4T pogo block is allowed in the four outer half-groups. For details see [UHC4T standard configuration](<02.05.05.02.05.01_UHC4T_standard_configuration_in_the_Smart_Scale_test_system.md>).

These filling rules apply only to V93000 Smart Scale and Pin Scale systems.
