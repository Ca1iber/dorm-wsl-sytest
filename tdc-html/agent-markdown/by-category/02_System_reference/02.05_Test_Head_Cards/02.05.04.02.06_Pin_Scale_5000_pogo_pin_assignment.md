# Pin Scale 5000 pogo pin assignment

The Pin Scale 5000 card supports three different pogo cable assemblies: The standard (STD) compatible 16x16 pogo cable assembly, the high-density (HD) 8x32 pogo cable assembly and the very-high-density (VHD) 4x64 pogo cable assembly.

## Pogo pin assignment SD pogo block

 The standard-density (SD) pogo block (sometimes referred to as a single-density pogo block) connects 16 channels of a Pin Scale 5000 card to the DUT board. The SD block is used for the following Pin Scale 5000 pogo cable assembly:

- [PS5000 pogo cable assembly EK601-61602: 16 SD pogo blocks](<../02.03_DUT_board_design_reference/02.03.06.03.05.01_PS5000_pogo_cable_assembly_EK601-61602__16_SD_pogo_blocks.md>)

The SD pogo block can also connect to DUT boards that are designed for the HD pogo block or for the VHD pogo block but can access only the channels A1 …nbsp;A16 on rows b and c. For more information, refer to [Pogo block compatibility](<../02.03_DUT_board_design_reference/02.03.07.07.01_Pogo_block_compatibility.md>).

## Pogo pin assignment HD pogo block

 The high-density (HD) pogo block connects 32 channels of a Pin Scale 5000 card to the DUT board. The HD block is used for the following Pin Scale 5000 pogo cable assembly:

- [PS5000 pogo cable assembly EK601-61603: 8 HD pogo blocks](<../02.03_DUT_board_design_reference/02.03.06.03.05.02_PS5000_pogo_cable_assembly_EK601-61603__8_HD_pogo_blocks.md>)

The HD pogo block can also connect to DUT boards that are designed for the SD pogo block as long as landing pads are provided for the extra pogo pins of the HD block. In addition, the HD pogo block can connect to DUT boards that are designed for the VHD block but can access only channels A1 …nbsp;A16 and B1 …nbsp;B16 on rows a, b, c, and d. For more information, refer to [Pogo block compatibility](<../02.03_DUT_board_design_reference/02.03.07.07.01_Pogo_block_compatibility.md>).

## Pogo pin assignment VHD pogo block

 The very-high-density (VHD) pogo block connects 64 channels of a Pin Scale 5000 card to the DUT board. The VHD block is used for the following Pin Scale 5000 pogo cable assembly:

- [PS5000 pogo cable assembly EK601-61604: 4 VHD pogo blocks](<../02.03_DUT_board_design_reference/02.03.06.03.05.03_PS5000_pogo_cable_assembly_EK601-61604__4_VHD_pogo_blocks.md>)

The VHD pogo block can also connect to DUT boards that are designed for the SD pogo block or for the HD pogo block as long as landing pads are provided for the extra pogo pins of the VHD block. For more information, refer to [Pogo block compatibility](<../02.03_DUT_board_design_reference/02.03.07.07.01_Pogo_block_compatibility.md>).

## Specific design rules

Specific design rules must be followed when designing a new DUT board and assigning PS5000 channels:

- [Pogo pad and via design](<../02.03_DUT_board_design_reference/02.03.07.07_Pogo_pad_and_via_design.md>): The standard recommendations for pogo pads and vias apply to all pogo block types of the Pin Scale 5000 pogo cable assemblies.
- [Differential pin pair assignment](<../02.03_DUT_board_design_reference/02.03.08.03.01.01_PS5000_differential_pin_pair_assignment.md>): Pin Scale 5000 channels can be configured as single ended channels or as differential channel pairs. The topics shows the assignment of the differential pin pairs on each pogo block.
- Note Ganging is not supported in SmarTest 7. [Ganging](<../02.03_DUT_board_design_reference/02.03.08.03.01.02_PS5000_ganging.md>): Pin Scale 5000 channels support the ganging of two adjacent channels. The arrangement of the channels must be taken into account when designing a DUT board.
- Note

The remote sensing feature is not available in SmarTest 8.4.4 but subject to a later SmarTest release.

Remote sensing is not supported in SmarTest 7.

 [Remote sensing](<../02.03_DUT_board_design_reference/02.03.08.03.01.03_PS5000_remote_sensing.md>): Pin Scale 5000 channels support remote sensing via the neighboring channel. The arrangement of the channels must be taken into account when designing a DUT board. For applications that need remote sensing and high-speed digital I/O capability on the same DUT pin, relays can be required to disconnect the sense line.
-  [Ground sensing](<../02.03_DUT_board_design_reference/02.03.08.03.01.04_PS5000_ground_sensing.md>): Pin Scale 5000 cards feature remote sensing of the common ground. The ground sense pins are available per 16 channels for SD and HD pogo blocks and per 32 channels for the VHD pogo blocks. The assignment of the ground sense pins to the channels must be taken into account when designing a DUT board.
- [Pin assignment for Fast Sync / Fast Match](<../02.03_DUT_board_design_reference/02.03.07.06_Pin_assignment_for_Fast_Sync___Fast_Match.md>): For fast local synchronization, the synchronized DUT pins must be assigned to the same group of channels respectively to the same test processor.
- [Recommendations for use](<../02.03_DUT_board_design_reference/02.03.08.03.01.05_PS5000_recommendations_for_use.md>): Recommendations like the [Sense connection test](<../02.03_DUT_board_design_reference/02.03.08.03.01.05_PS5000_recommendations_for_use.md#_352216__s_Sense_connection_test>) may influence the channel assignment.
- [HV (High-Voltage) protection](<../02.03_DUT_board_design_reference/02.03.07.03_HV__High-Voltage__protection.md>): PS5000 channels are protected against high voltage in the range from -80 V to +80 V. Since PS5000 channels may be connected to high-voltage cards via defective DUTs or unintentionally closed connections, we recommend that you implement a high-voltage protection circuitry on your DUT boards if other cards or inductive loads on the DUT board can cause this voltage range to be exceeded.To assess whether separate high-voltage protection is required, you must also take into account spikes caused by inductive loads or the inductance of traces on the DUT board or of cables.

See also [High-speed DUT board design](<../02.03_DUT_board_design_reference/02.03.07.02_High-speed_DUT_board_design.md>).
