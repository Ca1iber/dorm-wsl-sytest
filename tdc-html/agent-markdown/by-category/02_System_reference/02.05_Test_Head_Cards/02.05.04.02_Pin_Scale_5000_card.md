The Pin Scale 5000 (PS5000) is the digital base card of EXA Scale™ It can be used in EXA Scale™test systems only.

With 256 channels per card, it supports higher pin count and higher multisite testing, which enables smaller infrastructure usage and cost.

It has memory modules providing 448 MB of dedicated memory per channel. The maximum number of vectors that will completely fill up the vector memory can be determined from the physical memory size (448 MB) times the used X-mode. For example in the case of X-8 mode, the maximum number of vectors is 448MVectors * 8 = 3.584GVectors. However, be aware that this memory is also shared with other components of your test program, for example: sequencer instructions, vector padding, as well as digital and DC sets. Thus, the actual memory for your vectors is generally less than what is calculated above.

The Pin Scale 5000 addresses test requirements such as:

- IPs with increasing number of cores
- Higher speed serial and parallel interfaces
- More parametric DC, smaller geometries
- Higher scan data volume
- System like stress test
