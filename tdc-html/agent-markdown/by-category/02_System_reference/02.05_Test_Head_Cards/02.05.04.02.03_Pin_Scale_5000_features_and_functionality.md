The Pin Scale 5000 next generation digital card features a number of card specific functionalities as listed below.

## Licensing

A Pin Scale 5000 Base Capability license is required and can be specified in the device license file by adding the digitalFrontEnd license. Details of the available licenses can be found in [V93000 License Master Look-up Table](<../02.04_Model_File_and_Licensing/02.04.02.01_V93000_License_Master_Look-up_Table.md>) (filter with Product description = Pin Scale 5000 and DLF/TPLF definition = digitalFrontend).

## Channels

The Pin Scale 5000 card features 256 single ended I/O channels or 128 differential channel pairs. A card consists of eight channel modules with 32 single ended (or 16 differential) channels in each channel module.

## Pogo assemblies

The Pin Scale 5000 card supports three different pogo cable assemblies:

- the [standard (STD) compatible 16x16 pogo cable assembly](<../02.03_DUT_board_design_reference/02.03.06.03.05.01_PS5000_pogo_cable_assembly_EK601-61602__16_SD_pogo_blocks.md>)
- the [high-density (HD) 8x32 pogo cable assembly](<../02.03_DUT_board_design_reference/02.03.06.03.05.02_PS5000_pogo_cable_assembly_EK601-61603__8_HD_pogo_blocks.md>)
- the [very-high-density (VHD) 4x64 pogo cable assembly](<../02.03_DUT_board_design_reference/02.03.06.03.05.03_PS5000_pogo_cable_assembly_EK601-61604__4_VHD_pogo_blocks.md>)

## General features

 |

Data rates

 |

The Pin Scale 5000 digital card can handle data rates up to 5000 Mbit/s drive, receive and capture, given the prerequisites listed in [Pin Scale 5000 basic parameters](<../02.02_Specifications/02.02.04.03.01_Pin_Scale_5000_basic_parameters.md>).

 |
 |

Independent clock domains

 |

Independent clock domains per pin enable each pin to run at a different data rate. This allows:

- Unconstrained routing on the test fixture
- Concurrent testing of all interfaces at their native data-rates
- Optimized tester resource utilization with per pin granularity
- Each pin to synthesize its own and independent data-rate
 |

 |

 Pattern synchronous DC value measurements (see [Pin Scale 5000 DC value measurements](<02.05.04.02.07.02_Pin_Scale_5000_DC_value_measurements.md>)) can be performed during the execution of a pattern using either the board ADC (BADC), the pin PMU (PPMU), or both depending on the accuracy you require. This feature is also referred to as sequencer鈥慶ontrolled measurement of values.

 |
 |

Embedded timing search (fast adjustment)

 |

 [Embedded timing search (fast adjustment)](<02.05.04.02.03.02_Pin_Scale_5000_embedded_timing_search.md>) per-pin functionality allows you to adjust your timing to the actual behavior of the DUT. As this feature is embedded, it saves test time, as the data does not need to be uploaded to the workstation.

 |
 |

Preventing floating pins

 |

The active load should help to prevent a floating pin rather than a pull-down resistor.
