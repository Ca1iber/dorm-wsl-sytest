# XPS256 safety line and DUT board disconnect

XPS256 pins provide a safety line shutdown per site that is controlled by utility pins. This hardware鈥慶ontrolled shutdown can be configured for selected XPS256 pins or as a global disconnect shutdown for all XPS256 pins. It can be used for both the PMU operating mode and the DPS operating mode.

Since the shutdown is controlled by the hardware and cannot be delayed or hindered by the software, it reliably protects the DUT, the probes or DUT sockets and the DUT board.

The shutdown is triggered by utility lines of the optional [Utility Card](<02.05.08.04_Utility_Card.md>). In the [Utility Pins editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.04_Utility_Pins_editor.md>), the utility pins are configured in such a way that a trigger signal is send via an internal data path if the input level of the utility lines changes from low to high or from high to low. The trigger signal initiates the shutdown of the XPS256 pins assigned to the utility pins.

  ![Utility pins editor SmarTest 7.10.x](<../../../../raw/354720.png>)  In this context, low or high means the input voltage level of the utility lines:

 |   | Low:  | The utility line is tied to utility ground (UGND) or is forced to a voltage below the low threshold. |
 |   | High:  | The utility line is left open or is forced to a voltage above the high threshold. If the line remains open, it will be pulled to the high level by an internal pull鈥憉p resistor.  | For the minimum and maximum input voltage and the thresholds for detecting the low or high level, refer to [Utility lines (V93000 EXA Scale systems)](<../02.03_DUT_board_design_reference/02.03.04.02.01_Utility_lines__V93000_EXA_Scale_systems.md>).

## Safety line shutdown

Safety line shutdown means that defined XPS256 pins are automatically disconnected if an abnormal operating condition is detected. Trigger sources can be, for example, the DUT itself or monitoring hardware on the DUT board.

The characteristics of the safety line shutdown are as follows:

- Only one utility pin can be configured for the safety line shutdown.
- The utility pin can be configured for low to high level changes or for high to low level changes.
- Site鈥憇pecific utility lines or shared utility lines can be assigned to the utility pins.
- Only XPS256 pins that are assigned to a configured utility line are shutdown in case of a trigger event is received.

For information on how to configure utility pins and XPS256 pins for a safety line shutdown, refer to [Safety line shutdown](<02.05.05.03.10.18_XPS256_programming_-_Safety_line_and_DUT_board_disconnect.md#_354937__s_Safety_line_shutdown>) in [XPS256 programming - Safety line and DUT board disconnect](<02.05.05.03.10.18_XPS256_programming_-_Safety_line_and_DUT_board_disconnect.md>).

## DUT board disconnect shutdown

DUT board disconnect shutdown means that all XPS256 pins are automatically disconnected if the trigger signal is received via the assigned utility line. Trigger source can, for example, be the utility line itself, which is controlled via a test method API of the program.

The characteristics of the DUT board disconnect shutdown are as follows:

- Only one utility pin can be configured for the DUT board disconnect shutdown.
- The utility pin can be configured for low to high level changes or for high to low level changes.
- Site鈥憇pecific utility lines or a shared utility line can be assigned to the utility pin.
- All XPS256 pins are assigned automatically to the utility pin as soon as it is defined. The shutdown is performed on all XPS256 pins.
For information on how to configure utility pins and XPS256 pins for a DUT board disconnect shutdown, refer to [DUT board disconnect shutdown](<02.05.05.03.10.18_XPS256_programming_-_Safety_line_and_DUT_board_disconnect.md#_354937__s_DUT_board_disconnect_shutdown>) in [XPS256 programming - Safety line and DUT board disconnect](<02.05.05.03.10.18_XPS256_programming_-_Safety_line_and_DUT_board_disconnect.md>).
