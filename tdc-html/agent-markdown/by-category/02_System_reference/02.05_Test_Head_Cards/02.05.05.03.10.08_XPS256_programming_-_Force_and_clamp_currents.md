# XPS256 programming - Force and clamp currents

Each channel of an XPS256 card features six combined force, clamp, and measure current ranges.

The XPS256 channels feature a real current force mode (CF) with programmable voltage clamp. Other DC Scale cards utilize the current clamp in voltage force mode.

## Current ranges

Each PMU features six combined force, clamp, and measure current ranges:

 | Variant  | Range  | Minimum and maximum current |
 | XPS256  | 1 A  | -1.0 A  | ...  | 1.0 A |
 | 100 mA  | -100.0 mA  | ...  | 100.0 mA |
 | 10 mA  | -10.0 mA  | ...  | 10.0 mA |
 | 1 mA  | -1.0 mA  | ...  | 1.0 mA |
 | 100 渭A  | -100.0 渭A  | ...  | 100.0 渭A |
 | 10 渭A  | -10.0 渭A  | ...  | 10.0 渭A |

The current ranges are common for forcing, clamping, and measuring currents. The force or clamp range is always the same as the measurement range. For specification data, refer to [XPS256 voltage specifications](<../02.02_Specifications/02.02.05.03.02_XPS256_voltage_specifications.md>).

## Minimum clamp current distance

The PMU of an XPS256 channel needs a minimum distance between the positive and negative clamp current to avoid oscillation.

 | Variant  | Current range  | Minimum clamp value  | Minimum clamp distance |
 | XPS256  | 1 A  | 10 mA  | 100 mA |
 | 100 mA  | 1 mA  | 10 mA |
 | 10 mA  | 100 渭A  | 1 mA |
 | 1 mA  | 10 渭A  | 100 渭A |
 | 100 渭A  | 1 渭A  | 10 渭A |
 | 10 渭A  | 100 nA  | 1 渭A |

The minimum clamp distance is the distance from the minimum negative clamp value to the minimum positive clamp value. Asymmetrical clamp current definitions within the ranges defined above are supported as long as the minimum clamp distance between the two values is maintained. For clamp current specifications, refer to table [Current clamp](<../02.02_Specifications/02.02.05.03.03_XPS256_current_specifications.md#_350736__s_Current_clamp>) in [XPS256 current specifications](<../02.02_Specifications/02.02.05.03.03_XPS256_current_specifications.md>).

## Dynamic behavior in force current or clamp current mode

The following force current filters are available for an XPS256 channel:

- Current bandwidth

This value defines a current bandwidth that has an effect on the dynamic behavior of an XPS256 channel that is forcing or clamping the current.

 | Range  | Min  | Max  | Default |
 | All current ranges  | 10 Hz  | 500 kHz  | 10 kHz |
- Current slew rate

The parameter defines the slew rate for changes of the programmed current force value.

 | Range  | Min  | Max  | Default |
 | 1 A  | 10.0 渭A/渭s  | 200.0 mA/渭s  | 10.0 mA/渭s |
 | 100 mA  | 1.0 渭A/渭s  | 20.0 mA/渭s  | 10.0 mA/渭s |
 | 10 mA  | 100.0 nA/渭s  | 2.0 mA/渭s  | 2.0 mA/渭s |
 | 1 mA  | 10.0 nA/渭s  | 200.0 渭A/渭s  | 200.0 渭A/渭s |
 | 100 渭A  | 1.0 nA/渭s  | 20.0 渭A/渭s  | 20.0 渭A/渭s |
 | 10 渭A  | 100.0 pA/渭s  | 2.0 渭A/渭s  | 2.0 渭A/渭s |

The values defined in the table above apply for a single channel. For ganging groups, the current slew rate of the 1 A range can be multiplied by the number of ganged channels.

   Note The following units are to be used for programming the force current filters:

 |   | Current bandwidth:  | Hz  | (Hertz) |
 |   | Current slew rate:  | A / 渭s  | (Ampere per microsecond) |

## DC Scale voltage and current limits

The XPS256 card supports the [DC Scale voltage and current limits](<../02.08_Setup_and_Result_Tools/02.08.04.18.02.11_Setting_DC_Scale_voltage_and_current_limits.md>). SmarTest ensures that the defined voltage and current limits cannot be exceeded by programming higher or lower force or clamp values.
