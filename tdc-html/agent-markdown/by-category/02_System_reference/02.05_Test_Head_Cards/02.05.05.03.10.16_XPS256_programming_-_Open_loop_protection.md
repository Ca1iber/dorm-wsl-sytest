# XPS256 programming - Open loop protection

Open loop protection of the XPS256 means how the force pin (P#) and the sense pin (PS#) ) as well as the ground sense pin (GS#) and the common ground are connected internally to ensure that the feed back input of the control loop or the output stage respectively is not open in case the required connection at the DUT or on the DUT board is (unintentionally) open.

  There are two states on which the open loop protection can be set:

- DIODE:

The sense pins are internally connected to the force pins via two anti-parallel diodes.

This is the default state.

This is the recommended setting if for the [voltage drop measurement and monitoring](<02.05.05.03.10.19_XPS256_programming_-_Voltage_drop_measurement.md>) the maximum voltage drop both on the force line and on the return line as been set to be 鈮?nbsp;0.5 V.Note This setting does not make a low‑impedance connection on the DUT or on the DUT board unnecessary. If there is no force to sense connection at the DUT or on the DUT board, the forced or measured voltage will change within the range defined by the forward voltage of the diodes.
- NONE

There is no internal connection between the force and sense pins.

This is the required setting if for the [voltage drop measurement and monitoring](<02.05.05.03.10.19_XPS256_programming_-_Voltage_drop_measurement.md>) the maximum voltage drop both on the force line and on the return line as been set to be > 0.5 V.Note If the low‑impedance force to sense connection at the DUT or on the DUT board is opened (unintentionally), the output stage and the digital control no longer receive a voltage feedback signal. An active XPS256 channel may then force a voltage up to the supply voltage of the output stage and voltage measurements will be invalid.

## Rules

 These rules must be considered:

- For a [maximum voltage drop](<02.05.05.03.03.08_XPS256_voltage_drop_measurement.md>) > 0.5 V, the open loop protection must be set to NONE.
- In the [DC Scale Safety editor](<02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__s_DC_Scale_Safety_editor>) the [Vdrop Disco](<02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_Vdrop_Disco>) parameter must be set to ON if the open loop protection is set to NONE.

## Programming

The status of the open loop protection can be defined in the default settings for the testflow, in the level setups, and by test method APIs:

- Default values:

The default state of the open loop protection can be set in the [Open Loop Protection](<02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_Open_loop_protection>) column of the [DC Scale Safety editor](<02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__s_DC_Scale_Safety_editor>).

- Level setup in [DPS operating mode](<02.05.05.03.10.07_XPS256_programming_-_DPS_operating_mode.md>):

Use the [openLoopProtection()](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__open_loop_protection>) parameter of the [DPSPINS resources](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>).

- Setup in [PMU operating mode](<02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md>):

Use the [ openLoopProtection()](<../02.07_Test_Method_Reference/02.07.04.01.234.01.25_SPMU_PIN_TASK.openLoopProtection.md>) function of the [SPMU_PIN_TASK](<../02.07_Test_Method_Reference/02.07.04.01.234.01_SPMU_PIN_TASK.md>) test method API.

The status can also be changed in the Hardware view for the [DPS operating mode](<02.05.05.03.10.07_XPS256_programming_-_DPS_operating_mode.md>) and for the [PMU operating mode](<02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md>).
