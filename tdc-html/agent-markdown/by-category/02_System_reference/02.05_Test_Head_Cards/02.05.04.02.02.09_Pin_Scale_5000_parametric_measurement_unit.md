# Pin Scale 5000 parametric measurement unit

To achieve the specified accuracy, the user must specify as minimum the number of samples given in the next sections for the averaging.

## Voltage force and measure

Ia is the actual current. R is the maximum wiring resistance of 1 Ω

## Voltage clamp

The voltage clamp is available in current force mode only.

 | Voltage clamp |
 | Voltage clamp range  | -1.5 V to +6.5 V at |VGS| 鈮?100 mV |
 | Clamp resolution  | 1 mV |
 | Clamp accuracy, verified with a measurement current of 900 µA  | ± 100 mV at VGS = 0 mV |

To avoid clipping effects, the clamp must be specified with a sufficient distance to the expected measurement result. In symbolic notation, |clamp| > max(|expected measurement result range|) + |clamp accuracy| + |result accuracy|.

To avoid clipping effects, the clamp must be specified with a sufficient distance to the expected measurement result. In symbolic notation, |clamp| > max(|expected measurement result range|) + |clamp accuracy| + |result accuracy|.

The sustainable total load may not exceed 5000 mA per card.
