# XPS256 programming - Force and clamp voltages

Each channel of an XPS256 card features two combined force, clamp, and measure voltage ranges.

## Voltage ranges

Each PMU features two combined force, clamp, and measure voltage ranges:

 | Variant  | Range  | Minimum and maximum voltage |
 | XPS256  | 1.5 V[1)](<#fntarg_1>)  | -0.5 V ... 1.5 V |
 | 7.0 V  | -2.5 V ... 7.0 V |

The voltage ranges are common for forcing, clamping, and measuring voltages. The force or clamp range is always the same as the measurement range. For specification data, refer to [XPS256 voltage specifications](<../02.02_Specifications/02.02.05.03.02_XPS256_voltage_specifications.md>). For the maximum current related to the voltage, refer to [XPS256 voltage and current capability specifications](<../02.02_Specifications/02.02.05.03.04_XPS256_voltage_and_current_capability_specifications.md>).

## Minimum clamp voltage distance

The PMU of an XPS256 channel needs a minimum distance between the positive and negative clamp voltage to avoid oscillation.

 | Variant  | Voltage range  | Programmable range  | Minimum clamp distance |
 | Negative clamp  | Positive clamp  | |
 | XPS256  | 1.5 V  | -0.5 V ... 0.0 V  | 0.0 V ... 1.5 V  | 0.1 V |
 | 7.0 V  | -2.5 V ... 0.0 V  | 0.0 V ... 7.0 V  | 0.5 V |

The minimum clamp distance means that both the negative and the positive clamp voltage can be set within the full range from the minimum respectively the maximum value to 0.0 V if the minimum distance of the two values is maintained.

Asymmetrical clamp voltage definitions with one of the values set to 0.0 V can be programmed, but internally the channel controller always uses a maximum of -50 mV for the negative clamp and a minimum of +50 mV for the positive clamp.

For clamp voltage specifications, refer to table [Voltage clamp](<../02.02_Specifications/02.02.05.03.02_XPS256_voltage_specifications.md#_350735__s_Voltage_clamp>) in [XPS256 voltage specifications](<../02.02_Specifications/02.02.05.03.02_XPS256_voltage_specifications.md>).

## Dynamic behavior in force voltage or clamp voltage mode

The following force voltage filters are available for an XPS256 channel:

- Voltage bandwidth

This value defines the bandwidth that has an effect on the dynamic behavior of an XPS256 channel that is forcing or clamping the voltage.

 | Range  | Min  | Max  | Default |
 | 1.5 V  | 2 Hz  | 50 kHz  | 10 kHz |
 | 7 V  | 2 Hz  | 50 kHz  | 10 kHz |
- Voltage slew rate

The parameter defines the slew rate for changes of the programmed voltage force value.

 | Range  | Min  | Max  | Default |
 | 1.5 V  | 10 渭V/渭s  | 2 V/渭s  | 50.0 mV/渭s |
 | 7 V  | 45 渭V/渭s  | 2 V/渭s  | 50.0 mV/渭s |
- Load capacitance

Represents the load capacitance on the DUT board. The parameter is used to adapt the dynamic behavior of an XPS256 channel to different load capacitors. Although the filter values are defined for the current ranges, this filter has an effect on the dynamic behavior when a channel is forcing or clamping the voltage.

 | Range  | Min  | Max[2)](<#fntarg_2>)  | Default |
 | 1 A  | 0.0 mF  | 1.0 mF  | 0.0 mF |
 | 100 mA  | 0.0 渭F  | 100.0 渭F  | 0.0 渭F |
 | 10 mA  | 0.0 渭F  | 10.0 渭F  | 0.0 渭F |
 | 1 mA  | 0.0 渭F  | 1.0 渭F  | 0.0 渭F |
 | 100 渭A  | 0.0 nF  | 100.0 nF  | 0.0 nF |
 | 10 渭A  | 0.0 nF  | 10.0 nF  | 0.0 nF |

The values defined in the table above apply for a single channel. For ganging in the 1 A range, the maximum load capacitance value can be multiplied by the number of ganged channels.

 Note

Due to the capacitive load of the DUT board and the DUT, increasing the voltage slew rate will always result in a higher current while the forced voltage changes. If the higher current exceeds the programmed clamp current, the effective voltage slew rate is limited and the [Constant current flag](<02.05.05.03.10.02_XPS256_status_flags.md#_354167__r_Constant_current>) might be triggered.

For high voltage slew rates, we therefore recommend increasing the clamp current for the time while the forced voltage changes.

 |   | Voltage slew rate:  | V / 碌s  | (Volts per microsecond) |
 |   | Load capacitance:  | F  | (Farad) |

## Application note

  DC events in reused pattern For a minimized test time we recommend, not to reuse pattern with DC events that are to be applied for different XPS256 ranges. The recommendation applies to pattern that are manually created using the related test method APIs but not to the automatically created [SmartRDI](<../02.07_Test_Method_Reference/02.07.13_SmartRDI.md>) pattern.

The XPS256 channels feature several force ranges. The pattern data of related DC events must be reloaded in case the containing pattern is reused for another range. This may significantly increase the test time.

The recommendation applies to all DC events that change the force- or clamp value or range or the measurement range.
