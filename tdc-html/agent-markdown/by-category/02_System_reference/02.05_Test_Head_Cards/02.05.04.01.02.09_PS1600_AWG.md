# PS1600 AWG

The PPMU can be used as an arbitrary waveform generator (AWG), supporting both voltage and current waveforms.

All specifications for static PPMU force mode apply.

Max sample rate[1)](<#fntarg_1>)

   |    [1)](<#fnsrc_1>) For best AWG performance the neighbor channel of a PS1600 differential pair should not perform any AWG, PMU re-programming or Change Level Operation. PPMU reprogramming may cause noise on adjacent channel of differential pin pair's PPMU. Otherwise max sampling rate may drop to 75ksps and additional timing jitter may be introduced.[2)](<>) These values are typical numbers, based on generating a 12bit voltage ramp waveform (4096 steps), using the +/- 40mA PMU current range (Range 1). DNL/INL calculation is done using the best fit method.
