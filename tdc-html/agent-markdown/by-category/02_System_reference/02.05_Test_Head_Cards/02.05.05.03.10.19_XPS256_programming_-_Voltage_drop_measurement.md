# XPS256 programming - Voltage drop measurement

The XPS256 card supports voltage drop measurements that are also known as Kelvin measurements. Voltage drop measurement means that the voltage drop on the two force lines is measured to ensure that these connections to the DUT have a sufficiently low resistance. Voltage drop measurements are supported per channel for the force line (P#) and for the return line (common GND).

In this context, "Force lines" means both the high force line (P#) and the common return line (GND). The high force line is also referenced as "Force line".

## Measurement filters

XPS256 channels feature programmable anti-aliasing, low-pass measurement filters for all ADCs:

- Voltage measurement ADC of the PMU
- Current measurement ADC of the PMU
- Voltage drop measurements on the force line
- Voltage drop measurements on the return line

 | Measurement filter characteristics |
 | Minimum cutoff frequency:  | 10 Hz |
 | Maximum cutoff frequency:  | 500 kHz |
 | Default cutoff frequency:  | 30 kHz |

The dynamic behavior of the force output is independent of the measurement filters.

## Averaging

All channels of the card feature hardware based averaging of measurements. The average of multiple consecutive ADC samples is calculated and stored on board. Hardware based averaging can be utilized for code‑based and pattern‑based measurements.

 | Hardware-based averaging |
 | Programmable range of samples:  | 1 ... 262144 (any value supported) |
 | ADC sample frequency:  | 2 MHz[1)](<#_354548__d609e1117>) |

Some hints to consider:

- The sample time for averaged measurements must be taken into account.
- Pattern‑based measurements require a minimum number of vectors after the trigger has been initiated. For more information, refer to [Timing of DC events](<../02.07_Test_Method_Reference/02.07.04.01.63.01.01_Timing_of_DC_events.md>) and the related sub-topics.
- The effective maximum sample frequency is the ADC sample frequency of 2 MHz[1)](<#_354548__d609e1117>) divided by the number of averaged samples.
- The "measurement filter" may be used instead of averaging if a high effective sample frequency is required. This filter behaves like a simple RC filter. The settling time is to be considered but the filter setting has no effect on the effective maximum sample frequency.
- The dynamic behavior of the force output is independent of the settings for averaging.

## Voltage drop measurements in hardware view

 Voltage drop measurements are supported by the

- Measure Voltage Drop button of the [Hardware view](<02.05.05.03.10.07_XPS256_programming_-_DPS_operating_mode.md#_354249__s_Hardware_view>) in [DPS operating mode](<02.05.05.03.10.07_XPS256_programming_-_DPS_operating_mode.md>) and by the
- Measure dialog of the [Hardware view](<02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md#_354253__s_Hardware_view>) in [PMU operating mode](<02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md>).

The latched maximum voltage drop can be read using the Max Voltage Drop button of the Hardware view in DPS operating mode and in PMU operating mode. The latched value is automatically cleared after it has been read.

## Default voltage drop settings

 Several parameters related to the voltage drop settings can be defined as default values in the [DC Scale Safety editor](<02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__s_DC_Scale_Safety_editor>). Applicable settings:

- [max Vdrop](<02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_max_Vdrop>): The maximum voltage drop.
- [warn Vdrop](<02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_warn_Vdop>): The voltage drop warning threshold.
- [Vdrop Hold time](<02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_Vdrop_hold_time>): Specifies the time to wait when the maximum voltage drop is reached, before the [Voltage drop force](<02.05.05.03.10.02_XPS256_status_flags.md#_354167__r_Voltage_drop_force>) or [Voltage drop return](<02.05.05.03.10.02_XPS256_status_flags.md#_354167__r_Voltage_drop_return>) status flags are set.
- [Vdrop Disco](<02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_Vdrop_Disco>): Specify whether to disconnect when the programmed maximum force drop is exceeded.
- [Open Loop Protection](<02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_Open_loop_protection>): Specifies how the internal force to the sense connection is to be set in order to prevent an unintentionally established open control loop of the output stage.
