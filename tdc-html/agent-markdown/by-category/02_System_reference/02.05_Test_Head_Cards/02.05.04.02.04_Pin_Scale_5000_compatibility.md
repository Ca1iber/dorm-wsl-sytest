# Pin Scale 5000 compatibility

## Pogo cable compatibility

The Pin Scale 5000 card supports two pogo pin layouts with regard to compatibility:

- [Standard (compatible) layout](<../02.03_DUT_board_design_reference/02.03.06.03.05.01_PS5000_pogo_cable_assembly_EK601-61602__16_SD_pogo_blocks.md>), consisting of 16 pogo blocks per card having 16 pins per block. This layout is compatible with existing DUT boards.
- [High-density layout](<../02.03_DUT_board_design_reference/02.03.06.03.05.02_PS5000_pogo_cable_assembly_EK601-61603__8_HD_pogo_blocks.md>), consisting of eight pogo blocks per card having 32 pins per block. This layout is compatible with the current layout for the inner 16 pins.

For additional pins, two outer rows (each containing 8 pogo pins) are provided. See [Pin Scale 5000 pogo pin assignment](<02.05.04.02.06_Pin_Scale_5000_pogo_pin_assignment.md>).

The outer rows must be considered in your DUT board layout if you need to use them.
