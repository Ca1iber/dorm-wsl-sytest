# Pin Scale 5000 specific setup tasks

The Pin Scale 5000 card can drive and receive single-ended or differential signals up to data rates of 5.0 Gbit/s. For this purpose, you to need to set up various termination configurations and, depending on the speed of data you wish to transfer, one of the two operating modes: "Standard" (std) or "Fast" (FAST).

  Note FAST mode is a pre-release version on SmarTest 7.10.3 and has been enabled only for evaluation purposes.

Because of these additional features, there are some special aspects to be considered when setting up the pins, levels, timing and vectors.

## Speed option (Modes)

The Pin Scale 5000 card supports the following two modes:

- Standard mode: defined with the keyword std and for data rates up to about 1.6 Gbit/s.
- High-speed mode: Defined with the keyword FAST and for data rates up to 5.0 Gbit/s.

The modes are defined in the Pin Configuration.

## Differential option

PS5000 cards offer the possibility of setting up differential pins. A differential channel is made up by using two single-ended channels. The two channels must, however, be a matched pair. For the assignment of the differential pin pairs on each pogo block, refer to [PS5000 differential pin pair assignment](<../02.03_DUT_board_design_reference/02.03.08.03.01.01_PS5000_differential_pin_pair_assignment.md>).

To switch the software from single-ended to differential, you use the term expression in the timing file.
