# XPS256 force, clamp, and measure voltages

#### Subtopics

- [XPS256 force and clamp voltages](<02.05.05.03.06.01_XPS256_force_and_clamp_voltages.md>)
- [XPS256 measure voltages](<02.05.05.03.06.02_XPS256_measure_voltages.md>)

The XPS256 card features a PMU per channel for forcing, clamping, and measuring voltages. The PMUs provide two combined force, clamp, and measure voltage ranges.

## Forcing or clamping voltage

The XPS256 PMUs are digitally regulated VI supplies with remote sense lines and a common return path. The output voltage is referenced to channel specific ground sense pins (GS#). The common return path is the combination of all ground (GND) pins.

The digital controller of a PMU in force voltage mode will adjust the control value so that the voltage between the high sense pogo pin (PS#) and the ground sense pogo pin (GS#) is equal to the programmed voltage as long as the output current stays within the programmed clamp current limits.

For more information refer to [XPS256 force and clamp voltages](<02.05.05.03.06.01_XPS256_force_and_clamp_voltages.md>).

## Measuring voltage

The voltage is measured differentially between the channel specific high sense (PS#) and ground sense (GS#) pogo pins. The digital controller continuously measures voltages and currents, uses the measured values as feedback for the control loop, and provides the values for all user-defined measurements.

For more information refer to [XPS256 measure voltages](<02.05.05.03.06.02_XPS256_measure_voltages.md>).

## High-impedance voltage measurement mode (HIMP)

A high-impedance operation mode is available. This mode is used to measure the voltage with no voltage or current applied. The force output (P#) is switched to a high-impedance mode. The voltage is measured differentially between the high sense pogo pin (PS#) and the ground sense pogo pin (GS#).

Note The common ground (GND) pins must still be connected in the high-impedance voltage measurement mode for correct common mode operation.

## Power budget

Unlike legacy similar cards, XPS256 does not require distributing a power budget across the active pins.

Nevertheless, the available power of an XPS256 card limits the maximum current for the 256 channel high-current variant XPS256 (EK751HC) in some cases as can be seen in [XPS256 voltage and current capability specifications](<../02.02_Specifications/02.02.05.03.04_XPS256_voltage_and_current_capability_specifications.md>).

To prevent the power budget from being exceeded and one or more channels having to be switched off, SmarTest checks the required power budget before downloading the settings and issues an error message if the required power budget exceeds the available power budget.
