# DPS operating mode of DC Scale cards

#### Subtopics

- [Hardware view diagram of DC Scale channels in DPS operating mode](<02.05.05.04.01_Hardware_view_diagram_of_DC_Scale_channels_in_DPS_operating_mode.md>)
- [Standard DPS functionality of DC Scale cards in DPS operating mode](<02.05.05.04.02_Standard_DPS_functionality_of_DC_Scale_cards_in_DPS_operating_mode.md>)
- [Measuring current or voltage in DPS operating mode](<02.05.05.04.03_Measuring_current_or_voltage_in_DPS_operating_mode.md>)

For DPS mode specify the pin type as DPS+. In DPS mode you can use the DC Scale cards like a DPS-slot DPS, to supply devices with power during the execution of a test flow. Each of the channels can source and sink current at a programmed voltage, and each channel can measure the voltages and currents supplied.

## Equations

Note To use all features of the DC Scale cards in DPS mode you should use equations. For details see [Equation based level setup](<../02.08_Setup_and_Result_Tools/02.08.04.14.02_Equation_based_level_setup.md>).
