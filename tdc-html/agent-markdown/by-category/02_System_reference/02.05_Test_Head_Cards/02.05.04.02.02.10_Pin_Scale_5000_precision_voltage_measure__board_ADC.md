# Pin Scale 5000 precision voltage measure (board ADC)

## Precision voltage measure with board ADC

One board ADC (BADC) is shared between 16 channels for [precision](<../02.02_Specifications/02.02.04.03.14_Pin_Scale_5000_terms.md>) voltage measure.

 | Precision voltage measure |
 | Voltage range  | -1.5 V to +6.5 V at |VGS| 鈮?100 mV |
 | Measurement resolution  | 50 µV |
 | Measurement accuracy  | Ground sense connected and operational, or relative measurement without ground sense  | ± 500 µV at VGS = 0 V, number of internal samples for averaging 16 |
 | Ground sense disconnected or not enabled  | ± 1000 µV, number of internal samples for averaging 16 |
 | Maximum input leakage current in voltage range -1.5 V to +6.5 V  | High-Z  | ± 2 µA |
 | DCL off  | ± 10 nA |

The accuracy of a relative measurement refers to two consecutive measurements on the same pin or pins sharing the same board ADC, with or without ground sense.
