# XPS256 arbitrary waveform generator (AWG)

An XPS256 pin can be used as an arbitrary waveform generator (AWG), supporting both voltage and current waveforms.

An XPS256 channel used in AWG mode is set to the [PMU operating mode](<02.05.05.03.05.02_XPS256_in_PMU_operating_mode.md>) or to the [DPS operating mode](<02.05.05.03.05.01_XPS256_in_DPS_operating_mode.md>) and programmed like a standard PMU or DPS. The usual commands, APIs or level setups are used to set the initial values for the forced or clamped voltage or current. The arbitrary waves are defined by DC events and test points, stored into the pattern memory and applied to the selected front end of the AVI64 channel by the test processor.

Both, the voltage force or clamp values and the current force or clamp values can be defined as waveform and therefore may be controlled by the AWG functionality.

Refer to [XPS256 AWG, digitizer, and comparator specifications](<../02.02_Specifications/02.02.05.03.06_XPS256_AWG__digitizer__and_comparator_specifications.md>) for specification data of an XPS256 channel in AWG mode.

## Dynamic behavior of the AWG

The AWG functionality features some filters to modify the dynamic behavior.

The following force voltage filters are available for an XPS256 channel:

- Voltage bandwidth

This value defines the bandwidth that has an effect on the dynamic behavior of an XPS256 channel that is forcing or clamping the voltage.

 | Range  | Min  | Max  | Default |
 | 1.5 V  | 2 Hz  | 50 kHz  | 10 kHz |
 | 7 V  | 2 Hz  | 50 kHz  | 10 kHz |
- Voltage slew rate

The parameter defines the slew rate for changes of the programmed voltage force value.

 | Range  | Min  | Max  | Default |
 | 1.5 V  | 10 μV/μs  | 2 V/μs  | 50.0 mV/μs |
 | 7 V  | 45 μV/μs  | 2 V/μs  | 50.0 mV/μs |
- Load capacitance

Represents the load capacitance on the DUT board. The parameter is used to adapt the dynamic behavior of an XPS256 channel to different load capacitors. Although the filter values are defined for the current ranges, this filter has an effect on the dynamic behavior when a channel is forcing or clamping the voltage.

 | Range  | Min  | Max[1)](<#fntarg_1>)  | Default |
 | 1 A  | 0.0 mF  | 1.0 mF  | 0.0 mF |
 | 100 mA  | 0.0 μF  | 100.0 μF  | 0.0 μF |
 | 10 mA  | 0.0 μF  | 10.0 μF  | 0.0 μF |
 | 1 mA  | 0.0 μF  | 1.0 μF  | 0.0 μF |
 | 100 μA  | 0.0 nF  | 100.0 nF  | 0.0 nF |
 | 10 μA  | 0.0 nF  | 10.0 nF  | 0.0 nF |

The values defined in the table above apply for a single channel. For ganging in the 1 A range, the maximum load capacitance value can be multiplied by the number of ganged channels.

 Note

Due to the capacitive load of the DUT board and the DUT, increasing the voltage slew rate will always result in a higher current while the forced voltage changes. If the higher current exceeds the programmed clamp current, the effective voltage slew rate is limited and the [Constant current flag](<02.05.05.03.10.02_XPS256_status_flags.md#_354167__r_Constant_current>) might be triggered.

For high voltage slew rates, we therefore recommend increasing the clamp current for the time while the forced voltage changes.

The following force current filters are available for an XPS256 channel:

- Current bandwidth

This value defines a current bandwidth that has an effect on the dynamic behavior of an XPS256 channel that is forcing or clamping the current.

 | Range  | Min  | Max  | Default |
 | All current ranges  | 10 Hz  | 500 kHz  | 10 kHz |
- Current slew rate

The parameter defines the slew rate for changes of the programmed current force value.

 | Range  | Min  | Max  | Default |
 | 1 A  | 10.0 μA/μs  | 200.0 mA/μs  | 10.0 mA/μs |
 | 100 mA  | 1.0 μA/μs  | 20.0 mA/μs  | 10.0 mA/μs |
 | 10 mA  | 100.0 nA/μs  | 2.0 mA/μs  | 2.0 mA/μs |
 | 1 mA  | 10.0 nA/μs  | 200.0 μA/μs  | 200.0 μA/μs |
 | 100 μA  | 1.0 nA/μs  | 20.0 μA/μs  | 20.0 μA/μs |
 | 10 μA  | 100.0 pA/μs  | 2.0 μA/μs  | 2.0 μA/μs |

The values defined in the table above apply for a single channel. For ganging groups, the current slew rate of the 1 A range can be multiplied by the number of ganged channels.
