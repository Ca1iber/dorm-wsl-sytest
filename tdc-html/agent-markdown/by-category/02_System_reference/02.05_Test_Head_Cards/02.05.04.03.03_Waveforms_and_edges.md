# Waveforms and edges

A waveform is a sequence of actions, each associated with an edge. The edges can be separated into drive edges and receive edges. Drive actions are associated with drive edges, receive actions with receive edges.

Waveforms for Smart Scale pins can be specified in two formats:

- [Modified standard format](<../02.06_Command_Reference/02.06.06.01.03.02_Defining_waveform_shapes_for_Smart_Scale_pins.md>)
- [Native Smart Scale format](<../02.06_Command_Reference/02.06.06.01.03.02_Defining_waveform_shapes_for_Smart_Scale_pins.md>)

Smart Scale waveforms have separate sets of edges for drive actions and for "tri-state" actions. This is the main difference between Pin Scale and Smart Scale waveforms.

For PS9G, the known tri-state formatter is used to create a 3rd and 4th driver level, denoted by fn and sn (for details see [Set fixed driver levels (legacy)](<../02.06_Command_Reference/02.06.05.01.05.01.01_Set_fixed_driver_levels.md>)). There are 8 edges for each of the two types.

While the PS1600 card does have high-z (high impedance) capability, the PS9G card does not have high-z capability.

## Edge delays

For Smart Scale cards these fn and sn edges can programmed independently and they are all calibrated. Each of the 16 (2 x 8) fn and sn drive edges can be associated with a different delay by specifying f and s in the timing setup.

The dn syntax is also supported and sets fn and sn edges to the same delay. However, you cannot mix the native Smart Scale syntax with the earlier syntax within the same PINS block. For details see [Defining edge delays for Pin Scale 9G pins](<../02.06_Command_Reference/02.06.06.01.04.02.03_Defining_edge_delays_for_Smart_Scale_pins.md>).

Special requirements for protocol engine per pin tests are described in [Defining edge delays for a protocol engine test](<../02.06_Command_Reference/02.06.06.01.04.02.03.01_Defining_edge_delays_and_period_length_for_a_protocol_engine_test.md>).

## Edge ordering

In contrast to Pin Scale pins, drive edges for Smart Scale pins are not subject to any edge ordering restrictions. If the [edge order restrictions for drive pins](<../02.06_Command_Reference/02.06.06.01.03.01.02.01_Restrictions_for_drive_edges.md>) were not observed in a Pin Scale setup, the resulting waveforms will be different when the setup is loaded into a Smart Scale system.

The restrictions for receive edges are the same as for PS800/3600 pins. For details see [Restrictions for receive edges](<../02.06_Command_Reference/02.06.06.01.03.01.02.02_Restrictions_for_receive_edges.md>).
