# Pin configuration and level setup in DPS operating mode

The pin configuration of DC Scale cards is slightly different to that of a standard device power supply.

To configure a DC Scale pin for DPS operating mode you must specify the pin type as DPS+.

## Equations

To use all features of the DC Scale cards in DPS operating mode you should use equations. For details see [Equation based level setup](<../02.08_Setup_and_Result_Tools/02.08.04.14.02_Equation_based_level_setup.md>).

## Level setup

The Level Setup tool displays the currently active settings of the DC Scale card as follows:

- Force voltage (vout)
- Clamp current (ilimit)
- Settling time (t_ms)
- Off current state (offcurr)
- Force voltage range (vout_frc_rng)
- Clamp current range (iout_clamp_rng)
- disable_const_curr_check flag
- Connect state (connect_state)

For details on the setup procedure see [DPS Pins editor](<../02.08_Setup_and_Result_Tools/02.08.04.18.03.01.03_DPS_Pins_editor.md>).
