# DPS128 power budget decision model

To prevent any likelihood of an overpower shutdown of the DPS card, SmarTest limits the overall power usage and issues an error message if it is violated. The decision is based on the programmed current clamp limit of the channels, with the HC type also taking care of the programmed voltage range.

For the DPS operating mode, the parameters are defined in the level equations (ilimit, vout_frc_rng). The decision is based on the level primary set and is triggered during its activation.

For example, the following DPS128-HC setup triggers the error message during primary set activation, as it is impossible to source / sink 1 A @ 2.5 V on all 128 channels in parallel.

```
DPSPINS all_128_channels
    vout_frc_rng   = 2.5  # [V]
    vout           = 2.5  # [V]
    iout_clamp_rng = 1000 # [mA]
    ilimi          = 1000 # [mA]
```

For the PMU operating mode, the current clamp limit and voltage range is typically specified during the connect sequence of the instrument.

In the pattern‑based, dynamic mode, SmarTest also analyzes the programmed test points for the defined current clamp limits (current force) on a per pattern basis. Based on this, an error is triggered during pattern activation. There is no check for the voltage range, as it cannot be changed during the pattern execution.

The power characteristics differ between the HC and HV channel version:

  HC channel version

- Specified voltage range with a minimum value of 2.25 V.
- Current sink is the most important factor for voltage below 3.3 V.
- Current source is the most important factor for voltage above 3.3 V.
- No limitations when all channels operate at current below 1 A.
 HV channel version

- No dependency on voltage ranges - only a single range is available.
- Current source is the most important factor.
