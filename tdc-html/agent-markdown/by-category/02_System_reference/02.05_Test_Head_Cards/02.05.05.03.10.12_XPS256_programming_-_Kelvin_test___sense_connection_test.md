# XPS256 programming - Kelvin test / sense connection test

The XPS256 card features a Kelvin test unit that is also known as sense-connection test unit. Kelvin test means that the connection from the force lines to the sense lines on the DUT board or at the DUT pins is verified. The Kelvin test unit is available per channel for the force line (P#) and for the return line (common GND).

The Kelvin test unit applies a small test current to the tested force to sense (FS) connection and measures the voltage difference between the two lines. The resistance is calculated from the measured voltage difference and the test current, serves as criterion for the pass/fail decision and should be near 0.0 Ω for a good FS connection.

 Note

The purpose of the Kelvin test unit is to ensure that when the DUT is contacted, the high-impedance sense line is connected to the force line at the DUT with a sufficiently low contact resistance. Due to the high input impedance of the sense lines, the fixed threshold of some kilo-Ohms will be sufficiently low.

The Kelvin test unit is the only resource that can perform a reliable sense connection test with a defined test current applied.

Since connections and hardware on the DUT board can sabotage the test of the sense connections, we recommend that you check the functionality of the test without DUT and with open sense connections. All tested sense connections must fail in this verification.

The purpose of the Kelvin test unit is not to check the low impedance force connections. The force connections are to be checked by the [XPS256 voltage drop measurement](<02.05.05.03.03.08_XPS256_voltage_drop_measurement.md>) in combination with a high test current forced by the PMU. This force connection test requires that the contact resistance of the sense lines already has been verified.

Attention: An inadequate sense line connection does not necessarily mean that a test fails. The input bias current of the line may falsify the measurement and mask another fatal error like a high voltage drop on the force line.

  CAUTION The XPS256 PMU forces the test current via one of the tested lines, the FS connection at the DUT, and via the other tested line to ground. One of the lines may temporary be tied to ground or 0 V will be forced. Therefore, the DUT must be powered down before the Kelvin test (or sense connection test) is started in disconnected mode.

## Basic data

 Basic data of the Kelvin test unit:

- The Kelvin test unit is available per channel.
- The default value of the programmable threshold for the pass/fail decision is about 5 kΩ.
- The test current is about 100 µA per channel.
- The maximum capacitance between the force lines and the corresponding sense lines is 5 nF.
- Two measurements are serially performed for the PS# pin and the GS# pin.
- The test can be performed only in the disconnected state of the selected pins.

## API overview

Two APIs support a parallel go/no-go Kelvin test on all active sites and pins and a detailed Kelvin test on the site in focus. Both APIs perform two measurements for the P# to PS# connection and for the GND to GS# connection.

- Function [HW_STATE.checkKelvinStatusParallel()](<../02.07_Test_Method_Reference/02.07.04.01.117.03_HW_STATE.checkKelvinStatusParallel.md>)

The function checkKelvinStatusParallel() of class [HW_STATE](<../02.07_Test_Method_Reference/02.07.04.01.117_HW_STATE.md>) initiates a sense connection test on the defined pins to verify that the force lines and sense lines are connected together on the DUT board or at the DUT pins. The test is performed in parallel for all active sites. The function returns a go/no-go result for each configured site in a single integer array.

  - The go/no-go result of the function is set to 0 (Kelvin test has failed) if any of the tested pins has returned a failing result for any of the performed measurements.
  - The go/no-go result of the function is set to 1 (Kelvin test has passed) if all tested pins have successfully finished all measurements on all active sites.

- Function [HW_STATE.checkKelvinStatus()](<../02.07_Test_Method_Reference/02.07.04.01.117.02_HW_STATE.checkKelvinStatus.md>)

The function initiates a sense connection test for the site in focus. The function returns individual results for all tested pins in two integer arrays for the P# to PS# connections and for the GND to GS# connections.

For ganged pins, the Kelvin test / sense connection test is performed for each individual channel.

## Application note

  Kelvin test / sense connection test in a testflow A continuity test, which is normally performed at the beginning of a test flow, may use XPS256 channels. The continuity test will show a reliable result only if both the force pins (P# and GND) and the sense pins (PS# and GS#) of the XPS256 channels are connected properly. Therefore, we recommend implementing a Kelvin test / sense connection at the beginning of a testflow before the continuity test is performed.
