# 10 Mhz reference clock

The test head electronics use an internal 10 MHz reference clock to synchronize the test head cards. This frequency is also used with external equipment, for example, a Digital Multi Meter (DMM) or network analyzer (NA).

   Note Refer to the System Interconnections section of your test head type in the Service Documentation to locate the 10 MHz in and out BNC connectors.

## Internal reference clock

The internal 10 MHz reference clock is used to synchronize all cards installed in the test head. It is also routed to the 10 MHz Out connector at one side of the test head. This enables you to synchronize external equipment with the test head electronics, where the tester is the master.

The 10 MHz Out connection is also used to perform the external calibration on the test system. Also refer to the external calibration section in Maintenance Guide of the Service Documentation.

## External reference clock

An external 10 MHz reference clock can be used to synchronize all test head cards to an external clock. It is routed from the 10 MHz In connector at one side of the test head to the test head electronics. This enables you to synchronize the test head electronics with external equipment, where the external equipment is the master.

  Note If you cannot detect the external 10 MHz clock that is connected to the test head,

 check if the modification detailed in Service Note E8001-275 was performed.

For more information about specifying the usage of the reference clock, see [ETC section](<../02.04_Model_File_and_Licensing/02.04.01.03.02.05_ETC_section.md>).

## Examples

### Internal 10 MHz source and output to the 10 MHz output socket

```
REFERENCECLOCK : input = INTERNAL, output_at_rf_connector = ON
```

Internal source is used for 10 MHz reference clock signal. Reference clock signal is output at the 10MHz output socket on the Interconnection Panel.

### External 10 MHz source and no output to the 10 MHz output socket

```
REFERENCECLOCK : input = EXTERNAL, output_at_rf_connector = OFF
```

External source is used for 10 MHz reference clock signal. Reference clock signal is not output at the 10MHz output socket on the Interconnection Panel.
