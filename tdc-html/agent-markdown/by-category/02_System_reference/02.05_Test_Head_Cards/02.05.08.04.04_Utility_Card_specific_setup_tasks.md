## Global compatibility settings

Some characteristics of utility power supplies have been optimized for V93000 EXA Scale systems. For compatibility, the behavior can be adapted to the Pin Scale and Smart Scale systems using global settings. These settings are to be defined in a configuration file that is parsed when the SmarTest Work Center is started.

The compatibility setting are defined in file /opt/hp93000/soc/system/etc/systemPreferences.txt.

Data in the file are defined as `key=value` pairs.

The following keys are available for the Utility Card:

- utility_power_featureset For the Utility Card, the key controls the global power on/off behavior of the [UP5V utility power supply](<../02.03_DUT_board_design_reference/02.03.05.01_Utility_power_supply_-_UP5V_pins__V93000_EXA_Scale_systems.md>) and grouping of the [XP pins utility power supply](<../02.03_DUT_board_design_reference/02.03.05.02_Utility_power_supply_-_XP_pins__V93000_EXA_Scale_systems.md>) outputs.

    - The UP5V utility power supply automatically recovers after an overload condition.
The change in behavior applies only to the UP5V utility power supply of the first Utility Card that is routed to utility pogo utility pogo block 165 (UTIL 1) ... 172 (UTIL 8).

- up5v_voltage_reduction

 | Value:  | Boolean value true or false |

## UTILITY256 utility card configuration in the tester.model file

 The Utility Card is to be defined at two positions of the [tester.model](<../02.04_Model_File_and_Licensing/02.04.01.03.01_Model_file_reference__tester.model.md>) file:

- [GLOBAL section](<../02.04_Model_File_and_Licensing/02.04.01.03.01.01_GLOBAL_section.md>):The utility lines are to be defined in this section as follows:

```
utility_lines = number_of_lines, type = sequencer_controlled, pogo_size = 32, redirectpogoblocks = redirect_utility_pogoblocks
```

with number_of_lines replaced with

  - 256 for the first Utility Card or
  - 512 if two Utility Cards are installed.

Keyword utility_lines is mandatory for a V93000 EXA Scale system.

Example:

```
utility_lines = 256, type = sequencer_controlled, pogo_size = 32
```

Keyword redirectpogoblocks is used to specify available redirect utility pogo blocks only if the dut_interface type is WSMM_I2C or WSMM. If redirectpogoblocks is not specified, no utility pogo blocks will be redirected. If redirectpogoblocks is specified for other DUT interface types, SmarTest will not start. Supported redirect utility pogo blocks for a V93000 EXA Scale system are listed below:

  - First utility board: 4133 (165), 5209 (166), 6217 (167), 7225 (168), 4129 (169), 5205 (170), 6213 (171), 7221 (172)
  - Second utility board: 4333 (265), 5409 (266), 6417 (267), 7425 (268), 4329 (269), 5405 (270), 6413 (271), 7421 (272)
Example:

```
utility_lines = 256, type = sequencer_controlled, pogo_size = 32, redirectpogoblocks = 6217 7221 5209
```

- [CARD_CONFIGURATION section](<../02.04_Model_File_and_Licensing/02.04.01.03.01.02_CARD_CONFIGURATION_section.md>):The Utility Card and the utility pogo blocks must be defined in this section as follows:

```
slot = physical_location, HW = UTILITY256, pogoblocks = ppp-ppp, type = UTILITY
```

with

  - physical_location replaced with any valid slot specifier and
  - ppp-ppp replaced with a valid pogo block range:

    - 165-172 for the first Utility Card
    - 265-272 for the second Utility Card

  - type set to UTILITY.
The parameters are all mandatory.Example:

```
slot = 101, HW = UTILITY256, pogoblocks = 165-172, type=UTILITY
```

 Rules to follow when defining a Utility Card in the tester.model file:

- The first Utility Card in the tester.model file must always use the pogo block range 165 ... 172.
- Defining utility_lines = 256 always means that the first Utility Card is installed.
- The second Utility Card for the pogo block range 265 ... 272 can be defined only if the first Utility Card has also been defined.
- The pogo block ranges 165 ... 172 and 265 ... 272 must be defined in ascending order and without gaps.
- All eight pogo blocks must be defined for each installed Utility Card.

## Switching the utility power supplies on and off

The utility power supplies can be switched on or off by test method API [UTILITY_POWER_STATUS](<../02.07_Test_Method_Reference/02.07.04.01.264_UTILITY_POWER_STATUS.md>) of SmarTest 7.

For more information and valid combinations of the supply identifier and the target resource, refer to [UTILITY_POWER_STATUS.state()](<../02.07_Test_Method_Reference/02.07.04.01.264.01_UTILITY_POWER_STATUS.state.md>).
