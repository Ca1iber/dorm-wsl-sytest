# E8023PF pogo cable assembly: 2 MS-DPS style pogo blocks (DPS64 only)

The E8023PF pogo cable assembly connects the DPS64 card via two MS-DPS style pogo blocks to the DUT board. This pogo cable assembly is a solution for the reuse of existing MS-DPS based setups. It gangs four DPS64 channels to one channel on the pogo block side.

## Pogo cable assembly data

 | Overall length:  | 675 mm |
 | Pogo block style:  | MS-DPS |
 | Pogo blocks:  | 2 |
 | Channels per pogo block:  | 8 |
 | DPS64 channels per 1 channel on pogo block:  | 4 |
 | Total number of channels on pogo block level:  | 16 |
 | Max. current per channel on pogo block level:  | 4 A  |  ![Drawing_E8023PF](<../../../../raw/141889.png>)  ![E8023PF cable assembly](<../../../../raw/142430.png>)

Four DPS64 channels are ganged in the pogo block and routed as one channel.

 ![Pogo example E8023PF](<../../../../raw/141749.png>)
