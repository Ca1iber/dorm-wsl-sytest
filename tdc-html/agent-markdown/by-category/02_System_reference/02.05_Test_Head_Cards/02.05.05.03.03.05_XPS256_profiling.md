# XPS256 profiling

The XPS256 card supports profiling with a sample rate of up to 1 Msps (million samples per second) using sample data that are continuously provided by the digital closed loop control.

  Profiling is available per channel and is supported for

- Voltage
- Current
 Profiling can be done

- using the test method APIs

  - [DC_PROFILING_DEFINE](<../02.07_Test_Method_Reference/02.07.04.01.24_DC_PROFILING_DEFINE.md>),
  - [DC_PROFILING_ENABLE](<../02.07_Test_Method_Reference/02.07.04.01.25_DC_PROFILING_ENABLE.md>),
  - [DC_PROFILING_ON](<../02.07_Test_Method_Reference/02.07.04.01.27_DC_PROFILING_ON.md>), and
  - [DC_PROFILING_OFF](<../02.07_Test_Method_Reference/02.07.04.01.26_DC_PROFILING_OFF.md>)

- or in the [Hardware view](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.05.03_Hardware_view.md>) for the XPS256 pins in [DPS operating mode](<02.05.05.03.10.07_XPS256_programming_-_DPS_operating_mode.md#_354249__s_Hardware_view>) or in [PMU operating mode](<02.05.05.03.10.15_XPS256_programming_-_PMU_operating_mode.md#_354253__s_Hardware_view>).

The maximum sample rate for each channel is 1 Msps (million samples per second).

For more information, refer also to [Profiling of DC Scale cards with Hardware view](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.05.03.05_Profiling_of_DC_Scale_cards_with_Hardware_view.md>).
