# XPS256 surge tracker

The XPS256 card features a surge tracker per channel that monitors the voltage between the high sense (PS#) and ground sense (GS#) pins or the output current of the PMU.

Once the surge tracker is turned on, it monitors the voltage or current unless being turned off. In a typical use scenario the surge tracker is activated in the very beginning of a testflow and the status is checked at the end of the testflow.

The surge tracker checks against both high (positive) and low (negative) voltage or current thresholds, which can be set individually. Two flags indicate if thresholds have been exceeded. These flags are latched (stored) and can be retrieved any time in the testflow.

Refer to [Surge tracker](<../02.02_Specifications/02.02.05.03.07_XPS256_other_performance_characteristics.md#_350739__s_Surge_tracker>) in [XPS256 other performance characteristics](<../02.02_Specifications/02.02.05.03.07_XPS256_other_performance_characteristics.md>) for specification data of the surge tracker.

## Voltage surge tracker

The surge tracker in voltage sensing mode uses the voltage measurement values of the digital control loop as input.

## Current surge tracker

 The surge tracker in current sensing mode uses the current measurement values of the digital control loop as input:

- The effective maximum and minimum thresholds are limited by the actual current measurement range.
- SmarTest supports programming the thresholds to values outside of the actual current measurement range.
Therefore, the same thresholds can be maintained over a complete test suite or testflow but the effective thresholds are always truncated to the actual current measurement range.

## Surge tracker is silently disabled in temporarily unganged mode

Note that on DPS128/64 and XPS256 you cannot execute a current compare on a ganged group of channels in unganged mode. Already activated comparators are silently disabled in unganged mode. A user notification (Error or warning) is omitted in this case, to avoid any interrupt in the testflow. The previous state of the comparators is automatically restored after the ganged group has been restored.

## Functional changes

- Introduced in SmarTest 7.10.1
