# PS1600 MSET timing

Some settling times must be considered when using MSETs in pattern.

## Break vectors

Some break vectors are automatically generated after executing a DC sub sequencer instruction. These break vectors have to be considered when synchronizing a multiport pattern that combines DC events of DC Scale cards and PPMU measurements of digital cards.

## Note on wait time

 Note Note that in some use cases you must program additional wait time, as the SmartRDI settling time is shorter than the hardware requirement.

## Timing with open PPMU relay

 Note All settings of the PPMU are applied only if the PPMU relay is closed. As long as the relay is open, the settings for the range, the force value, and the clamp value are stored only in registers and are not effective on the hardware.
