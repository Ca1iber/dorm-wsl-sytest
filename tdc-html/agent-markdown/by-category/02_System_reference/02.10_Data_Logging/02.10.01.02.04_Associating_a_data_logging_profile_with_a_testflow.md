# Associating a data logging profile with a testflow

## About this task

Associating a data logging profile with a testflow is done by specifying both in a test program. Whenever that test program is executed, the profile is automatically loaded and applied to the testflow specified in the test program.

## Before you begin

The SmarTest software must be running.

## Procedure

-  In the Test Program Explorer, load the testflow.
-  Load the data logging profile.
-  Load any other components you want to associate with the test program, such as an application model.
-  Select the test program item and choose Save As.

## Results

You have created a new test program. Every time you load and execute the test program, the associated data logging profile will be loaded and executed.

## Functional changes

- Introduced before SmarTest 6.3.2
