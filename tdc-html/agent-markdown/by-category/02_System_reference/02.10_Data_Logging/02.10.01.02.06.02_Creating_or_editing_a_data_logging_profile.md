# Creating or editing a data logging profile

## About this task

This topic describes how to create a new data logging profile or edit an existing data logging profile using the Profile Editor.

The Profile Editor gives you some guidance: Tool tips are available for all list boxes by pointing the mouse at the box without clicking. For a syntax description of data logging profiles, see [Data logging profile rule syntax](<02.10.01.02.06.03_Data_logging_profile_rule_syntax.md>).

When you are creating or edit a profile, keep in mind that any changes are not effective until you save the profile.

## Before you begin

- The SmarTest software must be running.
- The Profile Editor was started as described in [Starting the Profile Editor](<02.10.01.02.06.01_Starting_the_Profile_Editor.md>).

## Procedures

### To edit a rule

- In the Current Profile section of the Profile Editor, select the rule you want to edit.
- Use the fields in the Rule Editor section to change the scope of the property, the value of the property or the property itself.
- Click Apply. The selected rule is updated.
- Repeat steps 1 through 3 for any other rules you want to edit.

### To create a new rule

- In the Rule Editor section of the Profile Editor, enter the scope of the rule in the three fields Test Suite or Group, Test Method, and Test Name, Num or Bin.
- In the Property field, choose a property from the list or define a user defined property by typing the desired property name.
- In the Value field, type the property value.
- Click Add. A new line is created.
- Repeat steps 1 through 4 for any additional rules you want to create.

### To change the rule sequence

When you have created or changed all rules, you can also modify the rule sequence if needed. Keep in mind that the sequence of the lines in a data logging profile is relevant. SmarTest executes the profile using a top-down approach. This means that in ambiguous situations, where multiple rules with the same property exist, the first rule in the list that matches is applied. Any subsequent rules are ignored.

To change the sequence, select a rule and click Up or Down.

### To delete a rule

To delete a rule, select it and click Remove.

### To save the profile

To save the profile, select the data log item in the Test Program Explorer, right-click, and choose Save or Save As. After you have saved the profile, the new settings take effect immediately.

## Results

You have created a new data logging profile or edited an existing one.

## Example

The first rule in every data logging profile contains the property `log_events_enable`. This property switches on the data logging mechanism if its value is set to 1.

To create this rule:

- In the Test Suite or Group, Test Method, and Test Name, Num or Bin fields, choose *.
- In the Property field, choose `log_events_enable`.
- In the Value field, enter 1.
- Click Add. The new rule is created: `*.*.*. log_events_enable = 1`
