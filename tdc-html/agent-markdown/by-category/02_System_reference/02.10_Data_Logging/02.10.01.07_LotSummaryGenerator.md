# LotSummaryGenerator

This tool is provided to generate the test summary in GDF format from data collection file or real-time event data stream. It is located in the directory /opt/hp93000/soc/formatter/bin.

- Ofline data collection file

Provide an offline data collection file (EDL file) as input when executing LotSummaryGenerator from the command line. LotSummaryGenerator will then retrieve data from the file and generate the lot summary for all the test program and testflow executions recorded in the file.

- Real-time event stream

If you do not provide the data collection file when executing the LotSummaryGenerator, it will try to attach to the current SmarTest session and generate the lot summary file in real time. If there's no SmarTest running, error messages will be printed and the LotSummaryGenerator exits. Make sure the system flag log_events_enable is set to on. Otherwise, no summary data will be generated.

The application variable LOT_SUMMNARY_PATH_NAME, FORCE_SUMMARY_GENERATION_FOR_LEVEL and  ENABLE_LOT_SUMMARY_GENERATOR are defined for LotSummaryGenerator.

LOT_SUMMNARY_PATH_NAME is used to specify the path and name of a separate summary file for each level in the application model file or BLC program.

FORCE_SUMMARY_GENERATION_FOR_LEVEL is used to generate the summary file before the level loop is completed in application model and BLC program.

ENABLE_LOT_SUMMARY_GENERATOR controls whether the LotSummaryGenerator is enabled. If this variable exists in the application model file, the LotSummaryGenerator will be started at the beginning of the application model execution. It will be shut down after the application model is finished.

If you use BLC client instead of application model file, you need to start and terminate the LotSummaryGenerator in the BLC client. You can define the variable LOT_SUMMNARY_PATH_NAME and  FORCE_SUMMARY_GENERATION_FOR_LEVEL with SetApplicationVar API.

You can also execute LotSummaryGenerator from the command line as below. The running of this tool will stop automatically when the current SmarTest session is terminated.

```
./LotSummaryGenerator [-d DataCollection] [-l logfile] [-o outputfile] [-v] [-m] [-h]
```

All the parameters are optional.

-d DataCollection

Specify the path and name of the offline EDL data collection file. If not specified, LotSummaryGenerator will try to attach to the current SmarTest session. If successfully attached, it will receive real-time events from SmarTest and generate the lot summary in GDF format. If no SmarTest is running, LotSummaryGenerator will send out error messages and exit.

-l logFile

Specify the path and name of the log file. If not specified, the log file LotSummaryGenerator.log will be generated in the home directory of the current user.

-o outputfile

Specify the path and name of the output lot summary file. If not specified, /tmp/LotSummary.output is used by default. If the specified file is already existing, the lot summary will be appended to this file. Otherwise, a new file will be created. When appending the lot summary to the existing file, the following line will be printed in the file as the separator.

```
========Start Of New TestProgram "testprogram_name" at yyyymmdd hhmmss========
```

where "testprogram_name" is the name of the test program/testflow and "yyyymmdd hhmmss" is the time stamp when the test program/testflow is started.

-v

Disables the effect of the application variable LOT_SUMMARY_PATH_NAME. This is used when you only want to generate the summary from offline data collection file to the output file specified by -o.

-m

Disables the printing of the test program separator above in the output summary file.

-h

Show the usage of LotSummaryGenerator and the description to each parameter.

## Examples

### Executing the LotSummaryGenerator in the command line

The following example generates the lot summary for the specified data collection file. The output file is /tmp/LotSummary.out. The log file LotSummrayGenerator.log is generated under the home directory of the current user.

```
/opt/hp93000/soc/formatter/bin/LotSummaryGenerator -d /var/opt/hp93000/soc/tm/93k.iI3eAe/DataColltion.
```

### Using LOT_SUMMNARY_PATH_NAME in the application model

```
...
{ lot:
         SCREEN_DIALOG
             Lot_id  = DIALOG_INPUT    /REGEXP(string);

        ACTIONS
            LOT_SUMMARY_PATH_NAME = CONST_INPUT(/tmp/{Lot_id}.lotSum.gdf);
}
...
```

### Using FORCE_SUMMARY_GENERATION_FOR_LEVEL in the application model

In the following example, the summary is generated at `point #1`. If FORCE_SUMMARY_GENERATION_FOR_LEVEL is not used, the lot summary is generated at `point #2`. Make sure to specify the current level name to FORCE_SUMMARY_GENERATION_FOR_LEVEL and put the variable in the post actions section of the level.

```
...
{ lot:
        ACTIONS
              ...
         {DEVICE device:
                      {
                               DEVICE_TEST
                       }
          }

           ACTIONS
                  FORCE_SUMMARY_GENERATION_FOR_LEVEL = CONST_INPUT(lot);
                   --point #1
                   EXEC_INP_CALL(process_lot_summary_file);
                  ...
}   --point #2
...
```

### Using ENABLE_LOT_SUMMARY_GENERATOR in the application model

In this example, ENABLE_LOT_SUMMARY_GENERATOR is used to enable the LotSummaryGenerator. The LotSummaryGenerator will be started at the beginning of the application model execution.

```
...
{ lot:
      SCREEN_DIALOG
          Lot_id  = DIALOG_INPUT    /REGEXP(string);
      ACTIONS
            ENABLE_LOT_SUMMARY_GENERATOR = CONST_INPUT(1);
}
...
```

### Using LotSummaryGenerator with BLC program

```
//header file
...
using namespace std;
using namespace xoc::hvmapi;
pid_t LSGPid = 0;
...
//Define the function to start the LotSummaryGenerator
void startLotSummaryGenerator()
{
  LSGPid = fork();

  if(LSGPid == 0)
  {
      execl("/opt/hp93000/soc/formatter/bin/LotSummaryGenerator", 0);
  }

}

//Define the function to terminate the LotSummaryGenerator
void terminateLotSummaryGenerator()
{
  int childStatus;

  if(LSGPid > 0)
  {
    sleep(5);
    kill(LSGPid, 9);
    waitpid(LSGPid, &childStatus, 0);
  }
}
...
int main(int argc, char* argv[])
{
  ParamList inputParam, outputParam;
  Status  retVal;

 /**********************
  * Initialize the BLC *
  **********************/
  //check if there are input file provided
  if(argc<=1)
  {
    cout<<"Please sepecify a BLC input file!!!"<<endl;
    cleanup();
    exit(1);
  }

  startLotSummaryGenerator();
  ...
  /***********************
  * Start the lot level *
  ***********************/
  inputParam.clear();
  inputParam["LEVEL_TYPE"] = "CUSTOM_LEVEL";
  inputParam["LEVEL_NAME"] = "lot";
  retVal = syncCommand("StartLevel", inputParam, LOCAL_SESSION_ID);
  processStatus(retVal);

  for(int lotNum=1; lotNum<=1; lotNum++)
  {
    ...
    //Add new variable LOT_SUMMARY_PATH_NAME for LotSummaryGenerator
    inputParam.clear();
    inputParam["VARIABLE_NAME"] = "LOT_SUMMARY_PATH_NAME";
    inputParam["VARIABLE_VALUE"] = string("/tmp/")+lotID+string(".lotSum.gdf");
    retVal = syncCommand("SetApplicationVar", inputParam, LOCAL_SESSION_ID);
    processStatus(retVal);
    ...
    //Add new variable FORCE_SUMMARY_GENERATION_FOR_LEVEL for LotSummaryGenerator
    inputParam.clear();
    inputParam["VARIABLE_NAME"] = "FORCE_SUMMARY_GENERATION_FOR_LEVEL";
    inputParam["VARIABLE_VALUE"] = string("lot");
    retVal = syncCommand("SetApplicationVar", inputParam, LOCAL_SESSION_ID);
    processStatus(retVal);
  } //end of the lot level loop
  terminateLotSummaryGenerator();
  cleanup();
  return 0;
}
```

## Functional changes

- Introduced in SmarTest 7.1.0
- SmarTest 7.1.1: Support the option -w waferIDVariable
- SmarTest 7.1.1: Add FF/TF/TT to the output file
- SmarTest 7.1.1: Start LotSummaryGenerator automatically when executing test program/testflow
- SmarTest 7.1.2: New application variable LOT_SUMMNARY_PATH_NAME and FORCE_SUMMARY_GENERATION_FOR_LEVEL
- SmarTest 7.1.2: Support generating lot summary for incomplete data collection file
- SmarTest 7.1.2: Support using with BLC program
- SmarTest 7.1.2: Remove the option -w waferIDVariable
- SmarTest 7.1.3: New option -v
- SmarTest 7.1.3: New option -m
- SmarTest 7.1.3: New application variable ENABLE_LOT_SUMMARY_GENERATOR.
