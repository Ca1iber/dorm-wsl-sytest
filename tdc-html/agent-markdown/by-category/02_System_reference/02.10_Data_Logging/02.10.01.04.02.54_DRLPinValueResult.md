# DRLPinValueResult

A variable of this type holds the pass/fail result data and the result value for a single pin.

The member failure_code can hold the following values:

Failure code values
 |

Value

 |

Description

 |
 |

-2= DRLFailureCode_Fatal

 |

test method execution incomplete or test method crashed

 |
 |

-1= DRLFailureCode_NA

 |

no pass/fail result determined

 |
 |

0 = DRLFailureCode_Pass

 |

passed

 |
 |

1 = DRLFailureCode_Fail

 |

failed

 |
 |

2 = DRLFailureCode_Error

 |

error

 |
 |

3 = DRLFailureCode_Bypass

 |

bypassed (this applies only to test suites)

 |

The member pin (see [DRLPinName](<02.10.01.04.02.46_DRLPinName.md>)) specifies the pin.

value holds the result value; for example, a measured pin current or pin voltage.

```
typedef struct {
  DRLPinName pin;
  unsigned char failure_code; /*s. enum DRLFailureCode
                                in dcl_drl.h */
   double value;
 } DRLPinValueResult;
```

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.4.1: Added error code -2.
