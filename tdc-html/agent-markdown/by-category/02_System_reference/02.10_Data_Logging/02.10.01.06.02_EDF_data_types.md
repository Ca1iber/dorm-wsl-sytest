# EDF data types

The table below describes the data types used for event data logging.

Little-endian byte order is used; the least significant byte is stored first.

Data type descriptions
 |

Type

 |

Description

 |
 |

char

 |

one-byte signed integer

 |
 |

short

 |

two-byte signed integer

 |
 |

int

 |

four-byte signed integer

 |
 |

long long

 |

eight-byte signed integer

 |
 |

unsigned char

 |

one-byte unsigned integer

 |
 |

unsigned short

 |

two-byte unsigned integer

 |
 |

unsigned int

 |

four-byte unsigned integer

 |
 |

real

 |

eight-byte floating point number in the IEEE 754 format

 |
 |

string

 |

null-terminated string

 |
