# ManualExecutionStateAttrType

Contains the information whether the test has been manually or automatically executed. The data type is [DRLManualExecutionStateAttr](<02.10.01.04.02.34_DRLManualExecutionStateAttr.md>).

  ![ManualExecutionStateAttrType structure](<../../../../raw/97986.png>)

Attribute type

 |

execution_state

 |

string

 |

Execution state, values are "Manual" or "Auto".

When the test is executed manually from the testflow editor, the value is "Manual". After the manual test execution is finished, the value is set to "Auto".
