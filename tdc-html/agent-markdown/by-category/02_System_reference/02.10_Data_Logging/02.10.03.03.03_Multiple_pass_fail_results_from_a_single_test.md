# Multiple pass/fail results from a single test

A TestEvent attribute is logged for each single test executed in a test suite. One or more PassFailResult attributes can be logged for each TestEvent attribute.

The pass/fail result is logged into the appropriate record, either one PTR, FTR, or MPR record. The TEST_FLG in each of the records is set accordingly:

- If all of the PassFailResult attributes are of type PASS, then the TEST_FLG is set to pass (bit 6 and 7 = 0).
- If one or more of the PassFailResult attributes are of type FAIL, the TEST_FLG is set to fail (bit 6 = 0, and 7 = 1).
- If any of the PassFailResult attributes are of type UNKNOWN, the TEST_FLG is set to unknown (bit 6 and 7 = 1).
