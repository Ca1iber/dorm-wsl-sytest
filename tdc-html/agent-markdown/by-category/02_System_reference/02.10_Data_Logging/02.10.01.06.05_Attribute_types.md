As described in [EDF data organization](<02.10.01.06.01_EDF_data_organization.md>), each event record body consists of a set of attribute records. These attribute records hold the characteristics describing the event. The number of attribute records and types of attributes that come with one event depend on the event type (see [Event types](<02.10.01.06.03_Event_types.md>)).

This section lists all attribute types in alphabetical order and describes the data held in the attribute record body for each type.

The [Data Retrieval Library](<02.10.01.04_Data_Retrieval_Library.md>) provides the [data types](<02.10.01.04.02_DRL_data_types.md>) for holding and processing attribute data.
