# TestProgramEndEventType

An event of this type is logged when the test program finishes.

## Attributes

- [TimeStampAttrType](<02.10.01.06.05.65_TimeStampAttrType.md>)

Holds the time at which the test program ended.

## Functional changes

- Introduced before SmarTest 6.3.2
