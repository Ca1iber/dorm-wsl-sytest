# ManualExecutionEventType

This event indicates whether events from the testflow are being generated by an execution of the testflow in the context of a test program or by manual execution from the Testflow Editor (for example, during debugging).

Each set of events from a manual execution is preceded by an event of the ManualExecutionEventType with the execution state attribute set to "Manual" and followed by an event of this type with the attribute set to "Auto".

## Attributes

- [ManualExecutionStateAttrType](<02.10.01.06.05.22_ManualExecutionStateAttrType.md>)

Contains either of the strings "Manual" or "Auto".

When the test is executed manually from the testflow editor, the value is "Manual". After the manual test execution is finished, the value is set to "Auto".

- [TimeStampAttrType](<02.10.01.06.05.65_TimeStampAttrType.md>)

Holds the time when the manual execution started.

## Functional changes

- Introduced before SmarTest 6.3.2
