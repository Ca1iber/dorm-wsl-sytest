# DRLEventGetNextAttributeByType

int DRLEventGetNextAttributeByType

```
              (const DRLEventRec *event, DRLAttributeType type, DRLAttributeRec *attribute)
```

This function retrieves the next attribute record of the type type and copies the reference to it to the caller-provided buffer attribute (see [DRLAttributeRec](<02.10.01.04.02.03_DRLAttributeRec.md>)).

'Next' attribute record means the next one after the last which has been accessed by one of the functions DRLEventGetAttribute, DRLEventGetFirstAttributeByType, or DRLEventGetNextAttributeByType.

If none of these functions was called before for the event record, DRLEventGetNextAttributeByType retrieves the first attribute record of this type from event.

## Return Value

The return value is zero if the function was successful; otherwise the error code ERR_NO_ATTR (see [Error Codes](<02.10.01.04.02.108_Error_Codes.md>)) is returned if the event has no more attribute records as specified by type.

## Example

```
void example (void)
{
    DRLEventRec event;
    DRLAttributeRec attribute;
    int error_code;
    if (DRLGetNextUnmaskedEvent(&event))
        { /* error handler*/
            break;
        }
    error_code = DRLEventGetFirstAttributeByType(&event,
                                         DeviceIdAttrType, &attribute);
    while (error_code == 0)
        {
            printf("Device processed: %s\n",
                    attribute.data.device_id_attr.device_id);
            error_code = DRLEventGetNextAttributeByType(&event,
                                        DeviceIdAttrType, &attribute);
        }
}
```
