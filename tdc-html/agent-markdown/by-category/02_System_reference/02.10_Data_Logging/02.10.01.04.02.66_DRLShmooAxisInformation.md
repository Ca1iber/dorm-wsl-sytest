# DRLShmooAxisInformation

A variable of this type holds the data describing a general shmoo axis. That is, it contains the definition of the parameters and their changes during the execution of the shmoo test function. Parameters are the main x-axis and y-axis parameters as well as the tracked parameters. In a multi-dimensional sweep test any of these parameters represents one axis of the shmoo plot.

A variable of this type is used in [DRLShmooAxisXYInformation](<02.10.01.04.02.67_DRLShmooAxisXYInformation.md>).

The member parameter holds the sweep parameter. parameter can be one of the values defined in the enumeration DRLShmooParameter:

The member devcyc holds the device cycle that uses the sweep parameter as a NULL terminated string.

unit holds the unit of the sweep parameter (mV, V, ps, ns, us, ms, A) as a NULL terminated string.

 Note You can specify any derived unit (such as ns or mA) for EDL data logging. However, when data logs are converted to STDF, all units are converted to their SI equivalents (ns to s, mA to A) and the corresponding values are converted accordingly. (For example, 435 mA is converted to 0.435 A.)

formula is TRUE (1) when the step values for a tracked parameter are calculated from master (x, y) values, otherwise it is FALSE (0).

slope_start holds either the slope value used for the calculation of the values of a tracked parameter (if formula is TRUE) or the start value of the sweep parameter.

intersection_stop holds either the offset value used for calculating the values of a tracked parameter (if formula is TRUE) or the stop value of the sweep parameter.

pins points to the first element of a list of the pins for which the sweep test was executed (see [DRLPinName](<02.10.01.04.02.46_DRLPinName.md>)).

size is the number of pins in the list.

```
typedef struct
{
  DRLShmooParameter parameter;
  const char *devcyc;
  const char *unit;
  short formula;

  double slope_start;   /* contains slope value, if
                           formula == TRUE
                   else it contains start value */

  double intersection_stop; /* contains intersection value,
                               if formula == TRUE;
                       else it contains stop value  */

  unsigned short size;
  DRLPinName *pins; /* this is an array; size is the real
                       size of this array */
} DRLShmooAxisInformation;
```
