# Example configuration file

Shown below are examples of configuration file formats. As mentioned before, there are global and STDF specific configuration files that allow you to customize your STDF output with regard to the default, tester or device levels of configuration.

 Note Not all possible configurations are shown. These examples are only intended to provide an overview of how an actual configuration file may look.

Example Global Configuration File

```
formatter.stdf.summaryFileLocation=~/summaryFiles
formatter.stdf.detailedFileLocation=~/detailedTestResults
formatter.stdf.testFlowEditorFileLocation=~/testflowResults
formatter.stdf.generateStdfFromTestflowEditor=True
```
