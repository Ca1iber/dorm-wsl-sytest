# Error Codes

The functions of the DRL return error codes for failures. The following error codes are defined:

- ERR_NO_ERROR: Dummy error code for no error. Same as the return value zero.
- ERR_UNSPECIFIED: The given contents of a parameter could not be processed.
- ERR_INVALID: A value was outside the valid range.
- ERR_ACCESS: The specified path or file could not be accessed (see [DRLSave](<02.10.01.04.01.20_DRLSave.md>), [DRLStart](<02.10.01.04.01.22_DRLStart.md>)).
- ERR_EOF: The end of the data log stream or data log file was encountered before the event record was read completely (see [DRLGetNextUnmaskedEvent](<02.10.01.04.01.09_DRLGetNextUnmaskedEvent.md>)).
- ERR_NO_EVENT: Either no event record was available or the events related to all available event records were masked by the current event mask (see [DRLGetNextUnmaskedEvent](<02.10.01.04.01.09_DRLGetNextUnmaskedEvent.md>)).
- ERR_NO_ATTR: The event does not have the specified attribute record (see [DRLEventGetAttribute](<02.10.01.04.01.02_DRLEventGetAttribute.md>)).
- ERR_TRUNC: The data log stream could not be truncated (see [DRLSave](<02.10.01.04.01.20_DRLSave.md>), [DRLTruncate](<02.10.01.04.01.24_DRLTruncate.md>)).

```
enum {
  ERR_NO_ERR,
  ERR_UNSPECIFIED
  ERR_INVALID
  ERR_ACCESS,
  ERR_EOF,
  ERR_NO_EVENT,
  ERR_NO_ATTR,
  ERR_TRUNC,
 };
```
