# DRLShmooUserDefinedParamType

A variable of this type holds the information for a user defined parameter which is varied for an axis on a shmoo plot.

- paramName: The name of the defined parameter, which is defined with the [addParameterType](<../02.07_Test_Method_Reference/02.07.07.02.01.01_addParameterType.md>) function.
- type: The data type of the defined parameter, which can be int or double.

## Syntax

```
typedef struct _DRLShmooUserDefinedParamType
{
  const char* paramName;
  const char* type;
}*DRLShmooUserDefinedParamType;
```
