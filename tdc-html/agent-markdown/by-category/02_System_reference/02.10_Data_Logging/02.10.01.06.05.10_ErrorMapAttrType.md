# ErrorMapAttrType

Contains detailed information about the errors occurred during running a scan pattern. The data type is [DRLErrorMapAttr](<02.10.01.04.02.15_DRLErrorMapAttr.md>).

mode

 |

unsigned int

 |

Bitwise or'ed, specifying which information is available:

- DRL_ERROR_MAP_MODE_TESTER_CYCLE: cycle_number is present and represents tester cycle
- DRL_ERROR_MAP_MODE_USER_CYCLE: cycle_number is present and represents user cycles
- DRL_ERROR_MAP_MODE_OFFSET: instance_id and offset fields are present
- DRL_ERROR_MAP_MODE_STATE_CHAR_AVAILABLE: state_char is present
- DRL_ERROR_MAP_MODE_RECEIVED_DATA_AVAILABLE: received is present
