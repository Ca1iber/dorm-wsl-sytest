# Restoring the default data logging profiles

## About this task

This task describes how to restore the default data logging profiles included with SmarTest when they have been deleted:

- datalog_OFF.prf
- datalog_ON.prf

## Procedure

-  If you have created your own data logging profiles, copy them to a private directory by typing cp <device directory>/profiles/* /<home directory>/my_profiles
-  Delete the profiles directory by typing rm -r <device directory>/profiles.
-  Is the SmarTest software running?

Yes: Continue with step 4.

No: Start SmarTest and continue with step 5.

-  Reload the testflow file. The profiles directory and the default data logging profiles will be recovered.
-  Copy your own data logging profiles back to the profiles directory by typing cp /<home directory>/my_profiles/* <device directory>/profiles.

## Results

The default data logging profiles are restored.

## Functional changes

- Introduced before SmarTest 6.3.2
