# Examples

These are some examples of commands for executing DRLDump:

- `DRLDump /my_streams/dl_stream1`

Processes the data log stream saved as dl_stream1 in the directory my_streams. All event types and attribute types coming with each event are printed. Then DRLDump terminates.

- `DRLDump -system`

Processes all event records currently stored in the system data log stream. All event types and attribute types coming with each event are printed. Then DRLDump waits for new event records to be written to the stream and processes them immediately after their occurrence.

- `DRLDump -system -trunc -print`

First, the current system data log stream is cleared. Then, all new event records that will be written to the system data log stream are processed until DRLDump is terminated by the user. All event types and attribute types coming with each event are printed, plus the contents of each attribute.
