# Test numbers

The following STDF records contain the TEST_NUM record field:

- [Test Synopsis Record](<02.10.03.05.26_Test_Synopsis_Record__TSR.md>) (TSR)
- [Parametric Test Record](<02.10.03.05.22_Parametric_Test_Record__PTR.md>) (PTR)
- [Multiple-result Parametric Record](<02.10.03.05.23_Multiple-Result_Parametric_Record__MPR.md>) (MPR)
- [Functional Test Record](<02.10.03.05.24_Functional_Test_Record__FTR.md>) (FTR)

If test numbers are enabled, then the TEST_NUM field is populated with the test number from either the TestEvent or the UserProcedureEvent.

If test numbers are not enabled, then a test number is not assigned for the TestEvent attribute in EDL. An ID number from the TestSuiteStartEvent for that test is populated into the TEST_NUM field. It is important to note that in this case, the test number will not be unique.

Note that valid PTR, MPR, and FTR records require unique test numbers. Records of these types that do not contain unique test numbers make any analysis unreliable or cause it to fail entirely.

For detailed information regarding test numbering, see [Generating Test Numbers](<02.10.01.08_Managing_Test_Numbers.md>).
