# Creating test tables

Test tables for storing test numbers, limits, and other test-related information can be created in various ways.

## About this task

Perform this task whenever you want to create a new test table.

(For modifying existing tables, see [Editing test tables](<02.10.01.08.03.02_Editing_test_tables.md>). For creating TMLimits tables, see [Creating TMLimits test tables](<02.10.01.08.02.01_Creating_TMLimits_test_tables.md>).)

### Test table template file

You can create a test table file named TestTableTemplate.csv within the <device>/testtable folder. SmarTest uses this file as template for each new test table file you create afterwards.

That is, if the TestTableTemplate.csv file exists SmarTest uses it as template. If it does not exist SmarTest will automatically generate it, based on the current test table file layout and stores it in the <device>/testtable folder.

## Procedures

### Creating a test table from the SmarTest Work Center

From the SmarTest Work Center, you can create TMLimits test tables, as described in [Creating TMLimits test tables](<02.10.01.08.02.01_Creating_TMLimits_test_tables.md>).

### Creating a test table from a test method

- Create a new TestTable class instance.
- Use the functions of the TestTable class to add fields (columns), tables (rows), and values to the instance object.

Which of these functions are best suited, depends on the specific issue you want to solve. See [TestTable](<../02.07_Test_Method_Reference/02.07.04.01.245_TestTable.md>) for a description of the available functions.

- Save the test table using the writeCsvFile function.

Note that only fields and tests (columns and rows) marked as visible are saved to disk.

### Creating a test table using an external editor

You can create a test table manually using any editor that can write CSV files, which includes most text editors, word processors, and spreadsheet applications.

- Open a new document in the editor of your choice.
- Enter the data for the test table.

If your using a text editor or word processor, separate fields (cells) by commas and tests (rows) by return characters. In spreadsheet programs, put each value in a separate cell.

- Save the file with a .csv extension.

Spreadsheet applications usually offer CSV as a supported file type. In editors or word processors, save the data as a text-only file with the .csv extension.

Note that you must make sure that the test table has the format that is expected by the test methods with which you intend to process it.

## Results

The new test table is saved as a file on disk.
