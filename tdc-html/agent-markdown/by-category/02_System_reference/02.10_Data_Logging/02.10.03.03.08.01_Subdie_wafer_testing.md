# Subdie wafer testing

Subdie wafer testing is a special case of wafer testing, where one set of wafer coordinates can represent multiple dies.

In normal wafer testing, each X,Y coordinate represents one die. In subdie wafer testing,each X,Y coordinate still represents one die. However, this die consists of several small dies that all have similar functionalities. These small dies are called subdies. They share the coordinate of the die to which they belong .

Every subdie has a unique part ID (PART_ID parameter) to distinguish it from other subdies with the same wafer coordinates. During testing, all subdies are tested, and an EDL report is generated in which the test results of the different subdies are distinguished through the different part IDs.

For more information, see the Subdie identification numbering section in [The PART_ID field in the PRR](<02.10.03.03.08_The_PART_ID_field_in_the_PRR.md>).
