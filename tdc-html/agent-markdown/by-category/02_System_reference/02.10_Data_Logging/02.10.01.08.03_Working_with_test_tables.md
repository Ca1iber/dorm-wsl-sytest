# Working with test tables

#### Subtopics

- [Creating test tables](<02.10.01.08.03.01_Creating_test_tables.md>)
- [Editing test tables](<02.10.01.08.03.02_Editing_test_tables.md>)
- [Using test tables](<02.10.01.08.03.03_Using_test_tables.md>)

Test tables store limits, test numbers, and optionally any additional information you want to associate with a test.

SmarTest includes the TestTable class as a versatile implementation of test that lets you use custom test table formats (as long as they are based on the CSV format).

 Note SmarTest also comes with a more specialized test table implementation named TMLimits that can be used even more easily. We recommend that you use TMLimits unless you have specific needs that it does not accommodate.

Working with test tables involves, creating, editing and using them:

- [Creating tables](<02.10.01.08.03.01_Creating_test_tables.md>)
- [Editing tables](<02.10.01.08.03.02_Editing_test_tables.md>)
- [Using the values from tables in test methods](<02.10.01.08.03.03_Using_test_tables.md>)
