# DRLTestFunctionParametersAttr

A variable of this type holds the list of parameters which are needed for the execution of a test function as a NULL terminated string.

```
typedef char *DRLTestFunctionParametersAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
