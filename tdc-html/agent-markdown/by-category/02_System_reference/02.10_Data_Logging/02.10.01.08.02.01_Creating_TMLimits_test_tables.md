# Creating TMLimits test tables

TMLimit test tables for storing test numbers, limits, and other test-related information can be created in various ways.

## About this task

Perform this task whenever you want to create a new TMLimits test table.

(For information on modifying TMLimits tables, see [Editing TMLimits test tables](<02.10.01.08.02.02_Editing_TMLimits_test_tables.md>). For creating other kinds of test tables, see [Editing test tables](<02.10.01.08.03.02_Editing_test_tables.md>).)

## Procedure

-  Load the testflow for which you want to create a test table.
-  In the Test Program Explorer, right-click the <Test Table> entry and choose New from the shortcut menu.

A Save dialog is displayed.

-  Enter a name for the new test table, choose a location, and click OK.

The name of the test table appears in the Test Program Explorer.

The created file already contains two [Header rows](<02.10.01.08.01.01.03.01_Structure_of_a_TMLimits_CSV_file.md#_112490__s_Header_rows>): The first header row contains the names of the columns. The second row contains the test mode assigned to each column.

-  Right-click the test table in the Test Program Explorer and choose Open from the shortcut menu.

The test table is displayed in the [Test table editor](<02.10.01.08.01.01.01_Test_table_editor.md>). It contains the values that have been set for the testflow.

-  Edit the values in the table as needed.

To edit the value in a cell, double-click it.

If desired, you can add new rows or columns. For a description of the standard columns, see [Structure of a TMLimits CSV file](<02.10.01.08.01.01.03.01_Structure_of_a_TMLimits_CSV_file.md>). To add a test mode row (if one is not present), add an empty row at the top and enter "Test mode" (without the quotes, case matters) in the first cell.

For a description of generating test numbers, see [Generating test numbers from the SmarTest GUI](<02.10.01.08.01.01_Generating_test_numbers_from_the_SmarTest_GUI.md>).

-  Right-click the test table in the Test Program Explorer and choose Save from the shortcut menu.

The standard location for TMLimits test tables is in the testtable subdirectory of the device directory.

 Note You can create TMLimits test tables from a test method or using an external editor by creating general test tables, as described in [Creating test tables](<02.10.01.08.03.01_Creating_test_tables.md>), and making sure that these tables conform to the specifications for TMLimits tables, as described in [Structure of a TMLimits CSV file](<02.10.01.08.01.01.03.01_Structure_of_a_TMLimits_CSV_file.md>).

## Results

The new TMLimits test table is saved as a file on disk.
