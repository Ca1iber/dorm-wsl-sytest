# DRLEventGetType

DRLEventType DRLEventGetType (const DRLEventRec *event)

This function reads the event type from the header of the event record event and returns that type.

The number of attribute records which come with an event record and their type depend on the event type. Thus, you can use the event type to call event-specific functions which analyze the attribute data coming with the event, or to branch to program parts which perform such analysis (see the example below).

For more information on the data types involved see [DRLEventType](<02.10.01.04.02.19_DRLEventType.md>) and [DRLEventRec](<02.10.01.04.02.18_DRLEventRec.md>).

## Return Value

The event type of event.

## Example

```
void example (void)
{
   /* event has been initialized before by a call of DRLGetNextUnmaskedEvent */

   DRLEventType event_type;
   event_type = DRLEventGetType (&event)
   switch (event_type)
       { case ProgramStartEventType:
         /* analysis of the attribute records coming
             with an event of the type ProgramStartEventType
         */
              break;
         case TestFlowStartEventType:
          /* analysis of the attribute records coming with
             an event of the typeTestFlowStartEventType */
              break;
         /*
              .
              .
              .
              .
         */
       };
}
```
