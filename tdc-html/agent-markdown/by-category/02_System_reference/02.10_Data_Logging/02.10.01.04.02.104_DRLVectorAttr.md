# DRLVectorAttr

A variable of this type holds the number of a vector or one of the defined values listed in the struct below.

```
typedef struct {
  int vector_number;/* contains the vector number or a
                     value defined in r_com.h:
                     R_MATCH_VECTOR,R_BRK_VECTOR or
                     R_UNKNOWN_VECTOR */
} DRLVectorAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
