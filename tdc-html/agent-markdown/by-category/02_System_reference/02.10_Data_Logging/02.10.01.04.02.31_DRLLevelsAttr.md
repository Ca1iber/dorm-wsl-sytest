# DRLLevelsAttr

A variable of this type holds the information on the levels used for a test. The member type specifies whether the levels are set-based or equation-based. type can be one of the values DRLSetBased or DRLEquationBased (see below).

If the levels are set-based, the member level_set holds the number of the level set and the member dps_or_spec_set holds the number of the dps set. In this case, the member equation_set is undefined.

If the levels are equation-based, the member equation_set holds the number of the equation set while the member dps_or_spec_set holds the number of the spec set.

The member level_set holds the number of the level set.

```
typedef struct _DRLLevelsAttr {
  unsigned char type; /* DRLSetBased or DRLEquationBased */
  short
    equation_set,
    level_set,
    dps_or_spec_set;
} DRLLevelsAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
