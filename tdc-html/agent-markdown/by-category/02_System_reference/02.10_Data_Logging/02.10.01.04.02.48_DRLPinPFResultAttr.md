# DRLPinPFResultAttr

A variable of this type is a pointer to a structure named _DRLPinPFResultAttr. In this structure a list of pin pass/fail results (see [DRLPinPFResult](<02.10.01.04.02.47_DRLPinPFResult.md>)) is stored.

The member size holds the real number of elements in the array pins, that is, the number of pin pass/fail results in the list.

The member description can hold any further information as a NULL terminated string.

```
typedef const struct _DRLPinPFResultAttr{
    char *description;
    unsigned size;
    DRLPinPFResult pins[1];
   } *DRLPinPFResultAttr;
```
