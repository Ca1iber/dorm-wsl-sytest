# DRLEventAvailable

int DRLEventAvailable (DRLDataStream *stream)

If stream references the system data log stream, this function checks if a new event record has been written to the data log stream since the last call of [DRLGetNextUnmaskedEvent](<02.10.01.04.01.09_DRLGetNextUnmaskedEvent.md>). This is done by looking at the event counter which resides in shared memory. If the DRL operates on a saved data log file referenced by stream, no checking is performed and non-zero is returned immediately.

Note that DRLEventAvailable only checks if any new event record is available and does not apply the event mask.

## Return Value

For the data log stream, non-zero is returned if a new event record is ready to be read. This allows you to treat the result value as true if a new record is ready and false if it is not.

For a data log file, non-zero is always returned.

Note that EOF is handled by the [DRLGetNextUnmaskedEvent](<02.10.01.04.01.09_DRLGetNextUnmaskedEvent.md>) function.

- Introduced before SmarTest 6.3.2
