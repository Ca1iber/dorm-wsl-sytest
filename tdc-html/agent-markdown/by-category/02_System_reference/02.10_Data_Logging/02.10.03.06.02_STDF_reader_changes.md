# STDF reader changes

The STDF reader has been modified so that, by default, the appropriate scale and units are displayed along with the result in the PTR.RESULT and MPR.RTN_RSLT fields. If you want to see the unscaled result field, you can use the "-r" option when you run the STDF reader as follows:

STDFreader -r <STDF filename>.

When you use the "-r" option, the results will be displayed as follows:

- The unscaled result is displayed in the RESULT/RTN_RSLT field of the PTR or MPR.
- The scale information is displayed in the RES_SCAL, LLM_SCAL, and HLM_SCAL fields.
- The formatting information is displayed in the C_RESFMT, C_LLMFMT, and C_HLMFMT fields.

(This is how the STDF reader displayed information prior to the SmarTest Data Formatter release.)
