# Logging user text to the MPR TEST_TXT field

To log data using test methods to the TEST_TXT field in the Multiple-result Parametric Record (MPR) the appropriate calls to the test methods must be made.

The text can be viewed with the [Detail data views](<../02.08_Setup_and_Result_Tools/02.08.04.13.03.03_Detail_data_views.md>) of the [Result perspective](<../02.08_Setup_and_Result_Tools/02.08.04.13.01.01_Result_perspective_overview.md>).

For details, see the [TESTSET API](<../02.07_Test_Method_Reference/02.07.04.01.244_TESTSET.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
