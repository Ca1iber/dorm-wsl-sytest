# DRLTestCondition

Variables of the DRLTestCondition type store a key-value pair describing a particular condition of a test.

They are used in [DRLTestConditionAttr](<02.10.01.04.02.86_DRLTestConditionAttr.md>) structs.

## Syntax

```
typedef struct _DRLTestCondition {
char* key;
char* value;
} *DRLTestCondition;
```

## Functional changes

- Introduced in SmarTest 7.1.2
