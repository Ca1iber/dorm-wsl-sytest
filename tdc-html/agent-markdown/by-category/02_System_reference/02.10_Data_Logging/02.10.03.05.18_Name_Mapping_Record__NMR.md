# Name Mapping Record (NMR)

A Name Mapping Record maps [PMR](<02.10.03.05.11_Pin_Map_Record__PMR.md>) indexes to ATPG signal names. This allows the signal names to be preserved even when the PMR records do not contain signal names.

The Name Mapping Record can appear after the [Pattern Sequence Record (PSR)](<02.10.03.05.12_Pattern_Sequence_Record__PSR.md>).

 |

ATPG_NAM

 |

Array of ATPG names corresponding to the PMR indexes

 |

- Array with the dimension LOCM_CNT
- Each value is a variable length character string:

- First byte is unsigned count of bytes to follow

- Maximum 255 bytes

- Length byte = 0 if missing or invalid data
