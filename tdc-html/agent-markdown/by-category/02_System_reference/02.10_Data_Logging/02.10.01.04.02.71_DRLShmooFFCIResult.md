# DRLShmooFFCIResult

A variable of this type holds a list of the pins that failed in a specific cycle during execution of a sweep test.

The member cycle_number holds the number of the cycle.

vector_number holds the number of the vector or one of the defined values listed in the struct below.

label holds the vector label as a NULL terminated string.

The member pins (see [DRLPinName](<02.10.01.04.02.46_DRLPinName.md>)) holds the list of the failed pins. size is the real number of elements in the pins array, that is, the number of pins in the pin list.

```
typedef struct

  DRLCycleNumber cycle_number;
  int vector_number; /* contains the vector number or
                     a value defined in r_com.h:
                     R_MATCH_VECTOR,R_BRK_VECTOR or
                     R_UNKNOWN_VECTOR */
  const char *label; /* is NULL, when no label
                     information is available */
  unsigned short size;
  DRLPinName *pins;  /* this is an array; size is the
                     real size of this array */
} DRLShmooFFCIResult;
```
