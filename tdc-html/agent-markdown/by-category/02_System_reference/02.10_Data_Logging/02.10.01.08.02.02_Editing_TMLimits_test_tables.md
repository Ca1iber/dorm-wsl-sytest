# Editing TMLimits test tables

You can edit TMLimits test tables that have been saved as CSV files individually or through a master file.

## About this task

Perform this task whenever you want to modify an existing TMLimits test table. (For creating new TMLimits test tables, see [Creating TMLimits test tables](<02.10.01.08.02.01_Creating_TMLimits_test_tables.md>). For editing general test tables, see [Editing test tables](<02.10.01.08.03.02_Editing_test_tables.md>).)

## Before you begin

Make sure that the test table that you want to edit exists as a TMLimits CSV file.

## Procedure

-  In the Test Program Explorer, right-click the <Test Table> entry and choose Load from the shortcut menu.

An Open dialog is displayed.

-  Choose the TMLimits test table that you want to edit and click OK.

You can also choose a master file (with a .mfh filename extension). The name of the chosen file appears in the Test Program Explorer.

-  Right-click the test table in the Test Program Explorer and choose Open from the shortcut menu.

The test table is displayed in the [Test table editor](<02.10.01.08.01.01.01_Test_table_editor.md>). It contains the values that have been set for the testflow.

When you have opened a master file, each file it references is displayed in an individual tab and can be edited independently.

-  Edit the values in the table as needed.

To edit the value in a cell, double-click it.

If desired, you can add new rows or columns. For a description of the standard columns, see [Structure of a TMLimits CSV file](<02.10.01.08.01.01.03.01_Structure_of_a_TMLimits_CSV_file.md>). To add a test mode row (if one is not present), add an empty row at the top and enter "Test mode" (without the quotes, case matters) in the first cell.For a description of generating test numbers, see [Generating test numbers from the SmarTest GUI](<02.10.01.08.01.01_Generating_test_numbers_from_the_SmarTest_GUI.md>).

-  Right-click the test table in the Test Program Explorer and choose Save from the shortcut menu. Note You can edit TMLimits test tables from a test method or using an external editor by editing them as general test tables, as described in [Creating test tables](<02.10.01.08.03.01_Creating_test_tables.md>). If you do so, make sure that these tables conform to the specifications for TMLimits tables, as described in [Structure of a TMLimits CSV file](<02.10.01.08.01.01.03.01_Structure_of_a_TMLimits_CSV_file.md>).

## Results

The modified TMLimits test table is saved as a file on disk.
