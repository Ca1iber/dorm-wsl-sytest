# DRLSiteId

A variable of this type holds the ID of a site. Such variables are used in [DRLSiteSetAttr](<02.10.01.04.02.83_DRLSiteSetAttr.md>).

```
typedef unsigned char DRLSiteId;
```

## Functional changes

- Introduced before SmarTest 6.3.2
