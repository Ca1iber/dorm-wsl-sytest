# DRLTestSuiteAttr

An attribute of this type contains the names, the type of a test suite, and the test number.

```
typedef struct _DRLTestsuiteAttr {
        const char *testsuite_name;     /* name of the test suite                 */
        const char *test_type;          /* for example functional, continuity, ...*/
        const char *description;        /* not used up to now                     */
        long test_number;               /* if const >=0, otherwise -1             */
} *DRLTestsuiteAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
