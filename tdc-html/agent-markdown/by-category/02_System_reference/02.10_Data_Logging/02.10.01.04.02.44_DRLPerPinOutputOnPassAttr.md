# DRLPerPinOutputOnPassAttr

A variable of this type holds the enabled or disabled state of the "Per Pin Output On Pass" test suite flag as a NULL terminated string.

```
typedef char *DRLPerPinOutputOnPassAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
