# Saving test numbers as TMLimits CSV files

#### Subtopics

- [Structure of a TMLimits CSV file](<02.10.01.08.01.01.03.01_Structure_of_a_TMLimits_CSV_file.md>)

Test numbers from any testflow can be exported as a CSV file for use with [TMLimits](<../02.07_Test_Method_Reference/02.07.04.01.250_TMLimits.md>).

## About this task

Exporting the test numbers (along with other information from the test table) allows you to access it from test methods via the TMLimits class.

This way, you can easily access the additional features that TMLimits offers, such as easily switchable test modes, as well as edit the CSV files on the fly without SmarTest (for example, in production environments).

Note Do not use the Export shortcut menu command to create a TMLimits file. The files this command creates are not compatible with the TMLimits class.

## Before you begin

Set up the test numbers as desired. Doing so is described in [Generating test numbers from the SmarTest GUI](<02.10.01.08.01.01_Generating_test_numbers_from_the_SmarTest_GUI.md>).

## Procedure

-  Load the testflow that contains the data you want to save as a TMLimits file.
-  In the test program explorer, right-click the Device Information > <Test Table> entry. From the shortcut menu, choose New.

A standard Save dialog opens.

Note that the actual file name is displayed in the test program explorer instead of <Test Table> if you have already saved a TMLimits CSV file.

-  Enter a name for the file and save it in the testtable/ directory inside the active device directory. Make sure to give it the .csv file name extension.

The <Test Table> entry in the test program explorer is replaced by the file name.

## Results

The CSV file is specified in the testflow as the active TMLimits configuration file.

## What to do next

Access the CSV file from your test methods using the [TMLimits](<../02.07_Test_Method_Reference/02.07.04.01.250_TMLimits.md>) API calls.
