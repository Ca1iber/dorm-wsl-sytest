# Editing test tables

You can edit test tables that have been saved as CSV files with a variety of tools.

## About this task

Perform this task whenever you want to modify an existing test table.

(For creating new test tables, see [Creating test tables](<02.10.01.08.03.01_Creating_test_tables.md>). For editing TMLimits tables, see [Editing TMLimits test tables](<02.10.01.08.02.02_Editing_TMLimits_test_tables.md>).)

## Before you begin

Make sure that the test table that you want to edit exists as a CSV file.

## Procedures

### Editing a test table from within a test method

- Create a new TestTable class instance.
- Load the test table that you want to edit, using the readCsvFile function.
- Use the functions of the TestTable class to modify the contents of the TestTable object.

Which of these functions are best suited depends on the specific issue you want to solve. See [TestTable](<../02.07_Test_Method_Reference/02.07.04.01.245_TestTable.md>) for a description of the available functions.

- Save the test table using the writeCsvFile function.

Note that only fields and tests (columns and rows) marked as visible are saved to disk.

### Editing a test table using an external editor

You can edit a test table manually using any editor that can read and write CSV files, which includes most text editors, word processors, and spreadsheet applications.

- Open the test table that you want to edit in the editor of your choice.
- Edit the test table as desired.

If your using a text editor or word processor, separate fields (cells) by commas and tests (rows) by return characters. In spreadsheet programs, put each value in a separate cell.

- Save the file.

Make sure that the file type is not changed in the saving process. Depending on the editor, this may mean that you have to use the Save As or the Export command instead of using simply Save.

## Results

The modified test table is saved as a file on disk.
