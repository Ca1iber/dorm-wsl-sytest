# DRLPortAttr

An attribute of this type contains an index to a port name string to identify the source port of a result.

```
typedef struct {
    unsigned short port_index; /* index to port name */
} DRLPortAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
