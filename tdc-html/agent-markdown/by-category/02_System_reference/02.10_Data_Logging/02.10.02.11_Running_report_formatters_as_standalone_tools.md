# Running report formatters as standalone tools

User-written report formatters and the Event Formatter can be run as stand-alone tools using the DRLtoASCII utility. This tool allows you to create ASCII output from a stored data log stream even if SmarTest is not running. DRLtoASCII is an extension of the simple DRLDump tool, which only provides simple output formatting (see [Appendix B: The DRLDump Tool](<02.10.01.10_Appendix_B__The_DRLDump_Tool.md>)).

The DRLtoASCII executable is located in:

/opt/hp93000/soc/hp83000/formatter/bin

DRLtoASCII is called with the following options:

 |

-h

 |

Prints a help message explaining the usage of DRLtoASCII.

 |
 |

-t

 |

This parameter applies only if the system data log stream is used as input.

Using it deletes the existing contents of the system data log stream without processing it. Then the report formatter waits for incoming event records and processes them immediately.

 |
 |

-s

 |

This parameter applies only if the system data log stream is used as input.

It synchronizes with the data log stream, that is, only events that are written to the stream after DRLtoASCII was started are displayed. Without this option, all events from the beginning of the data log stream are processed.

 |
 |

-f <formatter>

 |

This option specifies the report formatter shared library to be used.

If this parameter is missing, DRLtoASCII looks for the file libfilter.so in the current directory.

 |
 |

-d <data>

 |

This option specifies the file containing a data log stream.

If the option is missing and SmarTest is running, DRLtoASCII attaches to the system data log stream.

 |
 |

-o <output>

 |

This option specifies a file name for the output. If this option is missing the output is written to standard out.

 |

Examples:

- `DRLtoASCII -s -f /opt/hp93000/soc/hp83000/formatter/EventFormatter/libfilter.so`

DRLtoASCII generates Event Formatter output from the currently running test program.

- `DRLtoASCII -d DLstream.in -o eventdatalog.out -f /opt/hp93000/soc/hp83000/formatter/EventFormatter/libfilter.so`

DRLtoASCII generates Event Formatter output from the data log stream stored in the DLstream.in file and writes the output to the file eventdatalog.out.

## Functional changes

- Introduced before SmarTest 6.3.2
