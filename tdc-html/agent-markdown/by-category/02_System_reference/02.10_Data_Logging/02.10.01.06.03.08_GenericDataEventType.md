# GenericDataEventType

This event is a flexible container that can hold an arbitrary number of attributes (from 0 to 65535 attributes) of the [GenericDataFieldAttrType](<02.10.01.06.05.15_GenericDataFieldAttrType.md>) type.

## Attributes

- [GenericDataFieldAttrType](<02.10.01.06.05.15_GenericDataFieldAttrType.md>)

This type of attribute contains three member fields:

  - type: describes the data type pointed to by the data pointer
  - length: the length of the data in bytes
  - data: a pointer to the data for the GenericDataFieldAttrType attribute

- [TimeStampAttrType](<02.10.01.06.05.65_TimeStampAttrType.md>)

Holds the time when the event was logged.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.3.5.3: New attribute TimeStampAttrType
