# How the output is directed to the report window

The Event Formatter, that is, the eventProcess function, is called with the two parameters, output_buffer (type: char *) and length (type: int *). These two parameters form the interface to the report window. Any string that is written to output_buffer during the execution of the Event Formatter is written to the report window once the Event Formatter terminates. Output_buffer holds the actual output data, length holds only the number of characters in output_buffer.

## Functional changes

- Introduced before SmarTest 6.3.2
