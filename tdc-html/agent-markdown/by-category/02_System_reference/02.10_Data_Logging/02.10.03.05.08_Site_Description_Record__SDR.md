# Site Description Record (SDR)

The Site Description Record contains the configuration information for one or more test sites, connected to one test head that compose a site group.

The Site Description Record is located immediately after the RDR. If the RDR is not used, the SDR is located immediately after the MIR.

## SDR records for tests with more than 255 sites

In STDF logs for tests with more than 255 sites, multiple SDR records are created. Each of these records contains information for 128 sites. Several fields are handled specially in this case:

- SITE_GRP: The records are numbered in this field. The first of multiple SDRs has the group number 0, the second has 1, and so on.
- SITE_CNT: This field contains the number of sites in this group (that is, a maximum of 128).
- SITE_NUM: The site numbers in this field restart from 0 in each SDR and indicate the number of the site relative to the first site of the SDR.

To calculate the real site number, use this formula: (128 * SITE_GRP) + SITE_NUM.

For example, a test of 300 sites would produce three SDRs with the following values:

- Record 1: SITE_GRP 0, SITE_CNT 128, SITE_NUM 0 to 127
- Record 2: SITE_GRP 1, SITE_CNT 128, SITE_NUM 0 to 127
- Record 3: SITE_GRP 2, SITE_CNT 44, SITE_NUM 0 to 43
