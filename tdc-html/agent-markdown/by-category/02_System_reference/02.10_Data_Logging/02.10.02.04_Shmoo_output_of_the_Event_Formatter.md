# Shmoo output of the Event Formatter

The shmoo output by using the [Event Formatter](<02.10.02_Event_Formatter.md>) is demonstrated in this topic. (To use the Event Formatter to output shmoo data log, refer to [Logging shmoo tests in the report window](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.07_Saving_shmoo_plots_to_png_or_ASCII_files.md>).)

The shmoo output contains:

- The shmoo test suite name, appearing at the beginning and end.
- The shmoo setups:

  - This shmoo test suite used primary settings.
  - Result setups, such as the title of a shmoo plot, the result pins, and the test modes that determine the result data to be shown on shmoo cells.

For details, see [ShmooTestInforAttrType](<02.10.01.06.05.48_ShmooTestInforAttrType.md>).

  - The axis setups on shmoo plots. For details, see [ShmooTestInforAttrType](<02.10.01.06.05.48_ShmooTestInforAttrType.md>).

- Shmoo plots, including:

  - Plot descriptions: Such as the number of result pins and their names and the number of test modes and their names. For details, see [ShmooTestCellAttrType](<02.10.01.06.05.47_ShmooTestCellAttrType.md>).
  - Shmoo plots of different result pins and test modes.

By default, the y axis of the shmoo plot points down. To change its direction to be up, change the value of shmoo_y_axis_direction to 1 in the [Event Formatter configuration file (](<02.10.02.13_Appendix_B__Event_Formatter_Defaults.md>)[.formatterrc](<02.10.02.13_Appendix_B__Event_Formatter_Defaults.md>)[)](<02.10.02.13_Appendix_B__Event_Formatter_Defaults.md>).

If it is a multisite shmoo test, you will see shmoo setups and plots for each site and site numbers.

- (Optional) The directory in which the shmoo plots are saved as .png files. The directory will be <the current device>/shmoo/shmooPNG/. You will see it only if you have set shmoo_picture_generation to 1 in the configuration file [.formatterrc](<02.10.02.13_Appendix_B__Event_Formatter_Defaults.md>).

## Functional changes

- Introduced in SmarTest 7.2.0
- SmarTest 7.2.0: (7.2.0 patch 1) The output format of shmoo tests is changed.
- SmarTest 7.2.1: The Event Formatter starts to support the output of fail-bit-count shmoo test which is available for MTP.
- SmarTest 7.2.1: The Event Formatter can save shmoo plots to the <the current device>/shmoo/shmooPNG/ directory as .png files.
- SmarTest 7.2.2: Patch 5, the output will show the primary values of those resources that the X and Y axes represent
