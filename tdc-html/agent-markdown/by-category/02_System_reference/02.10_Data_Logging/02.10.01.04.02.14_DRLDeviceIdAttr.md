# DRLDeviceIdAttr

A variable of this type holds the ID of a device and the ID of the site for the device.

The member site holds the ID of the site (see [DRLSiteIdAttr](<02.10.01.04.02.82_DRLSiteIdAttr.md>)) while the member device_id holds the ID of the device as a NULL terminated string.

```
typedef struct {
  DRLSiteId site;
  char *device_id;
} DRLDeviceIdAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
