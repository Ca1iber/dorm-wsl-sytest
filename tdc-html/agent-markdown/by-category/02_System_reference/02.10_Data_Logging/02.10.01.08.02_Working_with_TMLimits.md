TMLimits is a high-level implementation of test tables that can be accessed both through the SmarTest Work Center and programmatically through test methods.

Working with TMLimits is described in:

- [Creating TMLimits test tables](<02.10.01.08.02.01_Creating_TMLimits_test_tables.md>)
- [Creating a TMLimits master file](<02.10.01.08.02.03_Creating_a_TMLimits_master_file.md>)
- [Editing TMLimits test tables](<02.10.01.08.02.02_Editing_TMLimits_test_tables.md>)
- [Editing a TMLimits master file](<02.10.01.08.02.04_Editing_a_TMLimits_master_file.md>)
- [Using TMLimits test tables](<02.10.01.08.02.05_Using_TMLimits_test_tables.md>)
- [TMLimits backwards compatibility](<02.10.01.08.02.06_TMLimits_backwards_compatibility.md>)Note For information on working with test tables other than TMLimits, see [Working with test tables](<02.10.01.08.03_Working_with_test_tables.md>). We recommend that you use TMLimits unless you have specific requirements that TMLimits does not meet.
