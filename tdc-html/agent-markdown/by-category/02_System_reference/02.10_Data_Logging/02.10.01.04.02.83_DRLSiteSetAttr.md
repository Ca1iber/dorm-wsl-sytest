# DRLSiteSetAttr

A variable of this type holds a set of sites. Each site can be identified by its site ID.

The member site points to the first ID in a list of the site IDs belonging to the set.

The member size holds the number of sites in the set. The example below shows how to read the site Ids of the set.

```
typedef struct _DRLSiteSetAttr {
  unsigned short size;
  DRLSiteId *site;
} DRLSiteSetAttr;

```

## Example

```
/* lists all site Ids of a site set */
void example (DRLSiteSetAttr ss_attribute)
/* contents of ss_attribute are passed by the caller
    of example */
{
  int i
  for (i=0; i<ss_attribute->size;i++)
  {
    printf(ss_attribute->site[i]);
  };
}
```
