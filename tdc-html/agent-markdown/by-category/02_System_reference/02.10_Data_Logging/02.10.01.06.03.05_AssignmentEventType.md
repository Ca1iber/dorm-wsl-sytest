# AssignmentEventType

An event of this type is logged when a value is assigned to a variable in either the application model or the testflow.

## Attributes

- [SiteIdAttrType](<02.10.01.06.05.49_SiteIdAttrType.md>)

Holds the ID of the site for which the assignment was made. If the assignment was not site specific, for example, an assignment in the application model, this attribute is not logged with the event.

- [NamedValueAttrType](<02.10.01.06.05.24_NamedValueAttrType.md>)

Holds the name of the variable or flag and the newly assigned value.

- [TimeStampAttrType](<02.10.01.06.05.65_TimeStampAttrType.md>)

Holds the time stamp of the assignment.

## Functional changes

- Introduced before SmarTest 6.3.2
