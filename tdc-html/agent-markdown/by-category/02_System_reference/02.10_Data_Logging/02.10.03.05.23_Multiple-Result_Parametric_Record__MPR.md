# Multiple-Result Parametric Record (MPR)

#### Subtopics

- [Logging user text to the MPR TEST_TXT field](<02.10.03.05.23.01_Logging_user_text_to_the_MPR_TEST_TXT_field.md>)

## Function

The Multiple-Result Parametric Record contains the results of a single execution of a parametric test with multiple results. The first occurrence of this record also establishes the default values for all semi-static information about the test, such as limits, units, and scaling. The MPR is related to the TSR by test number, head number, and site number.

## Location in the file

The Multiple-Result Parametric Record can appear anywhere in the data stream after the corresponding PIR, and before the corresponding PRR.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.1: The values of the C-RESFMT, C_LLMFMT, and C_HLMFMT fields are no longer hardcoded.
- SmarTest 7.5.0: TEST_FLG bit 0 is no longer hard-coded
