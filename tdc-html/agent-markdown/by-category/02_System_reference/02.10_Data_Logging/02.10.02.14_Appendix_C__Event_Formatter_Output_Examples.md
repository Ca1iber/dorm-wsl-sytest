# Appendix C: Event Formatter Output Examples

#### Subtopics

- [TESTSET.doLog_ShmooTest sample output](<02.10.02.14.01_TESTSET.doLog_ShmooTest_sample_output.md>)
- [dac_distortion sample output](<02.10.02.14.02_dac_distortion_sample_output.md>)

This appendix contains the Event Formatter output for the test functions.

- shmoo_2d and shmoo_2D_track
- dac-distortion

These examples provide a good impression of the detail and the amount of data that is generated by event data logging, and how this data is presented in a very readable format by the Event Formatter.

For the outputs shown here, the Event Formatter was set to generate the most detailed output possible, that is, all boxes were checked in the Report Dialog window.

## Functional changes
