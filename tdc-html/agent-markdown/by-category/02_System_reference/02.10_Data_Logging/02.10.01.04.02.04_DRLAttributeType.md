# DRLAttributeType

A variable of this type holds the type of an attribute. Such variables are members of type [DRLAttributeRec](<02.10.01.04.02.03_DRLAttributeRec.md>) objects.

```
typedef DCLAttributeType DRLAttributeType;
```

Type definition of DCLAttributeType:

```
typedef unsigned short DCLAttributeType;
```

## Functional changes

- Introduced before SmarTest 6.3.2
