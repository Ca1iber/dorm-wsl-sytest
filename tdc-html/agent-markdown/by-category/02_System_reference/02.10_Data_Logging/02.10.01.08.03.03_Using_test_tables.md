# Using test tables

Test tables are used to provide test numbers and limits for tests. They can be used from within a test method. Depending on the information that you have put into them, they can also provide additional custom data for tests.

## About this task

Use a test table whenever you want to apply test numbers, limits, or other data stored in it to a test.

(SmarTest contains predefined support for using TMLimits, as described in [Using TMLimits test tables](<02.10.01.08.02.05_Using_TMLimits_test_tables.md>).)

## Before you begin

Make sure that the test table is properly set up and stored in a CSV file.

## Procedure

-  To access values from a test table, create a [TestTable](<../02.07_Test_Method_Reference/02.07.04.01.245_TestTable.md>) class instance and load the CSV file into it using the readCsvFile function.
-  Access the values from the test table using the various functions, in particular the get... functions.

## Results

You can use the values from the test table in your test method.
