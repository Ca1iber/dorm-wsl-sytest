# DRLLabelListAttr

A variable of this type holds the information of which vector labels are loaded into the tester when a "configuration changed" event occurred.

## Syntax

```
typedef struct _DRLLabelListAttr {
  int label_count;
  struct _DRLLabelDescriptor label[1];
} *DRLLabelListAttr;
```
