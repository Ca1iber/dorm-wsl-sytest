# BinReachedEventType

An event of this type is logged whenever a device is binned. Note that if a device is binned multiple times due to the Overon flag, the binning is logged each time.

## Attributes

- [SiteIdAttrType](<02.10.01.06.05.49_SiteIdAttrType.md>)

Holds the ID of the site for which the tested device was binned.

- [BinAttrType](<02.10.01.06.05.03_BinAttrType.md>)

Holds the description of the bin in which the device was binned.

- [TimeStampAttrType](<02.10.01.06.05.65_TimeStampAttrType.md>)

Holds the time when the device was binned.

## Functional changes

- Introduced before SmarTest 6.3.2
