# DRLShmooCell

A variable of this type holds the result data for one cell of a shmoo plot. Such variables are used in [DRLShmooCellAttr](<02.10.01.04.02.69_DRLShmooCellAttr.md>).

The member status holds the overall result for the cell. status can be one of the values defined in the enumeration DRLShmooStatus:

POINT_NOT_CALCULATED

POINT_PASSED

POINT_FAILED

POINT_ERROR

test_mode holds the information about the mode in which the sweep test was executed (see [DRLShmooLegendAttr](<02.10.01.04.02.74_DRLShmooLegendAttr.md>) for more information). The mode determines the type of result data contained in the cell. This data is stored in the union result.

If test_mode is DRLShmooTestERCT, the member erct of the union is valid and contains the counted number of errors.

If test_mode is DRLShmooTestFFCI, the member ffci of the union is valid. Its contents are described in [DRLShmooFFCIResult](<02.10.01.04.02.71_DRLShmooFFCIResult.md>).

For test_mode = DRLShmooTestNormal, the union is not used. The pass/fail result is already contained in status.

If status is either POINT_NOT_CALCULATED or POINT_ERROR, result contains no valid data.

```
typedef struct{
  DRLShmooStatus status;
  DRLShmooTestMode test_mode;/*DRLShmooTestNormal,
                               DRLShmooTestERCT or
                               DRLShmooTestFFCI; see
                                 dcl_drl.h */
  union { long erct; DRLShmooFFCIResult *ffci; } result;
} DRLShmooCell;
```
