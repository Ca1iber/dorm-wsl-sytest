# Developing a data retrieval function

#### Subtopics

- [Recommended implementation structure](<02.10.01.05.01_Recommended_implementation_structure.md>)
- [Example of yield monitor](<02.10.01.05.02_Example_of_yield_monitor.md>)
- [Installing and starting a user-written data retrieval process](<02.10.01.05.03_Installing_and_starting_a_user-written_data_retrieval_process.md>)

This chapter explains the principles of developing your own data retrieval function using the event data logging capabilities.

First, a description of how to implement a data retrieval function is given, followed by an example (a simple yield monitor).

The various ways of starting a data retrieval function (whether implemented as a stand-alone program or as a function or program command set) are then described.

Finally, the characteristics of each of these ways to start a data retrieval function are discussed.
