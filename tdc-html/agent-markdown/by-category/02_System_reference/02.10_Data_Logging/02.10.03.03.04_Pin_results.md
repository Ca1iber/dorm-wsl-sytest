# Pin results

Pin data is logged to STDF depending on the status of the PerPinOutputOnPass and PerPinOutputOnFail data log flags. The SmarTest Data Formatter checks the per-pin flags and populates the pin data in the MPR or FTR record fields according to the pin data log flags:

 |

- PerPinOutputOnPass=true
 |

Pin data for the test suite is logged if the test passes.

 |
 |

- PerPinOutputOnPass=false
 |

Pin data for the test suite is not logged if the test passes.

 |
 |

- PerPinOutputOnFail=true
 |

Pin data for the test suite is logged if the test fails.

 |
 |

- PerPinOutputOnFail=false
 |

Pin data for the test suite is not logged if the test fails.

   |
