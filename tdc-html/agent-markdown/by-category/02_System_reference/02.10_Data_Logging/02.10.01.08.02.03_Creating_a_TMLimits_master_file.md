# Creating a TMLimits master file

TMLimits master files can reference several individual TMLimits CSV files.

## About this task

This allows several teams or individuals to work on their own test tables without requiring extensive coordination or inflexible merging procedures.

Create a test table master file whenever you want to use multiple test tables for the same test flow, for example, to allow different teams to work on their own test tables.

## Before you begin

Make sure that at least one of the individual TMLimits CSV files that you want to reference in the master file already exists. (The file does not need to have its final form; you can still modify it after using it to create the master file.)

## Procedure

-  In the Test Program Explorer, right-click the <Test Table> entry and choose Load from the shortcut menu.

An Open dialog is displayed.

-  Choose the TMLimits test table that you want to to reference from the master file and click OK.

The name of the test table appears in the Test Program Explorer.

-  Right-click the test table in the Test Program Explorer and choose Save As from the shortcut menu.

A Save dialog is displayed.

-  Save the file with a .mfh filename extension.

This extension marks the file as a master file and causes the software to perform the necessary setup steps. An appropriate message is displayed in the console.

The TMLimits file that you have opened in step 3 is automatically added to the master file.

To add additional TMLimits CSV files to the master file, manually add an entry of the form `testerfile :`<filename> to the master file.

-  Save the master file.

## Results

The master file can now be used in place of the individual CSV files. You can specify it as the TMLimits file of a testflow (as described in [Using TMLimits test tables](<02.10.01.08.02.05_Using_TMLimits_test_tables.md>)).

## Example

The master file shown below has been created from the Limits.csv test table file. The test table file Limits2.csv and Limits3.csv were added.

```
hp93000,testtable_master_file,0.1
#this is a comment

testerfile : Limits.csv
testerfile : Limits2.csv
testerfile : Limits3.csv
```
