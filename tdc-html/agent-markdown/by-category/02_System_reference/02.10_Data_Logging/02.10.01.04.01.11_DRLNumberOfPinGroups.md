# DRLNumberOfPinGroups

unsigned DRLNumberOfPinGroups (void)

This function is used to find out the number of pin groups in the current pin configuration.

## Return Value

The function returns the number of pin groups in the current pin configuration.

## Functional changes

- Introduced before SmarTest 6.3.2
