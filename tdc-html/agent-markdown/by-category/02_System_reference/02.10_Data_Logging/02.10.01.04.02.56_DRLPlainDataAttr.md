# DRLPlainDataAttr

A variable of this type holds any data stored in one string, for example, the output data for logging a user procedure.

The member data holds the string and the member size holds the number of characters in that string.

```
typedef unsigned char _DRLPlainDataAttr;
     int size;
     char *data;
} DRLPlainDataAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
