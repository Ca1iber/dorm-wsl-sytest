# DRLShmooTestCellData

A variable of this type holds the result data of a specific cell on a shmoo plot.

- coordinate[ ]: An array listing the coordinates of a specific cell on a shmoo plot. The maximum demension size of this array is ten.

For example, (x), (x, y), (x, y, z).

- numberOfValues: Th number of values logged in this cell.
- cellValue[ ]: An array listing the results contained in this cell.

## Syntax

```
typedef struct _DRLShmooTestCellData
{
  unsigned int coordinates[MAX_NUM_AXIS];
  unsigned int numberOfValues;
  double* cellValue;
} *DRLShmooTestCellData;
```
