# PrintToDatalogEventType

An event of this type is logged when a ‘Print to Datalog' testflow element is executed for a site.

## Attributes

- [SiteIdAttrType](<02.10.01.06.05.49_SiteIdAttrType.md>)

Holds the ID of the site for which the ‘Print to Datalog' testflow element was executed. If the execution was not site specific, this attribute is not logged with the event.

- [ExpressionAttrType](<02.10.01.06.05.12_ExpressionAttrType.md>)

Holds the expression to be printed to the data log. If the expression is not a string but a numeric value, the attribute also holds the expression's value.

- [TimeStampAttrType](<02.10.01.06.05.65_TimeStampAttrType.md>)

Holds the time when the 'Print to Datalog' element was executed.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.3.5.3: New attribute TimeStampAttrType
