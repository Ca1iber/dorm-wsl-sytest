# Part Results Record (PRR)

The Part Results Record contains the result information related to each part tested by the test program. The PIR and PRR bracket all the stored information pertaining to one tested part.

The Part Results Record can be located anywhere in the data stream before the corresponding PIR and MRR. This record is sent after the testing of each part is complete.

HEAD_NUM

- Test head number

- One-byte unsigned integer
- Hard-coded value of 1

If the ATR and GDR indicate that there are more than 255 sites in the test, HEAD_NUM is the number of the site divided by 256. For example, in a record for site 384, HEAD_NUM would be 2.

SITE_NUM

- Test site number
 |

- One-byte unsigned integer

If the ATR and GDR indicate that there are more than 255 sites in the test, SITE_NUM is the number of the site modulo 256. For example, in a record for site 600, SITE_NUM would be 88.

PART_ID

 |

- Part identification
 |

- Variable length character string
- First byte is unsigned count of bytes to follow
- Maximum 255 bytes
- Length byte = 0 if missing or invalid data
 |

- See [The PART_ID field in the PRR](<02.10.03.03.08_The_PART_ID_field_in_the_PRR.md>) for more information.

 |

PART_TXT

 |

- Part description text
 |

- Variable length character string
- First byte is unsigned count of bytes to follow
- Maximum 255 bytes
- Length byte = 0 if missing or invalid data
 |

- Can be populated from the application model variable PART_TXT. Must use the syntax SITEN_PART_TXT, where N is the site number. Must be populated before the device is tested.
 |
 |

PART_FIX

 |

- Part repair information
 |

- Variable-length bit encoded field.
- It may be used for bit-encoded, integer, floating point, or character information. The first byte must contain the number of bytes to follow.
 |

- Can be populated from the application model variable PART_FIX. Must use the syntax SITEN_PART_FIX, where N is the site number. Must be populated before the device is tested.
 |

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.2.2: Added HEAD_NUM and SITE_NUM conventions for tests on more than 255 sites.
- SmarTest 7.2.2: Added data source for PART_FIX field.
