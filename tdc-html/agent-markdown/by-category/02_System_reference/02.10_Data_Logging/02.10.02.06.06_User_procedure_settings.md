# User procedure settings

The Output User Procedure checkbox enables or disables inclusion of user procedure data in the output of the Event Formatter.

  ![Where to Enable User Procedure Output](<../../../../raw/34904.png>)

If the option is enabled, the output will be included like shown below:

```
========== Started Userprocedure up_test1 ======================
---------- Userprocedure Output: -------------------------------

========== Ended Userprocedure up_test1 ========================
```

The actual output of the user procedure is included below the `Userprocedure Output:` separator. For information on user procedure output, see [UserProcedureEventType](<02.10.01.06.03.21_UserProcedureEventType.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
