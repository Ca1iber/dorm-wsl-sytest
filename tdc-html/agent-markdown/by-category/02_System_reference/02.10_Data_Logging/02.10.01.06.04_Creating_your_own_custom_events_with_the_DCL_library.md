# Creating your own custom events with the DCL library

Using the Data Collection Library (DCL), you can create custom events that can easily be inserted into the event data log stream.

## About this task

The Event Data Logger consists of two main libraries, the Data Collection Library (DCL) and the Data Retrieval Library (DRL). The DCL Library provides an API to create all events logged to the event data log stream.

Create a custom event when you want to log data that none of the predefined events is suitable for.

The procedure below creates a custom assignment event, but other events can be created in the same manner.

## Before you begin

Start SmarTest.

## Procedure

-  Create a makefile using the install_cs script: /opt/hp93000/soc/prod_env/lbin/install_cs -t PROGRAM

The script creates a file named pg_templ.c.

-  Open pg_templ.c and insert this code:

```
include <stdio.h>
include <string.h>

include "tpi_c.h"
include "adiUserI.h"
include "ci_types.h"
include "libcicpi.h"

/* needed for the Data Collector Library */
include "dcl.h"

int main(int argc, char* argv[])
{

  DCLAttribute attribute_list[1];
  int attribute_list_count = 0;
  DCLEvent event;
  char name[256];
  char value[256];

  /* There are no definitions of the function _main() in Linux  */
  if !defined(OS_LINUX) && !defined(__cplusplus)
  _main();              /* Mandatory statement in a program source file */
  endif

  HpInit();

  strcpy(name, "MyAssigmentName");
  strcpy(value, "MyAssigmentValue");

  attribute_list[attribute_list_count++] = DCLMakeNamedStringValueAttr(name,value);

  event = DCLMakeEvent(AssignmentEventType,attribute_list_count,attribute_list);

  mc_connect();
  DCLStart(0);

  DCLLogEvent(event);
  DCLFreeEvent(event);  /* Free up the memory used for the event. This is important
                           when many events are logged, for example, in a loop.

  DCLStop();

  exit(CI_CALL_PASS);   /* Program completed without error */

  HpTerm();
}
```

-  Include a reference to the DCL library in the makefile:

```
shared libraries to be linked to target
SH_LIBS=-L $(HP83000_ROOT)/com/sh_lib -L $(HP83000_ROOT)/prod_com/sh_lib -Wl,\
-rpath,:$(HP83000_ROOT)/prod_com/sh_lib:$(HP83000_ROOT)/com/sh_lib:$(HP83000_ROOT)/pws/sh_lib \
-lcicpi -lmc_macc -ldcl -ldrl
```

-  Save the makefile and run `make`.
-  To test the program, activate event data logging as described in [Activating event data logging](<02.10.01.01.04_Activating_event_data_logging.md>).
-  Activate the Event Formatter as described in [Activating the Event Formatter](<02.10.02.01_Activating_the_Event_Formatter.md>).
-  In the Console window, click the Clear Console button.
-  Run the demonstration program compiled above.
-  Inspect the resulting data log with the DRLDump utility (located in /opt/hp93000/soc/.service/) by entering DRLDump -system -print.

## Results

DRLDump shows the data log created by your sample program, containing the custom event.

## What to do next

You can create and use custom events in your test methods in a similar way.
