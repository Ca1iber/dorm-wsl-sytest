# DRLOutputOnFailAttr

A variable of this type holds the enabled or disabled state of the "Output On Fail" test suite flag as a NULL terminated string.

```
typedef char *DRLOutputOnFail;
```

## Functional changes

- Introduced before SmarTest 6.3.2
