# Test Number Generator and TMLimits

#### Subtopics

- [Generating test numbers from the SmarTest GUI](<02.10.01.08.01.01_Generating_test_numbers_from_the_SmarTest_GUI.md>)
- [Generating test numbers from a test method](<02.10.01.08.01.02_Generating_test_numbers_from_a_test_method.md>)
- [Using TMLimits to manage test numbers](<02.10.01.08.01.03_Using_TMLimits_to_manage_test_numbers.md>)

The Test Number Generator is a software module that can be used either from the SmarTest GUI or by calling its APIs from a user-written test method to consistently number tests for data logging and evaluation purposes.

The test tables generated by it are stored in TMLimits files. Test tables can contain arbitrary information in addition to test numbers and limits.

For details, see:

- [Generating test numbers from the SmarTest GUI](<02.10.01.08.01.01_Generating_test_numbers_from_the_SmarTest_GUI.md>)
- [Generating test numbers from a test method](<02.10.01.08.01.02_Generating_test_numbers_from_a_test_method.md>). Three classes are provided for this purpose:

  - [TestNumGen](<../02.07_Test_Method_Reference/02.07.04.01.243_TestNumGen.md>)
  - [TestTable](<../02.07_Test_Method_Reference/02.07.04.01.245_TestTable.md>)
  - [TMLimits](<../02.07_Test_Method_Reference/02.07.04.01.250_TMLimits.md>)
