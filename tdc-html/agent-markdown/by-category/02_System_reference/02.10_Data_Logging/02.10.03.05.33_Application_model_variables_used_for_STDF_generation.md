# Application model variables used for STDF generation

Several STDF record fields contain data from special application model variables.

If such variables are defined in the application model, their values are read by the STDF generation tool and assigned to the corresponding STDF record field, as shown in the table below.

The full name of a variable in the application model is <record_type>`_`<STDF_field>`_SRC`. For example, the name of the variable described in the first line of the table below would be MIR_STAT_NUM_SRC.
