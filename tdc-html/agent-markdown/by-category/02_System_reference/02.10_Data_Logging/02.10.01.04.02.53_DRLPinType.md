# DRLPinType

A variable of this type specifies the type of a single pin, that is, whether the pin is an output, input, DPS, DC, analog, or virtual pin. Any member of the structure which is set to 1 indicates the according type of pin. For example, for a digital I/O pin, the members input and output are set to 1 while the other members are set to 0.

```
typedef struct {
  unsigned
    input:1,
    output:1,
    dps:1,
    dc:1,
    analog:1;
    virt:1;
  } DRLPinType;
```

## Example

```
void example (void)
{
  DRLPinType *type;
  DRLPinIndex index=1;
if (DRLPinIndexToName(index,type) = NULL)
    {
       /* error handler  */
    };
/* type now holds the information on the pin type. */
if (type->input)  {/* pin 1 is an input pin*/};
if (type->output) {/* pin 1 is an output pin*/};
if (type->dps)    {/* pin 1 is a DPS pin*/};
if (type->dc)     {/* pin 1 is a DC pin*/};
if (type->analog) {/* pin 1 is an analog pin*/};
if (type->virt)   {/* pin 1 is a virtual pin*/};
}
```
