# DRLRARepairResult

A variable of this type identifies a column or row that has been used for repairs or is part of a repair solution proposed by the [Redundancy analysis](<../02.12_Memory_Test_Plus_7.10.2/02.12.02.07.03_Redundancy_analysis.md>) of the DUT.

## Syntax

The struct contains these members:

- element: The identifier of the row or column in the segment.
- segment: The identifier of the segment to which the element belongs.
- spare: The spare resource used to repair the element.

```
typedef struct _DRLRARepairResult {
  unsigned int element;
  unsigned int segment;
  unsigned int spare;
} *DRLRARepairResult;
```
