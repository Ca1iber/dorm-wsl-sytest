# DRLValueResultAttr

A variable of this type is a pointer to a structure named _DRLValueResultAttr. In this structure any result of a test function or other value relevant to the test function is stored, for example, the DPS voltage for an IDDQ test function.

The member value holds the actual value.

The member unit holds the unit of the value as a NULL terminated string, and the member description can hold any further information as a NULL terminated string.

 Note You can specify any derived unit (such as ns or mA) for EDL data logging. However, when data logs are converted to STDF, all units are converted to their SI equivalents (ns to s, mA to A) and the corresponding values are converted accordingly. (For example, 435 mA is converted to 0.435 A.)

```
typedef const struct _DRLValueResultAttr {
  double value;
  char *unit;
  char *description;
} *DRLValueResultAttr;
```
