# DRLCycleNumber

A variable of this type holds the number of a cycle. Such variables are members of [DRLExpressionAttr](<02.10.01.04.02.20_DRLExpressionAttr.md>).

```
typedef double DRLCycleNumber;
```

## Functional changes

- Introduced before SmarTest 6.3.2
