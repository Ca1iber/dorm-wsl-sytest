# DRLPinIndex

A variable of this type holds a pin index. See [DRLPinIndexToName](<02.10.01.04.01.18_DRLPinIndexToName.md>) for further information on pin DC/DC power units and on mapping pin DC/DC power units to pin names.

```
typedef unsigned short DRLPinIndex;
```

## Functional changes

- Introduced before SmarTest 6.3.2
