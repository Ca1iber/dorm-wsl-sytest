# TestProgramStartEventType

An event of this type is logged when the test program is started.

## Attributes

- [WorkorderNameAttrType](<02.10.01.06.05.73_WorkorderNameAttrType.md>)

Holds the path and file name of the work order that the executed test program belongs to.

- [HostNameAttrType](<02.10.01.06.05.16_HostNameAttrType.md>)

Holds the host name of the system controller on which SmarTest is running.

- [UIDAttrType](<02.10.01.06.05.67_UIDAttrType.md>)

Holds the login name of the user who started the test program or work order, respectively.

- [TestProgramNameAttrType](<02.10.01.06.05.62_TestProgramNameAttrType.md>)

Holds the file name of the started test program which is local to the current device directory.

- [DeviceDirectoryAttrType](<02.10.01.06.05.08_DeviceDirectoryAttrType.md>)

Holds the path of the device directory for the device tested by the test program

- [BinListAttrType](<02.10.01.06.05.04_BinListAttrType.md>)

Holds a list of all bins and their descriptions.

- [SWVersionAttrType](<02.10.01.06.05.52_SWVersionAttrType.md>)

Contains a string representing the build version and build date of the software.

- [TesterProductAttrType](<02.10.01.06.05.56_TesterProductAttrType.md>)

Contains a string representing the tester type description. It has a constant value of "93000".

- [TestHeadNumberAttrType](<02.10.01.06.05.59_TestHeadNumberAttrType.md>)

Contains a string representing the test head number. It has a constant value of "1".

- [LotTypeAttrType](<02.10.01.06.05.21_LotTypeAttrType.md>)

Contains one of two strings: "PACKAGE Test" or "WAFER Test"..

- [TimeStampAttrType](<02.10.01.06.05.65_TimeStampAttrType.md>)

Holds the time when the test program was started. For example, you can use this time (together with the time which is logged with the event of the [TestProgramEndEventType](<02.10.01.06.03.17_TestProgramEndEventType.md>) type) to calculate the execution time of the test program.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.3.5.3: Moved TimeStampAttrType to end of attribute list
