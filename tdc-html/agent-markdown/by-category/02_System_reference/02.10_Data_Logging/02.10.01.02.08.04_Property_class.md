# Property class

This class provides access the value of a data logging property in a test method considering the active profile and the current system context.

This class is defined in the header file /opt/hp93000/soc/prod_com/include/Property.hpp.

## Constructor

```
Property::Property()
```

Default constructor for the Property class. Initializes all member variables.

```
Property::Property(char * propNameIn)
```

This constructor is used to immediately specify the property name.

Parameter
 |

propNameIn

 |

The name of the new property

 |

## Member functions

### getPropName

```
char* Property::getPropName()[inline]
```

Returns the property name defined by this instance.

Return code: pointer to the property name.

### isDefined

bool Property::isDefined()

Checks if the stored property is defined in the active profile for the active context.

Return code: true if the property is defined; false otherwise.

Parameters: none

### isDefined

```
bool Property::isDefined(char * name)[static]
```

Checks if the passed property is defined in the active profile for the active context.

Return code: true if the property is defined; false otherwise.

Parameter
 |

name

 |

The name of the property to check

 |

### Overridden bool cast operator

```
Property::operator bool()[inline]
```

Overrides the Boolean cast operator by calling value() and returning the result as a Boolean.

Return code: true if the value is non-zero; false otherwise.

Parameters: none

### Overridden int cast operator

```
Property::operator int()[inline]
```

Overrides the integer cast operator by calling value() and returning the result as an integer.

Return code: the value of the property.

Parameters: none

### setPropName

```
void Property::setPropName(char * name)
```

Sets the internal value of the property name to the value passed in as an argument. A copy of the string is made.

Return code: void

Parameters: none

### value

`int Property::value()`

Determines the value of the property indicated by the member variable propName by querying the value within the active profile.

Return code: The value of the property specified by member propName within the active profile; 0 if the value is unspecified.

Parameters: none

### value

```
int Property::value(char * name)[static]
```

Determines the value of the property indicated by the passed parameter name by querying the value within the active profile.

Return code: The value of the property specified by name within the active profile; 0 if the value is unspecified.

Parameter
 |

name

 |

the property name to query

 |
