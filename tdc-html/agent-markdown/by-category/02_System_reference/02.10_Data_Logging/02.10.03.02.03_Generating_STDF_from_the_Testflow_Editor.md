# Generating STDF from the Testflow Editor

If you are running a test from the Testflow Editor and you want to generate STDF, be certain that the following conditions are met:

- The SmarTest Data Formatter is enabled (global.conf configuration option formatter.stdf.generateStdf=true)
- All data log flags are set to produce event data log output
- g`enerateStdfFromTestflowEditor = true`(in the configuration file)

For related information, see [Configuring the STDF file locations](<02.10.03.04.01_Configuring_the_STDF_file_locations.md>) and [Setting data log flags](<02.10.03.02.04_Data_log_flags_for_STDF.md>).
