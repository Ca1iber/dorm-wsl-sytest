# DRLPinRangeResultAttr

A variable of this type holds a pointer to a structure named _DRLPinRangeResultAttr. In this structure a list of pin result ranges (see [DRLPinRangeResult](<02.10.01.04.02.49_DRLPinRangeResult.md>)) is stored.

The member unit holds the unit of the measured pin values as a NULL terminated string.

 Note You can specify any derived unit (such as ns or mA) for EDL data logging. However, when data logs are converted to STDF, all units are converted to their SI equivalents (ns to s, mA to A) and the corresponding values are converted accordingly. (For example, 435 mA is converted to 0.435 A.)

The member size holds the real number of elements in the array pins, that is, the number of pin result ranges stored in the list.

The member description can hold any further information as a NULL terminated string.

```
typedef const struct _DRLPinRangeResultAttr{
    char *unit;
    char *description;
    unsigned size;
    DRLPinRangeResult pins[1];
   } *DRLPinRangeResultAttr;
```
