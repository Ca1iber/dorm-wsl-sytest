# DRLTestIdAttr

A variable of this type holds the ID of a test. The test ID is a number which is increased after the termination of a test suite, and once for each pin during the execution of a per-pin measurement.

```
typedef int DRLTestIdAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
