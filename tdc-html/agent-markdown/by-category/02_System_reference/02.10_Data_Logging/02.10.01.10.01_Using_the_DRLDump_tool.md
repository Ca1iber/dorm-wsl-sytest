# Using the DRLDump tool

#### Subtopics

- [Examples](<02.10.01.10.01.01_Examples.md>)
- [Sample output](<02.10.01.10.01.02_Sample_output.md>)

The DRLDump executable is located in /opt/hp93000/soc/.service/bin/.

You can start the tool from a terminal using the following syntax:

```
DRLDump [-system][trunc][-print][-sync][<data log file>]
```

The command line options have these effects:

 |

Option

 |

Description

 |
 |

<data log file>

 |

The path and file name of the saved data log stream that is to be processed by DRLDump.

 |
 |

-print

 |

Enables output of the contents of the data log attributes.

This means that you also get result data in the output. By default, DRLDump only prints the event types and the attribute types that are logged with each event. This only gives you an overview of the execution flow of the production test.

The [Sample output](<02.10.01.10.01.02_Sample_output.md>) shows output with and without attribute contents.

 |
 |

-sync

 |

In conjunction with -system, DRLDump synchronizes with the data log stream. That is, only events that are written to the stream after DRLDump was started will be displayed.

Without -sync, all events from the beginning of the data log stream are displayed.

 |
 |

-system

 |

Executes DRLDump on the system data log stream.

All event records currently stored in the stream are processed. Then DRLDump waits for incoming event records and processes them immediately.

 |
 |

-trunc

 |

In conjunction with -system, DRLDump first deletes the contents of the system data log stream without processing them, and then waits for incoming event records and processes them immediately.

 |
