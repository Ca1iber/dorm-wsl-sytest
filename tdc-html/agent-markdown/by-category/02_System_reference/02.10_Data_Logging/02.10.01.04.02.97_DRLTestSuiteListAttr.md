# DRLTestSuiteListAttr

An attribute of this type contains a list of the test suites in the test flow as a [DRLTestSuiteAttr](<02.10.01.04.02.96_DRLTestSuiteAttr.md>) array.

```
typedef struct _DRLTestsuiteListAttr {
        int size;                          /* number of test suites in the      */
                                           /* testsuite_list array              */
        DRLTestsuiteAttr testsuite_list[0];/* placeholder for testsuite_list[0] */
                                           /* to testsuite_list[size-1]         */
} *DRLTestsuiteListAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
