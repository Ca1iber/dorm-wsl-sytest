# TestFlowStartEventType

An event of this type is logged when a testflow is started.

## Attributes

- [DeviceIdAttrType](<02.10.01.06.05.09_DeviceIdAttrType.md>)

Holds the ID of the device to be tested. This ID also contains information about how the device stream is organized (wafer or package) and, in the case of a wafer test, holds the die position.

- [TagAttrType](<02.10.01.06.05.53_TagAttrType.md>)

Holds the information about the tag information and its value.

- [TimeStampAttrType](<02.10.01.06.05.65_TimeStampAttrType.md>)

Holds the time when the execution of the testflow was started.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.3.5.3: Moved TimeStampAttrType to end of attribute list
