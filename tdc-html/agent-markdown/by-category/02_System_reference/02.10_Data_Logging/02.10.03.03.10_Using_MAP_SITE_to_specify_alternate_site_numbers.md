# Using MAP_SITE to specify alternate site numbers

The MAP_SITE application model variable can be used to specify a site number different from the SmarTest-assigned site number. For example, if you want the SmarTest site 2 to appear as site 3 in STDF, define this in the application model as follows:

```
MAP_SITE = CONST_INPUT(2:3);
```

The MAP_SITE assignments should appear early in the "lot" level in the application model. The SmarTest site number and alternate site number should be separated by a colon.

Use this functionality only if absolutely necessary for your application. It is best to use the SmarTest assigned site numbers. This functionality impacts all STDF records that report a site number.

 Note If MAP_SITE is used, the baseSiteIndex configuration setting is ignored.
