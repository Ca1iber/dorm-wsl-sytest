# DRLPinPFResult

A variable of this type holds the pass/fail result data for a single pin.

The member pin (see [DRLPinIndex](<02.10.01.04.02.45_DRLPinIndex.md>)) specifies the pin.

The member failure_code can hold the following values:

Failure code values
 |

Value

 |

Description

 |
 |

-2= DRLFailureCode_Fatal

 |

test method execution incomplete or test method crashed

 |
 |

-1= DRLFailureCode_NA

 |

no pass/fail result determined

 |
 |

0 = DRLFailureCode_Pass

 |

passed

 |
 |

1 = DRLFailureCode_Fail

 |

failed

 |
 |

2 = DRLFailureCode_Error

 |

error

 |
 |

3 = DRLFailureCode_Bypass

 |

bypassed (this applies only to test suites)

 |

```
typedef struct {
  DRLPinName pin;
  unsigned char failure_code; /* see enum DRLFailureCode
                                in dcl_drl.h */
 } DRLPinPFResult;
```

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.4.1: Added error code -2.
