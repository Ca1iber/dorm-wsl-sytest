# Setting the Multishot Per-Edge Detailed result mode

To enable the Multishot Per-Edge Detailed result mode, the H/L/I/U (multiple execution)flag must be set (H/L/I/U - High/Low/Intermediate/Unstable) (see [Setting the FRG (fine result granularity) flag](<02.10.02.05.01_Setting_the_FRG__fine_result_granularity__flag.md>)).

If the H/L/I/U (multiple execution)flag is not set, the Single-Shot Per-Edge P/F result mode is used instead. This is default in Pin Scale test systems. In single density test systems, the Single-Shot Per-Edge P/F result mode is not available. Single-density systems therefore default to the Multishot Per-Edge Detailed result mode.

 Note This option differs for Single-density and Pin Scale test systems. In single-density test systems the H/L/I/U (multiple execution)flag is set and cannot be altered. In Pin Scale systems the sameflag is not set by default but can be activated.

## Functional changes

- Introduced before SmarTest 6.3.2
