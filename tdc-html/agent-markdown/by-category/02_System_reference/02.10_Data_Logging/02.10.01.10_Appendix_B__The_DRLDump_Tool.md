# Appendix B: The DRLDump Tool

#### Subtopics

- [Using the DRLDump tool](<02.10.01.10.01_Using_the_DRLDump_tool.md>)
- [DRLDump as a template for user-written data retrieval tools](<02.10.01.10.02_DRLDump_as_a_template_for_user-written_data_retrieval_tools.md>)

This appendix describes the DRLDump tool and how to use it.

The DRLDump tool is a a simple tool to read the contents of a binary data log stream and print it in a readable format. As such, the DRLDump tool works like the Event Formatter, but with the following differences:

- The output is printed to stdout.
- The DRLDump tool can be used to process saved data log streams even when SmarTest is not running.
- The DRLDump tool performs very simple output formatting.

You can use this tool to get a quick overview of the contents of the system data log stream or of a saved data log stream. The tool may also be used to monitor the system data log stream and immediately print any new event that is written to the stream, plus its attributes if desired.

- Introduced before SmarTest 6.3.2
