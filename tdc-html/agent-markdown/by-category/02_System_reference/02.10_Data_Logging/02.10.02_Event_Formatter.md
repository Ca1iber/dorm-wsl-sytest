The Event Formatter is a report generating tool that is used for interactive debugging. With its own dialog window for customizing the format and scope of the data output, the Event Formatter is a powerful data logging tool.

This chapter describes:

- How to activate the Event Formatter
- How to use the new menus of the report window that are added by the Event Formatter
- How to use the Report Dialog window to control the output of the Event Formatter
- How result data is presented in that output
- How to customize the Event Formatter to your needs

The final sections of this chapter provide background information on how the Event Formatter works in principle, and highlight important considerations when writing your own event-based report formatter.
