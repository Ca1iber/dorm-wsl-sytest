# DRLShmooSpecVariableType

A variable of this type holds a spec variable and the related pins which are varied for an axis on a shmoo plot.

- spec: The spec variable to be varied for an axis.
- setupPins: A list of pins whose spec variable are varied for an axis. The default is "@" (all pins).

## Syntax

```
typedef struct _DRLShmooSpecVariableType
{
  const char* spec;
  const char* setupPins;
} *DRLShmooSpecVariableType ;
```
