# DRLOutputOnPassAttr

A variable of this type holds the enabled or disabled state of the "Output On Pass" test suite flag as a NULL terminated string.

```
typedef char *DRLOutputOnPass;
```

## Functional changes

- Introduced before SmarTest 6.3.2
