# Stopping the formatter

The SmarTest Data Formatter will automatically shut-down upon exiting the SmarTest software. If SmarTest is terminated while the STDF tool is still processing the EDL stream, the tool will finish the STDF output prior to stopping.

If you are changing devices, SmarTest will notify the dataformatter and the tool will finish the STDF output prior to changing devices.

If SmarTest terminates unexpectedly and generates a fatal error, a warning is displayed showing the impending shutdown. Please note that the kill_smarTest script does not generate a fatal error message.
