# Test method API for logging GDRs and DTRs

A new class has been added to the test method library, named GENERIC_DATA_EVENT. It allows logging of GDR and DTR within test methods.

GENERIC_DATA_EVENT - (gde)

You can use the system-prepared class object "gde" when using member functions. You can also create a new class object. If a function sets up a parameter, the parameter setting is kept until you reset it or return it to a default setting.

Important points

If a function sets up a parameter, the parameter setting is kept until you reset it or return it to a default setting.

Use the FLUSH API to transfer the data from the buffer to the data log stream.

Example 1 (shows the use of FLUSH)

```
{
  GENERIC_DATA_EVENT gde;
  char sdata[100];
  int idata;
  ...
  gde.add(sdata, 100);
  gde.add(idata);
  ...
  gde.flush();
}
```

Example 2 (shows that GENERIC_DATA_EVENT can be copied using the copy constructor or the copy operator)

```
{
  GENERIC_DATA_EVENT gde, gde2;
  ...
  gde.add(sdata, 100);
  gde.add(idata);
  ...
  gde2 = gde;
  gde2.flush();
}
```

Example 3 (shows that PUT_DATALOG accepts GENERIC_DATA_EVENT as a parameter)

```
{
  GENERIC_DATA_EVENT gde;
  char sdata[100];
  int idata;
  ...
  gde.add(sdata, 100);
  gde.add(idata);
  ...
  PUT_DATALOG(gde);
}
```
