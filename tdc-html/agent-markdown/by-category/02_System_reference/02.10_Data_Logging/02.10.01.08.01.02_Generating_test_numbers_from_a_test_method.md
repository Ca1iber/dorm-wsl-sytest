# Generating test numbers from a test method

The Test Number Generator can be controlled from test methods via public APIs, allowing test numbers to be generated automatically.

## About this task

Two classes with accompanying methods are provided for this purpose:

- [TestTable](<../02.07_Test_Method_Reference/02.07.04.01.245_TestTable.md>)
- [TestNumGen](<../02.07_Test_Method_Reference/02.07.04.01.243_TestNumGen.md>)

## Before you begin

Add all required tests and loops to the test program.

If you want to use the SmarTest implementation of TMLimits, declare the V93kLimits namespace in your test method:

```
using namespace V93kLimits;
```

## Procedure

-  In the test program, create an object of the [TestTable](<../02.07_Test_Method_Reference/02.07.04.01.245_TestTable.md>) type.
-  In the test program, create an object of the [TestNumGen](<../02.07_Test_Method_Reference/02.07.04.01.243_TestNumGen.md>) type.
-  Specify the test number generation settings of the TestTable object, using these functions:

  - setStartNum()
  - setNumIncrement()
  - setSquentialMode()
  - setDuplicateNumsInLoop()
  - setTestFlowLoopIncrement()
  - setTestMethodLoopIncrement()

When setting test numbers, consider the setting of the [test_number_inc](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.01_Alphabetical_list_of_flags.md#_342556__row_test_number_inc>) testflow flag: SmarTest automatically increases the test number by this value when the test is executed in a loop (except for the execution in the first loop iteration). This applies to loops in the test method as well as to loops in the testflow and to all methods of assigning test numbers (test suite properties, test method code, test tables).

-  Call the TestNumGen::generate() function.

Pass the TestTable object as its first parameter and specify the column in the table into which the numbers are to be entered. If you want to generate numbers for only part of the table, specify the desired range with the optional two additional parameters.

## Results

The TestTable object contains the test numbers in the specified column.

## What to do next

You can access the test numbers from your program using the getValue() function.

You can also export the entire TestTable object to a CSV file for use in a different tool using the writeCsvFile() function write the modified test numbers back to the testflow using writeTestflow().
