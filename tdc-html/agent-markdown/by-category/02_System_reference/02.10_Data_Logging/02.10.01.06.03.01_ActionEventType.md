# ActionEventType

An event of this type is logged to initiate an action of a data log formatter. The action and the information that must be provided to initiate it depend on the data formatter.

One application of this event type is for storing test method controlled time stamps using the START_TIMER, STOP_TIMER, and LOG_TIMER functions. (See [Time Stamps](<02.10.01.03_Time_Stamps.md>) for details.)

## Attributes

- [TagAttrType](<02.10.01.06.05.53_TagAttrType.md>)

Holds the name of a tag and its value. This attribute can appear multiple times.

- [CommandAttrType](<02.10.01.06.05.06_CommandAttrType.md>)

The details of a command for the data formatter or post-processing tool. This is an optional attribute.

- [TimeStampAttrType](<02.10.01.06.05.65_TimeStampAttrType.md>)

Holds the time stamp when the event was logged.

## Functional changes

- Introduced in SmarTest 6.5.3
