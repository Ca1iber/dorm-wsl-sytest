# DRLPinIndexToChannel

This function allows mapping of pin DC/DC power units with the site number to channel numbers.

```
unsigned *DRLPinIndexToChannel (DRLPinIndex pin_index,int site)
```

A channel number is a five digit number for digital pins, or a two digit number for DPS pins. Analog pins are not supported by this function.

For further information on the data types involved see [DRLPinIndex](<02.10.01.04.02.45_DRLPinIndex.md>).

## Return Value

The function returns the channel number of the pin with the index pin_index and the site site. The function returns 0, if pin_index belongs to an analog pin, or if pin_index is invalid.
