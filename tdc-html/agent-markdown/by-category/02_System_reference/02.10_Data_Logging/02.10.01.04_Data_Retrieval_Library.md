# Data Retrieval Library

#### Subtopics

- [DRL functions](<02.10.01.04.01_DRL_functions.md>)
- [DRL data types](<02.10.01.04.02_DRL_data_types.md>)

The Data Retrieval Library (DRL) is the application programming interface (API) that provides access to the data log stream where all events of the production test currently being executed are logged (see [Event Data Logging Concepts](<02.10.01.01_Event_Data_Logging_Concepts.md>)). The DRL also provides access to the data held in the individual event records. When you write your own data logging tools, the DRL lets you make full use of all capabilities of event data logging.

Using the DRL frees you from the need to write parsers for data log files.

The functions of the DRL enable you to read event records from the data log stream, to extract data from these records, and to store the extracted data in variables of appropriate data types. These data types, which are also provided by the DRL, are designed to hold all the different data from the various attributes. Thus, you can use them for any further direct processing of logged data you require.

For offline analysis of logged data, you can save the data log stream to a file and later access this file in the same way as the data log stream itself.

The Event Formatter (see [Using the Event Formatter](<02.10.02_Event_Formatter.md>)) is built on top of the DRL.

The header file of the DRL is /opt/hp93000/soc/com/include/drl.h. The same directory contains the header files dcl.h and dcl_drl.h that also are related to the data retrieval library.
