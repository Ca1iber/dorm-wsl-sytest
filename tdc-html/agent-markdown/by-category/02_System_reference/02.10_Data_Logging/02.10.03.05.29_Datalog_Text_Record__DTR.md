# Datalog Text Record (DTR)

The Datalog Text Record contains the ASCII text string logged by the [PUT_DATALOG(const STRING& comment)](<../02.07_Test_Method_Reference/02.07.04.01.174_PUT_DATALOG.md>) API in your test method program. This record occurs only when this API is executed. The information is included in the data log printout. DTRs may be written under the control of a test plan: for example, to highlight unexpected test results. They may also be generated by the tester executive software: for example, to indicate that the data log sampling rate has changed.

The Data Log Text Record can appear anywhere in the data stream after the initial sequence.
