# DRLShmooAxisXYInformation

A variable of this type holds the full definition of a x- or y-axis (master axis) of a sweep test and of the parameters tracked with that axis. Such variables are used in [DRLShmooLegendAttr](<02.10.01.04.02.74_DRLShmooLegendAttr.md>).

The member step_n holds the number of steps for the x- or y-parameter.

axis_n holds the overall number of axes defined in the axis array, that is, the number of tracking axes plus 1 for the master axis.

axis holds the definitions for the x- or y-parameter and for each parameter that is tracked with it (see [DRLShmooAxisInformation](<02.10.01.04.02.66_DRLShmooAxisInformation.md>)).

DRL_SHMOO_MAX_AXIS is 20, that is, the data for up to 19 tracked parameters can be stored.

```
typedef struct
{
  short step_n;
  short axis_n;
  DRLShmooAxisInformation axis[DRL_SHMOO_MAX_AXIS];
} DRLShmooAxisXYInformation;
```
