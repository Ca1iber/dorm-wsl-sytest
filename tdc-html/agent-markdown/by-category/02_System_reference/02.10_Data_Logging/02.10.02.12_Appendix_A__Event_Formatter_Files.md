# Appendix A: Event Formatter Files

#### Subtopics

- [Files explanations](<02.10.02.12.01_Files_explanations.md>)

This appendix contains a short description of the contents and the functions of all files in the /opt/hp93000/soc/formatter/EventFormatter directory.

These files are used to build the Event Formatter, which is provided with SmarTest as the standard event-based report formatter. The Event Formatter fully uses the capabilities of event data logging and writes the retrieved data to the report window. For further information on this formatter see [Using the Event Formatter](<02.10.02_Event_Formatter.md>).

For further information on the contents of the files, see also the comments contained in each file.

## Functional changes

- Introduced before SmarTest 6.3.2
