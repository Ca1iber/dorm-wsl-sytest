# DRLBinListAttr

This list type is used for variables that are needed to generate a complete bin statistic, as opposed to a bin statistic for bins containing some parts.

```
typedef struct _DRLBinListAttr {
        int size;
        DRLBinAttr bin_list;     /* this is an array; size is the   */
                                 /* real size of this array         */
} *DRLBinListAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
