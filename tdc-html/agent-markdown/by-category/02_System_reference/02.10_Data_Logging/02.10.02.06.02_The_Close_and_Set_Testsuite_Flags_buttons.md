# The Close and Set Testsuite Flags buttons

The Close button closes the Report Dialog window. All current settings of this window stay valid.

Set Testsuite Flags sets all test suite flags according to the current settings of the checkboxes in the Report Dialog window. See [Handling of test suite flags by the Event Formatter](<02.10.02.09_Handling_of_test_suite_flags_by_the_Event_Formatter.md>) for detailed information.

## Functional changes

- Introduced before SmarTest 6.3.2
