# GangAttrType

Marks whether an IDDQ measurement was done by summing up (ganging) the currents. The attribute is used only for ganged measurements. If the measurement was not ganged, that is, if individual measurements were performed, the attribute is omitted.

The data type is [DRLGangAttr](<02.10.01.04.02.25_DRLGangAttr.md>).
