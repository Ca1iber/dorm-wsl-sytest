# Wafer Results Record (WRR)

The Wafer Results Record contains the result information related to each wafer tested. The WRR and the WIR bracket all the stored information pertaining to one tested wafer. This record is used only when testing at wafer probe. A WIR/WRR pair will have the same HEAD_NUM and SITE_GRP values.

Location in the file:

The Wafer Results Record can be located anywhere in the data stream after the corresponding WIR. This record is sent after testing each wafer.
