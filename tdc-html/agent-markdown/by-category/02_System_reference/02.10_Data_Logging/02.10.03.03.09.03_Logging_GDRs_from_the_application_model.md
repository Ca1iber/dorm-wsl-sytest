# Logging GDRs from the application model

You can log information to STDF from the application model by using the FormatToGDE method from an EXEC_INP_CALL. FormatToGDE logs data to Generic Data Records (GDRs). See [Logging GDRs from the application model](<02.10.03.05.27.02_Logging_GDRs_from_the_application_model.md>) for more information.
