# Using TMLimits test tables

TMLimits test tables are used to provide test numbers and limits for tests. They can be used from the SmarTest Work Center or from within a test method.

## About this task

Use a TMLimits test table whenever you want to apply test numbers or limits stored in it to a test.

## Before you begin

Make sure that the test table is properly set up and stored in a CSV file in the testtable subdirectory of the device directory.

## Procedures

### Associating a TMLimits test table with a testflow

- Load and display the testflow.
- In the testflow's setups, specify the desired test table in the Test Table field.

You can specify either a CSV file or a [TMLimits test table master file](<02.10.01.08.02.03_Creating_a_TMLimits_master_file.md>).

- Save the testflow.

The TMLimits test table is now associated with the testflow and its content can be used by its test methods.

### Accessing test table values from a test method

To access values from the test table associated with the testflow:

- Make sure that all test methods from which you want to access the values include the namespace definition:

```
using namespace V93kLimits;
```

- Create a [TMLimits](<../02.07_Test_Method_Reference/02.07.04.01.250_TMLimits.md>) class instance and load the CSV file into it using the [load()](<../02.07_Test_Method_Reference/02.07.04.01.250_TMLimits.md#_110432__dle_load>) function.
- Access the values from the test table using the [getLimit()](<../02.07_Test_Method_Reference/02.07.04.01.250_TMLimits.md#_110432__dle_getLimit>) and [getLimitObj()](<../02.07_Test_Method_Reference/02.07.04.01.250_TMLimits.md#_110432__dle_getLimitObj>) member functions of TMLimits.

## Results

You can use the values from the test table in your test method.
