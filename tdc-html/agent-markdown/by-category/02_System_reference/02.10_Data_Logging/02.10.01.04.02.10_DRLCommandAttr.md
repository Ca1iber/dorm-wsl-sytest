# DRLCommandAttr

A variable of this type holds the information for a command that is being sent to a data formatter ot post-processing tool.

```
typedef struct _DRLCommandAttr {
  char* sender;
  char* receiver;
  char* command;
  int parameter_count;
  char* parameters[1];
} *DRLCommandAttr;
```

## Functional changes

- Introduced in SmarTest 6.5.3
