# Using TMLimits to manage test numbers

You can activate and switch between sets of limits and test numbers using the [TMLimits](<../02.07_Test_Method_Reference/02.07.04.01.250_TMLimits.md>) class.

## About this task

The TMLimits class lets you manage test limits and test numbers in a standard CSV file that is easily accessible with a wide range of tools. The file can contain setting for multiple test modes.

## Before you begin

Create a CSV file in the TMLimits format, either from existing testflow settings or from scratch:

- Creating a CSV file from testflow settings is described in [Saving test numbers as TMLimits CSV files](<02.10.01.08.01.01.03_Saving_test_numbers_as_TMLimits_CSV_files.md>).
- When you create a file from scratch, you can use any editor that can save as CSV (for example, OpenOffice.org). Make sure that the file confirms to the structure specified in [Structure of a TMLimits CSV file](<02.10.01.08.01.01.03.01_Structure_of_a_TMLimits_CSV_file.md>).

## Procedures

### Loading the CSV file from the GUI

- In the test program explorer, right-click the Device Information > <Test Table> entry. From the shortcut menu, choose Load.

A standard Open dialog is displayed.

Note that the actual file name is displayed in the test program explorer instead of <Test Table> if you have already loaded a TMLimits CSV file.

- Choose the desired file and click OK.

You can now edit the file in the [Test table editor](<02.10.01.08.01.01.01_Test_table_editor.md>) and save any changes back to disk.

### Loading the CSV file from a test method

Use the TMLimits::load() function:

- Without parameters to use the TMLimit_FileName and TMLimit_TestMode testflow variables to determine the file and test mode
- With the file name to use the default test mode. If you want to specify a file outside the testtable/ directory in the active device directory, enter the path relative to that directory.
- With the file name and test mode to specify the desired test mode

## Results

The TMLimits CSV file is now loaded and affects the execution of the active testflow.

## What to do next

Program the test method to access the data from the CSV file.

When running the test, you may want to vary the data in the CSV file, which you can do by editing it either in SmarTest, with a spreadsheet application such as Open Office Calc, or a simple text editor.
