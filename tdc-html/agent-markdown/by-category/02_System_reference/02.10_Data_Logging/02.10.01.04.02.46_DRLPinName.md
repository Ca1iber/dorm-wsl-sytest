# DRLPinName

A variable of this type holds the name of a pin as a NULL terminated string and the pin index, see [DRLPinIndex](<02.10.01.04.02.45_DRLPinIndex.md>).

```
typedef struct {
  char *name;
  [DRLPinIndex](<02.10.01.04.02.45_DRLPinIndex.md>) index;
} DRLPinName;
```

## Functional changes

- Introduced before SmarTest 6.3.2
