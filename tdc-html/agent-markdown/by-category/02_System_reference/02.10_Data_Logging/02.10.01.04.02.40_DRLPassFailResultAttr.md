# DRLPassFailResultAttr

A variable of this type holds a pass/fail result. For example, it can hold the overall result of a test function or a test suite.

The member failure_code can hold the following values:

Failure code values
 |

Value

 |

Description

 |
 |

-2= DRLFailureCode_Fatal

 |

test method execution incomplete or test method crashed

 |
 |

-1= DRLFailureCode_NA

 |

no pass/fail result determined

 |
 |

0 = DRLFailureCode_Pass

 |

passed

 |
 |

1 = DRLFailureCode_Fail

 |

failed

 |
 |

2 = DRLFailureCode_Error

 |

error

 |
 |

3 = DRLFailureCode_Bypass

 |

bypassed (this applies only to test suites)

 |

The member description holds the additional information that is logged with the result as a NULL terminated string.

```
typedef struct {
    unsigned char failure_code;
    char *description;
 } DRLPassFailResultAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.4.1: Added error code -2.
