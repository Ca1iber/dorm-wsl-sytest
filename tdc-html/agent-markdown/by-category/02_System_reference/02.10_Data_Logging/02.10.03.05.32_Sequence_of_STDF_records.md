# Sequence of STDF records

Every STDF file contains a number of mandatory records. These mandatory records include the three initial records in the sequence as well as the two terminating records.

Initial records:

- One File Attributes Record ([FAR](<02.10.03.05.03_File_Attributes_Record__FAR.md>))
- Optionally, one Audit Trail Record ([ATR](<02.10.03.05.04_Audit_Trail_Record__ATR.md>))

This record is required when more than 255 sites were tested.

- One Version Update Record ([VUR](<02.10.03.05.05_Version_Update_Record__VUR.md>))
- One Master Information Record ([MIR](<02.10.03.05.06_Master_Information_Record__MIR.md>))
- Optionally, one Retest Data Record ([RDR](<02.10.03.05.07_Retest_Data_Record__RDR.md>))
- Optionally, one or more Site Description Records ([SDR](<02.10.03.05.08_Site_Description_Record__SDR.md>))

One SDR can describe up to 128 sites. If more sites were tested, additional SDRs are inserted.

- When more than 255 sites were tested: one Generic Data Record ([GDR](<02.10.03.05.27_Generic_Data_Record__GDR.md>))

Terminating records:

- One or more Part Count Records ([PCR](<02.10.03.05.30_Part_Count_Record__PCR.md>))
- One Master Result Record ([MRR](<02.10.03.05.31_Master_Result_Record__MRR.md>))

Various other records are inserted between the initial and the terminating records, as described below.
