# Scan Structure Record (SSR)

A Scan Structure Record contains the scan structure record normally found in STIL files. It contains an array of indexes to Chain Description Records (CDRs).

A Scan Structure Record can appear after the [Scan Cell Name Record (CNR)](<02.10.03.05.19_Scan_Cell_Name_Record__CNR.md>).
