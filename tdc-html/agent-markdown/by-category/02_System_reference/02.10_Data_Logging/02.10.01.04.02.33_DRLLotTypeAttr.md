# DRLLotTypeAttr

A variable of this type holds one of two strings as a NULL terminated string. The string describes the type of the lot that is being logged and can be either "WAFER" or "PACKAGE".

```
typedef char *DRLLotTypeAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
