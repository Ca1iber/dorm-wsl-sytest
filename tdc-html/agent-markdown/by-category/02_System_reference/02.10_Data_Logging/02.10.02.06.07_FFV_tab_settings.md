# FFV tab settings

#### Subtopics

- [Selecting the output pins for FFV information](<02.10.02.06.07.01_Selecting_the_output_pins_for_FFV_information.md>)
- [FFV output control settings](<02.10.02.06.07.02_FFV_output_control_settings.md>)

The figure below shows the Report Dialog window displaying the FFV (First Failing Vectors) page.

  ![Report Dialog window - FFV page](<../../../../raw/35282.png>)

On this page, you can specify how first failing vector data will be included in the formatter output, when the output has been enabled with the FFV checkbox on the Test Types page of the Report Dialog window (see [Settings for a functional test](<02.10.02.06.03_Functional_test_settings.md>)). If you want to switch between including all or only the failed output pins in the output, you must have activated both the Passed Pins and the Failed Pins checkboxes on the Test Types page.

For the Fine Result Granularity and H/L/I/U Multiple Execution options, see [Fine result granularity](<02.10.02.05_Fine_result_granularity.md>).

At the bottom of the window, you find the two buttons Close and Set Testsuite Flags. They are explained in [Close and Set Testsuite Flags buttons](<02.10.02.06.02_The_Close_and_Set_Testsuite_Flags_buttons.md>).
