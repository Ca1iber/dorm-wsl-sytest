# TestFlowEndEventType

An event of this type is logged when the end of a testflow is reached.

## Attributes

- [TimeStampAttrType](<02.10.01.06.05.65_TimeStampAttrType.md>)

Holds the time when the execution of the testflow ended.

## Functional changes

- Introduced before SmarTest 6.3.2
