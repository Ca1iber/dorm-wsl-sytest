# DRLPerPinOutputOnFailAttr

A variable of this type holds the enabled or disabled state of the "Per Pin Output On Fail" test suite flag as a NULL terminated string.

```
typedef char *DRLPerPinOutputOnFailAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
