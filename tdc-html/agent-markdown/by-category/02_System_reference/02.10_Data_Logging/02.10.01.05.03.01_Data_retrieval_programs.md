# Data retrieval programs

## Data retrieval programs as stand-alone processes

When a data retrieval program is implemented as a standalone process, you can start the data retrieval directly from the command line of a terminal if SmarTest is running on the same machine. The data retrieval will run in parallel with the production test, which is the normal mode of operation. It allows permanent and immediate access to all event data written to the data log stream.

You can compile the source file for a data retrieval program using the makefile provided for the DRLDump tool, as described in [DRLDump as a template for user-written data retrieval tools](<02.10.01.10.02_DRLDump_as_a_template_for_user-written_data_retrieval_tools.md>), or with the following command:

```
cc -Ae -g -I/opt/hp93000/soc/com/include -L/opt/hp93000/
    soc/com/sh_lib -odestination_name source_name.c -ldrl
    -lmc_macc
```

## Data retrieval programs as program command sets

When a data retrieval program is implemented as a program command set, it can be called from the application model. As there is no designated call for data retrieval, you can use an EXEC_INP_CALL call instead. (See [Application Model](<../02.09_Test_Program_Management/02.09.01.02_Application_Model.md>) for further information.) The data retrieval program has to be installed in the appropriate command set directory.

The parameter "&" must be added to the parameter list for the call of the data retrieval program so that the program will run in parallel with the production test, which is the normal mode of operation. It allows permanent and immediate access to all event data written to the data log stream. If the data retrieval program is run in parallel, be sure to always implement it in such a way that it will terminate automatically (for example, when a special event occurs) or can be terminated by the user.

Note, that if the "&" parameter is not added to the parameter list, the data retrieval will not run in parallel. This means that the next application model command will not be executed before the data retrieval program has terminated.
