# General data content options for STDF files

This topic covers the different options for STDF files.

Summary and detailed files

You can choose to have the software generate summary files, detailed files, or both. See the generateSummaryFile and generateDetailedFile options in [Configuring the contents of an STDF file](<02.10.03.04.03_Configuring_the_contents_of_the_STDF_file.md>) for information on how to select these file types.

Summary file

A summary file can be significantly smaller than the detailed file because it only includes the header and summary records, including the [PRR](<02.10.03.05.25_Part_Results_Record__PRR.md>), [SBR](<02.10.03.05.10_Software_Bin_Record__SBR.md>), [HBR](<02.10.03.05.09_Hardware_Bin_Record__HBR.md>), and [TSR](<02.10.03.05.26_Test_Synopsis_Record__TSR.md>). It does not contain detailed test results information or records of the following types: [PTR](<02.10.03.05.22_Parametric_Test_Record__PTR.md>), [MPR](<02.10.03.05.23_Multiple-Result_Parametric_Record__MPR.md>), [FTR](<02.10.03.05.24_Functional_Test_Record__FTR.md>), [DTR](<02.10.03.05.29_Datalog_Text_Record__DTR.md>), [GDR](<02.10.03.05.27_Generic_Data_Record__GDR.md>), [PMR](<02.10.03.05.11_Pin_Map_Record__PMR.md>).

Detailed file

A detailed file contains the detailed test results and includes [PTR](<02.10.03.05.22_Parametric_Test_Record__PTR.md>), [MPR](<02.10.03.05.23_Multiple-Result_Parametric_Record__MPR.md>), [FTR](<02.10.03.05.24_Functional_Test_Record__FTR.md>), [DTR](<02.10.03.05.29_Datalog_Text_Record__DTR.md>), [GDR](<02.10.03.05.27_Generic_Data_Record__GDR.md>), and [PMR](<02.10.03.05.11_Pin_Map_Record__PMR.md>) records.

Lot and Wafer level files

See the stdfFileContentLevel option in [Configuring the contents of an STDF file](<02.10.03.04.03_Configuring_the_contents_of_the_STDF_file.md>) for information about how to produce one file per lot or one file per wafer.

`stdfFileContentLevel=lot` will produce one STDF file for each lot tested. All of the summary records will contain counts that reflect the entire lot.

The dataformatter determines the lot boundary based on the application model level named "lot". If you have a level in the application model that represents the lot boundary that is not named "lot", specify the name of the lot level in the configuration file. See alternateLotLevelName in [Configuring the STDF file locations](<02.10.03.04.01_Configuring_the_STDF_file_locations.md>) for information about naming lot levels.

`stdfFileContentLevel=wafer` will produce one STDF file for each wafer tested. All of the summary records will contain counts that reflect only the wafer test results contained in that file. For example, if you test five wafers in a lot and you are generating one file per wafer, you would get five STDF files (one per wafer).

`stdfFileContentLevel=auto` will cause the data formatter to generate one file per lot when you are performing package test and one file per wafer when you are performing wafer test.
