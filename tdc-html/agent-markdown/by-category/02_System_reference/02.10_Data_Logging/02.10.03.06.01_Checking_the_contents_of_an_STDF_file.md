# Checking the contents of an STDF file

To let you quickly check the contents of a generated STDF file, SmarTest includes a simple STDF reader.

The reader reads an STDF file and writes a list of all records, and of the data stored in all fields of the records, to stdout.

The executable of the STDF reader is named STDFreader. It is located in the /opt/hp93000/soc/system/bin directory.

The usage is:

```
STDFreader stdf_file_name
```

stdf_file_name is the path and file name of the STDF file to be read.

## Functional changes

- Introduced before SmarTest 6.3.2
