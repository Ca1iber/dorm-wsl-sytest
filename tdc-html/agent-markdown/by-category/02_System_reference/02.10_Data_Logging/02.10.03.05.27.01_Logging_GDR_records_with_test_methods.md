# Logging GDR records with test methods

To log GDRs and data using test methods, the appropriate calls to the test methods must be made. Refer to [Test method API for logging GDRs and DTRs](<02.10.03.03.09.01_Test_method_API_for_logging_GDRs_and_DTRs.md>) for details.

For complete information about these and other test methods, refer to the [GENERIC_DATA_EVENT API](<../02.07_Test_Method_Reference/02.07.04.01.78_GENERIC_DATA_EVENT_-__gde.md>), and the [TESTSET API](<../02.07_Test_Method_Reference/02.07.04.01.244_TESTSET.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.4: Removed support for logging GDRs with user procedures
