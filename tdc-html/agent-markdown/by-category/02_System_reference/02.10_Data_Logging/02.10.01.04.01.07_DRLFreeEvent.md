# DRLFreeEvent

void DRLFreeEvent (DRLEventRec *event))

This function releases the memory allocated for event by the function [DRLKeepEvent](<02.10.01.04.01.10_DRLKeepEvent.md>). DRLFreeEvent should always be called when the data stored with event is no longer used.

## Return Value

None.

## Functional changes

- Introduced before SmarTest 6.3.2
