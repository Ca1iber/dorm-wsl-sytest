# DeviceIdAttrType

Contains the device ID (dev@) and the site ID for the device. If multisite testing is performed, multiple DeviceIdAttrType attributes are included in a given [TestFlowStartEventType](<02.10.01.06.03.14_TestFlowStartEventType.md>) event record.

The data type is [DRLDeviceIdAttr](<02.10.01.04.02.14_DRLDeviceIdAttr.md>).
