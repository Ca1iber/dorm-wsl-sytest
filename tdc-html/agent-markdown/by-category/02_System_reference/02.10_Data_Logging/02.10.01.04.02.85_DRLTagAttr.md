# DRLTagAttr

A variable of this type holds a tag name and value as a NULL terminated string.

```
typedef struct _DRLTagAttr {
   const char *tag_name;
   const char *tag_value;
} DRLTagAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
