# DRLTestFunctionTypeAttr

A variable of this type holds the name of a test function (for example, continuity, leakage, or functional) as a NULL terminated string.

```
typedef char *DRLTestFunctionTypeAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
