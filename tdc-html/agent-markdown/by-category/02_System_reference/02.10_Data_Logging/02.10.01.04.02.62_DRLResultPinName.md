# DRLResultPinName

A variable of this type identifies the pin for which results are reported.

## Syntax

The struct contains these members:

- bit_pos: The position of the pin's bit in the d dimension.
- pin_name: The name of the pin being reported.

```
typedef struct _DRLResultPinName {
  unsigned int         bit_pos;
  [DRLPinName](<02.10.01.04.02.46_DRLPinName.md>)           pin_name;
} DRLResultPinName;
```

## Functional changes

- Introduced in SmarTest 7.0.3
