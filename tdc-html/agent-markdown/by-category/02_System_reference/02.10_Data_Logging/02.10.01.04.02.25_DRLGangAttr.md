# DRLGangAttr

A variable of this type holds information that an IDDQ measurement was performed by summing up the ganged currents.

The member *result is always 1.

```
typedef struct {
    char *result;
} *DRLGangAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
