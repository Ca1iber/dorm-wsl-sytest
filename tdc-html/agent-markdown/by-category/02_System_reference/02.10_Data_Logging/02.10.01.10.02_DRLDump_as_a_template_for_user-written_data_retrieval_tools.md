# DRLDump as a template for user-written data retrieval tools

The DRLDump tool is an excellent example of a simple, yet complete (in the sense that it processes all existing types of events and attributes) data retrieval tool. If you want to write your own data retrieval tool, we recommend to use the DRLDump tool as a template. Therefore, the source file main.c and a make file for compilation are provided in the /opt/hp93000/soc/.service/DRLDump/directory.

This directory also contains a read-me file that describes the parameter options for starting DRLDump.

To use main.c and the make file for your own data retrieval tool:

- Copy both files to your working directory.
- Make the required modifications to main.c and save it.
- Edit the first two lines of the make file:

`DEST =`<destination directory for the executable>

`PROGRAM =`<name for the executable>

Save the file.

- Execute the command `make depend` to generate a make file that is based on Makefile and contains updated information about the *.c files in your working directory.
- Execute the command `make all` to compile.
