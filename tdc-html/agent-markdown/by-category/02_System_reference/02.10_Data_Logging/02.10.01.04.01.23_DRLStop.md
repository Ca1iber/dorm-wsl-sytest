# DRLStop

void DRLStop (DRLDataStream *stream)

Closes the data log stream or file stream and releases the internal data structures. You should always call this function at the end of a data retrieval process.

For a report formatter the function DRLStop is called automatically (see [How the Event Formatter works](<02.10.02.07_How_the_Event_Formatter_works.md>)).

## Return Value

None.

## Functional changes

- Introduced before SmarTest 6.3.2
