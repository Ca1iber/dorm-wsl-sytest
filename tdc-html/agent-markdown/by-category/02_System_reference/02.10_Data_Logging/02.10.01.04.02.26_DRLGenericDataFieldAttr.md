# DRLGenericDataFieldAttr

A variable of this type is a pointer to a structure named _DRLGenericDataFieldAttr. In this structure, a type, its length, and the data are stored (the type can be one of various types). The data does not necessarily hold a NULL terminated string. The member type specifies the type of the value and determines how to interpret the bytes referenced by the data member.

The available data types are listed in [GenericDataFieldAttrType](<02.10.01.06.05.15_GenericDataFieldAttrType.md>).

```
typedef const struct _DRLGenericDataFieldAttr {
    unsigned char   type;
    unsigned short  length;
    char  *         data;
} *DRLGenericDataFieldAttr;
```
