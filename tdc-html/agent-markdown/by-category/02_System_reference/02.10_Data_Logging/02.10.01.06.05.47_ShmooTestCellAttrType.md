# ShmooTestCellAttrType

Contains the results of shmoo tests. The data type is [DRLShmooTestCellAttr](<02.10.01.04.02.77_DRLShmooTestCellAttr.md>).

 |

Field name

 |

Type

 |

Description

 |
 |

numberOfPin

 |

unsigned int

 |

The number of pins to display shmoo plots

 |
 |

numberOfTestMode

 |

unsigned int

 |

The number of available [Test modes](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.02.02_Test_modes.md>) on a shmoo plot

 |
 |

pinNames

 |

string

 |

List the pin names for the pins that display shmoo plots.

 |
 |

testModes

 |

string

 |

List the available [Test modes](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.02.02_Test_modes.md>) on a Shmoo plot.

 |
 |

numberOfCell

 |

unsigned int

 |

The number of cells on a shmoo plot.

 |
 |

ShmooTestCellData.coordinate[]

 |

unsigned int

 |

An array listing the coordinates for a certain cell on a shmoo plot. The maximum dimension size is ten.

For example, (x), (x, y), (x, y, z).

 |
 |

ShmooTestCellData.numberOfValues

 |

unsigned int

 |

The number of values logged in this cell.

 |
 |

ShmooTestCellData.cellValue[]

 |

double

 |

An array listing the result data contained in this cell.

 |
