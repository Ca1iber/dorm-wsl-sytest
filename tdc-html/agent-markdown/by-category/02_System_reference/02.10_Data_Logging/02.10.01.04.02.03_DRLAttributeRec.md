# DRLAttributeRec

A variable of this type holds the data of one attribute record. Such variables are initialized using the [DRLEventGetAttribute](<02.10.01.04.01.02_DRLEventGetAttribute.md>) function.

The DRLAttributeRec data type is a structure consisting of two members:

- type (see [DRLAttributeType](<02.10.01.04.02.04_DRLAttributeType.md>)), holds the type of the attribute (see [Attribute types](<02.10.01.06.05_Attribute_types.md>)). The type determines which element of the second member, the unit data, is valid.
- data holds the data of the body section of an attribute record for all possible attribute types. If, for example, type is PinResultAttrType, the pin_result_attr element holds the corresponding data.

For further information on how attribute data is organized, see [Data Organization](<02.10.01.06.01_EDF_data_organization.md>).

## Example

```

{
   /* event has been initialized before by a call of DRLGetNextUnmaskedEvent */

   DRLAttributeRec attribute;
   int i;
   i=1;
   DRLEventGetAttribute (&event,i,&attribute);
   /* gets the first (i=1) attribute record of event */

   switch (attribute.type)
       { case TestSuiteNameAttrType:
        /* processing attribute.data.test_suite_name_attr
       */
              break;
         case SiteSetAttrType:
       /* processing attribute.data.site_set_attr
       */
              break;
         /*
              ...

         */
       };
}
```
