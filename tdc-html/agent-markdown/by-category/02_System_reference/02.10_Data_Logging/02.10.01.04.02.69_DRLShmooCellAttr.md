# DRLShmooCellAttr

A variable of this type is a pointer to a structure named _DRLShmooCellAttr. This structure holds the result data for all cells of a shmoo plot.

The member shmoo_cell holds all results, and the member step_n holds the number of steps for each master axis (x- or y-axis) of the shmoo plot. See the comments of the definition below, for information on calculating the element in shmoo_cell that belongs to a certain coordinate in the plot. For information about the data type of shmoo_cell, see [DRLShmooCell](<02.10.01.04.02.68_DRLShmooCell.md>).

DRL_SHMOO_MAX_XY_AXIS is 2, that is, result data of a shmoo plot with up to two dimensions can be stored.

```
typedef struct _DRLShmooCellAttr
{
  short step_n[DRL_SHMOO_MAX_XY_AXIS];
  DRLShmooCell shmoo_cell[1];
  /* step_n[0] * step_n[1] *... is the real size
     of the array */

  /* To calculate the position pos of a
  given coordinate (for example, [x][y][z] with
  DRL_SHMOO_MAX_XY_AXIS == 3), in
  shmoo_cell, you have to calculate
  pos = x + y * step_n[0] + z * step_n[0] * step_n[1];

   */
} *DRLShmooCellAttr;
```
