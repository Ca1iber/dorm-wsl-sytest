# PerPinOutputOnFailAttrType

Contains a string representing the state for the "Per Pin On Fail" flag of a particular test suite. The data type is [DRLPerPinOutputOnFailAttr](<02.10.01.04.02.43_DRLPerPinOutputOnFailAttr.md>).
