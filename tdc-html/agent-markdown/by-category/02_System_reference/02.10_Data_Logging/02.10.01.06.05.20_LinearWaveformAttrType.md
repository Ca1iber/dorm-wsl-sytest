# LinearWaveformAttrType

Contains a complete result waveform for one or more pins. The waveform can be a captured waveform or a reference waveform.

The data type is [DRLLinearWaveformAttr](<02.10.01.04.02.32_DRLLinearWaveformAttr.md>).

   | Note You can specify any derived unit (such as ns or mA) for EDL data logging. (For example, 435 mA is converted to 0.435 A.)
