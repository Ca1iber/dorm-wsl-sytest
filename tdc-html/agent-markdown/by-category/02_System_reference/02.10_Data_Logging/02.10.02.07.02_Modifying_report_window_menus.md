# Modifying report window menus

As can be seen in [Report window menus](<02.10.02.02_Report_window_menus.md>), the Event Formatter adds the Help, Datalog, and Log File menus to the report window. The code for this is contained in the `filter.c` file, which is located in `/opt/hp93000/soc/formatter/EventFormatter`.(See [Appendix A: Event Formatter Files](<02.10.02.12_Appendix_A__Event_Formatter_Files.md>) for more information on the files in this directory.) This file contains the information on the menu structure of the report window. The following excerpt of `filter.c` shows how the menus are defined.

```
static MENUDEF menu_def[MAX_MENU] =
{
  { "Help",
    4,
    "Char.Translation", print_translation_table,
    "Print Separator",  separator_menu_handler,
    "Version",          version_menu_handler,
    "Documentation",    documentation_menu_handler
  },
  { "Datalog",
    6,
    "Open Report Dialog",                  open_report_dialog,
    "Save current Formatter settings",     save_report_dialog,
    "Restore Testsuite Flags",              restore_flags_handler,
    "FFV spaces ON/OFF between pins",      toggle_spaces,
    "Print Bin Statistics",                print_statistics,
    "Clear Bins",                          clear_bins
  },
  { "Log File",
    6,
    "Save Datalog Stream and Clear",      save_and_clear_stream,
    "Clear Datalog Stream",                   clear_stream,
    "Load Datalog Stream",                    load_stream,
    "Attach to current Datalog Stream",       attach_stream,
    "START Logging Formatter Output to File", log_to_file,
    "STOP  Logging Formatter Output to File", stop_logging
  }
};
```

The two first menus of the report window (File and Options) always exist and cannot be modified by the user. The MAX_MENU variable contains the number of additional menus defined in filter.c. The value for MAX_MENU is also assigned in filter.c. Here MAX_MENU is 3, for the three menus, Help, Datalog and Log File.

The value below the name of a menu is the number of items in that menu. For example, for the Datalog menu this number is 6.

As you can see in the code snippet, the functionality of a menu item is assigned by simply stating the name of the function to be called after the name of the menu item. For example, choosing Restore Testsuite Flags in the Datalog menu calls the `restore_flag_handler` function.

To define the menus of the report window for a user-written report formatter or to change existing menus, use the filter.c file as a template and modify it as needed.

To define new menus, use the format:

```
{ "Menu name",
  item count,
  "item name 1", function_to_be_called_1,
  "item name 2", function_to_be_called_2
}
```

Make sure to update MAX_MENU with the new number of menus in the report window.
