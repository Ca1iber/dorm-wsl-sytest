# Starting the Profile Editor

## About this task

This task describes how to start the Profile Editor. You need to start the Profile Editor to create or change a data logging profile.

Depending on what you want to do with the Profile Editor, it is started in two different ways:

- Option 1: You want to create a new data logging profile.
- Option 2: You want to edit change an existing data logging profile.

## Before you begin

The SmarTest software must be running.

## Procedures

### Option 1: Creating a new data logging profile

- In the Test Program Explorer, right-click the <Profile> item and choose New.

A new window opens.

- Enter a name for your data logging profile in the Selection field and click OK. The Profile Editor starts and opens the new empty data logging profile.

### Option 2: Editing an existing data logging profile

- Load the data logging profile you want to edit as described in [Loading a data logging profile](<02.10.01.02.02_Loading_a_data_logging_profile.md>).
- In the Test Program Explorer, double-click the loaded profile. The Profile Editor starts and opens the data logging profile you want to edit.

## Results

The Profile Editor is running, displaying the data logging profile you want to create or edit.
