# DRLPinGroupNameToIndex

int DRLPinGroupNameToIndex (char *name, unsigned short *index)

This function allows mapping of pin group names to pin group DC/DC power units.

The index of a pin group is needed, for example, to get a list of pins in a group with the function [DRLPinGroupIndexToPins](<02.10.01.04.01.15_DRLPinGroupIndexToPins.md>).

## Return Value

The function returns the value 1, if the index of the pin group with the name name could be determined, and the variable index then holds the index.

Otherwise, the function returns 0, and index holds the value DRLNumberOfPinGroups. (See [DRLNumberOfPinGroups](<02.10.01.04.01.11_DRLNumberOfPinGroups.md>)).

## Functional changes

- Introduced before SmarTest 6.3.2
