# DRLShmooHXInstrumentType

A variable of this type holds a HighspeedExtention instrument which is varied for an axis on a shmoo plot.

- instrumentPin: The analog pin connected to a HighspeedExtension lane.
- property: The property of a HighspeedExtension instrument.
- unit: This option includes Hz, kHz, MHz, mV, V, fs, ps, ns, us, ms, s.Note You can specify any derived unit (such as ns or mA) for EDL data logging. However, when data logs are converted to STDF, all units are converted to their SI equivalents (ns to s, mA to A) and the corresponding values are converted accordingly. (For example, 435 mA is converted to 0.435 A.)

## Syntax

```
typedef struct _DRLShmooHXInstrumentType
{
  const char* instrumentPin;
  const char* property;
  const char* unit;
} *DRLShmooHXInstrumentType;
```
