# DRLPinIndexToName

In order to save bandwidth, pin DC/DC power units are written to the data log stream rather than pin names.

```
const char *DRLPinIndexToName (DRLPinIndex pin_index, DRLPinType *capabilities)
```

This function allows mapping of pin DC/DC power units (0 ... DRLNumberOfPins()-1) to pin names to regain the names of the pins. Moreover, the type of the pin (that is whether the pin functions as input, output, dps, dc or analog pin), is determined and referenced by capabilities. Using this function, for example, you can obtain a list of all configured pins by simply passing all pin DC/DC power units with a loop.

For further information on the data types involved see [DRLPinIndex](<02.10.01.04.02.45_DRLPinIndex.md>) and [DRLPinType](<02.10.01.04.02.53_DRLPinType.md>).

## Return Value

The function returns the name of the pin with the index pin_index and capabilities holds the information on the type of that pin. In the case of an error the function returns NULL and type is undefined.

## Functional changes

- Introduced before SmarTest 6.3.2
