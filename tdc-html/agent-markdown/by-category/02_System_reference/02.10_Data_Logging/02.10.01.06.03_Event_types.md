As explained in [Data Logging Mechanism](<02.10.01.01_Event_Data_Logging_Concepts.md>), an event record is immediately written to the data log stream for each event of a production test, for example:

- The start of a test program
- The execution of a test suite
- The binning of a device

The structure of these event records is described in [EDF data organization](<02.10.01.06.01_EDF_data_organization.md>).

This section describes all the different event types for which event records are written to the data log stream. This gives you an overview of all the events of a production test that are covered by event data logging.

For each event type, the event in the test run is explained, and a list of the different types of attributes which may describe the event is given. For each attribute type, a description of the event specific data held in the attribute record body is included.

Note that attributes of some of the listed types will only appear with the event if:

- The required data is available.
- The test suite flags that trigger the output of that data are set.

Some attributes may also appear more than once. For example, a TestEventType event can have many FailingCycleAttrType attributes.

For an example on how to set test suite flags to produce certain data, see [Handling of test suite flags by the Event Formatter](<02.10.02.09_Handling_of_test_suite_flags_by_the_Event_Formatter.md>).

The names of all event types are chosen to reflect the production test events they describe, and the names of the attribute types are chosen to reflect the data held in the attributes.
