# DRLPassRangeAttr

A variable of this type holds a pointer to a structure named _DRLPassRangeAttr. In this structure the values that define a pass range are stored.

The member min_value holds the lower limit of the pass range, max_value holds the upper limit.

The members min_value_relation and value_max_relation define whether min_value and max_value are the inner or outer limits of the pass range, or if either of these values is not used as a limit at all. In that case, the pass range only is a pass limit.

min_value_relation and value_max_relation can be any of the values DRLCompareCode_Less (<), DRLCompareCode_LessEqual (<=) or DRLCompareCode_NA (NA).

The member unit holds the unit of range limits as a NULL terminated string.

 Note You can specify any derived unit (such as ns or mA) for EDL data logging. However, when data logs are converted to STDF, all units are converted to their SI equivalents (ns to s, mA to A) and the corresponding values are converted accordingly. (For example, 435 mA is converted to 0.435 A.)

```
typedef const struct _DRLPassRangeAttr{
    double min_value;
    double max_value;
    char min_value_relation; /* DRLCompareCode_Less,
                                DRLCompareCode_LessEqual or
                                DRLCompareCode_NA*/
    char value_max_relation;
    char *unit;
   } *DRLPassRangeAttr;
```
