# SmarTest Data Formatter Quick Start Guide

The SmarTest Data Formatter converts SmarTest test results to Standard Test Data Format (STDF) version 4. The SmarTest Data Formatter can generate STDF in real-time, while SmarTest is generating test results, or it can post-process files that contain test results (also known as event data log files).

The SmarTest Data Formatter is included with SmarTest. The SmarTest Data Formatter component is also available on the SmarTest Software Download website.

## How to generate STDF data

The SmarTest Data Formatter is enabled with the configuration option `formatter.stdf.generateStdf=true` in the /etc/opt/hp93000/soc_common/datalog/global.conf file. If the SmarTest Data Formatter has been enabled, it starts automatically when SmarTest starts. You do not need to explicitly call the formatter from the application model.

To convert data log files to STDF, the SmarTest Data Formatter can be executed from the command line. To process a data log file, enter:

```
dataformatter -d <data log file name>
```

 Note The Data Formatter program is located in /opt/hp93000/soc/formatter/bin. The data log file is located in /var/opt/hp93000/soc/tmp/93k.xxx, where 93k.xxx indicates a session specific directory. When SmarTest terminates abnormally, for example, because it loses the connection to the license server, this file is moved to /tmp/DataCollection.

To generate STDF from a testflow execution, the SmarTest Data Formatter must be enabled and you must change the configuration option `formatter.stdf.generateStdfFromTestflowEditor=true` in the /etc/opt/hp93000/soc_common/datalog/global.conf file. The next section describes the STDF configuration further.

## Configuring STDF

 Note

SmarTest logs floating-point values with 8-byte precision in the native EDL format, while STDF is limited to 4-byte precision. This may lead to rounding in STDF logs. Also, numbers bigger than about 3.0e38 can be represented in EDL (to a limit of about 1.7e308) but are logged as "inf" in STDF.

In rare cases, STDF logs may therefore deviate from EDL logs, and evaluating them may give different results.

## Configuration files

The options for the SmarTest Data Formatter are set in two configuration files:

- global.conf contains configuration options for the location of STDF output files and for generating STDF from the Testflow Editor.
- formatter.stdf.main.conf contains configuration options for STDF-specific settings.

The STDF configuration can be applied to STDF data that is generated in real-time or while post-processing data log files. To specify an STDF configuration for a data log file that is converted to STDF from the command line, enter the following at the command line:

```
dataformatter -d <data log filename> -c <STDF configuration path>
```

<STDF configuration path> is a directory containing the STDF configuration files. If the `-c` option is omitted, the standard configuration files (see below) are used.

## Configuration file locations

Configuration files can be located in different places:

- SmarTest is installed with standard STDF configuration files in the /etc/opt/hp93000/soc_common/datalog directory, which are linked to from /etc/opt/hp93000/soc/datalog. The options in /etc/opt/hp93000/soc/datalog are used by default, as long as no other files are available or specified (see below).

You must have root access to edit these configuration files.

- A different location for the configuration files can be specified in the DATAFORMATTER_SYSTEM_CONFIG_DIRECTORY environment variable.

For example, this shell command causes SmarTest to look for configuration files in the specified folder:

```
export DATAFORMATTER_SYSTEM_CONFIG_DIRECTORY=/users/myself/my_dataformatter_config
```

As above, you can copy the standard configuration files and edit them to your desired configuration.

If a configuration file is specified in this environment variable, the standard configuration file is ignored. If the environment variable points to a file that does not exist, an error message is generated and the formatter cannot run.

- Each device can have an additional device-specific STDF configuration: If there is a folder datalog in the device folder, any configuration file in this folder is used to modify the STDF settings from the standard configuration file or the configuration file specified in the environment variable (whichever is in effect).

You can copy the standard configuration files to the datalog folder and edit them as desired. The device-specific configuration file need not be complete, that is, it is possible to specify only some of the options in it and delete the rest.

If a particular configuration option is specified in both locations, the setting from the device-specific configuration is used.

## Viewing STDF files as text

The STDF reader can be used to view the text representation of the STDF file. To view an STDF file as text, type the following at the command line:

```
/opt/hp93000/soc/formatter/bin/STDFreader <STDF filename> > <Text output file name>
```
