# DRLLabelDescriptorAttr

A variable of this type holds the description of a label. The variable is used in [DRLLabelListAttr](<02.10.01.04.02.30_DRLLabelListAttr.md>).

## Syntax

```
typedef struct _DRLLabelDescriptor {
  int id;
  const char* name;
} *DRLLabelDescriptor;
```
