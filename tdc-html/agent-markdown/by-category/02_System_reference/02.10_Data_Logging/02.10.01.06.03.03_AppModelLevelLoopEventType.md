# AppModelLevelLoopEventType

Every application model level except for the DEVICE_TEST level is basically a while loop. When the level is entered the first time, an application model start event is generated. For each iteration, an application model loop event is generated, except for iterations in the DEVICE level. After the last iteration, an application model end event is generated.

## Attributes

- [AppModelLevelAttrType](<02.10.01.06.05.02_AppModelLevelAttrType.md>)

Holds the name and the type of an application model level.

- [TimeStampAttrType](<02.10.01.06.05.65_TimeStampAttrType.md>)

Holds the time when the loop was entered.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.3.5.3: New attribute TimeStampAttrType
