# DRLErrorOverviewAttr

A variable of this type holds overview information on the errors that occurred when a test pattern was run.

## Syntax

```
typedef struct _DRLErrorOverviewAttr {
  const char* description;
  long long cycle_count;
  long long failure_count;
} *DRLErrorOverviewAttr;
```

## Functional changes

- Introduced in SmarTest 6.5.0
