# DRLScanInstanceListAttr

A variable of this type holds a list of scan instances.

## Syntax

```
typedef struct _DRLScanInstanceListAttr {
  int instance_count;
  struct _DRLScanInstanceDescriptor instance[1];
} *DRLScanInstanceListAttr;
```
