# Data Formatter errors and warnings

When the SmarTest Data Formatter encounters an error or warning it will log an error or warning message either to the report window or to a log file called dataformatter.log. The location of the dataformatter.log file depends on the definition of certain environment variables in the following priority:

- If HP83000_ROOT is defined the dataformatter.log file is created in the /etc/opt/hp93000/soc/ directory.
- Else if HOME is defined the dataformatter.log file is created in the user home directory.
- If neither HP83000_ROOT or HOME are defined, the dataformatter.log file is created in the current directory.

When the dataformatter.log file exceeds 1 megabyte in size the SmarTest Data Formatter will automatically trim data from the file, reducing it to smaller than 5 kilobytes.
