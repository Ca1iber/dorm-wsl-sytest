# DRLPortTimingsAttr

A variable of this type contains information about the timing used for a port based test. It stores either a specification string or a timing set number.

```
typedef struct _DRLPortTimingsAttr {
    char* description;
    char* port_string;
    int tim_set;
} DRLPortTimingsAttr;
```

## Functional changes

- Introduced before SmarTest 6.3.2
