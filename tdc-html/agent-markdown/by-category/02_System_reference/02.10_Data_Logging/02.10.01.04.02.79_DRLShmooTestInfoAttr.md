# DRLShmooTestInfoAttr

A variable of this type holds the setups of a shmoo test.

- title: The title of a shmoo plot.
- testMode: The available [Test modes](<../02.08_Setup_and_Result_Tools/02.08.04.25.03.02.02_Test_modes.md>) on the shmoo plot.
- resultPins: The pins which can display pass/fail results on a shmoo plot. If you did not specify the result pins when setting, @(all pins) will be displayed.
- otherDescription: The description for the shmoo plot.
- resultResolution: The resolution to differentiate the results.

  - If the difference between two results is larger than or equal to the specified resolution, their results are considered different.
  - Otherwise, their results are considered the same.

- numberOfAxis: The number of dimensions on a shmoo plot.
- axisData: Stores the setups for the axes. The data type is [DRLShmooAxisData](<02.10.01.04.02.65_DRLShmooAxisData.md>).

## Syntax

```
typedef struct _DRLShmooTestInfoAttr
{
  const char* title;
  const char* testMode;
  const char* resultPins;
  const char* otherDescription;
  double resultResolution;
  int numberOfAxis;
  DRLShmooAxisData* axisData;
} *DRLShmooTestInfoAttr;
```
