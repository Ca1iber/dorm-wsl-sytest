# Setting the FRG (fine result granularity) flag

#### Subtopics

- [Setting the Multishot Per-Edge Detailed result mode](<02.10.02.05.01.01_Setting_the_Multishot_Per-Edge_Detailed_result_mode.md>)

The [Fine result granularity](<02.10.02.05_Fine_result_granularity.md>) for data logging is enabled by setting a test suite flag.

## About this task

Make sure that the test suite for which you set the flag does not perform protocol-aware tests; FRG is not compatible with protocol-aware tests.

## Procedure

 In the Properties page for the test suite, activate the Flags > FFC Enable > FRG enable flag.

The H/L/I/U (multiple execution) flag specifies if this option is active or not in Test Suite dialogs.

 Note On the firmware level, you can use the [CYRM (CYcle Resolution Mode)](<../02.06_Command_Reference/02.06.02.02.37_CYRM__CYRM__-__CYcle_Resolution_Mode.md>) firmware command to activate fine result granularity.
