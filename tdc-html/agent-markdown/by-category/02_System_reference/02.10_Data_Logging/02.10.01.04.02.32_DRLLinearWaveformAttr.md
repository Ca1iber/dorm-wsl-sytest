# DRLLinearWaveformAttr

A variable of this type is a pointer to a structure named _DRLLinearWaveformAttr. This structure stores the values of a waveform for a list of pins (usually there is only one pin in the list), and the complete information for the waveform presentation.

The first seven members hold the presentation data:

- x_parameter holds the description of the x-axis, for example, 'time'.
- x_unit holds the unit of the x-axis, for example, '[us]'.
- y_parameter holds the description of the x-axis, for example, 'amplitude'.
- y_unit holds the unit of the y-axis, for example, '[mV]'.
- start holds the start value of the x-axis.
- end holds the end value of the x-axis.

The member description can hold any further information as a NULL terminated string.

 Note You can specify any derived unit (such as ns or mA) for EDL data logging. However, when data logs are converted to STDF, all units are converted to their SI equivalents (ns to s, mA to A) and the corresponding values are converted accordingly. (For example, 435 mA is converted to 0.435 A.)

The next two members hold the measured waveform values:

- steps holds the number of measured values (that is, the number of steps on the x-axis).
- samples is an array of the size steps that holds the measured values.

The remaining two members hold the data for the pin list:

- size holds the number of pins in pins.
- pins holds the actual list of pins (see [DRLPinName](<02.10.01.04.02.46_DRLPinName.md>).)

```
typedef const struct _DRLLinearWaveformAttr {
  const char *description;
  const char *x_parameter;
  const char *x_unit;
  const char *y_parameter;
  const char *y_unit;
  double start;
  double end;
  int steps;
  double *samples;
  unsigned short size;
  DRLPinName pins[1];
} *DRLLinearWaveformAttr;
```
