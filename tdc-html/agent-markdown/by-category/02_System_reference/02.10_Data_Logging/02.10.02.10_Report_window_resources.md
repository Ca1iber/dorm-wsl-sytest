# Report window resources

Report window resources let you make various settings for the appearance and the functionality of the report window by configuring the amount of X window resources available.

Although these are general settings, there are two resources which are of special importance when the Event Formatter is used.

When you include FFV data in the output of the Event Formatter, especially in verbose mode, the output may contain a large number of lines (this also applies when including shmoo plots and waveforms). With the following two resources you control how many lines the report window may contain and what will happen if the defined number of lines is exceeded by the output of the formatter.

## XReport.maxLines

XReport.maxLines defines the number of lines the report window can hold. You should assign this resource a number of report lines that is large enough to hold all the data you need to have direct access to in the report window.

(The default of 10000 lines has proved to be a reasonable number in most situations.)

## XReport.purgeLines

XReport.purgeLines defines the number of lines that are deleted from the report window when XReport.maxLines are reached. The specified number of oldest lines are removed. (The default of 5000 lines has proved to be a reasonable number in most situations.)

## XReport*text_window*editable

Another resource you may want to make use of is XReport*text_window*editable. Set to True (default is False), this resource enables editing of the report window contents. This lets you, for example, add comments to the report before saving it with the File > Save menu command.

- Introduced before SmarTest 6.3.2
