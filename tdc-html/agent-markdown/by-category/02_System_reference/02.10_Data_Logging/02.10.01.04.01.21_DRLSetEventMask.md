# DRLSetEventMask

int DRLSetEventMask (DRLEventMask *mask, DRLDataStream *stream)

Calling this function sets the active event mask of the data log stream/file associated with stream as specified in the parameter mask of the type [DRLEventMask](<02.10.01.04.02.17_DRLEventMask.md>). The active event mask lets you determine whether a logged event record will be ignored, or dealt with by the function [DRLGetNextUnmaskedEvent](<02.10.01.04.01.09_DRLGetNextUnmaskedEvent.md>). Thus, this event mask lets you select only the event records of interest from the stream of all logged event records.

In order to quickly change the active event mask, different event masks may be predefined in DRLEventMask variables and then be made active by calling this function.

## Return Value

The return value is zero if the function was successful or non-zero if the event mask specified in mask is invalid.

## Example

```
void example (void)
{
   DRLEventMask mask;
   /* set the values for mask as shown in the example in
    "DRLEventMask" on page 137*/
   if (DRLSetEventMask(&mask,&stream))
   {
      /*  error handler  */
   }
/* the active event mask is now set to that specified in mask */
}
```
