# DRLPatternLabelAttr

A variable of this type holds the label of a pattern.

## Syntax

The pattern label is contained in the label member.

```
typedef struct _DRLPatternLabelAttr {
  const char* label;
} *DRLPatternLabelAttr;
```

## Functional changes

- Introduced in SmarTest 7.0.3
