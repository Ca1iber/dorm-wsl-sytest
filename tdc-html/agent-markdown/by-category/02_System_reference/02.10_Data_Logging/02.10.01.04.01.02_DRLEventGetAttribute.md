# DRLEventGetAttribute

int DRLEventGetAttribute (const DRLEventRec *event, unsigned which, DRLAttributeRec attribute)

This function retrieves the attribute record number which from event and copies the reference to it to the caller-provided buffer attribute (see [DRLAttributeRec](<02.10.01.04.02.03_DRLAttributeRec.md>)).

To retrieve all attribute records that come with an event record you have to call the function DRLEventGetAttribute once for each attribute record while incrementing which (starting with 0). The variable which can either be incremented until ERR_NO_ATTR is returned by DRLEventGetAttribute or until the actual number of attribute records (see [DRLEventGetNoOfAttributes](<02.10.01.04.01.05_DRLEventGetNoOfAttributes.md>)) is reached, as in the example below.

## Return Value

The return value is zero if the function was successful; otherwise the error code ERR_NO_ATTR (see [Error Codes](<02.10.01.04.02.108_Error_Codes.md>)) is returned if the event has no attribute record as specified by which.

## Example

```
void example (void)
{
   DRLEventRec event;
   DRLAttributeRec attribute;
   int i, no_of_attributes;
    if (DRLGetNextUnmaskedEvent(&event));
      { /* error handler*/ break;
      }
   no_of_attributes = DRLEventGetNoOfAttributes(&event);
   for (i=0; i < no_of_attributes, i++)
   {
       DRLEventGetAttribute(&event, i, &attribute);
       /* attribute is now filled with data of the
          attribute record number i of event and can be
          processed  */
    }
}
```
