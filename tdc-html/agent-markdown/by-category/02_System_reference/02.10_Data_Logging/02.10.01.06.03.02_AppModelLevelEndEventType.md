# AppModelLevelEndEventType

An event of this type is logged when an application model level is exited.

## Attributes

- [TimeStampAttrType](<02.10.01.06.05.65_TimeStampAttrType.md>)

Holds the time when the application model level was exited.

## Functional changes

- Introduced before SmarTest 6.3.2
