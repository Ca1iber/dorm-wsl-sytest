# DRLTruncate

int DRLTruncate (DRLDataStream *stream)

This function clears the data log stream specified by stream. All pointers to the data log stream and the event counter are reset. If the stream references on a previously saved data log file and not the data log stream, this file stays unchanged. See also [DRLSave](<02.10.01.04.01.20_DRLSave.md>) and [DRLStart](<02.10.01.04.01.22_DRLStart.md>).

## Return Value

The return value is zero if the function was successful. If the data log stream could not be truncated, the error code ERR_TRUNC is returned.

## Functional changes

- Introduced before SmarTest 6.3.2
