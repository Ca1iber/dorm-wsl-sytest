# Test Synopsis Record (TSR)

The Test Synopsis Record contains the test execution and failure counts for one parametric or functional test in the test program. It also contains static information such as the test name. The TSR is related to the FTR, PTR, and the MPR by test number, head number, and site number.

The Test Synopsis Record can be located anywhere in the data stream after the initial sequence and before the MRR. When test data is being generated in real time, these records will appear after the last PRR.

## Changes when useStandardTSR is set to false

When the [useStandardTSR](<02.10.03.04.03_Configuring_the_contents_of_the_STDF_file.md>)[ key](<02.10.03.04.03_Configuring_the_contents_of_the_STDF_file.md>) in the [active configuration file](<02.10.03.01.01_SmarTest_Data_Formatter_Quick_Start_Guide.md#_85250__config-file-locations>) is set to false, the content of the standard TSR record is slightly modified and an additional nonstandard record is generated for each standard TSR record. The additional record provides a summary of test execution times (as opposed to a summary of test result values).

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.2.2: Added HEAD_NUM and SITE_NUM conventions for tests on more than 255 sites.
- SmarTest 7.2.2: TEST_LBL now contains the pattern name.
- SmarTest 7.4.2: Setting the useStandardTSR or generateStandardTsrTestLabel key in the configuration file changes the semantics of several fields.
