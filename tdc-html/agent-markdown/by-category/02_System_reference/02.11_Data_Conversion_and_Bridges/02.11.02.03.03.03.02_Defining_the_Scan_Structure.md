# Defining the Scan Structure

A scan structure is defined by the SCAN_TEMPLATE statement, which specifies the name and the length of the template, and by the SCAN_PORT statements, which associate the scan pins with the template. The format of the SCAN_TEMPLATE statement is:

SCAN_TEMPLATE <template_name> <template_length>

 Note You cannot define the repeat length for the parallel parts with this statement. The repeat length will always be set to 1 by the vector translation.

The format of the SCAN_PORT statement is:

SCAN_PORT <template_name> (IN|OUT) <pins>

At least one input pin and one output pin must be specified for every template. If you specify more than one pin, the names must be separated by blanks.

 Note The SCAN_PORT statements are translated into DFSP firmware commands, which have a fill character for the scan pins as one of their parameters. This fill character cannot be defined with the SCAN_PORT statement. It will always be set to "0" by the vector translation. This also holds for scan output pins. Note If you process several ASCII vector files containing scan template definitions with one aiv run, take care that templates with the same name are also defined identically. If you use, for example, the same template name with different scan pins, the ASCII Interface will create these different definitions, but SmarTest will refuse to load a vector setup file with different definitions of the same template.

You can define frames with the SCAN_FRAME statement and associate them with a template. The format of the SCAN_FRAME statement is:

SCAN_FRAME <frame_name> <length> <input_pin> <output_pin> [<offset>]

The SCAN_FRAME statement does not contain any template name. You can associate a frame with a template in two ways, by position or by reference. If you put the SCAN_FRAME statement immediately below the SCAN_PORT statements for a template, you associate the frame with this template by position. You can also associate a previously defined frame with a template by referring to it with the SCAN_FRAME_OFFSET statement, which has the format:

SCAN_FRAME_OFFSET <frame_name> <offset>

The SCAN_FRAME_OFFSET statement must be put immediately below the SCAN_PORT statements for the respective template.

If you define a template and do not associate a frame with it, the ASCII interface will automatically create a standard frame, which displays the whole template.
