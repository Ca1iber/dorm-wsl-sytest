# Calling d2w directly

#### Subtopics

- [d2w parameters](<02.11.02.02.09.01_d2w_parameters.md>)

Normally, the timing translation is performed with the high-level tool ait, which calls the low-level tool d2w for each row of the PATTERNS section in the global configuration file. But you can also call d2w directly. This can be used, for example, to run different ASCII device cycles within the same pattern with different period lengths and different x-mode factors (see the explanation of the -b parameter). Normally, d2w creates one wavetable, one equation set, one timing set within this equation set, and one timing map file, which is then used as an auxiliary input file by the vector translation.

The d2w tool is located in /opt/93000/aif/d2w/bin. It is called from the command line by entering d2w with the appropriate parameters. These parameters are described in [d2w parameters](<02.11.02.02.09.01_d2w_parameters.md>).
