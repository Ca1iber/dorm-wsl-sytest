# Project-related STIL Reader setup options

The project related options in a STIL Reader setup file let you configure what and how much to translate.

## Syntax

 The project related options in alphabetical order:   input_file`='`source-input-file`'`

The file that is to be translated.

source-input-file is the name and path of the file. The path may be absolute or relative to the current directory.

If an input file is provided on the command line, this parameter is ignored.

(stil_file is a deprecated synonym for input_file. Do not use it any more.)

  input_file_type`='`file_type`'`

The type of the file that is to be translated, 'STIL', 'SVF', 'AIF' (for ASCII Interface files), 'TDL', or 'WGL'.

If this parameter is specified, STIL Reader is forced to treat the input file as a file of this type, regardless of the filename extension or file content.

This parameter is mandatory when processing [ASCII Interface files](<02.11.02_ASCII_Interface.md>) and optional (and not usually required) otherwise. If it is omitted, STIL Reader determines the file type automatically from the filename extension and file content.

   project_name`='`name-of-project`'`

This name is a part of many of the names of the files created by the STIL Reader and helps to identify them.

This parameter is optional. The default value is 'project'. If the -project_name command line option is used, this parameter is ignored. This parameter can be overridden by the [stil_file_name_as_project_name](<#_118726__stil_file_name_as_project_name>) parameter (see below).

  stil_editor_setup='filepath'

The STILEditor file to execute during the conversion. (For more information about STILEditor, see [STILEditor](<02.11.01.06.02_STILEditor.md>).)

filepath is the path of the setup file. It can be an absolute path or a path relative to the current directory.

This parameter is optional. There is no default value.

   stil_file_name_as_pattern_name`=`boolean  Whether the STIL pattern name or the STIL file name are to be used as the basis for naming generated pattern files:

- `0`: The STIL Pattern name is used.
-

`1`: The STIL file name (excluding the extension) is used.

This setting is ignored when multiple pattern files are generated, for example, when there is a PatList with more than one pattern.

The setting of this parameter influences the operation of the [VCAT command](<../02.06_Command_Reference/02.06.02.02.318_VCAT__VCAT__-__VeCtor_ATtachment.md>).

This parameter is optional. The default value is 0.

  stil_file_name_as_project_name`=`boolean  Whether the STIL file name is to be used as the basis for naming generated setup files:

- 0: The project_name parameter is used.
- 1: The STIL file name (excluding the extension) is used.

This parameter is optional. The default value is 0.

   stil_pattern_exec`='`pattern-exec-block-domain-name`'`

Specifies the desired PatternExec block if a STIL file contains more than one such block.

This parameter is optional. By default, the global, unnamed PatternExec block is used. If there is no global block but only one other block, that block is used.

  target`='`platform`'`  The type of V93000 platform for which the file is to be translated. Options for platform include:

- 93000SD: V93000 single-density systems
- 93000DD: V93000 double-density systems (except Smart Scale)
- 93000SS: V93000 Smart Scale systems

The additional option '93000SMT8' that STIL Reader supports cannot be used for creating SmarTest 7 files.

This parameter is required. There is no default value. If the -target command line option is used, this parameter is ignored.

  workdir`='`path-to-working-directory`'`

The location of the working directory, that is, the directory where the result files of the translation are saved. Usually, this is the V93000 device directory.

path-to-working-directory is an absolute path or a relative path from the current directory.

Placing this directory on a different physical drive from the input file can speed up the translation.

This parameter is optional. The default is './output'. If the -workdir command line option is used, this parameter is ignored.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.2.0: Added 93000SS option for the target parameter.
- SmarTest 7.2.1: Removed work_mode option.
- SmarTest 7.2.2: Added the stil_file_name_as_project_name setting.
- SmarTest 7.4.2: Removed stil_file option.
- SmarTest 7.5.3: Added the input_file_type setting.
- SmarTest 7.10.1: Added the stil_editor_setup parameter.
