# The AI_V2B_OPTIONS Section

This section is transferred to the vector configuration file. It specifies v2b parameters that are to be applied to the vector translation of all patterns in the PATTERNS section. If the specifications of this section contradict those of the v2b_options column (see [The Input Columns](<02.11.02.02.01.01.01_The_Input_Columns.md>)) for a specific pattern, the v2b_options column has priority.
