# Purpose

The use of x-modes allows you to test devices with a smaller period than the smallest possible test system cycle length (which depends on the test system model). It can also be used to save Vector Memory, as the number of binary vectors to be stored is only a fraction of the ASCII vectors (depending on the x-mode factor).
