# Files generated in the translation

The table below shows which kinds of 93000 files are generated by STIL Reader, with a short description for each file.

All files are generated in subfolders of the current device directory.

The following variables are used in creating the file names:

- <pn>: Project name. By default, this is "project", but a different name can be specified using the -project_name command line parameter or the project_name [setup file](<02.11.01.05.03.01_Project-related_STIL_Reader_setup_options.md>) parameter.
- <stil_pattern>: STIL pattern name.

By default, the STIL pattern name is pattern block name. If the stil_file_name_as_pattern_name parameter in the STIL Reader setup file is set to 1, the STIL file name (without the extension) is used instead.

Multiple pin, group, port, and channel configuration files, if channel maps are used.

One file is generated per channel map.

<chan_map> represents the name of a STIL NameMaps block that specifies the channel information. It must be contained in an Environment block, and its name must begin with "93kChannel:". For example:

    Signals {
      clk "10201,Pin Clock";
      data "10303";
  }
}

## Vector file names

Vector file names are created differently, depending on whether multiport is used and, if so, how it is set up:

- No multiport: The file name is the STIL pattern name.
- Multiport

  - Setup using ParallelPatList: The file name is the STIL pattern name.
  - Setup using NameMaps, when each STIL pattern is used for a single port: The file name is the STIL pattern name.
  - Setup using NameMaps, when a STIL pattern is mapped to multiple ports: The file name is the STIL pattern name and the port name - <stil_pattern>_<port>.
  - Setup using NameMaps, when a port is derived from multiple STIL Patterns: The file name is created from all STIL pattern names and the port name - <stil_pattern1><stil_pattern_2>...<stil_pattern_n>_<port>.

The lengths of vector file names are restricted to 128 characters. (If the target version of the conversion is a SmarTest release before 6.1.1, the maximum length is 40 characters.) Longer names are automatically trimmed, and a suffix is added to generate a unique name.
