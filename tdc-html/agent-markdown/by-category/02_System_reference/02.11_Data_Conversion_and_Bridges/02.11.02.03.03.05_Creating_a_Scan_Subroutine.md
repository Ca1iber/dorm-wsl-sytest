# Creating a Scan Subroutine

#### Subtopics

- [Understanding Scan Subroutines](<02.11.02.03.03.05.01_Understanding_Scan_Subroutines.md>)
- [Defining Scan Subroutines in the ASCII Interface](<02.11.02.03.03.05.02_Defining_Scan_Subroutines_in_the_ASCII_Interface.md>)

SCAN instructions are not allowed in subpatterns of type SVEC. They may only occur in special scan subroutines. Since these scan subroutines, which can only be called from MAIN patterns, have some special features, the ASCII vector files for them also have a special format.
