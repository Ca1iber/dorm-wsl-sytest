# DCapSetup

DCapSetup objects specify the pins to be used for digital capture.

To use them, you must reference them in PatternExec objects.

## Syntax

```
DCapSetup <setup_name> {
  Pins "<pin_names>";
}
```

The settings are:

- DCapSetup <setup_name>

The name for the object. <setup_name> can be any name that is valid for STIL objects.setup object.

- Pins "<pin_names>";

The names of the pins that are to be used for the digital capture.

## Example

```
DCapSetup DS1 {
  Pins              "data";
}

DCapFilter DF1 {
  Type              Capture;
  TransferMode      Parallel;
  VectorsPerFrame   8;
}

DCapFilter DF2 {
  Type              Capture;
  TransferMode      Parallel;
  FrameCount        4;
  VectorsPerFrame   8;
  VectorsPerSample  1;
  DiscardOffset     2;
  DiscardVectors    1;
 }

PatternExec PE1 {
  DCapSetup         DS1;
  DCapFilter        DF1;
  DCapFilter        DF2;
  PatternBurst      B1;
}
```
