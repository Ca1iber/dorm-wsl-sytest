# Defining ASCII Vectors

#### Subtopics

- [The FORMAT Statement](<02.11.02.03.02.02.01_The_FORMAT_Statement.md>)
- [The ASCII Vector Row](<02.11.02.03.02.02.02_The_ASCII_Vector_Row.md>)
- [Example 1](<02.11.02.03.02.02.03_Example_1.md>)
- [Example 2](<02.11.02.03.02.02.04_Example_2.md>)

The ASCII vectors are organized as a table. Every row of the table specifies one ASCII vector; every column contains in temporal order the state characters for one pin. The order of the pins is variable; it is defined by the FORMAT statement which servers as a kind of header to the ASCII vector table. Sequencer instructions can be inserted on separate rows between the vector rows; for more information see [Inserting Sequencer Instructions](<02.11.02.03.02.04_Inserting_Sequencer_Instructions.md>). Every row must be terminated by a semicolon.

For scan testing, the vector rows take a different form, and additional statements defining, for example, the templates and frames must be added (see [Defining the Scan Instances](<02.11.02.03.03.03.03_Defining_the_Scan_Instances.md>)).
