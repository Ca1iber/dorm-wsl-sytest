# Controlling the Waveforms for Differential Pins

#### Subtopics

- [Evaluation by Channel](<02.11.02.02.03.07.01_Evaluation_by_Channel.md>)
- [Evaluation by Signal (the Mapping Operator "=>")](<02.11.02.02.03.07.02_Evaluation_by_Signal__the_Mapping_Operator.md>)

Definition blocks for differential pins can be evaluated either by channel or by signal. Evaluation by channel, which is faster and requires less memory, should normally be used. Evaluation by signal is intended for masking a specific state character sequence in the ASCII vector file.

The evaluation method is determined by the mapping operator. If the normal mapping operator ‘>' is used, or no mapping operator is present at all, the definition is evaluated by channel. For evaluation by signal, a special mapping operator ‘>' must be used. Note that the two mapping operators cannot be combined within one definition block.
