# Creating a STIL Reader setup file

A STIL Reader setup file allows you to control a wide range of aspects of the conversion process. You can create it with any text editor or in the configuration tab of the STIL Reader window.

## About this task

Create a setup file when STIL Reader's [command line options](<02.11.01.05.02_STIL_Reader_command_line_options.md>) do not provide the desired degree of control or when you are using the STIL Reader window.

## Procedure

-  In any text editor, create a new file. If you are using the STIL Reader window, click Configure and then New Setup File.

You can also create a copy of one of the sample setup files at /opt/93000/stilrw/examples or use the template created with the -template command line option as a starting point.

Instead of a generic text editor, you can also use the STIL Reader window to create a setup file by clicking the New Setup File button in the configuration tab.

-  Add and edit options as desired.

For descriptions of the available options, see [STIL Reader setup file](<02.11.01.05.03_STIL_Reader_setup_file.md>).

-  Save the file.

There is no standard file name extension for setup files (although .setup and .py are common).

No special location is required for the file; you can save it in any convenient directory.

## Results

You can now use the setup file in a conversion by specifying it on the command line using the -setup option.

## Example

For a sample setup file, see [STIL Reader setup file](<02.11.01.05.03_STIL_Reader_setup_file.md>).
