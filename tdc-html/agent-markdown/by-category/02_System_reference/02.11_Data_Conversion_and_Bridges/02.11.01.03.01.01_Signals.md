# Signals

The information from the STIL signals block is used to create the V93000 configuration file:

- The signal name is used as the pin name in the target V93000 program.
- Signal direction (In, Out, or InOut) is used by STIL Reader to define the pin direction in the configuration file.
- Active STIL SignalGroups domains define V93000 groups. The active SignalGroups domain is selected in the PatternExec block. (See example 2.)

STIL Reader uses the STIL Environment block to define channel allocation. The name maps that define channels must start with `93000Channel` followed by a semicolon and the configuration name (for example, `93000Channel:Standard`). Multiple name maps are allowed for defining multiple configuration files, with the second part of the name maps name serving as the file name (Standard.cha in example 3, below).

## Examples

### Example 1

```
STIL signals block:
Signals {
    "jtag_tdi" In;
    "jtag_tms" In;
    "jtag_tck" In;
    "jtag_trst_" In;
    "jtag_tdo" Out;
}
```

Corresponding V93000 definition:

```
hp93000,config,0.1
DFPN 10301,"",(jtag_tck)
DFPN 10302,"",(jtag_tdi)
DFPN 10303,"",(jtag_tdo)
DFPN 10304,"",(jtag_tms)
DFPN 10305,"",(jtag_trst_)

CONF I,F160,(jtag_tdi,jtag_tms,jtag_tck,jtag_trst_)
CONF O,F160,(jtag_tdo)
```

### Example 2

STIL SignalGroups block:

```
SignalGroups {
  "clock_s" = '
    "clk[1]"
    + "clk[2]"
  ';
  "in_s" = '
    "jtag_tdi"
    + "jtag_tms"
    + "jtag_tck"
    + "jtag_trst_"
}
```

Corresponding V93000 group definition:

```
DFGP I,(clk[1],clk[0]),(clock_s)
DFGP I,(jtag_tdi,jtag_tms,jtag_tck,jtag_trst),(in_s)
```

STIL Reader uses the STIL Environment block to define channel allocation. The name maps that define channels must start with "93000Channel" followed by a colon and the configuration name (for example, "93000Channel:Standard"). Multiple name maps can be used to define multiple configuration files, with the second parts of the name map names serving as the file names. (Standard.cha in the example above.)

### Example 3

STIL channels block:

```
Environment "Default" {
  NameMaps "93000Channel:Standard" {
    Signals {
      "clk[1]" "11025,Pin Pad25";
      "clk[2]" "12010,Pin Pad10";
    }
  }
}
```

V93000 channel definitions:

```
DFPN 11025,"Pad25",(clk[1])
DFPN 12010,"Pad10",(clk[2])
```
