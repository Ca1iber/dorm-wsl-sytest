# State Character Lists and References

Instead of a single state character, you can also specify a state character list, the wildcard character *, or a reference. The purpose of these notational devices is to reduce the coding effort for the x-mode control file.

A sequence containing a list of n state characters is a generic notation for n sequences each of which contains a different element of the list in the respective column, but is otherwise identical with all the others. The list is marked off by brackets.

The wildcard character * is a special case of such a list. It stands for the list of all state characters that are defined for the respective combination of ASCII device cycle and pins.

As an example, consider the specifications for pin group input in the previous figure. This can be abbreviated by using a state character list as

PINS input

[01Z]11

You can also specify a state character list in more than one column. Thus

DDC dvc dvc dvc

PINS input

[01][01][01]

is shorthand for all possible sequences of length 3 that can be generated from the state characters 0 and 1.

When a sequence contains in position j a reference to position i, this means that the state character in position j is to be the same as the one in position i. A reference is coded by a backslash followed by the position referred to. Thus the sequence Z11 could also be coded as Z1\2. References are useful in combination with state character lists. Consider the following block:

DDC dvc dvc dvc

PINS input

111

010

Z1Z

This can be abbreviated to one line by combining a state character list with a reference as follows:

DDC dvc dvc dvc

PINS input

 [01Z]1\1
