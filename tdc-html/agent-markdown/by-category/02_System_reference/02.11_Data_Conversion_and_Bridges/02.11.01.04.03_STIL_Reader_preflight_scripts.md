# STIL Reader preflight scripts

STIL Reader automatically executes two preflight scripts if they are present. This lets you perform housekeeping tasks and prepare files for conversion in an automated way.

## Script location

Whenever STIL Reader performs a conversion, it checks for the presence of two files:

- System-level script: /etc/stilrw.d/stilreader.conf
- User-level script: ~/stilreader.conf

## Script content

The script files must be executable files. Other than that, no restrictions are placed on their nature or content. STIL Reader does not interact with the scripts (other than telling the system to launch them and passing them parameters, as described below) and does not evaluate any result codes they may return.

## Script execution

If the script files are present, STIL Reader executes them automatically before each conversion.

If both files are present, the system-level script is executed before the user-level script.

STIL Reader passes all command line options that have been specified for this conversion to the scripts.
