# Batch Mode and Interactive Mode

#### Subtopics

- [Batch Mode and Interactive Mode](<02.11.02.04.02.01_Batch_Mode_and_Interactive_Mode.md>)
- [Interactive Mode](<02.11.02.04.02.02_Interactive_Mode.md>)

The two restoration steps can be performed in one call (batch mode), or with two calls (interactive mode) of b2a. The interactive mode allows the user to modify the output of the timing reconstruction before it is used as input for the vector retranslation.
