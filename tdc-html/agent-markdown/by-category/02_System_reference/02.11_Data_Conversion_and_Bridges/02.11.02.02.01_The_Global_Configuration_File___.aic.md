# The Global Configuration File (*.aic)

#### Subtopics

- [The GROUPS Section](<02.11.02.02.01.02_The_GROUPS_Section.md>)
- [The AI_V2B_OPTIONS Section](<02.11.02.02.01.03_The_AI_V2B_OPTIONS_Section.md>)
- [The AI_DIR_FILE Section](<02.11.02.02.01.04_The_AI_DIR_FILE_Section.md>)
- [The DELETE Section](<02.11.02.02.01.05_The_DELETE_Section.md>)
- [Making Use of the Output Version](<02.11.02.02.01.06_Making_Use_of_the_Output_Version.md>)

The configuration file for ait, which has the standard extension *.aic, is conceived as a global input file for the whole translation process, that is, not only for the timing translation, but also for the vector translation. Thus, it contains vector related information as well as timing related information. The vector related information is transferred by ait to the vector configuration file (*.aiv) or to a pattern configuration file (*.vbc); see [The Vector Configuration File](<02.11.02.03.01_The_Vector_Configuration_File.md>) and [The Pattern Configuration File (*.vbc)](<02.11.02.03.05_The_Pattern_Configuration_File___.vbc.md>), respectively.

The global configuration file exists in two versions within the ASCII interface. One version is the primary input file for ait. The other version is created by ait. This output version contains further information, which is generated by ait, and can be used as a secondary input file if you call ait from a user procedure and want to extend or modify an already existing timing.

The global configuration file consists of several sections. The most important ones are the PATTERNS and the GROUPS sections. The other sections are the AI_DIR_FILE section, the AI_V2B_OPTIONS section, and the DELETE section. The PATTERNS section is mandatory, all the other sections, including the GROUPS section, are optional. The order of the sections is arbitrary, and several sections of the same type are allowed to occur in the file.

The AI_DIG_CAPT_SETTINGS section, which defines digital capture settings, can be defined in the global configuration file, but is simply transferred to the vector configuration file. It is described in [The AI_DIGCAP_SETTINGS section](<02.11.02.03.01.05_The_AI_DIGCAP_SETTINGS_section.md>).

You can insert comments into the file. These are identified by the hash character (#). If this character occurs in a line, the rest of the line after the hash character will be interpreted as a comment.
