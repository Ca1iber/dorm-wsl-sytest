# Using high-voltage pins

By default, STIL Reader treats all pins as standard voltage pins. It is possible to designate pins as high-voltage pins with the high_voltage_signals

## Specifying pins

To specify any signals as high-voltage pins, you must list them in the high_voltage_signals parameter of the [STIL Reader setup file](<02.11.01.05.03_STIL_Reader_setup_file.md>). This parameter is described in [Translation-related STIL Reader setup options](<02.11.01.05.03.03_Translation-related_STIL_Reader_setup_options.md>).

Note that these keywords are available only for Smart Scale platforms; that is, the target parameter in the setup file must be set to 93000SS. Note, too, that not all pins are available as high-voltage pins. Check the card specifications for details.

## Specifying voltage values

To specify high-voltage vhh or v3h values, describe a second value for the VIH voltage in the STIL file.

To do so, define a DC level block (using DCLevels) that contains a signal group in which two VIH signals are defined, vih and vt. (See the Example section, below, for how this might look.)

## Specifying waveforms

To the signal group you have defined, assign waveforms in which U0 and U1 are assigned to valid waveform characters. (U1 indicates a drive-high event using the second value of the VIH resource.) Specify the Z edge to drive these events.

## Example

These code snippets, when inserted into a STIL file, specify two high-voltage levels and then assign the U0 and U1 timing actions to the 1 and 3 characters, respectively, for these levels.

```
// Specify a DC level set for high-voltage pins
DCLevels DCL_HVLevel {
  IN0 { VIH 'vih', 'vt'; // Specify multiple drive high levels
        VIL 'vil'; }
}

//
Timing {
  WaveformTable normal {
    Period 'per';
    Waveforms {
      "IN0" {
        013 { '0ns' D/U0/U1; }
        LHX { '0ns' Z; 'per*1/2' L/H/X; }
      }
    }
  }
}
```
