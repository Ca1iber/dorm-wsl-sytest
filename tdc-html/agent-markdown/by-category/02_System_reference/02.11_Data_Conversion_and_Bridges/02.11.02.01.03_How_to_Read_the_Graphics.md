# How to Read the Graphics

This document contains many graphics that illustrate aspects of the translation process. All these graphics are built up from the same elements:

- Sections of files that serve as input files for the translation. These are framed with a thin line. Note that files that serve both as output and input files (for example, the timing map file) also have a thin frame.
- Sections of SmarTest setup files. These are framed by a thick line.
- Intermediate processing results that are not stored in a file. These are framed by a dotted line.

All comments on the file excerpts are in red (grey). These are:

- Rectangles that enclose data within the file sections. The graphic explains the processing of this data.
- Red (grey) circles or ellipses. These contain explanations of the processing.
- Arrows leading from one or more input rectangles to a processing comment, or leading from a processing comment to one or more output rectangles and/or processing comments. These arrows indicate the processing flow.

The following figure shows an example:

  ![Unifying ASCII Device Cycles with Different Periods for ctim set to NCT](<../../../../raw/46151.png>)

This graphic explains three calculations. The global configuration file and the ASCII timing file provide the input. The output of the first and second calculation is written into the timing setup file, that of the third into the timing map file. The result of the first calculation also serves as input for the second and the third calculation. For more information on this example see [The Input Columns](<02.11.02.02.01.01.01_The_Input_Columns.md>).

 Note The pin configuration file will be omitted from the graphics, except when it contains important information for a certain feature (for example, multi-port and continuous clock setups (port definitions), and NP setups.
