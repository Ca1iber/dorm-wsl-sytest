# V93000 break waveforms

The information of a STIL BreakPoint block is used to create V93000 break waveforms. The example below shows the use of BreakPoint in STIL and its representation in V93000 timing.

When x-modes are used, a break waveform is constructed from a number of vectors equal to the x-mode. (For example, in the x4 mode, four vectors are used for the break waveform.) STIL Reader also verifies that the content of the STIL BreakPoint block is repetitive.

## Example

Sample STIL break point:

```
Timing {
  WaveformTable T1 {
    Period '100ns';
    Waveforms {
        clk    { P  { '0ns' D; '25ns' U; '75ns' D; } }
    }
  }
}

Pattern Clocks {
  W T1;
  BreakPoint {
    V { clk = P; }
  }
}
```

Resulting 93000 break waveform:

```
WAVETBL "T1"
PINS clk
0 "d1:0 d2:F1N d3:F0N" P
brk "d1:0 d2:F1N d3:F0N"
...
EQNSET 1 "T1"
PINS clk
d1 = 0.0
d2 = 25.0
d3 = 75.0
```

When x-modes are used, break waveform are constructed from a number of vectors equal to the x-mode factor. STIL Reader also verifies whether the contents of the STIL BreakPoint block is repetitive.

- Introduced before SmarTest 6.3.2
