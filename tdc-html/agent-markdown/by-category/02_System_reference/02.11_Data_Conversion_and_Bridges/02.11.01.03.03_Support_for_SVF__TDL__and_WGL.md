# Support for SVF, TDL, and WGL

In addition to STIL, STIL Reader also supports SVF, TDL, and WGL as input formats.

SVF, TDL, and WGL files are processed by first converting them to STIL and then handling them as STIL files. See below for an example of this preprocessing conversion.

## Example

Consider this WGL input file:

```
waveform project
  signal
    "data":input;
  end
  timeplate "t1" period 100ns
    "data" := input [0ns:D, 50ns:S];
  end
pattern P1 ("data")
  vector(+,"t1") := [0];
  vector(+,"t1") := [1];
  vector(+,"t1") := [X];
end
end
```

Specifying it as the file to convert causes STIL reader to transparently convert it into this STIL file.

```
Signals {
  "data" In;
}

Timing {
  WaveformTable "t1" {
    Period '100ns';
    Waveforms {
      "data" {
        DUNZ { '0ns' D; '50ns' D/U/N/Z; }
      }
    }
  }
}

PatternBurst "w1_burst" {
  PatList {
    "P1";
  }
}

PatternExec "w1_exec" {
  PatternBurst "w1_burst";
}

Pattern "P1" {
  W "t1";
  V { "data"=D; }
  V { "data"=U; }
  V { "data"=N; }
}
```

This intermediate STIL file is then converted to V93000 as usual.
