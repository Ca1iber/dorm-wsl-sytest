# ASCII Device Cycles

The input information is organized by so-called ASCII device cycles. An ASCII device cycle is a complete timing description of the DUT for a certain DUT cycle length. More than one ASCII device cycle may be needed for one test.

Every ASCII device cycle contains a set of state characters for every pin of the DUT. Every state character represents a signal that is sent to a certain pin of the DUT. The state characters are defined in the ASCII timing file and used in the ASCII vector file.

For an example excerpt of an ASCII device cycle, see the figure in [ASCII Timing File](<02.11.02.01.01.02_ASCII_Timing_File.md>) section.
