# SmarTest Data Link licenses and components

SmarTest Data link (STDL) is a collection of tools that you can use to create an integrated workflow from your design tools to SmarTest. Depending on your specific needs, you can choose between different licenses, each of which combines a particular set of tools.

See the overviews below for information which license encompasses which tools and which tools are available.

## Tools

SmarTest Data Link comprises these tools:

- STIL Reader: Translates from STIL to V93000 formats.

The STIL Reader [manual](<02.11.01_STIL_Reader.md>) is available in the TDC.

-

STILEditor: Transforms STIL files based on rules.

The STILEditor [manual](<../../../../pdf/stileditor_manual.pdf>) is available as a PDF.

- EVCD to STIL Translator: Translates from EVCD to STIL.

The EVCD to STIL Translator [manual](<../../../../pdf/vcdstil_manual.pdf>) and [tutorial](<../../../../pdf/vcdstil_tutorial.pdf>) are available as PDFs.

- STIL Timing Editor: Edits STIL files.

The STIL Timing Editor [manual](<../../../../pdf/ste_manual.pdf>) is available as a PDF.

- EVCD to 93000 Translator: Translates from EVCD to V93000 formats.

The EVCD to 93000 Translator [manual](<../../../../pdf/vcd93k_manual.pdf>) and [tutorial](<../../../../pdf/vcd93k_tutorial.pdf>) are available as PDFs.

- Waver: Graphically displays EVCD, WGL, and STIL data.
- STIL Testbench Generator: Translates from STIL to Verilog test bench formats.

The STIL Testbench Generator [manual](<../../../../pdf/stilbench_manual.pdf>) is available as a PDF.

- 93000 Testbench Generator: Translates from V93000 formats to Verilog test bench formats.

The 93000 Testbench Generator [manual](<../../../../pdf/93kbench_manual.pdf>) and [tutorial](<../../../../pdf/93kbench_tutorial.pdf>) are available as PDFs.

- SmarTest Program Manager (STPM): Automatically integrates test suites into a test program and reuses test suites from other programs.

The SmarTest Program Manager [manual](<../02.09_Test_Program_Management/02.09.02_SmarTest_Program_Manager.md>) is available in the TDC.

- SmarTest Program Manager MCM (STPM MCM): Combines test programs for individual modules in a multichip or multicore device into a test program for the overall device.

The STPM MCM [manual](<../02.09_Test_Program_Management/02.09.03_SmarTest_Program_Manager_MCM.md>) is available in the TDC.

Note that using these tools requires the appropriate license package, as described below.

## Licenses

The available licenses include:

- SmarTest Data Link - STIL/WGL

This license includes:

  - STIL Reader

- SmarTest Data Link - VCD/EVCD

This license includes:

  - STIL Reader
  - EVCD to STIL Translator
  - STIL Timing Editor
  - Waver

- SmarTest Data Link - Simulator Link

This license includes:

  - 93000 Testbench Generator
  - STIL Testbench Generator

- SmarTest Program Manager

This license includes:

  - STIL Reader
  - SmarTest Program Manager
  - SmarTest Program Manager MCM
  - EVCD to 93000 Translator
