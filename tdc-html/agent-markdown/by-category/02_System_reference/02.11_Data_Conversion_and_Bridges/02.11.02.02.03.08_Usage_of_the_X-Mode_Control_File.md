# Usage of the X-Mode Control File

If ait is called with an x-mode control file, then for any x-mode factor > 1, no ASCII device cycle combination that is not defined in this file is processed by the timing translation. This holds for every pin and every ASCII device cycle. You can define the admitted combinations for more than one x-mode factor for the same ASCII device cycle in the same control file.

The name of the x-mode control file is passed to ait with the -k parameter. If -k is present, ait uses the file specified by this parameter. If the -k parameter is omitted, ait will apply an x-mode control file nonetheless, if

- a global name for input files is defined with the -i parameter, or for all files with the -b parameter, and
- an x-mode control file with this name and the extension *.cmb exists in the input directory.
