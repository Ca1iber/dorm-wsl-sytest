# Merging State Character Definitions: The OPTIONS Statement

Within an ASCII device cycle, more than one timing record is allowed to exist for the same pin. In this case, the default behavior of the timing translation is to process only the last of these records. However, you can cause it to merge the different timing records in such a way that a waveform is created for every state character occurring in any of these timing records. Furthermore, you can force the merge of different definitions for the same state character in the different timing records (provided the definitions are compatible). This can be used, for example, to reduce the coding effort by specifying identical data records for different pins only once, or to expand a common base definition in different ways.

The merge is switched on and off with the optional OPTIONS statement. This statement can be inserted anywhere between two ASCII device cycles . It is valid until anotherOPTIONS statement occurs, or the file ends.

The format of the OPTIONS statement is as follows:

OPTIONS (M|ML|O|S)

The meaning of the individual options is as follows:

- M: This option (for "Merge") causes the timing translation to create waveforms for any state character that is defined in any timing record within the same ASCII device cycle.
- ML: This compound option has the effect that in addition, different definitions of the same state character are merged even if they belong to different timing records, provided that they are compatible.
- O: This option (for "Overwrite") causes the timing translation to process only the last of several timing records for the same pin within one ASCII device cycle. Different definitions of the same state character within one timing record are merged if they are compatible. This is the default.
- S: This option (for "Subtract") causes the timing translation to recognize a minus sign in the PINS statement of the timing records as a subtracting operator. This serves to exclude certain pins or pin groups from a pin group.

As an example, consider the following timing record:

PINS input - CP

0 0:1.00

If OPTIONS has been set to S, this timing record will be applied to all pins of the pin group input except CP.

The following simple ASCII timing file illustrates the options M and L:

DVC normal

period= 12

PINS CP DS0

0 F00:3.00

1 F10:3.00

PINS DS0

Z F0Z:0.00

1 F10:0.00

If this file would be preprocessed with the options O, M, and ML, respectively, the results would be as follows:

 |

OPTIONS O

 |

OPTIONS M

 |

OPTIONS ML

 |
 |

DVC normal

period = 12

PINS CP

0 0:3

1 1:3

PINS DS0

Z F0Z:0

1 1:0

 |

DVC normal

period = 12

PINS CP

0 0:3

1 1:3

PINS DS0

0 0:3

1 1:0

Z F0Z:0

 |

DVC normal

period = 12

PINS CP

0 0:3

1 1:3

PINS DS0

0 0:3

1 1:0 1:3

Z F0Z:0

 |

The timing record for pin DS0 contains one more data record with option M than with option O, and the definition of state character 1 for DS0 contains one more event with option ML than with option M.

You can check the results of the merge if you call the low level tool d2w directly with the-D parameter. This will cause d2w to create an output ASCII timing file.
