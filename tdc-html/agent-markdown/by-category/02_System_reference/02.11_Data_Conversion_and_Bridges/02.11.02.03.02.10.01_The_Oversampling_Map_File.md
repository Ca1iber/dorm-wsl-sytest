# The Oversampling Map File

The oversampling map file defines the rules for the discarding mechanism. It may be used not only to discard repeated vectors, but in general to convert arbitrary blocks of ASCII vectors for a port into one single vector. The definitions in the oversampling file map a column of an ASCII vector block (a sequence of state characters) to a single state character.

The generality of the mechanism explains why the format of the oversampling map file, which is similar to that of [The Timing Map File](<02.11.02.03.04_The_Timing_Map_File.md>), is more complex than might at first be expected. The file has the following form:

[STATE_WILDCARD <wildcard_char>]

PINS <list_of_pins_or_ports_1>

DDC <ASCII_dvc_1> <ASCII_dvc_2> ... <ASCII_dvc_n>

DDC_OUT <output_ASCII_dvc>

<s_ch_1_1><s_ch_2_1>...<s_ch_n_1> <t_ch_1>

<s_ch_1_2><s_ch_2_2>...<s_ch_n_2> <t_ch_2>

...

PINS <list_of_pins_or_ports_2>

...

The function of the individual lines is as follows:

- STATE_WILDCARD <wildcard_char> (optional): This line defines the wildcard character which serves as a place holder for any state character.
- PINS <list_of_pins_or_pin_groups_i> (mandatory): This line defines (the pins of) a port to the vectors of which a reduction is to be applied.
- DDC <ASCII_dvc_i> (mandatory): This line defines the length of the block that is to be converted into a single vector, and for each ASCII vector of the block the ASCII device cycle to which it belongs. The same device cycle name can occur more than once; in fact, the most common case will be that the sequence is "homogeneous", that is, that the same device cycle name is specified for every <ASCII_dvc_i>.
- DDC_OUT <ASCII_dvc_i> (mandatory): This line defines the ASCII device cycle to which the single target vector will belong.
- <s_ch_i_k> <t_ch_k> (mandatory): Each of these lines specifies a mapping from a sequence of state characters to a single state character. The length of the state character sequence must equal the length of the ASCII device cycle sequence in the preceding DDC statement.
