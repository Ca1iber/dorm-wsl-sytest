# The AI_V2B_OPTIONS Section

This section of the [Vector Configuration File](<02.11.02.03.01_The_Vector_Configuration_File.md>) specifies v2b parameters that are to be applied to the vector translation of all patterns in the PATTERNS section. If the specifications of this section contradict those of the v2b_options column (see [The PATTERNS Section](<02.11.02.03.01.01_The_PATTERNS_Section.md>)) for a specific pattern, the v2b_options column has priority.

There is one option that can only be specified in the AI_V2B_OPTIONS section, not in the PATTERNS section:

```
-cmb <x-mode_control_file>
```

For more information on this option see [Adapting the X-Mode Control file to the ASCII Vector Files](<02.11.02.02.03.06_Adapting_the_X-Mode_Control_file_to_the_ASCII_Vector_Files.md>).
