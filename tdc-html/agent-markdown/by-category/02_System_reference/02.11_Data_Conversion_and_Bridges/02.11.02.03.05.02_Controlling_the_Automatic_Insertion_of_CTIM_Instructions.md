# Controlling the Automatic Insertion of CTIM Instructions

#### Subtopics

- [Inserting CTIM Between Vectors](<02.11.02.03.05.02.01_Inserting_CTIM_Between_Vectors.md>)
- [Inserting CTIM Between Patterns](<02.11.02.03.05.02.02_Inserting_CTIM_Between_Patterns.md>)

A CTIM instruction must be inserted into the sequencer program of a pattern in the following two situations:

- Two successive ASCII vectors within the pattern belong to different ASCII device cycles, and these ASCII device cycles are associated with different timing sets.
- Two successive patterns within a (multi-port) burst, or a subpattern and the pattern from which it is called, are associated with different timing sets.

If you create both the timing and the vector setup with the ASCII interface, the information required for these insertions is passed from the timing translation to the vector translation in the pattern configuration files (or the vector configuration file). Based on this information, the vector translation will automatically insert the CTIM instructions required by the timing into the sequencer programs of the patterns.

This feature not only greatly reduces the manual coding effort, it also allows you to combine the same ASCII vector file with different timings. As a rule, you should therefore refrain from inserting CTIM instructions manually into the ASCII vector files.
