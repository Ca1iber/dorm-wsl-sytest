# The AIV_OPTIONS Environment Variable

With this environment variable, you can change the default behavior of aiv with respect to retranslation of patterns for which binary vector files already exist. By default, the pattern is only retranslated it at least one of the input files has a later timestamp than the corresponding binary vector file.
