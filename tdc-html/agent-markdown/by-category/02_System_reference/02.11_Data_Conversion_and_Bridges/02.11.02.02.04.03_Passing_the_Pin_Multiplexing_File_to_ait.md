# Passing the Pin Multiplexing File to ait

The name of the pin multiplexing file is passed to ait with the -X parameter. If -X is present, ait uses the file specified by this parameter. If the -X parameter is omitted, ait will apply a pin multiplexing file nonetheless, if

- a global name for input files is defined with the -i parameter, or for all files with the -b parameter, and
- a pin multiplexing file with this name and the extension *.mux exists in the input directory.Note The pin multiplexing file is passed globally to ait. But it is this does not imply that all patterns in the PATTERNS section must use multiplexing in this case. The file is only applied to a pattern if the ASCII device cycles used by this pattern contain multiplexed pins.
