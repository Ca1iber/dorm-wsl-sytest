The STIL Reader setup file lets you control the operation of the STIL Reader in great detail.

Which setup file STIL reader is to use during a particular conversion is specified with the -setup [command line option](<02.11.01.05.02_STIL_Reader_command_line_options.md>).

Setup files do not require a specific file name extension, although .setup and .py are common.

## Syntax

The options available in the setup file are described according to the functional categories to which they belong. See the following sections for details on the various options:

- [Project-related options](<02.11.01.05.03.01_Project-related_STIL_Reader_setup_options.md>) specify what is to be translated.
- [Test-processing parameters](<02.11.01.05.03.02_Test-processing_STIL_Reader_setup_options.md>) specify the target platform for the translation.
- [Translation-related options](<02.11.01.05.03.03_Translation-related_STIL_Reader_setup_options.md>) control the translation process, in particular concerning variations between the source and target environments.
- [AIF-related options](<02.11.01.05.03.04_AIF-related_STIL_Reader_setup_options.md>) control translations of ASCII Interface files.
- [SVF-related options](<02.11.01.05.03.05_SVF-related_STIL_Reader_setup_options.md>) control translations of SVF files.
- [WGL-related options](<02.11.01.05.03.07_WGL-related_STIL_Reader_setup_options.md>) control translations of WGL files.
- [TDL-related options](<02.11.01.05.03.06_TDL-related_STIL_Reader_setup_options.md>) control translations of TDL files.

## Examples

```
# Use absolute paths
absolute_paths = 1

# Device cycle renaming
dcdf_remapping = { 'default_WFT_1' : 'U',
                   'default_WFT_0' : 'D' }

# Compress patterns with GZip.
gzip_patterns = 1

# Disable comments in timing files.
tim_comments = 0

# Use EQFS commands in timing and level files.
use_eqfs = 1

# Apply Xmode factor to all patterns
xmode_factor = 2

# Create all possible Xmode combinations in timing files
xmode_all_cmb = 1
```

You can generate an extensive commented template using this command:

```
/opt/93000/stdl/bin/stilreader -template
```
