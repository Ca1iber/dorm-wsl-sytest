# Calling aiv

#### Subtopics

- [The Parameters of aiv](<02.11.02.03.07.01_The_Parameters_of_aiv.md>)

The aiv tool is located in /opt/93000/aif/aiv/bin. It is called from the command line by entering aiv with the appropriate parameters. These parameters are described in the following section.

aiv collects the messages of the individual v2b calls in a log file *.v2blog.
