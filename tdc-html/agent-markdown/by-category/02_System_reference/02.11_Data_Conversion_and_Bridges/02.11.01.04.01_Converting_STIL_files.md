# Converting STIL files

#### Subtopics

- [Files generated in the translation](<02.11.01.04.01.01_Files_generated_in_the_translation.md>)
- [Naming of blocks and elements](<02.11.01.04.01.02_Naming_of_blocks_and_elements.md>)

To convert a STIL using STIL Reader, you call it from the command line using appropriate options or set up the conversion as desired in the STIL Reader window. For more detailed control of the conversion process, you can specify a settings file. In addition, preflight scripts may be automatically called.

## About this task

Use this procedure to convert a STIL file (conforming to the STIL 1450-1999, 1450.1, or 1450.2 standards) to V93000 setup and vector files.

## Before you begin

Make sure that you have a standards-compliant STIL file.

If you want to use a setup file for controlling the conversion, prepare the setup file as described in [Creating a STIL Reader setup file](<02.11.01.04.02_Creating_a_STIL_Reader_setup_file.md>). (Alternatively, if you convert the files using the STIL Reader window, you can create the file during the conversion process.)

If you want to use preflight scripts, set them up as desired. This is described in [STIL Reader preflight scripts](<02.11.01.04.03_STIL_Reader_preflight_scripts.md>).

You can convert files using the STIL Reader window or from the command line. Both procedures are described below.

## Procedures

### Using the STIL Reader window

When using the STIL Reader window, you first specify the files to convert, then the setup file to use, and then start the conversion process.

- Open the [STIL Reader window](<02.11.01.05.01_STIL_Reader_window_reference.md>) by entering /opt/93000/stdl/bin/stilreader-gui in a terminal window.
- Click Add Input Files.

A standard Open dialog is displayed.

Note: If the Add Input Files button is not visible, click Add Input Files to display it.

- In the Open dialog, select all STIL files that you want to convert and click Open.

You can shift-click or control-click to select multiple files.

The selected files are displayed in the file list of the STIL Reader window.

- If you want to add to or remove from the list of files:

  - To add STIL files for conversion, repeat step 3.
  - To remove files from the list, select them and click Remove Selected.

- When the file list contains all the files that you want to convert, click Configure.

The configuration tab is displayed.

- Specify the [setup file](<02.11.01.05.03_STIL_Reader_setup_file.md>) to use:

  - If you want to use an existing file, click Load Setup File and choose the desired file.
  - If you want to create a new file, click New Setup File.

A new setup file based on the setup file template is displayed in the file area.

- Edit the file as desired.

Your changes apply to the next conversion if you want to keep them for future uses as well, save them to disk by clicking Save Setup or Save Setup As.

- Click Convert.

The conversion tab is displayed.

- Click the Run button beside the progress bar to start the conversion process.

STIL Reader converts the files in the order in which they are contained in the list. The progress of the conversion is indicated by the progress bar and by the update of the files' statuses in the file table.

### Using the command line

- Open a terminal.
- Enter /opt/93000/stdl/bin/stilreader command using the appropriate options:

  - To specify a setup file, use the -setup option.
  - To specify the desired output directory, use the -workdir option. By default, the output subdirectory of the current directory is used.
  - To specify the project name, on which the names of many converted files are based, use the -project_name option. By default, "project" is used as the project name.
  - Specify the STIL file you want to convert as the last parameter.
  - Other options are described in [STIL Reader command line options](<02.11.01.05.02_STIL_Reader_command_line_options.md>).

- Press the Enter key to execute the command.

## Results

STIL Reader converts the specified file with the chosen options. The translated V93000 files are placed in the specified work directory.

See [Files generated in the translation](<02.11.01.04.01.01_Files_generated_in_the_translation.md>) for details about which files are generated.

## What to do next

Test the translated files.
