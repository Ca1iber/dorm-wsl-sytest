# Features not Supported by the b2a Tool

Currently, b2a is subject to the following restrictions:

- A continuous clock (PLL) will not be detected
- Fractional x-modes will not be detected
- Equation sets without a SPECS section will not be translated
- Shots will not be detected
- Agilent 83000 setups will not be translated
- Source Synchronous Bus (SSB) and First In First Out (FIFO) for differential pins using NP will be ignored
- Timing set changes within the pattern will not be adequately processed (see [Basic Operation of b2a](<02.11.02.04.01_Basic_Operation_of_b2a.md>))
- Extraction of a subset of pins is not possible
- Extraction of a port burst from a multi-port burst is not possible
- Pin multiplexing will not be detected
- DEFAULT_STATE definitions will not be reconstructed
- Memory test and scan test are not supported
- b2a does not support setups containing expression based pin names.
