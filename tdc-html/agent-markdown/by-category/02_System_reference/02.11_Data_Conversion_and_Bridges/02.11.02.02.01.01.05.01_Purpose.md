# Purpose

This feature is intended for two purposes:

- You can use it to reduce the number of receive edges required for output pins. For if two compare actions of the same state character definition are distributed among two shots, the same edge can be used for both of them. The different delays are realized by defining different timing sets for the two shots. See "Example 1" [The Global Configuration File (*.aic)](<02.11.02.02.01_The_Global_Configuration_File___.aic.md>).
- With an x-mode factor > 1, it can be used to reduce the number of waveforms that are generated for output pins. See "Example 2" [The Global Configuration File (*.aic)](<02.11.02.02.01_The_Global_Configuration_File___.aic.md>).

The drawback of working with shots is that n shots require n times as much Vector Memory and execution time.
