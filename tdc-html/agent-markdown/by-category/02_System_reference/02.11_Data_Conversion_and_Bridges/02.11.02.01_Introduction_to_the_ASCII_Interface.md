# Introduction to the ASCII Interface

#### Subtopics

- [Basic Translation Concept](<02.11.02.01.01_Basic_Translation_Concept.md>)
- [High Level Tools and Low Level Tools](<02.11.02.01.02_High_Level_Tools_and_Low_Level_Tools.md>)
- [How to Read the Graphics](<02.11.02.01.03_How_to_Read_the_Graphics.md>)

This chapter introduces to the basic translation concept of the ASCII interface and gives an overview of its module structure. It is intended for readers who have a good knowledge of SmarTest, but know nothing about the ASCII interface. Its purpose is to supply this target audience with the information that is needed to understand the following chapters.

The chapter consists of three sections:

- The first section, [Basic Translation Concept](<02.11.02.01.01_Basic_Translation_Concept.md>), describes the essentials of the translation process. It explains the fundamental concept of an ASCII device cycle, describes the two main input files for the tool (ASCII timing file and ASCII vector file), and shows how timing translation and vector translation, the two main parts of the ASCII interface, interlock.
- The second section, [High Level Tools and Low Level Tools](<02.11.02.01.02_High_Level_Tools_and_Low_Level_Tools.md>), explains that for both timing and vector translation there is a high level user interface and a low level module that is called repeatedly by the user interface. It also indicates how the timing translation can create nearly all the information that is needed by the vector translation, except the ASCII vector files.
- The third section, [How to Read the Graphics](<02.11.02.01.03_How_to_Read_the_Graphics.md>), explains the components of the graphical examples, of which there are a great number in this document.
