# Using One ASCII Vector File for Several Ports

It is possible to keep the ASCII vectors for a multi-port setup in a single file. If you specify this file as the *.avc file for a pattern that is associated with one of the ports in question, the vector translation will only process those columns of the file that belong to the specified port.
