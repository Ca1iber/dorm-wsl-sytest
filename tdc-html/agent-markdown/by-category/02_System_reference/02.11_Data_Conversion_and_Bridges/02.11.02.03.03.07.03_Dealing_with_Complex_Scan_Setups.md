# Dealing with Complex Scan Setups

The example displayed in [Converting an ASCII Scan Setup Into a Binary Multi-Port Setup](<02.11.02.03.03.07_Converting_an_ASCII_Scan_Setup_Into_a_Binary_Multi-Port_Setup.md>) contains only one scan template. But the multi-port conversion can also handle ASCII vector files with more than one scan template, provided that no pin is associated with more than one of these. If more than one template is present, a separate pattern with a separate port must be specified in the vector configuration file for every template. The pins that do not occur in any template are put into the parallel port. Note that the restriction to non-overlapping templates is not required for normal (scan tool) scan setups.

Scan subroutines (see [Understanding Scan Subroutines](<02.11.02.03.03.05.01_Understanding_Scan_Subroutines.md>)) cannot be converted into a multi-port setup.
