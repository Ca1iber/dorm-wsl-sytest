# STIL Reader additions to the STIL standard

#### Subtopics

- [DCapFilter](<02.11.01.05.04.01_DCapFilter.md>)
- [DCapSetup](<02.11.01.05.04.02_DCapSetup.md>)

To fully support the capabilities of the V93000 and streamline conversions, STIL Reader introduces some new objects as well as reserved names for existing objects.

## STIL objects

STIL Reader works with these objects in STIL files that are not part of the STIL standard:

- [DCapFilter](<02.11.01.05.04.01_DCapFilter.md>) is used to define parameter sets for digital capture pins.
- [DCapSetup](<02.11.01.05.04.02_DCapSetup.md>) is used to define digital capture pins.

## Reserved names

These names have specific meanings for STIL Reader when used for certain types of STIL objects. Do not use these names for other purposes:

- 93kChannel: The prefix of the name of a NameMaps block that specifies the channel information.
- 93kPorts: The name of a NameMaps object that defines the ports used.
- 93kExtraLevels: The name of a NameMaps object that defines additional DC levels and related options.

## Object definitions

For some objects that are specified in the STIL standard, STIL Reader supports special specification formats in addition to those defined in the standard:

- SignalGroup: The special syntax supported for multiport testing allows the specification of many signal group settings along with the signals themselves.

This is detailed in [Using concurrent (multiport) testing](<02.11.01.04.05_Using_concurrent__multiport__testing.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
