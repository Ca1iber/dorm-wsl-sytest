# The Pattern Configuration File (*.vbc)

#### Subtopics

- [Structure of the Pattern Configuration File](<02.11.02.03.05.01_Structure_of_the_Pattern_Configuration_File.md>)
- [Controlling the Automatic Insertion of CTIM Instructions](<02.11.02.03.05.02_Controlling_the_Automatic_Insertion_of_CTIM_Instructions.md>)

The pattern configuration file is an optional, pattern specific input file for the vector translation. It is generated automatically by the timing translation. If you use the vector translation without the timing translation, you must create this file manually. Note that aiv expects the name of the pattern configuration file to be in the format

<pattern_name>.vbc

The pattern configuration file serves the following purposes:

- It specifies the name of the base wavetable for the pattern.
- It indicates to the vector translation which timing set blocks of the timing map file are to be used for the translation, and where CTIM sequencer instructions must be inserted into the sequencer program of the pattern. For details on the former point, see [Structure of a Timing Map File Block](<02.11.02.03.04.01_Structure_of_a_Timing_Map_File_Block.md>), for details on the latter, see [Controlling the Automatic Insertion of CTIM Instructions](<02.11.02.03.05.02_Controlling_the_Automatic_Insertion_of_CTIM_Instructions.md>).
- If the ASCII device cycle names within the timing, which are used in the timing map file, are different from those in the ASCII vector file, it provides a mapping from ASCII vector device cycles to ASCII timing device cycles for the vector translation.

You can insert comments into the file. These are identified by the hash character (#); if this character occurs in a line, the rest of the line after the hash character will be considered as a comment.
