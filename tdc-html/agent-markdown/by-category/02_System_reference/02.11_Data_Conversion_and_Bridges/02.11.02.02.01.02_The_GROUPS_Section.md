# The GROUPS Section

#### Subtopics

- [Structure of the GROUPS Statements](<02.11.02.02.01.02.01_Structure_of_the_GROUPS_Statements.md>)

Bursts, multi-port bursts, and nested patterns (MAIN patterns calling a subpattern) are all executed in one sequencer run. The GROUPS section informs the timing translation of such pattern groups. The timing translation needs this information for the following reasons:

- The patterns of such a group must share certain elements of the timing setup. Thus, for example, if a subpattern (type SVEC) is to be called from a MAIN pattern, both must share the same equation set and wavetable. This also holds for the MAIN patterns that are contained in one burst.
- If different patterns of the group are associated with different timing sets, CTIM instructions must be inserted between the affected patterns. In this case, there are situations where the default insertion of a CTIM instruction before the first vector of the pattern is not sufficient. Based on the information of the GROUPS section, the timing translation tells the vector translation the positions at which additional CTIM instructions must be inserted. The vector translation then inserts these instructions automatically, as with CTIM instructions between two vectors of one pattern.
