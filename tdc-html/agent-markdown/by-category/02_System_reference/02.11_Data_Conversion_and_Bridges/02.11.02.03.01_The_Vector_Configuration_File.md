# The Vector Configuration File

- [The AI_DIGCAP_SETTINGS section](<02.11.02.03.01.05_The_AI_DIGCAP_SETTINGS_section.md>)

The vector configuration file, which has the standard extension *.aiv, controls the operation of the high level tool aiv. If you use ait to create your timing setup, the vector configuration file will be generated automatically from the information in the global configuration file. If you do not use ait, you must create the vector configuration file manually.

The vector configuration file mainly consists of a [PATTERNS](<02.11.02.03.01.01_The_PATTERNS_Section.md>) section and, optionally, one or more burst or multi-port burst definitions. It can also contain an [AI_V2B_OPTIONS](<02.11.02.03.01.03_The_AI_V2B_OPTIONS_Section.md>),an [AI_DIR_FILE](<02.11.02.03.01.04_The_AI_DIR_FILE_Section.md>) section, and an AI_PLATFORMS statement.

You can insert comments into the file. These are identified by the hash character (#); if this character occurs in a line, the rest of the line after the hash character will be considered as a comment.
