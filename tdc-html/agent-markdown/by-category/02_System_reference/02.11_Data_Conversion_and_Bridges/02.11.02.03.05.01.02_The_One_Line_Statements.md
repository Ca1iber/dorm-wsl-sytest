# The One Line Statements

The one line statements are in alphabetical order:

 (CTIM_AFTER_JSUB|CTIM_BEFORE_JSUB) <subp_name> <new_ts_no>

These two statements cause the insertion of CTIM with the timing set<new_ts_no> after or before a call of subpattern <subp_name>. They are explained in more detail in [Inserting CTIM Between Patterns](<02.11.02.03.05.02.02_Inserting_CTIM_Between_Patterns.md>) .

 INITIAL_CTIM <ts_no>

This statement causes the insertion of a CTIM instruction with the timing set <ts_no> immediately after the STSA instruction of the sequencer program. If the ASCII vector file starts with a sequencer instruction, you can use this statement to place a CTIM instruction before this instruction, whereas by default it would be inserted before the first vector, which would in this case be after the initial sequencer instruction.

Suppose, for example, that the ASCII vector file of the pattern starts with a JSUB sequencer instruction, and you have suppressed the default insertion of CTIM for the subpattern with the v2b option -T. Then you can use the INITIAL_CTIM statement to insert a CTIM instruction into the sequencer program before the JSUB instruction . Another example would be an ASCII vector file that starts with an RPTV instruction.

 SPECIFIED_DVCS_ONLY

This statement causes the vector translation to issue an error message if the ASCII vector file contains an ASCII device cycle that does not occur in the pattern configuration file.

 WAVETBL <wavetable_name>

This statement defines the base wavetable for the pattern. The base wavetable can also be specified with the v2b parameter -w. The entry in the pattern configuration file has priority.

The one line statements can be specified before or after the MAPPING section.
