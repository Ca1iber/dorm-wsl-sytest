# The Parameters of aiv

#### Subtopics

- [The AIV_OPTIONS Environment Variable](<02.11.02.03.07.01.01_The_AIV_OPTIONS_Environment_Variable.md>)

- -A (optional): This flag causes aiv to generate a global binary vector file. This is also the default.
- -a (optional): This flag suppresses generation of a global binary vector file.
- -c <vector_config_file> (mandatory): This parameter specifies the vector configuration file to be used.
- -d (optional): This flag causes aiv to create different state mapping tables for different scan templates. If it is omitted, only one state mapping table will be created for all scan templates. See [The State Mapping Tables for the Scan Tool](<02.11.02.03.03.03.04_The_State_Mapping_Tables_for_the_Scan_Tool.md>).
- -FD (optional): This flag tells aiv to require creation of VECD instead of VECC commands from v2b.
- -FE (optional): This flag tells aiv not to compress the individual binary pattern files.
- -H (optional): This flag causes aiv to display a help file about itself and v2b.
- -h (optional): This flag causes aiv to display a help file about itself.
- -I (optional): With the environment variable AIV_OPTIONS you can cause aiv to ignore the timestamp of certain input files when deciding whether to retranslate a vector pattern. With the -I parameter you can temporarily override the definitions of AIV_OPTIONS for specified files. The codes for the individual files are as follows:

  - -Ia: for the ASCII vector file,
  - -Ic: for the vector configuration file,
  - -Iv: for the pattern configuration file,
  - -It: for the timing map file,
  - -Ip: for the pin configuration file,

- -i (optional): By default, aiv retranslates an ASCII vector file only if the timestamp of any of the input files is later than that of the corresponding binary vector file. With the -i parameter, you can specify input files whose timestamp is to be ignored by aiv. The codes for the individual files are as follows:

  - -ia: for the ASCII vector file,
  - -ic: for the vector configuration file,
  - -iv: for the pattern configuration file,
  - -it: for the timing map file,
  - -ip: for the pin configuration file,

- -p (optional): This parameter specifies the pin configuration file to be used. The pin configuration can also be defined in the vector configuration file.
- -T: This flag forces aiv to retranslate a pattern even if the timestamps of all input files are earlier than that of the corresponding binary vector file.
- -t: This flag forces aiv not to retranslate a pattern if the timestamps of all input files are earlier than that of the corresponding binary vector file. The flag can be used to temporarily override the setup defined by the environment variable AIV_OPTIONS.
- -V (optional): This flag causes aiv to display the version of the tool.
- -y (optional): This flag causes aiv to create a binary vector file for the 83000.
