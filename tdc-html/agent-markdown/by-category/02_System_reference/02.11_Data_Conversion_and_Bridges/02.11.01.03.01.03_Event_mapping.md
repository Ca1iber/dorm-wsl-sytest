STIL Reader also performs the following optimizations on the waveforms:

- Reducing the tri-state edges
- Removing duplicate states

STIL Reader creates a .tim file that either contains wavetables, equation sets, and AC specs, or that contains a command to load this information from the separate files. (See the use_eqfs settings file parameter in [Test-processing STIL Reader setup options](<02.11.01.05.03.02_Test-processing_STIL_Reader_setup_options.md>).) Both STIL and the V93000 allow usage of equation based timing, thus equation based timing is always used in the V93000 timing files.

Sample STIL input:

```
Timing {
  WaveformTable "_default_" {
    Period '400ns';
    Waveforms {
      "D0" {
        4 { '100ns' Z; }
        5 { '100ns' Z; '300ns' h; '400ns' X; }
        6 { '100ns' Z; '300ns' l; '400ns' X; }
      }
      "CLK0" {
        1 { '100ns' D; '250ns' U; }
      }
      "OUT0" {
        0 { '304ns' h; '396ns' X; }
        1 { '304ns' l; '396ns' X; }
      }
    }
  }
}
```

Resulting output V93000 timing file:

```
EQNSET 1 "atein_setup_template_1"
SPECS

TIMINGSET 1 "atein_setup_template_1__default_"
period=400.0

PINS D0
d1 = 100.0
r1 = 300.0
r2 = 400.0

PINS CLK0
d1 = 100.0
d2 = 250.0

PINS OUT0
r1 = 304.0
r2 = 396.0
```
