# The MAPPING Table

The format of the MAPPING table is variable. Optional columns can be omitted, and the order of the columns is arbitrary. The actual format of the table is defined in a header row. This row specifies which columns exist and how they are ordered. The columns have fixed names.

The following list explains all the columns of the MAPPING section. The columns are ordered alphabetically by their name.

- ascii_dvc (mandatory): specifies the name of an ASCII device cycle as specified in the ASCII timing file. This name is the one that is used in the timing map file.
- hp_ts (mandatory): specifies a timing set number. This number is used for two purposes. First, it tells the vector translation which timing set block of the timing map file it is to use for translating ASCII vectors with this ASCII device cycle, and second it supplies information on where to insert CTIM instructions into the sequencer program of the pattern.
- vec_ascii_dvc (optional): specifies the name of an ASCII device cycle that is used in the ASCII vector file. The state characters of this ASCII device cycle will be translated according to the rules that are specified in the timing set block determined by the hp_ts column for the ASCII device cycle specified in the ascii_dvc column. If you use the timing translation, then you define the mapping to the ASCII interface in the global configuration file (see [The Input Columns](<02.11.02.02.01.01.01_The_Input_Columns.md>)). If the vec_ascii_dvc column is omitted, the vector translation assumes that the same device cycle names are used in the ASCII timing and in the ASCII vector file.
