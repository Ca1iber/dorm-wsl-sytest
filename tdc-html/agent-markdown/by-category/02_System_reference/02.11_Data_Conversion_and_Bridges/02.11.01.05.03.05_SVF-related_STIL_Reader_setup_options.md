# SVF-related STIL Reader setup options

The SVF-related options in a STIL Reader setup file let you configure translation options that are specific to SVF files.

## Syntax

 The SVF-related options in alphabetical order:   svf_enable_ds_comments=boolean  Whether STIL Reader transfers comments marked with double slashes (//) from the SVF files to the generated patterns: 0 Comments are dropped.  1 Comments are transferred to the generated pattern.

For example: `svf_enable_ds_comments = 0`.

This parameter is optional. The default is 1.

   svf_enable_em_comments=boolean  Whether STIL Reader transfers comments marked with exclamation marks (!) from the SVF files to the generated patterns: 0 Comments are dropped.  1 Comments are transferred to the generated pattern.

For example: `svf_enable_em_comments = 0`.

This parameter is optional. The default is 1.

   svf_generate_scan_comments=boolean  Whether STIL Reader adds the SDI and SDO states as comments to the generated pattern: 0 No annotations are added.  1 The SDI and SDO states are added as comments.

For example: `svf_generate_scan_comments = 1`.

This parameter is optional. The default is 0.

   svf_generate_tap_comments=boolean  Whether STIL Reader adds the state of the TAP controller as comments to the generated pattern: 0 No annotations are added.  1 The state of the TAP controller is added as comments.

For example: `svf_generate_tap_comments = 0`.

This parameter is optional. The default is 1.

   svf_in_d1=position

Where to position the d1 edge of input timing signals. position is a number that specifies a fraction of the period length.

For example, the statement `svf_in_d1 = 0.4` places the d0 edge 0.4 period lengths (that is, 40% of the period) after the beginning of the period.

If you do not want to use the d1 input timing edge, you can deactivate it by specifying `svf_in_d1 = -1`.

This parameter is optional. The default is 0.5.

   svf_out_r0=position

Where to position the r0 edge of output timing signals. position is a number that specifies a fraction of the period length.

For example, the statement `svf_out_r0 = 0.1` places the d0 edge 0.1 period lengths (that is, 10% of the period) after the beginning of the period.

If you do not want to use the r1 output timing edge, you can deactivate it by specifying `svf_out_r1 = -1`.

This parameter is optional. The default is -1.

   svf_out_r1=position

This parameter is similar to [svf_out_r0](<02.11.01.05.03.05_SVF-related_STIL_Reader_setup_options.md#_351279__svf_out_r0>) but specifies the r1 edge. The default is 0.24.

   svf_pio_stop_tck=boolean  Whether to stop TCK when the PIO command is executed: 0 TCK is not stopped.  1 TCK is stopped.

For example: `svf_pio_stop_tck = 1`.

This parameter is optional. The default is 0.

   svf_sck_freq=frequency

The frequency of the system clock in hertz.

For example: `svf_sck_freq = 20000000`

This parameter is optional. The default is 10000000 (ten million, that is, 10 MHz).

   svf_tck='signal'

Which SmarTest signal to map to the TCK signal.

By default, the simulation TAP signal will be used. This parameter lets you substitute a SmarTest signal. signal is the name of the signal to use instead of the TAP signal. For example: `svf_tck='A0'`

This parameter is optional.

   svf_tck_d0=position

Where to position the d0 edge of the TCK signal. position is a number that specifies a fraction of the period length.

For example, the statement `svf_tck_d0 = 0.125` places the d0 edge 0.125 period lengths (that is, one eighth of the period) after the beginning of the period.

If you do not want to use the d0 edge, you can deactivate it by specifying `svf_tck_d0 = -1`.

This parameter is optional. The default is 0.

   svf_tck_d1=position

This parameter is similar to [svf_tck_d0](<02.11.01.05.03.05_SVF-related_STIL_Reader_setup_options.md#_351279__svf_tck_d0>) but specifies the d1 edge. The default is 0.25.

   svf_tck_d2=position

This parameter is similar to [svf_tck_d0](<02.11.01.05.03.05_SVF-related_STIL_Reader_setup_options.md#_351279__svf_tck_d0>) but specifies the d2 edge. The default is 0.75.

   svf_tck_freq=frequency

The frequency of the test clock in hertz.

For example: `svf_tck_freq = 20000000`

This parameter is optional. The default is 10000000 (ten million, that is, 10 MHz).

   svf_tdi='signal'

Which SmarTest signal to map to the TDI signal.

By default, the simulation TAP signal will be used. This parameter lets you substitute a SmarTest signal. signal is the name of the signal to use instead of the TAP signal. For example: `svf_tdi='A1'`

This parameter is optional.

   svf_tdo='signal'

Which SmarTest signal to map to the TDO signal.

By default, the simulation TAP signal will be used. This parameter lets you substitute a SmarTest signal. signal is the name of the signal to use instead of the TAP signal. For example: `svf_td0='A2'`

This parameter is optional.

   svf_tms='signal'

Which SmarTest signal to map to the TMS signal.

By default, the simulation TAP signal will be used. This parameter lets you substitute a SmarTest signal. signal is the name of the signal to use instead of the TAP signal. For example: `svf_tms='A3'`

This parameter is optional.

   svf_trst='signal'

Which SmarTest signal to map to the TRST signal.

By default, the simulation TAP signal will be used. This parameter lets you substitute a SmarTest signal. signal is the name of the signal to use instead of the TAP signal. For example: `svf_trst='A4'`

This parameter is optional.

   svf_tset_prefix='prefix'

A prefix that STIL Reader adds to the names of all timing sets it generates from an SVF file.

For example: `svf_tset_prefix='myTMS-'`

This parameter is optional. The default is "T".
