This is a utility program, provided as part of the SmarTest software, which allows you to execute commands directly from a Linux shell window, while the system software is running. The utility is useful especially when debugging testflow programs.

hpt is provided in two versions that mainly differ in their reply format. They are located in different directories and will be called pws-hpt and fw-hpt after these directories.
