# FTST? - (Functional TeST)

The FTST? (Functional TeST) query executes a functional test and returns either a pass or a fail result. The test that is executed must have previously been defined by the [SQLB, SQLB? - (SeQuencer LaBel definition)](<02.06.02.02.236_SQLB__SQLB__-__SeQuencer_LaBel_definition.md>) command and activated for execution by the [SQSL, SQSL? - (SeQuencer Start Label)](<02.06.02.02.240_SQSL__SQSL__-__SeQuencer_Start_Label.md>) command.

## Syntax

```
FTST? ["exec_context"]
```

returns:

```
FTST {result_flag}
```

## Parameters

 | exec_context  | An execution context. For more information on execution contexts see [Using execution contexts](<02.06.07.01.08.05.03.02.03_Using_execution_contexts.md>). |
 | result_flag  | This is returned by the system when the functional test has finished. It can be:

 |   | P  | is returned if the functional test passes. |
 |   | F  | is returned if the functional test fails.  | |

## Application

AC tests

## Errors

An error is generated if:

- No sequencer start label has been set, see [SQSL, SQSL? - (SeQuencer Start Label)](<02.06.02.02.240_SQSL__SQSL__-__SeQuencer_Start_Label.md>). A functional test cannot be executed.
- The Primary Level Set number is greater than the range allowed by [LSUS, LSUS? - (Level Sets USed)](<02.06.02.02.155_LSUS__LSUS__-__Level_Sets_USed.md>).
- The Primary Timing Set number is greater than the range allowed by [TSUS, TSUS? - (Timing Sets USed)](<02.06.02.02.283_TSUS__TSUS__-__Timing_Sets_USed.md>).
- The Primary Waveform Set number is greater than the range allowed by [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>).
- The specified Primary DPS Set is not selected.
- The specified Timing Set number is greater than the range allowed by [TSUS, TSUS? - (Timing Sets USed)](<02.06.02.02.283_TSUS__TSUS__-__Timing_Sets_USed.md>).
- The data queue empties, causing the test to stop. The system tells you at which vector the test aborted and also which sequencer instruction was currently valid via the command number. See also the command [SQPG](<02.06.02.02.237_SQPG__SQPG__-__SeQuencer_ProGramming.md>), as well as [Managing the data queue](<02.06.07.01.09_Managing_the_data_queue.md>).
- Any of the primary sets has any test system resource range violations, a functional test cannot be executed.
- If there is insuffcient channel memory to store error map / digital capture result in the extended error map (RAM).

## Example

```
FTST?
```

returns:

```
FTST P
```

This example returns a pass result for the functional test.

## Functional changes

- Introduced before SmarTest 6.3.2
