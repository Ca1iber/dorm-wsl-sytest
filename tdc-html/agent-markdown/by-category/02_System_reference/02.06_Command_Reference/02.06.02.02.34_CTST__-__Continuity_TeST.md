# CTST? - (Continuity TeST)

The CTST? (Continuity TeST) query executes a continuity test using the active load (programmable load) to generate the force current, and a comparator to generate the result.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Predependencies

The continuity test must have already been defined with the DFCT command.

## Mode of operation

The type of result that is returned depends on the mode selected with DFCT. If SPOL (single polarity) has been selected, the test is executed using the polarity defined by the commutation voltage and the pass range. If BPOL (both polarities) has been selected, the test is repeated using the opposite polarity, but only if the first test has passed. A pass result is returned if both tests have passed.

This command does not support pins in HV mode.

## Syntax

```
CTST? {mode}
```

returns:

```
CTST {result},{(pinlist)}
```

## Parameters

 |

mode

 |

The mode is:

 |
 |

GPF - Global Pass/Fail. Returns a single pass/fail result that includes all pins in the pin list.

 |
 |

PPF - Per pin Pass/Fail. Returns a pass/fail result for each pin in the pin list.

 |
 |

result

 |

This parameter returns the result of the test.

 |
 |

F - If at least one pin fails.

 |
 |

P - If all pins pass.

 |
 |

pinlist

 |

Must contain the names of pins previously defined by the DFCT command. If more than one pin is specified, the names must be separated by a comma.

 |

## Application

Continuity test using the active load.

## Errors

An error is generated if:

- the sequencer state is not OFF when you start the test;
- a timeout occurs during test execution.

## Example

```
DFCT
10.000,1700.000,200.000,700.000,SPOL,(p1,p2,p3,p4)
CTST? GPF
```

This example uses the command to set up the parameters needed to execute a continuity test on pins p1 to p4. The parameters are as follows:

- Force current = 10 mA
- Commutation voltage = 1.7 V
- Voltage minimum pass value = 200 mV
- Voltage maximum pass value = 700 mV
- Single polarity measurement selected.

It then executes the test with the CTST command using the global pass/fail mode.
