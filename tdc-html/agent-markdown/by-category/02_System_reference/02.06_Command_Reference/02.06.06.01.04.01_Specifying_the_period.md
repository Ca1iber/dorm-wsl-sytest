# Specifying the period

#### Subtopics

- [Defining the global period](<02.06.06.01.04.01.01_Defining_the_global_period.md>)
- [Determining the period resolution](<02.06.06.01.04.01.02_Determining_the_period_resolution.md>)

You can define a global period for all pins, and also different periods for individual pins, which will override the global value. The global period must exist; if you do not specify it, it will be set to a default value.

 Note You cannot define pin specific periods in a multi-port setup (see [Restrictions for multiport setups](<02.06.06.01.04.01.01.01_Restrictions_for_multiport_setups.md>)). Note Pin specific periods are not supported by the result tools. Note For Smart Scale systems more sophisticated conditions apply, refer to [Period resolution for a multi-port setup (Smart Scale)](<02.06.06.01.04.01.02.04_Period_resolution_for_a_multi-port_setup__Smart_Scale.md>).
