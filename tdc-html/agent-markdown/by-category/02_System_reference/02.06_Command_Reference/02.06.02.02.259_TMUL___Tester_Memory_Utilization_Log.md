# TMUL? (Tester Memory Utilization Log)

The TMUL? query returns details about the tester's memory utilization.

 Note SmarTest automatically inserts the idle sequence into the cache, even if it is not used in the protocol test. Thus the report always shows one additional cache miss. This is not problematic in terms of memory consumption, since the idle sequence typically is very short.

## Syntax

TMUL? {client}, {type},{(portlist)}

returns

TMUL {client}, {type}, {"reportString"}, {(portlist)}

Parameter
 |

Name

 |

Description

 |
 |

client

 |

Use either of:

PROTOCOLTEST - to query protocol test clients only

ALL - to query all supported clients

 |
 |

type

 |

Use either of:

CACHE - to query cache related information only

SIZE - to query size related information only

ALL - to query all supported types

 |
 |

portList

 |

Is a comma separated list of ports.

To query all ports, use @@

 |
 |

reportString

 |

Contains the information queried in string format.

The output will differ depending on the type queried:

- Output for type CACHE: {number of hits}, {number of misses}, {number of removed entries}

  - number of hits: Number of times an entry had been found in the cache.
  - number of misses: Number of times a new entry had been added to cache because the entry was not found in cache already.
  - number of removed entries: Number of entries removed from cache because an entry should be added, but no sufficient space was available

- Output for type SIZE in bytes: {min memory mark}, {high memory mark}, {limit}

  - min memory mark: The minimum memory size (in bytes) required to store generated data.
  - high memory mark: The maximum memory size (in bytes) that has been utilized during testing.
  - limit: Specified size limit (in bytes).

If no limit is specified, the system will either return "AUTO", if no limit had been specified at all, or the limit specified by `PROTOCOL_TEST::reserveTransactionMemory()`.

 |

## Errors

Errors will happen if:

- client is unknown.
- type is unknown.
- portList contains specifiers that cannot be mapped to any configured port name.

## Example

The following example queries the `mdioPort` for details about the CACHE of the PROTOCOLTEST client. The returned string shows that entries have been found 1560 times in the cache (number of hits). It also shows that 28 entries had been added (number of misses) to the cache and no entry has been removed.

```
> TMUL? PROTOCOLTEST,CACHE,(mdioPort)
< TMUL PROTOCOLTEST,CACHE,"1560,28,0",(mdioPort)
```

The next example queries the `mdioPort` for ALL details of ALL clients. The returned strings shows the results for CACHE  and SIZE. With regards to SIZE, one can see that the minimum memory size required to store the generated data is 7488 bytes. It also shows that the maximum memory size utilized during testing was 10314 bytes and that there is no limit set, thus AUTO is displayed.

```
> TMUL? ALL,ALL,(mdioPort)
< TMUL PROTOCOLTEST,CACHE,"1560,28,0",(mdioPort)
< TMUL PROTOCOLTEST,SIZE,"7488,10314,AUTO",(mdioPort)
```

This example queries all ports (@@)`` for ALL details of ALL client.

```
> TMUL? ALL,ALL,(@@)
< TMUL PROTOCOLTEST,CACHE,"1560,28,0",(mdioPort)
< TMUL PROTOCOLTEST,CACHE,"0,0,0",(otherPort)
< TMUL PROTOCOLTEST,SIZE,"7488,10314,AUTO",(mdioPort)
< TMUL PROTOCOLTEST,SIZE,"0,0,AUTO",(otherPort)
```
