# SQRC - (SeQuencer Remove execution Context)

The SQRC command serves to remove a selected or all existing execution contexts. For information on execution contexts, see [Using execution contexts](<02.06.07.01.08.05.03.02.03_Using_execution_contexts.md>).

## SQRC

```
SQRC {"context_name"|ALL}
```

## Parameters

 |

context_name

 |

The name of the context to be removed.

 |
 |

ALL

 |

With this option, all existing contexts will be removed.

 |

## Errors

An error occurs if:

- The specified context does not exist.

## Example

```
> SQRC "c1"
```

## Functional changes

- Introduced in SmarTest 7.2.0
