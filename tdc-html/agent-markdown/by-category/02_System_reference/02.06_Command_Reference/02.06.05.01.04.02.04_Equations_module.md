# Equations module

An equations module defines an equation system to determine the values of the equation variables. It starts with the EQUATIONS header keyword.

The number of equations must equal the number of equation variables. The left hand side of an equation is given by an equation variable, the right hand side is given by an expression. The expression can contain specs, other equation variables and fixed values.

For example, you could introduce the equation variables vil_level, vih_level and vcc_level determined by the following equation system. For example:

```
EQUATIONS
  vcc_level = 5.0
  vil_level = vcc_level*0.1
  vih_level = vcc_level*0.9
```

In the level set module and the DPS module you would use these equation variables to specify the power supply voltage vout and the drive levels vih and vil.
