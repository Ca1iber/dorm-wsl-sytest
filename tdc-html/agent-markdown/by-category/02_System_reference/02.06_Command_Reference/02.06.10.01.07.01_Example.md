# Example

## Measurement set with DPSE command

```
DPSE 1,(Vcc),#90000000112,0.09,0.11
DPSE 1,(Vdd),#90000000092,32,0.1,0.2
PSIE 1,,,(Vcc,Vdd)
PSER? 1,PPF

PSER 1,P,(Vcc),#9000000000
PSER 1,F,(Vdd),#9000000000

PSER? 1,PVAL

PSER 1,(Vcc),#9000000006,0.155,0.152,0.158,....
PSER 1,(Vdd),#9000000006,0.152,0.154,0.151,....
```

In this example, the DPSE command defines a measurement set with the following conditions:

- Vcc: limit for pass/fail judgment is 0.09 A to 0.11 A
- Vdd: limit for pass/fail judgment is 0.1 A to 0.2 A

300 mA range is used for all the measurements that is determined by using the specified limit value automatically (in this case, 10 mA range is too low, 1 A range is too high).

Then the PSIE command starts measurements for the measurement set 1. In this case, the pin name is ignored because the set number is specified with the first parameter. After the measurements, the PSER? command retrieves the pass/fail results and measurement values for each pin. The PSER? command returns "P" if the measurement has passed, or "F" if it has failed.

## Case for Using User-Programmed Averaging

If the PSER? command is used with PPF or GPF mode, the specification of the current measurement accuracy will not be satisfied for measurements using the ranges except 1 A. This is because the specific times of data averaging is required for satisfying the specification but the PSIE command does not support the averaging function. For getting a global pass/fail or per pin pass/fail result that is judged by using data that satisfies the specification, average the measurement values that are retrieved by the PSER? command with PVAL mode and judge the averaged data in your program.

Note If the DPS pins are defined for multi-site test, this example can read the results of the site that is in focus (query focus). For getting results for each site, change the query focus by using the SetSiteInFocus TPI (Test Program Interface) before reading the result for each site. For details of this TPI, see the Test Flow Programming in C manual. In this case, you can also use the PRLT? command for getting global pass/fail results for each site. Note that the PSER? command must be executed with PPF or GPF mode prior to the PRLT? command.
