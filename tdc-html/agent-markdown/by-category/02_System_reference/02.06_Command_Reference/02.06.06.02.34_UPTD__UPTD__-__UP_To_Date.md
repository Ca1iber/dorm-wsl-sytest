# UPTD, UPTD? - (UP To Date)

The UPTD (UP To Date) command allows you to declare a given setup, result or command set as up to date or out of date.

The UPTD? query allows you to read if the data in hardware has been changed since the current device file was last saved or loaded. A 1 or a 0 is returned. At power-on or after use of the [*RST](<02.06.02.02.345_RST_-__ReSeT.md>) or [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) commands, all the flags are set to 0.

## UPTD

```
UPTD {status}, {flag}
```

## UPTD?

```
UPTD? {status}
```

returns:

```
UPTD {status}, {flag}
```

## Parameters

## flag

Sets or returns the up-to-date status:

- 1: The specified device file is identical to the data currently used in hardware.
- 0: The specified device file differs from the data currently used in hardware.

## Application

[Test Program Explorer](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.02_Test_Program_Explorer.md>).

## Errors

An error is generated if you specify a flag other than 0 or 1.

## Example

```
UPTD? CONF
```

This example requests if the pin configuration data has been changed since the file was last loaded or saved. If the data has not changed, the response is:

```
UPTD CONF,1
```

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.0.3: BIT and FAM are no longer supported
- SmarTest 7.0.3: TSTF are no longer supported due to the obsoletion of standard test functions.
- SmarTest 7.2.0: Removed the SHMO parameter
