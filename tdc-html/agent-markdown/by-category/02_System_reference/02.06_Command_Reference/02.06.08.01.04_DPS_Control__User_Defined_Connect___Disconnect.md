# DPS Control (User Defined Connect / Disconnect)

#### Subtopics

- [Defining connect/disconnect sequences](<02.06.08.01.04.01_Defining_connect_disconnect_sequences.md>)

You will find DPS control commands useful if you are designing your own test function. There may be test situations where you want to define a particular connect/disconnect sequence for DPSs. This can be done by creating two command files in the testfunc directory of the device that you are testing.

These command files must contain the firmware commands that are executed during connect/disconnect. If the files are not specified, the standard connect/disconnect sequence is used. The command files are user-defined. You must create them in your_device/testfunc and name them

- connect.user_def
- disconnect.user_def

To ensure backwards compatibility, multisite handling is kept outside of these files and performed by SmarTest.
