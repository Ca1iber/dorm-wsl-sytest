# Introduction

This is a facility that allows you to make current measurements triggered by an external source. This trigger can be connected to a tester channel driver which in turn is controlled by your test pattern. This means that the measurement can be included as part of a functional test.

This function is controlled by the following three firmware commands:

[DPSE, DPSE? - (Define Power Supply External trigger measurement)](<02.06.02.02.85_DPSE__DPSE__-__Define_Power_Supply_External_trigger_measurement.md>)

[PSEE - (Power Supply External trigger measurement Execute)](<02.06.02.02.189_PSEE_-__Power_Supply_External_trigger_measurement_Execute.md>)

[PSER? - (Power Supply External trigger measurement Read results)](<02.06.02.02.190_PSER__-__Power_Supply_External_trigger_measurement_Read_results.md>)
