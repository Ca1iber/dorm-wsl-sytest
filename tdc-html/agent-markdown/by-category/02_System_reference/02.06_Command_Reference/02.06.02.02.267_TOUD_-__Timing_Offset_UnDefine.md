# TOUD - (Timing Offset UnDefine)

The TOUD command removes the embedded timing search configuration for the specified pins on all sites that have the setup focus (defined with [PSFC](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>)).

## Syntax

```
TOUD {(pinlist)}
```

## Parameters

 |

pinlist

 |

The pins for which the embedded timing search configuration is to be removed.

 |

## Application

Embedded timing search.

## Example

```
TOUD (Pin1, Pin2)
```

## Functional changes

- Introduced in SmarTest 7.0.3
