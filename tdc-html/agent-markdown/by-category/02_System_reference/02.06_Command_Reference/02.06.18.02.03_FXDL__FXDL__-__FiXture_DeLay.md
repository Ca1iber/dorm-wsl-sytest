# FXDL, FXDL? - (FiXture DeLay)

The FXDL (FiXture DeLay) command specifies fixture delays on a per channel basis. The FXDL? query returns the existing values.

## FXDL

```
FXDL {channel}, {fixture_delay}
```

## FXDL?

```
FXDL? {channel}
```

returns:

```
FXDL {channel}, {fixture_delay}
```

## Parameters

 |

channel

 |

The test system channel number of the digital channel. This is a five digit field. See [DFPN, DFPN? - (DeFine Pin Name)](<02.06.02.02.63_DFPN__DFPN__-__DeFine_Pin_Name.md>) for the number. You can type ALL to set the attributes for all installed channels. For the query, you can type CFG to query only configured channels.

 |
 |

fixture_delay

 |

The fixture_delay represents the delay (in ns) of the lines on the DUT board. The range of the admissible values depends on the test system type as follows:

- PS1600: Between -0.015 and +26.4 ns

The default value is 0. The maximum number of digits after the decimal point is 3.

 |

## Application

Download command in Attributes, see [Calibration and Attributes Commands](<02.06.18_Calibration_and_Attributes_Commands.md>).

## Errors

An error is generated if:

- The specified channel is invalid,
- Any parameter is out of range.

## Example

```
FXDL 10101,2.5
```

This example sets the fixture delay of channel 10101 to 2.5 ns.

## Functional changes

- Introduced before SmarTest 6.3.2
