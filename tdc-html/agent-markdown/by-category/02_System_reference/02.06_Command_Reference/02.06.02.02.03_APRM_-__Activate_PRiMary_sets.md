# APRM - (Activate PRiMary sets)

The APRM command activates primary sets in the hardware which were made known to the firmware by the [SPRM](<02.06.02.02.228_SPRM__SPRM__-__Set_PRiMary_sets.md>) (Set PRiMary sets).

## Mode of operation

The following commands do not require a prior execution of APRM, since they themselves perform this function:

- [FTST?](<02.06.02.02.127_FTST__-__Functional_TeST.md>) - (Functional TeST)
- [RCLS?](<02.06.02.02.203_RCLS__-__ReCeive_Level_Sensitivity.md>) - (ReCeive Level Sensitivity)
- [SQST](<02.06.02.02.241_SQST__SQST__-__SeQuencer_STate.md>) RUN - (SeQuencer STate)
- [PSST](<02.06.02.02.198_PSST__PSST__-__Power_Supply_STatus.md>) - (Power Supply STatus)

## Syntax

```
APRM {mode}
```

## Parameters

 | mode  | Selects the activation mode: |
 | FRC  | Forced activation. Primary sets are always activated. |
 | CNL  | Conditional activation, depends on previous activation performed by APRM or by any of the commands in the second list above. |

## Application

AC tests and [DC Measurement Commands](<02.06.10_DC_Measurement_Commands.md>).

## Example

```
APRM CNL
```

## Functional changes

- Introduced before SmarTest 6.3.2
