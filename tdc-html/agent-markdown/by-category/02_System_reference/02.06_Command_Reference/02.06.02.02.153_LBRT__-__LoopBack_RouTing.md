# LBRT? - (LoopBack RouTing)

This query returns which of the specified pins could be configured as SmartLoop™pins, and with which pin they would be paired. Since only channels with channel numbers n and n+1 (n odd) can communicate in a loopback, a configured pin cannot be used as a SmartLoop™pin if the counterpart of its associated channel is not used in the pin configuration.

## Syntax

```
LBRT? {(pinlist)}
```

returns:

```
LBRT {(pin1)}, {(pin2)}
```

Parameters
 |

pinlist

 |

Specifies the pins for which the partner pin is to be retrieved.

 |
 |

pin1

 |

Specifies a pin of pinlist.

 |
 |

pin2

 |

Specifies the pin which is mapped to the partner channel of the channel for pin1.

 |

## Application

SmartLoop™ test.

## Example

```
> LBRT? (@)
< LBRT (pin1),(pin2)
< LBRT (pin2),(pin1)
```

## Functional changes

- Introduced in SmarTest 7.0.1
