# Specifying the actions

#### Subtopics

- [Drive actions](<02.06.06.01.03.01.01.01_Drive_actions.md>)
- [Receive actions](<02.06.06.01.03.01.01.02_Receive_actions.md>)

There are two kinds of actions, drive actions and receive actions. A drive action actually consists of two independent actions: it not only drives to 0 or 1, but also switches tri-state on or off. A receive action compares the actual value of an output pin with an expected value.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.2: Logical waveforms are no longer supported.
