# Delete a Fixed Level Set

You can delete single, multiple or all level sets (except level set 1) using the command [LSUS, LSUS? - (Level Sets USed)](<02.06.02.02.155_LSUS__LSUS__-__Level_Sets_USed.md>).

 Note The support for fixed level setups is discontinued with SmarTest version 7.4.1T. We recommend using the [Equation based level setup](<../02.08_Setup_and_Result_Tools/02.08.04.14.02_Equation_based_level_setup.md>) for all releases of SmarTest 7.2 or higher versions.

The LSUS command defines the number of level sets currently in use and consequently deletes any level sets that have a greater identification number than the defined maximum. Entering 1 deletes all level sets with the exception of level set 1.

The LSUS? query returns the highest number currently allocated to a level set.
