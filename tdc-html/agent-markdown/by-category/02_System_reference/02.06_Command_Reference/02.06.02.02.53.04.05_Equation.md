# Equation

To query the list's equation, the syntax is:

```
DDEF? "ListName","Equation"
```

## Example

1. If list A is defined as

```
DDEF "A",SET,"Equation","Loop(1,10,10)"
```

then `DDEF? "A",Equation` will return:

```
DDEF "A",SET,"Equation","Loop(1,10,10)"
```

2. If list A is defined as

```
DDEF "A",SET,"Equation","0x4532ac34 0x11111111"
```

then `DDEF? "A","Equation"` will return

```
DDEF "A",SET,"Equation","0x4532ac34 0x11111111"
```

## Functional changes

- Introduced before SmarTest 6.3.2
