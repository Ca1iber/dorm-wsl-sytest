# CYRS? - (CYcle Resolution State)

The CYRS?(CYcle Resolution State) query returns the state of the specified pins with respect to test results. The answer, which is global, is determined by the pins with the lowest state.

## Syntax

```
CYRS? {(pinlist)}
CYRS {result_state}, {(pinlist)}
```

## Parameters

 |

result_state

 |

Specifies the result state of the selected pins. Possible values are:

 |
 |

INVL

 |

No functional test has been executed, so that no test results are available.

 |
 |

CYCL

 |

Test results are available for all selected pins, but they are not edge specific for at least one of them.

 |
 |

EDGE

 |

Edge specific test results are available for all selected pins.

 |
 |

pinlist

 |

The pin or pin list for which the result state is to be returned. Only O or IO pins will be taken into consideration.

 |

## Application

Error Map

## Example

```
CYRS? (Out1,Out2)
CYRS CYCL,(Out1,Out2)
```
