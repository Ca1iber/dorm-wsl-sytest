# TORC - (Timing/level Offset Result Copy)

The TORC command serves to copy the offset of a certain timing or level set to another timing or level set on the same pin.

To configure or retrieve the offsets, see [TOCF, TOCF?](<02.06.02.02.260_TOCF__TOCF__-__Timing_Level_Offset_search_ConFiguration.md>) and [TORS?](<02.06.02.02.265_TORS__-__Timing_level_Offset_ReSult.md>).

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

## To copy timing search results

TORC {source_waveform_set|source_specset_id|"source_multi-port_spec"|PRM}, {source_timing_set|PRM}, {dest_waveform_set|dest_specset_id|"dest_multi-port_spec"|PRM|ALL}, {dest_timing_set|PRM|ALL}, {(pinlist)}

## To copy level search results

TORC {source_level_set_id|PRM}, , {dest_level_set_id|PRM|ALL}, , {(pinlist)}

Note The second parameter must be left empty

## Parameters

 |

source_waveform_set

 |

Number of the source waveform set. Enter PRM for the Primary Waveform Set, or an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>). For the query, you can also enter ALL for all waveform sets.

 |
 |

source_specset_id

 |

The source specification ID (single port). It is derived as follows:

100 * equation_set_no + specset_no

 |
 |

source_multi-port_spec

 |

Name of the source multi-port specification.

Note that the multi-port specification uniquely determines an equation set for every pin of pinlist, because no pin can belong to more than one port within a multi-port specification.

 |
 |

source_level_set_id

 |

The source level set ID. It can be:

- A fixed level set ID, which is an integer in the range of 1 to the maximum number of level sets allowed, which is defined by the [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) command.
- An equation based level set ID, which derived as follows:

eqnset * 100000 + specset * 1000 + level_set_no

The source timing set.

The maximum number is determined by [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>). For the query, you can also enter ALL for all waveform sets.

 |
 |

dest_specset_id

 |

The destination specification ID (single port). It is derived as follows:

100 * equation_set_no + specset_no

 |
 |

dest_multi-port_spec

 |

Name of the destination multi-port specification.

Note that the multi-port specification uniquely determines an equation set for every pin of pinlist, because no pin can belong to more than one port within a multi-port specification.

 |
 |

dest_timing_set

 |

The destination timing set.

 |

 |

The destination level set ID. It can be:

- A fixed level set ID, which is an integer in the range of 1 to the maximum number of level sets allowed, which is defined by the [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) command.

eqnset * 100000 + specset * 1000 + level_set_no

 |

This refers to the primary waveform set/specification or to the primary timing set or to the primary level set, all as defined with [SPRM](<02.06.02.02.228_SPRM__SPRM__-__Set_PRiMary_sets.md>).

 |

## Application

Embedded timing and level search.

## Example

Example 1: copies the offsets of timing set 2 of single port specification 102 to the primary timing set of the primary specification.

```
TORC 102,2,PRM,PRM,(Pin1,Pin2)
```

Example 2: copies all level_set offsets of level set 1 to all the other level sets for all pins (@).

```
> TORC 1,,ALL,,(@)
```
