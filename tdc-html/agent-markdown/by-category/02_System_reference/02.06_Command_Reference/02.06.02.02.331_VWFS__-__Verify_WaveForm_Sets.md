# VWFS? - (Verify WaveForm Sets)

The VWFS? (Verify WaveForm Sets) query checks whether two specified waveform sets are compatible for the specified pins. The system responds with 1 if the pins are compatible, and with 0 if they are not compatible.

The items that must be identical when checking for the compatibility of waveform sets are the device cycle name and waveform sequence, and the waveforms and data parameters as specified by the commands [WFDF, WFDF? - (WaveForm DeFinition)](<02.06.02.02.334_WFDF__WFDF__-__WaveForm_DeFinition.md>) and [WAVE, WAVE? - (WAVEform)](<02.06.02.02.333_WAVE__WAVE__-__WAVEform.md>).

The VWFS? query has no influence on the number of defined waveform sets.

## Syntax

```
VWFS? {waveform_set_1},{waveform_set_2},{(pinlist)}
```

returns:

```
VWFS {status}, {(pinlist)}
```

## Parameters

 |

waveform_set_x

 |

Waveform set number. Enter an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>).

 |
 |

pinlist

 |

The name of the pin or pins for which you wish to check waveform set compatibility. This parameter can also include groups previously created by [DFGP, DFGP? - (DeFine GrouP)](<02.06.02.02.60_DFGP__DFGP__-__DeFine_GrouP.md>). If more than one pin is to be included, the names must be separated with a comma. The symbol @ can be used to check all configured pins.

 |
 |

status

 |

The system returns:

 |
 |

 |

0

 |

The waveform sets are not compatible.

 |
 |

 |

1

 |

The waveform sets are compatible.

 |

## Application

Timing setup, see [Timing Setup Commands](<02.06.06_Timing_Setup_Commands.md>) and Test Program Explorer.

## Errors

An error is generated if waveform_set is greater than the range allowed by the [WSUS](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>) command.

## Example

```
VWFS? 1,2,(DATA)
```

This example checks whether waveform sets 1 and 2 are the same for the pins in the group DATA. If they are the same the following string is returned:

```
VWFS 1,(DATA)
```
