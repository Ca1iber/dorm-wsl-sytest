There are six parameters by which you can control how and where error information is recorded:

- [Recording mode for detailed Error Map](<02.06.11.01.02.01.02.01_Recording_mode_for_detailed_Error_Map.md>)
- [Recording position](<02.06.11.01.02.01.02.02_Recording_position.md>)
- [Result granularity](<02.06.11.01.02.01.02.03_Result_granularity.md>)
- [Resolution of the error code](<02.06.11.01.02.01.02.04_Resolution_of_the_error_code.md>)
- [Location of the detailed Error Map](<02.06.11.01.02.01.02.06_Location_of_the_detailed_Error_Map.md>)
- [Compression factor for overview Error Map](<02.06.11.01.02.01.02.07_Compression_factor_for_overview_Error_Map.md>)

There are dependencies between the result granularity and the error code resolution. In addition, these dependencies differ on different hardware types. A summary is given in [Possible combinations of CYRM, CYRP, and DCRM](<02.06.11.01.02.01.02.05_Possible_combinations_of_CYRM__CYRP__and_DCRM.md>).
