# Overview Error Map

The overview Error Map is affected by the configuration parameters as follows:

 |

Sequencer termination

 |

Recording position

 |

Notes

 |
 |

standard termination

 |

stop position

 |

Recording will stop at the specified position.

This combination requires that the recording position is interpreted as a stop position by the detailed Error Map, too.

 |
 |

start position

 |

Not allowed!

This combination will not even be accepted by the configuration commands.

 |
 |

position ignored

 |

Recording will stop at the end of the test. The area of interest may be overwritten.

 |
 |

non-standard termination (EL, SE, SEEL, STSQ)

 |

start position

or

stop position

 |

Not allowed!

FTST? and SQST RUN (which should be used for EL and SEEL) will not execute a functional test for this combination.

 |
 |

position ignored

 |

Recording will stop when the sequencers are stopped. No complications can arise.

   |
