# SREC, SREC? - (Set RECeiver mask)

The SREC command enables you to mask the specified receiver pins, so that do not contribute to the global PASS/FAIL result.

The SREC? query returns the current mask settings.

## SREC

```
SREC {mask_value}, {(pinlist)}
```

## SREC?

```
SREC? {(pinlist)}
```

Note Executing `SREC ACT,(@)` may cause excessive overhead. You can use the [UI_SUSPEND](<../02.07_Test_Method_Reference/02.07.04.01.260_UI_SUSPEND.md>) test method API to suspend updates of the graphical user interface.

## Parameters

 |

mask_value

 |

The mask value parameter specifies whether a pin mask will be applied:

 |
 |

ACT

 |

If ACT is selected, the output components of the pins specified in the pin list become active (not masked).

 |
 |

X

 |

If X is selected, the output components of the pins specified in the pin list are masked.

 |
 |

STOR

 |

If STOR is selected, the output components of the pins specified in the pin list are stored.

 |
 |

RSTO

 |

If RSTO is selected, the output components of the pins specified in the pin list are restored.

 |
 |

pinlist

 |

The name of the pin or pins to be masked. This parameter may also include groups previously created by [DFGP, DFGP? - (DeFine GrouP)](<02.06.02.02.60_DFGP__DFGP__-__DeFine_GrouP.md>) or by [DFGE, DFGE? - (DeFine Group Expressions)](<02.06.02.02.59_DFGE__DFGE__-__DeFine_Group_by_Expressions.md>). If more than one pin is to be included, the names must be separated with a comma. Pins in pinlist can be O or IO pin types. The @ character sets the mask for all pins of these types.

 |

## Application

Download command in Pattern Tool.

## Example

```
SREC X, (D1, D2, D3, D4)
```

This example masks the pins D1, D2, D3 and D4.

## Troubleshooting

If the following problem message is displayed in the Report window (ui_report):

`WARNING: SREC -name "<Pin-Name>" unknown"`

Check the following:

- If the pin is required, check that the reported pin is specified in the pin configuration file.
- If the pin is not required, deleted it from the associated ../vectors/.<Pattern-Name>.SREC file.
