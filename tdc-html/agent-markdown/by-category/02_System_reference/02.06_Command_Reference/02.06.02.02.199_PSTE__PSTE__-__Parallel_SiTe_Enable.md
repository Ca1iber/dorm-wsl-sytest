# PSTE, PSTE? - (Parallel SiTe Enable)

The PSTE command defines how many sites are to be configured in the pin configuration. Note that not all of these sites will be actually available for testing. If one of the channels that is used by a site is inactivated in the MCDIgnore file (MCDIgnore file in Service Guide Part 1), this site cannot be used for testing.

The PSTE? query simply returns the number of configured sites, or detailed information about which of these configured sites is actually available for testing.

Note Do not confuse the effects of the PSTE (Parallel SiTe Enable) command with the enabled state of the Site Control window. This state has no counterpart in the firmware. The PSTE command determines the number of sites that are displayed in the Site Control window. However, only available sites can be set to enabled in this window.

This command does not support pins in HV mode.

## PSTE

```
PSTE {sites}
```

## PSTE?

```
PSTE? [STR]
```

returns

```
PSTE {sites|"site_string"}
```

## Parameters

 | sites |

The sites parameter is an integer that specifies the number of sites (to be) configured. The maximum is 1024.

For more information, refer to [Number of sites](<../../01_Getting_started/01.04_SmarTest_system_parameters_-_default_values_and_limits/01.04_SmarTest_system_parameters_-_default_values_and_limits.md#_116532__r_numberOfSites>) in [SmarTest system parameters - default values and limits](<../../01_Getting_started/01.04_SmarTest_system_parameters_-_default_values_and_limits/01.04_SmarTest_system_parameters_-_default_values_and_limits.md>).

 |
 | site_string |

A string consisting of "0" and "1". The length of the string corresponds to the number of the configured sites. The nth character of this string stands for site n.

"0" indicates that the respective site uses a channel that is listed in the MCDIgnore file, and that this site therefore cannot be used for testing. "1" indicates that the site can be used.

 |
 | STR |

If you specify this optional keyword in the query, PSTE? will return a site string.

If this parameter is omitted, PSTE? will return the number of sites that are configured in the pin configuration.

 |

## Application

Site control window.

## Errors

An error is generated if:

- Not all pins at the site have had their channels assigned by the [PALS](<02.06.02.02.173_PALS__PALS__-__Pin_ALlocation_for_multiple_Sites.md>) command.
- All channels are listed in the MCDIgnore file and therefore not available for testing.

## Example

```
> PSTE 3
```

This example configures three sites (site 1, site 2, and site 3).

```
> PSTE? STR
< PSTE "101"
```

This example says that three sites are configured, but that only two of them (site 1 and site 3) are available for testing. Site 2 uses a channel that is listed in the MCDIgnore file, and therefore cannot be used for testing.
