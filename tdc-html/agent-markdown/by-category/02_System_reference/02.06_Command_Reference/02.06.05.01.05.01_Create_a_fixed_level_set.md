# Create a fixed level set

#### Subtopics

- [Set fixed driver levels](<02.06.05.01.05.01.01_Set_fixed_driver_levels.md>)
- [Set fixed receiver levels](<02.06.05.01.05.01.02_Set_fixed_receiver_levels.md>)
- [Set fixed clamping levels](<02.06.05.01.05.01.03_Set_fixed_clamping_levels.md>)

The system lets you create multiple level sets up to the maximum number previously defined by the command [DSCP, DSCP? - (Define System Control Parameter)](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>). Each level set contains all level resources. The sequencer controls the use of level sets during test. At power-on, one level set exists, containing the default drive and receive levels. This set is identified as level set 1.

 Note The support for fixed level setups is discontinued with SmarTest version 7.4.1T. We recommend using the [Equation based level setup](<../02.08_Setup_and_Result_Tools/02.08.04.14.02_Equation_based_level_setup.md>) for all releases of SmarTest 7.2 or higher versions.

The commands associated with creating a level set are as follows:

- [LSUS, LSUS? - (Level Sets USed)](<02.06.02.02.155_LSUS__LSUS__-__Level_Sets_USed.md>)
- [DRLV, DRLV? - (DRive LeVel)](<02.06.02.02.89_DRLV__DRLV__-__DRive_LeVel.md>)
- [RCLV, RCLV? - (ReCeive LeVel)](<02.06.02.02.204_RCLV__RCLV__-__ReCeive_LeVel.md>)
- [TERM, TERM? - (TERMination mode)](<02.06.02.02.257_TERM__TERM__-__TERMination_mode.md>)
- [CLMP, CLMP? - (CLaMP level)](<02.06.02.02.26_CLMP__CLMP__-__CLaMP_level.md>)
- [EQFC, EQFC? - (EQualization and Filter Configuration)](<02.06.02.02.107_EQFC__EQFC__-__EQualization_and_Filter_Configuration.md>)

Before creating a level set, use the LSUS? query to determine the number of sets currently in use. You can then identify the new set using the next available number. The firmware will then be updated to include the new number of sets.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.0.1: : Added firmware command EQFC[?]
