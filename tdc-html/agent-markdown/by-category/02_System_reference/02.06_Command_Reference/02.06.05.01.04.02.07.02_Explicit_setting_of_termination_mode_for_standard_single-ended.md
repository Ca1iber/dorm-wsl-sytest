# Explicit setting of termination mode for standard/single-ended

The differential termination modes must be set explicitly in the equation based level setup file with the keyword "term". In addition, the single-ended termination modes can also be set explicitly with the keyword "term" as opposed to implicitly as described in [Implicit setting of termination mode for standard/single-ended](<02.06.05.01.04.02.07.01_Implicit_setting_of_termination_mode_for_standard_single-ended.md>).

The line containing the keyword "term" must immediately follow the line with the key word "PINS".

The syntax for the keyword "term" line is

term <termination_mode_str>
