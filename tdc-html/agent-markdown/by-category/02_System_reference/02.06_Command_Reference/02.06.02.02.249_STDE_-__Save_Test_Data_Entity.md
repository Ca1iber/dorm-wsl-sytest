# STDE - (Save Test Data Entity)

The STDE command lets you save modified or newly created test data entities (TDEs).

The STDE command always saves all modified or newly created TDEs into the directory specified by the [PTDE](<02.06.02.02.200_PTDE__PTDE__-__Path_for_Test_Data_Entities.md>) command.

## Syntax

STDE

## Example

```
STDE
```
