# Changing the level set (CLEV)

The CLEV instruction allows you to change the level set during a test by specifying a new set number. It is implemented similarly to the CTIM instruction (see [Changing the timing set](<02.06.07.01.08.03.01_Changing_the_timing_set__CTIM.md>)). The overall length of a CLEV instruction equals the length of a CTIM instruction with p1 = p2.

## Functional changes

- Introduced before SmarTest 6.3.2
