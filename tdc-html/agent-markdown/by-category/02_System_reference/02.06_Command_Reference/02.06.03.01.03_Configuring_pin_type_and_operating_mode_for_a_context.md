# Configuring pin type and operating mode for a context

#### Subtopics

- [Mode contexts](<02.06.03.01.03.01_Mode_contexts.md>)

After a digital pin has been defined with DFPN, its type (input or output or both) and operating mode must be configured. This is done with the CONF command. The following table lists which operation modes are supported on the various systems:

Type and operating mode are always specified for a certain mode context (see [Mode contexts](<02.06.03.01.03.01_Mode_contexts.md>)). The same pin may have a different direction and operating mode in different contexts. If no context is specified, the settings apply to the DEFAULT context.

The CONF? command lists the pin type and operating mode of the specified pins in the specified or implied context.

 Note Executing the CONF command affects the following relay settings of the specified channel: AC relays connecting the pin electronics to the DUT pin are opened, and DC relays connecting the DC rail to the DUT pin are opened. You can close the relays (and reconnect the DUT) by using the RLYC command, as described in [Connect the DUT to the Tester Resources](<02.06.08.01.01_Connecting_the_DUT_to_the_test_system_resources.md>).
