# ASWE, ASWE? - (Auto SWing Enable)

The ASWE (Auto SWing Enable) command allows you to enable automatic swing adjustment for a waveform set or a spec set.

## ASWE

```
ASWE {waveform_set|specset_id}, {enable_status}
```

## ASWE?

```
ASWE? {waveform_set|specset_id}
```

returns:

```
ASWE {waveform_set|specset_id}, {enable_status}
```

## Parameters

 |

waveform_set

 |

Specifies the number of a waveform set for non-equation based testing. Enter PRM for the Primary Waveform Set, ALL for all waveform sets, or an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>).

 |
 |

specset_id

 |

Specifies a spec set ID for equation based testing. The specset_id is derived as follows:

`100 *` equation_set_no `+ ` specset_no

 |
 |

enable_status

 |

Enter ON to switch automatic swing modification on. Enter OFF to switch automatic swing modification off.

 |

## Application

Swing adjustment of mixed level devices.

## Errors

An error is generated if:

- The waveform set number is out of the used range.
- The spec specified is not defined.

## Example

```
ASWE 1,ON
```

This example enables the automatic swing adjustment for waveform set 1.

## Functional changes

- Introduced before SmarTest 6.3.2
