# SSRC - (Source Synchronous testing: Remove Configurations)

The SSRC command removes the buffer pin configurations for source synchronous testing from all those of the specified pins for which are configured as buffers.

## Syntax

```
SSRC {(pinlist)}
```

## Parameters

 |

pinlist

 |

The pins whose buffer configurations are to be removed. Pins for which no buffer configuration exists are ignored.

 |

## Example

```
> SSRC (@)
```

This example removes all buffer configurations. Pins for which no buffer has been configured are ignored.

## Functional changes

- Introduced before SmarTest 6.3.2
