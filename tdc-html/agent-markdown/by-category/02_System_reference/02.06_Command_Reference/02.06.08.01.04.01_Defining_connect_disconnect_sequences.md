# Defining connect/disconnect sequences

SmarTest provides you with the flexibility to modify the behavior of the standard connect/disconnect sequence.

 CAUTION If you plan to make use of this feature, you must have expert knowledge of the test system. Otherwise it is possible that you may write command files that cause damage to your test device or the test system, or both. Note On startup SmarTest always performs a standard disconnect.

## Standard connect/disconnect sequence

The standard connect/disconnect sequence, which can be used as model for your own sequences, is as follows:

 |

Connect:

 |

```
[RLYC](<02.06.02.02.206_RLYC__RLYC__-__ReLaY_Control.md>) CNCT,OFF,(@)
[PSST](<02.06.02.02.198_PSST__PSST__-__Power_Supply_STatus.md>) ON
[CNCT](<02.06.02.02.29_CNCT_-_CoNneCT_disCoNneCT.md>) ON,(@)
[SQST](<02.06.02.02.241_SQST__SQST__-__SeQuencer_STate.md>) BRK
```

 |
 |

Disconnect:

 |

```
[DLSO](<02.06.02.02.77_DLSO__Driver_Level_Switch_Off.md>) (@)
[CHRS](<02.06.02.02.23_CHRS__CHRS__-__CHeck_Routing_Set_globally.md>) OFF
[FLSH](<02.06.02.02.124_FLSH_-__FLuSH_buffered_commands.md>) MUX
[WSDN](<02.06.02.02.341_WSDN_-__Wait_Setup_DoNe.md>)
[SQST](<02.06.02.02.241_SQST__SQST__-__SeQuencer_STate.md>) OFF
[CNCT](<02.06.02.02.29_CNCT_-_CoNneCT_disCoNneCT.md>) OFF,(@)
[BCMD](<02.06.02.02.07_BCMD__BCMD__-_Binding_CoMmanD.md>) "",ACTION,"Update",
[PSST](<02.06.02.02.198_PSST__PSST__-__Power_Supply_STatus.md>) OFF
[RLYC](<02.06.02.02.206_RLYC__RLYC__-__ReLaY_Control.md>) IDLE,OFF,(@)
```

 |

## User-defined disconnect sequence

To write your own command files that define a connect/disconnect sequence for DPSs, use the enhanced PSST command to define a series of specific pinlists (see [PSST, PSST? - (Power Supply STatus)](<02.06.02.02.198_PSST__PSST__-__Power_Supply_STatus.md>)), for example:

 |

Connect:

 |

```
RLYC CNCT,OFF,(@)
PSST ON,(pinlist for DPS1)
PSST ON,(pinlist for DPS2)
CNCT ON,(@)
SQST BRK
```

 |
 |

Disconnect:

 |

```
SQST OFF
CNCT OFF,(@)
CHRS OFF
FLSH MUX
WSDN
PSST OFF,(pinlist for DPS2)
PSST OFF,(pinlist for DPS1)
RLYC IDLE,OFF,(@)
```

 |

Using this feature has the following restrictions:

- To keep the throughput, the files are read only during a software start or a device change. Editing a file while the software is running may not have any effect.
- Shared multisite is not supported with this feature.
