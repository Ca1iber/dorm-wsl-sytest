# BWDF, BWDF? - (Break Waveform DeFinition)

The BWDF (Break Waveform DeFinition) command defines the actions for the break waveform for the specified waveform set. Only drive actions are allowed. The break waveform must not contain data dependent actions. Edges with delays that are incompatible with the defined actions will be auto-corrected to fit.

The BWDF? query returns the definitions for the current break waveform.

Note This command is replaced by [BWDS](<02.06.02.02.14_BWDS__BWDS__-__Break_Waveform_Definition_String.md>)[, ](<02.06.02.02.14_BWDS__BWDS__-__Break_Waveform_Definition_String.md>)[BWDS?](<02.06.02.02.14_BWDS__BWDS__-__Break_Waveform_Definition_String.md>) from release 2.1 onwards when 14-edge setups are used. The command will be disabled for pin and waveform sets containing more than 6 edges. The query can still be used, but will return only the first 6 edges.

## BWDF

```
BWDF {wvf_set}, {a1}, {a2}, {a3}, {a4}, {a5}, {a6}, {(pinlist)}
```

## BWDF?

```
BWDF? {wvf_set|"wavetable_name"|specset_id|"multiport_spec"}, {(pinlist)}
```

returns:

```
BWDF {wvf_set|"wavetable_name"|specset_id|"multiport_spec"}, {a1}, {a2}, {a3}, {a4}, {a5}, {a6}, {(pinlist)}
```

## Parameters

 |

wvf_set

 |

Waveform Set Number. Enter ALL for all waveform sets, or an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by the command [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>).

 |
 |

specset_id

 |

Derived as follows:

`100 *` equation_set_no `+ ` specset_no

 |
 |

wavetable_name

 |

The wavetable name. Enter a string of up to 40 alphanumeric characters (upper or lower case) enclosed in double quotes.

 |
 |

multiport_spec

 |

To query a multi-port specification, enter the name of the specification.

 |

a1..a6

## Application

Timing Setup, see [Timing Setup Commands](<02.06.06_Timing_Setup_Commands.md>).

## Errors

- waveform_set is greater than the range allowed by the command [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>).
- There is a mismatch between the edge actions and edge order in the specified waveform.
- A tri-state action is defined or implicitly required on edge 2 or 5.
- specset_id is invalid because equation_set_no, specset_no, or both are invalid, or because specset_id does not reference a defined wavetable.

## Example

```
BWDF 1,N,N,N,F1N,F0N,N,(D0,D1,D2,D3)
```

This example defines a pulse for waveform set 1, and for pins D0 to D3, driving to 1 at edge action 4 and to 0 at edge action 5. The tri-state formatter is not used.
