# Activating and masking a site

You can activate or mask a site by using the PACT command. Activating a site means that a test is executed for the site, and that any errors generated by the site during the test are processed. If a site is masked, the receivers for the site are masked and no result information is available for that site.

 CAUTION This command implements the tpi interface for multi-site testing. Use the tpi call instead of the PACT firmware command. This is described in the manual Test Flow Programming in C.

The PACT? query returns the activation state of one or all sites.

## Functional changes

- Introduced before SmarTest 6.3.2
