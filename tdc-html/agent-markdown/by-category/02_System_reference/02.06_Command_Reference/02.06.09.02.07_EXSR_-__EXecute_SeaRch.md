# EXSR - (EXecute SeaRch)

The EXSR command executes all the search conditions of a search set, as defined with the [DPSR](<02.06.02.02.86_DPSR__DPSR__-__Define_Parallel_SeaRch.md>) command, and stores a result for each condition. The searches are executed in parallel for all pins on the active sites. The results for different search sets are stored at different locations and do not overwrite each other.

The active sites are those that were activated by the last execution of the [PACT](<02.06.02.02.171_PACT__PACT__-__Parallel_ACTivities_control.md>)command. By default, only the first site is active.

If at least one search condition uses a spec variable, the timing for the search must be equation based. If all conditions use hardware resources (edges), the timing can also be fixed. For details on this distinction see the [DPSR](<02.06.02.02.86_DPSR__DPSR__-__Define_Parallel_SeaRch.md>) command.

In offline mode, EXSR creates a fictitious transition point for every condition in the search set. This point lies at 10% of the range between the start and the stop value of the condition.

## Predependencies

The search set must have been defined with [DPSR](<02.06.02.02.86_DPSR__DPSR__-__Define_Parallel_SeaRch.md>).

## Postdependencies

The search results must be retrieved with the RSSR? query.

## Setting the primary port

You reserve the primary port with [DPSR](<02.06.02.02.86_DPSR__DPSR__-__Define_Parallel_SeaRch.md>) and it will be set and reset by EXSR.

This feature applies only, if the spec variable affects its period. For detailed information on the primary port, see [Modifying the period for a search or shmoo in a multi-port setup](<02.06.09.01.01.01_Modifying_the_period_for_a_search_or_shmoo_in_a_multi-port_setup__Pin_Sc.md>).

- The primary port must be already set by the [DPSR](<02.06.02.02.86_DPSR__DPSR__-__Define_Parallel_SeaRch.md>) command.
- SmarTest restores the original primary port at the end of each EXSR call.

## Syntax

```
EXSR{set_nr}
```

Parameter
 |

set_nr

 |

Specifies the number of the search set which is to be executed.

 |

## Application

Parallel search tests.

## Errors

An error is generated if:

- The specified search set does not exist
- No start label has been defined
- The spec type is TIM or LEV, and the timing or level setup is not equation based or the spec variables are not configured correctly

## Example

```
> EXSR 1
> EXSR 2
```

Note that the results for search set 1 are still extant after execution of search set 2.
