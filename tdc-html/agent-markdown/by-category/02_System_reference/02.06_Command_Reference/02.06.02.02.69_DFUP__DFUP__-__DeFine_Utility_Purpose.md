# DFUP, DFUP? - (DeFine Utility Purpose)

The DFUP command defines a group (utility purpose) of utility line channels and assigns a standard output state to each of the specified channels. These standard settings must be activated with UPST followed by FLSH.

## DFUP

```
DFUP {(ch_No_list)}, "{setting}", {(purpose_name)}
```

## DFUP?

```
DFUP? {(purpose_name)}
```

returns

```
DFUP {(ch_No_list)}, "{setting}", {(purpose_name)}
```

## Parameters

 | ch_No_list |

Utility line channel numbers to be defined as the members of a utility purpose and specified with five digits. The channels must be separated with a comma.

In the five‑digit format, the first three digits of the channel numbers specify the utility pogo block. For valid pogo blocks, refer to [DUT interface layout](<../02.03_DUT_board_design_reference/02.03.03.01_DUT_interface_layout.md>) and to [Utility pogo block mapping](<../02.03_DUT_board_design_reference/02.03.06.08.02_Utility_pogo_block_-_Utility_Card__V93000_EXA_Scale_systems.md#_347642__s_Utility_pogo_block_mapping>) in [Utility pogo block - Utility Card (V93000 EXA Scale systems)](<../02.03_DUT_board_design_reference/02.03.06.08.02_Utility_pogo_block_-_Utility_Card__V93000_EXA_Scale_systems.md>).

The legacy three‑digit format is also supported: The first digit (1 ... 8) specifies the utility pogo block UTIL鈥? ... UTIL鈥?.

The last two digits specify the channel number 01 ... 32 of the utility line.

On the utility pogo blocks, an offset of -1 is to be considered and the channel number is URW00 ... URW31.

When reading the defined utility lines with the DFUP? command, the data returned always have the five‑digit format. The same applies to the [PALS?](<02.06.02.02.173_PALS__PALS__-__Pin_ALlocation_for_multiple_Sites.md>) command.

The channel numbers 16515 and 16516 should not be used. They should only be accessed with the [I2CA](<02.06.02.02.142_I2CA__I2CA__-__I2CA_bus.md>)or the [BDID](<02.06.02.02.09_BDID__BDID__-__BoarD_ID.md>)firmware command.

 |
 | setting |

Output states for each channel in the ch_No_list. Specify the setting of each utility line with the following specifiers:

- 0: sets the corresponding (write) channel to high (high impedance state)
- 1: sets the corresponding (write) channel to low
- X (x): no action

Specify the setting values corresponding to the definition order of the ch_No_list parameter.

The number of characters must be equal to the number of the utility line channels in the ch_No_list parameter.

Note that the settings must be explicitly activated with [UPST](<02.06.02.02.305_UPST__UPST__-__Utility_Purpose_STate.md>) and [FLSH](<02.06.02.02.124_FLSH_-__FLuSH_buffered_commands.md>).

 |
 | purpose_name |

Name of the utility purpose. In the query you can use the symbol @ to list all defined utility purposes.

This parameter can have up to 16 alphanumeric characters and must not contain blank spaces, or any of the following characters: `# ; ( ' ' ) ? @ ,`

 |

## Application

For details about utility purposes, see [Configuration Setup Commands](<02.06.03_Pin_configuration_setup_commands.md>).

## Errors

An error is generated if:

- The channel number is out of range.
- The given name is already assigned to a digital pin, analog pin, DPS pin, or utility name.
- The specified channel has already been defined in the DFUT command as READ ONLY capability.
- Incompatible settings are specified for a channel (for example, `DFUP (101,101),"10", (bad)`).
- The setting contains characters other than "0", "1" and "X (or x)".
- The number of characters in the setting is not equal to that of the channel list.

## Example

```
> DFUP (16501,16502,16503,16504),"0110",(AWG_CNCT)
> UPST ,(AWG_CNCT)
> FLSH
> UPST? (AWG_CNCT)
< UPST "0110",(AWG_CNCT)
```

This example defines a utility purpose AWG_CNCT and activates its standard settings.

The members and the setting values are as follows:

```
Member:      16501  16502  16503  16504
---------------------------------------
Setting:     0      1      1      0
```
