# Available functions for Hex32List

 Note All functions are put in quotes.

## Equation

x1 x2 x3.......xn (separated by spaces)

x1, x2, x3, .......xn are 32-bit unsigned integer values, and are written in the format 0xHHHHHHHH, where H is a hexadecimal character (1...F).

For example, if list A is defined as

```
DDEF "A",SET,"Equation","0x55555555 0x1234ABCD"
```

then list A will be 55555555 1234ABCD

## RepeatValue(Value,Count)

The Value is the hexadecimal element to be repeated.

The Count is the number of times to repeat.

For example, if list A is defined as:

```
DDEF "A",SET,"Equation","RepeatValue(0x55555555,3)"
```

then list A will be 55555555 55555555 55555555.

## RepeatList(List,Count)

List is the name of an existing list, and Count is the number of times to repeat.

For example, if list A is 1234ABCD 55555555, and List B is defined as:

DDEF "B",SET,"Equation","RepeatList(B,2)"

then List B is 1234ABCD 55555555 1234ABCD 55555555.

## Read(Filename)

Filename is an absolute Unix path of a file. This function will read the file and take all the values in the file to construct the list.

For example, if list A is defined as:

```
DDEF "A",SET,"Equation","Read(/home/user/devices/RF_device/Hex32List.txt)"
```

and Hex32List.txt contains 0x12345678 0x55555555 0xabcdef23, then list A is 12345678 55555555 abcdef23.
