# Remove

The Remove subcommand is used to delete a list or to delete all lists.

## Syntax

```
DDEF {"ListName" | ALL},{REMOVE},,
```

## Example

```
DDEF "listA",REMOVE,,
DDEF ALL,REMOVE,,
```

## Functional changes

- Introduced before SmarTest 6.3.2
