# Defining the period

In fixed timing, the periods are defined with the PCLK command for a specified timing set within a waveform set. The range of the definition is determined by specifying the pins for which it is intended. For the global period, you must specify @, which denotes the default port, that is, all pins. In order to define a pin specific period, you must specify the pins in question.

For example, if the global period is to be 12 ns (which would result from setting the variable f shown in [Defining the global period](<02.06.06.01.04.01.01_Defining_the_global_period.md>) to 100) you can define the global period for timing set 1 in waveform set 1 with the following command:

```
PCLK 1,1,12,(@)
```
