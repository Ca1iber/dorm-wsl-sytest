# DFSP, DFSP? - (DeFine Sampling Profile)

The DFSP (DeFine Sampling Profile) command allows to measure the voltage or current during a functional test.

The DFSP? query returns the related settings of the specified pins.

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Predependencies

The DFSP (DeFine Sampling Profile) command is used for current profiling, which is supported on DC Scale cards only.

On DC Scale DPS128/64 and UHC4T cards, profiling for multiport setups does not stop when the DPS part is finished. On these cards, profiling stops when the longest running port is finished. This gives the capability to profile the supply voltages/currents during the complete execution. In case you want to reduce memory consumption, you could put DPS pins into an empty port.

For the [DC Scale DPS128/DPS64 cards](<../02.05_Test_Head_Cards/02.05.05.01_DC_Scale_DPS128_DPS64_cards.md>), changing the current measurement range for profiling is not supported. That is, the measure_range parameter of the DFSP command is ignored when the measure_type is set to CURR. The profiling measurements are performed in the selected clamp current range.

## DFSP

```
DFSP [meas_resource,] {measure_type}, {measure_range}, {sampling_rate}, [average_factor], [keep_range,] {(pinlist)}
```

## DFSP?

```
DFSP? {(pinlist)}
```

returns

```
DFSP [meas_resource,] {measure_type}, {measure_range},{sampling_rate}, [average_factor], [keep_range,] {(pinlist)}
```

## Parameters

 | meas_resource  | The measurement resource. It can be:

- PMU - The default value
 |
 | measure_type  | The measurement type. It can be:

- VOLT - for voltage measurements, or
- CURR - for current measurements.
 |
 | measure_range  | This parameter corresponds to the voltage/current measure range. |
 | sampling_rate  | Specifies the sampling rate in microseconds. |
 | average_factor  | The number of measurements per sample. |
 | keep_range  | Specifies whether the range used by current profiling should be kept. Default is to restore last measure range before doing the profiling. |
 | pinlist  | This parameter specifies the pins to be used for the measurements. |

## Application

The DFSP (DeFine Sampling Profile) command is used for current profiling.

## Examples

### Example 1: Current measurements

```
DFSP CURR,0.5,2048,2,(@)
```

or

```
DFSP CURR,40,2048,,KEEP,(dps1)
```

### Example 2: Voltage measurements

```
DFSP VOLT,2,50,8,(dps1)
```

or

```
DFSP VOLT,2,50,,(@)
```
