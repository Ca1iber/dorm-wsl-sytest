# CNGV - (CoNnect Generate Vectors)

The CNGV (CoNnect Generate Vectors) command connects two consecutive GENV (GENerate Vectors) sequencer constructs. The length of the new construct is equal to the sum of the lengths of the two connected constructs.

## Predependencies

The CNGV command can only be issued after a label has been selected for editing with the TSTL command.

## Mode of operation

Inactive vectors at the end of the first construct are filled with active vectors of the second construct. This can have the effect that a complete memory word becomes inactive. In this case, the inactive word is deleted, and the STVA instructions of the labels that use later segments of the respective vector area are updated accordingly.

## Syntax

```
CNGV {(cmd_No)}
```

## Parameters

 |

cmd_No

 |

The command number which references the first of the two consecutive GENV sequencer constructs.

 |

## Application

Edit command in Pattern Tool.

## Errors

An error is generated if:

- There is insufficient channel memory.
- There is insufficient disk space (offline operation only).
- No label has been activated for editing.
- The specified command number is out of range.

## Example

```
> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,9,,,(@)
< SQPG 3,GENV,8,,,(@)
< SQPG 4,STOP,,,,(@)
> TSTL "test_1",(@)
> CNGV 2
> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,17,,,(@)
< SQPG 3,STOP,,,,(@)
```
