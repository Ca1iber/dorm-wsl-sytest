# UPOW, UPOW? - (Utility POWer)

The UPOW command switches a utility power supply on or off. The UPOW? query returns the current state of the power supply.

The utility power supplies that can be controlled or queried are the utility power supplies of the [optional Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>) or the [Internal utility power supplies](<../02.05_Test_Head_Cards/02.05.08.03.02_Internal_utility_power_supplies.md>).

Note The command UPOW ON is to be issued only once during test-flow execution.

## UPOW

```
UPOW {mode} [, supply, (resourceID)]
```

## UPOW?

```
UPOW? [supply, (resourceID)]
```

returns:

```
UPOW {state} [, supplyId, resourceID]
```

## Parameters

 | mode |

The mandatory parameter defines the new state of the supply.

Available options of the parameter:

- ON: Switches the supply on
- OFF: Switches the supply off
 |
 | supplyId |

The extra parameter defines the utility power supply to be set.

Available options of the parameter:

- UP5V: The [+5 V supply on UP5V pins](<../02.03_DUT_board_design_reference/02.03.05.01_Utility_power_supply_-_UP5V_pins__V93000_EXA_Scale_systems.md>) of the optional Utility Card or the internal utility resources.
- XPP5V: The [+5 V supply on XPP5V pins](<../02.03_DUT_board_design_reference/02.03.05.02_Utility_power_supply_-_XP_pins__V93000_EXA_Scale_systems.md>) of the optional Utility Card.
- XPM5V: The [-5 V supply on XPM5V pins](<../02.03_DUT_board_design_reference/02.03.05.02_Utility_power_supply_-_XP_pins__V93000_EXA_Scale_systems.md>) of the optional Utility Card.
- XPP3V3: The [+3.3 V supply on XPP3V3 pins](<../02.03_DUT_board_design_reference/02.03.05.02_Utility_power_supply_-_XP_pins__V93000_EXA_Scale_systems.md>) of the optional Utility Card.
- P15V: The [+15 V supply on UPP15V pins](<../02.03_DUT_board_design_reference/02.03.05.03_Utility_power_supply_-_UPP15V___UPM15V___F24V_pins__V93000_EXA_Scale_sys.md>) of the optional Utility Card.
- M15V: The [-15 V supply on UPM15V pins](<../02.03_DUT_board_design_reference/02.03.05.03_Utility_power_supply_-_UPP15V___UPM15V___F24V_pins__V93000_EXA_Scale_sys.md>) of the optional Utility Card.
- F24VA: The [floating 24 V supply on F24VA pins](<../02.03_DUT_board_design_reference/02.03.05.03_Utility_power_supply_-_UPP15V___UPM15V___F24V_pins__V93000_EXA_Scale_sys.md>) of the optional Utility Card.
- F24VB: The [floating 24 V supply on F24VB pins](<../02.03_DUT_board_design_reference/02.03.05.03_Utility_power_supply_-_UPP15V___UPM15V___F24V_pins__V93000_EXA_Scale_sys.md>) of the optional Utility Card.
- UDPS: The [Internal Utility Power Option](<../02.03_DUT_board_design_reference/02.03.05.04_Internal_Utility_Power_Option__V93000_EXA_Scale_systems.md>) of the internal utility resources that replaces the legacy [SE-UDPS](<../02.03_DUT_board_design_reference/02.03.05.07_Internal_Utility_Power_Supply__SE-UDPS___V93000_systems.md>).
The extra parameter must always be set in combination with the resourceID parameter. |
 | resourceID |

The extra parameter defines the utility power resource to be set.

Available options of the parameter:

- 1: First [optional Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>) or the [Internal utility power supplies](<../02.05_Test_Head_Cards/02.05.08.03.02_Internal_utility_power_supplies.md>) of the first card cage.
- 2: Second [optional Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>) or the [Internal utility power supplies](<../02.05_Test_Head_Cards/02.05.08.03.02_Internal_utility_power_supplies.md>) of the second card cage.
The extra parameter must always be set in combination with the supplyId parameter. |
 |

state

 |

The returned state of the queried supply.

 Possible values are:

- ON: The supply is switched on.
- OFF: The supply is switched off.
- TRIP: Returned in case of a power fail, for example: overcurrent or DUT board undocking.Note To switch on the supply again after such power fail events have occurred, you need to use `UPOW ON` followed by the extra parameters defining the supply and the resource.
   |  Some hints and restrictions for setting the extra supplyId and resourceID parameters:

- For compatibility with the [Internal utility power supply (V93000 systems)](<../02.03_DUT_board_design_reference/02.03.05.05_Internal_utility_power_supply__V93000_systems.md>), the UP5V supply of the first Utility Card or the internal UP5V supply of the first card cage is always switched on. The supply can be programmed by this FW command but it has no effect on the hardware.
- For compatibility with PinScale and SmartScale systems, the [Utility power supply - XP pins (V93000 EXA Scale systems)](<../02.03_DUT_board_design_reference/02.03.05.02_Utility_power_supply_-_XP_pins__V93000_EXA_Scale_systems.md>) of the first Utility Card can be programmed only using the short syntax `UPOW {state}` without the extra parameters defined. The supplyId parameter set to XPP5V, XPM5V, or XPP3V3 in combination with the resourceID parameter set to 1 is not supported.
- Independently switching the XPP5V, XPM5V, and XPP3V3 supplies is supported only for the second Utility Card with resourceID parameter set to 2.
- The supplyId parameter set to UDPS is supported only in combination with the resourceID parameter set to 1: Since, the second [optional Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>) occupies all (legacy) DPS pogo blocks, the [Internal Utility Power Option](<../02.03_DUT_board_design_reference/02.03.05.04_Internal_Utility_Power_Option__V93000_EXA_Scale_systems.md>) cannot be used if a second Utility Card is installed.

## Application

For information on the utility power supplies see [Utility power supplies](<../02.03_DUT_board_design_reference/02.03.05_Utility_power_supplies.md>).

## Errors

None

## Example

```
UPOW ON
```

Switches on the [Utility power supply - XP pins (V93000 EXA Scale systems)](<../02.03_DUT_board_design_reference/02.03.05.02_Utility_power_supply_-_XP_pins__V93000_EXA_Scale_systems.md>) of the first Utility Card.

## Functional changes

- Introduced in SmarTest 7.2.0
- SmarTest 7.10.1: Support of utility power supplies of V93000 EXA Scale systems.
