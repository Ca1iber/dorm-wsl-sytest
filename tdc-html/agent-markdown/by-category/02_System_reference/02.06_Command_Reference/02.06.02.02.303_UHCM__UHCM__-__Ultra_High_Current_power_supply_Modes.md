# UHCM, UHCM? - (Ultra High Current power supply Modes)

The UHCM (Ultra High Current power supply Modes) command is for DC Scale UHC4T and XPS256 pins only. The command supports the UHC4T and XPS256 features.

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Parameters

 | set_nr  | The mandatory identification number of the DPS set which you want to modify:

 | ALL  | Modifies all existing DPS sets. |
 | PRM  | Modifies the primary DPS set. |
 | ACT  | Only for the query: Displays the settings of the actual enabled DPS set.  | |
 | time_to_alarm |

The extra parameter specifies the time (in milliseconds) from constant current clamp until an alarm flag is raised. See also ms_const_curr_time_to_alarm in [DPSPINS resources](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>).

Range: 0 ... 1270 ms.

This parameter is supported only by the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

 |
 | reserved_param  | The optional parameter is reserved and required for compatibility. |
 | clamp_mode  | The optional parameter defines the clamp mode:

 | limit |

The clamp is active forever (the delay value is ignored).

This is the default value.

 |
 | `<delay>` |

Switch off at overcurrent after a delay.

<delay> is a time in milliseconds [ms].

For `<delay>`, the clamp is active until the channel switches off.

In case the channel is switched off, a disconnect/connect sequence is required ([PSST](<02.06.02.02.198_PSST__PSST__-__Power_Supply_STatus.md>) OFF/ON).

 |

See also [ms_const_curr_disconnect](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__ms_const_curr_disconnect>) in [DPSPINS resources](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>).

 |
 | fast_preload |

The optional parameter defines the preload time in milliseconds (ms).

To be used to charge large capacities for a programmable time. It does not make sense to set a shorter delay for clamp_mode than for fast_preload. A delay of zero (0) switches the fast_preload feature off.

See also [ms_fast_preload](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__ms_fast_preload>) in [DPSPINS resources](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>).

 |
 | openLoopProtection  |  The extra parameter defines the status of the internal force to sense connections.

The internal force to sense connections are available between the P# pin and the PS# pin and between the GS# pin and the common GND pin.

The following options are supported:

 | DIODE |

The internal force to sense connections are made via anti鈥憄arallel diodes.

This is the default state if the parameter is not defined.

This is the recommended setting if both parameters [force_drop](<02.06.02.02.303_UHCM__UHCM__-__Ultra_High_Current_power_supply_Modes.md#_106910__r_force_drop>) and [return_drop](<02.06.02.02.303_UHCM__UHCM__-__Ultra_High_Current_power_supply_Modes.md#_106910__r_return_drop>) are set to a value < 0.5 V.

 |
 | NONE |

The internal force to sense connections are open.

The output stage no longer has any voltage feedback if the force to sense connection on the DUT or the DUT board is (unintentionally) open.

 The following rules apply to this option:

- The [Vdrop Disco](<../02.05_Test_Head_Cards/02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_Vdrop_Disco>) parameter must be set to ON in the [DC Scale Safety editor](<../02.05_Test_Head_Cards/02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__s_DC_Scale_Safety_editor>).
- This is the required setting if one of the parameters [force_drop](<02.06.02.02.303_UHCM__UHCM__-__Ultra_High_Current_power_supply_Modes.md#_106910__r_force_drop>) or [return_drop](<02.06.02.02.303_UHCM__UHCM__-__Ultra_High_Current_power_supply_Modes.md#_106910__r_return_drop>) is set to a value 鈮?nbsp;0.5 V.
 |

This parameter is supported only by the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

 |
 | force_drop |

The optional parameter forces a channel to be disconnected if a user鈥慸efined voltage drop on the force lines is reached, which means that the absolute voltage is higher than the defined threshold.

The [DC Scale UHC4T card](<../02.05_Test_Head_Cards/02.05.05.02_DC_Scale_UHC4T_card.md>) and the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) can measure the voltage drop of the force line on the DUT board.

Card specific behavior:

-

UHC4T: A comparator defines if the voltage drop is small enough or not. This means to measure the drop of the pogo cable (see specifications) plus the drop of the DUT board. Value/flag available for all channels ganged.

The range is 0 to 0.5 V with a resolution of 1 mV. Default is 0.25 V.

Two rules have to be respected for the two parameters force_drop and return_drop and the programmed force voltage:

  - Both force_drop and return_drop must be between 0.0 V and 0.5 V.
  - The sum of force_drop and return_drop is limited by the programmed force voltage according to the diagram below. Only values within the red area are allowed.

- XPS256: force_drop can be an integer or string. In the string representation it is possible to also add a user-defined warning level for the voltage force drop. If this level is exceeded, a flag is raised, see [PSAS? - (Power Supply Accumulated Status)](<02.06.02.02.188_PSAS__-__Power_Supply_Accumulated_Status.md>).

The range is 0 to 1.0 V with a resolution of 1 mV. The total of theforce_drop and the return_drop must not exceed 1.0 V.

For a maximum voltage drop > 0.5 V, the [openLoopProtection](<02.06.02.02.303_UHCM__UHCM__-__Ultra_High_Current_power_supply_Modes.md#_106910__r_openLoopProtection>) parameter must be set to none and in the [DC Scale Safety editor](<../02.05_Test_Head_Cards/02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__s_DC_Scale_Safety_editor>) the [Vdrop Disco](<../02.05_Test_Head_Cards/02.05.05.03.10.05_XPS256_programming_-_Default_values.md#_354611__r_Vdrop_Disco>) parameter must be set to ON.

In case the channel is switched off, a disconnect/connect sequence is required ([PSST](<02.06.02.02.198_PSST__PSST__-__Power_Supply_STatus.md>) OFF/ON).

See also [max_voltage_drop_force](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__max_voltage_drop_force>) in [DPSPINS resources](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>).

This optional parameter is supported only by the [DC Scale UHC4T card](<../02.05_Test_Head_Cards/02.05.05.02_DC_Scale_UHC4T_card.md>) and the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

 |
 | return_drop |

The optional parameter forces a channel to be disconnected if a user-defined voltage drop on the return lines is reached, which menas that the absolute voltage is higher than the defined threshold.

The [DC Scale UHC4T card](<../02.05_Test_Head_Cards/02.05.05.02_DC_Scale_UHC4T_card.md>) and the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>) can measure the voltage drop of the return line on the DUT board.

Card specific behavior:

-

UHC4T: A comparator defines if the voltage drop is small enough or not. This means to measure the drop of the pogo cable (see specifications) plus the drop of the DUT board. Value/flag available for all channels ganged. The range is 0 to 0.5 V with a resolution of 1 mV. Default is 0.25 V.

Two rules have to be respected for the two parameters force_drop and return_drop and the programmed force voltage:

  - Both force_drop and return_drop must be between 0 and 0.5 V.
  - The sum of force_drop and return_drop is limited by the programmed force voltage according to the diagram below. Only values within the red area are allowed.

- XPS256: See [force_drop](<02.06.02.02.303_UHCM__UHCM__-__Ultra_High_Current_power_supply_Modes.md#_106910__r_force_drop>).

In case the channel is switched off, a disconnect/connect sequence is required ([PSST](<02.06.02.02.198_PSST__PSST__-__Power_Supply_STatus.md>) OFF/ON).

See also [max_voltage_drop_return](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md#_16887__max_voltage_drop_return>) in [DPSPINS resources](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>).

This optional parameter is supported only by the [DC Scale UHC4T card](<../02.05_Test_Head_Cards/02.05.05.02_DC_Scale_UHC4T_card.md>) and the [DC Scale XPS256 card](<../02.05_Test_Head_Cards/02.05.05.03_DC_Scale_XPS256_card.md>).

 |
 | pulldown |

The extra parameter specifies whether a pulldown resistor is active after disconnect.

 Supported values:

- OFF
- ON (default)
 |

The mandatory comma鈥憇eparated list of pins.

The @ character can be used to specify all applicable pins.

pinlist must contain the names of pins previously defined by the [DFPS](<02.06.02.02.65_DFPS__DFPS__-__DeFine_Power_Supply.md>) command.

 |

## Application

DC Scale XPS256 and DC Scale UHC4T configurations

## Errors

Non-XPS256 and Non-UHC4T pins cause an error.

## Example

```
UHCM PRM,,,,0.4,0.1,(Vee)
```

This example sets the voltage drop force to 0.4 V, and the voltage drop return to 0.1 V.
