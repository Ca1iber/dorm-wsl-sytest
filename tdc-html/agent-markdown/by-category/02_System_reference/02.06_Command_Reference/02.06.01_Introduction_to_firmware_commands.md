# Introduction to firmware commands

The commands described in this manual are firmware instructions which you can use for low level control of the test system.

You can do this in the following ways:

- issue firmware commands using the /opt/hp93000/soc/pws/bin/hpt or /opt/hp93000/soc/fw/bin/hpt utility.
- include firmware commands within test methods (with the FW_TASK API).
- issue firmware commands directly in the SmarTest Work Center's [Firmware view](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.08.08_Firmware_view.md>).

This manual describes the firmware commands required to:

- [Configuration Setup Commands](<02.06.03_Pin_configuration_setup_commands.md>)
- [Level Setup Commands](<02.06.05_Level_Setup_Commands.md>)
- [Routing Setup Commands](<02.06.04_Routing_Setup_Commands.md>)
- [Timing Setup Commands](<02.06.06_Timing_Setup_Commands.md>)
- [Vector Setup Commands](<02.06.07_Vector_Setup_Commands.md>)
- [Relays Control Commands](<02.06.08_Relays_and_Control_Commands.md>)
- [AC Test Function Commands](<02.06.09_AC_Testing_Commands.md>)
- [DC Measurement Commands](<02.06.10_DC_Measurement_Commands.md>)
- [Test Result Commands](<02.06.11_Test_Result_Commands.md>)
- [Utility Line Commands](<02.06.12_Utility_Line_Commands.md>))
- [Calibration and Attributes Commands](<02.06.18_Calibration_and_Attributes_Commands.md>))

Before you perform any of these functions, you must first read the following sections in this chapter which provide a firmware overview, describe how to use the /opt/hp93000/soc/pws/bin/hpt utility, and describe the use of the command [DSCP, DSCP? - (Define System Control Parameter)](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) for setting up a new device.

Full syntax descriptions for the commands are given in [Commands in alphabetical order](<02.06.02_Commands_in_alphabetical_order.md>).
