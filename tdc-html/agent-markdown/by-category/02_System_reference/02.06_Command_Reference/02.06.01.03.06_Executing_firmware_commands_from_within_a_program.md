# Executing firmware commands from within a program

You can execute firmware commands by an API in a

- user procedure, or
- test method.

## User procedures

From a user procedure, you can execute firmware commands with the HpFwTask function. For details see [HpFwTask](<../02.09_Test_Program_Management/02.09.01.09.21_HpFwTask.md>).

## Test methods

You can execute a firmware command from a test method with the FW_TASK API. For details see [FW_TASK](<../02.07_Test_Method_Reference/02.07.04.01.77_FW_TASK.md>).

## Related information
