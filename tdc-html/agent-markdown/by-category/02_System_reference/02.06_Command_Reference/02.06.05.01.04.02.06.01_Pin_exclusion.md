# Pin exclusion

The pin exclusion is an extension to the PINS syntax in timing and level equations for specifying a list of pins which are to be excluded from the preceding pin list.

 Note This function applies also to DPS pins.

You can specify pins from a group by specifying the group name and excluding the pins which are not required.

## Syntax

```
PINS <pin list> [-( <exclude pin list> )] [# comment]
```

Note You must type a blank between the left parenthesis and <exclude pin list> and a blank between <exclude pin list> and the right parenthesis.

## Example

```
LEVELSET 1 "normal"
PINS I_PINS -( i1+@diff ) # remove pair
vil=0
vih=4.3

PINS i1+@diff
vil=0
vih=3.3
```
