# TSUS, TSUS? - (Timing Sets USed)

The TSUS (Timing Sets USed) command defines the number of timing sets contained in a given waveform set. The number of defined waveform sets is not modified. The new value has to be an integer in the range of 1 to Maximum allowed timing sets as set by [CONF, CONF? - (CONFiguration)](<02.06.02.02.31_CONF__CONF__-__CONFiguration.md>). The [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) command defines the number of timing sets for all waveform sets.

The maximum number of all timing sets belonging to all waveform sets is 512. The default number is 256.

The maximum number of timing sets for one waveform set is 256. The maximum number in a single waveform set also equals the number of timing sets as determined by [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) minus the timing sets used in the remaining waveform sets.

There must be at least one timing set in each waveform set. Various waveform sets can have different numbers of timing sets (see also [Data organization of fixed timing](<02.06.06.01.07.01_Data_organization_of_fixed_timing.md>)).

You can use the TSUS command to delete timing sets. If the waveform set you are using, or the timing setup file that you want to load to hardware, contains more timing sets than you require, use TSUS to delete all the sets above the number you specify.

The TSUS? query returns the number of timing sets currently defined for the given waveform set.

## Equation based testing

In equation based testing, you must identify the appropriate wavetable instead of a waveform set. This is achieved by supplying a specset ID, calculated from equation set number and spec set number as follows: `100 * equation_set_no + specset_no`.

The appropriate wavetable is determined by looking at which wavetable is referenced by equation_set_no and specset_no in the timing specification file.

## TSUS

```
TSUS {waveform_set},{timing_set}
```

## TSUS?

```
TSUS? {waveform_set}
```

returns:

```
TSUS {waveform_set},{timing_set}
```

Or:

```
TSUS? {specset_id}
```

returns:

```
TSUS {specset_id},{timing_set}
```

Or, for multiport specifications:

```
TSUS? {"multiport_spec"}[,(portlist)]
```

returns:

```
TSUS {"multiport_spec"},{timing_set}[,(port)]
```

## Parameters

 |

waveform_set

 |

Waveform Set Number. Enter an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>). For the query command you can also enter ALL for all waveform sets.

 |
 |

specset_id

 |

Derived as follows: `100 * `equation_set_no `+ `specset_no

 |
 |

multiport_spec

 |

To query a multiport specification, enter the name of the specification.

 |
 |

timing_set

 |

Timing set number. This is the highest number currently allocated to a timing set or the highest number of timing set you want to associate with a given waveform set. The number you enter must be less than or equal to the maximum number of timing sets allowed (as defined by the [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) command). This number is automatically updated to include any new timing set as it is created. At power-on only one timing set (containing the default values and belonging to the single waveform set) is available.

 |
 |

portlist

 |

For multiport specifications, you can specify a list of the ports for which the number of the timing sets used is to be displayed.

 |

## Application

Timing setup, see [Timing Setup Commands](<02.06.06_Timing_Setup_Commands.md>).

## Errors

An error is generated if:

- timing_set is greater than the range allowed by the [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) command.
- waveform_set is greater than the range allowed by the [WSUS](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>) command.
- waveform_set is smaller than 1.
- specset_id is invalid because equation_set_no, specset_no, or both are invalid.
- specset_id does not reference a defined wavetable.

## Example

```
TSUS 3,7
```

This example defines a maximum of 7 timing sets in waveform set 3.

```
TSUS? "spefc",(ARMPort)
TSUS "spefc",3,(ARMPort)
```

This example queries the number of timing sets defined for port ARMPort in the multiport specification spefc.
