# Defining the break waveform

For every I or I/O pin, a break waveform can be defined. This waveform will be issued to the DUT when the sequencer is in the BREAK state (on which see the SQST command). Its definition is introduced by the keyword brk. It must not contain any receive action. The format of the break waveform depends on the card type. For standard pins, it is

brk"<edge_action_pair_sequence>",

and for fast pins

brk"<action_sequence>".

If you do not define a break waveform, a default definition with an empty definition string will be used, that is, the default break waveform will do nothing. A possible application for a user defined break waveform is to keep a PLL running during a whole testflow (see [Continuous Clock Setup](<../../03_Use_cases_and_application_papers/03.03_How_to_use_Multiport_for_specific_Applications/03.03.04.01_Continuous_Clock_Setup.md>)).

## Related firmware commands

You can retrieve the definition of the break waveform with the BWDS? query.
