# UPST, UPST? - (Utility Purpose STate)

The UPST command sets the output (desired) state of the utility lines in the specified utility purpose.

 After issuing the UPST command, you must issue the [FLSH](<02.06.02.02.124_FLSH_-__FLuSH_buffered_commands.md>) command in order to download the settings to the hardware.

The UPST? query returns the current output states.

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## UPST

```
UPST ["setting"], {(purpose_name)}
```

## UPST?

```
UPST? {(purpose_name)}
```

returns:

```
UPST "{setting}", {(purpose_name)}
```

## Parameters

 | setting |

The optional parameter specifies the status of the utility lines in the utility purpose.

The status is determined with the following specifiers:

-

0: Sets the output state of the corresponding (write) channel to high (high impedance state)

-

1: Sets the corresponding (write) channel to low

-

X (x): No action

Specify the setting values corresponding to the definition order of the utility lines in the specified utility purpose.

If this parameter is omitted, the settings defined by the [DFUP](<02.06.02.02.69_DFUP__DFUP__-__DeFine_Utility_Purpose.md>) or UPAS commands (depending on the setup focus as set with [PSFC](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>)) are set to the utility lines of the specified utility purpose.

 |
 | purpose_name |

Name of the utility purpose to be set or read.

For the query, you can specify multiple names, which must be separated by a comma.

Specifying the symbol @ returns the definitions of all utility purposes.

   | Note All utility lines that are set with [UTST](<02.06.02.02.313_UTST__UTST__-__UTility_line_STate.md>) or UPST will be switched in parallel when the [FLSH](<02.06.02.02.124_FLSH_-__FLuSH_buffered_commands.md>) command is performed. If the [WSDN](<02.06.02.02.341_WSDN_-__Wait_Setup_DoNe.md>) command is used immediately after FLSH, the time span during which execution will pause equals the longest settling time that is defined for any of the switched utility lines (with [UTTI](<02.06.02.02.314_UTTI__UTTI__-__UTility_line_settling_TIme.md>)) or purposes (with [UPTI](<02.06.02.02.307_UPTI__UPTI__-__Utility_Purpose_settling_TIme.md>)).

## Application

For details about utility purposes, see [Configuration Setup Commands](<02.06.03_Pin_configuration_setup_commands.md>).

## Errors

An error is generated if:

- The referenced utility line has not been defined before.
- Exclusive setting is found on the same channel.

## Example

```
UPST ,(AWG_CNCT)
FLSH
WSDN
UPST? (AWG_CNCT)
```

returns

```
UPST "0110",(AWG_CNCT)
```

This example sets the utility purpose "AWG_CNCT" to the hardware, then reads the state of the utility purpose.

## Functional changes

- Introduced before SmarTest 6.3.2
