# FTSM, FTSM? - (Functional Test Set Mask)

The FTSM (Functional Test Set Mask) command lets you set a cycle mask for the next execution of a pattern. The settings made with the FTSM command take effect only in the next sequencer run.

The following masking possibilities are available:

- Parameter mask_before

Lets you mask all cycles before a specific cycle. The cycles masked do not contribute to the pass/fail result.

- Parameter mask_after

Lets you mask all cycles after a specific cycle. The cycles masked do not contribute to the pass/fail result.

- Parameter run_to

Lets the sequencer run up to a specific cycle including this cycle.

## Syntax

```
FTSM {mode}, [run_to], [mask_before], [mask_after][,(ref_port)]
FTSM?
FTSM?
```

returns:

```
FTSM CLEAR, , ,
```

or

```
FTSM SET, [run_to], [mask_before], [mask_after][,(ref_port)]
```

  Parameters

 | mode  | Lets you set the mode of the FTSM command. The mode can be: |
 | SET  | In this mode the parameters run_to, mask_before, and mask_after are set and used in the next sequencer run. The original SQGB values are saved and restored with the next FTSM CLEAR command. |
 | CLEAR  | The FTSM parameters run_to, mask_before, and mask_after will be ignored by subsequent sequencer runs. Instead, the original SQGB values are restored. Original values are the values that had been active before execution of the FTSM SET command to set a specific mask. |
 | run_to |

The pattern is executed up to the specified cycle, including this cycle. This parameter cannot be used together with the mask_before or mask_after parameter except for two cases:

- If the mask_before parameter is set to 0.
- If the run_to parameter is set to N and the mask_after parameter to N + 1.

The cycle number must be within the range [0 ... 248 - 2]

 |
 | mask_before |

All cycles before the specified cycle are masked and do not contribute to the pass/fail result. The specified cycle is not masked.

If mask_before is not a multiple of 8, cycles will be recorded starting from the next lowest multiple of 8, but those up to the specified cycle will be discarded afterwards.

 |
 | mask_after  | All cycles after the specified cycle are masked and do not contribute to the pass/fail result. The specified cycle is not masked. (Recording will run to the end of the test, but the cycles following the specified one will be discarded afterwards.) |
 | ref_port |

For a multi-port burst, this parameter specifies the reference port to which the cycle numbers of the run_to, mask_before, and mask_after parameters refer.

If you have set the run_to parameter, then the sequencers will be stopped for all ports after the reference port has completed the requested number of cycles. The mask_before, and mask_after parameters are only applied to the specified port. The other ports will not be masked,

Note that the reference port must belong to the current start label (as defined by SQSL).

   |  Application Used in the parametric functional test. Errors and warnings

An error is generated if:

- A value (run_to, mask_before, mask_after) is not in the valid range of [0... 248 - 2].
- The run_to and mask_before parameters are specified, and run_to is equal or bigger than mask_before.
- The run_to and the mask_after parameters are specified, and run_to is bigger than mask_after.

A warning is generated if:

- The run_to parameter and the mask_before parameter are specified and run_to < mask_before. In this case the pattern executed will always pass as all cycles executed are masked out for result evaluation.
- The run_to parameter and the mask_after parameter are specified and run_to <= mask_after. In this case the entry for the mask_after parameter can be omitted as the sequencer will not even execute the cycles that are masked out.

## Example

```
FTSM?
```

returns:

```
FTSM CLEAR, , ,
FTSM SET, ,10,20
```

The FTSM? query returns the current FTSM settings.

The FTSM SET command masks all cycles except for those in the range from cycle 10 to cycle 20.

- Introduced before SmarTest 6.3.2
