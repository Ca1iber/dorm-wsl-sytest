# RRUD - (Result Retention area UnDefine)

Removes all previously defined result retention areas.

## Syntax

```
RRUD
```

If the result area is currently selected for recording or upload, it will be deactivated.

## Application

Result area management for hidden digital upload.

## Functional changes

- Introduced in SmarTest 6.5.3
