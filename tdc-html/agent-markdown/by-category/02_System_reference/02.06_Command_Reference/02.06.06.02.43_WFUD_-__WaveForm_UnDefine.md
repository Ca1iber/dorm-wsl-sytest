# WFUD - (WaveForm UnDefine)

The WFUD command deletes a logical waveform (as defined by [WFDF](<02.06.02.02.334_WFDF__WFDF__-__WaveForm_DeFinition.md>) or [WFDS](<02.06.02.02.335_WFDS__WFDS__-__WaveForm_Definition_String.md>)) and all its associated physical waveforms (as defined by [WAVE](<02.06.02.02.333_WAVE__WAVE__-__WAVEform.md>)) in fixed timing. It can also be used to delete the runtime definition of a logical or pure physical waveform in an equation based timing.

## Syntax

```
WFUD {wvf_set},{wfIndex},{(pinlist)}
WFUD {specset_id|"multiport_spec"}, {wfIndex}, [mode], {definition_string}, {(pinlist)}, ALLOW_EQ
```

## Parameters

 |

wvf_set

 |

Waveform set number. Enter an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>).

 |
 |

wavetable_name

 |

The wavetable name. Enter a string of up to 40 alphanumeric characters (upper or lower case) enclosed in double quotes.

 |
 |

specset_id

 |

Derived as follows:

`100 *`equation_set_no `+ `specset_no

 |
 |

multiport_spec

 |

To change or query a multiport specification, enter the name of the specification.

 |
 |

wfIndex

 |

Logical waveform index. Enter an integer between 0 and 31 (255 on Pin Scale systems).

 |
 |

pinlist

 |

The name of the pin or pins for which the waveform is to be deleted. This parameter can also include groups previously created by [DFGP, DFGP? - (DeFine GrouP)](<02.06.02.02.60_DFGP__DFGP__-__DeFine_GrouP.md>). The @ symbol can be used to specify all configured input pins. If more than one pin is to be included, the names must be separated with a comma.

 |
 |

ALLOW_EQ

 |

This extra parameter allows you to delete a logical waveform for an equation based timing. Note that only the runtime settings are affected; the definitions in the wavetable are not changed.

Note also the following:

- Every runtime change will affect all specifications that use the respective wavetable.
- Since the new or changed waveform must be evaluated and downloaded for every specification that uses the respective wavetable, the change tends to be rather slow.
 |

## Application

Timing setup, see [Timing Setup Commands](<02.06.06_Timing_Setup_Commands.md>).

## Errors

An error is generated if wvf_set is greater than the range allowed by the [WSUS](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>) command.

## Example

```
WFUD 1,2,(D0,D2,D2,D3)
```

This example deletes a logical waveform defined for waveform set 1 and for pins `D0` to `D3`, referenced by waveform index 2.

## Functional changes

- Introduced before SmarTest 6.3.2
