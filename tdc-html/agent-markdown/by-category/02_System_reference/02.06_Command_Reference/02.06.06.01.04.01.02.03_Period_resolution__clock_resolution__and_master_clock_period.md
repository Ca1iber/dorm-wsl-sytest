# Period resolution, clock resolution, and master clock period

From the period resolution, SmarTest derives two other time spans which it needs internally. These are the clock resolution and the master clock period. Both of them are usually of interest only for debugging purposes.

For SmarTest 7.10 the master clock period is fixed at 8/3 = 2.67 ns (frequency of 375 MHz).

The clock resolution must be taken into account in certain situations (see, for example, [JSCF, JSCF? - (Jitter Set ConFiguration)](<02.06.02.02.147_JSCF__JSCF__-__Jitter_Set_ConFiguration.md>)). For the PS1600 card the clock resolution must be between 1.76 and 3.52 ns.

You can retrieve the clock resolution with the [CLKR? EXACT](<02.06.02.02.24_CLKR__CLKR__-__CLocK_Resolution.md>) firmware query. For PS1600 it is determined as follows:

clock_resolution = (m/n) * master_clock_period = period_resolution/p,

where p is an integer such that 1.76 鈮? clock_resolution 鈮?3.52 ns.

p is selected so that rounding errors are avoided or at least minimized. If several integers produce an exact result or the same minimal rounding error, the smallest of these is used (so that the clock resolution is as great as possible).
