 Firmware commands are used for low level control of the test system. In general it is recommended to use instead

- [SmartRDI](<../02.07_Test_Method_Reference/02.07.13_SmartRDI.md>)
- [Testmethod API](<../02.07_Test_Method_Reference/02.07.04_API_Reference.md>)
when possible, and in that order, and only work with firmware commands if none of these meets your need.

Examples for when firmware commands can be necessary are queries like [CHFA? - (CHannel FAil flag)](<02.06.02.02.21_CHFA__-__CHannel_FAil_flag.md>) or [CHER? - (CHeck ERrors)](<02.06.02.02.20_CHER__-__CHeck_ERrors.md>) which can be used to get pin specific test results.

Any firmware queries report setup and results for the site currently in focus only.
