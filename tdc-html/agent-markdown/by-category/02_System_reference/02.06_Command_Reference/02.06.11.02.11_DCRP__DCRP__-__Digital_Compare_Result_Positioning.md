# DCRP, DCRP? - (Digital Compare Result Positioning)

The DCRP command defines the recording position for Error Map recording. The interpretation of the recording position is defined with the DCGM command separately for both Error Maps; the position can be used as a start or a stop position, or it can be ignored.

The DCRP? query returns the current settings. It interprets the position value according to the current DCGM settings.

To specify a start or stop position for the Error Map does not make sense if the current sequencer mode is EL, SE, or SEEL (as set with SQGB). As for sequencer modes STSQ and STSV, recording is always stopped by stopping the sequencer. Therefore, a definition of the Error Map position with DCRP is ignored (and a warning will be issued), if any non-standard sequencer mode is active. The definition is stored, however, and can be (re)activated by changing the sequencer mode to STRD with SQGB.

## DCRP

```
DCRP {error_map_pos},{(ref_port)}
```

## DCRP?

```
DCRP? [answer_type,]{(port_list)}
```

returns:

```
DCRP {error_map_pos},{(port)}
```

## Parameters

 |

error_map_pos

 |

Specifies the start or stop position for Error Map recording. The interpretation of the value is determined by DCGM independently for both error maps:

- If the current interpretation mode is STRT, the value specifies the first cycle to be recorded. This applies only to the detailed Error Map.
- If the current interpretation mode is HALT, the value specifies the first cycle that will not be recorded any more.
- If the current interpretation mode is NONE, the value can also be specified, but it is ignored until the interpretation mode is changed.

The range of the value must be between 0 and 248 - 1

If the value is interpreted as a start (stop) value, recording will start (stop) at the largest multiple of 8 smaller than error_map_pos.

 |
 |

ref_port

 |

This parameter specifies the single port which is used for counting the cycles specified with the error_map_pos parameter. When this reference port has completed the specified number of cycles, cycle recording will be started or stopped for all ports. Note that the reference port must belong to the start label. In particular, you must specify the default @ for single port start labels.

 |
 |

port_list

 |

In the query, you can specify a port list. For the ports that are not used as the reference port, the reply will return the calculated Error Map positions. These are derived from the Error Map position of the reference port and the ratio between the period lengths of the reference port and the other port in the primary timing setup. If you specify @@, DCRM? will return the settings for all ports of the current start label.

 |
 |

answer_type

 |

This query parameter specifies whether the current configuration or the configuration of the last executed test is to be returned. Possible values are:

 |
 |

 |

CONF

 |

The current configuration is returned. This is the default.

 |
 |

 |

EXEC

 |

The configuration of the last executed test is returned.

 |

## Application

Error Map.

## Examples

### Example 1

```
> PCLK? "mu_burst",1,(@@)
< PCLK "mu_burst",1,20,(P1)
< PCLK "mu_burst",1,10,(P2)
> DCGM ALL,STRT,NONE
> DCRP 20,(P2)
> DCRP? (@@)
< DCRP 10,(P1)
< DCRP 20,(P2)
```

This example illustrates the calculation of the cycle numbers for the ports that are not used as the reference port. For interpretation mode STRT, recording will start for the reference port `P2` with cycle 16 (largest multiple of 8 smaller than 20). Since the period length for `P1` is twice the period length of `P2`, recording for `P1` will start with cycle 8 (largest multiple of 8 smaller than 10).

### Example 2

```
> SQGB STSQ,14,(P2)
> DCGM ALL,HALT,NONE
> DCRP 20,(P2)
> DCRP? (@@)
< DCRP 7,(P1)
< DCRP 14,(P2)
> SQGB STRD,
> DCRP? (@@)
< DCRP 10,(P1)
< DCRP 20,(P2)
```

This example shows that a definition of the Error Map position with DCRP is ignored when the sequencer mode is STSQ, but that it can subsequently be activated. Note that the DCGM command only serves to make the initial ineffectiveness of the definition visible. It is not possible to execute a functional test with these settings when the sequencer mode is STSQ.
