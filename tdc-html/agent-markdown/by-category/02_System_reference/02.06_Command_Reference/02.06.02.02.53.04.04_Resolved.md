# Resolved

The syntax to return the Resolved results to the query is:

```
DDEF? "ListName",Resolved
```

or

```
DDEF? All,Resolved
```

## Example

1. If list A and list B are defined as:

```
DDEF "A",SET,"Equation","3 4 5"
DDEF "B",SET,"Equation","Loop(3,5,3)"
```

then `DDEF? "A",Resolved` will return:

```
DDEF "A",DATA,"Length",3
DDEF "A",DATA,"Max",5
DDEF "A",DATA,"Min",3
DDEF "A",DATA,"Values",#9000000042 3.000000e+00      4.000000e+00 5.000000e+00
```

and `DDEF? All,Resolved` will return:

```
DDEF "A",DATA,"Length",3
DDEF "A",DATA,"Max",5
DDEF "A",DATA,"Min",3
DDEF "A",DATA,"Values",#9000000042 3.000000e+00      4.000000e+00 5.000000e+00
DDEF "B",DATA,"Length",3
DDEF "B",DATA,"Max",5
DDEF "B",DATA,"Min",3
DDEF "B",DATA,"Values",#9000000042 3.000000e+00      4.000000e+00 5.000000e+00
```

2. If list A is defined as:

```
DDEF "A",SET,"Equation","RepeatValue(0x55555555,2)"
```

then `DDEF? "A",Resolved` will return:

```
DDEF "A",DATA,"Length",2
DDEF "B",DATA,"Values",#9000000019 55555555 55555555
```

## Functional changes

- Introduced before SmarTest 6.3.2
