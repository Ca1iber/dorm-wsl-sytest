# Commands for the TMU per pin

#### Subtopics

- [Concepts of the TMU per pin](<02.06.13.01_Concepts_of_the_TMU_per_pin.md>)
- [List of commands for the TMU per pin](<02.06.13.02_List_of_commands_for_the_TMU_per_pin.md>)

This chapter describes the commands for the TMU per pin. The TMU (Time Measurement Unit) per pin is used to measure, among other things, the pulse width, period length and rise and fall times of periodic or non-periodic output signals.
