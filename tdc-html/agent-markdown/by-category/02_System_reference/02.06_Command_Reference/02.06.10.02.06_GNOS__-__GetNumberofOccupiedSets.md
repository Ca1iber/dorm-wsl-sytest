# GNOS? - (GetNumberofOccupiedSets)

GNOS? queries the occupied and maximum numbers of measurement sets and set actions within a DC set.

Exceeding the maximum numbers can reduce the software performance significantly.

With GNOS? you can check how many sets are already allowed and used, which in return can help you to optimize your measurement setup.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Syntax

GNOS? {set_type}

returns:

GNOS {NumberOfOccupiedSets},{MaxNumberOfSets},{NrOfOccupiedMSetActions},{MaxNumberOfMSETActions}

## Parameters

 |

set_type

 |

Must be MSET

 |
 |

NumberOfOccupiedSets

 |

Number of the current sets

 |
 |

MaxNumberOfSets

 |

Maximum allowed number of sets

 |
 |

NrOfOccupiedMSetActions

 |

Number ot the current set actions

 |
 |

MaxNumberOfMSETActions

 |

Maximum number of actions (pmu_set)

 |

## Application

DC measurements

## Example

```
> DSCP 4096,16,256,32,32,12800,16,1,256,9
> GNOS? MSET
< GNOS MSET,1,3201,1,12800
```
