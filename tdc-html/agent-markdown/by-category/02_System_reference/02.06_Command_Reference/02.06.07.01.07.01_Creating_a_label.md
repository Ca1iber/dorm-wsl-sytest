# Creating a label

#### Subtopics

- [Creating a label with low level commands](<02.06.07.01.07.01.01_Creating_a_label_with_low_level_commands.md>)
- [Creating a label with edit commands](<02.06.07.01.07.01.02_Creating_a_label_with_edit_commands.md>)

We will describe how to create the second label of the standard example. The label will be appended to the sequencer area, as is usual for new labels.

You can perform this task with low level commands or with high level commands. We will describe both methods.

## Functional changes

- Introduced before SmarTest 6.3.2
