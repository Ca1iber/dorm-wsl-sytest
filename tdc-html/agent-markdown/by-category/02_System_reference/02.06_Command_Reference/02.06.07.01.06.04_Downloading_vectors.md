# Downloading vectors

There are low level and edit commands for downloading vectors:

 |

Command

 |

Description

 |
 |

VECD

 |

Low level command which must be called with an absolute address. You can download any number of vectors with one call of this command. For an example, see [Creating a label with low level commands](<02.06.07.01.07.01.01_Creating_a_label_with_low_level_commands.md>).

 |
 |

VECC

 |

Same as VECD, except that the vector input data must be in compressed binary format.

 |
 |

VDCP

 |

Edit command which specifies the waveform DC/DC power units by the device cycle names. VDCP must be called with logical vector numbers. You can download one index with VDCP in the pure physical waveform format. For an example, see [Creating a label with edit commands](<02.06.07.01.07.01.02_Creating_a_label_with_edit_commands.md>).

 |
 |

VDCN

 |

Essentially the same as VDCP.

 |
 |

GETA?

 |

Edit query which can be used as a tool for low level vector download. It returns the absolute address of the vector at a specified logical vector number of the label currently activated for editing.

 |
