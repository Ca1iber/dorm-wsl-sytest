# DELI - (DELete Instruction)

The DELI (DELete Instruction) command removes sequencer instructions from the sequencer area of a port.

## Predependencies

The DELI command can only be issued after the label to which the sequencer instructions belong has been selected for editing with the TSTL command.

## Mode of operation

For all vector generating instructions, the instruction but not the associated vectors are deleted.

## Syntax

```
DELI {cmd_No}, {count}
```

## Parameters

 |

cmd_No

 |

The command number which references the first sequencer instruction to be deleted.

 |
 |

count

 |

This parameter defines the total number of instructions to be deleted.

 |

## Application

Edit command in Pattern Tool.

## Errors

An error is generated if:

- There is insufficient channel memory.
- There is insufficient disk space (offline operation only).
- No label has been selected for editing.
- The specified command number is out of range.
- The specified instruction count is negative.

## Example

```
> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,27,,,(@)
< SQPG 3,RPTV,7,5,,(@)
< SQPG 4,STOP,,,,(@)
< SQPG 5,STVA,544,,,(@)
< ...
> DELI 2,1
> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,RPTV,7,5,,(@)
< SQPG 3,STOP,,,,(@)
< SQPG 4,STVA,544,,,(@)
< ...
```

This example deletes the sequencer instruction with command number 2 from the sequencer area of the default port @. Note that since the vectors of the instruction are not deleted, the start address of the following label (STVA instruction at command number 4) does not change.

## Functional changes

- Introduced before SmarTest 6.3.2
