# Parameters

 |

Parameter

 |

ListName: User-defined unique name to identify what type of data list is being defined. It is a string without a ".".

All: To query all lists' information. Only Defined and Resolved can be used for the query All.

Defined tells about the definition, type, name, and comment of a list.

Resolved describes the list's data.

Both keywords return more than one type of information.

 |
 |

Definition

 |

This is a case-sensitive, predefined keyword. The available types are Equation and Values.

 |
 |

Function

 |

This can be a list of elements separated by a space or spaces, or a predefined function.

 |
