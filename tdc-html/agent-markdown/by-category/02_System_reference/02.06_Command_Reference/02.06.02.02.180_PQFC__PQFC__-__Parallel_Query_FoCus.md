# PQFC, PQFC? - (Parallel Query FoCus)

The PQFC command defines which site has the query focus. This site is the only site for which setup data can be retrieved or results displayed. The PQFC? query returns the site which currently has the query focus.

After loading the pin configuration the query focus is set to the first available site. This might not be site 1. The available sites are represented by a "1" in the reply to [PSTE?](<02.06.02.02.199_PSTE__PSTE__-__Parallel_SiTe_Enable.md>) STR.

CAUTION This command implements the tpi interface for multisite testing. Use the tpi call instead of this firmware command.

## PQFC

```
PQFC {site}
```

## PQFC?

```
PQFC?
```

## Parameters

 |

site

 |

The site parameter is single integer representing the number of the site that has or shall have the query focus.

 |

## Application

Site Control window. \

## Warnings

PQFC returns a warning if the specified site is not available. In such cases the query focus is not changed.

## Errors

An error is generated if not all pins at the site have had their channels assigned by the PALS command. \

## Example

```
PQFC 2
```

This example sets the query focus to site 2.

## Functional changes

- Introduced before SmarTest 6.3.2
