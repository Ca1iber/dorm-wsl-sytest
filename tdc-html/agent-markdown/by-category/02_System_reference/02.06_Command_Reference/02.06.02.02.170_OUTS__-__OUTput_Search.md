# OUTS? - (OUTput Search)

The OUTS? query scans the expected data looking for the first occurrence of a logic 0 or logic 1 state.

 Note In case of a burst, the vector search is limited to the first called Main pattern.

## Syntax

```
OUTS? {vector_no_1}, [vector_no_2], {vector_type}, {level_type}, {(pinlist)} [, (port)]
```

returns:

```
OUTS {cycle_no}, {output_level}, {(pinlist)}
```

## Parameters

 |

vector_no_1

 |

This parameter is an absolute vector number or a range specifier depending on whether DPTH, SNGL, or RNG has been selected.

 |
 |

vector_no_2

 |

This parameter is an absolute vector number.

 |
 |

vector_type

 |

The vector_type is one of the following:

 |
 |

DPTH

 |

The depth option. The vector table is searched from the current start label (defined by the label parameter or by the SQSL command) for the number of vectors specified in the vector_no_1 parameter. The vector_no_2 parameter must be omitted.

 |
 |

SNGL

 |

The single option. Only the vectors specified in the vector_no_1 and vector_no_2 parameters are searched.

 |
 |

RNG

 |

The range option. The range of vectors between (and including) vector_no_1 and vector_no_2 are searched.

 |
 |

level_type

 |

The level_type is one of the following:

 |
 |

HIGH

 |

If HIGH is selected, the system looks for a high level (logic 1 state).

 |
 |

LOW

 |

If LOW is selected, the system looks for a low level (logic 0 state).

 |
 |

BOTH

 |

If BOTH is selected, the system looks for both levels.

 |
 |

pinlist

 |

The pinlist can contain O, or IO pins. If all pins configured as outputs are to be searched, use the @ character. If more than one pin is included, the names must be separated by a comma.

 |
 |

port

 |

If you issue the query in a multi-port test, you must specify one of the pattern ports in order to determine the search range uniquely.

 |
 |

cycle_no

 |

The cycle number of the first occurrence of a logic 0 or logic 1 state.

 |
 |

output_level

 |

The output_level is one of the following:

 |
 |

LOW

 |

This indicates that a logic 0 occurs at the given cycle.

 |
 |

HIGH

 |

This indicates that a logic 1 occurs at the given cycle.

 |

## Application

DC measurements.

## Errors

An error is returned if:

- The sequencer program mode is per pin (PPIN).
- There is no active start label (you can define one using the command [SQSL, SQSL? - (SeQuencer Start Label)](<02.06.02.02.240_SQSL__SQSL__-__SeQuencer_Start_Label.md>)).
- You define a RNG search and vector_no_1 is greater than vector_no_2.
- You define a RNG search and the defined range is outside the current sequencer start label.
- You define a SNGL search and the defined vectors lie outside the current sequencer start label.
- You define a SNGL search and one of the vectors is not applicable (part of a match loop).
- You define a RNG or DPTH search and the resulting vector range only contains one vector.
- No waveform data (WAVEs) supplied for the waveform definitions (WFDS) in the current waveform set, see the commands [WAVE, WAVE? - (WAVEform)](<02.06.02.02.333_WAVE__WAVE__-__WAVEform.md>) and [WFDF, WFDF? - (WaveForm DeFinition)](<02.06.02.02.334_WFDF__WFDF__-__WaveForm_DeFinition.md>).
- The vector depth or range is too large.

## Warnings

A warning is generated if:

- The active level set at the returned cycle_no is not the primary level set.
- A logical 0 or logical 1 state is not found for the desired pin.
- The vector_no_2 parameter was ignored due to the selection of vector_type DPTH.
