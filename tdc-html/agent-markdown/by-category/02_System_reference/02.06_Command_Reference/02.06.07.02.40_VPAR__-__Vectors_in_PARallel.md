# VPAR? - (Vectors in PARallel)

The VPAR? query returns the command numbers of sequencer instructions (in the sequencer area) together with the logical address of the first vector affected by the instruction for a certain range of the vector areas.

The purpose of this command is to tell the Vector Setup screen where to display the sequencer instructions. The logical vectors are displayed in rows on this screen.

The VPAR? command can only be issued after a label has been selected for editing with the [TSTL](<02.06.02.02.281_TSTL__TSTL__-__TeST_Label.md>) command.

Note that the VPAR? query only returns information about the currently selected label, not about the vector area as a whole. Thus, for example, `VPAR? 0,100` checks the vector setup in the range 0 to 100 of the currently selected label.

## Syntax

```
VPAR? {start_vec_No}, {stop_vec_No}
```

returns:

```
VPAR {cmd_No}, [frst_used_vec]
```

## Parameters

 |

start_vec_No

 |

Defines the offset of the first vector to be searched from the start vector of the currently selected label. The specified address must not exceed the maximum vector address allowed by the system.

 |
 |

stop_vec_No

 |

Defines the last vector in the search range. The specified address must not exceed the maximum vector address allowed by the system.

 |
 |

cmd_No

 |

In the reply, the number of the command within the sequencer area, or NISQ - see below.

 |
 |

frst_used_vec

 |

Returns the logical address of the first vector affected by the sequencer instruction.

 |

NISQ (Non-Interpretable SeQuence) indicates that the sequencer program does not respect its context conditions. This means, there is non-linear use of vectors, or there are partial "Match Begin" or "Match End" sequences (for example a WTER without its MBGN, a MJPE without its MEND - see the SQPG command). The label is no longer displayable by the Vector Setup in this case. No frst_used_vec parameter is returned when the parameter cmd_No is NISQ.

## Application

Edit command in Pattern Tool.

## Errors

An error is generated if:

- No label has been activated for editing.
- The start vector number is outside the allowed range.
- The stop vector number is outside the allowed range.
- The stop vector number is lower than the start vector number.
- You enter a negative start or stop vector number.

## Example

```
> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,10,,,(@)
< SQPG 3,RPTV,6,5,,(@)
< SQPG 4,STOP,,,,(@)
> VPAR? 0,15
< VPAR 0,0
< VPAR 1,0
< VPAR 2,0
< VPAR 3,10
```

This example displays the sequencer instructions of the selected label before calling VPAR? in order to make its reply understandable.
