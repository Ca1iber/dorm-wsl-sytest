# MVCU - (Modify Vector variable Configuration Usage)

The MVCU (Modify Vector variable Configuration Usage) command modifies the usage defined for a Vector Variable Configuration (VVC), using the same parameters as DVCU (see [DVCU, DVCU? - (Define Vector variable Configuration Usage)](<02.06.02.02.96_DVCU__DVCU__-__Define_Vector_variable_Configuration_Usage.md>) for more information.

## Syntax

```
MVCU {label name}, {VVC name}, {vector offset}, {Init Discard Frames}, {Number Of Frames}, {VarNameDef}, {InitStaticData}
```

Parameters
 |

label name

 |

Name of the label for which usage is to be modified.

 |
 |

VVC name

 |

Name of the Vector Variable configuration. Refer to [DVVC, DVVC? - (Define Vector Variable Configuration)](<02.06.02.02.95_DVVC__DVVC__-__Define_Vector_Variable_Configuration.md>) for more information.

 |
 |

Vector offset

 |

This is the offset in the label where usage needs to be modified. Vector offset is the logical vector number in the label. A usage with this combination of parameters {label name, VVC name, Vector offset} should already exist in the system, when defined by DVCU.

 |
 |

Init Discard Frames

 |

This is a reserved parameter. For future use.

 |
 |

Number Of Frames

 |

Number Of Frames to which this usage refers. If the label is DSRC, usage allocates this many frames. If the label is a main label, usage refers to this many frames.

 |
 |

VarNameDef

 |

This parameter specifies the vector variable names for the variable names defined in VVC. This parameter is a string.

Syntax:

`"VVC_NAME=VEC_VAR_NAME[,VVC_NAME=VEC_VAR_NAME[,.....]]"`

There is no need to have aliases (vector variable names) for all the variables in VVC.

 |
 |

InitStaticData

 |

This parameter is either TRUE or FALSE.

TRUE: Static data will be downloaded on definition of usage.

FALSE: Static data will not be downloaded.

 |

## Application

Digital source memory application.

## Errors

An error is generated for the following reasons:

- Not enough memory.
- Usage does not exist with the combination of label, VVC and offset.
- Overlapping with other usages, but with a frame pattern that is different from the existing one.
- Given vector variable already exists.

## Example

The following example modifies the usage to change vector variable names. This usage is defined for the label "src" using VVC "AC97" at offset 0.

VVC "AC97" looks like:

```
ATTR DIGDATA
  VARIABLES LEFT,RIGHT
  PINS ser_in
     SOURCE_DATA_TEMPLATE LEFT[0-19]; RIGHT[0-19]
     MAPPING
         0 low
         1 high
>MVCU"src_ramp","AC97",0,0,1024,"LEFT=Sine,
 RIGHT=Ramp",TRUE
>DVCU? ALL,ALL,ALL
<DVCU "src_ramp","AC97",0,0,1024,"LEFT=Sine,
 RIGHT=Ramp",TRUE
```
