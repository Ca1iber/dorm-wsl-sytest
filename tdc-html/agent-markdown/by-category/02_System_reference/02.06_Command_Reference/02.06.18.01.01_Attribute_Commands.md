# Attribute Commands

The attribute commands contained in this section are the commands used to insert compensation delays in the system. These are required to allow for the time taken for a signal to reach the DUT, and the time taken for a signal emitted by the DUT to reach the measurement circuitry.

The command FXDL sets the delay for the lines on the DUT board. These delays are applied on a per channel basis.

The command PATR sets delays associated with receiver and driver circuitry on a per pin basis, while SATR sets the common system receiver delay.

The values of the delays to be applied come from the calibration measurements that you have already performed.

The following are the attributes commands:

FXDL / FXDL? FiXture DeLay

PADS / PADS? Pin Attributes Definition String

PTDS / PTDS? Pin attributes Tweaking Definition String

SATR / SATR? System ATtRibutes
