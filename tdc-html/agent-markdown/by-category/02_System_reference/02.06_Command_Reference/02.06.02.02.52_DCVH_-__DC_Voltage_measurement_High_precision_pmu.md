# DCVH - (DC Voltage measurement High precision pmu)

The DCVH command allows you to define a voltage measurement using a DC signal pin. To assign the measurement to a DC set you use the DC set ID.

The content of a DC set defined with DCVH can be retrieved with the [DCST?](<02.06.02.02.50_DCST__-__DC_SeT.md>) query.

To execute the measurement use the DC set execution command ([DCEX](<02.06.02.02.43_DCEX_-__DC_set_EXecute.md>)). To retrieve results use the DC result query ([DCRE?](<02.06.02.02.45_DCRE__-__DC_set_REsult.md>)).

The threshold will be evaluated internally for the pass/fail result.

The measurement is valid for the specified channels until minimum one of these conditions occurs:

- A measurement for the same DC set is redefined for the channel.
- A reset is executed ([DCCH](<02.06.02.02.40_DCCH_-__DC_Current_measurement_High_precision_pmu.md>), DCVH, [*RST](<02.06.02.02.345_RST_-__ReSeT.md>), [RSET DC](<02.06.02.02.210_RSET_-__ReSET.md>), [UDEF](<02.06.02.02.295_UDEF_-__UnDEFine_pin.md>)).

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

The previously defined parameters are applied to all pins, which are specified with the pinList parameter. If more than one pin is specified, pin names must be separated by commas. pinList can contain pins configured as O, I, IO, or DC pin types.

 | refPinList |

Some connection states (HC_AWG, DIFF_VM) require a reference pin. This extra parameter defines a single pin or a list of pins that are used as reference pin for the pins defined by pinList.

The reference pin defines always the low force or low sense pin(s). These pins are the LF pin of the floating high-current unit or the LS pin of the differential voltmeter.

Each pin in the refPinList corresponds to a pin in the pinList. Both lists must have the same number of pins defined. The first pin in refPinList belongs to the first pin in pinList.

The refPinList cannot be defined if pinList defines all pins or more than the half of the available pins that support a reference pin based connection state.

A "single-ended" connection mode will be selected if refPinList is omitted and no reference pin is defined: The low force pin and the low sense pin of the floating resource are connected to the common ground and the channel specific ground sense input.

The reference pin is currently not supported.

## Reset

To reset the DC Set for all pins omit all parameters and specify all pins (@) in the pinList. This also resets existing voltage measurements belonging to the same DC Set.

For example: `DCVH 1,,,,,,,,,(@)`

A reset resets all measurements for the specified DC Set ID and pins. It does not care about current or voltage measurement definitions. This means a voltage measurement with DC Set ID 1 for pin p1 that has been defined by the DCVH command can be reset by the DCCH command.

## Notes

- Different Settling times for parallel measurements with the same ID will internally wait for the specified maximum settling time.
- For HIZ measurements on digital pins the board ADC is used. The force parameters are optional, or will be ignored if specified.
- If none of the voltage or current ranges is given the maximum of the calculated ranges (either force, measure, or clamp) is set.
- The force range values controls raw supply of the channel. If no force range is specified the measurement range is used. If no range is specified the force value is used.

## Errors

An error is returned:

- If any parameter is out of the allowed range (hardware dependent).
- If any parameter is missing.
- If the force and measure range of the same type (current or voltage) do not match. For example, an explicit measure range setup of 50 mA with an implicit force range of 200 mA by 100 mA force value. Implicit clamp ranges are not considered.
- If a reference pin is specified but the connectState is not one of HR_AWG, HC_AWG or DIFF_VM.

## Warnings

A warning is generated if multiple measurements are defined with the same DC set ID but with different execution modes, the execution mode of the newly defined measurement is modified and set to the execution mode of the DC set. Any DC sets following later (with same ID) must have the same execution mode specified as the first DC set with that ID.

## Examples

### Example 1

Precondition:

```
DCVH 1,,1,1000,4820,5180,i,0,no,ser,(pin1, pin2, pin3)
```

Execution:

```
DCEX 1, MEAS_VAL
```

Result:

```
DCRE? 1, VAL
DCRE P, 4903.3, (pin1)
DCRE F, 200.1, (pin2)
DCRE P, 5108.4, (pin3)
```

### Example 2

Precondition:

```
DCVH 2,,,,100,200,i,0,TERM,HIZ,(pin1)
```

Execution:

```
DCEX 2, MEAS_VAL
```

Result:

```
DCRE? 2, VAL
DCRE F, 4903.3, (pin1)
```

### Example 3

Precondition:

```
DCVH 1,,I,200000,"lowLimit:-1000 highLimit:5000",-500,4700,I,0,NT,PAR,"DIFF_VM:ON",(pin1, pin2),(refPin1,refPin2)
```

Execution:

```
DCEX 1, FORCE_ON
```

### Example 4

Precondition:

```
DCVH 1,,V,10000,"lowLimit:-100000 highLimit:200000",-500,9000,I,0,NT,PAR,(pin1, pin2)
```

Execution:

```
DCEX 1, FORCE_ON
```
