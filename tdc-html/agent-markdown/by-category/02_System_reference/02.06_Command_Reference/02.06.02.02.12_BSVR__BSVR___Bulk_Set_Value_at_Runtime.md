# BSVR, BSVR? (Bulk Set Value at Runtime)

The BSVR command assigns a value to a spec (base) variable of a level or timing specification within a spec value set (also called bulk set). Spec value sets are used to change the runtime values of several variables so that the equation system must be recalculated only once. For more information see [Changing the runtime values of base variables](<02.06.06.01.05.02_Changing_the_runtime_values_of_base_variables.md>).

The BSVR? query returns the actual value for a selected or all spec variables of a spec value set.

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Predependencies

The spec value set must have been defined with DSVS.

## Postdependencies

In order to recalculate the equation system with the values of a spec value set, the BSVE command must be issued.

## BSVR

```
BSVR {spec_value_set_no}, {"spec_name"|"spec_name@port_name"}, {value}
```

## BSVR?

BSRV? {spec_value_set_no}

returns:

```
BSVR {spec_value_set_no}, {"spec_name"|"spec_name@port_name"}, {value}
```

## Parameters

 |

spec_value_set_no

 |

Number of a spec value set. The set must have been defined with DSVS.

 |
 |

number

 |

Variable number in a given range. One of two possible options for the second, optional parameter.

 |
 |

spec_name

 |

The name of a spec (base) variable. The variable must have been declared in the equation set of the specification to which the spec value set belongs. Note however that this is not checked by BSVR, but only by BSVE.

 |
 |

spec_name`@`port_name

 |

If the spec value set is associated with a multi-port timing specification, and the variable is declared in the equation sets of several ports, you can restrict the value change to one port by adding the port name. Note that this has a bearing on the scope of the variable (see [Global and local scope of base variables](<02.06.06.01.05.03.01_Global_and_local_scope_of_base_variables.md>)).

 |
 |

value

 |

The new value of the variable.

 |

## Errors

An error is generated if the spec value set number does not exist.

## Example

```
> DSVS 11, "per", TIM,1,1
> BSVR 11,"per1",30
> BSVR 11,"per2",60
> BSVR? 11
< BSVR 11,"per1",30
< BSVR 11,"per2",60
```
