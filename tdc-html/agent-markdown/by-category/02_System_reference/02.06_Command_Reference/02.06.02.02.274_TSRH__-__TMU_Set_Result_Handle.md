# TSRH? - (TMU Set Result Handle)

The TSRH? query serves to define, activate, or delete a handle for a TMU result area. For details see [Storing the results of more than one TMU measurement](<02.06.13.01.03_Storing_the_results_of_more_than_one_TMU_measurement.md>).

## Syntax

```
TSRH? {REQUEST|SELECT|RELEASE}, {"handle_name"}
```

returns:

TSRH {REQUEST|SELECT|RELEASE}, {"handle_name"}, {SUCCEED|FAILED}

## Parameters

 |

REQUEST

 |

Defines a handle. If the request is successful, the new handle will be the active handle.

 |
 |

SELECT

 |

Selects an existing handle as the active handle.

 |
 |

RELEASE

 |

Releases (deletes) an existing handle.

 |
 |

handle_name

 |

The name of the handle to be requested, selected, or released.

 |
 |

SUCCEED

 |

The requested action was successful.

 |
 |

FAILED

 |

The requested action failed.

 |

## Application

TMU per pin measurements.

## Example

```
> TSRH? REQUEST, "area1"
< TSRH REQUEST,"area1",SUCCEED
```

## Functional changes

- Introduced in SmarTest 7.1.0
