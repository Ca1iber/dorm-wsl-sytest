# UDGP - (UnDefine GrouP)

The UDGP (UnDefine GrouP) command dismantles a group that has been previously defined by [DFGP](<02.06.02.02.60_DFGP__DFGP__-__DeFine_GrouP.md>) or [DFGE](<02.06.02.02.59_DFGE__DFGE__-__DeFine_Group_by_Expressions.md>).

## Syntax

```
UDGP {(group)}
```

## Parameters

 |

group

 |

Defines the name of the group of pins to be removed. The symbol @ can be used to dismantle all groups. If more than one group is to be removed, the names must be separated by a comma.

 |

## Application

Pin configuration, see [Configuration Setup Commands](<02.06.03_Pin_configuration_setup_commands.md>).

## Example

```
UDGP (Qout)
```

This command dismantles the group entitled Qout.

## Functional changes

- Introduced before SmarTest 6.3.2
