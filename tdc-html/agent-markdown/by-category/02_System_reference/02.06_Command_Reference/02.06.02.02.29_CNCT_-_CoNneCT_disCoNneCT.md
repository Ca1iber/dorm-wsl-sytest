# CNCT - CoNneCT/disCoNneCT

Depending on the card type, the CNCT (CoNneCT/disCoNneCT) command connects or disconnects all output pins of the specified module.

PPS (Precision Parallel Source) cards: disconnects all output pins in all PPS cores of the specified PPS modules.

## CNCT

```
CNCT {mode}, {(pinlist)}
```

## CNCT?

```
CNCT? {(pinlist)}
```

## Parameters

 | mode |

OFF: Disconnects all pins in the specified modules.

CNCT? always returns OFF as mode.

 |
 | pinlist |

Pin names.

Multiple pin names must be separated with a comma.

The @ symbol specifies all modules that have a pin for which a pin name has been defined.

You do not need to specify more than one pin in one PPS module.

 |

CNCT disconnects the pins immediately.

The following rules apply if the CNCT command is used in conjunction with PPS cards:

- CNCT disconnects all 16 output pins in the PPS module, even in multisite testing.
- CNCT does not change the output voltage of the PPS core when disconnecting the pins.

## Errors

An error is generated if the mode value is invalid.

## Example

To set all defined PPS pins to 0 V and disconnect all output pins of the PPS modules:

```
FORC 0,(@)
CNCT OFF,(@)
```

- Introduced before SmarTest 6.3.2
