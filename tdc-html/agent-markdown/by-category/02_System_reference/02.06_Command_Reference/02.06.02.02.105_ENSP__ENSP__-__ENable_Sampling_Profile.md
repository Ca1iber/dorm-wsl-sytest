# ENSP, ENSP? - (ENable Sampling Profile)

The ENSP (Enable Sampling Profile) command enables or disables pins for a voltage or current measurement during a functional test (current profiling).

The ENSP? query returns the operation state.

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Predependencies

The ENSP, ENSP? (Enable Sampling Profile) command is used for current profiling, which is supported on DC Scale cards only, that is DPS128/64, XPS256, and UHC4T.

On DC Scale DPS128/64 and UHC4T cards, profiling for multiport setups does not stop when the DPS part is finished. On these cards, profiling stops when the longest running port is finished. This gives the capability to profile the supply voltages/currents during the complete execution. In case you want to reduce memory consumption, you could put DPS pins into an empty port.

For the [DC Scale DPS128/DPS64 cards](<../02.05_Test_Head_Cards/02.05.05.01_DC_Scale_DPS128_DPS64_cards.md>), changing the current measurement range for profiling is not supported. That is, the measure_range parameter of the DFSP command is ignored when the measure_type is set to CURR. The profiling measurements are performed in the selected clamp current range.

## ENSP

```
ENSP {operation_state},{(pinlist)}
```

## ENSP?

```
ENSP? {(pinlist)}
```

returns

```
ENSP {operation_state},{(pinlist)}
```

## Parameters

 |

operation_state

 |

Specifies the operation state (ON|OFF)

 |
 |

pinlist

 |

This parameter specifies the pins to be enabled or disabled for the [DFSP, DFSP? - (DeFine Sampling Profile)](<02.06.02.02.67_DFSP__DFSP__-__DeFine_Sampling_Profile.md>) command.

 |

## Application

The ENSP, ENSP? (Enable Sampling Profile) command is used for current profiling.

## Example

```
ENSP ON,(@)
```

or

```
ENSP ON,(dps1,dps2)
```

or

```
ENSP OFF,(@)
```
