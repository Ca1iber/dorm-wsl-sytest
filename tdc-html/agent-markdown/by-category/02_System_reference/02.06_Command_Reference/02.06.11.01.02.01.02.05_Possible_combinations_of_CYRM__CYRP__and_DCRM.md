In the CYRP column, 'Both' means both MULT and ONE; in the System type column, it means Pin Scale and Smart Scale.

The effect of CYRM on these combinations can be summarized as follows:

- If CYRM is set to EDGE, the result combinations must fulfill the conditions that are required for edge recording.
- If CYRM is set to CYCL, any result combination is accepted, but if the conditions for edge recording are not satisfied, edge reporting will not be possible.
