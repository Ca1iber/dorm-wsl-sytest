# PSFC, PSFC? - (Parallel Setup FoCus)

The PSFC command serves to restrict certain changes of setup data to a proper subset of the available sites. It does this by setting or unsetting the setup focus for individual sites. By default, all sites have the setup focus.

Note that some setup commands do not take the setup focus into account. These commands will always change the setup data of all sites, regardless of any restrictions configured with PSFC. Commands that comply with the setup focus are the timing and level setup commands; in contrast, most vector setup commands disregard it (but not [VECD](<02.06.02.02.325_VECD__VECD__-__VECtor_Download.md>) and [VECC](<02.06.02.02.324_VECC__VECC__-__VECtor_download_Compressed.md>)).

CAUTION Using PSFC directly may have the effect that the site control window does not show the correct information about which sites are active and which are not. This may lead to sites, thought to be inactive, being updated by site control FW commands with undesirable results or even damage. To avoid this, the site control should normally be performed via the site control window (see [Using the site control](<../../03_Use_cases_and_application_papers/03.02_How_to_do_Multi-Site_Testing/03.02.02.04_Using_the_site_control.md>)) or test method APIs.

Note also that not all sites that are configured in the pin configuration are necessarily available for testing. If a site uses a channel that is inactivated in the MCDIgnore file (see MCDIgnore file in Service_Guide Part 1), this site cannot be used for testing.

The PSFC? query returns the sites that have currently the setup focus.

## PSFC

```
PSFC {site|"site_string"|ALL}
```

## PSFC?

```

PSFC? [STR]
```

returns

```
PSFC {"site_string"|ALL}
```

## Parameters

 |

site

 |

A single integer representing the site number.

 |
 |

site_string

 |

A string of characters ("0" or "1"). The length of the string corresponds to the number of the configured sites. The nth character of this string stands for site n.

-

1 means that the site is (to be) addressed by any subsequent commands that take the setup focus into account.

-

0 means that the site is not (to be) addressed by any subsequent commands.

If some of the sites that are required to get the setup focus are not available (because they use a channel that is inactivated in the MCDIgnore file) the setup status of these sites will not be changed.

 |
 |

ALL

 |

In the command, this means that all sites that are available for testing (that is, do not use a channel that is inactivated in the MCDIgnore file) are to be addressed by subsequent (setup focus aware) commands.

ALL is returned in the query reply, if the query is issued without the STR parameter, and if all available sites have the setup focus.

 |
 |

STR

 |

forces the query to return a site string even if all available sites have the setup focus. This can be used to check if some sites are not available.

 |

## Application

Site control window.

## Errors

An error is generated if not all pins at the site have had their channels assigned by the PALS command.

## Example

```
PSFC "11111110"
```

In this example, 8 sites are defined. The PSFC command unsets the setup focus for the last site. The setup data of this site will not be changed by any subsequent command execution.
