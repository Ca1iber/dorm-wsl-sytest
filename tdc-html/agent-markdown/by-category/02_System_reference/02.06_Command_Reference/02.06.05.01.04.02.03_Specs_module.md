# Specs module

A specs module declares the spec variables and its units used in the equations module, the level sets, or in the DPS module. It does not specify the values of the spec variables. This is done in the SPECSET (or [Spec Tool](<../02.08_Setup_and_Result_Tools/02.08.04.30_Spec_Tool.md>)).

The module header starts with the SPECS keyword.

 Note You define the units in the equation based spec setup only. You cannot define units using the spec tool.

## Example

```
SPECS
  vcc_level   [V]  # Base vcc voltage
  vcc_offset   [V]  # Offset to add to vcc_level
```
