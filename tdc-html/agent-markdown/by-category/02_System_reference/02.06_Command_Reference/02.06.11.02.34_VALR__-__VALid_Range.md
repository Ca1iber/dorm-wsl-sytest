# VALR? - (VALid Range)

The VALR? query returns the total number of test point measurements or DC pattern measurements for the specified pins, as recorded in the error map. Note that results from a test point are always stored in the external error map.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Predependencies

A test point pattern must have been executed for DC scale pins, or a DC pattern for digital pins.

## Syntax

```
VALR? {(pinlist)}
```

returns:

```
VALR {map_state}, {no_of_results}, {(pinlist)}
```

## Parameters

 |

map_state

 |

Returns the current state of the error map. The state can be:

- INVL: Invalid - no error map details are available. (The setup has been changed, but no functional test has been performed.)
- INCS: Inconsistent - the contents of the error map are inconsistent with the current setup.
- CONS: Consistent - a functional test has been performed and the contents of the error map are consistent with the current setup.
 |
 |

no_of_results

 |

Integer indicating the number of results recorded.

 |
 |

pinlist

 |

List of DC Scale pins.

 |

## Example

```
> VALR? (dpsPin)
< VALR CONS,10,(dpsPin)
```

## Functional changes

- Introduced before SmarTest 6.3.2
