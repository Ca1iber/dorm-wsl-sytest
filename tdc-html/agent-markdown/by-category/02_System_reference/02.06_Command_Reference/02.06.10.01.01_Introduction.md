# Introduction

This chapter describes how to use the firmware commands to perform DC measurements. It is divided into the following sections:

- [General Considerations](<02.06.10.01.02_General_Considerations.md>)
- [DC Measurements Using the PMU](<02.06.10.01.03_DC_Measurements_Using_the_PMU.md>)
- [DC Measurements Using the DPS](<02.06.10.01.04_DC_Measurements_Using_the_DPS.md>)
- [DPS Measurements Using External Trigger](<02.06.10.01.06_DPS_Measurements_Using_External_Trigger.md>)

Some DC measurements can also be made using the programmable load to force a current and the comparator to make the measurement.
