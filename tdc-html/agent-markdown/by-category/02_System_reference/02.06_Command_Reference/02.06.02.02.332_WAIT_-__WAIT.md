# WAIT - (WAIT)

The WAIT command causes the MCD to wait the specified number of microseconds before executing the next firmware command. It is useful when switching relays or programming power supplies (waiting for power supplies to settle). From a practical viewpoint it makes sense to enter values in the millisecond range.

To avoid dead times caused by the communications overhead of processing this firmware command, include the command in a single string together with the preceding and the following command (see the example below).

## Syntax

```
WAIT {time}
```

## Parameters

 |

time

 |

Enter a time in µs.

 |

## Application

Hardware synchronization.

## Example

```
RLYC DC,PMU,(outputs); WAIT 1000; FTST?
```

This example causes the MCD to wait 1 ms (1000 µs) for the PMU relay to close before executing a functional test.

## Functional changes

- Introduced before SmarTest 6.3.2
