# Low level and high level (edit) commands

Sequencer area and vector areas are independent of each other. You can change one of them without changing the other. Logically, however, they are related. Every sequencer program is associated with a set of vector area segments that contain the physical waveform DC/DC power units for its vector generating instructions. Therefore, changes in the sequencer area will usually entail changes in the vector areas, and vice versa.

Both physical independence and logical dependencies are taken into account by the firmware commands for the vector setup. There are low level commands that modify or affect one area type, but do not change the other one in any way, and there are high level commands, the so-called edit commands, which combine the functions of several low level commands and modify both area types in a synchronized way. The edit commands derive their name from the fact that they are used by the Pattern Tool. Most edit commands require that the respective label has been activated for editing with the TSTL command.
