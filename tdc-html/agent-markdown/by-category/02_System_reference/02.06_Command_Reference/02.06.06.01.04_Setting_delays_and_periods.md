# Setting delays and periods

#### Subtopics

- [Specifying the period](<02.06.06.01.04.01_Specifying_the_period.md>)
- [Setting the edge delays](<02.06.06.01.04.02_Setting_the_edge_delays.md>)

The physical waveforms fix the shapes of the signals that can be sent to the DUT. What remains to be done is to determine

- the period, that is, the length of the tester cycle (see [Specifying the period](<02.06.06.01.04.01_Specifying_the_period.md>)), and
- the delays of the edges within this period (see [Setting the edge delays). ](<02.06.06.01.04.02_Setting_the_edge_delays.md>)

These values are defined in the timing sets and (if the timing set definitions contain variables) the spec set (see [Defining the timing specification](<02.06.06.01.05_Defining_the_timing_specification.md>)). The unit is nanoseconds (ns).

You can change the edge delays and the periods during a test by switching to another timing set with the CTIM sequencer instruction. For details, see [Changing the timing set](<02.06.07.01.08.03.01_Changing_the_timing_set__CTIM.md>).
