# PSEE - (Power Supply External trigger measurement Execute)

The PSEE (Power Supply External trigger measurement Execute) command executes an externally triggered DPS measurement that is set up with the [DPSE](<02.06.02.02.85_DPSE__DPSE__-__Define_Power_Supply_External_trigger_measurement.md>) command. The command causes a functional test to be executed, which means that a functional test must have been already defined. The measurements defined with the PSEE and DPSE command continue as long as a trigger is sent to the DPS. The PSER? command retrieves the external trigger DPS measurement.

 Note When executing PSEE, the primaries will be applied.

PSEE retains the current range after the measurement if the specified pins are not ganged. This reduces the settling time after changing the current measurement range.

For details of the related commands, see the following sections:

- [DPSE, DPSE? - (Define Power Supply External trigger measurement)](<02.06.02.02.85_DPSE__DPSE__-__Define_Power_Supply_External_trigger_measurement.md>)
- [PSER? - (Power Supply External trigger measurement Read results)](<02.06.02.02.190_PSER__-__Power_Supply_External_trigger_measurement_Read_results.md>)

## Syntax

```
PSEE [setnr], [current_range], [samples], {(pinlist)}
```

## Parameters

 |

setnr

 |

The set number of the external trigger measurement. (The range is 1 to 256). When this parameter is specified the corresponding set must have already been defined.

 |
 |

current_range

 |

If the setnr parameter is specified, the range in which the executed measurement will be made will be determined from the maximum value of the limits defined with the [DPSE](<02.06.02.02.85_DPSE__DPSE__-__Define_Power_Supply_External_trigger_measurement.md>) command, and this parameter will be ignored.

If the setnr parameter is not specified, you must specify the range with a value. In this case, the measurement will be executed in the smallest range that can measure the given value. The unit is Ampere [A].

 |
 |

samples

 |

This parameter specifies the number of measurements. After the measurements are completed, the average of the measurements will be calculated.

 |
 |

pinlist

 |

This parameter will be ignored if setnr is specified.

 |

## Example

```
DFPS 11,pos,(Vcc)
DFPS 12,pos,(Vdd)
DPSE 1,(@),#10          <- Delete set 1
DPSE 1,(Vcc),#150,1,2   <- Vcc min=1A, max=2A
DPSE 1,(Vdd),#150,2,3   <- Vdd min=2A, max=3A
PSST ON      <- Measurement requires connect state
PSEE 1,,,(@)   <- Measure both pins in parallel
PSER? 1,pval
PSER 1,P,(Vcc),#9000000006,1.501 <- value within range
PSER 1,F,(Vdd),#9000000006,3.173 <- value outside range
```

This example performs a measurement with format 2 and PSEE for two different pins in parallel.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.3: Maximum number of DPS sets increased to 256
