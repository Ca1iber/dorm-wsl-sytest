# FLSH - (FLuSH buffered commands)

The following commands for utility lines do not immediately set the hardware. Instead they are buffered in the MCD (Message Concentrator and Distributor).

 For utility lines:

- [UPST](<02.06.02.02.305_UPST__UPST__-__Utility_Purpose_STate.md>) (Utility Purpose STate)
- [UPTI](<02.06.02.02.307_UPTI__UPTI__-__Utility_Purpose_settling_TIme.md>) (Utility Purpose settling TIme)
- [UTST](<02.06.02.02.313_UTST__UTST__-__UTility_line_STate.md>) (UTility line STate)
- [UTTI](<02.06.02.02.314_UTTI__UTTI__-__UTility_line_settling_TIme.md>) (UTility line settling TIme)

## Syntax

```
FLSH {MUX}, {"init_flags"}
```

## Parameters

 |

MUX

 |

The optional MUX parameter is designed to be used as an execution code of a testflow that is generated by the system software for disconnecting the particular sites (not for user programming).

Do not use this parameter for programming a user procedure or executing the FLSH command from the hpt.

 |

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.3: Support of MBAV8+
- SmarTest 7.1.4: HW of analog modules cannot be accessed when the master clock is switched off. An error is issued and the message is displayed in the report window.
