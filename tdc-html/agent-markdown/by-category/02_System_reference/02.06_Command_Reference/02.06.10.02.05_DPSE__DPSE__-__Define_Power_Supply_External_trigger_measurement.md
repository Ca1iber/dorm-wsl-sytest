# DPSE, DPSE? - (Define Power Supply External trigger measurement)

The DPSE (DeFine Power Supply External trigger measurement) command defines an external or internal trigger measurement. (For historical reasons, the name of the command refers only to external trigger measurements.)

For starting measurements which are set up by this command, use the [PSEE](<02.06.02.02.189_PSEE_-__Power_Supply_External_trigger_measurement_Execute.md>) command (external), or the [PSIE](<02.06.02.02.192_PSIE_-__Power_Supply_Internal_trigger_Execute.md>) command (internal).

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## DPSE

```
DPSE {setnr}, {(pinlist)}, {binary_data}
```

## DPSE?

```
DPSE? {setnr}
```

returns:

```
DPSE {setnr}, {(pinlist)}, {binary_data}
```

## Parameters

 |

setnr

 |

This number defines the set number for the measurement. The number must be an integer from 1 to 256.

In the query, you can specify ALL to retrieve the data of all sets.

 |
 |

pinlist

 |

This parameter specifies the pins to be used for the measurements.

 |
 |

binary_data

 |

This is a binary data string. The string starts with the '#' character, followed by a digit in the range 1 to 9 which stipulates how many digits are used in the data length specifier. The data length specifier is next: up to 9 digits determine how many bytes of data will follow. The actual data string follows last.

 Note If the binary data string is empty, the definition for the pins specified in pinlist will be deleted from the set.

The first character or value of the data stream determines the format for the remainder of the data stream (characters '0' through '3' are for current measurements, '4' through '11' for voltage measurements):

 | 0: Waveform template |
 | |

If the first character is a '0', it is followed by a waveform template. The values are given first for the low value and then for the high value. The values are separated by a ',' (comma).

This template is for the PASS/FAIL results from the [PSER?](<02.06.02.02.190_PSER__-__Power_Supply_External_trigger_measurement_Read_results.md>) query. The current range in which the measurements will be executed is determined by the maximum/ minimum value of the template. The values have the unit Amps [A].

This option can only be combined with the [PSEE](<02.06.02.02.189_PSEE_-__Power_Supply_External_trigger_measurement_Execute.md>) command.

 |
 | 1: Number of measurement points followed by low and high values |
 |   | If the first character is a '1', a number and two values follow. The first number gives the number of measurement points. The second and third define the low and high values. These are separated by a "," (comma). The current range for the measurements is determined by the maximum and minimum value of the template. The values are given in the unit Amps [A].

This option can only be combined with the [PSEE](<02.06.02.02.189_PSEE_-__Power_Supply_External_trigger_measurement_Execute.md>) command.

 |
 | 2: Low and high value |
 |   | If the first character is a '2', two values follow. They define the low and high value (in this order) and are separated by a "," (comma). The current range for the measurements is determined by the maximum and minimum value of the template. The values are given in the unit Amps [A]. The number of measurement points is 1.

This option requires that the measurement is executed with the [PSIE](<02.06.02.02.192_PSIE_-__Power_Supply_Internal_trigger_Execute.md>) command.

 |
 | 3: Low and high value |
 |   | If the first character is a '3', two values follow. They define the low and high value (in this order) and are separated by a "," (comma). The current range for the measurements is determined by the maximum and minimum value of the template. The values are given in the unit Amps [A]. The number of measurement points is 1.

This option can only be selected for DC Scale channel DPS's and requires that the measurement is executed with the [PSIE](<02.06.02.02.192_PSIE_-__Power_Supply_Internal_trigger_Execute.md>) command. If the channels belong to a Master/Slave configuration, they are unganged during the measurement as far as possible, that is, as far this can be done without affecting the goal of the measurement.

 |
 | 4: Waveform template |
 |   | If the first character is a '4', it is followed by a waveform template. The values are given first for the low value and then for the high value. The values are separated by a ',' (comma). This template is for the PASS/FAIL results from the [PSER?](<02.06.02.02.190_PSER__-__Power_Supply_External_trigger_measurement_Read_results.md>) query. The voltage range in which the measurements will be executed is determined by the maximum/ minimum value of the template. The values have the unit Volt [V].

This option can only be selected for DC Scale channel DPS's and can be combined only with the [PSEE](<02.06.02.02.189_PSEE_-__Power_Supply_External_trigger_measurement_Execute.md>) command.

The values are given first for the low value and then for the high value. The values are separated by a ',' (comma). This template is for the PASS/FAIL results from the [PSER?](<02.06.02.02.190_PSER__-__Power_Supply_External_trigger_measurement_Read_results.md>) query. ## Application

It is possible to define different measurements for different pins contained in the same set. A DPSE 1, .... command does not overwrite a previous definition, if it refers to different pins. However definitions for pins that have already been defined will be overwritten. In this case if the binary string for the given pins is empty, then those pins will be removed entirely from the earlier DPSE 1, .... definitions.

## Examples

### Example 1

```
DPSE 1,(Vcc),#90000000170,0.1,0.2,0.2,0.3
```

This example defines a template which consists of 2 points (0.1, 0.2) and (0.2, 0.3). If the first measured value is in the range (0.1, 0.2) and the second value is in the range (0.2, 0.3), then the result will be a pass.

### Example 2

```
DPSE 1,(Vcc),#90000000121,15,0.1,0.2
```

This example defines a template which is 15 points long and is constant.

### Example 3

```
DFPS 11,pos,(Vcc)
DFPS 12,pos,(Vdd)
DPSE 1,(@),#10 <- Delete set 1
DPSE 1,(Vcc),#152,1,2 <- Vcc min=1A, max=2A
DPSE 1,(Vdd),#152,2,3 <- Vdd min=2A, max=3A
PSST ON <- Measurement requires connect state
PSIE 1,,,(@) <- Measure both pins in parallel
PSER? 1,pval
PSER 1,P,(Vcc),#9000000006,1.501 <- value within range
PSER 1,F,(Vdd),#9000000006,3.173 <- value outside range
PSER? 1,ppf
PSER 1,P,(Vcc),#9000000000
PSER 1,F,(Vdd),#9000000000
PSER? 1,gpf
PSER 1,F,(),#9000000000
```

This example performs a measurement with format 2 and PSIE for two different pins in parallel.

### Example 4

```
DFPS (10101),pos,(Vcc) <- DC Scale pin
DFPS (10102,10103),pos,(Vdd) <- DC Scale pin (Gang of two channels)
DPSE 1,(@),#10 <- Delete set 1
DPSE 1,(Vcc),#153,0.5,1.5 <- Vcc min=0.5A, max=1.5A
DPSE 1,(Vdd),#153,20,30 <- Vdd min=20A, max=30A
PSST ON <- Measurement requires connect state
PSIE 1,,,(@) <- Measure both pins in parallel
 Vcc: High Precision Mode is used
 Vdd: Only one channel of the gang is used
PSER? 1,pval
PSER 1,P,(Vcc),#9000000006,1.301 <- value within range
PSER 1,F,(Vdd),#9000000006,31.73 <- value outside range
PSER? 1,ppf
PSER 1,P,(Vcc),#9000000000
PSER 1,F,(Vdd),#9000000000
PSER? 1,gpf
PSER 1,F,(),#9000000000
```

This example performs a measurement with format 3 and PSIE for two different pins in parallel.
