# DPS (Device Power Supply) pins

The power supply pins of the DUT (Device) must be supplied with power supply voltages (vout).

  ![DPS voltage levels](<../../../../raw/56934.png>)

When the DUT is "connected", the DPS is programmed to the power supply voltage (vout). After an internal settling time and the setup time (t_ms), the sequencer starts.
