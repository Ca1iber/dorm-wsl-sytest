# Defining waveform shapes for Pin Scale standard pins

#### Subtopics

- [Specifying the actions](<02.06.06.01.03.01.01_Specifying_the_actions.md>)
- [Selecting and ordering edges](<02.06.06.01.03.01.02_Selecting_and_ordering_edges.md>)
- [Combining selective digital capture with a functional test](<02.06.06.01.03.01.03_Combining_selective_digital_capture_with_a_functional_test.md>)

Waveform shapes for standard pins are defined in the wavetable by a sequence of edge-action pairs. You can also add a name for the shape, which, for historical reasons, is called a "device cycle name". The format is:

<wf_index> "<edge_1>:<action_1> <edge_2>:<action_2> ... <edge_n>:<action_n>" [<dev_cycle_name>]

The maximum value of n is 16. For details on the action codes see [Specifying the actions](<02.06.06.01.03.01.01_Specifying_the_actions.md>). The ordering of the edges is subject to certain restrictions; for details see [Selecting and ordering edges](<02.06.06.01.03.01.02_Selecting_and_ordering_edges.md>).

If no name is specified, the Pattern Debug tool uses the waveform index as the device cycle name. Note that the waveform DC/DC power units must be coded hexadecimally in the wavetable, but that they will be displayed in decimal format by the Pattern Debug tool.

## Example

```
WAVETBL "std"

PINS IN1
0  "d1:0"  ZERO
1  "d1:0 d2:1 d3:0"  ONE

PINS O1
0  "r1:L"   LOW
1  "r1:H"   HIGH
```

ZERO and ONE are the names for the waveforms 0 and 1 for pin `IN1`. These names will be displayed by the Pattern Debug tool.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.2: Logical waveforms are no longer supported in the wavetable.
