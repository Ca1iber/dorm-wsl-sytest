# Defining waveforms for a protocol engine test

#### Subtopics

- [Special requirements for freezing the tracker](<02.06.06.01.03.02.01.01_Special_requirements_for_freezing_the_tracker.md>)

Waveforms for a protocol engine test must be defined in native Pin Scale 9G format. In addition, they must satisfy the following conditions:

- The number of receive actions must be 4 or 6. This number must conform to the value (X4 or X6) for the TTMODE keyword that must be specified immediately below the PINS statement.

The TTMODE keyword must also be specified in the timing set. When a wavetable is combined with a timing set in a timing specification, both must specify the same value for this keyword.

- Window compare actions are not available for protocol engine test pins. In a protocol engine test, the window formatter is used to switch off (by 0) or on (by 1) the transition tracking (see [Tracking bi-directional pins](<02.06.15.01.01.04_Tracking_bi-directional_pins.md>)). But note that the delays for the tracking control actions are still determined by the receive edges.
- The string for the window formatter is optional. However, all waveforms for a protocol engine test pin must be homogenous, that is, all or none must contain the "freezing" information. The number of actions must also be 4 or 6, depending on the value that is specified with the TTMODE keyword.

If the protocol engine pin is an IO pin, the following additional rules apply:

- Every waveform must contain the strings for the f- and s-edges as well as the string for the receive actions. If the waveform is a pure drive waveform, use "X" for the receive actions. If it is a pure receive waveform, use "." (for "no action") as the action code for the drive edges.
- The number of drive actions can be different from 4 and 6.

Thus, the format for O pins is

<waveform_index> "<compare_actions>" ["<transition_tracking_control>"],

and the format for IO pins is

<waveform_index> "<f_edge_actions>" "<s_edge_actions>" "<compare_actions>" ["<transition_tracking_control>"]
