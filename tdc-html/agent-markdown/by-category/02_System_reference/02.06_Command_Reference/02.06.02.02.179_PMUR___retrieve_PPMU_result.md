# PMUR? (retrieve PPMU result)

The PMUR? query retrieves the result of the last measurement performed with [MEAS](<02.06.02.02.160_MEAS_-__execute_a_MEASurement_set.md>), [MEAR](<02.06.02.02.159_MEAR__retrieve_MEAsurement_Results.md>), or the sequencer instruction MEAS. This is done for the site that has the query focus (set with [PQFC](<02.06.02.02.180_PQFC__PQFC__-__Parallel_Query_FoCus.md>)). You can cause PMUR? to perform an additional measurement with the measurement set used in the last call of the MEAS command or MEAS instruction, and to store the resulting value in a cache. You can also configure PMUR? so that it performs a measurement only if no value is present for this measurement set in the cache (from a previous call of PMUR? or MEAR).

 Note If you require a value from PMUR?, it will skip the measurement only if it finds a value in its cache from a previous call of PMUR? or MEAR.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Syntax

```
PMUR?{type}, [mode,] {(pinlist)}
```

returns

```
PMUR {judge}, [voltage], [current], {(pinlist)}
```

## Parameters

 |

type

 |

Data type to be retrieved. The following specifiers can be set:

VMUM: Returns the measurement value from the PPMU measurement (successive approximation) for the pins in pinlist.

VAL: Returns the per pin measurement value or values for the pins in pinlist.

PF: Per pin pass fail result for the pins in pinlist.

GPF: Global pass fail result for all tested pins. The pinlist is ignored.

 |
 |

mode

 |

This parameter controls the behavior of PMUR? if the type parameter is set to VAL. The allowed values are:

 |
 |

 |

FORCE_MEASURE

 |

PMUR? performs a value measurement for type VAL.

 |
 |

 |

USE_CACHE

 |

PMUR? performs a value measurement only if necessary, that is, if a result for the same measurement set is not present in the cache.

 |
 |

judge

 |

This parameter indicates a judgment of the pin with the following specifiers:

P: Pass

F: Fail

 |
 |

voltage

 |

Measured voltage in mV. This parameter is only returned when type = VAL.

 |
 |

current

 |

Measured current in uA. This parameter is only returned when type = VAL.

 |
 |

pinlist

 |

Target pin or pins to retrieve result

   | Note For the VAL type, either voltage or current will be returned depending on the measurement mode (I-force V-measure or V-force I-measure).

## Application

See [DC Measurement Commands](<02.06.10_DC_Measurement_Commands.md>), which introduces the firmware commands for DC test.

## Examples

### Example 1

```
> PMUR? VAL,(p1,p2)
< PMUR P,,2,(p1)
< PMUR F,-2100,,(p2)
```

This example retrieves the measurement value of "p1" and "p2" for the site that has the query focus.

### Example 2

```
> PMUR? GPF,(@)
< PMUR P,,,()
```

In this example, PMUR? returns the global pass/fail result for all tested pins of the site that has the query focus.

## Functional changes

- SmarTest 7.0.1: New type parameter: VMUM
- SmarTest 7.0.1: mode parameter FORCE_MEASURE: PMUR? performs a value measurement for type = VAL.
