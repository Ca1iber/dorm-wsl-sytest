# Setting the setup focus

You can to a certain extent control which sites will be affected by subsequent setup commands. This is done with the [PSFC](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>) command, which defines the sites that have the setup focus.

However, only a subset of the setup commands takes this setup focus into account. For example, the level and timing commands in fact change only the data of the sites that have the setup focus. The vector setup commands, on the other hand, disregard the setup focus; they always affect all available sites (unless the command itself can restrict the scope of the affected sites, as does the [SQSL](<02.06.02.02.240_SQSL__SQSL__-__SeQuencer_Start_Label.md>) command).

By default, all sites have the setup focus.

One typical application of the [PSFC](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>) command is to disconnect a single site. To do so, restrict the setup focus to the site in question with the [PSFC](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>) command, and then use the firmware commands associated with the disconnect sequence (see [Disconnect the DUT from the Tester Resources](<02.06.08.01.02_Disconnecting_the_DUT_from_the_tester_resources.md>)) to disconnect the site. No other site will be affected by this command sequence.
