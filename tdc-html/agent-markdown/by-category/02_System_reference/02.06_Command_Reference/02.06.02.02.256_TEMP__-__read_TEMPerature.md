# TEMP? - (read TEMPerature)

The TEMP? (read TEMPerature) query returns the temperature for each card.

## Syntax

```
TEMP? [cardType]
```

returns:

```
TEMP {cardType}, {cardId}, {temperature}
```

## Parameters

 | cardType  | Specifies the card type for which temperature is read |
 | DIGIO  | Digital IO card (including DC Scale cards) |
 | ANAIO  | Analog IO card |
 | CLK  | Clock Board |
 | cardId  | Returns

- the card number (or pogo block number) of the logical channel board (three digits)
- or the Clock Board number (11, 12, 21, 22, ..., 41, 42),
- or an identification number of the DPS card (101 to 108).
 |
 | temperature |

Returns the temperature (in Kelvin) for each card.

Default value in offline mode is 292.3 K.

 |

## Application

Hardware status.

## Example

```
TEMP? DIGIO
TEMP DIGIO,101,292.3
TEMP DIGIO,102,292.3
```
