# Site dependent firmware commands

This topic lists the firmware commands, which make use of the site focus. That means you have to set the site focus before you can execute the command. For more information, see the Focus section in [The states of the sites](<../02.08_Setup_and_Result_Tools/02.08.04.27.01_The_states_of_the_sites.md>).

- Command site focus (setup focus)

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

- Query site focus

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.
