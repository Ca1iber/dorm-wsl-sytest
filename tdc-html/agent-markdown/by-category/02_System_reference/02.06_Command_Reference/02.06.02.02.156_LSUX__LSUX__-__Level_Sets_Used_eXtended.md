# LSUX, LSUX? - (Level Sets Used eXtended)

The LSUX (Level Sets Used eXtended) command is only for use by the system, not the user. Do not attempt to execute it from the hpt utility! You may execute the query. The following information is provided to improve your understanding of any hpt output listings you may make.

During test flow optimization the LSUX command is used internally by the Test Flow Optimizer to generate additional (optimized) level sets. The LSUS? query (see [LSUS, LSUS? - (Level Sets USed)](<02.06.02.02.155_LSUS__LSUS__-__Level_Sets_USed.md>)) returns the number of all level sets, including those that are optimized. Thus LSUX? is used to return the original number of level sets, that is, those before optimization. The Test Flow Executor then calculates the number of optimized level sets.

The command is not active unless optimized test flows are used.

## LSUX

```
LSUX {level_set_no|SWAP|NONE}
```

## LSUX?

```
LSUX?
```

returns:

```
LSUX {level_set_no}
```

## Parameters

 |

level_set_no

 |

Level Set Number. If the number is smaller than the current value of LSUS then LSUX is set to this value. Otherwise it is set to the current value of LSUS.

 |
 |

SWAP

 |

This command parameter causes the values set by LSUS and LSUX to be switched, that is, LSUS is set to the current value of LSUX, and LSUX to that of LSUS.

 |
 |

NONE

 |

This command parameter sets the value of LSUX back to 1.

 |

## Application

Optimized testflows.

## Errors

An error is generated if:

- The level_set_no is greater than the range allowed by the [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) command.
- The level_set_no is smaller than one.
- The level_set_no is undefined.

## Example

```
LSUX 4
```

This example defines a maximum of 4 level sets.

## Functional changes

- Introduced before SmarTest 6.3.2
