# VALC? - (VALid Cycle range)

The VALC? query returns the number of the first cycle and the total number of cycles recorded in the Error Map for the specified DC Scale pins. All these pins must belong to the same port. For digital pins, use [VALD?](<02.06.02.02.316_VALD__-__VALid_Data.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Syntax

```
VALC? {(pinlist)}
```

returns:

```
VALC {map_state}, {start_cycle}, {no_of_cycles}, {(pinlist)}
```

## Parameters

 |

map_state

 |

Returns the current state of the error map. The state can be:

- INVL: Invalid - no error map details are available. (The setup has been changed, but no functional test has been performed.)
- INCS: Inconsistent - the contents of the error map are inconsistent with the current setup.
- CONS: Consistent - a functional test has been performed and the contents of the error map are consistent with the current setup.
 |
 |

start_cycle

 |

The first recorded cycle.

 |
 |

no_of_cycles

 |

The number of recorded cycles.

 |
 |

pinlist

 |

List of DC Scale pins. The pins must belong to the same port.

 |

## Example

```
> VALC? (dpsPin)
< VALC CONS,0,700,(dpsPin)
```

## Functional changes

- Introduced before SmarTest 6.3.2
