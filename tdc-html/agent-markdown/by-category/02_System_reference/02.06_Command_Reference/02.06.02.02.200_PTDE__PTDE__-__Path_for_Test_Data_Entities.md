# PTDE, PTDE? - (Path for Test Data Entities)

The PTDE command lets you specify the path at which the XML files that define test data entities (TDEs) are found.

The [LTDE](<02.06.02.02.157_LTDE__LTDE__-__Load_Test_Data_Entity.md>) and [STDE](<02.06.02.02.249_STDE_-__Save_Test_Data_Entity.md>) commands rely on the path specified with PTDE.

The PTDE? command returns the currently specified path.

## PTDE

PTDE "<device_directory>/<domain>/<TDE_directory>"

## PTDE?

PTDE?

## Parameters

 |

device_directory

 |

The path to the device directory in which the test data entities (TDEs) are located.

 |
 |

domain

 |

The name of the domain in the specified device directory that contains the test data entities (TDE).

The domain is one of the subdirectories of the device directory. It bundles all related TDEs.

 |
 |

TDE_directory

 |

The name of the directory in the domain that contains the test data entities (TDE).

This name is usually the name of the firmware command file to which the directory belongs, with a .files extension.

 |

## Example

```
PTDE "/mydevice/configuration/test.files"
```
