# Verifying the level settings

## About this task

Verify the setup data to ensure that the entered values, variables, and equations reflect the requirements. This helps you to view the different settings.

CAUTION If you modify a value in the Level Setup Editor, the level setup file will not be changed, but the entry in the Level Setup Editor will temporarily override what was specified in the level file. If you want to make a permanent change you must do so in the level setup file itself using the Equation Editor.

## Procedure

-  Check i, o, and io pins

  -  In the Level Setup editor, select Select > Show I/O Eqn & Specs Results.
  -  Alter the values in the Eqn#, Sps# and Lset# fields.

Eqn# refers to Equation set, Sps# to Spec set, and Lset# to Level Set.

  -  Check that the values reflect the requirements.

-  Check DPS pins

  -  In the Level Setup editor, select Select > Show DPS Eqn & Specs Results
  -  Alter the values in the Eqn# and Sps# fields
  -  View the different settings.
  -  Check that these values also correspond to the definitions.
