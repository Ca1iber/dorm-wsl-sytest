# APDV - (APpenD Vectors)

The APDV (APpenD Vectors) command appends vectors at the end of a sequencer construct.

## Predependencies

- The instruction of the construct must be GENV, RPTV, or MRPT.
- The APDV command can only be issued after a label has been selected for editing with the [TSTL](<02.06.02.02.281_TSTL__TSTL__-__TeST_Label.md>) command.

## Mode of operation

If the additional active vectors can be accommodated by the inactive vectors within the vector area segment of the label, the total length of this segment need not be increased. In this case, APDV just updates the length of the construct and moves comments so that they are aligned to the correct vectors. If the length of the segment increases, the command also expands the vector areas of the pins and updates the STVA instructions of the labels that use later segments of the vector area.

## Postdependencies

To generate useful data for the sequencer construct, you must overwrite the appended vectors with appropriate physical waveform DC/DC power units. You can do this with the command [VDCP, VDCP? (Vector Device Cycle Parameter)](<02.06.02.02.323_VDCP__VDCP___Vector_Device_Cycle_Parameter.md>).

## Syntax

```
APDV {cmd_No}, {vect_length}
```

## Parameters

 |

cmd_No

 |

A number that identifies the command within the sequencer area of the port to which the label belongs. Enter the command number of a GENV or RPTV instruction within the selected label.

 |
 |

vect_length

 |

The number of vectors you wish to append. Enter an integer in the range 0 to the maximum vector length.

 |

## Application

Edit command in Pattern Tool.

## Errors

An error is generated if:

- There is insufficient channel memory.
- There is insufficient disk space (offline operation only).
- The specified command number refers to a sequencer instruction other than GENV, RPTV, or MRPT, see the command [SQPG, SQPG? - (SeQuencer ProGramming)](<02.06.02.02.237_SQPG__SQPG__-__SeQuencer_ProGramming.md>).
- You specify a negative vector length.
- No label has been activated for editing.
- The specified command number is out of range.

## Example

```
> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,9,,,(@)
< SQPG 3,STOP,,,,(@)
< SQPG 4,STVA,520,,,(@)
< ...
> TSTL "test_1",(@)
> APDV 2,25
> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,34,,,(@)
< SQPG 3,STOP,,,,(@)
< SQPG 4,STVA,544,,,(@)
< ...
```

This example appends 25 vectors to the end of the sequencer construct with the command number 2. Note the change of the start address in command line 4.
