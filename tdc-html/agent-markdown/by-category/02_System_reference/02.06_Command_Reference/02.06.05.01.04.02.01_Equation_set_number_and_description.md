# Equation set number and description

A level equation set starts with the EQNSET header keyword followed by an equation set number and a descriptive name, the description.

The equation set number is an integer in the range 1 to 256. The number must be unique.

The equation set description is optional. It is a string of up to 60 characters enclosed in double quotes ("...").
