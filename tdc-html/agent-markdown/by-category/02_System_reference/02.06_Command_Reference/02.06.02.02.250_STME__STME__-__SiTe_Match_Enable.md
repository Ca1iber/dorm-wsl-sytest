# STME, STME? - (SiTe Match Enable)

The STME command defines the state of the site match function. The site match function controls if all sites are started simultaneously (option OFF), or successively with a slight delay (option ON). The command does nothing if a single site is configured.

The ON option is required for evaluation of match loops per site in a multisite test (on match loops see [Match loops](<02.06.07.01.08.04.03_Match_loops.md>)). For if all sites are started simultaneously, the decision if a match was obtained will be based on the compare results of all sites.

The OFF option is required if one digital channel is shared among several sites for triggering a shared analog module. For details see [Controlling the site match function](<02.06.03.01.10.04_Controlling_the_site_match_function.md>).

The FAST option is required if the local synchronization of the test processor is enabled for match loops and conditional jumps. For details see [Fast Sync](<02.06.07.01.08.04.03.03_Fast_Sync.md>).

The query returns the active settings.

## STME

```
STME {ON|OFF|AUTO|FAST},
```

## STME?

```
STME?
```

returns:

STME {ON|OFF|FAST),

## Parameters

 |

ON

 |

Turns the site match function on.

 |
 |

OFF

 |

Turns the site match function off.

 |
 |

AUTO

 |

Starting the sites successively affects the test negatively if the pin configuration contains at least one shared digital channel for triggering an analog module. The AUTO option checks if such a shared channel exists. If it does, the match site function is set to OFF; if not, it is set to ON. AUTO is the default.

 |
 |

FAST

 |

Activates the [Fast Sync](<02.06.07.01.08.04.03.03_Fast_Sync.md>) feature (local synchronization) of the test processor. After setting this option," STME ON" is required to turn on the site match function.

 |

## Application

Multisite testing

## Errors

An error is generated if the argument is invalid.

## Example

```
> STME AUTO,
> STME?
< STME ON,
```

This example sets the site match function to AUTO, then reads the actual setting. Since the actual setting is ON, the pin configuration cannot contain a shared digital channel.

```
>SQST OFF
>NIFE 2
>STME FAST,
>STME ON,
```

This example configures the Fast Sync feature, and sets two independent Fast Sync ports on each test processor.
