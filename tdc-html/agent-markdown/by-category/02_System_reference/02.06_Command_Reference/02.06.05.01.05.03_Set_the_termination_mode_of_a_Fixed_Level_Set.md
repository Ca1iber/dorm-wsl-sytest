# Set the termination mode of a Fixed Level Set

 Note The support for fixed level setups is discontinued with SmarTest version 7.4.1T. We recommend using the [Equation based level setup](<../02.08_Setup_and_Result_Tools/02.08.04.14.02_Equation_based_level_setup.md>) for all releases of SmarTest 7.2 or higher versions.

The termination mode lets you set the:

- termination voltage for output pins
- termination to high or low driver levels for IO pins
- high and low clamp voltages for output and IO pins

The command [TERM, TERM? - (TERMination mode)](<02.06.02.02.257_TERM__TERM__-__TERMination_mode.md>) defines the termination mode.
