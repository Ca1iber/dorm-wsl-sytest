# Disconnecting the DUT from the tester resources

Disconnecting the DUT from the test system Resources is performed using the same commands as in the connect sequence, but applied in the reverse order.

The sequencer is set to OFF, then the DPS is powered down and finally the pin electronics relay is opened.
