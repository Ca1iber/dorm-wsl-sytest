# Level Setup Commands

#### Subtopics

- [Concepts of level setup](<02.06.05.01_Concepts_of_level_setup.md>)
- [List of level setup commands](<02.06.05.02_List_of_level_setup_commands.md>)

Each channel of a channel card includes a driver, a dual level comparator, an active load, and clamps.

You program these resources in the level setup. That is, you assign values to the following level resources:

- drive levels,
- compare levels,
- termination modes,
- load currents,
- clamp levels, and
- power supply voltage.

The easiest way to achieve this is to assign fixed values to these level resources.

However, this approach does not satisfy the requirements of many applications. For this reason, SmarTest also provides the more powerful equation-based approach to level setup.

The elements of a fixed level setup are defined with firmware commands. With equation-based level setup, you can use variables for the definition of level resources. This provides more flexibility.

Note that fixed and equation based level setups do not exclude each other. You can define a fixed level setup and an equation based level setup in the same level file. The level file resides in the level sub-directory of the device directory.
