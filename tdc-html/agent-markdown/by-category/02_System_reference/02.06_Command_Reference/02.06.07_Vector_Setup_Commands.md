# Vector Setup Commands

#### Subtopics

- [Concepts of vector setup](<02.06.07.01_Concepts_of_vector_setup.md>)
- [List of vector setup commands](<02.06.07.02_List_of_vector_setup_commands.md>)

In the vector setup, you define the labels of the test (also called test labels, vector labels, sequencer labels, or patterns). A label is the basic processing unit of SmarTest. It consists of a sequence of instructions that serve to send a vector stream to the DUT, and is identified by a unique name.

## Functional changes

- Introduced before SmarTest 6.3.2
