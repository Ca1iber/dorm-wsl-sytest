# PTDS, PTDS? - (Pin attributes Tweaking Definition String)

The PTDS (Pin attributes Tweaking Definition String) command allows you to set offset delays for individual channels. The PTDS? query returns the existing settings.

PTDS offers more flexibility than [PADS, PADS? - (Pin Attributes Definition String)](<02.06.02.02.172_PADS__PADS__-__Pin_Attributes_Definition_String.md>). It defines pin attributes for channels instead of pins, and it enables you to associate different pin attributes with different timing sets.

PTDS is not reflected in the user interface as is the case with PADS. However, you can append PTDS commands to an existing pin attributes file. The settings made by PTDS overwrite those made by PADS.

The PTDS command can be issued only after timing, waveform, spec or equation sets have been defined. Failure to observe this causes the system to issue an error.

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## PTDS

```
PTDS {channelNo}, [EBT_specifier], {set_specifier}, {timing_set}, [tweaking_set], [mode], {definition_string}
```

## PTDS?

```
PTDS? {channelNo}, [EBT_specifier], {set_specifier}, {timing_set}, [tweaking_set], [mode]
```

returns:

```
PTDS {channelNo}, [EBT_specifier], {set_specifier}, {timing_set}, [tweaking_set], [mode], {definition_string}
```

## Parameters

 |

channelNo

 |

This is a five digit field which defines the channel to which the pin is connected. See also the command [DFPN, DFPN? - (DeFine Pin Name)](<02.06.02.02.63_DFPN__DFPN__-__DeFine_Pin_Name.md>) for this parameter.

 |
 |

You can also enter:

 |
 |

ALL

 |

Sets, or returns information on, all channels.

 |
 |

EBT_specifier

 |

The Equation Based Timing specifier can be:

 |
 |

eqn_set

 |

Equation Set number in the range of 1 to 256.

 |
 |

0

 |

Causes the next parameter (set_specifier) to be interpreted as waveform_set instead of spec_set.

 |
 |

If you specify the name of a multi-port specification for the set_specifier parameter, the EBT_specifier parameter will be ignored.

You can also enter:

 |
 |

ALL

 |

Sets delay for, or returns information on, all Equation Sets.

 |
 |

set_specifier

 |

Possible values are:

 |
 |

1 to 256

 |

The number is interpreted as a waveform set number if EBT_specifier is set to 0. Otherwise, it is taken as a specset number.

 |
 |

multi-port_spec

 |

In a multiport setup, you can specify the name of a multi-port specification in double quotes. In this case, the EBT_specifier parameter will be ignored. The pin attributes will be associated with the specified timing set (timing_set parameter) in every port of the specification.

 |
 |

You can also enter:

 |
 |

ALL

 |

Sets delay for, or returns information on, all Spec Sets or Waveform Sets.

 |
 |

timing_set

 |

Timing Set number in the range of 1 to 256. You can also enter ALL to select information on all timing sets.

Note that ALL is the only allowed option if EBT_specifier or set_specifier is also set to ALL.

 |
 |

tweaking_set

 |

Tweaking Set number. Currently not used.

 |
 |

mode

 |

Currently not used.

 |
 |

definition_string

 |

Definition string for the logical edges.

 |

## Application

Channels table, pin attributes data.

## Errors

An error is generated if:

- Any parameter is out of range.
- Issuing PTDS before timing, waveform, spec, or equation sets have been defined.

## Example

```
PTDS 10812,0,4,5,,1,1,"d1:2,d2:0.003, d8:5, r1:-1, r2:-2"
PTDS? 10101,,all,all,,
```

The following example defines pin attributes for timing sets of the multi-port specification spec_port_1_port_2.

```
> PTDS 10101,,"spec_port_1_port_2",1,,,"d1:1 d3:3"
> PTDS 10101,,"spec_port_1_port_2",2,,,"d1:2 d2:3"
> PTDS? 10101,,"spec_port_1_port_2",ALL,,
< PTDS 10101,,"spec_port_1_port_2",1,,,"d1:1 d3:3"
< PTDS 10101,,"spec_port_1_port_2",2,,,"d1:2 d2:3"
```
