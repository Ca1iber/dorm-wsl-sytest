# Location of the detailed Error Map

You can locate the detailed Error Map within the test processor or in the external memory (with the DCRT command). The latter option gives much more space and is particularly useful if you want to record results on the edge level (see [Result granularity](<02.06.11.01.02.01.02.03_Result_granularity.md>)). Note that the size of the internal Error Map is 4 times as great on Smart Scale systems as compared to Pin Scale systems (see [PS1600 error map size](<../02.05_Test_Head_Cards/02.05.04.01.03.02_PS1600_error_map_size.md>)).

The location of the detailed Error Map is defined on the port level. If the timing ports and vector ports of a multi-port setup are not identical, it is the vector ports that determine the error map location.

Note that the available amount of external memory space depends on the respective setup. Only that part can be used for the Error Map that is not required by other kind of data (this is the same area that is also used for digital capture). You can query the amount of available space with DCRS?.
