# NOOP, NOOP? - (NO OPeration)

The NOOP command is used as a placeholder or is inserted instead of an invalid command.

The command can also be used to add annotations to the MCD log file. For the MCD log, see [Using the Trace Function](<02.06.01.03.05_Using_the_Trace_Function.md>).

The NOOP? query returns the comments that are passed to it.

## NOOP

```
NOOP["string_1"|no_1],["string_2"|no_2],["string_3"|no_3],["string_4"|no_4]
```

## NOOP?

```
NOOP?["string_1"|no_1],["string_2"|no_2],["string_3"|no_3],["string_4"|no_4]
```

returns:

```
NOOP["string_1"|no_1],["string_2"|no_2],["string_3"|no_3],["string_4"|no_4]
```

## Parameters

 |

string_1 to string_4

 |

A string of up to 128 characters

 |
 |

no_1 to no_4

 |

An integer

 |

## Application

Placeholder, MCD log comment.

## Example

```
NOOP "TF1",,,
```

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.2.2: Number of characters for string_1 tostring_4 changed
