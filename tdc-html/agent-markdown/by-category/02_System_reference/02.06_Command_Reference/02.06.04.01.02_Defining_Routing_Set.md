# Defining Routing Set

Before executing all tests, you should prepare the necessary routing sets.

The system lets you create multiple routing sets, up to the maximum number previously defined by the DSCP (Define System Control Parameter) command. The system controls the use of routing sets during tests.

The commands associated with routing set definition are as follows:

- [UDRS - (UnDefine Routing Set)](<02.06.02.02.300_UDRS_-__UnDefine_Routing_Set.md>)

The DFRS command defines a routing set and allocates the specified size of the routing statements that will be programmed for the routing set by the DFRT command. The DFRS? query returns the size of the routing statements for the specified, or all routing sets.

The UDRS command deletes the specified routing set.
