# PSLR, PSLR? - (Power Supply Level Ranges)

The PSLR command allows you to make DPS settings for DC Scale channels previously configured with the [DFPS](<02.06.02.02.65_DFPS__DFPS__-__DeFine_Power_Supply.md>) command in DPS mode. The PSLR? query returns the existing settings.

If this command is applied to the primary DPS set, the settings specified with this command will be activated on the hardware immediately.

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## PSLR

```
PSLR {dps_No|dps_set_id}, [vout_frc_rng], [iout_clamp_rng], [current_limiter,] [const_curr_check], [connect_state], {(pinlist)}
```

## PSLR?

```
PSLR? {dps_No|dps_set_id}, {(pinlist)}
```

returns:

```
PSLR {dps_No|dps_set_id}, [vout_frc_rng], [iout_clamp_rng], [current_limiter,] [const_curr_check], [connect_state], {(pinlist)}
```

Note The PSLR command supports only DC Scale channels, except for one parameter: const_curr_check can be set for standard DPS-slot DPS's as well.

## Parameters

 |

dps_No

 |

Needed for non-equation-based setup.

The identification number of the DPS set which you want to modify. The number must not exceed the maximum number allowed (as defined by the DSCP (Define System Control Parameter) command). Typing ALL modifies all the existing DPS sets. Typing PRM modifies the primary DPS set. Typing ACT (only for PSLV?) displays the settings of the actual enabled DPS set.

 |
 |

dps_set_id

 |

Needed for equation-based setup.

This parameter is derived as follows:

`100000 * equation_set_no + 1000 * specset_no + 1`

 |
 |

vout_frc_rng

 |

Specifies the upper limit of the voltage range for DC Scale channels in [V].

This is the maximum output voltage that can later be programmed by the [PSLV](<02.06.02.02.195_PSLV__PSLV__-__Power_Supply_LeVel.md>) command. The specified value is rounded up to the next higher range limit of the underlying hardware. The value also effects the number of required channels in case of connect_state = UNGANG (see below).

This parameter does not apply to DPS-slot DPS's and to DC Scale DPS's which provide only one range. Check the [DC Scale Device Power Supplies specifications](<../02.02_Specifications/02.02.05_DC_Scale_Device_Power_Supplies_and_VI_Cards.md>) whether voltage force ranges are supported for your configuration. Use the (optional) parameter accordingly.

 DC Scale AVI64 and FVI16 The parameter can be changed in connected state and in disconnected state of the DPS. All other DPS The parameter may only be changed when [PSST, PSST? - (Power Supply STatus)](<02.06.02.02.198_PSST__PSST__-__Power_Supply_STatus.md>) is set to OFF for the specified pins.

When changing the range while in LOZ state (see [PSLV](<02.06.02.02.195_PSLV__PSLV__-__Power_Supply_LeVel.md>)), the system shortly opens the output relay and closes it afterwards.

 |
 |

iout_clamp_rng

 |

Specifies the maximum current for DC Scale channels in [A]. The parameter is ignored for DPS-slot DPS's.

  DC Scale AVI64 and FVI16 The parameter can be changed in connected state and in disconnected state of the DPS. All other DPS The parameter may only be changed when [PSST, PSST? - (Power Supply STatus)](<02.06.02.02.198_PSST__PSST__-__Power_Supply_STatus.md>) is set to OFF for the specified pins.

When changing the range while in LOZ state (see [PSLV](<02.06.02.02.195_PSLV__PSLV__-__Power_Supply_LeVel.md>)), the system shortly opens the output relay and closes it afterwards.

 |
 |

current_limiter

 |

Enables (= protected) or disables (= unprotected) a protection against a shutdown of the tester due to excessive current consumption (see also parameter hex_value, bit 12 of the [PSAS? - (Power Supply Accumulated Status)](<02.06.02.02.188_PSAS__-__Power_Supply_Accumulated_Status.md>) query).

 |
 |

const_curr_check

 |

Defines whether constant current check is enabled. The parameter can be set for DPS-slot DPS's as well. Possible values are:

ON Current check is enabled

OFF Current check is disabled (this is the default)

 |
 |

connect_state

 |

Defines the connection state for DC Scale channels. This parameter may only be changed when PSST is set to OFF for the specified pins. Possible values are:

 |   | HIMP  | High Impedance Measurement Mode. This mode allows you to use a DC Scale card as a voltmeter. |
 |   | NORM |

Normal (default)

 |
 |   | HDIG |

Digitizer Mode

This parameter is for UHC4 / UHC4T only!

 |
 |   | NORM_HDIG |

Normal with Digitizer Mode

This parameter is for UHC4 / UHC4T only!

 |
 |   | UNGANG |

Specifies to connect only necessary channels

This parameter is for all DC Scale cards.

Note that on DPS128/64 and XPS256 you cannot execute a current compare on a ganged group of channels in unganged mode. Already activated comparators are silently disabled in unganged mode. A user notification (Error or warning) is omitted in this case, to avoid any interrupt in the testflow. The previous state of the comparators is automatically restored after the ganged group has been restored.

See also [Using UNGANG connect state with DC Scale DPS cards](<../02.08_Setup_and_Result_Tools/02.08.04.14.06.01.03_Using_the_UNGANG_connect_state_with_DC_Scale_DPS_cards.md>).

   | |
 |

pinlist

 |

pinlist must contain the names of pins previously defined by the [DFPS](<02.06.02.02.65_DFPS__DFPS__-__DeFine_Power_Supply.md>) command. If a pin is associated with a DPS-slot DPS, it is ignored. @ refers to all pins that are associated with a DC Scale channel.

 |

## Application

Level setup, see [Level Setup Commands](<02.06.05_Level_Setup_Commands.md>).

## Errors

An error is generated if:

- The DPS set number is out of range
- The programmed voltage is out of range
- The programmed current is out of range
- A communication error with the DPS occurs
- The programmed voltage reaches the overvoltage limit
- The vout_frc_rng parameter is changed when PSST is set to ON for one of the specified pins

## Examples

### Example 1

```
PSLR PRM,4,0.5,OFF,NORM,(dps1)
```

This example sets the following parameters for device pin Vee:

- The current primary DPS set
- A voltage of 4 V
- A current of 0.5 A
- Current check is disabled
- The connect state is set to normal, and not high impedance measurement mode

### Example 2

```
PSLR PRM,,,,HDIG,(dps1)
```

This example uses the default parameters for device pin Vee, while the connect state is set to digitizer mode.
