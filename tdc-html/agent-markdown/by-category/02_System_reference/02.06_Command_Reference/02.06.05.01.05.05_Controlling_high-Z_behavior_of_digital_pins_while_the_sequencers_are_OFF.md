# Controlling high-Z behavior of digital pins while the sequencers are OFF

 Note The support for fixed level setups is discontinued with SmarTest version 7.4.1T. We recommend using the [Equation based level setup](<../02.08_Setup_and_Result_Tools/02.08.04.14.02_Equation_based_level_setup.md>) for all releases of SmarTest 7.2 or higher versions.

Digital pins in high-Z are floating to an arbitrary voltage because of +/- leakage current (RIL) from the comparators of the Pin Electronics (PE). This floating voltage, which can be different for every pin, is limited by the voltage rails or driver clamps. It can be anywhere between the voltage rails or the maximum positive and negative clamp voltage.

The floating voltage for digital pins in high-Z is controlled by the active level set. When the sequencers are in the RUN or BRK state, this is a user-defined level set. When they are in the OFF state, the predefined level set 0 (zero) is the active level set.

In addition to control the high-Z behavior use the level set 0 as well to [control the engagement of the 14 k鈩?pull-down resistor of the PS1600 card](<02.06.05.01.05.06_Pull-down_function.md>).

Programming of level set 0 is supported by the relevant firmware commands TERM and CLMP. However, these firmware commands are only effective when the sequencers are at least in the BRK state. Therefore, the following sequence of steps must be observed:

- Load the level setup file.

This must be done before you program level set 0, because otherwise level set 0 will be reset.

- Program level set 0 with TERM and CLMP.
- Put the sequencers into the BRK state to let the firmware commands come into effect.

These three steps need to be performed only once, at the start of the testflow. Step 2 and 3 can be interchanged.

Thereafter, level set 0 is activated whenever the sequencers are put into the OFF state (or DLSO is issued), and inactivated whenever the sequencers are put into the BRK state.

Level set 0 is subject to the following restrictions:

- It cannot be defined in an equation based level setup. You must use a fixed level setup for this feature.
- It cannot be selected as the primary level set with SPRM.
- It is not included in the ALL parameter of TERM and CLMP.
- It only admits a proper subset of the available termination modes.

The following recommendations should also be observed:

- The firmware commands referring to level set 0 are best embedded into a test method which is executed once at the start of the testflow.
- Do not enter firmware commands referring to level set 0 into the levels setup file. They will be overwritten when the level setup is saved from within SmarTest. Furthermore, level set 0 is not supported by the setup management tool.
- Do not put firmware commands referring to level set 0 into the connect sequence. These commands need not be executed with every connect, but only once, after the level setup file has been loaded.
- When you download a new level setup file, level set 0 is reset. In this case you must issue the firmware commands again and re-initialize the set as described.

## Example

```
CLMP 0,ON,vcl,vch,(@)
TERM 0,A,vcom,iol,ioh,,,(@)
SQST BRK
SQST OFF
```

The CLMP command sets the default off-level set clamp levels to vcl and vch mV for all pins. The TERM command sets the active load to vcom mV commutation voltage and iol, ioh 碌A load current, again for all pins. The switch to BRK initializes the set. Finally, the values are activated by the switch from BRK to OFF.
