# SWNG, SWNG? - (SWiNG [mV] for level dependent calibration)

The SWNG (SWiNG [mV] for level dependent calibration) command allows you to specify a swing for which the timing is to be adjusted on a low level. The SWNG? query returns the actual setting of the swings.

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## SWNG

```
SWNG {waveform_set|specset_id}, {timing_set}, {swing}, {(pinlist)}
```

## SWNG?

```
SWNG? {waveform_set|specset_id}, {timing_set}, {(pinlist)}
```

returns:

```
SWNG {waveform_set|specset_id}, {timing_set}, {swing}, {(pinlist)}
```

## Parameters

 |

waveform_set

 |

Specifies the number of a waveform set for non-equation based testing. Enter PRM for the primary waveform set, ALL for all waveform sets, or an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>).

 |
 |

specset_id

 |

Specifies a spec set ID for equation based testing. The specset_id is derived as follows:

`100 * equation_set_no + specset_no`

 |
 |

timing_set

 |

Timing Set Number. Enter PRM for the primary timing set, ALL for all timing sets, or an integer in the range 1 to the maximum number of allowed timing sets. The maximum number is determined by [TSUS](<02.06.02.02.283_TSUS__TSUS__-__Timing_Sets_USed.md>).

 |
 |

swing

 |

Swing in mV. Enter a value in the range from 1 to 9000. The parameter OFF switches off swing adjustment.

 |
 |

pinlist

 |

The name of the pin or pins for which swing adjustment is to be set. This parameter can also include groups previously created by the DFGP command.

The @ symbol can be used to specify all configured pins. If more than one pin is to be included, the names must be separated with a comma.

 |

## Application

Swing adjustment of mixed level devices.

## Errors

An error is generated if:

- The waveform set number or the timing set number are out of the used range.
- The swing value is out of range; this value must be in the range between 0 to 9000 mV.

## Example

```
SWNG 1,1,5000,(@)
```

This command adjusts the timing for all pins and pin groups specified for timing set 1 of waveform set 1. The swing for which the timing is to be adjusted has a value of 5000 mV.

## Functional changes

- Introduced before SmarTest 6.3.2
