# Executing a pattern‑based SmartLoop test

#### Subtopics

- [Defining a compliance pattern for pattern‑based SmartLoop testing](<02.06.17.04.01_Defining_a_compliance_pattern_for_pattern__ased_SmartLoop_testing.md>)

SmartLoop鈩?tests are a special kind of loopback tests that are provided by Smart Scale systems. In a loopback test, the received signals of one or more output pins are routed to their corresponding input pins, and are then used as drive data for these input pins. You can inject jitter into the resulting drive signals.

Which output pin corresponds to which input pin is determined by the pin configuration. The channels that are associated with such a pin pair must have consecutive numbers where the lower number is odd. This implies that both channels belong to the same 4-channel group on a PS9G system, and to the same 8-channel group on a PS1600 system. One of the pins must be defined as an input pin, the other as an output pin.

Note that data can be routed in both directions. In the PSG9 group 10105 through 10108, for example, channel 10105 can be used for an output pin, and its received data routed to channel 10106, which is used for an input pin. But it is also possible to use 10106 for an output pin and 10105 for its target input pin.

A corresponding pin pair is configured for a pattern‑based SmartLoop鈩?test in the wavetable. For details see [Defining the wavetable for a pattern‑based SmartLoop test](<02.06.06.01.03.02.03_Defining_the_wavetable_for_a_pattern__ased_SmartLoop_test.md>).

It is also possible to execute a pattern‑based SmartLoop鈩?test for pairs of differential pins. The positive connection of the input pair will be generated from the differential output signal. The negative input connection will be the inverse of the positive connection.

The pattern‑based SmartLoop鈩?test can be combined with transition tracking on the output pins. For details see [Combining transition tracking with a PRBS or pattern‑based SmartLoop test](<02.06.15.02.01_Combining_transition_tracking_with_a_PRBS_or_pattern__ased_SmartLoop_tes.md>).

A pattern‑based SmartLoop鈩?test is started with the sequencer instruction LPBK. For more information see [Instructions for PRBS and SmartLoop tests](<02.06.07.01.08.06_Instructions_for_PRBS_and_SmartLoop_tests.md>).

SmartLoop鈩?is activated by specifying the loopback keyword in the IOCHANNEL section of the model file.

## Restrictions

Observe the following restrictions:

- You cannot combine pattern defined SmartLoop鈩?pins and normal digital pins in one port. If you want to execute a normal digital test in parallel with a pattern defined SmartLoop鈩?test, you must put the pattern‑based SmartLoop鈩?pins and the digital pins into different ports. This holds for both timing and vector ports.
- Match loops cannot be executed in a port that belongs to the same sequencing group as a pattern‑based SmartLoop鈩?port.
