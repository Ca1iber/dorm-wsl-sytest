# NIFE, NIFE? - (Number of Independent Fast Error)

The NIFE command defines the number of independent error propagations.

If the [Fast Sync](<02.06.07.01.08.04.03.03_Fast_Sync.md>) feature is desired, use the NIFE command to specify the maximum number of independent Fast Sync ports occurring on a test processor. The number of ports depends on the DUT board design and should be as small as possible.

Note The command can be issued only when the test system is in a disconnected state.

## Syntax

```
NIFE {number}
```

```
NIFE?
```

returns:

```
NIFE {number}
```

`NIFE?` can be issued only if the number of independent Fast Sync ports already has been set by command `NIFE {number}`. Otherwise, the error message Failed to execute firmware command: NIFE? will be shown.

  Parameters

 | number  | Specifies the maximum number of independent Fast Sync ports. It can be [1,...,8]. |

## Application

Multisite testing

## Errors

An error is generated if the argument is invalid.

## Example

```
>SQST OFF
>NIFE 2
>STME FAST,
>STME ON,
```

This example configures the Fast Sync feature, and sets two independent Fast Sync ports on each test processor.
