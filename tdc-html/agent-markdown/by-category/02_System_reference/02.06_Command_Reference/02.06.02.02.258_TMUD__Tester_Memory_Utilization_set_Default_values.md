# TMUD (Tester Memory Utilization set Default values)

The TMUD firmware command will perform a clean up of all related memory entries.

This firmware command will just reset the log values (counters) to their defaults (zero), but does not touch the setting for the transaction memory size itself.

In addition you can enable or disable memory utilization logging. If logging is disabled the logged values will stay unchanged until logging is enabled again.

## Syntax

```
TMUD {client}, [logState],{(portlist)}
```

Parameter
 |

Parameter

 |

Description

 |
 |

client

 |

Possible values are:

 |
 |

 |

PROTOCOLTEST

 |

Logging of memory usage will be switched on or off for protocol tests.

 |
 |

 |

ALL

 |

Logging of memory usage will be switched on or off for all supported clients.

 |
 |

logState

 |

Possible values are:

 |
 |

 |

ON

 |

Starts logging of memory usage. The values recorded in the previous logging session will be reset to 0.

The values of the current logging session can be retrieved with the TMUL? query.

 |
 |

 |

OFF

 |

Stops logging of memory usage including the DEBUG_WATERMARK and DEBUG_SEQUENCES options.

The values that were determined are kept until logging is started again with option ON.

 Note When logging is stopped, all protocol patterns for the specified ports will be deleted. |
 |

 |

DEBUG_WATERMARK

 |

This option causes TMUD to write all changes of the maximum used memory to the report window (in bytes). If necessary, it also activates logging of memory usage (the ON state).

 |
 |

 |

DEBUG_SEQUENCES

 |

This option causes TMUD to write the cache management type (standard or volatile) of any new transaction sequence to the report window. If necessary, it also activates logging of memory usage (the ON state).

 |
 |

 |

DEBUG_ALL

 |

This option combines DEBUG_WATERMARK and DEBUG_SEQUENCES. If necessary, it also activates logging of memory usage (the ON state). Both these activities are also stopped by setting logState to OFF.

 |
 |

 |

If the parameter is omitted, the current counter values will be reset to 0, but the log state will not be changed.

 |
 |

portList

 |

Is a comma separated list of ports.

To apply the command to all ports, use @@.

 |

## Errors

Errors will happen if:

- client is unknown.
- type is unknown.
- portList contains specifiers that cannot be mapped to any configured port name.

## Example

```
> TMUD PROTOCOLTEST,ON,(mdioPort)

> TMUL? ALL,ALL,(mdioPort)
< TMUL PROTOCOLTEST,CACHE,"0,0,0",(mdioPort)
< TMUL PROTOCOLTEST,SIZE,"0,0,AUTO",(mdioPort)
```

In this example the TMUD resets the memory utilization logs of the mdioPort of the PROTOCOLTEST client. It also sets logging to ON in case it was disabled previously.

The TMUL? query is used to display that TMUD has reset all memory utilization counters to default values.

```
> TMUD ALL,ON,(@@)

> TMUL? ALL,ALL,(@@)
< TMUL PROTOCOLTEST,CACHE,"0,0,0",(mdioPort)
< TMUL PROTOCOLTEST,CACHE,"0,0,0",(otherPort)
< TMUL PROTOCOLTEST,SIZE,"0,0,65536",(mdioPort)
< TMUL PROTOCOLTEST,SIZE,"0,0,AUTO",(otherPort)
```

In this example the TMUD resets the memory utilization logs of all ports (@@) of all clients. It also sets logging to ON in case it was disabled previously for all ports and clients.

The TMUL? query is used to display that TMUD has reset all memory utilization counters to default values.

Note If the memory size was specified by `PROTOCOL_TEST::reserveTransactionMemory()` the according limit will be displayed, else AUTO is shown.
