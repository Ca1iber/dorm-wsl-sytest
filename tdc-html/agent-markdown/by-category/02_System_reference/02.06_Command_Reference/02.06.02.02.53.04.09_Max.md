# Max

To query the maximum value in the list the syntax is:

```
DDEF? "ListName","Max"
```

## Example

If list A is defined as

```
DDEF "A",SET,"Equation","Loop(1,10,10)"
```

then `DDEF? "A","Max"` will return:

```
DDEF "A",DATA,"Max",10
```

## Functional changes

- Introduced before SmarTest 6.3.2
