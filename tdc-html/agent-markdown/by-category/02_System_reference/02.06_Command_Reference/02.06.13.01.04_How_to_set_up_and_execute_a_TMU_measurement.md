# How to set up and execute a TMU measurement

The following describes how to set up and execute a TMU measurement on the firmware level for a PS1600 pin in STDDIFF mode.

## About this task

TMU measurements serve to measure the period length, pulse width, and rise time or fall time of output signals. See [TMU per Pin overview](<02.06.13.01.01_TMU_per_Pin_overview.md>) for more information.

## Procedure

-  Define a TMU set:

  -  Create a TMU set with TSDF.
  -  Define the measurement parameters for the appropriate pins with TSCF.

An example for measuring the period length is given in the description of TSCF.

  -  Make the TMU set the primary such set with TSPR.

-  Define the arming waveforms:

  - Define waveforms that specify the ARM keyword for the r7 edge.
  - Define an appropriate delay for r7 in the active timing set.

-  Make use of the arming waveforms in the pattern as required.
-  Activate the appropriate result area with TSRH?, if necessary (see [Storing the results of more than one measurement](<02.06.13.01.03_Storing_the_results_of_more_than_one_TMU_measurement.md>)).
-  Start the sequencers, for example with FTST?.

## Results

The measurement results can be retrieved with TSRS? (period length) or TSRW? (raw time stamps).
