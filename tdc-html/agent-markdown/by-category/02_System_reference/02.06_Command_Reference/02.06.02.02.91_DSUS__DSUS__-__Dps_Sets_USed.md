# DSUS, DSUS? - (Dps Sets USed)

The DSUS (Dps Sets USed) command sets the number of defined DPS sets to the given value. The new value has to be an integer in the range of 1 to the Maximum allowed DPS sets as set by [CONF, CONF? - (CONFiguration)](<02.06.02.02.31_CONF__CONF__-__CONFiguration.md>) (default is 32, maximum is 256).

You can use the DSUS command to delete sets. If the level setup file that you want to load to hardware contains more DPS sets than you require, you can use the DSUS command to delete all the sets above the number you specify.

The DSUS? query returns the number of DPS sets currently defined.

## DSUS

```
DSUS {ds_No}
```

## DSUS?

```
DSUS?
```

returns:

```
DSUS {ds_No}
```

## Parameters

 |

ds_No

 |

DPS Set Number. This is the highest number currently allocated to a DPS set, or the highest number of set you want to load. The number you type must not exceed the maximum number of DPS sets allowed (defined by the DSCP command).

This number is automatically updated to include any new DPS set as it is created. At power-on only one DPS set (containing the default values) is available.

 |

## Application

Level Setup, see [Level Setup Commands](<02.06.05_Level_Setup_Commands.md>).

## Errors

An error is generated if:

-  The ds_No is greater than the range allowed by the [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) command.
-  The ds_No is smaller than one.

## Example

```
DSUS 2
```

This example defines a maximum of 2 DPS sets.

## Functional changes

- Introduced before SmarTest 6.3.2
