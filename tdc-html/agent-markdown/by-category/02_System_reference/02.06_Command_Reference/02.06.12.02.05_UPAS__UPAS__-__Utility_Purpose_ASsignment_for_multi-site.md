# UPAS, UPAS? - (Utility Purpose ASsignment for multi-site)

The UPAS command serves to assign different standard output states to the same utility purpose for sites > 1.

The utility purpose must have been defined with the [DFUP](<02.06.02.02.69_DFUP__DFUP__-__DeFine_Utility_Purpose.md>) command. DFUP also sets the standard output states for site 1.

In order to activate the output states, first restrict the setup focus to the site in question with [PSFC](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>), and then activate the settings with [UPST](<02.06.02.02.305_UPST__UPST__-__Utility_Purpose_STate.md>) and [FLSH](<02.06.02.02.124_FLSH_-__FLuSH_buffered_commands.md>).

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## UPAS

```
UPAS {site}, ["{setting}"], {(purpose_name)}
```

## UPAS?

```
UPAS? {site}, {(purpose_name)}
```

returns:

```
UPAS {site}, "{setting}", {(purpose_name)}
```

## Parameters

 | site |

The site parameter is an integer that defines the number of the site where the channels are to be defined.

The integer must be greater than 1.

When specified as part of the UPAS? query, you can use the parameter ALL to read the standard output states for all sites.

 |
 | setting |

Output states for each member of the utility purpose on the specified site.

Set the output state of each utility line with the following specifiers:

- 0: Sets the corresponding (write) channel to high (high impedance state)
- 1: Sets the corresponding (write) channel to low
- X (x): No action

The number and order of characters must correspond to the ch_No_list parameter of the [DFUP](<02.06.02.02.69_DFUP__DFUP__-__DeFine_Utility_Purpose.md>) command.

If this parameter is omitted, the specified site is set to the same states as site 1.

 |
 | purpose_name |

Name of a utility purpose defined by the [DFUP](<02.06.02.02.69_DFUP__DFUP__-__DeFine_Utility_Purpose.md>) command.

In the query, the symbol @ can be used to list all defined utility purposes.

 |

## Application

For more information about utility purposes, see [Defining a utility purpose](<02.06.03.01.08_Defining_a_utility_purpose.md>) and [Accessing Utility Lines](<02.06.12.01_Accessing_Utility_Lines.md>).

## Errors

An error is generated if:

- A multisite setting is not performed with the [PSTE](<02.06.02.02.199_PSTE__PSTE__-__Parallel_SiTe_Enable.md>) command.
- The specified site number is less than 0 or greater than that of the max site.
- The given name is not allocated to any utility purpose.
- The given name has already been assigned to a digital pin, analog pin, DPS pin, or utility name.
- Inconsistent settings are specified for one channel (for an example, see the [DFUP](<02.06.02.02.69_DFUP__DFUP__-__DeFine_Utility_Purpose.md>) command).
- The setting contains characters other than "0", "1" and "X (or x)".
- The number of characters in the setting is not equal to that of the channel list in the [DFUP](<02.06.02.02.69_DFUP__DFUP__-__DeFine_Utility_Purpose.md>) command.

## Example

```
> DFUP (101,102,103,104),"11XX",(AWG_CNCT)
> UPAS 2,"XX11",(AWG_CNCT)
> UPST ,(AWG_CNCT)
> FLSH
> UPST? (AWG_CNCT)
< UPST "11XX", (AWG_CNCT)
> PSFC 2
> UPST ,(AWG_CNCT)
> FLSH
> UPST? (AWG_CNCT)
< UPST "XX11", (AWG_CNCT)
```

In this example, the [DFUP](<02.06.02.02.69_DFUP__DFUP__-__DeFine_Utility_Purpose.md>) command defines a utility purpose AWG_CNCT and output states for site 1. The UPAS command defines the output states of AWG_CNCT for site 2. First the settings of site 1 are activated. Then the setup focus is restricted to site 2, and the output states for site 2 are activated.
