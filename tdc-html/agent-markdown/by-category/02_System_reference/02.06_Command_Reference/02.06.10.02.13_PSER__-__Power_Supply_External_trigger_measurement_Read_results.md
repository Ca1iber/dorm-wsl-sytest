# PSER? - (Power Supply External trigger measurement Read results)

The PSER? (Power Supply External trigger measurement Read results) query returns the results of DPS current measurement that has been executed with the [PSEE](<02.06.02.02.189_PSEE_-__Power_Supply_External_trigger_measurement_Execute.md>) or [PSIE](<02.06.02.02.192_PSIE_-__Power_Supply_Internal_trigger_Execute.md>) command. The results sequence matches the pinlist given with the command.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Syntax

```
PSER? [setnr], {mode}
```

returns:

```
PSER [setnr], [result], {(pinlist)}, {binary_data}
```

## Parameters

 |

setnr

 |

The set number of the external trigger measurement. (The range is 1 to 256). If this parameter is omitted, this command returns the result of previous execution of the PSEE or PSIE command.

 |
 |

mode

 |

This parameter defines the type of result.

 |
 |

PVAL

 |

Binary data for each pin defined in the measurement will be returned.

 |
 |

PPF

 |

A per-pin pass/fail result will be returned. Only valid when a setnr is given.

 |
 |

BVAL

 |

Binary data mode.

4 Bytes header for the sample count

4 Byte for test points count

Test points (8 bytes per test point)

Sampler (channel count) is set to 1.

 |
 |

GPF

 |

A global pass/fail result will be returned. Only valid when a setnr is given. Data will be evaluated for all sites of a multi-site test.

 |
 |

result

 |

The result given when setnr is specified. The result parameter contains a P (pass) or an F (fail) if the GPF or PPF option has been selected.

 |
 |

pinlist

 |

Only DPS pins and DC Scale pins configured with [DFPS](<02.06.02.02.65_DFPS__DFPS__-__DeFine_Power_Supply.md>) are supported.

 |
 |

binary_data

 |

The binary data result string. The string starts with the '#' character, followed by a digit in the range 1 to 9 which stipulates how many digits are used in the data length specifier. The data length specifier is next - up to 9 digits determine how many bytes of data will follow. Then comes the actual data string which appears as a list of values separated by a "," (comma). The first byte of data is an identifier which defines the format of the following data. For a waveform the first byte is '\x00' with the waveform represented as FLOAT64 values. Each value is in Amps [A].

 |

## Errors

There are no errors except parameter checks.

In case of a measurement range overflow the command returns 99999, respectively -99999 in case of a negative overflow.

## Examples

### Example 1

```
DPSE 1,(Vcc),#90000000170,0.1,0.2,0.2,0.3
DPSE 1,(Vdd),#90000000121,2,0.1,0.2
PSEE 1,,,()
```

### Example 2

```
PSER? 1,PVAL
PSER 1,P,(Vcc),#9000000010,0.15,0.25
PSER 1,F,(Vdd),#9000000010,0.3,0.3
```

### Example 3

```
PSER? 1,PPF
PSER 1,P,(Vcc),#9000000000
PSER 1,F,(Vdd),#9000000000
```

### Example 4

```
PSER? 1,GPF
PSER 1,F,(),#9000000000
PRLT? ALL // get multisite results
PRLT "FPP" // site 1 fail, sites 2 & 3 are pass
```

### Example 5

```
PSEE, I_300mA, 32, (Vee)
PSER? ,PVAL
```

returns:

```
PSER,,(Vee),#90000000120,0001923451
```

### Example 6

```
DPSE 1,(Vcc),#90000000096,0.1,0.2
PSIE 1,,all_sampler,,,(Vcc)
PSER? ,PVAL
```

returns:

```
PSER ,,(Vcc),#90000000190.15,0.25,0.35,0.45
```

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.2: Results sequence matches the PSEE/PSIE pinlist (since 6.3.5.3)
- SmarTest 6.5.3: Maximum number of DPS sets increased to 256
