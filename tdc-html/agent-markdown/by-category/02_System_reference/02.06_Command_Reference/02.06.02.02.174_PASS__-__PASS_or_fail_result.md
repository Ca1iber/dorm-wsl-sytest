# PASS? - (PASS or fail result)

The PASS? (Pass or Fail result) query returns a single pass/fail result for the last test performed on the specified pins. A pass is returned if all pins in the pin list or the port list passed the test.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Syntax

```
PASS? {(pin_list)}
```

or

```
PASS? {(port_list)}
```

returns:

```
PASS {res_flag}, {(pin_list)}
```

or

```
PASS {res_flag}, {(port)}
```

respectively.

Note port_list mode returns the pass or fail result per port. This is different than the case when using pin_list mode.

To report the last test result per individual pin , the PPIN command is used.

## Syntax

```
PASS?PPIN,{(pins)}
```

returns

```
PASS PPIN,{res_flag}, {(pin}
```

Note The result (pass or fail) is returned for each pin specified in pins individually.

## Parameters

 |

pin_list

 |

The last test result is provided for the pins specified in pin_list. If more than one pin list is included, the names must be separated by a comma.

Normally, only O or IO pins in the list are taken into account; I pins are ignored. However, if any sequencer program of the setup contains a[MEAS](<02.06.02.02.160_MEAS_-__execute_a_MEASurement_set.md>) instruction (see the [SQPG](<02.06.02.02.237_SQPG__SQPG__-__SeQuencer_ProGramming.md>) command), and the measurement set that is executed by this instruction is defined for an I pin, then the measurement result for this pin will be included in the reply of PASS? if the I pin is specified in pin_list.

 |
 |

port_list

 |

The last test result is provided for the pins of a port specified in port_list. If more than one port is included, the names must be separated by a comma.

 |
 |

Pins

 |

The last test result is provided per each pin specified in pins individually. If more than one pin is included , the names must be separated by a comma.

 |
 |

res_flag

 |

F

 |

If this result is returned, at least one pin in pin_list or port failed the last test. In the case of per pin query (using PPIN command), a fail is returned if the individual pin specified in pins failed the last test.

 |
 |

P

 |

If this result is returned, all pins in pin_list or port passed the last test. In the case of per pin query (using PPIN command) , a pass is returned if the individual pin specified in pins passed the last test.

 |

Application

Test results, see [Test Result Commands](<02.06.11_Test_Result_Commands.md>) and [Multi-Port Testing](<../../03_Use_cases_and_application_papers/03.03_How_to_use_Multiport_for_specific_Applications/03.03.01.02_General_Overview_of_Multi-Port_Testing__Cover.md>).

## Errors

An error is generated if:

- You send the query while the sequencer is running. There is then no result data available.
- You make a change in the setup and then send the query. There is then no result data available. To get the data, start a new test.

## Example

After a functional test has been performed, sending PASS? returns one result for the whole test.

```
PASS? (@)
```

returns:

```
PASS P, (@)
```

or

```
PASS F, (@)
```

for a passed or a failed test result respectively.
