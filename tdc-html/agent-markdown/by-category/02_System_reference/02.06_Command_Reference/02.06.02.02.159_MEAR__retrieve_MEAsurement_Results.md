# MEAR (retrieve MEAsurement Results)

The MEAR command retrieves the Pass/Fail results of the last measurement executed with the [MEAS](<02.06.02.02.160_MEAS_-__execute_a_MEASurement_set.md>) command or the MEAS sequencer instruction and stores them in a cache. In addition, MEAR can perform a sequence of value measurements. The number of samples can be defined by the user. MEAR then also stores the average of all these samples in the cache. This is done for all active sites in parallel. The content of the cache can be retrieved with [PMUR?](<02.06.02.02.179_PMUR___retrieve_PPMU_result.md>).

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Syntax

```
MEAR{type}, [no_of_samples], {(pinlist)}
```

## Parameters

 |

type

 |

Data type to be measured. The following specifiers can be set:

VMUM: Per pin parallel value retrieval from PPMU measurement (successive approximation).

VAL: Per pin value measurement with BADC.

PF: Per pin pass fail result.

GPF: Global pass fail result.

 |
 |

no_of_samples

 |

Determines the number of samples that are taken if the type parameter is set to VAL. For the other types, it is ignored. The default is 1.

 |
 |

pinlist

 |

Target pin or pins to be measured

 |

## Application

See [DC Measurement Commands](<02.06.10_DC_Measurement_Commands.md>), which introduces the firmware commands for DC test.

## Example

```
> PSFC ALL
> MEAR VAL,35,(p1,p2)
> PQFC 1
> PMUR? VAL,(p1,p2)
< PMUR P,,2,(p1)
< PMUR F,-2100,,(p2)
> PQFC 2
> PMUR? VAL,(p1,p2)
< PMUR P,,2.3,(p1)
< PMUR F,-2200,,(p2)
```

This example triggers a value measurement with 35 samples for p1 and p2 on all sites. It then retrieves the average of the samples for every pin separately for each site with PMUR?.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.0.1: New type parameter: VMUM
