# DGCT? - (DiGital Capture Test)

The DGCT? query executes the current start pattern if it is configured for digital capture. The pattern must be a main pattern. The execution comprises three steps: First, DGCT? activates digital capturing. Then, it performs a standard functional test. Finally, it deactivates digital capturing again.

## Syntax

```
DGCT? ["exec_context"]
```

returns:

```
DGCT {result_flag}
```

## Parameters

 |

exec_context

 |

An execution context. For more information on execution contexts see [Using execution contexts](<02.06.07.01.08.05.03.02.03_Using_execution_contexts.md>) .

 |
 |

result_flag

 |

The result returned by DGCT?.

P (for Pass) is returned if received and expected data match.

F (for Fail) is returned if received and expected data do not match.

Note that the result flag refers to the functional test, and does not say anything about the success of the digital capture. Rather, when the functional test returns P, this may imply that something went wrong with digital capture. Thus, if the received values are compared against 0, which is recommended, P can indicate that no data was captured.

 |

## Application

This command performs hardware activation and clean-up on pins configured for digital capture.

## Errors

An error is generated if:

- If there is insuffcient channel memory to store error map / digital capture result in the extended error map (RAM).

## Example

```
> DGCT?
< DGCT F
```

## Functional changes

- Introduced before SmarTest 6.3.2
