# BSVE - (Bulk Set Value Evaluation)

The BSVE command recalculates the equation system with the values of a specified spec value set. Prior to this, it checks if the variables that are assigned a value in the spec value set are actually declared in the equation set that is associated with the specification of the spec value set. For more information on spec value sets see [Changing the runtime values of base variables](<02.06.06.01.05.02_Changing_the_runtime_values_of_base_variables.md>).

## Predependencies

The spec value set must have been defined with the [DSVS](<02.06.02.02.92_DSVS__DSVS__-__Define_Spec_Value_Set.md>) command, and the values must have been assigned with the [BSVR](<02.06.02.02.12_BSVR__BSVR___Bulk_Set_Value_at_Runtime.md>) command.

## Syntax

```
BSVE {spec_value_set_no}
```

## Parameters

 |

spec_value_set_no

 |

Number of a spec value set.

 |

## Errors

An error is generated if:

- The spec value set number does not exist.
- A variable specified in the spec value set is not declared in the equation set of the specification.

## Example

```
> BSVE 11
```

## Functional changes

- Introduced in SmarTest 6.5.3
