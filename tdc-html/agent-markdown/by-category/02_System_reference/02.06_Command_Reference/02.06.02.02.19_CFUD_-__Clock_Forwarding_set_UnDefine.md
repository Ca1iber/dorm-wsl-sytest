# CFUD - (Clock Forwarding set UnDefine)

CFUD deletes a clock forwarding set.

## Syntax

```
CFUD {"cf_set_name"}
```

## Parameters

 |

cf_set_name

 |

Specifies the name of an existing clock forwarding set.

 |
 |

ALL

 |

Remove all existing transition tests sets

 |

## Application

Protocol engine test.

## Errors

An error is generated if no clock forwarding set with this name exists.

## Example

```
> CFUD   "cf_set1"
```

## Functional changes

- Introduced in SmarTest 7.0.1
