# UDRS - (UnDefine Routing Set)

The UDRS (UnDefine Routing Set) command deletes the specified routing set.

## Syntax

```
UDRS {set}
```

## Parameters

 |

set

 |

An identification number of the routing set. This is an integer from 1 to the maximum number defined by the [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) command.

If the ALL specifier is specified, the command deletes all routing sets.

 |

## Application

Routing setup, see [Routing Setup Commands](<02.06.04_Routing_Setup_Commands.md>).

## Errors

An error occurs if the specified set number exceeds the maximum number defined by the [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) command.

## Example

```
UDRS ALL
```

## Functional changes
