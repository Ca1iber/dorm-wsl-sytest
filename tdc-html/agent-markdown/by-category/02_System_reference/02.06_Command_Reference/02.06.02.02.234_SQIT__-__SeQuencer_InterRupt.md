# SQIT? - (SeQuencer InterRupt)

The SQIT? query returns interrupt information about the last executed test.

## SQIT?

```
SQIT? ["context"]
```

returns:

```
SQIT {NO}
```

or

```
SQIT {BANDWIDTH|TIMEOUT|OTHER}, {(pinlist)}
```

## Parameters

 |

context

 |

The name of an execution context. For more information on execution contexts see [Using execution contexts](<02.06.07.01.08.05.03.02.03_Using_execution_contexts.md>).

 |
 |

NO

 |

No interrupt occurred during execution of the last test.

 |
 |

BANDWIDTH

 |

An interrupt occurred due to a bandwidth error.

 |
 |

TIMEOUT

 |

An interrupt occurred due to a timeout error.

 |
 |

OTHER

 |

An interrupt occurred due to an error that was neither a bandwidth nor a timeout error..

 |
 |

pinlist

 |

The pins on which the specified interrupt was observed.

 |

## Example

```
> SQSL "test1"
> SQST RUN
> SQIT?
< SQIT TIMEOUT, (pin1)
```

In this example, a timeout was observed on `pin1`.

## Functional changes

- Introduced in SmarTest 7.0.1
- SmarTest 7.2.0: Context parameter was added.
