# TTRS? - (Time TRansition Search)

The TTRS? (Time TRansition Search) query executes a global search test function. The command initiates a linear, linear/binary, or a binary search within the defined start and stop parameters. The start and stop values that you specify must be between the minimum and maximum edge delay values.

You must set the step width for the linear search with [ESGB, ESGB? - (Edge Search GloBal)](<02.06.02.02.116_ESGB__ESGB__-__Edge_Search_GloBal.md>).

The edge used for the search is selected with [EDSP, EDSP? - (EDge SPecification)](<02.06.02.02.102_EDSP__EDSP__-__EDge_SPecification.md>) and must meet the following conditions:

- The primary timing set and waveform set must already be defined.
- During the search, the measuring edge must at no time exceed a distance of one period from other edges with the same direction.
- During the search, the order of the measuring edge, relative to other edges with the same direction, must remain as defined by the nominal setting in the primary timing set and the primary waveform set.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Syntax

```
TTRS? {start}, {stop}, {search_type}, {(pinlist)}
```

returns:

```
TTRS {value_specifier}, [pass_value], [fail_value], {(pinlist)}
```

## Parameters

 |

start

 |

The start parameter defines the point in time (in ns), relative to the start of the cycle, where you want the search to begin.

 |
 |

stop

 |

The stop parameter defines the point in time (in ns), relative to the start of the cycle, where you want the search to end.

 |
 |

search_type

 |

The search type is one of the following:

 |
 |

L

 |

Specifies a linear search from the start of the window, at intervals defined by the ESGB command. The search will terminate after the first failed test or after the search limit specified by the stop parameter has been reached.

 |
 |

LB

 |

Specifies a combined linear and binary search using the step width defined by the ESGB command. A linear search is performed, with an additional binary search carried out in the interval between the last passed and the first failed test.

 |
 |

B

 |

Specifies a binary search carried out between the start and the stop positions.

 |
 |

pinlist

 |

The name of the pin or pins on which the search is to take place. This parameter may also include groups previously created using [DFGP, DFGP? - (DeFine GrouP)](<02.06.02.02.60_DFGP__DFGP__-__DeFine_GrouP.md>). If more than one pin is to be included, the names must be separated with a comma. Pinlist must only contain pins configured as outputs.

 |
 |

value_

specifier

 |

This parameter can be:

 |
 |

LT

 |

(less than) is returned if the first functional test of a search in the positive direction failed.

 |
 |

LE

 |

(less than or equal to) is returned if all the functional tests performed between start and stop pass. LE is only returned for a search in the negative direction.

 |
 |

EQ

 |

(equal to) is returned if the first failure of the search occurs between the start and the stop positions.

 |
 |

GE

 |

(greater than or equal to) is returned if all the tests carried out between start and stop pass. GE can only be returned for a search in the positive direction.

 |
 |

GT

 |

(greater than) is returned if the first functional test performed during a search in the negative direction fails.

 |
 |

pass_value

 |

The pass_value is the time (in ns) at which the last passed test occurs. A pass value is only returned for if value_specifier is EQ, LE, or GE.

 |
 |

fail_value

 |

The fail_value is the time (in ns) at which the last failed test occurs. A fail value is only returned for if value_specifier is EQ, LT, or GT.

 |

## Application

AC tests.

## Errors

An error is generated if:

- You remove the DUT board while the test system is in the connected state. To correct the error condition, replace the DUT board and click the "Disconnect" button followed by the "Connect" button.
- Not all pins in the pin list have the same period programmed.
- The edges selected with [EDSP, EDSP? - (EDge SPecification)](<02.06.02.02.102_EDSP__EDSP__-__EDge_SPecification.md>) are not consistent. Edges are consistent if, for all pins in the pin list, they use the same:

  - Edge number
  - Edge type
  - Edge direction

## Example

```
TTRS? 10,80,L,(Q0)
TTRS EQ,70,80,(Q0)
```

This example executes a global search test on pin Q0. A linear sweep takes place between 10 ns and 80 ns relative to the start of the period. The system returned a pass at 70 ns and a fail at 80 ns.
