# LTDE, LTDE? - (Load Test Data Entity)

The LTDE command lets you load a test data entity (TDE) for accessing the protocols it contains. The LTDE? query returns TDEs that have been loaded.

LTDE? returns the TDEs that have been loaded from the path specified with the [PTDE](<02.06.02.02.200_PTDE__PTDE__-__Path_for_Test_Data_Entities.md>) command.

## LTDE

```
LTDE "<tde_name>"
```

## LTDE?

```
LTDE?
```

## Parameters

 |

tde_name

 |

The name of the protocol test data entity (TDE) file. This is the file name including the extension that specifies the type of the TDE.

The file must be located at the path specified with the [PTDE](<02.06.02.02.200_PTDE__PTDE__-__Path_for_Test_Data_Entities.md>) command.

 |

## Example

```
LTDE "test.prot_asg"
LTDE?
```
