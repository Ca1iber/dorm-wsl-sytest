# UPTI, UPTI? - (Utility Purpose settling TIme)

The UPTI command sets the settling time for one or more utility purposes, that is used as the wait time from when the utility line states are changed until the next command is executed.

Actually, the settling time defined with this command is used in the following cases:

- When the [WSDN](<02.06.02.02.341_WSDN_-__Wait_Setup_DoNe.md>) command is excuted after the settings of the utility lines have been activated with the [FLSH](<02.06.02.02.124_FLSH_-__FLuSH_buffered_commands.md>) command.

The settings of utility lines in the specified utility purposes are activated in parallel and the specified settling time is used for all utility lines in the utility purposes. The default value of the settling time is 0 ms.

If different settling time values are set for a utility line by both the [UTTI](<02.06.02.02.314_UTTI__UTTI__-__UTility_line_settling_TIme.md>) and UPTI commands, the longest settling time is used.

## UPTI

```
UPTI {time}, {(purpose_name)}
```

## UPTI?

```
UPTI? {(purpose_name)}
```

returns:

```
UPTI {time}, {(purpose_name)}
```

## Parameters

 | time |

Specifies the wait time to change the utility line status using the [UPST](<02.06.02.02.305_UPST__UPST__-__Utility_Purpose_STate.md>) and [FLSH](<02.06.02.02.124_FLSH_-__FLuSH_buffered_commands.md>) commands (in ms).

0 ... 2鈥?47鈥?83.646 [ms]

 |
 | purpose_name |

Specifies the utility purpose name or names for which the settling time is to be set.

The symbol @ is used for all utility purposes.

If more than one name is required, the names must be separated with a comma.

 |

## Application

For details about utility purposes, see [Configuration Setup Commands](<02.06.03_Pin_configuration_setup_commands.md>).

## Errors

An error is generated if:

- The settling time is lower than zero or out of range.
- The referenced utility purpose has not been defined before.

## Example

```
UPTI 2.5,(AWG_CNCT)
```

This example sets the settling time of the utility purpose "AWG_CNCT" to 2.5 ms.
