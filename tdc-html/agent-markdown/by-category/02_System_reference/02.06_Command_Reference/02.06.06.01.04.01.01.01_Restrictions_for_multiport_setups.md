# Restrictions for multiport setups

The period definitions for the individual ports of a multi-port setup are largely independent of each other.

On a Smart Scale system, every port has its own period resolution (see [Period resolution for a multi-port setup (Smart Scale)](<02.06.06.01.04.01.02.04_Period_resolution_for_a_multi-port_setup__Smart_Scale.md>)). However, the following restrictions apply:

- You cannot define pin specific periods in a multi-port setup. That is, you cannot connect an equation set containing a period specification for a single pin to a port in a multi-port specification.
- You cannot use the [PCLK](<02.06.02.02.175_PCLK__PCLK__-__Pin_CLocK.md>) command to change the period within a multi-port specification. The [PCLK?](<02.06.02.02.175_PCLK__PCLK__-__Pin_CLocK.md>) query can be used.

## Functional changes

- Introduced before SmarTest 6.3.2
