# PRLT? - (request Parallel ResuLTs)

The PRLT? query returns the global pass/fail results of the last executed test for the specified sites in parallel. You can use this command to find out the global results of all sites (not only the one that has the query focus) in one step.

The global result for the site with the query focus is also given by FTST?.

Note

Pass/fail results that are retrieved by command [PRLT](<02.06.02.02.183_PRLT__-__request_Parallel_ResuLTs.md>) are invalidated by commands [CSAS](<02.06.02.02.33_CSAS__-__Channel_Slot_Accumulated_Status.md>) and [PSAS](<02.06.02.02.188_PSAS__-__Power_Supply_Accumulated_Status.md>).

We recommend therefore using the command PRLT directly after the related functional test and before command CSAS or PSAS are performed.

This behavior applies not only to the commands but also to the related APIs: Function [GET_FUNCTIONAL_RESULT()](<../02.07_Test_Method_Reference/02.07.04.01.88_GET_FUNCTIONAL_RESULT.md>) must be performed before any of the [DPS_AUX_PIN_TASK.check...()](<../02.07_Test_Method_Reference/02.07.04.01.43.01_DPS_AUX_PIN_TASK.md>) functions is called or the results of GET_FUNCTIONAL_RESULT() are invalid.

## Syntax

```
PRLT? ["exec_context",] {site}
```

returns:

```
PRLT {site}, {"result"}
```

## Parameters

 | exec_context  | An execution context. For more information on execution contexts see [Using execution contexts](<02.06.07.01.08.05.03.02.03_Using_execution_contexts.md>). |
 | site  | The site parameter is number A single integer representing the site number. ALL Means that all the results of all configured sites are returned. |
 | result  | The result parameter is a string containing one character for every site. The nth character stands for site n. Possible characters are: P If the last test passed on all pins. F If the last test failed at any pin. 0 If the site was masked during the last test. |

## Application

Test Results, see [Test Result Commands](<02.06.11_Test_Result_Commands.md>).

## Example

```
PRLT? ALL
```

returns:

```
PRLT ALL, "PF0"
```

In this example, site 1 passed the last test, site 2 failed it, and site 3 was masked during the test.

## Functional changes

- Introduced before SmarTest 6.3.2
