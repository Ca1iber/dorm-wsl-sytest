# PFND? - (Pin FiND)

The PFND? (Pin FiND) query returns the port or ports that contain the pin specified in the query, or the second pin in a pair of differential pins.

## Syntax

```
PFND? [group_type,] {(pin)}
```

returns:

```
PFND {group_type}, {(list)}, {(pin)}
```

## Parameters

 |

group_type

 |

The group type can be PRT (for "port") or DIFF (for "differential pair"). PRT is the default.

 |
 |

pin

 |

The name of the pin about which information is to be retrieved.

 |
 |

list

 |

List of the ports that contain the pin, or the differential pair to which the specified pin belongs.

 |

## Application

Pin configuration, see [Configuration Setup Commands](<02.06.03_Pin_configuration_setup_commands.md>).

## Example

```
> PFND? (I/O1_1)
< PFND PRT,(port_1,port_1.CP_1),(I/O1_1)
> PFND? DIFF,(P+)
< PFND DIFF,(P+,P-),(P+)
```
