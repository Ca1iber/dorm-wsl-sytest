# CTXT, CTXT? - (ConTeXT)

The CTXT (ConTeXT) command defines or deletes the name of a mode context. A mode context sets a type (I, O, or IO) and a mode (std or fast) for every configured pin. Use the CONF command to define these attributes for the individual pins.

The CTXT? query returns the context names that are currently defined.

## Mode of operation

When you define a new mode context, it is created as a copy of the actual DEFAULT context. You can change this default configuration with the CONF command.

## CTXT

```
CTXT {action},{"name"}
```

## CTXT?

```
CTXT?ALL
```

returns:

```
CTXT {DEFINE},{"name"}
```

## Parameters

 |

action

 |

Specifies the action. Possible values are:

 |
 |

DEFINE

 |

Defines a new mode context

 |
 |

DELETE

 |

Deletes a mode context

 |
 |

ALL

 |

Displays all existing mode contexts (only in the query).

 |
 |

name

 |

The name of the mode context. If the action parameter is set to DELETE, you can also specify ALL to delete all mode contexts.

 |

## Example

```
> CTXT? ALL
< CTXT DEFINE,"DEFAULT"
< CTXT DEFINE,"differential"
< CTXT DEFINE,"PdrvNPrcv"
```
