# Defining a utility line

A utility line channel is associated with a pin name and an operation mode by the [DFUT](<02.06.02.02.70_DFUT__DFUT__-__DeFine_UTility_line.md>) command. The pin name is the name by which the software identifies the utility line channel. Utility line channels are identified by a three-digit number. The first digit (1-8) specifies the utility line block. The second and third digits (01-16) specify the channel number of the utility line.

 Note In the header row of the Utility Line view, SmarTest shows the channel numbers of the utility lines, using the range [01 …nbsp;32] from right to left. The utility line itself are numbered with an offset of -1 in the range [00 …nbsp;31] that corresponds to the scheme "URW##" of the "Utility pogo pin layouts" in the "DUT Board Design Guidelines". For detailed description about utility pogo blocks, see [Utility line assignments](<../02.03_DUT_board_design_reference/02.03.04.01_Utility_line_assignments.md>).

The [DFUT?](<02.06.02.02.70_DFUT__DFUT__-__DeFine_UTility_line.md>) query lists the channel number and operation mode of the specified names.

The [UDUT](<02.06.02.02.302_UDUT_-__UnDefine_UTility_line.md>) command removes a utility line.

You can identify a named utility line by its name to the [UTST](<02.06.02.02.313_UTST__UTST__-__UTility_line_STate.md>) command which serves to set the output state of the line. Instead of setting the state of one utility line with [UTST](<02.06.02.02.313_UTST__UTST__-__UTility_line_STate.md>), you can also define a utility purpose with [DFUP](<02.06.02.02.69_DFUP__DFUP__-__DeFine_Utility_Purpose.md>), which allows you to set the state of a group of utility lines with one statement. For more information see [Defining a utility purpose](<02.06.03.01.08_Defining_a_utility_purpose.md>) and [Accessing Utility Lines](<02.06.12.01_Accessing_Utility_Lines.md>).

## Related firmware commands

You can use the UTTI command to set a settling time that is used as the wait time for the [WSDN](<02.06.02.02.341_WSDN_-__Wait_Setup_DoNe.md>) command. All utility lines that are set with [UTST](<02.06.02.02.313_UTST__UTST__-__UTility_line_STate.md>) or UPST will be switched in parallel when the [FLSH](<02.06.02.02.124_FLSH_-__FLuSH_buffered_commands.md>) command is performed. If the [WSDN](<02.06.02.02.341_WSDN_-__Wait_Setup_DoNe.md>) command is used immediately after [FLSH](<02.06.02.02.124_FLSH_-__FLuSH_buffered_commands.md>), the time span during which execution will pause equals the longest settling time that is defined for any of the switched utility lines (with UTTI) or purposes (with UPTI).
