# RVVA - (Remove Vector VAriable)

The RVVA(Remove Vector VAriable) command deletes a specified vector variable or all vector variables that are associated with the vector labels of one or more ports.

## Syntax

RVVA {"name"|ALL}[, (portlist)]

## Parameters

 |

name

 |

Name of the vector variable to be deleted. ALL can be used to remove all vector variables that are associated with the vector labels of one or more ports.

 |
 |

portlist

 |

This parameter is evaluated according to the following rules:

- If a vector variable is specified for name, the parameter is ignored.
- If you set name to ALL and specify a port list, all vector variables will be deleted that are associated with the vector labels of these ports.
- If you set name to ALL and do not specify a port list, all vector variables will be deleted that are associated with the vector labels of the default port.
- If you set name to ALL and specify @@, all vector variables of all ports will be deleted.
 |

## Application

Digital capture applications.

## Errors

An error occurs if the referenced vector variable has not yet been defined.

## Example

```
> DVVA? ALL,(@@)
< DVVA "vec_3",DIGCAPT,"port1_A",PARA,,,,0,1,1,0,
       1,0,(Q7_1)
< DVVA "vec_1",DIGCAPT,"port2_A",PARA,,,,0,1,1,0,
       1,0,(I/O5_2)
< DVVA "vec_2",DIGCAPT,"port2_B",PARA,,,,0,1,1,0,
       1,0,(I/O7_2,I/O6_2)
> RVVA ALL,(port_2)
> DVVA? ALL,(@@)
< DVVA "vec_3",DIGCAPT,"port1_A",PARA,,,,0,1,1,0,
       1,0,(Q7_1)
```

This example removes all vector variables that are defined for vector labels associated with port port_2.

## Functional changes

- Introduced before SmarTest 6.3.2
