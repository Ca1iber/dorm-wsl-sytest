# GETL? - (GET Label)

If the last test was executed with the overview Error Map in LMAP mode, which implies that the start label was a (single-port or multi-port) burst, then the GETL? query returns the label names for a range of label calls within this burst. If the last test was not executed in LMAP mode GETL? issues an error message.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Syntax

```
GETL? {index_first_call},[number_of_calls], {(pin_or_port)}
```

returns:

```
GETL {index_of_call},{label_name}, [start_cycle], [number_of_cycles], {(pin_or_port)}
```

## Parameters

 |

index_first_call

 |

Specifies the index of the first label call within the burst for which the name is requested.

 |
 |

number_of_calls

 |

The number of label calls for which the name is requested.

 |
 |

index_of_call

 |

This reply parameter specifies the index of the call for which the label name is returned.

 |
 |

label_name

 |

This reply parameter specifies the name of the label that was called at the position index_of_call.

 |
 |

start_cycle

 |

This reply parameter specifies the start cycle of the label within the burst. It is omitted if reconstruction of the label is not possible.

 |
 |

number_of_cycles

 |

This reply parameter specifies the number of cycles of the label. It is omitted if reconstruction of the label is not possible.

 |
 |

pin_or_port

 |

Specifies the pin or port for which label information is requested.

 |

## Example

```
> GETL? 0,9,(@)
< GETL 0,"MainInit",0,16,(@)
< GETL 1,"MainFailures",16,24,(@)
< GETL 2,"MainPassing",40,24,(@)
< GETL 3,"MainFailures",64,24,(@)
< GETL 4,"MainPassing",88,24,(@)
< GETL 5,"MainFailures",112,24,(@)
< GETL 6,"MainPassing",136,24,(@)
< GETL 7,"MainFailures",160,24,(@)
< GETL 8,"MainDataFail",184,24,(@)
```

In this example, the label names are requested for the first 9 calls of the burst that was executed as the last test. Note that certain labels are called more than once.

## Functional changes

- Introduced before SmarTest 6.3.2
