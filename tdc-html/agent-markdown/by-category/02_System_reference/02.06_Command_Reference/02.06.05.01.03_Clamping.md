# Clamping

Clamping is used to smooth the output signal of the device. Peaks generated by reflections of the signal can be limited by specific voltage levels (vch = voltage clamp high; vcl = voltage clamp low).

The functional integration of the clamps varies on the various channel card models.

On Pin Scale 1600 channel cards, the clamps are integrated into the driver.

Another difference in the functionality of the channel cards to be considered is the clamp mode setting. The clamp mode setting determines whether or not the clamp voltage is active. See the table below.
