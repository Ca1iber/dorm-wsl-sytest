# RRSC - (Result Retention area Select for Capture)

Selects the result retention areas for capturing results of following test. These areas must have been defined with RRDF. Recording non-(digital capture), that is, error map results requires [DCRT](<02.06.02.02.49_DCRT__DCRT__-__Digital_Compare_Result_Target.md>) to be configured for RAM.

## Syntax

RRSC {area-id} | OFF

## Parameters

 |

area-id

 |

A unique string identifying a specific result retention area.

 |
 |

OFF

 |

Enumerated parameter to switch back to normal result acquisition.

Using OFF will return result acquisition to non-reserved memory or internal error map (as specified by DCRT).

   | Note The RRDF pin list must match the capture pins for a capture test. An error map test requires that all pins of the selected port (recording to RAM via DCRT) are included.

## Application

Result area management for hidden digital upload.
