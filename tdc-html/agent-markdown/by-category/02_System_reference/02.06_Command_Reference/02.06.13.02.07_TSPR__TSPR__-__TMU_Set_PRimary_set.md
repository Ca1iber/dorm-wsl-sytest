# TSPR, TSPR? - (TMU Set PRimary set)

TSPR defines the primary TMU set. This is the set that will actually be used for testing. You can also undefine the primary TMU set by specifying the empty string. TSPR? returns the current primary set.

## TSPR

```
TSPR {"TMU_set_name"|""}
```

## TSPR?

```
TSPR?
```

returns:

```
TSPR {"TMU_set_name"|""}
```

## Parameters

 |

TMU_set_name

 |

Specifies the name of an existing TMU set.

 |
 |

""

 |

By specifying the empty name, you undefine the current primary TMU set.

 |

## Application

TMU per pin measurements.

## Errors

An error is generated if no TMU set with this name exists.

## Example

```
> TSPR   "TMU_set1"
```

## Functional changes

- Introduced in SmarTest 7.1.0
