# Length

To query the number of elements, or the lists' size, the syntax is:

DDEF? "ListName","Length"

## Example

1. If list A is defined as

```
DDEF "A",SET,"Equation","Loop(1,10,10)"
```

then `DDEF? "A","Length"` will return:

```
DDEF "A",DATA,"Length",10
```

2. If list A is defined as:

```
DDEF "A",SET,"Equation","RepeatValue(0x55555555,10)"
```

then `DDEF? "A","Length"` will return

```
DDEF "A",DATA,"Length",10
```

## Functional changes

- Introduced before SmarTest 6.3.2
