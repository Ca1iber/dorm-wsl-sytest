# Main programs and subroutines

#### Subtopics

- [Main labels](<02.06.07.01.08.05.01_Main_labels.md>)
- [SVEC subroutines](<02.06.07.01.08.05.02_SVEC_subroutines.md>)
- [Burst labels and multi-port burst labels](<02.06.07.01.08.05.03_Burst_labels_and_multi-port_burst_labels.md>)

Every label is associated by the SQLB command with a type. The type determines whether a label can be called directly (can serve as the start label that is specified with the SQSL command), or whether it must be called from within another label. It can also define the function of the label. The possible label types are MAIN, SVEC, BRST, MPBU.

## Functional changes

- Introduced before SmarTest 6.3.2
