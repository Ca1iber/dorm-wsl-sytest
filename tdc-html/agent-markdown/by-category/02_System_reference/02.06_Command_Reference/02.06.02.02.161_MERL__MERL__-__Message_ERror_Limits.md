# MERL, MERL? - (Message ERror Limits)

The MERL command sets the CKST and EQFS detailed message and error message limits.

The MERL? query returns the CKST and EQFS detailed message and error message limits.

The messages too many E R R O R S ... or Too m a n y messages are output in the ui_report window if the set error message or detailed message limit is exceeded.

## MERL

```
MERL [error_limit], [message_limit]
```

## MERL?

```
MERL?
```

returns:

```
MERL [error_limit], [message_limit]
```

## Parameters

 | error_limit |

The maximum number of errors that will be logged. An integer in the range 1 to 30000.

Default value is 10.

 |
 | message_limit |

The maximum number of messages that will be logged. An integer in the range 1 to 30000.

Default value is 40.

 |

## Application

Download of timing and level equations.

## Example

MERL 30,30

This example sets both the error and the message limits to 30.

## Functional changes

- Introduced before SmarTest 6.3.2
