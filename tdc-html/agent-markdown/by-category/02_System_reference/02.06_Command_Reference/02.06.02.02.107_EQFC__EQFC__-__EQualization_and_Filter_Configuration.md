# EQFC, EQFC? - (EQualization and Filter Configuration)

Use the EQFC command to configure the equalization and the low pass filter parameters.

The level set supports additional properties whereby filter time constants (risetime) and the relative swing offsets can be specified on a per pin base. The values can be specified using [Equation based level setup](<../02.08_Setup_and_Result_Tools/02.08.04.14.02_Equation_based_level_setup.md>) or by using the firmware command EQFC.

 Note This command only applies to PS1600 and PS5000 because the equalization feature is not supported on any other cards.

## EQFC

```
EQFC {level_set_no|level_set_id|ALL|PRM} ,{filter_parameter|ALL_specifier}, {offset_value|filter_value}, {(pinList)}
```

## EQFC?

```
EQFC? {level_set_no|level_set_id|ALL|PRM} ,{filter_parameter|ALL_specifier|ALL}, {value}, {(pinList)}
```

## Application

This command applies to the Level Setup applications.

## Errors

An error is generated in case of one or more of the following cases.

- The level set number is out of range.
- The specified filter or equalization offset value is out of range.

The filter values are silently clipped if they are in range but could not be set. An error is generated if the value is outside the range defined in the specification.

- One of the specified pins does not have the respective capabilities.

## Example

```
EQFC 1, LPFI, 0.080, (@)
EQFC 1, EQI1, 75.5, (pin1,pin2)
```

```
EQFC? 1, ALL, (pin1,pin2)
```

```
EQFC 1, EQI1, 75.5,(pin1,pin2)
EQFC 1, EQI2, 0,(pin1,pin2)
EQFC 1, EQI3, 0,(pin1,pin2)
EQFC 1, EQO1, 0,(pin1,pin2)
EQFC 1, EQO2, 0,(pin1,pin2)
EQFC 1, EQO3, 0,(pin1,pin2)
EQFC 1, LPFI, 0,(pin1,pin2)
EQFC 1, LPFO, 0.080,(pin1,pin2)
```
