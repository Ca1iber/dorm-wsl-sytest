# RVVC - (Remove Vector Variable Configuration)

The RVVC (Remove Vector Variable Configuration) command removes the vector variable configuration (VVC).

## Syntax

```
RVVC {VVC name}
```

## Parameters

 |

VVC name

 |

Name of the vector variable configuration to be removed.

 |

## Application

Digital source memory applications.

## Errors

An error will be generated if you try to remove the VVC and there is a usage defined for it.

## Functional changes

- Introduced before SmarTest 6.3.2
