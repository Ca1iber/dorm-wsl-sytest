# TSUD - (TMU Set UnDefine)

TSUD deletes a TMU set.

## Syntax

```
TSUD {"TMU_set_name"|ALL}
```

## Parameters

 |

TMU_set_name

 |

Specifies the name of an existing TMU set.

 |
 |

ALL

 |

This option removes all defined TMU sets.

 |

## Application

Jitter test.

## Errors

An error is generated if no TMU set with this name exists.

## Example

```
> TSUD   "TMU_set1"
```

## Functional changes

- Introduced in SmarTest 7.1.0
