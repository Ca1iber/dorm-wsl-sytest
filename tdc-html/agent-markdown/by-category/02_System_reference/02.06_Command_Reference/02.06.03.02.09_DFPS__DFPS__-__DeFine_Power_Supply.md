# DFPS, DFPS? - (DeFine Power Supply)

The DFPS (DeFine Power Supply) command tells the software which DPS channel is connected to the specified device pin, and the polarity of the channel. The DFPS? query returns the existing channel, polarity and assigned pin number.

The DFPS command can also be used to configure one or more DC Scale channels for DPS mode.

Ganged configurations for DC Scale channels in DPS mode are defined with the DFPS command (by specifying a channel list for the first parameter, see below).

Multi-site configurations are defined by the [PALS](<02.06.02.02.173_PALS__PALS__-__Pin_ALlocation_for_multiple_Sites.md>) and [PSTE](<02.06.02.02.199_PSTE__PSTE__-__Parallel_SiTe_Enable.md>) commands.

## DFPS

```
DFPS {dps_channel|(DC_scale_channel_list)}, {polarity}, {(pin)}
```

## DFPS?

```
DFPS? {(pinlist)}
```

returns:

```
DFPS {dps_channel|(DC_scale_channel_list)}, {polarity}, {(pin)}
```

## Parameters

 |

dps_channel

 |

The test system channel number of the DPS channel to be configured.

The channel is to be defined as follows:

- For [external device power supplies](<../02.05_Test_Head_Cards/02.05.06_External_device_power_supply__external_GPIB_DPS.md>), this is a three‑digit or four‑digit integer.

The first one or two digits define an external supply. To avoid a conflict with the internal supplies, we recommend using values above 8. The maximum supported value is 16.

The last two digits define the channel number of the DPS. If the channel number is less than 10, a leading "0" must be used.

-

For DC Scale channels (in DPS mode) this is a five digit number in the same format as for digital I/O channels.

 |
 |

DC_scale_channel_list

 |

To gang DC Scale channels, you must specify a consecutive number of channels enclosed by parentheses, either as comma separated list or as range, for example 10105-10106.

- DPS128/64: Ganging is possible for any number of successive channels within a card, but not across cards.

DPS128/DPS64 channels must be of the same type (HC or HV).

The maximum number of ganging groups per DPS128/64 is half the number of channels. The maximum current per card cannot be exceeded.

- XPS256: Only channels on the same HLA can be ganged.
- UHC4, UHC4T: For UHC4 or UHC4T ganging is possible for any number of successive channels within a card and any number of cards within a test head. The combination of UHC4 and UHC4T within the same ganging group is not supported. The maximum current per card cannot be exceeded.

Before cross-card ganging can be used, the connection must be enabled by command [DDIC](<02.06.02.02.54_DDIC__DDIC__-__Define_DUT_Interface_Connection.md>).

 |
 |

polarity

 |

Gives the polarity of the DPS which has to be applied to the selected channel.

 |
 |

POS

 |

Enter POS only if the DPS connections on the DUT board are as follows: The force is connected to power; the sink is connected to ground. The voltage supplied to the device will then be exactly as entered in the Level Setup, but the entry made there must be positive, otherwise the system returns an error.

For DC scale channels, only POS is allowed.

 |
 |

NEG

 |

NEG is not allowed for DC Scale channels.

 |
 |

pin

 |

Defines the pin name for the DPS channel.

 |
 |

pinlist

 |

The pin name or names of those power supply outputs which have already been defined. If more than one pin is required, the names must be separated with a comma. The @ character can be used to read all configured power supply pins.

 |

## Application

Configuration Setup, see [Configuration Setup Commands](<02.06.03_Pin_configuration_setup_commands.md>).

## Errors

An error is generated if:

-  You define more than the number of installed DPS pins.
-  The requested DPS channel has already been allocated.
-  The requested DPS channel is not installed.
-  The addressed DPS is not installed.
-  The requested DPS channel number is not valid.
-  The requested DPS pin has already been defined.
-  You try to assign DPS channels in the connected state.

## Examples

### Example 1

```
DFPS 11,POS,(Vee)
```

This example connects device pin Vee to channel 1 of DPS board 1. The DPS output polarity is positive.

### Example 2

 |

```
DFPS (10101, 10102),POS,(vee)
```

 |
 |

```
DFPS (10101-10102),POS,(vee)
```

 |

Both lines define the same master/slave configuration for DC Scale channels in DPS mode. They just use different notations. Note the five digit channel numbers.

### Example 3

```
DDIC CONN, (104GO, 105GI)
DFPS (10403, 10404, 10501, 10502),POS,(vee)
```

This example defines a master/slave configuration for DC Scale UHC4 channels in DPS mode across two boards.

### Example 4

```
DDIC CONN, (104GO, 105GI, 105GO, 106GI)
DFPS (10403, 10404, 10502, 10503, 10504, 10601),POS,(vee)
```

This example defines a master/slave configuration for DC Scale UHC4 channels in DPS mode across three boards.

### Example 5

```
DDIC CONN,(230GO, 227GI)
DFPS (23004, 22701),POS,(VDDCI)
```

This example specifies the ganging of channels across two DC Scale UHC4 cards.
