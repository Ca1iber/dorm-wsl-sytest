# DLTS - (DeLete TeSt)

The DLTS (DeLete TeSt) command deletes the label referenced by label. The command lines in question are removed from the sequencer area.

## Syntax

```
DLTS {"label"}[, (port)]
```

## Parameters

 |

label

 |

Specifies the label to be deleted.

 |
 |

port

 |

This parameter is only relevant for multi-port burst labels. If you call DLTS with a multi-port burst label and you do not specify a port, the label is deleted for all ports. If you specify a port, the label is only deleted for this port.

 |

## Application

Edit command in Pattern Tool.

## Errors

An error is generated if:

- The specified label does not exist.
- There is insufficient channel memory.
- There is insufficient disk space (offline operation only).

## Example

```
DLTS "MPBU_port_1_port_2",(port_1)
```

This example deletes the label referenced by `MPBU_port_1_port_2` from the port `port_1`.
