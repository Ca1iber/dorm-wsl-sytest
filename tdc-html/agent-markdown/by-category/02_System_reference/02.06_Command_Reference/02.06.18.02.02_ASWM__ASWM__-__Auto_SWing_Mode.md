# ASWM, ASWM? - (Auto SWing Mode)

The ASWM (Auto SWing Mode) command allows you to set a specific automatic swing mode.

If you perform a spec search in a user procedure it is recommended to use the ASWM command to restore the original state after completion of the search.

## ASWM

```
ASWM {command}, {mode}
```

## ASWM?

```
ASWM?
```

returns:

```
ASWM {command}, {mode}
```

## Parameters

 |

command

 |

This parameter is used to set the specified mode:

 |
 |

SET

 |

Sets the mode specified regardless of the previous mode.

 |
 |

MIN

 |

Sets the 'minimum' mode of either the mode specified or the previous mode. Minimum refers to minimum time consumption.

The following order applies:

FREEZE, SEARCH, AUTO. For example, SEARCH is the minimum mode of the two modes SEARCH and AUTO.

 |
 |

MAX

 |

Sets the 'maximum' mode of either the mode specified or the previous mode. Maximum refers to maximum time consumption.

The following order applies:

AUTO, SEARCH, FREEZE. For example, SEARCH is the maximum mode of the two modes SEARCH and FREEZE.

 |
 |

mode

 |

The mode can take one of the following values:

 |
 |

AUTO

 |

Automatic level swing adjustment is done for all waveform sets. Any change of waveforms or levels triggers an automatic swing adjustment.

 |
 |

FREEZE

 |

No swing adjustment is performed. The actual swing adjustment settings are used. As soon as primary sets change, the mode is switched back to AUTO.

 |
 |

 |

## Application

Swing adjustment of mixed level devices.

Whenever you perform a spec search in a user procedure, the ASWM command should be used as shown below. This reduces the execution time of the spec search, because the original sets are restored after the spec search has been executed. The example shown below does not affect the swing adjustment it only improves the performance of your spec search.

Note If you want to switch primary sets (firmware command SPRM) do that before you use the ASWM? command in your user procedure.

```
USER PROCEDURE:
ASWM? ----> [store result in buffer]
ASWM MIN, SEARCH
search { . . .
        DRLV ...
        ETDS ...
        . . . }
ASWM <---- [buffer as parameter input]
```

## Example

```
ASWM SET,AUTO
```

This example sets the swing adjustment mode AUTO.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.0.3: the SEARCH value of the mode parameter is no longer supported due to the obsoletion of standard test functions.
