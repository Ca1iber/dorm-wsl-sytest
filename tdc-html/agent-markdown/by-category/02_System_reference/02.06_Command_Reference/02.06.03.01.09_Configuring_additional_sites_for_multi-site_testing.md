# Configuring additional sites for multi-site testing

A test is configured for multi-site testing in three steps:

- Define the pin configuration for site 1 (which always exists).
- Use the PSTE command to define the required number of sites.
- Use the PALS command to assign channels to the pins of the new sites.

All the other configuration data will be shared with site 1.

Note that the number of sites that are actually available for testing can be smaller than the number of sites defined with PSTE. If, for example, a channel that is used for a certain site is defective, then the respective site will not be available for testing. You can use the PSTE? STR query to determine which sites are available for testing.

## Functional changes

- Introduced before SmarTest 6.3.2
