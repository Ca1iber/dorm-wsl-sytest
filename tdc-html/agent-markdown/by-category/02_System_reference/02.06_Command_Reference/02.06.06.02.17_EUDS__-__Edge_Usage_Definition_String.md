# EUDS? - (Edge Usage Definition String)

The EUDS? (Edge Usage Definition String) query returns the directions (drive or receive) of all edges for the specified waveform set. The waveform set must have been previously defined.

You set the edge directions with the commands [WFDS, WFDS? - (WaveForm Definition String)](<02.06.02.02.335_WFDS__WFDS__-__WaveForm_Definition_String.md>) or [BWDS, BWDS? - (Break Waveform Definition String)](<02.06.02.02.14_BWDS__BWDS__-__Break_Waveform_Definition_String.md>).

The EUDS? query has no influence on the number of defined waveform sets.

If ALL  is specified for the waveform set name, each name is returned with a pin list, as long as the waveform sequence is the same for all pins. Otherwise an answer per waveform set and pin is returned.

## Syntax

```
EUDS? {waveform_set}, [mode], {(pinlist)}
```

returns:

```
EUDS {waveform_set}, {definition_string}, {(pinlist)}
```

## Equation-based testing

```
EUDS? {"wavetable_name"},  [mode], {(pinlist)}
```

returns:

```
EUDS {"wavetable_name"}, {definition_string}, {(pinlist)}
```

or:

```
EUDS? {specset_id|"multi-port_spec"},  [mode], {(pinlist)}
```

returns:

```
EUDS {specset_id|"multi-port_spec"}, {definition_string},{(pinlist)}
```

## Parameters

 |

waveform_set

 |

Waveform Set Number. Enter ALL for all defined waveform sets, or an integer in the range 1 to the maximum number of allowed waveform sets. The waveform set must have previously been defined. The maximum number is determined by [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>). Enter PRM to select the primary waveform set. Equation specs (101 to 9999) can be used for queries.

 |
 |

mode

 |

Not used.

 |
 |

specset_id

 |

Derived as follows:

 |
 |

100 * equation_set_no + specset_no

Thus, the specset ID consists of 3 or 4 digits, where the first two digits specify the equation set number, and the following two digits the spec set number.

 |
 |

multi-port_spec

 |

To query a multi-port specification, enter the name of the specification.

 |
 |

wavetable_name

 |

The name of the wavetable. It must be enclosed in double quotes.

 |
 |

definition_string

 |

Edge usage definition string which consists of a list of all used edges. These are given as d1 through d8 (f1 through f8 and s1 through s8 on Smart Scale cards), and r1 through r8.

 |
 |

pinlist

 |

The name of the pin or pins for which edge usage definitions are to be read back. This parameter can also include groups previously created by the DFGP (DeFine GrouP) command. The symbol @ can be used to specify all configured pins. If more than one pin is to be included, the names must be separated with a comma.

 |

## Application

Timing setup ([Timing Setup Commands](<02.06.06_Timing_Setup_Commands.md>)), and test methods for AC testing.

## Errors

An error is generated if:

- waveform_set is greater than the range allowed by the [WSUS](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>)command.
- wavetable_name does not reference a defined wavetable.
- specset_id does not reference a defined wavetable.

## Example

```
EUDS? 1,,(@)
EUDS 1,"d1 d2 d3 r4",(io)
EUDS 1,"d1 d2 d3 d4 d5 d6 d7 d8",(clk)
```
