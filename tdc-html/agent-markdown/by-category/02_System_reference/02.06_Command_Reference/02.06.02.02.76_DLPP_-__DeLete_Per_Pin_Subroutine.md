# DLPP - (DeLete Per Pin Subroutine)

The DLPP (DeLete Per Pin Subroutine) command deletes a per-pin subroutine.

## Syntax

```
DLPP {label}
```

## Parameters

 |

label

 |

Specifies the name of the per-pin subroutine to be deleted.

 |

## Application

Edit command in Pattern Tool.

## Errors

An error is generated if:

- The specified label does not exist.
- The specified label is included in other labels.
- An affiliated sequencer call of the label has not been deleted yet.

## Example

```
DLPP "summer"
```

This command deletes the per-pin subroutine referenced by the label "summer".

## Functional changes

- Introduced before SmarTest 6.3.2
