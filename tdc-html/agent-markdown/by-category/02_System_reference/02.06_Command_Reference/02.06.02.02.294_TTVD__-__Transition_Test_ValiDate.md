# TTVD? - (Transition Test ValiDate)

TTVD? checks the protocol engine test configuration for the specified combinations of transition test set and pin. If the check fails, detail information about the errors is issued to the report window.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Syntax

```
TTVD? {"tt_name"|ALL|PRM}, {(pinlist)}
```

returns:

```
TTVD {"tt_name"}, {VALID|INVALID}, {(pinlist)}
```

## Parameters

 |

tt_name

 |

Specifies the name of a transition test set that must have been defined with [TTDF](<02.06.02.02.288_TTDF__TTDF__-__Transition_Test_set_DeFinition.md>).

 |
 |

ALL

 |

All transition test sets are checked.

 |
 |

PRM

 |

The current primary transition test set is checked.

 |
 |

pinlist

 |

Specifies the pins to which this configuration is to be applied.

 |

## Application

Protocol engine tests.

## Errors

An error is generated if no transition test set with the specified name exists.

## Example

```
> TTVD? "mySet",(p1,p2,p3)
< TTVD  "mySet", VALID, (p1,p3)
< TTVD  "mySet", INVALID, (p3)
```

## Functional changes

- Introduced in SmarTest 7.0.1
