# PRTG? - (PmuxRouTinG)

PRTG? is an internally used command, which may be visible in error reporting.

  If a PRTG? error appears in the ui Report Window, check the following:

- If you are calling functions from the [rdi.util()](<../02.07_Test_Method_Reference/02.07.13.23_SmartRDI__Utility_lines_control.md>) class within a block of RDI_BEGIN() and RDI_END(), check that this is correct.
- If you have defined the keyword PMUX_CTRL in the [RDI_Configure file](<../02.07_Test_Method_Reference/02.07.13.04_RDI_Configure_file.md>), then ensure you have the PMUX_CTRL pins in the pin configuration.
- That you have the correct configuration of utility lines / PMUX in the [Routing Tools](<../02.07_Test_Method_Reference/02.07.13.15.01_Routing_Tools_editors.md>). See also [Routing Tools (SmartRDI)](<../02.08_Setup_and_Result_Tools/02.08.04.24_Routing_Tools__SmartRDI.md>), [SmartRDI: DUT board connections control by Routing Tools](<../02.07_Test_Method_Reference/02.07.13.15_SmartRDI__DUT_board_connections_control_by_Routing_Tools.md>), and subtopics.
