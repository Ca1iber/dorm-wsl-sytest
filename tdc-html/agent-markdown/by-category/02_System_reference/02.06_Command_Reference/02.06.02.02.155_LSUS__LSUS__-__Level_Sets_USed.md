# LSUS, LSUS? - (Level Sets USed)

The LSUS (Level Sets USed) command sets the number of defined level sets to the given value. The new value has to be an integer in the range of 1 to the Maximum allowed level sets as set by [CONF, CONF? - (CONFiguration)](<02.06.02.02.31_CONF__CONF__-__CONFiguration.md>) (the default is 32, the maximum is 256).

You can use the LSUS command to delete sets. If the level setup file that you want to load to hardware contains more level sets than you require, you can use the LSUS command to delete all the sets above the number you specify.

In a non-equation-based environment, the LSUS? query returns the number of level sets currently defined. In an equation-based environment, the LSUS? query returns the number of level sets currently defined in the specified level equation set.

## LSUS

```
LSUS {level_set_no}
```

## LSUS?

```
LSUS? [level_set_no]
```

returns:

```
LSUS {level_set_no}
```

or:

```
LSUS? [equation_set_no]
```

returns:

```
LSUS {level_set_no}
```

## Parameters

 |

level_set_no

 |

Level Set Number. This is the highest number currently allocated to a level set or the highest number of set you want to load. The number you type must not exceed the maximum number of level sets allowed (defined by the [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) command).

This number is automatically updated to include any new level set as it is created. At power-on only one level set (containing the default values) is available.

 |
 |

equation_set_no

 |

The level equation set number for which the number of currently defined level sets is to be determined. Enter an integer in the range 1 to 99. Valid for Equation based testing only.

 |

## Application

Level Setup, see [Level Setup Commands](<02.06.05_Level_Setup_Commands.md>).

## Errors

An error is generated if:

- The level_set_no is greater than the range allowed by the [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) command.
- The level_set_no is smaller than one.
- The equation_set_no is undefined.

## Example

```
LSUS 4
```

This example defines a maximum of 4 level sets.

## Functional changes

- Introduced before SmarTest 6.3.2
