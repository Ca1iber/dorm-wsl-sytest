# PRMD? - (PRBS MoDe)

The PRMD? query returns the PRBS related configuration of one or more wavetables.

## Syntax

```
PRMD? {wvf_set|"wavetable_name"|specset_id|"multi_port_spec"|PRM}, {(pinlist)}
```

returns:

```
PRMD {wvf_set|"wavetable_name"|specset_id|"multi_port_spec"|PRM}, {prbs_mode}, [x_mode], {(pinlist)}
```

## Parameters

 |

wvf_set

 |

Waveform Set Number (range 1 to maximum). Enter ALL for all waveform sets. The maximum number is determined by the command [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>).

This option is needed by some GUI tools that use this query. A PRBS test can only be defined in equation based timing.

 |
 |

wavetable_name

 |

The wavetable name. Enter a string of up to 40 alphanumeric characters (upper or lower case).

 |
 |

specset_id

 |

Derived as follows:

100 * equation_set_no + specset_no

 |
 |

multi-port_spec

 |

To query a multi-port specification, enter the name of the specification.

 |
 |

PRM

 |

The PRBS configuration of the primary wavetable(s) is returned.

 |
 |

prbs_mode

 |

Possible values are:

 |
 |

PRBS_I

 |

The pin is enabled for PRBS generation.

 |
 |

PRBS_I_INV

 |

The pin is enabled for PRBS generation and is the negative connection of a differential pair.

 |
 |

PRBS_O_INV

 |

The pin is enabled for PRBS checking and is the negative connection of a differential pair.

 |
 |

PRBS_O

 |

The pin is enabled for PRBS checking.

 |
 |

PRBS_OFF

 |

The pin is not configured for PRBS testing.

 |
 |

x_mode

 |

Specifies the x-mode for PRBS enabled pins. Left empty if prbs_mode is PRBS_OFF.

 |
 |

pinlist

 |

The name of the pin or pins for which the PRBS configuration is to be retrieved. The symbol @ can be used to specify all configured input and IO pins. If more than one pin is to be included, the names must be separated with a comma.

 |

## Application

PRBS test.

## Examples

### Example 1

```
> PRMD? PRM,(@)
< PRMD 101,PRBS_OFF,,(pin1,pin2)
> SPRM 103,1,1,1
> PRMD? PRM,(@)
< PRMD 103,PRBS_I,2,(pin1)
< PRMD 103,PRBS_O,8,(pin2)
```

### Example 2

```
> PRMD? "prbs_2",(@)
< PRMD "prbs_2",PRBS_O,4,(pin1,pin2)
```

This example queries a wavetable.
