# SVEC subroutines

#### Subtopics

- [Calculating the buffer cycles for JMPE and RETC (and match loops)](<02.06.07.01.08.05.02.01_Calculating_the_buffer_cycles_for_JMPE_and_RETC__and_match_loops.md>)

SVEC labels cannot be called directly. However, you can call a SVEC label not only from a MAIN label, but also from another SVEC label. These calls can be nested seven levels deep.

SVEC labels are called with the JSUB, the JMPE or the COGO instruction. The JSUB instruction calls the subroutine unconditionally. The JMPE and the COGO instructions call the subroutine in dependence on whether an internal error flag is set. This flag indicates that at least one cycle has failed for at least one pin. Note that the software needs a certain time to propagate a failure to the flag (see [Calculating the buffer vectors for JMPE and RETC (and match loops)](<02.06.07.01.08.05.02.01_Calculating_the_buffer_cycles_for_JMPE_and_RETC__and_match_loops.md>)). This is the same error flag that is also used for new style (counted) match loops, see [Match loops](<02.06.07.01.08.04.03_Match_loops.md>).

COGO is a variant of JMPE. The basic difference is that the return address for a COGO call is not pushed onto the call stack. Therefore a subroutine called with COGO will not return to the calling label, but to the lowest label in the call hierarchy that did not use COGO for its subroutine call.

Every SVEC label must start with an STVA instruction. The end of a SVEC label is marked by the RSUB instruction. The return to the calling label can be unconditional, or it can be made to depend on the same error flag that controls the conditional subroutine call with JMPE. The conditional return is defined with the RETC instruction. You can choose whether control is returned to the calling routine if the flag is set or if it is not set. The same subroutine can contain more than one RETC instruction.

Note that, in contrast to MAIN labels, the primary timing and level sets are not reloaded at the start of a SVEC subroutine. The subroutine takes over the level and timing setup from the calling routine.

## Example

The following listing shows a SVEC subroutine that is called from two MAIN labels:

```
SQPG 0,STVA,408,,,(@)
SQPG 1,STSA,,,,(@)
SQPG 2,GENV,6,,,(@)
SQPG 3,JSUB,,"sub",,(@)
SQPG 4,STOP,,,,(@)
SQPG 5,STVA,416,,,(@)
SQPG 6,STSA,,,,(@)
SQPG 7,GENV,4,,,(@)
SQPG 8,JSUB,,"sub",,(@)
SQPG 9,STOP,,,,(@)
SQPG 10,STVA,424,,,(@)
SQPG 11,GENV,400,,,(@)
SQPG 12,RSUB,,,,(@)
```

The definitions of the three labels are as follows:

```
SQLB "test1",MAIN,0,4,"table1"
SQLB "test2",MAIN,5,9,"table1"
SQLB "sub",SVEC,10,12,"table1"
```
