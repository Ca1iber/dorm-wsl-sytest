# DFUT, DFUT? - (DeFine UTility line)

The DFUT command defines a symbolic name and an operation mode for a utility line.

Utility lines allow you to control external devices such as relays, solenoids or indicators, depending on the application. The utility lines are implemented as open drain output with a maximum current of 100 mA and a maximum voltage of about 5.0 V.

The definition made by command DFUT can be used by the [UTST](<02.06.02.02.313_UTST__UTST__-__UTility_line_STate.md>) command to set or read the status of the utility line.

## DFUT

```
DFUT {ch_No}, {type}, {(util_name)}
```

## DFUT?

```
DFUT? {(util_name)}
```

returns

```
DFUT {ch_No}, {type}, {(util_name)}
```

## Parameters

 | ch_No |

Channel number of the utility line specified with five or three digits.

In the five‑digit format, the first three digits specify the utility pogo block. For valid pogo blocks, refer to [DUT interface layout](<../02.03_DUT_board_design_reference/02.03.03.01_DUT_interface_layout.md>) and to [Utility pogo block mapping](<../02.03_DUT_board_design_reference/02.03.06.08.02_Utility_pogo_block_-_Utility_Card__V93000_EXA_Scale_systems.md#_347642__s_Utility_pogo_block_mapping>) in [Utility pogo block - Utility Card (V93000 EXA Scale systems)](<../02.03_DUT_board_design_reference/02.03.06.08.02_Utility_pogo_block_-_Utility_Card__V93000_EXA_Scale_systems.md>).

In the legacy three‑digit format, the first digit (1 ... 8) specifies the utility pogo block UTIL鈥? ... UTIL鈥?.

The last two digits specify the channel number 01 ... 32 of the utility line.

On the utility pogo blocks, an offset of -1 is to be considered and the channel number is URW00 ... URW31.

When reading the defined utility lines with the DFUT? command, the data returned always have the five‑digit format. The same applies to the [PALS?](<02.06.02.02.173_PALS__PALS__-__Pin_ALlocation_for_multiple_Sites.md>) command.

For more information, see [Utility line assignments](<../02.03_DUT_board_design_reference/02.03.04.01_Utility_line_assignments.md>) and [DUT interface layout](<../02.03_DUT_board_design_reference/02.03.03.01_DUT_interface_layout.md>)

 |
 | type |

Specifies the operating mode of the utility line with the following specifiers:

- W: Write-Only
- R: Read-Only
- RW: Read-Write

Utility lines of the optional [Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>) can also be configured as safety lines or as global shutdown line for hardware‑controlled shutdown of XPS256 pins:

- TRIGGER_IF_HIGH: Safety line
- TRIGGER_IF_LOW: Safety line
- TRIGGER_SITE_IF_HIGH: Global shutdown line
- TRIGGER_SITE_IF_LOW: Global shutdown line

For more information, refer to [XPS256 safety line and DUT board disconnect](<../02.05_Test_Head_Cards/02.05.05.03.03.06_XPS256_safety_line_and_DUT_board_disconnect.md>).

 |
 | util_name |

Name of the utility line. For the query, it specifies the utility line name to be retrieved. @ can be used to list all defined utility lines.

This parameter can have up to 16 alphanumeric characters and must not contain blank spaces, or any of the following characters: `# ; ( ' ' ) ? @ ,`

 |

## Application

For details about utility lines, see [Configuration Setup Commands](<02.06.03_Pin_configuration_setup_commands.md>).

## Errors

An error is generated if:

- The channel number is out of range.
- The channel number is already used.
- The utility line name is out of range.
- The utility line name is already assigned to an analog or digital pin.

## Example

```
DFUT 16504,w,(filter)
```

This example assigns the name `filter` and operating mode w to utility line 4 of the first utility pogo block.
