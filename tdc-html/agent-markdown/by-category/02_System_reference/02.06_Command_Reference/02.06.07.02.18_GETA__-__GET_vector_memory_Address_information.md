# GETA? - (GET vector memory Address information)

The GETA? query is called with a logical identification of a vector and returns the absolute address of this vector in the vector areas. GETA? can only be issued after a label has been selected for editing with the [TSTL](<02.06.02.02.281_TSTL__TSTL__-__TeST_Label.md>) command.

The absolute address of an active vector counts all the vectors of the respective areas including the inactive (padding) vectors. The vector areas, and therefore also the returned addresses, are port specific. The logical identification is provided by a logical vector number, which counts the active vectors of the label currently activated by TSTL, starting from 0 (zero).

The information returned by GETA? can serve as input to the [VECD](<02.06.02.02.325_VECD__VECD__-__VECtor_Download.md>) command for applications such as downloading unique initialization vector sequences in device specific tests.

## Syntax

GETA? {type}, [param_1], {param_2}, {(pinlist)}

returns:

GETA {type}, {param_1}, {param_2}, {applic}, {start_addr}, {length}, {(pinlist)}

## Parameters

 |

type

 |

Specifies the type of test for which vector area address information is required. The only allowed value is VEC (for VECtors).

 |
 |

param_1

 |

param_1 requires a label name. The present implementation always takes the label currently activated with the TSTL command, so you must leave this parameter blank in the query. The reply specifies the currently activated label.

 |
 |

param_2

 |

param_2 requires a logical vector number.

 |
 |

pinlist

 |

Information is only returned for the pins specified in pinlist. If more than one pin is to be included, the names must be separated with a comma. You can type the character @ to obtain data for all pins.

 |
 |

applic

 |

A reply parameter. Returns the type of the test application:

 |
 |

PARA

 |

Parallel test.

 |
 |

start_addr

 |

A reply parameter. It returns the absolute address of the queried vector in the vector area.

 |
 |

length

 |

A reply parameter. It returns an integer giving the remaining active vectors of the sequencer construct starting from the queried vector.

 |

## Application

Vector addressing for download.

## Errors

An error is generated if:

- The label you enter is invalid.
- The logical vector does not exist.

## Example

```
> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,9,,,(@)
< SQPG 3,RPTV,6,5,,(@)
< SQPG 4,STOP,,,,(@)
> TSTL "test_1",(@)
> GETA? VEC,,9,(S0_1)
< GETA VEC,"test_1",9,PARA,520,6,(S0_1)
```

This example queries the absolute address of the parallel vector with the logical vector number 9 (the first active vector of the RPTV instruction) in the label test_1 for pin S0_1. Note that 7 padding vectors exist between the last active vector of the GENV instruction and the first active vector of the RPTV instruction.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.0.1: The vector areas are now port-specific.
