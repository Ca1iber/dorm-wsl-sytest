# Managing the sequencer area

The sequencer area is managed by the following commands:

 |

Command

 |

Description

 |
 |

DMAS

 |

Serves to manage the size of the sequencer area

 |
 |

SAOF

 |

Sets the operation mode of the test system software and influences the behavior of the DMAS command.

 |
 |

SQLB

 |

Serves to define labels. Strictly speaking, the label definition is not part of the sequencer area, but it references the sequencer program of the label.

 |
 |

SQLA

 |

Serves to set or modify certain attributes of the label, for example, whether its physical waveform DC/DC power units are located in SM or SHMEM.

 |
 |

DLTS

 |

Serves to delete a label

 |
 |

APTS

 |

Considerably simplifies the creation of a new label at the end of the sequencer area for certain label types. Creation of a label with high level or low level commands will be discussed in more detail in [Editing and executing labels at firmware level](<02.06.07.01.07_Editing_and_executing_labels_at_firmware_level.md>).

 |
 |

INSI

 |

Edit command which inserts a line into the sequencer area. For some details see [Inserting a sequencer instruction](<02.06.07.01.07.03.01_Inserting_a_sequencer_instruction.md>).

 |
 |

INGV

 |

Edit command which inserts a GENV instruction into the sequencer area and makes room for the new instruction in the vector areas. For some details see [Inserting a sequencer instruction](<02.06.07.01.07.03.01_Inserting_a_sequencer_instruction.md>).

 |
 |

DELI

 |

Edit command which deletes a line in the sequencer area. For some details see [Deleting a sequencer instruction](<02.06.07.01.07.03.02_Deleting_a_sequencer_instruction.md>).

 |

Note that the sequencer area is also affected by commands which serve to manage sequencer constructs, see [Managing sequencer constructs](<02.06.07.01.06.05_Managing_sequencer_constructs.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
