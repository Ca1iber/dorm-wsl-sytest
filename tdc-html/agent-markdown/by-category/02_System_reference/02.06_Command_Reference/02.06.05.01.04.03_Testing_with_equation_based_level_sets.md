# Testing with equation based level sets

#### Subtopics

- [Verifying the level settings](<02.06.05.01.04.03.01_Verifying_the_level_settings.md>)

To run a test with equation based level sets you may either use the level GUIs or the following commands:

- [EQFS - (EQuation FileS command transfer)](<02.06.02.02.108_EQFS_-__EQuation_FileS_command_transfer.md>):

Provides the load/save operations required by the editor tools for loading/saving the equation based testing files from/to temporary files.

For example, to load the level equation file from

/tmp/level_equation

enter

EQFS LEV,EQN,LOAD,"/tmp/level_equation"

- [EQSP, EQSP? - (EQuation SPecification transfer)](<02.06.02.02.109_EQSP__EQSP__-__EQuation_SPecification_transfer.md>):

Downloads an equation based collection of setup data (for example level equation sets) in binary format to the firmware. The EQSP? query returns, in binary format, an equation based collection of setup data from the firmware.

Additionally for Pin Scale 9G:

- [EQFC, EQFC? - (EQualization and Filter Configuration)](<02.06.02.02.107_EQFC__EQFC__-__EQualization_and_Filter_Configuration.md>):

Configures the equalization and the low pass filter parameters. For example, specify filter time constants (risetime) and the relative swing offsets on a per pin base. EQFC? returns the queried configuration parameters.

When you run a test with equation based level sets you must select the following items:

- one level equation set (remember, you can define more than one equation set)
- one level set of the selected equation set (an equation set can contain several level sets)
- one spec set (an equation set can be associated with several spec sets)
