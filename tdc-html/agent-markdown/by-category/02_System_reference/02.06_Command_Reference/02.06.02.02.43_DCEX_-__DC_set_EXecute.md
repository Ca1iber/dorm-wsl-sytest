# DCEX - (DC set EXecute)

The DC set EXecution command executes the DC measurement, which has been defined by DCCH or DCVH. It is executed in parallel or in serial, as defined for the DC Set. By default a value measurement is executed. It is possible to apply the DC Set parameters to the HPMU, in order to use the HPMU as source. In this case the parameters FORCE_ON and FORCE_OFF are available.

## Syntax

```
DCEX {setNr}, [mode]
```

## Parameters

 | setNr  | The DC Set Identification number, starting with 1. |
 | mode   | MEAS_VAL  | Value measurement per pin (including P/F result) is executed as defined with [DCCH](<02.06.02.02.40_DCCH_-__DC_Current_measurement_High_precision_pmu.md>) or [DCVH](<02.06.02.02.52_DCVH_-__DC_Voltage_measurement_High_precision_pmu.md>). |
 |   | MEAS_GPF  | Global pass/fail measurement as defined with [DCCH](<02.06.02.02.40_DCCH_-__DC_Current_measurement_High_precision_pmu.md>) or [DCVH](<02.06.02.02.52_DCVH_-__DC_Voltage_measurement_High_precision_pmu.md>). |
 |   | MEAS_PPF  | Per-pin pass/fail measurement as defined with [DCCH](<02.06.02.02.40_DCCH_-__DC_Current_measurement_High_precision_pmu.md>) or [DCVH](<02.06.02.02.52_DCVH_-__DC_Voltage_measurement_High_precision_pmu.md>). |
 |   | FORCE_ON  | The parameters of the DC Set are applied to the HPMU to use the HPMU as source, no measurement is executed.

This mode is not supported for HV pins.

 |
 |   | FORCE_OFF  | The relays are re-opened, so that the HPMU is no longer used as source.

This mode is not supported for HV pins.

 |

## Notes

- DCEX executes the measurement for all active sites and caches the results for DCRE?. Serial measurements will be executed site parallel.
- If the execution mode is not given, a value measurement is executed per default.
- DCEX does not activate the primaries.
- If DCEX is executed on HV pins, it checks the voltage before connecting the pin PMU. If the voltage exceeds the safe range of the pin PMU, the test fails and the result value is 999999.

## Errors

An error is returned if the specified DC Set number has not been defined yet.

## Example

Precondition:

```
DCVH 1,,20000,200,-100,100,I,25,NTBBM,PAR,(pin1,pin2,pin3)
```

Execution:

```
DCEX 1, MEAS_VAL
```

Result:

```
DCRE? 1,
DCRE P, 10.3, (pin1)
DCRE F, 200.1, (pin2)
DCRE P, 20.4, (pin3)
```
