# MEAS - (execute a MEASurement set)

This command executes a measurement set that is created with the [MSET](<02.06.02.02.164_MSET__MSET__-__definition_of_Measurement_SET.md>) command.

 Note MEAS cannot be used if the measurement mode of the respective measurement set is VMUM, DFV1, or DFV2. In this case you must execute the measurement set from a DC pattern.

## Syntax

```
MEAS {id_dc}, {id_mset}
```

## Parameters

 |

id_dc

 |

The DC set identification number to be executed.

 |
 |

id_mset

 |

The measurement set identification number to be executed.

 |

## Application

[DC Measurement Commands](<02.06.10_DC_Measurement_Commands.md>) introduces the firmware commands for the DC test.

## Example

```
MEAS 1,2
```

This example executes the measurement set 2 of the DC set 1.

See also an example in [MSET, MSET? - (definition of Measurement SET)](<02.06.02.02.164_MSET__MSET__-__definition_of_Measurement_SET.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
