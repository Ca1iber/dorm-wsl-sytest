# Burst labels and multi-port burst labels

#### Subtopics

- [Burst labels](<02.06.07.01.08.05.03.01_Burst_labels.md>)
- [Multi-port burst labels](<02.06.07.01.08.05.03.02_Multi-port_burst_labels.md>)

Burst and multi-port burst labels serve to execute several MAIN labels using the same primary sets successively as if they were a sequence of subroutines. They are of particular value in a production test environment, because they allow you to execute a large number of labels quickly in one sequence. Bursts labels cannot be nested.

## Functional changes

- Introduced before SmarTest 6.3.2
