# PRCF, PRCF? - (Pseudo Random bit sequence ConFiguration)

This command serves to define and query the connection polynomial and the seed of the PRBS for the specified pins. Note that the LFSR on the Pin Scale 9G is a Fibonacci LFSR; for some background information see [Overview of pseudo random bit sequences](<02.06.17.01_Overview_of_pseudo_random_bit_sequences.md>). The length of the LFSR is determined by the degree of the polynomial or, equivalently, by the length of the seed.

The specified PRBS set must have been defined with [PRDF](<02.06.02.02.182_PRDF__PRDF__-__PRBS_set_DeFinition.md>).

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## PRCF

```
PRCF {"PRBS_set_name"|PRM}, {property}, {"property_value"}, {(pinlist)}
```

## PRCF?

```
PRCF? {"PRBS_set_name"|ALL|PRM}, {property|ALL}, {(pinlist)}
```

returns:

```
PRCF {"PRBS_set_name"}, {property}, {"property_value"}, {(pinlist)}
```

## Parameters

 |

PRBS_set_name

 |

Specifies the name of a PRBS set that must have been defined with PRDF.

 |
 |

property

 |

Specifies a property of the PRBS set. There are two properties to be configured:

 |
 |

POLYNOMIAL

 |

This property defines the connection polynomial of the LFSR. It is coded as a bit string where the position of the bit identifies the degree of the addend, and its value defines the coefficient of this addend. The constant term of the polynomial, which is always 1, must be omitted. The last bit is supposed to determine the degree n of the polynomial. Therefore, the length of the string must be n, and its last bit must be "1".

 |
 |

SEED

 |

This property defines the seed for the LFSR in the order in which it is output. This property is only required for PRBS generation. The seed for the PRBS check is taken from the received data.

 |
 |

ALL

 |

This value can be specified in the query to retrieve the configuration data of all PRBS sets.

 |
 |

PRM

 |

This value can be specified to modify or retrieve the configuration of the current primary PRBS set.

 |
 |

property_value

 |

Specify a bit string for this parameter. Its meaning depends on the selected property. For POLYNOMIAL it encodes the connection polynomial. For SEED, it defines the initial state of the LFSR. The maximum length is 32 in both cases.

- The default for the polynomial is

11111110111010110011110000100101,

which is the polynomial

1+x+x2+x3+x4+x5+x6+x7+x9+x10+x11+x13+x15+x16+x19+x20+x21+x22+x27+x30+x32.

- The default for the seed is

00110010011011110001001101100111.

 |
 |

pinlist

 |

Specifies the pins to which pin this configuration is to be applied.

 |

## Application

PRBS test.

## Errors

An error is generated if:

- No PRBS set with this name exists,
- The bit string is longer than 32 characters.

## Example

```
> PRCF? "PRBS_1",ALL,(Pin1)
< PRCF "PRBS_1",POLYNOMIAL,"101",(Pin1)
< PRCF "PRBS_1",SEED,"100",(Pin1)
```

This example defines 1 + x1 + x3 as the connection polynomial, and 100 as the initial segment for Pin1. This is the example which is also used in [Overview of pseudo random bit sequences](<02.06.17.01_Overview_of_pseudo_random_bit_sequences.md>).
