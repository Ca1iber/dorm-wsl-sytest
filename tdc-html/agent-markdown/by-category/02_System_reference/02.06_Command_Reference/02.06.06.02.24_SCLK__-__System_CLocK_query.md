# SCLK? - (System CLocK query)

The SCLK? query returns the system clock value for the specified waveform set or specification. The system clock is the reference clock which coordinates the operation of the test system channels, so that, for example, a functional test is started for all channels at the same time.

## Syntax

```
SCLK? {wf_set|specset_id|"multi-port_spec"|ALL|PRM}
```

returns:

```
SCLK {wf_set|specset_id|"multi-port_spec"} {sclk_val}
```

## Parameters

 |

wf_set

 |

Waveform Set Number. Enter an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>).

 |
 |

specset_id

 |

Derived as follows:

`100 *`equation_set_no `+ `specset_no

 |
 |

multi-port_spec

 |

To query a multi-port specification, enter the name of the specification.

 |
 |

sclk_val

 |

The SCLK period of the respective setup in ns.

 |
 |

ALL

 |

Returns the SCLK values for all waveform sets.

 |
 |

PRM

 |

Returns the value for the primary waveform set or specification (set by SPRM).

 |

## Example

```
> SCLK? 401
< SCLK 401,480
```

## Functional changes

- Introduced before SmarTest 6.3.2
