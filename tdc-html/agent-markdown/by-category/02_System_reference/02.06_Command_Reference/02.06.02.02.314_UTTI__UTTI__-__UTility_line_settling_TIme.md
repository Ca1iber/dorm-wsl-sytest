# UTTI, UTTI? - (UTility line settling TIme)

The UTTI (UTility line settling TIme) command sets the settling time that is used as a wait time from when the utility line state is changed until the next command is executed.

Actually, the settling time defined with this command is used in the following cases:

- When the [WSDN](<02.06.02.02.341_WSDN_-__Wait_Setup_DoNe.md>) command is performed after the settings of the utility lines have been activated with the [FLSH](<02.06.02.02.124_FLSH_-__FLuSH_buffered_commands.md>) command.

The settings of utility lines are activated in parallel and the longest settling time of all the utility lines is used. The default value of the settling time is 0 ms.

## UTTI

```
UTTI {time}, {(util_name)}
```

## UTTI?

```
UTTI? {(util_name)}
```

returns:

```
UTTI {time}, {(util_name)}
```

## Parameters

 | time  | Specifies the wait time to change the utility line status using the [UTST](<02.06.02.02.313_UTST__UTST__-__UTility_line_STate.md>) and [FLSH](<02.06.02.02.124_FLSH_-__FLuSH_buffered_commands.md>) command (in ms). |
 | util_name |

Specifies the utility line name or names for which the settling time is to be set.

The symbol @ is used for all utility lines.

If more than one name is required, the names must be separated with a comma.

 |

## Application

For details about utility lines, see [Configuration Setup Commands](<02.06.03_Pin_configuration_setup_commands.md>).

## Errors

An error is generated if the settling time is lower than zero.

## Example

```
UTTI 2.5,(filter)
```

This example sets the settling time of the utility line "filter" to 2.5 ms.

## Functional changes

- Introduced before SmarTest 6.3.2
