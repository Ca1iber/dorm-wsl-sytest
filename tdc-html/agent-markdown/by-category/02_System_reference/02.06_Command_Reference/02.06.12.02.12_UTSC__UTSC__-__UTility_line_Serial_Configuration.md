# UTSC, UTSC? - (UTility line Serial Configuration)

The UTSC (UTility line Serial Configuration) command allows utility lines to be controlled via a serial interface and multiple utility blocks to be ganged and controlled via a single utility block ('master') through a serial interface.

 Note This command is only available on systems that provide dynamic access utility lines. For details refer to [Utility line capabilities in relation to the system hardware](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01.07_Utility_line_capabilities_in_relation_to_the_system_hardware.md>).

Serial control involves shifting data into or out of (for reading) a 32鈥慴it (4鈥憆ow utility block) shift register associated with each utility block. UTSC can internally chain the shift registers of the selected utility blocks together ('ganging'). Once a gang has been set up, all UTSC commands must reference the whole group.

The serial interface has to be set up and used as described in [Sequencer-controlled utility lines](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01_Sequencer-controlled_utility_lines.md>).

The [*RST](<02.06.02.02.345_RST_-__ReSeT.md>) command resets all blocks to the default parallel in and out mode and turns off all ganging.

 The following rules are to be observed:

- Serial control can be used only if a hardware connection to the master utility block exists on the DUT board.
- Ganging is done internally; there is no need to connect the serial inputs and outputs of utility blocks together physically on the DUT interface board.
- Only contiguous utility blocks can be ganged. The utility block with the lowest number acts as the master for that gang.
- If sequencer control is active, static utility line access is disabled, see [UTIX?](<02.06.02.02.310_UTIX__-__UTility_line_Inputs_eXtended.md>), [UTOT](<02.06.02.02.311_UTOT__UTOT__-__UTility_line_OuTputs.md>).

## UTSC

```
UTSC {(word) | ALL}, {mode} [, maskMode]
```

## UTSC?

```
UTSC? {(word)} | ALL
```

returns:

```
UTSC {(word)}, {mode} [, maskMode]
```

## Parameters

 | word |

One unique utility pogo block number or a list enclosed in brackets containing utility pogo blocks separated by commas.

The pogo block or the list of pogo blocks uses three鈥慸igit numbers. For valid pogo blocks, refer to [DUT interface layout](<../02.03_DUT_board_design_reference/02.03.03.01_DUT_interface_layout.md>) and to [Utility pogo block mapping](<../02.03_DUT_board_design_reference/02.03.06.08.02_Utility_pogo_block_-_Utility_Card__V93000_EXA_Scale_systems.md#_347642__s_Utility_pogo_block_mapping>) in [Utility pogo block - Utility Card (V93000 EXA Scale systems)](<../02.03_DUT_board_design_reference/02.03.06.08.02_Utility_pogo_block_-_Utility_Card__V93000_EXA_Scale_systems.md>).

The legacy single鈥慸igit format 1 ... 8 is also supported, but the query always returns the three鈥慸igit format.

 |
 | ALL  | Keyword to use all available utility blocks with the given mode. |
 | mode |

Mode to be applied to a single block or the ganged utility blocks.

Available modes are:

 |
 | RD  | Parallel output (with [UTOT](<02.06.02.02.311_UTOT__UTOT__-__UTility_line_OuTputs.md>)), parallel input (with [UTIX?](<02.06.02.02.310_UTIX__-__UTility_line_Inputs_eXtended.md>)) or serial input (via serial interface pin SOUT), turns ganging on, if off. |
 | RW  | Serial output (via serial interface pin SINP), parallel input (with [UTIX?](<02.06.02.02.310_UTIX__-__UTility_line_Inputs_eXtended.md>)) or serial input (via serial interface pin SOUT), turns ganging on, if off. |
 | OFF  | Parallel output (with [UTOT](<02.06.02.02.311_UTOT__UTOT__-__UTility_line_OuTputs.md>)), parallel input (with [UTIX?](<02.06.02.02.310_UTIX__-__UTility_line_Inputs_eXtended.md>)), turns ganging off. |
 | maskMode |

The extra parameter sets the mask mode for the defined utility blocks.

Available modes are:

 |
 | MASK  | Enables the mask mode. |

## Errors

If an error occurs during mode setup or change, the hardware state remains unchanged. Possible root causes may be:

- Setting up a connection that is not possible, for example `UTSC (1,3,5),RW`
- Changing the mode using conflicting settings, for example setting up ganging: `UTSC (1,2,3),RW` and changing the mode: `UTSC (1,2),OFF`
- Using a block in more than one gang.

The following errors may be reported:

- "Utility block <u> not available."

Possible causes include:

  - <u> is not a valid integer
  - The DUT interface does not contain a utility block with number <u>

- "The '<m>' access mode is not available for utility block <u>."

You may be attempting to use the serial mode with an incompatible wiring board.

- "Too many utility blocks given."

You may be attempting to create a gang with more than eight utility blocks.

- "No utility blocks given."

You may be attempting to create a gang with 0 blocks.

- "Command not applicable because utility blocks <u> and <v> cannot be connected."

You may be attempting to create a gang where the blocks are not contiguous, for example, (1,2,4).

- "Command not applicable because it conflicts with earlier settings for utility block <u>."

You may be attempting to modify a part of a gang without setting all blocks to OFF first.

Errors that may be reported by the UTSC? query:

- "Utility block <u> not available."

Possible causes include:

  - <u> is not a valid integer
  - The test head does not contain a utility block with number <u>.

## Example

The following example shows how to reset the mode for all utility blocks to static:

```
UTSC ALL, OFF
```

The following example shows how to gang utility blocks 1 to 4 setting the mode to serial out:

```
UTSC (165,166,167,168),RW
```

The following example shows how to change the mode of the previously set up gang to parallel out:

```
UTSC (165,166,167,168),RD
```

The following example, based on the previous setup, will lead to an error, because the fourth utility pogo block is missing:

```
UTSC (165,166,167),OFF
```

The following example shows how to turn off ganging by changing the mode of the previously set up gang to off:

```
UTSC (165,166,167,168),OFF
```

The following example shows how to set up a new gang with the second, third and fourth utility pogo block in serial out mode:

```
UTSC (166,167,168),RW
```

The following example shows how to use the UTSC? query to display the entire gang and the mode if a single utility block of a gang is given:

```
UTSC? 166
```

results in:

```
UTSC (166,167,168),RW
```

The following example shows how to use the UTSC? query to display all gangs and modes of all utility blocks:

```
UTSC? ALL
```

results in:

```
UTSC 1,OFF
UTSC (166,167,168),RW
UTSC 169,OFF
UTSC 170,OFF
UTSC 171,OFF
UTSC 172,OFF
```

The following example shows how to change the existing gang with utility blocks 2 to 4 in serial out mode to the masked mode:

```
UTSC (166,167,168),RW,MASK
```

The following example shows the query result of UTSC? with mask mode set for the second to fourth utility pogo block:

```
UTSC? ALL
```

results in:

```
UTSC 165,OFF
UTSC (166,167,168),RW,MASK
UTSC 169,OFF
UTSC 170,OFF
UTSC 171,OFF
UTSC 172,OFF
```
