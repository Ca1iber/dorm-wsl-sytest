# HREX? - (High Resolution EXecution)

The HREX? query executes a high resolution measurement and returns the received values.

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## Syntax

```
HREX? {(pinlist)}
```

returns:

```
HREX {(pin)}, {#spec(data)}
```

## Parameters

 |

pinlist

 |

Specifies the pins or pin groups for which the measurement is to be reported. A reply will be given for a pin only if the port to which it belongs is in the same sequencing group as the reference port of [HRIT](<02.06.02.02.139_HRIT__HRIT__-__High_Resolution_Interval_of_Time.md>).

 |
 |

pin

 |

The pin for which an answer is given.

 |
 |

#spec(data)

 |

The binary data that are returned. The general format is:

Nn1n2...nNdata_stream

where the digit N defines the number of the digits ni (1 鈮?i 鈮?N) that specify the length of data_stream in bytes.

The data stream itself is in principle a sequence of pairs each which consists of a repetition factor and a result value. The repetition factor indicates how often the following result value is measured before the result changes. A repetition factor of 1 is omitted.

The possible result values are:

L: Low

H: High

I: Intermediate

U: Unstable

An example is given below.

 |

## Example

```
> HRIT HRES,40,0,42,0,800,(A)
> HREX? (a1,a2,b1)
< HREX (a1),#9000000020199LI199HI199LI199HI
< HREX (a2),#9000000020199LI199HI199LI199HI
> HRIT END
```

In this example, a rising edge occurs exactly in the middle of every cycle, and a falling edge at the end of every cycle for all pins. Note that the total number of results 4 * (199 + 1) equals the number of samples requested with HRIT RES.

## Functional changes

- Introduced before SmarTest 6.3.2
