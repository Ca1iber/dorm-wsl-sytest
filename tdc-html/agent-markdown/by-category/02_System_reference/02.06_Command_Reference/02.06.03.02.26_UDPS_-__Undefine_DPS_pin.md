# UDPS - (Undefine DPS pin)

The UDPS (Undefine DPS pin) command removes any specified DPS pins from your current setup, that have previously been defined by [DFPS, DFPS? - (DeFine Power Supply)](<02.06.02.02.65_DFPS__DFPS__-__DeFine_Power_Supply.md>). The gang (master/slave) configuration is also resolved.

## Syntax

```
UDPS {(pinlist)}
```

## Parameters

 |

pinlist

 |

Consists of single or multiple pin names or the symbol @ which undefines all DPS pins. If more than one pin is to be removed, the names must be separated with a comma.

 |

## Application

Pin configuration, see [Configuration Setup Commands](<02.06.03_Pin_configuration_setup_commands.md>).

## Example

```
UDPS (Vee)
```

This example removes pin Vee from the setup. The software saves the level data associated with the DPS channel. Therefore if you redefine the channel using the same or a different name, the DPS settings are immediately restored.

## Functional changes

- Introduced before SmarTest 6.3.2
