# Defining ports

Ports organize the device into groups of pins that can be tested independently with different timings and by separate sequencer programs. The default port (@), which supplied by the system, consists of all pins. User defined ports are created with the [DFPT](<02.06.02.02.66_DFPT__DFPT__-__DeFine_PorT.md>) command and deleted with the UDPT command. The DFPT? query returns the definitions of one or more ports.

Ports are related to pin groups (see [Defining pin groups](<02.06.03.01.06_Defining_pin_groups.md>)) as follows:

- A port must not have the same name as a pin or pin group.
- Port definitions correspond to fixed group definitions. Expression based port definitions are not supported.
- In contrast to pin groups, ports are not associated with a type.
- In spite of this, every port can be used as a pin group. Accordingly, ports can be specified in every command that can be executed for a pin group[1)](<#_110691__fn_exception>).

The command will be executed for all (but only) those pins of the port whose type fits the command.

- Ports can also be used as pin groups in expression based pin group definitions[1)](<#_110691__fn_exception>).
- Like pin groups, ports cannot contain pins assigned to analog instruments and DPS channels.
