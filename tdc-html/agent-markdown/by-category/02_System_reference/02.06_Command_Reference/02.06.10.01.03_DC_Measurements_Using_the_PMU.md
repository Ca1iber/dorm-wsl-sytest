# DC Measurements Using the PMU

 You can use the following low level PMU commands that define and execute a sequencer program for pin PMU measurements so that you can apply individual settings per pin to pin PMUs.

- [MSET, MSET? - (definition of Measurement SET)](<02.06.02.02.164_MSET__MSET__-__definition_of_Measurement_SET.md>) defines a sequencer program for pin PMU measurements.
- [MEAS - (execute a MEASurement set)](<02.06.02.02.160_MEAS_-__execute_a_MEASurement_set.md>) executes a sequencer program defined with the MSET command.
- [MEAR (retrieve MEAsurement Results)](<02.06.02.02.159_MEAR__retrieve_MEAsurement_Results.md>) retrieves and stores the results of the last measurement executed with the MEAS command.
- [PMUR? (read PPMU result)](<02.06.02.02.179_PMUR___retrieve_PPMU_result.md>) retrieves the result of the measurement that is set up and performed with the MSET command.

For DC measurements, it is recommended to use the APIs described in [DC Test Programming](<../02.07_Test_Method_Reference/02.07.03.02_DC_Test_Programming.md>).
