# Pin configuration setup commands

#### Subtopics

- [Concepts of Configuration setup](<02.06.03.01_Concepts_of_Configuration_setup.md>)
- [List of configuration commands](<02.06.03.02_List_of_configuration_commands.md>)
  Configuring pins is the first step you must take when preparing a test. It is impossible to define level, timing, or vector parameters without the pin configuration. The commands for defining a pin configuration can be grouped as follows.

Commands for digital pins: [DFPN](<02.06.02.02.63_DFPN__DFPN__-__DeFine_Pin_Name.md>), [CONF](<02.06.02.02.31_CONF__CONF__-__CONFiguration.md>), [UDEF](<02.06.02.02.295_UDEF_-__UnDEFine_pin.md>)

Commands for mode contexts: [CTXT](<02.06.02.02.35_CTXT__CTXT__-__ConTeXT.md>), [CONF](<02.06.02.02.31_CONF__CONF__-__CONFiguration.md>)

Commands for DPS pins: [DFPS](<02.06.02.02.65_DFPS__DFPS__-__DeFine_Power_Supply.md>), [UDPS](<02.06.02.02.298_UDPS_-__Undefine_DPS_pin.md>)

Commands for DC Scale pins: [DFPN](<02.06.02.02.63_DFPN__DFPN__-__DeFine_Pin_Name.md>), [UDEF](<02.06.02.02.295_UDEF_-__UnDEFine_pin.md>), [DFPS](<02.06.02.02.65_DFPS__DFPS__-__DeFine_Power_Supply.md>), [UDPS](<02.06.02.02.298_UDPS_-__Undefine_DPS_pin.md>), [PSSL](<02.06.02.02.196_PSSL__PSSL___Power_Supply_Safety_Limits.md>)

Commands for utility lines: [DFUT](<02.06.02.02.70_DFUT__DFUT__-__DeFine_UTility_line.md>), [UDUT](<02.06.02.02.302_UDUT_-__UnDefine_UTility_line.md>), [DFUP](<02.06.02.02.69_DFUP__DFUP__-__DeFine_Utility_Purpose.md>), [UPAS](<02.06.02.02.304_UPAS__UPAS__-__Utility_Purpose_ASsignment_for_multi-site.md>), [UDUP](<02.06.02.02.301_UDUP_-__UnDefine_Utility_Purpose.md>)

Commands for utility DC pins: [CONF](<02.06.02.02.31_CONF__CONF__-__CONFiguration.md>), [DFPN](<02.06.02.02.63_DFPN__DFPN__-__DeFine_Pin_Name.md>), [PALS](<02.06.02.02.173_PALS__PALS__-__Pin_ALlocation_for_multiple_Sites.md>)

Commands for pin groups and ports: [DFGP](<02.06.02.02.60_DFGP__DFGP__-__DeFine_GrouP.md>), [UDGP](<02.06.02.02.296_UDGP_-__UnDefine_GrouP.md>), [DFPT](<02.06.02.02.66_DFPT__DFPT__-__DeFine_PorT.md>), [UDPT](<02.06.02.02.299_UDPT_-__UnDefine_PorT.md>)

Commands for pin alias: [DFPR](<02.06.02.02.64_DFPR__DFPR__-__DeFine_Pin_Role.md>), [UDPR](<02.06.02.02.297_UDPR_-__UnDefine_Pin_Role.md>)

Commands for multi-site setups: [PACT](<02.06.02.02.171_PACT__PACT__-__Parallel_ACTivities_control.md>), [PALS](<02.06.02.02.173_PALS__PALS__-__Pin_ALlocation_for_multiple_Sites.md>), [PQFC](<02.06.02.02.180_PQFC__PQFC__-__Parallel_Query_FoCus.md>), [PSFC](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>), [PSTE](<02.06.02.02.199_PSTE__PSTE__-__Parallel_SiTe_Enable.md>), [STME](<02.06.02.02.250_STME__STME__-__SiTe_Match_Enable.md>)

 Note The firmware does not accept any configuration changes while a test is running.

An example of a pin configuration file is given in [Pin Configuration Example](<02.06.03.01.12_Pin_Configuration_Example.md>).
