# Min

 Note There are no Min or Max keywords for the Hex32List.

To query the minimum value in the list the syntax is:

DDEF? "ListName","Min"

## Example

If list A is defined as:

```
DDEF "A",SET,"Equation","Loop(1,10,10)"
```

then `DDEF? "A","Min"` will return:

```
DDEF "A",DATA,"Min",1
```
