# DCUD - (Device Cycle UnDefine)

The DCUD command undefines (deletes) the specified device cycle from the device cycle table. The command has no influence on the waveform table or on the physical waveform table.

## Syntax

```
DCUD {waveform_set},{"dev_cyc_name"},{(pinlist)}
```

## Parameters

 |

waveform_set

 |

Waveform Set Number. Enter an integer in the range 1 to the maximum number of allowed waveform sets. The maximum number is determined by [WSUS, WSUS? - (Waveform Sets USed)](<02.06.02.02.342_WSUS__WSUS__-__Waveform_Sets_USed.md>).

 |
 |

dev_cyc_name

 |

The device cycle name. Enter a string of up to 16 alphanumeric characters (upper or lower case) enclosed in double quotes. Enter ALL for the removal of all device cycles from the device cycle table.

 |
 |

pinlist

 |

The name of the pin or pins for which device cycle definitions are to be deleted. This parameter can also include groups previously created by the [DFGP](<02.06.02.02.60_DFGP__DFGP__-__DeFine_GrouP.md>) (DeFine GrouP) command. The symbol @ can be used to specify all configured pins. If more than one pin is to be included, the names must be separated with a comma.

 |

## Application

Timing Setup, see [Timing Setup Commands](<02.06.06_Timing_Setup_Commands.md>).

## Errors

An error is generated if:

- waveform_set is greater than the range allowed by the WSUS command.
- You enter an illegal device cycle name (a reserved name, a name containing illegal characters).

## Example

```
DCUD 1,"WRITE"
```

This example deletes the device cycle `WRITE` for waveform set 1 from the device cycle table.

## Functional changes

- Introduced before SmarTest 6.3.2
