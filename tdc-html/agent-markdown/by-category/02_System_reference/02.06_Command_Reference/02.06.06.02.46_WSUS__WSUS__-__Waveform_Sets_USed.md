# WSUS, WSUS? - (Waveform Sets USed)

The WSUS (Waveform Sets USed) command sets the number of defined waveform sets to the given value. The new value has to be an integer in the range of 1 to Maximum allowed waveform sets as set by [DSCP, DSCP? - (Define System Control Parameter)](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) (the default is 16, the maximum is 16).

You can use the WSUS command to delete sets. If the timing setup file that you want to load to hardware contains more waveform sets than you require, you can use the WSUS command to delete all the sets above the number you specify.

The WSUS? query returns the number of waveform sets currently defined.

## WSUS

```
WSUS {waveform_set}
```

## WSUS?

```
WSUS?
```

returns:

```
WSUS {waveform_set}
```

## Parameters

 |

waveform_set

 |

Waveform set number. This is the highest number currently allocated to a waveform set or the highest number of a set you want to load. The number you enter must not exceed the maximum number of waveform sets allowed (defined by the [DSCP](<02.06.02.02.90_DSCP__DSCP__-__Define_System_Control_Parameter.md>) command).

This number is automatically updated to include any new waveform set as it is created. At power-on, only one waveform set (containing one timing set and default values) is available.

 |

## Application

Timing setup, see [Timing Setup Commands](<02.06.06_Timing_Setup_Commands.md>).

## Errors

An error is generated if:

- waveform_set is greater than the range allowed by the DSCP command.
- waveform_set is smaller than one.

## Example

```
WSUS 3
```

This example sets the number of used waveform sets to 3.

## Functional changes

- Introduced before SmarTest 6.3.2
