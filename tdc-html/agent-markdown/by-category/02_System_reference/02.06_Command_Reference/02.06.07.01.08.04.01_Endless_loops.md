# Endless loops

An endless loop is started with the LBGN (Loop BeGiN) instruction. The end of the loop section is marked by the LEND (Loop END) instruction.

`LBGN`

[..]

`LEND`

To break out of an endless loop, force a break with the BRK parameter of the [SQST](<02.06.02.02.241_SQST__SQST__-__SeQuencer_STate.md>)[ (SeQuencer STate)](<02.06.02.02.241_SQST__SQST__-__SeQuencer_STate.md>) command.

## Nested loops

Within an [endless loop](<02.06.07.01.08.04.01_Endless_loops.md>) or within a counted loop you can nest counted loops and [repeated subroutines](<02.06.07.01.08.05.02_SVEC_subroutines.md>).

Note You must not nest an endless loop within any loop structure. Endless loops are only allowed as the most outer loop.

Nesting is limited to seven nested levels.

## Example

### Endless loop

```
SQPG 7,LBGN,,,,(@)
SQPG 8,GENV,7,,,(@)
SQPG 9,LEND,,,,(@)
```

The sequence repeats the [GENV](<02.06.07.01.07.03.01_Inserting_a_sequencer_instruction.md>) instruction in command line 8.
