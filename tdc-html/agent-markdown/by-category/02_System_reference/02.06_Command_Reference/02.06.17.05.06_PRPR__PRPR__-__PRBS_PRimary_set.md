# PRPR, PRPR? - (PRBS PRimary set)

PPPR defines the primary PRBS set. This is the set that will actually be be used for testing. If no user defined set has been specified, a predefined polynomial and a predefined seed will be used. You can also switch from a user defined set back to the default by specifying an empty name. TTPR? returns the current primary set.

## PRPR

PRPR {"prbs_set_name"|DEFAULT}

## PRPR?

PRPR?

returns:

```
PRPR {"prbs_set_name"}
```

## Parameters

 |

prbs_set_name

 |

Specifies the name of an existing PRBS set. If you specify "", the defaults will be restored.

 |

## Application

PRBS test.

## Errors

An error is generated if no PRBS set with the specified name exists.

## Example

```
> PRPR   "PRBS_set"
```

## Functional changes

- Introduced in SmarTest 7.0.1
