# SPGV - (SPlit Generate Vectors)

The SPGV (SPlit Generate Vectors) command splits the sequencer construct at the logical vector number vec_No. The sequencer construct must be of type GENV, see [SQPG, SQPG? - (SeQuencer ProGramming)](<02.06.02.02.237_SQPG__SQPG__-__SeQuencer_ProGramming.md>). The vec_No must not be the first vector of a sequencer construct. The SPGV command can only be issued after a label has been selected for editing with the [TSTL](<02.06.02.02.281_TSTL__TSTL__-__TeST_Label.md>) command.

The GENV construct is split into two new GENV constructs. The sum of the active vectors of both constructs equals the active vectors of the original construct. vec_No is the first vector of the second GENV construct.

Inactive vectors are inserted for both new GENV constructs as needed.

## Syntax

```
SPGV {vec_No}
```

## Parameters

 |

vec_No

 |

The logical vector number at which a GENV sequencer construct is to be split.

 |

## Application

Edit command in vector setup, see [Vector Setup Commands](<02.06.07_Vector_Setup_Commands.md>).

## Errors

An error is generated if:

- There is insufficient channel memory.
- There is insufficient disk space (offline operation only).
- No label has been activated for editing.
- The vectors have been generated by a sequencer instruction other than GENV. See [SQPG, SQPG? - (SeQuencer ProGramming)](<02.06.02.02.237_SQPG__SQPG__-__SeQuencer_ProGramming.md>).
- vec_No is the first vector number of a GENV sequencer construct.
- vec_No is zero.

## Example

```
> SQPG? ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,16,,,(@)
< SQPG 3,RPTV,6,5,,(@)
< SQPG 4,STOP,,,,(@)
< SQPG 5,STVA,528,,,(@)
< ...
> SPGV 7
> TSTL "test_1",(@)
> SQPG ALL,(@)
< SQPG 0,STVA,504,,,(@)
< SQPG 1,STSA,,,,(@)
< SQPG 2,GENV,7,,,(@)
< SQPG 3,GENV,9,,,(@)
< SQPG 4,RPTV,6,5,,(@)
< SQPG 5,STOP,,,,(@)
< SQPG 6,STVA,536,,,(@)
< ...
```

This example splits a GENV sequencer construct at command number 2 before vector 7. Note the adjustment of the start address in command 6.
