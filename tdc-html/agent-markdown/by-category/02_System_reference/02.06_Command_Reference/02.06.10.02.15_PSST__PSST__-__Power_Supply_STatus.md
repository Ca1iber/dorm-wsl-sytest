# PSST, PSST? - (Power Supply STatus)

The PSST (Power Supply STatus) command allows you to switch the DPS on and off for selected pins. The PSST? query reads its current state.

With this command you configure setups of those sites that have the setup focus: For more information, see also: [PSFC, PSFC?](<02.06.02.02.191_PSFC__PSFC__-__Parallel_Setup_FoCus.md>).

With this command you can retrieve site specific information (only one site can be in focus at a time). For the site in focus, SmarTest displays results in the Testflow Editor and in the result tools. Also, any firmware queries report setup and results for the site currently in focus only.

## PSST

```
PSST {state} [, (pinlist)]
```

## PSST?

```
PSST?  [(pinlist)]
```

returns:

```
PSST {state} [, (pinlist)]
```

## Parameters

 |

state

 |

The device power supply state:

 |
 |

 |

ON

 |

Switches the DPS on.

 |
 |

 |

OFF

 |

Switches the DPS off.

 |
 |

pinlist

 |

Specifies the pins for which the DPS is switched on/off.

 |

## Application

Connect and disconnect the test system, see [Relays Control Commands](<02.06.08_Relays_and_Control_Commands.md>).

DC Tests, see [DC Measurement Commands](<02.06.10_DC_Measurement_Commands.md>).

The status of the DPS when switched ON/OFF is specified with the [PSLV](<02.06.02.02.195_PSLV__PSLV__-__Power_Supply_LeVel.md>) command. The output impedance of each channel becomes either HIZ_R, HIZ, or LOZ, as specified in the currently active DPS set. Specifying HIZ_R as OFF impedance makes PSST substantially slower.

If the connect_state is ungang (see [PSLR, PSLR? - (Power Supply Level Ranges)](<02.06.02.02.194_PSLR__PSLR__-__Power_Supply_Level_Ranges.md>) and [DPSPINS resources](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>)), PSST connects only those channels of a gang, which are necessary to supply the device with the required current.

Switching the DPS status resets the accumulated status of the DPS. See [PSAS? - (Power Supply Accumulated Status)](<02.06.02.02.188_PSAS__-__Power_Supply_Accumulated_Status.md>).

## Errors

An error is generated if:

- You try to use the PSST or PSST? commands offline.
- A communication error with the DPS occurs.

## Warnings

A warning is generated if the specified voltage is not reached in 10 s.

## Examples

### Example 1

```
PSST ON
```

This example turns the DPS on.

### Example 2

The following example shows the use of the PSST command in conjunction with multisite:

```
PSFC ALL ; PSST ON   # turn on all supplies of all sites

PSFC "01"              # focus on one site only of the dual-site

PSST OFF,(vcc)         # turn off vcc of one site only!
PQFC 1 ; PSST? (vcc)   # these last two commands return different
PQFC 2 ; PSST? (vcc)   # answers, since one site should have vcc
                       # connected, whereas the other site does not
```
