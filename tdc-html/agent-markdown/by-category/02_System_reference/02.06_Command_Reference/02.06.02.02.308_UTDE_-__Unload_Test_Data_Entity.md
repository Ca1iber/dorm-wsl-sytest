# UTDE - (Unload Test Data Entity)

The UTDE command lets you unload a test data entity (TDE) that has been loaded using the [LTDE](<02.06.02.02.157_LTDE__LTDE__-__Load_Test_Data_Entity.md>) command.

## Syntax

```
UTDE "<file_name>" | ALL
```

## Parameters

 |

file_name

 |

The file name of the protocol test data entity (TDE) to unload.

The specified TDE must belong to the directory specified with the [PTDE](<02.06.02.02.200_PTDE__PTDE__-__Path_for_Test_Data_Entities.md>) `` command.

 |
 |

ALL

 |

Unloads all test data entities.

Only test data entities belonging to the directory specified with the [PTDE](<02.06.02.02.200_PTDE__PTDE__-__Path_for_Test_Data_Entities.md>) `` command will be unloaded.

 |

## Example

```
UTDE "test.prot_asg"
```
