# Twinning Wave Scale RF requirements

For Wave Scale RF applications of SmarTest 8, it is necessary to provide 2 cut-outs on the Twinning family board

The cut-out regions are shown in red in the figure below.

![Cut-outs on the Twinning Family board for Wave Scale RF](<../../../../raw/345692.jpg>)

This will create limitations on the available routing and component space in the Twinning family board. For more details on the family board layout, see [Twinning DUT and family board info](<02.03.12.01.19_Twinning_DUT_and_family_board_info.md>).

## Functional changes

- Introduced in SmarTest 8.2.0
