# Utility line assignments - HSM systems

Utility lines are provided by clock boards. All lines have both read and write capabilities. Each utility block contains 16 utility lines (00 to 15).

 Note The software references utility lines as 01 to 16.

The figure below shows the layout of utility and DPS blocks for the various combinations of test heads and DUT interfaces.

  ![Layout of utility and DPS blocks on DUT interfaces](<../../../../raw/53067.png>)

Details of utility pogo mapping and the mapping of pins on a utility pogo block for various combinations of test head and DUT interface are available by following the relevant link below.

All eight utility blocks (in eight groups) are available on:

- the [Large Test Head (with the large DUT interface)](<02.03.06.08.03_Utility_pogo_block_-_LTH_large_DUT_interface.md>)

Four utility blocks UTIL 1, 2, 3 and 4 (in four groups) are available on:

- the [Compact Test Head with the small DUT interface](<02.03.06.08.08_Utility_pogo_block_-_CTH_small_DUT_interface.md>)

The ground pins of the utility blocks (UGND) can be connected to the DUT board grounds (DGND, AGND) without impacting the level accuracy or introducing noise.

 Note Utility lines are not affected by standard connect/disconnect sequences. They are controlled by dedicated firmware commands and test methods. This allows a utility line to assume a steady state before a testflow takes control and to remain in this state after test execution has been completed.
