# GP-DPS capacitor requirements

#### Subtopics

- [GP-DPS load capacitors](<02.03.08.02.01.01.01_GP-DPS_load_capacitors.md>)
- [GP-DPS filter capacitors](<02.03.08.02.01.01.02_GP-DPS_filter_capacitors.md>)
- [GP-DPS performance ranges](<02.03.08.02.01.01.03_GP-DPS_performance_ranges.md>)
- [GP-DPS capacitor precautions](<02.03.08.02.01.01.04_GP-DPS_capacitor_precautions.md>)

There are two basic types of capacitors that can be used for the GP-DPS channels of the V93000 test system: [Load Capacitors](<02.03.08.02.01.01.01_GP-DPS_load_capacitors.md>) which stabilize the DPS operation and prevent voltage drops, and [Filter Capacitors](<02.03.08.02.01.01.02_GP-DPS_filter_capacitors.md>)  which filter noise-related signals from the DPS pins.

## Functional changes

- Introduced before SmarTest 6.3.2
