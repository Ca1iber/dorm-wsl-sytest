# Utility Lines - HSM systems

#### Subtopics

- [Utility line assignments - HSM systems](<02.03.08.05.01.03.01_Utility_line_assignments_-_HSM_systems.md>)
- [Utility line characteristics - HSM systems](<02.03.08.05.01.03.02_Utility_line_characteristics_-_HSM_systems.md>)

Using utility lines, you can control or read states of external devices such as relays, EEPROMS and indicators on a DUT board.

Utility lines are provided by the clock boards and can be controlled by dedicated firmware commands, routing sets or test methods.

Utility ground is isolated from system ground to avoid injecting noise generated by switching relays and other devices into the test system. You can also add filters to reduce noise, see [Reducing noise on utility lines](<02.03.04.03.02_Reducing_noise_on_utility_lines.md>) for details.

The DUT interface has 8 utility pogo blocks on the Large Test Head and 4 utility pogo blocks on the Compact Test Head, refer to [Utility line assignments - HSM systems](<02.03.08.05.01.03.01_Utility_line_assignments_-_HSM_systems.md>) for more information.
