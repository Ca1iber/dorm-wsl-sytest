# Step 4: Probe Needles planarity measurement

This topic describes the Direct Probe needle planarity and how to adjust it if required.

## About this task

Probe Card Analyzer is used to measure the planarity of the Probe card needle.

The Probe Needles planarity depends on Probe Card technology, Probe array size, Probe needle type.

The Probe Needles planarity is defined by Probe Card vendor.

## Before you begin

Make sure that you already adjusted the backer height of the probe card assembly according to the description in [Step 3: Backer height measurement](<02.03.11.01.03.05.03_Step_3__Backer_height_measurement.md>).

## Procedure

-  Measure Probe needles planarity via Probe Card Analyzer.
-  If planarity is out of specification, adjust Probe Head if possible and do the measurement on the Probe Card Analyzer again.

![Probe needle planarity](<../../../../raw/354887.png>)

-  If Probe Head adjustment is not possible, do the Probe Needle adjustment via Shims underneath the Contact Tabs and repeat the measurements of [Step 2: Contact Tab planarity measurement of complete Probe Card](<02.03.11.01.03.05.02_Step_2__Contact_Tab_planarity_measurement_of_complete_Probe_Card.md>) and [Step 3: Backer height measurement](<02.03.11.01.03.05.03_Step_3__Backer_height_measurement.md>).

## Results

You have completed the verification and adjustment procedure of the Direct Probe Card.
