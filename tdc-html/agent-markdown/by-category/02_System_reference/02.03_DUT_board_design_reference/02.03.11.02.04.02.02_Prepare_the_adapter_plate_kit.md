# Prepare the adapter plate kit

## About this task

This task is about preparing the Port Scale RF adapter kit by connecting the RF cables to the correct locations.

## Before you begin

Ensure you have the adapter plate kit and RF cables available.

## Procedure

-  Preparing the Adapter Plate Kit

  -  Connect RF cables to the Port Scale RF Adapter Plate Kit for 12" auto probe card changer.
  -  Remove nut from male SMP RF connector (N2398A-001) and attach to probe card adapter plate kit (N2398A).
  -  Using the DUT Ring allocation drawing shown in the next picture insert the nut into the appropriate hole in the RF adapter plate on the tester side and press it home.
  -  Make sure the arrows on the adapter plate kit (test head orientation) align with those on the drawing.  ![RF interface layout for FE12 cards (RF interface upside down)](<../../../../raw/96059.png>)   ![Preparing the Adapter Plate Kit](<../../../../raw/103238.jpg>)   ![Preparing the Adapter Plate Kit cont...](<../../../../raw/103239.jpg>)

-  Insert RF cables from the probe card side. Make sure the flange is flush with the surface of the ring. Screw on the nut using the thread-on tool making sure it is hand tight. See also [12" Wafer Prober Interface Parts List](<02.03.11.02.04.02.08_12__Wafer_prober_interface_parts_list.md>).  ![Insert RF cable on the probe card side](<../../../../raw/103240.jpg>)  Note The thread-on tool shown in the next picture is part of the wafer prober interface package. ![Thread-on tool](<../../../../raw/103241.jpg>)
-  Insert the female connector of the RF cable into the appropriate hole in the adapter ring of the RF adapter plate kit.  ![Insert the female connector on the RF cable](<../../../../raw/103242.jpg>)

## What to do next

Link the adapter plate kit and the pogo tower.
