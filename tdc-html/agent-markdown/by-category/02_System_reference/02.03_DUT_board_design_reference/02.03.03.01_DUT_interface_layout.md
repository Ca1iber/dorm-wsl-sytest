The V93000 test head can be configured with different combinations of different types of cards to meet specific test requirements. Cabling within the test head connects the cards and the infrastructure resources like utility lines and utility power supplies to one or more pogo pin blocks of the DUT interface.

The [POGOCABLING](<../02.04_Model_File_and_Licensing/02.04.01.03.02.02_POGOCABLING_section.md>) section of the model file (SmarTest 7) and the [CARD_CONFIGURATION](<../02.04_Model_File_and_Licensing/02.04.01.03.01.02_CARD_CONFIGURATION_section.md>) section of the tester.model file (SmarTest 8) map the physical card cage location of a card with the corresponding pogo block position of the DUT interface.

## Structure of the DUT interface layout

The DUT interface layout is structured as follows:

- Group 1 鈥?8:The pogo blocks are organized in eight groups, each providing 16 + 2 pogo blocks:

  - Groups 1, 2, 3, and 8 are available on all DUT interfaces.
  - Groups 4, 5, 6, and 7 are available on the large DUT interface and on the DUT Scale interface.

- DPS 1 鈥?8:

  - V93000 Pin Scale and Smart Scale systems (SmarTest 7):

These pogo blocks are reserved for [Pogo pin assignment - DPS-slot device power supplies](<02.03.06.04_Pogo_pin_assignment_-_DPS-slot_device_power_supplies.md>) and the [Internal Utility Power Supply (SE-UDPS)](<02.03.05.07_Internal_Utility_Power_Supply__SE-UDPS___V93000_systems.md>).

  - V93000 Smart Scale systems (SmarTest 8):

These pogo block positions are reserved for future use. The [MS-DPS style pogo blocks](<02.03.06.02.02_DPS128____PS64_pogo_cable_assemblies_and_pogo_pin_assignments.md>) of DPS128/64 and the pogo block of the [Internal Utility Power Supply (SE-UDPS)](<02.03.05.07_Internal_Utility_Power_Supply__SE-UDPS___V93000_systems.md>) may also be installed at these positions.

  - V93000 EXA Scale systems (SmarTest 7.10 and higher and SmarTest 8):

These pogo block positions are reserved for utility pogo blocks of the second optional [Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>). The alternate pogo block numbers 265 鈥?nbsp;272 must be used to define these utility blocks in the DUT board description file.

The pogo block of one [Internal Utility Power Option](<02.03.05.04_Internal_Utility_Power_Option__V93000_EXA_Scale_systems.md>) can be installed at pogo block position DPS 1 if only one optional [Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>) is installed.

- UTIL 1 鈥?UTIL 8:

These are the utility pogo blocks that provide connections to the [Utility lines](<02.03.04_Utility_lines.md>), the [Utility power supplies](<02.03.05_Utility_power_supplies.md>), and some other resources of the V93000 infrastructure.

- S1 and S2 position:

 | ![DUT interface layout - S1 and S2](<../../../../raw/347951.png>)  | Adjacent pogo blocks are sometimes referred as S1 and S2 pogo block. The number of the S2 pogo block is the number of the S1 block plus an offset of 200. |

## Virtual pogo blocks

SmarTest divides physical pogo blocks of more than 16 channels into 16 channel units called logical boards. The first logical board is assigned to the physical pogo block. The other logical boards are assigned to so-called virtual pogo blocks.

 | Group  | Pogo block range  | Usage |
 |

These virtual blocks are used for physical pogo blocks providing more than 16 channels and therefore covering minimum two logical boards. An offset of 400 is to be added to the position of the physical block to obtain the number of the virtual pogo block.
