## Pogo pin description

 | Pin  | Description  |   | DUT board connection |
 | HF#  | High force line of the channel  |   | |
 | HS#  | High sense line of the channel  |   | |
 | LF#  | Low force line of the channel  |   | |
 | LS#  | Low sense line of the channel  |   | |
 | GUARD#  | GUARD line of the HF# and HS# line  |   | |
 | TMU_H#  | TMU high input  |   | |
 | TMU_L#  | TMU low input  |   | |
 | SAFETY1_5V  | Control line of the safety circuit for channel 1 …nbsp;8  |   | Connect to an adequate +5.0 V supply via a safety interlock on the DUT board or the DUT interface. |
 | SAFETY2_5V  | Control line of the safety circuit for channel 9 …nbsp;16 |
 | SAFETY1_GND  | Return line of the safety circuit for channel 1 …nbsp;8  |   | Connect to the return pin of the +5.0 V supply at SAFETY_P and to the DUT board ground. |
 | SAFETY2_GND  | Return line of the safety circuit for channel 9 鈥?nbsp;16 |
 | DNC  | Do not connect pin  |   | These pins are internally used and reserved. Do not connect these pins on the DUT board. |
 | Separation  | Separation row between the channels  |   | To ensure that adjacent high voltage pins or traces have no effect on the DNC pins and Separation rows, adequate measures like sufficient insulation space have to be respected. |

Notes on the pogo pin descriptions:

- Pin: # = Channel 1 鈥?nbsp;16
- The DNC pins are internally connected and reserved. To ensure that adjacent high voltage pins or traces have no effect on the DNC pins, adequate measures like sufficient insulation space have to be respected.CAUTION The force lines "HF#" and "LF#" are each wired to three pogo pins. These three pogo pins must be connected in parallel on the DUT board to ensure that the specifications for the card and the maximum ratings for the pogo pins are met.

## Model file

For SmarTest 7, refer to model file topics [Pogocabling entries for different card types](<../02.04_Model_File_and_Licensing/02.04.01.03.02.02.01_Pogocabling_entries_for_various_card_types.md>) and [DPS Section](<../02.04_Model_File_and_Licensing/02.04.01.03.02.06_DPS_section.md>) for information on how to define the FVI16 pogo blocks in the model file.

 Note Although the sixteen channels of the FVI16 card are physically routed to four pogo blocks, SmarTest assigns all sixteen channels to the first block "A". For more information, refer to section "FVI16 in the model file" in FVI16 specific setup tasks.

## Specific design rules

Specific design rules must be followed when designing a new DUT board and assigning FVI16 channels:

- FVI16 power budget and energy budget: The available power and energy budgets must be considered when assigning FVI16 channels to DUT pins. The available power budget and energy budget on FVI16 cards is defined as follows:

  - The maximum total power budget is 400 W.
  - The maximum total energy budget is 3.2 J[1)](<#fntarg_1>).
  - The two budgets are equally distributed to two channel groups 1 鈥?nbsp;8 and 9 鈥?nbsp;16 providing 200 W and 1.6 J per group.
  - Within the two groups, the budgets are shared by all eight channels.

- [Pin assignment for Fast Sync / Fast Match](<02.03.07.06_Pin_assignment_for_Fast_Sync___Fast_Match.md>): For fast local synchronization, the synchronized DUT pins must be assigned to the same group of channels respectively to the same test processor.
- [HV (High-Voltage) protection](<02.03.08.01.04_DC_Scale_FVI16_card.md#_152671__s_HV_protection>): Since the FVI16 card may be connected to low-voltage cards via defective DUTs or unintentionally closed connections, we recommend that you implement a HV (High-Voltage) protection circuitry on your DUT boards to protect the low-voltage cards.
