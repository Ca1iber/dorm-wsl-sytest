# Pogo pin assignment - Utility power supplies

#### Subtopics

- [Internal Utility Power Option pogo pin assignments (V93000 EXA Scale systems)](<02.03.06.09.01_Internal_Utility_Power_Option_pogo_pin_assignments__V93000_EXA_Scale_sys.md>)
- [Internal Utility Power Supply (SE-UDPS) pogo pin assignments](<02.03.06.09.02_Internal_Utility_Power_Supply__SE-UDPS__pogo_pin_assignments.md>)

Utility power supplies are used to power active components like relays, operational amplifiers, and buffer on the DUT board or probe card. In contrast to device power supplies, the utility power supplies provide fixed voltages and do not provide a programmable clamp current or measurement functionalities.

## Supported V93000 system generations and variants

This section holds the pogo pin layouts for all V93000 system generations and variants. For the supported set of test head cards on your system, refer to [Pogo pin assignment](<02.03.06_Pogo_pin_assignment.md>).

## Utility power supplies routed to utility pogo blocks

This section hold only the pogo pin assignment for utility power supplies that are routed to DPS-slot pogo blocks. The pogo pin assignment for all other utility power supplies that are routed to utility pogo blocks is available in [Pogo pin assignment - Utility pogo blocks](<02.03.06.08_Pogo_pin_assignment_-_Utility_pogo_blocks.md>).
