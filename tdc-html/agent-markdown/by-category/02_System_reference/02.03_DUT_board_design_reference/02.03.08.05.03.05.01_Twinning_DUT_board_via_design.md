# Twinning DUT board via design

Via design for the Twinning DUT board is equivalent to the standard V93000 DUT board via design as described in [Pogo via examples](<02.03.07.07.03_Pogo_via_examples.md>). For the DUT board the top pad can be made arbitrary small as on the standard V93000 DUT board. The signal and ground pin assignments will be defined by the design used on the Twinning family board.

It is recommended for the Twinning DUT board design, that any unused pogo locations should still have a 56 mil bottom pad without any via, even if that location is not loaded with a pogo segment. The reason is to prevent the pogo pins from getting contaminated by pressing into non-metalized PCB board surfaces, should a segment be added on that location in the future (for example for a new application).
