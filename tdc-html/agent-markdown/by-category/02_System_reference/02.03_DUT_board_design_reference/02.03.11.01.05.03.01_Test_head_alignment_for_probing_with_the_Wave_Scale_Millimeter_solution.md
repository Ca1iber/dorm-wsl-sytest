# Test head alignment for probing with the Wave Scale Millimeter solution attached

To allow accurate docking even with the WSMM solution, the test head planarity must be ≤ 0.1° in reference to the prober's planarity. This ≤0.1° translates in ≤1mm (~ 0.04 inches) difference over the test head.

## About this task

The following procedure describes how to measure the planarity of the test head with a WSMM solution docked to it.

## Before you begin

 ![Preparations](<../../../../raw/344355.svg>)Preparations:

- Leveling the CTH or Leveling the STH
   ![Tools](<../../../../raw/344358.svg>)Tools:

![spirit level](<../../../../raw/113021.png>) Electronic spirit level with an accuracy of 0.5 mm/m (± 1/32 in @ 72 in) to check the leveling.

## Procedure

-  Turn the test head with the WSMM solution docked to it into probing position.
-  Move the test head over the head plate so it can be lowered towards the prober later on as shown below.  CAUTION

Accidental collision of objects.

Unconcerned diagonal movement of a Wave Scale Millimeter solution over a Wave Scale Millimeter DUT board can make the docking pins of the hard docking spacers collide, and damage both the Wave Scale Millimeter solution and the Wave Scale Millimeter DUT board.

When moving a Wave Scale Millimeter solution in parallel to a Wave Scale Millimeter DUT board provide sufficient clearance. Always approach a Wave Scale Millimeter solution to a Wave Scale Millimeter DUT board orthogonal to the Wave Scale Millimeter DUT board's surface only.

    ![Test head positioned above the prober head plate](<../../../../raw/349674.png>)
-  Using X- and Y-movement of the test head, position the test head above the prober head plate so hard docking cylinders and coarse alignment pins will exactly match later on. See the figures below.    ![Aligning the front hard docking pin with the cylinder](<../../../../raw/349675.png>)     ![Aligning the rear hard docking pins with the cylinders](<../../../../raw/349676.png>)
-  Following steps will help to verify test heads partiality with the prober head plate/stage. Use the direct probe bridge beam as reference. If not present, use the head plate/stage as reference.   Note Make sure not to interfere with the covers on the head plate/ stage.    ![Level 1](<../../../../raw/355506.png>)
-  After the reference is set, next step is to measure it across the WSMM. While measuring across the WSMM, make sure to measure above the WSMM card cage handle.   Note Make sure not to measure on any sheet metal or covers.   Note If the WSMM is outside the target requirement (鈮?0.1°), adjust the level with the manipulator footing specified in Leveling the CTH or Leveling the STH. Repeat this step until the planarity target is achieved.

![Level 2](<../../../../raw/355507.png>)

-  For second check, use the bridge beam as reference. If not present, use the head plate/stage as reference.   Note Make sure not to interfere with the covers on the head plate/ stage.

![Level 3](<../../../../raw/355508.png>)

-  After the reference is set, next step is to measure it across the WSMM. While measuring across the WSMM, make sure to measure on top of the soft docking hooks of the WSMM card cage. Make sure to touch the hooks with the biggest possible surface of the spirit level.   Note Make sure not to measure on any sheet metal or covers.   Note If the WSMM is outside the target requirement (鈮?0.1°), adjust the level with the manipulator footing specified in Leveling the CTH or Leveling the STH. Repeat this step until the planarity target is achieved.

![Level 2](<../../../../raw/355509.png>)

## Results

You have aligned the test head with the docked WSMM solution. It can now be hard docked to the prober.
