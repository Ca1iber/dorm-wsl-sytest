# High Voltage DPS (HV-DPS)

The High Voltage DPS differs from the General Purpose DPS in that it delivers a supply voltage ranging from 0.5 V to 22 V and a maximum current of 1 A.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : Smart Scale (SmarTest 7), Pin Scale |

As with the General Purpose DPS, four channels (power supply modules) per board are provided and can be connected in parallel (ganged) if needed for higher currents. The High Voltage DPS is also operated in one of four performance ranges and the same minimum load capacitor per range is required for stable operation (see [GP-DPS performance ranges](<02.03.08.02.01.01.03_GP-DPS_performance_ranges.md>)).

## Pin assignment

See [General Purpose DPS (GP-DPS) pogo pin assignments](<02.03.06.04.01_General_Purpose_DPS__GP-DPS__pogo_pin_assignments.md>) for pin assignment.

## Vbump for GP-DPS and HV-DPS

When using the Vbump feature keep the following in mind:

- The trigger pin is connected to VB+.
- TRVB- must be connected to digital ground (DCOM) via the DUT board.

See also Switching DPS Voltages (Vbump).
