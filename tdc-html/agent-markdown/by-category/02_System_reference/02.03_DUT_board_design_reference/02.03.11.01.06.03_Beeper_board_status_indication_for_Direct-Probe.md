# Beeper board status indication for Direct-Probe

## Beep codes

The following beep codes might occur:

- Slow continuous (about one beep within about 0.8s):

Test head is moving.

- Two beeps within about 0.4s:

Operation prohibited (usually indicates an accidental misuse, but might be suspended by the override key)

- Four beeps within about 0.4s:

Remote control is disabled. Disconnect the remote control and re-connect it to the replacement connector (for example, provided by the final-test manipulator extension).
