# Precision Parallel Source

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : HSM |

The Precision Parallel Source (PPS) is a voltage source designed for static tests on analog-to-digital converters. One PPS module has two identical static voltage sources. Each voltage source has eight buffered outputs.

Each voltage source can force a constant voltage, or force a ramp or arbitrary voltage pattern that consists of up to 64,000 voltage steps. Each time the voltage source receives a trigger from the trigger input pin, it forces the next voltage step in the respective voltage pattern. Generally, you will connect a digital channel to the trigger input pin of the PPS to trigger the voltage source.

The two voltage sources in a PPS module are independent instruments, however, they share one trigger signal input pin.

The PPS module is installed in one of the card cage slots in the test head normally used for a digital module (typically, in slot 8 or 4 of group 8).

Specifications for PPS Pins

Output pins:

- Max. output current: 15 mA (each output pin)
- Output resistance: =< 1 Ohm
- Analog band width: 50 kHz

Trigger pin:

- External trigger level: 0.6 V
- External trigger input range: 0 V to 5 V
