# Link Scale USB3 card

 The Link Scale USB3 card supports software-based functional tests and high鈥憇peed I/O (HSIO) scan tests using the USB protocol. A matrix in the front鈥慹nd of the card supports also routing signals of other DUT board resources to the DUT.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : Smart Scale (SmarTest 8)   |  Some specific rules are to be considered for the high鈥憇peed signal paths such as "USB Super Speed" and "USB High Speed" signals when designing a DUT board for the Link Scale USB3 card. The related signals are to be routed as differential pairs:

- "USB_HSp" and "USB_HSn"
- "USB_SSTXp" and "USB_SSTXn"
- "USB_SSTXp" and "USB_SSTXn"

See also section [Pogo pin description](<02.03.06.03.11_Link_Scale_USB3_pogo_pin_assignment.md#_353563__s_Pogo_pin_description>) in [Link Scale USB3 pogo pin assignment](<02.03.06.03.11_Link_Scale_USB3_pogo_pin_assignment.md>).

Specific rules for the high鈥憇peed signal paths:

-  General design:

  - The differential impedance of the traces should be 100 惟.
  - Use loosely coupled differential pairs.

-  Traces:

  - The maximum length of traces is 12 inches.
  - The width of traces should be 6 鈥?nbsp;8 mils.
  - Outside of the DUT socket and pogo pin area, use a spacing of approximately 2.5 x the width of the traces.
  - There is no need to tightly couple the legs.

- Signal path options:

  - Use a maximum of one 0402 or 0201 type "0 惟" resistor in the path from the pogo pin to the DUT.
  - Unpopulated pads in transmission lines must be designed in such a way that they have a minimal effect on the impedance.

- Signal path vias:

  - Use maximum four vias. This includes also the vias at the pogo pin and the DUT socket.
  - Stubs should be shorter than 10 mil.

- Loss Budget:

  - Design goal is < 6dB loss @ 5 GHz.

- AC coupling:

  - All required AC coupling capacitors are already integrated in the front-end of the OCST card.
  - Do not install AC coupling capacitors in SuperSpeed lines on the DUT board.

AC coupling capacitors on the DUT board prevent DC measurements via the matrix in the front鈥慹nd of the card.
