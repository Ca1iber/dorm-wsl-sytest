# GP-DPS performance ranges

Use the table below to find the appropriate GP-DPS performance range and capacitive load. The capacitive load is the sum of all capacitors used on one DPS channel. The current swings shown are maximum values within which the power supply ripple will not exceed 200 mV. They do not, however, represent the only current swings permissible for a particular range. Ranges 2, 3, and 4 can all drive current swings up to 8 A; performance range 1 can drive current swings up to 3 A.

As an example, performance range 1 could handle an expected current swing of 150 mA. However, to ensure that voltage ripple is below 200 mV, use performance range 2 with a capacitive load of 4 碌F.
