# Test heads - HSM systems

The V93000 comes equipped with one of the following test heads:

- Compact test head with up to 512 pins with Pin Scale 3600 series cards
- Large test head with up to 2048 pins with Pin Scale 3600 series cards

A large test head consists of eight card cages and a compact test head consists of two card cages.

For a detailed description of the V93000 test head, refer to the Memory test cards user guide of SmarTest 7.

## Default configuration

The default configurations are as follows:

- Two card cages, both digital and analog, for the compact test head
- Seven digital card cages and one analog card cage for the large test head

Each card cage can be equipped with channel electronics, power supply, and control boards. For more information see section Test heads - HSM systems in the Memory test cards user guide of SmarTest 7.
