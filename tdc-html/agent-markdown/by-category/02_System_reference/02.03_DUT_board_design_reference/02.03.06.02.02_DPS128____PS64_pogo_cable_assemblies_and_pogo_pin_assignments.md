The DPS128 and the DPS64 cards are members of the family of DC Scale power supplies and can reside in any I/O channel card slot. The various pogo cable assemblies supported by the DPS128/DPS64 ensure DUT board compatibility with the DPS32 and the MS-DPS power supplies.

Each of the channels can source and sink current at a programmed voltage, and each channel can measure the voltages and currents supplied. The maximum source/sink current per channel is 1 Amp. The maximum source/sink current per card is 64/52 Amp.

## Specific design rules

 Specific design rules must be followed when designing a new DUT board for the DPS128/DPS64:

- [DPS128/DPS64 power budget](<../02.05_Test_Head_Cards/02.05.05.01.05_DPS128____PS64_power_budget.md>): The DPS128/DPS64 card features two power domains with a dedicated power budget. Each domain is able to deliver half of the overall power budget. The power domain to channel mapping must be observed for DPS128 cards when assigning the available channels to the DUT pins.
- [DPS128 / DPS64 capacitor requirements](<02.03.08.01.02.01_DPS128___DPS64_capacitor_requirements.md>): For improved noise suppression, we recommend using small ceramic capacitors. Additional capacitor requirements must be considered for ganged channels
- [DPS128 / DPS64 recommendations for use](<02.03.08.01.02.02_DPS128___DPS64_recommendations_for_use.md>): For safe handling of the DPS128 / DPS64 card and getting out the best performance follow the recommendations for designing the DUT board and setting up the test.
- [Pin assignment for Fast Sync / Fast Match](<02.03.07.06_Pin_assignment_for_Fast_Sync___Fast_Match.md>): For fast local synchronization, the synchronized DUT pins must be assigned to the same group of channels respectively to the same test processor.
