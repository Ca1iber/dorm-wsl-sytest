# E8023PE pogo cable assembly: 8 MS-DPS style pogo blocks (DPS128-HC only)

The E8023PE pogo cable assembly connects the DPS128-HC via eight MS-DPS style pogo blocks to the DUT board. This pogo cable assembly is the standard solution for the reuse of existing MS-DPS based setups with the DPS128-HC card. It gangs two card channels to one channel on the pogo block side.

## Pogo cable assembly data

 | Overall length:  | 850 mm |
 | Pogo block style:  | MS-DPS |
 | Pogo blocks:  | 8 |
 | Channels per pogo block:  | 8 |
 | DPS128 channels per 1 channel on pogo block:  | 2 |
 | Total number of channels on pogo block level:  | 64 |
 | Max. current per channel on pogo block level:  | 2A  |  ![Drawing_E8023PE](<../../../../raw/141887.png>)

Two DPS128-HC channels are ganged in the pogo block and routed as one channel.

 ![Pogo ganging E8023Px](<../../../../raw/141747.png>)

## DPS128 power budget

The DPS128/DPS64 card features two power domains with a dedicated power budget. Each domain is able to deliver half of the overall power budget. The power domain to channel mapping must be observed for DPS128 cards when assigning the available channels to the DUT pins. For more information refer to [DPS128/DPS64 power budget](<../02.05_Test_Head_Cards/02.05.05.01.05_DPS128____PS64_power_budget.md>).
