# Utility lines (V93000 EXA Scale systems)

Utility lines allow you to control external devices such as relays, solenoids or indicators, depending on the application.

The utility line configuration and characteristics of V93000 EXA Scale systems is defined in this section. For the utility line configuration and characteristics of V93000 Pin Scale and Smart Scale systems, refer to [Utility lines (V93000 systems)](<../02.02_Specifications/02.02.02.04.01_Utility_lines__V93000_systems.md>).
