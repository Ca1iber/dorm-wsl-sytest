# E8023PG pogo cable assembly: 4 MS-DPS style pogo blocks (DPS64 only)

The E8023PG pogo cable assembly connects the DPS64-HC via four MS-DPS style pogo blocks to the DUT board. This pogo cable assembly is the standard solution for the reuse of existing MS-DPS based setups with the DPS64-HC card. It gangs two card channels to one channel on the pogo block side.

## Pogo cable assembly data

 | Overall length:  | 850 mm |
 | Pogo block style:  | MS-DPS |
 | Pogo blocks:  | 4 |
 | Channels per pogo block:  | 8 |
 | DPS64 channels per 1 channel on pogo block:  | 2 |
 | Total number of channels on pogo block level:  | 32 |
 | Max. current per channel on pogo block level:  | 2 A  |  ![Drawing_E8023PG](<../../../../raw/144868.png>)

The signals of two DPS64-HC channels are ganged in the pogo block and routed as one channel.

 ![Pogo ganging E8023Px](<../../../../raw/141747.png>)
