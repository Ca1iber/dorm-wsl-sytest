# Twinning stiffeners

Because the Twinning DUT and family boards have a different PCB geometry they require specific stiffeners. The standard V93000 DUT board stiffener cannot be used.

  The following table gives the part numbers for the stiffeners that are needed for the Twinning DUT and family boards.

 | Part Description  | Part Number |
 | Family board stiffener for standard applications and Wave Scale RF  | E8028FS |
 | DUT board stiffener  | E8028DS |
 | Direct-probe stiffener  | E8028DSD |
