# Test head adjustment

#### Subtopics

- [DUT interface adjustment during docking](<02.03.11.01.05.02.01_DUT_interface_adjustment_during_docking.md>)

This topic describes how to adjust the test head for the planarity verification.

## Before you begin

Adjust the prober head as described in [Prober head plate adjustment](<02.03.11.01.05.01_Prober_head_plate_adjustment.md>).

Note A probe card is not required to be inside the prober.

## Procedure

-  Verify that the DUT interface floating capability and the theta capability are enabled.  ![Enable/disable floating for the DUT interface](<../../../../raw/124176.jpg>)
-  Hard-dock the test head.
-  Verify that the test-head is visually planar to the prober head-plate in the side axis:

  -  Check the angle of the gap between the test head cover and the prober head plate.  ![Check gap between test head and prober](<../../../../raw/124177.jpg>)
  -  If required, adjust the parallel adjustment handle.  ![Adjusting the tilt angle of the manipulator](<../../../../raw/76437.jpg>)

-  Verify that the test head is visually planar to the prober head-plate in the front axis:

  -  Check the angle of the gap between the test head cover and the prober head plate.  ![Check front axis gap between test head and prober](<../../../../raw/124179.jpg>)
  -  If required, adjust the test head angle (for details see Test head movement in the LTH/STH Manipulator Installation Guide).  ![Test head adjustment for front axis](<../../../../raw/124180.png>)

-  Lock the manipulator arms by securing:

  - two horizontal movement locks
  - the swing-out lock

as shown in the following figure.

  ![Movement locks on the manipulator](<../../../../raw/76533.png>)

## What to do next

Verify the prober planarity as described in [Prober planarity verification](<02.03.11.01.05.03_Prober_planarity_verification.md>).
