# AV8 (MCA) pogo pin assignment

This section gives you an overview of the pin assignments of the AV8 - Audio/Video 8 analog card (MCA).

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : Pin Scale |

## Notes on GND pins:

- AGND - Analog ground - The AGND pins in one AV8 (MCA) module are connected to each other inside the analog module.
- FGND - Floating ground - For the AV8 (MCA), the FGND is the ground for the common trigger input and is separated from analog ground. On the DUT board, wire the FGND of the AV8 (MCA) to the ground of the digital channel that is used as a trigger source. The wiring is the same as for other analog modules whose trigger input ground is DGND. In the AV8 (MCA) module, the FGND pin for CT1 and the FGND pin for CT2 are separate from each other.

The AV8 (MCA) module contains eight units. For the E9714A AV8 (MCA) Source and Measure model, units 1 to 4 are source units and units 5 to 8 are measure units. For the E9715A AV8 (MCA) Measure model, all units are measure units.

Each source unit contains an audio AWG (1.024 Msps 24-bit) and a video AWG (100 Msps 14-bit). Each measure unit contains one video digitizer (65 Msps 14-bit) and two audio digitizers (200 ksps 24-bit). Each unit has two kinds of the trigger input pins: the common trigger (CT1/2) and unit trigger (CLK) pins. The common trigger pins can be shared with any units in an AV8 (MCA).

In the pin assignment table, the following names are used:

FGND: floating ground

AGND: analog ground on analog module

CT1, CT2: Common trigger input

A+, A-, to H+, H-: AWG output, digitizer input, MCA-PMU pin or V source output

AA+, AA- to HH+, HH-: Digitizer input, MCA-PMU pin, V source output, or trigger signal input for the unit

The AV8 (MCA) uses both the S1 and S2 pogo blocks.
