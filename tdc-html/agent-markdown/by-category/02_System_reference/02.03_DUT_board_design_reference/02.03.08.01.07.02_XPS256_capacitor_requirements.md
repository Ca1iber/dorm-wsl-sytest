# XPS256 capacitor requirements

XPS256 requires no capacitors on the DUT board to maintain stability. However, external capacitors can be used to improve the load step response.

## Capacitor requirements for stable operation

With stability maintained, XPS256 requires no capacitors on the DUT board and supports a capacitive load of up to 1000 渭F per channel [1)](<#_351003__d7364e55>).

For related specification data, refer to table Load capacitance range in topic [XPS256 other performance characteristics](<../02.02_Specifications/02.02.05.03.07_XPS256_other_performance_characteristics.md>).

## Capacitor requirements for improved load step response

Although the stability of the XPS256 can be maintained without external capacitors, it may be necessary to place capacitors on the DUT board in order to optimize the load step response.

The load step response achieved also depends on several other factors, such as the selected regulation mode, the programmed bandwidth of the XPS256 and the height and slew rate of the load step.

- Capacitor requirements for single channels

External capacitors up to 1000 渭F per channel [1)](<#_351003__d7364e55>) can be used on the DUT board to improve the load step response.

The value of the capacitors must be carefully selected: With small capacitors in the lower 渭F range, the improvement will not be that big, but very large capacitors increase the energy that cannot be controlled by the XPS256 if the current consumption of a faulty DUT is too high. In addition, the required settling time for current measurements increases with large capacitors. Typical capacitor values are in the range from 10 渭F to 100 渭F

Some example values for the maximum settling time and the maximum voltage deviation are available in table Load step response of topic [XPS256 load step response](<../02.02_Specifications/02.02.05.03.05_XPS256_load_step_response.md>). The table is valid for single channels considering the given conditions.

- Capacitor requirements for ganged channels

XPS256 ganging groups are handled like individual channels. This means that the capacitor values that have been determined for single channels, must be multiplied by the number of ganged channels in order to get the total required capacitance of the ganged channels.

Rules to consider:

- Place the capacitors as close as possible to the DUT pin.
- Use capacitor voltage derating of 50 %.
- [Low ESR](<02.03.08.01.06.04.02_Real_capacitors.md>) ceramic or tantalum capacitors can be used for higher capacitance values.
- Due to the equivalent series inductance (ESL) and equivalent series resistance (ESR) of real capacitors, we recommend using several smaller capacitors instead of one big capacitor for ganged channels. A maximum value of 100 渭F ... 220 渭F of the individual capacitors improves the effectiveness.
