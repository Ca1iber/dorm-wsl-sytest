# Utility pogo block - Utility Card (V93000 EXA Scale systems)

V93000 EXA Scale systems can be equipped with the optional Utility Card (EK051A) that provides 256 dynamically controlled utility lines and several utility power supplies per card. The 256 utility lines and the utility power supplies are routed to eight 4-row utility pogo blocks.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : EXA Scale (SmarTest 7+8) |

## Mapping of pin groups and utility pogo blocks

 Note

The assignment of the eight utility pogo blocks to the pogo blocks on the DUT interface is different for the first and second Utility Card. The mapping affects also the availability of the utility supplies on [UPP15V / UPM15V / F24V pins](<02.03.05.03_Utility_power_supply_-_UPP15V___UPM15V___F24V_pins__V93000_EXA_Scale_sys.md>).

For more information, refer to section [Utility pogo block mapping](<02.03.06.08.02_Utility_pogo_block_-_Utility_Card__V93000_EXA_Scale_systems.md#_347642__s_Utility_pogo_block_mapping>) below.

    ![Layout of utility and DPS blocks - Utility Card configuration of V93000 EXA Scale systems.](<../../../../raw/351272.png>)

In V93000 EXA Scale systems, the legacy pogo blocks DPS 1 鈥?nbsp;DPS 8 are used either for the optional 2nd Utility Card or for the [Internal Utility Power Option](<02.03.05.04_Internal_Utility_Power_Option__V93000_EXA_Scale_systems.md>). See also section [Structure of the DUT interface layout](<02.03.03.01_DUT_interface_layout.md#_20811__s_Structure>) in topic [DUT interface layout](<02.03.03.01_DUT_interface_layout.md>).

   CAUTION The 4鈥憆ow utility block uses the row sequence c-a-b-d for compatibility with the 2鈥憆ow utility block. This sequence is different to the row sequence a-b-c-d of other 4鈥憆ow pogo blocks. Do not use the wrong row sequence a-b-c-d for the 4鈥憆ow utility block. Use only the correct row sequence c-a-b-d for the 4鈥憆ow utility block. Violating this rule results in unusable DUT boards.

## Wiring rules and notes

- Connect all pogo pins of all blocks of a utility supply output to a separate power plane on the DUT board.
- Connect all sense pins of all blocks of a utility supply output to the related power plane.
- Utility power supply pogo pins of different Utility Cards must not be connected together.
- Maximum offset of utility ground to system ground: 卤0.5 V
- Pins URW14 and URW15 of utility block 1 (UTIL 1) are internally connected to the DUT Interface EEPROM of the system and can be used to control up to three more EEPROMS on the DUT board or probe card. For more information, refer to [Utility Lines and DUT Board EEPROMs](<02.03.04.06_Utility_lines_and_DUT_board_EEPROMs.md>).Note Utility pins URW14 and URW15 on utility block 1 are not to be used for a purpose other than EEPROM access otherwise the readout from the DUT Interface EEPROM may become corrupted. This would be the case when the DUT Board is docked while an EDC dump is in progress. For more information, refer to EDC Dump in the "Service Guide Part 1".
