# Utility lines and DUT board EEPROMs

You can identify your DUT board by reading out the EEPROMs mounted on the board. URW14 and URW15 on utility block 1 (UTIL 1) is used to address the EEPROMs.

EEPROMs are connected to the I2C bus and can be addressed individually:

- SmarTest 7: Firmware commands [BDID, BDID? - (BoarD ID)](<../02.06_Command_Reference/02.06.02.02.09_BDID__BDID__-__BoarD_ID.md>) and [I2CA, I2CA? - (I2CA bus)](<../02.06_Command_Reference/02.06.02.02.142_I2CA__I2CA__-__I2CA_bus.md>)
- SmarTest 8: IDutBoard interface of the Device Test API

Use one of the following EEPROMs:

- ST Microelectronics: M24C04-WMN6P
- Catalyst Semiconductor: CAT24C04W

Connection of serial DUT board EEPROM to utility block pins
 | EEPROM  | Pins of Utility block 1 |
 | Pin  | Signal name  | Description |
 | 1  | NC  | NC pin  | not connected |
 | 2  | A1  | Address input, to be connected to UGND or UP5V  | UGND |
 | 3  | A2  | UGND |
 | 4  | VSS  | Ground  | UGND |
 | 5  | SDA  | Serial data input/output  | URW15 |
 | 6  | SCL  | Serial clock input  | URW14 |
 | 7  | MODE / WPI  | Write control

Write operations are enabled when this pin is either driven low or left floating.

  | UGND |
 | 8  | VCC  | Supply voltage  | UP5V  |  Note Utility pins URW14 and URW15 on utility block 1 are not to be used for a purpose other than EEPROM access otherwise the readout from the DUT Interface EEPROM may become corrupted. This would be the case when the DUT Board is docked while an EDC dump is in progress. For more information, refer to EDC Dump in the "Service Guide Part 1".

## Generic EEPROM addressing

The table below shows generic EEPROM addressing on the I2C bus.

Generic addressing of EEPROMs
 | Purpose  | Address pin A1  | Address pin A2 |
 | DUT Board EEPROM  | A1 = 0 (Connect to UGND)  | A2 = 0 (Connect to UGND) |
 | DUT Interface EEPROM  | A1 = 1 (Connect to UP5V)  | A2 = 0 (Connect to UGND) |
 | Free for Probe Card  | A1 = 0 (Connect to UGND)  | A2 = 1 (Connect to UP5V) |
 | Free for another device  | A1 = 1 (Connect to UP5V)  | A2 = 1 (Connect to UP5V) |

## Utility pin B9 on the large DUT interface of LTH

Pin B9 on utility blocks 2, 4, 6 and 8 on the large DUT interface is reserved and should be left floating, see [Utility pogo block - LTH large DUT interface](<02.03.06.08.03_Utility_pogo_block_-_LTH_large_DUT_interface.md>). If not observed, the slave wiring board EEPROMs will be read out incorrectly, resulting in incorrect information about these boards in the EDC Dump (Service Guide Part 1).

 Note If your existing DUT interface board is designed the way that these pins are pulled low, you must undock the DUT board before starting the EDC Dump. Pin B9 on the utility blocks on all other test heads is already at utility ground.
