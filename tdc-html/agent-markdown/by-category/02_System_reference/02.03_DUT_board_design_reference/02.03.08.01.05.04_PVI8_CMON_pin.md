# PVI8 CMON pin

The PVI8 card provides a current monitor pin CMON# for each channel.

## CMON#

The pin is designed as a push-pull output. The return pin of the pin is the low force (LF#) pin of the floating PVI8 channel.

The output voltage is referenced to the low sense (LS#) pin of the floating PVI8 channel.
