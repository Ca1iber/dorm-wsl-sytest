# Multisite DUT board design

Before you design a multisite DUT board, you need to determine the test system resources, such as the number of channels, the number of device power supply (DPS) channels and the device pin count. These are all major aspects when designing a multisite DUT board.

The number of sites will depend upon the size of your device and size of DUT board.

 The maximum number of sites supported by the software is 1024 for SmarTest 7 and 4096 for SmarTest 8.

The handler that you have planned to use can also limit the number of sites. So, planning and selecting the handler before designing the DUT board is also an important task.

When designing a DUT board for multiple sites, bear in mind the following:

- The DPS channels can be shared between sites.
- In general, you cannot assign DPS's of different types to the same DUT power pin on different sites.
- When assigning the digital pin IO resources, you should try to assign these by whole cards or test processors to each site. This helps to speed up parallel measurements.
- Multisite DUT boards must be debugged with great care to avoid interference between the different sites.
