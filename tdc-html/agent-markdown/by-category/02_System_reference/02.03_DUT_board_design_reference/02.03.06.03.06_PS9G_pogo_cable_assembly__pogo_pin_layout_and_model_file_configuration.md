# PS9G pogo cable assembly, pogo pin layout and model file configuration

The PS9G is a high-speed and high-density digital card and part of the Smart Scale generation. It provides 64 single ended I/O channels, or 32 differential channel pairs, or any arbitrary combination of single ended and differential pairs.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : EXA Scale (SmarTest 8), Smart Scale (SmarTest 7+8), Pin Scale |

## Standard pogo layout

The PS9G card supports the standard pogo locations. Its pogo assembly features

- 4 pogo blocks per PS9G card
- 16 signal pogo pins per pogo block
- 32 ground pogo pins per pogo block
   ![Pin Scale 9G pogo cable](<../../../../raw/113122.jpg>)

Typically, a PS9G card uses four adjacent pogo block locations close to the DUT, for example 301, 302, and 305, 306.

## Specific design rules

 Specific design rules must be followed when designing a new DUT board and assigning PS9G channels:

- Pogo block compatibility: The standard pogo locations and the differential signal assignment (x01-x03 , x02-x04 , ...) make the PS9G card compatible to other digital cards and allows its general use in all applications.
- [The SmartLoop™loopback scheme](<02.03.06.03.06_PS9G_pogo_cable_assembly__pogo_pin_layout_and_model_file_configuration.md#_124636__dle_The_SmartLoop_loopback_scheme>): Loopback pins must belong to the same test processor.
- [Pin assignment for Fast Sync / Fast Match](<02.03.07.06_Pin_assignment_for_Fast_Sync___Fast_Match.md>): For fast local synchronization, the synchronized DUT pins must be assigned to the same group of channels respectively to the same test processor.

## PS9G card configuration in the model file

For the syntax of standard density (SD) pogo block entries in a model file, refer to the SD section in [PS1600 card configuration in the model file](<../02.05_Test_Head_Cards/02.05.04.01.07.02_PS1600_card_configuration_in_the_model_file.md>).

The following are model file examples.

```
CARD_CONFIGURATION (tester.model file syntax)
slot = 112, HW = PS9G, pogoblocks = 517-520

IOCHANNEL (model file syntax)
10101-10216: HW = PS9G, speed = max-rate, smem = 112M, tim = w256-d8-r8, diff, tmu, loopback = max-rate
```
