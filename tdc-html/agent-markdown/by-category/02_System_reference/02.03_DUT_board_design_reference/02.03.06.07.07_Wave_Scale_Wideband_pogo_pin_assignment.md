# Wave Scale Wideband pogo pin assignment

A WSWB card is routed to two pogo blocks: block A is used for digital signals (trigger inputs) and block B is used for IF signals.

   |  For each WSWB card, the TXTRIG and RXTRIG pogo pins of the digital block must be connected to 2 digital pogo pins, respectively. For example, the TXTRIG and RXTRIG pogo pins (43101 and 43104) of the first (left) WSWB card can be connected to two PS1600 digital pogo pins 10101 and 10102. In this case, 10101 (connected to 43101) and 10102 (connected to 43104) are digital triggering channels that are reserved for TX triggering and RX triggering of the WSWB card. Therefore, the digital channels 10101 and 10102 cannot be used for other purposes. Digital trigger pins must be explicitly configured for the corresponding IF pogo pins specified in the DUT board specification. For this example, the TX/RX digital triggers for the specified TX/RX pogo pins are configured as shown below:

```
dutboard ExampleBoard {
sites = 2;
//...
signal IF_RX {
site 1 { pogo = 23106; triggerChannel = "10101"; }
site 2 { pogo = 23106; triggerChannel = "10101"; }
}

signal IF_TX {
site 1 { pogo = 23110; triggerChannel = "10102"; }
site 2 { pogo = 23112; triggerChannel = "10102"; }
}
```

If the WSWB is used in Wave Scale Millimeter card cage, you must specify those WSWB pogo pins with the keyword testerpogo in the dutboard file, for example:

```
dutboard ExampleBoard {
sites = 2;
//...
signal IF_RX {
site 1 { testerpogo = 23106; triggerChannel = "10101"; }
site 2 { testerpogo = 23106; triggerChannel = "10101"; }
}

signal IF_TX {
site 1 { testerpogo = 23110; triggerChannel = "10102"; }
site 2 { testerpogo = 23112; triggerChannel = "10102"; }
}
```

The TX/RX pogo pins of the IF block must be connected to AUX ports of the corresponding RFIM-18 module correctly for providing wideband signal stimulus and measure.
