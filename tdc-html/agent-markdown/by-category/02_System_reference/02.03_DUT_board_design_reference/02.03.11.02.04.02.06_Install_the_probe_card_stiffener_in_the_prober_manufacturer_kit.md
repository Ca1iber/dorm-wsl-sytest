# Install the probe card stiffener in the prober manufacturer kit

## About this task

This task is about mounting the probe card into the prober manufacturer kit.

## Before you begin

Ensure that the probe card and the prober manufacturer kit are available.

## Procedure

-  Insert the probe card stiffener into the prober manufacturer kit (mounting ring) so that the position arrows on the probe card stiffener align with those on the mounting ring.  ![Probe Card stiffener in Probe Card Ring](<../../../../raw/103275.jpg>)
-  Place the assembled pogo tower frame on top of the resulting assembly and lock it in position with the handle.  ![Probe Card Stiffener in mounting ring back side](<../../../../raw/103276.jpg>)

## What to do next

Install the WPI DUT Board onto the wafer prober interface
