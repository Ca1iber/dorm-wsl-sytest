# Utility pogo block - STH DUT Scale interface

The small test head system fitted with the DUT Scale interface uses an active wiring board to generate utility lines.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : Smart Scale, Pin Scale, HSM |

Each utility pogo block on the STH DUT Scale interface is connected via the utility cable to the corresponding connector on the wiring board. Depending on the type of pogo block selected, 2-row or 4-row, 16 or 32 utility lines are available on each block. This arrangement provides 128 or 256 utility lines in 8 pin groups. The utility cable is always the same and has the capacity for 32 utility lines. The pogo blocks are exchangeable and are plugged on to the end of the cable, see [Utility line assignments](<02.03.04.01_Utility_line_assignments.md>).

## Mapping of pin groups and utility pogo blocks

The layout of utility and DPS blocks on the DUT Scale interface is shown in below.

   ![Layout of utility and DPS blocks on the large DUT interface (STH)](<../../../../raw/136561.png>)     CAUTION The 4‑row utility block uses the row sequence c-a-b-d for compatibility with the 2‑row utility block. This sequence is different to the row sequence a-b-c-d of other 4‑row pogo blocks. Do not use the wrong row sequence a-b-c-d for the 4‑row utility block. Use only the correct row sequence c-a-b-d for the 4‑row utility block. Violating this rule results in unusable DUT boards.

A layout overview of utility and DPS blocks for all types of DUT interfaces and test heads is shown in [Utility line assignments](<02.03.04.01_Utility_line_assignments.md>).

## Utility DC pins

 The utility DC pins support connection of utility card pins via the DC rail to external instruments connected to the card-cages. For compatibility, the channel specification "HPMU1" maps to "UTIDC165", "HPMU2" to "UTIDC166", and so on, in the Digital pins editor:

 | Utility DC pin in Digital Pins Editor  | Utility block  | Card cage |
 | UTIDC165  | 1  | 3 |
 | UTIDC166  | 2  | 2 |
 | UTIDC167  | 3  | 4 |
 | UTIDC168  | 4  | 1  |  Note The Utility DC pins are supported only in SmarTest 7.10.

## Wiring rules and notes

Some rules and notes are to be considered for the wiring of the utility line pogo blocks:

- Not all signals may be present on all utility blocks. This may vary depending on the type of interface used.
- On SmarTest Work Center DUT boards ensure that all power planes supplied by a particular external utility power line are connected together.
- Pins PDCS, PDCF, PGDS, PGRD are connected to the High Precision PMU (HPPMU) of the [Clock board](<../02.05_Test_Head_Cards/02.05.07_Clock_boards.md>). Note: The HPPMU functionality is not supported in SmarTest 8.
- Pins SINP, SOUT, SCLK and FRAMn are used as serial utility line interface pins. For more information, refer to [Sequencer‑controlled utility lines](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01_Sequencer-controlled_utility_lines.md>).
- Pins URW14 and URW15 of utility block 1 (UTIL 1) are internally connected to the DUT Interface EEPROM of the system and can be used to control up to three more EEPROMS on the DUT board or probe card. For more information, refer to [Utility Lines and DUT Board EEPROMs](<02.03.04.06_Utility_lines_and_DUT_board_EEPROMs.md>).Note Utility pins URW14 and URW15 on utility block 1 are not to be used for a purpose other than EEPROM access otherwise the readout from the DUT Interface EEPROM may become corrupted. This would be the case when the DUT Board is docked while an EDC dump is in progress. For more information, refer to EDC Dump in the "Service Guide Part 1".
-

The designation for utility pogo pins is URW00 ... URW15 (2‑row block) or URW00 ... URW31 (4‑row block). The corresponding scheme used by SmarTest is as follows:
