DC-Scale cards contain independently programmable channels. The DC Scale cards reside in I/O channel card slots.

## Supported V93000 system generations and variants

This section holds the pogo pin layouts for all V93000 system generations and variants. For the supported set of test head cards on your system, refer to [Pogo pin assignment](<02.03.06_Pogo_pin_assignment.md>).

## Filling rules for V93000 Smart Scale and Pin Scale systems

The DC Scale cards can reside in any channel card slot of the card cage. A pair of adjacent odd and even slots must be filled with the same card type. For details see [Card compatibility](<../02.02_Specifications/02.02.03.01_Card_compatibility.md>).

These filling rules apply only to V93000 Pin Scale and Smart Scale systems. The filling rules do not have to be observed for V93000 EXA Scale systems.
