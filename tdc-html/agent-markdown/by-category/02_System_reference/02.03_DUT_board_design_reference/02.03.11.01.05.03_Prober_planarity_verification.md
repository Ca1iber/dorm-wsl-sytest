# Prober planarity verification

#### Subtopics

- [Test head alignment for probing with the Wave Scale Millimeter solution attached](<02.03.11.01.05.03.01_Test_head_alignment_for_probing_with_the_Wave_Scale_Millimeter_solution.md>)

This topic describes in general how to verify the planarity of the prober head plate (prober only) using the Visual Planarity Gauge (VPG).

## About this task

For a detailed description, refer to the documentation you received with the VPG or contact your Advantest representative.Note Calibration: The VPG should be calibrated yearly.

## Before you begin

Finish the [Test head adjustment](<02.03.11.01.05.02_Test_head_adjustment.md>). The following procedure is done after the test head is docked.

Before the test head is docked, you should measure (with a filler gauge), that the VPG/probe card is within 0.1 mm before cams are clamping. Also, ensure that the SACC was set up correctly.

## Procedure

-  Load the VPG gauge into the prober using the semi-automatic card changer (SACC).
-  Verify that the VPG seats properly against the bridge beam on the prober head plate.
-  Measure the z height of the central optical target using the prober look-up camera. Use this z-value as reference. Measure the z of all other targets and calculate the difference between each target and the central target. Adjust the prober's head plate planarity as needed.

The maximum allowable z difference between any two of the measured points is 25 μm.
