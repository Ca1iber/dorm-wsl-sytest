# Configuration of 4-row or 2-row utility pogo blocks

Settings in the .technology file and the model file of SmarTest 7 or in the tester.model file of SmarTest 8, 4-row utility blocks and DUT boards that are designed for the 4-row utility blocks are required for utilizing 256 utility lines and the External utility power supply.

## Requirements for using 256 utility lines and the External utility power supply

To be able to use 256 utility lines and the [External utility power supply (V93000 systems)](<02.03.05.06_External_utility_power_supply__V93000_systems.md>) you need to

- install 4-row utility pogo blocks,
- install SmarTest software Release 7.2 (or higher),
- install a DUT board with 4-row utility pads that connects the DSC and POG4R utility pogo pins to UGND.

To be able to use 256 utility lines you must additionally

- insert the correct utility line entries in the model file and the .technology file of SmarTest 7 or in the tester.model file of SmarTest 8.

## Behavior of SmarTest 7 with incorrect entries

The following tables show the behavior of SmarTest 7 with incorrect entries in the .technology file and the model file.

  SmarTest 7.2 or higher

 | Utility pogo blocks fitted  | technology file entry  | model file entry |
 | No entry  | 16 utility lines  | 32 utility lines |
 | 2-row  | No entry  | Warning  | Warning  | Warning |
 | 16 lines  | Warning  | OK  | Warning |
 | 32 lines  | Warning  | Warning  | SW does not start |
 | 4-row  | No entry  | Warning  | Warning  | Warning |
 | 16 lines  | Warning  | Warning  | Warning |
 | 32 lines  | Warning  | SW does not start  | OK  |   Prior to SmarTest 7.2

 | Utility pogo blocks fitted  | technology file entry  | model file entry |
 | No entry  | 16 utility lines  | 32 utility lines |
 | 2-row  | No entry  | OK  | SW does not start  | SW does not start |
 | 16 lines  | Warning  | SW does not start  | SW does not start |
 | 32 lines  | Warning  | SW does not start  | SW does not start |
 | 4-row  | No entry  | OK  | SW does not start  | SW does not start |
 | 16 lines  | Warning  | SW does not start  | SW does not start |
 | 32 lines  | Warning  | SW does not start  | SW does not start  |   Note Default value (no entry) for utility lines in the model file or the .technology file of SmarTest 7 is 16 utility lines.

If the software does not start, the model file of SmarTest 7 contains an unsupported entry. A corresponding error message provides the location (the line-number) of this entry.

To get the software to start you must:

- modify the utility line entry in the model file or
- use a model file without a utility line entry.
