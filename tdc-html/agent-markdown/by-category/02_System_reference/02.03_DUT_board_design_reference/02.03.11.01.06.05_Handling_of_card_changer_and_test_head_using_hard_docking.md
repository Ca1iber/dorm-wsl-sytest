# Handling of card changer and test head using hard docking

If you use a semi automated card changer, Advantest recommends connecting the test head and the wafer prober always together via hard docking, see procedure below. It is not necessary to unfix this connection to change the probe card.

## Hard docking

- Move the test head to the probe.
- Ensure that the floating capability of the DUT interface is enabled.
- On the remote control, first press HARD UNDOCK, then HARD NEUTRAL to ensure that the pistons in the hard-docking cylinders are in the correct position for taking the coarse alignment.
- Move the test head closely to the prober.

The hard-docking cylinders of the test head must be in line with the coarse alignment pins, which are mounted to wafer prober.

- Move the test head carefully further towards the prober until the coarse alignment pins snap into the cylinders (audible).
- Make sure that all locks for horizontal and vertical movement of the test head are released.
- Press HARD DOCK.
- Press HARD NEUTRAL.
- Tighten the corresponding locks to disable all released test head movements.

Hard docking is complete and the semi automated probe card changer can commence operation.

## Hard un-docking

- Un-tighten the locks to enable test head movements.
- Press HARD UNDOCK.
- Move the test head carefully away from the wafer prober.
- Press HARD NEUTRAL.
