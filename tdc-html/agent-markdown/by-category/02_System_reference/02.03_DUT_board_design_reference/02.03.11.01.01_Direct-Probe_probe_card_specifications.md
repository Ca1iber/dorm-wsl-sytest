# Direct-Probe probe card specifications

This topic gives general specifications for the Direct-Probe™interface valid for all solutions. A universal stiffener design is used for all solutions.

This topic describes the interface for the digital and the mixed signal solution, which is the general basis for the RF solution. For details on the RF solution of SmarTest 7, see [Direct-Probe PSRF probe card specifications](<02.03.11.01.02_Direct-Probe_PSRF_probe_card_specifications.md>).

Note The Direct-Probe interface requires a large test head or a test head fitted with the DUT Scale interface.Note The drawings in this guide serve as conceptual descriptions only and may differ from the latest original design drawings. For the original drawings see [Direct-Probe probe card layout information](<02.03.12.01.01_Direct-Probe_probe_card_layout_information.md>) and [Direct-Probe stiffener](<02.03.12.01.02_Direct-Probe_stiffener.md>).
