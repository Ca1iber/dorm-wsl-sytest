# WSMM Card Cage DUT Interface

#### Subtopics

- [WSMM Card Cage RFIM18 / RFIM6 channel transformation](<02.03.06.07.02.01.01_WSMM_Card_Cage_RFIM18___RFIM6_channel_transformation.md>)
- [WSMM Card Cage pogo via design](<02.03.06.07.02.01.02_WSMM_Card_Cage_pogo_via_design.md>)
- [Wave Scale Millimeter PCB space](<02.03.06.07.02.01.03_Wave_Scale_Millimeter_PCB_space.md>)

The DUT interface of the WSMM solution features four groups of WSMM RF ports, resources of the [DUT Scale interface](<02.03.03.02_DUT_Scale_interface.md>) in four groups of pogo blocks, and direct access to RFIM-6/RFIM-8 and RFIM-18 ports of the Wave Scale RF card.

Compared to the DUT scale interface, the pogo block groups and RF ports are shifted outwards providing more application space in the center of the board.

  ![WSMM port locations](<../../../../raw/347787.svg>)

For a table with the internal RF‑related routing of two RFIM‑8 modules and two optional RFIM‑/8 modules, refer to section [RFIM-6/8 / RFIM-18 (E8027BRA) channel transformation](<02.03.06.07.02.01.01_WSMM_Card_Cage_RFIM18___RFIM6_channel_transformation.md#_348873__s_RFIM-6_8_RFIM-18_channel_transformation>) in [WSMM Card Cage RFIM18 / RFIM6 channel transformation](<02.03.06.07.02.01.01_WSMM_Card_Cage_RFIM18___RFIM6_channel_transformation.md>).

The DUT interface is divided into the following groups:

 | Group  | Usage |
 | 1, 2, 3, 8 |

RF ports of the Remote Mixing Modules (RMM) 1 to 8.

For more information, refer to Wave Scale RF with RMM hardware overview.

 |
 | 4, 5, 6, 7  | Resources of the [DUT Scale interface](<02.03.03.02_DUT_Scale_interface.md>), routed by the [WSMM Card Cage Family board](<02.03.06.07.02.02_WSMM_Family_Board_E8027FAA.md>). |
 | 9 |

[RFIM-6/RFIM-8](<02.03.06.07.05_Wave_Scale_RF_with_RFIM-6_RFIM-8_pogo_pin_assignment.md>) and [RFIM-18](<02.03.06.07.06_Wave_Scale_RF_with_RFIM-18_pogo_pin_assignment.md>) ports of the Wave Scale RF card.

The available ports are marked grey in the graphics above. The color-coded ports are internally connected to the RMMs of groups 1, 2, 3 and 8.

 |

## Virtual pogo blocks

SmarTest divides physical pogo blocks of more than 16 channels into 16 channel units called logical boards. The first logical board is assigned to the physical pogo block. The other logical boards are assigned to so-called virtual pogo blocks.

 | Group  | Pogo block and RF port range  | Usage |
 | 4  | 4528, 4529, 4530, 4532, 4533, 4534  | These virtual blocks are used for physical pogo blocks providing more than 16 channels and therefore covering minimum two logical boards. An offset of 400 is to be added to the position of the physical block to obtain the number of the virtual pogo block. |
 | 4727, 4728, 4729, 4730, 4731, 4732, 4733, 4734 |
 | 5  | 5604, 5605, 5606, 5608, 5609, 5610 |
 | 5803, 5804, 5805, 5806, 5807, 5808, 5809, 5810 |
 | 6  | 6612, 6613, 6614, 6616, 6617, 6618 |
 | 6811, 6812, 6813, 6814, 6815, 6816, 6817, 6818 |
 | 7  | 7620, 7621, 7622, 7624, 7625, 7626 |
 | 7819, 7820, 7821, 7822, 7823, 7824, 7825, 7826 |

For the [WSMM Family Board E8027FAA](<02.03.06.07.02.02_WSMM_Family_Board_E8027FAA.md>), virtual pogo blocks shown an offset of 400 in the "WSMM logical pin" column compared to the "WSMM block" column of the table in [WSMM Family Board E8027FAA pogo pin mapping](<02.03.06.07.02.02.02_WSMM_Family_Board_E8027FAA_pogo_pin_mapping.md>).

For more information, see also section Model file declaration in Wave Scale Millimeter specific setup tasks.
