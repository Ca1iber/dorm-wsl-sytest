# UHC4 / UHC4T capacitor requirements

#### Subtopics

- [UHC4 / UHC4T capacitor examples](<02.03.08.01.06.04.01_UHC4___UHC4T_capacitor_examples.md>)
- [Real capacitors](<02.03.08.01.06.04.02_Real_capacitors.md>)

The DC Scale UHC4 / UHC4T power supply is a fast and powerful DPS. It needs a carefully designed capacitor network that is specifically tailored to each DUT signal requirement.

UHC4 / UHC4T requirements challenge with low voltage level, high current, and fast switching speed. Increasing any of these requirements will also increase the complexity of the capacitor network.

The main functions of the capacitor network are:

- Ensure stability of the UHC4 / UHC4T.
- Supply a sufficient amount of charge for the high-speed change requirement, until the UHC4 / UHC4T card is finally able to respond.

Several applicable bulk and ceramic capacitors are listed in [Capacitor examples for UHC4](<02.03.08.01.06.04.01_UHC4___UHC4T_capacitor_examples.md>)
