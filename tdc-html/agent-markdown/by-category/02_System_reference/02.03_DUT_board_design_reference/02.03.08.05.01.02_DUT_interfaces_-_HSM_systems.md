# DUT interfaces - HSM systems

The DUT interface on the test head consists of high-performance coaxial cabling and spring-loaded contact pins (pogo pins) that provide electrical contact between the test head electronics and the DUT board. The DUT interface also contains a mechanism for docking to handlers and wafer probers.

 V93000 HSM Series systems offer two different [DUT interfaces](<02.03.03.02_DUT_Scale_interface.md>):

- The small DUT interface of the Compact test head and the
- Large DUT interface / DUT Scale interface of the Compact test head and Large test head and.
