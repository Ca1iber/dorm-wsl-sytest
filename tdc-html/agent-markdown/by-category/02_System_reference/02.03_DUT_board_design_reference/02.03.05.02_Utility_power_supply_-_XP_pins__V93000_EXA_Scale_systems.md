# Utility power supply - XP pins (V93000 EXA Scale systems)

The "Utility power supply - XP pins" of V93000 EXA Scale systems is routed to the XP... pins of the utility pogo blocks. Depending on the availability of the Utility Card, the supply is connected to utility pogo blocks 1 ... 8 or to other pogo blocks.

Note: The 4-row utility pogo blocks of the second Utility Card replace all existing 3-row DPS-slot pogo blocks.

The DPS block sequence of the second Utility Card differs from the UTIL block sequence of the first card. For the correct pogo block assignment of the second card, refer to section [Utility pogo block mapping](<02.03.06.08.02_Utility_pogo_block_-_Utility_Card__V93000_EXA_Scale_systems.md#_347642__s_Utility_pogo_block_mapping>) in [Utility pogo block - Utility Card (V93000 EXA Scale systems)](<02.03.06.08.02_Utility_pogo_block_-_Utility_Card__V93000_EXA_Scale_systems.md>).
