# WSMM Card Cage RFIM18 / RFIM6 channel transformation

Some WSRF ports of the DUT Scale interface are internally wired as input and output of the WSMM Card Cage Remote Mixing Modules (RMM). These modules are also controlled by the related RFIM-18 baseband pins. Other WSRF ports of the DUT Scale Interface are directly routed to group 9 of the WSMM Card Cage DUT Interface and can be utilized on the DUT board.

Up to four bracket assemblies transform the pogo blocks 901 ... 906 and 909 ... 914 of the DUT Scale interface to the pogo blocks 9901 ... 9904 and 9909 ... 9912 of the WSMM Card Cage DUT interface.

 |   ![RFIM-6/8 / RFIM-18 bracket assembly (E8027BRA)](<../../../../raw/348875.png>) |

Group 9 of the [WSMM Card Cage DUT Interface](<02.03.06.07.02.01_WSMM_Card_Cage_DUT_Interface.md>) holds totally up to four brackets each carrying two rows of RF ports.

The picture on the left shows the E8027BRA bracket assembly, consisting of two brackets for the RFIM-18 and an optional RFIM-6/8.

 |

## RFIM-6/8 / RFIM-18 bracket assembly (E8027BRA)

 The RFIM鈥?/8 / RFIM鈥?8 bracket assembly E8027BRA makes the WSRF ports of the DUT Scale interface available on the WSMM Card Cage DUT interface.

Compared to the DUT Scale interface, the WSMM Card Cage DUT interface features only two brackets on each side. If one side of the DUT Scale interface is fully loaded with [RFIM-6/8](<02.03.06.07.05_Wave_Scale_RF_with_RFIM-6_RFIM-8_pogo_pin_assignment.md>) modules then only two of them can be used on the WSMM Card Cage DUT board with the one at the outside edge not available. In the case there is an [RFIM-18](<02.03.06.07.06_Wave_Scale_RF_with_RFIM-18_pogo_pin_assignment.md>) to support Remote Mixing Modules (RMM) operations, then a single RFIM鈥?/8 module at the outside edge can be used.

  RFIM鈥?8 configuration

Up to two RFIM鈥?8 modules are supported in slots 901 ... 904 and 909 ... 912 of the DUT Scale interface.

The baseband part of the modules and the (1) ports of the mixing part are routed internally to the Remote Mixing Modules (RMM) of the WSMM Card Cage. The (2) ports of the mixing part are available on blocks 9901, 9902, 9909, and 9910.

Optional RFIM-6/8 modules in slots 905/906 and 913/914 are routed to 9903/9904 and 9911/9912 of the WSMM Card Cage DUT interface.

The graphics on the left shows how a combination of a RFIM-18 module and a RFIM-6/8 module are configured on the left side of the DUT interface.

A table with the internal routing of all ports of two RFIM鈥?8 modules and two optional RFIM鈥?/8 modules can be found in the [RFIM-6/8 / RFIM-18 (E8027BRA) channel transformation](<02.03.06.07.02.01.01_WSMM_Card_Cage_RFIM18___RFIM6_channel_transformation.md#_348873__s_RFIM-6_8_RFIM-18_channel_transformation>) section below. |

## RFIM-6/8 bracket assembly (E8027BRB)

The RFIM鈥?/8 bracket assembly E8027BRB makes the [RFIM-6/8](<02.03.06.07.05_Wave_Scale_RF_with_RFIM-6_RFIM-8_pogo_pin_assignment.md>) ports of the DUT Scale interface available on the WSMM Card Cage DUT interface if no RFIM鈥?8 module is installed.

  Single RFIM-6/8 configuration

Two RFIM-6/8 modules, installed in inner slots 901 ... 902 and 909 ... 910 of the DUT Scale interface are routed to the 9903/9904 and 9911/9912 slots of the WSMM Card Cage DUT interface.

 |   ![WSMM Card Cage DUT IF Single RFIM-6/8 configuration](<../../../../raw/355025.png>)    | The graphics shows how a single RFIM-6/8 module is configured on the left side of the DUT interface.  |  Note Using E8027BRB is only applicable if the RFIM-6/RFIM-8 is located in 901, 902 or 909, 910 (inside slots) in the test head. If the RFIM-6/RFIM-8 is located in 905, 906 or 913, 914 (outside slots) then please use E8027BRA. RFIM-6/RFIM-8 will be routed to 9903, 9904 or 9911, 9912 on the Wave Scale Millimeter card cage for both E8027BRA and E8027BRB. This provides flexibility for the installation of the RFIM-6/RFIM-8 module in the test head, yet maintains the Wave Scale Millimeter DUT board compatibility even if the Wave Scale Millimeter is upgraded to support additional (RMM) ports.
