# UHC4 / UHC4T DUT board layout

## DUT board layout

On the DUT board you must use an appropriate layout for the mating pads to the UHC4 / UHC4T pogo pins. The figure below shows the mechanical dimensions of the plated pads.

   ![Geometry of the pad layout on the DUT board for the UHC4 pogo assembly (all dimensions in mm)](<../../../../raw/105179.png>)

For the recommended size of signal pogo pads, refer to [Minimum pad size](<02.03.07.07_Pogo_pad_and_via_design.md#_91610__r_Minimum_pad_size>) and [Signal pogo via drill size](<02.03.07.07_Pogo_pad_and_via_design.md#_91610__r_Signal_via_drill_size>) in [Pogo pad and via design](<02.03.07.07_Pogo_pad_and_via_design.md>).

The spring contact area requires a surface flatness of Rz 8.0 um or better.

The figure below shows the bottom layer of a DUT board pogo area with a UHC4 / UHC4T pogo pad.

   ![Mating pad layout example on DUT board for the UHC4 pogo assembly (view from test head side, DUT board bottom)](<../../../../raw/105177.png>)

## Via design

Several vias are required to connect the plated pads to the inner power layers. The figure below shows a diagram of the via distribution in relation to the pad geometry for a single UHC4 / UHC4T power/ground pad.

   ![High-current section pogo via distribution](<../../../../raw/105180.png>)

The following design rules must be followed:

- Via drill diameter: 0.7 mm +/-
- Cu wall thickness: 25 碌m
- 40 A per pad requires the via configuration as shown in the graphic above (High current section pogo via distribution)
- For ganged configuration, connect to at least 4 inner layers
- Surface flatness: Rz < 8 碌m. Standard PCB processes should use un-filled vias; filled vias must be discussed with the DUT board manufacturer to confirm that the flatness specification is within manufacturing tolerances.
