The following topics present an example of a high-speed experimental DUT board design.

The challenges of this design were

- the high-speed data rate of up to 6.4 Gb/s,
- the trace density (4 I/O lanes in one pogo location, 16 high-speed traces), and
- the neighborhood of high-speed traces and traces for DC signal measurements.

The dielectric material for this design is GETEK. All signal traces are routed as striplines. The trace width is 19 mil.
