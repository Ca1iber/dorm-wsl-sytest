# PSSL pogo cable assembly, pogo pin layout and model file configuration

The E8080P pogo cable assembly connects the 32 channels of the PSSL card to the DUT board. The PSSL card supports the standard pogo locations.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : EXA Scale (SmarTest 8), Smart Scale (SmarTest 7+8) |

## Pogo cable assembly

 The pogo cable assembly features

- 2 pogo blocks per PSSL card
- 16 signal pogo pins per pogo block
- 32 ground pogo pins per pogo block
  ![PS-SL pogo cable](<../../../../raw/143039.jpg>)

Typically, a PSSL card uses two adjacent pogo block locations close to the DUT, for example, 301, 302 (or 305, 306). For further layout details see [Card Cage to Pogo Slot Standard Assignments](<../02.02_Specifications/02.02.03_Card_Cage_to_Pogo_Block_Standard_Assignments.md>) and [DUT interface layout](<02.03.03.01_DUT_interface_layout.md>).

## Example

### PSSL card configuration in the model file

For the syntax of standard density (SD) pogo block entries in a model file, refer to the SD section in [PS1600 card configuration in the model file](<../02.05_Test_Head_Cards/02.05.04.01.07.02_PS1600_card_configuration_in_the_model_file.md>).

```
CARD_CONFIGURATION
# PSSL card has standard-density pogos per filling rules in S2 locations
  slot = 105, HW = PSSL,     pogoblocks = 317 321
  slot = 106, HW = PSSL15G,  pogoblocks = 301 305
```
