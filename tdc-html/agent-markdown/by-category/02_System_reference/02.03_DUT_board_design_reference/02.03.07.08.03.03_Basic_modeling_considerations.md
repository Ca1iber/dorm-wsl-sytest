# Basic modeling considerations

Lumped-element simulation is not worth the invested time to even consider.

It is extremely narrow banded and usual simulation results rarely have any kind of correlation with the actual measured data.

Measurement based cascaded S-Parameters give a useful prediction of actual impedance matching vs. frequency.

## Key points for successful correlation between model using a circuit simulator and on-board actual hardware:

- Obtain measured Impedance of the DUT pin.
- Add-in transfer S-parameter of the socket.
- Calculate electrical length between the socket pin and first tuning element of the matching network (example: 5.4 pS for a 1/10th inch path using FR4).
- Use accurate transmission line model.
- De-embed test path and fixture losses.
- Account for spacing between tuning elements in the model. For the small distances between tuning elements add short transmission line sections into the model.
- Use advanced circuit model for L and C tuning components (example: [Modelithics, Inc](<http://www.modelithics.com/free-models.asp>).)
- Apply advanced models received from vendors for components such as baluns and switches.
- Apply port extension calibration correctly. Series and parallel (shunt) tuning elements will follow Smith chart circles. Note When all steps above are carefully followed, measurement based cascaded S-Parameters give a fairly accurate and reliable up front prediction of the impedance matching vs. frequency.

## Design preparation steps and other practical strategy considerations:

- To create an optimized matching network, one would need to know the input Impedance of the chip's Rx and Tx band pins - or input S-parameters, represented by their *.s2p file.
- For most practical cases the chip designers simply cannot, or will not, provide their chip's input parameters.
- If S-parameters are not known, measurement is an alternate solution; best is to use a test coupon.
- If measurement is impossible, EDA simulation is a workable alternate to get reasonable start values.
- If both measurement and EDA simulation values are unavailable, many times a data sheet value, an estimated value, or simply a good starting guess could be sufficient.
- If an experimental evaluation board is available from the chip's designer, best is to closely follow and repeat the same matching network on DUT board.
- If the dielectric constant is different in the new DUT board relative to the evaluation board, as a result of using a different board material, you need to adjust for any material change by scaling for different PCB dielectric material.
