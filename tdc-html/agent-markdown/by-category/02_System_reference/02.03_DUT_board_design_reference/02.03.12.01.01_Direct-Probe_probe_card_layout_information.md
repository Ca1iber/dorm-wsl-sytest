# Direct-Probe probe card layout information

For non-RF applications, we recommend using the [Dedicated non RF probe card](<02.03.12.01.01_Direct-Probe_probe_card_layout_information.md#_138464__dle_Dedicated_non_RF_probe_card>) listed below. In any case you need to chose one KOZ (keep-out zone) and one FF (form factor) drawing set.
