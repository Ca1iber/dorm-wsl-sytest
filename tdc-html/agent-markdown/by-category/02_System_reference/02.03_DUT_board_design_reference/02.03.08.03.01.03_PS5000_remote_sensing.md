# PS5000 remote sensing

Pin Scale 5000 channels support remote sensing via the neighboring channel for the dcVI instrument model and support also remote sensing of the ground (DGND) connections. Use the sense connections to the DUT to increase the accuracy of both force and measure operations.

  Note

The remote sensing feature is not available in SmarTest 8.4.4 but subject to a later SmarTest release.

Remote sensing is not supported in SmarTest 7.

## Basic principle

For the basic principle of remote sensing, refer to [Remote sensing](<02.03.07.01.07_Remote_sensing.md>) in the [DUT board design reference](<02.03_DUT_board_design_reference.md>).

## Remote sensing on Pin Scale 5000

You can use a neighboring channel of a force line as a sense line for all force voltage and measure voltage use cases. A neighboring channel is the mate of a channel, as it is the case for a [differential pair](<02.03.08.03.01.01_PS5000_differential_pin_pair_assignment.md>).

Remote sensing on Pin Scale 5000 means that both neighboring channels are connected to the same DUT pin. One of the channels forces voltage or current while the voltage is measued directly at the DUT via the other channel. The measured voltage is used as feedback for forcing voltage and can be used as measurement result.

## Rules for configuring remote sensing

 The following rules are to be considered when designing a DUT board:

- Remote sensing is supported for each [differential pair](<02.03.08.03.01.01_PS5000_differential_pin_pair_assignment.md>).
- The pin with the lower channel number is always the force pin.
- The pin with the higher channel number is always the sense pin.
-

The combination of remote sensing and ganging is supported within groups of four channels:

  - Supported channel groups are 1 ... 4, 5 ... 8, 9 ... 12, and 13 ... 16.
  - Ganged channels correspond to the [differential pairs](<02.03.08.03.01.01_PS5000_differential_pin_pair_assignment.md>).
  - The following configurations are supported:

 | Ganged channels  | Sense channel  |   | Ganged channels  | Sense channel |
 | 1-3  | 2  |   | 2-4  | 3 |
 | 5-7  | 6  |   | 6-8  | 7 |
 | 9-11  | 10  |   | 10-12  | 11 |
 | 13-15  | 14  |   | 14-16  | 15 |

For an example, refer to [PS5000 ganging](<02.03.08.03.01.02_PS5000_ganging.md>) in the DUT board design reference or to section Ganging and remote sensing in topic PS5000 ganging of the Test head cards reference.

## Recommendations for wiring of the sense channels

 We recommend that you observe the following rules:

- Route the sense trace in parallel and close to the force trace.
- For applications that need remote sensing and high-speed digital I/O capability on the same DUT pin, relays can be required to disconnect the sense trace.

## Defining remote sensing in SmarTest

For information on how to define remote sensing, refer to section Remote sensing on PS5000 in the DUT board description file in PS5000 remote sensing of the test head card description.

## Ground sensing on Pin Scale 5000

Pin Scale 5000 cards support also sensing of the common DGND connections. The ground sense pins of a PS5000 pogo block are shared by 16 for SD and HD, and 32 channels for VHD pogo blocks.

For the assignment of the channels to the ground sense pogo pins and the information on how to define ground sensing in SmarTest, refer to [Ground sense to channel assignment](<02.03.08.03.01.04_PS5000_ground_sensing.md#_352190__s_Ground_sense_to_channel_assignment>) and [Defining ground sense in SmarTest](<02.03.08.03.01.04_PS5000_ground_sensing.md#_352190__s_Defining_ground_sense_in_SmarTest>) in topic [PS5000 ground sensing](<02.03.08.03.01.04_PS5000_ground_sensing.md>).
