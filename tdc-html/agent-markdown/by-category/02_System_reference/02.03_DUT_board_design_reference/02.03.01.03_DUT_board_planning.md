# DUT board planning

Planning a new DUT board requires coordinating many participants and providing them with any required data in a timely fashion.

The provided planning template is meant to help you make sure you communicate all relevant information a vendor needs to efficiently design and fabricate a DUT board.

- It provides the vendor with everything needed up-front and thus helps to speed up the design.
- It includes all the information in one place. This eliminates confusion on what was already provided and what is missing.

## Required information

Besides the DUT Board Design Planner, the vendor requires the following information:

- Pin list

Check with the vendor for their preferred format, for example Microsoft Excel.

- Schematic (optional)

If the DUT board has external circuitry, provide a separate schematic, for example as PDF file. Simple schematics may be embedded in the DUT Board Design Planner.

- Bill of materials (BOM)

Include data sheets for the device sockets and DUT board components as PDF files or reference web URLs.

- Mechanical drawings for the handler interface

Provide PDF files or reference web URLs for the drawings.
