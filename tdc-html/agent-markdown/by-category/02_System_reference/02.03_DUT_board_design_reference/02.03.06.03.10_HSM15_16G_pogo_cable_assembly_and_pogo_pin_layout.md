# HSM15/16G pogo cable assembly and pogo pin layout

The E8080P pogo cable assembly connects the 32 channels of the PSSL card to the DUT board. The PSSL card supports the standard pogo locations.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : HSM |

## Pogo cable assembly

 The pogo cable assembly features

- 2 pogo blocks per PSSL card
- 16 signal pogo pins per pogo block
- 32 ground pogo pins per pogo block
  ![PS-SL pogo cable](<../../../../raw/143039.jpg>)

Typically, a PSSL card uses two adjacent pogo block locations close to the DUT, for example, 301, 302 (or 305, 306). For further layout details see [Card Cage to Pogo Slot Standard Assignments](<../02.02_Specifications/02.02.03_Card_Cage_to_Pogo_Block_Standard_Assignments.md>) and [DUT interface layout](<02.03.03.01_DUT_interface_layout.md>).

## Pogo pin assignment

  CAUTION The following signal assignment applies without restriction only to the STD operation mode. With the STDDIFF and FASTDIFF modes, differential drive pins can only be assigned to an odd‑numbered channel pair, and receive pins can only be assigned to an even‑numbered channel pair. Moreover, bidirectional pins are not supported in these modes.
