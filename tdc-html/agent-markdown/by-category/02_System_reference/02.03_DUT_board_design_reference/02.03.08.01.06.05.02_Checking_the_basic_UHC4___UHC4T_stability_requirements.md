# Checking the basic UHC4 / UHC4T stability requirements

When confronted with an oscillating DUT board, this may be caused by an improperly designed power distribution network (PDN).

For any PDN design your main concern must be to satisfy the stability requirements. This is especially true for a PDN of the UHC4 / UHC4T card. If the stability requirements are not met, the UHC4 / UHC4T may oscillate under certain conditions.

For detailed theoretical stability considerations see [Stability of ATE supplies with different ATE test fixtures - UHC4 Stability and special features](<../../03_Use_cases_and_application_papers/03.14_Application_Papers/03.14.08.12_Stability_of_ATE_supplies_with_different_ATE_test_fixtures_-_UHC4_Stabil.md>).

For all practical purposes, you can simplify the underlying stability requirements and follow the steps starting with [Step 1: Calculate the required total capacitance](<02.03.08.01.06.05.03.01_Step_1__Calculate_the_required_total_capacitance.md>).
