# GP-DPS capacitor precautions

- Never use the General Purpose DPS (GP-DPS) without an adequate sum of capacitance as specified by CMin in the table in [GP-DPS performance ranges](<02.03.08.02.01.01.03_GP-DPS_performance_ranges.md>). The GP-DPS will only provide stable operation with an adequate decoupling capacitor.
- Before disconnecting the DUT board, ensure that the DPS is switched to the high impedance mode (minimum current mode).
- To prevent arbitrary output voltages at the DPS in high impedance mode, provide a 100 k惟 resistor on the DUT board between the Force- and the guard pogo pin. This will prevent the DUT board capacitance from charging when the DPS is in high impedance mode. The guard line will carry the leakage current. See [General Purpose DPS (GP-DPS) pogo pin assignments](<02.03.06.04.01_General_Purpose_DPS__GP-DPS__pogo_pin_assignments.md>).
- When you connect multiple DPS channels in parallel, multiply the value of the load capacitor by the number of parallel channels.
