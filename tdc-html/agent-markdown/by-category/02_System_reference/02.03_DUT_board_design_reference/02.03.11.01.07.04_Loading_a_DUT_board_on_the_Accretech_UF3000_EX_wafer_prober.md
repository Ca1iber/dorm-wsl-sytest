# Loading a DUT board on the Accretech UF3000 EX wafer prober

## About this task

This topic tells you how to load a DUT board on the Accretech UF3000 EX Wafer Prober.

Note The photographs used here show just the board stiffener being loaded without a DUT board, however the procedure is identical.

## Before you begin

Before you can load a DUT board, you must have installed the Direct Probe™Bridge Beam on the prober. This is described in [Bridge beam installation on Accretech UF3000 EX prober - Overview](<02.03.11.01.07.03_Bridge_beam_installation_on_Accretech_UF3000_EX_prober_-_Overview.md>).

## Procedure

-  On the main page of the wafer prober display touch the CARD CHANGE button.   ![Touch the CARD CHANGE button](<../../../../raw/151281.png>)

The prober displays the Preparation for CARD CHANGE page:

  ![Preparation for CARD CHANGE screen](<../../../../raw/151282.png>)

and subsequently the Card Change page:

  ![CARD CHANGE START screen](<../../../../raw/151283.png>)
-  On the Card Change page ensure that the AUTO CARD CHANGE method is selected (the button color is displayed in green).

Touch the CARD CHANGE START button.

The prober displays the Auto Card Change page:

   ![Auto Card Change - ATTACH](<../../../../raw/151284.png>)
-  On the Auto Card Change page touch the ATTACH button.

The Auto Card Change page informs you of the processing state:

   ![Auto card change processing state](<../../../../raw/151286.png>)
-  Subsequently, the Card Holder Sensor Status page opens, telling you to open the front door of the prober:  ![Card Holder Sensor Status page: Open front door](<../../../../raw/151285.png>)

  -  Open the front door of the wafer prober.

Pull on both latches on the door, see the figure below,

   ![Front door latches on wafer prober](<../../../../raw/151287.jpg>)

 and open the door.

   ![Prober with the front door open - empty tray](<../../../../raw/151288.jpg>)
  -  Touch the START button on the Card Holder Sensor Status page.    ![Card Holder Sensor Status page: START](<../../../../raw/151297.png>)

You will hear a click. The Card Holder Sensor Status page informs you to pull the tray out:

   ![Card holder sensor status message: Pull out tray](<../../../../raw/151289.png>)

-  Pull the tray out slowly, see the figure below.  CAUTION Make sure you do not bump the tray against any hardware in the wafer prober. You could damage the equipment.   ![Pulling out the tray on the wafer prober](<../../../../raw/151290.jpg>)
-   Note the locations of the guide pins on the tray, refer to the following figure. They serve to position the DUT board on the stiffener.    ![Tray pulled out of the prober. Note the guide pins for the DUT board.](<../../../../raw/151291.jpg>)
-  Place the DUT board with the stiffener on the prober tray. Make sure the guide pins on the tray engage in guide holes in the stiffener. The guide holes are highlighted in the figure below.    ![Placing stiffener on prober tray](<../../../../raw/151292.jpg>)
-  Push the tray back into the wafer prober slowly, making sure you do not bump it against the chuck.    ![Pushing the tray back into the prober](<../../../../raw/151293.jpg>)
-  When done, the prober will prompt you to lock the tray:  ![Card holder sensor status prompt: Lock front door](<../../../../raw/151294.png>)

Touch the LOCK button on the display, see above.

-  The prober prompts you to close the front door and press START.    ![Card holder sensor status: Close front door](<../../../../raw/151295.png>)

  -  Close the front door on the prober.
  -  Touch the START button on the display.     ![Card Holder Sensor Status page: START](<../../../../raw/151297.png>)

-  The prober asks for a confirmation to continue with the DUT board docking procedure:  ![Auto Card Change: Continue to attach card](<../../../../raw/151296.png>)

Touch the CONTINUE button twice.

-   The prober informs you that the DUT board has been successfully docked.    ![Card Holder Sensor Status page: EXIT](<../../../../raw/151301.png>)

Touch the EXIT button.

-  Touch the END button in the bottom right corner of the screen to get back to the main page.

## Results

You have loaded the DUT board in the wafer prober.

## What to do next

You can now proceed to run your tests.
