# Precision Parallel Source (PPS)

The Precision Parallel Source (PPS) is a voltage source designed for A/D converter static tests. One PPS module has two identical static voltage sources. Each voltage source has eight buffered outputs.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : HSM |

Each of the two voltage sources in a PPS module is an independent instrument, except that the two sources share one trigger signal input pin.

The PPS module is typically installed in one of the slots in group 8.

The pin layout for the precision parallel source is shown below. AGND lines are common for all outputs (A0 to A7 and B0 to B7). DGND for TR is separated from AGND.

- A0 to A7: Output pins from one voltage source
- B0 to B7: Output pins from the other voltage source
