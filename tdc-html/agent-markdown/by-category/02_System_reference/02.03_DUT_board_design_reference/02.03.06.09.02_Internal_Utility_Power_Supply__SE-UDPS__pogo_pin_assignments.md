# Internal Utility Power Supply (SE-UDPS) pogo pin assignments

The three-row pogo block of the Internal Utility Power Supply (SE-UDPS) is installed at one of the DPS pogo block positions on the DUT interface. There can be up to eight such positions.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : Smart Scale, Pin Scale |

The functional assignment of the SE-UDPS pogo pads and pins is basically the same as for the legacy [General Purpose DPS (GP-DPS)](<02.03.06.04.01_General_Purpose_DPS__GP-DPS__pogo_pin_assignments.md>), as it uses the GP-DPS/MS-DPS pogo cable.

For SmarTest 7 see the GP-DPS Pogo Pin Assignments for pin layout details.

Unlike the legacy GP-DPS, the SE-UDPS uses no guard and ground sense pins. This results in the following pin assignment for the SE-UDPS:

 | Functional assignment of the SE-UDPS pogo pads |
 |

 | Pin  | a  | b  | c |
 | 1  | G1  | NC  | NC |
 | 2  | G1  | NC  | PS1 |
 | 3  | NC  | NC  | P1 |
 | 4  | NC  | NC  | NC |
 | 5  | G2  | NC  | NC |
 | 6  | G2  | NC  | PS2 |
 | 7  | NC  | NC  | P2 |
 | 8  | NC  | NC  | NC |
 | 9  | NC  | NC  | NC |
 | 10  | NC  | NC  | NC |
 | 11  | G3  | NC  | NC |
 | 12  | G3  | NC  | PS3 |
 | 13  | NC  | NC  | P3 |
 | 14  | NC  | NC  | NC |
 | 15  | G4  | NC  | NC |
 | 16  | G4  | NC  | PS4 |
 | 17  | NC  | NC  | P4  | |

The table uses the following names:

- G#: Ground pad
- P#: Power pad
- PS#: Power sense pad
- NC: Not connected

The assignment of the channel is as follows:

- +5.0 V: P1, PS1, G1 (two pins)
- +12.0 V: P2, PS2, G2 (two pins)
- +15.0 V: P3, PS3, G3 (two pins)
- -15.0 V: P4, PS4, G4 (two pins)
 |
