# Multisite DPS (MS-DPS) pogo pin assignments

The Multisite DPS (MS-DPS) is useful in applications where a low-noise DPS is required, where SmarTest Work Center testing is required (8-channel mode), or where modulation is required.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : Smart Scale (SmarTest 7), Pin Scale, HSM |

The figures show the pogo assembly for the Multisite DPS and the pogo pin block of the assembly.

   ![Pogo assembly for general-purpose DPS and Multisite DPS](<../../../../raw/93111.jpg>)     ![Pins of DPS pogo assembly](<../../../../raw/93245.jpg>)

The table below shows the pin information for the MS-DPS. The table uses the following names:

- G: ground pin
- GRD: guard pin
- GS: ground sense pin
- P: power pin
- PS: power sense pin
- TR+: trigger line pin for external trigger measurement and modulation
- VB+: trigger line pin for V bump
- TRVB- : ground pin for triggers
