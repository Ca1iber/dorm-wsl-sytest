# External utility power supply - Installation, diagnostics, troubleshooting

The external utility power supply unit is an optional device. As such, its installation takes place at the customer site.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : Smart Scale, Pin Scale, HSM |

## Installation

The supply is mounted inside the support rack (LTH, STH) or on the manipulator or engineering cart (ATH, CTH).

  Supply versions The supply is available in two versions, the difference being only in the mounting method. On an LTH or STH system it is mounted inside the support rack. On a CTH or ATH system it is mounted on the manipulator or the engineering cart. Appropriate cables between the power supply and the test head are provided with the power supply, together with matching mounting hardware.

- E7002EUSR: External utility power supply for STH (with DUT Scale interface) and LTH
- E7002EUSM: External utility power supply for ATH (with DUT Scale interface) and CTH (with DUT Scale interface)
 New and retrofit systems On new systems the utility power distribution wiring inside the test head is already installed regardless of whether you have ordered the external utility power supply or not. On test systems that have been put into operation prior to the introduction of 256 utility lines, the power wiring inside the test head must be retrofitted. For information on how to do this refer to the relevant topic:

- LTH with a large DUT interface
- STH with a DUT Scale interface
- CTH with a DUT Scale interface
- ATH with a DUT Scale interface.

Similarly, on new systems, the supply and the power wiring to the test head are in place if this option has been specified on your order. Otherwise, this wiring and the supply must be retrofitted. For information on how to do this refer to the relevant topic:

- LTH and STH systems
- CTH systems
- ATH systems.
Two upgrade kits are available:

- E7002EUUS External utility power supply upgrade for STH with DUT Scale interface and for LTH, consisting of

  - E7002EUSR External utility power supply for STH or LTH
  - E7002UPRL Long cable for utility power between supply and STH or between supply and LTH.

- E7002EUUC External utility power supply upgrade for ATH with DUT Scale interface and for CTH with DUT Scale interface, consisting of

  - E7002EUSM External utility power supply for ATH or CTH
  - E7002UPRS Short cable for utility power between supply and ATH or between supply and CTH.

## Diagnostics

 The UTIL - Utility connectivity test checks the correct functioning of the external utility power supply.Note To run the test you must dock the E7010F interconnection board.

## Troubleshooting

In case, the power outputs of the external utility power supply are not enabled, do the following:

- Ensure that the external utility power supply has its power cord connected.
- Ensure that the external utility power supply is turned on: There is a small switch near the AC input terminal.
- Ensure that the model file of SmarTest 7 or the tester.model file of SmarTest 8 is configured for active wiring board; one line should look similar to the following one: `utility_lines = ..., type=sequencer_controlled, pogo_size=32`
- When turning on the test head, the fan of the external utility power supply should start running for a short time and afterward it stops.
- Start the software and load a device that uses 32 utility lines per block (this is a prerequisite to run the diagnostic with all 4-row utility block features).
- Start the diagnostic (at least the utility line test) with an E7010F Diagnostics Interconnect board (there are different versions of E7010F, that should all work - any older interconnect board up to E7010E will not test the external utility power supply).
- Check the log files to ensure that the external utility power supply was tested. When the diagnostic fails or when the external utility power supply is not tested at all you have to check the power supply and the cabling.Note The external utility power supply is not configured in the model file. Diagnostics measures therefore the impedance of the supply outputs. The actual tests of the output voltage are performed only if the supply has been detected by the impedance measurements.
- When the external utility power supply tests are passing you have to check your DUT board: Pogo pins "DSC" and "POG4R" of the utility pogo blocks must be connected to UGND. These pins indicate that the DUT board is connected and that 4-row pogo blocks are used that is a prerequisite to turning on the power supply.

Note that the external power supply cannot be easily activated when the E7010F Diagnostics Interconnect board is docked: interface: The connectivity of the "DSC" and "POG4R" pogo pins is also tested by the diagnostic and these lines are not at low level by default!
