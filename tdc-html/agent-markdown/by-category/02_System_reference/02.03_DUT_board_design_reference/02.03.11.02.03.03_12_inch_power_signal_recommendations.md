# 12 inch power signal recommendations

For DC Scale cards like the UHC4 / UHC4T, which can be placed in any channel card slot, on the 12 inch pogo tower you should use the high-current pins that are rated to 25 A each. If additional connections are needed, you can also use the signal pins.

Each signal pin is rated for 4 A. But to reduce the overall resistance to the power distribution through the pogo tower, the current should be shared between several pins. As guideline use an effective power rating (not peak) of 1.3 A per pin.
