The following table shows the pogo pin cabling requirements according to the mode you require.

 | Pogo pins  | Cabling required for mode |
 | MUX 4  | MUX 2  | Loopback |
 | High-speed pogo pins  | X  |   | |
 | Low-speed pogo pins  | X  | X  | |
 | Modulation and tracking on low speed pogo pins  | Application depending on whether you wish to feed in external signals for jitter modulation or cascade tracking or modulation signals  |    Note The x2 (MUX 2) operation mode requires Mux/DeMux 0 and 2 of the low-speed pogo block.
