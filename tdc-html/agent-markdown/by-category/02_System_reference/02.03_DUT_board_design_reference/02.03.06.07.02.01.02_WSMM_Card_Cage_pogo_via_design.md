# WSMM Card Cage pogo via design

The pogo vias connect the pogo pins of the WSMM Card Cage DUT interface to the signal trace of the DUT board. The layout of pogo vias for a WSMM DUT board is the same as the pogo via layout of a DUT board for the DUT Scale interface.
