# Twinning DUT board design for Direct-Probe

Twinning DUT board design for Direct-Probe™wafer probing applications has some additional mechanical requirements, and pogo segment pin assignment restrictions, compared to the Twinning DUT board for package testing. The main difference to the standard Twinning DUT board design is shown in the pictures below. For the pogo segment area in Group 8B and 3A, a mechanical cut-out is necessary that does not exist on the standard Twinning DUT board design. This cut-out ensures compatibility between the Twinning stiffener and the standard stiffener for the prober. It is important that no signal pins are assigned in the cut-out area. For details on the DUT board design for direct-probe requirements see [Twinning DUT and family board info](<02.03.12.01.19_Twinning_DUT_and_family_board_info.md>).
