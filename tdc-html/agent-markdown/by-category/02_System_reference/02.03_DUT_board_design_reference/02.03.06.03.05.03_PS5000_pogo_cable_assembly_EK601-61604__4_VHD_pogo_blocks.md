# PS5000 pogo cable assembly EK601-61604: 4 VHD pogo blocks

The EK601-61604 pogo cable assembly connects the 256 channels of a PS5000 card via 4 very-high-density (VHD) pogo blocks to the DUT board.

## Basic data and pogo block

 |   ![PS5000 very-high-density (VHD) pogo block](<../../../../raw/352664.png>) |

 | Overall length:  | 585 mm |
 | Pogo block style:  | 7-row very-high-density (VHD) pogo block |
 | Pogo blocks:  | 4 |
 | Channels per pogo block:  | 64 |
 | Total channels:  | 256  | |
