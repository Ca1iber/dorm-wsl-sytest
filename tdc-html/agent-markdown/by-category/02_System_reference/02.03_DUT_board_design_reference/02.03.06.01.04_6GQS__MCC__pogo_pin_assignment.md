# 6GQS (MCC) pogo pin assignment

This section gives you an overview of the pin assignments of the 6GQS - 6Gig Quad Sampler (MCC).

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : Smart Scale (SmarTest 7), Pin Scale |

## Notes on GND pins:

- AGND - Analog ground - The AGND pins in one 6Gig Quad Sampler (MCC) module are connected to each other inside the analog module.

For the MCC, the AGND is also the ground for the common trigger input. On the DUT board, wire the AGND of the MCC to the ground of the digital channel that is used as a trigger source.

The 6Gig Quad Sampler (MCC) module contains four units. For the E9726A/B measure model, all units are measure units.

Each measure unit contains one sampler (110 Msps 16-bit). The MCC module has the common trigger (CT1/2) pins. The common trigger pins can be shared with any units in an MCC.

The figure shows the MCC pogo assembly and one of its pogo pin blocks.

   ![MCC pogo assembly](<../../../../raw/93167.jpg>)     ![Pins of pogo pin assembly](<../../../../raw/93238.jpg>)

The pin assignment table below uses the following names:

AGND: analog ground on analog module

CT1, CT2: Common trigger input

A+, A-, to D+, D-: Sampler input, MCC- PMU pin, or V source output

AA+, AA- to DD+, DD-: MCC-PMU pin or V source output

The MC uses both the S1 and S2 pogo blocks. (Only CT2 uses the S1 block.)
