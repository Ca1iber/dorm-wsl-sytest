# PS400 pogo assembly and channels

The Pin Scale 400 pogo assembly consists of four 16-channel pogo blocks that are available at the DUT interface. The figures show the Pin Scale 400 pogo assembly, and a close up view of the pogo pins.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : Pin Scale   |     ![Pin Scale 400 pogo assembly](<../../../../raw/92818.jpg>)     ![Pins of pogo pin assembly for Pin Scale 400/800 cards](<../../../../raw/93237.jpg>)

The table below shows the standard pin assignments for the 16 channels of a single Pin Scale 400 pogo assembly block.

The orientation mark shown on the diagram appears as a shallow hole or depression on the pin block mounted to the test head. It is recommended that a similar mark be included as part of the printed labeling on the DUT board.

The table uses the following abbreviations:

- GND: ground
- NC: pin not connected
- I/O: input/output
