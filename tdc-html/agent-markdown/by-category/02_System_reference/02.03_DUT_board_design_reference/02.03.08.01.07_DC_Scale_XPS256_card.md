The XPS256 is a high-density scalable DUT power supply and V/I card for all SOC test applications. The card belongs to the DC Scale family and can reside in any channel card slot of a V93000 EXA Scale system.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : EXA Scale (SmarTest 7+8)   |    ![XPS256 card photo](<../../../../raw/350665.png>)

## Electrical design rules

Some specific electrical design rules must be considered for the DC Scale XPS256 card to ensure that the specifications for the card and the maximum ratings for the pogo pins can be met. The following topics describe the XPS256 pins and provide some design rules.

For specification data of the pins, refer to [XPS256 other performance characteristics](<../02.02_Specifications/02.02.05.03.07_XPS256_other_performance_characteristics.md>).

## Specific design rules

Specific design rules must be followed when designing a new DUT board:

- [Pin assignment for Fast Sync / Fast Match](<02.03.07.06_Pin_assignment_for_Fast_Sync___Fast_Match.md>): For fast local synchronization, the synchronized DUT pins must be assigned to the same group of eight channels respectively to the same test processor[1)](<#_350677__d1727e1349>).
- Memory pooling: XPS256 cards support memory pooling in groups of eight channels respectively within the same test processor[1)](<#_350677__d1727e1349>). This must be taken into account when assigning the channels if, for example, very large amounts of sample data are expected for individual channels.
- [Ganging](<02.03.08.01.07.05_XPS256_ganged_wiring.md>): There are no restrictions for ganging XPS256 channels within a logical board of 16 channels. However, a maximum of 16 ganging groups are supported for ganging across logical boards on the same card. Each high-density (HD) XPS256 pogo block covers one logical board and each very-high-densitiy (VHD) pogo block covers two logical boards that are assigned to the PA# pins and to the PB# pins.
- [HV (High-Voltage) protection](<02.03.08.01.07_DC_Scale_XPS256_card.md#_350677__s_HV_protection>): Since the XPS256 card can possibly be connected to high-voltage cards via defective DUTs or unintentionally closed connections, we recommend that you implement a HV (High-Voltage) protection circuitry on your DUT boards if the voltage exceeds the compliance range of the XPS256 channels.
- [XPS256 recommendations for use](<02.03.08.01.07.03_XPS256_recommendations_for_use.md>) and [XPS256 capacitor requirements](<02.03.08.01.07.02_XPS256_capacitor_requirements.md>): These topics in section [Electrical design: Product-specific rules](<02.03.08_Electrical_design__Product-specific_rules.md>) of the [DUT board design reference](<02.03_DUT_board_design_reference.md>) provide information about wiring of the sense line and additional capacitors on the DUT board.
- [XPS256 VHD pogo pad and via design](<02.03.08.01.07.04_XPS256_VHD_pogo_pad_and_via_design.md>): An optimized pogo via design uses a minimized hole diameter of the via in combination with a controlled depth drill as pogo pin contacting area. The design is more complex than the standard pogo via design for the [VHD block](<02.03.06.02.07_XPS256_pogo_pin_assignment.md#_350670__s_Pogo_pin_assignment_VHD_pogo_block>), but provides more space for routing on the inner layers.

## Power budget

Unlike legacy similar cards, XPS256 does not require distributing a power budget across the active pins.

Nevertheless, the available power of an XPS256 card limits the maximum current for the 256 channel high-current variant XPS256 (EK751HC) in some cases as can be seen in [XPS256 voltage and current capability specifications](<../02.02_Specifications/02.02.05.03.04_XPS256_voltage_and_current_capability_specifications.md>).

## HV (High-Voltage) protection

The XPS256 card may be connected to high-voltage cards via defective DUTs or unintentionally closed connections.

Disconnected XPS256 channels can withstand any voltage within a compliance voltage range and are protected against high voltage pulses up to ±80 V:

 | |

 | Compliance range (at disconnect state) |
 | Min/max external voltage at force input  | -4.5 V 鈥?nbsp;+7.5 V |
 | Min/max external voltage at sense input  | -4.5 V 鈥?nbsp;+7.5 V  | |
 | |

 | Overvoltage protection |
 | Maximum voltage range  | -80 V 鈥?+80 V |
 | Maximum energy of voltage spike  | 20 mJ |
 | Maximum current  | 1.0 A  | |

In case defective DUTs or unintentionally closed connections can apply voltages that exceed the limits defined above, we strongly recommend that you implement a [HV (High-Voltage) protection](<02.03.07.03_HV__High-Voltage__protection.md>) circuitry on your DUT boards to protect the low-voltage channels of the XPS256 card. This will improve the uptime of the test system and the throughput of high-voltage applications.
