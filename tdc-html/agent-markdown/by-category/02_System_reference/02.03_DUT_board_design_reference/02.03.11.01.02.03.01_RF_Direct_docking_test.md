# RF Direct docking test

The RF Direct Docking test verifies the cabling of the [Direct-Probe solution](<02.03.11.01_Direct-Probe_interface.md>). This test uses TV calibrations data.

During this test, a Stimulus signal is generated using a RF source card (Src). The signal is directed through a port to the [Direct-Probe RF Interconnect Board](<02.03.11.01.02.03_Direct-Probe_RF_Interconnect_Board.md>) and looped the receiver port. Measurements are performed using RF source card 2 as LO and digitizers of MCB as illustrated in the following figure. All available Ports will be tested during the Direct Docking Test. Default port numbers on [Direct-Probe RF Interconnect Board](<02.03.11.01.02.03_Direct-Probe_RF_Interconnect_Board.md>) are 48 ports. An upgrade to 96 ports is possible.
