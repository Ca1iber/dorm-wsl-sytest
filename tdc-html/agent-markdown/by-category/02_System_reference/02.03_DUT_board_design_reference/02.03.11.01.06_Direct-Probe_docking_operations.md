There are several capabilities to move and rotate the test head manually.

## Manipulator

The vertical movement can either be done by the manipulator motor, or manually by using the crank. The manipulator motor power is generated, regulated and switched on the rack interface board.

For detailed information on the manipulator, see the corresponding documentation:

- For Advantest's V93000 large and small test head manipulator, see the chapter Test head movement in the LTH CTH Manipulator Installation Guide.
- For Advantest's V93000 compact test head manipulator, refer to the ESMO Installation Manual Part 1 and Part 2 supplied with the manipulator.

The test head might be connected to an evo or a tumble manipulator that provides a motor to move the test head up and down. A remote control is available, see [Remote control unit (V93000 EXA Scale system)](<02.03.03.04_Remote_control_unit__V93000_EXA_Scale_system.md>) or [Remote control unit (V93000 Pin Scale / Smart Scale system)](<02.03.03.05_Remote_control_unit__V93000_Pin_Scale___Smart_Scale_system.md>).

For the compact test head, inside the test head a beeper board provides the electrical connections between the related parts and locking mechanisms.

## DUT docking

To lock DUT boards to V93000 test heads and to connect the pogo pins, Advantest provides a [DUT docking](<02.03.11.01.06.02_DUT_docking_for_Direct-Probe.md>) mechanism that uses compressed air. As an option Advantest provides a [hard docking](<02.03.11.01.06.01_Hard_docking_for_Direct-Probe.md>) interface.

Note Direct docking requires an LTH test head or a DUT Scale interface.
