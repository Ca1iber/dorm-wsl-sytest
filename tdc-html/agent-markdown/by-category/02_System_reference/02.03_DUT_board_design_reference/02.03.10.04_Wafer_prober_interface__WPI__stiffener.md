# Wafer prober interface (WPI) stiffener

The V93000 features four Wafer Prober Interface (WPI) DUT board stiffeners for the Pin Scale DUT interface:

- A full-size 9.5 inch WPI stiffener (legacy product number: E7018BB) for 1024 channel boards
- A half-size 9.5 inch WPI stiffener (legacy product number: E7018BA) for 512 channel boards
- A full-size 12 inch WPI stiffener (product number: E7018HB)
- A half-size 12 inch WPI stiffener (product number: E7018HA)

WPI DUT board stiffeners and Pin Scale DUT board stiffeners are identical in general mechanical design except that WPI DUT board stiffeners do not use inlay plates for docking. See [DUT board stiffeners](<02.03.10.01_DUT_board_stiffeners.md>) for information about components that are common to both types of stiffeners, such as inner and outer roller assemblies and stiffener bushings.

The half-size and full-size WPI DUT board stiffeners can be docked to either size Pin Scale DUT interface. When you use a half-size stiffener with the large (1024 pins) DUT interface, protect the unused pogo blocks by covering them with the non-conducting plates supplied with each large DUT interface.

The WPI DUT board stiffener is an aluminum frame which gives the DUT board the necessary mechanical stability to withstand the pressure placed on the DUT board by the test head's pogo pins.

The WPI DUT board also provides the docking elements for docking of the DUT board to the DUT interface. See [DUT board stiffener manufacturing guidelines](<02.03.10.03_DUT_board_stiffener_manufacturing_guidelines.md>) and the following sections for details on the locking elements.

To ensure long term reliable contact to all pogo pins, it is essential that the stiffeners are manufactured to tight mechanical tolerances. Advantest can provide you with reliable, precisely manufactured aluminum and steel stiffeners.

If you choose to manufacture your own stiffeners, follow the instructions in the referenced drawings carefully.

 Note Before manufacturing or supplying WPI DUT board stiffeners, verify whether a standard DUT interface is in use or whether any modifications were performed by Advantest or any other party. If a nonstandard interface is in use, contact your Advantest representative before proceeding.
