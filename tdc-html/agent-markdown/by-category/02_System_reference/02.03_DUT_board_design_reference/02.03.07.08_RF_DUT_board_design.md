RF DUT boards deal with very high frequency signal routing and therefore require RF specific design solutions.

The simple concentrated parameter design approach usually needs to be replaced with distributed parameter elements applying Electro Magnetic (EM) wave propagation theory. Multisite DUT boards for devices with large number of RF ports at each site provide additional challenges.

The sections linked above provide various RF and high frequency routing and signal propagation design approaches and describe how to utilize Advantest's High Density (HD) Port Scale solution and RF DUT Board components.

They also address RF specific considerations regarding

- possible leakage and crosstalk,
- fencing and shielding, and
- matching networks between DUT and Test system.

For the power supply design see also [DPS layout rules for high frequency designs](<02.03.07.01.04_DPS_layout_rules_for_high_frequency_designs.md>).
