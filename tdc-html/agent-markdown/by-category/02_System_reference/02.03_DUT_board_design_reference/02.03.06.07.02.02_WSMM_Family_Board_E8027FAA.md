# WSMM Family Board E8027FAA

#### Subtopics

- [WSMM Family Board E8027FAA pogo block mapping](<02.03.06.07.02.02.01_WSMM_Family_Board_E8027FAA_pogo_block_mapping.md>)
- [WSMM Family Board E8027FAA pogo pin mapping](<02.03.06.07.02.02.02_WSMM_Family_Board_E8027FAA_pogo_pin_mapping.md>)

The family board of the Wave Scale Millimeter (WSMM) solution maps custom configured DUT Scale interface resources to the pogo blocks of the WSMM Card Cage DUT interface. The family board is integrated into the WSMM card cage (WSMM Card Cage).

 ![Wave Scale Millimeter main components](<../../../../raw/348728.png>)

Compared to the [DUT Scale interface](<02.03.03.02_DUT_Scale_interface.md>), the pogo block groups and RF ports of the WSMM Card Cage are shifted outwards providing more application space in the center of the board.

 ![WSMM Card Cage family board concept](<../../../../raw/348891.png>)

The inner four groups of the [WSMM Card Cage DUT Interface](<02.03.06.07.02.01_WSMM_Card_Cage_DUT_Interface.md>) are reserved for the RF ports of the Remote Mixing Modules. The family board must therefore route the resources of the DUT scale interface to the outer four groups 4, 5, 6, and 7 of the WSMM Card Cage DUT interface.

## Pogo block mapping

The WSMM Family board is adapted to a customer-specific configuration of the DUT Scale interface. For the assignment from the pogo blocks of the DUT Scale interface to the pogo blocks of the WSMM Card Cage DUT interface, refer to [WSMM Family Board E8027FAA pogo block mapping](<02.03.06.07.02.02.01_WSMM_Family_Board_E8027FAA_pogo_block_mapping.md>).

## Pogo pin mapping

The table in [WSMM Family Board E8027FAA pogo pin mapping](<02.03.06.07.02.02.02_WSMM_Family_Board_E8027FAA_pogo_pin_mapping.md>) provides detailed information how the individual pogo pins of the DUT Scale interface are mapped to the pogo pins of the WSMM Card Cage DUT interface.
