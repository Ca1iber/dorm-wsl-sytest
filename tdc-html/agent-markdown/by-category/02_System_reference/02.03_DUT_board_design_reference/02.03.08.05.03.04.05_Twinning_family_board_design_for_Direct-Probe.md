# Twinning family board design for Direct-Probe

Due to the Direct-Probe™mechanical requirements, note that the following pins in groups 8B and 3A cannot be used by the Twinning family board. Refer also to [Twinning DUT board design for Direct-Probe](<02.03.08.05.03.05.03_Twinning_DUT_board_design_for_Direct-Probe.md>).

- Group 8B: Rows AG...Y and columns 0...7
- Group 3A: Rows AG...Y and columns 10...18
