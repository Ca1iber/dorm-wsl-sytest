# Link adapter plate and pogo tower

## About this task

This task is about linking the prepared adapter plate kit to the pogo tower frame.

## Before you begin

Make sure you have prepared the adapter plate and you have equipped the pogo tower frame with the needed pogo segments.

## Procedure

-  Insert the prepared adapter plate kit into the pogo tower frame so that the direction arrows on both assemblies are aligned with each other. The arrows on the pogo tower frame are embossed on the outer ring.  ![Adapter Plate Kit into the Pogo Tower](<../../../../raw/103246.jpg>)
-  Secure the adapter plate kit to the pogo tower frame with four Torx T20 countersink screws.  ![Mount Adapter Plate Kit into the Pogo Tower Frame](<../../../../raw/103247.jpg>)

## What to do next

Prepare the probe card ring.
