# Internal Utility Power Option (V93000 EXA Scale systems)

The Internal Utility Power Option can be routed to a 3-row DPS-slot pogo block if maximum one optional Utility card (EK051 or EK051A) is installed. The supply provides compatibility with the legacy SE-UDPS and requires the EK051UP pogo cable assembly.

## Functional changes

- Introduced in SmarTest 8.3.4
- SmarTest 8.4.1: Default pogo block changed from 266 (DPS 1) to 268 (DPS 8).
- SmarTest 8.4.3: Support of LX test head of V93000 EXA Scale systems.
[1)](<#fnsrc_1>) Maximum one Utility card (EK051 or EK051A) can be installed for accessing the Internal Utility Power Option. The second Utility card occupies the pogo block position that is required for the Internal Utility Power Option.[2)](<#fnsrc_2>) Pogo block DPS 8 (268) is the recommended position as defined in the V93000 Standard Configuration Guidelines.
