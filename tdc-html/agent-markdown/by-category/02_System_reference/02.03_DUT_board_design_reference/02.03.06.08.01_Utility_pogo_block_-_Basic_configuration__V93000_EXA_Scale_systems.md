# Utility pogo block - Basic configuration (V93000 EXA Scale systems)

V93000 EXA Scale systems in basic configuration without the optional Utility Card provide 32 statically controlled utility lines and a +5 V utility power supply that are routed to a single 4-row utility block. For the SX and LX test heads, these internal resources can optionally be extended by 32 utility lines and one +5 V utility power supply, which are routed to another 4-row utility block.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : EXA Scale (SmarTest 7+8) |

For the utility pogo pin assignment of a V93000 EXA Scale system that is equipped with the [optional Utility Card](<../02.05_Test_Head_Cards/02.05.08.04_Utility_Card.md>), refer to [Utility pogo block - Utility Card (V93000 EXA Scale systems)](<02.03.06.08.02_Utility_pogo_block_-_Utility_Card__V93000_EXA_Scale_systems.md>).

## Wiring rules and notes

- Connect all pogo pins of all blocks of the same utility supply output to a separate power plane on the DUT board.
- Connect all sense pins of all blocks of a utility supply output to the related power plane.
- Utility power supply pogo pins of different card cages must not be connected together.
- Maximum offset of utility ground to system ground: 卤0.5 V
- Pins URW14 and URW15 of utility block 1 (UTIL 1) are internally connected to the DUT Interface EEPROM of the system and can be used to control up to three more EEPROMS on the DUT board or probe card. For more information, refer to [Utility Lines and DUT Board EEPROMs](<02.03.04.06_Utility_lines_and_DUT_board_EEPROMs.md>).Note Utility pins URW14 and URW15 on utility block 1 are not to be used for a purpose other than EEPROM access otherwise the readout from the DUT Interface EEPROM may become corrupted. This would be the case when the DUT Board is docked while an EDC dump is in progress. For more information, refer to EDC Dump in the "Service Guide Part 1".
-
