# Link Scale USB3 pogo pin assignment

 The Link Scale USB3 card supports software-based functional tests and high‑speed I/O (HSIO) scan tests using the USB protocol. A matrix in the front‑end of the card supports also routing signals of other DUT board resources to the DUT.

## Pogo pin assignment HD pogo block

The high-density (HD) pogo block connects 32 channels of a Link Scale USB3 card to a DUT board. The HD block is used for a Link Scale USB3 card pogo cable assembly.

The HD pogo block can also connect to a DUT board that is designed for the VHD pogo block type, but can access only the channels on rows a, b, c, and d. For more information, refer to [Pogo block compatibility](<02.03.07.07.01_Pogo_block_compatibility.md>).
