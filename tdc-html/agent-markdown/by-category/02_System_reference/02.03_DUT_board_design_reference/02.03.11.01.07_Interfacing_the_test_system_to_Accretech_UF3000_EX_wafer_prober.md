This section takes you through the steps needed to interface the V93000 test system with the Accretech UF3000 EX wafer prober.

You need to:

- prepare the wafer prober for the installation of a special piece of hardware called the Direct Probe鈩?Bridge Beam
- install the Direct Probe鈩?Bridge Beam hardware in the wafer prober
- load a DUT board into the wafer prober.
