# Bridge beam installation on Accretech UF3000 EX - Phase 2

An outline of the installation process is given in [Bridge beam installation on Accretech UF3000 EX prober - Overview](<02.03.11.01.07.03_Bridge_beam_installation_on_Accretech_UF3000_EX_prober_-_Overview.md>).

## About this task

This task deals with Phase 2 (of 2) of the installation process.

## Before you begin

 Note Installation must only be performed by trained personnel experienced with the operation and maintenance of Accretech UF3000EX series probers. CAUTION Two persons are required to install the Direct Probe™Bridge Beam hardware. This is to ensure that no damage is caused to the sensor cables or to the pneumatic hoses leading to the Bridge Beam.

## Procedure

-  Press the cables and hoses neatly into the cable channel on either side.    ![Cables and hoses laid out in the cable channel](<../../../../raw/151268.jpg>)
-  ![Pozidriv Pz3](<../../../../raw/73673.png>) Mount the cable cover using a Size 3 Pozidriv screwdriver.    ![Mounting the cable cover on the wafer prober](<../../../../raw/151270.jpg>)

## Results

This completes phase 2 of the installation procedure.
