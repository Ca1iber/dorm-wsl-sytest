# High Voltage DPS (HV-DPS) pogo pin assignments

The High Voltage DPS uses the same pin layout as the general purpose DPS.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : Smart Scale (SmarTest 7), Pin Scale |

See [General Purpose DPS (GP-DPS) pogo pin assignments](<02.03.06.04.01_General_Purpose_DPS__GP-DPS__pogo_pin_assignments.md>) for details and pin assignment.

If you install one or more High Voltage DPSs:

- General Purpose DPSs will be limited to -4 V to +8 V range when High Voltage DPSs are connected in parallel (ganged).
- High Current DPSs cannot be connected in parallel (ganged).
