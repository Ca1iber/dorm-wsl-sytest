# Installing HD pins to Accretech prober's headstage

Follow the procedure to install the hard docking pins to the Accretech prober's headstage.

## Before you begin

   ![Tools](<../../../../raw/344358.svg>)Tools:

- ![Allen5](<../../../../raw/112988.png>) Allen key
- ![Wrench17](<../../../../raw/113034.png>) Open-ended wrench
- ![Torx_10](<../../../../raw/113062.png>) Torx screwdriver
    ![Parts](<../../../../raw/344357.svg>)Parts:

- Hard docking pins

![HD pin](<../../../../raw/354592.png>)

## Procedure

-  Hold the hard docking pin with a ![Wrench17](<../../../../raw/113034.png>) Open-ended wrench, and remove the top screw with the help of ![Allen5](<../../../../raw/112988.png>) Allen key as shown below.

![HD pin](<../../../../raw/354592.png>)

![Disassemble HD pin](<../../../../raw/354591.png>)

-  Disassemble the pin as shown below.

![Parts od HD pin](<../../../../raw/354593.png>)

-  Take the lower part of the pin and place it on the Accretech prober's headstage.

![Pin](<../../../../raw/354594.png>)

![Headstage](<../../../../raw/354596.png>)

-  Using ![Torx_10](<../../../../raw/113062.png>) Torx screwdriver, affix the pin to the headstage with the three screws provided.

## Results

You have attached the hard docking pins to the Accretech prober's headstage.
