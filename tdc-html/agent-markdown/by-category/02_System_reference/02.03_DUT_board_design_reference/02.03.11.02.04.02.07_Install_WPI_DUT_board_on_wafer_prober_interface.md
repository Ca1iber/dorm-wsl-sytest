# Install WPI DUT board on wafer prober interface

## About this task

This task is about mounting the WPI DUT board onto the wafer prober interface.

## Before you begin

Ensure you have mounted the probe card stiffener into the mounting ring.

## Procedure

-  Place the DUT board on the wafer prober interface.
-  Lock it in place with the two locking levers.  ![WPI DUT board on WPI](<../../../../raw/103278.jpg>)
-  Adjust the height of the adapter plate kit to compensate for the thickness of the DUT board PCB.

  -  Raise the height of the adapter plate slightly by evenly turning out all four adjustment screws.
  -  Push out all four black levers so they click in.
  -  Using a flat head screwdriver, turn each adjustment screw on the adapter plate until the black levers touch the WPI DUT Board stiffener. This gives the correct height.
  -  Lock each adjustment screw by bringing up the serrated lock ring.  ![Height adjustment WPI](<../../../../raw/103279.jpg>)   ![Height adjustment WPI DUT boand on WPI](<../../../../raw/103280.jpg>)
