# Pogo via depth example

#### Subtopics

- [Pogo pin with knife edge tip](<02.03.07.07.04.01_Pogo_pin_with_knife_edge_tip.md>)
- [Pogo pin with cone shaped tip](<02.03.07.07.04.02_Pogo_pin_with_cone_shaped_tip.md>)

In this example a small 12 mil through via goes all the way through the board. A controlled depth drill 27 mil FHS via serves as pogo pin contacting area. All dimensions in the drawing below are in mm.

   ![Pogo pin design example (Knife edge tip)](<../../../../raw/93576.png>)

For the nominal 26 mil FHS via with a +1/-3 mil tolerance you can assume a maximum pin depth of 13 mils. This applies both for the [ Pogo pin with knife edge tip](<02.03.07.07.04.01_Pogo_pin_with_knife_edge_tip.md>) and for the [ Pogo pin with cone shaped tip](<02.03.07.07.04.02_Pogo_pin_with_cone_shaped_tip.md>).

When using controlled depth drilling you must specify a 20 mil +/- 7 mil drill depth to accommodate the drill tolerance and guarantee a 13 mil depth.
