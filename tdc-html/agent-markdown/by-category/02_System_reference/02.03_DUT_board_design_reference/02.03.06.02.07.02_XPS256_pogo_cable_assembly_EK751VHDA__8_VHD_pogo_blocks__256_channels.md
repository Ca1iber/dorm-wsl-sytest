# XPS256 pogo cable assembly EK751VHDA: 8 VHD pogo blocks, 256 channels

The EK751VHDA pogo cable assembly connects 256 channels of an XPS256 card via 8 very-high-density (VHD) pogo blocks to the DUT board.

## Basic data and pogo block

 |   ![XPS256 pogo block VHD](<../../../../raw/351425.png>) |

 | Overall length:  | 750 mm |
 | Pogo block style:  | 7-row very-high-density (VHD) pogo block |
 | Pogo blocks:  | 8 |
 | Channels per pogo block:  | 32 |
 | Total channels:  | 256 |
 | Part number:  | EK751-61605  | |
