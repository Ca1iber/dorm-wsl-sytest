# Utility line interface circuitry

#### Subtopics

- [Relay drivers](<02.03.04.03.01_Relay_drivers.md>)
- [Reducing noise on utility lines](<02.03.04.03.02_Reducing_noise_on_utility_lines.md>)
- [Utility line example circuits](<02.03.04.03.03_Utility_line_example_circuits.md>)

The utility line driver (for the write operation) is a Darlington pair open collector circuit.

 Note At low collector currents (< 10 mA) the utility line driver typically has a low level of ~0.7 V. At higher collector currents it has a level of up to 1.0 V. Consider this when using the utility lines to write to a device. Note If the utility line is connected to devices with higher input impedance there should be a stronger pull-up resistor employed, in the region of several hundred Ohms, depending on the type of device used.

The utility line interface circuitry varies with the type of wiring board your system is fitted with - the passive wiring board or the active wiring board.

Descriptions of the circuits together with the relevant diagrams are provided in [Utility line characteristics](<02.03.04.02_Utility_line_characteristics.md>).
