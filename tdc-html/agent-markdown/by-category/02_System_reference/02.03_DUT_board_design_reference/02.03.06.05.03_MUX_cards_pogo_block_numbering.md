# MUX cards pogo block numbering

Each of the MUX cards features one 34-row pogo interface that is divided into two 17-row blocks.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : EXA Scale (SmarTest 8), Smart Scale (SmarTest 7+8)   |   ![MUX Cards pogo block numbering](<../../../../raw/146879.png>)

## MUX card configuration in the model file

Diagnostics of the MUX cards in SmarTest 7.3.4 or higher versions requires defining all installed MUX cards in the model file. For more information, refer to keyword mux_boards in the [GLOBAL section](<../02.04_Model_File_and_Licensing/02.04.01.03.02.01_GLOBAL_section.md>) of the SmarTest 7 model file or in the [GLOBAL section of tester.model](<../02.04_Model_File_and_Licensing/02.04.01.03.01.01_GLOBAL_section.md>) of SmarTest 8 .

The following is an example of the GLOBAL section in the model file for configuring MUX cards:

```
GLOBAL
    mux_boards = 8, type=PMUX01, pogoblocks=866,868,870,872,881,883,885,887
```
