# Alternative cables for the high-density Port Scale RF solution

For very high-density Port Scale RF solution requirements you may want to consider microbend庐 cables provided by HUBER+SUHNER Astrolab, Inc..

The microbend庐 cables have a minimum inner bending radius of 1.5 mm (60 mil). As they Do not have strain reliefs, they allow immediate sharp turns close to the connector. Thus they are ideally suited for extremely limited routing space. The graphic shows an example microbend庐 cable with an SMA connector to visualize the bending capabilities.
