## Pogo pin assignment SD pogo block

 The standard-density (SD) pogo block (sometimes referred to as a single-density pogo block) connects 16 channels of a PS1600 card to the DUT board. The SD block is used for the following PS1600 pogo cable assemblies:

- [PS1600 pogo cable assembly E8030PSD: 8 SD pogo blocks](<02.03.06.03.03.01_PS1600_pogo_cable_assembly_E8030PSD__8_SD_pogo_blocks.md>)
- [PS1600 pogo cable assembly E8030PSDL: 8 SD pogo blocks](<02.03.06.03.03.02_PS1600_pogo_cable_assembly_E8030PSDL__8_SD_pogo_blocks.md>)

The SD pogo block can also connect to DUT boards that are designed for the HD pogo block or for the VHD pogo block but can access only the channels A1 鈥?nbsp;A16 on rows b and c. For more information, refer to [Pogo block compatibility](<02.03.07.07.01_Pogo_block_compatibility.md>).

## Pogo pin assignment HD pogo block

 The high-density (HD) pogo block connects 32 channels of a PS1600 card to the DUT board. The HD block is used for the following PS1600 pogo cable assembly:

- [PS1600 pogo cable assembly E8030PHD: 4 HD pogo blocks](<02.03.06.03.03.03_PS1600_pogo_cable_assembly_E8030PHD__4_HD_pogo_blocks.md>)

The HD pogo block can also connect to DUT boards that are designed for the SD pogo block as long as landing pads are provided for the extra pogo pins of the HD block. In addition, the HD pogo block can connect to DUT boards that are designed for the VHD block but can access only channels A1 鈥?nbsp;A16 and B1 鈥?nbsp;B16 on rows a, b, c, and d. For more information, refer to [Pogo block compatibility](<02.03.07.07.01_Pogo_block_compatibility.md>).

## Pogo pin assignment VHD pogo block

The very-high-density (VHD) pogo block connects 64 channels of a PS1600 card to the DUT board. The VHD block is used for the following PS1600 pogo cable assembly:

- [PS1600 pogo cable assembly E8030PVHD: 2 VHD pogo blocks](<02.03.06.03.03.04_PS1600_pogo_cable_assembly_E8030PVHD__2_VHD_pogo_blocks.md>)

The VHD pogo block can also connect to DUT boards that are designed for the SD pogo block or for the HD pogo block as long as landing pads are provided for the extra pogo pins of the VHD block. For more information, refer to [Pogo block compatibility](<02.03.07.07.01_Pogo_block_compatibility.md>).

This pogo cable assembly is to be used for special configurations only.

## Specific design rules

 Specific design rules must be followed when designing a new DUT board and assigning PS1600 channels:

- [Pogo block compatibility](<02.03.06.03.03_PS1600_pogo_pin_assignment.md#_138223__dle_Pogo_block_compatibility>): The three types of pogo blocks use the same grid. We recommend adding always landing pads for the VHD pogo block so that the higher density pogo blocks can connect to DUT boards that are designed for lower density pogo blocks.
- [Differential pin pairs](<02.03.06.03.03_PS1600_pogo_pin_assignment.md#_138223__dle_Differential_pin_pairs>): For the configuration PS1600 pins as differential pin pairs, these pin pairs must be considered when designing the DUT board.
- [The SmartLoop loopback scheme](<02.03.06.03.03_PS1600_pogo_pin_assignment.md#_138223__dle_The_SmartLoop_loopback_scheme>): Loopback pins must belong to the same test processor.
- [Pin assignment for Fast Sync / Fast Match](<02.03.07.06_Pin_assignment_for_Fast_Sync___Fast_Match.md>): For fast local synchronization, the synchronized DUT pins must be assigned to the same group of channels respectively to the same test processor.
  Pogo block compatibility

For the digital channels A1 鈥?nbsp;A16, the high-density pogo block has the same pogo pin assignment as the standard-density pogo block. These channels are marked yellow in the tables above.

Digital channels B1 鈥?nbsp;B16 are the additional channels of the high-density pogo block. For compatibility with the standard-density pogo block, only "NC" positions of the standard-density block are used for B1 鈥?nbsp;B16. These channels are marked light-red in the HD pin assignment table above and are located in rows a and d of the pogo block with exception of digital channel B16 that is located in row b.

The very-high-density pogo block has the same pogo pin assignment as the STD and HD block for channels A1 鈥?nbsp;A16 and B1 鈥?nbsp;B16. Channels C1 鈥?nbsp;C16 and D1 鈥?nbsp;D16 occupy positions in the extra rows e, f, and g. These extra rows are placed between the other four rows a, b, c, and d and are marked light blue and green in the VHD pin assignment table above.

For the compatibility of the three type of pogo blocks, refer also to [Pogo block compatibility](<02.03.07.07.01_Pogo_block_compatibility.md>).
