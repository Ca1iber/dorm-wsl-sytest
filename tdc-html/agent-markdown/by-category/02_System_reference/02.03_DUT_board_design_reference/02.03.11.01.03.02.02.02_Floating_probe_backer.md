# Floating probe backer

#### Subtopics

- [Adjusting the planarity of the floating probe backer assembly](<02.03.11.01.03.02.02.02.01_Adjusting_the_planarity_of_the_floating_probe_backer_assembly.md>)

The floating prober backer consists of a probe backer which is supported by the probe card PCB.

 Note The drawings in this guide serve as conceptual descriptions only and may differ from the latest original design drawings. For the original drawings see [Direct-Probe probe card layout information](<02.03.12.01.01_Direct-Probe_probe_card_layout_information.md>) and [Direct-Probe stiffener](<02.03.12.01.02_Direct-Probe_stiffener.md>).

## Recommendation

Advantest recommends this design when the component placement in the central area is restricted.

## Design example

 ![Direct-Probe鈩?floating probe backer](<../../../../raw/123433.png>)

The probe backer is only supported by the probe card (printed circuit board = PCB). However, since the top of the probe-backer still contacts the bottom of the bridge beam, the wafer-to-probe contact load is still transferred similarly.

 ![Direct-Probe鈩?floating probe backer cut-away view](<../../../../raw/123434.png>) Note More effort may be required to correctly adjust and planarize the floating probe-backer. Implementation of the type is typically recommended when component placement in the central area is restricted.
