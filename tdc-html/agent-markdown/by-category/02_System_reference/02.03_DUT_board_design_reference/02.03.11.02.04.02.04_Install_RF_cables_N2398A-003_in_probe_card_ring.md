# Install RF cables N2398A-003 in probe card ring

## About this task

This task is about installing the RF cables into the Port Scale RF probe card ring.

## Before you begin

Make sure you have a Torx T20 and a thread-on tool available. See also [12" Wafer Prober Interface Parts List](<02.03.11.02.04.02.08_12__Wafer_prober_interface_parts_list.md>).

## Procedure

-  Mount the RF cable so that the elbow of the SMP female connector at the other end of the cable points out of the ring.   ![Install RF cables N2398A-003 in Probe Card Ring](<../../../../raw/103249.jpg>)
-  Secure the RF cable with the nut using the thread-on tool.   ![RF Cable in Probe Card Ring](<../../../../raw/103250.jpg>)

## What to do next

Mount the probe card ring on the probe card stiffener.
