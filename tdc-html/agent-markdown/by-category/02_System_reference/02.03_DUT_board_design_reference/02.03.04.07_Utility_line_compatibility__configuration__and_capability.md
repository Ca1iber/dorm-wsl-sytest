## Compatible utility lines

Within the V93000 system, the utility lines are routed to four or eight 2-row or 4-row utility blocks and the configuration of the internal utility power supplies depends on the test head type. We recommend assigning the utility lines and the utility power on the DUT board so that the DUT board can be used on all test head types. For more information, refer to [Designing compatible utility lines](<02.03.04.07.01_Designing_compatible_utility_lines.md>).

## Configuration for 4-row or 2-row utility pogo blocks

Some settings in configuration files, 4-row utility blocks and DUT boards that are designed for the 4-row utility blocks are required for utilizing 256 utility lines and the External utility power supply. For more information, refer to [Configuration of 4-row or 2-row utility pogo blocks](<02.03.04.07.02_Configuration_of_4-row_or_2-row_utility_pogo_blocks.md>).

## Capability of utility lines in relation to the system hardware

For V93000 systems, the capability of utility lines depends on the test head type, the DUT interface and the type and version of the installed wiring board. For more information, refer to [Utility line capabilities in relation to the system hardware](<../../03_Use_cases_and_application_papers/03.09_How_to_set_up_sequencer__ontrolled_utility_lines/03.09.01.07_Utility_line_capabilities_in_relation_to_the_system_hardware.md>).
