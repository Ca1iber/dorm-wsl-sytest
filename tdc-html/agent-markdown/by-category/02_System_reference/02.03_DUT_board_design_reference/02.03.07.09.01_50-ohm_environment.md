# 50-ohm environment

Testing at high frequencies requires an impedance-matched environment in order to minimize reflections on the transmission lines. The 50-ohm environment is the most commonly used impedance-matched environment in the V93000. In most cases, you should design your DUT board to match the test system impedance.

An understanding of the DUT requirements is crucial. CMOS DUTs are not inherently impedance matched. However, they are usually characterized for high-speed measurements in a 50-ohm system. Frequent consultation with the test or application expert is often required to determine if a 50-ohm methodology is correct. RF devices are sensitive not only to mismatch, but also to trace resistive loss and cross-talk. RF devices commonly exhibit a 50-ohm or 75-ohm characteristic impedance.
