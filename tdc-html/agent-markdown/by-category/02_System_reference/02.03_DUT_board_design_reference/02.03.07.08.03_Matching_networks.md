# Matching networks

#### Subtopics

- [Two-element tuning with L-networks](<02.03.07.08.03.01_Two-element_tuning_with_L-networks.md>)
- [Advanced matching networks](<02.03.07.08.03.02_Advanced_matching_networks.md>)
- [Basic modeling considerations](<02.03.07.08.03.03_Basic_modeling_considerations.md>)

Matching network is applied to create an optimized transition between the non-50 Ohm DUT pin and the 50 Ohm characteristic impedance ATE test system pin.

Because of an imperfect matching between ATE test system and DUT (including DUT board), some of the incident energy is reflected. Thus, the actual power to (in Rx tests), or from (in Tx tests), the DUT is lower than expected.

## Matching network design tips

Here are some design tips for the impedance matching using the Smith chart:

- In general, load impedance (ZL) has to be the complex conjugate of the source impedance at ZS.
- Adding series or parallel (shunt) components can be visualized very easily and followed in Smith chart .
- Plot the impedance of the DUT pin in the Smith Chart and then start adding components until the impedance of the test system is reached (tester = 50 Ohm).
- Choose the appropriate matching structure:

  - [Two-element topologies](<02.03.07.08.03.01_Two-element_tuning_with_L-networks.md>): L-network types.

Basic design, narrow banded. Each type is limited to tune out input Impedance located at a certain area in the Smith chart.

  - [Three-element topologies](<02.03.07.08.03.02_Advanced_matching_networks.md>): Pi- and T-networks.

The added element offers more flexibility and allows for advanced design through the control of the quality factor (Q).

  - Four-element topologies:

In multi-element topologies added element(s) are usually used for creating wide(r) bandwidth and thus making design less sensitive to spread due to production variation of the DUT, and/or of the tuning components.
