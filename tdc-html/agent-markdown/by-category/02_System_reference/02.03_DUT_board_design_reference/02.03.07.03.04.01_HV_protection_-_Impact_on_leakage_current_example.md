# HV protection - Impact on leakage current example

The clamp diodes of the high-voltage protection circuitry cause a slightly higher DC leakage current.

Test conditions
 | Test instrument:  | PS1600 channel |
 | Test voltages:  | 6.5 V and -1.5 V forced by PPMU |
 | Measurements:  | Current measured with PPMU and BADC |
 | Other conditions:  | Value averaged over 128 measurements, settling time 5.0 ms |

Measurements
 | First measurement:  | Current measurement with open pogo pin |
 | Second measurement:  | Current measurement at the same pogo pin with high-voltage protection circuit connected |

## Result

The difference between the measurement with and without protection circuitry is less than 1 nA.

This result fits to the maximum reverse current value for the used type of diodes.
