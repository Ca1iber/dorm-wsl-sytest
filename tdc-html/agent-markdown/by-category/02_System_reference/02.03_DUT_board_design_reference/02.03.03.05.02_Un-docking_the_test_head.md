## Before you begin

You have docked the test head.

## Procedure

-  To un-dock the DUT interface, simultaneously press ENABLEand DUT UNDOCK.
-  Press HARD UNDOCK to release the grip of the docking cylinders and un-dock the test head.

## Results

You have un-docked the test head.
