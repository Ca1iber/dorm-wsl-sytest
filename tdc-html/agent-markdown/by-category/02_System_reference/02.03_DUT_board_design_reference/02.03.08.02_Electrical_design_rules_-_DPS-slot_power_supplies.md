# Electrical design rules - DPS-slot power supplies

#### Subtopics

- [General Purpose DPS (GP-DPS)](<02.03.08.02.01_General_Purpose_DPS__GP-DPS.md>)
- [High Current DPS (HC-DPS)](<02.03.08.02.02_High_Current_DPS__HC-DPS.md>)
- [High Voltage DPS (HV-DPS)](<02.03.08.02.03_High_Voltage_DPS__HV-DPS.md>)
- [Multisite DPS (MS-DPS)](<02.03.08.02.04_Multisite_DPS__MS-DPS.md>)

The DPS-slot device power supplies contain independently programmable device power supply (DPS) channels. The DPS-slot device power supplies can reside in the DPS-slot (that is the ninth slot beside the DC/DC cards) of any card cage of the V93000 Smart Scale and Pin Scale systems.

 |  [Supported V93000 systems](<02.03_DUT_board_design_reference.md>) : Smart Scale (SmarTest 7), Pin Scale, HSM |

## Supported V93000 system generations and variants

This section holds product-specific electrical design rules for the V93000 system generations and variants mentioned above. For the supported set of test head cards on your system, refer to [Electrical design: Product-specific rules](<02.03.08_Electrical_design__Product-specific_rules.md>).
