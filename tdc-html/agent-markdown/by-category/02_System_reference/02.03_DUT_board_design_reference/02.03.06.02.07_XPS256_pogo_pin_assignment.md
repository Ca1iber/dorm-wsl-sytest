## Pogo pin assignment HD pogo block

 The high-density (HD) pogo block connects 16 channels of an XPS256 card to the DUT board. The HD block is used for the following XPS256 pogo cable assembly:

-

[XPS256 pogo cable assembly EK751HDA: 16 HD pogo blocks, 256 channels](<02.03.06.02.07.01_XPS256_pogo_cable_assembly_EK751HDA__16_HD_pogo_blocks__256_channels.md>)

The HD pogo block can also connect to DUT boards that are designed for the VHD pogo block but can access only the channels on rows a, b, c, and d. For more information, refer to [Pogo block compatibility](<02.03.07.07.01_Pogo_block_compatibility.md>).

## Pogo pin assignment VHD pogo block

 The very-high-density (VHD) pogo block connects 32 channels of an XPS256 card to the DUT board. The VHD block is used for the following XPS256 pogo cable assembly:

 | Pin  |   | Description  | DUT board connection |
 |

PA#, PB#

   | |

High force line of channel #

PA# pins of the VHD pogo block correspond to the P# pins of the HD block.

PB# are the extra pins on rows e, f, and g of the VHD block.

   | |
 |

PS#

PSA#, PSB#

   | |

High sense line of channel #

PSA# pins of the VHD pogo block correspond to the PS# pins of the HD block.

PSB# are the extra pins on rows e, f, and g of the VHD block.  | Connect to the related high force line of the channel close to the DUT or via a separate sense connection of the probe card or DUT socket. |
 | GND  |   | Ground line of all channels  | Connect to DUT board ground. |
 |

GS#

GSA#, GSB#

   | |

Ground sense line of channel #

GSA# pins of the VHD pogo block correspond to the GS# pins of the HD block.

GSB# are the extra pins on new rows e, f, and g of the VHD block.  | Connect to the related GND reference pin or layer close to the DUT or via a separate sense connection of the probe card or DUT socket. |
 | NC  |   | Do not connect pin  | These pins are internally used. Do not connect these pins on the DUT board. |

Notes on the pogo pin descriptions:

- # = Channel 1 鈥?nbsp;16
-

DC/DC power units A and B of pin designations "PA#", "PSA#", "GSA#", "PB#", "PSB#", and "GSB#" refer to the two logical boards that are covered by a VHD pogo block. Since, this information is required only for the pin assignment, these pins are referenced as "P#", "PS#", and "GS#" in all other sections of the TDC.

For more information, refer to section XPS256 in the tester.model file in [XPS256 specific setup tasks](<../02.05_Test_Head_Cards/02.05.05.03.10.01_XPS256_specific_setup_tasks.md>).

- The "NC" pins are internally connected and reserved. To ensure that adjacent high voltage pins or traces have no effect on the "NC" pins, adequate measures like sufficient insulation space have to be respected.
 CAUTION The common ground is wired to several pogo pins. All "GND" pogo pins must be connected in parallel on the DUT board to ensure that the specifications for the card and the maximum ratings for the pogo pins are met.

## Specific design rules

Specific design rules must be followed when designing a new DUT board:

- [Pin assignment for Fast Sync / Fast Match](<02.03.07.06_Pin_assignment_for_Fast_Sync___Fast_Match.md>): For fast local synchronization, the synchronized DUT pins must be assigned to the same group of eight channels respectively to the same test processor[1)](<#_350670__d1727e1349>).
- Memory pooling: XPS256 cards support memory pooling in groups of eight channels respectively within the same test processor[1)](<#_350670__d1727e1349>). This must be taken into account when assigning the channels if, for example, very large amounts of sample data are expected for individual channels.
- [Ganging](<02.03.08.01.07.05_XPS256_ganged_wiring.md>): There are no restrictions for ganging XPS256 channels within a logical board of 16 channels. However, a maximum of 16 ganging groups are supported for ganging across logical boards on the same card. Each high-density (HD) XPS256 pogo block covers one logical board and each very-high-densitiy (VHD) pogo block covers two logical boards that are assigned to the PA# pins and to the PB# pins.
- [HV (High-Voltage) protection](<02.03.08.01.07_DC_Scale_XPS256_card.md#_350677__s_HV_protection>): Since the XPS256 card can possibly be connected to high-voltage cards via defective DUTs or unintentionally closed connections, we recommend that you implement a HV (High-Voltage) protection circuitry on your DUT boards if the voltage exceeds the compliance range of the XPS256 channels.
- [XPS256 recommendations for use](<02.03.08.01.07.03_XPS256_recommendations_for_use.md>) and [XPS256 capacitor requirements](<02.03.08.01.07.02_XPS256_capacitor_requirements.md>): These topics in section [Electrical design: Product-specific rules](<02.03.08_Electrical_design__Product-specific_rules.md>) of the [DUT board design reference](<02.03_DUT_board_design_reference.md>) provide information about wiring of the sense line and additional capacitors on the DUT board.
- [XPS256 VHD pogo pad and via design](<02.03.08.01.07.04_XPS256_VHD_pogo_pad_and_via_design.md>): An optimized pogo via design uses a minimized hole diameter of the via in combination with a controlled depth drill as pogo pin contacting area. The design is more complex than the standard pogo via design for the [VHD block](<02.03.06.02.07_XPS256_pogo_pin_assignment.md#_350670__s_Pogo_pin_assignment_VHD_pogo_block>), but provides more space for routing on the inner layers.
