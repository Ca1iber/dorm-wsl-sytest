# Parse the Argument Line

## Use

long ParseArgumentLine(char *comment_in, int *argc, char ***argv)

Converts the argument line *comment_in to a more handy form.

An example of how it can be used is given below:

 void MyUserProcedure(char *comment_in, ....)

 {

 int argc;

 char **argv;

 int i;

 ParseArgumentLine(comment_in,&argc,&argv);

 for (i=0; i<argc; i++)

 {

 char *this_argument = argv[i]

 DoSomethingWith(this_argument);

 }

 ...

 }
