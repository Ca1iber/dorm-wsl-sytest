# Parameter: test_completed_polarity

This parameter defines whether the test_completed_line is active low ("negative") or active high ("positive").

 Note For most equipment, a negative polarity is used.

Driver default: depends on driver plug-in

Changeable at run-time: yes

Applicable for: handlers

Example: test_completed_polarity: "negative"
