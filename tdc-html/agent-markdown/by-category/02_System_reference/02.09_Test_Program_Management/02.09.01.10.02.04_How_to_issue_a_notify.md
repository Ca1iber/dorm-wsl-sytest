# How to issue a notify

The signature [notify](<02.09.01.10.03.01.08_notify.md>) is used to enable the customer production software to proactively notify its state to SmarTest.

## About this task

The HVM APIs include:

[NotifyCassetteCompletedToSmartest](<02.09.01.10.03.02.02.36_NotifyCassetteCompletedToSmartest.md>), [NotifyCassetteStartedToSmartest](<02.09.01.10.03.02.02.37_NotifyCassetteStartedToSmartest.md>), [NotifyDieCompletedToSmartest](<02.09.01.10.03.02.02.38_NotifyDieCompletedToSmartest.md>), [NotifyDieStartedToSmartest](<02.09.01.10.03.02.02.39_NotifyDieStartedToSmartest.md>), [NotifyLevelCompletedToSmartest](<02.09.01.10.03.02.02.40_NotifyLevelCompletedToSmartest.md>), [NotifyLevelStartedToSmartest](<02.09.01.10.03.02.02.41_NotifyLevelStartedToSmartest.md>), [NotifyLotCompletedToSmartest](<02.09.01.10.03.02.02.42_NotifyLotCompletedToSmartest.md>), [NotifyLotStartedToSmartest](<02.09.01.10.03.02.02.43_NotifyLotStartedToSmartest.md>), [NotifyPackageCompletedToSmartest](<02.09.01.10.03.02.02.44_NotifyPackageCompletedToSmartest.md>), [NotifyPackageStartedToSmartest](<02.09.01.10.03.02.02.45_NotifyPackageStartedToSmartest.md>), [NotifyWaferCompletedToSmartest](<02.09.01.10.03.02.02.46_NotifyWaferCompletedToSmartest.md>), [NotifyWaferStartedToSmartest](<02.09.01.10.03.02.02.47_NotifyWaferStartedToSmartest.md>).

The prototype of [notify](<02.09.01.10.03.01.08_notify.md>) is defined as

```
xoc::hvmapi::Status notify(
const std::string &evName,
const xoc::hvmapi::ParamList &evParams,
const std::string &sessionId );
```

The session ID of SmarTest is required to execute some API. If you Do not know it, you can get the session ID with the API [GetOnlineSmartestSessionID](<02.09.01.10.03.02.01.04_GetOnlineSmartestSessionID.md>) or [ListSmartestSessionIDs](<02.09.01.10.03.02.01.07_ListSmartestSessionIDs.md>).

## Before you begin

Make sure you are using SmarTest 6.2 or later versions.

## Procedure

-  Prepare the parameters and SmarTest session ID for the event.

Each event has different parameters. You can use the code template below to prepare the parameters.

```
ParamList eventParams;
string sessionID;
eventParams["param1"] = "value_for_param1";
eventParams["param2"] = "value_for_param2";
eventParams.setValueArray("param3", "value_array_for_param3");
```

-  Notify the event to SmarTest

```
notify("HVMAPI_event_category", eventParams, sessionID);
```

## Results

The event is notified to the SmarTest session.

## Example

The following example shows how to notify the package start event to SmarTest. In the example, `split()` is a user-defined function to split a string to a vector of string.

```
ParamList eventParams;
string sessionID = "sessionID;
eventParams["EXECUTION_STATE"] = "PACKAGE_STARTED";
eventParams["LOT_ID"] = "lot_123";
eventParams.setValueArray("SITE_ID_FOR_SITES", split("1 2 3 4", " "));
eventParams.setValueArray("SITE_SETUP_FOR_SITES", split("I I I X", " "));
eventParams.setValueArray("PACKAGE_ID_FOR_SITES", split("100 101 102 -1", " "));
eventParams["WCR"] = "8.0 0.1 0.1 1 U 10 10 L U";
notify("EXECUTION", eventParams, sessionID);
```
