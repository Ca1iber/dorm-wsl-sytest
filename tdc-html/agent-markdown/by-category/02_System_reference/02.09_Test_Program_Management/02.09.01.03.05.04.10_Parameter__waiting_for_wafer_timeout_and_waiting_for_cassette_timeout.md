# Parameter: waiting_for_wafer_timeout and waiting_for_cassette_timeout

The time in seconds which the driver will wait for a new wafer or cassette, respectively, to be inserted by the prober. If this time is exceeded (timeout), a message will be generated by the driver, and the action defined by the parameters waiting_for_wafer_timeout_action, or waiting_for_cassette_timeout_action, respectively, will be taken (see above).

Driver default: 120

Changeable at run-time: yes

Applicable for: probers

Example: waiting_for_wafer_timeout: 100
