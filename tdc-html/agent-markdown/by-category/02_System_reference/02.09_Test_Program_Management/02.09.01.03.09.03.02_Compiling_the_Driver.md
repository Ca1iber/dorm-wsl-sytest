# Compiling the Driver

To make the new driver usable, you must compile the extracted sources (see [Unpacking the Driver and Hook Sources](<02.09.01.03.09.03.01_Unpacking_the_Driver_and_Hook_Sources.md>)) as follows:

- Enter the SmarTest run environment by the following command:

/opt/hp93000/soc/system/bin/run -S

- Go to your driver directory GenericHandler or GenericProber and compile the complete driver, for example:

cd /home/user/mydriver/GenericHandler or cd /home/user/mydriver/GenericProber

make clobber

make depend

make

You now have a complete and executable driver available, which you can use like a normal driver and enhance with hook functions according to your requirements. How to do this is explained in [Using the Provided Hook Function Templates](<02.09.01.03.09.04_Using_the_Provided_Hook_Function_Templates.md>).

 If you need to repeat the compilation later, ensure a clean environment by using the clobber target of the makefile.Note Always start the compilation from the GenericHandler or GenericProber directory. Only in this way, all the dependent files can be recompiled and a new driver library can be created.
