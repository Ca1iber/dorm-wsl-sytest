# Writing a Function

#### Subtopics

- [Directing a message to the report window](<02.09.01.08.03.01.01_Directing_a_message_to_the_report_window.md>)
- [Dependencies](<02.09.01.08.03.01.02_Dependencies.md>)
- [Additional Information](<02.09.01.08.03.01.03_Additional_Information.md>)

The function must be declared as follows:

void FunctionName (

 char *parm_list_input,

 int parmcount,

 char *comment_out,

 int *comlen

 int *return_status

 )

where FunctionName is a unique function identifier in the Command Set.

The parameters for the declaration are as follows:

 |

*parm_list_input

 |

is a pointer to a character array of length CI_MAX_PARM_INPUT + 1. This array holds all parameters directed at the function, and contains a list of 0 or more tokens which are separated by a space or a tab.

 |
 |

parmcount

 |

indicates the number of parameters present within the parm_list_input array. The length of each parameter may vary, and could even be 1 parameter occupying the whole parm_list_input array.

 |
 |

*comment_out

 |

is a pointer to a character array of length CI_MAX_COMMENT_LEN + 1. Any comment that is to be assigned to the application model variable must be written to this array and is passed on automatically, depending on the value of the comlen parameter; this does not apply, however, to user procedures.

 |
 |

*comlen

 |

is a pointer to an int, and must be set to the length of the comment written to array *comment_out.

 |
 |

*return_status

 |

is a pointer to an int, and must be set to indicate the success or failure of function execution. See [Return Codes](<02.09.01.08.05.05_Return_Codes.md>) for an explanation of the valid codes available.

   |
