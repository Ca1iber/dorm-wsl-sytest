# ASM handlers

#### Subtopics

- [LAN communication flow for ASM handlers](<02.09.01.03.06.01.07.01_LAN_communication_flow_for_ASM_handlers.md>)

ASM handlers are supported with LAN interface.

The ASM handler communicates with the driver through a LAN interface.

LAN driver configurations are provided for ASM handlers. You can find the configuration file here:

 /opt/hp93000/soc/PH_libs/GenericHandler/ASM/.

The following configuration file is provided:

ASM-LAN-4-SITE.cfg

## Functional changes

- Introduced in SmarTest 7.5.3
