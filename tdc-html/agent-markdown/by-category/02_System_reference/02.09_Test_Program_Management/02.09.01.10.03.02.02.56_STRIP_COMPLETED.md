# STRIP_COMPLETED

This asynchronous event indicates that the execution of a strip level is completed in the test program execution.

## Dependency and constraints

- The test program is in execution.
- If the [Application Model](<02.09.01.02_Application_Model.md>) does not contain a custom strip level or does not use the standard prober/handler driver function call (`ph_strip_done`) or the equivalent, this event may not be generated. To get the value of a strip ID, the variable for the strip ID should be `ph_STRIP_ID` or `STRIP_ID`.
