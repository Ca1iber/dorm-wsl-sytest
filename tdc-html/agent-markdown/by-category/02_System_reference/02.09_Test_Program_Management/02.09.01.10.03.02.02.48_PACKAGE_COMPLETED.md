# PACKAGE_COMPLETED

This asynchronous event indicates the test for a packaged device is completed in the test program execution. It is only available for final test.

## Dependency and constraints

- The test program is in execution.
- If the application model does not use the standard prober/handler driver function call (`ph_device_done`) or the equivalent, this event may not be generated. The variable naming for lot ID should be `ph_LOT_ID` or `LOT_ID`.
