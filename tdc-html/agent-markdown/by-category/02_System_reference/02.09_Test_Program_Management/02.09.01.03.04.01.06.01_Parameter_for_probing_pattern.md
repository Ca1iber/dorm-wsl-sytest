# Parameter for probing pattern

This parameter determines the die pattern for multi-site setups:

 multi_site_die_offsets

In addition, you must check the parameters for site management. See [Parameters for site management](<02.09.01.03.04.01.01.04_Parameters_for_site_management.md>)).
