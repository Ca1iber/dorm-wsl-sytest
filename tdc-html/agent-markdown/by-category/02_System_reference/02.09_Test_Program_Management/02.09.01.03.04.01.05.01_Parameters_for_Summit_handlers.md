# Parameters for Summit handlers

These parameters are valid only for Delta Design Summit handlers:

- summit_recipe_file

This is the name of the recipe file for storing temperature parameters. The file is stored in the Summit controller.

- summit_workarounds

This parameter determines how the driver deals with some features that are not supported in the Summit software revisions 1.7.3 and 1.7.4. If you have a newer revision of the software, please contact your Advantest representative to see if you can deactivate one of the workarounds.
