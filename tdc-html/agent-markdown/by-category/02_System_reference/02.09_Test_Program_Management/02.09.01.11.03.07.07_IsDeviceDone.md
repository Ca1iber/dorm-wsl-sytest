# IsDeviceDone()

This API checks if all the packages or dies are finished.

SUCCESS is returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- The local session does not exist.
 |

RECOVERABLE

 |

Parameter

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The ID of the session to work with.

 |
 |

O

 |

IS_DEVICE_DONE

 |

If all the packages or dies are finished, the value is `TRUE`. Otherwise it is `FALSE`.

 |

Prototype

```
ParamList outputResults;
Status query("IsDeviceDone", outputResults, ParamList(), sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID;
ParamList outputResults;

Status retVal = query("IsDeviceDone", outputResults, ParamList(), sid);
if ( retVal.isSuccess() )
{
cout<< "The DEVICE status = " << outputResults["IS_DEVICE_DONE"] << endl;
}
```
