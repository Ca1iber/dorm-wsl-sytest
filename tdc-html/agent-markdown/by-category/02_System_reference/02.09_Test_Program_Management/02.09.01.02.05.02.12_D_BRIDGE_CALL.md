# D_BRIDGE_CALL

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.12.01_Associated_Syntax_Entities.md>)

Used to run a program that transfers data to a database or statistical analysis package.

For example, the following lines runs the "`send_to_dbase`" function with the parameter /tmp/{Lot_id}.{wafer_id}.stdf.

```
ACTIONS
  D_BRIDGE_CALL (send_to_dbase /tmp/{Lot_id}.{wafer_id}.stdf);
```

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.0: GDF logging in application model is obsolete.
