The STPM UI plug-in for SmarTest provides access to a range of STPM functions from within the SmarTest graphical user interface.

The plug-in provides new submenus in the Edit menu and the shortcut menu of the Test Flow Editor from which you can access the supported functions. Dialogs are displayed in which you can set the desired execution options.

For extracting and merging subflows, there are also "quick" versions of the commands that do not display dialogs but instead execute the functions with the default settings.

The plug-in supports:

- Removing unused or duplicated primaries from the test program
- Extracting test groups as a subflow to a source test program (STP)
- Merging a subflow with the testflow of the master test program (MTP)
