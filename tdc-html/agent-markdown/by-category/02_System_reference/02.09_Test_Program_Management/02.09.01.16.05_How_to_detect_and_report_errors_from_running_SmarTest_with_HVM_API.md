# How to detect and report errors from running SmarTest with HVM API

## About this task

The following categories of errors and warnings can detected and reported with the alarm notification of HVM API (Refer to [ALARM_NOTIFICATION](<02.09.01.10.03.02.02.09_ALARM_NOTIFICATION.md>) for details):

- firmware execution warnings and errors
- SmarTest initialization warnings and errors
- test program execution warnings and errors
- Advantest generic prober/handler driver errors and warnings

Currently only calibration data errors and licensing errors can be identified from the alarm code. The other categories of errors can be handled generally.

The procedure below applies for the handling of all categories of alarm notification with HVM API.

## Before you begin

Make sure you are using SmarTest 6.2 or later versions. Not all the categories are supported from 6.2. Refer to the Functional Changes below.

## Procedure

- Define the event handler function to handle the event type ALARM.
- In the main() function, register the event handler with [addEventListener](<02.09.01.10.03.01.03_addEventListener.md>).
- In the main() function, start the event loop to execute the event handler with [eventLoop](<02.09.01.10.03.01.06_eventLoop.md>).

## Results

The event handler for alarm notification is created and registered. It will be executed when the ALARM occurs.

## Examples

### Handling the general errors with alarm notification

```
using namespace std;
using namespace ::xoc::hvmapi;
void alarmHandler(const string &evName, const ParamList &evParams,
                  unsigned long sec, long usec, const string &sessionId)
{
  if ( evName == "ALARM" )
  {
    string severity = params["ALARM_SEVERITY"];
    string code = params["ALARM_CODE"];
    string text = params["ALARM_TEXT"];
    cout << "PM: Event received ### Session: " << session << " # EventType: " << type
         << "# Severity:" << severity << "# Code:" << code << "# Text:" << text << endl;
  }
}
```

### Handling the license error during SmarTest startup

```
using namespace std;
using namespace ::xoc::hvmapi;
void alarmHandler(const string &evName, const ParamList &evParams,
                  unsigned long sec, long usec, const string &sessionId)
{
  if ( evName == "ALARM" )
  {
    string severity = params["ALARM_SEVERITY"];
    string code = params["ALARM_CODE"];
    string text = params["ALARM_TEXT"];
    if(code=="LICENSING_ERROR")
    {
      cout << "license error occurred"<<endl;

}
```

### Handling the error when calibration data expires

```

using namespace ::xoc::hvmapi;

                  unsigned long sec, long usec, const string &sessionId)
{

    string code = params["ALARM_CODE"];

    {
      cout << "The calibration data expires. Please do the calibrate!"<<endl;

           << "# Severity:" << severity << "# Code:" << code << "# Text:" << text << endl;

    }
  }
}
```

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.0: CAL_DATA_INVALID and LICENSING_ERROR are supported.
- SmarTest 6.5.2: SmarTest initialization warnings and errors, Test program execution warnings and errors and Verigy Generic Prober/Handler driver errors and warnings are supported.
