## Variable widgets

The widget LineEntry specifies the variables to be accessed and displayed by TCCT. It is used in the format

<widget:LineEntry name="xxxx" displayName="xxxxxx"/>, in which name specifies the variable name and displayName specifies the name to be displayed on the GUI.

 |

<widget:LineEntry name="equipment" displayName="Equipment:" />
