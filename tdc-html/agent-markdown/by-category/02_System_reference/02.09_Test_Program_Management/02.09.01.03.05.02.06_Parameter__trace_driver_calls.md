# Parameter: trace_driver_calls

If set to "yes", the driver will add internal function calls together with the passed parameters to the warnings/error output. This should be used for debugging only.

Driver default: "no"

Changeable at run-time: yes

Applicable for: handlers and probers

Example: trace_driver_calls: "no"
