# Conventions for GPIB/LAN communication

The conventions in the table below are used in this chapter to describe GPIB/LAN communication:

 Note The SRQ related conventions are not available for the LAN communication.

Conventions for describing GPIB/LAN communication
 |

Symbol

 |

Definition

 |
 |

a_word:

 |

Defines an action name.

 |
 |

<a_word>

 |

Placeholder for a sub-action as defined later.

 |
 |

0x..

 |

Answer SRQ code from the handler, sent as hex value.

 |
 |

[0x..]

 |

An optional (ignored) answer SRQ code from the handler.

 |
 |

 |

 |

OR sign (for alternatives).

 |
 |

string

 |

A command or answer string.

 |
 |

.

 |

An arbitrary character.

 |
 |

Italic letters

 |

A placeholder for variables, such as binning, positions an so on.

s = site, b = binning data

 |
 |

(...)

 |

A sub-expression.

 |
 |

+

 |

The previous expression may be generated several times, but is generated at least once (1-n).

 |
 |

*

 |

The previous expression may be generated several times, or it may not occur (0-n).

 |
