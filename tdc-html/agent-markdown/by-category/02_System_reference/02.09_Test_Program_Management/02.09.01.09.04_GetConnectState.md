# GetConnectState

This routine lets you determine the connect state of the device as shown in the report window.

 Note Note that the connect state might not reflect the actual hardware setting, if firmware commands have been sent to change the state.

## Syntax

```
VOID GetConnectState(
    INT32    *is_connected);
```

## Parameters

The output parameter is_connected is set to

- FALSE if the device is actually disconnected
- TRUE if the device is actually connected

## Example

```
INT32 isConnected;
GetNumberOfSites(&isConnected);
```

## Functional changes

- Introduced before SmarTest 6.3.2
