# Available Hook Functions

There are five different points in driver execution where five different hook functions can be called by the driver:

- with every PROB_HND_CALL from the application model, before the driver has performed any action
- with every PROB_HND_CALL from the application model, after the driver has performed all necessary actions for this call
- when error conditions occur during driver/equipment operation (in the current driver Revision 3.2, only timeouts while waiting cause a call of the hook function for error conditions)
- repeatedly while waiting
- any time before a dialog window is displayed by the driver

Corresponding to the calling points in the driver execution. The five hook functions to be called are named:

- phHookActionStart
- phHookActionDone
- phHookProblem
- phHookWaiting
- phHookPopup

For each of the five hook functions, a ready-to-use template is provided. This helps facilitate the implementation of user-specific hook function functionality. These templates already contain simple functionality as an implementation example. To give a hook function user-specific functionality, the example implementation must be replaced with user-specific code.

See [Description of the Hook Function Templates](<02.09.01.03.09.04.02_Description_of_the_Hook_Function_Templates.md>) for details.
