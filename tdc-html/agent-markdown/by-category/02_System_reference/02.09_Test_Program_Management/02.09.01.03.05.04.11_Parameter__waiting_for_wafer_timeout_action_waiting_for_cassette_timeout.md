# Parameter: waiting_for_wafer_timeout_action waiting_for_cassette_timeout_action

These parameters work exactly like waiting_for_parts_timeout_action, but for timeouts while the driver waits for the next wafer, or cassette, respectively, to be delivered by the prober.

Driver default: "continue"

Changeable at run-time: yes

Applicable for: probers

Example: waiting_for_wafer_timeout_action: "operator-help"
