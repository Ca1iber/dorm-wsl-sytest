# Function: ph_die_done

This function gets the binning and pass/fail information from SmarTest, applies a binning map on this data (optional), and tells the prober how to bin the tested die. The function will also send an inking command to the prober, if this is supported by the plug-in, and if the parameter ink_bad_dies is set to "yes."

ph_die_done is mandatory for wafer testing.

Applicable for: prober driver

Example: PROB_HND_CALL (ph_die_done)
