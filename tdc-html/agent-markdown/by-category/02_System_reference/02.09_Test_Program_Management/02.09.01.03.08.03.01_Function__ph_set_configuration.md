# Function: ph_set_configuration

Changes the settings of configuration parameters. Both the parameters and the new settings are provided as arguments.

For details about this function see [Changing the Driver Configuration at Run-Time](<02.09.01.03.03.04_Changing_the_Driver_Configuration_at_Run-Time.md>).

Applicable for: handler and prober driver

Example: PROB_HND_CALL (ph_set_configuration debug_level:3 trace_driver_calls:"yes")
