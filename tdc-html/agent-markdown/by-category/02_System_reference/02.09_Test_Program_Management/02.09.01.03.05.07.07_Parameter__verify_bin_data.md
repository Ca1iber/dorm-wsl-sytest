# Parameter: verify_bin_data

Some equipment allows to verify the binning data which has been transferred between the driver and the equipment before releasing the tested devices from the test system and binning them correctly.

Doing this, communication problems between the equipment and the driver as for example noise on the GPIB can be detected. If the equipment supports bin data verification and in case this parameter is set to "yes", all bin data is verified after having been sent to the equipment. Be aware that this verification may increase the device handling time compared to the case where this parameter is set to "no" since it requires further steps of communication. If the parameter is not defined, the mode as set up directly at the equipment will be used.

Driver default: "no"

Changeable at run-time: yes

Applicable for: handlers and probers, plug-in dependent

Example: verify_bin_data: "yes"
