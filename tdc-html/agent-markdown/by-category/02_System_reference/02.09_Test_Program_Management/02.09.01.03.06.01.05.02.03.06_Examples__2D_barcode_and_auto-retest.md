# Examples: 2D barcode and auto-retest

The following two examples explain how to get 2D barcodes and do auto-retest on GS! handlers.

## Examples

### Example 1: 2D barcode

This example explains how to get 2D barcodes.

- Use `PROB_HND_CALL` `(ph_get_status DEVICEID)` in your application model file to get 2D barcodes for all sites.
- Use `PROB_HND_CALL` `(ph_get_status DEVICEID n)` in your application model file to get a 2D barcode for a specific site. `n` is the index of a specific site.

For example, there are 16 sites. In your application model file, you set:

```
* DEVICEID = PROB_HND_CALL (ph_get_status DEVICEID);
* DEVICEID_1 = PROB_HND_CALL (ph_get_status DEVICEID 1);
```

The first command line does not specify any DEVICEID, so the handler returns all 2D barcodes in strings and DATANG at the same time for all 16 sites.

 |

```
1,1234567800000000;2,2345678900000000;3,1345678900000000;4,1245678900000000;
5,DATANG;6,DATANG;7,DATANG;8,DATANG;9,1234567800000000;10,2345678900000000;
11,1345678900000000;12,1245678900000000;13,DATANG;14,DATANG;15,DATANG;16,DATANG;
```

 |

DATANG means that the handler cannot read the barcode.

The second command line specifies `DEVICEID` as 1. The handler returns the 2D barcode in a string for site 1 as `1234567800000000`.

### Example 2: Auto-retest

This example demonstrates how to use the auto-retest feature in your application model file.

```
START_DIALOG

{ superlot:

    ACTIONS
    PROB_HND_CALL (ph_driver_start);

    { lot:

        SCREEN_DIALOG
          Lot_id = DIALOG_INPUT / REGEXP(string);
          Operator_id = DIALOG_INPUT / REGEXP(string);

        ACTIONS
          Iteration = AUTOINCREMENT;
          PROB_HND_CALL (ph_lot_start);
          RTST_COD = CONST_INPUT ({Iteration});
          STDF_FILE = CONST_INPUT (/tmp/Iteration_{Iteration}.stdf);

          { DEVICE [(package test),({package_id})] device:
              ACTIONS
                package_id = AUTOINCREMENT;
                SET_PACKAGE_ID({package_id});
                PROB_HND_CALL (ph_device_start);
                {
                  DEVICE_TEST
                }
                REPROBE_ACTION = PROB_HND_CALL(ph_reprobe);
              ACTIONS
              PROB_HND_CALL (ph_device_done);
          }
          ACTIONS
            PROB_HND_CALL (ph_lot_done);
     }
     ACTIONS
       PROB_HND_CALL (ph_driver_done);
}
```
