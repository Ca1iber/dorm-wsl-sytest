# GPIB communication flow for SRM handlers

This section describes the GPIB communication between the driver and the handler. The actions and messages are listed in sequential order in the table below.

See [Conventions for GPIB communication](<02.09.01.03.06.01.04_Conventions_for_GPIB_LAN_communication.md>) for syntax description. Please note the GPIB messages sent from the SRM driver plug-in to the handler end with '`\r`' instead of '`\r\n`'.

SRQ code Description

0x41 SOT for site A

0x42 SOT for site B

0x44 SOT for site C

0x48 SOT for site D

0x4F Parallel SOT for site A, B, C, and D

0x43 Parallel SOT for site A and B

0x4C Parallel SOT for site C and D
