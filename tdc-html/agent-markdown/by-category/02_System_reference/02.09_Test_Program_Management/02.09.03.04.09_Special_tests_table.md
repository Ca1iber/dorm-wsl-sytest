# Special tests table

The special tests table of the MTPT (STPM MCM mapping tables) describes which STPs (source test programs) will be used as the sources for the different kinds of [Special test suites](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.02_Special_test_suites.md>) in the MTP (master test program).

The table is stored in a file named specialtests.csv in the MTPT directory. It is created by the [generate_template](<02.09.03.03.02_generate_template.md>) command.

The file is best edited by importing it into the [OpenOffice spreadsheet](<02.09.03.04.15_OpenOffice_spreadsheet_for_editing_the_CSV_files.md>) located in the [MTPT](<02.09.03.04_MTPT__STPM_MCM_mapping_tables.md>) folder. Editing is also possible in text editors, but this requires you to make sure yourself that all formatting is correct.

## Syntax

Each row in the special tests table describes the handling of one type of special test suite. The table contains these columns:

- Type: The kind of [special test suite](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.01.02_Special_test_suites.md>) that the column describes
- Master STP: The name of the STP from which this kind of test suite is imported.

For example, when the entry for "download" in this column is "MyTP4", every time the download special test suite is needed in the MTP, the version from the MyTP4 STP is used.

An entry of __NONE__ in this column indicates that none of the specified STPs contain a special test of this type.

- Notes: This column allows both you and STPM MCM to add remarks. These notes are just for human consumption and are never processed automatically by STPM MCM. They may be overwritten when the tables are updated, so they are not a suitable place for storing important information.
