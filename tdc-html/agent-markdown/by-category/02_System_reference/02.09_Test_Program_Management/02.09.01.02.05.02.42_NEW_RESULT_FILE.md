# NEW_RESULT_FILE

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.42.01_Associated_Syntax_Entities.md>)

Specifies the file where all the results for the particular level are sent. Unless a different result file exists for a lower level, the results for the level on which the NEW_RESULT_FILE statement appears, and all lower levels are sent to the designated file. If, however, another NEW_RESULT_FILE statement appears in a lower level, the results for that level, and all lower levels are sent to it instead.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.0: GDF logging in application model is obsolete.
