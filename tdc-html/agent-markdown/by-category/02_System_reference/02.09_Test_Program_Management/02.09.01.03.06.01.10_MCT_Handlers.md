# MCT Handlers

#### Subtopics

- [GPIB driver configuration](<02.09.01.03.06.01.10.01_GPIB_driver_configuration.md>)

The MCT handlers are supported with GPIB interface.

## Strip testing

To enable the MCT handler to handle strip tests, you must add a strip level in the application model file.

The strip level will allow STDF data log files to be generated, which contain the wafer sort information such as wafer ID and both x and y coordinates. If you need to show the test results in the wafer map view, specify a wafer description file in the test program as well as add `SET_DIE_X_Y()` into the model file for being called in testing.

The following example demonstrates a piece of the strip level to be added into the application model file.

```
START_DIALOG

{
   Test_program:

ACTIONS
PROB_HND_CALL(ph_driver_start);
SET_DIE_X_Y(0,0);

{
  STRIP strip:

    SCREEN_DIALOG
           * Lot_id        = DIALOG_INPUT     / REGEXP(string);
           * Operator_id   = DIALOG_INPUT     / REGEXP(string);

        ACTIONS
           PROB_HND_CALL(ph_strip_start);
           WAFER_ID = PROB_HND_CALL(ph_get_id strip);

        {
          DEVICE device:
            ACTIONS
                package_id = AUTOINCREMENT;
                SET_PACKAGE_ID({package_id});
                PROB_HND_CALL(ph_device_start);
                {
                    DEVICE_TEST
                }
                REPROBE_ACTION = PROB_HND_CALL(ph_reprobe);
            ACTIONS
                PROB_HND_CALL(ph_device_done);
        }
        ACTIONS
        PROB_HND_CALL(ph_strip_done);
}
    ACTIONS
        PROB_HND_CALL(ph_driver_done);
}
```
