These functions allow you to set the driver to special modes of operation which differ from the normal mode.

The functions are closely related to the corresponding configuration parameters hand_test_mode and single_step_mode described in [Configuration Parameters for Driver Mode](<02.09.01.03.05.03_Configuration_Parameters_for_Driver_Mode.md>).
