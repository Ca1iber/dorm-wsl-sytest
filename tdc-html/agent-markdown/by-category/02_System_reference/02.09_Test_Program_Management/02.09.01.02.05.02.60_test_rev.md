# test_rev

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.60.01_Associated_Syntax_Entities.md>)

The test_rev keyword is used as an argument for [GET_TEST_INFO](<02.09.01.02.05.02.36_GET_TEST_INFO.md>) to return the revision information of the current test as entered in the Test Revision field of the Information screen of the testflow editor.

## Functional changes

- Introduced before SmarTest 6.3.2
