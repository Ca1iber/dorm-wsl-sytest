# Test Suite Control API

#### Subtopics

- [How to use the test suite control API](<02.09.01.14.01_How_to_use_the_test_suite_control_API.md>)
- [Test suite control API reference](<02.09.01.14.02_Test_suite_control_API_reference.md>)

Test suite control API is used to directly control the test suites outside of the testflow tool. Only UTM-based test suites are supported with these APIs. This is a set of independent APIs. They cannot be used in test method programming and also cannot be used in parallel with HVM API and BLC API by the same client process.

 Note The actions in the testflow tool like creating a test suite, deleting a test suite, changing the test suite setup and changing testflow, will impact the behavior of the running test suite control API. And the behaviors of the running test suite control API like creating a test suite, deleting a test suite and changing the test suite setup, will be reflected in the testflow tool. Running test suite control API interactively with testflow UI tool is NOT recommended.
