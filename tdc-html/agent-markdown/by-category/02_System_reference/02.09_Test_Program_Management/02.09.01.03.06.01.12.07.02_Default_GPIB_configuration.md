# Default GPIB configuration

This section describes the variables used in the configuration files.

When the configuration files were created, certain aspects necessarily had to be defined. The table below lists these aspects and how they were defined.

Important aspects of the Multitest configuration files
 |

Aspect

 |

Used setting

 |
 |

Debug level

 |

0, will log only basic messages, can be changed to a value between -1 and 4.

 |
 |

GPIB port used

 |

12, must be changed to correct value based on the handler's setup.

 |
 |

Auto pausing of handler

 |

Activated. Handler is stopped on SmarTest pause.

 |
 |

Resume after pause

 |

Automatic, if stopped automatically.

 |
 |

Bin mapping

 |

default

 |
 |

Number of bins

 |

32 (SmarTest hardbins 0 through 31), bin 0 represents the SmarTest reset bin.

 |
 |

Reprobe mode

 |

Automatic reprobe on a per site mode, if devices fall into SmarTest reprobe bins.

 |
 |

Reprobe bin number

 |

31, represents number sent to handler upon receiving a SmarTest reprobe bin. Must be changed to correct value according to set up of handler. Note that the reprobe mechanism refers to the disconnection and reconnection of the device before a retest is performed.

To disable this setting remove the "handler_reprobe_bin" parameter and set the "automatic_reprobe_mode" to "off"

 |
 |

Temperature parameters

 |

(MT93xx only) Temperature control may be activated by changing the parameter temp_control to "active" and setting the temp_setpoint.

 |
 |

Test start detection

 |

Done by interrupt (SRQ), can be changed to pure polling mode with given polling interval for troubleshooting.

 |
 |

End-of-line terminator

 |

Driver sends CR+LF and EOI on the GPIB bus, cannot be changed through configuration file. Driver expects no special end of line code from handler except EOI.

 |
 |

Polling interval

 |

Preset to 100 ms, only used if waiting for parts is done by polling.

   |
