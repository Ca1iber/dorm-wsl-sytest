This section provides the details of programming with BLC API, how to create a BLC executable file and some example codes using BLC API.

With the BLC APIs, you can

- Load and execute the testflow synchronously
- Load and execute the prober/handler driver, execution input library and data bridge library
- Add variables to the shared memory and access the variables in the shared memory
- Maintain the level structure as in application model
- Issue the EDL event and HVM execution event
- Update the test result to the display

These APIs are executed through the signature [syncCommand](<02.09.01.10.03.01.11_syncCommand.md>), [syncOperation](<02.09.01.10.03.01.12_syncOperation.md>) and [query](<02.09.01.10.03.01.10_query.md>).

To use the BLC API, you need to include the header file as below:

```
#include "xoc/hvmapi/hvmapi.hpp"
```

## Event data logging

To implement the event data logging as in an application model, you need to maintain the level structure with the level control API [StartLevel()](<02.09.01.11.03.02.01_StartLevel.md>), [LoopLevel()](<02.09.01.11.03.02.02_LoopLevel.md>) and [CompleteLevel()](<02.09.01.11.03.02.03_CompleteLevel.md>). The data will be logged if the event data logging is enabled. (For detailed explanation of event data logging, see [Event Data Logging Concepts](<../02.10_Data_Logging/02.10.01.01_Event_Data_Logging_Concepts.md>).)

You can also log the EDL event manually with the API [IssueEDLEvent()](<02.09.01.10.03.02.02.29_IssueEDLEvent.md>). The events you specified with the API will be logged if the event data logging is enabled. (For details of EDL event types, see [Event types](<../02.10_Data_Logging/02.10.01.06.03_Event_types.md>).)

## Using the prober/handler driver functions

To call the prober/handler driver functions, you can use the API [CallPHDriverFunc()](<02.09.01.11.03.05.02_CallPHDriverFunc.md>).

You can also linked the prober/handler driver libraries to the BLC executable file and then directly call the functions in the BLC program. To use the prober/handler functions in this way, you need to include the following header files in the BLC program and link the following libraries when compiling the BLC program.

Header files:

- /opt/hp93000/soc/PH_libs/GenericProber/include/prober_driver.h (for Prober Driver)
- /opt/hp93000/soc/PH_libs/GenericHandler/include/handler_driver.h (for Handler Driver)

Shared libraries:

-

For RHL7:

- /opt/hp93000/soc/PH_libs/GenericProber/libcifset-EL7.so (for Prober Driver)
- /opt/hp93000/soc/PH_libs/GenericHandler/libcifset-EL7.so (for Handler Driver)
