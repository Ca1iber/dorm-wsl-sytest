# GetOnlineSmartestSessionID

This data query command gets the session ID of an online SmarTest session. Only one online session is allowable to one test system.

Success will be returned if the command is successfully issued. Otherwise, an error object indicating the error code, description and severity will be returned.

 |

Code

 |

Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

There is no online session.

 |

RECOVERABLE

 |

## Dependency

An online session is running.

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

SESSION_ID

 |

The ID of the online SmarTest session.

 |

Prototype

`ParamList qrResults;`

`query("GetOnlineSmartestSessionID", qrResults);`

## Example

```
ParamList qrResults;
query("GetOnlineSmartestSessionID", qrResults);
printf("the session ID for online session id: s%\n",
        qrResults["SESSION_ID"]);
```
