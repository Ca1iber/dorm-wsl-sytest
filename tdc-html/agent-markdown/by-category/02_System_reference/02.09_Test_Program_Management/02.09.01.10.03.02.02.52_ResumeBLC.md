# ResumeBLC

This remote control command resumes the execution of a BLC which is currently on pause. The BLC must be designed to be able to react to the `RESUME` operation. Otherwise, this API will take no effect.

SUCCESS will returned if no error occurred. Otherwise, an error object will returned indicating the error code, description and severity.

 |

Code

 |

Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- There is no BLC being executed.
- There is no BLC being paused.
 |

RECOVERABLE

 |

## Dependency

The BLC is paused.
