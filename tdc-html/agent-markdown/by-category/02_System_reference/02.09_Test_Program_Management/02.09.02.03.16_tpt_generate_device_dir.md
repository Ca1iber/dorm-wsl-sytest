# tpt_generate_device_dir

The tpt_generate_device_dir command for the SmarTest Program Manager (STPM) [control file](<02.09.02.03_STPM_control_file.md>) lets you create a new device directory from a test program template.

When executing the command, STPM creates the directory structure for the device and fills it with a testflow and related files, as specified in the template.

If any static directories were imported with the copy_static_content parameter of the [tpt_import_from_device](<02.09.02.03.15_tpt_import_from_device.md>) command, tpt_generate_device_dir copies these directories into the newly generated device directory.

## Syntax

```
tpt_generate_device_dir(
tpt_dir = <tpt_directory>,
    device_dir = <directory>,
[device_name = <device_name>, ]
[pre_proc = <pre_proc>, ]
post_proc = <post_proc>]
)
```

## Parameters

The parameters in the order in which they are listed above:

 |

tpt_dir

 |

<tpt_directory> (string) is the name and path of the directory containing the TPT files from which the device directory is to be generated.

The path can be either absolute or relative to the current working directory.

 |
 |

device_dir

 |

<directory> (string) is the path, including the name, where the new device directory is created. The directory must either not exist yet (in which case STPM creates it) or it must be empty.

The path can be either absolute or relative to the current working directory.

 |
 |

device_name

 |

<device_name> (string) is the name for the newly created device.

This parameter is optional. If it is omitted, "device" is used.

 |
 |

pre_proc

 |

<pre_proc> is a script that is executed before this command.

The syntax of the parameter value is described in [Preprocessing and postprocessing scripts](<02.09.02.03.03_Preprocessing_and_postprocessing_scripts.md>).

This is an optional parameter.

 |
 |

post_proc

 |

<post_proc> is a script that is executed after this command.

The syntax of the parameter value is described in [Preprocessing and postprocessing scripts](<02.09.02.03.03_Preprocessing_and_postprocessing_scripts.md>).

This is an optional parameter.

 |

## Example

This example creates a device directory for the device "my_device" from the TPT master file "my_tpt.tpt" (located in the current working directory). The device directory is located at the same level as the current working directory.

```
tpt_generate_device_dir(
    tpt_dir     = 'my_tpt/'
    device_dir  = '../my_device/'
    device_name = 'my_device',
    )
```

## Functional changes

- Introduced in SmarTest 7.0.4
- SmarTest 7.2.1: Swapped the order of the device_dir and device_name parameters.
- SmarTest 7.2.1: Changed the default of the device_name parameter.
- SmarTest 7.2.1: Replaced the tpt_path parameter with tpt_dir.
- SmarTest 7.2.1: Renamed command to tpt_generate_device_dir.
- SmarTest 7.2.2: Added the pre_proc and post_proc parameters.
