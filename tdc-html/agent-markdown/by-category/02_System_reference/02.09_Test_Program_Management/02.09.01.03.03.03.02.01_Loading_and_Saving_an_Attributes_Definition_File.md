# Loading and Saving an Attributes Definition File

You can load an attributes definition file for editing, and save the edited file with your preferred text editor.

The default attributes definition file (shattrib - specific handler attributes definition, or spattrib - specific prober attributes definition) provided with a plug-in is located in the config sub-directory of the respective plug-in:

Examples:

/opt/hp93000/soc/PH_libs/GenericHandler/Synax-GPIO/config/shattrib

/opt/hp93000/soc/PH_libs/GenericProber/TEL/config/spattrib

This attribute definition file will be used by the driver, and by the driver configuration editor, to check whether all configuration parameter settings are in the valid range.

If you modify an attributes definition file and want the modified file to be used instead of the default file, you must store the modified file in the same directory as the driver configuration file that is going to use the modified attributes definition. If the driver finds an attributes definition file in the same directory as the driver configuration file, it will ignore the default attributes definition file.

## Example

You want to change the attributes definition of the TEL plug-in of the prober driver, and then modify the existing driver configuration file

/user/tom/my_TEL_configurations/P8-GPIB-Prober-1-Die-mod1.cfg to use the changed definition.

- Load the attributes definition file

/opt/hp93000/soc/PH_libs/GenericProber/TEL/config/spattrib

with an ASCII editor and make the desired changes (see [Changing an Attribute Definition](<02.09.01.03.03.03.02.02_Changing_an_Attribute_Definition.md>))

- Save the changed file to the directory

/user/tom/my_TEL_configurations/

The attributes definition file must be named spattrib (or shattrib, respectively) to be recognized by the driver. Be careful to not unintentionally overwrite another spattrib file already existing in the selected directory. Rename that file, or copy it to another location, if you want to keep it.

- Edit the driver configuration file /user/tom/my_TEL_configurations/P8-GPIB-Prober-1-Die-mod1.cfg as described in [Editing a Driver Configuration File](<02.09.01.03.03.03.01_Editing_a_Driver_Configuration_File.md>), and save it.
