# ALARM_NOTIFICATION

This notification is provided whenever an error occurred in the system.

## Dependency

The HVM alarms cover the following warnings and errors:

- firmware execution warnings and errors
- SmarTest initialization warnings and errors, like device changing error, TF process start failure error, `Xset fp+ /opt/hp93000/soc/prod_pws/fonts` error and MCD or calibration data error.
- Test program execution warnings and errors, like application model parse errors, test flow parse errors, errors occurring during application model execution, errors occurring during testflow execution, test program load errors (Prober/Handler driver library load errors, execute input library load errors etc.) and test method execution errors.
- Advantest Generic Prober/Handler driver errors and warnings, like GPIB communication error, binning error, incorrect site population information, driver configure file error.Note Except for firmware execution warnings and errors, the other warnings and errors generated before the event notification infrastructure started cannot be captured.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.0: CAL_DATA_INVALID and LICENSING_ERROR are supported.
- SmarTest 6.5.2: SmarTest initialization warnings and errors, Test program execution warnings and errors and Advantest Generic Prober/Handler driver errors and warnings are supported.
