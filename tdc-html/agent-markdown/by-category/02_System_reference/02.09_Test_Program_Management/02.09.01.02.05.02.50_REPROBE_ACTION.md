# REPROBE_ACTION

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.50.01_Associated_Syntax_Entities.md>)

This expression allows you to specify what action (performed once only) is taken whenever a part falls into a reprobe bin. The line below is typical.

REPROBE_ACTION = PROB_HND_CALL(chuck_down_then_up);

After the reprobe action has been taken, the testflow is executed once more.
