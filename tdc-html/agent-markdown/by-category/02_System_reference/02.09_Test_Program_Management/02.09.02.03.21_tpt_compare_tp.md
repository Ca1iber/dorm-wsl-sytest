# tpt_compare_tp

The tpt_compare_tp command for the SmarTest Program Manager (STPM) [control file](<02.09.02.03_STPM_control_file.md>) lets you compare an existing master test program (MTP) with the specifications in a [Test program template](<02.09.02.01.02.03_Test_program_template.md>) (TPT) to identify the differences between the settings specified in both.

The command compares the MTP specified by the [mtp_device_testflow](<02.09.02.03.02_File_and_parameter_settings.md>) parameter in the control file and the TPT specified in the [mtp_template_dir](<02.09.02.03.02_File_and_parameter_settings.md>) parameter, generating an HTML report of the found differences.

## Syntax

```
tpt_compare_tp(
[report_file_path = '<report_file>',       ]
[include_groups   = <include_groups>,      ]
[pre_proc         = <pre_proc>,            ]
[post_proc        = <post_proc>]
)
```

## Parameters

 |

report_file_path

 |

<report_file> (string) is the path (including the name) where the command is to store the report file.

If this parameter is omitted, the file is named compare_log.html and is stored in the current working directory.

 |
 |

include_groups

 |

<include_groups> (list of strings) is a list of groups in the specified testflow that are to be compared.

Each group name is a string enclosed in single or double quotes; groups are separated by commas, and the list is enclosed in square brackets.

This parameter is optional. If it is omitted, the entire testflow is compared.

 |
 |

pre_proc

 |

<pre_proc> is a script that is executed before this command.

The syntax of the parameter value is described in [Preprocessing and postprocessing scripts](<02.09.02.03.03_Preprocessing_and_postprocessing_scripts.md>).

This is an optional parameter.

 |
 |

post_proc

 |

<post_proc> is a script that is executed after this command.

The syntax of the parameter value is described in [Preprocessing and postprocessing scripts](<02.09.02.03.03_Preprocessing_and_postprocessing_scripts.md>).

This is an optional parameter.

 |

## Functional changes

- Introduced in SmarTest 7.2.1
- SmarTest 7.2.2: Added the pre_proc and post_proc parameters.
