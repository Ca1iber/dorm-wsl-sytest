# User Variables

User Variables are of type double or string.

The variables can be declared in two ways:

- explicitly in the [Variables page](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.01.05_Variables_page.md>) of the [Flow Data Editor](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.01_Flow_Data_Editor.md>)
- implicitly in the testflow itself

The variables are stored in the declarations section of the [Testflow file](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.05_Testflow_file.md>).
