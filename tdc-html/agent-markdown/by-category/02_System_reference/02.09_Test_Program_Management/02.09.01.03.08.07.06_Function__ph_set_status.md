# Function: ph_set_status

This function sets some information to probers or handlers. For different probers and handlers, different parameters are supported.

Parameters supported for probers
 |

Parameter

 |

Description

 |

Applicable Probers

 |
 |

alarm_buzzer

 |

Ask the Prober to turn on the buzzer, flicker the yellow lamp, and show the messages on the display.

 |

TSK UF series

 |

Parameters supported for handlers

 |

Parameter

 |

Description

 |

Applicable Probers

 |
 |

name xxx

 |

Set the handler name to xxx.

 |

Mirae MR5800, M660

 |
 |

loader

 |

Prepare new lot or additional devices.

 |

Mirae MR5800, M660

 |
 |

start

 |

Start the handler.

 |

Mirae MR5800, M660

 |
 |

stop

 |

Stop the handler.

 |

Mirae MR5800, M660

 |
 |

plunger n

 |

Set the contractor status. It can be:

0= OFF

1= ON

 |

Mirae MR5800, M660

 |
 |

runmode n

 |

Set the running mode. It can be:

0= Normal mode.

1= Flush mode.

 |

Mirae MR5800, M660

 |
 |

lotclear

 |

Clear the lot counter.

 |

M660

 |
 |

accclear

 |

Clear the accumulated counters.

 |

M660

 |
 |

contactsel xxx

 |

Set the contact(site) selection. `xxx` is the bit-coded site selection value.

 |

M660

 |
 |

sitesel xxx

 |

Set the contact(site) selection. `xxx` is the bit-coded site selection value.

 |

Mirae MR5800

 |
 |

tempmode n

 |

Set the temperature control mode. It can be:

0: no control (off)

1: hot mode

2: ambient

3: code mode

 |

M660

 |
 |

temperature_tempcontrol

 |

Same as `tempmode.`

 |

M660

 |

## Example

```
PROB_HND_CALL(ph_set_status plunger 0);
```
