# SmarTest Program Manager MCM operating principles

SmarTest Program Manager MCM (STPM MCM) integrates individual test program modules into a full test program by using [mapping tables](<02.09.03.04_MTPT__STPM_MCM_mapping_tables.md>) (also called templates) to identify the modules to be integrated and the relationships of their components.

## Creating a template

To set up STPM MCM for a project, you begin by creating a template. You can do so from scratch, by creating an empty template with the -template [command line option](<02.09.03.05_STPM_MCM_command_line_options.md>) and filling the required information in manually.

Usually, however, it is more efficient to use the [generate_template](<02.09.03.03.02_generate_template.md>) command. You supply the command with a list of the individual test programs (STPs) that you want to combine into a master test program (MTP), optionally specifying desired settings, and the command creates a fully populated template out of them.

You can then manually edit this template to make sure that the resulting MTP meets your requirements. This is most efficiently done by using the provided [OpenOffice spreadsheets](<02.09.03.04.15_OpenOffice_spreadsheet_for_editing_the_CSV_files.md>).

## Creating a master test program

Once a template has been created, you use the [create_mtp](<02.09.03.03.05_create_mtp.md>) command to build the MTP from it. The resulting MTP combines all STPs specified in the template according to the settings from the template.

## Updating a master test program

The main benefit that STPM MCM offers is that you do not need to manually propagate changes from the STP manually to the MTP. Instead, you can just rerun create_mtp to rebuild the MTP from the changed STPs. If only one STP has changed, you can propagate the change even faster by using [update_mtp](<02.09.03.03.06_update_mtp.md>).
