# Return Codes

Any unit (function, program, script or VEE object) must return one of the following predefined constants. Where constants are not available (script/VEE), then the respective values [0..3] must be assigned as the return status.

The valid codes are as follows:

CI_CALL_PASS

value = 0

The unit has successfully completed the task and has terminated without error. CI_CALL_PASS is used to indicate that an EXEC_INP, a D_BRIDGE, or a PRB_HND call has been successfully completed,

CI_TEST_PASS

value = 0

Indicates that the test has passed. CI_TEST_PASS is used in the USER_PROC Command Set, where tests are usually carried out.

CI_TEST_FAIL

value = 1

Indicates that the test has failed

CI_CALL_ERROR

value = 2

A failure occurred during execution of the unit, causing any information written as a comment to be illegal. When this constant is returned, NO comment (the empty string) is assigned to the application model file variable and the error state is asserted. You can then select RETRY or ABORT.

Note Any value apart from 0 or 1 generates an error popup dialog at the user interface.

CI_CALL_BREAKD

value = 3

The Break Key has been pressed. This can occur within Test Programming Interface (TPI) functions. If this status is returned the choice of RETRY or ABORT is given (as with an error state).

Any return code apart from the valid range [0..3] generates an error, and is an invalid code. The production software notes the failure, and manual intervention is necessary to rectify the situation. You are given the option of RETRY or ABORT.
