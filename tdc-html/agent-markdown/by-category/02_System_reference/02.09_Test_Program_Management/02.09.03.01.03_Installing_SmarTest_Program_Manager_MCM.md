# Installing SmarTest Program Manager MCM

SmarTest Program Manager MCM (STPM MCM) is installed as part of the SmarTest Program Manager installation.

See [Installing SmarTest Program Manager](<02.09.02.01.03_Installing_SmarTest_Program_Manager.md>) for details.
