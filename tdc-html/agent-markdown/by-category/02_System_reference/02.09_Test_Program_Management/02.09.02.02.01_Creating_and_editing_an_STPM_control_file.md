# Creating and editing an STPM control file

The control file for SmarTest Program Manager (STPM) can be created and modified with a standard text editor. It follows the syntax conventions of the Python programming language.

## About this task

Perform this task to create a new control file for STPM or modify an existing one.

## Before you begin

Install STPM as described in [Installing SmarTest Program Manager](<02.09.02.01.03_Installing_SmarTest_Program_Manager.md>).

## Procedures

### Creating a new control file

You can create a control file from scratch, using the syntax described in [STPM control file](<02.09.02.03_STPM_control_file.md>). However, it is usually much more convenient to start with a template create by STPM:

- In a terminal, enter:

```
stpm -template
```

This creates four template files in ./templates/:

  - stpm_core_setup_template.setup. Use this template for managing the master test program, for example, adding or removing tests, extracting or merging subflows, or optimizing test programs.
  - stpm_tpt_admin_setup_template.setup. Use this template to create and edit the TPT (test program template).
  - stpm_tpt_tpgen_setup_template.setup. Use this template for creating or updating a test program from the TPT.
  - stpm_merge_rules_template.setup. The template for the [merge rules file](<02.09.02.04_STPM_merge_rules_file.md>) (which is not used for this procedure).

- Open the template best suited for your task with any text editor and edit it as desired.

The control file syntax is described in [Structure of an STPM control file](<02.09.02.03.01_Structure_of_an_STPM_control_file.md>). You can use any command described there in any of the first three template files, even if it is not included in the template STPM creates. However, usually all the commands you need are already included in the template, and you just need to specify the parameters for the commands you need and delete the other commands.

- Save the file.
- If desired, rename it and/or put it into a different location.

An STPM control file can have any name and be stored in any location. It also does not require a specific filename extension, although .setup and .py are common.

### Editing an existing control file

- Open the control file that you want to edit with any text editor.
- Make the desired changes.

The control file syntax is described in [Structure of an STPM control file](<02.09.02.03.01_Structure_of_an_STPM_control_file.md>).

- Save the file.

If desired, you can put it into another location and/or rename it.

## Results

You have a control file that you can use to control STPM's operation.
