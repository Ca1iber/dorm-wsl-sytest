# Parameter: enable_diagnose_window

This parameter determines whether to enable the diagnose window.

The value can be `"yes"` or `"no"`.

Changeable at run-time: no

Applicable for: probers

Example: enable_diagnose_window: "yes"

## Functional changes

- Introduced before SmarTest 6.3.2
