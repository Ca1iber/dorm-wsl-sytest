# ExecuteTestflowSync()

This API executes a testflow in a synchronous way. It must be called after the `DownloadTestflowSync()` API.

This API sets the state of SmarTest to `TESTING`. At the end of the API, the SmarTest status will be changed to `WAITING`.

`SUCCESS ` will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

PARAMETER_EXCEPTION

 |

- The value of the parameter "SITE_ID_FOR_SITES" "XXX" is not valid
- The value of the parameter "SITE_SETUP_FOR_SITES" "XXX" is not valid; only "I" or "X" is allowed
 |

RECOVERABLE

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- The local session does not exist.
- Can't execute testflow "XXX" since the SmarTest state is not "WAITING".
- No testflow is downloaded.
 |

RECOVERABLE

 |

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The local session ID.

 |
 |

I

 |

SITE_ID_FOR_SITES

 |

(optional) The list of site IDs. For a four-site testing, it is {"1","2","3","4"}

 |
 |

I

 |

SITE_SETUP_FOR_SITES

 |

(optional) The list of site setup. "`I`" means device inserted to test, "X" means no device inserted to test. For four-sites parallel testing, {"I", "I", "I", "X"} means the devices are inserted to test for the site 1, 2, 3, but no device is inserted for site 4.

 |

## Prototype

```
Status syncCommand("ExecTestflowSync", ParamList(), sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID; //the local session ID
vector<string> list;
ParamList cmdParams;
list = split("1 2 3 4", " ");
cmdParams.setValueArray("SITE_ID_FOR_SITES", list);
list = split ("I I I I", " ");
cmdParams.setValueArray("SITE_SETUP_FOR_SITES", list);
Status retVal = syncCommand("ExecTestflowSync", cmdParams, sid);
if ( retVal.isError() )
{
cout<<"error code= " << retVal.code() << " description="
    << retVal.text() << endl;
}
```

## Functional changes

- SmarTest 6.5.2: New Parameter SITE_ID_FOR_SITES and SITE_SETUP_FOR_SITES.
