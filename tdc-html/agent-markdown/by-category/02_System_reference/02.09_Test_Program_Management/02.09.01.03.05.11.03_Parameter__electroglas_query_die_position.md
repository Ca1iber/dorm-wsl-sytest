# Parameter: electroglas_query_die_position

It is possible for Electroglas series of probers to operate in a more efficient mode of communication. The Electroglas prober can be setup so the die coordinates are sent with the test start signals. If this is the case then this parameter should be set to "no". The driver will then interpret the die coordinates sent from the prober with the test start signal and will not send a separate query for the die position.

Driver default: "no"

Changeable at run-time: yes

Applicable for: Electroglas probers

Example: electroglas_query_die_position: "yes"
