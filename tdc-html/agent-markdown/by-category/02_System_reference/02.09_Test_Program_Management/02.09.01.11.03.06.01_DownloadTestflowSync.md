# DownloadTestflowSync()

This API downloads testflow setup files in a synchronous way.

This API should be called once for each testflow. When calling this API, the state of SmarTest will be changed to `LOADING`. At the end of the execution of the API, the SmarTest status will be changed to `WAITING`.

`SUCCESS ` will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

## Prototype

```
ParamList inputParams;
Status syncCommand("DownloadTestflowSync", inputParams, sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams;
inputParams["TESTFLOW_NAME"] = "tf";

Status retVal = syncCommand("DownloadTestflowSync", inputParams, sid);
if ( retVal.isError() )
{
cout<<"error code= " << retVal.code() << " description="
    << retVal.text() << endl;
}
```
