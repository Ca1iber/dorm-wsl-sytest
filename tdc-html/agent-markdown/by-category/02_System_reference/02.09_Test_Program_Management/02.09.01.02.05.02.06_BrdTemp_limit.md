# BrdTemp_limit

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.06.01_Associated_Syntax_Entities.md>)

This expression is used in conjunction with MONITOR_CALL, and enables you to set lower and upper temperature limits on the tester's I/O boards. To be of any real use, BrdTemp_limit should also be used in conjunction with BrdTemp_check (see above). The line,

MONITOR_CALL (BrdTemp_limit, -2.0, 2.0);

sets a lower limit of -2掳 (the first parameter) and an upper limit of 2掳 (the second parameter) on the temperature of the boards.

Range for the lower limit is [-2.5, 0] and range for upper limit is [0, 2.5].
