# GetApplicationVar()

This API gets the value of a variable from the level model shared memory. This API goes through all the levels in the shared memory and once the variable is found the value will be returned.

SUCCESS is returned if no error occurs. Otherwise an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

PARAMETER_EXCEPTION

 |

The value of the parameter "VARIABLE_NAME" is empty.

 |

RECOVERABLE

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- The local session does not exist.
- The variable name "XXX" cannot be found in the shared memory.

## Prototype

```
ParamList inputParams, outputResults;
Status query("GetApplicationVar", outputResults, inputParams, sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams, outputResults;
inputParams["VARIABLE_NAME"] = "operator_id";

Status retVal = query("GetApplicationVar", outputResults,
                   inputParams,  sid);
if ( retVal.isSuccess() )
{
  cout<< "The value of operator_id is"
     << outputResults["VARIABLE_VALUE"] <<endl;
}
```
