A workorder is a set of commands used to load, execute, and control a test program in a production environment. The workorder operator interface provides a menu to select or enter the needed information and control parameters prior to starting the execution of the test program. Typical parameter are tester name, lot id, and wafer id. The workorder refers to a test program, which contains testflow, data bridge, and other relevant testfloor information.

The Workorder Manager can be used for creating new workorders, or editing, printing and deleting existing workorders.

This chapter explains how to prepare a workorder using the Workorder Manager and assign it to a user's workorder directory (see [Setting up Workorder Directories](<../../01_Getting_started/01.02_SmarTest_workstation_administration/01.02.02.02.03_Setting_up_Workorder_Directories.md>)).

If you do not want to assign a workorder to a particular user, you can put it in any directory path, see [Enabling Workorders for Command Line Use](<02.09.01.05.04_Enabling_Workorders_for_Command_Line_Use.md>).
