# GetProbeCardInfo

This data query command gets the probe card information. Currently only the probe card ID is available.

This information is retrieved from the probe card EEPROM. If the probe card has no EEPROM, this information is read from application model variable. The application model variable must be named as `PROBECARD_ID` or `ph_PROBECARD_ID`. If neither EEPROM installed nor application model set, this API will return empty value.

SUCCESS will be returned if the command is successfully issued. Otherwise an error object will be returned indicating the error code, description and severity.
