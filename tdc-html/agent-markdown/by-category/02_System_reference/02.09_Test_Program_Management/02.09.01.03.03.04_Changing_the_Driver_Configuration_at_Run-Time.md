# Changing the Driver Configuration at Run-Time

#### Subtopics

- [Direct Change of Configuration Parameters](<02.09.01.03.03.04.01_Direct_Change_of_Configuration_Parameters.md>)
- [Changing Configuration Parameters with the Editor](<02.09.01.03.03.04.02_Changing_Configuration_Parameters_with_the_Editor.md>)

You can change the driver configuration at run-time with two special configuration functions which can be called from the application model (see [Using driver functions in the application model](<02.09.01.02.04_Using_driver_functions_in_the_application_model.md>) for information about how to call driver functions from the application model).

The configuration function ph_set_configuration lets you directly change the settings of configuration parameters by providing the parameter names and the new settings as function parameters. See [Direct Change of Configuration Parameters](<02.09.01.03.03.04.01_Direct_Change_of_Configuration_Parameters.md>) for details.

The configuration function ph_interactive_configuration allows you to change parameter settings with the designated editor for driver configurations. See [Changing Configuration Parameters with the Editor](<02.09.01.03.03.04.02_Changing_Configuration_Parameters_with_the_Editor.md>) for details.

Both functions change the internal parameter settings of the driver only. The driver configuration file, which was loaded at driver start-up and defined the initial setting of the driver parameters, will not be changed.

 Note Some configuration parameters cannot be changed at run-time per definition. [Configuration Parameters](<02.09.01.03.05_Configuration_Parameters.md>) states for each parameter whether changes at run-time are possible, or not possible.
