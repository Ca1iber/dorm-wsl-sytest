# How to issue an operation

The signature [operation](<02.09.01.10.03.01.09_operation.md>) is used to execute the remote control commands in HVM API which have output value. Currently, only [StartSmartestSession](<02.09.01.10.03.02.01.17_StartSmartestSession.md>) uses [operation](<02.09.01.10.03.01.09_operation.md>).

## About this task

The prototype of [operation](<02.09.01.10.03.01.09_operation.md>) is

```
xoc::hvmapi::Status operation(
const std::string &opName,
xoc::hvmapi::ParamList &opResults,
const xoc::hvmapi::ParamList &opParams=xoc::hvmapi::ParamList(),
const std::string &sessionId=std::string("") ).
```

The session ID of SmarTest is required to execute some API. If you Do not know it, you can get the session ID with the API [GetOnlineSmartestSessionID](<02.09.01.10.03.02.01.04_GetOnlineSmartestSessionID.md>) or [ListSmartestSessionIDs](<02.09.01.10.03.02.01.07_ListSmartestSessionIDs.md>).

## Before you begin

Make sure you are using SmarTest 6.2 or later.

## Procedure

-  Prepare the parameters for the API. You can refer to the code template below.

```
ParamList opParams, opResults;  //define the variables
opParams["param1"] = "value_for_param1"; //set values for parameters
opParams["param2"] = "value_for_param2";
```

-  Execute the operation and output the results.

```
Status retVal = operation("API_to_execute", opResults, opParams);
if(!retVal.isError())
{
  cout <<"Successful startup and the session ID is "<< opResults["SESSION_ID"]<<endl;
}
else
{
  cout <<"error code is " << retVal.code()<<endl;
}
```

## Results

The API is executed and output the result values. An error object will be returned indicating the execution status of the API.

## Example

The following example shows how to execute the API [StartSmartestSession](<02.09.01.10.03.02.01.17_StartSmartestSession.md>) with [operation()](<02.09.01.10.03.01.09_operation.md>).

```
ParamList opParams, opResults;
opParams["ONLINE_MODE"] = "ONLINE";
opParams["USER_MODE"] = "SUPERVISOR";
Status retVal = operation("StartSmartestSession", opResults, opParams);
if(!retVal.isError())
{
  cout <<"Successful startup and the session ID is "<< opResults["SESSION_ID"]<<endl;
}
else
{
  cout <<"error code is " << retVal.code()<<endl;
}
```
