# deleteFloatingTestsuite()

This API removes a floating UTM-based test suite from the test flow.

If it is successfully executed, true will be returned. Otherwise, false will be returned.

## Syntax

```
bool deleteFloatingTestsuite(const std::string& name);
```

Parameters
 |

name

 |

The test suite to delete.

 |
