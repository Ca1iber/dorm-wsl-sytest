# GetTestHeadInfoByID

This data query command gets the test head information with the test head ID. The test head ID is always "1". The board ID list will be returned for all the installed test boards.

SUCCESS will be returned if the command is successfully issued. Otherwise an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" is not online session ID.
- The designated test head ID "XXX" does not exist; currently, the ID of test head must be "1".
 |

RECOVERABLE

 |

## Dependency

An online SmarTest session is running.

## Parameters

 |

I/O

 |

Parameters

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The online session ID.

 |
 |

I

 |

TESTHEAD_ID

 |

The test head ID. Here it is always "1".

 |
 |

O

 |

qrResults

 |

The query results are represented by a ParamList object. It contains the following members:

TESTHEAD_TYPE: The type of test head. It can be `TH_8CC`, `TH_4CC`, `TH_2CC`.

DUT_INTERFACE: The DUT interface. It can be `F330`, `SOC`, `EXHIBITION`.

BOARD_ID_LIST: The list of the test board ID. The test board and board ID here are logical concept from the perspective of HVMAPI. They are 1:1 mapped to pogo block.

TESTHEAD_SERIAL: The serial number of the whole test system, like DE12345678 or MY12345678.

 |

## Prototype

```
ParamList qrParams, qrResults;
string sessionId;
Status query("GetTestHeadInfoByID", qrResults, qrParams, sessionId);
```

## Example

```
ParamList qrResults, qrParams;
string sid;
qrParams ["TESTHEAD_ID"] = "1";
query("GetTestHeadInfoByID", qrResults, qrParams, sid);
vector<string> bidList = qrResults.valueArray("BOARD_ID_LIST");
printf("The information for the testhead 1 is:\n");
printf("  <TESTHEAD_TYPE>: %s\n", qrResults ["TESTHEAD_TYPE"]);
printf("  <DUT_INTERFACE >: %s\n", qrResults ["DUT_INTERFACE"]);
printf("  <BOARD_ID_LIST>: \n");
foreach bid in bidList
{
    printf("     %s\n",  bid);
}
printf("  < TESTHEAD_SERIAL>: %s\n", qrResults ["TESTHEAD_SERIAL"]);
```
