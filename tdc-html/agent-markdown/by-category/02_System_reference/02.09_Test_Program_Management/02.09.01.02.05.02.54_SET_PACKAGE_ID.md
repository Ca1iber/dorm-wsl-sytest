# SET_PACKAGE_ID

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.54.01_Associated_Syntax_Entities.md>)

Allows you to enter a package ID. This package ID is used for data logging purposes. Note that SET_PACKAGE_ID statement operates on all sites together when you test on multiple test sites.

By including lines similar to those below, you can prompt the user to enter a package ID, for example,

LINE_DIALOG

package_id=DIALOG_INPUT/REGEXP(string);

ACTIONS

SET_PACKAGE_ID({package_id});
