# TESTPROGRAM_DOWNLOAD_COMPLETED

This asynchronous event indicates a test program downloading is completed.

## Dependency

The API `DownloadTestprogram` is called.

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

SESSION_ID

 |

The ID of the SmarTest session this event belongs to.

 |
 |

O

 |

TIME_STAMP

 |

The time point when this event occurs. It contains two long-type parts: `SECONDS` and `MICROSECONDS`.

 |
 |

O

 |

EVENT_NAME

 |

The event category. Here it is always `EXECUTION`.

 |
 |

O

 |

EVENT_BODY

 |

The event parameters. It contains the following members:

 |

`EXECUTION_STATE`

 |

The HVM event type. Here it is always `TESTPROGRAM_DOWNLOAD_COMPLETED`.

 |
 |

`DEVICE_PATH`

 |

The current device path.

 |
 |

`DEVICE_NAME`

 |

The current device name.

 |
 |

`TESTPROGRAM_NAME`

 |

The name of the test program that is downloaded.

 |

This parameter is represented by the `ParamList` whose key and value are both `string` type.

 |
