# Syntax Listing

#### Subtopics

- [Explanation of the Syntax](<02.09.01.02.03.03.01_Explanation_of_the_Syntax.md>)

The example below illustrates the syntax usage in an application model file.

See [Explanation of the Syntax](<02.09.01.02.03.03.01_Explanation_of_the_Syntax.md>) for further syntax explanations. The line numbers are used in [Explanation of the Syntax](<02.09.01.02.03.03.01_Explanation_of_the_Syntax.md>).

```
1  hp93000,applicmodel,0.1

2  START_DIALOG

3  { init:

4    SCREEN_DIALOG
5       .....
6       Temperature = APPLIC_DATA_EDITOR_INPUT /CONST_FORMAT(AMB|75|40|10);
7       Operator_id   = DIALOG_INPUT             /REGEXP(string);
8       Cassette_size = DIALOG_INPUT             /CONST_FORMAT(25|50);

9    ACTIONS
10     .....
11      Start_time    = GET_TEST_INFO (date_time);

12     { lot:

13       SCREEN_DIALOG

14          Lot_id        = DIALOG_INPUT             / REGEXP(nnnn);
15           DISABLE_SKIP_BUTTON;

16       ACTIONS

17          Handler_equipment    = CONST_INPUT(1);
18       -- Handler_equipment    = CONST_INPUT(0);
19          PROB_HND_CALL (ph_init {Handler_equipment} {Temperature});
20          GET_WAFERLIST ({Cassette_size}, ,{Lot_id},/tmp/waf_list1, {Lot_id},/tmp/waf_list2,
                           {Lot_id},/tmp/waf_list3,{Lot_id},/tmp/waf_list4);
21          SUBLEVEL_COUNT count = CONST_INPUT(4);

22        { cassette :

23          ACTIONS

24            cass_no    = AUTOINCREMENT;
25            wafer_list = FILE_INPUT (/tmp/waf_list{cass_no});

26          LOG_SPECIFICATION

27            RESULT_LOG      = ON;

28         {  WAFER [({Lot_id}),({wafer_id})] wafer:

29            ACTIONS

30               wafer_id = ELEMENT_OF_PARAM_LIST({wafer_list})/REGEXP(int);
31                 PROB_HND_CALL (ph_get_wafer);

32              LOG_SPECIFICATION

33                RESULT_LOG      = ON;

34                {  DEVICE die:

35                   ACTIONS

36                       PROB_HND_CALL (ph_get_die_location);

37                   LOG_SPECIFICATION

38                       RESULT_LOG   = ON;

39                       {
40                          DEVICE_TEST
41                       }
42                   REPROBE_ACTION = PROB_HND_CALL(ph_reprobe);

43                   ACTIONS

44                       PROB_HND_CALL (ph_bin_die);

45                }

46                 -- wafer post-action

47            PROB_HND_CALL (ph_check_reference_wafer);

48      }

49       -- cassette post-action

50         ACTIONS

51           PROB_HND_CALL (ph_check_output_cassette );

52     }

53      -- lot post-action

54     ACTIONS

55         PROB_HND_CALL (ph_exit);

56   }

57  }

58   {ON_PAUSE pause:

59       ACTIONS

60          PROB_HND_CALL (ph_red_alert);

61       SCREEN_DIALOG

62          BUTTON clean_pr         = PROB_HND_CALL(ph_clean_probes);
63          DISABLE_SKIP_BUTTON;
64          DISABLE_D_RETEST_BUTTON;
65          DISABLE_W_RETEST_BUTTON;

66  }
```
