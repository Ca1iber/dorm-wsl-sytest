# General information about the Tesec GPIB handler driver

This section provides general information about the Tesec GPIB handler driver.

## Configurations provided

The following configurations are provided with the driver:

- Tesec-9588-GPIB-1.cfg

Tesec-9588-GPIB-2.cfg

Tesec-9588-GPIB-1-of-2.cfg

The configurations differ in the number of sites they provide (1,2 or 1 of a dual site setup). The Tesec-9588-GPIB-1-of-2.cfg configuration is an example how to use a handler that is setup for two sites (mechanically) but only the second site is used for testing with a single site test setup at the test system (it uses a site remapping of site 2).
