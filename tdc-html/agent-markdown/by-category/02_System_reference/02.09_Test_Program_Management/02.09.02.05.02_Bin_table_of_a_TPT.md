# Bin table of a TPT

The bin table CSV file in an STPM [Test program template](<02.09.02.01.02.03_Test_program_template.md>) (TPT) contains information about the bins to be set up in the test program.

The file is best edited by importing it into the [OpenOffice spreadsheet](<02.09.02.05.07_OpenOffice_spreadsheet_for_editing_the_CSV_files.md>) provided with TPT Admin. Editing is also possible in text editors, but this requires you to make sure yourself that all formatting is correct.

Note that bin definitions in an imported test table that conflict with existing bin definitions are not imported. Two bins are considered to conflict if the SBin attribute is the same and any of the attributes listed below, except Notes, is different (empty attributes are ignored).

## Syntax

Each row in the bin table describes one bin. The table contains these columns:

- SBin: The ID of the software bin. It is used to refer to this bin from the [test suite table](<02.09.02.05.01_Test_suite_table_of_a_TPT.md>). To be compatible with the SmarTest Data Formatter, the number must be between 0 and 32767.
- SBin Label: The name of the software bin.
- HBin: The ID of the hardware bin connected to the software bin.
- HBin Label: The name of the hardware bin.

Note that this information will be ignored by STPM when it converts the CSV file into a testflow.

- Type: The type of the bin. It can be "good", "bad", or "other".
- Color: The color for the bin. The color can be any string.

If this column is left empty, STPM uses "" (empty string) for the color.

- Reprobe: The reprobe flag for the bin. It can be 1 (on) or 0 (off).

If this column is left empty, STPM uses 0 (reprobe off).

- Overon: The overon flag for the bin. It can be 1 (on) or 0 (off).

If this column is left empty, STPM uses 0 (overon off).

- Notes: Any notes you want to make about the bin. Comments are strictly for human use and are not processed in any way by STPM.
