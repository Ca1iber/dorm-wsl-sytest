# GetEQVariableValue

For fast access to equation variables, some of them are cached, thus avoiding time-consuming inter-process communication. A variable is cached when it is accessed for the first time.

This routine lets you put a variable into the cache (if it is not already there) and retrieve its value in one call. It is a combination of [InsertEQVariableInCache](<02.09.01.09.22_InsertEQVariableInCache.md>) and [GetEQVariableFromCache](<02.09.01.09.09_GetEQVariableFromCache.md>).

A variable is either

- a specification (the name is listed in the SPECS section of an equation definition), or
- a derived value (the name appears left to an "=" sign in the EQUATIONS section).

## Syntax

```
VOID GetEQVariableValue(
    INT32      equation_system,
    INT32      equation_set,
    INT32      spec_set,
    INT32      site_number,
    CHAR     *variable_name,
    FLOAT64     *value,
    INT32     *return_state);
```

## Example

```
FLOAT64 variable_value;
INT32 re_state;
GetEQVariableValue(TIMING_EQ_SYSTEM,2,1,2,"var1",&variable_value,&re_state);
```
