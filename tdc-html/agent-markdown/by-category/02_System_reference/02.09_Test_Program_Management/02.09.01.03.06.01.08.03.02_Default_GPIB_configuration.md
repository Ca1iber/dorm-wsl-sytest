# Default GPIB configuration

When the configuration files were created, certain aspects necessarily had to be defined. The table below lists these aspects and how they were defined.

Important aspects of the Flex configuration files
 |

Aspect

 |

Used setting

 |
 |

Debug level

 |

0, will log only basic messages, can be changed to a value between -1 and 4.

 |
 |

GPIB port used

 |

6, must be changed to correct value based on the handler's setup .

 |
 |

Auto-pausing of handler

 |

Activated. Handler is stopped on SmarTest pause.

 |
 |

Resume after pause

 |

Automatically, if stopped automatically.

 |
 |

Bin mapping

 |

Default

 |
 |

Number of bins

 |

100 (SmarTest hardbins 0 through 99), bin 0 represents the handler's retest bin.

 |
 |

Retest bin

 |

0

 |
 |

Bin verification

 |

Deactivated, may be activated by changing the configuration parameters verify_bin_data and verify_retry_count.

 |
 |

Reprobe mode

 |

Automatic reprobe on a per site mode, if devices fall into SmarTest reprobe bins.

 |
 |

Temperature control

 |

Set up to manual, may be changed to active with parameter temp_control.

 |
 |

Temperature parameters

 |

Some values are predefined in the configuration and may be activated by changing the parameter temp_control to active. Temperature may be controlled for the storage and testsite area or for the tcu, if a tcu is installed; setpoint, guardbands, soaktime can be defined, heater and cooler can be activated.

 |
 |

Test start detection

 |

Done by interrupt (SRQ), may be changed to pure polling mode with given polling interval for troubleshooting.

 |
 |

End-of-line terminator

 |

Driver sends LF and EOI on the GPIB bus, cannot be changed in the configuration file. Driver expects no special end of line code from handler except EOI.

 |
 |

Polling interval

 |

Preset to 100 ms, only used if waiting for parts is done by polling.

   |
