# Installing the STPM UI plug-in

To install the STPM UI plug-in, run the separate installer for it.

## About this task

Perform this task when you have installed STPM and want to access it from the SmarTest graphical user interface.

## Before you begin

Make sure that you have installed both of these:

- SmarTest 7.2.1.0 or a higher version
- SmarTest Program Manager 2.4.3 or a higher version

## Procedure

-  Exit SmarTest, if it is running.
-  Install the stpm_ui_<version>.rpm installer package.
-  Open SmarTest again.

## Results

The STPM UI plug-in is now installed and can be accessed as described in [STPM UI plug-in](<02.09.02.07_STPM_UI_plug-in.md>).
