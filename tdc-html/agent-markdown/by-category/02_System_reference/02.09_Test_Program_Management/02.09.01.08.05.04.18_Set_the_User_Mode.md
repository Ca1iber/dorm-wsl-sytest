# Set the User Mode

The SetUserMode function sets the current mode of operation of the SmarTest software.

long SetUserMode(long mode)

mode can be one of the following values:

CI_CONSOLE_MODE=1, to set Console mode

CI_OPERATING_MODE=2 to set Operating mode

CI_SUPERVISING_MODE=3 to set Supervising mode

CI_ENGINEERING_MODE=4 to set Engineering mode

 Note Do not set the Console mode, as it is for the Operator Console (obsolete product).
