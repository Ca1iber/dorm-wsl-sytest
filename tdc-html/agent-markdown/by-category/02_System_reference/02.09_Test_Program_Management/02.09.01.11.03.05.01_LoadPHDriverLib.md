# LoadPHDriverLib()

This API loads the prober/handler driver into the memory at the run time. If a shared library is already loaded, this API will first unload the shared library and then load the requested one.

SUCCESS will be returned if no error occurs. Otherwise an error object will be returned indicating the error code, description and severity.

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The local session ID.

 |
 |

I

 |

PH_DRIVER_LIB_FILE

 |

The full path of the prober/handler driver library.

 |
 |

I

 |

PH_DRIVER_CONFIG_FILE

 |

(optional)The full path of the configuration file used by the generic prober/handler driver. If PH_PLUGIN_LIB and PH_PLUGIN_CONFIG_FILE are not specified, the PH driver will find the configure file in the default directory: /etc/opt/hp93000/soc/PH_libs/GenericHandler/.

 |
 |

I

 |

PH_PLUGIN_LIB

 |

(Optional) The path of the prober/handler plug-in library directory. It must work together with the PH_PLUGIN_CONFIG_FILE parameter. If the PH_DRIVER_CONFIG_FILE is not specified, the API will construct a global configuration file for the prober/handler driver based on these two parameters.

 |
 |

I

 |

PH_PLUGIN_CONFIG_FILE

 |

(Optional) The path of the prober/handler plug-in configuration file. It must work together with the PH_PLUGIN_LIB parameter.

   | Note The parameter `PH_DRIVER_CONFIG_FILE` has higher priority than the parameter `PH_PLUGIN_LIB` and `PH_PLUGIN_CONFIG_FILE`. If all the three parameters are specified, only the parameter `PH_DRIVER_CONFIG_FILE` will be used.

## Prototype

```
ParamList inputParams;
Status syncCommand("LoadPHDriverLib", inputParams, sessionID);
```

## Examples

### Example 1

This example loads the prober driver and uses the global configuration file

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams;
inputParams["PH_DRIVER_LIB_FILE"] = "/opt/hp93000/soc/PH_libs/GenericProber";
inputParams["PH_DRIVER_CONFIG_FILE"] = "/tmp/Global_prober_config.cfg";

Status retVal = syncCommand("LoadPHDriverLib", inputParams, sid);
if ( retVal.isError() )
{
  cout<<"error code= " << retVal.code() << "description="
     << retVal.text() << endl;
}
```

### Example 2

This example loads the prober driver and uses the plug-in library and plug-in configuration file

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams;
inputParams["PH_DRIVER_LIB"] = "/opt/hp93000/soc/PH_libs/GenericProber";
inputParams["PH_PLUGIN_LIB"] = "/opt/hp93000/soc/PH_libs/GenericProber/TSK";
inputParams["PH_PLUGIN_CONFIG_FILE"]=
"/etc/opt/hp93000/soc/PH_libs/GenericProber/TSK/GENERIC-GPIB-Prober-2-die.cfg";

Status retVal = syncCommand("LoadPHDriverLib", inputParams, sid);
if ( retVal.isError() )
{
  cout<<"error code= " << retVal.code() << " description="
     << retVal.text() << endl;
}
```

### Example 3

This example loads the Prober driver and uses the default global configuration file.

```

```
