# LEVEL_STARTED

The asynchronous event indicates that the execution for a new level of application model is started in the test program execution.

Level change is maintained by the application model. There are four types of levels in the application model: `WAFER_LEVEL`, `DEVICE_LEVEL`, `PAUSE_LEVEL`, `CUSTOM_LEVEL`.

## Dependency

The test program is in execution.
