# Using the Verify Wafer Checksum Button

You can use the Verify Checksum toggle button if your site uses the SEMI standard laser numbers (12 or 18 characters) for its wafer numbering scheme.

With the Verify Wafer Checksum set, SmarTest checks the wafer number with a predefined algorithm against the SEMI standard for that particular wafer number. When there is a mismatch, an error message is displayed.
