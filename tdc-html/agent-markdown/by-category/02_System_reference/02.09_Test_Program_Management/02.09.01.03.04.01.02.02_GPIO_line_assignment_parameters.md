# GPIO line assignment parameters

Make sure that the GPIO line assignment parameters are defined correctly, such as:

- per_site_bin_line_groups
- per_site_end_of_test_line
- per_site_test_start_line
- global_test_start_line

This should be considered especially for handlers that are not directly supported by default driver configurations. Compare the handler specifications with the GPIO line assignment parameters as found in a configuration file of the "Universal-GPIO" plug-in.

See [General Handler Driver](<02.09.01.03.06.01_General_Handler_Driver.md>) for additional information about a specific handler, such as the timing diagram and line assignments.
