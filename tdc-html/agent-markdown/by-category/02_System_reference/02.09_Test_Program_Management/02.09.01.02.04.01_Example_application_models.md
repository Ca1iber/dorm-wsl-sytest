# Example application models

#### Subtopics

- [Application model for package test](<02.09.01.02.04.01.01_Application_model_for_package_test.md>)
- [Application model for wafer test](<02.09.01.02.04.01.02_Application_model_for_wafer_test.md>)

These examples demonstrate the usage of general handler driver functions and of general prober driver functions in an application model.

The example application models contain calls of all available driver functions. The calls appear either at their mandatory position in the application model, or at positions which demonstrate the typical use of a function.

The data resulting from driver functions is included in the data log stream of event data logging, if the event logging is activated.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.0: GDF logging in application mode is obsolete.
