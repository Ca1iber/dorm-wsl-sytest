# AbortTestprogram

This remote control command tries to abort the execution of a test program. If the execution is aborted, the event `TESTPROGRAM_EXEC_ABORTED` will be notified.

SUCCESS will be returned if the command is successfully issued. Otherwise an error object indicating the error code, description and severity will be returned.

 |

Code

 |

Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- Cannott abort the test program execution because there is no test program currently running.
 |

RECOVERABLE

 |

## Dependency

The test program is in execution.
