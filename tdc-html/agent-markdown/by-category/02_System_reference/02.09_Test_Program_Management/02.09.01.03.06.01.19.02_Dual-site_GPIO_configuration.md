# Dual-site GPIO configuration

#### Subtopics

- [Valid combinations of plug-ins and configuration files](<02.09.01.03.06.01.19.02.01_Valid_combinations_of_plug-ins_and_configuration_files.md>)
- [Binning map](<02.09.01.03.06.01.19.02.02_Binning_map.md>)
- [Timing diagram (TESEC dual-site)](<02.09.01.03.06.01.19.02.03_Timing_diagram__TESEC_dual-site.md>)

The TESEC "Dual-site" configuration is valid for TESEC dual-site handlers.

Supported handler models

- 9588 or others with similar interface

Features

- 2 sites
- 2 test start signal
- serial binning
- explicit binning
- 5 bin categories
- no "empty" bin

Required handler cable

There is no preconfigured handler cable available for this configuration. Please see Tesec handler cable for the information on configuring the cable.
