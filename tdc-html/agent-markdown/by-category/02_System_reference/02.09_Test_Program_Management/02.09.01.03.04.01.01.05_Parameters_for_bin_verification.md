# Parameters for bin verification

These parameters determine how bin verification is handled:

- verify_bin_data

When this parameter is set to yes, the handler will request verification of the binning data from the driver before binning the devices. You can use this command to detect communication problems due to, for example, noise on the bus.

- verify_retry_count

This parameter determines how many times the verify_bin_data will be executed.
