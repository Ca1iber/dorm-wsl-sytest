# Move the Data Log Stream to a File

long MoveEventStreamToFile(char *moveStreamToFile)

Copy the data log stream file to the file specified by the parameter moveStreamToFile and reset the file pointer. If the parameter moveStreamToFile is NULL, the data log stream file is only reset and not moved.

The returned values are,

 |

0

 |

OK

 |
 |

1

 |

error occurred

   |
