# IsWaferDone()

This API checks whether all the wafers are finished.

`SUCCESS` is returned if no error occurred. Otherwise, an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- The local session does not exist.
 |

RECOVERABLE

 |

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The ID of the session to work with.

 |
 |

O

 |

IS_WAFER_DONE

 |

If all the wafers are finished, the value is `TRUE`. Otherwise, it is `FALSE`.

 |

Prototype

```
ParamList outputResults;
Status query("IsWaferDone", outputResults, ParamList(), sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID;
ParamList outputResults;

Status retVal = query("IsWaferDone", outputResults, ParamList(), sid);
if ( retVal.isSuccess() )
{
cout<< "The WAFER status = " << outputResults["IS_WAFER_DONE"] << endl;
}
```

## Functional changes

- Introduced in SmarTest 6.5.0
