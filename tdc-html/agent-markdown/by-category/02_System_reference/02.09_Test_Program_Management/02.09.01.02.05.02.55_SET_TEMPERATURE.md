# SET_TEMPERATURE

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.55.01_Associated_Syntax_Entities.md>)

Allows you to enter a temperature for your test environment. This information is used for data logging purposes.

By including lines similar to those below, you can prompt the user to enter a temperature, for example,

LINE_DIALOG

temperature=DIALOG_INPUT/REGEXP(real);

ACTIONS

SET_TEMPERATURE({temperature});
