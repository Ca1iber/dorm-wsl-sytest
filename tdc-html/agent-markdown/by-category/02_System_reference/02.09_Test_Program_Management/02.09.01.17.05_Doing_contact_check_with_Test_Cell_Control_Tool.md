# Doing contact check with Test Cell Control Tool

Doing contact check with Test Cell Control Tool will execute the loaded testflow and update the test results in the Binning area. But the test results will not be included in the data log file.

## Before you begin

Make sure TCCT and a SmarTest session are started. TCCT is successfully attached to the SmarTest session. The status is shown in the lowest part of TCCT. "SmarTest XXX Attached" will be shown if it is successfully attached. Otherwise, you will see the message "SmarTest Session Detached".

## Procedure

-  To load the testflow, click [Load Testflow](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>), select the testflow file and click OK.

The testflow and all its setups will be loaded.

-  To set the equipement, click the Equipment tab and then click the [Equipment Setting](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) button. In the dialog, select the test type and the configuration.
-  To execute the testflow, click [Contact Check](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) in the lower part of TCCT .
-  If some error occurs, you need to solve it before doing further test.

## Results

The test results are displayed in the report window. The binning information is updated in the Binning area. No data log file is created for the execution of the contact check.

## Functional changes

- Introduced in SmarTest 7.2.0
