# HVM API Reference

#### Subtopics

- [API Signature](<02.09.01.10.03.01_API_Signature.md>)
- [HVM APIs](<02.09.01.10.03.02_HVM_APIs.md>)
- [Terminology](<02.09.01.10.03.03_Terminology.md>)

This section provides the reference information of the HVM APIs for creating the application client. Firstly the API signatures used to represent the HVM APIs are described. The description, prototype, parameters and example are provided for each signature. The signatures are arranged in alphabetical order.

Then the details of HVM APIs are described. The description, parameters, prototype and example are provided for each API. The HVM APIs are arranged according to their capability category: SmarTest Session Management API, Test Execution API, Hardware Information API and Calibration and Diagnostic API.
