# Structure of an STPM control file

The STPM control file contains commands and setting for SmarTest Program manager (STPM) to use in a conversion. It's structure follows the conventions of the Python programming language.

The STPM control file can contain these settings and commands:

- Setting specifying files:

  - [mtp_device_testflow](<02.09.02.03.02_File_and_parameter_settings.md>)
  - [mtp_template_dir](<02.09.02.03.02_File_and_parameter_settings.md>)
  - [merge_rules](<02.09.02.03.02_File_and_parameter_settings.md>)

- Settings defining the environment:

  - [ate_model](<02.09.02.03.02_File_and_parameter_settings.md>)
  - [ate_target](<02.09.02.03.02_File_and_parameter_settings.md>)
  - [ate_version](<02.09.02.03.02_File_and_parameter_settings.md>)

- Other settings:

  - [enable_backup](<02.09.02.03.02_File_and_parameter_settings.md>)

- Commands for writing master test programs (MTPs):

  - [write_tp](<02.09.02.03.04_write_tp.md>)

- Integration commands:

  - [add_test](<02.09.02.03.05_add_test.md>)
  - [add_burst](<02.09.02.03.06_add_burst.md>)
  - [add_test_to_burst](<02.09.02.03.07_add_test_to_burst.md>)
  - [add_empty_test_group](<02.09.02.03.08_add_empty_test_group.md>)
  - [remove_test](<02.09.02.03.09_remove_test.md>)
  - [replace_test](<02.09.02.03.10_replace_test.md>)
  - [remove_label](<02.09.02.03.11_remove_label.md>)

- Commands for creating and modifying test program templates (TPTs):

  - [tpt_generate_template](<02.09.02.03.14_tpt_generate_template.md>)
  - [tpt_import_from_device](<02.09.02.03.15_tpt_import_from_device.md>)
  - [tpt_generate_device_dir](<02.09.02.03.16_tpt_generate_device_dir.md>)
  - [tpt_merge](<02.09.02.03.17_tpt_merge.md>)

- Commands for working with MTPs using TPTs:

  - [tpt_add_test](<02.09.02.03.18_tpt_add_test.md>)
  - [tpt_replace_test](<02.09.02.03.19_tpt_replace_test.md>)
  - [tpt_generate_tp](<02.09.02.03.20_tpt_generate_tp.md>)
  - [tpt_compare_tp](<02.09.02.03.21_tpt_compare_tp.md>)
  - [tpt_generate_test_stages](<02.09.02.03.22_tpt_generate_test_stages.md>)

- Collaboration support commands

  - [extract_subflow](<02.09.02.03.23_extract_subflow.md>)
  - [merge_subflow](<02.09.02.03.24_merge_subflow.md>)
  - [remove_subflow](<02.09.02.03.25_remove_subflow.md>)

- Clean-up commands

  - [clear_duplicated](<02.09.02.03.26_clear_duplicated.md>)
  - [clear_unused](<02.09.02.03.27_clear_unused.md>)Note STPM control files are Python files and as such support all standard conventions of the Python programming language. You can therefore use the usual programming constructs like conditional statements or loops. Describing these constructs is beyond the scope of this manual. If you require information about them, please see appropriate Python documentation.

## Order of statements

The order of the integration and MTP write commands in the file determines in which order STPM works on the test suites to integrate or remove them and what states get written to disk.

Bins and test types must be defined before they can be used.

The order of the settings is not important.

## Comments

You can add comments to the control file by beginning a line with #.

## Example

Sample control file with support for test methods and binning:

```
##############################
# Input: Device Test Program Location
##

##############################
# Configuration
##

# Master Test Program (MTP) device path
mtp_device_testflow = '/home/user/93K_Device/project.tf'

# Merge Rules file.
merge_rules = '/home/user/setup/merge_rules.py'

##############################
# Integration Commands
##

add_test(
    test_flow_file = './home/user/new1_93k/testflow/test.tf', # Link to new test flow file
    test = 'test_n1' # test name
    )
add_test(
    test_flow_file = './home/user/new2_93k/testflow/test.tf', # Link to new test flow file
    test = 'test_n2', # target test name
    position = 'first',
    lev_reuse = 'auto'
    )

##############################
# Output: Device Test Program Location
##

# Write Master Test Program (MTP).
write_tp = '/home/user/93K_Device/project.tf'
```
