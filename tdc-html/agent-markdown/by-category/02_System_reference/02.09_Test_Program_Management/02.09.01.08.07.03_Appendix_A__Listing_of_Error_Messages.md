# Appendix A: Listing of Error Messages

#### Subtopics

- [MCD Errors](<02.09.01.08.07.03.01_MCD_Errors.md>)

This appendix gives a listing of the MCD error codes and the associated error messages. Such an error code may be returned in the state integer when you execute a call to [HpFwTask](<02.09.01.09.21_HpFwTask.md>), or [DataManager](<02.09.01.09.02_DataManager.md>).
