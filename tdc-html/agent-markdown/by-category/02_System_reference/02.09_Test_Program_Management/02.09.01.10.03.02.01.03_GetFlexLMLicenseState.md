# GetFlexLMLicenseState

This API gets the FlexLM license information including the requested license types, the license number requested, the license number acquired and the license number missing.

It can be used anytime after the Smartest is started. It's generally used after receiving the DEVICE_CHANGE_COMPLETED event.

The HVM client can get the license state with this API actively, or get the state with the event FLEXLM_LICENSE_REQUEST_COMPLETED passively.

## Dependency

A device is already loaded in the Smartest session.

Parameter
 |

I/O

 |

Parameter

 |

Description

SESSION_ID

the ID of the session to work with

 |

O

 |

qrResults

 |

The query result is represented by a ParamList object. It contains the following members:

- `LICENSE_TYPES_REQUESTED:` The requested license types. It can be "`SMARTEST_SOC`", "`SMARTEST_OFFLINE_SOC`" or "`SOC_93K_FULL_SYSTEM_CAPABILITY`".
- `LICENSES_REQUESTED:` The requested licenses. It is in one to one correspondence with the result of `LICENSE_TYPES_REQUESTED.`
- `LICENSES_ACQUIRED:` The licenses acquired. It is in one to one correspondence with the result of `LICENSE_TYPES_REQUESTED.`
- `LICENSES_MISSING:` The licenses missing. It is in one to one correspondence with the result of `LICENSE_TYPES_REQUESTED.`
 |

## Prototype

```
ParamList qrResults;
Status query("GetFlexLMLicenseState", qrResults,  ParamList(), sessionId);
```

## Example

```
string sid ;
ParamList qrResults;
Status retVal = query("GetFlexLMLicenseState", qrResults, ParamList(), sid);
If(retVal = "SUCCESS")
{
vector<string> licenseTypes = qrResults.valueArray("LICENSE_TYPES_REQUESTED");
       for(unsigned int i=0; i<licenseTypes.size(); i++)
       {
             cout<<licenseTypes[i]<<endl;
       }
}
```
