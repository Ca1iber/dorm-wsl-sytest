# General information about the RFS handler driver

This section provides general information about the RFS handler driver.

## Configurations provided

The following configurations are provided with the driver:

- RFS-GPIB-1.cfg
- RFS-GPIB-2.cfg
- RFS-GPIB-4.cfg
- RFS-GPIB-8.cfg

The configurations differ only in the number of sites they provide.

## Supported handler models

The Flex handler driver supports all Delta Design Flex handler models.
