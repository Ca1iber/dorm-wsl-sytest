# FILE_INPUT

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.34.01_Associated_Syntax_Entities.md>)

Reads the content of a file into a parameter. This parameter must be a valid file name. It is used, for example, in the wafer_auto application model file to get the list of wafers from the /tmp/ directory;

 cassette_list = FILE_INPUT (/tmp/{Lot_id}.waf_list);

The wafer list file is in the format below. The line starting with `#` will be skipped. The line starting with `--` is a comment line. Each of the other lines represents a wafer to be tested. If the application model file uses the data defined in the wafer list file via [ELEMENT_OF_PARAM_LIST](<02.09.01.02.05.02.32_ELEMENT_OF_PARAM_LIST.md>) keyword, the corresponding application model variable must have the same data type (specified by [REGEXP](<02.09.01.02.05.02.49_REGEXP.md>) keyword) as the data in the wafer list file.

```
134
135
136
137
#138
139
140
--end of the file
```
