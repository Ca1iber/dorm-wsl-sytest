# LoadTestflowSync

This API loads a test flow into SmarTest synchronously.

`LoadTestflowSync` does not download the setups in the test flow to SmarTest. It is similar to the test flow load operation on the graphic user interface. It allows specifying alternative test flow data elements to replace the corresponding elements in the test flow file. When alternative setups are specified with this API, the corresponding setups in the test flow will be ignored. After calling this API, the test flow will become out-of-date (with an asterisk behind the test flow name in the Test Program Explorer). If you want to keep the original setups in the test flow, do not save it.

## Dependency

A device is already set (loaded) for SmarTest.

Parameters
 |

SESSION_ID

 |

The SmarTest session ID.

 |
 |

TESTFLOW_NAME

 |

The test flow name.

 |
 |

ALTERNATIVE_TF_ELEM_TYPE

 |

(optional) The alternative test flow element types. It is in the format of {"SETUP:LEVEL", "SETUP:TIMING"}. The valid values include

SETUP:LEVEL, SETUP:TIMING, SETUP:VECTOR, SETUP:PIN_CONFIG, SETUP:PIN_ATTRIBUTE, SETUP:WAVEFORM, SETUP:ROUTING, SETUP:ANALOG_CONTROL, and SETUP:CHANNEL_ATTRIBUTE.

 |
 |

ALTERNATIVE _TF_ELEM_VALUE

 |

(optional) The alternative test flow element data. It is in the format of {"level1", "timing1"}.The setups specified here must be in the current device directory.

 |

## Prototype

```
ParamList cmdParams;
Status syncCommand("LoadTestflowSync", cmdParams, sessionId);
```

## Example

```
string sid ;
ParamList cmdParams;
vector<string> list;
list = split("SETUP:LEVEL SETUP:TIMING", " ");
/* specify the tf element types */
cmdParams.setValueArray("ALTERNATIVE_TF_ELEM_TYPE", list);
list = split ("level1 timing1", " ");
/* specify the tf element values*/
cmdParams.setValueArray("ALTERNATIVE _TF_ELEM_VALUE", list);
syncCommand("LoadTestflowSync", cmdParams, sid,);
```
