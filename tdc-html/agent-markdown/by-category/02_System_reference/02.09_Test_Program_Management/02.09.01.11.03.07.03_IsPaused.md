# IsPaused()

This API checks whether the Pause production flag is set. BLC needs to take actions according to the return value. Generally, the pause state is checked immediately after the testflow is executed.

SUCCESS is returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- The local session does not exist.
 |

RECOVERABLE

 |

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The local session ID.

 |
 |

O

 |

IS_PAUSED

 |

If the PAUSE production flag is set, the value is TRUE. Otherwise it is FALSE.

 |

## Prototype

```
ParamList outputResults;
Status query("IsPaused", outputResults, ParamList(), sessionID);
```

## Example

```
string sid=LOCAL_SESSION_ID;
ParamList outputResults;
Status retVal=query("IsPaused", outputResults, ParamList(), sid);
if(retVal.isSuccess())
{
  cout<<"The PAUSE status =" << outputResults["IS_PAUSED"] <<endl;
}
```
