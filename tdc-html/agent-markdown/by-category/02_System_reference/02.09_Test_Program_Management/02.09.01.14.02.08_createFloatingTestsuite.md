# createFloatingTestsuite()

This API creates a floating test suite with the specified name to the current test flow.

If the test suite name is unique in the test flow, an object of [TestsuiteProxy](<02.09.01.14.02.01_TestsuiteProxy.md>) wil be returned. Otherwise, an `runtime_error` exception will be thrown out.

## Syntax

```
TestsuiteProxy createFloatingTestsuite(const std::string& testsuiteName);
```

Parameters
 |

testsuiteName

 |

The test suite name.

 |
