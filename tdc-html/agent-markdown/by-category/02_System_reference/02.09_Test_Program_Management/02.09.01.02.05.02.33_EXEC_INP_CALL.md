# EXEC_INP_CALL

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.33.01_Associated_Syntax_Entities.md>)

Used to call a function that controls data coming from the production process, such as a barcode reader. For example, you might set up lines similar to those below if you had a wafer barcode reader.

ACTIONS

wafer_number=EXEC_INP_CALL(BCR_read_wafer_no);
