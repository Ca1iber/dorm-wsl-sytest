# Configuration at the prober

The prober must be set up correctly to work with the prober driver. See the Electroglas documentation for information on how to set up the prober.

 Note If the learn pattern probing mode is required, where the coordinates are set up by the driver, use the "learnlist" configuration.

Please pay attention to the following points when configuring the prober:

- SmarTest

Under "smartest" mode, the driver will control stepping and inking. The prober must be set up ready to receive the handle wafer (HW) command.

- LearnList

The prober must be set up in the learn pattern mode as described in Electroglas documentation.

For Commander series probers, the setting recipe_file_name in the configuration file must be set to the file name as set up on the prober.
