# SET_DIE_X_Y

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.53.01_Associated_Syntax_Entities.md>)

Allows you to enter the x and y die positions. This information can be used for data logging purposes and for providing information for the prober driver. Use the SET_DIE_X_Y expression only when you want to control your wafer prober pattern from the application model; otherwise use the wafer description editor.

 Note If the SET_DIE_X_Y statement is used in the application model, it is assumed that the prober x_y control is NOT influenced by what is defined in the Wafer Description Editor (a prober pattern, for example).

When you test on multiple test sites the SET_DIE_X_Y statement sets the x and y die positions for all sites. The actual positions of the die are set by the Handler/Prober library.

In the lines below, the prober x_y position is controlled by what is entered at the DIALOG_INPUT,

{DEVICEdie:

LINE_DIALOG

x_pos=DIALOG_INPUT;

y_pos=DIALOG_INPUT;

ACTIONS

SET_DIE_X_Y({x_pos},{y_pos});

whereas, in the following lines, the x-y position is controlled by separate files,

{WAFER[(wafermap),()]wafer:

ACTIONS

x_list=FILE_INPUT(/tmp/x_coords);

y_list=FILE_INPUT(/tmp/y_coords);

:

:

{DEVICEdie:

ACTIONS

x_pos=ELEMENT_OF_PARAM_LIST({x_list});

y_pos=ELEMENT_OF_PARAM_LIST({y_list});

SET_DIE_X_Y({x_pox},{y_pos});
