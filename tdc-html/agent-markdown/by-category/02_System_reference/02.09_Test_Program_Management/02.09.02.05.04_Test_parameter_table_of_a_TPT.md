# Test parameter table of a TPT

The test parameter table CSV file in an STPM [Test program template](<02.09.02.01.02.03_Test_program_template.md>) (TPT) contains information about sets of parameters that can be applied to the tests to be used in the test program.

The file is best edited by importing it into the [OpenOffice spreadsheet](<02.09.02.05.07_OpenOffice_spreadsheet_for_editing_the_CSV_files.md>) provided with TPT Admin. Editing is also possible in text editors, but this requires you to make sure yourself that all formatting is correct.

## Syntax

Each row in the test suite table describes one set of test parameters. The table contains these columns:

- Test Suite Name: The name of the test suite in the test program to which the parameters apply. The test suite must be defined with this name in the [test suite table](<02.09.02.05.01_Test_suite_table_of_a_TPT.md>).
- Test Method: The name of the test method being executed in the test suite.
- Param: Each of these named Param contains the name and value for one parameter that is passed to the test method.

You can create as many parameter columns as desired. Each column must have the title Param.

Parameters must be specified in the column the form <name>`=`<value>, for example, `output=None`.
