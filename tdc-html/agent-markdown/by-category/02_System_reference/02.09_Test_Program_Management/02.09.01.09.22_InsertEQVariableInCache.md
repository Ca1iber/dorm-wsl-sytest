# InsertEQVariableInCache

For fast access to equation variables, some of them can are cached, thus avoiding time-consuming inter-process communication.

This routine lets you insert a variable into the cache from within your test flow program.

A variable is either

- a specification (the name is listed in the SPECS section of an equation definition), or
- a derived value (the name appears left to an "=" sign in the EQUATIONS section).Note You can also use [GetEQVariableValue](<02.09.01.09.10_GetEQVariableValue.md>) to cache a variable and retrieve its value in one call. InsertEQVariableFromCache, however, should be used in combination with [GetEQVariableFromCache](<02.09.01.09.09_GetEQVariableFromCache.md>) if you need to ensure constant run-times for your test flow program.

## Syntax

```
VOID InsertEQVariableInCache(
    INT32      equation_system;
    INT32      equation_set;
    INT32      spec_set;
    CHAR     *variable_name;
    INT32     *return_state)
```

## Example

```
INT32 re_state;
InsertEQVariableInCache(TIMING_EQ_SYSTEM, 1, 1, "tim_var",&re_state);
```
