# How to issue a query

The signature [query](<02.09.01.10.03.01.10_query.md>) is used to execute the data query command of HVM API.

## About this task

These APIs include:

[GetOnlineSmartestSessionID](<02.09.01.10.03.02.01.04_GetOnlineSmartestSessionID.md>), [GetSmartestSessionProfile](<02.09.01.12.03_GetSmartestSessionProfile.md>), [ListInstalledSmartestVersions](<02.09.01.10.03.02.01.06_ListInstalledSmartestVersions.md>), [ListSmartestSessionIDs](<02.09.01.10.03.02.01.07_ListSmartestSessionIDs.md>), [PingSmartestSessions](<02.09.01.10.03.02.01.08_PingSmartestSessions.md>), [GetApplicationProfile](<02.09.01.10.03.02.02.24_GetApplicationProfile.md>), [GetLastEvent](<02.09.01.10.03.02.02.25_GetLastEvent.md>), [GetLevelProfile](<02.09.01.10.03.02.02.26_GetLevelProfile.md>), [GetSmarTestExecStatus](<02.09.01.10.03.02.02.27_GetSmarTestExecStatus.md>), [GetControllerInfo](<02.09.01.10.03.02.03.01_GetControllerInfo.md>), [GetLoadboardInfo](<02.09.01.10.03.02.03.02_GetLoadboardInfo.md>), [GetInstrumentInfoById](<02.09.01.10.03.02.03.03_GetInstrumentInfoById.md>), [GetProbeCardInfo](<02.09.01.10.03.02.03.04_GetProbeCardInfo.md>), [GetTesterInfo](<02.09.01.10.03.02.03.05_GetTesterInfo.md>), [GetTestHeadInfoByID](<02.09.01.10.03.02.03.06_GetTestHeadInfoByID.md>), [GetTestBoardInfoByID](<02.09.01.10.03.02.03.07_GetTestBoardInfoByID.md>), [GetTestModuleInfobyID](<02.09.01.10.03.02.03.08_GetTestModuleInfobyID.md>), [GetCalStatus](<02.09.01.10.03.02.04.02_GetCalStatus.md>).

The prototype of [query](<02.09.01.10.03.01.10_query.md>) is defined as

```
xoc::hvmapi::Status query(
const std::string &qrName,
xoc::hvmapi::ParamList &qrResults,
const xoc::hvmapi::ParamList &qrParams=xoc::hvmapi::ParamList(),
const std::string &sessionId=std::string("") );
```

The session ID of SmarTest is required to execute some API. If you Do not know it, you can get the session ID with the API [GetOnlineSmartestSessionID](<02.09.01.10.03.02.01.04_GetOnlineSmartestSessionID.md>) or [ListSmartestSessionIDs](<02.09.01.10.03.02.01.07_ListSmartestSessionIDs.md>).

## Before you begin

Make sure you are using SmarTest 6.2 or later versions.

## Procedure

-  Prepare the parameters and session ID to be used by the API.

Each API has different parameters. You refer to the code template below.

```
ParamList qrResults, qrParams;  //define the variables
string sessionId = ":0"
qrParams["param1"] = "value_for_param1";  //set values for parameters
qrParams["param2"] = "value for param2";
```

-  Execute the query and output the result.

```
Status obj = query("API_to_execute", qrResults, qrParams, sessionId);
if( obj.success() )
{
  std::vector<std::string> varList = qrResults.valueArray("result1");
  std::vector<std::string> valueList = qrResults.valueArray("result2");

  for(int i=0; i<varList.size(); i++)
  {
    std::cout << varList.at(i) << " : " << valueList.at(i) << std::endl;
  }
}
```

## Results

The API is executed and outputs the results. An error object will be returned to indicate the execution status of the API.

## Example

The following example shows how to get a SmarTest session profile using the [query](<02.09.01.10.03.01.10_query.md>) signature.

```
ParamList qrResults;
string sessionId = "sessionId"; // the exact session ID such as ":13"
Status retVal = query("GetSmartestSessionProfile", qrResults, ParamList(), sessionId);
if(retVal.isSuccess())
{
  cout <<"SmarTest session " << sessionId <<" profile: "<<endl;
  cout <<"Revision: " << qrResults["VERSION"] << "."<< qrResults["PATCH_LEVEL"] <<endl;
  cout <<"Online_mode: " <<qrResults["ONLINE_MODE"] <<endl;
  cout <<"User_mode: " <<qrResults["USER_MODE"] <<endl;
  // ...
}
```
