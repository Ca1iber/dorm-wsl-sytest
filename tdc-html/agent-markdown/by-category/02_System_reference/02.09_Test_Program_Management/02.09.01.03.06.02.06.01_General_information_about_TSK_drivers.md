# General information about TSK drivers

This section provides general information about TSK prober drivers.

Restrictions

The maximum number of probes for multi-die probing is restricted to 32.

Sub-die probing is not supported.

Absolute die and chuck positioning by means of mills or microns is not supported.

Supported probers

The following TSK probers are supported:

- APM90A
- UF190, UF190A
- UF200, UF200D, UF200S, UF200FL
- UF300
- UF3000

The TSK probers are all in the generic configuration class. The TSK prober drivers can support up 0 to 999,999 bins.

 Note TSK probers support wafer cleaning in SmarTest 6.1.4 and later versions.
