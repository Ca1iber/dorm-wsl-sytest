# GetSiteInFocus

This routine is used for multisite testing. It lets you retrieve the number of the site currently in focus.

## Syntax

```
VOID GetSiteInFocus(
    INT32     *site_in_focus);
```

## Parameters

Note Another focus exists besides the query focus: the setup focus.

On return, site_in_focus specifies the number of the site that currently has the query focus.

## Example

```
INT32 focus_site;
GetSiteInFocus(&focus_site);
```

## Functional changes

- Introduced before SmarTest 6.3.2
