# Extended Popup Message

This function generates a message popup with maximum 24 buttons. The popup appears with two default buttons and the message in *msg. When any elements in the array of strings (bs array) are non-empty strings, additional buttons with Quit and Continue buttons also appear (see below).

long MsgDisplayMsgGetResponse2(char *msg, char **bs, long *response)

  ![Extended Popup Message](<../../../../raw/46502.png>)

The popup disappears when any button is pressed and the parameter *response is set to the button number selected as follows:

*response = 1; Quit

*response = 2; user button 2 (bs[0])

*response = 3; user button 3 (bs[1])

 : :

*response = 7; user button 7 (bs[5])

*response = 8; Continue

*response = 9; user button 9 (bs[6])

 : :

*response = 24; user button 24 (bs[21])

Button strings are restricted to a length of CI_MAX_BUTTON_STR_LEN2 = 16. The Message string is limited to a length of CI_MAX_MESSGE_STR_LEN = 512.

The button strings are given as a pointer to the array of strings (bs array). If you give the empty string "" or "\0" to an element of the bs array, the button corresponded to the element is not appeared. If you make 21 or less user buttons, you have to give a NULL pointer at the last element of the bs array. For example, if you want to make eight user buttons, the number of the array element is nine and the NULL pointer is given into the last element (bs[8]).

char *bs[9]={"user button2", "user button3",

 "user button4", "user button5",

 "user button6", "user button7",

 "user button9", "user button10",

 NULL};
