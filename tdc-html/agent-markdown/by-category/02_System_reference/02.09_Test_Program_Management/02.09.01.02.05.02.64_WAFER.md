# WAFER

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.64.01_Associated_Syntax_Entities.md>)

A keyword representing a level (like DEVICE), that has special features associated with it, namely,

- The screens that appear in this level have special buttons associated with them, such as reference (check with the reference wafer) or retest_w (retest the wafer).
- Its own set of identifiers, such as <header> and <level_name>. You might use this to give each device an ID number.
