# Input file access API

#### Subtopics

- [evalBLCInputFile()](<02.09.01.11.03.04.01_evalBLCInputFile.md>)

This API is used to validate and parse the BLC input file which is in a plain text format. It does not work for an input file with other formats.

For the description of a BLC input file, see [Batch/Lot Control](<02.09.01.11_Batch_Lot_Control.md>).

## Functional changes

- Introduced in SmarTest 6.5.0
