# Exit Status

The exit status of the program conveys the success or failure of the program execution, and must be set. For a full explanation of the available exit codes, see [Return Codes](<02.09.01.08.05.05_Return_Codes.md>). The following line shows an example:

exit(CI_CALL_PASS)
