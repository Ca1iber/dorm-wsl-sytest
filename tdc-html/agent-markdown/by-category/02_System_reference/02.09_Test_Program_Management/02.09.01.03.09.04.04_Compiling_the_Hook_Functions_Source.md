# Compiling the Hook Functions Source

After you have completed implementing the user-specific code in the ph_hhook.c file, or the ph_phook.c file, respectively, compile the file as follows:

- Change to the top directory of the plug-in you have written the hook function for.

 cd ... /GenericHandler/plug-in-name/

or

cd ... /GenericProber/plug-in-name/

For example, if you have worked on the ph_hhook.c file in the directory /home/user/mydriver/GenericHandler/Seiko-Epson-GPIO/hook/

change to /home/user/mydriver/GenericHandler/Seiko-Epson-GPIO/

- Then compile with the two commands

make depend

make

This generates the shared library libhook.sl in

... /GenericHandler/plug-in-name/lib/

or ... /GenericProber/plug-in-name/lib/ , respectively

 Note If you have made changes to the header file .../GenericHandler/include/ph_hhook.h, or .../GenericProber/include/ph_hhook.h, the complete handler driver or prober driver must be re-compiled, as described in [Compiling the Driver](<02.09.01.03.09.03.02_Compiling_the_Driver.md>), in order to make the changes active. This compilation will also create the new shared library libhook.sl.
