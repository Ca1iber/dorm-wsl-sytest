# Function: ph_interactive_configuration

Opens the configuration editor which allows you to change the settings of configuration parameters.

For details about this function see [Changing the Driver Configuration at Run-Time](<02.09.01.03.03.04_Changing_the_Driver_Configuration_at_Run-Time.md>).

Applicable for: handler and prober driver

Example: PROB_HND_CALL (ph_interactive_configuration)
