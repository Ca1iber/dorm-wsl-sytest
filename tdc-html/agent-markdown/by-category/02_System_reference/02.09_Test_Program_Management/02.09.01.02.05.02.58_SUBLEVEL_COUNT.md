# SUBLEVEL_COUNT

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.58.01_Associated_Syntax_Entities.md>)

This expression enables you to loop a lower (sub)level a particular number of times. For example, the following line in a cassette level,

{cassette:

 ACTIONS

SUBLEVEL_COUNTwafers_per_cassette=DIALOG_INPUT/REGEXP(int);

{wafer:

results in the wafer level being looped only as many times as there are wafers in the cassette - determined by the DIALOG_INPUT.
