# ListSmartestSessionIDs

This data query command lists all the session IDs of the running SmarTest sessions. The API can tell all visible sessions. Here the term "visible" means that any graphical window (like sa_splash, the report window, SmarTest Work Center, and so on) is visible to you. The visible SmarTest sessions cover three kinds of situations:

- The session is just launched from the shell console, some graphical window is already visible to you but it is not fully functional.
- The session is fully ready and functional (The event SMARTEST_SESSION_READY has been notified).
- The session is shutting down, but not completed. In another word, at the moment just before the very last window (like the report window) disappears, the SmarTest session is still regarded as "visible"

SUCCESS is always returned for the execution.
