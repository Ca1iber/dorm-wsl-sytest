# testprog

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.62.01_Associated_Syntax_Entities.md>)

The testprog keyword is used as an argument for [GET_TEST_INFO](<02.09.01.02.05.02.36_GET_TEST_INFO.md>) to return the name of the current test program.

The name is returned in the format <test_program_name> `on device`<device_full_path>. For example: program1 on device /home/demo/training_lab/74act299.

## Functional changes

- Introduced before SmarTest 6.3.2
