# Communication with a GPIO interface

#### Subtopics

- [Parallel interface timing](<02.09.01.03.01.01.01_Parallel_interface_timing.md>)
- [Bin data](<02.09.01.03.01.01.02_Bin_data.md>)

GPIO communication works over a parallel interface. The parallel interface is implemented using an optional GPIO card, which is plugged into a PCI slot of the workstation (see Supported System Controller and Changing the prober/handler configuration).

## Supported optional GPIO cards:

Z620 and Z640VM workstations: E7030C (with PCIexpress interface)

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.2.0: New workstation Z620
