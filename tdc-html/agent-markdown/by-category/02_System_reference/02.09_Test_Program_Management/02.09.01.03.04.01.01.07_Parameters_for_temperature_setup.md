# Parameters for temperature setup

These parameters should be checked if your equipment can be set up for temperature control:

- temp_...

If you suspect problems due to the temperature setup, you can deactivate these parameters by setting the parameter temp_control to manual.

It is also important to check the parameters specific to the interface, as described in the following sections.
