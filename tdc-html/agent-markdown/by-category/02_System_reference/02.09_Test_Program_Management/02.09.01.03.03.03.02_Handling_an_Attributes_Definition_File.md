# Handling an Attributes Definition File

#### Subtopics

- [Loading and Saving an Attributes Definition File](<02.09.01.03.03.03.02.01_Loading_and_Saving_an_Attributes_Definition_File.md>)
- [Changing an Attribute Definition](<02.09.01.03.03.03.02.02_Changing_an_Attribute_Definition.md>)

 Note The attributes definition is a sensitive part of the driver configuration. Wrong definitions can lead to unexpected driver behavior. Changes to an attributes definition must be done with care. It is recommended to consult your Advantest representative before making changes to attribute definitions.

Normally, the provided attributes definition files of a plug-in do not need to be changed. The definitions of valid configuration parameter settings in these files allow for all common settings of the parameters.

However, it may become necessary to change attribute definitions in order to enlarge or reduce the valid range of a parameter, for example, when testing a new configuration, or when equipment specifications have changed.

Everybody who has write access to an attributes definition file can edit that file with a text editor. Access permissions therefore must be set according to the data access policy and responsibilities on the production testfloor.
