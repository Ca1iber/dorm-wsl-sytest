# dpsCurrent_limit

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.30.01_Associated_Syntax_Entities.md>)

This expression is used in conjunction with MONITOR_CALL, and enables you to set a current limit on the tester's device power supply. To be of any real use, dpsCurrent_limit should also be used in conjunction with dpsCurrent_check (see above). The line,

MONITOR_CALL (dpsCurrent_limit, 0.9);

sets a limit of 0.9A for the DPS.

The range for the current limit is 0.0 to 1.0A.
