# Unpacking the Driver and Hook Sources

To obtain the hook function templates, the driver sources, and all make files for compilation, proceed as follows:

- Provide a directory for user-modified drivers, and change to that directory:

mkdir /home/user/mydriver

cd /home/user/mydriver

- Extract the source code of the handler/prober driver package. This will create the directory Generic*, and several subdirectories and Makefiles in mydriver/. Then change to the Generic* directory:

tar xvf /opt/hp93000/soc/PH_libs/Generic*/.hidden/source.tar

cd Generic*
