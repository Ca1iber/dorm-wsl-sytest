# Function: ph_wafer_done

This function assures that a fully tested wafer is unloaded by the prober.

Depending on the plug-in, the function may send a command to the prober to unload the wafer, or just ask the prober whether the wafer is already unloaded. Depending on the prober, a new wafer may already be loaded at this point of time.

ph_wafer_done is mandatory for wafer testing.

Applicable for: prober driver

Example: PROB_HND_CALL (ph_wafer_done)
