The program declaration of main must be defined as follows:

main(argc, argv)

char *argv[];

int argc;

The parameters are passed to the program through the argv array in the conventional Unix or C manner. The parameter count is available through int argc. Parameters are passed to the program exactly as written in the Command Set call and are available in the order specified (left to right).

The following line shows an example declaration:

argv[0] = init

argv[1] = one

argv[2] = two

argv[3] = three

To start a program in background mode, add an & to the last parameter of the Command Set call, as shown in the following example.

EXEC_INP_CALL(init one two three &);
