# User Flag

## get

IsUserFlagDefined checks whether the flag with the name *name is defined. It returns 0 when not defined, otherwise returns 1.

GetUserFlag retrieves the current value of the user defined flag named,*flag, and deposits it in long, pointed to by *value. The flag must have been declared as a userflag (= int).

GetUserFlagOfSite lets you specify which site should be used (1,2,...), while GetUserFlag assumes the site currently in focus (for example during sequential User Procedure execution). In case of single site test the first site is always in focus. Use a "string" constant to identify the flag required.

GetAllTestflowUserFlags retrieves the names and values of all the user flags and stores them in the relevant C structure.

```
int IsUserFlagDefined(char *name)
long  GetUserFlag(char *flag, long *value)
long  GetUserFlagOfSite(char *flag, long site, long *value)
long  GetAllTestflowUserFlags( CI_CPI_USER_FLAG_LIST *user_flag_list)
```

The values returned are as follows,

 |

0

 |

ok

 |
 |

1

 |

error on a name

 |
 |

-1

 |

internal error

   |  The following example code snippet shows how the function IsUserFlagDefined() is used to check if the `RDI_INFO_LEVEL` flag is defined in the testflow.

```
char testflag[] = "RDI_INFO_LEVEL";
int ok = IsUserFlagDefined(testflag);
```

The following example shows how the function `GetUserFlag()` is used,

```
void CiExample2(char  *parm_list_input,
  int    parmcount,
  char  *comment_out,
  int   *comlen,
  int   *state_out)
{
  /* A variable name is to be passed as parameter */

  long   type;
  long   flag_var;
  double double_var;
  char   str_var[CI_CPI_MAX_USER_STRING_LEN+1]
  *comment_out='\0';
  *comlen=0;

  if (GetUserType(param_list_input,&type))
     {
     Errorhandling("Cannot retrieve variable type.");
     *state_out=CI_TEST_FAIL;
     return;
     }

  switch(type)
    {
    case CI_CPI_DBL:
      {
        GetUserDouble(param_list_input,&double_var);
        fprintf(stderr,"Value of %s is %lf.\n",
                 param_list_input,double_var);
      }

    case CI_CPI_FLG:
      {
        GetUserFlag(param_list_input,&flag_var);
        fprintf(stderr,"Value of %s is %ld.\n",
                 param_list_input,flag_var);
      }

    case CI_CPI_STR:
      {
        GetUserString(param_list_input,str_var);
        fprintf(stderr,"Value of %s is \"%s\".\n",
                 param_list_input,str_var);
      }

    }
  *state_out = CI_CALL_PASS;
}

```

The next example shows how the function `GetAllTestflowUserFlags()` is used.

```
CI_CPI_USER_FLAG_LIST user_flag_list;
CI_CPI_USER_FLAG *pFlag;
int i = 0;
If (GetAllTestflowUserFlags(&user_flag_list)==0 )
{
  for (i=0; i< user_flag_list.number_of_user_flag; i++)
  {
    pFlag = & user_flag_list.user_flags[i];
    printf("the user flag name is %s\n", pFlag->name);
  }
}
```

## set

SetUserFlag sets the value of the user defined flag *flag with the value value. The flag specified must have been declared as a userflag. Flags are actually declared as ints, but are defined as longs within this function.

SetUserFlagOfSite lets you specify which site should be used (1,2,...), while SetUserFlag assumes the site currently in focus (for example during sequential User Procedure execution). In case of single site test the first site is always in focus.

Use a "string" constant to identify the flag required.
