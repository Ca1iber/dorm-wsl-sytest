# Parameter: temp_upper_guard_band

Insert the list of upper guard band limits. Devices will not be tested as long as the current device temperature is higher than the value set with temp_setpoint + (plus) temp_upper_guard_band. If temp_upper_guard_band is not configured, the upper guard band limit will not be set. If set to 0, the upper guard band will be deactivated if possible with the equipment. Thus, in this case there would be no upper temperature limit. Otherwise, for some equipment, setting the upper guard band to 0 would cause the equipment to try to hit the temperature setpoint.

temp_upper_guard_band will only be active, if temperature_control is set to "active" mode. The number of entries in the list must either match the number of entries of temp_chambers or one single value may be inserted. In case you insert one single value only, the upper guard band temperature limits of all chambers will be set to this single value.

The unit of the values is defined with temp_conf_unit.

 Note Firstly, the temperature values entered here are relative values while the values entered as for example in temp_setpoint are absolute values. Secondly, the entered values have to be positive.

Driver default: empty list

Changeable at run-time: yes

Applicable for: handlers and probers, plug-in dependent

Example 1: temp_upper_guard_band: [3.5 5.5]

Example 2: temp_upper_guard_band: 2.5
