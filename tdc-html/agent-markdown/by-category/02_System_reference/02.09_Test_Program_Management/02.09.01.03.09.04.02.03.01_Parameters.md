# Parameters:

- phFrameAction_t call

the identifier of the driver function called by the PROB_HND_CALL from the application model, for example, PHFRAME_ACT_DEV_START for the function ph_device_start.

In the switch(call) section, the function contains the code to be executed for the different driver functions called by the PROB_HND_CALL.

There are identifiers for all driver functions which can be called from the application model. The identifiers are defined in the header file phFrame.h in the directory ... /GenericHandler/include/ and in ... /GenericProber/include

- phEventResult_t *result

see [Common Components of All Hook Functions](<02.09.01.03.09.04.02.01_Common_Components_of_All_Hook_Functions.md>).

- char *parm_list_input

the driver function parameters passed over from the PROB_HND_CALL of the application model.

- int parmcount

the number of parameters passed over.

- char *comment_out

the comment to be send back to the application model. Only required if the return value of the parameter result is PHEVENT_RES_ABORT. Otherwise, the comment will be ignored.

- int *comlen

the length of the comment

- phTcomUserReturn_t *stReturn

see [Common Components of All Hook Functions](<02.09.01.03.09.04.02.01_Common_Components_of_All_Hook_Functions.md>).
