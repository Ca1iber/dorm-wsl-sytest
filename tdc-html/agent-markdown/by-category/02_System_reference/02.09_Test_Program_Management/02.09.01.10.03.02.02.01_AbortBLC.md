# AbortBLC

This command aborts the execution of a [Batch/Lot Control](<02.09.01.11_Batch_Lot_Control.md>) client. The BLC program must be designed to be able to react to the ABORT operation. Otherwise, this API will take no effect.

SUCCESS will returned if no error occurred. Otherwise, an error object will returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- There is no BLC being executed.
 |

RECOVERABLE

 |

## Dependency

The BLC is in execution and it could react to the ABORT operation.
