# Parameter: probe_cleaning_softbins

If the prober supports probe needle cleaning, an automatic cleaning may be performed every time a tested die was binned into one bin of a set of given software bins.

This way, probe needle cleaning can be controlled based on the actual test result.

The parameter defines a list of SmarTest software bins. If a die gets binned to one of these bins, an automatic probe needle cleaning will be carried out. If the parameter is set to empty list, or if it is not defined at all, no software bin based probe needle cleaning will be performed.

If the bin is defined as a reprobe bin in the SmarTest testflow, the die (or die group in case of multisite probing) will be probed again after the cleaning has been done.

 Note Probe needle cleaning based on software bins cannot be combined with cleaning based on hardware bins (see the parameter probe_cleaning_hardbins), but it may be combined with per die or per wafer probe needle cleaning (see the parameters per_die_probe_cleaning_rate and per_wafer_probe_cleaning_rate).

Driver default: empty list

Changeable at run-time: yes

Applicable for: prober

Example: probe_cleaning_softbins: [7 8]
