# Parameter: model

The name of the specific equipment model within the family, as accepted by the plug-in.

Driver default: none; value must be defined in the driver configuration

Changeable at run-time: no

Applicable for: handlers and probers

Example: model: "HM3500" (Seiko/Epson handler model)

 "P8" (TEL prober model)
