# Starting the Test Cell Control Tool

You can start the Test Cell Control Tool(TCCT) in the engineering mode or the production mode.

## About this task

Starting TCCT in the engineering mode means starting the tool without any setup information.

Starting TCCT in the production mode means starting the SmarTest, and then starting TCCT and loading the selected recipe file.

## Before you begin

Make sure the Test Cell Control Tool is successfully installed.

## Procedures

### Starting TCCT in the engineering mode

- Enter the following command in a shell:

/opt/hp93000/tcct/bin/tcct

TCCT will be started and attach to the running SmarTest session automatically.

  - If no SmarTest session is running, it will attach to the SmarTest session when you start SmarTest.
  - If there is an online SmarTest session, it will attach to the online session.
  - If there is no online session, it will attach to a running offline SmarTest session. If there are multiple offline SmarTest sessions running, a dialog box will be displayed asking you to select the session to work with. Select the session to use and click OK.

To load a recipe file when starting TCCT, enter the command like below:

```
/opt/hp93000/tcct/bin/tcct -r recipe1.xml
```

or

- From the main menu (Red Hat button on the task bar), click Red Hat button and select Advantest > Test Cell Control Tool.

### Starting TCCT in the production mode

- (optional)Switch to the root user (in a shell type su -).
- (optional)Edit the file /etc/opt/hp93000/tcct/production_environment_config.xml to set the environment variables.

You can set the SmarTest startup mode, the user mode, the model file and the directory of the recipe file to use.

The environment variable TCCT_RECIPE_FILE_LOCATION is also provided to specify the directory of the recipe files. You can use it in a shell as below and then start TCCT from command line.

`export TCCT_RECIPE_FILE_LOCATION=/home/demo/my_recipes`

- Start TCCT in the production mode:

  - Enter the following command in a shell:

`/opt/hp93000/tcct/bin/tcct.prod`

or

  - In the main menu, click Red Hat button and select Advantest > Test Cell Control Tool (production).

The Recipe File Selection dialog box will be displayed.

- In the dialog, choose the recipe file to use and click OK.

## Results

In the engineering mode, TCCT is started.

In the production mode, a SmarTest session is started. And TCCT is started with the selected recipe file loaded.

## Functional changes

- Introduced in SmarTest 7.2.0
- SmarTest 7.2.0: In patch 2, supports starting TCCT in production mode in TCCT 1.1
- SmarTest 7.2.2: Added the environment variable TCCT_RECIPE_FILE_LOCATION in TCCT 1.4.
