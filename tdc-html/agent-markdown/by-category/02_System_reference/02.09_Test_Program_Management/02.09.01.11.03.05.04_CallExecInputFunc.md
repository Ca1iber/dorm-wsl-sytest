# CallExecInputFunc()

This API executes an execution input function after the shared library is loaded. The `ACTION_EXEC_INPUT_CALL_STARTED` and `ACTION_EXEC_INPUT_CALL_COMPLETED` HVM events will be generated by this API if the implicit event generation is turned on.

SUCCESS will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

## Prototype

```
ParamList inputParams, outputResults;
Status syncOperation("CallExecInputFunc", outputRestuls,
                  inputParams, sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams, outputResults;
inputParams["FUNCTION_NAME"] = "eiinit";

Status retVal = syncOperation("CallExecInputFunc", outputResults, inputParams, sid);
if ( retVal.isError() )
{
cout<<"error code= " << retVal.code() << " description="
   << retVal.text() << endl;
}
```
