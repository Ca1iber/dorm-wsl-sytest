# TestsuiteProxy.setSiteMatch()

This function sets the site match value. If it is successfully executed, true will be returned. Otherwise, false will be returned.

## Syntax

```
bool setSiteMatch(const SiteMatchValue value);
```

Parameters
 |

value

 |

The site match value. It can be one of the options of SiteMatchValue enumeration defined below:

`enum SiteMatchValue`

`{`

`SITEMATCH_OFF = 0,`

`SITEMATCH_ON,`

`SITEMATCH_AUTO,`

`SITEMATCH_UNDEFINED`

`};`

 |

## Functional changes

- Introduced in SmarTest 6.5.2
