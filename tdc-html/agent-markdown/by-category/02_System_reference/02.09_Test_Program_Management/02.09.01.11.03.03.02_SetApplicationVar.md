# SetApplicationVar()

This API saves the value of a variable to the level model shared memory.

- If the variable does not exist in the shared memory,

  - If there are active level, then a new variable will be created for the current active level
  - If there's no active level currently, then a new level will be created and the new level will be set active and the variable will be added to the this new level.

-  If the variable exists in the shared memory already, the value of the variable will be updated.

This API also sends the HVM Assignment event and EDL Assignment event if the implicit event generation is turned on.

SUCCESS is returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

## Prototype

```
ParamList inputParams;
Status syncCommand("SetApplicationVar", inputParams, sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams;
inputParams["VARIABLE_NAME"] = "operator_id";
inputParams["VARIABLE_VALUE"] = "operator123";

Status retVal = syncCommand("SetApplicationVar", inputParams, sid);
if ( retVal.isError() )
{
cout<<"error code= " << retVal.code() << " description="
   << retVal.text() << endl;
}
```
