# Parameter: device_test_delay_time

In case the handler has a misalignment between its device plungers and sending the test start signal, the device test may fail if started too early. In this case, this parameter may be used to artificially delay the device test start of SmarTest after receiving all test start signals from the handler. The time is given in milliseconds. This delay time is specific to the handler and provided by the handler vendor.

Driver default: depends on plug-in

Changeable at run-time: yes

Applicable for: handlers

Example: device_test_delay_time: 0
