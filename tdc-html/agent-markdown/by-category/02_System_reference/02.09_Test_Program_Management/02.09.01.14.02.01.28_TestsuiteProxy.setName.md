# TestsuiteProxy.setName()

This function sets a name to the test suite. If it is successfully executed, true will be returned. Otherwise, false will be returned.

## Syntax

```
bool setName(const std::string& name);
```

Parameters
 |

name

 |

The test suite name.

 |

## Functional changes

- Introduced in SmarTest 6.5.2
