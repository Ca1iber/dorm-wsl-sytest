# GetLastEvent

This data query command gets the last event of the specified category for the specified SmarTest session. If no event category is specified, the latest event independent of its category will be returned.

SUCCESS will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

The designated session ID "XXX" does not exist.

 |

RECOVERABLE

 |

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The ID of the SmarTest session this event belongs to.

 |
 |

I

 |

EVENT_NAME

 |

The HVM event category. It can be `SESSION`, `EXECUTION`, `CALIBRATION`, `DIAGNOSTIC` or `ALARM.`

 |
 |

O

 |

qrResults

 |

The query results are represented by a ParamList object. It contains the following members:

- EVENT_NAME: The HVM event category. It can be `SESSION`, `EXECUTION`, `CALIBRATION`, `DIAGNOSTIC` or `ALARM`.
- TIME_STAMP_SEC: The second of time stamp when this event happens.
- TIME_STAMP_USEC: The microsecond of time stamp when this event happens.
- EVENT_BODY: The event parameters, including all other data of this event besides event name and time stamp.
 |

## Prototype

```
ParamList qrResults;
Status query("GetLastEvent", qrResults, ParamList(),sessionId);
```

## Example

```
ParamList qrResults, qrParams;
string sessionId = "session_rbzf";
Status obj;
//1) Get last alarm event:
qrParams["EVENT_NAME"] = "ALARM";
obj = query("GetLastEvent", qrResults, qrParams, sessionId);
if( obj.isSuccess() )
{
  printf("Last alarm of SmarTest: \n");
  printf("Alarm type: %s\n", qrResults["EVENT_NAME"]);
  printf("Alarm time stamp(sec): %s\n", qrResults["TIME_STAMP_SEC"]);
  printf("Alarm time stamp(usec): %s\n", qrResults["TIME_STAMP_USEC"]);
  printf("Alarm severity: %s\n", qrResults["ALARM_SEVERITY"]);
  printf("Alarm code: %s\n", qrResults["ALARM_CODE"]);
  printf("Alarm description: %s\n", qrResults["ALARM_TEXT"]);
}
else {
  //error handling
}
//2) Get last execution event with API
qrParams["EVENT_NAME"] = "EXECUTION";
obj = query("GetLastEvent", qrResults, qrParams, sessionId);
if(obj.isSuccess())
{
  printf("Last execution event of SmarTest: \n");
  printf("Execution type: %s\n", qrResults["EVENT_NAME"]);
  printf("Execution time stamp(sec): %s\n", qrResults["TIME_STAMP_SEC"]);
  printf("Execution time stamp(usec): %s\n", qrResults["TIME_STAMP_USEC"]);
  printf("Event state: %s\n", qrResults["EXECUTION_STATE"]);
  if(qrResults[EXECUTION_STATE] == "DEVICE_CHANGE_COMPLETED")
  {
    printf("device path: %s\n", qrResults["DEVICE_PATH"]);
    printf("device name: %s\n", qrResults["DEVICE_NAME"]);
  }
}
//3) Get last event independent of type
obj=query("GetLastEvent", qrResults, ParamList(), sessionId);
if(obj.isSuccess())
{
  printf("Last event of SmarTest: \n");
  printf("Event type: %s\n", qrResults["EVENT_NAME"]);
  printf("Event time stamp(sec): %s\n", qrResults["TIME_STAMP_SEC"]);
  printf("Event time stamp(usec): %s\n", qrResults["TIME_STAMP_USEC"]);
  string lastEventType = qrResults["EVENT_NAME"];
  string lastEventName;
  if(lastEventType == "SESSION")
  {
    lastEventName = qrResults["SESSION_STATE"];
  }
  else if(lastEventType == "EXECUTION")
 {
    lastEventName = qrResults["EXECUTION_STATE"];
  }
 printf("    Last event is: %s\n", lastEventName);
}
else{
  //error handling
}
```
