# ACTIONS

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.01.01_Associated_Syntax_Entities.md>)

This is one of the key expressions of a <level_section> and is central to the application model. It signals the beginning of one or more particular action in a level. It is of the form,

ACTIONS [<action_parameter>]+

where the <action_parameter> comprises,

["*"] [ [ <parameter_type> ] <name> "=" <action> ["/" <format_spec> ] ";"

It is to be used whenever you want to perform an action (defined by you) within one of the levels of your application model. For example,

ACTIONS

 PROB_HND_CALL (ph_driver_start);

sends the call ph_driver_start to your wafer prober or package handler.

Alternatively,

ACTIONS

*PH_init_result=PROB_HND_CALL(ph_driver_start);

does the same thing, but puts the return of this call into the variable PH_init_result, and is logged.
