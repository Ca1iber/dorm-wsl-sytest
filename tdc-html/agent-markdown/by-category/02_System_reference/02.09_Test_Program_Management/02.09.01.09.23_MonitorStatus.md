# MonitorStatus

This routine allows you to read the Monitor status from a test flow program. You can obtain the global test system operation state and read out the status register, which holds the current status of each monitored item. The MonitorState routine provides a subset of the capabilities available by the Monitor in the interactive environment.

## Syntax

```
VOID MonitorStatus(
    UINT16    *TstrOpState_p,
    UINT16    *StatusReg_p);
```
