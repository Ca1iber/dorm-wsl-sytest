# ExecMonitor

This routine allows you to program the Monitor from a test flow program. The settings you make control the Monitor behavior or execute specific Monitor functions. The ExecMonitor routine provides a subset of Monitor capabilities available in the interactive environment.

## Syntax

```
VOID ExecMonitor(
 UINT16  FuncType,
 CHAR *Parameter,
 INT32 *ExecReturn);
```

## Example

```
INT32 ExecReturn;

ExecMonitor(TM_RESET_STATUS,"",&ExecReturn);
ExecMonitor(TM_CONTROL_MONITOR,"CalAge;enable;\
           1;day(s);4.0;month(s)", &ExecReturn);
ExecMonitor(TM_CONTROL_MONITOR,"BoardTempr;enable;\
 2.0;-2.0;C",&ExecReturn);
ExecMonitor(TM_CONTROL_MONITOR,"DpsCurrent; \
            enable;10.0;second(s);0.8;A;\
            lock_enable",&ExecReturn);
```
