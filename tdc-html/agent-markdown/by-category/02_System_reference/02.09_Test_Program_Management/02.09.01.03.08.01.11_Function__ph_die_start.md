# Function: ph_die_start

This function tells the prober to contact the next dies with the probes, and waits either until the prober notifies that the contact is established, or until a waiting-for-parts-timeout occurs (see [Parameter: waiting_for_parts_timeout](<02.09.01.03.05.04.08_Parameter__waiting_for_parts_timeout.md>)).

ph_die_start is mandatory for wafer testing.

Applicable for: prober driver

Example: PROB_HND_CALL (ph_die_start)
