# GetControllerInfo

This data query command gets the information of the controller workstation. SUCCESS is always returned by the execution of this command.

Parameters
 |

I/O

 |

Parameters

 |

Description

 |
 |

O

 |

qrResults

 |

The query results are represented by a ParamList object. It contains the following members:

OS_RELEASE: The release information of Linux operation system installed in the controller workstation.

OS_KERNEL: The Linux kernel information.

HOSTNAME: The host name of the controller workstation.

 |

Prototype

```
ParamList qrResults;
Status query("GetControllerInfo", qrResults);
```
