# Terminology

The terms asynchronous command, synchronous command and signature used to describe HVM API are described below.

## Asynchronous command

The command call is returned immediately and the caller is not blocked. An asynchronous event is required to notify the result of command execution.

The command with long execution time is usually asynchronous command.

## Synchronous command

The caller is blocked and the result is available after the command's execution. It is usually used to retrieve the information and data from SmarTest or hardware.

## Signature

The signature of a function is roughly equivalent to its prototype definition in the C programming language. It contains the name of the function as well as its parameters and their type. This also includes the return value.

## HVM event category

The HVM event category is called event name in the HVM API. It includes SESSION, EXECUTION, CALIBRATION, DIAGNOSTIC and ALARM.
