# SetPackageID()

This API sets the package ID into the shared memory so that the package ID can be recorded in the EDL log for GDF.

 Note The package ID is not used in STDF logs. In STDF, devices are identified by setting SITE<N>_PART_ID system variables, as described in [The PART_ID field in the PRR](<../02.10_Data_Logging/02.10.03.03.08_The_PART_ID_field_in_the_PRR.md>)., using the [SetApplicationVar()](<02.09.01.11.03.03.02_SetApplicationVar.md>) function.

SUCCESS will be returned if no error occurs. Otherwise an error object will be returned indicating the error code, description and severity.

PACKAGE_ID

 |

The digit for `x` in the format `x.y`. If it is set to `2` and there are 4 sites configured, the package ID for each site is: `2.1`, `2.2`, `2.3` and `2.4`.

 |

## Prototype

```
ParamList inputParams;
Status syncCommand("SetPackageID", inputParams, sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams;
inputParams["PACKAGE_ID"] = "2";

Status retVal = syncCommand("SetPackageID", inputParams, sid);
if ( retVal.isError() )
{
cout<<"error code= " << retVal.code() << " description="
    << retVal.text() << endl;
}
```
