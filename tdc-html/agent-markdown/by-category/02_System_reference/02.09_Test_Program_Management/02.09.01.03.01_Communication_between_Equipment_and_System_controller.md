# Communication between Equipment and System controller

#### Subtopics

- [Communication with a GPIO interface](<02.09.01.03.01.01_Communication_with_a_GPIO_interface.md>)
- [Communication with a GPIB interface](<02.09.01.03.01.02_Communication_with_a_GPIB_interface.md>)

Advantest supports various interfaces between the equipment and system controller. GPIO and GPIB and LAN (TCP/IP) interfaces are currently supported.

## Functional changes

- Introduced in SmarTest 7.0.4
- SmarTest 7.2.3: LAN supported
