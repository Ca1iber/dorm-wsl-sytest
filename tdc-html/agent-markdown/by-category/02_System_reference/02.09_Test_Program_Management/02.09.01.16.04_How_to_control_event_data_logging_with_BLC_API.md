# How to control event data logging with BLC API

In the application model, the event data logging is controlled by the level structure. The event stream containing the generated events can be handled by the STDF data formatter.

## About this task

In BLC client, to control the event data logging you need to maintain the level structure manually. You can maintain the level structure by generating events explicitly with [issueEDLEvent](<02.09.01.10.03.02.02.29_IssueEDLEvent.md>) API or by generating events implicitly with [StartLevel](<02.09.01.11.03.02.01_StartLevel.md>), [LoopLevel](<02.09.01.11.03.02.02_LoopLevel.md>) and [CompleteLevel](<02.09.01.11.03.02.03_CompleteLevel.md>). The event stream containing the generated events can be handled by the STDF data formatter.

Event data logging is enabled when the system flag log_events_enable is set to on. For the concepts of event data logging, refer to [Event Data Logging Concepts](<../02.10_Data_Logging/02.10.01.01_Event_Data_Logging_Concepts.md>).

## Before you begin

Make sure you are using SmarTest 6.5.0 or later versions.

## Procedures

### Control event data logging by generating the events explicitly

- Maintain the level structure manually by issuing events for each level. The example code below issues the EDL event for lot level start. For the lot level,

```
ParamList inputParam;
Status retVal;
inputParam.clear();
inputParam["EVENT_TYPE"] = "ApplModelLevelStartEventType";
inputParam["LEVEL_TYPE"] = "CUSTOM_LEVEL";
inputParam["LEVEL_NAME"] = "lot";
retVal = syncCommand("IssueEDLEvent", inputParam, LOCAL_SESSION_ID);
```

- Set values for the variables defined in STDF data formatter with [setApplicationVar](<02.09.01.11.03.03.02_SetApplicationVar.md>). (Refer to [Application model variables used for STDF generation](<../02.10_Data_Logging/02.10.03.05.33_Application_model_variables_used_for_STDF_generation.md>).) The same variable name must be used. The example code below sets the value for the variable STDF_FILE defined in the STDF data formatter.

```
ParamList inputParam;
Status retVal;
inputParam["VARIABLE_NAME"] = "STDF_FILE";
inputParam["VARIABLE_VALUE"] = "/home/demo/stdf/my_stdf_file";
retVal = syncCommand("SetApplicationVar", inputParam, LOCAL_SESSION_ID);
```

- Save the event data log stream to a file with MoveEDLStream as the example code below:

```
string sid = LOCAL_SESSION_ID;
ParamList inputParams;
inputParams["DEST_EDL_FILE"] = "/tmp/new_datalog_file.log";
Status retVal = syncCommand("MoveEDLStream", inputParams, sid);
if ( retVal.isError() )
{
cout<<"error code= " << retVal.code() << " description=" << retVal.text() << endl;
}
```

### Control event data logging by generating the events implicitly

- Enable the implicit event generation with SetBLCProfile API as below:

```
string sid = LOCAL_SESSION_ID;
ParamList inputParams;
inputParams["TEST_TYPE"] = "WAFER_SORT";
inputParams["ENABLE_IMPLICIT_EVENT"] = "TRUE";
Status retVal = syncCommand("SetBLCProfile", inputParams, sid);
if ( retVal.isError() )
{
cout<<"error code= " << retVal.code() << " description="
   << retVal.text() << endl;
}
```

- Maintain the level structure with the StartLevel, LoopLevel and CompleteLevel API. The following example code starts a package level.

```
ParamList inputParam;
Status retVal;
inputParam["LEVEL_TYPE"] = "DEVICE_LEVEL";
inputParam["LEVEL_NAME"] = "package";
retVal = syncCommand("StartLevel", inputParam, LOCAL_SESSION)
```

- Set the value for the variables defined in STDF data formatter with setApplicationVar(). (Refer to [Application model variables used for STDF generation](<../02.10_Data_Logging/02.10.03.05.33_Application_model_variables_used_for_STDF_generation.md>).) The same variable name must be used. The following example code sets the value for the variable STDF_FILE defined in the STDF data formatter.

```
ParamList inputParam;
inputParam["VARIABLE_NAME"] = "STDF_FILE";
inputParam["VARIABLE_VALUE"] = "/home/demo/stdf/my_stdf_file";
retVal = syncCommand("SetApplicationVar", inputParam, LOCAL_SESSION_ID);
```

- Save the event data log stream to a file with MoveEDLStream as the example code below:

```
* Description: Clear and reset the BLC execution environment.

/**
* Function: processStatus()
*
* Description: process the return status of each API call
* this function is called after the completion
* of each API

inline void processStatus(Status &s)
{
if(s.isError())
{
cout<<"****************ERROR**************\n"
<<"Code:\"" <<s.code() << "\"\n"
<<"Text:\"" <<s.text() << "\"\n"
<<"***********************************"<<endl;

exit(1);
}

/**
* Function: checkPauseState()
*
* Description: check and respond to the SmarTest PAUSE state
**/
inline void checkPauseState()
{
ParamList inputParam, outputParam;
Status retVal;

retVal = query("IsPaused", outputParam, inputParam, LOCAL_SESSION_ID);
processStatus(retVal);
if(outputParam["IS_PAUSED"] == "TRUE")
{
//Issue the TESTPROGRAM_EXEC_PAUSED HVM event
inputParam.clear();
inputParam["EXECUTION_STATE"] = "TESTPROGRAM_EXEC_PAUSED";
inputParam["TESTPROGRAM_NAME"] = "BLC";
retVal = syncCommand("IssueHVMExecutionEvent", inputParam, LOCAL_SESSION_ID);
processStatus(retVal);

//Call the ph_pause_start PH driver function
inputParam.clear();
inputParam["FUNCTION_NAME"] = "ph_pause_start";
retVal = syncOperation("CallPHDriverFunc", outputParam, inputParam, LOCAL_SESSION_ID);
processStatus(retVal);

while(true)
{
//Enter a infinite loop until the PAUSE state is cleared
outputParam.clear();
retVal = query("IsPaused", outputParam, inputParam, LOCAL_SESSION_ID);
processStatus(retVal);
if(outputParam["IS_PAUSED"] == "FALSE") break;
}

//Call the ph_pause_done PH driver function
inputParam.clear();
inputParam["FUNCTION_NAME"] = "ph_pause_done";
retVal = syncOperation("CallPHDriverFunc", outputParam, inputParam, LOCAL_SESSION_ID);
processStatus(retVal);

//Issue the TESTPROGRAM_EXEC_RESUMED event
inputParam.clear();
inputParam["TESTPROGRAM_NAME"] = "BLC";
inputParam["EXECUTION_STATE"] = "TESTPROGRAM_EXEC_RESUMED";
retVal = syncCommand("IssueHVMExecutionEvent", inputParam, LOCAL_SESSION_ID);
processStatus(retVal);
}
}

/**
**Function:packageTest()
**
**Description:do the package test
**/
inline void packageTest(string lotID)
{
ParamList inputParam, outputParam;
Status retVal;

//Issue the device level start EDL event for STDF logging purpose
issueEDLforPackage("ApplModelLevelStartEventType");

/*********************
* Start the package *
*********************/
while(true)
{
//Issue the device level loop EDL event for STDF logging purpose
issueEDLforPackage("ApplModelLevelLoopEventType");

//Call the ph_device_start PH driver function
callAPhDriverFunc("ph_device_start");

//check if the operator interrupts the BLC execution
if(checkAbortState())
{
//leave the package loop
break;
}

//Query if the level_end index is set by the driver
outputParam.clear();
retVal = query("IsDeviceDone", outputParam, ParamList(), LOCAL_SESSION_ID);
processStatus(retVal);
//If all devices are finished, break the loop
if(outputParam["IS_DEVICE_DONE"] == "TRUE") break;

//update the header and subheader of the result display window
static int packageNum = 1;
char sPackageNum[10] = "";
sprintf(sPackageNum, "%d", packageNum);
inputParam.clear();
inputParam["HEADER"] = "PACKAGE TEST";
inputParam["SUBHEADER"] = string("PACKAGE#") + sPackageNum;
retVal = syncCommand("UpdateResultDisplay", inputParam, LOCAL_SESSION_ID);
processStatus(retVal);

//Set the package ID to something like 1.1, 1.2 etc.
inputParam.clear();
inputParam["PACKAGE_ID"] = sPackageNum;
retVal = syncCommand("SetPackageID", inputParam, LOCAL_SESSION_ID);
processStatus(retVal);
packageNum++;

//Get the site setup information in order to issue the PACKAGE_STARTED/PACKAGE_COMPLETED HVM events
outputParam.clear();
retVal = query("GetSiteSetup", outputParam, ParamList(), LOCAL_SESSION_ID);
string siteID = outputParam["SITE_ID_FOR_SITES"];
string siteSetup = outputParam["SITE_SETUP_FOR_SITES"];
string packageID = outputParam["PACKAGE_ID_FOR_SITES"];
processStatus(retVal);

//Issue the PACKAGE_STARTED HVM event

issueHVMforPackage("PACKAGE_STARTED",lotID,siteID,siteSetup,packageID);

/************************
* Execute the testflow *
************************/

//check if the operator interrupts the BLC execution
if(checkAbortState())
{
//leave the package loop before the testflow execution
break;
}

inputParam.clear();
retVal = syncCommand("ExecTestflowSync", inputParam, LOCAL_SESSION_ID);
processStatus(retVal);

//Check if the operator pauses the BLC execution
checkPauseState();

//Call the ph_device_done PH driver function
callAPhDriverFunc("ph_device_done");

//Issue the PACKAGE_COMPLETED HVM event
issueHVMforPackage("PACKAGE_COMPLETED",lotID,siteID,siteSetup,packageID);

}

}

/**
```
```
**Function:packageTest()
**
**Description:do the package test
**/

inline void packageTest(string lotID)
{
ParamList inputParam,outputParam;
Status retVal;

startALevel("DEVICE_LEVEL","package");

while(true)
{//Enter the package level loop
loopALevel();

//Call the ph_device_start PH driver function
callAPhDriverFunc("ph_device_start");

//check if the operator interrupts the BLC execution
if(checkAbortState())
{
//leave the current level
break;
}

//Query if the level_end index is set by the driver
outputParam.clear();
retVal = query("IsDeviceDone", outputParam, ParamList(), LOCAL_SESSION_ID);
processStatus(retVal);
//If all devices are finished, break the loop
if(outputParam["IS_DEVICE_DONE"] == "TRUE") break;

//update the header and subheader of the result display window
static int packageNum = 1;
char sPackageNum[10] = "";
sprintf(sPackageNum, "%d", packageNum);
inputParam.clear();
inputParam["HEADER"] = "PACKAGE TEST";
inputParam["SUBHEADER"] = string("PACKAGE#") + sPackageNum;
retVal = syncCommand("UpdateResultDisplay", inputParam, LOCAL_SESSION_ID);
processStatus(retVal);

//Set the package ID to something like 1.1, 1.2 etc.
inputParam.clear();
inputParam["PACKAGE_ID"] = sPackageNum;
retVal = syncCommand("SetPackageID", inputParam, LOCAL_SESSION_ID);
processStatus(retVal);
packageNum++;

//Get the site setup information in order to issue the DIE_STARTED/DIE_COMPLETED HVM events
outputParam.clear();
retVal = query("GetSiteSetup", outputParam, ParamList(), LOCAL_SESSION_ID);
string siteID = outputParam["SITE_ID_FOR_SITES"];
string siteSetup = outputParam["SITE_SETUP_FOR_SITES"];
string packageID = outputParam["PACKAGE_ID_FOR_SITES"];
processStatus(retVal);

//Issue the PACKAGE_STARTED HVM event
issueHVMforPackage("PACKAGE_STARTED",lotID,siteID,siteSetup,packageID);

/************************
* Execute the testflow *
************************/

//check if the operator interrupts the BLC execution
if(checkAbortState())
{
//leave the current level before the testflow execution
break;
}

inputParam.clear();
retVal = syncCommand("ExecTestflowSync", inputParam, LOCAL_SESSION_ID);
processStatus(retVal);

//Check if the operator pauses the BLC execution
checkPauseState();

//Call the ph_device_done PH driver function
callAPhDriverFunc("ph_device_done");

//Issue the PACKAGE_COMPLETED HVM event
issueHVMforPackage("PACKAGE_COMPLETED",lotID,siteID,siteSetup,packageID);;
} //end of package level loop

}

/**
* Function: main()
*
* Description: the main function
**/

int main(int argc, char* argv[])
{
ParamList inputParam, outputParam;
Status retVal;
string testflow,phLib,phConfig,eiLib,dbLib;

/**********************
* Initialize the BLC *
**********************/
initializeBLC(argc);

/**********************
* parse the input file*
**********************/
parseInputFile(argv[1],phLib,phConfig,testflow,eiLib,dbLib);

/**********************
* Load all the setups*
**********************/

loadSetups(testflow,phLib,phConfig,eiLib,dbLib);

/****************************
* Start the superlot level *
****************************/
startALevel("CUSTOM_LEVEL","superlot");

//Add new variables
addVariables();

//Call the ph_driver_start PH driver function
callAPhDriverFunc("ph_driver_start");

//the top level can only be executed once

{ //enter the superlot level loop
loopALevel();

/***********************
* Start the lot level *
***********************/
startALevel("CUSTOM_LEVEL","lot");

for(int lotNum=1; lotNum<=1; lotNum++)
{ //enter the lot level loop

processStatus(retVal);
string lotID = outputParam["OUTPUT_STRING"];

if(checkAbortState())
{
//leave the current level
break;
}

//Issue the LOT_STARTED HVM event
issueHVMforLot("LOT_STARTED",lotID);

/***************************
* Start the package level *
***************************/
packageTest(lotID);

* complete the package level *
******************************/

//Issue the LOT_COMPLETED HVM event
issueHVMforLot("LOT_COMPLETED",lotID);

string sid = LOCAL_SESSION_ID;
inputParam.clear();
inputParam["DEST_EDL_FILE"] = "/tmp/new_datalog_file.log";
retVal = syncCommand("MoveEDLStream", inputParam, sid);
if ( retVal.isError() )
{
  cout<<"error code= " << retVal.code() << " description=" << retVal.text() << endl;
}

} //end of the lot level loop

/**************************
* complete the lot level *
**************************/
completeALevel();

} //end of the superlot leve loop

//Call the ph_driver_done PH driver function
callAPhDriverFunc("ph_driver_done");

/**********************************
* complete the superlot level *
**********************************/
completeALevel();
cout<<">>>>>>>>>End of the level control"<<endl;

/***********
* The end *
***********/
cleanup();
return 0;
}
```
