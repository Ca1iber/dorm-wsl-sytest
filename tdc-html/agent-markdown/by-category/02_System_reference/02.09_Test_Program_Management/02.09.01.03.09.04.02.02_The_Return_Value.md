# The Return Value

In addition to the parameters result and stReturn, each hook function must return its execution state when it terminates. Valid states include:

- PHHOOK_ERR_OK

to be returned when the hook function executed without error.

- PHHOOK_ERR_NOT_INIT

to be returned when the hook function was not initialized correctly.

- PHHOOK_ERR_NA

to be returned when the hook function was not activated (see [Activating a Hook Function](<02.09.01.03.09.04.03_Activating_a_Hook_Function.md>)).

 Note When using the provided hook functions templates and the hook function activation as described in this manual, the last two states will not occur. Note The hook function ph_ActionDone does not have the parameter result. At the point of the driver execution when this function is called, the current driver action is finished, and none of the possible result values would change the further driver proceeding.
