# Parameter: per_die_probe_cleaning_rate

If the prober supports probe needle cleaning, an automatic cleaning may be performed every time a given number of dies (or of die groups in case of multisite probing) have been probed.

This parameter defines the cleaning rate. If the parameter is set to 0, or if it is not defined at all, no automatic probe cleaning will be done based on probe counts. If set to a positive number, an automatic probe cleaning will be performed after this number of dies have been probed.

Per die probe needle cleaning may be combined with per wafer or per bin probe needle cleaning (see also the configuration parameters per_wafer_probe_cleaning_rate probe_cleaning_hardbins and probe_cleaning_softbins described next.)

Driver default: 0

Changeable at run-time: yes

Applicable for: prober

Example: per_die_probe_cleaning_rate: 20
