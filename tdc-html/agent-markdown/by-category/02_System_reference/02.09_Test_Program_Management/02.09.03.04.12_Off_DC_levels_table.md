# Off DC levels table

The off DC levels table of the MTPT (STPM MCM mapping tables) describes which DC levels are applied to inactive STPs (source test programs).

The table is stored in a file named offdclevels.csv in the MTPT directory. It is created by the [generate_template](<02.09.03.03.02_generate_template.md>) command, but the desired levels must be filled in manually.

The file is best edited by importing it into the [OpenOffice spreadsheet](<02.09.03.04.15_OpenOffice_spreadsheet_for_editing_the_CSV_files.md>) located in the [MTPT](<02.09.03.04_MTPT__STPM_MCM_mapping_tables.md>) folder. Editing is also possible in text editors, but this requires you to make sure yourself that all formatting is correct.

## Syntax

Each row in the levels table describes the levels for one DC pin. The table contains these columns:

- MTP Pin: The name of the DC pin in the MTP for which you are setting the levels. The pin names in this column must match the names in the [Pin mapping table](<02.09.03.04.02_Pin_mapping_table.md>).

The __DEFAULT__ entry is already predefined; it applies to all pins of inactive STPs for which there is no explicit entry in this table. (That is, all pins whose name does not appear in the MTP Pin column.)

- vout: The DC power supply voltage in V
- ilimit: The connect current limit in mA
- offcurr: The off current state of the pin

Supported states are:

  - min: Minimum current for high impedance
  - act: Actual current for low impedance
  - open: High impedance and open output relay

See [DPSPINS resources](<../02.08_Setup_and_Result_Tools/02.08.04.14.02.03.07.01_DPSPINS_resources.md>) for more information on these states.

- vih: The Vih voltage in V
- vil: The Vil voltage in V
- voh: The Voh voltage in V
- vol: The Vol voltage in V
- Notes: This column allows both you and STPM MCM to add remarks about the level. These notes are just for human consumption and are never processed automatically by STPM MCM. They may be overwritten when the tables are updated, so they are not a suitable place for storing important information.
