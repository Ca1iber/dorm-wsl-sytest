# PauseBLC

This remote control command pauses the execution of a [Batch/Lot Control](<02.09.01.11_Batch_Lot_Control.md>) client. The BLC program must be designed to be able to react to the `PAUSE` operation. Otherwise, this API will take no effect.

SUCCESS will returned if no error occurred. Otherwise, an error object will returned indicating the error code, description and severity.

 |

Code

 |

Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- There is no BLC being executed.
- The BLC has already been paused.
 |

RECOVERABLE

 |

## Dependency

The BLC is in execution.
