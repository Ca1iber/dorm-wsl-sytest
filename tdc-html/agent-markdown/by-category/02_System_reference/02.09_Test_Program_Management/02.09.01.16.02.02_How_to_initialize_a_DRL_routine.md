# How to initialize a DRL routine

## About this task

To initialize the data retrieval routine, you need to set the parameters of [DRLStart](<../02.10_Data_Logging/02.10.01.04.01.22_DRLStart.md>), mask the events that you Do not want and set up the file to store the output result.

## Procedure

-  Setup the [DRLStart](<../02.10_Data_Logging/02.10.01.04.01.22_DRLStart.md>) parameters

  - To capture the test result in real time, no file name is needed.
  - Set the flags to unmask all the events.

-  Mask the event you Do not want using [DRLSetEventMask](<../02.10_Data_Logging/02.10.01.04.01.21_DRLSetEventMask.md>) like below:

```
DRLEventMask myMask;
myMask.event_mask[eventType1] = 1;
```

-  Set up the file to store the output result

  - Open the existing file and change its mode to writable
  - Create a new file if the specified file name does not exist

## Example

```
Void init()
{
  DRLDataStream stream;
  String filename;
  DRLEventType event_type;
  DRLEventMask my_event_mask;
  int fopened =0;
  FILE *templog;

  DRLStart(0, (DRL_SYNC_COUNTER|DRL_RESET_MASK), &my_stream);
  //mask all events and then unmask the event BinReachedEventType
  for (event_type=0; event_type<NumberOfEventTypes; event_type++)
  {
    my_event_mask.event_mask[event_type] = 1;
  }

  my_event_mask.size = NumberOfEventTypes;
  my_event_mask.event_mask[BinReachedEventType] = 0;
  DRLSetEventMask(&my_event_mask, &my_stream);
  //setup for output file
  filename.assign("/tmp/PETSummaryOut.log");
  templog = fopen( filename.c_str(), "w");
  if(templog == NULL)
  {
    cerr << "[EDL] Error: Unable to open ouptut log file named: " <<  filename <<endl;
    exit(-1);
  }
  else
  {
    string command = "chmod 666 " + filename;
    system(command.c_str());
    if(print_debug > 0)
    cerr << "[EDL] Output log file was opened and is named " <<  filename <<endl;
    fileopened = 1;
  }
}
```

In this example, the DRL routine is initialized. All the event types are masked except the [BinReachedEventType](<../02.10_Data_Logging/02.10.01.06.03.06_BinReachedEventType.md>). The file /tmp/PETSummaryOut.log is set as the result output file.
