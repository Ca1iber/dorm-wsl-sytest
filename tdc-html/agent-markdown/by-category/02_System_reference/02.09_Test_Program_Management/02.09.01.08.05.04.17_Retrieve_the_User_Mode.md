# Retrieve the User Mode

The GetUserMode function retrieves the current mode of operation from the SmarTest software.

long GetUserMode(long *mode)

The long pointer *mode can be one of the following:

CI_CONSOLE_MODE=1, for Console mode

CI_OPERATING_MODE=2 for Operating mode

CI_SUPERVISING_MODE=3 for Supervising mode

CI_ENGINEERING_MODE=4 for Engineering mode

If an error occurs, *mode is undefined.
