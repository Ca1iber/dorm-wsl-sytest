# GetSmartestSessionProfile

This data query command gets the profile information of the SmarTest session specified by session ID.

Success will be returned if the command is successfully issued. Otherwise an error object indicating the error code, description and severity will be returned.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

The designated session ID "XXX" does not exist.

 |

RECOVERABLE

 |

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The ID of the SmarTest session to query.

 |
 |

O

 |

`qrResults`

 |

The query result is represented by a `ParamList` object. It contains the following members:

- `VERSION:` The SmarTest version.
- `PATCH_LEVEL:` The patch level of the SmarTest session. If a SmarTest version has no patch, the value is "0". The `VERSION` and `PATCH_LEVEL` comprises the four digits of SmarTest revision, like 5.2.4.5.
- `ONLINE_MODE:` The online/offline mode.
- `USER_MODE:` The user mode. It can be ENGINEER, SUPERVISOR, OPERATOR or OTHER.
- `LOGIN_USER:` The login user name of the SmarTest session.
- `TEMP_PATH`: The temporary directory created by the current SmarTest session. By default, it is named like 93k.xxx under the directory /var/opt/hp93000/soc/tmp.
 |

## Prototype

```
ParamList qrResults;
string sessionId;
Status query("GetSmartestSessionProfile", qrResults, ParamList(), sessionId);
```

## Example

```
ParamList qrResults;
string sessionId;
Status retVal = query("GetSmartestSessionProfile",
                          qrResults,
                          ParamList(),
                          sessionId);
if(retVal == SUCCESS)
{
 printf("SmarTest session <%s> profile: \n", sessionId);
 printf("Revision: s%\n", qrResults["VERSION"], ".", qrResults["PATCH_LEVEL"]);
 printf("Online_mode: s%\n", qrResults["ONLINE_MODE"]);
 printf("User_mode: s%\n", qrResults["USER_MODE"]);
 printf("Temp_path: s%\n", qrResults["TEMP_PATH"]);
 ...
}
```

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.3.2: New output parameter PATCH_LEVEL
- SmarTest 7.3.2: New output parameter TMP_PATH.
