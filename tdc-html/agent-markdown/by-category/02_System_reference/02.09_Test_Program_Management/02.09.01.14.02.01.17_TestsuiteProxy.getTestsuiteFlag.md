# TestsuiteProxy.getTestsuiteFlag()

This function query the status of a test suite flag.

## Syntax

```
int getTestsuiteFlag(const TestsuiteFlag name) const;
```

Parameters
 |

name

 |

The test suite flag to query. It can be one of the options of `TestsuiteFlag` enumeration as defined in the above table.

 |
