# getCalibrationDate()

This function returns date and time of a calibration as struct of type tm. A calibration year of 1970 is returned for un-calibrated items.

## Syntax

```
const struct tm getCalibrationDate (CalStatusEvent event,
                                    CalStatusType  type,
                                    const char*    cat,
                                    const char*    pogoList);
```

  Parameters

 | Parameter  | Description |
 | event  | The calibration status event. It can be: |
 | CAL_EVENT_LAST  | Last calibration. For SmarTest 7.10, this will always return "01.01.1900". |
 | CAL_EVENT_NEXT  | Next calibration |
 | type  | The calibration status type. It can be: |
 | CAL_TYPE_FULL  | Full calibration |
 | CAL_TYPE_UPDATE  | The incremental calibration of some specific steps |
 | cat  | The calibration category name from [calibrationCategoryList_next()](<02.09.01.13.03.01_calibrationCategoryList_next.md>). It can be: |
 | Core  | for the mandatory parts of a full calibration. |
 | ExtDc  | for the focus calibration. |
 | Fact  | for the one-time calibration done during the production of the hardware. |
 | Tmu  | for TMU calibration. It is optional and only needed when TMU is used. |
 | Update |

for the DC update calibration. The calibration has a shorter life time than the full calibration. Refer to the calibration periods for the individual cards in the [Specifications](<../02.02_Specifications/02.02_Specifications.md>).

 |
 | pogoList  | The list of cards or channels to be queried. It can be `NULL`, meaning all cards and channels.  |  Return value The returned struct tm`` is defined as below:

```
struct tm
{
    int tm_sec;       // Seconds after the minute   [0 ... 60] (1 leap second)
    int tm_min;       // Minutes after the hour     [0 ... 59]
    int tm_hour;      // Hours since midnight       [0 ... 23]
    int tm_mday;      // Day of the month           [1 ... 31]
    int tm_mon;       // Months since January       [0 ... 11]
    int tm_year;      // Years since 1900
    int tm_wday;      // Days since Sunday          [0 ... 6]
    int tm_yday;      // Days since January 1       [0 ... 365]
    int tm_isdst;     // Daylight savings time flag [-1/0/1]
};
```

## Examples

### Example 1: Stand-alone sample program

This is a sample program to do a calibration date query provided with SmarTest in the directory /opt/hp93000/soc/pws/calibration/example/.

For information on how to implement the example refer to [How to use the calibration API](<02.09.01.13.01_How_to_use_the_calibration_API.md>).

```
#include <stdio.h>

#include "/opt/hp93000/soc/pws/include/calibration.h"

void printDate (CalStatusEvent event,   // Calibration event: last or next calibration
                const char* name,       // Calibration category name
                const struct tm t)      // Time structure
{
    printf("Date of %s %-7s calibration: %4d-%02d-%02d %02d:%02d\n",
           event == CAL_EVENT_LAST ? "last" : "next",
           name, t.tm_year+1900, t.tm_mon+1, t.tm_mday, t.tm_hour, t.tm_min);

} // void printDate (CalStatusEvent event, const char* name, const struct tm t)

//
// Show date & time of calibration for all calibration categories
//
void showAllCalibrationDates (CalStatusEvent event) /* calibrationevent: last or next */
{
    //
    // Create a category iterator
    //
    CalibrationCategoryList* catList = calibrationCategoryList_new (CompleteCalibration, NULL);

    const char* catName = NULL;

    //
    // Loop through all category names
    //
    while (catName = calibrationCategoryList_next (catList), catName != NULL && *catName != '\0')
    {
        //
        // Get & print calibration date
        //
        printDate (event, catName, getCalibrationDate (event, CAL_TYPE_FULL, catName, NULL));
    }

    //
    // Delete iterator
    //
    calibrationCategoryList_delete (catList);

    //
    // Repeat the loop for update calibration
    //
    catList = calibrationCategoryList_new (UpdateCalibration, NULL);

    while (catName = calibrationCategoryList_next (catList), catName != NULL && *catName != '\0')
    {
        printDate (event, catName, getCalibrationDate (event, CAL_TYPE_UPDATE, catName, NULL));
    }

    calibrationCategoryList_delete (catList);

} // void showAllCalibrationDates (CalStatusEvent event)

//
// Print if calibration of all categories is valid or invalid
//
void isCalibrationValid()
{
    //
    // Create a category iterator
    //
    CalibrationCategoryList* catList = calibrationCategoryList_new (CompleteCalibration, NULL);

    const char* catName = NULL;

    //
    // Loop through all names of the category list
    //
    while (catName = calibrationCategoryList_next (catList), catName != NULL && *catName != '\0')
    {
        printf("%-7s calibration is %svalid\n", catName, isValidCalibration (CAL_TYPE_FULL, catName, NULL) ? "" : "in");
    }

    //
    // Delete iterator
    //
    calibrationCategoryList_delete (catList);

    //
    // Repeat the loop for update calibration
    //
    catList = calibrationCategoryList_new (UpdateCalibration, NULL);

    while (catName = calibrationCategoryList_next (catList), catName != NULL && *catName != '\0')
    {
        printf("%-7s calibration is %svalid\n", catName, isValidCalibration (CAL_TYPE_UPDATE, catName, NULL) ? "" : "in");
    }

    calibrationCategoryList_delete (catList);

} // void isCalibrationValid()

int main (void)
{
    printf("\nplease make sure that tester SW is running ..\n\n");

    //
    // Show calibration date of last full calibration
    //
    showAllCalibrationDates (CAL_EVENT_LAST);

    //
    // Show calibration date of next update calibration
    //
    showAllCalibrationDates (CAL_EVENT_NEXT);

    //
    // Is calibration valid ?
    //
    isCalibrationValid();

}
```

### Example 2: SmarTest test method

The following code shows how to do a calibration date query within a test method.

```
#include "testmethod.hpp"

#include "mapi.hpp"

#include "/opt/hp93000/soc/pws/include/calibration.h"

using namespace std;

class getCalDate: public testmethod::TestMethod
{

protected:

    string sParameterSelectedEvent;

    virtual void initialize()
    {
        addParameter("CalInfo", "string", &sParameterSelectedEvent, testmethod::TM_PARAMETER_INPUT)
                        .setOptions("last:next")
                        .setDefault("last");

    } // virtual void initialize()

    void printDate (const char* name, const struct tm t)
    {
        if (sParameterSelectedEvent == "last")
        {
            printf("Date of last %-7s calibration: %4d-%02d-%02d %02d:%02d is %svalid\n",
                    name,t.tm_year+1900,t.tm_mon+1,t.tm_mday,t.tm_hour,t.tm_min,
                    isValidCalibration (CAL_TYPE_FULL, name, NULL) ? "" : "never done or in");
        }
        else
        {
            printf("Date of next %-7s update of calibration at: %4d-%02d-%02d %02d:%02d\n",
                    name,t.tm_year+1900,t.tm_mon+1,t.tm_mday,t.tm_hour,t.tm_min);
        }

    } // void printDate (const char* name, const struct tm t)

    /**
     *This test is invoked per site.
     */
    virtual void run()
    {
        ON_FIRST_INVOCATION_BEGIN();
        {
            if (sParameterSelectedEvent == "last")
            {
                cout << endl << endl << "Show last calibration dates and validity:" << endl;
            }
            else
            {
                cout << endl << endl << "Show coming calibration dates:" << endl;
            }

            //
            // Create a category iterator
            //
            CalibrationCategoryList* catList = calibrationCategoryList_new (CompleteCalibration, NULL);

            const char* catName = NULL;

            //
            // Loop through all names of the category list
            //
            while (catName = calibrationCategoryList_next (catList), catName != NULL && *catName != '\0')
            {
                if (sParameterSelectedEvent == "last")
                {
                    printDate (catName, getCalibrationDate (CAL_EVENT_LAST, CAL_TYPE_FULL, catName, NULL));
                }
                else
                {
                    printDate (catName, getCalibrationDate (CAL_EVENT_NEXT, CAL_TYPE_UPDATE, catName, NULL));
                }
            }

            //
            // Delete iterator
            //
            calibrationCategoryList_delete (catList);
        }
        ON_FIRST_INVOCATION_END();

        return;
    }

    virtual void postParameterChange(const string& parameterIdentifier)
    {
        return;
    }

    virtual const string getComment() const
    {
        string comment = " please add your comment for this method.";
        return comment;
    }
};
REGISTER_TESTMETHOD("getCalDate", getCalDate);

```

Date of last Tmu     calibration: 1900-01-01 00:00 is valid
Date of last Update  calibration: 1900-01-01 00:00 is valid
