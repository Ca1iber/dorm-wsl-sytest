# Producing a debug file

Once you have finished editing the configuration file, you can make a debug copy of it.

Proceed as follows:

- Make a copy of the configuration file in the same directory. Name this copy for example NewHandler-debug.cfg.
- Change the following general parameters:

  - debug_level
  - log_files_to_keep
  - single_step_mode

- Change the interface-dependent parameters.

GPIO parameters (only for equipment with GPIO interface):

bin_data_setup_time

- end_of_test_pulse_width
- bin_data_hold_time

GPIB parameters (only for equipment with GPIB interface):

- waiting_for_..._timeout
- ignored_SRQs

This parameter is only valid for TEL and TSK probers.

You can use the debug file of the original configuration file to determine the debug values of the interface-dependent parameters.
