# Parameters for TEL probers

These parameters may have to be changed if you are using TEL probers that are compatible with the model 20S. Whether you have to change these parameters depends on the prober firmware revision.

- tel_reversed_binning

If the binning results are incorrect, you can reverse the binning order by setting the parameter to yes.

- tel_o_command_style

The resulting string of the O command ("on wafer" command) may be either encoded or in ASCII. Set this parameter to ascii if necessary. The default uses encoded.

- tel_send_id_query

This parameter can be added to prevent the machine ID query being sent.

- tel_send_wafer_abort

This parameter can be added to prevent the unload and abort command being sent.
