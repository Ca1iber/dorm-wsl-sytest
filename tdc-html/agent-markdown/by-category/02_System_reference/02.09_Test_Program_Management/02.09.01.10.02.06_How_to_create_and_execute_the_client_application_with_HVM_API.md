# How to create and execute the client application with HVM API

This section describes how to create a client application with the HVM API and how to execute the application program.

## About this task

The client application is a C or C++ program which interfaces with both SmarTest and the user production environment. To use the HVM API, you need to include the ::xoc::hvmapi namespace in the program. The client application can:

- Control the SmarTest behavior by issuing remote control commands.
- Retrieve the SmarTest status and system information by executing data query commands.
- Notify SmarTest of its status via a notification command.

The remote control commands and operations are executed in an asynchronous way. Their final execution results will be sent out via an event notification channel. SmarTest will also actively notify its internal status change via the event notification channel. So the client application must be able to interact with the event notification and get notified with a certain event to proceed with its logic.

## Before you begin

Make sure that SmarTest 6.2 or above is installed.

## Procedures

### Create the client application program with HVM API

- Issue an HVM API command, operation, query or notify signature.

The HVM API command, operation, query, and notify signatures are used to control the SmarTest behavior, retrieve the SmarTest status, or notify SmarTest the production status. For details, see

[How to issue a command](<02.09.01.10.02.01_How_to_issue_a_command.md>)

[How to issue an operation](<02.09.01.10.02.02_How_to_issue_an_operation.md>)

[How to issue a query](<02.09.01.10.02.03_How_to_issue_a_query.md>)

[How to issue a notify](<02.09.01.10.02.04_How_to_issue_a_notify.md>)

- Get notified with the event notification.

The signatures used together to fulfill the event notification include [EventListenerType](<02.09.01.10.03.01.05_EventListenerType.md>), [addEventListener](<02.09.01.10.03.01.03_addEventListener.md>), [eventLoop](<02.09.01.10.03.01.06_eventLoop.md>), and [eventLoopExit](<02.09.01.10.03.01.07_eventLoopExit.md>). For details, see [How to get notified with a SmarTest event](<02.09.01.10.02.05_How_to_get_notified_with_a_SmarTest_event.md>).

Refer to [Example codes of the most often used test control tasks](<02.09.01.10.02.07_Example_codes_of_the_most_often_used_test_control_tasks.md>).

### Compile and link the client file

The client source code needs to be compiled with the header file /opt/hp93000/soc/system/include/xoc/hvmapi/hvmapi.hpp, and linked with the library /opt/hp93000/soc/system/lib/libhvm_cpp.so.

You can build your client application program like any ordinary C++ program with a Makefile. Before doing this, run /opt/hp93000/soc/system/bin/run -S first to prepare a build environment.

The following is an example of a Makefile:

```
HP83000_ROOT=/opt/hp93000/soc

CPP = /usr/bin/g++ -m64
LD = /usr/bin/g++ -m64

INCLUDES =  -I ${HP83000_ROOT}/system/include
LIB_PATHS = -L ${HP83000_ROOT}/system/lib \
            -Wl,-rpath,:${HP83000_ROOT}/system/lib

CPPFLAGS = -g -DHP83000_ROOT=${HP83000_ROOT} -DOS_LINUX $(INCLUDES)
LDFLAGS = $(LIB_PATHS)  -lhvm_cpp

SRCS = $(shell ls *.cpp)
OBJS = $(SRCS:.cpp=.o)

all: hvm_client
clean: ; @rm -f $(OBJS); rm -f core*; rm -f hvm_client
hvm_client: $(OBJS)
    ${LD} $(OBJS) $(LDFLAGS) -o $@
.cpp.o:
    ${CPP} $(CPPFLAGS) -c $<
```

### Execute the client application program

To execute the client application program, type in the following command:

```
/opt/hp93000/soc/system/bin/run -x YOUR_CLIENT_PROGRAM -- program_arg1 program_arg2
```

YOUR_CLIENT_PROGRAM is the executable client application program that you have created.

program_arg1 and program_arg2 are the arguments of the client application program.

With this command, a session manager will start automatically if it has not been running.

Note

- If the session manager is running, you can use either -QX or -x to execute the application program.
- If the session manager has NOT started, you can only use -x to execute the application program. If you use -QX now, it can cause an error. An error message "terminate called after throwing an instance of 'xoc::exc::ZUnrecoverable'" will pop up.
