# Application model file string

## get

long GetModelfileString(char *name, char *value)

Retrieves the current value of the model file variable named *name and copies it to the string pointed to by *value. application model file variables are implicitly declared as strings.

This function writes a maximum CI_CPI_MAX_MODL_STRING_LEN + 1 bytes to the pointer *value*.

Use a "string" constant to identify the variable required.

The values returned are as follows,

 |

0

 |

ok

 |
 |

1

 |

error on a name

 |
 |

-1

 |

internal error

 |

## set

long SetModelfileString(char *name, char *value)

Sets the value of the model file variable named *name to the string pointed to by *value. Application Model File variables are implicitly declared as strings.

The returned values are as for the get function.

## Example

```
#include <libcicpi> // Required by these two APIs.
...
char new_wafer_id[2];
GetModelfileString("Temperature",new_wafer_id);
char* LB_ID_var="debug_LB";
SetModelfileString("LB_ID", LB_ID_var);
...
```
