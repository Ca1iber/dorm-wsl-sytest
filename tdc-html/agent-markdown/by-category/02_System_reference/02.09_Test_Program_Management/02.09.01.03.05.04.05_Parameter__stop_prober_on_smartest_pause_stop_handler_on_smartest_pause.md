# Parameter: stop_prober_on_smartest_pause stop_handler_on_smartest_pause

This parameter determines whether the equipment will be paused by the driver, when the SmarTest pause flag is set. (Typically, this is done by clicking Pause in the Operation Control window of SmarTest.)

Depending on the equipment type, the driver will make the equipment leave the pause mode again, when the SmarTest pause mode is left, or the equipment must be returned to normal operation by the operator.

Driver default: "no"

Changeable at run-time: yes

Applicable for: probers and handlers

Example: stop_prober_on_smartest_pause: "yes"

 stop_handler_on_smartest_pause: "yes"

Note Pausing Sequence The below explained sequence should always be followed to avoid misalignment between equipment driver actions and the current state of the equipment: - After first pausing the equipment and then pausing SmarTest, first SmarTest should be continued, and then the equipment. - If stop_prober_on_smartest_pause is set to "no", and first SmarTest and then the equipment are paused, first the equipment should be continued, and then SmarTest.
