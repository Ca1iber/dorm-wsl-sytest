# selectTestmethodExecutor()

This API selects the universal test method executor to be used for test method execution.

If it is successfully executed, true will be returned. Otherwise, false will be returned.

## Syntax

```
bool selectTestmethodExecutor( const int executor);
```

Parameters
 |

executor

 |

The index number of the UTM executor to use. It can be:

1: the first executor for production execution.

2: the second executor for debug purpose and non-production execution.

 |
