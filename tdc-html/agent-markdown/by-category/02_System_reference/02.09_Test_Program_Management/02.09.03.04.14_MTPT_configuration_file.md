# MTPT configuration file

The MTPT configuration file contains basic information on the contents of the MTPT (STPM MCM mapping tables) directory that is used by STPM MCM for internal management purposes.

The file is named config.ptpt.

We recommend that you do not edit the MTPT configuration file.

## Syntax

The internal structure of the MTPT configuration file is private and subject to change without notice.
