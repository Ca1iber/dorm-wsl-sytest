# update_template

The update_template command for the SmarTest Program Manager MCM (STPM MCM) [control file](<02.09.03.03_STPM_MCM_control_file.md>) recalculates the tables in the MTPT (STPM MCM mapping table). Depending on the mode you choose, STPM MCM recalculates all tables - except those you specify - based on changes in the STPs and in the specified read-only tables, or it reviews the errors listed in the Notes columns of some or all tables and remove fixed ones.

Using this command makes it easier to keep an MTPT consistent when you have made changes and keep an overview of which errors still need attention.

Note that, in either mode, STPM will overwrite the contents of the Notes columns in the MTPT (except in the tables marked as read-only), so that you will lose any text you may have entered in these columns.

Before update_template can be executed, an MTPT (STPM MCM mapping table) must have been created, which is typically done with the [generate_template](<02.09.03.03.02_generate_template.md>) command.

## Syntax

```
update_template(
  mode      = '<mode>',
[ read_only = ['<table>', ...]  ]
)
```

## Parameters

 |

mode

 |

What STPM MCM is to update in the MTP.

<mode> can be any of these:

- 'adjust_tables': All tables in the MTP - except any read-only tables, see below - are updated from the STPs and the tables marked as read-only.

If this mode is specified and no table is listed as read-only, the effect is the same as rerunning [generate_template](<02.09.03.03.02_generate_template.md>) with the original parameters.

- 'clear_errors': STPM MCM reviews the errors and warnings in the note columns of all tables in the MTP - except any read-only tables, see below - and removes all that no longer apply.
 |
 |

read_only

 |

A list of all tables STPM MCM is to leave unchanged. These tables are used as the sources to recalculate the other tables.

<table> can be any of these terms:

- '[STPs](<02.09.03.04.01_STP_table.md>)'
- '[Pins Map](<02.09.03.04.02_Pin_mapping_table.md>)'
- '[Groups Map](<02.09.03.04.03_Group_mapping_table.md>)'
- '[Tests Map](<02.09.03.04.04_Test_mapping_table.md>)'
- '[Test Suites](<02.09.03.04.05_Test_suite_table.md>)'
- '[Bins Map](<02.09.03.04.06_Bin_mapping_table.md>)'
- '[Test Numbers Map](<02.09.03.04.07_Test_number_mapping_table.md>)'
- '[Flow Variables Map](<02.09.03.04.08_Testflow_variable_mapping_table.md>)'
- '[Special Tests](<02.09.03.04.09_Special_tests_table.md>)'
- '[Shared Pins](<02.09.03.04.10_Shared_pins_table.md>)'
- '[Test Flags](<02.09.03.04.11_Test_flag_table.md>)'
- '[Off DC Levels](<02.09.03.04.12_Off_DC_levels_table.md>)'
- '[STP Test Info](<02.09.03.04.13_STP_test_information_table.md>)'

You can specify multiple tables that must remain unchanged by separating them with commas. The list of tables - whether one or more - must be enclosed in square brackets.

This is an optional parameter. If it is not specified, STPM MCM will update all tables.

 |

(The information which MTPT to update comes from the [mtp_template_dir](<02.09.03.03.01_STPM_MCM_parameter_settings.md>)[ setting](<02.09.03.03.01_STPM_MCM_parameter_settings.md>) in the control file.)

## Example

This example checks the errors noted in the MTP in /prj/MTPT and removes those that have been fixed since the last update of the MTP. It does not remove any errors from the STP and test mapping tables.

```
mtp_template_dir = "/prj/MTPT"
update_template(
  mode = "clear_errors",
  read_only = ['STP Table', 'Tests Map']
)
```
