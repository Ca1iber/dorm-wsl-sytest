# srq_mask

Defines the value of SRQMASK for the supported handlers. SRQMASK is used by the handler to enable or disable the bits in the status byte for the specific operation. This parameter defines a two-digit hexadecimal number, for example, 43 means bits 6,1 and 0 of the status byte are effective.

Driver default: FF

Changeable at run-time: Yes

Applicable for: Advantest GS1/M48, Delta handlers

Example: srq_mask: "3F"

## Functional changes

- Introduced in SmarTest 7.2.1
