# command

The command signature is to trigger the execution of Remote Control Command of HVMAPI that does not have the output value.

The execution of command signature is run in asynchronous manner. The execution result is notified via the HVM event notification.

An error object will be returned indicating the success of operation execution or the error occurs.

Prototype

```
xoc::hvmapi::Status command(const std::string &cmdName,
const xoc::hvmapi::ParamList &cmdParams=xoc::hvmapi::ParamList(),
const std::string &sessionId=std::string(""))
```

Parameters
 |

cmdName

 |

The HVMAPI command name.

 |
 |

cmdParams

 |

The input parameters represented by `ParamList`.

 |
 |

sessionId

 |

The ID of the SmarTest session to work with.

 |

## Example

`ParamList cmdParams;`

`string sessionId;`

`Status command("DownloadTestprogram", cmdParams, sessionId);`
