# date_time

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.13.01_Associated_Syntax_Entities.md>)

This keyword is used in conjunction with [GET_TEST_INFO](<02.09.01.02.05.02.36_GET_TEST_INFO.md>) to assign the current date and time to a variable.

The format for the time mark is YYYYMMDD_HHMMSS (year, month, day, hours, minutes, and seconds).

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.4: Changed the output format of the date and time
