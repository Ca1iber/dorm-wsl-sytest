# GPIB communication flow for MCT handlers

The GPIB communication flow determines how the driver controls the handler and at the same time how the handler responses and acts by following the commands.

The table below shows the communication between the driver and the handler. The actions and messages are listed in sequential order.

See [Conventions for GPIB/LAN communication](<02.09.01.03.06.01.04_Conventions_for_GPIB_LAN_communication.md>) for the description of the syntax.

The handler sends the Set StartTest command to tell which parts are to be tested. For example, `Set StartTest "123456789" A1,B1,C1,D1,E1`.

If one strip has been tested, the handler sends the Set PanelComplete command to tell the driver that one strip test has been done.
