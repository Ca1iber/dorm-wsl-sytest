# Additional Information

#### Subtopics

- [Writing a Program with more than one Sourcefile](<02.09.01.08.03.02.05.01_Writing_a_Program_with_more_than_one_Sourcefile.md>)

CPI functions are obtained if you include the file libcicpi.h at the beginning of each source file. This is automatically included in the pg_templ.c template file. Further information about CPI functions is given in [Command Set Programming Interface](<02.09.01.08.05_Command_Set_Programming_Interface.md>).

If you have developed a program in a different directory from the Command Set directory, and subsequently copied the program to the Command Set directory, the program automatically becomes available to the Command Set. However, debugging is not possible on such a program.
