# CONST_FORMAT

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.10.01_Associated_Syntax_Entities.md>)

Used to specify a constant format - specifying a constant string, for example.

Including a line like this,

* Test_group = DIALOG_INPUT / CONST_FORMAT(PRODUCTION|QA|ENGINEERING);

means that the software expects the value for "Test_group" to be either "PRODUCTION", "QA" or "ENGINEERING".
