# IsInterrupted()

This API checks if the Abort production flag or Reset production flag is set. BLC should take actions according to the return value.

`SUCCESS` will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- The local session does not exist.
 |

RECOVERABLE

 |

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The local session ID.

 |
 |

O

 |

IS_INTERRUPTED

 |

If the Abort button production flag or Reset production flag is set, the value is TRUE otherwise FALSE.

 |

## Prototype

```
ParamList outputResults;
Status query("IsInterrupted", outputResults, ParamList(), sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList outputResults;

Status retVal = query("IsInterrupted", outputResults, ParamList(), sid);
if ( retVal.isSuccess() )
{
cout<< "The BLC interrupt condition = "
    << outputResults["IS_INTERRUPTED"] << endl;
}
```
