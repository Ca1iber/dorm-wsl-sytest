# Preprocessing and postprocessing scripts

The commands in the STPM control file allow preprocessing and postprocessing scripts to be specified that are automatically run, respectively, before or after the command itself is executed. This is done via the pre_proc and post_proc parameters.

## Supported scripts

Any script can be specified that is executable on the computer on which STPM is running. The operator is responsible for making sure that any required support for the script (such as the interpreter for the script language) is available and that the script can handle any parameters passed to it.

## Parameters for the scripts

The value of the pre_proc and post_proc parameters specifies the script to be executed and the parameters which will be passed to it. Each system parameter starts with a & and is replaced for the execution of the script with a similar parameter prefixed with a double dash (--) and the corresponding value.

For example, adding &mdir to the pre_proc value results in the script being called with the `--mdir '/user/johndoe/mtp`' parameter (assuming that /user/johndoe/mtp is the path of the current MTP directory).

You can also add any number of custom parameters at the end of the parameter list that are passed unchanged to the script. These script parameter names must not begin with a &.

## Syntax

Both the pre_proc (shown below) and post_proc parameters have the same syntax.

```
pre_proc = '<script>[&mdir][&sdir][&mtp_tf][&mtp_pmf][&mtp_conf][&mtp_tim][&mtp_lev][&mtp_tt][&mtp_rout][&mtp_wf][&mtp_anctrl][&mtp_chatt][&mtp_prot][&mtp_att][&stp_tf][&stp_pmf][&stp_conf][&stp_tim][&stp_lev][&stp_tt][&stp_rout][&stp_wf][&stp_anctrl][&stp_chatt][&stp_prot][&stp_att][<user_parameters>]'
```

## Example

This example executes the write_tp command with two scripts:

- Before write_tp itself is executed, the preparation.py script from the current working directory is run. No parameters are passed to this script.
- After write_tp has finished executing, the cleanup.pl script is run. This script receives this parameter string (assuming that the MTP is located in /user/johndoe/mtp):

`--mdir '/user/johndoe/mtp' --cmd write --stage 3`

```
write_tp('user/johndoe/mtp/flow1.tf',
         pre_proc  = 'preparation.py',
         post_proc = '/usr/tools/scripts/cleanup.pl &mdir --cmd write --stage 3')
```
