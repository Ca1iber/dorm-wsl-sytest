# User Double

## get

IsUserDoubleDefined checks whether the double with the name *name is defined. It returns 0 when not defined, otherwise returns 1.

GetUserDouble retrieves the current value of the user defined variable, *name, and deposits it in the double, pointed to by *value. The variable must have been declared as a double.

GetUserDoubleOfSite lets you specify which site should be used (1,2,...), while GetUserDouble assumes the site currently in focus (for example during sequential User Procedure execution). In case of single site test the first site is always in focus. Use a "string" constant to identify the variable required.

GetAllDoubleTestflowVariables retrieves the names and values of all the user-defined DOUBLE type testflow variables and stores them in the relevant C structure.

```
int IsUserDoubleDefined(char *name)
long  GetUserDouble(char *name, double *value)
long  GetUserDoubleOfSite(char *name, long site, double *value)
long  GetAllDoubleTestflowVariables( CI_CPI_DOUBLE_TFL_VAR_LIST *double_tfl_var_list)
```

The values returned are as follows,

 |

0

 |

ok

 |
 |

1

 |

error on a name

 |
 |

-1

 |

internal error

 |

The following example shows how the function `GetUserDouble()` is used.

```
void CiExample2(char  *parm_list_input,
  int    parmcount,
  char  *comment_out,
  int   *comlen,
  int   *state_out)
{
  /* A variable name is to be passed as parameter */

  long   type;
  long   flag_var;
  double double_var;
  char   str_var[CI_CPI_MAX_USER_STRING_LEN+1]
  *comment_out='\0';
  *comlen=0;

  if (GetUserType(param_list_input,&type))
     {
     Errorhandling("Cannot retrieve variable type.");
     *state_out=CI_TEST_FAIL;
     return;
     }

  switch(type)
    {
    case CI_CPI_DBL:
      {
        GetUserDouble(param_list_input,&double_var);
        fprintf(stderr,"Value of %s is %lf.\n",
                 param_list_input,double_var);
      }

    case CI_CPI_FLG:
      {
        GetUserFlag(param_list_input,&flag_var);
        fprintf(stderr,"Value of %s is %ld.\n",
                 param_list_input,flag_var);
      }

    case CI_CPI_STR:
      {
        GetUserString(param_list_input,str_var);
        fprintf(stderr,"Value of %s is \"%s\".\n",
                 param_list_input,str_var);
      }

    }
  *state_out = CI_CALL_PASS;
}

```

The next example shows how the function `GetAllDoubleTestflowVariables()` is used.

```
CI_CPI_DOUBLE_TFL_VAR_LIST double_tfl_var_list;
CI_CPI_DOUBLE_TFL_VAR *pTflVar;
int i = 0;
If (GetAllDoubleTestflowVariables(&double_tfl_var_list)==0 )
{
  for (i=0; i< double_tfl_var_list.number_of_double_tfl_vars; i++)
  {
    pTflVar = &  double_tfl_var_list.double_tfl_vars[i];
    printf("the DOUBLE Testflow Variable name is %s\n", pTflVar ->name);
  }
}
```

## set

SetUserDouble sets the value of the user defined variable, *name with value. The flag specified must have been declared as a double.

SetUserDoubleOfSite lets you specify which site should be used (1,2,...), while SetUserDouble assumes the site currently in focus (for example during sequential User Procedure execution). In case of single site test the first site is always in focus.

Use a "string" constant to identify the variable required.
