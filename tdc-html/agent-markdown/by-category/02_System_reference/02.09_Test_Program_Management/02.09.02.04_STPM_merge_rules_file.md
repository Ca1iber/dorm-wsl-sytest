The merge rules file of the SmarTest Program Manager (STPM) lets you fine-tune how test are integrated into existing master test programs (MTP).

Which merge rules file is used in a merge process is specified in the [STPM control file](<02.09.02.03_STPM_control_file.md>), enabling you to easily prepare and use different merge rule file, for example, for different stages of the development process. For example, you may have more permissive rules early on the test program development process to allow for rapid changes and more restrictive ones later to protect well-debugged programs.

Merge rule files are optional; if you Do not specify a merge rules file, a default set of rules is used. (See the descriptions of the individual merge rule options for information on the defaults.)
