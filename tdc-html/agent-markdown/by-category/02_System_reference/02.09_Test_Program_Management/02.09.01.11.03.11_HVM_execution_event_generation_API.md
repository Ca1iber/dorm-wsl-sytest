# HVM execution event generation API

#### Subtopics

- [IssueHVMExecutionEvent()](<02.09.01.11.03.11.01_IssueHVMExecutionEvent.md>)

This API sends out HVM execution events to the HVM client.

Like EDL event generation, BLC provides both the implicit and explicit approach to issue the HVM events.
