# GPIB communication flow for UENO SEIKl Handlers

The GPIB communication flow determines how the driver controls the UENO SEIKI handler and at the same time how the handler responses and acts by following the commands.

The table below shows the communication between the driver and the handler. The actions and messages are listed in sequential order.

 See [Conventions for GPIB/LAN communication](<02.09.01.03.06.01.04_Conventions_for_GPIB_LAN_communication.md>) for the description of the syntax.

GPIB communication flow for UENO SEIKI handlers
 | Message from driver  | Message from handler  | Description |
 | Starting test: |
 |   | `0x47`  | The handler sends `0x47` to ask for starting the test.

 | P_stb amount  | Status |
 | `0x47`  | Command to start test.  | |
 | `O`  |   | The tester answers the `O` command to indicate the request received.

 | `O`  | 1 byte |
 | CR (0x0d)  | 1 byte |
 | LF (0x0a)  | 1 byte  | |
 |   | Sending device information, `0100####`  | The handler sends the device information to the tester.
