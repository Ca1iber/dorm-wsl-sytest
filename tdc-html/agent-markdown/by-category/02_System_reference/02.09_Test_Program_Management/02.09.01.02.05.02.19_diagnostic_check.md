# diagnostic_check

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.19.01_Associated_Syntax_Entities.md>)

This expression is used in conjunction with MONITOR_CALL, and enables you to check if the diagnostics have been done or not. You would typically have this expression at the beginning of your application model file.

The line,

diag_done = [MONITOR_CALL](<02.09.01.02.05.02.40_MONITOR_CALL.md>) (diagnostic_check);

checks to see if diagnostics have been done. The result will be a simple yes or no that can be seen, for example, in [Report window](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.13_Report_window.md>) or in the log file CompleteSystem.slg (usually under /opt/hp93000/soc/system/log/).
