# Parameter: hand_test_mode

Sometimes it is necessary for the operator to remove the handler from the test system and to do the device handling by hand. This may even be necessary during driver run-time.

This parameter allows you to set the driver to the hand test mode. When running in this mode, the operator is prompted every time a device handling action needs to be performed.

Also, no driver communication to the handler takes place.

Hand test mode can also be activated/deactivated by calling special driver functions from the application model. This is described in [Functions for Changing the Driver Mode](<02.09.01.03.08.07_Functions_for_Changing_the_Driver_Mode.md>).

 Note If the hand test mode was enabled by the function ph_handtest_start, and not by setting this parameter to "on", it cannot be disabled by setting this parameter to "off'. The function ph_handtest_stop must be used for this. Driver default: "off"

Changeable at run-time: yes

Applicable for: handlers

Example: hand_test_mode: "on"
