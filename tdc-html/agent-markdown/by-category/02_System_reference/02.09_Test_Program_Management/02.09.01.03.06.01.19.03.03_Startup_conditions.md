# Startup conditions

At start up of the driver, the driver resets the GPIB bus to ensure stable operation. If the handler receives the reset and has already devices pending for test, it will bin these devices to a default location. I.e. these devices are not tested. Therefore it is best practice to start the test program on the test system first, before handling of devices is activated at the handler.
