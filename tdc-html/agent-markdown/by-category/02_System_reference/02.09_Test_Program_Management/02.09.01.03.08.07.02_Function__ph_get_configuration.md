# Function: ph_get_configuration

This function lets you retrieve the current setting of any configuration parameter.

ph_get_configuration returns the setting of the parameter (specific driver configuration parameter or global configuration parameter) provided as an argument.

The returned parameter setting is assigned to the calling variable (setting in the example below).

This assignment will automatically be logged to the data log stream of event data logging (see the Event Data Logging documentation).

Applicable for: handler and prober driver

```
Example:
setting = PROB_HND_CALL (ph_get_configuration handler_family);
```

See the section [Example application models](<02.09.01.02.04.01_Example_application_models.md>) for more examples.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.0: GDF logging in application model is obsolete.
