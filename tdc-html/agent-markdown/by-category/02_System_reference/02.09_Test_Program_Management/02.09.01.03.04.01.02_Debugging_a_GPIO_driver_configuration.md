# Debugging a GPIO driver configuration

#### Subtopics

- [Timing parameters](<02.09.01.03.04.01.02.01_Timing_parameters.md>)
- [GPIO line assignment parameters](<02.09.01.03.04.01.02.02_GPIO_line_assignment_parameters.md>)
- [Event detection parameters](<02.09.01.03.04.01.02.03_Event_detection_parameters.md>)

If your configuration does not work correctly, check the configuration file especially for the values of the following important parameters:

- GPIO interface parameters
- Timing parameters
- GPIO line assignment parameters
- Event detection parameters

The following sections give basic information on these parameters and hints for debugging.
