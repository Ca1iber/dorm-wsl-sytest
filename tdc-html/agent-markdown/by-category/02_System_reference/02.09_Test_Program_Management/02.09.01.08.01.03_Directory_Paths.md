# Directory Paths

 The Command Sets reside in the following default directories:

User Procedure: /opt/hp93000/soc/userproc_libs

Prober/Handler: /opt/hp93000/soc/PH_libs

Data Bridge: /opt/hp93000/soc/data_bridge

Execution Input: /opt/hp93000/soc/execution_input

You can use your own directory paths and names instead of the defaults.

To install a new Command Set, first create a new directory under the directory path you want to use. When you do this, the new Command Set will be accessible from the Test Program Explorer.

For example, to install a new command set called

newup

in the user procedure library in /opt/hp93000/soc , type the following:

cd /opt/hp93000/soc/userproc_libs

mkdir newup

cd newup

When you have created the new directory, and then use the cd command to move to it, you can proceed with installing the Command Set as defined in [How to install the command set](<02.09.01.08.02_How_to_install_the_command_set.md>).
