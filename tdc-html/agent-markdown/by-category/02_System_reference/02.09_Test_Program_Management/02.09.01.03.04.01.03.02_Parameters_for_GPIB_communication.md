# Parameters for GPIB communication

The following parameters affect the GPIB communication between the driver and equipment.

- ignored_SRQs

This parameter is valid only for TEL and TSK probers. If you activate this parameter, additional prober SRQs are ignored by the driver.

- waiting_for_parts_method

Determines whether the driver will use a polling-based or an interrupt- based algorithm while waiting for parts.

- polling_interval

This is the interval used if the driver uses a polling-based algorithm.
