# Application model setup

During the execution of the test program, the application model controls the sequence of the test.

Therefore, a set of driver functions to be called from the application models via PROB_HND_CALLs is provided. These functions control the driver and run actions like, for example, driver initialization and termination, changes of the operation mode of the driver (for example, hand test mode, single step mode) or driver configuration at run-time.

See [Using driver functions in the application model](<02.09.01.02.04_Using_driver_functions_in_the_application_model.md>) for a description of the driver functions and how to use them in the application model.

The driver functions to be called from the application model are designed to be as generic as possible, in order to make an application model usable with any handler, or any wafer prober, respectively.
