# Parameter: serial_bin_interval

The minimum time in milliseconds between subsequent end-of-test pulses for serial binning. The time is needed for processing of the binning signals by the handler.

Driver default: depends on plug-in

Changeable at run-time: yes

Applicable for: handlers and probers

Example: serial_bin_interval: 30
