# LoadTestprogramSync

This API loads a test program into SmarTest synchronously.

`LoadTestprogramSync` does not download the setups of the test program to SmarTest. It is similar to the load operation on the graphical user interface. It allows specifying alternative test program elements different to replace the data elements in the test program file.

If alternative test program elements are specified, the test program will become out-of-date after the API execution. If you want to keep the original elements, do not save the test program.

## Dependency

A device is already loaded in SmarTest.

Parameters
 |

SESSION_ID

 |

 The SmarTest session ID to work with.

 |
 |

TESTPROGRAM_NAME

 |

 The test program name.

 |
 |

ALTERNATIVE_TP_ELEM_TYPE

 |

(optional) The test program element type. It is in the format of {"TESTFLOW", "EXEC_INPUT"}.The valid values include TESTFLOW, APPLIC_DATA, PH_DRIVER, DATA_BRIDGE, EXEC_INPUT and WAFER_DESCRIPTION.

 |
 |

ALTERNATIVE _TP_ELEM_VALUE

 |

(optional) The test program element value. It is described in the format of {"testflow1", "exec_input1"}. The specified files must be in the current device directory.

 |

## Prototype

```
ParamList cmdParams;
Status syncCommand("LoadTestprogramSync", cmdParams, sessionId);
```

## Example

```
string sid ;
ParamList cmdParams;
vector<string> list;
list = split("TESTFLOW EXEC_INPUT", " ");
/* specify the tp element types */
cmdParams.setValueArray("ALTERNATIVE_TP_ELEM_TYPE", list);
list = split ("testflow1 exec_input1", " ");
/* specify the tp element values*/
cmdParams.setValueArray("ALTERNATIVE _TP_ELEM_VALUE", list);
syncCommand("LoadTestprogramSync", cmdParams, sid,);
```
