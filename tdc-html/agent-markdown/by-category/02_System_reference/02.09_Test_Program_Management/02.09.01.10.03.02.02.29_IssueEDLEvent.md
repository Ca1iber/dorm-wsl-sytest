# IssueEDLEvent()

This API generates the EDL (event data log) events for the specified SmarTest session. The execution of this API will result in an EDL event created and appended to the system EDL data stream.

This API currently supports the following EDL event type:

`TestProgramStartEventType`

`TestProgramEndEventType`

`AppModelLevelStartEventType`

`AppModelLevelEndEventType`

`AppModelLevelLoopEventType`

`AssignmentEventType`

SUCCESS will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

## Prototype

```
ParamList inParams;
Status syncCommand("IssueEDLEvent", inParams, sessionId);
```

## Example

```
string sid;
ParamList inParams;
inParams ["EVENT_TYPE"] = "AppModelLevelStartEventType";
inParams ["LEVEL_TYPE"]  = "CUSTOM_LEVEL";
inParams ["LEVEL_NAME"] = "lot";
syncCommand ("IssueEDLEvent", inParams, sid);
```
