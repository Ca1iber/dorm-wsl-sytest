# Parameter: bin_data_hold_time

The time in milliseconds the driver will keep the bin data signal stable after the end-of-test pulse.

Driver default: depends on plug-in

Changeable at run-time: yes

Applicable for: handlers and probers

Example: bin_data_hold_time: 3
