# Accessing Testflow Settings

#### Subtopics

- [Setting User Flags](<02.09.01.06.02.01_Setting_User_Flags.md>)

For a user with engineering status the Production Settings button is available in the Operation Control window (see [Starting SmarTest with engineer mode](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.01.03_Starting_SmarTest_with_engineer_mode.md>)). This button opens a dialog box that contains buttons to access all SmarTest flags (see the figure below).

  ![Accessing Flags in Testflow Settings Mode](<../../../../raw/46396.png>)  Note Clicking the Enter Prod. Settings Mode button leads you to the Production Settings mode (see [Using Production Settings](<02.09.01.06.03_Using_Production_Settings.md>)).

Testflow settings include

- [System Flags (Testflow flags for data logging)](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.03_Testflow_flags_for_data_logging.md>)
- [Testflow flags](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.02_Testflow_flags.md>)
- [User Flags](<02.09.01.08.05.01.02_User_Flags.md>)
- [Test suite flags](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.04_Test_suite_flags.md>)

Click any of the four toggle-buttons to get to the associated flag window (see following sections). The flags are interactive. You can change them during execution of the test and observe their effect.

Choose whichever method to view and edit the settings of the testflow, either from within the testflow or from the dedicated flag user interface, as discussed in this section. The effect is exactly the same.

See [Using Production Settings](<02.09.01.06.03_Using_Production_Settings.md>) for details on how to override flag settings using Production Settings.

 Note Additionally, you can select a report formatter to control the output to the report window produced by the testflow.
