# Popup Message with Input

This function generates a message popup with a string input field (see below), and is otherwise similar to MsgDisplayMsgGetResponse.

long MsgDisplayMsgGetStringResponse(char *msg, char *b2s,

 char *b3s, char *b4s, char *b5s, char *b6s,

 char *b7s, long *response, char *string)

  ![Popup with Dialog](<../../../../raw/46503.png>)

The popup disappears when any button is pressed and the parameter *response is set to the button number selected. If the Enter key is pressed to terminate the string input, the popup also disappears, and *response is set to -1.

Button strings are restricted to a length of CI_MAX_BUTTON_STR_LEN = 9. The Message string is limited to the length CI_MAX_MESSGE_STR_LEN = 512. The string is written to the pointer *string, and may be up to CI_MAX_MESSGE_STR_LEN + 1 (513) bytes long.
