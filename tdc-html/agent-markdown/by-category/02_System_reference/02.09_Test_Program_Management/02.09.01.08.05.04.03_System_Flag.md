# System Flag

#### Subtopics

- [CI_SITE_DISABLING_AUTOMATE](<02.09.01.08.05.04.03.01_CI_SITE_DISABLING_AUTOMATE.md>)

## get

```
long  GetSystemFlag(char *flag, long *value)
long  GetSystemFlagOfSite(char *flag, long site, long *value)
```

This function retrieves the current value of the system flag named *flag and deposits it in the long pointed to by *value. Flags are actually declared as int's, but are typecast to long's within this function. You can also use a "string" matching the flag name required.

`GetSystemFlagOfSite()` lets you specify which site should be used (1,2,...), while `GetSystemFlag()` assumes the site currently in focus (for example during sequential User Procedure execution). In a single site test, the first site is always in focus.

## set

```
long  SetSystemFlag(char *flag, long value)
long  SetSystemFlagOfSite(char *flag, long site, long value)
```

Sets the value of the system flag named *flag with the value value. Flags are actually declared as int's, but are typecast to long's within this function. You can also use a "string" matching the flag name required.

`SetSystemFlagOfSite()` lets you specify which site should be used (1,2,...), while `SetSystemFlag()` assumes the site currently in focus (for example during sequential User Procedure execution). In a single site test, the first site is always in focus.

The returned values are as for the `get` function.

For more definitions of system flags, refer to /hp93000/soc/prod_com/include/libcicpi.h.

## Example

Controlling the sites to be tested in multisite test

```
INT32         MaxSitesEnabled;
int         site,i;
long         status;

/* query current multi-site values */
GetNumberOfSites(&MaxSitesEnabled);

/* ------------------------------------------------------------------
 * Initialization:  disable all sites first (to get a known state)
 * ------------------------------------------------------------------
 */
for(site=1; site<=MaxSitesEnabled;site++)
{
   SetSystemFlagOfSite(CI_SITE_SETUP,site,CI_SITE_NOT_INSERTED);
}

/*--------------------------------------------------------------------------
 * Set the desired Sites to be Tested:  here, the example sets sites 1 & 3
 *--------------------------------------------------------------------------
 */
SetSystemFlagOfSite(CI_SITE_SETUP,1,CI_SITE_INSERTED_TO_TEST);
SetSystemFlagOfSite(CI_SITE_SETUP,3,CI_SITE_INSERTED_TO_TEST);
```
