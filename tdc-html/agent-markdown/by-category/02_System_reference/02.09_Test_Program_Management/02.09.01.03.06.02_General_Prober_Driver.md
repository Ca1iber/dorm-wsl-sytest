Each plug-in has its own directory containing the plug-in related files.

When referring to a plug-in in the global configuration, you must specify the plug-in path given below:

```
/opt/hp93000/soc/PH_libs/GenericProber/
                Electroglas/
                TEL/
                TSK/
```

For each plug-in, there are several default driver configurations available which typically are specific to the individual prober models.

The names of the default driver configuration files are of the following format:

<model>-<ifc>-<ctrl>-<probes>-<die>[-<misc>].cfg

<model>

defines the actual prober model, or model group, if several models can be covered by one common configuration.

<ifc>

the interface type.

<ctrl>

describes who controls the stepping. Valid entries are "SmarTest", "Prober", and "Learnlist".

<probes>

gives the number of probes/sites of the configuration.

<die>

is either "die" or "subdie" depending, whether this configuration performs subdie probing.

<misc>

is for any further information that characterizes the configuration (for example, Debug, etc.). Typically, the <misc> option is not used.

The default driver configuration files are located in:

/etc/opt/hp93000/soc/PH_libs/GenericProber/

and are listed in the sections which follow.

The /etc/opt/hp93000/soc/PH_libs/GenericProber/ directory also contains the global configuration file Global-prober-config.cfg.

 Note The maximum test sites supported by SmarTest and prober driver is 1024. The actual maximum number of test sites supported depends on the capacity of the probers.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.3.1: Support of up to 1024 sites
