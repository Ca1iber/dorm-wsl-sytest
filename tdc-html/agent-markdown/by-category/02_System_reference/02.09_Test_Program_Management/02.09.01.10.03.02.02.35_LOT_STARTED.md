# LOT_STARTED

This asynchronous event indicates that the execution of a new lot level is started in the test program execution.

## Dependency and constraints

- The test program is in execution.
- If the application model does not contain the custom Lot level or does not use the standard prober/handler driver function call (ph_lot_start) or the equivalent, this event may not be generated. To get the value of lot ID, the variable naming for lot ID should be `ph_LOT_ID` or `LOT_ID`.
