# How to issue a query

[query](<02.09.01.10.03.01.10_query.md>) is used to execute the data query command of BLC API.

## About this task

The BLC API which uses query include

[IsInterrupted()](<02.09.01.11.03.07.02_IsInterrupted.md>), [IsPaused()](<02.09.01.11.03.07.03_IsPaused.md>), [IsLotDone()](<02.09.01.11.03.07.04_IsLotDone.md>), [IsWaferDone()](<02.09.01.11.03.07.05_IsWaferDone.md>), [IsCassetteDone()](<02.09.01.11.03.07.06_IsCassetteDone.md>), [IsDeviceDone()](<02.09.01.11.03.07.07_IsDeviceDone.md>) and [GetSiteSetup()](<02.09.01.11.03.12.02_GetSiteSetup.md>).

The prototype of query is:

```
xoc::hvmapi::Status query(const std::string &qrName,xoc::hvmapi::ParamList &qrResults,
const xoc::hvmapi::ParamList &qrParams=xoc::hvmapi::ParamList(),
const std::string &sessionId=std::string("") );
```

## Before you begin

Make sure you are using SmarTest 6.5.0 or later.

## Procedure

-  Prepare the parameters to be used for the API. You can refer to the code template below.

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams, outputResults;
inputParams["param1"] = "value_param1";
```

-  Execute the API with [query](<02.09.01.10.03.01.10_query.md>) and output the results.

```
Status retVal = query("API_to_execute", outputResults, inputParams, sid);
if ( retVal.isSuccess() )
{
cout<< "The execution result is "
    << outputResults["results1"] << endl;
}
```

## Results

The API is executed and outputs the results. An error object will be returned to indicate the execution status of the API.

## Example

The following example shows how to execute [GetSiteSetup()](<02.09.01.11.03.12.02_GetSiteSetup.md>) with query.

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList outputResults;
Status retVal = query("GetSiteSetup", outputResults, ParamList(), sid);
if ( retVal.isSuccess() )
{
cout<< "The site ID list is " << outputResults["SITE_ID_FOR_SITES"] << endl;
cout<< "The site setup list is " << outputResults["SITE_SETUP_FOR_SITES"]
    << endl;
}
```
