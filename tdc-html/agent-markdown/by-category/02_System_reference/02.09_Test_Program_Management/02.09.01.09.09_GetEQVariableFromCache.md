# GetEQVariableFromCache

For fast access to equation variables, some of them are cached, thus avoiding time-consuming inter-process communication.

This routine lets you retrieve the value of a variable from the cache, provided the variable has already been cached.

A variable is either

- a specification (the name is listed in the SPECS section of an equation definition) or
- a derived value (the name appears left to an "=" sign in the EQUATIONS section).Note You can also use [GetEQVariableValue](<02.09.01.09.10_GetEQVariableValue.md>) to cache a variable and retrieve its value in one call. [GetEQVariableFromCache](<02.09.01.09.09_GetEQVariableFromCache.md>)[,](<02.09.01.09.09_GetEQVariableFromCache.md>) however, should be used in combination with [InsertEQVariableInCache](<02.09.01.09.22_InsertEQVariableInCache.md>) if you need to ensure constant run-times for your test flow program.

## Syntax

```
VOID GetEQVariableFromCache(
    INT32      equation_system,
    INT32      equation_set,
    INT32      spec_set,
    INT32      site_number,
    CHAR     *variable_name,
    FLOAT64     *value,
    INT32     *return_state);
```

## Example

```
FLOAT64 variable_value;
INT32 re_state;
GetEQVariableFromCache(TIMING_EQ_SYSTEM,2,1,2,"var1",&variable_value,&re_state);
```
