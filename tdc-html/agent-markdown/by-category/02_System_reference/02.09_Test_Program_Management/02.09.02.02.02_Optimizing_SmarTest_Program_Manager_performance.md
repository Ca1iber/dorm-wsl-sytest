# Optimizing SmarTest Program Manager performance

The performance of SmarTest Program Manager (STPM) depends mostly on the speed of the processor but may also be restricted by the speed of the disks.

In general, STPM performs faster as the performance of the CPU increases, so you will want to use the fastest processor available to minimize conversion times.

However, if the disks used are not fast enough, disk performance may become a bottleneck, so that even a faster processor will not increase throughput greatly.

To avoid slowing down STPM because of insufficient disk performance, you can:

- Use fast drives, optimally 7200 rpm or faster SCSI or SATA drives.
- Put the V93000 master test program (MTP) on a different drive than the source test programs (STPs) that the STPM is to integrate.

## Functional changes

- Introduced in SmarTest 7.0.4
