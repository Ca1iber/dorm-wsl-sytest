# Shared pins table

The shared pins table of the MTPT (STPM MCM mapping tables) describes which levels and timings from the STPs (source test programs) are applied to shared pins in the MTP (master test program) for concurrent testing.

The table is stored in a file named sharedpins.csv in the MTPT directory. It is created by the [generate_template](<02.09.03.03.02_generate_template.md>) command.

To ensure a proper conversion, all shared pins must be listed in this table.

The file is best edited by importing it into the [OpenOffice spreadsheet](<02.09.03.04.15_OpenOffice_spreadsheet_for_editing_the_CSV_files.md>) located in the [MTPT](<02.09.03.04_MTPT__STPM_MCM_mapping_tables.md>) folder. Editing is also possible in text editors, but this requires you to make sure yourself that all formatting is correct.

## Syntax

Each row in the shared pins table describes the handling of one set of shared pins. The table contains these columns:

- CCT Group Name: The name of an MTP test group that contains concurrent tests

The name must appear in the MTP Parent Group column in the [Test mapping table](<02.09.03.04.04_Test_mapping_table.md>) and the mode specified for the group must be CCT.

- Shared DPS Pin/Port: The name of the shared pin or digital port

If a shared port is noted here, it must be listed in the MTP Pin[@shared port] column of the [Pin mapping table](<02.09.03.04.02_Pin_mapping_table.md>).

- Master STP: The name of the STP from which the timings and levels for this shared pin or port are imported.
- Notes: This column allows both you and STPM MCM to add remarks about the shared pin. These notes are just for human consumption and are never processed automatically by STPM MCM. They may be overwritten when the tables are updated, so they are not a suitable place for storing important information.
