# Parameter: electroglas_recipe_file

In case the parameter stepping_controlled_by is set to "learnlist", Electroglas probers based on the EG Commander Series firmware need a recipe file to store a temporary learnlist.

Driver default: no default

Changeable at run-time: no

Applicable for: Electroglas probers

Example: electroglas_recipe_file: "rpf"
