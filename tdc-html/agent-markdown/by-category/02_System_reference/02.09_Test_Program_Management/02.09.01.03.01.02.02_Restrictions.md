# Restrictions

For the GPIB interface to function correctly, it is important to observe the following rules:

- Only one piece of equipment can be connected to the system controller.

GPIB interfaces generally support interconnection on one bus for up to 15 devices. The system controller, however, must only be connected to one piece of equipment.

- The length of the cables between the system controller and the equipment must not exceed five meters.
- No more than one cable can be used between the system controller and the equipment.
