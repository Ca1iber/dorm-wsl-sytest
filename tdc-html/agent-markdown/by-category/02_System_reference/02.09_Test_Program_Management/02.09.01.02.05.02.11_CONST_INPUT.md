# CONST_INPUT

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.11.01_Associated_Syntax_Entities.md>)

This is used to set a constant value. You might have an application model file that is valid only for one type of prober; this type of prober can then be set using CONST_INPUT.

Including a line like this,

Prober_Type = CONST_INPUT (prober_1);

results in the value "prober_1" always being assigned to "Prober_Type".
