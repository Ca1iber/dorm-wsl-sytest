# Timing parameters

Make sure that the timing parameters are defined correctly, such as:

- test_start_relax_time
- bin_data_setup_time
- end_of_test_pulse_width
- bin_data_hold_time

For each configuration file, there is a debug configuration file with relaxed values. If your system does not work, you can try using the debug file.

The debug file differs from the default configuration file with its relaxed timing values and a higher debug level. The timing values of the default configuration file and the debug file can be found in [General Handler Driver](<02.09.01.03.06.01_General_Handler_Driver.md>). The higher debug level generates more extensive error messages.

The relaxed timing values result in a slower run time. The debug files should only be used for finding errors, not for normal operations, because the system will run at less than optimal speed.

If the driver runs under the debug file, you can try to isolate the problem by changing the relaxed parameters one by one until you have achieved the optimal setup. See the Prober/Handler Drivers guide for more information on changing parameters.
