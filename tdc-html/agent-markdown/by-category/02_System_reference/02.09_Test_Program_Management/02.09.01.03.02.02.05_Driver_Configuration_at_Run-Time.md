# Driver Configuration at Run-Time

From the application model, you can call driver functions which allow you to change the settings of driver configuration parameters at run-time, as illustrated in [Basic Driver Usage](<02.09.01.03.02.02_Basic_Driver_Usage.md>).

The new settings overwrite the configuration settings which are stored internally by the driver. The driver configuration loaded at driver start-up remains unchanged.

Changes at run-time can be done either with a function which directly sets the settings of individual configuration parameters (by providing the parameter names and the new settings as function parameters), or by a function which calls a configuration editor that lets you make changes to parameter settings (see [Changing the Driver Configuration at Run-Time](<02.09.01.03.03.04_Changing_the_Driver_Configuration_at_Run-Time.md>) for details).
