# NotifyDieStartedToSmartest

This notification command notifies the test start event for a die to SmarTest.

It is mainly used when the FA (Factory Automation) client maintains the level handling and SmarTest does not know the level change information. FA can tell its state to HVM API and SmarTest with using this API.

When executing this API, the event `DIE_STARTED` will be notified. Success will be returned if the command is successfully issued. Otherwise an error object will be returned indicating the error code, description and severity.

The FA maintains level handling.

## Prototype

```
ParamList eventParams;
string sessionId;
Status notify("EXECUTION", eventParams, sessionId);
```

## Example

```
ParamList eventParams;
string sessionID;
eventParams["EXECUTION_STATE"] = "WAFER_COMPLETED";
eventParams["LOT_ID"] = "lot_123";
eventParams["CASSETTE_ID"] = "cass1";
eventParams["WAFER_ID"] = "wafer-12345";
eventParams.setValueArray("SITE_ID_FOR_SITES", split("1 2 3 4", " "));
eventParams.setValueArray("SITE_SETUP_FOR_SITES", split("I I I X", " "));
eventParams.setValueArray("PACKAGE_ID_FOR_SITES", split("100 101 102 -1", " "));
eventParams.setValueArray("DIE_X_FOR_SITES", split("10 11 12 13", " "));
eventParams.setValueArray("DIE_Y_FOR_SITES", split("0 1 2 3", " "));
notify("EXECUTION", eventParams, sessionID);
```

Note `split()` is a user defined function to split the string into separate characters. This function is not provided in the HVM API library. You can define your own function to implement this capability.
