# Generating a List of Testsuites

## Use

long GetTestsuiteList(CI_CPI_TESTSUITE_LIST *testsuite_list)

This function can be used to generate a list of all testsuites and copy it to the caller-provided buffer *testsuite_list. See the definition of CI_CPI_TESTSUITE_LIST for a description of the list items.

The return value is the number of testsuites in the list or -1 if an error occurred.
