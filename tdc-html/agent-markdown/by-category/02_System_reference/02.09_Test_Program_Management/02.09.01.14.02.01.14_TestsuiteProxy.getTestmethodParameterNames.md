# TestsuiteProxy.getTestmethodParameterNames()

This function gets all the parameter names of the attached test method. The parameters are returned in the order of definition.

## Syntax

```
const std::vector<std::string> getTestmethodParameterNames();
```

## Functional changes

- Introduced in SmarTest 6.5.2
