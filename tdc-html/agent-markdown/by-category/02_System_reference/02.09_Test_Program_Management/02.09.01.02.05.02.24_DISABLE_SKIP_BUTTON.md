# DISABLE_SKIP_BUTTON

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.24.01_Associated_Syntax_Entities.md>)

Each of the SCREEN_DIALOG and LINE_DIALOG screens have a set of defined buttons associated with them. Which buttons appear also depends at what level (device, wafer, lot, etc.) the screen appears.

In certain circumstances you might not want the skip button (skips the present device) to appear; you should, therefore, include the command, DISABLE_SKIP_BUTTON, in that particular LINE_DIALOG or SCREEN_DIALOG.

In the following lines, DISABLE_SKIP_BUTTON has been added to the ON_PAUSE section of the wafer_auto application model. The resulting screen - upon pressing the pause button during a production run - does not have the skip button.

{ON_PAUSEpause:

ACTIONS

PROB_HND_CALL(red_alert);

SCREEN_DIALOG

reason_of_distortion=DIALOG_INPUT;

BUTTONcheck=CONST_INPUT(1);

BUTTONclean_pr=CONST_INPUT(1);

BUTTONreference=CONST_INPUT(1);

DISABLE_SKIP_BUTTON;

ACTIONS

PROB_HND_CALL(green_alert);

}
