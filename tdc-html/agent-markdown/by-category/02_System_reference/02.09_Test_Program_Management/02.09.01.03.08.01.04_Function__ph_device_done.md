# Function: ph_device_done

This function gets the binning and pass/fail information from SmarTest, applies a binning map on this data (optional), and tells the handler how to bin the tested devices.

ph_device_done is mandatory for handler based testing.

Applicable for: handler driver

Example: PROB_HND_CALL (ph_device_done)
