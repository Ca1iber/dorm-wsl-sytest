# Parameter: gpib-port

The GPIB port number of the prober or handler. The port number is specific to the handler/prober the test system is connected to. Thus, the port number must always be set correctly in the configuration file that is used with a particular combination of a test system and handler/prober.

Driver default: none; value must be defined in the driver configuration

Changeable at run-time: no

Applicable for: handlers and probers

Example: gpib-port: 22
