# Driver Installation

Equipment driver installation is performed by Advantest' customer support during installation of the test system.

 Note Installation of a new driver version will neither change the driver configurations you created, nor the attribute definitions of plug-ins you adapted for your special purposes. If you use [hook functions](<02.09.01.03.09_Using_Hook_Functions.md>) which enhance the driver according to your special needs, these functions will also remain unaffected.
