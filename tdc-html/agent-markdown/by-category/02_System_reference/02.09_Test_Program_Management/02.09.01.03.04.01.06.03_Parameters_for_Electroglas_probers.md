# Parameters for Electroglas probers

This parameter is valid only for Electroglas probers in the EG Commander Series.

- electroglas_recipe_file

This parameter contains the name of the recipe file that is needed to store a temporary learnlist (only in case the parameter stepping_controlled_by is set to learnlist).

- electroglas_send_setup_cmd

This parameter can be added to prevent the Electroglas SM15 setup response to messages command being sent. Must be set if an Electroglas 4080 prober is being used in conjunction with an Electroglas station controller.

- electroglas_query_die_position

This parameter may be added to enable the Electroglas probers to operate in a more efficient mode.
