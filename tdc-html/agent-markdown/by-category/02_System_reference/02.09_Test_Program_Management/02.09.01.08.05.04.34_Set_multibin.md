# Set multibin

## Use

`long SetMultiBin(const char* softbin, int hardbin);`

`long SetMultiBinOfSite(long site, const char* softbin, int hardbin);`

These functions set the software bin number and hardware bin number for the multibin. When a device reaches a multibin node in the testflow, it will be binned to the bin specified by this function or to the otherwise bin if the bin is not found.

To be compatible with STDF, the software bin number must be between 0 and 32767.

The first function works for the site currently in focus while the second function works for the specified site.

## Functional changes

- Introduced before SmarTest 6.3.2
