# calAge_check

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.08.01_Associated_Syntax_Entities.md>)

This expression is used in conjunction with MONITOR_CALL, and enables you to check on how long it has been since the tester was last calibrated. It must also be used in conjunction with calAge_limit (see later), which sets the length of time (in days) for which your current calibration is regarded as valid by the software.

What happens if the age of calibration exceeds the limits, is determined by the out of control rules - see ooc_warning_rule and ooc_stop_rule.

The line,

 x = MONITOR_CALL (calAge_check);

checks to see if the calibration is still valid.
