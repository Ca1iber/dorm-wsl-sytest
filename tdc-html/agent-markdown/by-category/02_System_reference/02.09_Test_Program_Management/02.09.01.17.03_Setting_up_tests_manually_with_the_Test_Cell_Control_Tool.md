# Setting up tests manually with the Test Cell Control Tool

Introduces how to set up and perform the HAND test, the PROER test and the HANDLER test manually in the Test Cell Control Tool.

## About this task

HAND test means the manual test you usually do in the engineering mode without communicating with the prober and the handler.

HANDLER test means the final test communicating with the handler.

PROBER test means the wafer test communicating with the prober.

## Before you begin

Make sure TCCT and the needed SmarTest version are installed.

## Procedure

-  [Start SmarTest and TCCT](<02.09.01.17.02_Starting_the_Test_Cell_Control_Tool.md>). The following actions are done in TCCT.

Make sure TCCT session is successfully attached to the SmarTest session. The status is shown in the lowest part of TCCT. "SmarTest XXX Attached" will be shown if it is successfully attached. Otherwise, you will see "SmarTest Session Detached".

-  To load the testflow to be executed, click the [Load Testflow](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>)button, select the testflow and click OK.

The selected testflow and all its setup files will be loaded. The location of the loaded testflow file will be displayed in the [Lot Summary](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) area below the Load Testflow button.

-  (For HANDLER or PROBER test) To set the equipment setting, click the Equipment tab and then click the [Equipment Setting](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) button.

Select PROBER or HANDLER as the test type and then select the configuration and click OK. The configurations are defined in the file /etc/opt/hp93000/tcct/equipment.xml. You can edit the file to add your own equipment configurations. (Refer to [Equipment configuration file](<02.09.01.17.10.03_Equipment_configuration_file.md>) for detailed explanation.)

-  To configure the data log settings, click the [Datalog Setup](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) button in the lower part of TCCT to bring up the Datalog Setup dialog.

In the dialog, you can set the data log profile, the data log output information and the lot summary information. (Refer to [Setting up the data log information](<02.09.01.17.08_Setting_up_the_data_log_information.md>) for details.)

-  To start a lot, click [New Lot](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) and enter the values for the variables listed in the Lot Information dialog.

You can edit the [configuration file of the dialog](<02.09.01.17.10.04_Lot_configuration_file.md>) to change the variables listed in the dialog.

-  To execute the loaded testflow, Click [Start Test](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>).

The text data log file is created. The binning information of the execution is displayed in the [Binning](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) area and counted in the [Binning Statistics](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) area.

-  (optional)If any error occurs, you can [debug the testflow in EWC](<02.09.01.17.06_Debugging_the_testflow_during_tests_with_the_Test_Cell_Control_Tool.md>) or [disable some sites](<02.09.01.17.07_Changing_the_site_control_during_tests_with_the_Test_Cell_Control_Tool.md>) before further testing. For the PROBER and the HANLER test, you need to click [Pause Test](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) before debugging.
-  (optional) If you want to generate the partial lot summary for the tested devices, click [Partial Summary](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) in the lower part of TCCT. For the PROBER and the HANLER test, you need to click [Pause Test](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) before this.

The partial lot summary is generated in the lot summary file you specified in the Datalog Setup dialog.

-  (optional)To continue the tests for other devices in the lot, click [Start Test](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) for the HAND test and click [Resume](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) for the PROBER and the HANDLER test.
-  When the execution of the whole lot is completed, click [End Lot](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>).

The lot summary file and the STDF data log file you specified will be generated.

## Results

The lot summary file and the data log files can be generated as specified. The binning statistics and the yield are shown in the main GUI of TCCT.

## What to do next

Check and analyze the test results.
