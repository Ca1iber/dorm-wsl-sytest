# Creating a test table from a test program template

You can create a SmarTest test table from a TPT (test program template) by specifying in the TPT test table which settings you want to include.

## About this task

Note This topic describes creating a SmarTest test table (as described in [Working with test tables](<../02.10_Data_Logging/02.10.01.08.03_Working_with_test_tables.md>)), not an STPM test table (as described in [Test table](<02.09.02.05.03_Test_table_of_a_TPT.md>)).

Set up the creation of a SmarTest test table when you want to specify test limits and other parameters in SmarTest through test tables.

## Before you begin

Create a test program template and fill in the TPT tables.

## Procedure

-  In the TPT [test table](<02.09.02.05.03_Test_table_of_a_TPT.md>), set the Source column to "Test table" for all tests that you want to control through a test table.
-  Save the TPT test table.

## Results

When STPM generates a test program (using the [tpt_generate_tp](<02.09.02.03.20_tpt_generate_tp.md>) command), it will automatically create a SmarTest test table for all tests where "Test table" is the specified source. Likewise, the [tpt_add_test](<02.09.02.03.18_tpt_add_test.md>) and [tpt_replace_test](<02.09.02.03.19_tpt_replace_test.md>) commands will update the SmarTest Test table where specified.

## What to do next

Generate or update the test program.

## Functional changes

- Introduced in SmarTest 7.2.1
