# TestsuiteProxy.isPass()

This function gets the pass/fail result of the test suite execution. True is returned when the execution passed or the set_pass flag is on. False is returned when the execution failed, the set_fail flag is on or the test suite is not executed.

## Syntax

```
bool isPass(const int site) const;
```

Parameters
 |

site

 |

The site to query.

 |

## Functional changes

- Introduced in SmarTest 6.5.2
