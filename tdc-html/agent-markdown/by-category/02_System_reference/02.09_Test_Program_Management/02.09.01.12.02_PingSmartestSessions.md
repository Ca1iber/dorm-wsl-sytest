# PingSmartestSessions

This data query command acquires the life cycle of each SmarTest session that is visible.

Here the term "visible" means that any SmarTest related graphical window (like sa_splash, the report window, SmarTest Work Center, and so on) is visible to you. The visible SmarTest sessions cover three kinds of situations:

- The session is just launched from the shell console, some graphical window is already visible to you but it is not fully functional.
- The session is fully ready and functional (The event SMARTEST_SESSION_READY has been notified).
- The session is shutting down, but not completed. In another word, the SmarTest session is still regarded as "visible" at the moment before the last window (like the report window) disappears.

Another two status used for SmarTest session are `ACTIVE` and `INACTIVE`.

`ACTIVE` status indicates that the core processes like sa (hp83000), mcd(event notification infrastructure) are alive.

`INACTIVE` status means some core processes are not available. For example, during the session startup, the session ID is already available, but the ATE-Server is not available, and this is regarded as `INACTIVE` status.

SUCCESS is always returned for the execution.

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

qrResults

 |

The query result is a `ParamList` object. It contains the following members:

- SESSION_ID_LIST: The ID list of the visible SmarTest sessions.
- LIFE_STATUS_LIST: A string value indicating the status of a SmarTest session. It can be `ACTIVE` or `INACTIVE`. The elements of `SESSION_ID_LIST` and `LIFE_STATUS_LIST` have 1:1 mapping.
 |

Prototype

```
ParamList qrResults;
string sessionId;
Status query("PingSmartestSessions", qrResults);
```

## Example

```
ParamList qrResults;
query("PingSmartestSessions", qrResults);
vector<string> idList = qrResults.valueArray("SESSION_ID_LIST");
vector<string> lifeStatusList = qrResults.valueArray("LIFE_STATUS_LIST");
for (unsigned int i=0; i< idList.size(); i++)
{
string sid = idList[i];
string lifeStatus = lifeStatusList[i];
cout << "the session id "<< sid << " has the life status "
<< lifeStatus << endl;
}
```
