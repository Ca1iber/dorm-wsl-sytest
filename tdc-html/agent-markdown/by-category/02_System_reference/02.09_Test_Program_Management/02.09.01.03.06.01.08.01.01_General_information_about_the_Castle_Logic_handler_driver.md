# General information about the Castle Logic handler driver

This section provides general information about the Delta Design Castle Logic handler driver.

## Configurations provided

The following configurations are provided with the driver:

- Castle-GPIB-1.cfg
- Castle-GPIB-2.cfg
- Castle-GPIB-4.cfg
- Castle-GPIB-8.cfg

The configurations differ only in the number of sites they provide.

## Supported handler models

The Castle handler driver supports all Delta Design Castle Logic handler models.
