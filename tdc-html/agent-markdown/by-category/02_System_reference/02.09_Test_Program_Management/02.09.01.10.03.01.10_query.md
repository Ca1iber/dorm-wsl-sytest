# query

The query signature is for the data query command of HVMAPI.

The signature is run in synchronous manner. It will get the execution result immediately.

An error object will be returned indicating the successful execution of operation execution the error occurs.

Prototype

```
xoc::hvmapi::Status query(
const std::string &qrName,
xoc::hvmapi::ParamList &qrResults,
const xoc::hvmapi::ParamList &qrParams=xoc::hvmapi::ParamList(),
const std::string &sessionId=std::string("") );
```

Parameters
 |

qrName

 |

The HVM API query command name.

 |
 |

qrResults

 |

The output results represented by `ParamList`.

 |
 |

qrParams

 |

(optional) The input parameters represented by `ParamList`.

 |
 |

sessionId

 |

(optional) The ID of the SmarTest to work with.

 |

## Example

```
paramList qrResults;
Status query("ListInstalledSmartestVersions", qrResults);
```
