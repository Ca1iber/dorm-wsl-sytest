# Command Call Syntax

The syntax of a command call written in the application model file is as follows:

```
<var> '=' <set_identifier> '(' <command_and_parms> ');'
<set_identifier> ::= D_BRIDGE_CALL | PRB_HND_CALL | EXEC_INP_CALL
<command_and_parms> ::= <cmd> [<spc><parm>]..[&]
<var>  ::= [a-zA-Z1-9!"$%'*+-./:<=>[\]^_{|}~]..
<cmd>  ::= [a-zA-Z1-9!"$%'*+-./:<=>[\]^_{|}~]..
<spc>  ::= [space | tab]..
<parm> ::= [a-zA-Z1-9!"$%'*+-./:<=>[\]^_{|}~]..
```

In the following example, the command promptforinput is executed. The command implementation is located in the Command Set as selected in the Test Program Explorer under the Execution Input icon. The command is given the argument NAME. Any result generated by execution of the command is assigned to the ModelFile variable inputname (see [Writing a Function](<02.09.01.08.03.01_Writing_a_Function.md>) for details).

```
inputname = EXEC_INP_CALL(promptforinput NAME);
```
