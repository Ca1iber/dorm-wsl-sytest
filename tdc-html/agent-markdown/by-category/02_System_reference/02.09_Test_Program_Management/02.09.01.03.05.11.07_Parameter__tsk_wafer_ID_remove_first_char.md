# Parameter: tsk_wafer_ID_remove_first_char

This parameter specifies whether the first character in the WaferID string is removed or not. If this parameter is set to yes, the first character will be removed from the WaferID string.

Some TSK probers have a firmware bug that inserts the b WaferID command in front of the actual WaferID string. For example, if WaferID is "1234", the returned string would be "b1234". By setting this parameter to "yes", the first character will be removed from the WaferID string.

Driver default: "no"

Applicable for: TSK probers

Example: tsk_wafer_ID_remove_first_char: "no"

## Functional changes

- Introduced in SmarTest 7.4.4
