# TestsuiteProxy.setMultiportTiming()

This function sets multi-port timing to the test suite.

## Syntax

```
bool setMultiportTiming(const std::string& multiportSpec, const std::string& timingSet);
```

Parameters
 |

multiportSpec

 |

The multi-port spec.

 |
 |

timingSet

 |

The timing set.

 |

## Functional changes

- Introduced in SmarTest 6.5.2
