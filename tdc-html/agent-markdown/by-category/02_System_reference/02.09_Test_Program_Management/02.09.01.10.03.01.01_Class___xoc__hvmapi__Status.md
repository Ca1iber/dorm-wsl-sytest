# Class ::xoc::hvmapi::Status

The `::xoc::hvmapi::Status` class provides the error object (return status) which is returned from the HVMAPI execution.

An error object contains three aspects:

- `Severity`: The severity of error object.
- `Code`: The error sub-classification. (For error code definition, see the alarm code definition in [ALARM_NOTIFICATION](<02.09.01.10.03.02.02.09_ALARM_NOTIFICATION.md>) )
- `Text`: The error description, represented with the plain text.

## Enumeration

This enumeration defines the severity of the error object.

```
Severity{
      SEVERITY_NONE,
      SEVERITY_RECOVERALBE,
      SEVERITY_UNRECOVERABLE
     };
```

### isError()

`bool isError(void) const;`

This function checks whether any error occurred in the HVMAPI execution. It returns true, if any error occurs. Otherwise false is returned.

### isSuccess()

`bool isSuccess(void) const;`

This function checks whether the signature returns successfully. It returns true if no error occurs, otherwise false is returned.

### Example

The following example defines an object `errObj` of the class `xoc::hvmapi::Status`. This error object is used to display the execution result of the query command `GetOnlineSmartestSessionID`.

```
xoc::hvmapi::Status errObj;
xoc::hvmapi::ParamList params, results, qrResults;

errObj = query("GetOnlineSmartestSessionID", qrResults);
if (errObj.isSuccess())
{
    cout << "online session ID is: " << qrResults["SESSION_ID"] << endl;
}
else
{
    cout <<" error to get online session  " << endl;
    cout <<" the code is " << errObj.code() <<endl;
    cout << " the text is " << errObj.text() << endl;
}
```
