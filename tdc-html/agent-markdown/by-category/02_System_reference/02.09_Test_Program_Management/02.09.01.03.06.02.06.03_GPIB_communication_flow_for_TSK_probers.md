- `bbbb`: The raw setting temperature string.

## Ignored SRQs

Note The [listed STB codes](<02.09.01.03.06.02.06.02.01_Configuration_at_the_prober.md>) are SRQs used by the TSK driver. Those which are not listed do not contribute to the driver functionalities, but if the driver receives such SRQs, it cannot interpret the purpose of the SRQs and will pop up a Prober Not Understood dialog. You can then safely abort the test program by clicking the only Quit button on the dialog. The table below lists SRQs from the prober that are silently (hard-coded) ignored by the driver. Even these SRQs are turned on by the prober, the driver will ignore upon receiving them (warning/error messages will be printed).

To avoid the pop-up of Prober Not Understood dialogs when the driver receives those unused SRQs, you can:

- Use the driver's ignored_SRQs parameter in the configuration file to specify a list of such SRQs.
- Set up the SRQ to 0 on the prober side.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.2.3: (Patch 2) Removed ignored prober SRQ 0x59.
[1)](<>) That whether W or b is sent depends on the setup (W by default) of tsk_wafer_ID_command in configuration files:TSK probers can be configured to use either the W or the b command to perform a wafer ID request or a probe needle cleaning. This parameter defines which command, W or b, should be sent to perform a wafer ID request. The other command is then used for the probe needle cleaning. The default parameter is W if not specified.
