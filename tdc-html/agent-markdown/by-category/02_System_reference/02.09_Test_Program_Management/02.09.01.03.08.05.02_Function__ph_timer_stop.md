# Function: ph_timer_stop

This function stops the last started timer and returns the time (in seconds) elapsed since the start of that timer.

The returned time is assigned to the calling variable (time in the example below).

This assignment will automatically be logged to the data log stream of event data logging (see the [Event Data Logging Format (EDF)](<../02.10_Data_Logging/02.10.01.06_Event_Data_Logging_Format__EDF.md>)).

Applicable for: handler and prober driver

Example:

```
time = PROB_HND_CALL (ph_timer_stop)
```

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.0: GDF logging in application model is obsolete.
