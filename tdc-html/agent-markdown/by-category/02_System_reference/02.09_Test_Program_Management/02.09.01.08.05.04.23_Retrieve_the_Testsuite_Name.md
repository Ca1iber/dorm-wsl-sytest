# Retrieve the Testsuite Name

This function returns the name of the testsuite that contains the current user procedure. The pointer testsuiteName points to a user-provided area to which the testsuite name is copied. The area must be able to hold at least CI_CPI_MAX_TESTSUITE_LEN characters.

## Syntax

```
long GetTestsuiteName(char *testsuiteName)
```

## Example

The following example shows how this function is used:

```
char current_testsuite_name[CI_CPI_MAX_TESTSUITE_LEN];
.
.
.
/* The testsuite name is printed in the report window */
GetTestsuiteName(current_testsuite_name);

fprintf(stdout, "Current testsuite is %s\n", current_testsuite_name);
```
