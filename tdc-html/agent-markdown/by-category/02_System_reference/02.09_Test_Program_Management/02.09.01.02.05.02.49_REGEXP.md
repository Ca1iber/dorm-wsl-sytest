# REGEXP

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.49.01_Associated_Syntax_Entities.md>)

This regular expression specifies a type of format, used in conjunction with the various INPUT expressions (DIALOG_INPUT, LINE_INPUT, etc). This regular expression can be an integer, a real number, a string, or a <formatstring>. The line below is a typical example of REGEXP.

* Operator_id = DIALOG_INPUT / REGEXP(string);
