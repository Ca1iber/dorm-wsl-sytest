# TestsuiteProxy.getTestmethodUserDefinedLimitNames()

This function gets all limit names defined in the test methods of the test flow.

## Syntax

```
const std::vector<std::string> getTestmethodUserDefinedLimitNames() const;
```

## Functional changes

- Introduced in SmarTest 6.5.2
