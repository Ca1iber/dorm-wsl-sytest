# ooc_stop_rule

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.45.01_Associated_Syntax_Entities.md>)

The ooc_stop_rule keyword is used as an argument for [GET_TEST_INFO](<02.09.01.02.05.02.36_GET_TEST_INFO.md>) to return the elements of the current out-of-control stop rule, as defined in the Global OOC Rule page of the testflow editor.

## Functional changes

- Introduced before SmarTest 6.3.2
