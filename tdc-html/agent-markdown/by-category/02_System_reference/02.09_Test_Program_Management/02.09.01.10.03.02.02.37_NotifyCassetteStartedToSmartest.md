# NotifyCassetteStartedToSmartest

This notification command notifies the Cassette start event to SmarTest.

It is mainly used when the FA (Factory Automation) client maintains the level handling and SmarTest does not know the level change information. FA can tell its state to HVM API and SmarTest with using this API.

When executing this API, the event `CASSETTE_STARTED` will be notified. Success will be returned if the command is successfully issued. Otherwise an error object will be returned indicating the error code, description and severity.

## Dependency

The FA maintains level handling.

## Parameters

 |

I/O

 |

Parameters

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The ID of the SmarTest session to notify.

 |
 |

I

 |

EVENT_NAME

 |

The event category. Here it is always `EXECUTION`.

 |
 |

I

 |

EVENT_BODY

 |

The event parameters. It contains the following members:

 |

EXECUTION_STATE

 |

The HVM event name. Here it is always `CASSETTE`_STARTED.

 |
 |

LOT_ID

 |

The current lot ID.

 |
 |

`CASSETTE_ID`

 |

The ID of the cassette which is completed.

 |

This parameter is represented by `ParamList` whose key and value are both `string` type.

 |

## Prototype

```
ParamList eventParams;
string sessionId;
Status notify("EXECUTION", eventParams, sessionId);
```

## Example

```
ParamList eventParams;
string sessionID;
eventParams["EXECUTION_STATE"] ="CASSETTE_STARTED";
eventParams["LOT_ID"] = "lot_12345";
eventParams["CASSETTE_ID"] = "cass1";
notify("EXECUTION", eventParams, sessionID);
```
