# GPIB configuration for Electroglas probers

#### Subtopics

- [Configuration at the prober](<02.09.01.03.06.02.05.02.01_Configuration_at_the_prober.md>)

This section describes

- the settings that must be carried out at the prober, and
- the variables used in the configuration files.

When you are setting up GPIB communications between the test station and an Electroglas prober, you must make sure that the settings are as listed here.
