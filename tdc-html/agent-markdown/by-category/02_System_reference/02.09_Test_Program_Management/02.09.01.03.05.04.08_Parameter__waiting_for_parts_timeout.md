# Parameter: waiting_for_parts_timeout

The time in seconds which the driver will wait for a new part (for handlers: the next device; for probers: the next die) from the equipment. If this time is exceeded (timeout), a message will be generated by the driver, and the action defined by the parameter waiting_for_parts_timeout_action will be taken (see above).

Driver default: 30 for handlers, 120 for probers

Changeable at run-time: yes

Applicable for: handlers and probers

Example: waiting_for_parts_timeout: 90
