# ResetBLCProfile()

This API must be called at the end of the BLC execution.

The behavior of `ResetBLCProfile` includes:

- Reset the level model shared memory
- Reset the test type to package test
- Set the SmarTest state to `IDLE`
- Reset the system control flags
- Issue the `TESTPROGRAM_COMPLETED` or `TESTPROGRAM_ABORTED` HVM events if the implicit event generation is turned on.
- Issue the `TestProgramEndEventType` EDL event if the implicit event generation is turned on.

SUCCESS will be returned if no error occurs. Otherwise, an error object is returned indicating the error code, description and severity.

## Prototype

```
Status syncCommand("ResetBLCProfile", ParamList(), sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID;
Status retVal = syncCommand("ResetBLCProfile", ParamList(), sid);
if ( retVal.isError() )
{
cout<<"error code= " << retVal.code() << " description="
   << retVal.text() << endl;
}
```
