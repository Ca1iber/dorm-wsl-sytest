# setActiveSites()

This API sets the active sites.

If the specified site is not enabled, this API will enable it and then activate it. If the specified site is not available, an error message will be sent out without changing the sites.

## Syntax

```
void setActiveSites(const std::set<int>& sites);
```

Parameters
 |

sites

 |

The site number stored in `set<int>`.

 |

## Example

```
set<int> sites;
sites.insert(1);
sites.insert(3);
setActiveSites(sites);
```

In this example, site 1 and 3 are set to active.
