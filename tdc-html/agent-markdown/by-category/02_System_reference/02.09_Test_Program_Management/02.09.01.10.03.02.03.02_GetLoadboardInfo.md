# GetLoadboardInfo

This data query command gets the load board ID.

The load board ID is retrieved from load board EEPROM. If the load board has no EEPROM, the ID will be retrieved from the application model file variable. The application variable must be named as one of `LOADBOARD_ID`, `ph_LOADBOARD_ID`, `BOARD_ID` or `ph_BOARD_ID`. If neither EEPROM installed nor application variable set, this API will return empty result.

SUCCESS will be returned if the command is successfully issued. Otherwise an error object will be returned indicating the error code, description and severity.

## Dependency

The load board hardware has the EEPROM, that contains the load board ID information. Or the qualified application model variable is set.
