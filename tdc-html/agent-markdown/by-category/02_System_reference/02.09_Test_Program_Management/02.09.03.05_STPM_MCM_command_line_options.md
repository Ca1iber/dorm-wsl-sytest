# STPM MCM command line options

The basic operation of the SmarTest Program Manager MCM (STPM MCM) is controlled with command line options.

The detailed actions that STPM MCM performs are described in a [control file](<02.09.03.03_STPM_MCM_control_file.md>) that is specified on the command line using the -setup option (see below).

## Syntax

```
stpm_mcm[-help][-version][-timestamp][-licwait][-debug][-template][-setup <control_file>]
```

The parameters have these effects:

- -help: Displays online help. No files are processed, and no file needs to be specified.
- -version: The version of STPM MCM is output to STDOUT.
- -timestamp: A time stamp is added to each line that is output to STDOUT.
- -licwait: If no license is currently available, STPM MCM waits until one becomes available.

If this option is not used, STPM MCM exits with an error message when no license is available.

- -debug: Intermediate file are generated to make debugging easier. What specific files are generated depends on the operations specified in the control file.
- -template: A template for a [control file](<02.09.03.03_STPM_MCM_control_file.md>) is created. No conversion is performed and no control file needs to be specified.

The template file is located in the templates subdirectory of the current directory. For creating a mapping table (MTPT) template, see the [generate_template](<02.09.03.03.02_generate_template.md>) control file command.

- -setup: The control file to use. You can specify the file using a relative or absolute path; relative paths are based on the current directory.

See [STPM MCM control file](<02.09.03.03_STPM_MCM_control_file.md>) for a description of control files.

All of the parameters are optional. Specifying no parameter at all is the same as specifying `stpm_mcm -help`.

## Example

This example launches STPM MCM with the control file MCM/CreateNewMaster.py. If no license is available, STPM MCM will exit without creating a result:

```
stpm_mcm -setup setup/CreateNewMaster.py
```
