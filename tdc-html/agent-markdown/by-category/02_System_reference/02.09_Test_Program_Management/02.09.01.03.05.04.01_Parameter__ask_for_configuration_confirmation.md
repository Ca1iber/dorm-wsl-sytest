# Parameter: ask_for_configuration_confirmation

At driver start-up (ph_driver_start call from the application model) the operator may be asked to confirm the current configuration.

If the operator confirms the configuration, equipment operation starts. Otherwise, the test program is aborted.

The driver will only ask for configuration confirmation, if also the parameter log_configuration is set to "yes". This prints the current configuration file to the report window, and this way allows the operator to check the configuration before confirming it.

Driver default: "no"

Changeable at run-time: no

Applicable for: handlers and probers

Example: ask_for_configuration_confirmation: "yes"
