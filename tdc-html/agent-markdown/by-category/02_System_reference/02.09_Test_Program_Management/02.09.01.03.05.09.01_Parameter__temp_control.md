# Parameter: temp_control

If this parameter is set to "manual", no temperature settings will be sent to the equipment at all. All other temperature configurations are ignored.

If set to "ambient", the equipment will be initialized in a way that deactivates all temperature control and the devices will be tested at ambient temperature. All other temperature configurations are ignored.

If set to "active" the equipment will be initialized to perform active temperature control of devices as defined with the additional configuration parameters. If not given, "manual" is assumed.

Driver default: "manual"

Changeable at run-time: yes

Applicable for: handlers and probers, plug-in dependent

Example: temp_control: "active"
