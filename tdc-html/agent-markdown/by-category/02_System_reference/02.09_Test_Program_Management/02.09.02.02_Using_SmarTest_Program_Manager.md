SmarTest Program Manager (STPM) is controlled from the command line interface (for more information, see [STPM command line options](<02.09.02.06_STPM_command_line_options.md>)). The details of its operation are determined by the contents of its [control file](<02.09.02.03_STPM_control_file.md>).

## Running STPM

You run STPM from the command line. The details of the operation it is to perform are found in the control file that is specified as a command line argument:

- The SmarTest device directory that STPM is to modify
- The operations that you want STPM to perform (adding tests, adding tests to bursts, replacing tests, removing tests) and the test on which you want to perform them
- A reference to the [merge rules file](<02.09.02.04_STPM_merge_rules_file.md>) to use for the operation

## Results

STPM updates the SmarTest device directory, including (among others):

- Testflow file (.tf)
- Timing file (.tim)
- Configuration file (.ch)
- Levels file (.lev)
- Pattern binaries (.binl)
- Pattern master file (.pmfl)
