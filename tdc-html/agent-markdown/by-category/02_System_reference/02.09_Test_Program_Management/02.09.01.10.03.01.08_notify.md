# notify

The notify signature is for the notification commands of HVM API and enable the customer production software to proactively notify its state to SmarTest. The notify signature is run in synchronous manner.

Prototype

```
xoc::hvmapi::Status notify(
const std::string &evName,
const xoc::hvmapi::ParamList &evParams,
const std::string &sessionId );
```

Parametes

 |

evName

 |

The HVM API event category.

 |
 |

evParams

 |

The input parameters represented by `ParamList`.

 |
 |

sessionId

 |

The ID of the SmarTest session to work with.

 |

## Example

```
ParamList eventParams;
string sessionId;
Status notify("EXECUTION", eventParams, sessionId);
```
