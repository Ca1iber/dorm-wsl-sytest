# Configuration Parameters for Equipment Identification

#### Subtopics

- [Parameter: handler_family](<02.09.01.03.05.01.01_Parameter__handler_family.md>)
- [Parameter: prober_family](<02.09.01.03.05.01.02_Parameter__prober_family.md>)
- [Parameter: model](<02.09.01.03.05.01.03_Parameter__model.md>)

 Note When no further specification is necessary, handlers and wafer probers are simply referred to as 'equipment' in this manual

These parameters tell the driver which equipment is connected. The parameters are also used to verify whether the combination of plug-in and driver configuration, which was selected in the global configuration, is valid.
