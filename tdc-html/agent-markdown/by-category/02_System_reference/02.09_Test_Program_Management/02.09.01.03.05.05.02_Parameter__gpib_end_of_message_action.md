# Parameter: gpib_end_of_message_action

At the end of messages being send out by the GPIB interface to a prober or handler, the GPIB interface asserts the EOI control line to indicate the end of the message. This line remains asserted until the next communication occurs on the GPIB bus.

It has been reported that some probers or handlers do not work properly with the EOI line remaining asserted (seen at Electroglas 4080 prober in conjunction with a Electroglas station controller). In that case it is necessary to actively release the EOI line after the end of a message by enforcing a void communication on the GPIB bus. This may be achieved by performing a single serial poll (serial-poll) which results in the release of the EOI line. The default is not to perform any end of message action (none) and leave the EOI line asserted.

 Note To use this parameter in the configuration, you need to first add it into the shattrib file of the prober/handler driver.

Driver default: "none"

Changeable at run-time: no

Applicable for: probers and handlers

Example: gpib_end_of_message_action: "serial-poll"
