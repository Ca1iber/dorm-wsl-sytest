# Function: ph_device_start

This function tells the handler to insert the next (set of) devices into the sockets (if the handler is capable of processing this command), and waits either until the handler notifies that the insertion of devices is done, or until a waiting-for-parts timeout occurs (see [Parameter: waiting_for_parts_timeout](<02.09.01.03.05.04.08_Parameter__waiting_for_parts_timeout.md>)).

ph_device_start is mandatory for handler based testing.

Applicable for: handler driver

Example: PROB_HND_CALL (ph_device_start)
