# How to disable the interactive windows

The interactive windows that may pop up during the SmarTest startup include the splash screen, the device locking window and the device changing window. To avoid the interaction with these windows, you need to disable these windows before starting SmarTest.

## About this task

The splash screen appears during SmarTest startup to indicate the SmarTest version you are using. You need to click the OK button to make it disappear. To make the splash screen disappear automatically, you can use the environment variable SA_NO_SPLASH.

Note The splash screen will disappeared automatically after SmarTest is started for SmarTest 6.5.2 or later versions. So you can omit the step to disable the splash screen for these versions.

The device locking window pops up when there is a lock_file in the device you want to use. To make sure the device locking window does not pop up, you need to remove the lock_file in the device you want to use.

The device changing window pops up when the device in the device_in_use cannot be load correctly. To make sure that the device changing window will not pop up, you can use a safe device in the .device_inuse_soc@<hostname> file. This safe device is an empty device.

## Before you begin

Prepare a dummy device to be used as the safe device.

## Procedure

- Set a value to the environment variable SA_NO_SPLASH. Any value is useful.
- Change the device in use to the safe device.

  - Open the .device_inuse_soc@<hostname> file in your home directory.
  - Modify the .device_inuse_soc@<hostname> file with the safe device. The format of the path is device_path/waste.

- Remove the device locking file of the safe device
- Remove the device locking file of the target device.

## Results

The interactive windows are disabled and will not appear during the SmarTest startup and device changing.

## Examples

### Set a value to SA_NO_SPLASH

setenv("SA_NO_SPLASH",1);

This will disable the appearance of the splash screen during SmarTest startup.

### Change the device in use to the safe device

The following example is to disable the device changing window.

```
int switchDeviceInUse(string &safeDevicePath)
{
  struct stat stat_buf;
  char *HomeDir;
  ofstream devInUseFs;
  //  This is the SmarTest default device startup file name
  //  that will be added to the User's HOME directory path.
  string dotDevInUseFileName("/..device_inuse_soc@<hostname>");

  //   Get the HOME directory from the system ENV variable.
  if((HomeDir = getenv("HOME")) == (char *)NULL)
  {
     cerr <<  "Smartest_Server:switchDeviceInUse  $HOME variable does not exist!" << endl;
     return -1;
  }

  //  create the .device_inuse_soc@<hostname> full path name based
  //  on the value of the HOME env variable content.
  dotDevInUseFileName.insert(0,HomeDir);

  devInUseFs.open(dotDevInUseFileName.c_str(),ios::out);

  if (!devInUseFs.is_open())
  {
     cerr <<  "Smartest_Server:switchDeviceInUse  could NOT open .device_inuse_soc@<hostname> file" << endl;
     return -1;
  }
  else
  {
    /**
     *  Write the new information into the .device_inuse_soc@<hostname> file...
     *
     *  NOTE:   We need to append the "/waste" directory to the full
     *          device path, as required by SmarTest.
     **/
     safeDevicePath.append("/waste");
     //first check that the device exists
     if(stat(safeDevicePath.c_str(), &stat_buf))
     {
       cerr << "Smartest_Server:switchDeviceInUse - the device called for  "
            << safeDevicePath << " does not exist" << endl;
       return -1;
     }

    devInUseFs << safeDevicePath << endl;
    devInUseFs.close();
    cerr <<"Smartest_Server:switchDeviceInUse successfully modified"<< endl;
  }
  return 0;
}
```

### Remove the lock_file

The following example is to disable the device locking window.

```
int removeLockFile(string &Device)
{
  string filename;
  string command;
  struct stat stat_buf;

  filename.assign(Device);
  filename.append("/lock_file");

  if(stat(filename.c_str(), &stat_buf))
  {
    cerr << "Smartest_Server:removeLockFile -  no lock file to remove" << endl;
    return 0;
  }

  command.assign("rm -rf ");
  command.append(filename);

  if(system(command.c_str()))
  {
    cerr << "Smartest_Server:removeLockFile - command to remove lock file "
         << filename<< " failed" << endl;
  }
  else
  {
       //file removed
  }

  if(stat(filename.c_str(), &stat_buf))
  {
    cerr << "Smartest_Server:removeLockFile - lock file "
         << filename << " was removed" << endl;
      return 0;
  }

  cerr << "Smartest_Server:removeLockFile - could not remove lock file" << filename << endl;
  return -1;
}
```
