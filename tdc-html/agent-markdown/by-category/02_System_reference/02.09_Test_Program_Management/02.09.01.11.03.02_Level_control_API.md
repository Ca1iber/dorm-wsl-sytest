# Level control API

#### Subtopics

- [StartLevel()](<02.09.01.11.03.02.01_StartLevel.md>)
- [LoopLevel()](<02.09.01.11.03.02.02_LoopLevel.md>)
- [CompleteLevel()](<02.09.01.11.03.02.03_CompleteLevel.md>)

If you want to maintain the application model file level structure in the BLC, you can use the level control APIs.

If no level structure is maintained but the level related events need to be issued, the level information should be provided as input parameters to the event generation API. (See [IssueEDLEvent()](<02.09.01.10.03.02.02.29_IssueEDLEvent.md>) and [IssueHVMExecutionEvent()](<02.09.01.10.03.02.02.28_IssueHVMExecutionEvent.md>))

## Functional changes
