# Writing a Program with more than one Sourcefile

If you want to develop a single command comprising more than one source file, then it must be developed in a separate directory and the resulting executable program copied to the Command Set directory.

- Type the following to create a directory where the program is to be developed:

 mkdir /opt/hp93000/soc/PH_LIBS/.example

- Type the following to move to the new directory:

cd /opt/hp93000/soc/PH_LIBS/.example

- Create a Makefile as follows:

mkmf

- Add/change the Makefile as follows:

###

PROGRAM = a.out

OBJS = a.o pg_templ.o

a.o: a.h

pg_templ.o: a.h

###

CC=/opt/hp93000/soc/com/lbin/CC_hp83000

CXX=/opt/hp93000/soc/com/lbin/CCP_hp83000

CFLAGS=-I /opt/hp93000/soc/pws/lib \

-I /opt/hp93000/soc/prod_com/include \

-I /opt/hp93000/soc/com/include \

-I /opt/hp93000/soc/mix_sgnl/include

CXXFLAGS=-I /opt/hp93000/soc/pws/lib -I /opt/hp93000/soc/prod_com/include \

-I /opt/hp93000/soc/com/include -I /opt/hp93000/soc/mix_sgnl/include

LD = /opt/hp93000/soc/com/lbin/CCP_hp83000

LDFLAGS = -Wl,-B,immediate -Wl,-a,shared \

-L /opt/hp93000/soc/prod_com/sh_lib \

-L /usr/lib/X11R5

SH_LIBS = -lcicpi -lX11

SHELL = /usr/bin/sh

all: $(PROGRAM)

$(PROGRAM): $(OBJS) $(LIBS)

 @echo "Linking $(PROGRAM) ..."

 @$(LD) $(LDFLAGS) $(OBJS) $(LIBS) $(SH_LIBS) -o $(PROGRAM)

 @echo "done"

clean:; @rm -f $(OBJS) core

clobber:; @rm -f $(OBJS) $(PROGRAM) core tags

The above makefile is an example to produce one executable a.out from a.h, a.c and pg_templ.c. Change the file names between ### and ### corresponding to your program files.

- Develop your programs as described previously in this section.
- Type

make depend

and then

make all install
