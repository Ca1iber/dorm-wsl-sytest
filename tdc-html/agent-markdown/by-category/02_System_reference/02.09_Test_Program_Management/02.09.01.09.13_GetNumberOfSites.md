# GetNumberOfSites

This routine is used for multisite testing. It lets you retrieve the number of sites that are currently configured.

## Syntax

```
VOID GetNumberOfSites(
    INT32     *number_of_sites);
```

## Parameters

On return, number_of_sites specifies the number sites currently configured.

## Example

```
INT32 MaxSitesEnabled;
GetNumberOfSites(&MaxSitesEnabled);
```

## Functional changes

- Introduced before SmarTest 6.3.2
