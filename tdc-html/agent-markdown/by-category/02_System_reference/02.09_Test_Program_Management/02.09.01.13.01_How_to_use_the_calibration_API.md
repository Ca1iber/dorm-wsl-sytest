# How to use the calibration API

This section describes how to use the calibration API to check the calibration status and history.

## Before you begin

- Make sure you are using SmarTest 6.1.3 or later versions.
- To use the functionality of get calibration history, make sure you are using SmarTest 6.5.0 or later versions.
- Make sure an online SmarTest session is running.

## Procedure

-  Create your C++ program with the provided API functions.

Include the header file /opt/hp93000/soc/pws/include/calibration.h.

Example programs are provided in the directory  /opt/hp93000/soc/pws/calibration/Example.

-  Compile and link your program.

 Link the program with the library /opt/hp93000/soc/pws/sh_lib/libmcpub.so.

For example, if you use Makefile, type in make in the Linux command line. An example Makefile is provided in the directory

/opt/hp93000/soc/pws/calibration/Example.

-  Execute the program to check the calibration status.

## Results

The calibration status is printed in the report window.

## Example

See the provided example programs and Makefile in the directory /opt/hp93000/soc/pws/calibration/Example.

## Functional changes

- Introduced before SmarTest 6.3.2
