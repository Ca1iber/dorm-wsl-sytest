# How to issue a syncOperation

[syncOperation](<02.09.01.10.03.01.12_syncOperation.md>) is used to synchronously execute a control command which has output values. The BLC APIs which use syncOperation include [CallPHDriverFunc()](<02.09.01.11.03.05.02_CallPHDriverFunc.md>), [CallExecInputFunc()](<02.09.01.11.03.05.04_CallExecInputFunc.md>) and [CallDataBridgeFunc()](<02.09.01.11.03.05.06_CallDataBridgeFunc.md>).

## About this task

The prototype of the [syncOperation](<02.09.01.10.03.01.12_syncOperation.md>) is:

```
xoc::hvmapi::Status syncOperation(const string &opName,ParamList &opResults,
const ParamList &opParams=ParamList( ),const string &sessionID=string(""));
```

## Before you begin

Make sure you are using SmarTest 6.5.0 or later.

## Procedure

-  Prepare the parameters for the BLC API. You can refer to code template below.

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams;
inputParams["param1"] = "value_param1";
inputParams["param2"] = "value_param2"
```

-  Execute the API with [syncOperation](<02.09.01.10.03.01.12_syncOperation.md>) and output the results.

```
ParamList outputResults;
Status retVal = syncOperation("API_to_execute", outputResults,
                              inputParams, sid);
if ( retVal.isSuccess() )
{
cout<<"The output value is" <<  outputResults["output_value"] << endl;
}
```

## Results

The API is executed and the result values are outputed. An error object will be returned indicating the execution status of the API.

## Example

The following example shows how to execute the API [CallPHDriverFunc()](<02.09.01.11.03.05.02_CallPHDriverFunc.md>) which needs parameters and return values.

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList inputParams, outputResults;
inputParams["FUNCTION_NAME"] = "ph_get_status";
inputParams["PARAMETER"] = "die_height"
Status retVal = syncOperation("CallPHDriverFunc", outputResults,
                          inputParams, sid);
if ( retVal.isSuccess() )
{
cout<<"The "die_height =" <<  outputResults["OUTPUT_STRING"] << endl;
}
```
