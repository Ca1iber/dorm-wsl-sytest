# NotifyWaferCompletedToSmartest

This notification command notifies the Wafer complete event to SmarTest.

It it mainly used when the FA (Factory Automation) client maintains the level handling and SmarTest does not know the level change information. FA can tell its state to HVM API and SmarTest with using this API.

When executing this API, the event `WAFER_COMPLETED` will be notified. Success will be returned if the command is successfully issued. Otherwise an error object will be returned indicating the error code, description and severity.

## Dependency

The FA maintains level handling.
