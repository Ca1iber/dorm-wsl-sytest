# Changing the site control during tests with the Test Cell Control Tool

When you get the yield alarm or consecutive failure alarm on some specific site(s), you may want to disable these sites and only execute the testflow on the good site(s).

## Procedure

-  In the [Binning](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) area of TCCT, click the site number(s) you want to disable.
-  The disabled sites will be grayed out in the [Binning](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) area and [Binning statistics](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) area. Note It will not enable or disable the sites on probers and handlers. The enabled sites in TCCT may not match the enabled sites in the Site Control window in the EWC because they are not synchronized.

## Results

The testflow will be executed only on the enabled sites.

## Functional changes

- Introduced in SmarTest 7.2.0
- SmarTest 7.2.0: in patch 2, site control is moved to the Binning area in TCCT 1.1
