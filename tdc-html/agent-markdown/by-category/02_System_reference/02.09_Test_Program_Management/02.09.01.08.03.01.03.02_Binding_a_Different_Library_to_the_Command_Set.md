# Binding a Different Library to the Command Set

If you use a function defined in a library other than libcifset.sl, you must add a line in the Makefile to specify the library.

To do this:

- Open the Makefile
- Add the full path of the library to the LIBS line in the Makefile
- Save the Makefile
- Type make clean all at the command line.

For example, to use a function defined in the library lib_x.a, located at /opt/hp93000/soc/user_libs/, the Makefile must contain the line:

LIBS = /opt/hp93000/soc/user_libs/lib_x.a
