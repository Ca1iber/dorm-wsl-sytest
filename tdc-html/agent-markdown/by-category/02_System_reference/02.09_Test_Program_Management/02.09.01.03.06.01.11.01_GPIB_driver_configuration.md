# GPIB driver configuration

The GPIB driver configuration currently supports the handler model MR5800, M660 and M330.

The following configurations are provided for the driver:

M5800-GPIB-32.cfg

M660-GPIB-16.cfg

M330-GPIB-32.cfg

## Default GPIB configuration

When the configuration files were created, certain aspects necessarily had to be defined. The table below lists these aspects and how they were defined.
