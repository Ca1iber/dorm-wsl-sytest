# Creating a New Driver Configuration

#### Subtopics

- [Selecting a configuration file](<02.09.01.03.04.02.01_Selecting_a_configuration_file.md>)
- [Editing the configuration file](<02.09.01.03.04.02.02_Editing_the_configuration_file.md>)
- [Producing a debug file](<02.09.01.03.04.02.03_Producing_a_debug_file.md>)
- [Testing and debugging the configuration](<02.09.01.03.04.02.04_Testing_and_debugging_the_configuration.md>)

This section provides basic guidelines for creating a new configuration file based on the available default configuration files.

The following steps are recommended when creating a new configuration file:

- Selecting a configuration file
- Editing the configuration file
- Producing a debug file
- Testing and debugging the configuration
- Presence of a test system ready line
- Presence of a test complete line
- Presence of a bin parity line
