# GetInstrumentInfoById

This data query command gets the external instrument information with specified instrument ID.

SUCCESS will be returned if the command is successfully issued. Otherwise an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" is not online session ID.
- The designated instrument ID "XXX" does not exist .
 |

RECOVERABLE

 |

## Dependency

An online SmarTest session is running.

## Parameters

 |

I/O

 |

Parameters

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The online session ID.

 |
 |

I

 |

INSTRUMENT_ID

 |

The ID of the external instrument to query.

 |
 |

O

 |

qrResults

 |

The query results are represented by a `ParamList` object. It contains the following members:

GPIB_ADDRESS: The GPIB address of the external instrument.

DESCRIPTION: The general description of the external instrument. Currently it only includes the identification of the instrument.

 |

## Prototype

```
ParamList qrResults, qrParams;
string sessionId;
Status query("GetInstrumentInfoByID", qrResults,  qrParams, sessionId);
```

## Example

```
ParamList qrResults, qrParams;
string sid;
qrParams ["INSTRUMENT_ID"] = "IID_1";//Value from GetTesterInfo API
query("TetInstrumentInfoByID", qrResults, qrParams, sid);
printf("The information for the instruments <IID_1> is:\n");
printf("  <GPIB_ADDRESS>: %s\n", qrResults ["GPIB_ADDRESS"]);
printf("  <DESCRIPTION>: %s\n", qrResults ["DESCRIPTION"]);
```
