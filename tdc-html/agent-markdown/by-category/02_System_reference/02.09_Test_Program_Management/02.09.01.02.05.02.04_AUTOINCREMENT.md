# AUTOINCREMENT

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.04.01_Associated_Syntax_Entities.md>)

This increments (by 1) a parameter value; this parameter must be an integer.

A typical use for this command might be to create an order in a package_manual test, where each package has no explicit ID. For example,

package_id=AUTOINCREMENT;

SET_PACKAGE_ID({package_id});
