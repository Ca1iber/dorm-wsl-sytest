# Installing the Test Cell Control Tool

The Test Cell Control Tool(TCCT) can be installed separately through its own installation package.

## Before you begin

Make sure you have TCCT installation package and the root user authority.

## Procedure

-  Switch to the root user (in a shell type su -).
-  Search and uninstall the old version with the command like below.

```
$ rpm -qa|grep tcct
$ rpm -e v93000_tcct-1.2-el5
```

-  To install TCCT, enter the command like below in a shell.

```
rpm -ivh v93000_tcct-1.9.8_20200511-el7.x86_64
```

The name of the installation package may be different for different versions.

## Results

The Test Cell Control Tool is installed.

## Functional changes

- Introduced in SmarTest 7.2.0
