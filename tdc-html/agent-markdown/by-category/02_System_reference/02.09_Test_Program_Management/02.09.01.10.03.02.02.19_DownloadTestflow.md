# DownloadTestflow

This remote control command tries to download a specified test flow to the tester.

Downloading a test flow involves downloading of all setup files used in the test flow. During the downloading procedures, the status will be notified by asynchronous event. The figure below shows the sequence of the events coming up.

 ![Events in downloading a test flow](<../../../../raw/97056.png>)

The `SETUPFILE_DOWNLOAD_STARTED` and `SETUPFILE_DOWNLOAD_COMPLETED` will occur several times because the downloading of each setup file will make these two events notified.

SUCCESSwill be returned if the command is successfully issued. Otherwise an error object indicating the error code, description and severity will be returned.

## Dependency

A device is already set for the SmarTest session.

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The ID of the SmarTest session to work with.

 |
 |

I

 |

TESTFLOW_NAME

 |

The name of the test flow to download.

   | Note If no testflow name is specified, [LoadTestflowSync](<02.09.01.10.03.02.02.30_LoadTestflowSync.md>)/[LoadTestprogramSync](<02.09.01.10.03.02.02.31_LoadTestprogramSync.md>) should be called before this API or a test flow should have been loaded in SmarTest. If a test flow name is specified, the setups specified in the test flow will be downloaded.

## Prototype

```
ParamList cmdParams;
string sessionId;
Status command("DownloadTestflow", cmdParams, sessionId);
```
