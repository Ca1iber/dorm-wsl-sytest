# User String

## get

IsUserStringDefined checks whether the variable with the name *name is defined. It returns 0 when not defined, and returns 1 when defined.

GetUserString retrieves the current value of the user defined variable, *name, and copies it to the string pointed to by *value. The variable must have been declared as a string.

GetUserStringOfSite lets you specify which site should be used (1,2,...), while GetUserString assumes the site currently in focus (for example during sequential User Procedure execution). In case of single site test the first site is always in focus. Use a "string" constant to identify the variable required.

GetAllStringTestflowVariables retrieves the names and values of all the user-defined STRING type testflow variables and stores them in the relevant C structure.

This function writes a maximum CI_CPI_MAX_USER_STRING_LEN + 1 bytes to the pointer *value.

```
int IsUserStringDefined(char *name)
long GetUserString(char *name, char *value)
long GetUserStringOfSite(char *name, long site, char *value)
long GetAllStringTestflowVariables( CI_CPI_STRING_TFL_VAR_LIST *string_tfl_var_list)
```

The values returned are as follows,

 |

0

 |

ok

 |
 |

1

 |

error on a name/type

 |
 |

-1

 |

internal error

 |

The following example shows how the function `GetUserString()` is used.

```
void CiExample2(char  *parm_list_input,
  int    parmcount,
  char  *comment_out,
  int   *comlen,
  int   *state_out)
{
  /* A variable name is to be passed as parameter */

  long   type;
  long   flag_var;
  double double_var;
  char   str_var[CI_CPI_MAX_USER_STRING_LEN+1]
  *comment_out='\0';
  *comlen=0;

  if (GetUserType(param_list_input,&type))
     {
     Errorhandling("Cannot retrieve variable type.");
     *state_out=CI_TEST_FAIL;
     return;
     }

  switch(type)
    {
    case CI_CPI_DBL:
      {
        GetUserDouble(param_list_input,&double_var);
        fprintf(stderr,"Value of %s is %lf.\n",
                 param_list_input,double_var);
      }

    case CI_CPI_FLG:
      {
        GetUserFlag(param_list_input,&flag_var);
        fprintf(stderr,"Value of %s is %ld.\n",
                 param_list_input,flag_var);
      }

    case CI_CPI_STR:
      {
        GetUserString(param_list_input,str_var);
        fprintf(stderr,"Value of %s is \"%s\".\n",
                 param_list_input,str_var);
      }

    }
  *state_out = CI_CALL_PASS;
}

```

The next example shows how the function `GetAllStringTestflowVariables()` is used.

```
CI_CPI_STRING_TFL_VAR_LIST string_tfl_var_list;
CI_CPI_STRING_TFL_VAR *pTflVar;
int i = 0;
If (GetAllStringTestflowVariables(&string_tfl_var_list)==0 )
{
  for (i=0; i< string_tfl_var_list.number_of_string_tfl_vars; i++)
  {
    pTflVar = & string_tfl_var_list.string_tfl_vars[i];
    printf("the STRING Testflow Variable name is %s\n", pTflVar ->name);

  }
}
```

## set

SetUserString sets the value of the user defined variable, *name with the string value.

SetUserStringOfSite lets you specify which site should be used (1,2,...), while SetUserString assumes the site currently in focus (for example during sequential User Procedure execution). In case of single site test the first site is always in focus.

Use a "string" constant to identify the variable required.
