# Wafer related API

#### Subtopics

- [EvalWaferDescriptionFile()](<02.09.01.11.03.09.01_EvalWaferDescriptionFile.md>)

This wafer related API is provided to load and parse the wafer map file.

For wafer sort, the test result window will show the wafer sort result, otherwise, the package test result will be displayed.

## Functional changes

- Introduced in SmarTest 6.5.0
