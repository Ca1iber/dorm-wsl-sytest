# How to execute a BLC from command line

The BLC execution file can be executed as a stand alone program from the command line.

## About this task

To execute a BLC from the command line, the BLC input file can be used as an input parameter to the BLC executable file.

## Before you begin

Make sure a SmarTest session is running and you are using SmarTest 6.5 or above versions.

## Procedure

 Execute the BLC executable as below:

```
$ /opt/hp93000/soc/system/bin/run -x <full_path_of_the_blc_executable_file>
 [-- full_path_of_the_blc_input_file]
```

Note If you want to use both the workorder and command line to execute a BLC, make sure the BLC input file is the only input parameter of the BLC executable file or no input parameter is needed by the BLC executable file.

## Results

The BLC is executed and the device is tested.

## Functional changes

- Introduced in SmarTest 6.5.0
