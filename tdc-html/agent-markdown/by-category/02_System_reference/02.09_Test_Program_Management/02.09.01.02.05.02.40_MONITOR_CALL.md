# MONITOR_CALL

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.40.01_Associated_Syntax_Entities.md>)

Calls the internal system monitor in order to watch the different variables of the tester state and to set limits for these variables. These variables can be,

- age of calibration
- board temperature
- dps current
- a "diagnostic-done" flag (unlike the other variables, this is a simple flag that returns a yes or no result)

For example,

{lot:

MONITOR_CALL(brd_temp_limit,-2.0,2.0);

MONITOR_CALL(dps_current_limit,0.9)

defines limits for the monitor warnings, while,

{WAFERwafer:

*temp_ok=MONITOR_CALL(brd_temp_check);

checks the board temperature at the start of the wafer and returns the logged state, and,

{die:

MONITOR_CALL(dsp_current_check);

checks the DPS current limits but does not return the logged state; the tester does stop testing though, if the defined limits are exceeded.

The line,

MONITOR_CALL(diagnostic_check);

simply checks if the diagnostics have been done or not.
