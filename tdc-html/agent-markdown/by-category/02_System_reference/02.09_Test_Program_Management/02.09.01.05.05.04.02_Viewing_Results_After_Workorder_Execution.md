# Viewing Results After Workorder Execution

After workorder execution, results are accessible in the two files described below.

Additionally, there can be data log files generated by Event Datalogging.

 |

Lot Summary file

 |

The lot summary file generated by the [LotSummaryGenerator](<../02.10_Data_Logging/02.10.01.07_LotSummaryGenerator.md>).

 |
 |

Workorder Status File

 |

The purpose of the workorder status file is to store a report about a production run.

It consists of detailed information about date and time, when the workorder was executed, duration of workorder execution, device under test, test program, test flow, application model, etc. This file is created automatically when you execute a workorder. The file can be found in

~/workorder/wo_status/. See section [Executing a Workorder From the Command Line](<02.09.01.05.05.02_Executing_a_work_order_from_the_command_line.md>).

Each time the same workorder is executed, the suffix is incremented.

When executing a workorder, a workorder status file is created in $HOME/workorder/wo_status/<workorder_name>_xx

(xx being a number), and is also sent to the report window.

 |

Where the data goes depends on what flags you set during workorder execution (see [Accessing Testflow Settings](<02.09.01.06.02_Accessing_Testflow_Settings.md>)).

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.1.0: GDF logging in application model is obsolete.
- SmarTest 7.1.0: Lot summary file is generated by LotSummaryGenerator.
