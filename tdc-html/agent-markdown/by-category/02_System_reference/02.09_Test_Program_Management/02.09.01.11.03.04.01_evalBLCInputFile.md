# evalBLCInputFile()

This API validates and parses the BLC input file. The content of the input file will be returned as a map. This is a standard C++ function and can be called directly from the BLC executable file (not through `synOperation` or `synCommand` signature).

SUCCESS will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

The input file "XXX" does not follow the standard format in XXX line.

 |

 |
 |

 |

 |

## Prototype

```
string inputFile;
ParamList inputFileEntry;
Status evalBLCInputFile(inputFile, inputFileEntry);
```

## Example

```
ParamList inputFileEntry;
Status retVal = evalBLCInputFile(string(argv[1]), inputFileEntry);
if ( retVal.isSuccess() )
{
cout<<"PH_LIB= " << inputFileEntry["PH_LIB"] <<endl;
cout<< "PRE_TESTFLOW" << inputFileEntry["PRE_TESTFLOW"] <<endl;
}
```
