# Execute a TestFlow

The ExecTestFlow and ExecTestFlowSync functions execute the testflow currently loaded in the Test Program Explorer that is the same function as the execute all option in the TestFlow Editor. After a testflow is started, ExecTestFlow does not wait for the end of the testflow execution, and ExecTestFlowSync waits for the end of the testflow execution.

long ExecTestFlow()

long ExecTestFlowSync()

For executing testmethod-based testsuites, you can also use the Hardware Response Emulator for importing a hardware response data file that is generated by storing the actual measurement data or software simulation data. For more details of the Hardware Response Emulator, see the Test Method Programming Reference manual.

The ExecTestFlowImport and ExecTestFlowSyncImport functions execute the testflow currently loaded in the Test Program Explorer and start the Hardware Response Emulator for importing a hardware response data file for testmethod-based testsuites. After a testflow is started, ExecTestFlowImport does not wait for the end of the testflow execution, and ExecTestFlowSyncImport waits for the end of the testflow execution.

long ExecTestFlowImport()

long ExecTestFlowSyncImport()

The ExecTestFlowStore and ExecTestFlowSyncStore functions execute the testflow currently loaded in the Test Program Explorer and start the Hardware Response Emulator for storing the actual measurement data or software simulation data to a file for testmethod-based testsuites. After a testflow is started, ExecTestFlowStore does not wait for the end of the testflow execution, and ExecTestFlowSyncStore waits for the end of the testflow execution.

long ExecTestFlowSyncStore()
