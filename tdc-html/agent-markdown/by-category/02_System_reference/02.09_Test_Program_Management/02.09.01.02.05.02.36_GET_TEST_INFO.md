# GET_TEST_INFO

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.36.01_Associated_Syntax_Entities.md>)

GET_TEST_INFO returns information about the environment in which the application model is executed;which you can assign to a variable for further processing, for example, to use it as part of a file name.

Which information the function returns is governed by the keyword it is passed as its argument. These keywords are supported:

- [date_time](<02.09.01.02.05.02.13_date_time.md>): current date and time
- [dev_name](<02.09.01.02.05.02.14_dev_name.md>): device name from the testflow's information screen
- [dev_rev](<02.09.01.02.05.02.15_dev_rev.md>): device revision from the testflow's information screen
- [device](<02.09.01.02.05.02.16_device.md>): device name from the current device directory
- [ooc_stop_rule](<02.09.01.02.05.02.45_ooc_stop_rule.md>): elements of the global OOC stop rule
- [ooc_warning_rule](<02.09.01.02.05.02.46_ooc_warning_rule.md>): elements of the global OOC warning rule
- [smartest_rev](<02.09.01.02.05.02.56_smartest_rev.md>): revision of the active SmarTest
- [test_desc](<02.09.01.02.05.02.59_test_desc.md>): test description from the testflow's information screen
- [test_rev](<02.09.01.02.05.02.60_test_rev.md>): test revision from the testflow's information screen
- [tester_id](<02.09.01.02.05.02.61_tester_id.md>): the id of the tester on which the test program is executed
- [testprog](<02.09.01.02.05.02.62_testprog.md>): the name of the current test program
- [user_id](<02.09.01.02.05.02.63_user_id.md>): the log-in name of the active user

For examples, see [Example application models](<02.09.01.02.04.01_Example_application_models.md>).

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.4: Added device, smartest_rev, tester_id, and user_id keywords
