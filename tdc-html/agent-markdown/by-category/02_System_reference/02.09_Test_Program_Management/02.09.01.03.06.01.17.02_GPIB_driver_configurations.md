# GPIB driver configurations

#### Subtopics

- [GPIB communication flow for Synax handlers](<02.09.01.03.06.01.17.02.01_GPIB_communication_flow_for_Synax_handlers.md>)

This section provides general information about the Synax GPIB handler drivers. Currently the drivers support SX1101, SX1701, and SX2400 models.

The following configuration files are provided with the drivers:

- SX1101-GPIB-1.cfg

SX1101-GPIB-2.cfg

SX1101-GPIB-4.cfg

- SX1701-GPIB-1.cfg

SX1701-GPIB-2.cfg

SX1701-GPIB-4.cfg

- SX2400-GPIB-1.cfg

SX2400-GPIB-4.cfg

## Default GPIB Configuration

When a configuration file is created, some aspects need to be defined. The table below lists these aspects and how they are defined.

Important aspects of Synax configuration files
 |

Aspect

 |

Used setting

 |
 |

Debug level

 |

0

It will log only basic messages, can be changed to a value between -1 and 4.

 |
 |

GPIB port used

 |

1

The setting must be changed to correct value based on the handler's setup.

 |
 |

Bin mapping

 |

default

 |
 |

Number of bins

 |

32 (SmarTest hardbins 0 through 31), bin 0 represents the SmarTest reset bin.

 |
 |

Reprobe mode

 |

Automatic reprobe on a per site mode, if devices fall into SmarTest reprobe bins.

 |
 |

Reprobe bin number

 |

31, represents number sent to handler upon receiving a SmarTest reprobe bin. It must be changed to correct value according to set up of handler. Note that the reprobe mechanism refers to the disconnection and re-connection of the device before a retest is performed.

To disable this setting remove the `handler_reprobe_bin` parameter and set the `automatic_reprobe_mode` to "off"

 |
 |

Test start detection

 |

Done by interrupt (SRQ), can be changed to pure polling mode with given polling interval for troubleshooting.

 |
 |

Polling interval

 |

The default value is 200 ms, only used if waiting for parts is done by polling.

 |
