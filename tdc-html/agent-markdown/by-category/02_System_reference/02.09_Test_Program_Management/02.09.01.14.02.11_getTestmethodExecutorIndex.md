# getTestmethodExecutorIndex()

This API queries the index number of the UTM executor currently in use.

The index number of the UTM executor is returned. It can be:

`1`: the first executor, for production execution.

`2`: the second executor, for test debug purpose and non-production execution.

## Syntax

```
int getTestmethodExecutorIndex();
```
