# Function: ph_list_equipment

List the IDs of the current running equipment and query the status of the Generic prober/handler drivers.

The result is in the format of equ`ipmentID:ENABLE_DISABLE:ERROR_STATE_OF_LAST_FUNCTION_CALL`.

Applicable for: probers and handlers

Example: PROB_HND_CALL(ph_list_equipment)

Result example: MT1:enabled,normal MT2:enabled,error MT3:disabled,normal

The result means MT1 is enabled and the last function call returns CI_CALL_PASS, MT2 is enabled and the last function call returns fail and MT3 is disabled.

## Functional changes

- Introduced in SmarTest 7.2.2
