# Setting the Testsuite Flag of All Sites in Test

Changes the default behavior of the Connect() function.

## Use

long SetTestsuiteFlagOfAll(char *flag, long value)

Sets the testsuite flag *flag of all testsuites and all sites to value.

The returned values are,

 |

0

 |

OK

 |
 |

!=0

 |

an error has occurred

   |
