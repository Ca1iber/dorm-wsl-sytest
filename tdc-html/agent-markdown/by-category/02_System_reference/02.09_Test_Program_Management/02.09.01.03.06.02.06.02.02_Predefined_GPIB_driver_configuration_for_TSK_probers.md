   |   [1)](<#fnsrc_1>) Must be changed to the correct value, based on prober's configuration.[2)](<#fnsrc_2>) For the probers with multi-die probing and SmarTest-controlled stepping, the parameter dont_bin_dies is set as default to yes, so that the binning data will not be overwritten with empty bins in the case that dies are reprobed.[3)](<#fnsrc_3>) Recommendation: First start SmarTest's test program, then start lot at prober.
