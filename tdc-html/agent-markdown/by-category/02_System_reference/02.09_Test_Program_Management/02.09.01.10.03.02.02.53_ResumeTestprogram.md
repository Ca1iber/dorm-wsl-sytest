# ResumeTestprogram

This remote control command tries to resume the execution of a test program that is paused previously. If the test program has not been paused, this command has no impact on the test program execution.

Success will be returned if the command is successfully issued. Otherwise an error object indicating the error code, description and severity will be returned.

 |

Code

 |

Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- Cannot resume the test program execution because there is no test program currently paused.
 |

RECOVERABLE

 |

## Dependency

The test program is paused.

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The ID of the SmarTest session to work with.

 |

## Prototype

```
string sessionId;
Status command("ResumeTestprogram", ParamList(), sessionId);
```
