# DEVICE_TEST

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.18.01_Associated_Syntax_Entities.md>)

This statement is the lowest level of your application model. It specifies that the testflow (defined in the test program you are executing) will be executed. The following example shows that there are some pre- and post-actions around the DEVICE_TEST.

{DEVICEdie:

ACTIONS

SET_TEMPERATURE({Temperature});

PROB_HND_CALL(get_die);

LOG_SPECIFICATION

RESULT_LOG=ON;

{

DEVICE_TEST

}

REPROBE_ACTION=PROB_HND_CALL(reprobe);

--die

ACTIONS

PROB_HND_CALL(remove_die);

}
