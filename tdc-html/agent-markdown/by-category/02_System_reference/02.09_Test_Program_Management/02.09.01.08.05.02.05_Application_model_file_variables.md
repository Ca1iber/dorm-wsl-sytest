# Application model file variables

## get

long GetModelfileString(char *name, char *value)

Retrieves the current value of the application model file variable named *name and copies it to the string pointed to by *value. Application model file variables are implicitly declared as strings.

This function writes a maximum CI_CPI_MAX_MODL_STRING_LEN + 1 bytes to the pointer *value.

Use a "string" constant to identify the variable required.

## set

long SetModelfileString(char *name, char *value)

Sets the value of the model file variable named *name to the string pointed to by *value.
