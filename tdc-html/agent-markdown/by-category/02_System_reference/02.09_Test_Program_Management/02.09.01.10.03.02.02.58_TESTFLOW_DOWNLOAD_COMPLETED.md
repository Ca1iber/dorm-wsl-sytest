# TESTFLOW_DOWNLOAD_COMPLETED

This event indicates that a test flow downloading has been finished.

## Dependency

The API `DownloadTestflow` is called.

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

SESSION_ID

 |

The ID of the SmarTest session this event belongs to.

 |
 |

O

 |

TIME_STAMP

 |

The time point when this event occurs. It contains two long-type parts: `SECONDS` and `MICROSECONDS`.

 |
 |

O

 |

EVENT_NAME

 |

The event category. Here it is always `EXECUTION`.

 |
 |

O

 |

EVENT_BODY

 |

The event parameters. It contains the following members:

 |

`EXECUTION_STATE`

 |

The HVM event type. Here it is always `TESTFLOW_DOWNLOAD_COMPLETED`.

 |
 |

`DEVICE_PATH`

 |

The current device path.

 |
 |

`DEVICE_NAME`

 |

The device name in use.

 |
 |

`TESTFLOW_NAME`

 |

The name of the test flow downloaded.

 |

This parameter is represented by `ParamList` whose key and value are both `string` type.

 |
