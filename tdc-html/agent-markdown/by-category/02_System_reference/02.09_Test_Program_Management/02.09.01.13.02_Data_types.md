# Data types

The data types defined for the calibration API are listed below.

## CalStatusEvent

```
typedef enum
{
    CAL_EVENT_LAST,
    CAL_EVENT_NEXT,
    CAL_EVENT_NOW

} CalStatusEvent;
```

CAL_EVENT_LAST always returns "01.01.1900" with SmarTest 7.10.

CAL_EVENT_NEXT shows the date and time of next calibration.

CAL_EVENT_NOW shows the current calibration status.

## CalStatusType

```
typedef enum
{
    CAL_TYPE_FULL,
    CAL_TYPE_UPDATE

} CalStatusType;
```

CAL_TYPE_FULL queries the status of a full calibration.

CAL_TYPE_UPDATE queries the status of an update calibration.

## CalibrationCategory

```
typedef enum CalibrationCategory
{
    CoreCalibration,
    AuxCalibration,
    CompleteCalibration,
    UpdateCalibration,
    FirstCalibrationCategory = CoreCalibration,
    LastCalibrationCategory  = UpdateCalibration
};
```

CoreCalibration means the mandatory parts of a full calibration.

AuxCalibration means the optional parts of of a full calibration.

CompleteCalibration means all parts of a full calibration (CoreCalibration + CompleteCalibration).

UpdateCalibration means the DC update calibration.

FirstCalibrationCategory and LastCalibrationCategory defines the begin and end of a calibration category.

## Functional changes

- Introduced before SmarTest 6.3.2
