# dev_name

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.14.01_Associated_Syntax_Entities.md>)

The dev_name keyword is used as an argument for [GET_TEST_INFO](<02.09.01.02.05.02.36_GET_TEST_INFO.md>) to return the name of the current device as entered in the Device Name field of the Information screen of the testflow editor.
