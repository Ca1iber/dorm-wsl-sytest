# The Command Set

A Command Set is a set of user-written commands that is called from the application model file or from the testflow.

Command sets can be located in the following test setup components:

- when called from the application model:

  - Data Bridge
  - Execution Input
  - Prober/Handler

- when called from the testflow:

  - User Procedure
