# eventLoop

This signature is to start an HVMAPI internal event loop. The main job of event loop is to execute the particular event listener when the corresponding event occurs in HVMAPI internal execution thread. Calling this function will make the client give the control to the HVMAPI internal thread. The client execution will be blocked until exiting from the event loop.

An error object will be returned indicating the success of this API call or the error occurs.

Prototype

```
xoc::hvmapi::Status eventLoop();
```
