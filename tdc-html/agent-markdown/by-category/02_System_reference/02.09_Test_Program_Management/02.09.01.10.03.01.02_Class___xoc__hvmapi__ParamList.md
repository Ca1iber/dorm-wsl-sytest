# Class ::xoc::hvmapi::ParamList

The `::xoc::hvmapi::ParamList` class provides the parameter representation for all signatures, including the input value (like command parameter, query parameter, notify parameter) and output value (like query result, event body of event notification).

`::xoc::hvmapi::ParamList` implements the container of `<key, value>` pair similar to `std::map`. In comparison with the `std::map`, it also supports the `value` with `std::vector<std::string>` type and the `key` with type of `std::string`.

## Constructor

### ParamList ();

This constructs a `ParamList` object which provides the parameter representation for all signatures.

### ParamList (const ParamList& obj);

This constructs a `ParamList` object by copying from another defined object.

### getKeys()

```
const std::vector<std::string> getKeys() const;
```

This function returns all the parameter keys contained in a `ParamList` object. You can access all the parameter values using the parameter keys. An empty vector will be returned if there is no parameter key assigned to the given `ParamList ` object.

### Example

The following example shows how to set and get values with the member functions of `ParamList`.

```
::xoc::hvmapi::ParamList param param1;
param.setValue["SESSION_ID"] = "sid1";
std::string value1 = param.value("SESSION_ID");

param["SESSION_ID"] = "sid2";
std::string value2 = param["SESSION_ID"];

std::vector<std::string> values;
values.push_back("6.2.0");
values.push_back("6.2.1");

param1.setValueArray("INSTALLED_VERSION_LIST", values);

vector<string> keys = param1.getKeys();
// to display the values of the keys
for ( vector<string>::iterator it=keys.begin(); it != keys.end(); it++)
{
  cout <<"the keys: "<< *it << endl;
  // if the keys has value array
  if (param1.hasValueArray(*it))
  {
    vector<string> values=param1.valueArray(*it);
    for(vector<string>::iterator itr=values.begin(); itr != keys.end(); itr++)
    {
      cout << values.value(*itr) << endl;;
    }
  }
 // if the keys has a single value
 else
 {
    cout << param1.value(*it) << endl;
 }
}
```
