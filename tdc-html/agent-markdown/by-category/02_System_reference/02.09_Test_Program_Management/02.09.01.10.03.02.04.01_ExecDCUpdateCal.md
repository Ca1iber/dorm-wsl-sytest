# ExecDCUpdateCal

This synchronous control command runs DC update calibration and returns the calibration execution result.

 Note The command is kept in SmarTest 7.10 for compatibility, but will always return SUCCESS.SUCCESS will be returned if no error occurs. Otherwise an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- The designated session ID "XXX" is not online session ID.
 |

RECOVERABLE

 |

## Dependency

The specified SmarTest session is an running online session.

## Parameters

 |

I/O

 |

Parameters

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The online SmarTest session ID.

 |
 |

O

 |

qrResults

 |

The query results are represented by a ParamList object. It contains the following member:

 |

CAL_EXEC_STATUS

 |

The calibration execution status, `PASS` or `FAIL`. `PASS` means that the calibration is successfully finished and the calibration data file is saved accordingly. Any other situation is considered as `FAIL`.

For SmarTest 7.10 the status will always be `FAIL`.

 |

 |

## Prototype

```
ParamList opParams, opResults;
Status syncOperation("ExecDCUpdateCal", opResults, ParamList(), sessionID);
```

## Example

```
ParamList opResults;
Status retVal = syncOperation("ExecDCUpdateCal", opResults,
                         ParamList(), sessionId);
if ( ! retVal.isError() )
{
  printf("successful execution, and execution result is %s\n",
        opResults["CAL_EXEC_STATUS"]);
}
else {
printf("error (code=%s, description=%s), please check your operation",
      retVal.code(), retVal.text();
}
```
