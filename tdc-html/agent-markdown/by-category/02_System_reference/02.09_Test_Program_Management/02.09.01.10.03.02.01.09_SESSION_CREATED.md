# SESSION_CREATED

This asynchronous event indicates that a new Advantest application software session has been created.

The session type (such as SmarTest) and its parameters and user preferences may not be available now and will be notified by the upcoming events like `SMARTEST_SESSION_STARTING`.

In the future, there will be other application software types besides SmarTest, like test program conversion and low level diagnostic.
