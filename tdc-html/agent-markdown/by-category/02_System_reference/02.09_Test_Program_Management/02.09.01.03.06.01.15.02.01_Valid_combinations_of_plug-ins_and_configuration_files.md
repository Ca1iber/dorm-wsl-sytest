# Valid combinations of plug-ins and configuration files

The table below shows valid combinations of plug-ins and configuration files. The recommended combination is listed first.

 |
 |

Universal-GPIO

 |

 |

The combinations with the "Universal-GPIO" plug-in are to be used when setting up a configuration for a non-directly supported handler.

The configuration files with the "-debug.cfg" extension are to be used for debugging (timing parameter values are relaxed).
