# Parameter:mirae_mask_device_pending

This parameter enables or disables the effect of handler_site_mask.

The value can be "yes" or "no". If the value is set to "yes", the effect of handler_site_mask is enabled. If the value is set to "no", the effect of handler_site_mask will be turned off.

Driver default: `"yes"`

Changeable at run-time: no

Applicable for: Techwing handlers

Example: `mirae_mask_device_pending: "yes"`

## Functional changes

- Introduced before SmarTest 6.3.2
