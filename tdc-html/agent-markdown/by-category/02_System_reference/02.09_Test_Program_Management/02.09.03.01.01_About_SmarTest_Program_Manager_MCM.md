# About SmarTest Program Manager MCM

STPM MCM (SmarTest Program Manager MCM) is an extension to [SmarTest Program Manager](<02.09.02_SmarTest_Program_Manager.md>) (STPM) that combines individual test programs for components of multichip modules or multicore modules into a single test program for the entire module.

Like the core STPM, it combines individual source test programs (STPs) into a master test program (MTP). Unlike the core STPM, the commands and parameters of STPM MCM are specifically geared for handling the requirements of integrating independent chips or modules into a single device.

The MTPs created by STPM MCM can be further managed with the core STPM program.
