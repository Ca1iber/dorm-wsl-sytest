# How to issue a command

The signature [command](<02.09.01.10.03.01.04_command.md>) is used to execute the remote control commands which have no output in HVM API.

## About this task

These APIs include:

[ShutdownSmartestSession](<02.09.01.10.03.02.01.12_ShutdownSmartestSession.md>), [AbortBLC](<02.09.01.10.03.02.02.01_AbortBLC.md>), [AbortTestFLow](<02.09.01.10.03.02.02.02_AbortTestFLow.md>), [AbortTestprogram](<02.09.01.10.03.02.02.03_AbortTestprogram.md>), [ChangeDevice](<02.09.01.10.03.02.02.12_ChangeDevice.md>), [DownloadTestflow](<02.09.01.10.03.02.02.19_DownloadTestflow.md>), [DownloadTestprogram](<02.09.01.10.03.02.02.20_DownloadTestprogram.md>), [ExecBLC](<02.09.01.10.03.02.02.21_ExecBLC.md>), [ExecTestflow](<02.09.01.10.03.02.02.22_ExecTestflow.md>), [ExecTestprogram](<02.09.01.10.03.02.02.23_ExecTestprogram.md>), [PauseBLC](<02.09.01.10.03.02.02.50_PauseBLC.md>), [PauseTestflow](<02.09.01.10.03.02.02.51_PauseTestprogram.md>), [PauseTestprogram](<02.09.01.10.03.02.02.51_PauseTestprogram.md>), [ResumeBLC](<02.09.01.10.03.02.02.52_ResumeBLC.md>), [ResumeTestprogram](<02.09.01.10.03.02.02.53_ResumeTestprogram.md>).

The prototype of [command](<02.09.01.10.03.01.04_command.md>) is

```
xoc::hvmapi::Status command(
const std::string &cmdName,
const xoc::hvmapi::ParamList &cmdParams=xoc::hvmapi::ParamList(),
const std::string &sessionId=std::string("")
);
```

The session ID of SmarTest is required to execute some API. If you Do not know it, you can get the session ID with the API [GetOnlineSmartestSessionID](<02.09.01.10.03.02.01.04_GetOnlineSmartestSessionID.md>) or [ListSmartestSessionIDs](<02.09.01.10.03.02.01.07_ListSmartestSessionIDs.md>).

## Before you begin

Make sure you are using SmarTest 6.2 or later versions.

## Procedure

 Prepare the parameters and session ID for the HVM API.

Each API has different parameters. You can refer to the code template below.

```
ParamList cmdParams;      //define the ParamList used for the API
string sessionId = ":0";               // define the session ID used for the API
cmdParams["param1"] = "value_for_param1";
cmdParams["param2"] = "value_for_param2";
...                                   //set values for other parameters
```

Execute the API with [command](<02.09.01.10.03.01.04_command.md>) signature as below.

```
Status retVal;
retVal = command("API_to execute", cmdParams, sessionId);
```

## Results

The API is executed and an error object will be returned to indicate the execution status of the API.

## Example

The following example shows how to change device with HVM API.

```
ParamList cmdParams;
string sessionId=":0";
cmdParams["DEVICE_PATH"] = "/home/demo/devices/";
cmdParams["DEVICE_NAME"] = "74ACT299";
Status retVal = command("ChangeDevice", cmdParams, sessionId);
if(!retVal.isError())
{
  cout <<"Device is changed to " <<cmdParams["DEVICE_NAME"]<<endl;
}
  else
{
  cout << "error code is " << retVal.code() << endl;
}
```
