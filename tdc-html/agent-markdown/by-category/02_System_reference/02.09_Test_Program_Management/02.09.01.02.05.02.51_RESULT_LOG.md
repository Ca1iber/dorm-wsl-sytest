# RESULT_LOG

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.51.01_Associated_Syntax_Entities.md>)

This determines whether the data (comprising a header, binlist, summary, and if appropriate, device data) for a particular level is logged or not. It is simply turned ON or OFF. For example,

LOG_SPECIFICATION

RESULT_LOG=ON;
