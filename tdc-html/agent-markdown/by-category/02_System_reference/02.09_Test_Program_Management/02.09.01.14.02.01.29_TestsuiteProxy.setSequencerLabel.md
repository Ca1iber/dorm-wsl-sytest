# TestsuiteProxy.setSequencerLabel()

This function sets the sequencer label for the test suite.

## Syntax

```
bool setSequencerLabel(const std::string& value);
```

Parameters
 |

value

 |

The sequencer label to use. It must be in the format of "\"label_name\"".

 |

## Functional changes

- Introduced in SmarTest 6.5.2
