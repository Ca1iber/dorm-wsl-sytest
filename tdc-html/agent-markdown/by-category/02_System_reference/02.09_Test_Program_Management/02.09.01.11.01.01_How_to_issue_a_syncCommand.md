# How to issue a syncCommand

[syncCommand](<02.09.01.10.03.01.11_syncCommand.md>) is used to synchronously execute a control command which has no output value.

## About this task

The BLC APIs which use the [syncCommand](<02.09.01.10.03.01.11_syncCommand.md>) signature include:

[SetBLCProfile()](<02.09.01.11.03.01.01_SetBLCProfile.md>), [ResetBLCProfile()](<02.09.01.11.03.01.02_ResetBLCProfile.md>), [StartLevel()](<02.09.01.11.03.02.01_StartLevel.md>), [LoopLevel()](<02.09.01.11.03.02.02_LoopLevel.md>), [CompleteLevel()](<02.09.01.11.03.02.03_CompleteLevel.md>), [SetApplicationVar()](<02.09.01.11.03.03.02_SetApplicationVar.md>), [LoadPHDriverLib()](<02.09.01.11.03.05.01_LoadPHDriverLib.md>), [LoadExecInputLib()](<02.09.01.11.03.05.03_LoadExecInputLib.md>), [LoadDataBridgeLib()](<02.09.01.11.03.05.05_LoadDataBridgeLib.md>), [DownloadTestflowSyn()](<02.09.01.11.03.06.01_DownloadTestflowSync.md>), [ExecTestflowSync()](<02.09.01.11.03.06.02_ExecuteTestflowSync.md>), [SetReprobeAction()](<02.09.01.11.03.07.01_SetReprobeAction.md>), [SetSpecialBLCTestEnv()](<02.09.01.11.03.07.08_SetSpecialBLCTestEnv.md>), [IssueEDLEvent()](<02.09.01.10.03.02.02.29_IssueEDLEvent.md>), [MoveEDLStream()](<02.09.01.11.03.08.02_MoveEDLStream.md>), [EvalWaferDescriptionFile()](<02.09.01.11.03.09.01_EvalWaferDescriptionFile.md>), [UpdateResultDisplay()](<02.09.01.11.03.10.01_UpdateResultDisplay.md>), [IssueHVMExecutionEvent()](<02.09.01.10.03.02.02.28_IssueHVMExecutionEvent.md>), [SetPackageID()](<02.09.01.11.03.12.01_SetPackageID.md>).

The prototype of syncCommand is:

```
xoc::hvmapi::Status syncCommand(const string &cmdName,
const ParamList &cmdParams=ParamList( ),
const string &sessionID= string(""));
```

## Before you begin

Make sure you are using SmarTest 6.5.0 or later.

## Procedure

-  Prepare the parameters and session ID for the BLC API.

Each API has different parameters. You can refer to the code template below.

```
ParamList Params;
Params ["param1"] = "value_param1";
Params ["param2"] = "value_param2";
Params ["param3"] = "value_param3";
```

-  Execute the API with [syncCommand](<02.09.01.10.03.01.11_syncCommand.md>) as below.

```
Status retVal;
retVal = syncCommand ("API_to_execute", Params, LOCAL_SESSION_ID);
```

## Results

The API is executed and an error object will be returned to indicate the execution status of the API.

## Example

The following example shows how to execute the [IssueEDLEvent()](<02.09.01.10.03.02.02.29_IssueEDLEvent.md>) API with [syncCommand](<02.09.01.10.03.01.11_syncCommand.md>).

```
ParamList Params;
Status retVal;
Params ["EVENT_TYPE"] = "ApplModelLevelStartEventType";
Params ["LEVEL_TYPE"] = "CUSTOM_LEVEL";
Params ["LEVEL_NAME"] = "lot";
syncCommand ("IssueEDLEvent", Params, LOCAL_SESSION_ID);
```
