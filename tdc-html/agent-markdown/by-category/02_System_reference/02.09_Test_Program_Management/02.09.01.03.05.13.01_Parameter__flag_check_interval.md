# Parameter: flag_check_interval

While waiting, the driver repeatedly checks for changed SmarTest system flags to allow a reasonable reaction time on user interactions (for example, PAUSE or ABORT pressed while the driver is waiting for parts).

This parameter sets the time interval for these periodic checks in milliseconds. Also, this interval determines how often the hook function ph_HookWaiting will be called.

From the user side, a short reaction time of the driver is wanted (ideal: no reaction time). From the driver side, a requested short reaction time causes additional overhead, as more time is spent for checking the flags. This may increase the reaction time of the driver, when the action the drivers has been waiting for was done.

Reasonable values for this parameter lie between 2000 and 7000 milliseconds.

Driver default: depends on plug-in

Changeable at run-time: no

Applicable for: handlers and probers

Example: flag_check_interval: 4000
