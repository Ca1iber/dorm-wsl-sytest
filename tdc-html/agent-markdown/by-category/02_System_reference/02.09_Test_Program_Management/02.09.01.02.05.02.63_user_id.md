# user_id

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.63.01_Associated_Syntax_Entities.md>)

The user_id keyword is used as an argument for [GET_TEST_INFO](<02.09.01.02.05.02.36_GET_TEST_INFO.md>) to return the log-in name of the user who is executing the test program.

## Functional changes

- Introduced in SmarTest 6.5.4
