# tpt_generate_template

The tpt_generate_template command for the SmarTest Program Manager (STPM) [control file](<02.09.02.03_STPM_control_file.md>) lets you generate a new, empty test program template (TPT).

When executing the command, STPM creates the files that make up a test program template. However, it does not create the device-specific files ([Testflow file](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.05_Testflow_file.md>), [Pin configuration file](<../02.08_Setup_and_Result_Tools/02.08.04.18.04_Pin_configuration_file.md>), [.technology file](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.01.02_Technology_file_for_a_device.md>)). You will have to add those files manually before you convert the template to a new testflow device directory.

## Syntax

```
tpt_generate_template(
tpt_dir    = <location>,
[pre_proc   = <pre_proc>,    ]
[post_proc  = <post_proc>]
)
```

## Parameters

The parameters in the order in which they are listed above:

 |

tpt_dir

 |

<location> (string) is the path, including the name, where the new template files and directories are created.

The path can be either absolute or relative to the current working directory.

If the directory does not yet exist, STPM creates it.

 |
 |

pre_proc

 |

<pre_proc> is a script that is executed before this command.

The syntax of the parameter value is described in [Preprocessing and postprocessing scripts](<02.09.02.03.03_Preprocessing_and_postprocessing_scripts.md>).

This is an optional parameter.

 |
 |

post_proc

 |

<post_proc> is a script that is executed after this command.

The syntax of the parameter value is described in [Preprocessing and postprocessing scripts](<02.09.02.03.03_Preprocessing_and_postprocessing_scripts.md>).

This is an optional parameter.

 |

## Example

This example creates a test program template in the subdirectory "new_template" of the current working directory.

```
generate_new(
    tpt_dir  = 'new_template'
    )
```

## Functional changes

- Introduced in SmarTest 7.0.4
- SmarTest 7.2.1: Removed tpt_name parameter.
- SmarTest 7.2.1: Renamed command to tpt_generate_template.
- SmarTest 7.2.2: Added the pre_proc and post_proc parameters.
