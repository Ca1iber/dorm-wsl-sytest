BLC APIs are provided to create a C/C++ program to supersede the application model file and test program.

These APIs need to be executed synchronously, which means the caller will be blocked until the return of the APIs. These APIs can be categorized as synchronous command or data query command according to their behavior.

The BLC API only takes care of the local session. A maro LOCAL_SESSION_ID is provided to be used as the local session ID.

## LOCAL_SESSION_ID

This macro allows you to use the local SmarTest session in a BLC API. When you pass LOCAL_SESSION_ID as the session ID to the APIs, BLC will internally check the values of the two environment variables DISPLAY_HP83000 and DISPLAY. If DISPLAY_HP83000 is set, its value will be used as the session ID, otherwise the value of DISPLAY will be taken.

The LOCAL_SESSION_ID can be used in the following format:

```
Status syncCommand(const string &cmdName,
                   const ParamList &cmdParams=ParamList(),
                   LOCAL_SESSION_ID);
Status syncOperation(const string &opName,
                     ParamList &opResults,
                     const ParamList &opParams=ParamList( ),
                     LOCAL_SESSION_ID);
Status query(const string &qrName,
                   ParamList &qrResults,
                   const ParamList &qrParams=ParamList(),
                   LOCAL_SESSION_ID);
```
