# Equipment configuration file

The equipment configuration file defines the prober and handler configuration files to be used in the Test Cell Control Tool. The location of the file is /etc/opt/hp93000/tcct/equipment.xml.

It has two group of elements, probers and handlers. In each group, the following elements are included:

vendor: specifies the vendor name and the driver directory.

model: specifies the name of the equipment model from the specified vendor and the full path of its configuration file.

For probers, you need to specify different configuration files to support different number of sites for the same model of prober.

For handlers, you can specify one configuration file supporting the maximum number of sites for different number of sites on the same model of handler. This configuration file can also support less number of sites on this model of handler. Specifying different configuration files for different number of sites on the same model of handler is also supported.

## Example

This configuration file shows using one configuration file to support different number of sites on one model of handler.

```
<?xml version="1.0" encoding="UTF-8"?>
<equipment>
    <probers>
        <vendor name="TSK" driver="/opt/hp93000/soc/PH_libs/GenericProber/TSK/">
            <model name ="UF200_1_SITE" config="/etc/opt/hp93000/soc/PH_libs/GenericProber/TSK/GENERIC-GPIB-Prober-1-die.cfg"/>
            <model name ="UF200_2_SITE" config="/etc/opt/hp93000/soc/PH_libs/GenericProber/TSK/GENERIC-GPIB-Prober-2-die.cfg"/>
            <model name ="UF300_1_SITE" config="/etc/opt/hp93000/soc/PH_libs/GenericProber/TSK/GENERIC-GPIB-Prober-1-die.cfg"/>
            <model name ="UF300_2_SITE" config="/etc/opt/hp93000/soc/PH_libs/GenericProber/TSK/GENERIC-GPIB-Prober-2-die.cfg"/>
            <model name ="UF3000_1_SITE" config="/etc/opt/hp93000/soc/PH_libs/GenericProber/TSK/GENERIC-GPIB-Prober-1-die.cfg"/>
            <model name ="UF3000_2_SITE" config="/etc/opt/hp93000/soc/PH_libs/GenericProber/TSK/GENERIC-GPIB-Prober-2-die.cfg"/>
        </vendor>
        <vendor name="TEL" driver="/opt/hp93000/soc/PH_libs/GenericProber/TEL/">
            <model name ="20S_1_SITE" config="/etc/opt/hp93000/soc/PH_libs/GenericProber/TEL/20S-GPIB-Prober-1-die.cfg"/>
            <model name ="20S_2_SITE" config="/etc/opt/hp93000/soc/PH_libs/GenericProber/TEL/20S-GPIB-Prober-2-die.cfg"/>
            <model name ="P8_1_SITE" config="/etc/opt/hp93000/soc/PH_libs/GenericProber/TEL/P8-GPIB-Prober-1-die.cfg"/>
            <model name ="P8_2_SITE" config="/etc/opt/hp93000/soc/PH_libs/GenericProber/TEL/P8-GPIB-Prober-2-die.cfg"/>
            <model name ="P12_1_SITE" config="/etc/opt/hp93000/soc/PH_libs/GenericProber/TEL/P12-GPIB-Prober-1-die-256-bin.cfg"/>
            <model name ="P12_2_SITE" config="/etc/opt/hp93000/soc/PH_libs/GenericProber/TEL/P12-GPIB-Prober-2-die-256-bin.cfg"/>
        </vendor>
    </probers>
    <handlers>
        <vendor name="Seiko-Epson"  driver="/opt/hp93000/soc/PH_libs/GenericHandler/Seiko-Epson/">
            <!--Support 1~4 site NS5000-->
            <model name ="NS5000" config="/etc/opt/hp93000/soc/PH_libs/GenericHandler/Seiko-Epson/NS5000-GPIB-4.cfg"/>
            <!--Support 1~4 site NS6000-->
            <model name ="NS6000" config="/etc/opt/hp93000/soc/PH_libs/GenericHandler/Seiko-Epson/NS6000-GPIB-4.cfg"/>
        </vendor>
        <vendor name="Multitest" driver="/opt/hp93000/soc/PH_libs/GenericHandler/Multitest/">
            <!--Support 1~4 site MT9918-->
            <model name ="MT9918" config="/etc/opt/hp93000/soc/PH_libs/GenericHandler/Multitest/MT9918-GPIB-4.cfg"/>
        </vendor>
        <vendor name="Delta" driver="/opt/hp93000/soc/PH_libs/GenericHandler/Delta/">
            <!--Support 1~8 site Castle-->
            <model name ="Castle" config="/etc/opt/hp93000/soc/PH_libs/GenericHandler/Delta/Castle-GPIB-8.cfg"/>
            <!--Support 1~8 site Flex-->
            <model name ="Flex" config="/etc/opt/hp93000/soc/PH_libs/GenericHandler/Delta/Flex-GPIB-8.cfg"/>
        </vendor>
    </handlers>
</equipment>
```
