# TestsuiteProxy.getTestmethodLimitValue()

This function gets the value of a test method limit. The returned value is in `LimitValue` struct. LimitValue includes low limit value, low limit symbol, high limit value, high limit symbol, unit and test number offset.

## Syntax

```
const LimitValue getTestmethodLimitValue(const std::string& name) const;
```

Parameters
 |

name

 |

The limit name to query. If the name is invalid, empty `LimitValue ` will be returned with an error message sent out.

 |

## Functional changes

- Introduced in SmarTest 6.5.2
