The "HM2000-serial" configuration is valid for Seiko-Epson handlers.

Supported handler models

- HM 2000
- HM 3000
- HM 3500

Features

- up to 4 sites
- 4 DUT signals
- global test start signal
- serial binning
- explicit binning
- 5 bin categories
- no "empty" bin

Required handler cable

- E2790-61601-3
