# Parameter: temp_conf_unit

The unit of any temperature value that you enter in your temperature configuration parameters, will be interpreted to be the unit you insert in temp_conf_unit. Subsequently, these values will be automatically converted by the driver to the unit expected by the equipment. Thus, the unit, which the equipment expects, has to be entered, too. It has to be inserted in the parameter temp_equipment_unit.

For example, the equipment may need to receive the values in Celsius but the temperatures you insert may be in Fahrenheit.

Differentiating between a configuration temperature unit and an equipment temperature unit, enables you to enter your temperature configuration in the unit which is the most convenient for you to handle.

The valid entries are "celsius", "fahrenheit" and "kelvin". If not specified, "celsius" is assumed.

Driver default: "celsius"

Changeable at run-time: yes

Applicable for: handlers and probers, plug-in dependent

Example: temp_conf_unit: "celsius"
