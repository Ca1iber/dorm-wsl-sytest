# Editing the configuration file

## Using the editSpecificConfig tool

Once you have selected the configuration file, you will need to modify it. You can use either the editSpecificConfig tool or any text editor for this. See the Prober/Handler Drivers guide for more information.

Advantest recommends that you first make a copy of the file and give it a unique name, for example, NewHandler.cfg. This ensures that the file will not be overwritten when SmarTest is updated. Make sure you also enter the file name and path in the global configuration file (see [Setting Up the Global Configuration](<02.09.01.03.03.02_Setting_Up_the_Global_Configuration.md>)).

## Using a text editor

If you are using a text editor instead of the editSpecificConfig tool, you will find extensive descriptions and examples of the various parameters settings in the configuration file. Compare the parameter settings with the user documentation of your equipment and your demands, and change as necessary.

## Setting the parameters

[Debugging a Driver Configuration](<02.09.01.03.04.01_Debugging_a_Driver_Configuration.md>) provides hints for setting up the configuration file (for example, which parameters you need to change for the site management).
