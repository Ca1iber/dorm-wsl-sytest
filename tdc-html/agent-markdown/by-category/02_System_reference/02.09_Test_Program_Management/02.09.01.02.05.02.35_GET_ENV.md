# GET_ENV

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.35.01_Associated_Syntax_Entities.md>)

Accesses an environment variable value. The parameter of GET_ENV must be an environment variable name. It can be used to avoid any conflict (for example, with the DISPLAY variable) in multiple-offline applications, where more than one user is using the same application model. For example,

ACTIONS

DISPLAY=GET_ENV(DISPLAY);

list_of_wafers=FILE_INPUT(/tmp/{DISPLAY}_waf_list);
