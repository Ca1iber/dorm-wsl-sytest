# How to change to the target device

In the factory automation environment, you can use the [ChangeDevice](<02.09.01.10.03.02.02.12_ChangeDevice.md>) API to change to the target device.

## About this task

The related HVM API events and the error code will be issued during the device changing.

## Before you begin

Before changing to the target device, you need to synchronize with the SMARTEST_READY event. The synchronization is done through the HMVAPI event handler.

Make sure a SmarTest has been started successfully and the target device is ready to use.

The lock_file of the target device has been removed.

## Procedure

-  Prepare the parameters for the [ChangeDevice](<02.09.01.10.03.02.02.12_ChangeDevice.md>) API.
-  Change to the target device.
-  Report the execution status of the API.

## Results

The device currently in use is changed to the target device and the [DEVIVE_CHANGE_COMPELTED](<02.09.01.10.03.02.02.13_DEVICE_CHANGE_COMPLETED.md>) event is issued.

## Example

The following example changes the device in use to the target device with the [ChangeDevice](<02.09.01.10.03.02.02.12_ChangeDevice.md>) API when the HVMAPI event [SMARTEST_SESSION_READY](<02.09.01.10.03.02.01.14_SMARTEST_SESSION_READY.md>) is received.

```
void handlerSession (const std::string& type,
    const xoc::hvmapi::ParamList& params,
    unsigned long sec,
    long usec,
    const std::string& session)
{
  //undefine the Status that was defined in XWindow header file
  #ifdef Status
  #undef Status
  #endif
  xoc::hvmapi::Status errObj;

  static int nCountOfSessionReadyEvent = 0;

  hide_op_window();
  if (params["SESSION_STATE"] == "SMARTEST_SESSION_READY")
  {
    nCountOfSessionReadyEvent++;
    cout << "received SMARTEST_SESSION_READY" << endl;
    cout << "number of SMARTEST_SESSION_READY is "
         <<  nCountOfSessionReadyEvent << endl;
    if ( nCountOfSessionReadyEvent == 1)
    {
      xoc::hvmapi::ParamList cmdParam;
      string device;
      device="/home/demo/devices/training";
      removeLockFile(device);
      cmdParam["DEVICE_PATH"] = "/home/demo/devices/";
      cmdParam["DEVICE_NAME"] = "training";
      cout << "FA: ChangeDevice started: " << endl;
      errObj = command ("ChangeDevice",cmdParam,session);
      if (errObj.isSuccess())
      {
        cout << "FA: ChangeDevice executed: " << endl;
      }
      else
      {
        cout << "FA ChangeDevice not executed" << endl;
        cout << "error code is " << errObj.code( ) << endl;
      }
    }
    else
    {
      cout << "received second SESSION_READY, do not change the device" << endl;
    }
  }
//re-define Status as in the XWindow header file
  #define Status int
  return;
}
```

## What to do next

After changing to the target device is completed, synchronize with the [DEVICE_CHANGE_COMPLETED](<02.09.01.10.03.02.02.13_DEVICE_CHANGE_COMPLETED.md>) HVMAPI event and download the test program.
