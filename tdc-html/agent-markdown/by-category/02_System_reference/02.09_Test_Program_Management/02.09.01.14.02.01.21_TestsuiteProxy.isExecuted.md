# TestsuiteProxy.isExecuted()

This function queries whether this test suite has been executed on the specified site or not. True is returned for executed and false is returned for not executed.

## Syntax

```
bool isExecuted(const int site);
```

Parameters
 |

site

 |

The site to query.

 |

## Functional changes

- Introduced in SmarTest 6.5.2
