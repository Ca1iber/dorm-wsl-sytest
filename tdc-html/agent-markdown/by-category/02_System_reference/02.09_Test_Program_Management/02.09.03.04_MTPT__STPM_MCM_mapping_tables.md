An MTPT contains a number of CSV tables that specify various aspects of how STPs (source test programs) are combined into an MTP (master test program).

The STP table describes the STPs used in creating the MTP:

- [STP table](<02.09.03.04.01_STP_table.md>)

Several mapping table describe which objects from the STPs correspond to which objects from the MTP:

- [Pin mapping table](<02.09.03.04.02_Pin_mapping_table.md>)
- [Group mapping table](<02.09.03.04.03_Group_mapping_table.md>)
- [Test mapping table](<02.09.03.04.04_Test_mapping_table.md>)
- [Bin mapping table](<02.09.03.04.06_Bin_mapping_table.md>)
- [Test number mapping table](<02.09.03.04.07_Test_number_mapping_table.md>)
- [Testflow variable mapping table](<02.09.03.04.08_Testflow_variable_mapping_table.md>)

Several tables describe settings and parameters for the objects in the MTP:

- [Test suite table](<02.09.03.04.05_Test_suite_table.md>)
- [Special tests table](<02.09.03.04.09_Special_tests_table.md>)
- [Shared pins table](<02.09.03.04.10_Shared_pins_table.md>)
- [Test flag table](<02.09.03.04.11_Test_flag_table.md>)
- [Off DC levels table](<02.09.03.04.12_Off_DC_levels_table.md>)

Two additional tables, the MTPT configuration file and the STP test information table, are intended for internal bookkeeping and future expansion, respectively, and should not be edited.

While the tables listed above tables can be edited with text editors, we recommend using the [OpenOffice spreadsheet](<02.09.03.04.15_OpenOffice_spreadsheet_for_editing_the_CSV_files.md>) that is also part of the MTPT for editing the CSV files.
