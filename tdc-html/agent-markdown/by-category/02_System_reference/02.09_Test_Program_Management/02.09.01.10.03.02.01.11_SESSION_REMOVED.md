# SESSION_REMOVED

This asynchronous event indicates that an Advantest application software session has been terminated.

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

SESSION_ID

 |

The ID of the SmarTest session this event belongs to.

 |
 |

O

 |

TIME_STAMP

 |

The time point when this event occurs. It contains two long-type parts: `SECONDS` and `MICROSECONDS`.

 |
 |

O

 |

EVENT_NAME

 |

The event category. Here it is always `SESSION`.

 |
 |

O

 |

EVENT_BODY

 |

The event parameters. It contains the following members:

 |

`SESSION_STATE`

 |

The HVM event type. Here it is always `SESSION_REMOVED`.

 |

This parameter is represented by `ParamList` whose key and value are both `sting` type.

 |
