# Testing with the recipe file in the Test Cell Control Tool

The [Recipe file](<02.09.01.17.10.01_Recipe_file.md>) can contain all the settings needed for the test in the Test Cell Control Tool(TCCT). Using the recipe file can help avoid the step-by-step setup in the test with TCCT as described in [Setting up tests manually with the Test Cell Control Tool](<02.09.01.17.03_Setting_up_tests_manually_with_the_Test_Cell_Control_Tool.md>).

## Before you begin

Make sure the needed SmarTest version and TCCT are installed.

The recipe file is correct and ready to use. (Refer to [Recipe file](<02.09.01.17.10.01_Recipe_file.md>) for the detailed explanation.)

## Procedure

-  [Start SmarTest and TCCT](<02.09.01.17.02_Starting_the_Test_Cell_Control_Tool.md>). The following actions are done in TCCT.

In the engineering mode, only TCCT is started. You need start SmarTest and load the recipe file separately.

In the production mode, SmarTest and TCCT are started and the recipe file is loaded.

Make sure TCCT is successfully attached to the SmarTest session. The status is shown in the lowest part of TCCT. "SmarTest XXX Attached" will be shown if it is successfully attached. Otherwise, you will see the message "SmarTest Session Detached".

-  If TCCT was started in the engineering mode, to load the recipe file, click the [Load Recipe](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>)button and select the recipe file to load.

The full path of the loaded testflow, the equipment settings in the recipe file and the full path of the recipe file will be displayed in the [Lot Summary](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) area of TCCT.

-  To start the lot, click the [New Lot](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) button in the lower part of TCCT. In the pop-up [Lot Information](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) dialog, enter the values for the listed variables if needed.

You can edit the [configuration file of the dialog](<02.09.01.17.10.04_Lot_configuration_file.md>) to change the variables listed in the dialog.

-  To start the testing of the lot, click [Start Test](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>).

The text data log file is created as specified in the recipe file. The binning information of the execution will be displayed in the [Binning](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) area and counted in the [Binning Statistics](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) area.

-  (optional) If some error occurs in the testing, you can [debug the testflow in EWC](<02.09.01.17.06_Debugging_the_testflow_during_tests_with_the_Test_Cell_Control_Tool.md>) or [disable some sites](<02.09.01.17.07_Changing_the_site_control_during_tests_with_the_Test_Cell_Control_Tool.md>) before further testing.

For HANDLER and PROBER test, you need to click [Pause Test](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) before the debugging.

-  (optional)To generate the partial summary for the tested devices, click Pause Test and then click [Partial Summary](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) for the PROBER and the HANDLER test. For the HAND test, just click Partial Summary.

The partial summary is generated in the lot summary file you specified in the recipe file.

-  To continue the tests for other devices in the lot, click [Resume](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) for HANDLER and PROBER test and click [Start Test](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>) for HAND test.
-  When all the devices in this lot are finished, click [End Lot](<02.09.01.17.10_Elements_of_the_Test_Cell_Control_Tool.md>).

The data log files and the lot summary file are generated as specified in the recipe file.

## Results

The data log file(s) and lot summary file(s) can be generated as specified. The binning statistics and the yield of the tests are shown in the main GUI of TCCT.

## Functional changes

- Introduced in SmarTest 7.2.0
