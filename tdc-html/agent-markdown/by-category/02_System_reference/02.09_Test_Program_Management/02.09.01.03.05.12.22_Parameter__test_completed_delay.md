# Parameter: test_completed_delay

This parameter defines the delay between the driver sending the binning signals and the test completed signal. The delay time is given in milliseconds.

Driver default: depends on driver plug-in

Changeable at run-time: yes

Applicable for: handlers

Example: test_completed_delay: 10
