# CompleteLevel()

This API terminates the current active level. It sets the current level inactive and sets the upper level (if any) active.

The HVM event `LEVEL_COMPLETED` and the EDL event `AppModelLevelEndEventType` event will be issued if the implicit event generation is turned on.

SUCCESS will be returned if no error occurs. Otherwise, an error code will be returned indicating the error code, description and severity.

 |

- The designated session ID "XXX" does not exist.

- There is no active level currently.

## Prototype

```
Status syncCommand("CompleteLevel", ParamList(), sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID; //the local session ID

Status retVal = syncCommand("CompleteLevel", ParamList(), sid);
if ( retVal.isError() )
{
cout<<"error code= " << retVal.code() << " description="
   << retVal.text() << endl;
}
```
