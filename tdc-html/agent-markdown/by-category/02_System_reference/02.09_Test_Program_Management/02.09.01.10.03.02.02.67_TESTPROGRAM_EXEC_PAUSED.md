# TESTPROGRAM_EXEC_PAUSED

The asynchronous event indicates that the execution of a test program is paused. When this event occurs, the SmarTest execution status (See [GetSmarTestExecStatus](<02.09.01.10.03.02.02.27_GetSmarTestExecStatus.md>)) is changed to `WAITING`.

## Dependency

The execution of the test program is made.
