# Parameter for TSK probers

This parameter is valid only for TSK probers.

- tsk_wafer_ID_command: "W"

TSK probers can be configured to use either the "W" or the "b" command to perform a wafer ID request or a probe needle cleaning. This parameter defines, which command ("W" or "b") should be sent to perform a wafer ID request. The other one is then used for probe needle cleaning. The parameter defaults to "W" if not specified.

 Note The configuration file contains descriptions and examples of the parameters valid for the configuration. See also the Prober/Handler Drivers guide for more information.
