# Pausing a Production Run

#### Subtopics

- [Using the Form Dialog Screen](<02.09.01.07.04.01_Using_the_Form_Dialog_Screen.md>)

To pause a production test run, simply click the PAUSE toggle button in the Operation Control screen shown in [Controlling a Production Run](<02.09.01.07_Controlling_a_Production_Run.md>). This sets the PAUSE flag. The application model evaluates this flag immediately after the execution of a device test. The further course of action is specified in the ON_PAUSE section of your particular application model. For the wafer_auto application model, the test is paused and the Form Dialog screen appears.
