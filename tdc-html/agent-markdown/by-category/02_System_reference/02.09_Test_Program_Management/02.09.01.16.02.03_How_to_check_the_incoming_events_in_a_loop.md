# How to check the incoming events in a loop

## About this task

In the production test, the incoming events are written to the data log stream. To capture the needed events from the data log stream, a loop is needed to check the incoming events of the stream. You can follow the procedure below to implement the loop.

## Procedure

-  Check the incoming events of the data log stream with [DRLEventAvailable](<../02.10_Data_Logging/02.10.01.04.01.01_DRLEventAvailable.md>).

```
DRLDataStream my_stream;
DRLEeventAvailable(&my_stream);
```

-  Retrieve the unmasked event with [DRLNextUnmaskedEvent](<../02.10_Data_Logging/02.10.01.04.02.36_DRLNamedValueAttr.md>) and retrieve the event type with[DRLEventGetType](<../02.10_Data_Logging/02.10.01.04.01.06_DRLEventGetType.md>).

```
DRLEventRec event_rec;
DRLGetNextUnmaskedEvent(&my_stream, &event_rec);
DRLEventGetType(&event_rec);
```

-  Process the event according to its type. (For details, see [How to process an event](<02.09.01.16.02.04_How_to_process_an_event.md>))

## Example

```
void EventLoop(void)
{
  DRLEventRec
    event_rec;

  printf("Press \'Ctrl-c\' to stop the yield monitor.\n");
  /*  Event Loop  */

  while (!DRLEeventAvailable(&my_stream))
  {
    while (!DRLGetNextUnmaskedEvent(&my_stream, &event_rec))
    {
      switch (DRLEventGetType(&event_rec))
      {
        case BinReachedEventType:
        /* This is the only event we're interested in */
        ProcessBinReachedEventAttributes(&event_rec);
        /* Attribute Processing */
        break;
     }
     /* Errors of DRLGetNextUnmaskedEvent are ignored */
    }
  } /* End of Event Loop */
}
```
