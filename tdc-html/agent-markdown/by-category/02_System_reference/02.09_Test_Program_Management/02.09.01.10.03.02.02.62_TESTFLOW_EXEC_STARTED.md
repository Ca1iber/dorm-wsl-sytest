# TESTFLOW_EXEC_STARTED

This asynchronous event indicates the execution of a test flow is started.

## Dependency

The execution of testflow is made.

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

SESSION_ID

 |

The ID of the SmarTest session to work with.

 |
 |

O

 |

TIME_STAMP

 |

The time point when the event occurs. It contains two long-type parts: `SECONDS` and `MICROSECONDS`.

 |
 |

O

 |

EVENT_NAME

 |

The event category. Here it is always `EXECUTION`.

 |
 |

O

 |

EVENT_BODY

 |

The event parameters. It contains the following members:

 |

EXECUTION_STATE

 |

The HVM event type. Here it is always `TESTFLOW_EXEC_STARTED`.

 |
 |

TESTFLOW_NAME

 |

The test flow started.

 |
 |

SITE_ID_FOR_SITES

 |

The list of site IDs.

 |
 |

SITE_SETUP_FOR_SITES

 |

The list of site setup.

 |
 |

PACKAGE_ID_FOR_SITES

 |

The list of package IDs. The package ID is the number of device tested. It is empty for wafer sort.

 |
 |

DIE_X_FOR_SITES

 |

The list of dies' X coordinates. It is empty for final test.

 |
 |

DIE_Y_FOR_SITES

 |

The list of dies' Y coordinates. It is empty for final test.

 |
 |

OTHERWISE_HARD_BIN

 |

The hardware bin number of the [OTHERWISE bin defined in the testflow](<../02.08_Setup_and_Result_Tools/02.08.04.32.02.01.05_Inserting_a_bin_into_the_testflow.md>).

 |
 |

OTHERWISE_SOFT_BIN

 |

The software bin number of the [OTHERWISE bin defined in the testflow](<../02.08_Setup_and_Result_Tools/02.08.04.32.02.01.05_Inserting_a_bin_into_the_testflow.md>).

 |

This parameter is represented by `ParamList` whose key and value are both `string` type.

 |
