# How to manage the alarms through the startup

During the SmarTest startup, the HVM API events and the execution error are issued. You need to handle these events and errors in the program automatically for smooth SmarTest startup.

## About this task

The following errors can be handled by the HVM API:

license missing, device missing, test program missing, setup files missing, test program parsing error,setup files parsing error.

## Procedure

-  Create a handler for the alarm notification as in the Example.
-  Register the handler in the main() function as below:

```
xoc::hvmapi::addEventListener (handlerAlarm, "ALARM")
```

-  Enter the event loop in the `main()` function with

```
xoc::hvmapi::eventLoop();
```

## Results

The registered alarm notifications can be handled by the program.

## Example

```
void handlerAlarm(const std::string& type,
                       const xoc::hvmapi::ParamList& params,
                       unsigned long sec,
                       long usec,
                       const std::string& session)
{
  if(type=="ALARM")
  {
    string severity=params["ALARM_SEVERITY"];
    string code=params["ALARM_CODE"];
    string text=params["ALARM_TEXT"];
    cout<<severity <<"\n" <<code <<"\n" <<text <<endl;
  }
}
```
