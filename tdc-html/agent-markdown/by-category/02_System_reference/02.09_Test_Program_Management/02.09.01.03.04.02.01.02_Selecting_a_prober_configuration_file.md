# Selecting a prober configuration file

 Note If you need a GPIB driver for non-supported equipment, please contact your Advantest representative.

To make it easier to edit the configuration file, select the configuration file written for your equipment that is closest to your needs, based on the criteria given in the table below:

Please check to see which configuration files are available for your equipment. The configuration files are located in the directory

/etc/opt/hp93000/soc/PH_libs/GenericProber/<plug-in>,

where <plug-in> corresponds to the manufacturer's name (TEL, Electroglas or TSK).
