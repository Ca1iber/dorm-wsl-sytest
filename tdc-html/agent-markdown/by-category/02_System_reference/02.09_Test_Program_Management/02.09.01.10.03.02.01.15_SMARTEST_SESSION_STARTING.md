# SMARTEST_SESSION_STARTING

This asynchronous event indicates a SmarTest session is newly started up. When a SmarTest session is started by the command line /opt/hp93000/soc/prod_env/bin/HPSmartest or by HVM API, this event will be sent out.

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

SESSION_ID

 |

The ID of the SmarTest session this event belongs to.

 |
 |

O

 |

TIME_STAMP

 |

The time point when this event occurs. It consists two parts: `SECONDS` and `MICROSENDS`.

 |
 |

O

 |

EVENT_NAME

 |

The event category. Here it is always `SESSION`.

 |
 |

O

 |

EVENT_BODY

 |

The event parameters. It contains the following memebers:

 |

SESSION_STATE

 |

The HVM event type. Here it is always `SMARTEST_SESSION_STARTING`.

 |
 |

VERSION

 |

The SmarTest version.

 |
 |

ONLINE_MODE

 |

The online/offline mode.

 |
 |

USER_MODE

 |

The user mode.

 |

This parameter is represented by `ParamList` whose key and value are both string.

 |
