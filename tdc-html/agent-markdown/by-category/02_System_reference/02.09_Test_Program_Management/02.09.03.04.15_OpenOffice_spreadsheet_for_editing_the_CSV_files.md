# OpenOffice spreadsheet for editing the CSV files

Each MTPT directory created by STPM MCM includes an OpenOffice spreadsheet (.ods) that lets you edit the CSV files containing the test program mapping information.

The spreadsheet contains custom controls to allow you to load and save the CSV files.

Note The spreadsheet also contains the standard OpenOffice controls (menus, buttons, etc.). These standard controls are described in the OpenOffice documentation.Note The OpenOffice spreadsheet has been tested only with the Linux and Windows versions of OpenOffice 3.3. It is possible that it works with newer versions and on different platforms as well, but we can neither warrant this nor offer support for any issues that may occur in that case.

## Controls

 ![STPM MCM_OpenOffice spreadsheet buttons](<../../../../raw/138094.png>)

STPM MCM adds controls to the upper left corner of the spreadsheet (see graphic above):

- Open MTPT: Clicking this button lets you load a set of CSV files.

Select the desired [MTPT configuration file](<02.09.03.04.14_MTPT_configuration_file.md>) (with a .mtpt filename extension) in the Open dialog; the spreadsheet loads the CSV files belonging to it.

- Reload MTPT: Clicking this button reloads the information from the last loaded set of CSV files.

Note that this overwrites any unsaved changes you may have made in OpenOffice.

- Save MTPT: Clicking this button saves the current state of the spreadsheets to the corresponding CSV files.
- Update Shared Pins: Clicking this button creates one entry in the [Shared pins table](<02.09.03.04.10_Shared_pins_table.md>) for each shared pin specified in the [Pin mapping table](<02.09.03.04.02_Pin_mapping_table.md>). All entries created by clicking this button have default values.

## Sheets

Each sheet in the OpenOffice document contains one of the imported CSV tables described in [MTPT (STPM MCM mapping tables)](<02.09.03.04_MTPT__STPM_MCM_mapping_tables.md>).

## Columns

For descriptions of the table columns, see the documentation of the CSV file containing the column in [MTPT (STPM MCM mapping tables)](<02.09.03.04_MTPT__STPM_MCM_mapping_tables.md>). In the spreadsheet, columns with a light blue title cell contain data related to the STPs and columns with a medium blue title cell contain data related to the MTP.

Several of the columns have drop-down lists from which you can choose appropriate values:

- [STP table](<02.09.03.04.01_STP_table.md>)

  - Apply Prefix On Pin Config
  - Keep Unused Data

- [Pin mapping table](<02.09.03.04.02_Pin_mapping_table.md>)

  - MTP Pin Attribute

- [Test mapping table](<02.09.03.04.04_Test_mapping_table.md>)

  - Mode

- [Test suite table](<02.09.03.04.05_Test_suite_table.md>)

  - STP
  - Test Flags

- [Bin mapping table](<02.09.03.04.06_Bin_mapping_table.md>)

  - STP
  - Type
  - Color
  - Reprobe
  - Overon

- [Test number mapping table](<02.09.03.04.07_Test_number_mapping_table.md>)

  - STP

- [Testflow variable mapping table](<02.09.03.04.08_Testflow_variable_mapping_table.md>)

  - STP
  - Type

- [Special tests table](<02.09.03.04.09_Special_tests_table.md>)

  - Type

- [Test flag table](<02.09.03.04.11_Test_flag_table.md>)

  - All columns representing individual flags
