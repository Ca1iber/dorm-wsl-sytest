# MEC configuration file

This file defines the equipment to control with the MEC driver and the configurations to the equipment.

It contains the following keywords:

- equipment: declares an equipment ID. It can be an arbitrary string.
- driver: specifies the path to the Generic 93000 prober/handler driver. It is used with the keyword config to configure the equipment.
- config: specifies the path to the Global Configuration File for the Generic 93000 prober/handler driver. It is used with the keyword driver to configure the equipment.
- driver_plugin: specifies the driver plug-in for the 93000 prober/handler driver. It is used with the keyword plugin_config to configure the equipment.
- plugin_config: specifies the plug-in configuration file for the 93000 prober/handler driver. It is used with the keyword driver_plugin to configure the equipment.

You can use the combination of driver and config or the combination of driver_plugin and plugin_config to configure the equipment. The combination of driver and config has the higher priority.

## Example

```
equipment=1
driver_plugin=/opt/hp93000/soc/PH_libs/GenericHandler/Multitest
plugin_config=/tmp/MT9308-GPIB-4-1.cfg

equipment=2
driver=/opt/hp93000/soc/PH_libs/GenericHandler
config=/tmp/Global-handler-config.cfg
```
