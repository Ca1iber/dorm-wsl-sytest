# exitProcess()

This API disconnects from the connected SmarTest session and exits the test suite control process. Use it after your process has finished the cleanup work instead of calling exit().

## Syntax

```
void exitProcess(const int exitCode);
```

Parameters
 |

I

 |

exitCode

 |

The exit code of the process. It has the same meaning with the parameter status of exit(). (Type `man 3 exit` in the shell to see the details.)
