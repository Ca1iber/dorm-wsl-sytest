# GetSiteSetup()

This API gets the site setup information from SmarTest shared memory. The returned string from this API can be used as inputs to the `IssueHVMExecutionEvent` aPI for the events which require the site setup information.

SUCCESS will be returned if no error occurred. Otherwise, an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

The designated session ID "XXX" does not exist.

 |

RECOVERABLE

 |

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The local session ID.

 |
 |

O

 |

outputResults

 |

The query results are represented by a ParamList object. It includes the following members:

- SITE_ID_FOR_SITES: The site ID list. The site number is determined by the pin configuration setup. The format looks like "1 2 3 4 5 6 7 8"
- SITE_SETUP_FOR_SITES: The setup status for all the sites. The format of this parameter looks like "I X I I I X X I". Each character in the string is corresponding to the site ID in the site ID list. "I" means the site is inserted and "X" means there is no device on the corresponding site.
- PACKAGE_ID_FOR_SITES: The package ID list for all the sites. The format of this parameter looks like "p1 p2 p3 p4 p5 p6 p7 p8". This means the package ID for site "1" is "p1" and so forth. If the corresponding site is not inserted, then the package ID for that site is "-1".
- DIE_X_FOR_SITES: The X coordinate list for all the sites. The format of this parameter looks like "1 2 3 1 2 3 1 2".
- DIE_Y_FOR_SITES: The Y coordinate list for all the sites. The format of this parameter looks like "1 1 1 2 2 2 3 3".
 |

## Prototype

```
ParamList outputResults;
Status query("GetSiteSetup", outputResults, ParamList(), sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID; //the local session ID
ParamList outputResults;

Status retVal = query("GetSiteSetup", outputResults, ParamList(), sid);
if ( retVal.isSuccess() )
{
cout<< "The site ID list is " << outputResults["SITE_ID_FOR_SITES"] << endl;
cout<< "The site setup list is " << outputResults["SITE_SETUP_FOR_SITES"]
    << endl;
}
```
