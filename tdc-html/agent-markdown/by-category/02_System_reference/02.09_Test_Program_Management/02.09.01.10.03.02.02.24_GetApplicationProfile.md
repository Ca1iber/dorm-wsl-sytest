# GetApplicationProfile

This data query command returns the profile of the current application running in the specified SmarTest session.

The application here means, the test program/application model or the [Batch/Lot Control](<02.09.01.11_Batch_Lot_Control.md>) client. A typical application is made up of multiple levels like lot level, wafer level and device level. This API will also return the levels defined in the application.

SUCCESS will be returned if no error occurs. Otherwise, an error object will be returned indicating the error code, description and severity.

## Parameters

 |

 |

 |

 |

SESSION_ID

 |

 |
 |

O

 |

qrResults

 |

The query result is represented by a `ParamList` object. It contains the following members:

- TEST_TYPE: The test type of the application. It can be `WAFER_SORT` or `PACKAGE_TEST`.
- DEVICE_PATH: The path of the current device.
- DEVICE_NAME: The name of the current device.
- APPLICATION_TYPE: The type of the application. It can be `TESTPROGRAM` or `BLC`.
- TESTPROGRAM_NAME: The test program loaded in SmarTest if the application type is `TESTPROGRAM`. Otherwise, the value is empty.
- BLC_EXECUTABLE: The name of the BLC executable if the application type is `BLC`.
- ENABLE_IMPLICIT_EVENT: Whether the implicit event is enabled. It can be `TRUE` or `FALSE`. If the application type is `TESTPROGRAM`, the value is always `TRUE`.
- PROCESS_ID: The process ID of BLC executable if the running application is `BLC` or the process ID of SmarTest application model processor if the application type is `TESTPROGRAM`.
- LEVEL_NAME_LIST: The list of level names in the current application. This API is typically called after the event TESTPROGRAM_EXEC_STARTED. Otherwise, the value will be empty.
- LEVEL_TYPE_LIST: The list of the level types corresponding to the level name list. This API is typically called after the event TESTPROGRAM_EXEC_STARTED. Otherwise, the value will be empty.
 |

## Prototype

```
ParamList qrResults;
Status query("GetApplicationProfile", qrResults, ParamList(), sessionId);
```

## Example

```
ParamList qrResults;
Status obj = query("GetApplicationProfile", qrResults, ParamList(), sessionId);
if(obj.isSuccess())
{
  string testType = qrResults.value("TEST_TYPE");
  string processID =  qrResults.value("PROCESS_ID");
  vector<string> levelNameList = qrResults.valueArray("LEVEL_NAME_LIST");
  //...
}
else {
  //error handling
}
```
