# Temperature

## get

Retrieves the string currently set for temperature and copies it to the string pointer *temp.

This function writes a maximum CI_CPI_MAX_TEMP_LEN + 1 bytes to the pointer *temp.

long GetTemperature(char *temp)

## set

Sets the string recorded as device test temperature to the value pointed to by string pointer *temp.

long SetTemperature(char *temp)
