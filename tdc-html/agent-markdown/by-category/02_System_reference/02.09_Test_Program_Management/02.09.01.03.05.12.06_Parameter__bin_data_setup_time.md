# Parameter: bin_data_setup_time

The time in milliseconds the driver will wait for the binning signals to become stable, before it sends the end-of-test signal to the handler.

Driver default: depends on plug-in

Changeable at run-time: yes

Applicable for: handlers and probers

Example: bin_data_setup_time: 1
