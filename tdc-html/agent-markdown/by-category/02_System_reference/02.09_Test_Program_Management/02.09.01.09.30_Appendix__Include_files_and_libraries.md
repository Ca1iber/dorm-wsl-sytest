# Appendix: Include files and libraries

Your source file will probably contain some or all of the following lines. This depends on the libraries you will need to run your program.

```
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <errno.h>
```

They are standard include files that are part of the C high level language.

## SmarTest Specific Include File

The definitions of all symbolic constants, function declarations and structures that you are likely to need for your SmarTest test flow programs are contained in the include file /opt/hp93000/soc/pws/lib/tpi_c.h. To use these definitions in your program you must have the following statement in your testflow source file:

```
#include "/opt/hp93000/soc/pws/lib/tpi_c.h"
```

If you require extra constants that have not been defined in this include file, you have to define them yourself in the "defines" area of your program.
