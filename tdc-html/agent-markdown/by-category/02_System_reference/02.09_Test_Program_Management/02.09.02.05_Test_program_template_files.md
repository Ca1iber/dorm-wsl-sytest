A test program template contains a number of CSV tables that specify various aspects of the template in an easy-to-edit tabular format:

- [Test suite table](<02.09.02.05.01_Test_suite_table_of_a_TPT.md>)
- [Bin table](<02.09.02.05.02_Bin_table_of_a_TPT.md>)
- [Test table](<02.09.02.05.03_Test_table_of_a_TPT.md>)
- [Test parameter table](<02.09.02.05.04_Test_parameter_table_of_a_TPT.md>)
- [Test flag table](<02.09.02.05.05_Test_flag_table_of_a_TPT.md>)
- [Test stage table](<02.09.02.05.06_Test_stage_table_of_a_TPT.md>)

While all these tables can be edited with text editors, we recommend using the OpenOffice spreadsheet that is also part of the test program template: [OpenOffice spreadsheet for editing the CSV files](<02.09.02.05.07_OpenOffice_spreadsheet_for_editing_the_CSV_files.md>)

## Functional changes

- Introduced in SmarTest 7.0.4
- SmarTest 7.2.1: Added test table, test parameter table, and test stage table.
- SmarTest 7.2.1: Removed test type table and release management table.
