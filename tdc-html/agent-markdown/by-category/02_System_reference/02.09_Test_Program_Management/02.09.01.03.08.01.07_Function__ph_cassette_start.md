# Function: ph_cassette_start

This function assures that a cassette with untested wafers is inserted into the prober, before the next command in the application model is executed. The implementation of the function depends on the plug-in. For example, the function may ask the operator to insert a cassette, or may do nothing, if the prober manages the cassette handling autonomously.

Applicable for: prober driver

Example: PROB_HND_CALL (ph_cassette_start)
