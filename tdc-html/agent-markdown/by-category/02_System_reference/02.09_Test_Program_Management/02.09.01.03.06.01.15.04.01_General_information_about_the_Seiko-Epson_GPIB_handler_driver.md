# General information about the Seiko-Epson GPIB handler driver

This section provides general information about the Seiko-Epson GPIB handler driver.

## Configurations provided

The following configurations are provided with the driver:

- NS5000-GPIB-1.cfg
- NS5000-GPIB-2.cfg
- NS5000-GPIB-4.cfg
- NS6000-GPIB-1.cfg
- NS6000-GPIB-2.cfg
- NS6000-GPIB-4.cfg
- HONTECH-GPIB-1.cfg
- HONTECH-GPIB-2.cfg
- HONTECH-GPIB-4.cfg
- CHROMA3180-GPIB-4

The configurations differ only in the number of sites they provide and the model number.

## Supported handler models

The Seiko-Epson handler driver supports Seiko-Epson NS5000, NS6000 and NS7000 handlers, HonTech handlers, and Chroma 3180 handlers.

Note The HonTech handler is compatible with the Seiko-Epson GPIB protocol except for [certain status query commands](<02.09.01.03.06.01.15.04.03_GPIB_communication_flow_for_Seiko-Epson_handlers.md>).

## Functional changes

- SmarTest 7.3.2: Provides new driver configurations: HONTECH-GPIB-1.cfg, HONTECH-GPIB-2.cfg, and HONTECH-GPIB-4.cfg.
- SmarTest 7.3.2: The Seiko-Epson GPIB handler driver supports HonTech handlers with configurations in CHROMA3180-GPIB-4.
- SmarTest 7.5.3: The Seiko-Epson GPIB handler driver supports Chroma 3180 handlers.
- SmarTest 7.6.0: Auto-retest for HonTech handlers.
