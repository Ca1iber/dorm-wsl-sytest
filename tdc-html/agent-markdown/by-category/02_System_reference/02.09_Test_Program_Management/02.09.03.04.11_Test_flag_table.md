# Test flag table

The test flags table of the MTPT (STPM MCM mapping tables) describes test flag sets that are applied to tests in the MTP (master test program).

The table is stored in a file named testflags.csv in the MTPT directory. It is created by the [generate_template](<02.09.03.03.02_generate_template.md>) command.

The file is best edited by importing it into the [OpenOffice spreadsheet](<02.09.03.04.15_OpenOffice_spreadsheet_for_editing_the_CSV_files.md>) located in the [MTPT](<02.09.03.04_MTPT__STPM_MCM_mapping_tables.md>) folder. Editing is also possible in text editors, but this requires you to make sure yourself that all formatting is correct.

## Syntax

Each row in the test flag table describes a test flag set. The table contains these columns:

- FlagSet Id: The name of the flag set

This name can be used to reference the flag set from the [Test suite table](<02.09.03.04.05_Test_suite_table.md>).

- (individual flags): Each column corresponds to one flag. It can contain 1 to indicate that the flag is on, or 0 to indicate that it is off.
- Notes: This column allows both you and STPM MCM to add remarks about the flag set. These notes are just for human consumption and are never processed automatically by STPM MCM. They may be overwritten when the tables are updated, so they are not a suitable place for storing important information.

In all columns describing flag settings, 0 indicates that the flag is off and 1 indicates that it is on.
