The "NS5000-parallel" configuration is valid for NS 5000/6000 Seiko-Epson handlers.

Supported handler models

- NS5000 F(0)/F3/F4
- NS6000

Features

- up to 4 sites
- 4 DUT signals
- no global test start signal
- parallel binning
- explicit binning
- 4 bin categories
- no "empty" bin

Required handler cable

There is no preconfigured handler cable available for this configuration. Please see Seiko-Epson NS 5000/6000 parallel handler cable for the information on configuring the cable.
