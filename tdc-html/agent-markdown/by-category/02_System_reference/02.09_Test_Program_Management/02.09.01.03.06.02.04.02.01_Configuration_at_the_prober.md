# Configuration at the prober

The prober must be set up correctly with the driver. Please see the documentation of the prober for instructions on how to set the prober up.

20S configuration group The probers in the 20S configuration group must have the dip switch settings as listed in the table below.

 Note Any switches not listed are "Do not care" for the TEL GPIB prober driver plug-in. Switches marked "dc" are known to be "Do not care" for the driver. The recommended setting is shown.
