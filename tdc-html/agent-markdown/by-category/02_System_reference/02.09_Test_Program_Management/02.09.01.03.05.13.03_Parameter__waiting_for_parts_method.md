# Parameter: waiting_for_parts_method

Determines for a GPIO and a GPIB interface whether the driver will use a "polling" or an "interrupt" based algorithm while waiting for parts.

Note: For the GPIO, the current driver revision, Revision 3.2, only supports polling, that is, the driver repeatedly checks whether the equipment has sent the test start signal while you can choose between "polling" and "interrupt" for the GPIB.

Driver default (GPIO): "polling"

Driver default (GPIB): "interrupt"

Changeable at run-time: no

Applicable for: handlers and probers

Example: waiting_for_parts_method: "polling"
