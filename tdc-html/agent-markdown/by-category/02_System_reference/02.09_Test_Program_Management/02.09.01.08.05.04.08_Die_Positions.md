# Die Positions

## get

Retrieves the currently set x and y die coordinates of the die about to be tested, or which has just been tested (depending on whether the call is made before or after a device test. The parameters x and y are defined as longs, but are actually return values that can fit into an int.

If multiple sites are used, the second function (GetDiePosXYOfSite) allows you to retrieve die coordinates from a specific site. If you use the first function (GetDiePosXY), the die coordinates for the site currently in focus are returned.

long GetDiePosXY(long *x, long *y)

long GetDiePosXYOfSite(long site, long *x, long *y)

## set

Sets the x and y die coordinates of the die about to be tested when used before a device test takes place. The parameters x and y are defined as longs, but are internally typecast to an int.

The second function (SetDiePosXYOfSite) allows you to the die coordinates for a specific site. If you use the first function (SetDiePosXY), the die coordinates for the site currently in focus are set.

long SetDiePosXY(long x, long y)

long SetDiePosXYOfSite(long site, long x, long y)
