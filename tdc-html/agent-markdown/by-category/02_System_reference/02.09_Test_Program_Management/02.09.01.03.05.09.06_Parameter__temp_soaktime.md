# Parameter: temp_soaktime

Insert the list of temperature soaktimes in [seconds]. This parameter is only active, if temperature_control is set to "active" mode. The number of entries in the list must either match the number of entries of temp_chambers or one single value may be inserted.In case you insert one single value only, the soaktimes of all chambers will be set to this time.

Driver default: empty list

Changeable at run-time: yes

Applicable for: handlers and probers, plug-in dependent

Example 1: temp_soaktime: [30 20]

Example 2: temp_soaktime: 25
