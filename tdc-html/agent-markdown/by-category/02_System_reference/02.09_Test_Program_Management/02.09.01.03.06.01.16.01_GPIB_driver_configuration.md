# GPIB driver configuration

The following configurations are provided with the driver:

SRM-GPIB-1.cfg

SRM-GPIB-2.cfg

SRM-GPIB-3.cfg

SRM-GPIB-4.cfg

The configurations differ only in the number of sites.

## Default GPIB configuration

This section describes the variables used in the configuration files. When the configuration files are created, certain aspects necessarily have to be defined. The table below lists these aspects and how they are defined.

Important aspects of the SRM configuration files
 |

Aspect

 |

Used setting

 |
 |

Debug level

 |

0, will log only basic messages. It can be changed to a value between -1 and 4.

 |
 |

GPIB port used

 |

6, must be changed to correct value based on the handler's setup.

 |
 |

Bin mapping

 |

default

 |
 |

Test start detection

 |

Done by interrupt (SRQ). SRM driver plug-in only supports the interrupt mode. Polling mode is currently not supported.

 |
 |

Polling interval

 |

(Not useful for SRM driver plug-in right now) The default value is 100 ms, only used if waiting for parts is done by polling. It's kept in the configuration file for possible future enhancement when SRM handler support polling mode.

 |
