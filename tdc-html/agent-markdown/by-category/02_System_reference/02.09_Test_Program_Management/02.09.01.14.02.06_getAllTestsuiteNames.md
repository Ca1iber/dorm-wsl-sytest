# getAllTestsuiteNames()

 This API gets all the UTM-based test suite names of the test flow.

If it is successfully executed, a string vector holding the pointers to the test suites will be returned. Otherwise, an empty vector will be returned.

## Syntax

```
const std::vector<std::string> getAllTestsuiteNames();
```
