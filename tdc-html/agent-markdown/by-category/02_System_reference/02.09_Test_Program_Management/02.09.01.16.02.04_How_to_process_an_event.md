# How to process an event

## About this task

When an unmasked event is retrieved, you can retrieve the attributes of this event and log/print the needed information according to the event type. (See details of [Event types](<../02.10_Data_Logging/02.10.01.06.03_Event_types.md>).)

## Procedure

-  Retrieve each attribute of the event with [DRLEventGetAttribute](<../02.10_Data_Logging/02.10.01.04.01.02_DRLEventGetAttribute.md>).
-  Process the information of the attributes according to your needs. (See details of [Attribute types](<../02.10_Data_Logging/02.10.01.06.05_Attribute_types.md>).) For example, you can print out the information you are interested or summarize the test result and save it in the output file.

## Example

```
void ProcessBinReachedEventAttributes(const DRLEventRec *event)
{
  int number_of_attributes, i;
  double yield;
  DRLSiteIdAttr site_id;
  DRLAttributeRec attribute_rec;
  DRLBinAttr bin_attribute;

  number_of_attributes = DRLEventGetNoOfAttributes(event);
  for (i=0; i<number_of_attributes; i++)
  {
    if (DRLEventGetAttribute(event,i,&attribute_rec))
    {
      fprintf(stderr,"Error while reading attributes ");
      fprintf(stderr," - skipping event.\n");
      return;
    }
    switch (attribute_rec.type)
    {
      case BinAttrType:
      bin_attribute = attribute_rec.data.bin_attr;
      break;
      case SiteIdAttrType:
      site_id = attribute_rec.data.site_id_attr;
      break;
    }
  }
  tested_parts++;
  if (bin_attribute->is_good_bin)
  {
    good_parts++;
  }
  yield = ((double)good_parts) / (double)tested_parts;
  fprintf(stderr,"Site %d binned to bin %2s(%2d). Yield = %d/%d = %.2f%%\n",
          (int)site_id,bin_attribute->bin_name,bin_attribute->bin_number, good_parts,
          tested_parts, 100*yield);
}
```

This example processes the event of type BinReachedEventType and calculate and print out the yield.
