# SMARTEST_SESSION_TERMINATED

This asynchronous event indicates a SmarTest session has been shut down.

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

SESSION_ID

 |

The session ID this event belongs to.

 |
 |

O

 |

TIME_STAMP

 |

The time point when this event occurs. It consists two parts: `SECONDS` and `MICROSECONDS`.

 |
 |

O

 |

EVENT_NAME

 |

The event category. Here it is always `SESSION`.

 |
 |

O

 |

EVENT_BODY

 |

The event parameters. It contains the following memebers:

 |

SESSION_STATE

 |

The HVM event type. Here it is always `SMARTEST_SESSION_TERMINATED`.

 |
 |

VERSION

 |

The SmarTest version.

 |
 |

ONLINE_MODE

 |

The online/offline mode.

 |
 |

USER_MODE

 |

The user mode. It can be ENGINEER, SUPERVISOR, OPERATOR and OTHER.

 |

The parameter is represented by `ParamList` whose key and value are both string.

 |
