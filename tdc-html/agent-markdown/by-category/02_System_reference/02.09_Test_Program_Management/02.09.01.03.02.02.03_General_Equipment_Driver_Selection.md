# General Equipment Driver Selection

The general equipment driver is selected via the prober handler library selection of the test program, as illustrated in [Basic Driver Usage](<02.09.01.03.02.02_Basic_Driver_Usage.md>). This is the only specification you need to make in the test program definition in order to use the driver (see [Selecting the General Equipment Driver](<02.09.01.03.03.01_Selecting_the_General_Equipment_Driver.md>) for details.)

When the test program is started, the shared libraries of the general equipment driver and of the equipment specific plug-in (including the hook function library), which is specified in the global configuration, are loaded, and the driver configuration, which is also specified in the global configuration, is read (see [Basic Driver Usage](<02.09.01.03.02.02_Basic_Driver_Usage.md>)).
