# operation

The operation signature is to trigger the execution of HVMAPI remote control command that has the output value.

The execution is run asynchronously. It will get partial execution result via output value. The remaining execution result is notified via the event notification. There is only one API using the operation signature, `StartSmartestSession`.

An error object will be returned indicating the success of operation execution or the error occurs.

Prototype

```
xoc::hvmapi::Status operation(
const std::string &opName,
xoc::hvmapi::ParamList &opResults,
const xoc::hvmapi::ParamList &opParams=xoc::hvmapi::ParamList(),
const std::string &sessionId=std::string("") )
```

Parameters
 |

opName

 |

The HVM API operation name. Currently it can only be `StartSmartestSession`.

 |
 |

opResults

 |

The output results represented by `ParamList`.

 |
 |

opParams

 |

(optional) The input parameters represented by `ParamList.`

 |
 |

sessionId

 |

(optional) The ID of the SmarTest session to work with.

 |

## Example

```
ParamList opParams, opResult;
Status operation("StartSmartestSession", opResults, opParams);
```
