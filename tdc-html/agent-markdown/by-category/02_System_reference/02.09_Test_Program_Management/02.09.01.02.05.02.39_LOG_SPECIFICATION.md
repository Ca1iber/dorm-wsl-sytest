# LOG_SPECIFICATION

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.39.01_Associated_Syntax_Entities.md>)

This expression is used (in conjunction with RESULT_LOG, NEW_RESULT_PATH and POST_PROCESSING) to specify how and where results are logged.

For example, including the following lines in any particular level of your application model file, results in the header and summary being logged in the file specified by path/filename.

LOG_SPECIFICATION

RESULT_LOG=ON;

NEW_RESULT_PATH{path/filename};
