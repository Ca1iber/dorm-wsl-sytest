# Parameters for bin management

You should check these parameters if the binning does not function as expected:

- bin_mapping
- [handler|prober]_bin_ids
- hardbin_to_[handler|prober]_bin_map
- softbin_to_[handler|prober]_bin_map
- [handler|prober]_retest_bins

The last parameter lets you specify your own binning at unknown hardware bin code (see the Prober/Handler Drivers guide for details). The driver provides an error message at an unknown hardware bin code if this parameter is not defined.
