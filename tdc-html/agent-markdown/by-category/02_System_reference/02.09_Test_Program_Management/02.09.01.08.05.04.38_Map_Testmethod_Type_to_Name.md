# Map Testmethod Type to Name

This function maps a testmethod type to the corresponding testmethod name. That is, it returns a pointer to the name of the testmethod (for example, continuity, or global_search) when the corresponding type (4, 15 for the given examples) is provided. The type of a testmethod can be retrieved with the function GetTestsuiteList.

const char *TestmethodType2Name(int type)

The functions returns NULL if the value of type is invalid.
