# addEventListener

This signature is to register an event listener which will be executed by HVMAPI internal execution thread upon a particular event.

Prototype

```
xoc::hvmapi::Status addEventListener (
EventListenerType handler,
const std::string &evName,
const xoc::hvmapi::ParamList &evParams=xoc::hvmapi::ParamList(),
const std::string &sessionId=std::string(") );
```

Parameters
 |

handler

 |

The event handler that will be called for the registered event. It is the callback function provided by the client with the type of `EventListenerType`.

 |
 |

evName

 |

The HVMAPI event category which is concerned. It can be SESSION, EXECUTION, CALIBRATION, DIAGNOSTIC or ALARM.

 |
 |

evParams

 |

(optional) The event properties determining which HVMAPI event is concerned. If this is omitted, the client will be notified about all the HVM event types related to the event category (name).(See HVM event type in [Terminology](<02.09.01.10.03.03_Terminology.md>))

 |
 |

sessionId

 |

(optional) The ID of the SmarTest session to work with. If this is omitted, the client will monitor the events from all running SmarTest sessions.

 |

## Example

This example registers an event handler for the event type TESTFLOW_EXEC_COMPLETED.

```
using namespace std;
using namespace ::xoc::hvmapi;
ParamList evProperty;
string sid;
evProperty["EXECUTION_STATE"] = "TESTFLOW_EXEC_COMPLETED";
sid = sSessionId; //sSessionId is the variable containing the exact session ID to work with
addEventListener(handlerTestflowExecCompleted,
                    "EXECUTION",
                    evProperty, sid);
```
