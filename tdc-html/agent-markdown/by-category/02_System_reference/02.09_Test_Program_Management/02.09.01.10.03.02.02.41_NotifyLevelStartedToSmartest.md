# NotifyLevelStartedToSmartest

This notification command notifies the level start event to SmarTest.

It it mainly used when the FA (Factory Automation) client maintains the level handling and SmarTest does not know the level change information. FA can tell its state to HVMAPI and SmarTest with using this API. The other HVMAPI's client like Production Monitor and some SmarTest internal modules like EDL/STDF formatter could still work and be benefited.

When executing this API, the event `LEVEL_STARTED` will be notified. Success will be returned if the command is successfully issued. Otherwise an error object will be returned indicating the error code, description and severity.

## Dependency

The FA maintains level handling.

## Parameters

 |

I/O

 |

Parameters

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The ID of the SmarTest session to notify.

 |
 |

I

 |

EVENT_NAME

 |

The event category. Here it is always `EXECUTION`.

 |
 |

I

 |

EVENT_BODY

 |

The event parameters. It contains the following members:

 |

EXECUTION_STATE

 |

The HVM event name. Here it is always LEVEL_STARTED.

 |
 |

LEVEL_TYPE

 |

The level type can be: WAFER_LEVEL, DEVICE_LEVEL, PAUSE_LEVEL, CUSTOM_LEVEL.

 |
 |

LEVEL_NAME

 |

The level name within a certain level type.

 |

This parameter is represented by `ParamList` whose key and value are both `string` type.

 |

## Prototype

```
ParamList eventParams;
string sessionId;
Status notify("EXECUTION", eventParams, sessionId);
```

## Example

```
ParamList eventParams;
string sessionID;
eventParams["EXECUTION_STATE"] ="LEVEL_STARTED";
eventParams["LEVEL_TYPE"] = "WAFER_LEVEL";
eventParams["LEVEL_NAME"] = "Wafers";
notify("EXECUTION", eventParams, sessionID);
```
