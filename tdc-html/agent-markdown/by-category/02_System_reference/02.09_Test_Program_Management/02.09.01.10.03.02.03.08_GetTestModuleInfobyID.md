# GetTestModuleInfobyID

This data query command gets the information of the test module installed in the test board with specified test module ID.

SUCCESS will be returned if the command is successfully issued. Otherwise an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" is not online session ID.
- The designated module ID "XXX" does not exist.
 |

RECOVERABLE

 |

## Dependency

An online smartest session is running.

## Parameters

 |

I/O

 |

Parameters

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The online SmarTest session ID.

 |
 |

I

 |

MODULE_ID

 |

The ID of the test module.

 |
 |

O

 |

qrResults

 |

The query results are represented by a ParamList object. It contains the following members:

- MODULE_TYPE: The module type. It can be `CHANNEL_MODULE`, `DPS_MODULE` or `ANALOG_MODULE`.
- SLOT: The slot number for the test module.
- PART_NUMBER: The part number of the module.
- SERIAL_NUMBER: The module serial number.
- VENDOR: The test module vendor information.
- VERSION: The test module version information.
- REPAIR: How many times the test board has been repaired.
- FPGAREVS: The whole FPGA revisions on a board. The FPGA revision is presented by a hexadecimal number which begins with "0x". The whole FPGA revisons string may have a maximum of 8 FPGA revisions separated by ",".
- HW_TYPE: The hardware type of the test board.

- MAX_SPEED: (Only for channel module) The module's maximal speed.
 |

## Prototype

```
ParamList qrParams, qrResults;
string sessionId;
Status query("GetTestModuleInfoByID", qrResults,  qrParams, sessionId);
```
