# Function: ph_wafer_start

This function assures that an untested wafer is provided by the prober.

Depending on the plug-in, the function may send a command to the prober to provide the next wafer, or just ask the prober whether the next wafer is already in position for testing. The function waits either until the prober notifies that an untested wafer is ready for testing, or until a waiting-for-wafer-timeout occurs (see [Parameter: waiting_for_wafer_timeout and waiting_for_cassette_timeout](<02.09.01.03.05.04.10_Parameter__waiting_for_wafer_timeout_and_waiting_for_cassette_timeout.md>)).

ph_wafer_start is mandatory for wafer testing.

Applicable for: prober driver

Example: PROB_HND_CALL (ph_wafer_start)
