# Parameter: test_completed_line

Some handlers need an additional "test completed" signal from the test system to confirm that the binning process has finished.

This parameter defines such a pulse signal. The signal is sent after a delay of test_completed_delay has passed after the binning information is sent. The duration of the signal is defined with the test_completed_pulse_width .

Valid values for the output lines are "DO0" to "DO15", "CTL0", and "CTL1"

Driver default: no signal assumed necessary

Changeable at run-time: yes

Applicable for: handlers

Example: test_completed_line: "CTL0"
