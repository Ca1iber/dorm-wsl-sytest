# run_user_script

The run_user_script command for the SmarTest Program Manager MCM (STPM MCM) control file lets you execute any Python script from within the [control file](<02.09.03.03_STPM_MCM_control_file.md>). In particular, you can use it to copy auxiliary files that are outside the scope of STPM.

The execution context is provided to the script as a set of Python dictionaries that can be accessed by the user script.

The run_user_script command has as its only parameter the path of the Python script to run.

The Python script must begin with this code:

```
#!/usr/local/bin/python
import sys
import os
if len(sys.argv) < 2:
  raise "Error: MTP/STP data file missing."
execfile(sys.argv[1])
```

If you want to specify a different Python executable, edit the first line accordingly.

Add your own code after these lines.

The script can access the execution context through the Python dictionaries listed below. If any of the values are not yet defined (for example, because no MTP directory has yet been specified, they contain the string "None".

- mtpt_data contains information about the MTPT table directory and its contents in these keys:

  - template_dir: The path of the MTPT directory
  - config_path: The path of the config.mtpt configuration file
  - stp_table_path: The path of the CSV file for the [STP table](<02.09.03.04.01_STP_table.md>)
  - pin_table_path: The path of the CSV file for the [Pin mapping table](<02.09.03.04.02_Pin_mapping_table.md>)
  - test_table_path: The path of the CSV file for the [Test mapping table](<02.09.03.04.04_Test_mapping_table.md>)
  - shared_pin_table_path: The path of the CSV file for the [shared pin table](<02.09.03.04.10_Shared_pins_table.md>)
  - bin_table_path: The path of the CSV file for the [Bin mapping table](<02.09.03.04.06_Bin_mapping_table.md>)
  - test_num_table_path: The path of the CSV file for the [Test number mapping table](<02.09.03.04.07_Test_number_mapping_table.md>)
  - flag_table_path: The path of the CSV file for the [Test flag table](<02.09.03.04.11_Test_flag_table.md>)
  - test_suite_table_path: The path of the CSV file for the [Test suite table](<02.09.03.04.05_Test_suite_table.md>)
  - stp_test_info_table_path: Reserved for future expansion
  - flow_var_table_path: The path of the CSV file for the [Testflow variable mapping table](<02.09.03.04.08_Testflow_variable_mapping_table.md>)
  - special_tests_table_path: The path of the CSV file for the [Special tests table](<02.09.03.04.09_Special_tests_table.md>)
  - offlvl_suite_table_path: The path of the CSV file for the [DC level table](<02.09.03.04.12_Off_DC_levels_table.md>)

- mtp_data contains information about the MTP (master test program) in these keys:

  - testflow_path: The path of the MTP's testflow directory
  - config_path: The path of the MTP's configuration file
  - timing_path: The path of the MTP's timing file
  - levels_path: The path of the MTP's levels file
  - testflow_path: The path of the MTP's testflow file
  - pmf_path: The path of the MTP's pattern master file
  - analog_control_path: The path of the MTP's analog control file
  - waveform_path: The path of the MTP's waveform file
  - testflow_path: The path of the MTP's testflow file
  - tp_dir: The path of the MTP's device directory

- stps_data is a list that contains one dictionary for each STP (source test program) processed by the control file. Each dictionary contains these keys:

  - testflow_path: The path of the STP's testflow file
  - config_path: The path of the STP's configuration file
  - timing_path: The path of the STP's timing file
  - levels_path: The path of the STP's levels file
  - testflow_path: The path of the STP's testflow file
  - pmf_path: The path of the STP's pattern master file
  - analog_control_path: The path of the STP's analog control file
  - waveform_path: The path of the STP's waveform file
  - testflow_path: The path of the STP's testflow file
  - tp_dir: The path of the STP's device directory
  - stp_id: The ID of the STP as specified in the MTPT [STP table](<02.09.03.04.01_STP_table.md>)
  - prefix: The prefix of the STP that is specified in the MTPT [STP table](<02.09.03.04.01_STP_table.md>)

## Syntax

```
run_user_script(script = <path>)
```

Parameter
 |

script

 |

The path to the user script file.

<path> can be relative or absolute. If it is relative, the current directory is the base directory.

 |

## Example

This control file and user script concatenate the contents of the analog control files of all STPs to the analog control file of the MTP.

Control file:

```
# MTPT directory
mtp_template_dir = 'MTPT'

# MTP Device Path ( points to device testflow )
mtp_device_testflow = 'mtp_device/testflow/mtp_device.tf'

# Run script
run_user_script(script = "myscript.py")
```

User script myscript.py:

```
#!/usr/local/bin/python

import sys
import os

# import MTP and STPs data
if len(sys.argv) < 2:
  raise "Error: MTP/STP data file missing."
execfile(sys.argv[1])

# fetch anaset path from MTP
anaset_path = mtp_data['analog_control_path']

# open MTP anaset file
out = open(anaset_path,'a')

# for each STP
for stp in stps_data:
  # fetch STP anaset path
  stp_anaset_file = stp['analog_control_path']
  if '' == stp_anaset_file:
    continue

  # append contents of STP anaset file to MTP anaset file
  data = open(stp_anaset_file)
  for line in data:
    out.write(line)
  data.close()

# close MTP anaset file
out.close()
```
