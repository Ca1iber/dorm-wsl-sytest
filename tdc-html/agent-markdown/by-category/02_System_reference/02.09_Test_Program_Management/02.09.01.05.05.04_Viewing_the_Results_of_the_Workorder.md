# Viewing the Results of the Workorder

#### Subtopics

- [Viewing Results During Workorder Execution](<02.09.01.05.05.04.01_Viewing_Results_During_Workorder_Execution.md>)
- [Viewing Results After Workorder Execution](<02.09.01.05.05.04.02_Viewing_Results_After_Workorder_Execution.md>)

The results of a test run can be viewed

- during workorder execution by watching the graphic result display screens
- and/or after workorder execution by analyzing files where results have been written during test.
