# write_tp

The write_tp command for the SmarTest Program Manager (STPM) [control file](<02.09.02.03_STPM_control_file.md>) writes the modified master test program (MTP) from memory back to disk.

Before you can write the MTP back to disk, you must have specified it with the [mtp_device_testflow](<02.09.02.03.02_File_and_parameter_settings.md>) setting, causing STPM to read it into memory. Usually, you will want to modify it using [integration commands](<02.09.02.03.01_Structure_of_an_STPM_control_file.md>) before writing it to disk.

A control file can contain multiple write_tp statements. In that case, each one creates a separate file. Each file contains the state of the MTP in memory at the time the write_tp statement was encountered, that is, with all changes that were made before the write_tp statement was encountered but ignoring any changes made later in the control file.

## Syntax

```
write_tp(
    path = '<mtp_target_file>',
[pre_proc = <pre_proc>, ]
[post_proc = <post_proc>]
)
```

## Parameters

The parameters in the order in which they are listed above:

 |

path

 |

<mtp_target_file> (string) is the name and location under which STPM saves the MTP (master test program) testflow file after it has modified it.

It can be an absolute or a relative path. If it is a relative path, the base directory is the current working directory at the time STPM was called.

You can specify the same file here as for mtp_device_testflow. In that case, the original file is modified in place.

(You can still have STPM automatically create a backup of the MTP; see [enable_backup](<02.09.02.03.02_File_and_parameter_settings.md>) for details.)

 |
 |

pre_proc

 |

<pre_proc> is a script that is executed before this command.

The syntax of the parameter value is described in [Preprocessing and postprocessing scripts](<02.09.02.03.03_Preprocessing_and_postprocessing_scripts.md>).

This is an optional parameter.

 |
 |

post_proc

 |

<post_proc> is a script that is executed after this command.

The syntax of the parameter value is described in [Preprocessing and postprocessing scripts](<02.09.02.03.03_Preprocessing_and_postprocessing_scripts.md>).

This is an optional parameter.

 |
