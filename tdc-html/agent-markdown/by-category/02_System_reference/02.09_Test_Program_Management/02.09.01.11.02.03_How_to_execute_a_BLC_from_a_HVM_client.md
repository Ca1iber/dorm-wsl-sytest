# How to execute a BLC from a HVM client

## About this task

Four HVM APIs are defined for the BLC execution: `ExecBLC`, `AbortBLC`, `PauseBLC` and `ResumeBLC`.

## Before you begin

Make sure you are using SmarTest 6.5.0 or above versions.

## Procedure

-  Create a HVM client and call the BLC with the API ExecBLC, AbortBLC, PauseBLC and ResumeBLC.
-  Make the HVM client as usual.
-  Execute the HVM client. (See [How to Create and Execute the Application Client using HVM API](<02.09.01.10.02.06_How_to_create_and_execute_the_client_application_with_HVM_API.md>).)

## Results

The BLC are executed and the device is tested.

## Functional changes

- Introduced in SmarTest 6.5.0
