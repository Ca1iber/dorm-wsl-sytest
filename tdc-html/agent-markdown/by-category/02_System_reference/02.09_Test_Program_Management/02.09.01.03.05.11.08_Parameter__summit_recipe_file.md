# Parameter: summit_recipe_file

In case the temperature of a Summit handler is controlled by the driver, the driver needs to set up a recipe file located in the Summit handler to store the temperature parameters. This parameter defines the name of the file to be used in the Summit controller.

Driver default: no default

Changeable at run-time: yes

Applicable for: Delta Summit handlers

Example: summit_recipe_file: "tempGPIB"
