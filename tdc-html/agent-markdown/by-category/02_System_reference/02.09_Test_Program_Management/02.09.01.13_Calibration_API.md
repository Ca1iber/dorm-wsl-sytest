# Calibration API

#### Subtopics

- [How to use the calibration API](<02.09.01.13.01_How_to_use_the_calibration_API.md>)
- [Data types](<02.09.01.13.02_Data_types.md>)
- [API functions](<02.09.01.13.03_API_functions.md>)

 With this API, you can query

- the required next calibration date,
- the information about which parts of the test system have been calibrated.

To implement these functionalities, the following data types and functions are provided.

 Data types:

- [CalStatusEvent](<02.09.01.13.02_Data_types.md#_106812__s_CalStatusEvent>)
- [CalStatusType](<02.09.01.13.02_Data_types.md#_106812__s_CalStatusType>)
- [CalibrationCategory](<02.09.01.13.02_Data_types.md#_106812__s_CalibrationCategory>)
 API functions:

- [calibrationCategoryList_next()](<02.09.01.13.03.01_calibrationCategoryList_next.md>)
- [calibrationCategoryList_new()](<02.09.01.13.03.02_calibrationCategoryList_new.md>)
- [calibrationCategoryList_delete()](<02.09.01.13.03.03_calibrationCategoryList_delete.md>)
- [isValidCalibration()](<02.09.01.13.03.06_isValidCalibration.md>)
- [getCalibrationDate()](<02.09.01.13.03.04_getCalibrationDate.md>)
- [getCalibrationHistory()](<02.09.01.13.03.05_getCalibrationHistory.md>)

This interface is provided with the SmarTest installation package. You can find the header files calibration.h and calibration_common.h in the directory /opt/hp93000/soc/pws/include and the library libmcpu.so in the directory /opt/hp93000/soc/pws/sh_lib.

For information on how to perform the calibration, refer to Executing SmarTest 7.10 maintenance activities in the Service documentation.

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 6.5.0: New API function getCalibrationHistory().
