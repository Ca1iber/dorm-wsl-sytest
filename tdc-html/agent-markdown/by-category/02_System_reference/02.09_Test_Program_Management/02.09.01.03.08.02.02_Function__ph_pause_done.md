# Function: ph_pause_done

Notifies the driver that the pause level is left. When leaving the pause level, the driver will read the state of the CI flags check_dev, skip and retest.

A call of ph_pause_done is mandatory when the pause level is left.

Applicable for: handler and prober driver

Example: PROB_HND_CALL (ph_pause_done)
