# Parameters for LAN communication

The following parameters affect the LAN communication between the driver and equipment.

- waiting_for_parts_method

For the LAN interface, the driver will always use a polling-based approach to get the parts.

- polling_interval

If the driver uses a polling-based algorithm this interval is used.
