# SMARTEST_SESSION_READY

This asynchronous event indicates a SmarTest session is fully started and ready to accept commands operations and queries. The event is notified after starting a new SmarTest session or the successful execution of reset operation.

Parameters
 |

I/O

 |

Parameter

 |

Description

 |
 |

O

 |

SESSION_ID

 |

The ID of the SmarTest session this event belongs to.

 |
 |

O

 |

TIME_STAMP

 |

The time point when this event occurs. It consists two parts: `SECONDS` and `MICROSECONDS`.

 |
 |

O

 |

EVENT_NAME

 |

The event category. Here it is always `SESSION`.

 |
 |

 |

EVENT_BODY

 |

The event parameters. It contains the following members:

 |

SESSION_STATE

 |

The HVM event type. Here it is always `SMARTEST_SESSION_READY`.

 |
 |

VERSION

 |

The SmarTest version.

 |
 |

ONLINE_MODE

 |

The online/offline mode.

 |
 |

USER_MODE

 |

The user mode. It can be ENGINEER, SUPERVISOR, OPERATOR or OTHER.

 |
 |

LOGIN_USER

 |

The user who starts the SmarTest session.

 |

This parameter is represented by `ParamList` whose key and value are both string.

 |
