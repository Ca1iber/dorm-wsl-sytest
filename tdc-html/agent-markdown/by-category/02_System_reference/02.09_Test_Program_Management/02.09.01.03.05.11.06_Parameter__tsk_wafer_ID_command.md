# Parameter: tsk_wafer_ID_command

TSK probers can be configured to use either the "W" or the "b" command to perform a wafer ID request or a probe needle cleaning. This parameter defines, which command ("W" or "b") will be send to perform a wafer ID request. The other one is then used to perform probe needle cleaning.

Driver default: "W"

Changeable at run-time: no

Applicable for: TSK probers

Example: tsk_wafer_ID_command: "b"
