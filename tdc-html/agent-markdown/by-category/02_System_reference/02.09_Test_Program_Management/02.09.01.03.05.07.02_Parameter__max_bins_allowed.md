# Parameter: max_bins_allowed

This parameter defines the max bins allowed for the probers.

It's specific for TSK probers and the value can be `"64"` or `"256"`.

Driver default: "64"

Changeable at run-time: no

Applicable for: TSK probers

Example: max_bins_allowed: "256"

## Functional changes

- Introduced before SmarTest 6.3.2
