# User Flags

User flags are of type integer. The flags take on the name that the user specifies.

User Flags are defined in the [Variables page](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.01.05_Variables_page.md>) of the [Flow Data Editor](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.01_Flow_Data_Editor.md>) and stored in the flags section of the [Testflow file](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.05_Testflow_file.md>).
