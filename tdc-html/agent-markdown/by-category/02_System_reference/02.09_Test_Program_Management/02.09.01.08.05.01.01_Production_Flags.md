# Production Flags

Production flags typically have a boolean 0/1 value representing the states on and off. However, some of the flags contain an integer values.

The Production Flags each have a PREDEFINED name, and are grouped into the following categories:

- [Test suite flags](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.04_Test_suite_flags.md>)
- [Testflow flags](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.02_Testflow_flags.md>)
- [System Flags (Testflow flags for dataloggging)](<../02.08_Setup_and_Result_Tools/02.08.04.32.01.02.07.03_Testflow_flags_for_data_logging.md>)

All production flags are declared as type integer (int).
