# Restrictions

The number of probes for multi-die probing is restricted to a maximum value of 32 (8 for the 20S configuration group, if the parameter tel_o_command_style is set to ASCII, see note in the configuration file).

Sub-die probing is not supported.

Absolute die and chuck positioning by means of mills or microns is not supported. Positioning can only be carried out by index step position.

Two configuration parameters have been added in response to problems encountered with some TEL probers. The configuration parameters prevent the TEL driver from sending out certain commands or queries. For compatibility the values for the configurable parameters are set to the same behavior as seen with previous driver releases. Another configuration parameter tel_binning_method is added for the model TEL P-12 and P-8 to define the format of binning data.

TEL configuration parameters
 |

Configuration Parameter

 |

Description

 |

Setting

 |
 |

tel_send_id_query

 |

Send the "?V" command: Query the machine ID from the prober during startup.

 |

Default setting: "yes"

May need to be set to "no" if the prober experiences problems during startup.

 |
 |

tel_send_wafer_abort

 |

Send the "VF" command: Unload all wafers and force a lot end.

 |

Default setting: "yes"

May need to be set to "no" if prober experiences problems when a user decides to quit a currently running session where a wafer is still being probed.

 |
 |

tel_binning_method

   | For TEL P-12 and P-8 probers.

Define the valid format of binning data sent to the prober.

 |

Default value is "binary" which supports 1,000,000 bins which numbers are from 0 to 999,999.

The other option is "parity" which supports up to 32 bins.

 |
 |

tel_send_z_command

 |

Control whether the prober sends the "`z`" command after die coordinates have been retrieved.

 |

"yes" or "no".

Default setting: "yes".

 |

## Functional changes

- Introduced before SmarTest 6.3.2
- SmarTest 7.4.4: TEL P12 and P8 probers support up to 1,000,000 bins in the "binary" binning data mode.
