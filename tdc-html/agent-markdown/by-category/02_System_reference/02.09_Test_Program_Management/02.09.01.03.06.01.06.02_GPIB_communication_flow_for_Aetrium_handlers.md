# GPIB communication flow for Aetrium handlers

Describes the GPIB communication between the driver and the handler. The actions and messages are listed in the sequential order in the table below. (See [Conventions for GPIB communication](<02.09.01.03.06.01.04_Conventions_for_GPIB_LAN_communication.md>) for descriptions of the syntax.)
