# Setting the Testsuite Flag of All Testsuites in List

## Use

long SetTestsuiteFlagOfList(CI_CPI_TESTSUITE_LIST *testsuite_list, char* flag_name, long value)

Sets the testsuite flag flag_name of all testsuites in the *testsuite_list to value, OR if flag_name is NULL, it writes the flag settings stored in *testsuite_list to the testsuite flags. This feature can be used in conjunction with GetTestsuiteList() in order to restore an earlier state.

The returned values are,

 |

0

 |

OK

 |
 |

!=0

 |

an error has occurred (for example, flag_name is not a valid testsuite flag)

   |
