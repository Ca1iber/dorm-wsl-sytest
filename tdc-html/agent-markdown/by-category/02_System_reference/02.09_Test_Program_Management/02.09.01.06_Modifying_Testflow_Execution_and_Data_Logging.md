# Modifying Testflow Execution and Data Logging

#### Subtopics

- [Overview](<02.09.01.06.01_Overview.md>)
- [Accessing Testflow Settings](<02.09.01.06.02_Accessing_Testflow_Settings.md>)
- [Using Production Settings](<02.09.01.06.03_Using_Production_Settings.md>)
- [Site disabling](<02.09.01.06.04_Site_disabling.md>)

For modifying testflow execution you must either launch the SmarTest software in engineering mode (see [Starting SmarTest with engineer mode](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.01.03_Starting_SmarTest_with_engineer_mode.md>)) or switch to the engineering status from within SmarTest (see [Changing the User Mode](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.01.04_Changing_the_User_Mode.md>)).

- With engineering status, you have access to testflow (flags) settings and production settings. After an overview section introducing these settings, this chapter describes how to do this.
- The engineering/development tool set is available from within the SmarTest production interface, when you are in engineering mode. These tools are accessed from a group of buttons displayed at the top of the screen (main menu buttons).
