# Parameter:mirae_send_siteselection_cmd

This parameter controls whether to send the `CONTACTSEL` or `SITESEL` command to the handler.

The value could be `"yes"` or `"no"`. This parameter is used together with the handler_site_mask parameter. If the value is set to "yes", the `CONTACTSEL` or `SITESEL` command will be sent to the handler during handler driver initialization

Driver default: "no"

Changeable at run-time: no

Applicable for: Mirae handlers, Techwing handlers

Example: `mirae_send_siteselection_cmd: "yes"`

## Functional changes

- Introduced before SmarTest 6.3.2
