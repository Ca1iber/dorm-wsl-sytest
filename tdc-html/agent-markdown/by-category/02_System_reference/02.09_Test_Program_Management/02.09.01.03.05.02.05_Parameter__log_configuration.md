# Parameter: log_configuration

The driver may log the contents of the driver configuration file which was loaded at driver start-up to the message log output.

If set to "yes", this configuration will be logged at the ph_driver_start call from the application model.

Driver default: "no"

Changeable at run-time: no

Applicable for: handlers and probers

Example: log_configuration: "yes"
