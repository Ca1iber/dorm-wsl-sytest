# Shared library access API

#### Subtopics

- [LoadPHDriverLib()](<02.09.01.11.03.05.01_LoadPHDriverLib.md>)
- [CallPHDriverFunc()](<02.09.01.11.03.05.02_CallPHDriverFunc.md>)
- [LoadExecInputLib()](<02.09.01.11.03.05.03_LoadExecInputLib.md>)
- [CallExecInputFunc()](<02.09.01.11.03.05.04_CallExecInputFunc.md>)
- [LoadDataBridgeLib()](<02.09.01.11.03.05.05_LoadDataBridgeLib.md>)
- [CallDataBridgeFunc()](<02.09.01.11.03.05.06_CallDataBridgeFunc.md>)

These APIs are provided to use the existing shared libraries, including generic prober/handler driver, execution input functions and data bridge functions.

With these APIs, the existing shared libraries can be loaded into the memory at the run time. The BLC executable file need not to link to a fixed shared library. For example, you specify the required Prober/Handler driver library in the input file and dynamically load the library at the run time. And you can change the driver without rebuilding the BLC executable file.

Note You can also directly use the ci/cpi functions that can be used in the prober/handler driver, execution input and data bridge in the programming with BLC APIs.

## Functional changes

- Introduced in SmarTest 6.5.0
