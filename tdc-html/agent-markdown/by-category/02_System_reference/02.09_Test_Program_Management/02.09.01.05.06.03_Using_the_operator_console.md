# Using the operator console

#### Subtopics

- [Buttons and menus of the operator console](<02.09.01.05.06.03.01_Buttons_and_menus_of_the_operator_console.md>)

This section describes the usage the operator console.

## Before you begin

Before you can use the console, make sure that:

- The operator console is installed and has booted as described in [Installing the operator console](<02.09.01.05.06.01_Installing_the_operator_console.md>).CAUTION Always use the operator console with batteries loaded. If you use the console without batteries and disconnect it while running SmarTest, whether by chance or by purpose, SmarTest may freeze.
- The org file at /etc/opt/hp98000/soc/ is adapted as described in [Adapting the org file](<02.09.01.05.06.02_Adapting_the_org_file.md>).
- Set up or select the [Application model](<../02.08_Setup_and_Result_Tools/02.08.04.02_Application_model.md>) for your needs.
- At least one work order is defined, that shall be used with the console. For detailed information, see [Creating New Workorders](<02.09.01.05.01_Creating_New_Workorders.md>).Note When naming work orders for usage with the operator console: Make sure that the work order name consists of numbers only. Do not use other characters like alphabetical or symbol. Note Make sure that the operator console has booted properly before starting SmarTest.
- Use the following command to start SmarTest:

HPSmarTest -C

 Note SmarTest recognizes the console in this "operator console mode" only.

## Procedures

### General usage

Note After a defined period the console starts a screen saver. To stop the screen saver and to re-activate the console just touch the display.

- Working with workorders using the operator console is similar to the procedures using SmarTest on the system controller, see [Working with workorders](<02.09.01.05_Working_with_workorders.md>).
- To call a menu, press the respective function key, see [Buttons and menu of the operator console](<02.09.01.05.06.03.01_Buttons_and_menus_of_the_operator_console.md>)

### Executing a workorder

Note The following procedure reflects the usage of the standard workorder. It may vary according to your workorders.

- On the operator console, type the workorder name and press OK.
- Type the lot ID and press OK.
- Type your operator ID and press OK.
- Type the package ID and press OK.
- Press Start.

To cancel the procedure, press Abort.

The output depends on your Application Model and your workorder.

For further information, see [Executing a Workorders](<02.09.01.05.05_Executing_a_Workorder.md>).
