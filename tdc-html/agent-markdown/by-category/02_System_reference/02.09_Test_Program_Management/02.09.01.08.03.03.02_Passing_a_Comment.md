# Passing a Comment

To pass a comment to the application model file variable, write to stdout. All output that you write to stdout is classified as the comment, and is terminated by the termination of the script. The length of the comment is set automatically, and is equal to the number of bytes written to stdout.

When a script is started in background mode, comments are ignored.
