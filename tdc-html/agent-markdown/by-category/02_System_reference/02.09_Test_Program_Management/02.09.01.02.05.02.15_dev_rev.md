# dev_rev

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.15.01_Associated_Syntax_Entities.md>)

The dev_rev keyword is used as an argument for [GET_TEST_INFO](<02.09.01.02.05.02.36_GET_TEST_INFO.md>) to return the revision number of the current device as entered in the Device Revision field of the Information screen of the testflow editor.

## Functional changes

- Introduced before SmarTest 6.3.2
