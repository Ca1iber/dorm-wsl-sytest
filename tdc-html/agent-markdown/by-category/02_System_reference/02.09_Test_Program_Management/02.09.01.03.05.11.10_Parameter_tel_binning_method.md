# Parameter:tel_binning_method

This parameter selects the binning method for probers.

It's specific to TEL P12 probers and the value can be:

`"parity"`: supports up to 32 bins.

`"binary"`: supports up to 256 bins.

Driver default: "parity"

Changeable at run-time: no

Applicable for: TEL P12 prober

Example: tel_binning_method: "binary"

## Functional changes

- Introduced before SmarTest 6.3.2
