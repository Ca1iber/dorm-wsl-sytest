# Communication

The driver can communicate

- with the test system via the SmarTest software, and
- with the equipment by using either

  - a GPIO interface, or
  - a GPIB interface.
  - a LAN (TCP/IP) interface

## Functional changes

- Introduced in SmarTest 7.0.4
- SmarTest 7.2.3: LAN supported
