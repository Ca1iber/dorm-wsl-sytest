# How to start SmarTest with HVMAPI

In the factory automation production environment, SmarTest is usually started in the SUPERVISOR and ONLINE mode. When starting SmarTest with HVMAPI, you can catch and process the HVM API events issued during the startup.

## About this task

At this time, you start SmarTest with the safe device.

## Before you begin

The safe device is ready to use.

## Procedure

-  Prepare the parameters to start a SmarTest, including online mode, user mode and device path.
-  Start SmarTest with the [StartSmartestSession](<02.09.01.10.03.02.01.17_StartSmartestSession.md>) API.
-  Report the SmarTest startup status.

## Example

```
string safe_device;
opParams["ONLINE_MODE"] = "OFFLINE";
opParams["USER_MODE"] = "SUPERVISOR";
safe_device="/home/demo/devices/dummy";
removeLockFile(safe_device);
if(switchDeviceInUse(safe_device))
{
  cout <<"cannot start SmarTest and safe_device does not exist" <<endl;
  return 1;
}

::xoc::hvmapi::Status retVal = operation("StartSmartestSession", opResults, opParams);
if(!retVal.isError())
{
  cout <<"Successful startup and the session ID is s%\n" << opResults["SESSION_ID"] <<endl;
}
else
{
  cout <<"\nerror code" << retVal.code() <<"\nerror description"<< retVal.text()<<endl;
}
```

## What to do next

After the SmarTest is started, you need to synchronize with the [SMARTEST_SESSION_READY](<02.09.01.10.03.02.01.14_SMARTEST_SESSION_READY.md>) event and change to the target device.

## Functional changes

- Introduced before SmarTest 6.3.2
