# Customizing Driver Configurations

#### Subtopics

- [Debugging a Driver Configuration](<02.09.01.03.04.01_Debugging_a_Driver_Configuration.md>)
- [Creating a New Driver Configuration](<02.09.01.03.04.02_Creating_a_New_Driver_Configuration.md>)

This chapter gives you some general hints for debugging the configuration and for setting up configurations for equipment that is not directly supported, or modifying a configuration for special requirements (such as changing the bin mapping or reprobing).

SmarTest provides a designated editor (editSpecificConfig) especially for opening, editing and saving driver configurations. See the Prober/Handler Drivers guide for detailed information on using the editSpecificConfig tool.

You can also use any text editor for modifying the configuration files.
