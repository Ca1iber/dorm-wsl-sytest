# General information about the Electroglas drivers

This section provides general information about the Electroglas prober drivers.

Restrictions

The number of probes(sites) for multi-die probing is restricted to a maximum value of 32 (8 for the Prober Vision Series setups).

Sub-die probing is supported.

Absolute die and chuck positioning by means of mills or microns is not supported. Positioning can only be carried out by indexing the step position.
