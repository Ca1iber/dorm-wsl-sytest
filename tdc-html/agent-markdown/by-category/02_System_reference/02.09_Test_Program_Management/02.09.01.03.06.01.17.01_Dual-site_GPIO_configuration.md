#### Subtopics

- [Valid combinations of plug-ins and configuration files](<02.09.01.03.06.01.17.01.01_Valid_combinations_of_plug-ins_and_configuration_files.md>)

- [Timing diagram (Synax dual-site)](<02.09.01.03.06.01.17.01.04_Timing_diagram__Synax_dual-site.md>)

The "Dual-site" configuration is valid for Synax handlers.

Supported handler models

- 141H10A
- 1211H04A
- 1701-01A
- 1701-02A/B
- 1701-03A

Features

- up to 2 sites
- 2 DUT signals
- no global test start signal
- parallel binning
- explicit binning
- 8 bin categories
- no "empty" bin

Required handler cable

- E2790-61601-2
