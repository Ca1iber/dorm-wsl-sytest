# ExecTestprogram

The remote control command tries to execute the test program that has been downloaded to the tester. When the test program is starting to execute, the event `TESTPROGRAM_EXEC_STARTED` is notified. When the execution is finished, the event `TESTPRGROAM_EXEC_COMPLETED` is notified.

SUCCESS will be returned if the command is successfully issued. Otherwise an error object indicating the error code, description and severity will be returned.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- There is no test program downloaded.
- The execution of test program is still on running, cannot run a new execution of test program.
- There is testflow on running, cannot execute the test program.
 |

RECOVERABLE

 |

## Dependency and Constraints

- The test program is already downloaded.
- During the execution of a test program, the testflow is automatically executed. You cannot use this API when a test program or testflow is in execution.

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The ID of the SmarTest session to work with.

 |

## Prototype

```
ParamList cmdParams;
string sessionId;
Status command("ExecTestprogram", cmdParams, sessionId);
```

## Example

```
/* execute the test program which is already downloaded */
string sid; /* sid is SmarTest session ID to work with */
command("ExecTestprogram", ParamList(), sid);
```
