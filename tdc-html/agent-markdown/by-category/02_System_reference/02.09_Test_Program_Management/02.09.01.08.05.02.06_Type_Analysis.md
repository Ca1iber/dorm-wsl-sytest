# Type Analysis

If you do not know the type of a user flag, you can find this out using the function GetUserType. This function sets the parameter type to one of the following three constants:

CI_CPI_FLG = 0 /* flag */

CI_CPI_DBL = 1 /* double */

CI_CPI_STR = 2 /* string */
