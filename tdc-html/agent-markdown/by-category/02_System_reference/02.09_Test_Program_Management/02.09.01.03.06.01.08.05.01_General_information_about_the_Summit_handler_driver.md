# General information about the Summit handler driver

The following sections provide general information about the Summit handler driver.

## Configurations provided

The following configurations are provided with the driver:

- Summit-GPIB-1.cfg
- Summit-GPIB-2.cfg
- Summit-GPIB-4.cfg
- Summit-GPIB-8.cfg

The configurations differ only in the number of sites they provide.

## Supported handler models

The Summit handler driver supports all Delta Design Summit handler models.
