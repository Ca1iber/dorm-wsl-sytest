# device

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.16.01_Associated_Syntax_Entities.md>)

The device keyword is used as an argument for [GET_TEST_INFO](<02.09.01.02.05.02.36_GET_TEST_INFO.md>) to return the name of the current device as specified by the last element of the path of the current device directory.
