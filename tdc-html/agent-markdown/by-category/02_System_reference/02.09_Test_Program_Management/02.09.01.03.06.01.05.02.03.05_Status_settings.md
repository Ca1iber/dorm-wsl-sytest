# Status settings

You can use GPIB commands to set up the handler status. These commands can be sent by using the function [ph_set_status()](<02.09.01.03.08.04.02_Function__ph_get_status.md>).

 |

Message from driver

 |

Message from handler

 |

Description

 |
 |

`ACMCLEAR?`

 |

 |

This command clears all operation data (accumulated data).

 |
 |

 |

`ACMCLEARED | SETTINGNG`

 |

If the data has been correctly cleared, the handler returns ACMCLEARED.

If the data has not been cleared, the handler returns SETTINGNG.

 |
 |

`ACMRETESTCLEAR?`

 |

 |

This command clears the data of retest categories.

 |
 |

 |

`ACMRETSETCLEARED | SETTINGNG`

 |

If the data has been correctly cleared, the handler returns ACMRETSETCLEARED.

If the data has not been cleared, the handler returns SETTINGNG.

 |
 |

`CHANGEPAGE d`

 |

 |

This command changes the display of the handler.

- d = 0: Hide the GPIB communication dialog box.
- d = 1: Display the GPIB communication dialog box.
 |
 |

 |

`SETTINGOK | SETTINGNG`

 |

If the display has been changed successfully, the handler returns SETTINGOK, otherwise it returns SETTINGNG.

 |
 |

`GPIBTIMEOUT dd`

 |

 |

This command sets the GPIB communication timeout value in the handler.

dd is the timeout in seconds. The values are from 1 to 60.

 |
 |

 |

`SETTINGOK | SETTINGNG`

 |

If the timeout has been configured successfully, the handler returns SETTINGOK, otherwise it returns SETTINGNG.

 |
 |

`INPUTQTY dddd`

 |

 |

This command inputs a lot quantity.

dddd is the number.

 |
 |

 |

`SETTINGOK | SETTINGNG`

 |

If the input quantity has been configured successfully, the handler returns SETTINGOK, otherwise it returns SETTINGNG.

 |
 |

`LOTCLEAR?`

 |

 |

This command clears all operation data (lot data).

 |
 |

 |

`LOTCLEARED | SETTINGNG`

 |

If the lot data has been correctly cleared, the handler returns LOTCLEARED.

If the lot data has not been cleared, the handler returns SETTINGNG.

 |
 |

`LOTEND d`

 |

 |

This command executes the lot end sequence.

- d = 0: Start the execution of the lot end sequence.
- d = 1: Cancel the execution of the lot end sequence.
 |
 |

 |

`SETTINGOK | SETTINGNG`

 |

If the lot end sequence has been configured successfully, the handler returns SETTINGOK, otherwise it returns SETTINGNG.

 |
 |

`LOTRETESTCLEAR?`

 |

 |

This command clears the lot retest data.

 |
 |

 |

`LOTRETESTCLEARED | SETTINGNG`

 |

If the lot retest data has been correctly cleared, the handler returns LOTRETESTCLEARED.

If the lot retest data has not been cleared, the handler returns SETTINGNG.

 |
 |

`SOFTRESET`

 |

 |

This command resets the handler software.

 |
 |

`SOUNDOFF`

 |

 |

This command turns off the sound of the handler.

 |
 |

 |

`SETTINGOK | SETTINGNG`

 |

If the sound has been tuned off successfully, the handler returns SETTINGOK, otherwise it returns SETTINGNG.

 |
 |

`START`

 |

 |

This command starts the handler.

 |
 |

 |

`SETTINGOK | SETTINGNG`

 |

If the handler has been started successfully, the handler returns SETTINGOK, otherwise it returns SETTINGNG.

 |
 |

`STOP`

 |

 |

This command stops the handler.

 |
 |

 |

`SETTINGOK | SETTINGNG`

 |

If the handler has been stopped successfully, the handler returns SETTINGOK, otherwise it returns SETTINGNG.

 |
