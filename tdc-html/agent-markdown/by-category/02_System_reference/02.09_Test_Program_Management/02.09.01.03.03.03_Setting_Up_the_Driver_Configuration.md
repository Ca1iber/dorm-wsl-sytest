# Setting Up the Driver Configuration

#### Subtopics

- [Editing a Driver Configuration File](<02.09.01.03.03.03.01_Editing_a_Driver_Configuration_File.md>)
- [Handling an Attributes Definition File](<02.09.01.03.03.03.02_Handling_an_Attributes_Definition_File.md>)

This section describes how to set up a driver configuration. For conceptual information about driver configuration, see [Basic Driver Usage](<02.09.01.03.02.02_Basic_Driver_Usage.md>).

A description how to configure the driver at run-time, is provided in [Changing the Driver Configuration at Run-Time](<02.09.01.03.03.04_Changing_the_Driver_Configuration_at_Run-Time.md>).

A driver configuration is an ASCII file which contains the settings for the configuration parameters.

At driver start-up, the file will be read and the driver will be configured correspondingly.

The global configuration defines which driver configuration file will be read. See [Setting Up the Global Configuration](<02.09.01.03.03.02_Setting_Up_the_Global_Configuration.md>) for details.

You can easily open, edit and save driver configurations with the provided editor.

A set of default driver configurations is provided with the driver. One plug-in typically is capable of addressing more than one specific type of equipment. Therefore, normally more than one default driver configuration files are provided with a plug-in. Each default file then configures the driver for a specific equipment (for example, a specific handler model).

See [Appendix A: Plug-In and Default Configuration Files](<02.09.01.03.06_Plug-In_and_Default_Configuration_Files.md>) for a list of all plug-ins and default driver configurations provided with the current driver Revision 3.2.
