# PROB_HND_CALL

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.48.01_Associated_Syntax_Entities.md>)

Used to call a function that controls a wafer prober or a package handler.

The lines,

ACTIONS

PROB_HND_CALL(remove_die);

call the wafer prober routine "remove_die".
