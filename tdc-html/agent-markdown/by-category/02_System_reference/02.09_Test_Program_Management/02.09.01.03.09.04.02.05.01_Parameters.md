# Parameters:

- phEventCause_t reason

the identifier of the problem which caused the call of phHookProblem.

In the switch(reason) section, the function contains the code to be executed for the respective problem.

- phEventDataUnion_t *data

contains data associated with the problem which caused the calling of this hook function.

- phEventResult_t *result

see [Common Components of All Hook Functions](<02.09.01.03.09.04.02.01_Common_Components_of_All_Hook_Functions.md>).

- phTcomUserReturn_t *stReturn

see [Common Components of All Hook Functions](<02.09.01.03.09.04.02.01_Common_Components_of_All_Hook_Functions.md>).
