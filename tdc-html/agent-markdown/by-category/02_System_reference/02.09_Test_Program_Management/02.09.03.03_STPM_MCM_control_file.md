# STPM MCM control file

An STPM MCM control file contains a script that tells SmarTest Program Manager MCM how to perform an conversion process. The detailed rules for combining the files are set out in the [MTPT (STPM MCM mapping tables)](<02.09.03.04_MTPT__STPM_MCM_mapping_tables.md>).

There are commands for generating mapping tables or test program directories, for creating the MTP or updating specific objects in the MTP, as well as for executing Python scripts. The control file also contains a number of global settings.

## Functional changes

- Introduced in SmarTest 7.1.4
