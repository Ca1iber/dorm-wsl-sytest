# test_desc

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.59.01_Associated_Syntax_Entities.md>)

The test_desc keyword is used as an argument for [GET_TEST_INFO](<02.09.01.02.05.02.36_GET_TEST_INFO.md>) return the description of the current test as entered in the Test Description field of the Information screen of the testflow editor.

## Functional changes

- Introduced before SmarTest 6.3.2
