# Running Hook Functions

To finally use the user-specific hook functions you must carry out the following two steps:

- Set up your global configuration file to select the plug-in directory which contains the user-specific hook functions. (See [Setting Up the Global Configuration](<02.09.01.03.03.02_Setting_Up_the_Global_Configuration.md>)).
- In the Data Manger's test program page, select as Prober/Handler driver the general equipment driver which you have installed and compiled as described in [Preparing a Driver for Hook Function Use](<02.09.01.03.09.03_Preparing_a_Driver_for_Hook_Function_Use.md>), and which contains the plug-in with the user-specific hook functions.

For example, select in n the Data Manger's test program page the driver /home/user/mydriver/GenericHandler

(for details see [Selecting the General Equipment Driver](<02.09.01.03.03.01_Selecting_the_General_Equipment_Driver.md>)).
