# tester_id

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.61.01_Associated_Syntax_Entities.md>)

The tester_id keyword is used as an argument for [GET_TEST_INFO](<02.09.01.02.05.02.36_GET_TEST_INFO.md>) to return the ID of the V93000 tester on which the test program is executed.

## Functional changes

- Introduced in SmarTest 6.5.4
