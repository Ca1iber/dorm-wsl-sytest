# CPI functions

The table below identifies some of the functions found in the CPI library.

Some functions from the CPI library
 |

Function

 |

Description

 |
 |

ExecTestProgram()

 |

Executes the test program currently loaded in the Test Program Explorer. This is the same function as the execute option in the Test Program Explorer. After the test program is started, this procedure does not wait for the test program execution.

 |
 |

SetModelfileString()

 |

Sets the value of an application model variable. Note that these variables are implicitly declared as strings.

 |
 |

GetModelfileString()

 |

Retrieves the current value of an application model variable.

 |
 |

SetSystemFlag()

SetSystemFlagOfSite()

 |

Sets the value of a system flag. Some such flags are referred to by CI_PAUSE, CI_ABORT, CI_RESET, CI_QUIT, CI_LEVEL_END. You can specify which site you want using the second function.

 |
 |

GetSystemFlag()

GetSystemFlagOfSite()

 |

Retrieves the value of a system flag. You can specify which site you want using the second function.

 |
 |

SetTestflowFlag(

 |

Sets the value of a testflow flag. Flags are actually declared as int, but are typecast to long within this function for compatibility with VEE.

 |
 |

GetTestflowFlag()

 |

Retrieves the value of a testflow flag.

 |
 |

GetPackageId()

GetPackageIdOfSite()

 |

Retrieves the string currently set as the package ID. You can specify which site you want using the second function.

 |
 |

GetDiePosXY()

GetDiePosXYOfSite()

 |

Retrieves the currently set X and Y die coordinates of the die about to be tested, or which has just been tested, depending on whether the call is made before or after a device test. You can specify which site you want using the second function.

 |
 |

GetBinList()

 |

Generates a bin list and copies it to the caller provided buffer.

   |
