# CASSETTE_COMPLETED

This asynchronous event indicates that the execution of a Cassette level is finished in the test program execution.

## Dependency and constraints

- The test program is in execution.
- If the application model does not contain the custom Cassette level or does not use the standard prober/handler driver function call (ph_cassette_done) or the equivalent, this event may not be generated. The lot ID variable name should be `ph_LOT_ID` or `LOT_ID`. The cassette ID variable name should be `ph_CASSETTE_ID`, `CASSETTE_ID`, `ph_CASS_ID` or `CASS_ID`.
