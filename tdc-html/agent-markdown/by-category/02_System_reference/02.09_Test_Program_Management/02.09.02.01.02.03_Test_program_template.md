# Test program template

A test program template is a collection of files that describe the basic structure of a testflow and related information. STPM can convert testflows into test program templates and vice versa.

Test program templates can be created either from an existing testflow or using an empty set of files.

They consist of a number of files that together describe the structure of a test program, without some device-specific details such as primaries.

A test program template is made up of these files:

- A [Testflow file](<../02.08_Setup_and_Result_Tools/02.08.04.32.03.05_Testflow_file.md>) containing placeholder test suites (test suites that do not contain actual test methods)
- A [Pin configuration file](<../02.08_Setup_and_Result_Tools/02.08.04.18.04_Pin_configuration_file.md>)
- A [.technology file](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.07.02.01.02_Technology_file_for_a_device.md>)
- A set of [CSV files](<02.09.02.05_Test_program_template_files.md>) that describe the test suites, test types, bins, sets of test suite flags, and test stages
- A [spreadsheet for OpenOffice Calc](<02.09.02.05.07_OpenOffice_spreadsheet_for_editing_the_CSV_files.md>) that allows easy editing of the CSV files
- A [merge rules file](<02.09.02.04_STPM_merge_rules_file.md>) specifying details about creating the test program
