# Function: ph_reprobe

This function makes the driver send a reprobe command to the equipment. Calling this function if the equipment does not support reprobe will generate an error message, but have no other effect.

Applicable for: handler and prober driver

Example: PROB_HND_CALL (ph_reprobe)
