# Aborting a Production Run

Aborting a production test halts the execution of the test, and returns the software to its initial state. The settings that have been downloaded to the tester, however, remain unchanged.

To abort a production test, click the ABORT toggle button in the Operation Control window shown in [Controlling a Production Run](<02.09.01.07_Controlling_a_Production_Run.md>). A dialog appears asking if you really want to abort the test; if so, click OK. The Operation Control screen returns to its default state (when you first logged in, see [Starting SmarTest with supervisor mode](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.01.01_Starting_SmarTest_with_supervisor_mode.md>), for example).
