# CPI Functions

CPI functions are obtained if you include the file libcicpi.h at the beginning of each source file. This is automatically included in the fn_templ.c template file. Further information about CPI functions is given in [Command Set Programming Interface](<02.09.01.08.05_Command_Set_Programming_Interface.md>).
