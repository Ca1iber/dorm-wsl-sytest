# syncOperation

The `syncOperation` signature is to synchronously execute a control command which has output values. It has outputs and will impact the SmarTest system status after execution.

Prototype

```
xoc::hvmapi::Status syncOperation(
const string &opName,
ParamList &opResults,
const ParamList &opParams=ParamList( ),
const string &sessionID=string(""));
```

Parameters
 |

opName

 |

The synchronous command name to execute.

 |
 |

opResult

 |

The output result of the command.

 |
 |

opParams

 |

The parameter list of the command.

 |
 |

sessionID

 |

The ID of the session to work with.

 |

Example

```
ParamList opResults;
Status retVal = syncOperation("ExecDCUpdateCal", opResults,
                                   ParamList(), sessionId);
if ( ! retVal.isError() )
{
  printf("successful execution, and execution result is %s\n",
           opResults["CAL_EXEC_STATUS"]);
}
else
{
  printf("error (code=%s, description=%s), please check your operation",
          retVal.code(), retVal.text();
}
```
