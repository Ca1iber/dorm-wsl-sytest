# Handler status and setup

The driver asks for the handler status and sets up the handler.

The initiation actions are:

- `<communication test>`
- `<check handler status>`
- `<handler setup>`

 |

Message from driver

 |

Message from handler

 |

Description

 |
 |

Communication test:

 |

 |

 |
 |

`FR?`

 |

 |

The driver sends this command to test the communication between the handler and tester.

 |
 |

 |

`FRn`

 |

 |
 |

Check handler status:

 |

 |

 |
 |

`FR?`

 |

 |

The driver asks for the operating state of the handler.

 |
 |

 |

`FRn`

 |

The handler returns FR0 or FR1.

When the FR0 is returned:

- The handler operation stops.
- An alarm occurs.
- The lot end sequence is executed.
- The [Tester Interface] parameter is set to [Disconnected].

FR1 is returned in all other cases.

 |
 |

Handler setup:

 |

 |

 |
 |

`DL n (n = 0|1|2)`

 |

 |

This command sets the block delimiter of the data to be sent from the handler.

 |
 |

`SRQMASK nn`

 |

 |

This command masks the status byte for serial polling.
