# IsLotDone()

This API checks whether all the lots are finished.

SUCCESS will be returned if no error occurred. Otherwise, an error object will be returned indicating the error code, description and severity.

 |

Code

 |

Typical Description

 |

Severity

 |
 |

ILLEGAL_OPERATION

 |

- The designated session ID "XXX" does not exist.
- The local session does not exist.
 |

RECOVERABLE

 |

## Parameters

 |

I/O

 |

Parameter

 |

Description

 |
 |

I

 |

SESSION_ID

 |

The ID of the session to work with.

 |
 |

O

 |

IS_LOT_DONE

 |

If all the lots are finished, the value is `TRUE`. Otherwise, it is `FALSE`.

 |

Prototype

```
ParamList outputResults;
Status query("IsLotDone", outputResults, ParamList(), sessionID);
```

## Example

```
string sid = LOCAL_SESSION_ID;
ParamList outputResults;

Status retVal = query("IsLotDone", outputResults, ParamList(), sid);
if ( retVal.isSuccess() )
{
cout<< "The LOT status = " << outputResults["IS_LOT_DONE"] << endl;
}
```
