# Selecting the General Equipment Driver

The general equipment driver is selected via the prober handler library selection of the test program.

There is one general handler driver, and one general prober driver.

To select the general equipment driver:

- In the Test Program Explorer highlight the item Prober/Handler...
- Right-click and select Load. Select the driver 鈥楪enericHandler' or the driver 鈥楪enericProber'. These drivers are located in the directory /opt/hp93000/soc/PH_libs/.

Or, if you use a driver re-compilation (for example when having implemented hook functions), load the re-compiled driver 鈥楪enericHandler' or 鈥楪enericProber' from your path for re-compiled drivers.

If you prefer to directly edit the test program file with an ASCII editor, include the line

Hp_lib: /opt/hp93000/soc/PH_libs/GenericHandler

or

Hp_lib: /opt/hp93000/soc/PH_libs/GenericProber

Or specify the path of the driver re-compilation, respectively.
