# Using Production Settings

#### Subtopics

- [Creating Production Settings](<02.09.01.06.03.01_Creating_Production_Settings.md>)
- [Merging Production Settings](<02.09.01.06.03.02_Merging_Production_Settings.md>)

For a user with engineering status the Production Settings button is available in the Operation Control window (see [Starting SmarTest with engineer mode](<../../01_Getting_started/01.01_SmarTest_Work_Center/01.01.01.03_Starting_SmarTest_with_engineer_mode.md>)). This button brings up a dialog box that contains buttons to access all SmarTest flags (see [Accessing Testflow Settings](<02.09.01.06.02_Accessing_Testflow_Settings.md>)). Clicking Enter Production Settings Mode displays the screen shown below.

 Note Clicking Enter Testflow Settings Mode returns you into the Testflow Settings mode (see [Accessing Testflow Settings](<02.09.01.06.02_Accessing_Testflow_Settings.md>)).   ![Accessing Flags in Production Settings Mode](<../../../../raw/46402.png>)

In Production Settings Mode, the same flags are available (as described in [Accessing Testflow Settings](<02.09.01.06.02_Accessing_Testflow_Settings.md>)), but you can change their values and store them in Production Settings files.

Production Settings enable you to apply a particular focus for test execution and for the evaluation and logging of result information. You can quickly change the focus for production pass/fail testing vs. engineering characterization by just using another set of Production Settings.

 Note Production Settings are user specific and the Production Settings files are stored by default in the user's home directory.

When defining a workorder, you can specify a Production Settings file (see[Editing Workorders](<02.09.01.05.02_Editing_Workorders.md>)). In this case, the file gets loaded during production and overwrites the flags saved in the testflow file.

Changing the flags in Production Settings mode has no effect on the flags that were set in testflow settings mode (see [Accessing Testflow Settings](<02.09.01.06.02_Accessing_Testflow_Settings.md>)) or within the Test Flow Editor in the development environment.

  Note If you change a flag from Production Settings, all current flag values are written to the working copy of the test flow. The associated testflow is marked as changed. Saving the testflow overwrites the original testflow with the working copy and the current values become the new initial values of the testflow.

The following sections describe how to create new Production Settings and how to merge existing settings from either Testflow or Production Setting files. Moreover, the File Menu of the Production Settings Mode window provides functions for loading and deleting Production Settings files.
