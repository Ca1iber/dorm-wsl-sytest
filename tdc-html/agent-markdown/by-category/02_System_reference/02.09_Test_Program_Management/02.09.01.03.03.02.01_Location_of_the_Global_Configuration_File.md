# Location of the Global Configuration File

The default name and location of the global configuration file is:

- For the general handler driver:

Name: Global-handler-config.cfg

Directory: /etc/opt/hp93000/soc/PH_libs/GenericHandler/

- For the general prober driver:

Name: Global-prober-config.cfg

Directory: /etc/opt/hp93000/soc/PH_libs/GenericProber/

When you edit a global configuration file, and save it afterwards, there are two ways to ensure that the global configuration file will be found at driver start-up.

One way is to give the global configuration file its default name, and save it to the default directory named above.

The other way is to set the environment variable GLOBAL_HANDLER_CONFIGURATION or GLOBAL_PROBER_CONFIGURATION to the path and name of the edited global configuration file.

This lets you freely choose the location and the name of the file.

## Example

export GLOBAL_HANDLER_CONFIGURATION=/home/username/global_configurations/global_conf_file_name

If the variable GLOBAL_HANDLER_CONFIGURATION or GLOBAL_PROBER_CONFIGURATION is set, a global configuration file in the default directory will be ignored.
