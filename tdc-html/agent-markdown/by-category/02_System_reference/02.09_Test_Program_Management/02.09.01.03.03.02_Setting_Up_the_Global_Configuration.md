# Setting Up the Global Configuration

#### Subtopics

- [Location of the Global Configuration File](<02.09.01.03.03.02.01_Location_of_the_Global_Configuration_File.md>)
- [Editing the Global Configuration](<02.09.01.03.03.02.02_Editing_the_Global_Configuration.md>)

The global configuration specifies which equipment specific plug-in and which driver configuration will be used by the general equipment driver (see [Driver Structure](<02.09.01.03.02.01_Driver_Structure.md>)).

At driver start-up, the global configuration file will be read. Then, the specified plug-in will be loaded into the driver, and the driver will be configured according to the definitions of the specified driver configuration file.

You can edit the global configuration file with a designated editor. This is described in [Editing the Global Configuration](<02.09.01.03.03.02.02_Editing_the_Global_Configuration.md>).

The global configuration file contains two global configuration parameters. One holds the plug-in directory and the other the name of the driver configuration file.
