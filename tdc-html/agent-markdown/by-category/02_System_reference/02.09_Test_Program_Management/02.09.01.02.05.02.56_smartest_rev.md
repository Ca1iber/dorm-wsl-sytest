# smartest_rev

#### Subtopics

- [Associated Syntax Entities](<02.09.01.02.05.02.56.01_Associated_Syntax_Entities.md>)

The smartest_rev keyword is used as an argument for [GET_TEST_INFO](<02.09.01.02.05.02.36_GET_TEST_INFO.md>) to return the revision number of the running SmarTest version.

## Functional changes

- Introduced in SmarTest 6.5.4
