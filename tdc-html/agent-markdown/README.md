# Agent Markdown

Markdown-first conversion of SmarTest 7.10.3 TDC HTML.

- `index.md`: main entry point.
- `by-category/`: Markdown pages grouped like the readable HTML tree.
- `catalog-markdown.csv`: mapping from original topic files to Markdown paths.
- Image, ZIP, PDF, script, and stylesheet links point back to the existing `raw/` and `pdf/` folders.

Converted pages: 9393
