## 检索提示

- 查询具体对象或函数：优先搜索完整符号名，再搜索缩写和自然语言名称。
- 查询开发流程：优先从 `01_Getting_started` 开始，再进入 `02_System_reference` 查细节。
- 查询硬件能力：同时查看系统规格、卡片规格、DUT board reference 和 Test Method 页面。
- 查询本地 SYTest 是否支持：TDC 只能作为 V93000/SmarTest 参考，必须再对照本地 ICTestUI、SYChipTest 或 S100 API 资料。
